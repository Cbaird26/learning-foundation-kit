@article
Do two quantities tend to rise and fall together? **Covariance** measures the tendency of $X$ and $Y$ to lie on the same side of their means at the same time. With $\mu_X = E[X]$ and $\mu_Y = E[Y]$,

$$\operatorname{Cov}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)] = E[XY] - E[X]\,E[Y].$$

Positive covariance means large values of $X$ tend to go with large values of $Y$; negative means they tend to go in opposite directions; zero means no *linear* tendency. Useful properties: $\operatorname{Cov}(X, X) = \operatorname{Var}(X)$, $\operatorname{Cov}(X, Y) = \operatorname{Cov}(Y, X)$, and $\operatorname{Cov}(aX + b,\ cY + d) = ac\,\operatorname{Cov}(X, Y)$.

### Variance of sums

Expanding the square in the definition of variance gives

$$\operatorname{Var}(aX + bY) = a^2\operatorname{Var}(X) + b^2\operatorname{Var}(Y) + 2ab\,\operatorname{Cov}(X, Y).$$

For many variables, $\operatorname{Var}\!\left(\sum_i X_i\right) = \sum_i \operatorname{Var}(X_i) + 2\sum_{i<j}\operatorname{Cov}(X_i, X_j)$. Variances simply add when every covariance is zero.

### Correlation

Covariance depends on units. The **correlation coefficient** removes them:

$$\rho = \frac{\operatorname{Cov}(X, Y)}{\sigma_X\,\sigma_Y}, \qquad -1 \le \rho \le 1.$$

The extremes $\rho = \pm 1$ occur exactly when $Y = aX + b$ with probability $1$, with the sign of $a$. Correlation measures **linear** association only.

### Independent versus uncorrelated

If $X$ and $Y$ are independent, then $E[XY] = E[X]E[Y]$, so $\operatorname{Cov}(X, Y) = 0$: independent variables are **uncorrelated**. The converse is false. Let $X$ be uniform on $\{-1, 0, 1\}$ and $Y = X^2$. Then $E[X] = 0$ and $E[XY] = E[X^3] = 0$, so $\operatorname{Cov}(X, Y) = 0$, yet $Y$ is completely determined by $X$. The symmetry of $X$ cancels any straight-line trend but not a curved relationship.

Independence is much stronger: it forces $\operatorname{Cov}(g(X), h(Y)) = 0$ for every pair of reasonable functions $g$ and $h$, while zero correlation tests only $g(x) = x$ and $h(y) = y$. (For a *jointly normal* pair, zero covariance does imply independence, but that is a special property of that family.)

```python
import numpy as np
rng = np.random.default_rng(0)
x = rng.integers(-1, 2, size=100_000)   # values -1, 0, 1
y = x**2
print(np.corrcoef(x, y)[0, 1])          # near 0, yet y is a function of x
```

@example
title: Covariance and correlation from a joint pmf
problem: Two $0$-$1$ variables have $p(0,0) = 0.4$, $p(0,1) = 0.1$, $p(1,0) = 0.1$ and $p(1,1) = 0.4$. Find $\operatorname{Cov}(X, Y)$, the correlation $\rho$ and $\operatorname{Var}(X + Y)$.
step: Marginals: $P(X = 1) = 0.1 + 0.4 = 0.5$ and $P(Y = 1) = 0.1 + 0.4 = 0.5$, so $E[X] = E[Y] = 0.5$.
step: Only the point $(1, 1)$ contributes to the product: $E[XY] = 1 \cdot 1 \cdot 0.4 = 0.4$.
step: Covariance: $\operatorname{Cov}(X, Y) = 0.4 - 0.5 \cdot 0.5 = 0.15$.
step: Each variable is a coin flip with $p = 0.5$, so $\operatorname{Var}(X) = \operatorname{Var}(Y) = 0.25$ and $\rho = \dfrac{0.15}{\sqrt{0.25 \cdot 0.25}} = 0.6$.
step: Variance of the sum: $\operatorname{Var}(X + Y) = 0.25 + 0.25 + 2(0.15) = 0.8$, compared with $0.5$ if the variables were independent.

@example
title: Independent versus merely uncorrelated
problem: Let $X$ be uniform on $\{-1, 0, 1\}$. In model A, $Y$ is independent of $X$ with $P(Y = 1) = \frac{2}{3}$ and $P(Y = 0) = \frac{1}{3}$. In model B, $Y = X^2$. Compare the two models using the covariance, an independence check and the quantity $\operatorname{Cov}(X^2, Y)$.
step: Both models give $Y$ the same distribution: in model B, $Y = 1$ when $X = \pm 1$ (probability $\frac{2}{3}$) and $Y = 0$ when $X = 0$ (probability $\frac{1}{3}$).
step: Covariance. In A, independence gives $\operatorname{Cov}(X, Y) = 0$. In B, $E[X] = 0$ and $E[XY] = E[X^3] = \frac{-1 + 0 + 1}{3} = 0$, so $\operatorname{Cov}(X, Y) = 0$ as well. Both models are uncorrelated.
step: Independence check. In A, $P(X = 0, Y = 0) = \frac{1}{3} \cdot \frac{1}{3} = \frac{1}{9}$, matching the product of marginals. In B, $P(X = 0, Y = 0) = \frac{1}{3}$ but $P(X = 0)P(Y = 0) = \frac{1}{9}$, so B is dependent.
step: A nonlinear probe separates them. In A, $\operatorname{Cov}(X^2, Y) = 0$ by independence. In B, $Y = X^2$, so $\operatorname{Cov}(X^2, Y) = \operatorname{Var}(X^2) = E[X^4] - (E[X^2])^2 = \frac{2}{3} - \frac{4}{9} = \frac{2}{9} \ne 0$.
step: Takeaway: zero correlation rules out only a linear relationship. Independence rules out every relationship.

@mistakes
- Concluding that $\operatorname{Cov}(X, Y) = 0$ means $X$ and $Y$ are independent. It only means there is no linear trend.
- Writing $\operatorname{Var}(X - Y) = \operatorname{Var}(X) - \operatorname{Var}(Y)$. The variances add, and the covariance term enters with the sign of the coefficient product: $\operatorname{Var}(X) + \operatorname{Var}(Y) - 2\operatorname{Cov}(X, Y)$.
- Reading a correlation of $0.9$ as "$90\%$ of the variation is explained". The linear fit explains $\rho^2 = 81\%$.
- Quoting a correlation without looking at the data: one outlier or a curved pattern can make $\rho$ misleading.

prompt: The joint pmf of two $0$-$1$ variables is $p(0,0) = 0.3$, $p(0,1) = 0.2$, $p(1,0) = 0.1$ and $p(1,1) = 0.4$. Find $\operatorname{Cov}(X, Y)$.
answer: 0.1
check: (lambda T: sum(x * y * p for x, y, p in T) - sum(x * p for x, y, p in T) * sum(y * p for x, y, p in T))([(0, 0, 0.3), (0, 1, 0.2), (1, 0, 0.1), (1, 1, 0.4)])
hint: Use $\operatorname{Cov}(X, Y) = E[XY] - E[X]E[Y]$.
hint: $E[XY]$ has only one nonzero term, $p(1, 1)$. Get $E[X]$ and $E[Y]$ from the marginals.
solution: $E[X] = 0.1 + 0.4 = 0.5$, $E[Y] = 0.2 + 0.4 = 0.6$ and $E[XY] = 0.4$. So $\operatorname{Cov}(X, Y) = 0.4 - 0.5 \cdot 0.6 = 0.1$.

@practice num
prompt: Let $X$ be uniform on $\{-1, 0, 1\}$ and $Y = X^2$. Find $\operatorname{Cov}(X, Y)$.
answer: 0
check: sum(x * x**2 / 3 for x in (-1, 0, 1)) - sum(x / 3 for x in (-1, 0, 1)) * sum(x**2 / 3 for x in (-1, 0, 1))
hint: Compute $E[X]$, $E[Y]$ and $E[XY]$ using probability $\frac{1}{3}$ for each value of $X$.
solution: $E[X] = 0$ and $E[XY] = E[X^3] = \frac{-1 + 0 + 1}{3} = 0$, so $\operatorname{Cov}(X, Y) = 0 - 0 \cdot E[Y] = 0$. Yet $Y$ is determined by $X$: the variables are uncorrelated but dependent.

@practice ms
prompt: Which statements are true for random variables $X$ and $Y$ with finite positive variances? Select all that apply.
choice*: If $X$ and $Y$ are independent, then $\operatorname{Cov}(X, Y) = 0$.
choice: If $\operatorname{Cov}(X, Y) = 0$, then $X$ and $Y$ are independent.
choice*: If $\operatorname{Cov}(X, Y) = 0$, then $\operatorname{Var}(X + Y) = \operatorname{Var}(X) + \operatorname{Var}(Y)$.
choice: A correlation of $0.9$ means that $90\%$ of the variance of $Y$ is explained by a linear fit on $X$.
hint: Which direction of the implication "independent $\Rightarrow$ uncorrelated" is valid? And what is the fraction of variance explained by a linear fit?
solution: Independence gives $E[XY] = E[X]E[Y]$, hence zero covariance, but the converse fails (for example $Y = X^2$ with $X$ symmetric). With zero covariance the cross term in the variance of a sum vanishes. A linear fit explains $\rho^2 = 0.81$, not $0.9$, of the variance.

@practice self
prompt: Construct a joint pmf for two random variables $X$ and $Y$ that are uncorrelated but not independent, using a different construction from $Y = X^2$. Show that $\operatorname{Cov}(X, Y) = 0$ and exhibit a pair $(x, y)$ that violates $p(x, y) = p_X(x)\,p_Y(y)$.
hint: Look for a symmetric set of points on which the product $xy$ is always $0$ or cancels.
solution: Put probability $\frac{1}{4}$ on each of the four points $(1, 0)$, $(-1, 0)$, $(0, 1)$ and $(0, -1)$. Then $E[X] = \frac{1 + (-1) + 0 + 0}{4} = 0$ and likewise $E[Y] = 0$. Every point has a zero coordinate, so $XY = 0$ always and $E[XY] = 0$. Hence $\operatorname{Cov}(X, Y) = 0$. But $p(1, 1) = 0$ while $p_X(1)\,p_Y(1) = \frac{1}{4} \cdot \frac{1}{4} = \frac{1}{16} \ne 0$, so $X$ and $Y$ are not independent.
rubric: The joint pmf is valid: nonnegative entries that add to $1$.
rubric: The covariance is computed from $E[XY] - E[X]E[Y]$ and equals $0$.
rubric: One explicit pair $(x, y)$ is shown to violate the product rule, with the marginals computed.
rubric: The answer states that zero covariance rules out only linear association.

@quiz num
prompt: The joint density of $(X, Y)$ is $f(x, y) = x + y$ on the unit square $0 \le x, y \le 1$ (and $0$ elsewhere). Find $\operatorname{Cov}(X, Y)$ as an exact fraction.
answer: -1/144
check: quad2(lambda x, y: x * y * (x + y), 0, 1, 0, 1) - quad2(lambda x, y: x * (x + y), 0, 1, 0, 1) * quad2(lambda x, y: y * (x + y), 0, 1, 0, 1)
hint: Compute $E[XY]$, $E[X]$ and $E[Y]$ with double integrals over the unit square. By symmetry $E[X] = E[Y]$.
hint: $E[XY] = \iint xy\,(x + y)\,dx\,dy$, and $E[X] = \int_0^1 x\left(x + \tfrac{1}{2}\right)dx$.
solution: $E[XY] = \int_0^1\!\int_0^1 (x^2 y + x y^2)\,dx\,dy = \frac{1}{6} + \frac{1}{6} = \frac{1}{3}$ and $E[X] = E[Y] = \frac{1}{3} + \frac{1}{4} = \frac{7}{12}$. So $\operatorname{Cov}(X, Y) = \frac{1}{3} - \frac{49}{144} = -\frac{1}{144}$.

@article
A **continuous random variable** can take any value in an interval, such as a waiting time or a measured length. No single value carries positive probability, so instead of a pmf we use a **probability density function** (pdf) $f$, and probabilities are areas under its graph:

$$P(a \le X \le b) = \int_a^b f(x)\,dx.$$

A function $f$ is a valid density exactly when $f(x) \ge 0$ and $\int_{-\infty}^{\infty} f(x)\,dx = 1$. Note that $f(x)$ is **not** a probability: it can exceed $1$ (a density of $4$ on an interval of length $\frac14$ is fine), and $P(X = x) = 0$ for every single $x$.

The **cumulative distribution function** (cdf) is $F(x) = P(X \le x) = \int_{-\infty}^{x} f(t)\,dt$. It rises from $0$ to $1$, and $f = F'$ wherever $F$ is differentiable.

### Normalizing and moments

Often you know the *shape* of a density but not its scale. If $f(x) = c\,h(x)$ on a region and $0$ elsewhere, **normalize** by choosing

$$c = \frac{1}{\int h(x)\,dx}.$$

Expectations are then integrals in place of sums:

$$E[X] = \int x f(x)\,dx, \qquad E[g(X)] = \int g(x) f(x)\,dx, \qquad \operatorname{Var}(X) = E[X^2] - (E[X])^2.$$

Linearity of expectation and $\operatorname{Var}(aX + b) = a^2\operatorname{Var}(X)$ hold exactly as in the discrete case.

### Three continuous families

| Name | Density | Mean | Variance |
|---|---|---|---|
| Uniform$(a, b)$ | $\frac{1}{b-a}$ on $[a, b]$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| Exponential$(\lambda)$ | $\lambda e^{-\lambda x}$ for $x \ge 0$ | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ |
| Normal$(\mu, \sigma^2)$ | $\frac{1}{\sigma\sqrt{2\pi}}e^{-(x-\mu)^2/(2\sigma^2)}$ | $\mu$ | $\sigma^2$ |

The exponential has $P(X > t) = e^{-\lambda t}$ and is **memoryless**: $P(X > s + t \mid X > s) = P(X > t)$. In this model, a used component is as good as new.

For the normal distribution, **standardize**: $Z = \frac{X - \mu}{\sigma}$ is Normal$(0, 1)$, whose cdf is written $\Phi$. About $68\%$, $95\%$ and $99.7\%$ of the probability lies within $1$, $2$ and $3$ standard deviations of the mean. Python computes $\Phi$ from the error function:

```python
from math import erf, sqrt
def Phi(z):
    return 0.5 * (1 + erf(z / sqrt(2)))
print(round(Phi(1.96) - Phi(-1.96), 4))   # 0.95
```

@example
title: Normalize a density and find its moments
problem: The density of $X$ is $f(x) = c\,x^2$ for $0 \le x \le 3$ and $0$ elsewhere. Find $c$, $P(X \le 2)$, $E[X]$ and $\operatorname{Var}(X)$.
step: Normalize: $\int_0^3 c\,x^2\,dx = c \cdot \frac{3^3}{3} = 9c = 1$, so $c = \frac{1}{9}$.
step: The cdf on $[0, 3]$ is $F(x) = \int_0^x \frac{t^2}{9}\,dt = \frac{x^3}{27}$. Hence $P(X \le 2) = F(2) = \frac{8}{27} \approx 0.296$.
step: Mean: $E[X] = \int_0^3 x \cdot \frac{x^2}{9}\,dx = \frac{1}{9} \cdot \frac{3^4}{4} = \frac{9}{4}$.
step: Second moment: $E[X^2] = \int_0^3 \frac{x^4}{9}\,dx = \frac{1}{9} \cdot \frac{3^5}{5} = \frac{27}{5}$.
step: Variance: $\operatorname{Var}(X) = \frac{27}{5} - \left(\frac{9}{4}\right)^2 = \frac{432}{80} - \frac{405}{80} = \frac{27}{80} = 0.3375$.

@example
title: A normal probability by standardizing
problem: The fill volume of a bottle is Normal with mean $500$ mL and standard deviation $4$ mL. What fraction of bottles contain between $494$ mL and $504$ mL?
step: Standardize each endpoint with $z = (x - \mu)/\sigma$: $\frac{494 - 500}{4} = -1.5$ and $\frac{504 - 500}{4} = 1$.
step: The probability is the area between those $z$-values: $P = \Phi(1) - \Phi(-1.5)$.
step: Use $\Phi(1) \approx 0.8413$ and, by symmetry, $\Phi(-1.5) = 1 - \Phi(1.5) \approx 1 - 0.9332 = 0.0668$.
step: So $P \approx 0.8413 - 0.0668 = 0.7745$. About $77\%$ of bottles fall in that window.

@mistakes
- Treating $f(x)$ as a probability. It is a density: it can exceed $1$, and only areas under it are probabilities.
- Forgetting to normalize, or normalizing over the wrong interval, so that the total area is not $1$.
- Using $\sigma^2$ where $\sigma$ is needed when standardizing: divide by the standard deviation, not the variance.
- Computing $\operatorname{Var}(X)$ as $E[X^2]$ without subtracting $(E[X])^2$.

@practice num
prompt: A random variable $X$ is uniform on $[2, 8]$. What is $P(3 \le X \le 5)$?
answer: 1/3
check: quad(lambda x: 1 / (8 - 2), 3, 5)
hint: The density is constant, equal to $\frac{1}{b-a}$ on the interval.
hint: The probability is the area of a rectangle with height $\frac{1}{6}$ and width $5 - 3$.
solution: $P = \frac{5 - 3}{8 - 2} = \frac{2}{6} = \frac{1}{3}$.

@practice num
prompt: The function $f(x) = c\,(1 + x)$ for $0 \le x \le 2$ (and $0$ elsewhere) is a probability density. Find $c$.
answer: 1/4
check: 1 / quad(lambda x: 1 + x, 0, 2)
hint: The total area under a density must be $1$.
hint: Compute $\int_0^2 (1 + x)\,dx$, then choose $c$ so that $c$ times this integral equals $1$.
solution: $\int_0^2 (1 + x)\,dx = 2 + 2 = 4$, so $4c = 1$ and $c = \frac{1}{4}$.

@practice mc
prompt: A continuous random variable $X$ has density $f$. Which statement is correct?
choice*: $f(x)$ can exceed $1$ at some points, as long as the total area under $f$ is $1$.
choice: $f(x)$ is the probability that $X = x$.
choice: $P(X = 3)$ is positive whenever $f(3) > 0$.
choice: $P(a \le X \le b) = f(b) - f(a)$.
hint: Probabilities of continuous variables are areas, not heights.
solution: Only areas under $f$ are probabilities, so the height can exceed $1$ (a density equal to $4$ on an interval of length $\frac14$ has area $1$). Single points have probability $0$, and $P(a \le X \le b) = F(b) - F(a)$ uses the cdf $F$, not the density.

@practice num
prompt: The lifetime of a lamp is exponential with mean $10$ years, so its rate is $\lambda = 0.1$ per year. Find the probability that it lasts more than $15$ years. Round to four decimal places.
answer: 0.2231
check: quad(lambda t: 0.1 * exp(-0.1 * t), 15, 800)
tol: 0.0002
hint: For an exponential variable, $P(X > t) = \int_t^\infty \lambda e^{-\lambda s}\,ds$.
hint: This integral equals $e^{-\lambda t}$; use $\lambda = 0.1$ and $t = 15$.
solution: $P(X > 15) = e^{-0.1 \cdot 15} = e^{-1.5} \approx 0.2231$.

@practice num
prompt: A density has the shape $f(x) = c\,x(1 - x)$ on $0 \le x \le 1$ and $f(x) = 0$ elsewhere. Normalize it, then find $\operatorname{Var}(X)$. Give an exact fraction.
answer: 1/20
check: (lambda c: quad(lambda x: x**2 * c * x * (1 - x), 0, 1) - quad(lambda x: x * c * x * (1 - x), 0, 1)**2)(1 / quad(lambda x: x * (1 - x), 0, 1))
hint: First find $c$ from $\int_0^1 c\,x(1 - x)\,dx = 1$.
hint: Compute $E[X]$ and $E[X^2]$ with that $c$, then use $\operatorname{Var}(X) = E[X^2] - (E[X])^2$.
solution: $\int_0^1 x(1-x)\,dx = \frac{1}{6}$, so $c = 6$. By symmetry about $\frac12$, $E[X] = \frac{1}{2}$. Next $E[X^2] = 6\int_0^1 (x^3 - x^4)\,dx = 6\left(\frac14 - \frac15\right) = \frac{3}{10}$. Hence $\operatorname{Var}(X) = \frac{3}{10} - \frac{1}{4} = \frac{1}{20}$.

@quiz num
prompt: Exam scores are modeled as Normal with mean $70$ and standard deviation $8$. Find $P(62 < X < 90)$. Round to four decimal places.
answer: 0.8351
check: quad(lambda x: exp(-(x - 70)**2 / (2 * 8**2)) / (8 * sqrt(2 * pi)), 62, 90)
tol: 0.0003
hint: Standardize both endpoints with $z = (x - \mu)/\sigma$.
hint: The endpoints become $z = -1$ and $z = 2.5$, so $P = \Phi(2.5) - \Phi(-1)$. In Python, $\Phi(z) = \frac{1}{2}\left(1 + \operatorname{erf}(z/\sqrt{2})\right)$.
solution: The $z$-values run from $\frac{62 - 70}{8} = -1$ to $\frac{90 - 70}{8} = 2.5$. So $P = \Phi(2.5) - \Phi(-1) \approx 0.9938 - 0.1587 = 0.8351$.

@quiz expr
prompt: Let $X$ be uniform on $[a, b]$ with $0 < a < b$. Find $E[X^2]$ as an expression in $a$ and $b$.
vars: a, b
lead: $E[X^2] =$
answer: (a^2 + a*b + b^2)/3
check: lambda a, b: quad(lambda x: x**2 / (b - a), a, b)
domain: a: 0.2..1; b: 1.5..3
hint: The density is $\frac{1}{b-a}$ on $[a, b]$, so $E[X^2] = \int_a^b \frac{x^2}{b-a}\,dx$.
hint: $\int_a^b x^2\,dx = \frac{b^3 - a^3}{3}$, and $b^3 - a^3 = (b - a)(a^2 + ab + b^2)$.
solution: $E[X^2] = \frac{1}{b-a}\cdot\frac{b^3 - a^3}{3} = \frac{a^2 + ab + b^2}{3}$.

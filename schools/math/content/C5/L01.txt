@article
A **proposition** is a statement that is either true or false, never both. "17 is prime" is a proposition; "Close the door" and "$x > 3$" (with $x$ unspecified) are not. We name propositions with variables $p, q, r$ and combine them with **connectives**.

### The connectives

| Name | Symbol | Read as | True when |
|---|---|---|---|
| negation | $\neg p$ | not $p$ | $p$ is false |
| conjunction | $p \land q$ | $p$ and $q$ | both are true |
| disjunction | $p \lor q$ | $p$ or $q$ | at least one is true (inclusive or) |
| exclusive or | $p \oplus q$ | $p$ xor $q$ | exactly one is true |
| implication | $p \to q$ | if $p$ then $q$ | $p$ is false, or $q$ is true |
| biconditional | $p \leftrightarrow q$ | $p$ if and only if $q$ | $p$ and $q$ have the same truth value |

Implication surprises people. $p \to q$ is **false in exactly one case**: $p$ true and $q$ false. If $p$ is false the implication is *vacuously true*. "If $2 + 2 = 5$ then the moon is cheese" is a true implication. A promise "if you pass, I will buy lunch" is broken only when you pass and I do not buy lunch.

By convention $\neg$ binds tightest, then $\land$, then $\lor$, then $\to$, then $\leftrightarrow$. Use parentheses whenever a reader could hesitate.

### Truth tables

A formula with $n$ variables has $2^n$ assignments of truth values, so its **truth table** has $2^n$ rows. The table is a complete, mechanical proof of anything you claim about the formula.

- A **tautology** is true in every row (for example $p \lor \neg p$).
- A **contradiction** is false in every row (for example $p \land \neg p$).
- A formula that is true in at least one row is **satisfiable**.
- Two formulas are **logically equivalent**, written $\equiv$, when they have the same truth value in every row. Equivalently, $A \leftrightarrow B$ is a tautology.

### Equivalences worth memorizing

- Double negation: $\neg\neg p \equiv p$.
- De Morgan: $\neg(p \land q) \equiv \neg p \lor \neg q$ and $\neg(p \lor q) \equiv \neg p \land \neg q$.
- Implication as disjunction: $p \to q \equiv \neg p \lor q$.
- Negated implication: $\neg(p \to q) \equiv p \land \neg q$.
- Contrapositive: $p \to q \equiv \neg q \to \neg p$.
- Distribution: $p \land (q \lor r) \equiv (p \land q) \lor (p \land r)$, and the same with $\land$ and $\lor$ swapped.

Do not confuse the contrapositive with two near relatives. The **converse** $q \to p$ and the **inverse** $\neg p \to \neg q$ are equivalent to each other but **not** to $p \to q$.

### Translating English

- "$p$ only if $q$" is $p \to q$. ("You may drive only if you have a license.")
- "$p$ if $q$" is $q \to p$.
- "$p$ unless $q$" is $\neg q \to p$, which is equivalent to $p \lor q$.
- "Neither $p$ nor $q$" is $\neg p \land \neg q$.

### In Python

Python's `not`, `and` and `or` are the connectives. Implication is written `(not p) or q`, exclusive or on booleans is `p != q`, and the biconditional is `p == q`. Enumerating every assignment with `itertools.product((False, True), repeat=n)` turns a truth table into a loop, which you will do in the exercises.

@example
title: Proving De Morgan's law with a truth table
problem: Show that $\neg(p \land q) \equiv \neg p \lor \neg q$.
step: Two variables give $2^2 = 4$ rows. List every assignment of $p$ and $q$.
step: Compute the left side. $p \land q$ is true only for $p = T, q = T$, so $\neg(p \land q)$ has values $T, T, T, F$ for the rows $(F,F), (F,T), (T,F), (T,T)$.
step: Compute the right side. $\neg p$ and $\neg q$ are $T,T,F,F$ and $T,F,T,F$, so $\neg p \lor \neg q$ is $T, T, T, F$.
step: The two columns agree in all four rows, so the formulas are logically equivalent.
answer: Both formulas have the column $T, T, T, F$, so they are equivalent.

@example
title: Translating a requirement
problem: A site's rule says: "You can view the report only if you are logged in or you are an administrator." Write it as a formula and find its contrapositive.
step: Let $v$ be "you can view the report", $l$ be "you are logged in" and $a$ be "you are an administrator".
step: "$v$ only if ..." is an implication from $v$: the formula is $v \to (l \lor a)$.
step: The contrapositive swaps and negates: $\neg(l \lor a) \to \neg v$.
step: Apply De Morgan to the hypothesis: $(\neg l \land \neg a) \to \neg v$. In words: if you are neither logged in nor an administrator, you cannot view the report.
answer: $v \to (l \lor a)$, with contrapositive $(\neg l \land \neg a) \to \neg v$.

@mistakes
- Reading $p \to q$ as "$p$ causes $q$", or thinking it is false when $p$ is false. It is true whenever $p$ is false.
- Treating the converse $q \to p$ as if it were equivalent to $p \to q$. Only the contrapositive is.
- Writing $\neg(p \land q) \equiv \neg p \land \neg q$. De Morgan's law changes the connective as well as pushing the negation inward.
- Translating "$p$ only if $q$" as $q \to p$. The word "only" points the arrow away from $p$.

@practice code
prompt: Write `count_satisfying(f, n)`. Here `f` is a function taking `n` boolean arguments. Return how many of the $2^n$ assignments of `False` and `True` to those arguments make `f` return a true value. For `n = 0`, `f` takes no arguments and there is exactly one (empty) assignment. Example: `count_satisfying(lambda p, q: p and q, 2)` returns `1`.
starter:
```python
from itertools import product


def count_satisfying(f, n):
    pass
```
tests:
```python
assert count_satisfying(lambda p, q: p and q, 2) == 1
assert count_satisfying(lambda p, q: p or q, 2) == 3
assert count_satisfying(lambda p: p and not p, 1) == 0
assert count_satisfying(lambda p, q, r: (not p) or q or r, 3) == 7
assert count_satisfying(lambda: True, 0) == 1
```
model:
```python
from itertools import product


def count_satisfying(f, n):
    count = 0
    for values in product((False, True), repeat=n):
        if f(*values):
            count += 1
    return count
```
hint: `product((False, True), repeat=n)` yields every tuple of `n` booleans.
hint: Call `f(*values)` to pass a tuple as separate arguments, and count the tuples for which the result is true.
solution: Loop over all assignments produced by `product`, call `f` with each unpacked, and add 1 for each true result. For `n = 0`, `product` yields one empty tuple, so the count is `1` when `f()` is true.

@practice code
prompt: Write `equivalent(f, g, n)` that returns `True` if the boolean functions `f` and `g`, each taking `n` boolean arguments, give the same truth value on every assignment, and `False` otherwise. Return an actual `bool`. Example: De Morgan's law gives `equivalent(lambda p, q: not (p and q), lambda p, q: (not p) or (not q), 2)` is `True`.
starter:
```python
from itertools import product


def equivalent(f, g, n):
    pass
```
tests:
```python
assert equivalent(lambda p, q: not (p and q),
                  lambda p, q: (not p) or (not q), 2) is True
assert equivalent(lambda p, q: (not p) or q,
                  lambda p, q: (not (not q)) or (not p), 2) is True
assert equivalent(lambda p, q: (not p) or q,
                  lambda p, q: (not q) or p, 2) is False
assert equivalent(lambda p: p, lambda p: not p, 1) is False
assert equivalent(lambda p, q, r: p and (q or r),
                  lambda p, q, r: (p and q) or (p and r), 3) is True
```
model:
```python
from itertools import product


def equivalent(f, g, n):
    for values in product((False, True), repeat=n):
        if bool(f(*values)) != bool(g(*values)):
            return False
    return True
```
hint: Two formulas are equivalent when no assignment gives them different truth values.
hint: Loop over all assignments and return `False` as soon as you find one where `bool(f(*values)) != bool(g(*values))`; return `True` after the loop.
solution: A truth-table proof checks every row. Return `False` at the first disagreeing row and `True` if the loop finishes. The third test shows that an implication is not equivalent to its converse.

assert find_counterexample(lambda p, q: p or q,
                           lambda p, q: p and q, 2) == (False, True)
assert find_counterexample(lambda p, q: not (p and q),
                           lambda p, q: (not p) or (not q), 2) is None

model:
```python
from itertools import product


def find_counterexample(f, g, n):
    for values in product((False, True), repeat=n):
        if bool(f(*values)) != bool(g(*values)):
            return values
    return None
```
hint: This is the same loop as an equivalence test, except that you return the assignment itself.
hint: `product` already yields tuples, so return the tuple `values` when the two truth values differ, and `None` after the loop.
solution: Return the first disagreeing assignment, or `None` when the loop ends. Because `product` lists `(False, False)` first and then `(False, True)`, the first disagreement for $p \lor q$ versus $p \land q$ is `(False, True)`.

@quiz num
prompt: For how many of the 8 assignments to $p, q, r$ is the formula $(p \lor q) \to r$ true?
answer: 5
check: sum(1 for i in range(8) if (not (((i >> 2) & 1) or ((i >> 1) & 1))) or (i & 1))
hint: The implication is true when its hypothesis $p \lor q$ is false, and also when $r$ is true.
solution: If $p \lor q$ is false ($p = q = F$), the implication is true for both values of $r$: $2$ rows. If $p \lor q$ is true ($3$ assignments of $p, q$), it is true only when $r = T$: $3$ rows. Total $2 + 3 = 5$.

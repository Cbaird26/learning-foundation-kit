@article
Suppose a statement $P(n)$ is claimed for every integer $n \ge n_0$. You cannot check infinitely many cases, but you can build a chain: if the first case holds and each case implies the next, every case holds, like a line of dominoes where the first falls and each knocks over the next.

### The principle of induction

Let $P(n)$ be a statement about the integer $n$. To prove $P(n)$ for all $n \ge n_0$:

1. **Base case.** Prove $P(n_0)$.
2. **Inductive step.** Let $k \ge n_0$ be arbitrary and assume $P(k)$ (the **inductive hypothesis**). Prove $P(k + 1)$.

Then $P(n)$ holds for all $n \ge n_0$. Both parts are essential: the step alone proves nothing (the statement "$n = n + 1$" passes the step, since adding $1$ to both sides of $k = k + 1$ gives $k + 1 = k + 2$, but it has no base case), and a base case alone checks only one number.

Write the proof in a fixed shape: state $P(n)$ explicitly, say "by induction on $n$", prove the base case, then write "assume $P(k)$ for some $k \ge n_0$", then show where the hypothesis is used in proving $P(k + 1)$.

### Strong induction

In **strong induction**, the step may assume $P(j)$ for **all** $j$ with $n_0 \le j \le k$ and must prove $P(k + 1)$. It is equivalent in power to ordinary induction, but more convenient when $k + 1$ depends on an earlier case that is not $k$. Because the step can reach back several cases, you may need several base cases. A typical use is the existence of prime factorizations: if $n$ is composite, $n = ab$ with $2 \le a, b < n$, and both factors have factorizations by hypothesis.

A rule of thumb for base cases: if the step uses cases as far back as $P(k + 1 - m)$, you need base cases for the first $m$ values of $n$.

### Induction and recursion

Induction is the proof method for recursion. The recurrence $T(0) = 0$, $T(n) = 2T(n - 1) + 1$ (the number of moves in the Tower of Hanoi puzzle with $n$ disks) has the closed form $T(n) = 2^n - 1$. Proof: $T(0) = 0 = 2^0 - 1$; and if $T(k) = 2^k - 1$ then $T(k + 1) = 2(2^k - 1) + 1 = 2^{k+1} - 1$. A recursive function's correctness proofs follow the same pattern: the base case corresponds to the stopping condition and the inductive step to the recursive call.

```python
def hanoi_moves(n):
    if n == 0:
        return 0
    return 2 * hanoi_moves(n - 1) + 1
```

### How induction proofs go wrong

The step must work for **every** $k \ge n_0$, including the first one. A classic fallacy "proves" that all horses have the same colour by arguing that two overlapping groups of $k$ horses share a horse; the step silently fails for $k = 1$, where the groups do not overlap. Also, never prove $P(k + 1)$ by assuming $P(k + 1)$, and do not change the statement $P$ halfway through. When the step is hard, strengthening the statement (proving something stronger so the hypothesis gives more) sometimes makes induction work.

@example
title: Induction on a summation
problem: Prove that $1 + 2 + \cdots + n = \dfrac{n(n+1)}{2}$ for every integer $n \ge 1$.
step: Let $P(n)$ be the statement $\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$. We use induction on $n$.
step: Base case $n = 1$: the left side is $1$ and the right side is $\frac{1 \cdot 2}{2} = 1$.
step: Inductive hypothesis: assume $\sum_{i=1}^{k} i = \frac{k(k+1)}{2}$ for some $k \ge 1$.
step: Inductive step: $\sum_{i=1}^{k+1} i = \sum_{i=1}^{k} i + (k + 1) = \frac{k(k+1)}{2} + (k + 1)$ by the hypothesis.
step: Combine: $\frac{k(k+1)}{2} + \frac{2(k+1)}{2} = \frac{(k+1)(k+2)}{2}$, which is $P(k + 1)$. By induction, $P(n)$ holds for all $n \ge 1$. $\blacksquare$
answer: The sum equals $\frac{n(n+1)}{2}$ for every $n \ge 1$.

@example
title: A strong induction proof
problem: Show that every integer $n \ge 12$ can be written as $4a + 5b$ with integers $a, b \ge 0$ (postage with 4-cent and 5-cent stamps).
step: Let $P(n)$ say that $n = 4a + 5b$ for some $a, b \ge 0$. The step will use $P(n - 4)$, four cases back, so we need four base cases.
step: Base cases: $12 = 4 \cdot 3$, $13 = 4 \cdot 2 + 5$, $14 = 4 + 5 \cdot 2$, $15 = 5 \cdot 3$.
step: Strong inductive hypothesis: let $k \ge 15$ and assume $P(j)$ for every $12 \le j \le k$. We prove $P(k + 1)$.
step: Since $k + 1 \ge 16$, we have $12 \le k - 3 \le k$, so $P(k - 3)$ holds: $k - 3 = 4a + 5b$.
step: Then $k + 1 = (k - 3) + 4 = 4(a + 1) + 5b$, so $P(k + 1)$ holds. By strong induction, $P(n)$ holds for all $n \ge 12$. $\blacksquare$
answer: Every integer $n \ge 12$ can be written as $4a + 5b$ with $a, b \ge 0$.

@mistakes
- Omitting the base case, or checking a base case that is not the first value claimed.
- Assuming $P(k + 1)$ in the inductive step (circular), or proving the step for only some values of $k$.
- Using strong induction with too few base cases, so the step reaches back to cases that were never proved.
- Using the inductive hypothesis without naming it, so the reader cannot see where it is used.

@practice self
prompt: Prove by induction that $1 + 2 + 4 + \cdots + 2^n = 2^{n+1} - 1$ for every integer $n \ge 0$.
hint: Write $P(n)$, then in the step add $2^{k+1}$ to both sides of the hypothesis.
solution: Let $P(n)$ be $\sum_{i=0}^{n} 2^i = 2^{n+1} - 1$. Base case $n = 0$: the left side is $2^0 = 1$ and the right side is $2^1 - 1 = 1$. Inductive step: assume $P(k)$ for some $k \ge 0$, that is $\sum_{i=0}^{k} 2^i = 2^{k+1} - 1$. Then $\sum_{i=0}^{k+1} 2^i = (2^{k+1} - 1) + 2^{k+1} = 2 \cdot 2^{k+1} - 1 = 2^{k+2} - 1$, which is $P(k + 1)$. By induction the formula holds for all $n \ge 0$.
rubric: States $P(n)$ precisely and checks the base case $n = 0$ on both sides.
rubric: Writes the inductive hypothesis for an arbitrary $k \ge 0$ and uses it to replace the sum up to $k$.
rubric: Completes the algebra to $2^{k+2} - 1$ and concludes by induction.

@quiz self
prompt: Prove by induction that $n^3 - n$ is divisible by $3$ for every integer $n \ge 1$.
hint: Expand $(k+1)^3 - (k+1)$ and look for $k^3 - k$ inside it.
solution: Let $P(n)$ say $3 \mid n^3 - n$. Base case $n = 1$: $1 - 1 = 0 = 3 \cdot 0$, so $P(1)$ holds. Inductive step: assume $3 \mid k^3 - k$ for some $k \ge 1$, say $k^3 - k = 3m$. Then $(k+1)^3 - (k+1) = k^3 + 3k^2 + 3k + 1 - k - 1 = (k^3 - k) + 3k^2 + 3k = 3m + 3(k^2 + k) = 3(m + k^2 + k)$, which is divisible by $3$. So $P(k + 1)$ holds, and by induction $P(n)$ holds for all $n \ge 1$.
rubric: Checks the base case $n = 1$ and states the inductive hypothesis as $k^3 - k = 3m$ for an integer $m$.
rubric: Expands $(k+1)^3 - (k+1)$ correctly and isolates $k^3 - k$ so the hypothesis can be used.
rubric: Factors out $3$ to show divisibility and concludes by induction.

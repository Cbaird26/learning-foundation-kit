@article
Find all functions $f\colon \mathbb{R} \to \mathbb{R}$ with $f(x) + 3f(1 - x) = x$ for every real $x$. There is no formula to differentiate and no number to compute; the unknown is a whole function. Two ideas solve this at once: the equation holds for **every** $x$, so we may replace $x$ by anything; and the unknown values $f(x)$ and $f(1-x)$ can be treated as two unknowns of a linear system.

### Strategy for functional equations

1. **Special values.** Put $x = 0$, $x = 1$, or $y = 0$ to find $f(0)$, $f(1)$ and relations among values.
2. **Symmetry and substitution.** Replace $x$ by a function of $x$ that maps the equation to a new one in the same unknowns (here $x \mapsto 1 - x$).
3. **Injectivity and surjectivity.** From $f(f(x)) = x$ it follows that $f$ is bijective; such facts let you cancel $f$ from both sides.
4. **Reduce to a known equation**: subtract a guessed particular solution, as in the example below.
5. **Always verify.** Steps 1 to 4 show that *if* a solution exists it has a certain form; you must substitute the form back to check that it is a solution.

### Roots of polynomials

**Theorem.** A nonzero polynomial of degree $d$ with real (or complex) coefficients has at most $d$ roots.

*Proof.* Induct on $d$. A nonzero constant ($d = 0$) has no roots. Suppose the claim holds for degree $d - 1$ and let $P$ have degree $d \ge 1$. If $P$ has no root we are done. Otherwise, let $r$ be a root; by division, $P(x) = (x - r)Q(x) + P(r) = (x - r)Q(x)$ with $\deg Q = d - 1$ (the **factor theorem**). Any other root $s \ne r$ satisfies $(s - r)Q(s) = 0$, so $Q(s) = 0$. By the inductive hypothesis $Q$ has at most $d - 1$ roots, so $P$ has at most $d$. $\blacksquare$

**Corollary (identity theorem).** If two polynomials $P$ and $Q$ agree at infinitely many points, or if both have degree at most $n$ and agree at $n + 1$ points, then $P = Q$. (Apply the theorem to $P - Q$, which has too many roots to be nonzero.)

The field matters: over the integers modulo $6$, the polynomial $x^2 - x$ has the four roots $0, 1, 3, 4$. The theorem needs coefficients in a field, where $ab = 0$ forces $a = 0$ or $b = 0$.

**Rational root theorem.** Let $P(x) = a_n x^n + \dots + a_0$ have integer coefficients with $a_n \ne 0 \ne a_0$. If $p/q$ in lowest terms is a root, then $p \mid a_0$ and $q \mid a_n$. *Proof.* Multiply $P(p/q) = 0$ by $q^n$: $a_n p^n + a_{n-1}p^{n-1}q + \dots + a_0 q^n = 0$. Then $p \mid a_0 q^n$ and $\gcd(p, q) = 1$, so $p \mid a_0$; likewise $q \mid a_n p^n$ gives $q \mid a_n$. $\blacksquare$

### Cauchy's equation on the rationals

**Lemma.** If $g\colon \mathbb{Q} \to \mathbb{Q}$ satisfies $g(x + y) = g(x) + g(y)$ for all $x, y \in \mathbb{Q}$, then $g(x) = cx$ for all $x$, where $c = g(1)$.

*Proof.* Taking $x = y = 0$ gives $g(0) = 0$, and $y = -x$ gives $g(-x) = -g(x)$. Induction on $n$ gives $g(nx) = n g(x)$ for $n \in \mathbb{N}$. For $x = m/n$ with $m \in \mathbb{Z}$, $n \in \mathbb{N}$, we get $n g(m/n) = g(m) = m g(1)$, so $g(m/n) = \frac mn g(1)$. $\blacksquare$

On $\mathbb{R}$ the conclusion fails without an extra hypothesis such as continuity: there are additive functions $\mathbb{R} \to \mathbb{R}$ that are not of the form $cx$, but their construction requires the axiom of choice and they are not continuous. So always state the domain.

### Test candidates by program

Before proving that a function solves an equation, test it on exact rational inputs:

```python
from fractions import Fraction

f = lambda x: (3 - 4 * x) / 8
points = [Fraction(k, 3) for k in range(-9, 10)]
print(all(f(x) + 3 * f(1 - x) == x for x in points))
```

This prints `True`, which is evidence. The substitution argument in the example below proves that this is the only solution.

@example
title: A functional equation by swapping
problem: Find all functions $f\colon \mathbb{R} \to \mathbb{R}$ such that $f(x) + 3f(1 - x) = x$ for all real $x$.
step: Replace $x$ by $1 - x$ in the equation. Since $1 - (1 - x) = x$, we obtain a second equation: $f(1 - x) + 3f(x) = 1 - x$.
step: Treat $f(x)$ and $f(1 - x)$ as unknowns $u$ and $v$: $u + 3v = x$ and $3u + v = 1 - x$. Multiply the second equation by $3$: $9u + 3v = 3 - 3x$.
step: Subtract the first equation: $8u = 3 - 4x$, so $f(x) = \frac{3 - 4x}{8}$. Hence if a solution exists it must be this function.
step: Verify: $f(x) + 3f(1 - x) = \frac{3 - 4x}{8} + \frac{3(3 - 4 + 4x)}{8} = \frac{3 - 4x + 12x - 3}{8} = x$. So it is a solution.
answer: The only solution is $f(x) = \dfrac{3 - 4x}{8}$.

@example
title: A polynomial from a difference equation
problem: Find all polynomials $P$ with real coefficients such that $P(x + 1) - P(x) = 2x + 3$ for all real $x$.
step: Guess a particular solution. Try $x^2 + 2x$: $(x+1)^2 + 2(x+1) - x^2 - 2x = 2x + 1 + 2 = 2x + 3$.
step: Let $Q(x) = P(x) - (x^2 + 2x)$. Subtracting the equations gives $Q(x + 1) - Q(x) = 0$ for all $x$, that is $Q(x + 1) = Q(x)$.
step: Then $Q(0) = Q(1) = Q(2) = \dots = c$, a constant. So the polynomial $Q(x) - c$ has the infinitely many roots $0, 1, 2, \dots$.
step: By the theorem on roots, $Q(x) - c$ is the zero polynomial, so $Q$ is constant and $P(x) = x^2 + 2x + c$. Every such $P$ works, as the particular solution does and constants cancel.
answer: $P(x) = x^2 + 2x + c$ for an arbitrary constant $c$.

@mistakes
- Stopping after deriving a formula: the derivation shows what a solution must look like, not that it is a solution. Substitute back.
- Dividing by an expression that could be zero (for example by $f(0)$ or by $x$) without treating that case separately.
- Applying the root theorem over a ring such as the integers modulo $6$, where a polynomial can have more roots than its degree.
- Using Cauchy's equation to conclude $f(x) = cx$ on $\mathbb{R}$ without continuity or monotonicity: the domain must be $\mathbb{Q}$ or the extra hypothesis must be given.

prompt: Find all functions $f\colon \mathbb{Q} \to \mathbb{Q}$ such that $f(x + y) = f(x) + f(y) + xy$ for all rational $x, y$. Prove that your answer is correct.
hint: Subtract a particular solution: try $x^2/2$. What equation does $g(x) = f(x) - x^2/2$ satisfy?
solution: Let $g(x) = f(x) - \frac{x^2}{2}$. Then $g(x + y) = f(x + y) - \frac{(x+y)^2}{2} = f(x) + f(y) + xy - \frac{x^2 + 2xy + y^2}{2} = g(x) + g(y)$. So $g$ is additive on $\mathbb{Q}$ and, by Cauchy's lemma (taking $x = y = 0$ gives $g(0) = 0$; induction gives $g(nx) = ng(x)$; and $n\,g(m/n) = g(m) = m g(1)$), $g(x) = cx$ with $c = g(1)$. Hence $f(x) = \frac{x^2}{2} + cx$ for a rational constant $c$. Conversely, for $f(x) = \frac{x^2}{2} + cx$: $f(x) + f(y) + xy = \frac{x^2 + y^2 + 2xy}{2} + c(x + y) = f(x + y)$. So the solutions are exactly $f(x) = \frac{x^2}{2} + cx$ with $c \in \mathbb{Q}$.

model:
```python
from fractions import Fraction


def divisors(n):
    """Positive divisors of the positive integer n."""
    return [d for d in range(1, n + 1) if n % d == 0]


def rational_roots(coeffs):
    """Distinct rational roots of an integer polynomial, sorted."""
    coeffs = list(coeffs)
    roots = set()
    while len(coeffs) > 1 and coeffs[-1] == 0:
        coeffs.pop()
        roots.add(Fraction(0))
    if len(coeffs) > 1:
        for p in divisors(abs(coeffs[-1])):
            for q in divisors(abs(coeffs[0])):
                for sign in (1, -1):
                    r = Fraction(sign * p, q)
                    value = Fraction(0)
                    for c in coeffs:
                        value = value * r + c
                    if value == 0:
                        roots.add(r)
    return sorted(roots)
```
hint: Remove trailing zero coefficients first (each gives the root $0$). Then try every $\pm p/q$ with $p$ dividing the constant term and $q$ dividing the leading coefficient, evaluating with Horner's rule in exact arithmetic.
solution: The rational root theorem restricts candidates to $\pm p/q$ with $p \mid a_0$ and $q \mid a_n$, and evaluating with `Fraction` avoids rounding errors. Trailing zeros must be stripped before using the theorem, because the theorem needs $a_0 \ne 0$. A set removes duplicate candidates such as $\frac{2}{4}$ and $\frac12$. The number of candidates is finite, which is the point of the theorem.

@quiz num
prompt: A polynomial $P$ of degree at most $3$ satisfies $P(0) = 1$, $P(1) = 4$, $P(2) = 15$ and $P(3) = 40$. Find $P(4)$.
answer: 85
check: sum(y * math.prod(Fraction(4 - xj, xi - xj) for xj in range(4) if xj != xi) for xi, y in enumerate([1, 4, 15, 40]))
hint: Four values determine a polynomial of degree at most $3$ (why?). Use finite differences: the third differences are constant.
solution: Two polynomials of degree at most $3$ that agree at four points are equal, so $P$ is determined. The first differences of $1, 4, 15, 40$ are $3, 11, 25$, the second differences are $8, 14$, and the third difference is $6$, constant for a cubic. Extending, the next second difference is $20$, the next first difference is $45$, and $P(4) = 40 + 45 = 85$. (Indeed $P(x) = x^3 + x^2 + x + 1$.)

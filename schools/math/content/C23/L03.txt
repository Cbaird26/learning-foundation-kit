@article
A frog sits at the point $(0, 0)$ of the integer lattice. Each jump is one of three kinds: $(+1, +2)$, $(+2, +1)$ or $(-3, 0)$. Can the frog reach $(4, 4)$? A search through sequences of jumps never ends, because there are infinitely many. We need a reason that covers all sequences at once.

### Invariants

A **process** consists of states and allowed moves. An **invariant** is a quantity $I$ computed from a state such that every allowed move leaves $I$ unchanged. If $I$ has one value at the start and a different value at the target, then no sequence of moves, however long, leads from the start to the target. The logic is the contrapositive of "if the target is reachable, then its invariant equals the start's".

**Claim.** The frog cannot reach $(4, 4)$.

*Proof.* Let $I(x, y) = (x + y) \bmod 3$. A jump $(+1, +2)$ or $(+2, +1)$ increases $x + y$ by $3$ and the jump $(-3, 0)$ decreases it by $3$, so every jump preserves $x + y$ modulo $3$. At the start $I(0, 0) = 0$, so every reachable point has $x + y \equiv 0 \pmod 3$. But $4 + 4 = 8 \equiv 2 \pmod 3$. $\blacksquare$

The proof checked **every** allowed move. Checking one move, or one typical sequence, is a common error.

### Invariants do not prove reachability

Does the invariant say that $(5, 4)$ is reachable, since $5 + 4 = 9 \equiv 0$? No. It only says that $(5, 4)$ is not excluded. To show reachability you must construct the moves: four jumps $(+2, +1)$ reach $(8, 4)$, then one jump $(-3, 0)$ reaches $(5, 4)$. Equal invariants are necessary for reachability, never sufficient by themselves.

### Where invariants come from

Useful families are **parity** (is a count even or odd?), **residues** modulo $m$ of a sum, a difference or a weighted sum $ax + by$, **coloring** (give each cell a color and count cells of each color), and **products or sums of functions** such as $\sum x_i^2$. A good method: write down how each type of move changes the state, then look for a combination of coordinates in which all those changes cancel or are multiples of $m$.

### Monovariants

A **monovariant** is a quantity that changes in only one direction. If $M$ takes integer values, $M \ge 0$ always, and every move strictly decreases $M$, then the process must stop after at most $M_{\text{start}}$ moves, because a strictly decreasing sequence of nonnegative integers is finite. The integer hypothesis matters: the real numbers $1, \tfrac12, \tfrac14, \dots$ decrease forever and stay positive. A monovariant can also count moves exactly: if each move decreases $M$ by exactly $1$ and the process stops exactly when $M = 0$, then the number of moves is the starting value of $M$, whatever choices were made.

### Experimenting first

When you do not know what the invariant is, simulate and tabulate. This program explores the frog's reachable points inside a box and prints those it finds with $x + y$ not divisible by $3$ (there should be none):

```python
moves = [(1, 2), (2, 1), (-3, 0)]
seen = {(0, 0)}
todo = [(0, 0)]
while todo:
    x, y = todo.pop()
    for dx, dy in moves:
        p = (x + dx, y + dy)
        if abs(p[0]) <= 12 and abs(p[1]) <= 12 and p not in seen:
            seen.add(p)
            todo.append(p)
print([p for p in seen if (p[0] + p[1]) % 3 != 0])
```

It prints `[]`. This supports the conjecture; the proof above is what establishes it.

@example
title: Piles that can never match
problem: Three piles hold $5$, $7$ and $9$ coins. A move takes one coin from each of two piles and adds two coins to the third pile, so the total stays $21$. Prove that the piles can never hold $0$, $0$ and $21$ coins.
step: Describe the moves. Write the state as $(x, y, z)$. A move gives $(x-1, y-1, z+2)$, $(x-1, y+2, z-1)$ or $(x+2, y-1, z-1)$.
step: Find a quantity that no move changes. Look at $x - y$ modulo $3$. The first move leaves $x - y$ unchanged; the second changes it by $-3$; the third changes it by $+3$.
step: So $x - y \bmod 3$ is an invariant. At the start, $5 - 7 = -2 \equiv 1 \pmod 3$.
step: At the target $(0, 0, 21)$, $x - y = 0$, which is not $\equiv 1$. The values differ, so the target is unreachable.
answer: $x - y \bmod 3$ is invariant and equals $1$ at the start but $0$ at the target, so $(0, 0, 21)$ is never reached.

@example
title: A process that must stop
problem: A row of binary digits is changed by the rule: replace any adjacent pair $10$ by $01$. Show that the process stops from $1101001$, and find how many moves it makes.
step: Define a monovariant: $M$ is the number of pairs of positions $i < j$ with digit $1$ at $i$ and digit $0$ at $j$ (an inversion).
step: Effect of a move. Swapping an adjacent $10$ into $01$ changes the order of exactly that one pair of positions. Every other pair keeps its relative order. So $M$ decreases by exactly $1$.
step: The process stops exactly when no $10$ remains. A string without an inversion contains no $10$ pair at adjacent positions, and a string with an inversion must contain an adjacent $10$ somewhere between the two positions, so the process stops exactly when $M = 0$.
step: For $1101001$ the ones are in positions $1, 2, 4, 7$ and the zeros in $3, 5, 6$. The ones contribute $3 + 3 + 2 + 0 = 8$ inversions, so the process makes exactly $8$ moves, whatever order of moves is chosen, and ends at $0001111$.
answer: The process stops after exactly $8$ moves.

@mistakes
- Checking that a quantity is unchanged by one kind of move and forgetting the others.
- Concluding that a target is reachable because its invariant matches the start; you must construct the moves.
- Using a monovariant that is real-valued or not bounded below: the quantity $1/2^k$ decreases forever.
- Choosing an invariant after peeking at the target, then not recomputing it at the start; always compute the invariant at both ends.

@practice num
prompt: A particle starts at $0$ on the number line. In each step it jumps $6$ to the right or $9$ to the left. Over any number of steps, how many of the integers $1, 2, \dots, 100$ can it land on?
answer: 33
check: int(run("seen = {0}\ntodo = [0]\nwhile todo:\n    p = todo.pop()\n    for q in (p + 6, p - 9):\n        if abs(q) <= 300 and q not in seen:\n            seen.add(q)\n            todo.append(q)\nprint(sum(1 for k in range(1, 101) if k in seen))"))
hint: After $a$ right jumps and $b$ left jumps the position is $6a - 9b$. What do $6$ and $9$ have in common?
hint: Every position is a multiple of $3$. Which multiples of $3$ can you actually reach? Write $3k = 6a - 9b$ and look for $a, b \ge 0$.
solution: Both jumps are multiples of $3$, so the position stays a multiple of $3$ (the invariant is the position modulo $3$). Conversely every multiple of $3$ is reachable: $6a - 9b = 3(2a - 3b)$, and for $k \ge 0$ the choice $a = 2k$, $b = k$ gives $2a - 3b = k$, while for $k = -m < 0$ the choice $a = b = m$ gives $2a - 3b = -m$. The jumps can be made in any order on the infinite line. So the landing points are exactly the multiples of $3$, and those in $1, \dots, 100$ are $3, 6, \dots, 99$: there are $33$.

@practice ms
prompt: Which of these statements about a process with an invariant $I$ and an integer-valued quantity $M$ are true?
choice*: If $I$ has different values at the start and at a target state, the target can never be reached.
choice*: If $M \ge 0$ always and every move decreases $M$ by at least $1$, the process stops after at most $M_{\text{start}}$ moves.
choice: If $I$ has the same value at the start and at a target state, the target can be reached.
choice: If a real-valued quantity decreases at every move and stays positive, the process must stop.
hint: One of the two quantities needs an integer-valued hypothesis, and one of the two statements about $I$ is a converse.
solution: The first statement is the contrapositive of "reachable implies equal invariants". The second is the monovariant argument: a strictly decreasing sequence of nonnegative integers is finite. Equal invariants do not give reachability (the target might still be unreachable for other reasons). A positive real quantity can decrease forever, for example by halving.

@practice self
prompt: A board shows the single number $20$. A move chooses a number $n \ge 2$ on the board, erases it and writes two positive integers $a$ and $b$ with $a + b = n$. The process stops when every number on the board is $1$. Prove that the process always stops, and that it makes exactly $19$ moves, whatever choices are made.
hint: Track the sum of the numbers on the board and the count of numbers on the board.
hint: Look at $D = (\text{sum}) - (\text{count})$. How does a move change it?
solution: Let $D$ be the sum of the numbers on the board minus how many numbers there are. A move replaces $n$ by $a + b = n$, so the sum is unchanged, and the count increases by $1$. Thus every move decreases $D$ by exactly $1$. At the start $D = 20 - 1 = 19$. Every number on the board is a positive integer, so sum $\ge$ count, with equality exactly when every number is $1$; hence $D \ge 0$ always, and $D = 0$ exactly when the process has stopped. A move is available whenever some number is at least $2$, that is whenever $D > 0$. Since $D$ decreases by exactly $1$ per move from $19$ down to $0$, the process makes exactly $19$ moves and stops.
rubric: Defines the quantity $D$ = sum minus count (or an equivalent) and shows each move decreases it by exactly $1$.
rubric: Shows that $D = 0$ exactly when all numbers equal $1$, and that a move is possible whenever $D > 0$.
rubric: Concludes that the process stops after exactly $19$ moves, independent of the choices.

prompt: Three piles of coins start at $(5, 7, 9)$. A move takes one coin from each of two piles and puts two coins on the third. Using the invariant "$x - y$ modulo $3$", which position can never be reached?
choice*: $(6, 6, 9)$

choice: $(7, 6, 8)$

@quiz code
prompt: A process moves a point $(x, y)$ by one of the given move vectors at each step. Write `is_invariant(f, moves, points)` that returns `True` if, for every point `(x, y)` in `points` and every move `(dx, dy)` in `moves`, `f(x + dx, y + dy) == f(x, y)`, and `False` otherwise. For example, with `f = lambda x, y: 3*x + 2*y`, `moves = [(2, -3), (-2, 3)]`, the call returns `True` for any list of points. (Checking sample points can refute an invariant but proves nothing about all points.)
starter:
```python
def is_invariant(f, moves, points):
    pass
```
tests:
```python
pts = [(0, 0), (1, 1), (5, -2), (-4, 7)]
f = lambda x, y: 3 * x + 2 * y
assert is_invariant(f, [(2, -3), (-2, 3)], pts) is True
assert is_invariant(lambda x, y: x + y, [(2, -3), (-2, 3)], pts) is False
assert is_invariant(lambda x, y: (x + y) % 3, [(1, 2), (2, 1), (-3, 0)], pts) is True
assert is_invariant(lambda x, y: x * x - y, [(1, 1)], [(0, 0), (1, 0)]) is False
assert is_invariant(f, [], pts) is True
assert is_invariant(f, [(2, -3)], []) is True
```
model:
```python
def is_invariant(f, moves, points):
    """True if f is unchanged by every move at every sample point."""
    for x, y in points:
        for dx, dy in moves:
            if f(x + dx, y + dy) != f(x, y):
                return False
    return True
```
hint: Use two nested loops over the points and the moves, and return `False` as soon as one pair changes the value.
solution: Test every (point, move) pair; a single change shows that $f$ is not an invariant. The test with $x^2 - y$ shows why every sample point must be checked: at $(0, 0)$ the move $(1, 1)$ leaves the value $0$ unchanged, but at $(1, 0)$ it changes the value from $1$ to $3$. Passing on sample points is evidence only; an invariance proof must treat arbitrary $(x, y)$.

@quiz ms
prompt: In which of these processes must the process stop after finitely many moves, whatever choices are made?
choice*: A list of positive integers; a move replaces an entry $n \ge 2$ by two positive integers with sum $n$.
choice*: A row of letters $A$ and $B$; a move replaces an adjacent pair $BA$ by $AB$.
choice: A positive real number $x$; a move replaces $x$ by $x/2$.
choice: A row of binary digits; a move swaps any two adjacent digits that are different.
hint: For each process, look for an integer quantity that always moves one way, or a reason a move can be undone.
solution: In the first, the number of entries rises by $1$ per move and cannot exceed the sum, which is fixed. In the second, the number of pairs ($B$ before $A$) drops by exactly $1$ per move. Halving a positive real never reaches a stopping state, since a move is always available. In the last, a swap of $01$ can be undone by a swap of $10$, so the process can continue forever.

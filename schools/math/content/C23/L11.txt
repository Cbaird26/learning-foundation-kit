@article
Mathematicians write with **LaTeX**, a free typesetting system in which you write plain text with commands and a program turns it into a document. The site shows no images, so LaTeX source in this lesson appears in code blocks. A LaTeX source file is compiled on your own computer or in an online editor; nothing here runs in the browser, so check your work by compiling.

### The skeleton of a document

```text
\documentclass[11pt]{article}
\usepackage{amsmath, amssymb, amsthm}
\newtheorem{theorem}{Theorem}
\newtheorem{lemma}[theorem]{Lemma}

\title{Solutions to Problem Set 3}
\author{Your Name}
\date{}

\begin{document}
\maketitle

\section*{Problem 1}
Let $x > 0$. Then
\[
  x + \frac{1}{x} \ge 2 .
\]
\end{document}
```

Everything before `\begin{document}` is the **preamble**: the document class and packages. The package `amsmath` supplies aligned equations, `amssymb` more symbols such as the blackboard letters, and `amsthm` the theorem and proof environments.

### Math mode

Inline math goes between single dollar signs, as in this source line:

```text
The number $x^2 + 1$ is positive.
```

Displayed math goes between backslash-bracket pairs, `\[ ... \]`, or in an `equation` environment if you want a number. (Prefer the bracket form to double dollar signs in LaTeX source.) The core commands:

| Output | Source |
|---|---|
| $x^{10}$, $a_{n+1}$ | `x^{10}`, `a_{n+1}` |
| $\frac{a}{b+1}$ | `\frac{a}{b+1}` |
| $\sqrt{x^2+1}$, $\sqrt[3]{2}$ | `\sqrt{x^2+1}`, `\sqrt[3]{2}` |
| $\sum_{k=1}^{n} k^2$ | `\sum_{k=1}^{n} k^2` |
| $\int_0^1 x\,dx$ | `\int_0^1 x\,dx` |
| $\binom{n}{k}$ | `\binom{n}{k}` |
| $a \equiv b \pmod{n}$ | `a \equiv b \pmod{n}` |
| $a \mid b$, $x \le y$, $x \ne y$ | `a \mid b`, `x \le y`, `x \ne y` |
| $\mathbb{R}$, $\forall$, $\exists$ | `\mathbb{R}`, `\forall`, `\exists` |
| $\log x$, $\sin x$ | `\log x`, `\sin x` |

Three rules cause most errors. **Braces group:** `x^10` gives $x^1 0$ (only the `1` is raised), so write `x^{10}`. **Functions are commands:** `log x` sets the letters $l$, $o$, $g$ in italics, while `\log x` sets the operator with the right spacing. **Use `\mid`, not `|`, for divisibility**, and `\le`, `\ge` and `\ne` for inequalities.

### Aligned equations and theorems

To align a chain of equalities, use the `align*` environment, with `&` marking the alignment point and `\\` ending a line:

```text
\begin{align*}
  (a+b)^2 &= a^2 + 2ab + b^2 \\
          &\ge 4ab ,
\end{align*}
```

Theorems and proofs use the environments declared in the preamble:

```text
\begin{theorem}
  For $a, b \ge 0$ we have $\frac{a+b}{2} \ge \sqrt{ab}$.
\end{theorem}
\begin{proof}
  Since $(\sqrt a - \sqrt b)^2 \ge 0$, expanding gives
  $a + b \ge 2\sqrt{ab}$; divide by $2$.
\end{proof}
```

The `proof` environment ends with a box automatically.

### Generating source with a program

When you format a table of values or a list of cases, a program saves typing and mistakes. This function turns rows of numbers into the body of a LaTeX table:

```python
def table_rows(rows):
    """LaTeX table body: cells joined by ' & ', each row ending in \\\\."""
    return "\n".join(" & ".join(str(c) for c in row) + r" \\" for row in rows)


print(table_rows([[1, 1], [2, 4], [3, 9]]))
```

It prints the three lines `1 & 1 \\`, `2 & 4 \\` and `3 & 9 \\`.

### Compile errors you will meet

A missing brace or dollar sign gives an error that points to the line where the problem was *noticed*, which can be later than the line where it started. Common causes: an unmatched `{`, a `_` or `^` outside math mode, a missing `\end{...}`, and a special character (`%`, `&`, `#`, `_`) in text without a backslash. Compile often, after every few paragraphs, so that an error has few possible causes.

For every integer $n \ge 1$,

@example
title: Finding a compile error
problem: The following line of a LaTeX source file fails to compile. Find and fix the error.
```text
Let $a_{n+1} = \frac{a_n + 2}{3$ for $n \ge 0$.
```
step: Count braces in the fraction: `\frac{a_n + 2}{3` opens a denominator brace `{` that is never closed before the dollar sign.
step: The compiler reports the problem at the closing dollar sign, where it finds that math mode ended inside a group, not at the missing brace.
step: Add the closing brace: `\frac{a_n + 2}{3}`.
step: With the brace closed, the line compiles and shows the fraction with denominator $3$.
answer: The denominator brace `{3` needs a closing `}`, so the corrected line is
```text
Let $a_{n+1} = \frac{a_n + 2}{3}$ for $n \ge 0$.
```

@mistakes
- Writing `x^10` or `a_n+1` and getting a raised `1` followed by a ground-level `0`, or a subscript `n` followed by `+1`: group with braces, `x^{10}` and `a_{n+1}`.
- Typing `log`, `sin`, `max` as plain letters; use `\log`, `\sin`, and `\max` or `\operatorname{lcm}` for a function without a command.
- Using the character `<` in text mode or `|` for "divides". Put comparisons in math mode and use `\mid`.
- Compiling only at the end: one early missing brace can produce a dozen error messages, and you will not know which line began the trouble.

model:
```python
def latex_poly(coeffs):
    """LaTeX source of the polynomial with the given coefficients."""
    degree = len(coeffs) - 1
    out = ""
    for i, c in enumerate(coeffs):
        if c == 0:
            continue
        k = degree - i
        mag = abs(c)
        if k == 0:
            body = str(mag)
        else:
            coef = "" if mag == 1 else str(mag)
            body = coef + ("x" if k == 1 else "x^{%d}" % k)
        if out == "":
            out = ("-" if c < 0 else "") + body
        else:
            out += (" - " if c < 0 else " + ") + body
    return out or "0"
```
hint: Go through the coefficients with their degrees. Build each term from the absolute value of the coefficient, and add the sign when you join it to the text so far.
solution: For each nonzero coefficient compute its degree, then the term body from the magnitude: a plain number for degree $0$, and `x` or `x^{k}` with a numeric prefix only when the magnitude is not $1$. The first term carries a bare minus sign if negative; later terms are joined with ` + ` or ` - ` according to the sign. If every coefficient is zero nothing is produced, so return `"0"`. Common slips are writing `1x`, writing `+ -3x`, and dropping a term with coefficient $-1$.

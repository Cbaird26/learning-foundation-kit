@article
What are the last two digits of $7^{2026}$? Multiplying $7$ by itself $2026$ times is hopeless, but modular arithmetic turns the question into a short computation. Number theory problems reward a small toolkit used flexibly: find a **divisibility reduction**, a **congruence**, or a **size bound**, then enumerate what is left.

### Divisors, gcd and Bézout

Write $a \mid b$ if $b = ak$ for an integer $k$. Two facts are used constantly: if $a \mid b$ and $a \mid c$ then $a \mid bx + cy$ for all integers $x, y$; and if $a \mid b$ with $b \ne 0$ then $|a| \le |b|$.

**Theorem (Bézout).** For integers $a, b$ not both $0$, the least positive integer of the form $ax + by$ ($x, y \in \mathbb{Z}$) equals $\gcd(a, b)$. Consequently the integers of the form $ax + by$ are exactly the multiples of $\gcd(a, b)$.

*Proof.* The set of positive integers $ax + by$ is nonempty (it contains $a^2 + b^2$), so by well-ordering it has a least element $d = ax_0 + by_0$. Divide: $a = qd + r$ with $0 \le r < d$. Then $r = a - q(ax_0 + by_0)$ is also of the form $ax + by$, and $r < d$, so $r$ cannot be positive: $r = 0$ and $d \mid a$. Likewise $d \mid b$, so $d$ is a common divisor and $d \le \gcd(a, b)$. Conversely every common divisor of $a$ and $b$ divides $ax_0 + by_0 = d$, so $\gcd(a, b) \le d$. Hence $d = \gcd(a, b)$. $\blacksquare$

For example $12x + 18y$ takes exactly the values $\dots, -6, 0, 6, 12, \dots$. When $\gcd(a, m) = 1$, Bézout gives $ax + my = 1$ for some $x, y$, so $ax \equiv 1 \pmod m$: $a$ has an inverse modulo $m$.

### Congruences and Fermat's little theorem

Congruences modulo $m$ can be added and multiplied, so $a \equiv a'$ and $b \equiv b'$ imply $ab \equiv a'b'$ and $a^k \equiv a'^k \pmod m$.

**Theorem (Fermat's little theorem).** If $p$ is prime and $p \nmid a$, then $a^{p-1} \equiv 1 \pmod p$.

*Proof.* The numbers $a, 2a, \dots, (p-1)a$ are nonzero modulo $p$ and distinct modulo $p$: if $ia \equiv ja$ then $p \mid (i - j)a$, and since $p \nmid a$, Euclid's lemma gives $p \mid i - j$, so $i = j$ for $1 \le i, j \le p - 1$. So they are the residues $1, \dots, p-1$ in some order, and multiplying them all gives $a^{p-1}(p-1)! \equiv (p-1)! \pmod p$. Since $p \nmid (p-1)!$, we may cancel it. $\blacksquare$

The hypothesis $p$ prime matters: $3^3 = 27 \equiv 3 \pmod 4$, not $1$. Powers also cycle with a period that can be smaller than $p - 1$; computing the cycle by program is the fastest way to see it:

```python
print([pow(7, k, 100) for k in range(1, 9)])
```

It prints `[7, 49, 43, 1, 7, 49, 43, 1]`: the powers of $7$ repeat with period $4$ modulo $100$.

### Reducing modulo a good number

To show $F(x, y) = c$ has no integer solution, find $m$ such that $F(x, y)$ modulo $m$ can never equal $c$ modulo $m$. Squares modulo $4$ are $0, 1$; modulo $3$ they are $0, 1$; modulo $5$ they are $0, 1, 4$; modulo $8$ they are $0, 1, 4$. A good modulus makes the set of possible values small.

### Divisibility conditions

To find all $n$ with $n + k \mid f(n)$ for a polynomial $f$, divide: $f(n) = (n + k)g(n) + f(-k)$, so $n + k \mid f(n)$ if and only if $n + k \mid f(-k)$. A fixed number has finitely many divisors, so the problem becomes finite. This is a size bound in disguise.

@example
title: The last two digits of a large power
problem: Find the last two digits of $7^{2026}$.
step: Last two digits means the remainder modulo $100$. Compute small powers: $7^2 = 49$ and $7^4 = 2401 \equiv 1 \pmod{100}$.
step: Since $7^4 \equiv 1$, write $2026 = 4 \cdot 506 + 2$.
step: Then $7^{2026} = (7^4)^{506} \cdot 7^2 \equiv 1^{506} \cdot 49 = 49 \pmod{100}$.
answer: The last two digits are $49$.

@example
title: A Diophantine equation with no solution
problem: Prove that $x^2 - 5y^2 = 3$ has no solution in integers $x, y$.
step: Reduce modulo $5$. If $x^2 - 5y^2 = 3$, then $x^2 \equiv 3 \pmod 5$ because $5y^2 \equiv 0$.
step: List the squares modulo $5$ by trying $x \equiv 0, 1, 2, 3, 4$: they are $0, 1, 4, 4, 1$.
step: The value $3$ does not appear, so $x^2 \equiv 3 \pmod 5$ is impossible. Hence no integers $x, y$ satisfy the equation.
answer: There are no integer solutions.

@mistakes
- Using Fermat's little theorem for a composite modulus or when $p \mid a$: $a^{p-1} \equiv 1 \pmod p$ needs $p$ prime and $p \nmid a$.
- Dividing a congruence by a number that is not invertible modulo $m$: from $2x \equiv 2y \pmod 6$ you cannot conclude $x \equiv y \pmod 6$ (only modulo $3$).
- Reducing an equation modulo $m$ and concluding there are solutions because the congruence has solutions; reduction can only prove that an equation has none.
- Listing divisors of a number and forgetting negative divisors or the lower bound on $n + k$ from $n \ge 1$.

@practice self
prompt: This is the block deliverable for weeks 7 and 8: two inequalities and a divisibility problem. (a) Prove that $(a + b)(b + c)(c + a) \ge 8abc$ for all nonnegative reals $a, b, c$. (b) Prove that $\dfrac{a^2}{x} + \dfrac{b^2}{y} \ge \dfrac{(a + b)^2}{x + y}$ for all real $a, b$ and all $x, y > 0$, and state when equality holds. (c) Find all positive integers $n$ such that $n + 7$ divides $n^3 + 1$.
hint: For (a), apply AM–GM for two numbers to each factor. For (b), apply Cauchy–Schwarz to $(a/\sqrt{x}, b/\sqrt{y})$ and $(\sqrt{x}, \sqrt{y})$. For (c), divide $n^3 + 1$ by $n + 7$.
solution: (a) By AM–GM for two nonnegative numbers, $a + b \ge 2\sqrt{ab}$, $b + c \ge 2\sqrt{bc}$ and $c + a \ge 2\sqrt{ca}$. All sides are nonnegative, so multiplying gives $(a+b)(b+c)(c+a) \ge 8\sqrt{a^2b^2c^2} = 8abc$. (b) By Cauchy–Schwarz, $\left(\frac{a}{\sqrt x}\sqrt x + \frac{b}{\sqrt y}\sqrt y\right)^2 \le \left(\frac{a^2}{x} + \frac{b^2}{y}\right)(x + y)$, that is $(a + b)^2 \le \left(\frac{a^2}{x} + \frac{b^2}{y}\right)(x + y)$. Dividing by $x + y > 0$ gives the claim. Equality holds exactly when $(a/\sqrt x, b/\sqrt y)$ is proportional to $(\sqrt x, \sqrt y)$, that is when $a/x = b/y$. (c) Since $n^3 = (n + 7)(n^2 - 7n + 49) - 343$, we have $n^3 + 1 = (n + 7)(n^2 - 7n + 49) - 342$. So $n + 7 \mid n^3 + 1$ if and only if $n + 7 \mid 342 = 2 \cdot 3^2 \cdot 19$. The divisors of $342$ are $1, 2, 3, 6, 9, 18, 19, 38, 57, 114, 171, 342$, and $n \ge 1$ forces $n + 7 \ge 8$, leaving $9, 18, 19, 38, 57, 114, 171, 342$. Hence $n \in \{2, 11, 12, 31, 50, 107, 164, 335\}$. Check: $2^3 + 1 = 9 = 1 \cdot 9$.
rubric: Part (a) applies AM–GM to each factor and multiplies the three inequalities, noting that the quantities are nonnegative.
rubric: Part (b) applies Cauchy–Schwarz to suitable lists, divides by $x + y > 0$, and gives the equality condition $a/x = b/y$.
rubric: Part (c) divides to get the remainder $-342$, lists the divisors of $342$ that are at least $8$, and gives all eight values of $n$.

@quiz code
prompt: Write `order_mod(a, n)` that returns the multiplicative order of `a` modulo `n`: the least integer $k \ge 1$ with $a^k \equiv 1 \pmod n$. If $\gcd(a, n) \ne 1$ there is no such $k$, and the function returns `None`. Assume $n \ge 2$. For example, `order_mod(11, 100)` returns `10` and `order_mod(3, 7)` returns `6`.
starter:
```python
def order_mod(a, n):
    pass
```
tests:
```python
assert order_mod(11, 100) == 10
assert order_mod(3, 7) == 6
assert order_mod(2, 9) == 6
assert order_mod(4, 8) is None
assert order_mod(10, 3) == 1
assert order_mod(2, 15) == 4
```
model:
```python
from math import gcd


def order_mod(a, n):
    """Least k >= 1 with a**k = 1 (mod n), or None if gcd(a, n) > 1."""
    if gcd(a, n) != 1:
        return None
    power = a % n
    k = 1
    while power != 1:
        power = power * a % n
        k += 1
    return k
```
hint: First check that $\gcd(a, n) = 1$. Then multiply by `a` repeatedly, reducing modulo `n`, until the product returns to $1$.
solution: When $\gcd(a, n) = 1$, the powers of `a` modulo `n` eventually return to $1$ (by Euler's theorem the order divides the totient of $n$), so the loop terminates; when the gcd is larger, no power of $a$ is $\equiv 1$ and the function must return `None` before looping. Reducing modulo `n` at every step keeps the numbers small. The case `a % n == 1` returns `1` immediately because `power` starts at $1$.

@quiz num
prompt: How many integers $n$ with $1 \le n \le 200$ satisfy $7 \mid n^2 + n + 1$?
answer: 58
check: sum(1 for n in range(1, 201) if (n * n + n + 1) % 7 == 0)
hint: Compute $n^2 + n + 1$ modulo $7$ for $n \equiv 0, 1, \dots, 6$.
solution: Modulo $7$ the values of $n^2 + n + 1$ for $n \equiv 0, 1, 2, 3, 4, 5, 6$ are $1, 3, 0, 6, 0, 3, 1$, so the condition holds exactly for $n \equiv 2$ and $n \equiv 4 \pmod 7$. In $1, \dots, 200$ there are $29$ numbers $\equiv 2$ (namely $2, 9, \dots, 198$) and $29$ numbers $\equiv 4$ (namely $4, 11, \dots, 200$): $58$ in all.

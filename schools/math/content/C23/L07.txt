@article
What is the smallest value of $x + \frac{1}{x}$ for $x > 0$? You could use calculus, but there is an algebraic reason that works with no derivative: $x + \frac1x - 2 = \frac{(x - 1)^2}{x} \ge 0$. A square is never negative, and nearly every inequality in this lesson is a square in disguise.

### The AM–GM inequality

**Theorem (AM–GM).** For nonnegative real numbers $x_1, \dots, x_n$,
$$\frac{x_1 + \dots + x_n}{n} \ge \sqrt[n]{x_1 x_2 \cdots x_n},$$
with equality if and only if $x_1 = \dots = x_n$.

*Proof for $n = 2$.* For $a, b \ge 0$ we have $a + b - 2\sqrt{ab} = (\sqrt a - \sqrt b)^2 \ge 0$, with equality exactly when $\sqrt a = \sqrt b$.

*Proof for $n = 3$.* For $a, b, c \in \mathbb{R}$, expanding gives $a^3 + b^3 + c^3 - 3abc = \tfrac12 (a + b + c)\big((a-b)^2 + (b-c)^2 + (c-a)^2\big)$. If $a, b, c \ge 0$ the right side is nonnegative, with equality exactly when $a = b = c$ (if $a + b + c = 0$ then all three vanish). Put $a = x^{1/3}$, $b = y^{1/3}$, $c = z^{1/3}$ to get the claim for $x, y, z \ge 0$. $\blacksquare$

*Outline for general $n$.* Applying the case $n = 2$ repeatedly proves the case $n = 2^k$ (average pairs, then average the averages). For other $n$, choose $2^k \ge n$, let $A$ be the arithmetic mean of $x_1, \dots, x_n$, and apply the $2^k$ case to $x_1, \dots, x_n$ together with $2^k - n$ copies of $A$. The mean of this list is still $A$, and the inequality yields $x_1 \cdots x_n A^{2^k - n} \le A^{2^k}$, that is $x_1 \cdots x_n \le A^n$.

The hypothesis $x_i \ge 0$ is essential: for $a = -1$ and $b = -4$ the product $ab = 4$ has square root $2$, which exceeds the mean $-\frac52$.

### The Cauchy–Schwarz inequality

**Theorem.** For real numbers $a_1, \dots, a_n$ and $b_1, \dots, b_n$,
$$(a_1 b_1 + \dots + a_n b_n)^2 \le (a_1^2 + \dots + a_n^2)(b_1^2 + \dots + b_n^2),$$
with equality if and only if the lists $(a_i)$ and $(b_i)$ are proportional (one is a real multiple of the other).

*Proof.* Lagrange's identity says
$$\Big(\sum a_i^2\Big)\Big(\sum b_i^2\Big) - \Big(\sum a_i b_i\Big)^2 = \sum_{i < j} (a_i b_j - a_j b_i)^2 .$$
(Expand both sides: the terms $a_i^2 b_i^2$ cancel, and each pair $i < j$ contributes $a_i^2 b_j^2 + a_j^2 b_i^2 - 2a_i b_i a_j b_j$.) The right side is a sum of squares, so it is $\ge 0$, and it is $0$ exactly when $a_i b_j = a_j b_i$ for all $i, j$, which says the lists are proportional. $\blacksquare$

A quick numerical check of the identity on random integer lists catches algebra slips, but it proves only the cases tried:

```python
import random

random.seed(1)
ok = True
for _ in range(200):
    n = random.randint(1, 6)
    a = [random.randint(-9, 9) for _ in range(n)]
    b = [random.randint(-9, 9) for _ in range(n)]
    left = (sum(x * x for x in a) * sum(y * y for y in b)
            - sum(x * y for x, y in zip(a, b)) ** 2)
    right = sum((a[i] * b[j] - a[j] * b[i]) ** 2
                for i in range(n) for j in range(i + 1, n))
    ok = ok and left == right
print(ok)
```

### The rearrangement inequality

**Theorem.** Let $a_1 \le \dots \le a_n$ and $b_1 \le \dots \le b_n$ be real numbers. For every permutation $\sigma$ of $\{1, \dots, n\}$,
$$a_1 b_n + \dots + a_n b_1 \le \sum_{i} a_i b_{\sigma(i)} \le a_1 b_1 + \dots + a_n b_n .$$

*Proof of the upper bound.* Among the finitely many permutations choose one, $\sigma$, that maximizes $\sum a_i b_{\sigma(i)}$ and, among those, has the fewest inversions (pairs $i < j$ with $\sigma(i) > \sigma(j)$). If $\sigma$ is not the identity, there is an index $i$ with $\sigma(i) > \sigma(i+1)$. Swapping the values at positions $i$ and $i+1$ changes the sum by $(a_{i+1} - a_i)(b_{\sigma(i)} - b_{\sigma(i+1)}) \ge 0$, because both factors are $\ge 0$. The new permutation is still a maximizer and has one inversion fewer, a contradiction. So the identity maximizes. Applying this to $-b_n \le \dots \le -b_1$ gives the lower bound. $\blacksquare$

@example
title: Choosing terms so that equality can occur
problem: Find the minimum of $f(x) = x^2 + \dfrac{16}{x}$ for $x > 0$, and where it occurs.
step: Split to make a product that is constant. Write $f(x) = x^2 + \frac{8}{x} + \frac{8}{x}$. The three terms have product $x^2 \cdot \frac{8}{x} \cdot \frac{8}{x} = 64$, which does not depend on $x$.
step: AM–GM for three nonnegative numbers: $f(x) \ge 3\sqrt[3]{64} = 12$.
step: Equality needs the three terms equal: $x^2 = \frac{8}{x}$, so $x^3 = 8$ and $x = 2$. Check: $f(2) = 4 + 8 = 12$.
step: The bound $12$ is attained, so the minimum is $12$. (Splitting $16/x$ into $4/x$ four times, or into unequal pieces, would give a bound that equality never reaches.)
answer: The minimum is $12$, at $x = 2$.

@example
title: Cauchy–Schwarz with weights
problem: Find the maximum of $x + 2y + 3z$ subject to $x^2 + 2y^2 + 3z^2 = 12$.
step: Write the expression as a dot product of $(x, \sqrt2\, y, \sqrt3\, z)$ with $(1, \sqrt2, \sqrt3)$: indeed $x \cdot 1 + \sqrt2 y \cdot \sqrt2 + \sqrt3 z \cdot \sqrt3 = x + 2y + 3z$.
step: Apply Cauchy–Schwarz: $(x + 2y + 3z)^2 \le (x^2 + 2y^2 + 3z^2)(1 + 2 + 3) = 12 \cdot 6 = 72$.
step: So $x + 2y + 3z \le \sqrt{72} = 6\sqrt2$. Equality needs $(x, \sqrt2 y, \sqrt3 z)$ proportional to $(1, \sqrt2, \sqrt3)$, i.e. $x = y = z = t$ with a positive $t$.
step: The constraint gives $t^2 (1 + 2 + 3) = 12$, so $t = \sqrt2$, and then $x + 2y + 3z = 6\sqrt2$. The bound is attained.
answer: The maximum is $6\sqrt2$, at $x = y = z = \sqrt2$.

@mistakes
- Applying AM–GM to terms that may be negative: the inequality needs $x_i \ge 0$.
- Finding a bound but never checking that equality can occur. A bound that is never attained is not the minimum; always solve the equality condition.
- Splitting a term into unequal pieces so that the product of terms still depends on $x$.
- Writing Cauchy–Schwarz without squaring the left side, or applying it with mismatched pairings of the lists.

prompt: For $x > 0$, find the minimum value of $g(x) = 4x^2 + \dfrac{27}{x}$. (Hint: split the second term.)
answer: 27
check: min(4 * t * t + 27 / t for t in [i / 1000 for i in range(500, 5000)])
tol: 0.01
hint: Write $\frac{27}{x}$ as $\frac{27}{2x} + \frac{27}{2x}$ so that the three terms have a constant product.
hint: The three terms $4x^2$, $\frac{27}{2x}$, $\frac{27}{2x}$ have a constant product; compute it, take the cube root, and then check where equality occurs.
solution: The three terms $4x^2$, $\frac{27}{2x}$, $\frac{27}{2x}$ have product $4x^2 \cdot \frac{729}{4x^2} = 729$, a constant. By AM–GM, $g(x) \ge 3\sqrt[3]{729} = 27$. Equality needs $4x^2 = \frac{27}{2x}$, i.e. $x^3 = \frac{27}{8}$, $x = \frac32$, and indeed $g(\frac32) = 9 + 18 = 27$. So the minimum is $27$.

@practice self
prompt: Prove that $a^3 + b^3 + c^3 \ge a^2 b + b^2 c + c^2 a$ for all nonnegative real numbers $a, b, c$, and find when equality holds.
hint: Apply AM–GM to the three numbers $a^3, a^3, b^3$.
solution: By AM–GM for the nonnegative numbers $a^3, a^3, b^3$: $\frac{a^3 + a^3 + b^3}{3} \ge \sqrt[3]{a^6 b^3} = a^2 b$, that is $2a^3 + b^3 \ge 3a^2 b$. In the same way $2b^3 + c^3 \ge 3b^2 c$ and $2c^3 + a^3 \ge 3c^2 a$. Adding the three inequalities gives $3(a^3 + b^3 + c^3) \ge 3(a^2 b + b^2 c + c^2 a)$, and dividing by $3$ gives the claim. Equality in each use of AM–GM requires the three numbers to be equal, so $a^3 = b^3$, hence $a = b$, and likewise $b = c$ and $c = a$. So equality holds exactly when $a = b = c$.

@quiz num
prompt: Real numbers $x$ and $y$ satisfy $x^2 + y^2 = 29$. Find the largest possible value of $2x + 5y$ (to two decimal places).
answer: 29
check: max(2 * 29 ** 0.5 * math.cos(i * 2 * math.pi / 100000) + 5 * 29 ** 0.5 * math.sin(i * 2 * math.pi / 100000) for i in range(100000))
tol: 0.01
hint: Apply Cauchy–Schwarz to the lists $(2, 5)$ and $(x, y)$.
solution: $(2x + 5y)^2 \le (2^2 + 5^2)(x^2 + y^2) = 29 \cdot 29$, so $2x + 5y \le 29$. Equality needs $(x, y)$ proportional to $(2, 5)$ with a positive factor: $(x, y) = t(2, 5)$ and $29 t^2 = 29$, $t = 1$. So the maximum $29$ is attained at $(2, 5)$.

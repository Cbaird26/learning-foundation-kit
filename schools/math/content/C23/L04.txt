@article
At a gathering of people, friendship is mutual and everyone has at least $3$ friends in the group. Must it be possible to seat at least $4$ people around a table so that each sits between two of their friends? You could try to build a table seating by hand and keep getting stuck. The extremal principle gives a different attack: start with the *longest* chain of friends you can find, and see what its ends must look like.

### The principle

**Extremal principle.** A finite nonempty set of real numbers has a largest and a smallest element, so among finitely many objects there is one that maximizes or minimizes any numerical quantity. **Well-ordering.** Every nonempty set of positive integers has a least element. To use either, choose an object that is extreme in a quantity (longest, smallest, closest, largest area) and then show that its extremality forces a property, usually because an object without the property could be modified into a more extreme one.

### Longest path

A **graph** has vertices (people) and edges (friendships). A **path** is a sequence of distinct vertices, each joined to the next by an edge. The **degree** of a vertex is its number of neighbors.

**Theorem.** If every vertex of a finite graph has degree at least $k \ge 2$, the graph has a cycle with at least $k + 1$ vertices.

*Proof.* The graph has finitely many paths, so there is a longest one, $v_0, v_1, \dots, v_m$. Every neighbor of $v_0$ lies on this path: if a neighbor $w$ were not on it, then $w, v_0, v_1, \dots, v_m$ would be a longer path. The neighbors of $v_0$ are therefore among $v_1, \dots, v_m$. Let $v_j$ be the neighbor of $v_0$ with the largest index $j$. Since $v_0$ has at least $k$ distinct neighbors among $v_1, \dots, v_j$, we get $j \ge k \ge 2$. Then $v_0, v_1, \dots, v_j$ together with the edge $v_j v_0$ form a cycle with $j + 1 \ge k + 1$ vertices. $\blacksquare$

For the party: $k = 3$ gives a cycle of at least $4$ people, each next to two friends. The bound cannot be improved in general: the complete graph on $k + 1$ vertices has all degrees $k$ and no cycle with more than $k + 1$ vertices.

### Least counterexample and infinite descent

If a statement about positive integers has a counterexample, it has a *least* one. Showing that a least counterexample leads to a smaller one is **infinite descent**.

**Theorem.** The equation $x^2 + y^2 = 7z^2$ has no solution in positive integers.

*Proof.* Suppose solutions exist and choose one with $z$ least. The squares modulo $7$ are $0, 1, 2, 4$. If $7 \nmid x$, then $x^2 \in \{1, 2, 4\}$ and $y^2 \equiv -x^2 \in \{6, 5, 3\} \pmod 7$, but none of $6, 5, 3$ is a square modulo $7$; so $7 \mid x$. Then $y^2 \equiv 0$, so $7 \mid y$. Write $x = 7a$, $y = 7b$. Then $49(a^2 + b^2) = 7z^2$, so $z^2 = 7(a^2 + b^2)$. Thus $7 \mid z^2$, and since $7$ is prime, $7 \mid z$. Write $z = 7c$: now $a^2 + b^2 = 7c^2$ with $a, b, c$ positive integers and $c < z$, contradicting the minimality of $z$. $\blacksquare$

The hypothesis that matters is the modulus. Modulo $13$ the equation $x^2 + y^2 \equiv 0$ has nonzero solutions (for example $x = 5$, $y = 12$, because $25 + 144 = 169$), and indeed $x^2 + y^2 = 13z^2$ has the solution $(2, 3, 1)$. Counting solutions of $x^2 + y^2 \equiv 0 \pmod p$ shows the difference:

```python
for p in [3, 5, 7, 11]:
    count = sum(1 for x in range(p) for y in range(p)
                if (x * x + y * y) % p == 0)
    print(p, count)
```

It prints $1$ for $p = 3, 7, 11$ (only $x = y = 0$) and $9$ for $p = 5$. The descent for $7$ works because the only solution modulo $7$ is the trivial one. The code only counts residues; the proof is what uses them.

### The invariant deliverable

In the next exercises you will combine this lesson with the previous one: an invariant proves a target is unreachable, and the argument must treat *every* sequence of moves.

@example
title: A set closed under averages
problem: Prove that a finite set $S$ of at least two real numbers cannot have the property that $(a + b)/2 \in S$ for all distinct $a, b \in S$.
step: Understand and plan: if the property held, averaging would create new elements between old ones, so the set would be infinite. Make this precise with an extreme element.
step: Choose extreme elements. $S$ is finite with at least two elements, so it has a largest element $b$ and, among the others, a largest element $a$. Then $a < b$ and no element of $S$ lies strictly between $a$ and $b$.
step: Apply the property to $a$ and $b$: the number $c = (a + b)/2$ would lie in $S$.
step: But $a < c < b$, because $c - a = (b - a)/2 > 0$ and $b - c = (b - a)/2 > 0$. This contradicts the choice of $a$ as the largest element below $b$, so no such $S$ exists.
answer: No finite set with at least two elements is closed under averages of distinct elements.

@example
title: The least divisor is prime
problem: Prove that the least integer $d > 1$ dividing a given integer $n \ge 2$ is prime.
step: The set $D = \{d \ge 2 : d \mid n\}$ contains $n$, so it is a nonempty set of positive integers. By well-ordering it has a least element $d$.
step: Suppose $d$ were not prime. Then $d = ab$ with integers $1 < a < d$ and $1 < b < d$.
step: Since $a \mid d$ and $d \mid n$, we get $a \mid n$, so $a \in D$.
step: But $a < d$, contradicting that $d$ is the least element of $D$. So $d$ is prime.
answer: The least divisor greater than $1$ of any integer $n \ge 2$ is prime.

@mistakes
- Choosing an "extreme" object from an infinite set without a reason it exists: positive reals $x$ with $x^2 > 2$ have no least element, and a graph with infinitely many vertices need not have a longest path.
- Choosing the extreme object and then forgetting to use extremality: the proof must say which more extreme object the assumed failure would produce.
- In infinite descent, forgetting to check that the smaller solution still satisfies all the conditions (positive integers, the same equation).
- Using a "proof" of impossibility by invariant but checking only some of the moves.

@practice num
prompt: Count the ordered pairs $(x, y)$ of integers with $0 \le x, y \le 16$ such that $17$ divides $x^2 + y^2$.
answer: 33
check: sum(1 for x in range(17) for y in range(17) if (x * x + y * y) % 17 == 0)
hint: Look for an integer $t$ with $t^2 \equiv -1 \pmod{17}$; try $t = 4$.
hint: Since $4^2 \equiv -1 \pmod{17}$, the congruence $y^2 \equiv -x^2$ becomes $y^2 \equiv (4x)^2$.
solution: Modulo $17$ we have $4^2 = 16 \equiv -1$, so $x^2 + y^2 \equiv 0$ means $y^2 \equiv -x^2 \equiv (4x)^2$, that is $y \equiv \pm 4x$ (a prime modulus has no zero divisors). For each of the $16$ nonzero $x$ there are two values of $y$ (the values $4x$ and $-4x$ differ since $17$ is odd and $x \not\equiv 0$), giving $32$ pairs, plus the pair $(0, 0)$. The total is $33$.

@practice self
prompt: Prove that the equation $x^3 + 2y^3 = 4z^3$ has no solution in positive integers.
hint: Choose a solution with $z$ as small as possible. Show that $x$ is even, then that $y$ is even, then that $z$ is even.
solution: Suppose a solution exists and choose one with $z$ least. Since $x^3 = 4z^3 - 2y^3$ is even, $x$ is even; write $x = 2a$. Then $8a^3 + 2y^3 = 4z^3$, so $4a^3 + y^3 = 2z^3$ and $y^3$ is even, so $y$ is even; write $y = 2b$. Then $4a^3 + 8b^3 = 2z^3$, so $z^3 = 2a^3 + 4b^3$ is even and $z$ is even; write $z = 2c$. Then $2a^3 + 4b^3 = 8c^3$, that is $a^3 + 2b^3 = 4c^3$. Here $a, b, c$ are positive integers and $c = z/2 < z$, contradicting the minimality of $z$. So there is no solution.
rubric: Chooses a solution with $z$ minimal, justified by well-ordering.
rubric: Shows in turn that $x$, $y$ and $z$ are even, with the parity reason for each.
rubric: Produces the smaller solution $(x/2, y/2, z/2)$ of the same equation and states the contradiction.

@practice self
prompt: Four boxes $A, B, C, D$ stand in a circle (so $A$ and $C$ are each next to $B$ and $D$). They hold $3, 5, 7, 9$ marbles. A move chooses a box holding at least $2$ marbles, removes $2$ marbles from it, and puts one marble in each of the two neighboring boxes. Prove that the boxes can never hold $7, 4, 6, 7$ marbles (in the order $A, B, C, D$).
hint: Marbles are conserved, so look instead at how a move changes the quantity $(A + C) - (B + D)$.
hint: Consider this quantity modulo $4$ and check all four kinds of moves.
solution: Write $s = (A + C) - (B + D)$, the number of marbles in the boxes $A$ and $C$ minus the number in $B$ and $D$. A move on $A$ removes two marbles from $A$ and adds one to each of $B$ and $D$, so $A + C$ decreases by $2$ and $B + D$ increases by $2$: $s$ changes by $-4$. A move on $C$ does the same. A move on $B$ or on $D$ removes two marbles from the group $B, D$ and adds two to the group $A, C$, so $s$ changes by $+4$. Hence every move changes $s$ by $\pm 4$, and $s \bmod 4$ is an invariant. At the start $s = (3 + 7) - (5 + 9) = -4 \equiv 0 \pmod 4$. For the target $(7, 4, 6, 7)$, $s = (7 + 6) - (4 + 7) = 2 \not\equiv 0 \pmod 4$. Since every sequence of moves preserves $s \bmod 4$, the target is never reached. (The total is $24$ in both states, so conservation alone does not exclude the target.)
rubric: Identifies a quantity such as $(A+C)-(B+D)$ and computes its change under each of the four kinds of moves.
rubric: Concludes that the quantity modulo $4$ is invariant, so the argument covers every sequence of moves.
rubric: Computes the quantity at the start ($-4$) and at the target ($2$) and shows they differ modulo $4$.

path = {0: [1], 1: [0, 2], 2: [1, 3], 3: [2]}
star = {0: [1, 2, 3], 1: [0], 2: [0], 3: [0]}

model:
```python
def longest_path(adj):
    """Most vertices on a simple path, by depth-first search."""
    def extend(v, visited):
        best = len(visited)
        for w in adj[v]:
            if w not in visited:
                visited.add(w)
                best = max(best, extend(w, visited))
                visited.remove(w)
        return best

    best = 0
    for v in adj:
        best = max(best, extend(v, {v}))
    return best
```
hint: Try every starting vertex; from each path, try extending it by an unvisited neighbor, and remember the longest length seen.
solution: Depth-first search from every start vertex explores all simple paths, since the longest path can start anywhere (in the star it starts at a leaf, not the center). Adding a vertex to the visited set before recursing and removing it afterwards lets the search try every alternative. The running time grows quickly with graph size, so this brute force is for small graphs only.

@quiz num
prompt: Find the least integer $n > 1$ with $n^2 \equiv 1 \pmod{91}$.
answer: 27
check: next(n for n in range(2, 91) if n * n % 91 == 1)
hint: Since $91 = 7 \cdot 13$, the condition holds if and only if $n^2 \equiv 1$ modulo $7$ and modulo $13$.
solution: Modulo the prime $7$, $n^2 \equiv 1$ means $n \equiv \pm 1$; modulo $13$ it also means $n \equiv \pm 1$. Of the four combinations, $n \equiv 1, 1$ gives $n = 1$ and $n \equiv -1, -1$ gives $n = 90$. The others: $n \equiv 1 \pmod 7$ and $n \equiv -1 \pmod{13}$ gives $n = 64$, and $n \equiv -1 \pmod 7$ and $n \equiv 1 \pmod{13}$ gives $n = 27$. The least $n > 1$ is $27$ (check: $27^2 = 729 = 8 \cdot 91 + 1$).

@article
Let $S_n = 1 + \frac18 + \frac1{27} + \dots + \frac1{n^3}$. Every $S_n$ is less than $\frac32$; how would you prove that? Try induction on the statement "$S_n < \frac32$". The step assumes $S_k < \frac32$ and must show $S_{k+1} = S_k + \frac1{(k+1)^3} < \frac32$. But the hypothesis only says $S_k$ is *somewhere* below $\frac32$, perhaps just barely below, and then adding a positive term could cross the line. The hypothesis is too weak. This lesson is about fixing exactly that kind of failure.

### Strengthen the statement

Induction often succeeds on a stronger statement because the step then has a stronger hypothesis to use. Here the stronger statement records *how far below* $\frac32$ the sum stays.

**Claim.** For every integer $n \ge 1$, $S_n \le \frac32 - \frac{1}{2n^2}$. In particular $S_n < \frac32$.

*Base case.* For $n = 1$, $S_1 = 1$ and $\frac32 - \frac12 = 1$.

*Inductive step.* Let $k \ge 1$ and assume $S_k \le \frac32 - \frac{1}{2k^2}$. Then
$$S_{k+1} \le \frac32 - \frac1{2k^2} + \frac1{(k+1)^3}.$$
To reach $\frac32 - \frac{1}{2(k+1)^2}$ we need $\frac{1}{(k+1)^3} \le \frac{1}{2k^2} - \frac{1}{2(k+1)^2} = \frac{2k+1}{2k^2(k+1)^2}$. Multiplying by $2k^2(k+1)^3 > 0$, this becomes $2k^2 \le (2k+1)(k+1) = 2k^2 + 3k + 1$, which is true. So the statement holds for $k+1$. $\blacksquare$

How did we find the strengthening? We looked for an expression $c - f(n)$ with $f$ decreasing such that the step inequality $f(k) - f(k+1) \ge \frac{1}{(k+1)^3}$ holds. A strengthening must be **true**, must **imply** the original, and must **give the step more to work with**. Choosing it is a creative step: try a few candidate forms and let the algebra of the step tell you which one works.

### Recurrences need enough base cases

If a sequence is defined by $a_{n+2}$ in terms of $a_{n+1}$ and $a_n$, the step for $a_{k+2}$ uses *two* earlier cases. The induction therefore needs two base cases, and the hypothesis is "the statement holds for $k$ and $k + 1$" (a form of strong induction: assume all earlier cases). A recurrence of order $r$ needs $r$ base cases. Computing the first terms by program is an excellent way to guess a closed form:

```python
a, b = 2, 5               # a_0, a_1
checks = []
for n in range(2, 41):
    a, b = b, 5 * b - 6 * a
    checks.append(b == 2 ** n + 3 ** n)
print(all(checks))
```

This prints `True`: for the recurrence $a_0 = 2$, $a_1 = 5$, $a_{n+2} = 5a_{n+1} - 6a_n$, the formula $a_n = 2^n + 3^n$ fits for $n \le 40$. The worked example below proves it for all $n$.

### Choose what to induct on

You are free to choose the variable. Induct on the number of vertices of a graph, on the size of a set, on the degree of a polynomial, or on the length of a string. A good test: after removing or reducing one piece of size $k + 1$, you should land in a smaller case of the *same* problem. If the smaller object does not satisfy the hypothesis of your statement, strengthen or reformulate it.

### Where does the step start to work?

The inductive step may be valid only from some $k$ on. For $2^n > n^3$ the base case $n = 1$ holds, but the statement is false for $2 \le n \le 9$ and true from $n = 10$ on. The correct induction starts at $n = 10$ ($1024 > 1000$) and uses a step valid for $k \ge 10$, for example $2^{k+1} = 2 \cdot 2^k > 2k^3 \ge (k+1)^3$, where $2k^3 \ge (k+1)^3$ is equivalent to $2^{1/3} \ge 1 + 1/k$ and holds for $k \ge 4$.

@example
title: A closed form for a two-step recurrence
problem: Let $a_0 = 2$, $a_1 = 5$ and $a_{n+2} = 5a_{n+1} - 6a_n$ for $n \ge 0$. Prove that $a_n = 2^n + 3^n$ for every integer $n \ge 0$.
step: Plan: the recurrence reaches back two steps, so use two base cases and the hypothesis for $k$ and $k + 1$.
step: Base cases: $2^0 + 3^0 = 2 = a_0$ and $2^1 + 3^1 = 5 = a_1$.
step: Inductive hypothesis: let $k \ge 0$ and assume $a_k = 2^k + 3^k$ and $a_{k+1} = 2^{k+1} + 3^{k+1}$.
step: Compute: $a_{k+2} = 5a_{k+1} - 6a_k = 5(2^{k+1} + 3^{k+1}) - 6(2^k + 3^k) = 2^k(10 - 6) + 3^k(15 - 6) = 4 \cdot 2^k + 9 \cdot 3^k$.
step: Since $4 \cdot 2^k = 2^{k+2}$ and $9 \cdot 3^k = 3^{k+2}$, we get $a_{k+2} = 2^{k+2} + 3^{k+2}$. By induction the formula holds for all $n \ge 0$.
answer: $a_n = 2^n + 3^n$ for all $n \ge 0$.

@example
title: A bound on an iteration
problem: Let $x_1 = 2$ and $x_{n+1} = x_n + \frac{1}{x_n}$. Prove that $x_n^2 \ge 2n + 2$ for every $n \ge 1$.
step: Plan: the recurrence adds $1/x_n$, so squaring will turn the update into an increase of at least $2$ in $x_n^2$.
step: Base case: $x_1^2 = 4 = 2 \cdot 1 + 2$.
step: Inductive hypothesis: let $k \ge 1$ and assume $x_k^2 \ge 2k + 2$. Every $x_k$ is positive, as the sequence starts at $2$ and each step adds a positive number.
step: Compute: $x_{k+1}^2 = x_k^2 + 2 + \frac{1}{x_k^2} > x_k^2 + 2 \ge 2k + 4 = 2(k+1) + 2$.
step: This is the statement for $k + 1$, so $x_n^2 \ge 2n + 2$ for all $n \ge 1$. For instance $x_{100} > \sqrt{202} \approx 14.2$.
answer: $x_n^2 \ge 2n + 2$ for every $n \ge 1$.

@mistakes
- Using one base case for a two-step recurrence: the step for $a_{k+2}$ needs both $a_k$ and $a_{k+1}$, so $n = 0$ and $n = 1$ must both be checked.
- Trying to prove a bound $T_n < c$ directly when the step needs to know how close $T_k$ is to $c$; strengthen to $T_n \le c - f(n)$.
- Strengthening a statement to something false: check the new statement on small $n$ before investing in a proof.
- Starting the induction too early: if the step needs $k \ge 4$, the base case must cover every earlier case separately, or the induction must start later.

@practice ms
prompt: You want to prove a statement $P(n)$ by induction, and the plain inductive step does not work. A stronger statement $Q(n)$ might. Which of these must be true of a useful strengthening $Q(n)$?
choice*: $Q(n)$ implies $P(n)$ for every $n$.
choice*: $Q(n)$ is itself true for every $n$ being considered.
choice*: The hypothesis $Q(k)$ lets you prove $Q(k+1)$.
choice: $Q(n)$ is easier to prove than $P(n)$ without any use of the inductive step.
hint: A strengthening must still be correct, must still give you $P(n)$, and must make the step go through.
solution: A false $Q$ cannot be proved, and a $Q$ that does not imply $P$ does not help. The strengthening works when the step $Q(k) \Rightarrow Q(k+1)$ can be proved, which is the point: the stronger hypothesis has more information. A strengthened statement is not easier in itself; it is only easier to *use* inside the step.

@practice self
prompt: Let $a_1 = 1$ and $a_{n+1} = 2a_n + n$ for $n \ge 1$. Compute $a_2, a_3, a_4, a_5$, conjecture a closed form for $a_n$, and prove it by induction.
hint: The values are $1, 3, 8, 19, 42$. Compare them with $3 \cdot 2^{n-1}$.

Each falls short of $3 \cdot 2^{n-1} = 3, 6, 12, 24, 48$ by exactly $n + 1$ (that is, by $2, 3, 4, 5, 6$), which suggests $a_n = 3 \cdot 2^{n-1} - n - 1$. Then $a_{k+1} = 2a_k + k = 3 \cdot 2^k - 2k - 2 + k = 3 \cdot 2^k - k - 2 = 3 \cdot 2^{(k+1)-1} - (k+1) - 1$. This is the formula for $k + 1$, so it holds for all $n \ge 1$.

@practice self
prompt: Prove that $\left(1 + \frac{1}{1^2}\right)\left(1 + \frac{1}{2^2}\right)\cdots\left(1 + \frac{1}{n^2}\right) < 4$ for every integer $n \ge 1$.
hint: Induction on the bare statement "$P_n < 4$" fails, because $P_k < 4$ does not control $P_k(1 + \frac{1}{(k+1)^2})$.
hint: Try the stronger statement $P_n \le 4 - \frac{4}{n+1}$. The base case $n = 1$ is an equality.
solution: Let $P_n$ be the product. We prove the stronger statement $P_n \le 4 - \frac{4}{n+1} = \frac{4n}{n+1}$ for all $n \ge 1$, which implies $P_n < 4$. Base case: $P_1 = 2 = \frac{4 \cdot 1}{2}$. Inductive step: let $k \ge 1$ and assume $P_k \le \frac{4k}{k+1}$. Then $P_{k+1} = P_k \left(1 + \frac{1}{(k+1)^2}\right) \le \frac{4k}{k+1} \cdot \frac{(k+1)^2 + 1}{(k+1)^2} = \frac{4k\left((k+1)^2 + 1\right)}{(k+1)^3}$. We need this to be at most $\frac{4(k+1)}{k+2}$, that is, $k\left((k+1)^2 + 1\right)(k+2) \le (k+1)^4$. Expanding, the left side is $k(k^2 + 2k + 2)(k + 2) = k^4 + 4k^3 + 6k^2 + 4k$ and the right side is $k^4 + 4k^3 + 6k^2 + 4k + 1$, so the inequality holds. By induction the stronger statement holds for all $n \ge 1$, so $P_n < 4$.
rubric: Recognizes that the bare statement is too weak and proposes a strengthening that is true and implies the claim.
rubric: Checks the base case of the strengthened statement and uses the hypothesis for $k$ correctly in the step.
rubric: Carries out the final polynomial inequality accurately and deduces the original claim.

choice: The claim is false, so no proof is possible.

@quiz code
prompt: Write `induction_start(P, limit)` that takes a predicate `P` on positive integers and returns the least integer $n_0 \ge 1$ such that `P(n)` is true for every integer $n$ with $n_0 \le n \le$ `limit`. If `P(limit)` is false, return `None`. For example, if `P(n)` is `2**n > n**3`, then `induction_start(P, 60)` returns `10`, because $P$ is true at $n = 1$, false for $2 \le n \le 9$, and true from $10$ to $60$.
starter:
```python
def induction_start(P, limit):
    pass
```
tests:
```python
P = lambda n: 2 ** n > n ** 3
assert induction_start(P, 60) == 10
assert induction_start(P, 9) is None
assert induction_start(lambda n: 3 ** n > n * n, 50) == 1
assert induction_start(lambda n: n < 5, 20) is None
assert induction_start(lambda n: n % 2 == 0, 11) is None
assert induction_start(lambda n: n >= 7, 7) == 7
```
model:
```python
def induction_start(P, limit):
    """Start of the final run of true values of P up to limit."""
    if not P(limit):
        return None
    n = limit
    while n > 1 and P(n - 1):
        n -= 1
    return n
```
hint: Start at `limit` and move downward as long as the previous value is also true.
solution: If `P(limit)` is false there is no run, so return `None`. Otherwise walk down from `limit` while `P(n - 1)` is true; the loop stops at the first false value below, or at $1$. Returning the first $n$ with `P(n)` true would give $1$ for $2^n > n^3$, which is the mistake the induction warning is about: a true base case does not make the step valid from there on. Even a true result on $1, \dots,$ `limit` is only evidence for larger $n$.

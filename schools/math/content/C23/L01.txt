@article
Here is a problem you have probably never seen: **find all pairs of positive integers $(a, b)$ with $ab - 4a - 6b = 10$.** There is no formula to apply. Many students stare at it, try a few numbers at random and give up. This course teaches what to do instead.

### Four phases

In *How to Solve It* (1945), George Pólya described four phases that still organize good problem solving.

1. **Understand.** Say what is unknown, what is given and what condition links them. Restate the problem in your own words. What would a solution look like: a number, a list, a proof? Does an example (or a non-example) exist?
2. **Plan.** Choose a strategy. Try a smaller or more special problem, work backward from the goal, draw a table, introduce notation, change the representation, or ask whether you know a related problem.
3. **Carry out.** Execute the plan and check each step as you go. If it stalls, return to phase 2 and change the plan; do not just push harder.
4. **Look back.** Check the answer against the original conditions. Ask whether another route gives the same result, whether the idea solves a more general problem, and what you would do differently next time.

### Explore first

For our problem a solution is a list of pairs, so the first questions are: are there any, and are there finitely many? A short search answers the first question:

```python
def pairs(limit):
    """All (a, b) with 1 <= a, b < limit and ab - 4a - 6b = 10."""
    return [(a, b) for a in range(1, limit) for b in range(1, limit)
            if a * b - 4 * a - 6 * b == 10]


print(pairs(100))
```

It prints `[(7, 38), (8, 21), (23, 6), (40, 5)]`. This is a conjecture, not an answer: the search stopped at $100$, and a solution with $a = 1000$ would escape it.

### Change the representation

The left side has a product and two linear terms, which suggests factoring. Add $24$ to both sides: $ab - 4a - 6b + 24 = 34$, and the left side factors as $(a - 6)(b - 4)$.

**Claim.** The positive integer solutions of $ab - 4a - 6b = 10$ are exactly $(7, 38)$, $(8, 21)$, $(23, 6)$ and $(40, 5)$.

*Proof.* The equation is equivalent to $(a - 6)(b - 4) = 34$. Put $u = a - 6$ and $v = b - 4$. These are integers with $uv = 34$, and since $a, b \ge 1$ we have $u \ge -5$ and $v \ge -3$. Because $uv > 0$, $u$ and $v$ have the same sign.

If both are negative, then $v \in \{-1, -2, -3\}$. But $v$ divides $34$, which excludes $-3$, and $v = -1$ or $v = -2$ forces $u = -34$ or $u = -17$, contradicting $u \ge -5$. So both are positive, and $(u, v)$ is one of $(1, 34), (2, 17), (17, 2), (34, 1)$, the factorizations of $34$ into positive factors. Adding $6$ and $4$ gives the four pairs. Each satisfies the original equation; for example $7 \cdot 38 - 28 - 228 = 10$. $\blacksquare$

The code found the same four pairs; the proof shows there are no others.

### Look back, and keep a log

Looking back gives a general method: $ab - ca - db = e$ is equivalent to $(a - d)(b - c) = e + cd$, so every equation of this shape reduces to the divisors of one number. To make that habit stick, keep a **strategy log** while you work:

| Strategy tried | What I did | Result | Next step |
|---|---|---|---|
| Special cases | Searched $a, b < 100$ | Four pairs | Prove completeness |
| Change representation | Added $24$, factored | $(a-6)(b-4) = 34$ | Case-check signs |

A log turns "I was stuck" into a list of attempts you can learn from. It is also the raw material for the paragraph on how you found a solution that you will write in your project.

@example
title: Working backward
problem: A number $x$ is put through the rule "triple it, then subtract $4$" three times in a row, and the result is $56$. Find $x$.
step: Understand: the rule is $g(y) = 3y - 4$, and we know $g(g(g(x))) = 56$. A forward guess-and-check search would work, but each rule step can be undone exactly.
step: Plan: undo the rule. If $y = 3w - 4$ then $w = (y + 4)/3$. Apply this inverse three times to $56$.
step: Carry out: $(56 + 4)/3 = 20$, then $(20 + 4)/3 = 8$, then $(8 + 4)/3 = 4$.
step: Look back: forward from $4$: $3 \cdot 4 - 4 = 8$, $3 \cdot 8 - 4 = 20$, $3 \cdot 20 - 4 = 56$. The rule is one-to-one, so this is the only solution.
answer: $x = 4$.

@example
title: A divisibility condition
problem: Find all positive integers $n$ such that $n + 7$ divides $n^2 + 20$.
step: Change the representation: write $n^2 + 20 = (n + 7)(n - 7) + 69$, since $(n+7)(n-7) = n^2 - 49$ and $-49 + 69 = 20$.
step: If $n + 7$ divides $n^2 + 20$, it divides $n^2 + 20 - (n+7)(n-7) = 69$. Conversely, if $n + 7$ divides $69$ it divides $n^2 + 20$. So the condition is equivalent to $n + 7 \mid 69$.
step: The divisors of $69 = 3 \cdot 23$ are $1, 3, 23, 69$. Since $n \ge 1$, we need $n + 7 \ge 8$, which leaves $23$ and $69$.
step: So $n = 16$ or $n = 62$. Check: $16^2 + 20 = 276 = 12 \cdot 23$ and $62^2 + 20 = 3864 = 56 \cdot 69$.
answer: $n \in \{16, 62\}$.

@mistakes
- Computing before understanding: students solve a different problem (for example, allowing zero or negative integers) because they never restated the condition.
- Stopping at the first solution you find: "find all" requires a proof that the list is complete.
- Treating a search up to a limit as a proof that no larger solutions exist.
- Forgetting to translate the constraints after a substitution: after setting $u = a - 6$, the condition $a \ge 1$ becomes $u \ge -5$, and that is what rules out the negative cases.

answer: 4

hint: Add $15$ to both sides so that the left side factors as $(a - 5)(b - 3)$.

solution: Adding $15$ gives $(a-5)(b-3) = 22$. Both factors are positive or both negative. Negative factors would need $b - 3 \in \{-1, -2\}$ and $a - 5 = -22$ or $-11$, impossible since $a - 5 \ge -4$. @practice num
prompt: Two players alternately remove stones from a pile; on each turn a player removes exactly $1$, $4$ or $6$ stones, and the player who removes the last stone wins. With $31$ stones, how many different first moves (out of $1$, $4$, $6$) guarantee a win for the first player with correct play afterward?
answer: 3
check: int(run("w = [False]\nfor n in range(1, 32):\n    w.append(any(n >= m and not w[n - m] for m in (1, 4, 6)))\nprint(sum(1 for m in (1, 4, 6) if not w[31 - m]))"))
hint: Work backward from the end: a pile of $0$ is lost for the player to move. Which pile sizes are lost, which are won?
hint: A position is lost if every move leads to a won position, and won if some move leads to a lost one. Compute sizes $0, 1, 2, \dots$ in order.
solution: Writing L for lost and W for won for the player to move: sizes $0, 1, 2, 3, 4, 5, 6, 7$ are L, W, L, W, W, L, W, L, and the pattern repeats with period $5$: the lost sizes are exactly those congruent to $0$ or $2$ modulo $5$. tests:
```python
def is_prime(m):
    if m < 2:
        return False
    d = 2
    while d * d <= m:
        if m % d == 0:
            return False
        d += 1
    return True


assert smallest_counterexample(lambda n: n < 50, 100) == 50
assert smallest_counterexample(lambda n: n > 0, 100) is None
assert smallest_counterexample(lambda n: n != 7, 7) == 7
assert smallest_counterexample(lambda n: is_prime(n * n - n + 11), 100) == 11
assert smallest_counterexample(lambda n: is_prime(2 * n * n + 29), 100) == 29
assert smallest_counterexample(lambda n: n < 3, 2) is None
```
model:
```python
def smallest_counterexample(pred, limit):
    """Least n in 1..limit with pred(n) false, or None."""
    for n in range(1, limit + 1):
        if not pred(n):
            return n
    return None
```
hint: Test the values $1, 2, \dots$ in order and stop at the first failure.
solution: Loop over `range(1, limit + 1)`; the upper end must be `limit + 1` so that $n =$ `limit` is tested. Return the first $n$ where the predicate fails, and `None` if the loop ends. A result of `None` only says that no counterexample up to `limit` exists; it proves nothing beyond the limit.

@quiz num
prompt: Find the number of ordered pairs of positive integers $(a, b)$ with $ab - 2a - 7b = 31$.
answer: 6
check: sum(1 for a in range(1, 800) for b in range(1, 800) if a * b - 2 * a - 7 * b == 31)

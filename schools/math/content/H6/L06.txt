@article
**Probability** measures how likely an event is, on a scale from $0$ (impossible) to $1$ (certain). For equally likely outcomes, $P(A)$ is the number of outcomes in $A$ divided by the number of outcomes in the **sample space**. For long-run behavior, probability is the proportion of times an event occurs in many repetitions.

### Basic rules

- **Complement:** $P(\text{not } A) = 1 - P(A)$. This is the fastest route to "at least one" questions: $P(\text{at least one}) = 1 - P(\text{none})$.
- **Addition rule:** $P(A \text{ or } B) = P(A) + P(B) - P(A \text{ and } B)$. "Or" is inclusive, meaning $A$, $B$ or both. If $A$ and $B$ are **mutually exclusive** (cannot occur together), $P(A \text{ and } B) = 0$ and the rule becomes $P(A) + P(B)$.
- **Conditional probability:** the probability of $A$ given that $B$ has occurred is
$$P(A \mid B) = \frac{P(A \text{ and } B)}{P(B)}.$$
- **Multiplication rule:** $P(A \text{ and } B) = P(A)\,P(B \mid A)$.

### Independence

Events $A$ and $B$ are **independent** if knowing that one occurred does not change the probability of the other: $P(A \mid B) = P(A)$, equivalently $P(A \text{ and } B) = P(A)P(B)$. Do not confuse the two ideas: mutually exclusive events with positive probabilities are *never* independent (if $A$ occurs, $B$ cannot), because $P(B \mid A) = 0 \ne P(B)$.

### Two-way tables

Counts in a two-way table give conditional probabilities directly: restrict to the row or column of the given event and divide. For example, if $80$ of $200$ patients smoke and $20$ of those $80$ have a disease, then $P(\text{disease} \mid \text{smoker}) = 20/80 = 0.25$, while $P(\text{smoker and disease}) = 20/200 = 0.10$. The wording "given" or "among" signals that the denominator is the conditioning group.

### Screening tests and Bayes' rule

For a test, **sensitivity** is $P(\text{positive} \mid \text{disease})$ and **specificity** is $P(\text{negative} \mid \text{no disease})$. Clinicians want the reverse: the **positive predictive value** $\text{PPV} = P(\text{disease} \mid \text{positive})$. Bayes' rule combines the pieces:

$$P(D \mid +) = \frac{P(D)\,P(+ \mid D)}{P(D)\,P(+ \mid D) + P(\text{not } D)\,P(+ \mid \text{not } D)},$$

where $P(+ \mid \text{not } D) = 1 - \text{specificity}$. The key insight is that when a disease is rare, even an accurate test produces mostly false positives. A natural-frequency picture helps: imagine $10{,}000$ people, count how many have disease, how many of those test positive, and how many healthy people test positive.

@example
title: The addition rule
problem: Among patients in a clinic, $P(A) = 0.3$ have hypertension, $P(B) = 0.2$ have diabetes and $P(A \text{ and } B) = 0.1$ have both. Find the probability that a randomly selected patient has at least one of the two conditions.
step: The events overlap, so use $P(A \text{ or } B) = P(A) + P(B) - P(A \text{ and } B)$.
step: Substitute: $0.3 + 0.2 - 0.1 = 0.4$.
step: Subtracting $0.1$ avoids counting the patients with both conditions twice. Forty percent have at least one condition.

@example
title: Positive predictive value
problem: A disease has prevalence $2\%$. A test has sensitivity $90\%$ and specificity $95\%$. A randomly chosen person tests positive. What is the probability of disease?
step: $P(D) = 0.02$, $P(+ \mid D) = 0.90$, $P(\text{not } D) = 0.98$ and $P(+ \mid \text{not } D) = 1 - 0.95 = 0.05$.
step: True positives: $0.02(0.90) = 0.018$. False positives: $0.98(0.05) = 0.049$. All positives: $0.018 + 0.049 = 0.067$.
step: $\text{PPV} = 0.018/0.067 \approx 0.269$. Only about $27\%$ of positives have the disease, because most people tested are healthy.

@mistakes
- Adding $P(A)$ and $P(B)$ for overlapping events without subtracting $P(A \text{ and } B)$.
- Multiplying probabilities as if events were independent without checking.
- Confusing $P(A \mid B)$ with $P(B \mid A)$; sensitivity is not the same as the probability of disease after a positive test.
- Treating "mutually exclusive" and "independent" as meaning the same thing.

@quiz num
prompt: A condition has prevalence $10\%$. A test has sensitivity $80\%$ and specificity $90\%$. What is the probability that a person who tests positive has the condition? Round to three decimal places.
answer: 0.471
check: 0.10 * 0.80 / (0.10 * 0.80 + 0.90 * (1 - 0.90))
tol: 0.002
hint: Count true positives $P(D)P(+\mid D)$ and false positives $P(\text{not }D)P(+\mid\text{not }D)$.
hint: True positives: $0.08$. False positives: $0.90 \times 0.10 = 0.09$.
solution: $\text{PPV} = 0.08/(0.08 + 0.09) = 0.08/0.17 \approx 0.471$.

@quiz mc
prompt: Events $A$ and $B$ are mutually exclusive and both have positive probability. Which statement is true?
choice*: $A$ and $B$ cannot be independent.
choice: $A$ and $B$ must be independent.
choice: $P(A \text{ and } B) = P(A)P(B)$.
choice: $P(A \text{ or } B) = P(A) + P(B) - P(A)P(B)$.
hint: If $A$ occurs, what is the probability that $B$ also occurs?
solution: If $A$ occurs then $B$ cannot, so $P(B \mid A) = 0$, which differs from $P(B) > 0$. Therefore mutually exclusive events with positive probability are dependent.

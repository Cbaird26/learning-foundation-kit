@article
In $\mathbb{R}^3$ take $(1,2,3)$, $(4,5,6)$ and $(7,8,9)$. Three vectors might be expected to fill $3$-space, but $(7,8,9) = 2(4,5,6) - (1,2,3)$, so the third vector adds nothing: all three lie in a plane. This lesson makes "adds nothing" and "fills the space" precise, and shows that the number of independent directions of a space is a well-defined number.

### Definitions

Let $V$ be a vector space over $F$. The **span** of a list $v_1, \dots, v_m$ is the set of all linear combinations $a_1 v_1 + \dots + a_m v_m$ with $a_j \in F$; the span of the empty list is $\{0\}$. The space $V$ is **finite-dimensional** if some finite list spans it. A list is **linearly independent** if $a_1 v_1 + \dots + a_m v_m = 0$ forces $a_1 = \dots = a_m = 0$. A **basis** is a list that is linearly independent and spans $V$.

**Theorem 1.** A list $v_1, \dots, v_n$ is a basis of $V$ if and only if every $v \in V$ can be written in exactly one way as $a_1 v_1 + \dots + a_n v_n$.

*Proof.* If the list is a basis, every $v$ is a combination because the list spans. If $\sum a_j v_j = \sum b_j v_j$ then $\sum (a_j - b_j) v_j = 0$, so $a_j = b_j$ by independence. Conversely, existence gives spanning, and uniqueness of the representation of $0 = 0 v_1 + \dots + 0 v_n$ gives independence. $\blacksquare$

### Dimension is well defined

We use one fact from the first linear algebra course: **a homogeneous system of $n$ linear equations in $m > n$ unknowns has a nonzero solution** (row reduction leaves a free unknown).

**Theorem 2.** If $u_1, \dots, u_m$ are linearly independent in $V$ and $w_1, \dots, w_n$ span $V$, then $m \le n$.

*Proof.* Suppose $m > n$. Write each $u_j = \sum_{i=1}^n a_{ij} w_i$. The system $\sum_{j=1}^m a_{ij} c_j = 0$ for $i = 1, \dots, n$ has $n$ equations and $m > n$ unknowns, so it has a solution $(c_1, \dots, c_m) \ne 0$. Then $\sum_j c_j u_j = \sum_i \big( \sum_j a_{ij} c_j \big) w_i = 0$ is a nontrivial dependence among the $u_j$, a contradiction. $\blacksquare$

Applying Theorem 2 in both directions to two bases shows they have the same length. That length is the **dimension** $\dim V$. So $\dim F^n = n$, $\dim F^{m \times n} = mn$, and $\dim \mathcal{P}_n(F) = n + 1$ (basis $1, x, \dots, x^n$).

**Theorem 3.** Let $V$ be finite-dimensional with $\dim V = n$.
(a) Every spanning list contains a basis.
(b) Every independent list extends to a basis.
(c) A subspace $U$ is finite-dimensional, $\dim U \le n$, and $\dim U = n$ only if $U = V$.
(d) An independent list of length $n$, or a spanning list of length $n$, is a basis.

*Proof.* (a) If $\sum a_j v_j = 0$ with some $a_k \ne 0$, then $v_k = -a_k^{-1} \sum_{j \ne k} a_j v_j$ lies in the span of the others, so deleting $v_k$ does not change the span. Repeat until the list is independent. (b) Let $u_1, \dots, u_m$ be independent and $w_1, \dots, w_p$ span $V$. Go through the $w$'s and append $w_i$ whenever it is not in the span of the current list. Appending keeps independence: if $a w + \sum b_j u_j = 0$ with $w \notin \operatorname{span}(u_j)$, then $a = 0$ (otherwise $w$ would be in the span), and then all $b_j = 0$. At the end every $w_i$ lies in the span of the list, so it spans $V$. (c) Choose vectors of $U$ one at a time, each outside the span of the previous ones; the chosen list stays independent, so by Theorem 2 it has length at most $n$ and the process stops with an independent list spanning $U$. If $\dim U = n$ the basis of $U$ is independent of length $n$; by (b) it extends to a basis of $V$ of length $n$, so nothing was added and $U = V$. (d) An independent list of length $n$ extends to a basis of length $n$, hence is one; a spanning list of length $n$ contains a basis of length $n$, hence is one. $\blacksquare$

**Theorem 4.** For subspaces $U, W$ of a finite-dimensional space, $\dim(U + W) = \dim U + \dim W - \dim(U \cap W)$.

*Proof.* Let $x_1, \dots, x_k$ be a basis of $U \cap W$. Extend it to a basis $x_1, \dots, x_k, y_1, \dots, y_a$ of $U$ and to a basis $x_1, \dots, x_k, z_1, \dots, z_b$ of $W$. The combined list $x, y, z$ spans $U + W$. For independence, suppose $\sum \alpha_i x_i + \sum \beta_j y_j + \sum \gamma_l z_l = 0$. Then $\sum \gamma_l z_l = -\sum \alpha_i x_i - \sum \beta_j y_j$ lies in $U$ and in $W$, so it equals $\sum \delta_i x_i$ for some $\delta_i$. Independence of $x, z$ in $W$ gives all $\gamma_l = 0$. Then $x, y$ independent in $U$ gives $\alpha_i = \beta_j = 0$. So the list is a basis with $k + a + b$ vectors, and $\dim U + \dim W - \dim(U \cap W) = (k + a) + (k + b) - k$. $\blacksquare$

### Computing exactly

Row operations do not change the span of the rows, so the number of pivots of the reduced matrix is the dimension of the span. Floating point can hide a pivot, so use exact fractions:

```python
from fractions import Fraction


def rref(rows):
    """Exact reduced row echelon form; returns (matrix, pivot columns)."""
    R = [[Fraction(x) for x in row] for row in rows]
    pivots, r = [], 0
    for c in range(len(R[0]) if R else 0):
        p = next((i for i in range(r, len(R)) if R[i][c] != 0), None)
        if p is None:
            continue
        R[r], R[p] = R[p], R[r]
        R[r] = [x / R[r][c] for x in R[r]]
        for i in range(len(R)):
            if i != r and R[i][c] != 0:
                f = R[i][c]
                R[i] = [a - f * b for a, b in zip(R[i], R[r])]
        pivots.append(c)
        r += 1
        if r == len(R):
            break
    return R, pivots


R, pivots = rref([[1, 2, 3], [4, 5, 6], [7, 8, 9]])
print(len(pivots))
print([[str(x) for x in row] for row in R])
```

It prints `2` and a zero last row: the three vectors span a plane. This is a computation of one example, not a proof for others; the theorems above are what justify reading the dimension off the pivots.

@example
title: Proving a list is a basis
problem: Prove that $1 + x$, $x + x^2$, $1 + x^2$ is a basis of $\mathcal{P}_2(\mathbb{R})$.
step: To show: the list is independent and spans, or, by Theorem 3(d), that it is independent and has length $\dim \mathcal{P}_2(\mathbb{R}) = 3$. The length is $3$, so we prove independence.
step: Suppose $a(1 + x) + b(x + x^2) + c(1 + x^2) = 0$ as a polynomial. Collect coefficients of $1$, $x$, $x^2$: $a + c = 0$, $a + b = 0$, $b + c = 0$.
step: Adding the three equations gives $2(a + b + c) = 0$, so $a + b + c = 0$ (here $2 \ne 0$ in $\mathbb{R}$). Subtracting each equation in turn gives $b = 0$, $c = 0$ and $a = 0$.
step: The list is independent of length $3 = \dim \mathcal{P}_2(\mathbb{R})$, so it is a basis by Theorem 3(d). Over $\mathbb{F}_2$ the same list would be dependent, since the sum of the three polynomials is $2(1 + x + x^2) = 0$.
answer: The list is a basis of $\mathcal{P}_2(\mathbb{R})$.

@example
title: The dimension of a subspace
problem: Find a basis and the dimension of $U = \{(a, b, c, d) \in \mathbb{R}^4 : a + b + c + d = 0 \text{ and } a - b + c - d = 0\}$.
step: Add and subtract the two equations: $a + c = 0$ and $b + d = 0$, and conversely these two imply both original equations.
step: So $U = \{(a, b, -a, -b)\} = \{a(1, 0, -1, 0) + b(0, 1, 0, -1)\}$, which is the span of $(1, 0, -1, 0)$ and $(0, 1, 0, -1)$.
step: These two vectors are independent: $a(1, 0, -1, 0) + b(0, 1, 0, -1) = (a, b, -a, -b) = 0$ forces $a = b = 0$.
step: A spanning independent list of length $2$ is a basis, so $\dim U = 2$.
answer: $\dim U = 2$, with basis $(1,0,-1,0)$, $(0,1,0,-1)$.

@mistakes
- Treating a spanning list or an independent list as a basis: $1, x, x^2, x^2 + 1$ spans $\mathcal{P}_2$ but is dependent, and $1, x$ is independent but does not span.
- Counting nonzero vectors instead of independent ones: $(1,0), (2,0), (0,1)$ are three nonzero vectors in a $2$-dimensional space, and the dimension of their span is $2$.
- Forgetting that dimension depends on the field: $\mathbb{C}$ has dimension $1$ over $\mathbb{C}$ but $2$ over $\mathbb{R}$.
- Using $\dim(U + W) = \dim U + \dim W$ without checking that $U \cap W = \{0\}$.

model:
```python
from fractions import Fraction


def _rank(rows):
    """Rank of a list of rows by exact Gaussian elimination."""
    M = [[Fraction(x) for x in row] for row in rows]
    rank = 0
    for c in range(len(M[0]) if M else 0):
        p = next((i for i in range(rank, len(M)) if M[i][c] != 0), None)
        if p is None:
            continue
        M[rank], M[p] = M[p], M[rank]
        for i in range(rank + 1, len(M)):
            f = M[i][c] / M[rank][c]
            M[i] = [a - f * b for a, b in zip(M[i], M[rank])]
        rank += 1
    return rank


def extend_to_basis(vectors, n):
    """Standard basis vectors that extend an independent list to a basis."""
    current = [list(v) for v in vectors]
    added = []
    for i in range(n):
        e = [1 if j == i else 0 for j in range(n)]
        if _rank(current + [e]) == len(current) + 1:
            current.append(e)
            added.append(e)
    return added
```
hint: A new vector $w$ keeps an independent list independent exactly when the rank of the enlarged list is one more than the length of the old list.
hint: Compute the rank by exact Gaussian elimination with `Fraction`, and keep a running list of the vectors chosen so far.
solution: The list stays independent when a vector outside its span is appended (Theorem 3(b)), and a vector is outside the span exactly when the rank grows by one. Testing each standard vector in order and appending those that raise the rank produces an independent list; since $e_0, \dots, e_{n-1}$ span $\mathbb{Q}^n$, the final list spans and is a basis.

@quiz num
prompt: Let $V$ be the vector space of real $3 \times 3$ matrices in which every row sum and every column sum is $0$. Find $\dim V$.
answer: 4
check: 9 - rank([[1 if k // 3 == i else 0 for k in range(9)] for i in range(3)] + [[1 if k % 3 == j else 0 for k in range(9)] for j in range(3)])
hint: $V$ sits inside the $9$-dimensional space of all $3 \times 3$ matrices and is cut out by six linear equations; they are not independent.
solution: A matrix in $V$ is determined by its upper-left $2 \times 2$ block: the third entry of each of the first two rows is minus the sum of the other two, likewise for the first two columns, and the last row and column are then forced and consistent. So the map $V \to \mathbb{R}^{2 \times 2}$ taking the upper-left block is a bijection, and $\dim V = 4$. Equivalently, the six equations have rank $5$, since the sum of the three row equations equals the sum of the three column equations, and $9 - 5 = 4$.

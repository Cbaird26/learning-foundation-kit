@article
The matrix $A = \begin{pmatrix} 2 & 1 \\ 0 & 2 \end{pmatrix}$ is not diagonalizable, but $(A - 2I)^2 = 0$. Its eigenvector $(1, 0)$ spans only a line; the missing direction $(0, 1)$ is not killed by $A - 2I$, but it is killed by $(A - 2I)^2$. Allowing powers repairs the failure of eigenvectors to span.

### Generalized eigenspaces

Let $T \in \mathcal{L}(V)$ with $\dim V = n$. A vector $v$ is a **generalized eigenvector** of $T$ for $\lambda$ if $(T - \lambda I)^k v = 0$ for some $k \ge 1$ (and $v \ne 0$). The **generalized eigenspace** is $G(\lambda, T) = \{v : (T - \lambda I)^k v = 0 \text{ for some } k \ge 1\}$. It contains $E(\lambda, T)$. An operator $N$ is **nilpotent** if $N^k = 0$ for some $k$.

**Theorem 1.** For $N \in \mathcal{L}(V)$, $\operatorname{null} N^n = \operatorname{null} N^{n+1} = \operatorname{null} N^{n+2} = \cdots$. Hence $G(\lambda, T) = \operatorname{null}(T - \lambda I)^n$, and a nilpotent $N$ satisfies $N^n = 0$.

*Proof.* The null spaces satisfy $\operatorname{null} N^k \subseteq \operatorname{null} N^{k+1}$. If $\operatorname{null} N^k = \operatorname{null} N^{k+1}$ then $\operatorname{null} N^{k+1} = \operatorname{null} N^{k+2}$: if $N^{k+2}v = 0$ then $Nv \in \operatorname{null} N^{k+1} = \operatorname{null} N^k$, so $N^{k+1}v = 0$. Thus once two consecutive null spaces agree, all later ones do. Before that, the dimensions strictly increase, and they are at most $n$, so the sequence stabilizes by step $n$. For nilpotent $N$ with $N^k = 0$, $\operatorname{null} N^k = V$ and $\operatorname{null} N^n \supseteq \operatorname{null} N^{\min(k,n)}$, which gives $N^n = 0$ whenever the chain reaches $V$ by step $n$; since $\operatorname{null} N^m = \operatorname{null} N^n$ for all $m \ge n$, taking $m \ge k$ gives $\operatorname{null} N^n = V$. $\blacksquare$

**Theorem 2.** For every $N \in \mathcal{L}(V)$, $V = \operatorname{null} N^n \oplus \operatorname{range} N^n$, and both subspaces are $N$-invariant.

*Proof.* Invariance is clear. If $v \in \operatorname{null} N^n \cap \operatorname{range} N^n$, write $v = N^n w$. Then $N^{2n}w = N^n v = 0$, so $w \in \operatorname{null} N^{2n} = \operatorname{null} N^n$ by Theorem 1, and $v = N^n w = 0$. The intersection is $\{0\}$, so the sum is direct with $\dim = \dim \operatorname{null} N^n + \dim \operatorname{range} N^n = n$ by rank–nullity. A subspace of dimension $n$ in $V$ is $V$. $\blacksquare$

**Theorem 3 (generalized eigenspace decomposition; outline).** If $V$ is a complex vector space and $\lambda_1, \dots, \lambda_m$ are the distinct eigenvalues of $T$, then $V = G(\lambda_1, T) \oplus \dots \oplus G(\lambda_m, T)$. *Outline.* Induct on $\dim V$. With $N = T - \lambda_1 I$, Theorem 2 gives $V = G(\lambda_1, T) \oplus R$ with $R = \operatorname{range} N^n$ invariant under $T$ and $\dim R < n$ (since $\lambda_1$ is an eigenvalue). The restriction of $T$ to $R$ has no eigenvalue $\lambda_1$, and for $\mu \ne \lambda_1$ every generalized eigenvector of $T$ for $\mu$ lies in $R$, because $T - \mu I$ is injective on $G(\lambda_1, T)$. The induction hypothesis applied to $T|_R$ finishes the proof.

### Nilpotent operators

**Theorem 4.** If $N \in \mathcal{L}(V)$ is nilpotent, there are vectors $w_1, \dots, w_s$ and integers $m_1, \dots, m_s \ge 0$ with $N^{m_j + 1}w_j = 0$ such that the list $N^i w_j$ ($1 \le j \le s$, $0 \le i \le m_j$) is a basis of $V$.

*Proof.* Induct on $\dim V$; the case $\dim V = 0$ is empty. Let $\dim V \ge 1$. Since $N$ is not injective (a nilpotent operator on $V \ne \{0\}$ is not injective), $U = \operatorname{range} N$ has $\dim U < \dim V$ and is $N$-invariant, and $N|_U$ is nilpotent. By induction $U$ has a basis $N^i u_j$ ($1 \le j \le s$, $0 \le i \le m_j$) with $N^{m_j + 1}u_j = 0$. The last vectors $N^{m_j}u_j$ form a basis of $\operatorname{null} N \cap U$: they are independent, and if $x = \sum c_{ji}N^i u_j$ has $Nx = 0$, then $\sum c_{ji}N^{i+1}u_j = 0$ has the nonzero-looking terms $i < m_j$ independent, forcing $c_{ji} = 0$ for $i < m_j$.
Since $u_j \in \operatorname{range} N$, choose $w_j$ with $Nw_j = u_j$. Extend $N^{m_1}u_1, \dots, N^{m_s}u_s$ to a basis of $\operatorname{null} N$ by adding $z_1, \dots, z_p$. We claim the list $N^k w_j$ ($0 \le k \le m_j + 1$), together with $z_1, \dots, z_p$, is a basis of $V$. Its length is $\sum (m_j + 2) + p = \dim U + (s + p) = \dim \operatorname{range} N + \dim \operatorname{null} N = \dim V$, so independence suffices. Suppose $\sum c_{jk}N^k w_j + \sum d_i z_i = 0$. Apply $N$: $\sum_{j} \sum_{k \le m_j} c_{jk}N^k u_j = 0$ (the terms $k = m_j + 1$ vanish since $N^{m_j+1}u_j = 0$ and $Nz_i = 0$). By independence of the basis of $U$, $c_{jk} = 0$ for $k \le m_j$. What remains is $\sum_j c_{j, m_j+1}N^{m_j}u_j + \sum d_i z_i = 0$, a combination of the basis of $\operatorname{null} N$, so all remaining coefficients vanish. $\blacksquare$

Ordering each chain as $N^{m}w, \dots, Nw, w$ gives $N b_1 = 0$ and $N b_k = b_{k-1}$, so the matrix of $N$ is block diagonal with **Jordan blocks** $J_s(0)$: the $s \times s$ matrix with $1$ in each entry directly above the diagonal and $0$ elsewhere. $J_s(\lambda) = \lambda I + J_s(0)$.

### The Jordan form

**Theorem 5.** If $V$ is a finite-dimensional complex vector space and $T \in \mathcal{L}(V)$, then $V$ has a basis in which $\mathcal{M}(T)$ is block diagonal with blocks $J_s(\lambda)$. For each eigenvalue $\lambda$ and each $k \ge 1$, the number of blocks $J_s(\lambda)$ with $s \ge k$ equals $d_k - d_{k-1}$, where $d_k = \dim \operatorname{null}(T - \lambda I)^k$ and $d_0 = 0$. In particular the block sizes are uniquely determined by $T$.

*Proof.* Existence: write $V = \bigoplus G(\lambda_j, T)$ (Theorem 3). On $G(\lambda_j, T)$ the operator $T - \lambda_j I$ is nilpotent; apply Theorem 4 and add $\lambda_j I$. Counting: for a single block $J_s(\lambda)$, $(J_s(\lambda) - \lambda I)^k = J_s(0)^k$ has null space of dimension $\min(k, s)$ (it kills exactly the first $\min(k, s)$ basis vectors of the chain). A block $J_s(\mu)$ with $\mu \ne \lambda$ has $J_s(\mu) - \lambda I$ upper triangular with nonzero diagonal, hence invertible (Lesson 6). So $d_k = \sum_{\text{blocks } J_s(\lambda)} \min(k, s)$, and $d_k - d_{k-1}$ counts the blocks with $s \ge k$. $\blacksquare$

The number of blocks of size exactly $k$ is therefore $(d_k - d_{k-1}) - (d_{k+1} - d_k) = 2d_k - d_{k-1} - d_{k+1}$. The following code computes the sequence $d_k$ with exact arithmetic:

```python
from fractions import Fraction


def rank(rows):
    M = [[Fraction(x) for x in row] for row in rows]
    r = 0
    for c in range(len(M[0])):
        p = next((i for i in range(r, len(M)) if M[i][c] != 0), None)
        if p is None:
            continue
        M[r], M[p] = M[p], M[r]
        for i in range(r + 1, len(M)):
            f = M[i][c] / M[r][c]
            M[i] = [a - f * b for a, b in zip(M[i], M[r])]
        r += 1
    return r


def nullities(A, lam, kmax):
    """d_k = dim null (A - lam I)^k for k = 0, ..., kmax."""
    n = len(A)
    B = [[A[i][j] - (lam if i == j else 0) for j in range(n)] for i in range(n)]
    P = [[int(i == j) for j in range(n)] for i in range(n)]
    d = [0]
    for _ in range(kmax):
        P = [[sum(P[i][t] * B[t][j] for t in range(n)) for j in range(n)]
             for i in range(n)]
        d.append(n - rank(P))
    return d


print(nullities([[2, 1, 0], [0, 2, 0], [0, 0, 5]], 2, 3))
```

It prints `[0, 1, 2, 2]`: one block of size $2$ for the eigenvalue $2$ (and the eigenvalue $5$ contributes nothing to $\lambda = 2$). Computing ranks of powers is a check on a given matrix; Theorem 5 is what justifies reading the block sizes from them.

@example
title: The Jordan form of a $3 \times 3$ matrix
problem: Find the Jordan form $J$ of $A = \begin{pmatrix} 3 & -1 & 0 \\ 1 & 1 & 0 \\ 1 & -1 & 2 \end{pmatrix}$ and a matrix $P$ with $P^{-1}AP = J$.
step: Let $B = A - 2I = \begin{pmatrix} 1 & -1 & 0 \\ 1 & -1 & 0 \\ 1 & -1 & 0 \end{pmatrix}$. All three rows are multiples of $(1, -1, 0)$, so $B = uv^\top$ with $u = (1, 1, 1)$ and $v = (1, -1, 0)$, and $B^2 = u(v^\top u)v^\top = 0$ because $v^\top u = 0$. So $A = 2I + B$ with $B$ nilpotent, and $2$ is the only eigenvalue.
step: Dimensions: $\operatorname{rank} B = 1$, so $d_1 = 3 - 1 = 2$; and $B^2 = 0$ gives $d_2 = 3$. The number of blocks of size at least $1$ is $d_1 - d_0 = 2$, of size at least $2$ is $d_2 - d_1 = 1$, and of size at least $3$ is $d_3 - d_2 = 0$. So there is one block of size $2$ and one of size $1$.
step: Therefore $J = J_2(2) \oplus J_1(2) = \begin{pmatrix} 2 & 1 & 0 \\ 0 & 2 & 0 \\ 0 & 0 & 2 \end{pmatrix}$.
step: A Jordan basis: take $w = (1, 0, 0)$, so $Bw = (1, 1, 1) \ne 0$, and $z = (0, 0, 1) \in \operatorname{null} B$, independent of $Bw$. With $P = [\,Bw \mid w \mid z\,]$ (columns $(1,1,1)$, $(1,0,0)$, $(0,0,1)$) check $A(Bw) = 2Bw$, $Aw = Bw + 2w$ and $Az = 2z$, which is exactly $AP = PJ$.
answer: $J = \begin{pmatrix} 2 & 1 & 0 \\ 0 & 2 & 0 \\ 0 & 0 & 2 \end{pmatrix}$.

@example
title: Block sizes from nullities
problem: For an eigenvalue $\lambda = 5$ of an operator $T$ on $\mathbb{C}^7$, the dimensions $\dim \operatorname{null}(T - 5I)^k$ for $k = 1, 2, 3, 4$ are $2, 4, 5, 5$. Find the Jordan blocks for $5$.
step: With $d_0 = 0$ and $d_1, \dots, d_4 = 2, 4, 5, 5$, the numbers of blocks of size at least $k$ are $d_k - d_{k-1} = 2, 2, 1, 0$ for $k = 1, 2, 3, 4$.
step: The number of blocks of size exactly $k$ is the difference of consecutive terms: size $1$: $2 - 2 = 0$; size $2$: $2 - 1 = 1$; size $3$: $1 - 0 = 1$; size $4$ and larger: $0$.
step: So the blocks for $5$ are $J_3(5)$ and $J_2(5)$.
step: Check: $\dim G(5, T) = d_4 = 5 = 3 + 2$, the sum of the block sizes. The remaining $7 - 5 = 2$ dimensions belong to other eigenvalues.
answer: One block of size $3$ and one block of size $2$ for the eigenvalue $5$.

@mistakes
- Believing that the eigenvalues and their multiplicities determine the Jordan form: $J_2(1) \oplus J_1(1)$ and $J_1(1)^{\oplus 3}$ have the same characteristic polynomial $(z - 1)^3$ but different Jordan forms.
- Counting blocks by $\dim E(\lambda, T)$ and sizes by multiplicity alone: $\dim E(\lambda, T)$ is the number of blocks, while the sizes come from the larger $d_k$.
- Forgetting that the Jordan form theorem needs an algebraically closed field such as $\mathbb{C}$ (or that all eigenvalues lie in the field).
- Writing the $1$s of a Jordan block below the diagonal: with the chain ordered $N^m w, \dots, w$ they lie above it.

```python
from fractions import Fraction


def _rank(rows):
    """Rank by exact Gaussian elimination."""
    M = [[Fraction(x) for x in row] for row in rows]
    r = 0
    for c in range(len(M[0])):
        p = next((i for i in range(r, len(M)) if M[i][c] != 0), None)
        if p is None:
            continue
        M[r], M[p] = M[p], M[r]
        for i in range(r + 1, len(M)):
            f = M[i][c] / M[r][c]
            M[i] = [a - f * b for a, b in zip(M[i], M[r])]
        r += 1
    return r


def block_sizes(A, lam):
    """Jordan block sizes of A for the eigenvalue lam, largest first."""
    n = len(A)
    B = [[A[i][j] - (lam if i == j else 0) for j in range(n)] for i in range(n)]
    P = [[int(i == j) for j in range(n)] for i in range(n)]
    d = [0]
    for _ in range(n + 1):
        P = [[sum(P[i][t] * B[t][j] for t in range(n)) for j in range(n)]
             for i in range(n)]
        d.append(n - _rank(P))
    sizes = []
    for k in range(n, 0, -1):
        sizes += [k] * (2 * d[k] - d[k - 1] - d[k + 1])
    return sizes
```

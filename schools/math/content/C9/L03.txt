@article
Differentiation sends a polynomial of degree at most $3$ to a polynomial of degree at most $2$. It kills exactly the constants (a $1$-dimensional set) and it hits every polynomial of degree at most $2$ (a $3$-dimensional set). The domain has dimension $4 = 1 + 3$. This is no accident: every linear map splits the dimension of its domain between what it kills and what it produces.

### Linear maps

**Definition.** A function $T\colon V \to W$ between vector spaces over $F$ is **linear** if $T(u + v) = Tu + Tv$ and $T(av) = a\,Tv$ for all $u, v \in V$ and $a \in F$. The set of linear maps is $\mathcal{L}(V, W)$, a vector space under $(S + T)v = Sv + Tv$ and $(aT)v = a(Tv)$; for $S \in \mathcal{L}(W, X)$ the composition $ST$ is linear.

Examples: $D\colon \mathcal{P}_3(\mathbb{R}) \to \mathcal{P}_2(\mathbb{R})$, $p \mapsto p'$; evaluation $p \mapsto p(a)$; $\mathbb{R}^3 \to \mathbb{R}^2$, $(x, y, z) \mapsto (x + y, y + z)$; $A \mapsto A^\top$; $f \mapsto \int_0^1 f$. The map $x \mapsto x + 1$ on $\mathbb{R}$ is not linear: it sends $0$ to $1$, and $T0 = 0$ for every linear $T$ by $T0 = T(0 \cdot 0) = 0\,T0$.

**Theorem 1.** If $v_1, \dots, v_n$ is a basis of $V$ and $w_1, \dots, w_n \in W$ are arbitrary, there is exactly one $T \in \mathcal{L}(V, W)$ with $Tv_k = w_k$ for all $k$.

*Proof.* Define $T(\sum a_k v_k) = \sum a_k w_k$; this is well defined because the coefficients are unique (Lesson 2), and it is linear by direct check. Any linear map with $Tv_k = w_k$ must satisfy this formula, so it is unique. $\blacksquare$

### Null space and range

For $T \in \mathcal{L}(V, W)$ let $\operatorname{null} T = \{v \in V : Tv = 0\}$ and $\operatorname{range} T = \{Tv : v \in V\}$. Both are subspaces (the subspace test: $T0 = 0$, and $T$ respects sums and scalars).

**Theorem 2.** $T$ is injective if and only if $\operatorname{null} T = \{0\}$.

*Proof.* If $T$ is injective and $Tv = 0 = T0$, then $v = 0$. Conversely, if $\operatorname{null} T = \{0\}$ and $Tu = Tv$, then $T(u - v) = 0$, so $u - v = 0$. $\blacksquare$

**Theorem 3 (rank–nullity).** If $V$ is finite-dimensional and $T \in \mathcal{L}(V, W)$, then $\operatorname{range} T$ is finite-dimensional and
$$\dim V = \dim \operatorname{null} T + \dim \operatorname{range} T.$$

*Proof.* The subspace $\operatorname{null} T$ is finite-dimensional with a basis $u_1, \dots, u_m$. Extend it to a basis $u_1, \dots, u_m, v_1, \dots, v_r$ of $V$, so $\dim V = m + r$. We show that $Tv_1, \dots, Tv_r$ is a basis of $\operatorname{range} T$, which gives $\dim \operatorname{range} T = r$.
*Spanning.* Let $w = Tv$ with $v = \sum a_i u_i + \sum b_k v_k$. Since $Tu_i = 0$, $w = \sum b_k Tv_k$.
*Independence.* Suppose $\sum c_k Tv_k = 0$. Then $T(\sum c_k v_k) = 0$, so $\sum c_k v_k \in \operatorname{null} T$ and $\sum c_k v_k = \sum d_i u_i$ for some $d_i$. Then $\sum c_k v_k - \sum d_i u_i = 0$ is a dependence among basis vectors of $V$, so all $c_k$ and $d_i$ vanish. $\blacksquare$

**Corollary 4.** Let $V, W$ be finite-dimensional and $T \in \mathcal{L}(V, W)$. (a) If $\dim V > \dim W$, $T$ is not injective. (b) If $\dim V < \dim W$, $T$ is not surjective. (c) If $\dim V = \dim W$, then $T$ is injective if and only if it is surjective.

*Proof.* (a) $\dim \operatorname{null} T = \dim V - \dim \operatorname{range} T \ge \dim V - \dim W > 0$. (b) $\dim \operatorname{range} T \le \dim V < \dim W$. (c) $T$ is injective iff $\dim \operatorname{null} T = 0$ iff $\dim \operatorname{range} T = \dim V = \dim W$ iff $\operatorname{range} T = W$ (Lesson 2, Theorem 3(c)). $\blacksquare$

Part (c) fails in infinite dimensions. On the space of real sequences, the left shift $(a_1, a_2, a_3, \dots) \mapsto (a_2, a_3, \dots)$ is surjective but kills $(1, 0, 0, \dots)$, so it is not injective.

### Computing null space and range

```python
from fractions import Fraction


def rref(rows):
    """Exact reduced row echelon form; returns (matrix, pivot columns)."""
    R = [[Fraction(x) for x in row] for row in rows]
    pivots, r = [], 0
    for c in range(len(R[0])):
        p = next((i for i in range(r, len(R)) if R[i][c] != 0), None)
        if p is None:
            continue
        R[r], R[p] = R[p], R[r]
        R[r] = [x / R[r][c] for x in R[r]]
        for i in range(len(R)):
            if i != r and R[i][c] != 0:
                f = R[i][c]
                R[i] = [a - f * b for a, b in zip(R[i], R[r])]
        pivots.append(c)
        r += 1
        if r == len(R):
            break
    return R, pivots


def null_basis(rows):
    """Basis of {x : Mx = 0}: one vector per free column."""
    R, pivots = rref(rows)
    n = len(rows[0])
    basis = []
    for f in (c for c in range(n) if c not in pivots):
        x = [Fraction(0)] * n
        x[f] = Fraction(1)
        for r, p in enumerate(pivots):
            x[p] = -R[r][f]
        basis.append(x)
    return basis


M = [[1, 2, 1, 0], [2, 4, 0, 2], [3, 6, 1, 2]]
print(len(rref(M)[1]), len(null_basis(M)))
```

It prints `2 2`: rank plus nullity is $4$, the number of columns, as Theorem 3 predicts for $x \mapsto Mx$ on $\mathbb{Q}^4$. One matrix confirms nothing in general; the proof does.

@example
title: Null space and range of an evaluation map
problem: Let $T\colon \mathcal{P}_3(\mathbb{R}) \to \mathbb{R}^2$, $Tp = (p(1), p'(1))$. Find $\dim \operatorname{null} T$ and $\dim \operatorname{range} T$ and decide whether $T$ is surjective.
step: Find the null space. If $p(1) = 0$, then $p = (x - 1) r$ with $r \in \mathcal{P}_2(\mathbb{R})$. Then $p' = r + (x - 1) r'$, so $p'(1) = r(1)$. Thus $p \in \operatorname{null} T$ iff $r(1) = 0$, that is $r = (x - 1) s$ with $s \in \mathcal{P}_1(\mathbb{R})$.
step: So $\operatorname{null} T = \{(x - 1)^2 s : s \in \mathcal{P}_1(\mathbb{R})\}$, with basis $(x - 1)^2,\ x(x - 1)^2$. Hence $\dim \operatorname{null} T = 2$.
step: Apply rank–nullity: $\dim \operatorname{range} T = \dim \mathcal{P}_3(\mathbb{R}) - 2 = 4 - 2 = 2$.
step: $\operatorname{range} T$ is a $2$-dimensional subspace of $\mathbb{R}^2$, so it equals $\mathbb{R}^2$ and $T$ is surjective. Directly: $T(1) = (1, 0)$ and $T(x - 1) = (0, 1)$.
answer: $\dim \operatorname{null} T = 2$, $\dim \operatorname{range} T = 2$, and $T$ is surjective.

@example
title: Interpolation from injectivity
problem: Prove that for any real numbers $y_0, y_1, y_2$ there is a polynomial $p$ of degree at most $2$ with $p(0) = y_0$, $p(1) = y_1$ and $p(2) = y_2$.
step: Define $T\colon \mathcal{P}_2(\mathbb{R}) \to \mathbb{R}^3$ by $Tp = (p(0), p(1), p(2))$. It is linear. We must show that $T$ is surjective.
step: The spaces have equal dimension, $\dim \mathcal{P}_2(\mathbb{R}) = 3 = \dim \mathbb{R}^3$, so by Corollary 4(c) it suffices to show that $T$ is injective.
step: If $Tp = 0$, then $p$ has the three roots $0, 1, 2$. A nonzero polynomial of degree at most $2$ has at most $2$ roots, so $p = 0$. Hence $\operatorname{null} T = \{0\}$ and $T$ is injective by Theorem 2.
step: Therefore $T$ is surjective, and each $(y_0, y_1, y_2)$ equals $Tp$ for some $p$.
answer: Such a polynomial exists for every choice of $y_0, y_1, y_2$.

@mistakes
- Forgetting that a linear map sends $0$ to $0$: $x \mapsto 2x + 1$ is affine, not linear.
- Reading rank–nullity as $V = \operatorname{null} T \oplus \operatorname{range} T$: the two subspaces live in different spaces ($V$ and $W$), and even for $T \in \mathcal{L}(V)$ they can overlap: for $D$ on $\mathcal{P}_2(\mathbb{R})$ both contain the constants.
- Using "injective if and only if surjective" when $\dim V \ne \dim W$ or $V$ is infinite-dimensional.
- Checking injectivity by looking at one vector instead of showing $\operatorname{null} T = \{0\}$.

model:
```python
from fractions import Fraction


def solve(M, b):
    """One solution of Mx = b (free variables 0), or None if none exists."""
    A = [[Fraction(x) for x in row] + [Fraction(y)] for row, y in zip(M, b)]
    n = len(M[0])
    pivots, r = [], 0
    for c in range(n):
        p = next((i for i in range(r, len(A)) if A[i][c] != 0), None)
        if p is None:
            continue
        A[r], A[p] = A[p], A[r]
        A[r] = [x / A[r][c] for x in A[r]]
        for i in range(len(A)):
            if i != r and A[i][c] != 0:
                f = A[i][c]
                A[i] = [a - f * t for a, t in zip(A[i], A[r])]
        pivots.append(c)
        r += 1
    if any(row[-1] != 0 for row in A[r:]):
        return None
    x = [Fraction(0)] * n
    for row, c in zip(A, pivots):
        x[c] = row[-1]
    return x
```
hint: Row reduce the augmented matrix $[M \mid b]$ exactly. A row that reads $0 = $ nonzero means there is no solution.
hint: After reduction, each pivot row gives the pivot variable as its right-hand side when all free variables are $0$.
solution: Append $b$ as an extra column and row reduce with exact fractions. After the pivot columns of $M$ are processed, any remaining row has zeros in every coefficient column, so a nonzero right-hand side there is a contradiction and the system is inconsistent. Otherwise, with free variables set to $0$, the pivot variable of each pivot row equals the right-hand side of that row. Solutions differ by elements of the null space, which is why a consistent system with free columns has infinitely many.

prompt: Let $S \in \mathcal{L}(W, X)$ and $T \in \mathcal{L}(V, W)$ with $V$ finite-dimensional. Prove that $\dim \operatorname{range}(ST) \le \min\{\dim \operatorname{range} S, \dim \operatorname{range} T\}$.
hint: Show $\operatorname{range}(ST) \subseteq \operatorname{range} S$. For the other bound, note $\operatorname{range}(ST) = S(\operatorname{range} T)$ and apply rank–nullity to the restriction of $S$ to $\operatorname{range} T$.
solution: $\operatorname{range} T$ is a finite-dimensional subspace of $W$ by rank–nullity. Let $S'$ be the restriction of $S$ to $\operatorname{range} T$. Then $\operatorname{range}(ST) = \operatorname{range} S'$, and rank–nullity for $S'$ shows that this space is finite-dimensional with $\dim \operatorname{range} S' = \dim \operatorname{range} T - \dim \operatorname{null} S' \le \dim \operatorname{range} T$. Also every vector $STv = S(Tv)$ lies in $\operatorname{range} S$, so $\operatorname{range}(ST) \subseteq \operatorname{range} S$, and a subspace of a space has dimension at most that of the larger space (Lesson 2, Theorem 3(c), when $\operatorname{range} S$ is finite-dimensional; otherwise the bound is trivial). Both bounds together give the claim. $\blacksquare$

answer: 3
check: 9 - sum(1 for i in range(3) for j in range(3) if i <= j)
hint: $A - A^\top = 0$ exactly when $A$ is symmetric. How many independent entries does a symmetric $3 \times 3$ matrix have?
solution: The null space is the space of symmetric matrices, which has dimension $6$ (the entries on and above the diagonal are free). By rank–nullity, $\dim \operatorname{range} T = 9 - 6 = 3$; indeed the range is the space of skew-symmetric matrices.

hint: Decide for each map whether $(1, 0, 0, \dots)$ is in the range and whether the null space is $\{0\}$.
solution: The right shift has null space $\{0\}$, since $(0, a_1, a_2, \dots) = 0$ forces every $a_k = 0$, but $(1, 0, 0, \dots)$ is not in its range.

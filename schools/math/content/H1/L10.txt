@article
A **rational expression** is a fraction whose numerator and denominator are polynomials, such as $\dfrac{x^2 - 9}{x + 3}$. It obeys the same rules as numerical fractions, with one extra duty: remembering which values of $x$ are not allowed.

### Start with ordinary fractions

The fraction $\frac{12}{18}$ simplifies by factoring: $\frac{2 \cdot 6}{3 \cdot 6} = \frac{2}{3}$. You cancel common **factors** (things that are multiplied), never common **terms** (things that are added). Expressions work the same way: factor the top and the bottom, then cancel common factors.

### Excluded values

Division by zero is undefined, so any value of $x$ that makes a denominator zero is **excluded**. For $\dfrac{x^2 - 9}{x + 3}$ the excluded value is $x = -3$. Find the excluded values from the **original** denominator, before you cancel anything.

### Simplifying

$$\frac{x^2 - 9}{x + 3} = \frac{(x - 3)(x + 3)}{x + 3} = x - 3, \qquad x \neq -3.$$

Keep the condition $x \neq -3$ attached. The simplified form $x - 3$ happens to make sense at $x = -3$, but the original expression does not. And cancel only factors: in $\frac{x + 3}{3}$ the two $3$s are not both factors, so nothing cancels.

### Multiplying and dividing

Factor everything, multiply across, and cancel. To divide, multiply by the reciprocal of the second fraction.

$$\frac{x^2 - 4}{x + 1} \cdot \frac{x + 1}{x - 2} = \frac{(x - 2)(x + 2)}{x + 1} \cdot \frac{x + 1}{x - 2} = x + 2, \qquad x \neq -1,\; 2.$$

### Adding and subtracting

Use a common denominator, exactly as in $\frac{1}{2} + \frac{1}{3} = \frac{3}{6} + \frac{2}{6} = \frac{5}{6}$. Build the common denominator from each distinct factor:

$$\frac{2}{x} + \frac{3}{x + 1} = \frac{2(x + 1) + 3x}{x(x + 1)} = \frac{5x + 2}{x(x + 1)}.$$

Never add the tops and the bottoms separately.

### Rational equations

To solve $\frac{3}{x} + \frac{1}{2} = 2$, multiply every term by the LCD, here $2x$, just as you did with fractions in linear equations: $6 + x = 4x$, so $x = 2$. Because you multiplied by an expression containing $x$, you must check each answer against the excluded values. A value that makes a denominator zero is an **extraneous solution** and must be rejected, even though the algebra produced it.

@example
title: Simplify and state excluded values
problem: Simplify $\dfrac{x^2 - x - 6}{x^2 - 9}$ and state the excluded values.
step: Factor the denominator first, since the excluded values come from it: $x^2 - 9 = (x - 3)(x + 3)$. The excluded values are $x = 3$ and $x = -3$.
step: Factor the numerator: $x^2 - x - 6 = (x - 3)(x + 2)$, because $-3$ and $2$ have product $-6$ and sum $-1$.
step: Cancel the common factor $x - 3$: $\dfrac{(x - 3)(x + 2)}{(x - 3)(x + 3)} = \dfrac{x + 2}{x + 3}$.
step: State the result with its condition: $\dfrac{x + 2}{x + 3}$ for $x \neq 3, -3$.
step: Test $x = 1$: the original is $\dfrac{1 - 1 - 6}{1 - 9} = \dfrac{-6}{-8} = \dfrac{3}{4}$, and $\dfrac{1 + 2}{1 + 3} = \dfrac{3}{4}$.

@example
title: Rejecting an extraneous solution
problem: Solve $\dfrac{x^2}{x - 2} = \dfrac{4}{x - 2}$.
step: The denominator is zero when $x = 2$, so $x = 2$ is excluded.
step: Multiply both sides by $x - 2$: $x^2 = 4$.
step: Solve the quadratic: $x = 2$ or $x = -2$.
step: Reject $x = 2$. It is excluded, because it makes both denominators zero, so it is extraneous.
step: Check $x = -2$: the left side is $\dfrac{4}{-4} = -1$ and the right side is $\dfrac{4}{-4} = -1$. The only solution is $x = -2$.

@mistakes
- Canceling terms instead of factors, such as turning $\dfrac{x + 3}{3}$ into $x + 1$.
- Finding excluded values only after canceling, so a restriction such as $x \neq 3$ disappears.
- Adding fractions by adding the tops and the bottoms: $\dfrac{2}{x} + \dfrac{3}{x + 1}$ is not $\dfrac{5}{2x + 1}$.
- Keeping an extraneous solution that makes a denominator zero.

@practice expr
prompt: Simplify $\dfrac{x^2 - 25}{x^2 + 5x}$.
vars: x
answer: (x - 5)/x
check: lambda x: (x**2 - 25)/(x**2 + 5*x)
hint: Factor the top as a difference of squares and the bottom by taking out the common factor.
hint: The top is $(x - 5)(x + 5)$ and the bottom is $x(x + 5)$. Which factor is common?
solution: $\dfrac{(x - 5)(x + 5)}{x(x + 5)} = \dfrac{x - 5}{x}$, for $x \neq 0, -5$. Test $x = 1$: $\frac{-24}{6} = -4$ and $\frac{1 - 5}{1} = -4$.

@practice expr
prompt: Write $\dfrac{3}{x - 1} - \dfrac{2}{x + 2}$ as a single fraction.
vars: x
domain: x: 1.5..4
answer: (x + 8)/((x - 1)(x + 2))
check: lambda x: 3/(x - 1) - 2/(x + 2)
hint: The common denominator is $(x - 1)(x + 2)$. Multiply each top by the factor its denominator is missing.
hint: The numerator is $3(x + 2) - 2(x - 1)$. Keep the second product in brackets so the minus sign reaches both terms.
solution: $\dfrac{3(x + 2) - 2(x - 1)}{(x - 1)(x + 2)} = \dfrac{3x + 6 - 2x + 2}{(x - 1)(x + 2)} = \dfrac{x + 8}{(x - 1)(x + 2)}$. Test $x = 2$: $3 - \frac{2}{4} = 2.5$ and $\frac{10}{1 \cdot 4} = 2.5$.

@practice mc
prompt: A student solves $\dfrac{x}{x - 3} = \dfrac{3}{x - 3} + 2$ and finds $x = 3$. What should the student conclude?
choice*: There is no solution: $x = 3$ makes the denominators zero, so it must be rejected.
choice: The solution is $x = 3$, since the algebra produced it.
choice: Every number except $3$ is a solution.
choice: The solution is $x = -3$.
hint: Look at the original denominators. What happens to them when $x = 3$?
hint: Multiplying by $x - 3$ gives $x = 3 + 2(x - 3)$, which leads to $x = 3$. Can that value be used in the original equation?
solution: Multiplying by $x - 3$ gives $x = 3 + 2x - 6$, so $x = 3$. But $x = 3$ makes the denominators in the original equation zero, so it is extraneous. No value of $x$ solves the equation.

@practice self
prompt: (a) Solve $x^2 - 2x - 8 = 0$ by factoring. (b) Solve it again with the quadratic formula and check that the two methods agree. (c) For the expression $\dfrac{x^2 - 2x - 8}{x^2 - 16}$, state the excluded values, simplify it, and find its value at $x = 2$.
hint: For (a), find two numbers with product $-8$ and sum $-2$.
hint: For (c), find the excluded values from the original denominator $x^2 - 16$ before you cancel anything.
solution: (a) $x^2 - 2x - 8 = (x - 4)(x + 2) = 0$, so $x = 4$ or $x = -2$. (b) With $a = 1$, $b = -2$, $c = -8$: $D = 4 + 32 = 36$ and $x = \frac{2 \pm 6}{2}$, giving $x = 4$ or $x = -2$. The two methods agree. (c) The denominator is $(x - 4)(x + 4)$, so the excluded values are $x = 4$ and $x = -4$. Canceling the common factor $x - 4$ gives $\frac{x + 2}{x + 4}$ for $x \neq 4, -4$. At $x = 2$ the value is $\frac{4}{6} = \frac{2}{3}$, and the original expression gives $\frac{4 - 4 - 8}{4 - 16} = \frac{-8}{-12} = \frac{2}{3}$.
rubric: The factored form $(x - 4)(x + 2)$ is correct and gives the solutions $4$ and $-2$.
rubric: The quadratic formula uses the right $a$, $b$, $c$, finds the discriminant $36$, and gives the same two solutions, with a comparison stated.
rubric: The excluded values $4$ and $-4$ come from the original denominator and are stated before or alongside the canceling.
rubric: The simplified form $\frac{x + 2}{x + 4}$ keeps its restrictions, and the value at $x = 2$ is $\frac{2}{3}$.

@quiz expr
prompt: Simplify $\dfrac{x^2 + 2x - 15}{x^2 - 9}$.
vars: x
answer: (x + 5)/(x + 3)
check: lambda x: (x**2 + 2*x - 15)/(x**2 - 9)
hint: Factor both the top and the bottom completely.
hint: The top has two numbers with product $-15$ and sum $2$; the bottom is a difference of squares. Then cancel the common factor.
solution: $\dfrac{(x + 5)(x - 3)}{(x - 3)(x + 3)} = \dfrac{x + 5}{x + 3}$, for $x \neq 3, -3$. Test $x = 1$: $\frac{1 + 2 - 15}{1 - 9} = \frac{-12}{-8} = \frac{3}{2}$ and $\frac{6}{4} = \frac{3}{2}$.

@quiz list
prompt: Solve $\dfrac{1}{x} + \dfrac{1}{x + 2} = \dfrac{3}{4}$. Enter both solutions, separated by a comma.
answer: -4/3, 2
check: [root(lambda x: 1/x + 1/(x + 2) - 3/4, a, b) for a, b in [(-1.9, -0.1), (0.1, 100)]]
hint: The excluded values are $0$ and $-2$. Multiply every term by the LCD, $4x(x + 2)$.
hint: You should reach $4(x + 2) + 4x = 3x(x + 2)$, which simplifies to a quadratic equation. Collect everything on one side and factor.
solution: Multiplying by $4x(x + 2)$ gives $4(x + 2) + 4x = 3x(x + 2)$, so $8x + 8 = 3x^2 + 6x$ and $3x^2 - 2x - 8 = 0$. This factors as $(3x + 4)(x - 2) = 0$, so $x = -\frac{4}{3}$ or $x = 2$. Neither is excluded. Check $x = 2$: $\frac{1}{2} + \frac{1}{4} = \frac{3}{4}$. Check $x = -\frac{4}{3}$: $-\frac{3}{4} + \frac{3}{2} = \frac{3}{4}$.

@article
A **function** is a rule that assigns to each allowed input exactly one output. We write $f(x)$, read "$f$ of $x$", for the output that the function $f$ gives when the input is $x$.

### Start with a machine

Picture a machine: you drop in a number, a fixed rule runs, and one number comes out. A temperature converter takes a Celsius temperature $C$ and returns $F = \frac{9}{5}C + 32$. Put in $100$ and out comes $212$; put in $0$ and out comes $32$. The same input always gives the same output. That is what makes it a function.

We name a rule with a letter: $f(x) = 2x^2 - 3$. To evaluate $f(4)$, replace every $x$ by $4$: $f(4) = 2(16) - 3 = 29$. When the input is an expression, keep it in brackets: $f(x + 1) = 2(x + 1)^2 - 3$.

### Is it a function?

Each input may have only **one** output. On a graph, this is the **vertical line test**: no vertical line may cross the graph more than once. The parabola $y = x^2$ passes. The circle $x^2 + y^2 = 1$ fails, because the input $x = 0$ gives both $y = 1$ and $y = -1$.

### Domain and range

The **domain** is the set of allowed inputs. The **range** is the set of outputs that actually occur. Unless told otherwise, the domain is every real number for which the formula makes sense. Two things break a formula:

- A zero denominator: $f(x) = \dfrac{1}{x - 2}$ has domain $x \neq 2$.
- An even root of a negative number: $g(x) = \sqrt{x - 3}$ needs $x - 3 \ge 0$, so its domain is $[3, \infty)$ and its range is $[0, \infty)$.

### Composition

To **compose** functions, feed the output of one into the next: $(f \circ g)(x) = f(g(x))$. Work from the inside out. With $f(x) = 2x + 1$ and $g(x) = x^2$, we get $f(g(3)) = f(9) = 19$, but $g(f(3)) = g(7) = 49$. The order matters.

### Inverse functions

An **inverse function** undoes the original. If $f$ turns the input $a$ into the output $b$, then $f^{-1}$ turns $b$ back into $a$. The notation $f^{-1}$ means "inverse", **not** $\frac{1}{f}$.

To find an inverse: (1) write $y = f(x)$; (2) swap $x$ and $y$; (3) solve for $y$. For $f(x) = 3x - 5$ we write $x = 3y - 5$, so $y = \frac{x + 5}{3}$ and $f^{-1}(x) = \frac{x + 5}{3}$. Check by composing: $f\big(f^{-1}(x)\big) = 3 \cdot \frac{x + 5}{3} - 5 = x$.

An inverse function exists only when $f$ is **one-to-one**: different inputs must give different outputs (the horizontal line test). The function $f(x) = x^2$ is not one-to-one on all real numbers, since $f(2) = f(-2)$. Restricting the domain to $x \ge 0$ fixes this, and the inverse is then $\sqrt{x}$.

Inverses swap domain and range: the domain of $f^{-1}$ is the range of $f$, and the range of $f^{-1}$ is the domain of $f$. On a graph, $f^{-1}$ is the reflection of $f$ in the line $y = x$.

@example
title: Domain and range of a root function
problem: Find the domain and range of $h(x) = \sqrt{x + 4} - 1$.
step: The expression under a square root cannot be negative, so $x + 4 \ge 0$, which gives $x \ge -4$. The domain is $[-4, \infty)$.
step: Over that domain, $\sqrt{x + 4}$ takes every value from $0$ upwards: $\sqrt{x + 4} \ge 0$.
step: Subtract $1$ from each side of that inequality: $h(x) \ge -1$.
step: The range is $[-1, \infty)$.
step: Check: $h(-4) = 0 - 1 = -1$ is the smallest output, and $h(5) = 3 - 1 = 2$ lies inside the range.

@example
title: Finding an inverse and swapping domain and range
problem: Find the inverse of $f(x) = \dfrac{2x + 1}{x - 3}$ and compare the domains and ranges of $f$ and $f^{-1}$.
step: Write $y = \dfrac{2x + 1}{x - 3}$ (domain $x \neq 3$) and swap $x$ and $y$: $x = \dfrac{2y + 1}{y - 3}$.
step: Multiply both sides by $y - 3$ and expand: $xy - 3x = 2y + 1$.
step: Gather the $y$-terms on one side and factor: $xy - 2y = 3x + 1$, so $y(x - 2) = 3x + 1$.
step: Divide by $x - 2$: $f^{-1}(x) = \dfrac{3x + 1}{x - 2}$, with $x \neq 2$.
step: Check: $f(4) = \frac{9}{1} = 9$ and $f^{-1}(9) = \frac{28}{7} = 4$. Also $f(x) = 2 + \frac{7}{x - 3}$ never equals $2$, so the range of $f$ is $y \neq 2$, which is exactly the excluded value of $f^{-1}$.

@mistakes
- Reading $f^{-1}(x)$ as $\dfrac{1}{f(x)}$. The $-1$ means "inverse function".
- Treating $f(x + 1)$ as $f(x) + 1$. Replace $x$ by $(x + 1)$ everywhere in the formula.
- Composing in the wrong order. In $f(g(x))$, the function $g$ is applied first.
- Forgetting to restrict the domain when a function is not one-to-one, or forgetting the excluded values when you find a domain.

vars: x
lead: $f^{-1}(x) =$
answer: (5x - 1)/2
check: lambda x: root(lambda y: (2*y + 1)/5 - x, -1000, 1000)
hint: Write $y = \frac{2x + 1}{5}$, swap $x$ and $y$, and solve for $y$.
hint: After swapping you have $x = \frac{2y + 1}{5}$. Multiply by $5$, subtract $1$, then divide by $2$.
solution: $x = \frac{2y + 1}{5}$ gives $5x = 2y + 1$, so $y = \frac{5x - 1}{2}$. Check: $f\big(f^{-1}(x)\big) = \frac{2 \cdot \frac{5x - 1}{2} + 1}{5} = \frac{5x}{5} = x$.

@practice num
prompt: The function $f(x) = x^2 + 2$ with domain $x \ge 0$ has an inverse. Find $f^{-1}(18)$.
answer: 4
check: root(lambda y: y**2 + 2 - 18, 0, 100)
hint: $f^{-1}(18)$ is the input that $f$ turns into the output $18$.
hint: Solve $x^2 + 2 = 18$, and keep only the solution that the domain $x \ge 0$ allows.
solution: $x^2 = 16$, so $x = 4$ or $x = -4$. The domain $x \ge 0$ leaves $x = 4$. Check: $f(4) = 16 + 2 = 18$.

@quiz num
prompt: Let $f(x) = \sqrt{x - 1} + 2$ with domain $x \ge 1$. Find $f^{-1}(5)$.
answer: 10
check: root(lambda x: sqrt(x - 1) + 2 - 5, 1, 1000)
hint: $f^{-1}(5)$ is the input for which the output is $5$.
hint: Solve $\sqrt{x - 1} + 2 = 5$: isolate the root first, then square both sides.
solution: $\sqrt{x - 1} = 3$, so $x - 1 = 9$ and $x = 10$. Check: $\sqrt{9} + 2 = 5$.

@quiz expr
prompt: Find the inverse function of $f(x) = \dfrac{x + 3}{x}$.
vars: x
domain: x: 1.5..4
lead: $f^{-1}(x) =$
answer: 3/(x - 1)
check: lambda x: root(lambda y: (y + 3)/y - x, 0.01, 100)
hint: Swap $x$ and $y$ to get $x = \frac{y + 3}{y}$, then multiply both sides by $y$.
hint: You get $xy = y + 3$. Collect the $y$-terms on one side and factor out $y$.
solution: $xy - y = 3$, so $y(x - 1) = 3$ and $y = \frac{3}{x - 1}$. Check: $f(3) = \frac{6}{3} = 2$ and $f^{-1}(2) = \frac{3}{2 - 1} = 3$.

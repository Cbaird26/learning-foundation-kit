@article
Press the cosine key on a calculator over and over, starting from $0.5$. The display settles near $0.739085$, and it does so from any starting value. The number $x$ with $\cos x = x$ is a *fixed point* of cosine, and the iteration converges because cosine shrinks distances on the right interval. This idea, with completeness, solves equations in $\mathbb{R}$, in $\mathbb{R}^n$ and in spaces of functions.

### The theorem

A map $T\colon X \to X$ of a metric space is a **contraction** if there is $k \in [0,1)$ with $d(Tx, Ty) \le k\,d(x,y)$ for all $x,y \in X$. (One constant $k<1$ serves for all pairs.)

**Theorem 1 (contraction mapping principle, Banach).** Let $(X,d)$ be a nonempty complete metric space and $T\colon X \to X$ a contraction with constant $k$. Then $T$ has exactly one fixed point $x^*$. For any $x_0 \in X$ the iterates $x_{n+1} = T x_n$ converge to $x^*$, and
$$d(x_n, x^*) \le \frac{k^n}{1-k}\,d(x_1,x_0) \quad\text{(a priori)}, \qquad d(x_n, x^*) \le \frac{k}{1-k}\,d(x_n, x_{n-1}) \quad\text{(a posteriori)}.$$

*Proof.* By induction $d(x_{n+1},x_n) \le k^n d(x_1,x_0)$. For $m > n$ the triangle inequality gives
$$d(x_m,x_n) \le \sum_{j=n}^{m-1} d(x_{j+1},x_j) \le d(x_1,x_0)\sum_{j=n}^{\infty}k^j = \frac{k^n}{1-k}\,d(x_1,x_0) .$$
The right side tends to $0$, so $(x_n)$ is Cauchy and converges to some $x^* \in X$ by completeness. A contraction is continuous, so $T x^* = \lim T x_n = \lim x_{n+1} = x^*$. If also $Ty = y$, then $d(x^*,y) = d(Tx^*,Ty) \le k\,d(x^*,y)$, forcing $d(x^*,y) = 0$ because $k<1$. Letting $m \to \infty$ in the display gives the a priori bound. For the a posteriori bound apply the a priori bound to the sequence started at $x_{n-1}$, whose first step is $x_n$: $d(x_n,x^*) \le \frac{k}{1-k}d(x_n,x_{n-1})$ (it is the bound at index $1$). $\blacksquare$

The a priori bound tells you in advance how many steps give accuracy $\varepsilon$: it suffices that $\frac{k^n}{1-k}d(x_1,x_0) \le \varepsilon$. The a posteriori bound lets you stop as soon as consecutive iterates are close.

### Checking the hypotheses

On a closed interval $[a,b]$ (complete) suppose $g$ is differentiable with $g([a,b]) \subseteq [a,b]$ and $|g'| \le k < 1$. The mean value theorem gives $|g(x)-g(y)| = |g'(\xi)||x-y| \le k|x-y|$, so $g$ is a contraction. For $g = \cos$ on $[0,1]$: $\cos$ maps $[0,1]$ into $[\cos 1, 1] \subseteq [0,1]$ and $|g'(x)| = \sin x \le \sin 1 \approx 0.8415 =: k$. So cosine has a unique fixed point in $[0,1]$.

```python
from math import cos, sin


def iterate(g, x0, n):
    """Return the list [x0, g(x0), ..., g^n(x0)]."""
    xs = [x0]
    for _ in range(n):
        xs.append(g(xs[-1]))
    return xs


k = sin(1.0)
xs = iterate(cos, 0.5, 30)
print(round(xs[-1], 6), round(k ** 30 / (1 - k) * abs(xs[1] - xs[0]), 4))
```

It prints `0.739084` and `0.0134`: the a priori bound guarantees an error below $0.0134$ after 30 steps, and the actual error is about $1.5\times10^{-6}$. The bound is valid but pessimistic, because $|\sin x|$ is near $0.67$ at the fixed point rather than $0.84$. A numerical run illustrates the bound; the proof is the theorem.

### Why each hypothesis is needed

- *Completeness*: $T(x) = x/2$ maps $(0,1]$ into itself with $k = 1/2$, but has no fixed point in $(0,1]$ (the only candidate is $0$).
- *A constant $k<1$*: $T(x) = x + 1/x$ on the complete space $[1,\infty)$ satisfies $|Tx - Ty| = |x-y|\,|1 - 1/(xy)| < |x-y|$ for $x \neq y$, yet $Tx - x = 1/x > 0$ for every $x$: no fixed point. Strict shrinking is not enough.
- *$T$ maps $X$ into $X$*: $T(x) = x/2 + 1$ is a contraction of $\mathbb{R}$ but is not a self-map of $[0,1]$ (it maps $1$ to $3/2$).

### Picard iteration

**Theorem 2 (Picard).** Let $f\colon [t_0 - a, t_0 + a] \times \mathbb{R} \to \mathbb{R}$ be continuous with $|f(t,y) - f(t,z)| \le L|y - z|$. Let $0 < h < \min(a, 1/L)$. Then $y' = f(t,y)$, $y(t_0) = y_0$ has exactly one solution on $[t_0 - h, t_0 + h]$.

*Proof.* Let $X = C[t_0 - h, t_0 + h]$ with the sup metric, complete by Lesson 2. Define $(Ty)(t) = y_0 + \int_{t_0}^t f(s, y(s))\,ds$; $Ty$ is continuous. By the fundamental theorem of calculus, a continuous $y$ satisfies $Ty = y$ if and only if $y$ is differentiable with $y' = f(t,y)$ and $y(t_0) = y_0$. For $|t - t_0| \le h$,
$$|(Ty)(t) - (Tz)(t)| \le \left|\int_{t_0}^t L|y(s) - z(s)|\,ds\right| \le Lh\, d(y,z) ,$$
so $T$ is a contraction with $k = Lh < 1$. Apply Theorem 1. $\blacksquare$

The iterates $y_{n+1} = T y_n$ from $y_0(t) \equiv y_0$ are the Picard iterates. For $y' = y$, $y(0) = 1$: $y_n(t) = \sum_{j \le n} t^j/j!$, the partial sums of $e^t$.

@example
title: Solving an equation by iteration with an error bound
problem: Show that $x = \dfrac{1}{2 + x^2}$ has exactly one solution in $[0,1]$, and bound the error of $x_{10}$ when the iteration starts at $x_0 = 0$.
step: Let $g(x) = 1/(2 + x^2)$. On $[0,1]$, $2 + x^2 \in [2,3]$, so $g(x) \in [1/3, 1/2] \subseteq [0,1]$: $g$ is a self-map of the complete space $[0,1]$.
step: $g'(x) = -2x/(2+x^2)^2$, and $|g'(x)| \le 2/4 = 1/2$ on $[0,1]$ (numerator $\le 2$, denominator $\ge 4$). By the mean value theorem $g$ is a contraction with $k = 1/2$.
step: By Theorem 1 there is exactly one fixed point. With $x_0 = 0$: $x_1 = g(0) = 1/2$, so $d(x_1,x_0) = 1/2$.
step: A priori bound: $|x_{10} - x^*| \le \dfrac{(1/2)^{10}}{1/2}\cdot\dfrac12 = 2^{-10} \approx 0.00098$.
answer: There is exactly one solution in $[0,1]$ (near $0.4534$), and $|x_{10} - x^*| \le 2^{-10}$.

@example
title: Picard iterates for an initial value problem
problem: Compute the first three Picard iterates for $y' = t + y$, $y(0) = 0$.
step: Here $f(t,y) = t + y$ is Lipschitz in $y$ with $L = 1$, so Theorem 2 applies for $h < 1$. Start with $y_0(t) = 0$.
step: $y_1(t) = \int_0^t (s + 0)\,ds = t^2/2$.
step: $y_2(t) = \int_0^t \left(s + s^2/2\right)ds = t^2/2 + t^3/6$.
step: $y_3(t) = \int_0^t \left(s + s^2/2 + s^3/6\right)ds = t^2/2 + t^3/6 + t^4/24$.
step: These are partial sums of $e^t - 1 - t = t^2/2 + t^3/6 + \cdots$, which indeed solves the problem ($y' = e^t - 1 = t + (e^t - 1 - t)$ and $y(0) = 0$).
answer: $y_1 = t^2/2$, $y_2 = t^2/2 + t^3/6$, $y_3 = t^2/2 + t^3/6 + t^4/24$, converging to $e^t - 1 - t$.

@mistakes
- Checking only $d(Tx,Ty) < d(x,y)$: you need a uniform $k<1$ (or $\sup$ of the ratio below $1$); $\sin x$ and $x + 1/x$ shrink distances strictly but are not contractions.
- Forgetting to show that $T$ maps the space into itself: the derivative bound alone does not keep iterates inside $[a,b]$.
- Applying the theorem on an incomplete space such as $(0,1]$ or $\mathbb{Q}$.
- Using the a priori bound with $d(x_0, x_1)$ replaced by $d(x_0,x^*)$ or forgetting the factor $1/(1-k)$.

model:
```python
def contract_solve(g, x0, k, eps):
    """Iterate g until the a posteriori error bound is below eps."""
    factor = k / (1 - k)
    prev = x0
    n = 0
    while True:
        cur = g(prev)
        n += 1
        if factor * abs(cur - prev) < eps:
            return cur, n
        prev = cur
```
hint: After computing each new iterate, compare $\frac{k}{1-k}$ times the distance to the previous iterate with eps.
solution: Keep the previous and current iterates, count the steps, and test the stopping rule after each step. The scale factor $k/(1-k)$ matters when $k \ne 1/2$: for $k = 1/3$ it is $1/2$, so the rule stops earlier than the naive test $|x_n - x_{n-1}| < \texttt{eps}$ would. The bound guarantees $|x_n - x^*| < \texttt{eps}$, which a run can only illustrate, since the guarantee comes from the theorem.

@practice self
prompt: Let $(X,d)$ be a nonempty complete metric space and $T\colon X \to X$ a map such that some iterate $S = T^m$ ($m \ge 1$) is a contraction. Prove that $T$ has exactly one fixed point.
hint: Let $x^*$ be the fixed point of $S$. Show that $Tx^*$ is also a fixed point of $S$.
solution: By Theorem 1, $S$ has a unique fixed point $x^*$. Since $S(Tx^*) = T^{m+1}x^* = T(T^m x^*) = T(Sx^*) = Tx^*$, the point $Tx^*$ is also a fixed point of $S$, so $Tx^* = x^*$ by uniqueness. If $Ty = y$ then $Sy = T^m y = y$, so $y$ is a fixed point of $S$ and $y = x^*$. Hence $T$ has exactly one fixed point. $\blacksquare$
rubric: Applies the contraction mapping principle to $S = T^m$ to get a unique fixed point $x^*$.
rubric: Shows $Tx^*$ is again a fixed point of $S$ using $S T = T S$, and concludes $Tx^* = x^*$.
rubric: Shows every fixed point of $T$ is a fixed point of $S$, giving uniqueness.

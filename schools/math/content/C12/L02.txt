@article
Newton's iteration $x_{k+1} = (x_k + 2/x_k)/2$ started at $x_0 = 1$ produces only rational numbers: $1,\ 3/2,\ 17/12,\ 577/408, \dots$ The terms bunch together ever more tightly, yet there is no rational number they approach, because their limit would square to $2$. In $\mathbb{Q}$ the sequence "should" converge, and does not. Completeness is the property that rules this out.

```python
from fractions import Fraction

x = Fraction(1)
for k in range(4):
    print(k, x, f"{float(x * x - 2):.3e}")
    x = (x + 2 / x) / 2
```

The squares $x_k^2$ approach $2$ quickly, which is evidence that the $x_k$ crowd together; a computation like this suggests, but does not prove, the Cauchy property.

### Convergence and Cauchy sequences

**Definition.** A sequence $(x_n)$ in a metric space $(X,d)$ *converges* to $x \in X$ if for every $\varepsilon > 0$ there is $N$ with $d(x_n, x) < \varepsilon$ for all $n \ge N$. It is *Cauchy* if for every $\varepsilon > 0$ there is $N$ with $d(x_m, x_n) < \varepsilon$ for all $m, n \ge N$. Limits are unique: if $x_n \to x$ and $x_n \to x'$ then $d(x,x') \le d(x,x_n) + d(x_n,x') \to 0$.

**Proposition 1.** A convergent sequence is Cauchy.

*Proof.* If $x_n \to x$ and $\varepsilon > 0$, pick $N$ with $d(x_n,x) < \varepsilon/2$ for $n \ge N$. For $m,n \ge N$, $d(x_m,x_n) \le d(x_m,x) + d(x,x_n) < \varepsilon$. $\blacksquare$

The converse can fail, as the Newton example shows in $\mathbb{Q}$. **Definition.** $X$ is *complete* if every Cauchy sequence in $X$ converges to a point of $X$. By the completeness of $\mathbb{R}$ from C8 (a Cauchy sequence of reals converges), $\mathbb{R}$ is complete, and $\mathbb{Q}$ is not.

### Sequences and closed sets

**Theorem 2.** A set $F \subseteq X$ is closed if and only if whenever $x_n \in F$ and $x_n \to x \in X$, then $x \in F$.

*Proof.* ($\Rightarrow$) Suppose $F$ is closed, $x_n \in F$, $x_n \to x$, and $x \notin F$. The set $X \setminus F$ is open, so $B(x,r) \subseteq X \setminus F$ for some $r > 0$; but $x_n \in B(x,r)$ for large $n$, contradicting $x_n \in F$. ($\Leftarrow$) Suppose $F$ is not closed. Then $X \setminus F$ is not open, so some $x \notin F$ has the property that no ball $B(x, 1/n)$ lies in $X \setminus F$; pick $x_n \in B(x,1/n) \cap F$. Then $d(x_n,x) < 1/n$, so $x_n \to x \in X \setminus F$, and the sequence condition fails. $\blacksquare$

**Corollary 3.** A closed subset of a complete space is complete, and a complete subset of any metric space is closed.

*Proof.* A Cauchy sequence in a closed $F \subseteq X$ complete converges in $X$, and the limit lies in $F$ by Theorem 2. If $F \subseteq X$ is complete and $x_n \in F$, $x_n \to x \in X$, then $(x_n)$ is Cauchy by Proposition 1, so converges to a point of $F$; by uniqueness of limits that point is $x$, so $x \in F$ and $F$ is closed by Theorem 2. $\blacksquare$

### Two complete spaces

**Theorem 4.** $\mathbb{R}^n$ with the Euclidean metric is complete.

*Proof.* Let $(x^{(p)})$ be Cauchy. Since $|x^{(p)}_i - x^{(q)}_i| \le \|x^{(p)} - x^{(q)}\|$, each coordinate sequence is Cauchy in $\mathbb{R}$, hence converges to some $y_i$. Given $\varepsilon > 0$ choose $N$ so that each coordinate satisfies $|x^{(p)}_i - y_i| < \varepsilon/\sqrt{n}$ for $p \ge N$; then $\|x^{(p)} - y\| < \varepsilon$. $\blacksquare$

**Theorem 5.** $C[0,1]$ with the sup metric $d$ is complete.

*Proof.* Let $(f_n)$ be Cauchy. For each $t$, $|f_n(t) - f_m(t)| \le d(f_n,f_m)$, so $(f_n(t))$ is Cauchy in $\mathbb{R}$ and converges to a number $f(t)$. Given $\varepsilon > 0$ choose $N$ with $d(f_n,f_m) < \varepsilon$ for $m,n \ge N$. For fixed $t$ and $n \ge N$ let $m \to \infty$ in $|f_n(t) - f_m(t)| < \varepsilon$ to get $|f_n(t) - f(t)| \le \varepsilon$. So $\sup_t |f_n(t) - f(t)| \le \varepsilon$ for all $n \ge N$: the convergence is uniform. It remains to show $f$ is continuous. Fix $t_0$ and $\varepsilon > 0$, and take $n$ as above; $f_n$ is continuous, so there is $\delta > 0$ with $|f_n(t) - f_n(t_0)| < \varepsilon$ when $|t - t_0| < \delta$. Then $|f(t) - f(t_0)| \le |f(t) - f_n(t)| + |f_n(t) - f_n(t_0)| + |f_n(t_0) - f(t_0)| < 3\varepsilon$. So $f \in C[0,1]$ and $d(f_n, f) \le \varepsilon$ for $n \ge N$. $\blacksquare$

Completeness depends on the metric, not just the set. On $C[0,1]$ use instead $d_1(f,g) = \int_0^1 |f-g|$. Let $f_n(t) = 0$ for $t \le 1/2$, $f_n(t) = n(t - 1/2)$ for $1/2 \le t \le 1/2 + 1/n$, and $f_n(t) = 1$ after that. For $m > n$ the difference $f_m - f_n$ is nonnegative with $d_1(f_n,f_m) = \tfrac12\left(\tfrac1n - \tfrac1m\right) \to 0$, so $(f_n)$ is $d_1$-Cauchy. If $f_n \to g$ in $d_1$ with $g$ continuous, then $\int_0^{1/2} |g| \le \int_0^1 |g - f_n| \to 0$ forces $g = 0$ on $[0,1/2]$ by continuity, while for each $\delta > 0$ and $n > 1/\delta$ we get $\int_{1/2+\delta}^1 |g - 1| \le d_1(g,f_n) \to 0$, forcing $g = 1$ on $[1/2 + \delta, 1]$. Then $g(1/2) = 0$ but $g(1/2) = \lim_{\delta \to 0} g(1/2 + \delta) = 1$, a contradiction. So $(C[0,1], d_1)$ is not complete.

@example
title: A Cauchy sequence with no limit
problem: Let $X = \mathbb{N} = \{1,2,3,\dots\}$ with the metric $d(m,n) = |1/m - 1/n|$. Show that $X$ is a metric space that is not complete.
step: This is a metric: positivity and symmetry are clear, $d(m,n) = 0$ only if $1/m = 1/n$, that is $m = n$, and the triangle inequality is that of $|\cdot|$ applied to the numbers $1/m$.
step: Take $x_n = n$. For $m, n \ge N$ both $1/m$ and $1/n$ lie in $(0, 1/N]$, so $d(m,n) < 1/N$. Given $\varepsilon$ choose $N > 1/\varepsilon$: the sequence is Cauchy.
step: Suppose $x_n \to k \in \mathbb{N}$. Then $d(n,k) = |1/n - 1/k| \to 1/k > 0$ as $n \to \infty$, which is not $0$. So no limit exists in $X$.
answer: $(n)$ is Cauchy in $X$ but converges to no point of $X$, so $X$ is not complete.

@example
title: Cauchy plus a convergent subsequence
problem: Let $(x_n)$ be Cauchy in a metric space and suppose a subsequence $x_{n_k} \to x$. Prove that $x_n \to x$.
step: Fix $\varepsilon > 0$. Because $(x_n)$ is Cauchy, choose $N$ with $d(x_m, x_n) < \varepsilon/2$ for all $m,n \ge N$.
step: Because $x_{n_k} \to x$, choose $k$ with $n_k \ge N$ and $d(x_{n_k}, x) < \varepsilon/2$.
step: For any $n \ge N$ apply the triangle inequality with $m = n_k$: $d(x_n, x) \le d(x_n, x_{n_k}) + d(x_{n_k}, x) < \varepsilon/2 + \varepsilon/2 = \varepsilon$.
answer: $d(x_n,x) < \varepsilon$ for all $n \ge N$, so $x_n \to x$.

@mistakes
- Assuming Cauchy implies convergent: it is true in $\mathbb{R}^n$ and $C[0,1]$ (sup metric), false in $\mathbb{Q}$, in $(0,1)$ and in $(C[0,1], d_1)$.
- Calling a sequence Cauchy because consecutive differences tend to $0$: the partial sums $\sum_{k \le n} 1/k$ have $|s_{n+1} - s_n| \to 0$ but are unbounded, so not Cauchy.
- Treating completeness as a property of a set alone: $(0,\infty)$ is not complete with $|x-y|$ but is complete with the metric $|\log x - \log y|$.
- Forgetting that the limit must lie in the space: $x_n = 1/n$ converges in $\mathbb{R}$ but is not convergent in $(0,1]$.

model:
```python
def settle_index(a, eps):
    """Least N such that all entries from index N on lie within eps."""
    lo = hi = a[-1]
    best = len(a) - 1
    for i in range(len(a) - 2, -1, -1):
        lo = min(lo, a[i])
        hi = max(hi, a[i])
        if hi - lo < eps:
            best = i
        else:
            break
    return best
```
hint: All pairs in the tail are within eps exactly when the largest minus the smallest entry of the tail is less than eps.
hint: Grow the tail backward from the last index, keeping the running minimum and maximum, and stop at the first index where the spread reaches eps.
solution: Comparing consecutive terms is not enough (the list $0, 0.4, 0.8, 1.2$ has consecutive gaps $0.4$ but a spread of $1.2$). Extend the tail leftward while the spread $\max - \min$ of the tail stays below eps; the last index that keeps it below eps is the answer. Once the spread reaches eps, adding more terms on the left cannot reduce it.

@practice self
prompt: Let $X = (0,\infty)$ with the metric $d(x,y) = |\log x - \log y|$ (the natural logarithm). Check that $d$ is a metric, and prove that $(X,d)$ is complete.
hint: The map $\log\colon X \to \mathbb{R}$ is a bijection that preserves distances. Pull back a Cauchy sequence to $\mathbb{R}$, take the limit there, and push it forward with $\exp$.
solution: Positivity and symmetry are clear; $d(x,y) = 0$ gives $\log x = \log y$, so $x = y$ since $\log$ is injective; the triangle inequality is that of $|\cdot|$ applied to the numbers $\log x$, $\log y$, $\log z$. For completeness, let $(x_n)$ be $d$-Cauchy. Then $(\log x_n)$ is Cauchy in $\mathbb{R}$, because $|\log x_m - \log x_n| = d(x_m,x_n)$, so it converges to some $L \in \mathbb{R}$. Put $x = e^L \in X$. Then $d(x_n, x) = |\log x_n - L| \to 0$, so $x_n \to x$ in $X$. $\blacksquare$

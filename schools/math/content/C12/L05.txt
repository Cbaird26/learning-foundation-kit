@article
Let $f_n(x) = x^n$ on $[0,1]$. For each fixed $x \in [0,1)$, $x^n \to 0$, and for $x = 1$, $1^n = 1$. Every $f_n$ is continuous, yet the limit function $f$ ($=0$ on $[0,1)$, $=1$ at $1$) is not. Limits of continuous functions need not be continuous, if "limit" means the weak notion below. What stronger notion repairs this?

### Two kinds of convergence

Let $f_n, f\colon E \to \mathbb{R}$, where $E$ is a metric space or a set of reals. **Pointwise**: $f_n \to f$ if for each $x \in E$ and $\varepsilon > 0$ there is $N$ (which may depend on $x$) with $|f_n(x) - f(x)| < \varepsilon$ for $n \ge N$. **Uniform**: for every $\varepsilon > 0$ there is $N$ (independent of $x$) with $|f_n(x) - f(x)| < \varepsilon$ for all $x \in E$ and all $n \ge N$. Equivalently, $\sup_{x \in E} |f_n(x) - f(x)| \to 0$: uniform convergence is convergence in the sup metric. To test it, compute (or bound) $M_n = \sup_E |f_n - f|$ and ask whether $M_n \to 0$.

For $x^n$ on $[0,1)$ the limit is $0$ and $\sup_{[0,1)} x^n = 1$ for every $n$, so the convergence is not uniform. On $[0,a]$ with $a < 1$ it is uniform, because $\sup = a^n \to 0$.

### Basic theorems

**Theorem 1.** If $f_n \to f$ uniformly on $E$ and each $f_n$ is continuous, then $f$ is continuous.

*Proof.* Fix $p \in E$ and $\varepsilon > 0$. Choose $n$ with $\sup_E |f_n - f| < \varepsilon/3$. Since $f_n$ is continuous at $p$ there is $\delta > 0$ with $|f_n(x) - f_n(p)| < \varepsilon/3$ for $d(x,p) < \delta$. For such $x$, $|f(x) - f(p)| \le |f(x) - f_n(x)| + |f_n(x) - f_n(p)| + |f_n(p) - f(p)| < \varepsilon$. $\blacksquare$

The contrapositive explains the opening example: a pointwise limit of continuous functions that is discontinuous cannot be a uniform limit.

**Theorem 2 (uniform Cauchy criterion).** $(f_n)$ converges uniformly on $E$ to some function if and only if for every $\varepsilon > 0$ there is $N$ with $|f_m(x) - f_n(x)| < \varepsilon$ for all $x \in E$ and all $m,n \ge N$.

*Proof.* ($\Rightarrow$) Take $N$ with $|f_n - f| < \varepsilon/2$ on $E$ for $n \ge N$ and use the triangle inequality. ($\Leftarrow$) For each $x$, $(f_n(x))$ is Cauchy in $\mathbb{R}$, so it converges to some $f(x)$. Fix $\varepsilon$ and $N$ as in the hypothesis; letting $m \to \infty$ in $|f_m(x) - f_n(x)| < \varepsilon$ gives $|f(x) - f_n(x)| \le \varepsilon$ for all $x$ and $n \ge N$. $\blacksquare$

**Theorem 3 (Weierstrass M-test).** Let $|g_k(x)| \le M_k$ for all $x \in E$ with $\sum_k M_k < \infty$. Then $\sum_k g_k$ converges uniformly (and absolutely) on $E$.

*Proof.* For $n > m$, $\left|\sum_{k=m+1}^{n} g_k(x)\right| \le \sum_{k=m+1}^n M_k$, which is $< \varepsilon$ for $m,n \ge N$ because the tail of a convergent series of numbers tends to $0$. This is the uniform Cauchy criterion for the partial sums. $\blacksquare$

For example $\sum_{k \ge 1} \sin(kx)/k^2$ converges uniformly on $\mathbb{R}$ with $M_k = 1/k^2$, so its sum is a continuous function (Theorem 1). The M-test is sufficient, not necessary: $\sum \sin(kx)/k$ is not covered, and in fact its sum is the discontinuous sawtooth function on $(0,2\pi)$ extended periodically, so it does not converge uniformly on $\mathbb{R}$.

### Looking at a grid

Python can estimate $M_n$ on a grid of sample points:

```python
def sup_gap(f, limit, grid):
    """Largest |f(x) - limit(x)| over the grid points."""
    return max(abs(f(x) - limit(x)) for x in grid)


grid = [i / 100 for i in range(100)]  # 0, 0.01, ..., 0.99
for n in (10, 100, 1000):
    print(n, f"{sup_gap(lambda x: x ** n, lambda x: 0.0, grid):.3g}")
```

It prints about $0.904$, $0.366$ and $4.32 \times 10^{-5}$. The gaps seem to tend to $0$, but we know the true supremum over $[0,1)$ is $1$ for every $n$: the grid stops at $0.99$ and misses the points $x$ extremely close to $1$. A computation on a grid is evidence, not proof; it can suggest a conjecture or reveal that $M_n$ is not shrinking, but only a bound valid for all $x \in E$ proves uniform convergence.

@example
title: A uniformly convergent sequence on all of $\mathbb{R}$
problem: Show that $f_n(x) = \dfrac{x}{1 + n x^2}$ converges uniformly on $\mathbb{R}$, and find the limit.
step: Pointwise limit: for $x \ne 0$, $f_n(x) = x/(1 + nx^2) \to 0$ as $n \to \infty$, and $f_n(0) = 0$. So the limit is $f = 0$.
step: Bound the supremum without calculus. By the AM–GM inequality, $1 + nx^2 \ge 2\sqrt{n}\,|x|$ (since $(1 - \sqrt n |x|)^2 \ge 0$).
step: Hence $|f_n(x)| \le |x| / (2\sqrt n |x|) = 1/(2\sqrt n)$ for $x \ne 0$, and $f_n(0) = 0$. So $\sup_{\mathbb{R}} |f_n| \le 1/(2\sqrt n) \to 0$.
answer: $f_n \to 0$ uniformly on $\mathbb{R}$.

@example
title: Pointwise but not uniform, and the repair on smaller sets
problem: Let $g_n(x) = n x e^{-nx}$ on $[0,\infty)$. Show $g_n \to 0$ pointwise, but not uniformly on $[0,\infty)$; show it is uniform on $[a,\infty)$ for each $a > 0$.
step: Pointwise: $g_n(0) = 0$; for $x > 0$, $n x e^{-nx} \to 0$ because $e^{nx}$ grows faster than any multiple of $n$.
step: Not uniform: at $x_n = 1/n$ we have $g_n(1/n) = e^{-1}$. So $\sup_x |g_n(x)| \ge 1/e$ for every $n$, which does not tend to $0$.
step: On $[a,\infty)$: $g_n'(x) = n e^{-nx}(1 - nx)$ is negative for $x > 1/n$. For $n > 1/a$ the function $g_n$ is decreasing on $[a,\infty)$, so $\sup_{[a,\infty)} g_n = g_n(a) = n a e^{-na} \to 0$.
answer: $g_n \to 0$ pointwise on $[0,\infty)$, uniformly on each $[a,\infty)$ with $a>0$, but not uniformly on $[0,\infty)$.

@mistakes
- Checking convergence at each fixed $x$ and calling it uniform: the dependence of $N$ on $x$ is exactly what pointwise allows.
- Using a finite grid to "prove" uniform convergence: the bad points can sit between grid points, as with $x^n$ near $1$.
- Concluding that a series with $|g_k| \to 0$ pointwise converges uniformly: you need a summable bound $M_k$ valid for all $x$ (or another proof).
- Forgetting that the domain matters: $x^n$ converges uniformly on $[0,0.9]$ but not on $[0,1)$.

model:
```python
def first_n_below(fn, f, eps, grid, nmax):
    """Smallest n <= nmax whose grid sup-gap is below eps, else None."""
    for n in range(1, nmax + 1):
        gap = max(abs(fn(n, x) - f(x)) for x in grid)
        if gap < eps:
            return n
    return None
```
hint: For each $n$ compute the largest gap over the grid points and stop at the first $n$ whose gap is below eps.
solution: Loop over $n$ from $1$ to nmax, take the maximum over the grid of the absolute difference, and return the first $n$ that passes; return `None` after the loop. Note the grid answer $67$ for $x/(1+nx^2)$ is smaller than the true threshold $n \ge 70$ (where $1/(2\sqrt n) < 0.06$): the grid misses the peak at $x = 1/\sqrt n$, which is why a grid is only evidence.

@practice self
prompt: Suppose $f_n \to f$ and $g_n \to g$ uniformly on a set $E$, and all of $f, g, f_n, g_n$ are bounded on $E$. Prove that $f_n g_n \to fg$ uniformly on $E$. Then show that the boundedness hypothesis cannot simply be dropped, using $f_n = g_n = x + 1/n$ on $\mathbb{R}$.
hint: Write $f_n g_n - fg = f_n(g_n - g) + g(f_n - f)$ and bound each factor.
solution: Let $A = \sup_n \sup_E |f_n|$ and $B = \sup_E |g|$; $A$ is finite because a uniformly convergent sequence of bounded functions is uniformly bounded (choose $N$ with $\sup|f_n - f| < 1$ for $n \ge N$ and take the maximum of $\sup|f_1|, \dots, \sup|f_{N-1}|$ and $\sup|f| + 1$). Then $|f_n g_n - fg| \le |f_n||g_n - g| + |g||f_n - f| \le A \sup_E|g_n - g| + B \sup_E|f_n - f| \to 0$, uniformly in $x$. $\blacksquare$ Without boundedness: $f_n = g_n = x + 1/n$ converges uniformly to $x$ on $\mathbb{R}$ since $\sup|f_n - x| = 1/n$, but $f_n g_n - x^2 = 2x/n + 1/n^2$ has supremum $\infty$ for every $n$, so the products do not converge uniformly to $x^2$.
rubric: Splits $f_n g_n - fg$ into two terms, each containing one factor that tends to $0$ uniformly.

rubric: Gives the counterexample and computes that $\sup_{\mathbb{R}} |2x/n + 1/n^2| = \infty$.

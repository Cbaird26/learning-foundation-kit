@article
How many roots does $z^5 + 3z + 1$ have inside the unit circle? You could solve a quintic numerically, but there is a way to count roots *without finding them*, by integrating around the circle. The idea: the logarithmic derivative $f'/f$ has a simple pole with residue $m$ at every zero of $f$ of order $m$.

### Zeros, poles and the argument principle

A function is **meromorphic** on an open set $U$ if it is holomorphic on $U$ except at isolated poles. For $a \in U$ and $f \not\equiv 0$ near $a$, the **order** $\operatorname{ord}_a f$ is the integer $m$ with $f(z) = (z - a)^mg(z)$ near $a$, where $g$ is holomorphic and $g(a) \ne 0$: $m > 0$ at a zero of order $m$, $m < 0$ at a pole of order $-m$, and $m = 0$ at other points.

**Theorem 1 (argument principle).** Let $f$ be meromorphic on an open disk $D$ with finitely many zeros and poles $z_1, \dots, z_k$ in $D$, and let $\gamma$ be a closed contour in $D$ passing through none of them. Then
$$\frac{1}{2\pi i}\oint_\gamma\frac{f'(z)}{f(z)}\,dz = \sum_{j=1}^kn(\gamma, z_j)\operatorname{ord}_{z_j}f.$$
In particular, if $f$ is meromorphic on an open set containing $\overline{D}(a, r)$, has no zeros or poles on the circle $|z - a| = r$, and the circle is traversed counterclockwise, then $\frac{1}{2\pi i}\oint\frac{f'}{f}dz = Z - P$, where $Z$ and $P$ count the zeros and poles inside the circle with multiplicity.

*Proof.* Near $z_j$, write $f = (z - z_j)^mg$ with $m = \operatorname{ord}_{z_j}f$, $g$ holomorphic and nonzero near $z_j$. Then $\dfrac{f'}{f} = \dfrac{m}{z - z_j} + \dfrac{g'}{g}$ and $g'/g$ is holomorphic near $z_j$, so $f'/f$ has a simple pole at $z_j$ with residue $m$ (a removable point if $m = 0$). Away from the $z_j$, $f'/f$ is holomorphic. Apply the residue theorem (Lesson 9). For the circle: $f$ not identically zero and the zeros and poles have no accumulation point in $U$, so the compact disk contains finitely many, and a slightly larger disk $D$ contains the same ones. The winding number of the circle is $1$ about points inside and $0$ outside. $\blacksquare$

*Geometric meaning.* If $w = f(z)$ then $dw = f'(z)\,dz$, so $\frac{1}{2\pi i}\oint_\gamma\frac{f'}{f}dz = \frac{1}{2\pi i}\oint_{f\circ\gamma}\frac{dw}{w} = n(f\circ\gamma, 0)$: the number of times the image curve winds around $0$ equals $Z - P$.

### Rouché's theorem

**Theorem 2 (Rouché).** Let $f$ and $g$ be holomorphic on an open set containing $\overline{D}(a, r)$ and suppose $|g(z)| < |f(z)|$ for every $z$ on the circle $|z - a| = r$. Then $f$ and $f + g$ have the same number of zeros in $D(a, r)$, counted with multiplicity.

*Proof.* For $t \in [0, 1]$ put $f_t = f + tg$. On the circle $|f_t| \ge |f| - t|g| \ge |f| - |g| > 0$, so no $f_t$ has a zero there, and $f_t$ is not identically zero. Since $f_t$ is holomorphic, Theorem 1 says $N(t) = \dfrac{1}{2\pi i}\oint_{|z-a|=r}\dfrac{f'(z) + tg'(z)}{f(z) + tg(z)}dz$ is the number of zeros of $f_t$ in the disk, an integer. The integrand is a continuous function of $(z, t)$ on the compact set $\{|z - a| = r\}\times[0, 1]$ (the denominator is bounded away from $0$ there), hence uniformly continuous; so for $\varepsilon > 0$ there is $\delta > 0$ with $|N(t) - N(s)| \le \frac{1}{2\pi}\cdot 2\pi r\cdot\varepsilon$ when $|t - s| < \delta$, by the ML lemma. Thus $N$ is continuous, and a continuous integer-valued function on $[0, 1]$ is constant. Therefore $N(0) = N(1)$. $\blacksquare$

The strict inequality $|g| < |f|$ on the whole circle is essential: for $f = z$ and $g = -z$ the inequality is an equality, and $f + g \equiv 0$ has no finite number of zeros. A useful reading: if a dog on a leash of length $|g|$ walks around a tree at distance $|f|$, and $|g| < |f|$, the dog circles the tree as many times as the owner does.

### The fundamental theorem of algebra again

Let $p(z) = a_nz^n + \dots + a_0$ with $a_n \ne 0$, $n \ge 1$. Put $f = a_nz^n$ and $g = p - f$. For $|z| = R$ with $R$ large, $|g(z)| \le \sum_{k<n}|a_k|R^k < |a_n|R^n = |f(z)|$ (the left side is a polynomial of degree $\le n - 1$ in $R$). By Rouché's theorem $p$ has the same number of zeros in $|z| < R$ as $a_nz^n$, namely $n$ (counted with multiplicity). This is a second proof of the fundamental theorem of algebra, and it also shows that all $n$ zeros lie in $|z| < R$.

### Counting numerically

The winding number of the image curve gives a numerical check. This snippet samples a polynomial on a circle and verifies that it does not vanish there:

```python
import math


def circle_values(coeffs, r, n):
    """Values of the polynomial (highest power first) at n points of |z|=r."""
    values = []
    for j in range(n):
        z = r * complex(math.cos(2 * math.pi * j / n),
                        math.sin(2 * math.pi * j / n))
        p = 0
        for c in coeffs:
            p = p * z + c
        values.append(p)
    return values


vals = circle_values([1, 0, 0, 0, 3, 1], 1, 200)
print(min(abs(v) for v in vals) >= 1)
```

It prints `True`: on $|z| = 1$, $|z^5 + 3z + 1| \ge 3 - 2 = 1$, in agreement with the Rouché comparison used below. Sampling shows the claim at 200 points only; the inequality $|3z| > |z^5 + 1|$ proves it everywhere.

@example
title: Zeros of a quintic in a disk and in an annulus
problem: How many zeros (with multiplicity) does $p(z) = z^5 + 3z + 1$ have in $|z| < 1$, in $|z| < 2$, and in the annulus $1 < |z| < 2$?
step: In $|z| < 1$ take $f(z) = 3z$ and $g(z) = z^5 + 1$. On $|z| = 1$: $|g| \le |z|^5 + 1 = 2 < 3 = |f|$. By Rouché, $p = f + g$ has as many zeros in $|z| < 1$ as $3z$, namely $1$.
step: In $|z| < 2$ take $f(z) = z^5$ and $g(z) = 3z + 1$. On $|z| = 2$: $|g| \le 3\cdot 2 + 1 = 7 < 32 = |f|$. So $p$ has $5$ zeros in $|z| < 2$.
step: No zero lies on $|z| = 1$ or $|z| = 2$: the inequalities above show $|p| \ge |f| - |g| > 0$ on both circles.
step: The annulus therefore contains $5 - 1 = 4$ zeros.
answer: $1$ zero in $|z| < 1$, $5$ in $|z| < 2$, and $4$ in $1 < |z| < 2$.

@example
title: Solutions of a transcendental equation
problem: How many solutions does $e^z = 4z^3$ have in the unit disk $|z| < 1$?
step: The solutions are the zeros of $4z^3 - e^z$. Set $f(z) = 4z^3$ and $g(z) = -e^z$; both are entire.
step: On $|z| = 1$: $|f| = 4$, and $|g(z)| = e^{\operatorname{Re} z} \le e^1 < 2.72 < 4$.
step: The strict inequality $|g| < |f|$ holds on the whole circle, so Rouché applies: $f + g$ and $f = 4z^3$ have the same number of zeros in $|z| < 1$.
step: $4z^3$ has a zero of order $3$ at $0$ and no others, so the equation has exactly $3$ solutions in the unit disk, counted with multiplicity.
answer: $3$ solutions.

@mistakes
- Using $|g| \le |f|$ instead of the strict inequality, or checking the inequality at a few points instead of on the whole circle.
- Choosing the dominant term $f$ wrongly: you must compare the *whole* remaining part $g$ with $f$ on the circle; changing the circle changes which term dominates, as with $z^5$ and $3z$ above.
- Forgetting that the argument principle counts $Z - P$ with multiplicity and with sign: poles inside subtract.
- Treating Rouché's theorem as locating the zeros: it counts them in a disk (or, by differencing, an annulus) but does not say where they are.

model:
```python
import math


def zeros_in_disk(coeffs, r, n=400):
    """Number of zeros of a polynomial in |z| < r by the argument principle."""
    values = []
    for j in range(n):
        z = r * complex(math.cos(2 * math.pi * j / n),
                        math.sin(2 * math.pi * j / n))
        p = 0
        for c in coeffs:
            p = p * z + c
        values.append(p)
    total = 0.0
    for j in range(n):
        u = values[j]
        v = values[(j + 1) % n]
        cross = u.real * v.imag - u.imag * v.real
        dot = u.real * v.real + u.imag * v.imag
        total += math.atan2(cross, dot)
    return round(total / (2 * math.pi))
```
hint: Evaluate $p$ with Horner's rule at each sample point; `values[(j + 1) % n]` is the next value, wrapping around at the end.
hint: Do not subtract the principal arguments of consecutive values: they jump by $2\pi$ across the negative real axis.
solution: The image curve $p(re^{it})$ winds around $0$ exactly $Z$ times, where $Z$ is the number of zeros inside (there are no poles). Summing the signed angle between consecutive samples (each in $(-\pi, \pi)$) and dividing by $2\pi$ approximates that winding number, and rounding recovers the integer. A triple root at $0$ gives $3$; a constant gives total angle $0$. The result is numerical evidence: Rouché's theorem proves the counts for the first examples, while the code could be fooled if too few samples are used.

@article
What should $e^{i\pi}$ mean? Repeated multiplication does not make sense for an imaginary exponent. The way out is to define the exponential by its power series and then read off what it does. The same series idea answers a second puzzle: no continuous function $L$ on $\mathbb{C}\setminus\{0\}$ satisfies $e^{L(z)} = z$, so the logarithm needs "branches".

### Power series

A **power series** centered at $a$ is $\sum_{n \ge 0} a_n(z - a)^n$.

**Lemma (Abel).** If $\sum a_n z_0^n$ converges, then $\sum a_n z^n$ converges absolutely for every $|z| < |z_0|$.

*Proof.* Convergent series have terms tending to $0$, so $|a_nz_0^n| \le M$ for all $n$. For $|z| < |z_0|$ put $q = |z/z_0| < 1$. Then $|a_nz^n| = |a_nz_0^n|q^n \le Mq^n$, and $\sum Mq^n$ converges. $\blacksquare$

**Theorem 1 (radius of convergence).** For each power series $\sum a_n(z - a)^n$ there is a unique $R \in [0, \infty]$, the **radius of convergence**, such that the series converges absolutely when $|z - a| < R$ and diverges when $|z - a| > R$. If $\lim |a_n/a_{n+1}|$ exists (in $[0, \infty]$) it equals $R$; in general $R = 1/\limsup |a_n|^{1/n}$ (the Cauchy–Hadamard formula, stated here without proof; it is the root test from real analysis).

*Proof of existence.* Let $R$ be the supremum of $|z - a|$ over all $z$ at which the series converges. If $|z - a| < R$, there is $z_0$ with $|z_0 - a| > |z - a|$ at which the series converges, and Abel's lemma gives absolute convergence at $z$. If $|z - a| > R$, the series diverges by the definition of the supremum. $\blacksquare$

On the circle $|z - a| = R$ anything can happen. **Theorem 2** (stated without proof; it is an estimate with the binomial theorem): inside its disk of convergence a power series defines a holomorphic function, and its derivative is the series $\sum na_n(z - a)^{n-1}$ with the same radius.

For example, $\sum \dfrac{(n!)^2}{(2n)!}z^n$ has $a_n/a_{n+1} = \dfrac{(2n+1)(2n+2)}{(n+1)^2} \to 4$, so $R = 4$.

### The exponential function

Define $\exp(z) = e^z = \sum_{n \ge 0} z^n/n!$. The ratio $a_n/a_{n+1} = n + 1 \to \infty$, so $R = \infty$: $\exp$ is entire, and $\exp' = \exp$ by Theorem 2.

**Theorem 3.** (a) $e^{z+w} = e^ze^w$. (b) For real $y$, $e^{iy} = \cos y + i\sin y$, where $\cos$ and $\sin$ are given by their real power series. (c) $e^{x+iy} = e^x(\cos y + i\sin y)$; in particular $|e^z| = e^{\operatorname{Re} z}$ and $e^z \ne 0$. (d) $e^z = 1$ if and only if $z \in 2\pi i\mathbb{Z}$, and $e^z = e^w$ if and only if $z - w \in 2\pi i\mathbb{Z}$.

*Proof.* (a) Both series converge absolutely, so their Cauchy product converges to the product (a theorem from real analysis): $e^ze^w = \sum_n \sum_{k=0}^n \dfrac{z^k}{k!}\dfrac{w^{n-k}}{(n-k)!} = \sum_n \dfrac{(z + w)^n}{n!}$ by the binomial theorem. (b) Since $i^{2m} = (-1)^m$ and $i^{2m+1} = i(-1)^m$, splitting the series of $e^{iy}$ into even and odd terms gives $\sum (-1)^my^{2m}/(2m)! + i\sum(-1)^my^{2m+1}/(2m+1)! = \cos y + i\sin y$. (c) Combine (a) and (b). Then $|e^z| = e^x\sqrt{\cos^2y + \sin^2y} = e^x > 0$. (d) By (c), $e^z = 1$ forces $e^x = 1$, so $x = 0$, and $\cos y = 1$, $\sin y = 0$, so $y \in 2\pi\mathbb{Z}$. Conversely such $z$ give $1$. For the second claim use $e^z = e^w \iff e^{z-w} = 1$, which follows from (a). $\blacksquare$

Taking $y = \pi$ answers the first puzzle: $e^{i\pi} = -1$. Also, $e^z$ is $2\pi i$-periodic and maps each horizontal strip $\{a \le \operatorname{Im} z < a + 2\pi\}$ one-to-one onto $\mathbb{C}\setminus\{0\}$: given $w = \rho e^{i\varphi} \ne 0$, the solutions of $e^z = w$ are $z = \ln\rho + i(\varphi + 2\pi k)$.

### Logarithms and branches

For $z \ne 0$ the equation $e^w = z$ therefore has the infinitely many solutions $w = \ln|z| + i(\arg z + 2\pi k)$. They are the values of the multivalued $\log z$. The **principal logarithm** is $\operatorname{Log} z = \ln|z| + i\operatorname{Arg} z$ with $\operatorname{Arg} z \in (-\pi, \pi]$. A **branch** of the logarithm on a domain $D \not\ni 0$ is a continuous $L\colon D \to \mathbb{C}$ with $e^{L(z)} = z$ for all $z \in D$. For instance, $\operatorname{Arg} z = 2\arctan\dfrac{\operatorname{Im} z}{\operatorname{Re} z + |z|}$ on $\mathbb{C}\setminus(-\infty, 0]$ is continuous there (the denominator is positive), so $\operatorname{Log}$ is a branch on the slit plane $\mathbb{C}\setminus(-\infty, 0]$.

**Theorem 4.** A branch $L$ of the logarithm on $D$ is holomorphic, with $L'(z) = 1/z$.

*Proof.* Fix $z \in D$ and $h \ne 0$ small with $z + h \in D$. Put $w = L(z)$ and $w' = L(z + h)$. By continuity $w' \to w$ as $h \to 0$, and $w' \ne w$ because $e^{w'} = z + h \ne z = e^w$. Then $\dfrac{L(z+h) - L(z)}{h} = \dfrac{w' - w}{e^{w'} - e^w} \to \dfrac{1}{(e^w)'} = \dfrac{1}{e^w} = \dfrac1z$, since $(e^w)'$ is the derivative of $\exp$ at $w$. $\blacksquare$

**Theorem 5.** No continuous function $L$ on the unit circle $\{|z| = 1\}$ satisfies $e^{L(z)} = z$. In particular no branch exists on $\mathbb{C}\setminus\{0\}$, or on any domain containing the unit circle.

*Proof.* Suppose $L$ exists and put $g(t) = L(e^{it}) - it$ for $t \in [0, 2\pi]$. Then $e^{g(t)} = e^{L(e^{it})}e^{-it} = 1$, so $g(t) \in 2\pi i\mathbb{Z}$ by Theorem 3(d); $g$ is continuous with values in a discrete set, so it is constant. But $g(2\pi) - g(0) = L(1) - 2\pi i - L(1) = -2\pi i \ne 0$. $\blacksquare$

Powers are defined through $\log$: $z^a = e^{a\log z}$. For $a = i$ and $z = i$: $i^i = e^{i(i\pi/2 + 2\pi ik)} = e^{-\pi/2 - 2\pi k}$, infinitely many real values.

```python
import math


def exp_partial(z, n_terms):
    """Sum of the first n_terms terms of the exponential series."""
    total, term = 0, 1
    for n in range(n_terms):
        total += term
        term = term * z / (n + 1)
    return total


print(abs(exp_partial(1j * math.pi, 25) + 1) < 1e-12)
```

This prints `True`: the 25-term partial sum of $\sum (i\pi)^n/n!$ is within $10^{-12}$ of $-1$. It is a numerical check of $e^{i\pi} = -1$, not a proof.

@example
title: Solving $e^z = w$
problem: Find all $z \in \mathbb{C}$ with $e^z = 1 + i\sqrt{3}$.
step: Write the right side in polar form: $1 + i\sqrt{3} = 2e^{i\pi/3}$, so $\rho = 2$ and $\varphi = \pi/3$.
step: Write $z = x + iy$. By Theorem 3(c), $e^z = e^x(\cos y + i\sin y)$, so we need $e^x = 2$ and $y \equiv \pi/3 \pmod{2\pi}$.
step: Hence $x = \ln 2$ and $y = \pi/3 + 2\pi k$ for an integer $k$.
step: Check $k = 0$: $e^{\ln 2 + i\pi/3} = 2(\cos\tfrac{\pi}{3} + i\sin\tfrac{\pi}{3}) = 1 + i\sqrt{3}$.
answer: $z = \ln 2 + i(\pi/3 + 2\pi k)$ for $k \in \mathbb{Z}$.

@example
title: Choosing a branch
problem: Let $D = \mathbb{C}$ with the closed negative imaginary axis $\{-it : t \ge 0\}$ removed. Define the branch $L$ of $\log$ on $D$ whose imaginary part lies in $(-\pi/2, 3\pi/2)$, and compute $L(1 - i)$ and $L(-2)$.
step: Every $z \in D$ has exactly one argument $\theta \in (-\pi/2, 3\pi/2)$, because the excluded direction $-\pi/2 \equiv 3\pi/2$ is the removed ray. Define $L(z) = \ln|z| + i\theta$. It is continuous on $D$ (it is a branch), and $e^{L(z)} = |z|e^{i\theta} = z$.
step: For $z = 1 - i$: $|z| = \sqrt{2}$ and the argument $-\pi/4$ lies in $(-\pi/2, 3\pi/2)$, so $L(1 - i) = \tfrac12\ln 2 - i\pi/4$.
step: For $z = -2$: $|z| = 2$ and the argument $\pi$ lies in the interval, so $L(-2) = \ln 2 + i\pi$.
step: Compare with $\operatorname{Log}$: the two agree on points with argument in $(-\pi/2, \pi]$, but they differ by $2\pi i$ at points such as $-1 - i$, where $\operatorname{Log}$ has argument $-3\pi/4$ and $L$ has $5\pi/4$.
answer: $L(1 - i) = \tfrac12\ln 2 - i\pi/4$ and $L(-2) = \ln 2 + i\pi$.

@mistakes
- Claiming $\operatorname{Log}(z_1z_2) = \operatorname{Log} z_1 + \operatorname{Log} z_2$ always. It holds only up to a multiple of $2\pi i$: take $z_1 = z_2 = -1 + i\sqrt{3}$, whose principal arguments add to $4\pi/3$.
- Treating $e^z$ as one-to-one. It is $2\pi i$-periodic, so $e^z = w$ has infinitely many solutions.
- Using the ratio test where $a_n$ is zero for infinitely many $n$ (for example $\sum z^{2n}/3^n$ has $a_n = 0$ for odd exponents). Substitute $w = z^2$ or use the root-test formula.
- Saying a series converges "on its circle of convergence" because it converges inside: Theorem 1 says nothing about $|z - a| = R$.

```python
import math


def terms_needed(z, tol):
    """Least N with |S_N - e^z| < tol for the exponential series."""
    target = math.exp(z.real) * complex(math.cos(z.imag), math.sin(z.imag))
    total, term, n_terms = 0, 1, 0
    while True:
        total += term
        n_terms += 1
        if abs(total - target) < tol:
            return n_terms
        term = term * z / n_terms
```
hint: Keep a running sum and the current term; after adding each term, test the error before computing the next term.
hint: Count the terms added so far; the first partial sum $S_1$ is just the constant term $1$.
solution: Add the terms one by one and stop the first time the error is below `tol`, returning the number of terms added. Checking the error before adding the next term, and counting from $1$ rather than $0$, avoids the off-by-one errors the tests probe (for $z = 0$ the answer is $1$, not $0$). The loop terminates because the series converges to $e^z$.

Take $f(z) = z^2$ and apply it to the vertical line $\operatorname{Re} z = 1$, the points $1 + iy$. Then $f(1 + iy) = 1 - y^2 + 2iy$, so the image points $u + iv$ satisfy $v = 2y$ and $u = 1 - y^2 = 1 - v^2/4$: the line is bent into a parabola. A function of one complex variable cannot be graphed (the graph lives in $\mathbb{R}^4$), so we study it as a **map** from one picture of the plane to another. This lesson sets up that language and the limits behind it.

### Functions, real and imaginary parts

A **function** $f\colon S \to \mathbb{C}$ with $S \subseteq \mathbb{C}$ assigns a complex number to each $z \in S$. Writing $z = x + iy$ and $f(z) = u(x, y) + iv(x, y)$ turns $f$ into two real functions of two real variables, the **real part** $u$ and the **imaginary part** $v$. For $f(z) = z^2$ we get $u = x^2 - y^2$ and $v = 2xy$. In polar form $z = re^{i\theta}$ the same map is $re^{i\theta} \mapsto r^2e^{2i\theta}$: it squares the modulus and doubles the argument.

The **open disk** $D(a, r) = \{z : |z - a| < r\}$. A set $U$ is **open** if every point of $U$ has a disk around it inside $U$. A **domain** (or region) is a nonempty open set that is connected, meaning any two of its points can be joined by a polygonal path inside it.

### Limits and continuity

**Definition.** Let $f$ be defined on a set containing a punctured disk $\{0 < |z - z_0| < \rho\}$. Then $\lim_{z \to z_0} f(z) = L$ means: for every $\varepsilon > 0$ there is $\delta > 0$ such that $0 < |z - z_0| < \delta$ implies $|f(z) - L| < \varepsilon$. The function $f$ is **continuous at $z_0$** if $z_0$ is in its domain and $\lim_{z \to z_0} f(z) = f(z_0)$.

The definition is the one from real analysis with absolute value replaced by modulus, but the neighborhoods are disks in the plane: $z$ may approach $z_0$ from every direction, so the limit must be the same along every path.

**Theorem 1.** Let $f = u + iv$ and $L = a + ib$. Then $\lim_{z \to z_0} f(z) = L$ if and only if $\lim_{(x,y) \to (x_0, y_0)} u = a$ and $\lim_{(x,y) \to (x_0, y_0)} v = b$.

*Proof.* For any complex number $\zeta = s + it$ we have $|s| \le |\zeta|$, $|t| \le |\zeta|$ and $|\zeta| \le |s| + |t|$. Apply this to $\zeta = f(z) - L$, with $s = u - a$ and $t = v - b$. If $f \to L$ and $\varepsilon > 0$, choose $\delta$ for $\varepsilon$; then $|u - a| \le |f(z) - L| < \varepsilon$, and likewise for $v$. Conversely, given $\varepsilon$, choose $\delta$ so small that $|u - a| < \varepsilon/2$ and $|v - b| < \varepsilon/2$ for $0 < |z - z_0| < \delta$ (take the smaller of the two $\delta$s). Then $|f(z) - L| \le |u - a| + |v - b| < \varepsilon$. $\blacksquare$

The sum, product and quotient rules for limits hold, with the same proofs as in $\mathbb{R}$ (using the triangle inequality of Lesson 1). Hence polynomials are continuous on $\mathbb{C}$, rational functions are continuous where the denominator is nonzero, and $z \mapsto \overline{z}$, $\operatorname{Re}$, $\operatorname{Im}$ and $|z|$ are continuous. Compositions of continuous functions are continuous.

**A limit that does not exist.** Let $f(z) = z/\overline{z}$ for $z \ne 0$. Along the real axis, $z = t$, $f = 1$. Along the imaginary axis, $z = it$, $f = it/(-it) = -1$. Two paths give two values, so $\lim_{z \to 0} f(z)$ does not exist. In general $f(re^{i\theta}) = e^{2i\theta}$ depends on the direction. The same idea can be tried in code:

```python
import math


def along_ray(f, theta, r):
    """Value of f at the point at distance r from 0 in direction theta."""
    return f(r * complex(math.cos(theta), math.sin(theta)))


def f(z):
    return z / z.conjugate()


for theta in [0, math.pi / 2]:
    print(round(along_ray(f, theta, 1e-6).real, 6))
```

This prints `1.0` and `-1.0`, which proves nothing about the limit by itself; the algebra above does. (Different rays agreeing would not prove a limit exists either.)

### Mapping regions

**Squaring.** In polar coordinates, the sector $\{r_1 < |z| < r_2,\ \alpha < \arg z < \beta\}$ with $0 < \beta - \alpha \le \pi$ maps onto $\{r_1^2 < |w| < r_2^2,\ 2\alpha < \arg w < 2\beta\}$. The first quadrant becomes the upper half-plane.

**Translation and rotation-dilation.** $z \mapsto az + b$ with $a \ne 0$ rotates by $\arg a$, scales by $|a|$ and shifts by $b$. It maps circles to circles and lines to lines.

**Inversion.**

**Theorem 2.** Let $w = 1/z$ for $z \ne 0$. (a) The circle $|z| = r$ is mapped onto the circle $|w| = 1/r$. (b) For $c \ne 0$ real, the line $\operatorname{Re} z = c$ is mapped onto the circle $|w - \tfrac{1}{2c}| = \tfrac{1}{2|c|}$ with the point $w = 0$ removed.

*Proof.* (a) $|w| = 1/|z|$. (b) Put $w = u + iv \ne 0$, so $z = 1/w = (u - iv)/(u^2 + v^2)$. Then $\operatorname{Re} z = c$ if and only if $u = c(u^2 + v^2)$, which (dividing by $c$ and completing the square) is $(u - \tfrac{1}{2c})^2 + v^2 = \tfrac{1}{4c^2}$. Every $w \ne 0$ on this circle comes from $z = 1/w$ on the line, and $w = 0$ is never an image. $\blacksquare$

@example
title: The image of a sector under $z^2$
problem: Describe the image of $R = \{z : 1 < |z| < 2,\ 0 < \arg z < \pi/4\}$ under $w = z^2$, and decide whether the map is one-to-one on $R$.
step: Write $z = re^{i\theta}$ with $1 < r < 2$ and $0 < \theta < \pi/4$. Then $z^2 = r^2e^{2i\theta}$.
step: The modulus $\rho = r^2$ ranges over $1 < \rho < 4$, and the argument $2\theta$ ranges over $0 < 2\theta < \pi/2$.
step: Every pair $(\rho, \varphi)$ with $1 < \rho < 4$ and $0 < \varphi < \pi/2$ comes from $r = \sqrt{\rho}$ and $\theta = \varphi/2$, so the image is the whole region $\{1 < |w| < 4,\ 0 < \arg w < \pi/2\}$.
step: Injective: if $z_1^2 = z_2^2$ then $z_1 = \pm z_2$; but $-z_2$ has argument in $(\pi, 5\pi/4)$, outside $R$. So $z_1 = z_2$.
answer: The image is the quarter annulus $\{1 < |w| < 4,\ 0 < \arg w < \pi/2\}$, and the map is one-to-one on $R$.

@example
title: A line under inversion
problem: Find the image of the horizontal line $\operatorname{Im} z = 2$ under $w = 1/z$.
step: A point of the line is $z = x + 2i$ with $x$ real, so $w = \dfrac{x - 2i}{x^2 + 4}$, that is, $u = \dfrac{x}{x^2 + 4}$ and $v = \dfrac{-2}{x^2 + 4}$.
step: Compute $u^2 + v^2 = \dfrac{x^2 + 4}{(x^2 + 4)^2} = \dfrac{1}{x^2 + 4} = -\dfrac{v}{2}$.
step: Rearrange and complete the square: $u^2 + v^2 + \tfrac{v}{2} = 0$, so $u^2 + (v + \tfrac14)^2 = \tfrac{1}{16}$.
step: Conversely, if $w \ne 0$ satisfies this equation then $z = 1/w$ has $\operatorname{Im} z = -v/(u^2 + v^2) = 2$. The point $w = 0$ lies on the circle but is not an image (it would need $|z| = \infty$).
answer: The circle with center $-i/4$ and radius $1/4$, with the point $0$ removed.

@mistakes
- Deciding that a limit exists after testing only the real and imaginary axes. $f(z) = \operatorname{Re}z\operatorname{Im}z/|z|^2$ is $0$ on both axes but equals $1/2$ along $y = x$, so its limit at $0$ does not exist.
- Doubling the angle without halving the sector: $z \mapsto z^2$ maps a sector of opening greater than $\pi$ onto a region that overlaps itself, so the map is no longer one-to-one.
- Saying $1/z$ maps lines to lines. A line not through $0$ goes to a circle through $0$ (with $0$ removed); only lines through $0$ go to lines.
- Forgetting the punctured neighborhood in a limit: the value $f(z_0)$ itself plays no role in $\lim_{z \to z_0} f(z)$.

model:
```python
import math


def rays_agree(f, angles, tol):
    """True if f takes nearly the same value along every listed ray."""
    r = 1e-6
    values = [f(r * complex(math.cos(t), math.sin(t))) for t in angles]
    return all(abs(a - b) <= tol for a in values for b in values)
```
hint: Build the list of values `f(r * complex(cos t, sin t))`, one for each angle.
hint: Compare every pair of values, not only the first value with the others.
solution: Evaluate $f$ on each ray at the tiny radius and compare all pairs. The function $g = xy/|z|^2$ is $0$ on both axes, so the two-angle test returns `True` although its limit at $0$ does not exist; adding the angle $\pi/4$ exposes the disagreement. A single ray (one value) always agrees with itself.

@practice self
prompt: Prove from the $\varepsilon$–$\delta$ definition that $f(z) = z^2$ is continuous at every point $z_0 \in \mathbb{C}$.
hint: Factor $z^2 - z_0^2 = (z - z_0)(z + z_0)$ and bound $|z + z_0|$ when $|z - z_0| < 1$.
hint: If $|z - z_0| < 1$ then $|z + z_0| \le |z - z_0| + 2|z_0| < 2|z_0| + 1$.
solution: Let $z_0 \in \mathbb{C}$ and $\varepsilon > 0$. Put $\delta = \min\{1,\ \varepsilon/(2|z_0| + 1)\}$. If $|z - z_0| < \delta$, then $|z + z_0| = |(z - z_0) + 2z_0| \le |z - z_0| + 2|z_0| < 1 + 2|z_0|$, so $|z^2 - z_0^2| = |z - z_0||z + z_0| < \dfrac{\varepsilon}{2|z_0| + 1}(2|z_0| + 1) = \varepsilon$. Thus $\lim_{z \to z_0} z^2 = z_0^2$. $\blacksquare$
rubric: Factors the difference and bounds the second factor using $|z - z_0| < 1$.
rubric: Chooses $\delta$ as a minimum that depends on $z_0$ and $\varepsilon$.
rubric: Verifies $|f(z) - f(z_0)| < \varepsilon$ and concludes continuity at an arbitrary point.

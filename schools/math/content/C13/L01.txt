In the 1500s Cardano's formula for the equation $x^3 = 15x + 4$ gave the root $x = \sqrt[3]{2 + 11i} + \sqrt[3]{2 - 11i}$, with $i^2 = -1$. The equation obviously has the real root $x = 4$. The resolution: $(2 + i)^3 = 8 + 12i - 6 - i = 2 + 11i$, so the two cube roots are $2 + i$ and $2 - i$, and their sum is $4$. Computing with a "number" whose square is $-1$ gave a correct real answer. This course studies calculus with such numbers, and it turns out to be far more rigid and far more powerful than real calculus.

### The field of complex numbers

**Definition.** $\mathbb{C}$ is the set $\mathbb{R}^2$ with addition $(a, b) + (c, d) = (a + c, b + d)$ and multiplication $(a, b)(c, d) = (ac - bd, ad + bc)$. Write $a + bi$ for $(a, b)$, so $i = (0, 1)$ and $i^2 = (-1, 0) = -1$. For $z = a + bi$ put $\operatorname{Re} z = a$, $\operatorname{Im} z = b$, the **conjugate** $\overline{z} = a - bi$ and the **modulus** $|z| = \sqrt{a^2 + b^2}$.

With these operations $\mathbb{C}$ is a field: a nonzero $z$ has the inverse $1/z = \overline{z}/|z|^2$, because $z\overline{z} = a^2 + b^2 = |z|^2$. Real numbers are the points $(a, 0)$. Conjugation respects the operations: $\overline{z + w} = \overline{z} + \overline{w}$ and $\overline{zw} = \overline{z}\,\overline{w}$.

**Theorem 1.** For all $z, w \in \mathbb{C}$: (a) $|zw| = |z||w|$; (b) $|z + w| \le |z| + |w|$ (the triangle inequality); (c) $|z| - |w| \le |z + w|$.

*Proof.* (a) $|zw|^2 = (zw)\overline{zw} = z\overline{z}\,w\overline{w} = |z|^2|w|^2$, and moduli are nonnegative. (b) Expand $|z + w|^2 = (z + w)(\overline{z} + \overline{w}) = |z|^2 + 2\operatorname{Re}(z\overline{w}) + |w|^2$. For any $\zeta \in \mathbb{C}$, $\operatorname{Re}\zeta \le |\zeta|$, and by (a) $|z\overline{w}| = |z||w|$. So $|z + w|^2 \le |z|^2 + 2|z||w| + |w|^2 = (|z| + |w|)^2$; take square roots. (c) By (b), $|z| = |(z + w) + (-w)| \le |z + w| + |w|$. $\blacksquare$

### Polar form and roots

Every $z \ne 0$ can be written $z = r(\cos\theta + i\sin\theta)$ with $r = |z|$ and an **argument** $\theta$, determined up to adding multiples of $2\pi$. Write $e^{i\theta}$ for $\cos\theta + i\sin\theta$ (Lesson 4 shows this is the exponential function). The angle-addition formulas give $e^{i\theta}e^{i\varphi} = e^{i(\theta + \varphi)}$: multiplying multiplies moduli and adds arguments. Hence **de Moivre's formula** $(e^{i\theta})^n = e^{in\theta}$.

**Theorem 2 (roots).** Let $w = \rho e^{i\varphi}$ with $\rho > 0$ and let $n \ge 1$. The equation $z^n = w$ has exactly $n$ solutions, $z_k = \rho^{1/n}e^{i(\varphi + 2\pi k)/n}$ for $k = 0, 1, \dots, n - 1$.

*Proof.* Write a solution as $z = re^{i\theta}$ with $r > 0$. Then $z^n = r^n e^{in\theta} = \rho e^{i\varphi}$ holds if and only if $r^n = \rho$ and $n\theta - \varphi$ is a multiple of $2\pi$. So $r = \rho^{1/n}$ and $\theta = (\varphi + 2\pi k)/n$ for an integer $k$. Two integers $k, k'$ give the same point if and only if $2\pi(k - k')/n$ is a multiple of $2\pi$, that is, if and only if $n \mid k - k'$. So $k = 0, \dots, n - 1$ gives each solution exactly once. $\blacksquare$

The case $w = 1$ gives the **$n$-th roots of unity**, the vertices of a regular $n$-gon inscribed in the unit circle.

```python
import math


def roots_of_unity(n):
    """The n-th roots of unity, starting at 1, counterclockwise."""
    return [complex(math.cos(2 * math.pi * k / n),
                    math.sin(2 * math.pi * k / n)) for k in range(n)]


print([round(abs(z ** 5 - 1), 9) for z in roots_of_unity(5)])
```

This prints a list of zeros: five numerical checks, which illustrate Theorem 2 but do not replace its proof.

### The Riemann sphere

Let $S = \{(X, Y, Z) : X^2 + Y^2 + Z^2 = 1\}$ and $N = (0, 0, 1)$. Identify $\mathbb{C}$ with the plane $Z = 0$. The line from $N$ through $z = x + iy$ meets $S$ in one further point. The line is $N + t\big((x, y, 0) - N\big) = (tx, ty, 1 - t)$; putting this on $S$ gives $t^2(|z|^2 + 1) - 2t = 0$, so $t = 2/(|z|^2 + 1)$ (the root $t = 0$ is $N$). This is **stereographic projection**:
$$z \longmapsto \left(\frac{2x}{|z|^2 + 1},\ \frac{2y}{|z|^2 + 1},\ \frac{|z|^2 - 1}{|z|^2 + 1}\right).$$
It is a bijection from $\mathbb{C}$ onto $S \setminus \{N\}$, with inverse $(X, Y, Z) \mapsto (X + iY)/(1 - Z)$. The point $0$ goes to the south pole $(0, 0, -1)$, the unit circle to the equator $Z = 0$, the disk $|z| < 1$ to the southern hemisphere, and $|z|$ large to points near $N$. Adjoining one point $\infty$ with $\infty \leftrightarrow N$ gives the **Riemann sphere** $\widehat{\mathbb{C}} = \mathbb{C} \cup \{\infty\}$. A fact we use without proof here: circles on $S$ correspond to circles or lines in the plane, which is why lines and circles will behave alike in Lesson 12.

@example
title: All solutions of an equation $z^3 = -8$
problem: Find all complex numbers $z$ with $z^3 = -8$ and plot their positions.
step: Write the right side in polar form: $-8 = 8e^{i\pi}$, so $\rho = 8$ and $\varphi = \pi$.
step: Apply Theorem 2 with $n = 3$: $z_k = 8^{1/3}e^{i(\pi + 2\pi k)/3} = 2e^{i(\pi + 2\pi k)/3}$ for $k = 0, 1, 2$.
step: Compute: $z_0 = 2e^{i\pi/3} = 1 + i\sqrt{3}$, $z_1 = 2e^{i\pi} = -2$, $z_2 = 2e^{i5\pi/3} = 1 - i\sqrt{3}$.
step: Check one root: $(1 + i\sqrt{3})^2 = 1 - 3 + 2i\sqrt{3} = -2 + 2i\sqrt{3}$, and multiplying by $1 + i\sqrt{3}$ gives $-2 - 6 + (2\sqrt{3} - 2\sqrt{3})i = -8$.
step: The three roots lie on the circle $|z| = 2$ at angles $60^\circ$, $180^\circ$ and $300^\circ$, the vertices of an equilateral triangle.
answer: $z \in \{1 + i\sqrt{3},\ -2,\ 1 - i\sqrt{3}\}$.

@example
title: A point on the Riemann sphere
problem: Find the point of $S$ that corresponds to $z = 3 + 4i$, and check that it lies on $S$.
step: Compute $|z|^2 = 9 + 16 = 25$, so $|z|^2 + 1 = 26$.
step: Apply the formula: $X = 2 \cdot 3/26 = 3/13$ and $Y = 2 \cdot 4/26 = 4/13$.
step: The third coordinate is $Z = (25 - 1)/26 = 12/13$.
step: Check: $(3/13)^2 + (4/13)^2 + (12/13)^2 = (9 + 16 + 144)/169 = 1$. The point lies in the northern hemisphere because $|z| > 1$.
answer: $(3/13,\ 4/13,\ 12/13)$.

@mistakes
- Writing $\sqrt{-1}$ inside radicals and then using $\sqrt{ab} = \sqrt{a}\sqrt{b}$: $\sqrt{-1}\sqrt{-1}$ would be $1$, not $-1$. Work with $i$ and Theorem 2 instead.
- Forgetting that the argument is only defined up to multiples of $2\pi$: an equation $z^n = w$ has $n$ solutions, not one.
- Using $|z + w| = |z| + |w|$. Only the inequality holds in general; equality needs $z$ and $w$ to point in the same direction.
- Treating $\infty$ as a number you can add and multiply freely. On the Riemann sphere it is a single point, the image of $N$; $\infty - \infty$ and $0 \cdot \infty$ stay undefined.

@practice self
prompt: Prove that for every integer $n \ge 2$ the $n$-th roots of unity sum to $0$.
hint: Let $\omega = e^{2\pi i/n}$; the roots are $1, \omega, \dots, \omega^{n-1}$, a geometric progression.
hint: Use $1 + \omega + \dots + \omega^{n-1} = (\omega^n - 1)/(\omega - 1)$ and explain why $\omega \ne 1$.
solution: By Theorem 2 the $n$-th roots of unity are $\omega^k$ for $k = 0, \dots, n - 1$ with $\omega = e^{2\pi i/n}$. Since $n \ge 2$, $0 < 2\pi/n < 2\pi$ and $\omega \ne 1$, so the geometric sum formula applies: $\sum_{k=0}^{n-1}\omega^k = (\omega^n - 1)/(\omega - 1) = 0$ because $\omega^n = e^{2\pi i} = 1$. $\blacksquare$
rubric: Identifies the roots as the geometric progression $\omega^k$ with $\omega = e^{2\pi i/n}$.
rubric: States and justifies $\omega \ne 1$ (this is where $n \ge 2$ is used).
rubric: Applies the geometric sum formula and $\omega^n = 1$.

hint: There are $12$ solutions of $z^{12} = 1$. Count those with $z^4 = 1$ or $z^6 = 1$ and subtract.
solution: The solutions of $z^4 = 1$ number $4$ and those of $z^6 = 1$ number $6$. Both hold exactly when $z^2 = 1$ (since $\gcd(4, 6) = 2$), which gives $2$ solutions. So $4 + 6 - 2 = 8$ are excluded, and $12 - 8 = 4$ remain.

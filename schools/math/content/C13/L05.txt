@article
Integrate $z^n$ around the unit circle for $n = 0, 1, 2, \dots$ and also for $n = -1, -2, \dots$. Every answer is $0$ except one: $\oint_{|z|=1} z^{-1}\,dz = 2\pi i$. Why is $1/z$ so special? The answer comes from a fundamental theorem of calculus for contour integrals, and it will drive everything in the rest of the course.

### Paths and the integral

A **smooth path** is a continuously differentiable map $\gamma\colon [a, b] \to \mathbb{C}$ with $\gamma'(t) \ne 0$; a **contour** is a finite chain of smooth paths joined end to end (a piecewise smooth path). It is **closed** if $\gamma(b) = \gamma(a)$. Its **length** is $L(\gamma) = \int_a^b |\gamma'(t)|\,dt$. For a function $g\colon [a, b] \to \mathbb{C}$, $\int_a^b g = \int_a^b \operatorname{Re} g + i\int_a^b \operatorname{Im} g$.

**Definition.** For $f$ continuous on the image of $\gamma$,
$$\int_\gamma f(z)\,dz = \int_a^b f(\gamma(t))\gamma'(t)\,dt,$$
and for a contour the integral is the sum over its smooth pieces.

The integral is linear in $f$; reversing the path ($-\gamma(t) = \gamma(a + b - t)$) changes the sign; and it is unchanged by an orientation-preserving change of parameter (substitute $t = \phi(s)$ in the real integral). A **circle** $C(a, r)$ traversed counterclockwise is $\gamma(t) = a + re^{it}$, $0 \le t \le 2\pi$.

**Lemma 1.** For continuous $g\colon [a, b] \to \mathbb{C}$, $\left|\int_a^b g\right| \le \int_a^b |g|$.

*Proof.* Write $\int_a^b g = re^{i\theta}$ with $r \ge 0$. Then $r = e^{-i\theta}\int_a^b g = \int_a^b e^{-i\theta}g$ is real, so it equals the real part $\int_a^b \operatorname{Re}(e^{-i\theta}g) \le \int_a^b |e^{-i\theta}g| = \int_a^b |g|$. $\blacksquare$

### The estimation lemma

**Theorem 1 (ML lemma).** If $f$ is continuous on the image of the contour $\gamma$ and $|f(z)| \le M$ there, then $\left|\int_\gamma f\,dz\right| \le M\,L(\gamma)$.

*Proof.* For a smooth path, Lemma 1 gives $\left|\int_a^b f(\gamma(t))\gamma'(t)\,dt\right| \le \int_a^b |f(\gamma(t))||\gamma'(t)|\,dt \le M\int_a^b|\gamma'(t)|\,dt = ML(\gamma)$. For a contour, add the bounds over the pieces and use the triangle inequality. $\blacksquare$

### The fundamental theorem

**Theorem 2.** Let $U$ be open, $f$ continuous on $U$, and suppose $F$ is holomorphic on $U$ with $F' = f$ (a **primitive** of $f$). If $\gamma$ is a contour in $U$ from $p$ to $q$, then $\int_\gamma f\,dz = F(q) - F(p)$. In particular $\oint_\gamma f\,dz = 0$ for every closed contour in $U$.

*Proof.* On a smooth piece, the chain rule gives $\dfrac{d}{dt}F(\gamma(t)) = F'(\gamma(t))\gamma'(t) = f(\gamma(t))\gamma'(t)$, which is continuous. The fundamental theorem of calculus, applied to the real and imaginary parts, gives $\int_a^b f(\gamma)\gamma'\,dt = F(\gamma(b)) - F(\gamma(a))$. For a contour the sum over pieces telescopes. $\blacksquare$

So $z^n$, $n \ne -1$, has the primitive $z^{n+1}/(n+1)$ on $\mathbb{C}\setminus\{0\}$ and its integral over any closed contour there is $0$. The function $1/z$ has no primitive on $\mathbb{C}\setminus\{0\}$, as the next theorem shows.

**Theorem 3.** For $a \in \mathbb{C}$, $r > 0$ and an integer $n$, $\displaystyle\oint_{C(a, r)} (z - a)^n\,dz = \begin{cases} 2\pi i & n = -1, \\ 0 & n \ne -1. \end{cases}$

*Proof.* With $\gamma(t) = a + re^{it}$ we have $\gamma'(t) = ire^{it}$, so the integral is $\int_0^{2\pi} r^ne^{int}\,ire^{it}\,dt = ir^{n+1}\int_0^{2\pi} e^{i(n+1)t}\,dt$. If $n = -1$ the integrand is $1$ and the result is $i\cdot 2\pi$. If $n \ne -1$, put $m = n + 1 \ne 0$; $e^{imt}/(im)$ is a primitive of $e^{imt}$ and takes the same value at $0$ and $2\pi$, so the integral is $0$. $\blacksquare$

Hence $1/z$ cannot have a primitive on $\mathbb{C}\setminus\{0\}$ (Theorem 2 would force the integral to be $0$): this is the integral version of the fact, proved in Lesson 4, that there is no logarithm on $\mathbb{C}\setminus\{0\}$.

### Computing numerically

An integral can be approximated by the midpoint rule on the parameter interval:

```python
import math


def contour_integral(f, gamma, dgamma, a, b, n):
    """Midpoint rule with n subintervals of [a, b] for the integral of f."""
    h = (b - a) / n
    total = 0
    for k in range(n):
        t = a + (k + 0.5) * h
        total += f(gamma(t)) * dgamma(t) * h
    return total


def unit(t):
    return complex(math.cos(t), math.sin(t))


value = contour_integral(lambda z: 1 / z, unit, lambda t: 1j * unit(t),
                         0, 2 * math.pi, 50)
print(round(value.imag, 6))
```

With $n = 50$ midpoints this prints `6.283185`, matching $2\pi$ to six decimals. A numerical value like this is evidence for a computation, never a proof; for periodic integrands the midpoint rule is far more accurate than its general $O(1/n^2)$ error.

@example
title: An integral that is not zero
problem: Compute $\oint_{C(0, 2)} \overline{z}\,dz$ for the circle of radius $2$ traversed counterclockwise.
step: Parametrize $z = 2e^{it}$, $0 \le t \le 2\pi$. Then $dz = 2ie^{it}\,dt$ and $\overline{z} = 2e^{-it}$.
step: The integrand is $2e^{-it}\cdot 2ie^{it} = 4i$, a constant.
step: Integrate: $\int_0^{2\pi} 4i\,dt = 8\pi i$.
step: Compare with the fundamental theorem: $\overline{z}$ is not holomorphic, so it has no holomorphic primitive. Indeed, a closed-contour integral that is not $0$ rules out a primitive on any open set containing the circle.
answer: $8\pi i$.

@example
title: A bound from the ML lemma
problem: Let $R > 1$ and let $C_R$ be the upper semicircle $z = Re^{it}$, $0 \le t \le \pi$. Show that $\left|\int_{C_R} \dfrac{dz}{z^2 + 1}\right| \le \dfrac{\pi R}{R^2 - 1}$, and find the limit of the bound as $R \to \infty$.
step: The length of $C_R$ is $L = \pi R$.
step: For $|z| = R$ the reverse triangle inequality gives $|z^2 + 1| \ge |z|^2 - 1 = R^2 - 1 > 0$, so $\left|\dfrac{1}{z^2 + 1}\right| \le \dfrac{1}{R^2 - 1} = M$.
step: By the ML lemma, $\left|\int_{C_R}\dfrac{dz}{z^2+1}\right| \le ML = \dfrac{\pi R}{R^2 - 1}$.
step: As $R \to \infty$, $\dfrac{\pi R}{R^2 - 1} = \dfrac{\pi}{R - 1/R} \to 0$. So the integral over the large semicircle tends to $0$; this is exactly the kind of estimate used in Lesson 10.
answer: The bound is $\pi R/(R^2 - 1)$, which tends to $0$.

@mistakes
- Forgetting the factor $\gamma'(t)$ in $\int f(\gamma(t))\gamma'(t)\,dt$, or integrating with respect to $|dz|$ (arc length) when the problem says $dz$.
- Concluding $\oint f\,dz = 0$ because the contour is closed. That is true only when $f$ has a primitive on an open set containing the contour: $\oint_{|z|=1} dz/z = 2\pi i$.
- Using $|z^2 + 1| \le R^2 + 1$ to bound $1/|z^2 + 1|$: to bound a quotient above, bound the denominator from below, $|z^2 + 1| \ge R^2 - 1$.
- Applying the fundamental theorem on a set where the primitive is not defined, such as using $\log z$ along a contour that crosses its cut.

model:
```python
def polygon_integral(f, pts, n):
    """Midpoint-rule integral of f along a polygonal path."""
    total = 0
    for a, b in zip(pts, pts[1:]):
        d = (b - a) / n
        for k in range(n):
            total += f(a + (k + 0.5) * d) * d
    return total
```
hint: Loop over consecutive pairs `zip(pts, pts[1:])`; on each pair, the $k$-th midpoint is `a + (k + 0.5) * d`.
hint: The left endpoint `a + k * d` gives an error of order $1/n$ that the triangle test detects.
solution: Each segment contributes the sum of `f(midpoint) * d` over its `n` pieces, and the path's integral is the sum over segments. For the triangle, $\oint \overline{z}\,dz = 2i\cdot\text{Area} = i$; using the left endpoints instead of midpoints gives a real part of about $-0.02$, which fails the tolerance. These are numerical values: they support, but do not prove, the exact answers.

prompt: Which of these statements are true for continuous $f$ and contours $\gamma$?
choice*: Reversing the direction of $\gamma$ changes the sign of $\int_\gamma f\,dz$.

solution: Reversal and the ML lemma are properties proved above. One vanishing closed integral does not give a primitive: $\oint_{|z|=1}z^{-2}\,dz = 0$ is consistent with a primitive, but a single closed contour says nothing about other contours in $U$ (a primitive needs all closed integrals to vanish). $\oint dz/z = 2\pi i$. Path independence is Theorem 2.

material: **Code you may start from** (write the rest yourself):
```python
import math


def simpson(f, a, b, n):
    """Composite Simpson rule with n panels (n even)."""
    h = (b - a) / n
    total = f(a) + f(b)
    for k in range(1, n):
        total += (4 if k % 2 else 2) * f(a + k * h)
    return total * h / 3


def circle_average(g, n):
    """Mean of g(theta) over n equally spaced angles in [0, 2*pi)."""
    return sum(g(2 * math.pi * k / n) for k in range(n)) / n
```

@exam self
prompt: Let $f$ be holomorphic on the open unit disk $\mathbb{D}$ with $|f(z)| \le 1$ for all $z \in \mathbb{D}$ and $f(0) = 0$. Prove that $|f(z)| \le |z|$ for all $z \in \mathbb{D}$ and that $|f'(0)| \le 1$ (Schwarz's lemma).
hint: Define $g(z) = f(z)/z$ for $z \ne 0$ and use a removable-singularity argument.
hint: Apply the maximum modulus principle to $g$ on the closed disk $|z| \le r$ for $r < 1$, then let $r \to 1$.
solution: Define $g(z) = f(z)/z$ for $z \ne 0$. Since $f(0) = 0$, $f(z) = \sum_{n \ge 1}a_nz^n$ near $0$ by Taylor's theorem, so $g(z) = \sum_{n\ge1}a_nz^{n-1}$ extends holomorphically to $0$ with $g(0) = a_1 = f'(0)$; thus $g$ is holomorphic on $\mathbb{D}$. Fix $0 < r < 1$. On the circle $|z| = r$, $|g(z)| = |f(z)|/r \le 1/r$. By the maximum modulus principle applied to $g$ on $\overline{D}(0, r)$ (holomorphic on a neighborhood, so continuous on the closed disk), $|g(z)| \le 1/r$ for all $|z| \le r$. For a fixed $z \in \mathbb{D}$ this holds for every $r \in (|z|, 1)$; letting $r \to 1$ gives $|g(z)| \le 1$, that is $|f(z)| \le |z|$. Finally $|f'(0)| = |g(0)| \le 1$. $\blacksquare$
rubric: Shows $g = f/z$ has a removable singularity at $0$ with $g(0) = f'(0)$, using $f(0) = 0$.
rubric: Applies the maximum modulus principle on circles of radius $r < 1$ and bounds $|g| \le 1/r$ there.
rubric: Lets $r \to 1$ for each fixed $z$ and reads off both conclusions.

prompt: Evaluate $\dfrac{1}{2\pi i}\oint_{|z|=2}\dfrac{z^5}{z^6 - 1}\,dz$, with the circle traversed counterclockwise.
answer: 1
check: (lambda pts: round((sum(z ** 5 / (z ** 6 - 1) * z for z in pts) / 512).real))([2 * complex(math.cos(2 * math.pi * j / 512), math.sin(2 * math.pi * j / 512)) for j in range(512)])
hint: The numerator is one sixth of the derivative of the denominator, so the integrand is $\frac{1}{6}\,h'/h$ with $h = z^6 - 1$.
solution: With $h(z) = z^6 - 1$ we have $z^5/(z^6 - 1) = \frac16h'(z)/h(z)$. The six simple zeros of $h$ (the sixth roots of unity) all have modulus $1 < 2$, so by the argument principle $\frac{1}{2\pi i}\oint h'/h = 6$, and the answer is $\frac16\cdot 6 = 1$. Equivalently, each of the six simple poles has residue $\dfrac{z^5}{6z^5} = \dfrac16$.

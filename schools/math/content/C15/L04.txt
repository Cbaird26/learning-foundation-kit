@article
A number leaves remainder $2$ when divided by $5$ and remainder $3$ when divided by $7$. What can it be? Checking $2, 7, 12, 17, \dots$ finds $17$, and then $17 + 35k$ works for every $k$. Why is the answer one residue class modulo $35 = 5 \cdot 7$, and does this work for moduli like $4$ and $6$ that share a factor? Both questions reduce to one equation, $ax \equiv b$.

### One linear congruence

**Theorem 1.** Let $n \ge 1$, let $a, b$ be integers, and $g = \gcd(a, n)$.
1. The congruence $ax \equiv b \pmod{n}$ has a solution if and only if $g \mid b$.
2. If $g \mid b$, the solutions are exactly the integers congruent to one solution $x_0$ modulo $n/g$. Hence there are exactly $g$ solutions modulo $n$.

*Proof.* A solution means $ax - b = ny$ for some integer $y$, that is $ax - ny = b$. By Corollary 4 of week 1 this has an integer solution if and only if $g \mid b$, which is part 1. For part 2, divide the congruence by $g$: it is equivalent to $a'x \equiv b' \pmod{n'}$ with $a' = a/g$, $b' = b/g$, $n' = n/g$ (the equation $ax - b = ny$ is divisible by $g$ both ways). Now $\gcd(a', n') = 1$, so $a'$ has an inverse $c$ modulo $n'$ (week 3), and the congruence is equivalent to $x \equiv cb' \pmod{n'}$. The integers satisfying this are $x_0 + kn'$ with $k \in \mathbb{Z}$, and exactly $g$ of them, $k = 0, \dots, g-1$, lie in any window of $n$ consecutive integers. $\blacksquare$

For example $6x \equiv 4 \pmod{10}$: $g = 2$ divides $4$, so divide by $2$ to get $3x \equiv 2 \pmod 5$. The inverse of $3$ modulo $5$ is $2$, so $x \equiv 4 \pmod 5$, and the two solutions modulo $10$ are $4$ and $9$.

```python
def inverse(a, n):
    """Inverse of a modulo n (assumes gcd(a, n) = 1), by extended Euclid."""
    r0, r1, t0, t1 = n, a % n, 0, 1
    while r1:
        q = r0 // r1
        r0, r1, t0, t1 = r1, r0 - q * r1, t1, t0 - q * t1
    return t0 % n


def solve_linear_congruence(a, b, n):
    """Sorted list of all x in range(n) with a*x = b (mod n)."""
    from math import gcd
    g = gcd(a, n)
    if b % g != 0:
        return []
    n1 = n // g
    x0 = (b // g) * inverse(a // g, n1) % n1
    return [x0 + k * n1 for k in range(g)]


print(solve_linear_congruence(6, 4, 10))
```

This prints `[4, 9]`.

### The Chinese remainder theorem

**Theorem 2 (Chinese remainder theorem).** Let $n_1, \dots, n_k \ge 1$ be pairwise coprime ($\gcd(n_i, n_j) = 1$ for $i \ne j$), let $a_1, \dots, a_k$ be integers and $N = n_1 \cdots n_k$. Then the system $x \equiv a_i \pmod{n_i}$ for $i = 1, \dots, k$ has a solution, and any two solutions are congruent modulo $N$.

*Proof.* Existence. Put $N_i = N/n_i$. It is coprime to $n_i$, since $N_i$ is a product of numbers coprime to $n_i$ (Euclid-lemma style argument: a prime dividing $n_i$ and $N_i$ would divide some $n_j$ with $j \ne i$). Let $M_i$ be an inverse of $N_i$ modulo $n_i$ and set $x = \sum_i a_i N_i M_i$. For $j \ne i$, $n_j \mid N_i$, so the $i$-th term vanishes modulo $n_j$; modulo $n_i$ the $i$-th term is $a_i N_i M_i \equiv a_i$. Hence $x \equiv a_j \pmod{n_j}$ for every $j$.

Uniqueness. If $x, y$ are solutions then each $n_i$ divides $x - y$. We show by induction that $n_1 \cdots n_j \mid x - y$. If $m = n_1 \cdots n_{j-1}$ divides $d = x - y$, write $d = mt$. Then $n_j \mid mt$ and $\gcd(n_j, m) = 1$, so $n_j \mid t$ (week 1) and $mn_j \mid d$. Hence $N \mid x - y$. $\blacksquare$

The hypothesis "pairwise coprime" is needed: $x \equiv 1 \pmod 4$ and $x \equiv 2 \pmod 6$ have no common solution, since the first forces $x$ odd and the second forces $x$ even.

```python
def crt(residues, moduli):
    """Smallest x >= 0 with x = r_i (mod m_i); moduli pairwise coprime."""
    N = 1
    for m in moduli:
        N *= m
    x = 0
    for r, m in zip(residues, moduli):
        Ni = N // m
        x += r * Ni * inverse(Ni, m)
    return x % N


print(crt([1, 2, 3], [3, 4, 5]))
```

It prints `58`: indeed $58 = 19 \cdot 3 + 1 = 14 \cdot 4 + 2 = 11 \cdot 5 + 3$.

### Moduli that are not coprime

**Theorem 3.** Let $m, n \ge 1$ and $g = \gcd(m, n)$. The system $x \equiv a \pmod m$, $x \equiv b \pmod n$ has a solution if and only if $a \equiv b \pmod g$. Then the solutions form one residue class modulo $\operatorname{lcm}(m, n) = mn/g$.

*Proof.* A solution of the first congruence is $x = a + mt$. It satisfies the second if and only if $mt \equiv b - a \pmod n$. By Theorem 1 this is solvable if and only if $g \mid b - a$. If so, $t$ runs through one class modulo $n/g$, so $x = a + mt$ runs through one class modulo $mn/g$. $\blacksquare$

Merging two congruences into one gives an algorithm for any number of them: merge the first two, then merge the result with the third, and so on. If at any step the compatibility condition fails, the system has no solution.

@example
title: A linear congruence with several solutions
problem: Solve $35x \equiv 21 \pmod{56}$.
step: Compute $g = \gcd(35, 56) = 7$. Since $7 \mid 21$, solutions exist by Theorem 1, and there are $7$ of them modulo $56$.
step: Divide everything by $g$: $5x \equiv 3 \pmod 8$.
step: The inverse of $5$ modulo $8$ is $5$ because $25 = 3 \cdot 8 + 1$. So $x \equiv 5 \cdot 3 = 15 \equiv 7 \pmod 8$.
step: The solutions modulo $56$ are $7 + 8k$ for $k = 0, \dots, 6$: $7, 15, 23, 31, 39, 47, 55$.
step: Check one: $35 \cdot 15 = 525 = 9 \cdot 56 + 21$.
answer: $x \equiv 7 \pmod 8$, that is $x \in \{7, 15, 23, 31, 39, 47, 55\}$ modulo $56$.

@example
title: A system by the Chinese remainder theorem
problem: Solve $x \equiv 3 \pmod 8$, $x \equiv 5 \pmod 9$, $x \equiv 4 \pmod 7$.
step: The moduli $8, 9, 7$ are pairwise coprime, so Theorem 2 applies with $N = 504$. Compute $N_1 = 63$, $N_2 = 56$, $N_3 = 72$.
step: Find the inverses: $63 \equiv 7 \pmod 8$ has inverse $7$ (since $49 \equiv 1$); $56 \equiv 2 \pmod 9$ has inverse $5$; $72 \equiv 2 \pmod 7$ has inverse $4$.
step: Form the sum: $3 \cdot 63 \cdot 7 + 5 \cdot 56 \cdot 5 + 4 \cdot 72 \cdot 4 = 1323 + 1400 + 1152 = 3875$.
step: Reduce modulo $504$: $3875 - 7 \cdot 504 = 347$.
step: Check: $347 = 43 \cdot 8 + 3 = 38 \cdot 9 + 5 = 49 \cdot 7 + 4$.
answer: $x \equiv 347 \pmod{504}$.

@mistakes
- Dividing $ax \equiv b \pmod n$ by $g = \gcd(a, n)$ without dividing the modulus too. The new modulus is $n/g$, and the original congruence has $g$ solutions modulo $n$.
- Using the Chinese remainder theorem formula when the moduli share a factor: the inverse of $N_i$ may not exist, and the system may be unsolvable.
- Believing a compatible pair modulo non-coprime moduli is unique modulo $mn$: the solution is unique modulo $\operatorname{lcm}(m, n)$ only.
- Checking a solution against only some of the congruences.

```python
from math import gcd


def crt_pair(a1, n1, a2, n2):
    """Merge x = a1 (mod n1) and x = a2 (mod n2); None if inconsistent."""
    g = gcd(n1, n2)
    if (a2 - a1) % g != 0:
        return None
    n1g, n2g = n1 // g, n2 // g
    # solve n1 * t = a2 - a1 (mod n2) for t, after dividing by g
    t = 0
    if n2g > 1:
        r0, r1, s0, s1 = n2g, n1g % n2g, 0, 1
        while r1:
            q = r0 // r1
            r0, r1, s0, s1 = r1, r0 - q * r1, s1, s0 - q * s1
        t = ((a2 - a1) // g) * (s0 % n2g) % n2g
    lcm = n1 * n2g
    return (a1 + n1 * t) % lcm, lcm
```
hint: Write $x = a_1 + n_1 t$ and solve $n_1 t \equiv a_2 - a_1 \pmod{n_2}$ using Theorem 1; the result is unique modulo $n_2/g$.
solution: The condition from Theorem 3 is $(a_2 - a_1)$ divisible by $g = \gcd(n_1, n_2)$. Dividing $n_1 t \equiv a_2 - a_1 \pmod{n_2}$ by $g$ leaves a congruence whose coefficient $n_1/g$ is invertible modulo $n_2/g$, giving $t$ modulo $n_2/g$ and hence $x$ modulo $n_1 n_2/g$. Reducing modulo the lcm gives the representative in $[0, L)$.

Prove that the map $f\colon \mathbb{Z}/mn\mathbb{Z} \to \mathbb{Z}/m\mathbb{Z} \times \mathbb{Z}/n\mathbb{Z}$, $f(x \bmod mn) = (x \bmod m, x \bmod n)$, is well defined and bijective, and that it respects addition and multiplication (so it is a ring isomorphism).

```python
def mixed_radix(residues, moduli):
    """Garner's mixed-radix digits of the CRT solution."""
    def inverse(a, n):
        r0, r1, t0, t1 = n, a % n, 0, 1
        while r1:
            q = r0 // r1
            r0, r1, t0, t1 = r1, r0 - q * r1, t1, t0 - q * t1
        return t0 % n

    digits = []
    value = 0       # the partial solution built from the digits so far
    scale = 1       # m_1 * ... * m_(i-1)
    for r, m in zip(residues, moduli):
        v = ((r - value) * inverse(scale, m)) % m
        digits.append(v)
        value += v * scale
        scale *= m
    return digits
```
hint: At step $i$ you know the partial value $y$ built from the earlier digits; the new digit $v$ must satisfy $y + v \cdot (m_1 \cdots m_{i-1}) \equiv r_i \pmod{m_i}$.
solution: The product $m_1 \cdots m_{i-1}$ is coprime to $m_i$, so it has an inverse modulo $m_i$ and the equation determines $v_i$ uniquely in $[0, m_i)$. Adding $v_i m_1 \cdots m_{i-1}$ does not disturb the earlier congruences, because it is divisible by $m_1, \dots, m_{i-1}$. After the last step $x < m_1 \cdots m_k$ because each digit is below its modulus, and uniqueness comes from Theorem 2.

```python
from math import gcd


def _inverse(a, n):
    r0, r1, t0, t1 = n, a % n, 0, 1
    while r1:
        q = r0 // r1
        r0, r1, t0, t1 = r1, r0 - q * r1, t1, t0 - q * t1
    return t0 % n


def solve_system(congruences):
    """Combine a*x = b (mod n) congruences into one class (x, M) or None."""
    x, m = 0, 1
    for a, b, n in congruences:
        g = gcd(a, n)
        if b % g != 0:
            return None
        n1 = n // g
        r = (b // g) * _inverse(a // g, n1) % n1 if n1 > 1 else 0
        # merge x = r (mod n1) into x (mod m)
        d = gcd(m, n1)
        if (r - x) % d != 0:
            return None
        m_d, n_d = m // d, n1 // d
        t = 0
        if n_d > 1:
            t = ((r - x) // d) * _inverse(m_d, n_d) % n_d
        x = x + m * t
        m = m * n_d
        x %= m
    return x, m
```
hint: First turn each congruence into $x \equiv r \pmod{n/g}$ with Theorem 1, then merge the classes one at a time as in Theorem 3.
solution: Theorem 1 replaces $ax \equiv b \pmod n$ by a single class $x \equiv r \pmod{n/g}$ or shows it has no solution. Theorem 3 merges two classes into one modulo their lcm, or shows they are incompatible. Folding over the list gives the combined class; the empty system is satisfied by every integer, which is the class $0$ modulo $1$.

@article
What is $2^{100} \bmod 101$? Multiplying $100$ times is easy for a computer, but $2^{10^{18}} \bmod 101$ would be impossible that way. Two ideas make it easy. First, powers modulo $n$ repeat, and a theorem of Fermat and Euler tells us exactly when they return to $1$. Second, the exponent can be handled one binary digit at a time. For the first question the answer turns out to be $1$.

### Euler's function

For $n \ge 1$ let $\varphi(n)$ be the number of integers $k$ with $1 \le k \le n$ and $\gcd(k, n) = 1$. For example $\varphi(1) = 1$, $\varphi(7) = 6$ and $\varphi(36) = 12$.

**Theorem 1.** (a) If $p$ is prime and $k \ge 1$, then $\varphi(p^k) = p^k - p^{k-1}$. (b) If $\gcd(m, n) = 1$, then $\varphi(mn) = \varphi(m)\varphi(n)$.

*Proof.* (a) An integer in $[1, p^k]$ is not coprime to $p^k$ exactly when $p$ divides it; there are $p^{k-1}$ such integers. (b) By the Chinese remainder theorem (week 4, practice problem on the isomorphism), the map $x \mapsto (x \bmod m, x \bmod n)$ is a bijection from residues modulo $mn$ to pairs of residues. Now $\gcd(x, mn) = 1$ if and only if $\gcd(x, m) = 1$ and $\gcd(x, n) = 1$ (a prime dividing $x$ and $mn$ divides $m$ or $n$ by Euclid's lemma), and these conditions depend only on $x \bmod m$ and $x \bmod n$. So the units modulo $mn$ correspond to pairs (unit modulo $m$, unit modulo $n$), and counting gives $\varphi(mn) = \varphi(m)\varphi(n)$. $\blacksquare$

Hence for $n = p_1^{e_1} \cdots p_r^{e_r}$ we get $\varphi(n) = \prod p_i^{e_i - 1}(p_i - 1)$. For example $\varphi(36) = \varphi(4)\varphi(9) = 2 \cdot 6 = 12$.

### Euler's theorem and Fermat's little theorem

**Theorem 2 (Euler).** Let $n \ge 1$ and let $a$ be an integer with $\gcd(a, n) = 1$. Then $a^{\varphi(n)} \equiv 1 \pmod n$.

*Proof.* Let $r_1, \dots, r_t$ with $t = \varphi(n)$ be the integers in $[1, n]$ coprime to $n$, and let $P = r_1 \cdots r_t$. Consider the numbers $ar_1, \dots, ar_t$. Each is coprime to $n$ (a prime dividing $n$ and $ar_i$ would divide $a$ or $r_i$), so each is congruent to some $r_j$. They are pairwise incongruent: if $ar_i \equiv ar_j$, cancellation (week 3, since $\gcd(a, n) = 1$) gives $r_i \equiv r_j$, so $i = j$. Hence $ar_1, \dots, ar_t$ are congruent to $r_1, \dots, r_t$ in some order, and multiplying all of them, $a^t P \equiv P \pmod n$. Since $P$ is a product of numbers coprime to $n$, it is coprime to $n$, and cancellation gives $a^t \equiv 1$. $\blacksquare$

**Corollary 3 (Fermat's little theorem).** Let $p$ be prime. If $p \nmid a$, then $a^{p-1} \equiv 1 \pmod p$. For every integer $a$, $a^p \equiv a \pmod p$.

*Proof.* For a prime, $\varphi(p) = p - 1$; apply Theorem 2. For the second statement, multiply $a^{p-1} \equiv 1$ by $a$ when $p \nmid a$, and note that both sides are $\equiv 0$ when $p \mid a$. $\blacksquare$

Both theorems need the hypothesis on $a$: $2^{\varphi(4)} = 4 \equiv 0 \pmod 4$. So $2^{100} \equiv 1 \pmod{101}$ because $101$ is prime and $101 \nmid 2$. Euler's theorem also lets us reduce exponents: if $\gcd(a, n) = 1$, then $a^e \equiv a^{e \bmod \varphi(n)} \pmod n$.

### Fast exponentiation

To compute $a^e \bmod m$, write $e$ in binary. Square-and-multiply uses the identities $a^{2k} = (a^2)^k$ and $a^{2k+1} = a \cdot (a^2)^k$:

```python
def power_mod(a, e, m):
    """a**e mod m for e >= 0, m >= 1, by right-to-left binary exponentiation."""
    result = 1 % m
    base = a % m
    while e > 0:
        if e & 1:
            result = result * base % m
        base = base * base % m
        e >>= 1
    return result


def phi(n):
    """Euler's function by trial division, for n >= 1."""
    result, d = n, 2
    while d * d <= n:
        if n % d == 0:
            while n % d == 0:
                n //= d
            result -= result // d
        d += 1
    if n > 1:
        result -= result // n
    return result


print(power_mod(2, 100, 101), phi(36))
```

This prints `1 12`.

**Theorem 4.** `power_mod(a, e, m)` returns $a^e \bmod m$ using at most $2(\lfloor \log_2 e \rfloor + 1)$ modular multiplications for $e \ge 1$.

*Proof.* Let $a_0, e_0$ be the inputs. We claim that at the top of each pass, `result` $\cdot$ `base`$^{e} \equiv a_0^{e_0} \pmod m$. Initially `result` $= 1$ and `base` $\equiv a_0$, $e = e_0$. In a pass: if $e$ is odd, `result` becomes `result`$\cdot$`base`, and $e = 2k + 1$; the product `result`$\cdot$`base`$\cdot$(`base`$^2$)$^k$ equals the old `result`$\cdot$`base`$^{2k+1}$. If $e$ is even, $e = 2k$ and (`base`$^2$)$^k$ = `base`$^{2k}$. So the invariant holds with the new `base` = `base`$^2$ and new $e = k$. When $e = 0$ the invariant says `result` $\equiv a_0^{e_0}$. The number of passes is the number of binary digits of $e_0$, which is $\lfloor \log_2 e_0 \rfloor + 1$, and each pass does at most two multiplications. $\blacksquare$

So an exponent with $1000$ binary digits needs at most $2000$ multiplications, not $2^{1000}$.

### The converse fails

If $n$ is prime and $\gcd(a, n) = 1$ then $a^{n-1} \equiv 1 \pmod n$. The converse is false. A **Carmichael number** is a composite $n$ with $a^{n-1} \equiv 1 \pmod n$ for every $a$ coprime to $n$. The smallest is $561 = 3 \cdot 11 \cdot 17$: here $2$, $10$ and $16$ divide $560$, and one checks $a^{560} \equiv 1$ modulo each of $3$, $11$ and $17$ by Fermat, hence modulo $561$ by the Chinese remainder theorem. Next week's primality tests must avoid this trap.

@example
title: Reducing a large exponent
problem: Find the remainder of $7^{222}$ on division by $15$.
step: Check the hypothesis: $\gcd(7, 15) = 1$, so Euler's theorem applies.
step: Compute $\varphi(15) = \varphi(3)\varphi(5) = 2 \cdot 4 = 8$, so $7^8 \equiv 1 \pmod{15}$.
step: Reduce the exponent: $222 = 27 \cdot 8 + 6$, so $7^{222} = (7^8)^{27} \cdot 7^6 \equiv 7^6$.
step: Compute $7^2 = 49 \equiv 4$, so $7^6 \equiv 4^3 = 64 \equiv 4 \pmod{15}$.
answer: The remainder is $4$.

@example
title: Square-and-multiply by hand
problem: Compute $3^{13} \bmod 50$ with the right-to-left algorithm.
step: Start with result $= 1$, base $= 3$, $e = 13$. Since $13$ is odd, result $= 3$; then base $= 9$ and $e = 6$.
step: $e = 6$ is even, so result stays $3$; base $= 81 \bmod 50 = 31$ and $e = 3$.
step: $e = 3$ is odd: result $= 3 \cdot 31 = 93 \bmod 50 = 43$; base $= 31^2 = 961 \bmod 50 = 11$ and $e = 1$.
step: $e = 1$ is odd: result $= 43 \cdot 11 = 473 \bmod 50 = 23$; base $= 121 \bmod 50 = 21$ and $e = 0$, so the loop stops.
step: Check: $3^{13} = 1594323 = 31886 \cdot 50 + 23$.
answer: $3^{13} \equiv 23 \pmod{50}$, using $4$ passes of the loop.

@mistakes
- Using Euler's theorem when $\gcd(a, n) > 1$. For example $2^{\varphi(4)} \equiv 0 \pmod 4$, not $1$.
- Reducing the exponent modulo $n$ instead of modulo $\varphi(n)$ (or modulo $p - 1$ for a prime $p$).
- Using $\varphi(mn) = \varphi(m)\varphi(n)$ without $\gcd(m, n) = 1$: $\varphi(4) = 2$ but $\varphi(2)^2 = 1$.
- Concluding that $n$ is prime from $a^{n-1} \equiv 1 \pmod n$ for one or even all coprime $a$; Carmichael numbers like $561$ pass every such test.

from math import gcd


def is_carmichael(n):
    """True if n is composite and a**(n-1) = 1 mod n for all a coprime to n."""
    if n < 4:
        return False
    if all(n % d for d in range(2, int(n ** 0.5) + 1)):
        return False
    return all(pow(a, n - 1, n) == 1 for a in range(1, n) if gcd(a, n) == 1)

```python
def power_mod_counted(a, e, m):
    """Left-to-right square-and-multiply; returns (a**e % m, multiplications)."""
    if e == 0:
        return 1 % m, 0
    bits = bin(e)[2:]
    r = a % m
    count = 0
    for bit in bits[1:]:
        r = r * r % m
        count += 1
        if bit == "1":
            r = r * a % m
            count += 1
    return r, count
```
hint: The binary digits of $e$ are `bin(e)[2:]`; the first digit is always `1`, so start from `a % m` and process the rest.
solution: Reading the digits from the left, the exponent seen so far doubles at each digit (so `r` is squared) and gains $1$ when the digit is $1$ (so `r` is multiplied by `a`). If $e$ has $L$ binary digits the count is $(L - 1)$ squarings plus the number of ones after the leading one. For $64 = 2^6$ that is $6$ squarings and no multiplications.

model:
```python
def phi_table(n):
    """Table of Euler's function for 0..n by a sieve over the primes."""
    t = list(range(n + 1))
    t[0] = 0
    for p in range(2, n + 1):
        if t[p] == p:              # p has not been reduced yet, so it is prime
            for k in range(p, n + 1, p):
                t[k] -= t[k] // p
    return t
```
hint: A number $k$ still has `t[k] == k` when we reach it only if no smaller prime divides it, so it is prime.
solution: By Theorem 1, $\varphi(k) = k \prod_{p \mid k}(1 - 1/p)$. Replacing `t[k]` by `t[k] - t[k] // p` multiplies it by $(1 - 1/p)$ exactly (the value is always divisible by $p$ at that moment, because it is $k$ times earlier factors $(p_i - 1)/p_i$ with $p_i \ne p$). When the outer loop reaches $p$, `t[p] == p` unless a smaller prime divided $p$, which is impossible, so primes are recognized correctly.

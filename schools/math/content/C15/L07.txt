List the powers of $2$ modulo $13$: $2, 4, 8, 3, 6, 12, 11, 9, 5, 10, 7, 1$. The twelve values are all of $1, \dots, 12$ in a scrambled order, so every nonzero residue is a power of $2$. For $3$ the list is $3, 9, 1, 3, 9, 1, \dots$: only three values. Which bases generate everything, and given a target, can you find the exponent quickly? The first question is about *primitive roots*; the second is the *discrete logarithm problem*, the basis of several cryptosystems.

### The order of a unit

Let $n \ge 2$ and $\gcd(a, n) = 1$. The **order** of $a$ modulo $n$, written $\operatorname{ord}_n(a)$, is the least integer $k \ge 1$ with $a^k \equiv 1 \pmod n$. It exists by Euler's theorem, since $a^{\varphi(n)} \equiv 1$.

**Theorem 1.** Let $r = \operatorname{ord}_n(a)$. Then $a^k \equiv 1 \pmod n$ if and only if $r \mid k$. In particular $r \mid \varphi(n)$. Moreover $\operatorname{ord}_n(a^j) = r/\gcd(r, j)$ for every integer $j \ge 1$.

*Proof.* If $k = rs$ then $a^k = (a^r)^s \equiv 1$. Conversely, divide $k = qr + t$ with $0 \le t < r$; then $1 \equiv a^k = (a^r)^q a^t \equiv a^t$, and minimality of $r$ forces $t = 0$. Euler's theorem gives $r \mid \varphi(n)$. For the last claim let $g = \gcd(r, j)$: $(a^j)^k \equiv 1$ iff $r \mid jk$ iff $(r/g) \mid (j/g)k$ iff $(r/g) \mid k$, because $\gcd(r/g, j/g) = 1$. $\blacksquare$

A **primitive root** modulo $n$ is a unit $g$ with $\operatorname{ord}_n(g) = \varphi(n)$, equivalently every unit is a power of $g$. Modulo $13$, $2$ is a primitive root and $3$ is not.

```python
def order(a, n):
    """Multiplicative order of a modulo n (assumes gcd(a, n) = 1, n >= 2)."""
    k, x = 1, a % n
    while x != 1:
        x = x * a % n
        k += 1
    return k


def is_primitive_root(g, p, prime_factors):
    """Test g mod a prime p, given the distinct primes dividing p - 1."""
    return all(pow(g, (p - 1) // q, p) != 1 for q in prime_factors)


print(order(2, 13), order(3, 13), is_primitive_root(2, 13, [2, 3]))
```

This prints `12 3 True`. The second function uses the following test.

**Proposition 2.** Let $p$ be prime, $p \nmid g$, and let $q_1, \dots, q_s$ be the distinct primes dividing $p - 1$. Then $g$ is a primitive root modulo $p$ if and only if $g^{(p-1)/q_i} \not\equiv 1 \pmod p$ for every $i$.

*Proof.* If $g$ is a primitive root, its order is $p - 1$, which does not divide the smaller number $(p-1)/q_i$, so $g^{(p-1)/q_i} \not\equiv 1$ by Theorem 1. Conversely, if the order $r$ is less than $p - 1$, then $r$ is a proper divisor of $p - 1$, so $r \mid (p-1)/q_i$ for some prime $q_i$ (the quotient $(p-1)/r > 1$ has a prime factor $q_i$), and $g^{(p-1)/q_i} \equiv 1$. $\blacksquare$

### Primitive roots exist modulo a prime

**Theorem 3.** For every prime $p$ there are exactly $\varphi(p - 1)$ primitive roots modulo $p$.

*Proof.* We use that a polynomial of degree $d$ over the field $\mathbb{Z}/p\mathbb{Z}$ has at most $d$ roots (C11). Let $N = p - 1$ and let $\psi(d)$ be the number of $a \in \{1, \dots, N\}$ of order exactly $d$. Each order divides $N$ (Theorem 1), so $\sum_{d \mid N} \psi(d) = N$.

*Claim: $\psi(d) \le \varphi(d)$.* If $\psi(d) = 0$ this is clear. Otherwise pick $a$ of order $d$. The powers $1, a, \dots, a^{d-1}$ are distinct modulo $p$ (if $a^i \equiv a^j$ with $0 \le i < j < d$ then $a^{j-i} \equiv 1$, contradicting minimality), and all are roots of $x^d - 1$, which has at most $d$ roots. So these are all the roots. Any element $b$ of order $d$ satisfies $b^d \equiv 1$, hence $b \equiv a^j$ for some $0 \le j < d$, and by Theorem 1 its order is $d/\gcd(d, j)$, which is $d$ exactly when $\gcd(j, d) = 1$. There are $\varphi(d)$ such $j$.

*Counting identity: $\sum_{d \mid N} \varphi(d) = N$.* Sort the integers $k \in \{1, \dots, N\}$ by $\gcd(k, N) = N/d$. Those with $\gcd(k, N) = N/d$ are $k = (N/d)j$ with $1 \le j \le d$ and $\gcd(j, d) = 1$, which is $\varphi(d)$ many; summing over $d \mid N$ gives $N$.

Now $N = \sum \psi(d) \le \sum \varphi(d) = N$ forces $\psi(d) = \varphi(d)$ for every $d \mid N$; take $d = N$. $\blacksquare$

For composite moduli the situation is subtler. The following is stated **without proof**: a primitive root modulo $n \ge 2$ exists if and only if $n = 2$, $n = 4$, $n = p^k$ or $n = 2p^k$ for an odd prime $p$ and $k \ge 1$. For example, modulo $8$ every unit squares to $1$, so no element has order $\varphi(8) = 4$.

### Discrete logarithms

If $g$ is a primitive root modulo $p$, every unit $h$ equals $g^x$ for some $x$ determined modulo $p - 1$. This $x$ is the **discrete logarithm** (or index) $\log_g h$. It satisfies $\log_g(ab) \equiv \log_g a + \log_g b \pmod{p - 1}$. Computing $g^x$ is fast (week 5), but recovering $x$ appears hard for large $p$.

**Baby-step giant-step.** Let $m = \lceil \sqrt{p - 1} \rceil$. Every $x$ with $0 \le x < p - 1$ can be written $x = im + j$ with $0 \le j < m$ and $0 \le i \le m$. Then $g^{im + j} \equiv h$ means $g^j \equiv h \cdot (g^{-m})^i$. So: store the *baby steps* $g^j$ for $j = 0, \dots, m - 1$ in a dictionary, then compute the *giant steps* $h(g^{-m})^i$ for $i = 0, 1, \dots$ until one appears in the dictionary. This takes about $2\sqrt{p}$ operations instead of $p$, which is a saving but still exponential in the number of digits. Correctness: if the loop finds a match, then $g^{im + j} \equiv h$ by the computation above; and if $h = g^x$ with $0 \le x < p - 1$, then the pair $(i, j)$ of $x$ is among those searched, so a match is found.

@mistakes
- Looking for a primitive root modulo every $n$: modulo $8$, $12$ and $15$ there is none.
- Testing only $g^{p-1} \not\equiv 1$ or only one exponent $(p-1)/q$. Proposition 2 needs every prime $q \mid p - 1$.
- Treating the discrete logarithm as unique: it is defined modulo the order of $g$ ($p - 1$ for a primitive root).
- Believing $\operatorname{ord}(a^j) = \operatorname{ord}(a)/j$. The correct formula divides by $\gcd(\operatorname{ord}(a), j)$.

```python
from math import isqrt


def bsgs(g, h, p):
    """Smallest x >= 0 with g**x = h (mod p), or None."""
    m = isqrt(p - 1) + 1
    baby = {}
    value = 1
    for j in range(m):
        baby.setdefault(value, j)      # keep the smallest j for each value
        value = value * g % p
    factor = pow(pow(g, p - 2, p), m, p)
    y = h % p
    for i in range(m + 1):
        if y in baby:
            return i * m + baby[y]
        y = y * factor % p
    return None
```
hint: Store only the first $j$ at which each value appears; scanning $i = 0, 1, \dots$ then finds the smallest $x = im + j$ first.
solution: Every $x$ with $0 \le x < p - 1$ is $im + j$ with $0 \le j < m$ and $i \le m$, and $g^x \equiv h$ is equivalent to $g^j \equiv h(g^{-m})^i$. Because $j < m$, the number $im + j$ increases with $i$, so the first match in order of $i$, using the smallest $j$ for a value, is the smallest solution. Since $g^{p-1} \equiv 1$, any solution can be reduced below $p - 1$, so `None` is correct when the scan ends.

```python
def smallest_primitive_root(p):
    """Smallest primitive root modulo the prime p."""
    n, q, factors = p - 1, 2, []
    while q * q <= n:
        if n % q == 0:
            factors.append(q)
            while n % q == 0:
                n //= q
        q += 1
    if n > 1:
        factors.append(n)
    g = 1
    while True:
        if all(pow(g, (p - 1) // f, p) != 1 for f in factors):
            return g
        g += 1
```

```python
def elements_of_order(d, p):
    """All a in 1..p-1 with multiplicative order exactly d modulo p."""
    result = []
    for a in range(1, p):
        k, x = 1, a
        while x != 1:
            x = x * a % p
```

@article
The fraction $355/113 = 3.14159292\ldots$ agrees with $\pi$ to six decimal places, although its denominator has only three digits. A fraction with such a small denominator and so good an approximation is no accident: it is a *convergent* of the continued fraction of $\pi$. Continued fractions are the Euclidean algorithm applied to a real number, and they solve Pell's equation $x^2 - dy^2 = 1$ for non-square $d$.

### Continued fractions of rational numbers

Euclid's algorithm on $(355, 113)$ gives $355 = 3 \cdot 113 + 16$, $113 = 7 \cdot 16 + 1$, $16 = 16 \cdot 1$. The quotients $3, 7, 16$ are the **partial quotients**:
$$\frac{355}{113} = 3 + \cfrac{1}{7 + \cfrac{1}{16}} = [3; 7, 16].$$
In general, for a real number $x$ put $x_0 = x$, $a_k = \lfloor x_k \rfloor$, and $x_{k+1} = 1/(x_k - a_k)$ as long as $x_k \ne a_k$. Then $x = [a_0; a_1, a_2, \dots]$. For rational $x = p/q$ this is the Euclidean algorithm, so it stops after finitely many steps; an irrational $x$ never stops, and $x_k > 1$ for $k \ge 1$, so $a_k \ge 1$.

The **convergents** are $p_k/q_k = [a_0; a_1, \dots, a_k]$. They satisfy
$$p_k = a_k p_{k-1} + p_{k-2}, \qquad q_k = a_k q_{k-1} + q_{k-2},$$
with $p_{-1} = 1$, $q_{-1} = 0$, $p_{-2} = 0$, $q_{-2} = 1$ (this is proved by induction on $k$ from the definition of the bracket; the recurrence is used throughout). For $[3; 7, 16]$: $3/1$, $22/7$, $355/113$.

```python
def cf_rational(p, q):
    """Partial quotients of p/q (q > 0), by the Euclidean algorithm."""
    terms = []
    while q:
        terms.append(p // q)
        p, q = q, p % q
    return terms


def convergents(terms):
    """List of (p_k, q_k) for the continued fraction [a0; a1, ...]."""
    result = []
    p1, q1, p2, q2 = 1, 0, 0, 1          # p_{k-1}, q_{k-1}, p_{k-2}, q_{k-2}
    for a in terms:
        p, q = a * p1 + p2, a * q1 + q2
        result.append((p, q))
        p1, q1, p2, q2 = p, q, p1, q1
    return result


print(convergents(cf_rational(355, 113)))
```

This prints `[(3, 1), (22, 7), (355, 113)]`.

### Two theorems about convergents

**Theorem 1.** $p_k q_{k-1} - p_{k-1} q_k = (-1)^{k-1}$ for all $k \ge 0$. In particular $\gcd(p_k, q_k) = 1$.

*Proof.* For $k = 0$: $p_0 q_{-1} - p_{-1} q_0 = a_0 \cdot 0 - 1 \cdot 1 = -1 = (-1)^{-1}$. If it holds for $k - 1$, then
$$p_k q_{k-1} - p_{k-1} q_k = (a_k p_{k-1} + p_{k-2}) q_{k-1} - p_{k-1}(a_k q_{k-1} + q_{k-2}) = -(p_{k-1} q_{k-2} - p_{k-2} q_{k-1}) ,$$
which equals $-(-1)^{k-2} = (-1)^{k-1}$. A common divisor of $p_k$ and $q_k$ divides $\pm 1$. $\blacksquare$

**Theorem 2.** Let $x$ be irrational. Then for every $k \ge 0$,
$$\left| x - \frac{p_k}{q_k} \right| < \frac{1}{q_k q_{k+1}} \le \frac{1}{q_k^2} .$$

*Proof.* First, $x = \dfrac{x_{k+1} p_k + p_{k-1}}{x_{k+1} q_k + q_{k-1}}$ for all $k \ge 0$: for $k = 0$ this is $x = a_0 + 1/x_1$, and passing from $k$ to $k+1$ replaces $x_{k+1}$ by $a_{k+1} + 1/x_{k+2}$ and uses the recurrences. Subtracting $p_k/q_k$ and using Theorem 1,
$$x - \frac{p_k}{q_k} = \frac{p_{k-1} q_k - p_k q_{k-1}}{q_k(x_{k+1} q_k + q_{k-1})} = \frac{(-1)^k}{q_k(x_{k+1} q_k + q_{k-1})}.$$
Since $x$ is irrational, $x_{k+1} > a_{k+1}$, hence $x_{k+1} q_k + q_{k-1} > a_{k+1} q_k + q_{k-1} = q_{k+1}$. Also $q_{k+1} \ge q_k$. $\blacksquare$

### The continued fraction of $\sqrt{d}$

Let $d > 0$ be an integer that is not a perfect square and $a_0 = \lfloor \sqrt{d} \rfloor$. Define integers $m_0 = 0$, $d_0 = 1$, and
$$m_{k+1} = d_k a_k - m_k, \qquad d_{k+1} = \frac{d - m_{k+1}^2}{d_k}, \qquad a_{k+1} = \left\lfloor \frac{a_0 + m_{k+1}}{d_{k+1}} \right\rfloor .$$

**Lemma 3.** For all $k$, $d_k$ is a positive integer dividing $d - m_k^2$, and $x_k = (m_k + \sqrt{d})/d_k$ is the $k$-th complete quotient of $\sqrt{d}$, so $a_k = \lfloor x_k \rfloor$.

*Proof.* For $k = 0$, $x_0 = \sqrt{d}$ and $d_0 = 1$ divides $d$. Suppose the claim for $k$. Then $x_k - a_k = (\sqrt{d} - m_{k+1})/d_k$, and rationalizing,
$$x_{k+1} = \frac{d_k}{\sqrt{d} - m_{k+1}} = \frac{d_k(\sqrt{d} + m_{k+1})}{d - m_{k+1}^2}.$$
Now $d - m_{k+1}^2 = d - (d_k a_k - m_k)^2 = (d - m_k^2) + 2 m_k d_k a_k - d_k^2 a_k^2$, which is divisible by $d_k$ since $d_k \mid d - m_k^2$. So $d_{k+1} = (d - m_{k+1}^2)/d_k$ is an integer with $d - m_{k+1}^2 = d_k d_{k+1}$, and $x_{k+1} = (\sqrt{d} + m_{k+1})/d_{k+1}$. Also $m_{k+1} < \sqrt{d}$ because $x_k > a_k$ and $d_k > 0$, while $m_{k+1} = d_k a_k - m_k \ge -m_k > -\sqrt{d}$ (using $a_k \ge 0$ and $m_k < \sqrt{d}$, which holds for $k = 0$ and by the previous step). So $d_k d_{k+1} = d - m_{k+1}^2 > 0$, hence $d_{k+1} > 0$. Finally $a_{k+1} = \lfloor x_{k+1} \rfloor = \lfloor (a_0 + m_{k+1} + \theta)/d_{k+1} \rfloor$ with $\theta = \sqrt{d} - a_0 \in (0,1)$, which equals $\lfloor (a_0 + m_{k+1})/d_{k+1} \rfloor$ because the numerator without $\theta$ is an integer and $d_{k+1}$ is an integer. $\blacksquare$

So all the arithmetic is exact integer arithmetic.

```python
from math import isqrt


def sqrt_cf(d, count):
    """First `count` partial quotients of sqrt(d), d not a perfect square."""
    a0 = isqrt(d)
    m, den, a = 0, 1, a0
    terms = [a0]
    for _ in range(count - 1):
        m = den * a - m
        den = (d - m * m) // den
        a = (a0 + m) // den
        terms.append(a)
    return terms


print(sqrt_cf(7, 10))
```

It prints `[2, 1, 1, 1, 4, 1, 1, 1, 4, 1]`: the expansion of $\sqrt{7}$ is periodic. That the expansion of every $\sqrt{d}$ is periodic with the period ending at $2a_0$ is a theorem of Lagrange, which we use **without proof**.

### Pell's equation

**Theorem 4.** With $p_k, q_k$ the convergents of $\sqrt{d}$ and $d_{k+1}$ as above, $p_k^2 - d q_k^2 = (-1)^{k-1} d_{k+1}$.

*Proof.* Put $m = m_{k+1}$ and $D = d_{k+1}$. Substitute $x_{k+1} = (m + \sqrt{d})/D$ into $\sqrt{d} = \dfrac{x_{k+1} p_k + p_{k-1}}{x_{k+1} q_k + q_{k-1}}$ (proved in Theorem 2, valid for any real number) and clear denominators: $\sqrt{d}\,[(m + \sqrt{d}) q_k + D q_{k-1}] = (m + \sqrt{d}) p_k + D p_{k-1}$. The numbers $p, q, m, D$ are integers and $\sqrt{d}$ is irrational, so the parts without $\sqrt{d}$ agree, and so do the coefficients of $\sqrt{d}$: $p_k = m q_k + D q_{k-1}$ and $d q_k = m p_k + D p_{k-1}$. Then $p_k^2 - d q_k^2 = p_k(m q_k + D q_{k-1}) - q_k(m p_k + D p_{k-1}) = D(p_k q_{k-1} - p_{k-1} q_k) = (-1)^{k-1} D$ by Theorem 1. $\blacksquare$

Pell's equation $x^2 - dy^2 = 1$ always has the trivial solution $(1, 0)$. When $d$ is a perfect square $c^2$, the left side factors as $(x - cy)(x + cy) = 1$, which forces $y = 0$; so we take $d$ non-square. Lagrange's theorem (**stated without proof**) says that then there are infinitely many solutions in positive integers, that the one with smallest $x$ (the *fundamental solution*) is the first convergent $(p_k, q_k)$ of $\sqrt{d}$ with $p_k^2 - dq_k^2 = 1$, and that it is found at the end of the first period (if the period length $r$ is even) or of the second period (if $r$ is odd). By Theorem 4 the convergents have $p_k^2 - dq_k^2 = \pm d_{k+1}$, and $d_{k+1} = 1$ at the end of a period. For $\sqrt{7} = [2; \overline{1, 1, 1, 4}]$ the convergents are $2/1, 3/1, 5/2, 8/3$ and $8^2 - 7 \cdot 3^2 = 1$.

problem: Find the continued fraction of $415/93$ and its convergents.
step: Run the Euclidean algorithm: $415 = 4 \cdot 93 + 43$, $93 = 2 \cdot 43 + 7$, $43 = 6 \cdot 7 + 1$, $7 = 7 \cdot 1$. The partial quotients are $[4; 2, 6, 7]$.
step: Start the recurrence with $p_{-1} = 1$, $q_{-1} = 0$, $p_{-2} = 0$, $q_{-2} = 1$: $p_0 = 4$, $q_0 = 1$.
step: $a_1 = 2$: $p_1 = 2 \cdot 4 + 1 = 9$ and $q_1 = 2 \cdot 1 + 0 = 2$. Then $a_2 = 6$: $p_2 = 6 \cdot 9 + 4 = 58$ and $q_2 = 6 \cdot 2 + 1 = 13$.
step: $a_3 = 7$: $p_3 = 7 \cdot 58 + 9 = 415$ and $q_3 = 7 \cdot 13 + 2 = 93$. The last convergent is the number itself.
step: Check Theorem 1: $p_2 q_1 - p_1 q_2 = 58 \cdot 2 - 9 \cdot 13 = 116 - 117 = -1 = (-1)^{1}$.
answer: $415/93 = [4; 2, 6, 7]$ with convergents $4,\ 9/2,\ 58/13,\ 415/93$.

@example
title: Pell's equation when the period is odd
problem: Solve $x^2 - 5y^2 = 1$ with continued fractions.
step: Here $a_0 = 2$. Compute $m_1 = 1 \cdot 2 - 0 = 2$, $d_1 = (5 - 4)/1 = 1$, $a_1 = \lfloor (2 + 2)/1 \rfloor = 4$. Then $m_2 = 4 - 2 = 2$ and $d_2 = (5 - 4)/1 = 1$ again, so $\sqrt{5} = [2; \overline{4}]$ with period $r = 1$ (odd).
step: The convergents are $2/1$, $9/4$, $38/17$, $\dots$ Check the first: $2^2 - 5 \cdot 1^2 = -1$; by Theorem 4, $p_0^2 - 5q_0^2 = (-1)^{-1} d_1 = -1$.
step: The next convergent has $9^2 - 5 \cdot 4^2 = 81 - 80 = 1$, which is the fundamental solution (and the second period's end, as Lagrange's theorem says for an odd period).
step: Another route: $(2 + \sqrt{5})^2 = 9 + 4\sqrt{5}$, so squaring the solution of $x^2 - 5y^2 = -1$ gives $(9, 4)$.
answer: The fundamental solution is $(x, y) = (9, 4)$.

@mistakes
- Applying the convergent method to a perfect square $d$: $x^2 - c^2 y^2 = 1$ has only $y = 0$.
- Stopping at the first convergent of $\sqrt{d}$ without checking $p^2 - dq^2 = 1$: when the period is odd, the first period gives $-1$ and one must go on.
- Using floating-point `sqrt` to compute partial quotients of $\sqrt{d}$; rounding errors accumulate. Use the exact integer recurrence.
- Starting the recurrences at the wrong values: $p_{-1} = 1$, $q_{-1} = 0$, $p_{-2} = 0$, $q_{-2} = 1$.

```python
from fractions import Fraction


def best_convergent(x, max_den):
    """Last convergent of x whose denominator does not exceed max_den."""
    p, q = x.numerator, x.denominator
    p1, q1, p2, q2 = 1, 0, 0, 1
    best = None
    while q:
        a = p // q
        p, q = q, p % q
        cp, cq = a * p1 + p2, a * q1 + q2
        if cq > max_den:
            break
        best = Fraction(cp, cq)
        p1, q1, p2, q2 = cp, cq, p1, q1
    return best
```
hint: The denominators $q_k$ increase with $k$ (they are non-decreasing, and strictly increasing from $k = 1$), so stop at the first convergent whose denominator is too large.
solution: The convergents are generated in order of nondecreasing denominators, so scanning until the first $q_k > $ `max_den` returns the last allowed one. The first convergent $a_0/1$ always qualifies since $1 \le$ `max_den`. If the expansion ends before that happens, the last convergent is `x` itself. By Theorem 2, each convergent is a very good approximation for its size.

from math import isqrt


def pell_fundamental(d):
    """Fundamental solution of x^2 - d y^2 = 1 for non-square d > 0."""
    a0 = isqrt(d)
    m, den, a = 0, 1, a0
    p1, q1, p2, q2 = 1, 0, 0, 1
    while True:
        p, q = a * p1 + p2, a * q1 + q2
        if p * p - d * q * q == 1:
            return p, q
        p1, q1, p2, q2 = p, q, p1, q1
        m = den * a - m
        den = (d - m * m) // den
        a = (a0 + m) // den
```

def pell_solutions(d, x1, y1, n):
    """First n solutions generated by the fundamental one."""
    result = []
    x, y = 1, 0
    for _ in range(n):
        x, y = x1 * x + d * y1 * y, x1 * y + y1 * x
        result.append((x, y))
    return result
```
hint: Start from $(x_0, y_0) = (1, 0)$, the trivial solution, and multiply by $(x_1, y_1)$ $n$ times; both coordinates must be updated from the old values simultaneously.
solution: The pair update is the multiplication law $(x + y\sqrt{d})(x_1 + y_1\sqrt{d}) = (x x_1 + d y y_1) + (x y_1 + y x_1)\sqrt{d}$, and every such product again solves the equation because the norm $u^2 - dv^2$ of a product is the product of the norms. Updating both coordinates in one tuple assignment keeps the old $x$ available for the new $y$.

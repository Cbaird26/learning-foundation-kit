@article
Square the numbers $1, 2, \dots, 10$ modulo $11$: you get $1, 4, 9, 5, 3, 3, 5, 9, 4, 1$. Only the five residues $1, 3, 4, 5, 9$ occur, each twice. The other five, $2, 6, 7, 8, 10$, are never squares modulo $11$. Does exactly half always work, and is there a fast test that does not list all the squares?

### Quadratic residues

Let $p$ be an odd prime. An integer $a$ with $p \nmid a$ is a **quadratic residue** modulo $p$ if $x^2 \equiv a \pmod p$ has a solution, and a **quadratic nonresidue** otherwise. The **Legendre symbol** is
$$\left(\frac{a}{p}\right) = \begin{cases} 1 & \text{if } p \nmid a \text{ and } a \text{ is a quadratic residue modulo } p,\\ -1 & \text{if } p \nmid a \text{ and } a \text{ is a nonresidue},\\ 0 & \text{if } p \mid a. \end{cases}$$
It depends only on $a \bmod p$.

**Theorem 1.** Let $p$ be an odd prime. Exactly $(p-1)/2$ of the residues $1, \dots, p-1$ are quadratic residues, and exactly $(p-1)/2$ are nonresidues. Every quadratic residue has exactly two square roots modulo $p$.

*Proof.* If $x^2 \equiv y^2 \pmod p$ then $p \mid (x - y)(x + y)$, so by Euclid's lemma $y \equiv x$ or $y \equiv -x$. For $x \in \{1, \dots, p - 1\}$, $x$ and $-x \equiv p - x$ are different residues because $p$ is odd. Hence the map $x \mapsto x^2$ on $\{1, \dots, p-1\}$ takes each value either twice or not at all, so it has exactly $(p-1)/2$ values, and each residue has exactly two roots. $\blacksquare$

### Euler's criterion

**Theorem 2 (Euler's criterion).** Let $p$ be an odd prime and $a$ an integer. Then
$$\left(\frac{a}{p}\right) \equiv a^{(p-1)/2} \pmod p .$$

*Proof.* If $p \mid a$ both sides are $0$. Let $p \nmid a$ and $h = (p-1)/2$. Suppose $a \equiv x^2$ is a residue. Then $a^h \equiv x^{p-1} \equiv 1$ by Fermat's little theorem. So the $h$ quadratic residues are $h$ distinct roots of the polynomial $X^h - 1$ over the field $\mathbb{Z}/p\mathbb{Z}$; since a polynomial of degree $h$ has at most $h$ roots (C11), they are *all* its roots. Now let $a$ be a nonresidue. By Fermat, $(a^h)^2 = a^{p-1} \equiv 1$, so $p \mid (a^h - 1)(a^h + 1)$ and $a^h \equiv \pm 1$ by Euclid's lemma. It is not $1$, because $a$ is not a root of $X^h - 1$. Hence $a^h \equiv -1$. $\blacksquare$

**Corollary 3.** Let $p$ be an odd prime and $a, b$ integers. (i) $\left(\frac{ab}{p}\right) = \left(\frac{a}{p}\right)\left(\frac{b}{p}\right)$. (ii) $\left(\frac{-1}{p}\right) = (-1)^{(p-1)/2}$, so $-1$ is a square modulo $p$ if and only if $p \equiv 1 \pmod 4$.

*Proof.* (i) Both sides are $\equiv (ab)^h = a^h b^h$ modulo $p$ and take values in $\{0, \pm 1\}$; two such values that are congruent modulo an odd prime $p \ge 3$ are equal (they differ by at most $2 < p$). (ii) Put $a = -1$ in Theorem 2. $\blacksquare$

In words: a product of two nonresidues is a residue, and a residue times a nonresidue is a nonresidue.

```python
def legendre(a, p):
    """Legendre symbol (a/p) for an odd prime p, by Euler's criterion."""
    r = pow(a, (p - 1) // 2, p)
    return -1 if r == p - 1 else r      # r is 0 or 1 otherwise


def sqrt_3mod4(a, p):
    """A square root of the residue a modulo a prime p = 3 (mod 4)."""
    return pow(a, (p + 1) // 4, p)


print([legendre(a, 29) for a in (3, 7, 29)], sqrt_3mod4(5, 19))
```

This prints `[-1, 1, 0] 9`: modulo $29$, $3$ is a nonresidue and $7$ a residue, and $9^2 = 81 = 4 \cdot 19 + 5$.

### Square roots

**Theorem 4.** Let $p \equiv 3 \pmod 4$ be prime and let $a$ be a quadratic residue modulo $p$. Then $x = a^{(p+1)/4}$ satisfies $x^2 \equiv a \pmod p$, and the two roots are $\pm x$.

*Proof.* Since $p \equiv 3 \pmod 4$, $(p+1)/4$ is an integer. Then $x^2 = a^{(p+1)/2} = a \cdot a^{(p-1)/2} \equiv a \cdot 1 = a$ by Euler's criterion (as $a$ is a residue). The other root is $-x$ by Theorem 1. $\blacksquare$

The hypotheses matter: the formula needs $p \equiv 3 \pmod 4$ (for $p = 13$ the exponent $(p+1)/4$ is not an integer) and $a$ a residue (for a nonresidue $x^2 \equiv -a$). For primes $p \equiv 1 \pmod 4$ one uses the Tonelli–Shanks algorithm (a practice problem).

### Composite moduli

By the Chinese remainder theorem, for coprime $m, n$ the congruence $x^2 \equiv a \pmod{mn}$ is solvable if and only if it is solvable modulo $m$ and modulo $n$. Modulo a prime power $p^k$ with $p$ odd and $p \nmid a$, solvability is the same as modulo $p$ (lifting a root; stated without proof). So for composite moduli the Legendre symbol modulo each prime factor decides. A product of residues $\left(\frac{a}{p}\right)\left(\frac{a}{q}\right) = 1$ does *not* imply that $a$ is a square modulo $pq$: next week's Jacobi symbol shows this.

@example
title: Euler's criterion in two cases
problem: Decide whether $7$ and $3$ are squares modulo $29$.
step: Here $p = 29$ and $(p - 1)/2 = 14$. Compute powers of $7$ by squaring: $7^2 = 49 \equiv 20$, $7^4 \equiv 400 \equiv 23$, $7^8 \equiv 529 \equiv 7$.
step: Then $7^{14} = 7^8 \cdot 7^4 \cdot 7^2 \equiv 7 \cdot 23 \cdot 20$. Reduce: $7 \cdot 23 = 161 \equiv 16$ and $16 \cdot 20 = 320 \equiv 1 \pmod{29}$. So $\left(\frac{7}{29}\right) = 1$; indeed $6^2 = 36 \equiv 7$.
step: For $3$: $3^2 = 9$, $3^4 = 81 \equiv 23$, $3^8 \equiv 529 \equiv 7$, so $3^{14} = 3^8 \cdot 3^4 \cdot 3^2 \equiv 7 \cdot 23 \cdot 9 \equiv 16 \cdot 9 = 144 \equiv 28 \equiv -1$.
step: So $\left(\frac{3}{29}\right) = -1$: $3$ is a nonresidue.
answer: $7$ is a quadratic residue modulo $29$ (roots $6$ and $23$), and $3$ is not.

@example
title: A square root modulo a prime that is 3 mod 4
problem: Solve $x^2 \equiv 5 \pmod{19}$.
step: Check the hypothesis: $19 = 4 \cdot 4 + 3$, so $19 \equiv 3 \pmod 4$.
step: Check that $5$ is a residue: $\left(\frac{5}{19}\right) \equiv 5^9$. We compute $5^2 = 25 \equiv 6$, $5^4 \equiv 36 \equiv 17 \equiv -2$, $5^8 \equiv 4$, so $5^9 \equiv 20 \equiv 1$.
step: By Theorem 4, $x = 5^{(19+1)/4} = 5^5 = 5^4 \cdot 5 \equiv -2 \cdot 5 = -10 \equiv 9 \pmod{19}$.
step: Check: $9^2 = 81 = 4 \cdot 19 + 5$. The other root is $-9 \equiv 10$.
answer: $x \equiv 9$ or $x \equiv 10 \pmod{19}$.

@mistakes
- Using the formula $a^{(p+1)/4}$ for a prime $p \equiv 1 \pmod 4$ (the exponent is not an integer) or for a nonresidue $a$.
- Thinking $\left(\frac{a+b}{p}\right) = \left(\frac{a}{p}\right) + \left(\frac{b}{p}\right)$. The symbol is multiplicative, not additive.
- Forgetting that a residue has two roots, $x$ and $p - x$.
- Reading $a^{(p-1)/2} \equiv -1$ as $a^{(p-1)/2} = p - 1$ in a program that has not reduced modulo $p$; always use `pow(a, (p - 1) // 2, p)`.

model:
```python
def tonelli_shanks(a, p):
    """Smaller square root of a modulo the odd prime p, or None."""
    a %= p
    if a == 0:
        return 0
    if pow(a, (p - 1) // 2, p) != 1:
        return None
    q, s = p - 1, 0
    while q % 2 == 0:
        q //= 2
        s += 1
    z = 2
    while pow(z, (p - 1) // 2, p) != p - 1:
        z += 1
    m, c = s, pow(z, q, p)
    t, r = pow(a, q, p), pow(a, (q + 1) // 2, p)
    while t != 1:
        i, t2 = 0, t
        while t2 != 1:
            t2 = t2 * t2 % p
            i += 1
        b = pow(c, 1 << (m - i - 1), p)
        m = i
        c = b * b % p
        t = t * c % p
        r = r * b % p
    return min(r, p - r)
```
hint: The invariants are $R^2 \equiv a t$ and that $c$ has order exactly $2^M$ and $t$ has order dividing $2^{M-1}$; each pass makes $M$ smaller.
solution: Invariants: (1) $R^2 \equiv at$; (2) $c$ has order exactly $2^M$; (3) the order of $t$ divides $2^{M-1}$. At the start $R^2 = a^{q+1} = a \cdot a^q$, $c = z^q$ has order $2^s$ because $z$ is a nonresidue, and $t^{2^{s-1}} = a^{(p-1)/2} = 1$. If $t \ne 1$ with order $2^i$, $0 < i < M$, then $b = c^{2^{M-i-1}}$ has order $2^{i+1}$, so $b^2$ has order $2^i$ and $b^{2^i} = -1$, hence $(tb^2)^{2^{i-1}} = t^{2^{i-1}} (b^{2^i}) = (-1)(-1) = 1$: the new $t$ has order dividing $2^{i-1}$, and $M$ becomes $i$. The new $R^2 = R^2 b^2 \equiv a t b^2$ keeps invariant (1). Since $M$ strictly decreases, the loop ends with $t = 1$ and $R^2 \equiv a$.

```python
def quadratic_roots(a, b, c, p):
    """Roots of a*x^2 + b*x + c modulo a prime p = 3 (mod 4), p not dividing a."""
    d = (b * b - 4 * a * c) % p
    inv = pow(2 * a, p - 2, p)
    if d == 0:
        return [(-b * inv) % p]
    if pow(d, (p - 1) // 2, p) != 1:
        return []
    s = pow(d, (p + 1) // 4, p)
    return sorted({(-b + s) * inv % p, (-b - s) * inv % p})
```

solution: Because $p$ is odd and $p \nmid a$, $ax^2 + bx + c \equiv 0$ is equivalent to $(2ax + b)^2 \equiv D$. If $D \equiv 0$ this forces $2ax + b \equiv 0$, one root. If $D$ is a residue, Theorem 4 gives the roots $\pm s$ of $y^2 \equiv D$ and $x = (-b \pm s)/(2a)$. If $D$ is a nonresidue there is no solution.

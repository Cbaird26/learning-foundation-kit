@review
**Week by week.**

1. *Divisibility and Euclid.* Division algorithm; $\gcd(a, b) = \gcd(b, a \bmod b)$; Bézout: $ax + by = \gcd$; the extended algorithm and its loop invariant; $ax + by = c$ is solvable if and only if $\gcd(a, b) \mid c$.
2. *Primes.* Euclid's lemma (needs a prime), the fundamental theorem of arithmetic, infinitely many primes, the sieve and trial division up to $\sqrt{n}$, divisor counts.
3. *Congruences.* Congruence respects $+$ and $\times$ but not exponents; inverses exist if and only if $\gcd(a, n) = 1$; cancellation needs $\gcd(c, n) = 1$.
4. *Linear congruences and CRT.* $ax \equiv b \pmod n$ has $g = \gcd(a, n)$ solutions if $g \mid b$; the Chinese remainder theorem for pairwise coprime moduli; two congruences are compatible if and only if the residues agree modulo the gcd.
5. *Fermat and Euler.* $a^{\varphi(n)} \equiv 1$ for $\gcd(a, n) = 1$; $\varphi$ is multiplicative on coprime arguments; square-and-multiply; Carmichael numbers.
6. *RSA.* $m^{ed} \equiv m \pmod{pq}$ for every $m$ if $p \ne q$ and $ed \equiv 1 \pmod{(p-1)(q-1)}$; knowing $\varphi(n)$ factors $n$; textbook RSA is only a toy.
7. *Primitive roots.* Orders divide $\varphi(n)$; primitive roots exist modulo every prime; discrete logarithms; baby-step giant-step.
8. *Primality and factoring.* Miller–Rabin never rejects a prime; "composite" is a proof, "probably prime" is not; Pollard's rho; Fermat's method.
9. *Quadratic residues.* Euler's criterion, multiplicativity of the Legendre symbol, $-1$ is a square if and only if $p \equiv 1 \pmod 4$, roots modulo $p \equiv 3 \pmod 4$.
10. *Reciprocity.* Gauss's lemma, the prime $2$, $\left(\frac{p}{q}\right)\left(\frac{q}{p}\right) = (-1)^{\frac{p-1}{2}\frac{q-1}{2}}$, the Jacobi symbol (value $1$ is not enough for composite moduli).
11. *Continued fractions.* Convergents, $p_kq_{k-1} - p_{k-1}q_k = (-1)^{k-1}$, $|x - p_k/q_k| < 1/q_k^2$; $\sqrt{d}$ is periodic; Pell via convergents.
12. *Arithmetic functions.* Multiplicative functions, Möbius inversion, even perfect numbers, the prime number theorem $\pi(x) \sim x/\log x$, open problems.

**Self-check.** Can you (a) state each theorem with every hypothesis and give a counterexample when one is dropped? (b) write the loop invariant of `ext_gcd` and `power_mod` from memory? (c) decide $x^2 \equiv a \pmod p$ with reciprocity and then find a root? (d) explain what each of Miller–Rabin, rho and Fermat's method proves when it succeeds and when it fails?

**Common errors.** Reducing exponents modulo $n$ instead of $\varphi(n)$; canceling non-invertible factors; using Euclid's lemma for composite numbers; forgetting $\gcd(a, n) = 1$ in Euler's theorem; treating "probably prime" as proof; flipping Legendre symbols without the sign when both are $3 \pmod 4$; stopping the Pell search at a convergent with value $-1$; and presenting computational evidence as a proof.

@exam num
prompt: Find the smallest positive integer $x$ such that $x \equiv 3^{100} \pmod{11}$ and $x \equiv 2^{50} \pmod{13}$.
answer: 56
check: next(x for x in range(1, 144) if x % 11 == pow(3, 100, 11) and x % 13 == pow(2, 50, 13))
hint: Reduce each power with Fermat's little theorem ($3^{10} \equiv 1 \pmod{11}$ and $2^{12} \equiv 1 \pmod{13}$), then solve the pair of congruences with the Chinese remainder theorem.
solution: $3^5 = 243 = 22 \cdot 11 + 1$, so $3^{100} \equiv 1 \pmod{11}$. Since $2^{12} \equiv 1 \pmod{13}$ and $50 = 4 \cdot 12 + 2$, $2^{50} \equiv 2^2 = 4 \pmod{13}$. Solve $x \equiv 1 \pmod{11}$, $x \equiv 4 \pmod{13}$: write $x = 1 + 11t$, then $11t \equiv 3 \pmod{13}$; the inverse of $11$ modulo $13$ is $6$ ($66 = 5 \cdot 13 + 1$), so $t \equiv 18 \equiv 5$ and $x = 56$ (modulo $143$).

@exam self
prompt: Let $p$ be an odd prime. Prove that the product of all quadratic residues in $\{1, \dots, p - 1\}$ is congruent to $(-1)^{(p-3)/2}$ modulo $p$. (Check the claim for $p = 7$ and $p = 13$.)
hint: Use a primitive root $g$: the residues are $g^0, g^2, \dots, g^{p-3}$. Multiply them, and use $g^{(p-1)/2} \equiv -1$.
solution: Let $g$ be a primitive root modulo $p$ (week 7) and $h = (p-1)/2$. The quadratic residues are exactly the even powers $g^{2j}$, $j = 0, \dots, h - 1$: they are squares ($g^{2j} = (g^j)^2$), they are distinct because $g^{2i} \equiv g^{2j}$ with $0 \le i < j < h$ would give $g^{2(j-i)} \equiv 1$ with $0 < 2(j-i) < p - 1$, contradicting the order of $g$, and there are exactly $h$ residues in total (week 9). Their product is $g^{2(0 + 1 + \cdots + (h-1))} = g^{h(h-1)} = \left(g^h\right)^{h-1}$. By Euler's criterion $g^h \equiv \left(\frac{g}{p}\right) = -1$ (a primitive root is not a square, since otherwise $g^h \equiv 1$ would contradict the order $p - 1 > h$). So the product is $(-1)^{h-1} = (-1)^{(p-3)/2}$. Check: $p = 7$: residues $1, 2, 4$ have product $8 \equiv 1 = (-1)^2$. $p = 13$: residues $1, 3, 4, 9, 10, 12$ have product $12960 \equiv 12 \equiv -1 = (-1)^5$.
rubric: Identifies the residues as the even powers of a primitive root and counts them correctly.
rubric: Computes the product as $(g^h)^{h-1}$ and justifies $g^h \equiv -1$ using the order of $g$ or Euler's criterion.
rubric: Simplifies the sign to $(-1)^{(p-3)/2}$ and verifies the two small cases.

@exam code
prompt: A toy RSA public key has $n = pq$ for two odd primes that are close together. Write `crack_toy_rsa(n, e, c)` that returns the plaintext $m = c^d \bmod n$ without being given $p$, $q$ or $d$. Do this by Fermat's method: start at $a = \lceil\sqrt{n}\rceil$ (use `math.isqrt` with exact integers) until $a^2 - n$ is a perfect square $b^2$, so that $p = a - b$ and $q = a + b$; then compute $\varphi(n) = (p-1)(q-1)$, the inverse $d$ of $e$ modulo $\varphi(n)$ with the extended Euclidean algorithm, and decrypt with `pow(c, d, n)`. For example, `crack_toy_rsa(3233, 17, 2183)` returns `1234`. (This is an exercise on deliberately weak toy keys.)

model:
```python
from math import isqrt


def crack_toy_rsa(n, e, c):
    """Factor n = p*q by Fermat's method, then decrypt c."""
    a = isqrt(n)
    if a * a < n:
        a += 1
    while True:
        b2 = a * a - n
        b = isqrt(b2)
        if b * b == b2:
            p, q = a - b, a + b
            break
        a += 1
    phi = (p - 1) * (q - 1)
    r0, r1, t0, t1 = phi, e % phi, 0, 1
    while r1:
        k = r0 // r1
        r0, r1, t0, t1 = r1, r0 - k * r1, t1, t0 - k * t1
    d = t0 % phi
    return pow(c, d, n)
```
hint: Fermat's method finds the factorization whose factors are closest to $\sqrt{n}$, which is exactly the situation of close primes. The inverse of $e$ modulo $\varphi(n)$ comes from the extended Euclidean algorithm.
solution: If $n = pq$ with $p < q$ then $a = (p + q)/2$ and $b = (q - p)/2$ satisfy $a^2 - b^2 = n$, and the search from $\lceil \sqrt{n} \rceil$ reaches $a$ after $a - \lceil \sqrt{n} \rceil$ steps, which is tiny when $q - p$ is small. Given $p, q$, the private exponent is the inverse of $e$ modulo $(p-1)(q-1)$, and Theorem 1 of week 6 shows that $c^d \equiv m$ for the message $m$ with $c = m^e \bmod n$.

@article
Is $17$ a square modulo $101$? Euler's criterion needs a modular power. Reciprocity gives a shortcut: because $101 \equiv 1 \pmod 4$, the question "is $17$ a square modulo $101$?" has the same answer as "is $101$ a square modulo $17$?", and $101 \equiv 16 = 4^2 \pmod{17}$, so yes. Quadratic reciprocity, which Gauss was the first to prove (published in 1801), relates the symbols $\left(\frac{p}{q}\right)$ and $\left(\frac{q}{p}\right)$ for distinct odd primes. This week proves it completely.

### Gauss's lemma

Let $p$ be an odd prime, $h = (p - 1)/2$, and $a$ an integer with $p \nmid a$. For $k = 1, \dots, h$ let $r_k \in \{1, \dots, p - 1\}$ be the remainder of $ka$ modulo $p$, and let $\mu$ be the number of $k$ with $r_k > p/2$.

**Lemma 1 (Gauss).** $\left(\frac{a}{p}\right) = (-1)^{\mu}$.

*Proof.* Each $ka$ is congruent to $\varepsilon_k m_k$ with $\varepsilon_k = \pm 1$ and $m_k \in \{1, \dots, h\}$ (take $m_k = r_k$, $\varepsilon_k = 1$ if $r_k \le h$, and $m_k = p - r_k$, $\varepsilon_k = -1$ otherwise), and $\varepsilon_k = -1$ for exactly $\mu$ values of $k$. The $m_k$ are distinct: if $m_j = m_k$ then $ja \equiv \pm ka$, so $j \equiv \pm k \pmod p$ ($p \nmid a$), which for $1 \le j, k \le h$ forces $j = k$. So $\{m_1, \dots, m_h\} = \{1, \dots, h\}$. Multiplying the congruences $ka \equiv \varepsilon_k m_k$ gives $a^h h! \equiv (-1)^\mu h! \pmod p$. Since $p \nmid h!$, cancel it and apply Euler's criterion. $\blacksquare$

**Theorem 2 (the prime 2).** For an odd prime $p$, $\left(\frac{2}{p}\right) = 1$ if $p \equiv \pm 1 \pmod 8$ and $-1$ if $p \equiv \pm 3 \pmod 8$.

*Proof.* With $a = 2$, $r_k = 2k$ for $k \le h$, and $2k > p/2$ exactly when $k > p/4$. So $\mu = h - \lfloor p/4 \rfloor$. Write $p = 8m + j$: for $j = 1$: $h = 4m$, $\lfloor p/4 \rfloor = 2m$, $\mu = 2m$ (even); $j = 3$: $h = 4m + 1$, $\lfloor p/4 \rfloor = 2m$, $\mu = 2m + 1$ (odd); $j = 5$: $h = 4m + 2$, $\lfloor p/4 \rfloor = 2m + 1$, $\mu = 2m + 1$ (odd); $j = 7$: $h = 4m + 3$, $\lfloor p/4 \rfloor = 2m + 1$, $\mu = 2m + 2$ (even). Apply Lemma 1. $\blacksquare$

### The law of quadratic reciprocity

**Lemma 3.** If $a$ is odd and $p \nmid a$, then $\mu \equiv \sum_{k=1}^{h} \lfloor ka/p \rfloor \pmod 2$.

*Proof.* Write $ka = p\lfloor ka/p \rfloor + r_k$ and sum over $k = 1, \dots, h$. Let $T = 1 + \dots + h$ and $F = \sum \lfloor ka/p \rfloor$. The $r_k$ are either some $m_k \le h$ or $p - m_k$; as the $m_k$ run over $1, \dots, h$ once, $\sum r_k = T + p\mu - 2S$, where $S$ is the sum of the $m_k$ with $r_k > p/2$. So $aT = pF + T + p\mu - 2S$, that is $(a - 1)T = p(F + \mu) - 2S$. The left side is even (as $a$ is odd), and so is $2S$, so $p(F + \mu)$ is even; as $p$ is odd, $F + \mu$ is even. $\blacksquare$

**Theorem 4 (quadratic reciprocity).** Let $p \ne q$ be odd primes. Then
$$\left(\frac{p}{q}\right)\left(\frac{q}{p}\right) = (-1)^{\frac{p-1}{2}\cdot\frac{q-1}{2}} .$$
Equivalently, $\left(\frac{p}{q}\right) = \left(\frac{q}{p}\right)$ unless $p \equiv q \equiv 3 \pmod 4$, in which case $\left(\frac{p}{q}\right) = -\left(\frac{q}{p}\right)$.

*Proof.* Let $h = (p-1)/2$ and $l = (q-1)/2$. Consider the $hl$ pairs $(x, y)$ of integers with $1 \le x \le h$, $1 \le y \le l$. Neither $qx = py$ is possible (it would give $p \mid x$ with $0 < x < p$). Pairs with $py < qx$: for each $x$, $y$ ranges over $1 \le y \le \lfloor qx/p \rfloor$ (this bound is at most $l$ since $qx/p < q/2$). Pairs with $qx < py$: for each $y$, $x$ ranges over $1 \le x \le \lfloor py/q \rfloor$ (at most $h$). Hence
$$\sum_{x=1}^{h} \left\lfloor \frac{qx}{p} \right\rfloor + \sum_{y=1}^{l} \left\lfloor \frac{py}{q} \right\rfloor = hl .$$
By Lemmas 1 and 3 (with $a = q$ modulo $p$, and $a = p$ modulo $q$, both odd), $\left(\frac{q}{p}\right) = (-1)^{\sum \lfloor qx/p \rfloor}$ and $\left(\frac{p}{q}\right) = (-1)^{\sum \lfloor py/q \rfloor}$. Multiply and use the displayed identity. $\blacksquare$

### The Jacobi symbol

For an odd positive integer $n = p_1^{e_1} \cdots p_r^{e_r}$ define the **Jacobi symbol** $\left(\frac{a}{n}\right) = \prod_i \left(\frac{a}{p_i}\right)^{e_i}$, and $\left(\frac{a}{1}\right) = 1$. The following properties are stated **without proof**; they follow from the Legendre case by multiplying over the prime factors. The symbol is multiplicative in $a$ and in $n$ and depends only on $a \bmod n$; $\left(\frac{2}{n}\right) = 1$ if $n \equiv \pm 1 \pmod 8$ and $-1$ if $n \equiv \pm 3 \pmod 8$; and for odd positive coprime $m, n$, $\left(\frac{m}{n}\right)\left(\frac{n}{m}\right) = (-1)^{\frac{m-1}{2}\cdot\frac{n-1}{2}}$.

They give an algorithm that never factors: strip factors of $2$, flip with reciprocity, and reduce, exactly like the Euclidean algorithm.

```python
def jacobi(a, n):
    """Jacobi symbol (a/n) for odd n >= 1."""
    a %= n
    result = 1
    while a != 0:
        while a % 2 == 0:
            a //= 2
            if n % 8 in (3, 5):
                result = -result
        a, n = n, a                      # reciprocity
        if a % 4 == 3 and n % 4 == 3:
            result = -result
        a %= n
    return result if n == 1 else 0


print(jacobi(17, 101), jacobi(2, 15))
```

This prints `1 1`. Be careful with the second value: $\left(\frac{2}{15}\right) = \left(\frac{2}{3}\right)\left(\frac{2}{5}\right) = (-1)(-1) = 1$, yet $2$ is **not** a square modulo $15$ (it is not a square modulo $3$). For a prime $n$, the symbol $-1$ proves that $a$ is a nonresidue and $+1$ proves it is a residue; for composite $n$ only $-1$ is conclusive.

@example
title: Deciding a congruence by reciprocity
problem: Is $x^2 \equiv 38 \pmod{103}$ solvable? ($103$ is prime.)
step: Factor the numerator: $38 = 2 \cdot 19$, so $\left(\frac{38}{103}\right) = \left(\frac{2}{103}\right)\left(\frac{19}{103}\right)$.
step: Since $103 = 8 \cdot 13 - 1 \equiv -1 \pmod 8$, Theorem 2 gives $\left(\frac{2}{103}\right) = 1$.
step: For $19$: both $19$ and $103$ are $\equiv 3 \pmod 4$, so Theorem 4 gives $\left(\frac{19}{103}\right) = -\left(\frac{103}{19}\right)$.
step: Reduce: $103 = 5 \cdot 19 + 8$, so $\left(\frac{103}{19}\right) = \left(\frac{8}{19}\right) = \left(\frac{2}{19}\right)^3 = \left(\frac{2}{19}\right) = -1$ because $19 \equiv 3 \pmod 8$. Hence $\left(\frac{19}{103}\right) = +1$.
step: Multiply: $\left(\frac{38}{103}\right) = 1 \cdot 1 = 1$.
answer: Yes, $x^2 \equiv 38 \pmod{103}$ has two solutions.

@example
title: A Jacobi symbol with a composite bottom
problem: Compute $\left(\frac{105}{317}\right)$, then compute it again with the Jacobi algorithm by thinking in terms of $\left(\frac{317}{105}\right)$.
step: Since $317 \equiv 1 \pmod 4$, reciprocity gives $\left(\frac{105}{317}\right) = \left(\frac{317}{105}\right)$ (the Jacobi symbol is allowed here, with $105$ odd and coprime to $317$).
step: Reduce: $317 = 3 \cdot 105 + 2$, so $\left(\frac{317}{105}\right) = \left(\frac{2}{105}\right)$.
step: Since $105 = 8 \cdot 13 + 1 \equiv 1 \pmod 8$, $\left(\frac{2}{105}\right) = 1$.
step: Check by factoring: $\left(\frac{105}{317}\right) = \left(\frac{3}{317}\right)\left(\frac{5}{317}\right)\left(\frac{7}{317}\right) = \left(\frac{2}{3}\right)\left(\frac{2}{5}\right)\left(\frac{2}{7}\right) = (-1)(-1)(1) = 1$.
answer: The symbol is $1$, and since $317$ is prime, $105$ is a quadratic residue modulo $317$.

@mistakes
- Applying reciprocity to symbols whose top or bottom is even, or to a pair that is not coprime. Both arguments must be odd and coprime (and positive for the Jacobi symbol).
- Forgetting the sign when both numbers are $\equiv 3 \pmod 4$.
- Concluding that $a$ is a square modulo a composite $n$ from $\left(\frac{a}{n}\right) = 1$: $\left(\frac{2}{15}\right) = 1$, but $2$ is not a square modulo $15$.
- Flipping a symbol whose top is even. Reciprocity needs both numbers odd, so first remove the factors of $2$ with the rule for $2$, then flip, then reduce.

def square_roots_count(a, primes):
    """Number of x mod prod(primes) with x*x = a, for distinct odd primes."""
    count = 1
    for p in primes:
        r = pow(a, (p - 1) // 2, p)
        symbol = -1 if r == p - 1 else r      # 0 when p divides a
        count *= 1 + symbol
    return count
```

solution: Roots modulo $n$ correspond bijectively to tuples of roots modulo the $p_i$ (week 4), so the count is the product of the numbers of roots modulo each prime. ```python
from math import gcd


def jacobi_false_positives(n):
    """Units a with Jacobi symbol 1 that are not squares modulo n."""
    def jacobi(a, m):
        a %= m
        result = 1
        while a != 0:
            while a % 2 == 0:
                a //= 2
                if m % 8 in (3, 5):
                    result = -result
            a, m = m, a
            if a % 4 == 3 and m % 4 == 3:
                result = -result
            a %= m
        return result if m == 1 else 0

    squares = {x * x % n for x in range(n)}
    return sum(1 for a in range(1, n)
               if gcd(a, n) == 1 and jacobi(a, n) == 1 and a not in squares)
```
hint: Compute the set of squares once; for prime $n$ the Jacobi symbol is the Legendre symbol, so the answer is $0$.
solution: For a prime $n$, symbol $1$ means residue (Euler's criterion), so there are no false positives. For a composite $n$ the Jacobi symbol is a product of Legendre symbols, and two factors of $-1$ give $+1$ without making $a$ a square modulo either prime, as for $n = 15$ and $a = 2, 8$. For $n = 9$ the symbol is $\left(\frac{a}{3}\right)^2 = 1$ for every unit, but only $1, 4, 7$ are squares modulo $9$.

```python
def sqrt_mod_pq(a, p, q):
    """All square roots of a modulo pq for primes p, q = 3 (mod 4)."""
    def roots(prime):
        r = a % prime
        if r == 0:
            return [0]
        if pow(r, (prime - 1) // 2, prime) != 1:
            return []
        s = pow(r, (prime + 1) // 4, prime)
        return [s, prime - s]

    n = p * q
    cp = q * pow(q, p - 2, p)       # = 1 mod p, = 0 mod q
    cq = p * pow(p, q - 2, q)       # = 0 mod p, = 1 mod q
    return sorted({(rp * cp + rq * cq) % n for rp in roots(p) for rq in roots(q)})
```
hint: A root modulo $pq$ is determined by its residues modulo $p$ and $q$; the combination $r_p \cdot q q^{-1} + r_q \cdot p p^{-1}$ reduces to $r_p$ modulo $p$ and to $r_q$ modulo $q$.
solution: By the Chinese remainder theorem $x^2 \equiv a \pmod{pq}$ is equivalent to the pair $x^2 \equiv a \pmod p$ and $\pmod q$, and each factor has the roots from Theorem 4 of week 9 (one root $0$ if the prime divides $a$, none for a nonresidue). Combining every pair of roots gives all solutions: four when both symbols are $1$.

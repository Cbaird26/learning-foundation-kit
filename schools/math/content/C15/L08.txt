@article
Week 5 gave a tempting test: if $a^{n-1} \not\equiv 1 \pmod n$ then $n$ is composite, and a prime always passes. Does passing prove primality? No, because of Carmichael numbers like $561$. Is there a test that composites fail with good probability, whatever $n$ is? Yes: the Miller–Rabin test (Miller 1976, Rabin 1980). And once you know that $n$ is composite, how do you find a factor without trying all divisors? This week answers both, and also shows what makes a toy RSA key weak.

### Strong probable primes: the Miller–Rabin test

Let $n \ge 3$ be odd. Write $n - 1 = 2^s t$ with $t$ odd. For a base $a$ with $2 \le a \le n - 2$ consider the chain
$$a^t,\quad a^{2t},\quad a^{4t},\quad \dots,\quad a^{2^{s}t} = a^{n-1} \pmod n,$$
in which each term is the square of the previous one. We say $n$ is a **strong probable prime to base $a$** if $a^t \equiv 1 \pmod n$ or $a^{2^i t} \equiv -1 \pmod n$ for some $0 \le i < s$. A base for which $n$ fails is a **witness** for the compositeness of $n$.

**Theorem 1.** If $n$ is an odd prime, then $n$ is a strong probable prime to every base $a$ with $n \nmid a$. Equivalently: if some base is a witness, then $n$ is composite.

*Proof.* Since $n$ is prime and $n \nmid a$, Fermat's little theorem gives $a^{2^s t} = a^{n-1} \equiv 1$. The last term of the chain is $1$. If $a^t \equiv 1$ we are done. Otherwise let $j \ge 1$ be the least index with $a^{2^j t} \equiv 1$, and put $y = a^{2^{j-1}t}$. Then $y^2 \equiv 1$ and $y \not\equiv 1$ by the choice of $j$. Hence $n \mid (y-1)(y+1)$ and $n \nmid y - 1$, so by Euclid's lemma $n \mid y + 1$, that is $y \equiv -1$ with $j - 1 < s$. $\blacksquare$

So "composite" answers are certain, while "probably prime" answers are not. The reverse needs a deeper fact, which we state **without proof** (Rabin, 1980): if $n$ is odd and composite, at most $(n-1)/4$ of the bases $a \in \{1, \dots, n-1\}$ fail to be witnesses. Therefore if $k$ bases are chosen independently and uniformly at random, a composite $n$ is declared "probably prime" with probability at most $4^{-k}$. A fixed list of bases is not random: $3215031751 = 151 \cdot 751 \cdot 28351$ is composite but passes the strong test for the bases $2, 3, 5, 7$.

```python
def is_strong_probable_prime(n, a):
    """Strong test of an odd n >= 5 to base a (2 <= a <= n - 2)."""
    t, s = n - 1, 0
    while t % 2 == 0:
        t //= 2
        s += 1
    x = pow(a, t, n)
    if x == 1 or x == n - 1:
        return True
    for _ in range(s - 1):
        x = x * x % n
        if x == n - 1:
            return True
    return False


def miller_rabin(n, bases):
    """False: n is certainly composite. True: n passed every supplied base."""
    if n < 2:
        return False
    if n < 4:
        return True
    if n % 2 == 0:
        return False
    for a in bases:
        a %= n
        if a in (0, 1, n - 1):
            continue                      # such a base tells us nothing
        if not is_strong_probable_prime(n, a):
            return False
    return True


print(miller_rabin(2047, [2]), miller_rabin(2047, [2, 3]),
      miller_rabin(104729, [2, 3, 5]))
```

The output is `True False True`: $2047 = 23 \cdot 89$ fools base $2$ but not base $3$, and $104729$ is prime. The random choices (the bases) are an argument, as the course requires, so you can reproduce any run.

### Pollard's rho method

To split a composite $n$, iterate $x_{i+1} = x_i^2 + c \bmod n$ from a start $x_0$. If $p$ is a prime factor of $n$, the sequence modulo $p$ takes at most $p$ values, so it repeats after about $\sqrt{p}$ terms (a birthday-paradox *heuristic*, not proved here), usually long before the sequence modulo $n$ does. A repeat modulo $p$, that is $x_i \equiv x_j \pmod p$, means $p \mid x_i - x_j$, and then $\gcd(|x_i - x_j|, n)$ is a multiple of $p$. Floyd's trick compares $x_i$ with $x_{2i}$ so that only two variables are stored.

```python
from math import gcd


def pollard_rho(n, c, x0):
    """Return a divisor d of n with 1 < d < n, or None if this (c, x0) fails."""
    x = y = x0 % n
    d = 1
    while d == 1:
        x = (x * x + c) % n          # tortoise: one step
        y = (y * y + c) % n          # hare: two steps
        y = (y * y + c) % n
        d = gcd(abs(x - y), n)
    return d if d != n else None


print(pollard_rho(10403, 1, 2))
```

This prints `101` (and $10403 = 101 \cdot 103$).

**Theorem 2.** For $n \ge 2$, `pollard_rho` terminates, and when it returns an integer $d$ then $d \mid n$ and $1 < d < n$.

*Proof.* The sequence $x_i \bmod n$ takes finitely many values and each term determines the next, so it is eventually periodic: there are $\mu \ge 0$ and $\lambda \ge 1$ with $x_i = x_{i+\lambda}$ for $i \ge \mu$. For any $i \ge \mu$ that is a multiple of $\lambda$ we get $x_{2i} = x_{i+i} = x_i$ (as $i$ is a multiple of the period), so $\gcd(|x_i - x_{2i}|, n) = \gcd(0, n) = n \ne 1$. Hence the loop stops at the latest at such an $i$. At exit $d = \gcd(\cdot, n)$ is a divisor of $n$, and the function returns it only if $d \ne n$; $d \ne 1$ by the loop condition. $\blacksquare$

When it returns `None`, a different $c$ or $x_0$ is tried; all such choices are supplied by the caller.

### Fermat's factorization method

If $n = a^2 - b^2 = (a - b)(a + b)$, then $n$ is factored. For an odd $n = pq$ with $p \le q$, take $a = (p + q)/2$ and $b = (q - p)/2$. Fermat's method tries $a = \lceil \sqrt{n} \rceil, \lceil \sqrt{n} \rceil + 1, \dots$ until $a^2 - n$ is a perfect square. It finds the factorization whose factors are closest to $\sqrt{n}$ and is fast exactly when $p$ and $q$ are close: a toy RSA key with close primes falls at once. When $p$ and $q$ are far apart it can be slower than trial division.

@example
title: A witness for 561
problem: Show that $n = 561$ is composite using the Miller–Rabin test with base $2$, and extract a factor.
step: $n - 1 = 560 = 2^4 \cdot 35$, so $s = 4$ and $t = 35$. Compute $2^{35} \bmod 561 = 263$.
step: Square repeatedly: $263^2 = 69169 \equiv 166$, $166^2 = 27556 \equiv 67$, $67^2 = 4489 \equiv 1 \pmod{561}$.
step: The chain $263, 166, 67, 1$ never shows $1$ at the start or $-1 \equiv 560$ before the end. So $2$ is a witness, and by Theorem 1, $561$ is composite.
step: Moreover $67^2 \equiv 1$ with $67 \not\equiv \pm 1$ is a nontrivial square root of $1$, so $561 \mid (67 - 1)(67 + 1)$ but divides neither factor; $\gcd(66, 561) = 33$ is a proper divisor.
answer: $561$ is composite, and $\gcd(66, 561) = 33$ is a proper factor ($561 = 33 \cdot 17$).

@example
title: Pollard's rho on a small number
problem: Run `pollard_rho(91, 1, 2)` by hand.
step: Start with $x = y = 2$ and $f(x) = x^2 + 1$.
step: One round: $x = f(2) = 5$ and $y = f(f(2)) = f(5) = 26$.
step: Compute $d = \gcd(|5 - 26|, 91) = \gcd(21, 91) = 7$.
step: Since $1 < 7 < 91$, the function returns $7$, and $91 = 7 \cdot 13$. The sequences modulo $7$ are $2, 5, 5, \dots$ (as $26 \equiv 5$), which already repeat, though modulo $91$ they do not.

@mistakes
- Reading "probably prime" as a proof. Only "composite" is certain; $2047$ passes base $2$.
- Using a base $a \equiv 0, \pm 1 \pmod n$: such a base passes for every $n$ and tells you nothing.
- Believing a fixed list of bases proves primality for all $n$: $3215031751$ passes $2, 3, 5, 7$.
- Treating a `None` result of Pollard's rho as "$n$ is prime": it only means this choice of $c$ and $x_0$ failed.

```python
def mr_witnesses(n, bases):
    """Bases that prove the odd number n composite (strong test fails)."""
    t, s = n - 1, 0
    while t % 2 == 0:
        t //= 2
        s += 1
    found = []
    for a in bases:
        r = a % n
        if r in (0, 1, n - 1):
            continue
        x = pow(r, t, n)
        passed = x in (1, n - 1)
        for _ in range(s - 1):
            if passed:
                break
            x = x * x % n
            passed = x == n - 1
        if not passed:
            found.append(a)
    return found
```
hint: Factor $n - 1 = 2^s t$ once, then run the chain $a^t, a^{2t}, \dots$ for each base, looking for $1$ at the start or $-1$ before the end.
solution: The test for a base is exactly the definition: success if the first term is $\pm 1$ appropriately or some earlier term equals $-1$. Collecting the failures lists the witnesses. The two examples with $3215031751$ show that four bases can all fail to detect a composite while a fifth does.

```python
from math import isqrt


def fermat_factor(n):
    """Factor odd n = (a - b)(a + b); the factors closest to sqrt(n)."""
    a = isqrt(n)
    if a * a < n:
        a += 1
    while True:
        b2 = a * a - n
        b = isqrt(b2)
        if b * b == b2:
            return a - b, a + b
        a += 1
```
hint: For an odd $n = uv$ with $u \le v$ the loop must stop at $a = (u + v)/2$ at the latest.
solution: If $a^2 - n = b^2$ then $n = (a - b)(a + b)$. The loop terminates for odd $n$ because $a = (n + 1)/2$ gives $a^2 - n = ((n - 1)/2)^2$, which yields the trivial factorization $(1, n)$. The first $a$ that works corresponds to the factor pair closest to $\sqrt{n}$, which is why $45$ gives $(5, 9)$. For $3027 = 3 \cdot 1009$ the loop is long: the method is slow when the factors are far apart.

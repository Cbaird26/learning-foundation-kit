@article
How many divisors does $420$ have, and what do they add up to? Do the answers for $420 = 4 \cdot 105$ follow from those for $4$ and $105$? This week studies such **arithmetic functions**, functions $f\colon \mathbb{N} \to \mathbb{Z}$ defined by number-theoretic properties, and ends with the biggest question of the subject: how are the primes distributed among the integers?

### Multiplicative functions

An arithmetic function $f$ is **multiplicative** if $f(1) = 1$ and $f(mn) = f(m)f(n)$ whenever $\gcd(m, n) = 1$. Examples: $\tau(n)$, the number of positive divisors; $\sigma(n)$, their sum; and Euler's $\varphi$ (week 5). The **Möbius function** is $\mu(1) = 1$, $\mu(n) = (-1)^r$ if $n$ is a product of $r$ distinct primes, and $\mu(n) = 0$ if some square $p^2$ divides $n$.

**Lemma 1.** If $\gcd(m, n) = 1$, then $(d_1, d_2) \mapsto d_1 d_2$ is a bijection from pairs of divisors ($d_1 \mid m$, $d_2 \mid n$) to the divisors of $mn$.

*Proof.* By unique factorization (week 2), $m$ and $n$ have no prime in common. A divisor $d$ of $mn$ has each prime $p$ with exponent at most the exponent of $p$ in $mn$, which is its exponent in $m$ or in $n$ (not both). Let $d_1$ be the product of the prime powers of $d$ at primes dividing $m$, and $d_2$ the rest. Then $d_1 \mid m$, $d_2 \mid n$, $d = d_1 d_2$, and by uniqueness of factorization this pair is the only one with product $d$. $\blacksquare$

**Theorem 2.** If $f$ is multiplicative, so is $F(n) = \sum_{d \mid n} f(d)$.

*Proof.* For coprime $m, n$, Lemma 1 gives $F(mn) = \sum_{d_1 \mid m,\, d_2 \mid n} f(d_1 d_2) = \sum_{d_1 \mid m,\, d_2 \mid n} f(d_1)f(d_2)$, because $\gcd(d_1, d_2) = 1$; this equals $F(m)F(n)$. $\blacksquare$

Taking $f = 1$ and $f(n) = n$ shows that $\tau$ and $\sigma$ are multiplicative, with $\tau(p^k) = k + 1$ and $\sigma(p^k) = 1 + p + \dots + p^k = (p^{k+1} - 1)/(p - 1)$. Also $\mu$ is multiplicative (a quick check from the definition), and $\sum_{d \mid n} \varphi(d) = n$ (week 7).

```python
def arithmetic_functions(n):
    """Return (tau, sigma, phi, mu) of an integer n >= 1, by factoring."""
    factors, m, p = {}, n, 2
    while p * p <= m:
        while m % p == 0:
            factors[p] = factors.get(p, 0) + 1
            m //= p
        p += 1
    if m > 1:
        factors[m] = factors.get(m, 0) + 1
    tau = sigma = phi = 1
    mu = 1
    for p, k in factors.items():
        tau *= k + 1
        sigma *= (p ** (k + 1) - 1) // (p - 1)
        phi *= p ** (k - 1) * (p - 1)
        mu *= -1 if k == 1 else 0
    return tau, sigma, phi, mu


print(arithmetic_functions(420))
```

### Möbius inversion

**Theorem 3.** For every integer $n \ge 1$, $\sum_{d \mid n} \mu(d) = 1$ if $n = 1$ and $0$ if $n > 1$.

*Proof.* Let $n > 1$ have distinct prime divisors $p_1, \dots, p_r$ ($r \ge 1$). Only squarefree divisors contribute, and they are the products of subsets of $\{p_1, \dots, p_r\}$, so the sum is $\sum_{k=0}^{r} \binom{r}{k}(-1)^k = (1 - 1)^r = 0$. $\blacksquare$

**Theorem 4 (Möbius inversion).** Let $f, g$ be arithmetic functions with $g(n) = \sum_{d \mid n} f(d)$ for all $n \ge 1$. Then $f(n) = \sum_{d \mid n} \mu(d)\, g(n/d)$ for all $n \ge 1$.

*Proof.* $\sum_{d \mid n} \mu(d) g(n/d) = \sum_{d \mid n} \mu(d) \sum_{e \mid n/d} f(e) = \sum_{e \mid n} f(e) \sum_{d \mid n/e} \mu(d)$, where we exchanged the order of summation (the pairs $(d, e)$ with $de \mid n$ are the same in both). By Theorem 3 the inner sum is $1$ if $e = n$ and $0$ otherwise, leaving $f(n)$. $\blacksquare$

Applied to $\sum_{d \mid n} \varphi(d) = n$, it gives $\varphi(n) = \sum_{d \mid n} \mu(d)\, n/d$.

### Perfect numbers

A positive integer $n$ is **perfect** if $\sigma(n) = 2n$ (it equals the sum of its proper divisors): $6 = 1 + 2 + 3$ and $28$ are perfect.

**Theorem 5 (Euclid–Euler).** If $2^p - 1$ is prime, then $2^{p-1}(2^p - 1)$ is perfect (Euclid). Conversely, every even perfect number has this form (Euler).

*Proof of the first part.* Let $M = 2^p - 1$ be prime; it is odd, so $\gcd(2^{p-1}, M) = 1$ and $\sigma(2^{p-1}M) = \sigma(2^{p-1})\sigma(M) = (2^p - 1)(M + 1) = M \cdot 2^p = 2 \cdot 2^{p-1}M$. The converse is a practice problem. $\blacksquare$

### How are the primes distributed?

Let $\pi(x)$ be the number of primes at most $x$. Computation suggests $\pi(x)$ is close to $x/\log x$:

| $x$ | $\pi(x)$ | $x/\log x$ | ratio |
|---|---|---|---|
| $10^2$ | $25$ | $21.7$ | $1.151$ |
| $10^4$ | $1229$ | $1085.7$ | $1.132$ |
| $10^6$ | $78498$ | $72382.4$ | $1.084$ |

The **prime number theorem** (conjectured from tables around 1800 and proved independently by Hadamard and by de la Vallée Poussin in 1896; it is stated here without proof, because the proof needs complex analysis) says $\pi(x) \sim x/\log x$, meaning $\pi(x)/(x/\log x) \to 1$ as $x \to \infty$. It does *not* say the difference tends to $0$ (it grows). The ratio converges very slowly, and a better approximation is the logarithmic integral $\int_2^x dt/\log t$.

### Open problems

The following are open as of November 2026 (records and the status of problems change, so check current sources): the **Riemann hypothesis** (a statement about zeros of a complex function that is equivalent to a strong bound on the error in the prime number theorem, and one of the seven Millennium Prize Problems announced by the Clay Mathematics Institute in 2000, of which only the Poincaré conjecture has been solved); **Goldbach's conjecture** (every even integer greater than $2$ is a sum of two primes); the **twin prime conjecture** (infinitely many primes $p$ with $p + 2$ prime); and the **Collatz conjecture**. Known results include Zhang's theorem (2013) that there are infinitely many pairs of primes with bounded gap, improved by Maynard and the Polymath project to gap at most $246$, and the Green–Tao theorem (2004) that the primes contain arbitrarily long arithmetic progressions. The largest known prime, as of November 2026, is the Mersenne prime $2^{136279841} - 1$ with $41{,}024{,}320$ decimal digits, found in 2024 by the Great Internet Mersenne Prime Search. No odd perfect number is known.

```python
def dirichlet_convolve(f, g, n):
    """(f * g)(m) = sum over d | m of f(d) g(m / d), for m = 1..n."""
    h = [0] * (n + 1)
    for d in range(1, n + 1):
        for m in range(d, n + 1, d):
            h[m] += f[d] * g[m // d]
    return h
```
hint: Every pair $(d, e)$ with $de = m \le n$ arises as $d$ and the multiple $m = de$ of $d$.
solution: The double loop visits each pair $(d, m)$ with $d \mid m \le n$ exactly once and adds $f(d)g(m/d)$ to $h[m]$. With $g = 1$ this is the divisor sum, with $f = \mu$ and $g = 1$ it gives Theorem 3, and the function equal to $1$ at $1$ and $0$ elsewhere acts as an identity. The cost is about $n \log n$ operations.

```python
def mobius_invert(g):
    """f(n) = sum over d | n of mu(d) * g(n // d), for n = 1..len(g) - 1."""
    n_max = len(g) - 1

    def mu(k):
        result, p = 1, 2
        while p * p <= k:
            if k % p == 0:
                k //= p
                if k % p == 0:
                    return 0
                result = -result
            p += 1
        return -result if k > 1 else result

    f = [0] * (n_max + 1)
    for d in range(1, n_max + 1):
        md = mu(d)
        if md == 0:
            continue
        for n in range(d, n_max + 1, d):
            f[n] += md * g[n // d]
    return f
```
hint: Loop over $d$, skip it when $\mu(d) = 0$, and add $\mu(d)\,g(n/d)$ to $f[n]$ for each multiple $n$ of $d$.
solution: The formula of Theorem 4 is a convolution of $\mu$ with $g$. The first two tests invert $\sigma$ (giving $n$) and the identity (giving $\varphi$, since $\sum_{d \mid n}\varphi(d) = n$); the third inverts $\tau$ (giving the constant function $1$). A divisor-sum sequence is always a sum of the values of $f$ on divisors, so inverting and re-summing returns the original data.

```python
def amicable_pairs(limit):
    """All amicable pairs (a, b), a < b <= limit."""
    sigma = [0] * (limit + 1)
    for d in range(1, limit + 1):
        for m in range(d, limit + 1, d):
            sigma[m] += d
    pairs = []
    for a in range(2, limit + 1):
        b = sigma[a] - a
        if a < b <= limit and sigma[b] - b == a:
            pairs.append((a, b))
    return pairs
```

```python
from math import isqrt


def solve_negative_pell(d):
    """Smallest positive solution of x^2 - d y^2 = -1, or None."""
    a0 = isqrt(d)
    m, den, a = 0, 1, a0
    p1, q1, p2, q2 = 1, 0, 0, 1
    while True:
        p, q = a * p1 + p2, a * q1 + q2
        value = p * p - d * q * q
        if value == -1:
            return p, q
        if value == 1:
            return None
        p1, q1, p2, q2 = p, q, p1, q1
        m = den * a - m
        den = (d - m * m) // den
        a = (a0 + m) // den
```
hint: By Theorem 4 of week 11, $p_k^2 - dq_k^2 = (-1)^{k-1}d_{k+1}$, so the value $-1$ can only occur at an even index when $d_{k+1} = 1$, which is the end of a period of odd length.

@article
What is the last digit of $7^{2026}$? Computing the number is hopeless, but the last digit only depends on the remainder on division by $10$, and remainders behave well under multiplication. Powers of $7$ end in $7, 9, 3, 1, 7, \dots$, repeating with period $4$. Since $2026 = 4 \cdot 506 + 2$, the last digit is the second in the cycle, namely $9$. This week turns that argument into a theory.

### Congruence

**Definition.** Let $n \ge 1$ be an integer. We say $a$ is **congruent** to $b$ modulo $n$, written $a \equiv b \pmod{n}$, if $n \mid a - b$. Equivalently $a$ and $b$ leave the same remainder on division by $n$. Congruence modulo $n$ is reflexive, symmetric and transitive (if $n \mid a - b$ and $n \mid b - c$, then $n \mid a - c$), so it splits $\mathbb{Z}$ into $n$ **residue classes**; the set of classes is $\mathbb{Z}/n\mathbb{Z}$. In Python, `a % n` for $n > 0$ is the representative of $a$ in $\{0, \dots, n-1\}$, even for negative `a`.

**Theorem 1.** Let $n \ge 1$ and suppose $a \equiv a'$ and $b \equiv b' \pmod{n}$. Then $a + b \equiv a' + b'$ and $ab \equiv a'b' \pmod{n}$.

*Proof.* Write $a' = a + sn$ and $b' = b + tn$ for integers $s, t$. Then $a' + b' = a + b + (s + t)n$, and $a'b' = ab + (at + bs + stn)n$. $\blacksquare$

By induction, $a \equiv b \pmod{n}$ implies $a^k \equiv b^k \pmod{n}$ for every integer $k \ge 0$, and $f(a) \equiv f(b)$ for every polynomial $f$ with integer coefficients. So $\mathbb{Z}/n\mathbb{Z}$ is a commutative ring (see C10). For the opening puzzle: $7^4 = 2401 \equiv 1 \pmod{10}$, so $7^{2026} = (7^4)^{506} \cdot 7^2 \equiv 1 \cdot 49 \equiv 9 \pmod{10}$.

Be careful: Theorem 1 reduces the *base*, not the exponent. From $2 \equiv 7 \pmod 5$ we may conclude $2^3 \equiv 7^3$, but $3 \equiv 8 \pmod 5$ does not give $2^3 \equiv 2^8$: here $2^3 = 8 \equiv 3$ while $2^8 = 256 \equiv 1$.

### Divisibility tests

Since $10 \equiv 1 \pmod 9$, a number $d_k \cdots d_1 d_0$ in decimal satisfies $\sum d_i 10^i \equiv \sum d_i \pmod 9$: a number is congruent to its digit sum modulo $9$ (and modulo $3$). Since $10 \equiv -1 \pmod{11}$, it is congruent to the alternating sum $d_0 - d_1 + d_2 - \cdots$ modulo $11$.

### Inverses

**Theorem 2.** Let $n \ge 1$ and $a$ an integer. There is an integer $b$ with $ab \equiv 1 \pmod{n}$ if and only if $\gcd(a, n) = 1$. The residue of $b$ modulo $n$ is then unique.

*Proof.* If $ab \equiv 1$, then $ab - 1 = nk$ for some $k$, so $ab - nk = 1$ and every common divisor of $a$ and $n$ divides $1$; thus $\gcd(a, n) = 1$. Conversely, if $\gcd(a, n) = 1$, Bézout's identity gives $ax + ny = 1$, so $ax \equiv 1$. For uniqueness, if $ab \equiv ab' \equiv 1$ then $b \equiv b(ab') = (ab)b' \equiv b'$. $\blacksquare$

The proof is an algorithm: run the extended Euclidean algorithm on $(n, a \bmod n)$, tracking only the coefficient of $a$.

```python
def mod_inverse(a, n):
    """Return b in range(n) with a*b % n == 1; ValueError if none exists."""
    r0, r1 = n, a % n          # invariant: r_i is congruent to t_i * a mod n
    t0, t1 = 0, 1
    while r1 != 0:
        q = r0 // r1
        r0, r1 = r1, r0 - q * r1
        t0, t1 = t1, t0 - q * t1
    if r0 != 1:
        raise ValueError("a is not invertible modulo n")
    return t0 % n


print(mod_inverse(7, 40))
```

It prints `23`, and $7 \cdot 23 = 161 = 4 \cdot 40 + 1$. The invariant $r_i \equiv t_i a \pmod n$ holds at the start ($n \equiv 0 \cdot a$ and $a \bmod n \equiv 1 \cdot a$) and is preserved by the update since both sides change by the same multiple. At the end $r_0 = \gcd(n, a \bmod n) = \gcd(a, n)$, so if it is $1$ then $t_0 a \equiv 1$.

### Cancellation

**Theorem 3 (cancellation).** If $ac \equiv bc \pmod{n}$ and $\gcd(c, n) = 1$, then $a \equiv b \pmod{n}$.

*Proof.* Multiply by the inverse $c'$ of $c$ from Theorem 2: $a \equiv a(cc') = (ac)c' \equiv (bc)c' \equiv b$. $\blacksquare$

The hypothesis is needed: $2 \cdot 1 \equiv 2 \cdot 4 \pmod 6$ but $1 \not\equiv 4 \pmod 6$. Division by a non-invertible number loses information; the general statement is in the practice items.

@example
title: Digit sums and alternating sums
problem: Find the remainders of $n = 3141592653$ on division by $9$ and by $11$ without dividing.
step: Modulo $9$ the number is congruent to its digit sum: $3 + 1 + 4 + 1 + 5 + 9 + 2 + 6 + 5 + 3 = 39$.
step: Reduce again: $39 = 4 \cdot 9 + 3$, so $n \equiv 3 \pmod 9$.
step: Modulo $11$ use the alternating sum from the right: $3 - 5 + 6 - 2 + 9 - 5 + 1 - 4 + 1 - 3 = 1$, because $10^i \equiv (-1)^i \pmod{11}$.
step: Check with a calculator: $3141592653 = 285599332 \cdot 11 + 1$ and $n \bmod 9 = 3$.
answer: $n \equiv 3 \pmod 9$ and $n \equiv 1 \pmod{11}$.

@example
title: An inverse by the Euclidean algorithm
problem: Find the inverse of $17$ modulo $105$.
step: $\gcd(17, 105) = 1$ is needed first. Divide: $105 = 6 \cdot 17 + 3$, $17 = 5 \cdot 3 + 2$, $3 = 1 \cdot 2 + 1$. The last nonzero remainder is $1$, so the inverse exists by Theorem 2.
step: Work backward: $1 = 3 - 2$.
step: Substitute $2 = 17 - 5 \cdot 3$: $1 = 3 - (17 - 5 \cdot 3) = 6 \cdot 3 - 17$.
step: Substitute $3 = 105 - 6 \cdot 17$: $1 = 6(105 - 6 \cdot 17) - 17 = 6 \cdot 105 - 37 \cdot 17$.
step: So $17 \cdot (-37) \equiv 1 \pmod{105}$, and $-37 \equiv 68$. Check: $17 \cdot 68 = 1156 = 11 \cdot 105 + 1$.
answer: The inverse of $17$ modulo $105$ is $68$.

@mistakes
- Reducing an exponent modulo $n$: $2^8 \not\equiv 2^3 \pmod 5$ although $8 \equiv 3 \pmod 5$.
- Cancelling a factor that is not invertible: $2 \cdot 1 \equiv 2 \cdot 4 \pmod 6$ does not give $1 \equiv 4$.
- Assuming a nonzero residue always has an inverse: $4$ has no inverse modulo $6$ because $\gcd(4, 6) = 2$. Inverses exist exactly for residues coprime to $n$.
- Forgetting that $a \bmod n$ may be written with a negative representative: $-3 \equiv 4 \pmod 7$.

```python
def power_pattern(a, n):
    """(tail, period) of the sequence a^k mod n for k = 1, 2, ..."""
    first_seen = {}
    x = a % n
    k = 1
    while x not in first_seen:
        first_seen[x] = k
        x = (x * a) % n
        k += 1
    return first_seen[x] - 1, k - first_seen[x]
```
hint: Record the position at which each value first appears; the first repeated value tells you where the cycle starts.
solution: There are only $n$ residues, so a value must repeat. Because the next term depends only on the current one (multiply by $a$ modulo $n$), the sequence from the first repeat on is periodic. If the repeated value first appeared at position $s$ and appears again at position $k$, the tail has $s - 1$ terms and the period is $k - s$.

model:
```python
def isbn10_valid(s):
    """True if s is a valid ISBN-10 (weights 1..10, modulus 11)."""
    if len(s) != 10:
        return False
    total = 0
    for i, ch in enumerate(s, start=1):
        if ch.isdigit() and ch in "0123456789":
            value = int(ch)
        elif ch == "X" and i == 10:
            value = 10
        else:
            return False
        total += i * value
    return total % 11 == 0
```
hint: Convert each character to its value, rejecting `X` anywhere but last, then test the weighted sum modulo $11$.
solution: Check the length and the characters first, then compute $\sum i\,d_i$ and test divisibility by $11$. The modulus is prime, so a single wrong digit changes the sum by $i\,\delta$ with $i$ not divisible by $11$ and $0 < |\delta| \le 10$, which is never $\equiv 0 \pmod{11}$: every single-digit error is detected.

```python
def mod_of_digits(s, m):
    """Value of the decimal string s modulo m, by Horner's rule."""
    r = 0
    for ch in s:
        r = (r * 10 + int(ch)) % m
    return r
```

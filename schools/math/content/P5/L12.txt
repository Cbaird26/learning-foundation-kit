@article
The reason compact operators matter is that they turn differential and integral equations into the linear algebra of the previous lesson. An equation of the second kind, $u - \mu Tu = g$, with $T$ compact, behaves like a finite matrix equation: it has a unique solution for every right side, or it has a finite-dimensional family of obstructions. A differential equation such as $-u'' = f$ becomes $u = Gf$, with $G$ the compact inverse of an unbounded differential operator.

### The Neumann series

**Theorem 1 (Neumann series).** Let $X$ be a Banach space and $A \in B(X)$ with $\|A\| < 1$. Then $I - A$ is invertible in $B(X)$, $(I - A)^{-1} = \sum_{n\ge0}A^n$ (norm convergent), and $\|(I - A)^{-1}\| \le 1/(1 - \|A\|)$.

*Proof.* $\|A^n\| \le \|A\|^n$, so $\sum\|A^n\| < \infty$ and the series $S = \sum A^n$ converges in the Banach space $B(X)$ (Lesson 2, Theorem 2; Lesson 1, Theorem 1). With $S_N = \sum_{n\le N}A^n$ we have $(I - A)S_N = S_N(I - A) = I - A^{N+1} \to I$, so $(I - A)S = S(I - A) = I$. The norm bound is the geometric series. $\blacksquare$

Consequently, if $\|\mu T\| = q < 1$, the equation $u - \mu Tu = g$ has the unique solution $u = \sum\mu^nT^ng$, and the iteration $u_0 = 0$, $u_{k+1} = g + \mu Tu_k$ gives $u_k = \sum_{n<k}\mu^nT^ng$ with $\|u - u_k\| \le q^k\|g\|/(1 - q)$. **Volterra equations** need no smallness: if $k$ is continuous on $0 \le t \le x \le 1$ with $|k| \le M$ and $(Vf)(x) = \int_0^xk(x,t)f(t)\,dt$, then induction on $n$ gives $|V^nf(x)| \le \frac{M^nx^n}{n!}\|f\|_\infty$ (the step is $\int_0^xM^n\frac{t^n}{n!}\,dt = M^n\frac{x^{n+1}}{(n+1)!}$), so $\|V^n\| \le M^n/n!$ and $\sum|\mu|^n\|V^n\| < \infty$ for every $\mu$. Hence $u - \mu Vu = g$ has a unique solution in $C[0,1]$ for every $\mu$ and every $g$.

### The Fredholm alternative (compact self-adjoint case)

**Theorem 2.** Let $T$ be a compact self-adjoint operator on a Hilbert space $H$ and $\lambda \ne 0$. Then $(T - \lambda)u = g$ has a solution if and only if $g \perp \ker(T - \lambda)$. In that case the solutions form a coset of $\ker(T - \lambda)$, a finite-dimensional space. In particular, either $T - \lambda$ is invertible, or $\ker(T - \lambda) \ne \{0\}$ and $\lambda$ is an eigenvalue.

*Proof.* Use the spectral expansion $Tx = \sum\lambda_n\langle x,e_n\rangle e_n$ and the projection $Q$ onto $\ker T$ (Lesson 11), and write $c_n(x) = \langle x,e_n\rangle$. Then $(T - \lambda)u = g$ means: $(\lambda_n - \lambda)c_n(u) = c_n(g)$ for all $n$ and $-\lambda Qu = Qg$. If $\lambda_n \ne \lambda$ for all $n$ the unique solution is $u = \sum\frac{c_n(g)}{\lambda_n - \lambda}e_n - \lambda^{-1}Qg$, bounded by Lesson 11. If $\lambda = \lambda_n$ for $n$ in a finite set $F$, the equations for $n \in F$ read $0 = c_n(g)$, which says exactly that $g \perp \operatorname{span}\{e_n : n \in F\} = \ker(T - \lambda)$; when this holds, the $c_n(u)$ for $n \in F$ are free, and the remaining coefficients are determined as before. $\blacksquare$

For the equation $u - \mu Tu = g$ with $\mu \ne 0$ this is Theorem 2 with $\lambda = 1/\mu$: the solution is $u = \sum_n\frac{c_n(g)}{1 - \mu\lambda_n}e_n + Qg$ when $\mu\lambda_n \ne 1$ for all $n$. (The general Fredholm alternative holds for every compact operator, not only self-adjoint ones; the proof is longer and is quoted.)

### A boundary-value problem

Consider $-u'' = f$ on $[0,1]$ with $u(0) = u(1) = 0$. Let $G(x,y) = y(1 - x)$ for $y \le x$ and $G(x,y) = x(1 - y)$ for $y \ge x$, that is, $G(x,y) = \min(x,y)(1 - \max(x,y))$: continuous and symmetric. For $f \in C[0,1]$ the function $u(x) = \int_0^1G(x,y)f(y)\,dy$ is the unique $C^2$ solution (practice problem). The operator $T_Gf = \int Gf$ is compact (Lesson 10) and self-adjoint (symmetric real kernel).

**Theorem 3.** $T_G$ has eigenvalues $1/(n\pi)^2$ for $n = 1, 2, \dots$ with eigenfunctions $s_n(x) = \sqrt2\sin(n\pi x)$, which form an orthonormal basis of $L^2[0,1]$; there are no other eigenvalues, and $\ker T_G = \{0\}$. Hence for $f \in L^2[0,1]$, $T_Gf = \sum_{n\ge1}\frac{\langle f,s_n\rangle}{(n\pi)^2}s_n$.

*Proof.* Orthonormality is the computation $2\int_0^1\sin(m\pi x)\sin(n\pi x)\,dx = \delta_{mn}$. Completeness: extend $f \in L^2[0,1]$ to an odd function on $[-1,1]$; by Lesson 4, Theorem 4 (rescaled to $[-1,1]$) the odd function has an expansion in $e^{in\pi x}$ whose even part vanishes, i.e. a sine series, so $\{\sin n\pi x\}$ is complete. The function $v = s_n/(n\pi)^2$ satisfies $-v'' = s_n$ and $v(0) = v(1) = 0$, so by the uniqueness statement $T_Gs_n = v$: $s_n$ is an eigenfunction with eigenvalue $(n\pi)^{-2}$. By Lesson 11, Theorem 3, $H = \ker T_G \oplus \overline{\operatorname{span}}\{\text{eigenvectors for nonzero eigenvalues}\}$; the span of the $s_n$ is already dense, so $\ker T_G = \{0\}$ and every eigenvector for a nonzero eigenvalue is orthogonal to all $s_n$ with a different eigenvalue, hence there is no other eigenvalue. The expansion is the spectral theorem. $\blacksquare$

So the solution of $-u'' = f$ is $u = \sum\langle f,s_n\rangle(n\pi)^{-2}s_n$, and the equation $u - \mu T_Gu = g$ has solution $u = \sum\frac{\langle g,s_n\rangle}{1 - \mu/(n\pi)^2}s_n$ unless $\mu = (m\pi)^2$ for some $m$, where it is solvable iff $g \perp s_m$.

### Discretization and iteration

The midpoint matrix of Lesson 10 approximates $T$ by an $N \times N$ matrix $A$ with $A_{ij} = K(x_i,x_j)/N$, and $u - \mu Tu = g$ becomes $(I - \mu A)u = g$ at the nodes. If $\|\mu A\|_\infty < 1$ the Neumann iteration below solves it.

```python
def neumann_iterate(A, g, steps):
    """Run u <- g + A u for the given number of steps, starting at u = 0."""
    n = len(g)
    u = [0.0] * n
    for _ in range(steps):
        u = [g[i] + sum(A[i][j] * u[j] for j in range(n)) for i in range(n)]
    return u
```

The errors of a discretization (the Nyström method) and the error of an iteration are different things: the first is $O(1/N^2)$ for smooth kernels, the second is geometric in the number of steps.

@example
title: An eigenfunction expansion solution
problem: Solve $u - 4T_Gu = \sin(\pi x)$ in $L^2[0,1]$, where $T_G$ is the Green's operator of $-d^2/dx^2$ with Dirichlet conditions.
step: By Theorem 3, $T_G$ has eigenfunctions $s_n = \sqrt2\sin(n\pi x)$ with eigenvalues $\lambda_n = (n\pi)^{-2}$, and $\ker T_G = \{0\}$. The equation is $u - \mu T_Gu = g$ with $\mu = 4$ and $g = \sin(\pi x) = s_1/\sqrt2$.
step: $\mu = 4$ is not of the form $(m\pi)^2$ (since $\pi^2 \approx 9.87 > 4$), so $1 - \mu\lambda_n \ne 0$ for all $n$ and the solution is unique: $u = \sum\frac{\langle g,s_n\rangle}{1 - 4/(n\pi)^2}s_n$.
step: Only $n = 1$ contributes since $\langle g,s_n\rangle = 0$ for $n \ge 2$: $u = \frac{1}{1 - 4/\pi^2}\cdot g = \frac{\pi^2}{\pi^2 - 4}\sin(\pi x)$.
step: Check: $T_G\sin(\pi x) = \sin(\pi x)/\pi^2$, so $u - 4T_Gu = \frac{\pi^2}{\pi^2 - 4}\big(1 - \frac4{\pi^2}\big)\sin(\pi x) = \sin(\pi x)$. Numerically $\pi^2/(\pi^2 - 4) \approx 1.6892$.
answer: $u(x) = \dfrac{\pi^2}{\pi^2 - 4}\sin(\pi x)$.

@mistakes
- Applying the Neumann series when $\|A\| \ge 1$ without checking that the series converges (it can still converge if $\|A^n\|^{1/n} < 1$, as for Volterra operators).
- Forgetting the obstruction in the resonant case $\mu = (m\pi)^2$: then the equation is solvable only when $g \perp s_m$, and the solution is not unique.
- Mixing up the equations $u - \mu Tu = g$ and $(T - \lambda)u = g$: they correspond via $\lambda = 1/\mu$, with a factor $-\mu$.
- Believing that a discretization error and a truncation of the Neumann series are the same: they converge for different reasons and at different rates.

```python
def neumann_solve(A, g, tol):
    """Solve u = g + A u by iteration from u = 0; return (u, iterations)."""
    n = len(g)
    if max(sum(abs(a) for a in row) for row in A) >= 1:
        raise ValueError("maximum row sum must be below 1")
    u = [0.0] * n
    k = 0
    while True:
        k += 1
        new = [g[i] + sum(A[i][j] * u[j] for j in range(n)) for i in range(n)]
        change = max(abs(a - b) for a, b in zip(new, u))
        u = new
        if change < tol:
            return u, k
```
hint: Compute the new vector from the old one completely before replacing it, and record the largest coordinate change.
solution: The condition on the row sums is $\|A\|_\infty < 1$, which makes the Neumann series $\sum A^n$ converge, so the loop terminates. Starting from $u_0 = 0$ gives $u_1 = g$, so $k = 2$ for the zero matrix (the first iterate changes by $\max|g|$, the second by $0$). Updating `u` in place coordinate by coordinate would turn the method into Gauss–Seidel and change the iterates and the count. The stopping rule bounds the error: $\|u - u_k\| \le \frac{q}{1-q}\max_i|u_k[i] - u_{k-1}[i]|$ with $q = \|A\|_\infty$, so a small last change certifies the solution.

model:
```python
import math


def nystrom_top(K, N, steps):
    """Dominant eigenvalue of the midpoint (Nystrom) matrix of a kernel."""
    xs = [(i + 0.5) / N for i in range(N)]
    A = [[K(x, y) / N for y in xs] for x in xs]

    def mul(v):
        return [sum(a * b for a, b in zip(row, v)) for row in A]

    v = [1.0] * N
    for _ in range(steps):
        w = mul(v)
        norm = math.sqrt(sum(x * x for x in w))
        v = [x / norm for x in w]
    Av = mul(v)
    return sum(a * b for a, b in zip(Av, v))
```
hint: Build the matrix once, then repeat multiply and normalize; divide each kernel value by `N` so that the sums approximate integrals.
solution: The midpoint rule turns $(Tf)(x_i) = \int K(x_i,y)f(y)\,dy$ into $\sum_jK(x_i,x_j)f(x_j)/N$, so the matrix eigenvalues approximate those of $T$. Forgetting the factor $1/N$ would return $N$ times too much, and the constant-kernel test catches it. The dominant eigenvalue of $\min(x,y)$ is $4/\pi^2 \approx 0.4053$, that of $\min(x,y)(1 - \max(x,y))$ is $1/\pi^2$. These agree with the numerics up to the $O(1/N^2)$ discretization error and the power-method error; neither is a proof.

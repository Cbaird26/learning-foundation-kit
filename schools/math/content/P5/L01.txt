@article
Qualifying exams in analysis return again and again to one question: *is this space complete?* In $\mathbb{R}^n$ the answer is always yes, which is why a first course never needs to ask. In the function spaces of analysis it is the first thing to check, and the answer depends on the norm, not only on the set. The same vector space $C[0,1]$ is complete under the sup norm and incomplete under the $L^1$ norm. This course assumes measure theory (P1), so $L^p$ spaces and the dominated convergence theorem are available.

### Definitions

Let $X$ be a vector space over $\mathbb{K} = \mathbb{R}$ or $\mathbb{C}$. A **norm** is a function $\|\cdot\|\colon X \to [0,\infty)$ with (i) $\|x\| = 0$ only for $x = 0$, (ii) $\|\lambda x\| = |\lambda|\,\|x\|$, (iii) $\|x + y\| \le \|x\| + \|y\|$. A sequence $(x_n)$ is **Cauchy** if for every $\varepsilon > 0$ there is $N$ with $\|x_m - x_n\| < \varepsilon$ for all $m, n \ge N$. A normed space is a **Banach space** if every Cauchy sequence converges (in the norm) to an element of $X$.

Standard examples: $\ell^p$ for $1 \le p \le \infty$; $c_0$, the sequences tending to $0$, with the sup norm; $L^p(\mu)$ for $1 \le p \le \infty$ (the Riesz–Fischer theorem, from P1); $C(K)$ for compact $K$ with $\|f\|_\infty = \max|f|$. A subspace of a Banach space is a Banach space in the induced norm if and only if it is closed (a limit of a Cauchy sequence in the subspace lies in $X$, and lies in the subspace exactly when the subspace is closed).

### The series criterion

**Theorem 1.** A normed space $X$ is a Banach space if and only if every absolutely summable series converges: $\sum \|y_k\| < \infty$ implies that $\sum y_k$ converges in $X$.

*Proof.* ($\Rightarrow$) The partial sums $s_N = \sum_{k \le N} y_k$ satisfy $\|s_M - s_N\| \le \sum_{k=N+1}^{M} \|y_k\|$, which is small for large $N$, so $(s_N)$ is Cauchy and converges. ($\Leftarrow$) Let $(x_n)$ be Cauchy. Choose $n_1 < n_2 < \cdots$ with $\|x_m - x_n\| < 2^{-k}$ for $m, n \ge n_k$. Put $y_1 = x_{n_1}$ and $y_k = x_{n_k} - x_{n_{k-1}}$ for $k \ge 2$. Then $\sum \|y_k\| \le \|x_{n_1}\| + \sum_{k \ge 2} 2^{-(k-1)} < \infty$, so $\sum y_k = \lim x_{n_k}$ exists. A Cauchy sequence with a convergent subsequence converges to the same limit. $\blacksquare$

### Completeness of $C[0,1]$

**Theorem 2.** $C[0,1]$ with $\|f\|_\infty = \max_t |f(t)|$ is a Banach space.

*Proof.* Let $(f_n)$ be Cauchy. For each $t$, $(f_n(t))$ is Cauchy in $\mathbb{K}$, so converges to some $f(t)$. Given $\varepsilon > 0$ take $N$ with $|f_m(t) - f_n(t)| < \varepsilon$ for all $t$ and all $m, n \ge N$; letting $m \to \infty$ gives $|f(t) - f_n(t)| \le \varepsilon$ for all $t$ and $n \ge N$. So $f_n \to f$ uniformly, and a uniform limit of continuous functions is continuous (the $\varepsilon/3$ argument). Hence $f \in C[0,1]$ and $\|f_n - f\|_\infty \to 0$. $\blacksquare$

### What goes wrong without completeness

The norm matters. On $C[0,1]$ put $\|f\|_1 = \int_0^1 |f|$. Let $f_n(t) = 0$ for $t \le \tfrac12$, $f_n(t) = n(t - \tfrac12)$ for $\tfrac12 \le t \le \tfrac12 + \tfrac1n$, and $f_n(t) = 1$ after that. For $m > n$ one has $f_n \le f_m$ and $\|f_m - f_n\|_1 = \tfrac{1}{2n} - \tfrac{1}{2m}$, so the sequence is Cauchy. If $f_n \to f$ in $\|\cdot\|_1$ with $f$ continuous, then $\int_0^{1/2}|f| = 0$ forces $f = 0$ on $[0,\tfrac12]$, and $\int_{1/2+\delta}^{1}|f - 1| = 0$ for every $\delta > 0$ forces $f = 1$ on $(\tfrac12, 1]$: no continuous $f$ does both. So $(C[0,1], \|\cdot\|_1)$ is not complete; its completion is $L^1[0,1]$. Likewise the polynomials are dense in $(C[0,1], \|\cdot\|_\infty)$ by the Weierstrass approximation theorem but are not all of $C[0,1]$, so they are not closed and not complete.

### Finite dimensions

**Theorem 3.** On a finite-dimensional vector space any two norms are equivalent, i.e. $c\|x\|_a \le \|x\|_b \le C\|x\|_a$ for some $0 < c \le C$. Hence every finite-dimensional normed space is a Banach space and every finite-dimensional subspace of a normed space is closed.

*Proof.* Fix a basis $e_1, \dots, e_n$ and put $\|\sum a_i e_i\|_* = \sum |a_i|$. For any norm $N$, $N(x) \le \max_i N(e_i)\,\|x\|_*$, so $N$ is continuous for $\|\cdot\|_*$. The sphere $S = \{\|x\|_* = 1\}$ is compact (it is the image of the compact $\ell^1$-sphere of $\mathbb{K}^n$), so $N$ attains a minimum $c > 0$ on $S$ (positive because $N(x) = 0$ only at $x = 0$). By homogeneity $c\|x\|_* \le N(x) \le C\|x\|_*$. Two norms are each equivalent to $\|\cdot\|_*$, hence to each other. $\blacksquare$

The theorem is false in infinite dimensions, and that is the origin of nearly everything in this course.

### Truncations in Python

A computer holds only finitely many terms, so it can test the *definition* of Cauchy on a list but never prove completeness. The function below tests the Cauchy condition on a list of vectors with the sup norm.

```python
def sup_dist(a, b):
    """Sup-norm distance between two equal-length lists."""
    return max(abs(x - y) for x, y in zip(a, b))


def is_eps_cauchy_from(seq, start, eps):
    """True if all terms from index start on lie within eps of each other."""
    tail = seq[start:]
    return all(sup_dist(a, b) < eps for a in tail for b in tail)
```

For $x_n = 1/n$ this reports success for large `start` and any $\varepsilon$, as it should, but the same code would also report success on the first $10^6$ terms of a sequence that later jumps.

@example
title: $c_0$ is a Banach space
problem: Let $c_0$ be the space of real sequences $x = (x_1, x_2, \dots)$ with $x_k \to 0$, with the norm $\|x\|_\infty = \sup_k |x_k|$. Prove that $c_0$ is complete.
step: Plan: $\ell^\infty$ (all bounded sequences, sup norm) is complete, so it is enough to show that $c_0$ is a closed subspace of $\ell^\infty$. First, $\ell^\infty$ is complete: if $(x^{(n)})$ is Cauchy, each coordinate $(x^{(n)}_k)_n$ is Cauchy in $\mathbb{R}$, with limit $x_k$; the argument of Theorem 2 (let $m \to \infty$ in $|x^{(m)}_k - x^{(n)}_k| < \varepsilon$) gives $\sup_k |x_k - x^{(n)}_k| \le \varepsilon$ for $n \ge N$, so $x$ is bounded and $x^{(n)} \to x$.
step: $c_0$ is a subspace of $\ell^\infty$: a sequence tending to $0$ is bounded, and sums and scalar multiples of sequences tending to $0$ tend to $0$.
step: $c_0$ is closed. Let $x^{(n)} \in c_0$ with $x^{(n)} \to x$ in $\ell^\infty$. Given $\varepsilon > 0$ choose $n$ with $\|x - x^{(n)}\|_\infty < \varepsilon/2$, then $K$ with $|x^{(n)}_k| < \varepsilon/2$ for $k \ge K$.
step: For $k \ge K$, $|x_k| \le |x_k - x^{(n)}_k| + |x^{(n)}_k| < \varepsilon$. So $x_k \to 0$ and $x \in c_0$.
step: A closed subspace of a Banach space is complete, so $c_0$ is a Banach space. $\blacksquare$
answer: $c_0$ is a closed subspace of the Banach space $\ell^\infty$, hence complete.

@example
title: $C^1[0,1]$ with its natural norm is complete
problem: On $C^1[0,1]$ (real functions with continuous derivative) put $\|f\|_{C^1} = \|f\|_\infty + \|f'\|_\infty$. Prove that this is a Banach space.
step: Let $(f_n)$ be Cauchy in $\|\cdot\|_{C^1}$. Since $\|f_m - f_n\|_\infty \le \|f_m - f_n\|_{C^1}$ and $\|f_m' - f_n'\|_\infty \le \|f_m - f_n\|_{C^1}$, both $(f_n)$ and $(f_n')$ are Cauchy in $C[0,1]$ with the sup norm.
step: By Theorem 2 there are $f, g \in C[0,1]$ with $f_n \to f$ and $f_n' \to g$ uniformly.
step: Pass to the limit in the fundamental theorem of calculus, $f_n(t) = f_n(0) + \int_0^t f_n'(s)\,ds$. Uniform convergence lets the limit pass through the integral, so $f(t) = f(0) + \int_0^t g(s)\,ds$ for every $t$.
step: Since $g$ is continuous, the fundamental theorem of calculus gives $f \in C^1[0,1]$ with $f' = g$.
step: Then $\|f_n - f\|_{C^1} = \|f_n - f\|_\infty + \|f_n' - g\|_\infty \to 0$, so $(f_n)$ converges in $C^1[0,1]$. $\blacksquare$
answer: Every $\|\cdot\|_{C^1}$-Cauchy sequence converges in $C^1[0,1]$.

@mistakes
- Saying a space "is complete" without naming the norm: $C[0,1]$ is complete in $\|\cdot\|_\infty$ and not in $\|\cdot\|_1$.
- Checking that $\|x_{n+1} - x_n\| \to 0$ and calling the sequence Cauchy: the partial sums of $\sum 1/k$ have this property and diverge. The condition must hold for all pairs $m, n \ge N$.
- Forgetting the last step of the completeness proof: pointwise limits exist, but you must also show the limit lies in the space (continuous, bounded, tends to $0$) and that convergence is in the norm.
- Assuming a dense subspace is complete or that a closed and bounded set is compact: both fail in infinite dimensions.

prompt: Let $X$ be a Banach space, $Y \subseteq X$ a closed subspace, and $\|x + Y\| = \inf_{y \in Y}\|x + y\|$ the quotient norm on $X/Y$. Prove that $X/Y$ is a Banach space. (You may assume that $\|\cdot\|$ is a norm on $X/Y$; the key point is completeness.)
hint: Use Theorem 1: take an absolutely summable series in $X/Y$ and lift each term to $X$.
hint: Choose representatives $x_n$ with $\|x_n\| < \|\xi_n\| + 2^{-n}$, and note that the quotient map $\pi$ satisfies $\|\pi(z)\| \le \|z\|$.
solution: Let $\pi\colon X \to X/Y$ be the quotient map; $\|\pi(z)\| \le \|z\|$ by definition of the infimum (take $y = 0$). Let $\xi_n \in X/Y$ with $\sum \|\xi_n\| < \infty$. By the definition of the infimum choose $x_n \in X$ with $\pi(x_n) = \xi_n$ and $\|x_n\| < \|\xi_n\| + 2^{-n}$. Then $\sum \|x_n\| \le \sum \|\xi_n\| + 1 < \infty$, so by Theorem 1 (the direction "Banach implies series converge") $x = \sum x_n$ exists in $X$. The partial sums satisfy $\|\pi(x) - \sum_{n \le N}\xi_n\| = \|\pi(x - \sum_{n \le N} x_n)\| \le \|x - \sum_{n \le N}x_n\| \to 0$, so $\sum \xi_n = \pi(x)$ converges in $X/Y$. By Theorem 1 (the direction "series converge implies Banach") $X/Y$ is complete.

rubric: Uses completeness of $X$ to sum the lifted series and the bound $\|\pi(z)\| \le \|z\|$ to show the series in $X/Y$ converges to $\pi(x)$.

prompt: Prove that $C^1[0,1]$ with the sup norm $\|f\|_\infty$ (not the $C^1$ norm) is not complete.
hint: Look for $C^1$ functions that converge uniformly to a continuous function with a corner, such as $|t - \tfrac12|$.
hint: Try $f_n(t) = \sqrt{(t - \tfrac12)^2 + \tfrac1n}$ and bound $f_n(t) - |t - \tfrac12|$.

Then $0 \le f_n(t) - a = \dfrac{1/n}{f_n(t) + a} \le \dfrac{1/n}{\sqrt{1/n}} = \dfrac{1}{\sqrt n}$, since $f_n(t) \ge \sqrt{1/n}$. But $g$ is not differentiable at $\tfrac12$, a contradiction. So the Cauchy sequence $(f_n)$ has no limit in $C^1[0,1]$.

model:
```python
def cauchy_index(seq, eps):
    """Least N with all pairwise sup-distances among seq[N:] below eps."""
    def dist(a, b):
        return max(abs(x - y) for x, y in zip(a, b))

    for start in range(len(seq)):
        tail = seq[start:]
        if all(dist(a, b) < eps for a in tail for b in tail):
            return start
    return len(seq) - 1
```
hint: For each candidate `N`, check all pairs in the tail, not just neighbors.
solution: Try `N = 0, 1, 2, ...` and return the first for which every pair in `seq[N:]` is within `eps`. Checking only consecutive differences would give `0` for the sequence with steps of $0.06$, although its first and last terms are $0.54$ apart; that is the difference between "$\|x_{n+1} - x_n\|$ small" and the Cauchy condition. A finite list always has a trivial answer, which is why a program can illustrate but never prove that a sequence is Cauchy.

@quiz ms
prompt: Which of these functions $N\colon \mathbb{R}^2 \to [0,\infty)$ are norms on $\mathbb{R}^2$?
choice*: $N(x,y) = \max(|x|, 2|y|)$
choice*: $N(x,y) = \sqrt{x^2 + xy + y^2}$
choice*: $N(x,y) = |x| + |y| + |x + y|$
choice: $N(x,y) = \sqrt{|x|} + \sqrt{|y|}$
choice: $N(x,y) = |x - y|$
hint: Check definiteness, homogeneity $N(\lambda v) = |\lambda| N(v)$ and the triangle inequality separately for each candidate.
solution: The maximum of two seminorms that vanish together only at $0$ is a norm. $x^2 + xy + y^2 = (x + y/2)^2 + \tfrac34 y^2$ is a positive definite quadratic form, so its square root is an inner product norm. $|x| + |y| + |x+y|$ is a sum of seminorms and the first two already make it definite. $\sqrt{|x|} + \sqrt{|y|}$ is not homogeneous: $N(4,0) = 2 \ne 4N(1,0)$. $|x - y|$ vanishes at $(1,1) \ne 0$.

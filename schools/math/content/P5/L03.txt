@article
A closest-point problem is behind almost every approximation question: which line is closest to a point, which polynomial is closest to $e^t$ in mean square, which function in a closed class is closest to a given signal? In a Hilbert space the answer always exists and is unique, and it is characterized by an orthogonality condition. This lesson proves that, and it is the reason Hilbert spaces are the best-behaved infinite-dimensional spaces.

### Inner products

An **inner product** on a complex vector space $H$ is a map $\langle\cdot,\cdot\rangle\colon H \times H \to \mathbb{C}$, linear in the first variable, with $\langle y, x\rangle = \overline{\langle x, y\rangle}$ and $\langle x, x\rangle > 0$ for $x \ne 0$. Put $\|x\| = \langle x, x\rangle^{1/2}$.

**Theorem 1 (Cauchy–Schwarz).** $|\langle x, y\rangle| \le \|x\|\,\|y\|$ for all $x, y$, with equality if and only if $x, y$ are linearly dependent. Consequently $\|\cdot\|$ is a norm.

*Proof.* If $y = 0$ both sides vanish. Otherwise, for every scalar $t$, $0 \le \|x - ty\|^2 = \|x\|^2 - 2\operatorname{Re}\big(\bar t\langle x, y\rangle\big) + |t|^2\|y\|^2$. Take $t = \langle x, y\rangle/\|y\|^2$: this gives $0 \le \|x\|^2 - |\langle x, y\rangle|^2/\|y\|^2$. Equality forces $x = ty$. The triangle inequality follows from $\|x + y\|^2 = \|x\|^2 + 2\operatorname{Re}\langle x, y\rangle + \|y\|^2 \le (\|x\| + \|y\|)^2$. $\blacksquare$

The norm obeys the **parallelogram law** $\|x + y\|^2 + \|x - y\|^2 = 2\|x\|^2 + 2\|y\|^2$. The Jordan–von Neumann theorem (stated without proof here) says that a norm comes from an inner product if and only if it satisfies this law. A **Hilbert space** is an inner product space that is complete in the induced norm. Examples: $\mathbb{C}^n$, $\ell^2$, $L^2(\mu)$. The norms of $\ell^p$ and $L^p$ for $p \ne 2$ fail the parallelogram law: take $x = e_1$, $y = e_2$ in $\ell^p$, so the left side is $2\cdot 2^{2/p}$ and the right side is $4$.

### The nearest-point theorem

**Theorem 2.** Let $H$ be a Hilbert space, $C \subseteq H$ a nonempty, closed, convex set, and $x \in H$. Then there is exactly one $p \in C$ with $\|x - p\| = \operatorname{dist}(x, C) = \inf_{c \in C}\|x - c\|$.

*Proof.* Let $d$ be the infimum and choose $c_n \in C$ with $\|x - c_n\| \to d$. Apply the parallelogram law to $x - c_n$ and $x - c_m$:
$$\|c_n - c_m\|^2 = 2\|x - c_n\|^2 + 2\|x - c_m\|^2 - 4\Big\|x - \tfrac{c_n + c_m}{2}\Big\|^2 \le 2\|x - c_n\|^2 + 2\|x - c_m\|^2 - 4d^2,$$
because the midpoint $\tfrac12(c_n + c_m)$ lies in $C$ by convexity. The right side tends to $0$, so $(c_n)$ is Cauchy and converges to some $p$, which lies in $C$ since $C$ is closed and has $\|x - p\| = d$. If $q \in C$ also has $\|x - q\| = d$, the same identity with $c_n = p$, $c_m = q$ gives $\|p - q\|^2 \le 2d^2 + 2d^2 - 4d^2 = 0$. $\blacksquare$

Each hypothesis is needed. Without closedness: $C = c_{00} \subseteq \ell^2$ and $x = (1/k)_k$ have distance $0$ to $C$ but $x \notin C$, so no nearest point exists. Without convexity: the unit sphere of $\mathbb{R}^2$ and $x = 0$ have infinitely many nearest points.

### Orthogonal projection

For a subset $S$ put $S^\perp = \{y : \langle y, s\rangle = 0 \text{ for all } s \in S\}$, always a closed subspace.

**Theorem 3 (projection theorem).** Let $M$ be a closed subspace of a Hilbert space $H$. Every $x \in H$ has a unique decomposition $x = m + n$ with $m \in M$, $n \in M^\perp$; $m = P_Mx$ is the point of $M$ nearest to $x$. The map $P_M$ is linear, $\|P_Mx\| \le \|x\|$, and $(M^\perp)^\perp = M$.

*Proof.* Let $m = $ the nearest point of $M$ to $x$ (Theorem 2) and $n = x - m$. For $u \in M$, $u \ne 0$, and the scalar $t = \langle n, u\rangle/\|u\|^2$, we have $m + tu \in M$, so $\|n\|^2 \le \|n - tu\|^2 = \|n\|^2 - |\langle n, u\rangle|^2/\|u\|^2$, forcing $\langle n, u\rangle = 0$: $n \in M^\perp$. If $m' + n' = m + n$ is another decomposition then $m - m' = n' - n \in M \cap M^\perp = \{0\}$. Linearity follows from uniqueness and $\|x\|^2 = \|m\|^2 + \|n\|^2$ gives $\|P_Mx\| \le \|x\|$. Finally $M \subseteq M^{\perp\perp}$ is clear; if $x \in M^{\perp\perp}$ write $x = m + n$, then $n = x - m \in M^{\perp\perp}\cap M^\perp = \{0\}$. $\blacksquare$

For a non-closed subspace the last statement fails: if $M = c_{00} \subseteq \ell^2$ then $M^\perp = \{0\}$ (a vector orthogonal to every $e_k$ is zero) and $M^{\perp\perp} = \ell^2 \ne M$. In general $M^{\perp\perp}$ is the closure of $M$ (a practice problem).

### Gram–Schmidt and projections in coordinates

The projection onto $\operatorname{span}\{e_1, \dots, e_k\}$ with $e_j$ orthonormal is $\sum_j\langle x, e_j\rangle e_j$. Gram–Schmidt produces such $e_j$ from any independent list.

```python
def inner(u, v):
    return sum(a * b for a, b in zip(u, v))


def gram_schmidt(vectors):
    """Orthonormalize independent real vectors (modified Gram-Schmidt)."""
    basis = []
    for v in vectors:
        w = list(v)
        for e in basis:
            c = inner(w, e)
            w = [wi - c * ei for wi, ei in zip(w, e)]
        norm = inner(w, w) ** 0.5
        basis.append([wi / norm for wi in w])
    return basis


def project_onto_orthonormal(x, basis):
    coeffs = [inner(x, e) for e in basis]
    return [sum(c * e[i] for c, e in zip(coeffs, basis))
            for i in range(len(x))]
```

If the input vectors are dependent, some `w` is zero or nearly zero and the division by `norm` blows up. In exact arithmetic the test is $w = 0$; in floating point the test is $\|w\| \le \text{tol}$. Computing projections by summing the projections onto each non-orthogonal vector separately is a classic error: it only works after orthogonalizing.

@example
title: Best approximation in $L^2[0,1]$
problem: Find the polynomial $p$ of degree at most $1$ that minimizes $\int_0^1 (t^2 - p(t))^2\,dt$, and the minimum value.
step: The problem asks for the orthogonal projection of $t^2$ onto $M = \operatorname{span}\{1, t\}$ in $L^2[0,1]$; $M$ is finite-dimensional, hence closed, so Theorem 3 applies. Write $p = a + bt$. The condition $t^2 - p \perp M$ gives two equations: $\langle t^2 - a - bt, 1\rangle = 0$ and $\langle t^2 - a - bt, t\rangle = 0$.
step: Compute the integrals: $\langle 1,1\rangle = 1$, $\langle t, 1\rangle = \tfrac12$, $\langle t,t\rangle = \tfrac13$, $\langle t^2, 1\rangle = \tfrac13$, $\langle t^2, t\rangle = \tfrac14$. The equations become $a + \tfrac b2 = \tfrac13$ and $\tfrac a2 + \tfrac b3 = \tfrac14$.
step: Solve: from the first, $a = \tfrac13 - \tfrac b2$; substituting gives $\tfrac16 + \tfrac{b}{12} = \tfrac14$, so $b = 1$ and $a = -\tfrac16$. Thus $p(t) = t - \tfrac16$.
step: The minimum value is $\|t^2 - p\|^2 = \|t^2\|^2 - \|p\|^2$ by Pythagoras, and $\|p\|^2 = \langle t^2, p\rangle = -\tfrac16\cdot\tfrac13 + 1\cdot\tfrac14 = \tfrac{7}{36}$. With $\|t^2\|^2 = \tfrac15$ this is $\tfrac15 - \tfrac7{36} = \tfrac1{180}$.
answer: $p(t) = t - \tfrac16$, with minimum $\tfrac{1}{180}$.

@example
title: Projection onto a closed convex cone
problem: Let $C = \{y \in \mathbb{R}^3 : y_1, y_2, y_3 \ge 0\}$ and $x = (2, -1, 3)$. Find the nearest point of $C$ to $x$ and verify it with the inequality $\langle x - p, c - p\rangle \le 0$ for all $c \in C$.
step: $C$ is nonempty, closed and convex, so Theorem 2 gives a unique nearest point. The squared distance $\sum (x_i - c_i)^2$ splits by coordinate, so minimize each term over $c_i \ge 0$ separately.
step: For $x_1 = 2$ and $x_3 = 3$ the best choice is $c_i = x_i$; for $x_2 = -1 < 0$ the term $(-1 - c_2)^2$ is smallest at $c_2 = 0$. So $p = (2, 0, 3)$.
step: Verify: $x - p = (0, -1, 0)$, and for $c \in C$, $\langle x - p, c - p\rangle = -(c_2 - 0) = -c_2 \le 0$.
step: This inequality characterizes the nearest point of a closed convex set (see the practice problem); for a subspace it reduces to $x - p \perp M$.
answer: $p = (2, 0, 3)$.

@mistakes
- Using Cauchy–Schwarz without noting which variable is conjugate-linear: in a complex space $\langle \lambda x, y\rangle = \lambda\langle x,y\rangle$ but $\langle x, \lambda y\rangle = \bar\lambda\langle x,y\rangle$.
- Claiming $M^{\perp\perp} = M$ for every subspace. It holds exactly for closed subspaces; in general $M^{\perp\perp} = \overline{M}$.
- Applying the nearest-point theorem to a set that is not convex, or to a convex set that is not closed (the nearest point may be nonunique or missing).
- Computing $P_Mx$ as the sum of projections onto a non-orthogonal spanning list: this only works for an orthogonal list.

prompt: Let $M$ be a linear subspace (not necessarily closed) of a Hilbert space $H$. Prove that $M^\perp$ is closed and that $(M^\perp)^\perp = \overline{M}$, the closure of $M$.
hint: Show $\overline{M}^\perp = M^\perp$ using continuity of the inner product, then apply the projection theorem to $\overline{M}$.
hint: For $x \in M^{\perp\perp}$ write $x = m + n$ with $m \in \overline{M}$, $n \in \overline{M}^\perp$ and compute $\|n\|^2$.
solution: $M^\perp = \bigcap_{s \in M}\{y : \langle y, s\rangle = 0\}$ is an intersection of closed subspaces (each is the kernel of a continuous functional), hence closed. Since $M^{\perp\perp}$ is closed and contains $M$, we get $\overline{M} \subseteq M^{\perp\perp}$. Conversely put $N = \overline{M}$. Then $N^\perp = M^\perp$: clearly $N^\perp \subseteq M^\perp$, and if $y \in M^\perp$ and $s_k \to s$ with $s_k \in M$, then $\langle y, s\rangle = \lim\langle y, s_k\rangle = 0$. Let $x \in M^{\perp\perp}$ and write $x = m + n$ with $m \in N$ and $n \in N^\perp = M^\perp$ (Theorem 3 for the closed subspace $N$). Then $\langle x, n\rangle = 0$ because $x \in M^{\perp\perp}$ and $n \in M^\perp$, and $\langle m, n\rangle = 0$, so $\|n\|^2 = \langle x - m, n\rangle = 0$. Hence $x = m \in \overline{M}$.

prompt: Let $C$ be a nonempty closed convex subset of a real Hilbert space $H$, $x \in H$ and $p \in C$. Prove that $p$ is the nearest point of $C$ to $x$ if and only if $\langle x - p, c - p\rangle \le 0$ for all $c \in C$.
hint: For the forward direction use the points $p + t(c - p)\in C$ with $t \in (0,1]$ and let $t \to 0$.
hint: For the converse expand $\|x - c\|^2 = \|(x - p) - (c - p)\|^2$.
solution: ($\Rightarrow$) Let $p$ be the nearest point and $c \in C$. For $t \in (0,1]$ the point $p + t(c - p)$ lies in $C$ by convexity, so $\|x - p\|^2 \le \|x - p - t(c - p)\|^2 = \|x - p\|^2 - 2t\langle x - p, c - p\rangle + t^2\|c - p\|^2$. Hence $2\langle x - p, c - p\rangle \le t\|c - p\|^2$ for every $t \in (0,1]$; letting $t \to 0$ gives the inequality. ($\Leftarrow$) If the inequality holds for all $c \in C$ then $\|x - c\|^2 = \|x - p\|^2 - 2\langle x - p, c - p\rangle + \|c - p\|^2 \ge \|x - p\|^2$, so $p$ is a point of $C$ nearest to $x$, and it is the nearest point by uniqueness (Theorem 2).

rubric: Divides by $t$ and lets $t \to 0$ to reach the inequality, without dropping the $t^2$ term incorrectly.
rubric: Proves the converse by the expansion of $\|x - c\|^2$ and notes where uniqueness is used.

model:
```python
def project(x, vectors, tol):
    """Orthogonal projection of x onto span(vectors), skipping dependents."""
    def inner(u, v):
        return sum(a * b for a, b in zip(u, v))

    basis = []
    for v in vectors:
        w = [float(a) for a in v]
        for e in basis:
            c = inner(w, e)
            w = [wi - c * ei for wi, ei in zip(w, e)]
        norm = inner(w, w) ** 0.5
        if norm > tol:
            basis.append([wi / norm for wi in w])
    result = [0.0] * len(x)
    for e in basis:
        c = inner(x, e)
        result = [r + c * ei for r, ei in zip(result, e)]
    return result
```
hint: Keep a list of orthonormal vectors; subtract from each new vector its components along the list, and keep it only if the remainder is longer than `tol`.
solution: The orthonormal vectors that survive the tolerance test span the same space as all the input vectors, so the projection is $\sum_j \langle x, e_j\rangle e_j$. Adding up the projections of `x` onto each input vector separately fails for the non-orthogonal pair `[1,1,0]`, `[1,0,1]` (it gives `[3.5, 1.5, 2]`), and dividing by a tiny norm instead of skipping the vector gives garbage, which the test with `1e-12` detects. The tolerance is a numerical stand-in for the exact test $w = 0$.

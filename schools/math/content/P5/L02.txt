@article
Every linear map between finite-dimensional spaces is continuous. In infinite dimensions that is false: differentiation $f \mapsto f'$ sends $f_n(t) = t^n$, which has sup norm $1$ on $[0,1]$, to $nt^{n-1}$, which has sup norm $n$. Continuity is a property to be proved, and the right way to prove it is to bound the operator.

### Boundedness and continuity

**Theorem 1.** Let $X, Y$ be normed spaces and $T\colon X \to Y$ linear. The following are equivalent: (a) $T$ is continuous; (b) $T$ is continuous at $0$; (c) $T$ is **bounded**, i.e. there is $M \ge 0$ with $\|Tx\| \le M\|x\|$ for all $x \in X$.

*Proof.* (c)$\Rightarrow$(a): $\|Tx - Ty\| = \|T(x - y)\| \le M\|x - y\|$. (a)$\Rightarrow$(b) is trivial. (b)$\Rightarrow$(c): by continuity at $0$ there is $\delta > 0$ with $\|Tz\| < 1$ whenever $\|z\| < \delta$. For $x \ne 0$ apply this to $z = \tfrac{\delta}{2\|x\|}x$ to get $\tfrac{\delta}{2\|x\|}\|Tx\| < 1$, i.e. $\|Tx\| < \tfrac{2}{\delta}\|x\|$. $\blacksquare$

The **operator norm** is $\|T\| = \sup_{\|x\| \le 1}\|Tx\| = \sup_{x \ne 0}\|Tx\|/\|x\|$, the least $M$ in (c). Write $B(X,Y)$ for the bounded operators and $X^* = B(X,\mathbb{K})$ for the **dual space**.

**Theorem 2.** If $X$ is a normed space and $Y$ is a Banach space, then $B(X,Y)$ is a Banach space. In particular every dual space $X^*$ is a Banach space, even if $X$ is not complete.

*Proof.* Let $(T_n)$ be Cauchy in $B(X,Y)$. For each $x$, $\|T_nx - T_mx\| \le \|T_n - T_m\|\|x\|$, so $(T_nx)$ is Cauchy in $Y$ and converges to a limit $Tx$; $T$ is linear because limits are. Given $\varepsilon > 0$ take $N$ with $\|T_n - T_m\| < \varepsilon$ for $m, n \ge N$. Then $\|T_nx - T_mx\| \le \varepsilon\|x\|$, and letting $m \to \infty$ gives $\|T_nx - Tx\| \le \varepsilon\|x\|$. So $T_n - T$ is bounded with norm at most $\varepsilon$, hence $T = T_n - (T_n - T)$ is bounded and $T_n \to T$ in operator norm. $\blacksquare$

### Computing operator norms

For a matrix $A = (a_{ij})$ acting on $\mathbb{R}^n$: $\|A\|_{1 \to 1}$ is the largest absolute column sum, and $\|A\|_{\infty \to \infty}$ is the largest absolute row sum. (For $\ell^1$: $\|Ax\|_1 \le \sum_j |x_j|\sum_i |a_{ij}|$, with equality at a standard basis vector. For $\ell^\infty$ the maximizing $x$ is the sign vector of the best row.) The norm $\|A\|_{2\to 2}$ is the largest singular value; Lesson 11 computes it with the power method.

```python
def norm_1(A):
    """Operator norm on l^1: largest absolute column sum."""
    return max(sum(abs(A[i][j]) for i in range(len(A)))
               for j in range(len(A[0])))


def norm_inf(A):
    """Operator norm on l^infinity: largest absolute row sum."""
    return max(sum(abs(a) for a in row) for row in A)
```

**Theorem 3 (integral operators on $C[0,1]$).** Let $K\colon [0,1]^2 \to \mathbb{R}$ be continuous and $(Tf)(x) = \int_0^1 K(x,y)f(y)\,dy$. Then $T$ maps $(C[0,1], \|\cdot\|_\infty)$ to itself and $\|T\| = \max_{x}\int_0^1 |K(x,y)|\,dy$.

*Proof.* Continuity of $Tf$ follows from the uniform continuity of $K$. The bound $|Tf(x)| \le \|f\|_\infty\int|K(x,y)|\,dy$ gives $\le$. For $\ge$, pick $x_0$ maximizing $x \mapsto \int|K(x,y)|\,dy$ (a continuous function) and put $f_\varepsilon(y) = K(x_0,y)/(|K(x_0,y)| + \varepsilon)$, a continuous function with $\|f_\varepsilon\|_\infty \le 1$. Then $Tf_\varepsilon(x_0) = \int K(x_0,y)^2/(|K(x_0,y)| + \varepsilon)\,dy \to \int|K(x_0,y)|\,dy$ as $\varepsilon \downarrow 0$ by monotone convergence. $\blacksquare$

### Duals of sequence spaces

**Theorem 4.** $(\ell^1)^* \cong \ell^\infty$ isometrically: every $\varphi \in (\ell^1)^*$ has the form $\varphi(x) = \sum x_ny_n$ for a unique $y \in \ell^\infty$, and $\|\varphi\| = \|y\|_\infty$.

*Proof.* Let $y_n = \varphi(e_n)$. Then $|y_n| \le \|\varphi\|\|e_n\|_1 = \|\varphi\|$. Every $x \in \ell^1$ is the $\ell^1$-limit of $\sum_{n \le N}x_ne_n$, so continuity gives $\varphi(x) = \sum x_ny_n$. Also $|\varphi(x)| \le \|y\|_\infty\|x\|_1$, so $\|\varphi\| \le \|y\|_\infty \le \|\varphi\|$. Conversely each $y \in \ell^\infty$ defines such a functional. $\blacksquare$

**Stated without proof here** (Hölder's inequality plus the same argument, in P1 language the Riesz representation of $L^p$ duals): for $1 \le p < \infty$ and $\tfrac1p + \tfrac1q = 1$ one has $(\ell^p)^* \cong \ell^q$, and $(c_0)^* \cong \ell^1$. Notice $(\ell^\infty)^* \not\cong \ell^1$; its dual is larger and is only describable with the Hahn–Banach theorem (Lesson 6).

@example
title: A norm that is attained and a norm that is not
problem: (a) On $(C[0,1], \|\cdot\|_\infty)$ let $(Tf)(x) = \int_0^1 (x + y)f(y)\,dy$. Find $\|T\|$. (b) On $L^2[0,1]$ let $(Mf)(t) = t f(t)$. Find $\|M\|$ and decide whether some $f \ne 0$ has $\|Mf\| = \|M\|\|f\|$.
step: (a) Apply Theorem 3. For $x \in [0,1]$ the kernel $x + y$ is nonnegative, so $\int_0^1|x + y|\,dy = x + \tfrac12$, which is largest at $x = 1$: $\|T\| = \tfrac32$.
step: (a) The norm is attained: $f \equiv 1$ has $\|f\|_\infty = 1$ and $Tf(x) = x + \tfrac12$, so $\|Tf\|_\infty = \tfrac32$.
step: (b) Upper bound: $\|Mf\|_2^2 = \int_0^1 t^2|f(t)|^2\,dt \le \int_0^1|f|^2 = \|f\|_2^2$, so $\|M\| \le 1$.
step: (b) Lower bound: for $0 < \varepsilon < 1$ let $f_\varepsilon = \varepsilon^{-1/2}\mathbf{1}_{[1-\varepsilon,1]}$, so $\|f_\varepsilon\|_2 = 1$ and $\|Mf_\varepsilon\|_2^2 = \tfrac1\varepsilon\int_{1-\varepsilon}^1 t^2\,dt \ge (1-\varepsilon)^2$. Letting $\varepsilon \to 0$ gives $\|M\| = 1$.
step: (b) Not attained: equality $\|Mf\|_2 = \|f\|_2$ means $\int(1 - t^2)|f(t)|^2\,dt = 0$, so $f = 0$ almost everywhere, since $1 - t^2 > 0$ on $[0,1)$. So no nonzero $f$ attains the norm.
answer: (a) $\|T\| = 3/2$, attained by $f \equiv 1$. (b) $\|M\| = 1$, not attained.

@example
title: Differentiation is not bounded, and the norm decides
problem: Let $D f = f'$ on the polynomials $\mathcal{P}$. Show that $D$ is unbounded on $(\mathcal{P}, \|\cdot\|_\infty)$ with sup norm on $[0,1]$, and bounded as a map from $(C^1[0,1], \|\cdot\|_{C^1})$ to $(C[0,1], \|\cdot\|_\infty)$.
step: Take $p_n(t) = t^n$. Then $\|p_n\|_\infty = 1$ and $Dp_n = nt^{n-1}$ has sup norm $n$.
step: If $\|Dp\|_\infty \le M\|p\|_\infty$ held for all polynomials, then $n \le M$ for every $n$, which is impossible. So $D$ is unbounded, hence discontinuous, by Theorem 1.
step: On $C^1[0,1]$ with $\|f\|_{C^1} = \|f\|_\infty + \|f'\|_\infty$ we have $\|Df\|_\infty = \|f'\|_\infty \le \|f\|_{C^1}$, so $\|D\| \le 1$.
step: The bound is sharp. Take $f_N(t) = \sin(Nt)/N$. Then $\|f_N\|_\infty \le 1/N$ and $\|f_N'\|_\infty = 1$ (since $f_N'(0) = 1$), so $\|Df_N\|_\infty/\|f_N\|_{C^1} \ge 1/(1 + 1/N) \to 1$. Hence $\|D\| = 1$.
step: Lesson: the same formula $f \mapsto f'$ is unbounded or bounded depending on the norms on the domain and the codomain.
answer: $D$ is unbounded on $(\mathcal{P}, \|\cdot\|_\infty)$ and has norm $1$ from $(C^1[0,1], \|\cdot\|_{C^1})$ to $(C[0,1], \|\cdot\|_\infty)$.

@mistakes
- Confusing bounded as an operator (a Lipschitz bound $\|Tx\| \le M\|x\|$) with bounded as a function: a nonzero linear map is never bounded in the second sense.
- Computing $\|A\|_{1\to1}$ by row sums and $\|A\|_{\infty\to\infty}$ by column sums: columns go with $\ell^1$, rows with $\ell^\infty$.
- Claiming $\|T\| = \max$ of something without producing a sequence or vector that reaches it; the supremum need not be attained (multiplication by $t$ on $L^2[0,1]$).
- Writing $(\ell^\infty)^* = \ell^1$. The correct statements are $(\ell^1)^* = \ell^\infty$ and $(c_0)^* = \ell^1$.

@practice self
prompt: Let $V$ be the Volterra operator on $C[0,1]$ with the sup norm, $(Vf)(x) = \int_0^x f(t)\,dt$. Prove that $(V^nf)(x) = \int_0^x \frac{(x-t)^{n-1}}{(n-1)!}f(t)\,dt$ for $n \ge 1$, and deduce that $\|V^n\| = 1/n!$.
hint: Induct on $n$ and interchange the order of integration over the triangle $0 \le t \le s \le x$.
hint: For the lower bound on $\|V^n\|$ apply $V^n$ to $f \equiv 1$.
solution: For $n = 1$ the formula is the definition. Assume it for $n$. Then $(V^{n+1}f)(x) = \int_0^x (V^nf)(s)\,ds = \int_0^x\int_0^s \frac{(s-t)^{n-1}}{(n-1)!}f(t)\,dt\,ds$. The integrand is continuous on the triangle $\{0 \le t \le s \le x\}$, so Fubini's theorem lets us integrate first in $s$ from $t$ to $x$: $\int_t^x \frac{(s-t)^{n-1}}{(n-1)!}\,ds = \frac{(x-t)^n}{n!}$. This is the formula for $n+1$. Now $|(V^nf)(x)| \le \|f\|_\infty\int_0^x\frac{(x-t)^{n-1}}{(n-1)!}\,dt = \|f\|_\infty\frac{x^n}{n!} \le \frac{\|f\|_\infty}{n!}$, so $\|V^n\| \le 1/n!$. For $f \equiv 1$, $V^nf(x) = x^n/n!$ has sup norm $1/n!$ and $\|f\|_\infty = 1$, so $\|V^n\| \ge 1/n!$. Hence $\|V^n\| = 1/n!$ (note $\|V^n\|^{1/n} \to 0$).
rubric: Proves the iterated-integral formula by induction with a correct interchange of integration and the inner integral $(x-t)^n/n!$.
rubric: Obtains the upper bound $\|V^n\| \le 1/n!$ from the formula, using $x \le 1$.
rubric: Shows the bound is sharp with an explicit function ($f \equiv 1$).

@practice self
prompt: Let $\varphi\colon X \to \mathbb{K}$ be a linear functional on a normed space $X$. Prove that $\varphi$ is continuous if and only if its kernel $\ker\varphi$ is closed.
hint: For the hard direction assume $\varphi \ne 0$, pick $x_0$ with $\varphi(x_0) = 1$, and use a ball around $x_0$ that misses $\ker\varphi$.
hint: Show $|\varphi(y)| < 1$ when $\|y\| < r$ by scaling a violation to a point with $\varphi = 1$.
solution: If $\varphi$ is continuous then $\ker\varphi = \varphi^{-1}(\{0\})$ is closed. Conversely let $\ker\varphi$ be closed. If $\varphi = 0$ there is nothing to prove, so choose $x_0$ with $\varphi(x_0) = 1$. Then $x_0 \notin \ker\varphi$, and since the kernel is closed there is $r > 0$ such that the ball $B(x_0, r)$ does not meet $\ker\varphi$. Suppose some $y$ has $\|y\| < r$ and $|\varphi(y)| \ge 1$. Put $y' = y/\varphi(y)$; then $\|y'\| \le \|y\| < r$ and $\varphi(y') = 1$, so $x_0 - y' \in B(x_0, r)$ and $\varphi(x_0 - y') = 1 - 1 = 0$, i.e. $x_0 - y' \in \ker\varphi \cap B(x_0,r)$, a contradiction. Hence $|\varphi(y)| < 1$ for all $\|y\| < r$. For $x \ne 0$ apply this to $y = \tfrac{r}{2\|x\|}x$ to get $|\varphi(x)| < \tfrac{2}{r}\|x\|$. So $\varphi$ is bounded, hence continuous by Theorem 1.
rubric: Proves the easy direction ($\ker\varphi$ is the preimage of the closed set $\{0\}$).
rubric: Uses closedness of the kernel to find a ball around $x_0$ missing the kernel.
rubric: Derives the bound $|\varphi(y)| < 1$ on a ball via the rescaling $y/\varphi(y)$ and concludes boundedness by homogeneity.

model:
```python
from itertools import product


def norm_inf_to_1(A):
    """Max of ||A x||_1 over sign vectors x in {-1, 1}^n."""
    n = len(A[0])
    best = 0
    for signs in product((-1, 1), repeat=n):
        value = sum(abs(sum(a * s for a, s in zip(row, signs))) for row in A)
        best = max(best, value)
    return best
```
hint: `itertools.product((-1, 1), repeat=n)` lists all sign vectors.
solution: For each sign vector compute $Ax$ and add up the absolute values of its entries; keep the largest. Using only $x = (1, \dots, 1)$ is a typical mistake and gives $4$ instead of $8$ for the first example. The enumeration costs $2^n$ evaluations, so it is only for small $n$: in general $\|A\|_{\infty\to 1}$ is hard to compute.

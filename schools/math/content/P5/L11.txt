@article
For a real symmetric matrix the spectral theorem says that there is an orthonormal basis of eigenvectors. For a bounded self-adjoint operator on an infinite-dimensional space this is false: multiplication by $x$ on $L^2[0,1]$ is self-adjoint and has no eigenvectors at all. But for **compact** self-adjoint operators the matrix picture survives completely, with eigenvalues that can only accumulate at $0$. This is the theorem behind Fourier series solutions of boundary-value problems.

### Self-adjoint operators and their norms

Let $H$ be a Hilbert space (complex or real). $T \in B(H)$ is **self-adjoint** if $T = T^*$, i.e. $\langle Tx,y\rangle = \langle x,Ty\rangle$ for all $x, y$. Then $\langle Tx,x\rangle$ is real for every $x$, eigenvalues are real, and eigenvectors for distinct eigenvalues are orthogonal ($\lambda\langle x,y\rangle = \langle Tx,y\rangle = \langle x,Ty\rangle = \mu\langle x,y\rangle$). The **spectrum** $\sigma(T)$ is the set of scalars $\lambda$ for which $T - \lambda I$ has no bounded inverse; eigenvalues belong to it.

**Lemma 1.** If $T$ is self-adjoint then $\|T\| = \sup_{\|x\|=1}|\langle Tx,x\rangle|$.

*Proof.* Let $m$ be the supremum; $m \le \|T\|$ by Cauchy–Schwarz. Self-adjointness gives $\langle T(x+y),x+y\rangle - \langle T(x-y),x-y\rangle = 2\langle Tx,y\rangle + 2\langle Ty,x\rangle = 4\operatorname{Re}\langle Tx,y\rangle$. By the definition of $m$ and the parallelogram law the left side is at most $m(\|x+y\|^2 + \|x-y\|^2) = 2m(\|x\|^2 + \|y\|^2)$. For $\|x\| = 1$ with $Tx \ne 0$ take $y = Tx/\|Tx\|$: $4\|Tx\| \le 4m$. Hence $\|T\| \le m$. $\blacksquare$

**Lemma 2.** If $T$ is compact, self-adjoint and $T \ne 0$, then $\|T\|$ or $-\|T\|$ is an eigenvalue of $T$.

*Proof.* By Lemma 1 there are unit vectors $x_n$ with $|\langle Tx_n,x_n\rangle| \to \|T\|$; passing to a subsequence, $\langle Tx_n,x_n\rangle \to \lambda$ with $\lambda$ real and $|\lambda| = \|T\|$. Then $\|Tx_n - \lambda x_n\|^2 = \|Tx_n\|^2 - 2\lambda\langle Tx_n,x_n\rangle + \lambda^2 \le \|T\|^2 - 2\lambda\langle Tx_n,x_n\rangle + \lambda^2 \to 0$. By compactness a further subsequence has $Tx_n \to y$. Then $\lambda x_n \to y$, so $\|y\| = |\lambda| > 0$ and $x_n \to x = y/\lambda$ with $\|x\| = 1$; continuity gives $Tx = \lim Tx_n = y = \lambda x$. $\blacksquare$

### The spectral theorem

**Theorem 3 (spectral theorem for compact self-adjoint operators).** Let $T$ be a compact self-adjoint operator on a Hilbert space $H$. There is an orthonormal sequence $(e_n)$ in $H$ (finite or infinite) and real numbers $\lambda_n \ne 0$ with $|\lambda_1| \ge |\lambda_2| \ge \cdots$ such that $Te_n = \lambda_ne_n$,
$$Tx = \sum_n\lambda_n\langle x,e_n\rangle e_n \quad\text{for all } x \in H,$$
and, if the sequence is infinite, $\lambda_n \to 0$. Moreover $H = \ker T \oplus \overline{\operatorname{span}}\{e_n\}$, and every nonzero eigenvalue of $T$ occurs among the $\lambda_n$ with finite multiplicity.

*Proof.* Put $H_0 = H$ and $T_0 = T$. If $T_k = T|_{H_k} \ne 0$ is defined, Lemma 2 (applied to the compact self-adjoint operator $T_k$ on the Hilbert space $H_k$) gives a unit vector $e_{k+1} \in H_k$ and $\lambda_{k+1} = \pm\|T_k\|$ with $Te_{k+1} = \lambda_{k+1}e_{k+1}$. The subspace $H_{k+1} = H_k \cap \{e_{k+1}\}^\perp$ is invariant under $T$ (if $x \in H_{k+1}$ then $\langle Tx,e_{k+1}\rangle = \langle x,Te_{k+1}\rangle = 0$). Since $H_{k+1} \subseteq H_k$ the norms $\|T_k\|$ decrease, so $|\lambda_k|$ decreases, and the process stops when $T_k = 0$. If it never stops, the unit vectors $e_n$ converge weakly to $0$ (Bessel), so $Te_n \to 0$ in norm by Lesson 10, Theorem 4(c); thus $|\lambda_n| = \|Te_n\| \to 0$. For $x \in H$ let $y = x - \sum_n\langle x,e_n\rangle e_n$ (convergent by Bessel and Riesz–Fischer). Then $y \in H_k$ for all $k$, so $\|Ty\| \le \|T_k\|\|y\| = |\lambda_{k+1}|\|y\|$ (or $Ty = 0$ if the process stopped), which tends to $0$: $Ty = 0$. Hence $Tx = \sum\lambda_n\langle x,e_n\rangle e_n$ and $y \in \ker T$. Also $\ker T \perp e_n$ because $\lambda_n \ne 0$, so the sum is orthogonal. If $Tz = \mu z$ with $\mu \ne 0$, then $\langle z,e_n\rangle = 0$ whenever $\lambda_n \ne \mu$ (distinct eigenvalues), and $z \perp \ker T$, so $z \in \operatorname{span}\{e_n : \lambda_n = \mu\}$; finite because $\lambda_n \to 0$. $\blacksquare$

Consequences: $\|T\| = |\lambda_1|$; $\sigma(T) = \{\lambda_n\} \cup \{0\}$ when $\dim H = \infty$ (see the practice problem on resolvents; $0$ is in $\sigma(T)$ because a compact operator is not invertible on an infinite-dimensional space), and $0$ may or may not be an eigenvalue. For a function $\varphi$ one can define $\varphi(T)x = \sum\varphi(\lambda_n)\langle x,e_n\rangle e_n + \varphi(0)Qx$ with $Q$ the projection onto $\ker T$; this is how one solves $(T - \lambda)x = y$ in the next lesson.

**Hypotheses.** *Compact:* multiplication by $x$ on $L^2[0,1]$ is self-adjoint with no eigenvalue. *Self-adjoint:* the Volterra operator $V$ is compact but has $\sigma(V) = \{0\}$ and no eigenvalues (Lesson 2: $\|V^n\|^{1/n} \to 0$; and $Vf = \lambda f$, $\lambda \ne 0$, gives $f = 0$ by differentiating), so it cannot be diagonalized.

### Power method

For a symmetric matrix $A$ with eigenvalues $|\lambda_1| > |\lambda_2| \ge \cdots$, repeated multiplication $v \mapsto Av/\|Av\|$ converges to an eigenvector for $\lambda_1$ provided the start vector has a component along it, and the Rayleigh quotient $\langle Av,v\rangle$ converges to $\lambda_1$ at rate $(|\lambda_2|/|\lambda_1|)^{2k}$ for $k$ steps. This is the finite-dimensional shadow of Theorem 3.

```python
import math


def matvec(A, v):
    return [sum(a * x for a, x in zip(row, v)) for row in A]


def power_method(A, v, steps):
    """Return (Rayleigh quotient, unit vector) after the given steps."""
    for _ in range(steps):
        w = matvec(A, v)
        norm = math.sqrt(sum(x * x for x in w))
        v = [x / norm for x in w]
    Av = matvec(A, v)
    return sum(a * b for a, b in zip(Av, v)), v
```

The power method fails if the start vector is orthogonal to the dominant eigenvector, and converges slowly when $|\lambda_2| \approx |\lambda_1|$. It cannot see $\lambda_2$ until $\lambda_1$ is removed.

@example
title: Diagonalizing a rank-two operator
problem: Let $u, v$ be orthonormal vectors in a Hilbert space $H$ and $Tx = \langle x,u\rangle v + \langle x,v\rangle u$. Find the eigenvalues and eigenvectors of $T$, verify the expansion of Theorem 3, and find $\|T\|$ and $\ker T$.
step: $T$ has finite rank, hence is compact. It is self-adjoint: $\langle Tx,y\rangle = \langle x,u\rangle\langle v,y\rangle + \langle x,v\rangle\langle u,y\rangle$, and $\langle x,Ty\rangle = \overline{\langle y,u\rangle}\langle x,v\rangle + \overline{\langle y,v\rangle}\langle x,u\rangle$ is the same number because $\overline{\langle y,u\rangle} = \langle u,y\rangle$.
step: Compute $Tu = v$ and $Tv = u$ (using $\langle u,v\rangle = 0$, $\langle u,u\rangle = 1$). So $T(u+v) = u+v$ and $T(u-v) = -(u-v)$.
step: The unit eigenvectors are $e_1 = (u+v)/\sqrt2$ with $\lambda_1 = 1$ and $e_2 = (u-v)/\sqrt2$ with $\lambda_2 = -1$. Their orthonormality: $\langle e_1,e_2\rangle = \tfrac12(\langle u,u\rangle - \langle v,v\rangle) = 0$.
step: Expansion: $\langle x,e_1\rangle e_1 - \langle x,e_2\rangle e_2 = \tfrac12[(\langle x,u\rangle + \langle x,v\rangle)(u+v) - (\langle x,u\rangle - \langle x,v\rangle)(u-v)] = \langle x,u\rangle v + \langle x,v\rangle u = Tx$.
step: $\ker T = \{u,v\}^\perp$ (if $\langle x,u\rangle = \langle x,v\rangle = 0$ then $Tx = 0$, and conversely $Tx = 0$ forces both coefficients zero since $u, v$ are independent), $\|T\| = |\lambda_1| = 1$, and $\sigma(T) = \{1,-1,0\}$ when $\dim H = \infty$.
answer: Eigenvalues $1$ and $-1$ with eigenvectors $(u\pm v)/\sqrt2$; $\|T\| = 1$; $\ker T = \{u,v\}^\perp$.

@example
title: A degenerate integral kernel on $L^2[-1,1]$
problem: Let $(Tf)(x) = \int_{-1}^1(1 + xy)f(y)\,dy$ on $L^2[-1,1]$. Find the nonzero eigenvalues, the eigenfunctions, $\|T\|$, and $Tf$ for $f(t) = t^2$.
step: The kernel is symmetric and continuous, so $T$ is compact and self-adjoint. Its range is spanned by $1$ and $x$ because $Tf = \langle f,1\rangle\cdot1 + \langle f,y\rangle\cdot x$.
step: Compute $T1 = \int_{-1}^1(1 + xy)\,dy = 2$ and $Tx = \int_{-1}^1(1+xy)y\,dy = x\int_{-1}^1y^2\,dy = \tfrac23x$ (the term $\int y\,dy$ vanishes).
step: Normalize: $\|1\|^2 = 2$ and $\|x\|^2 = \tfrac23$, so $e_1 = 1/\sqrt2$ ($\lambda_1 = 2$) and $e_2 = \sqrt{3/2}\,x$ ($\lambda_2 = \tfrac23$). They are orthogonal, and $\ker T = \{1,x\}^\perp$.
step: Hence $\|T\| = 2$ and $Tf = 2\langle f,e_1\rangle e_1 + \tfrac23\langle f,e_2\rangle e_2$.
step: For $f = t^2$: $\langle f,1\rangle = \tfrac23$ and $\langle f,x\rangle = 0$, so $Tf = \tfrac23$. By the expansion, $2\cdot\langle t^2,1/\sqrt2\rangle\cdot1/\sqrt2 = 2\cdot\tfrac{2}{3}\cdot\tfrac12 = \tfrac23$ as well.
answer: Eigenvalues $2$ (eigenfunction $1$) and $\tfrac23$ (eigenfunction $x$), $\|T\| = 2$, and $T(t^2) = \tfrac23$.

@mistakes
- Using the spectral theorem for a self-adjoint operator that is not compact (multiplication by $x$) or a compact operator that is not self-adjoint (the Volterra operator).
- Believing $0$ is always an eigenvalue of a compact operator on an infinite-dimensional space; it is always in the spectrum, but the diagonal operator $\operatorname{diag}(1/n)$ is injective.
- Ordering eigenvalues by value instead of by modulus: $\|T\| = |\lambda_1|$ and the largest eigenvalue may be negative.
- Running the power method from a start vector orthogonal to the dominant eigenvector, or deflating with an unnormalized eigenvector.

prompt: Let $T$ be a compact self-adjoint operator on a Hilbert space with $Tx = \sum_n\lambda_n\langle x,e_n\rangle e_n$ as in Theorem 3. Let $\lambda \ne 0$ with $\lambda \ne \lambda_n$ for all $n$. Prove that $T - \lambda I$ is invertible with bounded inverse, and write the inverse explicitly. Deduce that $\sigma(T)\setminus\{0\}$ consists of eigenvalues.
hint: Let $P$ be the projection onto $\overline{\operatorname{span}}\{e_n\}$ and $Q = I - P$ the projection onto $\ker T$. Define the inverse separately on $PH$ and on $QH$.
hint: Since $\lambda_n \to 0$ and $\lambda \ne 0$, the numbers $|\lambda_n - \lambda|$ are bounded below by a positive constant.
solution: Put $c_n = \langle x,e_n\rangle$, $Px = \sum c_ne_n$ and $Qx = x - Px \in \ker T$. Since $\lambda_n \to 0$, $\lambda \ne 0$ and $\lambda \ne \lambda_n$ for all $n$, $\delta = \inf_n|\lambda_n - \lambda| > 0$ (only finitely many $\lambda_n$ lie within $|\lambda|/2$ of $\lambda$, each different from $\lambda$; the rest satisfy $|\lambda_n - \lambda| \ge |\lambda|/2$). Define $Rx = \sum_n\frac{c_n}{\lambda_n - \lambda}e_n - \frac1\lambda Qx$. The series converges and $\|Rx\|^2 = \sum|c_n|^2/|\lambda_n - \lambda|^2 + |\lambda|^{-2}\|Qx\|^2 \le \max(\delta^{-2},|\lambda|^{-2})\|x\|^2$, so $R$ is bounded. Now $(T - \lambda)x = \sum(\lambda_n - \lambda)c_ne_n - \lambda Qx$ because $TQx = 0$. Applying $R$ to this gives $\sum c_ne_n + Qx = x$, and applying $T - \lambda$ to $Rx$ gives $\sum c_ne_n + Qx = x$ (using $TQx = 0$ and $(T-\lambda)(-\lambda^{-1}Qx) = Qx$). So $R = (T - \lambda)^{-1}$ and $\lambda \notin \sigma(T)$. Therefore any $\lambda \in \sigma(T)$, $\lambda \ne 0$, equals some $\lambda_n$, an eigenvalue.
rubric: Shows $\inf_n|\lambda_n - \lambda| > 0$ using $\lambda_n \to 0$ and $\lambda \ne 0$.
rubric: Defines $R$ on the span of the $e_n$ and on $\ker T$, proves it is bounded, and verifies both $R(T - \lambda) = I$ and $(T - \lambda)R = I$.
rubric: Concludes that every nonzero spectral value is an eigenvalue.

Prove the min–max formula $\mu_2 = \min_{v \in H}\ \max\{\langle Tx,x\rangle : \|x\| = 1,\ x \perp v\}$.
hint: To show every $v$ gives a maximum at least $\mu_2$, find a unit vector $x \in \operatorname{span}\{f_1,f_2\}$ orthogonal to $v$.

model:
```python
import math


def top_two_eigenvalues(A, steps):
    """Dominant two eigenvalues (by modulus) of symmetric A by deflation."""
    n = len(A)

    def matvec(M, v):
        return [sum(m * x for m, x in zip(row, v)) for row in M]

    def power(M, v):
        for _ in range(steps):
            w = matvec(M, v)
            norm = math.sqrt(sum(x * x for x in w))
            v = [x / norm for x in w]
        Mv = matvec(M, v)
        return sum(a * b for a, b in zip(Mv, v)), v

    start = [float(i + 1) for i in range(n)]
    l1, e = power(A, start)
    B = [[A[i][j] - l1 * e[i] * e[j] for j in range(n)] for i in range(n)]
    l2, _ = power(B, start)
    return (l1, l2)
```
hint: Deflation subtracts the rank-one piece $\lambda_1ee^\top$, which removes $\lambda_1$ from the spectrum and leaves the other eigenvalues.
solution: The unit eigenvector `e` for `l1` satisfies $Ae = l_1e$, so $B = A - l_1ee^\top$ has $Be = 0$ and agrees with $A$ on $e^\perp$ (symmetry is used here: $e^\perp$ is invariant). The dominant eigenvalue of $B$ in modulus is therefore the second eigenvalue of $A$. Without normalizing `e` the deflation removes the wrong multiple, and without deflating the second run just returns `l1` again; the tests with a negative dominant eigenvalue catch the common slip of using `abs` instead of the Rayleigh quotient. The start vector must have a component along the second eigenvector, which `[1, 2, ..., n]` does for these matrices; the convergence is a computation, not a proof.

@article
The regular value theorem needs a regular value. How many are there? A function can have infinitely many critical points (a constant function has nothing but critical points), but its critical *values* form a very small set. This is Sard's theorem, and it is the reason generic level sets are manifolds and generic intersections are transverse.

### Sets of measure zero

A set $A\subseteq\mathbb{R}^n$ has **measure zero** if for every $\varepsilon>0$ it is covered by countably many cubes of total volume less than $\varepsilon$. A subset $A$ of an $n$-manifold $M$ has measure zero if $\varphi(A\cap U)$ has measure zero in $\mathbb{R}^n$ for every chart $(U,\varphi)$ (it is enough to check a countable atlas). Countable unions of null sets are null.

**Lemma 1.** If $W\subseteq\mathbb{R}^n$ is open and $f\colon W\to\mathbb{R}^n$ is $C^1$, then $f$ maps sets of measure zero to sets of measure zero.

*Proof.* Cover $W$ by countably many closed cubes $K$ contained in $W$; it is enough to treat $A\subseteq K$ null. On the compact convex set $K$ the norm of $df$ is bounded by some $L$, so $|f(x)-f(y)|\le L|x-y|$ by the mean value inequality. Cover $A$ by cubes $Q_i\subseteq K$ of side $s_i$ with $\sum s_i^n<\varepsilon$. Each $f(Q_i)$ lies in a ball of radius $L\sqrt n\,s_i$ and hence in a cube of side $2L\sqrt n\,s_i$, of volume $(2L\sqrt n)^ns_i^n$. So $f(A)$ is covered by cubes of total volume at most $(2L\sqrt n)^n\varepsilon$, which is arbitrarily small. $\blacksquare$

Hence measure zero is well defined on manifolds (transition maps are diffeomorphisms), and **smooth maps $M\to N$ with $\dim M = \dim N$ map null sets to null sets**.

### Sard's theorem

**Theorem (Sard).** Let $F\colon M\to N$ be a smooth map between smooth manifolds (Hausdorff, second countable). Then the set of critical values of $F$ has measure zero in $N$. In particular the regular values are dense.

*Easy case $m<n$.* Every point is critical, since $dF_p$ cannot be surjective. Locally $F$ is a map on $W\subseteq\mathbb{R}^m$; define $G\colon W\times\mathbb{R}^{n-m}\to\mathbb{R}^n$, $G(x,y) = F(x)$. The set $W\times\{0\}$ has measure zero in $\mathbb{R}^n$, so by Lemma 1 its image $F(W)$ is null. Countably many charts cover $M$, so $F(M)$ is null.

*Case $m=n$.* Let $C\subseteq W\subseteq\mathbb{R}^n$ be the critical set of $F\colon W\to\mathbb{R}^n$ and $K\subseteq W$ a closed cube of side $s$; we show $F(C\cap K)$ is null. Let $L$ bound $\|dF\|$ on $K$. By uniform continuity of $dF$ on $K$, for each $\varepsilon>0$ there is $\delta$ with $|F(x+h)-F(x)-dF_x h|\le\varepsilon|h|$ whenever $x, x+h \in K$, $|h|<\delta$. Subdivide $K$ into $N^n$ cubes of side $s/N$ with $\sqrt n\,s/N<\delta$. If a subcube $Q$ contains a critical point $x_0$, then for $x\in Q$ we have $|h|\le\sqrt n\,s/N$ and $F(x) = F(x_0)+dF_{x_0}h+r$ with $|r|\le\varepsilon\sqrt n\,s/N$. Since $dF_{x_0}$ has rank $<n$, the vectors $dF_{x_0}h$ lie in a hyperplane within distance $L\sqrt n\,s/N$ of the origin. So $F(Q)$ lies in a set of volume at most $c_n\,(L s/N)^{n-1}\cdot\varepsilon\,(s/N)$ (a slab of that thickness over an $(n-1)$-ball), with $c_n$ a dimensional constant. Summing over at most $N^n$ subcubes gives $\operatorname{vol}F(C\cap K)\le c_nL^{n-1}\varepsilon\,s^n$, for every $\varepsilon>0$. $\blacksquare$

*General case $m>n$ (outline only; the proof is by induction on $m$).* Let $C_k$ be the set where all partial derivatives of order up to $k$ vanish. One shows $F(C\setminus C_1)$ is null by the implicit function theorem (near such a point a level set of one coordinate function is a manifold on which $F$ restricts to a map from dimension $m-1$ and induction applies), $F(C_k\setminus C_{k+1})$ is null by a similar argument, and $F(C_k)$ is null for $k$ large by Taylor's theorem. In its sharp form the theorem needs only that $F$ be $C^k$ with $k\ge\max(m-n+1,1)$ (stated here, not proved); for smooth maps there is no issue. Whitney constructed a $C^1$ function $\mathbb{R}^2\to\mathbb{R}$ that is not constant on a connected arc of critical points, so its critical values contain an interval (stated here, not constructed); too little smoothness fails.

Applications: for almost every $c\in\mathbb{R}$ the level set of a smooth function is a submanifold; and (stated, not proved here) the **Whitney embedding theorem**: every smooth $n$-manifold embeds in $\mathbb{R}^{2n+1}$ (and, by a finer argument, in $\mathbb{R}^{2n}$); the weaker statement uses Sard's theorem to project a high-dimensional embedding down along a regular direction.

### Transversality

Let $F\colon M\to N$ be smooth and $S\subseteq N$ an embedded submanifold. We say $F$ is **transverse** to $S$, written $F\pitchfork S$, if for every $p\in F^{-1}(S)$
$$dF_p(T_pM) + T_{F(p)}S = T_{F(p)}N .$$
(If $F^{-1}(S)=\emptyset$ the condition holds vacuously.) For $S=\{q\}$ a point, $T_qS=0$, and this says $q$ is a regular value; so transversality generalizes regularity. Two submanifolds $S_1, S_2$ are transverse if the inclusion of $S_1$ is transverse to $S_2$, which says $T_pS_1+T_pS_2=T_pN$ at each common point.

**Theorem (transverse preimage).** If $F\pitchfork S$ and $c=\operatorname{codim}S$, then $F^{-1}(S)$ is empty or an embedded submanifold of $M$ of codimension $c$, and $T_pF^{-1}(S) = dF_p^{-1}(T_{F(p)}S)$.

*Proof.* Let $p\in F^{-1}(S)$ and $q = F(p)$. A slice chart of $N$ at $q$ gives an open $V\ni q$ and a submersion $g\colon V\to\mathbb{R}^c$ (the last $c$ coordinates) with $S\cap V = g^{-1}(0)$ and $\ker dg_q = T_qS$. On the open set $F^{-1}(V)$, $F^{-1}(S)\cap F^{-1}(V) = (g\circ F)^{-1}(0)$. Now $d(g\circ F)_p = dg_q\circ dF_p$ is surjective onto $\mathbb{R}^c$ exactly when $dF_p(T_pM)+\ker dg_q = T_qN$. Indeed, if the sum is everything and $w \in\mathbb{R}^c$, pick $u \in T_qN$ with $dg_qu=w$ (as $dg_q$ is onto) and write $u = dF_pv + k$ with $k\in\ker dg_q$; then $dg_q dF_p v = w$. Conversely, if the composite is onto and $u\in T_qN$, choose $v$ with $dg_qdF_pv=dg_qu$; then $u-dF_pv\in\ker dg_q$. The sum condition holds by transversality since $\ker dg_q=T_qS$. So $0$ is a regular value of $g\circ F$ near $p$, and the regular value theorem gives codimension $c$ and $T_pF^{-1}(S)=\ker d(g\circ F)_p = dF_p^{-1}(\ker dg_q)$. $\blacksquare$

*Counting.* For transverse submanifolds $S_1,S_2$ of $N^n$ of dimensions $a,b$ the intersection has dimension $a+b-n$ (or is empty). Parametric transversality (stated, with the idea of the proof: apply Sard to the projection $F^{-1}(S)\to P$) says that if $F\colon M\times P\to N$ is transverse to $S$ then $F(\cdot,s)\pitchfork S$ for almost every parameter $s$.

### Testing transversality of subspaces by machine

At a point, transversality of two tangent spaces $U, W\subseteq\mathbb{R}^n$ is a rank condition: $\dim(U+W)=n$ and then $\dim(U\cap W)=\dim U+\dim W-n$. With exact rational row reduction this is a short program (practice).
@example
title: A transverse intersection of two surfaces
problem: Show that the sphere $S^2$ and the cylinder $Z=\{x^2+y^2=1/4\}$ in $\mathbb{R}^3$ are transverse, and find the dimension of their intersection.
step: Write $Z = h^{-1}(1/4)$ with $h(x,y,z)=x^2+y^2$. Then $\nabla h = (2x, 2y, 0)$ vanishes only on the $z$-axis, which does not meet $Z$ (there $h=0$), so $1/4$ is a regular value and $T_pZ = \nabla h(p)^\perp$. Likewise $T_pS^2 = p^\perp$.
step: At a point $p\in S^2\cap Z$ the two tangent planes coincide iff their normals $p$ and $(x,y,0)$ are parallel. Since $|p|=1$ and $x^2+y^2 = 1/4$, we have $z^2 = 3/4\ne0$, so $p$ is not parallel to $(x,y,0)$.
step: Distinct planes through the origin in $\mathbb{R}^3$ span $\mathbb{R}^3$ together, so $T_pS^2+T_pZ=\mathbb{R}^3$ at every common point: $S^2\pitchfork Z$.
step: By the transverse preimage theorem the intersection has dimension $2+2-3=1$: it consists of the two circles $z=\pm\sqrt3/2$, $x^2+y^2=1/4$.
answer: The surfaces are transverse and meet in two circles, a $1$-dimensional submanifold.
@example
title: Tangency is where transversality fails
problem: Let $S^1=\{x^2+y^2=1\}$ and let $L_c=\{y=c\}$ in $\mathbb{R}^2$. For which $c$ is $S^1\pitchfork L_c$?
step: At a common point $p=(x,y)$ the tangent line of $S^1$ is $p^\perp$ and the tangent line of $L_c$ is the $x$-axis direction.
step: Two lines through the origin in $\mathbb{R}^2$ span $\mathbb{R}^2$ unless they coincide. They coincide iff $p^\perp$ is horizontal iff $p = (0,\pm1)$.
step: Such a $p$ lies on $L_c$ iff $c=\pm1$. If $|c|<1$ there are two common points, both with transverse tangents; if $|c|>1$ there are no common points, so the condition holds vacuously.
step: So the circle and the line are transverse exactly when $c\ne\pm1$, and the intersection is $2$ points for $|c|<1$ ($1+1-2=0$ dimensions) and empty for $|c|>1$.
answer: Transverse for every $c\ne\pm1$; tangent (not transverse) at $c=\pm1$.
@mistakes
- Saying the critical *points* have measure zero: a constant map has every point critical. Sard's theorem is about critical *values* in the target.
- Using Sard for a map that is only $C^1$ with $m>n$: the number of derivatives required grows with $m-n$ (Whitney's example).
- Calling submanifolds transverse when they are disjoint or merely "cross" at some points: transversality is a condition at every common point and is vacuous for disjoint submanifolds.
- Concluding that two surfaces in $\mathbb{R}^4$ meeting along a curve are transverse: planes in $\mathbb{R}^4$ whose sum is $3$-dimensional are not transverse, since $\dim(U+W)$ must be $4$.

model:
```python
from fractions import Fraction


def _rank(vectors):
    """Exact rank of a list of vectors by Gaussian elimination."""
    a = [[Fraction(v) for v in row] for row in vectors]
    rank = 0
    ncols = len(a[0]) if a else 0
    for col in range(ncols):
        pivot = None
        for r in range(rank, len(a)):
            if a[r][col] != 0:
                pivot = r
                break
        if pivot is None:
            continue
        a[rank], a[pivot] = a[pivot], a[rank]
        for r in range(rank + 1, len(a)):
            f = a[r][col] / a[rank][col]
            a[r] = [x - f * y for x, y in zip(a[r], a[rank])]
        rank += 1
    return rank


def transversality(U, W, n):
    """Return (U + W is everything, dimension of U intersect W)."""
    ru, rw = _rank(U), _rank(W)
    rs = _rank(list(U) + list(W))
    return (rs == n, ru + rw - rs)
```
hint: Compute three ranks: of `U`, of `W` and of the combined list `U + W`.
hint: Use $\dim(U\cap W) = \dim U + \dim W - \dim(U+W)$, and never use the number of vectors in a list as a dimension.
solution: Ranks give the dimensions of the spans, even with redundant vectors. The sum $U+W$ is spanned by the concatenated list, so it equals $\mathbb{Q}^n$ exactly when that rank is $n$, and the dimension formula for subspaces gives $\dim(U\cap W)$. A wrong answer that uses `len(U) + len(W)` fails the test with a redundant vector. This is a linear-algebra computation at one point; transversality of manifolds requires the condition at every common point.
@practice self
prompt: Let $M$ and $N$ be smooth manifolds with $\dim M = m < n = \dim N$ and $F\colon M\to N$ smooth. Prove directly (using only Lemma 1, that $C^1$ maps of equal dimension preserve measure zero sets) that $F(M)$ has measure zero in $N$. Deduce that $F$ is not surjective, and that $F(M)$ has empty interior in $N$.
hint: In local coordinates extend $F$ to a map on $W\times\mathbb{R}^{n-m}$ that ignores the extra variables.
hint: Use that $M$ is covered by countably many chart domains.
solution: Since $M$ and $N$ are second countable, each is covered by countably many chart domains: $(U_i,\varphi_i)$ for $M$ and $(V_j,\psi_j)$ for $N$. The sets $U_{ij} = U_i\cap F^{-1}(V_j)$ are open, countably many, and cover $M$, with $F(U_{ij})\subseteq V_j$. On $U_{ij}$ the coordinate representation is $f_{ij} = \psi_j\circ F\circ\varphi_i^{-1}\colon W_{ij}\to\mathbb{R}^n$, smooth on the open set $W_{ij}=\varphi_i(U_{ij})\subseteq\mathbb{R}^m$. Define $G_{ij}\colon W_{ij}\times\mathbb{R}^{n-m}\to\mathbb{R}^n$ by $G_{ij}(x,y) = f_{ij}(x)$, a smooth map between open subsets of $\mathbb{R}^n$. The set $W_{ij}\times\{0\}$ lies in the hyperplane $\mathbb{R}^{n-1}\times\{0\}$ and has measure zero in $\mathbb{R}^n$: a bounded piece inside $[-R,R]^{n-1}\times\{0\}$ is covered by $N^{n-1}$ cubes of side $2R/N$, of total volume $(2R)^n/N\to0$, and $W_{ij}\times\{0\}$ is a countable union of bounded pieces. By Lemma 1, $G_{ij}(W_{ij}\times\{0\}) = f_{ij}(W_{ij})$ has measure zero in $\mathbb{R}^n$. Thus $\psi_j(F(U_{ij}))$ is null, so $F(U_{ij})$ is null in $N$, and $F(M)=\bigcup_{i,j}F(U_{ij})$ is a countable union of null sets, hence null. A nonempty open set of $N$ has positive measure in a chart, so $F(M)$ contains no nonempty open set; in particular $F(M)\ne N$. $\blacksquare$

rubric: Shows $W\times\{0\}$ has measure zero in $\mathbb{R}^n$ because $m<n$, and invokes Lemma 1.

prompt: Let $\iota\colon S^2\hookrightarrow\mathbb{R}^3$ be the inclusion and $P_a=\{z=a\}$. Prove that $S^2$ is transverse to $P_a$ if and only if $|a|\ne1$.

If $|a|\ne1$, no point of $P_a$ equals $\pm e_3$ (such points have $z=\pm1$), so at every common point (possibly none, if $|a|>1$) the tangent spaces span $\mathbb{R}^3$: the surfaces are transverse. If $|a|=1$, the point $p=(0,0,a)$ lies in $S^2\cap P_a$, and there $T_pS^2=T_pP_a$, whose sum is only a plane, so transversality fails. $\blacksquare$

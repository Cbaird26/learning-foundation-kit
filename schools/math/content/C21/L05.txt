@article
A formula is a finite string, and there are infinitely many of them, so we cannot prove a claim about formulas by checking each one. What makes the proof possible is the way formulas are *defined*: every formula is built from atoms in finitely many steps. A property that survives each building step must hold for every formula. This is **structural induction**, and almost every metatheorem of logic (soundness, the truth lemma in the completeness proof, the substitution lemma) is proved this way.

### The inductive definition

Fix a set of **atoms** (sentence letters $P, Q, R, \ldots$). The set of **formulas** is the smallest set such that

1. every atom is a formula;
2. if $A$ is a formula, so is $\neg A$;
3. if $A$ and $B$ are formulas, so are $(A \wedge B)$, $(A \vee B)$ and $(A \to B)$.

"Smallest" is the **extremal clause**: nothing is a formula unless clauses 1 to 3 make it one. So $\neg\neg P$ and $((P \to Q) \wedge \neg R)$ are formulas, while $P \wedge$ and $(P \wedge Q \wedge R)$ are not: the official syntax gives every binary connective its own pair of parentheses. The **unique readability theorem** says that each formula is exactly one of an atom, $\neg A$ for a unique $A$, or $(A \ast B)$ for a unique connective $\ast$ and unique $A$ and $B$. We use it without proof; it is what makes recursive definitions below well defined.

### The principle of induction on formulas

| P1 | Every atom has property $\Phi$. |
| P2 | If $A$ has $\Phi$, then $\neg A$ has $\Phi$; and if $A$ and $B$ both have $\Phi$, then $(A \wedge B)$, $(A \vee B)$ and $(A \to B)$ have $\Phi$. |
| P3 | The set of formulas is the smallest set containing the atoms and closed under negation and the binary connectives. |
| C | So every formula has property $\Phi$. |

The argument is valid. By P1 and P2 the set $S$ of things with $\Phi$ contains the atoms and is closed under the formation rules; by P3 the set of formulas is a subset of every such set, in particular of $S$. In practice a proof has a **base case** (atoms), and an **inductive step** with one case for each formation rule, where we may assume $\Phi$ holds of the immediate parts (the **induction hypothesis**). Forgetting a case, usually the one for negation or for one of the binary connectives, is the commonest error. An equivalent form is induction on the **size** of a formula: assume the property for all formulas of smaller size.

**Lemma.** Every formula has as many left parentheses as right parentheses.
*Proof.* Write $\ell(A)$ and $r(A)$ for the numbers of left and right parentheses in $A$. Base case: an atom has $\ell = r = 0$. Case $\neg A$: $\ell(\neg A) = \ell(A) = r(A) = r(\neg A)$, using the induction hypothesis for $A$. Case $(A \ast B)$ for $\ast \in \{\wedge, \vee, \to\}$: $\ell((A \ast B)) = \ell(A) + \ell(B) + 1 = r(A) + r(B) + 1 = r((A \ast B))$, using the hypothesis for $A$ and for $B$. By induction on formulas, every formula has the property. $\square$

### Structural recursion

To define a function on all formulas, say what it does to atoms and how its value on $\neg A$ or $(A \ast B)$ depends on its values on the parts. Unique readability guarantees there is exactly one such function. Two examples:

| formula | size $s$ (symbols counted as nodes) | height $h$ |
|---|---|---|
| atom $P$ | $s(P) = 1$ | $h(P) = 0$ |
| $\neg A$ | $s(\neg A) = s(A) + 1$ | $h(\neg A) = h(A) + 1$ |
| $(A \ast B)$ | $s(A \ast B) = s(A) + s(B) + 1$ | $h(A \ast B) = \max(h(A), h(B)) + 1$ |

The **truth value** of a formula under a valuation $v$ (an assignment of $T$ or $F$ to atoms) is also defined by recursion: $\bar v(P) = v(P)$; $\bar v(\neg A) = T$ iff $\bar v(A) = F$; $\bar v(A \wedge B) = T$ iff both are $T$; $\bar v(A \vee B) = T$ iff at least one is; $\bar v(A \to B) = F$ iff $\bar v(A) = T$ and $\bar v(B) = F$. The set of **subformulas** of a formula is the formula together with the subformulas of its parts.

### Formulas as data in Python

In code, represent a formula as a nested tuple: `('atom', 'P')`, `('not', A)`, `('and', A, B)`, `('or', A, B)` and `('imp', A, B)`. A recursive function on this data has exactly the shape of a recursive definition: one branch for atoms, one for negation, one for each binary connective. For first-order logic, the same method works on terms first and then on formulas, with extra clauses $\forall x A$ and $\exists x A$.

@example
title: Counting atoms and connectives
problem: Prove by induction on formulas that every formula built from atoms with $\wedge$, $\vee$ and $\to$ only (no negation) has exactly one more atom occurrence than binary connective occurrences.
step: Write $a(A)$ for the number of atom occurrences and $c(A)$ for the number of binary-connective occurrences. The claim is $a(A) = c(A) + 1$.
step: Base case: an atom $P$ has $a(P) = 1$ and $c(P) = 0$, so $a = c + 1$.
step: Inductive step for $(A \ast B)$: by the induction hypothesis $a(A) = c(A) + 1$ and $a(B) = c(B) + 1$. The formula $(A \ast B)$ contains the atoms of $A$ and of $B$, and the connectives of $A$ and $B$ plus the main connective $\ast$. So $a(A \ast B) = a(A) + a(B) = c(A) + c(B) + 2$, and $c(A \ast B) = c(A) + c(B) + 1$.
step: Therefore $a(A \ast B) = c(A \ast B) + 1$. There is no negation case because negation is excluded from this class of formulas, so the induction is complete.
answer: In every negation-free formula, $a = c + 1$.

@example
title: Recursion on a formula
problem: For $A = ((P \to \neg Q) \vee (\neg P \wedge Q))$, compute the size $s(A)$, the height $h(A)$, and the truth value of $A$ when $v(P) = T$ and $v(Q) = F$.
step: Work bottom-up. $s(\neg Q) = 2$, $s(P \to \neg Q) = 1 + 2 + 1 = 4$, $s(\neg P) = 2$, $s(\neg P \wedge Q) = 2 + 1 + 1 = 4$, so $s(A) = 4 + 4 + 1 = 9$.
step: Heights: $h(\neg Q) = 1$, $h(P \to \neg Q) = \max(0, 1) + 1 = 2$, $h(\neg P) = 1$, $h(\neg P \wedge Q) = \max(1, 0) + 1 = 2$, so $h(A) = \max(2, 2) + 1 = 3$.
step: Truth values: $\bar v(\neg Q) = T$, so $\bar v(P \to \neg Q) = T$ (the consequent is true). $\bar v(\neg P) = F$, so $\bar v(\neg P \wedge Q) = F$.
step: A disjunction with a true disjunct is true, so $\bar v(A) = T$.
answer: $s(A) = 9$, $h(A) = 3$, and $A$ is true under this valuation.

@mistakes
- Omitting a case in the inductive step: a proof must treat negation and every binary connective (and, in first-order logic, both quantifiers).
- Assuming the property of the formula being proved instead of its parts: the induction hypothesis is about the immediate parts $A$ and $B$ only.
- Using a property of formulas in the proof that was never proved for the parts, such as unique readability, without saying so.
- Confusing the height of a formula (depth of nesting) with its size (the total number of nodes).

```python
def evaluate(f, v):
    """Truth value of formula f under valuation v, by structural recursion."""
    op = f[0]
    if op == 'atom':
        return v[f[1]]
    if op == 'not':
        return not evaluate(f[1], v)
    left, right = evaluate(f[1], v), evaluate(f[2], v)
    if op == 'and':
        return left and right
    if op == 'or':
        return left or right
    return (not left) or right
```
hint: Branch on `f[0]`: one case for atoms, one for `'not'`, and one for each binary connective.
hint: Evaluate the parts first with recursive calls, then combine the results. The conditional is false only when the antecedent is true and the consequent is false.
solution: This is the recursive definition of $\bar v$ written as code: look up atoms in `v`, negate for `'not'`, and combine the values of the two parts for the binary connectives. The conditional is `(not left) or right`, which is false exactly when `left` is true and `right` is false; writing `left and right` for it is the typical bug.

hint: State the property, then check the base case and the single inductive case.
solution: Let $\Phi(A)$ say: $A$ contains exactly one atom occurrence. Class: formulas built by the clauses "every atom is in the class" and "if $A$ is in the class so is $\neg A$". Base case: an atom $P$ contains exactly one atom occurrence, namely itself. Inductive step: suppose $A$ is in the class and contains exactly one atom occurrence (induction hypothesis). The formula $\neg A$ consists of the symbol $\neg$ followed by $A$, and $\neg$ is not an atom, so $\neg A$ has exactly the atom occurrences of $A$, which is one. No other formation rule applies in this class, so by induction every formula in the class has exactly one atom occurrence.

```python
def atoms(f):
    """The set of atom names occurring in formula f."""
    if f[0] == 'atom':
        return {f[1]}
    result = set()
    for part in f[1:]:
        result |= atoms(part)
    return result
```

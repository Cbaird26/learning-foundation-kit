@project
title: Metalogic report: one theorem, one construction, one page of philosophy
overview: You will choose one major metalogical result (Cantor's theorem, the undecidability of the halting problem, or the compactness theorem), write a careful proof of it with every step justified, implement a Python demonstration of its key construction, and write one page on its philosophical significance. The report shows that you can prove, compute and interpret a result of logic about logic.
goal: Write a complete proof of a major theorem in which every step is justified by a definition, an earlier result or a rule of inference.
goal: Implement and test a small Python program that carries out the key construction of the proof (a diagonal argument, a reduction or an encoding, or a witness construction).
goal: Explain what the result shows and what it does not show, stating its hypotheses exactly and presenting at least two sides of a philosophical question that it bears on.
step: Choose one of the three options in the material below. Read the corresponding section of the Open Logic Project texts, and the encyclopedia entry you find most useful, and note the exact statement of the theorem, including every hypothesis.
step: Write the proof by hand or in a document. Number the steps. Next to each, say why it holds: "by definition of $D$", "by modus ponens on lines 3 and 5", "by the pairing function being injective". Mark each place where you use a result from earlier in the course.
step: Design the Python demonstration. Decide what finite or computable fragment of the construction you can run, say what its output shows, and say what it cannot show (a finite table is not an infinite one). Write the code with a docstring for every function.
step: Write tests: at least five assertions, including edge cases (an empty set, a machine that never halts within the step limit, an inconsistent finite set) and one that checks the property the construction is supposed to achieve (the diagonal object differs from every row; the reduction maps yes-instances to yes-instances and no-instances to no-instances).
step: Write the philosophical page, about 400 words. Use one of the prompts in the material. State the theorem's hypotheses first, give the best argument on each of two sides of the question, and say what would settle the question, or why nothing in the theorem does.
step: Check the whole report. Does the proof use only what it has justified? Does the code do what the proof says? Does the philosophy page claim more than the theorem gives? Revise, and reread the report once aloud as if you were explaining it to a classmate.
material: **Option A: Cantor's theorem.** Statement: for every set $A$ there is no surjection from $A$ onto $\mathcal{P}(A)$. Key construction: the diagonal set $D = \{a \in A : a \notin f(a)\}$. Demonstration idea: write `cantor_set(f)` for a finite $A$, test it on many randomly generated functions $f$ (random subsets, with a fixed seed so that the tests are repeatable), and verify that `D != f[a]` for every `a`. Also count, for $\lvert A \rvert = 3$, how many functions there are and for how many of them $D$ is empty.
material: **Option B: the halting problem.** Statement: no Turing machine decides, for every machine $M$ and input $w$, whether $M$ halts on $w$. Key construction: the diagonal machine $D$, built from a supposed decider. Demonstration idea: implement a Turing machine simulator with a step limit, build a table of the halting behavior of a handful of small machines on small inputs up to the limit, apply the diagonal rule to the table, and show that the resulting row differs from every row. Also include a reduction, for example from "halts on input $x$" to "halts on the empty input", as a function that builds a new transition table from a machine and an input.
material: **Option C: compactness.** Statement: a set of first-order sentences has a model if and only if every finite subset has a model. Proof route: completeness, the finiteness of derivations and soundness. Demonstration idea: for propositional logic, implement a satisfiability test for a finite set of formulas (formulas as nested tuples), and implement the Lindenbaum-style construction on a small language with a given enumeration of formulas, producing a valuation that satisfies a consistent (satisfiable) set; show that for the set $\{P_1, P_1 \to P_2, P_2 \to P_3, \ldots\}$ truncated at a chosen length every finite subset is satisfiable, and display the valuation the construction chooses.
material: **Philosophy prompts.** (1) Does Cantor's theorem show that there are infinities of different sizes, or only that "size" is defined by one-to-one correspondence? (2) Does the undecidability of the halting problem show a limit on mathematics, on machines, on minds, or only on one kind of procedure? (3) Does compactness show a weakness of first-order logic as a language for mathematics, or a strength? Whichever prompt you use, say what the result assumes, and do not claim more than it proves.
deliverable: The written proof, with every step numbered and justified (one to two pages).
deliverable: The Python file with docstrings and at least five passing assertions, plus a short paragraph saying what the program demonstrates and what it cannot demonstrate.
deliverable: The philosophy page (about 400 words), with the theorem's hypotheses stated, two sides argued, and a conclusion that does not overreach.
rubric: Correctness of the proof: the statement is exact and each step is justified; no step assumes the conclusion or leaves a gap.
rubric: Faithfulness of the code: the program implements the construction from the proof, its tests check the property the construction should have, and it handles edge cases.
rubric: Honesty about limits: the report says clearly what the finite demonstration shows and what it does not.
rubric: Quality of the philosophy page: hypotheses stated exactly, two sides argued fairly, claims proportionate to the theorem.
rubric: Clarity: definitions are given before use, notation is consistent, and a classmate could follow the report.
tutor: Here is my proof of the theorem, with each step numbered. Which steps are unjustified or rely on something I have not proved?

## Review guide for C20

### Key ideas, week by week

- **Weeks 1 and 2: sets, relations, functions.** Extensionality, subsets and the power set ($2^n$ members), the operations; identities proved by double inclusion or by a chain of biconditionals about an arbitrary member. Relations as sets of pairs; reflexive, symmetric, antisymmetric, transitive; equivalence relations correspond to partitions; injective, surjective, bijective; partial, total and well-orders.
- **Weeks 3 and 4: countable and uncountable.** Same size means a bijection. $\mathbb{N}$, $\mathbb{Z}$, $\mathbb{Q}$, $\mathbb{N} \times \mathbb{N}$ and the finite strings over a finite alphabet are countable (Cantor's pairing function). Cantor's theorem: no surjection from $A$ onto $\mathcal{P}(A)$, by the diagonal set $D = \{a : a \notin f(a)\}$; $\mathcal{P}(\mathbb{N})$ and $\mathbb{R}$ are uncountable; the continuum hypothesis is independent of ZFC.
- **Weeks 5 and 6: induction and soundness.** Structural induction needs a base case and one case per formation rule. Recursive definitions: size, height, atoms, truth value. Soundness: if $\Gamma \vdash A$ then $\Gamma \vDash A$, by induction on the lines of a derivation, with the side conditions on $\forall$I and $\exists$E.
- **Weeks 7 and 8: completeness, compactness, Löwenheim-Skolem.** Model existence for every consistent set: Lindenbaum's lemma, Henkin witnesses, term model, truth lemma. Compactness from completeness, finiteness of derivations and soundness; finiteness is not first-order definable; nonstandard models; downward and upward Löwenheim-Skolem; Skolem's paradox.
- **Weeks 9 and 10: computability.** Turing machines, the Church-Turing thesis (a thesis, not a theorem), universal machines, the halting theorem by diagonalization, semi-decidability, reductions, Rice's theorem, undecidability of first-order validity.
- **Weeks 11 and 12: Gödel numbering and incompleteness.** Prime-power codes and unique factorization; representability in $Q$; the diagonal lemma; the first theorem (consistent, effectively axiomatized, extends $Q$: incomplete; Rosser); the second theorem ($T \nvdash \mathrm{Con}_T$); Tarski's undefinability theorem; the Lucas-Penrose argument and its contested premises.

### Key arguments and distinctions

Diagonalization in four guises: Cantor's set $D$, the flipped diagonal of binary sequences, the halting machine $D$, the Gödel sentence. Soundness versus completeness; consistent versus satisfiable; decidable versus semi-decidable; true versus provable; the numeral $\bar n$ versus the number $n$.

### Self-check

- Can you prove a set identity by double inclusion, and refute a false one with a small example in Python?
- Can you write a bijection from $\mathbb{N}$ to $\mathbb{Z}$ and prove it is one?
- Can you compute $\pi(m, n)$ and invert it, and encode and decode a Gödel number?
- Can you state each metatheorem with its hypotheses, and say which hypothesis fails for a given theory?
- Can you carry out the diagonal argument for Cantor and for halting without notes?

### Common errors

Proving one inclusion only; calling a map a bijection after checking injectivity only; omitting a case in a structural induction; stating soundness as completeness; calling the Church-Turing thesis a theorem; stating incompleteness without consistency, effective axiomatization or enough arithmetic; concluding that minds are not machines from the theorems alone.

@exam mc
prompt: Which combination of results yields the compactness theorem for first-order logic?
choice*: Completeness, the fact that a derivation uses only finitely many premises, and soundness.
choice: Cantor's theorem and the Schröder-Bernstein theorem.
choice: The halting theorem and Rice's theorem.
choice: The diagonal lemma and the second incompleteness theorem.
hint: Trace the proof: no model, hence a derivation of $\bot$, hence finitely many premises, hence a finite subset with no model.
solution: If a set has no model, completeness gives a derivation of $\bot$ from it. The derivation uses finitely many premises, and soundness shows that this finite subset has no model. The other combinations are results about cardinality, computability and incompleteness, not about the link between finite subsets and models.

prompt: A language has 11 symbols. How many strings of length at most 3 over this alphabet are there, counting the empty string once? (The same count shows that for each length there are finitely many strings, which is why the set of all strings is countable.)
answer: 1464
check: sum(11 ** k for k in range(4))
hint: Count the strings of each length separately and add: there are $11^k$ strings of length $k$.
solution: The numbers of strings of lengths $0, 1, 2, 3$ are $1$, $11$, $121$ and $1331$. Their sum is $1 + 11 + 121 + 1331 = 1464$.

@exam self
prompt: Cantor's theorem, the halting theorem and the diagonal lemma are all said to use "diagonalization". For each, state the result (with hypotheses), say what plays the role of the diagonal, and say what the construction produces. Then say which of the three results is about cardinality, which about computation, and which about provability.
hint: Identify, in each case, the table or function that is diagonalized and the object that disagrees with it at the diagonal place.
solution: Cantor's theorem: for every set $A$, no function $f : A \to \mathcal{P}(A)$ is onto. The diagonal is the question whether $a \in f(a)$; the construction produces $D = \{a : a \notin f(a)\}$, which differs from $f(a)$ about $a$ for every $a$. It is a result about cardinality: $\mathcal{P}(A)$ is strictly larger than $A$. The halting theorem: no Turing machine decides, for all $(e, x)$, whether $M_e$ halts on $x$. The diagonal is the halting behavior of $M_e$ on its own code $e$; assuming a decider $H$, one builds $D$ which halts on $e$ iff $H$ says $M_e$ does not halt on $e$, so $D$ differs from each $M_e$ at the diagonal place; contradiction at $e = \ulcorner D\urcorner$. It is a result about computation. The diagonal lemma: for $T$ extending $Q$ and any $\varphi(y)$ there is $\gamma$ with $T \vdash \gamma \leftrightarrow \varphi(\overline{\ulcorner\gamma\urcorner})$. The diagonal is the substitution function $d$ that plugs a formula's own code into itself; the construction produces a sentence that "says" $\varphi$ of itself. With $\varphi = \neg\mathrm{Prov}_T$ it yields the Gödel sentence, so it is the engine of a result about provability.
rubric: States each of the three results accurately, with its hypotheses (for the diagonal lemma: a theory extending $Q$).
rubric: Identifies correctly what is diagonalized in each case and what the diagonal object is.
rubric: Classifies the three results correctly as cardinality, computation and provability.

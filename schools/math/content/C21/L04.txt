@article
Last week every infinite set we met turned out to be countable: the integers, the rationals, the finite strings. Is every infinite set countable? In 1874 Cantor showed it is not, and in 1891 he gave the argument now called the **diagonal argument**. Diagonalization is the central technique of this course. The halting problem and the incompleteness theorems are diagonal arguments too, and Russell's paradox is Cantor's argument applied to the set of all sets.

### Infinite binary sequences

An **infinite binary sequence** is a function $s : \mathbb{N} \to \{0, 1\}$. Write it as $s(0)\,s(1)\,s(2) \ldots$. Suppose someone claims to have listed all of them as $s_0, s_1, s_2, \ldots$. Arrange the list as an infinite table whose row $n$ is $s_n$. The **diagonal** is the sequence of entries $s_0(0), s_1(1), s_2(2), \ldots$, and the **flipped diagonal** is $d(n) = 1 - s_n(n)$. The argument:

| P1 | Given any list $s_0, s_1, \ldots$ of infinite binary sequences, $d(n) = 1 - s_n(n)$ defines an infinite binary sequence $d$. |
| P2 | For every $n$, $d(n) \ne s_n(n)$, so $d \ne s_n$. |
| C1 | So $d$ is an infinite binary sequence that does not occur on the list. |
| P3 | If some infinite binary sequence is missing from a list, that list does not contain all infinite binary sequences. |
| C | So no list contains all infinite binary sequences: the set of infinite binary sequences is uncountable. |

The argument is valid: C1 follows from P1 and P2, and C follows from C1 and P3, since a set is countable only if some list contains all of its members. Nothing was assumed about the list except that it is a list, so the conclusion holds for every list. That is the logical shape of every diagonal argument: from any attempted enumeration, build a counterexample that differs from the $n$-th item in the $n$-th place.

### Cantor's theorem

**Theorem (Cantor).** For every set $A$, there is no surjection from $A$ onto $\mathcal{P}(A)$. Hence $\lvert A \rvert < \lvert \mathcal{P}(A) \rvert$ in the sense that there is an injection $a \mapsto \{a\}$ from $A$ into $\mathcal{P}(A)$ but no bijection.

*Proof.* Let $f : A \to \mathcal{P}(A)$ be any function, and define $D = \{a \in A : a \notin f(a)\}$. $D$ is a subset of $A$, so $D \in \mathcal{P}(A)$. Suppose $D = f(d)$ for some $d \in A$. Then $d \in D$ iff $d \in f(d)$ (since $D = f(d)$), and $d \in D$ iff $d \notin f(d)$ (by the definition of $D$). So $d \in f(d)$ iff $d \notin f(d)$, a contradiction. So $D$ is not in the range of $f$, and $f$ is not onto. $\square$

For $A = \mathbb{N}$, subsets correspond to binary sequences (the characteristic function of a subset), so the theorem says again that $\mathcal{P}(\mathbb{N})$ is uncountable. The set $D$ for $A$ = the universe of all sets, with $f$ the identity, is Russell's set, which is why there is no set of all sets.

### The real numbers

The interval $[0, 1)$ is uncountable. Every number in it has a decimal expansion $0.r_0 r_1 r_2 \ldots$, but some numbers have two: $0.5000\ldots = 0.4999\ldots$. A list of reals, written as decimals, could therefore hide a number behind its second expansion. The standard repair is to build the diagonal number from digits $4$ and $5$ only: let $d$'s $n$-th digit be $5$ if the $n$-th digit of the $n$-th listed number is $4$, and $4$ otherwise. An expansion made of $4$s and $5$s never ends in all $0$s or all $9$s, so $d$ has only one expansion, and it differs from the $n$-th listed number in the $n$-th digit of *every* expansion of that number. So $d$ is on no list, and the reals are uncountable. In fact $\mathbb{R}$ has the same cardinality as $\mathcal{P}(\mathbb{N})$, a result we state without proof.

### Comparing sizes

Write $\lvert A \rvert \le \lvert B \rvert$ when there is an injection from $A$ to $B$. The **Schröder-Bernstein theorem** says that if there are injections $A \to B$ and $B \to A$, then there is a bijection between $A$ and $B$. So "$\le$" on cardinalities is antisymmetric. The **continuum hypothesis** (CH) says there is no set whose size lies strictly between $\lvert \mathbb{N} \rvert$ and $\lvert \mathbb{R} \rvert$. Gödel (1940) showed CH cannot be refuted in ZFC if ZFC is consistent, and Cohen (1963) showed it cannot be proved: **CH is independent of ZFC**. The usual axioms of set theory do not settle it, and mathematicians and philosophers disagree about whether the question has a determinate answer.

@example
title: Running the diagonal on a table
problem: A claimed list of infinite binary sequences begins with these five rows (only the first five digits are shown):

| row | digits |
|---|---|
| $s_0$ | 0 1 1 0 1 |
| $s_1$ | 1 1 0 0 0 |
| $s_2$ | 0 0 1 1 1 |
| $s_3$ | 1 0 1 0 0 |
| $s_4$ | 0 1 0 1 1 |

Find the first five digits of the flipped diagonal $d$ and check that $d$ differs from every row.
step: The diagonal entries are $s_0(0) = 0$, $s_1(1) = 1$, $s_2(2) = 1$, $s_3(3) = 0$, $s_4(4) = 1$.
step: Flipping each gives $d = 1\,0\,0\,1\,0$.
step: Compare: $d(0) = 1 \ne s_0(0) = 0$; $d(1) = 0 \ne s_1(1) = 1$; $d(2) = 0 \ne s_2(2) = 1$; $d(3) = 1 \ne s_3(3) = 0$; $d(4) = 0 \ne s_4(4) = 1$.
step: So $d$ disagrees with row $n$ in position $n$ for each $n \le 4$, so $d$ is none of the first five rows. Extended by the same rule to the whole table, it is not on the list at all.
answer: $d = 10010$ (to five digits); it differs from row $n$ at position $n$.

@example
title: The set $D$ in Cantor's proof
problem: Let $A = \{1, 2, 3\}$ and $f(1) = \{2, 3\}$, $f(2) = \{1, 2\}$, $f(3) = \varnothing$. Find $D = \{a \in A : a \notin f(a)\}$ and show that $D$ is not a value of $f$.
step: Test each element: $1 \notin f(1) = \{2, 3\}$, so $1 \in D$. $2 \in f(2) = \{1, 2\}$, so $2 \notin D$. $3 \notin f(3) = \varnothing$, so $3 \in D$.
step: So $D = \{1, 3\}$.
step: $D \ne f(1)$ because $1 \in D$ but $1 \notin f(1)$. $D \ne f(2)$ because $2 \in f(2)$ but $2 \notin D$. $D \ne f(3)$ because $3 \in D$ but $3 \notin f(3)$.
step: In each case $D$ and $f(a)$ disagree about whether $a$ belongs: exactly the diagonal pattern. So $D \notin \operatorname{ran} f$.
answer: $D = \{1, 3\}$, which differs from $f(a)$ on the question whether $a$ is a member, for each $a$.

@mistakes
- Believing the diagonal argument produces a number not in $\mathbb{N}$ or in the "infinite part" of the list; it produces a sequence that differs from each listed item at one place, so it is missing from the list.
- Concluding that all infinite sets are uncountable, or that $\mathbb{Q}$ is: $\mathbb{N}$, $\mathbb{Z}$ and $\mathbb{Q}$ are countable.
- Ignoring double decimal expansions ($0.4999\ldots = 0.5$) when diagonalizing real numbers.
- Replying "just add the diagonal sequence to the list": the new list has its own diagonal, which differs from every item on the new list, so no repair completes the list.

@practice self
prompt: Give an explicit bijection $g : \mathbb{Z} \to \mathbb{N}$ and prove that it is injective and surjective. What does it show about the sizes of $\mathbb{Z}$ and $\mathbb{N}$?
hint: Send the non-negative integers to the even numbers and the negative integers to the odd numbers.
hint: For injectivity, treat the cases of both arguments non-negative, both negative, and one of each.
solution: Define $g(k) = 2k$ for $k \ge 0$ and $g(k) = -2k - 1$ for $k < 0$. Then $g$ sends non-negative integers to even numbers and negative integers to odd numbers $1, 3, 5, \ldots$. Injective: if $g(k) = g(k')$, then both values have the same parity, so both $k, k' \ge 0$ or both $< 0$; in the first case $2k = 2k'$ and in the second $-2k - 1 = -2k' - 1$, so $k = k'$ either way. Surjective: an even $m$ equals $g(m/2)$ with $m/2 \ge 0$; an odd $m$ equals $g(-(m+1)/2)$ with $-(m+1)/2 < 0$. So $g$ is a bijection, and $\mathbb{Z}$ and $\mathbb{N}$ have the same cardinality: $\mathbb{Z}$ is countably infinite.
rubric: Gives a correct explicit formula defined by cases.
rubric: Proves injectivity, using the parity of the values to separate the two cases.
rubric: Proves surjectivity for both even and odd numbers and states the conclusion about cardinality.

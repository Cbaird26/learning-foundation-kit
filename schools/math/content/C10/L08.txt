@article
Is $\mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/3\mathbb{Z}$ cyclic? The element $(1, 1)$ has multiples $(1,1), (0,2), (1,0), (0,1), (1,2), (0,0)$: all six elements, so yes. Is $\mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}$ cyclic? Every element satisfies $2(a, b) = (0, 0)$, so no element has order $4$, and no. The difference is whether the moduli are coprime. This lesson explains that and lists all finite abelian groups.

### Direct products

**Definition.** The **direct product** of groups $G$ and $H$ is the set $G \times H$ of pairs with the operation $(g, h)(g', h') = (gg', hh')$. It is a group with identity $(e_G, e_H)$ and inverses $(g, h)^{-1} = (g^{-1}, h^{-1})$, of order $|G||H|$. The same definition works for any finite number of factors. $G \times H$ is abelian if and only if both $G$ and $H$ are.

**Theorem 1.** (a) If $g \in G$ and $h \in H$ have finite orders $a$ and $b$, then $(g, h)$ has order $\operatorname{lcm}(a, b)$. (b) $\mathbb{Z}/m\mathbb{Z} \times \mathbb{Z}/n\mathbb{Z}$ is cyclic if and only if $\gcd(m, n) = 1$, and then it is isomorphic to $\mathbb{Z}/mn\mathbb{Z}$.

*Proof.* (a) $(g, h)^k = (g^k, h^k)$ is the identity if and only if $a \mid k$ and $b \mid k$ (lesson 2), that is, if and only if $\operatorname{lcm}(a, b) \mid k$. (b) The element $(1, 1)$ has order $\operatorname{lcm}(m, n)$ by (a). If $\gcd(m, n) = 1$ then $\operatorname{lcm}(m, n) = mn$, which is the order of the group, so $(1, 1)$ generates it. If $d = \gcd(m, n) > 1$ then for any $(a, b)$ we have $\frac{mn}{d}(a, b) = (0, 0)$, because $\frac{mn}{d} = \operatorname{lcm}(m, n)$ is a multiple of both $m$ and $n$. Since $\frac{mn}{d} < mn$, no element has order $mn$ and the group is not cyclic. $\blacksquare$

By induction, $\mathbb{Z}/n\mathbb{Z} \cong \mathbb{Z}/p_1^{e_1}\mathbb{Z} \times \cdots \times \mathbb{Z}/p_k^{e_k}\mathbb{Z}$ if $n = p_1^{e_1}\cdots p_k^{e_k}$ is the prime factorization (this is the Chinese remainder theorem for the additive group).

### The structure theorem

**Lemma 2.** Let $G$ be a finite abelian group and suppose that $G$ has an exponent $mn$, meaning $g^{mn} = e$ for all $g$, with $\gcd(m, n) = 1$. Put $G_m = \{g : g^m = e\}$ and $G_n = \{g : g^n = e\}$. Then $G_m$ and $G_n$ are subgroups and $G \cong G_m \times G_n$.

*Proof.* Because $G$ is abelian, $G_m$ is a subgroup: $(ab^{-1})^m = a^m b^{-m} = e$. Likewise $G_n$. If $g \in G_m \cap G_n$ then the order of $g$ divides both $m$ and $n$, so $g = e$. Choose integers $u, v$ with $um + vn = 1$. For $g \in G$, $g = g^{um}g^{vn}$ with $(g^{um})^n = (g^{mn})^u = e$ and $(g^{vn})^m = e$, so $g \in G_n G_m$. Define $\Phi\colon G_m \times G_n \to G$ by $\Phi(a, b) = ab$. It is a homomorphism since $G$ is abelian, injective since $G_m \cap G_n = \{e\}$, and surjective by what was just shown. $\blacksquare$

**Theorem 3 (fundamental theorem of finite abelian groups).** Every finite abelian group is isomorphic to a direct product of cyclic groups of prime-power order,
$$G \cong \mathbb{Z}/p_1^{e_1}\mathbb{Z} \times \cdots \times \mathbb{Z}/p_k^{e_k}\mathbb{Z},$$
and the list of prime powers $p_i^{e_i}$ (the **elementary divisors**) is unique up to order.

*Outline of the proof (not complete).* Applying Lemma 2 repeatedly splits $G$ into its $p$-primary parts, the subgroups of elements whose order is a power of $p$, one for each prime $p$ dividing $|G|$. For a $p$-primary part $P$, choose an element $x$ of maximal order $p^e$; one shows that $\langle x \rangle$ has a complement in $P$, a subgroup $Q$ with $P = \langle x \rangle \times Q$, and induction on $|P|$ finishes the existence. Uniqueness follows by counting the elements $g$ with $p^j g = 0$ for each $p$ and $j$, which determines the number of cyclic factors of each size. The full proof is in the reading.

**Counting.** For a prime $p$, the abelian groups of order $p^e$ correspond to the **partitions** of $e$ (ways to write $e$ as an unordered sum of positive integers): the partition $e = e_1 + \cdots + e_r$ gives $\mathbb{Z}/p^{e_1}\mathbb{Z} \times \cdots \times \mathbb{Z}/p^{e_r}\mathbb{Z}$. If $n = \prod p_i^{e_i}$, the number of abelian groups of order $n$ is $\prod_i P(e_i)$, where $P(e)$ is the number of partitions of $e$. Since $P(1) = 1$, $P(2) = 2$, $P(3) = 3$, $P(4) = 5$, the groups of order $p^3$ are $\mathbb{Z}/p^3\mathbb{Z}$, $\mathbb{Z}/p^2\mathbb{Z} \times \mathbb{Z}/p\mathbb{Z}$ and $(\mathbb{Z}/p\mathbb{Z})^3$.

### Telling groups apart

Isomorphic groups have the same number of elements of each order (an isomorphism preserves orders, by lesson 6). A short program counts them:

```python
from itertools import product
from math import gcd, lcm


def order_profile(moduli):
    """Number of elements of each order in Z/m1 x Z/m2 x ..."""
    counts = {}
    for g in product(*[range(m) for m in moduli]):
        order = 1
        for a, m in zip(g, moduli):
            order = lcm(order, m // gcd(m, a))
        counts[order] = counts.get(order, 0) + 1
    return dict(sorted(counts.items()))


for moduli in ([8], [4, 2], [2, 2, 2]):
    print(moduli, order_profile(moduli))
```

It prints `[8] {1: 1, 2: 1, 4: 2, 8: 4}`, then `[4, 2] {1: 1, 2: 3, 4: 4}`, then `[2, 2, 2] {1: 1, 2: 7}`. The three profiles differ, so the three groups of order $8$ are pairwise non-isomorphic. This is a proof that they differ (a finite check of an invariant), whereas matching profiles for two groups would only be evidence of an isomorphism.

@example
title: All abelian groups of order 360
problem: List the abelian groups of order $360$ up to isomorphism.
step: Factor: $360 = 2^3 \cdot 3^2 \cdot 5$. By the fundamental theorem, a group is determined by choosing, for each prime, a partition of its exponent.
step: For $2^3$ the partitions of $3$ are $3$, $2 + 1$, $1 + 1 + 1$, giving $\mathbb{Z}/8\mathbb{Z}$, $\mathbb{Z}/4\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}$, $(\mathbb{Z}/2\mathbb{Z})^3$. For $3^2$ the partitions of $2$ are $2$ and $1 + 1$, giving $\mathbb{Z}/9\mathbb{Z}$ and $(\mathbb{Z}/3\mathbb{Z})^2$. For $5^1$ there is only $\mathbb{Z}/5\mathbb{Z}$.
step: Combine one choice for each prime: $3 \cdot 2 \cdot 1 = 6$ groups, namely $\mathbb{Z}/8 \times \mathbb{Z}/9 \times \mathbb{Z}/5 \cong \mathbb{Z}/360$, then $\mathbb{Z}/8 \times (\mathbb{Z}/3)^2 \times \mathbb{Z}/5$, then $\mathbb{Z}/4 \times \mathbb{Z}/2 \times \mathbb{Z}/9 \times \mathbb{Z}/5$, then $\mathbb{Z}/4 \times \mathbb{Z}/2 \times (\mathbb{Z}/3)^2 \times \mathbb{Z}/5$, then $(\mathbb{Z}/2)^3 \times \mathbb{Z}/9 \times \mathbb{Z}/5$, and finally $(\mathbb{Z}/2)^3 \times (\mathbb{Z}/3)^2 \times \mathbb{Z}/5$.
answer: There are $6$ abelian groups of order $360$, one for each choice of a partition of $3$ and a partition of $2$.

@example
title: Deciding whether two products are isomorphic
problem: Are $\mathbb{Z}/12\mathbb{Z} \times \mathbb{Z}/18\mathbb{Z}$ and $\mathbb{Z}/36\mathbb{Z} \times \mathbb{Z}/6\mathbb{Z}$ isomorphic?
step: Both groups have order $216$. Write each as a product of cyclic groups of prime-power order using $\mathbb{Z}/ab \cong \mathbb{Z}/a \times \mathbb{Z}/b$ for coprime $a, b$.
step: $\mathbb{Z}/12 \times \mathbb{Z}/18 \cong (\mathbb{Z}/4 \times \mathbb{Z}/3) \times (\mathbb{Z}/2 \times \mathbb{Z}/9)$, with elementary divisors $4, 3, 2, 9$.
step: $\mathbb{Z}/36 \times \mathbb{Z}/6 \cong (\mathbb{Z}/4 \times \mathbb{Z}/9) \times (\mathbb{Z}/2 \times \mathbb{Z}/3)$, with elementary divisors $4, 9, 2, 3$.
step: The two lists of elementary divisors are the same, so by the uniqueness part of the theorem (or by reordering factors) the groups are isomorphic.
answer: Yes, both are isomorphic to $\mathbb{Z}/4 \times \mathbb{Z}/2 \times \mathbb{Z}/9 \times \mathbb{Z}/3$.

@mistakes
- Saying that the order of $(g, h)$ is the product of the orders, or the gcd. It is the least common multiple: $(1, 1) \in \mathbb{Z}/4 \times \mathbb{Z}/6$ has order $12$, not $24$.
- Believing that two abelian groups of the same order are isomorphic. $\mathbb{Z}/4 \times \mathbb{Z}/2$ and $\mathbb{Z}/8$ both have order $8$, but only the second has an element of order $8$.
- Writing $\mathbb{Z}/4 \times \mathbb{Z}/6 \cong \mathbb{Z}/24$. The moduli share the factor $2$, so no element has order $24$; the group is isomorphic to $\mathbb{Z}/2 \times \mathbb{Z}/12$.
- Applying the classification to non-abelian groups. The theorem is about abelian groups; for example $S_3$ and $\mathbb{Z}/6\mathbb{Z}$ both have order $6$ but only the second is abelian.

@practice self
prompt: Let $H$ and $K$ be normal subgroups of a group $G$ with $H \cap K = \{e\}$ and $HK = G$. Prove that $G \cong H \times K$.
hint: First show that every element of $H$ commutes with every element of $K$, by considering $hkh^{-1}k^{-1}$.
hint: Then check that $(h, k) \mapsto hk$ is a homomorphism, and show it is injective and surjective.
solution: Let $h \in H$ and $k \in K$. Then $hkh^{-1}k^{-1} = h(kh^{-1}k^{-1}) \in H$ since $H$ is normal, and $hkh^{-1}k^{-1} = (hkh^{-1})k^{-1} \in K$ since $K$ is normal. So it lies in $H \cap K = \{e\}$ and $hk = kh$. Define $\Phi\colon H \times K \to G$ by $\Phi(h, k) = hk$. Then $\Phi((h, k)(h', k')) = hh'kk'$, and $\Phi(h, k)\Phi(h', k') = hkh'k' = hh'kk'$ because $k$ and $h'$ commute; so $\Phi$ is a homomorphism. It is onto since $HK = G$. If $hk = e$ then $h = k^{-1} \in H \cap K$, so $h = k = e$ and the kernel is trivial. Hence $\Phi$ is an isomorphism. $\blacksquare$

### Permutations and cycle notation

A **permutation** of $\{1, \dots, n\}$ is a bijection of that set onto itself. They form the **symmetric group** $S_n$ under composition, of order $n!$. We write $\sigma\tau$ for $\sigma \circ \tau$: apply $\tau$ first, then $\sigma$. In **cycle notation**, $(a_1\, a_2\, \dots\, a_k)$ is the permutation sending $a_1 \mapsto a_2 \mapsto \dots \mapsto a_k \mapsto a_1$ and fixing everything else. For example $(1\,2)(1\,2\,3)$ sends $1 \mapsto 2 \mapsto 1$, $2 \mapsto 3 \mapsto 3$ and $3 \mapsto 1 \mapsto 2$, so it equals $(2\,3)$.

**Theorem 1.** Every permutation is a product of disjoint cycles, unique up to the order of the factors (and omission of $1$-cycles). Disjoint cycles commute. The order of $\sigma$ is the least common multiple of the cycle lengths.

*Proof.* Define $i \sim j$ if $j = \sigma^k(i)$ for some $k \in \mathbb{Z}$; this is an equivalence relation. Take a class of size $m$ containing $i$. The elements $i, \sigma(i), \dots$ cannot all be distinct forever, so $\sigma^a(i) = \sigma^b(i)$ with $a < b$, and then $\sigma^{b-a}(i) = i$. With $m$ the least positive integer such that $\sigma^m(i) = i$, the class is $\{i, \sigma(i), \dots, \sigma^{m-1}(i)\}$ and $\sigma$ acts on it as an $m$-cycle. Doing this for every class writes $\sigma$ as a product of disjoint cycles, which commute since each moves only its own elements. Uniqueness holds because the cycles must be the classes. Finally $\sigma^k = e$ if and only if every cycle length divides $k$, so the order is the least common multiple. $\blacksquare$

Every cycle is a product of transpositions: $(a_1\, a_2\, \dots\, a_k) = (a_1\, a_k)(a_1\, a_{k-1}) \cdots (a_1\, a_2)$. The cycle $(1\,2\,3)(4\,5)$ has order $\operatorname{lcm}(3, 2) = 6$. In code, with a permutation of $\{0, \dots, n-1\}$ stored as a list `p` with `p[i]` the image of `i`:

```python
def compose(s, t):
    """The permutation s after t: i -> s[t[i]]."""
    return [s[t[i]] for i in range(len(t))]


def cycles(p):
    """Cycles of length >= 2 of p, in 1-based notation."""
    seen, out = set(), []
    for start in range(len(p)):
        if start in seen:
            continue
        cyc, j = [start + 1], p[start]
        seen.add(start)
        while j != start:
            cyc.append(j + 1)
            seen.add(j)
            j = p[j]
        if len(cyc) > 1:
            out.append(cyc)
    return out


print(cycles(compose([1, 0, 2], [1, 2, 0])))
```

This prints `[[2, 3]]`, matching $(1\,2)(1\,2\,3) = (2\,3)$.

### The sign of a permutation

Define $\operatorname{sgn}(\sigma) = \prod_{1 \le i < j \le n} \dfrac{\sigma(j) - \sigma(i)}{j - i}$.

**Theorem 2.** $\operatorname{sgn}(\sigma) \in \{1, -1\}$, $\operatorname{sgn}(\sigma\tau) = \operatorname{sgn}(\sigma)\operatorname{sgn}(\tau)$, and every transposition has sign $-1$. Hence a permutation that is a product of $k$ transpositions has sign $(-1)^k$, and the parity of $k$ is determined by $\sigma$.

*Proof.* Since $\sigma$ permutes the unordered pairs $\{i, j\}$, the absolute values in numerator and denominator agree, so $\operatorname{sgn}(\sigma) = \pm 1$, with sign $(-1)^{N}$ where $N$ counts the pairs $i < j$ with $\sigma(i) > \sigma(j)$. For the product rule, write
$$\operatorname{sgn}(\sigma\tau) = \prod_{i<j} \frac{\sigma(\tau(j)) - \sigma(\tau(i))}{\tau(j) - \tau(i)} \cdot \prod_{i<j} \frac{\tau(j) - \tau(i)}{j - i}.$$
The second product is $\operatorname{sgn}(\tau)$. In the first, each factor is unchanged when $\tau(i)$ and $\tau(j)$ are swapped, so it depends only on the unordered pair $\{\tau(i), \tau(j)\}$, and as $\{i, j\}$ runs over all pairs so does this pair; hence the first product is $\operatorname{sgn}(\sigma)$. For a transposition $(a\, b)$ with $a < b$ the pairs out of order are $(a, b)$ and, for each $c$ with $a < c < b$, the pairs $(a, c)$ and $(c, b)$, so $N = 2(b - a - 1) + 1$ is odd. $\blacksquare$

A permutation is **even** if its sign is $1$ and **odd** otherwise. The even permutations form a subgroup $A_n$ (the **alternating group**), by the product rule. For $n \ge 2$, $\sigma \mapsto \sigma\,(1\,2)$ is a bijection from the even to the odd permutations, so $|A_n| = n!/2$. A $k$-cycle has sign $(-1)^{k-1}$: a $4$-cycle is odd.

### Dihedral groups

Label the vertices of a regular $n$-gon ($n \ge 3$) by $1, \dots, n$ in order around it. A symmetry permutes the vertices and takes adjacent vertices to adjacent vertices. The **dihedral group** $D_n$ is the group of all such permutations. Let $r = (1\,2\,\dots\,n)$ be the rotation by one step, and let $s$ be the reflection $s(i) = 2 - i \pmod n$ fixing vertex $1$.

**Theorem 3.** $|D_n| = 2n$, and $D_n = \{r^k, r^k s : 0 \le k < n\}$ with $r^n = s^2 = e$ and $srs = r^{-1}$.

*Proof.* A symmetry $\varphi$ is determined by $\varphi(1)$ and $\varphi(2)$: the image of vertex $3$ must be a neighbor of $\varphi(2)$ other than $\varphi(1)$, and so on around the polygon. There are $n$ choices for $\varphi(1)$ and then $2$ choices for $\varphi(2)$, a neighbor of $\varphi(1)$, so $|D_n| \le 2n$. The $n$ rotations $r^k$ and the $n$ reflections $r^k s$ are distinct symmetries (compare images of $1$ and $2$), so there are exactly $2n$. The relations are checked on vertices. $\blacksquare$

Since $sr = r^{-1}s \ne rs$ when $r^2 \ne e$, $D_n$ is non-abelian for $n \ge 3$.

problem: In $S_6$ let $\sigma = (1\,4\,2)(3\,5\,6)$ and $\tau = (1\,3)(2\,6\,4)$. Compute $\sigma\tau$ in cycle notation, then find its order and sign.
step: Apply $\tau$ first, then $\sigma$. Start with $1$: $\tau(1) = 3$ and $\sigma(3) = 5$, so $1 \mapsto 5$.
step: Continue with $5$: $\tau(5) = 5$, $\sigma(5) = 6$, so $5 \mapsto 6$. Then $6$: $\tau(6) = 4$, $\sigma(4) = 2$, so $6 \mapsto 2$. Then $2$: $\tau(2) = 6$, $\sigma(6) = 3$, so $2 \mapsto 3$. Then $3$: $\tau(3) = 1$, $\sigma(1) = 4$, so $3 \mapsto 4$. Finally $4$: $\tau(4) = 2$, $\sigma(2) = 1$, so $4 \mapsto 1$.
step: All six points are in one cycle, so $\sigma\tau = (1\,5\,6\,2\,3\,4)$, a $6$-cycle.
step: The order is the cycle length, $6$. The sign of a $k$-cycle is $(-1)^{k-1}$, so a $6$-cycle has sign $-1$ and $\sigma\tau$ is odd. Check with the product rule: $\sigma$ is a product of two $3$-cycles, so it is even, and $\tau$ is a transposition times a $3$-cycle, so it is odd; hence $\sigma\tau$ has sign $(+1)(-1) = -1$.
answer: $\sigma\tau = (1\,5\,6\,2\,3\,4)$, of order $6$ and sign $-1$.

@example
title: The dihedral group of the pentagon
problem: In $D_5$, with $r = (1\,2\,3\,4\,5)$ and $s = (2\,5)(3\,4)$, show that $D_5$ is not abelian and find the order of every element.
step: Compute $rs$ (apply $s$ first): $1 \mapsto 1 \mapsto 2$, $2 \mapsto 5 \mapsto 1$, $3 \mapsto 4 \mapsto 5$, $4 \mapsto 3 \mapsto 4$, $5 \mapsto 2 \mapsto 3$, so $rs = (1\,2)(3\,5)$.
step: Compute $sr$ (apply $r$ first): $1 \mapsto 2 \mapsto 5$, $2 \mapsto 3 \mapsto 4$, $3 \mapsto 4 \mapsto 3$, $4 \mapsto 5 \mapsto 2$, $5 \mapsto 1 \mapsto 1$, so $sr = (1\,5)(2\,4)$. Since $rs \ne sr$, the group is not abelian.
step: The rotations $r^k$ with $k = 1, 2, 3, 4$ are $5$-cycles of order $5$, and $r^0 = e$ has order $1$.
step: Each of the five reflections $r^k s$ is a product of two disjoint transpositions fixing one vertex, so it has order $\operatorname{lcm}(2, 2) = 2$. The group has $1$ element of order $1$, $4$ of order $5$ and $5$ of order $2$: $1 + 4 + 5 = 10 = 2 \cdot 5$.
answer: $D_5$ is non-abelian; it has $1$ element of order $1$, $5$ of order $2$ and $4$ of order $5$.

@mistakes
- Multiplying cycles in the wrong order. With the convention $\sigma\tau = \sigma \circ \tau$, the rightmost permutation acts first; reading left to right gives $\tau\sigma$ instead.
- Taking the order of a product of cycles that are not disjoint to be the least common multiple of their lengths. $(1\,2)(1\,2\,3) = (2\,3)$ has order $2$, not $6$.
- Saying a $4$-cycle is even because $4$ is even. A $k$-cycle has sign $(-1)^{k-1}$, so a $4$-cycle is a product of three transpositions and is odd.
- Treating $D_n$ as having order $n$ (rotations only) or as abelian. There are $n$ rotations and $n$ reflections, and $srs = r^{-1}$.

```python
def sign(p):
    """Sign of a permutation: (-1) to the power n minus the cycle count."""
    seen = [False] * len(p)
    cycle_count = 0
    for start in range(len(p)):
        if not seen[start]:
            cycle_count += 1
            j = start
            while not seen[j]:
                seen[j] = True
                j = p[j]
    return -1 if (len(p) - cycle_count) % 2 else 1
```
hint: A $k$-cycle (including a fixed point, a $1$-cycle) is a product of $k - 1$ transpositions.
hint: Adding up over all cycles, $p$ is a product of $n - c$ transpositions, where $c$ is the number of cycles counting fixed points.
solution: A permutation of $n$ points with $c$ cycles (fixed points count as cycles of length $1$) is a product of $\sum (k_i - 1) = n - c$ transpositions, so its sign is $(-1)^{n-c}$. The code counts cycles by walking each unvisited point around its cycle. A computation like this applies the theorem that the parity of the number of transpositions is well defined.

prompt: Let $\sigma$ be a $k$-cycle in $S_n$ and $m \ge 1$ an integer, and put $d = \gcd(k, m)$. Prove that $\sigma^m$ is a product of $d$ disjoint cycles, each of length $k/d$, on the $k$ points moved by $\sigma$.
hint: Write the cycle as $(a_0\, a_1\, \dots\, a_{k-1})$, so that $\sigma^m(a_j) = a_{j+m}$ with indices modulo $k$.
hint: The cycle of $\sigma^m$ through $a_j$ consists of the $a_{j + tm}$; which residues modulo $k$ do the numbers $tm$ cover?
solution: Write $\sigma = (a_0\, a_1\, \dots\, a_{k-1})$ with indices modulo $k$, so $\sigma^m(a_j) = a_{j+m}$. The cycle of $\sigma^m$ containing $a_j$ is $\{a_{j+tm} : t \in \mathbb{Z}\}$. The set of residues $\{tm \bmod k\}$ is the subgroup of $\mathbb{Z}/k\mathbb{Z}$ generated by $m$, which equals the subgroup generated by $d = \gcd(k, m)$, namely the multiples of $d$; it has $k/d$ elements (lesson 2). So each cycle of $\sigma^m$ has length $k/d$, it consists of the $a_i$ with $i \equiv j \pmod d$, and the cycles correspond to the $d$ residues $j \bmod d$. These are $d$ disjoint cycles of length $k/d$ that together cover all $k$ points. $\blacksquare$

```python
def perm_power(p, k):
    """The k-th power of a permutation, for any integer k."""
    result = list(range(len(p)))
    seen = [False] * len(p)
    for start in range(len(p)):
        if seen[start]:
            continue
        cycle, j = [start], p[start]
        seen[start] = True
        while j != start:
            cycle.append(j)
            seen[j] = True
            j = p[j]
        length = len(cycle)
        for index, x in enumerate(cycle):
            result[x] = cycle[(index + k) % length]
    return result
```
hint: Do not apply `p` repeatedly: on a cycle of length $L$, $p^k$ moves each point $k \bmod L$ steps along the cycle.
solution: Split `p` into cycles. On a cycle of length $L$ listed in the order of `p`, the point in position `index` goes to the position `(index + k) % L`; Python's `%` returns a nonnegative result, so negative `k` (powers of the inverse) works with no special case, and large `k` is reduced modulo $L$ automatically.

@article
In $\mathbb{Z}/12\mathbb{Z}$ take the subgroup $H = \{0, 4, 8\}$ and add $1$ to each element: $\{1, 5, 9\}$. Add $2$: $\{2, 6, 10\}$. Add $3$: $\{3, 7, 11\}$. These four blocks of size three are disjoint and cover all twelve elements. A subgroup always slices its group into equal blocks like this, so $|H|$ must divide $|G|$.

### Cosets

**Definition.** Let $H \le G$ and $a \in G$. The **left coset** of $H$ containing $a$ is $aH = \{ah : h \in H\}$ (in an additive group, $a + H$). The right coset is $Ha$. The number of left cosets is the **index** $[G : H]$.

**Lemma 1.** Let $H \le G$ and $a, b \in G$. Then (a) $a \in aH$; (b) $aH = bH$ if and only if $a^{-1}b \in H$; (c) two left cosets are either equal or disjoint; (d) $|aH| = |H|$ (also when $G$ is infinite, as a cardinality statement).

*Proof.* (a) $a = ae$ with $e \in H$. (b) If $aH = bH$ then $b = be \in aH$, so $b = ah$ and $a^{-1}b = h \in H$. Conversely if $a^{-1}b = h \in H$ then $b = ah$ and $bH = \{ahh' : h' \in H\} \subseteq aH$; also $a = bh^{-1}$ gives $aH \subseteq bH$. (c) If $c \in aH \cap bH$, write $c = ah_1 = bh_2$. Then $a^{-1}b = h_1 h_2^{-1} \in H$, so $aH = bH$ by (b). (d) The map $H \to aH$, $h \mapsto ah$ is surjective by definition and injective by cancellation. $\blacksquare$

So the left cosets partition $G$. Computing them in Python for an additive subgroup:

```python
def cosets(n, H):
    """The cosets x + H of a subgroup H of (Z/nZ, +), as sorted lists."""
    seen, out = set(), []
    for x in range(n):
        c = tuple(sorted((x + h) % n for h in H))
        if c not in seen:
            seen.add(c)
            out.append(list(c))
    return out


print(cosets(12, [0, 4, 8]))
```

It prints `[[0, 4, 8], [1, 5, 9], [2, 6, 10], [3, 7, 11]]`, the four blocks above.

### Lagrange's theorem

**Theorem 2 (Lagrange).** If $G$ is a finite group and $H \le G$, then $|G| = [G : H]\,|H|$. In particular $|H|$ divides $|G|$.

*Proof.* By Lemma 1 the $[G : H]$ left cosets partition $G$ into sets each of size $|H|$, so $|G|$ is their number times $|H|$. $\blacksquare$

**Corollary 3.** Let $G$ be finite. (a) The order of every $g \in G$ divides $|G|$, and $g^{|G|} = e$. (b) If $|G| = p$ is prime, then $G$ is cyclic, generated by any element other than $e$. (c) (Euler's theorem) If $\gcd(a, n) = 1$ then $a^{\varphi(n)} \equiv 1 \pmod{n}$; in particular, Fermat's little theorem $a^{p-1} \equiv 1 \pmod p$ for $p \nmid a$.

*Proof.* (a) The order of $g$ is $|\langle g \rangle|$ (lesson 2), which divides $|G|$; then $g^{|G|} = (g^{m})^{|G|/m} = e$ where $m$ is the order of $g$. (b) If $g \ne e$ then $|\langle g \rangle| > 1$ divides $p$, so equals $p$, and $\langle g \rangle = G$. (c) Apply (a) to the class of $a$ in the group $(\mathbb{Z}/n\mathbb{Z})^\times$ of order $\varphi(n)$. $\blacksquare$

### The converse is false

Lagrange's theorem gives a necessary condition on subgroup orders, not a sufficient one. The alternating group $A_4$ (even permutations of four points) has order $12$ but **no subgroup of order $6$**. First a lemma.

**Lemma 4.** If $[G : H] = 2$ then $g^2 \in H$ for every $g \in G$.

*Proof.* If $g \in H$ this is clear. If $g \notin H$, the two left cosets are $H$ and $gH$ (the coset $gH$ differs from $H$ since $g \in gH$). Suppose $g^2 \notin H$. Then $g^2 \in gH$, say $g^2 = gh$ with $h \in H$; canceling gives $g = h \in H$, a contradiction. $\blacksquare$

Now suppose $H \le A_4$ with $|H| = 6$. Then $[A_4 : H] = 2$, so $H$ contains $g^2$ for all $g \in A_4$. Every $3$-cycle $c$ satisfies $c^3 = e$, hence $c = c^4 = (c^2)^2$ lies in $H$. But $A_4$ contains $\binom{4}{3} \cdot 2 = 8$ three-cycles, more than $|H| = 6$. This contradiction proves the claim.

Right cosets give the same count: $aH \mapsto Ha^{-1}$ is a well-defined bijection from left to right cosets. Left and right cosets can still differ as sets, which leads to normal subgroups in the next lesson.

@example
title: Cosets and an index
problem: In $\mathbb{Z}/20\mathbb{Z}$ let $H = \langle 5 \rangle$. List the elements of $H$ and all its cosets, and check Lagrange's theorem.
step: $H = \{0, 5, 10, 15\}$, since $5$ has order $20/\gcd(20, 5) = 4$ and its multiples are $5, 10, 15, 20 \equiv 0$.
step: Add $1, 2, 3, 4$ to $H$: $1 + H = \{1, 6, 11, 16\}$, $2 + H = \{2, 7, 12, 17\}$, $3 + H = \{3, 8, 13, 18\}$, $4 + H = \{4, 9, 14, 19\}$.
step: These five cosets $0 + H, \dots, 4 + H$ are disjoint and together contain $5 \cdot 4 = 20$ elements, so they are all the cosets; for example $7 + H = 2 + H$ because $7 - 2 = 5 \in H$.
step: Lagrange: $|G| = 20 = [G : H]\,|H| = 5 \cdot 4$, and $4 \mid 20$.
answer: There are $5$ cosets, each of size $4$, so $[G : H] = 5$.

@example
title: Reducing a large power with Euler's theorem
problem: Find the remainder of $3^{1000}$ when divided by $14$.
step: $\gcd(3, 14) = 1$, so $3$ is an element of the group $(\mathbb{Z}/14\mathbb{Z})^\times$, of order $\varphi(14) = 6$.
step: By Corollary 3(a), $3^6 \equiv 1 \pmod{14}$ (check: $3^6 = 729 = 52 \cdot 14 + 1$).
step: Write $1000 = 6 \cdot 166 + 4$. Then $3^{1000} = (3^6)^{166} \cdot 3^4 \equiv 3^4 \pmod{14}$.
step: $3^4 = 81 = 5 \cdot 14 + 11$, so the remainder is $11$.
answer: $3^{1000} \equiv 11 \pmod{14}$.

@mistakes
- Reading Lagrange's theorem backwards. It says $|H|$ divides $|G|$; it does not say that every divisor of $|G|$ occurs as a subgroup order. $A_4$ has no subgroup of order $6$.
- Comparing cosets by listing one representative: $aH = bH$ is a statement about sets, tested by $a^{-1}b \in H$, not by $a = b$. Different representatives can give the same coset.
- Expecting the size of an arbitrary subset to divide $|G|$. Only subgroups must: $\{0, 1, 2, 3, 4\} \subseteq \mathbb{Z}/12\mathbb{Z}$ has $5$ elements, and $5 \nmid 12$, which just shows it is not a subgroup.
- Mixing up left and right cosets. $aH$ and $Ha$ are different sets in general, and $a^{-1}b \in H$ tests left cosets only.

model:
```python
def left_cosets(G, H):
    """Distinct left cosets gH of H in G, each coset a sorted list."""
    found = set()
    for g in G:
        coset = tuple(sorted(tuple(g[h[i]] for i in range(len(h))) for h in H))
        found.add(coset)
    return sorted(list(c) for c in found)
```
hint: For each $g$, form the set of products $g * h$ with $h \in H$.
hint: Store each coset as a sorted tuple in a set, so that equal cosets from different representatives are counted once.
solution: A coset has many representatives (every element of it gives the same set), so collect the cosets as canonical objects, sorted tuples, in a set. Left multiplication by `g` composes `g` after each `h`, giving `g[h[i]]`. In $S_3$ with $H$ of order $2$ there are $6/2 = 3$ cosets, as Lagrange's theorem predicts. The left cosets of this $H$ are not its right cosets, which are $\{(0,2,1), (1,2,0)\}$ and $\{(2,0,1), (2,1,0)\}$ in addition to $H$.

@practice self
prompt: Prove that a finite group of even order contains an element of order $2$.
hint: Pair each element $g$ with $g^{-1}$. Which elements are paired with themselves?
hint: Count the elements with $g \ne g^{-1}$ and use that the total is even.
solution: Let $|G|$ be even. Let $X = \{g \in G : g \ne g^{-1}\}$. The map $g \mapsto g^{-1}$ is an involution without fixed points on $X$ (it maps $X$ to $X$, since $g \ne g^{-1}$ implies $g^{-1} \ne (g^{-1})^{-1}$), so $X$ splits into pairs $\{g, g^{-1}\}$ and $|X|$ is even. The complement $G \setminus X = \{g : g = g^{-1}\} = \{g : g^2 = e\}$ then has even size $|G| - |X|$, and contains $e$, so it contains at least one more element $g \ne e$. That element satisfies $g^2 = e$ and $g \ne e$, so $g$ has order $2$. $\blacksquare$

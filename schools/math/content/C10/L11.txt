@article
In $S_3$, conjugate $(1\,2)$ by $(1\,3)$: the result is $(3\,2)$, another transposition. Conjugation seems to relabel the points moved by a permutation without changing its shape. Making this precise sorts a group into classes of elements that are "the same up to a change of viewpoint", and counting those classes gives an equation that is powerful for $p$-groups.

### Conjugacy classes and centralizers

A group $G$ acts on itself by conjugation, $g \cdot x = gxg^{-1}$ (it satisfies $e \cdot x = x$ and $(gh) \cdot x = g \cdot (h \cdot x)$). The orbit of $x$ is its **conjugacy class** $\operatorname{cl}(x) = \{gxg^{-1} : g \in G\}$ and the stabilizer is the **centralizer** $C_G(x) = \{g \in G : gx = xg\}$. The **center** is $Z(G) = \{z : zg = gz \text{ for all } g\}$.

**Theorem 1.** (a) The conjugacy classes partition $G$. (b) $|\operatorname{cl}(x)| = [G : C_G(x)]$, which divides $|G|$ if $G$ is finite. (c) $\operatorname{cl}(x) = \{x\}$ if and only if $x \in Z(G)$. (d) Conjugate elements have the same order.

*Proof.* (a) and (b) are Theorems 1 and 2 of lesson 9 for the conjugation action. (c) $gxg^{-1} = x$ for all $g$ means $x$ commutes with every element. (d) $(gxg^{-1})^k = gx^kg^{-1}$, which equals $e$ if and only if $x^k = e$. $\blacksquare$

### Conjugacy in $S_n$

**Theorem 2.** Two permutations of $\{1, \dots, n\}$ are conjugate in $S_n$ if and only if they have the same cycle type (the same multiset of cycle lengths, including $1$-cycles).

*Proof.* For $\tau \in S_n$ and a cycle $\sigma = (a_1\,a_2\,\dots\,a_k)$ we have $\tau\sigma\tau^{-1} = (\tau(a_1)\,\tau(a_2)\,\dots\,\tau(a_k))$: indeed $\tau\sigma\tau^{-1}(\tau(a_i)) = \tau(\sigma(a_i)) = \tau(a_{i+1})$, and points outside $\{\tau(a_i)\}$ are fixed. Applying this to each cycle of a disjoint-cycle decomposition shows that conjugation relabels the entries and keeps the cycle lengths. Conversely, suppose $\sigma$ and $\sigma'$ have the same cycle type. Write both as products of disjoint cycles including $1$-cycles, listing the cycles of equal lengths in matching order, and let $\tau$ send the $j$-th entry written for $\sigma$ to the $j$-th entry written for $\sigma'$. Then $\tau\sigma\tau^{-1} = \sigma'$ by the formula. $\blacksquare$

So the class sizes of $S_4$ are found by counting permutations of each cycle type: the identity ($1$), transpositions ($\binom{4}{2} = 6$), double transpositions ($3$), $3$-cycles ($8$) and $4$-cycles ($6$), and $24 = 1 + 6 + 3 + 8 + 6$. Here is code that finds the classes of any permutation group directly, with permutations as tuples (`s[i]` is the image of `i`):

```python
import itertools


def compose(s, t):
    return tuple(s[t[i]] for i in range(len(t)))


def inverse(s):
    inv = [0] * len(s)
    for i, x in enumerate(s):
        inv[x] = i
    return tuple(inv)


def conjugacy_classes(G):
    """Conjugacy classes of a permutation group G (a list of tuples)."""
    seen, classes = set(), []
    for g in G:
        if g in seen:
            continue
        cls = sorted({compose(compose(x, g), inverse(x)) for x in G})
        seen.update(cls)
        classes.append(cls)
    return classes


S4 = list(itertools.permutations(range(4)))
print(sorted(len(c) for c in conjugacy_classes(S4)))
```

It prints `[1, 3, 6, 6, 8]`, matching the cycle-type count.

### The class equation

**Theorem 3 (class equation).** Let $G$ be a finite group and $g_1, \dots, g_r$ representatives of the conjugacy classes with more than one element. Then
$$|G| = |Z(G)| + \sum_{i=1}^{r} [G : C_G(g_i)],$$
and each index $[G : C_G(g_i)]$ is a divisor of $|G|$ greater than $1$.

*Proof.* The classes partition $G$. The classes of size $1$ are the singletons $\{z\}$ with $z \in Z(G)$ (Theorem 1(c)), contributing $|Z(G)|$. The other classes have size $[G : C_G(g_i)] > 1$. Adding the sizes of all classes gives $|G|$. $\blacksquare$

**Theorem 4.** If $|G| = p^n$ with $p$ prime and $n \ge 1$, then $Z(G) \ne \{e\}$.

*Proof.* Each index $[G : C_G(g_i)]$ is a divisor of $p^n$ greater than $1$, so it is divisible by $p$. Also $p \mid |G|$. From the class equation, $|Z(G)| = |G| - \sum [G : C_G(g_i)]$ is divisible by $p$. Since $|Z(G)| \ge 1$ (it contains $e$), we get $|Z(G)| \ge p$. $\blacksquare$

**Corollary 5.** Every group of order $p^2$, with $p$ prime, is abelian.

*Proof.* By Theorem 4, $|Z(G)| \in \{p, p^2\}$. If $|Z(G)| = p$, then $G/Z(G)$ has order $p$ and is cyclic (a group of prime order). If $gZ(G)$ generates it, every element of $G$ has the form $g^iz$ with $z \in Z(G)$, and any two such elements $g^iz$ and $g^jw$ commute because $z, w$ are central; so $G$ is abelian and $Z(G) = G$ has order $p^2$, a contradiction. Hence $Z(G) = G$. $\blacksquare$

By the classification of lesson 8, a group of order $p^2$ is $\mathbb{Z}/p^2\mathbb{Z}$ or $\mathbb{Z}/p\mathbb{Z} \times \mathbb{Z}/p\mathbb{Z}$.

@example
title: Classes of the dihedral group of order 10
problem: In $D_5 = \{r^k, r^ks\}$ with $r^5 = s^2 = e$ and $srs = r^{-1}$, find the conjugacy classes using centralizers.
step: The center is trivial: $r$ is conjugated to $r^{-1} \ne r$ by $s$, and $s$ is conjugated to $rsr^{-1} = r^2s \ne s$ by $r$. So the identity is the only class of size $1$.
step: The centralizer of $r$ contains $\langle r \rangle$ of order $5$ and does not contain $s$, so it has order $5$ (it is a proper subgroup whose order is a multiple of $5$ dividing $10$). The class of $r$ has $10/5 = 2$ elements: $\{r, r^{-1}\}$. Likewise $\{r^2, r^{-2}\}$.
step: The centralizer of $s$ contains $\{e, s\}$ and does not contain $r$ (since $rs \ne sr$), so its order is $2$ and the class of $s$ has $10/2 = 5$ elements: all five reflections.
step: The class equation is $10 = 1 + 2 + 2 + 5$.
answer: The classes are $\{e\}$, $\{r, r^4\}$, $\{r^2, r^3\}$ and the set of five reflections.

@mistakes
- Assuming that elements of the same cycle type are conjugate in every subgroup of $S_n$. Theorem 2 is about conjugation by all of $S_n$; inside $A_4$ the eight $3$-cycles split into two classes of size $4$.
- Forgetting that the identity (and every central element) is a class of size $1$ in the class equation. The term $|Z(G)|$ counts all of them.
- Using the class equation to claim that $Z(G)$ is nontrivial for every group. The proof of Theorem 4 needs the order to be a power of a prime; $Z(S_3)$ is trivial.
- Mixing up the centralizer of an element with the center of the group. $C_G(x)$ depends on $x$, always contains $x$ and $Z(G)$, and $Z(G) = \bigcap_x C_G(x)$.

model:
```python
def class_sizes(table):
    """Sorted sizes of the conjugacy classes of a group table."""
    n = len(table)
    inverse = [next(j for j in range(n) if table[i][j] == 0)
               for i in range(n)]
    seen = set()
    sizes = []
    for g in range(n):
        if g in seen:
            continue
        cls = {table[table[x][g]][inverse[x]] for x in range(n)}
        seen |= cls
        sizes.append(len(cls))
    return sorted(sizes)
```
hint: First find the inverse of each element: the `j` with `table[i][j] == 0`.
hint: The conjugate of `g` by `x` is `x * g * x^-1`, that is `table[table[x][g]][inverse[x]]`. Collect all conjugates of `g` into a set.
solution: Build the inverse of each element from the table, then for each element not yet in a class collect its conjugates $xgx^{-1}$ over all $x$. Mark them as seen so that each class is counted once, and record the sizes. The sizes sum to $n$, and the number of size-$1$ classes is $|Z(G)|$.

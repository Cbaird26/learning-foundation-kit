Compute the powers of $3$ modulo $7$: $3, 2, 6, 4, 5, 1$. Every unit modulo $7$ appears. Now the powers of $2$: $2, 4, 1$, and then the list repeats. The set $\{1, 2, 4\}$ is closed under multiplication and inverses, a smaller group sitting inside $(\mathbb{Z}/7\mathbb{Z})^\times$. This lesson says how to recognize such sub-objects and how to describe all of them when the group is generated by one element.

### Subgroups

**Definition.** A subset $H$ of a group $G$ is a **subgroup**, written $H \le G$, if $H$ is a group under the operation of $G$. Equivalently, $H$ contains $e$, and is closed under products and inverses. A subgroup is **proper** if $H \ne G$ and **trivial** if $H = \{e\}$.

**Theorem 1 (subgroup test).** Let $H$ be a subset of a group $G$.

(a) $H$ is a subgroup if and only if $H \ne \emptyset$ and $ab^{-1} \in H$ for all $a, b \in H$.

(b) If $H$ is finite and nonempty and $ab \in H$ for all $a, b \in H$, then $H$ is a subgroup.

*Proof.* (a) A subgroup is nonempty and contains $ab^{-1}$ by closure. Conversely, pick $h \in H$. Taking $a = b = h$ gives $e = hh^{-1} \in H$. Taking $a = e$ and $b \in H$ gives $b^{-1} \in H$. For $a, b \in H$ we now have $b^{-1} \in H$, so $ab = a(b^{-1})^{-1} \in H$. Associativity is inherited from $G$.

(b) Take $a \in H$. The powers $a, a^2, a^3, \dots$ lie in $H$ by closure, and $H$ is finite, so $a^m = a^n$ for some $m > n \ge 1$. Cancel $a^n$ (Theorem 1 of lesson 1) to get $a^{m-n} = e$, so $e \in H$ and $a^{-1} = a^{m-n-1} \in H$ (with $a^0 = e$). So $H$ contains $e$ and inverses, and is closed. $\blacksquare$

The finiteness in (b) is needed: $\mathbb{N}$ is closed under addition in $\mathbb{Z}$ but is not a subgroup.

### Cyclic subgroups and orders

For $g \in G$ put $\langle g \rangle = \{g^k : k \in \mathbb{Z}\}$. By the test above it is a subgroup (since $g^k (g^l)^{-1} = g^{k-l}$), the smallest subgroup containing $g$. $G$ is **cyclic** if $G = \langle g \rangle$ for some $g$, called a **generator**.

**Theorem 2.** Let $g$ have finite order $n$. Then (a) $g^k = e$ if and only if $n \mid k$; (b) $\langle g \rangle = \{e, g, \dots, g^{n-1}\}$ has exactly $n$ elements; (c) $g^k$ has order $n / \gcd(n, k)$.

*Proof.* (a) If $k = qn$ then $g^k = (g^n)^q = e$. Conversely write $k = qn + r$ with $0 \le r < n$; if $g^k = e$ then $g^r = g^k (g^n)^{-q} = e$, so $r = 0$ by minimality of $n$. (b) Any $g^k$ equals $g^r$ with $r = k \bmod n$ by (a), and $g^0, \dots, g^{n-1}$ are distinct: $g^i = g^j$ with $0 \le i < j < n$ would give $g^{j-i} = e$ with $0 < j - i < n$. (c) Let $d = \gcd(n, k)$. Then $(g^k)^m = e$ if and only if $n \mid km$ by (a), if and only if $\frac{n}{d} \mid \frac{k}{d} m$, and since $\gcd(\frac nd, \frac kd) = 1$ this holds if and only if $\frac nd \mid m$. The least such $m$ is $n/d$. $\blacksquare$

In $\mathbb{Z}/n\mathbb{Z}$ under addition, with $g = 1$ of order $n$, the element $k$ has order $n / \gcd(n, k)$, and it generates when $\gcd(n, k) = 1$. For $\mathbb{Z}/12\mathbb{Z}$:

```python
def cyclic_subgroup(g, n):
    """The subgroup of Z/nZ (under +) generated by g, as a sorted list."""
    elems, x = [0], g % n
    while x != 0:
        elems.append(x)
        x = (x + g) % n
    return sorted(elems)


print(cyclic_subgroup(8, 12), len(cyclic_subgroup(5, 12)))
```

It prints `[0, 4, 8] 12`: the element $8$ has order $12/\gcd(12, 8) = 3$ and $5$ is a generator.

### Subgroups of cyclic groups

**Theorem 3.** Every subgroup of a cyclic group is cyclic. If $G = \langle g \rangle$ has order $n$, then for each divisor $d$ of $n$ there is exactly one subgroup of order $d$, namely $\langle g^{n/d} \rangle$, and $G$ has $\varphi(n)$ generators, the elements $g^k$ with $\gcd(k, n) = 1$.

*Proof.* Let $H \le \langle g \rangle$ with $H \ne \{e\}$. Let $m$ be the least positive integer with $g^m \in H$ (it exists since $H$ contains some $g^k$ with $k \ne 0$, and $g^{-k} \in H$ too). If $g^k \in H$, write $k = qm + r$ with $0 \le r < m$. Then $g^r = g^k (g^m)^{-q} \in H$, so $r = 0$ by minimality, and $g^k = (g^m)^q$. Hence $H = \langle g^m \rangle$. For the count: a subgroup of order $d$ is $\langle g^k \rangle$ for some $k$, so $d = n/\gcd(n, k)$ by Theorem 2(c), giving $\gcd(n,k) = n/d$, and then $n/d$ divides $k$, so $g^k \in \langle g^{n/d} \rangle$. Both subgroups have order $d$, so they are equal. The generators are the $g^k$ of order $n$, that is, with $\gcd(n, k) = 1$. $\blacksquare$

For $G = \mathbb{Z}/12\mathbb{Z}$ the subgroups are $\langle 0 \rangle, \langle 6 \rangle, \langle 4 \rangle, \langle 3 \rangle, \langle 2 \rangle, \langle 1 \rangle$, of orders $1, 2, 3, 4, 6, 12$, and the generators are $1, 5, 7, 11$.

@example
title: Proving a subset of a group of units is a subgroup
problem: Let $H = \{1, 4, 11, 14\} \subseteq (\mathbb{Z}/15\mathbb{Z})^\times$. Prove that $H$ is a subgroup and find the order of each element.
step: Each of $1, 4, 11, 14$ is coprime to $15$, so $H$ lies in the group $(\mathbb{Z}/15\mathbb{Z})^\times$. $H$ is finite and nonempty, so by Theorem 1(b) it suffices to show it is closed under multiplication.
step: Compute the products modulo $15$: $4 \cdot 4 = 16 \equiv 1$, $4 \cdot 11 = 44 \equiv 14$, $4 \cdot 14 = 56 \equiv 11$, $11 \cdot 11 = 121 \equiv 1$, $11 \cdot 14 = 154 \equiv 4$, $14 \cdot 14 = 196 \equiv 1$. Every product is in $H$ (products with $1$ are trivial, and the others follow by commutativity).
step: So $H$ is a subgroup. Orders: $1$ has order $1$; $4^2 \equiv 1$, $11^2 \equiv 1$ and $14^2 \equiv 1$, and none of these three is $1$, so each has order $2$.
answer: $H$ is a subgroup; $1$ has order $1$ and $4, 11, 14$ have order $2$.

@example
title: Orders of powers of an element of order 30
problem: Let $g$ be an element of order $30$ in a group. Find the order of $g^{12}$ and of $g^{25}$, and count the elements of order $10$ in $\langle g \rangle$.
step: By Theorem 2(c), $g^k$ has order $30 / \gcd(30, k)$.
step: For $k = 12$: $\gcd(30, 12) = 6$, so $g^{12}$ has order $30/6 = 5$. For $k = 25$: $\gcd(30, 25) = 5$, so $g^{25}$ has order $6$.
step: The elements of order $10$ in $\langle g \rangle$ are the generators of the unique subgroup of order $10$, which is cyclic of order $10$ (Theorem 3), so there are $\varphi(10) = 4$ of them. Explicitly they are $g^k$ with $\gcd(30, k) = 3$, namely $k = 3, 9, 21, 27$.
answer: $g^{12}$ has order $5$, $g^{25}$ has order $6$, and there are $4$ elements of order $10$.

@mistakes
- Using the finite test (b) for an infinite set. Closure alone does not make $\mathbb{N} \subseteq \mathbb{Z}$ a subgroup; inverses must be shown.
- Forgetting that the order of $g^k$ is $n/\gcd(n, k)$, not $n/k$. For $n = 12$ and $k = 8$ the order is $3$, not $1.5$.
- Believing that a union of subgroups is a subgroup. $2\mathbb{Z} \cup 3\mathbb{Z}$ contains $2$ and $3$ but not $2 + 3 = 5$.
- Believing every subgroup of an abelian group is cyclic. The Klein four-group $\{0, 1, 2, 3\}$ under bitwise exclusive or has three subgroups of order $2$ and is not cyclic.

@practice self
prompt: Let $H = \{k \in (\mathbb{Z}/35\mathbb{Z})^\times : k \equiv 1 \pmod 5\} = \{1, 6, 11, 16, 26, 31\}$. Prove that $H$ is a subgroup of $(\mathbb{Z}/35\mathbb{Z})^\times$ and find the order of every element of $H$.
hint: Use the one-step test, or show closure and use that $H$ is finite. Closure is easy with the congruence condition, since $5 \mid 35$.
hint: Compute the powers of each element modulo $35$ until you reach $1$.
solution: $H$ is nonempty ($1 \in H$) and finite. If $a, b \in H$ then $a \equiv b \equiv 1 \pmod 5$, so $ab \equiv 1 \pmod 5$; reducing $ab$ modulo $35$ keeps its residue modulo $5$ because $5 \mid 35$. Also $ab$ is coprime to $35$ because both factors are units. So $ab \in H$, and $H$ is a subgroup by the finite test. Orders: $6^2 = 36 \equiv 1$, so $6$ has order $2$. $11^2 = 121 \equiv 16$ and $11^3 \equiv 16 \cdot 11 = 176 \equiv 1$, so $11$ has order $3$; $16 = 11^2$ also has order $3$. $26^2 = 676 \equiv 11$, $26^3 \equiv 11 \cdot 26 = 286 \equiv 6$, so $26^6 \equiv 36 \equiv 1$ with $26^2 \ne 1$ and $26^3 \ne 1$: order $6$; likewise $31$ has order $6$ ($31^2 = 961 \equiv 16$, $31^3 \equiv 16 \cdot 31 = 496 \equiv 6$). The identity $1$ has order $1$. So $H$ is cyclic of order $6$, generated by $26$ or $31$.

rubric: Proves closure using $a \equiv b \equiv 1 \pmod 5$ and that products of units are units.
rubric: Gives the orders $1, 2, 3, 3, 6, 6$ with the powers computed.

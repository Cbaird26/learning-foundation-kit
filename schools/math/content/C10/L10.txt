@article
How many different necklaces can you make from $4$ beads, each black or white, when two necklaces count as the same if one is a rotation of the other? There are $2^4 = 16$ colorings of the four positions, but many are rotations of each other: the colorings with one black bead form a single necklace, not four. Listing by hand finds $6$ necklaces, but a counting formula is better. The right tool is the following lemma, usually called Burnside's lemma (it is also credited to Cauchy and Frobenius).

### Burnside's lemma

**Theorem 1 (Burnside's lemma).** Let a finite group $G$ act on a finite set $X$. Then the number of orbits is
$$|X/G| = \frac{1}{|G|}\sum_{g \in G} |\operatorname{Fix}(g)|.$$

*Proof.* Count the set $P = \{(g, x) \in G \times X : g \cdot x = x\}$ in two ways. Summing over $g$ gives $|P| = \sum_g |\operatorname{Fix}(g)|$. Summing over $x$ gives $|P| = \sum_x |G_x|$. By the orbit-stabilizer theorem $|G_x| = |G|/|Gx|$, so
$$|P| = |G|\sum_{x \in X}\frac{1}{|Gx|} = |G|\sum_{O}\ \sum_{x \in O}\frac{1}{|O|} = |G|\sum_{O} 1,$$
where $O$ runs over the orbits, because the orbits partition $X$ and each orbit contributes $|O| \cdot \frac{1}{|O|} = 1$. Hence $|P| = |G|\,|X/G|$, and dividing by $|G|$ gives the formula. $\blacksquare$

### Colorings

Let a group $G$ of permutations of the positions $\{0, \dots, n-1\}$ (for example, the rotations of a necklace) act on the set $X$ of colorings $c\colon \{0, \dots, n-1\} \to \{1, \dots, k\}$ by $(g \cdot c)(i) = c(g^{-1}(i))$. Two colorings are equivalent when they lie in one orbit.

**Lemma 2.** The number of $k$-colorings fixed by a permutation $g$ is $k^{c(g)}$, where $c(g)$ is the number of cycles of $g$, counting fixed points as cycles of length $1$.

*Proof.* A coloring $c$ is fixed if and only if $c(g^{-1}(i)) = c(i)$ for all $i$, that is, if $c$ takes the same value along each cycle of $g$. Such a coloring is chosen by picking a color for each cycle independently. $\blacksquare$

**Corollary 3.** The number of $k$-colorings up to $G$ is $\dfrac{1}{|G|}\sum_{g \in G} k^{c(g)}$.

For the $n$ rotations of a necklace of $n$ beads, the rotation by $j$ positions is a power of an $n$-cycle, so by the cycle-power rule of lesson 3 it has $\gcd(n, j)$ cycles. The number of necklaces is $\frac{1}{n}\sum_{j=0}^{n-1} k^{\gcd(n, j)}$, where $\gcd(n, 0) = n$. For $n = 4$ and $k = 2$: $\frac{1}{4}(2^4 + 2^1 + 2^2 + 2^1) = 6$, as found by hand.

The same computation in Python takes a list of permutations (each a list `p` with `p[i]` the image of `i`). Here we count the colorings of the vertices of a square with $3$ colors, first up to rotation and then up to all eight symmetries:

```python
def num_cycles(p):
    """Number of cycles of p, counting fixed points."""
    seen, count = set(), 0
    for start in range(len(p)):
        if start not in seen:
            count += 1
            j = start
            while j not in seen:
                seen.add(j)
                j = p[j]
    return count


def burnside(perms, k):
    """Colorings with k colors up to the group `perms`."""
    total = sum(k ** num_cycles(p) for p in perms)
    assert total % len(perms) == 0
    return total // len(perms)


rotations = [[(i + j) % 4 for i in range(4)] for j in range(4)]
reflections = [[(j - i) % 4 for i in range(4)] for j in range(4)]
print(burnside(rotations, 3), burnside(rotations + reflections, 3))
```

It prints `24 21`. The divisibility assertion is a built-in check: if Burnside's sum is not divisible by $|G|$, then `perms` is not a group or is not closed under products.

@example
title: Necklaces of six beads
problem: How many distinct necklaces of $6$ beads in $2$ colors are there when rotations are identified?
step: The group is the cyclic group of rotations of the six positions, of order $6$. The rotation by $j$ steps has $\gcd(6, j)$ cycles.
step: The cycle counts for $j = 0, 1, 2, 3, 4, 5$ are $6, 1, 2, 3, 2, 1$, and the numbers of fixed colorings $2^c$ are $64, 2, 4, 8, 4, 2$.
step: The sum is $64 + 2 + 4 + 8 + 4 + 2 = 84$.
step: By Burnside's lemma the number of necklaces is $84/6 = 14$.
answer: There are $14$ necklaces.

@example
title: Coloring the edges of a triangle
problem: Each edge of a triangle is painted with one of $3$ colors. How many colorings are there if two are the same when a symmetry of the triangle (rotation or reflection) takes one to the other?
step: The symmetry group $D_3$ has order $6$ and acts on the three edges as the full symmetric group $S_3$: the identity, two rotations (3-cycles of the edges) and three reflections (each swaps two edges and fixes the third).
step: Cycles of the edges: the identity has $3$ cycles; each rotation has $1$ cycle; each reflection has $2$ cycles (one swap and one fixed edge).
step: Fixed colorings with $3$ colors: $3^3 = 27$ for the identity, $3^1 = 3$ for each of the two rotations, and $3^2 = 9$ for each of the three reflections.
step: The sum is $27 + 2 \cdot 3 + 3 \cdot 9 = 60$, and $60/6 = 10$.
answer: There are $10$ colorings up to symmetry.

@mistakes
- Dividing by $|X|$ or by the number of colorings instead of $|G|$. The denominator is the order of the group, and the numerator adds the fixed colorings of each group element, the identity included.
- Counting only the cycles of length at least $2$. A fixed point is a cycle of length $1$ and contributes a factor of $k$ (choices for that position); omitting it gives the wrong exponent.
- Using the reflection count of a polygon without distinguishing odd from even $n$. For a square, two reflections fix two vertices (three cycles) and two fix none (two cycles), so the four reflections do not all contribute the same.
- Treating the answer as a proof for infinite families after checking small cases. Burnside's lemma is a theorem about finite groups acting on finite sets, and the divisibility check in code is a sanity check, not a proof of correctness.

model:
```python
def count_with_black(perms, m):
    """Orbits of 2-colorings with exactly m black positions."""
    total = 0
    for p in perms:
        lengths, seen = [], set()
        for start in range(len(p)):
            if start in seen:
                continue
            size, j = 0, start
            while j not in seen:
                seen.add(j)
                j = p[j]
                size += 1
            lengths.append(size)
        ways = [1] + [0] * m
        for size in lengths:
            for s in range(m, size - 1, -1):
                ways[s] += ways[s - size]
        total += ways[m]
    return total // len(perms)
```
hint: Find the cycle lengths of `p`. A fixed coloring chooses a set of whole cycles to be black.
hint: Count the subsets of cycles with total length `m` by dynamic programming, as in the subset-sum problem: `ways[s]` is the number of subsets of the cycles seen so far with total length `s`.
solution: A coloring fixed by `p` is black on a union of whole cycles of `p`, so the number of fixed colorings with exactly `m` black positions is the number of sets of cycles with total length `m`, found with a knapsack-style count that loops over the sums downward so each cycle is used at most once. Burnside's lemma then says the number of orbits is the average of these counts over the group. The sum is always divisible by the group order when `perms` is a group.

prompt: Let a finite group $G$ act transitively on a finite set $X$ with $|X| \ge 2$. Prove that some $g \in G$ has no fixed point.
hint: Transitive means there is exactly one orbit; apply Burnside's lemma.
hint: The identity has $|X| \ge 2$ fixed points. What would happen to the average if every other element had at least one fixed point?
solution: Since the action is transitive there is one orbit, so by Burnside's lemma $\sum_{g \in G}|\operatorname{Fix}(g)| = |G|$. Suppose every $g$ had at least one fixed point. The identity has $|X| \ge 2$ fixed points, and each of the other $|G| - 1$ elements has at least $1$, so the sum would be at least $2 + (|G| - 1) = |G| + 1 > |G|$, a contradiction. Hence some $g$ satisfies $\operatorname{Fix}(g) = \emptyset$. $\blacksquare$

@article
In $\mathbb{Z}/12\mathbb{Z}$ with $N = \{0, 4, 8\}$ the four cosets can be added by adding representatives: $(1 + N) + (2 + N) = 3 + N$, and choosing the representatives $5$ and $10$ instead gives $15 + N = 3 + N$ again. We would like to multiply cosets in any group this way: $(aH)(bH) = abH$. In $S_3$ with $H = \{e, (1\,2)\}$ it fails. The coset $eH$ equals $(1\,2)H$, but with $b = (1\,3)$ the product of $eH$ and $bH$ is $bH = \{(1\,3), (1\,2\,3)\}$, while the product of $(1\,2)H$ and $bH$ is $(1\,2)(1\,3)H = \{(1\,3\,2), (2\,3)\}$. The answer depends on the representative. The subgroups for which the idea works are the normal ones.

### Normal subgroups

**Definition.** A subgroup $N \le G$ is **normal**, written $N \trianglelefteq G$, if $gng^{-1} \in N$ for all $g \in G$ and $n \in N$. The element $gng^{-1}$ is the **conjugate** of $n$ by $g$.

**Theorem 1.** For a subgroup $N$ of $G$ the following are equivalent: (a) $N$ is normal; (b) $gNg^{-1} = N$ for all $g \in G$; (c) $gN = Ng$ for all $g \in G$.

*Proof.* (a) $\Rightarrow$ (b): By (a), $gNg^{-1} \subseteq N$ for every $g$. Applying this to $g^{-1}$ gives $g^{-1}Ng \subseteq N$, hence $N \subseteq gNg^{-1}$, and so $gNg^{-1} = N$. (b) $\Rightarrow$ (c): multiply $gNg^{-1} = N$ on the right by $g$. (c) $\Rightarrow$ (a): for $n \in N$, $gn \in gN = Ng$, so $gn = n'g$ for some $n' \in N$ and $gng^{-1} = n' \in N$. $\blacksquare$

**Examples.** (1) Every subgroup of an abelian group is normal, since $gng^{-1} = n$. (2) The **center** $Z(G) = \{z : zg = gz \text{ for all } g\}$ is normal. (3) A subgroup of index $2$ is normal: for $g \notin H$ both $gH$ and $Hg$ are the complement $G \setminus H$ of $H$. In particular $A_n \trianglelefteq S_n$. (4) **Non-example**: $H = \{e, (1\,2)\} \le S_3$ is not normal, since $(1\,3)(1\,2)(1\,3)^{-1} = (3\,2)$ is not in $H$.

The conjugation test is easy to program for permutation groups. Here a permutation of $\{0, \dots, n-1\}$ is a tuple `s` with `s[i]` the image of `i`:

```python
import itertools


def compose(s, t):
    """s after t, as tuples: i -> s[t[i]]."""
    return tuple(s[t[i]] for i in range(len(t)))


def inverse(s):
    inv = [0] * len(s)
    for i, x in enumerate(s):
        inv[x] = i
    return tuple(inv)


def is_normal(G, H):
    """True if g h g^-1 lies in H for all g in G and h in H."""
    members = set(H)
    return all(compose(compose(g, h), inverse(g)) in members
               for g in G for h in H)


S3 = list(itertools.permutations(range(3)))
print(is_normal(S3, [(0, 1, 2), (1, 0, 2)]),
      is_normal(S3, [(0, 1, 2), (1, 2, 0), (2, 0, 1)]))
```

This prints `False True`: the subgroup generated by a transposition is not normal, and the alternating group $A_3$ is.

### The quotient group

**Theorem 2.** Let $N \le G$. The rule $(aN)(bN) = abN$ is a well-defined operation on the set $G/N$ of left cosets if and only if $N$ is normal. In that case $G/N$ is a group, the **quotient group**, with identity $N$, inverse $(aN)^{-1} = a^{-1}N$ and order $[G : N]$.

*Proof.* Suppose $N$ is normal and $aN = a'N$, $bN = b'N$. Then $a' = an_1$ and $b' = bn_2$ with $n_1, n_2 \in N$. Using $Nb = bN$ (Theorem 1), $n_1 b \in Nb = bN$, so $n_1 b = b n_3$ with $n_3 \in N$. Thus $a'b' = an_1 b n_2 = abn_3 n_2 \in abN$, so $a'b'N = abN$ and the product is well defined. Associativity follows from that of $G$: $((aN)(bN))(cN) = abcN = (aN)((bN)(cN))$. Clearly $(aN)(N) = aN$ and $(aN)(a^{-1}N) = N$. Conversely, suppose the rule is well defined. Let $g \in G$, $n \in N$. Since $gnN = gN$ (as $gn \in gN$) and $g^{-1}N = g^{-1}N$, well-definedness gives $(gn)g^{-1}N = gg^{-1}N = N$, so $gng^{-1} \in N$. $\blacksquare$

For $G = \mathbb{Z}/12\mathbb{Z}$ and $N = \langle 4 \rangle$, the quotient has $4$ elements, and $1 + N$ has order $4$ (since $k(1) \in N$ if and only if $4 \mid k$), so $G/N$ is cyclic of order $4$. In general $(\mathbb{Z}/n\mathbb{Z})/\langle d \rangle$ is cyclic of order $d$ for $d \mid n$, generated by $1 + \langle d \rangle$.

A useful consequence: if $G/Z(G)$ is cyclic then $G$ is abelian (practice item). Normal subgroups are exactly the subgroups that can be quotiented out; the next lesson shows that they are also exactly the kernels of homomorphisms.

@example
title: A quotient of $\mathbb{Z}/18\mathbb{Z}$
problem: Let $G = \mathbb{Z}/18\mathbb{Z}$ and $N = \langle 6 \rangle$. List the elements of $G/N$, compute $(4 + N) + (5 + N)$, and find the order of $2 + N$.
step: $G$ is abelian, so $N = \{0, 6, 12\}$ is normal and $G/N$ is a group of order $18/3 = 6$. Its elements are the cosets $0 + N, 1 + N, \dots, 5 + N$.
step: Add by adding representatives: $(4 + N) + (5 + N) = 9 + N$. Since $9 - 3 = 6 \in N$, $9 + N = 3 + N$.
step: The order of $2 + N$ is the least $k \ge 1$ with $2k \in N$, that is, with $2k \equiv 0 \pmod 6$.
step: $2k \equiv 0 \pmod 6$ holds first for $k = 3$ ($2 \cdot 3 = 6 \in N$), and $k = 1, 2$ give $2, 4 \notin N$. So $2 + N$ has order $3$.
answer: $G/N$ has $6$ elements, $(4 + N) + (5 + N) = 3 + N$, and $2 + N$ has order $3$.

@example
title: The rotations in a dihedral group
problem: Let $R = \langle r \rangle \le D_n$ be the rotation subgroup of the dihedral group of order $2n$, with $r^n = e$, $s^2 = e$, $srs = r^{-1}$. Show that $R$ is normal and describe $D_n/R$.
step: $D_n = \{r^k, r^k s\}$. To show $R$ is normal we conjugate a rotation $r^k$ by each type of element and stay in $R$.
step: Conjugating by $r^j$ gives $r^j r^k r^{-j} = r^k \in R$. Conjugating by $r^j s$: $(r^j s) r^k (r^j s)^{-1} = r^j (s r^k s) r^{-j} = r^j r^{-k} r^{-j} = r^{-k} \in R$, using $s r^k s = (srs)^k = r^{-k}$.
step: So $R \trianglelefteq D_n$ (this also follows from $[D_n : R] = 2$). The quotient has order $2$, with cosets $R$ (the rotations) and $sR$ (the reflections), and $(sR)(sR) = s^2R = R$.
answer: $R$ is normal, and $D_n/R$ has two elements, the rotations and the reflections.

@mistakes
- Believing that "normal" means "$gh = hg$ for all $h \in N$". Normality only requires $gNg^{-1} = N$ as a set: conjugates of $n$ may be other elements of $N$. In $D_n$, $r$ is conjugated to $r^{-1}$, yet $\langle r \rangle$ is normal.
- Thinking that $N \trianglelefteq H \trianglelefteq G$ implies $N \trianglelefteq G$. Normality is not transitive: $\{e, (1\,2)(3\,4)\}$ is normal in the Klein four-group, which is normal in $A_4$, but is not normal in $A_4$.
- Defining the product of cosets by representatives without checking that it does not depend on the choice. The check is the content of Theorem 2.
- Treating $G/N$ as a subgroup of $G$. Its elements are cosets, not elements of $G$; for $\mathbb{Z}/12\mathbb{Z}$ modulo $\langle 4 \rangle$ it has $4$ elements, but $\{0, 1, 2, 3\}$ is not closed under addition modulo $12$.

@practice ms
prompt: Let $N$ be a subgroup of a group $G$. Which of these conditions are equivalent to $N$ being normal in $G$?
choice*: $gN = Ng$ for every $g \in G$.
choice*: $gng^{-1} \in N$ for every $g \in G$ and $n \in N$.
choice: $gng^{-1} = n$ for every $g \in G$ and $n \in N$.
choice: $N$ is abelian.
choice*: Every left coset of $N$ is also a right coset of $N$.
hint: The condition $gng^{-1} = n$ for all $g$ says that $N$ lies in the center of $G$, which is a stronger condition than normality.
solution: The conditions $gN = Ng$ and $gng^{-1} \in N$ are Theorem 1(c) and the definition. If every left coset is a right coset, then $gN = Nb$ for some $b$; since $g \in gN$, we have $g \in Nb$, so $Nb = Ng$ and $gN = Ng$. The condition $gng^{-1} = n$ means $N \le Z(G)$, which makes $N$ normal but is not equivalent (consider $\langle r \rangle \trianglelefteq D_4$). model:
```python
def normalizer(G, H):
    """Elements g of G with g H g^-1 = H, sorted."""
    def mul(s, t):
        return tuple(s[t[i]] for i in range(len(t)))

    def inv(s):
        out = [0] * len(s)
        for i, x in enumerate(s):
            out[x] = i
        return tuple(out)

    target = set(H)
    return sorted(g for g in G
                  if {mul(mul(g, h), inv(g)) for h in H} == target)
```
hint: For each `g`, compute the set of conjugates $g h g^{-1}$ over `h` in `H` and compare it with `set(H)`.
hint: You need an inverse permutation: if `t[i] = j` then the inverse sends `j` to `i`.
solution: A permutation `g` normalizes `H` when conjugation by `g` maps `H` onto itself; because `H` is finite and conjugation is injective, the conjugate set has the same size as `H`, so equality of sets is a single comparison. The normalizer contains `H` and is the largest subgroup in which `H` is normal; it equals `G` exactly when `H` is normal in `G`.

@practice self
prompt: Let $Z = Z(G)$ be the center of a group $G$. Prove that if the quotient group $G/Z$ is cyclic, then $G$ is abelian.
hint: Let $gZ$ generate $G/Z$. Write any $a \in G$ as $g^i z$ with $z \in Z$.
hint: Compute $ab$ and $ba$ for $a = g^i z$ and $b = g^j w$, using that $z, w$ commute with everything.
solution: $Z$ is normal (each of its elements commutes with all of $G$), so $G/Z$ is defined. Let $gZ$ generate $G/Z$. For $a \in G$ we have $aZ = (gZ)^i = g^iZ$ for some integer $i$, so $a = g^i z$ for some $z \in Z$. Similarly any $b \in G$ is $b = g^j w$ with $w \in Z$. Then $ab = g^i z g^j w = g^i g^j z w = g^{i+j} zw$ because $z$ commutes with $g^j$, and $ba = g^j w g^i z = g^{j+i} wz = g^{i+j} zw$ because $zw = wz$ ($w, z \in Z$) and $w$ commutes with $g^i$. Hence $ab = ba$. $\blacksquare$

rubric: Uses that central elements commute with every element to reorder the products.
rubric: Concludes $ab = ba$ for arbitrary $a, b$.

@quiz mc
prompt: A subgroup $N \le G$ is used to define $(aN)(bN) = abN$ on left cosets. Which statement is correct?
choice*: The rule is well defined for all choices of coset representatives exactly when $N$ is normal.
choice: The rule is well defined for every subgroup $N$ of every group $G$.

hint: Recall what went wrong for the subgroup generated by a transposition in $S_3$.
solution: This is Theorem 2: well-definedness is equivalent to normality. It can fail for non-normal subgroups of non-abelian groups (a transposition in $S_3$), it holds for non-abelian $G$ with normal $N$ (for example $A_3 \trianglelefteq S_3$), and divisibility of orders holds for every subgroup by Lagrange's theorem, so it cannot characterize normality.

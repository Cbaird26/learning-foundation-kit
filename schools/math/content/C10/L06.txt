@article
The sign of a permutation satisfies $\operatorname{sgn}(\sigma\tau) = \operatorname{sgn}(\sigma)\operatorname{sgn}(\tau)$: multiplying permutations corresponds to multiplying the numbers $\pm 1$. The determinant does the same for matrices, and reduction modulo $n$ does it for integers under addition. Maps that respect the operation are called homomorphisms. They let us compare groups and, as we will see, they produce every quotient group.

### Homomorphisms

**Definition.** Let $G$ and $H$ be groups. A map $\varphi\colon G \to H$ is a **homomorphism** if $\varphi(ab) = \varphi(a)\varphi(b)$ for all $a, b \in G$. Its **kernel** is $\ker \varphi = \{g \in G : \varphi(g) = e_H\}$ and its **image** is $\operatorname{im} \varphi = \varphi(G)$. A bijective homomorphism is an **isomorphism**; $G \cong H$ means that one exists.

**Theorem 1.** Let $\varphi\colon G \to H$ be a homomorphism. Then:

(a) $\varphi(e_G) = e_H$, $\varphi(a^{-1}) = \varphi(a)^{-1}$ and $\varphi(a^k) = \varphi(a)^k$ for all integers $k$;
(b) $\ker \varphi$ is a normal subgroup of $G$ and $\operatorname{im} \varphi$ is a subgroup of $H$;
(c) $\varphi$ is injective if and only if $\ker \varphi = \{e_G\}$;
(d) if $g$ has finite order $n$ then the order of $\varphi(g)$ divides $n$.

*Proof.* (a) $\varphi(e) = \varphi(ee) = \varphi(e)\varphi(e)$, and cancelling gives $\varphi(e) = e_H$. Then $\varphi(a)\varphi(a^{-1}) = \varphi(e) = e_H$, so $\varphi(a^{-1}) = \varphi(a)^{-1}$; the power rule follows by induction. (b) If $a, b \in \ker\varphi$ then $\varphi(ab^{-1}) = e_H e_H^{-1} = e_H$, so the kernel is a subgroup (nonempty, since it contains $e_G$). For $g \in G$ and $a \in \ker\varphi$, $\varphi(gag^{-1}) = \varphi(g) e_H \varphi(g)^{-1} = e_H$, so the kernel is normal. The image is closed under products and inverses by (a) and the definition. (c) $\varphi(a) = \varphi(b)$ if and only if $\varphi(a^{-1}b) = e_H$, that is, $a^{-1}b \in \ker\varphi$. So $\varphi$ is injective if and only if $a^{-1}b \in \ker\varphi$ forces $a = b$, which holds exactly when the kernel is trivial. (d) $\varphi(g)^n = \varphi(g^n) = \varphi(e) = e_H$, so the order of $\varphi(g)$ divides $n$ by lesson 2. $\blacksquare$

**Examples.** (1) $\operatorname{sgn}\colon S_n \to \{1, -1\}$ has kernel $A_n$. (2) $\det\colon GL_n(\mathbb{R}) \to \mathbb{R}^\times$ has kernel $SL_n(\mathbb{R})$, the matrices of determinant $1$. (3) $x \mapsto x \bmod 4$ from $\mathbb{Z}/12\mathbb{Z}$ to $\mathbb{Z}/4\mathbb{Z}$ is well defined since $4 \mid 12$, with kernel $\{0, 4, 8\}$. (4) $\exp\colon (\mathbb{R}, +) \to (\mathbb{R}_{>0}, \cdot)$ is an isomorphism. (5) $x \mapsto x \bmod 5$ from $\mathbb{Z}/12\mathbb{Z}$ is not even well defined, since $5 \nmid 12$.

Every normal subgroup is a kernel: $\pi\colon G \to G/N$, $\pi(g) = gN$, is a homomorphism with kernel $N$, by the definition of the product in $G/N$.

### The first isomorphism theorem

**Theorem 2 (first isomorphism theorem).** If $\varphi\colon G \to H$ is a homomorphism with kernel $K$, then $\Phi\colon G/K \to \operatorname{im}\varphi$, $\Phi(aK) = \varphi(a)$, is a well-defined isomorphism. In particular, if $G$ is finite, $|G| = |\ker\varphi|\,|\operatorname{im}\varphi|$.

*Proof.* We have $aK = bK$ if and only if $a^{-1}b \in K$, if and only if $\varphi(a^{-1}b) = e_H$, if and only if $\varphi(a) = \varphi(b)$. The "only if" direction of the chain shows $\Phi$ is well defined, and the "if" direction shows it is injective. It is a homomorphism: $\Phi(aK \cdot bK) = \Phi(abK) = \varphi(ab) = \varphi(a)\varphi(b) = \Phi(aK)\Phi(bK)$. It is surjective onto $\operatorname{im}\varphi$ by definition of the image. The order formula is Lagrange's theorem for the quotient: $|G| = |K|\,[G : K] = |K|\,|G/K|$. $\blacksquare$

So to identify a quotient $G/N$, find a homomorphism out of $G$ whose kernel is $N$; then $G/N$ is isomorphic to its image. From the examples above: $S_n/A_n \cong \{\pm 1\}$ (for $n \ge 2$, since $\operatorname{sgn}$ is onto), and $GL_n(\mathbb{R})/SL_n(\mathbb{R}) \cong \mathbb{R}^\times$, since $\det$ is onto (a diagonal matrix has any nonzero determinant).

### Testing homomorphisms by computer

A map from $\mathbb{Z}/n\mathbb{Z}$ to $\mathbb{Z}/m\mathbb{Z}$ can be given as a list `f` with `f[x]` the image of `x`. For finite groups, checking all pairs is a proof that it is (or is not) a homomorphism:

```python
def is_hom(f, n, m):
    """Is f (a list of length n) a homomorphism Z/n -> Z/m?"""
    return all((f[x] + f[y] - f[(x + y) % n]) % m == 0
               for x in range(n) for y in range(n))


def kernel(f, m):
    return [x for x in range(len(f)) if f[x] % m == 0]


f = [x % 4 for x in range(12)]
print(is_hom(f, 12, 4), len(kernel(f, 4)), len(set(f)))
```

This prints `True 3 4`: the kernel has $3$ elements and the image $4$, and $3 \cdot 4 = 12$ as the theorem says.

@example
title: Identifying a quotient of $\mathbb{Z}/30\mathbb{Z}$
problem: Show that $(\mathbb{Z}/30\mathbb{Z})/\langle 10 \rangle \cong \mathbb{Z}/10\mathbb{Z}$.
step: Define $\varphi\colon \mathbb{Z}/30\mathbb{Z} \to \mathbb{Z}/10\mathbb{Z}$ by $\varphi(x) = x \bmod 10$. It is well defined because $10 \mid 30$, and it is a homomorphism because $(x + y) \bmod 10 = (x \bmod 10) + (y \bmod 10)$ in $\mathbb{Z}/10\mathbb{Z}$.
step: The kernel is $\{x \in \mathbb{Z}/30\mathbb{Z} : 10 \mid x\} = \{0, 10, 20\} = \langle 10 \rangle$.
step: The map is onto: each residue $r \in \{0, \dots, 9\}$ is the image of $r$ itself.
step: By the first isomorphism theorem, $(\mathbb{Z}/30\mathbb{Z})/\langle 10 \rangle \cong \operatorname{im}\varphi = \mathbb{Z}/10\mathbb{Z}$. As a check, both sides have $30/3 = 10$ elements.
answer: $(\mathbb{Z}/30\mathbb{Z})/\langle 10 \rangle \cong \mathbb{Z}/10\mathbb{Z}$, via $x + \langle 10 \rangle \mapsto x \bmod 10$.

@example
title: The nonzero complex numbers modulo the unit circle
problem: Let $S^1 = \{z \in \mathbb{C} : |z| = 1\}$, a subgroup of $\mathbb{C}^\times$. Identify $\mathbb{C}^\times / S^1$.
step: Define $\varphi\colon \mathbb{C}^\times \to \mathbb{R}_{>0}$, $\varphi(z) = |z|$, a map into the positive reals under multiplication.
step: It is a homomorphism because $|zw| = |z||w|$.
step: Its kernel is $\{z : |z| = 1\} = S^1$ and it is onto, since $|r| = r$ for every $r > 0$.
step: By the first isomorphism theorem, $\mathbb{C}^\times / S^1 \cong \mathbb{R}_{>0}$ (under multiplication). The coset $zS^1$ is determined by the modulus $|z|$.
answer: $\mathbb{C}^\times / S^1 \cong (\mathbb{R}_{>0}, \cdot)$.

@mistakes
- Checking that a map preserves the operation but not that it is well defined. $x \mapsto x \bmod 5$ on $\mathbb{Z}/12\mathbb{Z}$ gives different values for the representatives $0$ and $12$.
- Concluding "injective" from "onto" or the reverse. Only a trivial kernel gives injectivity, and a map from $\mathbb{Z}/12\mathbb{Z}$ to $\mathbb{Z}/4\mathbb{Z}$ can be onto with kernel of size $3$.
- Forgetting to prove surjectivity when using the first isomorphism theorem. The theorem identifies $G/\ker\varphi$ with the image, which is all of $H$ only when $\varphi$ is onto.
- Thinking that the image of a homomorphism is normal in $H$. It is a subgroup, but it need not be normal: a homomorphism $\mathbb{Z}/2\mathbb{Z} \to S_3$ can send $1$ to a transposition.

```python
def count_homs(n, m):
    """Number of homomorphisms Z/n -> Z/m, found by testing each a."""
    total = 0
    for a in range(m):
        f = [a * x % m for x in range(n)]
        if all((f[x] + f[y] - f[(x + y) % n]) % m == 0
               for x in range(n) for y in range(n)):
            total += 1
    return total
```

hint: Compare your counts with $\gcd(n, m)$.
solution: For each of the $m$ candidates, build the map and test the condition on all $n^2$ pairs; count the passes. The condition holds exactly when $m \mid na$, and the number of such $a$ is $\gcd(n, m)$, which the tests confirm. This is a computation that illustrates, but does not prove, the formula; the proof is that $1 \mapsto a$ is well defined if and only if $n \cdot a = 0$ in $\mathbb{Z}/m\mathbb{Z}$, since $1$ has order $n$.

prompt: Let $\varphi\colon G \to H$ be a homomorphism of finite groups with $\gcd(|G|, |H|) = 1$. Prove that $\varphi(g) = e_H$ for every $g \in G$.
hint: Look at $|\operatorname{im}\varphi|$ and which two numbers it must divide.
solution: By the first isomorphism theorem, $\operatorname{im}\varphi \cong G/\ker\varphi$, so $|\operatorname{im}\varphi| = |G|/|\ker\varphi|$ divides $|G|$. Also $\operatorname{im}\varphi$ is a subgroup of $H$, so $|\operatorname{im}\varphi|$ divides $|H|$ by Lagrange's theorem. A positive integer dividing both $|G|$ and $|H|$ divides $\gcd(|G|, |H|) = 1$, so $|\operatorname{im}\varphi| = 1$ and $\operatorname{im}\varphi = \{e_H\}$. $\blacksquare$

@article
A frog hops among lily pads at random. After a long time, what fraction of the time is it on each pad, and does it come back to where it started? These are the questions of recurrence and stationarity.

### Definitions

Let $S$ be a countable set. A **transition matrix** is $P = (p(i,j))_{i,j \in S}$ with $p(i,j) \ge 0$ and $\sum_j p(i,j) = 1$. A sequence $X_0, X_1, \dots$ is a **Markov chain** with transition matrix $P$ if $P(X_{n+1} = j \mid X_0, \dots, X_n) = p(X_n, j)$. Then $P(X_n = j \mid X_0 = i) = p^n(i,j)$, the entry of the matrix power $P^n$ (the Chapman–Kolmogorov equations $p^{m+n} = p^m p^n$).

Write $i \to j$ if $p^n(i,j) > 0$ for some $n \ge 0$, and $i \leftrightarrow j$ if both $i \to j$ and $j \to i$; the classes of $\leftrightarrow$ are the **communicating classes**, and the chain is **irreducible** if there is one. A class is **closed** if no transition leaves it. The **period** of $i$ is $\gcd\{n \ge 1 : p^n(i,i) > 0\}$; it is constant on a class, and a class with period $1$ is **aperiodic**.

Let $T_j = \inf\{n \ge 1 : X_n = j\}$ and $\rho_{ij} = P_i(T_j < \infty)$. State $i$ is **recurrent** if $\rho_{ii} = 1$ and **transient** if $\rho_{ii} < 1$. It is **positive recurrent** if moreover $\mathbb{E}_iT_i < \infty$.

### Recurrence and transience

**Theorem 1.** State $i$ is recurrent if and only if $\sum_{n \ge 1}p^n(i,i) = \infty$. If $i$ is transient, the number of returns $N = \sum_{n \ge 1}\mathbf{1}_{\{X_n = i\}}$ is geometric under $P_i$ and $\mathbb{E}_iN = \rho_{ii}/(1 - \rho_{ii}) < \infty$.

*Proof.* By the strong Markov property (at the successive return times to $i$, the chain starts afresh from $i$), $P_i(N \ge k) = \rho_{ii}^k$. If $\rho_{ii} = 1$, then $N = \infty$ a.s. and $\mathbb{E}_iN = \sum_{n \ge 1}p^n(i,i) = \infty$. If $\rho_{ii} < 1$, then $\mathbb{E}_iN = \sum_{k \ge 1}\rho_{ii}^k = \rho_{ii}/(1-\rho_{ii}) < \infty$. The identity $\mathbb{E}_iN = \sum_n p^n(i,i)$ is Tonelli's theorem. $\blacksquare$

**Theorem 2.** Recurrence is a class property: if $i \leftrightarrow j$ and $i$ is recurrent, then $j$ is recurrent.

*Proof.* Choose $a, b$ with $p^a(i,j) > 0$ and $p^b(j,i) > 0$. For every $n$, $p^{b+n+a}(j,j) \ge p^b(j,i)\,p^n(i,i)\,p^a(i,j)$. Summing over $n$, $\sum_m p^m(j,j) \ge p^b(j,i)\,p^a(i,j)\sum_n p^n(i,i) = \infty$. $\blacksquare$

**Theorem 3.** A finite closed communicating class is recurrent.

*Proof.* Start at $i \in C$. Since $C$ is closed, $\sum_{j \in C}p^n(i,j) = 1$ for every $n$, so $\sum_{j \in C}\sum_{n \ge 1}p^n(i,j) = \infty$. As $C$ is finite, some $j \in C$ has $\sum_{n \ge 1}p^n(i,j) = \infty$. Decomposing according to the first visit to $j$ (strong Markov property), $\sum_{n \ge 1}p^n(i,j) \le \rho_{ij}\sum_{m \ge 0}p^m(j,j) \le \sum_{m \ge 0}p^m(j,j)$, so $\sum_m p^m(j,j) = \infty$. By Theorem 1, $j$ is recurrent, and by Theorem 2 every state of $C$ is. $\blacksquare$

The finiteness is essential: simple random walk on $\mathbb{Z}$ with $P(\text{up}) = \frac23$ has one infinite closed class and is transient.

For simple symmetric random walk on $\mathbb{Z}^d$, $p^{2n}(0,0)$ is of order $n^{-d/2}$ (for $d = 1$ it equals $\binom{2n}{n}4^{-n} \sim 1/\sqrt{\pi n}$ by Stirling's formula), so the series $\sum_n p^{n}(0,0)$ diverges for $d \le 2$ and converges for $d \ge 3$: the walk is recurrent in dimensions $1$ and $2$ and transient from dimension $3$ (Pólya's theorem, quoted without proof).

### Stationary distributions

A probability vector $\pi$ with $\pi P = \pi$ is a **stationary distribution**: if $X_0 \sim \pi$ then every $X_n \sim \pi$. If $\pi(i)p(i,j) = \pi(j)p(j,i)$ for all $i, j$ (**detailed balance**), then summing over $i$ gives $\sum_i\pi(i)p(i,j) = \pi(j)\sum_i p(j,i) = \pi(j)$, so $\pi$ is stationary.

**Theorem 4 (stated without proof).** Let the chain be irreducible. (a) A stationary distribution exists if and only if the chain is positive recurrent; it is then unique and $\pi(i) = 1/\mathbb{E}_iT_i$. (b) Every finite irreducible chain is positive recurrent. (c) If the chain is also aperiodic and positive recurrent, then $p^n(i,j) \to \pi(j)$ for all $i, j$.

Aperiodicity matters in (c): the chain on $\{0,1\}$ that swaps the states deterministically has $\pi = (\frac12, \frac12)$ but $p^n(0,0)$ alternates between $1$ and $0$. Irreducibility matters in (a): the identity chain on two states has every probability vector stationary.

### Computing

```python
from fractions import Fraction


def n_step(P, n):
    """The matrix power P**n for a list-of-rows matrix P."""
    m = len(P)
    result = [[Fraction(int(i == j)) for j in range(m)] for i in range(m)]
    for _ in range(n):
        result = [[sum(result[i][k] * P[k][j] for k in range(m))
                   for j in range(m)] for i in range(m)]
    return result


def classes(P):
    """Communicating classes, each with a flag telling if it is closed."""
    m = len(P)
    reach = [[i == j or P[i][j] > 0 for j in range(m)] for i in range(m)]
    for k in range(m):
        for i in range(m):
            for j in range(m):
                reach[i][j] = reach[i][j] or (reach[i][k] and reach[k][j])
    out, seen = [], set()
    for i in range(m):
        if i not in seen:
            cls = [j for j in range(m) if reach[i][j] and reach[j][i]]
            seen.update(cls)
            closed = all(k in cls
                         for j in cls for k in range(m) if P[j][k] > 0)
            out.append((cls, closed))
    return out


P = [[Fraction(1, 2), Fraction(1, 2), 0, 0],
     [Fraction(1, 3), Fraction(1, 3), Fraction(1, 3), 0],
     [0, 0, Fraction(1, 4), Fraction(3, 4)],
     [0, 0, Fraction(1, 2), Fraction(1, 2)]]
print(classes(P))
print([round(float(x), 3) for x in n_step(P, 80)[0]])
```

The first line prints `[([0, 1], False), ([2, 3], True)]`: states $0, 1$ form a non-closed (hence transient) class and $2, 3$ a closed (recurrent) one. The second prints `[0.0, 0.0, 0.4, 0.6]`, the row of $P^{80}$ from state $0$ rounded to three decimals: the mass has moved to states $2, 3$ and is near $(\frac25, \frac35)$. This is numerical evidence; the theorems are proofs. On exams, classify first (classes, closed or not, period), then solve $\pi P = \pi$ on each closed class.

@example
title: Classify and find the stationary distribution
problem: A chain on $\{1,2,3,4\}$ has $p(1,1) = \frac12$, $p(1,2) = \frac12$, $p(2,1) = \frac13$, $p(2,2) = \frac13$, $p(2,3) = \frac13$, $p(3,3) = \frac14$, $p(3,4) = \frac34$, $p(4,3) = \frac12$, $p(4,4) = \frac12$. Classify the states and find all stationary distributions.
step: $1 \leftrightarrow 2$ (since $p(1,2), p(2,1) > 0$), and $3 \leftrightarrow 4$. From $2$ the chain can go to $3$, but from $3$ it never returns to $\{1,2\}$. So the classes are $\{1,2\}$ (not closed) and $\{3,4\}$ (closed).
step: The class $\{1,2\}$ is transient: from state $2$ the chain leaves with probability $\frac13$ at each visit and never comes back, so $\rho_{22} < 1$. The class $\{3,4\}$ is finite and closed, hence recurrent (and aperiodic, since $p(3,3) > 0$).
step: A stationary distribution gives no mass to transient states, so $\pi = (0, 0, \pi_3, \pi_4)$ and solves $\pi_3 = \frac14\pi_3 + \frac12\pi_4$, $\pi_3 + \pi_4 = 1$. The first equation gives $\frac34\pi_3 = \frac12\pi_4$, so $\pi_4 = \frac32\pi_3$.
step: Hence $\pi_3 = \frac25$ and $\pi_4 = \frac35$. The stationary distribution is unique, equal to $(0, 0, \frac25, \frac35)$, and $\mathbb{E}_3T_3 = \frac52$.
answer: Transient class $\{1,2\}$, recurrent class $\{3,4\}$; $\pi = (0, 0, \tfrac25, \tfrac35)$.

@example
title: A birth–death chain by detailed balance
problem: On $\{0,1,2,3\}$, move up with probability $\frac13$ and down with probability $\frac23$, staying put when the move would leave the set. Find the stationary distribution and $\mathbb{E}_3T_3$.
step: The chain is irreducible and finite, and aperiodic because $p(0,0) = \frac23 > 0$. So a unique stationary distribution exists and $p^n(i,j) \to \pi(j)$.
step: Try detailed balance on neighbors: $\pi(i)\cdot\frac13 = \pi(i+1)\cdot\frac23$, so $\pi(i+1) = \frac12\pi(i)$. Detailed balance for non-neighbors is trivial, since both sides are $0$.
step: Then $\pi \propto (1, \frac12, \frac14, \frac18)$ and the normalizing sum is $\frac{15}{8}$, so $\pi = (\frac{8}{15}, \frac{4}{15}, \frac{2}{15}, \frac{1}{15})$.
step: By Theorem 4(a), $\mathbb{E}_3T_3 = 1/\pi(3) = 15$.
answer: $\pi = (\frac8{15}, \frac4{15}, \frac2{15}, \frac1{15})$ and $\mathbb{E}_3T_3 = 15$.

@mistakes
- Treating a stationary distribution as a limit without checking aperiodicity: $p^n(i,j)$ need not converge for periodic chains, only its Cesàro average does.
- Declaring a class recurrent because it is communicating; a class that can be left is transient, and an infinite closed class can also be transient.
- Looking for a stationary distribution on all of $S$ when the chain has several closed classes: each closed class has its own, and any mixture of them is stationary.
- Solving $P\pi = \pi$ (right eigenvector) instead of $\pi P = \pi$; the all-ones vector always solves the former.

model:
```python
from fractions import Fraction


def stationary(P):
    """Solve pi P = pi, sum(pi) = 1 exactly by Gauss-Jordan elimination."""
    m = len(P)
    # Row j encodes: sum_i pi_i (P[i][j] - [i == j]) = 0.
    rows = [[P[i][j] - (1 if i == j else 0) for i in range(m)] + [Fraction(0)]
            for j in range(m)]
    rows[m - 1] = [Fraction(1)] * m + [Fraction(1)]  # replace one equation
    for c in range(m):
        piv = next(r for r in range(c, m) if rows[r][c] != 0)
        rows[c], rows[piv] = rows[piv], rows[c]
        scale = rows[c][c]
        rows[c] = [x / scale for x in rows[c]]
        for r in range(m):
            if r != c and rows[r][c] != 0:
                f = rows[r][c]
                rows[r] = [x - f * y for x, y in zip(rows[r], rows[c])]
    return [rows[i][m] for i in range(m)]
```
hint: The unknowns are $\pi_0, \dots, \pi_{m-1}$; column $j$ of $P - I$ gives the equation for $\pi_j$.
hint: The $m$ balance equations are dependent (they sum to zero), so replace one of them by the normalization $\sum\pi_i = 1$.
solution: Write $\pi(P - I) = 0$ as $m$ linear equations, one per column of $P - I$. They are linearly dependent because each row of $P - I$ sums to zero, so one equation is dropped and replaced by $\sum_i\pi_i = 1$. For an irreducible chain the resulting system has a unique solution. Exact `Fraction` arithmetic makes the equality tests exact. Solving with the transpose by mistake (right eigenvector) would return the uniform vector for every stochastic matrix, which the nonsymmetric tests reject.

prompt: Let $\pi$ be a stationary distribution of a Markov chain on a countable state space, and let $j$ be a transient state. Prove that $\pi(j) = 0$. Deduce that an irreducible transient chain has no stationary distribution.
hint: Use $\pi(j) = \sum_i\pi(i)p^n(i,j)$ for every $n$, and show $p^n(i,j) \to 0$ for transient $j$.
hint: For transient $j$ the series $\sum_n p^n(i,j)$ is at most $\sum_{n \ge 0}p^n(j,j)$, which is finite; then use dominated convergence over $i$.
solution: Stationarity gives $\pi = \pi P^n$ for every $n$, so $\pi(j) = \sum_i\pi(i)p^n(i,j)$. For transient $j$, Theorem 1 gives $G(j,j) = \sum_{n \ge 0}p^n(j,j) = 1/(1 - \rho_{jj}) < \infty$. Decomposing by the first visit time to $j$ (strong Markov property), $\sum_{n \ge 0}p^n(i,j) \le G(j,j) < \infty$ (for $i \ne j$ it equals $\rho_{ij}\,G(j,j)$), so $p^n(i,j) \to 0$ as $n \to \infty$ for every $i$, as the terms of a convergent series. Since $0 \le \pi(i)p^n(i,j) \le \pi(i)$ and $\sum_i\pi(i) = 1$, dominated convergence (for sums) gives $\pi(j) = \lim_n\sum_i\pi(i)p^n(i,j) = 0$. If the chain is irreducible and transient, all states are transient (Theorem 2), so any stationary distribution would vanish identically, contradicting $\sum\pi(j) = 1$. $\blacksquare$

```python
from math import gcd


def period(P, i):
    """gcd of the return times to i, or None if i is never revisited."""
    m = len(P)
    positive = [[P[a][b] > 0 for b in range(m)] for a in range(m)]
    reach = {i}          # states reachable from i in exactly n steps
    g = 0
    for n in range(1, 2 * m * m + 1):
        reach = {b for a in reach for b in range(m) if positive[a][b]}
        if i in reach:
            g = gcd(g, n)
    return g if g > 0 else None
```
hint: Track the set of states reachable from `i` in exactly $n$ steps, and update the gcd whenever `i` is in the set.
hint: A bound of about $2m^2$ steps is more than enough for a matrix with $m$ states.
solution: Whether $p^n(i,i) > 0$ depends only on which transitions are possible, so a set of states reachable in exactly $n$ steps suffices. Every time $i$ is in that set, $n$ is a possible return time and the gcd is updated. Taking only the smallest return time is the typical mistake: the last test chain has return times $2$ and $3$, with gcd $1$.

Starter harness (the core simulations are yours to write):

```python
import math
import random


def estimate(sample, runs, seed):
    """Mean and a 95 percent error bar (2 standard errors)."""
    rng = random.Random(seed)
    values = [sample(rng) for _ in range(runs)]
    mean = sum(values) / runs
    var = sum((v - mean) ** 2 for v in values) / (runs - 1)
    return mean, 2 * math.sqrt(var / runs)
```

## Week-by-week review

**Weeks 1–2.** A probability space is $(\Omega, \mathcal{F}, P)$; continuity of $P$ from above and below, the $\pi$–$\lambda$ theorem and uniqueness; a distribution function is nondecreasing and right-continuous with limits $0$ and $1$, and $G(U)$ with $G(u) = \inf\{x : F(x) \ge u\}$ has law $F$. Independence of $\pi$-systems extends to $\sigma$-algebras. Borel–Cantelli: $\sum P(A_n) < \infty \Rightarrow P(A_n \text{ i.o.}) = 0$; independence and $\sum P(A_n) = \infty \Rightarrow P(A_n \text{ i.o.}) = 1$. Kolmogorov's zero–one law for tail events.

**Weeks 3–4.** Markov $P(|X| \ge a) \le \mathbb{E}|X|^p/a^p$, Chebyshev, Jensen. Almost sure and $L^p$ convergence each imply convergence in probability, which implies convergence in distribution; convergence in probability means every subsequence has an almost surely convergent further subsequence. Weak law by Chebyshev: $P(|S_n/n - \mu| \ge \varepsilon) \le C/(n\varepsilon^2)$. Strong law with $\mathbb{E}X^4 < \infty$: $\mathbb{E}S_n^4 = n\mathbb{E}X^4 + 3n(n-1)(\mathbb{E}X^2)^2$. Kolmogorov: $\mathbb{E}|X| < \infty$ suffices.

**Weeks 5–6.** $\varphi(t) = \mathbb{E}e^{itX}$; $\varphi_{X+Y} = \varphi_X\varphi_Y$ for independent variables (not conversely); the Taylor remainder bound; inversion and Lévy continuity (continuity of the limit at $0$ is essential). Central limit theorem: $\varphi(t/\sqrt{n})^n \to e^{-t^2/2}$ when $\mathbb{E}X = 0$, $\mathbb{E}X^2 = 1$. Lindeberg–Feller; Berry–Esseen rate $n^{-1/2}$.

**Weeks 7–8.** $\mathbb{E}[X \mid \mathcal{G}]$ is $\mathcal{G}$-measurable with $\int_A\mathbb{E}[X \mid \mathcal{G}] = \int_AX$ for $A \in \mathcal{G}$; tower property; taking out what is known; $L^2$ projection. Martingales, stopping times, stopped martingales, Doob decomposition, Doob's maximal inequality.

**Weeks 9–10.** Optional stopping: bounded $\tau$; bounded martingale with $\tau < \infty$; bounded increments with $\mathbb{E}\tau < \infty$; uniform integrability. Gambler's ruin: $P = i/N$, $\mathbb{E}\tau = i(N-i)$; biased case with $r = q/p$. Wald: $\mathbb{E}S_\tau = \mu\mathbb{E}\tau$. Upcrossing inequality; $L^1$-bounded submartingales converge a.s.; uniformly integrable martingales converge in $L^1$.

**Weeks 11–12.** Recurrent if and only if $\sum p^n(i,i) = \infty$; recurrence is a class property; finite closed classes are recurrent; $\pi P = \pi$, $\pi(i) = 1/\mathbb{E}_iT_i$; convergence needs aperiodicity. Brownian motion: covariance $\min(s,t)$, quadratic variation $t$, martingales $B_t^2 - t$ and $e^{\theta B_t - \theta^2t/2}$, reflection principle.

## Most common errors

Using the second Borel–Cantelli lemma without independence; confusing convergence in probability with almost sure convergence; applying optional stopping to a finite but unbounded stopping time; claiming $p^n(i,j) \to \pi(j)$ for a periodic chain; and treating a simulation as a proof.

@exam num
prompt: A walk starts at $0$ and each step is $+1$ with probability $\frac35$ and $-1$ with probability $\frac25$. Let $\tau$ be the first time the walk reaches $-3$ or $2$. Find $\mathbb{E}\tau$ to three decimal places.
answer: 5.261
tol: 0.001
check: lin([[1, -0.6, 0, 0], [-0.4, 1, -0.6, 0], [0, -0.4, 1, -0.6], [0, 0, -0.4, 1]], [1, 1, 1, 1])[2]
hint: Use the martingales $(q/p)^{S_n}$ and $S_n - (p-q)n$, together with optional stopping.
hint: First find $P(S_\tau = 2)$ with $r = q/p = \frac23$.
solution: With $r = \frac23$ and $S_\tau \in \{-3, 2\}$, $h = P(S_\tau = 2)$ satisfies $h\,r^2 + (1-h)\,r^{-3} = 1$, giving $h = \dfrac{1 - r^{-3}}{r^2 - r^{-3}} = \dfrac{171}{211}$. Then $\mathbb{E}S_\tau = 2h - 3(1-h) = \frac{342 - 120}{211} = \frac{222}{211}$, and optional stopping for $S_n - (p-q)n$ with $p - q = \frac15$ gives $\mathbb{E}\tau = 5\cdot\frac{222}{211} = \frac{1110}{211} \approx 5.261$.

choice*: If $X_n \to X$ almost surely and $|X_n| \le Y$ with $\mathbb{E}Y < \infty$, then $\mathbb{E}|X_n - X| \to 0$.
choice*: If $X_i$ are i.i.d. with mean $0$ and variance $\sigma^2 > 0$, then $S_n/(\sigma\sqrt{n}) \Rightarrow N(0,1)$.

@exam self
prompt: Let $X_1, X_2, \dots$ be i.i.d. with $\mathbb{E}X_1 = 0$ and $\mathbb{E}X_1^2 = 1$, $S_n = X_1 + \dots + X_n$, $a > 0$, and $\tau = \inf\{n : |S_n| \ge a\}$. Prove that $\mathbb{E}\tau < \infty$ and that $\mathbb{E}S_\tau^2 = \mathbb{E}\tau$.
hint: Use the central limit theorem to find $m$ with $P(|S_m| < 2a) \le \frac12$, then compare $S_{(k+1)m}$ with $S_{km}$ on the event $\{\tau > (k+1)m\}$.
hint: For the identity, stop the martingale $S_n^2 - n$ at $\tau \wedge n$ and show that $S_{\tau \wedge n}$ is a martingale bounded in $L^2$.
solution: Finiteness. Choose $\varepsilon > 0$ with $P(|Z| \le \varepsilon) < \frac12$, where $Z \sim N(0,1)$. By the central limit theorem and the portmanteau theorem for the closed set $[-\varepsilon, \varepsilon]$, $\limsup_m P(|S_m|/\sqrt{m} \le \varepsilon) \le P(|Z| \le \varepsilon) < \frac12$. Choose $m$ so large that $2a/\sqrt{m} \le \varepsilon$ and $P(|S_m|/\sqrt{m} \le \varepsilon) \le \frac12$; then $P(|S_m| < 2a) \le \frac12$. On $\{\tau > (k+1)m\}$ we have $|S_{km}| < a$ and $|S_{(k+1)m}| < a$, hence $|S_{(k+1)m} - S_{km}| < 2a$. So $\{\tau > (k+1)m\} \subseteq \{\tau > km\} \cap \{|S_{(k+1)m} - S_{km}| < 2a\}$. The first event lies in $\mathcal{F}_{km}$ and the increment is independent of $\mathcal{F}_{km}$ with the law of $S_m$, so $P(\tau > (k+1)m) \le \frac12P(\tau > km)$. Hence $P(\tau > km) \le 2^{-k}$ and $\mathbb{E}\tau = \sum_{n \ge 0}P(\tau > n) \le m\sum_{k \ge 0}P(\tau > km) \le 2m < \infty$. The identity. $S_n^2 - n$ is a martingale (this uses independence, $\mathbb{E}X_1 = 0$ and $\mathbb{E}X_1^2 = 1$), so its stopped version is a martingale and $\mathbb{E}S_{\tau \wedge n}^2 = \mathbb{E}(\tau \wedge n) \le \mathbb{E}\tau$. Thus $S_{\tau \wedge n}$ is a martingale bounded in $L^2$, and by the $L^2$ martingale convergence theorem it converges almost surely and in $L^2$; since $\tau < \infty$ almost surely, the almost sure limit is $S_\tau$. Therefore $\mathbb{E}S_\tau^2 = \lim_n\mathbb{E}S_{\tau \wedge n}^2 = \lim_n\mathbb{E}(\tau \wedge n) = \mathbb{E}\tau$ by monotone convergence. $\blacksquare$

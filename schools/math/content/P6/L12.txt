@article
Take a simple random walk, run it for $n$ steps, shrink time by $n$ and space by $\sqrt{n}$. By the central limit theorem each marginal looks Gaussian; Donsker's invariance principle says the whole rescaled path converges in law. The limit is Brownian motion, the central object of continuous-time probability. This lesson is an outline: it proves what the tools of this course reach and states the rest clearly.

### Definition

A **standard Brownian motion** is a process $(B_t)_{t \ge 0}$ with
1. $B_0 = 0$;
2. independent increments: for $0 \le t_0 < t_1 < \dots < t_k$ the variables $B_{t_i} - B_{t_{i-1}}$ are independent;
3. $B_t - B_s \sim N(0, t - s)$ for $s < t$;
4. almost surely, $t \mapsto B_t$ is continuous.

Properties 1–3 say that $B$ is a centered Gaussian process with $\operatorname{Cov}(B_s, B_t) = \min(s,t)$. Properties 1–3 determine the finite-dimensional laws, so Brownian motion exists as a process by Kolmogorov's extension theorem; the content of the existence theorem (Wiener's construction) is that a version with continuous paths exists, which follows from Kolmogorov's continuity criterion since $\mathbb{E}|B_t - B_s|^4 = 3|t-s|^2$. We use existence without proof.

**Symmetries (immediate from the covariance).** For $c > 0$, $c^{-1/2}B_{ct}$ is a standard Brownian motion (**scaling**); $B_{t+s} - B_s$ is a standard Brownian motion independent of $\sigma(B_u : u \le s)$ (**simple Markov property**); and $tB_{1/t}$, extended by $0$ at $t = 0$, is a standard Brownian motion (**time inversion**).

### Quadratic variation

**Theorem 1.** Let $0 = t_0^n < \dots < t_{k_n}^n = t$ be partitions of $[0,t]$ with mesh $\delta_n \to 0$ and $Q_n = \sum_i (B_{t_i^n} - B_{t_{i-1}^n})^2$. Then $Q_n \to t$ in $L^2$. For dyadic partitions $t_i^n = it2^{-n}$ the convergence is almost sure.

*Proof.* With $\Delta_i = t_i^n - t_{i-1}^n$ the increments are independent with $\mathbb{E}(\text{incr})^2 = \Delta_i$ and variance of the square $\mathbb{E}Z^4 \Delta_i^2 - \Delta_i^2 = 2\Delta_i^2$ (as $\mathbb{E}Z^4 = 3$ for standard normal $Z$). So $\mathbb{E}Q_n = t$ and, by independence, $\operatorname{Var}Q_n = 2\sum_i\Delta_i^2 \le 2\delta_n t \to 0$, which is $L^2$ convergence. For dyadic partitions $\delta_n = t2^{-n}$, so by Chebyshev $P(|Q_n - t| > \varepsilon) \le 2t^22^{-n}/\varepsilon^2$ is summable and the first Borel–Cantelli lemma gives almost sure convergence. $\blacksquare$

**Corollary 2.** Almost surely, $t \mapsto B_t$ has infinite total variation on every interval $[0, t]$, $t > 0$.

*Proof.* Fix $t$ and take a path with $Q_n \to t$ along dyadic partitions. If the path had total variation $V < \infty$ on $[0,t]$, then $Q_n \le \max_i|B_{t_i^n} - B_{t_{i-1}^n}|\cdot V \to 0$ by uniform continuity on the compact interval, contradicting $Q_n \to t > 0$. Take $t$ rational and use monotonicity of variation in $t$ to cover all $t$. $\blacksquare$

In fact, almost surely the path is *nowhere differentiable* (quoted without proof). For comparison, the discrete walk simulates this behavior:

```python
import math
import random


def quadratic_variation(increments):
    """Sum of the squared increments of a path."""
    return sum(x * x for x in increments)


def bm_increments(rng, t, n):
    """n independent N(0, t/n) increments of Brownian motion on [0, t]."""
    sd = math.sqrt(t / n)
    return [rng.gauss(0.0, sd) for _ in range(n)]


rng = random.Random(2)
qv = quadratic_variation(bm_increments(rng, 2.0, 1000))
print(abs(qv - 2.0) < 0.5)
```

It prints `True`: the sum of squares of 1000 increments over $[0, 2]$ is close to $2$, with standard deviation $\sqrt{2\cdot 4/1000} \approx 0.09$. Simulation illustrates Theorem 1; it proves nothing.

### Martingales and exit problems

**Theorem 3.** With $\mathcal{F}_t = \sigma(B_u : u \le t)$, the processes $B_t$, $B_t^2 - t$ and $\exp(\theta B_t - \theta^2t/2)$ ($\theta \in \mathbb{R}$) are martingales, and so is $B_t^3 - 3tB_t$.

*Proof.* Write $B_t = B_s + (B_t - B_s)$ with the increment $Z \sim N(0, t-s)$ independent of $\mathcal{F}_s$. Then $\mathbb{E}[B_t \mid \mathcal{F}_s] = B_s$; $\mathbb{E}[B_t^2 \mid \mathcal{F}_s] = B_s^2 + (t-s)$; $\mathbb{E}[e^{\theta Z}] = e^{\theta^2(t-s)/2}$ gives the exponential; and $\mathbb{E}[(B_s + Z)^3] = B_s^3 + 3B_s(t-s)$ so $\mathbb{E}[B_t^3 - 3tB_t \mid \mathcal{F}_s] = B_s^3 + 3(t-s)B_s - 3tB_s = B_s^3 - 3sB_s$. $\blacksquare$

**Exit from an interval.** For $a, b > 0$ let $T = \inf\{t : B_t \in \{-a, b\}\}$. Using the continuous-time versions of last week's results (bounded stopped martingales have constant expectation; these are quoted here), $T < \infty$ almost surely, $P(B_T = b) = \frac{a}{a+b}$ and $\mathbb{E}T = ab$. The argument is the gambler's-ruin argument: $B_{t \wedge T}$ is bounded, so $0 = \mathbb{E}B_T = bP(B_T = b) - a(1 - P(B_T = b))$; and $\mathbb{E}(t \wedge T) = \mathbb{E}B_{t \wedge T}^2 \to \mathbb{E}B_T^2 = b^2\frac{a}{a+b} + a^2\frac{b}{a+b} = ab$ by monotone and bounded convergence.

### The reflection principle

**Theorem 4 (reflection principle; quoted, the proof uses the strong Markov property).** For $a > 0$ and $t > 0$, with $M_t = \max_{s \le t}B_s$ and $T_a = \inf\{s : B_s = a\}$,
$$P(M_t \ge a) = P(T_a \le t) = 2P(B_t \ge a) = P(|B_t| \ge a).$$
*Outline.* At the stopping time $T_a$ the process $B_{T_a + s} - a$ is a new Brownian motion independent of the past. On $\{T_a \le t\}$ it is symmetric about $0$, so $B_t \ge a$ with conditional probability $\frac12$; and $\{B_t \ge a\} \subseteq \{T_a \le t\}$.

The discrete analogue is a complete theorem. For the simple symmetric random walk $S_n$ with $M_n = \max_{k \le n}S_k$ and an integer $a \ge 1$,
$$P(M_n \ge a) = P(S_n \ge a) + P(S_n > a).$$
*Proof.* Reflect a path after its first visit to $a$: this is a bijection between paths with $M_n \ge a$ and $S_n < a$ and paths with $S_n > a$ (every path ending above $a$ visits $a$), so $P(M_n \ge a, S_n < a) = P(S_n > a)$. Add $P(M_n \ge a, S_n \ge a) = P(S_n \ge a)$. $\blacksquare$

The two terms (not twice one term) differ from the continuous answer by the lattice correction $P(S_n = a)$. Next, Donsker's theorem (quoted): the rescaled walks $S_{\lfloor nt\rfloor}/\sqrt{n}$ converge in law, as random continuous functions, to $B$. The law of the iterated logarithm (quoted) says $\limsup_{t \to \infty}B_t/\sqrt{2t\log\log t} = 1$ almost surely. For exams, learn the definition, the martingales of Theorem 3, the quadratic variation proof and the way optional stopping solves exit problems.

@example
title: Conditioning a Brownian path on its endpoint
problem: Find $\mathbb{E}[B_1 \mid B_4 = 2]$ and $\operatorname{Var}(B_1 \mid B_4)$.
step: $(B_1, B_4)$ is jointly Gaussian, centered, with $\operatorname{Var}B_1 = 1$, $\operatorname{Var}B_4 = 4$ and $\operatorname{Cov}(B_1, B_4) = \min(1,4) = 1$.
step: For jointly Gaussian centered variables, $\mathbb{E}[B_1 \mid B_4] = \dfrac{\operatorname{Cov}(B_1, B_4)}{\operatorname{Var}B_4}B_4 = \dfrac{B_4}{4}$, which equals $\frac12$ when $B_4 = 2$.
step: The conditional variance is $\operatorname{Var}B_1 - \dfrac{\operatorname{Cov}(B_1, B_4)^2}{\operatorname{Var}B_4} = 1 - \dfrac14 = \dfrac34$.
step: Check with independence: $B_1$ and $B_4 - B_1$ are independent with variances $1$ and $3$, so by the projection formula $\mathbb{E}[B_1 \mid B_4] = \frac{1}{1+3}B_4$ and the variance is $\frac{1\cdot3}{1+3} = \frac34$.
answer: $\mathbb{E}[B_1 \mid B_4 = 2] = \frac12$ and $\operatorname{Var}(B_1 \mid B_4) = \frac34$.

@example
title: Brownian exit probabilities
problem: Let $T$ be the first time Brownian motion hits $-2$ or $3$. Find $P(B_T = 3)$ and $\mathbb{E}T$.
step: $B_{t \wedge T}$ is a bounded martingale, taking values in $[-2, 3]$, and $T < \infty$ almost surely. So $\mathbb{E}B_T = 0$.
step: With $p = P(B_T = 3)$: $3p - 2(1-p) = 0$, so $p = \frac25$.
step: $B_{t \wedge T}^2 - (t \wedge T)$ is a martingale, so $\mathbb{E}(t \wedge T) = \mathbb{E}B_{t \wedge T}^2 \le 9$ for each $t$. Monotone convergence gives $\mathbb{E}T \le 9 < \infty$, and bounded convergence gives $\mathbb{E}T = \mathbb{E}B_T^2$.
step: $\mathbb{E}B_T^2 = 9\cdot\frac25 + 4\cdot\frac35 = \frac{18 + 12}{5} = 6 = ab$.
answer: $P(B_T = 3) = \frac25$ and $\mathbb{E}T = 6$.

@mistakes
- Treating the paths of Brownian motion as differentiable or of bounded variation: the quadratic variation of $[0,t]$ is $t$, not $0$.
- Forgetting the lattice correction in the discrete reflection principle: for the walk, $P(M_n \ge a) = P(S_n \ge a) + P(S_n > a)$, not $2P(S_n \ge a)$.
- Using $B_t^2$ instead of $B_t^2 - t$ as the martingale, or $e^{\theta B_t}$ without the factor $e^{-\theta^2t/2}$.
- Applying optional stopping to $T_a$ (the hitting time of one level): $B_{T_a} = a \ne 0$, because $\mathbb{E}T_a = \infty$ and the stopped martingale is not uniformly integrable.

model:
```python
from fractions import Fraction
from math import comb


def max_tail(n, a):
    """Exact P(max of the first n partial sums >= a) for the +-1 walk."""
    at_least = 0
    greater = 0
    for k in range(n + 1):          # k up-steps give S_n = 2k - n
        s = 2 * k - n
        if s >= a:
            at_least += comb(n, k)
        if s > a:
            greater += comb(n, k)
    return Fraction(at_least + greater, 2 ** n)
```
hint: After $n$ steps with $k$ up-steps, $S_n = 2k - n$ and there are $\binom{n}{k}$ such paths among $2^n$.
hint: Count the paths with $S_n \ge a$ and with $S_n > a$ separately, then add the counts.
solution: The reflection principle for the walk gives $P(M_n \ge a) = P(S_n \ge a) + P(S_n > a)$; each probability is a sum of binomial counts divided by $2^n$. The Brownian formula $2P(B_t \ge a)$ would correspond to doubling only the first term, which is wrong for the lattice walk when $S_n = a$ has positive probability: for $n = 4$, $a = 2$ it would give $\frac58$ instead of $\frac38$.

@practice self
prompt: Use the reflection principle $P(\max_{s \le t}B_s \ge a) = 2P(B_t \ge a)$ for $a > 0$ to prove that $T_a = \inf\{t : B_t = a\}$ satisfies $P(T_a < \infty) = 1$ and $\mathbb{E}T_a = \infty$.
hint: Write $P(T_a > t) = P(|B_t| < a)$ and let $t \to \infty$.
hint: Use $\mathbb{E}T_a = \int_0^\infty P(T_a > t)\,dt$ and a lower bound of order $t^{-1/2}$ for $P(|B_t| < a)$.
solution: By the reflection principle, $P(T_a \le t) = P(M_t \ge a) = 2P(B_t \ge a) = P(|B_t| \ge a)$, so $P(T_a > t) = P(|B_t| < a) = P(|Z| < a/\sqrt{t})$ with $Z \sim N(0,1)$, since $B_t \sim \sqrt{t}\,Z$. As $t \to \infty$ this tends to $P(|Z| < 0) = 0$ (continuity of the law of $Z$), so $P(T_a < \infty) = \lim_t P(T_a \le t) = 1$. For the expectation, $\mathbb{E}T_a = \int_0^\infty P(T_a > t)\,dt$. For $t \ge a^2$, $a/\sqrt{t} \le 1$, so the standard normal density is at least $\varphi(1) = (2\pi)^{-1/2}e^{-1/2} > 0.24$ on $[-a/\sqrt t, a/\sqrt t]$, and $P(|Z| < a/\sqrt{t}) \ge 0.24\cdot 2a/\sqrt{t}$. Hence $\int_{a^2}^\infty P(T_a > t)\,dt \ge 0.48\,a\int_{a^2}^\infty t^{-1/2}\,dt = \infty$, so $\mathbb{E}T_a = \infty$. $\blacksquare$
rubric: Derives $P(T_a > t) = P(|B_t| < a)$ from the reflection principle.
rubric: Shows $P(T_a < \infty) = 1$ by letting $t \to \infty$ with scaling $B_t \sim \sqrt{t}\,Z$.
rubric: Uses the tail-integral formula for the expectation and a quantitative lower bound of order $t^{-1/2}$ to show divergence.

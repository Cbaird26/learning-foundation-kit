@article
Your fortune in a game can never go negative, and the game is fair. Can the fortune oscillate forever between, say, $1$ and $2$? Every time it crosses from below $1$ to above $2$ you could have bought low and sold high, which a fair game does not reward in expectation. Counting these crossings gives the proof that bounded martingales settle down.

### Upcrossings

Let $X_0, X_1, \dots, X_n$ be adapted and $a < b$. An **upcrossing** of $[a,b]$ is a passage from a time with $X_s \le a$ to a later time $t$ with $X_t \ge b$; $U_n[a,b]$ is the maximal number of disjoint upcrossings completed by time $n$. If $\liminf X_k < a < b < \limsup X_k$, then $U_n[a,b] \to \infty$; so finite upcrossing counts prevent oscillation.

**Theorem 1 (Doob's upcrossing inequality).** If $(X_k)$ is a submartingale, then $(b - a)\,\mathbb{E}\,U_n[a,b] \le \mathbb{E}(X_n - a)^+ - \mathbb{E}(X_0 - a)^+$.

*Proof.* Let $Y_k = a + (X_k - a)^+ = \max(X_k, a)$, a submartingale (a convex nondecreasing function of a submartingale), with the same upcrossings of $[a,b]$ as $X$. Define stopping times $N_1 = \inf\{m : Y_m = a\}$, $N_2 = \inf\{m > N_1 : Y_m \ge b\}$, $N_3 = \inf\{m > N_2 : Y_m = a\}$, and so on, and let $H_k = 1$ if $N_{2j-1} < k \le N_{2j}$ for some $j$ and $H_k = 0$ otherwise. Then $H_k \in \{0,1\}$ is $\mathcal{F}_{k-1}$-measurable (predictable), and $H$ is the strategy "hold while between a visit to $a$ and the next visit to $b$". Each completed upcrossing contributes at least $b - a$ to $(H \cdot Y)_n$, and an incomplete final holding period contributes at least $0$ since $Y \ge a$ throughout, so $(b-a)U_n[a,b] \le (H \cdot Y)_n$. With $K = 1 - H \ge 0$, $Y_n - Y_0 = (H\cdot Y)_n + (K \cdot Y)_n$ and $\mathbb{E}(K\cdot Y)_n \ge 0$ because $K\cdot Y$ is a submartingale starting at $0$ (last week's Theorem 1). Hence $(b-a)\mathbb{E}U_n \le \mathbb{E}(H\cdot Y)_n \le \mathbb{E}Y_n - \mathbb{E}Y_0 = \mathbb{E}(X_n - a)^+ - \mathbb{E}(X_0 - a)^+$. $\blacksquare$

### Convergence

**Theorem 2 (martingale convergence theorem).** If $(X_n)$ is a submartingale with $\sup_n \mathbb{E}X_n^+ < \infty$, then $X_n \to X_\infty$ almost surely, where $X_\infty$ is a random variable with $\mathbb{E}|X_\infty| < \infty$.

*Proof.* Fix rationals $a < b$. By Theorem 1, $\mathbb{E}U_n[a,b] \le (\mathbb{E}X_n^+ + |a|)/(b-a) \le C_{a,b}$ for all $n$, and $U_n \uparrow U_\infty$, so $\mathbb{E}U_\infty \le C_{a,b}$ by monotone convergence and $U_\infty[a,b] < \infty$ almost surely. The event $\{\liminf X_n < \limsup X_n\}$ is the countable union over rational $a < b$ of $\{\liminf X_n < a < b < \limsup X_n\} \subseteq \{U_\infty[a,b] = \infty\}$, so it has probability $0$ and $X_\infty = \lim X_n$ exists in $[-\infty, \infty]$ almost surely. Finally $\mathbb{E}|X_n| = 2\mathbb{E}X_n^+ - \mathbb{E}X_n \le 2\mathbb{E}X_n^+ - \mathbb{E}X_0$ is bounded, and Fatou's lemma gives $\mathbb{E}|X_\infty| \le \liminf \mathbb{E}|X_n| < \infty$, so $X_\infty$ is finite almost surely. $\blacksquare$

**Corollary 3.** A nonnegative supermartingale converges almost surely to an integrable limit. (Apply Theorem 2 to $-X$, whose positive part is $0$.)

**Corollary 4.** If $(M_n)$ is a martingale with $\sup_n \mathbb{E}M_n^2 < \infty$, then $M_n \to M_\infty$ almost surely and in $L^2$.

*Proof.* Orthogonality of increments gives $\mathbb{E}M_n^2 = \mathbb{E}M_0^2 + \sum_{k \le n}\mathbb{E}(M_k - M_{k-1})^2$, so the series converges and $(M_n)$ is Cauchy in $L^2$: $\mathbb{E}(M_n - M_m)^2 = \sum_{m < k \le n}\mathbb{E}(M_k - M_{k-1})^2$. Hence $M_n \to M$ in $L^2$. Also $\sup\mathbb{E}M_n^+ \le \sup(\mathbb{E}M_n^2)^{1/2} < \infty$, so $M_n$ converges a.s. by Theorem 2, and the two limits agree. $\blacksquare$

### $L^1$ convergence needs uniform integrability

Almost sure convergence of a martingale does not give $\mathbb{E}M_\infty = \mathbb{E}M_0$. A family is **uniformly integrable** if $\sup_n \mathbb{E}[|X_n|;\ |X_n| > K] \to 0$ as $K \to \infty$.

**Theorem 5 (stated without proof).** For a martingale $(M_n)$ the following are equivalent: (a) $(M_n)$ is uniformly integrable; (b) $M_n$ converges in $L^1$; (c) $M_n \to M_\infty$ a.s. and in $L^1$; (d) $M_n = \mathbb{E}[Y \mid \mathcal{F}_n]$ for some integrable $Y$. In that case $M_n = \mathbb{E}[M_\infty \mid \mathcal{F}_n]$, and for any integrable $Y$, $\mathbb{E}[Y \mid \mathcal{F}_n] \to \mathbb{E}[Y \mid \mathcal{F}_\infty]$ almost surely and in $L^1$ (Lévy's upward theorem).

**Product martingale.** Let $\eta_k$ be i.i.d. with $P(\eta = 0) = P(\eta = 2) = \frac12$, and $M_n = \prod_{k \le n}\eta_k$. It is a nonnegative martingale with $\mathbb{E}M_n = 1$. But $M_n = 2^n$ with probability $2^{-n}$ and $0$ otherwise, so $\sum P(M_n \ne 0) < \infty$ and $M_n \to 0$ almost surely by Borel–Cantelli. Thus $\mathbb{E}M_\infty = 0 < 1 = \mathbb{E}M_n$: no $L^1$ convergence, no uniform integrability.

**Pólya's urn.** Start with one red and one blue ball. Then $R_n$ (number of red balls after $n$ draws) is uniform on $\{1, \dots, n+1\}$. Induction: if $P(R_n = k) = \frac1{n+1}$ for $1 \le k \le n+1$, the total is $T = n + 2$ and
$$P(R_{n+1} = k) = \frac{1}{n+1}\cdot\frac{T - k}{T} + \frac{1}{n+1}\cdot\frac{k - 1}{T} = \frac{1}{n+1}\cdot\frac{T - 1}{T} = \frac{1}{n+2},$$
(with the convention that the terms outside the range vanish). So $M_n = R_n/(n+2)$ has a limit $M_\infty$ almost surely; $M_n \in (0,1)$ is bounded, hence uniformly integrable, and the limit is uniform on $(0,1)$: the law of $M_n$ is uniform on the grid $\{\frac{1}{n+2}, \dots, \frac{n+1}{n+2}\}$, which converges weakly to the uniform law.

```python
import random


def polya_path(red, blue, us):
    """Fraction of red balls after each draw, using the uniforms in us."""
    fractions = []
    for u in us:
        if u < red / (red + blue):
            red += 1
        else:
            blue += 1
        fractions.append(red / (red + blue))
    return fractions


rng = random.Random(5)
path = polya_path(1, 1, [rng.random() for _ in range(2000)])
print(all(0 < x < 1 for x in path), abs(path[-1] - path[-100]) < 0.2)
```

It prints `True True`: each sample path settles down, but to a *random* limit that differs from path to path. This illustrates the theorem; it proves nothing. On exams, the standard questions are to prove Theorem 2 or its corollaries, to find an $L^1$-bounded martingale that does not converge in $L^1$, and to identify a limit.

@example
title: A nonnegative martingale that vanishes
problem: Show that $M_n = \prod_{k \le n}\eta_k$ with $\eta_k$ i.i.d., $P(\eta = 0) = \frac13$ and $P(\eta = \frac32) = \frac23$, is a martingale that converges almost surely to $0$ although $\mathbb{E}M_n = 1$.
step: $\mathbb{E}\eta = \frac23\cdot\frac32 = 1$, and $M_n$ is adapted with $\mathbb{E}[M_{n+1} \mid \mathcal{F}_n] = M_n\mathbb{E}\eta_{n+1} = M_n$, so $M$ is a nonnegative martingale and $\mathbb{E}M_n = 1$.
step: By Corollary 3, $M_n$ converges almost surely to some limit $M_\infty \ge 0$.
step: $P(M_n > 0) = (\frac23)^n \to 0$, so $M_n \to 0$ in probability, and the almost sure limit must be $0$ (a subsequence of $M_n$ converges a.s. to $0$ by the subsequence criterion).
step: Hence $M_\infty = 0$ almost surely and $\mathbb{E}M_\infty = 0 \ne 1$. The convergence is not in $L^1$.
answer: $M_n \to 0$ almost surely while $\mathbb{E}M_n = 1$ for all $n$.

@example
title: An $L^2$-bounded martingale from a random series
problem: Let $\varepsilon_k$ be independent fair signs and $M_n = \sum_{k \le n}\varepsilon_k/k$. Show that $M_n$ converges almost surely and in $L^2$, and find $\mathbb{E}M_\infty^2$.
step: $M_n$ is a martingale for $\mathcal{F}_n = \sigma(\varepsilon_1, \dots, \varepsilon_n)$, with orthogonal increments.
step: $\mathbb{E}M_n^2 = \sum_{k \le n}k^{-2} \le \frac{\pi^2}{6}$, so $M$ is bounded in $L^2$.
step: By Corollary 4, $M_n \to M_\infty$ almost surely and in $L^2$.
step: Since $L^2$ convergence preserves second moments, $\mathbb{E}M_\infty^2 = \sum_{k \ge 1}k^{-2} = \frac{\pi^2}{6}$. The random harmonic series with random signs converges almost surely, although $\sum 1/k$ diverges.
answer: $M_n \to M_\infty$ a.s. and in $L^2$, with $\mathbb{E}M_\infty^2 = \pi^2/6$.

@mistakes
- Believing that almost sure convergence of a martingale implies $\mathbb{E}M_\infty = \mathbb{E}M_0$; the product martingale has $\mathbb{E}M_n = 1$ and limit $0$.
- Applying Theorem 2 to a martingale that is not $L^1$-bounded: the simple random walk is a martingale that oscillates forever.
- Forgetting that the limit of a martingale can be random, as in Pólya's urn.
- Using the sign convention wrong in Corollary 3: it is nonnegative *super*martingales (not submartingales) that always converge, since $-X$ is a submartingale with $\sup\mathbb{E}(-X_n)^+ = 0$.

model:
```python
from fractions import Fraction


def urn_distribution(red, blue, n):
    """Exact law of the number of red balls in a Polya urn after n draws."""
    dist = {red: Fraction(1)}
    for t in range(n):
        total = red + blue + t
        new = {}
        for r, mass in dist.items():
            new[r + 1] = new.get(r + 1, Fraction(0)) + mass * Fraction(r, total)
            new[r] = new.get(r, Fraction(0)) + mass * Fraction(total - r, total)
        dist = new
    return dist
```
hint: Keep a dictionary from "number of red balls" to probability and update it one draw at a time.
hint: When the urn has `r` red balls out of `total`, a red draw has probability `r / total` and then red increases by one; otherwise red stays the same.
solution: After $t$ draws the urn has $\text{red} + \text{blue} + t$ balls. From a state with $r$ red balls, a red draw (probability $r/\text{total}$) leads to $r + 1$ red balls, and a blue draw leaves $r$. Pushing the probabilities forward step by step gives the exact law; the last test checks the martingale property $\mathbb{E}[R_n/T_n] = R_0/T_0$ exactly. Drawing without replacement would give the hypergeometric law instead.

@practice self
prompt: Let $\xi_1, \xi_2, \dots$ be i.i.d. positive random variables with $\mathbb{E}\xi_1 = 1$ and $P(\xi_1 = 1) < 1$, and let $M_n = \prod_{k \le n}\xi_k$. Prove that $M_n$ is a martingale with $\mathbb{E}M_n = 1$ for all $n$, that $M_n \to 0$ almost surely, and hence that $M_n$ does not converge in $L^1$.
hint: Take logarithms: $\log M_n$ is a random walk, and strict Jensen gives $\mathbb{E}\log\xi_1 < \log\mathbb{E}\xi_1 = 0$.
hint: Apply the strong law to $\max(\log\xi_k, -K)$ for a large $K$ if $\mathbb{E}\log\xi_1$ might be $-\infty$.
solution: Independence gives $\mathbb{E}[M_{n+1} \mid \mathcal{F}_n] = M_n\mathbb{E}\xi_{n+1} = M_n$ and $\mathbb{E}M_n = 1$. Let $L_k = \log\xi_k$. Since $L_k^+ \le \xi_k$, $\mathbb{E}L_1^+ < \infty$, so $\mathbb{E}L_1 \in [-\infty, \infty)$ is defined. The function $\log$ is strictly concave and $\xi_1$ is not a.s. constant (if $\xi_1$ were constant with mean $1$ it would equal $1$), so strict Jensen gives $\mathbb{E}L_1 < \log\mathbb{E}\xi_1 = 0$. Choose $K$ with $\mathbb{E}\max(L_1, -K) < 0$ (possible by monotone convergence as $K \to \infty$ since $\max(L_1,-K) \downarrow L_1$ and $\mathbb{E}L_1 < 0$). The strong law of large numbers for the integrable i.i.d. variables $\max(L_k, -K)$ gives $\frac1n\sum_{k \le n}\max(L_k, -K) \to c := \mathbb{E}\max(L_1, -K) < 0$ almost surely, and $\log M_n = \sum_{k \le n}L_k \le \sum_{k \le n}\max(L_k, -K)$. Hence $\limsup\frac1n\log M_n \le c < 0$ and $\log M_n \to -\infty$, so $M_n \to 0$ almost surely. If $M_n \to 0$ in $L^1$ were true, $\mathbb{E}M_n \to 0$, contradicting $\mathbb{E}M_n = 1$; and the only possible $L^1$ limit is the almost sure limit $0$. $\blacksquare$

rubric: Proves $\mathbb{E}\log\xi_1 < 0$ by strict Jensen, noting why $\xi_1$ is not a.s. constant, and handles the case where the mean is $-\infty$ by truncation.
rubric: Applies the strong law to get $\log M_n \to -\infty$ a.s. and concludes that $L^1$ convergence is impossible because $\mathbb{E}M_n = 1$.

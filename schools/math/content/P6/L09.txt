@article
Start with $3$ dollars and bet $1$ dollar on a fair coin each round, stopping when you reach $10$ dollars or $0$. What is the probability of reaching $10$? Fortune is a martingale with $\mathbb{E}S_0 = 3$. If expectation were preserved at the stopping time, then $10\,P(\text{win}) = 3$, so $P(\text{win}) = 0.3$. Last week showed that $\mathbb{E}X_{n \wedge \tau} = \mathbb{E}X_0$ for every fixed $n$. The question is when the limit $n \to \infty$ may be taken inside.

### The theorem

**Theorem 1 (optional stopping).** Let $X$ be a martingale and $\tau$ a stopping time. Then $\mathbb{E}X_\tau = \mathbb{E}X_0$ in each of these cases:
(i) $\tau \le N$ for a constant $N$;
(ii) $\tau < \infty$ almost surely and $|X_n| \le K$ for all $n$, for a constant $K$;
(iii) $\mathbb{E}\tau < \infty$ and $|X_{n+1} - X_n| \le c$ for all $n$, for a constant $c$;
(iv) $\tau < \infty$ almost surely and $(X_{n \wedge \tau})_n$ is uniformly integrable.
For a submartingale the same conditions give $\mathbb{E}X_\tau \ge \mathbb{E}X_0$.

*Proof.* By Corollary 2 of last week, $\mathbb{E}X_{n \wedge \tau} = \mathbb{E}X_0$ for every $n$. (i) Take $n = N$, so $X_{N \wedge \tau} = X_\tau$. For (ii)–(iv), $\tau < \infty$ a.s. (in (iii) because $\mathbb{E}\tau < \infty$), so $X_{n \wedge \tau} \to X_\tau$ almost surely, and it remains to pass to the limit in the expectations. (ii) $|X_{n \wedge \tau}| \le K$; apply bounded convergence. (iii) $|X_{n \wedge \tau} - X_0| \le \sum_{k=1}^{n \wedge \tau}|X_k - X_{k-1}| \le c\tau$, which is integrable; apply dominated convergence. (iv) Uniform integrability and almost sure convergence give $L^1$ convergence (Vitali's theorem from P1), so the expectations converge. $\blacksquare$

**Nonnegative case.** If $X \ge 0$ is a supermartingale and $\tau < \infty$ a.s., Fatou's lemma gives $\mathbb{E}X_\tau \le \liminf \mathbb{E}X_{n \wedge \tau} \le \mathbb{E}X_0$, an inequality only.

**Counterexample.** Let $S$ be the simple symmetric random walk and $\tau = \inf\{n : S_n = 1\}$. It is a standard fact (the second worked example below shows why) that $\tau < \infty$ almost surely, so $S_\tau = 1$ and $\mathbb{E}S_\tau = 1 \ne 0 = \mathbb{E}S_0$. None of (i)–(iv) holds: $\tau$ is unbounded, $S$ is unbounded below, and $\mathbb{E}\tau = \infty$ (otherwise (iii) would apply, as increments are bounded by $1$). A finite stopping time is not enough.

### Gambler's ruin

Let $S_n = i + \xi_1 + \dots + \xi_n$ with i.i.d. steps, $P(\xi = 1) = p$, $P(\xi = -1) = q = 1 - p$, and $\tau = \inf\{n : S_n \in \{0, N\}\}$ for an integer $0 \le i \le N$.

**Finiteness.** From any position in $\{1, \dots, N-1\}$ the walk reaches the boundary within $N$ steps with probability at least $\min(p,q)^N =: \delta > 0$ (take $N$ steps in one direction). Hence $P(\tau > kN) \le (1 - \delta)^k$, so $\tau$ has geometric tails and $\mathbb{E}\tau < \infty$. Also $S_{n \wedge \tau} \in [0, N]$ is bounded.

**Symmetric case $p = \frac12$.** $S_n$ is a martingale bounded up to $\tau$, so (ii) gives $i = \mathbb{E}S_\tau = N\,P(S_\tau = N)$, that is $P(S_\tau = N) = i/N$. For the duration, $M_n = (S_n - i)^2 - n$ is a martingale with $|M_{(n+1)\wedge\tau} - M_{n \wedge \tau}| = 2|S_n - i|\,\mathbf{1}_{\{n < \tau\}} \le 2N$, so (iii) gives $0 = \mathbb{E}(S_\tau - i)^2 - \mathbb{E}\tau$ and
$$\mathbb{E}\tau = (N-i)^2\frac{i}{N} + i^2\frac{N-i}{N} = i(N - i).$$

**Biased case $p \ne \frac12$.** With $r = q/p$, $r^{S_n}$ is a martingale: $\mathbb{E}r^{\xi} = p\cdot\frac qp + q\cdot\frac pq = q + p = 1$. It is bounded up to $\tau$, so $r^i = \mathbb{E}r^{S_\tau} = r^N h_i + (1 - h_i)$ where $h_i = P(S_\tau = N)$, which gives
$$h_i = \frac{1 - r^i}{1 - r^N}.$$
For the duration use the martingale $S_n - (p - q)n$, a bounded-increment martingale: (iii) gives $\mathbb{E}S_\tau - i = (p-q)\mathbb{E}\tau$, so $\mathbb{E}\tau = \dfrac{N h_i - i}{p - q}$.

```python
from fractions import Fraction


def win_prob(i, N, p):
    """P(hit N before 0) starting from i, with up-probability p."""
    q = 1 - p
    if p == q:
        return Fraction(i, N)
    r = q / p
    return (1 - r ** i) / (1 - r ** N)


p = Fraction(2, 5)
h = [win_prob(i, 6, p) for i in range(7)]
print(all(h[i] == p * h[i + 1] + (1 - p) * h[i - 1] for i in range(1, 6)))
```

This prints `True`: the formula satisfies the one-step recursion $h_i = ph_{i+1} + qh_{i-1}$ with $h_0 = 0$, $h_N = 1$, which determines $h$ uniquely.

### Wald's identity

**Theorem 2 (Wald).** Let $\xi_1, \xi_2, \dots$ be i.i.d. with $\mathbb{E}|\xi_1| < \infty$ and mean $\mu$, $\mathcal{F}_n = \sigma(\xi_1, \dots, \xi_n)$, $S_n = \xi_1 + \dots + \xi_n$, and $\tau$ a stopping time with $\mathbb{E}\tau < \infty$. Then $\mathbb{E}S_\tau = \mu\,\mathbb{E}\tau$.

*Proof.* $S_n - \mu n$ is a martingale, so by Corollary 2, $\mathbb{E}S_{n \wedge \tau} = \mu\,\mathbb{E}(n \wedge \tau)$. As $n \to \infty$, $\mathbb{E}(n \wedge \tau) \uparrow \mathbb{E}\tau$ by monotone convergence. Also $|S_{n \wedge \tau}| \le Y = \sum_{k=1}^{\tau}|\xi_k| = \sum_{k \ge 1}|\xi_k|\mathbf{1}_{\{\tau \ge k\}}$, and $\{\tau \ge k\} = \{\tau \le k-1\}^c \in \mathcal{F}_{k-1}$ is independent of $\xi_k$, so $\mathbb{E}Y = \sum_k \mathbb{E}|\xi_1|\,P(\tau \ge k) = \mathbb{E}|\xi_1|\,\mathbb{E}\tau < \infty$. Since $S_{n \wedge \tau} \to S_\tau$ a.s., dominated convergence gives $\mathbb{E}S_{n \wedge \tau} \to \mathbb{E}S_\tau$. $\blacksquare$

On exams, say which of (i)–(iv) you use, and verify its hypotheses: that is where credit is earned.

@example
title: Symmetric ruin from four dollars
problem: A fair coin game starts at $4$ dollars and stops at $0$ or $12$. Find the probability of reaching $12$ and the expected number of rounds.
step: $S_n$ is a martingale. The stopping time $\tau$ is almost surely finite with geometric tails, and $0 \le S_{n \wedge \tau} \le 12$, so optional stopping (ii) applies.
step: $4 = \mathbb{E}S_\tau = 12\,P(S_\tau = 12) + 0$, so $P(S_\tau = 12) = \frac13$.
step: $(S_n - 4)^2 - n$ is a martingale with increments bounded by $2 \cdot 12$ up to $\tau$, and $\mathbb{E}\tau < \infty$, so (iii) gives $\mathbb{E}\tau = \mathbb{E}(S_\tau - 4)^2$.
step: $S_\tau - 4 = 8$ with probability $\frac13$ and $-4$ with probability $\frac23$, so $\mathbb{E}\tau = 64\cdot\frac13 + 16\cdot\frac23 = \frac{96}{3} = 32 = 4 \cdot 8$.
answer: $P(\text{reach } 12) = \frac13$ and $\mathbb{E}\tau = 32$.

@example
title: Why the hitting time of one has infinite mean
problem: For the simple symmetric walk from $0$ and $\tau = \inf\{n : S_n = 1\}$, deduce from optional stopping that $\mathbb{E}\tau = \infty$.
step: Suppose $\mathbb{E}\tau < \infty$. The walk has increments bounded by $1$, so optional stopping (iii) gives $\mathbb{E}S_\tau = \mathbb{E}S_0 = 0$.
step: But $S_\tau = 1$ on $\{\tau < \infty\}$, and $\mathbb{E}\tau < \infty$ implies $\tau < \infty$ a.s., so $\mathbb{E}S_\tau = 1$. Contradiction.
step: Hence $\mathbb{E}\tau = \infty$, even though $\tau < \infty$ almost surely: by the fair gambler's-ruin formula the walk reaches $1$ before $-N$ with probability $\frac{N}{N+1}$, so $P(\tau < \infty) \ge \frac{N}{N+1}$ for every $N$, and therefore $P(\tau < \infty) = 1$.
answer: $\mathbb{E}\tau = \infty$.

@mistakes
- Applying optional stopping to any a.s. finite stopping time: the walk hitting level $1$ shows that $\mathbb{E}S_\tau$ can differ from $\mathbb{E}S_0$.
- Using condition (iii) without checking $\mathbb{E}\tau < \infty$; for gambler's ruin this requires the geometric-tail argument.
- Mixing up the martingale for the biased walk: $S_n$ is not a martingale when $p \ne \frac12$, and $\left(\frac qp\right)^{S_n}$ is.
- Forgetting to center: for a walk started at $i$ the martingale is $(S_n - i)^2 - n$, not $S_n^2 - n$.

model:
```python
from fractions import Fraction


def expected_duration(N, p):
    """Exact expected absorption times by Gaussian elimination."""
    q = 1 - p
    n = N - 1
    rows = []
    for i in range(1, N):
        row = [Fraction(0)] * (n + 1)
        row[i - 1] = Fraction(1)
        if i + 1 < N:
            row[i] -= p
        if i - 1 >= 1:
            row[i - 2] -= q
        row[n] = Fraction(1)
        rows.append(row)
    for c in range(n):
        piv = next(r for r in range(c, n) if rows[r][c] != 0)
        rows[c], rows[piv] = rows[piv], rows[c]
        scale = rows[c][c]
        rows[c] = [x / scale for x in rows[c]]
        for r in range(n):
            if r != c and rows[r][c] != 0:
                f = rows[r][c]
                rows[r] = [x - f * y for x, y in zip(rows[r], rows[c])]
    return [Fraction(0)] + [rows[i][n] for i in range(n)] + [Fraction(0)]
```
hint: Unknowns are $D_1, \dots, D_{N-1}$; the boundary values $D_0 = D_N = 0$ simply drop out of the first and last equations.
hint: Build the matrix of $D_i - pD_{i+1} - qD_{i-1} = 1$ and run Gauss–Jordan elimination with `Fraction` entries.
solution: Each equation $D_i - pD_{i+1} - qD_{i-1} = 1$ is linear in the unknowns $D_1, \dots, D_{N-1}$, with the terms $D_0, D_N$ equal to zero removed. Gauss–Jordan elimination over the rationals gives the exact solution; for $p = \frac12$ it reproduces the optional-stopping formula $i(N-i)$, which the tests check. The system is nonsingular because absorption is certain.

@practice self
prompt: Let $S_n = \xi_1 + \dots + \xi_n$ with $\xi_k$ i.i.d., $P(\xi_k = 1) = p$, $P(\xi_k = -1) = q = 1 - p$, $p \ne \frac12$, and let $\tau$ be the first time that $S_n \in \{-a, b\}$ for positive integers $a, b$. Find $P(S_\tau = b)$ and $\mathbb{E}\tau$ in terms of $p, a, b$, justifying every use of optional stopping. (For $p = \frac23$, $a = 2$, $b = 3$ the answers are $\frac{24}{31}$ and $\frac{174}{31}$.)
hint: Use the martingales $r^{S_n}$ with $r = q/p$ and $S_n - (p - q)n$.
hint: First show $\mathbb{E}\tau < \infty$ using the geometric-tail argument, then check the hypotheses of the optional stopping theorem.
solution: Window and finiteness: in the interval $(-a, b)$ of $a + b - 1$ interior points, the walk exits within $m = a + b$ steps with probability at least $\delta = \min(p,q)^m > 0$ from any interior point, so $P(\tau > km) \le (1-\delta)^k$ and $\mathbb{E}\tau < \infty$. Hitting probability: with $r = q/p$, $\mathbb{E}[r^{\xi}] = q + p = 1$, so $r^{S_n}$ is a martingale; $r^{S_{n \wedge \tau}}$ is bounded by $\max(r^b, r^{-a})$, and $\tau < \infty$ a.s., so bounded convergence gives $\mathbb{E}r^{S_\tau} = 1$. With $h = P(S_\tau = b)$, $h\,r^b + (1-h)\,r^{-a} = 1$, hence $h = \dfrac{1 - r^{-a}}{r^b - r^{-a}}$. Expected duration: $S_n - (p-q)n$ is a martingale with increments bounded by $1 + |p - q| \le 2$ and $\mathbb{E}\tau < \infty$, so optional stopping (iii) gives $\mathbb{E}S_\tau = (p-q)\mathbb{E}\tau$, that is $\mathbb{E}\tau = \dfrac{hb - (1-h)a}{p - q}$. For $p = \frac23$, $r = \frac12$, $a = 2$, $b = 3$: $h = \frac{1 - 4}{\frac18 - 4} = \frac{24}{31}$, and $\mathbb{E}\tau = \frac{\frac{72}{31} - \frac{14}{31}}{1/3} = \frac{174}{31}$. $\blacksquare$

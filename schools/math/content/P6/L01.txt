@article
Pick a point uniformly from $[0,1]$. What is the probability that it lies in a given set $A$? For an interval the answer is its length, but the Vitali construction from P1 shows that no translation-invariant, countably additive extension of length to all subsets of $[0,1]$ exists. Probability theory therefore starts by deciding which sets are events, and then asks for countable additivity on those.

### Probability spaces

**Definition (Kolmogorov, 1933).** A *probability space* is a triple $(\Omega, \mathcal{F}, P)$: $\Omega$ is a set, $\mathcal{F}$ is a $\sigma$-algebra of subsets of $\Omega$ (contains $\Omega$, closed under complements and countable unions), and $P\colon \mathcal{F} \to [0,1]$ satisfies $P(\Omega) = 1$ and $P\left(\bigcup_i A_i\right) = \sum_i P(A_i)$ for every sequence of pairwise disjoint $A_i \in \mathcal{F}$.

**Theorem 1 (continuity).** Let $P$ be a probability measure. (a) If $A_n \in \mathcal{F}$ and $A_n \uparrow A$, then $P(A_n) \uparrow P(A)$. (b) If $A_n \downarrow A$, then $P(A_n) \downarrow P(A)$.

*Proof.* (a) Put $B_1 = A_1$ and $B_n = A_n \setminus A_{n-1}$. The $B_n$ are disjoint, $A_n = B_1 \cup \dots \cup B_n$ and $A = \bigcup_n B_n$, so $P(A) = \sum_n P(B_n) = \lim_n \sum_{k \le n} P(B_k) = \lim_n P(A_n)$. (b) The complements satisfy $A_n^c \uparrow A^c$, so by (a) $1 - P(A_n) \to 1 - P(A)$. This step uses $P(\Omega) < \infty$. $\blacksquare$

Part (b) fails for infinite measures: for Lebesgue measure, $[n, \infty) \downarrow \emptyset$ but each has measure $\infty$.

### Uniqueness

A family $\mathcal{P}$ of sets is a **$\pi$-system** if $A, B \in \mathcal{P}$ implies $A \cap B \in \mathcal{P}$; a family $\mathcal{L}$ is a **$\lambda$-system** if $\Omega \in \mathcal{L}$, $A, B \in \mathcal{L}$ with $A \subseteq B$ implies $B \setminus A \in \mathcal{L}$, and increasing unions of members belong to $\mathcal{L}$. **Dynkin's $\pi$–$\lambda$ theorem** (from P1): if $\mathcal{P} \subseteq \mathcal{L}$ with $\mathcal{P}$ a $\pi$-system and $\mathcal{L}$ a $\lambda$-system, then $\sigma(\mathcal{P}) \subseteq \mathcal{L}$.

**Theorem 2 (uniqueness).** If $P$ and $Q$ are probability measures on $(\Omega, \sigma(\mathcal{P}))$ with $\mathcal{P}$ a $\pi$-system and $P = Q$ on $\mathcal{P}$, then $P = Q$ on $\sigma(\mathcal{P})$.

*Proof.* Let $\mathcal{L} = \{A : P(A) = Q(A)\}$. It contains $\Omega$; if $A \subseteq B$ are in $\mathcal{L}$ then $P(B \setminus A) = P(B) - P(A) = Q(B \setminus A)$; and if $A_n \uparrow A$ with $A_n \in \mathcal{L}$, Theorem 1(a) gives $P(A) = \lim P(A_n) = \lim Q(A_n) = Q(A)$. So $\mathcal{L}$ is a $\lambda$-system containing $\mathcal{P}$, and the $\pi$–$\lambda$ theorem finishes. $\blacksquare$

Both hypotheses matter. On $\Omega = \{1,2,3,4\}$ the family $\{\{1,2\},\{1,3\}\}$ is not a $\pi$-system (the intersection $\{1\}$ is missing). The uniform measure and the measure with masses $(0, \tfrac12, \tfrac12, 0)$ agree on both sets but differ on $\{1\}$.

### Random variables and distribution functions

A *random variable* is a measurable $X\colon (\Omega, \mathcal{F}) \to (\mathbb{R}, \mathcal{B})$; its *law* is $\mu(B) = P(X \in B)$ and its *distribution function* is $F(x) = P(X \le x)$.

**Theorem 3.** $F$ is nondecreasing, right-continuous, with $F(-\infty) = 0$ and $F(+\infty) = 1$. Moreover $P(X = x) = F(x) - F(x-)$, and $F$ determines the law.

*Proof.* Monotonicity follows from monotonicity of $P$. If $x_n \downarrow x$ then $\{X \le x_n\} \downarrow \{X \le x\}$, so Theorem 1(b) gives right-continuity; the same argument with $x_n \downarrow -\infty$ (limit $\emptyset$) and $x_n \uparrow \infty$ (Theorem 1(a), limit $\Omega$) gives the limits. For $x_n \uparrow x$ the sets $\{X \le x_n\} \uparrow \{X < x\}$, so $F(x-) = P(X < x)$ and the atom formula follows. The half-lines $(-\infty, x]$ form a $\pi$-system generating $\mathcal{B}$, so Theorem 2 shows $F$ determines $\mu$. $\blacksquare$

**Theorem 4 (quantile transform).** Let $F$ be any function with the three properties of Theorem 3, let $G(u) = \inf\{x : F(x) \ge u\}$ for $u \in (0,1)$, and let $U$ be uniform on $(0,1)$. Then $G(U)$ has distribution function $F$.

*Proof.* We claim $G(u) \le x \iff u \le F(x)$. If $u \le F(x)$ then $x$ is in the set defining $G(u)$, so $G(u) \le x$. Conversely, the set $\{y : F(y) \ge u\}$ is an interval closed on the left by right-continuity, so $F(G(u)) \ge u$; if $G(u) \le x$ then $F(x) \ge F(G(u)) \ge u$. Hence $P(G(U) \le x) = P(U \le F(x)) = F(x)$. ($G$ is nondecreasing, hence Borel.) $\blacksquare$

So every distribution function is realized on $((0,1), \mathcal{B}, \text{Lebesgue})$, and simulation reduces to producing uniforms.

```python
import math
import random


def exp_quantile(u, rate):
    """Quantile function G(u) of the exponential law with this rate."""
    return -math.log(1 - u) / rate


def empirical_cdf(sample, x):
    """Fraction of the sample that is at most x."""
    return sum(1 for s in sample if s <= x) / len(sample)


rng = random.Random(7)
sample = [exp_quantile(rng.random(), 1.0) for _ in range(2000)]
print(abs(empirical_cdf(sample, 1.0) - (1 - math.exp(-1.0))) < 0.05)
```

This prints `True`; it illustrates Theorem 4 and proves nothing. On exams, expect to be asked to verify a $\pi$-system, to compute a law by a change of variables, or to prove one of Theorems 1–4.

@example
title: The law of a square
problem: Let $X$ be uniform on $[-1, 1]$ and $Y = X^2$. Find the distribution function and the density of $Y$.
step: $Y$ takes values in $[0, 1]$, so $F_Y(y) = 0$ for $y < 0$ and $F_Y(y) = 1$ for $y \ge 1$.
step: For $0 \le y < 1$, $\{Y \le y\} = \{-\sqrt{y} \le X \le \sqrt{y}\}$, so $F_Y(y) = P(-\sqrt{y} \le X \le \sqrt{y}) = \frac{2\sqrt{y}}{2} = \sqrt{y}$.
step: $F_Y$ is continuous, with no atoms, and is differentiable on $(0,1)$; differentiating gives $f_Y(y) = \frac{1}{2\sqrt{y}}$ for $0 < y < 1$.
step: Check: $\int_0^1 \frac{1}{2\sqrt{y}}\,dy = [\sqrt{y}]_0^1 = 1$, and the density is unbounded near $0$ even though $X$ has a bounded density.
answer: $F_Y(y) = \sqrt{y}$ on $[0,1]$ and $f_Y(y) = \frac{1}{2\sqrt{y}}$ on $(0,1)$.

@example
title: Finitely additive is not enough
problem: Let $\mathcal{A}$ be the family of subsets of $\mathbb{N}$ that are finite or have finite complement, and let $P(A) = 0$ if $A$ is finite and $P(A) = 1$ if $A$ is cofinite. Show that $\mathcal{A}$ is an algebra, $P$ is finitely additive, and $P$ is not countably additive.
step: $\mathcal{A}$ contains $\mathbb{N}$, is closed under complements by definition, and the union of two members is finite if both are, and cofinite otherwise. So it is an algebra.
step: If $A, B$ are disjoint members, at most one of them is cofinite (two cofinite sets intersect). If both are finite then $A \cup B$ is finite and $P(A \cup B) = 0 = P(A) + P(B)$; if $A$ is cofinite then $B \subseteq A^c$ is finite and $P(A \cup B) = 1 = P(A) + P(B)$.
step: The singletons $\{n\}$ are disjoint, each has $P(\{n\}) = 0$, and their union $\mathbb{N}$ has $P(\mathbb{N}) = 1 \ne 0 = \sum_n P(\{n\})$. So countable additivity fails.
step: Equivalently, $A_n = \{n, n+1, \dots\} \downarrow \emptyset$ yet $P(A_n) = 1$ for all $n$: continuity from above fails. Also $\mathcal{A}$ is not a $\sigma$-algebra: the union of all singletons $\{2k\}$ is neither finite nor cofinite.
answer: $P$ is finitely additive on the algebra $\mathcal{A}$ but not countably additive.

@mistakes
- Treating a distribution function as left-continuous: $F(x) = P(X \le x)$ is right-continuous, and $P(X = x) = F(x) - F(x-)$, not $F(x) - F(x+)$.
- Applying continuity from above to a measure that is not finite: it needs $P(A_1) < \infty$.
- Claiming that two measures agreeing on a generating family agree everywhere without checking that the family is a $\pi$-system.
- Differentiating $F_Y$ to get a density without checking that $F_Y$ is absolutely continuous; a distribution function can have jumps or be singular continuous.

@practice ms
prompt: Let $X$ be a real random variable with distribution function $F$. Which statements are true for every such $F$?
choice*: $F$ is nondecreasing.
choice*: $F$ is right-continuous at every point.

model:
```python
from fractions import Fraction


def quantile(values, probs, u):
    """Smallest x with F(x) >= u for a discrete law."""
    total = Fraction(0)
    for x, p in zip(values, probs):
        total += p
        if total >= u:
            return x
    return values[-1]
```
hint: Accumulate the probabilities in order and stop at the first value where the running total is at least $u$.
hint: Use `>=`, not `>`: at $u = F(x_j)$ exactly, the infimum is $x_j$ because $F(x_j) \ge u$.
solution: The distribution function is the running total of the probabilities, and the infimum over $\{x : F(x) \ge u\}$ is attained at the first atom whose running total reaches $u$ (right-continuity makes the infimum a minimum). Using exact `Fraction` arithmetic keeps the boundary case $u = F(x_j)$ correct; a strict inequality returns the next atom there.

@practice self
prompt: Let $\mathcal{A}$ be an algebra of subsets of $\Omega$ and let $P\colon \mathcal{A} \to [0,1]$ be finitely additive with $P(\Omega) = 1$. Suppose that $P(A_n) \to 0$ whenever $A_n \in \mathcal{A}$ and $A_n \downarrow \emptyset$. Prove that $P$ is countably additive on $\mathcal{A}$: if $B_1, B_2, \dots \in \mathcal{A}$ are pairwise disjoint and $B = \bigcup_i B_i \in \mathcal{A}$, then $P(B) = \sum_i P(B_i)$.
hint: Look at the remainders $A_n = B \setminus (B_1 \cup \dots \cup B_n)$.
hint: Use finite additivity to write $P(B) = \sum_{i \le n} P(B_i) + P(A_n)$ and let $n \to \infty$.
solution: Let $A_n = B \setminus (B_1 \cup \dots \cup B_n)$. Each $A_n$ lies in $\mathcal{A}$ because $\mathcal{A}$ is an algebra, $A_{n+1} \subseteq A_n$, and $\bigcap_n A_n = \emptyset$: a point of $B$ lies in exactly one $B_i$ and is removed from $A_n$ for $n \ge i$. So $A_n \downarrow \emptyset$ and $P(A_n) \to 0$ by hypothesis. Since $B$ is the disjoint union of $B_1, \dots, B_n, A_n$, finite additivity gives $P(B) = \sum_{i=1}^n P(B_i) + P(A_n)$. Letting $n \to \infty$ gives $P(B) = \sum_{i=1}^\infty P(B_i)$. $\blacksquare$
rubric: Defines the remainder sets $A_n$ and shows they decrease to the empty set (pointwise argument).
rubric: Uses finite additivity on the partition $B_1, \dots, B_n, A_n$ of $B$.
rubric: Passes to the limit using the continuity hypothesis, and concludes countable additivity.

@quiz mc
prompt: Two probability measures $P$ and $Q$ on $(\Omega, \mathcal{F})$ agree on a family $\mathcal{C}$ of sets with $\sigma(\mathcal{C}) = \mathcal{F}$. Which additional hypothesis on $\mathcal{C}$ guarantees $P = Q$?
choice*: $\mathcal{C}$ is closed under finite intersections.
choice: $\mathcal{C}$ is closed under finite unions only.
choice: $\mathcal{C}$ is countable.
choice: $\mathcal{C}$ contains every singleton.
hint: Recall which family the uniqueness proof starts from.
solution: Closure under finite intersections (a $\pi$-system) is the hypothesis of the uniqueness theorem. Closure under unions alone does not suffice, and neither does countability or containing the singletons: on $\{1,2,3,4\}$ the two-set family $\{\{1,2\},\{1,3\}\}$ is a counterexample to a family without intersections, and singletons would be useless on $\mathbb{R}$, where they generate only the countable/co-countable sets.

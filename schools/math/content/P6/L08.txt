@article
A gambler plays a fair game. Whatever rule decides how much to stake and when to quit, the expected fortune stays the same: no strategy beats a fair game. Martingale theory makes this precise, and it is the main technical tool for the rest of the course. Martingales are conditional expectations over time, so this week builds directly on conditional expectation.

### Definitions

A **filtration** is an increasing sequence of $\sigma$-algebras $\mathcal{F}_0 \subseteq \mathcal{F}_1 \subseteq \dots \subseteq \mathcal{F}$. A process $(X_n)$ is **adapted** if $X_n$ is $\mathcal{F}_n$-measurable. It is a **martingale** if it is adapted, each $X_n$ is integrable, and $\mathbb{E}[X_{n+1} \mid \mathcal{F}_n] = X_n$ almost surely; a **submartingale** if $\mathbb{E}[X_{n+1} \mid \mathcal{F}_n] \ge X_n$; a **supermartingale** if $\le$. A martingale is the fortune in a fair game, a submartingale in a favorable game.

**Examples.**
1. If $\xi_k$ are independent with $\mathbb{E}\xi_k = 0$, then $S_n = \xi_1 + \dots + \xi_n$ is a martingale for $\mathcal{F}_n = \sigma(\xi_1, \dots, \xi_n)$.
2. If $\xi_k$ are independent with $\mathbb{E}\xi_k = 0$ and $\mathbb{E}\xi_k^2 = 1$, then $S_n^2 - n$ is a martingale.
3. If $m(\theta) = \mathbb{E}e^{\theta\xi} < \infty$ for i.i.d. $\xi_k$, then $e^{\theta S_n}/m(\theta)^n$ is a positive martingale.
4. Products $\prod_{k \le n}\eta_k$ of independent nonnegative variables with $\mathbb{E}\eta_k = 1$.
5. **Doob's martingale** $X_n = \mathbb{E}[Y \mid \mathcal{F}_n]$ for an integrable $Y$; the tower property gives the martingale property.
6. **Pólya's urn.** An urn holds $r$ red and $b$ blue balls; draw a ball, return it with one more of the same color. If $R_n$ is the number of red balls after $n$ draws (total $T_n = r + b + n$) then $M_n = R_n/T_n$ is a martingale, since
$$\mathbb{E}[M_{n+1} \mid \mathcal{F}_n] = \frac{R_n}{T_n}\cdot\frac{R_n + 1}{T_n + 1} + \frac{T_n - R_n}{T_n}\cdot\frac{R_n}{T_n + 1} = \frac{R_n(T_n + 1)}{T_n(T_n + 1)} = M_n.$$

By conditional Jensen, if $M$ is a martingale and $\varphi$ is convex with $\varphi(M_n)$ integrable, then $\varphi(M_n)$ is a submartingale; examples are $|M_n|$ and $M_n^2$. Equal expectations are necessary but far from sufficient:

```python
from fractions import Fraction
from itertools import product


def mean_over_paths(n, f):
    """Average of f(steps) over all 2**n equally likely +-1 paths."""
    total = Fraction(0)
    for steps in product((1, -1), repeat=n):
        total += f(steps)
    return total / 2 ** n


print([mean_over_paths(n, lambda st: sum(st) ** 2 - len(st))
       for n in range(1, 7)])
print(mean_over_paths(5, lambda st: sum(st) ** 3))
```

The first line prints six zeros (as it must for the martingale $S_n^2 - n$), and the second prints `0` as well, yet $S_n^3$ is not a martingale: $\mathbb{E}[S_{n+1}^3 \mid S_n] = S_n^3 + 3S_n$.

### Stopping times

A **stopping time** is a map $\tau\colon \Omega \to \{0, 1, 2, \dots\} \cup \{\infty\}$ with $\{\tau \le n\} \in \mathcal{F}_n$ for all $n$: the decision to stop by time $n$ uses only information up to $n$. The first time a process enters a Borel set is a stopping time; the last time it visits a set before a horizon is not (one would have to know the future). The **stopped process** is $X_n^\tau = X_{n \wedge \tau}$.

**Theorem 1 (martingale transform).** Let $(X_n)$ be a martingale and $(H_n)_{n \ge 1}$ a *predictable* process (each $H_n$ is $\mathcal{F}_{n-1}$-measurable) with $|H_n| \le K_n < \infty$ for constants $K_n$. Then $(H \cdot X)_n = \sum_{k=1}^n H_k(X_k - X_{k-1})$ is a martingale. If $X$ is a submartingale and $H_n \ge 0$, then $H \cdot X$ is a submartingale.

*Proof.* $H \cdot X$ is adapted and integrable, because $|H_k| \le K_k$ and $X_k$ is integrable. Since $H_{n+1}$ is $\mathcal{F}_n$-measurable and $H_{n+1}(X_{n+1} - X_n)$ is integrable, taking out what is known gives $\mathbb{E}[(H\cdot X)_{n+1} - (H \cdot X)_n \mid \mathcal{F}_n] = H_{n+1}\,\mathbb{E}[X_{n+1} - X_n \mid \mathcal{F}_n] = 0$ (and $\ge 0$ in the submartingale case with $H_{n+1} \ge 0$). $\blacksquare$

The boundedness of $H$ is what makes the strategy realistic; the doubling strategy $H_n = 2^{n-1}$ is bounded at each fixed $n$ but its cumulative effect is the subject of next week.

**Corollary 2 (stopped martingales).** If $X$ is a martingale and $\tau$ a stopping time, then $X^\tau$ is a martingale; it is a submartingale if $X$ is.

*Proof.* Let $H_k = \mathbf{1}_{\{\tau \ge k\}} = 1 - \mathbf{1}_{\{\tau \le k-1\}}$. It is $\mathcal{F}_{k-1}$-measurable, with values in $\{0,1\}$, and $(H \cdot X)_n = X_{n \wedge \tau} - X_0$. Apply Theorem 1 and add the integrable constant $X_0$. $\blacksquare$

In particular $\mathbb{E}X_{n \wedge \tau} = \mathbb{E}X_0$ for every $n$. Passing to the limit $n \to \infty$ is not automatic, and that is next week's topic.

### Doob decomposition and the maximal inequality

**Theorem 3 (Doob decomposition).** A submartingale $X$ can be written uniquely as $X_n = M_n + A_n$ with $M$ a martingale, $A_0 = 0$, and $A$ predictable and nondecreasing.

*Proof.* Put $A_n = \sum_{k=1}^n \mathbb{E}[X_k - X_{k-1} \mid \mathcal{F}_{k-1}]$, which is predictable, integrable and nondecreasing since each term is $\ge 0$, and $M_n = X_n - A_n$. Then $\mathbb{E}[M_{n+1} - M_n \mid \mathcal{F}_n] = \mathbb{E}[X_{n+1} - X_n \mid \mathcal{F}_n] - (A_{n+1} - A_n) = 0$. For uniqueness, if $M + A = M' + A'$ then $D = M - M' = A' - A$ is a predictable martingale: $D_{n} = \mathbb{E}[D_{n} \mid \mathcal{F}_{n-1}] = D_{n-1}$, and $D_0 = 0$. $\blacksquare$

**Theorem 4 (Doob's maximal inequality; the proof is a qualifying-exam exercise, set below).** If $X$ is a nonnegative submartingale, then for $\lambda > 0$, $\lambda\,P\bigl(\max_{k \le n}X_k \ge \lambda\bigr) \le \mathbb{E}\bigl[X_n;\ \max_{k \le n}X_k \ge \lambda\bigr] \le \mathbb{E}X_n$.

@example
title: A walk's square, shifted
problem: Let $S_n$ be the simple symmetric random walk ($\xi_k = \pm 1$ with probability $\frac12$ each, $S_0 = 0$) and $\mathcal{F}_n = \sigma(\xi_1, \dots, \xi_n)$. Show that $S_n^2 - n$ is a martingale and find the Doob decomposition of $S_n^2$.
step: $S_n^2 - n$ is adapted and integrable (bounded by $n^2 + n$).
step: Write $S_{n+1} = S_n + \xi_{n+1}$ with $\xi_{n+1}$ independent of $\mathcal{F}_n$. Then $\mathbb{E}[S_{n+1}^2 \mid \mathcal{F}_n] = S_n^2 + 2S_n\,\mathbb{E}[\xi_{n+1}] + \mathbb{E}[\xi_{n+1}^2] = S_n^2 + 1$, using that $S_n$ is $\mathcal{F}_n$-measurable.
step: Hence $\mathbb{E}[S_{n+1}^2 - (n+1) \mid \mathcal{F}_n] = S_n^2 - n$, the martingale property.
step: So $S_n^2$ is a submartingale with decomposition $M_n = S_n^2 - n$ and $A_n = n$ (predictable, nondecreasing, $A_0 = 0$); by uniqueness this is the Doob decomposition.
answer: $S_n^2 = (S_n^2 - n) + n$.

@example
title: The absolute value of a walk
problem: For the simple symmetric random walk, find the compensator $A_n$ in the Doob decomposition of the submartingale $|S_n|$.
step: $|S_n|$ is a submartingale: it is the convex function $|\cdot|$ of a martingale.
step: If $S_n \ne 0$, then $S_n \pm 1$ have the same sign as $S_n$, so $\mathbb{E}[|S_{n+1}| \mid \mathcal{F}_n] = \frac12(|S_n| + 1) + \frac12(|S_n| - 1) = |S_n|$.
step: If $S_n = 0$, then $|S_{n+1}| = 1$, so $\mathbb{E}[|S_{n+1}| \mid \mathcal{F}_n] = 1 = |S_n| + 1$.
step: Thus $\mathbb{E}[|S_{n+1}| - |S_n| \mid \mathcal{F}_n] = \mathbf{1}_{\{S_n = 0\}}$ and $A_n = \sum_{k=0}^{n-1}\mathbf{1}_{\{S_k = 0\}}$, the number of visits to $0$ strictly before time $n$.
answer: $A_n = \#\{k < n : S_k = 0\}$, and $|S_n| - A_n$ is a martingale.

@mistakes
- Checking only $\mathbb{E}X_n = \mathbb{E}X_0$: the martingale property is a conditional statement for every $n$, and processes such as $S_n^3$ have constant mean without being martingales.
- Calling a time that looks ahead a stopping time, such as the last visit to $0$ before time $100$ or "one step before the first hitting time".
- Forgetting that the process must be adapted and integrable; the conditional statement is meaningless without integrability.
- Using a non-predictable $H_n$ in a transform: a strategy that depends on the next increment can beat a fair game.

@practice self
prompt: Prove Doob's maximal inequality: if $(X_k)_{k \le n}$ is a nonnegative submartingale and $\lambda > 0$, then $\lambda\,P\bigl(\max_{k \le n}X_k \ge \lambda\bigr) \le \mathbb{E}\bigl[X_n;\ \max_{k \le n}X_k \ge \lambda\bigr] \le \mathbb{E}X_n$.
hint: Let $\tau$ be the first $k \le n$ with $X_k \ge \lambda$, and decompose the event $\{\max_{k \le n}X_k \ge \lambda\}$ according to the value of $\tau$.
hint: On $\{\tau = k\}$ use the submartingale property to compare $\mathbb{E}[X_n;\ \tau = k]$ with $\mathbb{E}[X_k;\ \tau = k]$.
solution: Let $A = \{\max_{k \le n}X_k \ge \lambda\}$ and $\tau = \min\{k \le n : X_k \ge \lambda\}$ on $A$. The events $A_k = \{\tau = k\} = \{X_j < \lambda,\ j < k;\ X_k \ge \lambda\}$ belong to $\mathcal{F}_k$ and partition $A$. Since $X$ is a submartingale and $A_k \in \mathcal{F}_k$, $\mathbb{E}[X_n;\ A_k] \ge \mathbb{E}[X_k;\ A_k] \ge \lambda\,P(A_k)$, using the defining property of conditional expectation and $X_k \ge \lambda$ on $A_k$. Summing over $k$, $\mathbb{E}[X_n;\ A] \ge \lambda\,P(A)$. Finally $\mathbb{E}[X_n;\ A] \le \mathbb{E}X_n$ because $X_n \ge 0$. $\blacksquare$
rubric: Defines the first-passage index $\tau$ and shows the events $\{\tau = k\}$ are in $\mathcal{F}_k$ and partition the maximal event.
rubric: Uses the submartingale inequality $\mathbb{E}[X_n; A_k] \ge \mathbb{E}[X_k; A_k]$ for $A_k \in \mathcal{F}_k$ and the bound $X_k \ge \lambda$ on $A_k$.
rubric: Sums over $k$ and uses $X_n \ge 0$ for the last inequality.

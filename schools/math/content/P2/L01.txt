@article
A qualifying exam asks: "Show that no group of order 56 is simple." No structure of the group is given, only its order. The tool is a group action: if you can make $G$ permute a small set, or permute its own subgroups, you get homomorphisms and counts that force normal subgroups to exist.

### Actions, orbits, stabilizers

A (left) **action** of a group $G$ on a set $X$ is a map $G \times X \to X$ with $1\cdot x = x$ and $g\cdot(h\cdot x) = (gh)\cdot x$. Equivalently it is a homomorphism $G \to \mathrm{Sym}(X)$, whose kernel is the set of elements acting trivially. The **orbit** of $x$ is $Gx$, the **stabilizer** is $G_x = \{g : gx = x\}$.

**Theorem (orbit–stabilizer).** For a group $G$ acting on a set $X$ and $x \in X$, the map $gG_x \mapsto gx$ is a well-defined bijection $G/G_x \to Gx$. Hence $|Gx| = [G:G_x]$, and if $G$ is finite then $|Gx|$ divides $|G|$.

*Proof.* $gx = hx$ if and only if $h^{-1}g \in G_x$ if and only if $gG_x = hG_x$, so the map is well defined and injective; it is onto $Gx$ by definition. $\blacksquare$

Orbits partition $X$. Let $G$ be finite and act on itself by conjugation: orbits are conjugacy classes, stabilizers are centralizers, and the partition of $|G|$ gives the **class equation** $|G| = |Z(G)| + \sum_i [G : C_G(x_i)]$, the sum over representatives $x_i$ of the classes with more than one element.

**Burnside's lemma.** If a finite group $G$ acts on a finite set $X$, the number of orbits is $\frac{1}{|G|}\sum_{g\in G} |\mathrm{Fix}(g)|$. *Proof.* Count the pairs $(g,x)$ with $gx = x$ in two ways: $\sum_g |\mathrm{Fix}(g)| = \sum_x |G_x| = \sum_x |G|/|Gx|$, and each orbit contributes $|Gx|\cdot |G|/|Gx| = |G|$. $\blacksquare$

### The Sylow theorems

**Theorem (Sylow).** Let $G$ be a finite group, $p$ a prime, and $|G| = p^a m$ with $p \nmid m$. A **Sylow $p$-subgroup** is a subgroup of order $p^a$.
1. A Sylow $p$-subgroup exists.
2. Every $p$-subgroup of $G$ lies in a Sylow $p$-subgroup, and any two Sylow $p$-subgroups are conjugate.
3. The number $n_p$ of Sylow $p$-subgroups equals $[G:N_G(P)]$ for any Sylow $P$, divides $m$, and satisfies $n_p \equiv 1 \pmod p$.

*Proof of 1.* Induct on $|G|$; we use Cauchy's theorem for abelian groups, recalled from C11 without proof here. If $a = 0$ take the trivial subgroup. Let $a \ge 1$. If $p$ divides $|Z(G)|$, pick $z \in Z(G)$ of order $p$; $G/\langle z\rangle$ has order $p^{a-1}m$, so by induction has a subgroup of order $p^{a-1}$, whose preimage has order $p^a$. If $p \nmid |Z(G)|$, the class equation shows some $[G:C_G(x_i)]$ is not divisible by $p$, with $x_i \notin Z(G)$; then $C = C_G(x_i) \ne G$ and $p^a$ divides $|C|$, so by induction $C$ has a subgroup of order $p^a$. $\blacksquare$

*Proof of 2.* Let $P$ be Sylow and $Q$ a $p$-subgroup. $Q$ acts on $G/P$ by left multiplication. Orbit sizes are powers of $p$ and $|G/P| = m$ is prime to $p$, so some orbit has size $1$: $qgP = gP$ for all $q \in Q$, i.e. $g^{-1}Qg \subseteq P$. If $Q$ is also Sylow, orders force $Q = gPg^{-1}$. $\blacksquare$

*Proof of 3.* By 2 and orbit–stabilizer for conjugation, $n_p = [G:N_G(P)]$, which divides $[G:P] = m$ since $P \subseteq N_G(P)$. Let $P$ act by conjugation on the set of Sylow $p$-subgroups. A fixed point $Q$ means $P \subseteq N_G(Q)$. Then $P$ and $Q$ are both Sylow in $N_G(Q)$, and $Q$ is normal there, so by 2 applied to $N_G(Q)$, $P = Q$. So $P$ is the only fixed point, every other orbit has size a positive power of $p$, and $n_p \equiv 1 \pmod p$. $\blacksquare$

### How exam problems use this

1. List the numbers allowed by $n_p \mid m$ and $n_p \equiv 1 \pmod p$. If one value is $1$, the Sylow subgroup is normal.
2. If $n_p > 1$, different Sylow $p$-subgroups of prime order meet trivially, so count elements.
3. If $n_p = k$ is small, conjugation on the Sylow subgroups gives a homomorphism $G \to S_k$; it is nontrivial because the action is transitive (part 2), so its kernel is a proper normal subgroup, and it is nontrivial when $|G| > k!$.

The code below counts orbits on a set of colorings, using the representation of a permutation of $\{0,\dots,n-1\}$ as a list `p` with `p[i]` the image of `i`.

```python
from itertools import product


def orbit(x, gens):
    """Orbit of x under the finite group generated by the permutations gens."""
    seen = {x}
    stack = [x]
    while stack:
        y = stack.pop()
        for g in gens:
            z = g[y]
            if z not in seen:
                seen.add(z)
                stack.append(z)
    return seen


rot = [1, 2, 3, 0]                      # rotation of 4 beads
colorings = list(product([0, 1], repeat=4))
# act on colorings: c -> (c[rot[0]], ..., c[rot[3]])
act = [tuple(c[rot[i]] for i in range(4)) for c in colorings]
index = {c: k for k, c in enumerate(colorings)}
perm = [index[a] for a in act]          # a permutation of the 16 colorings
print(len({frozenset(orbit(k, [perm])) for k in range(16)}))
```

This prints `6`, matching $\frac{1}{4}(16 + 2 + 4 + 2)$ from Burnside's lemma. It illustrates the lemma on one case; the lemma itself is proved above.
@example
title: No group of order 56 is simple
problem: Prove that a group $G$ of order $56$ has a normal Sylow subgroup, so is not simple.
step: Factor $56 = 2^3\cdot 7$. By Sylow 3, $n_7 \mid 8$ and $n_7 \equiv 1 \pmod 7$, so $n_7 \in \{1, 8\}$. If $n_7 = 1$ the Sylow $7$-subgroup is normal and we are done.
step: Suppose $n_7 = 8$. Two distinct subgroups of order $7$ intersect in a subgroup of order dividing $7$ that is not $7$, so trivially. Each has $6$ elements of order $7$, so $G$ has $8\cdot 6 = 48$ elements of order $7$.
step: That leaves $56 - 48 = 8$ elements. A Sylow $2$-subgroup has order $8$ and contains no element of order $7$, so it consists of exactly these $8$ elements.
step: Hence there is only one Sylow $2$-subgroup, so $n_2 = 1$ and it is normal (it is the unique conjugate of itself). In both cases $G$ has a proper nontrivial normal subgroup.
answer: Either $n_7 = 1$ or $n_2 = 1$, so a group of order $56$ is never simple.
@example
title: Orders with two competing counts
problem: Prove that a group $G$ of order $105$ has a normal Sylow $5$-subgroup or a normal Sylow $7$-subgroup.
step: Factor $105 = 3\cdot 5\cdot 7$. Sylow 3 gives $n_5 \mid 21$ with $n_5 \equiv 1 \pmod 5$, so $n_5 \in \{1, 21\}$, and $n_7 \mid 15$ with $n_7 \equiv 1 \pmod 7$, so $n_7 \in \{1, 15\}$.
step: Suppose both are larger than $1$, so $n_5 = 21$ and $n_7 = 15$. Subgroups of prime order $5$ or $7$ meet trivially.
step: Then $G$ has $21\cdot 4 = 84$ elements of order $5$ and $15 \cdot 6 = 90$ elements of order $7$, in total $174 > 105$, a contradiction.
step: So $n_5 = 1$ or $n_7 = 1$, and the corresponding Sylow subgroup is normal.
answer: At least one of the Sylow $5$- and $7$-subgroups is normal.
@mistakes
- Claiming $n_p$ can be any divisor of $|G|$: it must divide $m = |G|/p^a$ and be $\equiv 1 \pmod p$. For $|G| = 12$, $n_3 = 2$ is excluded by the congruence.
- Concluding that a Sylow subgroup is normal when the count allows $n_p = 1$: the count only says it might be. Normality needs $n_p = 1$ to be forced.
- Counting elements of order $p$ when the Sylow subgroups have order $p^2$ or more: distinct Sylow subgroups can intersect nontrivially, so the disjointness argument works only for subgroups of prime order.
- Using the action on Sylow subgroups without checking $|G| > k!$: the kernel is nontrivial only if the image in $S_k$ is too small to be all of $G$.

model:
```python
def class_sizes(gens, n):
    """Sorted conjugacy class sizes of the group generated by gens."""
    def mul(g, h):
        return tuple(g[h[i]] for i in range(n))

    def inverse(g):
        r = [0] * n
        for i, x in enumerate(g):
            r[x] = i
        return tuple(r)

    identity = tuple(range(n))
    group = {identity}
    frontier = [identity]
    gens = [tuple(g) for g in gens]
    while frontier:
        new = []
        for x in frontier:
            for g in gens:
                y = mul(g, x)
                if y not in group:
                    group.add(y)
                    new.append(y)
        frontier = new
    seen = set()
    sizes = []
    for x in group:
        if x in seen:
            continue
        cls = {mul(mul(g, x), inverse(g)) for g in group}
        seen |= cls
        sizes.append(len(cls))
    return sorted(sizes)
```
hint: First generate all elements by multiplying by the generators until nothing new appears.
hint: The class of `x` is the orbit of `x` under conjugation `g x g^-1` for `g` in the group.
solution: Generate the group by a breadth-first closure, then partition it into conjugacy classes (the orbits of conjugation), skipping elements already placed in a class. Using only the generators to conjugate would give a union of generator-orbits that need not be a full class; here the full group is used. The sizes divide the group order and sum to it, as the class equation requires.
@practice self
prompt: Prove that no group of order $36$ is simple.
hint: Count the Sylow $3$-subgroups: which values of $n_3$ are allowed?
hint: If $n_3 \ne 1$, let $G$ act on the set of Sylow $3$-subgroups by conjugation and compare $|G|$ with the order of the symmetric group of that set.
solution: Suppose $G$ is simple of order $36 = 2^2\cdot 3^2$. An abelian simple group has prime order, so $G$ is nonabelian and has no normal subgroup other than $1$ and $G$. By Sylow 3, $n_3 \mid 4$ and $n_3 \equiv 1 \pmod 3$, so $n_3 \in \{1, 4\}$. If $n_3 = 1$, the Sylow $3$-subgroup, of order $9$, is a proper nontrivial normal subgroup, a contradiction. So $n_3 = 4$. Let $G$ act by conjugation on the four Sylow $3$-subgroups, giving a homomorphism $\varphi\colon G \to S_4$. By Sylow 2 the action is transitive, so $\varphi$ is not trivial and $\ker\varphi \ne G$. Since $|G| = 36 > 24 = |S_4|$, $\varphi$ is not injective, so $\ker\varphi \ne 1$. Thus $\ker\varphi$ is a proper nontrivial normal subgroup, contradicting simplicity. $\blacksquare$
rubric: Rules out abelian groups or otherwise uses the definition of simple correctly, and finds $n_3 \in \{1,4\}$ using both divisibility and the congruence.
rubric: Handles $n_3 = 1$ by observing that the Sylow subgroup is normal, proper and nontrivial.
rubric: For $n_3 = 4$ builds the homomorphism to $S_4$, shows the kernel is not all of $G$ (nontrivial action by transitivity) and not trivial (order comparison $36 > 24$).

@quiz ms
prompt: A finite group $G$ acts transitively on a finite set $X$ with $|X| = n$. Which statements are true?
choice*: $n$ divides $|G|$.
choice*: All stabilizers $G_x$ are conjugate subgroups of $G$.
choice*: The kernel of the action is the intersection of all stabilizers $G_x$.
choice: The action is faithful, meaning the homomorphism $G \to \mathrm{Sym}(X)$ is injective.
choice: Each stabilizer $G_x$ is a normal subgroup of $G$.
hint: Use orbit–stabilizer, and test the false statements on $S_3$ acting on three points and on the trivial action of a cyclic group.
solution: Transitivity gives $|X| = |Gx| = [G:G_x]$, which divides $|G|$. If $y = gx$ then $G_y = gG_xg^{-1}$. An element acts trivially exactly when it fixes every point, so the kernel is $\bigcap_x G_x$. Faithfulness fails for the action of $\mathbb{Z}/4$ on $\mathbb{Z}/2$ by $g\cdot x = g + x \bmod 2$, which is transitive with kernel $2\mathbb{Z}/4\mathbb{Z}$. Stabilizers need not be normal: in $S_3$ acting on three points, the stabilizer of a point has order $2$ and is not normal.

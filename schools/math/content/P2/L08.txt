@article
Why is $\mathbb{Z}/2\otimes\mathbb{Z}/3=0$, while $\mathbb{R}^2\otimes\mathbb{R}^3$ has dimension $6$? A tensor product converts bilinear maps into linear ones, and what survives depends on the ring. Throughout, $R$ is a commutative ring.

### Definition and universal property

Let $M,N$ be $R$-modules. A map $\beta\colon M\times N\to P$ is **bilinear** if it is $R$-linear in each variable. The **tensor product** $M\otimes_R N$ is an $R$-module with a bilinear map $\otimes\colon (m,n)\mapsto m\otimes n$ such that every bilinear $\beta\colon M\times N\to P$ factors as $\beta=\tilde\beta\circ\otimes$ for a unique linear $\tilde\beta\colon M\otimes N\to P$. It exists: take the free module on the set $M\times N$ modulo the submodule generated by the bilinearity relations, such as $(m+m',n)-(m,n)-(m',n)$ and $(rm,n)-r(m,n)$. It is unique up to unique isomorphism, and it is generated by the **pure tensors** $m\otimes n$. Not every element is pure, and $m\otimes n=0$ can happen with $m,n\ne0$.

**Rules.** $M\otimes N\cong N\otimes M$; $M\otimes(N\oplus P)\cong(M\otimes N)\oplus(M\otimes P)$; $R\otimes M\cong M$; and if $M,N$ are free with bases $(e_i)$ and $(f_j)$, then $M\otimes N$ is free with basis $(e_i\otimes f_j)$. For vector spaces $\dim(V\otimes W)=\dim V\cdot\dim W$.

**Functoriality.** Linear maps $f\colon M\to M'$ and $g\colon N\to N'$ give $f\otimes g\colon m\otimes n\mapsto f(m)\otimes g(n)$ (well defined by the universal property). If $f,g$ have matrices $A$ ($n\times n$) and $B$ ($m\times m$) in the bases $(e_i)$, $(f_j)$, then in the basis $e_i\otimes f_j$ ordered lexicographically $f\otimes g$ has the **Kronecker product** matrix $A\otimes B=(a_{ij}B)$, and
$$\det(A\otimes B)=\det(A)^m\det(B)^n.$$
*Proof.* $A\otimes B=(A\otimes I_m)(I_n\otimes B)$. The matrix $I_n\otimes B$ is block diagonal with $n$ copies of $B$, so has determinant $\det(B)^n$. After reordering the basis the matrix $A\otimes I_m$ becomes block diagonal with $m$ copies of $A$ (the same permutation on both sides, so the determinant is unchanged), so it has determinant $\det(A)^m$. $\blacksquare$

### Right exactness and flatness

**Theorem.** If $A'\xrightarrow{f}A\xrightarrow{g}A''\to0$ is exact, so is $M\otimes A'\to M\otimes A\to M\otimes A''\to0$.

*Proof.* The map $1\otimes g$ is onto since pure tensors $m\otimes a''=(1\otimes g)(m\otimes a)$ generate. The composite is $0$. Let $Q$ be the cokernel of $1\otimes f$. The map $M\times A''\to Q$, $(m,a'')\mapsto[m\otimes a]$ for any $a$ with $g(a)=a''$, is well defined, because two choices differ by $f(a')$ and $m\otimes f(a')$ is in the image of $1\otimes f$; it is bilinear, so induces $M\otimes A''\to Q$ inverse to the map $Q\to M\otimes A''$ induced by $1\otimes g$. Hence $\ker(1\otimes g)=\mathrm{im}(1\otimes f)$. $\blacksquare$

Tensoring need not preserve injections: multiplication by $2$ is injective on $\mathbb{Z}$, but $\mathbb{Z}/2\otimes\mathbb{Z}\xrightarrow{1\otimes 2}\mathbb{Z}/2\otimes\mathbb{Z}$ is the zero map on $\mathbb{Z}/2\neq0$. $M$ is **flat** if $M\otimes-$ preserves injections; free modules and $\mathbb{Q}$ over $\mathbb{Z}$ are flat, $\mathbb{Z}/2$ is not.

**Theorem.** For an ideal $I$, $R/I\otimes_RM\cong M/IM$.

*Proof.* The map $(r+I,m)\mapsto rm+IM$ is well defined and bilinear, so gives $\phi\colon R/I\otimes M\to M/IM$. The map $m\mapsto 1\otimes m$ sends $IM$ to $0$ (for $a\in I$, the class $\bar1=1+I$ gives $\bar1\otimes am=\bar a\otimes m=0$, because $\bar a=0$ in $R/I$), so induces $\psi\colon M/IM\to R/I\otimes M$. On generators $\phi(r\otimes m)=rm$ and $\psi(rm)=1\otimes rm=r\otimes m$, so they are inverse. $\blacksquare$

**Consequences.** $\mathbb{Z}/m\otimes\mathbb{Z}/n\cong(\mathbb{Z}/n)/m(\mathbb{Z}/n)\cong\mathbb{Z}/\gcd(m,n)$. If $M$ is divisible and $N$ is torsion (abelian groups), $M\otimes_{\mathbb{Z}}N=0$: for $nb=0$ and $a=na'$, $a\otimes b=na'\otimes b=a'\otimes nb=0$. So $\mathbb{Q}\otimes\mathbb{Z}/n=0$ and $\mathbb{Q}/\mathbb{Z}\otimes\mathbb{Q}/\mathbb{Z}=0$.

### How exam problems use tensor products

Three patterns recur. To compute $M\otimes N$ for cyclic or finitely presented modules, reduce to $M/IM$ with the formula above, or tensor a presentation of $M$ with $N$ using right exactness. To show a tensor product is zero, write each generator $a\otimes b$ as $na'\otimes b=a'\otimes nb$ and use that $nb=0$. To show a map out of $M\otimes N$ is well defined, define a bilinear map on $M\times N$ first; defining it on pure tensors alone proves nothing, because the same element can be written as a pure tensor in many ways.

### Base change and a computation

For a ring homomorphism $R\to S$ and an $R$-module $M$, $S\otimes_RM$ is an $S$-module (**base change**); $S\otimes_RR[x]/(f)\cong S[x]/(f)$. The code builds Kronecker products.

```python
def kron(A, B):
    """Kronecker product of two matrices given as lists of rows."""
    return [[a * b for a in row_a for b in row_b]
            for row_a in A for row_b in B]


K = kron([[1, 1], [0, 1]], [[2, 0], [1, 3]])
for row in K:
    print(row)
```

The output is the $4\times4$ matrix with rows `[2, 0, 2, 0]`, `[1, 3, 1, 3]`, `[0, 0, 2, 0]`, `[0, 0, 1, 3]`; its determinant is $1^2\cdot6^2=36$, as the formula predicts.
@example
title: Z/12 tensor Z/18
problem: Compute $\mathbb{Z}/12\otimes_{\mathbb{Z}}\mathbb{Z}/18$ and exhibit a generator.
step: Apply $R/I\otimes M\cong M/IM$ with $R=\mathbb{Z}$, $I=12\mathbb{Z}$ and $M=\mathbb{Z}/18$. Then the tensor product is $(\mathbb{Z}/18)/12(\mathbb{Z}/18)$.
step: Compute $12(\mathbb{Z}/18)$: the multiples $12x \bmod 18$ are $0,12,6$, the subgroup generated by $6$, of order $3$.
step: The quotient $(\mathbb{Z}/18)/\langle6\rangle$ has order $18/3=6$ and is cyclic (generated by the class of $1$), so it is $\mathbb{Z}/6$, which is $\mathbb{Z}/\gcd(12,18)$.
step: The isomorphism sends $1\otimes1\mapsto1$, so $1\otimes1$ generates, and $a\otimes b=ab\,(1\otimes1)$ is determined by $ab \bmod 6$.
answer: $\mathbb{Z}/12\otimes\mathbb{Z}/18\cong\mathbb{Z}/6$, generated by $1\otimes1$.
@example
title: The complex numbers tensored with themselves over the reals
problem: Show that $\mathbb{C}\otimes_{\mathbb{R}}\mathbb{C}\cong\mathbb{C}\times\mathbb{C}$ as rings.
step: As real vector spaces $\mathbb{C}\otimes_{\mathbb{R}}\mathbb{C}$ has dimension $2\cdot2=4$, with basis $1\otimes1$, $1\otimes i$, $i\otimes1$, $i\otimes i$. It is a ring with $(z\otimes w)(z'\otimes w')=zz'\otimes ww'$.
step: The map $(z,w)\mapsto(zw,\ z\overline w)$ from $\mathbb{C}\times\mathbb{C}$ to $\mathbb{C}\times\mathbb{C}$ is $\mathbb{R}$-bilinear, so induces an $\mathbb{R}$-linear $\Phi\colon\mathbb{C}\otimes\mathbb{C}\to\mathbb{C}\times\mathbb{C}$ with $\Phi(z\otimes w)=(zw,z\overline w)$. It is multiplicative on pure tensors, and $\Phi(1\otimes1)=(1,1)$, so $\Phi$ is a ring homomorphism.
step: Surjectivity: we show the image is everything. We have $\Phi(1\otimes1)=(1,1)$ and $\Phi(i\otimes i)=(-1,1)$, so $(1,0)$ and $(0,1)$ are in the image. Also $\Phi(1\otimes i)=(i,-i)$ and $\Phi(i\otimes 1)=(i,i)$, so $(i,0)$ and $(0,i)$ are in the image. The images span $\mathbb{C}\times\mathbb{C}$ over $\mathbb{R}$.
step: Hence $\Phi$ is a surjective linear map between real vector spaces of equal dimension, so bijective, and a ring isomorphism. (Equivalently $\mathbb{C}\otimes_{\mathbb{R}}\mathbb{R}[x]/(x^2+1)\cong\mathbb{C}[x]/((x-i)(x+i))\cong\mathbb{C}\times\mathbb{C}$ by the Chinese remainder theorem.)
answer: $\mathbb{C}\otimes_{\mathbb{R}}\mathbb{C}\cong\mathbb{C}\times\mathbb{C}$ via $z\otimes w\mapsto(zw,z\overline w)$.
@mistakes
- Assuming $m\otimes n=0$ forces $m=0$ or $n=0$. In $\mathbb{Z}/2\otimes\mathbb{Z}/3$ every pure tensor is $0$.
- Assuming every element of $M\otimes N$ is a pure tensor. In $\mathbb{R}^2\otimes\mathbb{R}^2$, $e_1\otimes e_1+e_2\otimes e_2$ is not of the form $u\otimes v$.
- Tensoring an injection and expecting an injection. Right exactness is all that holds in general; $\mathbb{Z}\xrightarrow{2}\mathbb{Z}$ tensored with $\mathbb{Z}/2$ is the zero map.
- Defining a map on $M\otimes N$ by its value on pure tensors without checking bilinearity of the formula in $(m,n)$. The universal property requires a bilinear map on $M\times N$.

model:
```python
def is_pure(t, m, n):
    """True if t, viewed as an m-by-n matrix, has rank at most 1."""
    rows = [t[i * n:(i + 1) * n] for i in range(m)]
    for i in range(m):
        for k in range(i + 1, m):
            for j in range(n):
                for l in range(j + 1, n):
                    if rows[i][j] * rows[k][l] - rows[i][l] * rows[k][j] != 0:
                        return False
    return True
```
hint: Arrange the coefficients as an $m\times n$ matrix; $u\otimes v$ corresponds to the outer product $uv^\top$.
hint: A matrix is an outer product exactly when its rank is at most $1$, that is, when all of its $2\times2$ minors vanish.
solution: The matrix of coefficients of $u\otimes v$ is $uv^\top$, of rank at most $1$. Conversely a matrix of rank at most $1$ is an outer product. Rank at most $1$ is equivalent to the vanishing of every $2\times2$ minor, so the code tests all of them. Checking only the first two rows and columns misses `[1,1,1,1,1,1,0,0,1]`, whose top-left minor is $0$ but whose rank is $2$.

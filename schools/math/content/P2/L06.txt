@article
Is $\mathbb{Z}/6\oplus\mathbb{Z}/4$ isomorphic to $\mathbb{Z}/2\oplus\mathbb{Z}/12$? Both have order $24$, and each has $2$ summands. The structure theorem answers all such questions at once: every finitely generated module over a PID is a direct sum of cyclic modules, in an essentially unique way. Throughout, $R$ is a PID.

### Submodules of free modules

**Lemma.** Every submodule $K$ of $R^n$ is free of rank at most $n$.

*Proof.* Induct on $n$; $n = 0$ is trivial. Let $\pi\colon R^n\to R$ be the last coordinate. Then $\pi(K) = (a)$ is an ideal, hence principal, and $K' = K\cap\ker\pi \subseteq R^{n-1}$ is free of rank at most $n-1$ by induction. If $a = 0$ then $K = K'$. Otherwise choose $k_0 \in K$ with $\pi(k_0) = a$; then $K = K'\oplus Rk_0$ (for $k\in K$, $\pi(k) = ca$ and $k - ck_0 \in K'$; if $ck_0 \in K'$ then $ca = 0$ so $c = 0$), and $Rk_0\cong R$ since $R$ is a domain. $\blacksquare$

### Smith normal form

Because a PID is a UFD, every nonzero $a\in R$ has a length $\ell(a)$, the number of prime factors counted with multiplicity; $\ell(ab) = \ell(a)+\ell(b)$ and $\ell(a) < \ell(b)$ when $a$ divides $b$ properly.

**Theorem (Smith normal form).** For a nonzero $n\times m$ matrix $A$ over $R$ there are invertible matrices $P$ and $Q$ such that $PAQ$ is diagonal with entries $d_1, \dots, d_r, 0,\dots,0$, where $d_i \ne 0$ and $d_i \mid d_{i+1}$.

*Proof.* Among all matrices obtained from $A$ by invertible row and column operations, choose one with a nonzero entry $d$ of least length, and move it to position $(1,1)$. Suppose $d \nmid a_{1j}$. Let $g = ud + va_{1j}$ be a gcd, so $\ell(g) < \ell(d)$. Replace columns $1$ and $j$ by $u c_1 + v c_j$ and $-(a_{1j}/g)c_1 + (d/g)c_j$; the $2\times 2$ transformation has determinant $(ud+va_{1j})/g = 1$, so it is invertible, and the new $(1,1)$ entry is $g$, contradicting minimality. So $d$ divides all entries in its row and, symmetrically, its column; subtracting multiples clears them. Now $A \sim \mathrm{diag}(d, A')$. If $d\nmid a_{ij}$ for some entry of $A'$, add row $i$ to row $1$; row $1$ then contains an entry not divisible by $d$, and the previous step contradicts minimality again. So $d$ divides every entry of $A'$; induct on $A'$. $\blacksquare$

### The structure theorem

**Theorem.** Let $M$ be a finitely generated module over a PID $R$. Then
$$M \cong R^{s}\oplus R/(d_1)\oplus\cdots\oplus R/(d_k),$$
with $d_i$ nonzero nonunits and $d_1\mid d_2\mid\cdots\mid d_k$ (the **invariant factors**). Equivalently $M \cong R^s\oplus\bigoplus R/(p_j^{e_j})$ with $p_j$ primes (the **elementary divisors**). The integer $s$, the ideals $(d_i)$, and the multiset of $(p_j^{e_j})$ are determined by $M$.

*Proof of existence.* Let $M$ be generated by $n$ elements, giving a surjection $\pi\colon R^n \to M$ with kernel $K$. By the Lemma, $K$ is free; let its basis be the columns of an $n\times m$ matrix $A$. If $A = 0$, then $M \cong R^n$. Otherwise, take $PAQ = D$. The columns of $P^{-1}$ form a new basis $e'_1,\dots,e'_n$ of $R^n$, and the columns of $Q$ turn the basis of $K$ into a basis $d_ie'_i$ ($i\le r$). Hence $M \cong R^n/K\cong\bigoplus_{i\le r}R/(d_i)\oplus R^{n-r}$; summands with $d_i$ a unit vanish. Splitting each $R/(d)$ by the Chinese remainder theorem gives the elementary-divisor form. $\blacksquare$

*Uniqueness (outline, not a full proof).* The rank $s$ is $\dim_{\mathrm{Frac}(R)}(M\otimes \mathrm{Frac}(R))$. For the torsion part and a prime $p$, the numbers $\dim_{R/(p)}\bigl(p^{t-1}M/p^{t}M\bigr)$ (modulo the free part) count the cyclic summands $R/(p^e)$ with $e\ge t$, which determines every exponent multiplicity.

For $R=\mathbb{Z}$: a finite abelian group is $\bigoplus\mathbb{Z}/d_i$ with $d_1\mid\cdots\mid d_k$, and the number of abelian groups of order $n=\prod p^{e_p}$ is $\prod p(e_p)$, where $p(e)$ is the number of partitions of $e$ (one per partition of each exponent). The code computes the Smith diagonal of an integer matrix whose rows are relations among generators.

```python
def smith_diagonal(A):
    """Smith normal form diagonal (d_1 | d_2 | ...) of an integer matrix."""
    A = [row[:] for row in A]
    m, n = len(A), len(A[0])
    diag = []
    for t in range(min(m, n)):
        while True:
            cells = [(abs(A[i][j]), i, j) for i in range(t, m)
                     for j in range(t, n) if A[i][j] != 0]
            if not cells:
                return diag + [0] * (min(m, n) - t)
            _, pi, pj = min(cells)
            A[t], A[pi] = A[pi], A[t]
            for row in A:
                row[t], row[pj] = row[pj], row[t]
            p, clean = A[t][t], True
            for i in range(t + 1, m):
                q = A[i][t] // p
                A[i] = [a - q * b for a, b in zip(A[i], A[t])]
                clean = clean and A[i][t] == 0
            for j in range(t + 1, n):
                q = A[t][j] // p
                for row in A:
                    row[j] -= q * row[t]
                clean = clean and A[t][j] == 0
            if not clean:
                continue
            bad = [i for i in range(t + 1, m)
                   if any(A[i][j] % p for j in range(t + 1, n))]
            if bad:
                A[t] = [a + b for a, b in zip(A[t], A[bad[0]])]
                continue
            break
        diag.append(abs(A[t][t]))
    return diag


print(smith_diagonal([[6, 0], [0, 4]]))      # [2, 12]
```

The output $[2,12]$ says $\mathbb{Z}^2/\langle(6,0),(0,4)\rangle = \mathbb{Z}/6\oplus\mathbb{Z}/4\cong\mathbb{Z}/2\oplus\mathbb{Z}/12$: the opening question. A zero on the diagonal is a free summand $\mathbb{Z}$. The loop ends because the least pivot size strictly drops each time the loop repeats.

@mistakes
- Deciding that two groups are isomorphic because they have the same order and the same number of cyclic summands. $\mathbb{Z}/8$ and $\mathbb{Z}/2\oplus\mathbb{Z}/4$ both have order $8$ and are not isomorphic; compare the full list of invariant factors.
- Forgetting the divisibility condition: $\mathbb{Z}/2\oplus\mathbb{Z}/6\oplus\mathbb{Z}/15$ is not in invariant-factor form, since $6 \nmid 15$. Its elementary divisors $2, 2, 3, 3, 5$ regroup into $\mathbb{Z}/6\oplus\mathbb{Z}/30$.
- Applying the theorem over a ring that is not a PID. Over $\mathbb{Z}[x]$ the ideal $(2,x)$ is finitely generated and torsion-free but not free.
- Reading the Smith normal form diagonal without dropping $1$'s: a diagonal entry $1$ gives the zero module $R/(1)$, not a summand.

```python
def invariant_factors(elementary):
    """Invariant factors of the abelian group with these elementary divisors."""
    by_prime = {}
    for q in elementary:
        p = 2
        while q % p:
            p += 1
        by_prime.setdefault(p, []).append(q)
    k = max((len(v) for v in by_prime.values()), default=0)
    factors = [1] * k
    for powers in by_prime.values():
        for position, q in enumerate(sorted(powers, reverse=True)):
            factors[position] *= q
    return sorted(factors)
```

```python
def count_abelian(n):
    """Number of abelian groups of order n (product of partition numbers)."""
    def partitions(total, largest):
        if total == 0:
            return 1
        return sum(partitions(total - k, k)
                   for k in range(1, min(total, largest) + 1))

    count = 1
    p = 2
    while n > 1:
        e = 0
        while n % p == 0:
            n //= p
            e += 1
        if e:
            count *= partitions(e, e)
        p += 1
    return count
```
hint: Factor $n$ by trial division, recording each exponent $e$.
hint: The number of partitions $p(e)$ satisfies a recursion on the largest part allowed.
solution: Each prime's exponent $e$ gives one abelian $p$-group for each partition of $e$ (the exponents of its cyclic summands), and the $p$-parts are chosen independently, so the count is $\prod p(e)$. For $2^5\cdot3^3\cdot5^2$ this is $p(5)p(3)p(2) = 7\cdot3\cdot2 = 42$, and for $n = 16$ it is $p(4) = 5$. Counting divisors or prime factors instead of partitions gives wrong values.

@article
A vector space is determined by its dimension. A module is a vector space over a ring instead of a field, and the first surprise is that the abelian group $\mathbb{Z}/6$ is a $\mathbb{Z}$-module with a submodule $\mathbb{Z}/2$ that has a complement, while $\mathbb{Z}/4$ with its submodule $\mathbb{Z}/2$ has none. The language of exact sequences makes such questions precise.

### Modules

Let $R$ be a ring with $1$. A (left) **$R$-module** is an abelian group $M$ with a map $R \times M \to M$ satisfying $r(m+n) = rm + rn$, $(r+s)m = rm + sm$, $(rs)m = r(sm)$ and $1m = m$. A $\mathbb{Z}$-module is an abelian group. For a field $F$, an $F[x]$-module is the same as an $F$-vector space $V$ with a linear map $T$ (acting as $x$); this is how Week 7 attacks canonical forms. Submodules, quotients $M/N$ and homomorphisms are defined as for vector spaces, and the isomorphism theorems hold with the same proofs as for groups: $M/\ker f \cong \mathrm{im} f$, $(N+L)/L \cong N/(N\cap L)$, and $(M/L)/(N/L) \cong M/N$ for $L \subseteq N \subseteq M$.

### Exact sequences

A sequence $\cdots \to A \xrightarrow{f} B \xrightarrow{g} C \to \cdots$ is **exact** at $B$ if $\mathrm{im} f = \ker g$. A **short exact sequence** is $0 \to A \xrightarrow{i} B \xrightarrow{p} C \to 0$: $i$ is injective, $p$ is surjective and $\mathrm{im}\, i = \ker p$. Then $A \cong i(A)$ and $C \cong B/i(A)$.

**Splitting lemma.** For a short exact sequence $0\to A\xrightarrow{i}B\xrightarrow{p}C\to 0$ of $R$-modules, the following are equivalent. (a) There is a homomorphism $s\colon C \to B$ with $ps = \mathrm{id}_C$ (a **section**). (b) There is a homomorphism $r\colon B \to A$ with $ri = \mathrm{id}_A$ (a **retraction**). (c) There is an isomorphism $B \cong A \oplus C$ under which $i$ is the inclusion and $p$ the projection. The sequence is then said to **split**.

*Proof.* (a)$\Rightarrow$(c): for $b \in B$, $p(b - sp(b)) = 0$, so $b - sp(b) \in i(A)$ and $B = i(A) + s(C)$. If $s(c) = i(a)$ then $c = ps(c) = pi(a) = 0$, so the sum is direct, and $B = i(A)\oplus s(C) \cong A \oplus C$. (b)$\Rightarrow$(c): $b = ir(b) + (b - ir(b))$ with $b - ir(b) \in \ker r$, so $B = i(A) + \ker r$; if $i(a) \in \ker r$ then $a = ri(a) = 0$. So $B = i(A)\oplus\ker r$, and $p$ maps $\ker r$ isomorphically onto $C$. (c)$\Rightarrow$(a),(b): use the inclusion of $C$ and the projection onto $A$. $\blacksquare$

**Short five lemma (statement; the proof is Practice 5).** If two short exact sequences are connected by homomorphisms $\alpha, \beta,\gamma$ in a commutative diagram ($\beta i = i'\alpha$ and $p'\beta = \gamma p$) and $\alpha$ and $\gamma$ are isomorphisms, then $\beta$ is an isomorphism.

### Free modules and rank

A **basis** of $M$ is a linearly independent generating set; $M$ is **free** if it has one, equivalently $M \cong R^{(I)}$. **Universal property:** if $M$ is free with basis $(e_i)$, every map $e_i \mapsto n_i \in N$ extends uniquely to a homomorphism $M \to N$. Consequently every module is a quotient of a free module, and a short exact sequence ending in a free module splits (send each basis element to a preimage).

**Theorem.** Let $R \ne 0$ be a **commutative** ring. If $R^m \cong R^n$ then $m = n$.

*Proof.* Choose a maximal ideal $\mathfrak{m}$ and put $k = R/\mathfrak{m}$, a field. An isomorphism $\phi\colon R^m\to R^n$ maps $\mathfrak{m}R^m$ onto $\mathfrak{m}R^n$, so induces an isomorphism $R^m/\mathfrak{m}R^m \cong R^n/\mathfrak{m}R^n$, that is $k^m \cong k^n$ as $k$-vector spaces. Dimension gives $m = n$. $\blacksquare$

Commutativity matters: for $R = \mathrm{End}_F(V)$ with $V$ of countably infinite dimension, $R \cong R^2$ as left $R$-modules. Free modules over a PID have free submodules (Week 6); over $\mathbb{Z}[x]$ the ideal $(2,x)$ is a submodule of a free module that is not free.

### Hom and exactness

$\mathrm{Hom}_R(M,N)$ is an abelian group, and an $R$-module if $R$ is commutative. For cyclic modules over $\mathbb{Z}$, $\mathrm{Hom}_{\mathbb{Z}}(\mathbb{Z}/m, \mathbb{Z}/n) \cong \mathbb{Z}/\gcd(m,n)$: a homomorphism is determined by the image $x$ of $1$, which must satisfy $mx = 0$ in $\mathbb{Z}/n$.

**Theorem (left exactness).** If $0 \to A \xrightarrow{i} B \xrightarrow{p} C$ is exact, then so is $0 \to \mathrm{Hom}(M,A) \to \mathrm{Hom}(M,B) \to \mathrm{Hom}(M,C)$. *Proof.* If $i\circ\varphi = 0$ then $\varphi = 0$ since $i$ is injective. Clearly $p\circ i\circ\varphi = 0$. If $p\circ\psi = 0$ then $\psi(M) \subseteq \ker p = i(A)$, and $\psi = i\circ\varphi$ with $\varphi = i^{-1}\circ\psi$. $\blacksquare$

The functor is **not** right exact in general (Example 2). The following code counts homomorphisms between cyclic groups by brute force, as a check on the formula (a check, not a proof).

```python
from math import gcd


def hom_count(m, n):
    """Number of homomorphisms Z/m -> Z/n: images x of 1 with m*x = 0."""
    return sum(1 for x in range(n) if (m * x) % n == 0)


print(hom_count(8, 12), gcd(8, 12))      # 4 4
```
@example
title: A short exact sequence that does not split
problem: Show that $0 \to \mathbb{Z}/2 \xrightarrow{\ \cdot 2\ } \mathbb{Z}/4 \xrightarrow{\ \text{mod }2\ } \mathbb{Z}/2 \to 0$ is exact but does not split, and that $0\to\mathbb{Z}/2\xrightarrow{\ \cdot 3\ }\mathbb{Z}/6\xrightarrow{\ \text{mod }3\ }\mathbb{Z}/3\to0$ does split.
step: Exactness of the first sequence. The map $x \mapsto 2x$ is injective with image $\{0,2\}$, and reduction modulo $2$ is onto with kernel $\{0,2\}$, which equals the image.
step: No section. A section $s\colon\mathbb{Z}/2\to\mathbb{Z}/4$ must send $1$ to an element $y$ with $2y = 0$, so $y \in\{0,2\}$; but then $p(y) = 0 \ne 1$. So no section exists and the sequence does not split. (Equivalently, $\mathbb{Z}/4 \not\cong \mathbb{Z}/2\oplus\mathbb{Z}/2$.)
step: Second sequence. The map $x \mapsto 3x$ is injective with image $\{0,3\}$, which is the kernel of reduction mod $3$ on $\mathbb{Z}/6$, and reduction is onto: exact.
step: A section: $s(1) = 4 \in \mathbb{Z}/6$, which has $3\cdot 4 = 12 \equiv 0$ so $s$ is well defined on $\mathbb{Z}/3$, and $4 \equiv 1 \pmod 3$. So $ps = \mathrm{id}$, the sequence splits, and $\mathbb{Z}/6 = \{0,3\}\oplus\{0,2,4\} \cong \mathbb{Z}/2\oplus\mathbb{Z}/3$.
answer: The first sequence is exact and non-split; the second splits.
@example
title: Hom is not right exact
problem: Apply $\mathrm{Hom}_{\mathbb{Z}}(\mathbb{Z}/2, -)$ to $0\to\mathbb{Z}\xrightarrow{\ \cdot 2\ }\mathbb{Z}\xrightarrow{\ \text{mod }2\ }\mathbb{Z}/2\to0$ and show that the resulting sequence is not exact on the right.
step: The sequence $0\to\mathbb{Z}\to\mathbb{Z}\to\mathbb{Z}/2\to0$ is exact: multiplication by $2$ is injective with image $2\mathbb{Z}$, the kernel of reduction.
step: Compute the Hom groups: $\mathrm{Hom}(\mathbb{Z}/2,\mathbb{Z}) = 0$ (the group $\mathbb{Z}$ has no element of order $2$), and $\mathrm{Hom}(\mathbb{Z}/2,\mathbb{Z}/2)\cong\mathbb{Z}/2$, generated by the identity.
step: The induced sequence is $0 \to 0 \to 0 \to \mathbb{Z}/2$, and the last map $\mathrm{Hom}(\mathbb{Z}/2,\mathbb{Z})\to\mathrm{Hom}(\mathbb{Z}/2,\mathbb{Z}/2)$ goes from $0$ to $\mathbb{Z}/2$, so it is not surjective. The identity of $\mathbb{Z}/2$ does not lift to a homomorphism into $\mathbb{Z}$.
answer: Left exactness holds, but $\mathrm{Hom}(\mathbb{Z}/2,\mathbb{Z})\to\mathrm{Hom}(\mathbb{Z}/2,\mathbb{Z}/2)$ is not onto.
@mistakes
- Treating "$B$ has a submodule isomorphic to $A$ with quotient $C$" as meaning $B \cong A\oplus C$. The orders of $\mathbb{Z}/4$ and $(\mathbb{Z}/2)^2$ agree, and both fit an exact sequence with $\mathbb{Z}/2$ at both ends, yet they differ.
- Using a section $s$ that is only a set map or only a group homomorphism: for $R$-modules the section must be $R$-linear.
- Claiming "rank is well defined for every ring". It holds for commutative rings (and many others), not for $\mathrm{End}_F(V)$ with $V$ infinite-dimensional.
- Assuming $\mathrm{Hom}(M,-)$ preserves surjections. It does when $M$ is projective, for instance free, but not for $M = \mathbb{Z}/2$.

@practice self
prompt: (Short five lemma.) Let $0\to A\xrightarrow{i}B\xrightarrow{p}C\to0$ and $0\to A'\xrightarrow{i'}B'\xrightarrow{p'}C'\to0$ be short exact sequences of $R$-modules and $\alpha\colon A\to A'$, $\beta\colon B\to B'$, $\gamma\colon C\to C'$ homomorphisms with $\beta i = i'\alpha$ and $p'\beta=\gamma p$. Prove that if $\alpha$ and $\gamma$ are isomorphisms, then $\beta$ is an isomorphism.
hint: Prove injectivity of $\beta$ by a diagram chase starting from $b \in \ker\beta$: first push it to $C'$.
hint: Prove surjectivity by choosing $b'\in B'$, finding a candidate $b\in B$ from $\gamma^{-1}p'(b')$, and correcting the difference using $A'$.
solution: Injective: let $\beta(b) = 0$. Then $\gamma p(b) = p'\beta(b) = 0$, so $p(b) = 0$ as $\gamma$ is injective. By exactness $b = i(a)$ for some $a \in A$. Then $0 = \beta i(a) = i'\alpha(a)$, so $\alpha(a) = 0$ as $i'$ is injective, hence $a = 0$ as $\alpha$ is injective, and $b = 0$. Surjective: let $b' \in B'$. Since $\gamma$ and $p$ are surjective, there is $b\in B$ with $\gamma p(b) = p'(b')$. Then $p'(b' - \beta(b)) = p'(b') - \gamma p(b) = 0$, so $b' - \beta(b) = i'(a')$ for some $a' \in A'$. Since $\alpha$ is surjective, $a' = \alpha(a)$, and $i'(a') = i'\alpha(a) = \beta i(a)$. Therefore $b' = \beta(b + i(a))$. So $\beta$ is bijective, and a bijective module homomorphism is an isomorphism. $\blacksquare$
rubric: Proves injectivity using exactness at $B$, injectivity of $\gamma$, injectivity of $i'$ and of $\alpha$.
rubric: Proves surjectivity by lifting through $\gamma p$ and correcting by an element of $i'(A')$ via surjectivity of $\alpha$.
rubric: Uses the commutativity relations $\beta i = i'\alpha$ and $p'\beta = \gamma p$ correctly at each step.

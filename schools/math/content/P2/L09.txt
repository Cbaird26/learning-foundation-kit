@article
The polynomial ring $\mathbb{Q}[x,y]$ has ideals needing many generators, such as $(x,y)^n$, which needs $n+1$. Yet no ideal needs infinitely many. This finiteness, and the proof technique that comes with it, is the content of the Noetherian condition. Rings here are commutative with $1$; the module statements hold over any ring.

### Equivalent conditions

**Theorem.** For a module $M$ over a ring $R$ the following are equivalent: (a) every ascending chain $N_1\subseteq N_2\subseteq\cdots$ of submodules is eventually constant (ACC); (b) every nonempty set of submodules has a maximal element; (c) every submodule is finitely generated. $M$ is then called **Noetherian**, and $R$ is a Noetherian ring if it is Noetherian as a module over itself, i.e. if its ideals are finitely generated.

*Proof.* (a)$\Rightarrow$(b): if a nonempty set $\Sigma$ had no maximal element, we could choose $N_1\subsetneq N_2\subsetneq\cdots$ in $\Sigma$ (dependent choice), violating (a). (b)$\Rightarrow$(c): for a submodule $N$, the set of finitely generated submodules of $N$ is nonempty, so has a maximal element $N_0$; if $N_0\ne N$, adding an element of $N\setminus N_0$ gives a larger finitely generated submodule, a contradiction. (c)$\Rightarrow$(a): the union $N=\bigcup N_k$ is a submodule, hence generated by finitely many elements, which all lie in some $N_m$; then $N_k=N$ for $k\ge m$. $\blacksquare$

**Theorem (extensions).** Let $0\to M'\to M\to M''\to0$ be exact. Then $M$ is Noetherian if and only if $M'$ and $M''$ are.

*Proof.* ($\Rightarrow$) Submodules of $M'$ and of $M''$ correspond to submodules of $M$ (by inclusion and by preimage), so chains in them give chains in $M$. ($\Leftarrow$) Let $N_1\subseteq N_2\subseteq\cdots$ in $M$ (regard $M'\subseteq M$). The chains $N_k\cap M'$ and the images $N_k''$ in $M''$ are eventually constant, say for $k\ge m$. If $N\subseteq N'$ have $N\cap M'=N'\cap M'$ and the same image in $M''$, then $N=N'$: for $x\in N'$ pick $y\in N$ with the same image; then $x-y\in N'\cap M'=N\cap M'$, so $x\in N$. Hence $N_k=N_m$ for $k\ge m$. $\blacksquare$

**Corollaries.** Finite direct sums of Noetherian modules are Noetherian. If $R$ is Noetherian, every finitely generated $R$-module is Noetherian (a quotient of $R^n$). Quotient rings $R/I$ are Noetherian, and so are localizations $S^{-1}R$, whose ideals are generated by images of generators of their contractions.

### The Hilbert basis theorem

**Theorem (Hilbert, 1890).** If $R$ is a Noetherian ring, then $R[x]$ is Noetherian.

*Proof.* Let $I\subseteq R[x]$ be an ideal that is not finitely generated. Choose $f_1\in I$ of least degree, and then $f_{k+1}\in I\setminus(f_1,\dots,f_k)$ of least degree. Let $d_k=\deg f_k$ and let $a_k$ be the leading coefficient. By the choice, $d_1\le d_2\le\cdots$. The chain $(a_1)\subseteq(a_1,a_2)\subseteq\cdots$ of ideals of $R$ stabilizes, so $a_{N+1}=\sum_{i\le N}c_ia_i$ for some $N$ and $c_i\in R$. Put $g=f_{N+1}-\sum_{i\le N}c_ix^{d_{N+1}-d_i}f_i$. The leading terms of degree $d_{N+1}$ cancel, so $\deg g<d_{N+1}$. And $g\notin(f_1,\dots,f_N)$, because otherwise $f_{N+1}$ would lie in it. Since $g\in I$, this contradicts the minimality of the degree of $f_{N+1}$. $\blacksquare$

By induction, $R[x_1,\dots,x_n]$ is Noetherian when $R$ is, so every finitely generated algebra over a field or over $\mathbb{Z}$ is Noetherian (a quotient of a polynomial ring). The power series ring $R[[x]]$ is also Noetherian (stated here without proof). A theorem of Hopkins and Levitzki, also stated without proof, says that an Artinian ring is Noetherian.

### Non-examples and techniques

The ring $k[x_1,x_2,\dots]$ in infinitely many variables is not Noetherian: $(x_1)\subsetneq(x_1,x_2)\subsetneq\cdots$. Subrings of Noetherian rings need not be Noetherian: $k[x_1,x_2,\dots]$ lies inside the field $k(x_1,x_2,\dots)$, which is Noetherian.

Exam problems use three moves. (1) **ACC argument**: build a chain, say it stabilizes, and derive an equality. (2) **Noetherian induction**: if a property fails for some ideal, take a maximal ideal failing it, and derive a contradiction. (3) **Surjective endomorphisms** of Noetherian rings and modules are injective (Example 2).

Monomial ideals make the finiteness visible: by Dickson's lemma a monomial ideal in $k[x_1,\dots,x_n]$ is generated by finitely many monomials, and a monomial lies in it if and only if some generator divides it. Exponent vectors $(a_1,\dots,a_n)$ stand for monomials.

```python
def divides(a, b):
    """Does the monomial with exponents a divide the one with exponents b?"""
    return all(x <= y for x, y in zip(a, b))


def in_monomial_ideal(m, gens):
    return any(divides(g, m) for g in gens)


gens = [(2, 0), (0, 2)]                   # the ideal (x^2, y^2)
print([in_monomial_ideal((i, j), gens) for i, j in [(1, 1), (2, 0), (3, 1)]])
```

This prints `[False, True, True]`. The code tests divisibility of exponent vectors componentwise; it does not prove Dickson's lemma, which is a separate induction on the number of variables.
@example
title: A surjective endomorphism that is not injective
problem: Let $R=k[x_1,x_2,\dots]$ and let $\varphi\colon R\to R$ be the $k$-algebra homomorphism with $\varphi(x_1)=0$ and $\varphi(x_{i+1})=x_i$ for $i\ge1$. Show that $\varphi$ is onto but not one-to-one, and that $R$ is not Noetherian.
step: Onto: every generator $x_i$ is $\varphi(x_{i+1})$, and $\varphi$ is a $k$-algebra homomorphism, so its image is a $k$-subalgebra containing all $x_i$, which is $R$.
step: Not injective: $\varphi(x_1)=0$ with $x_1\ne0$.
step: Not Noetherian: the ideals $I_n=\ker(\varphi^n)$ form a strictly ascending chain. The element $x_n\in\ker\varphi^n$ (indeed $\varphi^n(x_n)=\varphi^{n-1}(x_{n-1})=\cdots=\varphi(x_1)=0$), while $\varphi^{n-1}(x_n)=x_1\ne0$, so $x_n\notin\ker\varphi^{n-1}$. The chain never stabilizes.
step: This is the pattern that Example 2 turns into a proof: in a Noetherian ring the chain $\ker\varphi^n$ must stabilize, forcing injectivity.
answer: $\varphi$ is surjective with kernel containing $x_1$, and the chain $\ker\varphi^n$ shows $R$ is not Noetherian.
@example
title: Surjective ring endomorphisms of Noetherian rings
problem: Prove that if $R$ is a Noetherian ring and $\varphi\colon R\to R$ is a surjective ring homomorphism, then $\varphi$ is injective.
step: Set $K_n=\ker(\varphi^n)$. Then $K_1\subseteq K_2\subseteq\cdots$ is an ascending chain of ideals, since $\varphi^n(x)=0$ implies $\varphi^{n+1}(x)=0$.
step: Since $R$ is Noetherian the chain stabilizes: there is $n$ with $K_n=K_{n+1}=K_{2n}$.
step: Let $\varphi(x)=0$. Because $\varphi^n$ is onto, $x=\varphi^n(y)$ for some $y$. Then $\varphi^{n+1}(y)=\varphi(x)=0$, so $y\in K_{n+1}=K_n$, hence $x=\varphi^n(y)=0$.
step: So $\ker\varphi=0$. The same proof works for a surjective endomorphism of a Noetherian module.
answer: $\ker\varphi=0$, using ACC on the kernels of the powers of $\varphi$.
@mistakes
- Claiming a subring of a Noetherian ring is Noetherian. $k[x_1,x_2,\dots]\subset k(x_1,x_2,\dots)$ is a counterexample. Quotients and localizations do inherit the property.
- Applying the Hilbert basis theorem to infinitely many variables. $R[x_1,x_2,\dots]$ is not Noetherian even for a field $R$.
- Writing "finitely generated as a ring" when you need "finitely generated as an ideal". The ring $k[x_1,x_2,\dots]$ is generated by infinitely many elements, and its ideal $(x_1,x_2,\dots)$ is not finitely generated.
- Choosing the chain's stabilization point after knowing the answer. In the Hilbert basis proof the index $N$ comes from the stabilization of $(a_1)\subseteq(a_1,a_2)\subseteq\cdots$ in $R$, not in $R[x]$.
@practice num
prompt: Let $k$ be a field and $I=(x,y)^3\subseteq k[x,y]$. What is the minimum number of generators of $I$?
answer: 4
check: sum(1 for a in range(4) for b in range(4) if a + b == 3)
hint: $I$ is generated by the monomials of degree $3$, and no monomial of degree $3$ is a multiple of another.
solution: The ideal $(x,y)^3$ is generated by the four monomials $x^3,x^2y,xy^2,y^3$. The minimum number of generators of an ideal $I$ in this graded ring is $\dim_k I/(x,y)I$ (Nakayama's lemma), and here $I/(x,y)I=(x,y)^3/(x,y)^4$ has the four degree-$3$ monomials as a $k$-basis. So at least, and exactly, $4$ generators are needed.

```python
def minimal_generators(gens):
    """Minimal monomial generators: those not divisible by another one."""
    distinct = sorted(set(gens))
    result = []
    for g in distinct:
        if not any(h != g and all(a <= b for a, b in zip(h, g))
                   for h in distinct):
            result.append(g)
    return result
```
hint: First remove duplicates, so that "another generator dividing it" means a different tuple.
hint: A tuple $h$ divides $g$ when $h_i\le g_i$ for all $i$.
solution: Deduplicate, then keep a tuple unless a different tuple divides it. The minimal generators of a monomial ideal are exactly the minimal elements of its set of monomials under divisibility, and they are unique. Without deduplicating, equal tuples would divide each other and both would be discarded, which the test `[(1, 0), (1, 0)]` catches.
@practice self
prompt: Let $R\ne0$ be a Noetherian commutative ring. Prove that every ideal $I$ of $R$ contains a product $P_1P_2\cdots P_k$ of (not necessarily distinct) prime ideals of $R$, for some $k\ge1$.
hint: Suppose the set $\Sigma$ of ideals containing no such product is nonempty, and take a maximal element $I$ of $\Sigma$.
hint: Show $I$ is not prime and $I\ne R$. Then pick $a,b\notin I$ with $ab\in I$ and consider $I+(a)$ and $I+(b)$.
solution: Suppose the set $\Sigma$ of ideals that contain no product of primes (with $k\ge1$) is nonempty. Since $R$ is Noetherian, $\Sigma$ has a maximal element $I$. First $I\ne R$: because $R\ne0$ it has a maximal ideal $\mathfrak{m}$, which is prime, and $R\supseteq\mathfrak{m}$. Second, $I$ is not prime, since a prime ideal contains the product with $k=1$ consisting of itself. So there are $a,b\in R\setminus I$ with $ab\in I$. The ideals $J_1=I+(a)$ and $J_2=I+(b)$ strictly contain $I$, so by maximality they are not in $\Sigma$: $J_1\supseteq P_1\cdots P_r$ and $J_2\supseteq Q_1\cdots Q_s$ for prime ideals $P_i,Q_j$. Then $J_1J_2\subseteq I+(ab)\subseteq I$, because $(I+(a))(I+(b))=I^2+aI+bI+(ab)$ and each term is in $I$. Hence $I\supseteq J_1J_2\supseteq P_1\cdots P_rQ_1\cdots Q_s$, so $I\notin\Sigma$, a contradiction. Therefore $\Sigma$ is empty. $\blacksquare$

rubric: Rules out $I=R$ (using a maximal ideal) and $I$ prime, and extracts $a,b\notin I$ with $ab\in I$.
rubric: Shows $(I+(a))(I+(b))\subseteq I$ and concludes that $I$ contains a product of primes, a contradiction.

model:
```python
def count_outside(gens, d, n):
    """Monomials of degree <= d in n variables outside the ideal (gens)."""
    def tuples(left, slots):
        if slots == 0:
            yield ()
            return
        for first in range(left + 1):
            for rest in tuples(left - first, slots - 1):
                yield (first,) + rest

    count = 0
    for a in tuples(d, n):
        if not any(all(g[i] <= a[i] for i in range(n)) for g in gens):
            count += 1
    return count
```
hint: Enumerate all exponent tuples of length $n$ whose entries sum to at most $d$.
hint: Count a tuple only if no generator divides it componentwise.
solution: Enumerate exponent tuples with sum at most $d$ recursively, and keep those divisible by no generator. With no generators every tuple is kept: $\binom{3+2}{2}=10$ for $d=3$, $n=2$. For $(xy,yz,xz)$ in three variables with $d=3$, the surviving monomials are $1$, $x,y,z$, $x^2,y^2,z^2$ and $x^3,y^3,z^3$, which is $10$. The test with `(3,)` counts $1,x,x^2$.

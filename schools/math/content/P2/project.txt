material: **Exact arithmetic in Z[w].** Elements $a+bw$ of $\mathbb{Z}[w]$, with $w=e^{2\pi i/3}$ and $w^2=-1-w$, are stored as pairs `(a, b)`. This code multiplies, conjugates and forms the inner product (the result is the pair to divide by the order of the group). Use it for the table of $A_4$, whose classes have sizes $1,3,4,4$.
```python
def add(x, y):
    return (x[0] + y[0], x[1] + y[1])


def mul(x, y):
    a, b = x
    c, d = y
    return (a * c - b * d, a * d + b * c - b * d)    # uses w*w = -1 - w


def conj(x):
    a, b = x
    return (a - b, -b)                               # conj(w) = w*w


def inner_total(chi, psi, sizes):
    """Sum over classes of size * chi * conj(psi); divide by |G| afterwards."""
    total = (0, 0)
    for s, x, y in zip(sizes, chi, psi):
        t = mul(x, conj(y))
        total = add(total, (s * t[0], s * t[1]))
    return total
```

### Key ideas by week

1. **Actions and Sylow.** Orbit–stabilizer, the class equation, Burnside's lemma. Sylow: existence, conjugacy, $n_p\mid m$ and $n_p\equiv1\pmod p$. Use counts of elements, or the action on Sylow subgroups.
2. **Solvable and nilpotent.** Jordan–Hölder; derived series; $p$-groups are nilpotent; finite nilpotent means a product of its Sylow subgroups; Burnside's $p^aq^b$ and Feit–Thompson (stated without proof).
3. **Free groups and presentations.** Normal form, universal property, von Dyck, the recipe (surjection plus an upper bound), abelianization from exponent sums, Nielsen–Schreier rank $n(r-1)+1$.
4. **Rings.** Maximal and prime ideals, Zorn, nilradical, CRT, UFD $\supset$ PID $\supset$ Euclidean, localization and local rings.
5. **Modules.** Exact sequences, splitting lemma, free modules and rank, Hom is left exact.
6. **PID modules.** Smith normal form, structure theorem, invariant factors versus elementary divisors, counting abelian groups.
7. **Canonical forms.** $V_T$ as an $F[x]$-module, rational form, Jordan form, block sizes from ranks, similarity by the Smith form of $xI-A$.
8. **Tensor products.** Universal property, right exactness, $R/I\otimes M\cong M/IM$, Kronecker products.
9. **Noetherian rings.** ACC, extensions, Hilbert basis theorem, non-examples, Noetherian induction.
10. **Galois theory.** Separable, normal, Galois; Artin's theorem; the fundamental theorem.
11. **Applications.** Finite fields, cyclotomic polynomials, solvability by radicals and $S_5$.
12. **Characters.** Maschke, Schur, orthogonality, $\sum d_i^2=|G|$, tables.

### Key formulas and algorithms

Orbit–stabilizer $|Gx|=[G:G_x]$; Burnside $\frac1{|G|}\sum|\mathrm{Fix}(g)|$; $\mathbb{Z}/m\otimes\mathbb{Z}/n\cong\mathbb{Z}/\gcd(m,n)$; $\det(A\otimes B)=\det(A)^m\det(B)^n$; $N_q(n)=\frac1n\sum_{d\mid n}\mu(n/d)q^d$; $\mathrm{Gal}(\mathbb{Q}(\zeta_n)/\mathbb{Q})\cong(\mathbb{Z}/n)^\times$; $\langle\chi,\psi\rangle=\frac1{|G|}\sum\chi\bar\psi$. Algorithms: Smith normal form, Jordan blocks from $\mathrm{rank}(A-\lambda I)^k$, Galois groups from degree towers and permutation groups.

### Common errors

Using $n_p\equiv1\pmod p$ without $n_p\mid m$; concluding $\langle X\mid R\rangle\cong G$ from a surjection only; reading char poly plus min poly as complete invariants for $n\ge4$; tensoring injections and expecting injections; assuming irreducible of degree $n$ means Galois group $S_n$; weighting character inner products without class sizes or conjugates.

answer: 7
check: float(run("G = [(a, b) for a in range(11) for b in range(5)]\n\ndef m(x, y):\n    return ((x[0] + pow(3, x[1], 11) * y[0]) % 11, (x[1] + y[1]) % 5)\n\ndef inv(x):\n    return next(y for y in G if m(x, y) == (0, 0))\n\nseen = set()\nn = 0\nfor x in G:\n    if x not in seen:\n        seen |= {m(m(g, x), inv(g)) for g in G}\n        n += 1\nprint(n)"))
hint: Find the normal Sylow $11$-subgroup first, then see how conjugation by the elements of order $5$ moves its nonidentity elements.
hint: Count the elements: the identity, the $10$ elements of order $11$, and the $44$ elements outside the normal subgroup, and find the class sizes of each type.
solution: The subgroup $N=\{(a,0)\}$ of order $11$ is normal and $G/N\cong\mathbb{Z}/5$. Conjugation by $(0,1)$ sends $(a,0)$ to $(3a,0)$, and $3$ has order $5$ in $(\mathbb{Z}/11)^\times$ with orbits of size $5$ on the $10$ nonzero residues, so the elements of $N\setminus\{1\}$ form $2$ classes of size $5$. The $44$ elements outside $N$ have centralizers of order $5$ (the elements outside $N$ commute only with the powers of their own order-$5$ subgroup), so classes of size $55/5=11$; there are $44/11=4$ such classes. The total is $1+2+4=7$ classes. Consistently, $5+2\cdot5^2=55$ for the $5$ linear characters and two irreducible characters of degree $5$.
@exam self
prompt: Let $K=\mathbb{Q}(\zeta_7)$ with $\zeta_7=e^{2\pi i/7}$. Prove that $K$ has exactly one subfield of degree $3$ over $\mathbb{Q}$, that this subfield is a Galois extension of $\mathbb{Q}$, and that it is contained in $\mathbb{R}$.
hint: Use $\mathrm{Gal}(K/\mathbb{Q})\cong(\mathbb{Z}/7)^\times$ and the fundamental theorem of Galois theory.
hint: Which element of the Galois group is complex conjugation, and what is its order?
solution: By the irreducibility of the cyclotomic polynomial, $\mathrm{Gal}(K/\mathbb{Q})\cong(\mathbb{Z}/7)^\times$, which is cyclic of order $6$ (generated by $3$, whose powers are $3,2,6,4,5,1$). A cyclic group of order $6$ has exactly one subgroup of each order dividing $6$, in particular exactly one subgroup $H$ of order $2$, namely $\{1,6\}$. By the fundamental theorem, intermediate fields correspond to subgroups with $[K^H:\mathbb{Q}]=[G:H]$; so subfields of degree $3$ over $\mathbb{Q}$ correspond to subgroups of order $2$, and there is exactly one, $E=K^H$. Since $G$ is abelian, $H$ is normal, so $E/\mathbb{Q}$ is Galois with group $G/H\cong\mathbb{Z}/3$. Complex conjugation maps $\zeta_7\mapsto\zeta_7^{-1}=\zeta_7^6$, so it is the element $6\in(\mathbb{Z}/7)^\times$, the generator of $H$. Hence $E$ is the fixed field of complex conjugation (restricted to $K$), so every element of $E$ is real: $E\subseteq\mathbb{R}$. (Explicitly $E=\mathbb{Q}(\zeta_7+\zeta_7^{-1})$.) $\blacksquare$

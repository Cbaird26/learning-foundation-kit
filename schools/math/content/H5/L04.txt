@article
Computing every derivative from the limit definition would be exhausting. Fortunately a handful of rules, each proved once from the definition, handle almost everything. Learn them as patterns, then practice until they are automatic.

### Basic derivatives

| $f(x)$ | $f'(x)$ |
|---|---|
| constant $c$ | $0$ |
| $x^n$ (any constant $n$) | $n x^{n-1}$ |
| $e^x$ | $e^x$ |
| $\ln x$ | $\dfrac{1}{x}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x$ |

The trigonometric formulas assume $x$ is measured in **radians**. The **power rule** works for negative and fractional exponents too, but first rewrite roots and reciprocals as powers: $\sqrt{x} = x^{1/2}$ and $\frac{1}{x^3} = x^{-3}$.

### Linearity

Derivatives respect addition and scaling. For constants $a$ and $b$,

$$\frac{d}{dx}\big[a f(x) + b g(x)\big] = a f'(x) + b g'(x).$$

So you may differentiate a sum term by term and pull constant multipliers out front.

### Product and quotient rules

The derivative of a product is **not** the product of the derivatives. The correct rule has two terms, one for each factor changing while the other holds still:

$$(fg)' = f'g + fg'.$$

For a quotient, order matters:

$$\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}.$$

A memory aid: "low d-high minus high d-low, over the square of what is below", where "high" is the top function and "low" is the bottom one.

### Higher derivatives

Differentiating $f'$ gives the **second derivative** $f''$, and so on. If $s(t)$ is position, then $s'(t)$ is velocity and $s''(t)$ is acceleration.

### Choosing a strategy

Before reaching for the quotient rule, ask whether you can rewrite the expression as a sum of powers. For instance $\frac{x^2 + 1}{x} = x + x^{-1}$, whose derivative is $1 - x^{-2}$, which is far quicker than the quotient rule. Always simplify first.

@example
title: Rewrite, then differentiate
problem: Find $f'(x)$ for $f(x) = \dfrac{3}{x^2} + 4\sqrt{x} - 5x$.
step: Rewrite every term as a power of $x$: $f(x) = 3x^{-2} + 4x^{1/2} - 5x$.
step: Differentiate term by term with the power rule, keeping the constant multipliers: $3(-2)x^{-3} + 4\left(\tfrac{1}{2}\right)x^{-1/2} - 5$.
step: Simplify: $f'(x) = -6x^{-3} + 2x^{-1/2} - 5 = -\dfrac{6}{x^3} + \dfrac{2}{\sqrt{x}} - 5$.

@example
title: The quotient rule
problem: Differentiate $f(x) = \dfrac{e^x}{x^2 + 1}$ and simplify.
step: Name the pieces: top $u = e^x$ with $u' = e^x$, and bottom $v = x^2 + 1$ with $v' = 2x$.
step: Apply the quotient rule $\dfrac{u'v - uv'}{v^2}$: $f'(x) = \dfrac{e^x(x^2 + 1) - e^x \cdot 2x}{(x^2 + 1)^2}$.
step: Factor $e^x$ out of the numerator: $e^x\big(x^2 - 2x + 1\big) = e^x (x - 1)^2$.
step: So $f'(x) = \dfrac{e^x (x - 1)^2}{(x^2 + 1)^2}$. The numerator is never negative, so $f'(x) \ge 0$: the graph never goes downhill, and it is momentarily flat only at $x = 1$.

@mistakes
- Writing $(fg)' = f'g'$. The product rule has two terms.
- Reversing the quotient rule numerator. It must be $f'g - fg'$, in that order.
- Applying the power rule to $e^x$ and getting $x e^{x-1}$. In $e^x$ the variable is in the exponent, so the power rule does not apply.
- Forgetting to rewrite roots and reciprocals as powers before differentiating.

@practice expr
prompt: Differentiate $f(x) = 5x^3 - 4x^2 + 7x - 2$.
vars: x
lead: $f'(x) =$
answer: 15x^2 - 8x + 7
check: lambda x: nderiv(lambda t: 5*t**3 - 4*t**2 + 7*t - 2, x)
hint: Apply the power rule to each term separately: $x^n \to n x^{n-1}$.
hint: The constant $-2$ has derivative $0$, and the term $7x$ becomes $7$.
solution: $\frac{d}{dx}(5x^3) = 15x^2$, $\frac{d}{dx}(-4x^2) = -8x$, $\frac{d}{dx}(7x) = 7$, and the constant vanishes: $f'(x) = 15x^2 - 8x + 7$.

@practice expr
prompt: Differentiate $g(x) = \dfrac{2}{\sqrt{x}} + x^{3/2}$ for $x > 0$.
vars: x
lead: $g'(x) =$
answer: -x^(-3/2) + (3/2)x^(1/2)
check: lambda x: nderiv(lambda t: 2/sqrt(t) + t**1.5, x)
domain: x: 0.5..3
hint: Rewrite $\frac{2}{\sqrt{x}}$ as $2x^{-1/2}$ before differentiating.
hint: Apply $x^n \to n x^{n-1}$ to $2x^{-1/2}$ and to $x^{3/2}$.
solution: $g(x) = 2x^{-1/2} + x^{3/2}$, so $g'(x) = 2\left(-\tfrac{1}{2}\right)x^{-3/2} + \tfrac{3}{2}x^{1/2} = -x^{-3/2} + \tfrac{3}{2}x^{1/2}$.

@practice expr
prompt: Differentiate $f(x) = x^2 e^x$.
vars: x
lead: $f'(x) =$
answer: (x^2 + 2x)e^x
check: lambda x: nderiv(lambda t: t**2*exp(t), x)
hint: This is a product of $x^2$ and $e^x$, so use the product rule $(fg)' = f'g + fg'$.
hint: $f' g = 2x e^x$ and $f g' = x^2 e^x$. Add them and factor out $e^x$ if you like.
solution: $(x^2)' e^x + x^2 (e^x)' = 2x e^x + x^2 e^x = (x^2 + 2x)e^x$.

@practice num
prompt: Let $f(x) = \dfrac{\sin x}{x}$. Find $f'(\pi)$. Give an exact answer.
answer: -1/pi
check: nderiv(lambda x: sin(x)/x, pi)
hint: Use the quotient rule with top $\sin x$ and bottom $x$.
hint: $f'(x) = \dfrac{x\cos x - \sin x}{x^2}$. Now substitute $x = \pi$, where $\cos \pi = -1$ and $\sin \pi = 0$.
solution: $f'(x) = \dfrac{x\cos x - \sin x}{x^2}$, so $f'(\pi) = \dfrac{\pi(-1) - 0}{\pi^2} = -\dfrac{1}{\pi}$.

@practice self
prompt: Use the limit definition to find the derivative of $f(x) = 2x^2 + 5x - 7$. Then confirm your answer using the power rule and the sum rule.
hint: Expand $f(x + h)$, subtract $f(x)$, and look at which terms survive.
hint: After dividing by $h$ you should have a sum of three pieces, one of which still contains $h$.
solution: $f(x + h) - f(x) = 2(2xh + h^2) + 5h = 4xh + 2h^2 + 5h$. Dividing by $h$ gives $4x + 2h + 5$, which tends to $4x + 5$ as $h \to 0$. With the rules: $\frac{d}{dx}(2x^2) = 4x$, $\frac{d}{dx}(5x) = 5$ and the constant gives $0$, so $f'(x) = 4x + 5$. The two methods agree.
rubric: Writes the difference quotient and cancels the constant $-7$ and the terms without $h$.
rubric: Divides the whole numerator by $h$ and takes the limit to get $4x + 5$.
rubric: Applies the power, constant-multiple and sum rules to reach the same result.
rubric: States that the two answers agree.

@quiz expr
prompt: Differentiate $f(x) = \dfrac{x^2 - 1}{x^2 + 1}$.
vars: x
lead: $f'(x) =$
answer: 4x/(x^2 + 1)^2
check: lambda x: nderiv(lambda t: (t**2 - 1)/(t**2 + 1), x)
hint: Use the quotient rule with top $x^2 - 1$ and bottom $x^2 + 1$.
hint: The numerator is $2x(x^2 + 1) - (x^2 - 1)(2x)$. Factor out $2x$ before expanding.
solution: $f'(x) = \dfrac{2x(x^2 + 1) - (x^2 - 1)(2x)}{(x^2 + 1)^2} = \dfrac{2x\big[(x^2 + 1) - (x^2 - 1)\big]}{(x^2 + 1)^2} = \dfrac{4x}{(x^2 + 1)^2}$.

@quiz num
prompt: Find the slope of the tangent line to $y = x \ln x$ at $x = e$.
answer: 2
check: nderiv(lambda x: x*ln(x), e)
hint: The function is a product of $x$ and $\ln x$.
hint: By the product rule, $y' = 1 \cdot \ln x + x \cdot \frac{1}{x}$. Then substitute $x = e$.
solution: $y' = \ln x + 1$. At $x = e$, $\ln e = 1$, so the slope is $2$.

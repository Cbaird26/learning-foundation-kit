@article
In $\mathbb{Z}$ every integer factors uniquely into primes: $12 = 2^2 \cdot 3$ in only one way. In the ring $\mathbb{Z}[\sqrt{-5}]$, however,
$$6 = 2 \cdot 3 = (1 + \sqrt{-5})(1 - \sqrt{-5}),$$
and we will see that all four factors are irreducible and no two are associates. Unique factorization is a property some rings have and some do not. This lesson finds the property that guarantees it. Domains are commutative with $1$.

### Three classes of domains

A domain $D$ is **Euclidean** if there is a function $N\colon D \setminus \{0\} \to \mathbb{Z}_{\ge 0}$ such that for all $a$ and all $b \ne 0$ there are $q, r \in D$ with $a = qb + r$ and either $r = 0$ or $N(r) < N(b)$. Examples: $\mathbb{Z}$ with $N(n) = |n|$, and $F[x]$ for a field $F$ with $N(f) = \deg f$ (the division algorithm of Lesson 5). A **principal ideal domain** (PID) is a domain in which every ideal is principal.

**Theorem.** Every Euclidean domain is a PID.

*Proof.* Let $I \ne 0$ be an ideal. Choose $b \in I \setminus \{0\}$ with $N(b)$ minimal. For $a \in I$ write $a = qb + r$; then $r = a - qb \in I$, and $r \ne 0$ would contradict minimality since $N(r) < N(b)$. So $r = 0$ and $I = (b)$. $\blacksquare$

**The Gaussian integers are Euclidean.** Let $N(a + bi) = a^2 + b^2$, which is multiplicative. Given $\alpha, \beta \in \mathbb{Z}[i]$ with $\beta \ne 0$, write $\alpha/\beta = x + yi$ with $x, y \in \mathbb{Q}$ and choose integers $m, n$ with $|x - m| \le \frac12$ and $|y - n| \le \frac12$. Let $q = m + ni$ and $r = \alpha - q\beta \in \mathbb{Z}[i]$. Then $N(r) = N(\beta)\,N(\alpha/\beta - q) = N(\beta)\bigl((x - m)^2 + (y - n)^2\bigr) \le N(\beta)\cdot\tfrac12 < N(\beta)$. $\blacksquare$ (Here $N$ extends to $\mathbb{Q}(i)$ by the same formula.)

### Irreducible elements, primes and unique factorization

Let $D$ be a domain. A nonzero nonunit $p$ is **irreducible** if $p = ab$ implies $a$ or $b$ is a unit, and **prime** if $p \mid ab$ implies $p \mid a$ or $p \mid b$. Elements $a, b$ are **associates** if $a = ub$ for a unit $u$. $D$ is a **unique factorization domain** (UFD) if every nonzero nonunit is a product of irreducibles, uniquely up to order and associates. Every prime is irreducible; in a PID the converse holds.

**Theorem.** In a PID every irreducible element $p$ is prime.

*Proof.* Let $p \mid ab$ and $p \nmid a$. The ideal $(p, a) = (d)$ for some $d$. Then $d \mid p$, so $d$ is a unit or an associate of $p$; if $d \sim p$ then $p \mid a$, which is false. So $d$ is a unit and $1 = px + ay$ for some $x, y$. Multiply by $b$: $b = pbx + aby$, and $p$ divides both terms, so $p \mid b$. $\blacksquare$

**Theorem.** Every PID is a UFD. *Outline.* *Existence:* if a nonzero nonunit $a$ were not a product of irreducibles, then $a = a_1b_1$ with $a_1, b_1$ nonunits and one of them, say $a_1$, again not a product of irreducibles; then $(a) \subsetneq (a_1)$ (equality would make $b_1$ a unit by cancelling $a_1$). Repeating gives a strictly increasing chain $(a) \subsetneq (a_1) \subsetneq (a_2) \subsetneq \dots$. Its union is an ideal $(c)$, and $c$ lies in some $(a_n)$, forcing $(a_n) = (a_{n+1})$, a contradiction. *Uniqueness:* if $p_1 \cdots p_r = q_1 \cdots q_s$, then $p_1$ is prime, so $p_1 \mid q_j$ for some $j$, whence $p_1 \sim q_j$; cancel and induct. $\blacksquare$

So fields $\subset$ Euclidean $\subset$ PID $\subset$ UFD $\subset$ domains. None of the inclusions is an equality. $\mathbb{Z}[x]$ is a UFD (Gauss), but not a PID: if $(2, x) = (d)$, then $d \mid 2$ and $d \mid x$, so $d = \pm 1$ or $\pm 2$, and $d = \pm 2$ fails because $2 \nmid x$; $d = \pm 1$ fails because $(2, x) \ne \mathbb{Z}[x]$ (the map $f \mapsto f(0) \bmod 2$ is a surjection onto $\mathbb{Z}/2\mathbb{Z}$ killing $(2, x)$). The ring $\mathbb{Z}[\tfrac{1 + \sqrt{-19}}{2}]$ is a PID that is not Euclidean for any function $N$ (a harder fact we only quote).

### A ring where factorization is not unique

In $\mathbb{Z}[\sqrt{-5}]$ put $N(a + b\sqrt{-5}) = a^2 + 5b^2 = (a + b\sqrt{-5})(a - b\sqrt{-5})$, multiplicative as before. A unit has norm $1$, and $a^2 + 5b^2 = 1$ forces $\pm 1$. The equation $a^2 + 5b^2 = 2$ or $3$ has no integer solution. If $2 = \alpha\beta$ with $\alpha, \beta$ nonunits, both would have norm $2$ (since $N(2) = 4$): impossible, so $2$ is irreducible. In the same way $3$ is irreducible ($N(3) = 9$ would need norm $3$), and $1 \pm \sqrt{-5}$ are irreducible ($N = 6$ would need a factor of norm $2$ or $3$). The elements $2$ and $1 + \sqrt{-5}$ are not associates, since their norms differ. So $6$ has two genuinely different factorizations. In particular $2$ is irreducible but not prime: $2 \mid (1 + \sqrt{-5})(1 - \sqrt{-5})$ and $2$ divides neither factor.

@example
title: The Euclidean algorithm in the Gaussian integers
problem: Find a greatest common divisor of $11 + 3i$ and $1 + 8i$ in $\mathbb{Z}[i]$.
step: Divide $11 + 3i$ by $1 + 8i$: $\dfrac{11 + 3i}{1 + 8i} = \dfrac{(11 + 3i)(1 - 8i)}{65} = \dfrac{35 - 85i}{65} \approx 0.54 - 1.31i$. Round to $q = 1 - i$. The remainder is $11 + 3i - (1 - i)(1 + 8i) = 11 + 3i - (9 + 7i) = 2 - 4i$, and $N(2 - 4i) = 20 < 65 = N(1 + 8i)$.
step: Divide $1 + 8i$ by $2 - 4i$: $\dfrac{(1 + 8i)(2 + 4i)}{20} = \dfrac{-30 + 20i}{20} = -1.5 + i$. Take $q = -1 + i$: the remainder is $1 + 8i - (-1 + i)(2 - 4i) = 1 + 8i - (2 + 6i) = -1 + 2i$, with norm $5 < 20$.
step: Divide $2 - 4i$ by $-1 + 2i$: $\dfrac{(2 - 4i)(-1 - 2i)}{5} = \dfrac{-10}{5} = -2$, an exact division, so the remainder is $0$.
step: The last nonzero remainder $-1 + 2i$ is a gcd. Its associates are $\pm(-1 + 2i)$ and $\pm i(-1 + 2i)$; the one with positive real part and nonnegative imaginary part is $2 + i$ (since $-i(-1 + 2i) = 2 + i$).
answer: A gcd is $2 + i$ (norm $5$), unique up to multiplication by $\pm 1, \pm i$.

@example
title: Non-unique factorization in Z[sqrt(-5)]
problem: Show that $6$ has two essentially different factorizations into irreducibles in $\mathbb{Z}[\sqrt{-5}]$.
step: The norm $N(a + b\sqrt{-5}) = a^2 + 5b^2$ is multiplicative, so a unit has norm $1$, and conversely norm $1$ gives a unit (it divides $1$ by $\alpha\overline{\alpha} = 1$).
step: Norms: $N(2) = 4$, $N(3) = 9$, $N(1 \pm \sqrt{-5}) = 6$. The values $2$ and $3$ are not of the form $a^2 + 5b^2$ (for $b \ne 0$ the value is at least $5$, and for $b = 0$ it is a square).
step: A factorization of $2$ into nonunits needs two factors of norm $2$; impossible, so $2$ is irreducible. Similarly $3$ is irreducible, and $1 \pm \sqrt{-5}$, with norm $6 = 2 \cdot 3$, would need a factor of norm $2$ or $3$.
step: Then $2 \cdot 3 = (1 + \sqrt{-5})(1 - \sqrt{-5}) = 6$ gives two factorizations into irreducibles. They differ: $N(2) = 4 \ne 6 = N(1 \pm \sqrt{-5})$, so $2$ is not an associate of either factor.
answer: $\mathbb{Z}[\sqrt{-5}]$ is not a UFD; consequently it is not a PID and not Euclidean.

@mistakes
- Thinking irreducible and prime are the same. They agree in a PID, but in $\mathbb{Z}[\sqrt{-5}]$ the element $2$ is irreducible and not prime.
- Assuming every PID is Euclidean, or that every UFD is a PID: $\mathbb{Z}[x]$ is a UFD that is not a PID, and $\mathbb{Z}[\frac{1 + \sqrt{-19}}{2}]$ is a PID that is not Euclidean.
- Rounding the quotient incorrectly in the Gaussian Euclidean algorithm. Round the real and imaginary parts of $\alpha/\beta$ separately to the nearest integers; then $N(r) \le N(\beta)/2$.
- Treating a gcd as unique. In $\mathbb{Z}[i]$ a gcd is defined only up to the four units $\pm 1, \pm i$; in $F[x]$ only up to a nonzero constant.

@practice self
prompt: Prove that $\mathbb{Z}[\sqrt{-2}] = \{a + b\sqrt{-2} : a, b \in \mathbb{Z}\}$ is a Euclidean domain with respect to $N(a + b\sqrt{-2}) = a^2 + 2b^2$, and deduce that every ideal of $\mathbb{Z}[\sqrt{-2}]$ is principal.
hint: Imitate the proof for $\mathbb{Z}[i]$: write $\alpha/\beta = x + y\sqrt{-2}$ with rational $x, y$ and round both.
hint: The norm of $x - m + (y - n)\sqrt{-2}$ is $(x - m)^2 + 2(y - n)^2$; bound it by $\frac14 + \frac24$.
solution: The ring is a subring of $\mathbb{C}$, so it is an integral domain. The norm $N(z) = z\overline{z}$ is multiplicative and takes nonnegative integer values, and $N(z) = 0$ only for $z = 0$. Let $\alpha, \beta \in \mathbb{Z}[\sqrt{-2}]$ with $\beta \ne 0$. Then $\alpha/\beta = \alpha\overline{\beta}/N(\beta) = x + y\sqrt{-2}$ with $x, y \in \mathbb{Q}$. Choose integers $m, n$ with $|x - m| \le \frac12$ and $|y - n| \le \frac12$, put $q = m + n\sqrt{-2}$ and $r = \alpha - q\beta \in \mathbb{Z}[\sqrt{-2}]$. Then $N(r) = N(\beta) N\bigl((x - m) + (y - n)\sqrt{-2}\bigr) = N(\beta)\bigl((x - m)^2 + 2(y - n)^2\bigr) \le N(\beta)\bigl(\tfrac14 + \tfrac12\bigr) = \tfrac34 N(\beta) < N(\beta)$. So $\alpha = q\beta + r$ with $r = 0$ or $N(r) < N(\beta)$: the ring is Euclidean, hence a PID by the theorem that every Euclidean domain is a PID.
rubric: Sets up the rational coordinates of $\alpha/\beta$ and rounds both to the nearest integers.
rubric: Computes $N(r)$ using multiplicativity of the norm and the bound $\frac14 + 2 \cdot \frac14 = \frac34 < 1$.
rubric: Concludes Euclidean, then PID by the minimal-norm argument.

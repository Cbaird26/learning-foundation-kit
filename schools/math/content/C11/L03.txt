@article
In $\mathbb{Z}/12\mathbb{Z}$ the ideals $(2)$ and $(3)$ have quotients $\mathbb{Z}/2\mathbb{Z}$ and $\mathbb{Z}/3\mathbb{Z}$, which are fields, while $(4)$ has quotient $\mathbb{Z}/4\mathbb{Z}$, which has the zero divisor $2$. Which ideals give good quotients, and can we recognize them without computing the quotient? Rings in this lesson are commutative with $1$.

### Definitions

A proper ideal $P \subsetneq R$ is **prime** if $ab \in P$ implies $a \in P$ or $b \in P$. A proper ideal $M \subsetneq R$ is **maximal** if the only ideals $J$ with $M \subseteq J \subseteq R$ are $J = M$ and $J = R$.

In $\mathbb{Z}$: $(n)$ is prime if and only if $n = 0$ or $n$ is a prime number (Euclid's lemma), and $(n)$ is maximal if and only if $n$ is prime. The ideal $(0)$ is prime, because $\mathbb{Z}$ has no zero divisors, but not maximal, since $(0) \subsetneq (2) \subsetneq \mathbb{Z}$.

### The two characterizations

**Theorem 1.** An ideal $P$ of $R$ is prime if and only if $R/P$ is an integral domain.

*Proof.* $P$ is proper if and only if $1 \notin P$ if and only if $R/P$ is not the zero ring. Assume $P$ is prime and $(a + P)(b + P) = P$, that is $ab \in P$. Then $a \in P$ or $b \in P$, that is $a + P = P$ or $b + P = P$: $R/P$ has no zero divisors, and it is commutative. Conversely if $R/P$ is a domain and $ab \in P$, then $(a + P)(b + P) = 0$, so $a + P = 0$ or $b + P = 0$, that is $a \in P$ or $b \in P$. $\blacksquare$

**Theorem 2.** An ideal $M$ of $R$ is maximal if and only if $R/M$ is a field.

*Proof.* ($\Leftarrow$) Suppose $R/M$ is a field. Then $M$ is proper, since a field has $1 \ne 0$. Let $J$ be an ideal with $M \subsetneq J$ and choose $a \in J \setminus M$. Then $a + M \ne 0$ in $R/M$, so it has an inverse: there is $b$ with $(a + M)(b + M) = 1 + M$, that is $ab = 1 + m$ for some $m \in M$. Then $1 = ab - m \in J$, because $ab \in J$ (absorption) and $m \in M \subseteq J$. So $J = R$, and $M$ is maximal.

($\Rightarrow$) Suppose $M$ is maximal. Then $R/M$ is a commutative ring with $1 \ne 0$. Let $a + M \ne 0$, so $a \notin M$. The set $J = M + (a) = \{m + ra : m \in M, r \in R\}$ is an ideal containing $M$ and also $a \notin M$, so $M \subsetneq J$ and maximality gives $J = R$. Hence $1 = m + ra$ for some $m \in M$ and $r \in R$, so $(r + M)(a + M) = ra + M = 1 + M$. Every nonzero element of $R/M$ is invertible, so $R/M$ is a field. $\blacksquare$

**Corollary.** Every maximal ideal is prime, since a field is an integral domain. The converse is false: $(0)$ is prime but not maximal in $\mathbb{Z}$.

*Hypotheses.* Commutativity is needed: in the noncommutative ring $M_2(\mathbb{R})$ the zero ideal is a maximal ideal, but $M_2(\mathbb{R})$ is not a field. In a finite commutative ring every prime ideal is maximal, because a finite domain is a field (Lesson 1).

### Examples in $\mathbb{Z}[x]$

The map $f \mapsto f(0)$ is a surjective homomorphism $\mathbb{Z}[x] \to \mathbb{Z}$ with kernel $(x)$, since $f(0) = 0$ if and only if $f = xg$ for a polynomial $g$. Hence $\mathbb{Z}[x]/(x) \cong \mathbb{Z}$, a domain but not a field: $(x)$ is prime and not maximal. The map $f \mapsto f(0) \bmod 2$ is a surjection onto $\mathbb{Z}/2\mathbb{Z}$ with kernel $(2, x)$, so $(2, x)$ is maximal, and $(x) \subsetneq (2, x)$. The ideal $(x^2)$ is not prime: $x \cdot x \in (x^2)$ but $x \notin (x^2)$.

### Prime ideals of $\mathbb{Z}/n\mathbb{Z}$ by brute force

The function below tests the definition of "prime" literally on the ideal $(d)$ of $\mathbb{Z}/n\mathbb{Z}$. It checks every pair of residues, which is evidence in one ring rather than a proof.

```python
def is_prime_ideal(d, n):
    """Is (d) a prime ideal of Z/nZ? (d divides n)"""
    ideal = set(range(0, n, d))
    if len(ideal) == n:          # the whole ring is not prime
        return False
    return all(a in ideal or b in ideal
               for a in range(n) for b in range(n)
               if a * b % n in ideal)


print([d for d in range(1, 25) if 24 % d == 0 and is_prime_ideal(d, 24)])
```

It prints `[2, 3]`, the two primes dividing $24$, and the quotients are $\mathbb{Z}/2\mathbb{Z}$ and $\mathbb{Z}/3\mathbb{Z}$.

@example
title: A maximal ideal of the Gaussian integers
problem: Show that $(2 + i)$ is a maximal ideal of $\mathbb{Z}[i]$ and that $\mathbb{Z}[i]/(2 + i) \cong \mathbb{Z}/5\mathbb{Z}$.
step: Define $\psi\colon \mathbb{Z}[i] \to \mathbb{Z}/5\mathbb{Z}$ by $\psi(a + bi) = (a + 3b) \bmod 5$. It is additive, and it is multiplicative because $3^2 = 9 \equiv -1 \pmod 5$ matches $i^2 = -1$: $\psi((a + bi)(c + di)) = ac - bd + 3(ad + bc)$ and $(a + 3b)(c + 3d) = ac + 3ad + 3bc + 9bd$ agree modulo $5$. Also $\psi(1) = 1$ and $\psi$ is onto.
step: $\psi(2 + i) = 2 + 3 = 5 \equiv 0$, so $(2 + i) \subseteq \ker\psi$.
step: Count the cosets of $(2 + i)$. Modulo this ideal $i \equiv -2$, so $a + bi \equiv a - 2b$ is congruent to an integer; and $(2 + i)(2 - i) = 5$ gives $5 \equiv 0$. So every coset is that of one of $0, 1, 2, 3, 4$, and $\mathbb{Z}[i]/(2 + i)$ has at most $5$ elements.
step: The map $\bar\psi\colon \mathbb{Z}[i]/(2 + i) \to \mathbb{Z}/5\mathbb{Z}$ induced by $\psi$ is a surjection from a set of at most $5$ elements onto a set of $5$ elements, so it is a bijection, hence an isomorphism. The quotient is a field, so by Theorem 2 the ideal $(2 + i)$ is maximal.
answer: $\mathbb{Z}[i]/(2 + i) \cong \mathbb{Z}/5\mathbb{Z}$, a field, so $(2 + i)$ is maximal.

@example
title: Prime and maximal ideals of Z/18Z
problem: Decide which ideals of $\mathbb{Z}/18\mathbb{Z}$ are prime and which are maximal.
step: The ideals of $\mathbb{Z}/18\mathbb{Z}$ are $(d)$ for $d \in \{1, 2, 3, 6, 9, 18\}$, with $(\mathbb{Z}/18\mathbb{Z})/(d) \cong \mathbb{Z}/d\mathbb{Z}$; here $(18) = (0)$ and $(1)$ is the whole ring.
step: By Theorem 1 an ideal is prime if and only if $\mathbb{Z}/d\mathbb{Z}$ is a domain, which happens for $d = 2, 3$ (primes). The quotients $\mathbb{Z}/6\mathbb{Z}$, $\mathbb{Z}/9\mathbb{Z}$ and $\mathbb{Z}/18\mathbb{Z}$ have zero divisors, and $(1)$ is not proper.
step: $\mathbb{Z}/2\mathbb{Z}$ and $\mathbb{Z}/3\mathbb{Z}$ are fields, so by Theorem 2, $(2)$ and $(3)$ are maximal. Consistently with the finite-ring remark, prime and maximal ideals coincide here.
answer: The prime ideals are $(2)$ and $(3)$, and both are maximal; $(0)$, $(6)$, $(9)$ are neither.

@mistakes
- Saying "prime ideal" and "maximal ideal" mean the same thing. They differ in $\mathbb{Z}$ at $(0)$, and in $\mathbb{Z}[x]$ at $(x)$ and $(2)$, whose quotients are domains but not fields.
- Treating $R$ itself as a maximal or prime ideal: both definitions require a proper ideal, matching "the quotient has $1 \ne 0$".
- Testing primality of $(d)$ on generators only: $(6)$ in $\mathbb{Z}$ is not prime although $6 = 2 \cdot 3$ is "built from primes"; one needs $ab \in (6) \Rightarrow a \in (6)$ or $b \in (6)$, and $2 \cdot 3 \in (6)$ with $2, 3 \notin (6)$.
- Using Theorem 2 without commutativity: $M_2(\mathbb{R})$ has the maximal ideal $(0)$ but is not a field.

```python
def maximal_ideals(n):
    """Divisors d of n such that (d) is a maximal ideal of Z/nZ."""
    divisors = [d for d in range(1, n + 1) if n % d == 0]
    ideal = {d: set(range(0, n, d)) for d in divisors}
    result = []
    for d in divisors:
        if len(ideal[d]) == n:      # the whole ring is not proper
            continue
        bigger = [e for e in divisors
                  if len(ideal[e]) < n and ideal[d] < ideal[e]]
        if not bigger:
            result.append(d)
    return result
```
hint: Build each ideal $(d)$ as a Python set and compare sets with `<` (proper subset).
solution: For each divisor $d$, build the ideal $\{0, d, 2d, \dots\}$. Skip $d = 1$, which is the whole ring. The ideal $(d)$ is maximal when no other proper ideal $(e)$ strictly contains it.

@article
The intermediate fields of $\mathbb{Q}(\sqrt{2}, \sqrt{3})/\mathbb{Q}$ are $\mathbb{Q}$, $\mathbb{Q}(\sqrt{2})$, $\mathbb{Q}(\sqrt{3})$, $\mathbb{Q}(\sqrt{6})$ and the whole field: five fields. The group $\mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}$ also has exactly five subgroups. This is no accident. Galois (about 1830) turned questions about fields into questions about finite groups; the dictionary is the fundamental theorem.

### Automorphism groups and fixed fields

For a field extension $E/F$ let $\operatorname{Gal}(E/F)$ be the group of field automorphisms $\sigma$ of $E$ with $\sigma(a) = a$ for all $a \in F$. For a subgroup $H$ of $\operatorname{Aut}(E)$ the **fixed field** is $E^H = \{x \in E : \sigma(x) = x \text{ for all } \sigma \in H\}$, a subfield. If $f \in F[x]$ and $f(\alpha) = 0$, then for $\sigma \in \operatorname{Gal}(E/F)$ we have $f(\sigma\alpha) = \sigma(f(\alpha)) = 0$: **automorphisms permute the roots of each polynomial over $F$**. So $\operatorname{Gal}(E/F)$ acts on the roots of $f$ in $E$, faithfully if $E$ is generated over $F$ by those roots.

**Theorem 1.** If $E/F$ is finite, then $|\operatorname{Gal}(E/F)| \le [E:F]$.

*Proof.* We show more: for any field embedding $\tau\colon F \to K$, the number of extensions of $\tau$ to an embedding $E \to K$ is at most $[E:F]$. Induct on $[E:F]$; the case $E = F$ is clear. Choose $\alpha \in E \setminus F$ with minimal polynomial $m$ of degree $d > 1$. An extension to $F(\alpha) \cong F[x]/(m)$ is determined by the image of $\alpha$, a root of $\tau(m)$ in $K$: at most $d$ choices. Each embedding of $F(\alpha)$ extends to $E$ in at most $[E:F(\alpha)]$ ways by induction. The total is at most $d\,[E:F(\alpha)] = [E:F]$. Take $K = E$, $\tau = $ inclusion. $\blacksquare$

**Theorem 2 (Artin).** If $H$ is a finite group of automorphisms of $E$, then $[E:E^H] \le |H|$. Consequently $[E:E^H] = |H|$ and $\operatorname{Gal}(E/E^H) = H$.

*Proof.* Let $K = E^H$ and $H = \{\sigma_1 = \mathrm{id}, \dots, \sigma_n\}$. Suppose $\alpha_1, \dots, \alpha_m \in E$ with $m > n$. The $n$ equations $\sum_{j}\sigma_i(\alpha_j)x_j = 0$ ($i = 1, \dots, n$) in $m > n$ unknowns have a nonzero solution $x \in E^m$. Choose one with the fewest nonzero entries and scale so that $x_1 = 1$ after reordering. Applying $\sigma \in H$ to the $i$-th equation gives $\sum_j\sigma\sigma_i(\alpha_j)\sigma(x_j) = 0$; as $i$ varies, $\sigma\sigma_i$ runs over $H$, so $(\sigma(x_j))_j$ is also a solution. Then $(\sigma(x_j) - x_j)_j$ is a solution with first entry $0$ and a smaller support, hence zero by minimality. Therefore every $x_j \in K$. The equation for $\sigma_1 = \mathrm{id}$ says $\sum_j\alpha_jx_j = 0$ with $x_j \in K$ not all zero: the $\alpha_j$ are dependent over $K$. So $[E:K] \le n$. Finally $H \subseteq \operatorname{Gal}(E/K)$, so $|H| \le |\operatorname{Gal}(E/K)| \le [E:K] \le |H|$ by Theorem 1, and all are equal. $\blacksquare$

A finite extension $E/F$ is **Galois** if $E^{\operatorname{Gal}(E/F)} = F$; then $[E:F] = |\operatorname{Gal}(E/F)|$ by Theorem 2. We use the standard fact that in characteristic $0$, $E/F$ is Galois if and only if $E$ is the splitting field of some polynomial over $F$.

### The fundamental theorem

**Theorem (fundamental theorem of Galois theory).** Let $E/F$ be a finite Galois extension with group $G$. The maps $H \mapsto E^H$ and $K \mapsto \operatorname{Gal}(E/K)$ are mutually inverse, inclusion-reversing bijections between the subgroups $H$ of $G$ and the fields $K$ with $F \subseteq K \subseteq E$. Moreover $[E:E^H] = |H|$ and $[E^H:F] = [G:H]$. The extension $E^H/F$ is Galois if and only if $H$ is normal in $G$, and then $\operatorname{Gal}(E^H/F) \cong G/H$.

*Sketch.* By Theorem 2, $\operatorname{Gal}(E/E^H) = H$ and $[E:E^H] = |H|$; the tower law gives $[E^H:F] = |G|/|H|$. For an intermediate $K$, the extension $E/K$ is again a splitting field, so Galois, and $E^{\operatorname{Gal}(E/K)} = K$. For the last claim, $\sigma(E^H) = E^{\sigma H\sigma^{-1}}$, so $E^H$ is stable under every $\sigma \in G$ (which is what makes $E^H/F$ Galois) if and only if $\sigma H\sigma^{-1} = H$ for all $\sigma$. Restriction to $E^H$ then gives a surjection $G \to \operatorname{Gal}(E^H/F)$ with kernel $H$. $\blacksquare$

### Cyclotomic fields and a code check

The Galois group of a cyclotomic field is $\operatorname{Gal}(\mathbb{Q}(\zeta_n)/\mathbb{Q}) \cong (\mathbb{Z}/n\mathbb{Z})^\times$, via $\sigma_a(\zeta_n) = \zeta_n^a$ (the polynomial $\Phi_n$ is irreducible; we proved this for prime $n$). So the subfields of $\mathbb{Q}(\zeta_n)$ correspond to the subgroups of this unit group. The code lists subgroups by closing a subgroup under adjoining one more element; it counts them for $n = 7$, a prime, where the group is cyclic of order $6$.

```python
from math import gcd


def closure(gens, n):
    """Subgroup of (Z/nZ)^x generated by gens, as a sorted tuple."""
    elems, frontier = {1}, [1]
    while frontier:
        x = frontier.pop()
        for g in gens:
            y = x * g % n
            if y not in elems:
                elems.add(y)
                frontier.append(y)
    return tuple(sorted(elems))


n = 7
units = [a for a in range(1, n) if gcd(a, n) == 1]
print(sorted({closure([a], n) for a in units}))
```

It prints the four subgroups `(1,)`, `(1, 2, 3, 4, 5, 6)`, `(1, 2, 4)` and `(1, 6)` of $(\mathbb{Z}/7\mathbb{Z})^\times$ in sorted order of tuples. By the fundamental theorem they are the Galois groups of $\mathbb{Q}(\zeta_7)$ over $\mathbb{Q}(\zeta_7)$ itself, over $\mathbb{Q}$, over the quadratic field $\mathbb{Q}(\sqrt{-7})$ and over the real cubic field $\mathbb{Q}(\zeta_7 + \zeta_7^{-1})$ (the subgroup $\{1, 6\}$ is complex conjugation). The program checks one cyclic case; the cyclic group of order $6$ has exactly one subgroup for each divisor of $6$ by group theory.

@example
title: The Galois group and lattice of Q(sqrt 2, sqrt 3)
problem: Find $\operatorname{Gal}(\mathbb{Q}(\sqrt{2}, \sqrt{3})/\mathbb{Q})$ and all intermediate fields.
step: The field is the splitting field of $(x^2 - 2)(x^2 - 3)$, which is separable, so the extension is Galois and $|G| = [E:\mathbb{Q}] = 4$ by Lesson 8.
step: An automorphism is determined by $\sigma(\sqrt{2}) = \pm\sqrt{2}$ and $\sigma(\sqrt{3}) = \pm\sqrt{3}$, giving four candidates, and all four exist by $|G| = 4$. Define $\sigma\colon \sqrt{2} \mapsto -\sqrt{2},\ \sqrt{3} \mapsto \sqrt{3}$ and $\tau\colon \sqrt{2} \mapsto \sqrt{2},\ \sqrt{3} \mapsto -\sqrt{3}$. Then $\sigma^2 = \tau^2 = 1$ and $\sigma\tau = \tau\sigma$, so $G = \{1, \sigma, \tau, \sigma\tau\} \cong \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}$.
step: The subgroups are $1$, $\langle\sigma\rangle$, $\langle\tau\rangle$, $\langle\sigma\tau\rangle$ and $G$. Fixed fields: $\sigma$ fixes $\sqrt{3}$, so $E^{\langle\sigma\rangle} = \mathbb{Q}(\sqrt{3})$ (degree $[G:H] = 2$); $\tau$ fixes $\sqrt{2}$, so $E^{\langle\tau\rangle} = \mathbb{Q}(\sqrt{2})$; $\sigma\tau$ sends $\sqrt{6} = \sqrt{2}\sqrt{3}$ to $(-\sqrt{2})(-\sqrt{3}) = \sqrt{6}$, so $E^{\langle\sigma\tau\rangle} = \mathbb{Q}(\sqrt{6})$.
step: The lattice: $E = E^{1}$, three quadratic fields $\mathbb{Q}(\sqrt{3}), \mathbb{Q}(\sqrt{2}), \mathbb{Q}(\sqrt{6})$ (all Galois over $\mathbb{Q}$ because $G$ is abelian), and $\mathbb{Q} = E^G$.
answer: $G \cong V_4$; intermediate fields $\mathbb{Q}$, $\mathbb{Q}(\sqrt{2})$, $\mathbb{Q}(\sqrt{3})$, $\mathbb{Q}(\sqrt{6})$, $E$.

@example
title: The Galois group and lattice of the splitting field of x^3 - 2
problem: Find the Galois group of $x^3 - 2$ over $\mathbb{Q}$ and match its subgroups with the intermediate fields.
step: Let $\omega = e^{2\pi i/3}$. The roots are $r_0 = \sqrt[3]{2}$, $r_1 = \omega r_0$, $r_2 = \omega^2 r_0$, and the splitting field is $E = \mathbb{Q}(r_0, \omega)$ of degree $6$ (Lesson 8). It is Galois, so $|G| = 6$.
step: $G$ acts faithfully on the three roots, so it embeds into $S_3$; since $|G| = 6 = |S_3|$, we get $G \cong S_3$. Explicitly the 3-cycle $r_0 \to r_1 \to r_2 \to r_0$ has $\omega = r_1/r_0 \mapsto r_2/r_1 = \omega$, so it fixes $\omega$.
step: Subgroups of $S_3$: $1$; three of order $2$, namely $\langle(r_1\,r_2)\rangle$, $\langle(r_0\,r_2)\rangle$, $\langle(r_0\,r_1)\rangle$; $A_3 = \langle(r_0\,r_1\,r_2)\rangle$ of order $3$; and $S_3$. Six subgroups in all: $1$, three of order $2$, $A_3$ and $S_3$.
step: Fixed fields: the transposition fixing $r_i$ has fixed field $\mathbb{Q}(r_i)$, of degree $[G:H] = 3$ (so $\mathbb{Q}(\sqrt[3]{2})$, $\mathbb{Q}(\omega\sqrt[3]{2})$, $\mathbb{Q}(\omega^2\sqrt[3]{2})$); $A_3$ fixes $\mathbb{Q}(\omega)$, of degree $2$; $S_3$ fixes $\mathbb{Q}$ and $1$ fixes $E$.
step: Normality: only $A_3$ is normal in $S_3$, so $\mathbb{Q}(\omega)/\mathbb{Q}$ is Galois with group $S_3/A_3 \cong \mathbb{Z}/2\mathbb{Z}$, while $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ is not Galois.
answer: $G \cong S_3$; the lattice has six fields: $\mathbb{Q}$, $\mathbb{Q}(\omega)$, three conjugate cubic fields $\mathbb{Q}(r_i)$, and $E$.

@mistakes
- Assuming every extension is Galois. $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ has degree $3$ but only the identity automorphism (any automorphism sends $\sqrt[3]{2}$ to a real cube root of $2$, which is itself), so $|\operatorname{Gal}| = 1 < 3$.
- Reading the correspondence as order-preserving. Larger subgroups have smaller fixed fields: $H \subseteq H'$ gives $E^{H'} \subseteq E^H$.
- Confusing $[E^H:F]$ with $|H|$. The fixed field of $H$ has degree $[G:H] = |G|/|H|$ over $F$; it is $[E:E^H]$ that equals $|H|$.
- Forgetting that the fixed field of a non-normal subgroup gives a non-Galois extension: the fixed field of an order-$2$ subgroup of $S_3$ is a cubic field with trivial automorphism group.

model:
```python
from math import gcd


def _closure(gens, n):
    """Subgroup of the unit group generated by gens."""
    elems, frontier = {1}, [1]
    while frontier:
        x = frontier.pop()
        for g in gens:
            y = x * g % n
            if y not in elems:
                elems.add(y)
                frontier.append(y)
    return tuple(sorted(elems))


def unit_subgroups(n):
    """All subgroups of (Z/nZ)^x as sorted tuples, sorted."""
    units = [a for a in range(1, n) if gcd(a, n) == 1]
    found = {(1,)}
    todo = [(1,)]
    while todo:
        h = todo.pop()
        for g in units:
            k = _closure(list(h) + [g], n)
            if k not in found:
                found.add(k)
                todo.append(k)
    return sorted(found)
```
hint: Keep a set of subgroups found so far. For each subgroup `h` and each unit `g`, compute the closure of `h` together with `g`; if it is new, record it and process it later.
solution: Every subgroup of a finite group is reached from the trivial subgroup by adjoining one element at a time, so this search finds all subgroups. The closure of a set of generators is computed by repeatedly multiplying elements by generators, which in a finite group yields the generated subgroup because inverses are positive powers. For $n = 8$ the unit group is $\{1, 3, 5, 7\} \cong V_4$ with five subgroups, which matches the five subfields of $\mathbb{Q}(\zeta_8) = \mathbb{Q}(i, \sqrt{2})$. For $n = 24$ the group is $(\mathbb{Z}/2\mathbb{Z})^3$ with $16$ subgroups. This enumerates subgroups for small $n$; the identification of $\operatorname{Gal}(\mathbb{Q}(\zeta_n)/\mathbb{Q})$ with the unit group relies on the irreducibility of $\Phi_n$.

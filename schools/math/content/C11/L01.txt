@article
In $\mathbb{Z}/12\mathbb{Z}$ we have $3 \cdot 4 = 0$ although $3 \ne 0$ and $4 \ne 0$. In $\mathbb{Z}$ that never happens. Group theory studied one operation; most of the number systems you know have two, and the way they interact decides what algebra is possible. A **ring** records exactly the arithmetic you can do with addition, subtraction and multiplication.

### Definition of a ring

A **ring** is a set $R$ with operations $+$ and $\cdot$ such that

1. $(R, +)$ is an abelian group with identity $0$;
2. multiplication is associative: $(ab)c = a(bc)$;
3. multiplication has an identity $1$ with $1a = a1 = a$;
4. the distributive laws hold: $a(b + c) = ab + ac$ and $(a + b)c = ac + bc$.

In this course every ring has a $1$, and $R$ is **commutative** if $ab = ba$ for all $a, b$. (Some books omit axiom 3; we do not.) If $1 = 0$ then $a = 1a = 0a = 0$ for all $a$, so $R = \{0\}$ is the **zero ring**; every other ring has $1 \ne 0$.

Examples: $\mathbb{Z}$, $\mathbb{Q}$, $\mathbb{R}$, $\mathbb{C}$, $\mathbb{Z}/n\mathbb{Z}$, the polynomial ring $\mathbb{Z}[x]$, the Gaussian integers $\mathbb{Z}[i] = \{a + bi : a, b \in \mathbb{Z}\}$, and the ring $M_2(\mathbb{R})$ of $2 \times 2$ real matrices, which is a ring but not commutative.

**Proposition.** In every ring, $0a = 0$ and $(-a)b = -(ab)$. *Proof.* $0a = (0 + 0)a = 0a + 0a$; cancel $0a$ in the group $(R, +)$ to get $0a = 0$. Then $ab + (-a)b = (a + (-a))b = 0b = 0$, so $(-a)b = -(ab)$. $\blacksquare$

### Units, zero divisors, domains

An element $u$ is a **unit** if $uv = vu = 1$ for some $v \in R$; the units form a group $R^\times$. A nonzero $a$ is a **zero divisor** if $ab = 0$ for some nonzero $b$. A **field** is a commutative ring with $1 \ne 0$ in which every nonzero element is a unit. An **integral domain** is a commutative ring with $1 \ne 0$ and no zero divisors. A unit is never a zero divisor (if $ab = 0$ and $a$ is a unit, then $b = a^{-1}ab = 0$), so every field is a domain. The converse fails: $\mathbb{Z}$ is a domain, and its only units are $\pm 1$.

In a domain we may cancel: if $a \ne 0$ and $ab = ac$ then $a(b - c) = 0$, so $b = c$.

**Theorem.** A finite integral domain $D$ is a field.

*Proof.* Let $a \in D$ with $a \ne 0$. Define $\mu\colon D \to D$ by $\mu(x) = ax$. If $\mu(x) = \mu(y)$ then $ax = ay$, so $x = y$ by cancellation: $\mu$ is injective. An injective map of a finite set to itself is surjective, so $ax = 1$ for some $x$. Thus every nonzero $a$ is a unit. $\blacksquare$

The hypothesis "finite" is essential: $\mathbb{Z}$ is an infinite domain that is not a field. The theorem also shows when $\mathbb{Z}/n\mathbb{Z}$ is a domain: if $n = ab$ with $1 < a, b < n$ then $ab = 0$ in $\mathbb{Z}/n\mathbb{Z}$ with $a, b \ne 0$, so $n$ must be prime; conversely $p \mid ab$ forces $p \mid a$ or $p \mid b$ (Euclid's lemma). Hence $\mathbb{Z}/n\mathbb{Z}$ is a domain, and then a field, if and only if $n$ is prime.

### Subrings

A subset $S \subseteq R$ is a **subring** if it contains $1$ and is closed under subtraction and multiplication. (Then it is a ring with the inherited operations.) For example $\mathbb{Z}[\sqrt{2}] = \{a + b\sqrt{2} : a, b \in \mathbb{Z}\}$ is a subring of $\mathbb{R}$: it contains $1$, it is closed under subtraction, and $(a + b\sqrt{2})(c + d\sqrt{2}) = (ac + 2bd) + (ad + bc)\sqrt{2}$. By contrast $2\mathbb{Z}$ is closed under both operations but omits $1$, so it is not a subring of $\mathbb{Z}$ (it is an *ideal*, the subject of next week).

### Computing in $\mathbb{Z}/n\mathbb{Z}$

An element $a$ of $\mathbb{Z}/n\mathbb{Z}$ is a unit if and only if $\gcd(a, n) = 1$ (Bézout), and a nonzero non-unit is a zero divisor. The following code lists both kinds; it is evidence for the pattern, not a proof.

```python
from math import gcd


def units(n):
    """Units of Z/nZ, as integers in range(n)."""
    return [a for a in range(n) if gcd(a, n) == 1]


def zero_divisors(n):
    """Nonzero a in Z/nZ with a*b = 0 for some nonzero b."""
    return [a for a in range(1, n)
            if any(a * b % n == 0 for b in range(1, n))]


print(units(12), zero_divisors(12))
```

The program prints `[1, 5, 7, 11] [2, 3, 4, 6, 8, 9, 10]`: every element of $\mathbb{Z}/12\mathbb{Z}$ is zero, a unit or a zero divisor, never two of these.

@example
title: Units and zero divisors of Z/18Z
problem: Find all units and all zero divisors of $\mathbb{Z}/18\mathbb{Z}$ and verify that every nonzero element is one or the other.
step: An element $a$ is a unit exactly when $\gcd(a, 18) = 1$. Since $18 = 2 \cdot 3^2$, this means $a$ is odd and not divisible by $3$.
step: The units are $1, 5, 7, 11, 13, 17$: six of them, matching $\varphi(18) = 18 (1 - \tfrac12)(1 - \tfrac13) = 6$.
step: Any other nonzero $a$ has $d = \gcd(a, 18) > 1$. Then $b = 18/d$ satisfies $0 < b < 18$ and $ab = (a/d) \cdot 18 \equiv 0$, so $a$ is a zero divisor.
step: Count: $17$ nonzero elements, $6$ units, hence $17 - 6 = 11$ zero divisors, namely $2, 3, 4, 6, 8, 9, 10, 12, 14, 15, 16$.
answer: Units $1, 5, 7, 11, 13, 17$; the other $11$ nonzero elements are zero divisors.

@example
title: The units of the Gaussian integers
problem: Show that the units of $\mathbb{Z}[i]$ are exactly $1, -1, i, -i$.
step: Define the norm $N(a + bi) = a^2 + b^2 = (a + bi)(a - bi)$, a nonnegative integer. It is multiplicative, $N(zw) = N(z) N(w)$, because $N(z) = z \overline{z}$ and conjugation respects products.
step: If $zw = 1$ then $N(z) N(w) = N(1) = 1$, so $N(z) = 1$ because both factors are positive integers.
step: Solve $a^2 + b^2 = 1$ in integers: $(a, b) = (\pm 1, 0)$ or $(0, \pm 1)$, giving $z = \pm 1, \pm i$.
step: Conversely each of these is a unit: $1 \cdot 1 = 1$, $(-1)(-1) = 1$, $i \cdot (-i) = 1$. So $\mathbb{Z}[i]^\times = \{1, -1, i, -i\}$.
answer: $\mathbb{Z}[i]^\times = \{\pm 1, \pm i\}$, a cyclic group of order $4$.

@mistakes
- Forgetting that the ring axioms do not include commutativity: in $M_2(\mathbb{R})$, $AB \ne BA$ in general, and the identity $(a + b)^2 = a^2 + 2ab + b^2$ needs $ab = ba$.
- Calling $\mathbb{Z}/n\mathbb{Z}$ a field for every $n$. It is a field only when $n$ is prime; $\mathbb{Z}/12\mathbb{Z}$ has zero divisors such as $3$ and $4$.
- Treating "closed under addition and multiplication" as the subring test. The subring must contain $1$ and be closed under negatives (subtraction); $\mathbb{N}$ and $2\mathbb{Z}$ fail in different ways.
- Canceling a factor in a ring with zero divisors: in $\mathbb{Z}/12\mathbb{Z}$, $3 \cdot 4 = 3 \cdot 8$ but $4 \ne 8$.

@practice code
prompt: An element $a$ of $\mathbb{Z}/n\mathbb{Z}$ is **nilpotent** if $a^k \equiv 0 \pmod{n}$ for some integer $k \ge 1$. Computing powers up to $a^n$ suffices, since $a^k = 0$ for some $k$ implies $a^n = 0$.

```python

```
tests:
```python
assert nilpotents(12) == [0, 6]
assert nilpotents(8) == [0, 2, 4, 6]
assert nilpotents(7) == [0]
assert nilpotents(1) == [0]
assert nilpotents(72) == list(range(0, 72, 6))
```
model:
```python
def nilpotents(n):
    """Sorted nilpotent elements of Z/nZ."""
    result = []
    for a in range(n):
        if pow(a, n, n) == 0:
            result.append(a)
    return result
```
hint: Use `pow(a, n, n)` to test whether some power of `a` vanishes modulo `n`.
solution: If $a$ is nilpotent, every prime $p$ dividing $n$ divides $a$ (otherwise $a$ is invertible modulo $p$ and no power of $a$ vanishes modulo $p$). Then $p^n \mid a^n$, and $p^n$ is divisible by the full power of $p$ in $n$, so $n \mid a^n$. Hence testing the single power $a^n$ with `pow(a, n, n)` decides nilpotency. The output for $n = 72 = 2^3 \cdot 3^2$ is the multiples of $6 = 2 \cdot 3$, the product of the distinct primes dividing $n$: a pattern seen in cases, which this prime-by-prime argument explains.

hint: Test the three conditions: contains $1$, closed under subtraction, closed under multiplication.
solution: Fractions with denominator a power of $2$ are closed under subtraction and multiplication and contain $1$, and so are fractions with odd denominator (a product or difference of odd denominators is odd). @quiz num
prompt: An element $e$ of a ring is **idempotent** if $e^2 = e$. How many idempotent elements does $\mathbb{Z}/60\mathbb{Z}$ have?
answer: 8
check: sum(1 for e in range(60) if e * e % 60 == e)
hint: Since $60 = 4 \cdot 3 \cdot 5$, think of $e$ as a triple of residues modulo $4$, $3$ and $5$. In each residue ring $e^2 = e$ has only the solutions $0$ and $1$.
solution: By the Chinese remainder theorem, $e^2 \equiv e \pmod{60}$ if and only if it holds modulo $4$, $3$ and $5$. Modulo a prime power $p^k$, $e(e - 1) \equiv 0$ forces $e \equiv 0$ or $1$ because $e$ and $e - 1$ are coprime. That gives $2$ choices for each of the $3$ prime powers, so $2^3 = 8$ idempotents.

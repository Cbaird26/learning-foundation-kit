@article
The numbers $\sqrt{2}$ and $\sqrt{3}$ each satisfy a quadratic equation over $\mathbb{Q}$. What is the smallest polynomial equation satisfied by $\sqrt{2} + \sqrt{3}$? Is it of degree $2$, $3$ or $4$? Answering this means studying fields inside bigger fields.

### Extensions and degree

A **field extension** $E/F$ is a field $E$ containing a subfield $F$. Then $E$ is a vector space over $F$, and its dimension is the **degree** $[E:F]$; the extension is **finite** if $[E:F] < \infty$. Examples: $[\mathbb{C}:\mathbb{R}] = 2$ with basis $1, i$; $[\mathbb{Q}(\sqrt{2}):\mathbb{Q}] = 2$ with basis $1, \sqrt{2}$; $[\mathbb{R}:\mathbb{Q}]$ is infinite.

For $\alpha \in E$ let $F(\alpha)$ be the smallest subfield of $E$ containing $F$ and $\alpha$, and $F[\alpha] = \{f(\alpha) : f \in F[x]\}$. An element $\alpha$ is **algebraic over $F$** if $f(\alpha) = 0$ for some nonzero $f \in F[x]$, and **transcendental** otherwise.

**Theorem (minimal polynomial).** Let $\alpha \in E$ be algebraic over $F$. There is a unique monic irreducible polynomial $m \in F[x]$ with $m(\alpha) = 0$, and $f(\alpha) = 0$ if and only if $m \mid f$. Moreover $F(\alpha) = F[\alpha] \cong F[x]/(m)$, and $[F(\alpha):F] = \deg m$, with basis $1, \alpha, \dots, \alpha^{d-1}$ where $d = \deg m$.

*Proof.* The evaluation map $\mathrm{ev}\colon F[x] \to E$, $f \mapsto f(\alpha)$, is a ring homomorphism with image $F[\alpha]$, a subring of a field and therefore an integral domain. Its kernel is a nonzero ideal (since $\alpha$ is algebraic) of the PID $F[x]$, so $\ker = (m)$ for a unique monic $m$. By the first isomorphism theorem $F[x]/(m) \cong F[\alpha]$, a domain, so $(m)$ is a prime ideal. Also $m$ is not a unit, since $\mathrm{ev}(1) = 1 \ne 0$. If $m = gh$, then $gh \in (m)$, so (say) $g = mk$ and $m = mkh$, which gives $kh = 1$ and $h$ is a unit: $m$ is irreducible. In a PID, an irreducible element generates a maximal ideal (an ideal $(g) \supseteq (m)$ means $g \mid m$, so $g$ is a unit or an associate of $m$), so $F[x]/(m)$ is a field. Hence $F[\alpha]$ is a field containing $F$ and $\alpha$, and any subfield containing $F$ and $\alpha$ contains $F[\alpha]$, so $F[\alpha] = F(\alpha)$. By the division algorithm every $f$ equals $qm + r$ with $\deg r < d$, so $f(\alpha) = r(\alpha)$ and $1, \alpha, \dots, \alpha^{d-1}$ span; they are independent because a nonzero combination would be a polynomial of degree $< d$ vanishing at $\alpha$, not divisible by $m$. $\blacksquare$

### The tower law

**Theorem.** If $F \subseteq K \subseteq E$ are fields, then $[E:F] = [E:K]\,[K:F]$ (with the convention that both sides are infinite if either factor is).

*Proof.* Let $x_1, \dots, x_s$ be a basis of $K$ over $F$ and $y_1, \dots, y_t$ a basis of $E$ over $K$. We claim the $st$ products $x_iy_j$ form a basis of $E$ over $F$. *Spanning:* each $e \in E$ is $\sum_j k_jy_j$ with $k_j \in K$, and each $k_j = \sum_i c_{ij}x_i$ with $c_{ij} \in F$, so $e = \sum_{i,j}c_{ij}x_iy_j$. *Independence:* if $\sum_{i,j}c_{ij}x_iy_j = 0$ with $c_{ij} \in F$, then $\sum_j\bigl(\sum_ic_{ij}x_i\bigr)y_j = 0$, so each $\sum_ic_{ij}x_i = 0$ by independence of the $y_j$ over $K$, and then each $c_{ij} = 0$ by independence of the $x_i$ over $F$. $\blacksquare$

**Corollary.** If $E/F$ is finite and $\alpha \in E$, then $\deg(\alpha/F)$ divides $[E:F]$, because $[E:F] = [E:F(\alpha)]\,[F(\alpha):F]$. So if $[E:F]$ is prime, every element of $E \setminus F$ generates $E$.

### Computing degrees

*Example: $\mathbb{Q}(\sqrt{2}, \sqrt{3})$.* First $\sqrt{3} \notin \mathbb{Q}(\sqrt{2})$: if $\sqrt{3} = a + b\sqrt{2}$ with $a, b \in \mathbb{Q}$, squaring gives $3 = a^2 + 2b^2 + 2ab\sqrt{2}$, so $ab = 0$; then $a^2 = 3$ or $2b^2 = 3$, which have no rational solution. So $x^2 - 3$ has no root in $\mathbb{Q}(\sqrt{2})$ and is irreducible there, and $[\mathbb{Q}(\sqrt{2}, \sqrt{3}):\mathbb{Q}] = 2 \cdot 2 = 4$ with basis $1, \sqrt{2}, \sqrt{3}, \sqrt{6}$.

### Degrees by linear algebra

The degree of $\alpha$ over $\mathbb{Q}$ is the least $d$ for which $1, \alpha, \dots, \alpha^d$ are linearly dependent. In a field with a known basis this is a rank computation. Below, an element $a + b\sqrt{2} + c\sqrt{3} + d\sqrt{6}$ of $\mathbb{Q}(\sqrt{2}, \sqrt{3})$ is the tuple `(a, b, c, d)`.

```python
from fractions import Fraction


def rank(rows):
    """Rank of a list of vectors over Q (Gaussian elimination)."""
    m = [[Fraction(x) for x in row] for row in rows]
    r = 0
    for col in range(len(m[0])):
        piv = next((i for i in range(r, len(m)) if m[i][col] != 0), None)
        if piv is None:
            continue
        m[r], m[piv] = m[piv], m[r]
        for i in range(r + 1, len(m)):
            f = m[i][col] / m[r][col]
            m[i] = [a - f * b for a, b in zip(m[i], m[r])]
        r += 1
    return r


def degree(alpha, mul, one):
    """Least d with 1, alpha, ..., alpha^d dependent over Q."""
    powers = [one]
    while True:
        powers.append(mul(powers[-1], alpha))
        if rank(powers) < len(powers):
            return len(powers) - 1


def mul23(u, v):
    """Product in Q(sqrt 2, sqrt 3), basis 1, sqrt2, sqrt3, sqrt6."""
    a, b, c, d = u
    e, f, g, h = v
    return (a * e + 2 * b * f + 3 * c * g + 6 * d * h,
            a * f + b * e + 3 * (c * h + d * g),
            a * g + c * e + 2 * (b * h + d * f),
            a * h + d * e + b * g + c * f)


print(degree((0, 1, 1, 0), mul23, (1, 0, 0, 0)))
```

It prints `4`: the powers of $\sqrt{2} + \sqrt{3}$ are $1$, $(0,1,1,0)$, $(5,0,0,2)$, $(0,11,9,0)$, $(49,0,0,20)$, and the first four are independent while all five are dependent. This is a computation in one field; the tower law explains why the answer cannot exceed $4$.

@example
title: The minimal polynomial of the sum of two square roots
problem: Find the minimal polynomial of $\alpha = \sqrt{2} + \sqrt{3}$ over $\mathbb{Q}$ and show that $\mathbb{Q}(\alpha) = \mathbb{Q}(\sqrt{2}, \sqrt{3})$.
step: Compute powers: $\alpha^2 = 5 + 2\sqrt{6}$ and $\alpha^3 = 11\sqrt{2} + 9\sqrt{3}$.
step: Then $\alpha^3 - 9\alpha = 11\sqrt{2} + 9\sqrt{3} - 9\sqrt{2} - 9\sqrt{3} = 2\sqrt{2}$, so $\sqrt{2} = (\alpha^3 - 9\alpha)/2 \in \mathbb{Q}(\alpha)$, and then $\sqrt{3} = \alpha - \sqrt{2} \in \mathbb{Q}(\alpha)$. Hence $\mathbb{Q}(\alpha) = \mathbb{Q}(\sqrt{2}, \sqrt{3})$, whose degree over $\mathbb{Q}$ is $4$.
step: By the minimal polynomial theorem the minimal polynomial of $\alpha$ has degree $[\mathbb{Q}(\alpha):\mathbb{Q}] = 4$.
step: Find a monic degree-$4$ polynomial with root $\alpha$: from $\alpha^2 - 5 = 2\sqrt{6}$, squaring gives $(\alpha^2 - 5)^2 = 24$, that is $\alpha^4 - 10\alpha^2 + 1 = 0$. A monic degree-$4$ polynomial vanishing at $\alpha$ must be the minimal polynomial.
answer: The minimal polynomial is $x^4 - 10x^2 + 1$, and $\mathbb{Q}(\sqrt{2} + \sqrt{3}) = \mathbb{Q}(\sqrt{2}, \sqrt{3})$.

@example
title: A degree computed with the tower law
problem: Let $\omega = e^{2\pi i/3}$. Find $[\mathbb{Q}(\sqrt[3]{2}, \omega):\mathbb{Q}]$, where $\sqrt[3]{2}$ is the real cube root.
step: The polynomial $x^3 - 2$ is irreducible over $\mathbb{Q}$ by Eisenstein at $p = 2$, so $[\mathbb{Q}(\sqrt[3]{2}):\mathbb{Q}] = 3$.
step: $\omega$ is a root of $x^2 + x + 1$, which has coefficients in $\mathbb{Q}(\sqrt[3]{2})$. This field lies in $\mathbb{R}$ and $\omega \notin \mathbb{R}$, so $x^2 + x + 1$ has no root there and is irreducible over it. Hence $[\mathbb{Q}(\sqrt[3]{2}, \omega):\mathbb{Q}(\sqrt[3]{2})] = 2$.
step: By the tower law, $[\mathbb{Q}(\sqrt[3]{2}, \omega):\mathbb{Q}] = 2 \cdot 3 = 6$.
answer: $6$.

@mistakes
- Assuming $[F(\alpha, \beta):F] = [F(\alpha):F]\,[F(\beta):F]$. It is only a product when the second extension does not become smaller over $F(\alpha)$: $[\mathbb{Q}(\sqrt{2}, \sqrt{8}):\mathbb{Q}] = 2$, not $4$, since $\sqrt{8} = 2\sqrt{2}$.
- Calling a polynomial with root $\alpha$ "the minimal polynomial" without proving it irreducible: $(x^2 - 2)(x - 5)$ vanishes at $\sqrt{2}$ but has degree $3$, while $[\mathbb{Q}(\sqrt{2}):\mathbb{Q}] = 2$.
- Using the tower law backwards: from $d \mid [E:F]$ one cannot conclude that an element of degree $d$ exists. A field of degree $4$ over $\mathbb{Q}$ need not contain an element of degree $2$ outside $\mathbb{Q}$.
- Treating $\mathbb{Q}(\sqrt[3]{2})$ as containing the other cube roots of $2$. It is a subfield of $\mathbb{R}$ and the other two roots are not real.

model:
```python
from fractions import Fraction


def mul(u, v):
    """Product in Q(t), t**3 = 2, basis 1, t, t**2."""
    a, b, c = u
    d, e, f = v
    return (a * d + 2 * (b * f + c * e),
            a * e + b * d + 2 * c * f,
            a * f + b * e + c * d)


def min_poly_cbrt2(u):
    """Monic minimal polynomial of u over Q (constant term first)."""
    a, b, c = (Fraction(x) for x in u)
    if b == 0 and c == 0:
        return [-a, Fraction(1)]
    u1 = (a, b, c)
    u2 = mul(u1, u1)
    u3 = mul(u2, u1)
    one = (Fraction(1), Fraction(0), Fraction(0))
    cols = [one, u1, u2]
    # Augmented system: sum_j c_j * cols[j] = u3, one row per coordinate.
    m = [[cols[j][i] for j in range(3)] + [u3[i]] for i in range(3)]
    for col in range(3):
        piv = next(r for r in range(col, 3) if m[r][col] != 0)
        m[col], m[piv] = m[piv], m[col]
        m[col] = [x / m[col][col] for x in m[col]]
        for r in range(3):
            if r != col and m[r][col] != 0:
                f = m[r][col]
                m[r] = [x - f * y for x, y in zip(m[r], m[col])]
    c0, c1, c2 = (m[i][3] for i in range(3))
    return [-c0, -c1, -c2, Fraction(1)]
```
hint: Compute $u^2$ and $u^3$ with `mul`. Form the $3 \times 3$ system whose columns are the coordinates of $1$, $u$, $u^2$ and whose right-hand side is $u^3$.
solution: For an irrational element of $\mathbb{Q}(t)$ the powers $1, u, u^2$ are linearly independent (otherwise $u$ would have degree at most $2$, and the tower law with $[\mathbb{Q}(t):\mathbb{Q}] = 3$ forces degree $1$ or $3$). So $u^3$ is a unique rational combination $c_0 + c_1u + c_2u^2$, found by elimination, and $u$ is a root of $x^3 - c_2x^2 - c_1x - c_0$; because $u$ has degree $3$, this monic cubic is its minimal polynomial. A rational $a$ has minimal polynomial $x - a$. For $u = t^2$ the result is $x^3 - 4$, since $t^6 = 4$.

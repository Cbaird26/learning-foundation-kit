@article
How many roots can $x^2 - 1$ have? Over $\mathbb{R}$, two: $\pm 1$. Over $\mathbb{Z}/8\mathbb{Z}$ the values $x = 1, 3, 5, 7$ all give $x^2 - 1 \equiv 0$: four roots for a polynomial of degree $2$. Whatever theorem limits the roots of a polynomial must use a hypothesis that $\mathbb{Z}/8\mathbb{Z}$ lacks. This lesson finds it.

### Polynomial rings

For a commutative ring $R$ with $1$, the **polynomial ring** $R[x]$ consists of expressions $f = a_0 + a_1 x + \dots + a_n x^n$ with $a_i \in R$; equal polynomials have equal coefficients, and the operations are the usual ones. The **degree** $\deg f$ is the largest $n$ with $a_n \ne 0$ and $a_n$ is the **leading coefficient**; $f$ is **monic** if $a_n = 1$. The zero polynomial has no degree (we set $\deg 0 = -\infty$).

If $R$ is an integral domain and $f, g \ne 0$, the product of the leading coefficients is nonzero, so $\deg(fg) = \deg f + \deg g$ and $fg \ne 0$. Hence **$R[x]$ is an integral domain when $R$ is**, and its units are the units of $R$ (a unit has degree $0$ since degrees add). Without the domain hypothesis both fail: in $(\mathbb{Z}/4\mathbb{Z})[x]$, $(1 + 2x)^2 = 1 + 4x + 4x^2 = 1$, so $1 + 2x$ is a unit of degree $1$, and $2x \cdot 2 = 0$.

### The division algorithm

**Theorem (division algorithm).** Let $R$ be a commutative ring with $1$, let $f, g \in R[x]$ and suppose the leading coefficient of $g \ne 0$ is a unit of $R$ (for instance $g$ monic, or $R$ a field). Then there are unique $q, r \in R[x]$ with
$$f = qg + r, \qquad \deg r < \deg g .$$

*Proof.* *Existence*, by induction on $\deg f$. If $\deg f < \deg g$ take $q = 0$, $r = f$. Otherwise let $f$ have degree $n$ and leading coefficient $a$, and let $g$ have degree $m \le n$ and leading coefficient $b$, a unit. Put $f_1 = f - ab^{-1}x^{n-m}g$. The $x^n$ terms cancel, so $\deg f_1 < n$. By induction $f_1 = q_1 g + r$ with $\deg r < m$, and then $f = (q_1 + ab^{-1}x^{n-m})g + r$.

*Uniqueness.* Suppose $qg + r = q'g + r'$ with $\deg r, \deg r' < m$. Then $(q - q')g = r' - r$. If $q \ne q'$, let $c$ be the leading coefficient of $q - q'$; the leading coefficient of $(q - q')g$ is $cb \ne 0$ (since $b$ is a unit, $cb = 0$ would force $c = 0$), so $\deg((q - q')g) \ge m$, while $\deg(r' - r) < m$. This contradiction gives $q = q'$ and then $r = r'$. $\blacksquare$

The hypothesis on the leading coefficient is necessary: in $\mathbb{Z}[x]$ you cannot divide $x$ by $2x$ to get a remainder of degree $0$, since $x = q \cdot 2x + r$ forces $2c = 1$ for a constant $q = c$, impossible in $\mathbb{Z}$.

**Remainder and factor theorems.** For $a \in R$, dividing by the monic polynomial $x - a$ gives $f = q(x - a) + r$ with $r \in R$ a constant; substituting $x = a$ gives $r = f(a)$. In particular $(x - a) \mid f$ if and only if $f(a) = 0$.

**Theorem (roots).** If $D$ is an integral domain and $f \in D[x]$ is nonzero of degree $n$, then $f$ has at most $n$ roots in $D$.

*Proof.* Induction on $n$. For $n = 0$, $f$ is a nonzero constant with no roots. Let $n \ge 1$; if $f$ has no root we are done. If $f(a) = 0$, write $f = (x - a)q$ with $\deg q = n - 1$. For any root $b \ne a$ we get $0 = (b - a)q(b)$ and $b - a \ne 0$, so $q(b) = 0$ because $D$ is a domain. By induction $q$ has at most $n - 1$ roots, so $f$ has at most $1 + (n - 1) = n$. $\blacksquare$

This is exactly what fails in $\mathbb{Z}/8\mathbb{Z}$: $(x - 1)(x + 1)$ vanishes at $x = 3$ because $2 \cdot 4 = 0$, where both factors are nonzero. For a polynomial over a field the bound is sharp in the sense that $x^p - x$ has all $p$ elements of $\mathbb{Z}/p\mathbb{Z}$ as roots (Fermat's little theorem), so $x^p - x = \prod_{a=0}^{p-1}(x - a)$ in $(\mathbb{Z}/p\mathbb{Z})[x]$.

### Dividing by hand and by machine

Polynomials in code are lists of coefficients, **constant term first**: `[3, -1, 0, 2, 1]` is $3 - x + 2x^3 + x^4$. The loop below repeats the proof's step "subtract $ab^{-1}x^{n-m}g$" over $\mathbb{Q}$ using exact fractions.

```python
from fractions import Fraction


def trim(f):
    """Drop trailing zero coefficients (constant term first)."""
    f = list(f)
    while f and f[-1] == 0:
        f.pop()
    return f


def poly_divmod(f, g):
    """Quotient and remainder of f by g over Q (lists, constant first)."""
    g = trim(g)
    r = trim([Fraction(c) for c in f])
    q = [Fraction(0)] * max(len(r) - len(g) + 1, 1)
    while len(r) >= len(g):
        shift = len(r) - len(g)
        c = r[-1] / g[-1]
        q[shift] = c
        for i, gc in enumerate(g):
            r[i + shift] -= c * gc
        r = trim(r)
    return trim(q), r
```

The remainder list is empty exactly when $g$ divides $f$.

@example
title: Polynomial long division over Q
problem: Divide $f = x^4 + 2x^3 - x + 3$ by $g = x^2 + x + 1$ in $\mathbb{Q}[x]$ and verify the answer.
step: The leading terms give $x^4 / x^2 = x^2$. Subtract $x^2 g = x^4 + x^3 + x^2$ from $f$: the remainder so far is $x^3 - x^2 - x + 3$.
step: Next $x^3 / x^2 = x$. Subtract $xg = x^3 + x^2 + x$: the remainder is $-2x^2 - 2x + 3$.
step: Next $-2x^2 / x^2 = -2$. Subtract $-2g = -2x^2 - 2x - 2$: the remainder is $5$, of degree $0 < 2$. So $q = x^2 + x - 2$ and $r = 5$.
step: Verify: $(x^2 + x + 1)(x^2 + x - 2) = x^4 + 2x^3 + 0x^2 - x - 2$, and adding $5$ gives $x^4 + 2x^3 - x + 3$.
answer: $q = x^2 + x - 2$, $r = 5$.

@example
title: Four roots of a quadratic in Z/8Z
problem: Find all roots of $x^2 - 1$ in $\mathbb{Z}/8\mathbb{Z}$ and explain why the bound of two roots does not apply.
step: Test $x = 0, 1, \dots, 7$: $x^2 \bmod 8$ takes the values $0, 1, 4, 1, 0, 1, 4, 1$. So $x^2 \equiv 1$ exactly for $x = 1, 3, 5, 7$.
step: Each is a root: $3^2 - 1 = 8 \equiv 0$, $5^2 - 1 = 24 \equiv 0$ and $7^2 - 1 = 48 \equiv 0$.
step: The bound "at most $\deg f$ roots" is proved for integral domains. In $\mathbb{Z}/8\mathbb{Z}$, $(3 - 1)(3 + 1) = 2 \cdot 4 = 0$ with both factors nonzero, so a product can vanish without a factor vanishing, and the induction step "$(b - a)q(b) = 0 \Rightarrow q(b) = 0$" breaks.
answer: The roots are $1, 3, 5, 7$: four roots of a degree $2$ monic polynomial, because $\mathbb{Z}/8\mathbb{Z}$ has zero divisors.

@mistakes
- Dividing by a polynomial whose leading coefficient is not a unit: $x^2 + 1$ cannot be divided by $2x + 1$ in $\mathbb{Z}[x]$ with a remainder of smaller degree, although it can in $\mathbb{Q}[x]$.
- Quoting "a degree $n$ polynomial has at most $n$ roots" for any ring. It needs an integral domain: $x^2 - 1$ has four roots in $\mathbb{Z}/8\mathbb{Z}$.
- Forgetting that the degree of a product can drop when there are zero divisors: in $(\mathbb{Z}/6\mathbb{Z})[x]$, $(2x + 1)(3x + 1) = 5x + 1$ has degree $1$, not $2$.
- Evaluating at the wrong point: dividing by $x + 2$ gives the remainder $f(-2)$, not $f(2)$, because $x + 2 = x - (-2)$.

model:
```python
def roots_mod(f, n):
    """Roots of f in Z/nZ (f has the constant term first)."""
    result = []
    for x in range(n):
        value = 0
        for c in reversed(f):          # Horner's rule
            value = (value * x + c) % n
        if value == 0:
            result.append(x)
    return result
```
hint: Evaluate $f$ at every residue with Horner's rule, reducing modulo `n` at each step.
solution: Test each $x$ in `range(n)`. Horner's rule evaluates $a_0 + a_1x + \dots + a_dx^d$ by repeatedly multiplying by $x$ and adding the next coefficient from the top, and reducing modulo $n$ at every step keeps numbers small. The zero polynomial vanishes everywhere. For $x^2 - 1$ modulo $8$ the output has $4$ roots and for $x^2 + x$ modulo $10$ it has four roots too, which shows that when $n$ is composite the roots-bound theorem need not hold; for prime $n$ the number of roots never exceeds the degree, as proved.

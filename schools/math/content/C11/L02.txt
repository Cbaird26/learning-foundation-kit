@article
In group theory you divided a group by a *normal subgroup*. For rings the analogue of a normal subgroup is an **ideal**, and the reason is the same: an ideal is exactly what you may collapse to $0$ and still have a ring. Reduction modulo $n$ collapses $n\mathbb{Z}$ to $0$; the integers $n\mathbb{Z}$ are absorbing, since $n$ times any integer is again a multiple of $n$.

All rings in this lesson are commutative with $1$.

### Ideals and quotients

An **ideal** of $R$ is a subset $I \subseteq R$ such that $I$ is an additive subgroup and $ra \in I$ for all $r \in R$ and $a \in I$ (**absorption**). The set generated by one element, $(a) = aR = \{ra : r \in R\}$, is the **principal ideal** generated by $a$; more generally $(a_1, \dots, a_k) = \{r_1 a_1 + \dots + r_k a_k : r_i \in R\}$. An ideal $I$ equals $R$ if and only if $1 \in I$, because then $r = r \cdot 1 \in I$ for every $r$ (so an ideal containing a unit is all of $R$). Every ideal is a subgroup, but a proper ideal is never a subring, since it omits $1$.

**Theorem.** Every ideal of $\mathbb{Z}$ is $n\mathbb{Z} = (n)$ for a unique $n \ge 0$.

*Proof.* Let $I \ne \{0\}$ be an ideal and let $n$ be its least positive element (it has one, since $-a \in I$ whenever $a \in I$). If $a \in I$, write $a = qn + r$ with $0 \le r < n$. Then $r = a - qn \in I$, so $r = 0$ by minimality of $n$. Hence $I = (n)$. Uniqueness: $(n)$ has least positive element $n$. $\blacksquare$

For an ideal $I$ the **quotient ring** $R/I$ is the set of cosets $a + I$ with $(a + I) + (b + I) = (a + b) + I$ and $(a + I)(b + I) = ab + I$. The product is **well defined**: if $a' = a + i$ and $b' = b + j$ with $i, j \in I$, then $a'b' = ab + (aj + ib + ij)$ and the bracket lies in $I$ by absorption. The ring axioms for $R/I$ follow from those of $R$. The map $\pi\colon R \to R/I$, $\pi(a) = a + I$, is the **quotient map**.

### Homomorphisms and the first isomorphism theorem

A **ring homomorphism** is a map $\varphi\colon R \to S$ with $\varphi(a + b) = \varphi(a) + \varphi(b)$, $\varphi(ab) = \varphi(a)\varphi(b)$ and $\varphi(1_R) = 1_S$. Its **kernel** is $\ker \varphi = \{a : \varphi(a) = 0\}$. The image $\varphi(R)$ is a subring of $S$.

**Theorem (first isomorphism theorem).** If $\varphi\colon R \to S$ is a ring homomorphism, then $\ker \varphi$ is an ideal of $R$ and $R/\ker\varphi \cong \varphi(R)$ as rings, via $a + \ker\varphi \mapsto \varphi(a)$.

*Proof.* Let $K = \ker\varphi$. It is an additive subgroup, and if $a \in K$, $r \in R$ then $\varphi(ra) = \varphi(r)\varphi(a) = 0$, so $K$ is an ideal. Define $\bar\varphi(a + K) = \varphi(a)$. It is well defined and injective because $\varphi(a) = \varphi(b)$ if and only if $a - b \in K$ if and only if $a + K = b + K$. It preserves sums, products and $1$ because $\varphi$ does, and its image is $\varphi(R)$. $\blacksquare$

Conversely every ideal is a kernel, namely of its quotient map. So *ideals are exactly the kernels of ring homomorphisms*.

### Ideals of $\mathbb{Z}/n\mathbb{Z}$

The quotient map $\mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}$ gives a correspondence between ideals of $\mathbb{Z}/n\mathbb{Z}$ and ideals of $\mathbb{Z}$ containing $n\mathbb{Z}$, that is, ideals $(d)$ with $d \mid n$. Thus the ideals of $\mathbb{Z}/n\mathbb{Z}$ are the $(d) = \{0, d, 2d, \dots\}$ for the positive divisors $d$ of $n$, one for each divisor, and $(\mathbb{Z}/n\mathbb{Z})/(d) \cong \mathbb{Z}/d\mathbb{Z}$. Different generators can give the same ideal: $(a) = (\gcd(a, n))$. The code below confirms the count on $n = 24$, which has $8$ divisors; it is a check of the pattern, not a proof.

```python
def principal(a, n):
    """The ideal (a) of Z/nZ as a sorted list."""
    return sorted({a * x % n for x in range(n)})


n = 24
print(len({tuple(principal(a, n)) for a in range(n)}))
```

It prints `8`: the $24$ principal ideals $(0), (1), \dots, (23)$ collapse to $8$ distinct sets.

### An ideal is not a subring, and a subring is not an ideal

The ring $\mathbb{Z}$ is a subring of $\mathbb{Q}$ but not an ideal: $\frac12 \cdot 1 \notin \mathbb{Z}$. In a field the only ideals are $\{0\}$ and the field itself, since a nonzero ideal contains a unit.

@example
title: Ideals of Z/12Z and a quotient
problem: List the ideals of $\mathbb{Z}/12\mathbb{Z}$ and identify $(\mathbb{Z}/12\mathbb{Z})/(3)$.
step: Ideals of $\mathbb{Z}/12\mathbb{Z}$ correspond to the positive divisors of $12$: $1, 2, 3, 4, 6, 12$. So there are six ideals.
step: Write them out: $(1) = \mathbb{Z}/12\mathbb{Z}$, $(2) = \{0, 2, 4, 6, 8, 10\}$, $(3) = \{0, 3, 6, 9\}$, $(4) = \{0, 4, 8\}$, $(6) = \{0, 6\}$, $(12) = (0) = \{0\}$.
step: Reduction modulo $3$ is a well-defined ring homomorphism $\varphi\colon \mathbb{Z}/12\mathbb{Z} \to \mathbb{Z}/3\mathbb{Z}$ because $3 \mid 12$. It is surjective, and $\varphi(a) = 0$ if and only if $3 \mid a$, so $\ker\varphi = (3)$.
step: By the first isomorphism theorem, $(\mathbb{Z}/12\mathbb{Z})/(3) \cong \mathbb{Z}/3\mathbb{Z}$, a ring with $3$ elements (the number of cosets is $12/4 = 3$).
answer: Six ideals $(1), (2), (3), (4), (6), (0)$, and the quotient by $(3)$ is $\mathbb{Z}/3\mathbb{Z}$.

@example
title: A homomorphism whose image is not everything
problem: Define $\varphi\colon \mathbb{Z} \to \mathbb{Z}/6\mathbb{Z} \times \mathbb{Z}/10\mathbb{Z}$ by $\varphi(k) = (k \bmod 6,\ k \bmod 10)$. Find the kernel and identify the image.
step: The target is a ring with componentwise operations and $1 = (1, 1)$; $\varphi$ preserves sums, products and $1$, so it is a ring homomorphism.
step: $\varphi(k) = (0, 0)$ if and only if $6 \mid k$ and $10 \mid k$, if and only if $\operatorname{lcm}(6, 10) = 30$ divides $k$. So $\ker\varphi = 30\mathbb{Z}$.
step: By the first isomorphism theorem, the image is isomorphic to $\mathbb{Z}/30\mathbb{Z}$ and has $30$ elements.
step: The target has $6 \cdot 10 = 60$ elements, so $\varphi$ is not onto. This is why the Chinese remainder theorem needs coprime moduli: $\gcd(6, 10) = 2 \ne 1$.
answer: $\ker\varphi = 30\mathbb{Z}$ and $\varphi(\mathbb{Z}) \cong \mathbb{Z}/30\mathbb{Z}$, a proper subring of the $60$-element target.

@mistakes
- Confusing ideals with subrings: a proper ideal never contains $1$, so it is never a subring, and $\mathbb{Z} \subset \mathbb{Q}$ is a subring that is not an ideal.
- Checking only that $I$ is closed under addition and multiplication within $I$. An ideal must absorb multiplication by every element of $R$, not only elements of $I$.
- Believing that $(a) = (b)$ requires $a = b$. In $\mathbb{Z}/20\mathbb{Z}$, $(8) = (4)$ because $\gcd(8, 20) = 4$.
- Forgetting $\varphi(1) = 1$ in the definition: the map $x \mapsto 2x$ on $\mathbb{Z}$ is additive and sends $x y$ to $2xy \ne 4xy$, so it is not a ring homomorphism.

prompt: Prove that $\mathbb{Z}[i]/(1 + i) \cong \mathbb{Z}/2\mathbb{Z}$, where $(1 + i)$ is the principal ideal generated by $1 + i$ in the Gaussian integers $\mathbb{Z}[i]$.
hint: Define $\varphi(a + bi) = (a + b) \bmod 2$ and check that it is a ring homomorphism.

solution: Define $\varphi\colon \mathbb{Z}[i] \to \mathbb{Z}/2\mathbb{Z}$ by $\varphi(a + bi) = (a + b) \bmod 2$. It is additive. For products, $(a + bi)(c + di) = (ac - bd) + (ad + bc)i$ maps to $ac - bd + ad + bc \equiv ac + bd + ad + bc = (a + b)(c + d) \pmod 2$, and $\varphi(1) = 1$. It is onto, since $\varphi(1) = 1$. Kernel: $(1 + i)(c + di) = (c - d) + (c + d)i$ has coordinate sum $2c$, which is even, so $(1 + i) \subseteq \ker\varphi$. Conversely if $a + b$ is even, put $c = (a + b)/2$ and $d = (b - a)/2$, integers with $c - d = a$ and $c + d = b$; then $a + bi = (1 + i)(c + di)$. So $\ker\varphi = (1 + i)$, and the first isomorphism theorem gives $\mathbb{Z}[i]/(1 + i) \cong \mathbb{Z}/2\mathbb{Z}$.

model:
```python
from math import gcd


def ideal_generated(gens, n):
    """Ideal of Z/nZ generated by the integers in gens."""
    g = n
    for a in gens:
        g = gcd(g, a)
    return list(range(0, n, g))
```
hint: In $\mathbb{Z}$, the ideal $(a_1, \dots, a_k, n)$ is generated by $\gcd(a_1, \dots, a_k, n)$.
solution: The ideal of $\mathbb{Z}/n\mathbb{Z}$ generated by $a_1, \dots, a_k$ is the image of the ideal $(a_1, \dots, a_k, n)$ of $\mathbb{Z}$, which is $(g)$ for $g = \gcd(a_1, \dots, a_k, n)$ because every ideal of $\mathbb{Z}$ is principal. Its elements modulo $n$ are the multiples of $g$ in `range(n)`. Starting the gcd at $n$ handles the empty list ($g = n$ gives only $0$) and generators that are multiples of $n$.

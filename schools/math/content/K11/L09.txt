@article
Grown-up helper, please read this out loud.

A shopping list holds many things. A Python **list** does too.

```python
food = ["milk", "eggs", "bread"]
```

A list uses square brackets `[ ]`. The items go inside, with commas between them. Words need quote marks. Numbers do not: `[4, 8, 15]`.

### Place numbers

Each item has a place number. Python starts counting at **0**, not 1.

| Place | 0 | 1 | 2 |
|---|---|---|---|
| Item | milk | eggs | bread |

To pick one item, write the list name and the place number in square brackets.

```python
print(food[0])
print(food[2])
```

This shows `milk` and then `bread`.

### How many items?

`len` tells you how many items are in a list.

```python
print(len(food))
```

This shows `3`. The last place number is 2, one less than the length.

### Adding to a list

`append` adds a new item to the end.

```python
food.append("jam")
print(len(food))
```

Now the list has 4 items, and this shows `4`.

You can also change an item: `food[1] = "cheese"` puts `cheese` in place 1.

@example
title: Pick from a list
problem: What does this program show?

```python
pets = ["dog", "cat", "fish"]
print(pets[1])
```
step: Place numbers start at 0: `dog` is 0, `cat` is 1, `fish` is 2.
step: `pets[1]` is `cat`.
answer: cat

@example
title: Add and count
problem: What does this program show?

```python
nums = [5, 6]
nums.append(7)
print(len(nums))
```
step: The list starts with 2 items.
step: `append(7)` adds a third item.
step: `len(nums)` is `3`, so the screen shows `3`.

@mistakes
- Counting places from 1. The first item is place 0.
- Using the place number `len(food)`, which is too big and gives an `IndexError` ("there is no such place").
- Forgetting the quote marks around words in a list.

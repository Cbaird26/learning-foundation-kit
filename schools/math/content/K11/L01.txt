@article
Hello, grown-up helper! Please read this out loud with your learner.

A **program** is a list of instructions for a computer. The computer does exactly what the instructions say, one at a time.

Python is a language for writing programs. Let us write our first one.

```python
print("Hello!")
```

Run it. The computer shows this on the screen:

```text
Hello!
```

### What each part does

- `print` is a word that tells the computer, "Show this on the screen."
- The round brackets `( )` hold the thing to show.
- The quote marks `" "` tell Python, "These are words."

The quote marks do not show up on the screen. Only the words inside them do.

### More than one line

Each `print` shows one line. The computer reads from the top down.

```python
print("Hi")
print("Bye")
```

This shows `Hi` on the first line and `Bye` on the second line.

### Oops, an error

Sometimes there is a small mistake, like a missing quote mark. Python then shows an **error** message. An error is not bad. It is Python saying, "Please look here." Look at your line, find the small mistake, fix it and run again.

Python cares about small letters. `print` works. `Print` does not.

@example
title: Print two lines
problem: Write a program that shows `Good morning` and then `Time to play`.
step: We need two lines, so we need two `print` instructions.
step: Put each message inside brackets and quote marks.
step: The first line is `print("Good morning")` and the second line is `print("Time to play")`.
step: Run it. The screen shows `Good morning` and then `Time to play`.
answer: Two print lines, one for each message.

@example
title: Fix the missing quote
problem: This program has an error. How do we fix it?

```python
print("Hello)
```
step: Look at the quote marks. There is one at the start but none at the end.
step: Add the missing quote mark: `print("Hello")`.
step: Run it again. The screen shows `Hello`.

@mistakes
- Forgetting the quote mark at the end (or at the start) of the words.
- Writing `Print` with a big P. It must be `print` with a small p.
- Forgetting a bracket, so `print("Hi"` has no closing `)`.

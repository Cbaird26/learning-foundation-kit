@article
Grown-up helper, please read this out loud.

Now we can build a game! The computer keeps a secret number. A player guesses. The computer says if the guess is too low, too high, or right.

```python
secret = 7
guess = 4
if guess == secret:
    print("You got it!")
elif guess < secret:
    print("Too low")
else:
    print("Too high")
```

This shows `Too low`, because 4 is smaller than 7.

### The new word: elif

`elif` means "else, if". It lets us ask a second question. The computer checks the questions from the top. It runs the first one that is yes, and skips the rest.

### Put it in a function

A function lets us try many guesses without writing the same lines again.

```python
secret = 7

def check_guess(guess):
    if guess == secret:
        print("You got it!")
    elif guess < secret:
        print("Too low")
    else:
        print("Too high")

check_guess(3)
check_guess(9)
check_guess(7)
```

This shows `Too low`, `Too high` and `You got it!`.

### Make it yours

Change the secret number and run it again. A game is just a few ideas working together: a variable, a choice and a function. You can also add a loop to try a list of guesses.

@example
title: Follow a guess
problem: With `secret = 7`, what does `check_guess(9)` show?
step: Is `9 == 7`? No.
step: Is `9 < 7`? No.
step: So the `else` runs and shows `Too high`.
answer: Too high

@example
title: Guess a whole list
problem: With `secret = 5`, print the answer for each number in `[2, 5]`.
step: We use a loop: `for g in [2, 5]:`.
step: Inside the loop, call `check_guess(g)`.
step: The screen shows `Too low` for 2 and `You got it!` for 5.

@mistakes
- Using `=` instead of `==` when asking if the guess is the secret.
- Mixing up `<` and `>`, so the hints are backwards.
- Putting `else` before `elif`. The `else` must come last.
- Forgetting to call the function, so the game never runs.

@article
Grown-up helper, please read this out loud.

Words and letters in quote marks are called **text**. Programmers say **string**, like a string of letters.

```python
name = "Mia"
print("Hello, " + name)
```

This shows:

```text
Hello, Mia
```

### Joining with +

The plus sign joins two strings into one. Look at the space inside `"Hello, "`. The computer joins exactly what you give it, so you must type the space.

```python
print("sun" + "shine")
```

This shows `sunshine`.

### Joining with a comma

A comma in `print` shows both things with a space between them.

```python
friend = "Leo"
print("Hi,", friend)
```

This shows `Hi, Leo`.

### Repeating text

Times works on strings too.

```python
print("ha" * 3)
```

This shows `hahaha`.

### Text and numbers

You cannot join text and a number with `+`. Python gives a `TypeError`, which means, "These two things do not go together." Use the comma instead:

```python
print("I am", 7)
```

This shows `I am 7`.

Remember the greeting program: put the name in a variable, then print a greeting with it. Change the name and the greeting changes too.

```python
print("Good" + "day")
```

step: There is no space inside either string.
step: So the screen shows `Goodday`, with no space.
answer: Goodday

@mistakes
- Forgetting the space, so `"Hello," + name` shows `Hello,Mia`.
- Joining text and a number with `+`, which gives a `TypeError`. Use a comma instead.
- Putting quote marks around the variable name, which shows the name and not the friend's name.

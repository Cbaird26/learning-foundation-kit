@article
Grown-up helper, please read this out loud.

A **function** is a little program with a name. You write it once, and then you can use it as many times as you like. You have used one already: `print`!

```python
def cheer():
    print("Hooray!")

cheer()
cheer()
```

This shows `Hooray!` two times.

### The parts

- `def` means, "I am making a function."
- `cheer` is the name we chose. The brackets and the colon come after it.
- The indented lines are what the function does.
- Writing `def` only makes the function. Nothing happens until we **call** it by writing its name, `cheer()`.

### Giving it something to work with

A function can take a value. The name inside the brackets is called a **parameter**.

```python
def greet(name):
    print("Hello,", name)

greet("Mia")
greet("Leo")
```

This shows `Hello, Mia` and then `Hello, Leo`.

### Handing an answer back

`return` sends an answer back to the place that called the function.

```python
def double(n):
    return n * 2

print(double(4))
```

This shows `8`.

@example
title: Return an answer
problem: What does this program show?

```python
def add_one(n):
    return n + 1

print(add_one(5))
```
step: `add_one(5)` runs the function with `n` as `5`.
step: The function returns `5 + 1`, which is `6`.
step: So `print` shows `6`.
answer: 6

@mistakes
- Writing `def` and forgetting to call the function, so nothing happens.
- Forgetting the colon at the end of the `def` line, or forgetting to indent the lines under it.
- Writing the function name without brackets, like `cheer`, when you want to call it.
- Confusing `print` and `return`. Print shows something on the screen. Return hands back an answer.

@article
Grown-up helper, please read this out loud.

A **variable** is a name for a value. Think of a box with a label on it. The label is the name. The thing inside is the value.

```python
age = 7
print(age)
```

This shows:

```text
7
```

### Making a variable

The line `age = 7` means, "Put the value 7 in the box named age." The sign `=` here does not mean "is equal to". It means "put into the box".

### Using a variable

Write the name **without quote marks** to get the value out.

```python
pet = "cat"
print(pet)
print("pet")
```

The first `print` shows `cat`, the value in the box. The second shows `pet`, because the quote marks make it plain words.

### Changing a variable

A box can hold something new. The old value is gone.

```python
n = 3
n = 10
print(n)
```

This shows `10`.

### Using a variable in a sum

```python
apples = 4
print(apples + 2)
```

This shows `6`. The variable `apples` still holds `4`.

Good names help. `apples` is a better name than `a`. Names have no spaces. Use a small letter to start.

@example
title: Put a value in, take it out
problem: What does this program show?

```python
score = 5
score = score + 1
print(score)
```
step: First `score` holds `5`.
step: The line `score = score + 1` works out `5 + 1`, which is `6`, and puts it back in the box.
step: The screen shows `6`.
answer: 6

@example
title: Name or words?
problem: What does this show?

```python
color = "blue"
print(color)
print("color")
```
step: `color` holds the word `blue`.
step: `print(color)` has no quote marks, so it shows the value: `blue`.
step: `print("color")` has quote marks, so it shows the word `color`.

@mistakes
- Putting quote marks around a variable name, so the computer shows the name and not the value.
- Using a name before giving it a value. Python then says `NameError`, which means "I do not know that name."
- Thinking the old value stays after a new one is put in. The box holds only one value.

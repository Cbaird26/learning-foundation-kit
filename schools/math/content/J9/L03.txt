@article
A **string** is a sequence of characters: letters, digits, spaces and punctuation. Each character has a position called its **index**, and Python starts counting at `0`.

```python
word = "Python"
print(word[0], word[-1])   # P n
print(word[1:4])           # yth
print(len(word))           # 6
```

### Indexing and slicing

`word[0]` is the first character. A negative index counts from the end, so `word[-1]` is the last one. A **slice** `word[a:b]` takes the characters from index `a` up to, but not including, index `b`. That is why `word[1:4]` gives `yth` (indexes 1, 2 and 3). If you leave out `a` the slice starts at the beginning, and if you leave out `b` it runs to the end: `word[:2]` is `Py` and `word[2:]` is `thon`.

`len(word)` is the number of characters. The last valid index is `len(word) - 1`, and `word[6]` on a six-letter word is an error.

### Joining and repeating

`+` joins two strings, and `*` with a whole number repeats one:

```python
print("ice" + "cream")   # icecream
print("ha" * 3)          # hahaha
```

The keyword `in` checks for a smaller string inside a bigger one: `"th" in "Python"` is `True`.

### String methods

A **method** is a function that belongs to a value, called with a dot. Here are some useful ones:

| Method | What it does | Example | Result |
|---|---|---|---|
| `upper()` / `lower()` | change case | `"Hi".upper()` | `"HI"` |
| `title()` | capitalize each word | `"ada b".title()` | `"Ada B"` |
| `strip()` | remove spaces at both ends | `"  hi ".strip()` | `"hi"` |
| `replace(old, new)` | swap every `old` for `new` | `"cat".replace("c", "b")` | `"bat"` |
| `count(part)` | how many times `part` appears | `"banana".count("a")` | `3` |
| `find(part)` | index of the first match, or `-1` | `"banana".find("n")` | `2` |
| `startswith(part)` | does it begin with `part`? | `"cat".startswith("c")` | `True` |

Strings are **immutable**: they cannot be changed in place. A method gives back a new string and leaves the original alone, so you must store the result:

```python
name = "  ada  "
clean = name.strip().title()   # chain methods left to right
print(clean)                   # Ada
print(name == "  ada  ")       # True, name did not change
```

Trying `word[0] = "J"` is an error for the same reason.

@example
title: Slices and methods
problem: What does this program print?

```python
s = "sunshine"
print(s[0:3])
print(s[-4:])
print(s.upper().count("S"))
```
step: `s[0:3]` takes indexes 0, 1 and 2, which are `sun`.
step: `s[-4:]` starts four characters from the end and runs to the end: `s`, `h`, `i`, `n`, `e` has five letters after `sun`, so the last four are `hine`.
step: `s.upper()` is `"SUNSHINE"`, and it contains `S` twice (the first and fourth letters), so `count("S")` is `2`.
step: The program prints `sun`, `hine` and `2` on three lines.
answer: `sun`, `hine`, `2`

@example
title: Cleaning up a name
problem: A name arrives as `" tariq OKAFOR "`. Make it `Tariq Okafor`.
step: First remove the extra spaces at both ends with `strip()`.
step: Then fix the capital letters with `title()`, which makes the first letter of each word a capital and the rest lowercase.
step: Chain the methods and store the result:

```python
raw = " tariq OKAFOR "
name = raw.strip().title()
print(name)
```
step: The program prints `Tariq Okafor`, and `raw` is unchanged.

@mistakes
- Thinking `word[1:4]` includes index 4. A slice stops just before its end index.
- Calling `name.strip()` without storing the result. The original string does not change, so write `name = name.strip()`.
- Using an index that is too large: a string with `len` 6 has indexes `0` to `5`.
- Mixing up `find` and `count`: `find` gives a position, `count` gives how many.

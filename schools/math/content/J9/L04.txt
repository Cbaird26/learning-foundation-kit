@article
So far your programs have only printed. With `input()`, a program can ask the user a question and wait for the answer. The prompt text goes inside the parentheses, and whatever the user types comes back as a **string**:

```python
name = input("What is your name? ")
print("Hello, " + name + "!")
```

If the user types `Maya`, this prints `Hello, Maya!`.

### Input is always a string

Even when the user types digits, `input()` returns text. That causes a classic surprise:

```python
a = input("First number: ")
b = input("Second number: ")
print(a + b)
```

With `6` and `7` typed in, this prints `67`, because `+` joins two strings. Convert first, with `int()` for whole numbers or `float()` for decimals:

```python
a = int(input("First number: "))
b = int(input("Second number: "))
print(a + b)    # 13
```

If the user types something that is not a number, such as `six`, the conversion fails with a `ValueError`. For now your programs may assume that the user types sensible input.

### f-strings

An **f-string** is a string that starts with `f` before the opening quote. Anything inside braces `{...}` is calculated and put into the text:

```python
name = "Maya"
age = 12
print(f"{name} is {age} years old.")
print(f"Next year: {age + 1}")
```

This is much easier to read than joining pieces with `+` and `str()`. You can also control how a number looks. The format `:.2f` means "a float with 2 decimal places":

```python
price = 3.5
print(f"Price: {price:.2f}")   # Price: 3.50
```

### Print options

`print` can separate its values with something other than a space, using `sep`, and can end with something other than a new line, using `end`:

```python
print("a", "b", "c", sep="-")   # a-b-c
print("one", end=" ")
print("two")                    # one two
```

When this site checks a program that reads input, it feeds in the lines the test needs, and only the text your program prints is compared. A prompt is part of the printed text.

@example
title: Why the answer is 67
problem: A user types `6` and then `7`. What does each program print?

```python
a = input()
b = input()
print(a + b)
```

```python
a = int(input())
b = int(input())
print(a + b)
```
step: In the first program, `a` is the string `"6"` and `b` is the string `"7"`.
step: Adding two strings joins them, so the first program prints `67`.
step: In the second program, `int()` turns the strings into the numbers `6` and `7`.
step: Adding numbers gives `13`, so the second program prints `13`.
answer: `67` and `13`

step: Do the same for the height, then multiply to get the area.
step: Show the result with an f-string:

@mistakes
- Adding two values from `input()` without converting them. The result is joined text, such as `"6" + "7"` giving `"67"`.
- Forgetting the `f` before the quote, so the braces are printed as they are.
- Using `int()` on text that has a decimal point, such as `int("2.5")`, which is an error. Use `float()`.
- Writing `print("a", " ")` when you meant to change the ending. The options need their keyword names: write `end=" "` or `sep="-"`.

@article
So far each variable held one value. A **list** holds many values in order, written in square brackets:

```python
scores = [72, 90, 85]
print(scores[0], scores[-1], len(scores))   # 72 85 3
```

Lists use the same tools as strings: indexes start at `0`, negative indexes count from the end, `len` gives the number of items, and slices work too: `scores[1:3]` is `[90, 85]`. The keyword `in` checks membership: `90 in scores` is `True`. A list can hold any values, even mixed types, and `[]` is the **empty list**.

### Changing a list

Unlike strings, lists are **mutable**: you can change them in place.

```python
scores[0] = 75          # replace an item
scores.append(60)       # add to the end
scores.insert(1, 99)    # insert at index 1
last = scores.pop()     # remove and return the last item
scores.remove(99)       # remove the first item equal to 99
```

Built-in functions summarize a list: `sum(scores)`, `min(scores)` and `max(scores)`. The function `sorted(scores)` returns a **new** sorted list and leaves the original unchanged, while `scores.sort()` sorts the list itself.

### Looping over a list

A `for` loop can visit each item directly, without indexes:

```python
words = ["kiwi", "fig", "banana"]
for w in words:
    print(w.upper())
```

Combine this with the accumulator pattern. To **filter**, build a new list with `append`:

```python
big = []
for n in [3, 12, 7, 20]:
    if n > 5:
        big.append(n)
print(big)   # [12, 7, 20]
```

Start with an empty list, test each item, and append the ones you want. To **count**, start a number at `0` and add `1` when the test passes. To **total**, add each item to a number that starts at `0`.

### Two names, one list

When you write `b = a` with a list, you do not get a copy: both names refer to the **same** list.

```python
a = [1, 2]
b = a
b.append(3)
print(a)   # [1, 2, 3]
```

To make an independent copy, write `b = a[:]` or `b = list(a)`. Remember this when a function changes a list that was passed to it: the caller's list changes too. If a function should not change its input, build and return a new list instead.

@example
title: Filtering a list
problem: What does this program print?

```python
words = ["kiwi", "fig", "banana"]
long_words = []
for w in words:
    if len(w) > 3:
        long_words.append(w)
print(long_words)
```
step: `long_words` starts as the empty list `[]`.
step: `"kiwi"` has 4 letters, which is more than 3, so it is appended. `"fig"` has 3 letters and is skipped.
step: `"banana"` has 6 letters, so it is appended.
step: The program prints the list, including its square brackets and quotes: `['kiwi', 'banana']`.
answer: `['kiwi', 'banana']`

@example
title: Sum of squares
problem: Write `sum_of_squares(nums)` that returns the sum of the squares of the numbers in a list.
step: The answer is a total, so start an accumulator at `0`.
step: Visit each item with `for n in nums:` and add its square.
step: Return the total after the loop:

```python
def sum_of_squares(nums):
    total = 0
    for n in nums:
        total += n * n
    return total
```
step: Check: `sum_of_squares([1, 2, 3])` is `1 + 4 + 9`, which is `14`, and for `[]` the answer is `0`.

@mistakes
- Using an index past the end: a list with 3 items has indexes `0`, `1` and `2`.
- Forgetting that `b = a` does not copy a list, so changing `b` also changes `a`.
- Writing `scores = scores.sort()`. The method sorts in place and returns `None`, so `scores` becomes `None`.
- Adding to a list with `+=` a single value, such as `nums += 5`. Use `nums.append(5)`.

def count_negatives(nums):

def only_even(nums):

def only_even(nums):

For `[3, 9, 4, 7]` it returns `[9, 7]`. A repeated largest value counts twice: `[2, 2, 1]` gives `[2, 2]`.
starter:
```python
def top_two(nums):
    pass
```
tests:
```python
data = [3, 9, 4, 7]
assert top_two(data) == [9, 7]
assert data == [3, 9, 4, 7]
assert top_two([5]) == [5]
assert top_two([2, 2, 1]) == [2, 2]
assert top_two([-1, -9, -4]) == [-1, -4]
```

```python
def top_two(nums):
    ordered = sorted(nums, reverse=True)
    return ordered[:2]
```

@quiz code
prompt: Write `longest_word(words)` that returns the longest string in the non-empty list `words`. If two words tie for longest, return the one that comes first in the list.
starter:
```python
def longest_word(words):
    pass
```
tests:
```python
assert longest_word(["pear", "fig", "banana"]) == "banana"
assert longest_word(["aa", "bb", "c"]) == "aa"
assert longest_word(["x"]) == "x"
assert longest_word(["ab", "abc", "abd"]) == "abc"
```
model:
```python
def longest_word(words):
    best = words[0]
    for w in words:
        if len(w) > len(best):
            best = w
    return best
```
hint: Keep the best word seen so far, starting with the first item.
hint: Replace it only when a word is strictly longer, so that the earlier word wins a tie.
solution: Start with `best = words[0]` and replace it when `len(w) > len(best)`. Because the test is strictly greater, a later word of equal length never replaces the earlier one.

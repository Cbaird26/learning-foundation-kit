@article
Text is the most common kind of data a program reads, and almost every text task follows the same plan: *clean* the text, *split* it into pieces, then *examine* or *count* the pieces.

### Strings are sequences, and they are immutable

A string supports the same indexing and slicing as a list: `"python"[0]` is `"p"` and `"python"[-3:]` is `"hon"`. You can loop over its characters. But a string is **immutable**: `s[0] = "P"` raises a `TypeError`. To "change" a string, build a new one: `s = "P" + s[1:]`.

### Methods that return new strings

Every string method returns a new string (or another value) and leaves the original alone:

| Method | Result |
|---|---|
| `s.lower()`, `s.upper()` | all lowercase / all uppercase |
| `s.strip()` | remove whitespace at both ends; `s.strip(".,!")` removes those characters from both ends |
| `s.replace(old, new)` | every `old` replaced by `new` |
| `s.split()` | list of pieces separated by runs of whitespace; `s.split(",")` splits at every comma |
| `sep.join(pieces)` | glue a list of strings together with `sep` between them |
| `s.find(t)` | index of the first `t`, or `-1` if absent |
| `s.count(t)` | number of non-overlapping occurrences |
| `s.startswith(t)`, `s.endswith(t)` | `True` or `False` |
| `s.isalpha()`, `s.isdigit()` | whether every character is a letter / a digit (and the string is not empty) |

Because results are new strings, you can chain calls: `"  Hi There ".strip().lower()` is `"hi there"`.

### `split` and `join` are opposites

```python
words = "the cat sat".split()      # ['the', 'cat', 'sat']
sentence = "-".join(words)         # 'the-cat-sat'
```

`split()` with no argument treats any run of spaces, tabs and newlines as one separator and never produces empty pieces. `split(",")` produces an empty piece for each pair of adjacent commas.

### f-strings

An f-string puts expressions inside braces: `f"{name} scored {score * 2}"`. Use `:.2f` to show two decimals: `f"{3.14159:.2f}"` is `"3.14"`.

### Cleaning words

Splitting `"Hello, world! Hello."` gives `['Hello,', 'world!', 'Hello.']`, which would count `Hello,` and `Hello.` as different words. First lowercase the text, then strip punctuation from the ends of each piece. The module `string` provides `string.punctuation`, a string of the punctuation characters:

```python
import string

def clean_words(text):
    words = []
    for raw in text.lower().split():
        word = raw.strip(string.punctuation)
        if word:
            words.append(word)
    return words
```

Pieces that were only punctuation, such as `--`, strip down to the empty string and are skipped by `if word:`. Apostrophes inside a word (`don't`) are kept, because `strip` only removes characters at the ends.

### Counting words

Once you have a clean list of words, `words.count(w)` tells you how often `w` appears. A loop that keeps the word with the highest count so far finds the most frequent one. (Next lesson, a dictionary will count every word in a single pass.)

@mistakes
- Trying to assign to a character, `s[0] = "x"`, instead of building a new string.
- Calling `s.strip()` or `s.lower()` without using the result, so nothing changes.
- Forgetting to lowercase before counting, so `The` and `the` become different words.
- Using `split(" ")` when the text may contain several spaces or newlines, which produces empty pieces.

model:
```python
import string


def most_common_word(text):
    words = []
    for raw in text.lower().split():
        word = raw.strip(string.punctuation)
        if word:
            words.append(word)
    best = ""
    best_count = 0
    for w in words:
        c = words.count(w)
        if c > best_count:
            best = w
            best_count = c
    return best
```
hint: First build a clean list of lowercase words, as in the article.

solution: Clean the words, then scan them with `words.count(w)`. Replacing the best word only when the new count is strictly larger means that on a tie the word seen first wins. If there are no words the loop never runs and `""` is returned.

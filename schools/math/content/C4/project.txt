step: Write the corrected final version of each proof. Keep the draft and its critique next to the final version so the correction is visible.
step: Add a header to each proof giving the claim, the method, the key definition used, and one sentence on why that method suits the statement.
step: Choose two proofs to defend. Prepare a five-minute explanation of each: the claim, the main idea, the key step, and the answer to "what breaks if the hypothesis is dropped?".

## What to know, week by week

- **Logic and quantifiers (week 1).** $\neg(P \Rightarrow Q)$ is $P \wedge \neg Q$. $\neg \forall x\, P(x)$ is $\exists x\, \neg P(x)$, and $\neg \exists x\, P(x)$ is $\forall x\, \neg P(x)$. The order of quantifiers matters.
- **Sets and functions (week 2).** Prove $A \subseteq B$ by taking an arbitrary $x \in A$; prove $A = B$ by double inclusion. Know domain, codomain, range, image and preimage.
- **Direct proof (week 3).** Assume the hypothesis, unpack definitions (even, odd, divides) into equations, and derive the conclusion. Use cases when the hypothesis splits.
- **Contrapositive (week 4).** $P \Rightarrow Q$ is equivalent to $\neg Q \Rightarrow \neg P$, not to the converse or the inverse. Announce it, then prove the new statement directly.
- **Contradiction (week 5).** Assume the negation of the claim (for a conditional: $P$ and $\neg Q$) and derive a contradiction. Models: $\sqrt{2}$ is irrational, and there are infinitely many primes.
- **Induction (week 6).** A base case, a hypothesis for one arbitrary $k$, and a step that uses the hypothesis. Choose the right starting value.
- **Relations (week 7).** Reflexive, symmetric, antisymmetric, transitive. Prove a "for all" property in general; refute it with one explicit counterexample.
- **Equivalence classes (week 8).** An equivalence relation is reflexive, symmetric and transitive. Its classes partition the set, and $a \sim b$ exactly when $[a] = [b]$.
- **Injectivity and surjectivity (week 9).** Injective: $f(a) = f(a') \Rightarrow a = a'$. Surjective: solve $f(a) = b$ and check that $a$ lies in the domain. A bijection has an inverse.
- **Cardinality (week 10).** $|A| = |B|$ means a bijection exists. The sets $\mathbb{Z}$, $\mathbb{Q}$ and $\mathbb{N} \times \mathbb{N}$ are countable; $(0, 1)$ is not, by the diagonal argument.
- **Bounds and completeness (week 11).** A supremum is the least upper bound, and both parts must be proved. $\mathbb{R}$ is complete; $\mathbb{Q}$ is not.
- **Proof critique (week 12).** State the claim, justify each line, find the first unjustified step, then repair the proof or give a counterexample.

## Self-check

You are ready for the examination if you can, without notes:

- negate a statement with two quantifiers and an implication;
- choose a method for a new statement and say why it fits;
- write an induction proof with a labeled base case and inductive step;
- prove or refute each of the four properties for a relation;
- prove that a function is a bijection, including the domain check;
- explain the diagonal argument and the two parts of a supremum proof;
- find the first unjustified step in a flawed proof.

## Most common errors

- Assuming the conclusion, or proving the converse instead of the contrapositive.
- Proving a "for all" statement by examples, or refuting one with a vague argument instead of a single explicit counterexample.
- Using one letter for two objects that need not be equal.
- Forgetting the base case, or writing an inductive step that fails for small $k$.
- Dividing by something that may be zero.
- Showing that a number is an upper bound but not that it is the least one.
- Naming the last absurd line as the error instead of the first unjustified one.

@exam num
prompt: On $A = \{1, 2, \dots, 20\}$ define $a \sim b$ when $6 \mid a - b$. This is an equivalence relation, so its equivalence classes partition $A$. How many ordered pairs $(a, b) \in A \times A$ satisfy $a \sim b$?
answer: 68
check: sum(1 for a in range(1, 21) for b in range(1, 21) if (a - b) % 6 == 0)
hint: Group the elements of $A$ by their remainder on division by $6$. Each group is one equivalence class.
hint: A class with $s$ elements contributes $s \cdot s$ ordered pairs, since any two of its elements, including an element with itself, are related.
hint: Find the six class sizes (they add up to $20$), square them and add.
solution: The classes are the residue classes mod $6$. The sets $\{1, 7, 13, 19\}$ and $\{2, 8, 14, 20\}$ have $4$ elements each, and $\{3, 9, 15\}$, $\{4, 10, 16\}$, $\{5, 11, 17\}$, $\{6, 12, 18\}$ have $3$ each. Since $a \sim b$ exactly when $a$ and $b$ lie in the same class, the number of pairs is $4^2 + 4^2 + 4 \cdot 3^2 = 16 + 16 + 36 = 68$.

@exam self
prompt: Define $f: \mathbb{Z} \to \mathbb{Z}$ by $f(n) = n + 1$ if $n$ is even and $f(n) = n - 1$ if $n$ is odd. (a) Prove that $f(f(n)) = n$ for every integer $n$, and deduce that $f$ is a bijection. (b) Define a relation on $\mathbb{Z}$ by $a \sim b$ when $b = a$ or $b = f(a)$. Prove that $\sim$ is an equivalence relation. (c) Describe the equivalence classes, and explain why the set of classes is countably infinite.
solution: (a) If $n = 2k$ is even, then $f(n) = 2k + 1$ is odd, so $f(f(n)) = 2k + 1 - 1 = n$. If $n = 2k + 1$ is odd, then $f(n) = 2k$ is even, so $f(f(n)) = 2k + 1 = n$. Injective: if $f(a) = f(b)$ then applying $f$ gives $a = f(f(a)) = f(f(b)) = b$. Surjective: for any $m \in \mathbb{Z}$, the integer $n = f(m)$ satisfies $f(n) = f(f(m)) = m$. So $f$ is a bijection. (b) Reflexive: $a = a$, so $a \sim a$. Symmetric: suppose $a \sim b$. If $b = a$, then $a = b$ and $b \sim a$. If $b = f(a)$, then $f(b) = f(f(a)) = a$, so $a = f(b)$ and $b \sim a$. Transitive: suppose $a \sim b$ and $b \sim c$. If $b = a$, then $c = b = a$ or $c = f(b) = f(a)$, so $a \sim c$. If $b = f(a)$, then either $c = b = f(a)$, so $a \sim c$, or $c = f(b) = f(f(a)) = a$, so $a \sim c$. (c) For $k \in \mathbb{Z}$ we have $[2k] = \{2k, 2k + 1\} = [2k + 1]$, so the classes are exactly the sets $\{2k, 2k + 1\}$ for $k \in \mathbb{Z}$, and they partition $\mathbb{Z}$. The map $k \mapsto \{2k, 2k + 1\}$ is a bijection from $\mathbb{Z}$ to the set of classes: it is injective because different $k$ give different (disjoint) classes, and surjective because every class has this form. Since $\mathbb{Z}$ is countably infinite, so is the set of classes. $\blacksquare$
rubric: Part (a) handles both parity cases for $f(f(n)) = n$ and deduces injectivity and surjectivity from it.
rubric: Part (b) proves reflexivity, symmetry and transitivity, with the cases in the transitivity argument handled and the identity $f(f(a)) = a$ used.
rubric: Part (c) identifies the classes as $\{2k, 2k+1\}$ and argues countability through an explicit bijection with $\mathbb{Z}$.
hint: For (a), split into even and odd $n$. For the deduction, ask what $f(f(n)) = n$ says about injectivity and about finding a preimage.
hint: For (b), the identity $f(f(a)) = a$ is what makes symmetry and transitivity work. Check each property by cases on which alternative ("$b = a$" or "$b = f(a)$") holds.
hint: For (c), compute $[0]$, $[1]$, $[2]$, $[3]$ and spot the pattern, then match classes to integers.

@exam ms
prompt: Select every statement that is true. Here $f: A \to B$ and $g: B \to C$ are functions.
choice*: If $g \circ f$ is injective, then $f$ is injective.
choice: If $g \circ f$ is surjective, then $f$ is surjective.
choice*: For an integer $n$, the statement "if $n^2$ is odd then $n$ is odd" is logically equivalent to "if $n$ is even then $n^2$ is even".
choice*: Every infinite subset of $\mathbb{N}$ is countably infinite.
choice: The relation $a \le b$ on $\mathbb{R}$ is an equivalence relation.
hint: For each statement, try to prove it with the template for its method. If you get stuck, search for a counterexample on very small sets.
hint: For the function statements, begin with "suppose $f(a) = f(a')$" for injectivity and "let $c \in C$" for surjectivity, and see what the composition tells you.
solution: If $g(f(a)) = g(f(a'))$ forces $a = a'$, then $f(a) = f(a')$ certainly forces $a = a'$, because applying $g$ to equal values gives equal values; so the statement about $g \circ f$ being injective is true. The statement about $g \circ f$ being surjective is false: take $f: \{1\} \to \{1, 2\}$ with $f(1) = 1$ and $g: \{1, 2\} \to \{1\}$ constant; then $g \circ f$ is surjective but $f$ misses $2$. The two conditionals about $n^2$ odd and $n$ even are a statement and its contrapositive, so they are equivalent. The statement about infinite subsets of $\mathbb{N}$ is true because a subset of a countable set is countable and an infinite countable set is countably infinite. The statement that $\le$ is an equivalence relation is false, since $\le$ is not symmetric.

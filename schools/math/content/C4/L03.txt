@article
Most theorems have the form "if $P$, then $Q$". A **direct proof** is the most natural way to establish one: **assume** $P$, then use definitions and earlier facts to **derive** $Q$. Nothing is assumed about $Q$; it is the destination, not the starting point.

### Start with a concrete case

Is the sum of two odd integers always even? Try $3 + 7 = 10$ and $(-5) + 11 = 6$. Both are even. The pattern suggests why: each odd number is one more than an even number, so two of them contribute two extra ones, which pair up. A proof turns that idea into algebra.

### Definitions are the raw material

Almost every first proof is a matter of unpacking definitions into equations.

- An integer $n$ is **even** if $n = 2k$ for some integer $k$, and **odd** if $n = 2k + 1$ for some integer $k$.
- For integers $a \neq 0$ and $b$, **$a$ divides $b$**, written $a \mid b$, if $b = ac$ for some integer $c$.

We also use **closure**: sums, differences and products of integers are integers.

### The shape of a direct proof

**Proposition.** If $P$, then $Q$.

**Proof.** Suppose $P$. (Unpack $P$ using definitions.) (Manipulate, justifying each step.) Therefore $Q$. $\blacksquare$

Here is a complete example.

**Proposition.** If $a$ and $b$ are odd integers, then $a + b$ is even.

**Proof.** Suppose $a$ and $b$ are odd. Then $a = 2k + 1$ and $b = 2m + 1$ for some integers $k$ and $m$. Adding, $a + b = 2k + 2m + 2 = 2(k + m + 1)$. Since $k + m + 1$ is an integer, $a + b$ is even. $\blacksquare$

Notice three habits. The proof **opens** by stating what is assumed. It uses **two different letters**, $k$ and $m$, because nothing says $a$ and $b$ are equal. And it **closes** by returning to the definition: $a + b$ is $2$ times an integer.

### Cases

Sometimes the hypothesis gives several possibilities rather than one equation. Every integer is even or odd, so a statement about every integer $n$ can be proved by treating these two **cases** separately, provided they cover all possibilities. Each case must end at the same conclusion.

### Tests are not proofs

A computer can check thousands of integers, but a proof covers all of them at once.

```python
print(all((n * n + n) % 2 == 0 for n in range(-1000, 1001)))   # True
```

This supports the claim that $n^2 + n$ is even for every integer $n$, and the second example below proves it. Use checks to find conjectures and to hunt for counterexamples, then write the argument.

@example
title: Divisibility passes to combinations
problem: Prove that if $a \mid b$ and $a \mid c$, then $a \mid (3b - 5c)$.
step: Assume the hypothesis and unpack it. Since $a \mid b$, there is an integer $p$ with $b = ap$. Since $a \mid c$, there is an integer $q$ with $c = aq$. We use two letters because $b$ and $c$ need not be equal.
step: Substitute into the expression we care about: $3b - 5c = 3(ap) - 5(aq)$.
step: Factor out $a$: $3(ap) - 5(aq) = a(3p - 5q)$.
step: The number $3p - 5q$ is an integer, because the integers are closed under multiplication and subtraction.
step: So $3b - 5c = a \cdot (\text{an integer})$, which is exactly the definition of $a \mid (3b - 5c)$. $\blacksquare$

@example
title: Using cases
problem: Prove that for every integer $n$, the product $n(n + 1)$ is even.
step: Every integer is either even or odd, so we consider these two cases. Together they cover all integers.
step: Case 1, $n$ even. Then $n = 2k$ for some integer $k$, so $n(n + 1) = 2k(n + 1) = 2[k(n + 1)]$.
step: Case 2, $n$ odd. Then $n = 2k + 1$, so $n + 1 = 2k + 2 = 2(k + 1)$ and $n(n + 1) = 2[n(k + 1)]$.
step: In both cases $n(n + 1)$ equals $2$ times an integer, so it is even. Since $n^2 + n = n(n + 1)$, this also explains the Python check above. $\blacksquare$

@mistakes
- Assuming the conclusion and working backwards until you reach a true statement. A direct proof must start from the hypothesis.
- Using one letter for two integers that need not be equal, for example writing $a = 2k + 1$ and $b = 2k + 1$.
- Checking a few values such as $n = 1, 2, 3$ and calling it a proof of a statement about all integers.
- Forgetting to say that the quantity you produced (such as $k + m + 1$) is an integer.

@practice self
prompt: Prove that if $n$ is an odd integer, then $n^2 + 3n + 5$ is odd.
solution: Suppose $n$ is odd, so $n = 2k + 1$ for some integer $k$. Then $n^2 + 3n + 5 = (4k^2 + 4k + 1) + (6k + 3) + 5 = 4k^2 + 10k + 9 = 2(2k^2 + 5k + 4) + 1$. Since $2k^2 + 5k + 4$ is an integer, $n^2 + 3n + 5$ is odd. $\blacksquare$
rubric: The proof begins by assuming $n$ is odd and writes $n = 2k + 1$ for an integer $k$.
rubric: The expansion and collection of $n^2 + 3n + 5$ is algebraically correct.
rubric: The result is written as $2 \cdot (\text{integer}) + 1$, and the proof says the integer in brackets is an integer.
hint: Substitute $n = 2k + 1$ everywhere and expand.
hint: Collect terms until you can factor a $2$ out of everything except a single $1$.

@practice self
prompt: Prove that for every integer $n$, the square $n^2$ leaves remainder $0$ or $1$ when divided by $3$.
solution: Every integer can be written as $3q$, $3q + 1$ or $3q + 2$ for some integer $q$, and these cases cover all integers. Case 1: $n = 3q$ gives $n^2 = 9q^2 = 3(3q^2)$, remainder $0$. Case 2: $n = 3q + 1$ gives $n^2 = 9q^2 + 6q + 1 = 3(3q^2 + 2q) + 1$, remainder $1$. Case 3: $n = 3q + 2$ gives $n^2 = 9q^2 + 12q + 4 = 3(3q^2 + 4q + 1) + 1$, remainder $1$. In every case the remainder is $0$ or $1$. $\blacksquare$
rubric: The proof splits into the three cases $n = 3q$, $3q + 1$, $3q + 2$ and says these cover all integers.
rubric: Each case expands $n^2$ correctly.
rubric: Each case writes $n^2 = 3(\text{integer}) + r$ with $r \in \{0, 1\}$ and the proof concludes.
hint: Division by $3$ leaves remainder $0$, $1$ or $2$, so any integer has one of three forms.
hint: In each case, expand $n^2$ and pull out a factor of $3$, leaving a small constant over.

@quiz num
prompt: The values of $n^2 + n + 41$ are prime for $n = 1, 2, 3, \dots$ for a long stretch. What is the smallest positive integer $n$ for which $n^2 + n + 41$ is NOT prime?
answer: 40
check: min(n for n in range(1, 100) if sum(1 for d in range(2, n*n + n + 41) if (n*n + n + 41) % d == 0) > 0)
hint: Many prime values support a pattern but never prove it. Look for an $n$ that makes the expression a multiple of $41$.
hint: $n^2 + n + 41$ is a multiple of $41$ exactly when $41 \mid n(n + 1)$.
hint: Which $n$ just below $41$ makes $n(n + 1)$ a multiple of $41$?
solution: If $n = 40$ then $n^2 + n + 41 = 1600 + 40 + 41 = 1681 = 41^2$, which is not prime. The values for $n = 1, \dots, 39$ are all prime, so $40$ is the smallest.

@quiz self
prompt: Let $a$ and $b$ be nonzero integers and let $c$ be any integer. Prove directly that if $a \mid b$ and $b \mid c$, then $a \mid c$.
solution: Suppose $a \mid b$ and $b \mid c$. Then $b = ap$ for some integer $p$ and $c = bq$ for some integer $q$. Substituting, $c = (ap)q = a(pq)$. Since $pq$ is an integer, $a \mid c$. $\blacksquare$
rubric: Both hypotheses are unpacked into equations using two different integers, such as $p$ and $q$.
rubric: The substitution $c = (ap)q$ is made correctly and regrouped as $a(pq)$.
rubric: The proof says $pq$ is an integer and returns to the definition of $a \mid c$.
hint: Write what each hypothesis says as an equation with its own integer.
hint: Express $c$ using only $a$ and integers.

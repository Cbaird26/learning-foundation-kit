@article
Is the point $0$ "touching" the interval $(0, 1)$? It is not in the set, yet every interval around $0$ contains points of $(0, 1)$. Topology turns this feeling into a definition that uses only open sets, so it makes sense in spaces with no distances at all.

### Definitions

Let $(X, \mathcal{T})$ be a topological space and $A \subseteq X$.

- $A$ is **closed** if $X \setminus A$ is open. Closed sets contain $\emptyset$ and $X$, are closed under arbitrary intersections and finite unions (De Morgan applied to the axioms).
- The **closure** $\operatorname{Cl} A$ (also written $\overline{A}$) is the intersection of all closed sets containing $A$: the smallest closed set containing $A$.
- The **interior** $\operatorname{Int} A$ is the union of all open sets contained in $A$: the largest open subset of $A$.
- The **boundary** is $\operatorname{Bd} A = \operatorname{Cl} A \setminus \operatorname{Int} A$.
- A point $x$ is a **limit point** of $A$ if every open set containing $x$ contains a point of $A$ other than $x$. The set of limit points is the **derived set** $A'$.
- $A$ is **dense** if $\operatorname{Cl} A = X$.

An **open neighborhood** of $x$ is an open set containing $x$.

### The closure theorems

**Theorem 1.** $x \in \operatorname{Cl} A$ if and only if every open neighborhood of $x$ meets $A$.

*Proof.* Suppose some open $U \ni x$ has $U \cap A = \emptyset$. Then $X \setminus U$ is a closed set containing $A$, so $\operatorname{Cl} A \subseteq X \setminus U$ and $x \notin \operatorname{Cl} A$. Conversely, suppose $x \notin \operatorname{Cl} A$. Then $U = X \setminus \operatorname{Cl} A$ is open, contains $x$, and is disjoint from $A \subseteq \operatorname{Cl} A$. $\blacksquare$

**Theorem 2.** $\operatorname{Cl} A = A \cup A'$.

*Proof.* If $x \in A$ then $x \in \operatorname{Cl} A$. If $x \in A'$, every open neighborhood of $x$ meets $A$, so $x \in \operatorname{Cl} A$ by Theorem 1. Conversely let $x \in \operatorname{Cl} A$ with $x \notin A$. Every open neighborhood of $x$ meets $A$, and the common point cannot be $x$ itself, so $x \in A'$. $\blacksquare$

**Theorem 3.** $X \setminus \operatorname{Int} A = \operatorname{Cl}(X \setminus A)$. Indeed, $X \setminus \bigcup\{U \text{ open}: U \subseteq A\} = \bigcap\{X \setminus U : X \setminus U \text{ closed},\ X \setminus U \supseteq X \setminus A\}$.

In particular $A$ is open if and only if $A = \operatorname{Int} A$, and closed if and only if $A = \operatorname{Cl} A$.

### Examples

In $\mathbb{R}$: $\operatorname{Cl}(0, 1) = [0, 1]$, $\operatorname{Int}[0, 1] = (0, 1)$, and $\mathbb{Q}$ is dense with $\operatorname{Int} \mathbb{Q} = \emptyset$. In the cofinite topology on an infinite set $X$ the closed sets are $X$ and the finite sets, so an infinite $A$ lies in no proper closed set and $\operatorname{Cl} A = X$: every infinite set is dense.

On $X = \{a, b, c, d\}$ with open sets $\emptyset, \{a\}, \{c, d\}, \{a, c, d\}, X$ the closed sets are $X, \{b, c, d\}, \{a, b\}, \{b\}, \emptyset$. The closure of $\{c\}$ is the smallest closed set containing $c$, namely $\{b, c, d\}$. Closure and interior behave unevenly: $\operatorname{Cl}(A \cup B) = \operatorname{Cl} A \cup \operatorname{Cl} B$ always holds, but $\operatorname{Cl}(A \cap B) \subseteq \operatorname{Cl} A \cap \operatorname{Cl} B$ can be strict. In $\mathbb{R}$ take $A = (0, 1)$ and $B = (1, 2)$: $A \cap B = \emptyset$ but $\operatorname{Cl} A \cap \operatorname{Cl} B = \{1\}$.

### Closure and interior by program

For a finite space (open sets as frozensets) the definitions translate directly:

```python
def closure(X, T, A):
    """Intersection of all closed sets containing A."""
    X, A = frozenset(X), frozenset(A)
    result = X
    for U in T:
        closed = X - U
        if A <= closed:
            result &= closed
    return result


def interior(X, T, A):
    """Union of all open sets contained in A."""
    A = frozenset(A)
    result = frozenset()
    for U in T:
        if U <= A:
            result |= U
    return result


X = frozenset("abcd")
T = [frozenset(s) for s in ["", "a", "cd", "acd", "abcd"]]
print(sorted(closure(X, T, "c")), sorted(interior(X, T, "ac")))
```

It prints `['b', 'c', 'd'] ['a']`. These functions give correct answers for the finite examples we feed them; statements about all spaces still need the proofs above.

@example
title: Closure, interior, limit points and boundary in a finite space
problem: Let $X = \{1, 2, 3, 4, 5\}$ with open sets $\emptyset, \{1\}, \{1, 2\}, \{1, 3\}, \{1, 2, 3\}, \{1, 2, 3, 4\}, X$. For $A = \{2, 5\}$ find $\operatorname{Cl} A$, $\operatorname{Int} A$, $A'$ and $\operatorname{Bd} A$.
step: Closed sets are the complements: $X$, $\{2, 3, 4, 5\}$, $\{3, 4, 5\}$, $\{2, 4, 5\}$, $\{4, 5\}$, $\{5\}$, $\emptyset$.
step: Closure. The closed sets containing $\{2, 5\}$ are $X$, $\{2, 3, 4, 5\}$ and $\{2, 4, 5\}$. Their intersection is $\operatorname{Cl} A = \{2, 4, 5\}$.
step: Interior. The only open set inside $\{2, 5\}$ is $\emptyset$, so $\operatorname{Int} A = \emptyset$.
step: Limit points. The point $1$ has the neighborhood $\{1\}$, $3$ has $\{1, 3\}$, both missing $A$. The point $2$ has $\{1, 2\}$, which meets $A$ only in $2$ itself. The neighborhoods of $4$ are $\{1, 2, 3, 4\}$ and $X$, and the point $5$ has only $X$; all contain $2 \in A$ with $2 \ne 4, 5$. So $A' = \{4, 5\}$.
step: Check with Theorem 2: $A \cup A' = \{2, 4, 5\} = \operatorname{Cl} A$. The boundary is $\operatorname{Cl} A \setminus \operatorname{Int} A = \{2, 4, 5\}$.
answer: $\operatorname{Cl} A = \{2, 4, 5\}$, $\operatorname{Int} A = \emptyset$, $A' = \{4, 5\}$, $\operatorname{Bd} A = \{2, 4, 5\}$.

@example
title: Interiors do not commute with unions
problem: Prove that $\operatorname{Int}(A \cap B) = \operatorname{Int} A \cap \operatorname{Int} B$ for all subsets of a space, and show by example that $\operatorname{Int}(A \cup B) \ne \operatorname{Int} A \cup \operatorname{Int} B$ in general.
step: To show $\subseteq$: $A \cap B \subseteq A$, and the interior is monotone (a larger set contains every open set the smaller one does), so $\operatorname{Int}(A \cap B) \subseteq \operatorname{Int} A$; likewise for $B$.
step: To show $\supseteq$: $\operatorname{Int} A \cap \operatorname{Int} B$ is open (finite intersection of open sets) and contained in $A \cap B$. Hence it lies in the largest open subset of $A \cap B$.
step: For unions, the same monotonicity gives only $\operatorname{Int} A \cup \operatorname{Int} B \subseteq \operatorname{Int}(A \cup B)$.
step: Strictness: in $\mathbb{R}$ let $A = [0, 1]$ and $B = [1, 2]$. Then $\operatorname{Int}(A \cup B) = (0, 2)$ contains $1$, but $\operatorname{Int} A \cup \operatorname{Int} B = (0, 1) \cup (1, 2)$ does not.
answer: Interior commutes with finite intersections only.

@mistakes
- Confusing "limit point of $A$" with "point of $A$": $\operatorname{Cl} A = A \cup A'$, and an isolated point of $A$ belongs to $A$ without being a limit point of it.
- Writing $\operatorname{Cl}(A \cap B) = \operatorname{Cl} A \cap \operatorname{Cl} B$: only $\subseteq$ holds, as $(0, 1)$ and $(1, 2)$ show.
- Assuming a set is either open or closed: $[0, 1)$ is neither, and $\emptyset$, $X$ are both.
- Finding the closure by adding "endpoints" by eye in a non-metric space: use Theorem 1 or the smallest closed set containing $A$.

def derived_set(X, T, A):

prompt: Let $A$ be a dense subset of a topological space $X$ and let $U \subseteq X$ be open. Prove that $\operatorname{Cl}(U \cap A) = \operatorname{Cl}(U)$.
hint: One inclusion follows from monotonicity of closure. For the other, use Theorem 1 with a neighborhood $W$ of a point of $\operatorname{Cl} U$ and look at the open set $W \cap U$.
solution: Since $U \cap A \subseteq U$, we have $\operatorname{Cl}(U \cap A) \subseteq \operatorname{Cl} U$. Conversely let $x \in \operatorname{Cl} U$ and let $W$ be an open neighborhood of $x$. By Theorem 1, $W \cap U \ne \emptyset$. The set $W \cap U$ is open, and $A$ is dense, so it meets $A$ (a dense set meets every nonempty open set, by Theorem 1). Thus $W \cap (U \cap A) \ne \emptyset$. Since $W$ was arbitrary, Theorem 1 gives $x \in \operatorname{Cl}(U \cap A)$. $\blacksquare$ Openness of $U$ is essential: with $U = \{0\}$ and $A = \mathbb{Q} \setminus \{0\}$ in $\mathbb{R}$ we get $U \cap A = \emptyset$ but $\operatorname{Cl} U = \{0\}$.

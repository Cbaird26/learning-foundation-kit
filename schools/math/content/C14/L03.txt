A rubber band can be stretched into a circle, a square or a triangle, but cutting it or gluing two points together changes it. Topology makes this precise with maps that preserve "nearness" without measuring it.

### Continuity

**Definition.** A function $f\colon X \to Y$ between topological spaces is **continuous** if $f^{-1}(V)$ is open in $X$ for every open $V \subseteq Y$.

Preimages respect unions, intersections and complements, which gives several equivalent tests.

**Theorem 1.** For $f\colon X \to Y$ the following are equivalent.

- (a) $f$ is continuous.
- (b) $f^{-1}(C)$ is closed in $X$ for every closed $C \subseteq Y$.
- (c) $f(\operatorname{Cl} A) \subseteq \operatorname{Cl} f(A)$ for every $A \subseteq X$.
- (d) For some basis $\mathcal{B}$ of $Y$, $f^{-1}(B)$ is open for every $B \in \mathcal{B}$.

*Proof.* (a)$\iff$(b): $f^{-1}(Y \setminus V) = X \setminus f^{-1}(V)$, so open preimages of open sets correspond to closed preimages of closed sets.
(b)$\Rightarrow$(c): the set $C = \operatorname{Cl} f(A)$ is closed and $A \subseteq f^{-1}(C)$. By (b), $f^{-1}(C)$ is closed, so $\operatorname{Cl} A \subseteq f^{-1}(C)$, i.e. $f(\operatorname{Cl} A) \subseteq C$.
(c)$\Rightarrow$(b): let $C \subseteq Y$ be closed and $A = f^{-1}(C)$. Then $f(\operatorname{Cl} A) \subseteq \operatorname{Cl} f(A) \subseteq \operatorname{Cl} C = C$, so $\operatorname{Cl} A \subseteq f^{-1}(C) = A$, and $A$ is closed.
(a)$\Rightarrow$(d) is trivial. (d)$\Rightarrow$(a): an open $V$ is a union $\bigcup_i B_i$ of basis sets, so $f^{-1}(V) = \bigcup_i f^{-1}(B_i)$ is open. $\blacksquare$

A composite of continuous maps is continuous, because $(g \circ f)^{-1}(W) = f^{-1}(g^{-1}(W))$.

**Theorem 2 (metric spaces).** For $f\colon (X, d) \to (Y, \rho)$ with the metric topologies, $f$ is continuous if and only if for every $x \in X$ and $\varepsilon > 0$ there is $\delta > 0$ with $d(x, x') < \delta \Rightarrow \rho(f(x), f(x')) < \varepsilon$.

*Proof.* ($\Rightarrow$) The ball $B(f(x), \varepsilon)$ is open, so $f^{-1}$ of it is an open set containing $x$, and it contains some $B(x, \delta)$. ($\Leftarrow$) Let $V$ be open and $x \in f^{-1}(V)$. Pick $\varepsilon$ with $B(f(x), \varepsilon) \subseteq V$ and then $\delta$ from the hypothesis; then $B(x, \delta) \subseteq f^{-1}(V)$, so $f^{-1}(V)$ is open. $\blacksquare$

### Homeomorphisms

A **homeomorphism** is a bijection $f\colon X \to Y$ such that both $f$ and $f^{-1}$ are continuous. Equivalently, $f$ is a bijection and $U$ is open in $X$ if and only if $f(U)$ is open in $Y$: $f$ matches up the open sets. Then $X$ and $Y$ are **homeomorphic**, written $X \cong Y$, and share every **topological property** (one defined only through open sets, such as being discrete, having exactly $5$ open sets, or having a countable dense set).

The map $x \mapsto \tan(\pi x / 2)$ is a homeomorphism $(-1, 1) \to \mathbb{R}$: it is a strictly increasing continuous bijection, with continuous inverse $y \mapsto (2/\pi)\arctan y$. So boundedness is not a topological property, since $(-1, 1)$ is bounded and $\mathbb{R}$ is not.

**A continuous bijection need not be a homeomorphism.** Consider the identity map from $\mathbb{R}$ with the discrete topology to $\mathbb{R}$ with the standard topology: it is continuous, since every subset is open in the discrete topology, but its inverse is not, since $\{0\}$ is open in the discrete topology and not in the standard one. A classic geometric instance is $t \mapsto e^{2\pi i t}$ from $[0, 1)$ onto the unit circle: it is a continuous bijection that is not a homeomorphism. We prove that in Week 7 (it needs compactness; here it is stated, not proved).

### Testing continuity on finite spaces

For maps between finite spaces we can check the definition directly. Represent $f$ as a dictionary.

```python
def is_continuous(f, X, TX, Y, TY):
    """f is a dict X -> Y; TX, TY are lists of frozensets (open sets)."""
    opens = {frozenset(U) for U in TX}
    for V in TY:
        pre = frozenset(x for x in X if f[x] in V)
        if pre not in opens:
            return False
    return True


X = [0, 1, 2]
TX = [frozenset(s) for s in [(), (0,), (0, 1), (0, 1, 2)]]
Y = ["a", "b"]
TY = [frozenset(s) for s in [(), ("a",), ("a", "b")]]
f = {0: "a", 1: "a", 2: "b"}
g = {0: "b", 1: "a", 2: "a"}
print(is_continuous(f, X, TX, Y, TY), is_continuous(g, X, TX, Y, TY))
```

This prints `True False`: $f^{-1}(\{a\}) = \{0, 1\}$ is open, while $g^{-1}(\{a\}) = \{1, 2\}$ is not.

@example
title: A homeomorphism between two intervals
problem: Show that $f\colon (0, 1) \to (0, \infty)$, $f(x) = \dfrac{x}{1 - x}$, is a homeomorphism.
step: Well defined and continuous: for $0 < x < 1$ the denominator is positive, so $f$ is a quotient of continuous functions and $f(x) > 0$. Both subspaces carry the metric topology, so Theorem 2 applies.
step: Surjective and injective: solve $y = x/(1 - x)$ for $x$ to get $y(1 - x) = x$, i.e. $x = y/(1 + y)$. For every $y > 0$ this $x$ lies in $(0, 1)$ because $0 < y < 1 + y$, and it is the only solution.
step: The inverse $g(y) = y/(1 + y)$ is continuous on $(0, \infty)$ (its denominator is positive).
step: Hence $f$ is a continuous bijection with continuous inverse.
answer: $f$ is a homeomorphism, so $(0, 1) \cong (0, \infty)$.

@example
title: Finer topologies and the identity map
problem: Let $\mathcal{T}_\ell$ be the lower limit topology on $\mathbb{R}$ (basis $[a, b)$) and $\mathcal{T}$ the standard one. Show that the identity $\iota\colon (\mathbb{R}, \mathcal{T}_\ell) \to (\mathbb{R}, \mathcal{T})$ is continuous but not a homeomorphism.
step: $\iota$ is a bijection. To test continuity use Theorem 1(d) with the basis of open intervals $(a, b)$ of the target.
step: $\iota^{-1}((a, b)) = (a, b) = \bigcup_{a < x < b} [x, b)$ is open in $\mathcal{T}_\ell$. So $\iota$ is continuous.
step: The inverse is the identity $(\mathbb{R}, \mathcal{T}) \to (\mathbb{R}, \mathcal{T}_\ell)$. The set $[0, 1)$ is open in $\mathcal{T}_\ell$, but its preimage under this inverse is $[0, 1)$, which is not open in $\mathcal{T}$.
step: In general, the identity from a finer to a coarser topology is continuous, and it is a homeomorphism only if the two topologies are equal.
answer: $\iota$ is a continuous bijection whose inverse is not continuous.

@mistakes
- Testing continuity by images instead of preimages: $f(U)$ need not be open when $U$ is (a constant map is continuous).
- Thinking a continuous bijection is a homeomorphism: the identity from a finer to a coarser topology is a counterexample.
- Mixing up the direction of the inclusion in Theorem 1(c): continuity gives $f(\operatorname{Cl} A) \subseteq \operatorname{Cl} f(A)$, and equality can fail: for the inclusion $(0, 1) \to \mathbb{R}$ and $A = (0, \tfrac12]$, $f(\operatorname{Cl} A) = (0, \tfrac12]$ but $\operatorname{Cl} f(A) = [0, \tfrac12]$.
- Calling a property topological when it depends on a metric: boundedness and completeness are not preserved by homeomorphisms.

model:
```python
from itertools import permutations


def _continuous(f, X, TX, TY):
    opens = set(TX)
    return all(frozenset(x for x in X if f[x] in V) in opens for V in TY)


def homeomorphic(X, TX, Y, TY):
    """True if some bijection X -> Y is a homeomorphism."""
    if len(X) != len(Y):
        return False
    TX = [frozenset(U) for U in TX]
    TY = [frozenset(V) for V in TY]
    for image in permutations(Y):
        f = dict(zip(X, image))
        g = {y: x for x, y in f.items()}
        if _continuous(f, X, TX, TY) and _continuous(g, Y, TY, TX):
            return True
    return False
```
hint: A bijection is determined by a permutation of `Y`; build `f` with `zip` and the inverse by swapping keys and values.
solution: For every bijection test continuity of the map and of its inverse using preimages of open sets. Comparing only the number of open sets is wrong: the two topologies `T1` and `T2` above both have five open sets but are not homeomorphic, since in `T1` two points are separated by open singletons, which a homeomorphism would have to preserve.

@practice self
prompt: Let $f\colon X \to Y$ be a bijection between topological spaces. Prove that $f$ is a homeomorphism if and only if $f(\operatorname{Cl} A) = \operatorname{Cl} f(A)$ for every $A \subseteq X$.
hint: Use Theorem 1(c) for $f$ and for $f^{-1}$.
solution: ($\Rightarrow$) Since $f$ is continuous, $f(\operatorname{Cl} A) \subseteq \operatorname{Cl} f(A)$ by Theorem 1(c). Since $f^{-1}$ is continuous, applying (c) to $f^{-1}$ and the set $f(A)$ gives $f^{-1}(\operatorname{Cl} f(A)) \subseteq \operatorname{Cl} f^{-1}(f(A)) = \operatorname{Cl} A$; applying $f$ gives $\operatorname{Cl} f(A) \subseteq f(\operatorname{Cl} A)$ because $f$ is a bijection. ($\Leftarrow$) The hypothesis gives (c) for $f$, so $f$ is continuous. Let $g = f^{-1}$ and $B \subseteq Y$; put $A = g(B)$, so $B = f(A)$. Then $g(\operatorname{Cl} B) = g(\operatorname{Cl} f(A)) = g(f(\operatorname{Cl} A)) = \operatorname{Cl} A = \operatorname{Cl} g(B)$, so $g$ satisfies (c) and is continuous. $\blacksquare$
rubric: Uses Theorem 1(c) for $f$ to get one inclusion.
rubric: Uses (c) for $f^{-1}$ on the set $f(A)$ and the bijectivity of $f$ to get the reverse inclusion.
rubric: For the converse, derives continuity of $f$ and of $f^{-1}$ separately from the equality.

@article
Two points of a space can be indistinguishable by open sets (the indiscrete topology), or distinguishable but not separable by disjoint open sets (the line with two origins below), or nicely separated. The more separation a space has, the more it behaves like a metric space. Countability axioms play a complementary role: they say a space has a small description.

### Countability

A **neighborhood base** at $x$ is a family of open sets containing $x$ such that every open set containing $x$ contains a member of it. A space is **first countable** if every point has a countable neighborhood base, and **second countable** if the topology has a countable basis. It is **separable** if it has a countable dense subset, and **Lindelof** if every open cover has a countable subcover.

Metric spaces are first countable (balls of radius $1/n$). The space $\mathbb{R}^n$ is second countable: balls with rational centers and rational radii form a countable basis.

**Theorem 1.** A second countable space is first countable, separable and Lindelof.

*Proof.* Let $\{B_n\}$ be a countable basis. First countable: for each $x$, the $B_n$ containing $x$ form a neighborhood base. Separable: choose a point $d_n \in B_n$ for each nonempty $B_n$; every nonempty open set contains some $B_n$, hence some $d_n$, so $\{d_n\}$ is dense. Lindelof: given an open cover $\mathcal{U}$, let $N$ be the set of $n$ such that $B_n$ lies in some member of $\mathcal{U}$, and for $n \in N$ choose such a member $U_n$. Each $x$ lies in some $U \in \mathcal{U}$ and so in some $B_n \subseteq U$ with $n \in N$, hence in $U_n$. So $\{U_n\}_{n \in N}$ is a countable subcover. $\blacksquare$

None of the reverse implications holds in general. For metric spaces, separable, second countable and Lindelof are equivalent; the Sorgenfrey line below separates first countable plus separable from second countable.

### Separation axioms

Conventions vary between books; we use the following. A space is

- **T0** if for any two distinct points some open set contains exactly one of them;
- **T1** if for any two distinct points $x, y$ there is an open set containing $x$ but not $y$ (and one containing $y$ but not $x$);
- **Hausdorff** (T2) if distinct points have disjoint open neighborhoods;
- **regular** (T3) if it is T1 and for every point $x$ and closed set $C \not\ni x$ there are disjoint open sets $U \ni x$ and $V \supseteq C$;
- **normal** (T4) if it is T1 and any two disjoint closed sets have disjoint open neighborhoods.

Then normal $\Rightarrow$ regular $\Rightarrow$ Hausdorff $\Rightarrow$ T1 $\Rightarrow$ T0 (each with the T1 requirement built in where stated). Metric spaces are Hausdorff, and compact Hausdorff spaces are normal (closed sets are compact, and the Week 6 exercise separates disjoint compact sets).

**Theorem 2.** A space is T1 if and only if every singleton is closed.

*Proof.* ($\Rightarrow$) For $y \ne x$ there is an open set containing $y$ but not $x$, so $X \setminus \{x\}$ is a union of open sets and hence open. ($\Leftarrow$) If $\{x\}$ and $\{y\}$ are closed, $X \setminus \{x\}$ is an open set containing $y$ but not $x$, and symmetrically. $\blacksquare$

In a finite space T1 forces every singleton to be closed, hence every subset to be closed, hence the topology to be discrete. So finite T1 spaces are just discrete ones, and the interesting finite examples are T0 but not T1, such as the Sierpinski space $\{0, 1\}$ with open sets $\emptyset, \{1\}, \{0, 1\}$. A limit of a sequence in a Hausdorff space is unique; in a non-Hausdorff space it need not be.

@example
title: The Sorgenfrey line
problem: Let $\mathbb{R}_\ell$ be $\mathbb{R}$ with the lower limit topology (basis $[a, b)$). Show that it is first countable and separable but not second countable.
step: First countable: the sets $[x, x + 1/n)$, $n \ge 1$, form a neighborhood base at $x$, because any basis set $[a, b)$ containing $x$ contains $[x, x + 1/n)$ once $1/n < b - x$.
step: Separable: $\mathbb{Q}$ is dense, since every nonempty open set contains a basis set $[a, b)$ with $a < b$, and that contains a rational number.
step: Not second countable: suppose $\mathcal{B}$ is a basis. For each $x \in \mathbb{R}$ the set $[x, x + 1)$ is open, so there is $B_x \in \mathcal{B}$ with $x \in B_x \subseteq [x, x + 1)$. Then $x = \min B_x$, so $x$ is determined by $B_x$.
step: Hence $x \mapsto B_x$ is an injection of $\mathbb{R}$ into $\mathcal{B}$, so $\mathcal{B}$ is uncountable.
answer: $\mathbb{R}_\ell$ is first countable and separable but not second countable, so separable does not imply second countable.

@example
title: The line with two origins
problem: Let $X$ be obtained from $\mathbb{R} \times \{0, 1\}$ by identifying $(x, 0)$ with $(x, 1)$ for every $x \ne 0$, with the quotient topology $q\colon \mathbb{R} \times \{0, 1\} \to X$. Show that $X$ is T1 but not Hausdorff.
step: Write $0_a = q(0, 0)$ and $0_b = q(0, 1)$, two distinct points. A set $U \subseteq X$ is open if and only if $q^{-1}(U)$ is open in $\mathbb{R} \times \{0, 1\}$.
step: Not Hausdorff: let $U \ni 0_a$ and $V \ni 0_b$ be open. Then $q^{-1}(U)$ contains $(-\varepsilon, \varepsilon) \times \{0\}$ and $q^{-1}(V)$ contains $(-\delta, \delta) \times \{1\}$ for some $\varepsilon, \delta > 0$.
step: For $0 < |x| < \min(\varepsilon, \delta)$ the point $q(x, 0) = q(x, 1)$ lies in both $U$ and $V$. So $U \cap V \ne \emptyset$.
step: T1: singletons are closed. For $p \in X$ the preimage $q^{-1}(\{p\})$ is a single point, or the pair $\{(x, 0), (x, 1)\}$ for $x \ne 0$; either is closed in $\mathbb{R} \times \{0, 1\}$. So $\{p\}$ is closed, and Theorem 2 gives T1.
answer: The line with two origins is T1 but not Hausdorff, although every point has a neighborhood homeomorphic to an interval.

@mistakes
- Treating T1 and Hausdorff as the same: the line with two origins and any infinite cofinite space are T1 and not Hausdorff.
- Forgetting that "regular" and "normal" include T1 in this course: without it, the indiscrete topology on two points would be both.
- Thinking separable implies second countable: the Sorgenfrey line is a counterexample (it holds for metric spaces).
- Using sequences to separate points in a general space: uniqueness of limits holds for Hausdorff spaces but need not hold elsewhere.

@practice ms
prompt: Which of these spaces are second countable?
choice*: $\mathbb{R}^3$ with the standard topology.
choice*: $\mathbb{N}$ with the cofinite topology.
choice: An uncountable set with the discrete topology.
choice: $\mathbb{R}$ with the cofinite topology.
hint: A basis of a discrete space must contain every singleton. For the cofinite topology on $\mathbb{R}$, the complements of the basis sets form a countable union of finite sets.
solution: Balls with rational centers and radii give a countable basis of $\mathbb{R}^3$. The cofinite topology on $\mathbb{N}$ has only countably many open sets (each is determined by a finite subset of $\mathbb{N}$), so it is second countable. A basis of an uncountable discrete space must contain all the (uncountably many) singletons. For $\mathbb{R}$ with the cofinite topology, a countable basis would have complements $F_n$ that are finite; choose $x \ne y$ both outside the countable set $\bigcup F_n$. The open set $\mathbb{R} \setminus \{y\}$ contains $x$, so it contains some basis set $B_n \ni x$, which would miss $y$, forcing $y \in F_n$, a contradiction.

@practice self
prompt: Prove that the Sorgenfrey line $\mathbb{R}_\ell$ (basis $[a, b)$) is regular. (It is T1 because it is finer than the standard topology, which is Hausdorff.)
hint: Show each basis set $[a, b)$ is closed as well as open. Then, given $x \notin C$ with $C$ closed, find a basis set $[x, x + \varepsilon)$ missing $C$.
solution: First, every basis set $[a, b)$ is closed: its complement $(-\infty, a) \cup [b, \infty)$ is open, because $(-\infty, a) = \bigcup_{y < a} [y, a)$ and $[b, \infty) = \bigcup_{n} [b, b + n)$. Now let $C$ be closed and $x \notin C$. The complement $\mathbb{R} \setminus C$ is open and contains $x$, so it contains a basis set $[a, b) \ni x$, and therefore also $[x, b)$. Put $\varepsilon = b - x$ and $U = [x, x + \varepsilon)$ and $V = \mathbb{R} \setminus U$. Then $U$ is open and contains $x$, $V$ is open (as $U$ is closed), $C \subseteq V$ because $U \cap C = \emptyset$, and $U \cap V = \emptyset$. $\blacksquare$
rubric: Shows basis sets $[a, b)$ are clopen by writing the complement as a union of basis sets.
rubric: Chooses $\varepsilon$ with $[x, x + \varepsilon)$ inside the open complement of $C$.
rubric: Takes $V$ to be the complement of $U$ and checks the two open sets are disjoint with $C \subseteq V$.

@practice self
prompt: Prove that a space $X$ is Hausdorff if and only if the diagonal $\Delta = \{(x, x) : x \in X\}$ is closed in $X \times X$ (with the product topology).
hint: The complement of $\Delta$ is open iff each point $(x, y)$ with $x \ne y$ has a basic neighborhood $U \times V$ missing $\Delta$.
solution: A set is open if and only if each of its points lies in a basis set $U \times V$ inside it. So $\Delta$ is closed iff for every $(x, y)$ with $x \ne y$ there are open $U \ni x$ and $V \ni y$ with $(U \times V) \cap \Delta = \emptyset$. Now $(U \times V) \cap \Delta = \emptyset$ means that no point $z$ lies in both $U$ and $V$, that is, $U \cap V = \emptyset$. Thus $\Delta$ is closed iff any two distinct points have disjoint open neighborhoods, which is the Hausdorff property. $\blacksquare$
rubric: Describes openness of $(X \times X) \setminus \Delta$ through basic rectangles $U \times V$.
rubric: Translates $(U \times V) \cap \Delta = \emptyset$ into $U \cap V = \emptyset$.
rubric: States both directions of the equivalence.

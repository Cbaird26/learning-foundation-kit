@article
Why can't a continuous function jump from $-1$ to $1$ without passing through $0$? Because its domain interval cannot be cut into two open pieces. Connectedness captures "being in one piece" using only open sets.

### Definitions

A **separation** of a space $X$ is a pair of disjoint nonempty open sets $U, V$ with $X = U \cup V$. The space is **connected** if it has no separation. Equivalently, the only subsets that are both open and closed (**clopen**) are $\emptyset$ and $X$: if $U$ is clopen, $U$ and $X \setminus U$ form a separation unless one is empty. A subset is connected if it is connected in the subspace topology. A **path** from $x$ to $y$ in $X$ is a continuous map $\gamma\colon [0, 1] \to X$ with $\gamma(0) = x$ and $\gamma(1) = y$, and $X$ is **path connected** if any two points are joined by a path.

### The line

**Theorem 1.** A subset $I \subseteq \mathbb{R}$ is connected if and only if it is an interval (if $a, b \in I$ and $a < c < b$ then $c \in I$).

*Proof.* If $I$ is not an interval, pick $a < c < b$ with $a, b \in I$ and $c \notin I$. Then $I \cap (-\infty, c)$ and $I \cap (c, \infty)$ are disjoint, nonempty, open in $I$ and cover $I$, so $I$ is not connected.

Now let $I$ be an interval and suppose $I = U \cup V$ is a separation. Take $a \in U$, $b \in V$ and assume $a < b$ (otherwise swap the names). Put $c = \sup (U \cap [a, b])$. Then $a \le c \le b$, so $c \in I$. If $c \in U$, then $c \ne b$ and, as $U$ is open in $I$, some $[c, c + \varepsilon)$ lies in $U$, contradicting the definition of $c$. If $c \in V$, then $c \ne a$ and $(c - \varepsilon, c] \subseteq V$ for some $\varepsilon > 0$, so $U \cap [a, b]$ lies in $[a, c - \varepsilon]$ and has supremum at most $c - \varepsilon$, a contradiction. $\blacksquare$

### Permanence properties

**Theorem 2.** If $f\colon X \to Y$ is continuous and $X$ is connected, then $f(X)$ is connected.

*Proof.* If $f(X) = U \cup V$ were a separation (open sets of the subspace $f(X)$), then $f^{-1}(U), f^{-1}(V)$ would be disjoint, nonempty, open and cover $X$. $\blacksquare$

With Theorem 1 this gives the intermediate value theorem: the image of an interval under a continuous real function is an interval.

**Theorem 3.** (a) If $\{A_i\}$ are connected subsets of $X$ with a common point, then $\bigcup A_i$ is connected. (b) If $A$ is connected and $A \subseteq B \subseteq \operatorname{Cl} A$, then $B$ is connected. (c) If $X, Y$ are connected, so is $X \times Y$.

*Proof.* (a) A separation of the union restricts to each $A_i$; since $A_i$ is connected it lies wholly in one of the two sets, and the one containing the common point is the same for every $i$. So the other set is empty. (b) Suppose $B = U \cup V$ is a separation. Since $A$ is connected, it lies wholly in $U$ or in $V$; say in $U$. Let $x \in V$. As $V$ is open in $B$, $V = W \cap B$ with $W$ open in $X$ and $x \in W$. Since $x \in \operatorname{Cl} A$, $W$ meets $A$, giving a point of $A \cap W \subseteq B \cap W = V$, contradicting $A \subseteq U$. (c) Fix $(x_0, y_0)$. For each $x$, the set $T_x = (X \times \{y_0\}) \cup (\{x\} \times Y)$ is a union of two connected sets (each homeomorphic to $X$ or $Y$) that meet at $(x, y_0)$, so it is connected by (a). All $T_x$ contain $(x_0, y_0)$, and $\bigcup_x T_x = X \times Y$. $\blacksquare$

**Theorem 4.** A path-connected space is connected. *Proof.* Fix $x_0$. For each $x$ choose a path from $x_0$ to $x$; its image is connected (Theorem 2, as $[0, 1]$ is connected) and contains $x_0$. $X$ is the union of these images, so Theorem 3(a) applies. $\blacksquare$

### The topologist's sine curve

Let $G = \{(x, \sin(1/x)) : 0 < x \le 1\}$ and $S = G \cup (\{0\} \times [-1, 1])$. The set $G$ is the continuous image of $(0, 1]$, hence connected, and $S = \operatorname{Cl} G$ (for $c \in [-1, 1]$ take $x_n = 1/(\arcsin c + 2\pi n) \to 0$), (no other point lies in the closure, since the graph is closed in $(0, 1] \times \mathbb{R}$), so $S$ is connected by Theorem 3(b).

**$S$ is not path connected.** Suppose $\gamma = (\gamma_1, \gamma_2)\colon [0, 1] \to S$ is a path from $(0, 0)$ to $(1, \sin 1)$. The set $\gamma_1^{-1}(0)$ is closed and nonempty; let $t_0$ be its maximum, so $t_0 < 1$ and $\gamma_1 > 0$ on $(t_0, 1]$. By continuity of $\gamma_2$ at $t_0$ there is $\delta > 0$ with $|\gamma_2(t) - \gamma_2(t_0)| < 1$ for $t \in [t_0, t_0 + \delta]$. The function $\gamma_1$ is continuous on $[t_0, t_0 + \delta]$, takes the value $0$ at $t_0$ and a positive value $m$ at $t_0 + \delta$, so by the intermediate value theorem it takes every value in $[0, m]$. Choose $n$ large with $u = 1/(\tfrac{\pi}{2} + 2\pi n)$ and $u' = 1/(\tfrac{3\pi}{2} + 2\pi n)$ both in $(0, m)$, and times $t, t'$ in the interval with $\gamma_1(t) = u$, $\gamma_1(t') = u'$. Then $\gamma_2(t) = \sin(\tfrac{\pi}{2} + 2\pi n) = 1$ and $\gamma_2(t') = -1$, so $|\gamma_2(t) - \gamma_2(t')| = 2$, but both are within $1$ of $\gamma_2(t_0)$, giving a difference below $2$. Contradiction. $\blacksquare$

### Connected components of a finite space

A finite space is connected exactly when it has no clopen subset other than $\emptyset$ and $X$:

```python
def is_connected(X, T):
    """True if the finite space (X, T) has no separation."""
    X = frozenset(X)
    opens = {frozenset(U) for U in T}
    for U in opens:
        if U and U != X and (X - U) in opens:
            return False
    return True


X = {1, 2, 3, 4}
sets = [(), (1,), (3,), (1, 3), (2, 4), (1, 2, 4), (2, 3, 4), (1, 2, 3, 4)]
T = [frozenset(s) for s in sets]
print(is_connected(X, T), is_connected({1, 2}, [frozenset(), frozenset({1, 2})]))
```

The output is `False True`: the open set $\{2, 4\}$ is also closed, since $\{1, 3\}$ is open. As always, this decides the finite case; infinite spaces need Theorems 1 to 4.

@example
title: The rationals are totally disconnected
problem: Prove that every subset $A \subseteq \mathbb{Q}$ with at least two points is disconnected.
step: Let $a < b$ be two points of $A$. Between them lies an irrational number $r$ (the irrationals are dense), so $a < r < b$.
step: Put $U = A \cap (-\infty, r)$ and $V = A \cap (r, \infty)$. Both are open in the subspace $A$, because they are intersections of $A$ with open rays.
step: They are disjoint, they cover $A$ (as $r \notin A \subseteq \mathbb{Q}$), and $a \in U$, $b \in V$ make both nonempty.
step: So $(U, V)$ is a separation of $A$. The same argument shows no interval with two points is contained in $\mathbb{Q}$, matching Theorem 1.
answer: The only connected subsets of $\mathbb{Q}$ are the single points (and $\emptyset$).

@example
title: Removing a point to distinguish spaces
problem: Show that $[0, 1)$ is not homeomorphic to $(0, 1)$.
step: Suppose $h\colon [0, 1) \to (0, 1)$ is a homeomorphism. Removing the point $0$ leaves $[0, 1) \setminus \{0\} = (0, 1)$, which is connected by Theorem 1.
step: The restriction of $h$ to this subspace is a homeomorphism onto $(0, 1) \setminus \{h(0)\}$, so that set must be connected.
step: But $h(0) = c \in (0, 1)$, and $(0, 1) \setminus \{c\} = (0, c) \cup (c, 1)$ is not an interval, so it is disconnected by Theorem 1. Contradiction.
answer: $[0, 1)$ and $(0, 1)$ are not homeomorphic: connectedness after deleting a point is a topological property.

@mistakes
- Believing connected implies path connected: the topologist's sine curve is connected but not path connected.
- Calling a union of two connected sets connected without checking that they intersect: $[0, 1] \cup [2, 3]$ is disconnected.
- Mixing up "connected" with "no isolated points" or "in one piece to the eye": test the definition with a separation or a clopen set.
- Deciding that $A \cap B$ is connected because $A$ and $B$ are: two arcs of a circle can intersect in two disjoint pieces.

model:
```python
def components(X, T):
    """Connected components of the finite space (X, T)."""
    whole = frozenset(X)
    opens = {frozenset(U) for U in T}
    clopen = [U for U in opens if whole - U in opens]
    result = set()
    for x in X:
        comp = frozenset(
            y for y in X if all((x in U) == (y in U) for U in clopen)
        )
        result.add(comp)
    return result
```
hint: A set `U` is clopen when both `U` and `whole - U` are open. Group the points by which clopen sets contain them.
solution: Collect the clopen sets; two points are equivalent when every clopen set contains both or neither, and the classes are the components. A tempting wrong rule is "two points are related if some proper open set contains both": in the space `T1` above, the point `2` lies in no proper open set at all, yet the whole space is connected.

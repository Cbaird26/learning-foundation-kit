@article
Two disjoint closed sets can be pulled apart by open sets in a normal space. A much stronger statement is that they can be pulled apart by a *function*: a continuous $f$ that is $0$ on one set and $1$ on the other. That is Urysohn's lemma, and it gives continuous real functions on abstract spaces that have no distances.

### A reformulation of normality

**Lemma 1.** A T1 space $X$ is normal if and only if for every closed $A$ and open $U \supseteq A$ there is an open $V$ with $A \subseteq V \subseteq \operatorname{Cl} V \subseteq U$.

*Proof.* ($\Rightarrow$) The sets $A$ and $X \setminus U$ are disjoint and closed, so there are disjoint open $V \supseteq A$ and $W \supseteq X \setminus U$. Then $V \subseteq X \setminus W$, which is closed, so $\operatorname{Cl} V \subseteq X \setminus W \subseteq U$. ($\Leftarrow$) Given disjoint closed $A, B$, put $U = X \setminus B$ and take $V$ as stated; then $V$ and $X \setminus \operatorname{Cl} V$ are disjoint open sets containing $A$ and $B$. $\blacksquare$

### Metric spaces

**Theorem 2.** Let $(X, d)$ be a metric space and $A, B$ nonempty, disjoint and closed. Then
$$f(x) = \frac{d(x, A)}{d(x, A) + d(x, B)}, \qquad d(x, S) = \inf_{s \in S} d(x, s),$$
is a continuous function $X \to [0, 1]$ with $f = 0$ on $A$ and $f = 1$ on $B$. Consequently $X$ is normal.

*Proof.* The function $x \mapsto d(x, S)$ is continuous (indeed $|d(x, S) - d(y, S)| \le d(x, y)$), and $d(x, S) = 0$ if and only if $x \in \operatorname{Cl} S = S$. So the denominator vanishes only if $x \in A \cap B = \emptyset$; hence $f$ is continuous, with values in $[0, 1]$, equal to $0$ exactly on $A$ and to $1$ exactly on $B$. Then $U = f^{-1}([0, \tfrac12))$ and $V = f^{-1}((\tfrac12, 1])$ are disjoint open sets containing $A$ and $B$. (If $A$ or $B$ is empty, take $U = X$ and $V = \emptyset$ or the reverse.) $\blacksquare$

### Urysohn's lemma

**Theorem 3 (Urysohn's lemma).** Let $X$ be a normal space and $A, B$ disjoint closed subsets. Then there is a continuous function $f\colon X \to [0, 1]$ with $f(A) = \{0\}$ and $f(B) = \{1\}$ (in fact $f = 0$ on $A$ and $f = 1$ on $B$).

*Proof.* Let $D_n = \{k/2^n : 0 \le k \le 2^n\}$ and $D = \bigcup_n D_n$ be the dyadic rationals in $[0, 1]$. We construct open sets $U_r$ for $r \in D$ such that $A \subseteq U_0$, $U_1 = X \setminus B$ and
$$r < s \implies \operatorname{Cl} U_r \subseteq U_s. \tag{$*$}$$
Put $U_1 = X \setminus B$, an open set containing $A$. By Lemma 1 choose open $U_0$ with $A \subseteq U_0 \subseteq \operatorname{Cl} U_0 \subseteq U_1$, so $(*)$ holds on $D_0$. Suppose $U_r$ is defined for $r \in D_n$ with $(*)$. Each new $r \in D_{n+1} \setminus D_n$ has the form $r = (2k+1)/2^{n+1}$ with neighbors $r^- = k/2^n$ and $r^+ = (k+1)/2^n$ in $D_n$, and $\operatorname{Cl} U_{r^-} \subseteq U_{r^+}$. By Lemma 1 choose open $U_r$ with $\operatorname{Cl} U_{r^-} \subseteq U_r \subseteq \operatorname{Cl} U_r \subseteq U_{r^+}$. To check $(*)$ for $r < s$ in $D_{n+1}$, note that for old $p < q$ we know $U_p \subseteq \operatorname{Cl} U_p \subseteq U_q$. If both are old, this is the induction hypothesis. If $r$ is new and $s$ is old, then $r^+ \le s$ and $\operatorname{Cl} U_r \subseteq U_{r^+} \subseteq U_s$. If $r$ is old and $s$ is new, then $r \le s^-$ and $\operatorname{Cl} U_r \subseteq \operatorname{Cl} U_{s^-} \subseteq U_s$. If both are new, then $r^+ \le s^-$ and $\operatorname{Cl} U_r \subseteq U_{r^+} \subseteq \operatorname{Cl} U_{s^-} \subseteq U_s$. By induction $(*)$ holds on all of $D$.

Extend by $U_r = X$ for every dyadic rational $r > 1$; then $(*)$ still holds. Define
$$f(x) = \inf\{ r \ge 0 \text{ dyadic} : x \in U_r \}.$$
Then $0 \le f \le 1$; $f = 0$ on $A \subseteq U_0$; and if $x \in B$ then $x \notin U_1 \supseteq U_r$ for all $r \le 1$, so $f(x) = 1$.

Two observations, for dyadic $r$: (i) if $x \in \operatorname{Cl} U_r$ then $f(x) \le r$, because $x \in U_s$ for every dyadic $s > r$ by $(*)$ and dyadics are dense; (ii) if $x \notin U_r$ then $f(x) \ge r$, because $x \notin U_s$ for $s < r$.

Continuity: it suffices to show that $f^{-1}((-\infty, c))$ and $f^{-1}((c, \infty))$ are open for every real $c$ (rays form a subbasis for $\mathbb{R}$). For $c < 0$ or $c > 1$ these preimages are $\emptyset$ or $X$, so let $0 \le c \le 1$. First, $f(x) < c$ if and only if $x \in U_r$ for some dyadic $r < c$ (if $f(x) < c$ some $r < c$ has $x \in U_r$ by definition of the infimum; the converse is $f(x) \le r$). So $f^{-1}((-\infty, c)) = \bigcup_{r < c} U_r$ is open. Second, $f(x) > c$ if and only if $x \notin \operatorname{Cl} U_s$ for some dyadic $s > c$: if $f(x) > c$, pick dyadic $c < s < s' < f(x)$; then $x \notin U_{s'}$ (else $f(x) \le s'$), and $\operatorname{Cl} U_s \subseteq U_{s'}$, so $x \notin \operatorname{Cl} U_s$; conversely $x \notin \operatorname{Cl} U_s$ gives $x \notin U_s$ and $f(x) \ge s > c$ by (ii). So $f^{-1}((c, \infty)) = \bigcup_{s > c} (X \setminus \operatorname{Cl} U_s)$ is open. $\blacksquare$

The **Tietze extension theorem** (stated without proof here) says that on a normal space, every continuous function from a closed subset into $[0, 1]$ extends to a continuous function on $X$; it is proved by a series of Urysohn functions.

@example
title: An explicit Urysohn function in the plane
problem: Let $A = \{(x, y) : x^2 + y^2 \le 1\}$ and $B = \{(x, y) : x^2 + y^2 \ge 4\}$ in $\mathbb{R}^2$. Find a continuous $f\colon \mathbb{R}^2 \to [0, 1]$ with $f = 0$ on $A$ and $f = 1$ on $B$ using Theorem 2.
step: Write $\rho = \sqrt{x^2 + y^2}$. For $A$ the distance is $d(p, A) = \max(\rho - 1, 0)$, and for $B$ it is $d(p, B) = \max(2 - \rho, 0)$.
step: Both sets are closed and disjoint, and the denominator $d(p, A) + d(p, B)$ equals $1$ on the annulus $1 \le \rho \le 2$, equals $\rho - 1 \ge 1$ for $\rho \ge 2$ and equals $2 - \rho \ge 1$ for $\rho \le 1$ (so it never vanishes).
step: Compute $f$ in each region. For $\rho \le 1$, $f = 0/(2 - \rho) = 0$. For $1 \le \rho \le 2$, $f = (\rho - 1)/1 = \rho - 1$. For $\rho \ge 2$, $f = (\rho - 1)/(\rho - 1) = 1$.
step: So $f(p) = \min(\max(\rho - 1, 0), 1)$, a continuous function of $\rho$, equal to $0$ on $A$ and $1$ on $B$.
answer: $f(x, y) = \min\{\max\{\sqrt{x^2 + y^2} - 1, 0\}, 1\}$.

@example
title: Separating closed sets that are not uniformly apart
problem: In $\mathbb{R}$ let $A = \{n : n \ge 2\}$ and $B = \{n + 1/n : n \ge 2\}$, both closed and disjoint. Evaluate the Urysohn function of Theorem 2 at $x = 3.25$, and explain why a separating function exists even though $d(A, B) = 0$.
step: The points of $A$ are $2, 3, 4, \dots$ and those of $B$ are $2.5, 3.333\ldots, 4.25, \dots$. At $x = 3.25$ the nearest point of $A$ is $3$ at distance $0.25$.
step: The nearest point of $B$ to $3.25$ is $10/3 = 3.333\ldots$ (the other neighbors are $2.5$ and $4.25$, farther away), at distance $1/12$.
step: Therefore $f(3.25) = 0.25/(0.25 + 1/12) = 0.75$.
step: The function exists because for each fixed $x$ the two distances are not both $0$, and the quotient is continuous; the sets have $\inf d(a, b) = 0$ (since $d(n, n + 1/n) = 1/n$) but never touch. Urysohn separation is about the sets, not about a uniform gap.
answer: $f(3.25) = 3/4$; the function exists because the sets are disjoint and closed.

@mistakes
- Assuming Urysohn's lemma for any Hausdorff or any regular space: normality is the hypothesis, and it cannot be weakened to regular.
- Forgetting the dyadic condition $(*)$ in the proof: $\operatorname{Cl} U_r \subseteq U_s$ for $r < s$, not merely $U_r \subseteq U_s$; with only the weaker condition continuity fails.
- Using $d(x, A) / (d(x, A) + d(x, B))$ when $A$ or $B$ is not closed: the denominator may vanish at a limit point of $A$ in $B$.
- Confusing "separated by open sets" with "separated by a continuous function": the second implies the first in every space, but the converse needs normality.

@practice num
prompt: In $\mathbb{R}^2$ let $A$ be the closed unit disk centered at $(0, 0)$ and $B$ the closed disk of radius $1$ centered at $(6, 0)$. Let $f(p) = d(p, A)/(d(p, A) + d(p, B))$. Find $f(2, 0)$.
answer: 0.25
check: (lambda a, b: a / (a + b))(max(0, 2 - 1), max(0, 4 - 1))
hint: The distance from a point to a closed disk is the distance to the center minus the radius (or $0$ if the point is inside).
solution: The point $(2, 0)$ is at distance $2$ from the center of $A$, so $d(p, A) = 2 - 1 = 1$. It is at distance $4$ from the center $(6, 0)$ of $B$, so $d(p, B) = 4 - 1 = 3$. Then $f = 1/(1 + 3) = 0.25$.

Put $U = f^{-1}([0, \tfrac13))$ and $V = f^{-1}((\tfrac23, 1])$; they are open since $f$ is continuous, with $A \subseteq U$ and $B \subseteq V$. @practice self
prompt: Prove that a connected normal space $X$ with at least two points is uncountable.
hint: Pick two distinct points, which are disjoint closed sets since normal spaces are T1; apply Urysohn's lemma and look at the image of $f$.
solution: Let $a \ne b$ be points of $X$. In a normal space (T1) the sets $\{a\}$ and $\{b\}$ are closed and disjoint, so Urysohn's lemma gives a continuous $f\colon X \to [0, 1]$ with $f(a) = 0$ and $f(b) = 1$. The image $f(X)$ is connected (continuous image of a connected space), so it is an interval by Week 5, Theorem 1; it contains $0$ and $1$, hence it is all of $[0, 1]$. Thus $f$ maps $X$ onto the uncountable set $[0, 1]$, so $X$ is uncountable. $\blacksquare$
rubric: Uses T1 (part of normality) to see that two distinct points are disjoint closed sets.
rubric: Applies Urysohn's lemma and shows the image is connected, hence an interval.
rubric: Concludes that the image is $[0, 1]$ and that $X$ is uncountable.

@quiz mc
prompt: In the proof of Urysohn's lemma, which property do the open sets $U_r$ ($r$ dyadic) satisfy?
choice*: $A \subseteq U_0$, $U_1 = X \setminus B$, and $\operatorname{Cl} U_r \subseteq U_s$ whenever $r < s$.
choice: $U_s \subseteq U_r$ whenever $r < s$, and every $U_r$ is closed.
choice: The sets $U_r$ are pairwise disjoint and cover $X$.
choice: $U_r = f^{-1}(\{r\})$ for the Urysohn function $f$.
hint: The function is defined by $f(x) = \inf\{r : x \in U_r\}$, so the sets must increase with $r$.
solution: The family is increasing, and strictly so in the sense that the closure of a smaller set lies in the larger one; this is what makes $f$ continuous. The sets are open and nested, not disjoint, and they are not level sets of $f$.

@quiz num
prompt: In $\mathbb{R}$ let $A = [-1, 0] \cup [5, 6]$ and $B = [2, 3]$. With $f(x) = d(x, A)/(d(x, A) + d(x, B))$, find $f(4.5)$.
answer: 0.25
check: (lambda a, b: a / (a + b))(min(abs(4.5 - 5), abs(4.5 - 0)), abs(4.5 - 3))
hint: The nearest point of $A$ to $4.5$ is $5$; the nearest point of $B$ is $3$.
solution: $d(4.5, A) = \min(|4.5 - 5|, |4.5 - 0|) = 0.5$ and $d(4.5, B) = 4.5 - 3 = 1.5$, so $f(4.5) = 0.5/(0.5 + 1.5) = 0.25$.

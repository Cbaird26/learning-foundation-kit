@article
A university must schedule exams so that no student has two exams at the same time. Make each course a vertex, join two courses if they share a student, and give each exam a time slot: adjacent vertices need different slots. The least number of slots is the chromatic number of the conflict graph. A related geometric question is when a graph can be drawn in the plane with no crossing edges, and a famous theorem links the two.

### Colorings

A **proper $k$-coloring** of a graph $G$ assigns each vertex one of $k$ colors so that adjacent vertices get different colors. The **chromatic number** $\chi(G)$ is the least $k$ for which one exists. Every graph with $n$ vertices has $\chi \le n$, a clique $K_r$ forces $\chi \ge r$, and $\chi(G) \le 1$ exactly when there are no edges.

**Theorem.** A graph is bipartite (that is, $\chi(G) \le 2$) if and only if it contains no cycle of odd length.

*Proof.* ($\Rightarrow$) Colors alternate along a cycle, so a cycle has even length. ($\Leftarrow$) First, a closed walk of odd length contains an odd cycle: if no vertex repeats it is a cycle; otherwise split it at a repeated vertex into two shorter closed walks, one of which has odd length, and use induction on the length. Now assume there is no odd cycle. In each component choose a root $r$ and color each vertex $v$ by the parity of its distance from $r$. If an edge $uv$ joined two vertices of the same parity, the shortest paths from $r$ to $u$ and $v$ together with $uv$ would form a closed walk of odd length, giving an odd cycle, a contradiction. $\blacksquare$

**Greedy bound.** Let $\Delta$ be the maximum degree. List the vertices in any order and give each the smallest color in $\{0, 1, \dots, \Delta\}$ not used by its already colored neighbors. A vertex has at most $\Delta$ neighbors, so at most $\Delta$ colors are blocked, and one of the $\Delta + 1$ colors is free. Hence $\chi(G) \le \Delta + 1$, with equality for complete graphs and odd cycles; Brooks's theorem (stated without proof here) says these are the only connected graphs with equality. The order matters for the number of colors greedy uses, though not for the bound.

```python
def two_coloring(n, edges):
    """A proper 2-coloring (list of 0/1) of the graph on 0..n-1, or None."""
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    color = [-1] * n
    for start in range(n):
        if color[start] != -1:
            continue
        color[start] = 0
        queue = [start]
        head = 0
        while head < len(queue):
            u = queue[head]
            head += 1
            for w in adj[u]:
                if color[w] == -1:
                    color[w] = 1 - color[u]
                    queue.append(w)
                elif color[w] == color[u]:
                    return None
    return color


print(two_coloring(5, [(0, 1), (1, 2), (2, 3), (3, 4), (4, 0)]))
```
This prints `None`: the $5$-cycle is an odd cycle. The search colors by parity of distance, exactly as in the proof, and returns `None` as soon as an edge joins equal colors.

### The chromatic polynomial

Let $P(G, k)$ be the number of proper colorings of $G$ with $k$ colors available. For an edge $e = uv$ let $G - e$ be the graph without $e$ and $G / e$ the graph obtained by merging $u$ and $v$ (and deleting loops and repeated edges).

**Theorem (deletion–contraction).** For every simple graph $G$ and edge $e$, $P(G, k) = P(G - e, k) - P(G/e, k)$. For a graph with no edges on $n$ vertices, $P = k^n$.

*Proof.* Proper colorings of $G - e$ split into those where $u$ and $v$ get different colors (these are exactly the proper colorings of $G$) and those where they get the same color (these correspond to proper colorings of $G/e$, with the merged vertex taking the common color). Hence $P(G - e) = P(G) + P(G/e)$. $\blacksquare$

A tree on $n$ vertices has $P = k(k-1)^{n-1}$: color a root freely and each later vertex differently from its parent. For the cycle, deleting an edge of $C_n$ gives a path and contracting gives $C_{n-1}$, so $P(C_n) = k(k-1)^{n-1} - P(C_{n-1})$ and induction from $P(C_3) = k(k-1)(k-2)$ gives $P(C_n, k) = (k-1)^n + (-1)^n(k-1)$.

### Planar graphs

A graph is **planar** if it can be drawn in the plane with no crossing edges; such a drawing is a **plane graph**, and it divides the plane into regions called **faces** (including the unbounded one).

**Euler's formula.** For a connected plane graph with $V$ vertices, $E$ edges and $F$ faces, $V - E + F = 2$.

*Proof.* Induct on $E$. If the graph is a tree, then $E = V - 1$ and $F = 1$, so $V - E + F = 2$. Otherwise it has a cycle; by the Jordan curve theorem (used without proof) an edge on a cycle borders two different faces, and deleting it merges them and leaves the graph connected, so $E$ and $F$ both drop by $1$ and $V - E + F$ is unchanged. $\blacksquare$

**Edge bounds.** A simple connected plane graph with $V \ge 3$ has $E \le 3V - 6$; if it is also bipartite, $E \le 2V - 4$. *Proof.* Add up the lengths of the boundary walks of all faces: each edge is counted twice, giving $2E$. In a simple graph with $V \ge 3$ every face has boundary length at least $3$ (at least $4$ if the graph is bipartite, since it has no triangles; a tree has the single face of length $2E \ge 4$ when $V \ge 3$). So $2E \ge 3F = 3(2 - V + E)$, which gives $E \le 3V - 6$, and $2E \ge 4F$ gives $E \le 2V - 4$. $\blacksquare$

**Consequences.** $K_5$ has $V = 5$ and $E = 10 > 3 \cdot 5 - 6 = 9$, so it is not planar. A planar graph has a vertex of degree at most $5$: otherwise $2E \ge 6V$, so $E \ge 3V > 3V - 6$. Removing such a vertex, coloring the rest by induction and giving it a color unused by its at most five neighbors proves that every planar graph is $6$-colorable. The five color theorem (every planar graph is $5$-colorable) and the four color theorem (Appel and Haken, 1976, with a computer-assisted proof) are stronger statements, stated here without proof. Kuratowski's theorem (also stated without proof) says a graph is planar if and only if it contains no subdivision of $K_5$ or $K_{3,3}$.

title: The chromatic polynomial of a small graph
problem: Find $P(G, k)$ for the graph $G$ on vertices $0, 1, 2, 3$ with edges $01, 12, 23, 30, 02$ (a $4$-cycle with one chord), and evaluate it at $k = 4$.
step: Choose the chord $e = \{0, 2\}$. Deleting it leaves the $4$-cycle, so $P(G - e) = (k-1)^4 + (k-1)$.
step: Contracting the chord merges $0$ and $2$; the edges $01$ and $12$ become one edge, and $23$ and $30$ become one edge, so $G/e$ is a path on three vertices with $P(G/e) = k(k-1)^2$.
step: By deletion–contraction, $P(G) = (k-1)^4 + (k-1) - k(k-1)^2 = (k-1)\bigl[(k-1)^3 + 1 - k(k-1)\bigr]$.
step: The bracket expands to $k^3 - 4k^2 + 4k = k(k-2)^2$, so $P(G, k) = k(k-1)(k-2)^2$. Directly: color $0$ and $2$ in $k(k-1)$ ways; vertices $1$ and $3$ each avoid those two colors, in $(k-2)$ ways each.
step: At $k = 4$: $4 \cdot 3 \cdot 4 = 48$; at $k = 2$ the value is $0$, so $\chi(G) \ge 3$, and at $k = 3$ it is $6 > 0$, so $\chi(G) = 3$.
answer: $P(G, k) = k(k-1)(k-2)^2$, and $\chi(G) = 3$.

problem: A connected simple planar graph is drawn with $9$ vertices and $14$ edges. How many faces does the drawing have, and can every face be bounded by exactly three edges?

@mistakes
- Believing $E \le 3V - 6$ is sufficient for planarity: $K_{3,3}$ has $9 \le 12$ and is not planar. The bound is only a necessary condition.
- Reading the greedy bound $\chi \le \Delta + 1$ as exact: a greedy coloring with a bad vertex order can use more colors than $\chi(G)$, and $\chi$ can be much less than $\Delta + 1$.
- Applying Euler's formula to a disconnected plane graph: it becomes $V - E + F = 1 + (\text{number of components})$.
- Mixing up the chromatic polynomial of $G/e$ and of $G - e$ in deletion–contraction, or forgetting to remove the repeated edges after merging two vertices.

```python
def greedy_colors(n, edges, order):
    """Greedy coloring of vertices in the given order."""
    neighbors = [set() for _ in range(n)]
    for u, v in edges:
        neighbors[u].add(v)
        neighbors[v].add(u)
    colors = [-1] * n
    for v in order:
        used = {colors[w] for w in neighbors[v] if colors[w] != -1}
        c = 0
        while c in used:
            c += 1
        colors[v] = c
    return colors
```

```python
def chromatic_poly_value(n, edges, k):
    """Proper k-colorings by deletion-contraction."""
    def count(m, edge_set):
        if not edge_set:
            return k ** m
        u, v = min(tuple(sorted(e)) for e in edge_set)
        rest = edge_set - {frozenset((u, v))}
        merged = set()
        for e in rest:
            a, b = tuple(e)
            a = u if a == v else a
            b = u if b == v else b
            a -= a > v
            b -= b > v
            merged.add(frozenset((a, b)))
        return count(m, rest) - count(m - 1, merged)

    return count(n, {frozenset(e) for e in edges})
```
hint: Represent edges as frozensets so that repeated edges disappear after merging, and relabel the vertices above the removed one.
hint: Contracting `(u, v)` with `u < v` sends `v` to `u` and shifts every label greater than `v` down by one.
solution: Proper colorings of $G - e$ either give the endpoints of $e$ different colors, which are the proper colorings of $G$, or the same color, which correspond to proper colorings of $G/e$; so the count for $G$ is the difference. The recursion ends at edgeless graphs, whose colorings are free. Forgetting that merging can create repeated edges (a set of frozensets removes them), or relabeling incorrectly, are the common bugs, and the brute-force comparison on $K_{2,3}$ catches them. The running time is exponential in the number of edges, so this is for small graphs only.

```python
def chromatic_number(n, edges):
    """Least k admitting a proper k-coloring, by backtracking."""
    if n == 0:
        return 0
    neighbors = [set() for _ in range(n)]
    for u, v in edges:
        neighbors[u].add(v)
        neighbors[v].add(u)

    def colorable(k):
        colors = [-1] * n

        def place(v, used_max):
            if v == n:
                return True
            for c in range(min(k, used_max + 2)):
                if all(colors[w] != c for w in neighbors[v] if w < v):
                    colors[v] = c
                    if place(v + 1, max(used_max, c)):
                        return True
            colors[v] = -1
            return False

        return place(0, -1)

    k = 1
    while not colorable(k):
        k += 1
    return k
```
hint: A vertex may use any color in `0..k-1` not used by an earlier neighbor; undo the choice if the rest fails.
hint: To avoid repeating equivalent colorings, never use a color more than one larger than the largest used so far.
solution: A proper $k$-coloring exists exactly when the backtracking search succeeds, since it tries every assignment that is consistent with the neighbors colored so far (the restriction to new colors in order only removes colorings that differ by renaming colors). The first $k$ that works is $\chi(G)$. The greedy algorithm is not a correct answer: on the crown graph it can use three colors although two suffice, which the sixth test checks. The search is exponential in the worst case, since deciding $k$-colorability for $k \ge 3$ is NP-complete.

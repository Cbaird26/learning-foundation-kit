@article
Can a walker cross every bridge of a town exactly once and return to the start? Euler answered this for Königsberg in 1736 and in doing so founded graph theory. The related question, whether one can visit every *vertex* exactly once, looks similar but is dramatically harder.

### Connectivity and bridges

A graph is **connected** if every two vertices are joined by a path. Its **components** are its maximal connected subgraphs. A **bridge** is an edge whose deletion increases the number of components; a **cut vertex** is a vertex whose deletion (with its edges) does the same.

**Lemma.** An edge $e = \{u, v\}$ is a bridge if and only if $e$ lies on no cycle.

*Proof.* If $e$ lies on a cycle, the rest of the cycle is a path from $u$ to $v$ avoiding $e$, so deleting $e$ does not disconnect anything. If $e$ lies on no cycle, then $G - e$ has no $u$–$v$ path: such a path together with $e$ would form a cycle. So $u$ and $v$ end up in different components. $\blacksquare$

```python
def components(n, edges):
    """Connected components of a graph on 0..n-1, as sorted lists."""
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    seen = [False] * n
    result = []
    for start in range(n):
        if seen[start]:
            continue
        seen[start] = True
        stack, part = [start], []
        while stack:
            x = stack.pop()
            part.append(x)
            for y in adj[x]:
                if not seen[y]:
                    seen[y] = True
                    stack.append(y)
        result.append(sorted(part))
    return result


print(components(6, [(0, 1), (1, 2), (3, 4)]))
```
This prints `[[0, 1, 2], [3, 4], [5]]`. Each vertex is pushed once, so the work is proportional to $n$ plus the number of edges, and the vertices in one part are exactly those reachable from its start vertex.

### Eulerian circuits

A **trail** is a walk with no repeated edge; an **Eulerian circuit** is a closed trail using every edge exactly once.

**Theorem (Euler).** A connected graph (with at least one edge) has an Eulerian circuit if and only if every vertex has even degree. It has an Eulerian trail that is not closed if and only if exactly two vertices have odd degree, and then every such trail starts at one of them and ends at the other.

*Proof.* ($\Rightarrow$) Each time a circuit passes through a vertex it uses two edges there, and a closed circuit starts and ends at the same vertex, so every degree is even. ($\Leftarrow$) Let $W$ be a longest trail. If $W$ is not closed, its last vertex has used an odd number of its (even number of) edges, so an unused edge extends $W$, a contradiction; hence $W$ is closed. If some edge is unused, connectivity gives an unused edge $f$ at a vertex $x$ of $W$ (otherwise no unused edge touches the vertex set of $W$, and the graph would be disconnected). Rotate the closed trail $W$ to start and end at $x$ and append $f$: a longer trail, a contradiction. So $W$ uses all edges. For the trail version, add a new edge joining the two odd vertices (the argument for circuits does not need the edge to be new, so it works even if they were adjacent). The new graph has all degrees even, so it has an Eulerian circuit; cutting the circuit open at the new edge gives an Eulerian trail between the two odd vertices. Conversely, a non-closed Eulerian trail has odd degree exactly at its two ends, by the first paragraph's counting. $\blacksquare$

Both hypotheses matter: two disjoint triangles have all degrees even but no Eulerian circuit, since the graph is not connected. **Hierholzer's algorithm** builds a circuit in linear time: follow unused edges from a start vertex, pushing vertices on a stack; when stuck, pop the vertex to the output. The output, reversed, is the circuit.

### Hamiltonian cycles

A **Hamiltonian cycle** passes through every vertex exactly once. No simple characterization is known, and deciding whether a graph has one is NP-complete. A good sufficient condition:

**Theorem (Dirac).** If $G$ is a simple graph with $n \ge 3$ vertices and $\deg v \ge n/2$ for every vertex $v$, then $G$ has a Hamiltonian cycle.

*Proof.* First, $G$ is connected: two non-adjacent vertices $u, v$ have neighborhoods inside the other $n - 2$ vertices of total size at least $n$, so they share a neighbor. Let $P = v_1v_2\cdots v_k$ be a longest path. All neighbors of $v_1$ and of $v_k$ lie on $P$, otherwise $P$ could be extended. Consider the sets $A = \{i : v_1 \sim v_{i+1}\}$ and $B = \{i : v_k \sim v_i\}$, both subsets of $\{1, \dots, k-1\}$. They have $|A|, |B| \ge n/2$, so $|A| + |B| \ge n \ge k > k - 1$, and they share an index $i$. Here $k \ge 3$, because $\deg v_1 \ge n/2 > 1$ forces a neighbor of $v_1$ other than $v_2$ on $P$. Then $C = v_1v_2\cdots v_iv_kv_{k-1}\cdots v_{i+1}v_1$ is a cycle through all vertices of $P$. If $k < n$, connectivity gives a vertex outside $C$ adjacent to a vertex of $C$, and going around $C$ from that vertex gives a path with $k + 1$ vertices, contradicting the choice of $P$. So $k = n$ and $C$ is a Hamiltonian cycle. $\blacksquare$

The condition is not necessary: the cycle $C_n$ is Hamiltonian but has all degrees $2 < n/2$ once $n > 4$. And $n \ge 3$ is needed since a cycle needs three vertices.

To test for a Hamiltonian *path* in a small graph, use dynamic programming over subsets: let $E(S)$ be the set of vertices $v \in S$ such that some path visits exactly the vertices of $S$ and ends at $v$. Then $w \in E(S \cup \{w\})$ if $w \notin S$ and $w$ is adjacent to some $v \in E(S)$. A Hamiltonian path exists exactly when $E(V) \ne \emptyset$. This takes about $2^nn^2$ steps, far better than $n!$ but still exponential.

@mistakes
- Forgetting connectivity in Euler's theorem: even degrees alone do not give a circuit (two disjoint triangles).
- Confusing an Eulerian circuit (every edge once) with a Hamiltonian cycle (every vertex once); a graph can have one without the other.
- Treating Dirac's condition as necessary: the cycle $C_n$ is Hamiltonian although its degrees are only $2$.
- Calling an edge a bridge because deleting it makes the graph look sparser: it is a bridge only if the number of components increases, equivalently if the edge lies on no cycle.

```python
def euler_circuit(n, edges):
    """Eulerian circuit by Hierholzer's algorithm, or None."""
    if not edges:
        return []
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    if any(len(neighbors) % 2 for neighbors in adj):
        return None
    start = min(v for v in range(n) if adj[v])
    stack = [start]
    circuit = []
    while stack:
        v = stack[-1]
        if adj[v]:
            w = adj[v].pop()
            adj[w].remove(v)
            stack.append(w)
        else:
            circuit.append(stack.pop())
    if len(circuit) != len(edges) + 1:
        return None
    return circuit[::-1]
```
hint: Check the degrees first; then walk along unused edges, deleting each edge from both adjacency lists as you use it.
hint: When the current vertex has no unused edge left, move it from the stack to the output; at the end reverse the output and check that all edges were used.
solution: With all degrees even, a walk that starts at `start` and uses unused edges can only get stuck at `start`, because every other vertex entered has an unused exit; this builds a closed trail, and popping vertices as they get stuck splices the sub-circuits found later into the earlier trail, as in the proof of Euler's theorem. If the number of output vertices is not `len(edges) + 1`, some edge lies in another component, so no circuit exists. Omitting this final check wrongly accepts two disjoint triangles.

```python
def two_edge_components(n, edges):
    """Components after deleting all bridges (found by edge removal)."""
    def count(edge_list):
        parent = list(range(n))

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        for u, v in edge_list:
            parent[find(u)] = find(v)
        return len({find(v) for v in range(n)})

    base = count(edges)
    kept = [e for e in edges
            if count([f for f in edges if f != e]) == base]
    return count(kept)
```
hint: An edge is a bridge exactly when deleting it increases the number of components.
hint: Count components with a union–find or a search, with and without each edge; then count again using only the non-bridges.
solution: By the lemma, a bridge is an edge whose deletion increases the number of components, so the code tests each edge in turn and keeps the non-bridges. The components of the graph of non-bridges are the pieces that remain connected after any single edge is removed. A linear-time method uses depth-first search with low-link values, but the quadratic test is correct and enough for small graphs. Counting components of the original graph instead, or deleting all edges that lie in the DFS tree, are the typical wrong answers.

```python
def has_hamiltonian_path(n, edges):
    """Subset DP: ends[S] = bitmask of possible last vertices."""
    if n <= 1:
        return True
    adj = [0] * n
    for u, v in edges:
        adj[u] |= 1 << v
        adj[v] |= 1 << u
    ends = [0] * (1 << n)
    for v in range(n):
        ends[1 << v] = 1 << v
    for subset in range(1, 1 << n):
        if not ends[subset]:
            continue
        for v in range(n):
            if ends[subset] >> v & 1:
                free = adj[v] & ~subset
                for w in range(n):
                    if free >> w & 1:
                        ends[subset | 1 << w] |= 1 << w
    return ends[(1 << n) - 1] != 0
```
hint: `ends[1 << v]` is `1 << v` for a single vertex; extend a path ending at `v` by an unvisited neighbor `w`.
hint: Process subsets in increasing numeric order, since adding a vertex always increases the bitmask.
solution: By induction on $|S|$, `ends[S]` contains $w$ exactly when some path visits precisely the vertices of $S$ and ends at $w$: a path ending at $w$ with vertex set $S$ is a path on $S \setminus \{w\}$ ending at a neighbor of $w$, followed by $w$. Subsets are visited in increasing numeric order, which respects inclusion, so every `ends[S]` is final before it is used. A Hamiltonian path exists if and only if `ends` of the full set is nonzero. The loop is about $2^n n^2$ steps, so the method is for $n$ up to roughly $15$. Greedy methods that always step to the neighbor of smallest degree fail on small graphs and are not correct.

@article
Can a group of seven people each have exactly $3$ friends among the others? Add up the friendships from each person's point of view: $7 \cdot 3 = 21$ endpoints. But every friendship has two endpoints, so the total must be even. The answer is no, and the argument is the first theorem of graph theory.

All graphs here are **simple**: a graph $G = (V, E)$ has a finite vertex set $V$ and a set $E$ of two-element subsets of $V$ (edges), with no loops and no repeated edges. The **degree** $\deg(v)$ is the number of edges containing $v$. In code a graph on $n$ vertices has the vertices $0, \dots, n-1$ and is stored as a list of pairs, or as a dictionary of adjacency lists.

### Degrees

**Handshake lemma.** In every finite graph $\sum_{v \in V}\deg(v) = 2|E|$. Consequently the number of vertices of odd degree is even.

*Proof.* Count pairs $(v, e)$ with $v \in e$. Each edge has two endpoints, giving $2|E|$ pairs; each vertex $v$ lies in $\deg(v)$ edges, giving $\sum_v\deg(v)$. Hence the sum is even, and since the even-degree vertices contribute an even amount, the odd-degree vertices contribute an even sum, so there is an even number of them. $\blacksquare$

A finite sequence of nonnegative integers is **graphical** if it is the degree sequence of some simple graph. An even sum is necessary but not sufficient: $(3, 3, 3, 1)$ has sum $10$ yet cannot occur (three vertices of degree $3$ in a $4$-vertex graph are adjacent to everything, so the fourth vertex would have degree $3$).

**Theorem (Havel–Hakimi).** Let $d_1 \ge d_2 \ge \dots \ge d_n \ge 0$ be integers with $n \ge 2$ and $d_1 \ge 1$. The sequence is graphical if and only if the sequence obtained by deleting $d_1$ and subtracting $1$ from each of the next $d_1$ terms $d_2, \dots, d_{d_1+1}$ is graphical (this requires $d_1 \le n - 1$ and no negative entries).

*Proof.* ($\Leftarrow$) Given a graph $G'$ with the reduced degree sequence, add a new vertex adjacent to the vertices whose degrees were lowered; the result realizes the original sequence. ($\Rightarrow$) Let $G$ realize the sequence, with $\deg v_i = d_i$. Among all realizations, choose one in which $v_1$ is adjacent to as many of $v_2, \dots, v_{d_1+1}$ as possible. We claim $v_1$ is adjacent to all of them. If not, some $v_j$ with $2 \le j \le d_1 + 1$ is not adjacent to $v_1$. Since $\deg v_1 = d_1$, $v_1$ has a neighbor $v_k$ with $k > d_1 + 1$, and $d_j \ge d_k$. The sets $N(v_j) \setminus \{v_k\}$ and $N(v_k)\setminus\{v_j\}$ have sizes $d_j - \epsilon$ and $d_k - \epsilon$, where $\epsilon = 1$ if $v_j \sim v_k$ and $0$ otherwise, so the first is at least as large as the second. The second contains $v_1$ and the first does not, so there is a vertex $w \in N(v_j)\setminus\{v_k\}$ not in $N(v_k)$. Replace the edges $v_1v_k$ and $v_jw$ by $v_1v_j$ and $v_kw$. All degrees are unchanged, the new edges did not exist before, and $v_1$ now has one more neighbor among $v_2, \dots, v_{d_1+1}$: a contradiction. So in this realization, deleting $v_1$ leaves a graph with the reduced sequence. $\blacksquare$

```python
def havel_hakimi_test(seq):
    """True if seq (a list of nonnegative integers) is graphical."""
    s = sorted(seq, reverse=True)
    while s:
        d = s.pop(0)
        if d > len(s):
            return False
        for i in range(d):
            s[i] -= 1
            if s[i] < 0:
                return False
        s.sort(reverse=True)
    return True


print(havel_hakimi_test([4, 3, 3, 2, 2, 2, 1, 1]))
```
This prints `True`. Each pass removes one term and the loop ends when no terms remain, so it terminates. An odd sum always ends in `False`, because the parity of the sum drops by an even amount at each step and can never reach the all-zero sequence.

### Isomorphism

Graphs $G = (V, E)$ and $H = (W, F)$ are **isomorphic** if there is a bijection $f\colon V \to W$ with $\{u, v\} \in E \iff \{f(u), f(v)\} \in F$. An **invariant** is a quantity that isomorphic graphs share: the number of vertices and edges, the sorted degree sequence, the number of triangles, connectedness. A difference in any invariant proves non-isomorphism; agreement of invariants proves nothing. The $6$-cycle and two disjoint triangles both have degree sequence $(2,2,2,2,2,2)$ but are not isomorphic. To decide isomorphism one can search for $f$ vertex by vertex, rejecting a partial bijection as soon as it breaks adjacency or degree.

### Walks and the adjacency matrix

The **adjacency matrix** $A$ of a graph on $0, \dots, n-1$ has $A_{ij} = 1$ if $\{i,j\} \in E$ and $0$ otherwise. A **walk** of length $k$ is a sequence of $k+1$ vertices in which consecutive vertices are adjacent.

**Theorem.** $(A^k)_{ij}$ is the number of walks of length $k$ from $i$ to $j$, for every $k \ge 0$.

*Proof.* For $k = 0$, $A^0$ is the identity: one walk (of length $0$) from $i$ to $i$, none from $i$ to $j \ne i$. If the claim holds for $k$, then $(A^{k+1})_{ij} = \sum_t (A^k)_{it}A_{tj}$ counts walks of length $k$ from $i$ to a vertex $t$, followed by the edge $\{t, j\}$, and every walk of length $k + 1$ arises exactly once this way. $\blacksquare$

A closed walk of length $3$ from $i$ goes around a triangle containing $i$, in either of two directions, so $\operatorname{tr}(A^3) = 6\,T$, where $T$ is the number of triangles.

@example
title: Testing a degree sequence
problem: Is $(5, 4, 3, 3, 2, 2, 1)$ the degree sequence of a simple graph?
step: The sum is $20$, which is even, so parity does not rule it out. The sequence is sorted and $n = 7$.
step: Apply Havel–Hakimi: delete $5$ and subtract $1$ from the next five terms: $(4,3,3,2,2,1) \to (3,2,2,1,1,1)$.
step: Delete $3$ and subtract $1$ from the next three terms: $(2,2,1,1,1) \to (1,1,0,1,1)$, which sorts to $(1,1,1,1,0)$.
step: Delete $1$, lower the next term: $(1,1,1,0) \to (0,1,1,0)$, sorted $(1,1,0,0)$; delete $1$, lower the next: $(1,0,0) \to (0,0,0)$.
step: The final sequence is all zeros, which is graphical (a graph with no edges), so by the theorem each earlier sequence, including the original, is graphical.
answer: Yes, it is graphical.

@example
title: Proving two graphs are not isomorphic
problem: Let $G$ be the $6$-cycle $0$-$1$-$2$-$3$-$4$-$5$-$0$ and $H$ the disjoint union of the triangles $\{0,1,2\}$ and $\{3,4,5\}$. Show they are not isomorphic.
step: Compare the easy invariants. Both have $6$ vertices and $6$ edges, and every vertex has degree $2$, so these invariants agree and prove nothing.
step: Count triangles. $G$ has none: the only edges at vertex $0$ go to $1$ and $5$, and $1 \not\sim 5$, and the same holds at every vertex. $H$ has two triangles.
step: Alternatively, $G$ is connected and $H$ is not.
step: An isomorphism would map triangles to triangles, so the triangle counts would be equal. They differ, so no isomorphism exists.
answer: Not isomorphic: $G$ has $0$ triangles, $H$ has $2$.

@mistakes

- Treating "the sum of the degrees is even" as sufficient for a sequence to be graphical.
- Forgetting to re-sort the sequence after each Havel–Hakimi step; the next vertex removed must have the largest remaining degree.
- Stating that $\operatorname{tr}(A^3)$ is the number of triangles; it is six times that number.

```python
def havel_hakimi_graph(seq):
    """A simple graph with degree seq[i] at vertex i, or None."""
    remaining = [[d, v] for v, d in enumerate(seq)]
    edges = []
    while True:
        remaining.sort(key=lambda item: (-item[0], item[1]))
        if not remaining or remaining[0][0] == 0:
            break
        d, v = remaining[0]
        for item in remaining[1:d + 1]:
            item[0] -= 1
            if item[0] < 0:
                return None
            edges.append((min(v, item[1]), max(v, item[1])))
        if d > len(remaining) - 1:
            return None
        remaining[0][0] = 0
    return sorted(edges)
```
hint: Keep pairs `[remaining degree, vertex]`, sort them every round, and take the first pair.
hint: A vertex of degree `d` needs `d` other vertices with positive remaining degree; if a remaining degree would become negative, the sequence is not graphical.
solution: This is the construction in the proof of the Havel–Hakimi theorem: a graphical sequence has a realization in which the vertex of largest degree is adjacent to the next largest degrees, so joining them and recursing on the reduced sequence either completes a graph or fails exactly when the sequence is not graphical. Each vertex is processed once and then set to zero, so no edge is added twice. Not sorting in each round, or joining to arbitrary vertices, can strand a vertex with too few partners, which the unsorted test sequences catch.

```python
def is_isomorphic(n, edges1, edges2):
    """Backtracking isomorphism test for simple graphs on 0..n-1."""
    if len(edges1) != len(edges2):
        return False
    adj1 = [set() for _ in range(n)]
    adj2 = [set() for _ in range(n)]
    for u, v in edges1:
        adj1[u].add(v)
        adj1[v].add(u)
    for u, v in edges2:
        adj2[u].add(v)
        adj2[v].add(u)
    if sorted(map(len, adj1)) != sorted(map(len, adj2)):
        return False
    image = [-1] * n
    used = [False] * n

    def extend(i):
        if i == n:
            return True
        for w in range(n):
            if used[w] or len(adj2[w]) != len(adj1[i]):
                continue
            if all((image[j] in adj2[w]) == (j in adj1[i]) for j in range(i)):
                image[i] = w
                used[w] = True
                if extend(i + 1):
                    return True
                used[w] = False
                image[i] = -1
        return False

    return extend(0)
```
hint: Compare the number of edges and the degree sequences first; they are cheap invariants that settle many cases.
hint: When placing vertex `i` on `w`, check each earlier vertex `j`: `j` is adjacent to `i` exactly when `image[j]` is adjacent to `w`.
solution: A map that is complete and passes every pair check is a bijection preserving adjacency in both directions, so it is an isomorphism. Conversely, an isomorphism preserves degrees and adjacency of all pairs, so none of its partial restrictions is ever pruned, and the search finds it if one exists. Matching degrees and edge counts are not enough: the Petersen graph and the pentagonal prism are both $3$-regular on $10$ vertices and the search correctly rejects the pair. Checking adjacency in one direction only, which allows extra edges in the image, is the typical wrong version.

```python
def count_triangles(n, edges):
    """Number of triangles: trace of A^3 divided by 6."""
    adj = [[0] * n for _ in range(n)]
    for u, v in edges:
        adj[u][v] = 1
        adj[v][u] = 1

    def multiply(x, y):
        return [[sum(x[i][t] * y[t][j] for t in range(n)) for j in range(n)]
                for i in range(n)]

    cube = multiply(multiply(adj, adj), adj)
    return sum(cube[i][i] for i in range(n)) // 6
```
hint: The entry $(A^3)_{ii}$ counts closed walks of length $3$ through vertex $i$.
hint: Each triangle gives $6$ closed walks in total: three starting points and two directions.
solution: By the walk theorem, $(A^3)_{ii}$ counts closed walks of length $3$ at $i$; in a simple graph these are exactly the walks around a triangle containing $i$, two directions per triangle. Summing over $i$ counts each triangle $3 \cdot 2 = 6$ times, so dividing the trace by $6$ gives the number of triangles. Returning the trace itself is the usual mistake, and it fails on the first test with $24$ instead of $4$.

@article
How many strings of length $n$ over the alphabet $\{0, 1, 2\}$ contain no two adjacent zeros? Counting for $n = 0, 1, 2, 3$ gives $1, 3, 8, 22$, and a formula for all $n$ is not obvious. A **recurrence relation** expresses each term of a sequence through earlier terms; it is the natural way to count objects built step by step, and it can often be solved in closed form.

### Modeling with recurrences

Let $b_n$ be the number of such strings. For $n \ge 2$, classify a valid string by its last letter. If it ends in $1$ or $2$ (two choices), the first $n-1$ letters form any valid string, giving $2b_{n-1}$. If it ends in $0$, the letter before must be $1$ or $2$ (two choices), and the first $n-2$ letters are any valid string, giving $2b_{n-2}$. The cases are disjoint and exhaustive, so
$$b_n = 2b_{n-1} + 2b_{n-2} \quad (n \ge 2), \qquad b_0 = 1,\ b_1 = 3,$$
and $b_2 = 8$, $b_3 = 22$, $b_4 = 60$ agree with direct counts. The two initial values are needed because the recurrence looks back two steps.

### Linear recurrences with constant coefficients

A recurrence $a_n = c_1a_{n-1} + c_2a_{n-2}$ for $n \ge 2$ with constants $c_1, c_2$ and $c_2 \ne 0$ is **linear homogeneous of order two**. Its **characteristic equation** is $x^2 = c_1x + c_2$. Trying $a_n = r^n$ (with $r \ne 0$) gives $r^n = c_1r^{n-1} + c_2r^{n-2}$, which holds for all $n$ exactly when $r$ solves the characteristic equation.

**Theorem.** Let $c_2 \ne 0$ and let $r_1, r_2$ be the roots (in $\mathbb{C}$) of $x^2 - c_1x - c_2 = 0$. For any initial values $a_0, a_1$ there is exactly one sequence satisfying the recurrence, and
- if $r_1 \ne r_2$, it is $a_n = A r_1^n + B r_2^n$;
- if $r_1 = r_2 = r$, it is $a_n = (A + Bn)\,r^n$,

for constants $A, B$ determined by $a_0$ and $a_1$.

*Proof.* The recurrence determines $a_n$ for $n \ge 2$ from $a_0, a_1$, so there is exactly one solution. It suffices to show that the stated forms satisfy the recurrence and can match any $a_0, a_1$. For distinct roots, each $r_i^n$ satisfies the recurrence (as above), and a linear combination of solutions is a solution. Matching initial values means solving $A + B = a_0$, $Ar_1 + Br_2 = a_1$, which has the unique solution $A = \frac{a_1 - r_2a_0}{r_1 - r_2}$, $B = \frac{r_1a_0 - a_1}{r_1 - r_2}$ because $r_1 \ne r_2$. For a double root, $c_1 = 2r$ and $c_2 = -r^2$ (the sum and the negative of the product of the roots), and $r \ne 0$ because $c_2 \ne 0$. The sequence $nr^n$ satisfies the recurrence: $2r(n-1)r^{n-1} - r^2(n-2)r^{n-2} = r^n(2n - 2 - n + 2) = nr^n$. Matching initial values means $A = a_0$ and $r(A + B) = a_1$, so $B = a_1/r - a_0$. $\blacksquare$

The condition $c_2 \ne 0$ matters: for $a_n = 2a_{n-1}$ (so $c_2 = 0$) the characteristic equation $x^2 = 2x$ has the root $0$, and the form $A\cdot 2^n + B\cdot 0^n$ cannot fit $a_0, a_1$ unless $a_1 = 2a_0$. The same method works for any order $k$ with a polynomial of degree $k$; its roots with multiplicity $m$ contribute $r^n, nr^n, \dots, n^{m-1}r^n$, which we state without proof here.

For the strings above, $x^2 - 2x - 2 = 0$ has the roots $1 \pm \sqrt{3}$ and $b_n = A(1+\sqrt3)^n + B(1-\sqrt3)^n$ with $A = \frac{2 + \sqrt3}{2\sqrt3}$ and $B = \frac{\sqrt3 - 2}{2\sqrt3}$ (so that $A + B = 1$ and $A(1+\sqrt3) + B(1-\sqrt3) = 3$). Irrational roots are common, so exact computation of terms is usually done from the recurrence, not from the closed form, to avoid rounding.

### Nonhomogeneous recurrences

For $a_n = c_1a_{n-1} + c_2a_{n-2} + f(n)$, the general solution is the sum of one **particular solution** $p_n$ and the general solution of the homogeneous equation. Indeed, the difference of any two solutions satisfies the homogeneous recurrence. For $f(n)$ a polynomial of degree $d$ one tries a polynomial of degree $d$ (of degree $d+1$ if the characteristic equation has the root $1$). The initial values are applied at the end, to the full sum.

### Computing terms

```python
def linrec(coeffs, init, n):
    """a_n for a_m = coeffs[0]*a_{m-1} + coeffs[1]*a_{m-2} + ..."""
    seq = list(init)
    while len(seq) <= n:
        seq.append(sum(c * seq[-1 - i] for i, c in enumerate(coeffs)))
    return seq[n]


print(linrec([3, 4], [2, 3], 10))
```
This prints `1048577`, which equals $4^{10} + (-1)^{10}$, the value of the closed form $a_n = 4^n + (-1)^n$ for the recurrence $a_n = 3a_{n-1} + 4a_{n-2}$ with $a_0 = 2$, $a_1 = 3$ (check: $r^2 - 3r - 4 = (r-4)(r+1)$, and $A + B = 2$, $4A - B = 3$ give $A = B = 1$). Python integers are exact, so the answer has no rounding error. The loop does $n$ steps of $k$ multiplications, and checking that it agrees with a closed form for $n \le 100$ is evidence about the closed form, whereas the theorem proves it.

@example
title: A repeated characteristic root
problem: Solve $a_n = 4a_{n-1} - 4a_{n-2}$ for $n \ge 2$ with $a_0 = 3$, $a_1 = 2$, and find $a_5$.
step: The characteristic equation is $x^2 - 4x + 4 = (x-2)^2 = 0$, with the double root $r = 2$. By the theorem, $a_n = (A + Bn)2^n$.
step: Use the initial values. For $n = 0$: $A = 3$. For $n = 1$: $2(A + B) = 2$, so $A + B = 1$ and $B = -2$.
step: The closed form is $a_n = (3 - 2n)2^n$. Check the recurrence once: $a_2 = 4 \cdot 2 - 4 \cdot 3 = -4$ and $(3 - 4)\cdot 4 = -4$.
step: Evaluate $a_5 = (3 - 10)\cdot 32 = -224$.
answer: $a_n = (3 - 2n)2^n$, so $a_5 = -224$.

@example
title: A nonhomogeneous recurrence
problem: Solve $c_n = 2c_{n-1} + n$ for $n \ge 1$ with $c_0 = 1$.
step: The homogeneous equation $c_n = 2c_{n-1}$ has the solutions $A\cdot 2^n$.
step: Since $f(n) = n$ has degree $1$ and $1$ is not a root of $x = 2$, try the particular solution $p_n = \alpha n + \beta$. Substituting: $\alpha n + \beta = 2\alpha(n-1) + 2\beta + n$.
step: Compare coefficients of $n$: $\alpha = 2\alpha + 1$, so $\alpha = -1$. Compare constants: $\beta = -2\alpha + 2\beta$, so $\beta = 2\alpha = -2$. Thus $p_n = -n - 2$.
step: The general solution is $c_n = A\cdot2^n - n - 2$. The initial value $c_0 = 1$ gives $A - 2 = 1$, so $A = 3$.
step: Check: $c_1 = 2 \cdot 1 + 1 = 3$, and the formula gives $6 - 1 - 2 = 3$.
answer: $c_n = 3\cdot 2^n - n - 2$

@mistakes
- Writing $Ar^n + Br^n$ for a double root $r$: this has only one free constant, and the second solution is $nr^n$.
- Fitting the initial conditions to the particular solution alone, instead of to the sum of the particular and homogeneous parts.
- Using a closed form with irrational roots in floating point to count: the rounding error grows with $n$, so use the recurrence with integers.
- Forgetting initial values: a recurrence of order $k$ needs $k$ of them, and the recurrence may start to apply only from index $k$.

```python
def linrec_fast(coeffs, init, n):
    """a_n of a linear recurrence via the companion matrix power."""
    k = len(coeffs)
    if n < k:
        return init[n]

    def mul(x, y):
        return [[sum(x[i][t] * y[t][j] for t in range(k)) for j in range(k)]
                for i in range(k)]

    companion = [list(coeffs)]
    for i in range(1, k):
        companion.append([1 if j == i - 1 else 0 for j in range(k)])
    result = [[1 if i == j else 0 for j in range(k)] for i in range(k)]
    e = n - k + 1
    while e:
        if e & 1:
            result = mul(result, companion)
        companion = mul(companion, companion)
        e >>= 1
    state = list(reversed(init))   # (a_{k-1}, ..., a_0)
    return sum(result[0][j] * state[j] for j in range(k))
```
hint: The vector $(a_m, a_{m-1}, \dots, a_{m-k+1})$ is multiplied by the companion matrix to give the vector for $m + 1$.
hint: Reach $a_n$ by applying the matrix $n - k + 1$ times to $(a_{k-1}, \dots, a_0)$, using square-and-multiply for the power.
solution: With $v_m = (a_m, \dots, a_{m-k+1})^\top$, the first row of the companion matrix $M$ gives $a_{m+1} = \sum c_ia_{m+1-i}$ and the subdiagonal of ones shifts the other entries, so $v_{m+1} = Mv_m$ and $v_n = M^{n-k+1}v_{k-1}$. The first entry of $v_n$ is $a_n$. Repeated squaring computes $M^e$ with $O(\log e)$ products (the binary expansion of $e$ selects which squares to multiply), and all entries are integers, so nothing is rounded. A wrong exponent, $n$ instead of $n - k + 1$, is the typical off-by-one and is caught by the small cases.

```python
from fractions import Fraction


def fit_recurrence(seq, k):
    """Coefficients of an order-k linear recurrence fitting seq, or None."""
    s = [Fraction(x) for x in seq]
    rows = [[s[n - i] for i in range(1, k + 1)] + [s[n]]
            for n in range(k, 2 * k)]
    for col in range(k):
        pivot = next((r for r in range(col, k) if rows[r][col] != 0), None)
        if pivot is None:
            return None
        rows[col], rows[pivot] = rows[pivot], rows[col]
        scale = rows[col][col]
        rows[col] = [x / scale for x in rows[col]]
        for r in range(k):
            if r != col and rows[r][col] != 0:
                factor = rows[r][col]
                rows[r] = [x - factor * y for x, y in zip(rows[r], rows[col])]
    coeffs = [rows[i][k] for i in range(k)]
    for n in range(2 * k, len(s)):
        if s[n] != sum(coeffs[i - 1] * s[n - i] for i in range(1, k + 1)):
            return None
    return coeffs
```
hint: Row `n - k` of the system is `[s[n-1], ..., s[n-k] | s[n]]`; reduce the augmented matrix to the identity.
hint: After solving, check all remaining terms from index `2k` on with exact comparisons.
solution: If the $k \times k$ matrix of the first $k$ equations is invertible, its solution is the only candidate, so the sequence satisfies an order-$k$ recurrence exactly when that candidate also satisfies all later equations. If the matrix is singular, many coefficient vectors may fit the first terms (as for a sequence that already has a recurrence of lower order), and the function returns `None` rather than guess. Fractions keep every step exact, which floats would not.

```python
def count_no_run(n, k):
    """Binary strings of length n without k consecutive ones."""
    counts = []
    for length in range(n + 1):
        if length < k:
            counts.append(2 ** length)
        else:
            counts.append(sum(counts[length - j] for j in range(1, k + 1)))
    return counts[n]
```
hint: Look at the position of the last zero in a valid string of length at least $k$.
hint: For length at least $k$, a valid string ends with exactly $j - 1$ ones after a zero, for $j = 1, \dots, k$, and the part before that zero is any valid string of length $n - j$.
solution: For length $n \ge k$, classify a valid string by the position of its last zero: the string ends with a zero followed by $j - 1$ ones, where $1 \le j \le k$ (at least one zero exists, since a string of $n \ge k$ ones is not allowed). Removing the last $j$ symbols leaves any valid string of length $n - j$, so $a_n = a_{n-1} + a_{n-2} + \dots + a_{n-k}$; for $n < k$ every string is valid, so $a_n = 2^n$. The Fibonacci recurrence is the special case $k = 2$, and using it for other $k$ is the typical mistake.

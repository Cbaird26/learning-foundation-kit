@article
Is $\sum_{k=0}^{n} \binom{n}{k}^2$ a nice number? Compute small cases: $1$, $2$, $6$, $20$, $70$ for $n = 0, 1, 2, 3, 4$. These are central binomial coefficients $\binom{2n}{n}$. An algebraic proof is awkward; a counting proof is two lines. The technique is **double counting**: choose a finite set, count it in two different ways, and equate the answers.

### Basic facts, proved by counting

Write $[n] = \{1, \dots, n\}$ and let $\binom{n}{k}$ be the number of $k$-element subsets of $[n]$.

**Pascal's identity.** For integers $n \ge 1$ and $1 \le k \le n$, $\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$.

*Proof.* Count the $k$-subsets of $[n]$ by whether they contain $n$. Those that contain $n$ correspond to $(k-1)$-subsets of $[n-1]$; those that do not are $k$-subsets of $[n-1]$. The two cases are disjoint, so the sum rule gives the identity. $\blacksquare$

**Binomial theorem.** For every integer $n \ge 0$ and all real (or complex) $x, y$, $(x+y)^n = \sum_{k=0}^{n} \binom{n}{k} x^k y^{n-k}$.

*Proof.* Expand the product of $n$ factors $(x + y)$: each term of the expansion picks $x$ or $y$ from every factor, so terms correspond to subsets $S \subseteq [n]$ (the factors where $x$ is picked), and the term for $S$ is $x^{|S|} y^{n-|S|}$. Collecting terms by $|S| = k$ gives $\binom{n}{k}$ copies of $x^k y^{n-k}$. $\blacksquare$

Setting $x = y = 1$ gives $\sum_k \binom{n}{k} = 2^n$; setting $x = 1$, $y = -1$ gives $\sum_k (-1)^k \binom{n}{k} = 0$ for $n \ge 1$ (for $n = 0$ the sum is $1$, which is why the hypothesis matters).

### Double counting

**Committee with a chair.** For $n \ge 1$: $\sum_{k=1}^{n} k \binom{n}{k} = n\,2^{n-1}$.

*Proof.* Count the pairs $(C, c)$ where $C \subseteq [n]$ is a committee and $c \in C$ is its chair. Choosing the size $k$, then $C$, then the chair gives $\sum_k k\binom{n}{k}$. Choosing the chair first ($n$ ways), then deciding independently for each of the other $n - 1$ people whether to join gives $n \cdot 2^{n-1}$. $\blacksquare$

**Vandermonde's identity.** For integers $m, n, r \ge 0$, $\sum_{j=0}^{r} \binom{m}{j}\binom{n}{r-j} = \binom{m+n}{r}$, where $\binom{a}{b} = 0$ if $b > a$.

*Proof.* Take $m$ red and $n$ blue objects and count the $r$-subsets of all $m + n$ of them. Directly there are $\binom{m+n}{r}$. By the number $j$ of red objects chosen, there are $\binom{m}{j}\binom{n}{r-j}$ subsets, and the sum rule over $j$ gives the left side. $\blacksquare$

With $m = n = r$ and $\binom{n}{j} = \binom{n}{n-j}$, Vandermonde gives $\sum_j \binom{n}{j}^2 = \binom{2n}{n}$, the answer to the opening question.

**Hockey stick.** For integers $n \ge r \ge 0$, $\sum_{i=r}^{n} \binom{i}{r} = \binom{n+1}{r+1}$: classify the $(r+1)$-subsets of $[n+1]$ by their largest element $i + 1$, which leaves an $r$-subset of $[i]$ for the rest.

### Lattice paths and reflection

A monotone lattice path from $(0,0)$ to $(a,b)$ uses $a$ steps right and $b$ steps up; it is determined by which $b$ of the $a + b$ steps go up, so there are $\binom{a+b}{b}$ of them.

**Theorem (Catalan count).** For $n \ge 0$, the number of such paths from $(0,0)$ to $(n,n)$ that never go above the line $y = x$ is $\binom{2n}{n} - \binom{2n}{n+1} = \frac{1}{n+1}\binom{2n}{n}$.

*Proof.* A path that goes above the line $y = x$ touches the line $y = x + 1$, because the quantity $y - x$ changes by $\pm 1$ at each step and starts at $0$. Reflect the part of such a path up to its first touch of $y = x + 1$ in that line (the reflection sends $(x, y)$ to $(y - 1, x + 1)$ and exchanges right steps with up steps). It sends the start $(0,0)$ to $(-1,1)$ and leaves the rest of the path alone, giving a path from $(-1,1)$ to $(n,n)$ with $n + 1$ right steps and $n - 1$ up steps. Conversely, every path from $(-1,1)$ to $(n,n)$ touches the line $y = x + 1$: there $y - x - 1$ starts at $1$ and ends at $-1$, changing by $\pm 1$ at each step, so it passes through $0$. Reflecting the part up to the first touch recovers a bad path from $(0,0)$, so the two sets are in bijection and the bad paths number $\binom{2n}{n+1}$. Finally $\binom{2n}{n+1} = \frac{n}{n+1}\binom{2n}{n}$, which gives the second form. $\blacksquare$

### Computing binomial coefficients exactly

```python
def binom(n, k):
    """C(n, k) for integers 0 <= k <= n, using integers only."""
    k = min(k, n - k)
    result = 1
    for i in range(1, k + 1):
        result = result * (n - k + i) // i
    return result


print(binom(30, 12))
```
This prints `86493225`. After step $i$, `result` equals $\binom{n-k+i}{i}$, an integer, which is why the division `// i` is exact: $\binom{m}{i} = \binom{m-1}{i-1}\cdot\frac{m}{i}$ with $m = n-k+i$. A test that agrees with `math.comb` for all $n \le 40$ is evidence; the invariant is the proof.

@example
title: The coefficient in an expansion
problem: Find the coefficient of $x^3$ in $(2x - 5)^{7}$.
step: Apply the binomial theorem with the two terms $2x$ and $-5$: the term with $(2x)^k$ is $\binom{7}{k}(2x)^k(-5)^{7-k}$.
step: We need $k = 3$: $\binom{7}{3}\,2^3\,(-5)^4$.
step: Compute each factor: $\binom{7}{3} = 35$, $2^3 = 8$, $(-5)^4 = 625$.
step: Multiply: $35 \cdot 8 \cdot 625 = 175000$. The sign is positive because the exponent $4$ of $-5$ is even.
answer: $175000$

@example
title: A double-counting proof of a squared-sum identity
problem: Prove that $\sum_{k=0}^{n} k\,(n-k)\binom{n}{k} = n(n-1)\,2^{n-2}$ for every integer $n \ge 2$.
step: Interpret $k \binom{n}{k}(n-k)$ as the number of triples $(S, a, b)$ with $S \subseteq [n]$, $|S| = k$, $a \in S$ and $b \notin S$: choose $S$, then $a$ in $k$ ways, then $b$ in $n - k$ ways.
step: Count the same triples by choosing the ordered pair $(a, b)$ of distinct elements first: $n(n-1)$ ways.
step: Given $(a, b)$, the set $S$ must contain $a$ and avoid $b$, and each of the other $n - 2$ elements is in or out freely: $2^{n-2}$ sets.
step: Both counts count the same set of triples, so $\sum_{k=0}^{n} k\binom{n}{k}(n-k) = n(n-1)2^{n-2}$.
answer: Both counts equal the number of triples, so the sum is $n(n-1)2^{n-2}$.

@mistakes
- Citing $\sum_k (-1)^k\binom{n}{k} = 0$ for $n = 0$: the sum is $1$, so the hypothesis $n \ge 1$ is needed.
- Equating $\sum_k \binom{n}{k}^2$ with $2^n$ because both equal $2$ when $n = 1$; for $n = 2$ the sums are $6$ and $4$.
- In a double-counting proof, counting two different sets (for example ordered pairs on one side and unordered on the other) and equating them.
- Applying Pascal's identity at the boundary $k = 0$ or $k = n$ without the convention $\binom{n}{k} = 0$ outside $0 \le k \le n$.

```python
def odd_entries(n):
    """Odd entries in row n of Pascal's triangle, built by addition."""
    row = [1]
    for _ in range(n):
        row = [1] + [row[i] + row[i + 1] for i in range(len(row) - 1)] + [1]
    return sum(1 for value in row if value % 2 == 1)
```

@practice self
prompt: Prove both identities by double counting, for integers $n \ge k \ge j \ge 0$ in (a) and $n \ge 0$ in (b). (a) $\binom{n}{k}\binom{k}{j} = \binom{n}{j}\binom{n-j}{k-j}$. (b) $\sum_{k=0}^{n}\binom{n}{k}2^k = 3^n$.
hint: For (a), count pairs $(J, K)$ with $J \subseteq K \subseteq [n]$, $|J| = j$ and $|K| = k$.
hint: For (b), count pairs $(A, K)$ with $A \subseteq K \subseteq [n]$ and $|K| = k$, then sum over $k$; count the same pairs element by element.
solution: (a) Count pairs $(J, K)$ with $J \subseteq K \subseteq [n]$, $|J| = j$, $|K| = k$. Choosing $K$ first, then $J$ inside it, gives $\binom{n}{k}\binom{k}{j}$. Choosing $J$ first, then the $k - j$ further elements of $K \setminus J$ from the $n - j$ elements outside $J$, gives $\binom{n}{j}\binom{n-j}{k-j}$. Both count the same set. (b) Count pairs $(A, K)$ with $A \subseteq K \subseteq [n]$. Choosing $K$ with $|K| = k$ and then any of the $2^k$ subsets $A \subseteq K$, and summing over $k$ by the sum rule, gives $\sum_k \binom{n}{k}2^k$. Alternatively decide for each element of $[n]$ independently whether it is outside $K$, in $K \setminus A$, or in $A$: three options each, so $3^n$ pairs by the product rule.

rubric: Gives two correct counts of the same set in (a), using the product rule in both orders.
rubric: In (b), uses the three-way choice per element to get $3^n$ and the sum over $|K|$ for the left side.

model:
```python
def blocked_paths(a, b, blocked):
    """Count monotone lattice paths avoiding blocked points (DP)."""
    bad = set(blocked)
    ways = {}
    for x in range(a + 1):
        for y in range(b + 1):
            if (x, y) in bad:
                ways[(x, y)] = 0
            elif (x, y) == (0, 0):
                ways[(x, y)] = 1
            else:
                ways[(x, y)] = ways.get((x - 1, y), 0) + ways.get((x, y - 1), 0)
    return ways[(a, b)]
```
hint: Let `ways[(x, y)]` be the number of allowed paths to $(x, y)$; a path arrives from the left or from below.
hint: A blocked point has `0` paths through it; the origin starts with `1` unless it is blocked.
solution: Every path to $(x, y)$ other than the empty path ends with a step from $(x-1, y)$ or $(x, y-1)$, and these two families are disjoint, so `ways[(x, y)]` is the sum of the two values (the sum rule), set to $0$ at blocked points. For no obstacles this reproduces $\binom{a+b}{a}$, as the last test shows. The usual mistake is to forget that the origin itself can be blocked.

```python
assert ballot(2, 1) == 1
assert ballot(3, 1) == 2
assert ballot(5, 3) == 14
assert ballot(4, 0) == 1
```

model:
```python
def ballot(a, b):
    """Orderings of a A's and b B's with A strictly ahead throughout."""
    if a <= b:
        return 0
    ways = [[0] * (b + 1) for _ in range(a + 1)]
    ways[0][0] = 1
    for i in range(a + 1):
        for j in range(b + 1):
            if (i, j) == (0, 0) or i <= j:
                continue
            up = ways[i - 1][j] if i > 0 else 0
            left = ways[i][j - 1] if j > 0 else 0
            ways[i][j] = up + left
    return ways[a][b]
```
hint: Let `ways[i][j]` count good prefixes with `i` A's and `j` B's; a good prefix needs `i > j`, except for the empty prefix.
hint: A good prefix ends in A or in B, and removing the last letter leaves a good prefix.
solution: A nonempty prefix with $i$ A's and $j$ B's is allowed only if $i > j$; removing its last letter leaves an allowed prefix (or the empty one), so the counts satisfy $W(i,j) = W(i-1,j) + W(i,j-1)$ for $i > j$ and $W(i, j) = 0$ for $i \le j$ (apart from $W(0,0) = 1$). The values are the ballot numbers $\frac{a-b}{a+b}\binom{a+b}{a}$, for example $\frac{2}{8}\binom{8}{5} = 14$; the DP is a computation, and the reflection principle in the article is the kind of argument that proves the closed form.

@article
Three tetrahedral dice, with faces $1, 2, 3, 4$, are rolled. In how many ways does the total equal $8$? One could list them, but there is a cleaner idea: encode one die as the polynomial $x + x^2 + x^3 + x^4$ (one term per face). Multiplying polynomials adds exponents, so the coefficient of $x^8$ in the cube is the number of outcomes with total $8$. Packaging a sequence into one object and letting algebra do the counting is the idea of a **generating function**.

### Formal power series

A **formal power series** is an expression $A(x) = \sum_{n \ge 0} a_nx^n$, that is, the sequence $(a_n)$ itself, with no question of convergence. Two series are equal if all their coefficients agree. We add coefficientwise and multiply by the **Cauchy product** $A(x)B(x) = \sum_n c_nx^n$ with $c_n = \sum_{j=0}^{n} a_jb_{n-j}$. These operations are commutative, associative and distributive, as for polynomials.

**Theorem (inverses).** A series $A(x)$ with rational (or real) coefficients has a multiplicative inverse if and only if $a_0 \ne 0$.

*Proof.* If $A(x)B(x) = 1$ then the constant term gives $a_0b_0 = 1$, so $a_0 \ne 0$. Conversely let $a_0 \ne 0$. The equation $A(x)B(x) = 1$ says $a_0b_0 = 1$ and $\sum_{j=0}^{n}a_jb_{n-j} = 0$ for $n \ge 1$, which determines $b_0 = 1/a_0$ and, successively, $b_n = -\frac{1}{a_0}\sum_{j=1}^{n}a_jb_{n-j}$. These formulas define $B$. $\blacksquare$

In particular $(1 - x)\sum_{n\ge0}x^n = 1$, so $\frac{1}{1-x} = \sum_n x^n$ as formal series. Multiplying a series by $\frac{1}{1-x}$ replaces the coefficients by their partial sums. By stars and bars, $\frac{1}{(1-x)^k} = \sum_{n \ge 0}\binom{n+k-1}{k-1}x^n$, since the coefficient of $x^n$ in the product of $k$ geometric series counts solutions of $y_1 + \dots + y_k = n$ in nonnegative integers.

### Counting with products

If an object is built from independent parts, and part $i$ contributes an exponent from the set $S_i$ (with each allowed exponent contributing $1$), the number of objects of total size $n$ is the coefficient of $x^n$ in $\prod_i\sum_{s \in S_i}x^s$. For the dice, $(x+x^2+x^3+x^4)^3 = x^3\left(\frac{1 - x^4}{1-x}\right)^3$, and the coefficient of $x^8$ is the coefficient of $x^5$ in $(1 - 3x^4 + \cdots)\sum_n\binom{n+2}{2}x^n$, namely $\binom{7}{2} - 3\binom{3}{2} = 21 - 9 = 12$.

### Solving a recurrence

Let $a_n = 5a_{n-1} - 6a_{n-2}$ for $n \ge 2$, with $a_0 = 2$, $a_1 = 5$. Multiply by $x^n$ and sum over $n \ge 2$, with $A(x) = \sum a_nx^n$: the left side is $A - a_0 - a_1x$, and the right side is $5x(A - a_0) - 6x^2A$. So
$$A(x)\,(1 - 5x + 6x^2) = a_0 + (a_1 - 5a_0)x = 2 - 5x,$$
and $1 - 5x + 6x^2 = (1-2x)(1-3x)$ has constant term $1 \ne 0$, so by the theorem we may divide: $A(x) = \frac{2 - 5x}{(1-2x)(1-3x)}$. Partial fractions: $\frac{2-5x}{(1-2x)(1-3x)} = \frac{P}{1-2x} + \frac{Q}{1-3x}$ means $2 - 5x = P(1-3x) + Q(1-2x)$; setting $x = \frac12$ gives $P = 1$ and $x = \frac13$ gives $Q = 1$. Hence $A(x) = \sum_n(2^n + 3^n)x^n$ and $a_n = 2^n + 3^n$. The denominator is the characteristic polynomial written backwards, which explains why the method agrees with last week's, and it also handles repeated roots (terms $\frac{1}{(1-rx)^2}$) and nonhomogeneous terms.

### Partitions: Euler's identity

A **partition** of $n$ is a way to write $n$ as an unordered sum of positive integers. **Euler's theorem:** for every $n \ge 0$, the number of partitions of $n$ into distinct parts equals the number of partitions of $n$ into odd parts.

*Proof.* Work modulo $x^{N+1}$, so that only factors with $k \le N$ matter. Distinct parts: each $k$ is used $0$ or $1$ times, giving the generating function $\prod_{k}(1 + x^k)$. Odd parts, each used any number of times: $\prod_{k \text{ odd}}\frac{1}{1-x^k}$. Since $1 + x^k = \frac{1 - x^{2k}}{1 - x^k}$,
$$\prod_{k \ge 1}(1 + x^k) = \prod_{k\ge1}\frac{1 - x^{2k}}{1 - x^k} = \prod_{k \ge 1}\frac{1}{1 - x^{2k-1}},$$
because the numerator factors $1 - x^{2k}$ cancel exactly the even-$k$ denominator factors. Equal generating functions mean equal coefficients. $\blacksquare$

### Code

```python
def series_mul(a, b, n):
    """First n coefficients of the product of two coefficient lists."""
    out = [0] * n
    for i, ai in enumerate(a):
        for j, bj in enumerate(b):
            if i + j < n:
                out[i + j] += ai * bj
    return out


print(series_mul([1, 1, 1], [1, 1, 1, 1], 7))
```
This prints `[1, 2, 3, 3, 2, 1, 0]`. Truncating at $n$ terms is legitimate because the coefficient of $x^m$ in a product depends only on the coefficients of index at most $m$ in the factors. Exact integers keep every coefficient correct; coefficients that grow like $2^n$ would overflow floats long before Python integers.

@example
title: A recurrence by generating functions
problem: Solve $a_n = 7a_{n-1} - 10a_{n-2}$ for $n \ge 2$ with $a_0 = 0$ and $a_1 = 3$.
step: Let $A(x) = \sum a_nx^n$. Multiply the recurrence by $x^n$ and sum over $n \ge 2$: $A - 3x = 7xA - 10x^2A$.
step: Solve for $A$: $A(1 - 7x + 10x^2) = 3x$, and $1 - 7x + 10x^2 = (1-2x)(1-5x)$, so $A = \frac{3x}{(1-2x)(1-5x)}$.
step: Partial fractions: $3x = P(1 - 5x) + Q(1 - 2x)$. At $x = \frac12$: $\frac32 = P\cdot(-\frac32)$, so $P = -1$. At $x = \frac15$: $\frac35 = Q \cdot \frac35$, so $Q = 1$.
step: Expand: $A = \frac{1}{1-5x} - \frac{1}{1-2x}$, so $a_n = 5^n - 2^n$.
step: Check: $a_2 = 7\cdot3 - 0 = 21 = 25 - 4$ and $a_3 = 7\cdot21 - 10\cdot3 = 117 = 125 - 8$.
answer: $a_n = 5^n - 2^n$

@example
title: Coefficient extraction
problem: In how many ways can three tetrahedral dice (faces $1$ to $4$) show a total of $9$?
step: Encode one die by $x + x^2 + x^3 + x^4 = x\,\frac{1 - x^4}{1 - x}$, so the total is the coefficient of $x^9$ in $x^3\frac{(1-x^4)^3}{(1-x)^3}$.
step: That is the coefficient of $x^6$ in $(1 - 3x^4 + 3x^8 - x^{12})\sum_n\binom{n+2}{2}x^n$.
step: Collect: $\binom{8}{2} - 3\binom{4}{2} = 28 - 18 = 10$ (the terms $3x^8$ and $-x^{12}$ do not reach $x^6$).
answer: $10$

@mistakes
- Treating $\frac{1}{1-x}$ as a number and plugging in values of $x$ where the series diverges; formal series need no convergence, but an analytic argument does.
- Counting ordered selections with $\prod\frac{1}{1-x^{k}}$, which counts unordered multisets, or the reverse: ordered sequences correspond to $\frac{1}{1 - (x^{a} + x^{b} + \cdots)}$.
- Forgetting the initial terms when turning a recurrence into an equation for $A(x)$: the sum starts at $n = 2$, so $a_0$ and $a_1x$ must be subtracted.
- Dividing by a series with constant term $0$: it has no inverse as a formal series.

```python
from fractions import Fraction


def series_div(p, q, n):
    """First n coefficients of P(x)/Q(x), exactly."""
    if q[0] == 0:
        raise ValueError("denominator has zero constant term")
    out = []
    for m in range(n):
        value = Fraction(p[m]) if m < len(p) else Fraction(0)
        for j in range(1, min(m, len(q) - 1) + 1):
            value -= q[j] * out[m - j]
        out.append(value / q[0])
    return out
```
hint: If $C = P/Q$ then $P = QC$, so $p_m = \sum_{j} q_jc_{m-j}$; solve this for $c_m$.
hint: The term with $j = 0$ is $q_0c_m$, and all other terms involve earlier coefficients of $C$.
solution: Comparing coefficients of $x^m$ in $P = QC$ gives $p_m = q_0c_m + \sum_{j \ge 1}q_jc_{m-j}$, so $c_m = \frac{1}{q_0}\left(p_m - \sum_{j\ge1}q_jc_{m-j}\right)$, which is the formula for the inverse in the theorem with a numerator. Each $c_m$ uses only earlier coefficients, so one pass suffices, and `Fraction` keeps the values exact when $q_0 \ne \pm1$. The fourth test shows a cancellation: $\frac{1 + x}{1 - 2x - 3x^2} = \frac{1}{1-3x}$ because $1 - 2x - 3x^2 = (1+x)(1-3x)$.

model:
```python
def partition_counts(n):
    """Partitions into distinct parts and into odd parts, up to n."""
    distinct = [1] + [0] * n
    for k in range(1, n + 1):
        for m in range(n, k - 1, -1):      # multiply by (1 + x^k)
            distinct[m] += distinct[m - k]
    odd = [1] + [0] * n
    for k in range(1, n + 1, 2):
        for m in range(k, n + 1):          # multiply by 1/(1 - x^k)
            odd[m] += odd[m - k]
    return distinct, odd
```
hint: Multiplying a series by $1 + x^k$ adds a copy of itself shifted by $k$; going downward in `m` keeps each part from being used twice.
hint: Multiplying by $1/(1 - x^k)$ means `s[m] += s[m - k]` going upward in `m`, which allows repeats.
solution: For distinct parts, the update `distinct[m] += distinct[m - k]` for `m` from `n` down to `k` is multiplication by $1 + x^k$: it uses the old values of lower indices, so each part is used at most once. For odd parts the upward loop reads values that were already updated, which is multiplication by $1/(1 - x^k) = 1 + x^k + x^{2k} + \cdots$. Equality of the two lists for every $n$ is Euler's theorem; the tests check it up to $30$, but the proof is the product identity in the article. Reversing the loop direction in either part gives the wrong answer, which the first test exposes.

@quiz ms
prompt: Which statements about formal power series with real coefficients are true?
choice*: $A(x)$ has a multiplicative inverse exactly when its constant term is nonzero.
choice*: The coefficient of $x^n$ in $\frac{A(x)}{1-x}$ is $a_0 + a_1 + \dots + a_n$.
choice*: The coefficient of $x^n$ in $\frac{1}{(1-x)^2}$ is $n + 1$.

hint: Write out the Cauchy product for the fourth statement; for the fifth, recall how series are defined in this lesson.
solution: The first is the inverse theorem. The second holds because $\frac{1}{1-x} = \sum x^n$ and the Cauchy product sums $a_j$ for $j \le n$.
```python
def dice_counts(faces, k):
    """Number of ways each total can occur with k dice of given faces."""
    counts = [1]
    for _ in range(k):
        new = [0] * (len(counts) + faces)
        for total, ways in enumerate(counts):
            for face in range(1, faces + 1):
                new[total + face] += ways
        counts = new
    return counts
```
hint: Start with the polynomial `[1]` and multiply by $x + x^2 + \dots + x^{\text{faces}}$ once per die.
hint: After each multiplication the list grows by `faces` entries; the face value is added to the exponent.
solution: One die has generating function $x + \dots + x^{f}$, and the total of independent dice has the product, so after $k$ multiplications `counts[s]` is the number of outcomes with total $s$. The list has length $kf + 1$ because the largest total is $kf$. The coefficients add up to $f^k$, the number of outcomes, which the last test checks. Starting the faces at $0$ instead of $1$ shifts the whole list, a common slip.

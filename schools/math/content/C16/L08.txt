@article
A telephone company must connect $n$ towns by cables, each possible link having a cost. The cheapest network that connects all towns contains no cycle (a cable on a cycle could be removed without disconnecting anyone) and so is a tree. This week we characterize trees, find the cheapest one, and count how many exist.

A **tree** is a connected graph with no cycle. A **leaf** is a vertex of degree $1$.

### Leaves and edge counts

**Lemma.** Every tree with $n \ge 2$ vertices has at least two leaves.

*Proof.* Take a longest path $v_0, v_1, \dots, v_k$ in the tree; $k \ge 1$ because a connected graph on at least two vertices has an edge. If $v_0$ had a neighbor outside the path, the path could be extended; if it had a neighbor $v_i$ on the path with $i \ge 2$, there would be a cycle. So $v_0$ has degree $1$, and likewise $v_k$. $\blacksquare$

**Theorem.** A graph on $n \ge 1$ vertices is a tree if and only if it is connected and has exactly $n - 1$ edges.

*Proof.* ($\Rightarrow$) Induct on $n$. For $n = 1$ there are $0$ edges. For $n \ge 2$, remove a leaf and its edge; the result is connected (a path between two other vertices never passes through a leaf) and acyclic, so by induction it has $n - 2$ edges, and the original has $n - 1$. ($\Leftarrow$) Let $G$ be connected with $n - 1$ edges. If $G$ has a cycle, delete one edge of the cycle: the graph stays connected. Repeat until no cycle remains; the result is a tree on $n$ vertices, which has $n - 1$ edges by the first part, so no edge was deleted and $G$ was a tree. $\blacksquare$

Both hypotheses matter: a triangle plus an isolated vertex has $4$ vertices and $3$ edges but is not connected.

### Minimum spanning trees

A **spanning tree** of a connected graph $G$ is a subgraph that is a tree containing every vertex. Given a weight $w(e)$ on each edge, a **minimum spanning tree** (MST) minimizes the total weight. **Kruskal's algorithm** (1956) sorts the edges by weight and adds each edge unless it would close a cycle.

**Cut property.** Let $G$ be connected and weighted, $T$ an MST, and $F \subseteq T$ a set of edges. Let $S$ be a set of vertices with no edge of $F$ leaving $S$, and let $e$ be a lightest edge with exactly one endpoint in $S$. Then $F \cup \{e\}$ is contained in some MST.

*Proof.* If $e \in T$ we are done. Otherwise $T + e$ contains a unique cycle, and this cycle crosses between $S$ and its complement at another edge $f \ne e$. Then $T' = T + e - f$ is a spanning tree, and $w(T') = w(T) + w(e) - w(f) \le w(T)$ because $e$ is lightest among the edges leaving $S$. So $T'$ is an MST. Since $f$ leaves $S$ it is not in $F$, so $F \cup \{e\} \subseteq T'$. $\blacksquare$

**Correctness of Kruskal's algorithm.** Let $F$ be the edges chosen so far, contained in some MST (true at the start, with $F = \emptyset$). The next chosen edge $e = \{a, b\}$ joins two different components of $F$. Let $S$ be the component containing $a$. No edge of $F$ leaves $S$. Every edge leaving $S$ and lighter than $e$ was examined earlier and rejected because its endpoints were already in one component, and components only grow, so such an edge cannot leave the current component $S$. Hence $e$ is a lightest edge leaving $S$ (ties are allowed), and the cut property keeps $F \cup \{e\}$ inside an MST. At the end $F$ is a spanning tree contained in an MST, so it is an MST. $\blacksquare$

To test "would close a cycle" quickly, keep a **disjoint-set** (union–find) structure:

```python
def find(parent, x):
    """Root of x's set, with path halving."""
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x


def union(parent, x, y):
    """Merge the sets of x and y; False if they were already together."""
    rx, ry = find(parent, x), find(parent, y)
    if rx == ry:
        return False
    parent[rx] = ry
    return True
```
Two vertices are in one component exactly when `find` gives equal roots, because `union` is called only on edges that are accepted.

### Counting labeled trees

**Cayley's formula.** For $n \ge 2$ there are $n^{n-2}$ trees on the vertex set $\{0, 1, \dots, n-1\}$.

The **Prüfer code** of a tree repeats $n - 2$ times: delete the leaf with the smallest label and record the label of its neighbor.

*Proof.* We show the code is a bijection from trees to sequences in $\{0, \dots, n-1\}^{n-2}$, by induction on $n$. For $n = 2$ there is one tree and one (empty) sequence. Let $n \ge 3$. A vertex $v$ appears in the code exactly $\deg(v) - 1$ times: each deleted neighbor of $v$ records $v$, and if $v$ is deleted as a leaf it has one neighbor left at that time, while if $v$ is one of the last two vertices the other one is its single remaining neighbor. So the leaves are precisely the labels missing from the code, and the first deleted leaf is $\ell$, the smallest missing label. Given a sequence $a_1, \dots, a_{n-2}$, the tree must therefore contain the edge $\{\ell, a_1\}$ plus the tree on $\{0,\dots,n-1\} \setminus \{\ell\}$ with code $a_2, \dots, a_{n-2}$, which exists and is unique by the induction hypothesis (the entries avoid $\ell$ and the sequence has the right length $n - 3$). So every sequence is the code of exactly one tree. $\blacksquare$

```python
def prufer_encode(n, edges):
    """Prufer code of a tree on 0..n-1 given as a list of pairs."""
    adj = {v: set() for v in range(n)}
    for u, v in edges:
        adj[u].add(v)
        adj[v].add(u)
    code = []
    for _ in range(n - 2):
        leaf = min(v for v in adj if len(adj[v]) == 1)
        neighbor = next(iter(adj[leaf]))
        code.append(neighbor)
        adj[neighbor].discard(leaf)
        del adj[leaf]
    return code
```

### The matrix-tree theorem

The **Laplacian** of a graph on $0, \dots, n-1$ is the matrix $L = D - A$, where $D$ is the diagonal matrix of degrees and $A$ the adjacency matrix. **Matrix-tree theorem** (Kirchhoff), stated here without proof: the number of spanning trees of $G$ equals the determinant of the matrix obtained from $L$ by deleting one row and the corresponding column (any one). For the complete graph $K_4$ the minor is $\begin{pmatrix}3&-1&-1\\-1&3&-1\\-1&-1&3\end{pmatrix}$ with determinant $16 = 4^2$, in agreement with Cayley's formula.

step: Accept $\{4,5\}$ with weight $6$; the tree now has $5 = n - 1$ edges, so stop (the edge $\{3,5\}$ would be rejected).
step: The total weight is $1 + 2 + 2 + 3 + 6 = 14$.
answer: The edges $\{1,2\}, \{1,3\}, \{3,4\}, \{0,2\}, \{4,5\}$, of total weight $14$.

@example
title: A Prüfer code
problem: Find the Prüfer code of the tree on $\{0, \dots, 6\}$ with edges $\{0,4\}, \{1,4\}, \{2,5\}, \{3,5\}, \{4,6\}, \{5,6\}$.

answer: The code is $(4, 4, 5, 5, 6)$.

@mistakes
- Believing that $n - 1$ edges alone make a tree: the graph must also be connected (or acyclic); a triangle with an isolated vertex has $n - 1$ edges.
- Adding edges in Kruskal's algorithm without the cycle test, or testing for cycles only between consecutive edges instead of using connected components.
- Assuming the minimum spanning tree is unique: with equal weights there may be several, and the algorithm's output depends on how ties are broken (the total weight does not).
- Giving a Prüfer code of length $n$ or $n - 1$: it has exactly $n - 2$ entries, one for each deleted leaf, because the last two vertices are not deleted.

```python
def kruskal(n, edges):
    """Minimum spanning forest by Kruskal's algorithm."""
    parent = list(range(n))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    total = 0
    chosen = []
    for w, u, v in sorted(edges):
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            total += w
            chosen.append((w, u, v))
    return total, chosen
```
hint: Sort a copy of the edges, then go through them in order.
hint: An edge is accepted exactly when `find(u) != find(v)`; then merge the two sets.
solution: This is the algorithm whose correctness the lesson proves with the cut property: each accepted edge is a lightest edge leaving the component of one endpoint, so the chosen set always lies inside a minimum spanning tree (or forest, for a disconnected graph). The work is dominated by the sort, $O(m \log m)$. Typical wrong versions skip the cycle test, sort by the wrong key, or sort the caller's list in place (the last test checks that the input is unchanged).

```python
def prufer_decode(seq):
    """The tree on 0..n-1 whose Prufer code is seq."""
    n = len(seq) + 2
    degree = [1] * n
    for a in seq:
        degree[a] += 1
    edges = []
    for a in seq:
        leaf = min(v for v in range(n) if degree[v] == 1)
        edges.append((min(leaf, a), max(leaf, a)))
        degree[leaf] -= 1
        degree[a] -= 1
    last = [v for v in range(n) if degree[v] == 1]
    edges.append((last[0], last[1]))
    return sorted(edges)
```
hint: A vertex's degree is $1$ plus the number of times it occurs in the code; keep a degree array and lower it as you go.
hint: A vertex becomes a leaf when its remaining degree is $1$; a used leaf drops to degree $0$.
solution: As in the proof of Cayley's formula, the leaves are exactly the labels missing from the code, and the first deleted leaf is the smallest one. Each step joins the smallest current leaf to the next code entry, then lowers both degrees; the entry may become a leaf for later steps. After $n - 2$ steps exactly two vertices have degree $1$, and they are joined. The round-trip test encodes every decoded tree of the $64$ codes for $n = 5$ and recovers the code, as the bijection proof predicts.

@quiz ms
prompt: Which statements about spanning trees are true?
choice*: Every spanning tree of a connected graph with $n$ vertices has exactly $n - 1$ edges.
choice*: The total weight of a minimum spanning tree does not depend on how ties between equal weights are broken.

```python
from fractions import Fraction


def count_spanning_trees(n, edges):
    """Number of spanning trees via the matrix-tree theorem."""
    lap = [[Fraction(0)] * n for _ in range(n)]
    for u, v in edges:
        lap[u][u] += 1
        lap[v][v] += 1
        lap[u][v] -= 1
        lap[v][u] -= 1
    m = n - 1
    mat = [row[:m] for row in lap[:m]]
    det = Fraction(1)
    for col in range(m):
        pivot = next((r for r in range(col, m) if mat[r][col] != 0), None)
        if pivot is None:
            return 0
        if pivot != col:
            mat[col], mat[pivot] = mat[pivot], mat[col]
            det = -det
        det *= mat[col][col]
        for r in range(col + 1, m):
            factor = mat[r][col] / mat[col][col]
            mat[r] = [x - factor * y for x, y in zip(mat[r], mat[col])]
    return int(det)
```
hint: The Laplacian has the degree of vertex `i` at position `(i, i)` and `-1` at `(i, j)` for each edge.
hint: Reduce to an upper triangular matrix; the determinant is the product of the pivots times the sign from row swaps.
solution: The matrix-tree theorem says the number of spanning trees is the determinant of any cofactor of the Laplacian; the code deletes the last row and column. Gaussian elimination with exact fractions never rounds, so the product of pivots is an exact integer, whereas floating-point elimination can return $15.999999$ for $16$. A zero column means the minor is singular, and a disconnected graph has $0$ spanning trees. Forgetting the sign change on row swaps is the typical wrong answer.

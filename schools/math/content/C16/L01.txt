@article
How many ways can seven doughnuts be chosen from a shop that sells four kinds, if the shop has plenty of each? Choosing $7$ objects from $4$ kinds does not fit the formula for ordinary combinations, because kinds repeat and the order of choosing does not matter. You studied basic counting in discrete mathematics; this week we sharpen the toolkit with exact proofs and with code that counts and enumerates.

### Three principles

Let $|A|$ be the number of elements of a finite set $A$.

- **Sum rule.** If $A$ and $B$ are disjoint, $|A \cup B| = |A| + |B|$.
- **Product rule.** $|A \times B| = |A|\,|B|$. In practice: if a task is done in stages, with $a_1$ options for stage 1, and for each of them $a_2$ options for stage 2 (a number that does not depend on the earlier choices), and so on, the whole task can be done in $a_1 a_2 \cdots a_r$ ways.
- **Bijection rule.** If $f\colon A \to B$ is a bijection, then $|A| = |B|$. Most hard counting problems are solved by finding a bijection to a set that is easy to count.

The number of **permutations** of $n$ distinct objects is $n! = n(n-1)\cdots 1$ (product rule). The number of ordered selections of $k$ of them is $P(n,k) = n!/(n-k)!$, and the number of unordered selections (**combinations**) is $\binom{n}{k} = \frac{n!}{k!\,(n-k)!}$, because each $k$-subset is counted $k!$ times among the ordered selections.

### Repeated objects

**Theorem (arrangements with repeated letters).** A word has $n$ letters, of which $n_1$ are one letter, $n_2$ another, and so on up to $n_m$, with $n_1 + \dots + n_m = n$. The number of distinct rearrangements is $\dfrac{n!}{n_1!\,n_2!\cdots n_m!}$.

*Proof.* Label the equal letters to make all $n$ letters distinct. There are $n!$ arrangements of the labeled letters. Erasing the labels maps each of them to a rearrangement of the word, and every rearrangement is hit by exactly $n_1!\,n_2!\cdots n_m!$ labeled arrangements, the number of ways to order the labels within each letter. Dividing gives the count. $\blacksquare$

For MISSISSIPPI ($n = 11$; one M, four I, four S, two P) this gives $\frac{11!}{1!\,4!\,4!\,2!} = 34650$.

### Selections with repetition: stars and bars

**Theorem (stars and bars).** The number of solutions of $x_1 + x_2 + \dots + x_k = n$ in nonnegative integers is $\binom{n+k-1}{k-1}$. The number of multisets of size $n$ drawn from $k$ kinds is the same number.

*Proof.* A solution is matched with a string of $n$ stars and $k-1$ bars: write $x_1$ stars, a bar, $x_2$ stars, a bar, and so on, ending with $x_k$ stars. This is a bijection between solutions and strings of length $n + k - 1$ with exactly $k - 1$ bars, because a string determines the number of stars in each of the $k$ blocks between bars. A string is determined by the positions of its bars, which form a $(k-1)$-subset of $n+k-1$ positions. $\blacksquare$

The doughnuts: $n = 7$, $k = 4$, so $\binom{10}{3} = 120$ choices. A lower bound $x_i \ge a_i$ is handled by substituting $y_i = x_i - a_i$, which reduces $n$ by $\sum a_i$. An upper bound is handled by subtracting the violating solutions (more about this next week).

**Circular arrangements.** Seating $n$ people around a round table, where two seatings are the same if one is a rotation of the other, can be done in $(n-1)!$ ways: each class of $n$ rotations contains exactly one seating in which a fixed person sits at a marked seat.

### Ranking permutations

The $n!$ permutations of $\{0, 1, \dots, n-1\}$ can be listed in **lexicographic order**. The position of a permutation in this list (counting from $0$) is its **rank**. Writing $c_i$ for the number of entries to the right of position $i$ that are smaller than the entry at position $i$, the rank is
$$\sum_{i=0}^{n-1} c_i\,(n-1-i)!, \qquad 0 \le c_i \le n-1-i.$$
This is the **factorial number system**. It is a bijection between permutations and tuples $(c_0, \dots, c_{n-1})$ with $0 \le c_i \le n-1-i$: the number of permutations starting with a smaller first entry $p_0 < a$ is $c_0 \cdot (n-1)!$, and within a block of fixed first entry the remaining entries are ranked the same way, by induction on $n$. Going the other way is a sequence of divisions with remainder.

```python
from math import factorial


def unrank(n, r):
    """The permutation of 0..n-1 with lexicographic rank r (from 0)."""
    pool = list(range(n))
    out = []
    for i in range(n, 0, -1):
        q, r = divmod(r, factorial(i - 1))   # q = how many unused entries
        out.append(pool.pop(q))              # are skipped
    return out


print(unrank(5, 77))
```

This prints `[3, 0, 4, 2, 1]`. Correctness: at each step the block size is $(i-1)!$, so the quotient $q$ is the index in the sorted pool of the next entry, and the remainder is the rank inside the block. Checking that `unrank(4, r)` lists all $24$ permutations in sorted order for $r = 0, \dots, 23$ is evidence that the code is right; the argument above is the proof.

@example
title: Solutions with lower bounds
problem: How many integer solutions does $x_1 + x_2 + x_3 + x_4 = 20$ have with $x_1 \ge 2$, $x_2 \ge 0$, $x_3 \ge 3$ and $x_4 \ge 1$?
step: Remove the forced minimum: put $y_1 = x_1 - 2$, $y_2 = x_2$, $y_3 = x_3 - 3$, $y_4 = x_4 - 1$. Then every $y_i \ge 0$.
step: Rewrite the equation: $y_1 + y_2 + y_3 + y_4 = 20 - (2 + 0 + 3 + 1) = 14$. The map $x \mapsto y$ is a bijection between the two solution sets (its inverse adds the minima back).
step: Apply stars and bars with $n = 14$ and $k = 4$: the count is $\binom{14 + 4 - 1}{4 - 1} = \binom{17}{3}$.
step: Compute $\binom{17}{3} = \frac{17 \cdot 16 \cdot 15}{6} = 680$.
answer: $680$

@example
title: The rank of a permutation
problem: Find the lexicographic rank (counting from $0$) of the permutation $(2, 0, 3, 1)$ of $\{0,1,2,3\}$.
step: Count smaller entries to the right of each position: entry $2$ has $0$ and $1$ after it, so $c_0 = 2$; entry $0$ has none, so $c_1 = 0$; entry $3$ has $1$ after it, so $c_2 = 1$; the last entry gives $c_3 = 0$.
step: The weights are $(n-1-i)! = 3!, 2!, 1!, 0! = 6, 2, 1, 1$.
step: Rank $= 2\cdot 6 + 0 \cdot 2 + 1 \cdot 1 + 0 \cdot 1 = 13$. Sanity check: the $6$ permutations starting with $0$ and the $6$ starting with $1$ come first, which is $12$ permutations; the first permutation starting with $2$ is $(2,0,1,3)$ at rank $12$, and $(2,0,3,1)$ is the next one.
answer: $13$

@mistakes
- Dividing by $n!$ instead of by the factorials of the repeat counts, or forgetting to divide at all, when letters repeat.
- Using stars and bars with a strict lower bound without shifting: positive solutions of $x_1 + \dots + x_k = n$ number $\binom{n-1}{k-1}$, not $\binom{n+k-1}{k-1}$.
- Treating a circular arrangement as $n!$ when rotations are the same, or dividing by $2$ for reflections when the problem does not identify mirror images.
- Counting a union by adding when the sets overlap: the sum rule needs disjoint sets.

```python
from math import factorial


def count_arrangements(word):
    """n! divided by the factorial of each letter's multiplicity."""
    total = factorial(len(word))
    for letter in set(word):
        total //= factorial(word.count(letter))
    return total
```
hint: Start from $n!$ for $n$ letters and divide by $m!$ for each letter that appears $m$ times.
hint: Use integer division `//` after each step so the result stays an exact integer.

Dividing step by step with `//` is exact because the running quotient is always an integer count of arrangements of a sub-multiset times the remaining factors; using `/` would produce floats that lose digits for long words.

model:
```python
from math import factorial


def perm_rank(p):
    """Rank via the factorial number system (Lehmer code)."""
    n = len(p)
    rank = 0
    for i in range(n):
        smaller = sum(1 for later in p[i + 1:] if later < p[i])
        rank += smaller * factorial(n - 1 - i)
    return rank
```
hint: For each position count the later entries that are smaller, and weight the count by a factorial.
hint: The weight at position $i$ is $(n - 1 - i)!$.
solution: The entries to the right of position $i$ that are smaller than $p_i$ are exactly the unused values that would come earlier in sorted order, so each one skips a whole block of $(n-1-i)!$ permutations that start with the same prefix. Summing the skipped blocks gives the rank. A common wrong version counts smaller entries on the left, or weights by $i!$ instead of $(n-1-i)!$; the final test over all permutations of four elements catches both.

model:
```python
def next_permutation(p):
    """Next lexicographic arrangement of the values in p, or None."""
    q = list(p)
    i = len(q) - 2
    while i >= 0 and q[i] >= q[i + 1]:
        i -= 1
    if i < 0:
        return None
    j = len(q) - 1
    while q[j] <= q[i]:
        j -= 1
    q[i], q[j] = q[j], q[i]
    q[i + 1:] = reversed(q[i + 1:])
    return q
```
hint: Find the rightmost position $i$ with $q_i < q_{i+1}$; everything after it is non-increasing.
hint: Swap $q_i$ with the rightmost later entry larger than it, then put the suffix in increasing order.
solution: The suffix after the rightmost ascent $i$ is non-increasing, so it is the largest arrangement of its values, and no change inside it can give a larger word. To increase the word minimally, the entry at $i$ must grow to the smallest larger value available in the suffix (the rightmost such entry, which keeps the suffix non-increasing after the swap), and then the suffix is made as small as possible by reversing it into increasing order. If there is no ascent, the whole list is non-increasing and is the last arrangement.

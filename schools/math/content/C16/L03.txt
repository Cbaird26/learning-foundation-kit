@article
A hat-check clerk returns $n$ hats at random. What is the probability that nobody gets their own hat? The number of permutations with no fixed point is a classic, and the way to count it is the principle that lets us count a union by correcting overcounts.

### The principle

For two finite sets, $|A \cup B| = |A| + |B| - |A \cap B|$: the elements of $A \cap B$ are counted twice in $|A| + |B|$. For $n$ sets the corrections alternate in sign.

**Theorem (inclusion–exclusion).** Let $A_1, \dots, A_n$ be finite sets. Then
$$\Big|\bigcup_{i=1}^{n} A_i\Big| = \sum_{\emptyset \ne S \subseteq [n]} (-1)^{|S|+1} \Big|\bigcap_{i \in S} A_i\Big| .$$

*Proof.* We show that every element of the union is counted exactly once on the right and that elements outside the union are not counted. An element $x$ outside the union lies in no intersection, so it contributes $0$. Let $x$ be in the union, and let $m \ge 1$ be the number of sets $A_i$ that contain $x$. The element $x$ lies in $\bigcap_{i \in S} A_i$ exactly when $S$ is a subset of these $m$ indices, so its total contribution is
$$\sum_{k=1}^{m} (-1)^{k+1}\binom{m}{k} = 1 - \sum_{k=0}^{m} (-1)^k \binom{m}{k} = 1 - 0 = 1,$$
because $\sum_{k=0}^{m}(-1)^k\binom{m}{k} = (1-1)^m = 0$ when $m \ge 1$. $\blacksquare$

In applications the sets are "bad" properties inside a universe $U$, and the number of objects with none of the bad properties is $|U| - |\bigcup A_i| = \sum_{S \subseteq [n]} (-1)^{|S|} |\bigcap_{i\in S} A_i|$ (the empty intersection is $U$).

### Derangements

A **derangement** of $[n]$ is a permutation with no fixed point. Let $A_i$ be the permutations that fix $i$. An intersection of $|S| = k$ of these sets has $(n-k)!$ elements, and there are $\binom{n}{k}$ such $S$, so the number of derangements is
$$D_n = \sum_{k=0}^{n}(-1)^k\binom{n}{k}(n-k)! = n!\sum_{k=0}^{n}\frac{(-1)^k}{k!}.$$
The first values for $n = 0, 1, 2, \dots$ are $1, 0, 1, 2, 9, 44, 265, 1854$. Two consequences:

1. $D_n = nD_{n-1} + (-1)^n$ for $n \ge 1$. Indeed $nD_{n-1} = n!\sum_{k=0}^{n-1}\frac{(-1)^k}{k!}$, and subtracting this from the formula for $D_n$ leaves the term $k = n$, which is $(-1)^n$.
2. For $n \ge 1$, $D_n$ is the integer nearest to $n!/e$. Since $e^{-1} = \sum_{k \ge 0}(-1)^k/k!$, the difference $D_n - n!/e$ equals $-n!\sum_{k > n}(-1)^k/k!$. The terms of this series alternate in sign and strictly decrease in size, so its absolute value is less than its first term times $n!$, that is less than $\frac{n!}{(n+1)!} = \frac{1}{n+1} \le \frac12$.

So a random permutation has no fixed point with probability $D_n/n! \to 1/e \approx 0.368$.

### Surjections and coprime integers

**Theorem (surjections).** For integers $n, k \ge 0$ (with the convention $0^0 = 1$), the number of functions from an $n$-set onto a $k$-set is $\sum_{j=0}^{k}(-1)^j\binom{k}{j}(k-j)^n$.

*Proof.* Let $U$ be the $k^n$ functions into $[k]$ and $A_i$ those that never take the value $i$. A function in $\bigcap_{i \in S} A_i$ maps into the $k - |S|$ values outside $S$, so there are $(k-|S|)^n$ of them. A function is onto exactly when it lies in no $A_i$, so the formula above applies. $\blacksquare$

**Euler's totient.** If $n \ge 1$ has distinct prime factors $p_1, \dots, p_r$, the integers in $[1, m]$ coprime to $n$ are those divisible by none of the $p_i$. The number divisible by all primes in a set $S$ is $\lfloor m / \prod_{i \in S} p_i \rfloor$, so inclusion–exclusion counts the coprime integers, and for $m = n$ it gives $\varphi(n) = n\prod_i (1 - 1/p_i)$.

### Code

```python
from itertools import combinations
from math import factorial


def union_size(sets):
    """|A_1 u ... u A_n| by inclusion-exclusion (sets are Python sets)."""
    total = 0
    for r in range(1, len(sets) + 1):
        for chosen in combinations(sets, r):
            total += (-1) ** (r + 1) * len(set.intersection(*chosen))
    return total


def derangements(n):
    """D_n as an exact integer."""
    return sum((-1) ** k * (factorial(n) // factorial(k))
               for k in range(n + 1))


print(union_size([{1, 2, 3, 4}, {3, 4, 5}, {4, 5, 6, 1}]), derangements(7))
```
This prints `6 1854`. The division `factorial(n) // factorial(k)` is exact, because $k! \mid n!$ for $k \le n$, so no floating-point error can enter. Comparing `union_size` with `len(set.union(*sets))` on random sets is evidence; the theorem is the proof. Note the cost: the sum has $2^n - 1$ terms, so it is practical only for a few sets, and the point of the principle is to replace it by a formula when intersections have sizes that depend only on $|S|$.

@example
title: Integers divisible by at least one of three numbers
problem: How many integers in $\{1, 2, \dots, 600\}$ are divisible by at least one of $6$, $10$ and $15$?
step: Let $A_1, A_2, A_3$ be the multiples of $6$, $10$, $15$ in the range. Single sets: $\lfloor 600/6\rfloor = 100$, $\lfloor 600/10\rfloor = 60$, $\lfloor 600/15\rfloor = 40$.
step: An integer lies in $A_i \cap A_j$ exactly when it is a multiple of the least common multiple: $\operatorname{lcm}(6,10) = 30$, $\operatorname{lcm}(6,15) = 30$, $\operatorname{lcm}(10,15) = 30$, each giving $600/30 = 20$.
step: All three: $\operatorname{lcm}(6,10,15) = 30$, giving $20$ again.
step: Apply the principle: $100 + 60 + 40 - 20 - 20 - 20 + 20 = 160$.
answer: $160$

@example
title: Permutations with forbidden positions
problem: Count the permutations $p$ of $\{0, 1, 2, 3\}$ with $p(i) \ne i$ and $p(i) \ne i + 1 \pmod 4$ for every $i$, that is, $p(i) \notin \{i, i+1 \bmod 4\}$.
step: The forbidden cells form $8$ cells of the $4 \times 4$ board. Let $r_k$ be the number of ways to place $k$ non-attacking rooks (no two in the same row or column) on forbidden cells.
step: By inclusion–exclusion, with $A_c$ the permutations using forbidden cell $c$, a set of $k$ cells lies in a common permutation exactly when they are non-attacking, and then $(4-k)!$ permutations contain them. So the count is $\sum_k (-1)^k r_k (4-k)!$.
step: Count rook placements. $r_0 = 1$ and $r_1 = 8$. For $r_2$, subtract from the $\binom{8}{2} = 28$ pairs of cells those that attack each other: $4$ pairs share a row (each row has $2$ forbidden cells) and $4$ share a column (each column has $2$), so $r_2 = 28 - 8 = 20$.
step: For $r_3$, choose the row left empty ($4$ ways); the other three rows then have $4$ non-attacking choices (for rows $0, 1, 2$ with allowed columns $\{0,1\}$, $\{1,2\}$, $\{2,3\}$ the choices are $(0,1,2)$, $(0,1,3)$, $(0,2,3)$, $(1,2,3)$), and by symmetry the same holds for every empty row, so $r_3 = 16$. For $r_4$, the full placements are $p(i) = i$ for all $i$ and $p(i) = i + 1$ for all $i$, so $r_4 = 2$.
step: Compute $\sum_k (-1)^k r_k (4-k)! = 24 - 8 \cdot 6 + 20 \cdot 2 - 16 \cdot 1 + 2 \cdot 1 = 24 - 48 + 40 - 16 + 2 = 2$.
answer: $2$

@mistakes
- Adding the sizes of overlapping sets and stopping: the pairwise intersections must be subtracted, then the triple intersections added back, and so on to the last term.
- Computing every intersection size as if the properties were independent; the size of an intersection must be counted for the actual set, for example $(n-k)!$ for $k$ fixed points but not for forbidden cells that attack each other.
- Writing $D_n = n!/e$ without rounding: $D_n$ is the nearest integer to $n!/e$, which is not an integer.
- Forgetting the term $k = 0$ (the whole universe), which makes the signs start wrongly.

```python
def count_coprime(n, m):
    """Integers in 1..m coprime to n, by inclusion-exclusion on primes."""
    primes = []
    d = 2
    rest = n
    while d * d <= rest:
        if rest % d == 0:
            primes.append(d)
            while rest % d == 0:
                rest //= d
        d += 1
    if rest > 1:
        primes.append(rest)
    total = 0
    for mask in range(1 << len(primes)):
        product = 1
        bits = 0
        for i, p in enumerate(primes):
            if mask >> i & 1:
                product *= p
                bits += 1
        total += (-1) ** bits * (m // product)
    return total
```
hint: The integers in $[1, m]$ divisible by every prime in a set $S$ number $\lfloor m / \prod_{p \in S} p \rfloor$.
hint: Sum over all subsets $S$ of the distinct primes (including the empty one) with sign $(-1)^{|S|}$.
solution: An integer is coprime to $n$ exactly when it is divisible by none of the distinct primes of $n$. By inclusion–exclusion the count is $\sum_S (-1)^{|S|}\lfloor m/\prod_{p\in S}p\rfloor$, with the empty subset contributing $m$. The usual mistakes are to use each prime factor with multiplicity ($36$ has only the primes $2$ and $3$) and to forget the empty subset.

solution: Choose the set $F$ of the $k$ fixed points: $\binom{n}{k}$ ways. A permutation whose set of fixed points is exactly $F$ restricts to a permutation of the $n-k$ points outside $F$ with no fixed point, and conversely any derangement of $[n]\setminus F$ together with the identity on $F$ gives such a permutation. So for each $F$ there are $D_{n-k}$ permutations, and the product rule gives $\binom{n}{k}D_{n-k}$. Every permutation of $[n]$ has exactly one number of fixed points $k \in \{0, \dots, n\}$, so by the sum rule the counts add up to $n!$.

```python
from math import factorial


def avoiding(n, forbidden):
    """Permutations with p[i] not in forbidden[i], by rook numbers."""
    ways = {0: 1}  # bitmask of used columns -> placements of rooks
    for row in range(n):
        new = dict(ways)  # place no rook in this row
        for mask, count in ways.items():
            for col in forbidden[row]:
                if not mask >> col & 1:
                    key = mask | (1 << col)
                    new[key] = new.get(key, 0) + count
        ways = new
    rooks = [0] * (n + 1)
    for mask, count in ways.items():
        rooks[bin(mask).count("1")] += count
    return sum((-1) ** k * rooks[k] * factorial(n - k) for k in range(n + 1))
```
hint: Process the rows one at a time; keep, for each set of used columns, how many ways to place rooks so far.
hint: The number of rooks equals the number of used columns, so $r_k$ is the total over masks with $k$ bits set.
solution: A set of $k$ forbidden cells lies in some common permutation exactly when no two share a row or a column, and then it lies in $(n-k)!$ permutations, so inclusion–exclusion gives $\sum_k (-1)^k r_k (n-k)!$. The dynamic program counts each non-attacking placement once, by the columns used, because a rook in a row uses one new column. Counting all subsets of forbidden cells, without the non-attacking condition, is the typical wrong answer, and the ménage-type tests catch it.

model:
```python
from math import comb, factorial


def fixed_point_counts(n):
    """Number of permutations of n elements with k fixed points."""
    def derange(m):
        return sum((-1) ** j * (factorial(m) // factorial(j))
                   for j in range(m + 1))

    return [comb(n, k) * derange(n - k) for k in range(n + 1)]
```
hint: Choose which $k$ points stay fixed, then derange the other $n - k$ points.
hint: $D_0 = 1$: the empty permutation has no fixed point.
solution: Choosing the $k$ fixed points and deranging the rest gives $\binom{n}{k}D_{n-k}$ permutations with exactly $k$ fixed points. The values must add up to $n!$, which the tests check, along with a brute-force enumeration for $n = 6$ (evidence of the formula's correctness for that case; the counting argument is the proof). A wrong version that uses $(n-k)!$ in place of $D_{n-k}$ counts permutations with at least those $k$ fixed points, and fails the first tests.

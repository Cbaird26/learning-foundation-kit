@article
At a party of six people, any two are either friends or strangers. Must there be three mutual friends or three mutual strangers? With five people it can fail, but with six it cannot. This is the smallest case of Ramsey's theorem (1930): in a large enough structure, order is unavoidable. The tool is the pigeonhole principle, in a more careful form than in an introductory course.

### The pigeonhole principle

**Pigeonhole principle.** If $N$ objects are placed in $k \ge 1$ boxes, some box holds at least $\lceil N/k \rceil$ objects. *Proof.* If every box held at most $\lceil N/k \rceil - 1 < N/k$ objects, the total would be less than $N$. $\blacksquare$

**Theorem (Dirichlet's approximation).** Let $\alpha \in \mathbb{R}$ and $N \in \mathbb{N}$. There are integers $p, q$ with $1 \le q \le N$ and $|q\alpha - p| < 1/N$.

*Proof.* Consider the $N + 1$ numbers $\{j\alpha\} = j\alpha - \lfloor j\alpha\rfloor \in [0,1)$ for $j = 0, 1, \dots, N$. The $N$ intervals $[i/N, (i+1)/N)$ for $i = 0, \dots, N-1$ are boxes covering $[0,1)$. Two of the numbers, say for $j < j'$, lie in the same box, so $|\{j'\alpha\} - \{j\alpha\}| < 1/N$. With $q = j' - j \in [1, N]$ and $p = \lfloor j'\alpha \rfloor - \lfloor j\alpha\rfloor$, we get $|q\alpha - p| < 1/N$. $\blacksquare$

### Ramsey numbers

Color each edge of the complete graph $K_n$ red or blue. A **monochromatic $K_k$** is a set of $k$ vertices with all $\binom{k}{2}$ edges between them of one color. For integers $s, t \ge 1$ the **Ramsey number** $R(s,t)$ is the least $n$ such that every red/blue coloring of the edges of $K_n$ contains a red $K_s$ or a blue $K_t$. Obviously $R(s,t) = R(t,s)$, $R(s,1) = 1$ and $R(s,2) = s$ for $s \ge 2$. That $R(s,t)$ exists is part of the theorem below.

**Theorem (Ramsey, recursive bound).** For integers $s, t \ge 2$, $R(s,t)$ exists and $R(s,t) \le R(s-1,t) + R(s,t-1)$. Consequently $R(s,t) \le \binom{s+t-2}{s-1}$.

*Proof.* Induction on $s + t$; the cases $s = 2$ or $t = 2$ are the values above. Let $s, t \ge 3$, put $n = R(s-1,t) + R(s,t-1)$ and color $K_n$. Fix a vertex $v$. Let $X$ be the set of vertices joined to $v$ by a red edge and $Y$ those joined by a blue edge, so $|X| + |Y| = n - 1$. If $|X| \le R(s-1,t) - 1$ and $|Y| \le R(s,t-1) - 1$, then $n - 1 \le n - 2$, impossible. So $|X| \ge R(s-1,t)$ or $|Y| \ge R(s,t-1)$. In the first case, $X$ contains a red $K_{s-1}$, which together with $v$ is a red $K_s$, or a blue $K_t$. In the second case, $Y$ contains a red $K_s$ or a blue $K_{t-1}$, which together with $v$ gives a blue $K_t$. The binomial bound follows by induction using Pascal's identity, since $\binom{s+t-2}{s-1} = \binom{s+t-3}{s-2} + \binom{s+t-3}{s-1}$ and the base cases agree with the binomial bound: $R(2,t) = t = \binom{t}{1}$ and $R(s,2) = s = \binom{s}{s-1}$. $\blacksquare$

**$R(3,3) = 6$.** The bound gives $R(3,3) \le R(2,3) + R(3,2) = 6$. For $K_5$, color the edge $\{i,j\}$ red if $i - j \equiv \pm 1 \pmod 5$ and blue otherwise: both colors form a $5$-cycle, which has no triangle, so $R(3,3) > 5$.

**A lower bound by counting.** If $k \ge 3$ and $\binom{n}{k}\,2^{1-\binom{k}{2}} < 1$ then $R(k,k) > n$. *Proof.* There are $2^{\binom{n}{2}}$ colorings of $K_n$. For a fixed $k$-set of vertices, $2 \cdot 2^{\binom{n}{2} - \binom{k}{2}}$ colorings make it monochromatic (two color choices, free elsewhere). By the sum rule at most $\binom{n}{k}\,2^{1+\binom{n}{2}-\binom{k}{2}}$ colorings contain some monochromatic $k$-set, which is fewer than all colorings by hypothesis. So some coloring has none. $\blacksquare$ For $k = 5$, $\binom{11}{5} = 462 < 512 = 2^{9}$, so $R(5,5) > 11$; the true value is larger, and exact Ramsey numbers beyond a few small ones are open problems.

### Goodman's formula

If $r_v$ and $b_v$ are the red and blue degrees of $v$ in a coloring of $K_n$, then the number of monochromatic triangles is $\binom{n}{3} - \frac12\sum_v r_v b_v$. *Proof.* A non-monochromatic triangle has exactly two vertices where its two edges differ in color, so $\sum_v r_vb_v$ (the number of pairs of differently colored edges at a common vertex) counts each non-monochromatic triangle exactly twice, and monochromatic triangles never. $\blacksquare$

```python
from itertools import combinations


def mono_triangles(n, red):
    """Brute force: red is a list of pairs (i, j) with i < j."""
    red_set = set(red)
    count = 0
    for a, b, c in combinations(range(n), 3):
        colors = {(a, b) in red_set, (a, c) in red_set, (b, c) in red_set}
        if len(colors) == 1:
            count += 1
    return count


pentagon = [(0, 1), (1, 2), (2, 3), (3, 4), (0, 4)]
print(mono_triangles(5, pentagon))
```
This prints `0`, confirming the $K_5$ coloring above. Here a coloring of $K_n$ on vertices $0, \dots, n-1$ is given by its list of red edges; all other pairs are blue.

@example
title: Residues and the pigeonhole principle
problem: Prove that among any $7$ integers there are two whose sum or whose difference is divisible by $10$.
step: Sort integers into boxes by their remainder modulo $10$, grouping remainders that add to $10$: the six boxes are $\{0\}$, $\{1, 9\}$, $\{2, 8\}$, $\{3, 7\}$, $\{4, 6\}$ and $\{5\}$.
step: There are $7$ integers and $6$ boxes, so by the pigeonhole principle two of them, $a$ and $b$, fall in the same box.
step: If $a$ and $b$ have the same remainder, then $10 \mid a - b$.
step: Otherwise their remainders are $r$ and $10 - r$ for some $r \in \{1, 2, 3, 4\}$, so $a + b \equiv r + (10 - r) \equiv 0 \pmod{10}$ and $10 \mid a + b$.
answer: Two of the integers have a sum or a difference divisible by $10$.

@example
title: Counting monochromatic triangles with Goodman's formula
problem: Color the edges of $K_6$ so that the red edges are exactly the six edges of the cycle $0$-$1$-$2$-$3$-$4$-$5$-$0$. Find the number of monochromatic triangles.
step: Each vertex has red degree $r_v = 2$ and blue degree $b_v = 5 - 2 = 3$.
step: Then $\sum_v r_vb_v = 6 \cdot 6 = 36$, and $\frac12 \cdot 36 = 18$.
step: Goodman's formula gives $\binom{6}{3} - 18 = 20 - 18 = 2$.
step: Check: the red graph is a $6$-cycle, which has no triangle; the two blue triangles are $\{0,2,4\}$ and $\{1,3,5\}$.
answer: $2$

@mistakes
- Using the pigeonhole principle with boxes that are not disjoint or do not cover all the objects, so that the count of boxes is wrong.
- Reading $R(s,t) \le R(s-1,t) + R(s,t-1)$ as an equality: for $s = 3$, $t = 4$ it gives $10$, but $R(3,4) = 9$.
- Treating a coloring of $K_n$ with no monochromatic $K_k$ as proof that $R(k,k) = n$: it proves only the lower bound $R(k,k) > n$, and colorings of $K_{n+1}$ may still avoid monochromatic $K_k$.
- Forgetting the factor $\frac12$ in Goodman's formula: each non-monochromatic triangle is counted twice in $\sum_v r_vb_v$.

```python
from math import comb


def goodman(n, red):
    """Monochromatic triangles of a 2-colored K_n from the degrees."""
    degree = [0] * n
    for i, j in red:
        degree[i] += 1
        degree[j] += 1
    mixed = sum(d * (n - 1 - d) for d in degree)
    return comb(n, 3) - mixed // 2
```
hint: The blue degree of $v$ is $n - 1$ minus its red degree.
hint: The sum of $r_vb_v$ over all vertices is even, so integer division by $2$ is exact.
solution: Each triangle that is not monochromatic has exactly two vertices at which its two edges have different colors, so $\sum_v r_vb_v$ counts it twice, and monochromatic triangles contribute $0$. Hence the number of non-monochromatic triangles is half the sum, and the rest are monochromatic. Forgetting the factor $\frac12$ gives a negative count for most colorings, which the first tests catch.

model:
```python
from math import comb


def surjections(n, k):
    """Onto functions from an n-set to a k-set (inclusion-exclusion)."""
    return sum((-1) ** j * comb(k, j) * (k - j) ** n for j in range(k + 1))
```
hint: A function misses a set $S$ of values when it maps into the other $k - |S|$ values, and there are $(k-|S|)^n$ such functions.
hint: Sum over $j = |S|$ from $0$ to $k$ with sign $(-1)^j$ and the factor $\binom{k}{j}$ for the choice of $S$.
solution: The functions that miss every value of a given set $S$ number $(k-|S|)^n$; a function is onto exactly when it misses no value, so inclusion–exclusion over the $k$ possible missed values gives the formula. The result also equals $k!$ times the Stirling number of the second kind, which counts partitions of the $n$-set into $k$ blocks. Using $k^n$ minus $k(k-1)^n$ (stopping after the first correction) is the typical wrong answer.

model:
```python
from itertools import combinations


def mono_clique(n, red, k):
    """First k-set of vertices with all pairs of one color, or None."""
    red_set = set(red)
    for group in combinations(range(n), k):
        colors = {pair in red_set for pair in combinations(group, 2)}
        if len(colors) <= 1:
            return group
    return None
```
hint: Go through the $k$-subsets in lexicographic order (`itertools.combinations` does this) and collect the set of colors of their pairs.
hint: A $k$-set with $k = 1$ has no pairs, so it is monochromatic by default.
solution: A $k$-set is monochromatic when the set of colors of its pairs has at most one element; `combinations` produces the sets in lexicographic order, so the first one found is the answer. Checking only red cliques, or only blue ones, is the usual wrong answer. The search takes $\binom{n}{k}\binom{k}{2}$ steps, fine for small $n$, and no known algorithm is dramatically faster in general.

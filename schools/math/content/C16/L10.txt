@article
Five workers each know how to do some of five tasks. Can every worker be assigned a different task they can do? Trying assignments by hand quickly becomes a puzzle, and when it fails we would like a short reason why. This is the bipartite matching problem, and its theory gives both an algorithm and a certificate of optimality.

A graph is **bipartite** if its vertices split into two parts $X$ and $Y$ with every edge joining $X$ to $Y$. In code the left part is $0, \dots, L-1$, the right part is $0, \dots, m-1$, and the graph is a list `adj` where `adj[u]` lists the right neighbors of left vertex `u`. A **matching** is a set of edges no two of which share a vertex; it **saturates** the vertices it covers, and a **perfect matching** saturates every vertex. The set $N(S)$ is the set of neighbors of the vertices in $S$.

### Augmenting paths

Let $M$ be a matching. An **alternating path** alternates between edges not in $M$ and edges of $M$; an **augmenting path** is an alternating path that starts and ends at unmatched vertices (so it has one more non-$M$ edge than $M$-edge).

**Theorem (Berge).** A matching $M$ in a graph is maximum if and only if there is no augmenting path with respect to $M$.

*Proof.* If there is an augmenting path $P$, then replacing the $M$-edges of $P$ by its other edges gives a matching with one more edge. Conversely, suppose $M'$ is a matching with $|M'| > |M|$. In the symmetric difference $M \triangle M'$ every vertex has degree at most $2$, so its components are paths and even cycles whose edges alternate between $M$ and $M'$. Since $M'$ has more edges than $M$, some component has more edges of $M'$ than of $M$. It cannot be a cycle (equal numbers), so it is a path starting and ending with edges of $M'$, and its end vertices are unmatched in $M$ (otherwise the path could be extended by an $M$-edge, or the vertex would have two $M$-edges). It is an augmenting path for $M$. $\blacksquare$

**Kuhn's algorithm** processes the left vertices one at a time; for each it searches by depth-first search for an augmenting path starting at it and flips the path if it finds one. By Berge's theorem and the observation that a vertex that fails to find a path will never find one later, the final matching is maximum. The cost is $O(L \cdot E)$.

### Hall's theorem

**Hall's marriage theorem** (1935). Let $G$ be a finite bipartite graph with parts $X$ and $Y$. There is a matching saturating $X$ if and only if $|N(S)| \ge |S|$ for every subset $S \subseteq X$.

*Proof.* ($\Rightarrow$) The partners of the vertices of $S$ are distinct vertices of $N(S)$. ($\Leftarrow$) Induct on $|X|$; the case $|X| = 1$ is clear. Assume Hall's condition. *Case 1:* $|N(S)| \ge |S| + 1$ for every nonempty proper subset $S \subsetneq X$. Pick $x \in X$ and a neighbor $y$, and delete both. For a nonempty $S \subseteq X \setminus \{x\}$, the neighborhood lost at most $y$, so $|N'(S)| \ge |N(S)| - 1 \ge |S|$; by induction $X \setminus \{x\}$ is matched, and adding $xy$ finishes. *Case 2:* some nonempty proper $S$ has $|N(S)| = |S|$. Hall's condition holds inside the subgraph on $S \cup N(S)$ (for $T \subseteq S$, $N(T) \subseteq N(S)$), so $S$ can be matched onto $N(S)$ by induction. In the graph $G'$ obtained by deleting $S \cup N(S)$, every $T \subseteq X \setminus S$ satisfies $|N'(T)| = |N(T \cup S)| - |N(S)| \ge |T| + |S| - |S| = |T|$, so $X \setminus S$ can be matched in $G'$. The two matchings together saturate $X$. $\blacksquare$

**Corollary.** A $k$-regular bipartite graph with $k \ge 1$ has a perfect matching. *Proof.* Counting edges gives $k|X| = k|Y|$, so $|X| = |Y|$. For $S \subseteq X$, the $k|S|$ edges leaving $S$ all end in $N(S)$, which receives at most $k|N(S)|$ edges, so $|N(S)| \ge |S|$. Hall's theorem gives a matching saturating $X$, which is perfect. $\blacksquare$

Regularity cannot be dropped: in the path with three vertices $x_1 - y - x_2$, $S = \{x_1, x_2\}$ has $|N(S)| = 1 < 2$.

### König's theorem and certificates

A **vertex cover** is a set of vertices meeting every edge. Any cover must contain at least one endpoint of each edge of a matching, so $|M| \le |C|$ for every matching $M$ and cover $C$. Equality certifies that both are optimal.

**König's theorem.** In a finite bipartite graph the maximum size of a matching equals the minimum size of a vertex cover.

*Proof.* We have $\le$ from the remark above. For $\ge$, let $M$ be a maximum matching and let $Z$ be the set of vertices reachable from unmatched vertices of $X$ by alternating paths (non-$M$ edges from $X$ to $Y$, $M$-edges from $Y$ to $X$). Put $C = (X \setminus Z) \cup (Y \cap Z)$. Every vertex of $Y \cap Z$ is matched, otherwise we would have an augmenting path, and its partner is in $Z$. Every vertex of $X \setminus Z$ is matched (unmatched vertices of $X$ are in $Z$) and its partner is not in $Z$ (otherwise the vertex would be reached by the $M$-edge). So $C$ contains exactly one endpoint of each edge of $M$ and no other vertex, giving $|C| = |M|$. It is a cover: an edge $xy$ with $x \in Z$ and $y \notin Z$ would be a non-$M$ edge (an $M$-edge from $x \in Z$ leads to $y \in Z$), and then $y$ would be reached from $x$, a contradiction. $\blacksquare$

The theorem fails without bipartiteness: a triangle has maximum matching $1$ and minimum vertex cover $2$.

```python
from itertools import combinations


def hall_violator(adj):
    """A smallest set S of left vertices with |N(S)| < |S|, or None."""
    for size in range(1, len(adj) + 1):
        for subset in combinations(range(len(adj)), size):
            neighbors = set()
            for u in subset:
                neighbors.update(adj[u])
            if len(neighbors) < size:
                return list(subset)
    return None


print(hall_violator([[0], [0], [1, 2]]))
```
This prints `[0, 1]`: the left vertices $0$ and $1$ are both adjacent only to right vertex $0$. The search tries $2^L - 1$ subsets, so it is for tiny graphs only; Kuhn's algorithm finds the same obstruction in polynomial time.

title: An augmenting path
problem: The left vertices $0, 1, 2$ have right neighbors $0\!:\{0,1\}$, $1\!:\{1,2\}$, $2\!:\{0\}$. The matching $M = \{(0,0), (1,1)\}$ is given. Find an augmenting path and a larger matching.
step: The unmatched left vertex is $2$ and the unmatched right vertex is $2$. We look for an alternating path from $2$ to $2$.
step: Start at left $2$; its only edge goes to right $0$, which is matched to left $0$ (an $M$-edge), so continue to left $0$.
step: From left $0$ take the non-$M$ edge to right $1$, which is matched to left $1$; continue to left $1$.
step: From left $1$ take the non-$M$ edge to right $2$, which is unmatched. The path left $2$, right $0$, left $0$, right $1$, left $1$, right $2$ is augmenting.
step: Flip it: remove $(0,0)$ and $(1,1)$ and add $(2,0)$, $(0,1)$, $(1,2)$. The new matching has $3$ edges, which is perfect.
answer: The augmenting path gives the perfect matching $\{(2,0), (0,1), (1,2)\}$.

@example
title: A Hall violator and a vertex cover
problem: Left vertices $0, 1, 2, 3$ have right neighbors $0\!:\{0\}$, $1\!:\{0\}$, $2\!:\{0, 1\}$, $3\!:\{1, 2\}$. Show there is no matching saturating the left side, and find the maximum matching size with a certificate.
step: Take $S = \{0, 1, 2\}$. Then $N(S) = \{0, 1\}$ has size $2 < 3$, so Hall's condition fails and no matching saturates the left side.
step: A matching of size $3$ exists: $(0,0)$, $(2,1)$, $(3,2)$. By Hall's obstruction, no matching has size $4$.
step: To certify that $3$ is the maximum, find a vertex cover of size $3$: the right vertices $0$ and $1$, together with left vertex $3$ (whose edges go to right $1$ and right $2$; right $1$ is already in the cover, so left $3$ is needed only for the edge to right $2$).
step: Check that the cover meets every edge: edges at left $0, 1, 2$ end in right $0$ or $1$; the edges of left $3$ are covered by left $3$ itself. A cover of size $3$ and a matching of size $3$ show the maximum is $3$.
answer: The maximum matching has $3$ edges; the cover $\{$right $0$, right $1$, left $3\}$ proves it.

@mistakes
- Checking Hall's condition only for single vertices ($\deg \ge 1$) or only for $S = X$: it must hold for every subset $S \subseteq X$.
- Concluding that a matching is maximum because no edge can be added to it: a maximal matching need not be maximum (a path with four vertices has a maximal matching of size $1$ and a maximum of size $2$).
- Applying König's theorem to a non-bipartite graph: for the triangle the maximum matching is $1$ but the minimum vertex cover is $2$.
- Assuming $|X| \le |Y|$ is enough for a matching saturating $X$: it is only necessary, as the path $x_1 - y - x_2$ with an extra isolated $y'$ shows.

```python
def max_matching(adj, m):
    """Maximum bipartite matching by augmenting paths (Kuhn)."""
    match_right = [-1] * m

    def augment(u, seen):
        for v in adj[u]:
            if not seen[v]:
                seen[v] = True
                if match_right[v] == -1 or augment(match_right[v], seen):
                    match_right[v] = u
                    return True
        return False

    size = 0
    for u in range(len(adj)):
        if augment(u, [False] * m):
            size += 1
    pairs = sorted((u, v) for v, u in enumerate(match_right) if u != -1)
    return size, pairs
```
hint: Keep `match_right[v]`, the left partner of right vertex `v` (or `-1`), and a `seen` list per search.
hint: To use right vertex `v`, either it is free, or its current partner can be re-matched to a different right vertex by a recursive search.
solution: The recursive search follows the alternating path: from `u` take a non-matching edge to `v`, then continue from the current partner of `v`; if it reaches a free right vertex, the path is augmenting and the assignments `match_right[v] = u` along the recursion unwind flip it. By Berge's theorem the matching after all left vertices have been tried is maximum, because a vertex whose search failed has no augmenting path, and later augmentations cannot create one. A greedy version that never re-matches (taking the first free neighbor) gives size $2$ instead of $3$ on the first test graph.

```python
def vertex_cover(adj, m):
    """Minimum vertex cover of a bipartite graph (Koenig)."""
    n = len(adj)
    match_right = [-1] * m

    def augment(u, seen):
        for v in adj[u]:
            if not seen[v]:
                seen[v] = True
                if match_right[v] == -1 or augment(match_right[v], seen):
                    match_right[v] = u
                    return True
        return False

    for u in range(n):
        augment(u, [False] * m)
    matched_left = [False] * n
    for v in range(m):
        if match_right[v] != -1:
            matched_left[match_right[v]] = True
    reach_left = [not matched_left[u] for u in range(n)]
    reach_right = [False] * m
    stack = [u for u in range(n) if reach_left[u]]
    while stack:
        u = stack.pop()
        for v in adj[u]:
            if not reach_right[v]:
                reach_right[v] = True
                w = match_right[v]
                if w != -1 and not reach_left[w]:
                    reach_left[w] = True
                    stack.append(w)
    left = [u for u in range(n) if not reach_left[u]]
    right = [v for v in range(m) if reach_right[v]]
    return left, right
```
hint: After finding a maximum matching, start a search from every unmatched left vertex: go along any edge to the right, and from a right vertex go back along its matching edge.
hint: The cover is the left vertices that were not reached together with the right vertices that were reached.
solution: This is the construction in the proof of König's theorem: with a maximum matching there is no augmenting path, so every reached right vertex is matched, and the cover contains exactly one endpoint of each matching edge and nothing else, so its size equals the matching size; it meets every edge by the argument in the proof. Taking all left vertices, or all right vertices, covers the graph but is not minimum, and picking one endpoint of each matching edge without the reachability rule can leave an edge uncovered.

```python
def count_perfect_matchings(adj):
    """Number of perfect matchings, by DP over used right vertices."""
    n = len(adj)
    ways = {0: 1}
    for u in range(n):
        new = {}
        for mask, count in ways.items():
            for v in adj[u]:
                if not mask >> v & 1:
                    key = mask | (1 << v)
                    new[key] = new.get(key, 0) + count
        ways = new
    return ways.get((1 << n) - 1, 0)
```
hint: After processing the first `u` left vertices, `ways[mask]` counts matchings of them that use exactly the right vertices in `mask`.
hint: Left vertex `u` may take any neighbor `v` that is not yet in `mask`.
solution: Matchings of the first $u + 1$ left vertices using the right vertex set $S$ are in bijection with matchings of the first $u$ left vertices using $S \setminus \{v\}$ together with a choice of the partner $v$ of vertex $u$, so the dictionary update follows the sum rule. After all $n$ left vertices, the matchings using all $n$ right vertices are exactly the perfect matchings. The count is the permanent of the biadjacency matrix, which has no known polynomial-time algorithm; the DP takes about $2^n n^2$ steps. Using the determinant, or counting all matchings of any size, gives wrong values.

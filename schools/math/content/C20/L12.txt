@article
Physicists speak of a "unit point load" or an "instantaneous unit pulse of heat" as if some function were infinitely tall, infinitely thin and had area $1$. No ordinary function does that, yet $-G''=\delta$ was useful last week. **Distributions** make it rigorous by changing the question: instead of asking for the value of an object at each point, ask how it acts on smooth test functions.

### Test functions and distributions

A **test function** $\varphi$ is infinitely differentiable and zero outside some bounded interval. A **distribution** $T$ is a continuous linear rule that assigns a number $\langle T,\varphi\rangle$ to each test function. Any locally integrable function $f$ is a distribution through $\langle f,\varphi\rangle=\int f\varphi\,dx$. The **Dirac delta** at $a$ is
$$\langle\delta_a,\varphi\rangle=\varphi(a).$$
It samples the test function at one point. It is not a function, but it is a limit of functions: if $\eta\ge0$, $\int\eta=1$, and $\eta_\varepsilon(x)=\frac1\varepsilon\eta\!\left(\frac x\varepsilon\right)$, then $\int\eta_\varepsilon\varphi\,dx\to\varphi(0)$. The heat kernel $G(x,t)$ as $t\to0^+$ is an example.

### Derivatives of distributions

Integration by parts (with no boundary terms, because $\varphi$ has compact support) motivates the definition
$$\langle T',\varphi\rangle=-\langle T,\varphi'\rangle,\qquad\langle T'',\varphi\rangle=\langle T,\varphi''\rangle.$$
So every distribution can be differentiated as often as we like. For example:

- the Heaviside function $H$ ($0$ for $x<0$, $1$ for $x>0$) has $\langle H',\varphi\rangle=-\int_0^\infty\varphi'\,dx=\varphi(0)$, so $H'=\delta$;
- $\langle\delta',\varphi\rangle=-\varphi'(0)$ and $\langle\delta'',\varphi\rangle=\varphi''(0)$;
- **jump rule:** if $f$ is smooth except for a jump $[f]=f(a^+)-f(a^-)$ at $a$, then $f'=\{f'\}+[f]\,\delta_a$, where $\{f'\}$ is the ordinary derivative away from $a$.

### Computation rules

For smooth $g$, $g\,\delta_a=g(a)\,\delta_a$, so $x\,\delta=0$. Also $\delta(cx)=\frac{1}{|c|}\delta(x)$; in the transform convention of week 3, $\hat\delta=1$ and $\hat 1=2\pi\delta$; and $f*\delta=f$, so $\delta$ is the identity for convolution.

### Green functions revisited

The statement "$-G''=\delta_s$ with $G(0)=G(L)=0$" now has a precise meaning: for every test function $\varphi$ supported in $(0,L)$,
$$-\int_0^LG(x,s)\,\varphi''(x)\,dx=\varphi(s).$$
To check it, split the integral at $s$ and integrate by parts twice on each piece. Because $G$ is linear on each piece ($G_{xx}=0$), $G$ is continuous and $\varphi$ vanishes near the ends, everything cancels except
$$-\int_0^LG(x,s)\,\varphi''(x)\,dx=-\left[G_x(s^+,s)-G_x(s^-,s)\right]\varphi(s).$$
This equals $\varphi(s)$ exactly when the jump of $G_x$ is $-1$, the same jump condition as in week 11. The same computation shows that $G_0=-\frac12|x|$ satisfies $-G_0''=\delta$, since $|x|''=2\delta$. A function that solves the equation only in this weak sense is called a **weak solution**, and it allows rough loads such as jumps or point masses.

@example
title: The second derivative of $|x|$
problem: Show that $|x|'=\operatorname{sgn}x$ and $|x|''=2\delta$ as distributions.
step: By definition, $\langle|x|',\varphi\rangle=-\int|x|\varphi'\,dx=-\int_0^\infty x\varphi'\,dx+\int_{-\infty}^0x\varphi'\,dx$.
step: Integrate by parts on each half line; the boundary terms vanish because $x\varphi\to0$ at $\pm\infty$ and at $0$: $-\int_0^\infty x\varphi'=\int_0^\infty\varphi$ and $\int_{-\infty}^0x\varphi'=-\int_{-\infty}^0\varphi$. So $\langle|x|',\varphi\rangle=\int_0^\infty\varphi-\int_{-\infty}^0\varphi=\int\operatorname{sgn}(x)\,\varphi\,dx$.
step: Differentiate again: $\langle|x|'',\varphi\rangle=-\int\operatorname{sgn}(x)\varphi'\,dx=-\left[\int_0^\infty\varphi'-\int_{-\infty}^0\varphi'\right]=-\left[-\varphi(0)-\varphi(0)\right]=2\varphi(0)$.
step: Thus $|x|''=2\delta$, which agrees with the jump rule: $\operatorname{sgn}$ jumps by $2$ at $0$. Consequently $\left(-\frac12|x|\right)''=-\delta$, so $G_0=-\frac12|x|$ solves $-G_0''=\delta$.

@example
title: Checking a Green function with a test function
problem: Let $L=1$ and $s=\frac12$, so $G(x,\frac12)=\frac x2$ for $x\le\frac12$ and $\frac{1-x}{2}$ for $x\ge\frac12$. Check that $-\int_0^1G\,\varphi''\,dx=\varphi\!\left(\frac12\right)$ for $\varphi(x)=\sin\pi x$.
step: The function $\sin\pi x$ vanishes at $0$ and $1$ (as does $G$), so no boundary terms appear in the integrations by parts. We have $\varphi''=-\pi^2\sin\pi x$.
step: Then $-\int_0^1G\varphi''\,dx=\pi^2\left[\int_0^{1/2}\frac x2\sin\pi x\,dx+\int_{1/2}^1\frac{1-x}{2}\sin\pi x\,dx\right]$, and the two integrals are equal by the symmetry $x\to1-x$.
step: By parts, $\int_0^{1/2}x\sin\pi x\,dx=\left[-\frac{x\cos\pi x}{\pi}+\frac{\sin\pi x}{\pi^2}\right]_0^{1/2}=\frac1{\pi^2}$. Each integral equals $\frac12\cdot\frac1{\pi^2}$.
step: The total is $\pi^2\cdot\frac1{\pi^2}=1$, and $\varphi\left(\frac12\right)=\sin\frac\pi2=1$. The identity holds for this test function. One test function is only a check; the general proof is the jump computation.

@mistakes
- Treating $\delta$ as a function with a value at $0$ (such as "$\delta(0)=\infty$") and multiplying or squaring it; only $\langle\delta,\varphi\rangle$ is defined.
- Forgetting the sign in $\langle T',\varphi\rangle=-\langle T,\varphi'\rangle$, which makes $\langle\delta',\varphi\rangle=-\varphi'(0)$, not $+\varphi'(0)$.
- Taking the classical derivative of a function with a jump and missing the delta term $[f]\,\delta_a$.
- Writing $|x|'=\delta$; the derivative of $|x|$ is $\operatorname{sgn}x$, and it is the second derivative that gives $2\delta$.

@practice self
prompt: Let $L=1$ and $G(x,s)=x(1-s)$ for $x\le s$, $G(x,s)=s(1-x)$ for $x\ge s$. (a) Write $G_x$ as a combination of Heaviside functions and differentiate it in the distributional sense to show that $-G_{xx}=\delta_s$ on $(0,1)$. (b) Check the boundary conditions and the continuity of $G$ at $x=s$. (c) Explain why this checks the Green function and what the representation $u(x)=\int G(x,s)f(s)\,ds$ then provides.
hint: Away from $x=s$ the slope of $G$ is $1-s$ on the left and $-s$ on the right, so $G_x=(1-s)H(s-x)-s\,H(x-s)$.
hint: Use $\frac{d}{dx}H(x-s)=\delta_s$ and $\frac{d}{dx}H(s-x)=-\delta_s$.
solution: (a) $G_x=(1-s)H(s-x)-s\,H(x-s)$ for $0<x<1$. Differentiating, $G_{xx}=-(1-s)\delta_s-s\,\delta_s=-\delta_s$ (the classical second derivative is $0$ away from $s$). So $-G_{xx}=\delta_s$. (b) $G(0,s)=0\cdot(1-s)=0$ and $G(1,s)=s\cdot0=0$; at $x=s$ both branches give $s(1-s)$, so $G$ is continuous. (c) The equation, the end conditions and continuity are exactly the defining properties of the Green function, with the jump $-1$ coming from the delta. Then $u(x)=\int_0^1G(x,s)f(s)\,ds$ solves $-u''=f$, $u(0)=u(1)=0$ for any reasonable load $f$, including loads with jumps or point masses.
rubric: Writes $G_x$ with the correct slopes $1-s$ and $-s$ and the correct Heaviside functions $H(s-x)$, $H(x-s)$.
rubric: Differentiates with $H'=\delta$ (and the sign from $H(s-x)$) to get $-\delta_s$, concluding $-G_{xx}=\delta_s$.
rubric: Verifies $G(0,s)=G(1,s)=0$ and the continuity at $x=s$, and links the result to the solution formula.

prompt: Compute $\langle\delta'',\varphi\rangle$ for the test function $\varphi(x)=e^{-x}\cos2x$.
answer: -3
check: nderiv(lambda x: exp(-x)*cos(2*x), 0, 2)
hint: By definition, $\langle\delta'',\varphi\rangle=\varphi''(0)$ (two sign changes).
hint: $\varphi'=-e^{-x}\left(\cos2x+2\sin2x\right)$.

@article
An **identity** is an equation that is true for every value of the variable for which both sides are defined. The equation $\sin^2\theta + \cos^2\theta = 1$ is an identity. The equation $\sin\theta = \frac{1}{2}$ is not: it is true only at certain angles, and finding them is the subject of the next lesson.

### The fundamental identities

All of these come from the unit circle, where $(\cos\theta, \sin\theta)$ is a point at distance $1$ from the origin.

- **Quotient and reciprocal:** $\tan\theta = \dfrac{\sin\theta}{\cos\theta}$, $\sec\theta = \dfrac{1}{\cos\theta}$, $\csc\theta = \dfrac{1}{\sin\theta}$, $\cot\theta = \dfrac{\cos\theta}{\sin\theta}$.
- **Pythagorean:** $\sin^2\theta + \cos^2\theta = 1$. Dividing by $\cos^2\theta$ gives $1 + \tan^2\theta = \sec^2\theta$; dividing by $\sin^2\theta$ gives $1 + \cot^2\theta = \csc^2\theta$.
- **Even and odd:** $\cos(-\theta) = \cos\theta$ and $\sin(-\theta) = -\sin\theta$.

### Sum, difference and double angle

Two points on the unit circle, at angles $a$ and $b$, are a distance apart that depends only on $a - b$. Computing that distance two ways (directly from the coordinates, and after rotating so one point sits at $(1, 0)$) gives the key formula

$$\cos(a - b) = \cos a\cos b + \sin a\sin b.$$

The rest follow by replacing $b$ with $-b$ and using $\sin\theta = \cos\left(\frac{\pi}{2} - \theta\right)$:

$$\sin(a \pm b) = \sin a\cos b \pm \cos a\sin b, \qquad \cos(a \pm b) = \cos a\cos b \mp \sin a\sin b.$$

Setting $b = a$ gives the **double-angle formulas**

$$\sin 2a = 2\sin a\cos a, \qquad \cos 2a = \cos^2 a - \sin^2 a = 2\cos^2 a - 1 = 1 - 2\sin^2 a.$$

Notice that $\sin(a + b)$ is **not** $\sin a + \sin b$. Try $a = b = \frac{\pi}{2}$: the left side is $\sin\pi = 0$ but the right side is $2$.

### How to prove an identity

A proof is a chain of equalities that begins on one side and ends on the other. Every link must be a fact you already trust. A reliable strategy:

1. Start with the more complicated side.
2. Rewrite everything in terms of $\sin$ and $\cos$.
3. Combine fractions over a common denominator, expand or factor, and use $\sin^2 + \cos^2 = 1$ to collapse terms.
4. Stop when you reach the other side.

**Avoid circular reasoning.** Do not treat the identity as an equation and do the same operation to both sides: that assumes the very statement you are trying to prove. If your claim were $1 = -1$, squaring both sides would "prove" it by producing $1 = 1$. Work on one side only, or reduce each side separately to the same expression.

Finally, an identity holds only where both sides are defined, so note any excluded values, such as angles where a denominator is zero.

@example
title: Proving an identity from one side
problem: Prove that $\tan x + \cot x = \sec x\csc x$ wherever both sides are defined.
step: Start with the left side and rewrite it in sines and cosines: $\tan x + \cot x = \dfrac{\sin x}{\cos x} + \dfrac{\cos x}{\sin x}$.
step: Use the common denominator $\sin x\cos x$: the sum is $\dfrac{\sin^2 x + \cos^2 x}{\sin x\cos x}$.
step: Apply the Pythagorean identity to the numerator: $\dfrac{1}{\sin x\cos x}$.
step: Split into reciprocals: $\dfrac{1}{\cos x}\cdot\dfrac{1}{\sin x} = \sec x\csc x$, the right side. Every step rewrote the same expression, and both sides are defined exactly when $\sin x \ne 0$ and $\cos x \ne 0$.

@example
title: An exact value from the sum formula
problem: Find the exact value of $\sin\frac{5\pi}{12}$.
step: Write the angle as a sum of standard angles: $\frac{5\pi}{12} = \frac{3\pi}{12} + \frac{2\pi}{12} = \frac{\pi}{4} + \frac{\pi}{6}$.
step: Apply $\sin(a + b) = \sin a\cos b + \cos a\sin b$: $\sin\frac{5\pi}{12} = \sin\frac{\pi}{4}\cos\frac{\pi}{6} + \cos\frac{\pi}{4}\sin\frac{\pi}{6}$.
step: Substitute the exact values: $\frac{\sqrt{2}}{2}\cdot\frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2}\cdot\frac{1}{2} = \frac{\sqrt{6}}{4} + \frac{\sqrt{2}}{4}$.
step: So $\sin\frac{5\pi}{12} = \frac{\sqrt{6} + \sqrt{2}}{4} \approx 0.966$. This is plausible, because $75^\circ$ is close to $90^\circ$, where sine is $1$.

@mistakes
- Treating an identity like an equation to solve: cross-multiplying or squaring both sides assumes what you want to prove.
- Distributing sine or cosine over a sum. In general $\sin(a + b) \ne \sin a + \sin b$ and $\cos 2a \ne 2\cos a$.
- Cancelling terms instead of factors, for example "cancelling" the $\cos x$ in $\dfrac{1 + \cos x}{\cos x}$.
- Forgetting the excluded values where a denominator vanishes.

@practice expr
prompt: Simplify $\sin x\,\sec x$ to a single trigonometric function.
vars: x
domain: x: 0.2..1.3
lead: $\sin x\,\sec x =$
answer: tan(x)
check: lambda x: sin(x)*(1/cos(x))
hint: Replace $\sec x$ by its reciprocal form.
hint: $\sin x\cdot\frac{1}{\cos x}$ is a quotient that has a name.
solution: $\sin x\sec x = \sin x\cdot\frac{1}{\cos x} = \frac{\sin x}{\cos x} = \tan x$.

@practice num
prompt: Use a difference formula to find the exact value of $\sin\frac{\pi}{12}$.
answer: (sqrt(6)-sqrt(2))/4
check: sin(pi/12)
hint: Write $\frac{\pi}{12}$ as a difference of standard angles, for example $\frac{\pi}{3} - \frac{\pi}{4}$.
hint: Use $\sin(a - b) = \sin a\cos b - \cos a\sin b$ with $a = \frac{\pi}{3}$ and $b = \frac{\pi}{4}$.
solution: $\sin\left(\frac{\pi}{3} - \frac{\pi}{4}\right) = \frac{\sqrt{3}}{2}\cdot\frac{\sqrt{2}}{2} - \frac{1}{2}\cdot\frac{\sqrt{2}}{2} = \frac{\sqrt{6} - \sqrt{2}}{4} \approx 0.259$.

@practice num
prompt: The angle $\theta$ is in Quadrant II and $\sin\theta = \frac{5}{13}$. Find $\sin 2\theta$.
answer: -120/169
check: sin(2*(pi - arcsin(5/13)))
hint: The double-angle formula is $\sin 2\theta = 2\sin\theta\cos\theta$. You need $\cos\theta$ first.
hint: Use $\cos^2\theta = 1 - \sin^2\theta$ and choose the sign that Quadrant II requires.
solution: $\cos^2\theta = 1 - \frac{25}{169} = \frac{144}{169}$, and cosine is negative in Quadrant II, so $\cos\theta = -\frac{12}{13}$. Then $\sin 2\theta = 2\cdot\frac{5}{13}\cdot\left(-\frac{12}{13}\right) = -\frac{120}{169}$.

prompt: Select every statement that is an identity (true for all values where both sides are defined).
choice*: $\cos 2x = 1 - 2\sin^2 x$
choice*: $1 + \tan^2 x = \sec^2 x$
choice: $\sin(a + b) = \sin a + \sin b$
choice: $\cos(a - b) = \cos a - \cos b$
hint: Test a suspicious statement with simple numbers, such as $a = b = \frac{\pi}{2}$ or $a = \frac{\pi}{2}$, $b = 0$.
hint: For the other two, start from $\cos 2x = \cos^2 x - \sin^2 x$ and from $\sin^2 x + \cos^2 x = 1$.
solution: Since $\cos 2x = \cos^2 x - \sin^2 x$ and $\cos^2 x = 1 - \sin^2 x$, we get $\cos 2x = 1 - 2\sin^2 x$. Dividing $\sin^2 x + \cos^2 x = 1$ by $\cos^2 x$ gives $\tan^2 x + 1 = \sec^2 x$. The other two fail: with $a = b = \frac{\pi}{2}$, $\sin(a + b) = 0$ but $\sin a + \sin b = 2$; with $a = \frac{\pi}{2}$ and $b = 0$, $\cos(a - b) = 0$ but $\cos a - \cos b = -1$.

@practice self
prompt: Prove the identity $\dfrac{\sin x}{1 + \cos x} + \dfrac{1 + \cos x}{\sin x} = 2\csc x$. Work on the left side only, and state which values of $x$ must be excluded.
hint: Combine the two fractions over the common denominator $\sin x\,(1 + \cos x)$.
hint: After expanding $(1 + \cos x)^2$, look for $\sin^2 x + \cos^2 x$ in the numerator, then factor and cancel a common factor.
solution: $\dfrac{\sin x}{1 + \cos x} + \dfrac{1 + \cos x}{\sin x} = \dfrac{\sin^2 x + (1 + \cos x)^2}{\sin x(1 + \cos x)} = \dfrac{\sin^2 x + 1 + 2\cos x + \cos^2 x}{\sin x(1 + \cos x)} = \dfrac{2 + 2\cos x}{\sin x(1 + \cos x)} = \dfrac{2(1 + \cos x)}{\sin x(1 + \cos x)} = \dfrac{2}{\sin x} = 2\csc x$. Both denominators must be non-zero. If $1 + \cos x = 0$ then $\cos x = -1$ and $\sin x = 0$, so the single condition is $\sin x \ne 0$, that is $x \ne k\pi$.
rubric: Works from the left side only and never applies an operation to both sides.
rubric: Combines over the correct common denominator $\sin x(1 + \cos x)$ and expands $(1 + \cos x)^2$ correctly.
rubric: Uses $\sin^2 x + \cos^2 x = 1$ and cancels the common factor $1 + \cos x$ (a factor, not a term).
rubric: Ends at $2\csc x$ and states the exclusion $x \ne k\pi$.

@quiz expr
prompt: Simplify $\cos^4 x - \sin^4 x$ to a single trigonometric function.
vars: x
lead: $\cos^4 x - \sin^4 x =$
answer: cos(2x)
check: lambda x: cos(x)**4 - sin(x)**4
hint: Factor as a difference of squares, with $a = \cos^2 x$ and $b = \sin^2 x$.
hint: One factor becomes $\sin^2 x + \cos^2 x$. The other is a double-angle expression.
solution: $\cos^4 x - \sin^4 x = (\cos^2 x - \sin^2 x)(\cos^2 x + \sin^2 x) = (\cos^2 x - \sin^2 x)\cdot 1 = \cos 2x$.

@quiz num
prompt: Find the exact value of $\cos\frac{7\pi}{12}$.
answer: (sqrt(2)-sqrt(6))/4
check: cos(7*pi/12)
hint: Write $\frac{7\pi}{12}$ as the sum $\frac{\pi}{3} + \frac{\pi}{4}$.
hint: Use $\cos(a + b) = \cos a\cos b - \sin a\sin b$. Note the minus sign.
solution: $\cos\left(\frac{\pi}{3} + \frac{\pi}{4}\right) = \frac{1}{2}\cdot\frac{\sqrt{2}}{2} - \frac{\sqrt{3}}{2}\cdot\frac{\sqrt{2}}{2} = \frac{\sqrt{2} - \sqrt{6}}{4} \approx -0.259$. It is negative because $105^\circ$ lies in Quadrant II.

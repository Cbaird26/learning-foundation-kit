@article
Some quantities need only a number: a mass of $3$ kg, a temperature of $20^\circ$C. These are **scalars**. Others need a direction as well: a displacement of $3$ km north-east, a force of $50$ N pulling up a slope. These are **vectors**: quantities with both a **magnitude** (size) and a **direction**.

### Arrows and components

Draw a vector as an arrow. Two arrows with the same length and direction are the same vector wherever they are drawn. To add $\mathbf{u} + \mathbf{v}$, place the tail of $\mathbf{v}$ at the tip of $\mathbf{u}$; the sum runs from the first tail to the last tip. Multiplying by a scalar $k$ stretches the arrow by the factor $|k|$ and reverses it if $k < 0$.

Pictures are slow, so we choose axes and describe a vector by its **components**, the horizontal and vertical steps from tail to tip:

$$\mathbf{v} = \langle v_x, v_y\rangle = v_x\,\mathbf{i} + v_y\,\mathbf{j}, \qquad \mathbf{i} = \langle 1, 0\rangle, \quad \mathbf{j} = \langle 0, 1\rangle.$$

The **magnitude** follows from the Pythagorean theorem: $|\mathbf{v}| = \sqrt{v_x^2 + v_y^2}$.

### Magnitude and direction

Let $\theta$ be the **direction angle**, measured counterclockwise from the positive $x$-axis. This is exactly last week's polar conversion, with $r = |\mathbf{v}|$:

$$v_x = |\mathbf{v}|\cos\theta, \qquad v_y = |\mathbf{v}|\sin\theta, \qquad \theta = \operatorname{atan2}(v_y, v_x).$$

As before, check the quadrant: $\arctan(v_y/v_x)$ alone cannot tell $\langle 1, 1\rangle$ from $\langle -1, -1\rangle$.

A **unit vector** has length $1$. Any non-zero vector gives one: $\hat{\mathbf{v}} = \mathbf{v}/|\mathbf{v}|$. The unit vector at angle $\theta$ is $\langle\cos\theta, \sin\theta\rangle$, the point on the unit circle.

### Arithmetic is componentwise

$$\langle a, b\rangle + \langle c, d\rangle = \langle a + c, b + d\rangle, \qquad k\langle a, b\rangle = \langle ka, kb\rangle.$$

It follows that $|k\mathbf{v}| = |k||\mathbf{v}|$. But in general $|\mathbf{u} + \mathbf{v}| \ne |\mathbf{u}| + |\mathbf{v}|$: **magnitudes do not add; components do.**

### Forces and resolving

Forces are vectors, and the net force on an object is the vector sum of all the forces acting on it. The reverse process is **resolving** a force into perpendicular components. A $50$ N force directed $30^\circ$ above the horizontal has $F_x = 50\cos 30^\circ \approx 43.3$ N and $F_y = 50\sin 30^\circ = 25$ N.

On a ramp inclined at angle $\varphi$ to the horizontal, an object's weight $mg$ resolves into a part $mg\sin\varphi$ along the slope and a part $mg\cos\varphi$ pressing into it. Draw the triangle to see where $\varphi$ reappears.

```python
import numpy as np
F1 = np.array([3.0, 4.0])
F2 = np.array([-1.0, 2.0])
R = F1 + F2
print(R, round(np.linalg.norm(R), 3))                 # [2. 6.] 6.325
print(round(np.degrees(np.arctan2(R[1], R[0])), 2))   # 71.57
```

@example
title: The resultant of two forces
problem: A force $\mathbf{F}_1$ of $10$ N acts at $30^\circ$ and a force $\mathbf{F}_2$ of $6$ N acts at $120^\circ$, both measured counterclockwise from the positive $x$-axis. Find the magnitude and direction of the resultant $\mathbf{R} = \mathbf{F}_1 + \mathbf{F}_2$.
step: Resolve each force: $\mathbf{F}_1 = \langle 10\cos 30^\circ, 10\sin 30^\circ\rangle = \langle 5\sqrt{3}, 5\rangle$ and $\mathbf{F}_2 = \langle 6\cos 120^\circ, 6\sin 120^\circ\rangle = \langle -3, 3\sqrt{3}\rangle$.
step: Add the components: $\mathbf{R} = \langle 5\sqrt{3} - 3,\ 5 + 3\sqrt{3}\rangle \approx \langle 5.66, 10.20\rangle$.
step: The magnitude is $|\mathbf{R}|^2 = (84 - 30\sqrt{3}) + (52 + 30\sqrt{3}) = 136$, so $|\mathbf{R}| = \sqrt{136} \approx 11.66$ N.
step: The direction is $\theta = \operatorname{atan2}(10.20, 5.66) \approx 61.0^\circ$. Check: the forces are $90^\circ$ apart, so $|\mathbf{R}|^2 = 10^2 + 6^2 = 136$, which agrees.

@example
title: Magnitude, unit vector and direction
problem: For $\mathbf{v} = \langle -3, 4\rangle$, find $|\mathbf{v}|$, the unit vector $\hat{\mathbf{v}}$ and the direction angle.
step: The magnitude is $|\mathbf{v}| = \sqrt{9 + 16} = 5$.
step: The unit vector is $\hat{\mathbf{v}} = \frac{1}{5}\langle -3, 4\rangle = \langle -\frac{3}{5}, \frac{4}{5}\rangle$.
step: Since $\cos\theta = -\frac{3}{5} < 0$ and $\sin\theta = \frac{4}{5} > 0$, the angle is in Quadrant II. The reference angle is $\arctan\frac{4}{3} \approx 53.13^\circ$, so $\theta \approx 180^\circ - 53.13^\circ = 126.87^\circ$. Note that $\arctan\left(\frac{4}{-3}\right) \approx -53.13^\circ$ would be the wrong quadrant.
step: Check: $5\cos 126.87^\circ \approx -3$ and $5\sin 126.87^\circ \approx 4$.

@mistakes
- Adding magnitudes instead of components. $|\mathbf{u} + \mathbf{v}| = |\mathbf{u}| + |\mathbf{v}|$ only when the vectors point the same way.
- Computing the direction as $\arctan(v_y/v_x)$ without checking the quadrant.
- Swapping sine and cosine when resolving. The component along the axis from which the angle is measured uses the cosine.
- Treating a vector as tied to a position. Equal arrows drawn anywhere are the same vector.

prompt: A vector has magnitude $8$ and direction angle $150^\circ$. Find its components $\langle v_x, v_y\rangle$ in exact form.
answer: (-4sqrt(3), 4)
check: (8*cos(math.radians(150)), 8*sin(math.radians(150)))
hint: Use $v_x = |\mathbf{v}|\cos\theta$ and $v_y = |\mathbf{v}|\sin\theta$.
hint: $150^\circ$ is in Quadrant II with reference angle $30^\circ$: cosine is negative and sine is positive.
solution: $v_x = 8\cos 150^\circ = 8\left(-\frac{\sqrt{3}}{2}\right) = -4\sqrt{3}$ and $v_y = 8\sin 150^\circ = 8\cdot\frac{1}{2} = 4$.

answer: sqrt(277)

solution: The resultant is $\langle 12 + 3.5,\ \frac{7\sqrt{3}}{2}\rangle$, so $|\mathbf{R}|^2 = 15.5^2 + \frac{147}{4} = 240.25 + 36.75 = 277$ and $|\mathbf{R}| = \sqrt{277} \approx 16.64$ N.

@quiz ms

choice: $0$
choice*: $2$
choice*: $5$
choice: $8$
hint: When is the sum longest, and when is it shortest?
hint: The sum is longest when the vectors point the same way and shortest when they point in opposite directions. Everything in between is possible.
solution: The length of the sum ranges from $|3 - 4| = 1$ (opposite directions) to $3 + 4 = 7$ (same direction), and every value between occurs. So $2$ and $5$ are possible; $0$ would need equal lengths, and $8$ exceeds $7$.

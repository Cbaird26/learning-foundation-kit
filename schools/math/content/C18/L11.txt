@article
Walk straight ahead on a surface, never steering. You follow a geodesic. In a plane that is a straight line; on a sphere it is a great circle, the path a plane flight tries to follow. Even though you never steer, your acceleration in space is not zero: it points straight into or out of the surface, and the surface alone supplies it. That is the definition.

### Geodesics

**Definition.** A smooth curve $\alpha\colon I \to S$ is a **geodesic** if $\alpha''(t)$ is perpendicular to $T_{\alpha(t)}S$ for every $t$. Equivalently, $\alpha''$ is parallel to the unit normal $N$.

**Proposition 1.** A geodesic has constant speed.

*Proof.* $\frac{d}{dt}|\alpha'|^2 = 2\langle\alpha'', \alpha'\rangle = 0$ because $\alpha' \in T_{\alpha(t)}S$ and $\alpha'' \perp T_{\alpha(t)}S$. $\blacksquare$

**Proposition 2 (geodesic equations).** Let $x$ be a regular chart and $\alpha(t) = x(u(t), v(t))$. Then $\alpha$ is a geodesic if and only if
$$u'' + \Gamma^1_{11}u'^2 + 2\Gamma^1_{12}u'v' + \Gamma^1_{22}v'^2 = 0,\qquad v'' + \Gamma^2_{11}u'^2 + 2\Gamma^2_{12}u'v' + \Gamma^2_{22}v'^2 = 0.$$

*Proof.* From $\alpha' = u'x_u + v'x_v$ we get $\alpha'' = u''x_u + v''x_v + u'^2x_{uu} + 2u'v'x_{uv} + v'^2x_{vv}$. Substitute the expansions $x_{ij} = \Gamma^1_{ij}x_u + \Gamma^2_{ij}x_v + (\ldots)N$ from Week 9. The coefficient of $x_u$ is the left side of the first equation and the coefficient of $x_v$ is the left side of the second; the rest is a multiple of $N$. Since $x_u, x_v, N$ is a basis, $\alpha''$ is parallel to $N$ if and only if both coefficients vanish. $\blacksquare$

The equations are a system of second-order ordinary differential equations with smooth coefficients (Christoffel symbols are built from $E, F, G$ and derivatives). By the existence and uniqueness theorem for ordinary differential equations (Picard–Lindelöf, applicable since the coefficients are smooth and hence locally Lipschitz), for each point $p$ and tangent vector $w$ there is a unique geodesic with $\alpha(0) = p$ and $\alpha'(0) = w$ on a maximal interval around $0$.

### Examples

*The plane.* All Christoffel symbols of $x(u, v) = (u, v, 0)$ vanish, so $u'' = v'' = 0$: straight lines.

*The sphere.* Take the sphere of radius $r$ centered at the origin, with unit normal $N = \alpha/r$. A curve $\alpha$ on it is a geodesic if and only if $\alpha'' = \lambda\alpha$ for a function $\lambda$. Then $(\alpha\times\alpha')' = \alpha'\times\alpha' + \alpha\times\alpha'' = \lambda\,\alpha\times\alpha = 0$, so $c = \alpha\times\alpha'$ is a constant vector. With constant speed $s_0 > 0$, $|c| = r s_0 \ne 0$ because $\alpha\perp\alpha'$. Since $\langle\alpha, c\rangle = 0$, $\alpha$ lies in the plane through the origin perpendicular to $c$, and so on a **great circle**. Conversely a parametrized great circle $\alpha(t) = r(\cos(t/r)\,a + \sin(t/r)\,b)$ with $a, b$ orthonormal satisfies $\alpha'' = -\alpha/r^2$, parallel to $N$. Geodesics of the sphere are exactly the great circles, traversed at constant speed.

*The cylinder.* A local isometry preserves geodesics (the equations only involve $E, F, G$), and the cylinder is locally isometric to the plane. Straight lines in the unrolled strip become circles (horizontal), vertical lines and helices.

### Surfaces of revolution and Clairaut's relation

Let $x(u, v) = (\rho(u)\cos v, \rho(u)\sin v, z(u))$ with $E = \rho'^2 + z'^2$ (which depends on $u$ only), $F = 0$ and $G = \rho^2$. The nonzero Christoffel symbols are
$$\Gamma^1_{11} = \frac{E_u}{2E},\qquad \Gamma^2_{12} = \frac{\rho'}{\rho},\qquad \Gamma^1_{22} = -\frac{\rho\rho'}{E},$$
and the geodesic equations read
$$u'' + \frac{E_u}{2E}u'^2 - \frac{\rho\rho'}{E}v'^2 = 0,\qquad v'' + \frac{2\rho'}{\rho}u'v' = 0.$$

**Theorem (Clairaut's relation).** Along a geodesic of a surface of revolution, $\rho^2v'$ is constant. For a unit-speed geodesic making an angle $\psi$ with the parallel through the point, this says $\rho\cos\psi = $ constant.

*Proof.* $(\rho^2v')' = 2\rho\rho'u'v' + \rho^2v'' = \rho^2\left(v'' + \frac{2\rho'}{\rho}u'v'\right) = 0$ by the second equation. For a unit-speed curve $\langle\alpha', x_v\rangle = \rho^2v'$, and also $\langle\alpha', x_v\rangle = |\alpha'||x_v|\cos\psi = \rho\cos\psi$ since $x_v$ has length $\rho$ and points along the parallel. $\blacksquare$

*Consequences.* Meridians ($v$ constant, $u$ proportional to arc length) are geodesics. A parallel $u = u_0$ is a geodesic if and only if $\rho'(u_0) = 0$, because the first equation then reduces to $-\rho\rho'v'^2/E = 0$.

### Integrating the equations numerically

The simplest scheme is the explicit Euler method on the state $(u, v, u', v')$.

```python
def geodesic_euler(acc, state, h, n):
    """Explicit Euler for geodesics; acc(u, v, du, dv) -> (ddu, ddv)."""
    u, v, du, dv = state
    for _ in range(n):
        a, b = acc(u, v, du, dv)
        u, v, du, dv = u + h * du, v + h * dv, du + h * a, dv + h * b
    return u, v, du, dv


# plane in polar coordinates: E = 1, G = u^2, so u'' = u v'^2, v'' = -2 u' v'/u
polar = lambda u, v, du, dv: (u * dv * dv, -2 * du * dv / u)
u, v, du, dv = geodesic_euler(polar, (1.0, 0.0, 0.0, 1.0), 0.001, 1000)
print(round(u, 2), round(v, 2))
```

This starts at the point $(1, 0)$ moving tangentially to the circle of radius $1$, that is along the line $x = 1$, and after parameter value $1$ prints `1.41 0.79`, close to the exact point $(\sqrt2, \pi/4)$ in polar coordinates. Euler's method has error proportional to the step $h$, so this agreement is evidence, not proof; better schemes (Runge–Kutta) are the next step.

@example
title: Which parallels of a sphere are geodesics?
problem: On the unit sphere with chart $x(\varphi, \theta) = (\sin\varphi\cos\theta, \sin\varphi\sin\theta, \cos\varphi)$, decide which parallels $\varphi = \varphi_0$ are geodesics.
step: This is a surface of revolution with $u = \varphi$, $v = \theta$, $\rho = \sin\varphi$, and $E = 1$.
step: A parallel is a geodesic if and only if $\rho'(\varphi_0) = 0$ (see the consequences above).
step: $\rho' = \cos\varphi$ vanishes only for $\varphi_0 = \pi/2$, the equator.
step: Check with the great-circle description: only the equator is a great circle among the parallels, the others are circles in planes not through the center.
answer: Only the equator $\varphi_0 = \pi/2$ is a geodesic.

@example
title: Clairaut's relation on the unit sphere
problem: A unit-speed geodesic on the unit sphere crosses the equator at an angle $30^\circ$ to the equator. How far north does it go?
step: The unit sphere is a surface of revolution with $\rho = \sin\varphi$, and at the equator $\rho = 1$.
step: Clairaut: $\rho\cos\psi = 1\cdot\cos 30^\circ = \sqrt3/2$ along the geodesic.
step: The geodesic is tangent to a parallel ($\psi = 0$) when $\rho = \sqrt3/2$, so $\sin\varphi = \sqrt3/2$ and $\varphi = \pi/3$.
step: The colatitude $\pi/3$ corresponds to latitude $90^\circ - 60^\circ = 30^\circ$, which matches the great circle inclined at $30^\circ$ to the equator.
answer: The geodesic reaches latitude $30^\circ$ (colatitude $\varphi = \pi/3$).

@mistakes
- Thinking a geodesic has zero acceleration: only the tangential part of $\alpha''$ vanishes; on a sphere the acceleration $-\alpha/r^2$ points toward the center.
- Believing a geodesic is always the shortest path between its endpoints: a great circle arc longer than half the circle is not shortest. Geodesics are locally shortest (a fact we do not prove).
- Dropping the parametrization: a curve like $t \mapsto \alpha(t^2)$ traces a geodesic but is not itself a geodesic because its speed is not constant.
- Forgetting that the geodesic equations involve the velocity: the second-order system needs both the starting point and the starting velocity.

```python
def christoffel(E, F, G, Eu, Ev, Fu, Fv, Gu, Gv):
    """Christoffel symbols ((G111, G112, G122), (G211, G212, G222))."""
    det = E * G - F * F
    rhs = [(0.5 * Eu, Fu - 0.5 * Ev),
           (0.5 * Ev, 0.5 * Gu),
           (Fv - 0.5 * Gu, 0.5 * Gv)]
    first, second = [], []
    for a, b in rhs:
        first.append((G * a - F * b) / det)
        second.append((-F * a + E * b) / det)
    return tuple(first), tuple(second)
```
hint: Each pair $(a, b)$ on the right solves $\begin{pmatrix}E & F\\F & G\end{pmatrix}\begin{pmatrix}\Gamma^1\\\Gamma^2\end{pmatrix} = \begin{pmatrix}a\\b\end{pmatrix}$.
hint: The inverse of a $2\times2$ matrix with determinant $D = EG - F^2$ is $\frac1D\begin{pmatrix}G & -F\\-F & E\end{pmatrix}$.
solution: For each index pair $(ij)$ form the two dot products $\langle x_{ij}, x_u\rangle$ and $\langle x_{ij}, x_v\rangle$ from derivatives of $E, F, G$, then multiply by the inverse matrix of the first fundamental form. A version that assumes $F = 0$ passes the polar and sphere tests but fails the last test with $F \ne 0$; the surface in that test is $x = (u + v, u - v, uv)$ at $(u, v) = (0.4, 0.9)$.

model:
```python
import math


def sphere_geodesic(state, length, n):
    """Geodesic on the unit sphere by RK4 in (phi, theta) coordinates."""
    def rhs(s):
        p, t, dp, dt = s
        return (dp, dt,
                math.sin(p) * math.cos(p) * dt * dt,
                -2.0 * math.cos(p) / math.sin(p) * dp * dt)

    def shift(s, k, c):
        return [a + c * b for a, b in zip(s, k)]

    h = length / n
    s = list(state)
    for _ in range(n):
        k1 = rhs(s)
        k2 = rhs(shift(s, k1, h / 2))
        k3 = rhs(shift(s, k2, h / 2))
        k4 = rhs(shift(s, k3, h))
        s = [a + h / 6 * (p + 2 * q + 2 * r + w)
             for a, p, q, r, w in zip(s, k1, k2, k3, k4)]
    return tuple(s)
```
hint: Write a function `rhs` that returns $(\varphi', \theta', \varphi'', \theta'')$ for the current state, then apply the four Runge–Kutta stages to the whole 4-vector.
hint: The step size is $h = L/n$ and the four stages use the states $s$, $s + \tfrac h2k_1$, $s + \tfrac h2k_2$ and $s + hk_3$.
solution: The state $(\varphi, \theta, \varphi', \theta')$ satisfies a first-order system whose right side is $(\varphi', \theta', \sin\varphi\cos\varphi\,\theta'^2, -2\cot\varphi\,\varphi'\theta')$. A Runge–Kutta step combines four evaluations with weights $1, 2, 2, 1$. Along a geodesic the speed squared $\varphi'^2 + \sin^2\varphi\,\theta'^2$ is constant (Proposition 1), which the test uses as a check on accuracy; the first-order Euler method with the same $n$ misses the antipode by more than $10^{-4}$, far outside the tolerance of the tests.

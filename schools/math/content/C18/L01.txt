@article
An odometer measures how far a car has driven, not how fast the speedometer needle moved. Two cars can trace the same road at different speeds and still agree on the distance. This week makes that idea precise: the length of a curve should depend on the path in space and not on how we happen to run along it.

### Curves, velocity and speed

A **smooth parametrized curve** is a map $\alpha\colon I \to \mathbb{R}^3$ from an interval $I \subseteq \mathbb{R}$ whose coordinate functions have derivatives of all orders. Its **velocity** is $\alpha'(t)$ and its **speed** is $|\alpha'(t)|$. The curve is **regular** if $\alpha'(t) \ne 0$ for every $t \in I$. Regularity is a property of the parametrization, not of the image set: $\alpha(t) = (t^3, t^3, 0)$ traces the straight line $y = x$ but has $\alpha'(0) = 0$, so it is not regular, while $(t, t, 0)$ traces the same line and is regular. Likewise $(t^3, t^2)$ has a cusp at the origin, where its velocity vanishes.

For example, the circular helix $\alpha(t) = (3\cos t,\, 3\sin t,\, 4t)$ has $\alpha'(t) = (-3\sin t,\, 3\cos t,\, 4)$ and speed $\sqrt{9 + 16} = 5$ for every $t$. It is regular, and it moves at constant speed.

### Arc length

**Definition.** The **length** of a smooth curve $\alpha\colon [a, b] \to \mathbb{R}^3$ is $L(\alpha) = \int_a^b |\alpha'(t)|\,dt$. The **arc length function** of a regular curve, measured from $t_0 \in I$, is $s(t) = \int_{t_0}^{t} |\alpha'(u)|\,du$.

The helix over $[0, 2\pi]$ has length $\int_0^{2\pi} 5\,dt = 10\pi$.

This definition agrees with the idea of adding up the lengths of short chords: the length of the inscribed polygon with vertices $\alpha(t_0), \alpha(t_1), \dots, \alpha(t_n)$ tends to the integral as the mesh of the partition tends to $0$. We use that fact as motivation and do not prove it here.

**Theorem 1 (invariance of length).** Let $\alpha\colon [a, b] \to \mathbb{R}^3$ be smooth and let $\varphi\colon [c, d] \to [a, b]$ be a smooth bijection with $\varphi' \ne 0$ everywhere. Then $\beta = \alpha \circ \varphi$ has the same length as $\alpha$.

*Proof.* A smooth bijection with nonvanishing derivative is strictly monotone, so $\varphi' > 0$ throughout or $\varphi' < 0$ throughout. By the chain rule $\beta'(u) = \alpha'(\varphi(u))\,\varphi'(u)$, so $|\beta'(u)| = |\alpha'(\varphi(u))|\,|\varphi'(u)|$. If $\varphi' > 0$, then $\varphi(c) = a$, $\varphi(d) = b$, and the substitution $t = \varphi(u)$ gives $\int_c^d |\alpha'(\varphi(u))|\,\varphi'(u)\,du = \int_a^b |\alpha'(t)|\,dt$. If $\varphi' < 0$, then $\varphi(c) = b$, $\varphi(d) = a$, $|\varphi'| = -\varphi'$, and the substitution gives $-\int_b^a |\alpha'(t)|\,dt = \int_a^b |\alpha'(t)|\,dt$. $\blacksquare$

### The arc length parametrization

A curve is **unit speed** (or parametrized by arc length) if $|\beta'| = 1$ everywhere. Then $s(t) = t - t_0$: the parameter itself is the distance traveled.

**Theorem 2.** Let $\alpha\colon I \to \mathbb{R}^3$ be a regular smooth curve, $t_0 \in I$ and $s(t) = \int_{t_0}^{t} |\alpha'|$. Then $s$ is a smooth bijection from $I$ onto an open interval $J$, its inverse $t\colon J \to I$ is smooth, and $\beta = \alpha \circ t$ is a smooth unit-speed curve with the same image as $\alpha$.

*Proof.* Since $\alpha' \ne 0$, the function $|\alpha'| = \sqrt{\alpha_1'^2 + \alpha_2'^2 + \alpha_3'^2}$ is the square root of a positive smooth function, hence smooth and positive. By the fundamental theorem of calculus $s'(t) = |\alpha'(t)| > 0$, so $s$ is smooth and strictly increasing, hence a bijection onto an interval $J$, which is open when $I$ is open (for a closed $I$ the same argument works with endpoints included). The inverse function theorem in one variable says $t(s)$ is smooth with $t'(s) = 1/s'(t(s))$. By the chain rule $\beta'(s) = \alpha'(t(s))\,t'(s) = \alpha'(t(s))/|\alpha'(t(s))|$, a vector of length $1$. $\blacksquare$

Regularity is essential: for $\alpha(t) = (t^3, t^3, 0)$ the speed is $3\sqrt{2}\,t^2$ and $s(t) = \sqrt{2}\,t^3$ is smooth and bijective, but its inverse $t = (s/\sqrt{2})^{1/3}$ is not differentiable at $s = 0$.

### Measuring length on a computer

The inscribed-polygon idea gives a program that works for any curve you can evaluate.

```python
import math


def polyline_length(f, a, b, n):
    """Length of the inscribed polygon with n equal parameter steps."""
    pts = [f(a + (b - a) * i / n) for i in range(n + 1)]
    return sum(math.dist(p, q) for p, q in zip(pts, pts[1:]))


helix = lambda t: (3 * math.cos(t), 3 * math.sin(t), 4 * t)
for n in (4, 16, 64):
    print(n, polyline_length(helix, 0, 2 * math.pi, n))
```

The three lengths for $n = 4, 16, 64$ are about $30.33$, $31.34$ and $31.41$. They increase toward $10\pi \approx 31.4159$, and each is a lower bound because a straight chord is the shortest path between its endpoints. Seeing the numbers approach $10\pi$ is evidence for the formula, not a proof of it.

@example
title: Length of a cycloid arch and where regularity fails
problem: The cycloid is $\alpha(t) = (t - \sin t,\, 1 - \cos t)$. Find its length over $[0, 2\pi]$, and find the parameter values where it is not regular.
step: Differentiate: $\alpha'(t) = (1 - \cos t,\ \sin t)$.
step: Compute the squared speed: $(1 - \cos t)^2 + \sin^2 t = 2 - 2\cos t = 4\sin^2(t/2)$, so the speed is $2\,|\sin(t/2)|$.
step: On $[0, 2\pi]$ we have $t/2 \in [0, \pi]$, so $\sin(t/2) \ge 0$ and the speed is $2\sin(t/2)$.
step: Integrate: $L = \int_0^{2\pi} 2\sin(t/2)\,dt = \left[-4\cos(t/2)\right]_0^{2\pi} = 4 + 4 = 8$.
step: The speed is zero exactly when $\sin(t/2) = 0$, that is at $t = 2\pi k$ for integers $k$. At these cusps the curve touches the line $y = 0$ and is not regular, although the length integral still makes sense.
answer: The length is $8$; the curve is not regular at $t = 2\pi k$, $k \in \mathbb{Z}$.

@example
title: A unit-speed reparametrization
problem: Reparametrize $\alpha(t) = (t, \cosh t)$, $t \in \mathbb{R}$, by arc length measured from $t_0 = 0$.
step: Differentiate: $\alpha'(t) = (1, \sinh t)$, which is never zero, so $\alpha$ is regular.
step: The speed is $\sqrt{1 + \sinh^2 t} = \cosh t$ because $\cosh^2 t - \sinh^2 t = 1$ and $\cosh t > 0$.
step: Integrate: $s(t) = \int_0^t \cosh u\,du = \sinh t$.
step: Invert: $t(s) = \operatorname{arcsinh} s$, and $\cosh(\operatorname{arcsinh} s) = \sqrt{1 + s^2}$, so $\beta(s) = (\operatorname{arcsinh} s,\ \sqrt{1 + s^2})$.
step: Check the unit speed: $\beta'(s) = \left(\frac{1}{\sqrt{1+s^2}},\ \frac{s}{\sqrt{1+s^2}}\right)$ has squared length $\frac{1 + s^2}{1 + s^2} = 1$.
answer: $\beta(s) = (\operatorname{arcsinh} s,\ \sqrt{1 + s^2})$ for $s \in \mathbb{R}$.

@mistakes
- Calling a curve regular because its image looks smooth: regularity is about $\alpha'(t) \ne 0$ for the parametrization you are given, and $(t^3, t^3)$ fails it on a straight line.
- Integrating the velocity instead of the speed: $\int \alpha'\,dt$ is the displacement $\alpha(b) - \alpha(a)$, while the length integrates $|\alpha'|$ and is never smaller than $|\alpha(b) - \alpha(a)|$.
- Dropping the square root, or the absolute value after it: $\sqrt{4\sin^2(t/2)} = 2|\sin(t/2)|$, which equals $2\sin(t/2)$ only where $\sin(t/2) \ge 0$.
- Reading a table of polygon lengths as proof: the values approach the integral, but only the theorem tells you the limit is exactly that.

prompt: Let $f\colon [a, b] \to \mathbb{R}$ be smooth and let $\alpha(x) = (x, f(x))$ be its graph. Prove that the length of $\alpha$ is $\int_a^b \sqrt{1 + f'(x)^2}\,dx$ and that it is at least $b - a$, with equality if and only if $f' \equiv 0$.

Since $f'(x)^2 \ge 0$, the integrand is at least $1$, so the length is at least $\int_a^b 1\,dx = b - a$. The function $g(x) = \sqrt{1 + f'(x)^2} - 1$ is continuous and nonnegative. If its integral is $0$, then $g \equiv 0$, because a continuous nonnegative function with positive value at one point is positive on an interval and has positive integral. Then $f'(x)^2 = 0$ everywhere. Conversely, $f' \equiv 0$ gives integrand $1$ and length $b - a$.

model:
```python
import math


def polygon(f, a, b, n):
    pts = [f(a + (b - a) * i / n) for i in range(n + 1)]
    return sum(math.dist(p, q) for p, q in zip(pts, pts[1:]))


def length_tol(f, a, b, tol):
    """Doubling polygon length until two successive values agree."""
    n = 1
    old = polygon(f, a, b, n)
    while True:
        new = polygon(f, a, b, 2 * n)
        if abs(new - old) < tol:
            return new
        n *= 2
        old = new
```
hint: Keep the previous polygon length in a variable and compare it with the new one after doubling.
hint: Return the newer (finer) value, not the older one, when the difference falls below `tol`.
solution: Compute the length for $n$, then for $2n$; if they differ by less than `tol`, return the second; otherwise replace $n$ by $2n$ and repeat. The stopping rule is a heuristic: it measures how much the answer moved, not the true error. Inscribed polygons never exceed the curve length, and for a smooth curve the remaining error after the last doubling is typically about a third of the last increment.

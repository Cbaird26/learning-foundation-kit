@article
Last week the work done by a field depended on the path. For some fields it does not. Those fields are called conservative, and they make line integrals easy.

### Potentials and the endpoint rule

A field $\mathbf F$ is **conservative** on a domain if $\mathbf F=\nabla f$ for some scalar function $f$, called a **potential**. For such a field, the chain rule from Week 3 gives $\frac{d}{dt}f(\mathbf r(t))=\nabla f\cdot\mathbf r'(t)$, so integrating along any path from $A$ to $B$ gives

$$\int_C\nabla f\cdot d\mathbf r=f(B)-f(A) .$$

Only the endpoints matter. In particular every closed loop gives $\oint_C\mathbf F\cdot d\mathbf r=0$. The reverse is also true: if all closed loops in a connected domain give zero, the line integral is **path independent** and the field is conservative.

### The curl test

If $\mathbf F=\nabla f$ with continuous second derivatives, mixed partials are equal (Week 2), so in the plane $P_y=Q_x$, and in space $\nabla\times\mathbf F=\mathbf 0$. So a field with nonzero curl is **not** conservative.

The converse needs care. If the domain is **simply connected**, which means it is connected and every loop can be shrunk to a point inside the domain (a disk, a half-plane, all of space), then zero curl does imply conservative. If the domain has a hole that loops can wind around, such as a plane region missing a point or a region of space missing a whole line, zero curl is not enough. (Removing a single point from space does not cause this problem.)

### The field with a hole

The field $\mathbf G=\dfrac{\langle -y,\ x\rangle}{x^2+y^2}$ is defined away from the origin and has $\nabla\times\mathbf G=0$ there. But its circulation around the unit circle is $2\pi$, not $0$, so it is not conservative on the punctured plane. On the half-plane $x>0$, which is simply connected, it is conservative, with potential $f=\arctan(y/x)$, the polar angle. Going all the way around the origin returns the angle to its start plus $2\pi$, so no single-valued potential exists on the punctured plane.

### Finding a potential

Suppose $\mathbf F=\langle P,Q\rangle$ passes the curl test. Then:

1. Integrate $P$ with respect to $x$: $f=\int P\,dx+g(y)$. The "constant" may depend on $y$.
2. Differentiate with respect to $y$ and match $Q$ to find $g'(y)$, then integrate.
3. In three variables repeat once more, matching $R$.

Always check the result by computing $\nabla f$.

@example
title: Potential and endpoint value in space
problem: Show that $\mathbf F=\langle 2xy+z^2,\ x^2+z,\ y+2xz\rangle$ is conservative on $\mathbb R^3$, find a potential, and evaluate $\int_C\mathbf F\cdot d\mathbf r$ for any path from $(0,0,0)$ to $(1,2,3)$.
step: Curl test: $R_y=1=Q_z$, $P_z=2z=R_x$ and $Q_x=2x=P_y$. So $\nabla\times\mathbf F=\mathbf 0$, and all of $\mathbb R^3$ is simply connected, so $\mathbf F$ is conservative.
step: Integrate $P$ in $x$: $f=x^2y+xz^2+g(y,z)$.
step: Match $Q$: $f_y=x^2+g_y=x^2+z$, so $g_y=z$ and $g=yz+h(z)$.
step: Match $R$: $f_z=2xz+y+h'(z)=y+2xz$, so $h'=0$. A potential is $f=x^2y+xz^2+yz$.
step: By the endpoint rule the integral is $f(1,2,3)-f(0,0,0)=2+9+6-0=17$, whatever the path.

@example
title: Domain matters for zero curl
problem: Is $\mathbf G=\dfrac{\langle -y,\ x\rangle}{x^2+y^2}$ conservative on the punctured plane $\mathbb R^2\setminus\{(0,0)\}$?
step: With $P=-y/(x^2+y^2)$ and $Q=x/(x^2+y^2)$ we get $Q_x=\dfrac{y^2-x^2}{(x^2+y^2)^2}=P_y$. So the curl test passes everywhere on the domain.
step: Test a loop: on the unit circle $\mathbf r(t)=\langle\cos t,\sin t\rangle$ we have $\mathbf G=\langle-\sin t,\cos t\rangle=\mathbf r'(t)$, so $\mathbf G\cdot\mathbf r'=1$.
step: The circulation is $\oint\mathbf G\cdot d\mathbf r=\int_0^{2\pi}1\,dt=2\pi\neq0$.
step: A nonzero circulation means $\mathbf G$ is not conservative on the punctured plane. The curl test could not detect this because the domain has a hole. On any simply connected subdomain, such as $x>0$, the field is conservative.

@mistakes
- Concluding that a field is conservative from $\nabla\times\mathbf F=\mathbf 0$ without checking that the domain has no holes.
- Writing $+C$ instead of $+g(y)$ after integrating $P$ with respect to $x$. The missing term may depend on the other variables.
- Reversing the endpoint rule: the answer is $f(\text{end})-f(\text{start})$.
- Using a potential on a path that leaves the domain where the potential is defined, for example one that passes through a hole.

answer: pi

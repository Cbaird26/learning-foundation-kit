@article
A Riemann integral cuts the domain into small intervals; the Lebesgue integral cuts the range, and for that we need the sets $\{x : a < f(x) \le b\}$ to have a size. Measurability of $f$ is exactly the statement that every such set does.

**Definition.** Let $(X, \mathcal{A})$ be a measurable space. A function $f\colon X \to [-\infty, \infty]$ is **measurable** if $\{f > a\} = \{x : f(x) > a\} \in \mathcal{A}$ for every $a \in \mathbb{R}$.

**Equivalent forms.** Since $\{f \ge a\} = \bigcap_n \{f > a - 1/n\}$, $\{f \le a\}$ is the complement of $\{f > a\}$, and $\{f < a\}$ the complement of $\{f \ge a\}$, any one of the four families of sets being in $\mathcal{A}$ for all real $a$ gives the others; it is enough to test rational $a$. For real-valued $f$ the condition is equivalent to $f^{-1}(U) \in \mathcal{A}$ for every open $U$, hence for every Borel set: open sets are countable unions of open intervals, and $f^{-1}$ commutes with unions and complements, so the sets $B$ with $f^{-1}(B) \in \mathcal{A}$ form a σ-algebra containing the intervals.

**Theorem 1 (closure properties).** Let $f, g, f_n\colon X \to [-\infty, \infty]$ be measurable.
(a) $\sup_n f_n$, $\inf_n f_n$, $\limsup_n f_n$, $\liminf_n f_n$ are measurable; so the pointwise limit, if it exists everywhere, is measurable.
(b) If $f, g$ are real-valued then $f + g$ and $fg$ are measurable.
(c) If $h\colon \mathbb{R} \to \mathbb{R}$ is Borel (in particular continuous) and $f$ is real-valued, then $h \circ f$ is measurable.

*Proof.* (a) $\{\sup f_n > a\} = \bigcup_n \{f_n > a\}$, and $\inf f_n = -\sup(-f_n)$. Then $\limsup f_n = \inf_N \sup_{n \ge N} f_n$ and $\liminf f_n = -\limsup(-f_n)$. (b) $\{f + g > a\} = \bigcup_{r \in \mathbb{Q}} (\{f > r\} \cap \{g > a - r\})$: if $f(x) + g(x) > a$ pick a rational $r$ with $f(x) > r > a - g(x)$; the reverse inclusion is clear. For products, $f^2$ is measurable because $\{f^2 > a\} = \{f > \sqrt{a}\} \cup \{f < -\sqrt{a}\}$ for $a \ge 0$ (and is $X$ for $a < 0$), and $fg = \frac{1}{4}\left((f+g)^2 - (f-g)^2\right)$. (c) $(h \circ f)^{-1}(U) = f^{-1}(h^{-1}(U))$, and $h^{-1}(U)$ is Borel. $\blacksquare$

### Simple functions and approximation

A **simple function** is a measurable function taking finitely many real values; it can be written $s = \sum_{i=1}^m a_i \mathbf{1}_{A_i}$ with distinct values $a_i$ and measurable level sets $A_i = \{s = a_i\}$ (the **canonical form**).

**Theorem 2 (approximation by simple functions).** Let $f\colon X \to [0, \infty]$ be measurable. Define $s_n = \min\left(n, \; 2^{-n} \lfloor 2^n f \rfloor\right)$ (with $s_n = n$ where $f = \infty$). Then each $s_n$ is simple, $0 \le s_1 \le s_2 \le \cdots \le f$, and $s_n \to f$ pointwise. If $f$ is bounded the convergence is uniform.

*Proof.* The values of $s_n$ lie in $\{0, 2^{-n}, \dots, n\}$, a finite set, and $\{s_n = k 2^{-n}\} = \{k 2^{-n} \le f < (k+1) 2^{-n}\}$ is measurable for $k 2^{-n} < n$, so $s_n$ is simple. Since $\lfloor 2y \rfloor \ge 2 \lfloor y \rfloor$, we get $2^{-(n+1)} \lfloor 2^{n+1} f \rfloor \ge 2^{-n} \lfloor 2^n f \rfloor$, and $\min(n+1, \cdot) \ge \min(n, \cdot)$, so $s_n \le s_{n+1}$; also $s_n \le f$. Fix $x$. If $f(x) = \infty$ then $s_n(x) = n \to \infty$. If $f(x) < \infty$ then for $n > f(x)$ the minimum is the second term and $0 \le f(x) - s_n(x) < 2^{-n}$. For bounded $f \le M$ this holds for all $x$ once $n > M$, which gives uniform convergence. $\blacksquare$

A general measurable $f$ splits as $f = f^+ - f^-$ with $f^+ = \max(f, 0)$ and $f^- = \max(-f, 0)$, both measurable.

### Borel versus Lebesgue

A function on $\mathbb{R}$ is **Borel measurable** if $\{f > a\}$ is Borel for all $a$ and **Lebesgue measurable** if these sets lie in $\mathcal{M}$. Measurability with respect to a **complete** measure is unaffected by changing a function on a null set: if $f$ is measurable and $g = f$ off a null set, then $g$ is measurable. Warning: a Lebesgue measurable $f$ composed with a *continuous* $g$ need not be Lebesgue measurable, although $g \circ f$ always is. The standard counterexample uses $\psi(x) = x + \varphi(x)$, with $\varphi$ the Cantor function. It is a homeomorphism $[0,1] \to [0,2]$ sending $C$ to a set of measure $1$; a non-measurable $A \subseteq \psi(C)$ pulls back to a null (hence measurable) subset $B = \psi^{-1}(A)$ of $C$, but $\mathbf{1}_B \circ \psi^{-1} = \mathbf{1}_A$ is not measurable. (This uses the fact that every set of positive measure has a non-measurable subset.)

```python
import math


def s(y, n):
    """n-th dyadic simple approximation of y >= 0 (the formula of Theorem 2)."""
    if math.isinf(y):
        return float(n)
    return min(n, math.floor(2 ** n * y) / 2 ** n)


print([s(math.pi, n) for n in range(1, 8)])
```

This prints `[1, 2, 3, 3.125, 3.125, 3.140625, 3.140625]`: nondecreasing, below $\pi$ and within $2^{-n}$ of it once $n > \pi$. The values check Theorem 2 at one point; the proof covers every point.

@example
title: Monotone functions are Borel measurable
problem: Let $f\colon \mathbb{R} \to \mathbb{R}$ be nondecreasing. Show that $f$ is Borel measurable.
step: Fix $a \in \mathbb{R}$ and let $S = \{x : f(x) > a\}$. To be shown: $S$ is a Borel set.
step: $S$ is an up-set: if $x \in S$ and $y > x$ then $f(y) \ge f(x) > a$, so $y \in S$.
step: An up-set $S \subseteq \mathbb{R}$ is empty, all of $\mathbb{R}$, or a ray: with $c = \inf S \in [-\infty, \infty)$ we have $(c, \infty) \subseteq S \subseteq [c, \infty)$.
step: In every case $S$ is $\emptyset$, $\mathbb{R}$, $(c, \infty)$ or $[c, \infty)$, which are Borel. So $\{f > a\} \in \mathcal{B}(\mathbb{R})$ for every $a$, and $f$ is Borel measurable.
answer: Every monotone function is Borel measurable, although it may have countably many jumps.

@example
title: Level sets of a simple approximation
problem: For $f(x) = x^2$ on $[0, 2]$ find the set $\{s_2 = 1/2\}$ and the number of distinct values of $s_2$.
step: By Theorem 2, $s_2 = \min(2, \lfloor 4 f \rfloor / 4)$. The value $1/2 = 2/4$ means $\lfloor 4x^2 \rfloor = 2$, i.e. $2 \le 4x^2 < 3$.
step: Solve for $x \ge 0$: $\sqrt{2}/2 \le x < \sqrt{3}/2$, a half-open interval of length $(\sqrt{3} - \sqrt{2})/2 \approx 0.159$.
step: Count values: $\lfloor 4x^2 \rfloor / 4$ equals $k/4$ for $k = 0, 1, \dots, 7$ while $4x^2 < 8$, and for $x^2 \ge 2$ the cap gives $2$. On $[0,2]$ all of these occur, so $s_2$ takes the nine values $0, 1/4, \dots, 7/4, 2$.
answer: $\{s_2 = 1/2\} = [\sqrt{2}/2, \sqrt{3}/2)$, and $s_2$ takes $9$ distinct values.

@mistakes
- Treating "measurable" as "continuous almost everywhere" or "Riemann integrable": the indicator of a measurable set is always measurable.
- Composing in the wrong order: $g \circ f$ with $g$ continuous and $f$ Lebesgue measurable is measurable, but $f \circ g$ need not be.
- Forgetting that $\{f > a\}$ can be tested only for rational $a$, yet cannot be replaced by testing preimages of single points: the identity on $\mathbb{R}$ with the countable–cocountable σ-algebra has measurable singleton preimages but is not measurable.
- Using $f + g$ when $f$ takes the value $+\infty$ and $g$ the value $-\infty$: the sum is undefined there.

model:
```python
from fractions import Fraction
from math import floor


def s3(y, n):
    """Base-3 simple approximation min(n, floor(3^n y) / 3^n)."""
    return min(Fraction(n), Fraction(floor(3 ** n * y), 3 ** n))


def monotone_up_to(y, N):
    """Check s3 is nondecreasing in n and bounded by y for n <= N."""
    values = [s3(y, n) for n in range(1, N + 1)]
    increasing = all(a <= b for a, b in zip(values, values[1:]))
    return increasing and all(v <= y for v in values)
```
hint: `floor(3**n * y)` works on a `Fraction`; wrap the result in `Fraction(k, 3**n)`.
hint: Build the list of values for $n = 1, \dots, N$ and compare neighbors.
solution: The only changes from the base-$2$ formula are the grid size $3^{-n}$ and the cap. Using `Fraction` keeps everything exact, so the inequalities are tested without rounding error. The test of $y = 1/3$ is a good one for floating point: $3^n \cdot (1/3)$ is exactly an integer in rational arithmetic but may round down in floats. Checking these inequalities for one $y$ is evidence for the general proof, not a substitute for it.

prompt: Let $(X, \mathcal{A})$ be a measurable space and $f_n\colon X \to \mathbb{R}$ measurable for $n \ge 1$. Prove that the set $L = \{x : (f_n(x)) \text{ converges in } \mathbb{R}\}$ is measurable, and that $\lim f_n$ is measurable on $L$.
hint: Convergence in $\mathbb{R}$ is the Cauchy condition; write it with countable quantifiers over $k$, $N$, $m$ and $n$.
hint: Each set $\{|f_m - f_n| < 1/k\}$ is measurable by closure of measurable functions under differences and absolute values.
solution: A real sequence converges iff it is Cauchy, so $L = \bigcap_{k \ge 1} \bigcup_{N \ge 1} \bigcap_{m, n \ge N} \{x : |f_m(x) - f_n(x)| < 1/k\}$. Each $f_m - f_n$ is measurable (sum of $f_m$ and $-f_n$, real-valued), $|\cdot|$ is continuous, so $|f_m - f_n|$ is measurable, and $\{|f_m - f_n| < 1/k\} \in \mathcal{A}$. The expression for $L$ uses only countable unions and intersections, so $L \in \mathcal{A}$. On $L$ the limit equals $\limsup_n f_n$, which is measurable by Theorem 1(a). Restricting to $L$: for every $a$, $\{x \in L : \lim f_n(x) > a\} = L \cap \{\limsup f_n > a\} \in \mathcal{A}$. $\blacksquare$

choice: Always, because $s_n$ is within $2^{-n}$ of $f$.
choice: Exactly when $f$ is integrable.
choice: Exactly when $f$ is continuous.
hint: Where $f(x) \ge n$ the approximation is capped at $n$.
solution: For $n > \sup f$ the cap never applies and $0 \le f - s_n < 2^{-n}$ uniformly. solution: For rational $q$ only: $\{f > a\} = \bigcup_{q > a, q \in \mathbb{Q}} \{f > q\}$. For open $U$: take $U = (a, \infty)$. Singleton preimages are not enough: on an uncountable $X$ with the countable–cocountable σ-algebra, the identity map on $\mathbb{R}$ has countable preimages of points but $\{f > 0\} = (0, \infty)$ is neither countable nor cocountable.

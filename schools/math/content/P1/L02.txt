@article
The plan is to define the length of an arbitrary set from outside, by covers, and then single out the sets for which this behaves additively.

**Definition.** The **Lebesgue outer measure** of $A \subseteq \mathbb{R}$ is $\lambda^*(A) = \inf \sum_{k} \ell(I_k)$, the infimum over all countable families of bounded open intervals $I_k$ with $A \subseteq \bigcup_k I_k$.

**Theorem 1.** (a) $A \subseteq B$ implies $\lambda^*(A) \le \lambda^*(B)$. (b) $\lambda^*(\bigcup_n A_n) \le \sum_n \lambda^*(A_n)$. (c) $\lambda^*(A + t) = \lambda^*(A)$. (d) $\lambda^*(I) = \ell(I)$ for every interval $I$.

*Proof.* (a) and (c) are immediate from the definition. (b) We may assume the right side is finite. Given $\varepsilon > 0$, cover $A_n$ by open intervals of total length less than $\lambda^*(A_n) + \varepsilon 2^{-n}$. All these intervals together cover $\bigcup A_n$ and have total length less than $\sum_n \lambda^*(A_n) + \varepsilon$. (d) For $[a, b]$: the cover $(a - \varepsilon, b + \varepsilon)$ gives $\lambda^* \le b - a + 2\varepsilon$. Conversely let $\{I_k\}$ cover $[a, b]$. By the Heine–Borel theorem finitely many cover it. Choose one containing $a$, say $(a_1, b_1)$; if $b_1 \le b$ choose another finite-cover member containing $b_1$, and so on. This chain $(a_1, b_1), \dots, (a_m, b_m)$ has $a_1 < a$, $a_{j+1} < b_j$ and $b_m > b$, so $\sum (b_j - a_j) \ge b_m - a_1 > b - a$. Hence $\sum_k \ell(I_k) \ge b - a$. A bounded interval lies between closed intervals of lengths within $\varepsilon$ of its own, and an unbounded interval contains closed intervals of every length. $\blacksquare$

### Carathéodory's criterion

Outer measure is not additive on all sets (see the Vitali set below), so we restrict. A set $E \subseteq \mathbb{R}$ is **Lebesgue measurable** if $\lambda^*(A) = \lambda^*(A \cap E) + \lambda^*(A \setminus E)$ for **every** $A \subseteq \mathbb{R}$. By subadditivity "$\ge$" always holds, so only "$\le$" must be checked.

**Theorem 2 (Carathéodory).** The family $\mathcal{M}$ of Lebesgue measurable sets is a σ-algebra containing every Borel set, and $\lambda = \lambda^*|_{\mathcal{M}}$ is a complete measure.

*Proof.* If $\lambda^*(E) = 0$ then $\lambda^*(A \cap E) + \lambda^*(A \setminus E) \le 0 + \lambda^*(A)$, so null sets are measurable; this also gives completeness. The definition is symmetric in $E$ and $E^c$, so $\mathcal{M}$ is closed under complements and contains $\mathbb{R}$.
*Finite unions.* Let $E_1, E_2 \in \mathcal{M}$ and $A$ be arbitrary. Testing $E_1$ and then $E_2$ with $A \setminus E_1$: $\lambda^*(A) = \lambda^*(A \cap E_1) + \lambda^*((A \setminus E_1) \cap E_2) + \lambda^*(A \setminus (E_1 \cup E_2))$. Since $A \cap (E_1 \cup E_2) = (A \cap E_1) \cup ((A \setminus E_1) \cap E_2)$, subadditivity bounds the first two terms below by $\lambda^*(A \cap (E_1 \cup E_2))$. So $E_1 \cup E_2 \in \mathcal{M}$, and $\mathcal{M}$ is an algebra.
*Disjoint countable unions.* Let $E_j \in \mathcal{M}$ be pairwise disjoint, $F_n = \bigcup_{j \le n} E_j$, $F = \bigcup_j E_j$. Testing $E_n$ with the set $A \cap F_n$ gives $\lambda^*(A \cap F_n) = \lambda^*(A \cap E_n) + \lambda^*(A \cap F_{n-1})$, so $\lambda^*(A \cap F_n) = \sum_{j \le n} \lambda^*(A \cap E_j)$. Since $F_n \in \mathcal{M}$ and $F^c \subseteq F_n^c$, $\lambda^*(A) = \lambda^*(A \cap F_n) + \lambda^*(A \setminus F_n) \ge \sum_{j \le n} \lambda^*(A \cap E_j) + \lambda^*(A \setminus F)$. Let $n \to \infty$ and use countable subadditivity: $\lambda^*(A) \ge \lambda^*(A \cap F) + \lambda^*(A \setminus F)$. So $F \in \mathcal{M}$. Taking $A = F$ in the same chain gives $\lambda^*(F) \ge \sum_j \lambda^*(E_j)$, and subadditivity gives the reverse: $\lambda$ is countably additive. A general countable union is a disjoint countable union of sets in the algebra $\mathcal{M}$, so $\mathcal{M}$ is a σ-algebra.
*Borel sets.* It suffices to show $(a, \infty) \in \mathcal{M}$. For $A$ and $\varepsilon > 0$ take a cover by intervals $I_k$ with $\sum \ell(I_k) < \lambda^*(A) + \varepsilon$. The sets $I_k \cap (a, \infty)$ cover $A \cap (a, \infty)$ and $I_k \cap (-\infty, a)$ cover $A \setminus (a, \infty)$ except possibly the null point $a$; their lengths add to at most $\ell(I_k)$. By Theorem 1(d) and subadditivity, $\lambda^*(A \cap (a, \infty)) + \lambda^*(A \setminus (a, \infty)) \le \sum \ell(I_k) < \lambda^*(A) + \varepsilon$. $\blacksquare$

**Theorem 3 (regularity, cited).** For $E \in \mathcal{M}$: $\lambda(E) = \inf\{\lambda(G) : G \supseteq E \text{ open}\} = \sup\{\lambda(K) : K \subseteq E \text{ compact}\}$. Consequently every measurable set is a $G_\delta$ set minus a null set (and also an $F_\sigma$ set plus a null set). So $\mathcal{M}$ is the completion of the Borel σ-algebra.

### The Cantor set and Cantor function

Let $C_0 = [0,1]$ and let $C_{n+1}$ remove the open middle third of each interval of $C_n$. Then $C_n$ is a union of $2^n$ closed intervals of length $3^{-n}$, $\lambda(C_n) = (2/3)^n$, and the **Cantor set** $C = \bigcap_n C_n$ is compact with $\lambda(C) = 0$ by continuity from above. Yet $C$ is exactly the set of $x \in [0,1]$ with a ternary expansion using only the digits $0$ and $2$, so $x = \sum 2a_k 3^{-k}$ with $a_k \in \{0,1\}$ is a bijection with $\{0,1\}^{\mathbb{N}}$: $C$ is **uncountable**. The **Cantor function** $\varphi(\sum 2a_k 3^{-k}) = \sum a_k 2^{-k}$ on $C$, extended to be constant on each removed interval, is continuous, nondecreasing, maps $[0,1]$ onto $[0,1]$, and has $\varphi' = 0$ off $C$, a set of full measure. It is the standard example of a continuous function that is not the integral of its derivative.

```python
from fractions import Fraction


def cantor_stage(n):
    """Closed intervals (a, b) making up the n-th stage C_n."""
    intervals = [(Fraction(0), Fraction(1))]
    for _ in range(n):
        new = []
        for a, b in intervals:
            third = (b - a) / 3
            new.append((a, a + third))
            new.append((b - third, b))
        intervals = new
    return intervals


for n in range(5):
    stage = cantor_stage(n)
    print(n, len(stage), sum(b - a for a, b in stage))
```

The output shows $2^n$ intervals of total length $(2/3)^n$. Computation is evidence here, not proof; the proof is the induction above.

### A non-measurable set (outline)

Define $x \sim y$ on $[0,1]$ when $x - y \in \mathbb{Q}$, and use the **axiom of choice** to pick one point from each class, giving $V$. The translates $V + q$, $q \in \mathbb{Q} \cap [-1, 1]$, are pairwise disjoint and $[0,1] \subseteq \bigcup_q (V + q) \subseteq [-1, 2]$. If $V$ were measurable, translation invariance would give $1 \le \sum_q \lambda(V) \le 3$, which is impossible whether $\lambda(V) = 0$ or $\lambda(V) > 0$. The argument uses countable additivity, translation invariance and choice together; dropping any one of them removes the contradiction.

@example
title: A closed set of positive measure with empty interior
problem: Construct a compact $K \subseteq [0,1]$ with no interior and $\lambda(K) = 1/2$.
step: Start with $K_0 = [0,1]$. At stage $n \ge 1$, remove from each of the $2^{n-1}$ intervals of $K_{n-1}$ an open middle interval of length $4^{-n}$. This is possible: the surviving intervals of $K_n$ have length $\ell_n = (2^{-n} + 4^{-n})/2$, which is positive and larger than $4^{-(n+1)}$.
step: Total length removed at stage $n$ is $2^{n-1} 4^{-n} = 2^{-n-1}$, so $\lambda(K_n) = 1 - \sum_{j \le n} 2^{-j-1} = (1 + 2^{-n})/2$.
step: Put $K = \bigcap_n K_n$. It is compact (a decreasing intersection of compact sets). By continuity from above (finite measure), $\lambda(K) = \lim_n (1 + 2^{-n})/2 = 1/2$.
step: $K$ has empty interior: an interval of length $\delta > 0$ inside $K$ would lie inside one interval of $K_n$ for every $n$, but those have length $\ell_n \to 0$.
answer: $K$ is compact, nowhere dense and $\lambda(K) = 1/2$.

@example
title: The Cantor function at a point
problem: Evaluate $\varphi(1/4)$ for the Cantor function $\varphi$.
step: Find the ternary expansion: $\sum_{k \ge 1} 2 \cdot 9^{-k} = 2/8 = 1/4$, so $1/4 = 0.020202\ldots_3$, with digits $2$ in even positions. Hence $1/4 \in C$.
step: Replace each digit $2$ by $1$ and read in base $2$: the digits of $\varphi(1/4)$ are $0, 1, 0, 1, \dots$ in base $2$.
step: Sum the series: $\varphi(1/4) = \sum_{k \ge 1} 4^{-k} = 1/3$.
answer: $\varphi(1/4) = 1/3$.

@mistakes
- Believing "measure zero" means "countable": the Cantor set is uncountable and null.
- Believing a closed set with empty interior must be null: the set $K$ above has measure $1/2$.
- Defining outer measure with finite covers: that gives Jordan content, under which $\mathbb{Q} \cap [0,1]$ has outer content $1$, not $0$.
- Using regularity or additivity for non-measurable sets: $\lambda^*$ is only subadditive on arbitrary sets.

prompt: (a) Prove directly from the definition of outer measure that every countable subset of $\mathbb{R}$ has Lebesgue measure zero; deduce that $\mathbb{Q}$ is null although dense. (b) Outline the construction of a subset of $[0,1]$ that is not Lebesgue measurable, saying exactly where the axiom of choice and translation invariance are used.
hint: For (a), cover the $n$th point by an interval of length $\varepsilon 2^{-n-1}$.
hint: For (b), choose representatives of the classes of $x \sim y \iff x - y \in \mathbb{Q}$ and sandwich $[0,1]$ between a union of rational translates and $[-1,2]$.
solution: (a) Let $A = \{x_1, x_2, \dots\}$ be countable and $\varepsilon > 0$. The open intervals $I_n = (x_n - \varepsilon 2^{-n-2}, x_n + \varepsilon 2^{-n-2})$ have length $\varepsilon 2^{-n-1}$, cover $A$, and $\sum_n \ell(I_n) = \varepsilon/2 < \varepsilon$. So $\lambda^*(A) \le \varepsilon$ for all $\varepsilon$, i.e. $\lambda^*(A) = 0$; null sets are measurable. Thus $\lambda(\mathbb{Q}) = 0$. A finite set is handled by the same argument. (b) On $[0,1]$ define $x \sim y$ iff $x - y \in \mathbb{Q}$, an equivalence relation. By the axiom of choice pick a set $V \subseteq [0,1]$ with exactly one point from each class. For $q \in \mathbb{Q} \cap [-1,1]$ set $V_q = V + q$. Disjoint: if $v + q = w + r$ with $v, w \in V$ then $v - w \in \mathbb{Q}$, so $v = w$ and $q = r$. Covering: for $x \in [0,1]$ let $v \in V$ be its class representative; then $q = x - v \in \mathbb{Q} \cap [-1,1]$ and $x \in V_q$. So $[0,1] \subseteq \bigcup_q V_q \subseteq [-1,2]$. If $V$ were measurable, translation invariance gives $\lambda(V_q) = \lambda(V) =: c$ for all $q$, and countable additivity gives $1 \le \sum_q c \le 3$. If $c = 0$ the sum is $0 < 1$; if $c > 0$ it is $\infty > 3$. Contradiction, so $V$ is not measurable.

rubric: Part (b) defines the rational-translate equivalence relation and uses choice to select $V$.
rubric: Proves the translates are pairwise disjoint and cover $[0,1]$, with all inside $[-1,2]$.
rubric: Derives the contradiction from translation invariance and countable additivity in both cases $c = 0$ and $c > 0$.

model:
```python
from fractions import Fraction


def cantor(x, digits=40):
    """Cantor function by scanning the ternary digits of x."""
    if x == 1:
        return Fraction(1)
    value = Fraction(0)
    for k in range(1, digits + 1):
        t = 3 * x
        d = int(t)
        x = t - d
        if d == 1:
            return value + Fraction(1, 2 ** k)
        if d == 2:
            value += Fraction(1, 2 ** k)
    return value
```
hint: Multiply by $3$, take the integer part as the next digit, and keep the fractional part for the next step.
hint: Stop as soon as a digit equals $1$, after adding its contribution.
solution: Each pass of the loop extracts one ternary digit exactly using rational arithmetic. A digit $2$ contributes a binary $1$ in the same position, a digit $1$ means the point lies in a removed interval where the function is constant, so we add that bit and stop. Points of the Cantor set such as $1/10$ never hit a $1$, so the value is a truncated series, within $2^{-\text{digits}}$ of the true value. This is evidence of the formula, not a proof.

choice*: $\lambda^*(A \cup B) = \lambda^*(A) + \lambda^*(B)$ whenever $A$ and $B$ are disjoint.
choice: $A \subseteq B$ implies $\lambda^*(A) \le \lambda^*(B)$.

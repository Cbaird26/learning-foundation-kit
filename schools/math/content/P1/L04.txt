@article
Riemann sums partition the domain; Lebesgue sums partition the range. For $f(x) = x^2$ on $[0,1]$, group the points by the height $f$ reaches: the set $\{j/N \le f < (j+1)/N\}$ has Lebesgue measure $\sqrt{(j+1)/N} - \sqrt{j/N}$, and $\sum_j (j/N) \lambda(\{j/N \le f < (j+1)/N\})$ is a lower sum that approaches $1/3$. The advantage is that grouping by height needs only measurable level sets, not continuity.

### Definition in three stages

Let $(X, \mathcal{A}, \mu)$ be a measure space, with $0 \cdot \infty = 0$.

1. **Simple functions.** For $s = \sum_{i=1}^m a_i \mathbf{1}_{A_i} \ge 0$ in canonical form, $\int s \, d\mu = \sum_i a_i \mu(A_i) \in [0, \infty]$.
2. **Nonnegative functions.** For measurable $f\colon X \to [0, \infty]$, $\int f \, d\mu = \sup\left\{\int s \, d\mu : s \text{ simple}, \; 0 \le s \le f\right\}$.
3. **General functions.** A measurable $f$ is **integrable** if $\int |f| \, d\mu < \infty$, and then $\int f = \int f^+ - \int f^-$. The set of (equivalence classes of a.e.-equal) integrable functions is $L^1(\mu)$.

For $f \ge 0$ simple the two definitions agree (see below). With Lebesgue measure we write $\int f \, dx$. With counting measure on $\mathbb{N}$, $\int f \, d\mu = \sum_n f(n)$; with a weighted sum of Dirac masses, $\mu = \sum_i w_i \delta_{x_i}$, $\int f \, d\mu = \sum_i w_i f(x_i)$.

**Theorem 1.** Let $f, g\colon X \to [0, \infty]$ be measurable.
(a) If $f \le g$ then $\int f \le \int g$.
(b) **(Chebyshev's inequality)** For $t > 0$, $\mu(\{f \ge t\}) \le \frac{1}{t} \int f \, d\mu$.
(c) If $\int f = 0$ then $f = 0$ almost everywhere. If $\int f < \infty$ then $\mu(\{f = \infty\}) = 0$.
(d) If $f = g$ almost everywhere then $\int f = \int g$.

*Proof.* (a) Every simple function below $f$ is below $g$, so the supremum for $g$ is at least that for $f$. (b) The simple function $t \mathbf{1}_{\{f \ge t\}}$ is at most $f$, so $t \mu(\{f \ge t\}) \le \int f$. (c) $\{f > 0\} = \bigcup_n \{f \ge 1/n\}$ and by (b) each has measure at most $n \int f = 0$; countable subadditivity gives $\mu(\{f > 0\}) = 0$. For the second claim, $\mu(\{f = \infty\}) \le \mu(\{f \ge t\}) \le \frac{1}{t} \int f$ for every $t$, and $t \to \infty$ gives $0$. (d) Let $N$ be a null set containing $\{f \ne g\}$. For a simple $s \le f$, $s \mathbf{1}_{N^c} \le g$ is simple with $\int s \mathbf{1}_{N^c} = \int s$ (the level sets change by null sets). So $\int f \le \int g$; by symmetry equality holds. $\blacksquare$

Linearity of $f \mapsto \int f$ on nonnegative functions is a consequence of the monotone convergence theorem (Lesson 5); for simple functions it follows by refining the canonical partitions. Until then we use only monotonicity and the direct computation below.

### Countably-valued functions

**Theorem 2.** Let $A_1, A_2, \dots \in \mathcal{A}$ be pairwise disjoint with union $X$, $a_k \in [0, \infty)$, and $f = \sum_k a_k \mathbf{1}_{A_k}$. Then $\int f \, d\mu = \sum_k a_k \mu(A_k)$.

*Proof.* ($\ge$) For each $N$, $s_N = \sum_{k \le N} a_k \mathbf{1}_{A_k}$ is simple with $s_N \le f$ and $\int s_N = \sum_{k \le N} a_k \mu(A_k)$ (grouping equal values only adds disjoint sets). Let $N \to \infty$. ($\le$) Let $s = \sum_j b_j \mathbf{1}_{B_j} \le f$ be simple in canonical form. If $A_k \cap B_j \neq \emptyset$ then $b_j \le a_k$. By countable additivity, $\mu(B_j) = \sum_k \mu(A_k \cap B_j)$, so
$$\int s = \sum_j \sum_k b_j \mu(A_k \cap B_j) = \sum_k \sum_j b_j \mu(A_k \cap B_j) \le \sum_k a_k \sum_j \mu(A_k \cap B_j) = \sum_k a_k \mu(A_k),$$
where the exchange is legitimate since all terms are nonnegative and the $j$-sum is finite, and the last step uses $\sum_j \mu(A_k \cap B_j) = \mu(A_k)$. Taking the supremum over $s$ gives $\le$. $\blacksquare$

### Riemann versus Lebesgue

Every Riemann-integrable function on $[a, b]$ is Lebesgue integrable with the same value (Lebesgue's criterion: a bounded function is Riemann integrable iff it is continuous almost everywhere). The converse fails: $\mathbf{1}_{\mathbb{Q} \cap [0,1]}$ is not Riemann integrable (upper sum $1$, lower sum $0$ for every partition), but it equals $0$ almost everywhere, so its Lebesgue integral is $0$. For **improper** integrals the comparison breaks the other way: $\int_0^\infty \frac{\sin x}{x} \, dx$ converges as an improper Riemann integral, yet $\sin x / x \notin L^1(0, \infty)$ (see the example).

```python
import math


def lebesgue_lower(N):
    """Lower Lebesgue sum for f(x) = x**2 on [0, 1] with levels j/N."""
    total = 0.0
    for j in range(N):
        a, b = math.sqrt(j / N), math.sqrt((j + 1) / N)
        total += (j / N) * (b - a)
    return total


print([round(lebesgue_lower(N), 4) for N in (4, 16, 64, 256)])
```

The sums increase toward $1/3$ with error at most about $1/N$. Computation is evidence for a limit; the definition and the monotone convergence theorem prove it.

@example
title: A countably-valued function from the definition
problem: At stage $k \ge 1$ of the Cantor construction the open middle thirds removed form $2^{k-1}$ intervals of length $3^{-k}$. Let $f(x) = k$ on the intervals removed at stage $k$ and $f = 0$ on the Cantor set $C$. Compute $\int_0^1 f \, d\lambda$.
step: Set $A_0 = C$ and $A_k$ = the union of the intervals removed at stage $k$. These sets are measurable, pairwise disjoint and cover $[0,1]$. So $f = \sum_{k \ge 0} k \mathbf{1}_{A_k}$ is countably valued and Theorem 2 applies.
step: $\lambda(A_k) = 2^{k-1} 3^{-k}$ for $k \ge 1$, and $\lambda(A_0) = 0$.
step: By Theorem 2, $\int f = \sum_{k \ge 1} k \cdot 2^{k-1} 3^{-k} = \frac{1}{2} \sum_{k \ge 1} k (2/3)^k$.
step: Use $\sum_{k \ge 1} k x^k = x/(1 - x)^2$ with $x = 2/3$: the sum is $(2/3)/(1/9) = 6$. Hence $\int f = 3$.
answer: $\int_0^1 f \, d\lambda = 3$.

@example
title: sin x over x is not Lebesgue integrable
problem: Show that $f(x) = \frac{\sin x}{x}$ is not in $L^1(0, \infty)$.
step: To be shown: $\int_{(0,\infty)} |f| \, d\lambda = \infty$. Let $I_k = [k\pi, (k+1)\pi]$ for $k \ge 1$.
step: On $I_k$, $|\sin x|/x \ge |\sin x|/((k+1)\pi)$, and $\int_{I_k} |\sin x| \, dx = 2$ (a continuous function on a compact interval has equal Riemann and Lebesgue integrals). So $\int_{I_k} |f| \ge \frac{2}{(k+1)\pi}$.
step: For simple $s_k \le |f| \mathbf{1}_{I_k}$, $\sum_{k \le N} s_k \le |f|$ is simple, so $\int |f| \ge \sum_{k \le N} \int s_k$; taking suprema, $\int |f| \ge \sum_{k=1}^N \int_{I_k} |f|$.
step: Hence $\int |f| \ge \frac{2}{\pi} \sum_{k=1}^N \frac{1}{k+1}$ for every $N$. The harmonic series diverges, so $\int |f| = \infty$.
answer: $\sin x / x \notin L^1(0, \infty)$ although its improper Riemann integral converges.

@mistakes
- Using $\int f = \int f^+ - \int f^-$ when both terms are infinite: the integral is then undefined, not $0$.
- Believing a function with a convergent improper Riemann integral is Lebesgue integrable: only absolute integrability counts.
- Using Chebyshev's inequality for a function that is not nonnegative: apply it to $|f|$.
- Computing $\int f \, d\lambda$ from the values on a null set: changing $f$ on a null set never changes the integral, which is why $\mathbf{1}_{\mathbb{Q}}$ integrates to $0$.

model:
```python
import math


def lower_sum(N, p, b):
    """Lower Lebesgue sum of x**p on [0, b] with levels j/N."""
    total = 0.0
    top = math.ceil(N * b ** p) + 1
    for j in range(top + 1):
        lo = (j / N) ** (1 / p)
        if lo >= b:
            break
        hi = min(b, ((j + 1) / N) ** (1 / p))
        total += (j / N) * (hi - lo)
    return total
```
hint: Loop over $j$, compute the interval endpoints with exponent $1/p$, cap the upper endpoint at $b$, and stop when the lower endpoint reaches $b$.
solution: Each level set is an interval, so its Lebesgue measure is the difference of endpoints. Capping the upper endpoint at $b$ handles the last level, which would otherwise stick out of $[0, b]$. The sums are below the true integral $b^{p+1}/(p+1)$ and increase when $N$ doubles, as lower sums over nested level sets must. These numbers are evidence of convergence, not a proof of it.

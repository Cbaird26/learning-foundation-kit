@article
The fundamental theorem of calculus says $\frac{d}{dx}\int_a^x f = f(x)$ for continuous $f$. For merely integrable $f$ the correct statement holds almost everywhere. Write $A_r f(x) = \frac{1}{2r} \int_{x-r}^{x+r} f(y) \, dy$ for the symmetric average. The **Lebesgue differentiation theorem** says $A_r f(x) \to f(x)$ as $r \to 0$ for almost every $x$ when $f \in L^1_{\mathrm{loc}}(\mathbb{R})$. The proof rests on a bound for the worst average, the **Hardy–Littlewood maximal function**
$$Mf(x) = \sup_{r > 0} \frac{1}{2r} \int_{x-r}^{x+r} |f(y)| \, dy .$$
The set $\{Mf > t\}$ is open: if an average over $[x-r, x+r]$ exceeds $t$, then slightly larger intervals centered at nearby points also have averages above $t$, by continuity of the integral. So $Mf$ is Borel measurable.

**Lemma 1 (Vitali, finite form).** Any finite collection of intervals $I_1, \dots, I_m$ has a pairwise disjoint subcollection $I_{j_1}, \dots, I_{j_k}$ with $\sum_i |I_{j_i}| \ge \frac{1}{3} \lambda\left(\bigcup_j I_j\right)$.

*Proof.* Pick the longest interval $J_1$. Discard every interval meeting $J_1$; each is contained in the interval $3J_1$ with the same center and three times the length. From the rest pick the longest $J_2$, discard those meeting it, and continue. The chosen $J_i$ are disjoint, and every original interval lies in some $3J_i$, so $\lambda(\bigcup I_j) \le 3\sum |J_i|$. $\blacksquare$

**Theorem 2 (maximal inequality).** If $f \in L^1(\mathbb{R})$ and $t > 0$ then $\lambda(\{Mf > t\}) \le \frac{3}{t} \|f\|_1$.

*Proof.* Let $K \subseteq \{Mf > t\}$ be compact. Each $x \in K$ has $r_x > 0$ with $\int_{I_x} |f| > t |I_x|$, where $I_x = [x - r_x, x + r_x]$. Finitely many of the open intervals $\mathrm{int}\, I_x$ cover $K$; apply Lemma 1 to get disjoint $J_1, \dots, J_k$ among them with $\lambda(K) \le 3 \sum |J_i|$. Then $\lambda(K) \le \frac{3}{t} \sum_i \int_{J_i} |f| \le \frac{3}{t} \|f\|_1$, since the $J_i$ are disjoint. By inner regularity take the supremum over $K$. $\blacksquare$

The bound is *weak type* $(1,1)$: $Mf$ need not be integrable (for $f \ne 0$, $Mf(x) \ge c/|x|$ at infinity), so no $L^1$ bound is possible.

**Theorem 3 (Lebesgue differentiation).** If $f \in L^1_{\mathrm{loc}}(\mathbb{R})$ then $\lim_{r \to 0} A_r f(x) = f(x)$ for almost every $x$.

*Proof.* The statement is local, so we may take $f \in L^1(\mathbb{R})$ (multiply by the indicator of a bounded interval). Let $\Omega f(x) = \limsup_{r \to 0} |A_r f(x) - f(x)|$. Given $\varepsilon > 0$, by density (Lesson 10) choose $g \in C_c$ with $\|f - g\|_1 < \varepsilon$. For continuous $g$, $A_r g(x) \to g(x)$ at every $x$, so $\Omega f \le \Omega(f - g) \le M(f - g) + |f - g|$. For $t > 0$, $\{\Omega f > 2t\} \subseteq \{M(f - g) > t\} \cup \{|f - g| > t\}$, which has measure at most $\frac{3}{t}\|f - g\|_1 + \frac{1}{t}\|f - g\|_1 \le \frac{4\varepsilon}{t}$ by the maximal and Chebyshev inequalities. As $\varepsilon$ is arbitrary, $\lambda^*(\{\Omega f > 2t\}) = 0$ for each $t > 0$, so $\Omega f = 0$ a.e. $\blacksquare$

A point $x$ is a **Lebesgue point** of $f$ if $\frac{1}{2r} \int_{x-r}^{x+r} |f(y) - f(x)| \, dy \to 0$. Applying the theorem to $|f - q|$ for each rational $q$ shows that almost every point is a Lebesgue point. Taking $f = \mathbf{1}_E$ gives the **Lebesgue density theorem**: for measurable $E$, $\frac{\lambda(E \cap (x - r, x + r))}{2r} \to \mathbf{1}_E(x)$ for a.e. $x$.

### Consequences and limits

If $f \in L^1$ and $F(x) = \int_a^x f$, then $F'(x) = f(x)$ for a.e. $x$ (average over $[x, x+h]$ and $[x-h, x]$; the one-sided version follows from the same proof). More generally, if $\nu = f\lambda$ then $f(x) = \lim_{r \to 0} \frac{\nu((x-r, x+r))}{2r}$ for a.e. $x$: the Radon–Nikodym derivative is a derivative. The theorem **cannot** be strengthened to every $x$ (take $f = \mathbf{1}_{[0,\infty)}$ at $0$, where the averages tend to $1/2$), nor to the fundamental theorem of calculus without hypotheses: the Cantor function $\varphi$ has $\varphi' = 0$ a.e., so $\int_0^1 \varphi' = 0 \ne 1 = \varphi(1) - \varphi(0)$. The right hypothesis is **absolute continuity** (a function $F$ on $[a,b]$ is absolutely continuous if and only if $F(x) = F(a) + \int_a^x f$ for some $f \in L^1$; cited), and Lebesgue's theorem that monotone functions are differentiable a.e.

```python
def average(f, x, r, m=2000):
    """Midpoint-rule average of f over [x - r, x + r]."""
    w = 2 * r / m
    return sum(f(x - r + (i + 0.5) * w) for i in range(m)) / m


def f(y):
    return 1.0 if 0 <= y <= 1 else 0.0


for x in (0.95, 1.0):
    print(x, [round(average(f, x, r), 3) for r in (0.1, 0.01, 0.001)])
```

The point $0.95$ gives `[0.75, 1.0, 1.0]`, converging to $f(0.95) = 1$, while the jump point $1.0$ gives `0.5` at every scale, not $f(1) = 1$. Computation is evidence for one point; the theorem shows that only a null set of points misbehaves.

@example
title: The maximal function of an indicator
problem: For $f = \mathbf{1}_{[0,1]}$ find $Mf(x)$ for $x \notin [0, 1]$ with $x > 1$, and verify the weak-type inequality at $t = 1/4$.
step: For $x > 1$ and $r \le x - 1$ the interval $[x - r, x + r]$ misses $[0,1]$. For $x - 1 < r < x$ the overlap is $[x - r, 1]$ of length $1 - x + r$, so the average is $\frac{1 - x + r}{2r}$, which has derivative $\frac{x - 1}{2r^2} > 0$ in $r$. For $r \ge x$ the overlap is $[0,1]$ and the average is $\frac{1}{2r} \le \frac{1}{2x}$.
step: Hence the supremum is attained at $r = x$: $Mf(x) = \frac{1}{2x}$ for $x \ge 1$. By symmetry $Mf(x) = \frac{1}{2(1 - x)}$ for $x \le 0$, and $Mf = 1$ on $(0,1)$.
step: For $t = 1/4$: $\{Mf > 1/4\} = \{x : 1/(2x) > 1/4\} \cup [0,1] \cup \{x : 1/(2(1-x)) > 1/4\} = (-1, 2)$, which has measure $3$.
step: The bound of Theorem 2 is $3\|f\|_1/t = 3 \cdot 1 / (1/4) = 12 \ge 3$. In general $\lambda(\{Mf > t\}) = 1/t - 1$ for $t < 1/2$, comfortably below $3/t$.
answer: $Mf(x) = 1/(2x)$ for $x \ge 1$, and $\lambda(\{Mf > 1/4\}) = 3 \le 12$.

@example
title: A density at a jump
problem: Let $f(x) = x \, \mathbf{1}_{[0,1]}(x)$. Find $\lim_{r \to 0} A_r f(x)$ at $x = 1$ and $x = 1/2$, and say whether $x = 1$ is a Lebesgue point.
step: At $x = 1/2$ the function is continuous, and for $r < 1/2$, $A_r f(1/2) = \frac{1}{2r} \int_{1/2 - r}^{1/2 + r} y \, dy = \frac{1}{2}$, so the limit is $f(1/2) = 1/2$.
step: At $x = 1$: $f(1) = 1$. For $0 < r < 1$, $\int_{1-r}^{1} y \, dy = \frac{1 - (1-r)^2}{2} = r - \frac{r^2}{2}$, and $f = 0$ on $(1, 1 + r)$. So $A_r f(1) = \frac{r - r^2/2}{2r} = \frac{1}{2} - \frac{r}{4} \to \frac{1}{2}$.
step: The limit $1/2$ differs from $f(1) = 1$, so $x = 1$ is not a Lebesgue point; it is one of the exceptional null set (here a single point).
answer: The limits are $1/2$ at $x = 1/2$ (equal to $f$) and $1/2$ at $x = 1$ (not equal to $f(1) = 1$); $x = 1$ is not a Lebesgue point.

@mistakes
- Believing the differentiation theorem holds at every point: averages at a jump converge to the midpoint, not to the value.
- Using the maximal inequality with the $L^1$ norm of $Mf$ on the right: $Mf \notin L^1$ in general, only $\lambda(\{Mf > t\}) \le 3\|f\|_1/t$ holds.
- Applying the fundamental theorem of calculus $F(b) - F(a) = \int_a^b F'$ to an arbitrary differentiable-a.e. function: the Cantor function is the counterexample; absolute continuity is required.
- Mixing up Lebesgue points with continuity points: continuity at $x$ implies $x$ is a Lebesgue point, but not conversely.

model:
```python
def maximal(f):
    """Centered discrete Hardy-Littlewood maximal function of a finite list."""
    n = len(f)
    result = []
    for i in range(n):
        best = 0.0
        for r in range(n + 1):
            lo = max(0, i - r)
            hi = min(n - 1, i + r)
            total = 0.0
            for j in range(lo, hi + 1):
                total += f[j]
            best = max(best, total / (2 * r + 1))
        result.append(best)
    return result
```
hint: Clip the window $[i - r, i + r]$ to the list but divide by $2r + 1$, because the function is zero outside.
solution: For each position, scan all radii and keep the largest average; dividing by the full window length $2r+1$ (not the clipped length) encodes the zeros outside the list. The result illustrates the weak-type inequality: here, in the first test, $\{m > 1\}$ has $5$ points while $\|f\|_1 = 6$, so $3\|f\|_1/1 = 18$ is a generous bound. Such checks are evidence for the inequality, not a proof of it.

prompt: The Cantor function $\varphi$ is continuous and nondecreasing with $\varphi(0) = 0$, $\varphi(1) = 1$ and $\varphi' = 0$ almost everywhere. Why does $\varphi(1) - \varphi(0) = \int_0^1 \varphi'(x) \, dx$ fail?
choice*: $\varphi$ is not absolutely continuous.
choice: $\varphi$ is not continuous.
choice: $\varphi'$ is not Lebesgue measurable.
choice: Lebesgue measure on $[0,1]$ is not σ-finite.
hint: The identity holds for exactly the absolutely continuous functions.
solution: The right side is $\int_0^1 0 \, dx = 0$ while the left side is $1$. The function $\varphi$ is continuous, $\varphi'$ exists a.e. and equals $0$ (so it is measurable), and Lebesgue measure on $[0,1]$ is finite. What fails is absolute continuity: $\varphi$ maps the null Cantor set onto $[0,1]$, which an absolutely continuous function cannot do.

solution: The first is the maximal inequality, the second the differentiation theorem. At a continuity point, $\frac{1}{2r}\int |f(y) - f(x)| dy \le \sup_{|y - x| \le r} |f(y) - f(x)| \to 0$.

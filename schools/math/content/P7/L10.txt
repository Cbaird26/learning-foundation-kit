@article
You have a proof that took three weeks. Typeset badly, a reader will not believe it; typeset well, the reader notices only the mathematics. **LaTeX** is the standard typesetting system for mathematics, and the arXiv, most journals and most departments expect it. This lesson covers a workflow that works, the conventions that matter, and how preprints fit in. Journals and institutions differ, so check each journal's author instructions and your own university's rules.

### A minimal document

```text
\documentclass[11pt]{article}
\usepackage{amsmath, amssymb, amsthm}

\newtheorem{theorem}{Theorem}[section]
\newtheorem{lemma}[theorem]{Lemma}
\theoremstyle{definition}
\newtheorem{definition}[theorem]{Definition}

\newcommand{\R}{\mathbb{R}}
\DeclareMathOperator{\Gal}{Gal}

\title{A short title}
\author{Your Name}

\begin{document}
\maketitle

\section{Introduction}\label{sec:intro}
\begin{theorem}\label{thm:main}
Let $f\colon [0,1] \to \R$ be continuous. Then $f$ is bounded.
\end{theorem}
\begin{proof}
...
\end{proof}
See Theorem~\ref{thm:main} and~\cite{rudin}.

\begin{thebibliography}{9}
\bibitem{rudin} W. Rudin, \emph{Principles of Mathematical Analysis}.
\end{thebibliography}
\end{document}
```

Compile twice so that cross-references settle. Packages and class files vary with the journal; the structure does not.

### Conventions for mathematics

- Use `\[ ... \]` or `equation` for displays, not `$$ ... $$`, which has inconsistent spacing; punctuate displayed formulas as part of the sentence.
- Write functions with `\colon`: `$f\colon X \to Y$` has correct spacing, whereas `f: X \to Y` sets the colon as a relation.
- Use `\mid` for divisibility and set-builder bars, `\langle x, y \rangle` for inner products, `\ldots` or `\dots` for ellipses, and `\|x\|` for norms.
- Operators that are words take `\operatorname{}` or `\DeclareMathOperator`, so that `\sin`, `\lim` and `\Gal` are upright: write `\operatorname{rank}`, not `rank`.
- Use `align` for aligned multi-line equations: the `&` marks the alignment point, `\\` ends a line, and each line gets a number unless you write `\nonumber`. Use `equation*` or `\[ \]` for unnumbered displays.
- Define macros for repeated notation, and use them consistently.
- Never type theorem numbers: use `\label` inside the environment (after `\begin{theorem}`) and `\ref`. A tilde, as in `Theorem~\ref{thm:main}`, prevents a line break there.

### Bibliographies

A bibliography entry should let a reader find the source. For books give authors, title, publisher and year; for articles give authors, title, journal, volume, year and pages; for preprints give authors, title and the arXiv identifier with its version if relevant. BibTeX or BibLaTeX keeps entries in a `.bib` file:

```text
@book{hardywright,
  author    = {G. H. Hardy and E. M. Wright},
  title     = {An Introduction to the Theory of Numbers},
  publisher = {Oxford University Press}
}
```

Cite with `\cite{hardywright}`, and let the style produce the formatting. Be consistent, and look at the sources: a bibliographic database entry copied without checking often has errors. Cite the published version when one exists, and mention the arXiv version if it differs substantially.

### Good habits

Keep the source under version control or in frequent backups. Compile often, so that an error is found when it is a line old. Read the entire PDF, not just the changed page, before sending. Describe figures in the text, and make sure every figure has a caption and is referenced. Use a spell checker and read the compiler's warnings, especially "undefined reference."

### Preprints and the arXiv

Mathematicians commonly post a **preprint** on the arXiv when a paper is ready, often at about the time it is submitted to a journal. A preprint can be cited and read immediately, and the author can replace it with a revised **version** after refereeing; earlier versions stay available. Practice differs between areas and over time, and so do journal policies, so before submitting to a journal check what its policy says about preprints and about posting the accepted version. Your institution may also have rules about open access and about acknowledging funding.

To post, an author usually creates an account, uploads the TeX source and any figure files (the archive builds the PDF, so the source must compile there), chooses a subject class, supplies the title, authors and abstract, and reviews the generated PDF before confirming. Some new submitters need an endorsement from an established author in the field; the arXiv help pages describe the current rules, which can change. Moderators check that a submission is appropriate, not that it is correct. After the paper appears you may replace it; note changes in the comments field and, if the journal publishes it, update the journal reference.

@example
title: Fixing a messy snippet
problem: A draft contains: `Let $f: X -> Y$ be a map with $|x|<1$ and $S=\{x | x>0\}$; then $rank(f)=1$ $$f(x)=0.$$` List the corrections and write the corrected line.
step: Function arrow and colon: use `f\colon X \to Y`; `->` is not an arrow in math mode.
step: Norm or absolute value: `|x|<1` is fine for a real number; for a norm write `\|x\| < 1`. Here $x$ is real, so `|x| < 1` stays, with spaces around the relation.
step: Set-builder bar: use `\mid`: `S = \{x \mid x > 0\}`.
step: Operators: `\operatorname{rank}(f) = 1`; and replace `$$ ... $$` with `\[ ... \]` or `equation*`, ending with punctuation inside the display.
answer: `Let $f\colon X \to Y$ be a map with $|x| < 1$ and $S = \{x \mid x > 0\}$; then $\operatorname{rank}(f) = 1$, and \[ f(x) = 0. \]`

@example
title: Referring to a theorem correctly
problem: In the minimal document above, how does `Theorem~\ref{thm:main}` produce the right number, and what goes wrong if the label is placed before the theorem environment begins?
step: `\label` records the current counter value when it is processed; `\ref` prints the value that was recorded.
step: Inside `\begin{theorem}...\end{theorem}` the current counter is the theorem number, so `\label{thm:main}` placed there stores that number. Compile twice: the first run writes the number to an auxiliary file and the second reads it.
step: If the `\label` comes after `\section{...}` but before `\begin{theorem}`, it stores the section number, so `\ref{thm:main}` would print the section number and the cross-reference would silently be wrong.
step: A reference to a label that does not exist prints as `??`; search the log or output for it before submitting.
answer: Put `\label` inside the environment, compile twice, and check that no `??` remains.

@mistakes
- Typing theorem or equation numbers by hand, so that they go wrong the moment you insert a lemma.
- Using `$$ ... $$` and `f: X \to Y`, which give inconsistent spacing; use `\[ ... \]` and `\colon`.
- Copying a bibliography entry from a database without checking the title, year and author names against the source.
- Posting a preprint without reading the policy of the journal you plan to submit to; policies vary.

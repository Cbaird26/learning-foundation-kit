@article
**Continuity** says that small changes in the input cause small changes in the output. The precise version is a challenge game, like the one for sequences.

### The definition

Let $f:D\to\mathbb R$ and $c\in D$. The function $f$ is **continuous at $c$** if
$$\forall\varepsilon>0\ \exists\delta>0:\quad x\in D,\ |x-c|<\delta\ \Longrightarrow\ |f(x)-f(c)|<\varepsilon.$$
It is continuous on $D$ if it is continuous at every point of $D$. The number $\delta$ may depend on $\varepsilon$ and on the point $c$, but not on the moving point $x$.

### The sequence version

$f$ is continuous at $c$ if and only if $x_n\to c$ (with $x_n\in D$) implies $f(x_n)\to f(c)$. This is the best way to prove discontinuity: one bad sequence is enough. Let $f(x)=\sin\frac1x$ for $x\ne0$ and $f(0)=0$. The points $x_n=\frac1{\pi/2+2\pi n}$ tend to $0$, yet $f(x_n)=1$ for every $n$, so $f$ is not continuous at $0$. To prove continuity, however, one sequence is never enough: you need every sequence, or the $\varepsilon$–$\delta$ definition.

### Writing an epsilon-delta proof

Start from $|f(x)-f(c)|$ and factor out $|x-c|$. Bound the leftover factor by first restricting $x$ to a neighborhood such as $|x-c|<1$. Then take $\delta$ to be the minimum of that restriction and whatever makes the product smaller than $\varepsilon$. The worked example shows the pattern for $x^2$.

### Continuity meets compactness

**Theorem.** If $K$ is compact and $f:K\to\mathbb R$ is continuous, then $f(K)$ is compact.

*Proof.* Let $(y_n)$ be a sequence in $f(K)$, say $y_n=f(x_n)$ with $x_n\in K$. Because $K$ is compact, a subsequence $x_{n_j}$ converges to some $x\in K$. By continuity at $x$, $y_{n_j}=f(x_{n_j})\to f(x)\in f(K)$. So every sequence in $f(K)$ has a subsequence converging inside $f(K)$, which is compactness. $\square$

**Extreme value theorem.** A continuous $f:[a,b]\to\mathbb R$ attains a maximum and a minimum. The set $f([a,b])$ is compact, hence bounded and closed. A nonempty bounded set has a supremum, and a closed set contains its supremum, so the supremum is attained.

### The intermediate value theorem

If $f$ is continuous on $[a,b]$ and $y$ lies between $f(a)$ and $f(b)$, then $f(c)=y$ for some $c\in[a,b]$. The proof uses completeness: when $f(a)<y<f(b)$, take $c=\sup\{x\in[a,b] : f(x)<y\}$ and show $f(c)=y$. The two theorems together say that the continuous image of $[a,b]$ is a closed interval $[m,M]$.

@example
title: An epsilon-delta proof for x squared
problem: Prove from the definition that $f(x)=x^2$ is continuous at $c=3$.
step: Factor: $|x^2-9|=|x-3|\,|x+3|$. We must make this small by controlling $|x-3|$.
step: Control the extra factor. If $|x-3|<1$, then $2<x<4$, so $|x+3|<7$.
step: Let $\varepsilon>0$ and set $\delta=\min\left(1,\frac\varepsilon7\right)$.
step: If $|x-3|<\delta$, then both $|x-3|<1$ and $|x-3|<\frac\varepsilon7$, so $|x^2-9|=|x-3|\,|x+3|<\frac\varepsilon7\cdot7=\varepsilon$.
step: Since $\varepsilon>0$ was arbitrary, $f$ is continuous at $3$.

@mistakes
- Letting $\delta$ depend on $x$. It may depend on $\varepsilon$ and on the fixed point $c$ only.
- Trying to prove continuity with one or two sequences. One sequence disproves continuity; it never proves it.
- Applying the extreme value theorem without checking the hypotheses: $\frac1x$ on $(0,1]$ is continuous but unbounded, and $x$ on $(0,1)$ has no maximum.

@practice self
prompt: Let $K\subseteq\mathbb R$ be nonempty and compact and let $f:K\to\mathbb R$ be continuous. Prove that $f(K)$ is compact, and deduce that $f$ attains a maximum value on $K$.
hint: Use sequential compactness for the first part: start from a sequence $y_n=f(x_n)$ in $f(K)$.
hint: For the second part, show that $\sup f(K)$ is a limit of points of $f(K)$ and use that compact sets are closed.
solution: Let $(y_n)$ be a sequence in $f(K)$ with $y_n=f(x_n)$, $x_n\in K$. Since $K$ is compact, a subsequence $x_{n_j}\to x\in K$. By continuity, $y_{n_j}=f(x_{n_j})\to f(x)\in f(K)$. Hence every sequence in $f(K)$ has a subsequence converging in $f(K)$, so $f(K)$ is compact. Now $f(K)$ is nonempty and bounded, so $s=\sup f(K)$ exists. For each $n$ there is $y_n\in f(K)$ with $s-\frac1n<y_n\le s$, so $y_n\to s$. As $f(K)$ is closed, $s\in f(K)$, i.e. $s=f(x^*)$ for some $x^*\in K$, which is a maximum.

rubric: Uses compactness of $K$ to extract a convergent subsequence with limit in $K$.
rubric: Uses continuity at the limit point to show $f(x_{n_j})$ converges to a value in $f(K)$.
rubric: Deduces the maximum: the supremum exists, is a limit of points of $f(K)$, and lies in the closed set $f(K)$.

check: root(lambda x: x**3 + x - 1, 0, 1)
tol: 0.0005
hint: Bisect: $f(0.5)<0$, so the root lies in $[0.5,1]$. Keep halving and track the sign of $f$.

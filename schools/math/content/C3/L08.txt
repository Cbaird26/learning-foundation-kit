@article
Last week you found special directions that $A$ only stretches. If there are enough of them to form a basis, the matrix becomes as simple as it can be: in that basis it is diagonal.

### The factorization

Suppose $A$ has $n$ independent eigenvectors $\mathbf{v}_1, \dots, \mathbf{v}_n$ with eigenvalues $\lambda_1, \dots, \lambda_n$. Put the eigenvectors in the columns of $P$ and the eigenvalues on the diagonal of $D$. Then $AP = PD$, because column $j$ of each side is $\lambda_j\mathbf{v}_j$. Since $P$ is invertible,
$$A = PDP^{-1}.$$
This is exactly the formula $P^{-1}AP$ from the change-of-basis lessons: $D$ is the matrix of the same transformation in the **eigenbasis**. In those coordinates the map just scales each axis.

### Powers

The middle factors cancel: $A^2 = PDP^{-1}PDP^{-1} = PD^2P^{-1}$, and in general
$$A^k = PD^kP^{-1}, \qquad D^k = \operatorname{diag}(\lambda_1^k, \dots, \lambda_n^k).$$
Powers of a diagonal matrix are trivial. This solves difference equations $\mathbf{u}_{k+1} = A\mathbf{u}_k$: writing $\mathbf{u}_0 = c_1\mathbf{v}_1 + \cdots + c_n\mathbf{v}_n$ gives $\mathbf{u}_k = c_1\lambda_1^k\mathbf{v}_1 + \cdots + c_n\lambda_n^k\mathbf{v}_n$. The eigenvalue with the largest $|\lambda|$ eventually dominates.

### When does it work?

- If $A$ has $n$ **distinct** eigenvalues, it is diagonalizable, because eigenvectors for different eigenvalues are independent.
- With repeated eigenvalues you must check each one: $A$ is diagonalizable exactly when, for every eigenvalue, the geometric multiplicity (dimension of $N(A - \lambda I)$) equals the algebraic multiplicity.
- A matrix that fails this test is **defective**, or not diagonalizable. It has fewer than $n$ independent eigenvectors, so no basis of eigenvectors exists.

The matrix $\begin{bmatrix}3&1\\0&3\end{bmatrix}$ is defective: $\lambda = 3$ is a double root, but $A - 3I = \begin{bmatrix}0&1\\0&0\end{bmatrix}$ has a one-dimensional null space. Diagonalizability is unrelated to invertibility. This matrix is invertible and defective, while $\begin{bmatrix}0&0\\0&1\end{bmatrix}$ is singular and diagonal.

A real matrix such as a rotation may fail to be diagonalizable over $\mathbb{R}$ yet be diagonalizable over $\mathbb{C}$.

```python
import numpy as np
A = np.array([[4., 1.], [2., 3.]])
vals, P = np.linalg.eig(A)
D = np.diag(vals)
print(np.allclose(A, P @ D @ np.linalg.inv(P)))              # True
print(np.allclose(np.linalg.matrix_power(A, 5), P @ D**5 @ np.linalg.inv(P)))  # True
```

@example
title: Diagonalize and take powers
problem: Diagonalize $A = \begin{bmatrix}4&1\\2&3\end{bmatrix}$ and find a formula for $A^k$.
step: From last week, the eigenpairs are $\lambda = 5$ with $\mathbf{v} = (1, 1)$ and $\lambda = 2$ with $\mathbf{v} = (1, -2)$. Set $P = \begin{bmatrix}1&1\\1&-2\end{bmatrix}$ and $D = \begin{bmatrix}5&0\\0&2\end{bmatrix}$. Since $\det P = -3 \ne 0$, the eigenvectors are independent.
step: The inverse is $P^{-1} = \frac{1}{3}\begin{bmatrix}2&1\\1&-1\end{bmatrix}$.
step: Then $A^k = PD^kP^{-1} = \frac13\begin{bmatrix}1&1\\1&-2\end{bmatrix}\begin{bmatrix}5^k&0\\0&2^k\end{bmatrix}\begin{bmatrix}2&1\\1&-1\end{bmatrix}$, which multiplies out to $A^k = \frac13\begin{bmatrix}2\cdot 5^k + 2^k & 5^k - 2^k\\ 2\cdot 5^k - 2\cdot 2^k & 5^k + 2\cdot 2^k\end{bmatrix}$.
step: Check $k = 1$: the matrix is $\frac13\begin{bmatrix}12&3\\6&9\end{bmatrix} = A$. Check $k = 2$: $\frac13\begin{bmatrix}54&21\\42&33\end{bmatrix} = \begin{bmatrix}18&7\\14&11\end{bmatrix}$, which matches $A \cdot A$ computed directly.

@example
title: A matrix that is not diagonalizable
problem: Show that $A = \begin{bmatrix}3&1\\0&3\end{bmatrix}$ cannot be written as $PDP^{-1}$ with $D$ diagonal.
step: The matrix is triangular, so the characteristic polynomial is $(\lambda - 3)^2$. The only eigenvalue is $3$, with algebraic multiplicity $2$.
step: Compute $A - 3I = \begin{bmatrix}0&1\\0&0\end{bmatrix}$. The equation $(A - 3I)\mathbf{v} = \mathbf{0}$ says $v_2 = 0$, so the eigenspace is spanned by $(1, 0)$. The geometric multiplicity is $1 < 2$.
step: There is only one independent eigenvector, but a diagonalization needs two, so $A$ is not diagonalizable.
step: Another argument: if $A = PDP^{-1}$, the diagonal entries of $D$ would be the eigenvalues, so $D = 3I$. Then $A = P(3I)P^{-1} = 3I$, which is false since $A \ne 3I$.

@mistakes
- Putting the eigenvectors in $P$ in a different order from the eigenvalues in $D$. Column $j$ of $P$ must pair with $\lambda_j$.
- Concluding that a repeated eigenvalue means "not diagonalizable". The identity matrix has a repeated eigenvalue and is diagonal. Check the eigenspace dimension.
- Writing $A = P^{-1}DP$ instead of $A = PDP^{-1}$.

@practice self
prompt: Show that $A = \begin{bmatrix}3&1\\0&3\end{bmatrix}$ is not diagonalizable. Give the algebraic and geometric multiplicity of its eigenvalue, and explain what goes wrong.
hint: Find the characteristic polynomial first, then the null space of $A - \lambda I$.
solution: The characteristic polynomial is $(\lambda - 3)^2$, so $\lambda = 3$ has algebraic multiplicity $2$. Since $A - 3I = \begin{bmatrix}0&1\\0&0\end{bmatrix}$ has rank $1$, its null space is spanned by $(1, 0)$ and the geometric multiplicity is $1$. A diagonalization would need two independent eigenvectors, but there is only one direction of eigenvectors, so $A$ is defective. Equivalently, $PDP^{-1}$ with $D = 3I$ would equal $3I \ne A$.

rubric: Finds $N(A - 3I)$ spanned by $(1, 0)$, so the geometric multiplicity is $1$.

@quiz num
prompt: Let $A = \begin{bmatrix}1&2\\3&0\end{bmatrix}$, whose eigenvalues are $3$ and $-2$. Find the entry in row 1, column 1 of $A^5$.
answer: 133
check: np.linalg.matrix_power(np.array([[1,2],[3,0]]), 5)[0,0]
hint: Eigenvectors are $(1, 1)$ for $\lambda = 3$ and $(2, -3)$ for $\lambda = -2$.
hint: With $P = \begin{bmatrix}1&2\\1&-3\end{bmatrix}$, the (1,1) entry of $PD^5P^{-1}$ is $\frac15\left(3 \cdot 3^5 + 2 \cdot (-2)^5\right)$.
solution: $P^{-1} = \frac15\begin{bmatrix}3&2\\1&-1\end{bmatrix}$. The (1,1) entry of $PD^5P^{-1}$ is $\frac15\left(1\cdot 3^5\cdot 3 + 2\cdot(-2)^5\cdot 1\right) = \frac15(729 - 64) = 133$.

@article
General matrices can have complex eigenvalues and slanted, nonorthogonal eigenvectors. Symmetric matrices are far better behaved, and they are the ones that appear in physics, statistics and optimization.

### Definitions

A real matrix is **symmetric** if $A^T = A$. A complex matrix is **Hermitian** if $A^H = A$, where $A^H = \overline{A}^T$ is the conjugate transpose: entries satisfy $a_{ji} = \overline{a_{ij}}$, so the diagonal entries are real. A real symmetric matrix is a special case. For example $\begin{bmatrix}2&1-i\\1+i&3\end{bmatrix}$ is Hermitian but not symmetric.

### The spectral theorem

If $A$ is real symmetric, then

- all eigenvalues of $A$ are real,
- eigenvectors for different eigenvalues are orthogonal,
- there is an orthonormal basis of eigenvectors, so
$$A = Q\Lambda Q^T, \qquad Q^TQ = I,$$
with the eigenvectors in the columns of $Q$ and the eigenvalues on the diagonal of $\Lambda$.

For Hermitian $A$ the same holds with $A = U\Lambda U^H$, where $U$ is **unitary** ($U^HU = I$) and $\Lambda$ is still real. In particular a symmetric or Hermitian matrix is always diagonalizable, so defective examples cannot be symmetric.

Why are eigenvectors orthogonal? If $A\mathbf{v} = \lambda\mathbf{v}$ and $A\mathbf{w} = \mu\mathbf{w}$, then $\lambda(\mathbf{w}\cdot\mathbf{v}) = \mathbf{w}\cdot A\mathbf{v} = A\mathbf{w}\cdot\mathbf{v} = \mu(\mathbf{w}\cdot\mathbf{v})$, so $(\lambda - \mu)(\mathbf{w}\cdot\mathbf{v}) = 0$. When $\lambda \neq \mu$, the dot product is zero.

Writing $A = Q\Lambda Q^T$ column by column gives
$$A = \lambda_1\mathbf{q}_1\mathbf{q}_1^T + \cdots + \lambda_n\mathbf{q}_n\mathbf{q}_n^T,$$
a sum of eigenvalue-weighted projections onto orthogonal directions.

### Positive definite matrices

For symmetric $A$ the **quadratic form** is $\mathbf{x}^TA\mathbf{x} = \sum_{i,j}a_{ij}x_ix_j$. The matrix is **positive definite** if $\mathbf{x}^TA\mathbf{x} > 0$ for every $\mathbf{x} \neq \mathbf{0}$. For a symmetric matrix the following are equivalent:

- all eigenvalues are positive;
- all leading principal minors (determinants of the upper-left $k \times k$ blocks) are positive;
- all pivots are positive;
- $A = R^TR$ for some matrix $R$ with independent columns.

If the eigenvalues are only nonnegative the matrix is **positive semidefinite**.

```python
import numpy as np
A = np.array([[3., 2.], [2., 0.]])
vals, Q = np.linalg.eigh(A)          # eigh is for symmetric/Hermitian matrices
print(vals)                          # [-1.  4.]
print(np.allclose(Q @ np.diag(vals) @ Q.T, A))   # True
```

@example
title: Orthogonal diagonalization
problem: Write $A = \begin{bmatrix}3&2\\2&0\end{bmatrix}$ as $Q\Lambda Q^T$.
step: The trace is $3$ and the determinant is $-4$, so $\lambda^2 - 3\lambda - 4 = (\lambda - 4)(\lambda + 1) = 0$ and $\lambda = 4$ or $\lambda = -1$.
step: For $\lambda = 4$: $A - 4I = \begin{bmatrix}-1&2\\2&-4\end{bmatrix}$ gives $\mathbf{v} = (2, 1)$. For $\lambda = -1$: $A + I = \begin{bmatrix}4&2\\2&1\end{bmatrix}$ gives $\mathbf{w} = (1, -2)$.
step: As the theorem promises, $\mathbf{v}\cdot\mathbf{w} = 2 - 2 = 0$. Normalize both vectors, which have length $\sqrt5$: $\mathbf{q}_1 = \frac{1}{\sqrt5}(2, 1)$ and $\mathbf{q}_2 = \frac{1}{\sqrt5}(1, -2)$.
step: Then $Q = [\mathbf{q}_1\ \mathbf{q}_2]$ and $\Lambda = \operatorname{diag}(4, -1)$. Check with the projection form: $4\mathbf{q}_1\mathbf{q}_1^T - \mathbf{q}_2\mathbf{q}_2^T = \frac45\begin{bmatrix}4&2\\2&1\end{bmatrix} - \frac15\begin{bmatrix}1&-2\\-2&4\end{bmatrix} = \begin{bmatrix}3&2\\2&0\end{bmatrix}$.

@example
title: Testing positive definiteness
problem: Decide whether $A = \begin{bmatrix}2&-1&0\\-1&2&-1\\0&-1&2\end{bmatrix}$ and $B = \begin{bmatrix}1&2\\2&1\end{bmatrix}$ are positive definite.
step: For $A$, the leading minors are $\det[2] = 2$, then $\det\begin{bmatrix}2&-1\\-1&2\end{bmatrix} = 3$, then $\det A = 2(4 - 1) - (-1)(-2) = 4$. All are positive.
step: So $A$ is positive definite. Consistently, its eigenvalues are $2 - \sqrt2$, $2$ and $2 + \sqrt2$, all positive, with product $2(4 - 2) = 4 = \det A$.
step: For $B$, the leading minors are $1$ and $1 - 4 = -3$. The second is negative, so $B$ is not positive definite.
step: Find a witness: for $\mathbf{x} = (1, -1)$, $\mathbf{x}^TB\mathbf{x} = 1 - 2 - 2 + 1 = -2 < 0$. The eigenvalues of $B$ are $3$ and $-1$.

@mistakes
- Believing that every symmetric matrix with positive entries is positive definite. $\begin{bmatrix}1&2\\2&1\end{bmatrix}$ has all positive entries and an eigenvalue $-1$.
- Using the plain transpose for complex matrices. The correct operation is the conjugate transpose $A^H$.
- Testing only the diagonal entries or only the determinant for positive definiteness. All leading minors must be positive.

@practice list
prompt: Find the eigenvalues of the symmetric matrix $\begin{bmatrix}5&2\\2&2\end{bmatrix}$.
answer: 6, 1
check: np.linalg.eigvalsh(np.array([[5,2],[2,2]]))
hint: The trace is $7$ and the determinant is $6$.
solution: $\lambda^2 - 7\lambda + 6 = (\lambda - 6)(\lambda - 1) = 0$, so the eigenvalues are $6$ and $1$.

@practice num
prompt: For $A = \begin{bmatrix}2&-1\\-1&3\end{bmatrix}$ and $\mathbf{x} = (1, 2)$, compute the quadratic form $\mathbf{x}^TA\mathbf{x}$.
answer: 10
check: np.array([1,2]) @ np.array([[2,-1],[-1,3]]) @ np.array([1,2])
hint: First compute $A\mathbf{x}$, then take the dot product with $\mathbf{x}$.
solution: $A\mathbf{x} = (2 - 2,\ -1 + 6) = (0, 5)$, and $\mathbf{x}\cdot A\mathbf{x} = 0 + 10 = 10$. Equivalently $2(1)^2 + 2(-1)(1)(2) + 3(2)^2 = 2 - 4 + 12 = 10$.

@practice num

@practice self
prompt: Prove that eigenvectors of a real symmetric matrix $A$ belonging to different eigenvalues are orthogonal.
hint: Let $A\mathbf{v} = \lambda\mathbf{v}$ and $A\mathbf{w} = \mu\mathbf{w}$. Compute $\mathbf{w}^TA\mathbf{v}$ in two ways.
solution: First, $\mathbf{w}^TA\mathbf{v} = \mathbf{w}^T(\lambda\mathbf{v}) = \lambda\,\mathbf{w}^T\mathbf{v}$. Second, since $A^T = A$, $\mathbf{w}^TA\mathbf{v} = (A\mathbf{w})^T\mathbf{v} = \mu\,\mathbf{w}^T\mathbf{v}$. Subtracting gives $(\lambda - \mu)\,\mathbf{w}^T\mathbf{v} = 0$. Because $\lambda \ne \mu$, we get $\mathbf{w}^T\mathbf{v} = 0$.
rubric: Computes $\mathbf{w}^TA\mathbf{v}$ using $A\mathbf{v} = \lambda\mathbf{v}$ to get $\lambda\,\mathbf{w}^T\mathbf{v}$.
rubric: Uses $A^T = A$ to move $A$ across and obtain $\mu\,\mathbf{w}^T\mathbf{v}$.
rubric: Concludes $\mathbf{w}^T\mathbf{v} = 0$ from $\lambda \ne \mu$.

@quiz list
prompt: Find the eigenvalues of the Hermitian matrix $\begin{bmatrix}2&1-i\\1+i&3\end{bmatrix}$.
answer: 1, 4
check: np.linalg.eigvalsh(np.array([[2,1-1j],[1+1j,3]]))
hint: The trace is $5$. For the determinant, $(1 - i)(1 + i) = |1 - i|^2 = 2$.
solution: $\det = 2\cdot 3 - (1-i)(1+i) = 6 - 2 = 4$. So $\lambda^2 - 5\lambda + 4 = (\lambda - 1)(\lambda - 4) = 0$. The eigenvalues are real, as the theorem requires: $1$ and $4$.

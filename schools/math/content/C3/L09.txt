@article
So far vectors have been added and scaled. The **inner product** adds lengths and angles, and with them the idea of perpendicularity.

### Dot product, length, angle

For $\mathbf{u}, \mathbf{v}$ in $\mathbb{R}^n$,
$$\mathbf{u}\cdot\mathbf{v} = \mathbf{u}^T\mathbf{v} = u_1v_1 + \cdots + u_nv_n, \qquad \|\mathbf{v}\| = \sqrt{\mathbf{v}\cdot\mathbf{v}}.$$
The angle $\theta$ between nonzero vectors satisfies
$$\cos\theta = \frac{\mathbf{u}\cdot\mathbf{v}}{\|\mathbf{u}\|\,\|\mathbf{v}\|}.$$
Vectors are **orthogonal** when $\mathbf{u}\cdot\mathbf{v} = 0$. Then the Pythagorean theorem holds: $\|\mathbf{u} + \mathbf{v}\|^2 = \|\mathbf{u}\|^2 + \|\mathbf{v}\|^2$.

### General inner products

An **inner product** on a real vector space is a rule that assigns a number $\langle \mathbf{u}, \mathbf{v}\rangle$ to each pair of vectors, with

1. symmetry: $\langle\mathbf{u},\mathbf{v}\rangle = \langle\mathbf{v},\mathbf{u}\rangle$;
2. linearity in each slot;
3. positivity: $\langle\mathbf{v},\mathbf{v}\rangle > 0$ for every $\mathbf{v} \neq \mathbf{0}$.

Length and angle are defined from it exactly as above. Examples: $2u_1v_1 + 3u_2v_2$ on $\mathbb{R}^2$, and $\langle f, g\rangle = \int_0^1 f(x)g(x)\,dx$ on functions. For complex vectors the rule is $\langle\mathbf{u},\mathbf{v}\rangle = \mathbf{u}^H\mathbf{v} = \sum_i \overline{u_i}\,v_i$, where the bar is complex conjugation (here the first argument is conjugated). This keeps $\langle\mathbf{v},\mathbf{v}\rangle = \sum|v_i|^2$ positive.

### Two inequalities

$$|\langle\mathbf{u},\mathbf{v}\rangle| \le \|\mathbf{u}\|\,\|\mathbf{v}\| \quad\text{(Cauchy-Schwarz)}, \qquad \|\mathbf{u}+\mathbf{v}\| \le \|\mathbf{u}\| + \|\mathbf{v}\| \quad\text{(triangle inequality)}.$$
Cauchy-Schwarz is what guarantees $|\cos\theta| \le 1$.

### Orthogonal complements

The **orthogonal complement** $S^\perp$ of a subspace $S \subseteq \mathbb{R}^n$ is the set of all vectors orthogonal to every vector in $S$. It is a subspace, and $\dim S + \dim S^\perp = n$. The equation $A\mathbf{x} = \mathbf{0}$ says that $\mathbf{x}$ is orthogonal to every row of $A$, so
$$N(A) = C(A^T)^\perp, \qquad N(A^T) = C(A)^\perp.$$

### Orthonormal bases

Vectors $\mathbf{q}_1, \dots, \mathbf{q}_n$ are **orthonormal** if $\mathbf{q}_i\cdot\mathbf{q}_j$ equals $1$ when $i = j$ and $0$ otherwise. In such a basis, coordinates need no elimination: if $\mathbf{v} = \sum c_i\mathbf{q}_i$ then $c_i = \mathbf{q}_i\cdot\mathbf{v}$. The matrix $Q$ with these columns satisfies $Q^TQ = I$ and preserves lengths: $\|Q\mathbf{x}\| = \|\mathbf{x}\|$.

```python
import numpy as np
u, v = np.array([1., 2., 2.]), np.array([3., 0., 4.])
c = u @ v / (np.linalg.norm(u) * np.linalg.norm(v))
print(u @ v, np.degrees(np.arccos(c)))   # 11.0 and about 42.8
```

@example
title: Angle between two vectors
problem: Find the angle between $\mathbf{u} = (1, 2, 2)$ and $\mathbf{v} = (3, 0, 4)$.
step: Dot product: $\mathbf{u}\cdot\mathbf{v} = 3 + 0 + 8 = 11$.
step: Lengths: $\|\mathbf{u}\| = \sqrt{1 + 4 + 4} = 3$ and $\|\mathbf{v}\| = \sqrt{9 + 16} = 5$.
step: $\cos\theta = \dfrac{11}{3 \cdot 5} = \dfrac{11}{15} \approx 0.733$, so $\theta \approx 42.8^\circ$.
step: Cauchy-Schwarz check: $|\mathbf{u}\cdot\mathbf{v}| = 11 \le 15 = \|\mathbf{u}\|\|\mathbf{v}\|$, as it must be.

@example
title: An orthogonal complement
problem: Find $S^\perp$ for $S = \operatorname{span}\{(1, 1, 0),\ (0, 1, 1)\}$ in $\mathbb{R}^3$.
step: A vector $\mathbf{x} = (x, y, z)$ is in $S^\perp$ exactly when it is orthogonal to both spanning vectors. That is $A\mathbf{x} = \mathbf{0}$ where the rows of $A$ are $(1, 1, 0)$ and $(0, 1, 1)$.
step: The equations are $x + y = 0$ and $y + z = 0$. The variable $z$ is free. Setting $z = 1$ gives $y = -1$ and $x = 1$.
step: So $S^\perp = \operatorname{span}\{(1, -1, 1)\}$. Check: $(1, -1, 1)\cdot(1, 1, 0) = 0$ and $(1, -1, 1)\cdot(0, 1, 1) = 0$.
step: Dimensions: $\dim S + \dim S^\perp = 2 + 1 = 3 = n$.

@mistakes
- Forgetting the square roots: the length is $\sqrt{\mathbf{v}\cdot\mathbf{v}}$, not $\mathbf{v}\cdot\mathbf{v}$.
- Concluding "$\mathbf{u}\cdot\mathbf{v} = \mathbf{u}\cdot\mathbf{w}$ means $\mathbf{v} = \mathbf{w}$". Only $\mathbf{u}\cdot(\mathbf{v} - \mathbf{w}) = 0$ follows.
- Saying that $N(A)$ is orthogonal to the column space. It is orthogonal to the row space $C(A^T)$.

@practice self
prompt: Prove that if $A\mathbf{x} = \mathbf{0}$, then $\mathbf{x}$ is orthogonal to every vector in the row space of $A$. What does this say about $N(A)$ and $C(A^T)$?
hint: The row space is spanned by the rows of $A$. What does the $i$-th entry of $A\mathbf{x}$ equal?
hint: A vector orthogonal to each spanning vector is orthogonal to every combination of them.
solution: The $i$-th entry of $A\mathbf{x}$ is (row $i$ of $A$)$\cdot\mathbf{x}$, so $A\mathbf{x} = \mathbf{0}$ means $\mathbf{x}$ is orthogonal to every row. A vector in the row space is a combination $\sum c_i\,\text{row}_i$, and $\left(\sum c_i\,\text{row}_i\right)\cdot\mathbf{x} = \sum c_i(\text{row}_i\cdot\mathbf{x}) = 0$. Hence $N(A) \subseteq C(A^T)^\perp$. In fact $N(A) = C(A^T)^\perp$ (a vector orthogonal to every row satisfies $A\mathbf{x} = \mathbf{0}$), and $\dim N(A) + \dim C(A^T) = n$.
rubric: Identifies each entry of $A\mathbf{x}$ as a row-times-$\mathbf{x}$ dot product.
rubric: Extends orthogonality from the rows to arbitrary linear combinations of the rows.
rubric: States the conclusion $N(A) \perp C(A^T)$, that is $N(A) \subseteq C(A^T)^\perp$ (in fact $N(A) = C(A^T)^\perp$).

@quiz num
prompt: The vectors $\mathbf{q}_1 = \tfrac13(1, 2, 2)$, $\mathbf{q}_2 = \tfrac13(2, 1, -2)$, $\mathbf{q}_3 = \tfrac13(2, -2, 1)$ form an orthonormal basis of $\mathbb{R}^3$. Write $(3, 6, 0) = c_1\mathbf{q}_1 + c_2\mathbf{q}_2 + c_3\mathbf{q}_3$. Find $c_3$.
answer: -2

hint: In an orthonormal basis, $c_i = \mathbf{q}_i\cdot\mathbf{v}$.
solution: $c_3 = \mathbf{q}_3\cdot(3, 6, 0) = \tfrac13(6 - 12 + 0) = -2$. (The other coefficients are $c_1 = 5$ and $c_2 = 4$.)

@quiz ms
prompt: Select every statement that is true.
choice*: If $\mathbf{u}\cdot\mathbf{v} = 0$, then $\|\mathbf{u} + \mathbf{v}\|^2 = \|\mathbf{u}\|^2 + \|\mathbf{v}\|^2$.
choice*: Two nonzero orthogonal vectors in $\mathbb{R}^2$ are linearly independent.
choice*: $|\mathbf{u}\cdot\mathbf{v}| \le \|\mathbf{u}\|\,\|\mathbf{v}\|$ for all $\mathbf{u}$ and $\mathbf{v}$.
choice: If $\mathbf{u}\cdot\mathbf{v} = \mathbf{u}\cdot\mathbf{w}$ and $\mathbf{u} \ne \mathbf{0}$, then $\mathbf{v} = \mathbf{w}$.
choice: The null space of $A$ is orthogonal to the column space of $A$.
hint: Expand $\|\mathbf{u}+\mathbf{v}\|^2$ as $(\mathbf{u}+\mathbf{v})\cdot(\mathbf{u}+\mathbf{v})$, and test the statements about $\mathbf{u}\cdot\mathbf{v} = \mathbf{u}\cdot\mathbf{w}$ and about the null space and column space with small examples.
solution: Expanding gives $\|\mathbf{u}\|^2 + 2\mathbf{u}\cdot\mathbf{v} + \|\mathbf{v}\|^2$. If $c_1\mathbf{u} + c_2\mathbf{v} = \mathbf{0}$, taking the dot product with $\mathbf{u}$ gives $c_1\|\mathbf{u}\|^2 = 0$, so $c_1 = 0$, and likewise $c_2 = 0$. Cauchy-Schwarz holds always. For $\mathbf{u} = (1, 0)$, $\mathbf{v} = (0, 1)$, $\mathbf{w} = (0, 2)$ we have $\mathbf{u}\cdot\mathbf{v} = \mathbf{u}\cdot\mathbf{w}$ but $\mathbf{v} \ne \mathbf{w}$. The null space is orthogonal to the row space, not to the column space.

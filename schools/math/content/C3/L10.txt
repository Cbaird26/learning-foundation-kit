@article
When $A\mathbf{x} = \mathbf{b}$ has no solution, $\mathbf{b}$ lies outside the column space $C(A)$. The best we can do is to find the point of $C(A)$ **closest** to $\mathbf{b}$. That point is the orthogonal projection.

### Projection onto a line

The projection of $\mathbf{b}$ onto the line through $\mathbf{a}$ is the multiple $\mathbf{p} = \hat{x}\,\mathbf{a}$ for which the error $\mathbf{e} = \mathbf{b} - \mathbf{p}$ is orthogonal to $\mathbf{a}$. Setting $\mathbf{a}\cdot(\mathbf{b} - \hat{x}\mathbf{a}) = 0$ gives
$$\hat{x} = \frac{\mathbf{a}\cdot\mathbf{b}}{\mathbf{a}\cdot\mathbf{a}}, \qquad \mathbf{p} = \frac{\mathbf{a}\cdot\mathbf{b}}{\mathbf{a}\cdot\mathbf{a}}\,\mathbf{a}.$$

### Projection onto a subspace and the normal equations

Let the columns of $A$ be independent, so they are a basis of $C(A)$. We want $\hat{\mathbf{x}}$ so that $\mathbf{p} = A\hat{\mathbf{x}}$ and the **residual** $\mathbf{r} = \mathbf{b} - A\hat{\mathbf{x}}$ is orthogonal to every column of $A$. That condition is $A^T\mathbf{r} = \mathbf{0}$:
$$A^T(\mathbf{b} - A\hat{\mathbf{x}}) = \mathbf{0} \quad\Longrightarrow\quad A^TA\,\hat{\mathbf{x}} = A^T\mathbf{b}.$$
These are the **normal equations**. When the columns are independent, $A^TA$ is invertible, so
$$\hat{\mathbf{x}} = (A^TA)^{-1}A^T\mathbf{b}, \qquad \mathbf{p} = P\mathbf{b}, \quad P = A(A^TA)^{-1}A^T.$$
A projection matrix satisfies $P^2 = P$ and $P^T = P$: projecting twice changes nothing.

### Least squares and the residual

The same $\hat{\mathbf{x}}$ minimizes $\|\mathbf{b} - A\mathbf{x}\|^2$ over all $\mathbf{x}$. (Calculus gives the same equations: the gradient of $\|\mathbf{b} - A\mathbf{x}\|^2$ is $-2A^T(\mathbf{b} - A\mathbf{x})$.) Because $\mathbf{p}$ and $\mathbf{r}$ are orthogonal, Pythagoras gives $\|\mathbf{b}\|^2 = \|\mathbf{p}\|^2 + \|\mathbf{r}\|^2$. The minimum value $\|\mathbf{r}\|^2$ is the **sum of squared residuals**. For a line fit $y = c + dt$ each residual is a vertical gap between a data point and the line. Since $\mathbf{r}$ is orthogonal to the column of ones, the residuals sum to zero.

### Gram-Schmidt

To replace independent vectors $\mathbf{a}_1, \mathbf{a}_2, \dots$ by orthonormal ones, take $\mathbf{q}_1 = \mathbf{a}_1/\|\mathbf{a}_1\|$. Then subtract from each later vector its components along the earlier $\mathbf{q}$'s and normalize:
$$\mathbf{v}_2 = \mathbf{a}_2 - (\mathbf{q}_1\cdot\mathbf{a}_2)\mathbf{q}_1, \qquad \mathbf{q}_2 = \mathbf{v}_2/\|\mathbf{v}_2\|.$$
This produces $A = QR$ with $Q$ orthonormal columns and $R$ upper triangular, and the normal equations become $R\hat{\mathbf{x}} = Q^T\mathbf{b}$.

```python
import numpy as np
t = np.array([0., 1., 2., 3.]); y = np.array([1., 2., 2., 4.])
A = np.column_stack([np.ones_like(t), t])
xhat = np.linalg.solve(A.T @ A, A.T @ y)
print(xhat, y - A @ xhat)   # [0.9 0.9] and residuals [ 0.1  0.2 -0.7  0.4]
```

@example
title: Fitting a line by least squares
problem: Fit $y = c + dt$ to the points $(0, 1)$, $(1, 2)$, $(2, 2)$, $(3, 4)$. Find the residuals and check that they are orthogonal to the columns of $A$.
step: The equations $c + dt_i = y_i$ form $A\mathbf{x} = \mathbf{b}$ with $A = \begin{bmatrix}1&0\\1&1\\1&2\\1&3\end{bmatrix}$, $\mathbf{x} = (c, d)$ and $\mathbf{b} = (1, 2, 2, 4)$. There are four equations in two unknowns, so there is no exact solution.
step: Compute $A^TA = \begin{bmatrix}4&6\\6&14\end{bmatrix}$ and $A^T\mathbf{b} = (9,\ 18)$.
step: Solve $4c + 6d = 9$ and $6c + 14d = 18$. The determinant is $56 - 36 = 20$, giving $c = \frac{126 - 108}{20} = 0.9$ and $d = \frac{72 - 54}{20} = 0.9$. The best line is $y = 0.9 + 0.9t$.
step: The fitted values are $0.9, 1.8, 2.7, 3.6$, so the residual vector is $\mathbf{r} = (0.1,\ 0.2,\ -0.7,\ 0.4)$.
step: Check $A^T\mathbf{r} = \mathbf{0}$: the sum of the entries is $0.1 + 0.2 - 0.7 + 0.4 = 0$ and the weighted sum is $0 + 0.2 - 1.4 + 1.2 = 0$. The least squares error is $\|\mathbf{r}\|^2 = 0.01 + 0.04 + 0.49 + 0.16 = 0.70$.

@example
title: Gram-Schmidt on two vectors
problem: Apply Gram-Schmidt to $\mathbf{a}_1 = (1, 1, 0)$ and $\mathbf{a}_2 = (1, 0, 1)$.
step: Normalize the first vector: $\|\mathbf{a}_1\| = \sqrt2$, so $\mathbf{q}_1 = \frac{1}{\sqrt2}(1, 1, 0)$.
step: Find the component of $\mathbf{a}_2$ along $\mathbf{q}_1$: $\mathbf{q}_1\cdot\mathbf{a}_2 = \frac{1}{\sqrt2}$. Subtract: $\mathbf{v}_2 = (1, 0, 1) - \frac{1}{\sqrt2}\cdot\frac{1}{\sqrt2}(1, 1, 0) = (\tfrac12, -\tfrac12, 1)$.
step: Normalize: $\|\mathbf{v}_2\|^2 = \frac14 + \frac14 + 1 = \frac32$, so $\mathbf{q}_2 = \frac{1}{\sqrt6}(1, -1, 2)$.
step: Check orthogonality: $\mathbf{q}_1\cdot\mathbf{q}_2 = \frac{1}{\sqrt{12}}(1 - 1 + 0) = 0$. The diagonal entries of $R$ are $\|\mathbf{a}_1\| = \sqrt2$ and $\|\mathbf{v}_2\| = \sqrt{3/2}$.

@mistakes
- Writing the normal equations as $A\hat{\mathbf{x}} = A^T\mathbf{b}$ or $A^TA\hat{\mathbf{x}} = \mathbf{b}$. Both sides need a factor $A^T$.
- Calling the residual a vector in the column space. It is orthogonal to the column space.
- Using $(A^TA)^{-1} = A^{-1}(A^T)^{-1}$ when $A$ is not square. $A$ has no inverse in general.

@practice self
prompt: Derive the least squares normal equations for minimizing $\|\mathbf{b} - A\mathbf{x}\|^2$, where $A$ has independent columns. Then explain what the residual vector $\mathbf{r} = \mathbf{b} - A\hat{\mathbf{x}}$ is orthogonal to, and what $\|\mathbf{r}\|^2$ measures.
hint: Use the geometric condition that the closest point $A\hat{\mathbf{x}}$ makes the error orthogonal to $C(A)$.
hint: Alternatively expand $\|\mathbf{b} - A\mathbf{x}\|^2 = \mathbf{b}^T\mathbf{b} - 2\mathbf{x}^TA^T\mathbf{b} + \mathbf{x}^TA^TA\mathbf{x}$ and set the gradient to zero.
solution: The point of $C(A)$ closest to $\mathbf{b}$ is $A\hat{\mathbf{x}}$, and the error $\mathbf{r} = \mathbf{b} - A\hat{\mathbf{x}}$ must be orthogonal to every vector in $C(A)$, in particular to each column of $A$. That says $A^T\mathbf{r} = \mathbf{0}$, i.e. $A^T(\mathbf{b} - A\hat{\mathbf{x}}) = \mathbf{0}$, i.e. $A^TA\hat{\mathbf{x}} = A^T\mathbf{b}$. By calculus, $\nabla\|\mathbf{b} - A\mathbf{x}\|^2 = -2A^T\mathbf{b} + 2A^TA\mathbf{x}$, which vanishes at the same equation. The residual is orthogonal to $C(A)$, and $\|\mathbf{r}\|^2$ is the sum of squared residuals, the smallest achievable squared error. Since $\mathbf{p} = A\hat{\mathbf{x}}$ and $\mathbf{r}$ are orthogonal, $\|\mathbf{b}\|^2 = \|\mathbf{p}\|^2 + \|\mathbf{r}\|^2$.

rubric: States that the residual is orthogonal to $C(A)$, equivalently that $A^T\mathbf{r} = \mathbf{0}$.
rubric: Interprets $\|\mathbf{r}\|^2$ as the minimum sum of squared residuals.

@quiz mc
prompt: Let $P = A(A^TA)^{-1}A^T$ be the projection matrix onto the column space of a matrix $A$ with independent columns. Which statement is true?
choice*: $P^2 = P$ and $P^T = P$.
choice: $P^2 = I$.
choice: $P$ is always invertible.
choice: $P\mathbf{b}$ is always longer than $\mathbf{b}$.
hint: Think geometrically: what happens when you project a vector that is already in the column space?
solution: Projecting a vector already in $C(A)$ leaves it unchanged, so projecting twice equals projecting once: $P^2 = P$. Algebraically $P^2 = A(A^TA)^{-1}A^TA(A^TA)^{-1}A^T = P$, and $P^T = P$ because $(A^TA)^{-1}$ is symmetric. A projection onto a proper subspace sends the component orthogonal to it to $\mathbf{0}$, so it is not invertible, and it never lengthens a vector.

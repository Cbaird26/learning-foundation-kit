@article
A matrix is an array of numbers, and the operations on matrices are designed so that they describe what happens to systems of equations.

### Multiplication

If $A$ is $m \times n$ and $B$ is $n \times p$, the product $AB$ is $m \times p$. The inner sizes must match. The entry in row $i$, column $j$ is the dot product of row $i$ of $A$ with column $j$ of $B$:
$$(AB)_{ij} = \sum_{k=1}^{n} a_{ik}\, b_{kj}.$$
There is a second view that is often more useful. The product $A\mathbf{x}$ is a **combination of the columns of $A$**, with the entries of $\mathbf{x}$ as weights. Each column of $AB$ is $A$ times the matching column of $B$.

### What survives and what does not

Matrix multiplication is associative, $A(BC) = (AB)C$, and distributive, $A(B+C) = AB + AC$. It is **not commutative**. For
$$A = \begin{bmatrix}1&1\\0&1\end{bmatrix},\quad B = \begin{bmatrix}1&0\\1&1\end{bmatrix}$$
you get $AB = \begin{bmatrix}2&1\\1&1\end{bmatrix}$ but $BA = \begin{bmatrix}1&1\\1&2\end{bmatrix}$.

Two reversal rules are worth memorising:
$$(AB)^T = B^T A^T, \qquad (AB)^{-1} = B^{-1}A^{-1}.$$

### Inverses

A square matrix $A$ is **invertible** if some matrix $A^{-1}$ satisfies $AA^{-1} = A^{-1}A = I$. This happens exactly when elimination produces $n$ pivots. For a $2\times 2$ matrix,
$$\begin{bmatrix}a&b\\c&d\end{bmatrix}^{-1} = \frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}, \qquad ad - bc \neq 0.$$
In general, row reduce the block $[A \mid I]$ until the left block becomes $I$. The right block is then $A^{-1}$. When $A$ is invertible, $A\mathbf{x} = \mathbf{b}$ has the unique solution $\mathbf{x} = A^{-1}\mathbf{b}$.

### Elimination as multiplication

Each row operation is multiplication on the left by an **elementary matrix**. Recording the multipliers of forward elimination gives, when no row swaps are needed, the factorization $A = LU$, with $L$ lower triangular (the multipliers) and $U$ upper triangular (the pivots). Solving with $L$ and $U$ is cheap, which is how software solves large systems.

### Counting solutions with rank

The **rank** of a matrix is its number of pivots. For $A\mathbf{x} = \mathbf{b}$ with $n$ unknowns:

| Comparison | Outcome |
|---|---|
| $\operatorname{rank} A < \operatorname{rank}[A \mid \mathbf{b}]$ | no solution |
| $\operatorname{rank} A = \operatorname{rank}[A \mid \mathbf{b}] = n$ | exactly one solution |
| $\operatorname{rank} A = \operatorname{rank}[A \mid \mathbf{b}] < n$ | infinitely many solutions |

```python
import numpy as np
A = np.array([[1, 1, 1], [1, 2, 3], [2, 3, 4]])
b = np.array([1, 2, 4])
print(np.linalg.matrix_rank(A), np.linalg.matrix_rank(np.column_stack([A, b])))  # 2 3
```

@example
title: Inverse by row reduction, then solving
problem: Find $A^{-1}$ for $A = \begin{bmatrix}2&1\\5&3\end{bmatrix}$ and use it to solve $A\mathbf{x} = \begin{bmatrix}1\\2\end{bmatrix}$.
step: Form $[A \mid I]$ with rows $[2\ 1 \mid 1\ 0]$ and $[5\ 3 \mid 0\ 1]$.
step: Scale row 1 by $\tfrac12$ to get $[1\ \tfrac12 \mid \tfrac12\ 0]$. Then $R_2 \to R_2 - 5R_1$ gives $[0\ \tfrac12 \mid -\tfrac52\ 1]$.
step: Scale row 2 by $2$ to get $[0\ 1 \mid -5\ 2]$. Then $R_1 \to R_1 - \tfrac12 R_2$ gives $[1\ 0 \mid 3\ -1]$.
step: The right block is $A^{-1} = \begin{bmatrix}3&-1\\-5&2\end{bmatrix}$. Check with the $2\times 2$ formula: $ad - bc = 6 - 5 = 1$, which agrees.
step: Multiply: $\mathbf{x} = A^{-1}\mathbf{b} = \begin{bmatrix}3(1) - 1(2)\\-5(1) + 2(2)\end{bmatrix} = \begin{bmatrix}1\\-1\end{bmatrix}$. Check: $2(1) + (-1) = 1$ and $5(1) + 3(-1) = 2$.

@example
title: Absent and nonunique solutions
problem: Decide how many solutions $x + y + z = 1$, $x + 2y + 3z = 2$, $2x + 3y + 4z = c$ has for $c = 4$ and for $c = 3$.
step: Augmented matrix: rows $[1\ 1\ 1 \mid 1]$, $[1\ 2\ 3 \mid 2]$, $[2\ 3\ 4 \mid c]$.
step: Apply $R_2 \to R_2 - R_1$ and $R_3 \to R_3 - 2R_1$. The rows are $[1\ 1\ 1 \mid 1]$, $[0\ 1\ 2 \mid 1]$, $[0\ 1\ 2 \mid c - 2]$.
step: Apply $R_3 \to R_3 - R_2$. The last row is $[0\ 0\ 0 \mid c - 3]$. The coefficient matrix has rank $2$.
step: For $c = 4$ the last row is $[0\ 0\ 0 \mid 1]$: the augmented rank is $3 > 2$, so there is **no solution**.
step: For $c = 3$ the last row is zero: both ranks are $2 < 3$ unknowns, so there are **infinitely many solutions**, with $z$ free.

@mistakes
- Assuming $AB = BA$, for instance expanding $(A+B)^2$ as $A^2 + 2AB + B^2$.
- Writing $(AB)^{-1} = A^{-1}B^{-1}$. The order reverses: $(AB)^{-1} = B^{-1}A^{-1}$.
- Using the $2 \times 2$ inverse formula without checking that $ad - bc \neq 0$.

@practice num
prompt: Let $A = \begin{bmatrix}1&2\\0&3\end{bmatrix}$ and $B = \begin{bmatrix}4&1\\2&5\end{bmatrix}$. What is the entry in row 2, column 1 of $AB$?
answer: 6
check: (np.array([[1,2],[0,3]]) @ np.array([[4,1],[2,5]]))[1,0]
hint: Take the dot product of row 2 of $A$ with column 1 of $B$.
solution: Row 2 of $A$ is $(0, 3)$ and column 1 of $B$ is $(4, 2)$. Their dot product is $0 \cdot 4 + 3 \cdot 2 = 6$.

@practice mc
prompt: Which identity holds for all matrices for which the products involved are defined?
choice*: $(AB)^T = B^T A^T$
choice: $(AB)^{-1} = A^{-1}B^{-1}$ whenever both factors are invertible
choice: $AB = BA$
choice: $(A+B)^2 = A^2 + 2AB + B^2$
hint: Test each statement with the two $2\times 2$ matrices from the article.
solution: Only the transpose rule is always true. The inverse of a product reverses the order, and $AB \neq BA$ in general, which also breaks the expansion of $(A+B)^2$ into $A^2 + 2AB + B^2$: the true expansion is $A^2 + AB + BA + B^2$.

@practice num
prompt: Find the entry in row 1, column 2 of $A^{-1}$ for $A = \begin{bmatrix}4&7\\1&2\end{bmatrix}$.
answer: -7
check: np.linalg.inv(np.array([[4,7],[1,2]]))[0,1]
hint: Use the $2\times 2$ formula. First compute $ad - bc$.
hint: Here $ad - bc = 8 - 7 = 1$, and the (1,2) entry of the inverse is $-b/(ad-bc)$.
solution: $ad - bc = 8 - 7 = 1$, so $A^{-1} = \begin{bmatrix}2&-7\\-1&4\end{bmatrix}$. The requested entry is $-7$.

@practice tuple
prompt: Solve $\begin{bmatrix}3&1\\5&2\end{bmatrix}\mathbf{x} = \begin{bmatrix}4\\3\end{bmatrix}$ using the inverse of the coefficient matrix. Enter $(x_1, x_2)$.
answer: (5, -11)

@practice num
prompt: For which value of $c$ does $x + y + z = 1$, $x + 2y + 3z = 2$, $2x + 3y + 4z = c$ have infinitely many solutions?
answer: 3
check: root(lambda c: det([[1,1,1],[1,2,2],[2,3,c]]), 0, 10)
hint: Eliminate to find the last row of the augmented matrix. The coefficient matrix has rank $2$.
hint: The last row should come out as $[0\ 0\ 0 \mid c - 3]$.
solution: Forward elimination gives the last row $[0\ 0\ 0 \mid c - 3]$. If $c \neq 3$ the system has no solution. If $c = 3$ then $\operatorname{rank} A = \operatorname{rank}[A \mid \mathbf{b}] = 2 < 3$, so there are infinitely many solutions.

@quiz num
prompt: Let $A = \begin{bmatrix}1&1\\0&1\end{bmatrix}$ and $B = \begin{bmatrix}1&0\\1&1\end{bmatrix}$. What is the entry in row 1, column 1 of $AB - BA$?
answer: 1
check: (np.array([[1,1],[0,1]]) @ np.array([[1,0],[1,1]]) - np.array([[1,0],[1,1]]) @ np.array([[1,1],[0,1]]))[0,0]
hint: Compute both products, or only their (1,1) entries.
solution: Row 1 of $A$ times column 1 of $B$ gives $1 \cdot 1 + 1 \cdot 1 = 2$ for $AB$. Row 1 of $B$ times column 1 of $A$ gives $1 \cdot 1 + 0 \cdot 0 = 1$ for $BA$. The difference is $2 - 1 = 1$.

@quiz expr

@article
A population grows, a hot cup cools, a chemical decays. In each case the rate of change depends only on the current state: $\dot{x} = f(x)$, where $\dot{x} = dx/dt$. Can you say where a solution ends up as $t \to \infty$ without solving the equation? On the line, yes: the sign of $f$ tells you which way the point moves, and that is almost all there is to know.

### Fixed points and stability

An equation $\dot{x} = f(x)$ with $f\colon \mathbb{R} \to \mathbb{R}$ continuously differentiable is called a **one-dimensional flow**. A **fixed point** (equilibrium) is a number $x^*$ with $f(x^*) = 0$: the constant function $x(t) = x^*$ is a solution. A fixed point is **stable** if every solution that starts close enough to $x^*$ tends to $x^*$ as $t \to \infty$, and **unstable** if solutions starting arbitrarily close leave a neighborhood of it. It is **half-stable** if it attracts from one side and repels on the other.

**Theorem 1 (existence and uniqueness; Picard–Lindelöf).** If $f$ is continuously differentiable, then for each $x_0$ the problem $\dot{x} = f(x)$, $x(0) = x_0$ has a unique solution on a maximal time interval. *(Stated without proof; the proof is a contraction argument in a function space.)* Without differentiability uniqueness can fail: $\dot{x} = \sqrt{|x|}$ has both $x(t) = 0$ and $x(t) = t^2/4$ ($t \ge 0$) starting at $0$. A consequence: a solution can never reach a fixed point in finite time, since the constant solution already goes through it.

**Theorem 2 (monotone convergence).** Let $f$ be continuously differentiable and let $x(t)$ be a solution with $f(x(0)) \ne 0$ that stays bounded for all $t \ge 0$. Then $x(t)$ is monotone and tends to a fixed point.

*Proof.* The zeros of $f$ cut the line into open intervals on each of which $f$ has one sign (a continuous function that changes sign has a zero, by the intermediate value theorem). By Theorem 1, $x(t)$ never meets a zero of $f$, so it stays in one interval, and $\dot{x} = f(x(t))$ has one sign: $x$ is monotone. A bounded monotone function has a limit $L$. Suppose $f(L) \ne 0$. Then $x(t+1) - x(t) = \int_t^{t+1} f(x(s))\,ds \to f(L) \ne 0$, but the left side tends to $L - L = 0$, a contradiction. So $f(L) = 0$. $\blacksquare$

**Theorem 3 (linear stability).** If $f(x^*) = 0$ and $f'(x^*) < 0$, then $x^*$ is stable; if $f'(x^*) > 0$, it is unstable.

*Proof for $f'(x^*) < 0$.* By continuity $f' < 0$ on some interval $I = (x^* - \delta, x^* + \delta)$, so $f$ is strictly decreasing on $I$ with $f(x^*) = 0$: $f > 0$ to the left of $x^*$ and $f < 0$ to the right. A solution starting in $I$ moves toward $x^*$, never leaves $I$, and by Theorem 2 converges to a fixed point in $\overline{I}$, which can only be $x^*$ if $\delta$ is chosen so that $x^*$ is the only zero there. The case $f'(x^*) > 0$ is the same with time reversed. $\blacksquare$

If $f'(x^*) = 0$ the test says nothing: $\dot{x} = -x^3$ (stable), $\dot{x} = x^3$ (unstable) and $\dot{x} = x^2$ (half-stable) all have $f'(0) = 0$. Then look at the sign of $f$ on both sides.

### Euler's method and its limits

Euler's method replaces the flow by $x_{n+1} = x_n + h f(x_n)$. For $\dot{x} = -\lambda x$ with $\lambda > 0$ this gives $x_n = (1 - \lambda h)^n x_0$, which tends to $0$ if and only if $|1 - \lambda h| < 1$, that is, $0 < h < 2/\lambda$. The exact flow always decays; the numerical one oscillates with growing amplitude when $h > 2/\lambda$. So a step size must be small compared with the fastest time scale $1/|f'|$.

### Bisection

**Theorem 4 (bisection).** If $g$ is continuous on $[a, b]$ and $g(a)\,g(b) < 0$, then keeping the half-interval whose endpoints have opposite signs, $n$ times, leaves an interval of length $(b - a)/2^n$ that contains a zero of $g$; its midpoint is within $(b-a)/2^{n+1}$ of that zero.

*Proof.* The invariant "endpoint values have opposite signs" holds at the start and is kept by construction (if the midpoint value is $0$ we have a zero). A continuous function with opposite signs at the endpoints of an interval has a zero in it (intermediate value theorem), and each step halves the length. $\blacksquare$

```python
def euler(f, x0, h, n):
    """Return the list [x_0, ..., x_n] of Euler iterates."""
    xs = [x0]
    for _ in range(n):
        xs.append(xs[-1] + h * f(xs[-1]))
    return xs


def bisect(g, a, b, n):
    """n bisection steps; g(a) and g(b) must have opposite signs."""
    ga = g(a)
    for _ in range(n):
        m = (a + b) / 2
        gm = g(m)
        if gm == 0:
            return m
        if (gm < 0) == (ga < 0):
            a, ga = m, gm
        else:
            b = m
    return (a + b) / 2


print(round(bisect(lambda x: x * x - 2, 1, 2, 30), 6))
print(euler(lambda x: -5 * x, 1.0, 0.1, 3))
```

The first line prints `1.414214`; the second prints `[1.0, 0.5, 0.25, 0.125]`. A computation like this is evidence about a flow, and the theorems above are what justify it.

@example
title: Phase line of a quadratic flow
problem: Find the fixed points of $\dot{x} = x^2 - 4$, decide their stability, and describe the solution with $x(0) = 1$.
step: Fixed points: $x^2 - 4 = 0$ gives $x^* = \pm 2$.
step: Stability: $f'(x) = 2x$, so $f'(2) = 4 > 0$ (unstable) and $f'(-2) = -4 < 0$ (stable).
step: Sign of $f$ on each interval: $f > 0$ for $x < -2$, $f < 0$ on $(-2, 2)$, $f > 0$ for $x > 2$. The arrows on the line point toward $-2$ inside $(-2, 2)$ and away from $2$.
step: The solution with $x(0) = 1$ lies in $(-2, 2)$, where $f < 0$, so it decreases; it is bounded below by $-2$, hence by Theorem 2 it converges to $-2$ and never reaches it in finite time.
answer: Fixed points $-2$ (stable) and $2$ (unstable); the solution from $1$ decreases to $-2$.

@example
title: How large a step is too large
problem: Euler's method is applied to $\dot{x} = -5x$ with $x(0) = 1$. Compare the step sizes $h = 0.1$, $h = 0.2$ and $h = 0.5$.
step: The Euler iterates are $x_n = (1 - 5h)^n$, so the multiplier is $1 - 5h$.
step: For $h = 0.1$ the multiplier is $0.5$, so $x_n \to 0$ monotonically, like the exact solution $e^{-5t}$.
step: For $h = 0.2$ the multiplier is $0$, so $x_1 = 0$ and every later iterate is $0$.
step: For $h = 0.5$ the multiplier is $-1.5$ and $|-1.5| > 1$, so the iterates alternate in sign and grow: $1, -1.5, 2.25, \dots$. The threshold is $h = 2/5 = 0.4$.
answer: The method decays for $h < 0.4$ and diverges for $h > 0.4$, although the exact solution always decays.

@mistakes
- Using $f'(x^*) = 0$ to conclude that a fixed point is stable or unstable: the test is silent there, and $\dot{x} = x^2$ shows that the point can even be half-stable.
- Believing a solution can reach a fixed point in finite time. By uniqueness it only approaches it as $t \to \infty$.
- Reading the sign of $f'$ at the fixed point as the direction of motion elsewhere. The direction is the sign of $f$ itself on each interval between fixed points.
- Trusting a simulation whose step size is not small compared with $1/|f'|$: Euler's method can show oscillation that the flow does not have.

def classify(f, p, eps):
    """Classify a fixed point of x' = f(x) from signs on both sides."""
    left, right = f(p - eps), f(p + eps)
    if left > 0 and right < 0:
        return 'stable'
    if left < 0 and right > 0:
        return 'unstable'
    return 'half-stable'

```python
def steps_to_reach(f, x0, target, h, max_steps):
    """Euler steps until the target is reached, or None."""
    up = target >= x0
    x = x0
    for k in range(max_steps + 1):
        if (up and x >= target) or (not up and x <= target):
            return k
        x = x + h * f(x)
    return None
```
hint: Decide the direction once from `target >= x0`, then test before each step, including at step $0$.
solution: Test the stopping condition, then step; allowing `max_steps + 1` tests lets the target be reached exactly on step `max_steps`. The last test shows the boundary: ten unit steps are needed to go from $0$ to $10$, so nine are not enough.

@practice self
prompt: Prove that $\dot{x} = f(x)$, with $f$ continuously differentiable, has no nonconstant periodic solution.
hint: Use Theorem 2: what does monotone and periodic imply?
solution: Let $x(t)$ be a solution that is nonconstant and periodic with period $T > 0$. A nonconstant solution does not pass through a fixed point, so $f(x(t)) \ne 0$ for all $t$, and since $f(x(t))$ is continuous it has one sign; thus $x$ is strictly monotone. But periodicity gives $x(T) = x(0)$, which contradicts strict monotonicity. Hence no such solution exists.
rubric: Notes that a nonconstant solution never meets a fixed point (uniqueness).
rubric: Concludes that $f(x(t))$ has constant sign, so $x$ is strictly monotone.
rubric: Derives the contradiction from $x(T) = x(0)$.

model:
```python
import math


def _euler_error(lam, T, n):
    h = T / n
    x = 1.0
    for _ in range(n):
        x = x + h * (-lam * x)
    return abs(x - math.exp(-lam * T))


def error_ratio(lam, T, n):
    """E(n) / E(2n): close to 2 for a first-order method."""
    return _euler_error(lam, T, n) / _euler_error(lam, T, 2 * n)
```
hint: Write a helper that runs $n$ steps and returns the absolute error, then call it with $n$ and $2n$.
solution: Euler's method is first order: halving $h$ halves the error for small $h$, so the ratio is near $2$. This is numerical evidence for the order, not a proof; the proof compares $(1 - \lambda h)^n$ with $e^{-\lambda T}$ by Taylor expansion.

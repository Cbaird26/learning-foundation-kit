@article
Slowly turn a knob on a machine. For a while the machine settles at a steady state that moves a little with the knob; then at a critical setting the steady state vanishes and the machine jumps somewhere else. Such sudden qualitative changes are **bifurcations**. In a flow $\dot{x} = f(x, r)$ with a parameter $r$, a **bifurcation value** $r_0$ is a parameter at which the number or stability of the fixed points changes. The **bifurcation diagram** plots the fixed points $x^*$ against $r$, drawing stable branches as solid and unstable branches as dashed.

### The three local normal forms

- **Saddle-node:** $\dot{x} = r + x^2$. For $r < 0$ there are two fixed points $x = \pm\sqrt{-r}$: $-\sqrt{-r}$ is stable (since $f' = 2x < 0$) and $+\sqrt{-r}$ is unstable. At $r = 0$ they merge into the half-stable point $0$, and for $r > 0$ there is none.
- **Transcritical:** $\dot{x} = rx - x^2$. The fixed points $0$ and $r$ always exist and cross at $r = 0$ while exchanging stability: $f'(0) = r$ and $f'(r) = -r$.
- **Supercritical pitchfork:** $\dot{x} = rx - x^3$. For $r \le 0$ the origin is the only fixed point and is stable; for $r > 0$ the origin is unstable and two stable fixed points $\pm\sqrt{r}$ appear. The **subcritical pitchfork** $\dot{x} = rx + x^3$ has the unstable pair $\pm\sqrt{-r}$ for $r < 0$ and no nearby stable branch for $r > 0$, so solutions leave the neighborhood.

The pitchfork is symmetric: $f(-x, r) = -f(x, r)$. That symmetry forces the origin to be fixed for every $r$ and makes fixed points appear in pairs.

### Why the saddle-node is generic

**Theorem (saddle-node).** Let $f(x, r)$ be $C^2$ near $(x_0, r_0)$ with $f(x_0, r_0) = 0$, $f_x(x_0, r_0) = 0$, $f_{xx}(x_0, r_0) \ne 0$ and $f_r(x_0, r_0) \ne 0$. Then near $(x_0, r_0)$ the fixed points form a curve $r = g(x)$ with $g'(x_0) = 0$ and $g''(x_0) = -f_{xx}/f_r \ne 0$. Consequently, for $r$ on one side of $r_0$ there are exactly two fixed points near $x_0$ with opposite stability, and for $r$ on the other side there are none.

*Proof.* Since $f_r \ne 0$, the implicit function theorem gives a $C^2$ function $g$ with $g(x_0) = r_0$ and $f(x, g(x)) = 0$ for $x$ near $x_0$; these are all the zeros near $(x_0, r_0)$. Differentiate once: $f_x + f_r\,g' = 0$. At $x_0$, $f_x = 0$, so $g'(x_0) = 0$. Differentiate again and evaluate at $x_0$, where $g' = 0$: $f_{xx} + f_r\,g'' = 0$, so $g''(x_0) = -f_{xx}/f_r \ne 0$. Thus $g$ has a strict local extremum at $x_0$: $g(x) - r_0$ has the sign of $g''(x_0)$ on both sides of $x_0$. Parameters $r$ beyond the extreme value $r_0$ are not values of $g$ nearby (no fixed points), and parameters on the other side are taken twice, once on each side of $x_0$. For stability, $h(x) = f_x(x, g(x))$ has $h(x_0) = 0$ and $h'(x_0) = f_{xx} + f_{xr}g' = f_{xx} \ne 0$, so $h$ changes sign at $x_0$: the two fixed points have $f_x$ of opposite sign. $\blacksquare$

The hypotheses matter. The pitchfork $\dot{x} = rx - x^3$ at $(0, 0)$ has $f_{xx} = 0$ and $f_r = x = 0$, and indeed it does not behave like a saddle-node. Remove the symmetry by adding a small constant, $\dot{x} = h + rx - x^3$ (an imperfect pitchfork), and the pitchfork unfolds into a saddle-node at some $r > 0$ plus a branch that never bifurcates.

### Computing a bifurcation diagram

The function below scans $[\text{lo}, \text{hi}]$ in $n$ sub-intervals and records each sign change of $f(\cdot, r)$: from $+$ to $-$ is a stable fixed point, from $-$ to $+$ unstable.

```python
def branches(f, r, lo, hi, n):
    """Fixed points of x' = f(x, r) found by sign changes on a grid."""
    out = []
    h = (hi - lo) / n
    for i in range(n):
        a = lo + i * h
        fa, fb = f(a, r), f(a + h, r)
        if fa > 0 > fb:
            out.append((round(a + h / 2, 1) + 0.0, 'stable'))
        elif fa < 0 < fb:
            out.append((round(a + h / 2, 1) + 0.0, 'unstable'))
    return out


pitch = lambda x, r: r * x - x ** 3
print(branches(pitch, -1, -2, 2, 401))
print(branches(pitch, 1, -2, 2, 401))
```

The first call prints `[(0.0, 'stable')]`; the second prints `[(-1.0, 'stable'), (0.0, 'unstable'), (1.0, 'stable')]`. Repeating this for a grid of values of $r$ and plotting the points gives the diagram. A scan can miss two fixed points closer together than the grid spacing, which is exactly what happens just after a saddle-node, so the computed bifurcation value is accurate only to about the spacing. Use the theorem to check it.

@example
title: A saddle-node from the theorem
problem: Show that $\dot{x} = r + x - e^x$ has a saddle-node bifurcation at $r_0 = 1$, $x_0 = 0$, and describe the fixed points on each side.
step: Write $f(x, r) = r + x - e^x$. Then $f(0, 1) = 1 + 0 - 1 = 0$.
step: Compute the derivatives: $f_x = 1 - e^x$, so $f_x(0, 1) = 0$; $f_{xx} = -e^x$, so $f_{xx}(0, 1) = -1 \ne 0$; $f_r = 1 \ne 0$.
step: All four hypotheses hold, and $g''(0) = -f_{xx}/f_r = 1 > 0$: the fixed-point curve is $r = g(x) = e^x - x$, which has its minimum value $1$ at $x = 0$.
step: So for $r < 1$ there is no fixed point, and for $r > 1$ there are two, one with $x < 0$ and one with $x > 0$. Since $f(x, r) \le r - 1$ for all $x$, there are none for $r < 1$ anywhere, not just nearby.
answer: A saddle-node at $r_0 = 1$: no fixed points for $r < 1$, two for $r > 1$ with opposite stability.

@example
title: Exchange of stability in the transcritical form
problem: For $\dot{x} = rx - x^2$, classify the fixed points for $r = -1$ and $r = 1$ and say what happens at $r = 0$.
step: The fixed points are $x = 0$ and $x = r$, and $f'(x) = r - 2x$.
step: For $r = -1$: $f'(0) = -1 < 0$ so $0$ is stable, and $f'(-1) = 1 > 0$ so $-1$ is unstable.
step: For $r = 1$: $f'(0) = 1 > 0$ so $0$ is unstable, and $f'(1) = -1 < 0$ so $1$ is stable.
step: At $r = 0$ the two fixed points coincide in the half-stable point $0$: $\dot{x} = -x^2$ attracts from the right and repels on the left.
answer: The fixed points $0$ and $r$ pass through each other at $r = 0$ and exchange stability.

@mistakes
- Treating every change in $f'(x^*)$ as a saddle-node: the theorem needs $f_r \ne 0$ and $f_{xx} \ne 0$; a pitchfork has $f_r = f_{xx} = 0$ at the bifurcation.
- Drawing stable and unstable branches the wrong way round at a transcritical or pitchfork point; check the sign of $f'$ on each branch, never assume.
- Forgetting that a pitchfork is subcritical or supercritical depending on the cubic term's sign ($rx - x^3$ against $rx + x^3$) and that the subcritical one has no stable nearby branch for $r > 0$.
- Reading a computed bifurcation value from a grid scan as exact: two close fixed points can be missed.

def count_fixed_points(r):

    n = 1201
    values = [r + x - x ** 3 for x in (-3 + 6 * i / n for i in range(n + 1))]

model:
```python
def first_loss(count, lo, hi, tol):
    """Bisection for the jump of an integer-valued function."""
    base = count(lo)
    while hi - lo > tol:
        mid = (lo + hi) / 2
        if count(mid) == base:
            lo = mid
        else:
            hi = mid
    return (lo + hi) / 2
```
hint: Evaluate `count(lo)` once before the loop and compare each midpoint with that stored value.
solution: Invariant: `count(lo)` equals the left value and `count(hi)` differs, so the jump lies in `[lo, hi]`; each step halves the interval, so after $k$ steps its length is $(hi - lo)/2^k$ and the returned midpoint is within `tol` of the jump. Calling `count` once per step (and once at the start) keeps the number of evaluations near $\log_2((hi - lo)/tol)$, which the last test checks.

model:
```python
def stable_roots(r):
    """Stable fixed points of x' = r + 2*x - x**3 (scan, then bisection)."""
    def f(x):
        return r + 2 * x - x ** 3

    n = 1201
    xs = [-3 + 6 * i / n for i in range(n + 1)]
    roots = []
    for a, b in zip(xs, xs[1:]):
        if f(a) > 0 > f(b):
            for _ in range(50):
                m = (a + b) / 2
                if f(m) > 0:
                    a = m
                else:
                    b = m
            roots.append((a + b) / 2)
    return roots
```
hint: A stable fixed point is a sign change from positive to negative as $x$ increases; run bisection keeping the left end positive.
solution: On a bracket with $f(a) > 0 > f(b)$, bisection keeps $f(a) > 0$ and $f(b) \le 0$; after $50$ steps the bracket is about $10^{-15}$ times the grid spacing, far below the tolerance. Only $+\to-$ changes are kept because they are exactly the fixed points with $f' < 0$ (stable). The scan returns the roots already in increasing order.

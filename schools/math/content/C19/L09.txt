@article
Last week the logistic map went from a fixed point to a $2$-cycle at $r = 3$. Keep increasing $r$: the $2$-cycle splits into a $4$-cycle, then an $8$-cycle, and so on, with each doubling arriving faster than the one before. Where does the cascade end, and what is on the other side?

### The cascade

The multiplier of a $2$-cycle $\{x_1, x_2\}$ is $f_r'(x_1)f_r'(x_2) = r^2(1 - 2x_1)(1 - 2x_2)$. For the roots of $r^2x^2 - r(r+1)x + (r+1) = 0$ we have $x_1 + x_2 = \frac{r+1}{r}$ and $x_1x_2 = \frac{r+1}{r^2}$. Hence $(1 - 2x_1)(1 - 2x_2) = 1 - 2(x_1 + x_2) + 4x_1x_2$ and
$$\text{multiplier} = r^2 - 2r(r+1) + 4(r+1) = 4 + 2r - r^2 .$$
At $r = 3$ this is $1$ (the $2$-cycle is born from the fixed point), it decreases to $-1$ when $r^2 - 2r - 5 = 0$, that is, at $r = 1 + \sqrt{6} \approx 3.4495$, and it is $0$ at $r = 1 + \sqrt{5} \approx 3.2361$. So by Week 8's multiplier criterion the $2$-cycle is attracting for $3 < r < 1 + \sqrt{6}$, and at $r = 1 + \sqrt{6}$ it loses stability and a $4$-cycle is born.

The doublings continue at parameters $r_1 = 3 < r_2 = 1 + \sqrt{6} < r_3 \approx 3.54409 < r_4 \approx 3.56441 < r_5 \approx 3.56876 < \cdots$, accumulating at $r_\infty \approx 3.56995$. The gaps shrink geometrically: the ratio $(r_n - r_{n-1})/(r_{n+1} - r_n)$ tends to the **Feigenbaum constant** $\delta \approx 4.6692$ (Feigenbaum, 1978). It is *universal*: the same $\delta$ appears for a broad class of smooth maps of an interval with a single quadratic maximum (a result of renormalization theory, stated here without proof), such as $x \mapsto r\sin(\pi x)$ or $x \mapsto 1 - rx^2$, which is why laboratory experiments with very different physics show the same scaling. (This universality is a theorem proved with renormalization methods; we state it without proof.)

### Superstable parameters

A cycle is **superstable** when its multiplier is $0$, which for $f_r$ means that it contains the critical point $x = \tfrac12$ (where $f_r' = 0$). Let $R_n$ be the parameter at which the critical point lies on a cycle of period $2^n$, so $R_n$ is a root of $g_n(r) = f_r^{2^n}(\tfrac12) - \tfrac12$. The first ones are $R_0 = 2$ (fixed point $\frac12$), $R_1 = 1 + \sqrt{5}$. The $R_n$ obey the same geometric law as the $r_n$ and are easier to compute, because a root of a function can be bracketed by bisection. Since $(R_{n-1} - R_{n-2})/\delta$ predicts the next gap, a narrow bracket around $R_{n-1} + (R_{n-1} - R_{n-2})/\delta$ isolates $R_n$.

**Why bisection works here.** On a bracket $[a, b]$ where $g_n$ is continuous with $g_n(a)\,g_n(b) < 0$, bisection keeps a sign change, so the final interval of length $(b - a)/2^{k}$ contains a root (intermediate value theorem). That the root found is $R_n$ and not another root of $g_n$ rests on the bracket being narrow; we check it by comparing with the prediction.

```python
import math


def g(r, n):
    """f_r^(2^n)(1/2) - 1/2 for the logistic map."""
    x = 0.5
    for _ in range(2 ** n):
        x = r * x * (1 - x)
    return x - 0.5


def bisect_root(fn, a, b, steps=60):
    fa = fn(a)
    for _ in range(steps):
        m = (a + b) / 2
        if fn(m) * fa > 0:
            a = m
        else:
            b = m
    return (a + b) / 2


R = [2.0, 1 + math.sqrt(5)]
for k in range(2, 5):
    d = R[-1] - R[-2]
    guess = R[-1] + d / 4.669
    R.append(bisect_root(lambda r: g(r, k), guess - d / 20, guess + d / 20))
print([round(v, 6) for v in R])
```

This prints `[2.0, 3.236068, 3.498562, 3.554641, 3.566667]`. The three ratios $(R_n - R_{n-1})/(R_{n+1} - R_n)$ available from this list are $4.709,\ 4.681,\ 4.663$; running the loop up to $k = 6$ adds $4.668$ and $4.669$, converging to $\delta$. Such a table is numerical evidence for the constant, not a proof.

### Chaos at $r = 4$

A map $f$ has **sensitive dependence on initial conditions** on a set $S$ if there is $c > 0$ such that for every $x \in S$ and every $\epsilon > 0$ there are $y$ with $|x - y| < \epsilon$ and $n \ge 0$ with $|f^n(x) - f^n(y)| \ge c$. For $r = 4$ there is an exact solution. Put $x = \sin^2\varphi$. Then
$$f_4(\sin^2\varphi) = 4\sin^2\varphi\cos^2\varphi = (2\sin\varphi\cos\varphi)^2 = \sin^2(2\varphi),$$
so with $\varphi = \pi\theta$ the orbit is $x_n = \sin^2(2^n\pi\theta_0)$: the logistic map at $r = 4$ is the **doubling map** $T(\theta) = 2\theta \bmod 1$ in disguise (precisely, $\theta \mapsto \sin^2(\pi\theta)$ is a two-to-one semiconjugacy from $T$ to $f_4$, since $\sin^2(\pi\theta) = \sin^2(\pi(1 - \theta))$). For $T$, two points at distance $\epsilon < \frac14$ are at distance $2\epsilon$ after one step (as long as the distance stays below $\frac12$), so $|T^n\theta - T^n\theta'| = 2^n|\theta - \theta'|$ until it exceeds $\frac14$, after about $\log_2(1/\epsilon)$ steps: every small error is doubled at each step. The doubling map has periodic orbits for every period ($\theta = k/(2^p - 1)$ returns after $p$ steps) and rational $\theta$ are eventually periodic, so $f_4$ has cycles of every period. For example the orbit $\frac13, \frac23, \frac13, \dots$ of $T$ gives $x = \sin^2(\pi/3) = \frac34 = \sin^2(2\pi/3)$, which is the fixed point $\frac34$ of $f_4$.

@example
title: Doubling an error at $r = 4$
problem: Two initial conditions of $f_4$ are $x_0 = \sin^2(\pi\theta_0)$ and $x_0' = \sin^2(\pi(\theta_0 + 2^{-10}))$. After how many steps are the underlying angles $\theta_n$ and $\theta_n'$ at distance at least $\frac14$?

@mistakes
- Confusing superstable parameters ($R_n$, multiplier $0$) with bifurcation parameters ($r_n$, multiplier $-1$): $R_1 = 1 + \sqrt{5}$ and $r_2 = 1 + \sqrt{6}$ are different numbers.
- Thinking Feigenbaum's constant belongs to the logistic map alone: it is the same for every unimodal map with a quadratic maximum.
- Treating the accumulation point $r_\infty \approx 3.56995$ as the end of the story: beyond it the dynamics is a mixture of chaotic bands and periodic windows, not purely chaotic.
- Believing that sensitive dependence means all nearby orbits diverge at every step: errors can shrink for a step or two, and only the long-run average rate is positive (Week 10).

```python
def ratios_and_limit(rs, delta):
    """Feigenbaum ratio estimates and the accumulation-point estimate."""
    ratios = [(rs[k] - rs[k - 1]) / (rs[k + 1] - rs[k])
              for k in range(1, len(rs) - 1)]
    limit = rs[-1] + (rs[-1] - rs[-2]) / (delta - 1)
    return ratios, limit
```
hint: Use indices $k = 1, \dots, m-2$ in zero-based form, so each ratio looks one step back and one step forward.
solution: If every gap is $1/\delta$ of the previous one, the gaps after $r_m$ are $g/\delta, g/\delta^2, \dots$ with $g = r_m - r_{m-1}$, and their sum is $g/(\delta - 1)$. For the real cascade the estimate is $3.56995$ (more precisely $3.569946$), within $10^{-6}$ of the accepted value $3.5699456$, so this is an excellent extrapolation from five parameters. The second test uses a geometric sequence with $\delta = 2$ to check the formula exactly.

```python
def separation_steps(r, x0, eps, thr, max_steps):
    """First step at which two nearby logistic orbits are thr apart."""
    x, y = x0, x0 + eps
    for k in range(max_steps + 1):
        if abs(x - y) > thr:
            return k
        x = r * x * (1 - x)
        y = r * y * (1 - y)
    return None
```
hint: Test the distance before advancing the pair, so that the starting pair counts as step $0$.
solution: At $r = 4$ the separation roughly doubles per step, so reaching $0.1$ from $10^{-6}$ takes about $\log_2(10^5) \approx 17$ steps, and from $10^{-9}$ about $27$: a thousandfold smaller error buys only about $\log_2 1000 \approx 10$ extra steps. That is why long-term prediction is impossible even with extremely accurate data. The test tolerances are wide on purpose: individual steps expand by different factors, so only the average rate is stable, and nothing here depends on rounding details.

model:
```python
def attractor_size(r, x0, n_trans, n_keep, tol):
    """Number of tol-separated clusters among the recorded iterates."""
    x = x0
    for _ in range(n_trans):
        x = r * x * (1 - x)
    values = []
    for _ in range(n_keep):
        x = r * x * (1 - x)
        values.append(x)
    values.sort()
    return 1 + sum(1 for a, b in zip(values, values[1:]) if b - a > tol)
```
hint: After sorting, compare each value with its successor.
solution: On a $2^k$-cycle the iterates cluster at $2^k$ points up to rounding errors far below `tol`, so the cluster count is $2^k$; for a chaotic orbit the points spread over a band and the count grows with `n_keep`. Counting `len(set(values))` instead would fail because rounding makes the repeated values differ in the last digits, which is why a tolerance is used.

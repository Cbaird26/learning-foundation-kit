@article
A damped spring, a pair of coupled tanks and the linearization of a predator–prey model are all planar linear systems $\dot{\mathbf{x}} = A\mathbf{x}$ with $A$ a real $2 \times 2$ matrix. Some of them spiral into rest, some oscillate forever, some have one direction that blows up. What in $A$ decides which?

### The solution and the matrix exponential

The **matrix exponential** is $e^{B} = \sum_{k \ge 0} B^k/k!$. It converges for every square matrix $B$, because $\|B^k\| \le \|B\|^k$ in an operator norm and $\sum \|B\|^k/k!$ converges. Differentiating the series term by term gives $\frac{d}{dt}e^{tA} = A e^{tA}$, so $\mathbf{x}(t) = e^{tA}\mathbf{x}_0$ solves $\dot{\mathbf{x}} = A\mathbf{x}$ with $\mathbf{x}(0) = \mathbf{x}_0$.

**Theorem 1 (truncation bound).** Let $S_N(B) = \sum_{k=0}^{N} B^k/k!$ and $b = \|B\|$. Then $\|e^B - S_N(B)\| \le \dfrac{b^{N+1}}{(N+1)!}\,e^{b}$.

*Proof.* By the triangle inequality, $\|e^B - S_N(B)\| \le \sum_{k > N} b^k/k!$. Write $k = N + 1 + j$ with $j \ge 0$. Since $(N+1+j)! \ge (N+1)!\,j!$, we have $b^{N+1+j}/(N+1+j)! \le \frac{b^{N+1}}{(N+1)!}\cdot\frac{b^j}{j!}$. Summing over $j$ gives the factor $e^b$. $\blacksquare$

If $A\mathbf{v} = \lambda\mathbf{v}$ with $\mathbf{v} \ne 0$, then $e^{tA}\mathbf{v} = e^{\lambda t}\mathbf{v}$. If $A$ has two real eigenvalues $\lambda_1 \ne \lambda_2$ with eigenvectors $\mathbf{v}_1, \mathbf{v}_2$ (a basis), then $\mathbf{x}_0 = c_1\mathbf{v}_1 + c_2\mathbf{v}_2$ gives
$$\mathbf{x}(t) = c_1 e^{\lambda_1 t}\mathbf{v}_1 + c_2 e^{\lambda_2 t}\mathbf{v}_2 .$$
For complex eigenvalues $\alpha \pm i\omega$ the real and imaginary parts of $e^{(\alpha + i\omega)t}\mathbf{v}$ give solutions $e^{\alpha t}$ times rotations at angular speed $\omega$.

### The trace–determinant classification

Let $\tau = \operatorname{tr} A$, $\Delta = \det A$ and $D = \tau^2 - 4\Delta$. The characteristic polynomial is $\lambda^2 - \tau\lambda + \Delta$, so the eigenvalues are $\lambda_\pm = \frac{\tau \pm \sqrt{D}}{2}$, with $\lambda_+ + \lambda_- = \tau$ and $\lambda_+\lambda_- = \Delta$.

**Theorem 2.** For a real $2 \times 2$ matrix $A$ the origin of $\dot{\mathbf{x}} = A\mathbf{x}$ is:
- a **saddle** if $\Delta < 0$ (real eigenvalues of opposite signs);
- a **node** if $\Delta > 0$ and $D \ge 0$ (real eigenvalues of one sign), stable if $\tau < 0$ and unstable if $\tau > 0$; when $D = 0$ it is a degenerate or star node;
- a **spiral** if $\Delta > 0$, $D < 0$ and $\tau \ne 0$ (eigenvalues $\tau/2 \pm i\omega$), stable if $\tau < 0$ and unstable if $\tau > 0$;
- a **center** if $\Delta > 0$ and $\tau = 0$ (eigenvalues $\pm i\sqrt{\Delta}$): every orbit is closed with period $2\pi/\sqrt{\Delta}$;
- not an isolated fixed point if $\Delta = 0$ (a zero eigenvalue).

*Proof.* All cases read the roots of $\lambda^2 - \tau\lambda + \Delta$. If $\Delta < 0$, then $D > 0$ and $\lambda_+\lambda_- < 0$: one root positive and one negative. If $\Delta > 0$ and $D \ge 0$, the roots are real with positive product, so of one sign, which is the sign of their sum $\tau$. If $D < 0$, the roots are complex conjugates with real part $\tau/2$. If $\tau = 0$ and $\Delta > 0$ they are $\pm i\sqrt{\Delta}$ and $e^{tA}$ is periodic with period $2\pi/\sqrt{\Delta}$. If $\Delta = 0$, then $0$ is an eigenvalue. $\blacksquare$

**Corollary.** The origin is asymptotically stable (every solution tends to $0$) if and only if $\tau < 0$ and $\Delta > 0$. *Proof.* Real roots of one sign with negative sum are both negative, and complex roots have real part $\tau/2 < 0$; conversely, if both eigenvalues have negative real part then $\tau < 0$ and $\Delta = \lambda_+\lambda_- > 0$ (a product of two negatives, or $|\lambda|^2$). $\blacksquare$

The criterion needs both conditions: $A = \operatorname{diag}(-1, 1)$ has $\tau = 0$ and $\Delta = -1 < 0$ and is a saddle, while $\tau < 0$ with $\Delta < 0$ is unstable too.

### Classification in code

Classify with exact integer arithmetic; testing $D = 0$ or $\tau = 0$ with floats is unreliable.

```python
def classify(a, b, c, d):
    """Type of the origin for x' = [[a, b], [c, d]] x (exact for ints)."""
    tr, det = a + d, a * d - b * c
    disc = tr * tr - 4 * det
    if det < 0:
        return 'saddle'
    if det == 0:
        return 'zero eigenvalue'
    if tr == 0:
        return 'center'
    side = 'stable' if tr < 0 else 'unstable'
    return side + (' node' if disc >= 0 else ' spiral')


print(classify(1, 2, 3, 2), classify(-1, 2, -3, -4))
```

This prints `saddle stable spiral`. A computation of the exponential itself is a loop that multiplies by $B/k$ each time; Theorem 1 says how many terms are enough.

@example
title: Classify and solve a planar system
problem: For $A = \begin{pmatrix} 1 & 2 \\ 3 & 2 \end{pmatrix}$ classify the origin and solve $\dot{\mathbf{x}} = A\mathbf{x}$ with $\mathbf{x}(0) = (1, 0)$.
step: $\tau = 3$, $\Delta = 2 - 6 = -4 < 0$, so the origin is a saddle. The eigenvalues solve $\lambda^2 - 3\lambda - 4 = 0$: $\lambda = 4$ and $\lambda = -1$.
step: For $\lambda = 4$: $(A - 4I)\mathbf{v} = 0$ gives $-3v_1 + 2v_2 = 0$, so $\mathbf{v}_1 = (2, 3)$. For $\lambda = -1$: $2v_1 + 2v_2 = 0$, so $\mathbf{v}_2 = (1, -1)$.
step: Write $(1, 0) = c_1(2, 3) + c_2(1, -1)$: $2c_1 + c_2 = 1$ and $3c_1 - c_2 = 0$ give $c_1 = 1/5$, $c_2 = 3/5$.
step: The solution is $\mathbf{x}(t) = \frac15 e^{4t}(2, 3) + \frac35 e^{-t}(1, -1)$. As $t \to \infty$ it grows along $(2, 3)$; only data exactly on the line through $(1, -1)$ decays to $0$.
answer: A saddle; $\mathbf{x}(t) = \frac15 e^{4t}(2, 3) + \frac35 e^{-t}(1, -1)$.

@example
title: A spiral from the trace and determinant
problem: Classify the origin for $A = \begin{pmatrix} -1 & 2 \\ -3 & -4 \end{pmatrix}$ and describe the decay.
step: $\tau = -5$ and $\Delta = 4 + 6 = 10 > 0$.
step: $D = \tau^2 - 4\Delta = 25 - 40 = -15 < 0$, so the eigenvalues are complex: $\lambda = \frac{-5 \pm i\sqrt{15}}{2}$.
step: The real part is $-5/2 < 0$, so every solution tends to $0$, while the imaginary part $\sqrt{15}/2$ is the angular speed of rotation.
step: Each orbit spirals into the origin, shrinking by the factor $e^{-5/2 \cdot T}$ per turn, where $T = 4\pi/\sqrt{15}$ is the time of one turn.
answer: A stable spiral.

@mistakes
- Deciding stability from the trace alone, or from the determinant alone: the corollary needs $\tau < 0$ and $\Delta > 0$ together.
- Calling $\tau = 0$ a center without checking $\Delta > 0$: with $\Delta < 0$ it is a saddle, and with $\Delta = 0$ the matrix has a zero eigenvalue.
- Testing $D = 0$ or $\tau = 0$ on floating-point data. Equalities such as $\tau = 0$ are fragile: a center turns into a spiral under any perturbation, so use exact arithmetic for the classification.
- Truncating the exponential series after a fixed number of terms without bounding the tail: the needed number of terms grows with $\|tA\|$.

```python
import math


def eigvals2(a, b, c, d):
    """Eigenvalues of a real 2 x 2 matrix, larger real part first."""
    tr, det = a + d, a * d - b * c
    disc = tr * tr - 4 * det
    if disc >= 0:
        s = math.sqrt(disc)
        return complex((tr + s) / 2, 0.0), complex((tr - s) / 2, 0.0)
    s = math.sqrt(-disc) / 2
    return complex(tr / 2, s), complex(tr / 2, -s)
```
hint: Use $\lambda = (\tau \pm \sqrt{D})/2$ and take the square root of $-D$ when $D < 0$.
solution: The characteristic polynomial is $\lambda^2 - \tau\lambda + \Delta$. For $D \ge 0$ the roots are real; for $D < 0$ they are $\tau/2 \pm i\sqrt{-D}/2$. Returning the plus sign first gives the required order in both cases.

```python
def expm2(A, terms):
    """Partial sum of the exponential series of a 2 x 2 matrix."""
    result = [[1.0, 0.0], [0.0, 1.0]]
    term = [[1.0, 0.0], [0.0, 1.0]]
    for k in range(1, terms + 1):
        term = [[sum(term[i][m] * A[m][j] for m in range(2)) / k
                 for j in range(2)] for i in range(2)]
        for i in range(2):
            for j in range(2):
                result[i][j] += term[i][j]
    return result
```
hint: Keep a matrix `term` equal to $A^k/k!$ and multiply it by $A/k$ in each pass of the loop.
solution: Since $A^k/k! = (A^{k-1}/(k-1)!)\cdot A/k$, each term costs one matrix product. By Theorem 1 the error after `terms` terms is at most $b^{N+1}e^b/(N+1)!$ with $b = \|A\|$; for $\|A\| \approx 1$ thirty terms are far more than enough. The rotation test confirms that $e^{A}$ for $A = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$ is the rotation by one radian.

```python
import math


def flow_real(a, b, c, d, x0, t):
    """e^{tA} x0 for real distinct eigenvalues and b != 0."""
    tr, det = a + d, a * d - b * c
    s = math.sqrt(tr * tr - 4 * det)
    lp, lm = (tr + s) / 2, (tr - s) / 2
    vp, vm = (b, lp - a), (b, lm - a)
    # solve x0 = cp * vp + cm * vm by Cramer's rule
    det_v = vp[0] * vm[1] - vm[0] * vp[1]
    cp = (x0[0] * vm[1] - vm[0] * x0[1]) / det_v
    cm = (vp[0] * x0[1] - x0[0] * vp[1]) / det_v
    ep, em = cp * math.exp(lp * t), cm * math.exp(lm * t)
    return (ep * vp[0] + em * vm[0], ep * vp[1] + em * vm[1])
```
hint: The eigenvector for $\lambda$ satisfies the first row of $(A - \lambda I)\mathbf{v} = 0$: $(a - \lambda)v_1 + b v_2 = 0$, which $(b, \lambda - a)$ solves.
solution: With distinct eigenvalues the eigenvectors are independent, so $\mathbf{x}_0 = c_+\mathbf{v}_+ + c_-\mathbf{v}_-$ has a unique solution and the answer is $c_+ e^{\lambda_+ t}\mathbf{v}_+ + c_- e^{\lambda_- t}\mathbf{v}_-$. The tests compare it with an independent power-series evaluation of $e^{tA}\mathbf{x}_0$, which is evidence that the two formulas agree; Theorem 1 and the eigenvector computation are the proof.

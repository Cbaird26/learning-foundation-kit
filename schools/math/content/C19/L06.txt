@article
A heart keeps beating, a laser keeps pulsing, a clock keeps ticking, each with a steady rhythm that does not depend on how it was started. In a linear system a center has closed orbits at every amplitude; a rhythm with one definite amplitude needs nonlinearity. A **limit cycle** is an isolated closed orbit: nearby orbits are not closed, and they spiral toward it (stable) or away from it (unstable).

The simplest example is $\dot{r} = r(1 - r^2)$, $\dot{\theta} = 1$. For $0 < r < 1$ we have $\dot{r} > 0$ and for $r > 1$ we have $\dot{r} < 0$, so every orbit except the fixed point $r = 0$ approaches the circle $r = 1$, a stable limit cycle of period $2\pi$.

### Trapping regions and the Poincaré–Bendixson theorem

**Theorem 1 (Poincaré–Bendixson).** Let $\dot{\mathbf{x}} = F(\mathbf{x})$ be a continuously differentiable system on an open set of the plane. Let $R$ be a closed and bounded set that contains no fixed point, and let a trajectory $C$ be confined to $R$ for all $t \ge 0$. Then $C$ is itself a closed orbit or spirals toward one. In either case $R$ contains a closed orbit. *(Stated without proof; the proof uses the Jordan curve theorem and a study of the limit set of $C$.)*

Every hypothesis is used. Without "no fixed point" the trajectory can converge to a fixed point inside $R$. Without boundedness it can escape. The plane is essential: in three dimensions a bounded trajectory without fixed points can wander forever, which is how chaos appears in Week 11.

The usual way to meet the hypotheses is a **trapping region**: a closed bounded region $R$ whose boundary is crossed only inward (or tangentially), so $R$ is forward invariant. In practice we use an annulus $r_1 \le r \le r_2$ with $\dot{r} > 0$ on $r = r_1$ and $\dot{r} < 0$ on $r = r_2$, and we check that the region has no fixed points.

### Ruling cycles out: Bendixson's criterion

**Theorem 2 (Bendixson).** Let $\dot{x} = f(x, y)$, $\dot{y} = g(x, y)$ with $f, g$ continuously differentiable on a simply connected region $D$ of the plane. If $\operatorname{div} F = f_x + g_y$ does not change sign on $D$ and is not identically zero on any open subset of $D$, then $D$ contains no closed orbit.

*Proof.* Suppose a closed orbit $C$ lies in $D$ and bounds the region $A$; since $D$ is simply connected, $A \subseteq D$. Along $C$, $dx = f\,dt$ and $dy = g\,dt$, so $\oint_C (f\,dy - g\,dx) = \oint (fg - gf)\,dt = 0$. By Green's theorem the same integral equals $\iint_A (f_x + g_y)\,dA$. The interior of $A$ is a nonempty open subset of $D$, so the divergence is nonzero at some point of it, hence (by continuity) nonzero on a small disc, and it has one sign everywhere; therefore the integral is nonzero. This is a contradiction. $\blacksquare$

Simple connectedness cannot be dropped: an annulus can contain a closed orbit around its hole. The converse fails too: a zero divergence, as for a center, proves nothing.

### Integrating with Runge–Kutta

The classical fourth-order Runge–Kutta step for $\dot{\mathbf{s}} = F(\mathbf{s})$ is $\mathbf{s}_{n+1} = \mathbf{s}_n + \frac h6(\mathbf{k}_1 + 2\mathbf{k}_2 + 2\mathbf{k}_3 + \mathbf{k}_4)$ with $\mathbf{k}_1 = F(\mathbf{s}_n)$, $\mathbf{k}_2 = F(\mathbf{s}_n + \frac h2\mathbf{k}_1)$, $\mathbf{k}_3 = F(\mathbf{s}_n + \frac h2\mathbf{k}_2)$, $\mathbf{k}_4 = F(\mathbf{s}_n + h\mathbf{k}_3)$.

**Theorem 3 (accuracy on a linear test equation).** For $\dot{x} = \lambda x$ one step multiplies $x$ by $1 + z + \frac{z^2}{2} + \frac{z^3}{6} + \frac{z^4}{24}$ with $z = \lambda h$, the Taylor polynomial of $e^z$ of degree $4$. Hence the local error is $O(h^5)$.

*Proof.* Write $z = \lambda h$. Then $k_1 = \lambda x$, $k_2 = \lambda x(1 + z/2)$, $k_3 = \lambda x(1 + z/2 + z^2/4)$, $k_4 = \lambda x(1 + z + z^2/2 + z^3/4)$. The weighted sum is $\lambda x\,(6 + 3z + z^2 + z^3/4)$, and $x + \frac h6\lambda x(6 + 3z + z^2 + z^3/4) = x\left(1 + z + \frac{z^2}{2} + \frac{z^3}{6} + \frac{z^4}{24}\right)$. The difference from $e^z$ is $\frac{z^5}{120} + \cdots = O(h^5)$. $\blacksquare$

For general smooth $F$ the method has local error $O(h^5)$ and global error $O(h^4)$ (stated without proof here).

```python
def rk4_step(F, s, h):
    """One classical Runge-Kutta step for s' = F(s); s is a list."""
    k1 = F(s)
    k2 = F([a + h / 2 * b for a, b in zip(s, k1)])
    k3 = F([a + h / 2 * b for a, b in zip(s, k2)])
    k4 = F([a + h * b for a, b in zip(s, k3)])
    return [a + h / 6 * (b + 2 * c + 2 * d + e)
            for a, b, c, d, e in zip(s, k1, k2, k3, k4)]


print(round(rk4_step(lambda s: [-s[0]], [1.0], 0.5)[0], 6))
```

This prints `0.606771`, the value of the degree-4 polynomial at $z = -0.5$, close to $e^{-0.5} = 0.606531$. A simulation that settles onto a closed curve suggests a limit cycle; the trapping region is what proves it.

@example
title: A periodic orbit by trapping
problem: Prove that $\dot{r} = r(1 - r^2 + \tfrac12\cos\theta)$, $\dot{\theta} = 1$ has a periodic orbit.
step: Inner circle $r = 0.6$: then $r^2 = 0.36$, so $1 - r^2 + \tfrac12\cos\theta \ge 1 - 0.36 - 0.5 = 0.14 > 0$ and $\dot{r} > 0$ everywhere on it.
step: Outer circle $r = 1.3$: then $r^2 = 1.69$, so $1 - r^2 + \tfrac12\cos\theta \le 1 - 1.69 + 0.5 = -0.19 < 0$ and $\dot{r} < 0$ everywhere on it.
step: The annulus $R = \{0.6 \le r \le 1.3\}$ is closed and bounded, and a trajectory in $R$ cannot leave it: the flow enters across both boundary circles. It is forward invariant.
step: There is no fixed point in $R$: a fixed point needs $\dot{\theta} = 0$, but $\dot{\theta} = 1$, and the origin is outside $R$.
step: By the Poincaré–Bendixson theorem $R$ contains a closed orbit.
answer: A periodic orbit exists in $0.6 \le r \le 1.3$.

@example
title: No closed orbits by Bendixson
problem: Show that $\dot{x} = y + x^3$, $\dot{y} = -x + y^3$ has no closed orbit in the plane.
step: Compute the divergence: $f_x + g_y = 3x^2 + 3y^2$.
step: It is nonnegative everywhere and positive except at the origin, so it never changes sign and is not identically zero on any open set.
step: The plane is simply connected, so Bendixson's criterion applies and there is no closed orbit.
step: The linearization at the origin is a center, which shows that the nonlinear terms matter; here they push every orbit outward.
answer: There are no closed orbits.

@mistakes
- Applying Poincaré–Bendixson without checking that the region has no fixed point: a trapping region that contains a stable node only shows that orbits go there.
- Checking only $\theta = 0$ when verifying $\dot{r} > 0$ on a circle: the sign must hold at every angle, so test the worst angle.
- Using Bendixson's criterion on a region that is not simply connected, or when the divergence changes sign (as for the van der Pol oscillator, whose divergence $\mu(1 - x^2)$ changes sign).
- Taking a divergence of $0$ as proof of closed orbits: it only means the criterion is silent.

model:
```python
import math


def check_trapping(rdot, r1, r2, m):
    """True if rdot > 0 on the circle r1 and rdot < 0 on the circle r2."""
    for k in range(m):
        theta = 2 * math.pi * k / m
        if not (rdot(r1, theta) > 0 and rdot(r2, theta) < 0):
            return False
    return True
```
hint: Loop over the angles and return `False` as soon as one angle breaks either inequality.
solution: The conditions must hold at every angle, so a single failing angle makes the answer `False`; the tests place the failure at $\theta = 0$ or $\theta = \pi$, where $2 + \cos\theta$ is largest or smallest. A grid of angles checks only finitely many cases: it is evidence, and for a proof you bound $\dot{r}$ for all $\theta$ (here $2 + \cos\theta \le 3$ gives $\dot{r} \ge r(3 - 3r^2) > 0$ for $r < 1$).

model:
```python
def vdp_amplitude(mu, x0, y0, h, steps, tail):
    """Largest |x| over the last `tail` Runge-Kutta steps of the oscillator."""
    def F(x, y):
        return y, mu * (1 - x * x) * y - x

    x, y = x0, y0
    best = 0.0
    for k in range(steps):
        k1 = F(x, y)
        k2 = F(x + h / 2 * k1[0], y + h / 2 * k1[1])
        k3 = F(x + h / 2 * k2[0], y + h / 2 * k2[1])
        k4 = F(x + h * k3[0], y + h * k3[1])
        x += h / 6 * (k1[0] + 2 * k2[0] + 2 * k3[0] + k4[0])
        y += h / 6 * (k1[1] + 2 * k2[1] + 2 * k3[1] + k4[1])
        if k >= steps - tail:
            best = max(best, abs(x))
    return best
```
hint: Compute the four slopes from the old point, update both coordinates together, and record `abs(x)` only in the last `tail` iterations.
solution: For $\mu = 0$ the system is a harmonic oscillator and the amplitude is the initial one, $1.5$, so the test checks the integrator; for $\mu > 0$ every start (inside or outside) settles onto the same limit cycle, whose $x$-amplitude is near $2$ (about $2.009$ for $\mu = 1$). The equilibrium $(0, 0)$ is a fixed point and the start there stays there. This simulation illustrates the limit cycle; existence is proved by a theorem (for example Poincaré–Bendixson with a trapping region), not by a run.

model:
```python
def return_map(x0):
    """x-coordinate of the next crossing of the positive x-axis."""
    def F(x, y):
        s = 0.05 * (2 - x * x - y * y)
        return s * x - y, x + s * y

    h = 0.05
    x, y = x0, 0.0
    while True:
        k1 = F(x, y)
        k2 = F(x + h / 2 * k1[0], y + h / 2 * k1[1])
        k3 = F(x + h / 2 * k2[0], y + h / 2 * k2[1])
        k4 = F(x + h * k3[0], y + h * k3[1])
        xn = x + h / 6 * (k1[0] + 2 * k2[0] + 2 * k3[0] + k4[0])
        yn = y + h / 6 * (k1[1] + 2 * k2[1] + 2 * k3[1] + k4[1])
        if y < 0 <= yn:
            return x + (xn - x) * (-y) / (yn - y)
        x, y = xn, yn
```
hint: Keep the old point until the new one is computed, and test the sign pattern `y < 0 <= yn` before moving on.
solution: In polar form $\rho = r^2$ satisfies $\dot{\rho} = 0.1\rho(2 - \rho)$, so one turn ($t = 2\pi$) maps $r_0$ to $\sqrt{2/(1 + (2/r_0^2 - 1)e^{-0.2\cdot 2\pi})}$: that gives about $1.2478$ for $r_0 = 1$. The fixed point $\sqrt{2}$ of this return map is the limit cycle, and the map moves points toward it from both sides, the signature of a stable cycle. The test tolerance covers the interpolation error of about $4\cdot 10^{-4}$.

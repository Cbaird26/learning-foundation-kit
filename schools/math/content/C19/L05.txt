@article
A ball rolls without friction on a curved track of height $V(x)$. It speeds up as it goes downhill and slows going up, but the sum of kinetic and potential energy never changes. That single conserved number is enough to draw the whole phase portrait. This is the situation of Newton's equation $\ddot{x} = -V'(x)$ for a unit mass, which we write as the planar system
$$\dot{x} = v, \qquad \dot{v} = -V'(x) .$$

### Energy and its consequences

The **energy** is $E(x, v) = \tfrac12 v^2 + V(x)$. Along any solution
$$\frac{dE}{dt} = v\dot{v} + V'(x)\dot{x} = v\,(-V'(x)) + V'(x)\,v = 0,$$
so $E$ is constant: each orbit lies in a level set of $E$. A system with a conserved quantity that is not constant on any open set is called **conservative**.

**Theorem 1 (no attractors).** A conservative planar system has no asymptotically stable fixed point.

*Proof.* Suppose $\mathbf{x}^*$ were asymptotically stable, so every point $\mathbf{y}$ in a small open ball $B$ around it has $\mathbf{x}(t; \mathbf{y}) \to \mathbf{x}^*$. By continuity of $E$ and conservation, $E(\mathbf{y}) = E(\mathbf{x}(t; \mathbf{y})) \to E(\mathbf{x}^*)$, so $E(\mathbf{y}) = E(\mathbf{x}^*)$ for every $\mathbf{y} \in B$: $E$ is constant on an open set, contradicting the definition. $\blacksquare$

**Theorem 2 (centers of $\ddot{x} = -V'(x)$).** Let $V$ be $C^2$ with $V'(x_0) = 0$ and $V''(x_0) > 0$. Then $(x_0, 0)$ is a center: all orbits close to it are closed. If instead $V''(x_0) < 0$, then $(x_0, 0)$ is a saddle.

*Proof (outline for the first case).* The Jacobian at $(x_0, 0)$ is $\begin{pmatrix} 0 & 1 \\ -V''(x_0) & 0 \end{pmatrix}$ with $\tau = 0$ and $\Delta = V''(x_0)$. Near $(x_0, 0)$ the function $E$ has a strict local minimum with positive definite Hessian $\operatorname{diag}(V''(x_0), 1)$, so for energies slightly above $E(x_0, 0)$ the level set $\{E = c\}$ is a compact, smooth, connected closed curve around the point (the gradient $(V', v)$ vanishes only at fixed points). An orbit on it never stops, so it traverses the whole closed curve and is periodic. For $V''(x_0) < 0$ we have $\Delta < 0$, a saddle, which is hyperbolic. $\blacksquare$

Here the linearization (a center) is *not* enough by itself, as Week 4 showed; the conserved energy is what settles the question. The **period** of the orbit of energy $c$ is $T(c) = 2\int_{x_1}^{x_2} \frac{dx}{\sqrt{2(c - V(x))}}$, between the turning points $x_1 < x_2$. For small oscillations $T \approx 2\pi/\sqrt{V''(x_0)}$.

For the pendulum $V(x) = -\cos x$: the bottom $x = 0$ is a center, the top $x = \pm\pi$ a saddle with $E = 1$. Orbits with $E < 1$ swing back and forth, $E > 1$ go around forever, and the level $E = 1$ consists of the **separatrices** that connect the saddles.

### Integrators and energy drift

Explicit Euler on $\dot{x} = v$, $\dot{v} = -x$ gives $x' = x + hv$, $v' = v - hx$, hence $x'^2 + v'^2 = (1 + h^2)(x^2 + v^2)$: the energy is multiplied by $1 + h^2$ in every step and grows without bound. The **symplectic Euler** method updates $v$ first and then uses the *new* $v$: $v' = v - hx$, $x' = x + hv'$.

**Theorem 3.** For $0 < h < 2$, symplectic Euler on the harmonic oscillator preserves exactly the quantity $I = x^2 + v^2 - hxv$, and the energy $E = \frac12(x^2 + v^2)$ satisfies $\frac{2 - h}{2 + h}E_0 \le E_n \le \frac{2 + h}{2 - h}E_0$ for all $n$.

*Proof.* With $v' = v - hx$ and $x' = x + hv'$: $x'^2 - hx'v' = x'(x' - hv') = (x + hv')x = x^2 + hxv'$. Hence $I' = v'^2 + x^2 + hxv' = v'(v' + hx) + x^2 = v'v + x^2 = (v - hx)v + x^2 = I$. Since $|xv| \le \frac12(x^2 + v^2) = E$, we have $2E - hE \le I \le 2E + hE$. Applying this to $E_n$ and to $E_0$ with $I_n = I_0$: $E_n \le I_0/(2 - h) \le \frac{2 + h}{2 - h}E_0$, and $E_n \ge I_0/(2 + h) \ge \frac{2 - h}{2 + h}E_0$. $\blacksquare$

```python
def sympl_euler(dV, x, v, h, n):
    """n steps of v <- v - h dV(x), x <- x + h v; list of (x, v) pairs."""
    path = [(x, v)]
    for _ in range(n):
        v = v - h * dV(x)
        x = x + h * v
        path.append((x, v))
    return path


path = sympl_euler(lambda x: x, 1.0, 0.0, 0.1, 100)
print(round(max(0.5 * (x * x + v * v) for x, v in path), 4))
```

This prints `0.5263`, the maximal energy, an increase of $5.3\%$ over $E_0 = 0.5$ that never grows further, while explicit Euler reaches $E_{100} = 0.5\cdot 1.01^{100} \approx 1.352$. Computed energy curves are evidence about a method; Theorem 3 is what proves the bound.

@example
title: Escape from a double well
problem: A unit mass moves in the potential $V(x) = x^4/4 - x^2/2$. It sits at $x = 1$ and is given speed $v_0$. For which $v_0$ does it get over the barrier at $x = 0$?
step: Find the wells and the barrier: $V'(x) = x^3 - x = 0$ at $x = 0, \pm 1$. $V''(x) = 3x^2 - 1$ gives $V''(\pm 1) = 2 > 0$ (centers) and $V''(0) = -1 < 0$ (a saddle).
step: Compute the energies: $V(1) = 1/4 - 1/2 = -1/4$ and the barrier height $V(0) = 0$.
step: The energy of the particle is $E = \tfrac12 v_0^2 - \tfrac14$. It reaches $x = 0$ with $v^2/2 = E - V(0) = E \ge 0$ if and only if $E > 0$ (with $E = 0$ giving the separatrix, approached but never reached).
step: So it crosses the barrier if and only if $\tfrac12 v_0^2 > \tfrac14$, that is, $v_0 > 1/\sqrt{2}$.
answer: It crosses if and only if $|v_0| > 1/\sqrt{2} \approx 0.707$, and then it oscillates over both wells.

@example
title: Reading a phase portrait from the potential
problem: For $V(x) = \tfrac12 x^2 - \tfrac13 x^3$, classify the fixed points of $\ddot{x} = -V'(x)$ and describe the orbit with energy $E = 0$.
step: $V'(x) = x - x^2 = x(1 - x)$, so the fixed points are $(0, 0)$ and $(1, 0)$.
step: $V''(x) = 1 - 2x$: $V''(0) = 1 > 0$, a center; $V''(1) = -1 < 0$, a saddle.
step: $V(0) = 0$ and $V(1) = 1/6$. Orbits near the center have $E$ slightly above $0$ and are closed; the level $E = 1/6$ through the saddle is the separatrix, a loop that starts and ends at the saddle and encloses the center.
step: Energy $E = 0$ is the minimum of $E$ near the center, where the level set is the single point $(0, 0)$ (the level $E = 0$ also contains an unbounded curve through $(3/2, 0)$, a different orbit far to the right). Slightly larger energies give small closed loops around it, and all energies $0 < E < 1/6$ give closed orbits inside the separatrix loop.
answer: $(0, 0)$ is a center and $(1, 0)$ a saddle; orbits with $0 < E < 1/6$ are closed loops inside the saddle's loop.

@mistakes
- Believing a conserved energy lets the origin also attract: Theorem 1 forbids asymptotic stability in a conservative system.
- Calling every fixed point with $\tau = 0$ a center. It is a center for $\ddot{x} = -V'(x)$ only if $V''(x_0) > 0$; with $V''(x_0) < 0$ it is a saddle.
- Using the old velocity in the second line of symplectic Euler. Writing `x = x + h * v` before `v = v - h * dV(x)` is a different method with the same cost.
- Concluding from a long simulation with small energy drift that the method conserves energy exactly: only Theorem 3's invariant is exact, and it is for the harmonic oscillator.

model:
```python
def verlet(dV, x, v, h, n):
    """Velocity-Verlet integration of x'' = -dV(x)."""
    for _ in range(n):
        half = v - 0.5 * h * dV(x)
        x = x + h * half
        v = half - 0.5 * h * dV(x)
    return x, v
```
hint: Compute the half-step velocity first, move `x` with it, and then finish the velocity step with the force at the new position.
solution: The method is second order: halving $h$ divides the global error by about $4$, which the ratio test confirms for the harmonic oscillator, and the energy error stays bounded (here within $1\%$ after $1000$ steps). Replacing the two half kicks by one full kick per step gives symplectic Euler, which is only first order.

```python
def period(dV, x0, v0, h, n):
    """Estimate the period of x'' = -dV(x) from upward zero crossings."""
    x, v = x0, v0
    crossings = []
    for k in range(n):
        half = v - 0.5 * h * dV(x)
        x_new = x + h * half
        v = half - 0.5 * h * dV(x_new)
        if x < 0 <= x_new:
            crossings.append(k * h + h * (-x) / (x_new - x))
        x = x_new
    if len(crossings) < 2:
        return None
    return (crossings[-1] - crossings[0]) / (len(crossings) - 1)
```
hint: Remember the previous `x` before it is overwritten; interpolate only when the sign test succeeds.
solution: Linear interpolation locates a crossing to $O(h^2)$, much better than the step size; Verlet itself has a period error of order $h^2$. The pendulum test shows that the period grows with amplitude: it is about $6.287$ at amplitude $0.1$ (the small-oscillation value $2\pi$ times about $1 + \theta_0^2/16$) and about $8.350$ at amplitude $2$.

```python
def energy_range(h, n):
    """Smallest and largest E_k / E_0 along symplectic Euler."""
    x, v = 1.0, 0.0
    e0 = 0.5 * (x * x + v * v)
    lo = hi = 1.0
    for _ in range(n):
        v = v - h * x
        x = x + h * v
        ratio = 0.5 * (x * x + v * v) / e0
        lo, hi = min(lo, ratio), max(hi, ratio)
    return lo, hi
```
hint: Start `lo` and `hi` at the ratio $1$ for $k = 0$ and update them after each step.
solution: Theorem 3 gives the guaranteed range $\left[\frac{2-h}{2+h}, \frac{2+h}{2-h}\right]$; the computed range lies inside it for every $h < 2$. For this initial condition $v_0 = 0$ the maximum is exactly $2/(2 - h)$ (when $x v$ takes its extreme value), which the last test checks to $10^{-3}$. Running more steps does not widen the range, unlike explicit Euler, whose ratio is $(1 + h^2)^k$.

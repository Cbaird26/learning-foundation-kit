@article
Two orbits start $10^{-9}$ apart. After how many steps will they be $0.1$ apart? Last week we found about $27$ steps for the logistic map at $r = 4$, and that the answer grows only like $\log(1/\text{error})$. The **Lyapunov exponent** is the number that measures this: the average growth rate, per step, of a tiny separation.

### Definition and meaning

Let $f$ be a continuously differentiable map and let $x_n = f^n(x_0)$. If $y_0 = x_0 + \delta$ with $\delta$ tiny, then by the chain rule $y_n - x_n \approx (f^n)'(x_0)\,\delta$ and $(f^n)'(x_0) = \prod_{i=0}^{n-1} f'(x_i)$. The **Lyapunov exponent** of the orbit of $x_0$ is
$$\lambda(x_0) = \lim_{n \to \infty} \frac1n \sum_{i=0}^{n-1} \log|f'(x_i)|,$$
when the limit exists. Then $|y_n - x_n| \approx |\delta|\,e^{n\lambda}$: $\lambda < 0$ means nearby orbits converge, $\lambda > 0$ means they separate exponentially (until the approximation fails and the separation saturates at the size of the attractor).

**Theorem 1.** Let $f$ be $C^1$ and let $x_n \to p$ where $p$ lies on a $k$-cycle with multiplier $m = (f^k)'(p) \ne 0$. Then $\lambda(x_0) = \frac1k\log|m|$. In particular if $p$ is a fixed point, $\lambda = \log|f'(p)|$, which is negative exactly when $|f'(p)| < 1$ (and then $p$ is attracting).

*Proof.* The orbit approaches the cycle: if $c_0, \dots, c_{k-1}$ are the cycle points, then for each residue $j$ the subsequence $x_{nk+j}$ tends to $c_j$ (this is what "converging to a cycle" means). By continuity $a_i = \log|f'(x_i)|$ satisfies $a_{nk+j} \to \log|f'(c_j)|$, and $\sum_{j}\log|f'(c_j)| = \log|m|$. A sequence whose $k$ residue subsequences converge has Cesàro means converging to the average of the limits: given $\varepsilon > 0$, choose $N$ so that $|a_{nk+j} - \log|f'(c_j)|| < \varepsilon$ for all $nk + j \ge N$; then the mean of $a_0, \dots, a_{M-1}$ differs from the average of the limits by at most $\varepsilon + C/M$ for a constant $C$ depending only on $N$ and the first $N$ terms, which is below $2\varepsilon$ for large $M$. So $\lambda = \frac1k\log|m|$. $\blacksquare$

The convergence is slow only because of the transient: the first $N$ terms contribute $O(1/n)$, so an estimate from $n$ steps after discarding a transient has error of order $1/n$ for an attracting cycle. For a chaotic orbit there is no such bound and the estimate fluctuates by about $1/\sqrt{n}$.

**Examples.** At $r = 3.2$ the attracting $2$-cycle has multiplier $0.16$, so $\lambda = \frac12\log 0.16 \approx -0.916$. At a superstable cycle the multiplier is $0$ and $\lambda = -\infty$.

### The logistic map at $r = 4$

From the semiconjugacy $x_n = \sin^2(2^n\pi\theta_0)$ we get $dx_n/d\theta_0 = \pi 2^n\sin(2^{n+1}\pi\theta_0)$, hence
$$(f_4^n)'(x_0) = \frac{2^n\sin(2^{n+1}\pi\theta_0)}{\sin(2\pi\theta_0)}, \qquad \frac1n\log|(f_4^n)'(x_0)| = \log 2 + \frac1n\bigl(\log|\sin(2^{n+1}\pi\theta_0)| - \log|\sin 2\pi\theta_0|\bigr).$$
The bracket is bounded above (by $-\log|\sin 2\pi\theta_0|$), so $\lambda \le \log 2$ always, and $\lambda = \log 2$ whenever $\log|\sin(2^{n+1}\pi\theta_0)|$ is $o(n)$, which holds for almost every $\theta_0$ (stated without proof; it is a consequence of the ergodic theorem) and for every point of a cycle, where the sines repeat. At $r = 4$, then, typical orbits have $\lambda = \log 2 \approx 0.693$: one bit of information about the initial condition is lost per step.

A **chaotic orbit** is commonly defined as a bounded orbit that is not eventually periodic (not asymptotic to a periodic orbit) and has $\lambda > 0$. Both conditions matter: a repelling cycle also has $\lambda > 0$ (the cycle $\{3/7, 6/7\}$ of $f_{7/2}$ has multiplier $-1.25$ and $\lambda = \frac12\log 1.25 \approx 0.112$), but it is periodic; and $f(x) = 2x$ on $\mathbb{R}$ has $\lambda = \log 2$ but its orbits escape to infinity.

### Computing the exponent

```python
import math


def lyapunov_orbit(xs, fprime):
    """Mean of log|f'(x)| over a given list of orbit points."""
    return sum(math.log(abs(fprime(x))) for x in xs) / len(xs)


f_prime = lambda x: 3.5 * (1 - 2 * x)
print(round(lyapunov_orbit([3 / 7, 6 / 7], f_prime), 4))
```

This prints `0.1116`, the exponent of the repelling $2$-cycle at $r = 7/2$. Estimating $\lambda$ from a long orbit uses the same formula on the computed iterates. A computed chaotic orbit is not the true orbit of $x_0$ (rounding errors are amplified), but by the *shadowing* phenomenon it stays close to some true orbit, which is why the average is still reliable; the exact digits of the orbit are not. A direct simulation of the doubling map is the warning case: $T(\theta) = 2\theta \bmod 1$ is *exact* in floating point and a float $\theta_0 = m/2^k$ is mapped to $0$ after at most $k$ steps. The computer's orbit is not chaotic at all, though the map has $\lambda = \log 2$. For the logistic map the nonlinear rounding avoids this.

problem: For the logistic map at $r = 3.5$ the orbit settles on a $4$-cycle with multiplier $\approx -0.0305$. Find $\lambda$, and compare with the value $\log|2 - r|$ for a fixed point at $r = 2.6$.
step: By Theorem 1, $\lambda = \frac14\log|m| = \frac14\log 0.0305$ (the absolute value is used).
step: $\log 0.0305 \approx -3.49$, so $\lambda \approx -0.873$.
step: For a fixed point at $r = 2.6$ the multiplier is $2 - r = -0.6$, so $\lambda = \log 0.6 \approx -0.511$.
step: Both are negative, as expected for attracting cycles. The sign of the multiplier is irrelevant to $\lambda$ because of the absolute value.
answer: $\lambda \approx -0.873$ at $r = 3.5$ and $\approx -0.511$ at $r = 2.6$.

@example
title: A chaotic exponent from the semiconjugacy
problem: Use the formula for $(f_4^n)'$ to show that $\lambda = \log 2$ for the orbit of $x_0 = \sin^2(\pi/7)$.
step: Here $\theta_0 = 1/7$. Then $\sin(2^{n+1}\pi/7)$ takes only the values $\pm\sin(\pi/7), \pm\sin(2\pi/7), \pm\sin(3\pi/7)$ in some order, since $2^{n+1} \bmod 7$ cycles through $2, 4, 1$.
step: All three sines are nonzero, so $\log|\sin(2^{n+1}\pi/7)|$ is bounded, say by $B$, and $\log|\sin(2\pi/7)|$ is a fixed number.
step: Therefore $\frac1n\log|(f_4^n)'(x_0)| = \log 2 + O(1/n) \to \log 2$.
answer: $\lambda = \log 2$ (this orbit is a repelling $3$-cycle, so it is not a chaotic orbit despite $\lambda > 0$).

@mistakes
- Identifying $\lambda > 0$ with chaos: periodic repelling orbits have $\lambda > 0$ too, and unbounded orbits can have it as well.
- Leaving out the absolute value in $\log|f'(x)|$: derivatives can be negative, and the logarithm of a negative number is undefined.
- Averaging over a transient: include the transient and the estimate is biased by $O(1/n)$, so discard it.
- Believing that float simulation of the doubling map is chaotic: a double has only finitely many binary digits and the map shifts them out, giving $0$ after at most $1074$ steps.

model:
```python
import math


def lyapunov(r, x0, n_trans, n):
    """Lyapunov exponent of the logistic map from the derivative formula."""
    x = x0
    for _ in range(n_trans):
        x = r * x * (1 - x)
    total = 0.0
    for _ in range(n):
        slope = abs(r * (1 - 2 * x))
        if slope == 0:
            return float('-inf')
        total += math.log(slope)
        x = r * x * (1 - x)
    return total / n
```
hint: Evaluate the derivative at the current point before advancing, accumulate its log, and divide by `n` at the end.
solution: The derivative must be taken at the point from which the step starts, $x_i$ for $i = 0, \dots, n-1$. For attracting cycles the answer converges to $\frac1k\log|m|$ (Theorem 1), so the first two tests are tight; for chaotic parameters only a wide range is meaningful because the exact value depends on the orbit (about $\log 2$ at $r = 4$ and about $0.49$ at $r = 3.9$). The period-$3$ window at $r = 3.83$ gives a negative exponent, which shows how a small change in $r$ switches between order and chaos.

```python
def steps_to_zero(theta, max_steps):
    """Doublings (mod 1) of a float until it becomes exactly 0.0."""
    steps = 0
    while theta != 0.0:
        if steps >= max_steps:
            return None
        theta = (2 * theta) % 1.0
        steps += 1
    return steps
```
hint: Check `theta != 0.0` and the step limit before each application.
solution: A double in $(0, 1)$ equals $m/2^k$ with $m$ odd and $k \le 1074$; each doubling removes one binary digit, so $k$ doublings reach exactly $0.0$. The float $0.1$ is $3602879701896397/2^{55}$, which needs $55$ steps. A computer simulation of the doubling map therefore dies out, although the true map has exponent $\log 2$ and a positive-measure set of orbits that never reach $0$: floating-point numbers are the wrong model for the doubling map.

model:
```python
import math


def lyapunov_rate(r, x0, d0, n_trans, n):
    """Lyapunov exponent from the growth of a renormalized separation."""
    x = x0
    for _ in range(n_trans):
        x = r * x * (1 - x)
    y = x + d0
    total = 0.0
    for _ in range(n):
        x = r * x * (1 - x)
        y = r * y * (1 - y)
        d = y - x
        total += math.log(abs(d) / d0)
        y = x + d0 if d > 0 else x - d0
    return total / n
```
hint: Reset the separation to exactly `d0` after each step, keeping its sign, so the two orbits never drift apart.
solution: Each step multiplies the separation by $|f'(x)|$ to first order, so $\log(|d|/d_0) \approx \log|f'(x)|$ and the average is the exponent, with an error of order $d_0$. Renormalizing stops the separation from saturating at the size of the attractor. The tolerances for chaotic parameters are wide because the estimate from $2000$ steps fluctuates by a few hundredths.

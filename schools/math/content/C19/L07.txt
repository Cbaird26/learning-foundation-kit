@article
A chemical reactor sits at a steady state. Turn up a feed rate, and for a while nothing changes except that the steady state moves a little; then at a critical rate the concentrations begin to oscillate, with an amplitude that grows smoothly from zero. This is the **Hopf bifurcation**: a fixed point loses stability because a pair of complex eigenvalues crosses the imaginary axis, and a periodic orbit is born.

### The eigenvalue picture

For $\dot{\mathbf{x}} = F(\mathbf{x}, \mu)$ with a fixed point $\mathbf{x}^*(\mu)$ the Jacobian $J(\mu)$ has eigenvalues $\lambda = \alpha(\mu) \pm i\omega(\mu)$ when $\tau^2 < 4\Delta$. A Hopf bifurcation happens at $\mu_0$ where $\alpha(\mu_0) = 0$ with $\omega(\mu_0) > 0$. In terms of the trace and determinant, $J$ has eigenvalues $\pm i\omega_0$ if and only if $\tau = 0$ and $\Delta = \omega_0^2 > 0$ (the characteristic polynomial is then $\lambda^2 + \Delta$). A zero trace with $\Delta < 0$ gives a saddle, and a zero determinant gives a zero eigenvalue, the saddle-node family of Week 2.

**Theorem (Hopf; sufficient conditions).** Let $F$ be sufficiently smooth and let $\dot{\mathbf{x}} = F(\mathbf{x}, \mu)$ be a planar system with a smooth branch of fixed points $\mathbf{x}^*(\mu)$ whose Jacobian has eigenvalues $\alpha(\mu) \pm i\omega(\mu)$ with (i) $\alpha(\mu_0) = 0$ and $\omega(\mu_0) = \omega_0 > 0$, (ii) **transversality**: $\alpha'(\mu_0) \ne 0$, and (iii) the first Lyapunov coefficient $\ell_1 \ne 0$ (a number computed from the Taylor coefficients of $F$ up to order three). Then for $\mu$ near $\mu_0$ on one side, a unique small periodic orbit exists near $\mathbf{x}^*$, with amplitude proportional to $\sqrt{|\mu - \mu_0|}$ and period close to $2\pi/\omega_0$. If $\ell_1 < 0$ the bifurcation is **supercritical**: the cycle exists after the fixed point loses stability and is stable. If $\ell_1 > 0$ it is **subcritical**: an unstable cycle exists before the fixed point loses stability and shrinks onto it. *(Stated without proof; the proof reduces the system to the normal form below by a change of coordinates and an averaging argument.)*

Each hypothesis matters. Without transversality the eigenvalues can touch the imaginary axis and turn back: $J(\mu) = \begin{pmatrix} \mu^2 & -1 \\ 1 & \mu^2 \end{pmatrix}$ has eigenvalues $\mu^2 \pm i$, whose real part is $0$ at $\mu = 0$ but never changes sign, so stability does not change. Without $\ell_1 \ne 0$ the first nonlinear term vanishes: a linear system, or a conservative one, has eigenvalues $\pm i\omega$ and no cycle is born.

### Normal forms

In polar coordinates the supercritical and subcritical normal forms are
$$\dot{r} = \mu r - r^3, \qquad \dot{r} = \mu r + r^3, \qquad \dot{\theta} = \omega .$$
For $\dot{r} = \mu r - r^3 = r(\mu - r^2)$: for $\mu \le 0$ the origin is the only fixed point of the radial equation and is stable; for $\mu > 0$ the origin is unstable, and $r = \sqrt{\mu}$ is a stable fixed point of the radial equation (since $\frac{d}{dr}(\mu r - r^3) = \mu - 3r^2 = -2\mu < 0$ there), that is, a stable limit cycle of radius $\sqrt{\mu}$ and period $2\pi/\omega$. The amplitude $\sqrt{\mu}$ explains why Hopf oscillations "switch on" gently but quickly: at $\mu = 0.01$ the radius is already $0.1$.

For $\dot{r} = \mu r + r^3$ the cycle $r = \sqrt{-\mu}$ exists for $\mu < 0$ and is unstable. When $\mu$ passes $0$ the origin loses stability and orbits leave. Real systems usually have a higher-order term that saturates the growth, for instance
$$\dot{r} = \mu r + r^3 - r^5 = r(\mu + r^2 - r^4).$$
With $s = r^2$ the cycles solve $s^2 - s - \mu = 0$, so $s = \frac{1 \pm \sqrt{1 + 4\mu}}{2}$. For $-\frac14 < \mu < 0$ there are two cycles: a small unstable one and a large stable one, and the origin is stable. This coexistence is **hysteresis**: increasing $\mu$ through $0$ makes the state jump to the large cycle, and decreasing it keeps the large cycle until $\mu = -\frac14$, where the two cycles collide and annihilate (a saddle-node of cycles).

### Detecting a Hopf bifurcation by computation

The function below returns the largest real part of the eigenvalues of $\begin{pmatrix} a & b \\ c & d \end{pmatrix}$ and shows how a Hopf crossing looks along a parameter. For the Brusselator $\dot{x} = a - (b+1)x + x^2y$, $\dot{y} = bx - x^2y$, the fixed point $(a, b/a)$ has $J = \begin{pmatrix} b - 1 & a^2 \\ -b & -a^2 \end{pmatrix}$, with $\tau = b - 1 - a^2$ and $\Delta = a^2 > 0$. So the Hopf value is $b = 1 + a^2$, with frequency $\omega = a$.

```python
import math


def max_real_part(a, b, c, d):
    """Largest real part of the eigenvalues of [[a, b], [c, d]]."""
    tr, det = a + d, a * d - b * c
    disc = tr * tr - 4 * det
    if disc < 0:
        return tr / 2
    return (tr + math.sqrt(disc)) / 2


for b in (1.5, 1.9, 2.0, 2.1, 2.5):
    print(b, round(max_real_part(b - 1, 1, -b, -1), 3))
```

For $a = 1$ the output is `1.5 -0.25`, `1.9 -0.05`, `2.0 0.0`, `2.1 0.05`, `2.5 0.25`: the real part is $\tau/2 = (b - 2)/2$, crossing zero linearly at $b = 2$, so transversality holds. This locates the bifurcation; whether the cycle is stable (supercritical) needs $\ell_1$ or a simulation.

title: The Hopf value of a damped oscillator family
problem: For $\dot{x} = y$, $\dot{y} = -x + \mu y$, find the Hopf bifurcation and its frequency, and check transversality.
step: The origin is a fixed point with $J = \begin{pmatrix} 0 & 1 \\ -1 & \mu \end{pmatrix}$, so $\tau = \mu$ and $\Delta = 1$.
step: The eigenvalues are $\frac{\mu}{2} \pm i\sqrt{1 - \mu^2/4}$ for $|\mu| < 2$. The real part vanishes at $\mu = 0$, where $\Delta = 1 > 0$: eigenvalues $\pm i$, so $\omega_0 = 1$.
step: Transversality: $\alpha(\mu) = \mu/2$, so $\alpha'(0) = 1/2 \ne 0$.
step: The origin is stable for $\mu < 0$ and unstable for $\mu > 0$. The system is linear, so no cycle is born: the conditions (i) and (ii) hold but $\ell_1 = 0$ because there are no nonlinear terms, and hypothesis (iii) fails.
answer: Eigenvalues cross the imaginary axis at $\mu = 0$ with frequency $\omega_0 = 1$, but with no nonlinear terms the theorem does not apply and there is no limit cycle.

@example
title: Hysteresis in the saturated subcritical form
problem: For $\dot{r} = \mu r + r^3 - r^5$ with $\mu = -0.16$, find the cycles and their stability.
step: Substitute $s = r^2$: $s^2 - s - \mu = s^2 - s + 0.16 = 0$, so $s = \frac{1 \pm \sqrt{1 - 0.64}}{2} = \frac{1 \pm 0.6}{2}$, that is, $s = 0.2$ and $s = 0.8$.
step: The radii are $r = \sqrt{0.2} \approx 0.447$ and $r = \sqrt{0.8} \approx 0.894$.
step: Stability: at a cycle $g(r) = \dot{r}$ has derivative $2r^2(1 - 2r^2) = 2s(1 - 2s)$. For $s = 0.2$ this is $0.4 \cdot 0.6 = 0.24 > 0$ (unstable). For $s = 0.8$ it is $1.6 \cdot (-0.6) = -0.96 < 0$ (stable).
step: The origin is stable since $\mu < 0$. The unstable cycle at $r \approx 0.447$ separates the basin of the origin from that of the large cycle at $r \approx 0.894$.
answer: An unstable cycle of radius $\approx 0.447$ and a stable cycle of radius $\approx 0.894$, with the origin also stable.

@mistakes
- Declaring a Hopf bifurcation from $\tau = 0$ alone: also check $\Delta > 0$, since $\tau = 0$ with $\Delta < 0$ is a saddle crossing, not an oscillation.
- Forgetting transversality: if $\alpha(\mu)$ touches $0$ and turns back, no cycle is born.
- Concluding that every Hopf bifurcation produces a stable cycle. A subcritical one produces an unstable cycle before the bifurcation and a jump to a distant attractor after it.
- Treating the first Lyapunov coefficient as optional: when $\ell_1 = 0$ (a linear system or a conservative one) the theorem does not apply and the dynamics must be studied from higher-order terms.

model:
```python
import math


def find_hopf(J, lo, hi, tol):
    """Hopf value where the trace changes sign and the determinant is > 0."""
    def trace(mu):
        a, b, c, d = J(mu)
        return a + d

    t_lo, t_hi = trace(lo), trace(hi)
    if t_lo * t_hi > 0:
        return None
    while hi - lo > tol:
        mid = (lo + hi) / 2
        t_mid = trace(mid)
        if t_mid * t_lo > 0:
            lo, t_lo = mid, t_mid
        else:
            hi = mid
    mu0 = (lo + hi) / 2
    a, b, c, d = J(mu0)
    det = a * d - b * c
    if det <= 0:
        return None
    return mu0, math.sqrt(det)
```
hint: Compare the sign of the trace at the midpoint with its sign at `lo` using a product, and check the determinant only after the loop.
solution: Bisection on the trace keeps a sign change inside the interval, so the final midpoint is within `tol` of a zero of $\tau$ (the same proof as for any bisection). The determinant test separates a Hopf crossing from a saddle crossing: the second test matrix has $\tau = m - 2$ but $\Delta = -12 < 0$, so it returns `None`. The third has $\tau = 2m$ with a crossing at $0$, but the interval $[1, 5]$ does not contain it.

```python
def radius_after(mu, r0, T, n):
    """Runge-Kutta integration of r' = mu r - r^3 over time T."""
    def f(r):
        return mu * r - r ** 3

    h = T / n
    r = r0
    for _ in range(n):
        k1 = f(r)
        k2 = f(r + h / 2 * k1)
        k3 = f(r + h / 2 * k2)
        k4 = f(r + h * k3)
        r += h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
    return r
```
hint: The state is a single number, so each of the four slopes is one call to `f`.
solution: For $\mu > 0$ the radius settles at $\sqrt{\mu}$, so doubling the amplitude needs four times the parameter: the ratio $0.6/0.3 = 2$ in the test is the square-root law $r = \sqrt{\mu}$. At $\mu = 0$ the decay is algebraic, $r = r_0/\sqrt{1 + 2r_0^2T}$ (critical slowing down), which the first test uses as an exact check of the integrator; for $\mu < 0$ it is exponential.

```python
import math


def stable_radii(mu):
    """Limit cycles of r' = r (mu + r^2 - r^4) with their stability."""
    disc = 1 + 4 * mu
    if disc < 0:
        return []
    if disc == 0:
        return [(math.sqrt(0.5), 'semi-stable')]
    out = []
    for sign in (-1, 1):
        s = (1 + sign * math.sqrt(disc)) / 2
        if s > 0:
            out.append((math.sqrt(s), 'stable' if s > 0.5 else 'unstable'))
    return out
```
hint: Handle the discriminant cases first, then loop over the two signs, smaller root first.
solution: Cycles are positive roots of $\mu + s - s^2$; the derivative of $r\,g(r)$ at a root is $2s(1 - 2s)$, which is negative (stable) exactly when $s > 1/2$. For $\mu \ge 0$ the smaller root is $\le 0$ and is dropped, which leaves one stable cycle; for $-\frac14 < \mu < 0$ both roots are positive, an unstable inner and a stable outer cycle; at $\mu = -\frac14$ they merge in a semi-stable cycle, and for $\mu < -\frac14$ none remain.

@article
Two species compete for the same food. Each grows when alone, each hurts the other. Who wins, and can both survive? A nonlinear system $\dot{x} = f(x, y)$, $\dot{y} = g(x, y)$ usually cannot be solved, but near each fixed point it looks linear, and the fixed points together with their types give the skeleton of the phase portrait.

### Fixed points and the Jacobian

Write the system as $\dot{\mathbf{x}} = F(\mathbf{x})$ with $F = (f, g)$ continuously differentiable. A **fixed point** is a point $\mathbf{x}^*$ with $F(\mathbf{x}^*) = 0$. The **Jacobian matrix** at $\mathbf{x}^*$ is
$$J = \begin{pmatrix} f_x & f_y \\ g_x & g_y \end{pmatrix}\Big|_{\mathbf{x}^*} .$$
If $\mathbf{u} = \mathbf{x} - \mathbf{x}^*$ is small, then $\dot{\mathbf{u}} = J\mathbf{u} + (\text{terms of size } \|\mathbf{u}\|^2)$, so the **linearization** is $\dot{\mathbf{u}} = J\mathbf{u}$, which Week 3 classifies.

A fixed point is **hyperbolic** if no eigenvalue of $J$ has real part zero. In the plane, that means $\Delta \ne 0$ and not ($\tau = 0$ and $\Delta > 0$).

**Theorem (Hartman–Grobman).** Let $F$ be continuously differentiable and let $\mathbf{x}^*$ be a *hyperbolic* fixed point. Then in some neighborhood of $\mathbf{x}^*$ the flow of $\dot{\mathbf{x}} = F(\mathbf{x})$ is topologically conjugate to the flow of its linearization: there is a homeomorphism that maps orbits to orbits and preserves the direction of time. In particular a saddle, a stable or unstable node and a stable or unstable spiral of the linearization are the same in the nonlinear system. *(Stated without proof.)*

The hypothesis cannot be dropped. Take $\dot{x} = -y + \mu x(x^2 + y^2)$, $\dot{y} = x + \mu y(x^2 + y^2)$. At the origin $J = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$ has eigenvalues $\pm i$ for every $\mu$: a center. With $r^2 = x^2 + y^2$ we get $r\dot{r} = x\dot{x} + y\dot{y} = \mu r^4$, so $\dot{r} = \mu r^3$ and the origin is a stable spiral for $\mu < 0$, an unstable spiral for $\mu > 0$, and a true center only for $\mu = 0$. So at a non-hyperbolic point the linearization is inconclusive.

### Phase portraits

To sketch a phase portrait: (1) find the **nullclines**, the curves $f = 0$ (where the flow is vertical) and $g = 0$ (where it is horizontal); their intersections are the fixed points; (2) classify each fixed point with $J$ and note the eigendirections of nodes and saddles; (3) draw the sign of $(\dot{x}, \dot{y})$ in each region between nullclines; (4) connect the pieces. The stable and unstable curves of a saddle are **separatrices**: they separate regions with different long-term behavior.

For $\dot{x} = x(3 - x - 2y)$, $\dot{y} = y(2 - x - y)$ the nullclines are $x = 0$ or $x + 2y = 3$, and $y = 0$ or $x + y = 2$, so the fixed points are $(0, 0)$, $(3, 0)$, $(0, 2)$ and $(1, 1)$. The Jacobian is $\begin{pmatrix} 3 - 2x - 2y & -2x \\ -y & 2 - x - 2y \end{pmatrix}$ and gives: at $(0,0)$ the matrix $\operatorname{diag}(3, 2)$, an unstable node; at $(3,0)$ the matrix $\begin{pmatrix} -3 & -6 \\ 0 & -1 \end{pmatrix}$, a stable node; at $(0,2)$ the matrix $\begin{pmatrix} -1 & 0 \\ -2 & -2 \end{pmatrix}$, a stable node; at $(1,1)$ the matrix $\begin{pmatrix} -1 & -2 \\ -1 & -1 \end{pmatrix}$ with $\Delta = -1 < 0$, a saddle. So one of the species dies out, depending on which side of the saddle's stable curve the initial population lies on.

### Computing the Jacobian numerically

**Theorem (central difference).** If $g$ is $C^3$ on $[x - h, x + h]$ and $|g'''| \le M$ there, then $\left|\dfrac{g(x+h) - g(x-h)}{2h} - g'(x)\right| \le \dfrac{M h^2}{6}$.

*Proof.* Taylor's theorem with remainder gives $g(x \pm h) = g(x) \pm hg'(x) + \frac{h^2}{2}g''(x) \pm \frac{h^3}{6}g'''(\xi_\pm)$ for some $\xi_\pm$ in the interval. Subtracting and dividing by $2h$ leaves $g'(x) + \frac{h^2}{12}\left(g'''(\xi_+) + g'''(\xi_-)\right)$, and the last term has absolute value at most $Mh^2/6$. $\blacksquare$

Rounding errors in $g$ of size $\varepsilon$ add about $\varepsilon/h$, so $h \approx 10^{-5}$ is a good compromise in double precision.

```python
def jacobian(F, p, h=1e-5):
    """Central-difference Jacobian of F at the point p (list of floats)."""
    n = len(p)
    J = [[0.0] * n for _ in range(n)]
    for j in range(n):
        up, dn = list(p), list(p)
        up[j] += h
        dn[j] -= h
        fu, fd = F(up), F(dn)
        for i in range(n):
            J[i][j] = (fu[i] - fd[i]) / (2 * h)
    return J


F = lambda v: [v[0] * (3 - v[0] - 2 * v[1]), v[1] * (2 - v[0] - v[1])]
print([[round(a, 4) + 0.0 for a in row] for row in jacobian(F, [1, 1])])
```

This prints `[[-1.0, -2.0], [-1.0, -1.0]]`, the matrix at the saddle. A numerical Jacobian is off by about $10^{-10}$, so a test such as $\tau = 0$ must use a tolerance.

@example
title: Fixed points of a damped pendulum-like system
problem: Classify the fixed points of $\dot{x} = y$, $\dot{y} = -\sin x - y$ in $-\pi \le x \le \pi$.
step: Fixed points: $\dot{x} = 0$ gives $y = 0$, and then $\dot{y} = 0$ gives $\sin x = 0$, so $x = 0, \pm\pi$. The fixed points in the strip are $(0, 0)$, $(\pi, 0)$ and $(-\pi, 0)$.
step: The Jacobian is $J = \begin{pmatrix} 0 & 1 \\ -\cos x & -1 \end{pmatrix}$.
step: At $(0, 0)$: $J = \begin{pmatrix} 0 & 1 \\ -1 & -1 \end{pmatrix}$, so $\tau = -1$, $\Delta = 1$, $D = 1 - 4 < 0$: a stable spiral. The hanging pendulum settles.
step: At $(\pm\pi, 0)$: $J = \begin{pmatrix} 0 & 1 \\ 1 & -1 \end{pmatrix}$, so $\Delta = -1 < 0$: a saddle. The inverted pendulum is unstable. All three points are hyperbolic, so by the Hartman–Grobman theorem the types are those of the nonlinear system.
answer: $(0, 0)$ is a stable spiral; $(\pm\pi, 0)$ are saddles.

@example
title: Nullclines and the sign of the flow
problem: For $\dot{x} = x(3 - x - 2y)$, $\dot{y} = y(2 - x - y)$ (the competition model above), which way does the flow point in the region $x > 0$, $y > 0$ above both lines $x + 2y = 3$ and $x + y = 2$?

step: Then $3 - x - 2y < 0$ and $x > 0$, so $\dot{x} < 0$.

@mistakes
- Using linearization at a non-hyperbolic fixed point. When $J$ has eigenvalues $\pm i\omega$ (or a zero eigenvalue), the nonlinear terms decide, as $\dot{r} = \mu r^3$ shows.
- Computing the Jacobian with the roles of $x$ and $y$ swapped: row $i$ holds the derivatives of the $i$th component of $F$ with respect to $x$ and $y$.
- Classifying from the Jacobian at the wrong point: each fixed point has its own matrix, so evaluate $J$ after substituting the coordinates.
- Forgetting that a numerical Jacobian is only approximate: testing $\tau = 0$ or $\Delta = 0$ with `==` misclassifies, so use a tolerance such as $10^{-6}$.

model:
```python
def newton2(F, J, p0, tol, max_iter):
    """Newton's method in the plane; returns ((x, y), updates) or None."""
    x, y = p0
    for k in range(max_iter + 1):
        f1, f2 = F(x, y)
        if max(abs(f1), abs(f2)) < tol:
            return (x, y), k
        if k == max_iter:
            return None
        a, b, c, d = J(x, y)
        det = a * d - b * c
        dx = (d * f1 - b * f2) / det
        dy = (-c * f1 + a * f2) / det
        x, y = x - dx, y - dy
    return None
```
hint: Test the stopping condition before each update; Cramer's rule gives $\Delta_x = (d f_1 - b f_2)/\det J$ and $\Delta_y = (-c f_1 + a f_2)/\det J$.
solution: Newton's method replaces $F$ by its linearization at the current point and jumps to the zero of that. Checking the tolerance first handles the starting point and counts only the updates actually made; the step limit is enforced after the last allowed update has been tested. Convergence is quadratic near a zero where $\det J \ne 0$, which is why six updates suffice from $(2, 2)$.

model:
```python
def classify_point(F, p, h):
    """Classify a planar fixed point from a numerical Jacobian."""
    J = [[0.0, 0.0], [0.0, 0.0]]
    for j in range(2):
        up, dn = list(p), list(p)
        up[j] += h
        dn[j] -= h
        fu, fd = F(up), F(dn)
        for i in range(2):
            J[i][j] = (fu[i] - fd[i]) / (2 * h)
    tr = J[0][0] + J[1][1]
    det = J[0][0] * J[1][1] - J[0][1] * J[1][0]
    if abs(det) < 1e-6 or (abs(tr) < 1e-6 and det > 0):
        return 'non-hyperbolic'
    if det < 0:
        return 'saddle'
    side = 'stable' if tr < 0 else 'unstable'
    return side + (' node' if tr * tr - 4 * det >= 0 else ' spiral')
```
hint: Fill the matrix column by column by perturbing one coordinate at a time, then apply the trace and determinant tests in the stated order.
solution: The central difference is exact up to $O(h^2)$ by the error bound, so the entries are accurate to about $10^{-10}$. For $\dot{x} = y - x^3$ the computed trace at the origin is about $10^{-10}$ rather than exactly $0$, which is why the non-hyperbolic test needs a tolerance. The check for non-hyperbolic points comes first because the saddle and node tests would misclassify them.

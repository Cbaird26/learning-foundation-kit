@article
Most differential equations have no formula, but you can always step along the slope field. Starting at $(t_0, y_0)$, move a short distance $h$ in the direction the equation prescribes, then repeat.

### Euler's method

$$y_{n+1} = y_n + h\,f(t_n, y_n), \qquad t_{n+1} = t_n + h.$$
In Python:

```python
def euler(f, t0, y0, h, n):
    t, y = t0, y0
    for _ in range(n):
        y = y + h * f(t, y)      # slope uses the OLD (t, y)
        t = t + h
    return y

f = lambda t, y: y               # y' = y, y(0) = 1, so y(1) = e
for n in (10, 20, 40):
    print(n, abs(euler(f, 0, 1, 1/n, n) - 2.718281828))
```
This prints errors of about $0.1245$, $0.0650$, $0.0332$: each time $h$ is halved, the error is halved.

### Better methods

**Improved Euler (Heun)** averages two slopes: $k_1 = f(t_n, y_n)$, $k_2 = f(t_n + h,\ y_n + hk_1)$, $y_{n+1} = y_n + \frac h2(k_1 + k_2)$.

**Classical Runge-Kutta (RK4)** samples four slopes:
$$k_1 = f(t_n, y_n),\quad k_2 = f\!\left(t_n + \tfrac h2,\ y_n + \tfrac h2k_1\right),\quad k_3 = f\!\left(t_n + \tfrac h2,\ y_n + \tfrac h2k_2\right),\quad k_4 = f(t_n + h,\ y_n + hk_3),$$
$$y_{n+1} = y_n + \frac h6\left(k_1 + 2k_2 + 2k_3 + k_4\right).$$

### Order and error

The **local error** is the error made in a single step. A method of **order** $p$ has local error $O(h^{p+1})$. Reaching a fixed time $T$ takes $T/h$ steps, so these errors accumulate to a **global error** $O(h^p)$.

| method | order $p$ | slope evaluations per step | error ratio when $h$ is halved |
|---|---|---|---|
| Euler | 1 | 1 | about $2$ |
| Heun | 2 | 2 | about $4$ |
| RK4 | 4 | 4 | about $16$ |

RK4 costs four times as much per step, but it can use a far larger $h$ for the same accuracy. You can measure the order yourself: compute the error for $h$, $h/2$, $h/4$ and look at the ratios.

### Stability

Accuracy is not the only concern. For $y' = -\lambda y$ with $\lambda > 0$, Euler's method gives $y_{n+1} = (1 - h\lambda)\,y_n$, so $y_n = (1 - h\lambda)^n y_0$. The numerical solution decays only if $|1 - h\lambda| < 1$, that is
$$h < \frac{2}{\lambda}.$$
For larger $h$ the numerical solution oscillates with growing amplitude even though the true solution decays. Equations with a very fast decay rate (stiff equations) force tiny steps on explicit methods. A good habit: rerun with half the step and see whether the answer moves.

@example
title: Euler's method by hand
problem: Use Euler's method for $y' = t - y$, $y(0) = 1$ to approximate $y(1)$ with $h = 0.5$, and compare with the exact solution $y = t - 1 + 2e^{-t}$.
step: The update is $y_{n+1} = y_n + 0.5\,(t_n - y_n)$.
step: Step 1, from $(0, 1)$: the slope is $0 - 1 = -1$, so $y_1 = 1 + 0.5(-1) = 0.5$ at $t = 0.5$.
step: Step 2, from $(0.5, 0.5)$: the slope is $0.5 - 0.5 = 0$, so $y_2 = 0.5$ at $t = 1$.
step: The exact value is $y(1) = 2/e \approx 0.7358$, so the error is about $0.236$.
step: Repeating with $h = 0.25$ (four steps: $0.75,\ 0.625,\ 0.59375,\ 0.6328$) gives error about $0.103$. Halving $h$ roughly halved the error, as expected for a first order method.

@example
title: Euler's method can be unstable
problem: Apply Euler's method to $y' = -10y$, $y(0) = 1$ with $h = 0.05$ and with $h = 0.25$. What happens?
step: Euler gives $y_n = (1 - 10h)^n$.
step: For $h = 0.05$ the factor is $1 - 0.5 = 0.5$, so $y_n = 0.5^n$ decays, as the true solution $e^{-10t}$ does (the accuracy is poor but the behavior is right).
step: For $h = 0.25$ the factor is $1 - 2.5 = -1.5$, so $y_n = 1,\ -1.5,\ 2.25,\ -3.375, \dots$: it grows and alternates in sign although the true solution decays to $0$.
step: The dividing line is $|1 - 10h| = 1$, i.e. $h = 2/10 = 0.2$. Below it the method is stable; above it, unstable.

@mistakes
- Updating $t$ before computing the slope, or using the new $y$ in the slope; Euler uses $f(t_n, y_n)$.
- Confusing local and global error: Euler's one-step error is $O(h^2)$, but the error after a fixed time is only $O(h)$.
- Trusting a numerical solution that looks smooth; always repeat with a smaller step, and remember the stability limit $h < 2/\lambda$.
- Counting only steps, not cost: one RK4 step needs four evaluations of $f$.

@practice self
prompt: Write a Python program that estimates the order of Euler's method and of RK4 for $y' = y$, $y(0) = 1$ on $[0, 1]$. Use $n = 10, 20, 40$ steps, compute the error at $t = 1$ against $e$, print the ratio of successive errors for each method, and say what the ratios tell you.
solution: A model program:
```python
import math

def euler_step(f, t, y, h):
    return y + h * f(t, y)

def rk4_step(f, t, y, h):
    k1 = f(t, y)
    k2 = f(t + h/2, y + h/2 * k1)
    k3 = f(t + h/2, y + h/2 * k2)
    k4 = f(t + h, y + h * k3)
    return y + h/6 * (k1 + 2*k2 + 2*k3 + k4)

def solve(step, f, y0, n):
    h, t, y = 1.0 / n, 0.0, y0
    for _ in range(n):
        y = step(f, t, y, h)
        t += h
    return y

f = lambda t, y: y
for name, step in (("Euler", euler_step), ("RK4", rk4_step)):
    errs = [abs(solve(step, f, 1.0, n) - math.e) for n in (10, 20, 40)]
    print(name, errs, [errs[i] / errs[i+1] for i in range(2)])
```
The Euler ratios are close to $2$ and the RK4 ratios close to $16$. Halving $h$ divides the error by $2^p$, so Euler has order $p = 1$ and RK4 has order $p = 4$.

rubric: The conclusion links ratio $2^p$ to the order: about $2$ for Euler (order 1) and about $16$ for RK4 (order 4).

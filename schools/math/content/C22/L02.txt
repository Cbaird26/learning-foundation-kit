@article
A DFA has exactly one move at each step. A **nondeterministic finite automaton (NFA)** may have several moves, or none, and may also move without reading a symbol. Nondeterminism does not model a machine that guesses by luck; it is a convenient way to describe a search in which *some* sequence of choices may succeed.

### Definition

An NFA is a 5-tuple $N = (Q, \Sigma, \delta, q_0, F)$ where $\delta : Q \times \Sigma_\varepsilon \to \mathcal{P}(Q)$ and $\Sigma_\varepsilon = \Sigma \cup \{\varepsilon\}$. The value $\delta(q, a)$ is a *set* of states, possibly empty. An **$\varepsilon$-transition** moves to a new state without consuming input.

$N$ **accepts** $w$ if there is *some* way to read $w$ (possibly interleaving $\varepsilon$-moves) that ends in a state of $F$. All other branches are irrelevant, and a branch that gets stuck simply dies. The language of $N$ is the set of accepted strings.

### Tracking sets of states

To decide acceptance, keep the set of all states the NFA could currently be in. For an NFA with no $\varepsilon$-moves, after reading $a$ the set $S$ becomes $\bigcup_{q \in S} \delta(q, a)$. With $\varepsilon$-moves, define the **$\varepsilon$-closure** $E(S)$ as all states reachable from $S$ using only $\varepsilon$-moves (including $S$ itself). Start with $E(\{q_0\})$ and after each symbol $a$ replace $S$ by $E\big(\bigcup_{q \in S} \delta(q,a)\big)$. The string is accepted when the final set contains an accepting state.

### The subset construction

**Theorem.** Every NFA has an equivalent DFA.

Given $N = (Q, \Sigma, \delta, q_0, F)$, build the DFA $D = (\mathcal{P}(Q), \Sigma, \delta_D, E(\{q_0\}), F_D)$ where

$$\delta_D(S, a) = E\Big(\bigcup_{q \in S} \delta(q, a)\Big), \qquad F_D = \{S : S \cap F \neq \emptyset\}.$$

By induction on $|w|$, after reading $w$ the DFA is in exactly the set of states in which the NFA could be, so $D$ accepts $w$ iff $N$ does. Hence **regular languages are exactly the languages recognized by NFAs.**

In practice build only the subsets reachable from the start set, by a search. The worst case still has $2^{|Q|}$ states, and some languages really need them: "the symbol $n$ places from the end is $1$" has an NFA with $n+1$ states but no DFA with fewer than $2^n$ states. So NFAs can be exponentially more compact than DFAs, though never more powerful.

### Closure properties made easy

NFAs make closure proofs short. For union, add a new start state with $\varepsilon$-moves to both start states. For concatenation, add $\varepsilon$-moves from every accepting state of the first machine to the start of the second. For the star operation, add a new accepting start state with an $\varepsilon$-move to the old start, and $\varepsilon$-moves from the old accepting states back to the old start. This is the heart of the equivalence of regular expressions and automata next week.

@example
title: Subset construction on a small NFA
problem: The NFA over $\{0,1\}$ has states $q_0,q_1,q_2$, start state $q_0$, accepting set $\{q_2\}$ and moves $\delta(q_0,0)=\{q_0\}$, $\delta(q_0,1)=\{q_0,q_1\}$, $\delta(q_1,0)=\delta(q_1,1)=\{q_2\}$, and nothing from $q_2$. Convert it to a DFA.
step: There are no $\varepsilon$-moves, so the start set is $\{q_0\}$. Compute its transitions: on $0$ it goes to $\{q_0\}$, on $1$ to $\{q_0,q_1\}$.
step: From $\{q_0,q_1\}$: on $0$, $q_0$ gives $\{q_0\}$ and $q_1$ gives $\{q_2\}$, so the result is $\{q_0,q_2\}$; on $1$, $\{q_0,q_1\} \cup \{q_2\} = \{q_0,q_1,q_2\}$.
step: From $\{q_0,q_2\}$: on $0$, $\{q_0\} \cup \emptyset = \{q_0\}$; on $1$, $\{q_0,q_1\}$.
step: From $\{q_0,q_1,q_2\}$: on $0$, $\{q_0\} \cup \{q_2\} \cup \emptyset = \{q_0,q_2\}$; on $1$, $\{q_0,q_1\} \cup \{q_2\} = \{q_0,q_1,q_2\}$. No new subsets appear, so the DFA has $4$ states (not $2^3 = 8$).
step: The accepting states are those containing $q_2$: $\{q_0,q_2\}$ and $\{q_0,q_1,q_2\}$. The language is the set of strings whose second-to-last symbol is $1$.
answer: A $4$-state DFA with start $\{q_0\}$ and accepting states $\{q_0,q_2\}$ and $\{q_0,q_1,q_2\}$.

@example
title: Epsilon-closures
problem: An NFA has states $1,2,3,4$ with $\varepsilon$-moves $1 \to 2$ and $2 \to 3$, and a single symbol move $\delta(3,a)=\{4\}$. Find the set of states after reading $a$ from the start state $1$.
step: Compute the closure of the start state: from $1$ we can reach $2$, and from $2$ we can reach $3$, so $E(\{1\}) = \{1,2,3\}$.
step: Apply the symbol $a$ to every state in the set: $\delta(1,a)=\emptyset$, $\delta(2,a)=\emptyset$, $\delta(3,a)=\{4\}$. The union is $\{4\}$.
step: Take the closure of $\{4\}$. State $4$ has no $\varepsilon$-moves, so $E(\{4\}) = \{4\}$.
answer: After reading $a$ the NFA can be only in state $4$.

@mistakes
- Treating nondeterminism as "the machine tries all branches and all must accept". Acceptance needs only one accepting branch.
- Forgetting the $\varepsilon$-closure of the start state, or forgetting to close again after each symbol.
- Forgetting that the empty set is also a DFA state: if no NFA state survives, the DFA moves to $\emptyset$ and stays there.
- Assuming the subset construction always produces $2^{|Q|}$ states. That is the upper bound; build only the reachable subsets.

    todo = list(states)

    current = {start}

model:
```python
def to_dfa(delta, start, accepting, alphabet):
    start_set = frozenset({start})
    dfa_delta = {}
    seen = {start_set}
    todo = [start_set]
    while todo:
        subset = todo.pop()
        for ch in alphabet:
            target = set()
            for q in subset:
                target |= delta.get((q, ch), set())
            target = frozenset(target)
            dfa_delta[(subset, ch)] = target
            if target not in seen:
                seen.add(target)
                todo.append(target)
    dfa_accepting = {s for s in seen if s & set(accepting)}
    return dfa_delta, start_set, dfa_accepting
```
hint: Use a worklist of subsets, starting with `frozenset({start})`; `frozenset` values can be dictionary keys and set members.
hint: For each subset and each symbol, the target is the union of the NFA moves; record the transition and add the target to the worklist if it is new.
solution: Search the subset graph from `{start}`. Each popped subset gets one transition per symbol, computed as the union of the NFA's move sets; new targets are queued. At the end, a DFA state is accepting when it intersects the NFA's accepting set. Only reachable subsets are built.

```python
def nfa_accepts_eps(delta, eps, start, accepting, w):
    def close(states):
        result = set(states)
        todo = list(states)
        while todo:
            q = todo.pop()
            for r in eps.get(q, set()):
                if r not in result:
                    result.add(r)
                    todo.append(r)
        return result

    current = close({start})
    for ch in w:
        moved = set()
        for q in current:
            moved |= delta.get((q, ch), set())
        current = close(moved)
    return bool(current & set(accepting))
```
hint: Write a helper that closes a set of states under `eps`, then use it at the start and after every symbol.
hint: Closing after the symbol move matters: the NFA may take $\varepsilon$-moves both before and after reading a symbol.
solution: The state set always holds the closure. Begin with `close({start})`, and for each symbol take the union of the moves and close it again. Acceptance is whether the final set meets `accepting`.

@article
A finite automaton cannot count to an unbounded number. Give it a **stack** (a last-in, first-out memory of unlimited size) and it can. The result is a **pushdown automaton (PDA)**, the machine model matching context-free grammars.

### Definition

A PDA is a 6-tuple $P = (Q, \Sigma, \Gamma, \delta, q_0, F)$ with a finite state set $Q$, input alphabet $\Sigma$, **stack alphabet** $\Gamma$, start state $q_0$, accepting states $F$, and the **nondeterministic** transition function

$$\delta : Q \times \Sigma_\varepsilon \times \Gamma_\varepsilon \to \mathcal{P}(Q \times \Gamma_\varepsilon).$$

A transition $(q, a, X) \to (r, Y)$ reads: *in state $q$, reading input symbol $a$ (or none, if $a = \varepsilon$), with $X$ on top of the stack (or ignoring the stack, if $X = \varepsilon$), move to state $r$, pop $X$ and push $Y$.* Stack symbols pushed are written top first. A PDA **accepts** $w$ if some computation reads all of $w$ and ends in a state of $F$. The stack contents at the end do not matter, but a common trick is to push a bottom marker (here `$`) first so the machine can tell when the stack is "empty".

### A PDA for $\{0^n1^n\}$

States $q_0, \dots, q_3$ with $q_3$ accepting. Transitions, in the notation (state, input, pop) $\to$ (state, push):

| Move | Purpose |
|---|---|
| $(q_0, \varepsilon, \varepsilon) \to (q_1, \texttt{\$})$ | push the bottom marker |
| $(q_1, 0, \varepsilon) \to (q_1, 0)$ | push a $0$ for each $0$ read |
| $(q_1, 1, 0) \to (q_2, \varepsilon)$ | first $1$: pop a $0$ |
| $(q_2, 1, 0) \to (q_2, \varepsilon)$ | each further $1$: pop a $0$ |
| $(q_1, \varepsilon, \texttt{\$}) \to (q_3, \varepsilon)$ | accept $\varepsilon$ |
| $(q_2, \varepsilon, \texttt{\$}) \to (q_3, \varepsilon)$ | marker reached: counts matched |

The stack counts the $0$s, then the $1$s cancel them. Any input in which the $1$s do not match the $0$s leaves a stuck computation or a leftover $0$ on the stack.

### Nondeterminism is essential

The language of even-length palindromes $\{ww^R\}$ is accepted by a PDA that pushes the first half, *guesses* the midpoint with an $\varepsilon$-move, and then pops matching symbols. No deterministic PDA can recognize it, because a machine reading left to right cannot know where the middle is. So, unlike for finite automata, **deterministic PDAs are strictly weaker than nondeterministic PDAs**.

### The main theorem

**Theorem.** A language is context-free if and only if some PDA recognizes it.

*Grammar to PDA:* push $S$; then repeatedly, if the top of the stack is a variable $A$, nondeterministically replace it by the right-hand side of one of its rules, and if the top is a terminal, pop it while matching it against the input. *PDA to grammar:* a variable $A_{pq}$ generates all strings that take the PDA from state $p$ with an empty stack to state $q$ with an empty stack. The construction is longer; know the statement and idea.

### Beyond context-free

A stack can compare two quantities but not three. The **pumping lemma for context-free languages** says that long strings in a CFL can be written $uvxyz$ with $|vy| > 0$ and $|vxy| \le p$ such that $uv^ixy^iz$ stays in the language for all $i \ge 0$. It shows that $\{a^nb^nc^n\}$ is not context-free.

### Simulating a PDA

Because a PDA is nondeterministic, a simulator searches over **configurations** (state, input position, stack). Code that holds a stack as a string with the top at index $0$ is easy to write, but you must bound the stack height, since $\varepsilon$-moves can push forever.

@example
title: Tracing the 0^n 1^n PDA
problem: Show that the PDA above accepts $0011$ and rejects $001$.
step: Start in $q_0$ with an empty stack. The $\varepsilon$-move pushes the marker: state $q_1$, stack `$` (top first).
step: Read $0$: push $0$, so the stack is `0$`. Read the second $0$: the stack is `00$`. State is still $q_1$.
step: Read $1$ with $0$ on top: pop it, go to $q_2$, stack `0$`. Read the second $1$: pop again, stack `$`.
step: The input is used up. The $\varepsilon$-move $(q_2, \varepsilon, \texttt{\$}) \to (q_3, \varepsilon)$ pops the marker and enters the accepting state $q_3$. So $0011$ is accepted.
step: For $001$: after reading all three symbols the machine is in $q_2$ with stack `0$`. The only $\varepsilon$-move needs `$` on top, but a $0$ is on top, so it cannot reach $q_3$. No computation accepts, so $001$ is rejected.
answer: $0011$ is accepted; $001$ is rejected.

@example
title: A PDA for even palindromes
problem: Design a PDA for $\{ww^R : w \in \{a,b\}^*\}$ and trace it on $abba$.
step: In the first phase, push each input symbol. In the second phase, pop symbols while matching the input. The machine guesses the switch point nondeterministically.
step: Moves: $(q_0, \varepsilon, \varepsilon) \to (q_1, \texttt{\$})$; $(q_1, a, \varepsilon) \to (q_1, a)$; $(q_1, b, \varepsilon) \to (q_1, b)$; $(q_1, \varepsilon, \varepsilon) \to (q_2, \varepsilon)$ (the guess); $(q_2, a, a) \to (q_2, \varepsilon)$; $(q_2, b, b) \to (q_2, \varepsilon)$; $(q_2, \varepsilon, \texttt{\$}) \to (q_3, \varepsilon)$ with $q_3$ accepting.
step: On $abba$, push $a$, then $b$: the stack is `ba$`. Guess the midpoint here and go to $q_2$.
step: Read $b$ with $b$ on top: pop. Read $a$ with $a$ on top: pop. The stack is `$`, the input is done, and the $\varepsilon$-move to $q_3$ accepts.
step: On $abab$, the only way to empty the stack correctly would guess the midpoint after $ab$, leaving `ba$`, but the remaining input $ab$ would need to match $b$ first, so it fails. Other midpoints also fail, so $abab$ is rejected.
answer: A PDA that pushes, guesses the middle, and pops matching symbols, as described.

@mistakes
- Thinking the stack must be empty for acceptance. In this definition acceptance is by final state; emptiness is detected with a bottom marker.
- Assuming a PDA is deterministic. Without nondeterminism, palindromes cannot be recognized.
- Forgetting that a computation must read the whole input. A branch that reaches an accepting state with input remaining does not accept.
- Expecting a single stack to verify three equal counts. $\{a^nb^nc^n\}$ is not context-free.

```python
def balanced(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        else:
            if not stack or stack.pop() != pairs[ch]:
                return False
    return not stack
```

model:
```python
def pda_accepts(transitions, start, accepting, w):
    first = (start, 0, "")
    seen = {first}
    todo = [first]
    while todo:
        q, i, stack = todo.pop()
        if i == len(w) and q in accepting:
            return True
        for p, a, x, r, y in transitions:
            if p != q:
                continue
            if a and (i >= len(w) or w[i] != a):
                continue
            if x and (not stack or stack[0] != x):
                continue
            rest = stack[1:] if x else stack
            new_stack = y + rest
            if len(new_stack) > 40:
                continue
            config = (r, i + (1 if a else 0), new_stack)
            if config not in seen:
                seen.add(config)
                todo.append(config)
    return False
```
hint: Search over configurations `(state, position, stack)` with a worklist and a set of configurations already seen.
hint: A transition applies if the state matches, the input symbol matches (or is empty), and the stack top matches (or `x` is empty). Build the new stack as `y` followed by the old stack with the popped symbol removed.
solution: Treat each configuration as a node and each applicable transition as an edge. Accept as soon as a configuration with the whole input read and an accepting state is found. The `seen` set stops the search from repeating configurations, and the stack-height cap keeps the number of configurations finite.

model:
```python
def max_depth(s):
    depth = 0
    best = 0
    for ch in s:
        if ch == "(":
            depth += 1
            best = max(best, depth)
        else:
            depth -= 1
            if depth < 0:
                return -1
    return best if depth == 0 else -1
```
hint: A stack of identical symbols is just a counter. Add one for `(` and subtract one for `)`.
hint: If the counter ever goes below zero, or is not zero at the end, return `-1`; track the largest value seen.
solution: Keep a counter as the stack height. Increase it on `(` and record the maximum, decrease it on `)`, and return `-1` if it drops below zero or does not end at zero. For `")("` the first symbol already drives it below zero.

@quiz mc
prompt: Which of these languages is **not** context-free?
choice*: $\{a^nb^nc^n : n \ge 0\}$
choice: $\{a^nb^n : n \ge 0\}$
choice: The palindromes over $\{a,b\}$.
choice: $\{a^ib^jc^k : i = j \text{ or } j = k\}$
hint: One stack can compare two counts. Which language needs three counts equal at once?
solution: The pumping lemma for context-free languages rules out $\{a^nb^nc^n\}$: in $s = a^pb^pc^p$ the window $vxy$ has length at most $p$, so it cannot contain both an $a$ and a $c$; pumping $v$ and $y$ therefore changes at most two of the three counts (and at least one, since $|vy| > 0$), leaving them unequal. The others are context-free: a stack compares $a$s with $b$s, palindromes are accepted by guessing the middle, and the last language is a union of two context-free languages.

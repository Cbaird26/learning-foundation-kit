@article
A language is **decidable** if some Turing machine halts on every input and accepts exactly the strings of the language. We study which natural problems about machines are decidable. Problems are encoded as languages, with $\langle \cdot \rangle$ denoting an encoding of an object as a string.

### Decidable problems about finite automata and grammars

- $A_{\mathrm{DFA}} = \{\langle B, w \rangle : B \text{ is a DFA that accepts } w\}$. *Decider:* simulate $B$ on $w$. This always halts after $|w|$ steps.
- $A_{\mathrm{NFA}}$ and $A_{\mathrm{REX}}$ are decidable by converting to a DFA first.
- $E_{\mathrm{DFA}} = \{\langle B \rangle : L(B) = \emptyset\}$. *Decider:* mark the start state, then repeatedly mark states reachable from marked states. Accept if no accepting state is marked.
- $EQ_{\mathrm{DFA}} = \{\langle B, C \rangle : L(B) = L(C)\}$. *Decider:* build a DFA for the **symmetric difference** $(L(B) \setminus L(C)) \cup (L(C) \setminus L(B))$ using the product construction and complement, and test it for emptiness.
- $A_{\mathrm{CFG}}$ is decidable: convert the grammar to Chomsky normal form; any derivation of a string of length $n \ge 1$ has exactly $2n - 1$ steps, so try all of them (for the empty string, check for the rule $S \to \varepsilon$).
- $E_{\mathrm{CFG}}$ is decidable: mark every variable that can generate a terminal string, and check whether the start variable gets marked.
- $EQ_{\mathrm{CFG}}$, by contrast, is **undecidable**, even though $E_{\mathrm{CFG}}$ is decidable.

### Countability and diagonalization

A set is **countable** if it is finite or its elements can be listed in a sequence indexed by $1, 2, 3, \dots$. The set $\Sigma^*$ of strings over a finite alphabet is countable (list it in shortlex order), and so is the set of all Turing machines, since each machine has a finite description. The set of all languages over $\{0,1\}$, however, is **uncountable**. Suppose they could be listed $L_1, L_2, \dots$, and let $s_1, s_2, \dots$ be the strings in shortlex order. Define $L = \{s_i : s_i \notin L_i\}$. Then $L$ differs from every $L_i$ on the string $s_i$, so it is not on the list. This is **diagonalization**.

So there are uncountably many languages but only countably many Turing machines. **Some languages are not even recognizable**, and a fortiori not decidable. The remaining question is whether a *natural* language is undecidable.

### The undecidability of $A_{\mathrm{TM}}$

Let $A_{\mathrm{TM}} = \{\langle M, w \rangle : M \text{ is a TM that accepts } w\}$.

*Recognizable.* A **universal Turing machine** $U$ simulates $M$ on $w$ and accepts if $M$ accepts. If $M$ loops, so does $U$.

*Undecidable.* Suppose a decider $H$ exists for $A_{\mathrm{TM}}$. Build a machine $D$: on input $\langle M \rangle$, run $H$ on $\langle M, \langle M \rangle \rangle$ and do the **opposite**: accept if $H$ rejects, reject if $H$ accepts. Since $H$ always halts, $D$ always halts. Now run $D$ on its own description $\langle D \rangle$. By construction $D$ accepts $\langle D \rangle$ if and only if $H$ rejects $\langle D, \langle D \rangle \rangle$, that is, if and only if $D$ does *not* accept $\langle D \rangle$. A contradiction. Hence no such $H$ exists.

The diagonal is visible in a table whose rows are machines and columns are encodings of machines, with a $1$ if the machine accepts that input. $D$ is the row obtained by flipping the diagonal, so it differs from every machine's row.

@example
title: Deciding emptiness for a DFA
problem: A DFA has states $1,2,3$, alphabet $\{a,b\}$, start state $1$, accepting set $\{3\}$ and transitions $1 \xrightarrow{a} 2$, $1 \xrightarrow{b} 1$, $2 \xrightarrow{a} 1$, $2 \xrightarrow{b} 2$, $3 \xrightarrow{a} 3$, $3 \xrightarrow{b} 3$. Use the decider for $E_{\mathrm{DFA}}$ to decide whether its language is empty.
step: Mark the start state: marked $= \{1\}$.
step: From $1$ we can reach $2$ (on $a$) and $1$ (on $b$), so mark $2$: marked $= \{1, 2\}$.
step: From $2$ we can reach only $1$ and $2$. No new state is marked, so the procedure stops.
step: The accepting state $3$ is not marked, so no string leads to it.
answer: The language is empty, so the machine is in $E_{\mathrm{DFA}}$.

@example
title: The diagonal table
problem: Four machines $M_1, \dots, M_4$ give the table below, where entry $(i, j)$ is $1$ if $M_i$ accepts $\langle M_j \rangle$. Find the row of $D$ and show it differs from every $M_i$.
step: The table is: $M_1$: $1\,0\,1\,0$; $M_2$: $0\,0\,1\,1$; $M_3$: $1\,1\,1\,0$; $M_4$: $0\,1\,0\,0$.
step: The diagonal entries $(i, i)$ are $1, 0, 1, 0$.
step: $D$ does the opposite on each diagonal entry, so its row is $0\,1\,0\,1$.
step: $D$ differs from $M_i$ in column $i$ for every $i$: for example $D$ gives $0$ where $M_1$ gives $1$, and $D$ gives $1$ where $M_2$ gives $0$. So $D$ is none of the listed machines.
answer: $D = 0\,1\,0\,1$, which appears in no row.

@mistakes
- Saying "undecidable" when the problem is merely slow. Undecidable means *no* algorithm exists, however much time is allowed.
- Mixing up decidable and recognizable: $A_{\mathrm{TM}}$ is recognizable (by a universal machine) but not decidable.
- Proposing to decide $A_{\mathrm{TM}}$ by simulating and rejecting "if it takes too long". No bound on the time exists, so a timeout gives wrong answers.
- Forgetting that the diagonal argument needs $D$ to halt on its own description; that is what the decider $H$ guarantees.

model:
```python
def is_empty_dfa(delta, start, accepting, alphabet):
    seen = {start}
    todo = [start]
    while todo:
        q = todo.pop()
        if q in accepting:
            return False
        for ch in alphabet:
            r = delta[(q, ch)]
            if r not in seen:
                seen.add(r)
                todo.append(r)
    return True
```
hint: This is graph reachability from the start state.
hint: As soon as you reach an accepting state, the language is not empty.
solution: Search the states reachable from `start`; if any is accepting, return `False`. If the search finishes without finding one, no string is accepted, so return `True`. The decider always halts, because the number of states is finite.

model:
```python
def equivalent_dfas(d1, d2, alphabet):
    t1, s1, f1 = d1
    t2, s2, f2 = d2
    seen = {(s1, s2)}
    todo = [(s1, s2)]
    while todo:
        p, q = todo.pop()
        if (p in f1) != (q in f2):
            return False
        for ch in alphabet:
            nxt = (t1[(p, ch)], t2[(q, ch)])
            if nxt not in seen:
                seen.add(nxt)
                todo.append(nxt)
    return True
```
hint: Run both DFAs in lockstep: a node of the search is a pair `(state_in_d1, state_in_d2)`.
hint: If some reachable pair has exactly one accepting state, a string leading to it is accepted by one DFA and not the other.
solution: The languages differ exactly when some string leads to a pair of states in which one is accepting and the other is not. Searching the reachable pairs (at most the product of the two state counts) finds such a pair if it exists. This is the emptiness test on the symmetric difference, done directly.

prompt: Prove that the set of all languages over $\{0,1\}$ is uncountable, using diagonalization. Then explain why this implies some language is not Turing-recognizable.
solution: Suppose the languages could be listed as $L_1, L_2, L_3, \dots$. Let $s_1, s_2, s_3, \dots$ be all strings over $\{0,1\}$ in shortlex order. Define $L = \{s_i : s_i \notin L_i\}$. For every $i$, the string $s_i$ is in $L$ exactly when it is not in $L_i$, so $L \ne L_i$. Thus $L$ is a language that is not on the list, a contradiction, so the languages are uncountable. Every Turing machine has a finite description, so there are only countably many Turing machines, hence only countably many Turing-recognizable languages. Since there are uncountably many languages in all, some language is not recognizable.

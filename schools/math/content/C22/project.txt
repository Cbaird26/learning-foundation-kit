@review
This guide follows the course week by week; use it to plan your revision.

**Weeks 1 to 2: DFAs and NFAs.** An alphabet is a finite set of symbols, a language is a set of strings. A DFA $(Q, \Sigma, \delta, q_0, F)$ has a total transition function and exactly one computation per input. Design by deciding what each state remembers. An NFA allows several or zero moves and $\varepsilon$-moves, and accepts if some branch accepts. The subset construction turns an NFA into a DFA with at most $2^{|Q|}$ states (build only reachable subsets, close under $\varepsilon$ first).

**Weeks 3 to 4: Regular expressions and the pumping lemma.** Regular expressions (union, concatenation, star) describe exactly the regular languages (Thompson's construction one way, state elimination the other). The pumping lemma: a regular language has a length $p$ such that every long string splits as $xyz$ with $|y| > 0$, $|xy| \le p$ and $xy^iz$ in the language for all $i \ge 0$. To prove non-regularity, choose $s$ in terms of $p$, handle every split, and pump up or down. It cannot prove regularity.

**Weeks 5 to 6: Context-free languages.** A CFG generates strings by derivations; parse trees show structure; a grammar is ambiguous if a string has two parse trees. PDAs (an NFA plus a stack) recognize exactly the context-free languages, and nondeterminism is essential. $\{a^nb^nc^n\}$ is not context-free.

**Weeks 7 to 8: Turing machines.** A TM has an unbounded tape and a head; it accepts, rejects or loops. A decider always halts. Multitape and nondeterministic machines and enumerators are equivalent to single-tape machines. The Church–Turing thesis equates algorithms with TMs; it is a thesis, not a theorem.

**Weeks 9 to 10: Decidability.** $A_{\mathrm{DFA}}$, $E_{\mathrm{DFA}}$, $EQ_{\mathrm{DFA}}$, $A_{\mathrm{CFG}}$ and $E_{\mathrm{CFG}}$ are decidable. $A_{\mathrm{TM}}$ is recognizable but undecidable by diagonalization; $\mathrm{HALT}_{\mathrm{TM}}$ and $E_{\mathrm{TM}}$ are undecidable by reduction. Rice's theorem: every non-trivial property of $L(M)$ is undecidable. A language is decidable iff it and its complement are recognizable.

**Weeks 11 to 12: Complexity.** P is polynomial-time decidable, NP is polynomial-time verifiable ($\mathrm{P} \subseteq \mathrm{NP}$, and $\mathrm{P}$ versus $\mathrm{NP}$ is open). NP-complete means in NP and NP-hard. Cook–Levin: SAT is NP-complete. To prove $B$ NP-complete, show $B \in \mathrm{NP}$ and reduce a known NP-complete problem to $B$.

**Self-check list.**
- Can I trace a DFA, NFA, PDA and TM on an input by hand?
- Can I convert a small NFA to a DFA, and a small DFA to a regular expression?
- Can I write a complete pumping-lemma proof without the order of choices slipping?
- Can I state the direction of a reduction and say what it proves?
- Can I give a certificate and a verifier for a problem in NP?

**Common errors.** Leaving out transitions in a DFA; forgetting the empty set as a DFA state; wrong precedence in regular expressions; choosing $s$ after seeing the split; using the pumping lemma to prove regularity; reducing in the wrong direction; confusing "undecidable" with "slow"; reading NP as "not polynomial".

model:
```python
from collections import deque


def shortest_accepted(delta, start, accepting, alphabet):
    seen = {start}
    queue = deque([(start, "")])
    while queue:
        state, word = queue.popleft()
        if state in accepting:
            return word
        for ch in alphabet:
            nxt = delta[(state, ch)]
            if nxt not in seen:
                seen.add(nxt)
                queue.append((nxt, word + ch))
    return None
```
hint: Breadth-first search from the start state finds states in order of the length of the shortest string reaching them.
hint: Expand the symbols in the order given by `alphabet` and record, with each state, the string that first reached it. The first accepting state taken off the queue gives the answer.
solution: Search the DFA graph breadth first, keeping for each state the string that first reached it. Breadth-first order guarantees minimal length; expanding symbols in alphabet order guarantees that, among strings of equal length, the lexicographically first one reaches each state first. The first accepting state dequeued therefore holds the answer, and an exhausted queue means the language is empty.

check: int(run("delta = {('A','0'):'A', ('A','1'):'B', ('B','0'):'A', ('B','1'):'D', ('D','0'):'D', ('D','1'):'D'}\ncount = 0\nfor i in range(2 ** 10):\n    w = format(i, '010b')\n    s = 'A'\n    for ch in w:\n        s = delta[(s, ch)]\n    if s in ('A', 'B'):\n        count += 1\nprint(count)\n"))
hint: The DFA accepts the strings with no two consecutive $1$s. Count them by the last symbol: let $a_n$ be the number of valid strings of length $n$.
solution: State `D` is a dead state reached exactly when two $1$s are adjacent, so the DFA accepts the binary strings with no `11`. Let $a_n$ be the number of such strings of length $n$. A valid string ends in $0$ (preceded by any valid string of length $n-1$) or in $01$ (preceded by any valid string of length $n-2$), so $a_n = a_{n-1} + a_{n-2}$ with $a_0 = 1$ and $a_1 = 2$. Then $a_2 = 3$, $a_3 = 5$, $a_4 = 8$, and so on up to $a_{10} = 144$.

@exam self
prompt: Let $L = \{w \in \{a,b\}^* : w \text{ contains equally many } a\text{s and } b\text{s}\}$. (a) Give a context-free grammar for $L$. (b) Prove that $L$ is not regular, using closure under intersection and the pumping lemma. (c) Explain why $L$ is nevertheless decidable, and state how its complexity compares with the complexity of deciding a regular language.
solution: (a) $S \to aSbS \,|\, bSaS \,|\, \varepsilon$. (b) Suppose $L$ were regular. The language $a^*b^*$ is regular and regular languages are closed under intersection, so $L \cap a^*b^* = \{a^nb^n : n \ge 0\}$ would be regular. But it is not: assume it is regular with pumping length $p$ and take $s = a^pb^p$. Any split $s = xyz$ with $|y| > 0$ and $|xy| \le p$ has $y = a^k$, $k \ge 1$, so $xy^2z = a^{p+k}b^p$ has more $a$s than $b$s and is not in the language, a contradiction. So $L$ is not regular. (c) A Turing machine (indeed a simple program) can scan the input once, counting $a$s and $b$s, and accept if the counts are equal; it halts on every input, so $L$ is decidable, and in time linear in the input length on a RAM (a single-tape Turing machine needs quadratic time by crossing off pairs, or linear time with a counter on a second tape). A DFA decides a regular language in exactly $n$ steps with constant memory, while counting here needs memory that grows with the input (a counter of $O(\log n)$ bits), which is why no finite automaton suffices.
hint: For (b), intersect $L$ with a simple regular language to get a language you already know is not regular.
hint: For (c), a counter that goes up for $a$ and down for $b$ suffices; think about how much memory it needs.

@article
Automata *recognize* languages; **regular expressions** *describe* them. A regular expression is a compact algebraic formula, and the surprise of this week is that it can describe exactly the languages that finite automata can recognize.

### Formal definition

Fix an alphabet $\Sigma$. The regular expressions over $\Sigma$ and the languages they describe are defined recursively:

- $\emptyset$ describes the empty language $\{\}$, and $\varepsilon$ describes $\{\varepsilon\}$;
- each symbol $a \in \Sigma$ describes $\{a\}$;
- if $R_1$ and $R_2$ are regular expressions, so are the **union** $(R_1 \cup R_2)$, written $R_1 | R_2$ in most tools, the **concatenation** $R_1 R_2$ and the **star** $R_1^*$.

For languages, $L_1 \cup L_2$ is ordinary union, $L_1 L_2 = \{uv : u \in L_1, v \in L_2\}$, and $L^* = \{w_1 w_2 \cdots w_k : k \ge 0, \text{ each } w_i \in L\}$. The case $k = 0$ means $\varepsilon \in L^*$ always. By convention, star binds tightest, then concatenation, then union, so $ab^*|c$ means $(a(b^*))|c$.

Useful shorthand: $R^+ = RR^*$ (one or more) and $R?$ means $R | \varepsilon$. The expression $(a|b)^*$ describes every string over $\{a,b\}$.

### Examples worth knowing

| Language over $\{0,1\}$ | Regular expression |
|---|---|
| strings that end in $01$ | $(0 \cup 1)^*01$ |
| exactly two $1$s | $0^*10^*10^*$ |
| no two consecutive $1$s | $(0 \cup 10)^*(1 \cup \varepsilon)$ |
| even length | $((0 \cup 1)(0 \cup 1))^*$ |

### Kleene's theorem

**Theorem.** A language is regular (recognized by a DFA) if and only if some regular expression describes it.

*Expression to automaton.* Build an NFA by induction on the expression: a one-symbol or $\varepsilon$ machine for the base cases, and the union, concatenation and star constructions with $\varepsilon$-moves from last week for the inductive steps. This is called **Thompson's construction** and the NFA has $O(|R|)$ states.

*Automaton to expression.* Convert the DFA to a **generalized NFA** whose arrows are labeled by regular expressions, then **eliminate states** one at a time. Removing a state $q$ replaces each path $p \xrightarrow{R_1} q \xrightarrow{R_2} r$ (with a self-loop $R_3$ on $q$) by the label $R_1 R_3^* R_2$, united with any existing $p \to r$ label. When only the start and accept states remain, the label between them is the answer.

### Practical regexes

Programming languages and tools have a "regex" feature. Python's `re.fullmatch(pattern, text)` tests whether the *whole* text matches. The core operators `|`, `*`, `+`, `?` and grouping match the theory. But many extensions, notably **backreferences** like `(a*)b\1`, describe languages that are *not* regular, so such engines are more than finite automata, and may take exponential time on some patterns.

@example
title: Writing a regular expression
problem: Give a regular expression for the binary strings with no two consecutive $1$s, and show that $1010$ matches but $0110$ does not.
step: Every $1$ that is followed by another symbol must be followed by $0$. Group each $1$ with the $0$ that follows it: the blocks are $0$ and $10$.
step: A string with no $11$ is a sequence of these blocks, possibly followed by one final $1$ that has nothing after it. So the expression is $(0|10)^*(1|\varepsilon)$.
step: Match $1010$: it splits as $10$, $10$, using the block $10$ twice and the empty final part.
step: Try $0110$: after the block $0$, the remaining $110$ would have to start with a block, but neither $0$ nor $10$ begins with $11$; ending with the final optional $1$ leaves $10$ unmatched. No split works, so $0110$ does not match.
answer: $(0|10)^*(1|\varepsilon)$.

@example
title: From a DFA to a regular expression
problem: A DFA over $\{a,b\}$ has two states: $E$ (start and accepting, "even number of $a$s so far") and $O$. Reading $b$ stays in the same state; reading $a$ switches. Find a regular expression for its language by state elimination.
step: The arrows are $E \xrightarrow{b} E$, $E \xrightarrow{a} O$, $O \xrightarrow{b} O$ and $O \xrightarrow{a} E$.
step: Eliminate $O$. The only path through it is $E \xrightarrow{a} O \xrightarrow{b^*} O \xrightarrow{a} E$, which becomes a new self-loop on $E$ labeled $ab^*a$.
step: Now $E$ has two self-loops, $b$ and $ab^*a$, which combine to $b | ab^*a$. The start state is also the accepting state, so the language is described by the star of that label.
step: The result is $(b|ab^*a)^*$. It is equivalent to $b^*(ab^*ab^*)^*$: the strings with an even number of $a$s. Check on $abbab$ (two $a$s): split it as $abba$ (which is $ab^*a$ with $b^*=bb$) followed by $b$.
answer: $(b|ab^*a)^*$.

@mistakes
- Forgetting precedence: $ab^*$ means $a(b^*)$, not $(ab)^*$, and $a|bc$ means $a|(bc)$.
- Confusing a regular expression with a string it matches, or $\varepsilon$ (a string) with $\emptyset$ (no string): $\emptyset^* = \{\varepsilon\}$.
- Using `re.match` instead of `re.fullmatch` and so accepting strings with an unwanted tail.
- Thinking every feature of a programming-language regex is regular: backreferences are not.

model:
```python
def matches(r, w):
    kind = r[0]
    if kind == "empty":
        return False
    if kind == "eps":
        return w == ""
    if kind == "sym":
        return w == r[1]
    if kind == "union":
        return matches(r[1], w) or matches(r[2], w)
    if kind == "cat":
        return any(
            matches(r[1], w[:i]) and matches(r[2], w[i:])
            for i in range(len(w) + 1)
        )
    if kind == "star":
        if w == "":
            return True
        return any(
            matches(r[1], w[:i]) and matches(r, w[i:])
            for i in range(1, len(w) + 1)
        )
    raise ValueError(kind)
```
hint: Handle each kind of expression with one case, following the definition of its language.
hint: For concatenation, try every split point `w[:i]`, `w[i:]`. For star, `w` is empty or has a non-empty first piece matching the inner expression followed by a rest that matches the star again.
solution: Recurse on the structure. A concatenation matches if some split works. A star matches the empty string, or a non-empty prefix that matches the inner expression with the remainder matching the star again. Requiring the prefix to be non-empty (`range(1, ...)`) guarantees the recursion shrinks, so it terminates even when the inner expression matches $\varepsilon$.

@practice self
prompt: Give a regular expression over $\{a,b\}$ for the language of strings in which every $a$ is immediately followed by a $b$. Explain why every string matched is in the language and why every string of the language is matched. Then show how it matches $babbab$.
solution: The expression is $(b|ab)^*$. Every string it matches is a concatenation of blocks $b$ and $ab$; in each block any $a$ is immediately followed by $b$, and blocks do not create a new $a$ followed by something else, so every $a$ in the string is followed by $b$. Conversely, take a string in which every $a$ is followed by $b$. Cut it after each $b$ that ends an $ab$ pair and after each lone $b$: every piece is $b$ or $ab$ (an $a$ can only appear as the first letter of an $ab$ piece, and the string cannot end in $a$). So the string is in $(b|ab)^*$. For $babbab$: $b \cdot ab \cdot b \cdot ab$.
hint: Think of the string as a sequence of small blocks, each containing an $a$ together with the symbol that must follow it.
hint: The blocks are $b$ and $ab$; then star them.
rubric: The expression is correct: $(b|ab)^*$ or an equivalent one.
rubric: The argument covers both directions: matched strings are in the language, and every string in the language is matched.
rubric: The match of $babbab$ is shown as a split into blocks.

@quiz mc
prompt: Which regular expression describes exactly the same language as $(a|b)^*$ over $\{a,b\}$?
choice*: $(a^*b^*)^*$
choice: $a^*b^*$
choice: $(ab)^*$
choice: $a^*|b^*$
hint: Can $(a^*b^*)^*$ produce $ba$? Think of it as zero or more blocks, each of the form $a^*b^*$.
solution: The expression $(a^*b^*)^*$ can produce any string by using one block per symbol (each block is just $a$ or just $b$), so it matches every string over $\{a,b\}$. The expression $a^*b^*$ cannot produce $ba$, $(ab)^*$ only produces repetitions of $ab$, and $a^*|b^*$ cannot produce $ab$.

@quiz num
prompt: How many strings of length at most $3$ over $\{a,b\}$ (including the empty string) match the regular expression $(ab|b)^*$?
answer: 7
check: int(run("import re, itertools\nprint(sum(1 for n in range(4) for t in itertools.product('ab', repeat=n) if re.fullmatch('(ab|b)*', ''.join(t))))\n"))
hint: List the matching strings of each length: they are concatenations of the blocks $ab$ and $b$.
solution: Length $0$: $\varepsilon$. Length $1$: $b$. Length $2$: $bb$, $ab$. Length $3$: $bbb$, $abb$, $bab$. That is $1 + 1 + 2 + 3 = 7$ strings.

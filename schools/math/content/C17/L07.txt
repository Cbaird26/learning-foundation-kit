@article
The derivative is a limit, $f'(x) = \lim_{h \to 0}(f(x+h) - f(x))/h$, so it seems that taking $h$ smaller always improves the answer. Try $h = 10^{-14}$ in double precision and the answer is wrong in the third digit. There are two competing errors, and understanding both is the heart of this week.

### Truncation error

Suppose $f$ has enough continuous derivatives. Taylor's theorem gives $f(x + h) = f(x) + h f'(x) + \tfrac12 h^2 f''(\xi_1)$ for some $\xi_1$ between $x$ and $x+h$. Hence the **forward difference** satisfies
$$\frac{f(x+h) - f(x)}{h} - f'(x) = \tfrac12 h f''(\xi_1) = O(h).$$
Expanding one order further, with $\xi_\pm$ between $x$ and $x \pm h$:
$$f(x \pm h) = f(x) \pm h f'(x) + \tfrac12 h^2 f''(x) \pm \tfrac16 h^3 f'''(\xi_\pm).$$
Subtract the two expansions: $f(x+h) - f(x-h) = 2h f'(x) + \tfrac16 h^3\bigl(f'''(\xi_+) + f'''(\xi_-)\bigr)$. The **central difference** therefore satisfies
$$D(h) := \frac{f(x+h) - f(x-h)}{2h}, \qquad |D(h) - f'(x)| \le \frac{h^2}{6}\max|f'''| \quad (f \in C^3).$$
Adding the two expansions (carried to fourth order) gives the **second difference** $\dfrac{f(x+h) - 2f(x) + f(x-h)}{h^2} = f''(x) + \tfrac{1}{12}h^2 f^{(4)}(\xi)$ for $f \in C^4$.

### Rounding error and the best step size

A computer evaluates $f$ with an absolute error of at most $\epsilon$ (for $f \approx 1$, $\epsilon \approx u \approx 10^{-16}$).

**Theorem 1.** Let $f \in C^3$ with $|f'''| \le M$ near $x$, and suppose the computed values $\tilde f(x \pm h)$ satisfy $|\tilde f(x \pm h) - f(x \pm h)| \le \epsilon$. Then the computed central difference $\tilde D(h) = (\tilde f(x+h) - \tilde f(x-h))/(2h)$ satisfies (ignoring the rounding of the subtraction and division themselves)
$$|\tilde D(h) - f'(x)| \le \frac{M h^2}{6} + \frac{\epsilon}{h},$$
and the right side is smallest at $h^* = (3\epsilon/M)^{1/3}$.

*Proof.* $|\tilde D - D| \le (\epsilon + \epsilon)/(2h) = \epsilon/h$, and $|D - f'| \le Mh^2/6$; add by the triangle inequality. The function $E(h) = Mh^2/6 + \epsilon/h$ has $E'(h) = Mh/3 - \epsilon/h^2$, negative for $h < h^*$ and positive for $h > h^*$, so $h^*$ is its minimum point. $\blacksquare$

At $h^*$ the error is of order $\epsilon^{2/3}$, about $10^{-11}$ for $\epsilon = 10^{-16}$: a central difference cannot give more than about eleven correct digits. For $f(x) = \ln x$ at $x = 2$ the measured errors are about $4 \times 10^{-4}$, $4 \times 10^{-6}$, $4 \times 10^{-8}$ for $h = 10^{-1}, 10^{-2}, 10^{-3}$ (dropping a factor $100$ for each factor $10$: order $2$), a minimum of order $10^{-11}$ near $h = 10^{-5}$, and then growth like $1/h$ to about $10^{-8}$ at $h = 10^{-8}$ and $10^{-2}$ at $h = 10^{-14}$. The exact digits you see depend on the computer.

### Richardson extrapolation

If the leading error term is known, remove it. Suppose $f \in C^5$. Then $D(h) = f'(x) + a h^2 + r(h)$ with $a = f'''(x)/6$ and $|r(h)| \le C h^4$ for small $h$.

**Theorem 2 (Richardson extrapolation).** Under this assumption the combination
$$R(h) = \frac{4D(h/2) - D(h)}{3}$$
satisfies $|R(h) - f'(x)| \le \tfrac{5}{12} C h^4$.

*Proof.* $4D(h/2) - D(h) = 4f' + 4a\,h^2/4 + 4r(h/2) - f' - a h^2 - r(h) = 3f' + 4r(h/2) - r(h)$, because the $h^2$ terms $a h^2$ cancel. Hence $|R(h) - f'| = \tfrac13|4r(h/2) - r(h)| \le \tfrac13\bigl(4C h^4/16 + C h^4\bigr) = \tfrac{5}{12}C h^4$. $\blacksquare$

The idea repeats: the next extrapolation $R_{k,j} = R_{k,j-1} + (R_{k,j-1} - R_{k-1,j-1})/(4^j - 1)$ removes the $h^{2j}$ term, provided $f$ is smooth enough. Extrapolation costs a few more function values and no smaller step, so it avoids the rounding trap of tiny $h$.

```python
def central(f, x, h):
    return (f(x + h) - f(x - h)) / (2 * h)


def richardson1(f, x, h):
    """One extrapolation step: error O(h^4) for smooth f."""
    return (4 * central(f, x, h / 2) - central(f, x, h)) / 3


import math
print(abs(central(math.log, 2.0, 0.1) - 0.5) < 5e-4)        # True
print(abs(richardson1(math.log, 2.0, 0.1) - 0.5) < 1e-6)    # True
```

Both checks are evidence for particular inputs; Theorems 1 and 2 are the guarantees.

@example
title: Central difference of the exponential
problem: Estimate $f'(0)$ for $f(x) = e^x$ with $h = 0.1$, and compare the error with the bound of Theorem 1 (ignoring rounding).
step: $D(0.1) = (e^{0.1} - e^{-0.1})/0.2 = 1.10517 - 0.90484 = 0.20033$, divided by $0.2$: $D(0.1) \approx 1.001668$.
step: The exact derivative is $f'(0) = 1$, so the error is about $1.67 \times 10^{-3}$.
step: Bound: $M = \max_{[-0.1, 0.1]}|f'''| = e^{0.1} \approx 1.105$, so the bound is $Mh^2/6 \approx 1.105 \cdot 0.01/6 \approx 1.84 \times 10^{-3}$.
step: The actual error $1.67 \times 10^{-3}$ is below the bound $1.84 \times 10^{-3}$; indeed $h^2 f'''(0)/6 = 1.67 \times 10^{-3}$ is the leading term.
answer: $D(0.1) \approx 1.00167$, error $\approx 1.7 \times 10^{-3}$, below the bound $1.8 \times 10^{-3}$.

@example
title: The best step size
problem: Function values carry an error of $\epsilon = 10^{-16}$ and $|f'''| \le 1$. Find the best step size for the central difference and the error at that step.
step: By Theorem 1, $h^* = (3\epsilon/M)^{1/3} = (3 \times 10^{-16})^{1/3} \approx 6.7 \times 10^{-6}$.
step: The truncation part is $Mh^{*2}/6 \approx (6.7 \times 10^{-6})^2/6 \approx 7.5 \times 10^{-12}$.
step: The rounding part is $\epsilon/h^* \approx 10^{-16}/(6.7 \times 10^{-6}) \approx 1.5 \times 10^{-11}$, twice the truncation part (at the minimum $\epsilon/h = 2 \cdot Mh^2/6$).
step: The total bound is about $2.2 \times 10^{-11}$.
answer: $h^* \approx 6.7 \times 10^{-6}$ and a total error bound of about $2 \times 10^{-11}$.

@mistakes
- Believing that a smaller $h$ is always better: below $h^*$ the rounding term $\epsilon/h$ dominates and the error grows.
- Using the forward difference where an $O(h^2)$ method is as cheap: the central difference needs the same number of evaluations.
- Applying the Richardson factor $4$ to a method whose error expansion starts at $h$ (for the forward difference the factor is $2$): the factor is $2^p$ for a leading term $h^p$.
- Extrapolating with an $h$ so small that rounding noise, not the truncation term, is what the two values differ by.

model:
```python
def richardson_derivative(f, x, h, levels):
    """Richardson table for the central difference; returns R[levels][levels]."""
    def d(s):
        return (f(x + s) - f(x - s)) / (2 * s)

    table = []
    for k in range(levels + 1):
        row = [d(h / 2 ** k)]
        for j in range(1, k + 1):
            row.append(row[j - 1] + (row[j - 1] - table[k - 1][j - 1]) / (4 ** j - 1))
        table.append(row)
    return table[levels][levels]
```
hint: Fill the table row by row: row `k` starts with the central difference at `h / 2**k` and each later entry uses the entry to its left and the entry above that.
solution: Column $j$ removes the $h^{2j}$ error term using the factor $4^j$ (the ratio $2^{2j}$ of the error terms for steps $h$ and $h/2$), so $R[k][j]$ has error $O(h^{2j+2})$. A common slip is using $2^j - 1$ (the forward-difference factor), which does not cancel the $h^2$ term. Polynomials up to degree $5$ are differentiated exactly with `levels = 2`.

model:
```python
import math


def observed_order(f, df, x, h, rule):
    """log2 of the error ratio between step h and step h / 2."""
    def d(s):
        if rule == 'forward':
            return (f(x + s) - f(x)) / s
        return (f(x + s) - f(x - s)) / (2 * s)

    def err(s):
        return abs(d(s) - df(x))

    return math.log2(err(h) / err(h / 2))
```
hint: Define the difference quotient for the chosen rule, then take the base-2 logarithm of the ratio of the two errors.
solution: If the error behaves like $C h^p$, then $\text{err}(h)/\text{err}(h/2) \approx 2^p$, so the base-2 logarithm estimates $p$. For the cubic the central-difference error is exactly $h^2$ (the third derivative is constant), so the ratio is exactly $4$.

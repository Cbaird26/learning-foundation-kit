@review
**Week 1 – floating point.** Doubles have a $53$-bit significand; the unit roundoff is $u = 2^{-53}$ and $\mathrm{fl}(x) = x(1 + \delta)$, $|\delta| \le u$. Subtracting nearby numbers amplifies relative errors by $(|x| + |y|)/|x - y|$ (cancellation); rewrite formulas algebraically before computing.

**Week 2 – conditioning and stability.** $\kappa_f(x) = |xf'(x)/f(x)|$ measures the problem; a backward stable algorithm has forward error at most about $\kappa \times$ backward error. An unstable algorithm for a well-conditioned problem (the forward recurrence for $I_n$) is a different thing from an ill-conditioned problem.

**Weeks 3–4 – rootfinding and orders.** Bisection error $\le (b - a)/2^{n+1}$; contraction mappings converge linearly with rate $L < 1$; Newton's method converges quadratically at a simple root ($e_{n+1} \approx \frac{f''}{2f'}e_n^2$) and linearly at a multiple root. Order estimate: $p_n = \log(e_{n+1}/e_n)/\log(e_n/e_{n-1})$.

**Weeks 5–6 – interpolation.** Existence and uniqueness; error $f^{(n+1)}(\xi)\omega(x)/(n+1)!$; Runge phenomenon for equispaced nodes; Chebyshev points minimize $\max|\omega| = 2^{-n}$; piecewise linear error $h^2M_2/8$; cubic splines.

**Weeks 7–8 – differentiation and integration.** Central difference $O(h^2)$, best step about $\epsilon^{1/3}$; Richardson $(4D(h/2) - D(h))/3$; trapezoid $O(h^2)$, Simpson $O(h^4)$ and exact for cubics; $n$-point Gauss exact for degree $2n - 1$.

**Weeks 9–10 – linear algebra.** $PA = LU$ with partial pivoting, cost $\approx \frac23n^3$; $\|\delta x\|/\|x\| \le \kappa(A)\|\delta b\|/\|b\|$; normal equations $A^\top Ax = A^\top b$; QR by modified Gram–Schmidt and $Rx = Q^\top b$.

**Weeks 11–12 – iteration and ODEs.** Jacobi and Gauss–Seidel converge for strictly diagonally dominant matrices; the power method converges at rate $|\lambda_2/\lambda_1|$; Euler is first order (error $\le \frac{Mh}{2L}(e^{LT} - 1)$), RK4 is fourth order; Euler on $y' = -\lambda y$ needs $h < 2/\lambda$.

**Self-check.** Can you (1) prove the bisection bound and Newton's local convergence, (2) state each theorem with every hypothesis, (3) estimate an order from three errors, (4) say what goes wrong when a hypothesis fails (no sign change, $f'(r) = 0$, equispaced nodes, a tiny pivot, a stiff step)?

**Common errors.** Comparing floats with `==`; confusing an ill-conditioned problem with an unstable algorithm; reading orders from errors at rounding level; forgetting that Simpson needs an even number of panels; judging an answer by its residual alone; using the Euler bound to predict the size of an error.

@exam self
prompt: Let $a > 0$ and apply Newton's method to $f(x) = x^2 - a$ with a starting value $x_0 > 0$, so that $x_{n+1} = \tfrac12(x_n + a/x_n)$. Prove that (a) $x_{n+1} - \sqrt a = \dfrac{(x_n - \sqrt a)^2}{2x_n}$; (b) $x_n \ge \sqrt a$ for all $n \ge 1$ and the sequence $x_1, x_2, \dots$ is non-increasing; (c) $x_n \to \sqrt a$, and the convergence is quadratic with $e_{n+1}/e_n^2 \to 1/(2\sqrt a)$.
hint: For (a) put everything over the denominator $2x_n$. For (b) use (a) and then compare $x_{n+1}$ with $x_n$. For (c) a bounded monotone sequence converges; identify the limit with the fixed-point equation.
solution: (a) $x_{n+1} - \sqrt a = \dfrac{x_n^2 + a - 2\sqrt a\,x_n}{2x_n} = \dfrac{(x_n - \sqrt a)^2}{2x_n}$. (b) For $n \ge 0$ we have $x_n > 0$ (by induction: $x_{n+1}$ is a sum of positive terms), so (a) gives $x_{n+1} \ge \sqrt a$ for every $n \ge 0$, that is $x_n \ge \sqrt a$ for $n \ge 1$. For $n \ge 1$, $x_n \ge \sqrt a$ means $a/x_n \le x_n$, so $x_{n+1} = \tfrac12(x_n + a/x_n) \le x_n$. (c) The sequence $(x_n)_{n \ge 1}$ is non-increasing and bounded below by $\sqrt a$, so it converges to some $L \ge \sqrt a > 0$. Letting $n \to \infty$ in $x_{n+1} = \tfrac12(x_n + a/x_n)$ gives $L = \tfrac12(L + a/L)$, hence $L^2 = a$ and $L = \sqrt a$. By (a), $e_{n+1}/e_n^2 = 1/(2x_n) \to 1/(2\sqrt a)$, a finite nonzero constant, so the order is $2$ (for $x_0 \ne \sqrt a$ the errors are never zero, since $x_{n+1} = \sqrt a$ would need $x_n = \sqrt a$).
rubric: Derives the identity in (a) by direct algebra.
rubric: Shows positivity of the iterates and uses (a) for $x_n \ge \sqrt a$, then proves the monotone decrease from $a/x_n \le x_n$.
rubric: Concludes convergence by the monotone bounded argument, identifies the limit, and obtains the constant $1/(2\sqrt a)$ from (a).

model:
```python
def euler_richardson(f, t0, y0, T, N):
    """Richardson extrapolation 2 E_{2N} - E_N of Euler's method."""
    def euler(steps):
        h = (T - t0) / steps
        t, y = t0, y0
        for _ in range(steps):
            y = y + h * f(t, y)
            t = t + h
        return y

    return 2 * euler(2 * N) - euler(N)
```
hint: Write a helper that runs Euler with a given number of steps, call it with `N` and `2 * N`, and combine with weights $2$ and $-1$.
solution: Euler's error expands as $E_N = y(T) + c_1h + O(h^2)$, so $2E_{2N} - E_N = y(T) + (2 \cdot c_1h/2 - c_1h) + O(h^2) = y(T) + O(h^2)$: the first-order term cancels and the extrapolated method is second order, which the error ratio near $4$ confirms. For $y' = 2t$ Euler's error is exactly linear in $h$, so extrapolation gives the exact value $1$.

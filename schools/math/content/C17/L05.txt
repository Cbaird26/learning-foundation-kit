@article
Given $n + 1$ data points, is there a polynomial through all of them, is it the only one, and does it approximate the function that produced the data? The first two answers are yes. The third is subtler: more data points can make the approximation worse.

### Existence and uniqueness

**Theorem 1.** Let $x_0, \dots, x_n$ be distinct real numbers and $y_0, \dots, y_n$ arbitrary reals. There is exactly one polynomial $p$ of degree at most $n$ with $p(x_j) = y_j$ for $j = 0, \dots, n$.

*Proof.* *Existence.* Define the Lagrange basis polynomials $\ell_j(x) = \prod_{k \ne j} \dfrac{x - x_k}{x_j - x_k}$. Each has degree $n$, and $\ell_j(x_i) = 1$ if $i = j$ and $0$ otherwise (the denominators are nonzero because the nodes are distinct). So $p = \sum_j y_j \ell_j$ has degree at most $n$ and $p(x_i) = y_i$. *Uniqueness.* If $p$ and $q$ both qualify, $p - q$ has degree at most $n$ and $n + 1$ distinct roots $x_0, \dots, x_n$, so it is the zero polynomial. $\blacksquare$

Distinct nodes are needed: no polynomial passes through $(1, 0)$ and $(1, 1)$. The degree bound is needed too: adding a multiple of $\prod (x - x_j)$ gives other interpolants of degree $n + 1$.

### The error formula

**Theorem 2.** Let $f \in C^{n+1}[a, b]$, let $x_0, \dots, x_n \in [a, b]$ be distinct, and let $p$ be the interpolating polynomial of degree at most $n$ for $f$. For each $x \in [a, b]$ there is $\xi \in (a, b)$ with
$$f(x) - p(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}\,\omega(x), \qquad \omega(x) = \prod_{j=0}^n (x - x_j).$$

*Proof.* If $x$ is a node both sides are $0$. Otherwise $\omega(x) \ne 0$; set $K = (f(x) - p(x))/\omega(x)$ and $\varphi(t) = f(t) - p(t) - K\omega(t)$. Then $\varphi$ vanishes at the $n + 1$ nodes and at $x$: $n + 2$ distinct zeros in $[a, b]$. Repeated use of Rolle's theorem gives a zero of $\varphi'$ between each pair of consecutive zeros, so $\varphi^{(n+1)}$ has a zero $\xi$ in $(a, b)$. Since $p^{(n+1)} = 0$ and $\omega^{(n+1)} = (n+1)!$, $0 = f^{(n+1)}(\xi) - K(n+1)!$, which is the claim. $\blacksquare$

Hence $\max_{[a,b]}|f - p| \le \dfrac{\max|f^{(n+1)}|}{(n+1)!}\max_{[a,b]}|\omega|$. The first factor depends on $f$; the second on the nodes alone.

### Computing the interpolant

The Lagrange form can be evaluated directly, and works for floats and for `Fraction` alike:

```python
def lagrange_eval(xs, ys, x):
    """Evaluate the interpolating polynomial at x from its definition."""
    total = 0
    for j in range(len(xs)):
        term = ys[j]
        for k in range(len(xs)):
            if k != j:
                term = term * (x - xs[k]) / (xs[j] - xs[k])
        total = total + term
    return total
```

It costs $O(n^2)$ per point. The **barycentric formula** $p(x) = \dfrac{\sum_j w_j y_j/(x - x_j)}{\sum_j w_j/(x - x_j)}$ with weights $w_j = 1/\prod_{k \ne j}(x_j - x_k)$ costs $O(n)$ per point after $O(n^2)$ setup. It follows from $p = \omega \sum_j w_j y_j/(x - x_j)$ and $1 = \omega \sum_j w_j/(x - x_j)$ (interpolate the data $y_j = 1$ and use uniqueness). The **Newton form** $p(x) = c_0 + c_1(x - x_0) + c_2(x - x_0)(x - x_1) + \cdots$ has coefficients $c_k = f[x_0, \dots, x_k]$ given by divided differences, with $f[x_i] = y_i$ and $f[x_i, \dots, x_{i+k}] = \dfrac{f[x_{i+1}, \dots, x_{i+k}] - f[x_i, \dots, x_{i+k-1}]}{x_{i+k} - x_i}$.

### The Runge phenomenon

Take $f(x) = 1/(1 + 25x^2)$ on $[-1, 1]$, an infinitely differentiable function, and interpolate at $n + 1$ equispaced nodes. The maximum error on $[-1, 1]$, measured on a fine grid:

| degree $n$ | 4 | 6 | 10 | 14 | 20 |
|---|---|---|---|---|---|
| max error | 0.44 | 0.62 | 1.92 | 7.19 | 59.8 |

The error grows without bound as $n \to \infty$: this is the **Runge phenomenon** (Runge, 1901). The interpolant matches $f$ at the nodes and oscillates wildly near the ends. Theorem 2 explains part of it: for equispaced nodes $|\omega|$ is much larger near the ends of the interval than in the middle, and the derivatives of $f$ grow quickly (because $f$ has poles at $\pm i/5$ in the complex plane). The Weierstrass approximation theorem (1885) guarantees that good polynomials exist; it does not say that interpolation at equispaced points finds them. Next week you will see that choosing the nodes differently removes the problem.

@example
title: Error bound for a three-point interpolant
problem: Let $p$ interpolate $f(x) = \ln x$ at $x_0 = 1$, $x_1 = 2$, $x_2 = 3$. Bound $|f(1.5) - p(1.5)|$ with Theorem 2.
step: Here $n = 2$ and $f'''(x) = 2/x^3$, so $\max_{[1,3]}|f'''| = 2$ at $x = 1$.
step: The node polynomial at $x = 1.5$ is $\omega(1.5) = (1.5 - 1)(1.5 - 2)(1.5 - 3) = 0.5 \cdot (-0.5) \cdot (-1.5) = 0.375$.
step: Theorem 2 gives $|f(1.5) - p(1.5)| \le \dfrac{2}{3!} \cdot 0.375 = 0.125$.
step: The actual error is smaller: $p(1.5) \approx 0.3825$ and $\ln 1.5 \approx 0.4055$, so the error is about $0.023$, within the bound.
answer: $|f(1.5) - p(1.5)| \le 0.125$; actual error about $0.023$.

@example
title: Newton form by divided differences
problem: Find the polynomial of degree at most $2$ through $(1, 1)$, $(2, 4)$, $(4, 16)$.
step: First differences: $f[1,2] = (4 - 1)/(2 - 1) = 3$ and $f[2,4] = (16 - 4)/(4 - 2) = 6$.
step: Second difference: $f[1,2,4] = (6 - 3)/(4 - 1) = 1$.
step: Newton form: $p(x) = 1 + 3(x - 1) + 1\cdot(x - 1)(x - 2)$.
step: Expand: $1 + 3x - 3 + x^2 - 3x + 2 = x^2$. By uniqueness (Theorem 1) the polynomial through these points is $x^2$, which is why the data came from $x^2$.
answer: $p(x) = 1 + 3(x - 1) + (x - 1)(x - 2) = x^2$.

@mistakes
- Using the error formula for a function that is not $C^{n+1}$ on the interval (for example, $|x|$ at $0$): the theorem does not apply.
- Believing that higher degree always gives a better fit: with equispaced nodes the error for $1/(1 + 25x^2)$ grows with $n$.
- Dividing by zero in the barycentric formula at a node: handle $x = x_j$ separately and return $y_j$.
- Taking $\max|\omega|$ over the nodes (where $\omega = 0$) instead of over the interval.

model:
```python
from fractions import Fraction


def divided_differences(xs, ys):
    """Newton coefficients f[x0], f[x0,x1], ... computed in place."""
    n = len(xs)
    c = [Fraction(y) for y in ys]
    for k in range(1, n):
        for i in range(n - 1, k - 1, -1):
            c[i] = (c[i] - c[i - 1]) / (xs[i] - xs[i - k])
    return c
```
hint: Work in place on a copy of `ys`: for order `k`, update entries from the end down to index `k`, dividing by `xs[i] - xs[i - k]`.
solution: After the pass for order $k$, entry $i \ge k$ holds $f[x_{i-k}, \dots, x_i]$. Going from the end downward keeps the lower-order entry $c[i-1]$ available when entry $c[i]$ is updated. With `Fraction` there is no rounding at all.

model:
```python
from fractions import Fraction


def bary_eval(xs, ys, x):
    """Barycentric interpolation in exact arithmetic."""
    for xj, yj in zip(xs, ys):
        if x == xj:
            return Fraction(yj)
    num = Fraction(0)
    den = Fraction(0)
    for j in range(len(xs)):
        w = Fraction(1)
        for k in range(len(xs)):
            if k != j:
                w /= (xs[j] - xs[k])
        num += w * ys[j] / (x - xs[j])
        den += w / (x - xs[j])
    return num / den
```
hint: Compute each weight with a product over $k \ne j$, check for $x$ equal to a node first, and return `num / den`.
solution: The numerator $\sum w_j y_j/(x - x_j)$ equals $p(x)/\omega(x)$ and the denominator equals $1/\omega(x)$, so the quotient is $p(x)$. The weights can be computed once; here they are recomputed for clarity. The case $x = x_j$ is handled first because the formula has a $0/0$ there. The test data come from $p(x) = x^3 - 2x + 1$.

model:
```python
def interp_max_error(f, n, M):
    """Max error of equispaced interpolation on [-1, 1], measured on a grid."""
    xs = [-1 + 2 * i / n for i in range(n + 1)]
    ys = [f(x) for x in xs]

    def p(t):
        total = 0.0
        for j in range(n + 1):
            term = ys[j]
            for k in range(n + 1):
                if k != j:
                    term *= (t - xs[k]) / (xs[j] - xs[k])
            total += term
        return total

    worst = 0.0
    for j in range(M + 1):
        t = -1 + 2 * j / M
        worst = max(worst, abs(f(t) - p(t)))
    return worst
```
hint: Build the nodes and values once, define a local function for the Lagrange form, then take the maximum over the test points.
solution: A function in the interpolation space is reproduced exactly (up to rounding), so cubic data with $n = 3$ give zero error. For $1/(1 + 16x^2)$ the error is already above $1$ at $n = 10$: a smaller version of the Runge phenomenon. A grid maximum is only a lower bound for the true maximum, but a fine grid is close.

The constant polynomial $1$ has degree at most $n$ and takes the value $1$ at every node, so by uniqueness (Theorem 1) $s = 1$.

@article
A differential equation $y' = f(t, y)$ with $y(t_0) = y_0$ rarely has a closed-form solution, but it tells you the slope at every point: follow the slope for a short time, then recompute it. Choosing how to follow it decides the accuracy.

### Euler's method

With step $h$ and $t_n = t_0 + nh$, **Euler's method** is $y_{n+1} = y_n + h f(t_n, y_n)$: take the tangent-line step. If $y$ is the exact solution, Taylor's theorem gives $y(t_{n+1}) = y(t_n) + h f(t_n, y(t_n)) + \tfrac12 h^2 y''(\xi_n)$. The last term is the **local truncation error**, of size $O(h^2)$ per step. Over $T/h$ steps these accumulate to a **global error** of order $h$.

**Theorem 1 (convergence of Euler's method).** Let $y \in C^2[t_0, T]$ solve $y' = f(t, y)$, with $|y''| \le M$, and suppose $|f(t, u) - f(t, v)| \le L|u - v|$ for all $t \in [t_0, T]$ and all $u, v$ (with $L > 0$). If $y_0 = y(t_0)$, then for $t_n \le T$
$$|y(t_n) - y_n| \le \frac{Mh}{2L}\left(e^{L(t_n - t_0)} - 1\right).$$

*Proof.* Let $e_n = y(t_n) - y_n$. Subtracting the Euler step from the Taylor formula: $e_{n+1} = e_n + h\bigl(f(t_n, y(t_n)) - f(t_n, y_n)\bigr) + \tau_n$ with $|\tau_n| \le \tfrac12 Mh^2$. By the Lipschitz condition $|e_{n+1}| \le (1 + hL)|e_n| + \tfrac12 Mh^2$. With $e_0 = 0$, unrolling gives $|e_n| \le \tfrac12 Mh^2\sum_{j=0}^{n-1}(1 + hL)^j = \tfrac12 Mh^2\,\dfrac{(1 + hL)^n - 1}{hL}$. Finally $1 + hL \le e^{hL}$, so $(1 + hL)^n \le e^{nhL} = e^{L(t_n - t_0)}$. $\blacksquare$

The exponential factor shows how errors compound; the bound is usually pessimistic. The Lipschitz hypothesis is needed: for $y' = \sqrt{|y|}$, $y(0) = 0$ (not Lipschitz at $0$) Euler stays at $0$ while $y(t) = t^2/4$ is also a solution.

### Runge–Kutta methods

To get higher order, sample the slope at several points. The **midpoint method** (a second-order Runge–Kutta method) is
$$k_1 = f(t_n, y_n), \quad k_2 = f\bigl(t_n + \tfrac h2,\ y_n + \tfrac h2 k_1\bigr), \quad y_{n+1} = y_n + h k_2.$$
**Claim:** its local truncation error is $O(h^3)$. *Proof* (for $f$ with continuous second derivatives, starting from the exact value $y_n = y(t_n)$). The exact solution satisfies $y(t_n + h) = y + hf + \tfrac12 h^2(f_t + f f_y) + O(h^3)$, because $y'' = f_t + f_y y' = f_t + f f_y$. Taylor-expanding $k_2$ about $(t_n, y_n)$ gives $k_2 = f + \tfrac h2 f_t + \tfrac h2 f f_y + O(h^2)$, so $y_n + hk_2 = y + hf + \tfrac12 h^2(f_t + ff_y) + O(h^3)$. The two expansions agree through $h^2$. $\blacksquare$
A local error of $O(h^{p+1})$ gives a global error $O(h^p)$ by the same recurrence as in Theorem 1 (with $\tfrac12 Mh^2$ replaced by $Ch^{p+1}$), so the midpoint method is second-order. **Heun's method** $y_{n+1} = y_n + \tfrac h2\bigl(f(t_n, y_n) + f(t_{n+1}, y_n + hf(t_n, y_n))\bigr)$ is another.

The **classical fourth-order Runge–Kutta method** (Runge 1895, Kutta 1901) is
$$k_1 = f(t_n, y_n),\; k_2 = f\bigl(t_n + \tfrac h2, y_n + \tfrac h2k_1\bigr),\; k_3 = f\bigl(t_n + \tfrac h2, y_n + \tfrac h2k_2\bigr),\; k_4 = f(t_n + h, y_n + hk_3),$$
$$y_{n+1} = y_n + \tfrac h6\,(k_1 + 2k_2 + 2k_3 + k_4).$$
Its local error is $O(h^5)$ and its global error $O(h^4)$ (stated without proof; the algebra of matching Taylor series through $h^4$ is long, and this week's exercises check the order numerically). For $f$ independent of $y$ it reduces to Simpson's rule.

### Order from a table

If the global error is $Ch^p$, then halving $h$ divides it by $2^p$, so $p \approx \log_2\bigl(E(h)/E(h/2)\bigr)$.

```python
import math


def euler(f, t0, y0, T, N):
    """Euler's method with N steps from t0 to T; returns y_N."""
    h = (T - t0) / N
    t, y = t0, y0
    for _ in range(N):
        y = y + h * f(t, y)
        t = t + h
    return y


def midpoint(f, t0, y0, T, N):
    h = (T - t0) / N
    t, y = t0, y0
    for _ in range(N):
        k2 = f(t + h / 2, y + h / 2 * f(t, y))
        y = y + h * k2
        t = t + h
    return y


f = lambda t, y: y            # y' = y, y(0) = 1, exact solution e^t
e1 = abs(euler(f, 0, 1.0, 1.0, 100) - math.e)
e2 = abs(euler(f, 0, 1.0, 1.0, 200) - math.e)
print(1.9 < e1 / e2 < 2.1)    # True: order 1
```

### Stability of the step size

For $y' = -\lambda y$ with $\lambda > 0$ the exact solution decays. Euler gives $y_{n+1} = (1 - h\lambda)y_n$, so $y_n = (1 - h\lambda)^ny_0$ decays if and only if $|1 - h\lambda| < 1$, that is $h < 2/\lambda$. For larger steps the numerical solution grows although the true solution decays. For a **stiff** problem (a large $\lambda$ together with slow components) explicit methods are forced to take tiny steps; implicit methods such as backward Euler, $y_{n+1} = y_n/(1 + h\lambda)$, decay for every $h > 0$ on this equation.

step: The actual error $0.0368$ is below the bound $0.0822$, as it must be; halving $h$ would roughly halve both.

@example
title: One step of the classical Runge–Kutta method
problem: Take one RK4 step of size $h = 0.5$ for $y' = y$, $y(0) = 1$ and compare with $e^{0.5}$.
step: $k_1 = 1$. Then $k_2 = f(y + \tfrac h2k_1) = 1 + 0.25 = 1.25$.
step: $k_3 = 1 + 0.25 \cdot 1.25 = 1.3125$ and $k_4 = 1 + 0.5 \cdot 1.3125 = 1.65625$.
step: $y_1 = 1 + \tfrac{0.5}{6}(1 + 2 \cdot 1.25 + 2 \cdot 1.3125 + 1.65625) = 1 + \tfrac{0.5}{6}\cdot 7.78125 = 1.6484375$.
step: The exact value is $e^{0.5} \approx 1.6487213$, so the error is about $2.8 \times 10^{-4}$ after one big step. The result equals the Taylor polynomial $1 + h + h^2/2 + h^3/6 + h^4/24$ of $e^h$ at $h = 0.5$.
answer: $y_1 = 1.6484375$, error $\approx 2.8 \times 10^{-4}$.

@mistakes
- Believing that a smaller local error automatically means a smaller global error: the global error is the accumulated, amplified local error, and the order drops by one.
- Taking steps larger than the stability limit $2/\lambda$ for Euler on a decaying problem: the numerical solution then grows.
- Using the Euler bound to predict the actual error: it contains $e^{L T}$ and is usually far too large; use it for the order, not the size.
- In RK4, evaluating all four slopes at the old $y_n$ instead of at the intermediate points $y_n + \tfrac h2 k_1$, and so on.

```python
def rk4(f, t0, y0, T, N):
    """Classical fourth-order Runge-Kutta method; returns y at t = T."""
    h = (T - t0) / N
    t, y = t0, y0
    for _ in range(N):
        k1 = f(t, y)
        k2 = f(t + h / 2, y + h / 2 * k1)
        k3 = f(t + h / 2, y + h / 2 * k2)
        k4 = f(t + h, y + h * k3)
        y = y + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
        t = t + h
    return y
```
hint: Compute the four slopes in order, each evaluated at the point built from the previous slope, then combine with weights $1, 2, 2, 1$ over $6$.
solution: The step is Simpson-like: $k_1$ at the start, $k_2$ and $k_3$ at the midpoint (hence weight $2$ each), $k_4$ at the end. The error ratios near $16$ for halved steps confirm global order $4$, since $2^4 = 16$. For $f$ independent of $y$ the method reproduces Simpson's rule, which is exact for the cubic $t^3$ (second test). With `T == t0` the step is $0$ and `y0` is returned.

```python
def euler_system(f, t0, y0, T, N):
    """Euler's method for a system; returns the final state."""
    h = (T - t0) / N
    t = t0
    y = list(y0)
    for _ in range(N):
        slope = f(t, y)
        y = [y[i] + h * slope[i] for i in range(len(y))]
        t = t + h
    return y
```
hint: Compute the whole slope vector from the old state before changing any component.
solution: Each step multiplies the oscillator's radius squared by exactly $1 + h^2$, so after $N$ steps the energy $y_1^2 + y_2^2$ is $(1 + h^2)^N$: Euler's method makes the oscillation grow, a failure of qualitative behavior that the order-1 error bound does not forbid. A common bug is updating `y[0]` first and then using the new value for `y[1]`, which gives a different method. In the third test $y_1 = t$ and $y_2' = 2t$; Euler gives $y_2 = 0.75$ at $t = 1$ (the left-endpoint sum of $2t$).

```python
def heun(f, t0, y0, T, N):
    """Heun's method (second order); returns y at t = T."""
    h = (T - t0) / N
    t, y = t0, y0
    for _ in range(N):
        k1 = f(t, y)
        k2 = f(t + h, y + h * k1)
        y = y + h / 2 * (k1 + k2)
        t = t + h
    return y
```
hint: The second slope is taken at the Euler predictor $y + hk_1$ at time $t + h$; average the two slopes.
solution: Heun's method is the trapezoid rule with an Euler predictor. For $y' = g(t)$ it is exactly the trapezoid rule, hence exact for $g$ linear (the first two tests). Its global error is $O(h^2)$, so doubling $N$ divides the error by about $4$, as the ratio test checks.

@quiz self
prompt: For the test equation $y' = \lambda y$ show that one step of the midpoint method multiplies $y_n$ by $1 + h\lambda + \tfrac12(h\lambda)^2$. Compare with the exact factor $e^{h\lambda}$ to find the leading term of the local truncation error, and explain what this says about the order.
hint: Compute $k_1 = \lambda y_n$, then $k_2$, then $y_{n+1} = y_n + hk_2$; expand $e^{h\lambda}$ in a power series.
solution: With $k_1 = \lambda y_n$ we get $k_2 = \lambda(y_n + \tfrac h2\lambda y_n) = \lambda y_n(1 + \tfrac12 h\lambda)$, so $y_{n+1} = y_n + h\lambda y_n(1 + \tfrac12h\lambda) = y_n\bigl(1 + h\lambda + \tfrac12(h\lambda)^2\bigr)$. The exact solution satisfies $y(t_n + h) = e^{h\lambda}y(t_n) = y(t_n)\bigl(1 + h\lambda + \tfrac12(h\lambda)^2 + \tfrac16(h\lambda)^3 + \cdots\bigr)$. The two factors agree through the $h^2$ term, so the local truncation error is $\tfrac16(h\lambda)^3y(t_n) + O(h^4)$, which is $O(h^3)$. A local error of $O(h^3)$ gives a global error of $O(h^2)$, so the method is of order $2$.

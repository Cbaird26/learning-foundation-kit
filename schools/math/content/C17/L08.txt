@article
Most integrals have no closed form: $\int_0^1 e^{-x^2}dx$ cannot be written with elementary functions. A **quadrature rule** replaces $\int_a^b f$ by a weighted sum $\sum_j w_j f(x_j)$. The idea is always the same: integrate an interpolating polynomial exactly.

### The trapezoid rule

Split $[a, b]$ into $N$ panels of width $h = (b - a)/N$ with nodes $x_i = a + ih$. Interpolating $f$ linearly on each panel and integrating gives the **composite trapezoid rule**
$$T_N = h\left(\tfrac12 f(x_0) + f(x_1) + \dots + f(x_{N-1}) + \tfrac12 f(x_N)\right).$$

**Theorem 1.** If $f \in C^2[a, b]$ and $M_2 = \max|f''|$, then $\left|\int_a^b f - T_N\right| \le \dfrac{(b-a)\,h^2}{12} M_2$.

*Proof.* On one panel $[x_i, x_{i+1}]$ let $p$ be the linear interpolant; $\int p$ is the trapezoid area. By Theorem 2 of Week 5, $|f(x) - p(x)| \le \tfrac12 M_2 (x - x_i)(x_{i+1} - x)$ on the panel. Since $\int_{x_i}^{x_{i+1}}(x - x_i)(x_{i+1} - x)\,dx = h^3/6$, the panel error is at most $M_2 h^3/12$. Summing $N$ panels gives $N h^3 M_2/12 = (b-a)h^2 M_2/12$. $\blacksquare$

### Simpson's rule

On a double panel $[c - h, c + h]$ interpolate $f$ at $c - h, c, c + h$ by a quadratic and integrate:
$$\int_{c-h}^{c+h} f \approx \frac{h}{3}\bigl(f(c - h) + 4f(c) + f(c + h)\bigr).$$
For an even number $N$ of panels, the **composite Simpson rule** $S_N$ applies this to each pair of panels.

**Theorem 2.** Simpson's rule is exact for every polynomial of degree at most $3$. If $f \in C^4[a, b]$ and $M_4 = \max|f^{(4)}|$, then $\left|\int_a^b f - S_N\right| \le \dfrac{(b-a)h^4}{180}M_4$.

*Proof of exactness.* By linearity it suffices to test $1, t, t^2, t^3$ on $[-h, h]$. The rule gives $\tfrac h3(1 + 4 + 1) = 2h$ for $1$, which is $\int_{-h}^h 1\,dt$; $\tfrac h3(-h + h) = 0$ for $t$; $\tfrac h3(h^2 + h^2) = \tfrac23 h^3 = \int_{-h}^h t^2\,dt$ for $t^2$; and $0$ for $t^3$, as is the integral of an odd function. Translation to $[c - h, c + h]$ preserves degrees. *Outline of the error bound* (not a full proof): let $q$ be the cubic with $q = f$ at $c-h, c, c+h$ and $q'(c) = f'(c)$. Simpson's rule integrates $q$ exactly and has the same values as for $f$, and the Hermite interpolation error is $f(t) - q(t) = \tfrac{1}{24}f^{(4)}(\xi_t)(t^2 - h^2)t^2$. Integrating the absolute value gives at most $\tfrac{M_4}{24}\cdot\tfrac{4h^5}{15} = \tfrac{M_4h^5}{90}$ per double panel; there are $N/2$ of them. $\blacksquare$

### Gaussian quadrature

Simpson uses three nodes to be exact up to degree $3$. Free nodes do better. **Theorem 3.** Let $P_n$ be the Legendre polynomial of degree $n$, which has $n$ distinct zeros $x_1, \dots, x_n$ in $(-1, 1)$ and satisfies $\int_{-1}^1 q P_n = 0$ for every polynomial $q$ of degree less than $n$ (standard facts, assumed). Let $w_j = \int_{-1}^1 \ell_j$ with $\ell_j$ the Lagrange basis for these nodes. Then $\int_{-1}^1 p = \sum_j w_j p(x_j)$ for every polynomial $p$ of degree at most $2n - 1$.

*Proof.* Divide: $p = qP_n + r$ with $\deg q \le n - 1$ and $\deg r \le n - 1$. Then $\int p = \int qP_n + \int r = 0 + \int r$. The polynomial $r$ equals its own interpolant at the $n$ nodes, so $\int r = \sum_j w_j r(x_j)$. At the nodes $P_n(x_j) = 0$, so $r(x_j) = p(x_j)$. Hence $\int p = \sum_j w_j p(x_j)$. $\blacksquare$

For $n = 2$ the nodes are $\pm 1/\sqrt 3$ with weights $1, 1$; for $n = 3$ they are $0, \pm\sqrt{3/5}$ with weights $8/9, 5/9, 5/9$. Two evaluations integrate cubics exactly, while the two-point trapezoid rule is exact only up to degree $1$. On $[a, b]$ use the substitution $x = \tfrac{a+b}{2} + \tfrac{b-a}{2}t$, and for panels the **composite** two-point rule has error $O(h^4)$ (stated without proof).

```python
import math


def trapezoid(f, a, b, N):
    h = (b - a) / N
    total = (f(a) + f(b)) / 2
    for i in range(1, N):
        total += f(a + i * h)
    return h * total


def simpson(f, a, b, N):
    """N even."""
    h = (b - a) / N
    total = f(a) + f(b)
    for i in range(1, N):
        total += (4 if i % 2 == 1 else 2) * f(a + i * h)
    return h * total / 3


print(abs(trapezoid(math.sin, 0, math.pi, 4) - 2) > 0.1)    # True
print(abs(simpson(math.sin, 0, math.pi, 4) - 2) < 0.005)    # True
```

Halving $h$ divides the trapezoid error by about $4$ and the Simpson error by about $16$; you will measure this in the exercises. These runs are evidence for the stated orders; the theorems are the proof.

@example
title: Simpson's rule on a quartic
problem: Apply Simpson's rule with $N = 2$ panels to $\int_0^1 x^4\,dx$ and compare with Theorem 2.
step: $h = 1/2$ and the nodes are $0, 1/2, 1$ with $f = 0, 1/16, 1$.
step: $S_2 = \dfrac{1/2}{3}\left(0 + 4 \cdot \dfrac1{16} + 1\right) = \dfrac16 \cdot \dfrac54 = \dfrac{5}{24} \approx 0.208333$.
step: The exact value is $1/5 = 0.2$, so the error is $5/24 - 1/5 = 1/120 \approx 0.00833$.
step: Theorem 2: $\dfrac{(b-a)h^4}{180}M_4 = \dfrac{1 \cdot (1/16)}{180}\cdot 24 = \dfrac{1}{120}$. The bound is attained because $f^{(4)} = 24$ is constant.
answer: $S_2 = 5/24$ with error exactly $1/120$, equal to the bound.

@example
title: Two-point Gauss against Simpson
problem: Compare two-point Gauss–Legendre and Simpson's rule (three evaluations) for $\int_{-1}^1 e^x\,dx = e - e^{-1} \approx 2.350402$.
step: Gauss: nodes $\pm 1/\sqrt 3 \approx \pm 0.57735$, weights $1$: $G = e^{0.57735} + e^{-0.57735} \approx 1.78131 + 0.56138 = 2.34270$.
step: Simpson with $h = 1$ on $[-1, 1]$: $S = \tfrac13(e^{-1} + 4 + e) \approx \tfrac13(0.36788 + 4 + 2.71828) = 2.36205$.
step: Errors: $|G - \text{exact}| \approx 0.0077$ and $|S - \text{exact}| \approx 0.0117$.
step: With one evaluation fewer, Gauss is more accurate: free nodes buy degree of exactness $3$ with two points.
answer: Gauss error $\approx 0.0077$, Simpson error $\approx 0.0117$.

@mistakes
- Using Simpson's rule with an odd number of panels: the rule works on pairs of panels, so $N$ must be even.
- Applying the Gauss nodes $\pm 1/\sqrt 3$ on $[a, b]$ without the change of variables to $[-1, 1]$ (and the factor $(b-a)/2$ on the weights).
- Quoting the orders without the smoothness hypothesis: the bounds need $f \in C^2$ (trapezoid) or $C^4$ (Simpson); for $\sqrt x$ on $[0, 1]$ the observed orders drop.
- Confusing the degree of exactness with the order of the composite rule: Simpson is exact for degree $3$ and its composite error is $O(h^4)$.

```python
import math


def gauss2(f, a, b, N):
    """Composite two-point Gauss-Legendre quadrature."""
    h = (b - a) / N
    shift = h / (2 * math.sqrt(3))
    total = 0.0
    for i in range(N):
        mid = a + (i + 0.5) * h
        total += (h / 2) * (f(mid - shift) + f(mid + shift))
    return total
```
hint: On a panel the nodes are the midpoint plus or minus $h/(2\sqrt3)$; the weights are $h/2$.
solution: Mapping $[-1, 1]$ to a panel of width $h$ multiplies lengths by $h/2$, so the nodes $\pm 1/\sqrt3$ become $m \pm h/(2\sqrt3)$ and the weights $1$ become $h/2$. The composite error is $O(h^4)$, so doubling $N$ divides it by about $16$, as the ratio test checks. On a single panel $[-1, 1]$ the rule gives $2/9$ for $x^4$ (exact value $2/5$), showing that degree $4$ is beyond its exactness.

```python
def simpson_via_trapezoid(f, a, b, N):
    """Simpson's rule as a Richardson combination of trapezoid sums."""
    def trap(panels):
        h = (b - a) / panels
        total = (f(a) + f(b)) / 2
        for i in range(1, panels):
            total += f(a + i * h)
        return h * total

    return (4 * trap(N) - trap(N // 2)) / 3
```
hint: Write a helper for the trapezoid sum with a given number of panels, then combine $T_N$ and $T_{N/2}$ with weights $4$ and $-1$.
solution: The trapezoid error has an expansion $c_2h^2 + c_4h^4 + \cdots$, and $(4T_N - T_{N/2})/3$ cancels the $h^2$ term, exactly as in Richardson extrapolation of derivatives. Algebraically the combination reproduces the weights $1, 4, 2, 4, \dots, 4, 1$ of Simpson's rule, so the orders are $4$.

```python
import math


def gauss3(f, a, b):
    """Three-point Gauss-Legendre quadrature on [a, b]."""
    m = (a + b) / 2
    r = (b - a) / 2
    s = math.sqrt(3 / 5)
    return r * (5 / 9 * f(m - r * s) + 8 / 9 * f(m) + 5 / 9 * f(m + r * s))
```

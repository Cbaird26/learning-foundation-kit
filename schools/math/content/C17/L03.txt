@article
How do you compute $\sqrt 2$ with only the four arithmetic operations? Equivalently, how do you solve $x^2 - 2 = 0$? Calculators and libraries solve equations $f(x) = 0$ by *iteration*: start with a guess and improve it. Three classical iterations differ in what they assume and how fast they converge.

### Bisection

**Theorem 1 (bisection).** Let $f$ be continuous on $[a, b]$ with $f(a) f(b) < 0$. Set $[a_0, b_0] = [a, b]$, $c_n = (a_n + b_n)/2$, and let $[a_{n+1}, b_{n+1}]$ be the half of $[a_n, b_n]$ on whose endpoints $f$ has opposite signs or one zero (if $f(c_n) = 0$, stop: $c_n$ is a root). Then the intervals shrink to a point $r$ with $f(r) = 0$, and $|c_n - r| \le (b - a)/2^{n+1}$ for all $n \ge 0$.

*Proof.* By induction $f(a_n) f(b_n) \le 0$ and $b_n - a_n = (b - a)/2^n$. The intervals are nested and closed, so by the nested interval property they share a point $r$, and $a_n \to r$, $b_n \to r$. By continuity $f(a_n)f(b_n) \to f(r)^2$, and each term is $\le 0$, so $f(r)^2 \le 0$, hence $f(r) = 0$. Since $r$ and $c_n$ both lie in $[a_n, b_n]$ and $c_n$ is its midpoint, $|c_n - r| \le (b_n - a_n)/2 = (b-a)/2^{n+1}$. $\blacksquare$

The hypothesis $f(a)f(b) < 0$ is essential: $f(x) = x^2$ on $[-1, 1]$ has a root but no sign change, and bisection cannot find it. Bisection gains one binary digit per step, always.

### Fixed-point iteration

A **fixed point** of $g$ is a number $p$ with $g(p) = p$. The iteration $x_{n+1} = g(x_n)$ solves $x = g(x)$.

**Theorem 2 (contraction).** Let $g\colon [a, b] \to [a, b]$ be differentiable with $|g'(x)| \le L < 1$ for all $x \in [a, b]$. Then $g$ has exactly one fixed point $p \in [a, b]$, and for every $x_0 \in [a, b]$ the iterates satisfy $|x_n - p| \le L^n |x_0 - p|$.

*Proof.* *Existence.* The function $h(x) = g(x) - x$ is continuous with $h(a) = g(a) - a \ge 0$ and $h(b) = g(b) - b \le 0$ because $g$ maps into $[a, b]$; by the intermediate value theorem $h(p) = 0$ for some $p$. *Rate.* Every $x_n$ lies in $[a, b]$. By the mean value theorem there is $\xi$ between $x_n$ and $p$ with $|x_{n+1} - p| = |g(x_n) - g(p)| = |g'(\xi)||x_n - p| \le L |x_n - p|$; induct. *Uniqueness.* If $q$ is another fixed point then $|p - q| = |g(p) - g(q)| \le L|p - q|$, forcing $p = q$ since $L < 1$. $\blacksquare$

Without the hypothesis $|g'| \le L < 1$ the theorem fails: $g(x) = x$ maps $[0,1]$ to itself and every point is fixed; $g(x) = 1 - x$ has $|g'| = 1$, and the iteration from $0$ alternates $0, 1, 0, 1, \dots$.

### Newton's method

Replace $f$ near $x_n$ by its tangent line and solve for the zero of the line:
$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}.$$

**Theorem 3 (local convergence).** Let $f$ be twice continuously differentiable near a point $r$ with $f(r) = 0$ and $f'(r) \ne 0$. Then there is $\delta > 0$ such that for every $x_0$ with $|x_0 - r| \le \delta$ the Newton iterates converge to $r$, and $|e_{n+1}| \le K e_n^2$ where $e_n = x_n - r$ and $K$ is a constant.

*Proof.* Choose $\delta_0 > 0$ so that $f'$ has no zero on $I_0 = [r - \delta_0, r + \delta_0]$; let $m = \min_{I_0} |f'| > 0$, $M = \max_{I_0}|f''|$, $K = M/(2m)$, and $\delta = \min(\delta_0, 1/(2K))$ (take $\delta = \delta_0$ if $K = 0$). For $x_n \in I = [r - \delta, r + \delta]$, Taylor's theorem gives $\xi$ between $x_n$ and $r$ with $0 = f(r) = f(x_n) + f'(x_n)(r - x_n) + \tfrac12 f''(\xi)(r - x_n)^2$. Dividing by $f'(x_n)$ and rearranging, $x_{n+1} - r = \dfrac{f''(\xi)}{2 f'(x_n)}\, e_n^2$, so $|e_{n+1}| \le K e_n^2 \le K\delta\,|e_n| \le |e_n|/2$. Hence $x_{n+1} \in I$, and by induction $|e_n| \le 2^{-n}\delta \to 0$. $\blacksquare$

The hypothesis $f'(r) \ne 0$ matters; Week 4 shows what changes at a multiple root. The proof also shows why a good starting point matters: $\delta$ may be small.

### In Python

```python
def bisect(f, a, b, n):
    """Midpoint c_n after n halvings; requires f(a) * f(b) < 0."""
    for _ in range(n):
        c = (a + b) / 2
        if f(a) * f(c) <= 0:
            b = c
        else:
            a = c
    return (a + b) / 2


def fixed_point(g, x0, n):
    """The iterate x_n of x_{k+1} = g(x_k)."""
    x = x0
    for _ in range(n):
        x = g(x)
    return x


f = lambda x: x**3 - x - 1
r = bisect(f, 1.0, 2.0, 30)
print(abs(f(r)) < 1e-8)            # True
```

Checking $|f(r)|$ small, as here, is a test of the residual, not of the error: for an ill-conditioned problem the two differ. The theorems above bound the error itself.

@example
title: A contraction for the cosine
problem: Show that $g(x) = \cos x$ satisfies the hypotheses of Theorem 2 on $[0, 1]$ and bound the error of $x_5$ for $x_0 = 1$.
step: Range: on $[0, 1]$ the cosine decreases from $1$ to $\cos 1 \approx 0.5403$, so $g([0,1]) \subseteq [0,1]$.
step: Derivative: $g'(x) = -\sin x$, so $|g'(x)| = \sin x \le \sin 1 \approx 0.8415 =: L < 1$ on $[0, 1]$ because sine increases there.
step: By Theorem 2 there is a unique fixed point $p \in [0, 1]$ and $|x_5 - p| \le L^5 |x_0 - p| \le 0.8415^5 \cdot 1 \approx 0.42$, using $|x_0 - p| \le 1$.
step: The bound is pessimistic but guaranteed; the contraction factor $0.84$ is close to $1$, so the iteration converges slowly: about $13$ steps per decimal digit.
answer: Unique fixed point in $[0,1]$; $|x_5 - p| \le 0.42$.

@example
title: Newton's method for the square root of two
problem: Apply Newton's method to $f(x) = x^2 - 2$ with $x_0 = 3/2$ and watch the errors.
step: Newton's formula is $x_{n+1} = x_n - \dfrac{x_n^2 - 2}{2 x_n} = \dfrac{x_n}{2} + \dfrac{1}{x_n}$.
step: In exact fractions: $x_1 = 17/12 \approx 1.416667$, $x_2 = 577/408 \approx 1.414216$, $x_3 = 665857/470832$.
step: The errors $x_n - \sqrt 2$ are about $8.6 \times 10^{-2}$, $2.5 \times 10^{-3}$, $2.1 \times 10^{-6}$, $1.6 \times 10^{-12}$: each error is roughly a constant times the square of the previous one.
step: Theorem 3 predicts $e_{n+1} \approx \dfrac{f''(r)}{2f'(r)} e_n^2 = \dfrac{1}{2\sqrt 2} e_n^2 \approx 0.354\, e_n^2$; indeed $0.354 \cdot (2.5 \times 10^{-3})^2 \approx 2.2 \times 10^{-6}$.
answer: $x_3 = 665857/470832$, correct to about $12$ digits.

@mistakes
- Using bisection on an interval where $f$ does not change sign, or where $f$ is not continuous (a jump across zero gives a sign change but no root).
- Forgetting the range hypothesis in the contraction theorem: $|g'| < 1$ is not enough if $g$ maps the interval outside itself.
- Starting Newton's method far from the root, or where $f'(x_n)$ is near zero: the theorem is local, and a step can jump to a distant point.
- Judging an answer only by a small residual $|f(x)|$: a small residual does not bound the error when $|f'|$ is small near the root.

model:
```python
def bisect_tol(f, a, b, tol):
    """Bisection with the a priori stopping rule (b - a) / 2**(n+1) <= tol."""
    if f(a) * f(b) > 0:
        raise ValueError("no sign change")
    a0, b0 = a, b
    n = 0
    while True:
        c = (a + b) / 2
        if f(c) == 0 or (b0 - a0) / 2 ** (n + 1) <= tol:
            return c, n
        if f(a) * f(c) < 0:
            b = c
        else:
            a = c
        n += 1
```
hint: Compute the midpoint, test both stopping conditions, and only then choose the half with a sign change.
solution: The a priori bound of Theorem 1 tells you when to stop without looking at the residual, so the stopping test uses the original interval length. An exact zero of `f` at a midpoint ends the search early. Choosing the half with `f(a) * f(c) < 0` keeps a sign change; if the product is zero then `f(a) == 0`, and either half is acceptable.

model:
```python
def newton_iterates(f, df, x0, tol, maxit):
    """Newton iterates x0, x1, ... until the step is below tol."""
    xs = [x0]
    x = x0
    for _ in range(maxit):
        slope = df(x)
        if slope == 0:
            raise ValueError("zero derivative")
        x_new = x - f(x) / slope
        xs.append(x_new)
        if abs(x_new - x) < tol:
            break
        x = x_new
    return xs
```
hint: Append each new iterate before testing the step size, and check the derivative before dividing.
solution: Each pass computes the tangent-line zero. Newton's method on a linear function lands on the root in one step and the second step has size $0$, so the list has three entries. For $f(x) = x^3$ (a triple root at $0$) the steps shrink only by a factor $2/3$, so with a tiny tolerance the loop runs all `maxit` steps.

```python
def fp_steps(g, x0, tol, maxit):
    """Evaluations of g until successive iterates differ by less than tol."""
    x = x0
    for count in range(1, maxit + 1):
        x_new = g(x)
        if abs(x_new - x) < tol:
            return count
        x = x_new
    return None
```

For the constant function the first step moves from $0$ to $3$ and the second step does not move, so the count is $2$. The map $2x + 1$ has $|g'| = 2 > 1$, so the steps grow and the function returns `None`.

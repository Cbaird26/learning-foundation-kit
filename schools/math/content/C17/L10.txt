@article
You solve a $2 \times 2$ system, change one entry of the right-hand side in the fifth decimal place, and the solution changes completely. The matrix, not the algorithm, is to blame. Today we measure this sensitivity and then use it, together with orthogonality, to fit data.

### Norms and the condition number

For a vector $\mathbf x$ write $\|\mathbf x\|_\infty = \max_i|x_i|$. The induced matrix norm $\|A\|_\infty = \max_{\mathbf x \ne 0}\|A\mathbf x\|_\infty/\|\mathbf x\|_\infty$ equals the largest absolute row sum. Any induced norm satisfies $\|A\mathbf x\| \le \|A\|\,\|\mathbf x\|$ and $\|AB\| \le \|A\|\,\|B\|$. For nonsingular $A$ the **condition number** is $\kappa(A) = \|A\|\,\|A^{-1}\|$.

**Theorem 1.** Let $A$ be nonsingular, $\mathbf b \ne 0$, $A\mathbf x = \mathbf b$ and $A(\mathbf x + \delta\mathbf x) = \mathbf b + \delta\mathbf b$. Then
$$\frac{\|\delta\mathbf x\|}{\|\mathbf x\|} \le \kappa(A)\,\frac{\|\delta\mathbf b\|}{\|\mathbf b\|}.$$

*Proof.* Subtracting the equations, $A\,\delta\mathbf x = \delta\mathbf b$, so $\delta\mathbf x = A^{-1}\delta\mathbf b$ and $\|\delta\mathbf x\| \le \|A^{-1}\|\,\|\delta\mathbf b\|$. From $\mathbf b = A\mathbf x$ we get $\|\mathbf b\| \le \|A\|\,\|\mathbf x\|$, that is $1/\|\mathbf x\| \le \|A\|/\|\mathbf b\|$. Multiply the two inequalities. $\blacksquare$

The bound is sharp for some $\mathbf b$ and $\delta\mathbf b$. Two consequences: for any induced norm $\kappa(A) \ge 1$ (because $1 = \|I\| = \|AA^{-1}\| \le \|A\|\|A^{-1}\|$), and with $\delta\mathbf b = \mathbf r = \mathbf b - A\tilde{\mathbf x}$ (the **residual** of an approximate solution $\tilde{\mathbf x}$) the theorem bounds the error by $\kappa(A)\|\mathbf r\|/\|\mathbf b\|$: **a small residual guarantees a small error only when $\kappa(A)$ is modest.** Combined with Week 2: a backward stable solver such as $LU$ with partial pivoting gives a small residual, hence a relative error of size about $\kappa(A)\,u$ (the usual rule of thumb).

The Hilbert matrix $H_n = (1/(i+j-1))$ is notoriously ill conditioned: $\kappa_\infty(H_3) = 748$, and $\kappa_\infty(H_5) \approx 9.4 \times 10^5$.

### Least squares

If $A$ is $m \times n$ with $m > n$, the system $A\mathbf x = \mathbf b$ usually has no solution. The **least squares problem** is to minimize $\|A\mathbf x - \mathbf b\|_2$.

**Theorem 2 (normal equations).** If $A$ has linearly independent columns, then $A^\top A$ is nonsingular and the unique minimizer of $\|A\mathbf x - \mathbf b\|_2$ is the solution $\hat{\mathbf x}$ of $A^\top A\,\mathbf x = A^\top\mathbf b$.

*Proof.* If $A^\top A\mathbf z = 0$ then $\|A\mathbf z\|_2^2 = \mathbf z^\top A^\top A\mathbf z = 0$, so $A\mathbf z = 0$ and $\mathbf z = 0$ by independence; hence $A^\top A$ is nonsingular and $\hat{\mathbf x}$ exists and is unique. For any $\mathbf x$ write $A\mathbf x - \mathbf b = (A\hat{\mathbf x} - \mathbf b) + A(\mathbf x - \hat{\mathbf x})$. The cross term is $2(\mathbf x - \hat{\mathbf x})^\top A^\top(A\hat{\mathbf x} - \mathbf b) = 0$ by the normal equations, so $\|A\mathbf x - \mathbf b\|^2 = \|A\hat{\mathbf x} - \mathbf b\|^2 + \|A(\mathbf x - \hat{\mathbf x})\|^2$, which is larger unless $A(\mathbf x - \hat{\mathbf x}) = 0$, i.e. $\mathbf x = \hat{\mathbf x}$. $\blacksquare$

Forming $A^\top A$ squares the condition number in the 2-norm, $\kappa_2(A^\top A) = \kappa_2(A)^2$ (stated without proof), so the normal equations can lose twice as many digits. Orthogonal factorization avoids this.

### QR factorization

**Theorem 3.** If the columns $\mathbf a_1, \dots, \mathbf a_n$ of $A$ are linearly independent, then $A = QR$ where $Q$ is $m \times n$ with orthonormal columns and $R$ is $n \times n$ upper triangular with positive diagonal. Moreover $\|A\mathbf x - \mathbf b\|_2^2 = \|R\mathbf x - Q^\top\mathbf b\|_2^2 + \|(I - QQ^\top)\mathbf b\|_2^2$, so the least squares solution solves $R\mathbf x = Q^\top\mathbf b$.

*Proof.* Gram–Schmidt: set $\mathbf v_j = \mathbf a_j - \sum_{i<j}(\mathbf q_i^\top\mathbf a_j)\mathbf q_i$ and $r_{jj} = \|\mathbf v_j\|$, $\mathbf q_j = \mathbf v_j/r_{jj}$, $r_{ij} = \mathbf q_i^\top\mathbf a_j$. By induction $\mathrm{span}(\mathbf q_1, \dots, \mathbf q_{j-1}) = \mathrm{span}(\mathbf a_1, \dots, \mathbf a_{j-1})$, so $\mathbf v_j = 0$ would put $\mathbf a_j$ in the span of earlier columns, contradicting independence; hence $r_{jj} > 0$ and $\mathbf q_j \perp \mathbf q_i$ for $i < j$. Rearranging gives $\mathbf a_j = \sum_{i \le j} r_{ij}\mathbf q_i$, which is $A = QR$. For the identity, $A\mathbf x - \mathbf b = Q(R\mathbf x - Q^\top\mathbf b) - (I - QQ^\top)\mathbf b$, and the two terms are orthogonal because $Q^\top(I - QQ^\top) = 0$; apply Pythagoras and $\|Q\mathbf w\| = \|\mathbf w\|$. The first term vanishes exactly when $R\mathbf x = Q^\top\mathbf b$. $\blacksquare$

In floating point, **modified Gram–Schmidt** (subtracting each projection from the updated vector, not from the original column) loses orthogonality much more slowly than the classical formula above:

```python
import math


def mgs_qr(A):
    """Modified Gram-Schmidt: A (m x n, full column rank) = Q R.

    A and Q are lists of rows; R is n x n upper triangular.
    """
    m, n = len(A), len(A[0])
    V = [[A[i][j] for i in range(m)] for j in range(n)]   # columns of A
    R = [[0.0] * n for _ in range(n)]
    q = []
    for j in range(n):
        v = V[j]
        for i in range(j):
            R[i][j] = sum(q[i][k] * v[k] for k in range(m))
            v = [v[k] - R[i][j] * q[i][k] for k in range(m)]
        R[j][j] = math.sqrt(sum(x * x for x in v))
        q.append([x / R[j][j] for x in v])
    Q = [[q[j][i] for j in range(n)] for i in range(m)]
    return Q, R


Q, R = mgs_qr([[3.0, 1.0], [4.0, 2.0]])
print(abs(R[0][0] - 5.0) < 1e-12 and abs(Q[0][0] - 0.6) < 1e-12)   # True
```

problem: For $A = \begin{pmatrix} 1 & 1 \\ 1 & 1.0001\end{pmatrix}$ compute $\kappa_\infty(A)$ and show how a small change of $\mathbf b = (2, 2.0001)^\top$ changes $\mathbf x$.
step: $\|A\|_\infty = 2.0001$ (largest row sum). $A^{-1} = 10^{4}\begin{pmatrix} 1.0001 & -1 \\ -1 & 1\end{pmatrix}$, so $\|A^{-1}\|_\infty = 10^4 \cdot 2.0001 = 20001$.
step: $\kappa_\infty(A) = 2.0001 \cdot 20001 \approx 4.0 \times 10^4$.
step: For $\mathbf b = (2, 2.0001)^\top$ the solution is $\mathbf x = (1, 1)^\top$. Change $\mathbf b$ to $(2, 2.0002)^\top$: the solution becomes $(0, 2)^\top$. The relative change in $\mathbf b$ is $10^{-4}/2.0001 \approx 5 \times 10^{-5}$ and in $\mathbf x$ is $\|(-1, 1)\|_\infty/\|(1,1)\|_\infty = 1$.
step: Theorem 1 allows up to $\kappa \cdot 5 \times 10^{-5} \approx 2$, and the actual amplification is $2 \times 10^4$ times the input change, consistent with the bound.
answer: $\kappa_\infty(A) \approx 4.0 \times 10^4$; a relative data change of $5 \times 10^{-5}$ moved $\mathbf x$ by $100\%$.

@example

problem: Fit $y = c_0 + c_1 t$ by least squares to the points $(0, 1)$, $(1, 3)$, $(2, 4)$.
step: The matrix and right-hand side are $A = \begin{pmatrix} 1 & 0 \\ 1 & 1 \\ 1 & 2\end{pmatrix}$, $\mathbf b = (1, 3, 4)^\top$; the columns are independent, so Theorem 2 applies.

@mistakes
- Judging an answer by a small residual $\|A\tilde{\mathbf x} - \mathbf b\|$ alone: for large $\kappa(A)$ the error can still be large.
- Solving least squares with the normal equations when $A$ is ill conditioned: forming $A^\top A$ squares the condition number.
- Using classical Gram–Schmidt where orthogonality matters: the computed $Q$ can fail to be orthonormal; modified Gram–Schmidt or Householder reflections do better.
- Treating $\kappa(A) \approx \det A$ or "small determinant means ill conditioned": scaling $A$ by $10^{-10}$ changes the determinant but not $\kappa$.

```python
from fractions import Fraction


def cond_inf(A):
    """Exact infinity-norm condition number via Gauss-Jordan inversion."""
    n = len(A)
    M = [[Fraction(x) for x in row] + [Fraction(int(i == j)) for j in range(n)]
         for i, row in enumerate(A)]
    for k in range(n):
        p = k
        while p < n and M[p][k] == 0:
            p += 1
        if p == n:
            raise ValueError("singular matrix")
        M[k], M[p] = M[p], M[k]
        pivot = M[k][k]
        M[k] = [v / pivot for v in M[k]]
        for i in range(n):
            if i != k and M[i][k] != 0:
                f = M[i][k]
                M[i] = [a - f * b for a, b in zip(M[i], M[k])]
    inverse = [row[n:] for row in M]

    def norm(B):
        return max(sum(abs(v) for v in row) for row in B)

    return Fraction(norm(A)) * norm(inverse)
```
hint: Augment `A` with the identity, reduce the left half to the identity, and read the inverse from the right half; then take the maximum absolute row sum of each matrix.
solution: Gauss–Jordan elimination turns $[A \mid I]$ into $[I \mid A^{-1}]$. Exact fractions avoid rounding, so the condition number is exact. Scaling $A$ by $2$ scales $A^{-1}$ by $1/2$, leaving $\kappa$ unchanged, and a permutation matrix has $\kappa = 1$. The Hilbert matrix $H_3$ gives $\frac{11}{6}\cdot 408 = 748$.

```python
import math


def lstsq_qr(A, b):
    """Least squares via modified Gram-Schmidt QR and back substitution."""
    m, n = len(A), len(A[0])
    cols = [[A[i][j] for i in range(m)] for j in range(n)]
    q = []
    R = [[0.0] * n for _ in range(n)]
    for j in range(n):
        v = cols[j][:]
        for i in range(j):
            R[i][j] = sum(q[i][k] * v[k] for k in range(m))
            v = [v[k] - R[i][j] * q[i][k] for k in range(m)]
        R[j][j] = math.sqrt(sum(t * t for t in v))
        q.append([t / R[j][j] for t in v])
    c = [sum(q[i][k] * b[k] for k in range(m)) for i in range(n)]
    x = [0.0] * n
    for i in range(n - 1, -1, -1):
        s = c[i] - sum(R[i][j] * x[j] for j in range(i + 1, n))
        x[i] = s / R[i][i]
    return x
```
hint: Orthogonalize the columns one at a time (subtract projections from the updated vector), then $c_i = \mathbf q_i^\top\mathbf b$ and back substitution on $R$.
solution: By Theorem 3 the least squares solution satisfies $R\mathbf x = Q^\top\mathbf b$. The test with the $3 \times 2$ matrix checks the defining property: the residual is orthogonal to each column of `A`, which does not depend on knowing the answer in advance. The line-fit data are $(0,1), (1,2), (2,2), (3,4)$, whose fit is $y = 0.9 + 0.9t$.

```python
from fractions import Fraction


def fit_line(xs, ys):
    """Least squares line through the points, in exact arithmetic."""
    n = len(xs)
    sx = sum(Fraction(x) for x in xs)
    sy = sum(Fraction(y) for y in ys)
    sxx = sum(Fraction(x) * x for x in xs)
    sxy = sum(Fraction(x) * y for x, y in zip(xs, ys))
    den = n * sxx - sx * sx
    if den == 0:
        raise ValueError("all x values are equal")
    c1 = (n * sxy - sx * sy) / den
    c0 = (sy - c1 * sx) / n
    return (c1, c0)
```
hint: Compute the five sums $n, \sum x, \sum y, \sum x^2, \sum xy$ with `Fraction`, then apply the two formulas.
solution: The normal equations for the columns $(1, \dots, 1)$ and $(x_1, \dots, x_n)$ are $\begin{pmatrix} n & \sum x \\ \sum x & \sum x^2\end{pmatrix}\binom{c_0}{c_1} = \binom{\sum y}{\sum xy}$; solving gives the stated formulas. The denominator $n\sum x^2 - (\sum x)^2$ is zero exactly when all the $x$ values coincide, which is when the columns are dependent. Exact fractions give exact results.

prompt: Prove that $\kappa(A) \ge 1$ for every nonsingular matrix $A$ and every induced matrix norm. Then explain why this does not mean that a system with $\kappa(A) = 1$ is easy to solve in every other sense, or give an example of a matrix with $\kappa_\infty = 1$.
hint: Use $I = AA^{-1}$ and submultiplicativity; for the example think of the identity or a scaled identity.
solution: An induced norm satisfies $\|I\| = \max_{\mathbf x \ne 0}\|I\mathbf x\|/\|\mathbf x\| = 1$. Submultiplicativity gives $1 = \|I\| = \|AA^{-1}\| \le \|A\|\,\|A^{-1}\| = \kappa(A)$. Equality holds for the identity and for any multiple $cI$ with $c \ne 0$, since $\|cI\|\,\|c^{-1}I\| = |c|\cdot|c|^{-1} = 1$; a permutation matrix also has $\kappa_\infty = 1$. A condition number of $1$ means that the solution is as insensitive to data errors as possible (relative errors are not amplified), but it says nothing about the cost of the solve and nothing about whether the matrix entries themselves are known accurately.

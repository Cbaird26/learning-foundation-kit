@article
Elimination costs about $\tfrac23 n^3$ operations and destroys sparsity: a matrix with a million rows and five entries per row has no room for a dense $LU$ factorization. **Iterative methods** only multiply by $A$, which is cheap for sparse $A$, and improve a guess step by step. The same idea finds eigenvalues.

### Linear iterations

Split $A = L + D + U$ into its strictly lower triangular part, its diagonal and its strictly upper triangular part, with all $a_{ii} \ne 0$. **Jacobi iteration** solves the $i$-th equation for $x_i$ using the old values:
$$x_i^{(k+1)} = \frac{1}{a_{ii}}\Bigl(b_i - \sum_{j \ne i}a_{ij}x_j^{(k)}\Bigr), \quad\text{that is}\quad \mathbf x^{(k+1)} = -D^{-1}(L + U)\mathbf x^{(k)} + D^{-1}\mathbf b.$$
**Gauss–Seidel iteration** uses the newest values as soon as they are known: $(D + L)\mathbf x^{(k+1)} = \mathbf b - U\mathbf x^{(k)}$. Both have the form $\mathbf x^{(k+1)} = B\mathbf x^{(k)} + \mathbf c$ with a fixed matrix $B$.

**Theorem 1.** If $\mathbf x^* = B\mathbf x^* + \mathbf c$ and $\|B\| < 1$ in some induced matrix norm, then $\mathbf x_k \to \mathbf x^*$ for every starting vector, and $\|\mathbf x_k - \mathbf x^*\| \le \|B\|^k\|\mathbf x_0 - \mathbf x^*\|$.

*Proof.* The error $\mathbf e_k = \mathbf x_k - \mathbf x^*$ satisfies $\mathbf e_{k+1} = B\mathbf x_k + \mathbf c - B\mathbf x^* - \mathbf c = B\mathbf e_k$, so $\mathbf e_k = B^k\mathbf e_0$ and $\|\mathbf e_k\| \le \|B\|^k\|\mathbf e_0\|$. $\blacksquare$

(In fact the iteration converges for every start if and only if the spectral radius $\rho(B) < 1$; this is stated without proof.)

A matrix is **strictly diagonally dominant** (by rows) if $|a_{ii}| > \sum_{j \ne i}|a_{ij}|$ for every $i$.

**Theorem 2.** If $A$ is strictly diagonally dominant, then Jacobi and Gauss–Seidel iteration converge to the unique solution of $A\mathbf x = \mathbf b$ from every starting vector.

*Proof.* Put $\alpha_i = \sum_{j<i}|a_{ij}|/|a_{ii}|$ and $\beta_i = \sum_{j>i}|a_{ij}|/|a_{ii}|$; dominance says $\alpha_i + \beta_i < 1$. *Jacobi:* the row sums of $|B_J|$ are $\alpha_i + \beta_i$, so $\|B_J\|_\infty = \max_i(\alpha_i + \beta_i) < 1$; apply Theorem 1. (Also $A$ is nonsingular: if $A\mathbf x = 0$ then $\mathbf x = B_J\mathbf x$, so the iteration with $\mathbf c = 0$ started at $\mathbf x$ stays at $\mathbf x$, yet Theorem 1 says it tends to $\mathbf 0$; hence $\mathbf x = \mathbf 0$.) *Gauss–Seidel:* write the error update componentwise, $e^{(k+1)}_i = -\frac{1}{a_{ii}}\bigl(\sum_{j<i}a_{ij}e^{(k+1)}_j + \sum_{j>i}a_{ij}e^{(k)}_j\bigr)$, and let $r = \max_i \beta_i/(1 - \alpha_i) < 1$. Claim: $|e^{(k+1)}_i| \le r\|\mathbf e_k\|_\infty$ for all $i$. By induction on $i$, using the claim for $j < i$: $|e^{(k+1)}_i| \le \alpha_i r\|\mathbf e_k\|_\infty + \beta_i\|\mathbf e_k\|_\infty \le r\|\mathbf e_k\|_\infty$, because $\beta_i \le r(1 - \alpha_i)$. Hence $\|\mathbf e_{k+1}\|_\infty \le r\|\mathbf e_k\|_\infty$. $\blacksquare$

Without dominance convergence can fail: for $A = \begin{pmatrix} 1 & 2 \\ 3 & 1\end{pmatrix}$ the Jacobi matrix has $\|B_J\|_\infty = 3$ and the iteration diverges for most starting vectors.

```python
def jacobi(A, b, x0, steps):
    """Run `steps` Jacobi sweeps and return the final vector."""
    n = len(b)
    x = list(x0)
    for _ in range(steps):
        x = [(b[i] - sum(A[i][j] * x[j] for j in range(n) if j != i)) / A[i][i]
             for i in range(n)]
    return x
```

### The power method

To find the eigenvalue of largest absolute value, apply $A$ repeatedly and normalize: $\mathbf x_{k+1} = A\mathbf x_k/\|A\mathbf x_k\|_2$.

**Theorem 3 (power method).** Let $A$ be a real $n \times n$ matrix with a basis of eigenvectors $\mathbf v_1, \dots, \mathbf v_n$ and eigenvalues $|\lambda_1| > |\lambda_2| \ge \dots \ge |\lambda_n|$. If $\mathbf x_0 = \sum c_i\mathbf v_i$ with $c_1 \ne 0$, then the normalized iterates approach the direction of $\mathbf v_1$: the angle between $\mathbf x_k$ and $\mathbf v_1$ is $O(|\lambda_2/\lambda_1|^k)$, and so is the error of the Rayleigh quotient $\mathbf x_k^\top A\mathbf x_k/\mathbf x_k^\top\mathbf x_k$ as an estimate of $\lambda_1$.

*Proof.* Normalizing only rescales, so $\mathbf x_k$ is parallel to $A^k\mathbf x_0 = \sum c_i\lambda_i^k\mathbf v_i = \lambda_1^k\bigl(c_1\mathbf v_1 + \sum_{i \ge 2}c_i(\lambda_i/\lambda_1)^k\mathbf v_i\bigr)$. Since $|\lambda_i/\lambda_1| \le |\lambda_2/\lambda_1| < 1$, the bracket equals $c_1\mathbf v_1 + \mathbf w_k$ with $\|\mathbf w_k\| = O(|\lambda_2/\lambda_1|^k)$, which gives the claim for the direction. The Rayleigh quotient is a continuous function of the direction and equals $\lambda_1$ at $\mathbf v_1$; it is differentiable there, so its error is also $O(|\lambda_2/\lambda_1|^k)$ (for symmetric $A$ it is $O(|\lambda_2/\lambda_1|^{2k})$, stated without proof). $\blacksquare$

Both hypotheses matter. If $c_1 = 0$ (the start is orthogonal to the dominant eigenvector in the symmetric case), the iterates converge to another eigenvector in exact arithmetic (rounding errors eventually bring $\mathbf v_1$ back). If $\lambda_1 = -\lambda_2$ there is no dominant eigenvalue and the direction oscillates. The method needs only matrix–vector products, but convergence is slow when $|\lambda_2| \approx |\lambda_1|$.

@example
title: Two Jacobi steps with an error bound
problem: Apply Jacobi iteration to $A = \begin{pmatrix} 4 & 1 \\ 2 & 5\end{pmatrix}$, $\mathbf b = (6, 12)^\top$ (exact solution $(1, 2)$) from $\mathbf x_0 = \mathbf 0$ and compare the error with the bound of Theorem 1.
step: $A$ is strictly diagonally dominant ($4 > 1$, $5 > 2$), and $\|B_J\|_\infty = \max(1/4, 2/5) = 0.4$.
step: First step: $x_1 = (6 - 0)/4 = 1.5$, $y_1 = (12 - 0)/5 = 2.4$, so $\mathbf x_1 = (1.5, 2.4)$.
step: Second step: $x_2 = (6 - 2.4)/4 = 0.9$, $y_2 = (12 - 2 \cdot 1.5)/5 = 1.8$, so $\mathbf x_2 = (0.9, 1.8)$.
step: Error: $\|\mathbf x_2 - (1,2)\|_\infty = 0.2$, below the bound $0.4^2 \cdot \|\mathbf x_0 - \mathbf x^*\|_\infty = 0.16 \cdot 2 = 0.32$.
answer: $\mathbf x_2 = (0.9, 1.8)$, error $0.2 \le 0.32$.

@mistakes
- Assuming Jacobi or Gauss–Seidel converges for every nonsingular matrix: dominance (or $\rho(B) < 1$) is needed.
- Updating in place in Jacobi: the Jacobi sweep must use only old values (using new values makes it Gauss–Seidel).
- Starting the power method with a vector orthogonal to the dominant eigenvector, or applying it when $\lambda_1 = -\lambda_2$.
- Stopping on a small change between iterates and calling it a small error: when the rate is close to $1$, the error can be much larger than the step.

```python
def gauss_seidel(A, b, x0, tol, maxit):
    """Gauss-Seidel iteration; returns (x, number_of_sweeps)."""
    n = len(b)
    x = list(x0)
    for k in range(1, maxit + 1):
        change = 0.0
        for i in range(n):
            new = (b[i] - sum(A[i][j] * x[j] for j in range(n) if j != i)) / A[i][i]
            change = max(change, abs(new - x[i]))
            x[i] = new
        if change < tol:
            return x, k
    return x, maxit
```
hint: Overwrite `x[i]` immediately after computing it, so later components in the same sweep see the new value; track the largest change in the sweep.
solution: The only difference from Jacobi is the in-place update. For a strictly diagonally dominant matrix both converge (Theorem 2), but Gauss–Seidel typically needs fewer sweeps; for the first test matrix it takes about half as many. The matrix $\begin{pmatrix}1&2\\3&1\end{pmatrix}$ is not dominant and the iteration diverges, so the function returns `maxit`. Copying `x0` leaves the caller's list untouched.

```python
import math


def power_method(A, x0, steps):
    """Power iteration; returns (Rayleigh quotient, final unit vector)."""
    n = len(A)
    x = list(x0)
    for _ in range(steps):
        y = [sum(A[i][j] * x[j] for j in range(n)) for i in range(n)]
        norm = math.sqrt(sum(t * t for t in y))
        x = [t / norm for t in y]
    Ax = [sum(A[i][j] * x[j] for j in range(n)) for i in range(n)]
    num = sum(x[i] * Ax[i] for i in range(n))
    den = sum(t * t for t in x)
    return num / den, x
```
hint: Multiply, divide by the Euclidean norm of the product, repeat; compute the Rayleigh quotient only once at the end.
solution: By Theorem 3 the direction converges at rate $|\lambda_2/\lambda_1|$ per step (here $2/5$ and $1/3$). The start $(0, 1)$ for the diagonal matrix is exactly the eigenvector for the smaller eigenvalue $1$, so $c_1 = 0$ and the method stays there, which shows why the hypothesis $c_1 \ne 0$ is needed. The final tests check the eigenvector equation directly and that $\mathbf x$ is a unit vector.

```python
from fractions import Fraction


def jacobi_steps_bound(A, eps):
    """Smallest k with q**k <= eps, where q = ||B_J||_inf < 1."""
    n = len(A)
    q = Fraction(0)
    for i in range(n):
        off = sum(abs(Fraction(A[i][j])) for j in range(n) if j != i)
        q = max(q, off / abs(Fraction(A[i][i])))
    if q >= 1:
        raise ValueError("no guaranteed convergence")
    k = 0
    power = Fraction(1)
    while power > eps:
        power *= q
        k += 1
    return k
```
hint: Compute the row ratios exactly, then multiply by `q` repeatedly until the power is at most `eps`; a diagonal matrix has `q = 0`, and the loop must still stop.
solution: Theorem 1 gives $\|\mathbf e_k\|_\infty \le q^k\|\mathbf e_0\|_\infty$, so $k$ steps shrink the error by at least $q^k$. With exact fractions the comparison with `eps` is exact, so the boundary case $2^{-10} = 1/1024$ returns $10$ and $1/1025$ returns $11$. For $q = 0$ the first multiplication gives $0 \le$ `eps` and the loop stops.

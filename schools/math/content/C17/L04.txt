@article
Newton's method turned an error of $2.5 \times 10^{-3}$ into $2.1 \times 10^{-6}$, then into $1.6 \times 10^{-12}$: the number of correct digits doubles at each step. Bisection adds one binary digit at each step. How can you state this difference precisely, and how can you measure it from a table of errors?

### Orders and rates

Let $x_n \to r$ and $e_n = x_n - r$, with $e_n \ne 0$ for all $n$. The sequence converges with **order** $p \ge 1$ and **asymptotic error constant** $C$ if
$$\lim_{n \to \infty} \frac{|e_{n+1}|}{|e_n|^p} = C \in (0, \infty).$$
For $p = 1$ one also requires $C < 1$ and says the convergence is **linear** with rate $C$: each step multiplies the error by about $C$, gaining a fixed number of digits per step. For $p = 2$ the convergence is **quadratic**. If $|e_{n+1}|/|e_n| \to 0$ the convergence is **superlinear**.

**Theorem 1 (estimating the order).** Suppose $e_n \to 0$ and $|e_{n+1}|/|e_n|^p \to C \in (0, \infty)$, with $p > 1$, or with $p = 1$ and $C \ne 1$. Then
$$p_n := \frac{\log(|e_{n+1}|/|e_n|)}{\log(|e_n|/|e_{n-1}|)} \longrightarrow p.$$

*Proof.* Let $\ell_n = \log|e_n|$ and $c_n = \log(|e_{n+1}|/|e_n|^p)$, so $\ell_{n+1} = p\ell_n + c_n$ with $c_n \to \log C$. For $p = 1$: $p_n = c_n/c_{n-1} \to 1$ since $\log C \ne 0$. For $p > 1$: $\ell_n \to -\infty$ and $p_n = \dfrac{(p-1)\ell_n + c_n}{(p-1)\ell_{n-1} + c_{n-1}}$. Substitute $\ell_n = p\ell_{n-1} + c_{n-1}$ and divide numerator and denominator by $\ell_{n-1}$: the constants $c_n/\ell_{n-1}$ and $c_{n-1}/\ell_{n-1}$ tend to $0$, so $p_n \to p(p-1)/(p-1) = p$. $\blacksquare$

The estimate is only meaningful while $|e_n|$ is well above the rounding level; once the errors reach $10^{-16}$ the ratios are noise.

### The order of a fixed-point iteration

**Theorem 2.** Let $g$ be continuously differentiable near a fixed point $p$ and let $x_{n+1} = g(x_n)$ with $e_n \ne 0$ for all $n$.
(a) If $0 < |g'(p)| < 1$, the iteration converges from every $x_0$ near $p$, linearly with $|e_{n+1}|/|e_n| \to |g'(p)|$.
(b) If $g$ is twice continuously differentiable, $g'(p) = 0$ and $g''(p) \ne 0$, the iteration converges from every $x_0$ near $p$, quadratically, with $|e_{n+1}|/|e_n|^2 \to |g''(p)|/2$.

*Proof.* In both cases choose $\delta > 0$ and $L < 1$ with $|g'| \le L$ on $[p - \delta, p + \delta]$ (possible by continuity of $g'$ and $|g'(p)| < 1$). Then $g$ maps this interval into itself, because $|g(x) - p| \le L|x - p|$ by the mean value theorem, and Week 3's Theorem 2 gives convergence. (a) By the mean value theorem $e_{n+1} = g'(\xi_n) e_n$ with $\xi_n$ between $x_n$ and $p$; since $\xi_n \to p$ and $g'$ is continuous, $|e_{n+1}|/|e_n| \to |g'(p)|$. (b) Taylor's theorem with $g'(p) = 0$ gives $e_{n+1} = \tfrac12 g''(\xi_n) e_n^2$, and $\xi_n \to p$. $\blacksquare$

Newton's method is the fixed-point iteration with $g(x) = x - f(x)/f'(x)$. At a simple root, $g' = f f''/(f')^2$ vanishes, which is the quadratic convergence of Week 3.

### Multiple roots

If $f(x) = x^m$ with $m \ge 2$, the root $0$ has $f'(0) = 0$ and Theorem 3 of Week 3 does not apply. Newton's method gives $x_{n+1} = x_n - x_n/m = (1 - 1/m)\,x_n$ exactly, so the convergence is linear with $C = (m-1)/m$: for a double root the error only halves. The same constant appears for any $f(x) = (x - r)^m h(x)$ with $h(r) \ne 0$ (stated without proof). Multiplying the step by $m$ restores quadratic speed: $x_{n+1} = x_n - m f(x_n)/f'(x_n)$ solves $x^m = 0$ in one step. The price is that you must know $m$.

Two more orders are worth knowing. Bisection has error bound $(b-a)/2^{n+1}$, halving at each step (linear, though the error itself need not decrease monotonically). The secant method, which replaces $f'(x_n)$ by a difference quotient of the last two iterates, has order $(1 + \sqrt 5)/2 \approx 1.618$ at a simple root (stated without proof); it needs one function evaluation per step, so in cost per digit it competes with Newton.

### Measuring the order

```python
import math
from fractions import Fraction


def observed_orders(errors):
    """p_n = log(e[n+1]/e[n]) / log(e[n]/e[n-1]) for a list of errors."""
    return [math.log(errors[i + 1] / errors[i]) / math.log(errors[i] / errors[i - 1])
            for i in range(1, len(errors) - 1)]


x = Fraction(3)
errors = []
for _ in range(5):
    errors.append(float(x - 2))     # exact rational error, then converted
    x = (x + 4 / x) / 2             # Newton for x^2 - 4
print(observed_orders(errors)[-1] > 1.99)   # True
```

Using exact fractions for the iteration means the errors are exact until they are converted, so the table is not polluted by rounding.

@example
title: Estimating an order from three errors
problem: A method produces errors $2.0 \times 10^{-2}$, $8.0 \times 10^{-4}$, $1.28 \times 10^{-6}$ at three consecutive steps. Estimate its order and asymptotic constant.
step: Apply Theorem 1: $p_n = \dfrac{\log(1.28 \times 10^{-6}/8.0 \times 10^{-4})}{\log(8.0 \times 10^{-4}/2.0 \times 10^{-2})} = \dfrac{\log(1.6 \times 10^{-3})}{\log(0.04)}$.
step: Since $1.6 \times 10^{-3} = 0.04^2$, the quotient is exactly $2$, so the method looks quadratic.
step: Constant: $|e_{n+1}|/|e_n|^2 = 1.28 \times 10^{-6}/(8.0 \times 10^{-4})^2 = 2.0$.
step: Three errors cannot prove an order; they only suggest it. Check with more steps and, where possible, a theorem like Theorem 2.
answer: Order about $2$, constant about $2$.

@example
title: Newton's method at a double root
problem: Apply Newton's method to $f(x) = x^2$ from $x_0 = 1$ and then the version with the step multiplied by $m = 2$.
step: Newton: $x_{n+1} = x_n - x_n^2/(2x_n) = x_n/2$. The iterates $1, 1/2, 1/4, 1/8, \dots$ have errors halving each step.
step: So $|e_{n+1}|/|e_n| = 1/2$ for all $n$: linear convergence with $C = 1/2$, in agreement with $C = (m-1)/m$.
step: The observed order from Theorem 1 is $\log(1/2)/\log(1/2) = 1$.
step: Multiplied step: $x_{n+1} = x_n - 2x_n^2/(2x_n) = 0$, the exact root after one step.
answer: Linear convergence with rate $1/2$; the multiplied step is exact.

@mistakes
- Estimating an order from errors that have reached the rounding level: the ratios are noise; use only the part of the table above about $10^{-13}$.
- Treating linear convergence with rate $0.99$ as "fast" because it is "convergent": the rate $C$ tells you how many steps per digit.
- Applying the quadratic-convergence theorem for Newton's method at a multiple root: it needs $f'(r) \ne 0$.
- Computing $\log(e_{n+1}/e_n)$ with signed errors: use absolute values, since errors may alternate in sign.

def newton_multiple(f, df, x0, m, steps):
    """Newton iteration with the step multiplied by m."""
    xs = [x0]
    x = x0
    for _ in range(steps):
        x = x - m * f(x) / df(x)
        xs.append(x)
    return xs

model:
```python
def secant(f, x0, x1, steps):
    """Secant iterates, stopping if two consecutive values of f agree."""
    xs = [x0, x1]
    for _ in range(steps):
        f_prev, f_cur = f(xs[-2]), f(xs[-1])
        if f_cur == f_prev:
            break
        xs.append(xs[-1] - f_cur * (xs[-1] - xs[-2]) / (f_cur - f_prev))
    return xs
```
hint: Use the last two entries of the list, and test `f_cur == f_prev` before you divide.
solution: Each update replaces the derivative in Newton's step by the slope of the secant line through the last two points. The observed orders near $1.6$ agree with the golden ratio $(1+\sqrt5)/2 \approx 1.618$, which is slightly different from the quadratic order of Newton's method but achieved with one function evaluation per step.

model:
```python
import math


def fit_order(errors):
    """Least-squares slope of log e[n+1] against log e[n]."""
    xs = [math.log(v) for v in errors[:-1]]
    ys = [math.log(v) for v in errors[1:]]
    k = len(xs)
    mx = 0.0
    my = 0.0
    for a, b in zip(xs, ys):
        mx += a
        my += b
    mx /= k
    my /= k
    num = 0.0
    den = 0.0
    for a, b in zip(xs, ys):
        num += (a - mx) * (b - my)
        den += (a - mx) ** 2
    return num / den
```
hint: Compute the means of the $x$ values and $y$ values, then slope $= \sum (x - \bar x)(y - \bar y) / \sum (x - \bar x)^2$.
solution: If $e_{n+1} = C e_n^p$ exactly, the points lie on the line $y = px + \log C$, so the least-squares slope is exactly $p$. With noisy data the fit averages over all steps instead of using one triple. It still needs errors above the rounding level.

# Mathematics Learning Foundation

**Open the school:** https://cbaird26.github.io/learning-foundation/mathematics/

A Khan Academy-style self-study school: 64 courses in five stages, from kindergarten through a complete college degree in
mathematics to graduate study and PhD qualifying exams. The stages are elementary, middle and high school (including
computational thinking and Python), the mathematics degree, and graduate study. The degree covers calculus II,
multivariable and vector calculus, linear algebra, proof and discrete mathematics; real analysis, abstract algebra,
complex analysis and topology; ordinary differential equations, probability and statistical inference, number theory,
combinatorics and graph theory, and numerical analysis; differential geometry, dynamical systems, Fourier methods and
partial differential equations, logic and the theory of computation as electives; and problem solving and mathematical
writing. Graduate study covers measure theory, graduate algebra, algebraic topology, smooth manifolds and functional
analysis, with probability theory as an elective, and a research apprenticeship with qualifying-exam preparation.

Each course has 12 weekly lessons (an article, worked examples, common mistakes, and auto-graded practice and quiz
questions), a week 13–14 project with a review guide, and a cumulative final exam. Skills move through mastery levels
with unit quizzes, a midterm and course challenges, and missed questions go into an error log that brings back a
parallel problem 48 hours later.

## Proofs

The page grades what a computer can check: numbers, expressions, choices, counterexamples and code. For every proof you
write, it shows a complete model proof and a rubric, so you can compare your write-up line by line and mark it yourself.
When a lesson states a theorem whose full proof is beyond it, the lesson says so and labels any sketch as an outline.

## Python in the page

Many courses include Python exercises that run real Python in the browser, with nothing to install: the page includes
Brython, which follows Python 3.14, with CPython's own json package. Press Run to try code and Check to grade it against
the exercise's tests; a program that runs too long is stopped after a few seconds. Lesson code that runs here has a "Try
it" button, and the Python tab is a scratchpad. The browser's Python has the whole language and most of the standard
library, but not threads, networking or third-party packages such as NumPy, SciPy or SymPy, so the exercises use plain
Python with exact integers and fractions. Computation is evidence, not proof: the exercises use it to test conjectures,
find counterexamples and check examples. Projects are done on your own computer, where those libraries are available.
Your code is never uploaded.

## Using it

Open the site in any modern browser. The whole school is one self-contained page (`index.html`), so you can also save
the page and use it offline.

Progress and the error log are kept only in your own browser and are never uploaded. Keep using the same browser and do
not clear its site data; another browser or device starts fresh. The Tutor button prepares a prompt you can copy into a
chat with Claude.

## Accuracy and fairness

Every course was written and then independently reviewed. Every numeric and typed answer was checked against an
independent computation, every proof was checked step by step, every Python exercise's model solution was run against
its tests both in standard Python and in the browser's Python, and every "what does this print?" answer was produced by
running the program. On contested questions, such as whether Gödel's theorems show that minds are not machines, and on
questions of history and government in the general-education courses, the lessons present the main views and the
strongest arguments on each side and do not tell learners what to believe. Records such as the largest known prime, the
status of open problems, PhD programs and the job market change, so check current details before relying on them.
Self-study scores do not award credit, degrees or any credential.

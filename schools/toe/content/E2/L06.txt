@article
The Riemann integral slices the domain into small intervals. The Lebesgue integral slices the **range**: it groups together all points where $f$ takes about the same value and multiplies that value by the measure of the group. This makes limits behave, which is the point.

### Definition

A **simple function** is a finite sum $s=\sum_{k=1}^mc_k\mathbf 1_{E_k}$ with measurable sets $E_k$ and constants $c_k\ge0$. Its integral is $\int s\,d\mu=\sum_kc_k\,\mu(E_k)$. For a measurable $f\ge0$,

$$\int f\,d\mu=\sup\Big\{\int s\,d\mu:\ s\text{ simple},\ 0\le s\le f\Big\}.$$

For general real $f$ write $f=f^+-f^-$ with $f^\pm\ge0$. The function is **integrable** if $\int|f|\,d\mu<\infty$, and then $\int f=\int f^+-\int f^-$. The integral is linear and monotone, and **functions that agree almost everywhere have the same integral**.

Every Riemann integrable function is Lebesgue integrable with the same value. The converse fails: $\mathbf 1_{\mathbb{Q}}$ on $[0,1]$ has Riemann upper sums $1$ and lower sums $0$, but it is $0$ a.e., so its Lebesgue integral is $0$.

### Three theorems about limits

Let $(f_n)$ be measurable functions.

- **Monotone convergence (MCT).** If $0\le f_1\le f_2\le\cdots$ and $f_n\to f$ pointwise (a.e. suffices), then $\int f_n\to\int f$. Consequence: for $f_k\ge0$, $\int\sum_kf_k=\sum_k\int f_k$.
- **Fatou's lemma.** If $f_n\ge0$, then $\int\liminf_nf_n\le\liminf_n\int f_n$. Mass can disappear in the limit but not appear.
- **Dominated convergence (DCT).** If $f_n\to f$ a.e. and $|f_n|\le g$ for one integrable $g$, then $f$ is integrable, $\int f_n\to\int f$, and even $\int|f_n-f|\to0$.

Pointwise convergence alone is not enough. Let $f_n=n\mathbf 1_{(0,1/n)}$. For every $x$ we have $f_n(x)\to0$, but $\int_0^1f_n=1$ for all $n$. All the mass escapes into a spike that gets taller and thinner. A dominating function would need $g(x)\ge f_n(x)$ for all $n$, which forces $g(x)\ge\frac1{2x}$ for almost every $x\in(0,1)$, and $\int_0^1\frac{dx}{2x}=\infty$.

### Pointwise versus almost everywhere

The theorems only ask for convergence **almost everywhere**, and rightly so: changing $f_n$ on a null set changes no integral. The functions $x^n$ on $[0,1]$ converge to $0$ at every $x<1$ but to $1$ at $x=1$. So "$x^n\to0$ everywhere" is false, "$x^n\to0$ a.e." is true, and $\int_0^1x^n\,dx=\frac1{n+1}\to0$ agrees with the a.e. statement.

### When is an integral zero?

If $f\ge0$ is measurable and $\int f=0$, then $f=0$ a.e. The reason is **Markov's inequality**: for $t>0$, $t\,\mu(\{f\ge t\})\le\int f$. Taking $t=\frac1k$ and a countable union gives $\mu(\{f>0\})=0$.

```python
import numpy as np
from scipy.integrate import quad
for n in (1, 10, 100, 1000):
    val, _ = quad(lambda x: n * x / (1 + n * x), 0, 1)
    print(n, val)    # increases toward 1, the integral of the a.e. limit
```

@example
title: Interchanging a sum and an integral
problem: Compute $\int_0^1\sum_{k=1}^\infty x^k(1-x)\,dx$ in two ways and explain why they agree.
step: Sum first. For $0\le x<1$, $\sum_{k\ge1}x^k(1-x)=(1-x)\frac{x}{1-x}=x$. The value at $x=1$ is $0$, a single point, which does not matter.
step: Integrate: $\int_0^1x\,dx=\frac12$.
step: Integrate term by term. $\int_0^1x^k(1-x)\,dx=\frac1{k+1}-\frac1{k+2}$, and the sum over $k\ge1$ telescopes to $\frac12-\lim_{K}\frac1{K+2}=\frac12$.
step: The two answers agree because every term is $\ge0$, so the monotone convergence theorem allows $\int\sum=\sum\int$. Without non-negativity (or absolute summability) the exchange can fail.

@example
title: Dominated convergence with an a.e. limit
problem: Find $\lim_{n\to\infty}\int_0^1\frac{nx}{1+nx}\,dx$ and verify the answer by direct integration.
step: Pointwise limit. For each $x\in(0,1]$, $\frac{nx}{1+nx}\to1$. At $x=0$ every term is $0$. So the limit is $1$ almost everywhere, though not at every point.
step: Domination. $0\le\frac{nx}{1+nx}\le1$, and the constant $1$ is integrable on $[0,1]$.
step: By dominated convergence, $\lim_n\int_0^1\frac{nx}{1+nx}\,dx=\int_0^11\,dx=1$.
step: Check. $\frac{nx}{1+nx}=1-\frac1{1+nx}$, so the integral is $1-\frac{\ln(1+n)}{n}$, which tends to $1$.

@mistakes
- Invoking dominated convergence without producing one integrable function that bounds every $f_n$; pointwise convergence alone allows the spike $n\mathbf 1_{(0,1/n)}$.
- Concluding that a function is not Lebesgue integrable because it is not Riemann integrable, as with $\mathbf 1_{\mathbb{Q}}$.
- Deducing $f=0$ everywhere from $\int|f|=0$; the correct conclusion is $f=0$ almost everywhere.
- Exchanging a sum and an integral for terms of changing sign without checking $\sum_k\int|f_k|<\infty$.

@quiz num
prompt: Evaluate $\displaystyle\lim_{n\to\infty}\int_0^1\Big(1+\frac xn\Big)^{-n}dx$ as an exact value.
answer: 1-e^(-1)
check: quad(lambda x: exp(-1e7 * np.log1p(x / 1e7)), 0, 1)
hint: Find the pointwise limit of the integrand, then look for an integrable bound that does not depend on $n$.
hint: Bernoulli's inequality gives $(1+x/n)^n\ge1+x$ for $x\ge0$.
solution: For each $x$, $(1+x/n)^{-n}\to e^{-x}$. Since $(1+x/n)^n\ge1+x$, we have $0\le(1+x/n)^{-n}\le\frac1{1+x}\le1$, which is integrable on $[0,1]$. Dominated convergence gives the limit $\int_0^1e^{-x}\,dx=1-e^{-1}$.

@quiz self
prompt: Let $f_n=n\,\mathbf 1_{(0,1/n)}$ on $[0,1]$. (a) Show $f_n(x)\to0$ for every $x$ while $\int f_n=1$ for all $n$. (b) Explain which hypothesis of dominated convergence fails, by proving that no integrable $g$ satisfies $f_n\le g$ for all $n$. (c) Does Fatou's lemma hold for this sequence?
hint: For (b) bound $\sup_nf_n(x)$ below by a multiple of $1/x$ and use the fact that $\int_0^11/x\,dx=\infty$.
hint: For (c) compare $\int\liminf f_n$ with $\liminf\int f_n$.
solution: (a) If $x\in(0,1]$ then $f_n(x)=0$ once $n\ge1/x$, and $f_n(0)=0$ for all $n$. Also $\int f_n=n\cdot\frac1n=1$. (b) Suppose $g\ge f_n$ for all $n$. If $x\in(\frac1{m+1},\frac1m)$ then $f_m(x)=m$, and $m\ge\frac1{2x}$: for $m\ge2$ we have $x<\frac12$ and $m>\frac1x-1\ge\frac1{2x}$, while for $m=1$ we have $x>\frac12$ and $1\ge\frac1{2x}$. Hence $g(x)\ge\frac1{2x}$ for every $x\in(0,1)$ outside the countable set $\{1/m\}$, so $\int_0^1g\ge\frac12\int_0^1\frac{dx}{x}=\infty$ and $g$ is not integrable. The domination hypothesis fails. (c) $\int\liminf f_n=\int0=0\le1=\liminf\int f_n$, so Fatou's inequality holds, and it is strict: mass is lost in the limit.

@article
For a symmetric matrix you can always find an orthonormal basis of eigenvectors. The **spectral theorem** says how much of this survives in infinite dimensions, and the honest answer is: all of it for compact self-adjoint operators, and something subtler for the rest. Part of the skill is knowing which case you are in.

### Spectrum and self-adjointness

For a bounded operator $T$ on a complex Hilbert space, the **spectrum** $\sigma(T)$ is the set of $\lambda\in\mathbb{C}$ for which $T-\lambda I$ has no bounded inverse. Every eigenvalue lies in $\sigma(T)$, but in infinite dimensions $\sigma(T)$ can contain points that are not eigenvalues. The spectrum is compact, non-empty and contained in the disc $|\lambda|\le\|T\|$.

A bounded operator is **self-adjoint** if $T=T^*$, that is $\langle Tx,y\rangle=\langle x,Ty\rangle$ for all $x,y$. Then $\langle x,Tx\rangle$ is real, eigenvalues are real, eigenvectors for different eigenvalues are orthogonal, $\sigma(T)\subset\mathbb{R}$ and $\|T\|=\sup_{\|x\|=1}|\langle x,Tx\rangle|$.

### The theorem

**Spectral theorem (compact self-adjoint).** Let $T$ be a compact self-adjoint operator on a separable Hilbert space $H$. Then there are an orthonormal system $(e_k)$ and real numbers $\lambda_k\neq0$ with $|\lambda_1|\ge|\lambda_2|\ge\cdots$, and $\lambda_k\to0$ if there are infinitely many, such that $Te_k=\lambda_ke_k$ and

$$Tx=\sum_k\lambda_k\,\langle e_k,x\rangle\,e_k\quad\text{for all }x\in H.$$

The $e_k$ together with an orthonormal basis of $\ker T$ form an orthonormal basis of $H$. Every non-zero point of $\sigma(T)$ is some $\lambda_k$ and has finite multiplicity, and $\|T\|=\max_k|\lambda_k|$. It gives a **functional calculus**: $f(T)x=\sum_kf(\lambda_k)\langle e_k,x\rangle e_k$ for continuous $f$ with $f(0)=0$ (in general add $f(0)$ times the projection onto $\ker T$). In quantum theory, for a normalized state $\psi$ and an observable $A=\sum\lambda_k\langle e_k,\cdot\rangle e_k$, the outcome $\lambda_k$ has probability $|\langle e_k,\psi\rangle|^2$ (for distinct eigenvalues; equal ones add) and the expectation value is $\langle\psi,A\psi\rangle=\sum_k\lambda_k|\langle e_k,\psi\rangle|^2$.

For a self-adjoint integral operator with square-integrable kernel, $\sum_k\lambda_k^2=\|k\|_{L^2}^2$. If the kernel is continuous and the operator is positive, $\sum_k\lambda_k=\int k(x,x)\,dx$ (Mercer).

### When the hypotheses fail

- **Not compact.** Multiplication by $x$ on $L^2(0,1)$ is bounded and self-adjoint but has no eigenvalues at all, and $\sigma=[0,1]$. The correct general statement replaces the sum by an integral against a spectral measure: $T=\int\lambda\,dE(\lambda)$.
- **Not self-adjoint.** The Volterra operator is compact, but it has no eigenvalues and $\sigma(V)=\{0\}$. There is no eigenbasis.
- **Unbounded: domains matter.** The momentum operator $p=-i\,\frac{d}{dx}$ on $L^2(0,1)$ with domain $H_0^1$ (functions vanishing at both ends) satisfies $\langle\varphi,p\psi\rangle=\langle p\varphi,\psi\rangle$, so it is **symmetric**. But $p^*$ is $-i\,\frac{d}{dx}$ on the larger domain $H^1$, so $p\neq p^*$: it is not self-adjoint, and every $\lambda\in\mathbb{C}$ is an eigenvalue of $p^*$ with eigenfunction $e^{i\lambda x}$. For a symmetric unbounded operator, the spectral theorem needs self-adjointness (equal domains); symmetry alone is not enough.

```python
import numpy as np
n = 800
x = (np.arange(n) + 0.5) / n
K = np.minimum.outer(x, x) / n                 # discretized kernel min(x, y)
w = np.linalg.eigvalsh(K)[::-1]                # real eigenvalues, largest first
exact = 1 / ((np.arange(1, 5) - 0.5) * np.pi) ** 2
print(w[:4])
print(exact)                                   # agrees to about three digits
print(w.sum())                                 # about 0.5, the integral of k(x, x)
```

@example
title: Spectral decomposition of the kernel $\min(x,y)$
problem: Let $(Kf)(x)=\int_0^1\min(x,y)\,f(y)\,dy$ on $L^2(0,1)$. Find its eigenvalues and eigenfunctions.
step: $K$ is compact (the kernel is square integrable) and self-adjoint (the kernel is real and symmetric), so the theorem applies. Write $(Kf)(x)=\int_0^xy\,f(y)\,dy+x\int_x^1f(y)\,dy$.
step: Differentiate: $(Kf)'(x)=\int_x^1f(y)\,dy$ and $(Kf)''(x)=-f(x)$. Also $(Kf)(0)=0$ and $(Kf)'(1)=0$.
step: If $Kf=\lambda f$ with $\lambda\neq0$, then $u=f$ satisfies $\lambda u''=-u$, $u(0)=0$, $u'(1)=0$. With $\omega=\lambda^{-1/2}$ the solutions are $u=\sin(\omega x)$, and $u'(1)=\omega\cos\omega=0$ forces $\omega=(k-\tfrac12)\pi$.
step: So $\lambda_k=\dfrac{1}{(k-\frac12)^2\pi^2}$ with orthonormal eigenfunctions $e_k(x)=\sqrt2\sin\big((k-\tfrac12)\pi x\big)$, $k=1,2,\dots$ Thus $\|K\|=\lambda_1=\frac4{\pi^2}$.
step: Check with the trace formula: $\sum_k\lambda_k=\frac{4}{\pi^2}\sum_k\frac1{(2k-1)^2}=\frac4{\pi^2}\cdot\frac{\pi^2}{8}=\frac12=\int_0^1x\,dx$.

@example
title: Auditing the hypotheses
problem: Decide for each operator on $L^2(0,1)$ whether the spectral theorem for compact self-adjoint operators applies: (a) $K$ with kernel $\min(x,y)$; (b) the Volterra operator $Vf(x)=\int_0^xf$; (c) $Mf(x)=xf(x)$.
step: List the hypotheses: the operator is bounded, compact and self-adjoint, on a Hilbert space. All must hold, with $T=T^*$ as operators including domains.
step: (a) The kernel is in $L^2$ so $K$ is compact, and it is real and symmetric so $K=K^*$. The theorem applies.
step: (b) $V$ is compact since $\mathbf 1_{y<x}\in L^2$, but $V^*$ has kernel $\mathbf 1_{x<y}$, so $V\neq V^*$. If $Vf=\lambda f$ then $f$ is continuous and $f=\lambda f'$ with $f(0)=0$ (for $\lambda\neq0$), so $f=0$; and $Vf=0$ gives $f=0$. There is no eigenvector at all.
step: (c) $M$ is bounded and self-adjoint. It is not compact: $f_n=\sqrt n\,\mathbf 1_{(1-1/n,1)}$ has $\|f_n\|=1$ and $\|Mf_n\|\ge1-\frac1n$, while $f_n\rightharpoonup0$. Also $(x-\lambda)f=0$ a.e. forces $f=0$, so $M$ has no eigenvectors.

@mistakes
- Citing the spectral theorem for a bounded self-adjoint operator that is not compact and expecting an orthonormal basis of eigenvectors; multiplication by $x$ has none.
- Assuming that a symmetric (formally self-adjoint) differential operator is self-adjoint without comparing domains of $T$ and $T^*$.
- Assuming that compact implies diagonalizable: the Volterra operator is compact with spectrum $\{0\}$ and no eigenvectors.
- Treating the spectrum as the set of eigenvalues; in infinite dimensions $\sigma(T)$ can be larger, and $0\in\sigma(T)$ for every compact operator on an infinite-dimensional space.

@practice self
prompt: Show that multiplication by $x$ on $L^2(0,1)$, $(Mf)(x)=xf(x)$, has no eigenvalue, and that it is not compact. Explain which hypothesis of the spectral theorem for compact self-adjoint operators this violates.
hint: If $Mf=\lambda f$ then $(x-\lambda)f(x)=0$ for almost every $x$. On what set can $f$ be nonzero?
hint: For non-compactness use $f_n=\sqrt n\,\mathbf 1_{(1-1/n,1)}$ and last week's result that compact operators map weakly null sequences to norm null sequences.
solution: Suppose $Mf=\lambda f$ with $\lambda\in\mathbb{C}$. Then $(x-\lambda)f(x)=0$ for almost every $x$. Since $x-\lambda\neq0$ except for at most one point $x=\lambda$, which is a null set, $f=0$ a.e. So $M$ has no eigenvector. For non-compactness put $f_n=\sqrt n\,\mathbf 1_{(1-1/n,1)}$. Then $\|f_n\|_2=1$ and $\|Mf_n\|_2^2=n\int_{1-1/n}^1x^2\,dx\ge\big(1-\tfrac1n\big)^2$. Also $f_n\rightharpoonup0$: for $g\in L^2$, $|\langle g,f_n\rangle|\le\sqrt n\int_{1-1/n}^1|g|\le\|g\mathbf 1_{(1-1/n,1)}\|_2\to0$ by Cauchy–Schwarz and dominated convergence. If $M$ were compact, $Mf_n\to0$ in norm, contradicting $\|Mf_n\|\to1$. So $M$ is bounded and self-adjoint but not compact, and it has no orthonormal basis of eigenvectors; compactness is the violated hypothesis.
rubric: Proves there is no eigenvector, using that a single point is a null set.
rubric: Gives a bounded sequence $f_n$ with $f_n\rightharpoonup0$ but $\|Mf_n\|\not\to0$, and concludes $M$ is not compact.
rubric: Identifies compactness as the failed hypothesis (self-adjointness and boundedness hold).

@quiz self
prompt: (a) Let $T=T^*$ be bounded. Show every eigenvalue is real and eigenvectors for distinct eigenvalues are orthogonal. (b) Suppose $Tx=\sum_k\lambda_k\langle e_k,x\rangle e_k$ for an orthonormal system $(e_k)$ with real $\lambda_k$ tending to $0$. Show $\|Tx\|^2=\sum_k\lambda_k^2|\langle e_k,x\rangle|^2$ and deduce $\|T\|=\max_k|\lambda_k|$.
hint: For (a) compute $\langle x,Tx\rangle$ in two ways when $Tx=\lambda x$, and similarly $\langle y,Tx\rangle$ for two eigenvectors.
hint: For (b) use orthonormality for the norm formula, then Bessel's inequality for the upper bound and a test vector for the lower bound.
solution: (a) If $Tx=\lambda x$ with $x\neq0$, then $\lambda\|x\|^2=\langle x,Tx\rangle=\langle Tx,x\rangle=\bar\lambda\|x\|^2$, so $\lambda=\bar\lambda$ is real. If also $Ty=\mu y$ with $\mu\neq\lambda$, then $\lambda\langle y,x\rangle=\langle y,Tx\rangle=\langle Ty,x\rangle=\mu\langle y,x\rangle$ (using $\mu$ real), so $(\lambda-\mu)\langle y,x\rangle=0$ and $\langle y,x\rangle=0$. (b) The vectors $e_k$ are orthonormal, so by Parseval for the system $\|Tx\|^2=\sum_k\lambda_k^2|\langle e_k,x\rangle|^2$. Let $m=\max_k|\lambda_k|$, which exists because $\lambda_k\to0$ (if all $\lambda_k=0$ the claim is trivial). Then $\|Tx\|^2\le m^2\sum_k|\langle e_k,x\rangle|^2\le m^2\|x\|^2$ by Bessel, so $\|T\|\le m$. If $|\lambda_j|=m$ then $\|Te_j\|=|\lambda_j|=m$ and $\|e_j\|=1$, so $\|T\|\ge m$.
rubric: Proves reality of eigenvalues from $\langle x,Tx\rangle=\langle Tx,x\rangle$.
rubric: Proves orthogonality for distinct eigenvalues, using that eigenvalues are real.
rubric: Derives the norm formula from orthonormality and obtains $\|T\|=\max|\lambda_k|$ with an upper bound from Bessel and a lower bound from an eigenvector.

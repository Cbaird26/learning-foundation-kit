@article
Length is easy for an interval and hard for a general set. We need a rule that assigns a size to a rich family of sets, that behaves well under countable limits, and that ignores sets too small to matter. That rule is a **measure**, and the family of sets it can measure is a **$\sigma$-algebra**.

### Definitions

A **$\sigma$-algebra** on a set $X$ is a family $\mathcal{A}$ of subsets of $X$ with $X\in\mathcal{A}$, closed under complements, and closed under countable unions (hence countable intersections). A **measure** is a map $\mu:\mathcal{A}\to[0,\infty]$ with $\mu(\emptyset)=0$ and **countable additivity**: for pairwise disjoint $E_1,E_2,\ldots\in\mathcal{A}$,

$$\mu\Big(\bigcup_{k=1}^\infty E_k\Big)=\sum_{k=1}^\infty\mu(E_k).$$

The **Borel** $\sigma$-algebra on $\mathbb{R}$ is generated by the open sets. **Lebesgue measure** $\lambda$ assigns $\lambda([a,b])=b-a$ and extends uniquely to all Borel sets (and to a slightly larger $\sigma$-algebra). Not every subset of $\mathbb{R}$ is measurable; the counterexamples need the axiom of choice, and you will never meet one by accident.

Other examples: counting measure $\mu(A)=\#A$, and the Dirac measure $\delta_a(A)=1$ if $a\in A$ and $0$ otherwise. A weighted sum such as $\mu(A)=\sum_{k\in A\cap\mathbb{N}}2^{-k}$ is also a measure.

### Consequences of the axioms

For measurable sets: if $A\subseteq B$ then $\mu(A)\le\mu(B)$ (monotonicity); $\mu\big(\bigcup_kE_k\big)\le\sum_k\mu(E_k)$ for any sequence (countable subadditivity); and if $A_1\subseteq A_2\subseteq\cdots$ then $\mu\big(\bigcup_nA_n\big)=\lim_n\mu(A_n)$ (continuity from below). If the sets decrease and $\mu(A_1)<\infty$, then $\mu\big(\bigcap_nA_n\big)=\lim_n\mu(A_n)$. The finiteness assumption cannot be dropped: $A_n=[n,\infty)$ all have infinite Lebesgue measure but $\bigcap_nA_n=\emptyset$.

### Null sets and "almost everywhere"

A set $N$ is **null** if $\mu(N)=0$. Countable subadditivity shows that a countable union of null sets is null. Every countable subset of $\mathbb{R}$ is Lebesgue null: cover the $k$-th point by an interval of length $\varepsilon2^{-k}$, so the total length is at most $\varepsilon$. Null sets can also be uncountable, as for the Cantor set: stage $n$ of its construction leaves length $(2/3)^n\to0$.

A statement holds **almost everywhere** (a.e.) if the set where it fails is contained in a null set. The function $\mathbf 1_{\mathbb{Q}}$ is $0$ a.e. but not $0$ everywhere. Functions that agree a.e. are indistinguishable for integration, so function spaces built from integrals identify them.

### Measurable functions

A function $f:X\to\mathbb{R}$ is **measurable** if $\{x:f(x)>a\}\in\mathcal{A}$ for every real $a$. Continuous functions are measurable, and sums, products and pointwise limits of measurable functions are measurable. That last closure property is what the Riemann integral lacks.

```python
def length_of_union(intervals):
    intervals = sorted(intervals)
    total, start, end = 0.0, *intervals[0]
    for a, b in intervals[1:]:
        if a > end:                 # a gap: close the current block
            total += end - start
            start, end = a, b
        else:                       # overlap: extend the block
            end = max(end, b)
    return total + (end - start)

print(length_of_union([(0, 2), (1, 3), (5, 6)]))   # 4.0
```

@example
title: The rationals have measure zero
problem: Show that $\lambda(\mathbb{Q}\cap[0,1])=0$ and deduce $\lambda([0,1]\setminus\mathbb{Q})=1$.
step: The set is countable, so list it as $q_1,q_2,q_3,\ldots$. Fix $\varepsilon>0$ and let $I_k$ be an interval of length $\varepsilon2^{-k}$ containing $q_k$.
step: Then $\mathbb{Q}\cap[0,1]\subseteq\bigcup_kI_k$, and monotonicity with countable subadditivity gives $\lambda(\mathbb{Q}\cap[0,1])\le\sum_k\varepsilon2^{-k}=\varepsilon$.
step: Since $\varepsilon>0$ was arbitrary, the measure is $0$.
step: The sets $\mathbb{Q}\cap[0,1]$ and $[0,1]\setminus\mathbb{Q}$ are disjoint with union $[0,1]$, so additivity gives $0+\lambda([0,1]\setminus\mathbb{Q})=1$. Almost every point of $[0,1]$ is irrational, yet the rationals are dense.

@example
title: Continuity from below
problem: Let $A_1\subseteq A_2\subseteq\cdots$ be measurable. Prove $\mu\big(\bigcup_nA_n\big)=\lim_n\mu(A_n)$.
step: Disjointify. Put $B_1=A_1$ and $B_n=A_n\setminus A_{n-1}$ for $n\ge2$. These sets are measurable and pairwise disjoint.
step: Because the $A_n$ increase, $A_N=B_1\cup\cdots\cup B_N$ for each $N$ and $\bigcup_nA_n=\bigcup_nB_n$.
step: By countable additivity, $\mu\big(\bigcup_nA_n\big)=\sum_{n=1}^\infty\mu(B_n)=\lim_{N\to\infty}\sum_{n=1}^{N}\mu(B_n)$.
step: By finite additivity $\sum_{n\le N}\mu(B_n)=\mu(A_N)$, which gives the claim. For example, $\lambda([0,\infty))=\lim_n\lambda([0,n])=\infty$.

@mistakes
- Believing that an uncountable set must have positive measure; the Cantor set is uncountable and null.
- Adding measures of overlapping sets: additivity needs disjoint sets, and for finite measures $\mu(A\cup B)=\mu(A)+\mu(B)-\mu(A\cap B)$.
- Using continuity from above for sets of infinite measure, as with $[n,\infty)$.
- Calling a statement "true almost everywhere" when the exceptional set has positive measure, or confusing "a.e." with "except at countably many points".

prompt: Starting only from monotonicity and countable additivity, prove countable subadditivity: $\mu\big(\bigcup_kE_k\big)\le\sum_k\mu(E_k)$ for measurable $E_k$. Deduce that a countable union of null sets is null.

By countable additivity and monotonicity $\mu\big(\bigcup_kE_k\big)=\sum_k\mu(F_k)\le\sum_k\mu(E_k)$. If each $E_k$ is null, the right side is $0$, so the union has measure $0$.

@quiz self
prompt: Let $\mathcal{A}$ be the family of subsets $A\subseteq\mathbb{R}$ such that $A$ is countable or $\mathbb{R}\setminus A$ is countable. Prove that $\mathcal{A}$ is a $\sigma$-algebra, and that $\mu(A)=0$ for countable $A$ and $\mu(A)=1$ for co-countable $A$ defines a measure on $\mathcal{A}$.
hint: Closure under complements is immediate from the definition. For countable unions, split into the case where every set is countable and the case where some set is co-countable.
hint: For additivity, note that two disjoint sets cannot both be co-countable.
solution: $\mathbb{R}\in\mathcal{A}$ since its complement is empty. If $A\in\mathcal{A}$ then $\mathbb{R}\setminus A\in\mathcal{A}$ by symmetry of the definition. Let $A_1,A_2,\ldots\in\mathcal{A}$. If all are countable, the union is countable. If some $A_j$ is co-countable, then $\mathbb{R}\setminus\bigcup_kA_k\subseteq\mathbb{R}\setminus A_j$ is countable. Either way the union is in $\mathcal{A}$. For $\mu$: $\mu(\emptyset)=0$ and the two cases are exclusive, since $\mathbb{R}$ is uncountable, so a set cannot be both countable and co-countable. For disjoint $E_k\in\mathcal{A}$, at most one is co-countable (two co-countable sets intersect, since their complements are countable and $\mathbb{R}$ is not). If all are countable, the union is countable and both sides are $0$. If $E_j$ is co-countable, the other sets lie in the countable set $\mathbb{R}\setminus E_j$, so they are countable and the union is co-countable: both sides are $1$.

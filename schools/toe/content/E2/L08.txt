@article
"$f_n\to f$" can mean several things. Which one you have decides what you may conclude, so functional analysis keeps them apart. Let $f_n,f$ be measurable on a measure space $(X,\mu)$.

### The modes

- **Uniform:** $\sup_x|f_n(x)-f(x)|\to0$.
- **Almost everywhere (a.e.):** $f_n(x)\to f(x)$ for all $x$ outside a null set.
- **In $L^p$:** $\|f_n-f\|_p\to0$.
- **In measure:** for every $\varepsilon>0$, $\mu\big(\{|f_n-f|>\varepsilon\}\big)\to0$.

### What implies what

Take $\mu(X)<\infty$, for example $[0,1]$ with Lebesgue measure. Then

$$\text{uniform}\ \Longrightarrow\ \text{a.e.}\ \Longrightarrow\ \text{in measure},\qquad \text{uniform}\ \Longrightarrow\ L^p\ \Longrightarrow\ \text{in measure}.$$

The step a.e. $\Rightarrow$ in measure is **Egorov's theorem** in disguise and needs finite measure. The step $L^p\Rightarrow$ in measure is **Markov's inequality**: $\mu(\{|f_n-f|>\varepsilon\})\le\varepsilon^{-p}\|f_n-f\|_p^p$. No arrow can be reversed, and there is no arrow between a.e. and $L^p$:

- **$x^n$** on $[0,1]$ converges to $0$ a.e. and in every $L^p$, but not uniformly.
- **The spike** $n\mathbf 1_{(0,1/n)}$ converges to $0$ everywhere and in measure but not in $L^1$ (norm $1$). Dominated convergence says what is missing: an integrable bound.
- **The typewriter sequence** (Example 2) converges to $0$ in every $L^p$ with $p<\infty$ and in measure but at no point of $[0,1)$.

What survives is a partial converse, **Riesz's theorem**: if $f_n\to f$ in measure (in particular in $L^p$), then some subsequence converges a.e.

### Weak convergence

In a normed space $X$, say $x_n\to x$ **weakly**, written $x_n\rightharpoonup x$, if $\phi(x_n)\to\phi(x)$ for every $\phi\in X^*$. Norm convergence implies weak convergence because $|\phi(x_n)-\phi(x)|\le\|\phi\|\|x_n-x\|$. In finite dimensions the two coincide. In infinite dimensions they do not: in $\ell^2$ the basis vectors satisfy $e_n\rightharpoonup0$, because every functional is $x\mapsto\sum x_ky_k$ with $y\in\ell^2$ and $y_n\to0$, while $\|e_n\|=1$. Likewise $\sin(nx)\rightharpoonup0$ in $L^2(0,2\pi)$: oscillation averages away against any fixed function but the norm stays $\sqrt\pi$.

Weak limits can lose norm but never gain it: $\|x\|\le\liminf\|x_n\|$. In quantum theory this is the difference between a state that spreads out or oscillates away (weakly null) and one that actually vanishes.

```python
def typewriter(n):
    """Interval [a, b) of the n-th indicator, n = 0, 1, 2, ..."""
    k = 0
    while n >= 2**k:          # block k holds 2**k intervals of length 2**-k
        n -= 2**k
        k += 1
    return n / 2**k, (n + 1) / 2**k

x = 0.3
hits = [n for n in range(200) if typewriter(n)[0] <= x < typewriter(n)[1]]
print(hits)                   # one hit in every block: f_n(x) = 1 infinitely often
print(typewriter(199))        # an interval of length 2**-7: the norms still tend to 0
```

@example
title: The spike: everywhere and in measure, but not in $L^1$
problem: Let $f_n=n\mathbf 1_{(0,1/n)}$ on $[0,1]$. Determine in which senses $f_n\to0$.
step: Pointwise. If $x\in(0,1]$, then $f_n(x)=0$ as soon as $1/n\le x$. Also $f_n(0)=0$. So $f_n(x)\to0$ for every $x$, hence a.e.
step: In measure. For $\varepsilon>0$ and $n>\varepsilon$, $\{f_n>\varepsilon\}=(0,1/n)$, which has measure $\frac1n\to0$.
step: In $L^1$. $\|f_n-0\|_1=\int_0^{1/n}n\,dx=1$ for every $n$, so $f_n\not\to0$ in $L^1$.
step: In $L^p$ for $p>1$ it is worse: $\|f_n\|_p^p=n^{p-1}\to\infty$. A.e. convergence with norms not tending to $0$ is exactly what domination rules out.

@example
title: The typewriter sequence
problem: List the dyadic intervals $[j2^{-k},(j+1)2^{-k})$ for $k=0,1,2,\dots$ and $0\le j<2^k$ in the order of increasing $k$, then increasing $j$, as $I_0=[0,1)$, $I_1=[0,\tfrac12)$, $I_2=[\tfrac12,1)$, $I_3=[0,\tfrac14),\dots$ and put $f_n=\mathbf 1_{I_n}$. Study the convergence of $f_n$.
step: Norms. If $I_n$ lies in block $k$, then $\|f_n\|_p^p=\lambda(I_n)=2^{-k}$. As $n\to\infty$, $k\to\infty$, so $f_n\to0$ in every $L^p$ with $p<\infty$, and in measure.
step: No pointwise limit. Each $x\in[0,1)$ lies in exactly one interval of every block, so $f_n(x)=1$ for infinitely many $n$. It also equals $0$ for infinitely many $n$, so $(f_n(x))$ diverges for every $x$.
step: A subsequence. Let $n_k=2^k-1$ be the first index of block $k$, so $I_{n_k}=[0,2^{-k})$. For $x>0$, $f_{n_k}(x)=0$ once $2^{-k}\le x$. Thus $f_{n_k}\to0$ a.e., as Riesz's theorem predicts.

@mistakes
- Assuming that convergence in $L^p$ forces convergence a.e.; only a subsequence is guaranteed.
- Assuming that a.e. convergence forces convergence of integrals; the spike $n\mathbf 1_{(0,1/n)}$ shows a dominating function is needed.
- Using "a.e. implies in measure" or "uniform implies $L^p$" on an infinite measure space such as $\mathbb{R}$, where $\mathbf 1_{[n,n+1]}$ and $\frac1n\mathbf 1_{[0,n^2]}$ are counterexamples.
- Treating weak convergence as norm convergence: $e_n\rightharpoonup0$ in $\ell^2$ although $\|e_n\|=1$.

@practice mc
prompt: In $\ell^2$ let $e_n$ be the $n$-th standard basis vector. Which statement is correct?
choice: $e_n\to0$ in norm.
choice*: $e_n\rightharpoonup0$ weakly, but $e_n\not\to0$ in norm.
choice: $(e_n)$ has no weak limit, because it is not Cauchy in norm.
choice: $e_n\rightharpoonup e_1$ weakly.
hint: Every bounded functional on $\ell^2$ is $x\mapsto\sum_kx_ky_k$ for some $y\in\ell^2$. What is its value at $e_n$?
solution: $\phi_y(e_n)=y_n\to0$ because $\sum y_k^2<\infty$, so $e_n\rightharpoonup0$. But $\|e_n\|_2=1$ for all $n$, so there is no norm convergence to $0$. Weak convergence does not require the sequence to be Cauchy in norm.

prompt: Prove that norm convergence implies weak convergence in any normed space. Then show that the converse fails in $\ell^2$, using that every bounded functional on $\ell^2$ has the form $x\mapsto\sum_kx_ky_k$ with $y\in\ell^2$.
hint: Estimate $|\phi(x_n)-\phi(x)|$ using the definition of $\|\phi\|$.
hint: For the counterexample try $x_n=e_n$ and recall why $y_n\to0$ for $y\in\ell^2$.
solution: Suppose $\|x_n-x\|\to0$ and $\phi\in X^*$. Then $|\phi(x_n)-\phi(x)|=|\phi(x_n-x)|\le\|\phi\|\,\|x_n-x\|\to0$, so $x_n\rightharpoonup x$. For the converse take $x_n=e_n$ in $\ell^2$. A bounded functional is $\phi_y(x)=\sum x_ky_k$ with $y\in\ell^2$, and $\phi_y(e_n)=y_n\to0$ since the series $\sum y_k^2$ converges. @quiz self
prompt: Let $f_n\to f$ in $L^1(\mu)$. Prove that some subsequence converges to $f$ almost everywhere.
hint: Choose $n_1<n_2<\cdots$ with $\|f_{n_k}-f\|_1<2^{-k}$.
hint: Apply monotone convergence to $\sum_k|f_{n_k}-f|$.
solution: Choose $n_1<n_2<\cdots$ with $\|f_{n_k}-f\|_1<2^{-k}$, which is possible by $L^1$ convergence. Let $G=\sum_k|f_{n_k}-f|\ge0$. By monotone convergence $\int G=\sum_k\|f_{n_k}-f\|_1\le\sum_k2^{-k}=1<\infty$, so $G<\infty$ outside a null set $N$. For $x\notin N$ the series $\sum_k|f_{n_k}(x)-f(x)|$ converges, so its terms tend to $0$: $f_{n_k}(x)\to f(x)$. Hence $f_{n_k}\to f$ a.e.
rubric: Chooses a subsequence with summable $L^1$ distances.
rubric: Uses monotone convergence to show $\sum_k|f_{n_k}-f|$ is finite a.e.
rubric: Concludes that the terms, hence $f_{n_k}(x)-f(x)$, tend to $0$ almost everywhere.

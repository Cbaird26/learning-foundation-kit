@article
The potentials $\varphi$ and $\mathbf{A}$ produce the fields through $\mathbf{B} = \nabla\times\mathbf{A}$ and $\mathbf{E} = -\nabla\varphi - \partial_t\mathbf{A}$. Different potentials can describe the same fields, and exploiting that freedom is a routine tool.

### Gauge freedom

For any smooth function $\lambda(\mathbf{r},t)$ define

$$\mathbf{A}' = \mathbf{A} + \nabla\lambda,\qquad \varphi' = \varphi - \frac{\partial\lambda}{\partial t}.$$

The fields do not change:

$$\nabla\times\mathbf{A}' = \nabla\times\mathbf{A} + \nabla\times\nabla\lambda = \mathbf{B},$$
$$-\nabla\varphi' - \partial_t\mathbf{A}' = -\nabla\varphi + \nabla\partial_t\lambda - \partial_t\mathbf{A} - \partial_t\nabla\lambda = \mathbf{E},$$

because the curl of a gradient is zero and partial derivatives commute. In four-vector form, $A^\mu \to A^\mu - \partial^\mu\lambda$, and $F^{\mu\nu}$ is unchanged because $\partial^\mu\partial^\nu\lambda$ is symmetric. The two potentials must transform *together*, with the sign in $\varphi' = \varphi - \partial_t\lambda$ exactly as above.

Only gauge-invariant quantities are physical: $\mathbf{E}$, $\mathbf{B}$, and combinations such as $\oint\mathbf{A}\cdot d\boldsymbol{\ell}$ around a closed loop, which equals the magnetic flux $\Phi_B$ through it. (The potentials themselves enter quantum mechanics through phases, as in the Aharonov–Bohm effect.)

### Choosing a gauge

We use $\lambda$ to simplify the equations.

- **Lorenz gauge**, $\nabla\cdot\mathbf{A} + c^{-2}\partial_t\varphi = 0$, gives the decoupled wave equations of Week 9. If a given pair violates it, the new value is the old one plus $\Box\lambda$ with $\Box = \nabla^2 - c^{-2}\partial_t^2$, so choose $\lambda$ with $\Box\lambda = -(\nabla\cdot\mathbf{A} + c^{-2}\partial_t\varphi)$. **Residual freedom**: any $\lambda$ with $\Box\lambda = 0$ preserves the condition.
- **Coulomb gauge**, $\nabla\cdot\mathbf{A} = 0$, is reached by solving $\nabla^2\lambda = -\nabla\cdot\mathbf{A}$. Gauss's law becomes $\nabla^2\varphi = -\rho/\varepsilon_0$, so $\varphi$ is the instantaneous Coulomb potential of $\rho(\mathbf{r},t)$. This does not permit superluminal signals: $\mathbf{E} = -\nabla\varphi - \partial_t\mathbf{A}$ also contains $\mathbf{A}$, whose wave equation is sourced by the transverse part of $\mathbf{J}$, and the total field is causal.
- **Radiation gauge** (Coulomb gauge in empty space): $\varphi = 0$ and $\nabla\cdot\mathbf{A} = 0$, so a plane wave is $\mathbf{A} = \mathbf{A}_0\cos(\mathbf{k}\cdot\mathbf{r} - \omega t)$ with $\mathbf{k}\cdot\mathbf{A}_0 = 0$, and $\mathbf{E} = -\partial_t\mathbf{A}$.

Choose the gauge that suits the problem, but always check a final answer by computing only gauge-invariant quantities.

@example
title: A gauge change that preserves the Lorenz condition
problem: In vacuum take $\varphi = 0$ and $\mathbf{A} = A_0\sin(kx - \omega t)\,\hat{\mathbf{y}}$ with $\omega = ck$. Apply the gauge function $\lambda = \lambda_0\cos(kx - \omega t)$. Verify that $\mathbf{E}$ and $\mathbf{B}$ are unchanged and test the Coulomb and Lorenz conditions before and after.
step: Original fields: $\mathbf{E} = -\partial_t\mathbf{A} = \omega A_0\cos(kx - \omega t)\,\hat{\mathbf{y}}$ and $\mathbf{B} = \nabla\times\mathbf{A} = kA_0\cos(kx - \omega t)\,\hat{\mathbf{z}}$. Also $\nabla\cdot\mathbf{A} = 0$, so this is the radiation gauge.
step: New potentials: $\mathbf{A}' = \mathbf{A} + \nabla\lambda = A_0\sin(kx - \omega t)\,\hat{\mathbf{y}} - \lambda_0k\sin(kx - \omega t)\,\hat{\mathbf{x}}$ and $\varphi' = -\partial_t\lambda = -\lambda_0\omega\sin(kx - \omega t)$.
step: Magnetic field: $B'_z = \partial_xA'_y - \partial_yA'_x$. The new $x$-component depends only on $x$, so $\partial_yA'_x = 0$, and $\partial_xA'_y$ is unchanged. So $\mathbf{B}' = \mathbf{B}$.
step: Electric field: $E'_x = -\partial_x\varphi' - \partial_tA'_x = \lambda_0\omega k\cos(kx - \omega t) - \lambda_0k\omega\cos(kx - \omega t) = 0$, and $E'_y = -\partial_tA'_y = E_y$. So $\mathbf{E}' = \mathbf{E}$.
step: Gauge conditions: $\nabla\cdot\mathbf{A}' = -\lambda_0k^2\cos(kx - \omega t) \neq 0$, so the Coulomb condition no longer holds. But $\nabla\cdot\mathbf{A}' + c^{-2}\partial_t\varphi' = \lambda_0(\omega^2/c^2 - k^2)\cos(kx - \omega t) = 0$, so the Lorenz condition survives. This works because $\lambda$ satisfies $\Box\lambda = 0$: it is residual Lorenz-gauge freedom.

@mistakes
- Transforming only $\mathbf{A}$ (or only $\varphi$). Both must change together, and the time-derivative term has a minus sign in $\varphi' = \varphi - \partial_t\lambda$.
- Reading the instantaneous Coulomb-gauge potential as faster-than-light influence. It is a gauge artefact; the observable $\mathbf{E}$ and $\mathbf{B}$ remain causal.
- Treating $\varphi$ or $\mathbf{A}$ as directly measurable. Only gauge-invariant combinations such as $\mathbf{E}$, $\mathbf{B}$ and $\oint\mathbf{A}\cdot d\boldsymbol{\ell}$ are.
- Assuming the Lorenz condition fixes the potentials uniquely. Any $\lambda$ with $\Box\lambda = 0$ leaves it intact.

hint: The new vector potential is the gradient of $\lambda$.
hint: At fixed $t$, $\partial\lambda/\partial x = \alpha t$.
solution: $A'_x = \partial_x(\alpha xt) = \alpha t = (5.0)(3.0) = 15\ \text{V·s/m}$. The accompanying scalar potential is $\varphi' = -\alpha x$, and together they give $\mathbf{E}' = \alpha\hat{\mathbf{x}} - \alpha\hat{\mathbf{x}} = 0$, as it must be.

@practice expr
prompt: In a static situation $\varphi = 0$ and $\mathbf{A} = \alpha x\,\hat{\mathbf{x}}$ with $\alpha$ constant. Find the gauge function $\lambda(x)$ with $\lambda(0) = 0$ and $\lambda'(0) = 0$ for which $\mathbf{A}' = \mathbf{A} + \nabla\lambda$ satisfies the Coulomb gauge condition $\nabla\cdot\mathbf{A}' = 0$.
vars: alpha, x
lead: $\lambda(x) =$
answer: -alpha x^2/2
check: lambda alpha, x: quad(lambda s: quad(lambda u: -alpha, 0, s), 0, x)
hint: The new divergence is $\nabla\cdot\mathbf{A}' = \nabla\cdot\mathbf{A} + \nabla^2\lambda$.
hint: Solve $\lambda''(x) = -\alpha$ with the given conditions at $x = 0$.
solution: $\nabla\cdot\mathbf{A}' = \alpha + \lambda''(x) = 0$ gives $\lambda'' = -\alpha$. Integrating twice with $\lambda(0) = \lambda'(0) = 0$ gives $\lambda = -\alpha x^2/2$. Then $\mathbf{A}' = \alpha x\hat{\mathbf{x}} - \alpha x\hat{\mathbf{x}} = 0$: the original field was pure gauge, with $\mathbf{B} = \nabla\times\mathbf{A} = 0$.

@practice self
prompt: Prove that $\mathbf{E}$ and $\mathbf{B}$ are invariant under the gauge transformation $\mathbf{A}' = \mathbf{A} + \nabla\lambda$, $\varphi' = \varphi - \partial\lambda/\partial t$. Then explain what would go wrong if only $\mathbf{A}$ were changed.
hint: Compute $\nabla\times\mathbf{A}'$ first, then substitute $\varphi'$ and $\mathbf{A}'$ into $-\nabla\varphi' - \partial_t\mathbf{A}'$.
hint: You need two facts: the curl of a gradient vanishes, and $\nabla\partial_t\lambda = \partial_t\nabla\lambda$.
solution: Magnetic field: $\mathbf{B}' = \nabla\times(\mathbf{A} + \nabla\lambda) = \nabla\times\mathbf{A} + \nabla\times\nabla\lambda = \mathbf{B}$, since the curl of any gradient is zero. Electric field: $\mathbf{E}' = -\nabla\varphi' - \partial_t\mathbf{A}' = -\nabla\varphi + \nabla(\partial_t\lambda) - \partial_t\mathbf{A} - \partial_t(\nabla\lambda) = \mathbf{E} + [\nabla\partial_t\lambda - \partial_t\nabla\lambda] = \mathbf{E}$, because mixed partial derivatives of a smooth $\lambda$ commute. So everything built from $\mathbf{E}$ and $\mathbf{B}$ (the Lorentz force, the energy density, the Poynting vector) is gauge-invariant. If only $\mathbf{A}$ changed, $\mathbf{B}$ would still be unchanged but $\mathbf{E}$ would shift by $-\partial_t\nabla\lambda$, which is generally nonzero, so the physical electric field would be altered; $\varphi$ must change by $-\partial_t\lambda$ to cancel it.
rubric: Shows $\nabla\times\mathbf{A}' = \mathbf{B}$ using $\nabla\times\nabla\lambda = 0$.
rubric: Substitutes both transformed potentials into $\mathbf{E} = -\nabla\varphi - \partial_t\mathbf{A}$ and shows the extra terms cancel.
rubric: Justifies the cancellation by commuting partial derivatives of $\lambda$.
rubric: Explains that shifting only $\mathbf{A}$ would change $\mathbf{E}$ by $-\partial_t\nabla\lambda$, so $\varphi$ must change too.

@quiz num
prompt: In some gauge the static potentials are $\varphi = 0$ and $\mathbf{A} = (-0.050\,y,\ 0.450\,x,\ 0)$ in $\text{T·m}$. Find the magnetic flux through a circle of radius $0.10\ \text{m}$ centred on the origin in the $xy$-plane, in webers.
answer: 0.01571
check: quad(lambda th: (-0.050*0.10*sin(th))*(-0.10*sin(th)) + (0.450*0.10*cos(th))*(0.10*cos(th)), 0, 2*pi)
tol: 1%
unit: Wb
hint: Stokes' theorem turns the flux into a line integral: $\Phi_B = \oint\mathbf{A}\cdot d\boldsymbol{\ell}$ around the circle.
hint: Alternatively compute $B_z = \partial_xA_y - \partial_yA_x$, which is uniform, and multiply by the area.
solution: $B_z = \partial_x(0.450x) - \partial_y(-0.050y) = 0.450 + 0.050 = 0.50\ \text{T}$, so $\Phi_B = B_z\pi R^2 = 0.50\pi(0.10)^2 = 1.57\times10^{-2}\ \text{Wb}$. The line integral gives the same value. This $\mathbf{A}$ equals the symmetric-gauge potential $(-0.25y,\ 0.25x,\ 0)$ plus $\nabla(0.20\,xy)$, so the flux does not depend on which gauge is used.

@quiz ms
prompt: Which statements about the Lorenz and Coulomb gauges are correct? Select all that apply.
choice*: In the Lorenz gauge, a further gauge function with $\Box\lambda = 0$ can still be applied without violating the gauge condition.
choice*: In the Coulomb gauge the scalar potential is the instantaneous Coulomb potential of $\rho(\mathbf{r},t)$, yet the fields $\mathbf{E}$ and $\mathbf{B}$ remain causal.
choice*: In empty space the Coulomb gauge can be chosen with $\varphi = 0$.
choice: Changing from the Lorenz gauge to the Coulomb gauge changes the value of $\mathbf{E}$ at a given point and time.
choice: The instantaneous Coulomb-gauge potential shows that signals can travel faster than light.
hint: Ask which quantities are observable, and what the gauge function can and cannot change.
solution: The Lorenz condition is preserved by any $\lambda$ obeying the wave equation. The Coulomb-gauge $\varphi$ responds instantly, but the vector potential's equation compensates so that $\mathbf{E}$ and $\mathbf{B}$ stay causal. In empty space $\rho = 0$ allows $\varphi = 0$. Gauge changes never alter $\mathbf{E}$ or $\mathbf{B}$.

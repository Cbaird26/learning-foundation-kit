@article
Substitution undoes the chain rule. **Integration by parts** undoes the product rule, and it is the tool for products such as $x e^x$, $x\cos x$ or $x^2\ln x$, where substitution has nothing to grab onto.

### Where the formula comes from

For differentiable $u$ and $v$ the product rule says $(uv)' = u'v + uv'$. Integrate both sides and rearrange:

$$\int u\,dv = uv - \int v\,du.$$

The formula trades one integral for another. It helps exactly when the new integral $\int v\,du$ is easier than the one you started with.

### A first example

Take $\int x e^x\,dx$. Differentiating $x$ makes it simpler (it becomes $1$), and $e^x$ is easy to integrate. So let $u = x$ and $dv = e^x\,dx$; then $du = dx$ and $v = e^x$:

$$\int x e^x\,dx = x e^x - \int e^x\,dx = x e^x - e^x + C.$$

Check by differentiating: $(x e^x - e^x)' = e^x + x e^x - e^x = x e^x$. Had you chosen $u = e^x$ and $dv = x\,dx$, the new integral would be $\int \tfrac{x^2}{2}e^x\,dx$, which is worse. The choice matters.

### Choosing u

Pick $u$ to be a factor that gets simpler when differentiated, and $dv$ a factor you can integrate. A useful priority list for $u$ is **LIATE**: Logarithms, Inverse trig, Algebraic (powers of $x$), Trig, Exponentials. Take $u$ from the type that appears first. It is a guideline, not a law; the real test is whether $\int v\,du$ got easier.

Sometimes the product is hidden. For $\int \ln x\,dx$ take $u = \ln x$ and $dv = dx$, so $du = \frac{dx}{x}$ and $v = x$:

$$\int \ln x\,dx = x\ln x - \int 1\,dx = x\ln x - x + C.$$

### Repeating the formula

For $\int x^2 e^x\,dx$, one round leaves $\int 2x e^x\,dx$, which needs a second round. The **tabular method** organizes this: differentiate $u$ down to $0$, integrate $dv$ repeatedly, and multiply each entry in the left column by the entry one row down in the right column, with signs $+,-,+,\dots$

| sign | $u$ and its derivatives | $dv$ and its antiderivatives |
|---|---|---|
| $+$ | $x^2$ | $e^x$ |
| $-$ | $2x$ | $e^x$ |
| $+$ | $2$ | $e^x$ |
|  | $0$ | $e^x$ |

So $\int x^2 e^x\,dx = x^2e^x - 2xe^x + 2e^x + C$.

### When the integral comes back

For $\int e^x\sin x\,dx$, two rounds of parts (with the trig factor as $u$ both times) return the original integral $I$:

$$I = e^x\sin x - e^x\cos x - I.$$

Do not keep going in circles: solve this equation for $I$ to get $I = \tfrac12 e^x(\sin x - \cos x) + C$.

### Definite integrals

With limits, evaluate the boundary term at both ends:

$$\int_a^b u\,dv = \big[uv\big]_a^b - \int_a^b v\,du.$$

Whatever you find, you can always check an antiderivative by differentiating it. Make that a habit.

@example
title: A definite integral with a logarithm
problem: Evaluate $\int_1^e x\ln x\,dx$.
step: The logarithm comes first in LIATE, so let $u = \ln x$ and $dv = x\,dx$. Then $du = \frac{1}{x}\,dx$ and $v = \frac{x^2}{2}$.
step: Apply the formula with limits: $\int_1^e x\ln x\,dx = \left[\frac{x^2}{2}\ln x\right]_1^e - \int_1^e \frac{x^2}{2}\cdot\frac{1}{x}\,dx$.
step: Boundary term: at $x = e$ it is $\frac{e^2}{2}\cdot 1$, and at $x = 1$ it is $\frac12\cdot 0 = 0$. So it equals $\frac{e^2}{2}$.
step: Remaining integral: $\int_1^e \frac{x}{2}\,dx = \left[\frac{x^2}{4}\right]_1^e = \frac{e^2 - 1}{4}$.
step: Subtract: $\frac{e^2}{2} - \frac{e^2 - 1}{4} = \frac{e^2 + 1}{4} \approx 2.097$.

@example
title: A cyclic integral
problem: Find $\int e^x\cos x\,dx$.
step: Call the integral $I$. Take $u = \cos x$ and $dv = e^x\,dx$, so $du = -\sin x\,dx$ and $v = e^x$: $I = e^x\cos x + \int e^x\sin x\,dx$.
step: Integrate by parts again, again with the trig factor as $u$: $u = \sin x$, $dv = e^x\,dx$ gives $\int e^x\sin x\,dx = e^x\sin x - \int e^x\cos x\,dx = e^x\sin x - I$.
step: Substitute back: $I = e^x\cos x + e^x\sin x - I$. The original integral has reappeared.
step: Solve for $I$: $2I = e^x(\sin x + \cos x)$, so $I = \frac12 e^x(\sin x + \cos x) + C$.
step: Check: $\frac{d}{dx}\left[\frac12 e^x(\sin x + \cos x)\right] = \frac12 e^x(\sin x + \cos x) + \frac12 e^x(\cos x - \sin x) = e^x\cos x$.

@mistakes
- Choosing $u = e^x$ and $dv = x\,dx$ in $\int x e^x\,dx$, which makes the new integral harder instead of easier.
- Dropping the minus sign in front of $\int v\,du$, or losing the alternating signs in the tabular method.
- In a definite integral, evaluating $uv$ only at the upper limit, or forgetting the boundary term entirely.
- In a cyclic integral, switching which factor plays $u$ on the second round, which just undoes the first round.

@practice expr
prompt: Find $\int x\cos x\,dx$. Omit $+C$.
vars: x
const: yes
lead: $\int x\cos x\,dx =$
answer: x sin(x) + cos(x)
check: lambda x: quad(lambda t: t*cos(t), 0, x)
hint: Differentiating $x$ simplifies it, and $\cos x$ is easy to integrate. Try $u = x$ and $dv = \cos x\,dx$.
hint: Then $du = dx$ and $v = \sin x$. Apply $uv - \int v\,du$.
solution: With $u = x$, $dv = \cos x\,dx$: $du = dx$, $v = \sin x$. So $\int x\cos x\,dx = x\sin x - \int\sin x\,dx = x\sin x + \cos x + C$. Check: $(x\sin x + \cos x)' = \sin x + x\cos x - \sin x = x\cos x$.

@practice num
prompt: Evaluate $\int_0^1 x e^{-x}\,dx$. Give an exact answer.
answer: 1 - 2/e
check: quad(lambda x: x*exp(-x), 0, 1)
hint: Let $u = x$ and $dv = e^{-x}\,dx$. What is $v$?
hint: $v = -e^{-x}$, so the integral equals $\left[-xe^{-x}\right]_0^1 + \int_0^1 e^{-x}\,dx$.
solution: $\int_0^1 xe^{-x}\,dx = \left[-xe^{-x}\right]_0^1 + \int_0^1 e^{-x}\,dx = -e^{-1} + \left[-e^{-x}\right]_0^1 = -e^{-1} + 1 - e^{-1} = 1 - \frac{2}{e} \approx 0.264$.

@practice mc
prompt: You want $\int x^2\ln x\,dx$ by parts. Which choice gives a new integral $\int v\,du$ with no logarithm in it?
choice*: $u = \ln x$, $dv = x^2\,dx$
choice: $u = x^2$, $dv = \ln x\,dx$
choice: $u = x^2\ln x$, $dv = dx$
choice: $u = x$, $dv = x\ln x\,dx$
hint: For each choice, find $du$ and $v$ and look at the product $v\,du$.
hint: Differentiating removes the logarithm, $\frac{d}{dx}\ln x = \frac{1}{x}$, but integrating $\ln x$ does not.
solution: With $u = \ln x$ and $dv = x^2\,dx$: $du = \frac{dx}{x}$, $v = \frac{x^3}{3}$, so $v\,du = \frac{x^2}{3}\,dx$, a plain power. Every other choice leaves $\ln x$ inside $v$ or $du$ (for example $u = x^2$ needs $v = x\ln x - x$). Finishing the good choice: $\int x^2\ln x\,dx = \frac{x^3}{3}\ln x - \frac{x^3}{9} + C$.

@practice num
prompt: Evaluate $\int_0^{\pi} x^2\sin x\,dx$. Give an exact answer.
answer: pi^2 - 4
check: quad(lambda x: x**2*sin(x), 0, pi)
hint: Two rounds of parts are needed; the tabular method keeps the signs straight. Start with $u = x^2$ and $dv = \sin x\,dx$.
hint: Pair $x^2, 2x, 2$ with the successive antiderivatives $-\cos x, -\sin x, \cos x$ and use the signs $+, -, +$. Then evaluate at $\pi$ and at $0$.
solution: Tabular: $\int x^2\sin x\,dx = -x^2\cos x + 2x\sin x + 2\cos x + C$. At $\pi$: $\pi^2 + 0 - 2$. At $0$: $0 + 0 + 2$. The integral is $(\pi^2 - 2) - 2 = \pi^2 - 4 \approx 5.870$.

@practice expr
prompt: Find $\int e^{2x}\sin x\,dx$. Omit $+C$.
vars: x
const: yes
lead: $\int e^{2x}\sin x\,dx =$
answer: e^(2x)(2sin(x) - cos(x))/5
check: lambda x: quad(lambda t: exp(2*t)*sin(t), 0, x)
hint: This integral is cyclic. Integrate by parts twice, both times with the trig factor as $u$ and $dv = e^{2x}\,dx$, so $v = \frac12 e^{2x}$.
hint: After two rounds you should reach $I = \frac12 e^{2x}\sin x - \frac14 e^{2x}\cos x - \frac14 I$. Solve this equation for $I$.
solution: First round: $I = \frac12 e^{2x}\sin x - \frac12\int e^{2x}\cos x\,dx$. Second round: $\int e^{2x}\cos x\,dx = \frac12 e^{2x}\cos x + \frac12 I$. So $I = \frac12 e^{2x}\sin x - \frac14 e^{2x}\cos x - \frac14 I$, which gives $\frac54 I = \frac14 e^{2x}(2\sin x - \cos x)$ and $I = \frac15 e^{2x}(2\sin x - \cos x) + C$.

@quiz num
prompt: Evaluate $\int_1^e (\ln x)^2\,dx$. Give an exact answer.
answer: e - 2
check: quad(lambda x: log(x)**2, 1, e)
hint: Treat the integrand as $(\ln x)^2\cdot 1$: let $u = (\ln x)^2$ and $dv = dx$.
hint: You get $x(\ln x)^2 - 2\int\ln x\,dx$, and the remaining integral is the hidden product from the lesson.
solution: $\int(\ln x)^2\,dx = x(\ln x)^2 - 2\int\ln x\,dx = x(\ln x)^2 - 2x\ln x + 2x + C$. At $e$: $e - 2e + 2e = e$. At $1$: $0 - 0 + 2 = 2$. So the integral is $e - 2 \approx 0.718$.

@quiz expr
prompt: Find $\int x\arctan x\,dx$. Omit $+C$.
vars: x
const: yes
lead: $\int x\arctan x\,dx =$
answer: (x^2 + 1) arctan(x)/2 - x/2
check: lambda x: quad(lambda t: t*arctan(t), 0, x)
hint: Inverse trig comes before algebraic in LIATE, so let $u = \arctan x$ and $dv = x\,dx$.
hint: The new integral is $\frac12\int\frac{x^2}{1+x^2}\,dx$. Rewrite $\frac{x^2}{1+x^2} = 1 - \frac{1}{1+x^2}$.
solution: With $u = \arctan x$, $dv = x\,dx$: $du = \frac{dx}{1+x^2}$, $v = \frac{x^2}{2}$. Then $\int x\arctan x\,dx = \frac{x^2}{2}\arctan x - \frac12\int\left(1 - \frac{1}{1+x^2}\right)dx = \frac{x^2}{2}\arctan x - \frac{x}{2} + \frac12\arctan x + C = \frac{(x^2+1)\arctan x - x}{2} + C$.

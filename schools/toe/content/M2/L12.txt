@article
A Taylor polynomial is only useful if you know how wrong it can be. Use $T_3(x)=1+x+\frac{x^2}{2}+\frac{x^3}{6}$ for $e^{0.5}$ and you get $1.6458$, while the true value is $1.6487$. But when you do not know the true value, how can you be sure of the accuracy? An **error bound** gives a guarantee that does not need the answer.

### The remainder

The **remainder** $R_n(x)=f(x)-T_n(x)$ is the error of the degree-$n$ polynomial. **Taylor's theorem (Lagrange form):** if $f$ has $n+1$ continuous derivatives, then for each $x$ there is a number $c$ strictly between $a$ and $x$ such that

$$R_n(x)=\frac{f^{(n+1)}(c)}{(n+1)!}\,(x-a)^{n+1}.$$

It looks like the next term of the series, except that the derivative is evaluated at an unknown point $c$ instead of at $a$.

### The error bound

We cannot find $c$, but we can bound the derivative. If $|f^{(n+1)}(t)|\le M$ for every $t$ between $a$ and $x$, then

$$|R_n(x)|\le\frac{M\,|x-a|^{n+1}}{(n+1)!}.$$

Three ingredients control it: the **order** $n+1$, the **distance** $|x-a|$, and the **bound $M$** on the $(n+1)$st derivative. A short distance or a high order makes the bound tiny, because the factorial eventually beats any power.

### Using the bound

- **Check an approximation.** For $e^{0.5}$ with $n=3$ and $a=0$, every derivative is $e^t\le e^{0.5}<2$ on $[0,0.5]$, so $M=2$ works: $|R_3(0.5)|\le\frac{2\,(0.5)^4}{4!}\approx0.0052$. The actual error is $0.0029$. The bound holds and is a little pessimistic, as bounds usually are.
- **Choose the degree.** To guarantee an error below $\varepsilon$, find the smallest $n$ with $\frac{M|x-a|^{n+1}}{(n+1)!}<\varepsilon$. Simply try $n=1,2,3,\dots$ until the inequality holds.
- **Alternating series.** If the series at $x$ alternates with decreasing terms, the first omitted term bounds the error, which is often sharper.

### Comparing the bound with the truth in Python

```python
import math

def T(n, x):                          # Maclaurin polynomial of e^x
    return sum(x**k / math.factorial(k) for k in range(n + 1))

x = 0.5
for n in range(1, 6):
    err = abs(math.exp(x) - T(n, x))
    bound = 2 * x**(n + 1) / math.factorial(n + 1)
    print(n, err, bound, err <= bound)
```

Every line ends with `True`. The bound is never violated, and it shrinks at the same factorial rate as the true error.

@example
title: Choosing the degree for a target accuracy
problem: How large must $n$ be for $T_n(1)$ to approximate $\sin 1$ within $10^{-5}$ for certain?
step: Take $f(x)=\sin x$, $a=0$, $x=1$. Every derivative of sine is $\pm\sin$ or $\pm\cos$, so $|f^{(n+1)}(t)|\le1$ and we may use $M=1$.
step: The bound is $|R_n(1)|\le\frac{1}{(n+1)!}$. We need it below $10^{-5}$, that is $(n+1)!>100000$.
step: Try factorials: $8!=40320$ is too small and $9!=362880$ is enough. So $n+1=9$ and $n=8$.
step: Sine has no $x^8$ term, so $T_8=T_7$ and $T_7(1)=1-\frac16+\frac{1}{120}-\frac{1}{5040}\approx0.8414683$.
step: Compare: $\sin 1=0.8414710$, so the actual error is $2.7\times10^{-6}$, just below the guaranteed bound $\frac{1}{9!}\approx2.76\times10^{-6}$. Here the bound is almost sharp because the first omitted term dominates.

@example
title: A bound where the derivative bound must be found
problem: Approximate $\ln(1.1)$ by the degree-3 Maclaurin polynomial of $\ln(1+x)$. Bound the error and compare it with the actual error.
step: Differentiate four times: $f'=\frac{1}{1+x}$, $f''=-\frac{1}{(1+x)^2}$, $f'''=\frac{2}{(1+x)^3}$, $f^{(4)}=-\frac{6}{(1+x)^4}$.
step: On $[0,0.1]$, $|f^{(4)}(t)|=\frac{6}{(1+t)^4}$ is decreasing, so its largest value is at $t=0$: $M=6$.
step: The bound is $|R_3(0.1)|\le\frac{6\,(0.1)^4}{4!}=\frac{6\times10^{-4}}{24}=2.5\times10^{-5}$.
step: The polynomial is $T_3(x)=x-\frac{x^2}{2}+\frac{x^3}{3}$, so $T_3(0.1)=0.1-0.005+0.000333=0.095333$.
step: The true value is $\ln1.1=0.095310$, so the actual error is $2.3\times10^{-5}$. It lies inside the guaranteed bound $2.5\times10^{-5}$.

@mistakes
- Using $n$ instead of $n+1$: the bound needs the $(n+1)$st derivative, the power $(x-a)^{n+1}$ and the factorial $(n+1)!$.
- Bounding the derivative only at the center $a$. The number $M$ must bound $|f^{(n+1)}|$ over the whole interval between $a$ and $x$.
- Treating the bound as the error. It is a guaranteed upper limit, and the actual error is usually smaller.
- Evaluating sine and cosine series with angles in degrees. The series require radians.

solution: $f'''(t)=\frac{6}{(1-t)^4}$ is increasing, so $M=\frac{6}{0.9^4}\approx9.145$. The bound is $\frac{M\,(0.1)^3}{3!}=\frac{(0.1)^3}{0.9^4}=\frac{0.001}{0.6561}\approx0.00152$. For comparison, the actual error is $\frac{1}{0.9}-1.11\approx0.00111$, inside the bound.

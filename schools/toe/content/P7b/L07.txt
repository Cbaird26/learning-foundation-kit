@article
Perturbation theory needs a solvable $H_0$ close to the true $H$. The **variational method** needs only a good guess, and it gives something perturbation theory cannot: a rigorous *bound*.

### The variational principle

Let $H$ have a ground-state energy $E_0$, the lowest eigenvalue. For **any** normalized state $|\psi\rangle$ in the domain of $H$,

$$E[\psi] = \langle\psi|H|\psi\rangle \;\ge\; E_0 .$$

*Why:* expand $|\psi\rangle = \sum_n c_n|n\rangle$ in the true eigenstates. Then $\langle H\rangle = \sum_n |c_n|^2E_n \ge E_0\sum_n|c_n|^2 = E_0$, since every $E_n \ge E_0$ and $\sum_n |c_n|^2 = 1$. Equality needs all weight on the ground level.

If $|\psi\rangle$ is not normalized, use the **Rayleigh quotient**

$$E[\psi] = \frac{\langle\psi|H|\psi\rangle}{\langle\psi|\psi\rangle}.$$

### The recipe

1. Choose a trial family $\psi_\alpha(x)$ with one or more parameters $\alpha$ that has the right general shape: boundary behaviour, symmetry, number of nodes (none for the ground state).
2. Compute $E(\alpha) = \langle\psi_\alpha|H|\psi_\alpha\rangle$ for normalized $\psi_\alpha$. The kinetic term can be written $\frac{\hbar^2}{2m}\int|\psi'|^2dx$, which avoids a second derivative.
3. Minimize: $dE/d\alpha = 0$. The minimum $E_{\min}$ is your best bound inside the family.

### What the bound assumes

- **Admissible trial states.** The state must be normalizable, finite-energy and obey the problem's boundary conditions (for a hard wall it must vanish there). A function that does not satisfy these may give an energy below $E_0$, which is meaningless.
- **It is an upper bound only.** It never says how far above $E_0$ you are. The state error is first order but the energy error is *second* order in it, so a decent guess gives a good energy and a much worse wavefunction.
- **It targets the lowest state of the trial's symmetry.** An odd trial function gives an upper bound on the lowest odd state. More generally, a trial state orthogonal to the true ground state bounds $E_1$ from above.
- **Different families, different bounds.** The smallest bound wins, but you cannot compare a bound with a perturbation-theory estimate as if both were rigorous.

### Linear variational (Rayleigh-Ritz) method

Take a trial state $|\psi\rangle = \sum_{i=1}^N c_i|\phi_i\rangle$ from $N$ orthonormal basis functions. Minimizing the Rayleigh quotient over the $c_i$ gives the matrix eigenproblem $\sum_j H_{ij}c_j = Ec_i$ with $H_{ij} = \langle\phi_i|H|\phi_j\rangle$. The lowest eigenvalue of this $N\times N$ matrix bounds $E_0$ from above, and the $k$-th eigenvalue bounds the $k$-th exact level from above. Adding basis functions can only lower the bounds. This is exactly matrix diagonalization in a truncated basis.

@example
title: A delta-function well with a Gaussian guess
problem: A particle in $V(x) = -\beta\,\delta(x)$ (with $\beta > 0$) has exact ground energy $-m\beta^2/2\hbar^2$. Use the normalized trial function $\psi_\alpha(x) = (2\alpha/\pi)^{1/4}e^{-\alpha x^2}$ to find a variational bound, and compare it with the exact value.
step: Kinetic energy: for this Gaussian, $\langle p^2\rangle = \hbar^2\alpha$, so $\langle T\rangle = \frac{\hbar^2\alpha}{2m}$.
step: Potential energy: $\langle V\rangle = -\beta|\psi_\alpha(0)|^2 = -\beta\sqrt{2\alpha/\pi}$.
step: The energy function is $E(\alpha) = \frac{\hbar^2\alpha}{2m} - \beta\sqrt{\frac{2\alpha}{\pi}}$. Set $\frac{dE}{d\alpha} = \frac{\hbar^2}{2m} - \frac{\beta}{\sqrt{2\pi\alpha}} = 0$, so $\sqrt\alpha = \frac{m\beta}{\hbar^2}\sqrt{\frac{2}{\pi}}$ and $\alpha = \frac{2m^2\beta^2}{\pi\hbar^4}$.
step: Substitute: $\langle T\rangle = \frac{m\beta^2}{\pi\hbar^2}$ and $\langle V\rangle = -\frac{2m\beta^2}{\pi\hbar^2}$, so $E_{\min} = -\frac{m\beta^2}{\pi\hbar^2}$.
step: Compare: $-\frac{m\beta^2}{\pi\hbar^2} \approx -0.318\,\frac{m\beta^2}{\hbar^2}$ lies above the exact $-0.5\,\frac{m\beta^2}{\hbar^2}$, as the principle requires. The Gaussian captures about $2/\pi \approx 64\%$ of the binding energy, because the true wavefunction has a cusp, $e^{-m\beta|x|/\hbar^2}$, that no Gaussian can mimic.

@mistakes
- Forgetting to normalize the trial function, or to divide by $\langle\psi|\psi\rangle$ in the Rayleigh quotient.
- Using a trial function that violates the boundary conditions (for instance one that does not vanish at an infinite wall) and then trusting a number below the true $E_0$.
- Claiming that the optimized value is close to $E_0$ because the minimization "converged": the minimization only finds the best value within the chosen family.
- Believing a good energy implies a good wavefunction for other quantities such as $\langle x^4\rangle$.

@practice self
prompt: Prove the variational principle: for any normalized $|\psi\rangle$ and Hamiltonian $H$ with lowest eigenvalue $E_0$, $\langle\psi|H|\psi\rangle \ge E_0$. State when equality holds.
solution: Let $\{|n\rangle\}$ be orthonormal eigenstates, $H|n\rangle = E_n|n\rangle$, with $E_0 \le E_n$ for all $n$. Expand $|\psi\rangle = \sum_n c_n|n\rangle$, with $\sum_n|c_n|^2 = 1$. Then $\langle\psi|H|\psi\rangle = \sum_n|c_n|^2E_n \ge E_0\sum_n|c_n|^2 = E_0$. Equality requires $|c_n|^2(E_n - E_0) = 0$ for every $n$, so $|\psi\rangle$ has weight only on states with energy $E_0$: it is a ground state.
rubric: Expands the trial state in the energy eigenbasis and writes $\langle H\rangle$ as a weighted sum of eigenvalues.
rubric: Uses $E_n \ge E_0$ and normalization $\sum|c_n|^2 = 1$ to obtain the bound.
rubric: States the equality condition: the trial state lies entirely in the ground-state eigenspace.
hint: Insert the completeness relation $\sum_n|n\rangle\langle n| = 1$ on both sides of $H$.

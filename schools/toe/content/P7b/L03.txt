@article
Spin is an intrinsic angular momentum with no classical spatial picture, and it is the simplest quantum system that is not a wavefunction in space. A spin-1/2 particle has a two-dimensional state space, so everything is a $2\times 2$ calculation, and the Dirac-notation tools of the last two weeks are all you need.

### Spin operators

In the basis $\{|\uparrow\rangle, |\downarrow\rangle\}$ of $S_z$ eigenstates, the spin operators are $S_k = \frac{\hbar}{2}\sigma_k$ with the **Pauli matrices**

$$\sigma_x = \begin{pmatrix}0&1\\1&0\end{pmatrix},\quad \sigma_y = \begin{pmatrix}0&-i\\ i&0\end{pmatrix},\quad \sigma_z = \begin{pmatrix}1&0\\0&-1\end{pmatrix}.$$

They are Hermitian, square to the identity, and obey $\sigma_j\sigma_k = \delta_{jk} + i\epsilon_{jkl}\sigma_l$. Hence $[S_j, S_k] = i\hbar\,\epsilon_{jkl}S_l$, and $S^2 = \frac{3}{4}\hbar^2$ in every state. Each component has eigenvalues $\pm\hbar/2$:

$$|\pm x\rangle = \tfrac{1}{\sqrt2}\left(|\uparrow\rangle \pm |\downarrow\rangle\right),\qquad |\pm y\rangle = \tfrac{1}{\sqrt2}\left(|\uparrow\rangle \pm i|\downarrow\rangle\right).$$

Because the components do not commute, a state of definite $S_z$ has no definite $S_x$: a measurement of $S_x$ on $|\uparrow\rangle$ gives $\pm\hbar/2$ with probability $\frac{1}{2}$ each.

### Spin along any direction

For a unit vector $\hat n = (\sin\theta\cos\phi,\ \sin\theta\sin\phi,\ \cos\theta)$, the operator $S_{\hat n} = \hat n\cdot\vec S$ has eigenvalues $\pm\hbar/2$, and the "up" eigenstate is

$$|{+\hat n}\rangle = \cos\tfrac{\theta}{2}\,|\uparrow\rangle + e^{i\phi}\sin\tfrac{\theta}{2}\,|\downarrow\rangle .$$

If the spin is up along $\hat n$ and you measure along $\hat m$ at angle $\gamma$ to $\hat n$, then

$$P(+\hat m) = |\langle{+\hat m}|{+\hat n}\rangle|^2 = \cos^2\tfrac{\gamma}{2} = \tfrac{1}{2}\left(1 + \hat n\cdot\hat m\right).$$

The half-angle is the signature of spin-1/2: perpendicular axes give $\frac{1}{2}$, opposite axes give $0$. In any state, $\langle\vec S\rangle = \frac{\hbar}{2}\vec r$ for a unit vector $\vec r$ (the *Bloch vector*), so $P(+\hat m) = \frac{1}{2}(1 + \vec r\cdot\hat m)$.

### Rotations

Rotating a state by angle $\alpha$ about $\hat n$ (counterclockwise, right-hand rule) is done by the unitary operator

$$R_{\hat n}(\alpha) = e^{-i\alpha\,\hat n\cdot\vec S/\hbar} = \cos\tfrac{\alpha}{2} - i\sin\tfrac{\alpha}{2}\;\hat n\cdot\vec\sigma ,$$

where the second form uses $(\hat n\cdot\vec\sigma)^2 = 1$. It rotates $\langle\vec S\rangle$ like an ordinary vector. But a rotation by $\alpha = 2\pi$ gives $R = -1$: the state vector changes sign, though every probability is unchanged.

### Precession

A spin in a magnetic field along $z$ has $H = \omega S_z$ for some frequency $\omega$ (set by the field and the gyromagnetic ratio). Then $|\psi(t)\rangle = e^{-iHt/\hbar}|\psi(0)\rangle = R_z(\omega t)|\psi(0)\rangle$: the spin precesses about $z$ at angular frequency $\omega$, and $\langle S_z\rangle$ stays constant.

@example
title: Spin probabilities for a given state
problem: A spin-1/2 particle is in $|\psi\rangle = \frac{1}{\sqrt5}\left(|\uparrow\rangle + 2i|\downarrow\rangle\right)$. Find the probabilities of $S_z = \pm\hbar/2$, the probability of $S_y = +\hbar/2$, and $\langle S_y\rangle$.
step: The state is normalized: $\frac{1 + |2i|^2}{5} = 1$. The $S_z$ probabilities are $P(\uparrow) = \frac{1}{5}$ and $P(\downarrow) = \frac{4}{5}$.
step: The $S_y = +\hbar/2$ eigenstate is $|{+y}\rangle = \frac{1}{\sqrt2}(1, i)^T$, so the bra is $\langle{+y}| = \frac{1}{\sqrt2}(1, -i)$.
step: The amplitude is $\langle{+y}|\psi\rangle = \frac{1}{\sqrt{10}}\left(1\cdot 1 + (-i)(2i)\right) = \frac{3}{\sqrt{10}}$.
step: Therefore $P(S_y = +\hbar/2) = \frac{9}{10}$, and $P(S_y = -\hbar/2) = \frac{1}{10}$.
step: The expectation value is $\langle S_y\rangle = \frac{\hbar}{2}\left(\frac{9}{10} - \frac{1}{10}\right) = \frac{2\hbar}{5}$. A direct computation of $\langle\psi|S_y|\psi\rangle$ gives the same value.

@mistakes
- Using $\cos^2\gamma$ instead of $\cos^2(\gamma/2)$ for the probability between two axes: spin-1/2 has half-angles.
- Forgetting to conjugate the entries of the bra, especially for $|{\pm y}\rangle$, which have complex components.
- Quoting spin expectation values as $\pm 1$ instead of $\pm\hbar/2$, or confusing $\sigma_k$ with $S_k = \frac{\hbar}{2}\sigma_k$.
- Concluding that a $2\pi$ rotation does nothing to the state vector; it multiplies it by $-1$.

@practice num
prompt: A spin-1/2 particle is in the state $|\psi\rangle = \frac{\sqrt3}{2}|\uparrow\rangle + \frac{1}{2}|\downarrow\rangle$. Find $\langle S_z\rangle$ in units of $\hbar$. Give an exact fraction.
answer: 1/4
check: np.vdot([sqrt(3)/2, 1/2], np.array([[1, 0], [0, -1]]) @ np.array([sqrt(3)/2, 1/2])).real/2
hint: $\langle S_z\rangle = \frac{\hbar}{2}\left(P_\uparrow - P_\downarrow\right)$.
solution: $P_\uparrow = \frac{3}{4}$ and $P_\downarrow = \frac{1}{4}$, so $\langle S_z\rangle = \frac{\hbar}{2}\cdot\frac{1}{2} = \frac{\hbar}{4}$.

@practice num
prompt: A spin-1/2 particle is in the state $\cos\frac{\pi}{8}|\uparrow\rangle + \sin\frac{\pi}{8}|\downarrow\rangle$. What is the probability that a measurement of $S_x$ gives $+\hbar/2$? Give an exact value.
answer: (2+sqrt(2))/4
check: abs(np.vdot(np.array([1, 1])/np.sqrt(2), np.array([cos(pi/8), sin(pi/8)])))**2
hint: The $S_x = +\hbar/2$ eigenstate is $\frac{1}{\sqrt2}(|\uparrow\rangle + |\downarrow\rangle)$.
hint: The probability is $\frac{1}{2}\left(\cos\frac{\pi}{8} + \sin\frac{\pi}{8}\right)^2$. Use $2\sin a\cos a = \sin 2a$.
solution: $P = \frac{1}{2}\left(1 + \sin\frac{\pi}{4}\right) = \frac{1}{2}\left(1 + \frac{\sqrt2}{2}\right) = \frac{2 + \sqrt2}{4} \approx 0.854$.

@practice num
prompt: A spin-1/2 particle with $H = \omega S_z$ starts in $|{+x}\rangle$. At the time $t$ when $\omega t = \pi/3$, what is the probability of measuring $S_x = +\hbar/2$? Give an exact fraction.
answer: 3/4
check: abs(np.vdot(np.array([1, 1])/np.sqrt(2), np.exp(-1j*np.array([1, -1])*(pi/3)/2)*np.array([1, 1])/np.sqrt(2)))**2
hint: $e^{-iHt/\hbar}$ multiplies $|\uparrow\rangle$ by $e^{-i\omega t/2}$ and $|\downarrow\rangle$ by $e^{+i\omega t/2}$.

prompt: For a direction $\hat n = (\sin\theta, 0, \cos\theta)$ in the $x$-$z$ plane, show that $\cos\frac{\theta}{2}|\uparrow\rangle + \sin\frac{\theta}{2}|\downarrow\rangle$ is an eigenstate of $\hat n\cdot\vec\sigma$ with eigenvalue $+1$.
solution: In the $\{|\uparrow\rangle, |\downarrow\rangle\}$ basis, $\hat n\cdot\vec\sigma = \begin{pmatrix}\cos\theta & \sin\theta\\ \sin\theta & -\cos\theta\end{pmatrix}$. The vector is unchanged, so the eigenvalue is $+1$.

@quiz expr
prompt: A spin-1/2 particle is in the state $\cos\frac{\theta}{2}|\uparrow\rangle + e^{i\phi}\sin\frac{\theta}{2}|\downarrow\rangle$. Find $\langle S_x\rangle$ in units of $\hbar$ as a function of $\theta$ and $\phi$.
vars: theta, phi
lead: $\langle S_x\rangle/\hbar =$
answer: sin(theta)cos(phi)/2
check: lambda theta, phi: (lambda c: np.vdot(c, np.array([[0, 1], [1, 0]]) @ c).real/2)(np.array([cos(theta/2), np.exp(1j*phi)*sin(theta/2)]))
hint: $\langle S_x\rangle = \frac{\hbar}{2}\langle\sigma_x\rangle = \frac{\hbar}{2}\cdot 2\,\text{Re}(c_\uparrow^* c_\downarrow)$.
hint: $c_\uparrow^* c_\downarrow = \cos\frac\theta2\sin\frac\theta2\,e^{i\phi}$, and $2\sin\frac\theta2\cos\frac\theta2 = \sin\theta$.
solution: $\langle\sigma_x\rangle = 2\,\text{Re}(c_\uparrow^* c_\downarrow) = 2\cos\frac\theta2\sin\frac\theta2\cos\phi = \sin\theta\cos\phi$, so $\langle S_x\rangle = \frac{\hbar}{2}\sin\theta\cos\phi$, which is the $x$ component of $\frac{\hbar}{2}\hat n$.

@article
An ordinary function turns a number into a number. A **functional** turns a whole function into a number. The length of a curve is the standard example: give it the graph $y(x)$ from $x_1$ to $x_2$ and it returns

$$L[y]=\int_{x_1}^{x_2}\sqrt{1+y'^2}\,dx.$$

Mechanics asks the same kind of question ("which path makes a certain integral stationary?"), so we first learn the mathematics.

### The problem

Let $F(y,y',x)$ be given and define

$$J[y]=\int_{x_1}^{x_2}F\big(y(x),y'(x),x\big)\,dx,\qquad y(x_1)=y_1,\quad y(x_2)=y_2.$$

Which $y$ makes $J$ stationary? Compare $y$ with a nearby path $y+\epsilon\eta$, where $\eta(x)$ is smooth and $\eta(x_1)=\eta(x_2)=0$ so that the endpoints stay fixed. The path $y$ is **stationary** if

$$\frac{dJ}{d\epsilon}\Big|_{\epsilon=0}=0\quad\text{for every such }\eta.$$

A stationary path may be a minimum, a maximum or a saddle, so say "stationary" unless you have checked more.

### Deriving the equation

Differentiating under the integral with the chain rule,

$$\frac{dJ}{d\epsilon}\Big|_{0}=\int_{x_1}^{x_2}\left(\frac{\partial F}{\partial y}\,\eta+\frac{\partial F}{\partial y'}\,\eta'\right)dx.$$

Integrate the second term by parts. The boundary term $\left[\frac{\partial F}{\partial y'}\,\eta\right]_{x_1}^{x_2}$ vanishes because $\eta$ is zero at both ends, which leaves

$$\frac{dJ}{d\epsilon}\Big|_{0}=\int_{x_1}^{x_2}\left(\frac{\partial F}{\partial y}-\frac{d}{dx}\frac{\partial F}{\partial y'}\right)\eta\,dx=0.$$

This holds for every admissible $\eta$, so the bracket must vanish (the fundamental lemma of the calculus of variations). The result is the **Euler–Lagrange equation**:

$$\frac{\partial F}{\partial y}-\frac{d}{dx}\frac{\partial F}{\partial y'}=0.$$

The symbol $\frac{d}{dx}$ is a **total** derivative: it acts on the explicit $x$ in $F$ and also through $y(x)$ and $y'(x)$.

### A first integral

If $F$ has no explicit dependence on $x$, then along a stationary path

$$F-y'\,\frac{\partial F}{\partial y'}=\text{constant}.$$

You will prove this in the practice set. It reduces a second-order equation to a first-order one. Next week, with $x\to t$, $y\to q$ and $F\to L$, this machinery becomes the equation of motion, and this first integral becomes conservation of energy.

@example
title: The shortest path between two points
problem: Use the Euler–Lagrange equation to find the curve $y(x)$ of stationary length between two fixed points in the plane.
step: The integrand is $F=\sqrt{1+y'^2}$. It does not contain $y$, so $\partial F/\partial y=0$.
step: Differentiate with respect to $y'$: $\dfrac{\partial F}{\partial y'}=\dfrac{y'}{\sqrt{1+y'^2}}$.
step: The Euler–Lagrange equation becomes $\dfrac{d}{dx}\left(\dfrac{y'}{\sqrt{1+y'^2}}\right)=0$, so $\dfrac{y'}{\sqrt{1+y'^2}}=c$ for a constant $c$.
step: Square and solve: $y'^2=c^2(1+y'^2)$ gives $y'^2=\dfrac{c^2}{1-c^2}$, a constant. So $y'$ is constant.
step: Therefore $y=ax+b$, a straight line, with $a$ and $b$ fixed by the two endpoints.

@example
title: A stationary function with fixed ends
problem: Find the function that makes $J[y]=\int_0^1\left(y'^2+y^2\right)dx$ stationary with $y(0)=0$ and $y(1)=1$, and find the stationary value of $J$.
step: Here $F=y'^2+y^2$, so $\partial F/\partial y=2y$ and $\partial F/\partial y'=2y'$.
step: The Euler–Lagrange equation is $2y-\dfrac{d}{dx}(2y')=0$, that is, $y''=y$.
step: The general solution is $y=Ae^{x}+Be^{-x}$.
step: Impose the ends. $y(0)=A+B=0$ gives $B=-A$. Then $y(1)=A(e-e^{-1})=2A\sinh 1=1$, so $A=\dfrac{1}{2\sinh 1}$.
step: The stationary function is $y(x)=\dfrac{\sinh x}{\sinh 1}$. Then $y'^2+y^2=\dfrac{\cosh 2x}{\sinh^2 1}$ and $J=\dfrac{\sinh 1\cosh 1}{\sinh^2 1}=\coth 1\approx 1.313$.

@mistakes
- Treating $x$, $y$ and $y'$ as constants when taking $\frac{d}{dx}$ of $\partial F/\partial y'$; the total derivative must act on all of them.
- Using the fixed-endpoint derivation when an endpoint is free; then the boundary term does not vanish and gives extra conditions.
- Assuming that "stationary" means "minimum".

@practice self
prompt: Suppose $F(y,y')$ has no explicit dependence on $x$. Show that if $y(x)$ satisfies the Euler–Lagrange equation, then $F-y'\,\partial F/\partial y'$ is constant.
hint: Differentiate $F-y'\,\partial F/\partial y'$ with respect to $x$ and use the chain rule on $F$; there is no explicit $x$ term.
hint: After the product rule, the $y''\,\partial F/\partial y'$ terms cancel, and what is left contains the Euler–Lagrange expression as a factor.
solution: Because $F$ has no explicit $x$, $\dfrac{dF}{dx}=\dfrac{\partial F}{\partial y}y'+\dfrac{\partial F}{\partial y'}y''$. Then
$$\frac{d}{dx}\left(F-y'\frac{\partial F}{\partial y'}\right)=\frac{\partial F}{\partial y}y'+\frac{\partial F}{\partial y'}y''-y''\frac{\partial F}{\partial y'}-y'\frac{d}{dx}\frac{\partial F}{\partial y'}=y'\left(\frac{\partial F}{\partial y}-\frac{d}{dx}\frac{\partial F}{\partial y'}\right).$$
The bracket is zero on solutions of the Euler–Lagrange equation, so the derivative is zero and the quantity is constant.
rubric: Writes the total derivative $dF/dx$ using the chain rule with no explicit $x$ term.
rubric: Differentiates $y'\,\partial F/\partial y'$ with the product rule, so the $y''\,\partial F/\partial y'$ terms cancel.
rubric: Factors the remainder as $y'$ times the Euler–Lagrange expression.
rubric: Concludes that the derivative vanishes on solutions, so the quantity is constant.

@quiz num
prompt: Let $J[y]=\int_0^1\left(y'^2+y^2\right)dx$, $y_0(x)=x$ and $\eta(x)=x(1-x)$. Compute $\dfrac{dJ}{d\epsilon}\Big|_{\epsilon=0}$ where $J$ is evaluated on $y_0+\epsilon\eta$. Give an exact value.
answer: 1/6
tol: 0.001
check: nderiv(lambda eps: quad(lambda x: (1 + eps*(1 - 2*x))**2 + (x + eps*x*(1 - x))**2, 0, 1), 0)
hint: Differentiate under the integral: the derivative is $\int(2y_0'\eta'+2y_0\eta)\,dx$.
hint: Here $y_0'=1$ and $\eta'=1-2x$. Collect the integrand into a polynomial in $x$.
solution: $\dfrac{dJ}{d\epsilon}\Big|_0=\int_0^1\left[2(1-2x)+2x\cdot x(1-x)\right]dx=2\left(1-1+\tfrac13-\tfrac14\right)=\dfrac16$. It is nonzero, so $y_0=x$ is not stationary.

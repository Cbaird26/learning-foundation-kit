@article
Some coordinates make a problem easy: if a coordinate is cyclic, its momentum is conserved. Because Hamiltonian mechanics treats $q$ and $p$ almost symmetrically, we may look for new phase-space variables $(Q,P)$, mixing the old ones, in which $H$ is as simple as possible.

### Canonical transformations

A transformation $(q,p)\to(Q,P)$ is **canonical** if Hamilton's equations keep their form,

$$\dot Q_i=\frac{\partial K}{\partial P_i},\qquad\dot P_i=-\frac{\partial K}{\partial Q_i},$$

for some new Hamiltonian $K(Q,P,t)$. An ordinary change of coordinates $Q(q)$ is a special case, but now $P$ may depend on $q$ and $Q$ may depend on $p$.

### The bracket test

A transformation is canonical exactly when the new variables obey the fundamental brackets, evaluated with respect to the old variables:

$$\{Q_i,Q_j\}=0,\qquad\{P_i,P_j\}=0,\qquad\{Q_i,P_j\}=\delta_{ij}.$$

For one degree of freedom this is the single condition

$$\{Q,P\}=\frac{\partial Q}{\partial q}\frac{\partial P}{\partial p}-\frac{\partial Q}{\partial p}\frac{\partial P}{\partial q}=1,$$

which is the Jacobian determinant of the map $(q,p)\mapsto(Q,P)$. Canonical maps therefore preserve phase-space area and orientation. A consequence is that $\{f,g\}$ has the same value whether computed in $(q,p)$ or in $(Q,P)$. Time evolution is itself a canonical transformation, which is the reason phase-space volume is conserved (Liouville's theorem).

### Generating functions

A single function generates a canonical transformation automatically. Two common types are

$$F_1(q,Q,t):\quad p_i=\frac{\partial F_1}{\partial q_i},\quad P_i=-\frac{\partial F_1}{\partial Q_i};\qquad F_2(q,P,t):\quad p_i=\frac{\partial F_2}{\partial q_i},\quad Q_i=\frac{\partial F_2}{\partial P_i}.$$

In both cases the new Hamiltonian is $K=H+\partial F/\partial t$. The function $F_2=\sum_iq_iP_i$ gives the identity ($Q=q$, $P=p$), while $F_1=qQ$ exchanges the roles of coordinate and momentum: $Q=p$, $P=-q$. The minus sign is essential.

### Choosing good variables

The aim is to make coordinates cyclic. For the harmonic oscillator $H=\dfrac{p^{2}}{2m}+\tfrac12m\omega^{2}q^{2}$, the transformation

$$q=\sqrt{\frac{2P}{m\omega}}\,\sin Q,\qquad p=\sqrt{2m\omega P}\,\cos Q$$

is canonical and gives $K=\omega P$. Now $Q$ is cyclic, so $P=E/\omega$ is constant and $Q=\omega t+Q_0$. These are the **action** $P$ and **angle** $Q$ variables.

@example
title: Testing candidate transformations
problem: Decide which of these one-dimensional transformations are canonical: (a) $Q=q^{2}$, $P=p/(2q)$; (b) $Q=p$, $P=q$; (c) $Q=p$, $P=-q$.
step: The test is $\{Q,P\}=\partial_qQ\,\partial_pP-\partial_pQ\,\partial_qP=1$, with all derivatives taken with respect to the old variables $(q,p)$.
step: (a) $\partial_qQ=2q$, $\partial_pQ=0$ and $\partial_pP=\dfrac1{2q}$. So $\{Q,P\}=2q\cdot\dfrac1{2q}=1$, and the transformation is canonical.
step: (b) $\partial_qQ=0$, $\partial_pQ=1$, $\partial_qP=1$ and $\partial_pP=0$. So $\{Q,P\}=0-(1)(1)=-1$. This is not canonical: it reverses the orientation of phase space.
step: (c) Now $\partial_qP=-1$, so $\{Q,P\}=0-(1)(-1)=+1$. This is canonical. Exchanging coordinate and momentum is allowed, provided the sign is placed correctly.

@example
title: Action and angle for the oscillator
problem: Show that $q=\sqrt{2P/(m\omega)}\sin Q$, $p=\sqrt{2m\omega P}\cos Q$ is canonical, find the new Hamiltonian, and solve the motion.
step: Differentiate: $\partial_Qq=\sqrt{\dfrac{2P}{m\omega}}\cos Q$, $\partial_Pq=\dfrac{\sin Q}{\sqrt{2m\omega P}}$, $\partial_Qp=-\sqrt{2m\omega P}\sin Q$ and $\partial_Pp=\sqrt{\dfrac{m\omega}{2P}}\cos Q$.
step: Take the bracket with respect to $(Q,P)$: $\{q,p\}=\partial_Qq\,\partial_Pp-\partial_Pq\,\partial_Qp=\cos^{2}Q+\sin^{2}Q=1$. The map has unit Jacobian, so it is canonical.
step: Substitute into the Hamiltonian: $K=\dfrac{2m\omega P\cos^{2}Q}{2m}+\tfrac12m\omega^{2}\dfrac{2P}{m\omega}\sin^{2}Q=\omega P$.
step: Hamilton's equations give $\dot Q=\partial K/\partial P=\omega$ and $\dot P=-\partial K/\partial Q=0$. Hence $Q=\omega t+Q_0$ and $P$ is constant.
step: Return to the original variables. Since $K=E$, $P=E/\omega$ and $q=\sqrt{\dfrac{2E}{m\omega^{2}}}\,\sin(\omega t+Q_0)$. The amplitude agrees with $\tfrac12m\omega^{2}A^{2}=E$.

@mistakes
- Taking the derivatives with respect to the wrong set of variables. Evaluate $\{Q,P\}$ with the old variables $(q,p)$, with $Q$ and $P$ written as functions of them.
- Dropping the minus sign when exchanging coordinate and momentum. $Q=p$, $P=q$ is not canonical; $Q=p$, $P=-q$ is.
- Assuming that $Q=Q(q)$ forces $P=p$. The momentum must change too: $P=p/Q'(q)$.
- Forgetting the term $\partial F/\partial t$ in $K=H+\partial F/\partial t$ when the generating function depends explicitly on time.

@quiz num
prompt: A transformation of two degrees of freedom is $Q_1=q_1+q_2$, $Q_2=q_1-q_2$, $P_1=a\,(p_1+p_2)$ and $P_2=a\,(p_1-p_2)$, where $a$ is a constant. Find the value of $a$ for which it is canonical.
answer: 1/2
check: root(lambda a: nderiv(lambda s: s + 0.8, 0.3)*nderiv(lambda s: a*(s + 0.2), 0.5) + nderiv(lambda s: 0.3 + s, 0.8)*nderiv(lambda s: a*(0.5 + s), 0.2) - 1, 0.01, 10)
hint: Impose $\{Q_1,P_1\}=1$. Only the terms $\partial_{q_i}Q_1\,\partial_{p_i}P_1$ are nonzero.
hint: $\{Q_1,P_1\}=a+a$.
solution: $\{Q_1,P_1\}=\sum_i\partial_{q_i}Q_1\,\partial_{p_i}P_1=(1)(a)+(1)(a)=2a=1$, so $a=\tfrac12$. The other relations then hold: $\{Q_1,P_2\}=a-a=0$, $\{Q_2,P_1\}=a-a=0$ and $\{Q_2,P_2\}=a+a=1$. The $Q$–$Q$ and $P$–$P$ brackets vanish because the $Q$'s depend only on coordinates and the $P$'s only on momenta.

@quiz ms
prompt: Which statements about canonical transformations are true? Select all that apply.
choice*: For any functions $f$ and $g$, the value of $\{f,g\}$ is the same whether it is computed with $(q,p)$ or with $(Q,P)$.
choice*: In one degree of freedom, $\{Q,P\}$ equals the Jacobian determinant $\partial(Q,P)/\partial(q,p)$, so a canonical transformation preserves phase-space area.
choice: If $Q$ depends only on $q$, then $P=p$ completes a canonical transformation.
choice: Setting $Q=p$ and $P=q$ is canonical, because Hamilton's equations treat $q$ and $p$ symmetrically.
hint: Test the claim that $Q$ depending only on $q$ allows $P=p$, and the claim that $Q=p$, $P=q$ is canonical, with the bracket $\{Q,P\}$, using $Q=q^{2}$ and then $Q=p$, $P=q$.
hint: The bracket in $(q,p)$ and in $(Q,P)$ agree for canonical maps; that is the content of the statement about computing $\{f,g\}$ with either set of variables.
solution: The statement that $\{f,g\}$ is the same in either set of variables and the statement that $\{Q,P\}$ is the Jacobian determinant (so area is preserved) are correct. For the claim that $Q$ depending only on $q$ allows $P=p$, take $Q=q^{2}$, $P=p$: this gives $\{Q,P\}=2q\neq1$; the momentum must change to $P=p/(2q)$. For the claim that $Q=p$, $P=q$ is canonical, $\{Q,P\}=-1$. The asymmetry of Hamilton's equations (the minus sign in $\dot p=-\partial H/\partial q$) means the exchange needs $P=-q$.

@article
Classically, $\mathbf{L} = \mathbf{r}\times\mathbf{p}$. Quantum mechanically each component becomes an operator, for example $\hat L_z = \hat x\hat p_y - \hat y\hat p_x = -i\hbar\,\partial/\partial\phi$ in spherical coordinates. The components do not commute:

$$[\hat L_x,\hat L_y] = i\hbar\hat L_z \quad\text{and its cyclic permutations}, \qquad [\hat L^2,\hat L_i] = 0,$$

where $\hat L^2 = \hat L_x^2 + \hat L_y^2 + \hat L_z^2$. So a state can have sharp values of $L^2$ and **one** component (we choose $L_z$), but then $L_x$ and $L_y$ are necessarily uncertain: $\sigma_{L_x}\sigma_{L_y} \ge \tfrac{\hbar}{2}|\langle L_z\rangle|$.

### Allowed values

The common eigenstates $|l,m\rangle$, written as wavefunctions $Y_l^m(\theta,\phi)$ (**spherical harmonics**), satisfy

$$\hat L^2 Y_l^m = \hbar^2\,l(l+1)\,Y_l^m, \qquad \hat L_z Y_l^m = m\hbar\,Y_l^m,$$

with $l = 0, 1, 2, \dots$ and $m = -l, -l+1, \dots, l$. There are $2l+1$ values of $m$ for each $l$. The factor $e^{im\phi}$ in $Y_l^m$ must return to itself after $\phi \to \phi + 2\pi$, which is why $m$ is an integer. For example:

$$Y_0^0 = \frac{1}{\sqrt{4\pi}}, \qquad Y_1^0 = \sqrt{\frac{3}{4\pi}}\cos\theta, \qquad Y_1^{\pm1} = \mp\sqrt{\frac{3}{8\pi}}\sin\theta\,e^{\pm i\phi}.$$

They are normalized over the sphere: $\int|Y_l^m|^2\sin\theta\,d\theta\,d\phi = 1$. The magnitude is $|\mathbf L| = \hbar\sqrt{l(l+1)}$, which exceeds the largest projection $l\hbar$. So $\mathbf L$ can never point exactly along $z$; the angle with the $z$ axis satisfies $\cos\theta = m/\sqrt{l(l+1)}$. Spectroscopic letters: $l = 0, 1, 2, 3$ are called s, p, d, f.

### Ladder operators for $m$

Define $\hat L_\pm = \hat L_x \pm i\hat L_y$. Then $[\hat L_z,\hat L_\pm] = \pm\hbar\hat L_\pm$, so $\hat L_\pm$ changes $m$ by $\pm1$:

$$\hat L_\pm|l,m\rangle = \hbar\sqrt{l(l+1) - m(m\pm1)}\;|l,m\pm1\rangle.$$

Since $\hat L_x = \tfrac12(\hat L_+ + \hat L_-)$, one finds in $|l,m\rangle$ that $\langle L_x\rangle = \langle L_y\rangle = 0$ and

$$\langle L_x^2\rangle = \langle L_y^2\rangle = \tfrac12\hbar^2\bigl[l(l+1) - m^2\bigr].$$

### Spin and rotors

A beam of silver atoms (zero orbital angular momentum) sent through a non-uniform magnetic field splits into **two** beams in the Stern-Gerlach experiment. An orbital $l$ would give an odd number $2l+1$, so the extra degree of freedom is intrinsic **spin**, with $s = \tfrac12$, $S_z = \pm\hbar/2$ and $S^2 = \tfrac34\hbar^2$. Spin obeys the same commutation relations, but half-integer values are allowed for spin and not for orbital $l$. A rigid rotor with moment of inertia $I$ has energies $E_l = \hbar^2 l(l+1)/(2I)$, each $(2l+1)$-fold degenerate.

@example
title: States and angles for $l = 2$
problem: For $l = 2$ list the possible values of $L_z$, find $|\mathbf L|$, and find the smallest angle between $\mathbf L$ and the $z$ axis.
step: The allowed $m$ values are $-2,-1,0,1,2$, so $L_z \in \{-2\hbar,-\hbar,0,\hbar,2\hbar\}$. That is $2l+1 = 5$ states.
step: The magnitude is $|\mathbf L| = \hbar\sqrt{l(l+1)} = \hbar\sqrt6 \approx 2.45\,\hbar$.
step: The smallest angle belongs to $m = l = 2$: $\cos\theta = \dfrac{2}{\sqrt6} = 0.816$, so $\theta \approx 35.3^\circ$.
step: Even at the maximum projection $2\hbar$, $|\mathbf L|$ is larger, so $\mathbf L$ cannot lie along $z$. The leftover $L_x^2 + L_y^2 = (6 - 4)\hbar^2$ is uncertain in direction.

@example
title: Uncertainty in $L_x$ for $|1,0\rangle$
problem: In the state $|l=1, m=0\rangle$, compute $\langle L_x^2\rangle$ using the ladder operators and check it against the general formula.
step: From $\hat L_\pm|l,m\rangle = \hbar\sqrt{l(l+1)-m(m\pm1)}\,|l,m\pm1\rangle$ with $l=1$, $m=0$: $\hat L_+|1,0\rangle = \sqrt2\,\hbar|1,1\rangle$ and $\hat L_-|1,0\rangle = \sqrt2\,\hbar|1,-1\rangle$.
step: Since $\hat L_x = \tfrac12(\hat L_+ + \hat L_-)$, $\hat L_x|1,0\rangle = \dfrac{\hbar}{\sqrt2}\bigl(|1,1\rangle + |1,-1\rangle\bigr)$.
step: Because $\hat L_x$ is Hermitian, $\langle L_x^2\rangle = \|\hat L_x|1,0\rangle\|^2 = \dfrac{\hbar^2}{2}(1 + 1) = \hbar^2$.
step: Check: $\frac12\hbar^2[l(l+1) - m^2] = \frac12\hbar^2(2 - 0) = \hbar^2$. Also $\langle L_x^2\rangle + \langle L_y^2\rangle + \langle L_z^2\rangle = \hbar^2 + \hbar^2 + 0 = 2\hbar^2 = \hbar^2 l(l+1)$.

@mistakes
- Writing $|\mathbf L| = l\hbar$ instead of $\hbar\sqrt{l(l+1)}$, or claiming $\mathbf L$ can point along $z$.
- Counting $2l$ states, or allowing $|m| > l$.
- Assuming $L_x$, $L_y$ and $L_z$ can all be sharp at once.
- Treating spin-$\tfrac12$ as orbital angular momentum with $l = \tfrac12$. Orbital $l$ is an integer, and spin is a separate degree of freedom.

@article
The **wavefunction** $\psi(x,t)$ is a complex-valued function that holds everything quantum mechanics can say about a particle moving along a line. Its meaning is statistical (the **Born rule**): the quantity

$$\rho(x,t) = |\psi(x,t)|^2 = \psi^{*}\psi$$

is the **probability density**, and the probability of finding the particle between $a$ and $b$ is $\int_a^b |\psi|^2\,dx$. Probability per unit length means $\psi$ has units of $\text{length}^{-1/2}$ in one dimension.

A concrete picture helps. Prepare a million electrons in exactly the same way and detect the position of each one once. A histogram of the results, with bins of width $\Delta x$, approaches the curve $|\psi(x)|^2\,\Delta x$. The wavefunction itself is never observed directly; only the probabilities built from it are.

### Normalization

The particle must be found somewhere:

$$\int_{-\infty}^{\infty} |\psi(x,t)|^2\,dx = 1.$$

Given an unnormalized $\psi$, compute $N = \int|\psi|^2\,dx$ and divide $\psi$ by $\sqrt{N}$. For example, $\psi = Ax$ on $0\le x\le 1$ (zero elsewhere) gives $|A|^2/3 = 1$, so $A = \sqrt{3}$.

If the integral diverges, $\psi$ cannot describe one particle. A plane wave $e^{ikx}$ has constant $|\psi|^2$ and is only an idealization; it has momentum $p = \hbar k$, matching $p = h/\lambda$ with $k = 2\pi/\lambda$. An acceptable wavefunction is normalizable, single-valued and continuous.

### Expectation values

An expectation value is the long-run average of many such position readings, so it can land where $|\psi|^2$ is tiny, for example between the two humps of a double-peaked density. Averages over many identically prepared particles use $|\psi|^2$ as the weight:

$$\langle x\rangle = \int x\,|\psi|^2\,dx, \qquad \langle f(x)\rangle = \int f(x)\,|\psi|^2\,dx.$$

Momentum is represented by the operator $\hat p = -i\hbar\,\dfrac{d}{dx}$, and

$$\langle p\rangle = \int \psi^{*}\left(-i\hbar\,\frac{d\psi}{dx}\right)dx.$$

The order matters: differentiate $\psi$ first, then multiply by $\psi^{*}$. The **spread** (standard deviation) is

$$\sigma_x = \sqrt{\langle x^2\rangle - \langle x\rangle^2}.$$

If $\psi = f(x)\,e^{ikx}$ with $f$ real, then $\langle p\rangle = \hbar k$: the real part of the integrand is $\hbar k f^2$, and the remaining term $-i\hbar f f'$ integrates to zero.

### Checking numerically

A numerical integral is a quick check on algebra:

```python
import numpy as np
from scipy.integrate import quad

psi = lambda x: 2*x*np.exp(-x)               # trial wavefunction for x >= 0
norm, _ = quad(lambda x: abs(psi(x))**2, 0, np.inf)
print(norm)                                    # 1.0 up to rounding
```

@example
title: A polynomial wavefunction in a box
problem: A particle has $\psi(x) = A\,x(L-x)$ for $0\le x\le L$ and $\psi = 0$ elsewhere. Find $A$, $\langle x\rangle$ and $\sigma_x$.
step: Normalization: $|A|^2\int_0^L x^2(L-x)^2\,dx = 1$. Expand the integrand as $L^2x^2 - 2Lx^3 + x^4$.
step: Integrate: $\int_0^L x^2(L-x)^2\,dx = L^5\left(\tfrac13 - \tfrac12 + \tfrac15\right) = \dfrac{L^5}{30}$, so $A = \sqrt{30/L^5}$.
step: $|\psi|^2$ is symmetric about $x = L/2$, so $\langle x\rangle = L/2$ with no integral needed.
step: $\langle x^2\rangle = \dfrac{30}{L^5}\int_0^L x^4(L-x)^2\,dx = \dfrac{30}{L^5}\cdot L^7\left(\tfrac15 - \tfrac13 + \tfrac17\right) = \dfrac{30}{L^5}\cdot\dfrac{L^7}{105} = \dfrac{2L^2}{7}$.
step: $\sigma_x^2 = \dfrac{2L^2}{7} - \dfrac{L^2}{4} = \dfrac{L^2}{28}$, so $\sigma_x = L/\sqrt{28} \approx 0.19\,L$.

@example
title: A Gaussian wavefunction
problem: Normalize $\psi(x) = A\,e^{-x^2/(2b^2)}$ on the whole line, using $\int_{-\infty}^{\infty}e^{-u^2}\,du = \sqrt{\pi}$, and find the probability of finding the particle with $|x| < b$.
step: $|\psi|^2 = |A|^2 e^{-x^2/b^2}$. Substitute $u = x/b$: $\int|\psi|^2\,dx = |A|^2\,b\sqrt{\pi}$.
step: Setting this equal to $1$ gives $A = (\pi b^2)^{-1/4}$.
step: $P(|x|<b) = \dfrac{1}{b\sqrt{\pi}}\int_{-b}^{b}e^{-x^2/b^2}\,dx = \dfrac{1}{\sqrt{\pi}}\int_{-1}^{1}e^{-u^2}\,du = \operatorname{erf}(1)$.
step: Numerically $\operatorname{erf}(1) \approx 0.843$, so about 84% of the probability lies within $|x| < b$.

@mistakes
- Normalizing with $\int\psi\,dx$ instead of $\int|\psi|^2\,dx$.
- Using $\psi^2$ for a complex $\psi$; the density is $\psi^{*}\psi = |\psi|^2$.
- In $\langle p\rangle$, putting $\psi^{*}$ on the wrong side or differentiating the product $\psi^{*}\psi$ instead of $\psi$ alone.
- Reporting $\langle x^2\rangle - \langle x\rangle^2$ as the spread without taking the square root, or forgetting to square $\langle x\rangle$.

answer: sqrt(3/8)

hint: The integral equals $\frac{2^3}{3} = \frac{8}{3}$.
solution: $|A|^2\cdot\frac{8}{3} = 1$, so $A = \sqrt{3/8}$.

@practice num
prompt: A particle on the half-line has the normalized wavefunction $\psi(x) = 2x\,e^{-x}$ for $x\ge 0$ (with $x$ in some length unit). Find the probability of finding it in $0\le x\le 1$. Round to four decimal places.
answer: 0.3233
check: quad(lambda x: (2*x*exp(-x))**2, 0, 1)
tol: 0.001
hint: The probability is the integral of $|\psi|^2 = 4x^2e^{-2x}$ over the interval.
hint: An antiderivative of $x^2e^{-2x}$ is $-e^{-2x}\left(\frac{x^2}{2} + \frac{x}{2} + \frac14\right)$.
solution: $P = 4\left[-e^{-2x}\left(\tfrac{x^2}{2} + \tfrac{x}{2} + \tfrac14\right)\right]_0^1 = 1 - 5e^{-2} \approx 0.3233$.

@practice num
prompt: For the normalized wavefunction $\psi(x) = 2x\,e^{-x}$ on $x\ge0$, find $\langle x\rangle$ in the same length unit as $x$. Give an exact value.
answer: 3/2
check: quad(lambda x: x*(2*x*exp(-x))**2, 0, inf)
hint: $\langle x\rangle = \int_0^\infty x\,|\psi|^2\,dx = 4\int_0^\infty x^3e^{-2x}\,dx$.
hint: Use $\int_0^\infty x^n e^{-ax}\,dx = n!/a^{n+1}$ with $n = 3$ and $a = 2$.
solution: $\langle x\rangle = 4\cdot\frac{3!}{2^4} = \frac{24}{16} = \frac{3}{2}$.

@practice num
prompt: A particle on $0\le x\le 1$ has the unnormalized wavefunction $\psi(x) = A\,x$ with $A$ not yet fixed. Find the standard deviation $\sigma_x$ of its position. Give an exact value.
answer: sqrt(3/80)
check: (lambda N: sqrt(quad(lambda x: x**4, 0, 1)/N - (quad(lambda x: x**3, 0, 1)/N)**2))(quad(lambda x: x**2, 0, 1))
hint: Normalize first; $\sigma_x$ does not depend on $A$ once you divide by the norm, so you can compute with $|\psi|^2 = x^2$ and divide each integral by $\int_0^1 x^2\,dx$.
hint: $\langle x\rangle = \frac{1/4}{1/3}$ and $\langle x^2\rangle = \frac{1/5}{1/3}$.
solution: $\langle x\rangle = \frac34$ and $\langle x^2\rangle = \frac35$, so $\sigma_x^2 = \frac35 - \frac{9}{16} = \frac{3}{80}$ and $\sigma_x = \sqrt{3/80} \approx 0.194$.

@quiz num
prompt: A particle has $\psi(x) = A\,(1 - x^2)$ for $-1\le x\le 1$ and $\psi = 0$ elsewhere ($x$ in a convenient length unit). Find the positive normalization constant $A$. Give an exact value.
answer: sqrt(15)/4
check: 1/sqrt(quad(lambda x: (1 - x**2)**2, -1, 1))
hint: Expand $(1 - x^2)^2 = 1 - 2x^2 + x^4$ and integrate from $-1$ to $1$.
hint: The integral is $2\left(1 - \frac23 + \frac15\right)$.
solution: $\int_{-1}^{1}(1-x^2)^2\,dx = 2\left(1 - \tfrac23 + \tfrac15\right) = \tfrac{16}{15}$, so $A = \sqrt{15/16} = \sqrt{15}/4$.

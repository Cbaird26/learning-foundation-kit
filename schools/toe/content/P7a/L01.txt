@article
Classical physics keeps two separate pictures: **particles** follow paths, and **waves** spread out and interfere. Experiments with light and matter show that neither picture is enough on its own. Quantum mechanics replaces both with one rule built on **probability amplitudes**.

### Three experiments

- **Photoelectric effect.** Light of frequency $f$ ejects electrons from a metal only if $hf$ exceeds the metal's work function $\phi$, and the fastest electrons leave with $K_{\max} = hf - \phi$. Light is delivered in quanta (photons) of energy $E = hf$, where $h$ is Planck's constant.
- **Electron diffraction.** Electrons scattered from a crystal form a diffraction pattern, as if they had the **de Broglie wavelength** $\lambda = h/p$.
- **Double slit, one particle at a time.** Fire electrons at two narrow slits one by one. Each arrives as a single dot at an unpredictable place, yet after thousands of dots the screen shows interference fringes. Close one slit, or add a detector that records which slit each electron used, and the fringes disappear.

### Amplitudes

Each way an event can happen gets a complex number, its **probability amplitude**. Two rules do most of the work:

1. If the alternatives are **indistinguishable** (nothing anywhere records which one occurred), add the amplitudes, then square: $P = |\alpha_1 + \alpha_2|^2$.
2. If the alternatives are **distinguishable**, add the probabilities: $P = |\alpha_1|^2 + |\alpha_2|^2$.

Expanding rule 1 shows the **interference term**:

$$P = |\alpha_1|^2 + |\alpha_2|^2 + 2\,\mathrm{Re}\,(\alpha_1^{*}\alpha_2).$$

For two amplitudes of equal size $a$ and relative phase $\varphi$, this becomes $P = 2a^2(1+\cos\varphi)$, which runs from $0$ (destructive) to $4a^2$ (constructive). For slits a distance $d$ apart and a far screen, the relative phase at angle $\theta$ is $\varphi = 2\pi d\sin\theta/\lambda$, so bright fringes sit at $d\sin\theta = m\lambda$ with $m = 0, \pm 1, \dots$

### States and normalization

Suppose a measurement has outcomes $n = 1, \dots, N$ with amplitudes $c_n$. The list $(c_1, \dots, c_N)$ is a **state**. The **Born rule** says the probability of outcome $n$ is $|c_n|^2 = c_n^{*}c_n$. Probabilities must total one, which is the **normalization condition**:

$$\sum_{n=1}^{N} |c_n|^2 = 1.$$

Given unnormalized amplitudes, multiply them all by a constant $A$ chosen so that this holds. An overall phase has no physical effect, but **relative** phases between amplitudes do, because they control interference.

### Expectation values

If outcome $n$ has value $a_n$ of some quantity, the **expectation value** is the average over many identically prepared systems:

$$\langle a \rangle = \sum_{n} a_n\,|c_n|^2.$$

It need not equal any single possible outcome, and it is not the "most likely" outcome.

@example
title: Interference of two paths
problem: A particle reaches a detector by path 1 with amplitude $\alpha_1 = 0.3$ or by path 2 with amplitude $\alpha_2 = 0.3\,e^{i\pi/3}$. Find the detection probability when the paths are indistinguishable, and compare it with the case where a record of the path exists.
step: The paths are indistinguishable, so add amplitudes before squaring: $\alpha = 0.3\,(1 + e^{i\pi/3})$.
step: Use $|1 + e^{i\varphi}|^2 = (1+\cos\varphi)^2 + \sin^2\varphi = 2 + 2\cos\varphi$. With $\varphi = \pi/3$ this equals $2 + 1 = 3$.
step: Therefore $P = 0.3^2 \times 3 = 0.27$.
step: With a path record, add probabilities instead: $P = 0.09 + 0.09 = 0.18$. The interference term contributes $+0.09$, a 50% increase.

@example
title: Normalize, then average
problem: A system has three possible outcomes with energies $0$, $\epsilon$ and $2\epsilon$. Its amplitudes are proportional to $1$, $2$ and $2i$. Normalize the state and find the probabilities and $\langle E \rangle$.
step: Write $c = A\,(1, 2, 2i)$. Normalization requires $|A|^2\,(1 + 4 + 4) = 1$, so we may take $A = 1/3$.
step: The probabilities $|c_n|^2$ are $\frac{1}{9}$, $\frac{4}{9}$, $\frac{4}{9}$. They sum to $1$.
step: $\langle E \rangle = 0\cdot\frac{1}{9} + \epsilon\cdot\frac{4}{9} + 2\epsilon\cdot\frac{4}{9} = \frac{12}{9}\,\epsilon = \frac{4}{3}\,\epsilon$.
step: The average $\frac{4}{3}\epsilon$ is not one of the three possible outcomes. The factor $i$ in the last amplitude changed nothing here, because only $|c_n|^2$ enters.

@mistakes
- Squaring each amplitude and adding the results even when the alternatives are indistinguishable, which throws away the interference term.
- Using $c^2$ instead of $|c|^2$ for a complex amplitude, which can give negative or complex "probabilities".
- Reading probabilities from amplitudes before normalizing.
- Treating the expectation value as the most probable outcome.

answer: 0.727
check: 6.626e-34/(9.109e-31*1.0e6)*1e9
unit: nm
tol: 1%
hint: The de Broglie relation is $\lambda = h/p$, and $p = mv$ at low speed.
hint: Compute $h/(m_e v)$ in metres, then convert: $1\ \text{nm} = 10^{-9}\ \text{m}$.
solution: $\lambda = \dfrac{h}{m_e v} = \dfrac{6.626\times10^{-34}}{(9.109\times10^{-31})(10^{6})} = 7.27\times10^{-10}\ \text{m} = 0.727\ \text{nm}$.

@practice num
prompt: Two indistinguishable paths lead to the same detector, with amplitudes $0.2$ and $0.2\,e^{i\,2\pi/3}$. Find the detection probability.
answer: 0.04
check: abs(0.2 + 0.2*cmath.exp(2j*pi/3))**2
hint: Add the amplitudes first. Use $|1 + e^{i\varphi}|^2 = 2 + 2\cos\varphi$.
hint: For $\varphi = 2\pi/3$, $\cos\varphi = -\tfrac{1}{2}$, so the bracket equals $1$.
solution: $P = 0.2^2\,(2 + 2\cos\tfrac{2\pi}{3}) = 0.04\,(2 - 1) = 0.04$. Without interference the answer would have been $0.08$.

@quiz num
prompt: A measurement has outcomes with values $-1$, $0$ and $+1$. The unnormalized amplitudes are proportional to $1$, $-4i$ and $8$. Find the expectation value of the outcome.
answer: 7/9
check: sum(abs(c)**2*v for c, v in zip([1, -4j, 8], [-1, 0, 1]))/sum(abs(c)**2 for c in [1, -4j, 8])
hint: Normalize first: the squared moduli are $1$, $16$, $64$.
hint: The probabilities are $\tfrac1{81}, \tfrac{16}{81}, \tfrac{64}{81}$. Weight each value by its probability.
solution: The norm squared is $81$, so the probabilities are $\frac{1}{81}, \frac{16}{81}, \frac{64}{81}$. Then $\langle a \rangle = (-1)\frac{1}{81} + 0 + (1)\frac{64}{81} = \frac{63}{81} = \frac{7}{9}$. The phase of $-4i$ does not matter.

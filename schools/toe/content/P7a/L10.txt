@article
Last week we found the oscillator levels by solving a differential equation. Operators give a faster route that reveals why the levels are equally spaced. With $x_0 = \sqrt{\hbar/(m\omega)}$, define the **lowering** and **raising** operators

$$\hat a = \frac{1}{\sqrt2}\left(\frac{\hat x}{x_0} + \frac{i\,x_0\hat p}{\hbar}\right), \qquad \hat a^\dagger = \frac{1}{\sqrt2}\left(\frac{\hat x}{x_0} - \frac{i\,x_0\hat p}{\hbar}\right).$$

Using $[\hat x,\hat p] = i\hbar$ gives the key commutator $[\hat a,\hat a^\dagger] = 1$. Multiplying out the product $\hat a^\dagger\hat a$ and using the commutator shows

$$\hat H = \frac{\hat p^2}{2m} + \frac12m\omega^2\hat x^2 = \hbar\omega\left(\hat a^\dagger\hat a + \tfrac12\right) = \hbar\omega\left(\hat N + \tfrac12\right),$$

where $\hat N = \hat a^\dagger\hat a$ is the **number operator**. Note also $\hat a\hat a^\dagger = \hat N + 1$.

### Why the spacing is $\hbar\omega$

From $[\hat a,\hat a^\dagger] = 1$ we get $[\hat H,\hat a^\dagger] = \hbar\omega\,\hat a^\dagger$ and $[\hat H,\hat a] = -\hbar\omega\,\hat a$. If $\hat H|\psi\rangle = E|\psi\rangle$, then

$$\hat H\,\hat a^\dagger|\psi\rangle = \hat a^\dagger\hat H|\psi\rangle + \hbar\omega\,\hat a^\dagger|\psi\rangle = (E + \hbar\omega)\,\hat a^\dagger|\psi\rangle.$$

So $\hat a^\dagger$ **raises** the energy by exactly $\hbar\omega$, and $\hat a$ **lowers** it by $\hbar\omega$. The energy cannot go down forever, because $\langle\hat H\rangle = \hbar\omega\bigl(\|\hat a\psi\|^2 + \tfrac12\bigr) \ge \tfrac12\hbar\omega$. So there is a lowest state $|0\rangle$ with $\hat a|0\rangle = 0$ (the zero vector), and its energy is $E_0 = \tfrac12\hbar\omega$. Climbing with $\hat a^\dagger$ gives $E_n = (n + \tfrac12)\hbar\omega$.

### Normalization

The squared norm of $\hat a^\dagger|n\rangle$ is $\langle n|\hat a\hat a^\dagger|n\rangle = \langle n|(\hat N+1)|n\rangle = n + 1$, and that of $\hat a|n\rangle$ is $\langle n|\hat N|n\rangle = n$. For normalized number states $|n\rangle$:

$$\hat a|n\rangle = \sqrt{n}\,|n-1\rangle, \qquad \hat a^\dagger|n\rangle = \sqrt{n+1}\,|n+1\rangle, \qquad |n\rangle = \frac{(\hat a^\dagger)^n}{\sqrt{n!}}|0\rangle.$$

The ground-state wavefunction comes from the first-order equation $\hat a\psi_0 = 0$, which is $\left(x + x_0^2\,\dfrac{d}{dx}\right)\psi_0 = 0$ and has the Gaussian solution found last week.

### Position and momentum from ladders

Inverting the definitions,

$$\hat x = \frac{x_0}{\sqrt2}\,(\hat a + \hat a^\dagger), \qquad \hat p = \frac{i\hbar}{\sqrt2\,x_0}\,(\hat a^\dagger - \hat a).$$

Because $\hat a$ and $\hat a^\dagger$ change $n$ by $\mp1$, the only nonzero matrix elements of $\hat x$ are $\langle n\pm1|\hat x|n\rangle$; in particular $\langle n|\hat x|n\rangle = 0$. For $\hat x^2$ the terms $\hat a^2$ and $\hat a^{\dagger2}$ change $n$ by $\pm2$, and the terms $\hat a\hat a^\dagger + \hat a^\dagger\hat a = 2\hat N + 1$ do not, so $\langle n|\hat x^2|n\rangle = (n+\frac12)x_0^2$.

@example
title: Raising the energy by one quantum
problem: Show that $\hat a^\dagger$ turns an eigenstate of energy $E$ into an eigenstate of energy $E + \hbar\omega$, starting from $\hat H = \hbar\omega(\hat a^\dagger\hat a + \tfrac12)$ and $[\hat a,\hat a^\dagger] = 1$.
step: Compute the commutator: $[\hat H,\hat a^\dagger] = \hbar\omega\,[\hat a^\dagger\hat a,\hat a^\dagger] = \hbar\omega\,\hat a^\dagger[\hat a,\hat a^\dagger] = \hbar\omega\,\hat a^\dagger$.
step: Apply $\hat H$ to $\hat a^\dagger|\psi\rangle$, with $\hat H|\psi\rangle = E|\psi\rangle$: $\hat H\hat a^\dagger|\psi\rangle = \hat a^\dagger\hat H|\psi\rangle + [\hat H,\hat a^\dagger]|\psi\rangle$.
step: Substitute: this equals $E\,\hat a^\dagger|\psi\rangle + \hbar\omega\,\hat a^\dagger|\psi\rangle = (E + \hbar\omega)\,\hat a^\dagger|\psi\rangle$.
step: So repeated use of $\hat a^\dagger$ climbs a ladder of rungs separated by $\hbar\omega$, provided $\hat a^\dagger|\psi\rangle \neq 0$ (and it never is, since its squared norm is $n+1 > 0$).

@example
title: Normalizing a superposition and averaging
problem: A state is $|\psi\rangle = A\bigl(|0\rangle + \hat a^\dagger|1\rangle\bigr)$. Find $A$, then $\langle E\rangle$ and $\langle x^2\rangle$.
step: Since $\hat a^\dagger|1\rangle = \sqrt2\,|2\rangle$, the state is $A(|0\rangle + \sqrt2\,|2\rangle)$. Normalization gives $|A|^2(1 + 2) = 1$, so $A = 1/\sqrt3$.
step: The probabilities are $\frac13$ for $n=0$ and $\frac23$ for $n=2$. Hence $\langle E\rangle = \frac13\cdot\frac12\hbar\omega + \frac23\cdot\frac52\hbar\omega = \frac{11}{6}\hbar\omega$.
step: Write $\hat x^2 = \frac{x_0^2}{2}(\hat a^2 + \hat a^{\dagger2} + 2\hat N + 1)$. The diagonal part gives $\frac{x_0^2}{2}\left[\frac13(1) + \frac23(5)\right] = \frac{11}{6}x_0^2$.
step: The cross terms connect $n=0$ and $n=2$. With $\langle0|\hat a^2|2\rangle = \sqrt2$, they add $2\cdot\frac{\sqrt2}{3}\cdot\frac{x_0^2}{2}\cdot\sqrt2 = \frac23x_0^2$. Therefore $\langle x^2\rangle = \frac{11}{6}x_0^2 + \frac23x_0^2 = \frac52x_0^2$.

@mistakes
- Writing $\hat a|0\rangle = |0\rangle$ or $|{-1}\rangle$. The lowering operator annihilates the ground state: $\hat a|0\rangle = 0$, the zero vector.
- Dropping the factors $\sqrt{n}$ and $\sqrt{n+1}$, which produces unnormalized states.
- Treating $\hat a$ and $\hat a^\dagger$ as commuting, for instance writing $\hat a\hat a^\dagger = \hat N$ instead of $\hat N + 1$.
- Writing $\hat H = \hbar\omega\hat N$ and forgetting the $\tfrac12$ (the zero-point energy).

@practice self
prompt: Prove that $[\hat H,\hat a] = -\hbar\omega\,\hat a$ and use it to show that if $\hat H|\psi\rangle = E|\psi\rangle$ then $\hat a|\psi\rangle$ is either zero or an eigenstate with energy $E - \hbar\omega$. Then explain why this forces a ground state with $\hat a|0\rangle = 0$.
hint: Use $\hat H = \hbar\omega(\hat a^\dagger\hat a + \tfrac12)$ and $[\hat a^\dagger\hat a,\hat a] = [\hat a^\dagger,\hat a]\hat a$.
hint: Positivity: $\langle\hat H\rangle = \hbar\omega(\|\hat a\psi\|^2 + \tfrac12)$ cannot be below $\tfrac12\hbar\omega$.
solution: $[\hat H,\hat a] = \hbar\omega[\hat a^\dagger\hat a,\hat a] = \hbar\omega[\hat a^\dagger,\hat a]\hat a = -\hbar\omega\,\hat a$. Then $\hat H\hat a|\psi\rangle = \hat a\hat H|\psi\rangle - \hbar\omega\,\hat a|\psi\rangle = (E - \hbar\omega)\hat a|\psi\rangle$. Repeated lowering would eventually give energies below $\frac12\hbar\omega$, but $\langle\hat H\rangle = \hbar\omega(\|\hat a\psi\|^2 + \frac12) \ge \frac12\hbar\omega$ for any state. The sequence must therefore end: some state $|0\rangle$ has $\hat a|0\rangle = 0$, and then $\hat H|0\rangle = \frac12\hbar\omega|0\rangle$.

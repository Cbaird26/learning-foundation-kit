@article
Hydrogen is the simplest atom, and its Schrödinger equation can be solved exactly. The electron (mass $m$, essentially the reduced mass) feels the Coulomb potential $V(r) = -\dfrac{e^2}{4\pi\epsilon_0 r}$, which depends only on the distance $r$. Because the potential is spherically symmetric, the angular dependence is exactly the angular-momentum problem of last week:

$$\psi_{nlm}(r,\theta,\phi) = R_{nl}(r)\,Y_l^m(\theta,\phi).$$

### The radial equation

Write $u(r) = rR(r)$. The angular eigenvalue $\hbar^2l(l+1)$ appears as a repulsive **centrifugal term**:

$$-\frac{\hbar^2}{2m}\frac{d^2u}{dr^2} + \left[-\frac{e^2}{4\pi\epsilon_0 r} + \frac{\hbar^2 l(l+1)}{2mr^2}\right]u = E\,u, \qquad u(0) = 0.$$

This is a one-dimensional bound-state problem with an effective potential, so only discrete energies $E<0$ are normalizable.

### Energies and quantum numbers

$$E_n = -\frac{13.6\ \text{eV}}{n^2}, \qquad n = 1, 2, 3, \dots$$

The other quantum numbers are constrained by $n$: $l = 0, 1, \dots, n-1$ and $m = -l, \dots, l$. The number of orbital states with a given $n$ is

$$\sum_{l=0}^{n-1}(2l+1) = n^2,$$

or $2n^2$ counting the two spin states. The energy depends only on $n$, a degeneracy peculiar to the $1/r$ potential. The ground state needs $13.6\ \text{eV}$ to ionize. The number of radial nodes of $R_{nl}$ is $n - l - 1$, and near the origin $R_{nl} \propto r^l$, so only $s$ states ($l=0$) are nonzero at the nucleus. Spectroscopic letters are s, p, d, f for $l = 0,1,2,3$.

### Size of the ground state

The **Bohr radius** is $a_0 = \dfrac{4\pi\epsilon_0\hbar^2}{me^2} = 0.0529\ \text{nm}$, and

$$\psi_{100} = \frac{1}{\sqrt{\pi a_0^3}}\,e^{-r/a_0}.$$

The probability of finding the electron between $r$ and $r + dr$ is $P(r)\,dr$ with $P(r) = 4\pi r^2|\psi|^2$, which for the ground state is $\dfrac{4r^2}{a_0^3}e^{-2r/a_0}$. Do not confuse $P(r)$ with $|\psi|^2$: the latter peaks at the nucleus, but $P(r)$ peaks at $r = a_0$ because the volume of the shell grows as $r^2$. The mean radius is $\langle r\rangle = \tfrac32a_0$.

### Spectral lines and selection rules

A transition from $n_i$ to $n_f$ emits a photon of energy

$$E_\gamma = 13.6\ \text{eV}\left(\frac{1}{n_f^2} - \frac{1}{n_i^2}\right), \qquad \frac{1}{\lambda} = R_\infty\left(\frac{1}{n_f^2} - \frac{1}{n_i^2}\right),$$

with $R_\infty = 1.097\times10^{7}\ \text{m}^{-1}$ (the **Rydberg constant**). Series: Lyman ($n_f = 1$, ultraviolet), Balmer ($n_f = 2$, visible), Paschen ($n_f = 3$, infrared). Because a photon carries one unit of angular momentum, single-photon electric-dipole transitions obey the **selection rules**

$$\Delta l = \pm 1, \qquad \Delta m = 0, \pm 1.$$

So $2p \to 1s$ is allowed, while $2s \to 1s$ and $3p \to 2p$ are not.

@example
title: The Balmer-alpha line
problem: Find the wavelength of the photon emitted in the $n = 3 \to n = 2$ transition. Use $hc = 1240\ \text{eV nm}$.
step: The energy difference is $E_\gamma = 13.6\left(\dfrac14 - \dfrac19\right) = 13.6\cdot\dfrac{5}{36} = 1.889\ \text{eV}$.
step: The wavelength is $\lambda = \dfrac{hc}{E_\gamma} = \dfrac{1240}{1.889} \approx 656\ \text{nm}$.
step: Cross-check with the Rydberg formula: $\dfrac1\lambda = (1.097\times10^7)\dfrac{5}{36} = 1.524\times10^6\ \text{m}^{-1}$, so $\lambda = 656\ \text{nm}$ again.
step: This red line lies in the visible Balmer series, as expected for $n_f = 2$.

@example
title: Quantum numbers and allowed decays from $n = 3$
problem: List the orbital states with $n = 3$, then decide which $n = 3$ states can decay to a $2p$ state by one-photon electric-dipole emission, and which final $m$ values are possible for $3d$ with $m = 2$.
step: For $n = 3$, $l = 0, 1, 2$ (3s, 3p, 3d), with $1 + 3 + 5 = 9 = n^2$ orbital states.
step: The final state $2p$ has $l = 1$, so we need $\Delta l = \pm1$: $3s\to2p$ ($0\to1$) is allowed, $3d\to2p$ ($2\to1$) is allowed, and $3p\to2p$ ($\Delta l = 0$) is forbidden.
step: For $3d$ with $m=2$ going to $2p$, the final $m'$ is in $\{-1, 0, 1\}$ and must satisfy $|m' - 2| \le 1$. Only $m' = 1$ works.
step: Also $3d \to 1s$ is forbidden because $\Delta l = -2$. Such a state must cascade, for example $3d \to 2p \to 1s$.

@mistakes
- Allowing $l = n$ or counting only $n$ states per shell instead of $n^2$ orbital states.
- Writing $E_n \propto 1/n$ or leaving out the minus sign. Bound states have $E<0$.
- Mixing up $|\psi|^2$ with the radial density $P(r) = 4\pi r^2|\psi|^2$.
- Allowing $\Delta l = 0$ transitions, such as $2s \to 1s$, for a single photon.

@practice num
prompt: How many distinct states (including the two spin orientations) does the $n = 4$ shell of hydrogen contain?
answer: 32
check: sum(2*(2*l + 1) for l in range(4))
hint: For each $l = 0,\dots,3$, count $2l+1$ values of $m$.
hint: The orbital count is $n^2$; spin doubles it.
solution: The orbital states number $1 + 3 + 5 + 7 = 16 = n^2$, and with two spin states the total is $2n^2 = 32$.

@practice num
prompt: Find the wavelength of the photon emitted in the $n = 4 \to n = 2$ transition of hydrogen, using $R_\infty = 1.097\times10^7\ \text{m}^{-1}$.
answer: 486
check: 1/(1.097e7*(1/2**2 - 1/4**2))*1e9
unit: nm
tol: 1%
hint: Use $1/\lambda = R_\infty(1/n_f^2 - 1/n_i^2)$ with $n_f = 2$, $n_i = 4$.
hint: $\frac14 - \frac1{16} = \frac{3}{16}$.
solution: $1/\lambda = (1.097\times10^7)(3/16) = 2.057\times10^6\ \text{m}^{-1}$, so $\lambda = 486\ \text{nm}$ (blue-green).

@practice num
prompt: The electron in the hydrogen ground state has $P(r) = \dfrac{4r^2}{a_0^3}e^{-2r/a_0}$. Find the probability of finding it within $r < 2a_0$. Round to three decimal places.
answer: 0.762
check: quad(lambda s: 4*s**2*exp(-2*s), 0, 2)
tol: 0.001
hint: Use $s = r/a_0$ so that the probability is $\int_0^2 4s^2e^{-2s}\,ds$.
hint: An antiderivative of $4s^2e^{-2s}$ is $-e^{-2s}(2s^2 + 2s + 1)$.
solution: $P = \left[-e^{-2s}(2s^2 + 2s + 1)\right]_0^2 = 1 - 13e^{-4} \approx 0.762$.

@practice self
prompt: Show that the $n$-th shell of hydrogen contains $n^2$ orbital states ($2n^2$ with spin) and list all $(l, m)$ pairs for $n = 3$.
hint: Count the allowed $m$ values for each allowed $l$, then add.
hint: Use $\sum_{l=0}^{n-1}(2l+1) = n^2$.
solution: For a given $n$, $l = 0,1,\dots,n-1$ and each $l$ has $2l+1$ values of $m$, so the number of orbital states is $\sum_{l=0}^{n-1}(2l+1) = 2\cdot\frac{n(n-1)}{2} + n = n^2$. With two spin states this is $2n^2$. For $n = 3$: $l = 0$ has $m = 0$; $l = 1$ has $m = -1,0,1$; $l = 2$ has $m = -2,-1,0,1,2$; the total is $1 + 3 + 5 = 9$.

@quiz num
prompt: For the hydrogen $2p$ state, $R_{21} \propto r\,e^{-r/(2a_0)}$, so the radial probability density is $P(r) \propto r^4e^{-r/a_0}$. Find the most probable radius in units of $a_0$.
answer: 4
check: root(lambda s: 4*s**3*exp(-s) - s**4*exp(-s), 1, 10)
hint: Set $dP/dr = 0$ with $P \propto s^4e^{-s}$, where $s = r/a_0$.
hint: $\frac{d}{ds}(s^4e^{-s}) = (4s^3 - s^4)e^{-s}$.
solution: The derivative vanishes when $4s^3 = s^4$, so $s = 4$ and $r = 4a_0$, which is $n^2a_0$ with $n = 2$.

@quiz list
prompt: A hydrogen atom is in the $3d$ state with $m = 1$ and decays to a $2p$ state by one-photon electric-dipole emission. List every allowed final value of $m$.
answer: 0, 1
check: [mp for mp in range(-1, 2) if abs(mp - 1) <= 1]
hint: The $2p$ state allows $m' \in \{-1, 0, 1\}$.
hint: The rule is $|m' - m| \le 1$ with $m = 1$.
solution: We need $\Delta m = m' - 1 \in \{-1, 0, 1\}$, so $m' \in \{0, 1, 2\}$. The $2p$ state only has $m' \in \{-1, 0, 1\}$, leaving $m' = 0$ and $m' = 1$.

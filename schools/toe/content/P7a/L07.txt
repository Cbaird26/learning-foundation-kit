@article
In quantum mechanics every measurable quantity (an **observable**) is represented by a **linear operator** that acts on wavefunctions. The basic ones are

$$\hat x\,\psi = x\,\psi, \qquad \hat p\,\psi = -i\hbar\,\frac{d\psi}{dx}, \qquad \hat H\,\psi = \left[\frac{\hat p^2}{2m} + V(x)\right]\psi = -\frac{\hbar^2}{2m}\psi'' + V\psi.$$

The Schrödinger equation is then $i\hbar\,\partial_t\Psi = \hat H\Psi$, and the time-independent one is the eigenvalue problem $\hat H\psi = E\psi$.

### Eigenvalues and measurement

For any observable $\hat A$, solve $\hat A\phi_n = a_n\phi_n$. The rules are:

1. A measurement of $A$ can only give one of the eigenvalues $a_n$.
2. Expand the state as $\psi = \sum_n c_n\phi_n$. The probability of $a_n$ is $|c_n|^2$ (for a non-degenerate eigenvalue).
3. Immediately after a measurement that gives $a_n$, the state is $\phi_n$ (collapse), so repeating the measurement gives $a_n$ again with certainty.
4. The average over many identical preparations is the **expectation value**
$$\langle A\rangle = \int \psi^{*}\,\hat A\psi\,dx = \sum_n |c_n|^2\,a_n.$$

The overlap integral $\langle\phi|\psi\rangle = \int\phi^{*}\psi\,dx$ gives the coefficients: $c_n = \langle\phi_n|\psi\rangle$.

### Hermitian operators

An operator is **Hermitian** if $\int f^{*}\,\hat A g\,dx = \int (\hat A f)^{*}g\,dx$ for acceptable functions $f,g$. Observables are Hermitian, which guarantees:

- eigenvalues are **real**;
- eigenfunctions with different eigenvalues are **orthogonal**;
- the eigenfunctions form a **complete** set, so any state can be expanded.

The operator $\hat p = -i\hbar\,d/dx$ is Hermitian (the $i$ matters), but $d/dx$ alone is not. For matrices, Hermitian means $A = A^\dagger$ (conjugate transpose), and the eigenvectors play the role of eigenfunctions:

```python
import numpy as np
A = np.array([[2, 1], [1, 2]])
vals, vecs = np.linalg.eigh(A)
print(vals)    # [1. 3.]
```

### Commutators

The order of operators matters. The **commutator** is $[\hat A,\hat B] = \hat A\hat B - \hat B\hat A$. To evaluate one, act on an arbitrary test function $f$. The most important result is

$$[\hat x,\hat p] = i\hbar.$$

Two helpful rules: $[\hat A,\hat B\hat C] = [\hat A,\hat B]\hat C + \hat B[\hat A,\hat C]$ and $[\hat A,\hat B] = -[\hat B,\hat A]$. If $[\hat A,\hat B] = 0$ the observables are **compatible** and share eigenfunctions (next week).

@example
title: Measurement statistics for a two-component state
problem: An observable is represented by $A = \begin{pmatrix}2&1\\1&2\end{pmatrix}$, and the state is $\psi = \begin{pmatrix}0.6\\0.8\end{pmatrix}$. Find the possible results, their probabilities, and $\langle A\rangle$.
step: Eigenvalues: $\det(A - \lambda) = (2-\lambda)^2 - 1 = 0$ gives $\lambda = 1$ and $\lambda = 3$, with normalized eigenvectors $v_{-} = (1,-1)/\sqrt2$ and $v_{+} = (1,1)/\sqrt2$.
step: Overlaps: $\langle v_+|\psi\rangle = 1.4/\sqrt2$ and $\langle v_-|\psi\rangle = -0.2/\sqrt2$. Squaring, $P(3) = 0.98$ and $P(1) = 0.02$, which sum to $1$.
step: Expectation value: $\langle A\rangle = 3(0.98) + 1(0.02) = 2.96$.
step: Check directly: $A\psi = (2.0,\,2.2)$ and $\psi^{\dagger}A\psi = 0.6(2.0) + 0.8(2.2) = 2.96$. If the result $3$ is obtained, the state collapses to $v_+$ and a second measurement gives $3$ with probability $1$.

@example
title: Commutators by acting on a test function
problem: Compute $[\hat x,\hat p]$ and then $[\hat x,\hat p^2]$.
step: Act on a test function $f(x)$. First $\hat x\hat p f = x(-i\hbar f') = -i\hbar x f'$.
step: Next $\hat p\hat x f = -i\hbar (xf)' = -i\hbar f - i\hbar x f'$.
step: Subtract: $[\hat x,\hat p]f = i\hbar f$ for every $f$, so $[\hat x,\hat p] = i\hbar$.
step: Use the product rule for commutators: $[\hat x,\hat p^2] = [\hat x,\hat p]\hat p + \hat p[\hat x,\hat p] = 2i\hbar\,\hat p$. As a consequence, $[\hat x,\hat H] = i\hbar\,\hat p/m$ because $V(x)$ commutes with $\hat x$.

@mistakes
- Treating the expectation value as one of the possible measurement results.
- Forgetting the complex conjugate in the overlap $\langle\phi|\psi\rangle$, or forgetting to normalize the eigenvectors before squaring.
- Dropping the test function and concluding $[\hat x,\hat p] = 0$ because "$x$ and $d/dx$ are just symbols".
- Assuming the product of two Hermitian operators is Hermitian. $\hat x\hat p$ is not, because $\hat x$ and $\hat p$ do not commute.

@practice num
prompt: An observable has eigenvalues $-1$, $2$ and $4$ (in some unit). A measurement gives these with probabilities $0.5$, $0.3$ and $0.2$. Find $\langle A\rangle$.
answer: 0.9
check: sum(p*a for p, a in zip([0.5, 0.3, 0.2], [-1, 2, 4]))
hint: The expectation value weights each eigenvalue by its probability.
hint: Compute $-0.5 + 0.6 + 0.8$.
solution: $\langle A\rangle = (-1)(0.5) + 2(0.3) + 4(0.2) = 0.9$. Notice that $0.9$ is not an eigenvalue and so can never be the outcome of a single measurement.

solution: $\det = 6 - 2 = 4$ and the trace is $5$, so $\lambda^2 - 5\lambda + 4 = 0$ gives $\lambda = 1$ or $4$. The larger one is $4$.

@quiz num
prompt: An observable is represented by $\sigma_y = \begin{pmatrix}0&-i\\ i&0\end{pmatrix}$ and the state is $\psi = \dfrac15\begin{pmatrix}3\\ 4i\end{pmatrix}$. Find $\langle\sigma_y\rangle = \psi^{\dagger}\sigma_y\psi$. Give an exact value.
answer: 24/25
check: (np.conj(np.array([3, 4j])/5) @ np.array([[0, -1j], [1j, 0]]) @ (np.array([3, 4j])/5)).real
hint: Remember $\psi^{\dagger}$ is the conjugate transpose, so the second component of the row vector is $-4i/5$.
hint: $\sigma_y\psi = \frac15(4,\ 3i)^T$.
solution: $\sigma_y\psi = \frac15(4,\,3i)^T$, so $\psi^{\dagger}\sigma_y\psi = \frac{1}{25}(3\cdot4 + (-4i)(3i)) = \frac{12 + 12}{25} = \frac{24}{25}$. Equivalently $P(+1) = 0.98$ and $P(-1) = 0.02$, so $\langle\sigma_y\rangle = 0.96$.

@quiz ms
prompt: Select every true statement about observables in quantum mechanics.
choice*: The eigenvalues of a Hermitian operator are real.
choice*: Eigenfunctions of a Hermitian operator with different eigenvalues are orthogonal.
choice*: After a measurement of $A$ gives $a_n$, an immediate second measurement of $A$ gives $a_n$ again with certainty.
choice: The expectation value $\langle A\rangle$ is always one of the eigenvalues of $\hat A$.

solution: Real eigenvalues, orthogonality of eigenfunctions with different eigenvalues, and a repeated measurement reproducing the result are standard results.

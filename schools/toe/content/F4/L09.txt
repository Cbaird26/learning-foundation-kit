@article
A plot is an argument: it should let a reader see what you measured, what your model predicts and how well they agree, without reading your code. We use `matplotlib`, the standard Python plotting library.

### A first plot

```python
import numpy as np
import matplotlib.pyplot as plt

t = np.linspace(0, 2, 201)        # 201 points give a smooth curve
d = 4.9 * t ** 2                  # free fall from rest, metres

plt.plot(t, d, label="model: 4.9 t^2")
plt.xlabel("time t (s)")
plt.ylabel("distance fallen d (m)")
plt.title("Free fall from rest")
plt.legend()
plt.grid(True)
plt.savefig("freefall.png", dpi=150)   # save before show
plt.show()
```

Each call adds to the current figure. `plt.plot(x, y)` joins the points with straight lines, so a model needs a dense grid of `x` values to look smooth. **Always** label both axes with the quantity and its unit.

### Data and models look different

Measurements are separate points, often with uncertainty. A model is a continuous curve. Show them differently:

```python
plt.plot(t_data, d_data, "o", label="measured")      # markers only
plt.plot(t, d, "-", label="model")                    # smooth line
plt.errorbar(t_data, d_data, yerr=0.05, fmt="o")      # points with error bars
```

The short format string chooses a marker or line style and a colour: `"o"` is circles, `"-"` a solid line, `"r--"` a red dashed line.

### Several panels and residuals

```python
fig, (ax1, ax2) = plt.subplots(2, 1, sharex=True)
ax1.plot(t_data, d_data, "o")
ax1.plot(t, d, "-")
ax2.plot(t_data, d_data - 4.9 * t_data ** 2, "o")
ax2.axhline(0.0)
ax2.set_xlabel("time t (s)")
```

The top panel compares data and model. The bottom panel shows the **residuals**, data minus model. If the model is right, the residuals scatter randomly around zero. A visible curve or trend in them shows what the model misses.

### Log scales

On a log axis equal distances mean equal ratios. A power law $y = c\,x^{n}$ becomes a straight line on a **log-log** plot with slope $n$, because $\ln y = \ln c + n \ln x$. An exponential $y = c\,e^{kx}$ becomes a straight line on a **semi-log** plot (log $y$, linear $x$) with slope $k$ in natural-log units. Use `plt.xscale("log")` and `plt.yscale("log")`.

### Honest plots

Choose axis ranges that do not hide the data. Do not join noisy points with lines unless the line means something. Keep text legible. Save figures from the script that made them, so the picture can be regenerated.

@example
title: Building a data-and-model figure
problem: A student measured the distance a ball fell at five times and wants a figure comparing the data with the model $d = 4.9\,t^2$. List the plotting steps in order and say why each is there.
step: Make a dense grid for the model: `t = np.linspace(0, 1, 201)` and `d = 4.9 * t ** 2`. With 201 points the spacing is 0.005 s, so the straight segments look like a smooth curve.
step: Plot the model as a line, `plt.plot(t, d, "-", label="model")`, and the five measurements as markers only, `plt.plot(t_data, d_data, "o", label="measured")`. Markers say "these are separate observations".
step: Label the axes with quantities and units: `plt.xlabel("time t (s)")` and `plt.ylabel("distance d (m)")`. Add `plt.legend()` so a reader can tell the two sets apart.
step: Save the figure from the script with `plt.savefig("ball.png", dpi=150)` before `plt.show()`, so rerunning the script regenerates the same picture.

@example
title: Reading a log-log plot
problem: Three measurements are $(x, y) = (1, 5)$, $(2, 20)$ and $(4, 80)$. On log-log axes they lie on a straight line. Find the power law $y = c\,x^n$.
step: On log-log axes the slope between two points is $n = \dfrac{\ln y_2 - \ln y_1}{\ln x_2 - \ln x_1}$.
step: Between the first two points, $n = \dfrac{\ln 20 - \ln 5}{\ln 2 - \ln 1} = \dfrac{\ln 4}{\ln 2} = 2$.
step: Check with the last two points: $\dfrac{\ln 80 - \ln 20}{\ln 4 - \ln 2} = \dfrac{\ln 4}{\ln 2} = 2$. The slopes agree, so the points lie on one line.
step: At $x = 1$ the formula gives $y = c$, so $c = 5$. The law is $y = 5x^2$.

@mistakes
- Leaving axes unlabelled or without units, so the figure cannot be read without the code.
- Plotting a model with a handful of points, which produces a jagged polygon instead of a curve.
- Joining noisy measurements with straight lines, which suggests a trend between observations that was never measured.
- Calling `plt.show()` before `plt.savefig(...)`, which can leave you with an empty saved file.

answer: 3

@practice self
prompt: The following simulated cooling data are supplied. The model is $T(t) = 20 + 60\,e^{-t/15}$ in degrees Celsius, with $t$ in minutes.
```python
t_data = np.array([0, 5, 10, 20, 30])            # minutes
T_data = np.array([80.0, 63.4, 50.2, 36.1, 27.9])  # degrees Celsius
```
Write code that produces one saved figure with two panels sharing the time axis: the top panel shows the data as markers and the model as a smooth line, and the bottom panel shows the residuals (data minus model) with a zero line. Label every axis with its unit.
hint: Use `plt.subplots(2, 1, sharex=True)`, a dense `np.linspace` grid for the model, and the model evaluated at `t_data` for the residuals.
hint: Do not forget the legend in the top panel and `plt.savefig` before `plt.show`.
solution: One possible program:
```python
import numpy as np
import matplotlib.pyplot as plt

def model(t):
    return 20 + 60 * np.exp(-t / 15)

t_data = np.array([0, 5, 10, 20, 30])
T_data = np.array([80.0, 63.4, 50.2, 36.1, 27.9])
t = np.linspace(0, 30, 301)

fig, (top, bottom) = plt.subplots(2, 1, sharex=True)
top.plot(t, model(t), "-", label="model")
top.plot(t_data, T_data, "o", label="measured")
top.set_ylabel("temperature T (deg C)")
top.legend()
bottom.plot(t_data, T_data - model(t_data), "o")
bottom.axhline(0.0)
bottom.set_xlabel("time t (min)")
bottom.set_ylabel("residual (deg C)")
fig.savefig("cooling.png", dpi=150)
```
The residuals are all smaller than 0.7 degrees in size and alternate in sign with no clear trend, so the model describes the data well.
rubric: Data are shown as markers and the model as a line computed on a dense grid.
rubric: The residual panel plots data minus model and includes a zero reference line.
rubric: Both panels share the time axis, and every axis label includes its unit.
rubric: The figure is saved from the script with savefig.

@quiz num
prompt: A quantity follows $y = 2\,e^{0.5\,t}$. If you plot $\log_{10} y$ against $t$ on ordinary linear axes, the points fall on a straight line. What is its slope? Give the value to four decimal places.
answer: 0.2171
check: (np.log10(2 * np.exp(0.5 * 10)) - np.log10(2 * np.exp(0.5 * 0))) / 10
tol: 0.0005
hint: Take $\log_{10}$ of both sides of $y = 2e^{0.5t}$.
hint: $\log_{10} e^{0.5t} = 0.5\,t\,\log_{10} e$, and $\log_{10} e = 1/\ln 10$.
solution: $\log_{10} y = \log_{10} 2 + 0.5\,t\,\log_{10} e$, so the slope is $0.5 \log_{10} e = 0.5 / \ln 10 \approx 0.2171$.

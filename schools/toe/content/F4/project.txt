@review
## Review: Python for scientific work

### Key results and methods, week by week

1. **Variables and expressions.** `=` assigns. The operators `+ - * / // % **` follow algebraic precedence. `/` always gives a float and `//` floors. Trace a program with a table of its variables.
2. **Conditionals.** `if`/`elif`/`else` run the first true branch. Comparisons can be chained. Check inputs and `raise ValueError` for impossible values, and test the boundaries.
3. **Loops.** `range(a, b, step)` excludes `b`. Start an accumulator before the loop. A `while` condition must be able to become false, and floats should not be tested with `==`.
4. **Functions and scope.** `return` hands a value back, `print` does not. Names assigned inside a function are local. Use defaults and docstrings, and build sequences from recurrences.
5. **Lists and arrays.** Indexing starts at 0 and slices exclude the stop. `b = a` aliases a list. NumPy acts element by element, `linspace(a, b, n)` has `n - 1` gaps, and array slices are views.
6. **File input and output.** Use `with open(...)`. Text must be converted with `float`. Skip comments and blanks in code, never edit raw data, and write results to new files.
7. **Debugging.** Read a traceback from the bottom. Reproduce, predict, inspect, change one thing, and keep the failing case as a test. Use `assert`, and catch only specific exceptions.
8. **Tests and precision.** Use known-answer, boundary and round-trip tests with inputs that cannot hide a bug. Floats are binary approximations with machine epsilon near $2.2\times10^{-16}$, so compare with tolerances. Know absolute versus relative error.
9. **Plotting.** Label axes with units. Draw data as markers and models as lines on a dense grid. Use residual panels, and remember that a log-log slope is the exponent of a power law.
10. **Numerical differentiation.** Forward differences are $O(h)$ and central differences are $O(h^2)$. The ratio of errors gives the order. Rounding error limits how small $h$ can usefully be, roughly $10^{-8}$ for forward and $10^{-5}$ for central differences.
11. **Numerical integration.** The trapezoid rule is $O(h^2)$ and Simpson's rule is $O(h^4)$ with an even number of intervals. $n$ intervals have $n+1$ nodes. Refine and watch the value settle.
12. **ODE stepping.** Euler's method is $y_{n+1} = y_n + h f(t_n, y_n)$ with global error $O(h)$. Treat position and velocity as a system. Compare with the exact solution on the same grid. For decay, stability needs $kh < 2$.

### Most common errors

- Using `^` for a power, or `=` where `==` is meant.
- Off-by-one mistakes in `range`, slices, `linspace` and quadrature nodes.
- Resetting an accumulator inside a loop, or printing where a function should return.
- Treating an alias or a NumPy view as a copy.
- Comparing computed floats with `==`.
- Comparing a simulation with the exact solution at different times, or trusting a result that no test has checked.

@exam num
prompt: A function and a loop simulate decay:
```python
def step(y, h):
    return y + h * (-3 * y)

y = 2.0
for i in range(4):
    y = step(y, 0.1)
```
The exact solution of $y' = -3y$, $y(0) = 2$, at $t = 0.4$ is $2e^{-1.2}$. How far is the value of `y` after the loop from this exact value? Give the absolute difference to four decimal places.
answer: 0.1222
check: (lambda s: abs(2 * math.exp(-1.2) - s(s, 0, 2.0)))(lambda s, i, y: y if i == 4 else s(s, i + 1, y + 0.1 * (-3 * y)))
tol: 0.0005
hint: Work out what one call of `step` does to `y`: it multiplies it by a constant.
hint: Each pass multiplies `y` by $1 - 3(0.1) = 0.7$, so after four passes `y` is $2 \times 0.7^4$.
solution: Each pass gives $y \leftarrow 0.7\,y$, so after four passes $y = 2 \times 0.7^4 = 0.4802$. The exact value is $2e^{-1.2} \approx 0.60239$. The difference is about $0.1222$. Euler undershoots because each step uses the slope at its start, which is steeper than the average slope over the step.

@exam tuple
prompt: Consider the arrays
```python
x = np.linspace(0, 2, 5)
y = x ** 3
```
(a) Estimate $\int_0^2 y\,dx$ with the trapezoid rule using all five nodes. (b) Estimate $dy/dx$ at $x = 1$ with the central difference that uses the neighbouring nodes $x = 0.5$ and $x = 1.5$. Enter the pair (trapezoid estimate, central difference).
lead: $(T, D) =$
answer: (4.25, 3.25)
check: (lambda y: (0.5 * (np.sum(y) - 0.5 * (y[0] + y[-1])), (y[3] - y[1]) / 1.0))(np.linspace(0, 2, 5) ** 3)
tol: 0.0001
hint: The nodes are $0, 0.5, 1, 1.5, 2$, so `y` is $0, 0.125, 1, 3.375, 8$.
hint: For (a), the width is $h = 0.5$ and the end values have weight one half. For (b), the denominator is $2h = 1$.
solution: (a) $T = 0.5\,[\tfrac12(0) + 0.125 + 1 + 3.375 + \tfrac12(8)] = 0.5 \times 8.5 = 4.25$. The exact integral is $4$, so the trapezoid rule overestimates for this convex function. (b) $D = (3.375 - 0.125)/(2 \times 0.5) = 3.25$. The exact derivative is $3$, and the error $0.25$ equals $\tfrac{h^2}{6} f''' = \tfrac{0.25}{6} \times 6$.

@exam self
prompt: The decay law $y' = -3y$, $y(0) = 2$ has the exact solution $y = 2e^{-3t}$. Write a complete script that does the following. (a) Defines `euler_decay(k, y0, T, n)`, which returns arrays `t` and `y` of length `n + 1`. (b) Defines `max_error(n)`, which compares the Euler solution on $0 \le t \le 1$ with the exact solution on the same grid and returns the largest absolute error. (c) Prints a table of `n`, `h`, the error and the observed order $\log_2(E_n/E_{2n})$ for `n = 10, 20, 40, 80`. (d) Includes two `assert` tests that do not use the exact solution. State what observed orders you expect.
hint: Use the loop pattern `y[i + 1] = y[i] + h * f(t[i], y[i])`, with $f = -k\,y$.
hint: Keep the errors in an array `errs`. Then `np.log2(errs[:-1] / errs[1:])` gives the observed orders for consecutive rows.
solution: One possible script:
```python
import numpy as np

def euler_decay(k, y0, T, n):
    """Euler solution of y' = -k y on [0, T] with n steps."""
    h = T / n
    t = np.linspace(0.0, T, n + 1)
    y = np.zeros(n + 1)
    y[0] = y0
    for i in range(n):
        y[i + 1] = y[i] + h * (-k * y[i])
    return t, y

def max_error(n):
    t, y = euler_decay(3.0, 2.0, 1.0, n)
    return np.abs(y - 2.0 * np.exp(-3.0 * t)).max()

t, y = euler_decay(3.0, 2.0, 1.0, 10)
assert len(y) == 11 and y[0] == 2.0               # n steps, n + 1 values
assert abs(y[1] - 2.0 * (1 - 3.0 * 0.1)) < 1e-12  # first step by hand: 1.4

ns = [10, 20, 40, 80]
errs = np.array([max_error(n) for n in ns])
orders = np.log2(errs[:-1] / errs[1:])
for j, n in enumerate(ns):
    p = orders[j - 1] if j > 0 else float("nan")
    print(n, 1.0 / n, errs[j], p)
```
The errors are about 0.127, 0.059, 0.028 and 0.014, and the observed orders are about 1.11, 1.05 and 1.02. They approach 1, as expected for a first-order method.
rubric: `euler_decay` applies the Euler update n times and returns arrays of length n + 1 that include the starting value.
rubric: `max_error` evaluates the exact solution on the same time array and takes the largest absolute difference.
rubric: The table prints n, h, the error and the observed order computed from consecutive rows.
rubric: At least two asserts do not depend on the exact solution, and the expected order is given as about 1 with the reason (first-order method).

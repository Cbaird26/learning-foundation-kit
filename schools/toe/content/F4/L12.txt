@article
Most laws of motion are **differential equations**: they say how a quantity changes, not what it is. An **initial value problem** gives the rule and a starting point:
$$\frac{dy}{dt} = f(t, y), \qquad y(t_0) = y_0.$$
Radioactive decay, for example, obeys $y' = -k\,y$, whose exact solution is $y = y_0 e^{-kt}$. Many equations have no formula for $y$, and then we step forward numerically.

### Euler's method

Follow the tangent line for a short time $h$, then look at the slope again:
$$y_{n+1} = y_n + h\,f(t_n, y_n), \qquad t_{n+1} = t_n + h.$$

```python
import numpy as np

def euler(f, y0, t0, t1, n):
    h = (t1 - t0) / n
    t = np.linspace(t0, t1, n + 1)     # n steps, n+1 times
    y = np.zeros(n + 1)
    y[0] = y0
    for i in range(n):
        y[i + 1] = y[i] + h * f(t[i], y[i])
    return t, y

t, y = euler(lambda t, y: -y, 1.0, 0.0, 1.0, 10)
print(y[-1])     # about 0.3487; the exact value is e**-1 = 0.3679
```

For $y' = -y$ each step multiplies $y$ by $1 - h$, so after $n$ steps $y_n = (1-h)^n$, and $0.9^{10} \approx 0.3487$.

### Error and order

Each step makes a *local* error of order $h^2$, the Taylor term $\tfrac{h^2}{2}y''$ that was dropped. Over about $1/h$ steps these add up to a *global* error of order $h$. Halve the step and the final error roughly halves. Euler's method is the forward difference of week 10 turned around. For decay with $h = 0.1$ the final error is $0.3679 - 0.3487 \approx 0.019$, and with $h = 0.05$ it is about $0.009$.

### Motion as a system

Newton's law is second order, $x'' = a$. Introduce the velocity $v = x'$ to get two first-order equations:
$$x' = v, \qquad v' = a(t, x, v).$$
Step both together, with the right-hand sides evaluated at the old values:

```python
x, v = x0, v0
for i in range(n):
    x, v = x + h * v, v + h * a(x, v)    # both use the old x and v
```

### Comparing with a known solution

A simulation you never compare with anything is only a picture. When an exact solution exists, evaluate it on the same time grid, form `err = np.abs(y_num - y_exact)`, report `err.max()`, plot both curves and the error, and then halve `h` to confirm that the error falls at the expected rate. When no exact solution exists, compare with a much finer run, or watch a quantity that should stay constant, such as the energy.

### Stability

For $y' = -k\,y$ Euler gives $y_{n+1} = (1 - kh)\,y_n$. If $kh > 2$ then $|1 - kh| > 1$, and the numerical solution grows and flips sign at every step, although the true solution decays smoothly. Keep $kh$ well below 1.

@example
title: Euler by hand
problem: Use Euler's method with $h = 0.25$ to approximate $y(0.5)$ for $y' = -2y$, $y(0) = 1$, and compare with the exact value.
step: The update is $y_{n+1} = y_n + 0.25\,(-2\,y_n) = 0.5\,y_n$.
step: First step: $y_1 = 0.5 \times 1 = 0.5$ at $t = 0.25$.
step: Second step: $y_2 = 0.5 \times 0.5 = 0.25$ at $t = 0.5$.
step: The exact solution is $e^{-2t}$, so $y(0.5) = e^{-1} \approx 0.3679$. The error is about $0.118$. The step is large, so the error is large. A smaller $h$ gives a better answer.

@example
title: A falling ball
problem: A ball is dropped from rest. Let $d$ be the distance fallen and $v$ the speed, so $d' = v$ and $v' = g$ with $g = 9.8\ \text{m/s}^2$ and $d(0) = v(0) = 0$. Use Euler's method with $h = 0.1$ s to find $d(1)$ and compare with the exact value $\tfrac12 g t^2 = 4.9$ m.
step: Each step adds $g h$ to the speed, so at step $i$ the speed is $v_i = g\,i\,h$.
step: The distance update uses the speed at the start of the step: $d_{i+1} = d_i + h\,v_i$. After 10 steps, $d_{10} = h \sum_{i=0}^{9} g\,i\,h = g h^2 (0 + 1 + \dots + 9) = 9.8 \times 0.01 \times 45 = 4.41$ m.
step: The exact value is $4.9$ m, so Euler is $0.49$ m too low. The speed at the start of each step is smaller than the average speed during it, so each step undercounts.
step: In general the error is $-\tfrac12 g\,h\,t$. With $h = 0.05$ it would be $-0.245$ m, half as large, which is the first-order behaviour expected.

@mistakes
- Comparing at the wrong times: the exact solution must be evaluated on the same time array `t` as the simulation.
- Using too large a step. For $y' = -ky$ a step with $kh > 2$ makes Euler blow up.
- Updating `x` with the already-updated `v` and not realising this is a different method from the one in the formula.
- Mixing up steps and points: $n$ steps produce $n + 1$ stored values, including the starting value.
- Keeping only the final value, which makes it impossible to plot or check the trajectory.

@practice self
prompt: A ball is thrown straight up at $20$ m/s from the ground. Take $g = 9.8\ \text{m/s}^2$. Write a program that simulates its height $x(t)$ for $0 \le t \le 2$ s with Euler's method (position and velocity updated together) using $h = 0.01$ s, compares it with the exact height $x = 20t - 4.9t^2$ on the same time grid, and prints the largest absolute error. Repeat with $h = 0.005$ and state what ratio of errors you expect.
hint: Store `x` and `v` in arrays of length `n + 1`, with `n = round(2 / h)`.
hint: Use `err = np.abs(x - exact).max()`. For this problem the Euler error is $\tfrac12 g\,h\,t$.
solution: One possible program:
```python
import numpy as np

g, v0, T = 9.8, 20.0, 2.0

def max_error(h):
    n = int(round(T / h))
    t = np.linspace(0.0, T, n + 1)
    x = np.zeros(n + 1)
    v = np.zeros(n + 1)
    v[0] = v0
    for i in range(n):
        x[i + 1] = x[i] + h * v[i]       # old velocity
        v[i + 1] = v[i] - h * g
    exact = v0 * t - 0.5 * g * t ** 2
    return np.abs(x - exact).max()

e1 = max_error(0.01)
e2 = max_error(0.005)
print(e1, e2, e1 / e2)      # about 0.098, 0.049, 2.0
```
The Euler error is $\tfrac12 g\,h\,t$, largest at $t = 2$: $0.098$ m for $h = 0.01$ and $0.049$ m for $h = 0.005$. The ratio is 2, which confirms first-order accuracy.

rubric: The exact solution is evaluated on the same time array as the simulation, and the largest absolute difference is reported.
rubric: The program is run for both step sizes and the ratio of the errors is computed.
rubric: The expected ratio is about 2, explained by first-order accuracy.

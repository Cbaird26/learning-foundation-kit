@article
Python is a calculator that can remember. You type an **expression**, Python **evaluates** it to a value, and you can store that value under a **name** (a *variable*) for later use. Everything in this course, from loops to simulating motion, is built from these two moves.

### Arithmetic operators

| operator | meaning | example | value |
|---|---|---|---|
| `+` `-` `*` | add, subtract, multiply | `2 + 3 * 4` | `14` |
| `/` | true division (always a float) | `7 / 2` | `3.5` |
| `//` | floor division | `7 // 2` | `3` |
| `%` | remainder | `7 % 2` | `1` |
| `**` | power | `2 ** 10` | `1024` |

Precedence matches algebra: `**` first, then `*` `/` `//` `%`, then `+` `-`. Parentheses override it. So `2 + 3 * 4 ** 2` means $2 + 3\cdot 16 = 50$. Note that `^` is **not** a power in Python.

### Variables are names, not equations

```python
g = 9.8          # m/s^2
t = 3.0          # s
d = 0.5 * g * t ** 2
print(d)         # 44.1
```

The sign `=` means *assign*: evaluate the right-hand side, then attach the name on the left to the result. That is why `x = x + 1` is legal even though $x = x + 1$ is false as an equation. It reads "take the current value of `x`, add 1, store it back in `x`." Statements run top to bottom, one at a time, and a name always holds its **latest** value.

### Types: int and float

Whole numbers such as `3` are `int`. Numbers with a decimal point or an exponent, such as `3.0` or `1.5e3` (that is $1.5\times 10^{3}$), are `float`. Mixing them gives a float. Floats are binary approximations to real numbers, so `0.1 + 0.2` prints `0.30000000000000004`. Week 8 studies this properly; for now, do not expect exact equality from decimal fractions.

### The math module

```python
import math
r = 2.0
area = math.pi * r ** 2
side = math.sqrt(area)
```

The module `math` provides `sqrt`, `sin`, `cos`, `exp`, `log` (the natural logarithm) and the constant `pi`. Trigonometric functions expect radians.

### Readable science code

Choose names that say what a quantity is (`speed_ms`, not `s`), record the unit in a comment, and give each constant one name instead of retyping the number. Code is read far more often than it is written, and the next reader is usually you.

@example
title: Free-fall distance and speed
problem: A stone is dropped from rest and falls for $t = 3.0$ s. Take $g = 9.8\ \text{m/s}^2$ and use Python to find the distance fallen, $d = \tfrac{1}{2} g t^2$, and the speed reached, $v = g t$.
step: Give each quantity one name and note its unit: `g = 9.8` (m/s^2) and `t = 3.0` (s).
step: Translate the distance formula, writing the square with `**`: `d = 0.5 * g * t ** 2`. Because `**` binds tighter than `*`, only `t` is squared, exactly as in the formula.
step: The speed is `v = g * t`.
step: Print rounded values with `print(round(d, 1), round(v, 1))`. This shows `44.1 29.4`. By hand: $\tfrac{1}{2}(9.8)(9) = 44.1$ m and $9.8 \times 3 = 29.4$ m/s, so the program agrees.

@example
title: Tracing variable updates
problem: Work out by hand what this program prints, then confirm each line.
```python
x = 4
y = x + 1
x = x * y
y = x - y
print(x, y)
```
step: After line 1, `x` is 4. After line 2, `y` is 5.
step: Line 3 evaluates the right side with the current values: `x * y` is 20, and that becomes the new `x`.
step: Line 4 uses the new `x`: `y = 20 - 5 = 15`.
step: The program prints `20 15`. Keeping a small table of `x` and `y` after every line is the surest way to trace a program.

@mistakes
- Writing `^` for a power. In Python it is bitwise XOR, so `2 ^ 3` gives `1`, not `8`. Use `**`.
- Reading `=` as a claim of equality. It is an instruction: evaluate the right-hand side, then store the result.
- Expecting `/` to return a whole number: `6 / 3` is `2.0`, a float. Use `//` when you want floor division.
- Dropping parentheses: `a + b / 2` is $a + b/2$, not $(a+b)/2$.

@practice num
prompt: What number does `-17 // 5` produce?
answer: -4
check: -17 // 5
hint: First compute the true quotient $-17/5$.
hint: Floor division rounds down to the next integer below the quotient, not toward zero.
solution: $-17/5 = -3.4$, and rounding down (toward negative infinity) gives $-4$. So `-17 // 5` is `-4`. Consistency check: `-4 * 5 + 3 = -17`, and `-17 % 5` is `3`.

@practice self
prompt: Write a short program that converts a speed of $72$ km/h to m/s. Store the conversion constants in named variables, store the result in a variable called `speed_ms`, and print it. Add a comment giving the unit of every variable.
hint: There are $1000$ m in a kilometre and $3600$ s in an hour.
hint: A speed in km/h is multiplied by metres-per-km and divided by seconds-per-hour.
solution: One possible program:
```python
metres_per_km = 1000.0       # m/km
seconds_per_hour = 3600.0    # s/h
speed_kmh = 72.0             # km/h
speed_ms = speed_kmh * metres_per_km / seconds_per_hour   # m/s
print(speed_ms)              # 20.0
```
rubric: Every quantity has a descriptive name and no unexplained number is retyped in the final formula.
rubric: The arithmetic multiplies by 1000 and divides by 3600 (not the reverse).
rubric: Running the program prints 20.0.
rubric: Each variable's unit appears in a comment.

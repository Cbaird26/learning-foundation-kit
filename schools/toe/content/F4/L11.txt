@article
An integral $\int_a^b f(x)\,dx$ is the area under a curve. To compute it numerically, cut $[a, b]$ into $n$ equal **subintervals** of width $h = (b - a)/n$, with nodes $x_i = a + ih$ for $i = 0, 1, \dots, n$. Then approximate the area of each strip. Note that $n$ subintervals have $n + 1$ nodes.

### The rules

$$\text{left: } h\sum_{i=0}^{n-1} f(x_i), \qquad \text{midpoint: } h\sum_{i=0}^{n-1} f\!\left(x_i + \tfrac{h}{2}\right).$$

$$\text{trapezoid: } h\Big[\tfrac12 f_0 + f_1 + \cdots + f_{n-1} + \tfrac12 f_n\Big].$$

$$\text{Simpson } (n \text{ even}): \ \tfrac{h}{3}\big[f_0 + 4f_1 + 2f_2 + 4f_3 + \cdots + 2f_{n-2} + 4f_{n-1} + f_n\big].$$

Here $f_i = f(x_i)$. The trapezoid rule replaces the curve in each strip with a straight line. Simpson's rule uses a parabola through three consecutive nodes, which is why $n$ must be even and why the weights alternate $4, 2, 4, 2, \dots$.

### Implementation

```python
import numpy as np

def trapezoid(f, a, b, n):
    x = np.linspace(a, b, n + 1)       # n+1 nodes
    y = f(x)
    h = (b - a) / n
    return h * (y.sum() - 0.5 * (y[0] + y[-1]))

def simpson(f, a, b, n):               # n must be even
    x = np.linspace(a, b, n + 1)
    y = f(x)
    h = (b - a) / n
    return h / 3 * (y[0] + y[-1] + 4 * y[1:-1:2].sum() + 2 * y[2:-1:2].sum())
```

The slice `y[1:-1:2]` picks the odd-numbered nodes $f_1, f_3, \dots$ and `y[2:-1:2]` the even interior nodes. NumPy has a built-in trapezoid function (named `np.trapz` in older versions and `np.trapezoid` in recent ones), but writing it once yourself shows exactly what it does.

### Accuracy

For a smooth function the errors behave like a power of $h$:

| rule | error | halving $h$ divides the error by |
|---|---|---|
| left or right | $O(h)$ | about 2 |
| midpoint, trapezoid | $O(h^2)$ | about 4 |
| Simpson | $O(h^4)$ | about 16 |

The trapezoid rule is exact for straight lines, and Simpson's rule is exact for polynomials up to degree 3. The midpoint error is about half the trapezoid error and has the opposite sign for a curve that bends one way.

### Check your integrals

Always test on integrals you know: $\int_0^1 x^2\,dx = \tfrac13$, $\int_0^\pi \sin x\,dx = 2$. Then run with $n$, $2n$, $4n$ and watch the results settle. A value you computed at one $n$ cannot tell you how accurate it is.

@example
title: Trapezoid and Simpson on a parabola
problem: Approximate $\int_0^1 x^2\,dx = \tfrac13$ with the trapezoid rule and with Simpson's rule, both with $n = 4$.
step: The width is $h = 1/4 = 0.25$ and the nodes are $0, 0.25, 0.5, 0.75, 1$. The function values are $0,\ 0.0625,\ 0.25,\ 0.5625,\ 1$.
step: Trapezoid: $0.25\,[\tfrac12(0) + 0.0625 + 0.25 + 0.5625 + \tfrac12(1)] = 0.25 \times 1.375 = 0.34375$. The error is about $0.0104$, which matches $\tfrac{(b-a)h^2}{12} f'' = \tfrac{0.0625}{12} \cdot 2 \approx 0.0104$.
step: Simpson: $\tfrac{0.25}{3}\,[0 + 4(0.0625) + 2(0.25) + 4(0.5625) + 1] = \tfrac{0.25}{3} \times 4 = \tfrac13$.
step: Simpson's rule is exact here because $x^2$ is a polynomial of degree at most 3. The trapezoid rule is not exact for a curved function.

@example
title: A convergence study
problem: Apply the trapezoid rule to $\int_0^\pi \sin x\,dx = 2$ with $n = 4$ and $n = 8$, and estimate the order of the rule from the two errors.
step: For $n = 4$, $h = \pi/4$ and the interior values $\sin(\pi/4), \sin(\pi/2), \sin(3\pi/4)$ add to $2.4142$. The end values are 0. The result is $\tfrac{\pi}{4} \times 2.4142 \approx 1.8961$, so the error is about $0.1039$.
step: For $n = 8$, $h = \pi/8$ and the seven interior values add to $5.0273$, giving $\tfrac{\pi}{8} \times 5.0273 \approx 1.9742$ with error about $0.0258$.
step: The ratio of errors is $0.1039 / 0.0258 \approx 4.03$.
step: Doubling $n$ cut the error by about $4 = 2^2$, so the trapezoid rule is second order, as the table in the article says.

@mistakes
- Fencepost errors: $n$ subintervals have $n + 1$ nodes, not $n$. Use `np.linspace(a, b, n + 1)`.
- Giving the two end values of the trapezoid rule full weight instead of one half.
- Using Simpson's rule with an odd number of subintervals.
- Returning the bare sum and forgetting the factor $h$ (or $h/3$).
- Trusting a single $n$. Refine and check that the answer settles.

@practice num
prompt: Use the left Riemann sum with $n = 4$ subintervals to approximate $\int_0^2 x^2\,dx$.
answer: 1.75
check: (lambda f: 0.5 * sum(f(0.5 * i) for i in range(4)))(lambda x: x ** 2)
hint: The width is $h = (2 - 0)/4 = 0.5$. The left endpoints are $0, 0.5, 1, 1.5$.
solution: The sum of $f$ at the left endpoints is $0 + 0.25 + 1 + 2.25 = 3.5$, and multiplying by $h = 0.5$ gives $1.75$. The exact integral is $8/3 \approx 2.667$. The left sum is too low because $x^2$ is increasing.

@practice num
prompt: Apply the trapezoid rule with $n = 2$ subintervals to $\int_1^3 (2x + 1)\,dx$.
answer: 10
check: (lambda f: 1.0 * (f(1) / 2 + f(2) + f(3) / 2))(lambda x: 2 * x + 1)
hint: The width is $h = 1$ and the nodes are $1, 2, 3$.
solution: The values are $f(1) = 3$, $f(2) = 5$, $f(3) = 7$. The rule gives $1\,[\tfrac12(3) + 5 + \tfrac12(7)] = 10$. This is exact, because the trapezoid rule integrates straight lines exactly.

@practice num
prompt: Apply Simpson's rule with $n = 2$ subintervals to $\int_0^2 x^3\,dx$.
answer: 4
check: (lambda f: (1.0 / 3) * (f(0) + 4 * f(1) + f(2)))(lambda x: x ** 3)
hint: The width is $h = 1$ and the nodes are $0, 1, 2$. The weights are $1, 4, 1$.
solution: $\tfrac{1}{3}\,[0 + 4(1) + 8] = \tfrac{12}{3} = 4$. This equals the exact value $\tfrac{2^4}{4} = 4$, because Simpson's rule is exact for cubics.

@practice self
prompt: Write a function `midpoint(f, a, b, n)` that returns the midpoint-rule approximation of $\int_a^b f(x)\,dx$ using NumPy and no explicit loop. Then use it on $\int_0^\pi \sin x\,dx = 2$ with $n = 10$ and $n = 20$, and say what ratio of errors you expect.
hint: The midpoints of the $n$ strips are $a + h/2,\ a + 3h/2,\ \dots$. Build them with `a + h * (np.arange(n) + 0.5)`.
hint: Compute the error as the absolute value of the difference from 2 for each $n$, then divide the two errors.
solution: One possible program:
```python
import numpy as np

def midpoint(f, a, b, n):
    h = (b - a) / n
    x = a + h * (np.arange(n) + 0.5)     # centres of the n strips
    return h * f(x).sum()

e10 = abs(midpoint(np.sin, 0, np.pi, 10) - 2)
e20 = abs(midpoint(np.sin, 0, np.pi, 20) - 2)
print(e10, e20, e10 / e20)
```
The errors are about 0.0082 and 0.0021, so the ratio is about 4, which shows second-order accuracy.
rubric: The function computes n midpoints (not n + 1 nodes) and multiplies the sum by h.
rubric: The code uses array operations rather than an explicit loop.
rubric: Errors are computed against the exact value 2 for both values of n.
rubric: The learner expects a ratio near 4 and explains it as second-order accuracy.

@quiz num
prompt: Use the trapezoid rule with $n = 2$ subintervals to approximate $\int_0^1 e^x\,dx$. Give the value to four decimal places.
answer: 1.7539
check: 0.5 * (math.exp(0) / 2 + math.exp(0.5) + math.exp(1) / 2)
tol: 0.0005
hint: The width is $h = 0.5$ and the nodes are $0, 0.5, 1$.
hint: Compute $e^0 = 1$, $e^{0.5} \approx 1.64872$ and $e^1 \approx 2.71828$, and weight the ends by one half.
solution: $0.5\,[\tfrac12(1) + 1.64872 + \tfrac12(2.71828)] = 0.5 \times 3.50786 \approx 1.7539$. The exact value is $e - 1 \approx 1.7183$, so the trapezoid rule overestimates for this convex function.

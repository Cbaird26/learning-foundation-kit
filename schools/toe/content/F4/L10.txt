@article
The derivative $f'(x)$ is the limit of a slope. A computer cannot take a limit, but it can compute a slope over a small step $h$. That is a **finite difference**.

### Three formulas

$$\text{forward: } \frac{f(x+h) - f(x)}{h}, \qquad \text{backward: } \frac{f(x) - f(x-h)}{h}, \qquad \text{central: } \frac{f(x+h) - f(x-h)}{2h}.$$

```python
import math

def forward_diff(f, x, h):
    return (f(x + h) - f(x)) / h

def central_diff(f, x, h):
    return (f(x + h) - f(x - h)) / (2 * h)

print(central_diff(math.sin, 1.0, 0.1))     # about 0.5394
```

Notice that `f` is itself an argument. A function can be passed to another function.

### How accurate? Use Taylor series

Expand about $x$:
$$f(x+h) = f(x) + h f'(x) + \tfrac{h^2}{2} f''(x) + \tfrac{h^3}{6} f'''(x) + \cdots$$
Rearranging gives, for the forward difference,
$$\frac{f(x+h) - f(x)}{h} = f'(x) + \tfrac{h}{2} f''(x) + \cdots$$
so its **truncation error** is about $\tfrac{h}{2} f''(x)$. It is proportional to $h$: the method is *first order*. In the central difference the $f''$ terms of the two expansions cancel, leaving an error of about $\tfrac{h^2}{6} f'''(x)$. It is proportional to $h^2$: the method is *second order*. Halving $h$ halves a forward error but quarters a central error.

### Estimating the order from data

If the error is about $C h^p$, then the errors at step sizes $h$ and $h/2$ have ratio $2^p$. So $p \approx \log_2(\text{ratio})$. A table of errors at $h = 10^{-1}, 10^{-2}, \dots$, or a log-log plot of error against $h$ whose slope is $p$, is the standard test of an implementation.

### Rounding error fights back

Computed values of $f$ carry errors near $\epsilon\,|f|$, where $\epsilon \approx 2.2\times 10^{-16}$. The numerator $f(x+h) - f(x)$ subtracts nearly equal numbers, so its relative error grows, and dividing by the tiny $h$ magnifies it to about $\epsilon |f|/h$. The total error is truncation error (which falls with $h$) plus rounding error (which grows as $h$ falls). On a log-log plot this makes a V shape. The best $h$ is near $10^{-8}$ for the forward difference and near $10^{-5}$ for the central difference. Below that, accuracy gets worse again. Shrinking $h$ without limit is not the answer.

@example
title: Forward and central differences for sin
problem: Estimate $f'(1)$ for $f(x) = \sin x$ with $h = 0.1$ using the forward and central differences, and compare with the exact value $\cos 1 \approx 0.540302$.
step: Collect the function values: $\sin 0.9 \approx 0.783327$, $\sin 1 \approx 0.841471$, $\sin 1.1 \approx 0.891207$.
step: Forward: $(0.891207 - 0.841471)/0.1 \approx 0.49736$. The error is $0.540302 - 0.497364 \approx 0.0429$.
step: Central: $(0.891207 - 0.783327)/0.2 \approx 0.53940$. The error is $0.540302 - 0.539402 \approx 0.0009$.
step: Compare with the predictions. Forward: $\tfrac{h}{2}|f''(1)| = 0.05 \sin 1 \approx 0.042$. Central: $\tfrac{h^2}{6}|f'''(1)| = \tfrac{0.01}{6}\cos 1 \approx 0.0009$. Both match, and the central difference is about 48 times more accurate for the same two function evaluations.

@example
title: Estimating the order of accuracy
problem: For the forward difference of $\sin x$ at $x = 1$, the errors are $4.294 \times 10^{-2}$ for $h = 0.1$ and $2.126 \times 10^{-2}$ for $h = 0.05$. Estimate the order $p$.
step: Form the ratio of the errors: $4.294 / 2.126 \approx 2.02$.
step: Halving $h$ should multiply the error by $2^{-p}$, so the ratio of the larger error to the smaller one is $2^p \approx 2.02$.
step: Then $p \approx \log_2 2.02 \approx 1.01$, which rounds to 1: the method is first order, as the Taylor analysis predicted.
step: A central difference would show errors of about $9.0 \times 10^{-4}$ and $2.25 \times 10^{-4}$. Their ratio is about 4, which gives $p = 2$.

@mistakes
- Forgetting the factor 2 in the central difference denominator, $2h$.
- Believing that a smaller $h$ is always better. Below about $10^{-8}$ rounding error dominates and accuracy falls.
- Using an `h` so large that the step spans a feature of the function, so the Taylor argument no longer applies.
- Comparing errors at only one step size. One value cannot show the order of the method.

@practice self
prompt: Write a program that compares finite differences at several step sizes. For $f(x) = \sin x$ at $x = 1$, compute the forward and central difference estimates for $h = 10^{-1}, 10^{-2}, \dots, 10^{-10}$, print a table of the absolute errors against the exact derivative $\cos 1$, and say what pattern the table should show.
hint: Loop over `k` from 1 to 10 and set `h = 10.0 ** (-k)`. Use `math.cos(1.0)` as the exact value.
hint: Look at how the error changes from one row to the next, first for large `h` and then for very small `h`.
solution: One possible program:
```python
import math

exact = math.cos(1.0)
print("      h    forward err   central err")
for k in range(1, 11):
    h = 10.0 ** (-k)
    fwd = (math.sin(1.0 + h) - math.sin(1.0)) / h
    cen = (math.sin(1.0 + h) - math.sin(1.0 - h)) / (2 * h)
    print(f"{h:8.0e} {abs(fwd - exact):13.3e} {abs(cen - exact):13.3e}")
```
For large `h` the forward error falls about tenfold per row (first order) and the central error about a hundredfold (second order). The forward error is smallest, a few times $10^{-9}$, near $h = 10^{-8}$, and then it grows again because of rounding error. The central error is smallest, about $10^{-11}$, near $h = 10^{-5}$ to $10^{-6}$, and then it grows too.

@quiz mc
prompt: In an experiment you shrink $h$ from $10^{-4}$ to $10^{-14}$ in a forward difference of a smooth function, and the error first falls and then rises. What causes the rise?
choice*: $f(x+h)$ and $f(x)$ agree in almost all their digits, so their difference has few correct digits, and dividing by the tiny $h$ magnifies that error.
choice: The Taylor series stops converging when $h$ is smaller than $10^{-8}$.
choice: The truncation error grows as $h$ gets smaller.
choice: Python's division is inaccurate whenever the denominator is below $10^{-10}$.
hint: Think about the numerator $f(x+h) - f(x)$ when $h$ is very small.
solution: For tiny $h$ the two function values are nearly equal, so their difference suffers cancellation: most leading digits vanish and only rounding noise remains. Dividing by $h$ multiplies that noise by $1/h$. The truncation error still falls with $h$, but the rounding term grows faster.

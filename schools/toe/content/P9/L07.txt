@article
Many laboratory systems are described by an **initial value problem**, $\dot{\mathbf y} = \mathbf f(t,\mathbf y)$ with $\mathbf y(t_0)$ given. Pendulums, circuits and falling bodies with drag rarely have closed-form solutions, so we step forward in time numerically.

### Euler's method

Replace the derivative by a finite step $h$:

$$\mathbf y_{n+1} = \mathbf y_n + h\,\mathbf f(t_n,\mathbf y_n).$$

It is easy and rarely good enough. The error made in one step is $O(h^2)$, and over a fixed time interval these add up to a **global error** of $O(h)$: halving $h$ halves the error.

### Better steps

The **midpoint** method (second-order Runge-Kutta) samples the slope halfway across the step:

$$\mathbf k_1 = \mathbf f(t_n,\mathbf y_n),\quad \mathbf k_2 = \mathbf f\!\left(t_n+\tfrac h2,\ \mathbf y_n+\tfrac h2 \mathbf k_1\right),\quad \mathbf y_{n+1} = \mathbf y_n + h\,\mathbf k_2 .$$

Its global error is $O(h^2)$: halving $h$ quarters the error. The classical **fourth-order Runge-Kutta** method (RK4) uses four slope evaluations per step and has global error $O(h^4)$: halving $h$ divides the error by $16$.

### Second-order equations

Write the equation as a first-order system. A mass on a spring with damping, $m\ddot x = -kx - b\dot x$, becomes, with $v = \dot x$,

$$\dot x = v, \qquad \dot v = -\frac{k}{m}x - \frac{b}{m}v .$$

### Checking a simulation

A simulation that runs is not a simulation that is right. Check it against (1) an exact solution in a special case, (2) a conserved quantity, such as the energy of an undamped oscillator, and (3) the expected error scaling when $h$ changes. Forward Euler on an undamped oscillator multiplies $x^2 + v^2/\omega^2$ by $1 + h^2\omega^2$ at every step, so the amplitude grows steadily: a numerical artifact, not physics.

```python
import numpy as np
from scipy.integrate import solve_ivp

def rhs(t, y):                       # y = [x, v], omega = 1
    return [y[1], -y[0]]

def euler(f, y0, t0, t1, h):
    y, t = np.array(y0, float), t0
    for _ in range(round((t1 - t0) / h)):
        y = y + h * np.array(f(t, y))   # both components use the old y
        t += h
    return y

print(euler(rhs, [1.0, 0.0], 0.0, 10.0, 0.01))
sol = solve_ivp(rhs, (0, 10), [1.0, 0.0], rtol=1e-10, atol=1e-12)
print(sol.y[:, -1], np.cos(10.0), -np.sin(10.0))
```

The reference from `solve_ivp` agrees with the exact $x=\cos t$, $v=-\sin t$ to about ten digits, while Euler's amplitude is about $5\%$ too large, as the energy formula predicts.

@example
title: Euler against midpoint on a decay equation
problem: Solve $y' = -2y$, $y(0) = 1$ with step $h = 0.1$, and compare forward Euler and the midpoint method with the exact solution $y = e^{-2t}$.
step: The exact value after one step is $y(0.1) = e^{-0.2} = 0.81873$.
step: Euler: $y_1 = 1 + 0.1(-2) = 0.800$. The error is $0.0187$.
step: Midpoint: $k_1 = -2$, so the midpoint value is $1 + 0.05(-2) = 0.9$ and $k_2 = -2(0.9) = -1.8$. Then $y_1 = 1 + 0.1(-1.8) = 0.820$, with error $0.0013$.
step: Five steps reach $t = 0.5$, where $e^{-1} = 0.3679$. Euler gives $0.8^5 = 0.3277$ (error $0.040$) and the midpoint method gives $0.82^5 = 0.3707$ (error $0.0029$).
step: The midpoint method costs two slope evaluations per step but is about fourteen times more accurate here; Euler would need a step about fourteen times smaller to match it.

@mistakes
- Updating $x$ first and then using the new $x$ in the update of $v$ when you meant plain Euler, which uses the old values of both.
- Believing a simulation is right because it ran without an error message, with no check against an exact solution or a conserved quantity.
- Mixing up local and global error: Euler's error per step is $O(h^2)$ but its error over a fixed interval is $O(h)$.
- Hoping a smaller step will fix an error in the model itself.

@practice mc
prompt: A mass $m$ on a spring with constant $k$ and linear damping $b$ obeys $m\ddot x = -kx - b\dot x$. With $v = \dot x$, which first-order system is correct?
choice*: $\dot x = v,\ \ \dot v = -\dfrac{k}{m}x - \dfrac{b}{m}v$
choice: $\dot x = v,\ \ \dot v = \dfrac{k}{m}x + \dfrac{b}{m}v$
choice: $\dot x = v,\ \ \dot v = -kx - bv$
choice: $\dot x = -\dfrac{k}{m}x,\ \ \dot v = -\dfrac{b}{m}v$
hint: Divide the original equation by $m$ and solve for $\ddot x$.
hint: The first equation of the system just defines $v$.
solution: Dividing by $m$ gives $\ddot x = -(k/m)x - (b/m)\dot x$. Writing $\ddot x = \dot v$ and $\dot x = v$ gives $\dot v = -\frac km x - \frac bm v$. The system with $+\frac km x + \frac bm v$ has sign errors, the system with $-kx - bv$ forgets the mass, and the system with $\dot x = -\frac km x$ and $\dot v = -\frac bm v$ does not couple $x$ and $v$.

@quiz num

check: (lambda f: f(f, 0, 1.0, 0.0))(lambda s, n, x, v: 0.5 * (x * x + v * v) if n == 2 else s(s, n + 1, x + 0.1 * v, v + 0.1 * (-x)))

hint: Both components must be updated from the old values of $x$ and $v$.
hint: After step 1, $x = 1$ and $v = -0.1$.

@quiz mc
prompt: A frictionless oscillator simulated with forward Euler shows an amplitude that grows steadily with time. What is the best explanation and remedy?
choice: Undamped oscillators really do gain energy; no remedy is needed.
choice*: Euler's truncation error adds energy at every step; use a smaller $h$ or a higher-order method such as RK4.
choice: Floating-point round-off; switch to higher precision.
choice: The initial conditions are wrong; start from $v = 0$ instead.
hint: Look at how the energy changes by a fixed factor at every step.
hint: The growth follows the formula $E_n = E_0(1+h^2\omega^2)^n$, which depends on $h$.
solution: The growth factor per step depends on $h$, so it is a property of the method (truncation error), not of the physics or of round-off. Reducing $h$ or using RK4 shrinks the artifact. It never disappears completely, so a long run still needs a conservation check.

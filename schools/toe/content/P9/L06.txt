@article
A measured difference means something only if nothing else changed. **Controls** are the design features that make that claim defensible.

### Controlled variables and control runs

- A **controlled variable** is held fixed on purpose: pendulum length, release angle, the stopwatch, the person timing. Change one thing at a time.
- A **blank** or **background run** measures the apparatus with the thing under test absent, such as a scale with an empty pan or a light sensor with the lamp off. Subtract it and add its uncertainty in quadrature.
- A **known-standard run** measures something whose answer you already know, such as a 100 g reference mass. If your procedure cannot reproduce the known answer, do not trust it on the unknown.
- **Replicates** repeat a setting several times to measure the scatter.

### Randomization and drift

Batteries sag, rooms warm and you get tired. If you measure all of condition A and then all of condition B, a slow drift looks like an effect of A against B. **Randomize** the run order, or interleave A and B, and use **paired comparisons** in which each A has a neighboring B so that drift cancels in the difference.

```python
import numpy as np

rng = np.random.default_rng(2025)
order = rng.permutation(["A"] * 5 + ["B"] * 5)
print(order)
```

Write the seed in the notebook so the order can be regenerated.

### Is the difference real?

For two conditions with means $\bar x_A,\bar x_B$ and standard uncertainties $u_A,u_B$, compute

$$z = \frac{\bar x_A - \bar x_B}{\sqrt{u_A^2 + u_B^2}}.$$

If $|z|$ is below about $2$ the data show no resolvable difference. If it is above about $3$ the difference is very unlikely to be chance. "No resolvable difference" is not "no effect": it means any effect is smaller than your sensitivity, and you should state that sensitivity.

With $N$ replicates per condition and single-run scatter $\sigma$, the uncertainty of the difference is $\sigma\sqrt{2/N}$. Setting a target $z$ and solving for $N$ tells you how many runs a given difference needs.

### Provenance

**Provenance** records where each number came from: who measured it, when, with which instrument and settings, and which script made any derived file. Keep raw files read-only and put a small metadata file beside each:

```python
import json, hashlib

raw = open("pendulum_run1.csv", "rb").read()
meta = {"operator": "initials", "date": "2025-03-02",
        "instrument": "phone stopwatch, 0.01 s display",
        "sha256": hashlib.sha256(raw).hexdigest()}
json.dump(meta, open("pendulum_run1.meta.json", "w"), indent=2)
```

The checksum lets anyone confirm later that the file is unchanged.

@example
title: Does the period depend on the bob mass?
problem: Two bobs of different mass hang from the same $0.500$ m string, released from $10^\circ$ and timed by the same person with the same method, with runs interleaved A, B, A, B. The light bob gave $T_A = 1.432 \pm 0.004$ s and the heavy bob $T_B = 1.440 \pm 0.005$ s (supplied, illustrative data; each is a mean with its standard error). Decide whether the data show a mass dependence.
step: List the controls: length, release angle, timer, operator and run order pattern are all the same, and only the bob mass changes.
step: The difference is $\Delta T = 1.440 - 1.432 = 0.008$ s.
step: Its uncertainty is $\sqrt{0.004^2 + 0.005^2} = 0.0064$ s.
step: $z = 0.008/0.0064 = 1.25$, below $2$, so there is no resolvable difference.
step: State the sensitivity: the data exclude a mass effect larger than about $2 \times 0.0064 = 0.013$ s, roughly $0.9\%$ of the period. They do not prove that there is no effect at all.

@mistakes
- Changing two things at once, such as a heavier bob on a longer string.
- Measuring all of A and then all of B, so that drift is confounded with the effect.
- Reading "no resolvable difference" as proof of no effect without stating the sensitivity.
- Subtracting a blank but leaving its uncertainty out of the result.

@practice num
prompt: A repeated measurement gives $9.84 \pm 0.06$ m/s² for condition A and $9.62 \pm 0.08$ m/s² for condition B (supplied, illustrative values; uncertainties are standard errors). Find $z$.
answer: 2.2
check: (9.84 - 9.62) / math.hypot(0.06, 0.08)
tol: 0.02
hint: The numerator is the difference of the means.
hint: The denominator is the quadrature sum $\sqrt{0.06^2 + 0.08^2}$.
solution: $z = 0.22/\sqrt{0.0036 + 0.0064} = 0.22/0.10 = 2.2$. This is borderline: a difference may be present, so the experiment should be repeated or extended.

prompt: A light sensor reads $105.0 \pm 3.0$ lux with the sample in place and $12.0 \pm 4.0$ lux with the lamp off (blank), supplied illustrative values. The net signal is the difference. Find the standard uncertainty of the net signal.
answer: 5.0
check: math.hypot(3.0, 4.0)

@practice num
prompt: Five paired runs (A and B taken one after the other, so slow drift cancels) gave differences $A - B = 0.12, 0.08, 0.15, 0.10, 0.05$ (supplied, illustrative values). Divide the mean difference by its standard error to get a signal-to-noise ratio. Round to one decimal place.
answer: 5.9
check: np.mean([0.12, 0.08, 0.15, 0.10, 0.05]) / (np.std([0.12, 0.08, 0.15, 0.10, 0.05], ddof=1) / np.sqrt(5))
tol: 0.1
hint: Treat the five differences as one set of repeated readings.
hint: The mean is $0.10$; find the sample standard deviation and divide by $\sqrt 5$.
solution: The mean is $0.10$. The squared deviations sum to $0.0058$, so $s = \sqrt{0.0058/4} = 0.0381$ and the standard error is $0.0381/\sqrt 5 = 0.0170$. The ratio is $0.10/0.0170 = 5.9$, a clear difference.

@quiz num
prompt: Single-run timings have a scatter of $\sigma = 0.06$ s. You want to detect a true difference of $0.05$ s between two conditions at $z = 3$, using the same number $N$ of runs per condition. What is the smallest $N$?
answer: 26
check: math.ceil(round(2 * (3 * 0.06 / 0.05)**2, 9))
hint: The difference of two means has standard uncertainty $\sigma\sqrt{2/N}$.
hint: Require $0.05/(\sigma\sqrt{2/N}) \ge 3$ and solve for $N$.
solution: $N \ge 2(3\sigma/0.05)^2 = 2(0.18/0.05)^2 = 2(3.6)^2 = 25.92$, so $N = 26$ runs per condition.

@quiz num
prompt: A scale reads $0.0$ g unloaded at the start of a session and $0.6$ g unloaded $60$ minutes later; assume the drift is linear in time. A sample reads $250.8$ g at minute $20$. What is the drift-corrected mass?
answer: 250.6
check: 250.8 - 0.6 * 20 / 60
tol: 0.05
unit: g
hint: Find the zero offset that the scale has at minute $20$.
hint: The drift accumulates at $0.6/60$ g per minute.
solution: At minute $20$ the zero has drifted by $0.6 \times 20/60 = 0.2$ g, so the corrected mass is $250.8 - 0.2 = 250.6$ g.

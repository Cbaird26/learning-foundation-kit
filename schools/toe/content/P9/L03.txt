@article
An instrument does not report the quantity itself; it reports a number related to the quantity. **Calibration** measures that relation by comparing the instrument's readings $y$ with **reference standards** whose true values $x$ are known far better, and then uses the relation to correct later readings.

### Two systematic errors

A kitchen scale might read $1\ \text{g}$ with nothing on it (an **offset**, or zero error) and show $202\ \text{g}$ for a true $200\ \text{g}$ (a **gain**, or scale error). A straight line captures both:

$$y = a + b\,x,$$

where $a$ is the offset and $b$ is the gain. A perfect instrument has $a = 0$ and $b = 1$. Calibration removes these *systematic* errors. It cannot remove random scatter, which you still average down by repeating.

### Fit the line

Least squares chooses $a$ and $b$ to minimize $\sum_i (y_i - a - b x_i)^2$. The result is

$$b = \frac{\sum_i (x_i-\bar x)(y_i-\bar y)}{\sum_i (x_i-\bar x)^2}, \qquad a = \bar y - b\,\bar x.$$

### Use the line backwards

Later you read $y$ and want the true $x$, so invert the calibration:

$$x = \frac{y - a}{b}.$$

### Plan the calibration

- Use references several times better than the instrument; a factor of 3 to 10 is a common rule of thumb.
- Spread five or more points evenly across the **whole working range**, including near zero.
- Go up and then down. A difference between the two directions is **hysteresis**, a separate error.
- Do not extrapolate: the line has only been tested where you have points.
- Keep the raw calibration data with date and conditions, and recalibrate after the instrument is moved, repaired or left unused for a long time.

### In code

```python
import numpy as np

x = np.array([0, 50, 100, 150, 200, 250.0])   # true mass, g (reference masses)
y = np.array([1, 52, 102, 152, 203, 254.0])   # scale reading, g
b, a = np.polyfit(x, y, 1)                    # slope first, intercept second
print(f"y = {a:.2f} + {b:.4f} x")

def correct(reading):
    return (reading - a) / b

print(correct(100.0))
```

Notice that `np.polyfit` returns the highest power first. Plot `y` against `x` with the fitted line before trusting any number it prints.

@example
title: Calibrating a kitchen scale (supplied data)
problem: A kitchen scale was checked against reference masses (supplied, illustrative data). True masses $x = 0, 50, 100, 150, 200, 250$ g gave readings $y = 1, 52, 102, 152, 203, 254$ g. Find the calibration line and the true mass when the scale reads $100.0$ g.
step: The means are $\bar x = 125$ g and $\bar y = 764/6 = 127.33$ g.
step: The sums are $\sum (x_i - \bar x)^2 = 43\,750\ \text{g}^2$ and $\sum (x_i - \bar x)(y_i - \bar y) = 44\,200\ \text{g}^2$.
step: The gain is $b = 44\,200/43\,750 = 1.0103$, and the offset is $a = 127.333 - 1.01029 \times 125 = 1.05$ g.
step: Invert for a reading of $100.0$ g: $x = (100.0 - 1.05)/1.0103 = 97.9$ g.
step: Without calibration you would have recorded $100.0$ g for an object of $97.9$ g, a $2\%$ error that no amount of averaging would remove.

@mistakes
- Calibrating at one point near full scale and assuming the zero is correct.
- Applying the line the wrong way round, computing $a + b y$ instead of $(y - a)/b$ for a corrected value.
- Using the calibration far outside the range of the reference masses.
- Keeping the fitted $a$ and $b$ but throwing away the raw calibration readings.

@practice num
prompt: A scale reads $1.0$ g with nothing on it and $101.5$ g with a true $100.0$ g reference mass (supplied, illustrative values). Assuming a straight-line response, find the gain $b$.
answer: 1.005
check: (101.5 - 1.0) / (100.0 - 0.0)
tol: 0.0005
hint: The gain is the change in reading divided by the change in true mass between the two points.
hint: The readings differ by $101.5 - 1.0$ while the true masses differ by $100.0 - 0$.
solution: $b = (101.5 - 1.0)/(100.0 - 0) = 100.5/100.0 = 1.005$. The offset is $a = 1.0$ g.

@practice num
prompt: A homemade spring balance was checked with hanging masses of 1, 2, 3 and 4 (in units of 100 g). The pointer positions were $2.1, 3.9, 6.2, 7.8$ cm (supplied, illustrative data). Fit a straight line and report its slope.
answer: 1.94
check: np.polyfit([1, 2, 3, 4], [2.1, 3.9, 6.2, 7.8], 1)[0]
tol: 0.005
unit: cm per 100 g
hint: Use $b = \sum (x_i-\bar x)(y_i-\bar y) / \sum (x_i-\bar x)^2$, or `np.polyfit`.
hint: Here $\bar x = 2.5$, $\bar y = 5.0$, and $\sum (x_i-\bar x)^2 = 5$.
solution: $\sum (x_i-\bar x)(y_i-\bar y) = (-1.5)(-2.9) + (-0.5)(-1.1) + (0.5)(1.2) + (1.5)(2.8) = 9.7$, so $b = 9.7/5 = 1.94$ cm per 100 g. The intercept is $5.0 - 1.94 \times 2.5 = 0.15$ cm.

@practice num
prompt: A scale was calibrated with true masses $x = 0, 20, 40, 60, 80, 100$ g, giving readings $y = 0.5, 21.0, 41.0, 61.5, 81.5, 102.0$ g (supplied, illustrative data). Fit $y = a + bx$ and find the true mass of an object for which the scale reads $70.0$ g. Round to one decimal place.
answer: 68.5
check: (lambda c: (70.0 - c[1]) / c[0])(np.polyfit([0, 20, 40, 60, 80, 100], [0.5, 21.0, 41.0, 61.5, 81.5, 102.0], 1))

unit: g
hint: Fit the line first, then invert it: $x = (y - a)/b$.

solution: $b = 7095/7000 = 1.01357$ and $a = 51.25 - 1.01357 \times 50 = 0.571$ g. For a reading of $70.0$ g the true mass is $(70.0 - 0.571)/1.01357 = 68.5$ g.

@quiz ms
prompt: Select all of the practices that make a calibration trustworthy.
choice*: Use reference standards whose uncertainty is several times smaller than the instrument's.
choice*: Spread the reference points over the whole range in which the instrument will be used.
choice*: Take readings with the reference increasing and then decreasing, to look for hysteresis.
choice: Calibrate at a single point near full scale and assume the zero is correct.
choice: Keep only the fitted offset and gain, and discard the raw calibration readings.
hint: Ask what each practice lets you test or check later.
hint: A good calibration can be audited from its raw data and does not assume what it should measure.
solution: Good references, full range coverage and up-and-down sweeps all make errors visible. A single-point calibration assumes the offset and the linearity instead of measuring them, and discarding the raw data makes the calibration impossible to audit or redo.

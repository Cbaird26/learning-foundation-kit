@article
A **contour** is a piecewise smooth curve $\gamma$ given by $z(t)$ for $a \le t \le b$. The **contour integral** of $f$ along $\gamma$ is

$$\int_\gamma f(z)\,dz = \int_a^b f(z(t))\,z'(t)\,dt.$$

This is an ordinary integral over the real variable $t$ of a complex-valued function (integrate real and imaginary parts separately). Reversing the direction of $\gamma$ changes the sign; a different parametrization of the same oriented curve gives the same value.

### Elementary contours

- **Segment** from $a$ to $b$: $z(t) = a + t(b - a)$, $0 \le t \le 1$, with $z'(t) = b - a$.
- **Circle** of radius $R$ about $c$, counterclockwise: $z(t) = c + Re^{it}$, $0 \le t \le 2\pi$, with $z'(t) = iRe^{it}$. A half circle uses $0 \le t \le \pi$.
- **Piecewise paths**: add the integrals over the pieces.

To see what the integral means, chop $\gamma$ into tiny steps $\Delta z$. Each product $f(z)\,\Delta z$ takes a small step along the curve and rotates and stretches it by the complex number $f(z)$; the contour integral adds up all these rotated, stretched steps. That is why the answer is a complex number even though the curve lives in the plane, and why the direction of travel matters.

### The most important integral

For a circle $|z - c| = R$ traversed counterclockwise and an integer $n$,

$$\oint (z-c)^n\,dz = \int_0^{2\pi} R^ne^{int}\cdot iRe^{it}\,dt = iR^{n+1}\int_0^{2\pi}e^{i(n+1)t}\,dt = \begin{cases} 2\pi i, & n = -1,\\ 0, & n \neq -1.\end{cases}$$

For $n \neq -1$ the integral of $e^{ikt}$ over a full period vanishes; for $n = -1$ the integrand is the constant $i$. The whole residue calculus rests on this one computation.

### Antiderivatives

If $F' = f$ on a domain containing $\gamma$, which runs from $z_0$ to $z_1$, then

$$\int_\gamma f(z)\,dz = F(z_1) - F(z_0),$$

because $\frac{d}{dt}F(z(t)) = f(z(t))\,z'(t)$. The value depends only on the endpoints and is $0$ for a closed curve. So $z^n$ with $n \neq -1$ and $e^z$ have path-independent integrals. The function $1/z$ has no antiderivative on a region surrounding $0$, which is exactly why its circle integral is $2\pi i$.

### The ML inequality

If $|f| \le M$ on $\gamma$ and $\gamma$ has length $L$, then

$$\left|\int_\gamma f(z)\,dz\right| \le ML.$$

This follows from $\left|\int g\right| \le \int |g|$. We will use it in Week 10 to show that integrals over large arcs vanish.

### A numerical check

```python
import numpy as np
N = 2000
t = 2*np.pi*np.arange(N)/N      # periodic grid on [0, 2*pi)
z = 2*np.exp(1j*t)              # the circle |z| = 2
dz = 2j*np.exp(1j*t)            # z'(t)
print(np.sum(dz/z) * 2*np.pi/N) # about 6.283185j, that is 2*pi*i
```

@example
title: A segment integral, checked with an antiderivative
problem: Evaluate $\int_\gamma z^2\,dz$, where $\gamma$ is the straight segment from $0$ to $1 + i$.
step: Parametrize: $z(t) = (1 + i)t$ for $0 \le t \le 1$, so $z'(t) = 1 + i$.
step: Then $z(t)^2 = (1+i)^2t^2 = 2it^2$, and the integrand $f(z(t))z'(t)$ is $2it^2(1 + i)$.
step: Integrate: $\int_0^1 2i(1+i)t^2\,dt = \dfrac{2i(1+i)}{3} = \dfrac{2i - 2}{3}$.
step: Check with the antiderivative $F(z) = z^3/3$: $F(1+i) - F(0) = \dfrac{(1+i)^3}{3} = \dfrac{(1+i)(2i)}{3} = \dfrac{-2 + 2i}{3}$. The two answers agree.

@example
title: A non-analytic integrand depends on the path
problem: Compute $\int_\gamma \bar z\,dz$ along (A) the segment from $0$ to $1 + i$, and (B) the path from $0$ to $1$ and then from $1$ to $1 + i$. Why do the answers differ?
step: Path A: $z = (1+i)t$, $\bar z = (1-i)t$, $dz = (1+i)\,dt$. So $\bar z\,dz = (1-i)(1+i)t\,dt = 2t\,dt$, and the integral is $\int_0^1 2t\,dt = 1$.
step: Path B, first leg: $z = t$, $\bar z = t$, $dz = dt$, giving $\int_0^1 t\,dt = \tfrac12$.
step: Path B, second leg: $z = 1 + it$, $\bar z = 1 - it$, $dz = i\,dt$. Then $(1 - it)i = i + t$, and $\int_0^1 (i + t)\,dt = i + \tfrac12$.
step: Path B total: $\tfrac12 + i + \tfrac12 = 1 + i$, which differs from path A's value $1$.
step: The values differ because $\bar z$ fails the Cauchy-Riemann equations, so it is not analytic and has no antiderivative. Next week shows that analytic integrands cannot behave this way.

@mistakes
- Forgetting the factor $z'(t)$: the integrand is $f(z(t))\,z'(t)\,dt$, not $f(z(t))\,dt$.
- Taking the length $L$ in the ML inequality to be the length of the $t$-interval; it is the arc length (for a circle, $2\pi R$).
- Using the antiderivative shortcut with $\bar z$, or with $1/z$ around a closed curve enclosing $0$.
- Ignoring orientation: a clockwise circle gives the negative of the counterclockwise value.

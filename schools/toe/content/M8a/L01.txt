@article
A **complex number** is $z = x + iy$ with $x, y$ real and $i^2 = -1$. We call $x = \operatorname{Re} z$ and $y = \operatorname{Im} z$ (note that $\operatorname{Im} z$ is the real number $y$, not $iy$). Plot $z$ as the point $(x, y)$ in the **complex plane**. Addition is vector addition; multiplication just uses $i^2 = -1$:

$$(a + ib)(c + id) = (ac - bd) + i(ad + bc).$$

Why bother with a plane of numbers? Many physical quantities oscillate, and an oscillation $A\cos(\omega t + \phi)$ has an amplitude $A$ and a phase $\phi$. The single complex number $Ae^{i\phi}$ stores both, because $A\cos(\omega t + \phi) = \operatorname{Re}\left(Ae^{i\phi}e^{i\omega t}\right)$, and shifting a phase becomes a multiplication. Equations for waves and quantum amplitudes then reduce to arithmetic with these numbers, which is why this course starts here.

### Conjugate, modulus, division

The **conjugate** $\bar z = x - iy$ reflects $z$ across the real axis. The **modulus** $|z| = \sqrt{x^2 + y^2}$ is the distance from the origin, and

$$z\bar z = x^2 + y^2 = |z|^2.$$

That identity is how you divide: multiply top and bottom by the conjugate of the denominator, so $\dfrac{1}{z} = \dfrac{\bar z}{|z|^2}$. For example $\dfrac{1}{3 + 4i} = \dfrac{3 - 4i}{25}$.

### Polar form and Euler's formula

Write $z = r(\cos\theta + i\sin\theta)$ with $r = |z|$ and $\theta$ an **argument** of $z$. Euler's formula $e^{i\theta} = \cos\theta + i\sin\theta$ shortens this to

$$z = re^{i\theta}.$$

Multiplication becomes geometric: **moduli multiply and arguments add**,

$$r_1e^{i\theta_1}\cdot r_2e^{i\theta_2} = r_1r_2\,e^{i(\theta_1 + \theta_2)}.$$

Multiplying by $e^{i\alpha}$ rotates the plane by $\alpha$; multiplying by $i = e^{i\pi/2}$ is a quarter turn.

The argument is **multivalued**: $\theta$ and $\theta + 2\pi k$ describe the same point. The **principal argument** $\operatorname{Arg} z$ is the one in $(-\pi, \pi]$. This course uses that convention throughout.

### Powers and roots

Integer powers follow from the rule above: $z^n = r^ne^{in\theta}$. Roots are where the multivaluedness shows up. If $w^n = z = re^{i\theta}$ with $z \neq 0$, then each of

$$w_k = r^{1/n}\,e^{i(\theta + 2\pi k)/n}, \qquad k = 0, 1, \dots, n-1,$$

is a solution, and these $n$ values are the vertices of a regular $n$-gon on the circle $|w| = r^{1/n}$. A nonzero number has exactly $n$ distinct $n$-th roots. Geometrically, the roots of $1$ split the circle into $n$ equal arcs, which is why they appear in discrete Fourier transforms and in the description of $n$-fold rotational symmetry.

### A quick Python check

```python
import cmath
z = 1 + 1j
print(abs(z), cmath.phase(z))   # 1.414..., 0.785... (pi/4)
print(z**10)                     # 32j
print(cmath.exp(1j*cmath.pi))    # about -1 (tiny imaginary rounding error)
```

@example
title: A quotient in Cartesian form
problem: Write $\dfrac{3 + 4i}{1 - 2i}$ in the form $x + iy$.
step: Multiply numerator and denominator by the conjugate of the denominator, $1 + 2i$.
step: The denominator becomes $(1 - 2i)(1 + 2i) = 1 + 4 = 5$.
step: The numerator becomes $(3 + 4i)(1 + 2i) = 3 + 6i + 4i + 8i^2 = -5 + 10i$.
step: So the quotient is $\dfrac{-5 + 10i}{5} = -1 + 2i$. Check: $(-1 + 2i)(1 - 2i) = -1 + 2i + 2i - 4i^2 = 3 + 4i$.

@example
title: All cube roots of $-8$
problem: Find every complex number $w$ with $w^3 = -8$.
step: Write $-8$ in polar form: $r = 8$ and $\theta = \pi$, so $-8 = 8e^{i\pi}$.
step: The roots are $w_k = 8^{1/3}e^{i(\pi + 2\pi k)/3} = 2e^{i(\pi + 2\pi k)/3}$ for $k = 0, 1, 2$.
step: For $k = 0$: $2e^{i\pi/3} = 2\left(\tfrac12 + \tfrac{\sqrt3}{2}i\right) = 1 + i\sqrt3$. For $k = 1$: $2e^{i\pi} = -2$. For $k = 2$: $2e^{i5\pi/3} = 1 - i\sqrt3$.
step: Check: $(-2)^3 = -8$, and the three points are equally spaced by $120^\circ$ on the circle of radius $2$.

@mistakes
- Dividing by a complex number without multiplying by its conjugate, or conjugating the numerator instead of the denominator.
- Writing $|z|^2 = z^2$; the correct identity is $|z|^2 = z\bar z$.
- Adding arguments when you add numbers; arguments add under multiplication, moduli add only through the triangle inequality, and neither does anything simple under addition.
- Giving only one $n$-th root, or forgetting that $\theta$ is only defined up to multiples of $2\pi$.

@practice num
prompt: Compute $\dfrac{1 + 2i}{3 - 4i}$. Enter the answer as a single fraction in the form $(a + bi)/c$ with integers $a, b, c$.
answer: (-1+2i)/5
check: (1+2*I)/(3-4*I)
hint: Multiply top and bottom by the conjugate of the denominator, $3 + 4i$.
hint: The denominator becomes $3^2 + 4^2 = 25$. Expand $(1 + 2i)(3 + 4i)$ for the numerator.
solution: $(1+2i)(3+4i) = 3 + 4i + 6i + 8i^2 = -5 + 10i$, and $(3-4i)(3+4i) = 25$. So the quotient is $\frac{-5+10i}{25} = \frac{-1+2i}{5}$.

@practice num
prompt: Compute the modulus $\left|\dfrac{(2 + i)(1 - 3i)}{1 + i}\right|$.
answer: 5
check: abs((2+I)*(1-3*I)/(1+I))
hint: The modulus of a product or quotient is the product or quotient of the moduli.
hint: $|2 + i| = \sqrt5$, $|1 - 3i| = \sqrt{10}$, $|1 + i| = \sqrt2$.
solution: $\dfrac{\sqrt5\cdot\sqrt{10}}{\sqrt2} = \sqrt{\dfrac{50}{2}} = \sqrt{25} = 5$.

@practice num
prompt: Compute $(1 + i)^{10}$ in the form $x + iy$.
answer: 32i
check: (1+I)**10
hint: Write $1 + i$ in polar form: $|1+i| = \sqrt2$ and $\operatorname{Arg}(1+i) = \pi/4$.
hint: Then $(1+i)^{10} = (\sqrt2)^{10}e^{i\,10\pi/4}$. Reduce $10\pi/4$ by multiples of $2\pi$.
solution: $(1+i)^{10} = 2^5e^{i5\pi/2} = 32e^{i\pi/2} = 32i$.

@quiz expr
prompt: For real $x$ and $y$ (not both zero), express $\operatorname{Re}\dfrac{1}{x + iy}$ in terms of $x$ and $y$.
vars: x, y
lead: $\operatorname{Re}\dfrac{1}{x+iy} =$
answer: x/(x^2+y^2)
check: lambda x, y: (1/(x + I*y)).real
hint: Use $\dfrac{1}{z} = \dfrac{\bar z}{|z|^2}$.
hint: $\bar z = x - iy$ and $|z|^2 = x^2 + y^2$; read off the real part.
solution: $\dfrac{1}{x+iy} = \dfrac{x - iy}{x^2+y^2}$, so the real part is $\dfrac{x}{x^2+y^2}$.

@quiz num
prompt: Find the smallest positive integer $n$ such that $\left(\dfrac{1 + i\sqrt3}{2}\right)^n = 1$.
answer: 6
check: min(n for n in range(1, 50) if abs(((1 + sqrt(3)*I)/2)**n - 1) < 1e-9)
hint: Write the base in polar form. What are its modulus and argument?
hint: The base is $e^{i\pi/3}$. You need $n\pi/3$ to be a multiple of $2\pi$.
solution: $\frac{1+i\sqrt3}{2} = e^{i\pi/3}$, so the $n$-th power is $e^{in\pi/3}$, which equals $1$ exactly when $n\pi/3 = 2\pi k$, i.e. $n = 6k$. The smallest positive such $n$ is $6$.

@article
A function of a complex variable assigns a complex number $f(z)$ to each $z = x + iy$, so we can write $f = u(x,y) + i\,v(x,y)$ with $u, v$ real. Limits and continuity are defined exactly as in calculus, with $|z - z_0|$ measuring closeness.

### The complex derivative

$$f'(z_0) = \lim_{h \to 0}\frac{f(z_0 + h) - f(z_0)}{h}, \qquad h \in \mathbb{C}.$$

The catch is that $h$ is a complex number approaching $0$ in the plane, so it can come in from any direction, and the limit must be the same for all of them. For $f(z) = z^2$ the quotient is $(2z_0h + h^2)/h = 2z_0 + h \to 2z_0$, as you expect. For $f(z) = \bar z$ the quotient is $\bar h/h$, which equals $1$ when $h$ is real and $-1$ when $h$ is purely imaginary, so $\bar z$ is differentiable **nowhere**.

A function is **analytic** (also called holomorphic) on an open set if it is complex-differentiable at every point of it. The sum, product, quotient and chain rules hold with the same proofs as in real calculus, so polynomials and rational functions (away from zeros of the denominator) are analytic.

### Exponential, sine and cosine

Define $e^z = e^x(\cos y + i\sin y)$. Then $|e^z| = e^x$, $e^{z+2\pi i} = e^z$ (period $2\pi i$), and $\frac{d}{dz}e^z = e^z$. Sine and cosine come from Euler's formula:

$$\cos z = \frac{e^{iz} + e^{-iz}}{2}, \qquad \sin z = \frac{e^{iz} - e^{-iz}}{2i}.$$

For example $\cos(iy) = \cosh y$, which is unbounded, unlike real cosine.

### Logarithms and branches

Since $e^{w+2\pi i} = e^w$, the equation $e^w = z$ has infinitely many solutions when $z \neq 0$:

$$\log z = \ln|z| + i\,(\operatorname{Arg} z + 2\pi k), \qquad k \in \mathbb{Z}.$$

The **principal branch** $\operatorname{Log} z = \ln|z| + i\operatorname{Arg} z$ uses $k = 0$. It is analytic on the plane with the non-positive real axis removed, where $\operatorname{Log}'(z) = 1/z$. That removed ray is a **branch cut**: crossing it, $\operatorname{Arg}$ jumps by $2\pi$, so $\operatorname{Log}$ jumps by $2\pi i$.

### General powers

Define $z^a = e^{a\log z}$. Then: an integer $a$ gives one value; $a = p/q$ in lowest terms gives $q$ values; any other $a$ gives infinitely many. The **principal value** uses $\operatorname{Log}$: $z^a = e^{a\operatorname{Log}z}$. For $a = 1/2$ the two values of $\sqrt z$ differ by a sign, and the principal one has $\operatorname{Re}\sqrt z \ge 0$.

Always say which branch you use. Identities such as $\operatorname{Log}(z_1z_2) = \operatorname{Log}z_1 + \operatorname{Log}z_2$ hold only up to a multiple of $2\pi i$.

@example
title: All values of a logarithm
problem: Find every value of $\log(1 - i\sqrt3)$ and identify the principal value.
step: Compute the modulus: $|1 - i\sqrt3| = \sqrt{1 + 3} = 2$, so the real part of every value is $\ln 2$.
step: The point $(1, -\sqrt3)$ is in the fourth quadrant with $\tan\theta = -\sqrt3$, so $\operatorname{Arg}(1 - i\sqrt3) = -\pi/3$.
step: Therefore $\log(1 - i\sqrt3) = \ln 2 + i\left(-\tfrac{\pi}{3} + 2\pi k\right)$ for $k \in \mathbb{Z}$.
step: The principal value is $k = 0$: $\operatorname{Log}(1 - i\sqrt3) = \ln 2 - \tfrac{i\pi}{3}$. Check: $e^{\ln 2}e^{-i\pi/3} = 2\left(\tfrac12 - \tfrac{\sqrt3}{2}i\right) = 1 - i\sqrt3$.

@example
title: The values of $i^i$
problem: Find all values of $i^i$ and the principal value.
step: Use the definition $i^i = e^{i\log i}$, and write $i = e^{i\pi/2}$ so that $\operatorname{Arg} i = \pi/2$.
step: Then $\log i = i\left(\tfrac{\pi}{2} + 2\pi k\right)$, and $i\log i = -\left(\tfrac{\pi}{2} + 2\pi k\right)$.
step: So $i^i = e^{-\pi/2 - 2\pi k}$ for $k \in \mathbb{Z}$: infinitely many values, all real and positive.
step: The principal value is $k = 0$: $i^i = e^{-\pi/2} \approx 0.2079$.

@mistakes
- Testing the derivative only along the real axis; the limit must agree for every direction of $h$.
- Writing $\log z$ as a single number, or assuming $\operatorname{Log}(e^z) = z$ for every $z$; it holds only when $\operatorname{Im} z \in (-\pi, \pi]$.
- Using $\sin z$ and $\cos z$ as if they were bounded by $1$; for complex $z$ they are not.
- Forgetting the branch cut: $\operatorname{Log}$ is not continuous across the negative real axis.

@practice num
prompt: Compute the principal value of $(-1)^{1/3}$, that is $e^{\frac13\operatorname{Log}(-1)}$, in the form $x + iy$.
answer: (1+i*sqrt(3))/2
check: cmath.exp(cmath.log(-1)/3)
hint: $\operatorname{Log}(-1) = \ln 1 + i\operatorname{Arg}(-1)$.
hint: $\operatorname{Arg}(-1) = \pi$, so you need $e^{i\pi/3}$.
solution: $\operatorname{Log}(-1) = i\pi$, so $(-1)^{1/3} = e^{i\pi/3} = \cos\frac{\pi}{3} + i\sin\frac{\pi}{3} = \frac{1 + i\sqrt3}{2}$. The other two cube roots of $-1$ are $-1$ and $\frac{1 - i\sqrt3}{2}$, which the principal branch does not select.

@practice num

answer: (e+1/e)/2
check: cmath.cos(1j)

@practice ms
prompt: Select all true statements.
choice*: $e^{z + 2\pi i} = e^z$ for every complex $z$.
choice: $\operatorname{Log}(e^z) = z$ for every complex $z$.
choice*: $f(z) = \bar z$ is not complex-differentiable at any point.
choice*: For each $z \neq 0$, the equation $e^w = z$ has infinitely many solutions $w$.
hint: Test each statement with a specific number, such as $z = 3\pi i$ for the statement about $\operatorname{Log}(e^z)$.
hint: For $\bar z$, compare $\bar h/h$ for real $h$ and for imaginary $h$.
solution: The statement $e^{z + 2\pi i} = e^z$ holds because $e^{2\pi i} = 1$. The statement $\operatorname{Log}(e^z) = z$ fails: $\operatorname{Log}(e^{3\pi i}) = \operatorname{Log}(-1) = i\pi \neq 3\pi i$. The statement about $f(z) = \bar z$ holds because $\bar h/h$ is $1$ along the real axis and $-1$ along the imaginary axis. The statement about $e^w = z$ holds because $w$ can be shifted by any $2\pi i k$.

@quiz num
prompt: With the principal branch of the square root, $\sqrt{z} = e^{\frac12\operatorname{Log}z}$, find $\displaystyle\lim_{\varepsilon\to 0^+}\sqrt{-4 - i\varepsilon}$, approaching the cut from below.
answer: -2i
check: cmath.sqrt(-4 - 1e-12*I)
hint: For small $\varepsilon > 0$, which quadrant is $-4 - i\varepsilon$ in, and what is its principal argument?
hint: The argument tends to $-\pi$, so the square root has argument tending to $-\pi/2$ and modulus $2$.
solution: As $\varepsilon \to 0^+$, $\operatorname{Arg}(-4 - i\varepsilon) \to -\pi$ and $|{-4} - i\varepsilon| \to 4$. So $\sqrt{z} \to 2e^{-i\pi/2} = -2i$. Approaching from above gives $+2i$: the principal square root jumps across the cut.

@quiz expr
prompt: Let $z = x + iy$ with $x, y$ real. Find $\operatorname{Re}\left(e^{z^2}\right)$ in terms of $x$ and $y$.
vars: x, y
lead: $\operatorname{Re}\,e^{z^2} =$
answer: e^(x^2-y^2) cos(2x y)
check: lambda x, y: exp((x + I*y)**2).real
hint: First write $z^2$ as $(x^2 - y^2) + i(2xy)$.
hint: Apply $e^{a+ib} = e^a(\cos b + i\sin b)$ and take the real part.
solution: $z^2 = (x^2 - y^2) + 2ixy$, so $e^{z^2} = e^{x^2 - y^2}\left(\cos 2xy + i\sin 2xy\right)$ and the real part is $e^{x^2-y^2}\cos(2xy)$.

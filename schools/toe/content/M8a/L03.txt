@article
The definition of the complex derivative is awkward to test directly. The **Cauchy-Riemann (CR) equations** turn "complex-differentiable" into two conditions on real partial derivatives.

### Where they come from

Let $f = u + iv$ be differentiable at $z_0$. Let $h \to 0$ along the real axis, $h = t$: the quotient tends to $u_x + iv_x$. Now let $h = it$ approach along the imaginary axis: the quotient tends to $(u_y + iv_y)/i = v_y - iu_y$. The two limits must agree, so

$$u_x = v_y, \qquad u_y = -v_x, \qquad f'(z) = u_x + iv_x.$$

CR at a single point does not quite guarantee differentiability, but this does: **if $u$ and $v$ have continuous first partial derivatives on an open set and satisfy CR there, then $f = u + iv$ is analytic there.** That is the working test.

### Three test cases

| $f(z)$ | $u$ | $v$ | CR |
|---|---|---|---|
| $z^2$ | $x^2 - y^2$ | $2xy$ | hold everywhere, so analytic |
| $\bar z$ | $x$ | $-y$ | $u_x = 1 \neq -1 = v_y$ everywhere, so analytic nowhere |
| $\lvert z\rvert^2$ | $x^2 + y^2$ | $0$ | $2x = 0$ and $2y = 0$ only at $z = 0$ |

The last row is worth remembering: $\lvert z\rvert^2$ is differentiable at the single point $0$, but analytic nowhere, because analytic means differentiable on a whole open set.

### Harmonic functions

If $f = u + iv$ is analytic, then differentiating CR gives $u_{xx} = v_{yx}$ and $u_{yy} = -v_{xy}$. Adding them (mixed partials agree; week 6 shows analytic functions are infinitely differentiable) gives

$$u_{xx} + u_{yy} = 0,$$

and likewise for $v$. Such functions are **harmonic**. We call $v$ a **harmonic conjugate** of $u$; on a disk it is unique up to an added constant.

This is physics: in a charge-free region of the plane the electrostatic potential $\phi$ is harmonic, and $\phi + i\psi$ is analytic, where the level curves of $\psi$ are the field lines. The same holds for the velocity potential and stream function of ideal planar flow. Level curves of $u$ and $v$ cross at right angles wherever $f' \neq 0$, since

$$\nabla u\cdot\nabla v = u_xv_x + u_yv_y = -u_xu_y + u_yu_x = 0.$$

### Finding a conjugate

Integrate $v_y = u_x$ with respect to $y$, which leaves an unknown function $g(x)$. Then use $v_x = -u_y$ to pin down $g$.

@example
title: CR for the exponential
problem: Verify that $f(z) = e^z$ satisfies the Cauchy-Riemann equations and find $f'$.
step: Write $e^z = e^x\cos y + ie^x\sin y$, so $u = e^x\cos y$ and $v = e^x\sin y$.
step: Compute $u_x = e^x\cos y$ and $v_y = e^x\cos y$, so $u_x = v_y$.
step: Compute $u_y = -e^x\sin y$ and $v_x = e^x\sin y$, so $u_y = -v_x$. The partials are continuous, so $e^z$ is analytic on all of $\mathbb{C}$.
step: Then $f' = u_x + iv_x = e^x\cos y + ie^x\sin y = e^z$.

@example
title: A harmonic conjugate
problem: Show that $u = x^2 - y^2 + x$ is harmonic and find a harmonic conjugate $v$ and the analytic function $f = u + iv$.
step: $u_{xx} = 2$ and $u_{yy} = -2$, so $u_{xx} + u_{yy} = 0$ and $u$ is harmonic.
step: CR gives $v_y = u_x = 2x + 1$. Integrating in $y$: $v = 2xy + y + g(x)$.
step: CR also requires $v_x = -u_y = 2y$. From the formula, $v_x = 2y + g'(x)$, so $g' = 0$ and $g$ is a constant $C$.
step: Hence $v = 2xy + y + C$ and $f = (x^2 - y^2 + x) + i(2xy + y + C) = z^2 + z + iC$.

@mistakes
- Using $u_x = -v_y$ or $u_y = v_x$: only the second equation carries a minus sign, $u_y = -v_x$.
- Concluding "analytic" from CR holding at one point (like $\lvert z\rvert^2$ at the origin); you need an open set and continuous partials.
- Forgetting the unknown function $g(x)$ when integrating $v_y$ in $y$.
- Mixing up the roles of $u$ and $v$: if $v$ is a conjugate of $u$, then $-u$ is a conjugate of $v$.

@practice self
prompt: Let $f = u + iv$ be analytic on a connected open set $D$ with $\lvert f\rvert$ constant on $D$. Prove that $f$ is constant.
hint: Write the hypothesis as $u^2 + v^2 = c$ and differentiate it with respect to $x$ and with respect to $y$.
hint: Replace $v_x$ and $v_y$ using the Cauchy-Riemann equations. You get two linear equations in the unknowns $u_x$ and $u_y$; look at the determinant.
solution: Let $u^2 + v^2 = c$. Differentiate in $x$ and $y$: $uu_x + vv_x = 0$ and $uu_y + vv_y = 0$. Substitute CR ($v_x = -u_y$, $v_y = u_x$): $uu_x - vu_y = 0$ and $vu_x + uu_y = 0$. This is a linear system for $(u_x, u_y)$ with determinant $u^2 + v^2 = c$. If $c = 0$ then $f \equiv 0$. If $c \neq 0$ the only solution is $u_x = u_y = 0$, so $v_x = v_y = 0$ too, hence $f' = u_x + iv_x = 0$ on $D$ and $f$ is constant since $D$ is connected.
rubric: Differentiates $u^2 + v^2 = c$ with respect to both $x$ and $y$.
rubric: Uses the Cauchy-Riemann equations to get a linear system in $u_x, u_y$.
rubric: Handles the case $c = 0$ separately and uses a nonzero determinant when $c \neq 0$.
rubric: Concludes $f' = 0$ and uses connectedness to conclude $f$ is constant.

@quiz num
prompt: Find the positive value of $a$ for which $u(x, y) = e^{ax}\cos 3y$ is harmonic.
answer: 3
check: root(lambda a: pderiv(lambda x, y: exp(a*x)*cos(3*y), (0.3, 0.2), 0, 2) + pderiv(lambda x, y: exp(a*x)*cos(3*y), (0.3, 0.2), 1, 2), 0.5, 10)
hint: Compute $u_{xx}$ and $u_{yy}$ and add them.
hint: $u_{xx} = a^2e^{ax}\cos 3y$ and $u_{yy} = -9e^{ax}\cos 3y$.
solution: $u_{xx} + u_{yy} = (a^2 - 9)e^{ax}\cos 3y$, which vanishes identically exactly when $a^2 = 9$. The positive solution is $a = 3$, and then $u = \operatorname{Re}e^{3z}$ with $z = x + iy$.

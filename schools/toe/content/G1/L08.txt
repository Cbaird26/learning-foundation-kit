@article
**Why distributions.** Physics uses objects such as a point-charge density $\rho=q\,\delta(\mathbf r)$ or the derivative of a step. No ordinary function can do the job: a function that vanishes for $x\ne0$ equals the zero function almost everywhere, and its integral is $0$, not $1$. **Distributions** repair this by describing an object through how it acts on smooth test functions.

### Definitions

The **test functions** $\mathcal D(\mathbb R)=C_c^\infty(\mathbb R)$ are smooth functions with compact support. A **distribution** is a continuous linear functional $T:\mathcal D\to\mathbb C$, written $\langle T,\varphi\rangle$. Continuity means $\langle T,\varphi_n\rangle\to\langle T,\varphi\rangle$ whenever the $\varphi_n$ are supported in one fixed compact set and $\varphi_n\to\varphi$ together with all derivatives, uniformly.

Every locally integrable function $f$ defines a **regular distribution** $\langle T_f,\varphi\rangle=\int f\varphi\,dx$. Not every distribution is regular:
$$\langle\delta_a,\varphi\rangle=\varphi(a).$$

### Calculus rules

The derivative is defined by duality, which is integration by parts with no boundary terms:
$$\langle T',\varphi\rangle=-\langle T,\varphi'\rangle,\qquad\text{so}\quad\langle\delta_a',\varphi\rangle=-\varphi'(a).$$
Hence $\Theta'=\delta$, $(\operatorname{sgn})'=2\delta$ and $(|x|)''=2\delta$. If $f$ is smooth except for a jump $J=f(a^+)-f(a^-)$ at $a$, then $f'_{\text{dist}}=\{f'\}+J\,\delta(x-a)$, where $\{f'\}$ is the classical derivative away from $a$.

Multiplication by a smooth $g$ is $\langle gT,\varphi\rangle=\langle T,g\varphi\rangle$. So $g\,\delta_a=g(a)\,\delta_a$, $x\,\delta(x)=0$, and $g\,\delta'=g(0)\,\delta'-g'(0)\,\delta$. The product of two singular distributions, such as $\delta^2$, is **undefined**.

For a function $g$ whose zeros $x_i$ are all simple ($g'(x_i)\ne0$),
$$\delta\big(g(x)\big)=\sum_i\frac{\delta(x-x_i)}{|g'(x_i)|}.$$

### Weak convergence

$T_n\to T$ **weakly** if $\langle T_n,\varphi\rangle\to\langle T,\varphi\rangle$ for every test function. Nascent deltas such as
$$\frac{1}{\sqrt{2\pi}\,\epsilon}e^{-x^2/2\epsilon^2}\quad\text{and}\quad\frac{\epsilon/\pi}{x^2+\epsilon^2}$$
converge weakly to $\delta$ as $\epsilon\to0^+$. The convergence is not pointwise, and the limit is not a function.

### Fourier transform and the Plemelj relation

Using week 7's convention, the transform of a tempered distribution is defined by $\langle\hat T,\varphi\rangle=\langle T,\hat\varphi\rangle$. Then $\hat\delta=1$, $\widehat{\delta'}=ik$ and $\hat 1=2\pi\,\delta(k)$. As $\epsilon\to0^+$,
$$\frac{1}{x\mp i\epsilon}\;\longrightarrow\;\mathrm P\frac1x\pm i\pi\,\delta(x),$$
where $\big\langle\mathrm P\tfrac1x,\varphi\big\rangle=\lim_{\eta\to0^+}\int_{|x|>\eta}\frac{\varphi(x)}{x}dx$. This is the distributional form of the indentation rule of week 6.

### Function or distribution?

- A function has a **value at each point**. The delta does not: "$\delta(0)$" is meaningless, and the picture of a spike of infinite height is only a mnemonic.
- Functions can be multiplied and squared. Distributions in general cannot: $\delta^2$ is undefined.
- Two locally integrable functions that agree almost everywhere give the same distribution, so a distribution forgets values on sets of measure zero.
- The statement $\int\delta(x)f(x)\,dx=f(0)$ is shorthand for the definition $\langle\delta,f\rangle=f(0)$.
- The function $1/x$ is not locally integrable at $0$, so it does not define a regular distribution; $\mathrm P\frac1x$ is a different object obtained by a limiting procedure.

@example
title: The second derivative of $|x|$
problem: Show that $\dfrac{d^2}{dx^2}|x|=2\delta(x)$ in the sense of distributions.
step: By definition, $\langle(|x|)'',\varphi\rangle=\langle|x|,\varphi''\rangle=\int_{-\infty}^{\infty}|x|\,\varphi''(x)\,dx$ for a test function $\varphi$.
step: Split at the kink: $\int_0^\infty x\,\varphi''\,dx-\int_{-\infty}^0x\,\varphi''\,dx$.
step: Integrate each part by parts. On $[0,\infty)$: $\big[x\varphi'\big]_0^\infty-\int_0^\infty\varphi'\,dx=0+\varphi(0)$. On $(-\infty,0]$: $\big[x\varphi'\big]_{-\infty}^0-\int_{-\infty}^0\varphi'\,dx=0-\varphi(0)$.
step: Combine: $\varphi(0)-(-\varphi(0))=2\varphi(0)=\langle2\delta,\varphi\rangle$.
step: Hence $(|x|)''=2\delta$. The classical second derivative is $0$ away from $x=0$; the delta records the jump of the slope, $+1-(-1)=2$.

@example
title: A delta composed with a function
problem: Evaluate $\displaystyle\int_{-\infty}^{\infty}\delta(x^2-4)\,(x+3)\,dx$.
step: The zeros of $g(x)=x^2-4$ are $x=\pm2$, both simple, with $g'(x)=2x$, so $|g'(\pm2)|=4$.
step: Therefore $\delta(x^2-4)=\tfrac14\big[\delta(x-2)+\delta(x+2)\big]$.
step: Apply it to $\varphi(x)=x+3$: $\tfrac14\big[\varphi(2)+\varphi(-2)\big]=\tfrac14(5+1)$.
step: The value is $\tfrac32$. Check: the two nascent-delta spikes each carry weight $\tfrac14$ because $g$ is steep ($|g'|=4$) near its zeros.

@mistakes
- Treating $\delta$ as an ordinary function with a value at $0$, or writing $\delta(x)^2$.
- Omitting the factor $1/|g'(x_i)|$ in $\delta(g(x))$, or using $g'$ without the absolute value.
- Getting the sign wrong in $\langle T',\varphi\rangle=-\langle T,\varphi'\rangle$, which flips $\langle\delta',\varphi\rangle=-\varphi'(0)$.
- Assuming weak convergence implies pointwise convergence, or that $1/x$ defines a distribution without specifying a principal value.

prompt: Using a Gaussian nascent delta with width $\epsilon=0.01$ to approximate $\delta(x-\pi/3)$, evaluate $\int\cos x\,\delta(x-\pi/3)\,dx$. Give a number to three decimal places.
answer: 0.5
check: quad(lambda x: cos(x)*np.exp(-(x - pi/3)**2/(2*1e-4))/sqrt(2*pi*1e-4), pi/3 - 0.2, pi/3 + 0.2)
tol: 0.001
hint: The delta picks out the value of the test function at the point where its argument vanishes.
hint: Evaluate $\cos(\pi/3)$.
solution: $\int\cos x\,\delta(x-\pi/3)\,dx=\cos(\pi/3)=\tfrac12$. The Gaussian approximation reproduces this up to a relative error of order $\epsilon^2$.

choice*: The Heaviside step $\Theta(x)$
choice: The delta $\delta(x)$
choice: The derivative $\delta'(x)$

@practice num
prompt: Let $T=(|x|)''$ be the distributional second derivative and let $\varphi(x)=e^{-x^2}$. Compute $\langle T,\varphi\rangle$ using the definition $\langle T,\varphi\rangle=\int|x|\,\varphi''(x)\,dx$.
answer: 2
check: quad(lambda x: x*(4*x*x - 2)*np.exp(-x*x), 0, 12) - quad(lambda x: x*(4*x*x - 2)*np.exp(-x*x), -12, 0)
hint: Compute $\varphi''(x)=(4x^2-2)e^{-x^2}$ and split the integral at $x=0$.
hint: You need $\int_0^\infty x^3e^{-x^2}dx=\tfrac12$ and $\int_0^\infty x\,e^{-x^2}dx=\tfrac12$.
solution: $\int|x|\varphi''dx=2\int_0^\infty x(4x^2-2)e^{-x^2}dx=2\big(4\cdot\tfrac12-2\cdot\tfrac12\big)=2$. This equals $2\varphi(0)$, as $(|x|)''=2\delta$ predicts.

@practice num
prompt: Use $\dfrac{1}{x-i0}=\mathrm P\dfrac1x+i\pi\,\delta(x)$ to find the imaginary part of $\displaystyle\lim_{\epsilon\to0^+}\int_{-1}^{2}\frac{dx}{x-i\epsilon}$. Give an exact answer.
answer: pi
check: quad(lambda x: 1e-5/(x*x + 1e-10), -1, 0) + quad(lambda x: 1e-5/(x*x + 1e-10), 0, 2)

hint: The imaginary part comes from the delta term, since $\mathrm P\frac1x$ is real.

@quiz num
prompt: Evaluate $\displaystyle\int_1^{10}\delta(\sin x)\,dx$.
answer: 3
check: sum(1/abs(cos(x0)) for x0 in allroots(lambda x: sin(x), 1, 10))
hint: Find the zeros of $\sin x$ in $(1,10)$, and use $\delta(g)=\sum\delta(x-x_i)/|g'(x_i)|$.
hint: The zeros are at $\pi$, $2\pi$, $3\pi$ (since $4\pi\approx12.57>10$), and $|\cos x_i|=1$ at each.
solution: There are three simple zeros in $(1,10)$, each with $|g'|=|\cos x_i|=1$, so each contributes $1$. The integral is $3$.

@quiz ms
prompt: Select all true statements about distributions.
choice*: $x\,\delta(x)=0$ as a distribution.
choice*: $\Theta'=\delta$ in the sense of distributions, where $\Theta$ is the Heaviside step.
choice: $\delta(x)^2=\delta(x)$.
choice: $\delta$ is a function with value $+\infty$ at $x=0$ and value $0$ elsewhere, with integral $1$.
hint: Test each statement against an arbitrary test function $\varphi$.
hint: Which statements require multiplying two singular objects (squaring $\delta$), or assigning a point value to $\delta$?
solution: $\langle x\delta,\varphi\rangle=\langle\delta,x\varphi\rangle=0\cdot\varphi(0)=0$. $\langle\Theta',\varphi\rangle=-\int_0^\infty\varphi'=\varphi(0)$. The square $\delta^2$ is undefined. A function that is $0$ except at one point has Lebesgue integral $0$, so the "infinite spike" picture is a mnemonic, not a function.

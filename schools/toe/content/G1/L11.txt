@article
**Idea.** Many laws say that a quantity is stationary: a physical state makes a functional stationary. Eigenvalue problems have the same structure, which gives rigorous bounds and accurate approximations from crude trial functions.

### Functionals and the Euler–Lagrange equation

A **functional** $J[y]=\int_a^bF(x,y,y')\,dx$ assigns a number to each admissible function $y$. Its **first variation** in the direction $\eta$ is $\delta J[y;\eta]=\frac{d}{d\epsilon}J[y+\epsilon\eta]\big|_{\epsilon=0}$. If $y$ is stationary for all variations $\eta$ with $\eta(a)=\eta(b)=0$, the fundamental lemma of the calculus of variations gives the **Euler–Lagrange equation**
$$\frac{\partial F}{\partial y}-\frac{d}{dx}\frac{\partial F}{\partial y'}=0 .$$
Stationary does not mean minimum; the second variation decides. Conditions imposed on the admissible set, such as $y(a)=\alpha$, are **essential**. If an endpoint value is left free, the variation $\eta$ is free there and the first variation yields the **natural boundary condition** $\partial F/\partial y'=0$ at that end. A constraint $\int G\,dx=c$ is handled by stationarizing $J-\lambda\int G\,dx$ with a Lagrange multiplier $\lambda$.

In mechanics, Hamilton's principle makes $S[x]=\int(T-V)\,dt$ stationary; for $L=\tfrac12m\dot x^2-\tfrac12kx^2$ the Euler–Lagrange equation is $m\ddot x=-kx$.

### The Rayleigh quotient

For the Sturm–Liouville problem $-(pu')'+qu=\lambda wu$ with real functions and Dirichlet conditions, define
$$R[u]=\frac{\int_a^b\big(p\,u'^2+q\,u^2\big)\,dx}{\int_a^b w\,u^2\,dx}.$$
Stationarizing $\int(pu'^2+qu^2)\,dx$ subject to $\int wu^2\,dx=1$ gives exactly the Sturm–Liouville equation, with $\lambda$ the multiplier. So the eigenfunctions are the stationary functions of $R$, the eigenvalues are the stationary values, and
$$\lambda_1=\min_{u}R[u].$$
The minimum runs over functions satisfying only the **essential** conditions (here, the Dirichlet conditions); a Neumann condition is natural and need not be imposed on trial functions.

Two consequences:

- **Upper bound.** $R[u]\ge\lambda_1$ for every admissible $u$, with equality only for $u=u_1$.
- **Second-order accuracy.** $R$ is stationary at $u_1$, so a trial function $u=u_1+\epsilon\eta$ gives $R[u]-\lambda_1=O(\epsilon^2)$. A 10% error in the shape typically costs about 1% in the eigenvalue.

### Rayleigh–Ritz

Choose admissible basis functions $\phi_1,\dots,\phi_n$ and write $u=\sum c_i\phi_i$. Stationarity of $R$ gives the generalized matrix eigenproblem
$$A\mathbf c=\theta\,B\mathbf c,\qquad A_{ij}=\int(p\phi_i'\phi_j'+q\phi_i\phi_j)\,dx,\quad B_{ij}=\int w\,\phi_i\phi_j\,dx .$$
The Ritz values $\theta_1\le\dots\le\theta_n$ obey $\theta_k\ge\lambda_k$ and never increase when a basis function is added. The reason is the **min–max principle**: $\lambda_k=\min_{\dim V=k}\max_{u\in V}R[u]$.

### Quantifying the approximation

An upper bound alone is not an error estimate. State the known value or a lower bound if one exists, report the relative excess $(R-\lambda_1)/\lambda_1$, and show convergence by enlarging the trial space: the change between successive Ritz values measures how much is left. Lower bounds need separate tools (perturbation theory, week 12).

@example
title: An Euler–Lagrange problem with a closed form
problem: Minimize $J[y]=\int_0^1(y'^2+y^2)\,dx$ over $y$ with $y(0)=0$ and $y(1)=1$, and find the minimum value.
step: Here $F=y'^2+y^2$, so $\partial F/\partial y=2y$ and $\partial F/\partial y'=2y'$. The Euler–Lagrange equation is $2y-\tfrac{d}{dx}(2y')=0$, that is $y''=y$.
step: The general solution is $y=A\cosh x+B\sinh x$. The condition $y(0)=0$ gives $A=0$ and $y(1)=1$ gives $B=1/\sinh1$, so $y=\sinh x/\sinh1$.
step: Evaluate $J$: integrating $\int y'^2$ by parts, $\int_0^1y'^2dx=\big[yy'\big]_0^1-\int_0^1yy''\,dx$, and $y''=y$ cancels the other term, so $J=\big[yy'\big]_0^1=y(1)y'(1)$.
step: With $y'(1)=\cosh1/\sinh1$, the minimum value is $J=\coth1\approx1.3130$. It is a minimum because $F$ is convex in $(y,y')$.

@example
title: A Rayleigh quotient estimate
problem: Estimate the lowest eigenvalue of $-u''=\lambda u$ on $[0,1]$ with $u(0)=u(1)=0$ using the trial function $u=x(1-x)$, and compare with the exact value.
step: The trial function satisfies both essential conditions. Here $p=w=1$ and $q=0$.
step: Compute $u'=1-2x$, so $\int_0^1u'^2dx=\int_0^1(1-2x)^2dx=\tfrac13$.
step: Compute $\int_0^1u^2dx=\int_0^1x^2(1-x)^2dx=\tfrac1{30}$ (a beta integral, $B(3,3)$).
step: Therefore $R[u]=\dfrac{1/3}{1/30}=10$.
step: The exact value is $\lambda_1=\pi^2\approx9.8696$. The estimate is an upper bound, with relative excess $(10-9.8696)/9.8696\approx1.3\%$, while $u$ differs from $\sin\pi x$ by about $4\%$ in shape (relative $L^2$ difference after matching scales), which is second-order accuracy at work.

@mistakes
- Imposing natural boundary conditions on trial functions unnecessarily, or forgetting essential ones, so that the quotient is no longer an upper bound.
- Claiming a Rayleigh quotient is a lower bound, or reporting it without a comparison value or convergence check.
- Forgetting the weight $w$ in the denominator, or using a quotient from the wrong sign convention for $q$.
- Treating "stationary" as "minimum" in the Euler–Lagrange equation, which requires a second-variation check.

@practice self
prompt: Let $\lambda_1\le\lambda_2\le\cdots$ be the eigenvalues of the Dirichlet problem $-(pu')'+qu=\lambda wu$ on $[a,b]$, with eigenfunctions $u_n$ orthonormal in weight $w$ and complete. Prove that $R[u]\ge\lambda_1$ for every admissible real $u$ with $\int wu^2\,dx>0$, and that equality holds only for multiples of $u_1$. Then explain why a trial function with a 10% error in shape typically has an eigenvalue error of order 1%.
hint: Expand $u=\sum c_nu_n$ and show that $\int(pu'^2+qu^2)\,dx=\sum\lambda_nc_n^2$ using integration by parts and the Dirichlet conditions.
hint: Use Parseval for $\int wu^2\,dx=\sum c_n^2$ and $\lambda_n\ge\lambda_1$.
hint: For the accuracy statement write $u=u_1+\epsilon\eta$ with $\eta\perp u_1$.
solution: Because $u$ and $u_n$ vanish at the endpoints, integration by parts gives $\int(pu'u_n'+quu_n)\,dx=\int u\,\mathcal Lu_n\,dx=\lambda_n\int wuu_n\,dx=\lambda_nc_n$. Hence the numerator equals $\sum\lambda_nc_n^2$, and by Parseval the denominator equals $\sum c_n^2$. Then $R[u]-\lambda_1=\dfrac{\sum(\lambda_n-\lambda_1)c_n^2}{\sum c_n^2}\ge0$. Equality requires $c_n=0$ whenever $\lambda_n>\lambda_1$; since $\lambda_1$ is simple, $u=c_1u_1$. For $u=u_1+\epsilon\eta$ with $\eta=\sum_{n\ge2}\eta_nu_n$, the same formula gives $R-\lambda_1=\epsilon^2\sum_{n\ge2}(\lambda_n-\lambda_1)\eta_n^2\big/(1+\epsilon^2\sum\eta_n^2)=O(\epsilon^2)$: there is no first-order term, so a shape error of $0.1$ costs about $0.01$ times a number of the order of the spectral gap.

rubric: Uses Parseval and $\lambda_n\ge\lambda_1$ to obtain $R[u]\ge\lambda_1$, and identifies the equality case using simplicity of $\lambda_1$.

prompt: A Rayleigh–Ritz calculation for the lowest eigenvalue $\lambda_1$ of a Dirichlet Sturm–Liouville problem uses trial functions satisfying the Dirichlet conditions. A second basis function is added to the trial space. Which statement is correct?
choice*: The new lowest Ritz value is less than or equal to the old one, and it is still at least $\lambda_1$.
choice: The new lowest Ritz value may fall below $\lambda_1$.
choice: The new lowest Ritz value is a lower bound for $\lambda_1$.
choice: The error in the eigenvalue is first order in the error of the trial function, so the new value is improved only if the new function is very accurate.
hint: Minimizing $R$ over a larger set cannot give a larger minimum, and no admissible function gives $R<\lambda_1$.
solution: The lowest Ritz value is $\min R$ over the trial space. Enlarging the space cannot raise a minimum, and every admissible $u$ has $R[u]\ge\lambda_1$, so the value stays at or above $\lambda_1$. The error is second order, not first order, in the eigenfunction error.

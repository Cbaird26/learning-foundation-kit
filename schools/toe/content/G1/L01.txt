@article
A function is a vector. If $f$ and $g$ are functions on an interval and $\alpha,\beta$ are scalars, then $\alpha f+\beta g$ is again a function, and the vector-space axioms hold pointwise. Everything in linear algebra that does not depend on finite dimension therefore transfers: subspaces, linear independence, linear operators, eigenvalues. What changes is that the dimension is infinite, so **convergence** needs care. Conventions for the whole course: scalars are complex unless stated, intervals are finite unless stated, and a weight $w(x)>0$ is allowed (the default is $w=1$).

### Subspaces and boundary conditions

A subset is a **subspace** if it contains $0$ and is closed under addition and scalar multiplication. The functions on $[0,L]$ with $u(0)=u(L)=0$ form a subspace. The functions with $u(0)=1$ do not: the sum of two members has value $2$ at $0$. Homogeneous linear boundary conditions define subspaces, which is why they are the natural setting for eigenvalue problems.

### Inner product, norm, orthogonality

On $(a,b)$ with weight $w$ we use

$$\langle f,g\rangle=\int_a^b \overline{f(x)}\,g(x)\,w(x)\,dx,\qquad \|f\|=\sqrt{\langle f,f\rangle}.$$

The convention is conjugate-linear in the first slot and linear in the second, so $\langle f,\alpha g\rangle=\alpha\langle f,g\rangle$. For real functions the bar can be dropped. The space $L^2_w(a,b)$ consists of measurable functions with $\|f\|<\infty$, where two functions that differ only on a set of measure zero are identified; without that identification $\|f\|=0$ would not force $f=0$. Functions $f,g$ are **orthogonal** when $\langle f,g\rangle=0$. Two inequalities hold in every inner-product space:

$$|\langle f,g\rangle|\le\|f\|\,\|g\|\ \ \text{(Cauchy–Schwarz)},\qquad \|f+g\|\le\|f\|+\|g\|\ \ \text{(triangle)}.$$

### Orthonormal expansions

A set $\{e_n\}$ is **orthonormal** if $\langle e_m,e_n\rangle=\delta_{mn}$. For a function $f$ put $c_n=\langle e_n,f\rangle$ and $S_N=\sum_{n\le N}c_ne_n$. Then $S_N$ is the closest element of $\operatorname{span}\{e_1,\dots,e_N\}$ to $f$, and the leftover $f-S_N$ is orthogonal to that span. Taking the norm of $f-S_N$ gives

$$\sum_{n}|c_n|^2\le\|f\|^2\qquad\text{(Bessel's inequality)}.$$

The set is **complete** if equality holds for every $f$ in the space:

$$\|f\|^2=\sum_{n}|c_n|^2\qquad\text{(Parseval's identity)},$$

which is equivalent to $\|f-S_N\|\to0$, convergence **in mean square**. Mean-square convergence says nothing about any single point. The sine series of a step function converges in $L^2$ yet overshoots near the jump, and $\{\sin(n\pi x/L)\}$ is complete in $L^2(0,L)$ even though every member vanishes at both endpoints: the partial sums simply cannot converge uniformly to a function that does not.

Standard complete orthonormal sets with $w=1$:

| interval | orthonormal set |
|---|---|
| $(0,L)$ | $\sqrt{2/L}\,\sin(n\pi x/L)$, $n\ge1$ |
| $(-\pi,\pi)$ | $\dfrac1{\sqrt{2\pi}}$, $\dfrac{\cos nx}{\sqrt\pi}$, $\dfrac{\sin nx}{\sqrt\pi}$, $n\ge1$ |

### Gram–Schmidt

Given independent $f_1,f_2,\dots$ build orthogonal functions by subtracting projections:

$$g_k=f_k-\sum_{j<k}\frac{\langle g_j,f_k\rangle}{\langle g_j,g_j\rangle}\,g_j .$$

Applied to $1,x,x^2,\dots$ with different choices of $(a,b,w)$ this produces the classical orthogonal polynomials, the subject of week 3.

### Completeness belongs to a space

Completeness is a statement about a particular space and weight. Also, the continuous functions with the $L^2$ norm are not complete as a normed space: continuous ramps can converge in mean square to a discontinuous step. The space $L^2$ is the completion. Differential operators will be defined on a **domain**, a subspace such as "twice differentiable with $u(0)=u(L)=0$". Carrying the domain along with the formula is the central discipline of this course.

@example
title: Orthonormal polynomials on $[-1,1]$
problem: With $\langle f,g\rangle=\int_{-1}^{1}f g\,dx$, apply Gram–Schmidt to $1,x,x^2$ and normalize the result.
step: Start with $f_1=1$. Its norm squared is $\int_{-1}^1 1\,dx=2$, so $e_0=1/\sqrt2$.
step: The function $x$ is orthogonal to $1$ (odd integrand on a symmetric interval). Its norm squared is $\int_{-1}^1x^2dx=\tfrac23$, so $e_1=\sqrt{3/2}\,x$.
step: Subtract the projections of $x^2$. Since $\langle e_0,x^2\rangle=\tfrac{1}{\sqrt2}\cdot\tfrac23$, the projection onto $e_0$ is $\tfrac13$; the projection onto $e_1$ is $0$ by parity. The remainder is $g_2=x^2-\tfrac13$.
step: Its norm squared is $\int_{-1}^1(x^2-\tfrac13)^2dx=\tfrac25-\tfrac49+\tfrac29=\tfrac{8}{45}$.
step: Therefore $e_2=\sqrt{45/8}\,(x^2-\tfrac13)=\sqrt{5/8}\,(3x^2-1)$. Check: $\int_{-1}^1(x^2-\tfrac13)dx=\tfrac23-\tfrac23=0$.

@example
title: Parseval's identity sums a series
problem: Use $f(x)=x$ on $(-\pi,\pi)$ and the trigonometric orthonormal set to evaluate $\sum_{n\ge1}n^{-2}$.
step: Because $f$ is odd, every cosine coefficient and the constant coefficient vanish. Only $e_n=\sin(nx)/\sqrt\pi$ contributes.
step: Compute $c_n=\frac{1}{\sqrt\pi}\int_{-\pi}^{\pi}x\sin(nx)\,dx$. Integrating by parts, $\int_{-\pi}^{\pi}x\sin(nx)\,dx=\frac{2\pi(-1)^{n+1}}{n}$, so $c_n=\frac{2\sqrt\pi\,(-1)^{n+1}}{n}$ and $c_n^2=\frac{4\pi}{n^2}$.
step: The norm is $\|f\|^2=\int_{-\pi}^{\pi}x^2dx=\frac{2\pi^3}{3}$.
step: The trigonometric set is complete in $L^2(-\pi,\pi)$, so Parseval gives $\frac{2\pi^3}{3}=4\pi\sum_{n\ge1}\frac1{n^2}$.
step: Hence $\sum_{n\ge1}n^{-2}=\frac{\pi^2}{6}$.

@mistakes
- Dropping the weight $w$ or the complex conjugate, so that $\langle f,f\rangle$ is no longer a norm squared.
- Using $\sin(n\pi x/L)$ as if it had norm $1$; its norm is $\sqrt{L/2}$, so an orthonormal set needs the factor $\sqrt{2/L}$.
- Treating mean-square convergence as pointwise convergence, or writing equality in Parseval's identity for an orthonormal set that is not known to be complete.
- Calling a set with an inhomogeneous condition such as $u(0)=1$ a subspace.

@quiz mc
prompt: Let $\{e_n\}$ be an orthonormal set in $L^2(a,b)$ and $c_n=\langle e_n,f\rangle$. Which statement is correct?
choice*: Bessel's inequality $\sum|c_n|^2\le\|f\|^2$ holds for every $f$; equality for every $f$ is exactly what completeness means.
choice: Parseval's identity $\sum|c_n|^2=\|f\|^2$ holds for every orthonormal set, complete or not.
choice: If the set is complete, the series $\sum c_ne_n$ converges to $f(x)$ at every point $x$.
choice: Bessel's inequality can only be proved after completeness of the set is known.
hint: Bessel's inequality comes from $\|f-S_N\|^2\ge0$, which needs no completeness.
hint: Completeness is a statement about norms of differences, not about values at points.
solution: $0\le\|f-S_N\|^2=\|f\|^2-\sum_{n\le N}|c_n|^2$ proves Bessel for any orthonormal set. Completeness means the gap closes as $N\to\infty$ for all $f$, i.e. convergence in mean square, which does not imply pointwise convergence.

@article
Lagrangian mechanics allows any change of coordinates $q \to Q(q)$. Hamiltonian mechanics has twice as many variables, so it allows much more: you may mix coordinates and momenta. The price is that the new variables must still obey Hamilton's equations. Such changes are **canonical transformations**, and they are the main tool for solving problems exactly.

### Definition

A transformation $(q, p) \to (Q, P)$ is **canonical** if for every Hamiltonian $H(q, p, t)$ there is a function $K(Q, P, t)$ such that the motion obeys
$$\dot Q^i = \frac{\partial K}{\partial P_i}, \qquad \dot P_i = -\frac{\partial K}{\partial Q^i}.$$
For a time-independent transformation, $K$ is just $H$ rewritten in the new variables. For a time-dependent transformation, $K$ differs from $H$ by an extra term, which L06 derives.

### Tests for a time-independent transformation

Write $z = (q, p)$, $Z = (Q, P)$, and let $M_{ab} = \partial Z_a/\partial z_b$ be the Jacobian. Using the matrix $J$ from L03, the following are equivalent:
- The new variables obey the fundamental brackets, computed with respect to the old ones:
$$\{Q^i, Q^j\} = 0, \qquad \{P_i, P_j\} = 0, \qquad \{Q^i, P_j\} = \delta^i_j .$$
- $M$ is **symplectic**: $M J M^{T} = J$.
- For every $F$ and $G$: $\{F, G\}_{q,p} = \{F, G\}_{Q,P}$.

Note that $(M J M^{T})_{ab} = \{Z_a, Z_b\}$, which is why the first two tests agree. For one degree of freedom, the symplectic condition is just $\det M = \{Q, P\} = 1$. For $n \ge 2$ the condition $\det M = 1$ is necessary but not sufficient, and checking only the diagonal brackets $\{Q^i, P_i\} = 1$ is not enough: you need the whole set.

### Why these tests work

By the chain rule, $\nabla_z F = M^{T}\nabla_Z F$, so
$$\{F, G\}_z = (\nabla_Z F)^{T} M J M^{T} (\nabla_Z G) = \{F, G\}_Z \quad\text{if } M J M^{T} = J .$$
Then $\dot Z = \{Z, H\}_z = \{Z, K\}_Z = J\nabla_Z K$ for $K(Z) = H(z(Z))$. Hamilton's equations keep their form.

### Consequences

- **Volume preservation.** $\det(MJM^{T}) = \det J$ gives $(\det M)^2 = 1$, and in fact $\det M = +1$: canonical maps preserve phase-space volume. For one degree of freedom they preserve areas, and in particular $\oint p\,dq$ around a closed curve.
- **Brackets are invariant**, so a bracket is the same in any canonical coordinates and conservation statements $\{F, H\} = 0$ do not depend on the coordinates.
- **Inverses and compositions** of canonical maps are canonical.

### Standard families

- **Point transformations** $Q = Q(q)$ with $P_i = p_j\,\partial q^j/\partial Q^i$. These are the changes of coordinates of the Lagrangian formulation.
- **Exchange** $Q = p$, $P = -q$: momentum and position trade roles.
- **Shears** $Q = q$, $P = p + f'(q)$ for any function $f$.
- **Flows.** The time evolution generated by *any* Hamiltonian is a canonical map, and so is the flow generated by any function $G(q, p)$ (infinitesimally, $\delta z = \epsilon\,\{z, G\}$). This is what makes $G$ the **generator**.

### Rescalings

A map $Q = \lambda q$, $P = \lambda p$ has $\{Q, P\} = \lambda^2$ and is not canonical unless $\lambda = \pm 1$. A scaled map with $\{Q, P\} = c$ is sometimes called *extended* canonical: Hamilton's equations hold only with $K$ replaced by $cK$. We will not use these unless stated.

@example
title: The oscillator in action-angle-like variables
problem: Show that $q = \sqrt{\dfrac{2P}{m\omega}}\sin Q$, $\ p = \sqrt{2 m\omega P}\cos Q$ (with $P > 0$) is a canonical transformation, and find $K$ for $H = \dfrac{p^2}{2m} + \tfrac12 m\omega^2 q^2$.
step: For one degree of freedom it suffices that $\{q, p\}_{Q,P} = \partial_Q q\,\partial_P p - \partial_P q\,\partial_Q p = 1$, which is equivalent to $\{Q, P\}_{q,p} = 1$ because the two Jacobian determinants are inverses of each other.
step: Compute $\partial_Q q = \sqrt{\dfrac{2P}{m\omega}}\cos Q$ and $\partial_P p = \sqrt{\dfrac{m\omega}{2P}}\cos Q$. Their product is $\cos^2 Q$.
step: Compute $\partial_P q = \dfrac{\sin Q}{\sqrt{2 m\omega P}}$ and $\partial_Q p = -\sqrt{2 m\omega P}\,\sin Q$. Their product is $-\sin^2 Q$.
step: Hence $\{q, p\}_{Q,P} = \cos^2 Q + \sin^2 Q = 1$, and the map is canonical.
step: Substituting, $H = \omega P\cos^2 Q + \omega P\sin^2 Q = \omega P = K$. Now $Q$ is cyclic: $\dot Q = \partial K/\partial P = \omega$ and $\dot P = 0$. So $Q = \omega t + Q_0$ grows linearly, while $P = E/\omega$ is a constant of the motion.

@example
title: Which linear maps are canonical?
problem: For one degree of freedom, find the condition for $Q = \alpha q + \beta p$, $P = \gamma q + \delta p$ to be canonical. Use it to bring the oscillator Hamiltonian into a symmetric form.
step: The bracket is $\{Q, P\} = \partial_q Q\,\partial_p P - \partial_p Q\,\partial_q P = \alpha\delta - \beta\gamma$. The map is canonical exactly when $\alpha\delta - \beta\gamma = 1$.
step: Take $Q = \sqrt{m\omega}\,q$ and $P = p/\sqrt{m\omega}$. Here $\beta = \gamma = 0$ and $\alpha\delta = 1$, so the map is canonical.
step: Invert: $q = Q/\sqrt{m\omega}$ and $p = \sqrt{m\omega}\,P$. Then $K = \dfrac{m\omega P^2}{2m} + \tfrac12 m\omega^2\dfrac{Q^2}{m\omega} = \dfrac{\omega}{2}\left(P^2 + Q^2\right)$.
step: Contrast the map $Q = \sqrt{m\omega}\,q$, $P = \sqrt{m\omega}\,p$. It has $\{Q, P\} = m\omega \ne 1$, so it is not canonical and the equations $\dot Q = \partial K/\partial P$, $\dot P = -\partial K/\partial Q$ do not hold with $K = H$.

@mistakes
- Checking $\{Q^i, P_i\} = 1$ for each $i$ and forgetting the mixed brackets $\{Q^i, P_j\}$, $\{Q^i, Q^j\}$ and $\{P_i, P_j\}$ when $n \ge 2$.
- Computing the bracket with respect to the wrong variables, or with the arguments in the wrong order. $\{Q, P\} = +1$ is the convention; $\{P, Q\} = -1$.
- Taking $\det M = 1$ as a complete test when $n \ge 2$; it is only necessary.
- Assuming $K = H$ for a time-dependent transformation. The equality holds only for time-independent maps.

Define $X = (m_1 x_1 + m_2 x_2)/(m_1 + m_2)$ and $p = (p_1 - p_2)/2$. Evaluate the bracket $\{X, p\}$ (SI units). For a canonical choice of relative momentum it would be zero.
answer: -1/4
check: nderiv(lambda a: (1.0*a + 3.0*0.7)/4.0, 0.3)*nderiv(lambda b: (b - 0.2)/2, 0.5) + nderiv(lambda a: (1.0*0.3 + 3.0*a)/4.0, 0.7)*nderiv(lambda b: (0.5 - b)/2, 0.2)
tol: 0.005
hint: $X$ depends only on positions and $p$ only on momenta, so $\{X, p\} = \sum_i \partial_{x_i}X\,\partial_{p_i}p$.
hint: $\partial_{x_1}X = m_1/M$, $\partial_{x_2}X = m_2/M$, $\partial_{p_1}p = 1/2$, $\partial_{p_2}p = -1/2$.
solution: $\{X, p\} = \dfrac{m_1}{M}\cdot\dfrac12 + \dfrac{m_2}{M}\cdot\left(-\dfrac12\right) = \dfrac{m_1 - m_2}{2M} = \dfrac{1 - 3}{8} = -\dfrac14$. The canonical relative momentum for unequal masses is instead $(m_2 p_1 - m_1 p_2)/M$, for which the bracket vanishes.

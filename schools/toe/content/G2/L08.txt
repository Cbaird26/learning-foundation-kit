@article
Hamilton–Jacobi gives the motion as quadratures. Action-angle variables squeeze out the most structure from that solution: they put an integrable system into coordinates where each degree of freedom is just a uniform rotation.

### One degree of freedom

Take a bounded periodic motion with $H(q, p) = E$ constant, so that the orbit in the $(q, p)$ plane is a closed curve. Define the **action**
$$J = \frac{1}{2\pi}\oint p\,dq = \frac{\text{area enclosed by the orbit}}{2\pi},$$
where $p = p(q, E)$ is solved from $H = E$. The factor $1/2\pi$ is our convention throughout. $J$ is a function of $E$ alone, so we can invert to $E = H(J)$.

Use the characteristic function of L07 with the constant $J$ as the new momentum: $W(q, J)$, $p = \partial W/\partial q$. The conjugate coordinate is the **angle variable**
$$\theta = \frac{\partial W}{\partial J}.$$
Because $K = H(J)$ has no $\theta$-dependence, Hamilton's equations give
$$\dot J = 0, \qquad \dot\theta = \frac{\partial H}{\partial J} \equiv \omega(J), \qquad \theta = \omega t + \theta_0 .$$
Over one period $W$ increases by $2\pi J$, so $\theta$ increases by exactly $2\pi$. Hence the period and the frequency are
$$T = \frac{2\pi}{\omega} = 2\pi\,\frac{dJ}{dE}, \qquad \omega = \frac{dE}{dJ} .$$
Note that the frequency in general depends on the energy. Among the standard examples, only the harmonic oscillator has a constant frequency.

### Several degrees of freedom

A system with $n$ degrees of freedom is **Liouville integrable** if it has $n$ functionally independent constants of motion $F_1 = H, F_2, \dots, F_n$ in involution: $\{F_i, F_j\} = 0$. The Liouville–Arnold theorem then says: if a common level set is compact and connected, it is an $n$-dimensional **torus**, and there are canonical variables $(\theta_k, J_k)$ with
$$H = H(J_1, \dots, J_n), \qquad \omega_k = \frac{\partial H}{\partial J_k}, \qquad \theta_k = \omega_k t + \theta_k^0 ,$$
where the $\theta_k$ are angles of period $2\pi$. Each action is an integral over one independent cycle $C_k$ of the torus, $J_k = \frac{1}{2\pi}\oint_{C_k} p_i\,dq^i$. If the Hamilton–Jacobi equation separates, this reduces to
$$J_k = \frac{1}{2\pi}\oint p_k\,dq^k .$$
For a cyclic angle (a rotation), the integral runs over a full turn, so that $J_\phi = p_\phi$.

### Closed orbits and frequency ratios

The motion on the torus is periodic if and only if all frequency ratios $\omega_j/\omega_k$ are rational. Otherwise the motion is **quasi-periodic**: the trajectory never repeats and fills the torus densely. A system is **degenerate** when $H$ depends on the $J_k$ only through fewer combinations, so that some frequencies coincide for all orbits. Integrable does *not* mean that all orbits close.

### Recipe

1. Choose coordinates in which the Hamilton–Jacobi equation separates.
2. Solve $H = E$ for each $p_k(q^k; \alpha)$ and find the turning points.
3. Compute $J_k = \frac{1}{2\pi}\oint p_k\,dq^k$ over a full cycle (twice the integral between turning points for a libration).
4. Invert to get $H(J_1, \dots, J_n)$ and differentiate to get the $\omega_k$.

### Adiabatic invariance

If a parameter of $H$ (say $\omega$) changes very slowly compared with the periods, the action $J$ is approximately conserved while the energy changes. L09 uses this.

@example
title: Action and angle for the oscillator
problem: Find $J$, $H(J)$, the angle variable and the period for $H = \dfrac{p^2}{2m} + \tfrac12 m\omega^2 q^2$.
step: The orbit $H = E$ is an ellipse with semi-axes $q_m = \sqrt{2E/(m\omega^2)}$ and $p_m = \sqrt{2mE}$. Its area is $\pi q_m p_m = 2\pi E/\omega$.
step: Hence $J = \dfrac{1}{2\pi}\cdot\dfrac{2\pi E}{\omega} = \dfrac{E}{\omega}$, i.e. $H(J) = \omega J$.
step: Then $\dot\theta = \partial H/\partial J = \omega$, so $\theta = \omega t + \theta_0$, and the period is $T = 2\pi/\omega$, independent of amplitude.
step: To relate $\theta$ to $q$: $\theta = \partial W/\partial J = \displaystyle\int \frac{m\omega\,dq}{\sqrt{2m\omega J - m^2\omega^2 q^2}} = \arcsin\!\left(q\sqrt{\frac{m\omega}{2J}}\right)$.
step: Invert: $q = \sqrt{\dfrac{2J}{m\omega}}\sin\theta$ and $p = \sqrt{2m\omega J}\cos\theta$. This is the canonical map of L05 and L06 with $Q = \theta$ and $P = J$.

@example
title: Kepler's third law from action variables
problem: A particle of mass $m$ moves in the plane under $V(r) = -k/r$ with $E < 0$. Find $H(J_r, J_\phi)$ and the orbital period.
step: $H = \dfrac{p_r^2}{2m} + \dfrac{p_\phi^2}{2mr^2} - \dfrac{k}{r}$ separates, with $\phi$ cyclic. The angular action is $J_\phi = \dfrac{1}{2\pi}\oint p_\phi\,d\phi = p_\phi = L$.
step: The radial action is $J_r = \dfrac{1}{2\pi}\oint p_r\,dr = \dfrac{1}{\pi}\displaystyle\int_{r_-}^{r_+}\sqrt{2m\left(E + \dfrac{k}{r}\right) - \dfrac{L^2}{r^2}}\;dr$, where $r_\pm$ are the zeros of the radicand.
step: Use the standard integral $\displaystyle\int_{r_-}^{r_+}\sqrt{-A + \dfrac{2B}{r} - \dfrac{C}{r^2}}\,dr = \pi\left(\dfrac{B}{\sqrt A} - \sqrt C\right)$ with $A = -2mE$, $B = mk$ and $C = L^2$. This gives $J_r = \dfrac{m k}{\sqrt{-2mE}} - J_\phi$.
step: Solve for the energy: $H = -\dfrac{m k^2}{2\,(J_r + J_\phi)^2}$. It depends on the actions only through $J_r + J_\phi$, so $\omega_r = \omega_\phi = \dfrac{m k^2}{(J_r + J_\phi)^3}$. The frequencies are equal for every orbit, so every bound orbit closes.
step: With $E = -k/(2a)$ one finds $J_r + J_\phi = \sqrt{m k a}$ and $T = 2\pi/\omega = 2\pi\sqrt{m a^3/k}$, which is Kepler's third law.

@mistakes
- Omitting the factor $1/2\pi$ (or using half an orbit) in $J$. With our convention $T = 2\pi\,dJ/dE$; without the $2\pi$ one gets $T = dJ/dE$.
- Using $\oint p\,dq$ for a libration as the integral between the turning points once, instead of there and back.
- Believing that integrable means every orbit is closed; this holds only when the frequency ratios are rational.
- Forgetting that the actions are defined at fixed values of the other constants, so $\partial H/\partial J_k$ is a partial derivative at fixed $J_l$ ($l \ne k$).

hint: The path is $(\theta_1, \theta_2) = (\omega_1 t, \omega_2 t) + \text{const}$ on a torus; ask when it closes.
solution: In an integrable system $\dot J_k = 0$ always, so the motion stays on its torus. prompt: Solve an integrable example. A particle moves in the plane with $H = \dfrac{p_x^2 + p_y^2}{2m} + \tfrac12 m\left(\omega_x^2 x^2 + \omega_y^2 y^2\right)$. Find the actions $J_x$ and $J_y$, write $H(J_x, J_y)$, give the angle-variable motion and $x(t)$, $y(t)$, and state the condition on $\omega_x/\omega_y$ for the orbits to close.
hint: The Hamiltonian is a sum of two independent oscillators, so the Hamilton–Jacobi equation separates in $x$ and $y$.
hint: Each action is the one-dimensional oscillator result $J = E/\omega$ for its own energy.
solution: Separate $E = E_x + E_y$ with $E_x = \frac{p_x^2}{2m} + \frac12 m\omega_x^2x^2$ and similarly for $y$.

@article
The Hamiltonian $H$ generates the motion, but you will often want the rate of change of some *other* function, such as an angular momentum or a product of coordinates and momenta. The Poisson bracket packages this into one operation, and it is the algebraic heart of the Hamiltonian picture.

### Definition and conventions

For functions $F(q, p, t)$ and $G(q, p, t)$ on a phase space with coordinates $(q^i, p_i)$, $i = 1, \dots, n$,
$$\{F, G\} = \sum_{i=1}^{n}\left( \frac{\partial F}{\partial q^i}\frac{\partial G}{\partial p_i} - \frac{\partial F}{\partial p_i}\frac{\partial G}{\partial q^i} \right).$$
This is the sign convention used throughout; it is equivalent to $\{F, G\} = (\nabla F)^{T} J\, (\nabla G)$ with the matrix $J$ of L03. The fundamental brackets are
$$\{q^i, q^j\} = 0, \qquad \{p_i, p_j\} = 0, \qquad \{q^i, p_j\} = \delta^i_j .$$

### Algebraic properties

For any functions $F, G, K$ and constants $a, b$:
- **Bilinearity:** $\{aF + bG, K\} = a\{F, K\} + b\{G, K\}$.
- **Antisymmetry:** $\{F, G\} = -\{G, F\}$, so $\{F, F\} = 0$.
- **Leibniz rule:** $\{F, GK\} = \{F, G\}\,K + G\,\{F, K\}$.
- **Jacobi identity:** $\{F, \{G, K\}\} + \{G, \{K, F\}\} + \{K, \{F, G\}\} = 0$.

The Leibniz rule makes $\{F, \cdot\}$ a derivation, so $\{F, g(G)\} = g'(G)\{F, G\}$. Together with the fundamental brackets, it lets you compute any bracket without differentiating coordinates explicitly.

### Time evolution

Along a solution of Hamilton's equations,
$$\frac{dF}{dt} = \{F, H\} + \frac{\partial F}{\partial t}.$$
In particular $\dot q^i = \{q^i, H\}$ and $\dot p_i = \{p_i, H\}$. A function $F$ is a **constant of motion** when this vanishes along every solution. If $F$ has no explicit time dependence, the condition is simply $\{F, H\} = 0$. If $F$ depends explicitly on $t$, both terms matter.

### Poisson's theorem

Using the Jacobi identity one finds, for any $F$ and $G$,
$$\frac{d}{dt}\{F, G\} = \left\{\frac{dF}{dt}, G\right\} + \left\{F, \frac{dG}{dt}\right\}.$$
So the bracket of two constants of motion is again a constant of motion. This can generate new conservation laws from old ones, though it may return only a trivial constant (zero, or a function of those you already have).

### Angular momentum

With $\mathbf L = \mathbf r \times \mathbf p$, indices $i, j, k \in \{x, y, z\}$ summed when repeated, and $\epsilon_{ijk}$ the Levi-Civita symbol with $\epsilon_{xyz} = +1$,
$$\{L_i, L_j\} = \epsilon_{ijk} L_k, \qquad \{L_i, x_j\} = \epsilon_{ijk} x_k, \qquad \{L_i, p_j\} = \epsilon_{ijk} p_k .$$
The last two say that $\mathbf r$ and $\mathbf p$ transform as vectors under the flow generated by $\mathbf L$. For a scalar such as $\mathbf r^2$, $\mathbf p^2$ or $\mathbf r\cdot\mathbf p$ the brackets with every $L_i$ vanish.

### Procedure for a conservation proof

1. Write $H$ and the candidate $F$, noting any explicit time dependence.
2. Compute $\{F, H\}$ using the fundamental brackets and the Leibniz rule.
3. Add $\partial F/\partial t$.
4. If the total is zero, $F$ is conserved. A nonzero result tells you its rate of change.

@example
title: The angular-momentum algebra
problem: With $L_x = y p_z - z p_y$, $L_y = z p_x - x p_z$ and $L_z = x p_y - y p_x$, compute $\{L_x, L_y\}$. Then say what Poisson's theorem implies for a Hamiltonian in which $L_x$ and $L_y$ are both conserved.
step: Write the partial derivatives needed. For $L_x$: $\partial_y L_x = p_z$, $\partial_z L_x = -p_y$, $\partial_{p_y} L_x = -z$, $\partial_{p_z} L_x = y$, others zero. For $L_y$: $\partial_x L_y = -p_z$, $\partial_z L_y = p_x$, $\partial_{p_x} L_y = z$, $\partial_{p_z} L_y = -x$, others zero.
step: First group: $\sum_i \partial_{q^i}L_x\,\partial_{p_i}L_y = (0)(z) + (p_z)(0) + (-p_y)(-x) = x p_y$.
step: Second group: $\sum_i \partial_{p_i}L_x\,\partial_{q^i}L_y = (0)(-p_z) + (-z)(0) + (y)(p_x) = y p_x$.
step: Subtract: $\{L_x, L_y\} = x p_y - y p_x = L_z$.
step: By Poisson's theorem, if $L_x$ and $L_y$ are constants of motion (neither depends explicitly on $t$), then $L_z = \{L_x, L_y\}$ is also conserved. Two components of angular momentum conserved imply the third.

@example
title: A conserved quantity that depends explicitly on time
problem: For the oscillator $H = \dfrac{p^2}{2m} + \tfrac12 m\omega^2 q^2$, show that $F = q\cos\omega t - \dfrac{p}{m\omega}\sin\omega t$ is a constant of motion, and say what it is.
step: Compute the brackets with $H$: $\{q, H\} = p/m$ and $\{p, H\} = -m\omega^2 q$.
step: Then $\{F, H\} = \cos\omega t\,\dfrac{p}{m} - \dfrac{\sin\omega t}{m\omega}\left(-m\omega^2 q\right) = \dfrac{p}{m}\cos\omega t + \omega q\sin\omega t$.
step: The explicit derivative is $\dfrac{\partial F}{\partial t} = -\omega q\sin\omega t - \dfrac{p}{m}\cos\omega t$.
step: Sum: $\dfrac{dF}{dt} = \{F, H\} + \dfrac{\partial F}{\partial t} = 0$. So $F$ is conserved. Evaluating at $t = 0$ shows that $F$ equals the initial position $q(0)$.

@mistakes
- Dropping the $\partial F/\partial t$ term. For a function with explicit time dependence, $\{F, H\} = 0$ is neither necessary nor sufficient.
- Reversing the order in $\{F, H\}$, which flips the sign of $\dot F$ because the bracket is antisymmetric.
- Taking the product of the fundamental brackets as symmetric: $\{q, p\} = 1$ but $\{p, q\} = -1$.
- Assuming that Poisson's theorem always yields a new independent constant; it may give zero or a combination of known ones.

prompt: A particle has $H = \dfrac{\mathbf p^2}{2m} + V(r)$ with $r = \sqrt{x^2 + y^2 + z^2}$. Using brackets, show that $L_z = x p_y - y p_x$ is conserved. First derive $\{L_z, x\}$, $\{L_z, y\}$, $\{L_z, p_x\}$ and $\{L_z, p_y\}$.
hint: Each fundamental bracket needs only one partial derivative of $L_z = x p_y - y p_x$.
hint: Use the Leibniz rule to show $\{L_z, \mathbf p^2\} = 0$ and $\{L_z, r^2\} = 0$, then the chain rule for $V(r)$.
solution: $\{L_z, x\} = -\partial_{p_x}L_z = y$ and $\{L_z, y\} = -\partial_{p_y}L_z = -x$, while $\{L_z, p_x\} = \partial_x L_z = p_y$ and $\{L_z, p_y\} = \partial_y L_z = -p_x$; $z$ and $p_z$ commute with $L_z$.

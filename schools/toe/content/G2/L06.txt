@article
L05 told you how to *test* a map. A generating function lets you *build* one, because the canonical property comes with the construction. You specify one function of half the variables; the map follows by differentiation.

### The type-1 relations

A transformation is canonical when both pairs $(q, p, H)$ and $(Q, P, K)$ describe the same motion through Hamilton's principle: the two phase-space actions
$$\int \left( p_i\,dq^i - H\,dt \right) \quad\text{and}\quad \int \left( P_i\,dQ^i - K\,dt \right)$$
must be stationary on the same paths for fixed endpoints in $q$ and in $Q$. That happens when their integrands differ by the differential of a function $F$:
$$p_i\,dq^i - H\,dt = P_i\,dQ^i - K\,dt + dF .$$
Take $F = F_1(q, Q, t)$ as a function of the old and new coordinates. Rearranging and comparing coefficients in $dq^i$, $dQ^i$ and $dt$:
$$p_i = \frac{\partial F_1}{\partial q^i}, \qquad P_i = -\frac{\partial F_1}{\partial Q^i}, \qquad K = H + \frac{\partial F_1}{\partial t}.$$
The first set gives $p_i$ as a function of $(q, Q, t)$; solve it for $Q(q, p, t)$ (this needs $\det \partial^2 F_1/\partial q^i\partial Q^j \ne 0$), and then the second set gives $P(q, p, t)$.

### The four types

Legendre transformations of $F_1$ give the other types. In every case $K = H + \partial F/\partial t$, with the partial derivative taken at fixed values of the function's own arguments.

| Type | Function | Relations |
|---|---|---|
| 1 | $F_1(q, Q, t)$ | $p_i = \partial F_1/\partial q^i$, $\ P_i = -\partial F_1/\partial Q^i$ |
| 2 | $F_2(q, P, t) = F_1 + Q^i P_i$ | $p_i = \partial F_2/\partial q^i$, $\ Q^i = \partial F_2/\partial P_i$ |
| 3 | $F_3(p, Q, t) = F_1 - q^i p_i$ | $q^i = -\partial F_3/\partial p_i$, $\ P_i = -\partial F_3/\partial Q^i$ |
| 4 | $F_4(p, P, t) = F_1 - q^i p_i + Q^i P_i$ | $q^i = -\partial F_4/\partial p_i$, $\ Q^i = \partial F_4/\partial P_i$ |

For type 2: solve $p_i = \partial F_2/\partial q^i$ for $P(q, p)$, then insert it in $Q^i = \partial F_2/\partial P_i$.

### Important examples

- **Identity:** $F_2 = q^i P_i$ gives $Q^i = q^i$, $p_i = P_i$. No $F_1$ exists for the identity, since $q$ and $Q$ are not independent.
- **Point transformations:** $F_2 = f^i(q)\,P_i$ gives $Q^i = f^i(q)$ and $p_j = P_i\,\partial f^i/\partial q^j$.
- **Exchange:** $F_1 = q\,Q$ gives $p = Q$ and $P = -q$, i.e. $Q = p$, $P = -q$.
- **Infinitesimal maps:** $F_2 = q^i P_i + \epsilon\,G(q, P)$ gives $\delta q^i = \epsilon\,\partial G/\partial p_i$ and $\delta p_i = -\epsilon\,\partial G/\partial q^i$ to first order. So $G$ is the generator of the transformation. With $G = H$ and $\epsilon = dt$ this is the time evolution.

### Which type exists?

A given canonical transformation may have no generating function of a particular type. Locally, though, at least one of the four types (or, for $n \ge 2$, a mixture that treats each degree of freedom with its own type) always works. You pick the type according to the problem: $F_2$ when you want $Q$ to be a function of $q$ and a new momentum, $F_1$ for maps that mix $q$ and $p$ strongly.

### Time dependence

If $F$ depends explicitly on $t$, the new Hamiltonian is not just $H$ rewritten. Such transformations include moving to a rotating or uniformly translating frame. The extra term $\partial F/\partial t$ is exactly what produces inertial terms.

### Procedure

1. Pick the type that matches the variables you want.
2. Differentiate to get the two sets of relations.
3. Eliminate to express $(Q, P)$ in terms of $(q, p)$ or vice versa.
4. Substitute into $H$ and add $\partial F/\partial t$ to get $K$.
5. Sanity check by computing $\{Q, P\} = 1$.

@example
title: The oscillator map from a type-1 function
problem: Show that $F_1(q, Q) = \tfrac12 m\omega\, q^2\cot Q$ generates the map $q = \sqrt{2P/(m\omega)}\,\sin Q$, $p = \sqrt{2 m\omega P}\cos Q$ of L05, and find $K$ for $H = p^2/(2m) + \tfrac12 m\omega^2 q^2$.
step: The first relation gives $p = \partial F_1/\partial q = m\omega\, q\cot Q$.
step: The second gives $P = -\partial F_1/\partial Q = \dfrac{m\omega\, q^2}{2\sin^2 Q}$, because $\dfrac{d}{dQ}\cot Q = -1/\sin^2 Q$.
step: Solve for $q$: $q^2 = \dfrac{2P}{m\omega}\sin^2 Q$. On the standard branch, $q = \sqrt{\dfrac{2P}{m\omega}}\,\sin Q$.
step: Then $p = m\omega\, q\cot Q = \sqrt{2 m\omega P}\,\cos Q$, matching L05.
step: $F_1$ has no explicit time dependence, so $K = H = \omega P$ (as in L05). The map is canonical by construction, with no bracket check required.

@example
title: A time-dependent generating function
problem: A frame moves at constant velocity $u$. Use $F_2(q, P, t) = (q - u t)\,P$ to find the transformation and the new Hamiltonian for $H = \dfrac{p^2}{2m} + V(q)$.
step: $Q = \partial F_2/\partial P = q - u t$ and $p = \partial F_2/\partial q = P$.
step: $K = H + \partial F_2/\partial t = H - u P$.
step: Write $q = Q + u t$ and $p = P$ in $H$: $K(Q, P, t) = \dfrac{P^2}{2m} + V(Q + u t) - u P$.
step: Hamilton's equations: $\dot Q = \partial K/\partial P = P/m - u$ and $\dot P = -V'(Q + u t)$. The first is $\dot q - u$, as expected for a frame moving with velocity $u$.
step: Note that $K \ne H$ as numbers, because the transformation depends on time.

@mistakes
- Using $K = H$ with a generating function that depends explicitly on $t$; you must add $\partial F/\partial t$.
- Mixing up the signs: in types 1 and 3 it is $P = -\partial F/\partial Q$, and in types 3 and 4 it is $q = -\partial F/\partial p$.
- Forgetting that each type has its own independent variables. In $F_2(q, P)$ the arguments are the old coordinate and the *new momentum*, so $\partial F_2/\partial q$ is taken at fixed $P$.
- Expecting every canonical map to have an $F_1$; the identity does not.

@practice self
prompt: Construct and verify a nontrivial canonical map. For the oscillator $H = \dfrac{p^2}{2m} + \tfrac12 m\omega^2 q^2$ and a fixed number $\tau$ with $\sin\omega\tau \ne 0$, take the type-1 function $F_1(q, Q) = -\dfrac{m\omega}{2\sin\omega\tau}\left[(q^2 + Q^2)\cos\omega\tau - 2 q Q\right]$. Find $Q(q, p)$ and $P(q, p)$, verify with a bracket that the map is canonical, and say what the map does physically.
hint: Use $p = \partial F_1/\partial q$ first and solve it for $Q$.
hint: Then insert $Q$ in $P = -\partial F_1/\partial Q$ and simplify with $\sin^2 + \cos^2 = 1$.
solution: $p = \partial F_1/\partial q = -\dfrac{m\omega}{\sin\omega\tau}\left(q\cos\omega\tau - Q\right)$, so $Q = q\cos\omega\tau + \dfrac{p}{m\omega}\sin\omega\tau$. Next $P = -\partial F_1/\partial Q = \dfrac{m\omega}{\sin\omega\tau}\left(Q\cos\omega\tau - q\right)$. Substituting $Q$ gives $Q\cos\omega\tau - q = -q\sin^2\omega\tau + \dfrac{p}{m\omega}\sin\omega\tau\cos\omega\tau$, hence $P = p\cos\omega\tau - m\omega\, q\sin\omega\tau$. Bracket: $\{Q, P\} = \partial_q Q\,\partial_p P - \partial_p Q\,\partial_q P = \cos^2\omega\tau + \sin^2\omega\tau = 1$, so the map is canonical (as it must be, being generated by $F_1$). Physically, $(Q, P)$ is the exact solution of Hamilton's equations after a time $\tau$: the map is the time-$\tau$ flow, a rotation of the (scaled) phase plane by angle $\omega\tau$.

@quiz num
prompt: In two degrees of freedom, a type-2 function $F_2 = (q_1 P_1 + q_2 P_2)\cos\theta + (q_1 P_2 - q_2 P_1)\sin\theta$ with $\theta = 30^\circ$ generates a canonical map. At the point $p_1 = 0.50$, $p_2 = -1.0$ (SI units), find $P_1$.
answer: 0.933
check: lin([[cos(pi/6), sin(pi/6)], [-sin(pi/6), cos(pi/6)]], [0.5, -1.0])[0]
tol: 0.5%
hint: Use $p_i = \partial F_2/\partial q^i$ at fixed $P_1, P_2$. This gives a linear system for $(P_1, P_2)$.
hint: $p_1 = P_1\cos\theta + P_2\sin\theta$ and $p_2 = -P_1\sin\theta + P_2\cos\theta$.
solution: Differentiating, $p_1 = P_1\cos\theta + P_2\sin\theta$ and $p_2 = P_2\cos\theta - P_1\sin\theta$. Solving, $P_1 = p_1\cos\theta - p_2\sin\theta = 0.50(0.866) + 1.0(0.5) \approx 0.933$. The coordinates rotate as $Q_1 = q_1\cos\theta - q_2\sin\theta$ and $Q_2 = q_2\cos\theta + q_1\sin\theta$, and the momenta rotate with them: this is the point transformation induced by a rotation.

@quiz ms
prompt: Which statements about generating functions are correct? Select all that apply.
choice*: For $F_2(q, P, t)$, the new Hamiltonian is $K = H + \partial F_2/\partial t$.
choice*: $F_2 = f^i(q)\,P_i$ generates the point transformation $Q^i = f^i(q)$.
choice: Every canonical transformation can be generated by some $F_1(q, Q, t)$.
choice: For type 1, the relation is $P_i = +\partial F_1/\partial Q^i$.
choice*: Adding a constant to a generating function does not change the transformation.
hint: Think of the identity map and of the derivation of the type-1 relations.
hint: A constant has zero derivative with respect to every variable.
solution: $K = H + \partial F_2/\partial t$ is the time-dependent relation. The point-transformation statement follows from $Q^i = \partial F_2/\partial P_i = f^i(q)$ and $p_j = P_i\,\partial f^i/\partial q^j$. The identity map has no $F_1$ because $q$ and $Q$ would not be independent, so the claim that every canonical transformation has an $F_1$ is false. The statement $P_i = +\partial F_1/\partial Q^i$ has the wrong sign: $P_i = -\partial F_1/\partial Q^i$. The statement about adding a constant is true: only derivatives of $F$ enter.

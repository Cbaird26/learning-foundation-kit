@article
Push on the mass-spring system and the equation changes to
$$m\,x'' + c\,x' + k\,x = F(t).$$
The right side is the **forcing** or input, and $x(t)$ is the **response**. The left side is still the same linear operator you solved last week.

### The structure of solutions

Suppose $y_p$ is *one* solution of $y'' + by' + cy = f(t)$. If $y$ is any other solution, then $y - y_p$ solves the homogeneous equation. Therefore
$$y = y_h + y_p,$$
where $y_h = C_1y_1 + C_2y_2$ is the general homogeneous solution. The recipe:

1. Solve the homogeneous equation for $y_h$.
2. Find one particular solution $y_p$.
3. Add them.
4. Apply the initial conditions to the **whole sum**.

### Undetermined coefficients

Guess a $y_p$ of the same family as $f$, with unknown coefficients, substitute, and match coefficients.

| forcing $f(t)$ | trial $y_p$ |
|---|---|
| constant | $A$ |
| polynomial of degree $n$ | a full polynomial of degree $n$ |
| $e^{at}$ | $Ae^{at}$ |
| $\cos\omega t$ or $\sin\omega t$ | $A\cos\omega t + B\sin\omega t$ (both terms) |

A cosine forcing needs a sine term in the trial, because differentiation (and the damping term) turns cosines into sines. If the trial duplicates a homogeneous solution the method fails; that is resonance, and it is next week's topic.

For sinusoidal forcing there is a shortcut. For $y'' + by' + cy = \cos\omega t$, the steady response is the real part of $\dfrac{e^{i\omega t}}{c - \omega^2 + ib\omega}$, which has amplitude
$$\frac{1}{\sqrt{(c - \omega^2)^2 + b^2\omega^2}}.$$

### Transient and steady state

If the system is damped, every term of $y_h$ decays. Then $y_h$ is the **transient** and $y_p$ is the **steady state**: whatever the starting conditions, the long-time response is the same $y_p$. The transient dies out at the rate of the *slowest* decaying root. If the roots have real parts $-\sigma_1, -\sigma_2$, the transient is multiplied by roughly $e^{-\sigma t}$ with $\sigma = \min(\sigma_1, \sigma_2)$, so reducing it to a fraction $\varepsilon$ takes about $t = \ln(1/\varepsilon)/\sigma$.

@example
title: Constant forcing with initial conditions
problem: Solve $y'' + 3y' + 2y = 6$ with $y(0) = 0$ and $y'(0) = 0$, and identify the transient.
step: Homogeneous part: $r^2 + 3r + 2 = (r+1)(r+2) = 0$, so $y_h = C_1e^{-t} + C_2e^{-2t}$.
step: Try the constant $y_p = A$. Then $y_p' = y_p'' = 0$ and $2A = 6$, so $A = 3$.
step: The general solution is $y = 3 + C_1e^{-t} + C_2e^{-2t}$, with $y' = -C_1e^{-t} - 2C_2e^{-2t}$.
step: Apply the conditions to the sum: $3 + C_1 + C_2 = 0$ and $-C_1 - 2C_2 = 0$. The second gives $C_1 = -2C_2$, then $3 - C_2 = 0$, so $C_2 = 3$ and $C_1 = -6$.
step: $y = 3 - 6e^{-t} + 3e^{-2t}$. The steady state is $3$ and the transient is $-6e^{-t} + 3e^{-2t}$, dominated for large $t$ by $e^{-t}$.

@example
title: Sinusoidal forcing
problem: Find the steady-state response of $y'' + 2y' + 5y = 10\cos t$ and its amplitude.
step: Use both terms in the trial: $y_p = a\cos t + b\sin t$. Then $y_p' = -a\sin t + b\cos t$ and $y_p'' = -a\cos t - b\sin t$.
step: Substitute and collect: $(4a + 2b)\cos t + (4b - 2a)\sin t = 10\cos t$.
step: Match coefficients: $4a + 2b = 10$ and $-2a + 4b = 0$. The second gives $a = 2b$, so $10b = 10$, $b = 1$ and $a = 2$.
step: $y_p = 2\cos t + \sin t$, with amplitude $\sqrt{2^2 + 1^2} = \sqrt5$. The complex formula agrees: $\dfrac{10}{|4 + 2i|} = \dfrac{10}{\sqrt{20}} = \sqrt5$.
step: The homogeneous roots are $-1 \pm 2i$, which decay, so $y_p$ really is the long-time response.

@mistakes
- Fitting $y(0)$ and $y'(0)$ to $y_h$ alone and adding $y_p$ afterward; the conditions apply to the sum.
- Using only $A\cos\omega t$ as the trial for a cosine forcing, with no sine term.
- Forgetting that $y_h$ still contains two free constants in the general solution of a forced equation.
- Choosing a trial that is already a homogeneous solution, which gives $0 = f(t)$ when substituted.

choice*: $A\cos 2t + B\sin 2t$

hint: Differentiate $\sin 2t$ once and twice. Which functions appear?

solution: The term $2y'$ turns a sine into a cosine, so $A\sin 2t$ alone cannot balance the equation. The roots $-1 \pm 2i$ do not match $\pm 2i$, so no extra factor of $t$ is needed. The trial is $A\cos 2t + B\sin 2t$.

hint: The steady state is the constant solving $3y_{ss} = 6$. The roots of $r^2 + 4r + 3$ are $-1$ and $-3$.
hint: Write $y = 2 + C_1e^{-t} + C_2e^{-3t}$ and apply both initial conditions to this whole expression.
solution: $y = 2 + C_1e^{-t} + C_2e^{-3t}$. Conditions: $2 + C_1 + C_2 = 0$ and $-C_1 - 3C_2 = 0$, so $C_2 = 1$ and $C_1 = -3$. Then $y_{tr}(1) = -3e^{-1} + e^{-3} \approx -1.054$.

@quiz expr

vars: t
lead: $y_p(t) =$
answer: 2*t + 1/2
check: lambda t: np.ravel(ivp(lambda s, y: [y[1], 4*s + 7 - 3*y[1] - 2*y[0]], [0, 0], t - 40, t))[0]
hint: Try $y_p = at + b$.
hint: Then $y_p' = a$ and $y_p'' = 0$. Match the coefficients of $t$ and of $1$.
solution: With $y_p = at + b$: $3a + 2(at + b) = 4t + 7$. Matching $t$: $2a = 4$, so $a = 2$. Matching constants: $3a + 2b = 7$, so $b = \frac12$. Hence $y_p = 2t + \frac12$.

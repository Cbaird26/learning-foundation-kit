@article
Many quantities evolve together: the two tanks of a chemical process, predator and prey, position and velocity. A **linear system with constant coefficients** is
$$\mathbf{x}' = A\mathbf{x},$$
where $\mathbf{x}(t)$ is a vector and $A$ is a constant square matrix. (You met eigenvalues in linear algebra; here is what they are for.)

### Higher order equations are systems

Any higher order equation becomes a first order system. For $y'' + by' + cy = 0$, set $x_1 = y$ and $x_2 = y'$. Then $x_1' = x_2$ and $x_2' = -cx_1 - bx_2$:
$$\begin{pmatrix} x_1 \\ x_2 \end{pmatrix}' = \begin{pmatrix} 0 & 1 \\ -c & -b \end{pmatrix}\begin{pmatrix} x_1 \\ x_2 \end{pmatrix}.$$
The characteristic polynomial of this matrix is $\lambda^2 + b\lambda + c$, the same one you used in week 3.

### Eigenvalue solutions

Try $\mathbf{x} = e^{\lambda t}\mathbf{v}$ with $\mathbf{v}$ a constant vector. Then $\mathbf{x}' = \lambda e^{\lambda t}\mathbf{v}$ while $A\mathbf{x} = e^{\lambda t}A\mathbf{v}$, so we need
$$A\mathbf{v} = \lambda\mathbf{v}:$$
$\mathbf{v}$ is an **eigenvector** with **eigenvalue** $\lambda$. The eigenvalues solve $\det(A - \lambda I) = 0$; for a $2\times2$ matrix this is $\lambda^2 - (\operatorname{tr}A)\,\lambda + \det A = 0$.

If $A$ has distinct real eigenvalues $\lambda_1, \lambda_2$ with eigenvectors $\mathbf{v}_1, \mathbf{v}_2$,
$$\mathbf{x}(t) = c_1e^{\lambda_1t}\mathbf{v}_1 + c_2e^{\lambda_2t}\mathbf{v}_2.$$
The initial condition $\mathbf{x}(0) = \mathbf{x}_0$ becomes the linear system $c_1\mathbf{v}_1 + c_2\mathbf{v}_2 = \mathbf{x}_0$: the eigenvectors are the columns of the coefficient matrix.

### Complex eigenvalues

A real matrix has complex eigenvalues in conjugate pairs $\alpha \pm i\beta$, with eigenvectors $\mathbf{a} \pm i\mathbf{b}$. The complex solution $e^{(\alpha + i\beta)t}(\mathbf{a} + i\mathbf{b})$ has a real part and an imaginary part, and each of them is a real solution:
$$e^{\alpha t}\left(\mathbf{a}\cos\beta t - \mathbf{b}\sin\beta t\right), \qquad e^{\alpha t}\left(\mathbf{a}\sin\beta t + \mathbf{b}\cos\beta t\right).$$
Take real combinations of those two. The solution rotates at rate $\beta$ while its size changes like $e^{\alpha t}$.

### What the eigenvalues tell you

- If every eigenvalue has negative real part, all solutions tend to $\mathbf{0}$.
- If some eigenvalue has positive real part, most solutions grow without bound.
- Imaginary parts mean rotation.

For a repeated eigenvalue with only one eigenvector the solution also contains a $te^{\lambda t}$ term, just as in the scalar case. Also remember the shortcuts $\lambda_1 + \lambda_2 = \operatorname{tr}A$ and $\lambda_1\lambda_2 = \det A$.

@example
title: Distinct real eigenvalues
problem: Solve $\mathbf{x}' = \begin{pmatrix}1 & 2\\ 3 & 0\end{pmatrix}\mathbf{x}$ with $\mathbf{x}(0) = (5, 0)$.
step: Characteristic equation: $\lambda^2 - \lambda - 6 = (\lambda - 3)(\lambda + 2) = 0$ (trace $1$, determinant $-6$), so $\lambda = 3$ and $\lambda = -2$.
step: For $\lambda = 3$: $(A - 3I)\mathbf{v} = 0$ gives $-2v_1 + 2v_2 = 0$, so $\mathbf{v}_1 = (1, 1)$. For $\lambda = -2$: $3v_1 + 2v_2 = 0$, so $\mathbf{v}_2 = (2, -3)$.
step: General solution: $\mathbf{x} = c_1e^{3t}(1,1) + c_2e^{-2t}(2,-3)$.
step: Initial condition: $c_1 + 2c_2 = 5$ and $c_1 - 3c_2 = 0$, so $c_1 = 3$ and $c_2 = 1$.
step: $x_1 = 3e^{3t} + 2e^{-2t}$ and $x_2 = 3e^{3t} - 3e^{-2t}$. Check at $t = 0$: $(5, 0)$. One eigenvalue is positive, so the solution grows.

@example
title: Complex eigenvalues
problem: Solve $\mathbf{x}' = \begin{pmatrix}-1 & 2\\ -2 & -1\end{pmatrix}\mathbf{x}$ with $\mathbf{x}(0) = (1, 0)$.
step: Trace $-2$ and determinant $5$ give $\lambda^2 + 2\lambda + 5 = 0$, so $\lambda = -1 \pm 2i$.
step: For $\lambda = -1 + 2i$: the first row of $A - \lambda I$ is $(-2i,\ 2)$, so $-2iv_1 + 2v_2 = 0$ and $\mathbf{v} = (1, i)$.
step: Expand $e^{-t}(\cos 2t + i\sin 2t)(1, i)$. Real part: $e^{-t}(\cos 2t,\ -\sin 2t)$. Imaginary part: $e^{-t}(\sin 2t,\ \cos 2t)$.
step: At $t = 0$ these are $(1, 0)$ and $(0, 1)$, so the initial condition $(1,0)$ selects the first one.
step: $\mathbf{x} = e^{-t}(\cos 2t,\ -\sin 2t)$: a clockwise spiral into the origin, since $\alpha = -1 < 0$ and the rotation rate is $2$.

@mistakes
- Writing $c_1e^{\lambda_1t} + c_2e^{\lambda_2t}$ without the eigenvectors; the answer must be a vector.
- Putting the entries of the companion matrix in the wrong places: for $y'' + by' + cy = 0$ the second row is $(-c, -b)$.
- Solving for $c_1, c_2$ using the wrong matrix; the eigenvectors are the columns of the system $c_1\mathbf{v}_1 + c_2\mathbf{v}_2 = \mathbf{x}_0$.
- In the complex case, keeping the imaginary unit in the final answer instead of extracting the real and imaginary parts.

@practice list
prompt: Find the eigenvalues of $A = \begin{pmatrix}4 & 1\\ 2 & 3\end{pmatrix}$.
answer: 2, 5
check: np.linalg.eigvals(np.array([[4, 1], [2, 3]]))
hint: Solve $\det(A - \lambda I) = 0$, i.e. $(4 - \lambda)(3 - \lambda) - 2 = 0$.
hint: Equivalently $\lambda^2 - 7\lambda + 10 = 0$, since the trace is $7$ and the determinant is $10$.
solution: $\lambda^2 - 7\lambda + 10 = (\lambda - 2)(\lambda - 5) = 0$, so $\lambda = 2$ or $\lambda = 5$.

@practice num
prompt: A $2\times2$ matrix has trace $1$ and determinant $-6$. What is its larger eigenvalue?
answer: 3
check: max(np.roots([1, -1, -6]))
hint: The eigenvalues satisfy $\lambda^2 - (\operatorname{tr}A)\lambda + \det A = 0$.
solution: $\lambda^2 - \lambda - 6 = (\lambda - 3)(\lambda + 2) = 0$, so the eigenvalues are $3$ and $-2$, and the larger one is $3$.

@practice num
prompt: Solve $y'' - y' - 6y = 0$ with $y(0) = 2$ and $y'(0) = 1$, by writing it as a system in $(y, y')$. Give $y(1)$ as an exact value.
answer: e^3 + e^(-2)
check: np.ravel(ivp(lambda t, x: [x[1], 6*x[0] + x[1]], [2, 1], 0, 1))[0]
hint: With $\mathbf{x} = (y, y')$ the matrix is $\begin{pmatrix}0&1\\6&1\end{pmatrix}$, with eigenvalues $3$ and $-2$.
hint: The eigenvectors are $(1, 3)$ for $\lambda = 3$ and $(1, -2)$ for $\lambda = -2$. Solve $c_1(1,3) + c_2(1,-2) = (2, 1)$.
solution: $c_1 + c_2 = 2$ and $3c_1 - 2c_2 = 1$ give $c_1 = c_2 = 1$. So $y = x_1 = e^{3t} + e^{-2t}$ and $y(1) = e^3 + e^{-2}$. (Equivalently, the characteristic equation $r^2 - r - 6 = 0$ from week 3 gives the same exponents.)

@quiz num
prompt: Solve $\mathbf{x}' = \begin{pmatrix}2 & 1\\ 1 & 2\end{pmatrix}\mathbf{x}$ with $\mathbf{x}(0) = (3, 1)$, and give $x_1(1/2)$ rounded to $0.001$.
answer: 10.612
tol: 0.001
check: np.ravel(ivp(lambda t, x: [2*x[0] + x[1], x[0] + 2*x[1]], [3, 1], 0, 0.5))[0]
hint: The eigenvalues are $3$ and $1$ (trace $4$, determinant $3$), with eigenvectors $(1, 1)$ and $(1, -1)$.
hint: Solve $c_1(1,1) + c_2(1,-1) = (3,1)$ for $c_1$ and $c_2$.
solution: $c_1 + c_2 = 3$ and $c_1 - c_2 = 1$ give $c_1 = 2$ and $c_2 = 1$. So $x_1 = 2e^{3t} + e^{t}$, and $x_1(1/2) = 2e^{1.5} + e^{0.5} \approx 8.963 + 1.649 = 10.612$.

@article
The Laplace transform trades a differential equation in $t$ for an algebraic equation in a new variable $s$. For a function $f(t)$ defined for $t \ge 0$,
$$F(s) = \mathcal{L}\{f\}(s) = \int_0^\infty e^{-st}f(t)\,dt,$$
defined for $s$ large enough that the integral converges. For example, for $f = e^{at}$ the integral is $\int_0^\infty e^{-(s-a)t}dt = \frac{1}{s-a}$ when $s > a$.

### A short table

| $f(t)$ | $F(s)$ |
|---|---|
| $1$ | $\dfrac1s$ |
| $t^n$ | $\dfrac{n!}{s^{n+1}}$ |
| $e^{at}$ | $\dfrac{1}{s-a}$ |
| $\sin\omega t$ | $\dfrac{\omega}{s^2 + \omega^2}$ |
| $\cos\omega t$ | $\dfrac{s}{s^2 + \omega^2}$ |

### Rules

- **Linearity:** $\mathcal{L}\{af + bg\} = aF + bG$.
- **Shift in $s$:** $\mathcal{L}\{e^{at}f(t)\} = F(s - a)$. For instance $\mathcal{L}\{e^{-t}\sin 2t\} = \dfrac{2}{(s+1)^2 + 4}$.
- **Derivatives:** integrate by parts. Since $e^{-st}y \to 0$ at infinity,
$$\mathcal{L}\{y'\} = sY - y(0), \qquad \mathcal{L}\{y''\} = s^2Y - s\,y(0) - y'(0).$$

The initial conditions enter automatically; you never fit constants at the end.

### The method

1. Transform both sides of the ODE, using the derivative rules.
2. Solve the algebraic equation for $Y(s)$.
3. Split $Y(s)$ into simple pieces with partial fractions (complete the square for quadratics with complex roots).
4. Invert piece by piece, reading the table from right to left.

The same procedure handles every forcing term in the table, including resonant ones, with no change of trial function. Next week it will also handle forcing that switches on and off.

### Reading denominators

Roots of the denominator of $Y(s)$ are the exponents in the answer: a simple root $s = a$ gives $e^{at}$, a double root gives $te^{at}$ as well, and roots $a \pm i\omega$ give $e^{at}\cos\omega t$ and $e^{at}\sin\omega t$. Before any cancellation, the denominator is the characteristic polynomial times the denominator of the forcing's transform.

@example
title: A forced equation solved by transforms
problem: Use Laplace transforms to solve $y'' + 3y' + 2y = 6$ with $y(0) = 0$ and $y'(0) = 0$.
step: Transform each term. With zero initial conditions $\mathcal{L}\{y''\} = s^2Y$ and $\mathcal{L}\{y'\} = sY$, so $(s^2 + 3s + 2)Y = \dfrac6s$.
step: Solve: $Y = \dfrac{6}{s(s+1)(s+2)}$.
step: Partial fractions: $Y = \dfrac As + \dfrac{B}{s+1} + \dfrac{C}{s+2}$. Covering up each factor gives $A = \dfrac{6}{1\cdot2} = 3$, $B = \dfrac{6}{(-1)(1)} = -6$ and $C = \dfrac{6}{(-2)(-1)} = 3$.
step: Invert each piece: $y = 3 - 6e^{-t} + 3e^{-2t}$. This is the answer of the week 4 example, found without a trial function.

@example
title: Complex roots and the shift rule
problem: Solve $y'' + 2y' + 5y = 0$ with $y(0) = 0$ and $y'(0) = 2$.
step: Transform: $\left(s^2Y - 0 - 2\right) + 2\left(sY - 0\right) + 5Y = 0$, so $(s^2 + 2s + 5)Y = 2$.
step: Solve: $Y = \dfrac{2}{s^2 + 2s + 5}$. The denominator has complex roots, so complete the square: $s^2 + 2s + 5 = (s+1)^2 + 4$.
step: Compare with the shift rule: $\mathcal{L}\{e^{-t}\sin 2t\} = \dfrac{2}{(s+1)^2 + 2^2}$. That is exactly $Y$.
step: $y = e^{-t}\sin 2t$. Check: $y(0) = 0$ and $y'(0) = 2$.

@mistakes
- Dropping the initial-condition terms: $\mathcal{L}\{y''\}$ is $s^2Y - sy(0) - y'(0)$, not $s^2Y$.
- Shifting in the wrong direction: $\mathcal{L}\{e^{at}f\} = F(s-a)$, so $e^{-t}$ gives $F(s+1)$.
- Inverting $\dfrac{s}{s^2 + \omega^2}$ as a sine; it is the cosine, and $\dfrac{\omega}{s^2 + \omega^2}$ is the sine.
- Leaving a quadratic with complex roots unsplit instead of completing the square.

@practice num
prompt: Compute $\mathcal{L}\{te^{-t}\}$ at $s = 2$ as an exact value.
answer: 1/9
check: quad(lambda t: exp(-2*t)*t*exp(-t), 0, inf)
hint: $\mathcal{L}\{t\} = \dfrac{1}{s^2}$. The factor $e^{-t}$ shifts $s$.
hint: $\mathcal{L}\{e^{at}f\} = F(s - a)$ with $a = -1$, so replace $s$ by $s + 1$.
solution: $\mathcal{L}\{t\} = 1/s^2$, so $\mathcal{L}\{te^{-t}\} = \dfrac{1}{(s+1)^2}$. At $s = 2$ this is $\dfrac19$.

@practice mc
prompt: The IVP $y'' + y = 0$, $y(0) = 1$, $y'(0) = 0$ is transformed. What is $Y(s)$?
choice*: $\dfrac{s}{s^2 + 1}$
choice: $\dfrac{1}{s^2 + 1}$
choice: $\dfrac{s}{s^2 - 1}$
choice: $\dfrac{1}{s}$
hint: $\mathcal{L}\{y''\} = s^2Y - s\,y(0) - y'(0)$. Substitute the initial values.
solution: $(s^2Y - s) + Y = 0$, so $(s^2 + 1)Y = s$ and $Y = \dfrac{s}{s^2 + 1}$, the transform of $\cos t$. Dropping the $-s\,y(0)$ term would wrongly give $Y = 0$; swapping the initial values ($y(0) = 0$, $y'(0) = 1$) would give $Y = \dfrac{1}{s^2 + 1}$.

@practice expr
prompt: Use Laplace transforms to solve $y' + 2y = e^{-t}$ with $y(0) = 3$.
vars: t
lead: $y(t) =$
answer: e^(-t) + 2*e^(-2*t)
check: lambda t: np.ravel(ivp(lambda s, y: exp(-s) - 2*y, 3, 0, t))[0]
hint: $\mathcal{L}\{y'\} = sY - 3$ and $\mathcal{L}\{e^{-t}\} = \dfrac{1}{s+1}$.
hint: $Y = \dfrac{3}{s+2} + \dfrac{1}{(s+1)(s+2)}$. Split the second fraction.
solution: $(s+2)Y = 3 + \dfrac{1}{s+1}$, so $Y = \dfrac{3}{s+2} + \dfrac{1}{(s+1)(s+2)} = \dfrac{3}{s+2} + \dfrac{1}{s+1} - \dfrac{1}{s+2} = \dfrac{1}{s+1} + \dfrac{2}{s+2}$. Hence $y = e^{-t} + 2e^{-2t}$.

@practice expr
prompt: Use Laplace transforms to solve $y'' + 3y' + 2y = e^{-t}$ with $y(0) = 0$ and $y'(0) = 0$. (The forcing is a homogeneous solution.)
vars: t
lead: $y(t) =$
answer: (t - 1)*e^(-t) + e^(-2*t)
check: lambda t: np.ravel(ivp(lambda s, y: [y[1], exp(-s) - 3*y[1] - 2*y[0]], [0, 0], 0, t))[0]
hint: $(s^2 + 3s + 2)Y = \dfrac{1}{s+1}$, and $s^2 + 3s + 2 = (s+1)(s+2)$.
hint: $Y = \dfrac{1}{(s+1)^2(s+2)}$. Use the form $\dfrac{A}{s+1} + \dfrac{B}{(s+1)^2} + \dfrac{C}{s+2}$.
solution: $Y = \dfrac{1}{(s+1)^2(s+2)} = -\dfrac{1}{s+1} + \dfrac{1}{(s+1)^2} + \dfrac{1}{s+2}$, since $B = 1$ and $C = 1$ by covering up, and $A = -1$ from $s = 0$. Inverting, $y = -e^{-t} + te^{-t} + e^{-2t}$. The double root at $s = -1$ is the resonance, and produces $te^{-t}$.

@quiz num
prompt: Compute $\mathcal{L}\{e^{2t}\cos 3t\}$ at $s = 4$ as an exact value.
answer: 2/13
check: quad(lambda t: exp(-4*t + 2*t)*cos(3*t), 0, inf)
hint: Start from $\mathcal{L}\{\cos 3t\} = \dfrac{s}{s^2 + 9}$.
hint: The factor $e^{2t}$ replaces $s$ by $s - 2$.
solution: $\mathcal{L}\{e^{2t}\cos 3t\} = \dfrac{s - 2}{(s-2)^2 + 9}$. At $s = 4$ this is $\dfrac{2}{4 + 9} = \dfrac{2}{13}$.

@quiz expr
prompt: Use Laplace transforms to solve $y'' + 4y' + 4y = 0$ with $y(0) = 1$ and $y'(0) = 0$.
vars: t
lead: $y(t) =$
answer: (1 + 2*t)*e^(-2*t)
check: lambda t: np.ravel(ivp(lambda s, y: [y[1], -4*y[1] - 4*y[0]], [1, 0], 0, t))[0]
hint: $\mathcal{L}\{y''\} = s^2Y - s$ and $\mathcal{L}\{y'\} = sY - 1$.
hint: $(s+2)^2Y = s + 4$. Write $s + 4 = (s + 2) + 2$.
solution: $(s^2Y - s) + 4(sY - 1) + 4Y = 0$ gives $(s+2)^2Y = s + 4$. Then $Y = \dfrac{(s+2) + 2}{(s+2)^2} = \dfrac{1}{s+2} + \dfrac{2}{(s+2)^2}$, so $y = e^{-2t} + 2te^{-2t} = (1 + 2t)e^{-2t}$.

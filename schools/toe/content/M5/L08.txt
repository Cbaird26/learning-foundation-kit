@article
Real inputs switch. A heater turns on at a set time, a motor cuts out, a hammer strikes. Undetermined coefficients struggles with these; Laplace transforms handle them cleanly.

### The unit step

The **Heaviside step** is $u(t-c) = 0$ for $t < c$ and $1$ for $t \ge c$. It switches things on at time $c$. Steps combine:

- a pulse that is on during $a \le t < b$ is $u(t-a) - u(t-b)$;
- a function equal to $g(t)$ before $c$ and $h(t)$ after is $g(t) + \big[h(t) - g(t)\big]u(t-c)$.

### The second shift rule

Since $\mathcal{L}\{u(t-c)\} = \int_c^\infty e^{-st}dt = \dfrac{e^{-cs}}{s}$, the general rule is
$$\mathcal{L}\{u(t-c)\,g(t-c)\} = e^{-cs}G(s).$$
Read it in both directions. Forward: delaying a function by $c$ multiplies its transform by $e^{-cs}$. Backward: if $Y(s) = e^{-cs}G(s)$ then $y(t) = u(t-c)\,g(t-c)$, which is the response $g$ **started at time $c$**.

Caution: the function must be written in terms of $t - c$ before you use the rule. For example $u(t-2)\,t = u(t-2)\big[(t-2) + 2\big]$, so
$$\mathcal{L}\{u(t-2)\,t\} = e^{-2s}\left(\frac{1}{s^2} + \frac2s\right).$$

### Solving a switched-input problem

For $y' + y = u(t-1)$ with $y(0) = 0$:
$$Y = \frac{e^{-s}}{s(s+1)} = e^{-s}\left(\frac1s - \frac{1}{s+1}\right) \quad\Longrightarrow\quad y = u(t-1)\left(1 - e^{-(t-1)}\right).$$
Nothing happens until $t = 1$; then the output relaxes to the steady state $1$ with its usual time constant. Notice that $y$ is continuous: a first order equation integrates the jump in the input. For a second order equation both $y$ and $y'$ are continuous and only $y''$ jumps.

### The impulse

The **delta function** $\delta(t-c)$ models a unit-area push delivered in an instant. Its transform is $\mathcal{L}\{\delta(t-c)\} = e^{-cs}$. For $my'' + cy' + ky = \delta(t-c_0)$ starting at rest, the impulse changes the velocity instantly by $1/m$ and leaves the position unchanged; afterwards the system simply obeys its homogeneous equation. For example $y'' + y = \delta(t-c)$ gives $Y = e^{-cs}/(s^2 + 1)$ and $y = u(t-c)\sin(t-c)$.

The response to $\delta$ from rest is called the **impulse response**; the response to any forcing can be built from it.

@example
title: A pulse input
problem: Solve $y' + 2y = u(t-1) - u(t-3)$ with $y(0) = 0$, and find $y(4)$.
step: Transform: $(s+2)Y = \dfrac{e^{-s} - e^{-3s}}{s}$, so $Y = \left(e^{-s} - e^{-3s}\right)\dfrac{1}{s(s+2)}$.
step: Partial fractions: $\dfrac{1}{s(s+2)} = \dfrac12\left(\dfrac1s - \dfrac{1}{s+2}\right)$, whose inverse is $g(t) = \frac12\left(1 - e^{-2t}\right)$.
step: Apply the second shift rule to each exponential: $y = u(t-1)\,g(t-1) - u(t-3)\,g(t-3)$.
step: At $t = 4$ both steps are on: $y(4) = \frac12\left(1 - e^{-6}\right) - \frac12\left(1 - e^{-2}\right) = \frac12\left(e^{-2} - e^{-6}\right) \approx 0.0664$.

@example
title: Forcing switched on in a second order system
problem: Solve $y'' + y = u(t-\pi)$ with $y(0) = 0$ and $y'(0) = 0$.
step: Transform with zero initial data: $(s^2 + 1)Y = \dfrac{e^{-\pi s}}{s}$.
step: Partial fractions: $\dfrac{1}{s(s^2+1)} = \dfrac1s - \dfrac{s}{s^2+1}$, with inverse $g(t) = 1 - \cos t$.
step: Apply the shift: $y = u(t-\pi)\left[1 - \cos(t-\pi)\right] = u(t-\pi)\,(1 + \cos t)$, because $\cos(t - \pi) = -\cos t$.
step: So $y = 0$ for $t < \pi$ and $y = 1 + \cos t$ for $t \ge \pi$. Check continuity at $t = \pi$: $y = 1 + \cos\pi = 0$ and $y' = -\sin\pi = 0$, matching the values just before the switch.

@mistakes
- Using $e^{-cs}$ times the transform of $g(t)$ when the function is written as $u(t-c)\,g(t)$ rather than $u(t-c)\,g(t-c)$; rewrite $g$ in terms of $t - c$ first.
- Inverting $e^{-cs}G(s)$ as $g(t)$, forgetting both the delay $t \to t - c$ and the factor $u(t-c)$.
- Reporting a response that is nonzero before the switch.
- Treating $\delta$ as a tall pulse with a value; its effect is a jump in velocity (for $m = 1$, a jump of $1$), not a jump in position.

@practice num
prompt: Compute $\mathcal{L}\{u(t-2)\}$ at $s = 1$ as an exact value.
answer: e^(-2)
check: quad(lambda t: exp(-t), 2, inf)
hint: The transform of the step switched on at time $c$ is $\dfrac{e^{-cs}}{s}$.
solution: $\mathcal{L}\{u(t-2)\} = \dfrac{e^{-2s}}{s}$, which at $s = 1$ is $e^{-2}$. Directly: $\int_2^\infty e^{-t}dt = e^{-2}$.

choice: $2\,u(t-2)$

solution: Before $t = 2$ the signal is $3$; at $t = 2$ it jumps by $5 - 3 = 2$. So $f = 3 + 2u(t-2)$. The choice $3 + 5\,u(t-2)$ jumps by $5$ (giving $8$), the choice $5 - 2\,u(t-2)$ is the reverse switch, and the choice $2\,u(t-2)$ lacks the base level $3$.

@quiz num
prompt: A unit mass on a spring obeys $y'' + 4y = \delta(t-1)$ with $y(0) = 0$ and $y'(0) = 0$. Find $y(1 + \pi/4)$ as an exact value.
answer: 1/2
check: np.ravel(ivp(lambda s, y: [y[1], -4*y[0]], [0, 1], 1, 1 + pi/4))[0]
hint: Transform: $Y = \dfrac{e^{-s}}{s^2 + 4}$. Recall $\mathcal{L}\{\sin 2t\} = \dfrac{2}{s^2 + 4}$.
hint: $y = u(t-1)\cdot\frac12\sin 2(t-1)$. Evaluate at $t - 1 = \pi/4$.
solution: $Y = \dfrac12\cdot\dfrac{2e^{-s}}{s^2+4}$, so $y = \frac12u(t-1)\sin 2(t-1)$. At $t = 1 + \pi/4$: $y = \frac12\sin\frac\pi2 = \frac12$. (Physically: at $t = 1$ the velocity jumps to $1$, then $y = \frac12\sin 2(t-1)$.)

solution: $G(s) = \dfrac{1}{s^2+4}$ has inverse $g(t) = \frac12\sin 2t$. The factor $e^{-3s}$ delays it by $3$: $u(t-3)\,g(t-3) = \frac12u(t-3)\sin 2(t-3)$.

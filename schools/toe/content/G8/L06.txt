@lesson
title: Independent verification
summary: Separate verification from validation, choose checks that would fail differently from your own code, and express the agreement of two results in units of their combined uncertainty.
objective: Distinguish verification (solving the equations right) from validation (solving the right equations).
objective: Cross-check a result with an independent method, such as the arithmetic–geometric mean for $K$, a conservation law or a limiting case, and recognise common-mode failures.
objective: Plan an independent check by another implementation or another person, and quantify the agreement with a z-score.
reading: Look up "verification and validation" and "method of manufactured solutions" in a computational-science text, and "independent replication" and "blind analysis" in a research-methods guide.

@article
**Verification** asks whether you are solving the equations correctly: does the code match the mathematics? **Validation** asks whether you are solving the correct equations: does the model match nature? Verification comes first. If your code has a bug, a comparison with an experiment teaches you nothing about the physics.

### What makes a check independent

A check is independent to the extent that it would **fail differently** from your result. Running the same script on another computer is not independent. Typical **common-mode failures** are a shared constant, a shared unit conversion, a shared input file, or a shared function for the equation of motion. Two programs that call the same right-hand side with a sign error agree perfectly and are both wrong.

Roughly from weak to strong:

1. rerun the same script (checks only that the run is repeatable);
2. same method, different step size (convergence);
3. a different algorithm for the same equation (for example RK4 against a symplectic integrator);
4. a different formulation (ODE integration against a closed form or a quadrature);
5. a different person implementing from the written specification, without seeing your code or your numbers.

### A different formulation: the AGM

The complete elliptic integral can be computed without any ODE or integral:

$$K(k) = \frac{\pi}{2\,\mathrm{AGM}\!\left(1,\sqrt{1-k^2}\right)}.$$

The arithmetic–geometric mean starts from $a_0, b_0$ and iterates $a_{n+1} = (a_n + b_n)/2$, $b_{n+1} = \sqrt{a_n b_n}$. The two sequences converge to the same limit very fast, so three or four iterations give many digits. This shares nothing with your RK4 code except the value of $\theta_0$.

### Conservation laws

In units with $g/L = 1$ the pendulum energy $E = \tfrac12\omega^2 - \cos\theta$ is constant. Its drift tests the integrator. It cannot test the model: a wrong right-hand side that still conserves some energy would pass. Use conservation laws to check numerics, and a separate formulation to check the equation.

### Quantifying agreement

Given independent results $x_1 \pm u_1$ and $x_2 \pm u_2$, compute

$$z = \frac{|x_1 - x_2|}{\sqrt{u_1^2 + u_2^2}}.$$

Values of $z$ below about 2 are consistent. Values above about 3 need an explanation. For deterministic numerics, use the estimated numerical error in place of $u$. Report $z$ or a relative difference, never just "they agree".

### Asking another person

Give them the written specification (equations, inputs with units, what to output) and the pass criterion, but not your code or your result. Ask them to record their numbers before comparing. A mismatch that you can trace is worth more than a match you cannot.

@example
title: AGM check of the 60 degree period
problem: Verify $T_{\rm ref} = 4K(0.5) = 6.7430$ for $g/L = 1$ and $\theta_0 = 60^\circ$ using the AGM, with no library routine for $K$.
step: Here $k = \sin 30^\circ = 0.5$, so $\sqrt{1 - k^2} = 0.8660254$. Start with $a_0 = 1$ and $b_0 = 0.8660254$.
step: First iteration: $a_1 = (1 + 0.8660254)/2 = 0.9330127$ and $b_1 = \sqrt{0.8660254} = 0.9306049$.
step: Second iteration: $a_2 = (0.9330127 + 0.9306049)/2 = 0.9318088$ and $b_2 = \sqrt{0.9330127 \times 0.9306049} = 0.9318080$. They agree to six digits, so $\mathrm{AGM} \approx 0.9318084$.
step: Then $K = \pi/(2 \times 0.9318084) = 1.685750$, and $4K = 6.74300$.
step: Compare with last week's extrapolated RK4 value $6.743001$: the two independent routes agree to the digits shown, a relative difference below $10^{-6}$.

@mistakes
- Treating a second run of the same code as an independent check.
- Sharing the right-hand side, constants or input file between two "independent" implementations.
- Using conservation of energy to claim that the model is right, when it only tests the integrator.
- Reporting "agreement" without a number such as a relative difference or a z-score.

@practice num
prompt: Use the AGM to evaluate the complete elliptic integral $K$ for $k^2 = 0.64$, that is $K = \pi/\left(2\,\mathrm{AGM}(1, 0.6)\right)$. Three iterations are enough. Round to four decimal places.
answer: 1.9953
check: special.ellipk(0.64)
tol: 0.0005
hint: Start with $a_0 = 1$, $b_0 = \sqrt{1 - 0.64} = 0.6$.
hint: $a_1 = 0.8$, $b_1 = \sqrt{0.6} = 0.77460$. Continue until $a_n$ and $b_n$ agree to five digits, which takes three iterations.
solution: $a_1 = 0.8$, $b_1 = 0.774597$; $a_2 = 0.787298$, $b_2 = 0.787196$; $a_3 = 0.787247$, $b_3 = 0.787247$. So $\mathrm{AGM} = 0.787247$ and $K = \pi/(2 \times 0.787247) = 1.9953$.

@practice num
prompt: Two independent estimates of the period at $\theta_0 = 60^\circ$ (with $g/L = 1$, supplied for practice) are $6.7430 \pm 0.0004$ and $6.7425 \pm 0.0003$ in the same units. Find the discrepancy in units of the combined standard uncertainty, $z$.
answer: 1.0
check: abs(6.7430 - 6.7425)/math.sqrt(0.0004**2 + 0.0003**2)
tol: 0.05
hint: The difference of the two values is $0.0005$.
hint: The combined uncertainty is $\sqrt{0.0004^2 + 0.0003^2}$.
solution: The combined uncertainty is $\sqrt{16 + 9} \times 10^{-4} = 5\times10^{-4}$, and the difference is $5\times10^{-4}$, so $z = 1.0$. The two results are consistent.

@practice self
prompt: Block deliverable: reproduce a known result and seek an independent check. For a known result of your own choosing, write a plan that names the result and its source, states how you will reproduce it, describes an independent check (another method or another person), says how agreement will be measured, and lists the common-mode failures you will guard against.
hint: Decide what counts as agreement as a number before you compute anything.
hint: For each shared ingredient (inputs, constants, equation, code), ask whether the check would catch an error in it.
solution: Model answer. Result: the period of a pendulum released from rest at $60^\circ$ with $g/L = 1$ is $T = 4K(0.5) = 6.7430$, from the derivation of the exact period. Reproduction: RK4 with step $h = 0.05$, period from successive upward crossings located by Newton refinement, run at $h$, $h/2$, $h/4$ with an observed order between 3.5 and 4.5. rubric: The independent check differs in method or in author, and shares no code or inputs with the first.
rubric: Agreement is defined by a number (relative difference or z-score) before the comparison.

@quiz mc

choice: The equation of motion has been verified, since two programs agree.

@quiz self
prompt: You have written a numerical integrator for the planar Kepler problem (an orbit under a force $-GMm\hat{r}/r^2$). List three independent checks of the results, say what each would catch, and give a pass criterion for each.
hint: Think of the conserved quantities of the Kepler problem and of one closed-form result.
solution: Model answer. (1) Energy: $E = \tfrac12 v^2 - GM/r$ should stay constant; a relative drift below $10^{-8}$ over ten orbits would be the criterion; this tests the integrator, not the force law. (2) Angular momentum: $\vec{r}\times\vec{v}$ is constant for any central force, so a pass at $10^{-10}$ relative checks the geometry of the code, though not the $1/r^2$ form. (3) Period against Kepler's third law: with semi-major axis $a = -GM/(2E)$ from the initial conditions, $T = 2\pi\sqrt{a^3/(GM)}$; the measured period should agree within $10^{-6}$ relative, and this does test the $1/r^2$ form. A fourth check is the Laplace–Runge–Lenz vector, whose slow rotation reveals precession produced by integration error rather than physics.
rubric: At least three distinct checks are listed, including one that involves a closed-form result.
rubric: Each check states what kind of error it would or would not catch.
rubric: Each check has a numerical pass criterion.
rubric: Distinguishes tests of the integrator from tests of the force law or model.

@lesson
title: Controlled extension
summary: Add exactly one change to a verified baseline, predict its effect by perturbation reasoning first, and compare the two in a controlled way.
objective: Add one model change with a parameter that switches it off, and use the zero-parameter case as a regression test.
objective: Predict the size and sign of the effect to first order before computing, and compare the prediction with the computed difference.
objective: Hold a midcourse review before adding the change and record its outcome.
reading: Look up "controlled experiments: change one variable at a time", "ablation studies" and "regression testing in scientific software", and "perturbation theory for anharmonic oscillators" (the Duffing oscillator) in a mechanics text.

@article
A **controlled extension** differs from the baseline in exactly one respect. It uses the same inputs, the same step size, the same code path and the same way of measuring the observable. Otherwise a difference between two runs cannot be attributed to anything.

### Build in an off switch

Add the change with a parameter that turns it off. For the oscillator $\ddot x + \omega_0^2 x + \epsilon x^3 = 0$, the case $\epsilon = 0$ must reproduce the baseline.

```python
import numpy as np

def rhs(y, eps=0.0):
    x, v = y
    return np.array([v, -x - eps*x**3])    # eps = 0 is the baseline (omega_0 = 1)

# regression test: the extension must reduce to the baseline
assert np.allclose(run(eps=0.0), run_baseline(), rtol=0, atol=1e-12)
```

This **regression test** catches accidental changes to the baseline, which are easy to make while editing.

### Predict first

Before computing, estimate the effect. For a cubic term with release from rest at amplitude $A$, first-order perturbation theory (the Duffing oscillator) gives

$$\omega \approx \omega_0\left(1 + \frac{3\epsilon A^2}{8\omega_0^2}\right).$$

The sign makes sense: with $\epsilon > 0$ the restoring force stiffens at large displacement, so the frequency rises. The next term is of order $\epsilon^2A^4/\omega_0^4$, which tells you how large a discrepancy you may expect from a first-order prediction.

A known limit gives a consistency check. Since $\sin\theta \approx \theta - \theta^3/6$, the pendulum is this oscillator with $\epsilon = -\omega_0^2/6$. The formula then gives $\omega \approx \omega_0(1 - A^2/16)$, so $T \approx T_0(1 + A^2/16)$, the same leading correction as the exact elliptic-integral result. An extension should reproduce what is already known.

### Compare in a controlled way

Compute the observable for both versions with identical settings and report the difference. Then check that:

1. the sign and size agree with the prediction, within the size of the next-order term;
2. the limit $\epsilon \to 0$ returns the baseline;
3. the difference hardly changes when you halve the step size, because the numerical errors of the two runs largely cancel.

If the difference is several times larger or smaller than the first-order estimate, suspect a bug before you suspect new physics.

### The midcourse review

Before you add the change, hold the review: baseline status with numbers, the proposal, the predicted effect, the falsification statement and the go or no-go rules from last week. Write down the outcome and the date. A change decided on later, outside the review, is a new proposal.

@example
title: Predict, compute, compare
problem: For $\ddot x + x + 0.1x^3 = 0$ released from rest at $A = 0.5$, predict the period to first order, then compare it with the period from conservation of energy.
step: Regression test: with $\epsilon = 0$ the code gives $T = 2\pi = 6.2832$, matching the baseline.
step: Prediction: $\omega \approx 1 + 3(0.1)(0.25)/8 = 1.009375$, so $T \approx 2\pi/1.009375 = 6.2248$, about 0.9% shorter than the baseline.
step: Computation: energy conservation gives $T = 4\int_0^{\pi/2} d\varphi\,/\sqrt{1 + \tfrac{\epsilon A^2}{2}(1 + \sin^2\varphi)}$. Evaluated numerically, it is $T = 6.2251$.
step: Compare: the difference is $3\times10^{-4}$ in absolute terms, or $5\times10^{-5}$ relative. The next-order term, of size $\tfrac{21}{256}\epsilon^2A^4 = 5\times10^{-5}$, accounts for it.
step: Verdict: the prediction is confirmed to the expected accuracy. A discrepancy of several percent would have meant a bug.

@mistakes
- Changing the model, the step size and the initial condition in the same run, so that nothing can be attributed.
- Skipping the zero-parameter regression test and discovering later that the baseline was altered.
- Computing first and then explaining the result, instead of predicting size and sign first.
- Expecting a first-order prediction to match to more digits than its next-order term allows.

@quiz self
prompt: Your extended code gives a period 0.4% longer than the baseline, while your first-order estimate predicted 0.2%. Describe the sequence of runs you would make to decide whether the difference is physics, numerics or a bug, and what each run would tell you.
hint: Change one thing at a time: the new parameter, then the step size, then the amplitude.
solution: Model answer. (1) Set the new parameter to zero and confirm the baseline is recovered to roundoff; a failure means the extension altered the baseline. (2) Halve the step size twice for both versions and look at the difference: if it changes, numerics matter, and the observed order of the difference should be that of the integrator. (3) Scan the new parameter at small values: the shift should be linear at first order (halving the parameter halves the shift), and a different power law points to a mis-implemented term or a wrong factor. (4) Scan the amplitude: the first-order shift should scale as $A^2$ for a cubic term. (5) Estimate the next-order term; if the extra 0.2% is of the size of the neglected term, the estimate was simply too crude, and a second-order prediction should explain it. Only if the numerics are converged, the limits are right and the scalings agree is the difference attributed to the physics.

rubric: Uses scaling with the parameter or amplitude to test the implementation.
rubric: Compares the discrepancy with the size of the neglected next-order term before concluding.

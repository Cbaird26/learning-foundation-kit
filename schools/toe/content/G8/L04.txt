@article
A result that nobody, including you next month, can repeat is not yet a result. A **reproducibility plan** is a short document written *before* you test your baseline. It says what you will run, with which inputs, and what outcome counts as success. Writing the pass line first prevents you from choosing a tolerance that your output happens to meet.

### What the plan fixes

- **Assumptions.** The baseline card from last week.
- **Inputs.** Every parameter with units and the source of its value, kept in one parameter table or dictionary rather than buried in the code.
- **Code.** Language and library versions, and a version-control identifier for the exact code used.
- **Randomness.** Seeds for every random-number generator, and the number of samples.
- **Outputs.** File names for each table and figure, and the single command that regenerates them.
- **Acceptance criteria.** Numbers, not adjectives.
- **Decision rules.** What you will do if a criterion fails: debug, refine or report.

### Choosing acceptance criteria

Choose each tolerance from an *expected error*, not from the result. A fourth-order Runge–Kutta (RK4) integrator has a global error that scales as $h^4$ with step size $h$, so halving $h$ should reduce the error by about $2^4 = 16$. If $E_1$ is the error at $h$ and $E_2$ the error at $h/2$, the **observed order** is

$$p = \log_2\frac{E_1}{E_2}.$$

A good criterion therefore reads: "The RK4 period at $h = T_0/200$ agrees with $4\sqrt{L/g}\,K(k)$ to a relative difference below $10^{-6}$, and halving $h$ gives an observed order between 3.5 and 4.5."

Statistical outputs get tolerances from sample size. A Monte Carlo estimate from $N$ independent samples has a standard error of order $1/\sqrt{N}$, so a relative tolerance of $10^{-3}$ needs about $10^6$ samples. Fixed seeds make a run repeatable exactly, but they do not make the estimate more accurate.

```python
import numpy as np

PARAMS = {"g_over_L_s2": 1.000, "theta0_deg": 60.0, "h_over_T0": 1/200}

rng = np.random.default_rng(SEED) # used for any sampling

# ... run, then print the key numbers with enough digits to compare them
```

Store the parameters and the seed with the output, so that every result file records how it was made.

### Decision rules

Write what you will do when a criterion fails. For example: "check units and degrees against radians first, then the initial condition, then the definition of the period. Do not loosen the tolerance without recording why." That sentence protects you from quietly moving the goalposts.

@example
title: Acceptance criteria for a numerical period
problem: You will test an RK4 pendulum code against the exact period at $\theta_0 = 60^\circ$ with $g/L = 1.000\ \text{s}^{-2}$. Write the acceptance criteria before running anything.
step: Fix the inputs with units: $g/L = 1.000\ \text{s}^{-2}$, so $T_0 = 2\pi\ \text{s}$; $\theta_0 = 60^\circ = \pi/3$ rad; release from rest; step $h = T_0/200 = 0.0314\ \text{s}$.
step: Fix the reference value from an independent formula: $T_{\rm ref} = 4K(k)$ seconds with $k = \sin 30^\circ = 0.5$, which is $6.7430\ \text{s}$.
step: Choose the tolerance from an expected error. The relative period error of RK4 is of order $(\omega_0 h)^4/120 \approx 10^{-8}$ for this step, so a relative tolerance of $10^{-6}$ leaves a margin of about 100.
step: Add a convergence criterion: errors at $h$ and $h/2$ must give an observed order $p$ between 3.5 and 4.5.
step: Add the decision rule: if the tolerance fails, check degrees against radians, then the initial velocity, then how the period is measured. Record any change of tolerance with the reason.

@mistakes
- Choosing the tolerance after seeing the output, so the test cannot fail.
- Leaving parameters inside the code without units, so the run cannot be reproduced from the plan.
- Forgetting to record seeds, library versions or the code version.
- Writing adjectives ("close", "good agreement") where a number is needed.

answer: 3.93
check: math.log2(3.2e-6/2.1e-7)
tol: 0.02
hint: Divide the two errors first: $E_1/E_2 = 3.2\times10^{-6}/2.1\times10^{-7}$.
hint: The ratio is about 15.2. Take the logarithm to base 2.
solution: $E_1/E_2 = 15.24$ and $\log_2 15.24 = 3.93$. This is close to the expected order 4, so the convergence criterion "between 3.5 and 4.5" is met.

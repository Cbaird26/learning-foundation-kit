@article
To **reproduce** a result is to obtain a known number or curve with your own code from the stated inputs. You do not copy a figure. You compute, compare with a reference, and report the difference. This week you reproduce the exact pendulum period.

### Plan, implement, compare

1. **Nondimensionalize.** With $g/L = 1$ the time unit is $\sqrt{L/g}$ and the equation is $\ddot\theta = -\sin\theta$. Then $T_0 = 2\pi$ and the reference is $T_{\rm ref} = 4K(k)$.
2. **Integrate** the state $(\theta, \omega)$ with fourth-order Runge–Kutta (RK4), release from rest at $\theta_0$.
3. **Measure the period** as the time between two successive upward zero crossings of $\theta$.
4. **Compare** with $T_{\rm ref}$ and report the relative difference against the criterion you fixed in the plan.

```python
import numpy as np

def rhs(y):                        # y = (theta, omega), units with g/L = 1
    return np.array([y[1], -np.sin(y[0])])

def rk4(y, h):
    k1 = rhs(y); k2 = rhs(y + h/2*k1)
    k3 = rhs(y + h/2*k2); k4 = rhs(y + h*k3)
    return y + h/6*(k1 + 2*k2 + 2*k3 + k4)

def crossing(y):                   # time after the step start where theta = 0
    tau = -y[0]/y[1]               # first guess: straight line
    for _ in range(3):             # Newton steps with partial RK4 steps
        ys = rk4(y, tau)
        tau -= ys[0]/ys[1]
    return tau

def period(theta0, h):
    y, t, cross = np.array([theta0, 0.0]), 0.0, []
    while len(cross) < 2:
        y_new = rk4(y, h)
        if y[0] < 0 <= y_new[0]:   # upward crossing inside this step
            cross.append(t + crossing(y))
        y, t = y_new, t + h
    return cross[1] - cross[0]
```

Notice how the crossing is found. Linear interpolation of $\theta$ between steps has an error that scales as $h^3$, which would hide the $h^4$ behavior of RK4. Measurement methods add error too, so test them.

### Convergence study

Compute the period with $h$, $h/2$ and $h/4$. If the error scales as $h^p$, then successive differences shrink by $2^p$:

$$p = \log_2\frac{T_h - T_{h/2}}{T_{h/2} - T_{h/4}},\qquad T \approx T_{h/4} + \frac{T_{h/4} - T_{h/2}}{2^p - 1}.$$

The second formula is **Richardson extrapolation**. It estimates the limit without knowing the exact answer, so it is an independent check on the reference.

### When the test fails

Check in this order, cheapest first: degrees versus radians; the initial condition; the sign and form of the right-hand side; the definition and measurement of the period; the step size. A useful quick test is the small-angle limit: $\theta_0 = 0.01$ should give $T = 2\pi(1 + 6.25\times10^{-6})$.

### Reporting

State the case, the step, the number and the verdict, for example: "At $\theta_0 = 60^\circ$, RK4 with $h = 0.05$ gave a period within a relative difference of [value] of $4K(0.5) = 6.743001$; the criterion was $10^{-6}$." Never write "good agreement" without the number.

@example
title: Reading a convergence table
problem: Three RK4 runs of the $60^\circ$ pendulum with $g/L = 1$ give the periods below (supplied illustrative values, not from a real run). The reference is $T_{\rm ref} = 4K(0.5) = 6.743001$. Estimate the observed order, extrapolate, and judge the pass criterion of relative difference below $10^{-6}$.
step: List the periods. $T(0.4) = 6.744025$, $T(0.2) = 6.743065$, $T(0.1) = 6.743005$.
step: Take the differences between successive runs: $T(0.4) - T(0.2) = 9.60\times10^{-4}$ and $T(0.2) - T(0.1) = 6.0\times10^{-5}$.
step: Their ratio is $16.0$, so $p = \log_2 16 = 4.0$, matching RK4.
step: Extrapolate: $T \approx 6.743005 + (6.743005 - 6.743065)/15 = 6.743001$. This agrees with $T_{\rm ref}$ to the digits shown.
step: Judge the criterion. For $h = 0.1$ the relative difference is $(6.743005 - 6.743001)/6.743001 = 5.9\times10^{-7}$, below $10^{-6}$. The test passes, and the convergence criterion is also satisfied.

@mistakes
- Finding the crossing by linear interpolation and then wondering why the observed order is not 4.
- Measuring between a downward and an upward crossing, which gives a half period, or from the start, which gives three quarters of a period.
- Calling a reproduction successful because the plot looks right, with no relative difference reported.
- Changing the tolerance after a failed test without recording why.

@practice self
prompt: Write Python that computes $T_{\rm ref} = 4K(\sin(\theta_0/2))$ with a library elliptic-integral routine, runs your RK4 period measurement at $h = 0.1$ and $h = 0.05$ for $\theta_0 = 60^\circ$, and prints the relative differences and the observed order. State what you expect the order to be.
hint: SciPy's ellipk takes the parameter $m = k^2$, not $k$.
hint: With two step sizes, the observed order is the base-2 logarithm of the ratio of the two relative errors.
solution: Model code, using the functions from the article.

```python
import numpy as np
from scipy.special import ellipk

theta0 = np.radians(60.0)
ref = 4*ellipk(np.sin(theta0/2)**2)       # scipy uses m = k**2
errs = []
for h in (0.1, 0.05):
    T = period(theta0, h)
    errs.append(abs(T - ref)/ref)
    print(f"h={h}: T={T:.8f}  rel. diff={errs[-1]:.2e}")
print("observed order:", np.log2(errs[0]/errs[1]))
```

Expected order: close to 4 for RK4, provided the crossing is located with the Newton refinement. A value near 3 would point to the crossing measurement rather than the integrator.
rubric: The reference uses the elliptic integral with the correct argument convention, $m = k^2$.
rubric: Relative differences are computed against the reference, not absolute ones, and printed with enough digits.
rubric: The observed order is computed from the ratio of errors at $h$ and $h/2$ with a base-2 logarithm.
rubric: The expected order (about 4) is stated, with a reason for any departure.

@quiz self
prompt: A convergence table of relative differences from the reference at $60^\circ$ reads $2.1\times10^{-3}$ for $h = 0.1$, $2.0\times10^{-3}$ for $h = 0.05$ and $2.0\times10^{-3}$ for $h = 0.025$. Explain what this pattern tells you, list three candidate causes in the order you would check them, and give a quick test for each.
hint: What does it mean that the error does not shrink when the step does?
solution: Model answer. An error that does not fall as $h$ falls is not RK4 truncation error, because that would drop by about 16 per halving. Something independent of $h$ is wrong: the inputs, the model or the reference. Candidate causes in order of cheapness. (1) Mismatched inputs: the code and the reference use different $\theta_0$ (degrees converted with a rounded value) or different $g/L$; test by printing both sets of inputs and by computing the reference from the code's own variables. (2) Wrong period measurement, such as a crossing located with a coarse tolerance or the wrong pair of crossings; test with $\theta_0 = 0.01$, where the answer must be $2\pi(1 + 6.25\times10^{-6})$. (3) A wrong reference, such as using $k$ in place of $m = k^2$ or a truncated series; test by evaluating the reference with a different method such as the arithmetic–geometric mean. Do not loosen the tolerance to make the table pass.

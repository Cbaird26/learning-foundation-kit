@article
Rotate a square by $90^\circ$ and it looks unchanged. Do two such moves in a row and you get another symmetry. Every move can be undone. These three facts are the whole idea of a group.

### The definition

A **group** is a set $G$ with an operation $(a,b)\mapsto ab$ satisfying:

1. **Closure:** $ab\in G$ for all $a,b\in G$.
2. **Associativity:** $(ab)c=a(bc)$ for all $a,b,c\in G$.
3. **Identity:** there is $e\in G$ with $ea=ae=a$ for all $a$.
4. **Inverses:** for each $a$ there is $a^{-1}$ with $aa^{-1}=a^{-1}a=e$.

If also $ab=ba$ for all $a,b$, the group is **abelian**. The **order** $|G|$ is the number of elements.

### Examples to keep in mind

- $(\mathbb{Z},+)$: identity $0$, inverse of $n$ is $-n$. Abelian, infinite.
- $(\mathbb{Z}_n,+)$, addition mod $n$: order $n$, identity $0$, inverse of $a\neq 0$ is $n-a$.
- $(\mathbb{Z}_n^\times,\cdot)$: residues mod $n$ having no common factor with $n$, under multiplication. For $n=10$ this is $\{1,3,7,9\}$. Its order is Euler's $\varphi(n)$.
- $GL_2(\mathbb{R})$: invertible $2\times 2$ real matrices under multiplication. Not abelian.
- $S_3$: the six rearrangements of $\{1,2,3\}$. We write $(1\,2\,3)$ for $1\to2\to3\to1$ and multiply right to left (apply the right factor first). Then $(1\,2)(1\,2\,3)=(2\,3)$ but $(1\,2\,3)(1\,2)=(1\,3)$, so $S_3$ is not abelian.

### Non-examples

To show something is **not** a group you need only one failure. $(\mathbb{Z},-)$ is not associative: $(5-3)-1=1$ but $5-(3-1)=3$. $(\{0,1,2,\dots\},+)$ has no inverses. $(\mathbb{Z},\cdot)$ has identity $1$ but $2$ has no inverse. To show something **is** a group you must check the axiom for all elements, not a few samples.

### First consequences

These follow from the axioms alone.

- **Unique identity:** if $e,e'$ are identities, then $e=ee'=e'$.
- **Unique inverses:** if $b$ and $c$ are inverses of $a$, then $b=be=b(ac)=(ba)c=ec=c$.
- **Socks and shoes:** $(ab)^{-1}=b^{-1}a^{-1}$, since $(ab)(b^{-1}a^{-1})=a(bb^{-1})a^{-1}=aa^{-1}=e$.
- **Cancellation:** if $ab=ac$ then $b=c$, by multiplying on the left by $a^{-1}$.

Cancellation says that in a multiplication table (a **Cayley table**) every row and every column lists each element exactly once.

@example
title: Verifying the axioms for a small table
problem: Show that $G=\{1,3,5,7\}$ with multiplication mod $8$ is a group.
step: Closure. Compute the products: $3\cdot 3=9\equiv 1$, $3\cdot5=15\equiv 7$, $3\cdot 7=21\equiv 5$, $5\cdot5=25\equiv1$, $5\cdot7=35\equiv 3$, $7\cdot7=49\equiv 1$. Every product lies in $G$.
step: Associativity. Multiplication of integers is associative and reducing mod $8$ respects products, so $(ab)c\equiv a(bc)$ with nothing more to check.
step: Identity. The element $1$ satisfies $1\cdot a=a\cdot 1=a$.
step: Inverses. $1\cdot1\equiv3\cdot3\equiv5\cdot5\equiv7\cdot7\equiv1$, so every element is its own inverse.
step: The table is symmetric, so $G$ is abelian of order $4$.

@example
title: Finding a counterexample
problem: On $\mathbb{Z}$ define $a*b=a+2b$. Is $(\mathbb{Z},*)$ a group?
step: Closure holds, because $a+2b$ is an integer.
step: Test associativity on small numbers: $(0*0)*1=0*1=2$, while $0*(0*1)=0*2=4$.
step: One failure is enough: the operation is not associative, so $(\mathbb{Z},*)$ is not a group.
step: The identity also fails. $b*e=b$ forces $e=0$, but $0*b=2b\neq b$ for $b\neq0$.

@mistakes
- Checking closure and an identity but forgetting that every element needs an inverse; this is why $(\mathbb{Z},\cdot)$ and $(\mathbb{Z}_n,\cdot)$ with $0$ included fail.
- Assuming $ab=ba$. In general $(ab)^{-1}=b^{-1}a^{-1}$, not $a^{-1}b^{-1}$, and $(ab)^2\neq a^2b^2$.
- "Proving" associativity or the whole group property from a few sample triples. Samples can only disprove; a proof must cover all elements.

@practice ms
prompt: Select every statement that is true in every group $G$.
choice*: $(ab)^{-1}=b^{-1}a^{-1}$ for all $a,b\in G$.
choice: $ab=ba$ for all $a,b\in G$.
choice*: If $ax=ay$ then $x=y$.
choice: $(ab)^2=a^2b^2$ for all $a,b\in G$.
hint: Test each statement in $S_3$ or $GL_2(\mathbb{R})$ if you suspect it fails.
hint: Statements that need commutativity are false in non-abelian groups.
solution: Socks-and-shoes and cancellation follow from the axioms. Commutativity fails in $S_3$, and $(ab)^2=abab$ equals $a^2b^2=aabb$ only when $ba=ab$.

@practice self
prompt: Prove that every element $a$ of a group $G$ has exactly one inverse, and deduce that $(a^{-1})^{-1}=a$.
hint: Suppose $b$ and $c$ are both inverses of $a$ and compute $bac$ in two ways.
hint: To find the inverse of $a^{-1}$, ask which element multiplies with $a^{-1}$ to give $e$ on both sides.
solution: Let $b,c$ be inverses of $a$. Then $b=be=b(ac)=(ba)c=ec=c$, so the inverse is unique. Now $a\,a^{-1}=a^{-1}a=e$ says exactly that $a$ is an inverse of $a^{-1}$. By uniqueness, $(a^{-1})^{-1}=a$.
rubric: Starts from two assumed inverses $b$ and $c$ and ends with $b=c$.
rubric: Uses associativity explicitly in the step $(ba)c=b(ac)$.
rubric: Shows $a$ satisfies the defining equations of an inverse of $a^{-1}$, then invokes uniqueness.

@quiz num
prompt: How many elements $x$ of $(\mathbb{Z}_{15}^\times,\cdot)$ satisfy $x^2=1$?
answer: 4
check: len([x for x in range(1,15) if math.gcd(x,15)==1 and (x*x)%15==1])
hint: First list the eight elements of $\mathbb{Z}_{15}^\times$.
hint: Square each one mod $15$ and keep those giving $1$.
solution: The elements are $1,2,4,7,8,11,13,14$. Squares mod $15$: $1,4,1,4,4,1,4,1$. So $x=1,4,11,14$ work, giving $4$ elements.

@quiz mc
prompt: On $\mathbb{Z}$ define $a*b=a+b+ab$. This operation is associative and has identity $0$. Which group axiom fails?
choice: Closure, because $a+b+ab$ might not be an integer.
choice: Associativity, because the formula is not symmetric in $a,b,c$.
choice*: Inverses: for example, $1$ has no inverse in $\mathbb{Z}$.
choice: Identity, because $0*a=a$ only for some $a$.
hint: Solve $a*b=0$ for $b$ in terms of $a$.
hint: You should get $b=-a/(1+a)$. For which integers $a$ is this an integer?
solution: $0*a=a$ for every $a$, so $0$ is the identity. The equation $a*b=0$ gives $b(1+a)=-a$. For $a=1$ this is $2b=-1$, which has no integer solution, so $1$ has no inverse and $(\mathbb{Z},*)$ is not a group.

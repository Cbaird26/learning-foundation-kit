@article
Quantum states, vibrations and fields transform under symmetry by **matrices**. A representation is the bridge: it turns an abstract group into matrices, so that group questions become linear algebra.

### Definition

A **representation** of $G$ on a vector space $V$ (real or complex, finite dimensional) is a homomorphism
$$\rho:G\to GL(V),\qquad \rho(gh)=\rho(g)\rho(h),\quad \rho(e)=I.$$
After choosing a basis, each $\rho(g)$ is an invertible $n\times n$ matrix, and $n=\dim V$ is the **dimension**. Equivalently, $G$ acts linearly on $V$ by $g\cdot v=\rho(g)v$. The **kernel** of $\rho$ is a normal subgroup; $\rho$ is **faithful** if the kernel is trivial.

### Examples

- **Trivial:** $\rho(g)=1$ for every $g$.
- **Sign** of $S_n$: $\rho(\sigma)=\operatorname{sgn}(\sigma)$, one-dimensional.
- **Cyclic group $\mathbb{Z}_n$:** the rotation representation $\rho(m)=R(2\pi m/n)$ with $R(\alpha)=\begin{pmatrix}\cos\alpha&-\sin\alpha\\ \sin\alpha&\cos\alpha\end{pmatrix}$. It is a homomorphism because $R(\alpha)R(\beta)=R(\alpha+\beta)$ (angle-addition formulas), and it is well defined mod $n$ because $R(2\pi)=I$.
- **Permutation representation:** $S_n$ acts on $\mathbb{R}^n$ by $\rho(\sigma)e_i=e_{\sigma(i)}$, giving permutation matrices.

### Verifying a representation

You do not need to test every pair. If $G$ is described by generators and relations, it is enough to check that the proposed matrices satisfy the same relations. For $S_3$ generated by $s=(1\,2)$ and $r=(1\,2\,3)$, the defining relations are $s^2=r^3=(sr)^2=e$, so matrices $S,R$ with $S^2=R^3=(SR)^2=I$ define a representation. For a cyclic group $\mathbb{Z}_n$ the only relation is $n\cdot1=0$, so any single invertible matrix $A$ with $A^n=I$ defines a representation $\rho(m)=A^m$.

### Characters

The **character** of $\rho$ is $\chi(g)=\operatorname{tr}\rho(g)$. Three facts:

1. $\chi(e)=\dim V$.
2. $\chi(hgh^{-1})=\chi(g)$, because $\operatorname{tr}(PAP^{-1})=\operatorname{tr}A$. So $\chi$ is constant on conjugacy classes.
3. Changing basis, $\rho'(g)=P\rho(g)P^{-1}$, does not change $\chi$.

The trace is **not** multiplicative: $\chi(gh)\neq\chi(g)\chi(h)$ in general.

For the permutation representation, $\chi(\sigma)$ is the number of fixed points of $\sigma$, since the diagonal entries of a permutation matrix are $1$ at fixed points and $0$ elsewhere.

Lagrange's theorem helps here too: $g^{|G|}=e$ implies $\rho(g)^{|G|}=I$, so every eigenvalue of $\rho(g)$ is a $|G|$-th root of unity, and $\chi(g)$ is a sum of such roots of unity.

@example
title: A two-dimensional representation of $\mathbb{Z}_4$
problem: Let $R=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$ (rotation by $90^\circ$) and define $\rho(m)=R^m$ for $m\in\mathbb{Z}_4$. Verify that $\rho$ is a representation and compute its character.
step: Well defined: $R^2=\begin{pmatrix}-1&0\\0&-1\end{pmatrix}$ and $R^4=I$, so $R^m$ depends only on $m \bmod 4$.
step: Homomorphism: $\rho(m)\rho(n)=R^mR^n=R^{m+n}=\rho(m+n)$.
step: Character: $\operatorname{tr}I=2$, $\operatorname{tr}R=0$, $\operatorname{tr}R^2=-2$, $\operatorname{tr}R^3=0$. So $\chi=(2,0,-2,0)$.
step: $\rho$ is faithful: only $m=0$ gives $\rho(m)=I$.

@example
title: The permutation representation of $S_3$
problem: Write the matrices of $(1\,2)$ and $(1\,2\,3)$ in the permutation representation on $\mathbb{R}^3$ and find their characters.
step: Use $\rho(\sigma)e_i=e_{\sigma(i)}$; the $i$th column of $\rho(\sigma)$ is $e_{\sigma(i)}$.
step: For $(1\,2)$: the columns are $e_2,e_1,e_3$, so the matrix is $\begin{pmatrix}0&1&0\\1&0&0\\0&0&1\end{pmatrix}$, with trace $1$ (one fixed point).
step: For $(1\,2\,3)$: the columns are $e_2,e_3,e_1$, so the matrix is $\begin{pmatrix}0&0&1\\1&0&0\\0&1&0\end{pmatrix}$, with trace $0$ (no fixed points).
step: With $\chi(e)=3$, the character on the classes $\{e\}$, transpositions, $3$-cycles is $(3,1,0)$.

@mistakes
- Checking $\rho(g)\rho(h)=\rho(gh)$ for a single pair, or only for the generators without checking the defining relations.
- Treating the character as multiplicative. Only $\rho$ itself is multiplicative; $\operatorname{tr}(AB)\neq\operatorname{tr}A\operatorname{tr}B$ in general.
- Building a rotation representation of $\mathbb{Z}_n$ with a step that is not a multiple of $2\pi/n$ (for example $\pi/n$), so that $\rho(n)\neq I$ and the map is not well defined.

@practice num
prompt: The cyclic group $\mathbb{Z}_6$ acts on the plane by $\rho(k)=$ rotation through $60^\circ k$. Find the character value $\chi(2)=\operatorname{tr}\rho(2)$.
answer: -1
check: np.trace(np.array([[cos(2*pi/6*2),-sin(2*pi/6*2)],[sin(2*pi/6*2),cos(2*pi/6*2)]]))
hint: $\rho(2)$ is the rotation by $120^\circ$.
hint: The trace of a rotation matrix by angle $\alpha$ is $2\cos\alpha$.
solution: $\operatorname{tr}\rho(2)=2\cos120^\circ=2\cdot(-\tfrac12)=-1$.

@practice num
prompt: In the permutation representation of $S_3$ on $\mathbb{R}^3$, what is the character value of the transposition $(1\,2)$?
answer: 1
check: np.trace(np.eye(3)[[1,0,2]])
hint: The character of a permutation matrix counts fixed points.
hint: Which point does $(1\,2)$ leave fixed?
solution: The transposition $(1\,2)$ fixes the point $3$, so its permutation matrix has trace $1$.

@practice mc
prompt: Which assignment defines a representation $\rho$ of $\mathbb{Z}_2=\{0,1\}$ on $\mathbb{R}$ (one-dimensional)?
choice*: $\rho(0)=1,\ \rho(1)=-1$
choice: $\rho(0)=1,\ \rho(1)=2$
choice: $\rho(0)=0,\ \rho(1)=1$
choice: $\rho(0)=1,\ \rho(1)=0$
hint: A representation needs $\rho(0)=1$ (the identity) and $\rho(1)^2=\rho(1+1)=\rho(0)$.
hint: Also, each $\rho(g)$ must be invertible.
solution: We need $\rho(1)^2=\rho(0)=1$, so $\rho(1)=\pm1$. The option $\rho(1)=2$ gives $\rho(1)^2=4$, and the options with $0$ are not invertible or not the identity at $0$. The choice $\rho(1)=-1$ is the sign representation.

@practice ms
prompt: Let $\rho:G\to GL_n(\mathbb{C})$ be a representation with character $\chi$. Select every statement that must be true.
choice*: $\rho(e)=I$ and $\chi(e)=n$.
choice*: $\rho(g^{-1})=\rho(g)^{-1}$ for every $g\in G$.
choice: $\chi(gh)=\chi(g)\chi(h)$ for all $g,h\in G$.
choice: Some $\rho(g)$ may be a singular matrix.
hint: A representation is a homomorphism into the group $GL_n(\mathbb{C})$.
hint: Test the trace identity on $2\times 2$ matrices such as $A=B=\operatorname{diag}(1,-1)$.
solution: Homomorphisms send identity to identity and inverses to inverses, and every element of $GL_n$ is invertible. The trace is not multiplicative: $\operatorname{tr}(A^2)=\operatorname{tr}I=2$ but $\operatorname{tr}A\cdot\operatorname{tr}A=0$ for $A=\operatorname{diag}(1,-1)$.

@practice self
prompt: Let $R(\alpha)$ be the $2\times2$ rotation matrix by angle $\alpha$. Show that $\rho(m)=R(\pi m/2)$ defines a representation of $\mathbb{Z}_4$, and compute its character.
hint: Two things must be checked: that $\rho$ is well defined on residues mod $4$, and that $\rho(m)\rho(n)=\rho(m+n)$.
hint: Use the angle-addition formulas $\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta$ and the sine analogue.
solution: Well defined: if $m'=m+4j$ then $R(\pi m'/2)=R(\pi m/2+2\pi j)=R(\pi m/2)$. Homomorphism: multiplying the matrices and using the angle-addition formulas gives $R(\alpha)R(\beta)=R(\alpha+\beta)$, so $\rho(m)\rho(n)=R(\pi m/2+\pi n/2)=\rho(m+n)$. Character: $\chi(m)=2\cos(\pi m/2)$, which is $2,0,-2,0$ for $m=0,1,2,3$.
rubric: Shows $\rho$ is well defined mod $4$ (uses $R(2\pi)=I$).
rubric: Proves $R(\alpha)R(\beta)=R(\alpha+\beta)$ via the angle-addition formulas.
rubric: Computes the character $\operatorname{tr}\rho(m)=2\cos(\pi m/2)$ and lists its four values.

@quiz num
prompt: In the permutation representation of $S_4$ on $\mathbb{R}^4$, what is the value of the character on the $3$-cycle $(1\,2\,3)$?
answer: 1
check: np.trace(np.eye(4)[[1,2,0,3]])
hint: The character counts fixed points of the permutation of $\{1,2,3,4\}$.
hint: Which of $1,2,3,4$ does $(1\,2\,3)$ leave unchanged?
solution: The $3$-cycle $(1\,2\,3)$ fixes only the point $4$, so the character value is $1$.

@quiz mc
prompt: The map $\rho:\mathbb{Z}_6\to GL_1(\mathbb{C})$, $\rho(k)=e^{2\pi ik/3}$, is a representation. What is its kernel?
choice: $\{0\}$
choice*: $\{0,3\}$
choice: $\{0,2,4\}$
choice: $\mathbb{Z}_6$
hint: The kernel is the set of $k$ with $\rho(k)=1$.
hint: When is $e^{2\pi ik/3}=1$? You need $k/3$ to be an integer.
solution: $e^{2\pi ik/3}=1$ exactly when $3$ divides $k$. In $\mathbb{Z}_6$ these are $k=0$ and $k=3$, so the kernel is $\{0,3\}$ and $\rho$ is not faithful.

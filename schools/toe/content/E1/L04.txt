@article
A **homomorphism** is a map between groups that respects the operations: a function $\varphi:G\to H$ with
$$\varphi(ab)=\varphi(a)\,\varphi(b)\quad\text{for all }a,b\in G.$$
It translates the structure of $G$ into $H$. Familiar examples:

- $\exp:(\mathbb{R},+)\to(\mathbb{R}_{>0},\cdot)$, since $e^{x+y}=e^xe^y$.
- $\det:GL_n(\mathbb{R})\to(\mathbb{R}^\times,\cdot)$, since $\det(AB)=\det A\det B$.
- Reduction mod $n$: $\mathbb{Z}\to\mathbb{Z}_n$.

### Automatic consequences

From $\varphi(e)=\varphi(ee)=\varphi(e)\varphi(e)$, cancelling gives $\varphi(e)=e$. From $\varphi(a)\varphi(a^{-1})=\varphi(aa^{-1})=\varphi(e)=e$ we get $\varphi(a^{-1})=\varphi(a)^{-1}$. If $a^n=e$, then $\varphi(a)^n=e$, so **the order of $\varphi(a)$ divides the order of $a$**.

### Kernel and image

$$\ker\varphi=\{g\in G:\varphi(g)=e\},\qquad \operatorname{im}\varphi=\{\varphi(g):g\in G\}.$$
Both are subgroups. For the kernel, use the one-step test: if $a,b\in\ker\varphi$ then $\varphi(ab^{-1})=\varphi(a)\varphi(b)^{-1}=e$.

**Key fact:** $\varphi$ is injective if and only if $\ker\varphi=\{e\}$. If the kernel is trivial and $\varphi(a)=\varphi(b)$, then $\varphi(ab^{-1})=e$, so $ab^{-1}=e$ and $a=b$. The converse is immediate since $\varphi(e)=e$.

### Fibers are cosets

If $\varphi(a)=b$, then the set of all solutions of $\varphi(x)=b$ is the coset $a\ker\varphi$, because
$$\varphi(x)=\varphi(a)\iff\varphi(a^{-1}x)=e\iff a^{-1}x\in\ker\varphi.$$
So every point of the image has exactly $|\ker\varphi|$ preimages, and for a finite group $|G|=|\ker\varphi|\cdot|\operatorname{im}\varphi|$. The kernel measures how much information the homomorphism forgets.

### Isomorphisms

A bijective homomorphism is an **isomorphism**; we write $G\cong H$. Isomorphic groups are the same group with different labels, so they share every structural property: order, being abelian, the number of elements of each order. This is how you show two groups differ. $\mathbb{Z}_6\not\cong S_3$ because one is abelian and the other is not. Another quick test: if one group has an element of order $k$ and the other does not, they cannot be isomorphic, since an isomorphism preserves the order of every element.

### Homomorphisms out of $\mathbb{Z}_n$

A homomorphism from a cyclic group is determined by where it sends the generator. A map $\varphi:\mathbb{Z}_n\to\mathbb{Z}_m$ with $\varphi(1)=b$ must be $\varphi(k)=kb$. It is well defined exactly when $nb\equiv0\pmod m$. Counting such $b$ shows that there are exactly $\gcd(n,m)$ homomorphisms $\mathbb{Z}_n\to\mathbb{Z}_m$. More generally, a homomorphism is determined by its values on a generating set, but those values must respect the relations among the generators. You will check exactly this for representations in week 9.

@example
title: Kernel, image and a counting check
problem: Let $\varphi:\mathbb{Z}_{12}\to\mathbb{Z}_{18}$ be $\varphi(x)=3x$. Check it is well defined, then find its kernel and image.
step: Well defined: replacing $x$ by $x+12$ changes $3x$ by $36=2\cdot18\equiv0\pmod{18}$. So $\varphi$ is a homomorphism, since $3(x+y)=3x+3y$.
step: Kernel: solve $3x\equiv0\pmod{18}$, i.e. $x\equiv0\pmod 6$. In $\mathbb{Z}_{12}$ this gives $\ker\varphi=\{0,6\}$.
step: Image: the values $3x\bmod18$ are the multiples of $3$, so $\operatorname{im}\varphi=\{0,3,6,9,12,15\}$, with $6$ elements.
step: Check: $|G|=12=|\ker\varphi|\cdot|\operatorname{im}\varphi|=2\cdot6$. This counting rule is the start of week 6.

@example
title: An injective homomorphism from the real line
problem: Show that $\varphi:(\mathbb{R},+)\to GL_2(\mathbb{R})$, $\varphi(t)=\begin{pmatrix}1&t\\0&1\end{pmatrix}$ is an injective homomorphism.
step: Multiply: $\begin{pmatrix}1&s\\0&1\end{pmatrix}\begin{pmatrix}1&t\\0&1\end{pmatrix}=\begin{pmatrix}1&s+t\\0&1\end{pmatrix}$, so $\varphi(s)\varphi(t)=\varphi(s+t)$.
step: The kernel consists of $t$ with $\varphi(t)=I$, which forces $t=0$.
step: The kernel is trivial, so $\varphi$ is injective, and $(\mathbb{R},+)$ is isomorphic to its image, the matrices $\begin{pmatrix}1&t\\0&1\end{pmatrix}$.

@mistakes
- Assuming a map such as $x\mapsto x+1$ or $x\mapsto x^2$ is a homomorphism without testing $\varphi(ab)=\varphi(a)\varphi(b)$; a homomorphism must send $e$ to $e$.
- Forgetting well-definedness when defining a map out of $\mathbb{Z}_n$ by a formula such as $k\mapsto kb$.
- Concluding "isomorphic" from equal orders alone; $\mathbb{Z}_4$ and the group $\{1,3,5,7\}$ mod $8$ have the same order but are not isomorphic.

@practice num
prompt: Let $\varphi:\mathbb{Z}_{12}\to\mathbb{Z}_{12}$ be $\varphi(x)=4x$. How many elements are in $\ker\varphi$?
answer: 4
check: len([x for x in range(12) if (4*x)%12==0])
hint: Solve $4x\equiv0\pmod{12}$ for $x$ between $0$ and $11$.
hint: Divide through by $4$: $x\equiv0\pmod3$.
solution: $4x$ is a multiple of $12$ exactly when $x$ is a multiple of $3$, so $\ker\varphi=\{0,3,6,9\}$, which has $4$ elements.

@practice num
prompt: How many homomorphisms are there from $(\mathbb{Z}_{12},+)$ to $(\mathbb{Z}_{18},+)$?
answer: 6
check: len([b for b in range(18) if (12*b)%18==0])
hint: A homomorphism is determined by $b=\varphi(1)\in\mathbb{Z}_{18}$, and $b$ must satisfy $12b\equiv0\pmod{18}$.
hint: $12b\equiv0\pmod{18}$ means $2b\equiv0\pmod3$, so $b$ is a multiple of $3$.
solution: The allowed values are $b\in\{0,3,6,9,12,15\}$, giving $6=\gcd(12,18)$ homomorphisms.

@practice ms
prompt: Let $\varphi:G\to H$ be a homomorphism. Select every statement that must be true.
choice*: $\varphi(a^{-1})=\varphi(a)^{-1}$ for all $a\in G$.
choice*: If $G$ is abelian, then $\operatorname{im}\varphi$ is abelian.
choice: $\varphi$ is injective.
choice: If $H$ is abelian, then $G$ is abelian.
hint: Use $\varphi(a)\varphi(b)=\varphi(ab)$ to move products across.
hint: Consider the homomorphism sending every element of a non-abelian group to the identity of $H$.
solution: The statements about $\varphi(a^{-1})$ and about $\operatorname{im}\varphi$ follow from the homomorphism property; for the image, $\varphi(a)\varphi(b)=\varphi(ab)=\varphi(ba)=\varphi(b)\varphi(a)$. A homomorphism need not be injective (the trivial map), and the trivial map from a non-abelian group into an abelian one shows that "$H$ abelian implies $G$ abelian" can fail.

@practice self
prompt: Prove that a homomorphism $\varphi:G\to H$ is injective if and only if $\ker\varphi=\{e\}$.
hint: For the forward direction, what must $\varphi(e)$ be?
hint: For the reverse, assume $\varphi(a)=\varphi(b)$ and show that $ab^{-1}$ lies in the kernel.
solution: Suppose $\varphi$ is injective and $g\in\ker\varphi$. Then $\varphi(g)=e=\varphi(e)$, so $g=e$ and $\ker\varphi=\{e\}$. Conversely, suppose $\ker\varphi=\{e\}$ and $\varphi(a)=\varphi(b)$. Then $\varphi(ab^{-1})=\varphi(a)\varphi(b)^{-1}=e$, so $ab^{-1}\in\ker\varphi=\{e\}$. Hence $a=b$, and $\varphi$ is injective.
rubric: Proves both directions separately.
rubric: Uses $\varphi(e)=e$ in the forward direction.
rubric: Uses $\varphi(b^{-1})=\varphi(b)^{-1}$ (and the homomorphism property) to show $ab^{-1}\in\ker\varphi$ in the reverse direction.

@quiz num
prompt: The map $\varphi:\mathbb{Z}_{20}\to\mathbb{Z}_{30}$, $\varphi(k)=6k$, is a well-defined homomorphism. How many elements does its image have?
answer: 5
check: len({(6*k)%30 for k in range(20)})
hint: The image is the set of multiples of $6$ in $\mathbb{Z}_{30}$.
hint: List $0,6,12,\dots$ until the values repeat mod $30$.
solution: The values are $0,6,12,18,24$ and then $30\equiv0$ again, so the image has $5$ elements. Consistently, $|\ker\varphi|=4$ and $20=4\cdot5$.

@quiz ms
prompt: Select every pair of groups that are isomorphic.
choice*: $(\mathbb{R},+)$ and $(\mathbb{R}_{>0},\cdot)$
choice: $(\mathbb{Z}_6,+)$ and $S_3$
choice*: $(\mathbb{Z}_5^\times,\cdot)$ and $(\mathbb{Z}_4,+)$
choice: $(\mathbb{Z}_8^\times,\cdot)$ and $(\mathbb{Z}_4,+)$
hint: Compare orders first, then whether the groups are abelian, then the orders of elements.
hint: For the pair involving $\mathbb{Z}_8^\times$, square every element of $\{1,3,5,7\}$ mod $8$.
solution: $\exp$ is an isomorphism between $(\mathbb{R},+)$ and $(\mathbb{R}_{>0},\cdot)$. $\mathbb{Z}_6$ is abelian and $S_3$ is not. In $\mathbb{Z}_5^\times$ the powers of $2$ are $2,4,3,1$, so it is cyclic of order $4$ like $\mathbb{Z}_4$. In $\mathbb{Z}_8^\times$ every element squares to $1$, so there is no element of order $4$ and it is not isomorphic to $\mathbb{Z}_4$.

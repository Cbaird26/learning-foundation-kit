@article
Clock arithmetic is a quotient. On a 12-hour clock let $N=\{0,4,8\}$. The four cosets $N,\ 1+N,\ 2+N,\ 3+N$ can be added: $(1+N)+(3+N)=4+N=N$. We have collapsed each coset to a single "hour" and obtained arithmetic mod $4$. Normality is what makes this collapsing consistent.

### Definition

Let $N\trianglelefteq G$. The **quotient group** $G/N$ is the set of cosets $\{gN\}$ with
$$(aN)(bN)=(ab)N.$$
**Well defined.** Suppose $aN=a'N$ and $bN=b'N$, so $a'=an_1$ and $b'=bn_2$ with $n_1,n_2\in N$. Then
$$a'b'=an_1bn_2=ab\,(b^{-1}n_1b)\,n_2\in abN,$$
because $b^{-1}n_1b\in N$ by normality. So the product coset does not depend on the representatives. For a non-normal subgroup this step fails.

The identity is $N$, the inverse of $aN$ is $a^{-1}N$, and associativity is inherited from $G$. For finite $G$,
$$|G/N|=\frac{|G|}{|N|}.$$

### The projection and the First Isomorphism Theorem

The map $\pi:G\to G/N$, $\pi(g)=gN$, is a surjective homomorphism with kernel exactly $N$. So **normal subgroups are exactly the kernels of homomorphisms.**

Conversely, let $\varphi:G\to H$ be any homomorphism with kernel $K$. Then
$$G/K\ \cong\ \operatorname{im}\varphi,\qquad gK\mapsto\varphi(g).$$
This is well defined and injective because $\varphi(a)=\varphi(b)\iff a^{-1}b\in K\iff aK=bK$, and it respects products because $\varphi$ does.

### Examples

- $\mathbb{Z}/n\mathbb{Z}\cong\mathbb{Z}_n$, using the reduction map $\mathbb{Z}\to\mathbb{Z}_n$.
- $GL_n(\mathbb{R})/SL_n(\mathbb{R})\cong\mathbb{R}^\times$, via $\det$.
- $S_n/A_n\cong\mathbb{Z}_2$ (for $n\ge2$), via the sign: the quotient remembers only whether a permutation is even or odd.
- $\mathbb{R}/2\pi\mathbb{Z}\cong U(1)$, the group of complex numbers of modulus $1$, via $t\mapsto e^{it}$: an angle is a real number with multiples of $2\pi$ forgotten.

### How to read a quotient

Quotienting by $N$ means **ignoring** whatever $N$ does. The coset $gN$ records everything about $g$ except the part $N$ can change. Whenever a physical description contains redundant information that forms a normal subgroup (for example an overall phase), the meaningful objects live in the quotient. A quotient can be simpler than the group it comes from: $S_3$ is not abelian, but $S_3/A_3\cong\mathbb{Z}_2$ is. Information is lost, and that is the point.

@example
title: Constructing a quotient and identifying it
problem: Describe $\mathbb{Z}_{12}/N$ for $N=\langle4\rangle$ and identify it with a familiar group.
step: $N=\{0,4,8\}$, so $|\mathbb{Z}_{12}/N|=12/3=4$. The cosets are $N$, $1+N=\{1,5,9\}$, $2+N=\{2,6,10\}$, $3+N=\{3,7,11\}$. ($N$ is normal because $\mathbb{Z}_{12}$ is abelian.)
step: Add cosets by adding representatives: $(2+N)+(3+N)=5+N=1+N$ and $(3+N)+(3+N)=6+N=2+N$.
step: The element $1+N$ generates: its multiples are $1+N,\ 2+N,\ 3+N,\ 4+N=N$.
step: So $k+N\mapsto k\bmod4$ is an isomorphism $\mathbb{Z}_{12}/N\cong\mathbb{Z}_4$. The quotient remembers only the hour mod $4$.

@example
title: Using the First Isomorphism Theorem
problem: Let $\varphi:\mathbb{Z}_{12}\to\mathbb{Z}_{18}$, $\varphi(x)=3x$. Identify $\mathbb{Z}_{12}/\ker\varphi$.
step: From week 4, $\ker\varphi=\{0,6\}$ and $\operatorname{im}\varphi=\{0,3,6,9,12,15\}$.
step: By the First Isomorphism Theorem, $\mathbb{Z}_{12}/\{0,6\}\cong\operatorname{im}\varphi$, which has $6$ elements.
step: The image is generated by $3$ (its multiples $3,6,9,12,15,0$ exhaust it), so it is cyclic of order $6$.
step: Hence $\mathbb{Z}_{12}/\{0,6\}\cong\mathbb{Z}_6$: reduce a number mod $6$.

@mistakes
- Forming $G/H$ for a subgroup that is not normal; the product $(aH)(bH)$ then depends on the representatives.
- Thinking $G/N$ is a subgroup of $G$. Its elements are cosets, not elements of $G$.
- Reading $G/N$ as "$G$ with $N$ removed". The quotient has $|G|/|N|$ elements, and each element is an entire coset.

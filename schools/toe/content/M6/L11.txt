@article
Does the interval $(0, 1)$ have a largest element? No: if $x < 1$, then $\frac{x + 1}{2}$ lies between $x$ and $1$. Yet $1$ clearly plays the role of a ceiling: it is the smallest number that is at least as big as every element. That ceiling is the **supremum**, and the fact that it always exists is what separates $\mathbb{R}$ from $\mathbb{Q}$.

### Definitions

Let $S \subseteq \mathbb{R}$ be nonempty.

- $u$ is an **upper bound** of $S$ if $x \le u$ for every $x \in S$. If one exists, $S$ is **bounded above**.
- $M$ is a **maximum** of $S$ if $M \in S$ and $M$ is an upper bound of $S$.
- $s$ is the **supremum** (least upper bound), written $s = \sup S$, if (i) $s$ is an upper bound of $S$, and (ii) $s \le u$ for every upper bound $u$ of $S$.

Lower bounds, the minimum and the **infimum** $\inf S$ (greatest lower bound) are defined the same way with the inequalities reversed.

A supremum need not belong to the set. For $S = (0, 1)$ we have $\sup S = 1 \notin S$, and there is no maximum. For $S = [0, 1]$ the supremum is $1 \in S$, so it is also the maximum. For $S = \{\frac{1}{n} : n \in \mathbb{N}\}$, $\sup S = 1$ is a maximum, while $\inf S = 0$ is not attained.

### Proving a supremum

To prove $s = \sup S$ you must do **both** parts:

1. Show $x \le s$ for every $x \in S$.
2. Show no smaller number is an upper bound: if $u < s$, then some $x \in S$ has $x > u$.

Part 2 is the contrapositive of (ii), and it is usually where the work is.

### The completeness axiom

**Completeness.** Every nonempty subset of $\mathbb{R}$ that is bounded above has a supremum in $\mathbb{R}$.

This is an axiom: we adopt it rather than prove it, and it characterises the real numbers. It fails for the rationals. Let $S = \{q \in \mathbb{Q} : q^2 < 2\}$. It is bounded above in $\mathbb{Q}$ (by $2$), but its only candidate for a least upper bound is $\sqrt{2}$, which is not rational. In fact, if $u$ is any rational upper bound, so $u > 0$ and $u^2 > 2$, then $u' = \frac{1}{2}\left(u + \frac{2}{u}\right)$ is a smaller rational upper bound, because $u' < u$ exactly when $u^2 > 2$, and $u'^2 - 2 = \frac{1}{4}\left(u - \frac{2}{u}\right)^2 > 0$. So no rational upper bound is the least:

```python
from fractions import Fraction

u = Fraction(2)
for _ in range(3):
    u = (u + 2 / u) / 2   # a smaller rational upper bound each time
    print(u)               # 3/2, then 17/12, then 577/408
```

@example
title: The naturals are not bounded above
problem: Use the completeness axiom to prove that $\mathbb{N}$ is not bounded above in $\mathbb{R}$.
step: Suppose, for contradiction, that $\mathbb{N}$ is bounded above. It is nonempty, so by completeness $s = \sup \mathbb{N}$ exists.
step: The number $s - 1$ is smaller than $s$, so it is not an upper bound of $\mathbb{N}$, since $s$ is the least upper bound.
step: Hence there is a natural number $n$ with $n > s - 1$.
step: Then $n + 1 > s$. But $n + 1 \in \mathbb{N}$ and $s$ is an upper bound of $\mathbb{N}$, so $n + 1 \le s$. This is a contradiction.
step: So $\mathbb{N}$ is not bounded above. A consequence we will use: for every real $\varepsilon > 0$ there is $n \in \mathbb{N}$ with $\frac{1}{n} < \varepsilon$ (take any $n > \frac{1}{\varepsilon}$).

@example
title: A supremum that is not a maximum
problem: Let $S = \{1 - \frac{1}{n} : n \in \mathbb{N}\}$. Prove that $\sup S = 1$ and that $S$ has no maximum.
step: Part 1, upper bound. For every $n$, $1 - \frac{1}{n} < 1$, so $1$ is an upper bound of $S$.
step: Part 2, least. Let $u < 1$. We show $u$ is not an upper bound. Set $\varepsilon = 1 - u > 0$.
step: By the consequence of the previous example, choose $n$ with $\frac{1}{n} < \varepsilon$. Then $1 - \frac{1}{n} > 1 - \varepsilon = u$.
step: So some element of $S$ exceeds $u$. No number below $1$ is an upper bound, hence $\sup S = 1$.
step: No maximum. If $S$ had a maximum $M$, then $M$ would equal $\sup S = 1$. But $1 \notin S$, since $1 - \frac{1}{n} = 1$ would force $\frac{1}{n} = 0$. So $S$ is bounded above yet has no maximum.

@mistakes
- Confusing the supremum with the maximum. The set $(0, 1)$ has supremum $1$ but no largest element.
- Showing only that $s$ is an upper bound and forgetting to show that it is the least one.
- Testing a few elements and declaring a number an upper bound, or taking the largest listed element as the supremum of an infinite set.
- Applying the completeness axiom to a set that is empty or not bounded above. Both hypotheses are needed.

hint: Is $3$ an upper bound? Is there a smaller upper bound? Is $3$ an element of $S$?
hint: A bound that lies below the set, such as $0$, is a lower bound, not an upper bound.
solution: Every element of $S$ is less than $3$, so $3$ is an upper bound, and any $u < 3$ is exceeded by an element of $S$ (for example the midpoint of $\max(u, 0)$ and $3$). So $\sup S = 3$. Since $3 \notin S$, there is no maximum. A supremum can exist without a maximum, and $0$ is a lower bound.

solution: Let $S = \{\frac{n}{n+1} : n \in \mathbb{N}\}$. Upper bound: $\frac{n}{n+1} < 1$ for every $n$, so $1$ is an upper bound of $S$. Least: let $u < 1$ and set $\varepsilon = 1 - u > 0$. @practice self
prompt: Let $S$ be a nonempty set of real numbers that is bounded above, and let $T = \{2x : x \in S\}$. Prove that $\sup T = 2 \sup S$.
solution: Let $s = \sup S$. Upper bound: if $y \in T$ then $y = 2x$ for some $x \in S$, and $x \le s$, so $y \le 2s$. Hence $2s$ is an upper bound of $T$. Least: let $u$ be any upper bound of $T$. For each $x \in S$ we have $2x \in T$, so $2x \le u$, that is, $x \le \frac{u}{2}$. So $\frac{u}{2}$ is an upper bound of $S$, and since $s$ is the least upper bound, $s \le \frac{u}{2}$, which gives $2s \le u$. Therefore $2s$ is the least upper bound of $T$. $\blacksquare$
rubric: The proof shows that $2s$ is an upper bound of $T$, starting from an arbitrary element $2x$ of $T$.
rubric: The proof takes an arbitrary upper bound $u$ of $T$ and shows $\frac{u}{2}$ is an upper bound of $S$.
rubric: It uses that $s$ is the least upper bound of $S$ to conclude $2s \le u$.
hint: Let $s = \sup S$ and verify the two parts of the definition for the number $2s$ and the set $T$.
hint: For the second part, take an upper bound $u$ of $T$ and divide it by $2$. What can you say about it as a bound for $S$?

answer: 1

solution: The elements are $1, 2, \frac{7}{3}, \frac{5}{2}, \dots$, increasing toward $3$. The smallest element is $1$ (at $n = 1$), so $\inf S = \min S = 1$. The number $3$ is the supremum, which is not attained.

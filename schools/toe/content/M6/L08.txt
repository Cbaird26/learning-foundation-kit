@article
Sort a pile of integers into "even" and "odd" boxes. Every integer lands in exactly one box, and two integers share a box exactly when their difference is even. An **equivalence relation** captures this idea of "being the same in some respect".

### Definition

A relation $\sim$ on a set $A$ is an **equivalence relation** if it is reflexive, symmetric and transitive. The **equivalence class** of $a \in A$ is
$$[a] = \{x \in A : x \sim a\}.$$
For example, **congruence mod $3$**, where $a \equiv b \pmod 3$ means $3 \mid a - b$, is an equivalence relation on $\mathbb{Z}$ with exactly three classes: $[0] = \{\dots, -3, 0, 3, 6, \dots\}$, $[1] = \{\dots, -2, 1, 4, 7, \dots\}$ and $[2] = \{\dots, -1, 2, 5, 8, \dots\}$. Notice $[1] = [4] = [-2]$: one class has many names.

### Classes partition the set

A **partition** of $A$ is a collection of nonempty, pairwise disjoint subsets (the **blocks**) whose union is $A$.

**Theorem.** Let $\sim$ be an equivalence relation on $A$. Then (i) $a \in [a]$; (ii) if $a \sim b$ then $[a] = [b]$; (iii) if $[a] \cap [b] \neq \emptyset$ then $[a] = [b]$. Hence the classes form a partition of $A$.

**Proof.** (i) Reflexivity gives $a \sim a$. (ii) Suppose $a \sim b$ and let $y \in [a]$, so $y \sim a$. Transitivity applied to $y \sim a$ and $a \sim b$ gives $y \sim b$, so $y \in [b]$. Thus $[a] \subseteq [b]$. By symmetry $b \sim a$, and the same argument gives $[b] \subseteq [a]$. (iii) Let $x \in [a] \cap [b]$. Then $x \sim a$ and $x \sim b$, so $a \sim x$ by symmetry and $a \sim b$ by transitivity; now apply (ii). By (i) the classes are nonempty and cover $A$, and by (iii) two classes are equal or disjoint. $\blacksquare$

### Every partition comes from an equivalence relation

Conversely, given a partition of $A$, define $a \sim b$ to mean "$a$ and $b$ lie in the same block". The classes are exactly the blocks. So equivalence relations and partitions are the same data in two disguises. A program can count the equivalence relations on a three-element set by testing all $512$ relations:

```python
from itertools import product

A = [0, 1, 2]
pairs = [(a, b) for a in A for b in A]
count = 0
for bits in product([0, 1], repeat=9):
    R = {p for p, bit in zip(pairs, bits) if bit}
    refl = all((a, a) in R for a in A)
    sym = all((b, a) in R for (a, b) in R)
    trans = all((a, d) in R for (a, b) in R for (c, d) in R if b == c)
    count += refl and sym and trans
print(count)   # 5
```

The five relations match the five partitions of $\{0, 1, 2\}$: all singletons, three ways to pair two elements, and one block holding everything.

### Building examples and counterexamples

To test a claim about relations, try the smallest set that could break it. A claim "every relation with properties X and Y has property Z" is refuted by one explicit relation that has X and Y but not Z. Verify each property separately, and write the relation as a list of pairs.

@example
title: Listing equivalence classes
problem: Let $A = \{1, 2, \dots, 8\}$ and define $a \sim b$ when $3 \mid a - b$. List the equivalence classes.
step: This is an equivalence relation, by the same three-line proof as for "difference is even" with $3$ in place of $2$. So the classes partition $A$.
step: Start with $1$. The class $[1]$ is every $x \in A$ with $3 \mid x - 1$, namely $[1] = \{1, 4, 7\}$.
step: The smallest element not yet used is $2$: $[2] = \{2, 5, 8\}$. The smallest remaining element is $3$: $[3] = \{3, 6\}$.
step: Every element of $A$ appears in exactly one class, and $3 + 3 + 2 = 8$. There are three distinct classes, and for instance $[1] = [4] = [7]$.

@example
title: Refuting a claim by construction
problem: Claim: every symmetric and transitive relation is reflexive. Decide whether this is true.
step: Reflexivity needs $(a, a) \in R$ for every $a \in A$. To refute the claim we need a symmetric, transitive relation that leaves some element out.
step: Take $A = \{1, 2\}$ and $R = \{(1,1)\}$.
step: Symmetric: the only pair is $(1,1)$, and its reverse is itself.
step: Transitive: the only chain is $(1,1), (1,1)$, whose shortcut $(1,1)$ is in $R$.
step: Not reflexive: $(2,2) \notin R$. So the claim is false. The tempting "proof" ($a \,R\, b$, so $b \,R\, a$, so $a \,R\, a$) silently assumes every $a$ is related to something, which fails for $2$.

@mistakes
- Counting $[1]$, $[4]$ and $[7]$ as three different classes. They are one class with three names.
- Believing that symmetric and transitive together imply reflexive. They do not, as the second example shows.
- Calling a collection a partition when blocks overlap, when an element is left out, or when a block is empty.
- Giving a counterexample without verifying each hypothesis, so the reader cannot tell it satisfies them.

@practice self
prompt: Let $\sim_1$ and $\sim_2$ be equivalence relations on a set $A$. (a) Prove that the intersection, defined by $a \sim b$ when both $a \sim_1 b$ and $a \sim_2 b$, is an equivalence relation. (b) Show by a counterexample on $\{1, 2, 3\}$ that the union of two equivalence relations need not be an equivalence relation.
solution: (a) Reflexive: $a \sim_1 a$ and $a \sim_2 a$, so $a \sim a$. Symmetric: if $a \sim b$ then $a \sim_1 b$ and $a \sim_2 b$, so $b \sim_1 a$ and $b \sim_2 a$ by symmetry of each, giving $b \sim a$. Transitive: if $a \sim b$ and $b \sim c$, then $a \sim_1 b$, $b \sim_1 c$ give $a \sim_1 c$, and likewise $a \sim_2 c$, so $a \sim c$. (b) Let $\sim_1$ have classes $\{1,2\}, \{3\}$ and $\sim_2$ have classes $\{1\}, \{2,3\}$. In the union, $1$ is related to $2$ (through $\sim_1$) and $2$ is related to $3$ (through $\sim_2$), but $1$ and $3$ are in different classes of both relations, so $(1,3)$ is not in the union. The union is not transitive.
rubric: Part (a) proves reflexivity, symmetry and transitivity, using the corresponding property of both $\sim_1$ and $\sim_2$ each time.
rubric: Part (b) names two explicit equivalence relations on $\{1, 2, 3\}$, for instance as partitions.
rubric: Part (b) identifies a specific chain in the union whose shortcut is missing and concludes the union is not transitive.
hint: For (a), a pair is in the intersection when it is in both relations, so apply each property to both relations.
hint: For (b), choose two partitions of $\{1, 2, 3\}$ so that $1$ and $2$ are together in one and $2$ and $3$ are together in the other.

answer: 14

hint: A pair $(a, b)$ belongs to $\sim$ exactly when $a$ and $b$ are in the same block, including the case $a = b$.
hint: Count the ordered pairs inside each block separately, then add.
solution: A block of size $s$ contributes $s \cdot s$ ordered pairs (any element of the block first, any element second). So the total is $3^2 + 2^2 + 1^2 = 9 + 4 + 1 = 14$.

@quiz self
prompt: Let $\mathcal{P}$ be a partition of a set $A$, and define $a \sim b$ to mean that $a$ and $b$ lie in the same block of $\mathcal{P}$. Prove that $\sim$ is an equivalence relation.
solution: Reflexive: the blocks cover $A$, so each $a$ lies in some block, and $a$ lies in the same block as itself, so $a \sim a$. Symmetric: if $a$ and $b$ lie in the same block, then so do $b$ and $a$, so $a \sim b$ implies $b \sim a$. Transitive: suppose $a, b$ lie in a block $B_1$ and $b, c$ lie in a block $B_2$. Then $b \in B_1 \cap B_2$. Distinct blocks are disjoint, so $B_1 = B_2$, and therefore $a$ and $c$ lie in this common block, that is, $a \sim c$. $\blacksquare$
rubric: Reflexivity uses the fact that the blocks cover $A$.
rubric: Symmetry is argued from the symmetric wording "lie in the same block".
rubric: Transitivity uses that distinct blocks are disjoint to conclude the two blocks are the same.
hint: Translate each property into a statement about blocks, and recall what makes a collection of subsets a partition.
hint: For transitivity, let the two blocks be $B_1$ and $B_2$ and find an element they share.

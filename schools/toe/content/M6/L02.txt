@article
A **set** is a collection of objects called its **elements**; $x \in A$ says that $x$ is an element of $A$. A set is determined by its elements alone, so order and repetition do not matter: $\{1, 2, 2\} = \{2, 1\}$. In this course $\mathbb{N} = \{1, 2, 3, \dots\}$, and $\mathbb{Z}$, $\mathbb{Q}$, $\mathbb{R}$ are the integers, rationals and reals. The empty set is $\varnothing$.

**Set-builder notation** $\{x \in S : P(x)\}$ collects the elements of $S$ that make $P(x)$ true. For example, $\{n \in \mathbb{Z} : n^2 < 5\} = \{-2, -1, 0, 1, 2\}$.

### Subsets and equality

$A \subseteq B$ means $\forall x,\ (x \in A \Rightarrow x \in B)$. Negating with last week's rules, $A \not\subseteq B$ means $\exists x \in A,\ x \notin B$: one element of $A$ outside $B$ is enough. Two sets are equal when each is a subset of the other:

$$A = B \iff (A \subseteq B \ \text{and}\ B \subseteq A).$$

Keep **element** and **subset** apart. In $A = \{1, \{1\}\}$ both $1 \in A$ and $\{1\} \in A$, and also $\{1\} \subseteq A$. The empty set is a subset of every set (the condition is vacuously true), yet $\varnothing \neq \{\varnothing\}$: the second set has one element.

### Operations

| notation | meaning |
|---|---|
| $A \cup B$ | $\{x : x \in A \text{ or } x \in B\}$ |
| $A \cap B$ | $\{x : x \in A \text{ and } x \in B\}$ |
| $A \setminus B$ | $\{x : x \in A \text{ and } x \notin B\}$ |
| $\overline{A}$ | $U \setminus A$, for a universal set $U$ |
| $A \times B$ | $\{(a, b) : a \in A,\ b \in B\}$ |
| $\mathcal{P}(A)$ | the set of all subsets of $A$ |

For finite sets, $\lvert A \times B \rvert = \lvert A \rvert \cdot \lvert B \rvert$ and $\lvert \mathcal{P}(A) \rvert = 2^{\lvert A \rvert}$, because each element is either in a subset or not.

### Element-chasing

To prove $X \subseteq Y$, write: "Let $x \in X$." Unpack what membership in $X$ means, and finish with "Therefore $x \in Y$." Because $x$ was arbitrary, this proves the universal statement. To prove $X = Y$, chase elements in both directions.

### Functions

A **function** $f : A \to B$ assigns to **each** $a \in A$ **exactly one** value $f(a) \in B$. $A$ is the domain, $B$ the codomain, and the **range** $f(A) = \{f(a) : a \in A\}$ may be smaller than $B$. A rule fails to be a function when some input has no allowed output (the rule $n \mapsto n/2$ from $\mathbb{Z}$ to $\mathbb{Z}$ fails at $n = 1$) or some input gets two outputs.

For $X \subseteq A$ and $Y \subseteq B$, the **image** and **preimage** are

$$f(X) = \{f(x) : x \in X\}, \qquad f^{-1}(Y) = \{a \in A : f(a) \in Y\}.$$

The preimage exists for **every** function, even one with no inverse function. Finally, if $f : A \to B$ and $g : B \to C$, the **composition** $g \circ f : A \to C$ is $(g \circ f)(a) = g(f(a))$.

@example
title: An image and a preimage
problem: Let $f : \mathbb{R} \to \mathbb{R}$, $f(x) = x^2 - 2x$. Find $f([0, 3])$ and $f^{-1}([3, 8])$.
step: Complete the square: $f(x) = (x - 1)^2 - 1$. The graph is a parabola with lowest point $(1, -1)$.
step: On $[0, 3]$ the smallest value is $f(1) = -1$. The largest is at the endpoint farther from $1$: $f(3) = 3$, while $f(0) = 0$. Since $f$ is continuous, every value in between is taken, so $f([0, 3]) = [-1, 3]$.
step: For the preimage, solve $3 \le (x - 1)^2 - 1 \le 8$, that is, $4 \le (x - 1)^2 \le 9$.
step: This says $2 \le \lvert x - 1 \rvert \le 3$, so $x - 1 \in [-3, -2] \cup [2, 3]$.
step: Therefore $f^{-1}([3, 8]) = [-2, -1] \cup [3, 4]$. Check the endpoints: $f(-2) = 8$, $f(-1) = 3$, $f(3) = 3$, $f(4) = 8$.

@example
title: A set identity by element-chasing
problem: Prove that $A \times (B \cap C) = (A \times B) \cap (A \times C)$ for all sets $A$, $B$, $C$.
step: ($\subseteq$) Let $p \in A \times (B \cap C)$. Then $p = (a, x)$ with $a \in A$ and $x \in B \cap C$.
step: Since $x \in B$, $p \in A \times B$; since $x \in C$, $p \in A \times C$. So $p \in (A \times B) \cap (A \times C)$.
step: ($\supseteq$) Let $p \in (A \times B) \cap (A \times C)$. From $p \in A \times B$, $p = (a, x)$ with $a \in A$ and $x \in B$. From $p \in A \times C$, the same second coordinate $x$ lies in $C$.
step: So $x \in B \cap C$ and $p = (a, x) \in A \times (B \cap C)$. Both inclusions hold, so the two sets are equal.

@mistakes
- Confusing $\in$ with $\subseteq$, for example writing $1 \subseteq \{1, 2\}$ or $\{1\} \in \{1, 2\}$.
- Proving only one inclusion when the claim is that two sets are equal.
- Thinking that $f^{-1}(Y)$ only makes sense when $f$ has an inverse function; the preimage is defined for every function.
- Treating $\varnothing$ and $\{\varnothing\}$ as the same set.

@practice num
prompt: Let $A = \{1, 2, \{1, 2\}, \varnothing\}$. How many elements does $\mathcal{P}(A)$ have?
answer: 16
check: 2**len({1, 2, (1, 2), ()})
hint: First count the elements of $A$. The set $\{1, 2\}$ and the empty set are each a single element of $A$.
hint: A set with $n$ elements has $2^n$ subsets.
solution: $A$ has four elements: $1$, $2$, $\{1, 2\}$ and $\varnothing$. So $\lvert \mathcal{P}(A) \rvert = 2^4 = 16$. (Here $\varnothing$ is both an element of $A$ and, like for every set, a subset of $A$.)

@practice list
prompt: Let $f : \mathbb{Z} \to \mathbb{Z}$, $f(n) = n^2 - 3n$. List every element of the preimage $f^{-1}(\{0, 4\})$.
answer: -1, 0, 3, 4
check: [n for n in range(-100, 101) if n**2 - 3*n in (0, 4)]
hint: $f^{-1}(\{0, 4\})$ is the set of integers $n$ with $f(n) = 0$ or $f(n) = 4$.
hint: Solve $n^2 - 3n = 0$ and $n^2 - 3n - 4 = 0$ by factoring.
solution: $n^2 - 3n = n(n - 3) = 0$ gives $n = 0, 3$. $n^2 - 3n - 4 = (n - 4)(n + 1) = 0$ gives $n = 4, -1$. So $f^{-1}(\{0, 4\}) = \{-1, 0, 3, 4\}$.

@practice mc
prompt: A function $f : A \to \mathbb{R}$ is **bounded** if $\exists M \in \mathbb{R},\ \forall x \in A,\ \lvert f(x) \rvert \le M$. Which statement says precisely that $f$ is **not** bounded?
choice*: $\forall M \in \mathbb{R},\ \exists x \in A,\ \lvert f(x) \rvert > M$
choice: $\exists M \in \mathbb{R},\ \forall x \in A,\ \lvert f(x) \rvert > M$
choice: $\forall M \in \mathbb{R},\ \forall x \in A,\ \lvert f(x) \rvert > M$
choice: $\exists M \in \mathbb{R},\ \exists x \in A,\ \lvert f(x) \rvert > M$
choice: $\forall x \in A,\ \exists M \in \mathbb{R},\ \lvert f(x) \rvert > M$
hint: Move $\neg$ inward one quantifier at a time, flipping each quantifier and keeping its domain.
hint: Keep the quantifiers in their original order. At the end, negate $\lvert f(x) \rvert \le M$.
solution: $\neg \exists M\, \forall x\, (\lvert f(x) \rvert \le M) \equiv \forall M\, \exists x\, (\lvert f(x) \rvert > M)$: whatever bound you propose, some value of $f$ exceeds it. The choice $\forall x \in A,\ \exists M \in \mathbb{R},\ \lvert f(x) \rvert > M$ swaps the order of the quantifiers and is true for every function (take $M = \lvert f(x) \rvert - 1$), so it cannot mean "not bounded".

@practice self
prompt: Prove that for all sets $A$, $B$, $C$: $A \setminus (B \cup C) = (A \setminus B) \cap (A \setminus C)$.
hint: Prove two inclusions. Begin each with an arbitrary element of one side.
hint: $x \notin B \cup C$ means it is not true that ($x \in B$ or $x \in C$). Negate the "or".
hint: For the reverse inclusion, start from $x \in A$, $x \notin B$ and $x \notin C$.
solution: ($\subseteq$) Let $x \in A \setminus (B \cup C)$. Then $x \in A$ and $x \notin B \cup C$. Since $x \notin B \cup C$, it is not the case that $x \in B$ or $x \in C$, so $x \notin B$ and $x \notin C$. Hence $x \in A \setminus B$ and $x \in A \setminus C$, so $x \in (A \setminus B) \cap (A \setminus C)$.
($\supseteq$) Let $x \in (A \setminus B) \cap (A \setminus C)$. Then $x \in A$, $x \notin B$ and $x \notin C$. So $x$ is in neither $B$ nor $C$, which means $x \notin B \cup C$, and therefore $x \in A \setminus (B \cup C)$.
Both inclusions hold, so the sets are equal.
rubric: Both inclusions are proved, each starting from an arbitrary element.
rubric: The step "$x \notin B \cup C$ exactly when $x \notin B$ and $x \notin C$" is stated and used correctly.
rubric: The proof ends by citing the two inclusions to conclude equality.

@quiz ms
prompt: Let $f : \mathbb{R} \to \mathbb{R}$, $f(x) = x^2$. Select every true statement.
choice*: $f([-1, 2]) = [0, 4]$
choice: $f^{-1}([4, 9]) = [2, 3]$
choice*: $f^{-1}([-1, 0]) = \{0\}$
choice: $f^{-1}(f([1, 2])) = [1, 2]$
choice*: $f(f^{-1}([-4, 4])) = [0, 4]$
hint: For a preimage, solve the inequality for $x$, and remember that negative $x$ have positive squares.
hint: For a composite such as $f^{-1}(f(X))$, compute the inner set first.
solution: On $[-1, 2]$, $x^2$ takes every value from $0$ (at $x = 0$) to $4$ (at $x = 2$), so the statement $f([-1, 2]) = [0, 4]$ is true. $4 \le x^2 \le 9$ also holds on $[-3, -2]$, so the statement $f^{-1}([4, 9]) = [2, 3]$ is false. $x^2 \le 0$ forces $x = 0$, so the statement $f^{-1}([-1, 0]) = \{0\}$ is true. $f([1, 2]) = [1, 4]$ and its preimage is $[-2, -1] \cup [1, 2]$, so the statement $f^{-1}(f([1, 2])) = [1, 2]$ is false. $f^{-1}([-4, 4]) = [-2, 2]$ and $f([-2, 2]) = [0, 4]$, so the statement $f(f^{-1}([-4, 4])) = [0, 4]$ is true.

@quiz num
prompt: How many functions $f : \{1, 2, 3, 4\} \to \{1, 2, 3\}$ satisfy $f(1) = 1$?
answer: 27
check: sum(1 for a in range(1, 4) for b in range(1, 4) for c in range(1, 4) for d in range(1, 4) if a == 1)
hint: A function is determined by choosing one output for each input.
hint: The output at $1$ is fixed. How many choices are there for each of $f(2)$, $f(3)$, $f(4)$?
solution: $f(1) = 1$ is forced, and each of $f(2)$, $f(3)$, $f(4)$ can be any of $3$ values independently, so there are $3^3 = 27$ such functions.

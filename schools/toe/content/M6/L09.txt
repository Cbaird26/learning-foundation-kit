@article
A function $f: A \to B$ assigns to each $a \in A$ exactly one value $f(a) \in B$. The set $A$ is the **domain**, $B$ is the **codomain**, and the set of values actually attained, $\{f(a) : a \in A\}$, is the **range**. The codomain is part of the definition of the function, and that matters below.

### Two ways to behave well

A function is **injective** (one-to-one) if different inputs always give different outputs:
$$\forall a, a' \in A:\quad f(a) = f(a') \Rightarrow a = a'.$$
It is **surjective** (onto) if every element of the codomain is hit:
$$\forall b \in B\ \exists a \in A:\quad f(a) = b.$$
A **bijection** is both. Injective means at most one input per output, surjective means at least one, and bijective means exactly one.

The same rule can behave differently on different sets:

| Function | Injective? | Surjective? |
|---|---|---|
| $x \mapsto x^2$, from $\mathbb{R}$ to $\mathbb{R}$ | no ($f(-2) = f(2)$) | no ($-1$ is never hit) |
| $x \mapsto x^2$, from $\mathbb{R}$ to $[0, \infty)$ | no | yes |
| $x \mapsto x^2$, from $[0, \infty)$ to $[0, \infty)$ | yes | yes |

### Proof templates

- **Prove injective:** Suppose $f(a) = f(a')$. (Algebra.) Therefore $a = a'$.
- **Prove surjective:** Let $b \in B$ be arbitrary. (Find $a$, often by solving $f(a) = b$.) Check that $a \in A$ and $f(a) = b$.
- **Refute injective:** give two different inputs with the same output.
- **Refute surjective:** name one element of the codomain and prove that nothing maps to it.

The check "$a \in A$" is not decoration. It is exactly where surjectivity proofs fail when the domain is restricted.

### Composition and inverses

The composition $(g \circ f)(a) = g(f(a))$ of injective functions is injective, and of surjective functions is surjective, so a composition of bijections is a bijection. A function $f: A \to B$ is a bijection exactly when it has an **inverse** $f^{-1}: B \to A$ with $f^{-1}(f(a)) = a$ for all $a \in A$ and $f(f^{-1}(b)) = b$ for all $b \in B$.

### Finite sets

For a finite domain we can simply test every input:

```python
A = range(-5, 6)
images = [x * x for x in A]
print(len(set(images)) == len(images))   # False, since (-2)**2 == 2**2
```

For finite sets with the same number of elements, injective and surjective are equivalent. For infinite sets that fails: $n \mapsto 2n$ from $\mathbb{Z}$ to $\mathbb{Z}$ is injective but misses every odd number. The next lesson turns this observation into a theory of size.

@example
title: Proving a bijection
problem: Prove that $f: \mathbb{R} \to \mathbb{R}$ defined by $f(x) = 3x - 5$ is a bijection, and find its inverse.
step: Injective. Suppose $f(a) = f(b)$, that is, $3a - 5 = 3b - 5$. Adding $5$ and dividing by $3$ gives $a = b$.
step: Surjective. Let $y \in \mathbb{R}$ be arbitrary. We want $x$ with $3x - 5 = y$. Solving gives $x = \frac{y + 5}{3}$.
step: Check this works. The number $x = \frac{y+5}{3}$ is real, so it lies in the domain, and $f(x) = 3 \cdot \frac{y + 5}{3} - 5 = y$. So every $y$ has a preimage.
step: Hence $f$ is a bijection, and the formula we found for $x$ is the inverse: $f^{-1}(y) = \frac{y + 5}{3}$.

@example
title: Injective but not surjective
problem: Let $g: \mathbb{Z} \to \mathbb{Z}$ be defined by $g(n) = 2n + 1$. Show that $g$ is injective but not surjective.
step: Injective. Suppose $g(a) = g(b)$, so $2a + 1 = 2b + 1$. Then $2a = 2b$ and $a = b$.
step: To refute surjectivity we need one element of the codomain $\mathbb{Z}$ that is never hit. Try $y = 2$.
step: Suppose $g(n) = 2$ for some integer $n$. Then $2n + 1 = 2$, so $n = \frac{1}{2}$, which is not an integer. So no element of the domain maps to $2$.
step: Therefore $g$ is injective but not surjective. If we shrink the codomain to the odd integers, the same rule becomes a bijection.

@mistakes
- Trying to prove injectivity by testing a few inputs. A handful of distinct outputs proves nothing about all pairs.
- Forgetting the codomain. The rule $x \mapsto x^2$ is surjective onto $[0, \infty)$ but not onto $\mathbb{R}$.
- Solving $f(x) = y$ for $x$ in a surjectivity proof but never checking that the solution lies in the domain (for example, $x = y/2$ is not an integer when $y$ is odd).
- Confusing the definition of a function (each input has exactly one output) with injectivity (each output has at most one input).

@practice mc
prompt: Which statement says that a function $f: A \to B$ is injective?
choice*: For all $a, a' \in A$, if $f(a) = f(a')$ then $a = a'$.
choice: For every $b \in B$ there is some $a \in A$ with $f(a) = b$.
choice: For every $a \in A$ there is exactly one $b \in B$ with $f(a) = b$.
choice: There exist $a \neq a'$ in $A$ with $f(a) = f(a')$.
hint: Injective means "different inputs, different outputs", or in the equivalent contrapositive form, "equal outputs force equal inputs".
hint: One choice describes surjectivity, one describes what makes $f$ a function at all, and one is the negation of injectivity.
solution: The statement "if $f(a) = f(a')$ then $a = a'$" is the definition. The statement that every $b \in B$ has some $a \in A$ with $f(a) = b$ is surjectivity, the statement that every $a \in A$ has exactly one $b \in B$ with $f(a) = b$ is the condition for $f$ to be a function, and the statement that some $a \neq a'$ in $A$ have $f(a) = f(a')$ is the negation of injectivity.

@practice num
prompt: How many injective functions are there from $\{1, 2, 3\}$ to $\{1, 2, 3, 4, 5\}$?
answer: 60
check: sum(1 for m in range(125) if len({m % 5, (m // 5) % 5, (m // 25) % 5}) == 3)
hint: Choose the value $f(1)$ first. How many choices does it have?
hint: Injectivity means each later value must avoid the values already used.
solution: There are $5$ choices for $f(1)$, then $4$ remaining choices for $f(2)$, then $3$ for $f(3)$, so $5 \cdot 4 \cdot 3 = 60$.

prompt: Select every function from $\mathbb{R}$ to $\mathbb{R}$ that is a bijection.
choice*: $f(x) = x^3$
choice*: $f(x) = 2x + 1$
choice: $f(x) = e^x$
choice: $f(x) = x^2$
choice: $f(x) = x^3 - x$

hint: Look at $e^x$ for negative targets, and at $x^3 - x$ at the inputs $-1$, $0$ and $1$.
solution: $x^3$ and $2x + 1$ are bijections of $\mathbb{R}$. The function $e^x$ is injective but only takes positive values, so it is not surjective. The function $x^2$ is neither (it takes $f(-1) = f(1)$ and no negative values). The function $x^3 - x$ is surjective but not injective, since it is $0$ at $-1$, $0$ and $1$.

@practice self
prompt: Show that $f: \mathbb{Z} \to \mathbb{Z}$ defined by $f(n) = n^2 - n$ is neither injective nor surjective.
solution: Not injective: $f(0) = 0 = f(1)$ although $0 \neq 1$. Not surjective: we show $1$ is never attained. For any integer $n$, $f(n) = n(n - 1)$ is a product of two consecutive integers, which is even (it is $m(m+1)$ with $m = n - 1$). Since $1$ is odd, $f(n) \neq 1$ for all $n$, so $1$ has no preimage. $\blacksquare$
rubric: Non-injectivity is shown by two explicit different inputs with the same output.
rubric: Non-surjectivity names a specific element of the codomain, such as $1$, and proves that nothing maps to it.
rubric: The proof that $n(n-1)$ is always even is given or correctly cited (product of consecutive integers).
hint: For injectivity, evaluate $f$ at a few small inputs and look for a repeated output.
hint: Factor $n^2 - n$. What do you know about the parity of a product of consecutive integers?

@practice self
prompt: Let $f: A \to B$ and $g: B \to C$ be injective functions. Prove that $g \circ f: A \to C$ is injective.
solution: Suppose $a, a' \in A$ and $(g \circ f)(a) = (g \circ f)(a')$, that is, $g(f(a)) = g(f(a'))$. Since $g$ is injective, $f(a) = f(a')$. Since $f$ is injective, $a = a'$. Hence $g \circ f$ is injective. $\blacksquare$
rubric: The proof starts by assuming equal outputs of the composition, $g(f(a)) = g(f(a'))$.
rubric: It applies injectivity of $g$ first, then injectivity of $f$, in the correct order.
rubric: It concludes $a = a'$ for arbitrary $a, a'$.
hint: Begin with the template for injectivity: suppose the outputs of $g \circ f$ agree.
hint: Peel the functions off from the outside in. Which one is applied last?

@quiz num
prompt: How many surjective functions are there from $\{1, 2, 3, 4\}$ onto $\{a, b, c\}$?
answer: 36
check: sum(1 for m in range(81) if len({m % 3, (m // 3) % 3, (m // 9) % 3, (m // 27) % 3}) == 3)
hint: There are $3^4 = 81$ functions in all. Surjective ones use all three output values.
hint: Subtract the functions that miss at least one of $a, b, c$, using inclusion and exclusion on "misses $a$", "misses $b$", "misses $c$".
solution: Functions missing a given element of $\{a, b, c\}$ number $2^4 = 16$, and there are $3$ such elements. Functions missing two given elements number $1$, and there are $3$ pairs. No function misses all three. So the surjective ones number $81 - 3 \cdot 16 + 3 \cdot 1 = 36$.

@quiz self
prompt: Let $f: \mathbb{R} \setminus \{2\} \to \mathbb{R} \setminus \{3\}$ be defined by $f(x) = \frac{3x}{x - 2}$. Prove that $f$ is a bijection.
solution: Injective: suppose $f(a) = f(b)$, so $\frac{3a}{a - 2} = \frac{3b}{b - 2}$. Cross-multiplying, $3a(b - 2) = 3b(a - 2)$, so $3ab - 6a = 3ab - 6b$, hence $a = b$. Surjective: let $y \in \mathbb{R} \setminus \{3\}$. Solving $y = \frac{3x}{x - 2}$ gives $y(x - 2) = 3x$, so $x(y - 3) = 2y$ and $x = \frac{2y}{y - 3}$, which is defined because $y \neq 3$. This $x$ is not $2$, since $\frac{2y}{y-3} = 2$ would give $2y = 2y - 6$. So $x$ is in the domain, and $f(x) = \frac{3 \cdot 2y/(y-3)}{2y/(y-3) - 2} = \frac{6y}{2y - 2(y - 3)} = y$. Hence $f$ is a bijection. $\blacksquare$
rubric: Injectivity is proved by assuming $f(a) = f(b)$ and cross-multiplying correctly to get $a = b$.
rubric: Surjectivity solves for $x$ in terms of an arbitrary $y \neq 3$ and shows where $y \neq 3$ is used.
rubric: The proof checks that the $x$ found lies in the domain ($x \neq 2$) and that $f(x) = y$.
hint: For injectivity, cross-multiply and simplify; the $ab$ terms cancel.
hint: For surjectivity, solve $y = \frac{3x}{x-2}$ for $x$. Where does $y \neq 3$ come in, and why is the answer not $2$?

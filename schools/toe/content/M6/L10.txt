@article
How do you compare the sizes of two infinite sets? Counting fails, but **matching** works. A theatre has as many seats as ticket holders when each person can be paired with one seat and none is left over, and you can see that without counting either. Mathematicians take pairing as the definition.

### Same size means a bijection

Sets $A$ and $B$ have the same **cardinality**, written $|A| = |B|$, if there is a bijection $f: A \to B$. We write $|A| \le |B|$ if there is an injection $A \to B$. For a finite set with $n$ elements this agrees with counting, since counting is a bijection with $\{1, \dots, n\}$.

Let $\mathbb{N} = \{1, 2, 3, \dots\}$. A set is **countably infinite** if it has the same cardinality as $\mathbb{N}$, which means its elements can be listed $a_1, a_2, a_3, \dots$ with every element appearing exactly once. It is **countable** if it is finite or countably infinite.

### Surprises

An infinite set can have the same cardinality as a proper subset. The map $n \mapsto 2n$ is a bijection from $\mathbb{N}$ to the even positive integers, so there are "as many" evens as positive integers. Even $\mathbb{Z}$ is countable, by the listing $0, 1, -1, 2, -2, \dots$:

```python
def f(n):
    return n // 2 if n % 2 == 0 else -(n - 1) // 2

print([f(n) for n in range(1, 11)])   # [0, 1, -1, 2, -2, 3, -3, 4, -4, 5]
```

A printed list is evidence, not proof. A proof must show the rule is a bijection.

### Facts we will use

- A subset of a countable set is countable, and a set with an injection into $\mathbb{N}$ is countable.
- $\mathbb{N} \times \mathbb{N}$ is countable: $(m, n) \mapsto 2^{m-1}(2n - 1)$ is a bijection to $\mathbb{N}$, because every positive integer is uniquely a power of $2$ times an odd number.
- $\mathbb{Q}$ is countable. Sending a positive fraction $p/q$ in lowest terms to $2^{p-1}(2q - 1)$ is an injection into $\mathbb{N}$, and negatives and $0$ are handled the same way.

### Not everything is countable

The interval $(0, 1)$ is not countable. The proof (second example below) is a contradiction argument: assume a complete list of its elements, then build a number that cannot be on it. The same diagonal idea shows that no set has the same cardinality as its collection of subsets, so there are infinitely many different sizes of infinity.

Bijections transfer countability: if $|A| = |B|$ and $B$ is countable, then so is $A$ (compose the bijections). So any set in bijection with $(0, 1)$ is uncountable too.

@example
title: Squares are as many as integers
problem: Let $S = \{1, 4, 9, 16, \dots\}$ be the set of perfect squares. Prove that $S$ is countably infinite.
step: Define $f: \mathbb{N} \to S$ by $f(n) = n^2$. This is well defined, since $n^2$ is a perfect square.
step: Injective. Suppose $f(a) = f(b)$, so $a^2 = b^2$. Since $a$ and $b$ are positive, taking square roots gives $a = b$.
step: Surjective. Let $s \in S$. By definition $s = k^2$ for some positive integer $k$, and then $f(k) = s$ with $k \in \mathbb{N}$.
step: So $f$ is a bijection and $|S| = |\mathbb{N}|$. The squares are sparse, yet there are exactly as many of them as there are positive integers.

@example
title: The interval (0,1) is uncountable
problem: Prove that $(0, 1)$ is not countable.
step: Suppose, for contradiction, that $(0, 1)$ is countable. It is infinite, so its elements can be listed $x_1, x_2, x_3, \dots$ with every element of $(0, 1)$ appearing. Write each in decimal form, $x_n = 0.d_{n1} d_{n2} d_{n3} \dots$, where $d_{nk}$ is the $k$-th digit of $x_n$.
step: Build a new number $d = 0.e_1 e_2 e_3 \dots$ by looking at the diagonal digits $d_{nn}$: let $e_n = 5$ if $d_{nn} \neq 5$, and $e_n = 4$ if $d_{nn} = 5$.
step: Every digit of $d$ is $4$ or $5$, so $0 < d < 1$ and $d$ is a legitimate element of $(0, 1)$. Also, because it has no trailing $0$'s or $9$'s, $d$ has only one decimal expansion.
step: By construction the $n$-th digit of $d$ differs from the $n$-th digit of $x_n$. Since $d$ has only one expansion, $d \neq x_n$ for every $n$.
step: So $d \in (0, 1)$ is missing from the list, contradicting that the list contained every element. Hence $(0, 1)$ is not countable. $\blacksquare$

@mistakes
- Thinking "infinite" means "the same size". The sets $\mathbb{N}$ and $(0, 1)$ are both infinite but have different cardinalities.
- Calling a set countable because you listed its first few elements. A listing must reach every element, so give a rule and prove it is a bijection.
- In the diagonal argument, building the new number from digits $0$ or $9$, which can make it equal to a listed number in disguise ($0.4999\ldots = 0.5$).
- Assuming a proper subset must be smaller. That is true for finite sets and false for infinite ones.

@practice self
prompt: Define $f: \mathbb{N} \to \mathbb{Z}$ by $f(n) = \frac{n}{2}$ if $n$ is even and $f(n) = \frac{1 - n}{2}$ if $n$ is odd. Prove that $f$ is a bijection, and explain what this shows about $\mathbb{Z}$.
solution: Injective: suppose $f(a) = f(b)$. If $a$ is even then $f(a) = \frac{a}{2} > 0$, and if $a$ is odd then $f(a) = \frac{1 - a}{2} \le 0$. So equal values force $a$ and $b$ to have the same parity. If both are even, $\frac{a}{2} = \frac{b}{2}$ gives $a = b$. If both are odd, $\frac{1 - a}{2} = \frac{1 - b}{2}$ gives $a = b$. Surjective: let $z \in \mathbb{Z}$. If $z > 0$, take $n = 2z$, which is an even natural number, and $f(n) = z$. If $z \le 0$, take $n = 1 - 2z$, which is an odd natural number (at least $1$), and $f(n) = \frac{1 - (1 - 2z)}{2} = z$. So $f$ is a bijection. Hence $\mathbb{Z}$ has the same cardinality as $\mathbb{N}$: it is countably infinite, and $f$ is the listing $0, 1, -1, 2, -2, \dots$. $\blacksquare$
rubric: Injectivity is proved with both parity cases handled, including why equal outputs force the same parity.
rubric: Surjectivity gives an explicit preimage for $z > 0$ and for $z \le 0$, verifies $f(n) = z$, and checks that $n$ is a natural number.
rubric: The conclusion states that a bijection with $\mathbb{N}$ means $\mathbb{Z}$ is countably infinite.
hint: Compute $f(1), f(2), \dots, f(6)$ to see where the evens and the odds land.
hint: For injectivity, first show that equal outputs force equal parity. For surjectivity, split into $z > 0$ and $z \le 0$ and solve for $n$.

@practice self
prompt: Prove that the intervals $(0, 1)$ and $(1, \infty)$ have the same cardinality, and conclude that $(1, \infty)$ is not countable. (Use that $(0, 1)$ is not countable.)
solution: Define $f: (0, 1) \to (1, \infty)$ by $f(x) = \frac{1}{x}$. It maps into $(1, \infty)$ because $0 < x < 1$ implies $\frac{1}{x} > 1$. Injective: if $\frac{1}{a} = \frac{1}{b}$ then $a = b$. Surjective: for $y \in (1, \infty)$ let $x = \frac{1}{y}$; then $0 < x < 1$ and $f(x) = y$. So $f$ is a bijection and $|(0, 1)| = |(1, \infty)|$. Now suppose $(1, \infty)$ were countable. Composing the bijection $f$ with a listing of $(1, \infty)$ would give a listing of $(0, 1)$, contradicting that $(0, 1)$ is not countable. Hence $(1, \infty)$ is not countable. $\blacksquare$
rubric: The function is shown to map into $(1, \infty)$ and to be injective.
rubric: Surjectivity gives the preimage $\frac{1}{y}$ and checks it lies in $(0, 1)$.
rubric: The conclusion transfers uncountability through the bijection, with a contradiction or a composition argument.
hint: Look for a simple formula that sends numbers just above $0$ to huge numbers and numbers just below $1$ to numbers just above $1$.
hint: To conclude uncountability, assume $(1, \infty)$ is countable and compose bijections.

@quiz self
prompt: Let $A$ and $B$ be disjoint, countably infinite sets. Prove that $A \cup B$ is countably infinite.
solution: Since $A$ and $B$ are countably infinite, list them as $A = \{a_1, a_2, a_3, \dots\}$ and $B = \{b_1, b_2, b_3, \dots\}$, each element appearing exactly once. Define $h: \mathbb{N} \to A \cup B$ by $h(2k - 1) = a_k$ and $h(2k) = b_k$. Every natural number is of the form $2k - 1$ or $2k$ for exactly one $k$, so $h$ is well defined. Surjective: each element of $A \cup B$ is some $a_k$ or some $b_k$, which is $h(2k - 1)$ or $h(2k)$. Injective: the $a_k$ are distinct, the $b_k$ are distinct, and no $a_j$ equals a $b_k$ because $A$ and $B$ are disjoint, so distinct inputs have distinct outputs. Thus $h$ is a bijection and $A \cup B$ is countably infinite. $\blacksquare$
rubric: The proof gives an explicit rule that interleaves the two listings, such as $h(2k - 1) = a_k$ and $h(2k) = b_k$.
rubric: Surjectivity is argued: every element of $A \cup B$ is $a_k$ or $b_k$ for some $k$.
rubric: Injectivity is argued and uses the disjointness of $A$ and $B$ explicitly.
hint: Write both sets as listings and merge the two lists by alternating between them.
hint: Where in the proof do you need $A \cap B = \emptyset$?

@article
A **relation** compares elements of a set. "Less than" compares numbers, "divides" compares positive integers, "has the same birthday as" compares people. To study them all at once, we strip each one down to the collection of pairs that are related.

### Relations as sets of pairs

A **relation on a set $A$** is a subset $R \subseteq A \times A$. We write $a \,R\, b$ to mean $(a, b) \in R$. On $A = \{1, 2, 3\}$,
$$R = \{(1,1), (1,2), (2,1), (2,2), (3,3)\}$$
relates $1$ and $2$ to each other and to themselves, and relates $3$ only to itself. A three-element set has $9$ ordered pairs, each either in $R$ or not, so there are $2^9 = 512$ relations on it.

### Four properties

| Property | Definition (for a relation $R$ on $A$) |
|---|---|
| **Reflexive** | for all $a \in A$: $a \,R\, a$ |
| **Symmetric** | for all $a, b \in A$: if $a \,R\, b$ then $b \,R\, a$ |
| **Antisymmetric** | for all $a, b \in A$: if $a \,R\, b$ and $b \,R\, a$ then $a = b$ |
| **Transitive** | for all $a, b, c \in A$: if $a \,R\, b$ and $b \,R\, c$ then $a \,R\, c$ |

Symmetric and antisymmetric are not opposites. Equality is both, and the relation $\{(1,2), (2,1), (1,3)\}$ is neither. Here is how some familiar relations score:

| Relation | Refl. | Sym. | Antisym. | Trans. |
|---|---|---|---|---|
| $a = b$ on $\mathbb{Z}$ | yes | yes | yes | yes |
| $a \le b$ on $\mathbb{Z}$ | yes | no | yes | yes |
| $a < b$ on $\mathbb{Z}$ | no | no | yes | yes |
| $a \mid b$ on positive integers | yes | no | yes | yes |
| $\lvert a - b \rvert \le 1$ on $\mathbb{Z}$ | yes | yes | no | no |

The "yes" for $<$ under antisymmetric is **vacuous**: the hypothesis "$a < b$ and $b < a$" never occurs, so the implication can never fail.

### Proving and refuting

Each property begins with "for all". To **prove** it, name arbitrary elements and argue. To **refute** it, exhibit one explicit counterexample and check every condition: the negation of "for all $a, b, c$, the implication holds" is "for some $a, b, c$, the implication fails".

For a finite relation, a program that tests every pair is a legitimate proof, because it covers all cases:

```python
A = {1, 2, 3}
R = {(1, 1), (1, 2), (2, 1), (2, 2), (3, 3)}

reflexive = all((a, a) in R for a in A)
symmetric = all((b, a) in R for (a, b) in R)
transitive = all((a, d) in R for (a, b) in R for (c, d) in R if b == c)
print(reflexive, symmetric, transitive)   # True True True
```

@example
title: Proving three properties
problem: On $\mathbb{Z}$ define $a \sim b$ to mean that $a - b$ is even. Prove that $\sim$ is reflexive, symmetric and transitive.
step: Reflexive. Let $a \in \mathbb{Z}$. Then $a - a = 0 = 2 \cdot 0$ is even, so $a \sim a$.
step: Symmetric. Suppose $a \sim b$, so $a - b = 2k$ for some integer $k$. Then $b - a = 2(-k)$, and $-k$ is an integer, so $b \sim a$.
step: Transitive. Suppose $a \sim b$ and $b \sim c$, so $a - b = 2k$ and $b - c = 2m$ for integers $k$ and $m$ (two different letters). Adding, $a - c = 2(k + m)$, so $a \sim c$.
step: All three properties hold. A relation with these three properties is called an equivalence relation, the subject of the next lesson.

@example
title: Refuting with a counterexample
problem: On $\mathbb{Z}$ define $a \,R\, b$ to mean $\lvert a - b \rvert \le 1$. Show that $R$ is not transitive.
step: Transitivity says: for all $a, b, c$, if $a \,R\, b$ and $b \,R\, c$ then $a \,R\, c$. To refute it we need one explicit triple $a, b, c$ with $a \,R\, b$ and $b \,R\, c$ but not $a \,R\, c$.
step: Try $a = 1$, $b = 2$, $c = 3$.
step: Check the hypotheses: $\lvert 1 - 2 \rvert = 1 \le 1$, so $1 \,R\, 2$, and $\lvert 2 - 3 \rvert = 1 \le 1$, so $2 \,R\, 3$.
step: Check the failure: $\lvert 1 - 3 \rvert = 2 > 1$, so $1$ is not related to $3$. This one triple shows that $R$ is not transitive. $\blacksquare$

@mistakes
- Treating "symmetric" and "antisymmetric" as opposites. Equality is both, and many relations are neither.
- Trying to prove a "for all" property by checking a few pairs, or trying to refute one with a vague argument instead of one explicit counterexample.
- Missing vacuous truth. The relation $<$ on $\mathbb{Z}$ is antisymmetric precisely because its hypothesis never happens.
- Checking reflexivity only for elements that already appear in some pair. Every element of $A$ needs its own pair $(a, a)$.

@practice mc
prompt: Let $R = \{(1,1), (2,2), (1,2)\}$ be a relation on $A = \{1, 2, 3\}$. Which statement is true?
choice*: $R$ is transitive and antisymmetric but not reflexive.
choice: $R$ is reflexive and transitive.
choice: $R$ is symmetric because $(1,1)$ and $(2,2)$ are symmetric.
choice: $R$ is not transitive because $(1,2)$ is in $R$ but $(2,1)$ is not.
hint: Reflexivity needs a pair $(a, a)$ for every $a \in A$. Is any element missing?
hint: Symmetry asks that every pair in $R$ has its reverse in $R$. Transitivity asks that every chain $(a,b), (b,c)$ has its shortcut $(a,c)$.
solution: The pair $(3,3)$ is missing, so $R$ is not reflexive. The pair $(1,2)$ has no reverse, so $R$ is not symmetric, and the only non-diagonal pair has no reverse either, so $R$ is antisymmetric. Every chain, such as $(1,1), (1,2)$ or $(1,2), (2,2)$, gives a pair already in $R$, so $R$ is transitive. A missing reverse pair breaks symmetry, not transitivity.

@practice num
prompt: How many of the $512$ relations on the set $\{1, 2, 3\}$ are reflexive?
answer: 64
check: sum(1 for m in range(512) if all((m >> (3*i + i)) & 1 for i in range(3)))
hint: A reflexive relation must contain $(1,1)$, $(2,2)$ and $(3,3)$.
hint: The other $6$ ordered pairs are unconstrained. Each is either in the relation or out.
solution: The three diagonal pairs are forced. Each of the other $9 - 3 = 6$ pairs is independently in or out, giving $2^6 = 64$ reflexive relations.

@practice self
prompt: Let $a$ and $b$ be positive integers. Prove that if $a \mid b$ and $b \mid a$, then $a = b$. (This shows that divisibility is antisymmetric on the positive integers.)
solution: Suppose $a \mid b$ and $b \mid a$. Then $b = ac$ and $a = bd$ for some integers $c$ and $d$. Since $a$ and $b$ are positive, $c$ and $d$ are positive integers too, so $c \ge 1$ and $d \ge 1$. Substituting, $a = bd = (ac)d = a(cd)$, and since $a \neq 0$ we may cancel to get $cd = 1$. Positive integers with product $1$ must both equal $1$, so $c = 1$ and $b = ac = a$. $\blacksquare$
rubric: Both divisibility statements are unpacked as equations with two different integers.
rubric: The proof substitutes one equation into the other and cancels the nonzero $a$ to get $cd = 1$.
rubric: The proof uses positivity to conclude $c = d = 1$ and hence $a = b$.
hint: Write each divisibility statement as an equation with its own integer.
hint: Substitute one equation into the other. What must the product of the two integers be?

@practice self
prompt: Let $R$ be a symmetric and transitive relation on a set $A$, and suppose every element $a \in A$ is related to at least one element of $A$. Prove that $R$ is reflexive.
solution: Let $a \in A$ be arbitrary. By hypothesis there is some $b \in A$ with $a \,R\, b$. By symmetry, $b \,R\, a$. Now $a \,R\, b$ and $b \,R\, a$, so transitivity gives $a \,R\, a$. Since $a$ was arbitrary, $R$ is reflexive. $\blacksquare$
rubric: The proof takes an arbitrary $a$ and uses the hypothesis to choose a $b$ with $a \,R\, b$.
rubric: It applies symmetry to get $b \,R\, a$, then transitivity to the chain $a \,R\, b$, $b \,R\, a$.
rubric: It concludes $a \,R\, a$ for the arbitrary $a$, hence reflexivity.
hint: Pick any $a$. Where does the extra hypothesis let you find a partner for $a$?
hint: Combine the partner's relation with its reverse, then apply transitivity.

@quiz num
prompt: How many of the $2^{16}$ relations on the set $\{1, 2, 3, 4\}$ are symmetric?
answer: 1024
check: sum(1 for m in range(65536) if all(((m >> (4*i + j)) & 1) == ((m >> (4*j + i)) & 1) for i in range(4) for j in range(4)))
hint: A symmetric relation is determined by two kinds of independent choices: which diagonal pairs $(a, a)$ it contains, and which two-element subsets $\{a, b\}$ it relates (both orders in, or both out).
hint: Count the diagonal pairs and the two-element subsets. Each is one independent in-or-out choice.
solution: There are $4$ diagonal pairs and $\binom{4}{2} = 6$ two-element subsets, so $4 + 6 = 10$ independent in-or-out choices. That gives $2^{10} = 1024$ symmetric relations.

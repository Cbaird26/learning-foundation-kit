@article
A **traveling wave** carries a disturbance from place to place without carrying the medium along with it. The simplest example is the sinusoid:

$$y(x,t) = A\cos(kx - \omega t + \phi).$$

### The parameters

$A$ is the amplitude and $\phi$ the phase constant. The **wavelength** $\lambda$ is the spatial period, and the **wavenumber** is $k = 2\pi/\lambda$ (rad/m). The **period** is $T_p = 1/f$, and $\omega = 2\pi f$ is the angular frequency. (We write $T_p$ so as not to confuse it with tension.)

### Speed and direction

A crest is a point of constant phase, $kx - \omega t = \text{const}$. Differentiating gives $k\,dx - \omega\,dt = 0$, so the crest moves at the **phase velocity**

$$v = \frac{dx}{dt} = \frac{\omega}{k} = \lambda f.$$

The argument $kx - \omega t$ describes motion toward $+x$; $kx + \omega t$ describes motion toward $-x$. Substituting into the wave equation gives $-\omega^2 = -v^2k^2$, so $\omega = vk$. Because $\omega$ is proportional to $k$, every sinusoid on the string travels at the same speed.

### Two different velocities

Each piece of string just moves up and down, with transverse velocity

$$\frac{\partial y}{\partial t} = \omega A\sin(kx - \omega t + \phi).$$

Its largest value is $\omega A$. This is not the wave speed $v = \omega/k$. The small-slope assumption behind the wave equation means $kA \ll 1$, which is the same as $\omega A \ll v$.

### Energy and power

Per unit length, the kinetic energy is $\tfrac12\mu\,y_t^2$ and the potential energy is $\tfrac12 T\,y_x^2$. For a traveling sinusoid they are equal at every point, so the total energy per length is $\mu\omega^2A^2\sin^2(kx-\omega t+\phi)$, with average $\tfrac12\mu\omega^2A^2$. That energy moves along at speed $v$, so the average power is

$$P = \tfrac12\,\mu\,\omega^2A^2\,v = \tfrac12\sqrt{\mu T}\;\omega^2A^2.$$

Doubling the amplitude or the frequency therefore multiplies the power by four.

### Checking a proposed wave

To test whether a given $y(x,t)$ solves $y_{tt} = v^2y_{xx}$, differentiate twice in each variable and compare the results. For a sinusoid the whole test reduces to whether $\omega^2 = v^2k^2$, that is, whether $\omega/k$ equals the speed the medium allows. The sign in front of $\omega t$ then tells you the direction.

@example
title: Reading a wave function
problem: A wave on a string is $y(x,t) = 0.020\cos(5.0x - 400t + 0.30)$ in SI units. Find the amplitude, wavelength, frequency, wave speed, direction of travel and maximum transverse speed.
step: Compare with $A\cos(kx - \omega t + \phi)$: $A = 0.020\ \text{m}$, $k = 5.0\ \text{rad/m}$, $\omega = 400\ \text{rad/s}$ and $\phi = 0.30\ \text{rad}$.
step: The wavelength is $\lambda = 2\pi/k \approx 1.26\ \text{m}$ and the frequency is $f = \omega/2\pi \approx 63.7\ \text{Hz}$.
step: The speed is $v = \omega/k = 400/5.0 = 80\ \text{m/s}$. The argument has the form $kx - \omega t$, so the wave travels toward $+x$.
step: The maximum transverse speed is $\omega A = 400(0.020) = 8.0\ \text{m/s}$, a tenth of the wave speed.
step: Check the small-slope assumption: $kA = 5.0(0.020) = 0.10 \ll 1$, so the string model is reasonable.

@example
title: Does the proposed wave fit the string?
problem: A string has $T = 160\ \text{N}$ and $\mu = 0.10\ \text{kg/m}$. Test $y_1 = 0.05\sin(2x + 80t)$ and $y_2 = 0.05\sin(2x - 60t)$ (SI units) against the wave equation.
step: The wave equation requires $y_{tt} = v^2 y_{xx}$ with $v^2 = T/\mu = 1600\ \text{m}^2/\text{s}^2$.
step: For $y_1$, $y_{tt} = -(80)^2y_1 = -6400\,y_1$ and $y_{xx} = -(2)^2y_1 = -4\,y_1$, so $v^2y_{xx} = -6400\,y_1$. The two sides match, so $y_1$ is a solution.
step: The argument $2x + 80t$ means $y_1$ travels toward $-x$ at $\omega/k = 40\ \text{m/s} = \sqrt{1600}$.
step: For $y_2$, $y_{tt} = -(60)^2y_2 = -3600\,y_2$, but $v^2y_{xx} = 1600(-4)\,y_2 = -6400\,y_2$. They differ, so $y_2$ is not a solution. Its speed would be $60/2 = 30\ \text{m/s}$.

@mistakes
- Confusing the wave speed $v = \omega/k$ with the transverse speed $\partial y/\partial t$ of a piece of string, whose maximum is $\omega A$.
- Getting the direction backwards: $kx - \omega t$ moves toward $+x$ and $kx + \omega t$ toward $-x$.
- Mixing $f$ and $\omega$, or $\lambda$ and $k$, which introduces stray factors of $2\pi$.
- Forgetting that the power scales as $A^2$ and $\omega^2$, so doubling the amplitude quadruples the power.

@practice num
prompt: A wave on a string is $y(x,t) = 0.010\sin(20x + 500t)$ in SI units. What is the wave speed?
answer: 25
check: 500.0/20.0
unit: m/s
hint: Compare with $\sin(kx + \omega t)$ and read off $k$ and $\omega$.
hint: The speed is the ratio $\omega/k$. The plus sign only tells you the direction.
solution: Here $k = 20\ \text{rad/m}$ and $\omega = 500\ \text{rad/s}$, so $v = \omega/k = 25\ \text{m/s}$. The wave travels toward $-x$.

@practice num
prompt: A sinusoidal wave of amplitude $4.0\ \text{mm}$ and frequency $100\ \text{Hz}$ travels on a string with tension $72\ \text{N}$ and linear density $0.0200\ \text{kg/m}$. Find the average power it transmits. Give three significant figures.
answer: 3.79
check: 0.5*0.0200*(2*pi*100.0)**2*0.0040**2*sqrt(72.0/0.0200)
tol: 1%
unit: W
hint: Use $P = \tfrac12\mu\omega^2A^2v$ with $v = \sqrt{T/\mu}$.
hint: Here $v = 60\ \text{m/s}$ and $\omega = 200\pi\ \text{rad/s}$.
solution: $v = \sqrt{72/0.0200} = 60\ \text{m/s}$ and $\omega = 200\pi \approx 628.3\ \text{rad/s}$. Then $P = \tfrac12(0.0200)(628.3)^2(0.0040)^2(60) \approx 3.79\ \text{W}$.

@practice self
prompt: A student proposes that $y(x,t) = 0.03\sin(4x - 200t)$ (SI units) describes a wave on a string with tension $50\ \text{N}$ and linear density $0.040\ \text{kg/m}$. Decide whether it satisfies the wave equation $y_{tt} = (T/\mu)\,y_{xx}$ by computing both second derivatives. If it does not, say what value of $\omega$ would fix it.
hint: Differentiate twice with respect to $t$ and twice with respect to $x$; each differentiation of a sine or cosine brings out a factor of $\omega$ or $k$.
hint: Compare $y_{tt}$ with $(T/\mu)\,y_{xx}$ term by term, using $T/\mu = 1250\ \text{m}^2/\text{s}^2$.
solution: $T/\mu = 50/0.040 = 1250\ \text{m}^2/\text{s}^2$. Then $y_{tt} = -(200)^2y = -40000\,y$ and $y_{xx} = -(4)^2y = -16\,y$, so $(T/\mu)\,y_{xx} = -20000\,y$. Since $-40000\,y \neq -20000\,y$, the function is not a solution: its speed would be $\omega/k = 50\ \text{m/s}$, while the string supports $\sqrt{1250} \approx 35.4\ \text{m/s}$. The fix is $\omega = k\sqrt{T/\mu} = 4(35.4) \approx 141\ \text{rad/s}$.
rubric: Computes $y_{tt} = -\omega^2y$ and $y_{xx} = -k^2y$ with the correct numbers and signs.
rubric: Compares $y_{tt}$ with $(T/\mu)\,y_{xx}$ using $T/\mu = 1250$ and finds a mismatch.
rubric: Concludes the proposal is not a solution, and notes that $\omega/k = 50\ \text{m/s}$ differs from $v \approx 35.4\ \text{m/s}$.
rubric: States the corrected frequency $\omega \approx 141\ \text{rad/s}$.

@quiz ms
prompt: Which statements about the wave $y = A\cos(kx - \omega t)$ on a string are true?
choice*: Its wave speed is $\omega/k$.
choice*: The maximum transverse speed of a piece of string is $\omega A$.
choice: The maximum transverse speed of a piece of string equals the wave speed.
choice: Doubling the amplitude at fixed frequency doubles the average power.
hint: The wave speed is the speed of a crest; the transverse speed is $\partial y/\partial t$.
hint: Recall how $P$ depends on $A$.
solution: A crest moves at $\omega/k$, and $\partial y/\partial t$ has maximum $\omega A$. These are different quantities in general (their ratio is $kA \ll 1$). The power is proportional to $A^2$, so doubling $A$ quadruples it.

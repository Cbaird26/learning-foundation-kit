@article
Lesson 7 showed that every motion of a fixed string is a sum of normal modes. The practical question is how much of each mode a given starting shape contains. **Fourier analysis** finds the amounts, and **Fourier synthesis** rebuilds the shape by adding the modes back.

### Orthogonality and coefficients

The sine modes on $0 \le x \le L$ are orthogonal:

$$\int_0^L \sin\frac{m\pi x}{L}\,\sin\frac{n\pi x}{L}\,dx = \begin{cases} L/2, & m = n,\\ 0, & m \neq n.\end{cases}$$

Suppose a string starts at rest with the shape $h(x) = \sum_n c_n\sin(n\pi x/L)$. Multiply by $\sin(m\pi x/L)$ and integrate along the string. Only the $n = m$ term survives, which gives

$$c_n = \frac{2}{L}\int_0^L h(x)\,\sin\frac{n\pi x}{L}\,dx.$$

The motion at all later times is then

$$y(x,t) = \sum_{n=1}^{\infty} c_n\,\sin\frac{n\pi x}{L}\,\cos\omega_n t, \qquad \omega_n = \frac{n\pi v}{L}.$$

(A string that starts flat with a velocity profile $u(x)$ instead has $\sin\omega_nt$ factors, with coefficients $\frac{2}{\omega_nL}\int_0^L u(x)\sin\frac{n\pi x}{L}\,dx$.)

### The plucked string

Pull a string aside at its midpoint to height $h$ and release it. The triangular shape has

$$c_n = \frac{8h}{n^2\pi^2}\,\sin\frac{n\pi}{2}.$$

Odd modes appear with alternating signs ($+, -, +, \dots$ for $n = 1, 3, 5, \dots$), and even modes vanish: they have a node at the midpoint, so a midpoint pluck cannot excite them. The coefficients fall as $1/n^2$.

### How fast do coefficients fall?

The smoother the shape, the faster the fall. A continuous shape with a corner, like the triangle, gives $1/n^2$. A shape with a **jump** gives only $1/n$: for $h(x) = 1$ on $0 < x < L$, the coefficients are $c_n = 4/(n\pi)$ for odd $n$. Near a jump the partial sums overshoot by about $9\%$ of the jump height however many terms you keep. This is the **Gibbs phenomenon**: more terms squeeze the overshoot closer to the jump but do not shrink it. At the jump itself the series converges to the midpoint of the two sides.

### Synthesis by computer

```python
import numpy as np

x = np.linspace(0, 1, 501)          # string of length L = 1
h = 0.01                            # pluck height

def pluck(t, N, v=1.0):
    y = np.zeros_like(x)
    for n in range(1, N + 1, 2):    # only odd modes appear
        c = 8*h/(n*np.pi)**2 * np.sin(n*np.pi/2)
        y += c*np.sin(n*np.pi*x)*np.cos(n*np.pi*v*t)
    return y

print(pluck(0, 1).max(), pluck(0, 15).max())   # about 0.0081 and 0.0097
```

One mode gives a rounded hump of height $8h/\pi^2 \approx 0.81h$; eight odd modes already rebuild $97\%$ of the triangle's peak.

@example
title: Modes of a plucked string
problem: A string of length $L = 1.0\ \text{m}$ is plucked at its midpoint to a height $h = 2.0\ \text{cm}$ and released from rest. Find $c_1$, $c_2$ and $c_3$, and the midpoint height predicted by modes 1 and 3 alone.
step: For a midpoint pluck, $c_n = (8h/n^2\pi^2)\sin(n\pi/2)$. For $n = 1$: $c_1 = 16/\pi^2 \approx 1.62\ \text{cm}$.
step: For $n = 2$, $\sin\pi = 0$, so $c_2 = 0$. The midpoint is a node of mode 2.
step: For $n = 3$, $\sin(3\pi/2) = -1$, so $c_3 = -(16/\pi^2)/9 \approx -0.18\ \text{cm}$.
step: At $x = L/2$ the mode shapes are $\sin(n\pi/2) = +1$ and $-1$ for $n = 1$ and $3$. So $y(L/2) \approx 1.62 + 0.18 = 1.80\ \text{cm}$, already $90\%$ of $h$.
step: With all the odd modes, $\sum 1/n^2 = \pi^2/8$ gives $y(L/2) = (16/\pi^2)(\pi^2/8) = 2.0\ \text{cm} = h$ exactly.

@example
title: Coefficients of a flat-topped shape
problem: Find the sine-series coefficients of $h(x) = 1$ for $0 < x < L$, and evaluate the first three nonzero terms at $x = L/2$.
step: By the coefficient formula, $c_n = \dfrac{2}{L}\displaystyle\int_0^L \sin\frac{n\pi x}{L}\,dx = \dfrac{2}{L}\cdot\dfrac{L}{n\pi}\big(1 - \cos n\pi\big) = \dfrac{2\big(1 - (-1)^n\big)}{n\pi}$.
step: Even $n$ give $0$, and odd $n$ give $c_n = 4/(n\pi)$, so $h(x) \approx \dfrac{4}{\pi}\big[\sin\tfrac{\pi x}{L} + \tfrac13\sin\tfrac{3\pi x}{L} + \tfrac15\sin\tfrac{5\pi x}{L} + \cdots\big]$.
step: At $x = L/2$ the sines are $+1, -1, +1$, so three terms give $\dfrac{4}{\pi}\big(1 - \tfrac13 + \tfrac15\big) \approx 1.10$.
step: The full series is $\dfrac{4}{\pi}\cdot\dfrac{\pi}{4} = 1$, but the partial sums only creep toward it, since the coefficients fall as $1/n$. The sine series describes the odd extension of $h$, which jumps from $-1$ to $1$ at each fixed end (a jump of $2$). That jump is why the convergence is slow, and why the partial sums overshoot to about $1.18$ near the ends.

@mistakes
- Dropping the factor $2/L$ in the coefficient formula. The integral of $\sin^2$ over the string is $L/2$, not $1$.
- Expecting every harmonic from a pluck. A mode with a node at the pluck point is not excited (no even modes for a midpoint pluck).
- Using $\cos\omega_nt$ for a string started flat with a velocity (it needs $\sin\omega_nt$), or $\sin\omega_nt$ for a string released from rest.
- Believing the Gibbs overshoot disappears as more terms are added. It keeps its height and only moves closer to the jump.

prompt: The Fourier coefficients of the plucked-string triangle fall off as $1/n^2$, but those of a square wave fall off only as $1/n$. Why?
choice*: The triangle is continuous with only a corner, while the square wave has jump discontinuities, which need many more high-frequency terms.
choice: The triangle has a smaller amplitude than the square wave.

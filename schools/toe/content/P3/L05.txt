@article
Lesson 4 described a few masses on springs. Now let the number of masses grow until the chain becomes a continuous string. The displacement is no longer a list $x_1, x_2, \dots$ but a function $y(x,t)$ of position and time, and Newton's law becomes a partial differential equation.

### Deriving the equation

Take a string with tension $T$ and linear mass density $\mu$ (kg/m), lying along the $x$-axis, with small transverse displacement $y(x,t)$. Look at the element between $x$ and $x + dx$. If the slope $\partial y/\partial x$ is small, the element's length is about $dx$ and the tension pulls at each end along the string at angle $\theta$, with $\sin\theta \approx \tan\theta = \partial y/\partial x$. The net vertical force is

$$T\left[\frac{\partial y}{\partial x}(x+dx) - \frac{\partial y}{\partial x}(x)\right] = T\,\frac{\partial^2 y}{\partial x^2}\,dx.$$

Newton's second law for the element, whose mass is $\mu\,dx$, gives $\mu\,dx\,\partial_t^2 y = T\,\partial_x^2 y\,dx$, so

$$\frac{\partial^2 y}{\partial t^2} = v^2\,\frac{\partial^2 y}{\partial x^2}, \qquad v = \sqrt{\frac{T}{\mu}}.$$

This is the **wave equation**. The units work: $T/\mu$ is $(\text{kg m/s}^2)/(\text{kg/m}) = \text{m}^2/\text{s}^2$. We assumed small slopes, uniform tension, no damping and no gravity. The same equation, with a different $v$, describes sound in a gas, voltage on a cable and light in vacuum.

### Solutions of the form $f(x - vt)$

Let $y = f(x - vt)$ for any twice-differentiable $f$, and write $u = x - vt$. The chain rule gives

$$\partial_x y = f'(u),\quad \partial_x^2 y = f''(u),\quad \partial_t y = -v f'(u),\quad \partial_t^2 y = v^2 f''(u).$$

So $\partial_t^2 y = v^2\,\partial_x^2 y$: the wave equation holds, whatever the shape $f$. At time $t$ the shape is the same curve shifted right by $vt$, so $f(x - vt)$ is a **right-moving wave** that keeps its shape. The same argument shows that $g(x + vt)$ is a **left-moving wave**.

### The general solution

The wave equation is linear, so sums of solutions are solutions. The general solution is

$$y(x,t) = f(x - vt) + g(x + vt).$$

Because the equation is second order in time, you need two initial conditions, the initial shape $y(x,0)$ and initial velocity $\partial_t y(x,0)$, to fix $f$ and $g$.

### Checking a proposed solution

To test a candidate $y(x,t)$, compute $\partial_t^2 y$ and $\partial_x^2 y$ and see whether $\partial_t^2 y = v^2\,\partial_x^2 y$ with the right $v$. For a sinusoid $\sin(kx \pm \omega t)$ or $\sin(kx)\cos(\omega t)$ this reduces to one condition, $\omega = vk$. A function such as $\sin(x^2 - vt)$ fails because it is not a function of $x \pm vt$.

@example
title: Speed of a pulse on a string
problem: A $2.50\ \text{m}$ string of total mass $12.5\ \text{g}$ is stretched with tension $50\ \text{N}$. Find the wave speed and the time for a pulse to cross the string. What happens to the speed if the tension is quadrupled?
step: The linear density is $\mu = 0.0125/2.50 = 5.0\times10^{-3}\ \text{kg/m}$. Convert grams to kilograms first.
step: The speed is $v = \sqrt{T/\mu} = \sqrt{50/0.0050} = \sqrt{10000} = 100\ \text{m/s}$.
step: The crossing time is $t = L/v = 2.50/100 = 0.025\ \text{s}$.
step: Quadrupling $T$ multiplies $v$ by $\sqrt4 = 2$, giving $200\ \text{m/s}$ (taking $\mu$ unchanged).

@example
title: Testing a proposed wave function
problem: A string has $T = 100\ \text{N}$ and $\mu = 0.010\ \text{kg/m}$. A student proposes $y(x,t) = 0.03\cos(4x - 1000t)$ in SI units. Does it satisfy the wave equation? If not, what should the $1000$ be?
step: Here $v^2 = T/\mu = 1.0\times10^{4}\ \text{m}^2/\text{s}^2$, so the equation to satisfy is $y_{tt} = 10^4\,y_{xx}$.
step: Differentiating twice in time, $y_{tt} = -(1000)^2\,y = -10^{6}\,y$.
step: Differentiating twice in space, $y_{xx} = -(4)^2\,y = -16\,y$, so $v^2 y_{xx} = -1.6\times10^{5}\,y$.
step: The two sides, $-10^{6}y$ and $-1.6\times10^{5}y$, differ, so the proposal is not a solution. Its implied speed is $1000/4 = 250\ \text{m/s}$, not $100\ \text{m/s}$.
step: The condition $\omega = vk$ gives $\omega = 100(4) = 400\ \text{rad/s}$. The corrected function $0.03\cos(4x - 400t)$ has $y_{tt} = -1.6\times10^{5}y = v^2y_{xx}$, as required.

@mistakes
- Using $v = \sqrt{\mu/T}$ (inverted), or forgetting to convert grams to kilograms when computing $\mu$.
- Reading the coefficient in $y_{tt} = 9\,y_{xx}$ as the speed. The coefficient is $v^2$, so $v = 3$.
- Assuming $f(x - ct)$ solves the equation for any $c$. The number multiplying $t$ must equal the $v$ in the equation.
- Forgetting the small-slope assumption: for steep deflections the tension changes and the equation is no longer linear.

@practice num
prompt: A string of length $2.0\ \text{m}$ and mass $5.0\ \text{g}$ is stretched with tension $36\ \text{N}$. What is the speed of transverse waves on it?
answer: 120
check: sqrt(36.0/(0.0050/2.0))
unit: m/s
hint: Find the linear density $\mu$ = mass/length in kg/m first.
hint: $\mu = 2.5\times10^{-3}\ \text{kg/m}$. Then use $v = \sqrt{T/\mu}$.
solution: $\mu = 0.0050/2.0 = 2.5\times10^{-3}\ \text{kg/m}$ and $v = \sqrt{36/0.0025} = \sqrt{14400} = 120\ \text{m/s}$.

@practice num
prompt: The tension in a string is increased by a factor of $4$ and, at the same time, its linear density is increased by a factor of $9$. By what factor does the wave speed change? Give an exact fraction.
answer: 2/3
check: sqrt(4.0/9.0)
hint: The speed is $v = \sqrt{T/\mu}$, so only the ratio $T/\mu$ matters.
hint: The ratio $T/\mu$ is multiplied by $4/9$; take the square root.
solution: $v \propto \sqrt{T/\mu}$, so $v_{\text{new}}/v_{\text{old}} = \sqrt{4/9} = 2/3$.

@practice num
prompt: On a string with $T = 64\ \text{N}$ and $\mu = 0.010\ \text{kg/m}$, a solution of the wave equation has the form $y = A\sin(kx)\cos(\omega t)$ with wavelength $\lambda = 0.50\ \text{m}$. Find its frequency $f$.
answer: 160
check: sqrt(64.0/0.010)/0.50
unit: Hz
hint: Substituting this form into the wave equation requires $\omega = vk$.
hint: Compute $v = \sqrt{T/\mu}$ and $k = 2\pi/\lambda$, then convert $\omega$ to $f$.
solution: $v = \sqrt{64/0.010} = 80\ \text{m/s}$ and $k = 2\pi/0.50 = 4\pi\ \text{rad/m}$. Then $\omega = vk = 320\pi\ \text{rad/s}$ and $f = \omega/2\pi = 160\ \text{Hz}$, which equals $v/\lambda$.

@quiz num
prompt: A $12.0\ \text{m}$ rope of total mass $0.060\ \text{kg}$ is held under a tension of $20\ \text{N}$. How long does a transverse pulse take to travel its length? Give three significant figures.
answer: 0.190
check: 12.0/sqrt(20.0/(0.060/12.0))
tol: 1%
unit: s
hint: Find $\mu$, then the speed $v = \sqrt{T/\mu}$.
hint: The travel time is the length divided by the speed.
solution: $\mu = 0.060/12.0 = 5.0\times10^{-3}\ \text{kg/m}$ and $v = \sqrt{20/0.0050} = \sqrt{4000} \approx 63.2\ \text{m/s}$. Then $t = 12.0/63.2 \approx 0.190\ \text{s}$.

@quiz mc
prompt: Exactly one of these functions satisfies $y_{tt} = 4\,y_{xx}$. Which one?
choice*: $y = \sin(3x + 6t)$
choice: $y = \sin(x - 4t)$
choice: $y = \sin(2x)\cos(3t)$
choice: $y = (x - 4t)^2$
hint: The coefficient $4$ is $v^2$, so the wave speed is $v = 2$.
hint: A sinusoid works only if $\omega/k = 2$, and a general function must depend on $x \pm 2t$.
solution: $\sin(3x + 6t)$ has $\omega/k = 6/3 = 2$ and is a function of $3(x + 2t)$. The function $\sin(x - 4t)$ moves at speed $4$, $\sin 2x\cos 3t$ has $\omega/k = 1.5$, and $(x - 4t)^2$ depends on $x - 4t$, not on $x \pm 2t$.

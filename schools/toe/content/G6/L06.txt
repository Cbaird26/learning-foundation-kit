@article
For a conservative mechanical system, a good integrator should respect the *structure* of the equations, not only be accurate for short times. Hamiltonian systems have exactly the structure that long simulations of orbits, molecules and oscillators depend on.

### Hamiltonian systems

With coordinates $q$ and momenta $p$ and a Hamiltonian $H(q,p)$,

$$\dot q = \frac{\partial H}{\partial p}, \qquad \dot p = -\frac{\partial H}{\partial q}.$$

For $H=\tfrac12p^2+V(q)$ this is $\dot q=p$, $\dot p=-V'(q)$. The energy $H$ is conserved, and the flow is **symplectic**: a map with Jacobian $M$ is symplectic if $M^{T}JM=J$ where $J=\begin{pmatrix}0&I\\-I&0\end{pmatrix}$. For one degree of freedom this just says the map preserves area ($\det M=1$).

### Two symplectic methods

For $H=\tfrac12p^2+V(q)$:

- **Symplectic Euler** (first order): $p_{n+1}=p_n-h\,V'(q_n)$, then $q_{n+1}=q_n+h\,p_{n+1}$. Note that $q$ uses the *new* $p$.
- **Velocity Verlet / leapfrog / Störmer–Verlet** (second order, time-reversible):

$$p_{n+\frac12}=p_n-\tfrac h2V'(q_n),\quad q_{n+1}=q_n+h\,p_{n+\frac12},\quad p_{n+1}=p_{n+\frac12}-\tfrac h2V'(q_{n+1}).$$

Verlet needs one new force evaluation per step, because the last half-kick of one step and the first of the next can be merged. Both are built by composing exactly solvable symplectic pieces (a "kick" changing $p$ and a "drift" changing $q$), which is why they are symplectic. For a central force, each kick is along $r$ and each drift is along $p$, so the angular momentum $r\times p$ is conserved exactly.

### Why energy stays bounded

A symplectic method does **not** conserve $H$. Backward error analysis shows that, for small enough $h$ and analytic $H$, the numerical solution of an order-$p$ symplectic method is, up to an exponentially small remainder, the *exact* flow of a **modified Hamiltonian**

$$\tilde H = H + h^{p}H_{p+1} + h^{p+1}H_{p+2}+\cdots .$$

So $\tilde H$ is essentially conserved and $H$ oscillates by $O(h^{p})$ with **no secular drift** over very long times. Non-symplectic methods, even high-order ones, drift: explicit Euler on the harmonic oscillator multiplies the energy by $1+h^2$ every step, while RK4 multiplies it by $1-h^{6}/72+\cdots$. The RK4 drift is tiny for small $h$ and wins on short runs, but it grows steadily with time and is never bounded. Two cautions: adaptive step size destroys the property (it is a statement about a fixed $h$), and for the oscillator $\ddot q=-\omega^2q$ Verlet is stable only for $h\omega<2$.

### Measuring energy drift

Record the energy error at *every* step and summarize it two ways: the maximum $|\Delta E|/|E_0|$ and the slope of a linear fit of $\Delta E$ against $t$. Bounded oscillation means a maximum that does not grow with run length and a slope near zero; secular drift means both grow with $T$.

```python
import numpy as np

def energy(q, p):
    return 0.5 * p**2 + 0.5 * q**2

def euler(q, p, h):
    return q + h * p, p - h * q

def sympl_euler(q, p, h):
    p = p - h * q
    return q + h * p, p

def verlet(q, p, h):
    p = p - 0.5 * h * q
    q = q + h * p
    p = p - 0.5 * h * q
    return q, p

def energy_error(step, h, nsteps, q=1.0, p=0.0):
    E0 = energy(q, p)
    err = np.empty(nsteps)
    for i in range(nsteps):
        q, p = step(q, p, h)
        err[i] = (energy(q, p) - E0) / E0
    t = h * np.arange(1, nsteps + 1)
    return np.abs(err).max(), np.polyfit(t, err, 1)[0]
```

Over very long runs rounding errors also add a slow random-walk growth of order $\sqrt{n}\,u$; this is small compared with truncation effects unless $n$ is huge.

@example
title: Explicit Euler spirals outward
problem: Apply explicit Euler with $h=0.1$ to the harmonic oscillator $\dot q=p$, $\dot p=-q$. Show how the energy $E=\tfrac12(q^2+p^2)$ changes per step and find the growth factor by $t=100$.
step: One step is $q'=q+hp$, $p'=p-hq$.
step: Expanding, $q'^2+p'^2 = q^2+2hqp+h^2p^2+p^2-2hpq+h^2q^2 = (1+h^2)(q^2+p^2)$. The cross terms cancel exactly.
step: So $E_n=(1+h^2)^nE_0$ for every start. With $h=0.1$ and $n=1000$ steps, $E_n/E_0=1.01^{1000}=e^{1000\ln1.01}\approx e^{9.95}\approx2.1\times10^{4}$.
step: Since $(1+h^2)^{t/h}\approx e^{ht}$, the drift rate is proportional to $h$: halving the step only halves the exponent. The orbit spirals outward whatever $h$ is.

@example
title: Symplectic Euler has a conserved quantity
problem: For the same oscillator, symplectic Euler is $p'=p-hq$, $q'=q+hp'$. Show that $I=q^2+p^2-h\,qp$ is exactly conserved and use it to bound the energy error for the start $(q,p)=(1,0)$ and $h=0.1$.
step: Eliminating $p'$ gives $q'=(1-h^2)q+hp$ and $p'=p-hq$.
step: Substituting into $q'^2+p'^2-hq'p'$ and expanding, the coefficients of $q^2$, $qp$ and $p^2$ come out as $1$, $-h$ and $1$. Hence $I(q',p')=I(q,p)$ exactly.
step: For the start $(1,0)$, $I=1$, so the energy satisfies $2E-hqp=1$, i.e. $E=\tfrac12(1+hqp)$.
step: Since $|qp|\le E$, we get $\frac{1}{2+h}\le E\le\frac{1}{2-h}$. For $h=0.1$ this is $0.4762\le E\le0.5263$, a relative error of at most $h/(2-h)\approx5.3\%$ for all time. The energy oscillates but never drifts.

@mistakes
- Assuming a high-order method such as RK4 is symplectic, or that "accurate" means "structure preserving".
- Using an adaptive step size (for instance `solve_ivp`) for a very long Hamiltonian run and expecting bounded energy error.
- Looking only at the final energy or only at a short run, which cannot separate bounded oscillation from slow drift.
- Writing the symplectic Euler step with the old $p$ in the $q$ update, which gives the explicit Euler method and a growing energy.

@quiz self
prompt: Write a function that integrates the pendulum $\ddot\theta=-\sin\theta$ with fixed-step velocity Verlet starting from $\theta_0$ with zero angular velocity, and returns the maximum absolute energy error $|\Delta E|$ (with $E=\tfrac12\omega^2-\cos\theta$) and the slope of a linear fit of $\Delta E$ against $t$. State how you would distinguish bounded oscillation from secular drift using these two numbers, and what you expect for RK4 on the same run.
hint: Apply the half kick, drift, half kick sequence with force $-\sin\theta$.
hint: Store $\Delta E$ at every step before fitting.
solution: Model code:

```python
import numpy as np

def pendulum_verlet(theta0, h, nsteps):
    th, om = theta0, 0.0
    E = lambda th, om: 0.5 * om**2 - np.cos(th)
    E0 = E(th, om)
    dE = np.empty(nsteps)
    for i in range(nsteps):
        om -= 0.5 * h * np.sin(th)
        th += h * om
        om -= 0.5 * h * np.sin(th)
        dE[i] = E(th, om) - E0
    t = h * np.arange(1, nsteps + 1)
    return np.abs(dE).max(), np.polyfit(t, dE, 1)[0]
```
Bounded oscillation shows a maximum that stays the same when `nsteps` is multiplied by 10 and a slope near zero (relative to the maximum divided by $T$); secular drift shows a maximum that grows with `nsteps` and a clearly nonzero slope. Verlet should give the first behavior. RK4 is more accurate at short times but not symplectic, so over a long enough run its error grows steadily.

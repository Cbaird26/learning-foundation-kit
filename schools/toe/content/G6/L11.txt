@article
Inference asks the inverse of simulation: given noisy data, which parameter values are plausible, and how well are they determined? The answer always has two parts, a best estimate and an uncertainty, and both rest on stated assumptions about the noise.

### Likelihood and least squares

Suppose $y_i=f(x_i;\theta)+\epsilon_i$ with independent Gaussian noise $\epsilon_i\sim N(0,\sigma_i^2)$. The likelihood of the data is a product of Gaussians, and

$$-2\ln L(\theta)=\chi^2(\theta)+\text{const},\qquad \chi^2(\theta)=\sum_i\frac{\big(y_i-f(x_i;\theta)\big)^2}{\sigma_i^2}.$$

So the **maximum-likelihood estimate** is the **weighted least-squares** fit. With different noise models (outliers, Poisson counts) the likelihood changes and so does the best method.

### Linear models

For $y=A\theta+\epsilon$ the minimizer solves the normal equations $A^TA\,\theta=A^Ty$. Do not solve them numerically: forming $A^TA$ squares the condition number, $\kappa(A^TA)=\kappa(A)^2$. Use `np.linalg.lstsq` (SVD) or a QR factorization instead. For noise of variance $\sigma^2$,

$$\operatorname{Cov}(\hat\theta)=\sigma^2\,(A^TA)^{-1},\qquad \hat\sigma^2=\frac{\|y-A\hat\theta\|^2}{n-p}$$

when $\sigma$ is unknown ($n$ data points, $p$ parameters). The standard errors are the square roots of the diagonal.

### Nonlinear models

Replace $A$ by the Jacobian $J_{ik}=\partial f(x_i;\theta)/\partial\theta_k$ and iterate (Gauss–Newton, Levenberg–Marquardt). At the optimum, $\operatorname{Cov}(\hat\theta)\approx\sigma^2(J^TJ)^{-1}$, valid when $f$ is nearly linear over the uncertainty region. Start from several initial guesses: nonlinear fits can stop in local minima.

```python
import numpy as np
from scipy.optimize import curve_fit

rng = np.random.default_rng(4)
t = np.linspace(0.0, 5.0, 40)
sigma = 0.05
model = lambda t, A, tau: A * np.exp(-t / tau)
y = model(t, 2.0, 1.5) + sigma * rng.standard_normal(t.size)   # known truth: A=2, tau=1.5

popt, pcov = curve_fit(model, t, y, p0=(1.0, 1.0),
                       sigma=sigma * np.ones_like(t), absolute_sigma=True)
perr = np.sqrt(np.diag(pcov))
chi2_red = np.sum(((y - model(t, *popt)) / sigma) ** 2) / (t.size - 2)
print(popt, perr, chi2_red)
```

With `absolute_sigma=False` (the default) SciPy rescales `pcov` by the fit's reduced $\chi^2$, so the quoted errors then reflect the scatter in the data rather than the $\sigma$ you supplied.

### Diagnosing a fit

Plot the residuals: they should look like noise with the stated spread and no trend. The **reduced chi-square** $\chi^2_\nu=\chi^2/(n-p)$ should be $1\pm\sqrt{2/(n-p)}$. Values well above $1$ mean the model is wrong or $\sigma$ is underestimated; values well below $1$ mean $\sigma$ is overestimated or the model is overfitting. Inspect the correlation matrix from `pcov`: correlations near $\pm1$ mean two parameters are nearly interchangeable (near-degeneracy), and $J^TJ$ is close to singular.

### The Bayesian view

Bayes' rule gives the **posterior** $p(\theta\mid y)\propto L(\theta)\,p(\theta)$, where $p(\theta)$ is the prior. For a Gaussian mean $\mu$ with prior $N(\mu_0,\tau^2)$ and $n$ data with sample mean $\bar y$ and noise $\sigma$, the posterior is Gaussian with

$$\frac1{s^2}=\frac1{\tau^2}+\frac n{\sigma^2},\qquad m=s^2\Big(\frac{\mu_0}{\tau^2}+\frac{n\bar y}{\sigma^2}\Big).$$

Precisions add, and the mean is a precision-weighted average, pulled from $\bar y$ toward $\mu_0$ (**shrinkage**). As $n$ grows the data dominate. A prior is an assumption, not a lack of one, so report it. For models without closed forms, sample the posterior with MCMC and apply the autocorrelation analysis of the last lesson.

### Test the pipeline on synthetic data

Before touching real data, simulate with known $\theta$, fit, and check that (i) the estimates scatter around the truth, (ii) the scatter matches the quoted standard errors, and (iii) about 68% of repeated datasets give a 1-sigma interval that contains the truth. Failures reveal bugs, bad starts, degeneracy or an inconsistent noise model.

@example
title: A straight-line fit with uncertainties
problem: Fit $y=a+bx$ to the points $(0,1.0),(1,3.1),(2,4.9),(3,7.0)$, where the noise level is unknown. Give $b$ and its standard error.
step: $\bar x=1.5$, $\bar y=4.0$, $S_{xx}=\sum(x-\bar x)^2=5$, and $S_{xy}=\sum(x-\bar x)(y-\bar y)=9.9$.
step: The slope is $\hat b=S_{xy}/S_{xx}=1.98$ and the intercept is $\hat a=\bar y-\hat b\bar x=1.03$.
step: Fitted values are $1.03,\,3.01,\,4.99,\,6.97$, so the residuals are $-0.03,\,0.09,\,-0.09,\,0.03$ and the sum of squares is $0.018$.
step: With $n-p=2$ degrees of freedom, $\hat\sigma^2=0.018/2=0.009$, and $\operatorname{SE}(\hat b)=\hat\sigma/\sqrt{S_{xx}}=0.0949/2.236=0.042$. Result: $b=1.98\pm0.04$.

@example
title: A Gaussian prior shrinks the estimate
problem: The prior is $\mu\sim N(0,1)$. Four measurements with $\sigma=1$ have mean $\bar y=2.0$. Find the posterior mean and standard deviation.
step: The prior precision is $1/\tau^2=1$ and the data precision is $n/\sigma^2=4$, so the posterior precision is $5$ and $s=1/\sqrt5=0.447$.
step: The mean is $m=s^2\,(0\cdot1+4\cdot2.0)=\tfrac15\cdot8=1.6$.
step: The data alone would give $2.0\pm0.5$. The posterior $1.6\pm0.45$ is pulled toward the prior mean $0$ and slightly narrower.
step: With $n=100$ the data precision is $100$, giving $m=200/101=1.98$: the prior's influence has almost disappeared.

@mistakes
- Solving the normal equations $A^TA\theta=A^Ty$ for an ill-conditioned problem instead of using QR or SVD.
- Quoting `curve_fit` errors without knowing whether `absolute_sigma` rescaled them by the reduced $\chi^2$.
- Accepting the first converged nonlinear fit without trying other starting values or checking residuals.
- Treating a flat or "uninformative" prior as assumption-free: a flat prior on $\tau$ and on $1/\tau$ are different assumptions.

@quiz self
prompt: Write code that tests a nonlinear fit by repetition. Generate synthetic data $y=A e^{-t/\tau}+\epsilon$ with known $A,\tau,\sigma$, fit with `curve_fit` and `absolute_sigma=True`, repeat for 200 independent datasets (independent random streams), and report the fraction of datasets in which the true $\tau$ lies within one standard error of the estimate. State the value you expect and what a much lower fraction would indicate.
hint: Spawn one random stream per dataset from a single `SeedSequence`.
hint: For each dataset, compare `abs(popt[1] - tau_true)` with `perr[1]`.
solution: Model code:

```python
import numpy as np
from scipy.optimize import curve_fit

def coverage(A=2.0, tau=1.5, sigma=0.05, reps=200, seed=11):
    t = np.linspace(0.0, 5.0, 40)
    model = lambda t, A, tau: A * np.exp(-t / tau)
    hits = 0
    for s in np.random.SeedSequence(seed).spawn(reps):
        rng = np.random.default_rng(s)
        y = model(t, A, tau) + sigma * rng.standard_normal(t.size)
        popt, pcov = curve_fit(model, t, y, p0=(1.0, 1.0),
                               sigma=sigma * np.ones_like(t), absolute_sigma=True)
        hits += abs(popt[1] - tau) < np.sqrt(pcov[1, 1])
    return hits / reps
```
For a well-behaved fit, about $68\%$ of datasets (plus or minus about $3\%$ from finite repetitions) should cover the truth. A much lower fraction means the quoted errors are too small: the noise model is wrong, the fit is stuck in local minima, the linearized covariance is inaccurate for this model, or the parameters are nearly degenerate.

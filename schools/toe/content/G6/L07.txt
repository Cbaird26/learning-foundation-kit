@article
A partial differential equation (PDE) lives on a continuum; a computer can only hold finitely many numbers. **Discretization** replaces the unknown function by its values on a grid and the derivatives by combinations of those values. Everything that follows, accuracy, stability and cost, is decided by how you do this.

### Finite-difference stencils

Take grid spacing $h$ and Taylor-expand about $x$. Three basic quotients:

$$\frac{u(x+h)-u(x)}{h}=u'+\tfrac h2u''+\cdots \qquad\text{(forward, first order)}$$

$$\frac{u(x+h)-u(x-h)}{2h}=u'+\tfrac{h^2}{6}u'''+\cdots \qquad\text{(central, second order)}$$

$$\frac{u(x+h)-2u(x)+u(x-h)}{h^2}=u''+\tfrac{h^2}{12}u''''+\cdots \qquad\text{(second derivative, second order)}$$

The leading term that remains is the **truncation error**. A scheme is **consistent** if the truncation error tends to zero with $h$, and of order $p$ if it is $O(h^{p})$.

### Model problem: 1D Poisson

Solve $-u''=f$ on $(0,1)$ with $u(0)=u(1)=0$. Use $n$ intervals, $h=1/n$, and unknowns $u_1,\dots,u_{n-1}$ at the interior nodes $x_j=jh$. The scheme $-(u_{j-1}-2u_j+u_{j+1})/h^2=f_j$ is the linear system

$$A\mathbf u=\mathbf f,\qquad A=\frac1{h^2}\,\text{tridiag}(-1,\,2,\,-1)\in\mathbb R^{(n-1)\times(n-1)}.$$

$A$ is symmetric positive definite and sparse, so a sparse direct solve costs only $O(n)$ operations.

```python
import numpy as np
from scipy.sparse import diags
from scipy.sparse.linalg import spsolve

def poisson_error(n):
    h = 1.0 / n
    x = np.linspace(0.0, 1.0, n + 1)[1:-1]
    A = diags([-1.0, 2.0, -1.0], [-1, 0, 1], shape=(n - 1, n - 1), format="csc") / h**2
    f = np.pi**2 * np.sin(np.pi * x)          # manufactured: u = sin(pi x)
    u = spsolve(A, f)
    return np.abs(u - np.sin(np.pi * x)).max()

errs = np.array([poisson_error(n) for n in (16, 32, 64, 128)])
print(np.log2(errs[:-1] / errs[1:]))           # close to 2
```

This is the **method of manufactured solutions**: choose a smooth $u$, compute the $f$ that it satisfies, and check that your code reproduces $u$ with the expected order. It tests the implementation, not the physics.

### Boundary conditions

Dirichlet values go straight into the right-hand side. For a **Neumann** condition $u'(0)=g$, introduce a ghost node $u_{-1}$ and use the central difference $(u_1-u_{-1})/(2h)=g$ to eliminate it, which keeps second-order accuracy. Using the one-sided quotient $(u_1-u_0)/h=g$ is simpler but only first order, and the boundary error then limits the whole solution.

### Method of lines for the heat equation

For $u_t=\alpha u_{xx}$ discretize only in space. The result is a system of ODEs $\dot{\mathbf u}=-\alpha A\mathbf u$, which you integrate with any ODE method from the earlier lessons. The eigenvalues of $-\alpha A$ are

$$\lambda_j=-\frac{4\alpha}{h^2}\sin^2\!\frac{j\pi}{2n},\qquad j=1,\dots,n-1,$$

between about $-\alpha\pi^2$ (the slowest physical mode, well approximated) and $-4\alpha/h^2$ (the grid-scale mode). Their ratio grows like $h^{-2}$. This spread, harmless for accuracy, controls stability in the next lesson.

### Verifying a discretization

1. Pick a smooth exact solution and derive its data.
2. Solve on at least three grids ($h$, $h/2$, $h/4$).
3. Compute the error in a fixed norm on the common grid points.
4. Check that $\log_2(e_h/e_{h/2})$ approaches the order you derived.

A small *residual* of the discrete system proves nothing here: the linear system can be solved perfectly while the discretization error is large.

@example
title: Deriving the second-derivative stencil
problem: Show that $(u(x+h)-2u(x)+u(x-h))/h^2$ approximates $u''(x)$ with error $\tfrac{h^2}{12}u''''(x)+O(h^4)$, and test it on $u=e^{x}$ at $x=0$ with $h=0.1$.
step: Expand $u(x\pm h)=u\pm hu'+\tfrac{h^2}{2}u''\pm\tfrac{h^3}{6}u'''+\tfrac{h^4}{24}u''''+\cdots$.
step: Add the two expansions: odd derivatives cancel, giving $u(x+h)+u(x-h)=2u+h^2u''+\tfrac{h^4}{12}u''''+\cdots$.
step: Subtract $2u$ and divide by $h^2$: the quotient equals $u''+\tfrac{h^2}{12}u''''+O(h^4)$.
step: For $u=e^{x}$ at $0$, the quotient is $(e^{0.1}-2+e^{-0.1})/0.01=1.000834$. The error $8.34\times10^{-4}$ matches $h^2/12=8.33\times10^{-4}$.

@example
title: Spectrum of the semi-discrete heat operator
problem: For $u_t=u_{xx}$ on $(0,1)$ with $u=0$ at both ends, use $n=10$ intervals. Find the slowest and fastest eigenvalues of the semi-discrete system and compare the slowest with the exact $-\pi^2$.
step: With $h=0.1$ the matrix is $\frac{1}{h^2}\text{tridiag}(1,-2,1)$ and $\lambda_j=-400\sin^2(j\pi/20)$.
step: Slowest mode $j=1$: $\sin(\pi/20)=0.15643$, so $\lambda_1=-400(0.024472)=-9.789$. The exact value is $-\pi^2=-9.870$, a relative difference of 0.8%.
step: Fastest mode $j=9$: $\sin(9\pi/20)=0.98769$, so $\lambda_9=-400(0.97553)=-390.2$.
step: The spread is $\lambda_9/\lambda_1\approx40$ and grows like $h^{-2}$: the fast modes are grid artifacts and determine the largest stable explicit time step.

@mistakes
- Confusing the number of intervals $n$ with the number of unknowns $n-1$, so the matrix size or the factor $1/h^2$ is wrong.
- Using a one-sided difference for a Neumann condition and not noticing that it lowers the global order to one.
- Declaring convergence because the linear solver's residual is tiny, without comparing with an exact or finer-grid solution.
- Measuring the observed order from errors taken at different points or in different norms on the different grids.

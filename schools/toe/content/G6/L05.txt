@article
An **initial value problem** (IVP) asks for $y(t)$ with $y'=f(t,y)$ and $y(t_0)=y_0$, where $y$ may be a vector. Numerical integrators march forward in steps of size $h$. The questions that matter for computation are: how fast does the error shrink as $h \to 0$, and how do you *demonstrate* that your code is doing what you think?

### One-step methods

Write $t_{n+1}=t_n+h$. Three standard methods:

- **Explicit Euler:** $y_{n+1}=y_n+h\,f(t_n,y_n)$.
- **Heun (explicit trapezoid rule, order 2):** $k_1=f(t_n,y_n)$, $k_2=f(t_n+h,\,y_n+hk_1)$, $y_{n+1}=y_n+\tfrac h2(k_1+k_2)$.
- **Classical RK4:**

$$y_{n+1}=y_n+\tfrac h6\,(k_1+2k_2+2k_3+k_4),$$

with $k_1=f(t_n,y_n)$, $k_2=f(t_n+\tfrac h2,\,y_n+\tfrac h2k_1)$, $k_3=f(t_n+\tfrac h2,\,y_n+\tfrac h2k_2)$, $k_4=f(t_n+h,\,y_n+hk_3)$.

```python
import numpy as np

def euler(f, y0, t0, t1, n):
    h = (t1 - t0) / n
    t, y = t0, np.array(y0, float)
    for _ in range(n):
        y = y + h * f(t, y)
        t += h
    return y

def rk4(f, y0, t0, t1, n):
    h = (t1 - t0) / n
    t, y = t0, np.array(y0, float)
    for _ in range(n):
        k1 = f(t, y)
        k2 = f(t + h / 2, y + h / 2 * k1)
        k3 = f(t + h / 2, y + h / 2 * k2)
        k4 = f(t + h, y + h * k3)
        y = y + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
        t += h
    return y
```

### Order of accuracy

A method has **order** $p$ if its *global* error at a fixed final time behaves like $C h^{p}$. Each step contributes a **local truncation error** of size $O(h^{p+1})$, and about $1/h$ steps accumulate, losing one power. Euler has $p=1$, Heun $p=2$, RK4 $p=4$.

If $e(h)\approx Ch^{p}$, halving the step divides the error by $2^{p}$, so

$$p_{\text{obs}} = \log_2\frac{e(h)}{e(h/2)}.$$

Computing $p_{\text{obs}}$ for a problem whose exact solution you know is the standard **convergence test**. It catches bugs that a single accurate-looking answer hides: an RK4 code that converges at order 2 has a mistake in a coefficient.

```python
f = lambda t, y: -y
for n in (10, 20, 40, 80):
    err = abs(euler(f, [1.0], 0.0, 1.0, n)[0] - np.exp(-1.0))
    print(n, err)       # roughly halves each time: first order
```

### Limits of a convergence test

Use at least three step sizes and check that the observed order is steady. For very small $h$ the truncation error is below the rounding error, and the total error behaves like $Ch^{p} + u/h$, so $p_{\text{obs}}$ drifts away from $p$. If the solution is not smooth enough (a discontinuous right-hand side, a singularity), the nominal order will not be reached.

### Adaptive step size and solve_ivp

Embedded pairs such as Dormand–Prince (`method="RK45"` or the higher-order `"DOP853"`) compare two estimates of different order to estimate the local error and adjust $h$:

```python
from scipy.integrate import solve_ivp

sol = solve_ivp(lambda t, y: -y, (0.0, 1.0), [1.0],
                method="RK45", rtol=1e-8, atol=1e-10)
print(sol.y[0, -1] - np.exp(-1.0))
```

`rtol` and `atol` bound the **local** error per step, roughly $|{\rm err}| \lesssim {\rm atol} + {\rm rtol}\,|y|$. The global error can be larger, and it grows with the length of the integration. Always verify with a tighter tolerance or a second method. Stiff problems need implicit methods (`"Radau"`, `"BDF"`, `"LSODA"`); that is the subject of the stability lesson.

title: Three Euler steps by hand
problem: Apply explicit Euler with $h=0.1$ to $y'=-2y$, $y(0)=1$, for three steps. Compare with the exact value $y(0.3)=e^{-0.6}$.
step: Each step multiplies by $1+h\lambda$ with $\lambda=-2$: $y_{n+1}=y_n+0.1(-2y_n)=0.8\,y_n$.
step: After three steps $y_3=0.8^{3}=0.512$.
step: The exact value is $e^{-0.6}\approx0.5488$.
step: The error is $0.5488-0.512\approx0.0368$, about 6.7% of the solution. A first-order method at $h=0.1$ gives only about one correct digit, which is typical.

@example
title: Observed order from a convergence table
problem: A method gives global errors $3.2\times10^{-3}$, $8.1\times10^{-4}$ and $2.0\times10^{-4}$ at $h=0.1,\,0.05,\,0.025$. Estimate its order and predict the error at $h=0.0125$.
step: First ratio: $3.2\times10^{-3}/8.1\times10^{-4}\approx3.95$, so $p_{\text{obs}}=\log_2 3.95\approx1.98$.
step: Second ratio: $8.1\times10^{-4}/2.0\times10^{-4}\approx4.05$, so $p_{\text{obs}}\approx2.02$.
step: Both are close to $2$ and steady, so the method is second order.
step: Halving $h$ again divides the error by $2^2=4$: predicted error $2.0\times10^{-4}/4=5\times10^{-5}$.

@mistakes
- Confusing local and global error: a method with local error $O(h^{p+1})$ has global error $O(h^{p})$.
- Judging order from two step sizes, or from sizes so small that rounding error dominates.
- Setting `rtol=1e-3` in `solve_ivp` and reading the result as accurate to three digits at the end of a long integration.
- Testing only against a single reference value instead of checking that the error scales with $h$ as the theory predicts.

@quiz self
prompt: Write a function `observed_orders(method, f, y0, t1, exact, ns)` where `method(f, y0, t0, t1, n)` returns the numerical solution at `t1`. It should return the list of observed orders between consecutive step counts in `ns` (each double the previous). Explain what you would conclude if the orders were close to 2 for a method claimed to be fourth order.
solution: Model code:

```python
import numpy as np

def observed_orders(method, f, y0, t1, exact, ns):
    errs = [np.linalg.norm(method(f, y0, 0.0, t1, n) - exact) for n in ns]
    return [np.log2(errs[i] / errs[i + 1]) for i in range(len(ns) - 1)]
```

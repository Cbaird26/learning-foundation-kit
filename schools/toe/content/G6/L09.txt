@article
**Monte Carlo** (MC) methods estimate a quantity by random sampling. They are the method of choice when an integral is high dimensional, when a distribution is known only through a simulator, or when a density is known only up to a constant.

### Monte Carlo integration

For a random variable $X$ with density $p$, the integral $I=\int f(x)p(x)\,dx = \mathbb E[f(X)]$ is estimated from independent draws $X_1,\dots,X_N\sim p$ by the sample mean

$$\hat I_N=\frac1N\sum_{i=1}^{N}f(X_i).$$

The estimator is unbiased, and by the central limit theorem its error is approximately normal with variance $\sigma^2/N$, where $\sigma^2=\operatorname{Var}f(X)$. In practice $\sigma$ is estimated from the same draws, giving the **standard error**

$$\operatorname{SE}=\frac{s}{\sqrt N},\qquad s^2=\frac1{N-1}\sum_{i}(f(X_i)-\hat I_N)^2 .$$

A 95% interval is roughly $\hat I_N\pm1.96\,\mathrm{SE}$ for large $N$. The $N^{-1/2}$ rate does not depend on dimension, which is the strength of MC, but it is slow: one more correct digit costs 100 times as many samples.

```python
import numpy as np

rng = np.random.default_rng(12345)       # reproducible generator object
N = 100_000
f = np.exp(-rng.random(N) ** 2)           # integrand e^{-x^2}, x ~ U(0,1)
print(f.mean(), f.std(ddof=1) / np.sqrt(N))   # about 0.7465 with SE about 6e-4; exact 0.7468...
```

### Reproducibility and independent streams

Pseudo-random numbers are deterministic: the same seed gives the same stream. Create a generator once with `np.random.default_rng(seed)` and pass it to your functions instead of relying on global state. To run independent replicates or parallel workers, spawn child streams:

```python
ss = np.random.SeedSequence(2024)
rngs = [np.random.default_rng(s) for s in ss.spawn(8)]   # 8 independent streams
```

Creating each replicate with the *same* seed gives identical "independent" runs, a classic and silent bug. Record the seed and library versions with every result.

### Generating samples

**Inverse transform.** If $U\sim U(0,1)$ and $F$ is a CDF with inverse $F^{-1}$, then $F^{-1}(U)$ has distribution $F$. For the exponential distribution, $F(x)=1-e^{-\lambda x}$, so $X=-\ln(1-U)/\lambda$.

**Rejection sampling.** Draw $Y$ from an easy density $q$ with $p(x)\le Mq(x)$; accept with probability $p(Y)/(Mq(Y))$. The acceptance rate is $1/M$, which collapses in high dimension.

### Variance reduction

Cut $\sigma$ rather than raising $N$. **Control variates** subtract a correlated function $g$ with known mean: use $f-\beta\,(g-\mathbb E g)$. **Antithetic variates** pair $U$ with $1-U$. **Importance sampling** draws from $q$ and averages $f\,p/q$; it needs $q$ to have tails at least as heavy as $p$, otherwise the variance can be infinite.

### Markov chain Monte Carlo

When only $\pi(x)$ up to a constant is available, build a Markov chain with $\pi$ as stationary distribution. The **Metropolis** rule proposes $y=x+\epsilon$ from a symmetric distribution and accepts with probability $\min\{1,\pi(y)/\pi(x)\}$, which satisfies detailed balance.

```python
def metropolis(logp, x0, step, n, rng):
    x, lp = x0, logp(x0)
    out = np.empty(n)
    for i in range(n):
        y = x + step * rng.standard_normal()
        lq = logp(y)
        if np.log(rng.random()) < lq - lp:
            x, lp = y, lq
        out[i] = x
    return out
```

Tune `step` so that the acceptance rate is neither near 0 (steps so large that almost every proposal is rejected) nor near 1 (steps so small that the chain diffuses slowly), and discard an initial burn-in. The output is **correlated**, so the formula $s/\sqrt N$ does not apply to it; handling that is the topic of the next lesson.

@example
title: Planning a sample size
problem: A pilot run with $N=10^4$ draws of $f(X)$ gives $\hat I=0.7471$ and sample standard deviation $s=0.2012$. Report the standard error and a 95% interval, and estimate how many draws give $\mathrm{SE}=10^{-4}$.
step: $\mathrm{SE}=s/\sqrt N=0.2012/100=2.01\times10^{-3}$.
step: The 95% interval is $0.7471\pm1.96(2.01\times10^{-3})=0.7471\pm0.0039$, i.e. $[0.7432,\,0.7510]$.
step: Since $\mathrm{SE}\propto N^{-1/2}$, we need $N=(s/\mathrm{SE}_{\text{target}})^2=(0.2012/10^{-4})^2\approx4.0\times10^{6}$.
step: That is $400$ times the pilot size for a $20$-fold smaller error. A variance-reduction trick that halves $s$ would cut the required $N$ by four.

@example
title: Sampling an exponential by inversion
problem: Generate a sample from $p(x)=\lambda e^{-\lambda x}$ using a uniform $U$, and compute the sample for $\lambda=2$, $U=0.3$.
step: The CDF is $F(x)=1-e^{-\lambda x}$ for $x\ge0$.
step: Solve $u=F(x)$ for $x$: $e^{-\lambda x}=1-u$, so $x=-\ln(1-u)/\lambda$.
step: With $\lambda=2$ and $u=0.3$: $x=-\ln(0.7)/2=0.3567/2=0.1783$.
step: Check: $F(0.1783)=1-e^{-0.3567}=0.3$. Averaging many such $x$ should approach the mean $1/\lambda=0.5$.

@mistakes
- Creating every replicate with `default_rng(0)` and being surprised that all the "independent" results are identical.
- Reporting an estimate without its standard error and sample size, or using `ddof=0` for small samples.
- Using $s/\sqrt N$ for Markov chain output, which treats correlated samples as independent and understates the error.
- Importance sampling with a proposal whose tails are lighter than the target's, which makes the variance infinite.

@quiz num
prompt: A Metropolis sampler targets $\pi(x)\propto e^{-x^2/2}$ with a symmetric proposal. The current state is $x=1$ and the proposal is $y=2$. What is the acceptance probability? Give it to four decimals.
answer: e^(-3/2)
check: min(1.0, math.exp(-2.0**2 / 2) / math.exp(-1.0**2 / 2))
tol: 0.00005
hint: With a symmetric proposal the acceptance probability is $\min\{1,\pi(y)/\pi(x)\}$.
hint: The normalizing constant cancels in the ratio.
solution: $\pi(y)/\pi(x)=e^{-2}/e^{-1/2}=e^{-3/2}\approx0.2231$. Since this is less than $1$, it is the acceptance probability.

@quiz self
prompt: Write a function `mc_integral(f, a, b, N, rng)` that estimates $\int_a^bf(x)\,dx$ with uniform sampling and returns the estimate and its standard error. Then describe a replicate experiment, using independent streams, that checks the reported standard error is honest.
hint: The estimator is $(b-a)$ times the sample mean of $f$; the standard error scales by the same factor.
hint: In the check, compare the standard deviation of many estimates with the average reported standard error.
solution: Model code:

```python
import numpy as np

def mc_integral(f, a, b, N, rng):
    x = rng.uniform(a, b, N)
    y = f(x)
    return (b - a) * y.mean(), (b - a) * y.std(ddof=1) / np.sqrt(N)

def check_se(f, a, b, N, reps=200, seed=1):
    streams = [np.random.default_rng(s) for s in np.random.SeedSequence(seed).spawn(reps)]
    res = np.array([mc_integral(f, a, b, N, r) for r in streams])
    return res[:, 0].std(ddof=1), res[:, 1].mean()
```
If the standard errors are honest, the first returned number (the empirical spread of the estimates) is close to the second (the mean reported SE), within about $1/\sqrt{2\,\text{reps}}\approx5\%$. A large mismatch signals correlated samples, a bug, or heavy tails.

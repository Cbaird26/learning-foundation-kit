@article
Mechanics describes motion with numbers, and almost every physical quantity carries a unit (pure ratios are the exception). This lesson fixes the units we use, shows how to test a formula before trusting it, and introduces the vectors that describe displacement, velocity and force.

### SI units

We use three base units: length in metres (m), mass in kilograms (kg) and time in seconds (s). Every other mechanical unit is built from them:

| Quantity | Unit | In base units |
|---|---|---|
| velocity | m/s | m s$^{-1}$ |
| acceleration | m/s$^2$ | m s$^{-2}$ |
| force | newton (N) | kg m s$^{-2}$ |
| energy | joule (J) | kg m$^2$ s$^{-2}$ |
| power | watt (W) | kg m$^2$ s$^{-3}$ |

### Converting units

Multiply by fractions equal to one so that unwanted units cancel like algebraic symbols:

$$72\ \frac{\text{km}}{\text{h}} \times \frac{1000\ \text{m}}{1\ \text{km}} \times \frac{1\ \text{h}}{3600\ \text{s}} = 20\ \frac{\text{m}}{\text{s}}.$$

### Dimensional analysis

Write $[L]$, $[M]$, $[T]$ for the dimensions of length, mass and time. You can only add or equate quantities with the same dimensions, and the argument of $\sin$, $\exp$ or $\ln$ must be dimensionless. For the pendulum formula $T = 2\pi\sqrt{L/g}$, the ratio $L/g$ has dimensions $[L]/([L][T]^{-2}) = [T]^2$, so the square root is a time, as it must be. Dimensions cannot fix pure numbers such as $2\pi$, but they catch many wrong formulas in seconds.

### Measurements carry uncertainty

A measurement is a value with an uncertainty, for example $x = 2.50 \pm 0.05$ m. The **relative uncertainty** is $\delta x / |x| = 0.05/2.50 = 2\%$. Never quote more digits than the uncertainty supports. We develop this properly in weeks 11 and 12.

### Vectors

A **vector** has a magnitude and a direction. In components, $\vec A = (A_x, A_y)$, or $(A_x, A_y, A_z)$ in three dimensions. A vector of magnitude $A$ at angle $\theta$ above the $+x$ axis has

$$A_x = A\cos\theta, \qquad A_y = A\sin\theta, \qquad |\vec A| = \sqrt{A_x^2 + A_y^2}.$$

Vectors add **component by component**: $\vec A + \vec B = (A_x + B_x,\ A_y + B_y)$. The **unit vector** $\hat A = \vec A / |\vec A|$ has length $1$ and points along $\vec A$. The **dot product** is the number

$$\vec A \cdot \vec B = A_xB_x + A_yB_y + A_zB_z = AB\cos\phi,$$

where $\phi$ is the angle between the vectors. It is zero exactly when they are perpendicular, and it will measure work in week 5.

```python
import numpy as np
A = np.array([3.0, 4.0])
B = np.array([7.0, -1.0])
print(A + B, np.linalg.norm(A), A @ B)   # [10.  3.] 5.0 17.0
```

@example
title: Testing a formula with dimensions
problem: A student writes the position of an object moving with constant acceleration as $x = v_0 t + \tfrac{1}{2} a t^2$. Show that this is dimensionally consistent, and show that $x = v_0 + \tfrac{1}{2} a t^2$ is not.
step: The left side is a length, so every term on the right must have dimension $[L]$.
step: First term: $[v_0 t] = ([L]/[T])\,[T] = [L]$. Second term: $[a t^2] = ([L]/[T]^2)\,[T]^2 = [L]$. The factor $\tfrac12$ is dimensionless, so both terms are lengths and the formula passes.
step: In the second formula the term $v_0$ has dimension $[L]/[T]$, which cannot be added to the length $\tfrac12 a t^2$.
step: Conclusion: the first formula can be right, and the second is certainly wrong. Passing the test does not prove a formula correct, but failing it proves the formula is wrong.

@example
title: Adding two displacements
problem: A rover moves $\vec A = (7, 1)$ m and then $\vec B = (-4, 3)$ m. Find the total displacement, its magnitude, and its direction above the $+x$ axis.
step: Add component by component: $\vec R = (7 + (-4),\ 1 + 3) = (3, 4)$ m.
step: Magnitude: $|\vec R| = \sqrt{3^2 + 4^2} = 5$ m.
step: Direction: $\theta = \arctan(4/3) \approx 53.1^\circ$. Both components are positive, so the vector is in the first quadrant and the calculator's value is correct.
step: Check: $|\vec A| + |\vec B| = \sqrt{50} + 5 \approx 12.1$ m, much larger than $5$ m. Magnitudes do not add; only components do.

@mistakes
- Adding the magnitudes of two vectors instead of adding their components.
- Taking $\arctan(A_y/A_x)$ straight from a calculator without checking which quadrant the vector is in.
- Converting only part of a compound unit, for example turning km/h into m/h instead of m/s.
- Quoting a result with more digits than its uncertainty justifies.

prompt: Convert a speed of $72$ km/h to metres per second.
answer: 20
check: 72*1000/3600

hint: Multiply by $\frac{1000\ \text{m}}{1\ \text{km}}$ and by $\frac{1\ \text{h}}{3600\ \text{s}}$ so the kilometres and hours cancel.
solution: $72 \times 1000 / 3600 = 20$ m/s. A handy shortcut: divide km/h by $3.6$ to get m/s.

@practice num
prompt: Find the angle, in degrees, between the vectors $\vec A = (1, 1, 0)$ and $\vec B = (0, 1, 1)$.
answer: 60
check: math.degrees(math.acos(dot([1,1,0],[0,1,1])/(norm([1,1,0])*norm([0,1,1]))))
unit: degrees
tol: 0.01
hint: Use $\vec A\cdot\vec B = |\vec A||\vec B|\cos\phi$ and solve for $\phi$.
hint: $\vec A\cdot\vec B = 1$ and each magnitude is $\sqrt{2}$, so $\cos\phi = 1/2$.
solution: $\vec A\cdot\vec B = 0 + 1 + 0 = 1$ and $|\vec A| = |\vec B| = \sqrt2$, so $\cos\phi = 1/2$ and $\phi = 60^\circ$.

@quiz tuple
prompt: Find the unit vector $\hat A$ pointing in the direction of $\vec A = (3, 4)$, as an ordered pair.
answer: (3/5, 4/5)
check: [3/norm([3,4]), 4/norm([3,4])]
hint: A unit vector is the vector divided by its own magnitude.
hint: The magnitude of $(3, 4)$ is $5$.
solution: $|\vec A| = \sqrt{9 + 16} = 5$, so $\hat A = (3/5, 4/5) = (0.6, 0.8)$, which has length $1$.

@quiz tuple
prompt: A student suspects that the centripetal acceleration of an object depends on its speed $v$ and orbit radius $r$ as $a = v^p r^q$, with no other dimensional quantities. Find the exponents $(p, q)$ that make the dimensions match.
answer: (2, -1)
check: lin([[1,0],[1,1]], [2,1])
hint: Match the powers of $[T]$ and of $[L]$ separately. The acceleration has dimensions $[L][T]^{-2}$.
hint: Time: $-p = -2$. Length: $p + q = 1$.
solution: $[v^p r^q] = [L]^{p+q}[T]^{-p}$. Matching $[L][T]^{-2}$ gives $p = 2$ and $p + q = 1$, so $q = -1$. Hence $a \propto v^2/r$.

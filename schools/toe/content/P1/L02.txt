@article
**Kinematics** describes how things move without asking why. The key idea is that velocity and acceleration are rates of change.

### Position, velocity, acceleration

Along a line, with position $x(t)$,

$$v = \frac{dx}{dt}, \qquad a = \frac{dv}{dt} = \frac{d^2x}{dt^2}.$$

Going the other way, $v(t) = v(0) + \int_0^t a\,dt'$ and $x(t) = x(0) + \int_0^t v\,dt'$. On an $x$–$t$ graph the velocity is the slope; on a $v$–$t$ graph the acceleration is the slope and the displacement is the signed area.

### Constant acceleration

When $a$ does not change with time, integration gives three equations:

$$v = v_0 + at, \qquad x = x_0 + v_0 t + \tfrac12 a t^2, \qquad v^2 = v_0^2 + 2a(x - x_0).$$

They hold **only** for constant $a$. Before using them, choose the positive direction and keep every sign consistent. Free fall near Earth's surface has $a = -g = -9.8\ \text{m/s}^2$ with up positive. That is true while the object rises, at the top, and while it falls.

### Projectiles

In two dimensions the components are independent. Ignoring air, $a_x = 0$ and $a_y = -g$, so

$$x = x_0 + v_{0x}t, \qquad y = y_0 + v_{0y}t - \tfrac12 g t^2.$$

For launch speed $v_0$ at angle $\theta$ above the horizontal, $v_{0x} = v_0\cos\theta$ and $v_{0y} = v_0\sin\theta$. If the projectile lands at its launch height, the flight time is $2v_{0y}/g$ and the range is $R = v_0^2\sin 2\theta / g$. The time is shared by both components, which is why you solve the vertical motion first and then use that time horizontally.

### Plotting a trajectory and estimating errors

With supplied or measured positions at equal time steps $\Delta t$, a second difference estimates acceleration:

$$a \approx \frac{y_{i+1} - 2y_i + y_{i-1}}{\Delta t^2}.$$

```python
import numpy as np
import matplotlib.pyplot as plt

t = np.array([0.0, 0.1, 0.2, 0.3, 0.4])
y = np.array([1.000, 0.951, 0.804, 0.559, 0.216])   # metres, supplied data
dy = 0.005                                          # reading uncertainty, m

a_est = (y[2:] - 2*y[1:-1] + y[:-2]) / 0.1**2
print(a_est)                                        # values near -9.8

plt.errorbar(t, y, yerr=dy, fmt="o")
plt.xlabel("t (s)")
plt.ylabel("y (m)")
plt.show()
```

Each second difference combines three readings with weights $1, -2, 1$, so independent reading errors add in quadrature: $\delta a \approx \sqrt{6}\,\delta y/\Delta t^2$. With $\delta y = 0.005$ m and $\Delta t = 0.1$ s that is about $1.2\ \text{m/s}^2$. Dividing by a small $\Delta t^2$ magnifies noise, so a single second difference is a weak estimate; fitting a curve to all the points is better.

@example
title: A stone thrown down from a bridge
problem: A stone is thrown straight down at $4.9$ m/s from a bridge $29.4$ m above the water. Take $g = 9.8\ \text{m/s}^2$. How long does it take to hit the water, and how fast is it moving then?
step: Choose down as positive, so $a = +9.8\ \text{m/s}^2$, $v_0 = 4.9$ m/s and the displacement is $29.4$ m.
step: Use $x = v_0 t + \tfrac12 a t^2$: $29.4 = 4.9t + 4.9t^2$. Divide by $4.9$: $t^2 + t - 6 = 0$.
step: Factor: $(t + 3)(t - 2) = 0$. The root $t = -3$ s is before the throw, so $t = 2$ s.
step: Speed at impact: $v = v_0 + at = 4.9 + 9.8(2) = 24.5$ m/s.
step: Check with $v^2 = v_0^2 + 2ax = 24.01 + 576.24 = 600.25$, and $\sqrt{600.25} = 24.5$. The two methods agree.

@example
title: A ball kicked horizontally off a platform
problem: A ball leaves a platform $19.6$ m high moving horizontally at $15$ m/s. Take $g = 9.8\ \text{m/s}^2$. Find the fall time, the horizontal distance travelled, and the speed on landing.
step: Vertical motion: it starts with $v_{0y} = 0$, so $19.6 = \tfrac12(9.8)t^2 = 4.9t^2$ and $t = 2$ s.
step: Horizontal motion has no acceleration: $x = v_{0x}t = 15 \times 2 = 30$ m.
step: Velocity components at landing: $v_x = 15$ m/s and $v_y = -g t = -19.6$ m/s.
step: Speed: $\sqrt{15^2 + 19.6^2} = \sqrt{609.16} \approx 24.7$ m/s, directed below the horizontal.

@mistakes
- Using the constant-acceleration equations when the acceleration changes with time.
- Saying the acceleration is zero at the top of a throw because the velocity is zero there; it is still $-g$.
- Taking up as positive for the velocity but writing $+g$ in the equation.
- Using $R = v_0^2\sin 2\theta/g$ when the launch and landing heights differ.

@practice self
prompt: A student reads a ball's height $y$ from video every $\Delta t = 0.05$ s, each reading good to $\pm 0.01$ m. Write a short Python script that plots $y$ against $t$ with error bars and computes the second-difference acceleration estimates. Then estimate the uncertainty of one estimate and say what that implies.
hint: Slice the array three ways, `y[2:]`, `y[1:-1]` and `y[:-2]`, so that the second difference is computed for all interior points at once.
hint: Each estimate combines three readings with weights $1, -2, 1$, so $\delta a \approx \sqrt{6}\,\delta y/\Delta t^2$.
solution: ```python
import numpy as np
import matplotlib.pyplot as plt

dt, dy = 0.05, 0.01
t = np.arange(len(y)) * dt          # y is the array of readings (m)
a = (y[2:] - 2*y[1:-1] + y[:-2]) / dt**2
plt.errorbar(t, y, yerr=dy, fmt="o")
plt.xlabel("t (s)"); plt.ylabel("y (m)")
plt.show()
print(a, np.sqrt(6)*dy/dt**2)
```
Each estimate has $\delta a \approx \sqrt{6}\,(0.01)/(0.05)^2 \approx 9.8\ \text{m/s}^2$, as large as $g$ itself. A single second difference from these readings is nearly useless; fit a parabola to all the points, or use a longer time step.
rubric: The second difference uses correct slices so that the three arrays have equal length.
rubric: The plot uses error bars and labelled axes with units.
rubric: The uncertainty estimate uses $\sqrt{6}\,\delta y/\Delta t^2$ (or an equivalent quadrature argument) and gives roughly $10\ \text{m/s}^2$.
rubric: The conclusion says that the estimates are too noisy to use singly and suggests fitting or averaging.

@quiz num
prompt: A ball is kicked from level ground at $20$ m/s at $30^\circ$ above the horizontal. Take $g = 9.8\ \text{m/s}^2$ and ignore air resistance. How far away does it land? Round to one decimal place.
answer: 35.3
check: 20*cos(pi/6)*root(lambda t: 20*sin(pi/6)*t - 0.5*9.8*t**2, 0.1, 10)
unit: m
tol: 1%
hint: Find the flight time first: the height returns to zero when $v_{0y}t - \tfrac12 g t^2 = 0$.
hint: With $v_{0y} = 10$ m/s, the flight time is $2v_{0y}/g \approx 2.04$ s. Then multiply by $v_{0x}$.
solution: $v_{0x} = 20\cos30^\circ \approx 17.3205$ m/s and $v_{0y} = 10$ m/s. The flight time is $2(10)/9.8 \approx 2.0408$ s, so the range is $17.3205 \times 2.0408 \approx 35.348$, which rounds to $35.3$ m.

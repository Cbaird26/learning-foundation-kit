@article
Two random variables measured on the same experiment have a **joint distribution**, which records not just how each behaves alone but how they behave together.

### Discrete case

The **joint pmf** is $p(x, y) = P(X = x,\ Y = y)$, with $p \ge 0$ and $\sum_{x,y} p(x, y) = 1$. Summing out one variable gives a **marginal**; dividing a joint probability by a marginal gives a **conditional**:

$$p_X(x) = \sum_y p(x, y), \qquad p_{Y \mid X}(y \mid x) = \frac{p(x, y)}{p_X(x)}.$$

### Continuous case

A **joint density** $f(x, y) \ge 0$ with total integral $1$ assigns probabilities by volume under its surface:

$$P((X, Y) \in A) = \iint_A f(x, y)\,dx\,dy.$$

Marginals integrate out the other variable, $f_X(x) = \int f(x, y)\,dy$, and conditionals divide by a marginal, $f_{Y \mid X}(y \mid x) = f(x, y)/f_X(x)$. When the region $A$ is not a rectangle, the inner limits depend on the outer variable, so sketch the region before you write the integral.

### Independence

$X$ and $Y$ are **independent** when knowing one tells you nothing about the other:

$$p(x, y) = p_X(x)\,p_Y(y) \ \text{ for all } x, y \qquad \text{or} \qquad f(x, y) = f_X(x)\,f_Y(y).$$

One failing pair $(x, y)$ is enough to prove dependence; proving independence requires the product rule everywhere. For densities, independence needs a rectangular support and a formula that factors into a function of $x$ times a function of $y$. A density equal to $2$ on the triangle $0 \le y \le x \le 1$ cannot be independent: $Y > \frac{1}{2}$ forces $X > \frac{1}{2}$.

### Functions of two variables

$$E[g(X, Y)] = \sum_{x,y} g(x, y)\,p(x, y) \qquad \text{or} \qquad \iint g(x, y)\,f(x, y)\,dx\,dy.$$

Always $E[X + Y] = E[X] + E[Y]$. But $E[XY] = E[X]\,E[Y]$ is guaranteed only for independent variables, a fact that the next lesson turns into a measurement.

Marginals do not determine the joint distribution. Two quite different joint models can have identical marginals, which is why you always need the joint table or density, not just each variable's distribution.

@example
title: Marginals, conditionals and independence from a joint pmf
problem: The joint pmf of $X \in \{0, 1\}$ and $Y \in \{0, 1, 2\}$ is $p(0,0) = 0.10$, $p(0,1) = 0.20$, $p(0,2) = 0.10$, $p(1,0) = 0.20$, $p(1,1) = 0.10$, $p(1,2) = 0.30$. Find both marginals and the conditional distribution of $Y$ given $X = 1$, then decide whether $X$ and $Y$ are independent.
step: Check validity: $0.10 + 0.20 + 0.10 + 0.20 + 0.10 + 0.30 = 1.00$.
step: Marginals: $p_X(0) = 0.40$ and $p_X(1) = 0.60$; $p_Y(0) = 0.30$, $p_Y(1) = 0.30$ and $p_Y(2) = 0.40$.
step: Conditional given $X = 1$: divide the $x = 1$ row by $p_X(1) = 0.60$. This gives $p(y \mid 1) = \frac{1}{3}, \frac{1}{6}, \frac{1}{2}$ for $y = 0, 1, 2$, which add to $1$.
step: Independence would require $p(0,0) = p_X(0)\,p_Y(0) = 0.4 \cdot 0.3 = 0.12$, but $p(0,0) = 0.10$. One mismatch is enough: the variables are dependent.
step: Expectations: $E[X] = 0.6$, $E[Y] = 0(0.3) + 1(0.3) + 2(0.4) = 1.1$, so $E[X + Y] = 1.7$. Also $E[XY] = 1 \cdot 1 \cdot 0.10 + 1 \cdot 2 \cdot 0.30 = 0.70$, which differs from $E[X]E[Y] = 0.66$.

@example
title: A joint density on the unit square
problem: The joint density of $(X, Y)$ is $f(x, y) = c\,(x + y)$ on $0 \le x, y \le 1$ and $0$ elsewhere. Find $c$, the marginal density of $X$ and $P(X + Y \le 1)$, and decide whether $X$ and $Y$ are independent.
step: Normalize: $\int_0^1\!\int_0^1 (x + y)\,dy\,dx = \int_0^1 \left(x + \tfrac{1}{2}\right) dx = \tfrac{1}{2} + \tfrac{1}{2} = 1$, so $c = 1$.
step: Marginal of $X$: $f_X(x) = \int_0^1 (x + y)\,dy = x + \tfrac{1}{2}$ for $0 \le x \le 1$. By symmetry $f_Y(y) = y + \tfrac{1}{2}$.
step: The region $x + y \le 1$ is a triangle, so the inner limit depends on $x$: $P(X + Y \le 1) = \int_0^1\!\int_0^{1-x} (x + y)\,dy\,dx$.
step: The inner integral is $x(1 - x) + \tfrac{(1-x)^2}{2} = \tfrac{1}{2} - \tfrac{x^2}{2}$. Then $\int_0^1 \left(\tfrac{1}{2} - \tfrac{x^2}{2}\right) dx = \tfrac{1}{2} - \tfrac{1}{6} = \tfrac{1}{3}$.
step: Independence would need $f_X(x)f_Y(y) = (x + \tfrac12)(y + \tfrac12)$ to equal $x + y$. At $x = y = 0$ the product is $\tfrac14$ but $f(0, 0) = 0$, so $X$ and $Y$ are dependent.

@mistakes
- Declaring independence because the marginals look alike, or because the product rule holds at a few points. It must hold at every pair.
- Integrating over a rectangle when the region is a triangle or another shape; write the inner limits as functions of the outer variable.
- Dividing by the wrong marginal when conditioning: $p_{Y \mid X}$ divides by $p_X$, not by $p_Y$.
- Assuming that the marginals determine the joint distribution. They do not.

@practice num
prompt: The joint pmf of two $0$-$1$ variables is $p(0,0) = 0.1$, $p(0,1) = 0.2$, $p(1,0) = 0.3$ and $p(1,1) = 0.4$. Find the marginal probability $P(Y = 1)$.
answer: 0.6
check: sum(p for x, y, p in [(0, 0, 0.1), (0, 1, 0.2), (1, 0, 0.3), (1, 1, 0.4)] if y == 1)
hint: Add the joint probabilities over all values of $x$ for which $y = 1$.
solution: $P(Y = 1) = p(0, 1) + p(1, 1) = 0.2 + 0.4 = 0.6$.

@practice num
prompt: A joint pmf has $p(x, y) = c\,(x + y)$ for $x, y \in \{0, 1, 2\}$ (nine points) and $0$ elsewhere. Find $c$.
answer: 1/18
check: 1 / sum(x + y for x in range(3) for y in range(3))
hint: The nine probabilities must add to $1$.
hint: Compute $\sum_{x, y}(x + y)$ over the nine points, then set $c$ times that sum equal to $1$.
solution: Each value of $x$ appears with three values of $y$, so $\sum (x + y) = 3(0 + 1 + 2) + 3(0 + 1 + 2) = 18$. Hence $18c = 1$ and $c = \frac{1}{18}$.

@practice ms
prompt: Which of these joint models describe independent random variables $X$ and $Y$? Select all that apply.
choice*: $p(x, y) = \frac{1}{4}$ for each $(x, y) \in \{0, 1\} \times \{0, 1\}$.
choice: $f(x, y) = 2$ on the triangle $0 \le y \le x \le 1$, and $0$ elsewhere.
choice*: $f(x, y) = 4xy$ on the unit square $0 \le x, y \le 1$, and $0$ elsewhere.
choice: $f(x, y) = x + y$ on the unit square $0 \le x, y \le 1$, and $0$ elsewhere.
hint: Independence needs the joint to equal the product of the marginals, which for densities means a rectangular support and a formula that factors.
solution: The model $p(x, y) = \frac14$ on $\{0, 1\} \times \{0, 1\}$ has both marginals equal to $(\frac12, \frac12)$ and $\frac12 \cdot \frac12 = \frac14$, so it is independent. The triangle is not a rectangle ($Y > \frac12$ forces $X > \frac12$). The density $4xy = (2x)(2y)$ factors into two valid densities on $[0, 1]$. For $x + y$, the product $(x + \frac12)(y + \frac12)$ is not $x + y$.

@practice num
prompt: A joint pmf is $p(x, y) = \frac{x + y}{21}$ for $x \in \{1, 2\}$ and $y \in \{1, 2, 3\}$. Find $E[XY]$ as an exact fraction.
answer: 24/7
check: sum(x * y * (x + y) / 21 for x in range(1, 3) for y in range(1, 4))
hint: Use $E[g(X, Y)] = \sum g(x, y)\,p(x, y)$ with $g(x, y) = xy$.
hint: List the six terms $xy\,(x + y)$ and add them before dividing by $21$.
solution: The six values of $xy(x + y)$ are $2, 6, 12, 6, 16, 30$, which add to $72$. So $E[XY] = \frac{72}{21} = \frac{24}{7}$.

@practice num
prompt: $X$ and $Y$ are independent with joint density $f(x, y) = e^{-(x + y)}$ for $x, y \ge 0$. Find $P(X + Y \le 1)$. Give an exact answer.
answer: 1 - 2/e
check: quad2(lambda x, y: exp(-(x + y)), 0, 1, 0, lambda x: 1 - x)
hint: The region $x + y \le 1$ with $x, y \ge 0$ is a triangle. Integrate $y$ from $0$ to $1 - x$, then $x$ from $0$ to $1$.
hint: The inner integral is $e^{-x}\left(1 - e^{-(1 - x)}\right) = e^{-x} - e^{-1}$.
solution: $P = \int_0^1 \left(e^{-x} - e^{-1}\right) dx = \left(1 - e^{-1}\right) - e^{-1} = 1 - \frac{2}{e} \approx 0.2642$.

@quiz num
prompt: A joint pmf is $p(x, y) = \frac{x + y + 1}{15}$ for $x \in \{0, 1, 2\}$ and $y \in \{0, 1\}$. Find the conditional probability $P(X = 2 \mid Y = 1)$ as an exact fraction.
answer: 4/9
check: (2 + 1 + 1) / sum(x + 1 + 1 for x in range(3))
hint: The conditional probability is $p(2, 1)$ divided by the marginal $p_Y(1)$.
hint: Find $p_Y(1)$ by adding $p(x, 1)$ over $x = 0, 1, 2$.
solution: $p(2, 1) = \frac{4}{15}$ and $p_Y(1) = \frac{2 + 3 + 4}{15} = \frac{9}{15}$. So $P(X = 2 \mid Y = 1) = \frac{4}{9}$.

vars: x
lead: $f_X(x) =$
answer: 1.5*x^2 + 0.5
check: lambda x: quad(lambda y: x**2 + y**2, 0, 1) / quad2(lambda u, v: u**2 + v**2, 0, 1, 0, 1)
domain: x: 0..1
hint: Find $c$ first: $\int_0^1\!\int_0^1 (x^2 + y^2)\,dy\,dx = \frac{2}{3}$.

solution: The double integral of $x^2 + y^2$ is $\frac{1}{3} + \frac{1}{3} = \frac{2}{3}$, so $c = \frac{3}{2}$. Then $f_X(x) = \frac{3}{2}\left(x^2 + \frac{1}{3}\right) = \frac{3}{2}x^2 + \frac{1}{2}$.

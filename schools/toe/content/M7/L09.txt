@article
Suppose you observe iid data $X_1, \dots, X_n$ from a model with an unknown parameter $\theta$. An **estimator** $\hat\theta = g(X_1, \dots, X_n)$ is a *rule*, so it is a random variable with its own sampling distribution. An **estimate** is the number the rule gives for the data you actually have.

### Two ways to build estimators

**Method of moments.** Equate population moments to sample moments and solve for the parameter. For an exponential model $E[X] = 1/\lambda$, so set $1/\lambda = \bar x$ and get $\hat\lambda = 1/\bar x$. For Uniform$(0, \theta)$, $E[X] = \theta/2$, so $\hat\theta = 2\bar x$.

**Maximum likelihood.** The **likelihood** is the joint density (or pmf) of the observed data, viewed as a function of $\theta$:

$$L(\theta) = \prod_{i=1}^n f(x_i;\ \theta), \qquad \ell(\theta) = \ln L(\theta) = \sum_{i=1}^n \ln f(x_i;\ \theta).$$

The **maximum likelihood estimate** (MLE) is the $\theta$ that makes the observed data most probable. Since $\ln$ is increasing, maximize $\ell$ instead of $L$: solve $\ell'(\theta) = 0$ and check that you found a maximum. For $k$ successes in $n$ independent success-or-failure trials, $\ell(p) = k\ln p + (n - k)\ln(1 - p)$ gives $\hat p = k/n$. Note that the likelihood is a function of $\theta$ for fixed data; it is not a probability distribution for $\theta$.

### How good is an estimator?

Define the **bias** and the **mean squared error** (MSE):

$$\text{Bias}(\hat\theta) = E[\hat\theta] - \theta, \qquad \text{MSE}(\hat\theta) = E[(\hat\theta - \theta)^2] = \operatorname{Var}(\hat\theta) + \text{Bias}(\hat\theta)^2.$$

An estimator is **unbiased** if its bias is $0$ for every $\theta$, and **consistent** if $\hat\theta \to \theta$ in probability as $n \to \infty$. Unbiasedness is not the only goal: a slightly biased estimator with much smaller variance can have the smaller MSE.

Familiar cases: $\bar X$ is unbiased for $\mu$; $S^2$ (divisor $n - 1$) is unbiased for $\sigma^2$; the normal MLE of $\sigma^2$ divides by $n$, so it is biased low by the factor $\frac{n-1}{n}$, yet still consistent.

### Simulating the trade-off

```python
import numpy as np
rng = np.random.default_rng(3)
theta, n = 10.0, 10
x = rng.uniform(0, theta, size=(100000, n))
for name, est in (("2*mean", 2 * x.mean(axis=1)), ("max", x.max(axis=1))):
    print(name, round(est.mean(), 2), round(((est - theta)**2).mean(), 2))
```

The first estimator is unbiased (mean near $10$, MSE near $3.33$). The maximum is biased low (mean near $9.09$) yet has a much smaller MSE (near $1.52$). The second worked example explains why.

@example
title: Maximum likelihood for an exponential rate
problem: Four waiting times are $0.5,\ 1.5,\ 2.0,\ 1.0$ hours, modeled as iid exponential with rate $\lambda$. Find the maximum likelihood estimate of $\lambda$.
step: The density is $f(x;\lambda) = \lambda e^{-\lambda x}$, so the likelihood is $L(\lambda) = \prod_i \lambda e^{-\lambda x_i} = \lambda^n e^{-\lambda \sum x_i}$.
step: Take logs: $\ell(\lambda) = n\ln\lambda - \lambda\sum x_i$.
step: Differentiate and set to zero: $\ell'(\lambda) = \frac{n}{\lambda} - \sum x_i = 0$, so $\hat\lambda = \dfrac{n}{\sum x_i} = \dfrac{1}{\bar x}$.
step: Check that it is a maximum: $\ell''(\lambda) = -\frac{n}{\lambda^2} < 0$ for all $\lambda > 0$.
step: Here $n = 4$ and $\sum x_i = 5$, so $\hat\lambda = 0.8$ per hour. This agrees with the method of moments estimate $1/\bar x$.

@example
title: Bias versus variance for a uniform upper limit
problem: A sample of size $n = 10$ is drawn from Uniform$(0, \theta)$. Compare $\hat\theta_1 = 2\bar X$ (method of moments) with $\hat\theta_2 = \max(X_i)$ (the MLE) by bias and MSE, and then rescale $\hat\theta_2$ to remove its bias.
step: The likelihood is $\theta^{-n}$ for $\theta \ge \max x_i$ and $0$ otherwise. It decreases in $\theta$, so it is maximized at the smallest allowed value, $\hat\theta_2 = \max x_i$. Calculus does not apply here because the maximum is on the boundary.
step: For $\hat\theta_1$: $E[2\bar X] = \theta$, so it is unbiased. Since $\operatorname{Var}(X_i) = \theta^2/12$, we get $\operatorname{Var}(2\bar X) = \frac{4\theta^2}{12n} = \frac{\theta^2}{3n}$, and $\text{MSE} = \frac{\theta^2}{30}$ for $n = 10$.
step: For $\hat\theta_2$: $E[\max] = \frac{n}{n+1}\theta$, so the bias is $-\frac{\theta}{n+1}$. Also $\operatorname{Var}(\max) = \frac{n\theta^2}{(n+1)^2(n+2)}$. Adding the squared bias gives $\text{MSE} = \frac{2\theta^2}{(n+1)(n+2)} = \frac{\theta^2}{66}$ for $n = 10$.
step: So $\text{MSE}(\hat\theta_2) \approx 0.0152\,\theta^2$ is less than half of $\text{MSE}(\hat\theta_1) \approx 0.0333\,\theta^2$, even though $\hat\theta_2$ is biased. The variance saved outweighs the squared bias.
step: Removing the bias with $\hat\theta_3 = \frac{n+1}{n}\max(X_i)$ gives variance $\frac{\theta^2}{n(n+2)} = \frac{\theta^2}{120}$ for $n = 10$, the best of the three. Its MSE shrinks like $1/n^2$, while the MSE of $2\bar X$ shrinks only like $1/n$.

@mistakes
- Treating the likelihood as a probability distribution for $\theta$. It is a function of $\theta$ for fixed data and need not integrate to $1$.
- Setting a derivative to zero when the maximum is on the boundary of the allowed values, as in the uniform example, or skipping the check that the stationary point is a maximum.
- Assuming that unbiased always means better. Compare MSE, which includes both variance and squared bias.
- Dividing by $n$ when an unbiased estimate of the variance is wanted; use $n - 1$.

@practice num
prompt: In $20$ independent trials you observe $7$ successes. Find the maximum likelihood estimate of the success probability $p$.
answer: 0.35
check: root(lambda p: 7 / p - 13 / (1 - p), 0.01, 0.99)
hint: The log-likelihood is $\ell(p) = 7\ln p + 13\ln(1 - p)$. Set $\ell'(p) = 0$.
solution: $\ell'(p) = \frac{7}{p} - \frac{13}{1 - p} = 0$ gives $7(1 - p) = 13p$, so $p = \frac{7}{20} = 0.35$, the sample proportion.

choice: It is biased upward, because $\bar X$ is estimated from the same data.
choice: It is not consistent, because it is biased.
hint: Estimating $\mu$ by $\bar X$ makes the deviations slightly smaller than the deviations from the true $\mu$.
solution: Deviations from $\bar X$ are on average smaller than deviations from $\mu$, so dividing by $n$ gives a value too small by the factor $\frac{n-1}{n}$. The bias vanishes as $n \to \infty$, so the estimator is still consistent. Dividing by $n - 1$ removes the bias.

@practice num
prompt: Let $X_1, \dots, X_4$ be iid Uniform$(0, 10)$ and let $M = \max(X_1, \dots, X_4)$. Find $E[M]$, and notice how it compares with the upper limit $10$.
answer: 8
check: quad(lambda m: 1 - (m / 10)**4, 0, 10)
hint: Find the cdf of $M$ first: $M \le m$ exactly when all four observations are at most $m$.
hint: $P(M \le m) = (m/10)^4$ on $[0, 10]$. Differentiate to get the density, or use $E[M] = \int_0^{10} P(M > m)\,dm$.
solution: $P(M \le m) = (m/10)^4$, so the density is $\frac{4m^3}{10^4}$ and $E[M] = \int_0^{10} m \cdot \frac{4m^3}{10^4}\,dm = \frac{4}{10^4}\cdot\frac{10^5}{5} = 8$. In general $E[\max] = \frac{n}{n+1}\theta$, so the maximum is biased low.

@quiz num
prompt: Estimator A is unbiased with variance $4$. Estimator B has bias $-1$ and variance $2$. Find $\text{MSE}(B) - \text{MSE}(A)$.
answer: -1
check: (2 + (-1)**2) - (4 + 0**2)
hint: Use $\text{MSE} = \text{variance} + \text{bias}^2$ for each estimator.
solution: $\text{MSE}(A) = 4 + 0 = 4$ and $\text{MSE}(B) = 2 + (-1)^2 = 3$. The difference is $3 - 4 = -1$, so the biased estimator B has the smaller MSE.

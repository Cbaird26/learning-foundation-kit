@article
Systems $A\mathbf{x} = \mathbf{b}$ naturally live in spaces of vectors. This week names those spaces, so that "does a solution exist, and what do all the solutions look like?" becomes a question about geometry.

### Vector spaces

A **vector space** is a set of objects that can be added and multiplied by numbers, obeying the usual algebra rules: addition is commutative and associative, there is a zero vector, every vector has a negative, and scaling distributes over addition. What matters most is that sums and scalar multiples **stay inside the set**. Examples: $\mathbb{R}^n$, the $m \times n$ matrices, the polynomials of degree at most $2$, the continuous functions on $[0, 1]$.

### Subspaces

A **subspace** is a subset of a vector space that is itself a vector space. To test a subset $S$ you need three checks:

1. the zero vector $\mathbf{0}$ is in $S$;
2. if $\mathbf{u}$ and $\mathbf{v}$ are in $S$, then $\mathbf{u} + \mathbf{v}$ is in $S$;
3. if $\mathbf{u}$ is in $S$ and $c$ is any number, then $c\mathbf{u}$ is in $S$.

In $\mathbb{R}^2$ the subspaces are the origin alone, the lines through the origin, and the whole plane. A line that misses the origin fails check 1. The first quadrant passes checks 1 and 2 but fails check 3: multiplying by $-1$ throws a vector out of the quadrant.

### Span

The **span** of $\mathbf{v}_1, \dots, \mathbf{v}_k$ is the set of all linear combinations $c_1\mathbf{v}_1 + \cdots + c_k\mathbf{v}_k$. It is always a subspace, and it is the smallest subspace containing those vectors.

### The two subspaces of a matrix

Let $A$ be an $m \times n$ matrix.

- The **column space** $C(A)$ is the span of the columns of $A$. It lives in $\mathbb{R}^m$. Because $A\mathbf{x}$ is a combination of the columns, $A\mathbf{x} = \mathbf{b}$ is solvable **exactly when** $\mathbf{b}$ is in $C(A)$.
- The **null space** $N(A)$ is the set of all $\mathbf{x}$ with $A\mathbf{x} = \mathbf{0}$. It lives in $\mathbb{R}^n$. It is a subspace because $A(\mathbf{x} + \mathbf{y}) = A\mathbf{x} + A\mathbf{y} = \mathbf{0}$ and $A(c\mathbf{x}) = cA\mathbf{x} = \mathbf{0}$.

The solutions of $A\mathbf{x} = \mathbf{b}$ with $\mathbf{b} \neq \mathbf{0}$ do **not** form a subspace, since they miss $\mathbf{0}$. They form a shifted copy of the null space: if $\mathbf{x}_p$ is one solution, then every solution is $\mathbf{x}_p + \mathbf{n}$ with $\mathbf{n}$ in $N(A)$. So a solution is unique exactly when $N(A) = \{\mathbf{0}\}$.

```python
import numpy as np
A = np.array([[1, 0], [0, 1], [1, 1]])
b = np.array([2, 3, 5])
x = np.linalg.lstsq(A, b, rcond=None)[0]
print(x, np.allclose(A @ x, b))   # [2. 3.] True, so b is in C(A)
```

@example
title: Testing a subset
problem: Is $S = \{(x, y, z) : x + y + z = 0\}$ a subspace of $\mathbb{R}^3$?
step: Check 1: $0 + 0 + 0 = 0$, so $\mathbf{0}$ is in $S$.
step: Check 2: take $\mathbf{u} = (u_1, u_2, u_3)$ and $\mathbf{v} = (v_1, v_2, v_3)$ in $S$. The coordinates of $\mathbf{u} + \mathbf{v}$ add up to $(u_1 + u_2 + u_3) + (v_1 + v_2 + v_3) = 0 + 0 = 0$, so $\mathbf{u} + \mathbf{v}$ is in $S$.
step: Check 3: the coordinates of $c\mathbf{u}$ add up to $c(u_1 + u_2 + u_3) = c \cdot 0 = 0$, so $c\mathbf{u}$ is in $S$.
step: All three checks pass, so $S$ is a subspace. It is the null space of the $1 \times 3$ matrix $[1\ 1\ 1]$, a plane through the origin. By contrast, the plane $x + y + z = 1$ fails check 1.

@example
title: Is a vector in the column space?
problem: Let $A = \begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix}$. Decide whether $(2, 3, 5)$ and $(2, 3, 4)$ are in $C(A)$.
step: A vector $\mathbf{b}$ is in $C(A)$ exactly when $A\mathbf{x} = \mathbf{b}$ has a solution. Row reduce $[A \mid \mathbf{b}]$ with $\mathbf{b} = (2, 3, 5)$: rows $[1\ 0 \mid 2]$, $[0\ 1 \mid 3]$, $[1\ 1 \mid 5]$.
step: Apply $R_3 \to R_3 - R_1 - R_2$. The last row becomes $[0\ 0 \mid 0]$, so the system is consistent with $\mathbf{x} = (2, 3)$. Indeed $2(1, 0, 1) + 3(0, 1, 1) = (2, 3, 5)$.
step: For $\mathbf{b} = (2, 3, 4)$ the same operation gives the last row $[0\ 0 \mid -1]$, which says $0 = -1$. There is no solution, so $(2, 3, 4)$ is not in $C(A)$.
step: Geometrically, $C(A)$ is the plane in $\mathbb{R}^3$ spanned by the two columns. The first vector lies on it and the second does not.

@mistakes
- Forgetting the zero-vector check. A plane or line that does not pass through the origin is never a subspace.
- "Verifying" closure with a couple of numerical examples. A proof must work for arbitrary vectors and scalars.
- Mixing up where the spaces live: for an $m \times n$ matrix, $C(A)$ is in $\mathbb{R}^m$ but $N(A)$ is in $\mathbb{R}^n$.

@practice self
prompt: Prove that the null space $N(A)$ of an $m \times n$ matrix $A$ is a subspace of $\mathbb{R}^n$.
hint: Use the three-part subspace test.
hint: For closure, compute $A(\mathbf{x} + \mathbf{y})$ and $A(c\mathbf{x})$ using the rules of matrix multiplication.
solution: $N(A)$ is a subset of $\mathbb{R}^n$ because it consists of vectors $\mathbf{x}$ with $n$ entries. First, $A\mathbf{0} = \mathbf{0}$, so $\mathbf{0}$ is in $N(A)$. Second, if $A\mathbf{x} = \mathbf{0}$ and $A\mathbf{y} = \mathbf{0}$, then $A(\mathbf{x} + \mathbf{y}) = A\mathbf{x} + A\mathbf{y} = \mathbf{0}$. Third, if $A\mathbf{x} = \mathbf{0}$ and $c$ is a number, then $A(c\mathbf{x}) = cA\mathbf{x} = \mathbf{0}$. All three checks pass.
rubric: States that $N(A)$ is a subset of $\mathbb{R}^n$ and shows that $\mathbf{0}$ is in it.
rubric: Proves closure under addition for arbitrary $\mathbf{x}, \mathbf{y}$ in $N(A)$ using $A(\mathbf{x}+\mathbf{y}) = A\mathbf{x} + A\mathbf{y}$.
rubric: Proves closure under scalar multiplication for an arbitrary scalar $c$, not for a specific example.

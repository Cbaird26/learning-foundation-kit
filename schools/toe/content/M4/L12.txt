@article
Eigendecompositions work for square, diagonalizable matrices. The **singular value decomposition** (SVD) works for **every** matrix, rectangular or not, and its factors are always orthogonal.

### The decomposition

Every real $m \times n$ matrix can be written
$$A = U\Sigma V^T,$$
where $U$ ($m \times m$) and $V$ ($n \times n$) are orthogonal and $\Sigma$ is $m \times n$ with nonnegative numbers $\sigma_1 \ge \sigma_2 \ge \cdots \ge 0$ on its diagonal. These are the **singular values**.

### Where it comes from

The matrix $A^TA$ is symmetric and positive semidefinite, so by last week's theorem it has orthonormal eigenvectors $\mathbf{v}_i$ and eigenvalues $\sigma_i^2 \ge 0$. Those eigenvectors are the columns of $V$. For $\sigma_i > 0$ define $\mathbf{u}_i = A\mathbf{v}_i/\sigma_i$. These are orthonormal too, and
$$A\mathbf{v}_i = \sigma_i\mathbf{u}_i.$$
In words: $A$ sends the orthonormal input directions $\mathbf{v}_i$ to the orthogonal output directions $\mathbf{u}_i$, stretching by $\sigma_i$.

### Geometry and meaning

- $A$ maps the unit sphere to an ellipsoid whose semi-axes are $\sigma_i\mathbf{u}_i$.
- The rank of $A$ is the number of nonzero singular values.
- The largest stretch is $\|A\|_2 = \sigma_1$, and the condition number is $\sigma_1/\sigma_{\min}$. A large condition number warns that solving $A\mathbf{x} = \mathbf{b}$ amplifies errors.
- For square $A$, $\sigma_1\sigma_2\cdots\sigma_n = |\det A|$.
- The first $r$ columns of $V$ span the row space, the rest span $N(A)$; the first $r$ columns of $U$ span $C(A)$, the rest span $N(A^T)$.

### Low-rank approximation

Written as a sum of rank-one pieces, $A = \sigma_1\mathbf{u}_1\mathbf{v}_1^T + \cdots + \sigma_r\mathbf{u}_r\mathbf{v}_r^T$. Keeping only the first $k$ terms gives the best rank-$k$ approximation to $A$, and the 2-norm error is $\sigma_{k+1}$. This is the basis of image compression and principal component analysis.

### Eigendecomposition versus SVD

| | Eigendecomposition $A = PDP^{-1}$ | SVD $A = U\Sigma V^T$ |
|---|---|---|
| Which matrices | square, with $n$ independent eigenvectors | every matrix |
| Factors | $P$ usually not orthogonal | $U$, $V$ always orthogonal |
| Diagonal entries | eigenvalues, possibly negative or complex | singular values, always $\ge 0$ |
| Best for | repeated application: $A^k$ | size and geometry: stretching, rank, approximation |

They agree when $A$ is symmetric positive semidefinite: then $U = V = Q$ and $\Sigma = \Lambda$. For a general symmetric matrix the singular values are $|\lambda_i|$.

```python
import numpy as np
A = np.array([[2., 2.], [-1., 1.]])
U, s, Vt = np.linalg.svd(A)
print(s)                                  # [2.828... 1.414...]
print(np.allclose(U @ np.diag(s) @ Vt, A))   # True
```

@example
title: Computing an SVD
problem: Find the SVD of $A = \begin{bmatrix}2&2\\-1&1\end{bmatrix}$.
step: Form $A^TA = \begin{bmatrix}5&3\\3&5\end{bmatrix}$. Its trace is $10$ and its determinant is $16$, so its eigenvalues are $8$ and $2$.
step: The singular values are $\sigma_1 = \sqrt8 = 2\sqrt2$ and $\sigma_2 = \sqrt2$. Check: $\sigma_1\sigma_2 = 4 = |\det A|$.
step: The unit eigenvectors of $A^TA$ are $\mathbf{v}_1 = \frac{1}{\sqrt2}(1, 1)$ for $8$ and $\mathbf{v}_2 = \frac{1}{\sqrt2}(1, -1)$ for $2$.
step: Compute $\mathbf{u}_i = A\mathbf{v}_i/\sigma_i$. First $A\mathbf{v}_1 = \frac{1}{\sqrt2}(4, 0)$, so $\mathbf{u}_1 = (1, 0)$. Then $A\mathbf{v}_2 = \frac{1}{\sqrt2}(0, -2)$, so $\mathbf{u}_2 = (0, -1)$.
step: Verify the rank-one sum: $2\sqrt2\,\mathbf{u}_1\mathbf{v}_1^T + \sqrt2\,\mathbf{u}_2\mathbf{v}_2^T = 2\begin{bmatrix}1&1\\0&0\end{bmatrix} + \begin{bmatrix}0&0\\-1&1\end{bmatrix} = \begin{bmatrix}2&2\\-1&1\end{bmatrix} = A$.

@example
title: A matrix with an SVD but no eigendecomposition
problem: Compare the eigenvalues and singular values of the shear $A = \begin{bmatrix}1&1\\0&1\end{bmatrix}$.
step: Eigenvalues: the characteristic polynomial is $(\lambda - 1)^2$. The eigenspace $N(A - I)$ is spanned by $(1, 0)$ only, so there is a single independent eigenvector. $A$ is not diagonalizable and has no eigendecomposition.
step: Singular values: $A^TA = \begin{bmatrix}1&1\\1&2\end{bmatrix}$ has trace $3$ and determinant $1$, so its eigenvalues are $\frac{3 \pm \sqrt5}{2}$.
step: Since $\left(\frac{1 \pm \sqrt5}{2}\right)^2 = \frac{3 \pm \sqrt5}{2}$, the singular values are $\sigma_1 = \frac{1 + \sqrt5}{2} \approx 1.618$ and $\sigma_2 = \frac{\sqrt5 - 1}{2} \approx 0.618$. Their product is $1 = \det A$.
step: Interpretation: the SVD always exists. The shear turns the unit circle into an ellipse with semi-axes $1.618$ and $0.618$, which has the same area $\pi$ as the circle. The eigenvalue $1$ alone could not reveal this stretching.

@mistakes
- Treating the singular values as the eigenvalues of $A$. They are the square roots of the eigenvalues of $A^TA$, and they coincide with $|\lambda|$ only for special matrices such as symmetric ones.
- Listing a negative singular value. Singular values are nonnegative by definition, and any sign goes into $U$ or $V$.
- Forgetting the order $\sigma_1 \ge \sigma_2 \ge \cdots$ when matching the columns of $U$ and $V$.

solution: (a) $A = Q\Lambda Q^T$ with $Q = [\mathbf{q}_1\ \mathbf{q}_2]$ and $\Lambda = \operatorname{diag}(3, -1)$. (b) $A^TA = A^2$ has eigenvalues $9$ and $1$ with the same eigenvectors, so $\sigma_1 = 3$, $\sigma_2 = 1$ and $\mathbf{v}_i = \mathbf{q}_i$. So $A = U\Sigma V^T$ with $U = [\mathbf{q}_1\ \ {-\mathbf{q}_2}]$, $\Sigma = \operatorname{diag}(3, 1)$ and $V = [\mathbf{q}_1\ \ \mathbf{q}_2]$.

@article
A **linear transformation** is a function $T$ between vector spaces that respects addition and scaling:
$$T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v}), \qquad T(c\mathbf{u}) = cT(\mathbf{u}).$$
Together these say that $T$ turns every linear combination of inputs into the same combination of outputs. In particular $T(\mathbf{0}) = \mathbf{0}$, which gives a fast way to reject a candidate: the map "add the vector $(1, 0)$" sends $\mathbf{0}$ to $(1, 0)$, so it is not linear.

### Examples

- Rotating the plane about the origin, reflecting across a line through the origin, projecting onto such a line, and scaling are all linear.
- Differentiation $D(p) = p'$ on polynomials is linear, because $(p + q)' = p' + q'$ and $(cp)' = cp'$.
- $T(x, y) = (x^2, y)$ and $T(x, y) = (x + 1, y)$ are not linear.

### Every linear map on R^n is a matrix

Suppose $T : \mathbb{R}^n \to \mathbb{R}^m$ is linear. Since $\mathbf{x} = x_1\mathbf{e}_1 + \cdots + x_n\mathbf{e}_n$, linearity gives $T(\mathbf{x}) = x_1 T(\mathbf{e}_1) + \cdots + x_n T(\mathbf{e}_n)$. That is $A\mathbf{x}$, where the **columns of $A$ are $T(\mathbf{e}_1), \dots, T(\mathbf{e}_n)$**. Counterclockwise rotation by $\theta$ sends $\mathbf{e}_1$ to $(\cos\theta, \sin\theta)$ and $\mathbf{e}_2$ to $(-\sin\theta, \cos\theta)$, so
$$R_\theta = \begin{bmatrix}\cos\theta & -\sin\theta\\ \sin\theta & \cos\theta\end{bmatrix}.$$

### Kernel, image, composition

The **kernel** $\ker T = \{\mathbf{x} : T(\mathbf{x}) = \mathbf{0}\}$ is the null space $N(A)$, and the **image** is the column space $C(A)$. Rank-nullity reads $\dim \ker T + \dim \operatorname{im} T = n$. If $T$ has matrix $A$ and $S$ has matrix $B$, then "first $T$, then $S$" has matrix $BA$. The matrix applied first sits on the right.

### Coordinates and bases

A vector is not its list of numbers. The numbers are its **coordinates relative to a basis**. If $\mathcal{B} = \{\mathbf{b}_1, \dots, \mathbf{b}_n\}$ is a basis and $\mathbf{v} = c_1\mathbf{b}_1 + \cdots + c_n\mathbf{b}_n$, then $[\mathbf{v}]_{\mathcal{B}} = (c_1, \dots, c_n)$. Put the basis vectors in the columns of a matrix $P$. Then $\mathbf{v} = P[\mathbf{v}]_{\mathcal{B}}$, so $[\mathbf{v}]_{\mathcal{B}} = P^{-1}\mathbf{v}$.

The **matrix of $T$ in the basis $\mathcal{B}$** has as its $j$-th column the coordinates $[T(\mathbf{b}_j)]_{\mathcal{B}}$. If $A$ is the matrix of $T$ in the standard basis, this matrix is
$$[T]_{\mathcal{B}} = P^{-1}AP.$$
It describes the same transformation in different coordinates, and next week's lesson puts it to work.

```python
import numpy as np
t = np.pi / 2
R = np.array([[np.cos(t), -np.sin(t)], [np.sin(t), np.cos(t)]])
print(np.round(R @ np.array([1, 0]), 6))   # [0. 1.]
```

@example
title: The matrix of a map from R^2 to R^3
problem: Let $T(x, y) = (x + 2y,\ 3x - y,\ y)$. Find its standard matrix and its kernel.
step: Compute $T(\mathbf{e}_1) = T(1, 0) = (1, 3, 0)$.
step: Compute $T(\mathbf{e}_2) = T(0, 1) = (2, -1, 1)$.
step: These are the columns: $A = \begin{bmatrix}1&2\\3&-1\\0&1\end{bmatrix}$. It is $3 \times 2$ because $T$ takes $\mathbb{R}^2$ to $\mathbb{R}^3$. Check on $(1, 1)$: $A(1, 1)^T = (3, 2, 1) = T(1, 1)$.
step: Kernel: $A\mathbf{x} = \mathbf{0}$ has third row $y = 0$, then $x + 2y = 0$ gives $x = 0$. So $\ker T = \{\mathbf{0}\}$, the rank is $2$, and the image is a plane in $\mathbb{R}^3$.

@example
title: Composition order
problem: Let $R$ rotate the plane $90^\circ$ counterclockwise and let $F$ reflect it across the $x$-axis. Find the matrix of "first $R$, then $F$".
step: Rotation: $R\mathbf{e}_1 = (0, 1)$ and $R\mathbf{e}_2 = (-1, 0)$, so $R = \begin{bmatrix}0&-1\\1&0\end{bmatrix}$.
step: Reflection: $F\mathbf{e}_1 = (1, 0)$ and $F\mathbf{e}_2 = (0, -1)$, so $F = \begin{bmatrix}1&0\\0&-1\end{bmatrix}$.
step: First $R$ then $F$ means $F(R\mathbf{x})$, so the matrix is $FR = \begin{bmatrix}1&0\\0&-1\end{bmatrix}\begin{bmatrix}0&-1\\1&0\end{bmatrix} = \begin{bmatrix}0&-1\\-1&0\end{bmatrix}$.
step: Check with $\mathbf{e}_1$: $R\mathbf{e}_1 = (0, 1)$ and $F(0, 1) = (0, -1)$, which is the first column of $FR$. The opposite order gives $RF = \begin{bmatrix}0&1\\1&0\end{bmatrix}$, a different transformation.

@mistakes
- Writing the composition "first $T$, then $S$" as $AB$ instead of $BA$.
- Building the matrix with the images $T(\mathbf{e}_j)$ as rows instead of columns.
- Calling an affine map such as $\mathbf{x} \mapsto A\mathbf{x} + \mathbf{c}$ with $\mathbf{c} \ne \mathbf{0}$ linear. It fails $T(\mathbf{0}) = \mathbf{0}$.

prompt: Which of these maps from $\mathbb{R}^2$ to $\mathbb{R}^2$ is linear?
choice*: $T(x, y) = (2x - y,\ x + 3y)$
choice: $T(x, y) = (x + 1,\ y)$
choice: $T(x, y) = (xy,\ y)$
choice: $T(x, y) = (|x|,\ y)$
hint: A linear map must send $\mathbf{0}$ to $\mathbf{0}$ and must satisfy $T(c\mathbf{u}) = cT(\mathbf{u})$ for negative $c$ as well.
solution: The map $T(x, y) = (2x - y,\ x + 3y)$ is $A\mathbf{x}$ for a matrix $A$. The map $T(x, y) = (x + 1,\ y)$ sends $\mathbf{0}$ to $(1, 0)$. The map $T(x, y) = (xy,\ y)$ fails scaling: $T(2, 2) = (4, 2)$ but $2T(1, 1) = (2, 2)$. The map $T(x, y) = (|x|,\ y)$ fails for $c = -1$ since $|{-x}| \ne -|x|$.

@practice tuple
prompt: Let $T$ rotate the plane counterclockwise by $90^\circ$. Find $T(2, 3)$.
answer: (-3, 2)
check: np.array([[np.cos(np.pi/2), -np.sin(np.pi/2)], [np.sin(np.pi/2), np.cos(np.pi/2)]]) @ np.array([2, 3])
hint: Find the images of $\mathbf{e}_1$ and $\mathbf{e}_2$ first. They are the columns of the rotation matrix.
solution: $T(\mathbf{e}_1) = (0, 1)$ and $T(\mathbf{e}_2) = (-1, 0)$. So $T(2, 3) = 2(0, 1) + 3(-1, 0) = (-3, 2)$.

@practice num
prompt: Let $T(x, y, z) = (x + y,\ y + z,\ x - z)$. What is $\dim \ker T$?
answer: 1
check: 3 - rank([[1,1,0],[0,1,1],[1,0,-1]])
hint: Write the standard matrix, with columns $T(\mathbf{e}_1)$, $T(\mathbf{e}_2)$, $T(\mathbf{e}_3)$, and find its rank.
hint: The rows are $[1\ 1\ 0]$, $[0\ 1\ 1]$, $[1\ 0\ -1]$. Row 3 minus row 1 is $[0\ -1\ -1]$.
solution: Row 3 minus row 1 equals the negative of row 2, so elimination gives a zero row and the rank is $2$. By rank-nullity $\dim \ker T = 3 - 2 = 1$. The kernel is spanned by $(1, -1, 1)$.

@practice tuple
prompt: Let $A = \begin{bmatrix}1&2\\0&1\end{bmatrix}$ and $B = \begin{bmatrix}0&1\\1&0\end{bmatrix}$. Apply the map of $A$ first and then the map of $B$ to $\mathbf{v} = (3, 1)$. Enter the result.
answer: (1, 5)
check: np.array([[0,1],[1,0]]) @ (np.array([[1,2],[0,1]]) @ np.array([3,1]))
hint: The matrix applied first acts on $\mathbf{v}$ first, so it is the one on the right in the product $BA\mathbf{v}$.
solution: $A\mathbf{v} = (3 + 2, 1) = (5, 1)$. Then $B(5, 1) = (1, 5)$. The wrong order $AB\mathbf{v}$ would give $(7, 3)$.

@practice self
prompt: Let $D$ be differentiation on the space of polynomials of degree at most $2$, with basis $\{1, x, x^2\}$. Find the matrix of $D$ in this basis, then describe $\ker D$ and the image of $D$ and check rank-nullity.
hint: Apply $D$ to each basis vector and write the result in coordinates with respect to $\{1, x, x^2\}$.
solution: $D(1) = 0$, $D(x) = 1$, $D(x^2) = 2x$. In coordinates these are $(0, 0, 0)$, $(1, 0, 0)$ and $(0, 2, 0)$, so the matrix is $\begin{bmatrix}0&1&0\\0&0&2\\0&0&0\end{bmatrix}$. The kernel is the constants (dimension $1$). The image is all polynomials of degree at most $1$ (dimension $2$). Rank-nullity: $1 + 2 = 3 = \dim$ of the domain.

@quiz tuple
prompt: A linear map $T : \mathbb{R}^2 \to \mathbb{R}^2$ satisfies $T(1, 0) = (2, 1)$ and $T(1, 1) = (5, 4)$. Find $T(2, 3)$.
answer: (13, 11)
check: np.array([[2,5],[1,4]]) @ lin([[1,1],[0,1]], [2,3])
hint: Write $(2, 3)$ as a combination $a(1, 0) + b(1, 1)$.
hint: The second coordinate forces $b = 3$. Then apply linearity.
solution: $(2, 3) = -1\cdot(1, 0) + 3\cdot(1, 1)$. By linearity, $T(2, 3) = -(2, 1) + 3(5, 4) = (13, 11)$.

@quiz num
prompt: Let $A = \begin{bmatrix}2&1\\0&3\end{bmatrix}$ be the standard matrix of $T$, and let $\mathcal{B}$ consist of $\mathbf{b}_1 = (1, 1)$ and $\mathbf{b}_2 = (0, 1)$. The matrix $[T]_{\mathcal{B}}$ has entry in row 1, column 2 equal to what?
answer: 1
check: (np.linalg.inv(np.array([[1,0],[1,1]])) @ np.array([[2,1],[0,3]]) @ np.array([[1,0],[1,1]]))[0,1]
hint: Column 2 of $[T]_{\mathcal{B}}$ holds the coordinates of $T(\mathbf{b}_2)$ relative to $\mathcal{B}$.

solution: $T(\mathbf{b}_2) = (1, 3) = 1\cdot(1, 1) + 2\cdot(0, 1)$, so column 2 of $[T]_{\mathcal{B}}$ is $(1, 2)$ and the requested entry is $1$. (Also $T(\mathbf{b}_1) = (3, 3) = 3\mathbf{b}_1$, so $[T]_{\mathcal{B}} = \begin{bmatrix}3&1\\0&2\end{bmatrix}$.)

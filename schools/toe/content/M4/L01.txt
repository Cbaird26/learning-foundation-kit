@article
A **linear system** is a collection of linear equations in the same unknowns, such as
$$x + 2y = 5, \qquad 3x - y = 1.$$
Each equation describes a line in the plane, and a **solution** is a point lying on all the lines at once. Two lines can cross at a single point, be parallel and never meet, or be the same line. That trichotomy holds for every linear system, however large: it has **exactly one solution, no solution, or infinitely many solutions**.

### Matrix form and the augmented matrix

Collect the coefficients into a matrix $A$, the unknowns into a vector $\mathbf{x}$ and the right-hand sides into $\mathbf{b}$, so the system reads $A\mathbf{x} = \mathbf{b}$. The **augmented matrix** $[A \mid \mathbf{b}]$ records everything without rewriting the variable names:
$$\left[\begin{array}{cc|c} 1 & 2 & 5 \\ 3 & -1 & 1 \end{array}\right].$$

### Row operations

Three **elementary row operations** change the look of a system but never its solutions:

1. swap two rows;
2. multiply a row by a nonzero number;
3. add a multiple of one row to another row.

**Gaussian elimination** uses them to create zeros below each leading entry. The first nonzero entry of a row, once the zeros are in place, is its **pivot**. The finished staircase, with each pivot to the right of the one above, is **echelon form**. If a pivot position holds a zero, swap in a lower row that has a nonzero entry there.

### Back substitution

From echelon form, work from the bottom row upward. The last equation has the fewest unknowns, so solve it first, substitute into the row above, and continue.

### Reading the outcome

Look at the echelon form of $[A \mid \mathbf{b}]$:

| What you see | Meaning |
|---|---|
| A row $[0\ \cdots\ 0 \mid c]$ with $c \neq 0$ | It says $0 = c$: **no solution** |
| No such row, and every column of $A$ has a pivot | **Unique solution** |
| No such row, and some column of $A$ has no pivot | **Infinitely many solutions** |

A column without a pivot gives a **free variable**: you may choose its value, and the other unknowns then follow. With $n$ unknowns and $r$ pivots, a consistent system has $n - r$ free variables.

### Checking with Python

```python
import numpy as np
A = np.array([[1., 2.], [3., -1.]])
b = np.array([5., 1.])
print(np.linalg.solve(A, b))   # [1. 2.]
```

`solve` works only when the solution is unique. Elimination by hand is what tells you which of the three cases you are in.

@example
title: A 3 by 3 system with a unique solution
problem: Solve $x + y + z = 6$, $2x - y + z = 3$, $x + 2y - z = 2$.
step: Write the augmented matrix with rows $[1\ 1\ 1 \mid 6]$, $[2\ -1\ 1 \mid 3]$, $[1\ 2\ -1 \mid 2]$. The first pivot is the $1$ in the top left.
step: Clear column 1 with $R_2 \to R_2 - 2R_1$ and $R_3 \to R_3 - R_1$. The rows become $[1\ 1\ 1 \mid 6]$, $[0\ -3\ -1 \mid -9]$, $[0\ 1\ -2 \mid -4]$.
step: The second pivot is $-3$. Apply $R_3 \to R_3 + \tfrac13 R_2$. The last row becomes $[0\ 0\ -\tfrac73 \mid -7]$.
step: Solve the last equation: $-\tfrac73 z = -7$, so $z = 3$.
step: Back-substitute. Row 2 gives $-3y - 3 = -9$, so $y = 2$. Row 1 gives $x + 2 + 3 = 6$, so $x = 1$.
step: Check in the original equations: $1+2+3 = 6$, $2-2+3 = 3$, $1+4-3 = 2$. The solution is $(1, 2, 3)$.

@example
title: A system with infinitely many solutions
problem: Solve $x + 2y + z = 4$ and $2x + 4y + 3z = 9$.
step: The augmented matrix has rows $[1\ 2\ 1 \mid 4]$ and $[2\ 4\ 3 \mid 9]$.
step: Apply $R_2 \to R_2 - 2R_1$. Row 2 becomes $[0\ 0\ 1 \mid 1]$.
step: The pivots are in columns 1 and 3. Column 2 has no pivot, so $y$ is a free variable.
step: Row 2 gives $z = 1$. Row 1 gives $x + 2y + 1 = 4$, so $x = 3 - 2y$.
step: Write $y = t$. Every solution has the form $(x, y, z) = (3 - 2t,\ t,\ 1)$. Check $t = 0$: $(3, 0, 1)$ gives $3 + 0 + 1 = 4$ and $6 + 0 + 3 = 9$.

@mistakes
- Changing a row on the left of the bar but forgetting to apply the same change to its right-hand entry.
- Reading a row $[0\ 0\ 0 \mid 0]$ as "no solution". It only says one equation was redundant. Only $[0\ 0\ 0 \mid c]$ with $c \neq 0$ is a contradiction.
- Dividing by a zero pivot instead of swapping in a lower row that has a nonzero entry in that column.

@practice tuple
prompt: Solve the system $x + 2y = 5$, $3x - y = 1$. Enter $(x, y)$.
answer: (1, 2)
check: lin([[1,2],[3,-1]], [5,1])
hint: Eliminate $x$ from the second equation by subtracting $3$ times the first equation from it.
hint: The second equation becomes $-7y = -14$.
solution: $R_2 - 3R_1$ gives $-7y = -14$, so $y = 2$, and then $x = 5 - 4 = 1$. Check: $3(1) - 2 = 1$.

@practice num
prompt: Eliminate below the pivots of $A = \begin{bmatrix}1&2&1\\3&8&2\\0&4&1\end{bmatrix}$. No row swaps are needed. What is the third pivot?
answer: 3
check: det([[1,2,1],[3,8,2],[0,4,1]]) / det([[1,2],[3,8]])
hint: Subtract $3$ times row 1 from row 2 first. That creates the second pivot.
hint: Row 2 becomes $[0\ 2\ -1]$. Now use it to clear the $4$ in row 3.
solution: $R_2 - 3R_1 = [0\ 2\ -1]$, then $R_3 - 2R_2 = [0\ 0\ 3]$. The pivots are $1, 2, 3$.

@practice num
prompt: How many free variables does $A\mathbf{x} = \mathbf{0}$ have when $A = \begin{bmatrix}1&2&3&4\\2&4&6&8\\1&0&1&0\end{bmatrix}$?
answer: 2
check: 4 - rank([[1,2,3,4],[2,4,6,8],[1,0,1,0]])
hint: Row 2 is twice row 1, so elimination turns it into a zero row.
hint: Count the pivots that remain. Free variables $= 4 - $ pivots.
solution: $R_2 - 2R_1 = 0$ and $R_3 - R_1 = [0\ -2\ -2\ -4]$. There are two pivots (columns 1 and 2), so there are $4 - 2 = 2$ free variables.

@practice tuple
prompt: Solve $2y + z = 1$, $x + y + z = 2$, $2x - y + 3z = 0$. The first pivot position holds a zero, so begin by swapping rows. Enter $(x, y, z)$.
answer: (2, 1, -1)
check: lin([[0,2,1],[1,1,1],[2,-1,3]], [1,2,0])
hint: Swap the first two equations so that the first pivot is $1$.
hint: Then subtract $2$ times row 1 from row 3, and use row 2 to clear column 2 of row 3.
solution: After the swap and $R_3 - 2R_1$ the rows are $[1\ 1\ 1 \mid 2]$, $[0\ 2\ 1 \mid 1]$, $[0\ -3\ 1 \mid -4]$. Then $R_3 + \tfrac32 R_2$ gives $[0\ 0\ \tfrac52 \mid -\tfrac52]$, so $z = -1$. Next $2y - 1 = 1$ gives $y = 1$, and $x + 1 - 1 = 2$ gives $x = 2$.

@quiz num
prompt: For which value of $k$ does the system $x + 2y = 3$, $2x + 4y = k$ have infinitely many solutions?
answer: 6
check: root(lambda k: det([[1,3],[2,k]]), 0, 10)
hint: Subtract $2$ times the first equation from the second.
hint: The second row becomes $[0\ 0 \mid k - 6]$. When is that row harmless?
solution: $R_2 - 2R_1 = [0\ 0 \mid k - 6]$. If $k \neq 6$ this says $0 = k - 6 \neq 0$, so there is no solution. If $k = 6$ the row is $[0\ 0 \mid 0]$ and one equation in two unknowns remains, giving infinitely many solutions.

@quiz ms
prompt: A consistent system has $3$ equations and $5$ unknowns. Select every statement that must be true.
choice*: It has at least one free variable.
choice*: It has infinitely many solutions.
choice*: The coefficient matrix has at most $3$ pivots.
choice: It has a unique solution if the three equations are independent.
choice: It has exactly $2$ free variables.
hint: Each row contains at most one pivot.
hint: Free variables $= 5 - $ (number of pivots), and the number of pivots can be $1$, $2$ or $3$.
solution: There are at most $3$ pivots, so at least $2$ of the $5$ columns have none, giving free variables. A consistent system with a free variable has infinitely many solutions. The number of free variables is $5 - r$ with $r \le 3$, so it may be $2$, $3$ or $4$, not necessarily $2$.

@article
Most vectors change direction when you multiply them by a matrix $A$. A few special vectors do not: $A$ only stretches, shrinks or flips them. These directions explain how a matrix behaves when applied repeatedly.

### Definition

A nonzero vector $\mathbf{v}$ is an **eigenvector** of the square matrix $A$ with **eigenvalue** $\lambda$ if
$$A\mathbf{v} = \lambda\mathbf{v}.$$
The vector must be nonzero, since $A\mathbf{0} = \lambda\mathbf{0}$ holds for every $\lambda$. Any nonzero multiple of an eigenvector is also an eigenvector. All eigenvectors for $\lambda$, together with $\mathbf{0}$, form the **eigenspace** $N(A - \lambda I)$.

### How to find them

Rewrite $A\mathbf{v} = \lambda\mathbf{v}$ as $(A - \lambda I)\mathbf{v} = \mathbf{0}$. A nonzero solution exists exactly when $A - \lambda I$ is singular, that is
$$\det(A - \lambda I) = 0.$$
This is the **characteristic equation**. For a $2 \times 2$ matrix it expands to
$$\lambda^2 - (\operatorname{tr} A)\,\lambda + \det A = 0.$$
Solve it for the eigenvalues, then for each $\lambda$ solve $(A - \lambda I)\mathbf{v} = \mathbf{0}$ by elimination. Do not row-reduce $A$ itself to find eigenvalues, because row operations change them.

### Useful facts

- The eigenvalues add up to the **trace** and multiply to the **determinant**. Use this as a check.
- For a triangular matrix the eigenvalues are the diagonal entries.
- $A$ is singular exactly when $0$ is an eigenvalue.
- If $A\mathbf{v} = \lambda\mathbf{v}$ then $A^k\mathbf{v} = \lambda^k\mathbf{v}$, and $A^{-1}\mathbf{v} = \lambda^{-1}\mathbf{v}$ when $A$ is invertible. The eigenvectors stay the same.

### Complex and repeated eigenvalues

A real matrix may have complex eigenvalues, and they come in conjugate pairs. A $90^\circ$ rotation has $\lambda^2 + 1 = 0$, so $\lambda = \pm i$: it turns every real vector, so no real direction survives.

A root can be **repeated**. Its multiplicity as a root is the **algebraic multiplicity**. The dimension of its eigenspace is the **geometric multiplicity**, and it can be smaller. For $\begin{bmatrix}2&1\\0&2\end{bmatrix}$ the eigenvalue $2$ appears twice, yet $A - 2I = \begin{bmatrix}0&1\\0&0\end{bmatrix}$ has a one-dimensional null space. We will see next week why this matters.

```python
import numpy as np
A = np.array([[4., 1.], [2., 3.]])
vals, vecs = np.linalg.eig(A)      # columns of vecs are eigenvectors
print(vals)                        # [5. 2.]
print(A @ vecs[:, 0] - vals[0] * vecs[:, 0])   # approximately [0. 0.]
```

@example
title: Eigenpairs of a 2 by 2 matrix
problem: Find the eigenvalues and eigenvectors of $A = \begin{bmatrix}4&1\\2&3\end{bmatrix}$.
step: The trace is $7$ and the determinant is $12 - 2 = 10$, so the characteristic equation is $\lambda^2 - 7\lambda + 10 = (\lambda - 5)(\lambda - 2) = 0$. The eigenvalues are $5$ and $2$.
step: For $\lambda = 5$: $A - 5I = \begin{bmatrix}-1&1\\2&-2\end{bmatrix}$. The equation $-v_1 + v_2 = 0$ gives $\mathbf{v} = (1, 1)$.
step: For $\lambda = 2$: $A - 2I = \begin{bmatrix}2&1\\2&1\end{bmatrix}$. The equation $2v_1 + v_2 = 0$ gives $\mathbf{v} = (1, -2)$.
step: Check: $A(1, 1)^T = (5, 5) = 5(1, 1)$ and $A(1, -2)^T = (2, -4) = 2(1, -2)$. Also $5 + 2 = 7$ and $5 \cdot 2 = 10$.

@example
title: Complex eigenvalues of a rotation
problem: Find the eigenvalues and an eigenvector of $A = \begin{bmatrix}0&-1\\1&0\end{bmatrix}$.
step: The trace is $0$ and the determinant is $1$, so $\lambda^2 + 1 = 0$ and $\lambda = \pm i$.
step: For $\lambda = i$, solve $(A - iI)\mathbf{v} = \mathbf{0}$, where $A - iI = \begin{bmatrix}-i&-1\\1&-i\end{bmatrix}$. The first row says $-iv_1 - v_2 = 0$, so $v_2 = -iv_1$.
step: Take $v_1 = 1$ to get $\mathbf{v} = (1, -i)$. The eigenvector for $\lambda = -i$ is the conjugate $(1, i)$.
step: Check: $A(1, -i)^T = (i, 1)$ and $i \cdot (1, -i) = (i, 1)$. No real eigenvector exists, matching the geometry of a rotation.

@mistakes
- Computing $\det(A) - \lambda$ instead of $\det(A - \lambda I)$. The $\lambda$ is subtracted from each diagonal entry only.
- Row-reducing $A$ and reading eigenvalues from the pivots. Row operations change eigenvalues.
- Accepting $\mathbf{0}$ as an eigenvector. Eigenvectors are nonzero by definition.

@practice list
prompt: Find all eigenvalues of $\begin{bmatrix}2&1\\0&5\end{bmatrix}$.
answer: 2, 5
check: np.linalg.eigvals(np.array([[2,1],[0,5]]))
hint: The matrix is triangular.
solution: For a triangular matrix the eigenvalues are the diagonal entries: $2$ and $5$. Check with the characteristic polynomial: $(2 - \lambda)(5 - \lambda)$.

@practice list
prompt: Find all eigenvalues of $A = \begin{bmatrix}1&2\\3&0\end{bmatrix}$.
answer: 3, -2
check: np.linalg.eigvals(np.array([[1,2],[3,0]]))
hint: The trace is $1$ and the determinant is $-6$. The eigenvalues satisfy $\lambda^2 - \lambda - 6 = 0$.
solution: $\lambda^2 - \lambda - 6 = (\lambda - 3)(\lambda + 2) = 0$, so $\lambda = 3$ or $\lambda = -2$. Check: $3 + (-2) = 1$ is the trace and $3(-2) = -6$ is the determinant.

@practice num
prompt: For $A = \begin{bmatrix}1&2\\3&0\end{bmatrix}$, the vector $(1, t)$ is an eigenvector with eigenvalue $-2$ for exactly one value of $t$. Find $t$.
answer: -3/2
check: root(lambda t: (np.array([[1,2],[3,0]]) @ np.array([1,t]))[1] + 2*t, -10, 10)
hint: Compute $A(1, t)^T$ and compare it with $-2(1, t)$.
hint: The second component of $A(1, t)^T$ is $3$, and must equal $-2t$.
solution: $A(1, t)^T = (1 + 2t,\ 3)$ and this must equal $(-2,\ -2t)$. The second component gives $t = -\tfrac32$. The first component agrees: $1 + 2(-\tfrac32) = -2$.

@practice num
prompt: The matrix $A = \begin{bmatrix}0&6\\1&-1\end{bmatrix}$ has eigenvalues $2$ and $-3$. What is the largest eigenvalue of $A^2$?
answer: 9
check: max(np.linalg.eigvals(np.linalg.matrix_power(np.array([[0,6],[1,-1]]), 2)))
hint: If $A\mathbf{v} = \lambda\mathbf{v}$ then $A^2\mathbf{v} = \lambda^2\mathbf{v}$.
solution: The eigenvalues of $A^2$ are $2^2 = 4$ and $(-3)^2 = 9$. The largest is $9$.

@practice mc
prompt: Consider $A = \begin{bmatrix}2&1\\0&2\end{bmatrix}$. Which statement is true?
choice*: Its only eigenvalue is $2$, and every eigenvector is a multiple of $(1, 0)$.
choice: It has two independent eigenvectors because the eigenvalue $2$ is repeated.
choice: It has no real eigenvalues.
choice: Its eigenvalues are $1$ and $2$.
hint: Find $N(A - 2I)$.
solution: The matrix is triangular, so the eigenvalue $2$ appears twice. $A - 2I = \begin{bmatrix}0&1\\0&0\end{bmatrix}$ forces $v_2 = 0$, so the eigenspace is spanned by $(1, 0)$ alone. A repeated eigenvalue does not guarantee two independent eigenvectors.

@quiz list
prompt: Find all eigenvalues of $A = \begin{bmatrix}2&1&0\\1&2&0\\0&0&5\end{bmatrix}$.
answer: 1, 3, 5
check: np.linalg.eigvals(np.array([[2,1,0],[1,2,0],[0,0,5]]))
hint: The matrix is block diagonal. Find the eigenvalues of each block.
solution: The upper block $\begin{bmatrix}2&1\\1&2\end{bmatrix}$ has trace $4$ and determinant $3$, so $\lambda^2 - 4\lambda + 3 = (\lambda - 1)(\lambda - 3)$. The last block contributes $5$. The eigenvalues are $1$, $3$ and $5$.

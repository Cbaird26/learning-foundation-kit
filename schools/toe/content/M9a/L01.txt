@article
Every calculus fact you have used, such as "a bounded increasing quantity settles down to a limit", quietly depends on one property of the real numbers. This lesson names that property and shows how to use it.

### A gap in the rationals

Look at $S=\{q\in\mathbb Q : q^2<2\}$. It is bounded above (by $2$, say). Its rational upper bounds $1.5,\ 1.42,\ 1.415,\dots$ keep getting smaller, but there is never a smallest one, because the number that ought to be smallest, $\sqrt2$, is not rational. The rationals have a hole there. The real numbers $\mathbb R$ have no such holes.

### Upper bounds and suprema

Let $S\subseteq\mathbb R$ be nonempty. A number $M$ is an **upper bound** of $S$ if $x\le M$ for every $x\in S$. The **supremum** $\sup S$ is the *least* upper bound: an upper bound that is $\le$ every other upper bound. The **infimum** $\inf S$ is the greatest lower bound. If $\sup S$ belongs to $S$, it is called the **maximum**.

For $S=(0,1)$ we have $\sup S=1$, but $1\notin S$, so there is no maximum. For $[0,1]$ the supremum $1$ is the maximum.

### The completeness axiom

**Completeness axiom.** Every nonempty subset of $\mathbb R$ that is bounded above has a supremum in $\mathbb R$.

Applying this to $-S=\{-x : x\in S\}$ shows that every nonempty set bounded below has an infimum, and $\inf S=-\sup(-S)$. Nearly everything in this course that produces a limit without being told its value (monotone convergence, Bolzano–Weierstrass, the extreme value theorem, the integral) rests on this axiom.

### The two-part test

To prove $s=\sup S$, show two things:

- **$s$ is an upper bound:** $x\le s$ for all $x\in S$.
- **Nothing smaller works:** for every $\varepsilon>0$ there is some $x\in S$ with $x>s-\varepsilon$.

The second part says that $s-\varepsilon$ is not an upper bound, for any $\varepsilon>0$, so no number below $s$ is an upper bound.

### The Archimedean property

For every real $x$ there is a natural number $n>x$. Otherwise $\mathbb N$ would be bounded above and would have a supremum $s$. But $s-1$ is not an upper bound, so some $n>s-1$, and then $n+1>s$ with $n+1\in\mathbb N$, a contradiction.

The consequence you will use constantly: **for every $\varepsilon>0$ there is $n\in\mathbb N$ with $\frac1n<\varepsilon$.** Apply the property to $x=1/\varepsilon$. A companion fact is density: between any two distinct real numbers there is a rational number.

@example
title: A supremum that is not a maximum
problem: Prove that $\sup\left\{1-\frac1n : n\in\mathbb N\right\}=1$, and that this set has no maximum.
step: Upper bound. For every $n$ we have $\frac1n>0$, so $1-\frac1n<1$. Hence $1$ is an upper bound.
step: Nothing smaller works. Fix $\varepsilon>0$. By the Archimedean property choose $n$ with $\frac1n<\varepsilon$.
step: For this $n$, the element $1-\frac1n$ of the set satisfies $1-\frac1n>1-\varepsilon$. So $1-\varepsilon$ is not an upper bound.
step: Since $\varepsilon>0$ was arbitrary, no number less than $1$ is an upper bound. Together with the first step, $1$ is the least upper bound.
step: No maximum. A maximum would have to equal the supremum $1$, but every element of the set is strictly less than $1$.

@mistakes
- Treating the supremum as an element of the set. Here $\sup(0,1)=1$ and $1\notin(0,1)$.
- Showing only that a number is an upper bound and concluding it is the least upper bound. You also need part two of the test.
- Arguing "$\mathbb Q$ is dense, so it has no gaps". Density does not give completeness: $\{q\in\mathbb Q : q^2<2\}$ has no least upper bound in $\mathbb Q$.

prompt: Let $S=\{x\in\mathbb R : 0<x<1\}$. Which statement is true?
choice*: $\sup S=1$, and $S$ has no maximum.
choice: $\sup S=1$ and $\max S=1$.
choice: $S$ has no supremum, because it has no maximum.
choice: $\sup S$ can be any number that is at least $1$.
hint: A supremum is the least upper bound. Must it be an element of the set?
solution: Every upper bound of $S$ is at least $1$, and $1$ is itself an upper bound, so $\sup S=1$. But $1\notin S$, so $S$ has no maximum.

@practice num
prompt: Find $\sup\{x\in\mathbb R : x^2+3x<4\}$.
answer: 1
check: max(allroots(lambda x: x**2 + 3*x - 4, -10, 10))
hint: Factor $x^2+3x-4$ and decide where it is negative.
hint: $(x+4)(x-1)<0$ exactly when $x$ lies between the two roots.
solution: The inequality reads $(x+4)(x-1)<0$, which holds exactly for $-4<x<1$. The set is the interval $(-4,1)$, whose supremum is $1$ (not attained).

@practice num
prompt: Let $S=\{q\in\mathbb Q : q^2<5\}$. Find $\sup S$, viewed as a real number. Give an exact value.
answer: sqrt(5)
check: root(lambda x: x*x - 5, 0, 5)
hint: Every element of $S$ is below the positive solution of $x^2=5$. Is anything smaller still an upper bound? Think about density of $\mathbb Q$.
solution: Every $q\in S$ has $q<\sqrt5$, so $\sqrt5$ is an upper bound. If $b<\sqrt5$, density gives a rational $q$ with $\max(b,0)<q<\sqrt5$; then $q\in S$ and $q>b$, so $b$ is not an upper bound. Hence $\sup S=\sqrt5$, which is irrational, so $S$ has no least upper bound inside $\mathbb Q$.

@practice ms
prompt: Select all true statements.
choice*: Every nonempty subset of $\mathbb R$ that is bounded above has a least upper bound in $\mathbb R$.
choice: Every nonempty subset of $\mathbb Q$ that is bounded above has a least upper bound in $\mathbb Q$.
choice*: If $s=\sup S$, then for every $\varepsilon>0$ there is $x\in S$ with $x>s-\varepsilon$.
choice: If $s=\sup S$, then $s\in S$.
choice*: If $S$ is nonempty and bounded below, then $\inf S=-\sup(-S)$, where $-S=\{-x : x\in S\}$.
hint: Test each statement on $\{q\in\mathbb Q : q^2<2\}$ and on $(0,1)$.
solution: The completeness statement for $\mathbb R$, the $\varepsilon$-criterion for $s=\sup S$ and the formula $\inf S=-\sup(-S)$ are true. The statement about subsets of $\mathbb Q$ fails for $\{q\in\mathbb Q : q^2<2\}$. The statement $s\in S$ fails for $(0,1)$, where $\sup=1\notin S$. The formula $\inf S=-\sup(-S)$ holds because lower bounds of $S$ are the negatives of upper bounds of $-S$.

@practice self
prompt: Prove that $\inf\left\{\frac1n : n\in\mathbb N\right\}=0$, and that this set has no minimum.
hint: Mirror the two-part test: first show $0$ is a lower bound, then show no positive number $\varepsilon$ is a lower bound.
hint: For the second part, which property of $\mathbb N$ gives an $n$ with $\frac1n<\varepsilon$?
solution: Lower bound: $\frac1n>0$ for every $n$, so $0$ is a lower bound. Nothing larger works: let $\varepsilon>0$. By the Archimedean property pick $n$ with $\frac1n<\varepsilon$; then $\varepsilon$ is not a lower bound. So no number greater than $0$ is a lower bound, and $0$ is the greatest lower bound. There is no minimum because a minimum would equal the infimum $0$, yet $0\ne\frac1n$ for every $n$.

@quiz num
prompt: Find $\sup\left\{\dfrac{3n^2-1}{n^2+1} : n\in\mathbb N\right\}$.
answer: 3
check: lim(lambda t: (3 - t*t)/(1 + t*t), 0, 1)
hint: Rewrite the fraction as $3-\frac{c}{n^2+1}$ for a constant $c$.
hint: The expression is $3-\frac4{n^2+1}$. Is it increasing in $n$, and what does it approach?
solution: Since $\frac{3n^2-1}{n^2+1}=3-\frac4{n^2+1}$, every term is below $3$. Given $\varepsilon>0$, choosing $n$ large makes $\frac4{n^2+1}<\varepsilon$, so the terms come within $\varepsilon$ of $3$. Hence $\sup=3$, and it is not attained.

@quiz mc
prompt: Let $S$ be nonempty and bounded above, and suppose $M$ is an upper bound of $S$ with $M\in S$. Which statement must be true?
choice*: $M=\sup S$, so $M$ is also the maximum of $S$.
choice: $M>\sup S$, because $M$ belongs to the set.
choice: $\sup S$ might not exist.
choice: $M$ is an upper bound, but another element of $S$ could be larger than $M$.
hint: Compare $M$ with the least upper bound, and remember $M$ is itself in $S$.
solution: The supremum is at most any upper bound, so $\sup S\le M$. Since $M\in S$ and $\sup S$ is an upper bound, $M\le\sup S$. Thus $M=\sup S$, and an element of $S$ that equals the supremum is the maximum. Completeness guarantees $\sup S$ exists.

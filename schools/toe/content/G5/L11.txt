@article
**Conventions.** We simulate the Ising model $H = -J\sum_{\langle ij\rangle}s_is_j$ ($h=0$) on an $L\times L$ square lattice with periodic boundaries, $N = L^2$. We set $J = k_B = 1$, so temperature is measured in units of $J/k_B$ and $\beta = 1/T$; the exact critical temperature is $T_c = 2/\ln(1+\sqrt2) = 2.269$. One **sweep** is $N$ attempted updates. Per-spin observables are $e = E/N$ and $m = |\sum_is_i|/N$.

### Why sample

The sum over $2^N$ configurations cannot be done for $N\sim10^3$ or more. **Importance sampling** generates configurations $s_1, s_2,\dots$ with probability $\pi(s) = e^{-\beta E(s)}/Z$ and estimates $\langle A\rangle\approx\frac1M\sum_tA(s_t)$. The partition function $Z$ is never needed.

### Markov chains

Choose transition probabilities $W(s\to s')$ with $\sum_{s'}W(s\to s')=1$. Two properties give the right answer:

- **Ergodicity:** every configuration can be reached from every other in finitely many steps.
- **Stationarity of $\pi$.** A sufficient condition is **detailed balance**,
$$\pi(s)\,W(s\to s') = \pi(s')\,W(s'\to s) .$$

Summing over $s'$ shows that $\pi$ is then stationary. Detailed balance is sufficient but not necessary.

### Metropolis and heat bath

Propose flipping one randomly chosen spin and accept with probability $\min(1, e^{-\beta\Delta E})$. The proposal is symmetric, so $W(s\to s')/W(s'\to s) = e^{-\beta\Delta E} = \pi(s')/\pi(s)$. For the Ising model flipping spin $i$ changes the energy by

$$\Delta E = 2J\,s_i\sum_{j\in\text{nn}(i)}s_j \in \{-8,-4,0,4,8\}J .$$

Only the acceptance probabilities for $\Delta E = 4J$ and $8J$ are nontrivial, so they can be precomputed. The **heat-bath** rule instead draws $s_i$ from its conditional distribution, $P(s_i=+1) = 1/(1+e^{-2\beta J\sum_j s_j})$.

```python
import numpy as np
rng = np.random.default_rng(1)

def sweep(s, beta):
    L = s.shape[0]
    for _ in range(L * L):
        i, j = rng.integers(0, L, 2)
        nn = s[(i+1) % L, j] + s[(i-1) % L, j] + s[i, (j+1) % L] + s[i, (j-1) % L]
        dE = 2 * s[i, j] * nn                       # J = 1
        if dE <= 0 or rng.random() < np.exp(-beta * dE):
            s[i, j] = -s[i, j]

L, T = 16, 2.0
s = rng.choice([-1, 1], size=(L, L))                # hot start
m = []
for t in range(2000):
    sweep(s, 1.0 / T)
    m.append(abs(s.mean()))
```

### Equilibration

The chain starts from an arbitrary configuration, so the first sweeps are not distributed according to $\pi$. Run from two different starts (all spins up, and random), plot $e(t)$ and $m(t)$, and discard everything before the curves agree and fluctuate stationarily. Running averages that still drift signal that you are not equilibrated.

### Autocorrelation and error bars

Successive configurations are correlated. For an observable $A$ the normalized autocorrelation function is $\rho(t) = [\langle A_0A_t\rangle - \langle A\rangle^2]/[\langle A^2\rangle - \langle A\rangle^2]$ and the **integrated autocorrelation time** is

$$\tau_{\rm int} = \tfrac12 + \sum_{t\ge1}\rho(t),$$

summed up to a window where $\rho$ has decayed into noise. For $M$ measurements with variance $\sigma_A^2$, the error of the mean is

$$\delta\bar A = \sqrt{\frac{2\tau_{\rm int}\,\sigma_A^2}{M}},$$

i.e. only $M/(2\tau_{\rm int})$ samples are effectively independent. **Blocking** achieves the same without computing $\rho$: average over blocks much longer than $\tau_{\rm int}$ and take the standard error of the block means.

### Critical slowing down

Near $T_c$ the correlation length grows and local updates decorrelate slowly: $\tau\sim\xi^{z}\sim L^{z}$ with $z\approx2.2$ for Metropolis in 2D. **Cluster algorithms** (Wolff) grow a cluster of aligned spins, adding each aligned neighbour with probability $p = 1 - e^{-2\beta J}$, and flip it; this satisfies detailed balance and reduces $z$ to about $0.3$ or less in 2D, making simulations near $T_c$ feasible.

@example
title: Detailed balance for Metropolis
problem: Show that the Metropolis rule satisfies detailed balance for $\pi(s)\propto e^{-\beta E(s)}$.
step: Let $s\to s'$ flip one spin, with $\Delta E = E(s') - E(s)$. The proposal probability is the same in both directions (choose that site with probability $1/N$), so only the acceptance probabilities matter.
step: Case $\Delta E\le0$: the forward move is accepted with probability $1$. The reverse move has energy change $-\Delta E\ge0$ and is accepted with probability $e^{\beta\Delta E}$.
step: The ratio of transition probabilities is $W(s\to s')/W(s'\to s) = 1/e^{\beta\Delta E} = e^{-\beta\Delta E}$.
step: The Boltzmann ratio is $\pi(s')/\pi(s) = e^{-\beta\Delta E}$, so $\pi(s)W(s\to s') = \pi(s')W(s'\to s)$. The case $\Delta E>0$ is the same with the roles exchanged.

@example
title: Acceptance probabilities near $T_c$
problem: For the 2D Ising model at $T = 2.269$, find the acceptance probabilities for $\Delta E = 4$ and $8$, and for $T=1$.
step: At $T = 2.269$: $e^{-4/2.269} = e^{-1.763} = 0.171$.
step: $\Delta E = 8$: $e^{-8/2.269} = e^{-3.526} = 0.0294$.
step: At $T = 1$: $e^{-4} = 0.0183$ and $e^{-8} = 3.4\times10^{-4}$.
step: At low $T$ almost all attempted flips of spins with aligned neighbours are rejected, so many sweeps yield little change; at $T_c$ roughly one in six attempts that raise the energy by $4J$ is accepted, but the correlated clusters still make decorrelation slow.

@mistakes
- Using the new energy $E'$ instead of the difference $\Delta E$ in the acceptance rule.
- Estimating the error bar as $\sigma/\sqrt M$ with correlated data; it can be too small by a factor $\sqrt{2\tau_{\rm int}}$.
- Averaging over the initial transient without checking equilibration, which biases the mean.
- Believing that symmetric transition probabilities $W(s\to s') = W(s'\to s)$ give the Boltzmann distribution; they give the uniform one.

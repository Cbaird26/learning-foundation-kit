@article
**Conventions.** The lattice is $L^d$ with $N = L^d$ spins, periodic boundaries, $J = k_B = 1$ and $t = (T - T_c)/T_c$. In a finite system $\langle M\rangle = 0$ by symmetry, so we use $m = |M|/N$ or moments of the signed $M/N$. Define

$$\chi = \frac{N}{T}\big(\langle m^2\rangle - \langle |m|\rangle^2\big), \qquad C = \frac{N}{T^2}\big(\langle e^2\rangle - \langle e\rangle^2\big), \qquad U_L = 1 - \frac{\langle m^4\rangle}{3\langle m^2\rangle^2},$$

with $U_L$ the **Binder cumulant** of the signed magnetization per spin.

### Why finite size matters

For finite $L$ the partition function is a finite sum of exponentials, so nothing diverges: singularities become **rounded peaks** and the correlation length is cut off at $\xi\sim L$. The renormalization-group scaling of the singular free energy, $f_s(t,h,L^{-1}) = b^{-d}f_s(b^{y_t}t, b^{y_h}h, b/L)$, evaluated with $b = L$, gives

$$m = L^{-\beta/\nu}\,\mathcal M(tL^{1/\nu}), \qquad \chi = L^{\gamma/\nu}\,\mathcal X(tL^{1/\nu}), \qquad U_L = \mathcal U(tL^{1/\nu}).$$

Because $\xi\sim|t|^{-\nu}$, the scaling variable $tL^{1/\nu}$ is, up to a constant, $\pm(L/\xi)^{1/\nu}$: it measures the ratio of system size to correlation length. Consequences:

- At $T_c$: $m\sim L^{-\beta/\nu}$ and $\chi\sim L^{\gamma/\nu}$.
- The peak of $\chi$ (a pseudocritical point) sits at $T^*(L) = T_c + aL^{-1/\nu}$ and has height $\chi_{\max}\sim L^{\gamma/\nu}$.
- The specific-heat peak grows as $L^{\alpha/\nu}$; for $\alpha = 0$ in the 2D Ising model it grows as $\ln L$.
- $U_L$ is dimensionless, so at $t=0$ it is independent of $L$.

### The Binder cumulant

$U_L\to\frac23$ in the ordered phase (where $m^2$ is fixed and $\langle m^4\rangle = \langle m^2\rangle^2$) and $U_L\to0$ in the disordered phase (where $m$ is Gaussian and $\langle m^4\rangle = 3\langle m^2\rangle^2$). Curves of $U_L(T)$ for different $L$ therefore **cross near $T_c$** at a universal value ($U^*\approx0.61$ for the periodic 2D Ising model). For larger $L$ the slope at the crossing grows as $L^{1/\nu}$, so the crossing is sharp, and plotting $U_L$ against $tL^{1/\nu}$ collapses the curves.

### Practical analysis

```python
import numpy as np

def binder_chi(m_signed, T, N):
    m = np.asarray(m_signed)              # signed magnetization per spin, one entry per sweep
    m2, m4 = np.mean(m**2), np.mean(m**4)
    U = 1 - m4 / (3 * m2**2)
    chi = N * (m2 - np.mean(np.abs(m))**2) / T
    return U, chi
```

Estimate $T_c$ from crossings of $U_L$ for pairs $(L, 2L)$, then extract $\gamma/\nu$ from $\ln(\chi_{\max}(2L)/\chi_{\max}(L))/\ln2$. Corrections to scaling (irrelevant couplings) shift the crossings at small $L$, so fit with several $L$ and drop the smallest.

### Simulation length and critical slowing down

Both equilibration time and autocorrelation time at $T_c$ scale as $\tau\sim L^{z}$ with $z\approx2.2$ for Metropolis. Each sweep costs $L^d$ operations, so the cost of a run of fixed number of independent samples grows as $L^{d+z}$, a factor $2^{4.2}\approx18$ per doubling of $L$ in $d=2$. A defensible protocol: start from two initial states, discard at least a few $\tau_{\rm eq}$, measure $\tau_{\rm int}$, run for $M\gtrsim100\,\tau_{\rm int}$ sweeps, and quote errors from $\sqrt{2\tau_{\rm int}\sigma^2/M}$ or blocking.

### What mean field can say

Mean-field theory is an infinite-system, uniform-density prediction ($T_c = qJ$, $\beta = \frac12$, $\gamma = 1$). For a finite 2D lattice it gives the wrong $T_c$ ($4$ against $2.269$) and the wrong size dependence (the exact $\beta/\nu = 1/8$, not the mean-field $1$). Comparing the two is useful for diagnosing *where* fluctuations matter, such as the shift of the susceptibility peak and the failure of $m\sim|t|^{1/2}$, but not for quoting exponents.

@example
title: Locating $T_c$ from Binder crossings
problem: The following are simulated numbers for illustration. At $T = 2.25$ the cumulants are $U_{16} = 0.612$ and $U_{32} = 0.622$; at $T = 2.30$ they are $U_{16} = 0.590$ and $U_{32} = 0.568$. Estimate $T_c$ and $U^*$ by linear interpolation.
step: Between the two temperatures $U_{16}$ falls by $0.022$ and $U_{32}$ by $0.054$ over $\Delta T = 0.05$. The larger lattice has the steeper slope, as expected.
step: Write $x = T - 2.25$. Then $U_{16} = 0.612 - 0.44x$ and $U_{32} = 0.622 - 1.08x$.
step: The curves cross when $0.612 - 0.44x = 0.622 - 1.08x$, so $0.64x = 0.010$ and $x = 0.0156$, giving $T_c\approx2.266$.
step: At the crossing $U^* = 0.612 - 0.44(0.0156) = 0.605$, close to the known universal $0.61$. The exact $T_c = 2.269$ lies within the likely uncertainty of the estimate.

@example
title: Exponent from the size dependence at $T_c$
problem: Simulated magnetizations at $T_c$ are $m(16) = 0.840$ and $m(64) = 0.707$. Estimate $\beta/\nu$, and compare with the mean-field value.
step: At $T_c$, $m\sim L^{-\beta/\nu}$, so $\beta/\nu = -\ln[m(64)/m(16)]/\ln(64/16)$.
step: $m(64)/m(16) = 0.707/0.840 = 0.8417$, and $-\ln0.8417 = 0.1724$.
step: Dividing by $\ln4 = 1.386$ gives $\beta/\nu = 0.124$, consistent with the exact $1/8$ (with $\beta = 1/8$, $\nu=1$).
step: Mean-field exponents $\beta = \frac12$, $\nu = \frac12$ would give $\beta/\nu = 1$, a magnetization that falls by a factor $4$ from $L=16$ to $L=64$, not the observed $0.84$. The data decide against it.

@mistakes
- Using $\langle M\rangle$ in a finite system. It is zero by symmetry; use $|M|$ or moments of $M$.
- Reading $T_c$ off the susceptibility peak of a single lattice size, which is shifted by $L^{-1/\nu}$.
- Stopping a run after a fixed number of sweeps regardless of $L$ and $T$; near $T_c$ the autocorrelation time grows like $L^z$.
- Fitting scaling forms with only the smallest lattices, where corrections to scaling dominate.

choice: Because the magnetization vanishes at $T_c$ for every $L$, so all cumulants equal zero there.

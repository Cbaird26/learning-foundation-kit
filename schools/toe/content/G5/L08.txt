@article
**Conventions.** $f_s(t,h)$ is the singular part of the free energy per unit volume (with $\beta$ absorbed), $t = (T - T_c)/T_c$, $h$ is the field conjugate to $m = -\partial f/\partial h$, and exponents are equal on both sides of $T_c$. Last week's exponents were measured one at a time; scaling says they are not independent.

### The scaling hypothesis

Close to the critical point the only thing that matters is how far you are from it in the two relevant directions, $t$ and $h$. **Widom's hypothesis** is that $f_s$ is a generalized homogeneous function:

$$f_s(t,h) = |t|^{2-\alpha}\;\Phi_\pm\!\Big(\frac{h}{|t|^{\Delta}}\Big),$$

where $\Phi_+$ is used for $t>0$, $\Phi_-$ for $t<0$, and $\Delta$ is the **gap exponent**. This is equivalent to $f_s(\lambda^{a_t}t,\lambda^{a_h}h) = \lambda f_s(t,h)$ with $a_t = 1/(2-\alpha)$ and $a_h = \Delta/(2-\alpha)$. Week 9 will explain it with renormalization.

### Relations among exponents

Differentiate the scaling form. The magnetization is

$$m = -\frac{\partial f_s}{\partial h} \sim |t|^{2-\alpha-\Delta}\,\Phi'_\pm\!\Big(\frac{h}{|t|^\Delta}\Big) \quad\Rightarrow\quad \beta = 2 - \alpha - \Delta .$$

The susceptibility at $h=0$ is

$$\chi = \frac{\partial m}{\partial h}\Big|_{h=0}\sim|t|^{2-\alpha-2\Delta}\quad\Rightarrow\quad \gamma = 2\Delta + \alpha - 2 .$$

Adding, $\beta + \gamma = \Delta$. On the critical isotherm the argument $h/|t|^\Delta$ must grow so that $|t|$ drops out of $m$, giving $m\sim h^{\beta/\Delta}$ and hence $\delta = \Delta/\beta$. Eliminating $\Delta$:

$$\alpha + 2\beta + \gamma = 2 \quad(\text{Rushbrooke}),\qquad \gamma = \beta(\delta - 1)\quad(\text{Widom}).$$

Rushbrooke is an *inequality* ($\ge$) from thermodynamic stability alone; scaling makes it an equality.

### Correlation length and hyperscaling

The susceptibility is the integrated correlation function, $\chi = \int d^dr\,G(r)$ (Week 4). With $G(r)\sim r^{-(d-2+\eta)}$ up to $r\sim\xi$ this gives $\chi\sim\xi^{2-\eta}$, so

$$\gamma = \nu(2-\eta)\quad(\text{Fisher}).$$

If $\xi$ is the *only* length scale, the singular free energy per unit volume is one unit of $k_BT$ per correlation volume, $f_s\sim\xi^{-d}\sim|t|^{d\nu}$. Comparing with $|t|^{2-\alpha}$,

$$d\,\nu = 2 - \alpha\quad(\text{Josephson, or hyperscaling}).$$

Hyperscaling is the only relation that contains $d$. It holds for the true exponents of systems with $d<4$. Above $d=4$ the true exponents are the mean-field ones, for which $d\nu = d/2$ equals $2-\alpha = 2$ only at $d=4$, so hyperscaling fails there: the $u\,m^4$ coupling of Week 7 is a "dangerous irrelevant" variable.

### Data collapse

Scaling is also a practical test. Plot not $m(h,t)$ but $m/|t|^\beta$ against $h/|t|^{\beta\delta}$: all data fall on two universal curves (one for $t>0$, one for $t<0$) if the exponents are right. Adjusting $\beta$ and $\delta$ until the curves collapse is one way to measure them. The Landau equation of state collapses exactly:

```python
import numpy as np
a, b = 1.0, 2.0
def m_of(h, t):                      # real root of a t m + b m^3 = h
    r = np.roots([b, 0, a*t, -h])
    return r[abs(r.imag) < 1e-9].real.max()
for t in (0.1, 0.01, 0.001):
    h = 0.5 * t**1.5                 # fixed scaled field h / t^(3/2) = 0.5
    print(t, m_of(h, t) / t**0.5)    # the same scaled m for every t
```

Real data collapse only close to $T_c$: corrections to scaling spoil the collapse far from it.

@example
title: Testing the scaling relations
problem: Check Rushbrooke, Widom, Fisher and Josephson for (i) mean-field exponents in $d=3$ and (ii) the 3D Ising values $\alpha = 0.110$, $\beta = 0.326$, $\gamma = 1.237$, $\delta = 4.79$, $\nu = 0.630$, $\eta = 0.036$.
step: Mean field ($\alpha=0$, $\beta=\frac12$, $\gamma=1$, $\delta=3$, $\nu=\frac12$, $\eta=0$): $\alpha+2\beta+\gamma = 2$ ✓, $\beta(\delta-1) = 1 = \gamma$ ✓, $\nu(2-\eta) = 1 = \gamma$ ✓.
step: Josephson in mean field: $d\nu = 3/2$ but $2-\alpha = 2$. It fails for $d=3$ and holds only at $d=4$ where $d\nu = 2$.
step: 3D Ising: $\alpha + 2\beta + \gamma = 0.110 + 0.652 + 1.237 = 1.999 \approx 2$ ✓.
step: $\beta(\delta-1) = 0.326\times3.79 = 1.236\approx\gamma$ ✓ and $\nu(2-\eta) = 0.630\times1.964 = 1.237$ ✓.
step: $d\nu = 3\times0.630 = 1.890$ and $2-\alpha = 1.890$ ✓: hyperscaling holds because $d=3<4$. All four agree within the numerical uncertainty, so the six exponents have only two independent values.

@example
title: All exponents of the 2D Ising model from three inputs
problem: Given $d=2$, $\nu=1$, $\beta=1/8$ and $\delta=15$, use scaling relations to find $\gamma$, $\alpha$ and $\eta$.
step: Widom: $\gamma = \beta(\delta - 1) = \frac18\times14 = \frac74$.
step: Josephson: $\alpha = 2 - d\nu = 2 - 2 = 0$ (a logarithmic divergence in this case).
step: Fisher: $\eta = 2 - \gamma/\nu = 2 - \frac74 = \frac14$.
step: Check with Rushbrooke: $\alpha + 2\beta + \gamma = 0 + \frac14 + \frac74 = 2$ ✓.

@mistakes
- Treating the six exponents as independent. Scaling leaves only two independent ones, so a measured set that violates a relation signals a mistake or a nonasymptotic fit.
- Applying hyperscaling ($d\nu = 2-\alpha$) to mean-field exponents in $d<4$; it is the one relation that depends on $d$ and it fails there.
- Collapsing data with the wrong scaled variable: it is $h/|t|^{\beta\delta}$, not $h/|t|^\beta$, and the two sides of $T_c$ give two curves.
- Fitting scaling forms far from $T_c$ and attributing the failure of the collapse to wrong exponents rather than to corrections to scaling.

@practice self
prompt: Starting from $f_s(t,h) = |t|^{2-\alpha}\Phi_\pm(h/|t|^\Delta)$, derive $\beta = 2-\alpha-\Delta$ and $\gamma = 2\Delta + \alpha - 2$, and from them Rushbrooke's relation and $\delta = \Delta/\beta$.
hint: Differentiate with respect to $h$ once for $m$ and twice for $\chi$, then set $h=0$.
hint: For $\delta$, demand that $m$ becomes independent of $t$ at fixed small $h$ as $t\to0$.
solution: $m = -\partial_hf_s = -|t|^{2-\alpha-\Delta}\Phi'_\pm(h/|t|^\Delta)$. At $h=0$, $\Phi'_\pm(0)$ is a constant, so $m\sim|t|^{2-\alpha-\Delta}$ and $\beta = 2-\alpha-\Delta$. Then $\chi = \partial_hm|_{h=0}\sim|t|^{2-\alpha-2\Delta}\Phi''_\pm(0)$ and $\gamma = 2\Delta + \alpha - 2$. Adding: $\beta + \gamma = \Delta$. Eliminating $\Delta$ between the two expressions, $\alpha + 2\beta + \gamma = \alpha + 2(2-\alpha-\Delta) + 2\Delta + \alpha - 2 = 2$. On the critical isotherm $\Phi'(x)\sim x^{p}$ for large $x$; $m$ independent of $t$ requires $2-\alpha-\Delta - p\Delta = 0$, so $m\sim h^{p}$ with $p = (2-\alpha-\Delta)/\Delta = \beta/\Delta = 1/\delta$.
rubric: Obtains $\beta$ and $\gamma$ by differentiating the scaling form with respect to $h$.
rubric: Derives Rushbrooke's equality by eliminating $\Delta$ (or $\beta+\gamma=\Delta$).
rubric: Obtains $\delta = \Delta/\beta$ from the large-argument behaviour at $t=0$.
rubric: Notes that $\Phi'_\pm(0)$ and $\Phi''_\pm(0)$ are finite constants (assumption of analyticity in $h$ at fixed $t\ne0$).

@article
Geodesics describe how particles move. **Curvature** is the coordinate-independent answer to the question "is spacetime flat?". The Christoffel symbols cannot answer it, because they change with the coordinates.

### Curvature as non-commuting derivatives

Covariant derivatives of a vector do not commute, and the failure defines the **Riemann tensor**:
$$[\nabla_\mu, \nabla_\nu]\,V^\rho = R^\rho{}_{\sigma\mu\nu}\,V^\sigma .$$
With the convention fixed in Week 1,
$$R^\rho{}_{\sigma\mu\nu} = \partial_\mu \Gamma^\rho_{\nu\sigma} - \partial_\nu \Gamma^\rho_{\mu\sigma} + \Gamma^\rho_{\mu\lambda}\Gamma^\lambda_{\nu\sigma} - \Gamma^\rho_{\nu\lambda}\Gamma^\lambda_{\mu\sigma}.$$
Geometrically, carry a vector around a small closed loop by parallel transport: it returns rotated by an amount proportional to the curvature times the enclosed area.

**Flatness test.** $R^\rho{}_{\sigma\mu\nu} = 0$ everywhere in a region if and only if coordinates exist there in which $g_{\mu\nu} = \eta_{\mu\nu}$. This is a tensor equation, so it is true in all coordinates or none.

### Symmetries and counting

With all indices down, $R_{\rho\sigma\mu\nu} = g_{\rho\lambda}R^\lambda{}_{\sigma\mu\nu}$ satisfies
$$R_{\rho\sigma\mu\nu} = -R_{\sigma\rho\mu\nu} = -R_{\rho\sigma\nu\mu}, \qquad R_{\rho\sigma\mu\nu} = R_{\mu\nu\rho\sigma}, \qquad R_{\rho\sigma\mu\nu} + R_{\rho\mu\nu\sigma} + R_{\rho\nu\sigma\mu} = 0 .$$
The last is the first Bianchi identity. In $n$ dimensions these leave $n^2(n^2 - 1)/12$ independent components: $1$ for $n = 2$, $6$ for $n = 3$, and $20$ for $n = 4$. The **second Bianchi identity** is a differential statement,
$$\nabla_{\lambda}R_{\rho\sigma\mu\nu} + \nabla_{\rho}R_{\sigma\lambda\mu\nu} + \nabla_{\sigma}R_{\lambda\rho\mu\nu} = 0 .$$

### Contractions

$$R_{\mu\nu} = R^\rho{}_{\mu\rho\nu}, \qquad R = g^{\mu\nu}R_{\mu\nu}, \qquad G_{\mu\nu} = R_{\mu\nu} - \tfrac12 R\, g_{\mu\nu} .$$
The Ricci tensor is symmetric. Contracting the second Bianchi identity twice gives
$$\nabla^\mu G_{\mu\nu} = 0 ,$$
the identity that makes Einstein's equation consistent in Week 7. Ricci is a contraction, so it can vanish in a curved spacetime. Only the full Riemann tensor decides flatness.

### Worked case: the sphere, and tidal effects

For a sphere of radius $a$ the only independent component is $R_{\theta\phi\theta\phi} = a^2\sin^2\theta$. This gives $R_{\theta\theta} = 1$, $R_{\phi\phi} = \sin^2\theta$ and
$$R = \frac{2}{a^2} > 0 .$$
Positive curvature for a sphere is the check that you are using the same sign convention as this course.

Curvature is the tidal tensor. Two nearby free-falling particles with tangent $T^\mu$ and small separation $S^\mu$ obey the **geodesic deviation equation**
$$\frac{D^2 S^\mu}{d\tau^2} = R^\mu{}_{\nu\rho\sigma}\,T^\nu T^\rho\, S^\sigma ,$$
a relativistic version of the tidal acceleration of Week 2. In the Newtonian limit $R^i{}_{0j0} = \partial_i\partial_j\Phi$ (Week 8).

### Method for a given metric

1. Compute the inverse metric and $\Gamma$ (Week 3).
2. Compute $R^\rho{}_{\sigma\mu\nu}$ for the independent index sets only, using the symmetries.
3. Contract to $R_{\mu\nu}$ and $R$.
4. Check: Bianchi symmetries, expected sign for spheres, and known limits.

@example
title: The flat plane in polar coordinates has zero curvature
problem: For $ds^2 = dr^2 + r^2d\theta^2$, with $\Gamma^r_{\theta\theta} = -r$ and $\Gamma^\theta_{r\theta} = 1/r$, show that $R^r{}_{\theta r\theta} = 0$.
step: Write the definition with $\rho = r$, $\sigma = \theta$, $\mu = r$, $\nu = \theta$: $R^r{}_{\theta r\theta} = \partial_r\Gamma^r_{\theta\theta} - \partial_\theta\Gamma^r_{r\theta} + \Gamma^r_{r\lambda}\Gamma^\lambda_{\theta\theta} - \Gamma^r_{\theta\lambda}\Gamma^\lambda_{r\theta}$.
step: $\partial_r\Gamma^r_{\theta\theta} = \partial_r(-r) = -1$, and $\partial_\theta\Gamma^r_{r\theta} = 0$.
step: $\Gamma^r_{r\lambda} = 0$ for every $\lambda$, so the third term vanishes. In the fourth term only $\lambda = \theta$ contributes: $\Gamma^r_{\theta\theta}\Gamma^\theta_{r\theta} = (-r)(1/r) = -1$.
step: Total: $-1 - 0 + 0 - (-1) = 0$. By the symmetries the other components vanish too, so the plane is flat even though $\Gamma \neq 0$ in these coordinates.

@example
title: Ricci scalar of the unit 2-sphere
problem: For $ds^2 = d\theta^2 + \sin^2\theta\,d\phi^2$, with $\Gamma^\theta_{\phi\phi} = -\sin\theta\cos\theta$ and $\Gamma^\phi_{\theta\phi} = \cot\theta$, find $R$.
step: $R^\theta{}_{\phi\theta\phi} = \partial_\theta\Gamma^\theta_{\phi\phi} - \partial_\phi\Gamma^\theta_{\theta\phi} + \Gamma^\theta_{\theta\lambda}\Gamma^\lambda_{\phi\phi} - \Gamma^\theta_{\phi\lambda}\Gamma^\lambda_{\theta\phi}$. Here $\Gamma^\theta_{\theta\lambda} = 0$ and $\partial_\phi\Gamma^\theta_{\theta\phi} = 0$.
step: $\partial_\theta\Gamma^\theta_{\phi\phi} = -\cos^2\theta + \sin^2\theta$ and $\Gamma^\theta_{\phi\phi}\Gamma^\phi_{\theta\phi} = -\cos^2\theta$. So $R^\theta{}_{\phi\theta\phi} = (\sin^2\theta - \cos^2\theta) + \cos^2\theta = \sin^2\theta$.
step: Contract: $R_{\phi\phi} = R^\theta{}_{\phi\theta\phi} = \sin^2\theta$. Using the pair symmetry, $R_{\theta\theta} = g^{\phi\phi}R_{\phi\theta\phi\theta} = \dfrac{1}{\sin^2\theta}\,\sin^2\theta = 1$.
step: $R = g^{\theta\theta}R_{\theta\theta} + g^{\phi\phi}R_{\phi\phi} = 1 + 1 = 2$. For radius $a$ the metric scales by $a^2$ and $R = 2/a^2$. The result is positive, as our convention requires.

@mistakes
- Using a different sign convention for the Riemann tensor without noticing: the check is that a sphere has $R > 0$ here.
- Concluding that spacetime is flat because $R_{\mu\nu} = 0$. Ricci-flat spacetimes with gravitational fields exist (Week 9).
- Deducing curvature from $\Gamma \neq 0$, or flatness from $\Gamma(P) = 0$ at a single point.
- Treating all $n^4$ components of the Riemann tensor as independent, instead of using the symmetries to compute only $n^2(n^2-1)/12$ of them.

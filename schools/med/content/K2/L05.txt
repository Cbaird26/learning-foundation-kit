@lesson
title: The meaning of multiplication
summary: Use equal groups, repeated addition and arrays to understand what multiplication means.
objective: Tell when objects are in equal groups.
objective: Write repeated addition as a multiplication.
objective: Draw an array and find how many are in it.
reading: Khan Academy, 3rd grade math: look up the topic "Intro to multiplication".

@article
### Equal groups

Look at 3 baskets with 5 apples in each basket. Each basket has the **same** number. These are **equal groups**.

We can add: $5 + 5 + 5 = 15$. That is called **repeated addition**.

There is a faster way to write it. We say "3 groups of 5" and write

$$3 \times 5 = 15.$$

The sign $\times$ is read "times." The first number tells how many groups. The second number tells how many are in each group. The answer is called the **product**.

### Arrays

An **array** puts objects in neat rows and columns. Think of eggs in a carton or windows on a building. Rows go across. Columns go up and down.

Here is an array with 2 rows and 4 columns:

- Row 1: 4 dots
- Row 2: 4 dots

Each row is a group of 4, and there are 2 rows. So $2 \times 4 = 8$ dots.

### Not equal groups

If one plate has 3 cookies and another plate has 5 cookies, the groups are not equal. We cannot use multiplication for that. We add instead: $3 + 5 = 8$.

### Skip counting helps

To find 4 groups of 3, skip count by 3 four times: 3, 6, 9, 12. So $4 \times 3 = 12$.

@example
title: Equal groups
problem: There are 3 baskets with 5 apples in each basket. How many apples are there in all?
step: The groups are equal. There are 3 groups with 5 in each group.
step: Write it as repeated addition: $5 + 5 + 5 = 15$.
step: Write it as multiplication: $3 \times 5 = 15$. There are 15 apples.

@mistakes
- Using multiplication when the groups are not equal.
- Mixing up the two numbers, so that 3 groups of 5 is drawn as 5 groups of 3. The answer is the same, but the picture is different.
- Skip counting too far or stopping too soon.

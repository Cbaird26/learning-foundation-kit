# Metaphysics Learning Foundation

**Open the school:** https://cbaird26.github.io/metaphysics-learning-foundation/

A Khan Academy-style self-study school: 63 courses in five stages, from kindergarten through a complete college
philosophy degree with a concentration in metaphysics to graduate study and research — elementary, middle and high
school (including philosophy for children, reasoning well, a first course in the big questions, an introduction to
philosophy, logic and critical reasoning, and ethics), the philosophy degree (symbolic logic, logic and computation
with Python, ancient, medieval, early modern, Kantian and nineteenth-century philosophy, ethics, epistemology,
philosophy of mind, two courses in metaphysics, philosophy of language, science, physics and religion, twentieth-century
analytic philosophy, phenomenology, existentialism and process philosophy, world philosophies, metalogic and modal
logic), and graduate study (contemporary metaphysics, mind, consciousness and AI, the metaphysics of science and
physics, formal methods, philosophical research and writing, and qualifying exams and the dissertation prospectus).

Each course has 12 weekly lessons (an article, worked examples, common mistakes, and auto-graded practice and quiz
questions), a week 13–14 project with a review guide, and a cumulative final exam. Skills move through mastery levels
with unit quizzes, a midterm and course challenges, and missed questions go into an error log that brings back a
parallel problem 48 hours later.

## Python in the page

The logic courses include Python exercises that run real Python in the browser, with nothing to install: the page
includes Brython, which follows Python 3.14, with CPython's own json package. Press Run to try code and Check to grade
it against the exercise's tests; a program that runs too long is stopped after a few seconds. Lesson code that runs
here has a "Try it" button, and the Python tab is a scratchpad. The browser's Python has the whole language and most of
the standard library (including itertools, functools, fractions and math), but not threads, networking or third-party
packages. Your code is never uploaded.

## Using it

Open the site in any modern browser. The whole school is one self-contained page (`index.html`), so you can also save
the page and use it offline.

Progress and the error log are kept only in your own browser and are never uploaded. Keep using the same browser and do
not clear its site data; another browser or device starts fresh. The Tutor button prepares a prompt you can copy into a
chat with Claude.

## Accuracy and fairness

Every course was written and then independently reviewed. Every numeric, truth-table and typed answer was checked
against an independent computation, every Python exercise's model solution was run against its tests both in standard
Python and in the browser's Python, and every "what does this print?" answer was produced by running the program. On
contested questions, including questions about God and religion, the lessons present the main views and the strongest
arguments on each side and do not tell learners what to believe. Quotations come only from public-domain texts;
everything else is paraphrased. Facts about PhD programs and the academic job market vary and change, so check current
details with each program. Self-study scores do not award credit, degrees or any credential.

@article
Many programs answer a question about a whole collection: *how much in total?*, *how many?*, *which is biggest?* Python answers all three with the same pattern, the **accumulator loop**: a variable that starts with a sensible value and is updated once for every item.

### Totals

```python
prices = [4, 10, 3]
total = 0              # 1. start the accumulator
for p in prices:       # 2. visit every item
    total = total + p  # 3. update the accumulator
print(total)           # 4. use the result after the loop
```

The accumulator `total` is `0` before the loop, then `4`, `14` and `17`. The `print` is **not** indented, so it runs once, after the loop. Indent it and it runs on every pass, printing `4`, `14` and `17`.

### Counts

Counting is a total in which each item adds either 1 or 0. Start at `0` and add 1 only when a condition holds:

```python
count = 0
for p in prices:
    if p > 5:
        count += 1
```

`count += 1` is shorthand for `count = count + 1`.

### The largest value

To find a maximum, the accumulator holds the **largest value seen so far**. Starting it at `0` is a classic bug: for the list `[-8, -3, -5]` the answer would wrongly be `0`, a value that is not even in the list. Start instead with the first item, then compare each item with the best so far:

```python
best = nums[0]
for n in nums:
    if n > best:
        best = n
```

This needs a non-empty list, because `nums[0]` raises `IndexError` on `[]`. A function should say what it does in that case.

### Built-ins

Python's built-in `sum`, `len` and `max` do these jobs for you, and in real programs you should use them. Writing the loops yourself is how you learn the pattern, and the pattern also handles questions the built-ins cannot, such as "the total of the even numbers" or "the longest word".

@example
title: Tracing an accumulator loop
problem: What does this program print?

```python
nums = [2, 7, 1, 8]
total = 0
for n in nums:
    if n % 2 == 0:
        total += n
print(total)
```
step: Before the loop, `total` is `0`.
step: `n = 2`: `2 % 2 == 0` is true, so `total` becomes `2`.
step: `n = 7`: odd, so nothing changes. `n = 1`: odd again.
step: `n = 8`: even, so `total` becomes `2 + 8 = 10`.
step: The `print` is outside the loop, so it runs once and prints `10`.
answer: `10`

@example
title: Writing a counting function
problem: Write `count_long(words, n)` that returns how many strings in `words` have more than `n` characters.
step: The answer is a count, so start an accumulator at `0`.
step: Visit every word with `for w in words:`.
step: Add 1 only when the condition holds: `if len(w) > n: count += 1`.
step: Return the count after the loop:

```python
def count_long(words, n):
    count = 0
    for w in words:
        if len(w) > n:
            count += 1
    return count
```
step: Check it: `count_long(["hi", "hello", "hey"], 2)` visits 2, 5 and 3 characters and counts the last two, so it returns `2`.

@mistakes
- Starting a maximum at `0`, which gives a wrong answer when every value is negative.
- Indenting the final `print` or `return` inside the loop, so it runs on the first pass instead of after the loop.
- Resetting the accumulator inside the loop (`total = 0` as the first line of the loop body), so it forgets the earlier items.
- Writing `total + p` without assigning it back to `total`, so the accumulator never changes.

```python
def total(nums):
    result = 0

        result = result + n
    return result
```

```python
def count_above(nums, limit):
```

```python
def count_above(nums, limit):

    return count
```
hint: A count is a total in which each item adds 1 or nothing.

@practice mc
prompt: This function is meant to return the largest number in a non-empty list.

```python
def largest(nums):
    best = 0
    for n in nums:
        if n > best:
            best = n
    return best
```

For which list does it return the wrong answer?
choice: `[3, 9, 4]`
choice: `[0, 0, 0]`
choice*: `[-8, -3, -5]`
choice: `[7]`
hint: What happens when no item is bigger than the starting value of `best`?
solution: With `[-8, -3, -5]` no item is greater than `0`, so `best` stays `0` and the function returns `0`, which is not in the list. Starting with `best = nums[0]` fixes it. For `[0, 0, 0]` the answer `0` happens to be correct.

```python
def largest(nums):

```

```python
assert largest([3, 9, 4]) == 9

```

```python
def largest(nums):
    best = nums[0]
    for n in nums[1:]:

            best = n
    return best
```
hint: Start the accumulator with an item from the list, not with `0`.

@quiz num
prompt: How many times does the line `count += 1` run when this program runs?

```python
count = 0
for word in ["sun", "moon", "star", "sky"]:
    if len(word) == 4:
        count += 1
```
answer: 2
check: int(run("count = 0\nfor word in ['sun', 'moon', 'star', 'sky']:\n    if len(word) == 4:\n        count += 1\nprint(count)\n"))
hint: The line runs only for words with exactly four letters.
solution: Only `moon` and `star` have four letters, so `count += 1` runs twice and `count` ends at `2`.

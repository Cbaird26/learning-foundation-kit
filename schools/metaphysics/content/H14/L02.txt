@article
Consider two arguments. First: "All cats can fly. Felix is a cat. So Felix can fly." Second: "Felix has been a healthy cat for years and the vet says he is fine. So he will probably still be healthy next month." The first has a false premise but there is something right about it: if the premises were true, the conclusion would have to be true. The second has true premises, but the conclusion is only likely. Logic gives us words to describe these differences.

### Deductive arguments: validity and soundness

An argument is **valid** when it is impossible for all the premises to be true and the conclusion false. Validity concerns only the link between premises and conclusion, not whether the premises are actually true. The cat argument above is valid. An argument is **sound** when it is valid and all its premises are true. Only a sound argument guarantees a true conclusion. A valid argument with a false premise may have a true or a false conclusion, and an invalid argument can have all true premises and a true conclusion by accident.

To show that an argument is **invalid**, give a **counterexample**: a possible situation in which the premises are true and the conclusion false. Validity depends on form. Two valid forms to know:

| P1 | If $P$, then $Q$. |
| P2 | $P$. |
| C | So $Q$. |

This is **modus ponens**. **Modus tollens** is: if $P$ then $Q$; not $Q$; so not $P$. Two tempting invalid forms are **affirming the consequent** (if $P$ then $Q$; $Q$; so $P$) and **denying the antecedent** (if $P$ then $Q$; not $P$; so not $Q$). "If it rained, the grass is wet. The grass is wet. So it rained" fails because the sprinkler might have made the grass wet.

### Inductive arguments: strength and cogency

An **inductive** argument aims only to make its conclusion probable. It is **strong** when, if the premises were true, the conclusion would be likely, and **weak** otherwise. A strong argument with true premises is **cogent**. Strength comes in degrees and can change with new evidence: a sample of five students is a weaker basis for a claim about a school than a well-chosen sample of five hundred.

### Reconstructing arguments

Real arguments are rarely tidy. To **reconstruct** one in standard form: find the conclusion; list the premises in plain, complete sentences; delete rhetoric and repetition; and if the argument is not valid as stated, consider an **implicit (hidden) premise** that would make it valid and that the speaker plausibly accepts. Add it only when it is a fair reading, and label it clearly. Then evaluate: Is it valid? Are the premises true? Which premise would you challenge?

Here is a short argument: "Since lying makes people distrust you, you should never lie." Its conclusion is "You should never lie." The stated premise is "Lying makes people distrust you." To make it valid you would need something like "You should never do anything that makes people distrust you." Once that premise is on the table, you can see what to question: perhaps some lies, such as keeping a surprise party secret, do not breed distrust at all.
@example
title: Testing validity with a counterexample
problem: Is this argument valid? "If a number is divisible by 4, it is even. This number is even. So it is divisible by 4."
step: Identify the form: if $P$ then $Q$; $Q$; so $P$. That is affirming the consequent.
step: Look for a possible case in which both premises are true and the conclusion is false. Take the number 6.
step: Six is even, so the second premise holds for it, and the first premise is true of every number. But 6 is not divisible by 4. So the conclusion is false.
step: A counterexample exists, so the argument is invalid. (Its premises and conclusion may each be true of some numbers; validity asks about every possible case.)
answer: Invalid; the number 6 is a counterexample.
@example
title: Reconstructing a prose argument
problem: Put this in standard form and find a hidden premise: "Our town should build a bike lane on Pine Street, because it would reduce car traffic."
step: The conclusion is "Our town should build a bike lane on Pine Street." The stated reason is "A bike lane on Pine Street would reduce car traffic."
step: As stated, nothing links reducing traffic to what the town should do. Add a premise that would link them: "Our town should do what reduces car traffic."
step: The reconstruction is below. Now it is valid.

| P1 | A bike lane on Pine Street would reduce car traffic. |
| P2 | (Implicit) Our town should build whatever would reduce car traffic. |
| C | So our town should build a bike lane on Pine Street. |
step: Evaluate: P2 is doubtful, since reducing traffic might not be worth the cost. The reconstruction shows exactly where a critic should push.
answer: The hidden premise links reducing traffic to what the town should do; P2 is the weak point.
@mistakes
- Saying an argument is invalid because its conclusion is false: validity is about the link. A valid argument can have a false conclusion if a premise is false.
- Saying an argument is valid because its premises are true: true premises and true conclusion do not guarantee that the conclusion follows.
- Calling a good argument "valid" when the arguer only means it is persuasive: in logic, validity is a precise term.
- Adding a hidden premise that does all the work or that the speaker would reject: add the most modest premise the speaker plausibly accepts, and label it.

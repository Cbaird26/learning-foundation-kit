@article
Many stories use equal groups. Look for three things: **how many groups**, **how many in each group**, and **how many in all**.

### Know two, find the third

- If you know the groups and the number in each group, **multiply** to find the total.
- If you know the total and the number of groups, **divide** to find how many in each group.
- If you know the total and the number in each group, **divide** to find how many groups.

### Steps for any story

1. Read the story slowly. Say it in your own words.
2. Draw a picture, such as circles with dots inside.
3. Write a number sentence. Use a box or letter for the number you do not know.
4. Solve it and write the answer in a sentence.
5. Check that the answer makes sense.

### Examples of each kind

- *Multiplying:* 5 vases have 3 flowers in each vase. $5 \times 3 = 15$ flowers.
- *Dividing to share:* 18 marbles go in 3 bags. $18 \div 3 = 6$ marbles in each bag.
- *Dividing to make groups:* 18 marbles go in bags of 6. $18 \div 6 = 3$ bags.

### Make your own

A good story has equal groups, a question and a number you must find. For example: "Maya has 4 boxes. Each box has 5 crayons. How many crayons does she have?" The number sentence is $4 \times 5 = 20$.

@example
title: Multiply to find the total
problem: There are 5 vases with 3 flowers in each vase. How many flowers are there in all?
step: There are 5 groups with 3 in each group. We know the groups and the size of each group.
step: Multiply: $5 \times 3 = 15$. There are 15 flowers.

@example
title: Divide to find the size of a group
problem: 18 marbles are put in 3 bags, with the same number in each bag. How many marbles are in each bag?
step: We know the total (18) and the number of groups (3). We need the number in each group.
step: Divide: $18 \div 3 = 6$.
step: Check: $3 \times 6 = 18$. Each bag has 6 marbles.

@mistakes
- Adding the two numbers in the story when the story is about equal groups.
- Dividing when you should multiply, or the other way around. Ask what you know and what you need to find.
- Not checking that the answer makes sense. Fewer groups of the same size should give a smaller total.

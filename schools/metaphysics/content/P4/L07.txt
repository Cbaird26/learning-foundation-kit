@article
"Socrates is wise." "Wisdom is a virtue." "Everything Ann said is true." Each sentence quantifies, or could be taken to quantify, into a position that first-order logic reserves for names: a predicate position in "Socrates has some property that Plato lacks", a sentence position in "Ann said something true". **Higher-order metaphysics** takes these quantifiers at face value and asks what they show about the structure of reality. This lesson first fixes the formal system, simple type theory, and then examines the philosophical argument.

### Simple type theory

Following Church's simple theory of types, the **types** are built from two basic types, $e$ (individuals) and $t$ (truth values, or propositions), by the rule: if $\sigma$ and $\tau$ are types then so is $\sigma \to \tau$, the type of functions from $\sigma$-things to $\tau$-things. Predicates and connectives are curried functions:

| one-place predicate, "is wise" | $e \to t$ |
| two-place relation, "loves" | $e \to (e \to t)$ |
| negation | $t \to t$ |
| conjunction | $t \to (t \to t)$ |
| the existential quantifier over individuals | $(e \to t) \to t$ |
| a quantifier over properties of individuals | $((e \to t) \to t) \to t$ |
| propositional quantifier $\forall p$ | $(t \to t) \to t$ |

Terms are variables, constants, **applications** $(MN)$, where $M$ has type $\sigma \to \tau$ and $N$ has type $\sigma$, giving type $\tau$, and **abstractions** $\lambda x^\sigma.M$ of type $\sigma \to \tau$ when $M$ has type $\tau$. The two basic conversion rules are **beta-conversion**, $(\lambda x.M)N = M[N/x]$ with $N$ substituted for the free occurrences of $x$ (renaming bound variables to avoid capture), and **eta-conversion**, $\lambda x.(Mx) = M$ when $x$ is not free in $M$. A quantifier over objects of type $\sigma$ is a constant of type $(\sigma \to t) \to t$ and $\forall x^\sigma\,\varphi$ abbreviates $\forall(\lambda x.\varphi)$. A language is **first-order** if it quantifies only at type $e$, **second-order** if also at $e \to t$ and its relatives, and so on.

### Full frames and counting

A **full frame** over a nonempty domain $D$ sets $D_e = D$, $D_t = \{0,1\}$ and $D_{\sigma \to \tau}$ equal to the set of all functions from $D_\sigma$ to $D_\tau$, so that

$$\lvert D_{\sigma \to \tau}\rvert = \lvert D_\tau\rvert^{\lvert D_\sigma\rvert}.$$

With $\lvert D\rvert = n$ individuals, $\lvert D_{e \to t}\rvert = 2^n$ and $\lvert D_{(e \to t) \to t}\rvert = 2^{2^n}$, which is why full semantics outruns any set of formulas. A **Henkin frame** takes designated subsets of these function spaces. In a full frame the Leibniz definition of identity at type $t$, $p = q := \forall X^{t \to t}\,(Xp \to Xq)$, comes to this: $p$ and $q$ have the same truth value, because $D_t$ has only two elements. Intensional frames take $D_t$ to be a Boolean algebra of propositions, such as the subsets of a set of worlds, and then identical propositions are necessarily equivalent ones. Lesson 9 asks for frames fine enough to distinguish necessary equivalents.

### Is higher-order quantification ontologically committing?

The Quinean objection to second-order logic (Lesson 6) can be set out as an argument:

| P1 | Every quantifier ranges over entities, and a true quantified sentence $\exists \xi\,\varphi$ commits one to entities of the kind the variable $\xi$ ranges over. |
| P2 | "Socrates has some property" is a true sentence containing a quantifier $\exists X$ binding a predicate position. |
| C | So the sentence commits one to entities, properties, of the kind $X$ ranges over. |

It is valid. The replies are the heart of the debate. Prior's work on quantification into sentence position suggested that such quantifiers are not quantification over objects named by nouns, and Williamson and others have defended higher-order quantification as a sui generis form of generality. They deny P1 in its generality: the commitment of $\exists x$ to objects is a fact about first-order quantifiers, and a higher-order quantifier carries no such commitment. Their opponents reply that without a regimentation of the English that does not use nouns, the denial is only a claim of faith.

### A Cantorian argument

A different challenge says that, if you read higher-order quantification as first-order quantification over objects, you get paradox.

| P1 | If quantifying over properties of individuals were first-order quantification over individuals, then there would be a one-to-one map from the properties of individuals into the individuals. |
| P2 | There is no one-to-one map from the collection of all subsets of a domain into the domain. |
| C | So quantifying over properties of individuals is not first-order quantification over individuals. |

It is valid (modus tollens). P2 is Cantor's theorem, which holds for the full frame, so the argument assumes that the properties of individuals are as numerous as the subsets of the domain. Someone who restricts properties to the definable ones, or who takes a Henkin frame, can resist P2. The formal lesson is a recurring pattern in this course: an apparently innocent semantic choice, here the choice of frame, decides a metaphysical question, and an argument is only as good as the semantics it presupposes.

@example
title: Typing and reducing terms
problem: Let $a$ have type $e$, $L$ type $e \to (e \to t)$ and $F$ type $e \to t$. Give the type of $\lambda x.\,Lxa$, and reduce $(\lambda X.\,Xb)(\lambda y.\,Lya)$ to a term without abstractions. (Here $X$ has type $e \to t$.)
step: $L$ takes an individual and gives a function $e \to t$. So $Lx$ has type $e \to t$ when $x$ has type $e$, and $Lxa$, which applies it to $a$, has type $t$. The abstraction $\lambda x.\,Lxa$ therefore has type $e \to t$: it is the property that $x$ has when $L$ holds between $x$ and $a$.
step: The term $(\lambda X.\,Xb)(\lambda y.\,Lya)$ applies a function of type $(e \to t) \to t$ to an argument of type $e \to t$, so it has type $t$.
step: Beta-reduce: replace $X$ by $\lambda y.\,Lya$ in $Xb$ to get $(\lambda y.\,Lya)\,b$.
step: Beta-reduce again: replace $y$ by $b$ in $Lya$ to get $Lba$.
answer: $\lambda x.\,Lxa$ has type $e \to t$, and the second term reduces to $Lba$, of type $t$.

@example
title: Counting objects of each type
problem: A full frame has $2$ individuals. How many objects are there of types $e \to t$, $(e \to t) \to t$ and $e \to (e \to t)$?
step: $\lvert D_e \rvert = 2$ and $\lvert D_t \rvert = 2$. Type $e \to t$ has $2^2 = 4$ objects: the four subsets of the domain.
step: Type $(e \to t) \to t$ maps each of the $4$ properties to a truth value, giving $2^4 = 16$ objects.
step: Type $e \to (e \to t)$ maps each of 2 individuals to one of the 4 properties, giving $4^2 = 16$ objects, the binary relations.
answer: 4, 16 and 16 objects respectively.

@mistakes
- Reading $e \to (e \to t)$ and $(e \to e) \to t$ as the same type. The first is a curried binary relation, the second a property of functions on individuals.
- Counting $\lvert D_{\sigma \to \tau}\rvert$ as $\lvert D_\sigma\rvert^{\lvert D_\tau\rvert}$, the wrong way round. There are $\lvert D_\tau\rvert$ choices for each of the $\lvert D_\sigma\rvert$ arguments.
- Treating higher-order logic as first-order logic over a domain that includes properties. The difference between the two readings is exactly what Quine's and Cantor's arguments are about.
- Substituting without avoiding variable capture in beta-reduction.

@practice num
prompt: A full frame has $3$ individuals. How many objects does it contain of type $e \to (e \to t)$, the curried binary relations?
answer: 512
unit: objects
check: len(list(itertools.product([0, 1], repeat=3))) ** 3
hint: Each individual is sent to a property, and there are $2^3$ properties.
solution: There are $2^3 = 8$ objects of type $e \to t$. A function from the 3 individuals to these 8 properties can be chosen in $8^3 = 512$ ways, which equals $2^9$, the number of binary relations on a 3-element set.

prompt: Evaluate the Cantorian argument that higher-order quantification over properties of individuals cannot be first-order quantification over individuals (it appeals to Cantor's theorem that no one-to-one map takes all the subsets of a domain into the domain). State which premise a defender of "properties as individuals" should deny and say what that costs.
hint: Ask what P2 assumes about how many properties there are.
solution: The argument: P1 if quantifying over properties of individuals were first-order quantification over individuals, there would be an injection from properties to individuals. A defender should deny P2, not as a theorem, but as applied: the theorem concerns all subsets, so the defender must hold that there are fewer properties than subsets, for instance only definable or only sparse properties, or use a Henkin frame.

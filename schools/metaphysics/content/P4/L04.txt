@article
Is there a smallest part of every material thing? Is there a largest whole, to which everything belongs? The formal vocabulary is simple. An **atom** is a thing with no proper parts: $Atom(x) := \neg\exists y\,PPyx$. **Atomism** says that every thing has an atom as a part: $\forall x\,\exists y\,(Atom(y) \wedge Pyx)$. **Gunk**, in Lewis's term, is a thing all of whose parts have proper parts, and a world is **gunky** when everything is gunk: $\forall x\,\exists y\,PPyx$. The dual notion is **junk**, a term used by Schaffer and by Bohn: a world is **junky** when every thing is a proper part of something, $\forall x\,\exists y\,PPxy$, so that there is no largest whole.

### Finite models are atomistic

**Theorem 1.** In every finite nonempty model of ground mereology, every element has an atom as a part. In particular no finite model is gunky.

*Proof.* Let $x$ be an element and let $X$ be the set of its parts, which is finite and nonempty since $Pxx$. Suppose no member of $X$ is an atom. Then each member of $X$ has a proper part, which is also in $X$ by transitivity. Starting from $x$ we can form a sequence $x = x_0, x_1, x_2, \ldots$ with $PPx_{i+1}x_i$ each time. By transitivity of $PP$ (Lesson 1, Theorem 1) $PPx_jx_i$ whenever $j > i$, and by irreflexivity no element repeats. A finite set cannot contain an infinite sequence without repetition, a contradiction. So some member of $X$ is an atom. $\square$

The same argument run upward shows that every finite nonempty model has a maximal element. So gunk and junk, if possible at all, need infinite models, and a finite Python check can only detect their absence.

### A gunky model

Let $G$ consist of the **dyadic intervals** $[k/2^n,\,(k+1)/2^n)$ for $n \geq 0$ and $0 \leq k < 2^n$, ordered by inclusion. Each interval has two halves of the next level, so $G$ is gunky. It satisfies the axioms of M, and also strong supplementation: if $I \not\subseteq J$ then either $I$ and $J$ are disjoint, in which case $I$ itself is disjoint from $J$, or $J$ is a proper subinterval of $I$, in which case the half of $I$ not containing $J$ is a part of $I$ disjoint from $J$. But $G$ fails unrestricted composition: no dyadic interval is the fusion of $[0,1/4)$ and $[1/2,3/4)$. A model of full CEM with gunk exists too: the nonempty regular open subsets of the real line, ordered by inclusion, are a complete atomless Boolean algebra with zero deleted. So **CEM is consistent with gunk and with atomism**, and settles neither.

### Unrestricted composition rules out junk

**Theorem 2.** In M + SSP + UC there is a thing of which nothing is a proper whole: no model is junky.

*Proof.* Apply UC to the condition $x = x$ to get a fusion $u$ of everything. By the result of Lesson 2 every thing is part of $u$. Suppose $PPuy$. Then $Pyu$ since $y$ is something, and $Puy$, so $u = y$ by antisymmetry, contradicting $u \neq y$. $\square$

The argument from possible junk, aimed at classical mereology, is then short:

| P1 | If unrestricted composition holds necessarily, then necessarily there is no junk. |
| P2 | Possibly there is junk. |
| C | So unrestricted composition does not hold necessarily. |

It is valid by modus tollens in the form $\Box(UC \to \neg Junk)$, $\Diamond Junk \vdash \neg\Box UC$. P1 is Theorem 2 plus necessitation. Defenders of UC deny P2: an infinite ascending hierarchy of ever-larger wholes might be held to be metaphysically impossible, or to be only apparent if some "universe" always exists. The case for P2 is the thought that nothing in the idea of parthood rules out a world with no top.

### Dropping extensionality

The statue and the clay push the other way: some philosophers want distinct things with the same proper parts. Consider the model $B$ with four elements $a$, $b$, $x$, $y$, where $a$ and $b$ are atoms and both are the only proper parts of each of $x$ and $y$ (and $x$, $y$ are not parts of each other). It is a model of M, and it satisfies WSP: the proper part $a$ of $x$ has the disjoint part $b$, and symmetrically for the others. But SSP fails: $x$ is not part of $y$, yet every part of $x$ overlaps $y$. Extensionality of proper parts fails, and so does the uniqueness of fusions: both $x$ and $y$ are fusions of $\{a,b\}$ in the overlap sense of Lesson 2. Thomson and Fine, among others, have developed non-extensional theories, and Simons's *Parts* surveys the alternatives. A different kind of revision gives up antisymmetry itself, and a few authors, Cotnoir among them, have studied what is left of mereology without it.

The price of dropping SSP is that fusions are no longer determined by their parts, so "the sum of the $\varphi$s" is not a definite description. The attraction is that sortal and modal differences between the statue and the clay need no appeal to a hidden part. Formal work here is largely model-building: which combination of principles is consistent, and what each of them forces.

@example
title: Counting in a truncated gunky model
problem: Let $T$ be the dyadic intervals of levels $n = 0, 1, 2, 3$ (lengths $1, 1/2, 1/4, 1/8$), ordered by inclusion. How many elements does it have, which are the atoms, and how many ordered proper-part pairs does it have?
step: Level $n$ has $2^n$ intervals, so the number of elements is $1 + 2 + 4 + 8 = 15$.
step: An interval has a proper part exactly when it has halves in the model, which holds for levels $0, 1, 2$ but not for level $3$. So the atoms are the $8$ intervals of length $1/8$. Truncating at a level gives atoms: this is Theorem 1 at work.
step: An interval at level $k$ properly contains $2^{j-k}$ intervals at each level $j > k$ up to $3$, that is $2^{4-k} - 2$ proper parts in all.
step: Add over the intervals: level 0 gives $14$; level 1 gives $2 \times 6 = 12$; level 2 gives $4 \times 2 = 8$; level 3 gives $0$. The total is $14 + 12 + 8 = 34$.
answer: 15 elements, 8 atoms, 34 proper-part pairs.

@example
title: Checking the statue model by hand and by code
problem: In the model $B$ with elements $a, b, x, y$ and proper parthood $a, b < x$ and $a, b < y$, how many fusions does the set $\{a, b\}$ have, and which supplementation principle fails?
step: A fusion of $\{a,b\}$ is a $z$ such that for every $w$, $Owz$ iff $w$ overlaps $a$ or $b$.
step: Test $z = x$: $a$ and $b$ overlap $x$; $y$ overlaps $x$ (at $a$) and overlaps $a$; $x$ overlaps itself and $a$. So $x$ passes for $w = a, b, x, y$.
step: The same check with $z = y$ passes by symmetry. Candidates $a$ and $b$ fail: $b$ overlaps $b$ but not $a$.
step: So $\{a,b\}$ has exactly two fusions, $x$ and $y$. Strong supplementation fails: $\neg Pxy$, yet every part of $x$ (namely $a$, $b$ and $x$) overlaps $y$.
answer: The set has 2 fusions, $x$ and $y$; strong supplementation fails while weak supplementation holds.

@mistakes
- Saying that gunk is inconsistent with classical mereology. Atomless complete Boolean algebras exist, and their nonzero elements model CEM.
- Confusing gunk (every thing has proper parts) with the denial of atoms in a particular thing: atomism and gunk are global claims about every thing, and a world can have atoms and gunky regions together.
- Thinking a finite model can be gunky. In a finite model every thing has an atom.
- Assuming that a failure of extensionality means a failure of weak supplementation. The statue model satisfies WSP and violates SSP.

def atoms(D, P):

model:
```python
def is_atomistic(D, P):
    """Every element has an atom as a part."""
    def is_atom(x):
        return not any((y, x) in P and y != x for y in D)
    return all(any(is_atom(y) and (y, x) in P for y in D) for x in D)
```
hint: First write a helper deciding whether an element is an atom.
hint: Then require, for each `x`, some atom `y` with `(y, x)` in `P`.
solution: An element is an atom when it has no other part. The model is atomistic when each element has an atom among its parts (an atom counts as its own atom part). By Theorem 1 every finite partial order passes. The last test uses a relation that is not antisymmetric, where each of the two elements is a proper part of the other: nothing is an atom, so the model is not atomistic.

model:
```python
def fusion_count(D, P, S):
    """Number of fusions of S in the overlap sense."""
    def overlap(x, y):
        return any((z, x) in P and (z, y) in P for z in D)
    return sum(1 for z in D
               if all(overlap(w, z) == any(overlap(w, s) for s in S)
                      for w in D))
```
hint: Define overlap first, then test each candidate `z` against every `w`.
hint: Compare the boolean `overlap(w, z)` with `any(overlap(w, s) for s in S)`.
solution: For each candidate `z`, check the biconditional for all `w`, counting the candidates that pass. In the model with two wholes sharing the same proper parts both pass for `{'a', 'b'}`, which is the failure of uniqueness of fusions; in the extensional model of three elements the answer is $1$, and two disjoint atoms alone have no fusion.

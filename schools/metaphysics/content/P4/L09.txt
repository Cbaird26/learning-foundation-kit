@article
Two sentences are **necessarily equivalent** when they are true at exactly the same possible worlds: "$p \wedge q$" and "$q \wedge p$", "Hesperus is a planet" and "Phosphorus is a planet", or any two mathematical truths. Yet someone can believe one without the other, and one can explain, or be grounded in, one but not the other. An operator $O$ is **intensional** when necessarily equivalent sentences are interchangeable in its scope, so that whenever $A$ and $B$ are true at the same worlds, $OA$ and $OB$ have the same truth value. It is **hyperintensional** when there are necessarily equivalent $A$ and $B$ such that $OA$ is true and $OB$ is false. Candidates include "believes that", "knows that", "because", "is about", "it is essential to $x$ that" and counterfactuals with impossible antecedents.

### Why possible worlds cannot do the job

**Theorem 1.** Suppose an operator is defined by the clause $w \models OA$ iff $\forall v\,(wRv \to v \models A)$, where $R$ relates worlds to possible worlds. Then $O$ is intensional, and $OA \to OB$ holds whenever $A$ entails $B$.

*Proof.* If $A$ and $B$ are true at the same possible worlds, then for every accessible $v$, $v \models A$ iff $v \models B$, so the two clauses agree. If $A$ entails $B$, every accessible world that satisfies $A$ satisfies $B$. $\square$

This is the problem of **logical omniscience** for the possible-worlds analysis of knowledge and belief, which gives the following argument.

| P1 | On the possible-worlds analysis of belief, if $A$ entails $B$ and someone believes $A$, then they believe $B$. |
| P2 | The axioms of a theory entail all its theorems. |
| P3 | Someone can believe the axioms of a theory without believing all its theorems. |
| C | So the possible-worlds analysis of belief is incorrect. |

It is valid. Replies deny P3 by idealizing belief (the analysis models what an ideal reasoner is committed to), or treat the model as one of information and not belief. The impossible-worlds reply keeps the semantic style and denies P1 by adding worlds that are not possible.

### Impossible-worlds semantics for belief

Take a propositional language with atoms $p, q, \ldots$, connectives $\neg$, $\wedge$, $\vee$ and a belief operator $B$ applied to $B$-free formulas. A **model** has a set $W_p$ of possible worlds, a set $W_i$ of impossible worlds, an accessibility relation $R$ on $W_p \cup W_i$, a valuation $V$ giving each possible world a set of true atoms, and a function $\Sigma$ giving each impossible world an arbitrary set of formulas.

| possible $w$ | $w \models p$ iff $p \in V(w)$; $\neg$, $\wedge$, $\vee$ behave classically |
| impossible $i$ | $i \models A$ iff $A \in \Sigma(i)$, for every formula $A$ |
| belief | $w \models BA$ iff $v \models A$ for every $v$ with $wRv$ |

The impossible worlds here are **anarchic**: nothing constrains the formulas they make true. More refined theories make them closed under some weaker logic, or build them from parts of the possible worlds. Nolan's article "Impossible Worlds: A Modest Approach" and Berto and Jago's book *Impossible Worlds* are the standard introductions.

**Theorem 2.** If $R$ relates $w$ only to possible worlds, belief at $w$ is closed under classical entailment. If an impossible world is accessible, closure can fail.

*Example.* Let $w$ be possible, with $wRi$, where $i$ is impossible and $\Sigma(i) = \{p \wedge q\}$. Then $w \models B(p \wedge q)$, because $p \wedge q \in \Sigma(i)$, but $w \not\models B(q \wedge p)$, although the two sentences are necessarily equivalent. And $w \not\models Bp$, though $p \wedge q$ entails $p$. So belief is hyperintensional and not closed under conjunction elimination. Giving $i$ the set $\{p, \neg p\}$ makes $w \models Bp \wedge B\neg p$ while $w \not\models Bq$: contradictory belief without belief in everything.

### The programmed model

```python
def sat(model, w, f):
    """Truth of a B-free formula f at world w."""
    if w in model['imposs']:
        return f in model['imposs'][w]
    if isinstance(f, str):
        return f in model['poss'][w]
    if f[0] == 'not':
        return not sat(model, w, f[1])
    if f[0] == 'and':
        return sat(model, w, f[1]) and sat(model, w, f[2])
    return sat(model, w, f[1]) or sat(model, w, f[2])


def believes(model, w, f):
    return all(sat(model, v, f) for (u, v) in model['R'] if u == w)
```

Atoms are strings and compound formulas are tuples such as `('and', 'p', 'q')`, which are hashable, so they can be members of the sets of impossible worlds. The key line is the first test in `sat`: at an impossible world, truth is membership, with no recursion.

### The dilemma for impossible worlds

A familiar objection runs between two horns. If impossible worlds are closed under even a modest amount of logic, belief is closed under that much logic, and one wants to know where to stop. If they are not closed under any logic, the semantics permits believing $p \wedge q$ without believing $p$, and some say it then says too little about what makes a belief state rational or about the logic of $B$. Proponents answer that a semantics need not be a theory of rationality and that the closure properties can be added as constraints, one at a time, so that their joint consequences can be studied. The formal task is to say which constraints on impossible worlds yield which closure principle, and that is a theorem-proving task of the kind this course teaches.

@example
title: Reading a belief claim off a model
problem: A model has one possible world $w$ with $V(w) = \{p\}$, one impossible world $i$ with $\Sigma(i) = \{p, \neg\neg p\}$, and $R = \{(w, i)\}$. Which of $Bp$, $B\neg\neg p$, $B(p \wedge p)$ and $B(p \vee q)$ are true at $w$?
step: The only accessible world is $i$, and truth at $i$ is membership in $\Sigma(i)$.
step: $p \in \Sigma(i)$, so $Bp$ is true. $\neg\neg p \in \Sigma(i)$, so $B\neg\neg p$ is true.
step: $p \wedge p$ and $p \vee q$ are not members of $\Sigma(i)$, so $B(p \wedge p)$ and $B(p \vee q)$ are false, although $p \wedge p$ is equivalent to $p$ and $p \vee q$ is entailed by $p$.
answer: $Bp$ and $B\neg\neg p$ are true; $B(p \wedge p)$ and $B(p \vee q)$ are false.

@example
title: A possible-worlds check that closure holds
problem: In a model where $R$ relates $w$ only to the possible worlds $v_1$ with $V(v_1) = \{p, q\}$ and $v_2$ with $V(v_2) = \{p\}$, is $B(p \vee r)$ true at $w$?
step: The accessible worlds are classical, so truth is computed recursively.
step: At $v_1$ and at $v_2$, $p$ is true, so $p \vee r$ is true at both.
step: $B(p \vee r)$ holds at $w$ because $p \vee r$ is true at every accessible world. This is Theorem 2: $Bp$ holds at $w$ since $p$ is true at both, and closure gives $B(p \vee r)$.
answer: Yes, $B(p \vee r)$ is true at $w$.

@mistakes
- Saying that an impossible world is a world where a *contradiction* is true. It is a world where some classically necessary sentence fails or some classically impossible sentence holds; a world that makes every sentence true is the trivial extreme, not the typical case.
- Using recursion at an impossible world. There, $A \wedge B$ is true iff $A \wedge B$ is in $\Sigma(i)$, not iff $A$ and $B$ are.
- Confusing hyperintensional with non-extensional. "Necessarily" is non-extensional but intensional; the hyperintensional contexts are those that fail to respect necessary equivalence.
- Thinking that impossible worlds are needed to represent mere contingency. Contingent differences are already given by possible worlds.

model:
```python
def believed(model, w, formulas):
    """Formulas believed at w in an impossible-worlds model."""
    def sat(v, f):
        if v in model['imposs']:
            return f in model['imposs'][v]
        if isinstance(f, str):
            return f in model['poss'][v]
        if f[0] == 'not':
            return not sat(v, f[1])
        if f[0] == 'and':
            return sat(v, f[1]) and sat(v, f[2])
        return sat(v, f[1]) or sat(v, f[2])

    accessible = [v for (u, v) in model['R'] if u == w]
    return {f for f in formulas if all(sat(v, f) for v in accessible)}
```

@quiz self
prompt: State the dilemma for anarchic impossible worlds as an objection to the impossible-worlds analysis of belief and give the strongest reply you can.
hint: Consider what happens if impossible worlds are required to be closed under some logic and what happens if they are not.
solution: The objection: if impossible worlds are unconstrained (anarchic), the logic of belief is nearly empty: one may believe $p \wedge q$ without believing $p$, so the semantics fails to capture even minimal rationality, and it cannot distinguish a believer who fails to draw an obvious inference from one who fails to draw a very difficult one. Reply: a semantics for the operator $B$ does not have to be a theory of rationality. The anarchic model gives the weakest logic and each closure principle can be added as an explicit constraint on worlds, so the framework lets one study the consequences of each. Which closure principles are plausible is then a separate question, answered by the epistemology of the agents being modeled.

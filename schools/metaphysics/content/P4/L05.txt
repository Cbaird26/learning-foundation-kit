@article
"Some critics admire only one another." "The rocks form a pile." "Ann and Bo lifted the piano." The first sentence cannot be written in first-order logic with the predicates "is a critic" and "admires": a classic result shown by Boolos, building on an example of Geach and Kaplan. In the other two, the predicate applies to several things at once, not to each. **Plural logic** adds variables for *some things* and a primitive relation "is one of", and so makes such sentences expressible without turning the things into a set or a fusion.

### The language PFO

Plural first-order logic has singular variables $x, y, z$ and **plural variables** $xx, yy, zz$, read "some things", with first-order quantifiers over both. Its one new primitive is the binary predicate $\prec$: $x \prec yy$ says that $x$ is **one of** the $yy$. Two pluralities are identical when they have the same members, $xx = yy := \forall z\,(z \prec xx \leftrightarrow z \prec yy)$. The characteristic axiom is **plural comprehension**: for any formula $\varphi(y)$ in which $xx$ does not occur free,

$$\exists y\,\varphi(y) \to \exists xx\,\forall y\,(y \prec xx \leftrightarrow \varphi(y)).$$

If anything satisfies a condition, there are some things that are exactly the things satisfying it. Plural variables are nonempty by construction: you cannot quantify over zero things. Following Boolos's 1984 paper "To Be Is To Be a Value of a Variable (or to Be Some Values of Some Variables)", the thesis is that plural quantification is **ontologically innocent**: it commits you to some things, not to a set of them. The book *Plural Logic* by Oliver and Smiley develops the system at length, including predicates that take plural arguments.

### The standard semantics

A model is a nonempty domain $D$ and an interpretation of the predicates. Singular variables are assigned members of $D$. Plural variables are assigned **nonempty subsets** of $D$, and $x \prec yy$ is true when the value of $x$ belongs to the value of $yy$. On a domain with $n$ elements a plural variable therefore has $2^n - 1$ possible values. This is a set-theoretic *model* of plural logic. Whether it captures its *meaning* is itself disputed, since a plural reading of the metalanguage is what Boolos proposed instead. For finite models, though, the two agree, and the semantics is easy to program. Up to the treatment of the empty set, plural logic has the expressive power of monadic second-order logic with full semantics, which Lesson 6 takes up.

### The Geach–Kaplan sentence

Let $Cx$ be "$x$ is a critic" and $Axy$ be "$x$ admires $y$". "Some critics admire only one another" is regimented as

$$\exists xx\,\big(\forall y\,(y \prec xx \to Cy) \wedge \forall y\,\forall z\,((y \prec xx \wedge Ayz) \to (z \prec xx \wedge y \neq z))\big).$$

There are some critics such that anyone among them admires only people among them, and never themselves. The clause $y \neq z$ gives "one another"; without it, a lone self-admirer would count. The sentence is true in a model exactly when some nonempty set of critics is closed under the admiration relation in this sense, and this can be tested by checking subsets. Because the sentence is true in some models and false in others in a way no first-order sentence matches, plural quantification adds genuine expressive power.

### Plural composition

In plural logic the notion of fusion applies to a plurality: $z$ is a fusion of the $yy$ when $\forall w\,(Owz \leftrightarrow \exists y\,(y \prec yy \wedge Owy))$. Unrestricted composition becomes a single sentence, $\forall yy\,\exists z\,Fu(z,yy)$, in place of the schema of Lesson 2. In a finite model it is checked by running through all $2^{|D|} - 1$ pluralities.

### Is plural quantification quantification over sets?

If plural variables ranged over sets, plural logic would be a fragment of set theory and would inherit its commitments. Here is a well-known argument that it does not:

| P1 | By plural comprehension there are some things, the $rr$, such that anything is one of them iff it is a set that is not a member of itself. |
| P2 | If plural quantification were quantification over sets, there would be a set whose members are exactly the things that are among the $rr$. |
| P3 | There is no set whose members are exactly the sets that are not members of themselves. |
| C | So plural quantification is not quantification over sets. |

The argument is valid (P1 and P2 give a set contradicting P3). The reply is that it begs the question about the set-theoretic model theory of Section 2: a theorist who accepts that the semantics uses sets can restrict it to set-sized domains. A second reply denies that comprehension is innocent for such conditions.

@example
title: Translating a collective-and-distributive claim
problem: Translate into plural logic: "Some of the mathematicians solved the problem together, but none of them solved it alone." Use $Mx$ for "$x$ is a mathematician", $Solve(xx,p)$ for "the $xx$ solved $p$ together" and $Alone(x,p)$ for "$x$ solved $p$ alone".
step: The vocabulary is given: $Solve$ takes a plurality as its first argument and $Alone$ takes a single thing.
step: "Some of the mathematicians" is a plurality made of mathematicians: $\exists xx\,\forall y\,(y \prec xx \to My)$.
step: The collective clause applies the plural predicate to $xx$: $Solve(xx, p)$.
step: "None of them solved it alone" is distributive: $\forall y\,(y \prec xx \to \neg Alone(y, p))$.
step: Conjoin the clauses under the one existential quantifier.
answer: $\exists xx\,\big(\forall y\,(y \prec xx \to My) \wedge Solve(xx,p) \wedge \forall y\,(y \prec xx \to \neg Alone(y,p))\big)$.

@example
title: Evaluating the Geach–Kaplan sentence on a model
problem: Let the domain be $\{1,2,3,4\}$, every element a critic, with $A = \{(1,2),(2,1),(3,4)\}$. Is "some critics admire only one another" true?
step: Look for a nonempty $X$ such that each member admires only members of $X$, and never itself. No pair in $A$ has equal coordinates, so the self-admiration clause is never violated.
step: Try $X = \{1,2\}$. Element $1$ admires only $2$, which is in $X$. Element $2$ admires only $1$, which is in $X$. So $X$ works.
step: One witness suffices for the existential. The set $\{3,4\}$ also works: $3$ admires only $4$, which is in the set and different from $3$, and $4$ admires nobody, so the condition holds vacuously for $4$.
answer: True, witnessed by $\{1,2\}$ (and also by $\{3,4\}$).

@mistakes
- Forming the sum or set of the critics and applying "admires" to it. The point of plural logic is to quantify over several things without a single object that they compose.
- Reading a plural variable as possibly empty. Plural variables range over nonempty pluralities, so "there are some things" is never trivially true by taking none.
- Dropping $y \neq z$ in the Geach–Kaplan sentence, which lets a lone self-admirer verify it.
- Treating "$x \prec xx$" as parthood or membership in a set: it is a primitive of plural logic.

model:
```python
from itertools import combinations


def geach_kaplan(D, C, A):
    """Some critics admire only one another."""
    critics = list(C)
    for r in range(1, len(critics) + 1):
        for X in combinations(critics, r):
            group = set(X)
            if all(y in group and y != x for (x, y) in A if x in group):
                return True
    return False
```

solution: Search the nonempty subsets of the critics. A subset works when every admiration pair starting inside it ends inside it at a different element. The second test fails because a lone critic admires himself, and the fifth fails because critic $1$ admires the non-critic $3$ and so belongs to no group, and critic $2$ admires critic $1$ and so belongs to none either.

model:
```python
from itertools import combinations


def plural_uc(D, P):
    """Every nonempty plurality has a fusion."""
    items = list(D)

    def overlap(x, y):
        return any((z, x) in P and (z, y) in P for z in items)

    def is_fusion(z, S):
        return all(overlap(w, z) == any(overlap(w, s) for s in S)
                   for w in items)

    return all(any(is_fusion(z, S) for z in items)
               for r in range(1, len(items) + 1)
               for S in combinations(items, r))
```
hint: Loop over every nonempty subset `S` with `itertools.combinations` and look for a fusion among the elements.
hint: The fusion test compares `overlap(w, z)` with `any(overlap(w, s) for s in S)` for every `w`.
solution: Enumerate the nonempty subsets of the domain and require that each has at least one fusion in the overlap sense. The model of nonempty sets of two atoms passes. In the second model the set $\{a, c\}$ has no fusion, and in the last domain the two unrelated atoms have none.

@article
A theorem tells you what holds in every model. A **model** tells you what a theory permits. To show that a principle is *not* a theorem, you need a model of the axioms in which the principle fails, and for mereology small finite models are enough for most purposes. They are also easy to check by machine, and a machine check is a good guard against the slips that creep into hand verification of an eight-element model with sixty-four pairs.

### Representing a model

A finite mereological model is a pair $(D, P)$: a finite domain $D$ and a set $P \subseteq D \times D$ of ordered pairs, where $(x,y) \in P$ means $Pxy$. In Python, $D$ is a `set` and $P$ is a `set` of tuples. Every function in this lesson takes `D` and `P` first.

```python
def overlap(D, P, x, y):
    """x and y overlap iff some z is part of both."""
    return any((z, x) in P and (z, y) in P for z in D)
```

Each quantifier of the axioms becomes `all(...)` or `any(...)` over `D`. A universal formula $\forall x\,\forall y\,\varphi$ becomes `all(phi for x in D for y in D)`, and a conditional $\alpha \to \beta$ inside it is written `(not alpha) or beta`, which is the truth table of the material conditional.

```python
def is_partial_order(D, P):
    """Reflexivity, antisymmetry and transitivity of P on D."""
    refl = all((x, x) in P for x in D)
    anti = all(x == y or not ((x, y) in P and (y, x) in P)
               for x in D for y in D)
    trans = all((x, z) in P
                for x in D for y in D for z in D
                if (x, y) in P and (y, z) in P)
    return refl and anti and trans
```

Notice how the code mirrors the axioms. In `anti` the clause `x == y or not (...)` is the axiom $(Pxy \wedge Pyx) \to x = y$ rewritten as $x = y \vee \neg(Pxy \wedge Pyx)$.

### The supplementation principles and fusion

```python
def ssp(D, P):
    """Strong supplementation: not Pxy -> some z is part of x, disjoint from y."""
    return all(any((z, x) in P and not overlap(D, P, z, y) for z in D)
               for x in D for y in D if (x, y) not in P)

def is_fusion(D, P, z, S):
    """z fuses the set S iff whatever overlaps z overlaps a member of S."""
    return all(overlap(D, P, w, z) == any(overlap(D, P, w, s) for s in S)
               for w in D)
```

Weak supplementation is the same with the guard `(x, y) in P and x != y` and the roles of the variables adjusted. A model satisfies **unrestricted composition** when every nonempty set $S \subseteq D$ has a fusion in $D$. For a domain of 7 elements there are $2^7 - 1 = 127$ nonempty subsets, so brute force is trivial; at 20 elements it would already take over a million subsets, so finite checking is for small models.

### The model of nonempty sets of atoms

The most important finite model takes a set of atoms and lets the elements be the nonempty subsets, with parthood as inclusion:

```python
from itertools import combinations

def power_model(atoms):
    atoms = list(atoms)
    D = {frozenset(c)
         for r in range(1, len(atoms) + 1)
         for c in combinations(atoms, r)}
    P = {(x, y) for x in D for y in D if x <= y}
    return D, P
```

`frozenset` is used because ordinary sets cannot be members of sets. The relation `x <= y` between sets is inclusion, so reflexivity is automatic. With three atoms the domain has $2^3 - 1 = 7$ elements and $P$ has $3^3 - 2^3 = 19$ pairs: choose, for each atom, whether it is in neither set, in both, or only in the larger one ($3^3$ ways), and remove the $2^3$ ways in which the smaller set is empty. Running `ssp`, `is_partial_order` and the fusion test on this model confirms that it is a model of CEM, as the Boolean-algebra theorem of Lesson 2 predicts.

### Reading the output

Counterexamples are more informative than `True`. A useful habit is to make checking functions return a *witness* when a principle fails, and to print it. When you formalize a recent argument in this course, a Python-found countermodel is a perfectly good way to show that a premise is not forced by the axioms, provided you state the model in the text so a reader can verify it by hand. Never let the code stand in for the model: write the domain and the relation down.

@example
title: Tracing a model-checking program
problem: What does this program print? Explain the output.

```python
D = {1, 2, 3, 6}
P = {(x, y) for x in D for y in D if y % x == 0}
def overlap(x, y):
    return any((z, x) in P and (z, y) in P for z in D)
print(overlap(2, 3), overlap(2, 6))
print(sum(1 for x in D for y in D if x != y and (x, y) in P))
```
step: The set `P` contains $(x,y)$ exactly when $x$ divides $y$. So the model is divisibility on $\{1,2,3,6\}$.
step: `overlap(2, 3)` asks for a common divisor in `D` of $2$ and $3$. The number $1$ divides both, so it returns `True`.
step: `overlap(2, 6)` is true because $2$ is part of both. The first line prints `True True`.
step: The second line counts pairs of distinct elements with $x \mid y$: $(1,2)$, $(1,3)$, $(1,6)$, $(2,6)$, $(3,6)$, which is 5 pairs. So it prints `5`.
answer: The program prints `True True` and then `5`.

@example
title: Writing a check from an axiom
problem: Write `wsp(D, P)` that tests weak supplementation, and say what it returns on the two-element chain $\{0, 1\}$ with $P = \{(0,0), (1,1), (0,1)\}$.
step: Weak supplementation says $PPxy \to \exists z\,(Pzy \wedge \neg Ozx)$. It must hold for every pair $(x,y)$ that satisfies the antecedent: $Pxy$ and $x \neq y$.
step: Translate each part: the pair loop with its guard, the existential as `any`, and the disjointness as `not overlap(...)`:

```python
def wsp(D, P):
    return all(any((z, y) in P and not overlap(D, P, z, x) for z in D)
               for x in D for y in D if (x, y) in P and x != y)
```
step: On the chain, the only pair with $PPxy$ is $x = 0$, $y = 1$. The candidates for $z$ are $0$ and $1$, and both are parts of $1$. But $0$ overlaps $0$ (it is part of itself), and $1$ overlaps $0$ (they share the part $0$). So no candidate is disjoint from $x$, and `any` is false.
step: Hence `wsp` returns `False` on the chain, which agrees with the lesson-1 fact that weak supplementation is not a theorem of ground mereology.
answer: `wsp` returns `False` on the two-element chain.

@mistakes
- Writing `(x, y) in P` for proper parthood. `P` contains the reflexive pairs, so proper parthood also needs `x != y`.
- Forgetting that `all(...)` over an empty set is `True` and `any(...)` over an empty set is `False`. An empty domain satisfies every universal axiom vacuously.
- Writing a transitivity test that skips chains whose ends coincide (`x != z`): the chain $(1,2), (2,1)$ then escapes, although it requires $(1,1)$.
- Testing "fusion" by the condition that every member of `S` is part of `z`. That is only half of the definition used here.

@quiz num
prompt: In the model of nonempty sets of atoms from $\{a,b,c\}$ with parthood as inclusion, how many nonempty sets $S$ of elements have the element $\{a,b,c\}$ as a fusion, in the sense that whatever overlaps $\{a,b,c\}$ overlaps a member of $S$?
answer: 109
unit: sets
check: sum(1 for r in range(1, 8) for S in itertools.combinations(range(1, 8), r) if all(any(s & bit for s in S) for bit in (1, 2, 4)))
hint: Every element overlaps $\{a,b,c\}$, so the condition says every element overlaps a member of $S$.
hint: Equivalently, every atom must be in some member of $S$: the members of $S$ must cover $\{a,b,c\}$.
solution: Since every element overlaps $\{a,b,c\}$, the condition requires each atom to lie in some member of $S$. Count families of the 7 elements that cover all three atoms by inclusion–exclusion. There are $2^7$ families in all. The elements avoiding a given atom number 3, those avoiding two given atoms number 1, and none avoids all three. So the count is $2^7 - 3 \cdot 2^3 + 3 \cdot 2^1 - 2^0 = 128 - 24 + 6 - 1 = 109$. The empty family covers nothing, so it is not counted.

def trans(D, P):

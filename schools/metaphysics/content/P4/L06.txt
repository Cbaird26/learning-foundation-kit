@article
First-order logic cannot say that a domain is finite, cannot pin down the natural numbers up to isomorphism, and cannot define identity from other predicates. **Second-order logic** can do all three, and the price is the subject of this lesson. A philosophical question hides inside the technical one: when you quantify over *properties* or *pluralities* and then ask what the quantifier means, which semantics are you using?

### Syntax

Second-order logic extends first-order logic with **relation variables** $X, Y, \ldots$ of each arity $n$, atomic formulas $Xt_1 \ldots t_n$, and quantifiers $\forall X$ and $\exists X$. The **comprehension schema** says that every formula defines a relation: for any formula $\varphi(x)$ in which $X$ is not free,

$$\exists X\,\forall x\,(Xx \leftrightarrow \varphi(x)).$$

Parameters (free first- and second-order variables) are allowed in $\varphi$. Identity is definable by Leibniz's law: $x = y \leftrightarrow \forall X\,(Xx \leftrightarrow Xy)$.

### Two semantics

A structure supplies a domain $D$ and interprets the non-logical vocabulary. The semantics differs in what the relation variables range over.

| Standard (full) semantics | $n$-ary variables range over **all** subsets of $D^n$ |
| Henkin (general) semantics | $n$-ary variables range over a designated family $\mathcal{D}_n \subseteq \mathcal{P}(D^n)$, which in a *Henkin model* satisfies comprehension |

On a domain with $n$ elements there are $2^n$ possible values of a monadic variable and $2^{n^2}$ of a binary one under the standard semantics. Henkin semantics, introduced in Henkin's 1950 paper on the theory of types, treats second-order logic as a many-sorted first-order theory.

### The metalogical contrast

**Full semantics.** (1) *Categoricity*: Dedekind's second-order axioms for arithmetic, with induction as one sentence, have only models isomorphic to the natural numbers. (2) *Finiteness* is expressible: "every injective function from the domain to itself is onto" can be written as a second-order sentence and holds exactly on finite domains (in a metatheory with the axiom of choice). (3) *Compactness fails*: the sentence saying the domain is finite together with the sentences "there are at least $n$ things", for each $n$, has every finite subset satisfiable and itself no model. (4) The downward *Löwenheim–Skolem theorem* fails: the second-order axioms of a complete ordered field have only models isomorphic to the reals, an uncountable structure. (5) *Incompleteness*: there is no effective sound and complete proof system, a consequence of Gödel's incompleteness theorems. (6) Validity is sensitive to set theory: there is a sentence of second-order logic that is valid on the full semantics if and only if the continuum hypothesis holds.

**Henkin semantics.** With the usual deductive system, including comprehension, second-order logic is sound and complete with respect to Henkin models, and therefore compact and subject to Löwenheim–Skolem. But it also loses categoricity: there are countable Henkin models of the second-order Peano axioms that are not isomorphic to the natural numbers.

### Finite domains collapse the difference

**Theorem.** If $D$ is finite and $(D, \mathcal{D}_1)$ is a Henkin model, that is, $\mathcal{D}_1$ satisfies comprehension with parameters, then $\mathcal{D}_1 = \mathcal{P}(D)$.

*Proof.* For $a \in D$, comprehension for $\varphi(x) := x = a$, with $a$ as a parameter, puts $\{a\} \in \mathcal{D}_1$. For $S = \{a_1, \ldots, a_k\} \subseteq D$ nonempty, comprehension for $\varphi(x) := x = a_1 \vee \ldots \vee x = a_k$, a finite disjunction, puts $S \in \mathcal{D}_1$; for $S = \varnothing$ use $x \neq x$. $\square$

The same argument works for $n$-ary variables, using conjunctions of identities. So on finite domains, quantifying over all subsets by brute force computes the Henkin truth value as well as the standard one, and a counterexample to a second-order claim found in a finite model is a counterexample under both.

### Is second-order logic logic?

Quine called second-order logic "set theory in sheep's clothing", and an argument in his spirit is set out as follows.

| P1 | If full second-order consequence is logical consequence, then whether some sentences are logically valid depends on substantive set-theoretic hypotheses such as the continuum hypothesis. |
| P2 | Logical validity does not depend on substantive set-theoretic hypotheses. |
| C | So full second-order consequence is not logical consequence. |

It is valid (modus tollens). Shapiro, in *Foundations without Foundationalism*, accepts P1 and rejects P2, defending the full semantics as the correct account of what the quantifiers mean. Boolos, in "To Be Is To Be a Value of a Variable (or to Be Some Values of Some Variables)" (1984), proposed reading monadic second-order quantifiers plurally, which removes the commitment to sets that Quine's slogan alleges. The debate shapes the metaphysics of Lesson 7, where higher-order quantification is used to state claims about the structure of reality.

@example
title: Evaluating a second-order sentence by brute force
problem: Let $D = \{1,2,3\}$ and $R = \{(1,2),(2,3)\}$, where $Rxy$ means $x$ is related to $y$. Is $\forall X\,\big((\exists x\,Xx) \to \exists x\,(Xx \wedge \forall y\,(Xy \to \neg Ryx))\big)$ true, that is, does every nonempty subset contain an element with no $R$-predecessor in the subset?
step: The sentence quantifies over all $2^3 = 8$ subsets. The empty set makes the antecedent false, so its conditional is true, and only the 7 nonempty subsets need checking.
step: An element $x$ of $X$ qualifies when no $y \in X$ has $Ryx$. The relation $R$ gives $1$ a successor $2$ and $2$ a successor $3$, so $1$ has no predecessor, $2$ has predecessor $1$, and $3$ has predecessor $2$.
step: Check the subsets: $\{1\}$, $\{2\}$, $\{3\}$ each qualify (a singleton has no other element, and $R$ has no loops). $\{1,2\}$: $1$ qualifies. $\{1,3\}$: both qualify. $\{2,3\}$: $2$ has no predecessor inside $\{2,3\}$, so it qualifies. $\{1,2,3\}$: $1$ qualifies.
step: Every nonempty subset has a qualifying element, so the sentence is true.
answer: True: on this finite domain every nonempty subset has an $R$-minimal element.

@example
title: Counting under the standard semantics
problem: How many values can a binary relation variable take on a domain of $3$ elements under the standard semantics, and how many of those are reflexive?
step: A binary relation is a subset of $D \times D$, which has $3^2 = 9$ pairs, so there are $2^9 = 512$ values.
step: A reflexive relation contains the 3 diagonal pairs and may contain any of the other 6.
step: That gives $2^6 = 64$ reflexive relations.
answer: 512 values, of which 64 are reflexive.

@mistakes
- Saying that second-order logic is incomplete without saying which semantics: with the standard semantics it has no effective complete proof system, but with Henkin semantics it is complete.
- Using "second-order" to mean "involving higher-order properties of properties". A second-order variable ranges over properties or relations of individuals, and a property of properties is third-order.
- Treating the Henkin family as an arbitrary choice of subsets. A Henkin model must satisfy comprehension, which forces closure under the definable subsets.
- Concluding from finite brute force that a sentence is valid. A finite check settles it only on that domain.

model:
```python
from itertools import combinations


def every_subset_has_minimal(D, R):
    """Every nonempty subset has an R-minimal element."""
    items = list(D)
    for r in range(1, len(items) + 1):
        for X in combinations(items, r):
            if not any(all((y, x) not in R for y in X) for x in X):
                return False
    return True
```

model:
```python
from itertools import combinations


def count_closed(D, R, base):
    """Subsets containing base and closed under R."""
    items = list(D)
    count = 0
    for r in range(len(items) + 1):
        for c in combinations(items, r):
            X = set(c)
            if base <= X and all(y in X for (x, y) in R if x in X):
                count += 1
    return count
```

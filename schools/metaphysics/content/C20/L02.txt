@article
Last week's sets are the raw material; this week's relations and functions are the structures built from them. A model of a first-order language interprets each predicate as a **relation** and each function symbol as a **function**, so everything a model does is described in this vocabulary.

### Relations

A **relation** from $A$ to $B$ is a subset of $A \times B$; a relation **on** $A$ is a subset $R \subseteq A \times A$. We write $aRb$ for $(a, b) \in R$. On a set $A$, $R$ is

- **reflexive** if $aRa$ for every $a \in A$;
- **symmetric** if $aRb$ implies $bRa$;
- **antisymmetric** if $aRb$ and $bRa$ together imply $a = b$;
- **transitive** if $aRb$ and $bRc$ together imply $aRc$.

Symmetric and antisymmetric are not opposites. The identity relation $\{(a, a) : a \in A\}$ is both; the relation $\{(1, 2), (2, 1), (1, 3)\}$ on $\{1, 2, 3\}$ is neither symmetric nor antisymmetric.

### Equivalence relations and partitions

An **equivalence relation** is reflexive, symmetric and transitive. "Has the same remainder on division by 3" is one; so is "is the same height as". The **equivalence class** of $a$ is $[a] = \{b : aRb\}$. A **partition** of $A$ is a set of nonempty, pairwise disjoint sets whose union is $A$.

**Theorem.** If $R$ is an equivalence relation on $A$, the equivalence classes form a partition of $A$; conversely, every partition of $A$ determines an equivalence relation ("lies in the same block"), and these two constructions undo each other. So equivalence relations on $A$ correspond one-to-one with partitions of $A$.

A tempting shortcut shows why reflexivity cannot be dropped:

| P1 | $R$ is symmetric. |
| P2 | $R$ is transitive. |
| P3 | For every $x$ there is some $y$ with $xRy$. |
| C | So $R$ is reflexive. |

The argument is valid. Take any $x$. By P3 choose $y$ with $xRy$; by P1, $yRx$; by P2, from $xRy$ and $yRx$ we get $xRx$. Hence $R$ is reflexive. The argument is often given without P3, and then it is invalid: P3 is the hidden premise, and it is false for the empty relation on $\{1\}$, which is symmetric and transitive (both conditions hold vacuously) but not reflexive. Whoever uses the shortcut must show that every element is related to something.

### Functions

A **function** $f : A \to B$ is a relation from $A$ to $B$ such that every $a \in A$ is related to exactly one $b \in B$, written $f(a) = b$. $A$ is the **domain** and $B$ the **codomain**; the **range** is $\{f(a) : a \in A\}$. For $X \subseteq A$, the **image** is $f[X] = \{f(x) : x \in X\}$. The function $f$ is

- **injective** (one-to-one) if $f(a) = f(a')$ implies $a = a'$;
- **surjective** (onto) if every $b \in B$ equals $f(a)$ for some $a \in A$;
- **bijective** if it is both.

The composition $g \circ f$ is defined by $(g \circ f)(a) = g(f(a))$. A function has an **inverse** $f^{-1} : B \to A$ with $f^{-1}(f(a)) = a$ and $f(f^{-1}(b)) = b$ exactly when it is a bijection. If $\lvert A \rvert = m$ and $\lvert B \rvert = n$, there are $n^m$ functions from $A$ to $B$, and if $m \le n$ there are $n(n-1)\cdots(n-m+1)$ injective ones.

**Example proof.** The composition of two injections is an injection. Let $f : A \to B$ and $g : B \to C$ be injective, and suppose $g(f(a)) = g(f(a'))$. Since $g$ is injective, $f(a) = f(a')$. Since $f$ is injective, $a = a'$.

### Orders

A **partial order** is reflexive, antisymmetric and transitive; written $\le$, it makes $(A, \le)$ a partially ordered set. Examples: $\subseteq$ on $\mathcal{P}(A)$, and divisibility on the positive integers. It is a **total** (linear) order if any two elements are **comparable**: $a \le b$ or $b \le a$. In $(\mathcal{P}(\{1, 2\}), \subseteq)$ the sets $\{1\}$ and $\{2\}$ are not comparable. An element $m$ is **maximal** if nothing lies strictly above it, and the **greatest** element if everything is below it; a partial order can have several maximal elements and no greatest. A total order is a **well-order** if every nonempty subset has a least element: $\le$ on $\mathbb{N}$ is a well-order, while $\le$ on $\mathbb{Z}$ is not, since $\mathbb{Z}$ itself has no least element. Well-orders underlie induction, the topic of week 5.

@example
title: Classifying a relation
problem: On $A = \{1, 2, 3, 4\}$ let $R = \{(a, b) : a - b \text{ is even}\}$. Is $R$ an equivalence relation? If so, find its classes.
step: Reflexive: $a - a = 0$ is even, so $aRa$ for every $a$.
step: Symmetric: if $a - b$ is even, then $b - a = -(a - b)$ is even.
step: Transitive: if $a - b$ and $b - c$ are even, then $a - c = (a - b) + (b - c)$ is a sum of even numbers, so it is even.
step: So $R$ is an equivalence relation. Its classes are $[1] = [3] = \{1, 3\}$ and $[2] = [4] = \{2, 4\}$: the odd and the even numbers of $A$. These two sets are nonempty, disjoint and have union $A$, as the theorem says.
answer: $R$ is an equivalence relation with the two classes $\{1, 3\}$ and $\{2, 4\}$.

@example
title: Images and unions
problem: Prove that $f[X \cup Y] = f[X] \cup f[Y]$ for every function $f : A \to B$ and all $X, Y \subseteq A$.
step: ($\subseteq$) Let $b \in f[X \cup Y]$. Then $b = f(x)$ for some $x \in X \cup Y$.
step: If $x \in X$ then $b \in f[X]$; if $x \in Y$ then $b \in f[Y]$. Either way $b \in f[X] \cup f[Y]$.
step: ($\supseteq$) Let $b \in f[X] \cup f[Y]$. If $b \in f[X]$, then $b = f(x)$ for some $x \in X \subseteq X \cup Y$, so $b \in f[X \cup Y]$. The case $b \in f[Y]$ is the same.
step: Each set is a subset of the other, so they are equal. (The analogous identity for intersections, $f[X \cap Y] = f[X] \cap f[Y]$, fails when $f$ is not injective: take $f(1) = f(2) = 0$, $X = \{1\}$, $Y = \{2\}$.)
answer: $f[X \cup Y] = f[X] \cup f[Y]$, by double inclusion.

@mistakes
- Treating "symmetric" and "antisymmetric" as opposites: the identity relation is both, and many relations are neither.
- Forgetting that a relation can be symmetric and transitive without being reflexive; the empty relation on a nonempty set is the standard counterexample.
- Calling $f : \mathbb{N} \to \mathbb{N}$, $f(n) = 2n$ a bijection: it is injective but not surjective, since odd numbers are never values.
- Assuming a partial order has a greatest element whenever it has a maximal one; in divisibility on $\{2, 3, 4\}$, both $3$ and $4$ are maximal and neither is greatest.

solution: The first relation has all three loops, is symmetric (the pair $(1,2)$ comes with $(2,1)$) and is transitive. The second lacks $(3,3)$, the third lacks $(2,1)$, and the last is not transitive: it has $(1,2)$ and $(2,3)$ but not $(1,3)$.

@practice num
prompt: How many different equivalence relations are there on a set with 5 elements?
answer: 52
check: sum(1 for a in product(range(5), repeat=5) if a[0] == 0 and all(a[i] <= max(a[:i]) + 1 for i in range(1, 5)))
hint: Equivalence relations correspond one-to-one with partitions, so count the ways to partition a 5-element set into nonempty blocks.
hint: Count by the number of blocks: the numbers of partitions of a 5-element set into 1, 2, 3, 4, 5 blocks are 1, 15, 25, 10, 1.
solution: By the correspondence theorem, count partitions. A 5-element set has $1 + 15 + 25 + 10 + 1 = 52$ partitions (into 1, 2, 3, 4 and 5 blocks respectively), so there are 52 equivalence relations. This number is the Bell number $B_5$.

@practice list
prompt: Consider the positive integers $1, 2, \ldots, 12$ ordered by divisibility ($a \le b$ when $a$ divides $b$). List all the maximal elements, separated by commas.
answer: 7, 8, 9, 10, 11, 12
check: [n for n in range(1, 13) if not any(m != n and m % n == 0 for m in range(1, 13))]
hint: An element is maximal if no other element of the set is a multiple of it.
solution: $1$ through $6$ each have a larger multiple in the set ($2$ divides $4$, $3$ divides $6$, $4$ divides $8$, $5$ divides $10$, $6$ divides $12$, $1$ divides everything). The numbers $7, 8, 9, 10, 11, 12$ have no multiple at most $12$ other than themselves, so they are the maximal elements. There is no greatest element.

prompt: Prove that for every function $f : A \to B$ and all sets $X, Y \subseteq A$, $f[X \cap Y] \subseteq f[X] \cap f[Y]$, and give an example in which the inclusion is proper.

@quiz num
prompt: How many injective functions are there from a 3-element set to a 5-element set?
answer: 60
check: len([f for f in product(range(5), repeat=3) if len(set(f)) == 3])
hint: Choose the image of the first element, then the second, then the third, with no repeated values.
solution: There are $5$ choices for the first value, $4$ for the second and $3$ for the third, so $5 \cdot 4 \cdot 3 = 60$.

@quiz ms

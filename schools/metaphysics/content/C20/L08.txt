@article
A derivation is finite: it uses only finitely many premises. Completeness says that derivability coincides with semantic consequence. Put the two together and something remarkable follows about structures: if every finite part of a set of sentences can be made true, the whole set can. This is the **compactness theorem**, and it costs first-order logic some expressive power that a philosopher would like to have. We now see what it buys and what it costs.

### Compactness

**Compactness Theorem.** A set $\Gamma$ of first-order sentences has a model if and only if every finite subset of $\Gamma$ has a model. Equivalently: $\Gamma \vDash A$ if and only if $\Gamma_0 \vDash A$ for some finite $\Gamma_0 \subseteq \Gamma$.

| P1 | If $\Gamma$ has no model, then $\Gamma \vdash \bot$. |
| P2 | If $\Gamma \vdash \bot$, then some finite $\Gamma_0 \subseteq \Gamma$ has $\Gamma_0 \vdash \bot$. |
| P3 | If $\Gamma_0 \vdash \bot$, then $\Gamma_0$ has no model. |
| C | So if $\Gamma$ has no model, then some finite subset of $\Gamma$ has no model. |

The argument is valid. P1 is completeness (in model-existence form: a set with $\Gamma \nvdash \bot$ has a model, contrapositively). P2 holds because a derivation is a finite object and uses finitely many premises. P3 is soundness. The conclusion is the contrapositive of the nontrivial direction of the theorem; the other direction is trivial, since a model of $\Gamma$ is a model of each subset.

### What compactness shows

**Finiteness is not first-order definable.** For each $n$, the sentence $\lambda_n = \exists x_1 \cdots \exists x_n \bigwedge_{i < j} x_i \neq x_j$ says that there are at least $n$ elements (the conjunction has $\binom{n}{2}$ conjuncts). Suppose a set $\Sigma$ of sentences were true in exactly the finite structures. Consider $\Sigma \cup \{\lambda_n : n \ge 1\}$. Any finite subset mentions $\lambda_n$ only for $n$ up to some $N$, and is satisfied by a finite structure with at least $N$ elements (such structures satisfy $\Sigma$ by hypothesis). By compactness the whole set has a model; it satisfies every $\lambda_n$, so it is infinite, and it satisfies $\Sigma$, so it is finite. Contradiction. Likewise no single sentence is true in exactly the infinite structures, although the infinite set $\{\lambda_n : n \ge 1\}$ is.

**Nonstandard models of arithmetic.** Let $\mathrm{Th}(\mathbb{N})$ be the set of all sentences of the language $\{0, S, +, \times, <\}$ true in the standard natural numbers $\mathbb{N}$. Add a new constant $c$ and the sentences $\bar n < c$ for every $n$ (here $\bar n$ is the numeral $S \cdots S0$). Any finite subset is satisfied in $\mathbb{N}$ by interpreting $c$ as a number larger than the finitely many $n$ involved. By compactness there is a model $\mathcal{M}$ of $\mathrm{Th}(\mathbb{N})$ containing an element above every numeral. It satisfies every first-order sentence that $\mathbb{N}$ does, yet it is not isomorphic to $\mathbb{N}$, since $\mathbb{N}$ has no such element. So first-order sentences cannot pin down the standard natural numbers.

### Löwenheim-Skolem

**Downward Löwenheim-Skolem.** If a set of sentences in a countable language has a model, then it has a model with a countable domain. If it has an infinite model, it has a countably infinite one. (This is already visible in the completeness proof, whose term model is countable.)

**Upward Löwenheim-Skolem.** If a set $\Gamma$ of sentences in a language of cardinality $\lambda$ has an infinite model, then for every cardinal $\kappa \ge \max(\lambda, \aleph_0)$ it has a model of cardinality $\kappa$. *Proof sketch:* add $\kappa$ new constants $c_\alpha$ and the sentences $c_\alpha \ne c_\beta$ for $\alpha \ne \beta$; every finite subset is satisfied in the infinite model by interpreting the finitely many constants as distinct elements; compactness gives a model, with at least $\kappa$ elements, and the general form of the downward theorem (a model of a language of size at most $\kappa$ has a submodel of size $\kappa$) trims it to exactly $\kappa$.

So a first-order theory with an infinite model has models of many sizes, and no first-order theory can force its infinite models to be of one size or isomorphic to each other. By the theorem of **Lindström** (1969), first-order logic is, in a precise sense, the strongest logic with both compactness and the downward Löwenheim-Skolem property.

### Skolem's paradox

Suppose ZFC is consistent. Its language is countable, so ZFC has a countable model $\mathcal{M}$ by the downward theorem. Yet ZFC proves the sentence "there is an uncountable set", for instance $\mathcal{P}(\mathbb{N})$ by Cantor's theorem. How can a countable model satisfy "there is an uncountable set"? The standard answer is that "uncountable" in $\mathcal{M}$ means "$\mathcal{M}$ contains no bijection from $\mathbb{N}$ onto it". The set that $\mathcal{M}$ thinks uncountable really is countable, but the enumeration of it exists only outside $\mathcal{M}$. Countability is **relative to a model**, not an absolute property in first-order logic. Skolem took this to show that set-theoretic notions of size are relative; others reply that the relativity is a feature of first-order axiomatization, not of the concept of size itself, which second-order formulations are said to capture. It remains a debated philosophical point. Putnam later used Löwenheim-Skolem reasoning in a model-theoretic argument against metaphysical realism, which most philosophers have not accepted.

@example
title: Finiteness has no single-sentence definition
problem: Use compactness to show that no single first-order sentence is true in exactly the infinite structures.
step: Suppose a sentence $\varphi$ is true in exactly the infinite structures. Then $\neg\varphi$ is true in exactly the finite structures.
step: Consider $\Sigma = \{\neg\varphi\} \cup \{\lambda_n : n \ge 1\}$, where $\lambda_n$ says that there are at least $n$ elements.
step: Each finite subset of $\Sigma$ has a model: it mentions $\lambda_n$ only for $n \le N$, so a finite structure with $N$ elements satisfies $\neg\varphi$ and all those $\lambda_n$.
step: By compactness $\Sigma$ has a model. It satisfies all $\lambda_n$, so it is infinite, and it satisfies $\neg\varphi$, so it is finite. Contradiction. Hence no such $\varphi$ exists.
answer: No single sentence defines "infinite" (and no set defines "finite").

@example
title: A finite subset of the nonstandard-model theory
problem: Let $\Gamma = \mathrm{Th}(\mathbb{N}) \cup \{\bar n < c : n \in \mathbb{N}\}$. Show that the finite subset $\Delta = \{\bar 3 < c,\ \bar 8 < c,\ \bar{20} < c\} \cup \{\text{any finitely many sentences from } \mathrm{Th}(\mathbb{N})\}$ has a model.
step: Every member of $\mathrm{Th}(\mathbb{N})$ is true in $\mathbb{N}$, so $\mathbb{N}$ satisfies the finitely many sentences from $\mathrm{Th}(\mathbb{N})$ whatever $c$ means.
step: The remaining sentences say $3 < c$, $8 < c$ and $20 < c$; these hold in $\mathbb{N}$ if $c$ is interpreted as $21$ (or any larger number).
step: So $(\mathbb{N}, c := 21)$ satisfies all of $\Delta$.
step: The same recipe works for every finite subset: interpret $c$ as one more than the largest $n$ mentioned. By compactness $\Gamma$ has a model.
answer: Interpreting $c$ as $21$ in the standard model satisfies $\Delta$, and the same method handles every finite subset.

@mistakes
- Thinking compactness says that every set of sentences has a model; it says only that a set has one if all its finite subsets do.
- Concluding that the nonstandard model $\mathcal{M}$ contradicts the truth of arithmetic. $\mathcal{M}$ satisfies exactly the first-order sentences true in $\mathbb{N}$; what differs is what first-order sentences cannot express, such as "every element is a numeral".
- Reading Skolem's paradox as a contradiction in ZFC. It is a clash with the *absolute* notion of countability; relative to the model the statement "there is an uncountable set" is true, while from outside the model its domain is countable.
- Stating upward Löwenheim-Skolem without its hypotheses: the structure must be infinite, and the target cardinality must be at least the size of the language.

@practice self
prompt: Explain the main steps of the proof of the completeness theorem for first-order logic, in about six sentences, including why each step is needed.
hint: Start from model existence; then list the steps: maximal consistent set, Henkin witnesses, term model, truth lemma.
solution: Completeness is reduced to model existence: if $\Gamma \nvdash A$ then $\Gamma \cup \{\neg A\}$ is consistent, so it suffices to show that every consistent set has a model. First, Lindenbaum's lemma extends the consistent set to a maximal consistent set, which decides every sentence; this is needed so that the model is determined by membership. Second, the language is extended with new constants and Henkin axioms $\exists x\,\psi \to \psi(c)$, whose consistency uses $\forall$I and the newness of $c$; this guarantees that every existential sentence has a witness. Third, the term model is built from closed terms modulo provable equality, with relations interpreted by membership in the maximal set. Fourth, the truth lemma, proved by induction on sentences, shows that a sentence is true in the term model iff it belongs to the maximal set; the witnesses are used in the quantifier cases. So the original consistent set is true in the term model, which is the required model.
rubric: Reduces completeness to the existence of a model of every consistent set.
rubric: Names and explains the maximal consistent extension and the Henkin witnesses, including why witnesses must be new constants.
rubric: Describes the term model and the truth lemma and says where the witnesses are used.

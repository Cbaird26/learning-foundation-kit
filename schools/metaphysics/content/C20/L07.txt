@article
Soundness says that derivations track truth. **Completeness** says that they miss nothing. Whenever an argument is valid, because every structure making the premises true makes the conclusion true, a derivation exists. This is far from obvious: validity quantifies over all structures, and a derivation is a finite object. Gödel proved it for first-order logic in his doctoral work (1929, published 1930). We follow Henkin's later method, which is the one that generalizes.

### The theorem and its model-existence form

**Completeness Theorem.** For a set $\Gamma$ of first-order formulas, if $\Gamma \vDash A$, then $\Gamma \vdash A$.

A set $\Gamma$ is **consistent** if $\Gamma \nvdash \bot$. The theorem is equivalent to the following, which is the version we prove:

**Model Existence.** Every consistent set of sentences has a model.

| P1 | If $\Gamma \nvdash A$, then $\Gamma \cup \{\neg A\}$ is consistent. |
| P2 | Every consistent set of sentences has a model. |
| P3 | If $\Gamma \cup \{\neg A\}$ has a model, then $\Gamma \nvDash A$. |
| C | So if $\Gamma \nvdash A$, then $\Gamma \nvDash A$. |

The argument is valid: by P1 and P2, $\Gamma \cup \{\neg A\}$ has a model, and by P3 that gives $\Gamma \nvDash A$. The conclusion is the contrapositive of completeness. P1 holds because if $\Gamma, \neg A \vdash \bot$ then $\Gamma \vdash A$ by IP; P3 holds because a model of $\Gamma \cup \{\neg A\}$ makes $\Gamma$ true and $A$ false. So the work is P2. (For sentences; free variables are handled by replacing them with new constants.) Conversely, completeness follows from model existence as just shown, and model existence follows from completeness: if $\Gamma$ has no model then $\Gamma \vDash \bot$, so $\Gamma \vdash \bot$.

### Step 1: maximal consistent sets

A consistent set $\Delta$ is **maximal consistent** if for every sentence $A$, $A \in \Delta$ or $\neg A \in \Delta$.

**Lemma 1.** If $\Gamma$ is consistent, then $\Gamma \cup \{A\}$ or $\Gamma \cup \{\neg A\}$ is consistent.
*Proof.* Suppose both are inconsistent. From $\Gamma, A \vdash \bot$, $\neg$I gives $\Gamma \vdash \neg A$. From $\Gamma, \neg A \vdash \bot$ and $\Gamma \vdash \neg A$, replace the assumption $\neg A$ by the derivation of $\neg A$ from $\Gamma$ to get $\Gamma \vdash \bot$, contradicting consistency. $\square$

**Lemma 2 (Lindenbaum).** If the language is countable, every consistent set $\Gamma$ extends to a maximal consistent $\Delta$.
*Proof.* List all sentences $A_0, A_1, A_2, \ldots$ (possible because the set of finite strings over a countable alphabet is countable). Put $\Gamma_0 = \Gamma$, and let $\Gamma_{n+1} = \Gamma_n \cup \{A_n\}$ if that is consistent, otherwise $\Gamma_n \cup \{\neg A_n\}$. By Lemma 1 each $\Gamma_n$ is consistent. Let $\Delta = \bigcup_n \Gamma_n$. It is consistent: a derivation of $\bot$ uses only finitely many premises, all of which lie in some single $\Gamma_n$, which would then be inconsistent. And for every $n$, $A_n$ or $\neg A_n$ is in $\Gamma_{n+1} \subseteq \Delta$. $\square$

**Lemma 3.** Let $\Delta$ be maximal consistent. Then (a) if $\Delta \vdash A$ then $A \in \Delta$; (b) $\neg A \in \Delta$ iff $A \notin \Delta$; (c) $A \wedge B \in \Delta$ iff $A \in \Delta$ and $B \in \Delta$; (d) $A \vee B \in \Delta$ iff $A \in \Delta$ or $B \in \Delta$; (e) $A \to B \in \Delta$ iff $A \notin \Delta$ or $B \in \Delta$.
For (a): if $A \notin \Delta$ then $\neg A \in \Delta$, so $\Delta \vdash A$ and $\Delta \vdash \neg A$ give $\Delta \vdash \bot$ by $\neg$E. For (b): not both $A, \neg A \in \Delta$ (else $\bot$), and at least one is, by maximality. The rest follow by (a), (b) and the rules ($\wedge$E, $\vee$E, $\to$E and their introductions).

### Step 2: the truth lemma (propositional case)

Define a valuation $v(P) = T$ iff $P \in \Delta$. **Truth Lemma:** for every formula $A$, $\bar v(A) = T$ iff $A \in \Delta$. By induction on formulas: atoms by definition of $v$; the cases of $\neg, \wedge, \vee, \to$ by clauses (b) to (e), which are exactly the truth-table clauses. So every consistent set of propositional formulas is satisfied by $v$.

### Step 3: first-order logic and Henkin witnesses

Two new problems arise: an existential sentence $\exists x\,\psi$ needs a *witness*, and there are no truth tables for quantifiers. Henkin solved both.

1. **Add witnesses.** Extend the language by countably many new constants $c_0, c_1, \ldots$. For each sentence $\exists x\,\psi(x)$ of the extended language (listed in order) add the **Henkin axiom** $\exists x\,\psi(x) \to \psi(c_n)$ for a constant $c_n$ not yet used. Consistency is preserved: if $\Gamma, \exists x\,\psi \to \psi(c) \vdash \bot$ for a $c$ new to $\Gamma$ and $\psi$, then $\Gamma \vdash \exists x\,\psi \wedge \neg\psi(c)$, so $\Gamma \vdash \exists x\,\psi$ and $\Gamma \vdash \neg\psi(c)$. Since $c$ is new, $\forall$I gives $\Gamma \vdash \forall x\,\neg\psi(x)$, which contradicts $\Gamma \vdash \exists x\,\psi$. So $\Gamma$ is inconsistent.
2. **Extend to a maximal consistent set** $\Delta$ by Lindenbaum (the extended language is still countable). It contains the Henkin axioms, so if $\exists x\,\psi \in \Delta$ then $\psi(c) \in \Delta$ for some constant $c$.
3. **Build the term model $\mathcal{M}$.** The domain is the set of closed terms modulo $t \sim s$ iff $t = s \in \Delta$ (this is an equivalence relation, by the identity rules). Interpret $f$ by $f([t_1], \ldots) = [f(t_1, \ldots)]$ and $R$ by: $R([t_1], \ldots)$ iff $R(t_1, \ldots) \in \Delta$.
4. **Truth Lemma.** For every sentence $A$: $\mathcal{M} \vDash A$ iff $A \in \Delta$. Induction on the complexity of $A$; atomic sentences by construction, connectives as before. For $\exists x\,\psi$: if it is in $\Delta$, so is $\psi(c)$ for a witness $c$, which is true in $\mathcal{M}$; conversely, if $\psi(t)$ is true for a term $t$ then $\psi(t) \in \Delta$ so $\Delta \vdash \exists x\,\psi$. For $\forall x\,\psi$: if it is in $\Delta$ then each $\psi(t)$ is, by $\forall$E; if it is not, then $\exists x\,\neg\psi \in \Delta$ by the quantifier equivalences, so some $\neg\psi(c) \in \Delta$, and $\psi(c)$ fails in $\mathcal{M}$.
5. $\mathcal{M}$ satisfies $\Delta \supseteq \Gamma$, so $\Gamma$ has a model (restrict to the original language). $\square$

The domain of the term model is countable. This is the seed of the Löwenheim-Skolem theorem, and of compactness, which we study next. Completeness fails for second-order logic with full semantics: no sound and effective proof system there derives all valid arguments.

@example
title: Lindenbaum's construction in action
problem: Let $\Gamma = \{P \vee Q, \neg P\}$ in a language with atoms $P, Q, R$, and list the sentences with the atoms first: $A_0 = P$, $A_1 = Q$, $A_2 = R$. Carry out the first three steps of Lindenbaum's construction and read off the valuation.
step: $\Gamma_0 = \Gamma$ is consistent: $P = F$, $Q = T$ satisfies it, so by soundness $\Gamma \nvdash \bot$.
step: $A_0 = P$: $\Gamma_0 \cup \{P\}$ is inconsistent (it contains $P$ and $\neg P$), so $\Gamma_1 = \Gamma_0 \cup \{\neg P\} = \Gamma_0$.
step: $A_1 = Q$: $\Gamma_1 \cup \{Q\}$ is satisfiable by $P = F$, $Q = T$, hence consistent, so $\Gamma_2 = \Gamma_1 \cup \{Q\}$.
step: $A_2 = R$: $\Gamma_2 \cup \{R\}$ is satisfiable by $P = F$, $Q = T$, $R = T$, hence consistent, so $\Gamma_3 = \Gamma_2 \cup \{R\}$.
step: The final set contains $\neg P$, $Q$ and $R$ among its atomic members, so $v(P) = F$, $v(Q) = T$, $v(R) = T$. (The construction put $R$ in only because it tries $A_n$ before $\neg A_n$; the other choice, putting $\neg R$ into the set, would have given a different maximal consistent set.)
answer: $v(P) = F$, $v(Q) = T$, $v(R) = T$.

@example
title: One closure property of a maximal consistent set
problem: Prove clause (d) of Lemma 3 in the direction: if $A \vee B \in \Delta$ then $A \in \Delta$ or $B \in \Delta$.
step: Suppose $A \vee B \in \Delta$ but $A \notin \Delta$ and $B \notin \Delta$.
step: By maximality, $\neg A \in \Delta$ and $\neg B \in \Delta$.
step: From $A \vee B$, $\neg A$ and $\neg B$ derive $\bot$: assume $A$, then $\bot$ by $\neg$E with $\neg A$; assume $B$, then $\bot$ by $\neg$E with $\neg B$; so $\vee$E gives $\bot$ from $A \vee B$.
step: Hence $\Delta \vdash \bot$, contradicting the consistency of $\Delta$. So $A \in \Delta$ or $B \in \Delta$.
answer: $A \vee B \in \Delta$ implies $A \in \Delta$ or $B \in \Delta$, by maximality and $\vee$E.

@mistakes
- Confusing completeness with soundness. Soundness: derivable implies valid. Completeness: valid implies derivable.
- Thinking that the term model is the "intended" model: it is built from syntax, its elements are terms, and it is only one of the many models of the set.
- Forgetting why the witnesses must be *new* constants: the consistency proof for the Henkin axioms uses $\forall$I, which needs $c$ to be absent from $\Gamma$ and $\psi$.
- Believing that a maximal consistent set decides a sentence "by proof": it contains $A$ or $\neg A$ by choice in the construction, not because $\Gamma$ proves either.

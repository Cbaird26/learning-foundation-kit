@article
Hilbert's hotel has infinitely many rooms, numbered $0, 1, 2, \ldots$, and every room is full. A new guest arrives. The manager moves the guest in room $n$ to room $n + 1$, and room $0$ is free. A bus with infinitely many new guests arrives next: move the guest in room $n$ to room $2n$ and give the new passengers the odd rooms. The story is not about hotels. It says that an infinite set can be put in one-to-one correspondence with a proper part of itself, which no finite set can do. This week makes "same size" precise for infinite sets.

### Same size, and countable

Two sets $A$ and $B$ have the same **cardinality**, $A \approx B$, if there is a bijection $f : A \to B$. This is the only workable notion of "same size" for infinite sets (Cantor's idea): we never count, we pair off. A set is **finite** if it is in bijection with $\{0, 1, \ldots, n - 1\}$ for some $n \in \mathbb{N}$, and **countably infinite** if it is in bijection with $\mathbb{N}$. A set is **countable** if it is finite or countably infinite; a bijection with $\mathbb{N}$ is an **enumeration**: a list $a_0, a_1, a_2, \ldots$ with every member of the set appearing exactly once.

**Lemma 1.** A set $A$ is countable iff there is an injection $A \to \mathbb{N}$, and a nonempty set $B$ is countable iff there is a surjection $\mathbb{N} \to B$.
For the second claim, given a surjection $s : \mathbb{N} \to B$, define $g(b)$ as the least $n$ with $s(n) = b$; $g$ exists because $s$ is onto, and $g$ is injective because $s(g(b)) = b$ for every $b$. Conversely, from an injection $g : B \to \mathbb{N}$ with $B$ nonempty, fix $b_0 \in B$ and let $s(n)$ be the $b$ with $g(b) = n$ if there is one, and $b_0$ otherwise.

### Basic examples

The integers are countable: the function $f(n) = n/2$ for even $n$ and $f(n) = -(n+1)/2$ for odd $n$ lists $\mathbb{Z}$ as $0, -1, 1, -2, 2, -3, \ldots$. It is injective, because even $n$ give values $\ge 0$ and odd $n$ give values $\le -1$, and on each class the formula is strictly monotone; and it is surjective, because $k \ge 0$ equals $f(2k)$ and $k \le -1$ equals $f(-2k - 1)$. Likewise $n \mapsto 2n$ is a bijection from $\mathbb{N}$ to the even numbers.

### Pairs of natural numbers

The **Cantor pairing function** $\pi : \mathbb{N} \times \mathbb{N} \to \mathbb{N}$ is
$$\pi(m, n) = \frac{(m + n)(m + n + 1)}{2} + n.$$
List the pairs by **diagonals** $m + n = d$. Diagonal $d$ has $d + 1$ pairs, and the diagonals $0, \ldots, d - 1$ together contain $1 + 2 + \cdots + d = d(d+1)/2$ pairs. So $\pi$ gives diagonal $d$ the numbers $d(d+1)/2, \ldots, d(d+1)/2 + d$, in the order $n = 0, 1, \ldots, d$. These blocks of numbers are consecutive and disjoint and cover $\mathbb{N}$, which shows $\pi$ is a bijection. To invert it, given $z$ find the largest $w$ with $w(w+1)/2 \le z$ (this $w$ is the diagonal), then $n = z - w(w+1)/2$ and $m = w - n$. In Python, `w = (math.isqrt(8 * z + 1) - 1) // 2` computes $w$ exactly without floating-point error.

### More countable sets

The pairing function opens the door to several theorems.

| P1 | $\mathbb{N} \times \mathbb{N}$ is countable. |
| P2 | The function $s : \mathbb{N} \times \mathbb{N} \to \mathbb{Q}_{\ge 0}$ with $s(m, n) = m/(n+1)$ is a surjection. |
| P3 | If a countable set maps onto a set $B$, then $B$ is countable. |
| C | So the set $\mathbb{Q}_{\ge 0}$ of nonnegative rationals is countable. |

The argument is valid. P1 is the pairing function. P2 holds because every nonnegative rational is $p/q$ with $q \ge 1$, and equals $s(p, q - 1)$. P3 is Lemma 1 (composing the surjection from $\mathbb{N}$ onto $\mathbb{N} \times \mathbb{N}$ with $s$). Negative rationals are handled by the same trick together with the integer enumeration, so $\mathbb{Q}$ is countable, though there are rationals densely between any two rationals.

Further results: the union of two countable sets is countable, and so is $A \times B$ for countable $A$, $B$. The set of **finite strings** over a finite alphabet is countable, because strings of length $k$ over an alphabet of $b$ symbols are finitely many ($b^k$ of them), and a countable union of finite sets can be listed length by length. So the set of all formulas of a first-order language with countably many symbols is countable, which is why a proof system has countably many proofs. The union of *countably many* countable sets is also countable, though the general proof needs a choice of an enumeration for each set (a weak form of the axiom of choice). Next week shows that some sets are not countable.

@example
title: Enumerating the rationals' building blocks
problem: Compute $\pi(2, 3)$ and find the pair $(m, n)$ with $\pi(m, n) = 17$.
step: For $\pi(2, 3)$: $m + n = 5$, so $\pi(2, 3) = \tfrac{5 \cdot 6}{2} + 3 = 15 + 3 = 18$.
step: To invert $17$, find the diagonal: the triangular numbers $w(w+1)/2$ are $0, 1, 3, 6, 10, 15, 21, \ldots$. The largest one that is at most $17$ is $15$, for $w = 5$.
step: Then $n = 17 - 15 = 2$ and $m = w - n = 5 - 2 = 3$. So $(m, n) = (3, 2)$.
step: Check: $\pi(3, 2) = \tfrac{5 \cdot 6}{2} + 2 = 17$. Also, $\pi(2, 3) = 18$ and $\pi(3, 2) = 17$ are on the same diagonal, $m + n = 5$, next to each other.
answer: $\pi(2, 3) = 18$ and $\pi^{-1}(17) = (3, 2)$.

@example
title: Hilbert's hotel as a bijection
problem: Show that $\mathbb{N}$ and $\mathbb{N} \setminus \{0\}$ have the same cardinality, and that a set can have the same size as a proper subset.
step: Define $h : \mathbb{N} \to \mathbb{N} \setminus \{0\}$ by $h(n) = n + 1$.
step: Injective: if $n + 1 = n' + 1$ then $n = n'$.
step: Surjective: if $k \ge 1$ then $k = h(k - 1)$ and $k - 1 \in \mathbb{N}$.
step: So $h$ is a bijection from $\mathbb{N}$ onto its proper subset $\mathbb{N} \setminus \{0\}$. This is the manager moving the guest in room $n$ to room $n + 1$. Having the same size as a proper part is a mark of being infinite (Dedekind used it as a definition).
answer: $h(n) = n + 1$ is a bijection from $\mathbb{N}$ onto $\mathbb{N} \setminus \{0\}$.

@mistakes
- Thinking that a proper subset of an infinite set must be smaller: the even numbers are a proper subset of $\mathbb{N}$ of the same cardinality.
- Proving only injectivity and calling a function a bijection; a bijection needs surjectivity too (the map $n \mapsto 2n$ from $\mathbb{N}$ to $\mathbb{N}$ is injective, not onto).
- Assuming the rationals are uncountable because they are dense; density concerns order, not size.
- Saying that "countable" means "finite"; countable sets include $\mathbb{N}$, which is infinite.

def nat_to_int(n):
    """Map 0, 1, 2, 3, 4, ... to 0, 1, -1, 2, -2, ..."""
    if n % 2 == 1:

@practice self
prompt: Let $A$ and $B$ be disjoint, countably infinite sets. Prove that $A \cup B$ is countably infinite by constructing a bijection from $\mathbb{N}$ onto $A \cup B$.
hint: Start from enumerations $\alpha : \mathbb{N} \to A$ and $\beta : \mathbb{N} \to B$ and interleave them.
hint: Send even numbers into $A$ and odd numbers into $B$, then prove injectivity and surjectivity separately.
solution: Let $\alpha : \mathbb{N} \to A$ and $\beta : \mathbb{N} \to B$ be bijections. Define $h(2n) = \alpha(n)$ and $h(2n + 1) = \beta(n)$. Injective: if $h(x) = h(y)$, both values lie in $A$ or both in $B$ (the sets are disjoint), so $x$ and $y$ have the same parity; if both are even, $\alpha(x/2) = \alpha(y/2)$ gives $x = y$ because $\alpha$ is injective, and the odd case is the same with $\beta$. Surjective: any $a \in A$ equals $\alpha(n)$ for some $n$, so $a = h(2n)$; any $b \in B$ equals $\beta(n) = h(2n + 1)$. So $h$ is a bijection from $\mathbb{N}$ onto $A \cup B$.
rubric: Defines an explicit map that interleaves the two enumerations.
rubric: Proves injectivity and uses disjointness of $A$ and $B$.
rubric: Proves surjectivity by handling members of $A$ and of $B$ separately.

@quiz code
prompt: Write `unpair(z)` that inverts the Cantor pairing function $\pi(m, n) = \frac{(m+n)(m+n+1)}{2} + n$: for every natural number `z` it returns the tuple `(m, n)` of natural numbers with $\pi(m, n) = z$. Use integer arithmetic (`math.isqrt`), not floating point.
starter:
```python
from math import isqrt


def unpair(z):
    pass
```
tests:
```python
assert unpair(0) == (0, 0)
assert unpair(26) == (1, 5)
assert unpair(11) == (3, 1)
pi = lambda m, n: (m + n) * (m + n + 1) // 2 + n
assert all(unpair(pi(m, n)) == (m, n) for m in range(12) for n in range(12))
assert [unpair(z) for z in range(6)] == [(0, 0), (1, 0), (0, 1), (2, 0), (1, 1), (0, 2)]
```
model:
```python
from math import isqrt


def unpair(z):
    """Return the pair (m, n) with pi(m, n) == z."""
    w = (isqrt(8 * z + 1) - 1) // 2
    n = z - w * (w + 1) // 2
    return (w - n, n)
```
hint: Find the diagonal $w = m + n$ as the largest $w$ with $w(w+1)/2 \le z$; the formula $w = (\sqrt{8z + 1} - 1)/2$, rounded down, gives it.
hint: Then $n = z - w(w+1)/2$ and $m = w - n$.
solution: Compute the diagonal $w$ with `isqrt` (the exact integer square root, so no rounding error), subtract the number of pairs on earlier diagonals to get $n$, and set $m = w - n$. The round-trip test confirms that `unpair` undoes `pi` on a grid of pairs.

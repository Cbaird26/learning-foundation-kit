@article
Does "if it snows, the road is closed; the road is not closed; so it did not snow" follow? In the last lesson you computed the value of a sentence for one assignment of truth values. A **complete truth table** does it for every assignment at once, and so settles every semantic question about a truth-functional sentence by finite checking.

### Building the table

List every sentence letter in the sentence, then every combination of truth values for them: $2^n$ rows for $n$ letters, in the **standard order**, with all letters true on the first row and the last letter alternating fastest. Then compute columns for subformulas, ending with a **main column** for the main connective.

### Semantic concepts

A sentence is a **tautology** if it is true on every row, a **contradiction** if it is false on every row, and **contingent** if it is true on some rows and false on others. A set of sentences **entails** a sentence, written $\Gamma \vDash A$, if there is no row on which every member of $\Gamma$ is true and $A$ is false. An argument is **valid** exactly when its premises entail its conclusion, so the truth-table test for validity is: look for a row with every premise true and the conclusion false. That row is a **counterexample** (a countermodel); if none exists, the argument is valid. Two sentences are **equivalent**, when they have the same truth value on every row; this holds exactly when $A \leftrightarrow B$ is a tautology. Note a link: $A \vDash B$ exactly when $A \to B$ is a tautology.

Some consequences are surprising. If $\Gamma$ is contradictory (no row makes all of it true), then there is no row with all premises true and a false conclusion, so $\Gamma$ entails every sentence. And if $B$ is a tautology, then every set entails $B$, since $B$ is never false.

### An argument about explosion

| P1 | An argument is valid if there is no possible situation in which all its premises are true and its conclusion false. |
| P2 | If the premises of an argument are contradictory, there is no possible situation in which all of them are true. |
| C | So an argument with contradictory premises is valid, whatever its conclusion. |

The argument is valid, and it uses the definition of validity from the first lesson in the "if" direction; P2 does the work. The best objection comes from **relevance logicians**, such as Anderson and Belnap: validity should require that the premises be *relevant* to the conclusion, and "$P \wedge \neg P$, so the moon is made of cheese" has no such connection. The classical reply is that validity is truth preservation and nothing more: such arguments never have true premises, so they can never lead from truth to falsehood, and they can do no harm; to demand relevance is to ask validity to do a different job, such as modeling what makes an inference a good way of reasoning.

@example
title: Classifying sentences
problem: Classify each sentence as a tautology, a contradiction or contingent: (a) $(P \to Q) \vee (Q \to P)$ (b) $P \wedge (Q \wedge \neg P)$ (c) $P \to \neg P$.
step: (a) Compute the table: $P \to Q$ is T, F, T, T and $Q \to P$ is T, T, F, T on rows TT, TF, FT, FF. The disjunction is T on all four rows. It is a tautology.
step: (b) The conjunct $P$ and the conjunct $Q \wedge \neg P$ cannot both be true, since the second needs $\neg P$. So the main column is F, F, F, F: a contradiction.
step: (c) $\neg P$ is F, F, T, T, so $P \to \neg P$ is F on the rows where $P$ is true and T where $P$ is false: F, F, T, T. It is true on some rows and false on others: contingent (and equivalent to $\neg P$).
answer: (a) tautology; (b) contradiction; (c) contingent.

@example
title: Testing an argument with a full table
problem: Test the argument $P \to Q$, $Q \to R$, so $P \to R$ for validity.
step: With three letters there are $2^3 = 8$ rows. Write the premises and conclusion as columns.
step: The table, with rows in the standard order:

| $P$ | $Q$ | $R$ | $P \to Q$ | $Q \to R$ | $P \to R$ |
|---|---|---|---|---|---|
| T | T | T | T | T | T |
| T | T | F | T | F | F |
| T | F | T | F | T | T |
| T | F | F | F | T | F |
| F | T | T | T | T | T |
| F | T | F | T | F | T |
| F | F | T | T | T | T |
| F | F | F | T | T | T |
step: Look for rows where both premise columns are T and the conclusion is F. Rows 1, 5, 7 and 8 have both premises true, and the conclusion is true on each of them. The other rows each have a false premise.
answer: There is no counterexample row, so the argument is valid.

@mistakes
- Stopping at the first row where the conclusion is true. Only rows where all premises are true matter, and on those the conclusion must be true; rows with a false premise are irrelevant to validity.
- Confusing a tautology with a valid argument: a tautology is a sentence that is true on every row, while an argument is valid when no row makes all premises true and the conclusion false.
- Writing the rows in a different order each time, which makes columns hard to compare. Use the standard order, last letter alternating fastest.
- Thinking that an argument with a contradictory premise set is invalid because "the conclusion has nothing to do with the premises": by the definition of validity it is valid.

@quiz mc
prompt: Which statement about entailment is correct?
choice*: A set of sentences that is true on no row entails every sentence.
choice: A sentence entails another only if they share a sentence letter.
choice: If $A$ entails $B$, then $B$ entails $A$.
choice: An argument is invalid if its premises are all false on some row.
hint: Look for a row with every premise true and the conclusion false.
solution: If no row makes every premise true, there is no row making them true with the conclusion false, so a contradictory set entails everything. Entailment does not require shared letters (a tautology is entailed by anything), it is not symmetric ($P \wedge Q$ entails $P$ but not the converse), and rows with false premises never make an argument invalid.

@quiz self
prompt: Use a truth table to show that $(P \to Q) \to P$ is equivalent to $P$. Then say whether $(P \to Q) \to P$ is a tautology.
hint: Compute $P \to Q$ on all four rows, then the whole conditional.
solution: On rows TT, TF, FT, FF, $P \to Q$ is T, F, T, T, so $(P \to Q) \to P$ is T, T, F, F. That is the column of $P$ itself (T, T, F, F), so the two are equivalent. It is not a tautology, because it is false on the rows where $P$ is false. (The conditional $((P \to Q) \to P) \to P$ is a tautology, known as Peirce's law.)

@article
From "every philosopher is wise" and "Ana is a philosopher", you can conclude that Ana is wise. From "somebody left the door open" you cannot conclude that Ana did. The quantifier rules say exactly when you may pass between general sentences and their instances. Every rule from the truth-functional system stays; we add six.

### The rules

Write $A(c)$ for a sentence with the name $c$ in place of the variable $x$ in $A(x)$.

| Rule | What it does | Restriction |
|---|---|---|
| $\forall$E | from $\forall x\,A(x)$ infer $A(c)$, for any name $c$ | none |
| $\forall$I | from $A(c)$ infer $\forall x\,A(x)$ | $c$ must not occur in any undischarged assumption (premises count) |
| $\exists$I | from $A(c)$ infer $\exists x\,A(x)$ | none |
| $\exists$E | from $\exists x\,A(x)$ and a subproof $i$–$j$ that assumes $A(c)$ and ends in $B$, infer $B$ | $c$ must not occur in any undischarged assumption outside the subproof, in $\exists x\,A(x)$, or in $B$ |
| $=$I | infer $c = c$, citing no line | none |
| $=$E | from $a = b$ and a sentence containing $a$, infer the result of replacing one or more occurrences of $a$ by $b$ (or the reverse) | none |

**Why the restrictions?** Without the restriction on $\forall$I you could assume $Fa$ and infer $\forall x\,Fx$, which would prove that if one thing is $F$ then everything is. The name $a$ would be "carrying" information from an assumption, not standing for an arbitrary object. $\forall$I works only when the name is arbitrary: nothing special is assumed about it. Likewise, without the restriction on $\exists$E, from $\exists x\,Fx$ and $\exists x\,Gx$ you could assume $Fa$ and $Ga$ for the same $a$ and conclude $\exists x(Fx \wedge Gx)$. The name introduced by $\exists$E must be fresh: it stands for *some* witness about which nothing else is known.

### An argument to prove

A famous argument, usually attributed to Descartes, says "I think, therefore I am". Put into standard form with the premise that it needs, it is:

| P1 | I think. |
| P2 | Whatever thinks exists. |
| C | So I exist. |

Let $a$ name the thinker, $Tx$: "$x$ thinks", $Ex$: "$x$ exists". The form is $Ta$, $\forall x(Tx \to Ex)$, so $Ea$.

```text
1 | Ta               PR
2 | ∀x(Tx → Ex)      PR
  |---
3 | Ta → Ea          ∀E 2
4 | Ea               →E 3, 1
```

The argument is valid; the philosophical questions concern P2 and P1. Descartes himself, in his replies to objections, denied that the cogito is a syllogism from a general principle, saying that one knows one's own existence directly through thinking. The best objection to the premise P1 is a point often credited to Lichtenberg: all that is given is that there is thinking, not that there is an "I" that does it. The reply is that the very occurrence of a thought is something that must have a subject, which is a form of P2; a critic can respond that P2 then begs the question about what the subject is. A note on the logic: in first-order logic every name refers to an object, so $\exists x\,x = a$ is provable from no premises. That is why the formalization needs the predicate $E$: it treats existence as a property that things may have or lack, which is itself something that philosophers dispute.

@example
title: A proof with $\forall$I
problem: Prove $\forall x\,Gx$ from the premises $\forall x(Fx \to Gx)$ and $\forall x\,Fx$.
step: To prove a universal sentence, prove an instance for a name that appears in no assumption, then apply $\forall$I. Use the name $a$, which does not occur in the premises.
step: Instantiate both premises with $a$ by $\forall$E, then use $\to$E to get $Ga$.
step: Apply $\forall$I to line 5. The name $a$ occurs only in lines 3–5, not in a premise or an open assumption, so the restriction holds.
```text
1 | ∀x(Fx → Gx)       PR
2 | ∀x Fx             PR
  |---
3 | Fa → Ga           ∀E 1
4 | Fa                ∀E 2
5 | Ga                →E 3, 4
6 | ∀x Gx             ∀I 5
```
answer: $\forall x(Fx \to Gx)$, $\forall x\,Fx$ $\vdash \forall x\,Gx$, as proved.

@example
title: A proof with $\exists$E
problem: Prove $\exists x\,Gx$ from the premises $\forall x(Fx \to Gx)$ and $\exists x\,Fx$.
step: Use the existential premise by $\exists$E: assume an instance $Fa$ with a fresh name $a$ for the witness, derive the goal inside the subproof, then close it.
step: Inside the subproof, $\forall$E gives $Fa \to Ga$, $\to$E gives $Ga$, and $\exists$I gives $\exists x\,Gx$.
step: Apply $\exists$E to line 2 and the subproof 3–6. The name $a$ does not occur in the premises, in $\exists x\,Fx$, or in the conclusion $\exists x\,Gx$, so the restriction holds.
```text
1 | ∀x(Fx → Gx)       PR
2 | ∃x Fx             PR
  |---
3 | | Fa              AS
4 | | Fa → Ga         ∀E 1
5 | | Ga              →E 4, 3
6 | | ∃x Gx           ∃I 5
7 | ∃x Gx             ∃E 2, 3–6
```
answer: $\forall x(Fx \to Gx)$, $\exists x\,Fx$ $\vdash \exists x\,Gx$, as proved.

@mistakes
- Applying $\forall$I to a name that occurs in a premise or an open assumption, as in "from $Fa$ infer $\forall x\,Fx$". The name must be arbitrary.
- Using $\exists x\,Fx$ to infer $Fa$ directly. You may only *assume* $Fa$ in an $\exists$E subproof, and the conclusion must not contain $a$.
- Citing a line inside the $\exists$E subproof from outside it. Only the final line of the subproof's result, $B$, is available after $\exists$E.
- Forgetting that $\forall$E and $\exists$I may be applied to any name, but $\forall$I and $\exists$E need a name that is new.

@practice mc
prompt: Which is a correct use of $\forall$E, given the line $\forall x(Rxa \to Fx)$ ?
choice*: Infer $Rba \to Fb$.
choice: Infer $Rxa \to Fb$.
choice: Infer $\forall x\,Fx$.
choice: Infer $\exists x(Rxa \to Fx)$ and then $Rba$.
hint: $\forall$E replaces every occurrence of the variable by the same name.
solution: $\forall$E replaces every occurrence of the bound variable by the same name, here $b$, giving $Rba \to Fb$. The name $a$ already in the formula is unaffected. The sentence $Rxa \to Fb$ mixes a variable and a name, and the other choices are not instances of $\forall$E.

@practice ms
prompt: Which of these are correct single applications of the quantifier and identity rules? Select all that apply.
choice*: From $\forall x\,Fx$, infer $Fb$ by $\forall$E.
choice: From the premise $Fa$, infer $\forall x\,Fx$ by $\forall$I.
choice*: From $Fa$, infer $\exists x\,Fx$ by $\exists$I.
choice: From $\exists x\,Fx$, infer $Fa$.
choice*: With no cited line, write $b = b$ by $=$I.
hint: Check whether each rule's restriction on names is respected.
solution: $\forall$E, $\exists$I and $=$I are always allowed. The inference from the premise $Fa$ to $\forall x\,Fx$ breaks the restriction on $\forall$I, since $a$ occurs in a premise, and the inference from $\exists x\,Fx$ to $Fa$ has no justification: a witness exists, but nothing says it is $a$.

@practice mc
prompt: What is wrong with this attempted proof of $\exists x(Fx \wedge Gx)$ from the premises $\exists x\,Fx$ and $\exists x\,Gx$?
```text
1 | ∃x Fx             PR
2 | ∃x Gx             PR
  |---
3 | | Fa              AS
4 | | | Ga            AS
5 | | | Fa ∧ Ga       ∧I 3, 4
6 | | | ∃x(Fx ∧ Gx)   ∃I 5
7 | | ∃x(Fx ∧ Gx)     ∃E 2, 4–6
8 ∃x(Fx ∧ Gx)         ∃E 1, 3–7
```
choice*: The same name $a$ is used as the witness in both $\exists$E subproofs, but the second subproof must use a name new to the first, since the first's assumption $Fa$ is still open.
choice: $\exists$I may not be applied to a conjunction.
choice: $\exists$E requires the premises to be universal sentences.
choice: A subproof may not be nested inside another subproof.
hint: Look at the restriction on the name in $\exists$E, and at which assumptions are still open on line 4.
solution: When $Ga$ is assumed on line 4, the assumption $Fa$ from line 3 is still open, so $a$ occurs in an undischarged assumption and the second use of $\exists$E breaks the restriction. Indeed the argument is invalid: some thing may be $F$ and a different thing $G$. Nesting subproofs is allowed, and $\exists$I applies to any sentence containing a name.

@practice num
prompt: The sequent $\exists x(Fx \wedge Gx) \vdash \exists x\,Fx \wedge \exists x\,Gx$ is provable, so the argument is valid. The domain has three objects, and an interpretation chooses extensions for the one-place predicates $F$ and $G$ (64 interpretations). In how many is the premise $\exists x(Fx \wedge Gx)$ true?
answer: 37
unit: interpretations
check: sum(1 for fg in product(product([0, 1], repeat=2), repeat=3) if any(f and g for f, g in fg))
hint: Count the interpretations in which the premise is false, that is, in which no object is both $F$ and $G$.
solution: Each object has four possible pairs of values for ($Fx$, $Gx$), and three of them are not both true. The premise is false when all three objects avoid being both: $3^3 = 27$ interpretations. So it is true in $64 - 27 = 37$.

@practice self
prompt: Write a proof of $\forall x\,\neg Fx$ from the premise $\neg\exists x\,Fx$, with the rule and line numbers on every line.
hint: To prove a universal sentence, prove an instance with a name not occurring in any assumption. To prove $\neg Fa$, assume $Fa$.
solution:
```text
1 | ¬∃x Fx            PR
  |---
2 | | Fa              AS
3 | | ∃x Fx           ∃I 2
4 | | ⊥               ¬E 3, 1
5 | ¬Fa               ¬I 2–4
6 | ∀x ¬Fx            ∀I 5
```
rubric: Assumes $Fa$ to prove $\neg Fa$ and derives $\bot$ using $\exists$I and the premise.
rubric: Closes with $\neg$I citing the subproof, then applies $\forall$I.
rubric: States or shows that $a$ occurs in no open assumption or premise when $\forall$I is applied.

@quiz mc
prompt: In an $\exists$E subproof that begins by assuming an instance of $\exists x\,A(x)$, which name may be used for the instance?
choice*: A name that occurs in no premise, no open assumption, $\exists x\,A(x)$, or the conclusion of the subproof.
choice: Any name that occurs in the premises, so that the instance is connected to them.
choice: Only a name that occurs in the conclusion.
choice: Any name, since $\exists$E has no restriction.
hint: The name stands for an unknown witness about which nothing else may be assumed.
solution: The name must be fresh: it may not occur in any open assumption or premise, in the existential sentence, or in the sentence the subproof proves. Otherwise information about other objects would be smuggled into the witness.

@quiz self
prompt: Write a proof of $\forall x\forall y(x = y \to y = x)$ from no premises, with the rule and line numbers on every line.
hint: Prove an instance for fresh names $a$ and $b$ by conditional proof, then generalize. You will need $=$I and $=$E.
solution:
```text
  |---
1 | | a = b                     AS
2 | | a = a                     =I
3 | | b = a                     =E 1, 2
4 | a = b → b = a               →I 1–3
5 | ∀y(a = y → y = a)           ∀I 4
6 | ∀x∀y(x = y → y = x)         ∀I 5
```
rubric: Assumes $a = b$ and uses $=$I to get $a = a$.
rubric: Uses $=$E to replace the first occurrence of $a$ by $b$, getting $b = a$.
rubric: Closes with $\to$I and then generalizes twice with $\forall$I, noting that no open assumption contains the names.

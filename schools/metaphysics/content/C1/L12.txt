@article
You now have two different tests for an argument. A **proof** shows it valid; a **countermodel** shows it invalid. Why should the first be trustworthy, and why would one of the two always be available? Two metatheorems answer. Write $\Gamma \vdash A$ for "there is a proof of $A$ from premises $\Gamma$" and $\Gamma \vDash A$ for "every interpretation making all of $\Gamma$ true makes $A$ true".

### The two theorems

| Property | Statement | What it says |
|---|---|---|
| **Soundness** | If $\Gamma \vdash A$, then $\Gamma \vDash A$. | The proof system proves only valid arguments. |
| **Completeness** | If $\Gamma \vDash A$, then $\Gamma \vdash A$. | Every valid argument has a proof. |

Soundness is proved by induction on the length of a proof. One shows that every line of a proof is entailed by the premises and the assumptions open at that line: premises and assumptions entail themselves, and each rule leads from lines with this property to a new line with it. For $\to$E, if the premises together with the open assumptions make $A \to B$ and $A$ true, they make $B$ true. The restrictions on $\forall$I and $\exists$E are exactly what is needed for this step to hold for the quantifier rules. Without them, one could "prove" that $Fa$ entails $\forall x\,Fx$, which is not valid.

Completeness is much harder. The idea of the standard proof is to show the contrapositive: if there is no proof of $A$ from $\Gamma$, then $\Gamma$ together with $\neg A$ is **consistent** (it does not prove $\bot$), and every consistent set of sentences has a model, which can be built out of the names and sentences of the language itself (a **Henkin construction**). That model is a countermodel to the argument. Completeness for the truth-functional system was proved by Post (1921); for first-order logic by Gödel (1929–1930).

### What follows for you

- A proof of $A$ from $\Gamma$ shows, by soundness, that no countermodel exists.
- A countermodel shows, by soundness, that no proof exists.
- By completeness, if an argument is valid then a proof exists, so a search for proofs finds every valid argument eventually.

### Limits

- **Decidability.** For truth-functional logic, a truth table with at most $2^n$ rows for $n$ letters settles validity mechanically. For first-order logic no algorithm decides, for every argument, whether it is valid (Church and Turing, 1936). Because proofs can be listed one after another, valid arguments can be found by patient search, but a search for a proof or a countermodel may run forever.
- **Compactness.** A set of first-order sentences has a model if and only if every finite subset of it has a model. It follows from completeness, since a proof uses only finitely many premises.
- **Löwenheim–Skolem.** If a set of first-order sentences in a countable language has a model, it has a model whose domain is finite or countable; and if it has an infinite model, it has models of every infinite size. So first-order sentences cannot pin down the size of an infinite domain, and no first-order theory can fix the natural numbers uniquely.
- **Incompleteness is something else.** Gödel's *incompleteness* theorems (1931) concern **theories**: any consistent, effectively axiomatized theory strong enough for basic arithmetic leaves some arithmetical sentence neither provable nor refutable. That is a fact about particular sets of axioms, not about the logic, and it does not conflict with the completeness theorem, which says that whatever is entailed by given axioms is provable from them.

### An argument about what validity is

Kreisel's **squeezing argument** uses completeness to argue that the formal notions capture the intuitive one. Call an argument *intuitively valid* when its conclusion would be true in every possible circumstance in which its premises are:

| P1 | If $\Gamma \vdash A$, then the argument from $\Gamma$ to $A$ is intuitively valid (each rule is evidently valid). |
| P2 | If the argument from $\Gamma$ to $A$ is intuitively valid, then $\Gamma \vDash A$ (a counterexample in some interpretation would be a possible circumstance of the forbidden kind). |
| P3 | If $\Gamma \vDash A$, then $\Gamma \vdash A$ (completeness). |
| C | So $\Gamma \vdash A$, intuitive validity and $\Gamma \vDash A$ all coincide. |

The argument is valid: the three conditionals form a loop, so each notion implies the others. P1 is secure, and P3 is a theorem. The premise doing the philosophical work is P2. The best objection, in the spirit of Etchemendy's criticisms of the model-theoretic analysis of consequence, is that P2 assumes that every interpretation, a set-theoretic structure, corresponds to a genuinely possible circumstance, so that a countermodel always shows an intuitive counterexample; if "true in all interpretations" is only a mathematical property, nothing guarantees that it tracks necessity. The reply is that this is plausible for the formal arguments of first-order logic: a countermodel, once its objects and predicates are described in ordinary terms, describes a circumstance of exactly the forbidden kind, with true premises and a false conclusion. One might still doubt it for arguments whose validity depends on more than form.

@example
title: What can you conclude?
problem: You are studying an argument $\Gamma$, so $A$ in first-order logic. What follows in each case? (a) You find a countermodel. (b) You find a proof. (c) After a long search you find neither.
step: (a) The countermodel makes all of $\Gamma$ true and $A$ false, so $\Gamma \nvDash A$. By soundness, if there were a proof then $\Gamma \vDash A$; so there is no proof: the argument is invalid.
step: (b) By soundness, $\Gamma \vDash A$, so no interpretation is a countermodel. You have shown that the argument is valid.
step: (c) Nothing definite follows. By completeness, if the argument is valid then a proof exists, and if it is invalid then (in the cases where a finite countermodel exists) you may find one; but since first-order validity is undecidable, no general procedure tells you in advance how long the search will take, and some invalid arguments have only infinite countermodels.
answer: (a) invalid; (b) valid; (c) no conclusion yet.

@example
title: Soundness for a rule
problem: Show that $\to$E preserves entailment: if every interpretation making all of $\Gamma$ true makes both $A \to B$ and $A$ true, then it makes $B$ true.
step: Take any interpretation in which all of $\Gamma$ is true. By the hypothesis, $A \to B$ and $A$ are both true in it.
step: By the truth table for $\to$, a true conditional with a true antecedent has a true consequent, so $B$ is true.
step: This holds for every interpretation making $\Gamma$ true, so $\Gamma \vDash B$. A proof that uses $\to$E at a line therefore never leads from lines entailed by the premises to a line that is not.
answer: $\to$E preserves entailment. The same kind of argument, rule by rule, proves soundness.

@mistakes
- Confusing soundness (provable implies valid) with completeness (valid implies provable).
- Confusing the completeness of first-order logic with the incompleteness of arithmetic: the first is about the proof system, the second about certain theories.
- Treating "undecidable" as "unprovable": undecidability of first-order validity means that no algorithm settles every case, not that some valid arguments lack proofs.
- Thinking that completeness lets you decide validity by trying to find a proof: if the argument is invalid, the search for a proof never ends.

prompt: Which statement is the soundness of a proof system?
choice*: If there is a proof of $A$ from $\Gamma$, then $A$ is true in every interpretation in which all of $\Gamma$ is true.
choice: If $A$ is true in every interpretation in which all of $\Gamma$ is true, then there is a proof of $A$ from $\Gamma$.
choice: Every sentence is either provable or refutable.
choice: There is an algorithm that decides whether an argument is valid.
hint: Soundness guarantees that proofs do not lead from truth to falsehood.
solution: Soundness says that provability implies entailment: whatever can be proved from $\Gamma$ is true wherever $\Gamma$ is true. The statement that every valid argument has a proof is completeness, the claim that every sentence is provable or refutable is a (false) claim of the kind that incompleteness theorems refute for arithmetic, and the existence of an algorithm that decides validity is what Church and Turing showed to be impossible for first-order logic.

prompt: A truth-functional argument uses twelve different sentence letters. At most how many rows of a complete truth table must you check to decide whether it is valid?
answer: 4096
unit: rows
check: 2 ** 12
hint: Each letter independently has two values.
solution: A complete table has $2^{12} = 4096$ rows, so at most 4096 rows need to be checked (fewer if you stop at the first counterexample). This is why truth-functional validity is decidable, in contrast with first-order validity.

@practice self
prompt: In four or five sentences, explain why Gödel's completeness theorem for first-order logic and his first incompleteness theorem do not contradict each other.
hint: Say what each theorem is about: the proof system in general, or a particular set of axioms.
solution: The completeness theorem says that the first-order proof system is strong enough: whatever is entailed by a set of premises is provable from them. The first incompleteness theorem concerns a particular kind of theory, a consistent and effectively axiomatized set of axioms strong enough for basic arithmetic, and says that there is an arithmetical sentence which that theory neither proves nor refutes. There is no contradiction, because such a sentence is not entailed by the axioms: it is true in some models of them and false in others, so completeness does not say it must be provable. The two results are about different things, the logic and a theory expressed in it.
rubric: States what completeness says: entailment implies provability, for any premises.
rubric: States that incompleteness is about particular theories of arithmetic with some sentence neither provable nor refutable.
rubric: Explains why they are consistent: an undecided sentence is true in some models of the axioms and false in others, so it is not entailed.

@quiz mc
prompt: Which of these is a consequence of compactness for first-order logic?
choice*: If every finite subset of an infinite set of sentences has a model, then the whole set has a model.
choice: Every first-order sentence is either provable or refutable.
choice: Every consistent first-order theory has a model with exactly one object.
choice: Every first-order sentence has a finite model.

solution: Compactness says that a set of sentences has a model whenever each of its finite subsets does. The other choices are false: sentences can be neither provable nor refutable, some consistent theories (such as one that says there are at least two objects) have no one-object model, and some sentences have only infinite models.

@quiz self
prompt: A student says: "By completeness, if I cannot find a proof of an argument after a week of trying, then it must be invalid." Say what is wrong with this inference, using what you know about soundness, completeness and decidability.
hint: Ask what completeness guarantees, and whether a failed search ever shows that no proof exists.
solution: Completeness says that every valid argument has a proof, not that a proof can be found in any particular time. A failure to find a proof in a week shows nothing about validity: the proof may be longer than the student tried, or the argument may be invalid, and since first-order validity is undecidable there is no general method to tell which in advance. To show invalidity the student needs a countermodel, which by soundness proves that no proof exists.

rubric: Mentions that undecidability means no general method settles every argument.
rubric: Says that invalidity is shown by a countermodel (with soundness), not by a failed search.

@article
Compare two arguments. The first: "Every multiple of 6 is even. 18 is a multiple of 6. So 18 is even." The second: "Every multiple of 6 is even. 14 is even. So 14 is a multiple of 6." Both start from a true general claim, and both use only true premises. Yet the first is a good argument and the second is a bad one. Logic is the study of what makes the difference, and it aims to say so in a way that does not depend on numbers, multiples or evenness at all.

### Arguments

An **argument** is a set of sentences, the **premises**, offered as support for a further sentence, the **conclusion**. Words such as "so", "therefore", "hence" and "thus" mark conclusions; "because", "since" and "for" mark premises. In this course we set an argument out in **standard form**: premises labeled P1, P2, and so on, then the conclusion C.

### Validity and soundness

An argument is **valid** when there is no possible situation in which all its premises are true and its conclusion false. Equivalently: if the premises were all true, the conclusion would have to be true. An argument that is not valid is **invalid**, and a situation in which the premises are true and the conclusion false is a **counterexample** to it. An argument is **sound** when it is valid and all its premises are true.

Validity is a claim about the *connection* between premises and conclusion, not about whether they are in fact true. Of the four combinations of a valid or invalid argument with true or false premises, only one cannot occur together with a false conclusion: a valid argument with all true premises has a true conclusion. So a valid argument with a false conclusion must have a false premise, and a sound argument always has a true conclusion. Everything else is possible: a valid argument can have a false premise and a true conclusion, and an invalid argument can have true premises and a true conclusion.

The second argument above is invalid. A counterexample need not be exotic: the actual number 14 is even and is not a multiple of 6, so the premises are true and the conclusion is false.

### Form

The first argument is valid because of its **form**: every F is a G; a is an F; so a is a G. Any argument of that form is valid whatever F, G and a stand for. The second argument has the form: every F is a G; a is a G; so a is an F. That form is invalid, because some arguments of that form have true premises and a false conclusion. A **formal language** makes forms explicit: it replaces the content-bearing parts of sentences by symbols and keeps the logical words, so that validity can be checked by rule instead of by imagination.

### The language of truth-functional logic

The first formal language we use has **sentence letters** $P, Q, R, \ldots$ (with subscripts if we run out) and five **connectives**: $\neg$ (not), $\wedge$ (and), $\vee$ (or), $\to$ (if...then), $\leftrightarrow$ (if and only if), together with parentheses. A **well-formed formula** (wff, or sentence) is defined recursively:

1. Every sentence letter is a wff.
2. If $A$ is a wff, then $\neg A$ is a wff.
3. If $A$ and $B$ are wffs, then $(A \wedge B)$, $(A \vee B)$, $(A \to B)$ and $(A \leftrightarrow B)$ are wffs.
4. Nothing else is a wff.

By convention we drop the outermost parentheses. Each binary connective brings its own parentheses, so $P \wedge Q \vee R$ is not a wff: it does not say whether the conjunction or the disjunction comes last. The **main connective** of a wff is the one added last in its construction; in $\neg(P \to Q)$ it is $\neg$, and in $(P \to Q) \vee R$ it is $\vee$. Statements *in* the formal language form the **object language**; the English we use to talk about it is the **metalanguage**.

### An argument to evaluate

| P1 | If the planet Lumen has an atmosphere, then it has weather. |
| P2 | Lumen has no weather. |
| C | So Lumen has no atmosphere. |

The argument is valid. Write $A$ for "Lumen has an atmosphere" and $W$ for "Lumen has weather": the form is $A \to W$, $\neg W$, so $\neg A$. Both premises do work: without P1 nothing links weather to atmosphere, and without P2 nothing is denied. Whether it is sound depends on the premises. The best objection is to P1: an atmosphere might be too thin or too still to produce weather. The reply is not that the argument is invalid, but that it is then unsound; a defender must replace P1 with a more careful claim, such as "if Lumen has a dense atmosphere, then it has weather", and then the conclusion must change too, because the new argument concludes only that Lumen has no dense atmosphere. A valid argument shows exactly what each premise commits you to.

@example
title: Valid, invalid, sound
problem: Classify each argument as valid or invalid, and sound or unsound. (a) "Every prime greater than 2 is odd. 9 is odd. So 9 is a prime greater than 2." (b) "Every triangle has three sides. This shape is a triangle. So this shape has three sides." (c) "All fish can fly. Rex is a fish. So Rex can fly."
step: For (a), look for a counterexample. The premises are true. The conclusion is false, since 9 = 3 times 3. The actual situation is a counterexample, so (a) is invalid, and therefore unsound.
step: For (b), try to describe a situation where both premises are true and the conclusion false: none exists, because being a triangle already requires three sides. The form is "every F is a G, a is an F, so a is a G", so (b) is valid. Its premises are true of any real triangle, so it is sound.
step: For (c), the form is the same as in (b), so it is valid: if all fish could fly and Rex were a fish, Rex could fly. But the first premise is false, so the argument is unsound.
answer: (a) invalid, unsound; (b) valid, sound; (c) valid, unsound.

@example
title: Is it a well-formed formula?
problem: For each string, say whether it is a wff, and if so name its main connective. (a) $(P \to (Q \vee \neg R))$ (b) $P \wedge Q \vee R$ (c) $\neg(P \leftrightarrow \neg Q)$ (d) $(P \to) Q$
step: (a) Build it up: $R$ is a wff, so $\neg R$ is; then $(Q \vee \neg R)$ is; then $(P \to (Q \vee \neg R))$ is. The last connective added is $\to$, so it is a wff with main connective $\to$ (outer parentheses may be dropped).
step: (b) Two binary connectives share no parentheses, so rule 3 cannot have produced it: it is not a wff. Either $(P \wedge Q) \vee R$ or $P \wedge (Q \vee R)$ would be.
step: (c) $\neg Q$ is a wff, so $(P \leftrightarrow \neg Q)$ is, and then so is $\neg(P \leftrightarrow \neg Q)$. The main connective is the leading $\neg$.
step: (d) The connective $\to$ needs a wff on each side inside one pair of parentheses: this string is not a wff.
answer: (a) wff, main connective $\to$; (b) not a wff; (c) wff, main connective $\neg$; (d) not a wff.

@mistakes
- Calling an argument invalid because its conclusion is false, or valid because its premises are true. Validity is about whether the premises could be true while the conclusion is false, not about what is actually true.
- Treating "sound" as a synonym for "valid": sound means valid with all premises actually true.
- Looking at an argument's subject matter instead of its form: two arguments on different topics can share an invalid form.
- Reading $P \wedge Q \vee R$ as a wff: the language requires parentheses to show which connective is the main one.

solution: Validity forbids true premises with a false conclusion, so the valid argument with all true premises and a false conclusion cannot exist, and neither can a sound argument with a false conclusion, since soundness means valid with true premises. The other three kinds are possible: validity says nothing against a false premise with a true conclusion, and an invalid argument may happen to have a true conclusion, or false premises and a false conclusion.

@quiz self
prompt: Put the following reasoning in standard form and say whether it is valid: "The lamp is on only if the switch is down. The switch is not down. So the lamp is not on." Then name one way someone could object to it.
hint: Let $L$ stand for "the lamp is on" and $D$ for "the switch is down", and write the form.
solution: P1: If the lamp is on, then the switch is down. P2: The switch is not down. C: So the lamp is not on. The form is $L \to D$, $\neg D$, so $\neg L$. It is valid: if the premises were true and the lamp were on, then by P1 the switch would be down, contradicting P2. An objector can reject P1, for example by pointing out that the lamp could be wired so that it is on while the switch is up; that would make the argument unsound, not invalid.

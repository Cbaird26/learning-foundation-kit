title: A logic workbook of five philosophical arguments
overview: You will formalize five arguments of the kind found in classic philosophical debates, decide which are valid, prove the valid ones in natural deduction, give countermodels for the invalid ones, and write a page on what formalizing each argument revealed. The workbook uses everything in the course: symbolization, truth tables and partial tables, proofs, quantifiers, identity and interpretations.
goal: Symbolize arguments from philosophical texts accurately, with an explicit key and domain.
goal: Decide validity with the right tool (partial table, proof or countermodel) and justify every line.
goal: Say what formalization shows about an argument: hidden premises, the exact location of the disagreement, and the limits of formalization.
step: Read the five arguments in the material below (or, if you prefer, replace up to two of them with arguments from texts you find through the course reading, the encyclopedias or PhilPapers, citing what you use). For each, mark the premises and conclusion and note any hidden premise you think the author needs.
step: For each argument choose a symbolization key. Decide whether it needs only sentence letters or also names, predicates, quantifiers and identity, and write the domain when you use quantifiers. Symbolize the premises and the conclusion.
step: Before writing any proof, decide for each argument whether it is valid, using a partial truth table for the truth-functional ones and an attempt at a countermodel for the quantified ones.
step: For each valid argument, write a natural deduction proof with the rule and line numbers on every line. Check each line against the rule, and check the restrictions on $\forall$I and $\exists$E where you use them.
step: For each invalid argument, give a countermodel: a truth-value assignment, or an interpretation with its domain, names and extensions. Verify every premise and the conclusion in it, and say what extra premise would be needed to make the argument valid.
step: Write about a page (400 to 500 words) on what formalizing the arguments revealed: the hidden premises you found, where a defender or critic would push back, a place where the symbolization could be done in more than one way, and what the formal treatment cannot tell you.
step: Assemble the workbook with one section per argument (key, symbolization, verdict, proof or countermodel), put the reflection at the end, and use the self-check list in the review guide to test every item.
material: Argument 1 (an ontological argument, simplified). Use $U$: God exists in the understanding; $R$: God exists in reality; $G$: a being greater than God can be conceived.

| P1 | God exists in the understanding. |
| P2 | If God exists in the understanding but not in reality, then a being greater than God can be conceived. |
| P3 | No being greater than God can be conceived. |
| C | So God exists in reality. |
material: Argument 2 (a skeptical argument, in the closure style). Use $K$: I know that I have hands; $N$: I know that I am not a brain in a vat.

| P1 | If I know that I have hands, then I know that I am not a brain in a vat. |
| P2 | I do not know that I am not a brain in a vat. |
| C | So I do not know that I have hands. |
material: Argument 3 (an argument about personal identity, from a fission case). Names: $o$ for the original person, $l$ for the survivor on the left, $r$ for the survivor on the right. Use identity.

| P1 | The left survivor is not identical to the right survivor. |
| C | So the original person is not identical to both the left survivor and the right survivor. |
material: Argument 4 (an argument about the mind, in the spirit of debates over direct awareness). Domain: all states. Use $Mx$: $x$ is a mental state; $Bx$: $x$ is a brain state; $Dx$: $x$ is something I know directly.

| P1 | Every mental state is something I know directly. |
| P2 | Some brain states are things I know directly. |
| C | So some brain states are mental states. |
material: Argument 5 (an argument from design, as critics sometimes read it). Use $D$: the universe has a designer; $O$: the universe shows order.

| P1 | If the universe has a designer, then the universe shows order. |
| P2 | The universe shows order. |
| C | So the universe has a designer. |

## Week-by-week key ideas

1. **Arguments and validity.** Valid: no possible situation with true premises and a false conclusion. Sound: valid with true premises. A counterexample shows invalidity. Wffs are built recursively; the main connective is the last one added.
2. **Symbolization.** The connectives are truth functions. "$A$ only if $B$" is $A \to B$; "$A$ unless $B$" is $A \vee B$; "neither $A$ nor $B$" is $\neg(A \vee B)$; "not both" is $\neg(A \wedge B)$. The material conditional is false only when the antecedent is true and the consequent false.
3. **Truth tables.** $2^n$ rows. Tautology, contradiction, contingent; entailment means no row with true premises and a false conclusion; equivalence means the same column. A contradictory set entails everything.
4. **Partial tables.** Make the conclusion false and the premises true, force what you can, and branch where there is a choice. A closed attempt in every branch means valid; an open branch gives a countermodel.
5. **Basic rules.** $\wedge$I, $\wedge$E, $\vee$I, $\vee$E (two subproofs ending in the same sentence), $\to$E, $\leftrightarrow$E, $\neg$E, X, R.
6. **Subproof rules.** $\to$I, $\leftrightarrow$I, $\neg$I (assume $A$, reach $\bot$), IP (assume $\neg A$, reach $\bot$). Work backward from the goal's main connective.
7. **Quantifiers.** All $F$s are $G$s: $\forall x(Fx \to Gx)$. Some $F$s are $G$s: $\exists x(Fx \wedge Gx)$. $\neg\forall x\,Fx \equiv \exists x\,\neg Fx$ and $\neg\exists x\,Fx \equiv \forall x\,\neg Fx$.
8. **Multiple generality.** $\exists y\forall x\,Rxy$ entails $\forall x\exists y\,Rxy$, not the reverse. Unlike quantifiers do not commute.
9. **Identity.** Leibniz's Law; "at least", "at most", "exactly" claims; Russell's analysis of "the $F$ is $G$" with wide and narrow scope for negation.
10. **Interpretations.** Domain, names, extensions. A countermodel makes the premises true and the conclusion false; verify every sentence.
11. **Quantifier proofs.** $\forall$E, $\exists$I free; $\forall$I and $\exists$E need a fresh name; $=$I, $=$E.
12. **Soundness and completeness.** $\Gamma \vdash A$ iff $\Gamma \vDash A$ for first-order logic (completeness: Gödel, 1929–1930). Validity is decidable for truth-functional logic, but not for first-order logic (Church and Turing, 1936). Compactness; Löwenheim–Skolem; incompleteness of arithmetic is a different result.

## Self-check list

- Can you state the definitions of validity, soundness, tautology and entailment without looking?
- Can you translate "only if", "unless", "neither...nor" and "at most one" correctly?
- Can you test an argument with a partial table, and read off a countermodel?
- Can you plan a proof by working backward, and justify every line?
- Can you explain why the restrictions on $\forall$I and $\exists$E are needed?
- Can you build and verify a countermodel for a quantified argument?

## Most common errors

- Using $\forall x(Fx \wedge Gx)$ for "all $F$s are $G$s", or $\exists x(Fx \to Gx)$ for "some".
- Reversing "only if", or treating "unless" as a biconditional.
- Citing lines from a closed subproof, or applying $\forall$I to a name in an open assumption.
- Calling an argument valid because the conclusion is true, or because one branch of a partial table closed.

prompt: How many of the sixteen rows of the truth table, for letters $P$, $Q$, $R$, $S$ in that order, are counterexamples to the argument $P \to (Q \vee R)$, $S \to P$, so $S \to (Q \wedge R)$?
answer: 2
unit: rows
check: count_countermodels([lambda p, q, r, s: implies(p, q or r), lambda p, q, r, s: implies(s, p)], lambda p, q, r, s: implies(s, q and r))
hint: A counterexample needs $S$ true and $Q \wedge R$ false. Then check the premises.
solution: With $S$ true, $S \to P$ forces $P$ true, and then $P \to (Q \vee R)$ forces $Q \vee R$ true. The conclusion is false when $Q \wedge R$ is false. So exactly one of $Q$, $R$ is true: $Q$ true and $R$ false, or $Q$ false and $R$ true. The countermodels are $P$, $Q$, $R$, $S$ = T, T, F, T and T, F, T, T: 2 rows. The argument is invalid.

@exam ms
prompt: The domain is nonempty. Which of these first-order sentences are true in every interpretation (logical truths)? Select all that apply.
choice*: $\forall x\,Fx \to \exists x\,Fx$
choice: $\exists x\,Fx \to \forall x\,Fx$
choice*: $\exists x\forall y\,Rxy \to \forall y\exists x\,Rxy$
choice: $\forall x\exists y\,Rxy \to \exists y\forall x\,Rxy$
choice*: $\forall x\exists y\,x = y$
hint: For each sentence, look for a countermodel on a domain with one or two objects.
solution: The sentence $\forall x\,Fx \to \exists x\,Fx$ is true because the domain is nonempty, so if everything is $F$ then something is. The sentence $\exists x\forall y\,Rxy \to \forall y\exists x\,Rxy$ is the valid direction of the quantifier swap, and $\forall x\exists y\,x = y$ says that everything is identical to something, which is true because each object is identical to itself. The sentence $\exists x\,Fx \to \forall x\,Fx$ fails when $F$ is true of one object and not another, and $\forall x\exists y\,Rxy \to \exists y\forall x\,Rxy$ fails in the domain $\{1, 2\}$ with $R$ true of $(1, 2)$ and $(2, 1)$ only: everything bears $R$ to something, but nothing is such that everything bears $R$ to it.

@exam self
prompt: (a) Write a natural deduction proof of $\exists x\,\neg Fx$ from the premises $\forall x(Fx \to Gx)$ and $\exists x\,\neg Gx$, with the rule and line numbers on every line. (b) Say, using soundness, what your proof shows about whether a countermodel to this argument exists, and explain in one sentence why the restriction on $\exists$E is met.
hint: Use $\exists$E on the second premise: assume $\neg Ga$, then prove $\neg Fa$ by assuming $Fa$ and reaching $\bot$.
solution: (a)
```text
 1 | ∀x(Fx → Gx)       PR
 2 | ∃x ¬Gx            PR
   |---
 3 | | ¬Ga             AS
 4 | | | Fa            AS
 5 | | | Fa → Ga       ∀E 1
 6 | | | Ga            →E 5, 4
 7 | | | ⊥             ¬E 6, 3
 8 | | ¬Fa             ¬I 4–7
 9 | | ∃x ¬Fx          ∃I 8
10 | ∃x ¬Fx            ∃E 2, 3–9
```
(b) By soundness, a proof shows that the argument is valid, so no interpretation makes both premises true and the conclusion false: there is no countermodel. The restriction on $\exists$E is met because the name $a$ occurs in neither premise, in $\exists x\,\neg Gx$, nor in the conclusion $\exists x\,\neg Fx$.

rubric: Proves $\neg Fa$ inside it with $\neg$I from the assumption $Fa$ and $\bot$, with every line cited correctly.
rubric: Concludes that, by soundness, no countermodel exists, and checks that $a$ does not occur in the premises or the conclusion.

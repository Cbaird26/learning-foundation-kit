@article
A complete table for an argument with eight letters has $2^8 = 256$ rows. Nobody should write that out. Fortunately validity asks only whether *one* kind of row exists: a row with every premise true and the conclusion false. A **partial truth table** looks for such a row directly, filling in only what is forced.

### The method

1. Write the argument across the top, premises first, conclusion last.
2. Put F under the conclusion's main connective and T under each premise's main connective.
3. Work inward, as far as the values are **forced**: a conjunction that is true forces both conjuncts true; a conditional that is false forces its antecedent true and consequent false; a disjunction that is false forces both disjuncts false; and so on.
4. If a sentence letter is forced to be both T and F, this attempt has failed. If a choice remains open (a true disjunction, a false conjunction, a true conditional), **branch**: try each way.
5. If **every** branch ends in a contradiction, no row makes the premises true and the conclusion false, and the argument is **valid**. If some branch assigns every letter a value without contradiction, you have a **countermodel**, and the argument is **invalid**. Check it by computing every premise and the conclusion on that row.

A countermodel is a single row; to claim validity you must have closed every branch.

### An argument from antiquity

The **lazy argument**, known from antiquity, runs roughly as follows when applied to the claim that the future is fixed:

| P1 | If the future is already fixed, then deliberating about what to do is pointless. |
| P2 | If deliberating is pointless, then I should stop deliberating. |
| P3 | I should not stop deliberating. |
| C | So the future is not already fixed. |

Write $F$ for "the future is already fixed", $D$ for "deliberating is pointless" and $S$ for "I should stop deliberating". The form is $F \to D$, $D \to S$, $\neg S$, so $\neg F$. Put F under the conclusion, which forces $F$ true; then P1 forces $D$ true, P2 forces $S$ true, but P3 needs $S$ false. The single attempt fails with nothing left to branch on, so the argument is valid. The premises that do the work are P1 and P2, since they link fixity to a verdict about deliberation, and P3, which denies it. The best objection attacks P1: even if the future is fixed, deliberation may be one of the things that fixes it. The Stoic reply to the lazy argument was that outcomes and our efforts are "co-fated" and so deliberation is not idle. A defender of the argument can reply that this makes P1 false rather than the argument invalid, which is exactly where the dispute belongs.

@example
title: A partial table that closes
problem: Test the argument $(P \vee Q) \to R$, $S \to P$, $\neg R$, so $\neg S$.
step: Put F under the conclusion $\neg S$, which makes $S$ true. Put T under each premise.
step: $\neg R$ is true, so $R$ is false. $S \to P$ is true with $S$ true, so $P$ is true.
step: Now $(P \vee Q) \to R$ is true, with $P \vee Q$ true (since $P$ is true) and $R$ false: that makes the conditional false. The premise is forced both true and false.
step: There was no choice anywhere, so no branch is left. No row has all premises true and the conclusion false.
answer: The argument is valid.

@example
title: A partial table with a branch
problem: Test the argument $P \to Q$, $R \to S$, $P \vee R$, so $Q \wedge S$, and give a countermodel if there is one.
step: Put F under $Q \wedge S$. That is true when at least one of $Q$, $S$ is false, so there is a choice: branch on $Q$ false or $S$ false.
step: Branch 1, $Q$ false: $P \to Q$ true forces $P$ false. Then $P \vee R$ true forces $R$ true, and $R \to S$ true forces $S$ true. Assignment: $P$ F, $Q$ F, $R$ T, $S$ T. Check: the premises are T, T, T and the conclusion $Q \wedge S$ is F. This branch succeeds.
step: We could stop, but the other branch gives a second countermodel. Branch 2, $S$ false: $R \to S$ forces $R$ false, $P \vee R$ forces $P$ true, $P \to Q$ forces $Q$ true: $P$ T, $Q$ T, $R$ F, $S$ F, which also makes the premises true and the conclusion false.
answer: The argument is invalid. A countermodel: $P$ false, $Q$ false, $R$ true, $S$ true.

@mistakes
- Declaring an argument valid after one failed attempt without checking every branch. If a choice was open (a false conjunction, a true disjunction), each way of making it true or false must be tried.
- Giving a countermodel without checking it: always recompute every premise and the conclusion on the row you found.
- Putting T under the conclusion. To look for a counterexample, the conclusion is made false and the premises true.
- Leaving a sentence letter unassigned in a countermodel when it matters. Every letter that occurs needs a value, though letters that were not forced may take either value.

@practice mc
prompt: Consider the argument $P \to Q$, $R \to Q$, so $\neg(P \wedge R)$. Which assignment to $P$, $Q$, $R$ is a counterexample?
choice*: $P$ true, $Q$ true, $R$ true
choice: $P$ true, $Q$ true, $R$ false
choice: $P$ true, $Q$ false, $R$ true
choice: $P$ false, $Q$ true, $R$ true
hint: A counterexample needs the conclusion false, which means $P \wedge R$ is true.
solution: For the conclusion to be false, $P$ and $R$ must both be true. Then both premises are true only if $Q$ is true, giving $P$, $Q$, $R$ all true. The choice with $R$ false, and the one with $P$ false, make the conclusion true; the choice with $Q$ false makes the premises false.

@practice ms
prompt: Which of these argument forms are valid? Select all that apply.
choice*: $P \to Q$, $\neg Q$, so $\neg P$
choice: $P \to Q$, $Q$, so $P$
choice*: $P \vee Q$, $\neg P$, so $Q$
choice: $P \to Q$, $\neg P$, so $\neg Q$
choice*: $P \to R$, $Q \to R$, $P \vee Q$, so $R$
hint: For each form, try to make the conclusion false and the premises true.
solution: The valid forms are modus tollens, disjunctive syllogism and the one that reasons by cases from $P \vee Q$ to $R$: forcing the conclusion false forces a premise false in each. The other two are invalid: affirming the consequent has the counterexample $P$ false, $Q$ true, and denying the antecedent has the same counterexample, with $P$ false and $Q$ true.

@practice self
prompt: Use the partial-table method to test the argument $P \to (Q \wedge R)$, $\neg R \vee S$, $\neg S$, so $\neg P$. State clearly what you put under each main connective, what is forced, and what you conclude.
hint: Start by making the conclusion false and each premise true, and see which letters are forced.
solution: Make $\neg P$ false, so $P$ is true. Make $\neg S$ true, so $S$ is false. Then $\neg R \vee S$ is true with $S$ false, so $\neg R$ is true and $R$ is false. Finally $P \to (Q \wedge R)$ is true with $P$ true, so $Q \wedge R$ must be true, which needs $R$ true. But $R$ was forced false. Every value was forced, so there is no branch to try; the attempt fails and the argument is valid.
rubric: Starts correctly: F under the conclusion and T under each premise, which forces $P$ true.
rubric: Shows the forced values $S$ false and $R$ false, and the conflict with the first premise needing $R$ true.
rubric: Concludes that the argument is valid because there is no way to make the premises true and the conclusion false.

@quiz num
prompt: How many of the sixteen rows of the truth table are counterexamples to the argument $P \vee Q$, $R \to S$, so $(P \wedge R) \vee (Q \wedge S)$?
answer: 4
unit: rows
check: count_countermodels([lambda p, q, r, s: p or q, lambda p, q, r, s: implies(r, s)], lambda p, q, r, s: (p and r) or (q and s))
hint: Make the conclusion false first: both disjuncts false. Then count the rows that also make the premises true.
solution: Checking all sixteen rows for true premises and a false conclusion: the counterexamples are the rows where $P \vee Q$ and $R \to S$ are true but $P \wedge R$ and $Q \wedge S$ are both false. They are $P$, $Q$, $R$, $S$ = T,T,F,F; T,F,F,T; T,F,F,F; F,T,F,F: 4 rows.

@quiz mc
prompt: A partial table for an argument closes in every branch (each attempt to make the premises true and the conclusion false ends in a contradiction). What does that show?
choice*: The argument is valid.
choice: The argument is invalid.
choice: The argument is sound.
choice: The conclusion is true.
hint: What does it mean that no assignment makes the premises true and the conclusion false?
solution: If every attempt fails, no row makes all premises true and the conclusion false, which is the definition of validity. It says nothing about whether the premises or conclusion are actually true, so it does not show soundness or the truth of the conclusion.

@quiz self
prompt: Test the argument "If the theory is true, it explains the data. The theory explains the data. So the theory is true." Symbolize it, find a countermodel, and say in one sentence what the countermodel tells you about the argument.
hint: Make the conclusion false and see whether the premises can still be true.
solution: Let $T$ be "the theory is true" and $E$ "the theory explains the data". The form is $T \to E$, $E$, so $T$. Make the conclusion false: $T$ false. Then $T \to E$ is true whatever $E$ is, and $E$ true makes the second premise true. The countermodel is $T$ false and $E$ true. It shows that the argument is invalid (it affirms the consequent): a false theory can still explain the data.
rubric: Symbolizes the argument correctly as $T \to E$, $E$, so $T$.
rubric: Gives the countermodel $T$ false, $E$ true, and checks that the premises are true.
rubric: States that the argument is invalid, because explaining the data does not guarantee truth.

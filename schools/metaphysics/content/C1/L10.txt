@article
For truth-functional logic, a row of the truth table says all there is to say about a situation: which sentence letters are true. First-order sentences are about objects, so a "situation" must supply objects. That is an **interpretation**, also called a **model** when it makes certain sentences true.

### Interpretations

An **interpretation** of a first-order language consists of:

1. a nonempty **domain** $D$, the objects the quantifiers range over;
2. for each name, one object of $D$ that it refers to;
3. for each one-place predicate, its **extension**, a subset of $D$ (the objects it is true of);
4. for each two-place predicate, a set of ordered pairs of objects of $D$;
5. the identity sign always means identity.

Truth in an interpretation is defined from the inside out. $Fa$ is true if the object named by $a$ is in the extension of $F$. The connectives behave as before. $\forall x\,A(x)$ is true if $A$ is true of **every** object of $D$; $\exists x\,A(x)$ is true if $A$ is true of **at least one** object. On a finite domain, $\forall x\,A(x)$ comes to the conjunction $A(d_1) \wedge \cdots \wedge A(d_n)$ and $\exists x\,A(x)$ to the disjunction $A(d_1) \vee \cdots \vee A(d_n)$, which gives a mechanical way to compute.

### Validity, entailment, countermodels

An argument is **valid** when there is no interpretation in which all the premises are true and the conclusion false; it is **invalid** if there is one, and that interpretation is a **countermodel**. A sentence is a **logical truth** when it is true in every interpretation, and a set of sentences is **satisfiable** (consistent) when some interpretation makes all its members true. In first-order logic there are infinitely many interpretations, including interpretations with infinite domains, so we cannot test validity by running through all of them: a validity needs a proof, and an invalidity needs a countermodel. (Church and Turing showed in 1936 that no general mechanical procedure decides, for every argument, which of the two holds.)

### Building a countermodel

1. Write down what is needed: the premises true, the conclusion false.
2. Choose a small domain, often one, two or three objects.
3. Assign the names to objects.
4. Choose extensions for the predicates, guided by the conclusion first (to make it false) and then the premises.
5. **Verify**: compute each premise and the conclusion in the finished model.

### An argument to evaluate

| P1 | Some beliefs are justified. |
| P2 | Some beliefs are false. |
| C | So some beliefs are both justified and false. |

Write $Bx$ for "$x$ is a belief", $Jx$ for "$x$ is justified" and $Fx$ for "$x$ is false". The form is $\exists x(Bx \wedge Jx)$, $\exists x(Bx \wedge Fx)$, so $\exists x(Bx \wedge Jx \wedge Fx)$. Many epistemologists accept the conclusion (the view that justification does not guarantee truth is called **fallibilism**). But the argument is invalid. Countermodel: the domain is $\{1, 2\}$; $B$ is true of both; $J$ is true of 1 only; $F$ is true of 2 only. Then P1 is true (object 1), P2 is true (object 2), but nothing is both justified and false, so the conclusion is false. The two existential premises can be witnessed by different objects. A defender who wants the conclusion needs an extra premise, such as a particular belief that is both: the example shows that validity concerns the form of the argument, not whether its conclusion is plausible. The lesson for philosophers is to see which extra premise an argument is quietly relying on.

@example
title: Evaluating sentences in a model
problem: The domain is $\{1, 2, 3\}$. $F$ is true of 1 and 2; $G$ is true of 2 and 3; $R$ is true of the pairs $(1, 2)$, $(2, 3)$ and $(3, 3)$. Find the truth values of (a) $\forall x(Fx \to Gx)$, (b) $\exists x(Fx \wedge Gx)$, (c) $\forall x\exists y\,Rxy$, (d) $\exists x\forall y\,Rxy$.
step: (a) Check each object. Object 1 is $F$ but not $G$, so $F1 \to G1$ is false, and the universal sentence is false.
step: (b) Object 2 is both $F$ and $G$, so the existential sentence is true.
step: (c) For each $x$ find some $y$ with $Rxy$: object 1 has 2, object 2 has 3, object 3 has 3. All three succeed, so it is true.
step: (d) We would need an $x$ with $Rxy$ for all three $y$. Object 1 has only $y = 2$, object 2 only $y = 3$, object 3 only $y = 3$. None works, so it is false.
answer: (a) false; (b) true; (c) true; (d) false.

@example
title: A countermodel
problem: Show that $\forall x(Fx \to Gx)$, $Ga$, so $Fa$ is invalid.
step: We need the premises true and $Fa$ false. Take the domain $\{1\}$ and let $a$ refer to 1. To make the conclusion false, let $F$ be true of nothing.
step: Now let $G$ be true of 1, so that $Ga$ is true. Then $F1 \to G1$ is true (it has a false antecedent and a true consequent), so $\forall x(Fx \to Gx)$ is true.
step: Verify: P1 is true, P2 is true, and the conclusion $Fa$ is false.
answer: The interpretation with domain $\{1\}$, $a = 1$, $F$ true of nothing and $G$ true of 1 is a countermodel, so the argument is invalid.

@mistakes
- Giving a countermodel without verifying all the premises and the conclusion in it. Always compute each one.
- Interpreting $\forall x(Fx \to Gx)$ as requiring that something is $F$. It is true in an interpretation where nothing is $F$.
- Using an empty domain: the domain must be nonempty.
- Concluding that an argument is valid because you could not find a countermodel on a small domain. Failing to find a small countermodel does not prove validity: a proof is needed.

@practice mc
prompt: What must be exhibited to show that a first-order argument is invalid?
choice*: An interpretation in which every premise is true and the conclusion is false.
choice: An interpretation in which the conclusion is false.
choice: An interpretation in which every premise is false.
choice: A proof that the conclusion is false.
hint: Recall the definition of validity: no interpretation makes the premises true and the conclusion false.
solution: Invalidity means that some interpretation makes all premises true and the conclusion false, so exhibiting one such interpretation is exactly what is needed. A false conclusion alone, or false premises alone, shows nothing, and a conclusion's being false in some interpretations does not make it false in general.

@practice ms
prompt: The domain is $\{1, 2, 3\}$; $F$ is true of 1; $G$ is true of 1 and 2. Which of these sentences are true in this interpretation? Select all that apply.
choice*: $\forall x(Fx \to Gx)$
choice*: $\exists x(Gx \wedge \neg Fx)$
choice: $\forall x\,Gx$
choice: $\exists x(Fx \wedge \neg Gx)$
choice*: $\neg\exists x(Fx \wedge \neg Gx)$
hint: Compute each sentence object by object.
solution: Every $F$ object (only 1) is $G$, so $\forall x(Fx \to Gx)$ is true, and so is its equivalent $\neg\exists x(Fx \wedge \neg Gx)$. Object 2 is $G$ and not $F$, so $\exists x(Gx \wedge \neg Fx)$ is true. Object 3 is not $G$, so $\forall x\,Gx$ is false, and no object is $F$ without being $G$, so $\exists x(Fx \wedge \neg Gx)$ is false.

@practice num
prompt: The domain is $\{1, 2\}$. An interpretation chooses extensions for two one-place predicates $F$ and $G$, each any subset of the domain, so there are 16 interpretations. In how many of them are $\exists x\,Fx$ and $\exists x\,Gx$ both true while $\exists x(Fx \wedge Gx)$ is false?
answer: 2
unit: interpretations
check: sum(1 for f in product([0, 1], repeat=2) for g in product([0, 1], repeat=2) if any(f) and any(g) and not any(a and b for a, b in zip(f, g)))
hint: Both extensions must be nonempty and must share no object.
solution: Two nonempty subsets of $\{1, 2\}$ with no common element must be $\{1\}$ and $\{2\}$ in one order or the other: $F = \{1\}$, $G = \{2\}$, or $F = \{2\}$, $G = \{1\}$. So there are 2 interpretations.

@practice self
prompt: Show that the argument $\forall x(Fx \to Gx)$, $\forall x(Hx \to Gx)$, so $\forall x(Fx \to Hx)$ is invalid by giving a countermodel and verifying each sentence in it.
hint: Use a one-object domain, make the conclusion false first, then adjust the premises.
solution: Take the domain $\{1\}$. Let $F$ be true of 1, $G$ true of 1 and $H$ true of nothing. Check: $F1 \to G1$ is true, so $\forall x(Fx \to Gx)$ is true. $H1 \to G1$ is true (false antecedent), so $\forall x(Hx \to Gx)$ is true. But $F1 \to H1$ has a true antecedent and a false consequent, so $\forall x(Fx \to Hx)$ is false. The premises are true and the conclusion false, so the argument is invalid.
rubric: Specifies a domain and extensions for $F$, $G$ and $H$ with a false conclusion.
rubric: Verifies that both premises are true in the model.
rubric: States that the argument is invalid because the model is a countermodel.

@quiz mc
prompt: In an interpretation whose domain is $\{1, 2, 3\}$, the sentence $\forall x\,Fx$ is equivalent to which of these?
choice*: $F1 \wedge F2 \wedge F3$
choice: $F1 \vee F2 \vee F3$
choice: $F1 \to (F2 \to F3)$
choice: $\neg F1 \wedge \neg F2 \wedge \neg F3$
hint: A universal sentence is true when every object is $F$.
solution: On a finite domain, $\forall x\,Fx$ is true exactly when each object is $F$, which is the conjunction $F1 \wedge F2 \wedge F3$. The disjunction corresponds to $\exists x\,Fx$, and the conjunction of the negations says that nothing is $F$.

@quiz num
prompt: The domain is $\{1, 2, 3\}$. An interpretation chooses the extension of a one-place predicate $F$ as any subset of the domain (8 interpretations). In how many of them is $\forall x\,Fx$ false?
answer: 7
unit: interpretations
check: sum(1 for s in product([0, 1], repeat=3) if not all(s))
hint: Only one interpretation makes $F$ true of every object.
solution: $\forall x\,Fx$ is true only when $F$ is true of all three objects, which is 1 of the 8 interpretations, so it is false in $8 - 1 = 7$.

@quiz self
prompt: Show that $\exists x\exists y\,Rxy$, so $\exists x\,Rxx$ is invalid by giving a countermodel, and verify it.
hint: Use a domain of two objects and a relation that never relates an object to itself.
solution: Take the domain $\{1, 2\}$ and let $R$ be true of the single pair $(1, 2)$. Then $\exists x\exists y\,Rxy$ is true, with $x = 1$ and $y = 2$. But $Rxx$ would need $(1, 1)$ or $(2, 2)$ in $R$, and neither is, so $\exists x\,Rxx$ is false. The premise is true and the conclusion false, so the argument is invalid.

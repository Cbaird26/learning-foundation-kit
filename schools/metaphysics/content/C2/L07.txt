@article
Last week's evaluator computes the truth value of a formula under one valuation. A truth table is that computation repeated for every valuation. The only new problem is generating all the valuations: for $n$ letters there are $2^n$ of them, and nested loops would need a different program for each $n$. The standard library solves this once and for all.

### itertools.product

`product` from the module `itertools` produces all combinations that take one item from each of several sequences. With the keyword `repeat=n` it takes $n$ items from the same sequence:

```python
from itertools import product

rows = list(product([True, False], repeat=2))
# [(True, True), (True, False), (False, True), (False, False)]
```

Each row is a tuple, and the rows come out in the **standard order**: all letters true first, and the last letter changes fastest. Because the value `True` is listed first, this is the order TT, TF, FT, FF of every truth table so far. `product` is lazy: it yields one row at a time, so wrap it in `list(...)` when you want a list.

### From rows to valuations

A row is a tuple of values, with one value per letter. To evaluate a formula we need a dictionary from letter names to values. `zip` pairs names with values and `dict` turns the pairs into a dictionary:

```python
v = dict(zip(['P', 'Q'], (True, False)))   # {'P': True, 'Q': False}
```

### Finding the letters of a formula

We need the list of distinct letters of a formula, in a fixed order so that the columns come out the same every time. A **set** is a collection that keeps each item once and has no order: `set(['Q', 'P', 'Q'])` is the set containing `'P'` and `'Q'`. Applying `sorted` to a set gives a sorted list. The function below finds the letters recursively and removes repeats at each level (the function `evaluate` is last week's):

```python
def atoms(f):
    if isinstance(f, str):
        return [f]
    found = []
    for part in f[1:]:
        found = found + atoms(part)
    return sorted(set(found))
```

### Printing a table

With these pieces, a table is one loop. This function prints the header, then one line per row with the truth values written as `T` and `F`:

```python
def table(f):
    names = atoms(f)
    print(" ".join(names), "| f")
    for row in product([True, False], repeat=len(names)):
        v = dict(zip(names, row))
        cells = ["T" if x else "F" for x in row]
        print(" ".join(cells), "|", "T" if evaluate(f, v) else "F")
```

For a formula with no letters, `product(..., repeat=0)` yields exactly one empty row, which is correct: a formula with no letters has a one-row table.

### An argument about rows

| P1 | The formula $(P \to Q) \wedge (Q \to P)$ is true on a row if and only if $P$ and $Q$ have the same truth value on that row. |
| P2 | Exactly two of the four rows of the table for $P$ and $Q$ give them the same value. |
| C | So $(P \to Q) \wedge (Q \to P)$ is true on exactly two rows. |

The argument is valid: P1 says which rows make the formula true and P2 counts them. It is also sound: the conditionals are both true exactly when $P$ and $Q$ agree (if $P$ is true, $Q$ must be; if $P$ is false, $Q$ must be false too), and the agreeing rows are TT and FF. The program confirms it: the column of the formula is `TFFT`.

@example
title: Reading the output of product
problem: What is row number 5 (counting from 0) produced by `product([True, False], repeat=3)`?
step: There are $2^3 = 8$ rows. The first letter changes slowest, so the first four rows have `True` first and the last four have `False` first.
step: Within each half the second letter changes next slowest, and the third letter alternates on every row.
step: The rows, numbered from 0, are TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
step: Row number 5 is the sixth row, FTF.
answer: `(False, True, False)`

@example
title: Computing the main column of a formula
problem: Write `truth_column(f)` that returns the main column of the table of the formula `f` as a string of `T` and `F`, in the standard order, and use it on `('iff', 'P', ('not', 'Q'))`.
step: Get the letters with `atoms(f)`, and loop over the rows of the right size with `product([True, False], repeat=len(names))`.
step: For each row build the valuation `dict(zip(names, row))` and evaluate the formula under it; record `T` or `F`:

```python
def truth_column(f):
    names = atoms(f)
    cells = ["T" if evaluate(f, dict(zip(names, row))) else "F"
             for row in product([True, False], repeat=len(names))]
    return "".join(cells)
```
step: For $P \leftrightarrow \neg Q$ the rows are TT (true against false: F), TF (true against true: T), FT (false against false: T) and FF (false against true: F).
answer: `truth_column(('iff', 'P', ('not', 'Q')))` is `'FTTF'`.

@mistakes
- Passing the repeat count as a positional argument, `product([True, False], 3)`, which treats `3` as another sequence and raises a `TypeError`; write `repeat=3`.
- Using the letters of the formula in an unsorted or repeated list: the columns then come out in an unpredictable order, or with duplicates. Use `sorted(set(...))`.
- Printing a table row's raw tuple instead of converting `True` and `False` to `T` and `F`.
- Forgetting that `product` is lazy: `product(...)` alone is not a list, and a loop over it uses it up.

        return v[f]
    op = f[0]
    if op == 'not':
        return not evaluate(f[1], v)
    a = evaluate(f[1], v)

        return a and b
    if op == 'or':
        return a or b

    for part in f[1:]:
        found = found + atoms(part)
    return sorted(set(found))

def models(f):

@quiz num
prompt: For how many of the 16 rows of the truth table for $(P \vee Q) \wedge (R \vee S)$ is the formula true?
answer: 9
unit: rows
check: count_models(lambda p, q, r, s: (p or q) and (r or s))
hint: The two conjuncts mention different letters, so they can be counted separately.
solution: $P \vee Q$ is true on 3 of the 4 combinations of $P$ and $Q$, and $R \vee S$ is true on 3 of the 4 combinations of $R$ and $S$. The choices are independent, so the conjunction is true on $3 \times 3 = 9$ rows.

@article
A truth table has many rows, and you do not want to write each one by hand. Loops repeat work; functions package work under a name so that you can reuse it. Together they let a short program examine every row of a table of any size.

### Functions

```python
def implies(p, q):
    """Return the truth value of P -> Q."""
    return (not p) or q
```

`def` starts a **function definition**. `implies` is its name, `p` and `q` are its **parameters**, and the indented block is its body. The string in triple quotes is a **docstring**, a comment that says what the function does. `return` hands a value back to the caller and ends the call at once. Calling `implies(True, False)` evaluates to `False`.

**`return` is not `print`.** `print` shows a value on the screen and gives nothing back; `return` gives a value to the program, which can store it, compare it or pass it on. A function that reaches its end without a `return` gives back the special value `None`. Names assigned inside a function are **local**: they exist only during the call.

Functions are values too, so one function can be an argument of another. For a short one-line function you can write an unnamed one with `lambda`: `lambda p: p or not p` is a function of one truth value. We will use this to hand formulas to a program that tests them.

### for loops

`for x in sequence:` runs its indented body once for each item of the sequence, with `x` bound to that item. The sequence may be a list, `[True, False]`, or a range: `range(3)` gives `0, 1, 2`, and `range(2, 5)` gives `2, 3, 4` (the end is excluded). A loop inside a loop is a **nested loop**: the inner loop runs completely for every pass of the outer one. Two nested loops over `[True, False]` visit all four rows of a two-letter table.

### while loops

`while condition:` repeats the body as long as the condition is `True`. Something in the body must change what the condition tests, or the loop never ends. `break` leaves the loop at once.

### Searching with early return

Often you do not need to visit everything: you want the first item with some property. Put a `return` inside the loop, in an `if`, and put the "nothing found" answer after the loop:

```python
def first_multiple_above(m, n):
    """Return the smallest multiple of m that is greater than n."""
    for k in range(n + 1, n + m + 1):
        if k % m == 0:
            return k
```

The loop tries `n + 1`, `n + 2`, ... and the first success ends the whole function. The `return k` sits inside the `if`, which sits inside the loop, so it runs on the pass where the test succeeds; a `return` for the failure case belongs outside the loop, aligned with `for`. Moving it inside is the most common loop bug.

### An argument about a search

| P1 | If some row of the truth table makes a formula false, the formula is not a tautology. |
| P2 | The row on which $P$ is true and $Q$ is false makes $P \to Q$ false. |
| C | So $P \to Q$ is not a tautology. |

This is modus ponens, so it is valid, and it is sound because P1 is just the definition of a tautology (true on every row) turned around. P2 is the one row of the conditional's table where the antecedent is true and the consequent false. A program tests tautology the same way: loop over the rows and return `False` the moment one row fails.

@example
title: Tracing nested loops
problem: What does this program print, and which truth table is it?

```python
for p in [True, False]:
    for q in [True, False]:
        print(p, q, not p or q)
```
step: The outer loop first sets `p` to `True`. The inner loop then runs twice, with `q` equal to `True` and then `False`.
step: With `p = True`: `q = True` prints `True True True`; `q = False` prints `True False False`, since `not True or False` is `False`.
step: The outer loop now sets `p` to `False` and the inner loop runs again: `False True True`, then `False False True`.
step: The third column is `not p or q`, which is the conditional $P \to Q$: the program prints its truth table, with rows in the order TT, TF, FT, FF.
answer: The four lines `True True True`, `True False False`, `False True True`, `False False True`: the table of $P \to Q$.

@example
title: A function that tests every row
problem: Write `always_true(f)` for a function `f` of one truth value: it returns `True` when `f` gives `True` for both values, and `False` otherwise. Test it on `lambda p: p or not p` and on `lambda p: p`.
step: A "for every row" test is a search for a counterexample: look for a row where `f` gives `False`.
step: Loop over `[True, False]`; as soon as `f(p)` is `False`, return `False`. Only after the loop has finished without finding one may you return `True`:

```python
def always_true(f):
    for p in [True, False]:
        if not f(p):
            return False
    return True
```
step: For `lambda p: p or not p` both values give `True`, the loop ends, and the function returns `True`.
step: For `lambda p: p`, the first value `True` passes, the second value `False` fails, and the function returns `False` inside the loop.
answer: `always_true(lambda p: p or not p)` is `True`; `always_true(lambda p: p)` is `False`.

@mistakes
- Putting `return True` inside the loop (indented under `for`) so that the function answers after the first row; the "for every row" answer can be given only after the loop.
- Printing a result instead of returning it: the caller then receives `None`.
- Writing a `while` loop whose body never changes the condition, which runs forever.
- Forgetting that `range(2, 5)` stops before 5, so it has three items, not four.

@practice code
prompt: Write two functions, `implies(p, q)` for the material conditional and `iff(p, q)` for the biconditional. Each takes two truth values and returns a truth value.
starter:
```python
def implies(p, q):
    pass

def iff(p, q):
    pass
```
tests:
```python
assert implies(True, True) is True
assert implies(True, False) is False
assert implies(False, True) is True
assert implies(False, False) is True
assert iff(True, True) is True
assert iff(True, False) is False
assert iff(False, True) is False
assert iff(False, False) is True
```
model:
```python
def implies(p, q):
    """P -> Q is false only when P is true and Q is false."""
    return (not p) or q

def iff(p, q):
    """P <-> Q is true when P and Q have the same truth value."""
    return p == q
```
hint: $P \to Q$ is equivalent to $\neg P \vee Q$.
hint: $P \leftrightarrow Q$ is true exactly when the two values are equal.
solution: The conditional is false only when `p` is true and `q` false, so `(not p) or q` computes it. The biconditional holds when the two values agree, which is `p == q`. Both return real truth values, so `is True` tests pass.

@practice code
prompt: Write `first_failure(f)` for a function `f` of two truth values. It returns the first row `(p, q)` on which `f(p, q)` is `False`, trying the rows in the order `(True, True)`, `(True, False)`, `(False, True)`, `(False, False)`, and returns `None` if `f` is true on every row. Use nested loops.
starter:
```python
def first_failure(f):
    pass
```
tests:
```python
assert first_failure(lambda p, q: p or q) == (False, False)
assert first_failure(lambda p, q: p == q) == (True, False)
assert first_failure(lambda p, q: p or not p) is None
assert first_failure(lambda p, q: (not p) or q) == (True, False)
assert first_failure(lambda p, q: p and q) == (True, False)
```
model:
```python
def first_failure(f):
    for p in [True, False]:
        for q in [True, False]:
            if not f(p, q):
                return (p, q)
    return None
```
hint: Loop over `[True, False]` twice, nested, so the rows come in the required order.
hint: Return `(p, q)` from inside the inner loop as soon as `f(p, q)` is false; return `None` only after both loops.
solution: The nested loops visit the rows in order, and returning at the first failing row gives the first failure. `None` is returned only when the loops finish without finding one.

@practice code
prompt: Write `letters_needed(m)` that returns the smallest number $n$ of sentence letters for which a truth table has at least `m` rows (that is, the smallest $n$ with $2^n \ge m$), for a whole number `m` of at least 1. Use a `while` loop.
starter:
```python
def letters_needed(m):
    pass
```
tests:
```python
assert letters_needed(1) == 0
assert letters_needed(2) == 1
assert letters_needed(3) == 2
assert letters_needed(1000) == 10
assert letters_needed(1024) == 10
assert letters_needed(1025) == 11
```
model:
```python
def letters_needed(m):
    n = 0
    while 2 ** n < m:
        n = n + 1
    return n
```
hint: Start with `n = 0` and keep increasing `n` while `2 ** n` is still too small.
solution: The loop condition `2 ** n < m` says "not enough rows yet"; each pass adds one letter. When it fails, `2 ** n >= m` and `n` is the smallest such number. For `m = 1024` the loop stops at exactly 10, and for 1025 it needs 11.

@quiz code
prompt: Write `all_rows3(f)` for a function `f` of three truth values. It returns `True` if `f(p, q, r)` is `True` for all eight combinations of values, and `False` otherwise. Use three nested loops and return as soon as you find a failing row.
starter:
```python
def all_rows3(f):
    pass
```
tests:
```python
assert all_rows3(lambda p, q, r: p or not p) == True
assert all_rows3(lambda p, q, r: (not (p and q)) or p) == True
assert all_rows3(lambda p, q, r: p or q or r) == False
assert all_rows3(lambda p, q, r: (not p) or r) == False
assert all_rows3(lambda p, q, r: p and q and r) == False
```
model:
```python
def all_rows3(f):
    for p in [True, False]:
        for q in [True, False]:
            for r in [True, False]:
                if not f(p, q, r):
                    return False
    return True
```
hint: Nest three loops over `[True, False]`.
hint: Return `False` inside the innermost `if`; return `True` once, after all the loops.
solution: A failing row is a counterexample, so return `False` the moment one appears. Only when all eight rows pass does control reach the final `return True`, which sits outside every loop.

@quiz num

```python
for p in [True, False]:
    for q in [True, False]:
        for r in [True, False]:
            if p or q:
                print(r)
```
answer: 6
unit: lines
check: len(run("for p in [True, False]:\n    for q in [True, False]:\n        for r in [True, False]:\n            if p or q:\n                print(r)\n").splitlines())
hint: The `print` runs once for every combination of `p`, `q` and `r` that passes the `if`.
solution: Of the four pairs `(p, q)`, three satisfy `p or q`, and for each of them `r` takes two values. That makes $3 \times 2 = 6$ lines.

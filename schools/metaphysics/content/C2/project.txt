## Week by week

1. **Values and variables.** `int`, `float`, `str`, `bool`; `//`, `%`, `**`; assignment is an instruction, not an equation; a table with $n$ letters has $2^n$ rows.
2. **Booleans.** `and`, `or`, `not`, precedence (`not`, then `and`, then `or`), short-circuiting; the conditional is `(not p) or q`, the biconditional `p == q`; `if`, `elif`, `else` and `input()`.
3. **Loops and functions.** `def`, `return` versus `print`, `for`, `range`, `while`; a "for every row" test returns `False` inside the loop and `True` after it.
4. **Sequences.** Lists, tuples, strings, indexing from 0, slices, `split` and `join`, comprehensions, `zip`.
5. **Formulas as data.** Letters are strings; compound formulas are tuples `(op, A)` or `(op, A, B)`. Equal tuples are the same tree, not necessarily equivalent formulas.
6. **Recursion.** A base case and a recursive case on smaller parts; `evaluate`, `show`, `letters`, `substitute`; valuations are dictionaries.
7. **Truth tables.** `product([True, False], repeat=n)`; `dict(zip(names, row))`; `sorted(set(...))` for the letters.
8. **Semantic tests.** Tautology is true on every row, entailment has no countermodel, equivalence is mutual entailment; collect the letters of all formulas.
9. **Normal forms.** Eliminate $\to$ and $\leftrightarrow$, push negations in, distribute $\vee$ over $\wedge$; CNF can have $2^n$ clauses.
10. **Search.** Clauses as lists of literal strings; `assign` simplifies; `solve` backtracks; $\Gamma \vDash A$ iff $\Gamma \cup \{\neg A\}$ is unsatisfiable.
11. **Models.** Sets of tuples are relations; `holds` loops over the domain with `all` and `any`; countermodels refute quantifier shifts.
12. **Proofs.** A line needs the right rule and accessible citations; soundness turns a countermodel into a proof that no proof exists.

## Key facts

- Definitions: tautology, satisfiable, contradiction, entailment, equivalence, countermodel, literal, clause, CNF, DNF.
- Laws: $A \to B \equiv \neg A \vee B$; $A \leftrightarrow B \equiv (\neg A \vee B) \wedge (\neg B \vee A)$; De Morgan; double negation; distribution of $\vee$ over $\wedge$.
- Counts: $2^n$ rows; $2^{n^2}$ binary relations on $n$ elements; $2^n$ subsets.

## Common errors

- Treating `=` as equality, or `/` as whole-number division.
- Putting the "all rows pass" `return True` inside the loop.
- Generating valuations from the wrong set of letters.
- Confusing `[]` (no clauses, true) with `[[]]` (an empty clause, false).
- Citing a line inside a closed subproof.

```python
from itertools import product

def evaluate(f, v):
    if isinstance(f, str):
        return v[f]
    op = f[0]
    if op == 'not':
        return not evaluate(f[1], v)
    a = evaluate(f[1], v)
    b = evaluate(f[2], v)
    if op == 'and':
        return a and b
    if op == 'or':
        return a or b
    if op == 'imp':
        return (not a) or b
    return a == b

def atoms(f):
    if isinstance(f, str):
        return [f]
    found = []
    for part in f[1:]:
        found = found + atoms(part)
    return sorted(set(found))

def valuations(names):
    return [dict(zip(names, row))
            for row in product([True, False], repeat=len(names))]

def classify(f):
    values = [evaluate(f, v) for v in valuations(atoms(f))]
    if all(values):
        return 'tautology'
    if not any(values):
        return 'contradiction'
    return 'contingent'
```
hint: Compute the list of values of the formula under every valuation.
hint: `all` of the list means tautology, and `not any` of the list means contradiction.
solution: Evaluate the formula under every valuation of its letters. If all values are true it is a tautology; if none is true it is a contradiction; otherwise it is contingent. The order of the two tests does not matter, because the list of values is never empty (even a formula with no letters has one valuation, the empty one).

@exam num
prompt: The clause list `[['P', 'Q'], ['-P', 'R'], ['-Q', 'R']]` stands for the formula $(P \vee Q) \wedge (\neg P \vee R) \wedge (\neg Q \vee R)$. Over the three letters $P, Q, R$ there are 8 valuations. For how many of them are all three clauses true?
answer: 3
unit: valuations
check: count_models(lambda p, q, r: (p or q) and ((not p) or r) and ((not q) or r))
hint: Consider separately the valuations where $R$ is true and where $R$ is false.
solution: If $R$ is false, then $\neg P \vee R$ forces $P$ false and $\neg Q \vee R$ forces $Q$ false, which contradicts $P \vee Q$: no valuation works. If $R$ is true, the last two clauses hold, and $P \vee Q$ is true on 3 of the 4 values of $P, Q$. So 3 valuations satisfy the clauses, and in all of them $R$ is true, which shows that $P \vee Q,\ P \to R,\ Q \to R \vDash R$.

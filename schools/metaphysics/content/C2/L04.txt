@article
A truth table is a collection: rows, each holding several truth values, and columns, each holding one value per row. A formula typed by a person is a string. Python has three basic **sequence** types for these jobs, and they share most of their operations.

### Lists

A **list** is an ordered, changeable collection: `xs = [10, 20, 30, 40]`. Items are numbered from `0`, so `xs[0]` is `10`; negative indices count from the end, so `xs[-1]` is `40`. `len(xs)` is the length. A **slice** `xs[1:3]` is a new list of the items at positions 1 and 2 (the end is excluded): `[20, 30]`. Omit an end to go to the edge: `xs[:2]` and `xs[2:]`. Useful operations: `xs.append(50)` adds an item, `30 in xs` tests membership, `xs + ys` joins lists, and `sorted(xs)` returns a sorted copy.

### Tuples

A **tuple** is like a list but fixed: `row = (True, False)`. It cannot be changed after creation (`row[0] = False` raises a `TypeError`), which suits a row of a truth table. Tuples **unpack**: `p, q = row` gives `p` the value `True` and `q` the value `False`. A function can return a tuple to give back several values. A tuple of one item needs a trailing comma: `(5,)`.

### Strings

A string is a sequence of characters, so it indexes and slices like a list: `"modus"[0]` is `"m"` and `"modus"[:3]` is `"mod"`. Strings are also fixed, but their **methods** return new strings:

| call | result |
|---|---|
| `"if P then Q".split()` | `['if', 'P', 'then', 'Q']` |
| `" ".join(['P', 'and', 'Q'])` | `'P and Q'` |
| `"P -> Q".replace("->", "=>")` | `'P => Q'` |
| `"  P ".strip()` | `'P'` |
| `"Q".isupper()` | `True` |

`split` with no argument cuts at runs of spaces; `join` is called on the separator and takes a list of strings.

### Comprehensions and zip

A **list comprehension** builds a list from another sequence in one expression: `[x * 2 for x in xs]`, or with a filter, `[x for x in xs if x > 15]`. A comprehension with two `for` parts runs a nested loop. `zip(xs, ys)` pairs up items from two sequences: `[a == b for a, b in zip(xs, ys)]` compares two lists position by position. Together with the functions from last week you can process a whole table:

```python
ROWS = [(True, True), (True, False), (False, True), (False, False)]
col = [implies(p, q) for p, q in ROWS]     # [True, False, True, True]
text = "".join(["T" if v else "F" for v in col])    # 'TFTT'
```

The first line lists the four rows of a two-letter table, the second computes the column of the conditional, and the third turns it into the string `TFTT`, the compact form used for truth-table columns throughout this course.

### An argument that is not valid

| P1 | If a list is sorted, then its first item is its smallest. |
| P2 | This list's first item is its smallest. |
| C | So this list is sorted. |

The form is $P \to Q,\ Q \vdash P$: **affirming the consequent**, which is invalid. Premise P1 is true, but the premises do not force the conclusion: a countermodel is the list `[1, 3, 2]`. Python confirms it:

```python
xs = [1, 3, 2]
print(xs[0] == min(xs), xs == sorted(xs))    # True False
```

Both premises hold of `xs` while the conclusion fails. In truth-table terms, the countermodel is the row with $P$ false and $Q$ true, the row that makes $P \to Q$ true.

@example
title: Reading indexes, slices and methods
problem: What does this program print?

```python
row = (True, False, True)
vals = [row[0], row[-1], row[1]]
word = "modus ponens"
print(vals, len(word), word[:5], word[-6:])
```
step: `row[0]` is `True`, `row[-1]` is the last item, `True`, and `row[1]` is `False`. So `vals` is `[True, True, False]`, and `print` shows a list with brackets.
step: `"modus ponens"` has 5 letters, a space and 6 letters, so `len(word)` is `12`.
step: `word[:5]` is the first five characters, `modus`. `word[-6:]` starts six characters from the end and runs to the end: `ponens`.
answer: `[True, True, False] 12 modus ponens`

@example
title: Filtering rows with a comprehension
problem: Write `true_rows(f)` that returns the list of rows (tuples) of the two-letter table on which the function `f` of two truth values is `True`.
step: Start from the list `ROWS` of all four rows, each a tuple `(p, q)`.
step: A row is a tuple, so call the function on its items with `f(*row)`: the star unpacks the tuple into separate arguments.
step: Keep a row when `f(*row)` is true, with a comprehension filter:

```python
ROWS = [(True, True), (True, False), (False, True), (False, False)]

def true_rows(f):
    return [row for row in ROWS if f(*row)]
```
step: Check: for `lambda p, q: p and not q` only the row `(True, False)` passes, so `true_rows` returns `[(True, False)]`.
answer: The function above; for `lambda p, q: p and not q` it returns `[(True, False)]`.

@mistakes
- Counting from 1: the first item has index `0`, and `xs[len(xs)]` is out of range (an `IndexError`).
- Expecting `xs[1:3]` to include `xs[3]`; the end of a slice is excluded.
- Trying to change a tuple or a string in place (`row[0] = False`); build a new one instead.
- Forgetting the star in `f(*row)` and passing the whole tuple as a single argument.

def implies_list(xs, ys):

@quiz num
prompt: How many items does the list `[(p, q, r) for p in (True, False) for q in (True, False) for r in (True, False) if not (p and q)]` have?
answer: 6
unit: items
check: len([(p, q, r) for p in (True, False) for q in (True, False) for r in (True, False) if not (p and q)])
hint: Without the filter the list has 8 items, one for each combination.
solution: The filter removes the combinations in which `p` and `q` are both true, which are 2 of the 8 (one for each value of `r`). That leaves $8 - 2 = 6$ items.

@quiz mc
prompt: Let `row = (True, True)`. Which statement is correct?
choice*: `row[0] = False` raises a `TypeError`, because a tuple cannot be changed after it is created
choice: `row.append(False)` makes the tuple longer

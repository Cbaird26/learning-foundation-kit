@article
Truth tables decide every question about propositional formulas, but they need $2^n$ rows. Many algorithms, including the satisfiability search of next week, work better on formulas of a restricted shape. Fortunately every formula can be rewritten, without changing its meaning, into such a shape.

### Literals, clauses and normal forms

A **literal** is a sentence letter or its negation. A formula is in **negation normal form (NNF)** when it is built from literals with $\wedge$ and $\vee$ only: negation appears only directly in front of letters, and there is no $\to$ or $\leftrightarrow$. A **clause** is a literal or a disjunction of literals. A formula is in **conjunctive normal form (CNF)** when it is a conjunction of clauses, and in **disjunctive normal form (DNF)** when it is a disjunction of **terms**, a term being a literal or a conjunction of literals. Every formula is equivalent to one in NNF, one in CNF and one in DNF.

### Three rewriting steps

1. **Eliminate** $\to$ and $\leftrightarrow$: $A \to B \equiv \neg A \vee B$, and $A \leftrightarrow B \equiv (\neg A \vee B) \wedge (\neg B \vee A)$.
2. **Push negations inward** with De Morgan's laws, $\neg(A \wedge B) \equiv \neg A \vee \neg B$ and $\neg(A \vee B) \equiv \neg A \wedge \neg B$, and with double negation, $\neg\neg A \equiv A$. The result is NNF.
3. **Distribute** $\vee$ over $\wedge$: $A \vee (B \wedge C) \equiv (A \vee B) \wedge (A \vee C)$, and symmetrically on the left. The result is CNF. For DNF distribute $\wedge$ over $\vee$ instead.

### The functions

Each step is a recursion over the tuple representation:

```python
def eliminate(f):
    if isinstance(f, str):
        return f
    op = f[0]
    parts = [eliminate(g) for g in f[1:]]
    if op == 'imp':
        return ('or', ('not', parts[0]), parts[1])
    if op == 'iff':
        a, b = parts
        return ('and', ('or', ('not', a), b), ('or', ('not', b), a))
    return (op,) + tuple(parts)

def push(f):                      # f uses only not, and, or
    if isinstance(f, str):
        return f
    if f[0] != 'not':
        return (f[0], push(f[1]), push(f[2]))
    g = f[1]
    if isinstance(g, str):
        return f
    if g[0] == 'not':
        return push(g[1])
    flip = 'or' if g[0] == 'and' else 'and'
    return (flip, push(('not', g[1])), push(('not', g[2])))

def distribute(a, b):             # a and b are in CNF; result: CNF of a or b
    if not isinstance(a, str) and a[0] == 'and':
        return ('and', distribute(a[1], b), distribute(a[2], b))
    if not isinstance(b, str) and b[0] == 'and':
        return ('and', distribute(a, b[1]), distribute(a, b[2]))
    return ('or', a, b)

def to_cnf(f):                    # f is in NNF
    if isinstance(f, str) or f[0] == 'not':
        return f
    a, b = to_cnf(f[1]), to_cnf(f[2])
    if f[0] == 'and':
        return ('and', a, b)
    return distribute(a, b)

def cnf(f):
    return to_cnf(push(eliminate(f)))
```

The negation case of `push` calls itself on `('not', part)`, which applies the law to the part below. After `push`, the formula is in NNF, so `push(eliminate(f))` is a function `nnf`.

### Size can explode

Distribution can multiply the size. The formula $(P_1 \wedge Q_1) \vee (P_2 \wedge Q_2) \vee \dots \vee (P_n \wedge Q_n)$ is a disjunction of $n$ small terms, but its CNF has $2^n$ clauses: each clause picks one letter from every pair. No clause can be dropped. There are cleverer conversions that introduce new letters and preserve only satisfiability, not equivalence; the plain one used here preserves equivalence, and that is why it can be large.

### Correctness

| P1 | If every rewriting step replaces a subformula by an equivalent formula, then the final formula is equivalent to the original. |
| P2 | Each step of `eliminate`, `push` and `distribute` replaces a subformula by an equivalent formula. |
| C | So `cnf(f)` is equivalent to `f`. |

The argument is valid (modus ponens). P1 holds because replacing a part of a formula by an equivalent part cannot change any truth value. P2 is the list of laws above, each of which a four-row truth table confirms. The argument gives us confidence in the design; checking a particular output with an equivalence test (week 8) is how you catch a bug in the code.

@example
title: Converting to CNF by hand
problem: Convert $(P \to Q) \to R$ to CNF and check the result.
step: Eliminate the conditionals, inside first: $P \to Q$ becomes $\neg P \vee Q$, and the whole formula becomes $\neg(\neg P \vee Q) \vee R$.
step: Push the negation inward: $\neg(\neg P \vee Q) \equiv \neg\neg P \wedge \neg Q \equiv P \wedge \neg Q$. The formula is now $(P \wedge \neg Q) \vee R$, which is in NNF.
step: Distribute the disjunction over the conjunction: $(P \wedge \neg Q) \vee R \equiv (P \vee R) \wedge (\neg Q \vee R)$.
step: Check: the original is false exactly when $P \to Q$ is true and $R$ is false, that is, on the rows PQR = TTF, FTF and FFF. The CNF is false when $R$ is false and ($P$ false or $Q$ true): the same three rows.
answer: $(P \vee R) \wedge (\neg Q \vee R)$

@example
title: Distribution multiplies clauses
problem: What does `distribute(('and', 'P', 'Q'), ('and', 'R', 'S'))` return, and how many clauses does it have?
step: This computes the CNF of $(P \wedge Q) \vee (R \wedge S)$. The first argument is a conjunction, so the function splits it: it returns the conjunction of `distribute('P', b)` and `distribute('Q', b)`, where `b` is `('and', 'R', 'S')`.
step: In `distribute('P', b)` the first argument is a letter, and `b` is a conjunction, so the function splits `b`: the result is the conjunction of `('or', 'P', 'R')` and `('or', 'P', 'S')`. Similarly `distribute('Q', b)` gives `('or', 'Q', 'R')` and `('or', 'Q', 'S')`.
step: The whole result is `('and', ('and', ('or', 'P', 'R'), ('or', 'P', 'S')), ('and', ('or', 'Q', 'R'), ('or', 'Q', 'S')))`.
step: It has four clauses, $P \vee R$, $P \vee S$, $Q \vee R$ and $Q \vee S$: one letter chosen from each of the two original terms, $2 \times 2$ ways.
answer: A conjunction of four clauses, as shown.

@mistakes
- Pushing a negation through a conjunction without turning it into a disjunction: $\neg(A \wedge B)$ is $\neg A \vee \neg B$, not $\neg A \wedge \neg B$.
- Eliminating $A \to B$ as $\neg A \wedge B$ or as $A \vee \neg B$; the correct form is $\neg A \vee B$.
- Calling a formula CNF because it contains $\wedge$ and $\vee$: in CNF no $\wedge$ may sit below a $\vee$, so $(P \wedge Q) \vee R$ is not in CNF.
- Distributing before eliminating the conditionals and pushing the negations in, so that the function meets connectives and negations it does not handle.

```python
        return v[f]
    op = f[0]
    if op == 'not':
        return not evaluate(f[1], v)
    a = evaluate(f[1], v)
    b = evaluate(f[2], v)
    if op == 'and':
        return a and b
    if op == 'or':
        return a or b
    if op == 'imp':
        return (not a) or b
    return a == b

        return [f]
    found = []
    for part in f[1:]:
        found = found + atoms(part)
    return sorted(set(found))

def valuations(names):
    return [dict(zip(names, row))
            for row in product([True, False], repeat=len(names))]

def equivalent(f, g):
    names = sorted(set(atoms(f) + atoms(g)))
    return all(evaluate(f, v) == evaluate(g, v) for v in valuations(names))

def is_literal(f):
    return isinstance(f, str) or (f[0] == 'not' and isinstance(f[1], str))

def is_clause(f):
    if is_literal(f):
        return True
    return f[0] == 'or' and is_clause(f[1]) and is_clause(f[2])

        return is_cnf(f[1]) and is_cnf(f[2])
    return is_clause(f)
```

```python
    return is_cnf(g) and equivalent(f, g)
```
hint: Two things must hold: the shape of `g` and its meaning relative to `f`.
solution: A correct conversion must be in CNF (shape) and equivalent to the original (meaning). Joining the two tests with `and` rejects a conversion that is equivalent but not in CNF, such as `f` itself, and one that is in CNF but changes the meaning, such as the converse of a conditional.

@quiz num
prompt: The formula $(A_1 \wedge B_1) \vee (A_2 \wedge B_2) \vee (A_3 \wedge B_3) \vee (A_4 \wedge B_4)$ has four terms, each a conjunction of two different letters, and all eight letters are different. answer: 16
unit: clauses
check: len(list(product([0, 1], repeat=4)))
hint: Each clause takes one letter from each of the four terms.
solution: A clause picks either $A_i$ or $B_i$ for every $i$ from 1 to 4, and different choices give different clauses. That gives $2 \cdot 2 \cdot 2 \cdot 2 = 2^4 = 16$ clauses; with $n$ terms there would be $2^n$.

@quiz mc
prompt: Which formula is a correct CNF of $P \leftrightarrow Q$?
choice*: $(\neg P \vee Q) \wedge (\neg Q \vee P)$
choice: $(P \wedge Q) \vee (\neg P \wedge \neg Q)$
choice: $(\neg P \vee Q) \vee (\neg Q \vee P)$
choice: $(P \vee Q) \wedge (\neg P \vee \neg Q)$
hint: A CNF is a conjunction of clauses, and it must be equivalent to the biconditional.
solution: The biconditional is equivalent to $(P \to Q) \wedge (Q \to P)$, that is, $(\neg P \vee Q) \wedge (\neg Q \vee P)$, a conjunction of clauses. The disjunction of the two conjunctions $P \wedge Q$ and $\neg P \wedge \neg Q$ is equivalent but is a DNF, not a CNF. The disjunction of the two clauses is true on every row, and $(P \vee Q) \wedge (\neg P \vee \neg Q)$ is exclusive or, which has the opposite truth values.

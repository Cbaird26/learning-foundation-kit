@article
A truth table settles the central questions of propositional logic. Now that a program can run through every valuation, each question becomes one short function. Recall the definitions (C1), with $\Gamma$ a set of premises and $A$, $B$ formulas.

| notion | definition |
|---|---|
| tautology | $A$ is true under every valuation |
| satisfiable | $A$ is true under some valuation |
| contradiction | $A$ is false under every valuation |
| entailment, $\Gamma \vDash A$ | every valuation that makes all of $\Gamma$ true makes $A$ true |
| equivalence | $A$ and $B$ have the same truth value under every valuation |

A valuation that makes every premise true and the conclusion false is a **countermodel**, and an argument is valid exactly when it has none.

### Two helpers: all and any

The built-in `all(items)` is `True` when every item is true, and `any(items)` is `True` when at least one is. Applied to a generator expression they say "for every valuation" and "for some valuation" almost in English: `all(evaluate(f, v) for v in valuations(names))`. Both are safe on an empty collection: `all([])` is `True` and `any([])` is `False`, which are the right answers for "every premise" when there are no premises.

### The functions

Assume `evaluate`, `atoms` and `valuations(names)` from the previous weeks. A subtle point: an argument's valuations must cover the letters of all its formulas, premises and conclusion together; a letter that occurs only in the conclusion still doubles the number of rows.

```python
def letters_of(formulas):
    return sorted(set(name for f in formulas for name in atoms(f)))

def is_tautology(f):
    return all(evaluate(f, v) for v in valuations(atoms(f)))

def entails(premises, conclusion):
    names = letters_of(premises + [conclusion])
    for v in valuations(names):
        if all(evaluate(p, v) for p in premises) and not evaluate(conclusion, v):
            return False
    return True
```

The loop in `entails` is the search for a countermodel from week 3: return `False` at the first one found, and `True` only if the loop finishes. Satisfiability is `any(evaluate(f, v) for v in valuations(atoms(f)))`. Equivalence is mutual entailment: `entails([f], g) and entails([g], f)`. Tautology is entailment from no premises, since `entails([], f)` is true exactly when `f` is true under every valuation. Two consequences follow from the definition. Premises that cannot all be true together entail every formula, because there is no valuation to serve as a countermodel (the *principle of explosion*). And $\Gamma \vDash A$ holds exactly when $\Gamma$ together with $\neg A$ cannot all be true (week 10).

### Checking an argument

An argument in English is checked by translating it into formulas and calling `entails`.

| P1 | If the butler did it, the window was open. |
| P2 | If the window was open, the cat escaped. |
| C | So if the butler did it, the cat escaped. |

With $B$, $W$ and $C$ for the three sentences, the premises are $B \to W$ and $W \to C$, and the conclusion is $B \to C$. This is **hypothetical syllogism**: `entails([('imp','B','W'), ('imp','W','C')], ('imp','B','C'))` is `True`, so the argument is valid. Validity says that if the premises are true then so is the conclusion; whether the premises are true of any real butler is a separate question.

@example
title: Checking modus tollens with a table
problem: Is the argument from $P \to Q$ and $\neg Q$ to $\neg P$ valid? Check every row.
step: There are four valuations of $P$ and $Q$. For each one, compute the two premises and the conclusion.
step: Row TT: $\neg Q$ is false, so the premises are not both true. Row TF: $P \to Q$ is false. Row FT: $\neg Q$ is false. None of these rows can be a countermodel.
step: Row FF: $P \to Q$ is true and $\neg Q$ is true, so both premises are true; the conclusion $\neg P$ is true as well, so this row is not a countermodel either.
step: No row makes both premises true and the conclusion false, so there is no countermodel.
answer: The argument is valid (modus tollens).

@example
title: Looking for a countermodel
problem: Is the argument from $P \to Q$ and $\neg P$ to $\neg Q$ valid? If not, give a countermodel.
step: A countermodel makes $P \to Q$ and $\neg P$ true and $\neg Q$ false. Premise $\neg P$ forces $P$ false; then $P \to Q$ is true whatever $Q$ is.
step: The conclusion $\neg Q$ is false when $Q$ is true. So take $P$ false and $Q$ true.
step: Check that valuation: $P \to Q$ is $F \to T$, which is true; $\neg P$ is true; $\neg Q$ is false.
answer: Invalid, with the countermodel $P$ false and $Q$ true: the fallacy of denying the antecedent.

@mistakes
- Generating valuations only for the letters of the conclusion (or only of the premises), so a letter that occurs elsewhere causes a `KeyError` or too few rows.
- Returning `True` inside the loop on the first row that works: validity needs the argument to hold on every row, so `True` belongs after the loop.
- Confusing "is satisfiable" with "is a tautology": satisfiable asks for some valuation, tautology for all of them.
- Believing that premises which are contradictory make an argument invalid. They make it valid, since no valuation makes all of them true.

@quiz num
prompt: An argument has premises $P \vee Q$ and $R \to S$ and conclusion $P \wedge R$. Over the four letters $P, Q, R, S$ there are 16 valuations. For how many of them are both premises true and the conclusion false?
answer: 7
unit: countermodels
check: count_countermodels([lambda p, q, r, s: p or q, lambda p, q, r, s: implies(r, s)], lambda p, q, r, s: p and r)
hint: First count the valuations that make both premises true, then remove those that also make the conclusion true.
solution: $P \vee Q$ is true on 3 of the 4 values of $P, Q$, and $R \to S$ is true on 3 of the 4 values of $R, S$, so both premises are true on $3 \times 3 = 9$ valuations. The conclusion $P \wedge R$ is true on 2 of those 9: $P, R$ true with $Q$ true or false, and $S$ forced true by $R \to S$. That leaves $9 - 2 = 7$ countermodels.

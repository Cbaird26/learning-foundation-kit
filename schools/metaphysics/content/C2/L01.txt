### Statements and expressions

A Python program is a list of **statements** that run from top to bottom. The statement `print(2 + 3)` shows `5` on a line of its own. The piece `2 + 3` is an **expression**: code that Python **evaluates** to a value. Every expression has a value, and every value has a **type**.

| type | what it holds | examples |
|---|---|---|
| `int` | whole numbers | `0`, `42`, `-7` |
| `float` | decimal numbers | `3.5`, `-0.25` |
| `str` | text, written in quotes | `"P"`, `'if P then Q'` |
| `bool` | truth values | `True`, `False` |

The two truth values are spelled `True` and `False`, with capital first letters. The built-in `type(3.5)` tells you the type of a value.

### Arithmetic

| operator | meaning | example | value |
|---|---|---|---|
| `+`, `-`, `*` | add, subtract, multiply | `7 * 2` | `14` |
| `/` | division, always a float | `7 / 2` | `3.5` |
| `//` | whole-number quotient (floor division) | `7 // 2` | `3` |
| `%` | remainder | `7 % 2` | `1` |
| `**` | power | `2 ** 5` | `32` |

`/` gives a float even when the division is exact: `8 / 2` is `4.0`. The pair `//` and `%` always fit together: `(a // b) * b + a % b` equals `a`. Python obeys the usual precedence (`**` first, then `*`, `/`, `//`, `%`, then `+` and `-`), so `2 + 3 * 4` is `14`; parentheses override it.

### Variables

The statement `rows = 2 ** 5` evaluates the right-hand side and **assigns** the value to the name `rows`. This `=` is not the equals sign of mathematics: it is an instruction, executed once, in order. That is why `n = n + 1` makes sense: it computes the old `n` plus one and stores the result back in `n`. Names use letters, digits and underscores, cannot start with a digit, and are case-sensitive. Choose names that say what the value means.

### Text and printing

Strings join with `+` and repeat with `*`: `"ab" + "c"` is `"abc"` and `3 * "ab"` is `"ababab"`. `len("abc")` is `3`. You cannot add a number to a string: `"rows: " + 8` raises a `TypeError`. Convert with `str(8)`, or use an **f-string**, where an expression in braces is evaluated and inserted: `f"{n} letters give {2 ** n} rows"`. `print` accepts several arguments and separates them with single spaces.

### Comparisons make truth values

`==`, `!=`, `<`, `<=`, `>` and `>=` compare two values and produce a `bool`: `5 == 5` is `True`, `5 != 5` is `False`. Note the difference: `=` assigns, `==` compares. Next week these truth values are combined with `and`, `or` and `not`.

### A first argument about a program

Here is a short argument about truth tables, and a program that checks its conclusion.

| P1 | For every number $n$ of sentence letters, the truth table has $2^n$ rows. |
| P2 | The formula $(P \to Q) \vee (R \wedge S \wedge T)$ has five sentence letters. |
| C | So its truth table has 32 rows. |

The argument is valid: the conclusion is premise P1 applied to $n = 5$. It is sound, because P1 is true: each letter independently takes one of two values, and $2 \cdot 2 \cdots 2$ with $n$ factors is $2^n$. In Python, `2 ** 5` evaluates to `32`.

@example
title: Tracing a program with variables
problem: What does this program print?

```python
a = 17
b = a // 5
a = a % 5
c = a + b
print(a, b, c)
```
step: `a = 17` stores `17` in `a`.
step: `b = a // 5` evaluates `17 // 5`, which is `3`, so `b` is `3`.
step: `a = a % 5` evaluates the right side with the old `a`: `17 % 5` is `2`. Now `a` is `2` and `b` is still `3`.
step: `c = a + b` is `2 + 3`, so `c` is `5`.
step: `print(a, b, c)` prints the three values separated by single spaces.
answer: `2 3 5`

@example
title: Writing a program that prints a sentence
problem: Write a program that stores the number of sentence letters (6) in a variable, computes the number of truth-table rows, and prints `A table with 6 letters has 64 rows.`
step: Store the input in a variable with a meaningful name: `letters = 6`.
step: Compute the rows with the power operator: `rows = 2 ** letters`, which is `64`.
step: Print the sentence. With several arguments, `print` puts a space between them, so the pieces are the text, the number, the text, the number and the final text:

```python
letters = 6
rows = 2 ** letters
print("A table with", letters, "letters has", rows, "rows.")
```
step: An f-string gives the same line and is easier to read: `print(f"A table with {letters} letters has {rows} rows.")`.
answer: Both versions print `A table with 6 letters has 64 rows.`

@mistakes
- Writing `=` where you mean `==`: `x = 5` stores a value, `x == 5` asks whether `x` is 5.
- Expecting `/` to give a whole number: `10 / 2` is `5.0`, a float. Use `//` for a whole-number quotient.
- Joining text and numbers with `+`, as in `"rows: " + 8`, which raises a `TypeError`. Use `str(8)` or an f-string.
- Forgetting quotes: `print(P)` looks for a variable named `P`, while `print("P")` prints the letter.

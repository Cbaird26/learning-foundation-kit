@article
Propositional logic asks whether a formula is true under a valuation. First-order logic asks whether a **sentence** is true in a **model**: a non-empty set of objects, the **domain**, together with an interpretation of each predicate as a set of objects (or of tuples of objects) of which it is true. When the domain is finite, the quantifiers become loops: $\forall x$ means "for every element of the domain" and $\exists x$ means "for some element". This week you build the data structures, and write the evaluator.

### Sets

A **set** holds each item at most once and has no order. `{1, 2, 3}` is a set; `set()` is the empty set (while `{}` is an empty dictionary). Tests and operations:

- `2 in A` tests membership, and `len(A)` is the number of elements.
- `A | B` is the union, `A & B` the intersection, and `A - B` the elements of `A` that are not in `B`.
- `A <= B` tests whether `A` is a subset of `B`.
- A **set comprehension** builds a set: `{x * x for x in A if x > 1}`.

A set with $n$ elements has $2^n$ subsets, which is why the number of relations on a domain grows so fast. Elements of a set must not be changeable, so lists cannot be put in sets, but tuples can: `{(1, 2), (2, 3)}` is a set of ordered pairs, which is exactly a binary relation.

### Dictionaries

A **dictionary** maps keys to values: `ages = {'Ana': 31, 'Bo': 27}`. Then `ages['Ana']` is `31`, `ages['Cy'] = 40` adds an entry, `'Ana' in ages` tests whether a key is present, and `ages.get('Di')` returns `None` for a missing key (where `ages['Di']` would raise a `KeyError`). Looping `for name in ages:` visits the keys, and `for name, age in ages.items():` visits key-value pairs.

### Models and sentences

A model is a dictionary with the domain and the extension of each predicate. We store every extension as a set of tuples, even for one-place predicates, so that all predicates are handled in one way:

```python
model = {'domain': {1, 2, 3},
         'preds': {'F': {(1,), (2,)}, 'R': {(1, 2), (2, 3)}}}
```

Here $F$ is true of 1 and 2, and $Rab$ is true when $(a, b)$ is $(1, 2)$ or $(2, 3)$. Formulas extend the tuple representation of week 5: `('pred', 'R', 'x', 'y')` is $Rxy$, `('eq', 'x', 'y')` is $x = y$, `('all', 'x', A)` is $\forall x\, A$ and `('some', 'x', A)` is $\exists x\, A$; the connectives `not`, `and`, `or`, `imp` and `iff` are as before. For instance $\forall x\,(Fx \to \exists y\, Rxy)$ is

```python
('all', 'x', ('imp', ('pred', 'F', 'x'), ('some', 'y', ('pred', 'R', 'x', 'y'))))
```

### The evaluator

The truth of a formula with free variables depends on an **environment** `env`, a dictionary from variables to elements of the domain. A quantifier extends the environment with each element in turn:

```python
def extend(env, var, d):
    new = dict(env)
    new[var] = d
    return new

def holds(model, f, env):
    op = f[0]
    if op == 'pred':
        return tuple(env[x] for x in f[2:]) in model['preds'][f[1]]
    if op == 'eq':
        return env[f[1]] == env[f[2]]
    if op == 'not':
        return not holds(model, f[1], env)
    if op == 'all':
        return all(holds(model, f[2], extend(env, f[1], d))
                   for d in model['domain'])
    if op == 'some':
        return any(holds(model, f[2], extend(env, f[1], d))
                   for d in model['domain'])
    a = holds(model, f[1], env)
    b = holds(model, f[2], env)
    if op == 'and':
        return a and b
    if op == 'or':
        return a or b
    if op == 'imp':
        return (not a) or b
    return a == b
```

A sentence has no free variables, so it is evaluated with the empty environment: `holds(model, sentence, {})`. The two quantifier cases are the new idea; everything else is the recursion of week 6. A universal sentence is true in an empty domain and an existential one false, but our models have non-empty domains, as in standard first-order logic.

### A countermodel for a quantifier shift

| P1 | Everyone admires someone: $\forall x\, \exists y\, Rxy$. |
| C | So there is someone whom everyone admires: $\exists y\, \forall x\, Rxy$. |

This argument, the **quantifier shift fallacy**, is invalid. Take the domain $\{1, 2\}$ with $R = \{(1, 2), (2, 1)\}$: each element admires the other, so the premise is true, but neither element is admired by both, so the conclusion is false. `holds` confirms it, giving `True` for the premise and `False` for the conclusion. The fallacy is exposing how the order of quantifiers matters: in the premise the admired person may depend on the admirer.

@example
title: Evaluating a nested quantifier by hand
problem: In the model with domain $\{1, 2, 3\}$, $F = \{1, 2\}$ and $R = \{(1, 2), (2, 3)\}$, is $\forall x\,(Fx \to \exists y\, Rxy)$ true?
step: A universal sentence is true when its body is true for every element, so check $x = 1$, $x = 2$ and $x = 3$.
step: For $x = 1$: $F1$ is true, and $\exists y\, R1y$ is true with $y = 2$, because $(1, 2) \in R$. The conditional is true.
step: For $x = 2$: $F2$ is true, and $\exists y\, R2y$ is true with $y = 3$. The conditional is true.
step: For $x = 3$: $F3$ is false, so the conditional is true whatever follows, even though no $y$ satisfies $R3y$.
answer: True, since the body holds for all three elements.

@example
title: Finding a witness to a false universal sentence
problem: In the model with domain $\{1, 2, 3\}$ and $R = \{(1, 2), (2, 1), (2, 3)\}$, is $\forall x\, \forall y\,(Rxy \to Ryx)$ true? The sentence says that $R$ is symmetric.
step: A universal sentence is false as soon as one case fails, so look for a pair $(x, y)$ with $Rxy$ true and $Ryx$ false.
step: The pair $(1, 2)$ is fine: $(2, 1)$ is in $R$. The pair $(2, 1)$ is fine for the same reason.
step: The pair $(2, 3)$ is in $R$, but $(3, 2)$ is not. With $x = 2$ and $y = 3$, the conditional $Rxy \to Ryx$ is false.
answer: False; the witness is $x = 2$, $y = 3$.

@mistakes
- Writing `{}` for the empty set; it is an empty dictionary, and the empty set is `set()`.
- Storing a one-place predicate as a set of numbers, `{1, 2}`, while `holds` looks for tuples such as `(1,)`.
- Forgetting that a one-element tuple needs a comma: `(1)` is just the number `1`.
- Evaluating a quantifier body without extending the environment, so the variable is never bound and `env[x]` raises a `KeyError`.

model:
```python
def is_reflexive(domain, rel):
    return all((x, x) in rel for x in domain)

def is_symmetric(rel):
    return all((y, x) in rel for (x, y) in rel)

def is_transitive(rel):
    return all((x, w) in rel
               for (x, y) in rel for (z, w) in rel if y == z)
```
hint: Each property is a "for all" statement, which is what `all` with a generator expression expresses.
hint: For transitivity, look at every pair of pairs `(x, y)` and `(z, w)` where `y == z`, and require `(x, w)`.
solution: Reflexivity asks for `(x, x)` for every `x` in the domain. Symmetry asks for the reversed pair of every pair. Transitivity asks, for every two pairs that chain, for the pair that joins their ends. The empty relation is symmetric and transitive, and reflexive only on an empty domain.

For `{1}` the result is a list of the two relations `frozenset()` and `frozenset({(1, 1)})`.

tests:
```python
assert len(all_relations({1, 2})) == 16
assert len(all_relations({1})) == 2
assert len(all_relations(set())) == 1
assert frozenset() in all_relations({1, 2})
assert frozenset({(1, 1), (1, 2), (2, 1), (2, 2)}) in all_relations({1, 2})

```
model:
```python
from itertools import product

def all_relations(domain):
    pairs = [(x, y) for x in sorted(domain) for y in sorted(domain)]
    return [frozenset(p for p, keep in zip(pairs, bits) if keep)
            for bits in product([False, True], repeat=len(pairs))]
```
hint: First list all the possible ordered pairs; a relation chooses, for each pair, whether to include it.
hint: `product([False, True], repeat=len(pairs))` lists every way of choosing; use `zip(pairs, bits)` to pick the included pairs.
solution: Each relation corresponds to a row of a truth table over the possible pairs: `True` means the pair is in the relation. So `product` over `len(pairs)` choices generates all $2^{n^2}$ relations, and each is turned into a `frozenset` of the chosen pairs. For the empty domain there are no pairs and exactly one relation, the empty one.

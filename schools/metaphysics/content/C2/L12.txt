@article
A proof is a finite object, and checking it is a mechanical job: no insight is needed to see whether each line is justified. That is why proof checkers can be small programs, and why a proof is a trustworthy certificate of validity. This week you write one for a fragment of the Fitch-style natural deduction system of C1, with the rule names of forall x: Calgary.

### What a correct proof is

A proof is a numbered list of lines. A line is a formula with a **depth** (how many subproofs it sits inside) and a **justification**: a rule and the lines it cites. The premises come first, at depth 0, with the rule `PR`; an **assumption** `AS` opens a subproof one level deeper. Here is a proof of the hypothetical syllogism.

```text
1 | P → Q        PR
2 | Q → R        PR
  |---
3 | | P          AS
4 | | Q          →E 1, 3
5 | | R          →E 2, 4
6 | P → R        →I 3–5
```

Line 4 is justified by →E (conditional elimination, modus ponens) from the conditional on line 1 and its antecedent on line 3. Line 6 is justified by →I from the whole subproof 3–5: assuming $P$ and reaching $R$ shows $P \to R$. Two kinds of check apply to each line: the **rule check** (does the formula follow from the cited formulas by the rule?) and the **scope check** (may the cited lines be used here?). A line may cite an earlier line only if that line is in the same subproof or in an enclosing one; lines inside a subproof that has been closed are out of reach, and only the subproof as a whole may be cited, by rules such as →I and ¬I. Another example, with a negation rule: a proof of $\neg(P \wedge \neg P)$ from no premises.

```text
  |---
1 | | P ∧ ¬P     AS
2 | | P          ∧E 1
3 | | ¬P         ∧E 1
4 | | ⊥          ¬E 3, 2
5 | ¬(P ∧ ¬P)    ¬I 1–4
```

### A proof as data

Each line is a tuple `(depth, formula, rule, cites)`, where `formula` uses the tuple representation, `cites` is a list of line numbers (counting from 1), and a subproof is cited as a pair `(first, last)`. In code we write the rule names in plain characters: `'&I'` for ∧I, `'&E'` for ∧E, `'->E'` for →E, `'->I'` for →I, `'R'`, `'PR'` and `'AS'`. The proof above is

```python
proof = [
    (0, ('imp', 'P', 'Q'), 'PR', []),
    (0, ('imp', 'Q', 'R'), 'PR', []),
    (1, 'P', 'AS', []),
    (1, 'Q', '->E', [1, 3]),
    (1, 'R', '->E', [2, 4]),
    (0, ('imp', 'P', 'R'), '->I', [(3, 5)]),
]
```

### Checking scope

Line `j` is **accessible** from line `i` when `j` is earlier and no line from `j` up to `i` has a smaller depth than `j`: a smaller depth means a subproof has closed. A subproof cited from line `i` must begin with an assumption at depth $d$, end at depth $d$, have no line shallower than $d$ in between, be closed right after its last line, and `i` must be at depth $d - 1$ and still inside the enclosing context.

```python
def depth(proof, n):
    return proof[n - 1][0]

def formula(proof, n):
    return proof[n - 1][1]

def accessible(proof, j, i):
    return (isinstance(j, int) and 1 <= j < i
            and all(depth(proof, k) >= depth(proof, j)
                    for k in range(j, i + 1)))

def subproof_ok(proof, a, b, i):
    if not (isinstance(a, int) and isinstance(b, int) and 1 <= a <= b < i):
        return False
    d = depth(proof, a)
    return (proof[a - 1][2] == 'AS' and d >= 1 and depth(proof, b) == d
            and all(depth(proof, k) >= d for k in range(a, b + 1))
            and depth(proof, b + 1) < d and depth(proof, i) == d - 1
            and all(depth(proof, k) >= d - 1 for k in range(b + 1, i + 1)))
```

### Checking rules

Each rule is a small function that looks at line `i`:

```python
def check_and_intro(proof, i):
    d, f, rule, cites = proof[i - 1]
    if len(cites) != 2 or not all(accessible(proof, j, i) for j in cites):
        return False
    return f == ('and', formula(proof, cites[0]), formula(proof, cites[1]))

def check_and_elim(proof, i):
    d, f, rule, cites = proof[i - 1]
    if len(cites) != 1 or not accessible(proof, cites[0], i):
        return False
    g = formula(proof, cites[0])
    return not isinstance(g, str) and g[0] == 'and' and f in g[1:]
```

The checks for →E, →I and the other rules follow the same pattern. A whole-proof checker runs the rule check for every line, and also checks the shape of the depths. Writing it is part of this week's work and of the project.

### Proofs and countermodels

The proof system is **sound**: if $\Gamma \vdash A$ then $\Gamma \vDash A$. For propositional logic and, with the quantifier rules, for first-order logic it is also **complete**: if $\Gamma \vDash A$ then $\Gamma \vdash A$ (for first-order logic this is Gödel's completeness theorem, 1929–1930). Soundness gives a way to show that no proof can exist.

| P1 | If $\Gamma \vdash A$, then $\Gamma \vDash A$ (soundness). |
| P2 | In the model with domain $\{1, 2\}$ and $R = \{(1, 2), (2, 1)\}$, the sentence $\forall x\, \exists y\, Rxy$ is true and $\exists y\, \forall x\, Rxy$ is false, so $\forall x\, \exists y\, Rxy \nvDash \exists y\, \forall x\, Rxy$. |
| C | So there is no proof of $\exists y\, \forall x\, Rxy$ from $\forall x\, \exists y\, Rxy$. |

The argument is valid by modus tollens. P1 is the soundness theorem and P2 is checked by `holds` from last week. A finite model, evaluated by a program, therefore settles that a hunt for a proof is pointless.

@example
title: Finding the faulty line
problem: Find the first incorrect line of this proof of $P \to R$ from $P \to (Q \to R)$ and $Q$, and repair it.

```text
1 | P → (Q → R)   PR
2 | Q             PR
  |---
3 | | P           AS
4 | | Q → R       →E 1, 3
5 | | R           →E 4, 3
6 | P → R         →I 3–5
```
step: Lines 1 and 2 are premises, and line 3 opens a subproof with an assumption; none of them needs a rule check.
step: Line 4 cites line 1, $P \to (Q \to R)$, and line 3, $P$. Modus ponens gives $Q \to R$. Correct.
step: Line 5 cites line 4, $Q \to R$, and line 3, which is $P$. For →E, the second cited line must be the antecedent of the first, $Q$, but line 3 is $P$. Incorrect.
step: Repair: the formula $Q$ is on line 2, a premise at depth 0, which is accessible from inside the subproof. Line 5 should read `→E 4, 2`, and then line 6 is correct: →I 3–5 closes the subproof and gives $P \to R$.
answer: Line 5 is the first incorrect line; the correct justification is →E 4, 2.

@mistakes
- Citing a line inside a subproof that has already closed: only the subproof as a whole can be cited after it ends.
- Citing the lines of →E in the wrong roles: the first is the conditional $A \to B$, the second is $A$ itself, and the conclusion is $B$.
- Ending a →I subproof but writing the conclusion at the subproof's own depth, or citing a range whose first line is not an assumption.
- Treating a countermodel as a failed proof attempt: a model in which the premises are true and the conclusion false shows that no proof exists, by soundness; failing to find a proof shows nothing by itself.

```python
            and all(depth(proof, k) >= d for k in range(a, b + 1))
            and depth(proof, b + 1) < d and depth(proof, i) == d - 1
            and all(depth(proof, k) >= d - 1 for k in range(b + 1, i + 1)))

def line_ok(proof, i):
    d, f, rule, cites = proof[i - 1]
    if rule in ('PR', 'AS'):
        return True
    if rule == '->I':
        if len(cites) != 1 or not isinstance(cites[0], tuple):
            return False
        a, b = cites[0]
        return (subproof_ok(proof, a, b, i)
                and f == ('imp', formula(proof, a), formula(proof, b)))
    if rule not in ('R', '&I', '&E', '->E'):
        return False
    if not all(accessible(proof, j, i) for j in cites):
        return False
    got = [formula(proof, j) for j in cites]
    if rule == 'R':
        return len(got) == 1 and got[0] == f
    if rule == '&I':
        return len(got) == 2 and f == ('and', got[0], got[1])
    if rule == '&E':
        return (len(got) == 1 and not isinstance(got[0], str)
                and got[0][0] == 'and' and f in got[0][1:])
    return len(got) == 2 and got[0] == ('imp', got[1], f)

def check_proof(proof):
    previous = 0
    seen_other = False
    for i, line in enumerate(proof, start=1):
        d, f, rule, cites = line
        if rule == 'AS':
            if d != previous + 1:
                return False
        elif d > previous:
            return False
        if rule == 'PR':
            if d != 0 or seen_other:
                return False
        else:
            seen_other = True
        if not line_ok(proof, i):
            return False
        previous = d
    return previous == 0
```

solution: The shape checks are local to a line and its predecessor, and `line_ok` does the rule and scope checks. After the loop, the last depth must be 0, so no subproof is left open. Each of the failing tests violates exactly one condition: a bad citation, a depth jump, a depth increase without an assumption, a late premise, or an open subproof.

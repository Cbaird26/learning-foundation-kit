@article
A truth table for an argument with six letters has 64 rows. Nobody should check them one by one if one clever question can settle the matter: **can the premises all be true while the conclusion is false?** The short truth table method asks exactly this question.

### The short method

1. Write the argument in symbols.
2. **Assume** the conclusion is false and every premise is true, and write those values under the main connectives.
3. Work out the values of the letters as far as they are **forced**.
4. If you reach a **contradiction** (a letter that must be both T and F), the assumption is impossible, so the argument is **valid**.
5. If you can fill in every letter without contradiction, you have found a **counterexample**, so the argument is **invalid**, and the values you found are its row.

If a choice is not forced, try each option. The argument is valid only if every option ends in contradiction.

### The common valid forms

These forms are valid, and every argument with the same shape is valid, whatever sentences replace the letters. A truth table for the form proves it once for all instances.

| Name | Form |
|---|---|
| **Modus ponens** | $p \to q$, $p$ $\therefore$ $q$ |
| **Modus tollens** | $p \to q$, $\neg q$ $\therefore$ $\neg p$ |
| **Hypothetical syllogism** | $p \to q$, $q \to r$ $\therefore$ $p \to r$ |
| **Disjunctive syllogism** | $p \vee q$, $\neg p$ $\therefore$ $q$ |
| **Constructive dilemma** (simple form) | $p \vee q$, $p \to r$, $q \to r$ $\therefore$ $r$ |

### Two invalid forms that look valid

| Name | Form | Counterexample row |
|---|---|---|
| **Affirming the consequent** | $p \to q$, $q$ $\therefore$ $p$ | $p$ false, $q$ true |
| **Denying the antecedent** | $p \to q$, $\neg p$ $\therefore$ $\neg q$ | $p$ false, $q$ true |

"If it is a square, it has four sides. It has four sides. So it is a square" has true premises and a false conclusion when the shape is a rectangle. Another invalid form is "$p$ or $q$; $p$; so not $q$": the inclusive "or" does not rule out both.

### Using forms in reasoning

To test an argument, first see whether it has a valid form. If it does, it is valid. If it resembles an invalid form, do not conclude invalidity just from the resemblance: check the actual formulas, since an argument can contain more structure than the form shows. In everyday reasoning, modus tollens is the form behind "if the theory were true we would see $X$; we do not see $X$; so the theory is false".

@example
title: A short table that proves validity
problem: Test: $p \to q$, $q \to r$, $\neg r$ $\therefore$ $\neg p$.
step: Assume the conclusion is false, so $\neg p$ is F and $p$ is T. Assume the premises are true, so $\neg r$ is T and $r$ is F.
step: With $r$ false, $q \to r$ is true only if $q$ is F. With $p$ true, $p \to q$ is true only if $q$ is T.
step: So $q$ would have to be both F and T: a contradiction.
answer: Valid: the assumption of true premises and a false conclusion is impossible.

@example
title: A short table that finds a counterexample
problem: Test: $p \to q$, $r \to q$ $\therefore$ $p \vee r$.
step: Assume the conclusion false: $p \vee r$ is F, so $p$ is F and $r$ is F.
step: Check the premises. With $p$ false, $p \to q$ is true whatever $q$ is. With $r$ false, $r \to q$ is true whatever $q$ is.
step: No contradiction: for example $p$ F, $r$ F and $q$ T make both premises true and the conclusion false.
answer: Invalid; counterexample: $p$ false, $q$ true, $r$ false (and $q$ false works as well).

@mistakes
- Stopping the short method when the first forced value is found. Continue until every letter is forced or you reach a contradiction.
- Concluding "invalid" after a contradiction in one case when a choice was not forced: you must check every option for the unforced letters.
- Confusing modus tollens with denying the antecedent: modus tollens denies the consequent ($\neg q$) and concludes $\neg p$.
- Treating "or" as exclusive in the disjunctive syllogism test. With the inclusive or, "$p$ or $q$; $p$; so not $q$" is invalid.

@practice num
prompt: How many of the eight rows have all of these true and the conclusion false: premises $p \vee q$ and $p \to r$, conclusion $r$ (letters in the order $p, q, r$)?
answer: 1
unit: rows
check: count_countermodels([lambda p, q, r: p or q, lambda p, q, r: implies(p, r)], lambda p, q, r: r)
hint: With $r$ false, $p \to r$ forces $p$ to be false; then $p \vee q$ forces $q$ true.
solution: A counterexample needs $r$ false. Then $p \to r$ is true only if $p$ is false, and $p \vee q$ is true only if $q$ is true. That fixes one row: $p$ F, $q$ T, $r$ F. So there is 1 counterexample row.

prompt: Use the short truth table method to test: $p \to (q \vee r)$, $\neg q$ $\therefore$ $\neg p$. Show each assumed value and give your verdict, with a counterexample if there is one.
hint: Assume the conclusion is false and both premises are true, then see which letters are forced and which are free.
solution: Assume $\neg p$ is false, so $p$ is T. Assume $\neg q$ is T, so $q$ is F. Then $p \to (q \vee r)$ is true only if $q \vee r$ is T, and since $q$ is F, $r$ must be T. No contradiction arises: $p$ T, $q$ F, $r$ T makes $p \to (q \vee r)$ true, $\neg q$ true and $\neg p$ false. So the argument is invalid, with that counterexample.

rubric: Finds the values $p$ T, $q$ F, $r$ T with no contradiction.

@quiz num
prompt: For the argument $p \to (q \wedge r)$, $q$ $\therefore$ $p$, how many of the eight rows (letters $p, q, r$) are counterexamples?
answer: 2
unit: rows
check: count_countermodels([lambda p, q, r: implies(p, q and r), lambda p, q, r: q], lambda p, q, r: p)
hint: A counterexample has $p$ false and $q$ true; the letter $r$ is not constrained.
solution: With $p$ false the first premise is true, and with $q$ true the second is true; the conclusion $p$ is false. The letter $r$ can be either value, so there are 2 counterexamples: FTT and FTF.

@article
Week 2 defined validity as the impossibility of true premises with a false conclusion, and tested it by hunting for a counterexample in the imagination. Truth tables replace the imagination with a complete list: every way the sentence letters could be true or false. If the list contains a counterexample, you will find it; if not, the argument is valid.

### The test

Write the argument in symbols, list the letters, and build a table with $2^n$ rows. Give each premise and the conclusion its own column. Then look at each row:

- A **counterexample row** has every premise true and the conclusion false. If there is one, the argument is **invalid**.
- If there is no counterexample row, the argument is **valid**.

Only the rows where all premises are true matter. On each of these, the conclusion must be true. Rows where some premise is false place no demands on the conclusion.

### Why this works

A row of the table is a possible situation, described in terms of the truth or falsity of the sentence letters. Validity says that no possible situation makes the premises true and the conclusion false, so the table checks them all. This links back to week 6: an argument is valid exactly when the conditional "premise 1 and premise 2 and ... then conclusion" is a tautology.

### Some special cases

- If **no row makes all the premises true** (the premises are inconsistent), there is no counterexample, so the argument is valid. It is valid but cannot be sound.
- If the **conclusion is a tautology**, it is true on every row, so no row can be a counterexample, and the argument is valid whatever the premises say.
- A premise that is a **contradiction** makes the argument valid for the first reason.

These results can seem odd, since a valid argument need not have any connection between premises and conclusion. They follow directly from the definition of validity, and logicians who want a connection between premises and conclusion study different logics.

### Layout

| $p$ | $q$ | $p \to q$ | $q$ | $p$ |
|---|---|---|---|---|

Put the premises first, then the conclusion, separated in your own table by a double line. Mark each row where all premises are T, and check the conclusion on exactly those rows.

@example
title: An invalid argument
problem: Test: "If the pipe froze, the basement flooded. The basement flooded. So the pipe froze." Use $p$: the pipe froze and $q$: the basement flooded.
step: In symbols: P1, $p \to q$; P2, $q$; C, $p$. Two letters give four rows: TT, TF, FT, FF.
step: Fill in the columns. $p \to q$: T, F, T, T. $q$: T, F, T, F. Conclusion $p$: T, T, F, F.
step: Rows where both premises are true: TT (conclusion T) and FT (conclusion F). Row FT is a counterexample.
step: The counterexample row says: the pipe did not freeze, the basement flooded (some other cause), so both premises are true and the conclusion is false.
answer: Invalid; the counterexample row is $p$ false, $q$ true.

@example
title: A valid argument with three letters
problem: Test: $p \to q$, $q \to r$, so $p \to r$.
step: Three letters give eight rows. Compute $p \to q$ over TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF: T, T, F, F, T, T, T, T.
step: Compute $q \to r$: T, F, T, T, T, F, T, T. And the conclusion $p \to r$: T, F, T, F, T, T, T, T.
step: Rows where both premises are T: TTT, FTT, FFT, FFF (rows 1, 5, 7 and 8). On these four rows, $p \to r$ is T, T, T, T.
step: No counterexample row, so the argument is valid.
answer: Valid: on every row where both premises are true, the conclusion is also true.

@mistakes
- Judging validity from a single row or from the conclusion column alone. You need every row where all the premises are true.
- Declaring an argument invalid because some row has a false conclusion. That is fine unless all premises are true on that row.
- Thinking that an argument with inconsistent premises must be invalid. With no row making all premises true, there is no counterexample.
- Mixing up the order of rows between columns. Use the standard order for every column of one table.

@quiz num
prompt: For the argument $p \to q$, $q \to r$ $\therefore$ $r \to p$, how many of the eight rows have both premises true and the conclusion false?
answer: 2
unit: rows
check: count_countermodels([lambda p, q, r: implies(p, q), lambda p, q, r: implies(q, r)], lambda p, q, r: implies(r, p))
hint: The conclusion $r \to p$ is false only when $r$ is true and $p$ is false.
solution: The conclusion is false on rows where $r$ is T and $p$ is F: FTT and FFT. On both rows $p \to q$ is true (false antecedent) and $q \to r$ is true (true consequent). So there are 2 counterexample rows, and the argument is invalid.

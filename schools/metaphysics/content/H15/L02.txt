@article
Compare two arguments. "All dogs are reptiles; Rex is a dog; so Rex is a reptile." And: "Every swan I have seen is white; so the next swan I see will be white." Something is right about the first, even though its premise is false: if the premises were true, the conclusion could not be false. The second offers good but not perfect support. Logic gives names to these different relationships.

### Deductive validity

A deductive argument claims that its conclusion follows with certainty. An argument is **valid** if it is impossible for all its premises to be true and its conclusion false. Otherwise it is **invalid**. Validity is about the link between premises and conclusion, not about whether the premises are actually true. The argument about Rex is valid: in any situation where all dogs are reptiles and Rex is a dog, Rex is a reptile.

An argument is **sound** if it is valid and all its premises are actually true. The Rex argument is valid but not sound, since its first premise is false. A sound argument always has a true conclusion. Two facts to remember:

- A valid argument can have false premises and a true or false conclusion.
- If a valid argument has a false conclusion, at least one premise is false.

### The counterexample method

To show an argument invalid, describe a possible situation in which every premise is true and the conclusion is false: a **counterexample**. It need not be a realistic situation, only a possible one. Take "If the alarm is on, the door is locked. The door is locked. So the alarm is on." Imagine a house whose door is locked and whose alarm is off. Then both premises are true and the conclusion is false, so the argument is invalid. If you cannot find a counterexample after real effort, that is a sign of validity but not proof; later weeks give exact tests (Venn diagrams and truth tables).

### Induction: strength and cogency

An **inductive** argument claims only that its conclusion is probable given its premises. It is **strong** if, supposing the premises true, the conclusion is likely; **weak** otherwise. Strength comes in degrees. An inductive argument that is strong and has all true premises is **cogent**. Even a strong inductive argument is deductively invalid: its premises could be true and its conclusion false.

| | Deductive | Inductive |
|---|---|---|
| Claim | Conclusion follows with certainty | Conclusion is probable |
| Good form | Valid | Strong |
| Good form plus true premises | Sound | Cogent |
| Comes in degrees? | No | Yes |

A simple inductive pattern is the **statistical syllogism**: "A fraction $f$ of the $F$s are $G$; this is an $F$; so this is probably a $G$." The higher $f$ is, the stronger the argument. If 9 out of 10 bulbs in a box work, a bulb picked at random works with probability 0.9, and the argument is strong, but not valid.

### Deduction or induction?

Ask which claim the author is making. Words like "certainly", "must", "it follows that" suggest deduction; "probably", "likely", "so we can expect" suggest induction. When the wording is unclear, evaluate the argument both ways, or charitably as the stronger kind it could be.

@example
title: Valid, sound, or neither?
problem: Classify each argument as valid or invalid, and sound or unsound. (a) "Every planet of our solar system orbits the Sun. Neptune is a planet of our solar system. So Neptune orbits the Sun." (b) "All metals are magnets. Copper is a metal. So copper is a magnet." (c) "Some teachers are musicians. Mr. Cho is a teacher. So Mr. Cho is a musician."
step: (a) If every planet of our solar system orbits the Sun and Neptune is one of them, Neptune must orbit the Sun: valid. The premises are true, so the argument is sound.
step: (b) The form is the same as in (a), so it is valid. But "All metals are magnets" is false, so it is unsound.
step: (c) Counterexample: suppose some teachers are musicians but Mr. Cho is one of the teachers who is not. Both premises are true and the conclusion false, so it is invalid, and therefore unsound. It could still be a weak inductive argument.
answer: (a) valid and sound; (b) valid but unsound; (c) invalid, so unsound.

@example
title: Judging inductive strength
problem: A jar holds 50 buttons, 47 of them blue. Someone argues: "A button drawn at random from this jar is probably blue, since 47 of the 50 are." Is the argument deductive or inductive, strong or weak, and valid?
step: The word "probably" shows that the claim is only that the conclusion is likely: inductive.
step: The chance of blue is $47/50 = 0.94$, which is high, so the argument is strong.
step: It is not valid, since the premise could be true while the drawn button is one of the 3 non-blue ones.
answer: Inductive, strong, and not valid; with a true premise it is cogent.

@mistakes
- Thinking that a valid argument must have true premises. Validity only says that if the premises were true, the conclusion would have to be.
- Calling an argument "invalid" because its conclusion is false or surprising. A false conclusion shows that an argument is unsound, not that it is invalid.
- Calling a strong inductive argument "valid". Strength and validity are different properties, and a strong argument has a possible counterexample.
- Saying that an argument with a counterexample "might still be valid". One possible situation with true premises and a false conclusion is enough to make it invalid.

choice*: All squares are rectangles. All rectangles have four sides. So all squares have four sides.
choice: Some cats are black. Some black things are bats. So some cats are bats.
choice*: If it is Monday, the shop is open. The shop is not open. So it is not Monday.

The cats-and-bats argument is invalid: the cats that are black may be different from the black things that are bats. The sun argument is a good inductive argument, but it is deductively invalid since the sun could fail to rise even though it has always risen so far.

@quiz num
prompt: A box holds 500 sealed packets, and 20 of them contain a defect. One packet is chosen at random. What is the probability, as a percent, that it has no defect?
answer: 96
unit: %
check: (500 - 20) / 500 * 100
hint: Count the packets without a defect first.
solution: There are $500 - 20 = 480$ packets without a defect, and $480/500 = 0.96$, so the probability is 96%.

@quiz mc
prompt: Consider: "If the cake contains eggs, it is not vegan. The cake is not vegan. So the cake contains eggs." Which description shows that the argument is invalid?
choice*: A cake with no eggs that contains butter, so it is not vegan: both premises true, conclusion false.
choice: A cake that contains eggs: both premises true, conclusion true.
choice: The observation that most cakes do not contain eggs.
choice: The observation that the conclusion could be true.
hint: A counterexample makes every premise true and the conclusion false.
solution: The eggless cake with butter makes both premises true (it has no eggs, so the first premise holds trivially, and it is not vegan) and the conclusion false. A case where the conclusion is true shows nothing, and a conclusion that could be true does not make the argument valid.

@quiz mc
prompt: "All birds can fly. A kiwi is a bird. So a kiwi can fly." Which description is correct?
choice: Invalid, because kiwis cannot fly.
choice*: Valid but unsound, because the first premise is false.
choice: Sound, because the argument has a valid form.
choice: Invalid, because the first premise is false.
hint: Separate the link between premises and conclusion from the truth of the premises.
solution: If all birds could fly and a kiwi were a bird, a kiwi would fly, so the argument is valid. Since some birds, including kiwis, cannot fly, the first premise is false, so the argument is unsound.

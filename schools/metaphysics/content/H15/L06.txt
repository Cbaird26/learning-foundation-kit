@article
"It will rain or it won't." Nobody needs a forecast to accept that. "It will rain and it won't" is just as clearly wrong. But "It will rain" depends on the weather. A truth table sorts every formula into these three kinds by checking every possible way the world could be.

### The connectives as functions

Each connective is a function from the truth values of its parts to a truth value. T means true, F means false.

| $p$ | $q$ | $\neg p$ | $p \wedge q$ | $p \vee q$ | $p \to q$ | $p \leftrightarrow q$ |
|---|---|---|---|---|---|---|
| T | T | F | T | T | T | T |
| T | F | F | F | T | F | F |
| F | T | T | F | T | T | F |
| F | F | T | F | F | T | T |

Two entries deserve attention. The conditional $p \to q$ is false in exactly one case: true antecedent, false consequent. It is true whenever the antecedent is false (a promise is not broken if the condition never arises), and this **material conditional** is the only reading of "if" that truth tables use. And the biconditional is true when both parts have the same truth value.

### Building a table

1. List the sentence letters. With $n$ letters there are $2^n$ rows: 2 letters give 4 rows, 3 give 8, 4 give 16.
2. Use the standard order: the first letter's column starts with all T's in the first half and all F's in the second; each later column alternates in smaller blocks, and the last letter alternates T, F, T, F. For two letters the rows are TT, TF, FT, FF.
3. Work from the inside out. Add a column for each subformula, ending with a **main column** for the main connective.

### Three kinds of formula

- A **tautology** is true on every row: $p \vee \neg p$.
- A **contradiction** is false on every row: $p \wedge \neg p$.
- A **contingency** is true on some rows and false on others: $p \wedge q$.

Two formulas are **logically equivalent** if their main columns are identical, row by row. For example, $p \to q$ and $\neg p \vee q$ both have the column T, F, T, T. A formula is a tautology exactly when its negation is a contradiction.

### Why it matters

Tautologies are true in virtue of logical form alone: they say nothing about the world, which is why they cannot be refuted by any observation. Contradictions can never be true. Contingent formulas are the ones whose truth depends on how things are, so these are the only ones that science, news and everyday talk can usefully assert.

@example
title: A contingency
problem: Classify $(p \vee q) \to \neg p$ with a truth table.
step: Two letters give 4 rows, in the order TT, TF, FT, FF. Compute $p \vee q$: T, T, T, F, and $\neg p$: F, F, T, T.
step: Now the conditional with antecedent $p \vee q$ and consequent $\neg p$. Row TT: T $\to$ F is F. Row TF: T $\to$ F is F. Row FT: T $\to$ T is T. Row FF: F $\to$ T is T.
step: The main column is F, F, T, T: true on some rows and false on others.
answer: Contingency; the main column is F, F, T, T.

@example
title: A tautology
problem: Show that $p \to (q \to p)$ is a tautology.
step: Compute the inner conditional $q \to p$ on the rows TT, TF, FT, FF: T, T, F, T.
step: Now $p \to (q \to p)$. Rows TT and TF: $p$ is true and $q \to p$ is T, so T. Row FT: $p$ is false, so the conditional is T. Row FF: $p$ is false, so T.
step: The main column is T, T, T, T, so the formula is true on every row.
answer: Tautology; the main column is T, T, T, T.

@mistakes
- Treating a conditional with a false antecedent as false. $p \to q$ is true whenever $p$ is false.
- Using the wrong number of rows, or listing the rows in a different order from the column you compare against. $n$ letters give exactly $2^n$ rows.
- Calling a formula a tautology after checking only the rows you tried. A tautology must be true on every row.
- Confusing a contradiction with a contingency: a contingency is true on at least one row, a contradiction on none.

answer: FTTF
check: tt_column(lambda p, q: iff(p, not q))
hint: $\neg q$ is F, T, F, T. A biconditional is true when both sides match.
solution: On TT, $p$ is T and $\neg q$ is F: they differ, so F. On TF: T and T, so T. On FT: F and F, so T. On FF: F and T, so F. The column is F, T, T, F.

answer: TTTFFFFF

solution: On the four rows where $p$ is true (TTT, TTF, TFT, TFF), the value equals $q \vee r$: T, T, T, F. On the four rows where $p$ is false, the conjunction is false. The column is TTTFFFFF.

@quiz num
prompt: On how many of the eight rows of the truth table is $(p \to q) \wedge (q \to r)$ true?
answer: 4
unit: rows
check: count_models(lambda p, q, r: implies(p, q) and implies(q, r))
hint: List the rows where $p \to q$ is true, then keep those where $q \to r$ is also true.
solution: The rows are TTT (T), TTF (F, since $q \to r$ fails), TFT (F), TFF (F), FTT (T), FTF (F), FFT (T), FFF (T). The formula is true on 4 rows: TTT, FTT, FFT and FFF.

@quiz mc
prompt: Which formula is a contradiction?
choice*: $(p \to q) \wedge p \wedge \neg q$
choice: $(p \vee q) \wedge \neg p$
choice: $p \to \neg p$
choice: $\neg p \vee q$
hint: A contradiction is false on every row. Check whether the parts can all be true together.
solution: If $p$ and $\neg q$ are true then $p \to q$ is false, so the three conjuncts can never all be true. The other three are each true on some row: for example $(p \vee q) \wedge \neg p$ is true when $p$ is false and $q$ is true.

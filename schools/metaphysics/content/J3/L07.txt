@article
A **function** is a rule that assigns to each **input** exactly one **output**. A vending machine is a good model: press one button and you get one item. The set of allowed inputs is the **domain** and the set of outputs is the **range**.

### Function or not?

A relation is a function if no input is paired with two different outputs. Different inputs **may** share an output. The pairs $(1, 2), (2, 5), (3, 2)$ form a function: the output $2$ is repeated, but each input has one output. The pairs $(1, 2), (1, 5)$ do **not**: the input $1$ gives two outputs.

On a graph, use the **vertical line test**: if any vertical line crosses the graph more than once, it is not a function.

### Function notation

We write $f(x)$ for the output of $f$ at input $x$. If $f(x) = 2x^2 - 5x + 1$, then $f(3) = 2(9) - 15 + 1 = 4$. Here $f(3)$ means "substitute $3$ for $x$"; it does **not** mean $f$ times $3$.

### Three views of one function

The same function can be shown as a **rule** (an equation), a **table** or a **graph**.

| $x$ | $0$ | $1$ | $2$ | $3$ |
|---|---|---|---|---|
| $y$ | $5$ | $8$ | $11$ | $14$ |

The table adds $3$ to $y$ each time $x$ goes up $1$, so the rate of change is constant ($3$) and the function is **linear**: $y = 3x + 5$. A function whose rate of change varies, such as $y = x^2$, is **nonlinear**; its graph is curved.

To **describe** a function, give its rule, say what the slope (rate of change) and the starting value (value at $x = 0$) are, and say whether it is increasing or decreasing and linear or nonlinear.

### Comparing functions

To compare two functions given in different forms, compute the same features for each. For a linear function the rate of change is the slope. If Function A is $y = 4x - 3$ and Function B is a line through $(0, 1)$ and $(2, 7)$, then A has slope $4$ and B has slope $\frac{7 - 1}{2 - 0} = 3$, so A is increasing faster, while B has the larger starting value ($1$ versus $-3$).

### Where functions go next

Functions are the language of all later algebra. Whenever you see "$y$ depends on $x$ in exactly one way", you are looking at a function.

@example
title: Evaluating and testing
problem: Let $f(x) = 2x^2 - 5x + 1$. Find $f(3)$, and decide whether the pairs $(0, 4), (1, 6), (2, 4)$ form a function.
step: Substitute $3$ for $x$: $f(3) = 2(3)^2 - 5(3) + 1$.
step: Compute: $2(9) - 15 + 1 = 18 - 15 + 1 = 4$.
step: Look at the inputs of the pairs: $0$, $1$ and $2$. Each appears once, so each input has exactly one output.
step: The output $4$ appears twice, but that is allowed. The pairs form a function.

@mistakes
- Saying a relation is not a function because an **output** repeats; only a repeated **input** with different outputs breaks the rule.
- Reading $f(3)$ as $f \cdot 3$.
- Squaring incorrectly: $(-2)^2 = 4$, but $-2^2$ means $-(2^2) = -4$.
- Calling a table linear without checking that the rate of change is the same in every step.

@practice num
prompt: Function A is $y = 4x - 3$. Function B is the line through $(0, 1)$ and $(2, 7)$. By how much does the rate of change of A exceed the rate of change of B?
answer: 1
check: 4 - (7 - 1) / (2 - 0)
hint: The rate of change of a linear function is its slope.
hint: A has slope $4$. Compute the slope of B from its two points.
solution: B has slope $\frac{7 - 1}{2 - 0} = 3$. A has slope $4$, so A exceeds B by $4 - 3 = 1$.

@practice self
prompt: A function has the table $x = -1, 0, 1, 2$ and $y = 4, 1, -2, -5$. Describe the function using a rule, the slope and starting value, and a short description of its graph.
hint: Find the rate of change between two table entries.
hint: Then use the entry at x = 0 as the starting value.
solution: The rate of change is $\frac{1 - 4}{0 - (-1)} = -3$ and $y = 1$ at $x = 0$, so the rule is $y = -3x + 1$. It is linear and decreasing: its graph is a straight line through $(0, 1)$ that falls $3$ units for each $1$ unit to the right. Check: at $x = 2$, $-3(2) + 1 = -5$.

rubric: Identifies the slope $-3$ and the starting value (intercept) $1$ with their meaning.
rubric: Says the function is linear and decreasing and describes a graph through $(0, 1)$ that slopes downward.
rubric: Verifies the rule against at least one other table entry.

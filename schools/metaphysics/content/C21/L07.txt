@article
To show that a formula is *valid*, you prove it (Lesson 6). To show that it is *not valid*, you build a countermodel: a model and a world where it is false. There is a method, and it makes countermodel-building far more reliable than guessing.

### Working backwards

Suppose the formula is a conditional $A \to B$. It is false at $w$ exactly when $A$ is true and $B$ false at $w$. Write down what must hold at $w$, and then keep expanding, using these rules:

| requirement at a world $w$ | what to do |
|---|---|
| $\neg\Box B$ (or $\Diamond\neg B$) | add a new world $v$ with $wRv$ and make $\neg B$ hold at $v$ |
| $\Diamond B$ | add a new world $v$ with $wRv$ and make $B$ hold at $v$ |
| $\Box B$ | $B$ must hold at *every* successor of $w$, existing or added later |
| $\neg\Diamond B$ | $\neg B$ must hold at every successor of $w$ |
| a letter or its negation | fix it in the valuation at $w$ |

Stop when every requirement is met and no requirement is contradictory (for instance $P$ and $\neg P$ at the same world). If a contradiction appears in every branch, the formula is valid. If you are working in a system such as T or S4, the frame must also satisfy the frame condition, so add the loops or the arrows it needs, and check that the new arrows create no new requirements you have not met: in T, for instance, $\Box B$ at $w$ now forces $B$ at $w$ itself.

### The finite model property

How big can a minimal countermodel be? The answer is a theorem. A logic has the **finite model property** (FMP) if every formula that is not a theorem fails in some model on a finite frame for the logic. K, T, S4 and S5 all have the FMP. The standard proof uses **filtration**. Let $\Sigma$ be the set of subformulas of the formula $A$ and let $n = |\Sigma|$. Starting from any countermodel, merge worlds that agree on every formula in $\Sigma$. Since a world's behavior on $\Sigma$ is a choice of true or false for $n$ formulas, there are at most $2^n$ merged worlds, and one can show that the merged model still falsifies $A$ and still belongs to the frame class (the details differ between K, T, S4 and S5; see the reading). So:

> If $A$ is not a theorem of K, T, S4 or S5, then $A$ is false at a world of a model with at most $2^n$ worlds on a frame for that system, where $n$ is the number of subformulas of $A$.

For K there is a further fact: since $\Box$ and $\Diamond$ look only one step ahead, a formula of modal depth $d$ can be refuted in a model in which every world is at most $d$ steps from the root.

### Decidability

The FMP gives an algorithm: to test $A$, check every frame for the system with at most $2^n$ worlds and every valuation. If $A$ is true everywhere, it is valid. This idea gives an argument that the systems are decidable:

| P1 | K is finitely axiomatizable. |
| P2 | K has the finite model property. |
| P3 | A finitely axiomatizable logic with the finite model property is decidable (Harrop's theorem). |
| C | K is decidable: some algorithm decides, for every formula, whether it is a theorem of K. |

The argument is valid, and all three premises are established results. The same argument works for T, S4 and S5. Two cautions. First, "decidable" is not "feasible": deciding satisfiability for K, T and S4 is PSPACE-complete, and for S5 it is NP-complete (a result of Ladner). Second, the FMP is not automatic: not every modal logic has it, so the result depends on the particular systems. For the metaphysician, the upshot is that questions about what follows from what in these modal systems are *mechanical*; the philosophical work lies in choosing the system and the premises.

### Programming a countermodel search

A **countermodel search** enumerates frames and valuations in order of size. For `n` worlds there are $2^{n^2}$ relations, so searches are feasible for up to three or four worlds. A frame condition can be passed in as a function that accepts or rejects each relation, which turns the same search into a test for T, S4 or S5 formulas. Code the search so that it tries one world, then two, and so on: the first model found is then a smallest one.

@example
title: A countermodel by working backwards
problem: Show that $(\Box P \to \Box Q) \to \Box(P \to Q)$ is not valid.
step: To make the conditional false at $w$, we need $\Box P \to \Box Q$ true at $w$ and $\Box(P \to Q)$ false at $w$.
step: $\Box(P \to Q)$ false requires a successor $v$ of $w$ where $P$ is true and $Q$ false. Add it.
step: $\Box P \to \Box Q$ true: the easiest way is to make $\Box P$ false, which needs a successor of $w$ where $P$ is false. Add a second successor $u$, with $P$ false there.
step: Final model: $W = \{w, u, v\}$, $R = \{(w, u), (w, v)\}$, $P$ true at $v$ only, $Q$ true nowhere. At $w$: $\Box P$ is false (because of $u$), so $\Box P \to \Box Q$ is true; $\Box(P \to Q)$ is false (because of $v$); so the whole formula is false.
answer: The countermodel above has three worlds; the formula is not valid.

@example
title: A countermodel in S5
problem: Show that $(\Diamond P \wedge \Diamond Q) \to \Diamond(P \wedge Q)$ is not a theorem of S5, and say how many worlds are needed.
step: S5 is sound for equivalence frames, so we need an equivalence frame with a failing world. We want $\Diamond P$ and $\Diamond Q$ true and $\Diamond(P \wedge Q)$ false.
step: $\Diamond(P \wedge Q)$ false means that no accessible world makes both true. $\Diamond P$ needs a $P$-world and $\Diamond Q$ a $Q$-world, so they must be different worlds.
step: Take $W = \{1, 2\}$ with universal accessibility $R = \{(1,1), (1,2), (2,1), (2,2)\}$, $P$ true at 1 only, and $Q$ true at 2 only. At world 1: $\Diamond P$ (via 1) and $\Diamond Q$ (via 2) are true, and $P \wedge Q$ holds nowhere, so $\Diamond(P \wedge Q)$ is false.
step: One world is not enough: with a single world, $P$ and $Q$ would be true there, or one of $\Diamond P$, $\Diamond Q$ would fail. So two is the minimum.
answer: The two-world universal model above is a countermodel; two worlds are needed.

@mistakes
- Satisfying the failing formula at the wrong world: the countermodel needs a world where the whole formula is false, not just one part.
- Forgetting a requirement that appears later: after adding an arrow, every $\Box$ requirement at the source world applies to the new target.
- Checking a countermodel for K when the system is T or S4: the frame must satisfy the frame condition (reflexive, transitive, ...).
- Reading the finite model property as "every model is finite": it says that every non-theorem has a finite countermodel.

```python
from itertools import product


def holds(model, w, f):
    W, R, V = model
    op = f[0]
    if op == 'atom':
        return f[1] in V[w]
    if op == 'not':
        return not holds(model, w, f[1])
    if op == 'and':
        return holds(model, w, f[1]) and holds(model, w, f[2])
    if op == 'or':
        return holds(model, w, f[1]) or holds(model, w, f[2])
    if op == 'imp':
        return (not holds(model, w, f[1])) or holds(model, w, f[2])
    succ = [v for v in W if (w, v) in R]
    if op == 'box':
        return all(holds(model, v, f[1]) for v in succ)
    return any(holds(model, v, f[1]) for v in succ)


def find_countermodel(f, letters, max_worlds, frame_ok=None):
    """Smallest-first search for a model that falsifies f somewhere."""
    for n in range(1, max_worlds + 1):
        worlds = list(range(n))
        pairs = [(a, b) for a in worlds for b in worlds]
        slots = [(w, p) for w in worlds for p in letters]
        for rbits in product([False, True], repeat=len(pairs)):
            R = {pair for pair, b in zip(pairs, rbits) if b}
            if frame_ok is not None and not frame_ok(set(worlds), R):
                continue
            for vbits in product([False, True], repeat=len(slots)):
                V = {w: set() for w in worlds}
                for (w, p), b in zip(slots, vbits):
                    if b:
                        V[w].add(p)
                model = (set(worlds), R, V)
                for w in worlds:
                    if not holds(model, w, f):
                        return model, w
    return None
```
hint: Loop over `n`, and inside it use `product([False, True], repeat=...)` twice: once for the choice of arrows and once for the valuation.
hint: Skip a relation as soon as `frame_ok` rejects it, and return the first failing world you find; return `None` only after every size has been tried.
solution: Loop over sizes in increasing order, over every subset of the pairs of worlds as the relation, and over every valuation. Test `frame_ok` before the valuations to save work, then check the formula at every world and return as soon as one fails. The search for 4 on reflexive frames shows the interaction of the two ideas: no two-world reflexive frame is a counterexample, because all reflexive relations on two worlds are transitive, but a three-world one exists.

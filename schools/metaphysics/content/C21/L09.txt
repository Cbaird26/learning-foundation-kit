@article
"If Ana had dropped the glass, it would have broken." Ana did not drop it, so the antecedent is false. Is the sentence true? What makes it so? Counterfactual conditionals matter to metaphysics because analyses of causation, dispositions, laws and essence lean on them: a glass is fragile if it *would* break *if* struck. Their logic is not the logic of the material conditional.

### Why not the material conditional

Write $A \mathbin{\Box\!\!\to} C$ for "if $A$ were the case, $C$ would be the case". Here is an argument that this is not the material conditional $A \to C$:

| P1 | If $\Box\!\!\to$ were the material conditional, then both "if Ana had dropped the glass it would have broken" and "if Ana had dropped the glass it would not have broken" would be true whenever Ana did not drop the glass. |
| P2 | Ana did not drop the glass. |
| P3 | These two counterfactuals are not both true. |
| C | $\Box\!\!\to$ is not the material conditional. |

The argument is valid: from P1 and P2, if $\Box\!\!\to$ were material the two counterfactuals would both be true, contradicting P3. All premises are hard to deny, though one may ask whether P3 is correct when the antecedent is impossible. The **strict conditional** $\Box(A \to C)$ fares no better: it makes "if I had struck the match it would have lit" false whenever some possible situation (a wet match, no oxygen) strikes it without lighting.

### The Lewis-Stalnaker semantics

The idea of Robert Stalnaker (1968) and David Lewis (1973) is that a counterfactual is true when $C$ holds at the **closest** worlds where $A$ holds. A **similarity model** is $M = (W, V, \{\leq_w\}_{w \in W})$: worlds, a valuation, and for each world $w$ a **total preorder** $\leq_w$ of the worlds by closeness to $w$ (reflexive, transitive and any two worlds comparable; ties allowed). We assume **strong centering**: $w$ is strictly closer to itself than any other world is. Lewis's truth condition:

> $A \mathbin{\Box\!\!\to} C$ is true at $w$ iff either there are no $A$-worlds (the counterfactual is **vacuously true**), or some $A \wedge C$-world is strictly closer to $w$ than every $A \wedge \neg C$-world.

In a finite model this says: **$C$ is true at every closest $A$-world**. The **might-counterfactual** $A \mathbin{\Diamond\!\!\to} C$ abbreviates $\neg(A \mathbin{\Box\!\!\to} \neg C)$: $C$ is true at *some* closest $A$-world (and it is false when there are no $A$-worlds). The ordering is not given by logic; it depends on context and on what we hold fixed.

A concrete model: worlds $w$ (actual: the match is not struck and is dry), $a$ (struck, dry, lit) and $b$ (struck, wet, not lit). Closeness to $w$:

| world | distance from $w$ | $S$ (struck) | $W$ (wet) | $L$ (lit) |
|---|---|---|---|---|
| $w$ | 0 | false | false | false |
| $a$ | 1 | true | false | true |
| $b$ | 2 | true | true | false |

The closest $S$-world is $a$, where the match lights, so $S \mathbin{\Box\!\!\to} L$ is true at $w$. The closest $S \wedge W$-world is $b$, where it does not light, so $(S \wedge W) \mathbin{\Box\!\!\to} \neg L$ is true as well. Adding "wet" to the antecedent has changed the verdict.

### Stalnaker versus Lewis

**Stalnaker** assumes a unique closest $A$-world for each $A$ (no ties), so $A \mathbin{\Box\!\!\to} C$ is true iff $C$ holds there. Then **conditional excluded middle**, $(A \mathbin{\Box\!\!\to} C) \vee (A \mathbin{\Box\!\!\to} \neg C)$, is valid. **Lewis** allows ties and rejects conditional excluded middle: if two equally close $A$-worlds disagree about $C$, both $A \mathbin{\Box\!\!\to} C$ and $A \mathbin{\Box\!\!\to} \neg C$ are false, while both might-counterfactuals are true. Lewis's standard example, going back to Quine, is Bizet and Verdi: if they had been compatriots, would Bizet have been Italian or Verdi French? Lewis says that neither counterfactual is true. Stalnaker's reply is that there is a fact we cannot know, or that it is indeterminate which closest world is selected (a supervaluationist treatment).

### The logic

With strong centering these hold: $A \mathbin{\Box\!\!\to} A$; **modus ponens** ($A$ and $A \mathbin{\Box\!\!\to} C$ together yield $C$, since $w$ itself is the closest $A$-world when $A$ holds there); and $A \wedge C$ yields $A \mathbin{\Box\!\!\to} C$. These fail: **antecedent strengthening** (from $A \mathbin{\Box\!\!\to} C$ infer $(A \wedge B) \mathbin{\Box\!\!\to} C$), **transitivity** (from $A \mathbin{\Box\!\!\to} B$ and $B \mathbin{\Box\!\!\to} C$ infer $A \mathbin{\Box\!\!\to} C$) and **contraposition** (from $A \mathbin{\Box\!\!\to} C$ infer $\neg C \mathbin{\Box\!\!\to} \neg A$). The match model refutes strengthening, as shown above.

### Programming it

Represent a similarity model as `(W, V, rank)`: `W` a set of worlds, `V` a dictionary from worlds to sets of letters, and `rank[w][v]` a number giving how far `v` is from `w` (smaller means closer; equal numbers mean ties). Formulas for the antecedent and consequent are nested tuples built from `('atom', 'P')`, `('not', f)`, `('and', f, g)` and `('or', f, g)`. To evaluate $A \mathbin{\Box\!\!\to} C$ at `w`: collect the $A$-worlds, return `True` if there are none, find the smallest rank among them, and check $C$ at all the $A$-worlds with that rank.

@example
title: Evaluating counterfactuals in a model with ties
problem: The world $w$ is actual, with $P$ and $Q$ false. The worlds $x$ and $y$ are both at distance 1 from $w$; $P$ is true at both, $Q$ is true at $y$ only. Evaluate $P \mathbin{\Box\!\!\to} Q$, $P \mathbin{\Box\!\!\to} \neg Q$, $P \mathbin{\Diamond\!\!\to} Q$ and $(P \wedge \neg P) \mathbin{\Box\!\!\to} Q$ at $w$.
step: The $P$-worlds are $x$ and $y$, both at distance 1, so both are closest.
step: $P \mathbin{\Box\!\!\to} Q$ needs $Q$ at both: it fails at $x$. False.
step: $P \mathbin{\Box\!\!\to} \neg Q$ needs $\neg Q$ at both: it fails at $y$. False. So conditional excluded middle fails in this model, as Lewis allows.
step: $P \mathbin{\Diamond\!\!\to} Q$ is $\neg(P \mathbin{\Box\!\!\to} \neg Q)$, true because $Q$ holds at the closest world $y$.
step: $P \wedge \neg P$ is true at no world, so the counterfactual is vacuously true.
answer: False, false, true, true.

@example
title: Antecedent strengthening fails
problem: Using the match model of the article, show that $S \mathbin{\Box\!\!\to} L$ does not entail $(S \wedge W) \mathbin{\Box\!\!\to} L$.
step: In the model, the closest $S$-world to $w$ is $a$ (distance 1), and the match is lit there. So $S \mathbin{\Box\!\!\to} L$ is true at $w$.
step: The $S \wedge W$-worlds are those where the match is struck and wet; only $b$ qualifies, at distance 2. The match is not lit at $b$.
step: So $(S \wedge W) \mathbin{\Box\!\!\to} L$ is false at $w$, while $S \mathbin{\Box\!\!\to} L$ is true.
step: The premise is true and the conclusion false at $w$: antecedent strengthening is not valid for counterfactuals. A strict conditional would validate it, which is one more reason the counterfactual is not strict.
answer: The match model is a countermodel: adding the antecedent $W$ moves us to a farther world.

@mistakes
- Treating a counterfactual with a false antecedent as true automatically (the material reading): it is true only if the closest antecedent-worlds make the consequent true.
- Applying antecedent strengthening, transitivity or contraposition to counterfactuals, as if they were strict or material conditionals.
- Forgetting the vacuous case: if there are no $A$-worlds, $A \mathbin{\Box\!\!\to} C$ is true for every $C$ (and $A \mathbin{\Diamond\!\!\to} C$ is false).
- Ignoring ties: with two equally close $A$-worlds, you must check $C$ at both for the would-conditional, and at one of them for the might-conditional.

def holds_p(V, v, f):
    op = f[0]
    if op == 'atom':
        return f[1] in V[v]
    if op == 'not':
        return not holds_p(V, v, f[1])
    if op == 'and':
        return holds_p(V, v, f[1]) and holds_p(V, v, f[2])
    return holds_p(V, v, f[1]) or holds_p(V, v, f[2])


def would(model, w, A, C):
    """Lewis truth condition for A []-> C at w (finite models)."""
    W, V, rank = model
    a_worlds = [v for v in W if holds_p(V, v, A)]
    if not a_worlds:
        return True
    nearest = min(rank[w][v] for v in a_worlds)
    return all(holds_p(V, v, C) for v in a_worlds
               if rank[w][v] == nearest)
```
hint: First list the worlds where `A` is true; if the list is empty, the counterfactual is vacuously true.
hint: Find the smallest `rank[w][v]` among the `A`-worlds, and use `all(...)` over exactly the `A`-worlds with that rank.
solution: The `A`-worlds are those where `holds_p` says `A` is true. If there are none, return `True`. Otherwise take the minimum distance from `w` among them and require `C` at every `A`-world at that distance; ties are handled automatically by using `all`. Taking one arbitrary closest world instead would give the wrong answer on the tie model, and ignoring `w` itself as a candidate would fail the centering test.

    op = f[0]
    if op == 'atom':
        return f[1] in V[v]
    if op == 'not':
        return not holds_p(V, v, f[1])
    if op == 'and':
        return holds_p(V, v, f[1]) and holds_p(V, v, f[2])
    return holds_p(V, v, f[1]) or holds_p(V, v, f[2])


def would(model, w, A, C):
    W, V, rank = model
    a_worlds = [v for v in W if holds_p(V, v, A)]
    if not a_worlds:
        return True
    nearest = min(rank[w][v] for v in a_worlds)
    return all(holds_p(V, v, C) for v in a_worlds
               if rank[w][v] == nearest)


def might(model, w, A, C):
    """True iff C holds at some closest A-world (false if no A-world)."""
    W, V, rank = model
    a_worlds = [v for v in W if holds_p(V, v, A)]
    if not a_worlds:
        return False
    nearest = min(rank[w][v] for v in a_worlds)
    return any(holds_p(V, v, C) for v in a_worlds
               if rank[w][v] == nearest)
```
hint: A might-counterfactual is the dual of the would-counterfactual: use `any` where `would` uses `all`.
hint: Remember the vacuous case: with no `A`-worlds, `would` is true but `might` is false.
solution: Collect the `A`-worlds, return `False` if there are none, find the nearest rank, and use `any` instead of `all` over the nearest `A`-worlds. Equivalently, `might` is `not would(model, w, A, ('not', C))`, since with at least one `A`-world "not all closest worlds satisfy `not C`" means that some closest world satisfies `C`.

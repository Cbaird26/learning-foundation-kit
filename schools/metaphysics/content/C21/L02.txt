@article
Lesson 1 left a question open: if $\Box$ has no truth table, what makes $\Box P$ true? The answer, due in its mature form to Saul Kripke and developed in the same years by Jaakko Hintikka, Stig Kanger and others, is that $\Box P$ is true when $P$ holds at every **world** that is possible *from the point of view of* the world we are at.

### Models

A **Kripke model** is a triple $M = (W, R, V)$:

- $W$ is a non-empty set of **worlds** (points, situations, states);
- $R \subseteq W \times W$ is the **accessibility relation**; read $wRv$ as "$v$ is accessible from $w$", or "$v$ is possible relative to $w$";
- $V$ assigns to each sentence letter the set of worlds where it is true.

The pair $(W, R)$ is the **frame** of the model. Truth at a world is defined by recursion on the formula, written $M, w \vDash A$:

- $M, w \vDash P$ iff $w \in V(P)$, and never $M, w \vDash \bot$;
- the connectives behave classically at $w$: for example $M, w \vDash A \to B$ iff $M, w \nvDash A$ or $M, w \vDash B$;
- $M, w \vDash \Box A$ iff $M, v \vDash A$ for **every** $v$ with $wRv$;
- $M, w \vDash \Diamond A$ iff $M, v \vDash A$ for **some** $v$ with $wRv$.

$\Box$ and $\Diamond$ are therefore a universal and an existential quantifier over the accessible worlds, which is why duality holds. A formula is **true in the model** when it is true at every world of $W$.

### An example

Here is a model with three worlds. The accessibility relation is $\{(w_1, w_2), (w_1, w_3), (w_2, w_3)\}$, so $w_3$ sees no world.

| world | sees | true letters |
|---|---|---|
| $w_1$ | $w_2, w_3$ | none |
| $w_2$ | $w_3$ | $P$ |
| $w_3$ | nothing | $P, Q$ |

At $w_1$: $\Box P$ is true (both $w_2$ and $w_3$ make $P$ true), $\Diamond Q$ is true (via $w_3$), and $\Box Q$ is false ($w_2$ is a counterexample). At $w_3$ something odd happens: $\Box Q$ is true and also $\Box\neg Q$ is true, because there are no accessible worlds to be a counterexample, and $\Diamond Q$ is false. Necessity at a **dead end** is vacuous. In fact $\Box\bot$ is true exactly at the worlds with no accessible world, which is how modal logic expresses that a world is a dead end.

### From the semantics to an argument

Here is an argument about the relation between truth and necessity:

| P1 | $M, w \vDash \Box A$ iff $A$ is true at every world accessible from $w$. |
| P2 | $wRw$: the world $w$ is accessible from itself. |
| P3 | $M, w \vDash \Box A$. |
| C | $M, w \vDash A$. |

It is valid: by P3 and P1, $A$ is true at every accessible world, and by P2 that includes $w$. The weight rests on premise P2. For metaphysical necessity, P2 is natural: whatever is necessarily so is so. For the reading "it ought to be that", P2 is wrong: what ought to be the case is, sadly, sometimes not the case. So the logic of obligation must not assume that every world is accessible from itself. Lesson 4 shows that exactly this assumption is the axiom $\Box A \to A$.

### Models refute inferences

To show that an inference is invalid, you give a model and a world where the premises are true and the conclusion false. This is a **countermodel**. A model with only two or three worlds is usually enough, and finding one is mostly a matter of asking what the failure would have to look like.

### Programming it

In Python, represent a model as a tuple `(W, R, V)`: `W` a set of worlds, `R` a set of pairs `(w, v)`, and `V` a dictionary mapping each world to the set of letters true there. Represent formulas as nested tuples: `('atom', 'P')`, `('not', f)`, `('and', f, g)`, `('or', f, g)`, `('imp', f, g)`, `('box', f)` and `('dia', f)`. Truth at a world is a recursive function that follows the clauses above. The only subtle line is the one for `box`: it must quantify over the *successors* of `w`, not over all worlds and not over `w` itself.

@example
title: Evaluating formulas in a model
problem: In the three-world model of the article, evaluate $\Diamond\Box Q$ at $w_1$, $\Box\Diamond Q$ at $w_1$, and $\Diamond(P \wedge \neg Q)$ at $w_1$ and at $w_2$.
step: $\Diamond\Box Q$ at $w_1$: look at the successors $w_2$ and $w_3$. At $w_2$, the only successor is $w_3$ and $Q$ holds there, so $\Box Q$ is true at $w_2$. One successor suffices: true.
step: $\Box\Diamond Q$ at $w_1$: this needs $\Diamond Q$ at both $w_2$ and $w_3$. At $w_2$ it is true, but $w_3$ has no successors, so $\Diamond Q$ is false at $w_3$: false.
step: $\Diamond(P \wedge \neg Q)$ at $w_1$: at $w_2$, $P$ is true and $Q$ false, so $P \wedge \neg Q$ holds there: true. At $w_2$ itself the only successor is $w_3$, where $Q$ holds: false.
answer: $\Diamond\Box Q$ is true at $w_1$; $\Box\Diamond Q$ is false at $w_1$; $\Diamond(P \wedge \neg Q)$ is true at $w_1$ and false at $w_2$.

@example
title: Two invalid inferences refuted
problem: Show with countermodels that (a) $\Box(P \to Q)$ and $P$ do not entail $\Box Q$, and (b) $\Diamond P \wedge \Diamond Q$ does not entail $\Diamond(P \wedge Q)$, in the sense that a world can make the premises true and the conclusion false.
step: (a) Let $W = \{a, b\}$, $R = \{(a, b)\}$, with $P$ true at $a$ only and $Q$ true nowhere. At $a$, $P$ is true.
step: At $a$, $\Box(P \to Q)$ needs $P \to Q$ at $b$; $P$ is false at $b$, so the conditional is true there. Hence $\Box(P \to Q)$ is true at $a$.
step: But $\Box Q$ at $a$ needs $Q$ at $b$, and $Q$ is false there. So both premises are true and the conclusion false at $a$.
step: (b) Let $W = \{a, b, c\}$, $R = \{(a, b), (a, c)\}$, with $P$ true at $b$ only and $Q$ true at $c$ only. At $a$, $\Diamond P$ is true (via $b$) and $\Diamond Q$ is true (via $c$).
step: But no single accessible world makes $P \wedge Q$ true, so $\Diamond(P \wedge Q)$ is false at $a$. The two possibilities are realized in different worlds.
answer: Both inferences are invalid; the models above are countermodels.

@mistakes
- Evaluating $\Box A$ at the current world, or at all worlds, instead of only at the accessible ones.
- Thinking that $\Box A$ is false at a world with no accessible worlds: it is vacuously true, and $\Diamond A$ is false.
- Confusing "true at a world" with "true in the model" (true at all worlds): $P$ can be true at $w$ and false elsewhere.
- Assuming that a world sees itself. Accessibility is whatever relation the model says; reflexivity is an extra condition.

model:
```python
def holds(model, w, f):
    """Truth of the formula f at world w of a Kripke model."""
    W, R, V = model
    op = f[0]
    if op == 'atom':
        return f[1] in V[w]
    if op == 'not':
        return not holds(model, w, f[1])
    if op == 'and':
        return holds(model, w, f[1]) and holds(model, w, f[2])
    if op == 'or':
        return holds(model, w, f[1]) or holds(model, w, f[2])
    if op == 'imp':
        return (not holds(model, w, f[1])) or holds(model, w, f[2])
    succ = [v for v in W if (w, v) in R]
    if op == 'box':
        return all(holds(model, v, f[1]) for v in succ)
    if op == 'dia':
        return any(holds(model, v, f[1]) for v in succ)
    raise ValueError(op)
```
hint: Handle each operator with its own `if`, and call `holds` recursively on the parts.
hint: For `box` and `dia`, first collect the successors `[v for v in W if (w, v) in R]`, then use `all` or `any` over them.
solution: Atoms look up the valuation, the Boolean connectives recurse at the same world, and the modal operators recurse at the successors of `w`. Python's `all` of an empty list is `True` and `any` of an empty list is `False`, which gives exactly the right behavior at a dead end. Evaluating the formula at `w` itself instead of at the successors is the classic mistake, and the first test catches it.

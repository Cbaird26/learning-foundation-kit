@article
K assumes nothing about accessibility, so it proves very little. The interesting modal systems add axioms, and each axiom says something about how worlds see one another. The central fact of this lesson is that many axioms **correspond** to simple properties of the accessibility relation $R$: the axiom is valid on a frame exactly when the frame has the property. Metaphysicians can then ask which property metaphysical possibility has, instead of asking directly about the axiom.

### The conditions

A relation $R$ on a set $W$ of worlds is:

- **reflexive** if $wRw$ for every $w$;
- **serial** if every $w$ has some $v$ with $wRv$;
- **symmetric** if $wRv$ implies $vRw$;
- **transitive** if $wRv$ and $vRu$ imply $wRu$;
- **Euclidean** if $wRv$ and $wRu$ imply $vRu$ (two worlds both seen from one world see each other, and each sees itself).

| axiom | formula | name | frame condition |
|---|---|---|---|
| T | $\Box A \to A$ | reflexivity | reflexive |
| D | $\Box A \to \Diamond A$ | seriality | serial |
| B | $A \to \Box\Diamond A$ | symmetry | symmetric |
| 4 | $\Box A \to \Box\Box A$ | transitivity | transitive |
| 5 | $\Diamond A \to \Box\Diamond A$ | Euclideanness | Euclidean |

**Theorem.** For every frame $F = (W, R)$: $F \vDash \mathrm{T}$ iff $R$ is reflexive; $F \vDash \mathrm{D}$ iff serial; $F \vDash \mathrm{B}$ iff symmetric; $F \vDash 4$ iff transitive; $F \vDash 5$ iff Euclidean. (Here "$F \vDash$ axiom" means that every instance is valid on $F$; it is enough to use a single letter $P$ for $A$ in the proofs below.)

### Proofs

**T.** ($\Leftarrow$) If $R$ is reflexive and $\Box A$ is true at $w$, then, because $wRw$, $A$ is true at $w$. ($\Rightarrow$) Suppose $wRw$ fails. Make $P$ true at every world except $w$. Every successor of $w$ makes $P$ true, so $\Box P$ is true at $w$, but $P$ is false at $w$.

**D.** ($\Leftarrow$) If $w$ has a successor $v$ and $\Box A$ is true at $w$, then $A$ is true at $v$, so $\Diamond A$ is true at $w$. ($\Rightarrow$) If $w$ has no successor, then $\Box P$ is true at $w$ vacuously and $\Diamond P$ is false.

**4.** ($\Leftarrow$) Let $R$ be transitive, $\Box A$ true at $w$, and $wRv$, $vRu$. Then $wRu$, so $A$ is true at $u$. Hence $\Box A$ is true at $v$, and $\Box\Box A$ is true at $w$. ($\Rightarrow$) Suppose $wRv$ and $vRu$ but not $wRu$. Make $P$ true everywhere except at $u$. Every successor of $w$ differs from $u$, so $\Box P$ is true at $w$. But $u$ is a successor of the successor $v$, and $P$ is false at $u$, so $\Box\Box P$ is false at $w$.

**B.** ($\Leftarrow$) Let $R$ be symmetric, $A$ true at $w$, and $wRv$. Then $vRw$, so $\Diamond A$ is true at $v$. Hence $\Box\Diamond A$ is true at $w$. ($\Rightarrow$) Suppose $wRv$ but not $vRw$. Make $P$ true at $w$ only. Then $P$ is true at $w$; but $\Diamond P$ is false at $v$, since the only $P$-world is $w$ and $v$ does not see it. So $\Box\Diamond P$ is false at $w$.

**5.** ($\Leftarrow$) Let $R$ be Euclidean and $\Diamond A$ true at $w$, witnessed by $u$ with $wRu$. For any $v$ with $wRv$, Euclideanness gives $vRu$, so $\Diamond A$ is true at $v$. Hence $\Box\Diamond A$ is true at $w$. ($\Rightarrow$) Suppose $wRv$, $wRu$ but not $vRu$. Make $P$ true at $u$ only. Then $\Diamond P$ is true at $w$ (via $u$), but $\Diamond P$ is false at $v$ (the only $P$-world is $u$), so $\Box\Diamond P$ is false at $w$. $\square$

### Combining conditions

Conditions interact. If $R$ is reflexive and Euclidean, then it is symmetric (from $wRv$ and $wRw$, Euclideanness gives $vRw$) and transitive (from $wRv$, $vRu$: symmetry gives $vRw$, and then $vRw$, $vRu$ give $wRu$). A reflexive, symmetric and transitive relation is an **equivalence relation**. These are the frames of S5, in Lesson 5.

Not every modal formula corresponds to a first-order condition in this way; Löb's axiom, important in provability logic, does not. But the five above do, and so does much of what metaphysicians use.

### Is possibility transitive?

Axiom 4 says that whatever is possibly possible is possible: $\Diamond\Diamond A \to \Diamond A$. Nathan Salmon, developing a puzzle raised by Hugh Chandler, argued against it for metaphysical possibility, using a table. Let $A_k$ say "the table is made from hunk $h_k$", where each hunk differs from the previous one in a tiny part, so that $h_0$ and the last hunk share no matter at all. For two steps:

| P1 | $A_0$: the table is made from hunk $h_0$. |
| P2 | $A_0 \to \Diamond A_1$: if the table is made from $h_0$, it could have been made from $h_1$. |
| P3 | $\Box(A_1 \to \Diamond A_2)$: necessarily, if the table is made from $h_1$, it could have been made from $h_2$. |
| P4 | $\Diamond\Diamond A_2 \to \Diamond A_2$ (axiom 4). |
| C | $\Diamond A_2$: the table could have been made from $h_2$. |

The argument is valid: P1 and P2 give $\Diamond A_1$; some accessible world $v$ makes $A_1$ true, and P3 makes $A_1 \to \Diamond A_2$ true at $v$, so $\Diamond A_2$ holds at $v$ and $\Diamond\Diamond A_2$ at the actual world; P4 detaches the conclusion. Repeating the pattern along a long enough chain gives that the table could have been made from entirely different matter, contradicting the plausible view that a thing's origin is essential to it. Replies deny P4 (metaphysical accessibility is not transitive, which is the point), deny the "small change" premises (their vagueness is the source of trouble), or accept the conclusion and reject strong origin essentialism. Notice that the argument is only as good as its weakest link, and that the formal result tells you exactly which condition on the frame is being used: transitivity.

@example
title: Finding the frame conditions
problem: Let $W = \{1, 2, 3\}$ and $R = \{(1, 2), (2, 2), (3, 2)\}$. Which of the properties reflexive, serial, symmetric, transitive and Euclidean does $R$ have, and which of T, D, B, 4 and 5 are therefore valid on the frame?
step: Reflexive: $(1, 1) \notin R$, so no. Serial: worlds 1, 2 and 3 each see world 2, so yes.
step: Symmetric: $(1, 2) \in R$ but $(2, 1) \notin R$, so no.
step: Transitive: the only chains are $(w, 2), (2, 2)$, and the conclusion $(w, 2)$ is in $R$ each time: yes.
step: Euclidean: each world has exactly one successor, 2, so the condition asks only for $(2, 2) \in R$: yes.
answer: $R$ is serial, transitive and Euclidean, but neither reflexive nor symmetric. So D, 4 and 5 are valid on the frame, and T and B are not.

@example
title: Proving that a condition is necessary
problem: Show that if $A \to \Box\Diamond A$ is valid on a frame $F$, then $F$ is symmetric.
step: Suppose $F$ is not symmetric: there are worlds $w, v$ with $wRv$ but not $vRw$.
step: Define the valuation on $F$ making $P$ true at $w$ and nowhere else.
step: Then $P$ is true at $w$. At $v$, a world with $\Diamond P$ needs a successor where $P$ is true, and the only such world is $w$, which $v$ does not see. So $\Diamond P$ is false at $v$.
step: Since $v$ is a successor of $w$ and $\Diamond P$ fails there, $\Box\Diamond P$ is false at $w$. So $P \to \Box\Diamond P$ fails at $w$ under this valuation, contradicting validity on $F$.
answer: Every frame on which B is valid is symmetric. The proof builds a valuation that exploits the missing arrow.

@mistakes
- Confusing validity on a frame with truth in a model: a frame condition guarantees the axiom under all valuations. A model on a non-reflexive frame may still make $\Box P \to P$ true everywhere.
- Mixing up symmetry and the Euclidean property: axiom B corresponds to symmetry, and axiom 5 to Euclideanness. Reflexive plus Euclidean gives symmetry, but Euclidean alone does not.
- Forgetting that the conditions also apply to $w$ and $v$ being the same world: Euclideanness gives $vRv$ whenever $wRv$.
- Claiming that T is valid on any serial frame: seriality is the weaker condition, corresponding to D. Reflexive frames are serial, but not the other way round.

hint: For the first direction, take $A$ true at $w$ and ask what $wRw$ gives. For the converse, suppose $wRw$ fails and make $P$ true at one world only.
solution: ($\Leftarrow$) Let the frame be reflexive, take any model on it and a world $w$ where $A$ is true. Since $wRw$ and $A$ is true at $w$, $\Diamond A$ is true at $w$. Let $P$ be true at $w$ and nowhere else. $P$ is true at $w$. A world seen from $w$ is different from $w$, because $wRw$ fails, so $P$ is false at every successor of $w$ and $\Diamond P$ is false at $w$. rubric: For the converse, constructs a valuation with $P$ true at exactly the world $w$ for which $wRw$ fails.

model:
```python
def frame_properties(W, R):
    """Names of the frame conditions satisfied by the frame (W, R)."""
    found = []
    if all((a, c) in R for (a, b) in R for (b2, c) in R if b == b2):
        found.append('transitive')
    if all((b, c) in R for (a, b) in R for (a2, c) in R if a == a2):
        found.append('euclidean')
    if all((b, a) in R for (a, b) in R):
        found.append('symmetric')
    if all((w, w) in R for w in W):
        found.append('reflexive')
    if all(any((w, v) in R for v in W) for w in W):
        found.append('serial')
    return sorted(found)
```
hint: Write one test per condition, each with `all(...)` over the pairs in `R` or the worlds in `W`.
hint: The Euclidean test: for all `(a, b)` and `(a2, c)` in `R` with `a == a2`, the pair `(b, c)` must be in `R`.
solution: Check each definition directly, collect the names of the conditions that hold, and sort. For the empty relation the conditions that quantify over pairs of `R` hold vacuously, while reflexivity and seriality quantify over worlds and fail.

```python
def axioms_valid(W, R):
    """Axioms among T, D, B, 4, 5 valid on the frame (W, R)."""
    reflexive = all((w, w) in R for w in W)
    serial = all(any((w, v) in R for v in W) for w in W)
    symmetric = all((b, a) in R for (a, b) in R)
    transitive = all((a, c) in R for (a, b) in R for (b2, c) in R
                     if b == b2)
    euclidean = all((b, c) in R for (a, b) in R for (a2, c) in R
                    if a == a2)
    found = []
    if reflexive:
        found.append('T')
    if serial:
        found.append('D')
    if symmetric:
        found.append('B')
    if transitive:
        found.append('4')
    if euclidean:
        found.append('5')
    return sorted(found)
```
hint: Compute the five frame properties first, then translate each into the name of its axiom.
solution: Each axiom is valid exactly when its frame condition holds, so compute the five conditions and report the matching axiom names, sorted. The one-world frame without accessibility shows that a frame can validate 4, 5 and B while failing T and D.

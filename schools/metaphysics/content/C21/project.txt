### Week by week

1. **The modal language.** $\Box$ and $\Diamond$; not truth-functional; duality $\Diamond A \leftrightarrow \neg\Box\neg A$; scope ($\Box(A \to B)$ is not $A \to \Box B$); modal depth.
2. **Kripke models.** $M = (W, R, V)$; $\Box A$ true at $w$ iff $A$ true at every $v$ with $wRv$; dead ends make every $\Box A$ true and every $\Diamond A$ false.
3. **Validity and K.** True at a world, in a model, valid on a frame, valid; K axiom and necessitation; K is sound and complete for all frames.
4. **Frame conditions.** T reflexive, D serial, B symmetric, 4 transitive, 5 Euclidean; proofs in both directions; reflexive plus Euclidean gives an equivalence relation.
5. **T, S4, S5.** Frame classes; strict hierarchy; collapse of iterated modalities; S5 as the logic of universal accessibility.
6. **Proofs.** PL, K, Nec, MP, RM, RE; strict subproofs; S5 proves B and 4.
7. **Countermodels.** Work backwards from the failure; finite model property, filtration bound $2^n$, decidability.
8. **Quantified modal logic.** Domains at worlds; BF holds iff domains decrease, CBF iff they increase; both on constant domains.
9. **Counterfactuals.** Closest worlds; vacuous truth; ties; no antecedent strengthening, transitivity or contraposition; Lewis versus Stalnaker.
10. **Tense and deontic logic.** $G, F, H, \mathsf{P}$; transitivity, density, no last moment; SDL is KD; Chisholm's paradox.
11. **Modal ontological argument.** Valid on symmetric frames, invalid in S4; the parody and the equivalence with $\Box M$ in S5; modal collapse.
12. **Necessitism and contingentism.** $\Box\forall x\,\Box E!x$ versus $\Diamond\exists x\,\Diamond\neg E!x$; the derivation from classical logic; free logic.

### Key arguments and distinctions

- Necessity of the consequence (valid) versus the scope fallacy (invalid).
- Salmon's table argument, which uses axiom 4; the argument for S5 from universal accessibility.
- The argument against the material conditional for counterfactuals.
- Truth in a model versus validity on a frame; a valid formalization versus true premises.

### Self-check

- Can you evaluate a nested formula at every world of a four-world model, with a dead end?
- Can you prove, in both directions, that B is valid exactly on symmetric frames?
- Can you give a countermodel for $\Box P \to \Box\Box P$ in T, and for $P \to \Box\Diamond P$ in S4?
- Can you derive $\Box P \to \Box\Box P$ in S5 from T and 5?
- Can you say which premise of each argument in the course a critic attacks?

### Common errors

- Evaluating $\Box A$ at the current world, or forgetting dead ends.
- Mixing up symmetry (B) with Euclideanness (5), or BF with CBF.
- Calling an argument invalid because its premises are false (validity is about form).
- Applying necessitation to a premise instead of a theorem.
- Applying antecedent strengthening to counterfactuals.

answer: 5

check: sum(1 for bits in product([0, 1], repeat=4) if (lambda R: all((a, c) in R for (a, b) in R for (b2, c) in R if b == b2) and all((b, a) in R for (a, b) in R))({p for p, x in zip([(1, 1), (1, 2), (2, 1), (2, 2)], bits) if x}))
hint: Use the frame correspondences: 4 is valid exactly on transitive frames and B exactly on symmetric frames.
hint: List the symmetric relations on two worlds (there are 8) and test each for transitivity.
solution: Both axioms are valid iff the relation is symmetric and transitive. The symmetric relations on $\{1, 2\}$ are the subsets that contain $(1,2)$ exactly when they contain $(2,1)$. Of those, the three that contain both $(1,2)$ and $(2,1)$ but lack a loop are not transitive (transitivity would force both $(1,1)$ and $(2,2)$), so only the full relation survives among the four that contain both. The remaining five are transitive: the empty relation, $\{(1,1)\}$, $\{(2,2)\}$, $\{(1,1), (2,2)\}$ and the full relation. So there are 5.

```python
from itertools import product


def holds(model, w, f):
    W, R, V = model
    op = f[0]
    if op == 'atom':
        return f[1] in V[w]
    if op == 'not':
        return not holds(model, w, f[1])
    if op == 'and':
        return holds(model, w, f[1]) and holds(model, w, f[2])
    if op == 'or':
        return holds(model, w, f[1]) or holds(model, w, f[2])
    if op == 'imp':
        return (not holds(model, w, f[1])) or holds(model, w, f[2])
    succ = [v for v in W if (w, v) in R]
    if op == 'box':
        return all(holds(model, v, f[1]) for v in succ)
    return any(holds(model, v, f[1]) for v in succ)


def valid_on_all_frames(f, letters, max_worlds, frame_ok=None):
    """True iff f holds everywhere on all admitted frames up to a size."""
    for n in range(1, max_worlds + 1):
        worlds = list(range(n))
        pairs = [(a, b) for a in worlds for b in worlds]
        slots = [(w, p) for w in worlds for p in letters]
        for rbits in product([False, True], repeat=len(pairs)):
            R = {pair for pair, b in zip(pairs, rbits) if b}
            if frame_ok is not None and not frame_ok(set(worlds), R):
                continue
            for vbits in product([False, True], repeat=len(slots)):
                V = {w: set() for w in worlds}
                for (w, p), b in zip(slots, vbits):
                    if b:
                        V[w].add(p)
                model = (set(worlds), R, V)
                if not all(holds(model, w, f) for w in worlds):
                    return False
    return True
```
hint: Enumerate the relations with `product([False, True], repeat=...)` over all pairs of worlds, skip those rejected by `frame_ok`, then enumerate valuations in the same way.
hint: Return `False` the first time the formula fails at some world of some model; return `True` only after every admitted frame and valuation has been checked.
solution: For each size $n$, loop over every relation on $n$ worlds, filter by the frame condition, loop over every valuation of the letters, and check the formula at every world. The tests combine the correspondences of Lessons 4 and 5: T and 5 and B are valid on their frame classes, T fails on arbitrary frames, and axiom 4 is valid on all reflexive frames of two worlds (every reflexive relation on two worlds is transitive) but fails on a reflexive frame of three worlds.

prompt: Consider the argument "P1: It is possible that Ana wins the lottery. P2: Necessarily, if Ana wins the lottery then she is rich. C: So it is possible that Ana is rich." (a) Formalize it with $W$ and $R$, write it in standard form and show that it is valid by an argument about Kripke models. (b) Show that the converse argument, from "possibly Ana is rich" and "necessarily, if she wins she is rich" to "possibly she wins", is invalid, by giving a countermodel and evaluating each formula. (c) Say what the validity in (a) does and does not show about whether Ana could be rich.
hint: For (a), take a world where P1 and P2 are true and look at the accessible world that witnesses P1. For (b), you need a world where $W$ is false at every accessible world.
solution: (a) P1: $\Diamond W$. P2: $\Box(W \to R)$. C: $\Diamond R$. Suppose P1 and P2 are true at $w$. By P1 there is $v$ with $wRv$ and $W$ true at $v$. By P2, $W \to R$ is true at $v$, so $R$ is true at $v$. So $\Diamond R$ is true at $w$. The argument is valid in K, with no assumption about the accessibility relation. (b) Take $W_0 = \{w, v\}$ (worlds), accessibility $\{(w, v)\}$, $R$ true at $v$ only and $W$ true nowhere. At $w$: $\Diamond R$ is true (via $v$); $\Box(W \to R)$ is true, because $W$ is false at $v$; but $\Diamond W$ is false, since no accessible world makes $W$ true. So both premises are true and the conclusion false at $w$, and the converse is invalid. (c) The validity in (a) shows only that the conclusion follows if the premises are true; whether Ana could be rich depends on whether it is possible for her to win and on whether winning would make her rich, which the logic leaves open.

@article
Lesson 2 evaluated formulas in one model at a time. Logic needs more: claims that hold *whatever* the model is. A formula can be true in a particular model by luck. Take a model in which $P$ happens to be true at every world: then $\Box P \to P$ is true at every world of that model, whether or not worlds see themselves. To separate luck from logic, we vary the valuation while keeping the frame fixed.

### Four levels of truth

Let $M = (W, R, V)$ be a model on the frame $F = (W, R)$.

| notion | holds when |
|---|---|
| $M, w \vDash A$ | $A$ is true at the world $w$ of $M$ |
| $M \vDash A$ | $A$ is true at every world of $M$ |
| $F \vDash A$ ($A$ is **valid on the frame** $F$) | $M \vDash A$ for every model $M$ on $F$, that is, for every valuation $V$ |
| $\vDash A$ ($A$ is **valid**) | $F \vDash A$ for every frame $F$ |

For a class $\mathcal{C}$ of frames, "valid on $\mathcal{C}$" means valid on every frame in $\mathcal{C}$. Each notion is stronger than the one above it. The key idea is the third row: validity on a frame says that the *structure* of the worlds and their accessibility guarantees $A$, however the facts are distributed.

### The distribution axiom and necessitation

**Theorem 1.** The formula $\Box(A \to B) \to (\Box A \to \Box B)$ is valid on every frame.

*Proof.* Take any model and any world $w$ at which $\Box(A \to B)$ and $\Box A$ are true. Let $v$ be any world with $wRv$. Then $A \to B$ and $A$ are true at $v$, so $B$ is true at $v$. Since $v$ was arbitrary, $\Box B$ is true at $w$. Hence the whole conditional is true at $w$. $\square$

This formula is called **K**, after Kripke. **Theorem 2** (necessitation). If $A$ is valid on a class of frames, then so is $\Box A$. *Proof.* Take any model on a frame of the class, and any world $w$. Every world $v$ is in a model on that frame, and $A$ is true at $v$ by validity, so in particular at every world accessible from $w$. So $\Box A$ is true at $w$. $\square$

Necessitation is a rule about *valid* formulas. It does not license $A \to \Box A$: a formula that is merely true at a world need not hold at its successors.

### The system K

The **system K** is the smallest set of formulas that (i) contains all instances of propositional tautologies, (ii) contains all instances of the axiom K, (iii) is closed under **modus ponens** (from $A$ and $A \to B$ infer $B$), and (iv) is closed under **necessitation** (from $A$ infer $\Box A$), where $\Diamond A$ abbreviates $\neg\Box\neg A$. A system with these features is called **normal**. We write $\mathrm{K} \vdash A$ when $A$ is in K.

**Soundness and completeness.** $\mathrm{K} \vdash A$ if and only if $A$ is valid on all frames. Soundness (the left-to-right direction) follows from Theorems 1 and 2 plus the fact that modus ponens preserves validity; completeness is proved with canonical models (see the reading). So K is exactly the logic of Kripke models with no restrictions.

Among the valid formulas of K:

- $\Box(A \wedge B) \leftrightarrow (\Box A \wedge \Box B)$ and $\Diamond(A \vee B) \leftrightarrow (\Diamond A \vee \Diamond B)$;
- $(\Box A \vee \Box B) \to \Box(A \vee B)$ and $\Diamond(A \wedge B) \to (\Diamond A \wedge \Diamond B)$, but **not** their converses (Lesson 2 gave countermodels);
- $\Box\top$ (with $\top$ for $\neg\bot$) and $\neg\Diamond\bot$.

Not valid in K: $\Box A \to A$, $\Box A \to \Box\Box A$, $A \to \Box\Diamond A$ and $\Diamond A \to \Box\Diamond A$. Lesson 4 shows that each of these is valid exactly on frames with a particular shape.

### Logical omniscience

Read $\Box A$ as "Ana knows that $A$", and let the accessible worlds be those compatible with what Ana knows. The semantics then has a surprising consequence.

| P1 | $M, w \vDash \Box A$ iff $A$ is true at every world $v$ with $wRv$ (the worlds compatible with what Ana knows). |
| P2 | If $A$ is valid, $A$ is true at every world of every model. |
| C | If $A$ is valid, then $\Box A$ is true at every world of every model: Ana knows every valid formula. |

The argument is valid, so the problem lies with the model of knowledge: real agents do not know every tautology of a hundred letters, and they do not know all the consequences of what they know (K and necessitation together give $\Box A \to \Box B$ whenever $A \to B$ is valid). This is the **problem of logical omniscience**. The usual replies change the semantics: add worlds that are logically impossible, or model what the agent is *aware* of as well as what is compatible with her knowledge. Or they say that the model describes an idealized agent, not a human being.

### What the code does

To test validity on a frame by program, run through every valuation of the letters on the frame's worlds and check that the formula is true at every world under each. With $n$ worlds and $k$ letters there are $2^{nk}$ valuations. For small frames that is a perfectly good decision procedure.

@example
title: Truth in a model versus validity on a frame
problem: Let the frame be $W = \{1, 2\}$ with $R = \{(1, 2), (2, 1)\}$. (a) Find a valuation making $\Box P \to P$ false at some world. (b) Show that in the model where $P$ is true at both worlds, $\Box P \to P$ is true at every world. What do (a) and (b) show?
step: (a) Make $P$ true at world 2 only. At world 1, the only successor is 2, where $P$ is true, so $\Box P$ is true at 1. But $P$ is false at 1.
step: So $\Box P \to P$ is false at world 1 under this valuation: the formula is **not valid on this frame**.
step: (b) If $P$ is true at both worlds, then $P$ is true at every world, so the consequent of the conditional is true everywhere and the conditional is true at both worlds. It is true in this model.
step: Truth in one model proves nothing about validity: (b) is a model of a non-valid formula. Validity requires truth in all models on the frame, and (a) is one where it fails.
answer: The formula is true in the model of (b) but not valid on the frame, because of the valuation in (a).

@example
title: Using the soundness of K
problem: Using the validity of K and necessitation, show that $\Box(P \wedge Q) \to \Box P$ is valid.
step: The formula $(P \wedge Q) \to P$ is a tautology, hence valid.
step: By necessitation (Theorem 2), $\Box((P \wedge Q) \to P)$ is valid.
step: Instantiating K with $A := P \wedge Q$ and $B := P$ gives that $\Box((P \wedge Q) \to P) \to (\Box(P \wedge Q) \to \Box P)$ is valid.
step: Modus ponens preserves validity, so $\Box(P \wedge Q) \to \Box P$ is valid.
answer: $\Box(P \wedge Q) \to \Box P$ is valid on all frames (and so a theorem of K).

@mistakes
- Treating truth in one model as validity: validity quantifies over all valuations on the frame (and, for logical validity, all frames).
- Reading necessitation as $A \to \Box A$: the rule applies only to formulas that are valid, not to formulas that are merely true.
- Assuming that K proves $\Box A \to A$: K assumes nothing about accessibility, so a world need not see itself.
- Forgetting that the converses of $\Box A \vee \Box B \to \Box(A \vee B)$ and of $\Diamond(A \wedge B) \to \Diamond A \wedge \Diamond B$ fail.

```python
from itertools import product


def holds(model, w, f):
    W, R, V = model
    op = f[0]
    if op == 'atom':
        return f[1] in V[w]
    if op == 'not':
        return not holds(model, w, f[1])
    if op == 'and':
        return holds(model, w, f[1]) and holds(model, w, f[2])
    if op == 'or':
        return holds(model, w, f[1]) or holds(model, w, f[2])
    if op == 'imp':
        return (not holds(model, w, f[1])) or holds(model, w, f[2])
    succ = [v for v in W if (w, v) in R]
    if op == 'box':
        return all(holds(model, v, f[1]) for v in succ)
    return any(holds(model, v, f[1]) for v in succ)


def valid_on_frame(W, R, f, letters):
    """True iff f holds at every world under every valuation on (W, R)."""
    worlds = sorted(W)
    slots = [(w, p) for w in worlds for p in letters]
    for bits in product([False, True], repeat=len(slots)):
        V = {w: set() for w in worlds}
        for (w, p), b in zip(slots, bits):
            if b:
                V[w].add(p)
        if not all(holds((W, R, V), w, f) for w in worlds):
            return False
    return True
```
hint: A valuation is a choice, for each pair (world, letter), of true or false; `product([False, True], repeat=...)` lists all choices.
hint: For each choice build `V`, then test `holds` at every world; return `False` as soon as one world fails, and `True` only after all valuations pass.
solution: Enumerate every valuation of the letters on the worlds, build the model, and check the formula at every world. Return `False` at the first failure and `True` if none occurs. The one-world frame with no accessibility is the edge case: $\Box P$ is vacuously true there, so $\Box P \to P$ fails under the valuation making $P$ false.

@quiz self
prompt: In a few sentences, explain the difference between a formula being true in a model and being valid on a frame, using the formula $\Box P \to \Box\Box P$ as your example.
hint: Give one model in which the formula is true everywhere and one valuation on a frame where it is false.
solution: A formula is true in a model if it holds at every world under that one valuation. It is valid on a frame only if it is true in every model on the frame, that is, under every valuation. Take the frame with worlds 1, 2 and 3 and $R = \{(1, 2), (2, 3)\}$. If $P$ is true at all three worlds, $\Box P \to \Box\Box P$ is true at all three, so the formula is true in this model. But if $P$ is true only at 2, then $\Box P$ is true at 1 (its only successor is 2), while $\Box\Box P$ is false at 1, because 2 sees 3, where $P$ is false. So the formula is false at 1 in that model. Hence it is true in one model on the frame and not valid on the frame.

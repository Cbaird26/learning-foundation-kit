@article
Socrates might never have existed: his parents might never have met. That seems obvious. But it is hard to make logic agree. In Lesson 8 we saw that the Barcan formula and its converse tie the quantifiers to domains of existents that cannot shrink or grow. Now we ask the question directly: are there things that exist at some worlds but not others?

### Two positions

Define an existence predicate by $E!x := \exists y\,(y = x)$: something is identical to $x$. In the varying-domain semantics of Lesson 8, with $D(w)$ the objects that exist at $w$, the quantifier $\exists y$ ranges over $D(w)$, so $E!x$ is true at $w$ of exactly those objects that belong to $D(w)$.

- **Contingentism** says that what exists could have been different: it is possible that something exists that possibly does not exist. Formally, $\Diamond\exists x\,\Diamond\neg E!x$.
- **Necessitism**, as Timothy Williamson defends it, says that necessarily everything necessarily exists: $\Box\forall x\,\Box E!x$, that is, $\Box\forall x\,\Box\exists y\,(y = x)$.

The two are contradictories: $\neg\Box\forall x\,\Box E!x$ is equivalent to $\Diamond\exists x\,\Diamond\neg E!x$ by duality. Necessitism does *not* say that everything is concrete in every world. The necessitist uses "exists" in a very thin sense, and says that Ana's merely possible child exists (as a *non-concrete* object) in the actual world; what varies from world to world is which things are concrete, which are persons, and so on, not which things there are.

### Reading the formulas in a model

Compare two similar-looking formulas:

| formula | says | status |
|---|---|---|
| $\Box\forall x\,E!x$ | necessarily, everything exists (at the world where it is considered) | valid |
| $\forall x\,\Box E!x$ | everything exists at every accessible world | not valid |

The first is trivial: at any world, every object in the domain exists. The second is the substantive claim. In a model, $\forall x\,\Box E!x$ is true at $w$ iff every $a \in D(w)$ belongs to $D(v)$ for every $v$ with $wRv$. Necessitism, $\Box\forall x\,\Box E!x$, is true at $w$ iff for all $v$ accessible from $w$ and all $u$ accessible from $v$, $D(v) \subseteq D(u)$.

**Theorem.** On a frame $(W, R, D)$ where $R$ is an equivalence relation (the S5 case), necessitism is true at every world iff the domains are constant within each equivalence class.

*Proof.* ($\Leftarrow$) If domains are constant on each class, then for $wRv$ and $vRu$, $D(v) = D(u)$, so the condition holds. ($\Rightarrow$) Suppose necessitism is true at every world and $vRu$. By reflexivity, $vRv$, so with $w = v$ the condition gives $D(v) \subseteq D(u)$. By symmetry $uRv$, and the same argument gives $D(u) \subseteq D(v)$. So $D(u) = D(v)$. $\square$

For example, let $W = \{w, v\}$ with universal accessibility, $D(w) = \{a\}$ and $D(v) = \{a, b\}$. At $w$, $\forall x\,\Box E!x$ is true (the only object, $a$, exists at both worlds), but at $v$ it is false: $b$ does not exist at $w$. So necessitism is false at both worlds and contingentism, $\Diamond\exists x\,\Diamond\neg E!x$, is true: $b$ exists at $v$ and possibly does not exist (at $w$).

The Barcan formulas are tied to this. The instance of the converse Barcan formula with $F := E!$ is $\Box\forall x\,E!x \to \forall x\,\Box E!x$, whose antecedent is valid. So the converse Barcan formula, together with the trivial first formula, yields $\forall x\,\Box E!x$: *everything necessarily exists*. Whoever accepts the Barcan formulas in a system with standard rules is on the way to necessitism.

### An argument from classical logic

Williamson's central argument is that classical logic itself implies necessitism:

| P1 | $\vdash \exists y\,(y = x)$: classical logic proves that anything is identical to something, with $x$ free. |
| P2 | If $\vdash A$ then $\vdash \Box A$, also when $A$ contains free variables (necessitation). |
| P3 | If $\vdash A(x)$ then $\vdash \forall x\,A(x)$ (universal generalization). |
| C | $\vdash \Box\forall x\,\Box\exists y\,(y = x)$: necessitism is a theorem. |

The derivation: P1 gives $\exists y\,(y = x)$; P2 gives $\Box\exists y\,(y = x)$; P3 gives $\forall x\,\Box\exists y\,(y = x)$; P2 again gives the conclusion. The argument is valid. A **contingentist** has to reject a premise, and the premise to reject is P1, in the form assumed by classical quantifier logic. In the varying-domain semantics of Lesson 8, $\exists y\,(y = x)$ is *not* valid: assign to $x$ an object that does not exist at $w$ and it is false there. So the classical rules for free variables are unsound in that semantics, and the logic must be weakened: **free logic** replaces "$\forall x\,A \to A(t)$" with "$\forall x\,A \to (E!t \to A(t))$" and restricts the rule $=$-introduction so that $t = t$ yields $\exists y\,(y = t)$ only given $E!t$. (Free logics come in positive and negative versions, differing over whether an atomic sentence about a non-existent can be true.)

The costs of each position: the necessitist must accept non-concrete objects and a thin sense of "exist", which may seem to flout ordinary speech ("there are no unicorns", yet some non-concrete thing could have been a unicorn). The contingentist must adopt a free logic, with more complicated quantifier rules, and must say what the possible child is, if not something that exists now. Neither view is forced by the logic alone: the question of which logic to use is part of the metaphysical question. A valid argument from logical premises leaves open whether those premises are true of the world.

@example
title: Evaluating existence formulas in a model
problem: Let $W = \{w, v\}$ with universal accessibility, $D(w) = \{a, b\}$ and $D(v) = \{a\}$. Evaluate at $w$ and at $v$: (i) $\forall x\,\Box E!x$; (ii) $\Box\forall x\,E!x$; (iii) $\Diamond\exists x\,\Diamond\neg E!x$.
step: (ii) At every world, every object in its domain exists there, so $\forall x\,E!x$ is true at both worlds, and $\Box\forall x\,E!x$ is true at both.
step: (i) At $w$: $b \in D(w)$ but $b \notin D(v)$, so $\Box E!x$ fails of $b$ and $\forall x\,\Box E!x$ is false. At $v$: the only object is $a$, which exists at both worlds, so the formula is true at $v$.
step: (iii) At $w$ the object $b$ is such that $\Diamond\neg E!x$ holds of it (at $v$ it does not exist), so $\exists x\,\Diamond\neg E!x$ is true at $w$ and $\Diamond\exists x\,\Diamond\neg E!x$ is true at both worlds (every world sees $w$).
answer: (i) false at $w$, true at $v$; (ii) true at both; (iii) true at both. This model has shrinking domains: contingentism holds and necessitism fails.

@example
title: The derivation of necessitism
problem: Write out the derivation of $\Box\forall x\,\Box\exists y\,(y = x)$ in classical quantified modal logic and say where a free logic blocks it.
step: Line 1: $\exists y\,(y = x)$, by $=$-introduction ($x = x$) and $\exists$-introduction.
step: Line 2: $\Box\exists y\,(y = x)$, by necessitation applied to line 1.
step: Line 3: $\forall x\,\Box\exists y\,(y = x)$, by universal generalization on line 2.
step: Line 4: $\Box\forall x\,\Box\exists y\,(y = x)$, by necessitation applied to line 3.
step: A free logic blocks line 1: from $x = x$ one may infer $\exists y\,(y = x)$ only if $x$ is known to exist ($E!x$), so line 1 is not a theorem, and the later lines do not follow.
answer: Classical logic yields necessitism in four lines; a contingentist rejects line 1, the unrestricted $\exists$-introduction for a free variable.

@mistakes
- Confusing "necessarily everything exists" ($\Box\forall x\,E!x$, trivially valid) with "everything necessarily exists" ($\forall x\,\Box E!x$, the necessitist claim).
- Taking necessitism to say that everything is concrete in every world: it says that everything exists, in a thin sense, and that concreteness is what varies.
- Blaming the derivation for an invalid step: it is valid, and the contingentist's complaint is with its first premise and with the classical rules behind it.
- Assuming that constant-domain semantics is neutral: it builds in necessitism, and varying domains are what a contingentist uses.

material: **Question A: negative existentials.** "Vulcan does not exist" seems true and meaningful. The puzzle: if "Vulcan" names something, there is something that does not exist; if it names nothing, how is the sentence meaningful? Starting argument: P1: If a name's meaning is its bearer, a name without a bearer is meaningless. P2: "Vulcan" has no bearer. P3: "Vulcan" is not meaningless, since it contributes to the meaningful sentence "Vulcan does not exist". C: So the meaning of a name is not its bearer. Compare at least a Russellian descriptive analysis and a Fregean view in which a name has a sense.
material: **Question B: the necessary a posteriori.** "Hesperus is Phosphorus" seems both necessary and knowable only empirically. Starting argument: P1: Hesperus is Phosphorus. P2: Hesperus has the property of being necessarily identical to Hesperus. P3: If a is b, whatever is true of a is true of b. C: So Phosphorus has the property of being necessarily identical to Hesperus; that is, necessarily, Hesperus is Phosphorus. Compare a descriptivist account of the names with Kripke's rigid designation, and discuss the explanation of why the identity seems contingent.
material: **Question C: names in fiction.** "Holmes is a detective" seems true in some sense, and "Holmes does not exist" seems true too. Puzzle: on a Millian view the name lacks a bearer; on a descriptivist view it is a disguised description. Compare at least a Russellian reading, a causal-historical account, and a view on which fictional names have a special status. Say what each says about the truth-values of the two sentences.

### Week by week

1. **Meaning, reference and truth.** Referent, extension, truth-value, meaning; truth-conditions versus truth; use and mention; Millianism, descriptivism, ideationalism; the argument from empty names.
2. **Frege.** The puzzle of informative identity; sense as mode of presentation; the reference of a sentence is its truth-value; indirect contexts; empty names.
3. **Russell.** "The F is G" as existence, uniqueness and predication; scope of negation; negative existentials without nonexistent objects.
4. **Strawson and Donnellan.** Presupposition survives negation; attributive and referential uses; Kripke's reply with speaker's reference.
5. **Kripke on names.** The description and cluster theories; the modal, epistemic and semantic arguments; the scope reply.
6. **Rigid designation.** The necessity of identity; the necessary a posteriori; epistemic versus metaphysical possibility.
7. **Causal theory and natural kinds.** Baptism and chain; Evans's reference-change objection; the qua problem; "gold" and pyrite.
8. **Twin Earth.** Putnam's argument; externalism; narrow content; Burge's social externalism.
9. **Truth.** Correspondence; deflationism; Convention T; satisfaction; the Liar and the hierarchy.
10. **Compositionality.** The productivity argument; Davidson's program; deviant T-theorems; idioms and belief reports.
11. **Speech acts and implicature.** Locutionary, illocutionary and perlocutionary acts; Searle's categories; Grice's maxims and scalar implicature; cancellability.
12. **Context and vagueness.** Character and content; "I am here now"; the sorites; epistemicism, supervaluationism, degree theories, contextualism; penumbral connections.

### Key arguments

Know each in standard form: the empty-name argument against Millianism, Frege's argument for sense, the modal and semantic arguments against descriptivism, the necessity of identity, the Twin Earth argument, the Liar, the productivity argument, and the Gricean derivation of a scalar implicature. For each, know which premise each main objection attacks.

### Common errors

Confusing meaning with reference; calling a valid argument invalid because a premise is denied; forgetting uniqueness in Russell's analysis; treating necessity as certainty; taking Putnam to say that meaning is entirely outside the head; confusing illocutionary and perlocutionary acts; saying that supervaluationism rejects excluded middle.

@exam num
prompt: Five worlds w1 to w5 are given. The name "n" designates a in every world. In the five worlds the set of things that are F is: {a}, {a, b}, {b}, {a}, {}. The set of things that are G is: {a}, {a, b}, {a}, {b}, {a}. In how many of the five worlds do the Russellian sentence "The F is G" and the sentence "n is G" differ in truth-value?
answer: 3
unit: worlds
check: sum(1 for F, G in [({'a'}, {'a'}), ({'a', 'b'}, {'a', 'b'}), ({'b'}, {'a'}), ({'a'}, {'b'}), (set(), {'a'})] if (len(F) == 1 and F <= G) != ('a' in G))
hint: Evaluate the description sentence by existence, uniqueness and predication in each world, and the name sentence by whether a is in G.
solution: "The F is G" is true only in w1, where exactly one thing is F and it is G: true, false, false, false, false across the five worlds. "n is G" is true in w1, w2, w3 and w5, and false in w4. The sentences differ in w2, w3 and w5, and agree in w1 and w4, so they differ in 3 worlds. This is the kind of modal difference between a rigid name and a non-rigid description that the modal argument exploits.

@exam mc
prompt: Which of the following correctly pairs a philosopher with the position or objection associated with them?
choice*: Strawson held that a use of "The king of France is wise" when there is no king makes neither a true nor a false statement.
choice: Russell held that sentences containing empty descriptions are neither true nor false.
choice: Putnam argued against descriptivism about proper names using the Gödel and Schmidt case.
choice: Tarski held that a language can contain its own truth predicate without restriction, if its logic is classical.
hint: Match each view with the philosopher who held it, and recall which views were contrasted in weeks 3, 4, 8 and 9.
solution: Strawson's presupposition view holds that the question of truth does not arise when no king exists. Russell held that such sentences are false. The Gödel–Schmidt case is Kripke's argument against descriptivism about names, and Tarski concluded that, given classical logic, truth for a language cannot be defined within it.

@exam self
prompt: Compare a Russellian and a Kripkean account of the name "Vulcan" as used in "Vulcan does not exist". Reconstruct in standard form one argument against each account, say which premise each of its best replies attacks, and defend a view of which account handles the case better, with the strongest reply to your own view. Write about 400 words.
hint: Use a semantic argument against descriptivism (the modal argument needs a bearer to evaluate, which an empty name lacks), and the problem of empty names for the causal theory.
solution: On the Russellian account, "Vulcan" abbreviates a description such as "the planet that perturbs Mercury's orbit", and "Vulcan does not exist" says that nothing uniquely satisfies it, which is true, with no nonexistent object. On the Kripkean account, a name is introduced at a baptism and passed along a chain, and names are rigid. Argument against the Russellian (a semantic argument; the modal argument is awkward here, since an empty name has no bearer to evaluate in other worlds): P1: If "Vulcan" is synonymous with the description, then had some undiscovered planet caused the perturbations of Mercury's orbit, "Vulcan" would have named that planet. P2: Even then, "Vulcan" would not have named that planet, since the astronomers' use of the name had no causal link to it. C: So "Vulcan" is not synonymous with the description. A defender attacks P2, and a cluster theorist attacks P1 by saying that more descriptions than this one are associated with the name. Argument against the Kripkean: P1: If the causal chain from a baptism is what gives a name its meaning, then a name with no object to start a chain has no meaning. P2: "Vulcan" had no object to start a chain. P3: "Vulcan" is meaningful. C: So the causal chain is not what gives "Vulcan" its meaning. The reply that attacks P3 says that the name is not really meaningful, and the reply that attacks P1 says that the name's meaning is given by the description used at the introduction. My view: the Kripkean account is right that ordinary uses of names are not tied to the speaker's descriptions, but for empty names it needs the Russellian description introduced at the start, so a hybrid is best. The strongest reply is that the hybrid reintroduces descriptivism for exactly the cases in dispute.

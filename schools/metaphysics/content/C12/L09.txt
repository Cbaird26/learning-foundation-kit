@article
"What I said is true." It sounds as if the speaker has said something about a sentence, attributing a property to it. But what could that property be? The sentence "Basalt is volcanic" is true, and so is "Seven is prime", and they have little in common except that both are true. Philosophers have long asked whether truth is a deep, substantial property with a nature to be analyzed, or something thin and almost trivial.

### The correspondence theory

The **correspondence theory** says that a statement or belief is true when it corresponds to the facts: it represents things as they are. The idea is old: Aristotle said, in a famous passage of the *Metaphysics* (Book Gamma, chapter 7), that to say of what is that it is, and of what is not that it is not, is true. Bertrand Russell developed a version in *The Problems of Philosophy* (1912), in which a belief is true when there is a fact corresponding to it. Objections include the demand to say what facts are and what correspondence consists in, and the worry that facts look like true statements dressed up: P. F. Strawson argued that facts are not things in the world but what true statements state.

### The deflationary theory

**Deflationism** holds that truth is not a substantive property whose nature needs an analysis. F. P. Ramsey's **redundancy theory** held that "it is true that p" says no more than p. Later versions include **disquotationalism**, associated with Quine and with Hartry Field, on which the truth predicate lets us undo quotation: "'Basalt is volcanic' is true" is equivalent to "Basalt is volcanic". Paul Horwich's **minimalism** takes the instances of the schema "the proposition that p is true if and only if p" to give all there is to the concept. Deflationists stress that the truth predicate is a **device of generalization**: it lets us say "Everything the witness said is true" without listing every sentence.

| P1 | For every p, "it is true that p" is equivalent to p. |
| P2 | If, for every p, ascribing truth to p is equivalent to asserting p, then truth is not a substantive property with a nature to be analyzed. |
| C | So truth is not a substantive property with a nature to be analyzed. |

The argument is valid (modus ponens). Critics attack P2. An equivalence between "x is water" and "x is H$_2$O" does not show that being water is not a property with a nature, and a deflationist must explain why truth is different. A related criticism is that truth seems to figure in explanations, for instance of why a theory leads to successful action, and a deflationist replies that the explanation can be given by generalizing over instances.

### Tarski

Alfred Tarski, in his 1933 monograph on the concept of truth in formalized languages, asked how to define truth for a formal language without circularity. He required that a definition be **materially adequate**, and gave a test, **Convention T**: a definition of "true-in-L" for an object language L is adequate if it entails, for each sentence s of L, a **T-sentence** of the form

$$s \text{ is true in } L \text{ if and only if } p,$$

where $s$ is replaced by a name of the sentence, and $p$ by a translation of the sentence into the metalanguage. An example, with English as the metalanguage and German as the object language: "'Es regnet' is true in German if and only if it is raining". The T-sentence uses the right-hand sentence and mentions the left-hand one. A T-sentence for a false sentence is still true: "'Whales are fish' is true in English if and only if whales are fish" is a true biconditional, since both sides are false.

Tarski's method is recursive. First he defines **satisfaction**: which objects satisfy which open sentences. Then truth is defined for sentences by clauses, such as: a conjunction is true when both conjuncts are true, a negation when the negated sentence is not true, and a universal sentence when every object satisfies its open sentence. Tarski said that his definition is neutral between metaphysical positions, and that it can be seen as capturing the classical idea behind the correspondence theory.

### The Liar and the hierarchy

Consider the sentence $\lambda$: "$\lambda$ is not true."

| P1 | For every sentence S, S is true if and only if things are as S says. |
| P2 | $\lambda$ says that $\lambda$ is not true. |
| C | So $\lambda$ is true if and only if $\lambda$ is not true, which in classical logic is a contradiction. |

The argument is valid. Tarski concluded that an adequate truth definition for a language cannot be given within that language, assuming classical logic and that the language can name its own sentences and contain its own truth predicate. The truth predicate for the object language belongs to a richer metalanguage, whose own truth predicate belongs to a meta-metalanguage, in a **hierarchy**. Later theorists, such as Saul Kripke in his 1975 paper on truth, tried to allow a language to contain its own truth predicate by giving up classical assumptions, such as bivalence.

@example
title: Writing T-sentences
problem: Write the T-sentence for the English sentence "Granite is igneous", taking English as the metalanguage, and say what makes it an instance of Convention T. Then write the T-sentence for "Granite is not igneous".
step: Name the sentence by quoting it: "Granite is igneous". The T-sentence is: "Granite is igneous" is true in English if and only if granite is igneous.
step: The left side mentions the sentence, and the right side uses a translation of it, which is the sentence itself in this case.
step: For the negation: "Granite is not igneous" is true in English if and only if granite is not igneous.
step: Both T-sentences are true biconditionals. Whatever the truth about granite, one sentence is true and the other false, and each T-sentence connects a sentence to the way the world would have to be.
answer: "Granite is igneous" is true in English iff granite is igneous; "Granite is not igneous" is true in English iff granite is not igneous.

@example
title: Satisfaction in a small model
problem: A model has domain {1, 2, 3, 4, 5}. The predicate F is true of 1, 2 and 3, and G of 3 and 4. Which objects satisfy "$Fx \wedge \neg Gx$" and "$Fx \vee Gx$"?
step: A conjunction is satisfied by an object when both conjuncts are. The objects with F are 1, 2 and 3. Those without G among them are 1 and 2.
step: So $Fx \wedge \neg Gx$ is satisfied by 1 and 2.
step: A disjunction is satisfied when at least one disjunct is. F gives 1, 2, 3 and G gives 3, 4.
step: So $Fx \vee Gx$ is satisfied by 1, 2, 3 and 4, and not by 5.
answer: $Fx \wedge \neg Gx$ is satisfied by 1 and 2; $Fx \vee Gx$ is satisfied by 1, 2, 3 and 4.

@mistakes
- Saying that a T-sentence is true only if the sentence mentioned is true. A T-sentence is a biconditional, and it is true when both sides are true or both false.
- Writing the right side of a T-sentence in quotation marks. It uses the sentence, and does not mention it.
- Saying that deflationists deny that "true" is a meaningful predicate. They hold that it is meaningful and useful, but that it does not name a substantive property.
- Saying that Tarski solved the Liar by banning self-reference altogether. He showed that classical truth for a language cannot be defined in that language, which motivates a hierarchy of languages.

@quiz self
prompt: Give one objection to the correspondence theory and one to deflationism, and say what a defender of each might reply, in two or three sentences each.
hint: For the correspondence theory consider what facts are; for deflationism consider the explanatory role of truth.
solution: Objection to correspondence: it is unclear what facts are and what correspondence amounts to, since facts look like nothing more than true statements. A defender can reply that facts are structured states of affairs in the world and that correspondence is a relation between structure and structure, as in Russell's account of belief. Objection to deflationism: truth seems to play an explanatory role, as when we explain why a true theory leads to successful action. A deflationist can reply that the explanation can be given case by case, by citing the particular facts, and that the truth predicate serves only to generalize over such cases.

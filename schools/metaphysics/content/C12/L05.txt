@article
How do you manage to talk about Aristotle when you have never met him? A tempting answer is that you associate with the name some description, perhaps "the teacher of Alexander the Great", and that "Aristotle" refers to whoever satisfies it. This is the **description theory** (descriptivism) of names, which Frege's remarks and Russell's account of ordinary names suggest. John Searle and others developed the **cluster theory**: a speaker associates a whole cluster of descriptions with a name, and the name refers to the thing that satisfies most of them or a weighted majority. Wittgenstein's remarks on the name "Moses" in the *Philosophical Investigations* (section 79) are an early statement of the idea.

Saul Kripke's lectures *Naming and Necessity* argue that the theory is false. It helps to separate what the theory says in each of its parts: that the description gives the meaning of the name, that it fixes the name's reference, and that the sentence "N is D" is in some sense knowable a priori by anyone who is competent with N. Kripke has three main kinds of argument, the modal, the epistemic and the semantic.

### The modal argument

Suppose "Aristotle" meant "the teacher of Alexander." Then "Aristotle taught Alexander" would be something like a definition, and so true however things might have gone. But Aristotle might never have taught Alexander. He might have pursued other work and left the prince's education to someone else.

| P1 | If "Aristotle" is synonymous with "the teacher of Alexander", then "It might have been that Aristotle did not teach Alexander" and "It might have been that the teacher of Alexander did not teach Alexander" have the same truth-value. |
| P2 | "It might have been that the teacher of Alexander did not teach Alexander", with the description read inside the scope of "might have been", is false: nothing could have been a teacher of Alexander and not have taught him. |
| P3 | "It might have been that Aristotle did not teach Alexander" is true. |
| C | So "Aristotle" is not synonymous with "the teacher of Alexander." |

The argument is valid: synonymous expressions can be exchanged without changing the truth-value of a sentence, and P2 and P3 give two sentences with different truth-values. The most important point about the argument is that Kripke's explanation of P3 is that the name designates the same man in every possible situation in which he exists, while a description picks out whoever satisfies it in each situation. This is the idea of **rigid designation**, the topic of next week.

### Replies to the modal argument

The standard reply from descriptivists attacks P1. Descriptions interact with modal operators through **scope**, as they do with negation (week 3). "The teacher of Alexander might not have taught Alexander" has two readings. With the description inside the scope of "might", it is false; with the description outside, it says that the actual teacher of Alexander might not have taught him, which is true. So the descriptivist says that synonymy requires no more than a match of readings: "Aristotle might not have taught Alexander" is true because the matching reading, with wide scope for the description, is true. Michael Dummett is the best-known source of this reply. Kripke's answer is that the name sentence has only the one reading, so that whatever the theory says about descriptions, names do not behave like descriptions in modal contexts, and that the wide-scope reading attributes to the description only a role in fixing reference. A second line of reply keeps descriptivism but rigidifies the description with "actually", as in "the person who actually taught Alexander". This avoids the modal argument and faces the epistemic and semantic arguments.

### The epistemic and semantic arguments

The **epistemic argument**: if "Gödel" meant "the man who proved the incompleteness of arithmetic", then anyone competent with the name would be in a position to know a priori that Gödel, if anyone, proved it. But that is not something one could know by reflecting on the name.

The **semantic argument**, Kripke's Gödel–Schmidt case. Imagine, for the sake of the thought experiment only, that a man named Schmidt proved the theorem and that the man we call "Gödel" got the credit by an accident. If descriptivism were true, our name would refer to Schmidt. But in that situation we would still be talking about the man we call Gödel, who, in the story, did not prove it. So descriptivism gets the reference wrong. A further observation of Kripke is that most speakers associate with names such as "Feynman" no uniquely identifying description, yet refer successfully.

| P1 | If descriptivism is true, then in the Schmidt situation the name "Gödel" would refer to Schmidt. |
| P2 | In the Schmidt situation the name "Gödel" would still refer to the man we call Gödel and not to Schmidt. |
| C | So descriptivism is false. |

This argument is valid. A descriptivist can attack P2 by arguing that speakers would in fact shift the reference of the name, or attack P1 by arguing that the cluster of associated descriptions is much larger than the single proof, so that descriptivism does not imply that the name refers to Schmidt.

@example
title: Running the modal argument for a new name
problem: Use Kripke's modal reasoning to test the claim that the invented name "Odile Brandt" means "the first person to cross the Varn Pass". Say why the test shows that the name and the description differ in modal behavior, and what the descriptivist's best reply is.
step: Suppose the name means the description. Then "Odile Brandt might not have crossed the Varn Pass first" and "the first person to cross the Varn Pass might not have crossed it first" should have the same truth-value.
step: The second, with the description in the scope of "might", is false: whoever is the first to cross crossed it first.
step: The first is plausibly true: the person we call "Odile Brandt" might have stayed home that season.
step: So the name and the description differ in modal behavior, and by the premise that synonyms agree, they are not synonymous.
step: The descriptivist's best reply is the scope reply: the sentence with the description read with wide scope is true, so the two need not differ.
answer: The name and the description differ in modal behavior, so they are not synonymous, unless the descriptivist's scope reply is accepted.

@example
title: Which argument is this?
problem: A philosopher says: "Suppose someone other than the man we call 'Cooper' invented the first telephone switch, and he got the credit by mistake. Descriptivism says 'Cooper' would then refer to the real inventor, but it would not." Classify the argument, and state the premise that a descriptivist attacks.
step: The argument asks what our name would refer to in a counterfactual situation, and it appeals to a judgment about reference. That is a semantic argument, as in the Gödel–Schmidt case.
step: Its first premise is that descriptivism implies that the name would refer to the inventor.
step: Its second premise is that the name would not refer to him but to the man we call "Cooper".
step: A descriptivist attacks the second premise: she says that speakers would be willing to say that the name refers to the true inventor. (A cluster theorist would instead attack the first premise, saying that more descriptions than the invention are involved, so that descriptivism does not imply reference to the inventor.)
answer: It is a semantic argument, and the descriptivist attacks its second premise.

@mistakes
- Saying that Kripke argues that names have no sense because they are meaningless. He argues against the claim that a description gives their meaning or fixes their reference.
- Forgetting that the modal argument depends on reading the description inside the scope of the modal operator.
- Attributing the Schmidt case to history. It is an imagined case, not a claim that anyone proved the theorem other than the person usually credited.
- Confusing the claim that a name is not synonymous with a description with the claim that the description plays no role in fixing the name's reference. The two claims are different, and Kripke allows that descriptions may fix reference in special cases.

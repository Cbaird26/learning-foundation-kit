@article
Two ideas that philosophers had long run together are **necessity** (could not have been otherwise) and **a priori knowability** (knowable without appeal to experience). Necessity is a metaphysical matter, about how things might have been, and a priori knowability is an epistemic matter, about how we can know. Before Kripke it was widely assumed that the two coincide: whatever is necessary can be known a priori, and whatever is known a priori is necessary. His *Naming and Necessity* argued that they come apart.

### Rigid designation

A designator is **rigid** if it designates the same object in every possible world in which that object exists, and designates nothing else in any world. Proper names, such as "Aristotle", are rigid on Kripke's view. Many definite descriptions are **non-rigid**: "the number of planets" designates 8 in the actual world, but in a world with nine planets it designates 9. Some descriptions are rigid: "the smallest prime number" designates 2 in every world. You can make a rigid description from a non-rigid one by adding "actually": "the actual teacher of Alexander" designates the same person in every world.

Kripke distinguishes **fixing the reference** from **giving the meaning**. A description may be used to fix the reference of a name without being synonymous with it. At the introduction of a name for a planet one may say "let 'Zed' refer to the planet that causes the orbital irregularities". The description fixes the referent, but "Zed" then designates that planet in all worlds, including those in which it causes no irregularities.

### The necessity of identity

If "Hesperus" and "Phosphorus" are rigid and refer to the same planet, then "Hesperus is Phosphorus" could not have been false. The argument that identity is necessary has a standard form, using Leibniz's Law, the principle that if a is identical with b then whatever is true of a is true of b.

| P1 | Hesperus is Phosphorus. |
| P2 | Hesperus has the property of being necessarily identical to Hesperus. |
| P3 | If a is b, then every property a has, b has. |
| C | So Phosphorus has the property of being necessarily identical to Hesperus; that is, necessarily, Hesperus is Phosphorus. |

The argument is valid: from P1 and P3, whatever Hesperus has Phosphorus has, and P2 supplies the property in question. The premise most open to challenge is P2, though it seems secure: everything is necessarily self-identical. A critic can resist by denying that "being necessarily identical to Hesperus" is a property to which Leibniz's Law applies in modal contexts, though most philosophers accept the argument for names and rigid terms.

### The necessary a posteriori

If the identity is necessary, why did astronomers have to discover it? Because that the two names refer to the same planet can only be learned from observation. So we have a truth that could not have been false and that is knowable only a posteriori.

| P1 | "Hesperus is Phosphorus" is true. |
| P2 | "Hesperus" and "Phosphorus" are rigid designators. |
| P3 | If two rigid designators designate the same thing, an identity statement flanked by them could not have been false. |
| P4 | That Hesperus is Phosphorus can be known only by empirical investigation. |
| C | So there are truths that are necessary but knowable only a posteriori. |

The argument is valid. Kripke's other examples are that water is H$_2$O, that heat is molecular motion, and **origin essentialism**: a particular table could not have been made from a completely different block of wood. The converse case is the **contingent a priori**. Kripke's example concerns the standard metre bar, as the metre was once defined: someone who fixes the reference of "one metre" by that bar may know a priori that the bar is one metre long at that time, although the bar could have been of a different length.

### Why do these truths seem contingent?

We can easily imagine finding out that the planet seen in the morning is not the planet seen in the evening. Kripke's explanation is that what is imaginable is an **epistemic possibility**: a situation qualitatively like ours, with the same evidence, in which the names pick out different planets. It is not a metaphysical possibility in which Hesperus is not Phosphorus. The impression of contingency confuses the two. Two-dimensional semanticists, such as Chalmers and Jackson, offer a different diagnosis, by assigning to expressions an epistemic and a metaphysical intension. Other critics doubt that the distinction between epistemic and metaphysical possibility can be drawn as Kripke draws it.

@example
title: Rigid or non-rigid?
problem: Say whether each designator is rigid. (a) "the tallest person in Orlo"; (b) "Orlo" (the town); (c) "the positive square root of 49"; (d) "the actual tallest person in Orlo".
step: (a) The tallest person varies from world to world, so the designator is non-rigid.
step: (b) A proper name designates the same town in every world where it exists: rigid.
step: (c) The number 7 is the positive square root of 49 in every world: rigid.
step: (d) "Actually" fixes the description's reference to the person who is actually tallest in Orlo, so the designator is rigid.
answer: (a) non-rigid; (b) rigid; (c) rigid; (d) rigid.

@example
title: Necessary a posteriori or contingent a priori?
problem: Classify each as necessary or contingent and as a priori or a posteriori on Kripke's view: (a) "Water is H$_2$O"; (b) "2 + 2 = 4"; (c) "Some bridge in the town of Orlo is more than 50 years old."
step: (a) Kripke holds that it is necessary, since "water" and "H$_2$O" designate the same kind in every world. It was discovered by chemistry, so it is a posteriori.
step: (b) It is necessary and knowable a priori.
step: (c) It could have been false, so it is contingent, and it is known by observation: a posteriori.
answer: (a) necessary a posteriori; (b) necessary a priori; (c) contingent a posteriori.

@mistakes
- Treating "necessary" as meaning "known for certain". Necessity is about how things could have been, not about what we know.
- Saying that Kripke denies that the identity statement was a discovery. It is an empirical discovery, and also necessary.
- Describing a rigid designator as one that designates an object that exists in every world. It designates the same object in each world where that object exists.
- Confusing reference-fixing with giving the meaning. A description can fix the reference of a name without being synonymous with it.

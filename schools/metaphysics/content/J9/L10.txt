@article
"Bats can fly. A baseball bat is a bat. So a baseball bat can fly." That is obviously wrong, but notice that every sentence in it sounds fine. The trick is in one small word.

### Equivocation

A word is **ambiguous** when it has more than one meaning. **Equivocation** is using a word in one meaning in one part of an argument and another meaning in another part. In the bat argument, the first "bat" is an animal and the second is a piece of sports equipment, so the argument has four ideas, not three. Equivocation can also be subtle: "A feather is light. What is light cannot be dark. So a feather cannot be dark." Here "light" means "not heavy" and then "not dark". To catch it, list the key words and ask whether each one means the same thing each time.

### False dilemma

A **false dilemma** (or false dichotomy) offers two choices, as if they were the only ones, when there are more.

"Either we build a skate park, or kids will be bored forever." Maybe there are other things to do: sports clubs, a music room, a basketball court. A false dilemma is often used to push you toward one of two options. To answer it, ask, **"Are these really the only choices?"** Note that a dilemma is fine when the two options really are all there are: "Either the number is even or it is odd."

### Begging the question

An argument **begs the question** (is **circular**) when it assumes, in a premise, the very thing it is supposed to prove. "This diary is truthful, because every page says that it tells only the truth." The question was whether the diary is truthful; the premise uses the diary's own say-so, which is only worth trusting if the diary is already truthful. Another example: "Our team is the best, because no team is better than ours." The premise just repeats the conclusion in different words.

A circular argument can be valid: if the premise is the conclusion, then it cannot be true while the conclusion is false. Its defect is that someone who doubted the conclusion would have no reason to accept the premise. It gives no new support.

### Comparing the three

| Fallacy | What goes wrong | Question to ask |
|---|---|---|
| Equivocation | A word changes meaning | Does the key word mean the same each time? |
| False dilemma | Options are left out | Are there other choices? |
| Begging the question | The conclusion is assumed | Would a doubter accept this premise? |

@example
title: Catching an equivocation
problem: Find the mistake: "A mouse is an animal. A computer mouse is a mouse. So a computer mouse is an animal."
step: Look for a word used twice: "mouse".
step: In the first premise it means the small furry animal. In the second it means a computer device.
step: The argument looks like a syllogism, but because the word changes meaning, the two premises do not link up.
answer: Equivocation on the word "mouse".

@example
title: Two fallacies in two sentences
problem: Name the fallacy in each. (a) "Either you let me go to the party, or you don't trust me at all." (b) "The school rule is fair, because it is fair to everyone."
step: (a) The speaker gives two options. Parents may trust their child and still say no to this party for other reasons, so the options are not the only ones. This is a false dilemma.
step: (b) The conclusion is that the rule is fair. The premise says it is "fair to everyone", which says the same thing. This begs the question.
answer: (a) False dilemma; (b) begging the question.

@mistakes
- Calling every two-option statement a false dilemma. If there are really only two possibilities, it is fine.
- Thinking a circular argument must be invalid. It can be valid, but it gives no independent reason.
- Missing equivocation because the word looks the same each time. Check its meaning, not its spelling.
- Saying "that's a fallacy" without explaining which one and what is wrong. Name it and say why.

@quiz mc
prompt: "Nothing is better than a quiet day. A noisy day is better than nothing. So a noisy day is better than a quiet day." What is the problem?
choice*: The word "nothing" changes meaning, so the argument equivocates.
choice: It is a false dilemma.
choice: It is an appeal to popularity.
choice: It is an ad hominem.
hint: Compare what "nothing" means in the first premise and in the second.
solution: In the first premise "nothing is better" means that no day is better than a quiet day. In the second, "nothing" is treated as a thing, namely having no day at all. The shift makes the conclusion look supported when it is not.

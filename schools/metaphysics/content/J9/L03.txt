@article
Here is an argument: "All birds can swim. A robin is a bird. So a robin can swim." Something is wrong with it, but what? The first premise is false, since many birds cannot swim. Yet the argument has a good feature: **if** the premises were true, the conclusion would have to be true. That feature has a name.

### Validity

A **deductive argument** tries to give premises that guarantee its conclusion. It is **valid** when it is **impossible for all the premises to be true and the conclusion false at the same time**. In a valid argument, the conclusion follows from the premises.

Validity is about the **link** between premises and conclusion, not about whether the premises are really true. Our bird argument is valid, because in any situation where all birds could swim and a robin was a bird, the robin could swim. It is just not a good argument for another reason: a premise is false.

### Invalid arguments

An argument is **invalid** when it is possible for the premises to be true and the conclusion false. To show this, give a **counterexample**: a situation, which may be imaginary, where the premises are true and the conclusion is false.

"All dogs are animals. Rex is an animal. So Rex is a dog." Counterexample: Rex is a cat. Then both premises are true and the conclusion is false, so the argument is invalid. A single counterexample is enough.

Notice that an invalid argument can still have a true conclusion. Maybe Rex really is a dog. The problem is that the premises do not **guarantee** it.

### Sound arguments

A **sound** argument is valid **and** has all true premises. A sound argument always has a true conclusion. The table shows what to expect:

| Valid? | Premises all true? | What we can say |
|---|---|---|
| Yes | Yes | Sound: the conclusion must be true |
| Yes | No | Valid but unsound: the conclusion may be true or false |
| No | Yes | Invalid: the conclusion may be true or false |
| No | No | Invalid and unsound |

So you judge an argument with two questions: **Is it valid? Are the premises true?** The only combination that is impossible for a valid argument is true premises with a false conclusion.

### Deduction and probability

Many good arguments in daily life do not aim at certainty. "The sky is dark, so it will probably rain" is not deductively valid, but it can still be a reasonable argument. We study those in weeks 5 and 6. This week, we ask only about the guarantee.

@example
title: Valid but unsound
problem: Is this argument valid? Is it sound? "All fish live in the ocean. A trout is a fish. So a trout lives in the ocean."
step: Imagine that both premises were true. Then every fish lives in the ocean, and a trout is a fish, so a trout must live in the ocean. There is no way for the premises to be true and the conclusion false, so the argument is **valid**.
step: Now check the premises. "All fish live in the ocean" is false, because many fish live in rivers and lakes.
step: A sound argument needs all true premises, so this one is **not sound**.
answer: Valid but not sound.

@example
title: A counterexample for an invalid argument
problem: Show that this is invalid: "All the players on the Hawks are tall. Mina is tall. So Mina is a Hawks player."
step: To show invalidity, imagine a situation where the premises are true and the conclusion false.
step: Suppose every Hawks player is tall, and Mina is tall too, but she plays for the Falcons. Both premises are true.
step: In that situation the conclusion "Mina is a Hawks player" is false, so the premises do not guarantee it.
answer: Invalid: Mina might be tall without being a Hawk.

@mistakes
- Thinking a valid argument must have true premises or a true conclusion. Validity is only about whether the premises, if true, would guarantee the conclusion.
- Calling an argument invalid because you disagree with its conclusion. Check the link first.
- Calling an argument valid because its premises and conclusion are all true. A true conclusion can still fail to follow.
- Thinking you need many counterexamples. One counterexample shows that an argument is invalid.

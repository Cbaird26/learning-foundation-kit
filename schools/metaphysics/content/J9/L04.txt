@article
Some arguments are valid because of their **pattern**, not because of their topic. Learn the pattern and you can check a new argument in seconds. An "if ... then ..." statement has two parts: the **antecedent** (the "if" part) and the **consequent** (the "then" part).

### Modus ponens

"If it rains, the field is wet. It rains. So the field is wet." The pattern is:

| P1 | If P, then Q. |
| P2 | P. |
| C | So Q. |

You assert the antecedent, and conclude the consequent. This is **modus ponens** ("the way of affirming"). It is valid.

### Modus tollens

"If the oven is on, the kitchen is warm. The kitchen is not warm. So the oven is not on."

| P1 | If P, then Q. |
| P2 | Not Q. |
| C | So not P. |

You deny the consequent, and conclude that the antecedent is false. This is **modus tollens** ("the way of denying"). It is valid, too: if the oven's being on guaranteed a warm kitchen, then a kitchen that is not warm tells you the oven is off.

### The syllogism

A **syllogism** links two premises to a conclusion. The classic kind uses "all":

| P1 | All A are B. |
| P2 | All B are C. |
| C | So all A are C. |

"All owls are birds. All birds have feathers. So all owls have feathers." A similar chain works for "if": from "If P then Q" and "If Q then R", we may conclude "If P then R".

### Two tempting mistakes

**Affirming the consequent:** "If Lena finishes her homework, she can play. Lena is playing. So she finished her homework." This looks like modus ponens but is invalid. The "if" says finishing homework is enough to play; it does not say it is the only way. Perhaps she was allowed to play anyway.

**Denying the antecedent:** "If Sam studies, he passes. Sam did not study. So he did not pass." Also invalid: Sam may pass without studying.

| Pattern | Form | Valid? |
|---|---|---|
| Modus ponens | If P then Q; P; so Q | Yes |
| Modus tollens | If P then Q; not Q; so not P | Yes |
| Affirming the consequent | If P then Q; Q; so P | No |
| Denying the antecedent | If P then Q; not P; so not Q | No |

A quick check: replace the sentences by silly ones and look for a counterexample. If you find one, the pattern is invalid.

@example
title: Spot the pattern
problem: Name the pattern and say if it is valid: "If it is a school day, the bell rings at 8:00. The bell did not ring at 8:00. So it is not a school day."
step: Find the "if" statement: P is "it is a school day" and Q is "the bell rings at 8:00".
step: The second premise says Q is false ("the bell did not ring"). The conclusion says P is false.
step: Denying the consequent to conclude that the antecedent is false is modus tollens, so the argument is valid.
answer: Modus tollens: valid.

@example
title: A look-alike
problem: Is this valid? "If a figure is a square, it has four sides. This figure has four sides. So it is a square."
step: The "if" statement has P = "a figure is a square" and Q = "it has four sides". The second premise affirms Q.
step: Concluding P from Q is affirming the consequent. A rectangle that is not a square has four sides, so the premises can be true while the conclusion is false.
answer: Invalid: affirming the consequent.

@mistakes
- Mixing up modus tollens with denying the antecedent. Modus tollens denies the consequent (Q) and concludes not P; the invalid pattern denies P and concludes not Q.
- Treating "if P then Q" as "if Q then P". The two are different claims.
- Calling an argument invalid because one of its premises is false. Pattern validity is separate from truth.
- Thinking that a valid pattern guarantees a true conclusion even when a premise is false. It guarantees the conclusion only if the premises are true.

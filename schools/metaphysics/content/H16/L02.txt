@article
Societies differ about food, dress and manners, and also about marriage, punishment, the treatment of elders and the rights of strangers. When you meet a practice that looks wrong to you, is that because it is wrong, or only because it is unfamiliar? **Relativism** is the idea that the answer depends on who is asking. This is one of the most common views among students, and one of the most useful to examine carefully.

### Three claims to keep apart

**Descriptive relativism** (or *cultural relativism* in the descriptive sense) is a claim of fact: different societies, and different times, hold different moral beliefs. This is supported by a great deal of evidence, though how deep the differences go is debated, since some apparent differences come from different beliefs about facts (for example, about what happens after death) while the underlying values are shared.

**Ethical relativism** (or *normative* or *metaethical relativism*, depending on the version) is a claim about morality: there is no single standard of right and wrong that holds for everyone. An action is right *relative to* a society's code, and wrong relative to another's. On the simplest version, **cultural relativism**, an action is right in a society just in case that society's code approves of it.

**Moral universalism** (or *absolutism*, though that word often suggests rules without exceptions, which universalists need not hold) says that at least some moral standards apply to all people everywhere, whatever anyone believes. A universalist may still accept that applying a standard depends on circumstances.

Another idea is often confused with these: **tolerance**. Tolerance is a moral attitude, respecting people who differ from us. It is a good thing to hold, but it is not the same as relativism, as we will see.

### The cultural differences argument

The most famous reason for relativism is an argument from disagreement:

| P1 | Different cultures have different moral codes. |
| C | So there is no objective truth in morality; right and wrong are just what each culture approves. |

Written this way the argument jumps from a descriptive premise to a normative or metaethical conclusion. A fuller version fills the gap with a hidden premise:

| P1 | Different cultures have different moral codes. |
| P2 | If cultures disagree about whether something is right, then there is no objective fact about whether it is right. |
| C | So there is no objective fact about what is right. |

This is valid, but premise P2 is doubtful. People also disagree about the age of the universe, or whether a medicine works, and nobody thinks that shows there is no fact about those things. Disagreement is compatible with one side being mistaken. A relativist must therefore say more than "people disagree".

### Arguments for relativism

One reply is that moral disagreement seems especially hard to resolve: there is no experiment to settle it. A second is that relativism seems to promote humility and tolerance. The reply to the second is that it doesn't follow. If right is relative to each culture, and a culture's code tells it to persecute minorities, the relativist must say persecution is right *for that culture*. A universalist can say that respect for persons is a standard everyone should honor, which would make tolerance a universal standard (though universalists must then say how far tolerance extends).

### Arguments against relativism

Critics raise several problems. (1) On cultural relativism, a reformer who criticizes her own society's code is wrong by definition, since the code defines what is right; yet moral progress, such as the abolition of slavery, seems to be a case of reformers being *right* against their society. (2) It is unclear how to individuate cultures: most people belong to several communities with different codes. (3) If the standard is the code of one's own society, then the claim "it is wrong to impose your code on others" cannot be a universal truth either. (4) Relativism seems unable to explain how criticism across cultures could make sense.

Relativists have replies. They may say that reformers appeal to ideals already within their society's own code; that a more sophisticated relativism relativizes to the individual's or group's framework without claiming that tolerance is universal; or that cross-cultural criticism remains possible as expressing our own values. Whether these replies work is a live question.

### The deliverable for weeks 1 and 2

A good habit for this unit: when someone discusses a practice, first **describe** it (what do people do, and what do they believe about it?), and then **judge** it (is it right?). The relativist question is whether the second step has any answer beyond "it depends on the society".

@example
title: Testing the cultural differences argument
problem: A student argues: "Society A allows people to eat a certain food. Society B forbids it. So neither is right or wrong; it all depends on the society." Is the argument valid? Evaluate it.
step: Set out the argument as stated: P1, Society A allows it and Society B forbids it. C, so there is no fact about whether it is right.
step: The argument is invalid as stated, because it has a descriptive premise and a conclusion about moral facts. To make it valid, add: "If societies disagree about whether something is right, there is no fact about whether it is right."
step: Test the added premise. Societies once disagreed about whether disease was caused by spirits or germs, but there was a fact. So disagreement alone doesn't show there is no fact. The premise needs more support.
step: Also look at the example itself. The disagreement may rest on different factual beliefs (perhaps B thinks the food is unhealthy), and then both could share the value "do not harm people"; a descriptive difference would hide a shared standard.
answer: The argument is invalid as stated, and its hidden premise is doubtful, since disagreement does not by itself show there is no fact of the matter.

@example
title: Describe, then judge
problem: In the town of Marden, a common practice is that the youngest child inherits the family house. Describe the practice and then give one reason someone might judge it fair and one reason someone might judge it unfair.
step: Description: In Marden the youngest child inherits the family house. A description can add what people in Marden believe about it, for example that the youngest stays longest to care for the parents.
step: Judging it fair: if the youngest does most of the caring, getting the house may be a fair return for that work.
step: Judging it unfair: if siblings who did equal work, or who are in greater need, receive nothing, then the rule treats like cases differently without a relevant reason.
step: Note that the description is the same whichever judgment you reach, and that neither judgment follows from the description alone.
answer: Describing reports what Marden does and believes; judging asks whether it is fair, and requires a moral reason.

@mistakes
- Treating descriptive relativism (cultures differ in their moral beliefs) as if it proved ethical relativism (there is no objective right and wrong).
- Thinking that relativism implies tolerance. If right is whatever a culture approves, a culture that approves of intolerance is simply right by its own code.
- Assuming that disagreement shows no one is right. People disagree about many matters of fact, and one side is often mistaken.
- Concluding that a universalist must be intolerant or must hold rules without exceptions. A universalist can accept that circumstances change what a standard requires.

@practice self
prompt: A classmate says: "Society X thinks it is fine to exclude newcomers from the village council. Society Y thinks it is wrong. Neither is wrong, because morality is just what a society thinks." First describe the disagreement in two sentences. Then give one objection to the classmate's reasoning and one reply a relativist could make.
hint: Separate what the societies believe from what is right, and recall what the argument from disagreement assumes.
solution: Description: Society X approves of excluding newcomers from the council and Society Y disapproves. The two societies hold conflicting beliefs about whether this practice is right. Objection: the classmate moves from the fact that societies disagree to the claim that morality is only what a society thinks, but that step assumes disagreement shows there is no fact, and people disagree about facts too, so one society may be mistaken. Also, on this view a reformer within X who says the exclusion is wrong would be mistaken by definition. A relativist could reply that the reformer appeals to values that are already part of the society's own tradition (such as fairness), so the criticism is internal; but the relativist then has to explain what is wrong with outside criticism of cultures.

@quiz self
prompt: Give an argument for ethical relativism and an argument against it, each in standard form with premises labeled P1, P2 and conclusion C. Then say in two or three sentences which you find stronger and why, and what the other side could reply.
hint: For the argument for, try the cultural differences argument with its hidden premise. For the argument against, try the reformer or the consistency of relativism with tolerance.
solution: For. P1: Different societies hold different moral codes. P2: If societies disagree about whether something is right, there is no objective fact about it. C: So there is no objective moral fact. Against. P1: If cultural relativism is true, then whatever a society's code approves is right in that society. P2: Reformers who criticize their society's code are sometimes right. P3: If cultural relativism were true, a reformer who criticizes the code would be wrong, since the code defines what is right. C: So cultural relativism is false. Judgment: the argument against seems stronger, because the argument for relies on P2 of the first argument, and disagreement alone does not show there is no fact (people disagree about facts of science). A relativist could reply that reformers appeal to ideals already inside the society's code, so they can be right relative to that deeper standard; the critic then has to show that the code is not unified enough for this reply to work.

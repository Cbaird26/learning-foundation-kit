# Writing one course for the Law School Learning Foundation

The Law School Learning Foundation is a Khan Academy–style self-study site for a 67-course pathway from kindergarten to law school and the bar exam: elementary school (K–5), middle school, high school, college pre-law courses, the first year of law school, upper-level law courses, and bar exam preparation. Each course follows a 14-week syllabus. You write the lessons for ONE course: weeks 1–12 (one lesson per weekly topic) plus a project/review/final-exam file for weeks 13–14. Your course JSON says who the learner is (`audience`) and the course `level`; write for that learner. Address the learner as "you". Assume the course prerequisites, but briefly remind key prerequisite rules or facts when you use them. Use the standard names of doctrines, rules, tests, statutes, model codes, landmark cases and theorems: learners need them to use the readings and pass exams. Do not write about real people themselves (no biographies or anecdotes about judges, lawyers or parties; case names and eponyms are fine), and never mention the curriculum's author.

## Files you write (only these)

- `/home/claude/law/content/<CODE>/L01.txt` … `L12.txt` — week N lesson = the syllabus topic for week N.
- `/home/claude/law/content/<CODE>/project.txt` — the week 13–14 project brief, review guide and cumulative exam items.

Your course data (audience, level, topics, block deliverables, project, primary reading) is in `/home/claude/law/toolkit/courses/<CODE>.json`. Read it and `/home/claude/law/toolkit/example_lesson.txt` (a complete lesson from a math course showing the exact format) before writing anything.

## File format

Sections start with `@name` at the start of a line. Fields are `key: value`; a line that does not begin with a known key continues the previous field, so multi-line values are fine. Write TeX directly (`$\frac{1}{2}$`); there is no escaping. Inline math is `$...$`, display math is `$$...$$`; write `\$` for a literal dollar sign (money: `\$4.50`).

Lesson file sections, in order:
- `@lesson` — `title:` (the week's topic as a clear title), `summary:` (one sentence: what the learner will be able to do), `objective:` ×2–4, `reading:` (see below).
- `@article` — markdown: paragraphs, `###` subheadings, **bold**, lists, tables, `$math$`. Length by level (see below).
- `@example` ×1–2 — `title:`, `problem:`, `step:` ×2–6 (each step is revealed one at a time, Khan-style).
- `@mistakes` — 2–4 lines starting with `- `.
- `@practice <type>` ×5 — ordered easy → hard.
- `@quiz <type>` ×2 — new problems used only in unit quizzes, the midterm and the final. Never near-copies of practice items, and never the numbers of a worked example.

Item fields: `prompt:`, `answer:`, `check:`, `hint:` ×1–3 (progressive; the last hint gets the learner to the method but not the final value), `solution:` (complete and short), plus optional `vars:`, `domain:`, `tol:`, `form:`, `const:`, `unit:`, `lead:`. Item types:

| type | learner enters | answer | check |
|---|---|---|---|
| `num` | one number or exact value | `3/4`, `sqrt(2)/2`, `2pi`, `1.5e3`, `inf`, `dne` | expression giving the value |
| `expr` | an expression in `vars` | `3x^2 sin(x)` | `lambda x: ...` taking `vars` in order |
| `list` | several values, any order | `-2, 3` (or `none`) | expression giving all values |
| `tuple` | ordered values | `(2, -1, 0)` | expression giving the components in order |
| `mc` | one choice | — mark the correct `choice*:` | — |
| `ms` | select all that apply | — mark every correct `choice*:` | — |
| `self` | works on paper, then compares | — give `solution:` (a model answer) and `rubric:` ×2–4 | — |

`mc`/`ms` use `choice:` lines (3–5 total) with the correct ones written `choice*:`. **The site shuffles the choices**, so never use "all/none of the above" or "both A and B", and in hints and solutions name a choice by its content, never by its position ("the second choice", "option B"). Distractors come from real misconceptions. Use `self` for writing, explanations, derivations, notes, plans and anything a person must judge; give a complete model `solution:` and 2–4 `rubric:` lines the learner checks their work against.

Optional fields: `vars: x, y` (expr; also any multi-letter or subscripted symbol such as `omega`, `v_0`); `domain: x: 3..6` (sampling ranges for expr equivalence; default 0.35..2.65 — set it whenever the answer is undefined there); `tol: 0.005` (absolute) or `tol: 1%` (relative) whenever the prompt asks for rounding or uses measured data; `form: expanded` or `form: factored`; `const: yes` (antiderivatives); `unit: dollars` (shown after the input box; ask for the value in that unit); `lead: $x =$` (shown before the input box).

A `num` item without `tol:` needs an exact answer: the site rejects a rounded decimal for it, so such a prompt must not ask for a decimal. Any prompt that asks for a rounded value, or uses measured numbers, needs a `tol:`. Money answers are usually exact (`answer: 37500`); when a prompt asks to round to the nearest dollar or cent, add `tol: 0.5` or `tol: 0.005`.

## Canonical answer syntax (what the site's grader reads)

Plain calculator syntax with implicit multiplication: `3/4`, `-sqrt(3)/2`, `2pi`, `e^(-x)`, `x^2`, `ln(x)`, `log(x)` (base 10 only), `abs(x)`, `5!`, `1.5e3`, `inf`, `dne`. No units, words or `x =` inside answers. Prefer exact answers; for rounded answers give the rounded value and a `tol`.

## Checks: every num/expr/list/tuple item must be verified by computation

`check:` is ONE Python expression that computes the expected result **independently from the problem statement**: redo the arithmetic from the given numbers (`200000 * (1 - 0.30)` for a recovery under pure comparative fault, `(12 - 9) * 1000 + 500` for expectation damages with incidental costs, `50000 * (1 + 0.06) ** 3` for compound interest, `120000 / (1.05 ** 4)` for a present value, `comb(5, 2)`) — never retype your answer. The validator compares it with your `answer` using the site's own grader. For `expr`, the check is a lambda that returns, for given inputs, the value the correct expression must have.

Available names: `quad(f,a,b)`, `nderiv(f,x,n=1..3)`, `root(f,a,b)`, `allroots(f,a,b)`, `roots(coeffs)`, `lin(A,b)`, `det(A)`, `inv(A)`, `mat(A)`, `dot`, `norm`, `lim(f,x0)`, `nsum(f,a,b)` (inclusive), `ivp(f,y0,t0,t1)`, `comb`, `perm`, `factorial`, `erf`, `Fraction`, `math`, `np`, `special` (scipy.special), `sin cos tan arcsin arccos arctan exp log ln log10 log2 sqrt floor ceil`, `pi`, `e`, `inf`, and Python builtins such as `sum`, `range`, `min`, `max`, `round`. `log` is the natural log here. Only when an item truly cannot be computed, write `nocheck: <reason>` instead (at most two per course).

## Writing for each level

- **Elementary (K–5).** The learner is a child with an adult helper who reads aloud. Short sentences, everyday words, one idea at a time, concrete things a child can see, count or touch. Articles 120–300 words (K–2) or 200–400 words (grades 3–5). Examples have 2–4 steps. Prompts are one or two short sentences with small, friendly numbers. Use mostly `mc` and `num` items (at least 4 of 7 auto-graded); a `self` item may be a hands-on task ("Draw…", "Read this aloud to your grown-up…") whose rubric the adult checks. Avoid TeX except for simple arithmetic like $3 + 4 = 7$. Reading courses use short original passages written by you, quoted inside the prompt. Hands-on activities use only safe household materials, with a grown-up.
- **Middle school.** Articles 250–450 words; clear, encouraging, concrete before abstract.
- **High school.** Articles 300–600 words.
- **College.** Articles 350–700 words; university-level precision, worked quantitative examples.
- **Law school and bar preparation.** Articles 400–900 words. Teach each doctrine in this order: the rule and its elements, the main exceptions and variations, the policy behind it, then how to apply it to facts (IRAC: issue, rule, application, conclusion). Name the governing source: the common law and the Restatements, the UCC, the Federal Rules of Civil Procedure, the Federal Rules of Evidence, the Model Penal Code, the ABA Model Rules of Professional Conduct, the Uniform Probate Code, the Internal Revenue Code, the APA, and U.S. Supreme Court precedent. Use landmark cases by name and year (for example *Hadley v. Baxendale* (1854), *Palsgraf v. Long Island R.R.* (1928), *International Shoe Co. v. Washington* (1945)) with accurate holdings; no reporter citations. `mc` items are bar-exam style: an original fact pattern of 3–6 sentences, a call of the question ("Is the buyer likely to prevail?"), and exactly 4 choices, each a conclusion with a reason ("Yes, because …" / "No, because …"); the correct choice is the single best answer and each distractor is wrong for a reason a learner can name (a misstated rule, the minority rule, a missing element, the right rule applied to the wrong fact). `ms` items ask which elements are met, which claims or defenses are available, or which statements of a rule are accurate. `num` items cover damages and mitigation, comparative fault, interest and present value, tax computations, intestate and elective shares, child-support percentages, voting thresholds and counting days to a deadline. `self` items ask for an IRAC analysis, a rule statement from memory, a case brief, a memo section, a drafted clause, a client letter or an argument outline, with a complete model answer and a rubric. Invented parties get role names or plain invented names (Buyer, Seller, Ana, Ben, Acme Corp.).

## Content standards

- **Correct above all.** Precise definitions, true statements, stated conventions and units. If unsure of a fact, choose a problem you can verify.
- **Law.** Teach U.S. law as commonly taught in law schools and tested on the bar in 2025–2026: the majority rule first, then the main minority rule, Model Penal Code or UCC variation in one clause ("most states …; a minority …"). Say when a point varies by jurisdiction. Do not invent cases, holdings, statutes or section numbers: if you are not sure a case says something, teach the rule without the case, and give section numbers only when you are confident of them (UCC § 2-207, FRCP 12(b)(6), FRE 801(d)(2), MPC § 2.02, Model Rule 1.7). Federal statutes, federal rules and judicial opinions may be quoted briefly and exactly, but only words you are certain of ("minimum contacts … fair play and substantial justice"); paraphrase the Restatements, the UCC, the Model Rules and the Uniform Probate Code, quoting a few words at most. For tax, never state a current-year dollar amount, rate, phase-out or limit as fact: give every such number in the prompt as an assumption ("Assume a standard deduction of \$15,000 and a flat 22% rate"); stable rules such as the § 121 home-sale exclusion amounts may be stated. Fact patterns are invented: no real clients or parties. Present contested constitutional questions neutrally: state the holding, then the main reasoning of the majority and of the dissent, and take no side. Never present this as legal advice to the reader about their own situation.
- **Recent changes to teach as current law** (verified; build them in where your course touches them, and never teach the older rule as current):
  - *Loper Bright Enterprises v. Raimondo* (2024) overruled *Chevron*: courts decide the best reading of a statute themselves and may give an agency's view *Skidmore* respect; prior *Chevron*-based holdings stay in force by statutory stare decisis.
  - *Trump v. Slaughter* (June 2026, 6–3) overruled *Humphrey's Executor*: the FTC Act's for-cause removal protection is unconstitutional, so FTC commissioners are removable at will; the Court left open the Federal Reserve (in *Trump v. Cook*, 2026, it refused to let a Federal Reserve governor's removal take effect while that case continues) and offices outside the traditional executive branch. Before this, *Seila Law* (2020) and *Collins v. Yellen* (2021) had already struck down removal limits on single-director agencies.
  - *Learning Resources, Inc. v. Trump* (February 2026, 6–3): the International Emergency Economic Powers Act does not authorize tariffs; the majority relied on the statutory text, and a plurality also applied the major questions doctrine (*West Virginia v. EPA*, 2022; *Biden v. Nebraska*, 2023).
  - *Trump v. CASA, Inc.* (2025): universal injunctions likely exceed the equitable authority Congress gave federal courts; relief is limited to what is needed to give the plaintiffs complete relief.
  - *SEC v. Jarkesy* (2024): the Seventh Amendment requires a jury when the SEC seeks civil penalties for securities fraud. *Corner Post v. Board of Governors* (2024): an APA claim accrues when the plaintiff is injured. *FCC v. Consumers' Research* (2025) upheld the Universal Service Fund against a nondelegation challenge.
  - Personal jurisdiction: *Ford Motor Co. v. Montana Eighth Judicial District Court* (2021: claims may "relate to" forum contacts without strict causation); *Mallory v. Norfolk Southern Railway Co.* (2023: a registration-based consent statute did not violate due process).
  - Criminal procedure: *Case v. Montana* (2026: police may enter a home without a warrant when they have an objectively reasonable basis to believe someone inside needs emergency aid); *Chatrie v. United States* (2026: obtaining a person's location data from Google with a geofence warrant is a Fourth Amendment search); *Barnes v. Felix* (2025: excessive-force claims are judged on the totality of the circumstances, not only the "moment of threat"); *Vega v. Tekoh* (2022: a Miranda violation alone does not support a § 1983 damages claim).
  - Evidence: *Smith v. Arizona* (2024: when a testifying expert conveys an absent analyst's statements as the basis of an opinion and they support it only if true, they are offered for their truth under the Confrontation Clause). FRE 702 was amended December 1, 2023 (the proponent must show the court it is more likely than not that each requirement is met). Effective December 1, 2024: new FRE 107 (illustrative aids) and amendments to FRE 613(b), 801(d)(2) and 804(b)(3).
  - Civil procedure: effective December 1, 2025, new FRCP 16.1 (early management of multidistrict litigation) and amendments to FRCP 16(b) and 26(f) requiring the parties to address how they will describe withheld privileged material.
  - First Amendment: *Kennedy v. Bremerton School District* (2022: the Establishment Clause is read by reference to historical practices and understandings; the *Lemon* test is abandoned); *303 Creative LLC v. Elenis* (2023); *Counterman v. Colorado* (2023: true-threats prosecutions require at least recklessness); *Mahmoud v. Taylor* (2025: parents' free-exercise claim to opt their children out of instruction); *Free Speech Coalition v. Paxton* (2025: intermediate scrutiny for age verification on sexual content harmful to minors); *Chiles v. Salazar* (2026: a ban on conversion therapy as applied to talk therapy regulates speech based on content and viewpoint; remanded for the correct scrutiny); *NRSC v. FEC* (2026: limits on political parties' coordinated spending with candidates violate the First Amendment); *First Choice Women's Resource Centers v. Davenport* (2026: standing to challenge a state subpoena for donor information).
  - Equal protection and other rights: *Dobbs v. Jackson Women's Health Organization* (2022) overruled *Roe* and *Casey*; *Students for Fair Admissions v. Harvard* (2023: race-conscious admissions at Harvard and UNC violate equal protection); *United States v. Skrmetti* (2025: Tennessee's ban on puberty blockers and hormones to treat gender dysphoria in minors gets rational-basis review and is upheld); *Little v. Hecox* (2026: Idaho's law limiting girls' and women's teams by biological sex does not violate the Equal Protection Clause) and *West Virginia v. B.P.J.* (2026: Title IX allows schools to keep separate male and female teams based on biological sex); *Louisiana v. Callais* (2026: a congressional map was an unconstitutional racial gerrymander because the Voting Rights Act did not require the second majority-minority district); *Trump v. Barbara* (2026: children born in the United States to parents who are unlawfully or temporarily present are citizens at birth under the Fourteenth Amendment).
  - Second Amendment: *New York State Rifle & Pistol Ass'n v. Bruen* (2022: text and historical tradition), *United States v. Rahimi* (2024: upheld the ban for persons under domestic-violence restraining orders), *Wolford v. Lopez* (2026: Hawaii's default ban on licensed carry on private property open to the public, without the owner's express permission, violates the Second Amendment) and *United States v. Hemani* (2026: the federal ban on gun possession by drug users was unconstitutional as applied without a showing of dangerousness or impairment).
  - Other: *Groff v. DeJoy* (2023: Title VII "undue hardship" means substantial increased costs); *Andy Warhol Foundation v. Goldsmith* (2023: fair use's first factor and a commercial licensing purpose); *Jack Daniel's Properties v. VIP Products* (2023: the *Rogers* test does not apply when a mark is used as a source identifier).
  - Exams: the LSAT has had two scored Logical Reasoning sections, one scored Reading Comprehension section and one unscored section since August 2024 (logic games are gone), scored 120–180, plus a separate unscored LSAT Argumentative Writing task; from August 2027 the unscored section is replaced by unscored questions embedded in three sections. The NextGen Uniform Bar Examination was first given in July 2026 in ten jurisdictions, more join in July 2027, nearly all UBE jurisdictions are scheduled to switch by July 2028, and the legacy UBE (MBE, MEE and MPT) runs through February 2028. The MPRE is a separate ethics exam of 60 multiple-choice questions in two hours (50 scored, 10 unscored pretest questions), scaled 50–150, with passing scores set by each jurisdiction (75 to 86); nearly all jurisdictions require it.
- **History, social studies and current issues.** Factual and neutral. Present major perspectives fairly, describe religions descriptively, and do not take sides on contested political questions.
- **Reading and writing.** Write your own passages and model essays. You may quote short passages from works published before 1929; never reproduce later copyrighted text.
- **Khan-style teaching:** intuition and a concrete case first, then the precise statement; short paragraphs; key results in display math or bold; worked examples whose steps each do one thing.
- **Science.** SI units, given values stated in the prompt, `unit:` and `tol: 1%` for numeric answers from data. Experiments only with safe household materials (no flames, heat sources, glassware or chemicals beyond kitchen items such as vinegar, baking soda and red cabbage); for anything else, use clearly labeled supplied data.
- **Course profile** (in your course JSON): T theory — standard mix of auto-graded items and a few `self`. W reading and writing — reading items on short original passages (`mc`, `ms`), concepts and vocabulary (`mc`), and `self` items for writing with clear rubrics; still at least 3 auto-graded items per lesson. J legal analysis — bar-style fact-pattern `mc` items, `ms` items on elements and claims, `num` items where the law involves numbers, and 1–2 `self` items per lesson for IRAC answers and rule statements. D drafting and advocacy — `self` items for drafting, writing and oral-advocacy tasks with model answers and rubrics, plus at least 3 auto-graded items per lesson on structure, rules and choices (for example which point heading is stronger, which clause is ambiguous, which rule governs a deadline).
- Each lesson's practice + quiz items include at least 3 auto-graded ones (not `self`).
- Where natural, one item in a block's second-week lesson exercises that block's deliverable (in your course JSON).
- Every item is self-contained: restate any data it needs. Never write "the previous problem", "the example above" or "as above" in an item, because items appear alone in practice sessions and exams.
- **reading:** name the part of the course's primary reading to study that week (a chapter, a rule or section such as "FRCP 12" or "UCC § 2-207", or an article title) only if you are confident it exists there; otherwise name the topic to look up in that resource. No URLs anywhere.
- Original wording only: do not reproduce casebook, outline, bar-review or LSAT passages or questions, or released exam questions.
- Week 7 is an ordinary lesson; the site schedules the midterm itself.

## project.txt

- `@project` — `title:`, `overview:` (2–3 sentences), `goal:` ×2–4, `step:` ×4–8 (a concrete plan), `deliverable:` ×2–4, `rubric:` ×3–6, optional `safety:`, `tutor:` ×2–3 (good questions to ask the AI tutor while doing the project). Base it on the syllabus project. Any "supplied" data, cases, sources or transcripts the project needs must be written out in `material:` fields (one per case, data set or source; markdown allowed), placed after the steps. Never put text after the `tutor:` lines: it would become part of the last tutor question.
- `@review` — markdown week-13 review guide: the course's key ideas week by week, a self-check list, and the most common errors. 250–600 words (elementary 120–300).
- `@exam <type>` ×3 — cumulative, multi-step final-exam problems that connect several weeks; at least one auto-graded; same fields and checks as practice items.

## Workflow

1. Read your course JSON and the example lesson, once each. Do not open any other file: not the site's checker, the validator, the toolkit scripts or other courses. Everything you need is in this brief. Do not run experiments before writing; write, then let the validator tell you what to fix.
2. If some of your lesson files already exist (you may be resuming), run the validator first and continue with the missing ones. Never rewrite a lesson that already passes.
3. Write two lessons per message (two Write calls), in week order, then project.txt. Do not read your files back after writing them.
4. After every four lessons, run `python3 /home/claude/law/toolkit/validate.py <CODE>` and fix every ERROR in the files you have written (ignore "file missing" for files you have not written yet). Fix errors with Edit, using the reported line numbers. When all files exist, rerun until it reports 0 errors.
5. Finish with a message of at most five lines: the validator result, the item count, any `nocheck` items, and any topic where you are unsure of accuracy. Do not paste lesson content.

Work only inside your course folder. Do not modify the toolkit, install packages or browse the web.

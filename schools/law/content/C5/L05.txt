@article
A firm turns inputs into output. To decide how much to produce, it needs to know what each level of output costs. The accounting that matters is **economic cost**: all opportunity costs, including the return the owner could have earned elsewhere on her own money and time.

### Short run and long run

In the **short run** at least one input (a factory, a lease) is fixed; in the **long run** all inputs can be changed. These are not calendar periods but descriptions of flexibility.

### Product and diminishing returns

The **marginal product** of labor is the extra output from one more worker, holding the fixed input constant. Beyond some point each added worker adds less than the previous one: this is the law of **diminishing marginal returns**. Imagine adding cooks to a single small kitchen; the first few help a lot and later ones get in each other's way. Diminishing returns is the reason marginal cost eventually rises with output.

### The cost concepts

| Concept | Definition |
|---|---|
| Fixed cost, $FC$ | Does not vary with output (paid even at zero output) |
| Variable cost, $VC$ | Varies with output |
| Total cost, $TC$ | $FC + VC$ |
| Marginal cost, $MC$ | Added cost of one more unit: $\Delta TC / \Delta Q$ |
| Average fixed cost, $AFC$ | $FC/Q$ |
| Average variable cost, $AVC$ | $VC/Q$ |
| Average total cost, $ATC$ | $TC/Q = AFC + AVC$ |

Marginal cost depends only on variable cost, since fixed cost does not change with output.

### The key relationship: marginal and average

Marginal cost pulls average cost toward itself, just as a new test score pulls a class average up or down:

- If $MC < ATC$, producing one more unit lowers $ATC$.
- If $MC > ATC$, producing one more unit raises $ATC$.
- So $MC$ crosses $ATC$ at the **minimum** of $ATC$, and likewise crosses $AVC$ at the minimum of $AVC$.

$AFC$ always falls as output rises, since a fixed amount is spread over more units. Together with rising $AVC$, this gives the typical U-shaped $ATC$ curve. For a smooth cost function like $TC = F + cQ + Q^2$, $MC = c + 2Q$ and the minimum of $ATC = F/Q + c + Q$ occurs where $MC = ATC$, that is $Q^* = \sqrt{F}$.

### Long-run costs and scale

In the long run the firm chooses its scale. The long-run average cost curve shows the lowest cost per unit for each output when all inputs are adjustable. **Economies of scale** (average cost falling as output rises) arise from specialization, spreading large fixed costs, and bulk purchasing; **diseconomies of scale** (average cost rising) arise from coordination and management problems. A **natural monopoly** exists when economies of scale are so large that one firm can supply the whole market at lower cost than two could, which is the cost-side reason some utilities are regulated. The lowest output at which long-run average cost is minimized is called the **minimum efficient scale**.

Finally, remember that **sunk costs** (expenditures that cannot be recovered) are fixed costs that are irrelevant to forward-looking decisions, a point the next lesson uses.

@example
title: Cost table and the minimum of average cost
problem: (a) A firm has fixed cost 60 and variable costs of 30, 50, 80, 120 and 170 at outputs 1 through 5. Find $TC$ and $MC$ for each output and $ATC$, $AVC$ and $AFC$ at $Q = 4$. (b) For $TC = 100 + 20Q + Q^2$, find the output that minimizes $ATC$ and the minimum value.
step: $TC = 60 + VC$ gives 90, 110, 140, 180 and 230 for outputs 1 to 5. Total cost at zero output is 60.
step: $MC$ is the change in $TC$: $30$ (from 60 to 90), $20$, $30$, $40$, $50$. At $Q = 4$: $ATC = 180/4 = 45$, $AVC = 120/4 = 30$, $AFC = 60/4 = 15$. Check: $30 + 15 = 45$.
step: For (b), $MC = 20 + 2Q$ and $ATC = 100/Q + 20 + Q$. Set $MC = ATC$: $20 + 2Q = 100/Q + 20 + Q$, so $Q = 100/Q$, $Q^2 = 100$ and $Q^* = 10$.
step: At $Q = 10$: $ATC = 10 + 20 + 10 = 40$, which equals $MC = 20 + 20 = 40$, confirming that marginal cost crosses average cost at its minimum.

@mistakes
- Including fixed cost in marginal cost; $MC$ reflects only how variable cost changes.
- Thinking $MC$ equals $ATC$ everywhere; they are equal only at the minimum of $ATC$.
- Saying average cost must rise whenever marginal cost rises; average cost keeps falling as long as $MC$ is below it.
- Dividing total cost by the wrong quantity when computing an average (for example using the previous output level).

answer: 55
check: (200 + 350) / 10
unit: dollars

@practice num
prompt: A firm's total cost is $TC = 150 + 8Q + 0.5Q^2$. Find its average variable cost at $Q = 20$ (in dollars per unit). Give an exact value.
answer: 18
check: (8 * 20 + 0.5 * 20**2) / 20
unit: dollars
hint: Variable cost is everything except the constant 150.

@practice num
prompt: A firm's total cost is $TC = 400 + Q^2$. At what output is average total cost minimized?
answer: 20
check: root(lambda q: 2*q - (400 + q**2)/q, 1, 100)
hint: Marginal cost equals average total cost at the minimum.
hint: $MC = 2Q$ and $ATC = 400/Q + Q$.
solution: $2Q = 400/Q + Q$ gives $Q^2 = 400$, so $Q = 20$. There $ATC = 20 + 20 = 40 = MC$.

@quiz num
prompt: A firm's total cost is $TC = 324 + 7Q + Q^2$. At what output is average total cost minimized?
answer: 18
check: root(lambda q: (7 + 2*q) - (324 + 7*q + q**2)/q, 1, 100)
hint: Set marginal cost equal to average total cost.
hint: $7 + 2Q = 324/Q + 7 + Q$.
solution: $MC = 7 + 2Q$ and $ATC = 324/Q + 7 + Q$. Equating gives $Q = 324/Q$, so $Q = 18$. Check: $ATC = 18 + 7 + 18 = 43 = MC$.

@quiz mc

choice: Average total cost has risen above \$15.
choice: Average total cost is still exactly \$15.
choice*: Average total cost has fallen below \$15, to \$14.50.

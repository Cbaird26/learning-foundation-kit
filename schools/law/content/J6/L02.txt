@article
The **periodic table** arranges all known elements in order of increasing atomic number. Its shape is not an accident: elements in the same column behave in similar ways, and the table lets you predict that behavior.

### Periods and groups

A horizontal row is a **period**. A vertical column is a **group** (or family). Each box shows the element's symbol, name and atomic number, and usually its average atomic mass. Hydrogen is $1$, helium is $2$, lithium is $3$, and so on, reading left to right and row by row.

### Metals, nonmetals and metalloids

Most elements are **metals**. They are shiny, conduct heat and electricity well, and can be hammered or drawn into wire. **Nonmetals**, on the right side of the table, are usually dull and poor conductors. **Metalloids**, such as silicon, lie along the staircase line between them and have properties of both.

### Electron shells and valence electrons

Electrons sit in **shells** around the nucleus. The first shell holds up to $2$ electrons, the second holds up to $8$, and the third holds up to $8$ for the first 18 elements. Electrons fill the inner shells first.

The electrons in the outermost shell are the **valence electrons**. They decide how an atom bonds with other atoms. For main-group elements:

- The **period number** equals the number of occupied shells.
- For the tall groups numbered $1$, $2$ and $13$ to $18$, the number of valence electrons is $1$, $2$, and then the group number minus $10$ (so group 16 has $6$).

Elements in the same group have the same number of valence electrons, which is why they react alike. The **alkali metals** in group 1 each have one valence electron and react strongly with water. The **halogens** in group 17 each have seven. The **noble gases** in group 18 have full outer shells (helium has $2$, the others $8$), so they rarely react.

### Reading an atom from its place

Suppose an element has atomic number $6$. Then a neutral atom has $6$ electrons: $2$ in the first shell and $4$ in the second. It has two shells, so it is in period $2$, and it has $4$ valence electrons, so it is in group $14$. This is carbon.

@example
title: Placing an atom on the table
problem: A neutral atom has $12$ electrons. How many shells does it use, how many valence electrons does it have, and which period and group is it in?
step: Fill the shells in order: $2$ in the first, $8$ in the second. That leaves $12 - 2 - 8 = 2$ electrons for the third shell.
step: Three shells are occupied, so the atom is in period $3$.
step: The outer shell has $2$ electrons, so there are $2$ valence electrons and the atom is in group $2$.
step: This is magnesium, a metal that behaves like calcium, which is also in group $2$.

@mistakes
- Counting all the electrons instead of only the outermost ones when finding valence electrons.
- Mixing up periods and groups. Periods are rows (shells); groups are columns (similar behavior).
- Placing the atom by its mass number instead of its atomic number. The table is ordered by atomic number.
- Forgetting that the second shell holds up to $8$ electrons, not $2$.

answer: 13
check: 2 + 8 + 3
hint: A neutral atom has as many protons as electrons, and the atomic number is the number of protons.
hint: Add up the electrons in all the shells.
solution: $2 + 8 + 3 = 13$ electrons, so there are $13$ protons and the atomic number is $13$ (aluminum).

@practice mc
prompt: Lithium, sodium and potassium all react vigorously with water. Why do these elements behave so similarly?
choice: They have the same number of protons.
choice: They are all in the same period.
choice*: They are in the same group and have one valence electron each.
choice: They have the same mass number.
hint: Think about which electrons control how an atom reacts.
solution: These three elements are in group $1$, so each has a single valence electron. The valence electrons decide how an atom reacts. Their numbers of protons and mass numbers are different, and they sit in different periods.

@practice num
prompt: An element is in period $2$ and group $16$. Counting the $2$ electrons in the first shell and the valence electrons in the second, what is its atomic number?
answer: 8
check: 2 + (16 - 10)
hint: Group $16$ has $16 - 10$ valence electrons.
hint: Add the $2$ inner electrons to the valence electrons.
solution: Group $16$ has $6$ valence electrons. Total electrons $= 2 + 6 = 8$, so the atomic number is $8$ (oxygen).

@article
A **system of equations** is a set of equations that must all be true at the same time. A **solution** is a pair of values $(x, y)$ that makes every equation true. Each linear equation in $x$ and $y$ describes a line, so a solution is a point lying on both lines: **where the lines cross**.

### Start with a story

A cinema sold $100$ tickets. Adult tickets cost 8 dollars each, child tickets cost 5 dollars each, and the takings were 680 dollars. How many of each? Let $a$ be the number of adult tickets and $c$ the number of child tickets:

$$a + c = 100, \qquad 8a + 5c = 680.$$

One equation is about counting tickets, the other about money. Neither alone pins down $a$ and $c$, but together they do.

### Method 1: graph

Draw both lines and read off the crossing point. This shows you what a solution **is**, but a graph is only as accurate as your drawing, so use it as a picture and a rough check rather than for exact answers.

### Method 2: substitution

Solve one equation for one variable, then substitute into the other so that only one unknown remains. From $a + c = 100$ we get $c = 100 - a$, so

$$8a + 5(100 - a) = 680 \;\Rightarrow\; 3a + 500 = 680 \;\Rightarrow\; a = 60,$$

and then $c = 100 - 60 = 40$. Substitution is best when a variable already has coefficient $1$ or stands alone.

### Method 3: elimination

Add or subtract the equations so that one variable cancels. For $x + y = 9$ and $x - y = 3$, adding gives $2x = 12$, so $x = 6$, and then $y = 3$. If nothing cancels at first, multiply one or both equations (every term!) so that the coefficients of one variable become opposites.

### Three possible outcomes

- **One solution:** the lines have different slopes and cross once.
- **No solution:** the lines are parallel (same slope, different intercepts). The algebra ends in a false statement such as $0 = 5$.
- **Infinitely many solutions:** both equations describe the same line. The algebra ends in a true statement such as $0 = 0$.

### Always check in both equations

For the cinema: $60 + 40 = 100$ and $8(60) + 5(40) = 480 + 200 = 680$. A pair that fits only one equation is not a solution of the system.

@example
title: Solving by substitution
problem: Solve $2x + 3y = 13$ and $4x - y = 5$.
step: The second equation is easy to solve for $y$: $y = 4x - 5$.
step: Substitute into the first equation: $2x + 3(4x - 5) = 13$.
step: Expand and combine: $2x + 12x - 15 = 13$, so $14x = 28$ and $x = 2$.
step: Back-substitute to find $y$: $y = 4(2) - 5 = 3$.
step: Check in both original equations: $2(2) + 3(3) = 13$ and $4(2) - 3 = 5$. The solution is $(2, 3)$.

@example
title: Solving by elimination
problem: Solve $2x + 3y = 12$ and $3x - 2y = 5$.
step: Eliminate $y$. The $y$-coefficients are $3$ and $-2$, with common multiple $6$. Multiply the first equation by $2$ and the second by $3$, every term: $4x + 6y = 24$ and $9x - 6y = 15$.
step: Add the two equations. The $y$-terms cancel: $13x = 39$.
step: Divide by $13$: $x = 3$.
step: Substitute into the first original equation: $2(3) + 3y = 12$, so $3y = 6$ and $y = 2$.
step: Check in the second original equation, the one you did not use to find $y$: $3(3) - 2(2) = 5$. The solution is $(3, 2)$.

@mistakes
- Multiplying only some terms of an equation when scaling it for elimination.
- Subtracting one equation from another and forgetting that the minus sign applies to every term of the second one.
- Checking the answer in only one equation.
- Stopping after finding $x$ and never finding $y$.

@practice mc
prompt: How many solutions does the system $2x - 4y = 6$ and $x - 2y = 5$ have?
choice*: None, because the lines are parallel
choice: Exactly one
choice: Infinitely many, because the lines coincide
choice: Exactly two
hint: Divide the first equation by $2$ and compare it with the second.
hint: The first equation becomes $x - 2y = 3$. Can $x - 2y$ equal both $3$ and $5$?
solution: The first equation says $x - 2y = 3$ and the second says $x - 2y = 5$. The same quantity cannot equal both, so there is no solution. Both lines have slope $\frac{1}{2}$ but different intercepts, so they are parallel.

@practice self
prompt: Solve the system $y = 2x - 1$ and $x + y = 8$ in two ways. (a) On graph paper, draw both lines and read off the crossing point. (b) Solve algebraically by substitution and check your answer in both equations. Then compare: do the two results agree, and why might a hand-drawn graph give a slightly different answer for other systems?
hint: For the graph, plot the $y$-intercept and use the slope for the first line, and find the intercepts for the second line.
hint: For the algebra, substitute $y = 2x - 1$ into $x + y = 8$.
solution: (a) The first line passes through $(0, -1)$, $(1, 1)$, $(2, 3)$, $(3, 5)$. The second line passes through $(0, 8)$ and $(8, 0)$, and also $(3, 5)$. The lines cross at $(3, 5)$. (b) Substituting: $x + 2x - 1 = 8$, so $3x = 9$, $x = 3$ and $y = 5$. Check: $2(3) - 1 = 5$ and $3 + 5 = 8$. The two results agree. Here the crossing falls exactly on grid lines, so it can be read exactly; if the crossing were at non-integer coordinates, a hand drawing could only give an estimate, while the algebra stays exact.
rubric: Both lines are drawn correctly (for example from intercepts or slope) and the crossing point is read as $(3, 5)$.
rubric: The substitution is done correctly, giving $x = 3$ and $y = 5$.
rubric: The solution is checked in both original equations.
rubric: The comparison says the results agree and explains that a graph is limited by drawing accuracy while algebra is exact.

@quiz num
prompt: A coffee shop sells small cups for \$3 and large cups for \$4.50. One morning it sold $40$ cups and took in \$150. How many large cups did it sell?
answer: 20
check: lin([[1, 1], [3, 4.5]], [40, 150])[1]
hint: Let $s$ be small cups and $l$ be large cups. Write one equation for the number of cups and one for the money.
hint: $s + l = 40$ and $3s + 4.5l = 150$. Replace $s$ by $40 - l$ in the second equation.
solution: $3(40 - l) + 4.5l = 150$ gives $120 + 1.5l = 150$, so $l = 20$ (and $s = 20$). Check: $20(3) + 20(4.5) = 60 + 90 = 150$.

@quiz num
prompt: For what value of $k$ does the system $x + 2y = 5$ and $3x + ky = 15$ have infinitely many solutions?
answer: 6
check: root(lambda k: det([[1, 2], [3, k]]), -100, 100)
hint: Infinitely many solutions means both equations describe the same line, so one is a multiple of the other.
hint: What do you multiply $x + 2y = 5$ by to turn the $x$ into $3x$? Check that the right side then becomes $15$.
solution: Multiplying the first equation by $3$ gives $3x + 6y = 15$, which matches the second equation exactly when $k = 6$. Then both equations describe the same line.

objective: Evaluate expressions using the order of operations.
objective: Write an algebraic expression from a word description.

@article
An **expression** is a combination of numbers, variables and operations, such as $3x + 2$. It has no equals sign. A **variable** is a letter standing for a number that can change.

### The order of operations

When an expression has several operations, everyone must compute in the same order, or the same expression would have different values. The order is:

1. **Parentheses** (and other grouping symbols).
2. **Exponents**, such as $2^3 = 2 \times 2 \times 2 = 8$.
3. **Multiplication and division**, left to right.
4. **Addition and subtraction**, left to right.

So $3 + 4 \times 2^2 = 3 + 4 \times 4 = 3 + 16 = 19$. The multiplication happens before the addition.

### Evaluating with a variable

To **evaluate** an expression, replace each variable by its value (put it in parentheses) and then follow the order of operations. If $x = 5$, then $3x + 2 = 3(5) + 2 = 17$.

### Writing expressions from words

Key phrases translate into operations. "Twice $n$" is $2n$. "$5$ more than $n$" is $n + 5$. "$5$ less than $n$" is $n - 5$. So "$5$ more than twice $n$" is $2n + 5$. Costs work the same way: $p$ pencils at \$0.25 each cost $0.25p$ dollars.

### The distributive property

Multiplication distributes over addition:

$$a(b + c) = ab + ac.$$

So $3(x + 4) = 3x + 12$. Both sides have the same value for every $x$, so the expressions are **equivalent**. Test it: if $x = 2$, $3(6) = 18$ and $3(2) + 12 = 18$.

### Parts of an expression

A **term** is a piece separated by plus or minus signs. In $3x + 12$ the terms are $3x$ and $12$. The **coefficient** is the number multiplying a variable: $3$ in $3x$. A **constant** is a term with no variable.

@example
title: Evaluate with several operations
problem: Evaluate $5 + 2(7 - 3)^2 \div 8$.
step: Parentheses first: $7 - 3 = 4$, so the expression is $5 + 2 \cdot 4^2 \div 8$.
step: Exponent next: $4^2 = 16$, giving $5 + 2 \cdot 16 \div 8$.
step: Multiply and divide left to right: $2 \cdot 16 = 32$, then $32 \div 8 = 4$.
step: Add: $5 + 4 = 9$.

@mistakes
- Adding before multiplying, such as computing $3 + 4 \times 2$ as $7 \times 2$.
- Treating $3x$ as $3 + x$; it means $3$ times $x$.
- Distributing to only the first term: $3(x + 4)$ is not $3x + 4$.

@practice num
prompt: Evaluate $3 + 4 \times 2^2$.
answer: 19
check: 3 + 4 * 2**2
hint: Exponents come before multiplication.
hint: $2^2 = 4$. Then multiply by $4$, then add $3$.
solution: $3 + 4 \times 4 = 3 + 16 = 19$.

@practice num
prompt: Evaluate $3x + 2$ when $x = 5$.
answer: 17
check: 3 * 5 + 2
hint: Replace $x$ with $5$.
hint: $3(5)$ means $3$ times $5$.
solution: $3(5) + 2 = 15 + 2 = 17$.

@practice expr
prompt: Write an expression for "5 more than twice $n$".
vars: n
answer: 2n + 5
check: lambda n: 2 * n + 5
hint: "Twice $n$" comes first.
hint: Twice $n$ is $2n$; "5 more" means add $5$.
solution: Twice $n$ is $2n$, and $5$ more is $2n + 5$.

@practice mc
prompt: Which expression is equivalent to $3(x + 4)$?
choice*: $3x + 12$
choice: $3x + 4$
choice: $x + 12$
choice: $3x + 7$
hint: The $3$ multiplies every term in the parentheses.
hint: Compute $3 \cdot x$ and $3 \cdot 4$.
solution: $3(x + 4) = 3x + 12$. Writing $3x + 4$ distributes to only the first term.

@practice num
prompt: Evaluate $2(a + 3b) - c^2$ when $a = 4$, $b = 1$ and $c = 3$.
answer: 5
check: 2 * (4 + 3 * 1) - 3**2
hint: Substitute the values, keeping parentheses.
hint: $2(4 + 3) - 3^2$. Compute the parentheses and the exponent first.
solution: $2(4 + 3) - 9 = 14 - 9 = 5$.

@quiz num
prompt: Evaluate $(18 - 6) \div 3 + 2 \times 5$.
answer: 14
check: (18 - 6) / 3 + 2 * 5
hint: Work inside the parentheses first.
hint: $12 \div 3 = 4$ and $2 \times 5 = 10$.
solution: $12 \div 3 + 10 = 4 + 10 = 14$.

@quiz expr
prompt: A school sells pencils for \$0.40 each and an eraser for \$3. Write an expression for the total cost, in dollars, of $p$ pencils and one eraser.
vars: p
answer: 0.4p + 3
check: lambda p: 0.40 * p + 3
hint: The pencil cost depends on $p$, the eraser cost does not.
hint: Cost of pencils plus cost of the eraser.
solution: The pencils cost $0.40p$ dollars and the eraser costs $3$, so the total is $0.40p + 3$.

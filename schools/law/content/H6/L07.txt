@article
A **random variable** $X$ assigns a number to each outcome of a chance process: the number of patients out of ten who respond, the number of emergency visits next month. A **discrete** random variable takes separate values (usually counts); a continuous one takes any value in an interval (like a blood pressure).

### Probability distributions

The **probability distribution** of a discrete $X$ lists each possible value $x$ and its probability $P(X = x)$. Two conditions must hold: each probability is between $0$ and $1$, and the probabilities sum to $1$. A missing probability can therefore be found by subtraction.

### Expected value and spread

The **expected value** (mean) of $X$ is the long-run average over many repetitions:

$$\mu_X = E(X) = \sum x\,P(X = x).$$

The **variance** is the average squared deviation from the mean, and the **standard deviation** is its square root:

$$\sigma_X^2 = \sum (x - \mu_X)^2\,P(X = x) = E(X^2) - \mu_X^2, \qquad \sigma_X = \sqrt{\sigma_X^2}.$$

Here the divisor is built into the probabilities, so the sample-versus-population issue from week 2 does not arise: these are properties of a probability distribution, not of a sample. The expected value need not be a possible value of $X$; the average of many dice rolls is $3.5$ though no roll gives $3.5$.

### Linear transformations

If $Y = a + bX$, then
$$\mu_Y = a + b\mu_X, \qquad \sigma_Y = |b|\,\sigma_X.$$
Adding a constant shifts the center but not the spread; multiplying by $b$ scales both (the spread by $|b|$, never by a negative number).

### Combining random variables

For any random variables, **means add**: $E(X + Y) = \mu_X + \mu_Y$ and $E(X - Y) = \mu_X - \mu_Y$. For **independent** variables, **variances add**, whether we add or subtract the variables:

$$\sigma_{X \pm Y}^2 = \sigma_X^2 + \sigma_Y^2, \qquad \sigma_{X \pm Y} = \sqrt{\sigma_X^2 + \sigma_Y^2}.$$

Standard deviations do not add directly: two independent measurements with standard deviations $3$ and $4$ combine to $\sqrt{9 + 16} = 5$, not $7$. Variability accumulates, but partly cancels.

@example
title: Emergency visits
problem: The number $X$ of emergency visits by a patient next month has $P(0) = 0.50$, $P(1) = 0.30$, $P(2) = 0.15$ and $P(3) = 0.05$. Find the mean and standard deviation.
step: The probabilities sum to $1$, so this is a valid distribution.
step: $\mu = 0(0.50) + 1(0.30) + 2(0.15) + 3(0.05) = 0.75$ visits.
step: $E(X^2) = 0 + 1(0.30) + 4(0.15) + 9(0.05) = 1.35$, so $\sigma^2 = 1.35 - 0.75^2 = 0.7875$.
step: $\sigma = \sqrt{0.7875} \approx 0.887$ visits.

@example
title: A transformed variable
problem: A clinic charges $\$40$ per visit plus a flat fee of $\$25$. If $X$ is the number of visits, with $\mu_X = 0.75$ and $\sigma_X = 0.887$, find the mean and SD of the total cost $C = 25 + 40X$.
step: $\mu_C = 25 + 40(0.75) = 55$ dollars.
step: $\sigma_C = 40(0.887) \approx 35.5$ dollars. The flat fee adds nothing to the spread.

@mistakes
- Adding standard deviations instead of variances when combining independent variables.
- Subtracting variances for $X - Y$; variances add even when the variables are subtracted.
- Forgetting that a negative multiplier $b$ gives $\sigma_Y = |b|\sigma_X$, never a negative spread.
- Using a distribution whose probabilities do not sum to $1$.

@practice num
prompt: A random variable $X$ takes the values $0, 1, 2, 3$ with probabilities $0.35, 0.25, 0.10$ and $k$. Find $k$.
answer: 0.3
check: 1 - (0.35 + 0.25 + 0.10)
tol: 0.001
hint: The probabilities of a valid distribution sum to $1$.
solution: $k = 1 - (0.35 + 0.25 + 0.10) = 0.30$.

@practice num
prompt: $X$ takes the values $1, 2, 3, 4$ with probabilities $0.1, 0.2, 0.3, 0.4$. Find the expected value $E(X)$.
answer: 3
check: 1 * 0.1 + 2 * 0.2 + 3 * 0.3 + 4 * 0.4
tol: 0.001
hint: Multiply each value by its probability and add.
solution: $0.1 + 0.4 + 0.9 + 1.6 = 3.0$.

@practice num
prompt: $X$ takes the values $0, 1, 2$ with probabilities $0.5, 0.3, 0.2$. Find the standard deviation of $X$, rounded to three decimal places.
answer: 0.781
check: sqrt((0**2 * 0.5 + 1**2 * 0.3 + 2**2 * 0.2) - (0 * 0.5 + 1 * 0.3 + 2 * 0.2)**2)
tol: 0.005
hint: First find the mean, then $E(X^2)$.
hint: $\mu = 0.7$ and $E(X^2) = 1.1$. Variance is $E(X^2) - \mu^2$.
solution: $\mu = 0.3 + 0.4 = 0.7$ and $E(X^2) = 0.3 + 0.8 = 1.1$. $\sigma^2 = 1.1 - 0.49 = 0.61$ and $\sigma = \sqrt{0.61} \approx 0.781$.

@practice num
prompt: A variable $X$ has mean $4$ and standard deviation $1.5$. Let $Y = 3X - 2$. Find the standard deviation of $Y$.
answer: 4.5
check: abs(3) * 1.5
tol: 0.001
hint: Adding a constant does not change the spread; multiplying by $b$ multiplies it by $|b|$.
solution: $\sigma_Y = |3|(1.5) = 4.5$. The "$-2$" shifts the mean (to $10$) but does not affect the standard deviation.

@practice num
prompt: Two independent measurements $X$ and $Y$ have standard deviations $3$ and $4$ (in the same units). Find the standard deviation of $X + Y$.
answer: 5
check: sqrt(3**2 + 4**2)
tol: 0.001
hint: Variances add for independent variables, not standard deviations.
solution: $\sigma^2 = 9 + 16 = 25$, so $\sigma = 5$.

@quiz num
prompt: The number of days $X$ a patient stays after a minor procedure is $10$ with probability $0.2$, $20$ with probability $0.5$ and $30$ with probability $0.3$ (an invented model). Find the expected value of $X$.
answer: 21
check: 10 * 0.2 + 20 * 0.5 + 30 * 0.3
tol: 0.001
hint: Weight each value by its probability.
solution: $2 + 10 + 9 = 21$.

@quiz mc
prompt: $X$ and $Y$ are independent with variances $\sigma_X^2$ and $\sigma_Y^2$. What is the variance of $X - Y$?
choice*: $\sigma_X^2 + \sigma_Y^2$
choice: $\sigma_X^2 - \sigma_Y^2$
choice: $(\sigma_X - \sigma_Y)^2$
choice: $\sigma_X + \sigma_Y$
hint: Does subtracting a variable make the outcome more predictable or more variable?
solution: For independent variables variances add whether we add or subtract the variables, so $\text{Var}(X - Y) = \sigma_X^2 + \sigma_Y^2$.

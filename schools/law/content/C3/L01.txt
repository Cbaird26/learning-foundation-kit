@article
Philosophy is the disciplined study of questions that cannot be settled by a laboratory experiment or a lookup in a reference book: What can we know? What is a person? What do we owe each other? Its tools are **concepts, arguments and thought experiments**, and its habit is to ask "why should I believe that?" until a claim rests on reasons you can state.

The main branches you will meet in this course are **epistemology** (knowledge and justification), **metaphysics** (what exists: minds, persons, free will), **ethics** (right and wrong, good and bad) and **political philosophy** (authority, justice, punishment). **Logic** runs through all of them.

### Arguments

In ordinary speech an argument is a quarrel. In philosophy an **argument** is a set of statements in which some, the **premises**, are offered as reasons for another, the **conclusion**. Words such as *because*, *since* and *given that* often flag premises; *therefore*, *so* and *it follows that* often flag a conclusion. Only statements that can be true or false count: questions and commands are not premises.

A **deductive** argument aims at certainty: if the premises are true, the conclusion must be. An **inductive** argument aims only at probability; it is **strong** when true premises would make the conclusion likely, and **cogent** when it is strong and the premises are in fact true.

### Validity and soundness

An argument is **valid** when it is impossible for all the premises to be true and the conclusion false. Validity concerns *form*, not truth. An argument is **sound** when it is valid and all its premises are true. A valid argument may have a false conclusion, but only if at least one premise is false.

| Form | Pattern | Status |
|---|---|---|
| Modus ponens | If $P$ then $Q$; $P$; so $Q$ | valid |
| Modus tollens | If $P$ then $Q$; not $Q$; so not $P$ | valid |
| Affirming the consequent | If $P$ then $Q$; $Q$; so $P$ | invalid |
| Denying the antecedent | If $P$ then $Q$; not $P$; so not $Q$ | invalid |

To test validity, try to imagine a case where the premises are true and the conclusion false. If you can, the argument is invalid.

### Common fallacies

- **Equivocation**: a key word changes meaning between premises.
- **Begging the question**: the conclusion is assumed in a premise.
- **Straw man**: attacking a weaker version of the opponent's view.
- **Ad hominem**: attacking the speaker instead of the reasons.

### Charity and reconstruction

When you restate someone's argument, use the **principle of charity**: choose the strongest reasonable reading, and supply an unstated premise only if the author would plausibly accept it. Then number the premises, state the conclusion, and test the result. This is the core method of the course. It is also the core skill behind the LSAT's Logical Reasoning sections (two are scored; since August 2024 the test has one scored Reading Comprehension section and no logic games) and behind reading judicial opinions, where you must separate a court's reasons from its holding.

### Thought experiments

A **thought experiment** is an imagined case built to isolate one factor. If a principle gives an absurd verdict in the case, that counts against the principle. Philosophers also seek **reflective equilibrium**: adjusting principles and case judgments against each other until they cohere.

title: Reconstructing and testing an argument
problem: Reconstruct this passage with numbered premises and test it: "Anyone who breaks a promise for convenience acts wrongly. Dara skipped her friend's recital only because she preferred to stay home, so she acted wrongly."
step: Find the conclusion. The word "so" flags it: C. Dara acted wrongly.
step: List the stated premises. P1. Anyone who breaks a promise for convenience acts wrongly. P2. Dara skipped her friend's recital only because she preferred to stay home.
step: Notice the missing premise. The argument needs P3, that Dara had promised to attend. Charity supplies it only if the passage implies a promise; flag it as an assumption.
step: Test the form. With P3 added: all promise-breakers-for-convenience are wrong; Dara is one; so Dara is wrong. This is valid.
step: Judge soundness. Validity does not make it sound; the argument is sound only if P1 is true, and a critic could attack P1 by describing a trivial promise.
@mistakes
- Treating a valid argument as a good argument: validity says nothing about whether the premises are true.
- Calling an argument "invalid" because you reject its conclusion, instead of finding a possible case with true premises and a false conclusion.
- Attacking a weak version of a view (a straw man) instead of reconstructing the strongest one.

@article
Last week you learned to find arguments. This week you learn the two basic ways to evaluate a **deductive** argument, one meant to guarantee its conclusion.

### Validity

An argument is **valid** when it is impossible for all the premises to be true while the conclusion is false. Equivalently: if the premises were true, the conclusion would have to be true. Validity is about the *connection* between premises and conclusion, not about whether anything is actually true.

Here is a valid argument with false premises:

1. All judges are astronauts.
2. Alice is a judge.
3. Therefore, Alice is an astronaut.

If the premises were true, the conclusion could not fail. The argument is valid, though the first premise is false. Here is an invalid argument with true premises and a true conclusion:

1. Some lawyers are tall.
2. Some tall people are athletes.
3. Therefore, some lawyers are athletes.

The conclusion might be true, but the premises do not guarantee it, so the argument is invalid.

### Soundness

An argument is **sound** when it is valid *and* all its premises are true. A sound argument must have a true conclusion. An argument can fail to be sound in two ways: a bad form (invalid) or a false premise. Calling an argument "unsound" tells you at least one failure occurred, not which.

| Valid? | All premises true? | Verdict |
|---|---|---|
| yes | yes | sound (conclusion true) |
| yes | no | valid but unsound |
| no | yes or no | invalid (so unsound) |

The only combination validity forbids is **true premises with a false conclusion**. Every other mix of truth values can occur in a valid argument.

### Counterexample method

To show an argument is invalid, build a **counterexample**: a situation (or another argument of the same form) in which the premises are clearly true and the conclusion clearly false. For "If it is a dog, it is a mammal; it is a mammal; so it is a dog," swap in a cat: the premises hold, the conclusion fails. Same form, so the form is invalid. Failing to find a counterexample does not prove validity; you need a reason, which truth tables and proofs will give us.

### Strength and cogency

Many good arguments are **inductive**: the premises make the conclusion probable, not certain. We call such an argument **strong** if the premises, assumed true, make the conclusion highly probable, and **weak** otherwise; it is **cogent** if it is strong and the premises are actually true. Strength comes in degrees, validity does not. Premises combine, too: if each of three independent premises is only 90% likely, all are true together with probability $0.9^3 = 0.729$. Long chains of plausible steps can be shaky.

@example
title: Valid, sound, both, or neither?
problem: Classify: "(1) All birds can fly. (2) Penguins are birds. (3) So penguins can fly."
step: Test validity: suppose both premises were true. Penguins are birds, and all birds fly, so penguins fly. The conclusion follows, so the argument is valid.
step: Test soundness: is premise 1 true? No. Penguins are birds that cannot fly, so "all birds can fly" is false.
step: Verdict: valid but unsound. Its conclusion is also false, which shows that a valid argument with a false premise can have a false conclusion.

@example
title: Building a counterexample
problem: Show that "Every senator is a politician. Dana is a politician. So Dana is a senator" is invalid.
step: Keep the form: Every S is P; Dana is P; so Dana is S.
step: Substitute: Every dog is a mammal; Rex's owner is a mammal; so Rex's owner is a dog. The premises are true and the conclusion is false.
step: Since a same-form argument has true premises and a false conclusion, the form is invalid and so is the original.

@mistakes
- Saying an argument is invalid because a premise is false. Validity ignores the actual truth of the premises.
- Saying an argument is valid because its conclusion happens to be true.
- Thinking that a valid argument must have a true conclusion. It does only when it is also sound.
- Applying "valid" to single statements. Statements are true or false; arguments are valid or invalid.

@article
A **truth table** lists every way the sentence letters can be true or false and computes the value of a compound sentence in each case. It is the first fully mechanical test of validity you will use.

### Building a table

With $n$ sentence letters there are $2^n$ **rows**: two letters give 4 rows, three give 8, four give 16. List the letters' values systematically (for two letters: TT, TF, FT, FF) so no row is missed or repeated. Then add a column for each subformula, working from the inside out, and finish with the main connective.

| $P$ | $Q$ | $P \to Q$ |
|---|---|---|
| T | T | T |
| T | F | F |
| F | T | T |
| F | F | T |

### Classifying sentences

A sentence is a **tautology** if it is true in every row ($P \lor \neg P$), a **contradiction** if false in every row ($P \land \neg P$), and **contingent** otherwise. Two sentences are **equivalent** if they have the same value in every row; De Morgan's laws can be verified this way.

### Testing validity

An argument form is **valid** if no row makes all premises true and the conclusion false. So the method is:

1. Put the premises and the conclusion in columns of one table.
2. Find every row in which all the premises are true.
3. If the conclusion is also true in each of those rows, the form is valid. If some such row has a false conclusion, that row is a **counterexample** and the form is invalid.

You only need to *find* one counterexample to show invalidity; you must check every row to show validity. Rows where a premise is false do not matter.

### Four conditional forms to know

- **Modus ponens:** $P \to Q$, $P$; therefore $Q$. Valid.
- **Modus tollens:** $P \to Q$, $\neg Q$; therefore $\neg P$. Valid.
- **Affirming the consequent:** $P \to Q$, $Q$; therefore $P$. Invalid (counterexample: $P$ false, $Q$ true).
- **Denying the antecedent:** $P \to Q$, $\neg P$; therefore $\neg Q$. Invalid (counterexample: $P$ false, $Q$ true).

Also valid: **disjunctive syllogism** ($P \lor Q$, $\neg P$; therefore $Q$) and **hypothetical syllogism** ($P \to Q$, $Q \to R$; therefore $P \to R$).

### Shortcuts

Full tables get long (five letters give 32 rows). A shortcut is to try to *force* a counterexample: set the conclusion false, then see whether the premises can all be made true. If this is impossible, the form is valid. This is the truth-table version of the counterexample method from Week 2.

### Limits

Truth tables test only the form of sentences *as built from whole sentences*. They cannot see inside "All lawyers are literate," which is why Week 8 introduces predicate logic.

@example
title: Testing a form with a truth table
problem: Test the form: $P \lor Q$, $\neg P$; therefore $Q$.
step: List the four combinations of values for $P$ and $Q$: TT, TF, FT, FF. Compute $P \lor Q$ and $\neg P$ in each row.
step: Row TT: premises $T, F$ (not all true). Row TF: $T, F$ (no). Row FT: $T, T$ and the conclusion $Q$ is T. Row FF: $F, T$ (no).
step: The only row with all premises true is FT, and there $Q$ is true. No counterexample exists, so the form is valid (disjunctive syllogism).

@example
title: Finding a counterexample row
problem: Test the form: $P \to Q$, $Q \to R$; therefore $R \to P$.
step: Try to force invalidity. Make the conclusion false: $R$ true, $P$ false.
step: Now make the premises true. With $P$ false, $P \to Q$ is true whatever $Q$ is. With $R$ true, $Q \to R$ is true whatever $Q$ is. Take $Q$ true.
step: The row $P = F$, $Q = T$, $R = T$ has true premises and a false conclusion, so the form is invalid.

@mistakes
- Skipping rows or listing letter combinations unsystematically.
- Counting rows where a premise is false as evidence of invalidity (or validity). Only rows with all premises true matter.
- Concluding that a form is valid after checking only some rows.
- Treating the conditional as false when its antecedent is false.

@quiz num
prompt: In how many rows of a complete table for three letters is $(P \lor Q) \to R$ false?
answer: 3
check: sum(1 for p in (True, False) for q in (True, False) for r in (True, False) if (p or q) and not r)
hint: A conditional is false only when the antecedent is true and the consequent is false.
hint: Count rows with $R$ false and at least one of $P$, $Q$ true.
solution: We need $R$ false and $P \lor Q$ true. With $R$ false, the pairs $(P, Q)$ that make $P \lor Q$ true are TT, TF, FT: 3 rows.

@article
A **function** is a rule that assigns to every allowed input exactly one output. We write $y = f(x)$: $x$ is the input and $f(x)$ is the output. The set of allowed inputs is the **domain**; the set of outputs that actually occur is the **range**. On a graph, the *vertical line test* checks the "exactly one" condition: no vertical line may cross the graph twice.

### Why families matter

Calculus and physics keep reusing a small set of shapes. Instead of treating every formula as brand new, ask first: **which family is this?** The family tells you the shape of the graph, the domain, how fast the function grows and what happens at the ends.

| Family | Typical form | Domain | Fingerprint |
|---|---|---|---|
| Linear | $mx + b$ | all reals | constant first differences |
| Quadratic | $ax^2 + bx + c$ | all reals | constant second differences |
| Polynomial | $a_n x^n + \dots + a_0$ | all reals | smooth, no breaks or gaps |
| Rational | $p(x)/q(x)$ | $q(x) \neq 0$ | often vertical asymptotes; may have a horizontal or slant asymptote |
| Radical | $\sqrt{x}$ | $x \ge 0$ | starts at a point, grows slowly |
| Exponential | $ab^x$, $b > 0$, $b \neq 1$ | all reals | constant ratios |
| Logarithmic | $\log_b x$ | $x > 0$ | vertical asymptote at $x = 0$ |
| Trigonometric | $\sin x$, $\cos x$ | all reals | repeats with a fixed period |

### Fingerprints in tables

Suppose you are given outputs at equally spaced inputs $x = 0, 1, 2, \dots$ Three quick tests separate the common cases.

- **Constant first differences**, meaning $f(x+1) - f(x)$ is the same every time, means **linear**.
- **Constant second differences** (differences of the differences) means **quadratic**. With step $1$ the second difference equals $2a$.
- **Constant ratios**, meaning $f(x+1)/f(x)$ is the same every time, means **exponential**, and the ratio is the base $b$.

"Grows fast" is not the test. The outputs $1, 4, 9, 16, 25$ speed up, yet their second differences are constant, so they are quadratic and not exponential.

### Domain from a formula

Start with all real numbers and remove whatever breaks the formula:

- a denominator equal to $0$;
- a negative number under an even root;
- a zero or negative input to a logarithm.

For $f(x) = \dfrac{\sqrt{x+3}}{x-1}$ we need $x + 3 \ge 0$ and $x \neq 1$, so the domain is $[-3, 1) \cup (1, \infty)$.

### Function notation is not multiplication

$f(x+h)$ means "replace every $x$ in the formula by $x + h$". For $f(x) = x^2$ we get $f(3+1) = 16$, but $f(3) + f(1) = 10$. In general $f(a+b) \neq f(a) + f(b)$.

@example
title: Identify and fit a table of values
problem: A function has values $f(0)=2$, $f(1)=5$, $f(2)=12$, $f(3)=23$, $f(4)=38$. Decide which family fits, find a formula, and predict $f(10)$.
step: First differences: $5-2=3$, $12-5=7$, $23-12=11$, $38-23=15$. They are not constant, so the data are not linear.
step: Second differences: $7-3=4$, $11-7=4$, $15-11=4$. Constant, so the data are quadratic. With step $1$, the second difference is $2a$, so $2a = 4$ and $a = 2$.
step: $f(0) = c = 2$. Then $f(1) = a + b + c = 5$ gives $2 + b + 2 = 5$, so $b = 1$.
step: The formula is $f(x) = 2x^2 + x + 2$. Check with $x = 4$: $32 + 4 + 2 = 38$. It matches.
step: Predict: $f(10) = 2(100) + 10 + 2 = 212$.

@example
title: Domain of a formula with a root and a fraction
problem: Find the domain of $g(x) = \dfrac{\sqrt{5 - x}}{x + 2}$.
step: The square root needs a non-negative radicand: $5 - x \ge 0$, so $x \le 5$.
step: The denominator must not be zero: $x + 2 \neq 0$, so $x \neq -2$.
step: Combine both conditions. The domain is $(-\infty, -2) \cup (-2, 5]$.

@mistakes
- Calling any fast-growing table "exponential". Test for a constant ratio, not for speed.
- Reading $f(x+h)$ as $f(x) + h$ or $f(x) + f(h)$ instead of substituting $x + h$ for every $x$.
- Checking only the denominator when finding a domain and forgetting an even root or a logarithm elsewhere in the formula.

@practice mc
prompt: Which table of outputs, taken at $x = 0, 1, 2, 3$, comes from an exponential function?
choice*: $y = 2,\ 6,\ 18,\ 54$
choice: $y = 2,\ 5,\ 8,\ 11$
choice: $y = 1,\ 4,\ 9,\ 16$
choice: $y = 1,\ 2,\ 6,\ 24$
hint: An exponential function multiplies by the same number at every step.
hint: Divide each output by the one before it and compare the ratios.
solution: For $2, 6, 18, 54$ the ratios are $3, 3, 3$. The table $2,\ 5,\ 8,\ 11$ has constant differences (linear), the table $1,\ 4,\ 9,\ 16$ has constant second differences (quadratic), and the table $1,\ 2,\ 6,\ 24$ has ratios $2, 3, 4$, which are not constant.

@practice num
prompt: The outputs at $x = 0, 1, 2, 3$ are $5, 15, 45, 135$. Assuming the pattern is exponential, find $f(5)$.
answer: 1215
check: np.exp(np.polyval(np.polyfit([0, 1, 2, 3], np.log([5, 15, 45, 135]), 1), 5))
hint: Find the common ratio between consecutive outputs.
hint: The ratio is $3$ and $f(0) = 5$, so $f(x) = 5 \cdot 3^x$.
solution: Each output is $3$ times the previous one, so $f(x) = 5 \cdot 3^x$ and $f(5) = 5 \cdot 243 = 1215$.

@practice list
prompt: Find every real number that is NOT in the domain of $f(x) = \dfrac{1}{x^2 - 5x + 6}$. Enter the numbers separated by commas.
answer: 2, 3
check: allroots(lambda x: x**2 - 5*x + 6, -10, 10)
hint: A fraction is undefined where its denominator is zero.
hint: Factor the quadratic $x^2 - 5x + 6$ and set each factor to zero.
solution: $x^2 - 5x + 6 = (x-2)(x-3)$, which is zero at $x = 2$ and $x = 3$. The domain is all reals except $2$ and $3$.

@quiz num
prompt: A quadratic function satisfies $f(0) = 4$, $f(1) = 3$ and $f(2) = 6$. Find $f(5)$.
answer: 39
check: np.polyval(np.polyfit([0, 1, 2], [4, 3, 6], 2), 5)
hint: Write $f(x) = ax^2 + bx + 4$ and use the other two values.
hint: $f(1) = 3$ gives $a + b = -1$, and $f(2) = 6$ gives $4a + 2b = 2$.
solution: Solving gives $a = 2$, $b = -3$, so $f(x) = 2x^2 - 3x + 4$ and $f(5) = 50 - 15 + 4 = 39$.

@quiz expr
prompt: An exponential function $f(x) = ab^x$ with $b > 0$ passes through $(1, 6)$ and $(3, 54)$. Write $f(x)$.
vars: x
lead: $f(x) =$
answer: 2*3^x
check: lambda x: (6 / ((54/6)**0.5)) * ((54/6)**0.5)**x
hint: Divide the two equations $ab^3 = 54$ and $ab = 6$ to eliminate $a$.
hint: You get $b^2 = 9$. Take the positive root, then find $a$ from $ab = 6$.
solution: $b^2 = 54/6 = 9$, so $b = 3$ and $a = 6/3 = 2$. Hence $f(x) = 2 \cdot 3^x$. Check: $f(1) = 6$ and $f(3) = 54$.

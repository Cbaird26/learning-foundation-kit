@lesson
title: Fitting a model by gradient descent
summary: Fit a one-parameter model to data by computing the gradient of the mean squared error and stepping downhill with a well-chosen step size.
objective: Write the mean squared error of a simple model and compute its derivative.
objective: Run gradient descent by hand and in code.
objective: Explain how the step size decides whether gradient descent converges, crawls or diverges.
reading: Mathematics for Machine Learning, the chapter on continuous optimization: optimization using gradient descent.

@article
A café notices that on sunnier days it sells more iced drinks. It records three days: 1 hour of sun and 3 drinks, 2 hours and 5 drinks, 3 hours and 8 drinks. A model that predicts sales from sunshine is a function $\hat{y} = w x$, where $x$ is the hours of sun and $w$ is a **parameter** we have to choose. Which $w$ fits best, and how can a computer find it when there are millions of parameters instead of one?

### The loss

First we say what "fits best" means. The **mean squared error** (MSE) of the model on data $\{(x_i, y_i)\}_{i=1}^{n}$ is

$$L(w) = \frac{1}{n} \sum_{i=1}^{n} (w x_i - y_i)^2 .$$

Each term is the squared gap between a prediction and the truth, so $L(w) \ge 0$, and a smaller loss means a better fit. Training a model means finding the $w$ that makes $L(w)$ as small as possible.

### The gradient

The derivative of the loss tells us which way is downhill. By the chain rule, the derivative of $(w x_i - y_i)^2$ with respect to $w$ is $2(w x_i - y_i) x_i$, so

$$L'(w) = \frac{2}{n} \sum_{i=1}^{n} (w x_i - y_i)\, x_i .$$

If $L'(w)$ is negative, increasing $w$ lowers the loss; if it is positive, decreasing $w$ does. For the café data at $w = 0$: $L'(0) = \frac{2}{3}\big((0 - 3)(1) + (0 - 5)(2) + (0 - 8)(3)\big) = \frac{2}{3}(-37) \approx -24.67$, so we should increase $w$.

### The update

**Gradient descent** starts from a guess and repeats one step:

$$w \leftarrow w - \eta\, L'(w),$$

where $\eta > 0$ is the **step size** (also called the learning rate), a **hyperparameter** that we choose rather than learn. With $\eta = 0.1$, the first step from $w = 0$ gives $w = 0 - 0.1 \times (-24.67) \approx 2.47$.

For this model we can also solve $L'(w) = 0$ directly: $w^\star = \sum x_i y_i / \sum x_i^2 = 37/14 \approx 2.643$. Gradient descent matters because most models have no such formula.

### Choosing the step size

The loss here is a parabola whose second derivative, its **curvature**, is $L''(w) = \frac{2}{n}\sum x_i^2 = 28/3 \approx 9.33$. Each step multiplies the distance to $w^\star$ by $1 - \eta L''$, so gradient descent converges exactly when $0 < \eta < 2 / L''$, here $\eta < 0.214$. Starting from $w = 0$:

| step | $\eta = 0.01$ | $\eta = 0.1$ | $\eta = 0.25$ |
|---|---|---|---|
| 1 | 0.2467 | 2.4667 | 6.1667 |
| 2 | 0.4703 | 2.6311 | −2.0556 |
| 5 | 1.0236 | 2.6429 | 13.7798 |
| 20 | 2.2704 | 2.6429 | −830.7474 |

A step size that is too small crawls, a good one converges in a few steps, and one above $2/L''$ overshoots further every time and diverges.

### In code

```python
data = [(1, 3), (2, 5), (3, 8)]

def grad(w):
    n = len(data)
    return 2 / n * sum((w * x - y) * x for x, y in data)

w = 0.0
for step in range(5):
    w = w - 0.1 * grad(w)
    print(step + 1, round(w, 4))
```

With NumPy, practitioners compute the same gradient for all examples at once, `2 * np.mean((w * x - y) * x)`, and libraries such as PyTorch compute gradients automatically. The idea is exactly the one above.

@example
title: One step by hand
problem: Fit $\hat{y} = w x$ to the points $(1, 2)$ and $(3, 7)$ with the mean squared error. Starting from $w = 1$ with step size $\eta = 0.1$, take one step of gradient descent.
step: Write the derivative: $L'(w) = \frac{2}{n}\sum (w x_i - y_i) x_i$ with $n = 2$.
step: Evaluate at $w = 1$: the errors are $1 \cdot 1 - 2 = -1$ and $1 \cdot 3 - 7 = -4$, so $L'(1) = \frac{2}{2}\big((-1)(1) + (-4)(3)\big) = -13$.
step: Update: $w = 1 - 0.1 \times (-13) = 2.3$.
step: Check: the exact minimizer is $\sum x_i y_i / \sum x_i^2 = (2 + 21)/(1 + 9) = 2.3$. One step landed exactly on it because $\eta = 0.1$ equals $1/L''$, and $L'' = \frac{2}{2}(1 + 9) = 10$.
answer: $w = 2.3$, which is already the minimizer.

@mistakes
- Moving with the gradient instead of against it: the update is $w - \eta L'(w)$, and adding the gradient climbs the loss.
- Forgetting to divide by $n$: the gradient then grows with the size of the data set, and a step size that worked on small data diverges on large data.
- Picking the step size by habit: above $2/L''$ the iterates bounce farther each step, and far below it they barely move.

model:
```python
def fit(data, lr, steps):
    """Run gradient descent on the MSE of y_hat = w * x, starting from 0."""
    n = len(data)
    w = 0.0
    for _ in range(steps):
        grad = 2 / n * sum((w * x - y) * x for x, y in data)
        w -= lr * grad
    return w
```
hint: Inside a loop that runs `steps` times, compute the gradient at the current `w` and subtract `lr` times it.
solution: Each iteration recomputes the gradient at the current parameter and moves against it. The last test uses a step size above $2/L''$ (here $L'' = 5$), so the iterates must grow: a function that adds the gradient, or stops early, fails one of the tests.

@quiz ms
prompt: Gradient descent with step size $\eta$ is run on the mean squared error of $\hat{y} = w x$, whose curvature is $L''$. Which of these statements are true? Select all that apply.
choice*: If $\eta = 1 / L''$, one step reaches the minimizer from any starting point.
choice*: Doubling every $x_i$ in the data multiplies $L''$ by 4, so a step size that worked before may now diverge.
choice: A larger step size always reaches the minimum in fewer steps.
choice: The step size is a parameter that gradient descent learns from the data.
hint: For a parabola, each step multiplies the distance to the minimizer by $1 - \eta L''$, and $L'' = \frac{2}{n}\sum x_i^2$.
solution: With $\eta = 1/L''$ the factor $1 - \eta L''$ is 0, so one step lands on the minimizer. Since $L'' = \frac{2}{n}\sum x_i^2$, doubling each $x_i$ multiplies it by 4 and can push $2/L''$ below the old step size. Larger steps help only up to a point and diverge beyond $2/L''$, and the step size is a hyperparameter we choose, not a learned parameter.

@quiz self
prompt: A classmate trains a model with a step size of 0.5 and reports that the loss went from 3.2 to 41.0 to 690.4 over the first three steps. Explain what is happening, why, and what they should try next.
hint: Compare the step size with $2/L''$ and think about what an increasing loss means.
solution: The loss grows at every step, so gradient descent is diverging: the step size is larger than $2/L''$ for this loss, and each update overshoots the minimum by more than it started from. The fix is a smaller step size, for example by dividing it by 10 and increasing again while the loss falls steadily; scaling the inputs to similar sizes also lowers the curvature and makes a larger step safe. A loss that rises from the first step points to the step size rather than to a bug in the data, though checking the gradient against a finite difference rules out a sign error.
rubric: Identifies divergence caused by a step size above the stable range, not a data problem.
rubric: Explains overshooting in terms of the curvature (or $2/L''$).
rubric: Proposes a concrete next step: a smaller step size, input scaling or a gradient check.

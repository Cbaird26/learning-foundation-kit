# AI Learning Foundation

**Open the school:** https://cbaird26.github.io/ai-learning-foundation/

A Khan Academy-style self-study school: 66 courses in five stages, from kindergarten through a complete college degree in
artificial intelligence and machine learning to graduate study and research — elementary, middle and high school
(including computational thinking, first programs and Python through object-oriented programming), the AI and machine
learning degree (programming, discrete mathematics, developer tools, data structures and algorithms; calculus, linear
algebra, probability, optimization, statistics and information theory; classical AI and a survey of machine learning;
numerical computing and data science; supervised and unsupervised learning; deep learning and its architectures;
natural language processing, computer vision and reinforcement learning; causal inference; AI ethics, safety and
governance; and machine learning engineering), and graduate study (statistical learning theory, probabilistic and
generative models, large language models, interpretability and alignment, research methods, and a research
apprenticeship with qualifying-exam preparation).

Each course has 12 weekly lessons (an article, worked examples, common mistakes, and auto-graded practice and quiz
questions), a week 13–14 project with a review guide, and a cumulative final exam. Skills move through mastery levels
with unit quizzes, a midterm and course challenges, and missed questions go into an error log that brings back a
parallel problem 48 hours later.

## Python in the page

Programming and machine learning courses include Python exercises that run real Python in the browser, with nothing to
install: the page includes Brython, which follows Python 3.14, with CPython's own json package. Press Run to try code and
Check to grade it against the exercise's tests; a program that runs too long is stopped after a few seconds. Lesson code
that runs here has a "Try it" button, and the Python tab is a scratchpad. The browser's Python has the whole language
and most of the standard library, but not threads, networking or third-party packages such as NumPy or PyTorch, so the
exercises build each method from scratch in plain Python on small data. Projects are done on your own computer, where
those libraries are available. Your code is never uploaded.

## Using it

Open the site in any modern browser. The whole school is one self-contained page (`index.html`), so you can also save
the page and use it offline.

Progress and the error log are kept only in your own browser and are never uploaded. Keep using the same browser and do
not clear its site data; another browser or device starts fresh. The Tutor button prepares a prompt you can copy into a
chat with Claude.

## Accuracy and fairness

Every course was written and then independently reviewed. Every numeric and typed answer was checked against an
independent computation, every Python exercise's model solution was run against its tests both in standard Python and
in the browser's Python, and every "what does this print?" answer was produced by running the program. On contested
questions, such as how fast AI will progress, how large its risks are, how it should be governed, and whether AI systems
could understand or be conscious, the lessons present the main views and the strongest arguments on each side and do not
tell learners what to believe. Laws, standards, PhD programs and the job market change, so check current details before
relying on them. Self-study scores do not award credit, degrees or any credential.

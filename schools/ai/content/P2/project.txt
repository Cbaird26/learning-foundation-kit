material: The metrics, written out so that every student computes the same quantities.
- Fréchet distance in one dimension: $(\mu_r-\mu_g)^2 + (\sigma_r-\sigma_g)^2$, using population standard deviations (divide by $n$).
- Unbiased MMD squared with $k(a,b) = \exp(-(a-b)^2/(2\ell^2))$: average $k$ over ordered pairs $i\ne j$ within each sample, subtract twice the average of $k$ over all cross pairs.
- Precision: the fraction of generated samples within $r$ of at least one real sample. Recall: the fraction of real samples within $r$ of at least one generated sample.
```python
from math import exp

def mmd2_unbiased(xs, ys, ell=1.0):
    k = lambda a, b: exp(-(a - b) ** 2 / (2 * ell ** 2))
    n, m = len(xs), len(ys)
    kxx = sum(k(xs[i], xs[j]) for i in range(n) for j in range(n) if i != j)
    kyy = sum(k(ys[i], ys[j]) for i in range(m) for j in range(m) if i != j)
    kxy = sum(k(a, b) for a in xs for b in ys)
    return kxx / (n * (n - 1)) + kyy / (m * (m - 1)) - 2 * kxy / (n * m)
```

## Week 13 review: probabilistic machine learning and generative models

**Key ideas by week**

1. **Bayesian linear regression.** Gaussian prior and likelihood give a Gaussian posterior with $\mathbf{S}_N^{-1} = \alpha\mathbf{I}+\beta\boldsymbol{\Phi}^\top\boldsymbol{\Phi}$ and $\mathbf{m}_N = \beta\mathbf{S}_N\boldsymbol{\Phi}^\top\mathbf{t}$; predictive variance $1/\beta + \boldsymbol{\phi}_*^\top\mathbf{S}_N\boldsymbol{\phi}_*$; the MAP estimate is ridge with $\lambda = \alpha/\beta$.
2. **Gaussian processes.** Posterior mean $\mathbf{k}_*^\top\mathbf{K}_y^{-1}\mathbf{y}$ and variance $k_{**}-\mathbf{k}_*^\top\mathbf{K}_y^{-1}\mathbf{k}_*$; the log marginal likelihood trades fit against complexity; exact inference is $O(n^3)$.
3. **Variational inference.** $\log p(x) = \mathrm{ELBO}+\mathrm{KL}(q\Vert p(z\mid x))$; maximizing the ELBO minimizes the reverse KL; mean-field underestimates variance and is mode-seeking.
4. **VAEs.** ELBO $=$ reconstruction $-$ KL to the prior; reparameterization $z = \mu+\sigma\varepsilon$ gives low-variance gradients; posterior collapse.
5. **Autoregressive models.** Chain rule factorization; exact likelihood, parallel training, sequential sampling; bits per dimension and perplexity.
6. **Flows.** $\log p_X(\mathbf{x}) = \log p_Z(\mathbf{z}) - \log\lvert\det\mathbf{J}_f\rvert$; coupling layers give triangular Jacobians.
7. **GANs.** $D^\star = p_{\text{data}}/(p_{\text{data}}+p_g)$; the value is $-\log 4 + 2\,\mathrm{JS}$; training dynamics can rotate or diverge.
8. **Diffusion.** $q(\mathbf{x}_t\mid\mathbf{x}_0) = \mathcal{N}(\sqrt{\bar\alpha_t}\mathbf{x}_0,(1-\bar\alpha_t)\mathbf{I})$; posterior mean and variance of the reverse step; noise-prediction loss.
9. **Score matching.** Score of a mixture is a responsibility-weighted pull to the means; denoising score matching; Tweedie's formula; Langevin dynamics; $\boldsymbol{\varepsilon}_{\boldsymbol{\theta}}\approx-\sqrt{1-\bar\alpha_t}\,\mathbf{s}_{\boldsymbol{\theta}}$.
10. **Energy-based models.** $p = e^{-E}/Z$; the likelihood gradient is a data term minus a model term; contrastive divergence, score matching and noise-contrastive estimation avoid $Z$.
11. **Evaluation.** Likelihood, IS, FID, MMD, precision and recall, memorization checks; report several metrics with variation.
12. **Generated media.** Uses, deception, non-consensual imagery, privacy; detection base rates, watermark tests, signed provenance; layered defenses.

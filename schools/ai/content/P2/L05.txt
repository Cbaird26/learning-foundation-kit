@article
Variational autoencoders gave up exact likelihoods: the ELBO is only a bound. Is there a deep generative model that keeps the exact likelihood and needs no latent variable at all? Yes, and it is the oldest idea in probability: the **chain rule**. For any random vector $\mathbf{x} = (x_1,\dots,x_d)$,

$$p(\mathbf{x}) = \prod_{i=1}^{d} p(x_i \mid x_1,\dots,x_{i-1}) = \prod_{i=1}^{d} p(x_i\mid\mathbf{x}_{<i}).$$

This is an identity, not a modeling assumption, and it holds for every ordering of the variables. The modeling decision is how to represent each conditional. An **autoregressive model** parameterizes each conditional $p_{\boldsymbol{\theta}}(x_i\mid\mathbf{x}_{<i})$ with a shared function (a logistic regression, a neural network, a transformer), so the model has an exact, tractable log-likelihood
$$\log p_{\boldsymbol{\theta}}(\mathbf{x}) = \sum_{i=1}^d \log p_{\boldsymbol{\theta}}(x_i\mid\mathbf{x}_{<i}).$$

### A three-variable example

Let $x_1,x_2,x_3\in\{0,1\}$ with $P(x_1{=}1) = 0.6$; $P(x_2{=}1\mid x_1{=}1) = 0.7$ and $P(x_2{=}1\mid x_1{=}0) = 0.2$; and $P(x_3{=}1\mid x_1,x_2) = 0.9, 0.5, 0.4, 0.1$ for $(x_1,x_2) = (1,1), (1,0), (0,1), (0,0)$. The probability of $(1,0,1)$ is the product of three conditionals: $0.6\times(1-0.7)\times 0.5 = 0.09$. Its negative log-likelihood is $-\log 0.09 = 2.408$ nats, or $3.474$ bits. The eight sequence probabilities sum to 1 automatically, because each conditional is normalized: that is the structural advantage of the factorization.

To **sample**, draw $x_1$ from its marginal, then $x_2$ from its conditional given the drawn $x_1$, and so on (ancestral sampling). With uniform draws $u = (0.5, 0.9, 0.3)$ and the rule "$x_i = 1$ if $u_i < P(x_i{=}1\mid\cdot)$": $x_1 = 1$ since $0.5 < 0.6$; $x_2 = 0$ since $0.9 > 0.7$; $x_3 = 1$ since $0.3 < 0.5$.

### Parameterizations and what they cost

A full conditional table over $d$ binary variables needs $2^d - 1$ numbers (1023 for $d = 10$). Cheaper choices share structure:

- **Logistic autoregression** (fully visible sigmoid belief network): $p(x_i{=}1\mid\mathbf{x}_{<i}) = \sigma(b_i + \sum_{j<i}w_{ij}x_j)$ has $d + d(d-1)/2$ parameters (55 for $d=10$).
- **Weight sharing with neural networks**: NADE (Larochelle and Murray, 2011) shares hidden-unit weights across the conditionals, so cost grows linearly rather than quadratically in $d$.
- **Masked networks**: MADE (Germain and colleagues, 2015) computes all $d$ conditionals in one forward pass by masking weights. Give each input a degree $1,\dots,d$ and each hidden unit a degree $m$; allow a hidden unit of degree $m$ to see inputs of degree $\le m$, and let output $i$ see hidden units of degree $< i$. Then output $i$ depends only on $\mathbf{x}_{<i}$, because any path from input $j$ passes through a hidden degree $m$ with $j\le m<i$.
- **Convolutional and attention-based models**: PixelRNN and PixelCNN (van den Oord and colleagues, 2016) order the pixels of an image in raster order, and a causal mask on a convolution gives the same property; transformer decoders (Vaswani and colleagues, 2017) use a causal attention mask.

For real-valued variables each conditional needs a density family: a mixture of Gaussians, or a discretization into bins with a categorical output.

### Training, sampling and evaluation

Training maximizes $\sum_n\log p_{\boldsymbol{\theta}}(\mathbf{x}^{(n)})$, i.e., minimizes the cross-entropy. With **teacher forcing**, each conditional is evaluated with the true previous values, so with masks all $d$ terms are computed in one parallel pass. **Sampling** has no such shortcut: $x_i$ needs the sampled $\mathbf{x}_{<i}$, so generating $d$ values takes $d$ sequential network evaluations (caching of intermediate results reduces the cost per step but not the sequential dependency). A related weakness is **exposure bias**: the model is trained only on true prefixes but at generation time conditions on its own samples, so early mistakes can compound.

Likelihoods are reported in nats per example, or in **bits per dimension**: $\text{NLL (nats)}/(d\ln 2)$. For sequence models, **perplexity** is $\exp(\text{average NLL per token in nats})$, the effective number of equally likely choices per step. Bits per dimension compares models of the same data and discretization, nothing more.

### Strengths and limits

Autoregressive models give exact likelihoods, stable maximum-likelihood training, and very flexible conditionals, and the same recipe underlies large language models, which later courses treat. The weaknesses are slow sequential sampling, a dependence on the chosen ordering for how easily the conditionals can be learned (even though every ordering is exact in principle), and the absence of a compact latent representation: there is no low-dimensional code to edit or interpolate. They also do not by themselves tell you whether samples look good: likelihood and sample quality are distinct (week 11).

```python
p1 = 0.6
p2 = {1: 0.7, 0: 0.2}
p3 = {(1, 1): 0.9, (1, 0): 0.5, (0, 1): 0.4, (0, 0): 0.1}

def prob(x1, x2, x3):
    a = p1 if x1 else 1 - p1
    b = p2[x1] if x2 else 1 - p2[x1]
    c = p3[(x1, x2)] if x3 else 1 - p3[(x1, x2)]
    return a * b * c

def sample(us):
    x1 = 1 if us[0] < p1 else 0
    x2 = 1 if us[1] < p2[x1] else 0
    x3 = 1 if us[2] < p3[(x1, x2)] else 0
    return x1, x2, x3

print(prob(1, 0, 1), sample([0.5, 0.9, 0.3]))
```

@example
title: Likelihood, bits per symbol and perplexity
problem: A model of strings over the two-symbol alphabet $\{a, b\}$ has $P(\text{first} = a) = 0.5$, $P(a\mid a) = 0.9$, $P(b\mid a) = 0.1$, $P(a\mid b) = 0.4$ and $P(b\mid b) = 0.6$. Compute the probability of the string "aabb", its negative log-likelihood in nats, the bits per symbol and the perplexity.
step: Chain rule: $P(\text{aabb}) = P(a)\,P(a\mid a)\,P(b\mid a)\,P(b\mid b) = 0.5\times 0.9\times 0.1\times 0.6$.
step: Multiply: $0.5\times 0.9 = 0.45$, $\times 0.1 = 0.045$, $\times 0.6 = 0.027$.
step: Negative log-likelihood: $-\ln 0.027 = 3.612$ nats, which is $3.612/\ln 2 = 5.211$ bits for four symbols.
step: Bits per symbol: $5.211/4 = 1.303$.
step: Perplexity: $2^{1.303} = 0.027^{-1/4} \approx 2.467$, equal to $\exp(3.612/4)$ in nats. The model behaves as if it chose among about 2.5 equally likely symbols per step, out of 2.
answer: $P = 0.027$; NLL $= 3.612$ nats; $1.303$ bits per symbol; perplexity $\approx 2.467$.

@mistakes
- Believing the chain rule assumes independence: it assumes nothing. A model's assumptions live in how the conditionals are parameterized.
- Using the same $\log$ base for NLL and perplexity inconsistently: perplexity is $2^{\text{bits per token}} = e^{\text{nats per token}}$, and mixing a bits value with $e$ gives the wrong number.
- Training with the model's own samples as the conditioning prefix and calling it maximum likelihood: teacher forcing conditions on the true prefix, and the difference is the source of exposure bias.
- Thinking parallel training means parallel sampling: generation remains $d$ sequential steps.

So no path exists from $x_i,\dots,x_3$ to output $i$, and the conditionals multiply to a valid joint distribution.

title: Choices: if this, then that
summary: Follow "if this, then that" rules, and shorten a long set of instructions by using a loop.
objective: Follow an if-then rule.
objective: Say what to do when the "if" is true and when it is not.
objective: Shorten a long set of instructions with a loop.
reading: CS Unplugged, look up an activity about making choices with if-then rules, such as a game with cards or a robot that decides.

@article
Sometimes a computer has to make a **choice**. We tell it what to do using the words **if** and **then**.

Here is a rule you may know:

```text
If it is raining,
    then take an umbrella.
```

If it is raining, you take an umbrella. If it is sunny, the rule does not say to take one. You do nothing special.

### Adding "otherwise"

We can say what to do in the other case, too. We use the word **otherwise**.

```text
If the card is red,
    then say "stop".
Otherwise,
    say "go".
```

A red card means "stop". Any other card, like blue or green, means "go". The computer always does exactly one of the two.

### Choices inside loops

Loops and choices work well together. Here is a program for a row of cards:

```text
For each card:
    If the card is red, say "stop".
    Otherwise, say "go".
```

The computer looks at the cards one at a time. It makes the choice again for every card.

### Shorter with a loop

If a long list of steps has a part that repeats, a loop can make it shorter. Look at this long list:

```text
wave, wave, wave, wave
```

The short way is:

```text
Repeat 4 times: wave
```

Grown-up helper: take turns. One person writes a long list that repeats. The other person writes the short version with "Repeat".

@example
title: Following an if-then rule
problem: The rule is: if the number is bigger than 5, clap. Otherwise, stomp. What do you do for the number 8, and for the number 3?
step: For 8: is 8 bigger than 5? Yes. So you clap.
step: For 3: is 3 bigger than 5? No. So the "otherwise" part happens, and you stomp.
answer: Clap for 8 and stomp for 3.

@mistakes
- Doing both parts of an if-otherwise rule. Only one of them happens each time.
- Forgetting to check the "if" part first. Ask yourself the question, then say yes or no.
- Treating "bigger than 5" as if it included 5. The number 5 is not bigger than 5.

@practice mc
prompt: The rule says: If it is raining, take an umbrella. It is raining. What do you do?
choice*: Take an umbrella.
choice: Leave the umbrella at home.
choice: Wear sunglasses.
hint: Is the "if" part true right now?
solution: It is raining, so the "if" part is true. You take an umbrella.

@practice mc
prompt: The rule says: If it is cold, wear a coat. Otherwise, wear a T-shirt. It is hot. What do you wear?
choice*: A T-shirt.
choice: A coat.
choice: Both.
choice: Neither.
hint: Is it cold? What does "otherwise" tell you to do?
solution: It is hot, not cold, so the "if" part is false. The "otherwise" part says wear a T-shirt.

@practice num
prompt: The rule is: if the number is bigger than 5, clap. Otherwise, stomp. The numbers are 3, 7, 9, 5, 2. How many claps do you do? Type a number.
answer: 2
check: sum(1 for n in [3, 7, 9, 5, 2] if n > 5)
hint: Check each number one at a time. Only a number bigger than 5 gets a clap.
solution: 7 and 9 are bigger than 5, so they get claps. 3, 5 and 2 are not bigger than 5, so they get stomps. That is 2 claps.

@practice text
prompt: The rule is: if the card is red, say "stop". Otherwise, say "go". The cards are red, blue, red, green. Type the words you say, in order, with spaces between them.
answer: stop go stop go
accept: stop, go, stop, go
check: " ".join("stop" if c == "red" else "go" for c in ["red", "blue", "red", "green"])
hint: Look at one card at a time. Red means stop. Any other color means go.
solution: Red says stop, blue says go, red says stop, green says go. So you say: stop go stop go.

@practice self
prompt: Here is a long set of instructions for a dance: clap, stomp, clap, stomp, clap, stomp, clap, stomp, clap, stomp. Write a short set with a loop that does the same dance. Say how many times to repeat and what is inside the loop.
hint: Take it one step at a time, and ask your grown-up to check each part with you.
solution: Repeat 5 times: clap, then stomp. The long list has clap, stomp five times in a row, so the loop goes around 5 times with clap and stomp inside.
rubric: The loop says to repeat 5 times.
rubric: The loop has clap and stomp inside it, in that order.
rubric: The child checked that the short set makes the same dance as the long one.

@quiz mc

@quiz num
prompt: The rule is: if the number is even, clap. Otherwise, do nothing. The numbers are 1, 2, 3, 4, 5, 6. How many claps do you do? Type a number.
answer: 3
check: sum(1 for n in [1, 2, 3, 4, 5, 6] if n % 2 == 0)
hint: Even numbers are the ones you say when you count by twos: 2, 4, 6.
solution: The even numbers are 2, 4 and 6, so you clap 3 times. The odd numbers get nothing.

@article
Imagine pumping a liquid through a network of pipes with limited capacities. How much can reach the destination per second? This is the **maximum flow** problem, and a surprising number of problems turn out to be max flow in disguise.

### Definitions

A **flow network** is a directed graph with a source $s$, a sink $t$ and an edge capacity $c(u, v) \ge 0$. A **flow** assigns each edge a value $f(u,v)$ with

1. **Capacity:** $0 \le f(u,v) \le c(u,v)$ on every edge.
2. **Conservation:** for every vertex $v$ other than $s$ and $t$, the flow into $v$ equals the flow out of $v$.

The **value** $|f|$ is the net flow out of $s$. We want a flow of maximum value.

### The residual graph and augmenting paths

Given a flow $f$, the **residual graph** $G_f$ has, for each edge $(u,v)$:

- a **forward** residual edge $(u,v)$ with residual capacity $c(u,v) - f(u,v)$ (how much more we can push), and
- a **backward** residual edge $(v,u)$ with residual capacity $f(u,v)$ (how much we can **cancel**).

An **augmenting path** is a path from $s$ to $t$ in $G_f$ using only edges of positive residual capacity. Pushing the bottleneck (smallest residual capacity on the path) along it increases the flow value by that amount. The **Ford–Fulkerson method** repeats this until no augmenting path remains. Backward edges are essential: they let the algorithm undo an earlier bad choice.

With integer capacities each augmentation adds at least 1, so there are at most $|f^*|$ augmentations, each found in $O(E)$ time, giving $O(E\,|f^*|)$. That can be slow when capacities are large, and with irrational capacities a bad choice of paths might never terminate. **Edmonds–Karp** always picks a **shortest** augmenting path (fewest edges, found by BFS). It makes $O(VE)$ augmentations, so it runs in $O(VE^2)$ time regardless of the capacities.

### Cuts and the max-flow min-cut theorem

An **$s$–$t$ cut** is a partition $(S, T)$ of the vertices with $s \in S$, $t \in T$. Its **capacity** is the sum of $c(u,v)$ over edges going from $S$ to $T$. For any flow $f$ and any cut, the value of the flow equals the net flow across the cut (add up the conservation equations of all vertices in $S$ other than $s$: edges with both ends in $S$ cancel, leaving $|f|$ = flow out of $S$ minus flow into $S$), so $|f| \le c(S, T)$: every flow is bounded by every cut.

**Theorem (max-flow min-cut).** The maximum value of a flow equals the minimum capacity of an $s$–$t$ cut.

*Proof sketch.* A maximum flow exists (with integer capacities Ford–Fulkerson reaches one; for real capacities the set of feasible flows is closed and bounded, so the maximum is attained), and it admits no augmenting path, since augmenting would increase its value. Let $S$ be the set of vertices reachable from $s$ in the residual graph; $t \notin S$. Every edge $(u,v)$ from $S$ to $T$ must be saturated ($f = c$): otherwise its forward residual edge would make $v$ reachable. Every edge $(u,v)$ from $T$ to $S$ must carry zero flow: otherwise its backward residual edge $(v,u)$ would lead from $S$ to $u \in T$, making $u$ reachable. Hence $|f| = c(S, T)$. Combined with $|f| \le$ every cut capacity, $f$ is a maximum flow and $(S,T)$ is a minimum cut. $\square$

This gives a **certificate of optimality** and also **integrality**: when capacities are integers, some maximum flow assigns integer values to all edges.

### Reductions to flow

**Bipartite matching.** Given workers $L$, jobs $R$ and the allowed pairs, add a source with a capacity-1 edge to each worker, a capacity-1 edge from each worker to each job it can do, and a capacity-1 edge from each job to the sink. By integrality, a maximum flow of value $k$ uses 0/1 edges and describes a matching of size $k$, and conversely. Ford–Fulkerson, and hence Edmonds–Karp, takes $O(VE)$ here, since the flow value is at most $V$ and each augmentation costs $O(E)$.

**Edge-disjoint paths.** The maximum number of pairwise edge-disjoint $s$–$t$ paths in a directed graph equals the maximum flow when every edge has capacity 1.

The skill that matters most in this unit is the **reduction**: recognizing that a problem has the structure of another, solved problem, and translating it faithfully.

@example
title: Why backward edges matter
problem: Edges $s \to a$, $s \to b$, $a \to b$, $a \to t$, $b \to t$ all have capacity 1. Find the maximum flow.
step: First augmenting path (unlucky choice): $s \to a \to b \to t$, bottleneck 1. Flow value is now 1.
step: Residual graph: $s \to a$, $a \to b$ and $b \to t$ are saturated, but their backward edges $a \to s$, $b \to a$, $t \to b$ have capacity 1. Edges $s \to b$ and $a \to t$ are unused.
step: A second augmenting path exists: $s \to b \to a \to t$, which uses the **backward** edge $b \to a$ (cancelling the flow on $a \to b$). Flow value is now 2.
step: Now the residual graph has no $s$–$t$ path. The cut $S = \{s\}$ has capacity $c(s,a) + c(s,b) = 2$, matching the flow.
answer: The maximum flow is 2, and the minimum cut is $(\{s\}, \{a, b, t\})$ with capacity 2.

@example
title: Matching as flow
problem: Workers $W_1, W_2, W_3$ can do jobs: $W_1$: $\{J_1, J_2\}$, $W_2$: $\{J_1\}$, $W_3$: $\{J_2, J_3\}$. What is the largest set of assignments with one job per worker and one worker per job?
step: Build the network: source to each $W_i$, each $W_i$ to its allowed jobs, each job to the sink, all with capacity 1.
step: Augment along $s \to W_2 \to J_1 \to t$, then $s \to W_1 \to J_2 \to t$, then $s \to W_3 \to J_3 \to t$. Each path is disjoint from the others.
step: Three units of flow reach the sink, and the source has only three outgoing edges, so this is maximum.
answer: Maximum matching of size 3: $W_2 J_1$, $W_1 J_2$, $W_3 J_3$.

@mistakes
- Forgetting the backward residual edges, which makes the algorithm stop at a flow that is not maximum.
- Choosing the cut capacity as the sum over edges in **both** directions; only edges from $S$ to $T$ count.
- Assuming a flow is optimal because every edge out of $s$ is saturated. Optimality requires no augmenting path, or a cut of equal capacity.
- Using the Ford–Fulkerson bound $O(E|f^*|)$ as if it were polynomial: it depends on the capacity values; Edmonds–Karp's $O(VE^2)$ does not.

model:
```python
from collections import deque


def max_flow(n, edges, s, t):
    cap = [[0] * n for _ in range(n)]
    for u, v, c in edges:
        cap[u][v] += c
    flow = 0
    while True:
        parent = [-1] * n
        parent[s] = s
        queue = deque([s])
        while queue and parent[t] == -1:
            u = queue.popleft()
            for v in range(n):
                if parent[v] == -1 and cap[u][v] > 0:
                    parent[v] = u
                    queue.append(v)
        if parent[t] == -1:
            return flow
        bottleneck = None
        v = t
        while v != s:
            u = parent[v]
            if bottleneck is None or cap[u][v] < bottleneck:
                bottleneck = cap[u][v]
            v = u
        v = t
        while v != s:
            u = parent[v]
            cap[u][v] -= bottleneck
            cap[v][u] += bottleneck
            v = u
        flow += bottleneck
```
hint: Store the residual capacities in a matrix: for each augmentation, find a path from `s` to `t` with BFS using only entries greater than 0.
hint: Subtract the bottleneck from each forward residual entry on the path and add it to the matching backward entry, then add it to the flow value. Stop when BFS cannot reach `t`.
solution: Each round BFS finds a shortest augmenting path in the residual graph, the bottleneck is the minimum residual capacity on it, and updating `cap[u][v] -= b` and `cap[v][u] += b` creates the backward edges that allow later cancellation. When `t` is unreachable the flow is maximum. Edmonds–Karp does $O(VE)$ augmentations.

model:
```python
def max_matching(n_left, n_right, pairs):
    adj = [[] for _ in range(n_left)]
    for left, right in pairs:
        adj[left].append(right)
    owner = [-1] * n_right

    def try_assign(left, seen):
        for right in adj[left]:
            if right in seen:
                continue
            seen.add(right)
            if owner[right] == -1 or try_assign(owner[right], seen):
                owner[right] = left
                return True
        return False

    return sum(1 for left in range(n_left) if try_assign(left, set()))
```
hint: `owner[r]` records which left vertex currently holds right vertex `r`, or `-1` if it is free.
hint: To place a left vertex, try each neighbor `r` not yet seen in this attempt: take it if free, or if its owner can be re-assigned elsewhere by a recursive call.
solution: Each call to `try_assign` searches for an augmenting path in the matching: it either grabs a free right vertex or asks the current owner to move. The `seen` set prevents revisiting right vertices within one search. This is the flow algorithm on the unit-capacity matching network, in $O(VE)$ time.

@practice self
prompt: Show how to compute the maximum number of pairwise **edge-disjoint** paths from $s$ to $t$ in a directed graph by reduction to maximum flow, and prove that the reduction is correct.
solution: Give every edge capacity 1 and compute a maximum flow from $s$ to $t$; the answer is its value $k$. Correctness has two directions. (1) If there are $m$ edge-disjoint $s$–$t$ paths, send one unit along each. Since no edge is shared, every edge carries at most 1 unit, so capacities hold; conservation holds at intermediate vertices because each path enters and leaves them equally often. The flow has value $m$, so $k \ge m$. (2) Conversely, by the integrality theorem there is a maximum flow of value $k$ that is integral, so each edge has flow 0 or 1. In the subgraph $H$ of edges with flow 1, every vertex other than $s$ and $t$ has equal in- and out-degree, and $s$ has out-degree minus in-degree equal to $k$. Starting at $s$, follow an unused edge of $H$ out of the current vertex; we can always continue unless we are at $t$, because an intermediate vertex entered by an edge has an unused outgoing edge (in-degree equals out-degree). The walk therefore ends at $t$; it may repeat vertices, but it contains a simple $s$–$t$ path. Remove the edges of the walk from $H$: the conservation conditions still hold with the value reduced by 1. Repeat $k$ times to obtain $k$ pairwise edge-disjoint walks, hence $k$ edge-disjoint paths. So the maximum number of edge-disjoint paths equals $k$. Time: Edmonds–Karp gives $O(VE^2)$, and since the flow value is at most the out-degree of $s$ (below $V$ when there are no parallel edges), simple augmenting-path search gives $O(VE)$.
rubric: Sets every capacity to 1 and states that the answer is the maximum flow value.
rubric: Shows that edge-disjoint paths yield a flow of equal value (the capacity and conservation conditions hold).
rubric: Uses integrality to turn an integral maximum flow into that many edge-disjoint paths, by following flow edges from $s$.

hint: For the converse, use the fact that an integer-capacity network has an integral maximum flow, and trace paths along edges with flow 1.

```python
def is_valid_flow(edges, flow, s, t):
    balance = {}
    for (u, v, cap), f in zip(edges, flow):
        if f < 0 or f > cap:
            return False
        balance[u] = balance.get(u, 0) - f
        balance[v] = balance.get(v, 0) + f
    return all(b == 0 for x, b in balance.items() if x != s and x != t)
```

hint: Keep a net balance per vertex (incoming minus outgoing) and require it to be 0 for every vertex except `s` and `t`.
solution: One pass checks the capacity constraint and accumulates, for every vertex, incoming minus outgoing flow. Conservation means that balance is 0 at all vertices except the source and the sink. Time is linear in the number of edges.

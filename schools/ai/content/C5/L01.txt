@article
An algorithm is only useful if it is **correct** and **fast enough**. This course gives you tools for both: a way to describe running time that ignores machine details, and a way to prove that code does what you claim.

### Measuring growth

We model running time as a function $T(n)$ of the input size $n$, counting basic operations (comparisons, arithmetic, array accesses). Constant factors depend on the machine and compiler, so we compare **growth rates** instead.

Let $f, g$ be functions from the positive integers to the non-negative reals.

- $f(n) = O(g(n))$ means there are constants $c > 0$ and $n_0$ such that $f(n) \le c\,g(n)$ for all $n \ge n_0$. ($g$ is an **upper bound**.)
- $f(n) = \Omega(g(n))$ means there are $c > 0$ and $n_0$ with $f(n) \ge c\,g(n)$ for all $n \ge n_0$. ($g$ is a **lower bound**.)
- $f(n) = \Theta(g(n))$ means both hold: $f$ is squeezed between two constant multiples of $g$.

The "$=$" is a convention; $O(g)$ is really a set of functions. Three consequences are used constantly: lower-order terms vanish ($3n^2 + 10n = \Theta(n^2)$), constant factors vanish ($100n = \Theta(n)$), and the base of a logarithm does not matter, because $\log_a n = \log_b n / \log_b a$ differs by a constant factor. The base of an **exponential** does matter: $2^{2n} = 4^n$ is not $O(2^n)$.

The common classes, slowest-growing first:

$$1 \;\prec\; \log n \;\prec\; \sqrt n \;\prec\; n \;\prec\; n\log n \;\prec\; n^2 \;\prec\; n^3 \;\prec\; 2^n \;\prec\; n!$$

Do not confuse notation with cases. **Worst case**, **best case** and **average case** describe which inputs of size $n$ we measure; $O$, $\Omega$ and $\Theta$ describe how a function grows. You can say "the worst-case time of insertion sort is $\Theta(n^2)$" and "its best-case time is $\Theta(n)$".

### Counting loop steps

Count how often the innermost statement runs. For

```python
for i in range(n):
    for j in range(i):
        work()
```

`work()` runs $0 + 1 + \dots + (n-1) = n(n-1)/2 = \Theta(n^2)$ times. A loop that doubles its variable, `while i < n: i *= 2`, runs $\lceil \log_2 n \rceil$ times, which is $\Theta(\log n)$.

### Proving code correct: loop invariants

Testing shows a bug; a proof shows its absence. For a loop, find a **loop invariant**: a statement about the variables that is true at the start of every iteration. Prove three things:

1. **Initialization.** The invariant holds before the first iteration.
2. **Maintenance.** If it holds before an iteration, it still holds before the next one.
3. **Termination.** When the loop ends, the invariant together with the exit condition implies the goal.

This is induction on the number of iterations. Recursive algorithms are proved by induction on the input size instead: assume the recursive calls are correct on smaller inputs, and show the combination step is correct.

Also state the **precondition** (what the caller must guarantee, such as "the list is non-empty") and the **postcondition** (what the function guarantees). Correctness always means: precondition implies postcondition.

@example
title: Proving a bound with constants
problem: Show that $f(n) = 3n^2 + 10n$ is $O(n^2)$.
step: We must find $c > 0$ and $n_0$ with $3n^2 + 10n \le c\,n^2$ for all $n \ge n_0$.
step: For $n \ge 1$ we have $n \le n^2$, so $10n \le 10n^2$.
step: Therefore $3n^2 + 10n \le 3n^2 + 10n^2 = 13n^2$ for every $n \ge 1$.
step: Take $c = 13$ and $n_0 = 1$. The definition is satisfied, so $f(n) = O(n^2)$.
answer: $c = 13$, $n_0 = 1$ works (other choices, such as $c = 4$, $n_0 = 10$, also work).

@example
title: A loop-invariant proof
problem: Prove that `maximum(a)` returns the largest element of a non-empty list `a`.

```python
def maximum(a):
    best = a[0]
    for i in range(1, len(a)):
        if a[i] > best:
            best = a[i]
    return best
```
step: Precondition: `len(a) >= 1`. Invariant: at the start of the iteration with index `i`, `best == max(a[0:i])` (the maximum of the first `i` elements).
step: Initialization. Before the first iteration `i = 1` and `best = a[0] = max(a[0:1])`, so the invariant holds.
step: Maintenance. Assume `best == max(a[0:i])`. If `a[i] > best`, the code sets `best = a[i]`, which is `max(a[0:i+1])`. Otherwise `a[i] <= best`, so the maximum of `a[0:i+1]` is still `best`. Either way the invariant holds for `i + 1`.
step: Termination. The last iteration has `i = len(a) - 1`, and maintenance then gives the invariant for `i = len(a)`; this is the exit condition (also true if the loop never runs, when `len(a) = 1`). So the invariant says `best == max(a[0:len(a)])`, the maximum of the whole list. That is the postcondition.

@mistakes
- Reading $O(g)$ as "exactly $g$". $n = O(n^2)$ is true but loose; use $\Theta$ when you mean a tight bound.
- Saying "$O$ means worst case". $O$ is an upper bound on a function; worst case is a choice of inputs. Each case has its own $O$, $\Omega$ and $\Theta$.
- Dropping the base of an exponential: $2^{2n}$ is not $O(2^n)$, although the base of a logarithm can always be dropped.
- Writing a loop-invariant proof that checks initialization and maintenance but never uses the exit condition in the termination step.

prompt: Consider this function, whose precondition is that `a` is a list of numbers (possibly empty).

```python
def count_negative(a):
    count = 0
    for i in range(len(a)):
        if a[i] < 0:
            count += 1
    return count
```

State a loop invariant and prove by initialization, maintenance and termination that the function returns the number of negative entries of `a`.
solution: Invariant: at the start of the iteration with index `i`, `count` equals the number of indices `k < i` with `a[k] < 0`. Initialization: when `i = 0` there are no indices `k < 0` and `count = 0`. Maintenance: assume the invariant for `i`. If `a[i] < 0`, the code increments `count`, which now counts the negative entries among indices `0..i`; if not, `count` is unchanged and index `i` contributes nothing. In both cases the invariant holds for `i + 1`. Termination: after the last iteration maintenance gives the invariant for `i = len(a)` (the exit condition), and then it says `count` is the number of negative entries among all indices `k < len(a)`, which is the postcondition. For an empty list the loop never runs, and the initialization already gives the right answer `0`.

```python
def count_halvings(n):
    steps = 0
    i = 1
    while i < n:
        i *= 2
        steps += 1
    return steps
```

hint: The variable takes the values 1, 2, 4, 8, ... and the loop stops at the first power of two that is at least `n`.

@quiz num
prompt: Find the smallest positive integer $n_0$ such that $2^n > n^3$ for **every** integer $n \ge n_0$.
answer: 10
check: next(k for k in range(1, 60) if all(2**n > n**3 for n in range(k, 300)))
hint: Compute $2^n$ and $n^3$ for $n = 1, \dots, 10$. The inequality fails at $n = 2$ through $n = 9$.
solution: At $n = 9$: $2^9 = 512 < 729 = 9^3$. At $n = 10$: $1024 > 1000$. For larger $n$, going from $n$ to $n+1$ multiplies $2^n$ by 2 but $n^3$ by $(1 + 1/n)^3 \le 1.331 < 2$, so the inequality persists. Hence $n_0 = 10$.

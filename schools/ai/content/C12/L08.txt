@article
A ball rolling down a long, shallow valley does not stop and re-aim at every step: it builds up speed along the valley floor and shrugs off the small bumps across it. Gradient descent has no memory, and on the thin canyons of week 5 that costs it hundreds of steps. Momentum gives the iterates a memory.

### The heavy-ball method

The **heavy-ball method** (Polyak, 1964) adds a fraction $\beta \in [0,1)$ of the previous displacement to the gradient step:

$$\mathbf{x}_{k+1} = \mathbf{x}_k - \eta\,\nabla f(\mathbf{x}_k) + \beta\,(\mathbf{x}_k - \mathbf{x}_{k-1}).$$

Equivalently, with a velocity $\mathbf{v}_{k+1} = \beta\mathbf{v}_k - \eta\nabla f(\mathbf{x}_k)$ and $\mathbf{x}_{k+1} = \mathbf{x}_k + \mathbf{v}_{k+1}$. Setting $\beta = 0$ recovers gradient descent. Momentum accumulates consistent gradient components (along the valley) and cancels alternating ones (across it).

**Nesterov's accelerated gradient** (Nesterov, 1983) evaluates the gradient at a look-ahead point:

$$\mathbf{y}_k = \mathbf{x}_k + \beta\,(\mathbf{x}_k - \mathbf{x}_{k-1}), \qquad \mathbf{x}_{k+1} = \mathbf{y}_k - \eta\,\nabla f(\mathbf{y}_k).$$

The only difference from heavy ball is where the gradient is taken: at $\mathbf{y}_k$, after the momentum move, instead of at $\mathbf{x}_k$.

### A hand-run example

For the one-dimensional $f(x) = 2x^2$ (curvature $\lambda = 4$), take $\eta = 0.2$, $\beta = 0.5$, $x_{-1} = x_0 = 1$. The gradient is $4x$, so the heavy-ball update is $x_{k+1} = x_k - 0.8x_k + 0.5(x_k - x_{k-1})$:

| $k$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| heavy ball $x_k$ | 1 | 0.2 | $-0.36$ | $-0.352$ | $-0.0664$ | 0.1295 |
| gradient descent $x_k$ | 1 | 0.2 | 0.04 | 0.008 | 0.0016 | 0.0003 |

On this easy one-dimensional problem momentum is worse: it overshoots zero and oscillates, because there is nothing to gain from speed. Momentum pays off only when the curvatures differ greatly.

### Analysis on a quadratic

On a quadratic, each eigen-direction with curvature $\lambda$ decouples, and the error obeys $e_{k+1} = (1 + \beta - \eta\lambda)\,e_k - \beta\,e_{k-1}$, a linear recurrence with the **characteristic equation**
$$r^2 - (1 + \beta - \eta\lambda)\,r + \beta = 0 .$$
The errors are combinations of $r_1^k$ and $r_2^k$, so the method converges iff both roots satisfy $|r| < 1$, which happens exactly when $0 \le \beta < 1$ and $0 < \eta\lambda < 2(1 + \beta)$. When the discriminant $(1 + \beta - \eta\lambda)^2 - 4\beta$ is negative the roots are complex conjugates with modulus $\sqrt\beta$: the error oscillates while shrinking by $\sqrt\beta$ per step, which is the oscillation in the table (here $\sqrt{0.5} \approx 0.707$). Momentum extends the stable step range from $2/\lambda$ to $2(1 + \beta)/\lambda$.

### Acceleration

Let $f$ be a quadratic with eigenvalues in $[\mu, L]$ and $\kappa = L/\mu$. With the tuned parameters
$$\eta = \frac{4}{(\sqrt L + \sqrt\mu)^2}, \qquad \beta = \Big(\frac{\sqrt\kappa - 1}{\sqrt\kappa + 1}\Big)^2,$$
every direction has complex roots of modulus $\sqrt\beta = (\sqrt\kappa - 1)/(\sqrt\kappa + 1)$, versus $(\kappa - 1)/(\kappa + 1)$ for tuned gradient descent. For $f(x,y) = \tfrac12(x^2 + 100y^2)$, $\kappa = 100$: gradient descent with $\eta = 2/101$ has rate $99/101 \approx 0.980$ and needed $691$ steps in a run to bring the norm down by $10^{6}$, while heavy ball with $\eta = 4/121$ and $\beta = (9/11)^2 \approx 0.669$ has rate $9/11 \approx 0.818$ and needed $93$ steps. The number of steps scales with $\sqrt\kappa$ instead of $\kappa$.

For general convex functions the analogous statements are due to Nesterov: for convex $L$-smooth $f$, Nesterov's method with $\eta = 1/L$ and a momentum weight growing toward 1, such as $\beta_k = (k-1)/(k+2)$, satisfies $f(\mathbf{x}_k) - f^\star = O\big(L\lVert\mathbf{x}_0 - \mathbf{x}^\star\rVert_2^2/k^2\big)$, improving on gradient descent's $O(1/k)$; this matches the order of a lower bound for methods that use only gradients (Nemirovski and Yudin, 1983), so it cannot be improved in general. For $\mu$-strongly convex $f$ with $\beta = (\sqrt\kappa - 1)/(\sqrt\kappa + 1)$ the error contracts about $1 - 1/\sqrt\kappa$ per step. Accelerated methods are **not monotone**: $f(\mathbf{x}_k)$ can rise for a few steps before falling, and heavy ball is not guaranteed to converge on all convex functions with the quadratic tuning. In deep learning, SGD with momentum ($\beta$ around $0.9$) is a standard baseline: the velocity also averages out minibatch noise.

### In code

```python
def heavy_ball(grad, x0, lr, beta, steps):
    x = list(x0)
    prev = list(x0)
    for _ in range(steps):
        g = grad(x)
        new = [xi - lr * gi + beta * (xi - pi)
               for xi, gi, pi in zip(x, g, prev)]
        prev, x = x, new
    return x
```

The first step uses $\mathbf{x}_{-1} = \mathbf{x}_0$, so it carries no momentum. In PyTorch, `torch.optim.SGD(params, lr=0.1, momentum=0.9)` stores the velocity in a buffer, and `nesterov=True` selects the look-ahead variant.

@example
title: Two heavy-ball steps
problem: For $f(x) = 3x^2$ run the heavy-ball method with $\eta = 0.1$ and $\beta = 0.8$ from $x_{-1} = x_0 = 2$. Find $x_1$ and $x_2$, and decide if these parameters converge.
step: The gradient is $6x$. First step, with no momentum since $x_0 - x_{-1} = 0$: $x_1 = 2 - 0.1\cdot 12 = 0.8$.
step: Second step: $\nabla f(x_1) = 4.8$, so $x_2 = 0.8 - 0.1 \cdot 4.8 + 0.8(0.8 - 2) = 0.8 - 0.48 - 0.96 = -0.64$.
step: Convergence check with $\lambda = 6$: $\eta\lambda = 0.6$, and $2(1 + \beta) = 3.6$, so $0 < 0.6 < 3.6$ and $\beta < 1$: it converges.
step: The roots solve $r^2 - (1.8 - 0.6)r + 0.8 = r^2 - 1.2r + 0.8 = 0$ with discriminant $1.44 - 3.2 < 0$, so they are complex with modulus $\sqrt{0.8} \approx 0.894$: slow, oscillating convergence.
answer: $x_1 = 0.8$ and $x_2 = -0.64$; the method converges, with oscillation, at rate $\sqrt{0.8} \approx 0.894$ per step.

@example
title: Tuning momentum for a condition number
problem: A quadratic has eigenvalues between $\mu = 1$ and $L = 16$. Find the tuned heavy-ball parameters and compare the rate with that of tuned gradient descent.
step: $\kappa = 16$, so $\sqrt\kappa = 4$ and $\sqrt L + \sqrt\mu = 5$.
step: Step size: $\eta = 4/25 = 0.16$. Momentum: $\beta = (3/5)^2 = 0.36$.
step: Heavy-ball rate: $\sqrt\beta = 0.6$. Tuned gradient descent has $(\kappa - 1)/(\kappa + 1) = 15/17 \approx 0.882$.
step: Steps to shrink the error by $10^{-6}$: $\ln 10^6/(-\ln 0.6) \approx 27.1$ for momentum, versus $\ln 10^6/(-\ln 0.882) \approx 110$ for gradient descent: about $\sqrt\kappa = 4$ times fewer.
answer: $\eta = 0.16$, $\beta = 0.36$, rate $0.6$ versus $0.882$: about four times faster.

@mistakes
- Believing momentum always helps: on a well-conditioned problem it may only add oscillation, and with too large a $\beta$ or $\eta$ it diverges (stability needs $\eta\lambda < 2(1 + \beta)$).
- Mixing up heavy ball and Nesterov: heavy ball takes the gradient at $\mathbf{x}_k$; Nesterov takes it at the look-ahead point $\mathbf{y}_k$.
- Assuming accelerated methods decrease the loss at every step: the loss can go up for a few steps, which is not a bug.
- Raising $\beta$ without lowering $\eta$: the effective step along a consistent direction is about $\eta/(1-\beta)$, so $\beta = 0.9$ makes steps up to ten times larger.

@article
A friend says, "my gradient descent will reach 1% error in about two thousand steps, and I can prove it." How can anyone know that without running it? Convergence theory answers by combining two numbers that describe the function: how fast its gradient can change, and how sharply it curves upward at least.

### Two assumptions

A differentiable $f$ is **$L$-smooth** if its gradient is $L$-Lipschitz: $\lVert\nabla f(\mathbf{x}) - \nabla f(\mathbf{y})\rVert_2 \le L\lVert\mathbf{x} - \mathbf{y}\rVert_2$ for all $\mathbf{x}, \mathbf{y}$. For a twice differentiable $f$ this holds exactly when every eigenvalue of the Hessian has magnitude at most $L$ everywhere; for a convex function, when $\mathbf{H} \preceq L\mathbf{I}$. The consequence we use is the **descent lemma**:

$$f(\mathbf{y}) \le f(\mathbf{x}) + \nabla f(\mathbf{x})^\top(\mathbf{y} - \mathbf{x}) + \tfrac{L}{2}\lVert\mathbf{y} - \mathbf{x}\rVert_2^2 .$$

A differentiable $f$ is **$\mu$-strongly convex** ($\mu > 0$) if $f(\mathbf{y}) \ge f(\mathbf{x}) + \nabla f(\mathbf{x})^\top(\mathbf{y} - \mathbf{x}) + \tfrac{\mu}{2}\lVert\mathbf{y} - \mathbf{x}\rVert_2^2$ for all $\mathbf{x}, \mathbf{y}$: the function lies above a parabola, not just above its tangent. For a convex quadratic $\tfrac12\mathbf{x}^\top\mathbf{A}\mathbf{x}$ the constants are $L = \lambda_{\max}(\mathbf{A})$ and $\mu = \lambda_{\min}(\mathbf{A})$. The ratio $\kappa = L/\mu \ge 1$ is the **condition number**.

### The descent lemma gives progress per step

Take one gradient step $\mathbf{x}^+ = \mathbf{x} - \eta\nabla f(\mathbf{x})$ and set $\mathbf{y} = \mathbf{x}^+$ in the descent lemma: $f(\mathbf{x}^+) \le f(\mathbf{x}) - \eta\big(1 - \tfrac{L\eta}{2}\big)\lVert\nabla f(\mathbf{x})\rVert_2^2$. With $\eta = 1/L$ this becomes

$$f(\mathbf{x}^+) \le f(\mathbf{x}) - \frac{1}{2L}\lVert\nabla f(\mathbf{x})\rVert_2^2 .$$

Every step decreases $f$ by an amount tied to the gradient norm. For any $\eta < 2/L$ the factor $1 - L\eta/2$ is positive, which explains the stability limit $2/L$ from last week.

### Two theorems

**Theorem 1 (convex, smooth).** Let $f$ be convex and $L$-smooth with a minimizer $\mathbf{x}^\star$. Gradient descent with $\eta = 1/L$ satisfies
$$f(\mathbf{x}_k) - f^\star \le \frac{L\,\lVert\mathbf{x}_0 - \mathbf{x}^\star\rVert_2^2}{2k}.$$
The error shrinks like $1/k$: a **sublinear** rate, so each extra digit of accuracy costs ten times as many steps.

**Theorem 2 (strongly convex, smooth).** Let $f$ be $\mu$-strongly convex and $L$-smooth. With $\eta = 1/L$,
$$f(\mathbf{x}_k) - f^\star \le \Big(1 - \frac{\mu}{L}\Big)^k\big(f(\mathbf{x}_0) - f^\star\big), \qquad \lVert\mathbf{x}_k - \mathbf{x}^\star\rVert_2^2 \le \Big(1 - \frac{\mu}{L}\Big)^k\lVert\mathbf{x}_0 - \mathbf{x}^\star\rVert_2^2 .$$
The error shrinks geometrically: a **linear** rate (a straight line on a log plot). Since $(1 - 1/\kappa)^k \le e^{-k/\kappa}$, reaching error $\varepsilon$ takes at most about $\kappa\ln(1/\varepsilon)$ steps relative to the starting error, so the number of steps is proportional to the condition number.

(The distance bound is also standard; it follows from combining smoothness and strong convexity in one inequality, which we do not reproduce here.)

*Proof of the function-value bound.* The descent lemma gives $f(\mathbf{x}^+) - f^\star \le f(\mathbf{x}) - f^\star - \tfrac{1}{2L}\lVert\nabla f(\mathbf{x})\rVert_2^2$. Strong convexity gives, for every $\mathbf{y}$, $f(\mathbf{y}) \ge f(\mathbf{x}) + \nabla f(\mathbf{x})^\top(\mathbf{y} - \mathbf{x}) + \tfrac\mu2\lVert\mathbf{y}-\mathbf{x}\rVert_2^2$; minimizing the right side over $\mathbf{y}$ (at $\mathbf{y} = \mathbf{x} - \nabla f(\mathbf{x})/\mu$) shows $f^\star \ge f(\mathbf{x}) - \tfrac{1}{2\mu}\lVert\nabla f(\mathbf{x})\rVert_2^2$, that is $\lVert\nabla f(\mathbf{x})\rVert_2^2 \ge 2\mu\big(f(\mathbf{x}) - f^\star\big)$. Substituting, $f(\mathbf{x}^+) - f^\star \le \big(1 - \tfrac{\mu}{L}\big)\big(f(\mathbf{x}) - f^\star\big)$, and induction gives the claim. $\blacksquare$

### A worked count

Take $f(x,y) = \tfrac12(x^2 + 20y^2)$, so $\mu = 1$, $L = 20$, $\kappa = 20$. With $\eta = 1/L = 0.05$ the $x$ coordinate shrinks by $0.95$ per step. To shrink it by a factor of $10^{3}$ we need $0.95^k \le 10^{-3}$, so $k \ge \ln 1000 / (-\ln 0.95) \approx 134.7$: **135 steps**. With the better step $\eta = 2/(L + \mu) = 2/21$, both coordinates are multiplied by $\pm 19/21$ and we need $(19/21)^k \le 10^{-3}$, so $k \ge 69.02$: **70 steps**, roughly half as many.

### In code

The theory predicts iteration counts, which you can measure. For a diagonal quadratic $f(\mathbf{x}) = \tfrac12\sum_i a_i x_i^2$ the update multiplies coordinate $i$ by $1 - \eta a_i$, so counting steps until $\lVert\mathbf{x}\rVert_2$ falls below a tolerance takes a few lines, and the count scales with $\kappa$.

```python
import math

def steps_needed(a, eta, tol, max_steps=2000):
    x = [1.0] * len(a)
    for k in range(max_steps + 1):
        if math.sqrt(sum(t * t for t in x)) <= tol:
            return k
        x = [t - eta * ai * t for t, ai in zip(x, a)]
    return -1
```

Real losses are rarely strongly convex everywhere, and the constants $L$ and $\mu$ are rarely known, which is why practitioners tune the step size by experiment. The theory explains what they see: the speed is set by $\kappa$, and the step by $L$.

@example
title: Constants and a rate for a quadratic
problem: For $f(x,y) = x^2 + 6y^2$, find $L$, $\mu$ and $\kappa$, the guaranteed per-step factor for $f(\mathbf{x}_k) - f^\star$ with $\eta = 1/L$, and the number of steps that guarantee a reduction of $f(\mathbf{x}_k) - f^\star$ by a factor $10^{-4}$.
step: The Hessian is $\operatorname{diag}(2, 12)$, so $L = 12$, $\mu = 2$ and $\kappa = 6$.
step: With $\eta = 1/L$, Theorem 2 gives the factor $1 - \mu/L = 1 - 1/6 = 5/6 \approx 0.8333$ per step.
step: We need $(5/6)^k \le 10^{-4}$, so $k \ge \ln(10^4)/\ln(6/5) = 9.2103/0.18232 \approx 50.5$.
step: The guarantee holds after $k = 51$ steps. (The true error may fall faster; the theorem is an upper bound.)
answer: $L = 12$, $\mu = 2$, $\kappa = 6$, factor $5/6$ per step, and $51$ steps.

@example
title: What a sublinear guarantee demands
problem: A convex function is $4$-smooth and the starting point is at distance $3$ from a minimizer. Using Theorem 1 with $\eta = 1/L$, bound the error after $100$ steps and find how many steps guarantee error at most $0.01$.
step: The distance squared is $\lVert\mathbf{x}_0 - \mathbf{x}^\star\rVert_2^2 = 9$ and $L = 4$, so the bound is $L \cdot 9/(2k) = 18/k$.
step: At $k = 100$, the bound is $18/100 = 0.18$.
step: For error at most $0.01$ we need $18/k \le 0.01$, so $k \ge 1800$.
step: Each factor of $10$ in accuracy costs a factor of $10$ in steps, in contrast with the strongly convex case, where it costs a fixed number of extra steps.
answer: The error is at most $0.18$ after $100$ steps, and $1800$ steps guarantee at most $0.01$.

@mistakes
- Confusing $L$ with the Lipschitz constant of $f$ itself: $L$ bounds how fast the gradient changes, so it equals the largest Hessian eigenvalue, not the gradient size.
- Using the linear rate for a convex function that is not strongly convex: with $\mu = 0$ the factor $1 - \mu/L$ is $1$ and only the $1/k$ rate remains.
- Reading $\kappa\ln(1/\varepsilon)$ as the exact number of steps: it is an upper bound from the theorem, and the actual count may be lower.
- Forgetting that the theorems assume a step size no larger than $1/L$ (or at least $\eta < 2/L$ for convergence): a larger step breaks the descent lemma argument.

model:
```python
def steps_to_reduce(a, eta, factor, max_steps=2000):
    """Steps of gradient descent on 0.5 * sum(a_i x_i^2) until f falls by factor."""
    def value(x):
        return 0.5 * sum(ai * t * t for ai, t in zip(a, x))

    x = [1.0] * len(a)
    target = factor * value(x)
    for k in range(max_steps + 1):
        if value(x) <= target:
            return k
        x = [t - eta * ai * t for t, ai in zip(x, a)]
    return -1
```
hint: Record the starting function value once, check the current value against `factor` times it before each update, and update each coordinate $x_i \leftarrow x_i - \eta\,a_i x_i$.
solution: The gradient of coordinate $i$ is $a_i x_i$. Testing the value before updating lets the loop return 0 when the target already holds, and the loop runs up to `max_steps` updates before giving up. The step size $0.1$ equals $2/\lambda_{\max}$ for `[1.0, 20.0]`, so one coordinate flips sign without shrinking and the function value never falls below its starting value times $10^{-6}$, giving $-1$; $0.11$ diverges. Comparing with the norm instead of the function value, or with the current value instead of the starting value, gives different counts.

@quiz self
prompt: A student minimizes $f(x,y) = x^2 + 10y^2$ from $(1,1)$ with gradient descent and records $f$ after $10$, $50$ and $100$ steps for three step sizes. For $\eta = 0.005$: $2.03$, $0.366$, $0.134$. For $\eta = 0.05$: $0.122$, $2.7\times 10^{-5}$, $7.1 \times 10^{-10}$. For $\eta = 0.12$: $8.4\times 10^{3}$, $4.1\times 10^{15}$, $1.7\times 10^{30}$. Explain each row in terms of $L$, $\mu$ and the stability limit, and say which step size is best.
hint: The Hessian is $\operatorname{diag}(2, 20)$. Compare each step size with $1/L$ and $2/L$ and compute the per-step factor of the slow coordinate.
solution: The Hessian is $\operatorname{diag}(2, 20)$, so $\mu = 2$, $L = 20$, $\kappa = 10$ and the stability limit is $2/L = 0.1$. For $\eta = 0.005$, far below $1/L$, both coordinates shrink, but the slow coordinate $x$ is multiplied by only $1 - 2\eta = 0.99$, so $f \approx 0.99^{2k}$ and 100 steps leave about $0.13$: stable but too slow. For $\eta = 0.05 = 1/L$, the factors are $0.9$ for $x$ and $0$ for $y$, so $f$ falls like $0.9^{2k}$, matching Theorem 2's rate $(1 - \mu/L)^k = 0.9^k$ (the actual decrease is even faster in $f$); this is the best of the three. For $\eta = 0.12 > 2/L$ the $y$ factor is $1 - 20 \cdot 0.12 = -1.4$, so $|y|$ grows by $1.4$ each step and $f$ grows like $1.96^k$, which explains the explosion even though $x$ still shrinks. The lesson is that the large curvature $L$ sets the maximum step size and $\kappa$ sets how many steps are needed.

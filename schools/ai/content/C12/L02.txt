@article
A model is a pipeline: inputs go through a linear layer, then a nonlinearity, then a loss. To train it we need the derivative of the final loss with respect to numbers deep inside the pipeline. The chain rule tells us how, and written with Jacobians it becomes a few matrix products.

### The chain rule with Jacobians

Let $\mathbf{g}:\mathbb{R}^n \to \mathbb{R}^m$ and $\mathbf{h}:\mathbb{R}^m \to \mathbb{R}^p$ be differentiable. For the composition $\mathbf{f} = \mathbf{h} \circ \mathbf{g}$,

$$\mathbf{J}_{\mathbf{f}}(\mathbf{x}) = \mathbf{J}_{\mathbf{h}}\big(\mathbf{g}(\mathbf{x})\big)\, \mathbf{J}_{\mathbf{g}}(\mathbf{x}),$$

a $p \times m$ matrix times an $m \times n$ matrix, giving $p \times n$. The shapes must chain: the inner dimension $m$ is shared. If $p = 1$ (a scalar loss), transposing gives the gradient:

$$\nabla_{\mathbf{x}} f = \mathbf{J}_{\mathbf{g}}(\mathbf{x})^\top \, \nabla_{\mathbf{z}} h(\mathbf{z})\big|_{\mathbf{z} = \mathbf{g}(\mathbf{x})}.$$

**A small case.** Let $\mathbf{x} = (1,2)^\top$, $\mathbf{z} = \mathbf{W}\mathbf{x}$ with $\mathbf{W} = \begin{pmatrix} 1 & 2 \\ 3 & 0 \\ -1 & 1 \end{pmatrix}$, target $\mathbf{t} = (4,1,3)^\top$ and loss $h(\mathbf{z}) = \tfrac12 \lVert \mathbf{z} - \mathbf{t} \rVert_2^2$. Then $\mathbf{z} = (5,3,1)^\top$, the residual is $\mathbf{r} = \mathbf{z} - \mathbf{t} = (1,2,-2)^\top$, and $\nabla_{\mathbf{z}} h = \mathbf{r}$. The Jacobian of $\mathbf{z}$ with respect to $\mathbf{x}$ is $\mathbf{W}$, so $\nabla_{\mathbf{x}} h = \mathbf{W}^\top \mathbf{r} = (9, 0)^\top$.

### Backpropagation is a chain of vector–Jacobian products

For a pipeline $\mathbf{x} \to \mathbf{a}_1 \to \mathbf{a}_2 \to \dots \to L$ with a scalar loss $L$, the gradient is $\mathbf{J}_1^\top \mathbf{J}_2^\top \cdots \nabla_{\mathbf{a}_k} L$. Multiplying from the loss end, we only ever multiply a **matrix by a vector**: each step takes the gradient with respect to a layer's output and returns the gradient with respect to its input. This is a **vector–Jacobian product** (VJP), and running the pipeline backward this way is **reverse-mode automatic differentiation**, which neural-network practitioners call **backpropagation** (popularized for neural networks by Rumelhart, Hinton and Williams, 1986). Multiplying from the input end would form matrix–matrix products and cost far more when the output is a scalar and the layers are wide. Elementwise activations such as $\tanh$ have diagonal Jacobians, so their VJP is just an elementwise product with the local derivative.

### Gradients of five standard losses

Let $\mathbf{x}$ be a feature vector, $z = \mathbf{w}^\top \mathbf{x}$ a score, and $\sigma(u) = 1/(1 + e^{-u})$ the logistic sigmoid.

| loss | formula | gradient with respect to $\mathbf{w}$ |
|---|---|---|
| squared | $\tfrac12 (z - y)^2$ | $(z - y)\,\mathbf{x}$ |
| logistic, $y \in \{-1,+1\}$ | $\log(1 + e^{-yz})$ | $-y\,\sigma(-yz)\,\mathbf{x}$ |
| hinge, $y \in \{-1,+1\}$ | $\max(0, 1 - yz)$ | $-y\,\mathbf{x}$ if $yz < 1$, else $\mathbf{0}$ |
| L2 penalty | $\tfrac{\lambda}{2}\lVert \mathbf{w}\rVert_2^2$ | $\lambda \mathbf{w}$ |
| softmax cross-entropy | $-\log p_k$ | $(\mathbf{p} - \mathbf{e}_k)\,\mathbf{x}^\top$ for the weight matrix |

Each follows the same pattern: the derivative of the loss with respect to the score, times $\mathbf{x}$, since $\partial z / \partial \mathbf{w} = \mathbf{x}^\top$. For the logistic loss, $\frac{d}{dz}\log(1 + e^{-yz}) = \frac{-y e^{-yz}}{1 + e^{-yz}} = -y\,\sigma(-yz)$. The hinge loss is not differentiable at $yz = 1$; at that kink any value between the two one-sided slopes is a **subgradient**, and implementations pick one.

**Softmax cross-entropy.** For logits $\mathbf{z} \in \mathbb{R}^K$, $p_j = e^{z_j}/\sum_l e^{z_l}$ and the loss for true class $k$ is $\ell = -z_k + \log \sum_l e^{z_l}$. Then $\partial \ell / \partial z_j = -[j = k] + p_j$, so

$$\nabla_{\mathbf{z}} \ell = \mathbf{p} - \mathbf{e}_k.$$

The gradient is the predicted distribution minus the one-hot target, and its entries sum to zero.

### In code

Computing $e^{z_j}$ directly overflows for large logits, so subtract $\max_j z_j$ first; the softmax does not change because the common factor cancels.

```python
import math

def softmax(z):
    m = max(z)
    exps = [math.exp(t - m) for t in z]
    total = sum(exps)
    return [e / total for e in exps]

print(softmax([1.0, 0.0, -1.0]))
```

With PyTorch the same gradient comes from `loss.backward()`, which applies VJPs through every operation recorded in the forward pass; the formulas above are what it computes.

Find the gradient of $h$ with respect to $\mathbf{x}$, and its gradient with respect to $\mathbf{W}$.
step: Forward pass: $\mathbf{z} = (1\cdot 2 + 0\cdot(-1),\; 2 \cdot 2 + 1\cdot(-1)) = (2, 3)^\top$.
step: Residual: $\mathbf{r} = \mathbf{z} - \mathbf{t} = (-1, 2)^\top$, which is $\nabla_{\mathbf{z}} h$.
step: Gradient with respect to $\mathbf{x}$: $\mathbf{W}^\top \mathbf{r} = \begin{pmatrix} 1 & 2 \\ 0 & 1 \end{pmatrix}(-1, 2)^\top = (3, 2)^\top$.
step: Gradient with respect to $\mathbf{W}$: entry $(i,j)$ is $r_i x_j$, so $\nabla_{\mathbf{W}} h = \mathbf{r}\mathbf{x}^\top = \begin{pmatrix} -2 & 1 \\ 4 & -2 \end{pmatrix}$.

step: Check: the entries sum to zero, as they must, and the true class gets a negative gradient, so a gradient step raises its logit.

@mistakes
- Getting the order of Jacobians backward: the Jacobian of the outer function is on the left, $\mathbf{J}_{\mathbf{h}}\mathbf{J}_{\mathbf{g}}$, and the shapes will not multiply if you reverse them.
- Forgetting to transpose: for a scalar loss the gradient is $\mathbf{J}_{\mathbf{g}}^\top \nabla h$, not $\mathbf{J}_{\mathbf{g}} \nabla h$.
- Writing the softmax cross-entropy gradient as $-\mathbf{e}_k$ or as $\mathbf{p}$ alone: it is $\mathbf{p} - \mathbf{e}_k$.
- Computing softmax with `exp(z)` on large logits: it overflows, and subtracting the maximum first fixes it without changing the result.

model:
```python
import math

def softmax_ce_grad(z, k):
    """Gradient of softmax cross-entropy with respect to the logits."""
    m = max(z)
    exps = [math.exp(t - m) for t in z]
    total = sum(exps)
    grad = [e / total for e in exps]
    grad[k] -= 1.0
    return grad
```
hint: Compute the softmax after subtracting `max(z)` from every logit, then subtract 1 from the entry at index `k`.
solution: The stable softmax gives $\mathbf{p}$; the gradient is $\mathbf{p}$ with 1 subtracted at the true class. A version without the maximum shift raises an overflow error on the logits $\pm 1000$.

@quiz self
prompt: A binary classifier outputs $p = \sigma(z)$ with $z = \mathbf{w}^\top\mathbf{x}$ and is trained with the binary cross-entropy $\ell = -\big[y\log p + (1-y)\log(1-p)\big]$ for a label $y \in \{0,1\}$. Derive $d\ell/dz$ and $\nabla_{\mathbf{w}}\ell$, showing each factor of the chain rule.
hint: Use $\sigma'(z) = \sigma(z)(1 - \sigma(z))$ and multiply three derivatives: $\ell$ with respect to $p$, $p$ with respect to $z$, $z$ with respect to $\mathbf{w}$.
solution: First, $d\ell/dp = -y/p + (1-y)/(1-p)$. Second, $dp/dz = p(1-p)$. Multiplying, $d\ell/dz = \big(-y/p + (1-y)/(1-p)\big)p(1-p) = -y(1-p) + (1-y)p = p - y$. Third, $\partial z/\partial\mathbf{w} = \mathbf{x}^\top$, so $\nabla_{\mathbf{w}}\ell = (p - y)\,\mathbf{x}$. The result has the same form as the squared-loss gradient for a linear model, with the prediction $p$ in place of $z$.

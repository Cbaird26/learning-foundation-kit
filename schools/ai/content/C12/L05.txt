@article
Imagine a long, narrow canyon whose floor slopes gently toward a lake at one end. Standing on one wall, the steepest downhill direction points almost straight across the canyon, not along it. A walker who follows it bounces from wall to wall while creeping toward the lake. That bouncing is what gradient descent does on badly scaled problems, and the step size decides whether it settles down or flings itself out of the canyon.

### The method

**Gradient descent** minimizes a differentiable $f:\mathbb{R}^n \to \mathbb{R}$ by starting at $\mathbf{x}_0$ and repeating

$$\mathbf{x}_{k+1} = \mathbf{x}_k - \eta\,\nabla f(\mathbf{x}_k),$$

where $\eta > 0$ is the step size. The direction $-\nabla f$ is a descent direction: by the first-order Taylor expansion, $f(\mathbf{x} - \eta\nabla f(\mathbf{x})) \approx f(\mathbf{x}) - \eta\lVert\nabla f(\mathbf{x})\rVert_2^2$, which decreases when $\eta$ is small enough and the gradient is nonzero.

### A two-dimensional quadratic

Let $f(x,y) = 2x^2 + 8y^2$, whose gradient is $(4x, 16y)$ and whose Hessian is $\operatorname{diag}(4, 16)$. The update acts on each coordinate separately:

$$x_{k+1} = (1 - 4\eta)\,x_k, \qquad y_{k+1} = (1 - 16\eta)\,y_k.$$

Each coordinate is multiplied by a fixed factor, so after $k$ steps $x_k = (1-4\eta)^k x_0$ and $y_k = (1 - 16\eta)^k y_0$. Both converge to $0$ exactly when $|1 - 4\eta| < 1$ and $|1 - 16\eta| < 1$, that is $0 < \eta < 2/16 = 0.125$: **the largest curvature $\lambda_{\max}$ of the Hessian limits the step size to $\eta < 2/\lambda_{\max}$**. Starting from $(1,1)$ where $f = 10$:

| $k$ | $\eta = 0.05$: $f$ | $\eta = 0.1$: $f$ | $\eta = 0.13$: $f$ |
|---|---|---|---|
| 1 | 1.6 | 3.6 | 9.79 |
| 2 | 0.832 | 1.296 | 10.99 |
| 5 | 0.2147 | 0.0605 | 17.27 |
| 20 | 0.0003 | $\approx 0$ | 173.8 |

With $\eta = 0.05$ the $y$ coordinate dies fast (factor $0.2$) while $x$ shrinks slowly (factor $0.8$), so the slow direction sets the speed. With $\eta = 0.1$ the factors are $0.6$ and $-0.6$: the best common speed, because $\eta = 2/(\lambda_{\max} + \lambda_{\min}) = 0.1$ balances the two. With $\eta = 0.13$ the $y$ factor is $-1.08$, which flips sign and grows, so the loss diverges (the $y$ coordinate bounces across the valley with growing amplitude).

### Conditioning

The ratio $\kappa = \lambda_{\max}/\lambda_{\min}$ is the **condition number** of the quadratic; here $\kappa = 4$. Even with the best fixed step, the slowest factor is $(\kappa - 1)/(\kappa + 1) = 0.6$, and for $\kappa = 1000$ it is $0.998$: hundreds of steps for each digit of accuracy. Level sets of such a function are long thin ellipses, and the gradient is nearly perpendicular to the long axis, which causes the zigzag. Rescaling the inputs of a model so that features have similar sizes reduces $\kappa$ and is one of the cheapest ways to speed up training.

### Choosing the step by line search

For non-quadratic functions there is no single formula, because the curvature changes from point to point. **Backtracking line search** adapts $\eta$ at each iteration: start from a trial step $t = t_0$ and shrink it by a factor $\rho \in (0,1)$ until the **Armijo condition**

$$f\big(\mathbf{x} - t\,\nabla f(\mathbf{x})\big) \le f(\mathbf{x}) - c\,t\,\lVert\nabla f(\mathbf{x})\rVert_2^2$$

holds, with a small constant such as $c = 0.1$ (or $10^{-4}$). It demands that the actual decrease be at least a fraction $c$ of the decrease the linear approximation promises. For a differentiable $f$ with $\nabla f(\mathbf{x}) \ne \mathbf{0}$ the loop terminates, because for small $t$ the linear prediction is accurate. On the function above, from $(1,1)$ with $t_0 = 1$, $\rho = \tfrac12$ and $c = 0.1$: the trial steps $1, \tfrac12, \tfrac14, \tfrac18$ all fail (the function value at $t = \tfrac18$ is $8.5$, but the condition demands at most $6.6$), and $t = \tfrac1{16}$ succeeds, moving to $(0.75, 0)$ with $f = 1.125$.

### In code

```python
def gradient_descent(grad, x, eta, steps):
    x = list(x)
    for _ in range(steps):
        g = grad(x)
        x = [xi - eta * gi for xi, gi in zip(x, g)]
    return x

grad = lambda v: [4 * v[0], 16 * v[1]]
print(gradient_descent(grad, [1.0, 1.0], 0.1, 5))
```

In machine learning practice, the step size (learning rate) is the most important hyperparameter, and it is usually tuned by trying values spaced by factors of about 3 or 10 and watching the training loss.

@example
title: One step and the stability limit
problem: For $f(x,y) = x^2 + 5y^2$, take one step of gradient descent from $(3, 1)$ with $\eta = 0.15$. Then find the range of step sizes for which gradient descent converges.
step: The gradient is $(2x, 10y)$, which at $(3,1)$ equals $(6, 10)$.
step: The update is $(3 - 0.15 \cdot 6,\; 1 - 0.15 \cdot 10) = (2.1, -0.5)$. The value of $f$ goes from $9 + 5 = 14$ to $4.41 + 1.25 = 5.66$.
step: The Hessian is $\operatorname{diag}(2, 10)$. The coordinates are multiplied by $1 - 2\eta$ and $1 - 10\eta$ at each step, so we need $|1 - 2\eta| < 1$ and $|1 - 10\eta| < 1$.
step: The binding condition is the second: $\eta < 2/10 = 0.2$. So gradient descent converges for $0 < \eta < 0.2$ and diverges from any starting point with $y_0 \ne 0$ when $\eta > 0.2$.
answer: One step gives $(2.1, -0.5)$; convergence holds exactly for $0 < \eta < 0.2$ (for starting points with $y_0 \ne 0$).

@example
title: A backtracking line search
problem: For $f(x,y) = x^2 + 9y^2$ at the point $(1,1)$, find the step size chosen by backtracking with $t_0 = 1$, $\rho = \tfrac12$ and $c = 0.1$.
step: At $(1,1)$: $f = 10$, $\nabla f = (2, 18)$, and $\lVert\nabla f\rVert_2^2 = 4 + 324 = 328$.
step: The Armijo bound at step $t$ is $10 - 0.1 \cdot 328\, t = 10 - 32.8\,t$. At $t = 1$, the new point is $(-1, -17)$ with $f = 2602$, far above the bound $-22.8$: reject. At $t = \tfrac12$: the point $(0, -8)$ has $f = 576$ versus $-6.4$: reject.
step: At $t = \tfrac14$: the point $(0.5, -3.5)$ has $f = 110.5$ versus $1.8$: reject. At $t = \tfrac18$: the point $(0.75, -1.25)$ has $f = 14.625$ versus $5.9$: reject.
step: At $t = \tfrac1{16}$: the point $(0.875, -0.125)$ has $f \approx 0.906$ versus the bound $7.95$: accept.
answer: The line search accepts $t = 1/16$, reaching $(0.875, -0.125)$.

@mistakes
- Using a step size above $2/\lambda_{\max}$ because it "worked on another problem": the safe range depends on the curvature of the function at hand.
- Choosing the step by looking only at the slowest coordinate: the fastest-curving direction sets the upper limit, while the slowest direction sets the speed.
- Using a line search condition that only requires $f$ to decrease: tiny decreases can make the iterates stall far from a minimum, which is why the Armijo condition compares with the predicted decrease.
- Reading a falling loss as proof of convergence: with a good step size the loss falls, but with a small step size it also falls, very slowly.

model:
```python
def backtracking_step(f, grad, x, t0=1.0, rho=0.5, c=0.1):
    """One gradient step with Armijo backtracking; returns (new_x, t)."""
    g = grad(x)
    gg = sum(gi * gi for gi in g)
    fx = f(x)
    t = t0
    while True:
        new_x = [xi - t * gi for xi, gi in zip(x, g)]
        if f(new_x) <= fx - c * t * gg:
            return new_x, t
        t *= rho
```
hint: Compute `g`, `f(x)` and the squared norm of `g` once, then loop: try the step `t`, and either return or shrink `t`.
solution: The Armijo test compares the real decrease with $c\,t\,\lVert g\rVert_2^2$. The point $(1,1)$ rejects $t = 1, 0.5, 0.25$ and accepts $0.125$. With a zero gradient the right side equals $f(x)$, so the first trial passes; the loop is safe because for a nonzero gradient some small $t$ always passes.

prompt: Gradient descent with a fixed step size $\eta$ is run on $f(\mathbf{x}) = \tfrac12\mathbf{x}^\top\mathbf{A}\mathbf{x}$ with $\mathbf{A}$ symmetric positive definite and eigenvalues $\lambda_{\min} \le \lambda_{\max}$. Which statements are true? Select all that apply.
choice*: It converges from every starting point if and only if $0 < \eta < 2/\lambda_{\max}$.
choice*: Along an eigenvector with eigenvalue $\lambda$, the distance to the minimizer is multiplied by $1 - \eta\lambda$ at each step.
choice*: With $\eta = 2/(\lambda_{\min} + \lambda_{\max})$, the slowest factor has magnitude $(\kappa - 1)/(\kappa + 1)$ with $\kappa = \lambda_{\max}/\lambda_{\min}$.
choice: Doubling $\eta$ always halves the number of steps needed.
hint: Decompose the starting point along the eigenvectors of $\mathbf{A}$ and track each component.
solution: In the eigenbasis each component is multiplied by $1 - \eta\lambda_i$, which has magnitude below 1 for all $i$ exactly when $\eta < 2/\lambda_{\max}$. At the balanced step the factors for $\lambda_{\min}$ and $\lambda_{\max}$ are $\pm(\kappa - 1)/(\kappa + 1)$. Doubling the step can push it past $2/\lambda_{\max}$ and cause divergence, so it does not halve the work.

solution: The Hessian eigenvalues are $2$ and $50$, so convergence needs $\eta < 2/50 = 0.04$. With $\eta = 0.01$ the factors are $0.98$ and $0.5$: the $y$ coordinate vanishes quickly but $x$ shrinks by only 2% per step, so convergence is stable but slow (hundreds of steps). With $\eta = 0.04$ the factors are $0.92$ and $-1$: the $y$ coordinate flips sign and keeps its size forever, so the iterates do not converge, because $\eta = 2/\lambda_{\max}$ is exactly the boundary. With $\eta = 0.09$ the factors are $0.82$ and $-3.5$: the $y$ coordinate is multiplied by $-3.5$ at each step, so the iterates and the loss diverge even though $x$ is still shrinking. The step size must respect the largest curvature, while the small curvature determines how fast we get there.

@article
Roll a marble inside a bowl and it ends at the bottom wherever it starts. Roll it on a bumpy field and where it ends depends on where it started. Convexity is the precise property that makes the optimization landscape a bowl, and it is why linear regression, logistic regression and support vector machines can be trained reliably.

### Convex sets

A set $C \subseteq \mathbb{R}^n$ is **convex** if the segment between any two of its points stays inside it: for all $\mathbf{x}, \mathbf{y} \in C$ and all $\theta \in [0,1]$, $\theta\mathbf{x} + (1-\theta)\mathbf{y} \in C$. Balls $\{\mathbf{x} : \lVert \mathbf{x} - \mathbf{c} \rVert_2 \le r\}$, half-spaces $\{\mathbf{x} : \mathbf{a}^\top\mathbf{x} \le b\}$ and the whole space are convex, and **an intersection of convex sets is convex**. A circle (the boundary only) and the union of two disjoint disks are not convex.

### Convex functions

A function $f$ defined on a convex set is **convex** if for all $\mathbf{x}, \mathbf{y}$ and $\theta \in [0,1]$,

$$f\big(\theta\mathbf{x} + (1-\theta)\mathbf{y}\big) \le \theta f(\mathbf{x}) + (1-\theta) f(\mathbf{y}).$$

In words: the chord between two points of the graph lies on or above the graph. It is **strictly convex** if the inequality is strict for $\mathbf{x} \ne \mathbf{y}$ and $\theta \in (0,1)$, and **$\mu$-strongly convex** ($\mu > 0$) if $f(\mathbf{x}) - \tfrac{\mu}{2}\lVert\mathbf{x}\rVert_2^2$ is convex. A function is **concave** if $-f$ is convex.

To refute convexity, one counterexample suffices. For $f(x) = x^3$ take $x = -2$, $y = 0$, $\theta = \tfrac12$: the left side is $f(-1) = -1$ and the right side is $\tfrac12(-8) + \tfrac12(0) = -4$, and $-1 \le -4$ is false. To prove convexity we need an argument that covers all points, and the next two tests supply it.

### Two tests for differentiable functions

**First-order condition.** A differentiable $f$ is convex if and only if for all $\mathbf{x}, \mathbf{y}$,

$$f(\mathbf{y}) \ge f(\mathbf{x}) + \nabla f(\mathbf{x})^\top(\mathbf{y} - \mathbf{x}).$$

The graph lies above every tangent plane. This is the inequality behind most convergence proofs.

**Second-order condition.** A twice continuously differentiable $f$ on an open convex set is convex if and only if its Hessian $\mathbf{H}(\mathbf{x})$ is **positive semidefinite** (PSD) at every point, meaning $\mathbf{v}^\top\mathbf{H}\mathbf{v} \ge 0$ for all $\mathbf{v}$, equivalently all eigenvalues are $\ge 0$. If $\mathbf{H}(\mathbf{x})$ is positive definite everywhere, $f$ is strictly convex (the converse fails: $x^4$ is strictly convex but $f''(0) = 0$). If $\mathbf{H}(\mathbf{x}) \succeq \mu\mathbf{I}$ everywhere, $f$ is $\mu$-strongly convex.

For $f(x,y) = x^2 + xy + y^2$ the Hessian is $\begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$, with eigenvalues $1$ and $3$: convex, in fact $1$-strongly convex. For $f(x,y) = xy$ the Hessian is $\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$ with eigenvalues $\pm 1$, so $f$ is not convex. A concrete witness: $f(1,-1) = f(-1,1) = -1$, but the midpoint $(0,0)$ has $f = 0 > -1$.

### Building convex functions

Starting from known convex functions, these operations preserve convexity:

| operation | result |
|---|---|
| nonnegative combination $\sum_i a_i f_i$, $a_i \ge 0$ | convex |
| composition with an affine map, $f(\mathbf{A}\mathbf{x} + \mathbf{b})$ | convex |
| pointwise maximum $\max_i f_i(\mathbf{x})$ | convex |

Known convex functions include affine functions, $e^{ax}$, $x^2$, every norm, $-\log x$ on $x > 0$, $\log(1 + e^{x})$, the log-sum-exp $\log\sum_i e^{x_i}$, and quadratics $\tfrac12\mathbf{x}^\top\mathbf{A}\mathbf{x}$ with $\mathbf{A} \succeq 0$. So the logistic loss $\log(1 + e^{-y\mathbf{w}^\top\mathbf{x}})$ is convex in $\mathbf{w}$ (convex function of an affine map), the hinge loss is convex (a maximum of two affine functions), and any sum of these with an L2 penalty is convex. By contrast, a neural network's loss is generally not convex in its weights, because the products of weights between layers destroy convexity.

Convex functions also have convex **sublevel sets** $\{\mathbf{x} : f(\mathbf{x}) \le c\}$, and **Jensen's inequality** $f(\mathbb{E}[X]) \le \mathbb{E}[f(X)]$ generalizes the definition to expectations.

@example
title: Convexity by the Hessian test
problem: Show that $f(x,y) = x^2/y$ is convex on the open half-plane $y > 0$.
step: Compute the partial derivatives: $f_x = 2x/y$ and $f_y = -x^2/y^2$.
step: Compute the second derivatives: $f_{xx} = 2/y$, $f_{xy} = -2x/y^2$, $f_{yy} = 2x^2/y^3$.
step: Factor the Hessian: $\mathbf{H} = \dfrac{2}{y^3}\begin{pmatrix} y^2 & -xy \\ -xy & x^2 \end{pmatrix} = \dfrac{2}{y^3}\,\mathbf{v}\mathbf{v}^\top$ with $\mathbf{v} = (y, -x)^\top$.
step: For any $\mathbf{u}$, $\mathbf{u}^\top\mathbf{H}\mathbf{u} = \dfrac{2}{y^3}(\mathbf{v}^\top\mathbf{u})^2 \ge 0$ because $y > 0$. So $\mathbf{H}$ is PSD everywhere on the domain, and $f$ is convex.
answer: The Hessian is $\frac{2}{y^3}\mathbf{v}\mathbf{v}^\top \succeq 0$ for $y > 0$, so $f$ is convex.

@example
title: Refuting convexity with a counterexample
problem: Is $f(x) = \sin x$ convex on $\mathbb{R}$? Give a proof or a refutation.
step: Try the second-order test: $f''(x) = -\sin x$, which is negative for $x \in (0, \pi)$, so $f$ cannot be convex on $\mathbb{R}$.
step: Make it concrete with the definition. Take $x = 0$, $y = \pi$ and $\theta = \tfrac12$.
step: The left side is $f(\pi/2) = 1$, and the right side is $\tfrac12\sin 0 + \tfrac12 \sin\pi = 0$.
step: Since $1 \le 0$ is false, the definition fails at this triple of points.
answer: Not convex: $f(\pi/2) = 1 > 0 = \tfrac12 f(0) + \tfrac12 f(\pi)$.

@mistakes
- Checking convexity with a few examples: passing the definition at some points proves nothing, but a single failure disproves convexity.
- Testing only that the Hessian is positive at one point: it must be PSD at every point of the domain (for $x^3$ the second derivative is positive for $x > 0$ and negative for $x < 0$).
- Confusing convex sets with convex functions: the unit circle is not a convex set, while the unit disk is.
- Believing that strictly convex needs a positive definite Hessian: $x^4$ is strictly convex yet $f''(0) = 0$. Positive definite is sufficient, not necessary.

answer: 1.310
tol: 0.001
check: 0.25 * exp(0) + 0.75 * exp(2) - exp(0.25 * 0 + 0.75 * 2)
hint: The point $\theta x + (1-\theta)y$ is $0.75 \cdot 2 = 1.5$.
solution: The chord value is $0.25 \cdot 1 + 0.75 e^2 \approx 0.25 + 5.5417 = 5.7917$, and the function value is $e^{1.5} \approx 4.4817$. The gap is about $1.310$, which is nonnegative as convexity requires.

@practice num
prompt: What is the smallest eigenvalue of the Hessian of $f(x,y) = x^2 + 3xy + y^2$?
answer: -1
check: min(np.linalg.eigvalsh(np.array([[2, 3], [3, 2]])))
hint: The Hessian is constant. Its eigenvalues are $2 \pm 3$ because the matrix has equal diagonal entries.
solution: The Hessian is $\begin{pmatrix} 2 & 3 \\ 3 & 2 \end{pmatrix}$, with eigenvalues $2 + 3 = 5$ and $2 - 3 = -1$. The smallest is $-1$, so $f$ is not convex.

@practice mc
prompt: Which of these subsets of $\mathbb{R}^2$ is convex?
choice*: $\{(x,y) : y \ge x^2\}$
choice: $\{(x,y) : y \le x^2\}$
choice: $\{(x,y) : x^2 + y^2 = 1\}$
choice: $\{(x,y) : |x| \ge 1\}$
hint: A set is convex if the segment between any two of its points stays inside. Test each set with two well-chosen points, such as points on opposite sides.
solution: The set $\{y \ge x^2\}$ is the region above a parabola, the epigraph of a convex function. The set $\{y \le x^2\}$ is not convex: the points $(-1,1)$ and $(1,1)$ lie in it, but their midpoint $(0,1)$ has $1 > 0$ and falls outside. The circle misses its own midpoints, and $\{|x| \ge 1\}$ misses the strip between its two pieces.

@practice self
prompt: Prove or refute: $f(x,y) = x^2 y^2$ is convex on $\mathbb{R}^2$.
hint: Compute the Hessian and look at its determinant, or search for two points whose midpoint violates the definition. The points $(1,0)$ and $(0,1)$ are worth trying.
solution: The function is not convex. Take $\mathbf{a} = (1, 0)$ and $\mathbf{b} = (0, 1)$. Then $f(\mathbf{a}) = f(\mathbf{b}) = 0$, so $\tfrac12 f(\mathbf{a}) + \tfrac12 f(\mathbf{b}) = 0$. The midpoint is $(\tfrac12, \tfrac12)$ with $f = \tfrac1{16} > 0$, violating the definition. The Hessian confirms it: $\mathbf{H} = \begin{pmatrix} 2y^2 & 4xy \\ 4xy & 2x^2 \end{pmatrix}$ has determinant $4x^2y^2 - 16x^2y^2 = -12x^2y^2 < 0$ whenever $xy \ne 0$, so it has a negative eigenvalue there.
rubric: Concludes that $f$ is not convex.
rubric: Gives a valid counterexample to the definition with correct arithmetic, or a Hessian with a negative eigenvalue at a stated point.
rubric: Does not argue from a single point where the Hessian happens to be PSD.

@quiz num
prompt: Let $f(x,y) = x^2 + 3y^2 + xy$. Its Hessian is constant, and $f$ is $\mu$-strongly convex for the largest $\mu$ equal to the smallest eigenvalue of the Hessian. Find $\mu$ to three decimal places.
answer: 1.764
tol: 0.001
check: min(np.linalg.eigvalsh(np.array([[2, 1], [1, 6]])))
hint: The Hessian is $\begin{pmatrix} 2 & 1 \\ 1 & 6 \end{pmatrix}$; solve $\det(\mathbf{H} - \lambda\mathbf{I}) = 0$.
solution: The characteristic equation is $(2 - \lambda)(6 - \lambda) - 1 = \lambda^2 - 8\lambda + 11 = 0$, so $\lambda = 4 \pm \sqrt{5}$. The smaller root is $4 - \sqrt{5} \approx 1.764$.

@quiz mc
prompt: A differentiable function $f$ is convex if and only if which of these holds for all $\mathbf{x}$ and $\mathbf{y}$?
choice*: $f(\mathbf{y}) \ge f(\mathbf{x}) + \nabla f(\mathbf{x})^\top(\mathbf{y} - \mathbf{x})$
choice: $f(\mathbf{y}) \le f(\mathbf{x}) + \nabla f(\mathbf{x})^\top(\mathbf{y} - \mathbf{x})$
choice: $\nabla f(\mathbf{x})^\top \nabla f(\mathbf{y}) \ge 0$
choice: $\lVert \nabla f(\mathbf{x}) \rVert_2 \le \lVert \nabla f(\mathbf{y}) \rVert_2$ whenever $f(\mathbf{x}) \le f(\mathbf{y})$
hint: Convexity means the graph lies on one side of every tangent plane; decide which side.
solution: The first-order condition says the graph lies above each tangent plane. The reversed inequality describes concave functions, and the other two statements are not equivalent to convexity (for instance $f(x) = x^2$ has $f'(1)f'(-1) = -4 < 0$).

@quiz self
prompt: Prove that if $f:\mathbb{R}^n \to \mathbb{R}$ is convex, then every sublevel set $S_c = \{\mathbf{x} : f(\mathbf{x}) \le c\}$ is convex. Then give an example showing that the converse is false.
hint: Take two points in $S_c$ and apply the definition of convexity to a point on the segment between them. For the converse, think of a one-variable function that is not convex but has intervals as sublevel sets.
solution: Let $\mathbf{x}, \mathbf{y} \in S_c$ and $\theta \in [0,1]$. By convexity, $f(\theta\mathbf{x} + (1-\theta)\mathbf{y}) \le \theta f(\mathbf{x}) + (1-\theta)f(\mathbf{y}) \le \theta c + (1-\theta)c = c$, so $\theta\mathbf{x} + (1-\theta)\mathbf{y} \in S_c$. For the converse, take $f(x) = \sqrt{|x|}$: it is not convex (for $x = 0$, $y = 4$, $f(2) \approx 1.414 > 1 = \tfrac12 f(0) + \tfrac12 f(4)$), but its sublevel set for $c \ge 0$ is the interval $[-c^2, c^2]$, which is convex.
rubric: Uses the definition of convexity and the bound $f \le c$ at both endpoints.
rubric: Concludes that the point on the segment lies in $S_c$.
rubric: Gives a correct non-convex function with convex sublevel sets and verifies both claims.

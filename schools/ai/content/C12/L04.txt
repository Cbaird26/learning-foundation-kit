@article
A hiker reaches a spot where the ground is perfectly level. Is it the bottom of a valley, the top of a hill, or the middle of a mountain pass? The gradient is zero in all three cases, so we need more information, and we need to know when a valley bottom is the lowest point anywhere.

### What a minimizer must satisfy

A point $\mathbf{x}^\star$ is a **local minimizer** of $f$ if $f(\mathbf{x}^\star) \le f(\mathbf{x})$ for all $\mathbf{x}$ in some neighborhood of $\mathbf{x}^\star$, and a **global minimizer** if this holds for all $\mathbf{x}$. For unconstrained problems with smooth $f$:

1. **First-order necessary condition.** If $f$ is differentiable and $\mathbf{x}^\star$ is a local minimizer, then $\nabla f(\mathbf{x}^\star) = \mathbf{0}$. A point with zero gradient is called **stationary** or critical.
2. **Second-order necessary condition.** If $f$ is twice continuously differentiable and $\mathbf{x}^\star$ is a local minimizer, then also $\mathbf{H}(\mathbf{x}^\star)$ is positive semidefinite.
3. **Second-order sufficient condition.** If $f$ is twice continuously differentiable, $\nabla f(\mathbf{x}^\star) = \mathbf{0}$ and $\mathbf{H}(\mathbf{x}^\star)$ is positive definite, then $\mathbf{x}^\star$ is a strict local minimizer.

The reason behind (1) is the descent direction: if $\nabla f(\mathbf{x}) \ne \mathbf{0}$, then $f(\mathbf{x} - t\nabla f(\mathbf{x})) < f(\mathbf{x})$ for small $t > 0$, so $\mathbf{x}$ is not a minimizer. The reason behind (3) is the Taylor expansion, $f(\mathbf{x}^\star + \mathbf{d}) \approx f(\mathbf{x}^\star) + \tfrac12\mathbf{d}^\top\mathbf{H}\mathbf{d}$, which is above $f(\mathbf{x}^\star)$ for every small $\mathbf{d} \ne \mathbf{0}$ when $\mathbf{H}$ is positive definite.

### Classifying stationary points

At a stationary point, look at the eigenvalues of $\mathbf{H}$: all positive gives a strict local minimum; all negative a strict local maximum; some positive and some negative a **saddle point**, which is a minimum along some directions and a maximum along others. If $\mathbf{H}$ is only semidefinite (some eigenvalue zero) the test is **inconclusive**: for $f(x) = x^4$, $f(x) = -x^4$ and $f(x) = x^3$ at $x = 0$ we have $f' = f'' = 0$, but the point is a minimum, a maximum and an inflection point respectively.

For $f(x) = x^4 - 2x^2$, $f'(x) = 4x^3 - 4x$ vanishes at $-1, 0, 1$, and $f''(x) = 12x^2 - 4$:

| $x$ | $f(x)$ | $f''(x)$ | type |
|---|---|---|---|
| $-1$ | $-1$ | $8$ | local (and global) minimum |
| $0$ | $0$ | $-4$ | local maximum |
| $1$ | $-1$ | $8$ | local (and global) minimum |

### Why convexity changes everything

For general $f$, the conditions above find only **local** minima. For a convex function the picture simplifies completely.

**Theorem.** Let $f$ be convex and differentiable. Then $\mathbf{x}^\star$ is a global minimizer if and only if $\nabla f(\mathbf{x}^\star) = \mathbf{0}$.

*Proof.* A global minimizer is a local minimizer, so its gradient is zero by (1). Conversely, if $\nabla f(\mathbf{x}^\star) = \mathbf{0}$, the first-order condition for convexity gives, for every $\mathbf{y}$, $f(\mathbf{y}) \ge f(\mathbf{x}^\star) + \nabla f(\mathbf{x}^\star)^\top(\mathbf{y} - \mathbf{x}^\star) = f(\mathbf{x}^\star)$. $\blacksquare$

Two more facts follow from convexity. Every local minimizer of a convex function is global, and the set of minimizers is convex. If $f$ is strictly convex, there is at most one minimizer. This is why optimizing a convex loss reduces to "find any point with zero gradient".

### The convex quadratic

The most important example is $f(\mathbf{x}) = \tfrac12\mathbf{x}^\top\mathbf{A}\mathbf{x} - \mathbf{b}^\top\mathbf{x}$ with $\mathbf{A}$ symmetric positive definite. Its gradient is $\mathbf{A}\mathbf{x} - \mathbf{b}$, so the unique global minimizer solves the linear system $\mathbf{A}\mathbf{x}^\star = \mathbf{b}$, and the minimum value is $-\tfrac12\mathbf{b}^\top\mathbf{x}^\star$. Least squares is the special case $\mathbf{A} = \mathbf{X}^\top\mathbf{X}$ and $\mathbf{b} = \mathbf{X}^\top\mathbf{y}$, whose stationarity equation is the **normal equations** $\mathbf{X}^\top\mathbf{X}\mathbf{w} = \mathbf{X}^\top\mathbf{y}$. When $\mathbf{X}$ has linearly independent columns, $\mathbf{X}^\top\mathbf{X}$ is positive definite and the solution is unique.

In deep learning, the loss is not convex, so a point with a tiny gradient might be a local minimum, a saddle point or a flat region, and different runs can end in different places. Week 12 returns to this.

@example
title: Classifying the stationary points of a cubic
problem: Find and classify the stationary points of $f(x,y) = x^3 - 3x + y^2$.
step: Set the gradient to zero: $\nabla f = (3x^2 - 3,\; 2y) = (0,0)$ gives $x = \pm 1$ and $y = 0$, so the stationary points are $(1,0)$ and $(-1,0)$.
step: The Hessian is $\mathbf{H} = \begin{pmatrix} 6x & 0 \\ 0 & 2 \end{pmatrix}$, which is diagonal, so its eigenvalues are $6x$ and $2$.
step: At $(1,0)$ the eigenvalues are $6$ and $2$, both positive: a strict local minimum with $f = -2$.
step: At $(-1,0)$ the eigenvalues are $-6$ and $2$, of mixed sign: a saddle point with $f = 2$. The function is not convex, and indeed $f \to -\infty$ as $x \to -\infty$, so $(1,0)$ is not a global minimizer.
answer: $(1,0)$ is a strict local minimum (value $-2$); $(-1,0)$ is a saddle point (value $2$).

@example
title: Minimizing a convex quadratic
problem: Minimize $f(\mathbf{x}) = \tfrac12\mathbf{x}^\top\mathbf{A}\mathbf{x} - \mathbf{b}^\top\mathbf{x}$ with $\mathbf{A} = \begin{pmatrix} 2 & 1 \\ 1 & 3 \end{pmatrix}$ and $\mathbf{b} = (1, 2)^\top$.
step: The matrix $\mathbf{A}$ is symmetric with $\det\mathbf{A} = 5 > 0$ and trace $5 > 0$, so both eigenvalues are positive and $f$ is strictly convex.
step: Stationarity: $\mathbf{A}\mathbf{x} - \mathbf{b} = \mathbf{0}$, that is $2x + y = 1$ and $x + 3y = 2$.
step: Solve: from the first equation $y = 1 - 2x$; substituting gives $x + 3 - 6x = 2$, so $x = 0.2$ and $y = 0.6$.
step: The minimum value is $-\tfrac12\mathbf{b}^\top\mathbf{x}^\star = -\tfrac12(0.2 + 1.2) = -0.7$. Because $f$ is convex, this is the global minimum.
answer: $\mathbf{x}^\star = (0.2, 0.6)^\top$ with minimum value $-0.7$.

@mistakes
- Saying that a zero gradient means a minimum: it can also be a maximum or a saddle point, and for non-convex functions only the Hessian (or more) can tell.
- Treating a zero eigenvalue of the Hessian as proof of a saddle point or a minimum: the second-order test is inconclusive there.
- Applying "stationary implies global minimum" to a function that is not convex.
- Expecting the minimizer of a convex function to be unique: that holds for strictly convex functions, while a constant function is convex and every point minimizes it.

prompt: Two training runs of a neural network from different random initializations both stop with a gradient norm below $10^{-6}$, but their final training losses are $0.31$ and $0.47$. What can you conclude about the loss function, what can you not conclude about the two points, and what could you compute to learn more?
hint: Think about which kinds of points have zero gradient, and which theorem would explain why the two runs agree if the loss were convex.
solution: For a convex differentiable loss, every stationary point is a global minimizer, so two stationary points would have the same loss value. Different values mean that the loss is not convex, and at least one point (the one with loss $0.47$) is not a global minimizer. A small gradient norm alone does not say whether a point is a local minimum, a saddle point or a flat region, and it does not say whether the $0.31$ point is global either. To learn more, compute (or estimate) the eigenvalues of the Hessian at each point: all positive suggests a local minimum, a negative eigenvalue shows a saddle point, and perturbing the weights slightly and continuing training is another practical probe.

@quiz self
prompt: Prove that a strictly convex function $f:\mathbb{R}^n \to \mathbb{R}$ has at most one global minimizer.
hint: Suppose there are two different minimizers and evaluate $f$ at their midpoint.
solution: Suppose $\mathbf{x} \ne \mathbf{y}$ are both global minimizers with common minimum value $m = f(\mathbf{x}) = f(\mathbf{y})$. By strict convexity with $\theta = \tfrac12$, $f\big(\tfrac12\mathbf{x} + \tfrac12\mathbf{y}\big) < \tfrac12 f(\mathbf{x}) + \tfrac12 f(\mathbf{y}) = m$. So the midpoint has a value below the minimum, a contradiction. Hence the minimizer, if it exists, is unique.

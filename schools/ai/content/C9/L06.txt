@article
In a **constraint satisfaction problem (CSP)** the state has structure. A CSP has a set of **variables** $X_1, \dots, X_n$, a **domain** $D_i$ of allowed values for each variable, and a set of **constraints** that restrict which combinations of values are allowed. An assignment is **consistent** if it violates no constraint, **complete** if every variable has a value, and a **solution** is a consistent complete assignment. Classic CSPs include map coloring, scheduling, Sudoku and cryptarithmetic.

Constraints are **unary** (one variable), **binary** (two) or higher order. Any CSP can be turned into a binary one, and a binary CSP is drawn as a **constraint graph**: nodes are variables and an edge joins two variables that share a constraint. In **map coloring**, each region is a variable, the domain is the set of colors, and adjacent regions must differ.

The structure lets algorithms reject a partial assignment early without exploring its completions. General CSP solving is NP-hard, but good inference makes many instances easy.

### Backtracking search

**Backtracking search** assigns one variable at a time (assignments are commutative, so the order of variables does not change which solutions exist), checks each new assignment against the constraints, and undoes it when no value works for some variable. With $n$ variables and domain size $d$ there are $d^n$ complete assignments, but backtracking prunes whole subtrees as soon as a constraint is violated.

```python
def backtrack(assignment, variables, domains, ok):
    if len(assignment) == len(variables):
        return assignment
    var = next(v for v in variables if v not in assignment)
    for value in domains[var]:
        if ok(assignment, var, value):
            assignment[var] = value
            result = backtrack(assignment, variables, domains, ok)
            if result is not None:
                return result
            del assignment[var]
    return None
```

### Ordering heuristics

- **Minimum remaining values (MRV)**: choose the variable with the fewest legal values left (the "fail-first" principle).
- **Degree heuristic**: break ties by choosing the variable involved in the most constraints on unassigned variables.
- **Least constraining value (LCV)**: try first the value that rules out the fewest values in neighbours' domains.

### Inference: forward checking and arc consistency

**Forward checking** maintains the remaining legal values of the unassigned variables: after assigning $X = v$, it removes inconsistent values from the domains of neighbouring variables, and backtracks immediately if any domain becomes empty.

A variable $X$ is **arc consistent** with $Y$ if every value in $D(X)$ has at least one **supporting** value in $D(Y)$ that satisfies the constraint between them. **AC-3** puts all arcs in a queue; it removes a value from $D(X)$ that lacks support in $D(Y)$, and whenever $D(X)$ shrinks, it re-queues the arcs $(Z, X)$ for the other neighbours $Z$ of $X$. If a domain empties, there is no solution. For a CSP with $e$ binary constraints and domain size $d$, AC-3 runs in $O(e\,d^3)$ time. Arc consistency is stronger than forward checking, and it can be used before search and after each assignment (**maintaining arc consistency, MAC**). It is not complete: arc-consistent domains may still have no solution.

### Structure and local search

A CSP whose constraint graph is a **tree** can be solved in $O(n\,d^2)$ time: pick a root, order the variables so that parents come before children, make each parent arc consistent with its child from the leaves up, then assign values from the root down with no backtracking. Other structure is exploited by **cutset conditioning** and **tree decompositions**. Local search with the **min-conflicts** heuristic (week 4) also works well for many CSPs.

@example
title: Backtracking with forward checking on a triangle
problem: Three mutually adjacent regions X, Y, Z each have domain {1, 2, 3} and adjacent regions must differ. Solve it with forward checking, using alphabetical order and ascending values.
step: Assign X = 1. Forward checking removes 1 from the domains of Y and Z, so both become {2, 3}.
step: Assign Y = 2. Forward checking removes 2 from Z, leaving Z = {3}. No domain is empty.
step: Assign Z = 3, its only value. All variables are assigned with no violated constraint.
step: Contrast with two colors: with domains {1, 2}, X = 1 leaves Y = {2} and Z = {2}; then Y = 2 empties Z, so forward checking backtracks immediately, and no assignment can succeed.
answer: X = 1, Y = 2, Z = 3.

@example
title: One step of arc consistency
problem: Variables X and Y have domains $D(X) = \{1, 2, 3, 4\}$ and $D(Y) = \{1, 2, 3\}$ and the constraint $X < Y$. Make the arc consistent in both directions.
step: Revise $D(X)$ against $Y$: a value $x$ needs some $y > x$ in $D(Y)$. For $x = 3$ and $x = 4$ no $y$ exists, so remove them: $D(X) = \{1, 2\}$.
step: Revise $D(Y)$ against $X$: a value $y$ needs some $x < y$ in the new $D(X)$. For $y = 1$ there is no $x < 1$, so remove it: $D(Y) = \{2, 3\}$.
step: Now every value has a support. For $X$: $1 < 2$ and $2 < 3$. For $Y$: the value 2 is supported by $x = 1$ and the value 3 by $x = 1$ or $x = 2$.
answer: $D(X) = \{1, 2\}$ and $D(Y) = \{2, 3\}$.

@mistakes
- Calling an assignment "consistent" when it is complete; consistent only means no constraint is violated so far.
- Believing arc consistency solves the CSP: domains can all be arc consistent while no solution exists (for example three mutually different variables with domain {1, 2}).
- After forward checking empties some domain, continuing the search instead of backtracking at once.
- Applying MRV to assigned variables, or forgetting that MRV chooses the *variable* while LCV chooses the *value*.

```python
def color_map(neighbors, colors):
    regions = sorted(neighbors)

    def backtrack(assignment):
        if len(assignment) == len(regions):
            return dict(assignment)
        region = regions[len(assignment)]
        for color in colors:
            if all(assignment.get(n) != color for n in neighbors[region]):
                assignment[region] = color
                result = backtrack(assignment)
                if result is not None:
                    return result
                del assignment[region]
        return None

    return backtrack({})
```

hint: If the recursive call returns `None`, undo the assignment (`del`) and try the next color.
solution: Plain backtracking: pick the next region in sorted order, try each color that no assigned neighbour uses, recurse, and undo on failure. In the four-region test, `B = "r"` is tried first but leaves no color for `D`, so the search backtracks and sets `B = "g"`.

model:
```python
from collections import deque


def ac3(domains, neighbors):
    queue = deque((x, y) for x in neighbors for y in neighbors[x])
    while queue:
        x, y = queue.popleft()
        removed = {a for a in domains[x]
                   if not any(b != a for b in domains[y])}
        if removed:
            domains[x] -= removed
            if not domains[x]:
                return False
            for z in neighbors[x]:
                if z != y:
                    queue.append((z, x))
    return True
```
hint: Start with a queue of all directed arcs `(x, y)`.
hint: A value `a` in `domains[x]` has no support when every value in `domains[y]` equals `a`. When `domains[x]` shrinks, queue the arcs `(z, x)` for the other neighbours `z` of `x`.
solution: This is AC-3 with a "revise" step per arc. In the second test, `A = {1}` removes 1 from `B`, which leaves `B = {2}`, and that removes 2 from `C`, leaving `{3}`. The last test shows arc consistency does not detect that three variables with only two values each have no solution.

model:
```python
def count_colorings(neighbors, k):
    regions = sorted(neighbors)
    assignment = {}

    def count(i):
        if i == len(regions):
            return 1
        total = 0
        for color in range(k):
            if all(assignment.get(n) != color for n in neighbors[regions[i]]):
                assignment[regions[i]] = color
                total += count(i + 1)
                del assignment[regions[i]]
        return total

    return count(0)
```
hint: Use the same backtracking structure as for finding one coloring, but add up the solutions instead of returning the first.
hint: A complete assignment contributes 1; at each level sum the counts for all allowed colors.
solution: Backtracking that sums over all consistent extensions counts every proper coloring exactly once. For a path of three regions the first has 3 choices and each later region has 2, giving $3 \cdot 2 \cdot 2 = 12$.

@quiz mc
prompt: A CSP has $n$ variables with domain size $d$ and its constraint graph is a tree. Which statement is correct?
choice: It needs $O(d^n)$ time in the worst case, as every CSP does
choice: Plain backtracking in any variable order always avoids dead ends
choice*: It can be solved in $O(n\,d^2)$ time by making arcs consistent from the leaves up and then assigning from the root down
choice: It cannot be solved faster than a general CSP because the problem is NP-hard
hint: Think about processing the tree from the leaves toward the root.
solution: Tree-structured CSPs are solvable in linear time in $n$ (with a factor $d^2$ per arc): directional arc consistency guarantees that a value for the parent always has support in each child, so assignment from the root never backtracks. Arbitrary variable orders can still fail, which is why the order matters.

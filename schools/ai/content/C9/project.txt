material: **Environment code** (`connect4.py`). Players are the strings `"X"` (moves first) and `"O"`. An agent is any function `agent(board, player)` that returns a column number from `legal_moves(board)`.

```python
import random

ROWS, COLS = 6, 7
EMPTY = "."


def new_board():
    return tuple(EMPTY * COLS for _ in range(ROWS))


def legal_moves(board):
    return [c for c in range(COLS) if board[0][c] == EMPTY]


def drop(board, col, player):
    for r in range(ROWS - 1, -1, -1):
        if board[r][col] == EMPTY:
            row = board[r][:col] + player + board[r][col + 1:]
            return board[:r] + (row,) + board[r + 1:]
    raise ValueError("column is full")


def winner(board):
    for r in range(ROWS):
        for c in range(COLS):
            p = board[r][c]
            if p == EMPTY:
                continue
            for dr, dc in ((0, 1), (1, 0), (1, 1), (1, -1)):
                end_r, end_c = r + 3 * dr, c + 3 * dc
                if not (0 <= end_r < ROWS and 0 <= end_c < COLS):
                    continue
                if all(board[r + i * dr][c + i * dc] == p for i in range(4)):
                    return p
    return None


def play(agent_x, agent_o):
    board, player = new_board(), "X"
    agents = {"X": agent_x, "O": agent_o}
    while winner(board) is None and legal_moves(board):
        col = agents[player](board, player)
        board = drop(board, col, player)
        player = "O" if player == "X" else "X"
    return winner(board)


def random_agent(seed):
    rng = random.Random(seed)

    def agent(board, player):
        return rng.choice(legal_moves(board))

    return agent


def tournament(agent_a, agent_b, games):
    wins = {"a": 0, "b": 0, "draw": 0}
    for g in range(games):
        if g % 2 == 0:
            w = play(agent_a, agent_b)
            label = {"X": "a", "O": "b", None: "draw"}[w]
        else:
            w = play(agent_b, agent_a)
            label = {"X": "b", "O": "a", None: "draw"}[w]
        wins[label] += 1
    return wins
```

`tournament` alternates who moves first. A game ends when a player has four in a row (horizontally, vertically or diagonally) or the board is full (a draw). The board has 7 columns and 6 rows, so a game lasts at most 42 moves.

**Week 1: agents and problems.** An agent maps percepts to actions; describe the task environment with PEAS and classify it (observable or not, deterministic or stochastic, sequential, static, discrete, single or multi-agent). A search problem is an initial state, actions, a transition model, a goal test and step costs.

**Week 2: uninformed search.** BFS (queue; complete; optimal for unit costs; $O(b^d)$ time and space), DFS (stack; $O(bm)$ space; not optimal), iterative deepening ($O(b^d)$ time, $O(bd)$ space), uniform-cost search (priority queue on $g$; goal test on removal).

**Week 3: heuristic search.** $f = g + h$. Admissible means $h \le h^*$; consistent means $h(n) \le c + h(n')$ and implies admissible. A* is optimal with an admissible heuristic (tree search) or a consistent one (graph search without reopening). Heuristics come from relaxed problems; the larger of two admissible heuristics dominates.

**Week 4: local search.** Hill climbing and its traps, random restarts, simulated annealing with acceptance probability $e^{\Delta/T}$, beam search, genetic algorithms, min-conflicts for $n$-queens.

**Week 5: adversarial search.** The minimax value; alpha–beta returns the same value with up to $O(b^{m/2})$ nodes under the best ordering; cutoff plus evaluation function.

**Week 6: CSPs.** Variables, domains, constraints; backtracking, MRV, degree, LCV, forward checking, AC-3 (not complete by itself), trees solved in $O(nd^2)$.

**Week 7: logic.** Models, entailment, validity, satisfiability; model checking, resolution refutation, forward chaining on definite clauses; first-order quantifier patterns and unification.

**Week 8: planning.** STRIPS states, actions with add and delete lists, progression and regression, delete-relaxation heuristics.

**Week 9: probability.** Bayes' rule, conditional independence, Bayesian networks as products of CPTs, d-separation (chain, fork, collider), enumeration.

**Week 10: MDPs.** Discounted return, the Bellman optimality equation, value iteration, greedy policy extraction.

**Week 11: reinforcement learning.** TD error, Q-learning (off-policy, max) and SARSA (on-policy), $\varepsilon$-greedy exploration, convergence conditions.

**Week 12: ML, LLMs and ethics.** Train, validation and test sets, overfitting, precision and recall, gradient descent, next-token prediction, limits of language models, fairness, accountability and privacy.

**Self-check.** Can you (1) run each search algorithm by hand and state its complexity, (2) prove that a consistent heuristic is admissible, (3) run alpha–beta and count pruned leaves, (4) do one Bellman backup and one Q-learning update, (5) compute a posterior with Bayes' rule, and (6) explain one limitation of a learned model aloud without notes?

**Common errors.** Testing the goal on generation in uniform-cost search; confusing admissible with consistent; updating $\alpha$ and $\beta$ at the wrong player's nodes; forgetting to normalize a posterior; mixing up SARSA and Q-learning targets; forgetting the future value of a terminal state is 0; evaluating a model on its training data.

```python
def grid_policy(grid, gamma, sweeps):
    rows, cols = len(grid), len(grid[0])
    moves = {"U": (-1, 0), "D": (1, 0), "L": (0, -1), "R": (0, 1)}
    cells = [(r, c) for r in range(rows) for c in range(cols)
             if grid[r][c] not in "#GX"]
    V = {cell: 0.0 for cell in cells}

    def q(cell, a):
        dr, dc = moves[a]
        nr, nc = cell[0] + dr, cell[1] + dc
        if not (0 <= nr < rows and 0 <= nc < cols) or grid[nr][nc] == "#":
            nr, nc = cell
        ch = grid[nr][nc]
        reward = 10.0 if ch == "G" else -10.0 if ch == "X" else -1.0
        future = 0.0 if ch in "GX" else V[(nr, nc)]
        return reward + gamma * future

    for _ in range(sweeps):
        V = {cell: max(q(cell, a) for a in "UDLR") for cell in cells}
    policy = {}
    for cell in cells:
        best, best_q = None, None
        for a in "UDLR":
            value = q(cell, a)
            if best_q is None or value > best_q:
                best, best_q = a, value
        policy[cell] = best
    return policy
```
hint: Write a helper `q(cell, a)` that finds the next cell (staying put at walls and edges), the reward from the character there, and the discounted value of that cell (0 for terminal cells).
hint: Build the whole new `V` dictionary from the old one in each sweep. For the policy, scan `"UDLR"` and replace the best action only on a strictly larger value.
solution: This is value iteration (week 10) on a grid-world formulation (week 1), with the greedy-policy extraction step. The helper `q` computes the Bellman backup term for one action. The `V` used inside `q` is rebound after each sweep, so each sweep uses only the previous values. With zero sweeps every value is 0, so the policy chases the immediate reward: `R` next to the goal and `"U"` (the first tie) elsewhere.

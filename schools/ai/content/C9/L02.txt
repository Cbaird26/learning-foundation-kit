@article
An **uninformed** (or blind) search strategy uses only the problem definition: it has no estimate of how close a state is to the goal. All such strategies share one loop and differ only in which frontier node they expand next.

### The generic search loop

The **frontier** holds nodes that have been generated but not expanded. The **explored set** (or visited set) holds states already reached. Search repeatedly removes a node from the frontier, tests whether it is a goal, and otherwise **expands** it by generating its successors. A **node** records a state, its parent, the action that produced it and its path cost $g$. Following parent links from a goal node gives the solution.

Without an explored set, a cyclic state space makes the search loop forever; this is called **tree search**. With one, it is **graph search**.

We measure strategies by four properties: **completeness** (finds a solution if one exists), **optimality** (finds a lowest-cost one), and time and space complexity in the **branching factor** $b$, the depth $d$ of the shallowest goal and the maximum depth $m$ of the space.

### Breadth-first search (BFS)

BFS keeps the frontier as a **FIFO queue**, so all nodes at depth $k$ are expanded before any at depth $k + 1$. It is complete when $b$ is finite, and optimal when all step costs are equal. It generates $O(b^d)$ nodes and stores $O(b^d)$ nodes, and the memory is usually the binding limit.

```python
from collections import deque

def bfs(graph, start, goal):
    parent = {start: None}
    frontier = deque([start])
    while frontier:
        node = frontier.popleft()
        if node == goal:
            break
        for nxt in graph[node]:
            if nxt not in parent:
                parent[nxt] = node
                frontier.append(nxt)
    return parent
```

### Depth-first search (DFS)

DFS keeps the frontier as a **LIFO stack** (or uses recursion), always expanding the deepest node. Its space is only $O(bm)$, but time is $O(b^m)$, it is not optimal, and it is incomplete in infinite spaces or, without an explored set, in spaces with cycles. **Depth-limited search** cuts DFS off at a depth limit $\ell$. **Iterative deepening** runs depth-limited search with $\ell = 0, 1, 2, \dots$: it is complete for finite $b$, optimal for unit step costs, takes $O(b^d)$ time and only $O(bd)$ space. The repeated work is small because most nodes lie at the deepest level.

### Uniform-cost search (UCS)

When step costs differ, expand the frontier node with the lowest path cost $g(n)$, using a **priority queue**. The goal test is applied when a node is **removed** from the frontier, not when it is generated; otherwise a cheaper path could be missed. UCS is complete and optimal if every step cost is at least some $\varepsilon > 0$. With $C^*$ the optimal cost, its time and space are $O(b^{1 + \lfloor C^*/\varepsilon \rfloor})$. With unit costs it behaves like BFS.

| Strategy | Complete | Optimal | Time | Space |
|---|---|---|---|---|
| BFS | yes ($b$ finite) | unit costs | $O(b^d)$ | $O(b^d)$ |
| DFS | no | no | $O(b^m)$ | $O(bm)$ |
| Iterative deepening | yes ($b$ finite) | unit costs | $O(b^d)$ | $O(bd)$ |
| UCS | yes ($\ge \varepsilon$) | yes | $O(b^{1+\lfloor C^*/\varepsilon\rfloor})$ | same |

@example
title: Uniform-cost search by hand
problem: Edges are S to A (cost 2), S to B (5), A to B (1), A to G (7) and B to G (3). Run uniform-cost search from S to G.
step: Frontier: S with g = 0. Remove S and generate A (g = 2) and B (g = 5).
step: Remove the cheapest, A (2). Generate B through A with g = 2 + 1 = 3, which is better than 5, and G with g = 2 + 7 = 9.
step: Remove the cheapest, B (3). Generate G through B with g = 3 + 3 = 6, better than 9.
step: Remove G (6): it is the goal, tested on removal. Following parents gives S, A, B, G.
answer: Path S, A, B, G with cost 6.

@example
title: BFS and DFS order on the same tree
problem: A tree has root R with children X and Y (in that order); X has children P and Q; Y has child Z. List the expansion order of BFS and of DFS (children in listed order).
step: BFS uses a queue: expand R, then its children X and Y, then the next level in order.
step: BFS order: R, X, Y, P, Q, Z.
step: DFS uses a stack and always goes deep first, taking children in listed order: R, then X, then P (a leaf), then back to Q.
step: After finishing X's subtree, DFS visits Y and then Z.
answer: BFS: R, X, Y, P, Q, Z. DFS: R, X, P, Q, Y, Z.

@mistakes
- Testing for the goal only when a node is generated in uniform-cost search, which can return a non-optimal path.
- Forgetting the explored set, so a graph with cycles makes DFS or BFS revisit states endlessly.
- Claiming that DFS is optimal because it "finds a goal fast"; it returns the first goal it meets, which may be deep.
- Saying UCS is complete with zero-cost steps: a cycle of zero-cost edges can keep it from ever making progress.

```python
from collections import deque


def bfs_path(graph, start, goal):
    parent = {start: None}
    frontier = deque([start])
    while frontier:
        node = frontier.popleft()
        for nxt in graph[node]:
            if nxt not in parent:
                parent[nxt] = node
                frontier.append(nxt)
    if goal not in parent:
        return None
    path = []
    node = goal
    while node is not None:
        path.append(node)
        node = parent[node]
    return path[::-1]
```
hint: Keep a `parent` dictionary; its keys also serve as the explored set.
hint: After the search, rebuild the path by following parents from the goal back to the start, then reverse it.
solution: Breadth-first search with a `parent` dict records, for each reached node, the node it was first reached from. Because BFS reaches nodes in order of depth, the parent chain is a shortest path. Walk it from the goal and reverse.

```python
from collections import deque


def min_actions(cap_a, cap_b, target):
    dist = {(0, 0): 0}
    frontier = deque([(0, 0)])
    while frontier:
        a, b = frontier.popleft()
        if b == target:
            return dist[(a, b)]
        to_b = min(a, cap_b - b)
        to_a = min(b, cap_a - a)
        for nxt in [(cap_a, b), (a, cap_b), (0, b), (a, 0),
                    (a - to_b, b + to_b), (a + to_a, b - to_a)]:
            if nxt not in dist:
                dist[nxt] = dist[(a, b)] + 1
                frontier.append(nxt)
    return -1
```
hint: The states form a graph with at most `(cap_a + 1) * (cap_b + 1)` nodes; run BFS on it and store each state's distance.
hint: Return the distance of the first state removed from the queue whose `b` equals `target`. If the queue empties, no such state is reachable.
solution: This is the formulation from week 1 searched breadth-first: with unit step costs, the first goal state removed from the queue is at the minimum depth. The `dist` dictionary doubles as the explored set, and an empty queue means the target is unreachable.

model:
```python
import heapq


def ucs(graph, start, goal):
    frontier = [(0, [start])]
    best = {}
    while frontier:
        cost, path = heapq.heappop(frontier)
        node = path[-1]
        if node == goal:
            return cost, path
        if node in best and best[node] <= cost:
            continue
        best[node] = cost
        for nxt, step in graph[node]:
            heapq.heappush(frontier, (cost + step, path + [nxt]))
    return None
```
hint: Use `heapq` with entries `(path_cost, path)` so the cheapest comes out first.
hint: When you pop a node you have already expanded at a lower or equal cost, skip it.
solution: Pop the cheapest path from the heap; if its last node is the goal, that path is optimal because every other frontier path costs at least as much and costs are positive. Otherwise expand it. The path `S, A, G` costs 9 and `S, B, C, G` costs 9, but `S, B, A, G` costs 8.

@article
A **knowledge-based agent** stores sentences about the world in a **knowledge base (KB)** and uses **inference** to derive new sentences. A **logic** gives a formal language with a precise **syntax** (which strings are sentences) and **semantics** (when a sentence is true in a **model**, a possible world).

### Propositional logic

Sentences are built from proposition symbols $P, Q, \dots$ with $\neg$ (not), $\land$ (and), $\lor$ (or), $\Rightarrow$ (implies) and $\Leftrightarrow$ (if and only if). A model assigns true or false to every symbol; the truth value of a sentence follows from the truth tables. Note that $P \Rightarrow Q$ is false only when $P$ is true and $Q$ is false, so it is equivalent to $\neg P \lor Q$.

- $\alpha$ **entails** $\beta$, written $\alpha \models \beta$, if $\beta$ is true in every model in which $\alpha$ is true.
- A sentence is **valid** if it is true in all models (a tautology), **satisfiable** if true in some model, and **unsatisfiable** otherwise.
- Link: $\alpha \models \beta$ exactly when $\alpha \land \neg\beta$ is unsatisfiable. This is **proof by contradiction**.
- An inference algorithm is **sound** if it derives only entailed sentences and **complete** if it derives every entailed sentence.

**Model checking** enumerates all $2^n$ models of $n$ symbols and tests the definition directly. It is sound and complete but takes $O(2^n)$ time. Deciding satisfiability (**SAT**) is NP-complete, yet **DPLL** (backtracking with early termination, the pure-symbol rule and the unit-clause rule) and modern clause-learning solvers handle very large industrial instances.

```python
from itertools import product

def entails(kb, query, symbols):
    for values in product([False, True], repeat=len(symbols)):
        model = dict(zip(symbols, values))
        if kb(model) and not query(model):
            return False
    return True
```

### Resolution and Horn clauses

A **literal** is a symbol or its negation, and a **clause** is a disjunction of literals. **Conjunctive normal form (CNF)** is a conjunction of clauses; every sentence has an equivalent CNF. The **resolution rule** takes two clauses containing complementary literals and produces the clause of all the other literals:

$$\frac{\ell_1 \lor \dots \lor \ell_k, \quad m_1 \lor \dots \lor m_n}{\text{all literals except } \ell_i \text{ and } m_j} \quad \text{where } \ell_i = \neg m_j.$$

Resolving $P$ with $\neg P$ gives the **empty clause**, which is false. **Resolution refutation** proves $KB \models \alpha$ by adding $\neg\alpha$ to the CNF of the KB and deriving the empty clause. It is sound and **refutation-complete** for propositional logic.

A **definite clause** is a clause with exactly one positive literal, usually written as a rule $P_1 \land \dots \land P_k \Rightarrow Q$; a **Horn clause** has at most one. For definite clauses, **forward chaining** repeatedly fires any rule whose premises are all known, adding its conclusion, until the query is derived or nothing changes. It is sound, complete for definite clauses and runs in time linear in the size of the KB. **Backward chaining** works from the goal back to facts.

### First-order logic

First-order logic describes **objects** and **relations**. Its syntax has constants (`Alice`), variables, functions, predicates, equality, connectives and the quantifiers $\forall$ (for all) and $\exists$ (there exists). Two translation rules avoid the common errors: $\forall x\,(\text{Student}(x) \Rightarrow \text{Studies}(x))$ uses $\Rightarrow$ with $\forall$, and $\exists x\,(\text{Student}(x) \land \text{Studies}(x))$ uses $\land$ with $\exists$. Quantifier order matters: $\forall x\,\exists y\,\text{Loves}(x, y)$ (everyone loves someone) is weaker than $\exists y\,\forall x\,\text{Loves}(x, y)$ (someone is loved by everyone).

**Unification** finds a substitution that makes two terms identical. $P(x, f(y))$ and $P(a, f(z))$ unify with $\{x/a, y/z\}$. The **occurs check** rejects binding a variable to a term containing it, so $x$ and $f(x)$ do not unify. First-order entailment is **semidecidable**: complete procedures (such as resolution with unification) find a proof if one exists but may run forever otherwise.

@example
title: Resolution refutation
problem: The KB is $P \Rightarrow Q$, $Q \Rightarrow R$ and $P$. Prove $R$ by resolution.
step: Convert to clauses: $\neg P \lor Q$, $\neg Q \lor R$, $P$. Add the negated query $\neg R$.
step: Resolve $\neg P \lor Q$ with $P$ on the symbol $P$: the result is $Q$.
step: Resolve $Q$ with $\neg Q \lor R$ on $Q$: the result is $R$.
step: Resolve $R$ with $\neg R$: the result is the empty clause, a contradiction, so the KB with $\neg R$ is unsatisfiable.
answer: $KB \models R$, because the empty clause was derived.

@example
title: Unifying two terms
problem: Unify $\text{Likes}(x, \text{Mother}(y))$ with $\text{Likes}(\text{Bo}, \text{Mother}(\text{Ann}))$.
step: Both literals use the predicate Likes with two arguments, so compare argument by argument.
step: First arguments: the variable $x$ against the constant Bo gives $x/\text{Bo}$.
step: Second arguments: Mother(y) against Mother(Ann) have the same function, so unify the arguments: $y/\text{Ann}$.
step: Apply $\{x/\text{Bo}, y/\text{Ann}\}$ to the first literal to check: it becomes Likes(Bo, Mother(Ann)), identical to the second.
answer: The most general unifier is $\{x/\text{Bo},\; y/\text{Ann}\}$.

@mistakes
- Reading $P \Rightarrow Q$ as "$P$ causes $Q$": it is simply false only when $P$ is true and $Q$ is false, so it is true whenever $P$ is false.
- Translating "all students study" as $\forall x\,(\text{Student}(x) \land \text{Studies}(x))$, which says that everything is a student.
- Swapping quantifier order: $\forall x\,\exists y$ and $\exists y\,\forall x$ are different statements.
- Resolving two pairs of complementary literals in one step: each resolution step eliminates exactly one complementary pair (the result of resolving $P \lor Q$ with $\neg P \lor \neg Q$ is the tautology $Q \lor \neg Q$ or $P \lor \neg P$, not the empty clause).

model:
```python
def fc_entails(rules, facts, query):
    known = set(facts)
    changed = True
    while changed:
        changed = False
        for premises, conclusion in rules:
            if conclusion not in known and all(p in known for p in premises):
                known.add(conclusion)
                changed = True
    return query in known
```
hint: Keep a set of known symbols that starts with the facts.
hint: Repeat over all rules until a full pass adds nothing new; a rule fires when all its premises are known.
solution: Fire every rule whose premises are all known, add its conclusion, and repeat until nothing changes; the query is entailed exactly when it ends up in the set. A rule with an empty premise list always fires.

model:
```python
def resolve(c1, c2):
    def complement(lit):
        return lit[1:] if lit.startswith("~") else "~" + lit

    resolvents = set()
    for lit in c1:
        comp = complement(lit)
        if comp in c2:
            resolvents.add(frozenset((set(c1) - {lit}) | (set(c2) - {comp})))
    return resolvents
```
hint: The complement of `"P"` is `"~P"` and the complement of `"~P"` is `"P"`.
hint: For each literal in `c1` whose complement is in `c2`, remove that pair and take the union of the rest.
solution: Resolve on one complementary pair at a time: remove the literal from `c1` and its complement from `c2` and union what remains. Two pairs (`P`/`~P` and `Q`/`~Q`) give two different resolvents, each still containing a complementary pair, so they are tautologies.

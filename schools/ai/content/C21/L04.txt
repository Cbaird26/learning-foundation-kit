@article
Suppose you are standing at a fork. One path gives a small reward now and leads to a good state; the other gives a bigger reward now and leads to a bad one. To choose well you need to know how good each state is, not just how good the next reward is. The **value function** measures that, and the **Bellman equations** say how the values of neighboring states must relate to each other.

### Value functions

Fix a policy $\pi$ and a discount factor $\gamma$. The **state-value function** and **action-value function** are

$$v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s], \qquad q_\pi(s, a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a].$$

The value of a terminal state is 0, because no reward follows it.

### The Bellman expectation equation

Start from $G_t = R_{t+1} + \gamma G_{t+1}$ and take the expectation given $S_t = s$. The expectation splits over the action chosen by $\pi$ and then over the outcome of the dynamics. By the Markov property, once $S_{t+1} = s'$ is known, the expected future return is $v_\pi(s')$ no matter how the agent got there, so

$$v_\pi(s) = \sum_a \pi(a \mid s) \sum_{s', r} p(s', r \mid s, a)\,\big[\, r + \gamma\, v_\pi(s') \,\big].$$

In words, the value of a state is the policy-weighted average, over actions and outcomes, of the immediate reward plus the discounted value of the next state. Define the inner quantity

$$q_\pi(s, a) = \sum_{s', r} p(s', r \mid s, a)\,\big[\, r + \gamma\, v_\pi(s') \,\big],$$

so that $v_\pi(s) = \sum_a \pi(a \mid s)\, q_\pi(s, a)$.

### Solving for $v_\pi$

The equation holds for every state, so for $n$ non-terminal states it is a system of $n$ linear equations in $n$ unknowns. In the notation of lesson 3, with $r_\pi$ the vector of expected rewards and $\mathbf{P}_\pi$ the matrix of transition probabilities among non-terminal states,

$$\mathbf{v}_\pi = \mathbf{r}_\pi + \gamma \mathbf{P}_\pi \mathbf{v}_\pi \quad\Longleftrightarrow\quad (\mathbf{I} - \gamma \mathbf{P}_\pi)\,\mathbf{v}_\pi = \mathbf{r}_\pi .$$

For $\gamma < 1$ the matrix $\mathbf{I} - \gamma\mathbf{P}_\pi$ is invertible, because every row of $\mathbf{P}_\pi$ sums to at most 1, so there is a unique solution $\mathbf{v}_\pi = (\mathbf{I} - \gamma \mathbf{P}_\pi)^{-1} \mathbf{r}_\pi$.

A tiny example. Two states A and B, one action in each, and $\gamma = 0.5$. From A the agent moves to B and receives 2. From B it receives 0 and returns to A with probability 0.5, or receives 4 and terminates with probability 0.5. The equations are $v_A = 2 + 0.5\,v_B$ and $v_B = 0.5(0 + 0.5\,v_A) + 0.5(4 + 0) = 0.25\,v_A + 2$. Substituting gives $v_A = 3 + 0.125\,v_A$, so $v_A = 24/7 \approx 3.429$ and $v_B = 20/7 \approx 2.857$.

### Optimal values

A policy $\pi$ is at least as good as $\pi'$ if $v_\pi(s) \ge v_{\pi'}(s)$ in every state. For finite MDPs there is always at least one **optimal policy** $\pi_*$, and all optimal policies share the same optimal value functions $v_*$ and $q_*$. They satisfy the **Bellman optimality equation**

$$v_*(s) = \max_a \sum_{s', r} p(s', r \mid s, a)\,\big[\, r + \gamma\, v_*(s') \,\big], \qquad q_*(s, a) = \sum_{s', r} p(s', r \mid s, a)\,\big[\, r + \gamma \max_{a'} q_*(s', a') \,\big].$$

The expectation over actions is replaced by a maximum, so the equations are no longer linear. If you know $v_*$, a policy that is **greedy** with respect to it, choosing in each state an action that attains the maximum, is optimal. The next two lessons compute $v_*$ by turning these equations into updates.

### In code

```python
def q_value(P, v, s, a, gamma):
    """Expected reward plus discounted next value; terminal states are 0."""
    return sum(p * (r + gamma * v.get(s2, 0.0)) for p, s2, r in P[s][a])

P = {'A': {'go': [(1.0, 'B', 2)]},
     'B': {'go': [(0.5, 'A', 0), (0.5, 'T', 4)]}}
v = {'A': 24 / 7, 'B': 20 / 7}
print(q_value(P, v, 'A', 'go', 0.5), v['A'])
```

Both printed numbers are $3.4286$, which confirms that $v$ satisfies the equation in state A. Here `v.get(s2, 0.0)` gives terminal states the value 0.

@example
title: From values to action values and the greedy choice
problem: State S0 has two actions. `safe` leads to S1 with reward 1. `risky` leads to S1 with reward 4 with probability 0.5 and to the terminal state with reward $-2$ with probability 0.5. Assume $\gamma = 0.9$ and $v(S1) = 2$. Compute the action values of S0 and the greedy action. Then, with a policy that picks each action with probability 0.5, find $v_\pi(S0)$.
step: For `safe`: $q = 1\,(1 + 0.9 \times 2) = 2.8$.
step: For `risky`: $q = 0.5\,(4 + 0.9 \times 2) + 0.5\,(-2 + 0) = 0.5(5.8) - 1 = 1.9$.
step: The greedy action is `safe`, with $q = 2.8 > 1.9$, even though `risky` has the larger best-case reward.
step: Under the uniform policy, $v_\pi(S0) = 0.5(2.8) + 0.5(1.9) = 2.35$.
answer: $q(S0, \text{safe}) = 2.8$, $q(S0, \text{risky}) = 1.9$, the greedy action is `safe`, and $v_\pi(S0) = 2.35$.

@mistakes
- Giving a terminal state a nonzero value: its value is 0, and the reward for entering it belongs to the transition.
- Forgetting the discount on the next state's value, or discounting the immediate reward as well.
- Using the Bellman expectation equation (an average over the policy) where the optimality equation (a maximum over actions) is meant, or the reverse.
- Treating a greedy policy for an arbitrary value function as optimal: it is optimal only if the value function satisfies the optimality equation.

model:
```python
def evaluate_exact(P, pi, gamma):
    """Solve (I - gamma * P_pi) v = r_pi by Gaussian elimination."""
    states = list(P)
    index = {s: i for i, s in enumerate(states)}
    n = len(states)
    a = [[0.0] * n for _ in range(n)]
    b = [0.0] * n
    for s in states:
        i = index[s]
        a[i][i] += 1.0
        for act, outcomes in P[s].items():
            w = pi[s].get(act, 0.0)
            for prob, s2, r in outcomes:
                b[i] += w * prob * r
                if s2 in index:
                    a[i][index[s2]] -= gamma * w * prob
    for c in range(n):
        p = max(range(c, n), key=lambda row: abs(a[row][c]))
        a[c], a[p] = a[p], a[c]
        b[c], b[p] = b[p], b[c]
        for row in range(n):
            if row != c:
                f = a[row][c] / a[c][c]
                for k in range(c, n):
                    a[row][k] -= f * a[c][k]
                b[row] -= f * b[c]
    return {s: b[index[s]] / a[index[s]][index[s]] for s in states}
```
hint: Row $i$ of the system reads $v_i - \gamma\sum_j P_\pi[i][j]\, v_j = r_\pi[i]$; terminal next states contribute nothing to the matrix because their value is 0.
solution: Build the matrix row by row: put 1 on the diagonal, subtract `gamma * pi * prob` in the column of every non-terminal next state, and accumulate `pi * prob * reward` on the right-hand side. Then eliminate with partial pivoting. The test with `gamma = 0.0` reduces to the expected immediate reward, which catches a solution that discounts the reward instead of the next value.

```python
def greedy_policy(P, v, gamma):
    """Greedy action in each state with respect to the values v."""
    policy = {}
    for s in P:
        best_a, best_q = None, None
        for a, outcomes in P[s].items():
            q = sum(p * (r + gamma * v.get(s2, 0.0)) for p, s2, r in outcomes)
            if best_q is None or q > best_q:
                best_a, best_q = a, q
        policy[s] = best_a
    return policy
```
hint: For every action compute $\sum p\,(r + \gamma\,v(s'))$ using `v.get(s2, 0.0)`, and update the best action only on a strictly larger value.
solution: The greedy action maximizes the one-step lookahead $q(s, a)$ computed from the given values. In the first test the values make `L` better in state 1 (a reward of 2 plus a valuable next state beats the terminal reward of 5 only because state 0 is worth 6); using strict inequality keeps the earlier action in a tie.

```python
def optimality_residual(P, v, gamma):
    """Largest Bellman optimality error over the states of P."""
    worst = 0.0
    for s in P:
        best = max(sum(p * (r + gamma * v.get(s2, 0.0)) for p, s2, r in outs)
                   for outs in P[s].values())
        worst = max(worst, abs(v.get(s, 0.0) - best))
    return worst
```
hint: For each state compute the best one-step lookahead value, compare it with `v[s]`, and keep the largest absolute gap.
solution: The residual is the sup-norm of $v - T v$, where $T$ is the optimality backup. In the last two tests the single action repeats reward 2 forever, so $v = 2/(1 - \gamma)$ gives residual 0 (20 at $\gamma = 0.9$, 4 at $\gamma = 0.5$). The value 10 at $\gamma = 0.5$ has one-step lookahead $2 + 0.5 \times 10 = 7$, so its residual is 3.

@article
A bandit has one situation and one choice. Real problems have many situations, and a choice now changes which situation comes next: a robot in a hallway that steps left moves closer to the charger, and a step right moves it away. Reward may come only after many steps. The **Markov decision process** (MDP) is the model that captures this, and it is the language of the rest of the course.

### The definition

A finite MDP consists of

- a set of **states** $\mathcal{S}$ and, for each state, a set of **actions** $\mathcal{A}(s)$;
- **dynamics** $p(s', r \mid s, a)$: the probability of landing in state $s'$ and receiving reward $r$ after taking action $a$ in state $s$;
- a **discount factor** $\gamma \in [0, 1]$.

The **Markov property** says the dynamics depend only on the current state and action, not on earlier history: the state summarizes everything relevant from the past. In code we write the dynamics as a dictionary: `P[s][a]` is a list of triples `(prob, next_state, reward)` whose probabilities add up to 1. A **terminal state** ends the episode; it has no actions (it does not appear as a key of `P`) and yields no further reward.

The agent follows a **policy** $\pi$. A deterministic policy gives an action $\pi(s)$; a stochastic policy gives probabilities $\pi(a \mid s)$. Interaction produces a **trajectory** $S_0, A_0, R_1, S_1, A_1, R_2, \dots$, where $R_{t+1}$ is the reward received after the action $A_t$.

### Returns

The agent's goal is not the next reward but the total future reward. The **discounted return** from time $t$ is

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}.$$

A reward received $k$ steps later is worth $\gamma^k$ times as much. For an episode that ends after $T$ steps the sum stops at $R_T$.

Factor out the first reward and what remains is $\gamma$ times the return from the next step:

$$G_t = R_{t+1} + \gamma\,G_{t+1}.$$

This **recursion** is the seed of the Bellman equations in the next lesson. It also gives the fast way to compute returns: start at the end of an episode and work backward. For the reward sequence $2, 0, 6$ with $\gamma = 0.5$: $G_2 = 6$, $G_1 = 0 + 0.5(6) = 3$, $G_0 = 2 + 0.5(3) = 3.5$, which equals $2 + 0 + 0.25 \times 6 = 3.5$.

Why discount? For a **continuing** task with no terminal state the undiscounted sum may be infinite. If every reward satisfies $|R| \le R_{\max}$ and $\gamma < 1$ then $|G_t| \le R_{\max}/(1 - \gamma)$. If the reward is a constant $c$, then $G_t = c/(1 - \gamma)$, the sum of a geometric series. Small $\gamma$ makes the agent short-sighted; $\gamma$ near 1 makes it patient. Episodic tasks can use $\gamma = 1$.

### A policy turns an MDP into a simpler process

Fix a stochastic policy $\pi$. The expected reward and the transition probabilities from a state, with the action averaged out, are

$$r_\pi(s) = \sum_a \pi(a \mid s) \sum_{s', r} p(s', r \mid s, a)\, r, \qquad P_\pi(s' \mid s) = \sum_a \pi(a \mid s) \sum_r p(s', r \mid s, a).$$

Together they form a **Markov reward process**. We will solve it exactly in lesson 4.

### In code

```python
def discounted_return(rewards, gamma):
    """Return of a finite reward list, computed from the end backward."""
    g = 0.0
    for r in reversed(rewards):
        g = r + gamma * g
    return g

print(discounted_return([1, 0, 0, 5], 0.9))
```

This prints `4.645`, which equals $1 + 0.9^3 \times 5$. A **gridworld** is an MDP whose states are cells of a small grid; the actions move the agent up, down, left or right, a move into a wall leaves it in place, and the episode ends in terminal cells. Later lessons use gridworlds of at most $5 \times 5$ cells.

@example
title: Returns by recursion and the effect of a policy
problem: (a) A trajectory gives rewards $1, 0, 0, 5$ at times $1, 2, 3, 4$. Find all returns $G_0, \dots, G_3$ for $\gamma = 0.9$. (b) In state A, the action `safe` always gives reward 1, and the action `risky` gives reward 4 with probability 0.6 and reward $-1$ with probability 0.4. A policy plays `safe` with probability 0.5 and `risky` with probability 0.5. What is $r_\pi(A)$?
step: Work backward. The last reward is the whole return from time 3: $G_3 = 5$.
step: Then $G_2 = 0 + 0.9 \times 5 = 4.5$, $G_1 = 0 + 0.9 \times 4.5 = 4.05$ and $G_0 = 1 + 0.9 \times 4.05 = 4.645$. Direct check: $1 + 0.9^3 \times 5 = 1 + 3.645 = 4.645$.
step: The expected reward of each action: `safe` gives $1$ and `risky` gives $0.6 \times 4 + 0.4 \times (-1) = 2.0$.
step: Average over the policy: $r_\pi(A) = 0.5 \times 1 + 0.5 \times 2.0 = 1.5$.
answer: (a) $G = (4.645, 4.05, 4.5, 5)$. (b) $r_\pi(A) = 1.5$.

@mistakes
- Discounting the first reward: $R_{t+1}$ has weight $\gamma^0 = 1$, and the weights start counting from the reward after $G_t$'s own time step.
- Computing returns forward and mixing up the exponents: working backward with $G_t = R_{t+1} + \gamma G_{t+1}$ avoids powers entirely.
- Forgetting that transition probabilities for one state-action pair must add up to 1, and that terminal states have no future reward.
- Reading the reward as the label of a state: the reward $r$ in $p(s', r \mid s, a)$ depends on the transition, and the return is the sum over the whole future.

model:
```python
def rollout(step, policy, s0, gamma, max_steps):
    """Discounted return of a deterministic policy in a deterministic MDP."""
    total = 0.0
    discount = 1.0
    s = s0
    for _ in range(max_steps):
        if s not in step:
            break
        s, reward = step[s][policy[s]]
        total += discount * reward
        discount *= gamma
    return total
```
hint: Keep a running discount that starts at 1 and is multiplied by `gamma` after every reward; check for a terminal state before acting.
solution: Each step looks up the action from the policy and the `(next_state, reward)` from `step`, adds the reward times the current discount, and advances. The test with `max_steps = 4` shows a policy that bounces between two states and is cut off by the step limit, and the test starting in a terminal state returns zero.

model:
```python
def policy_dynamics(P, pi):
    """Expected reward and next-state probabilities under a policy."""
    r_pi = {}
    P_pi = {}
    for s in P:
        r_pi[s] = 0.0
        P_pi[s] = {}
        for a, outcomes in P[s].items():
            w = pi[s].get(a, 0.0)
            if w == 0.0:
                continue
            for prob, s2, r in outcomes:
                r_pi[s] += w * prob * r
                P_pi[s][s2] = P_pi[s].get(s2, 0.0) + w * prob
    return r_pi, P_pi
```
hint: Loop over states, actions and outcomes; add `pi * prob * reward` to the expected reward and `pi * prob` to the entry of the next state.
solution: Weight each outcome by the probability of the action times the outcome's probability. Several outcomes or actions can lead to the same next state, so their weights are accumulated in the dictionary (state B is reached by both actions of A). Skipping zero-probability actions in the second test keeps `P_pi` free of impossible next states.

model:
```python
def all_returns(rewards, gamma):
    """Discounted returns G_t for every time step, computed backward."""
    returns = [0.0] * len(rewards)
    g = 0.0
    for t in range(len(rewards) - 1, -1, -1):
        g = rewards[t] + gamma * g
        returns[t] = g
    return returns
```
hint: Start from the last time step with `g = 0`, and apply `g = rewards[t] + gamma * g` while filling the list from the end.
solution: The recursion $G_t = R_{t+1} + \gamma G_{t+1}$ turns the whole list into one backward pass, with $G_T = 0$ beyond the end. The test with `gamma = 1.0` gives the undiscounted suffix sums.

@quiz num
prompt: An agent receives reward 1 once, $k$ steps in the future, so that this reward contributes $\gamma^k$ to the return. With $\gamma = 0.9$, what is the smallest integer $k$ for which $\gamma^k < 0.01$?

solution: $k > \ln 0.01 / \ln 0.9 = 43.7$, so $k = 44$; indeed $0.9^{43} = 0.0108$ and $0.9^{44} = 0.0097$. Rewards more than about 44 steps ahead barely matter at $\gamma = 0.9$.

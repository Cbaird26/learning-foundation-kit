```python
ACTIONS = [('U', (-1, 0)), ('D', (1, 0)), ('L', (0, -1)), ('R', (0, 1))]
ROWS, COLS = 4, 5
START, GOAL = (3, 0), (3, 4)
HAZARDS = {(3, 1), (3, 2), (3, 3)}

def make_world(goal_reward=10.0, hazard_reward=-50.0, step_reward=-1.0,
               bonus_cell=None, bonus=0.0):
    """step[s][a] = (next_state, reward); terminal states are not keys."""
    step = {}
    for r in range(ROWS):
        for c in range(COLS):
            s = (r, c)
            if s == GOAL or s in HAZARDS:
                continue
            step[s] = {}
            for a, (dr, dc) in ACTIONS:
                nr, nc = r + dr, c + dc
                if not (0 <= nr < ROWS and 0 <= nc < COLS):
                    nr, nc = r, c
                n = (nr, nc)
                if n == GOAL:
                    rew = goal_reward
                elif n in HAZARDS:
                    rew = hazard_reward
                else:
                    rew = step_reward
                    if n == bonus_cell:
                        rew += bonus
                step[s][a] = (n, rew)
    return step
```

### Week by week

1. **Bandits.** Incremental estimate $Q \leftarrow Q + \alpha(R - Q)$; greedy, $\varepsilon$-greedy, optimistic initial values; regret $\sum_t \Delta_{A_t}$.
2. **UCB and Thompson sampling.** UCB score $Q + c\sqrt{\ln t / N}$ with untried arms first; Beta posteriors $\text{Beta}(1 + s, 1 + f)$; sample and play the largest.
3. **MDPs and returns.** $G_t = R_{t+1} + \gamma G_{t+1}$; the dynamics as `P[s][a]`; policy-induced reward and transitions.
4. **Bellman equations.** $v_\pi(s) = \sum_a \pi(a|s)\sum p\,[r + \gamma v_\pi(s')]$; $(\mathbf{I} - \gamma\mathbf{P}_\pi)\mathbf{v} = \mathbf{r}_\pi$; optimality equation with a maximum.
5. **Policy evaluation and iteration.** Sweeps are contractions with factor $\gamma$; improvement theorem; stable tie-breaking.
6. **Value iteration.** Optimality backup; stopping error $\gamma\theta/(1 - \gamma)$; greedy extraction.
7. **Monte Carlo.** First-visit and every-visit averages; $\varepsilon$-soft control; importance ratios $\rho = \prod \pi/b$.
8. **TD learning.** $\delta = R + \gamma V(S') - V(S)$; $n$-step returns; bias versus variance against Monte Carlo.
9. **Q-learning and SARSA.** Target with $\max_{a'} Q$ (off-policy) versus $Q(S', A')$ (on-policy); expected SARSA.
10. **Function approximation.** Semi-gradient TD, $\mathbf{w} \leftarrow \mathbf{w} + \alpha\delta\mathbf{x}$; replay and target network; the deadly triad.
11. **Policy gradients.** $\nabla J = \mathbb{E}[G\,\nabla\ln\pi]$; softmax gradient $\mathbb{1}[a=b] - \pi(b)$; baselines; actor-critic.
12. **Models and reward safety.** Dyna; reward hacking; potential-based shaping $\gamma\Phi(s') - \Phi(s)$.

### Common errors

- Counting the first reward with a discount, or mixing up the indices of $R_{t+1}$ and $S_t$.
- Giving terminal states a nonzero value or forgetting to stop bootstrapping at them.
- Updating in place when the method calls for a synchronous sweep, and the reverse.
- Mixing the SARSA and Q-learning targets, or using the maximum in an on-policy evaluation.
- Reading a high training return as a good greedy policy: training returns include exploration.
- Treating a weighted and an ordinary importance-sampling estimate as interchangeable.

    for c in range(1, n - 1):
        out = {}

model:
```python
def solve_mdp(P, gamma, theta):
    """Value iteration followed by greedy policy extraction."""
    def q(s, a, v):
        return sum(p * (r + gamma * v.get(s2, 0.0)) for p, s2, r in P[s][a])

    v = {s: 0.0 for s in P}
    while True:
        new_v = {s: max(q(s, a, v) for a in P[s]) for s in P}
        delta = max(abs(new_v[s] - v[s]) for s in P)
        v = new_v
        if delta < theta:
            break
    policy = {}
    for s in P:
        best = None
        best_q = None
        for a in P[s]:
            value = q(s, a, v)
            if best is None or value > best_q + 1e-9:
                best, best_q = a, value
        policy[s] = best
    return policy, v
```
hint: Value iteration first, then a second pass over states and actions comparing action values with a tolerance of 1e-9.
solution: Value iteration converges to $v_*$ within $\gamma\theta/(1 - \gamma)$, and the greedy policy for it is optimal up to ties; the tolerance in the scan makes ties go to the first listed action even when floating-point noise separates two equal values. With a tiny discount factor (0.1) the immediate rewards dominate, so the best action in state 1 changes from `L` to `R`.

hint: Only two deterministic policies exist. For action `a` forever, $v = 1 + 0.8v$; for action `b` forever, $v = 0.5 \times 8 + 0.5 \times 0.8\,v$. Take the larger.
solution: Always playing `a` gives $v = 1/(1 - 0.8) = 5$. Always playing `b` gives $v = 4/(1 - 0.4) = 6.667$, because $v = 4 + 0.4v$. The optimal value satisfies $v_* = \max(1 + 0.8v_*,\ 4 + 0.4v_*)$, and its solution is $6.667$ with `b` optimal. Check: $1 + 0.8 \times 6.667 = 6.33 < 6.667$.

prompt: A Q-learning agent and a SARSA agent are trained with fixed $\varepsilon = 0.1$ on a gridworld where the shortest route to the goal runs along the edge of a hazard region (entering it ends the episode with a large penalty). (1) Predict which route each agent's greedy policy will prefer and which agent will score higher on its own training episodes, and justify with the update rules. (2) Explain what would change if $\varepsilon$ were decayed to 0, and what would change if Monte Carlo control with the same $\varepsilon$ were used instead of TD. (3) Give one experiment with a reward change that would test your explanation, and say what outcome would show that you were wrong.
hint: Compare the targets: Q-learning bootstraps from the greedy next action and SARSA from the next action actually taken, including random ones.
solution: (1) Q-learning's target uses the maximum next value, so it learns the values of the greedy policy and its greedy policy takes the short route along the edge; SARSA's target includes the chance that exploration steps into the hazard, so the edge cells get lower values and its policy prefers a route farther from the hazard. During training both explore with $\varepsilon = 0.1$, so the Q-learning agent occasionally falls into the hazard from the edge and typically has the lower average training return, while SARSA takes the safer route and scores higher on its training episodes, even though its greedy policy is longer. (2) If $\varepsilon \to 0$ suitably, SARSA's policy approaches the optimal one, because the policy it evaluates becomes the greedy one, and the two methods agree in the limit; the training-return gap closes. Monte Carlo control with the same $\varepsilon$ also evaluates the $\varepsilon$-greedy policy, like SARSA, so it should prefer the safe route, but it learns from whole-episode returns, with higher variance, and so it typically needs more episodes and its curves are noisier. (3) Reduce the hazard penalty from a large to a small value: the edge route becomes cheap for both agents, so SARSA's route should move toward the short path; a result in which SARSA keeps the long route when the hazard is nearly free would contradict the explanation that its route choice comes from the cost of exploration. Averaging over several seeds is needed before concluding anything.

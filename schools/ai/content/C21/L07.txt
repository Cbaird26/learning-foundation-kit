@article
Dynamic programming needs the dynamics $p(s', r \mid s, a)$ written down. A robot, a game or a recommender rarely comes with them. What it does come with is **experience**: you can run the policy and record what happens. **Monte Carlo** (MC) methods learn value functions from sampled episodes alone, with no model. The idea is old and simple: since $v_\pi(s)$ is the expected return from $s$, average the returns you actually see.

### Episodes as data

An episode is a list of steps `(s, a, r)`: the agent was in state `s`, took action `a`, and then received reward `r` (this is $R_{t+1}$). MC applies to **episodic** tasks, because it needs the whole episode to finish before it knows any return. For an episode of length $T$, compute the returns backward with $G_{T} = 0$ and $G_t = R_{t+1} + \gamma G_{t+1}$.

### Prediction: first-visit and every-visit

A state can appear several times in one episode. **First-visit MC** averages, for each state, the return that follows its first visit in each episode. **Every-visit MC** averages the returns after all visits. Take $\gamma = 0.5$ and two episodes: episode 1 visits A (reward 2), then B (reward $-1$), then A again (reward 4); episode 2 visits B (reward 3), then A (reward 1). The returns are $(2.5, 1, 4)$ in episode 1 and $(3.5, 1)$ in episode 2. First-visit MC gives $V(A) = (2.5 + 1)/2 = 1.75$ and $V(B) = (1 + 3.5)/2 = 2.25$; every-visit MC gives $V(A) = (2.5 + 4 + 1)/3 = 2.5$ and the same $V(B)$.

Both estimates converge to $v_\pi(s)$ as the number of episodes grows. First-visit returns are independent, identically distributed samples with expected value $v_\pi(s)$, so that estimate is unbiased; every-visit estimates are biased for finite data but also consistent. MC does not **bootstrap**: it never uses another state's estimate to update this one, so the estimate of each state is computed without using the estimates of other states, and the cost of estimating one state does not grow with the size of the state space. The price is that returns are noisy: they depend on many random steps, so the variance is high.

The averages can be kept incrementally, $V(s) \leftarrow V(s) + \tfrac{1}{N(s)}\,(G - V(s))$, or with a constant step size, $V(s) \leftarrow V(s) + \alpha\,(G - V(s))$, which tracks a changing policy or environment.

### Control

To improve a policy we want the greedy choice $\arg\max_a q(s, a)$. With a model we could compute that from $v$ by one-step lookahead; without one we need action values, so MC control estimates $q_\pi(s, a)$ by averaging returns for state-action pairs. The new difficulty is **exploration**: a deterministic policy never tries the other actions, so their values are never estimated. Two fixes:

- **Exploring starts**: begin each episode from a random state-action pair.
- **$\varepsilon$-soft policies**: act greedily with probability $1 - \varepsilon$ and uniformly at random with probability $\varepsilon$, so every action keeps probability at least $\varepsilon/|\mathcal{A}|$ and the greedy action has probability $1 - \varepsilon + \varepsilon/|\mathcal{A}|$.

Improving an $\varepsilon$-greedy policy toward $\varepsilon$-greedy with respect to its own $q$ is still guaranteed to be an improvement within the class of $\varepsilon$-soft policies. If $\varepsilon$ is reduced toward 0 in the right way (a condition called GLIE, greedy in the limit with infinite exploration), the policy converges to an optimal one.

### Off-policy prediction

Often we learn about a **target policy** $\pi$ from episodes generated by a different **behavior policy** $b$ (for example, learning about the greedy policy from exploratory data). We need $\pi(a \mid s) > 0 \Rightarrow b(a \mid s) > 0$. Correct the sampled return with the **importance-sampling ratio** of the episode,

$$\rho = \prod_{k=0}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)},$$

in which the unknown dynamics cancel. For episodes $i = 1, \dots, n$ from the same start state with returns $G_i$ and ratios $\rho_i$, the **ordinary** estimate is $\frac{1}{n}\sum_i \rho_i G_i$ and the **weighted** estimate is $\sum_i \rho_i G_i / \sum_i \rho_i$. The ordinary estimate is unbiased but can have huge variance; the weighted one is biased (the bias shrinks as $n$ grows) but usually has much lower variance.

### In code

```python
def mc_prediction(episodes, gamma, first_visit=True):
    """Average (first- or every-visit) returns for each state."""
    total, count = {}, {}
    for episode in episodes:
        g, returns = 0.0, [0.0] * len(episode)
        for t in range(len(episode) - 1, -1, -1):
            g = episode[t][2] + gamma * g
            returns[t] = g
        seen = set()
        for t, (s, a, r) in enumerate(episode):
            if first_visit and s in seen:
                continue
            seen.add(s)
            total[s] = total.get(s, 0.0) + returns[t]
            count[s] = count.get(s, 0) + 1
    return {s: total[s] / count[s] for s in total}

e1 = [('A', 'go', 2), ('B', 'go', -1), ('A', 'go', 4)]
e2 = [('B', 'go', 3), ('A', 'go', 1)]
print(mc_prediction([e1, e2], 0.5))
print(mc_prediction([e1, e2], 0.5, first_visit=False))
```

This prints `{'A': 1.75, 'B': 2.25}` and `{'A': 2.5, 'B': 2.25}`, the numbers computed above.

title: First-visit versus every-visit, and two importance-sampling estimates
problem: (a) With $\gamma = 1$, episode 1 visits S (reward 1), T (reward 0), S (reward 5) and ends; episode 2 visits T (reward 5) then S (reward 1) and ends. Compute $V(S)$ by first-visit and every-visit MC. (b) Three episodes from a behavior policy have importance ratios $\rho = (2, 0, 4)$ and returns $G = (1, 5, 3)$. Compute the ordinary and the weighted importance-sampling estimates.
step: Work backward with $\gamma = 1$. Episode 1 has rewards $1, 0, 5$, so its returns are $G_2 = 5$, $G_1 = 0 + 5 = 5$ and $G_0 = 1 + 5 = 6$. Episode 2 has rewards $5, 1$, so $G_1 = 1$ (the visit to S) and $G_0 = 6$.
step: First-visit: S's first visit in episode 1 has return 6 and the only visit in episode 2 has return 1, so $V(S) = (6 + 1)/2 = 3.5$. Every-visit: the returns for S are $6, 5, 1$, so $V(S) = 12/3 = 4.0$.
step: Ordinary importance sampling: $\frac{1}{3}(2 \cdot 1 + 0 \cdot 5 + 4 \cdot 3) = 14/3 \approx 4.667$.
step: Weighted importance sampling: $(2 + 0 + 12)/(2 + 0 + 4) = 14/6 \approx 2.333$. The episode with $\rho = 0$ is impossible under the target policy, so it counts as nothing in the weighted estimate but still counts as one episode in the ordinary estimate's denominator.
answer: (a) First-visit $V(S) = 3.5$; every-visit $V(S) = 4.0$. (b) Ordinary $4.667$; weighted $2.333$.

@mistakes
- Computing returns forward from the first reward: the return of a step needs all later rewards, so work backward from the end of the episode.
- Counting a state twice in first-visit MC when it appears twice in one episode.
- Trying to improve a policy greedily from state values alone when there is no model: without $p$ you cannot do the lookahead, so estimate $q(s, a)$.
- Using a deterministic policy to generate the episodes in MC control: unexplored actions get no estimates, so the policy cannot improve.
- Dividing a weighted importance-sampling sum by the number of episodes instead of the sum of the ratios.

```python
def mc_greedy(episodes, gamma):
    """Greedy policy from first-visit Monte Carlo estimates of q."""
    total, count = {}, {}
    for episode in episodes:
        returns = [0.0] * len(episode)
        g = 0.0
        for t in range(len(episode) - 1, -1, -1):
            g = episode[t][2] + gamma * g
            returns[t] = g
        seen = set()
        for t, (s, a, r) in enumerate(episode):
            if (s, a) in seen:
                continue
            seen.add((s, a))
            total[(s, a)] = total.get((s, a), 0.0) + returns[t]
            count[(s, a)] = count.get((s, a), 0) + 1
    policy, best = {}, {}
    for s, a in sorted(total):
        q = total[(s, a)] / count[(s, a)]
        if s not in best or q > best[s]:
            policy[s], best[s] = a, q
    return policy
```
hint: Estimate the value of each (state, action) pair from the first occurrence in each episode, then pick the best action per state; visit the pairs in sorted order and replace the incumbent only when strictly better.
solution: The estimates are keyed by the pair, not the state alone. With $\gamma = 0.5$ the first-visit estimates are $q(M, a) = 2.375$ and $q(M, b) = 3.5$, so `b` is greedy in state M; an every-visit average would count the second occurrence of `('M', 'a')` (return 6) and give about 3.92, which would flip the answer in the first test. Sorting the pairs makes ties go to the alphabetically first action.

```python
def mc_constant_alpha(episodes, gamma, alpha):
    """Every-visit constant-step-size Monte Carlo prediction."""
    V = {}
    for episode in episodes:
        returns = [0.0] * len(episode)
        g = 0.0
        for t in range(len(episode) - 1, -1, -1):
            g = episode[t][2] + gamma * g
            returns[t] = g
        for t, (s, a, r) in enumerate(episode):
            old = V.get(s, 0.0)
            V[s] = old + alpha * (returns[t] - old)
    return V
```
hint: The returns do not depend on `V`, so compute them first; then loop over the steps in time order and move `V[s]` a fraction `alpha` toward each return.
solution: Each step moves the estimate a fraction `alpha` of the way toward its return. With `alpha = 1.0` the estimate is simply the most recent return, so state P ends with the return of its last visit, 2.0; with `alpha = 0.0` nothing moves. The order of the updates matters because each uses the current value of `V`.

```python
def ordinary_is(episodes, pi, b, gamma):
    """Ordinary importance-sampling estimate of the start-state value."""
    total = 0.0
    for episode in episodes:
        rho = 1.0
        g = 0.0
        for s, a, r in episode:
            rho *= pi[(s, a)] / b[(s, a)]
        for s, a, r in reversed(episode):
            g = r + gamma * g
        total += rho * g
    return total / len(episodes)
```
hint: Multiply the ratios along the episode, compute the first return with the backward recursion, and average the products over episodes.
solution: Each episode contributes its return scaled by how much more (or less) likely the target policy was to produce it. With `pi = b` every ratio is 1 and the result is the plain mean of the returns (2.75). An episode whose action has target probability 0 contributes nothing, as in the last test.

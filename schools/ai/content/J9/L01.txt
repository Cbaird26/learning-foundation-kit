@article
A **program** is a list of instructions that a computer follows one line at a time, from top to bottom. Python is a language for writing those instructions so that both people and computers can read them. Your programs run in the editor on this site, and the same code runs on any computer with Python installed.

### Showing things with print

The instruction `print(...)` displays something on the screen. Text goes inside quotes and is called a **string**. Numbers have no quotes.

```python
print("Hello")   # shows Hello
print(2 + 3)     # shows 5
print("2 + 3")   # shows 2 + 3
```

The quotes matter: Python calculates `2 + 3`, but it only copies the string `"2 + 3"`. Anything after a `#` on a line is a **comment**. Python ignores it, so you can use it to leave notes for people.

### Arithmetic

Python is a very capable calculator. These are its operators:

| Operator | Meaning | Example | Result |
|---|---|---|---|
| `+` | add | `7 + 2` | `9` |
| `-` | subtract | `7 - 2` | `5` |
| `*` | multiply | `7 * 2` | `14` |
| `/` | divide | `7 / 2` | `3.5` |
| `//` | whole-number division | `7 // 2` | `3` |
| `%` | remainder | `7 % 2` | `1` |
| `**` | power | `7 ** 2` | `49` |

Notice that `/` always gives a number with a decimal point, even when the answer is whole: `8 / 2` is `4.0`. Use `//` and `%` together to split a quantity: `17 // 5` is `3` (five fits into 17 three times) and `17 % 5` is `2` (what is left over).

### Order of operations

Python follows the same order as in math class: `**` first, then `*`, `/`, `//` and `%`, then `+` and `-`. Parentheses go first of all. So `2 + 3 * 4` is `14`, but `(2 + 3) * 4` is `20`.

Here is a complete program. Run it and compare the output with your predictions:

```python
# A tiny program
print("Minutes in a day:")
print(24 * 60)
print(17 // 5, 17 % 5)
```

It prints `Minutes in a day:`, then `1440`, then `3 2`. When `print` gets several values separated by commas, it puts a space between them.

title: Predicting arithmetic
problem: What does this program print?

```python
print(10 - 4 * 2)
print((10 - 4) * 2)
print(2 ** 3 + 1)
```
step: Line 1: multiplication comes before subtraction, so `4 * 2` is `8` and `10 - 8` is `2`.
step: Line 2: the parentheses force the subtraction first, so `6 * 2` is `12`.
step: Line 3: the power comes first, so `2 ** 3` is `8` and `8 + 1` is `9`.
step: Each `print` shows its own line, so the output is `2`, `12` and `9`.
answer: `2`, `12`, `9`

@mistakes
- Forgetting the quotes around text, so Python looks for a name instead and reports an error.
- Expecting `/` to give a whole number: `8 / 2` is `4.0`, and `8 // 2` is `4`.
- Ignoring the order of operations: `2 + 3 * 4` is `14`, not `20`. Use parentheses when you mean the addition first.
- Confusing `%` with a percent sign: it gives a remainder, so `17 % 5` is `2`.

@quiz code

```python
# Print the average of 8, 12 and 19
```
stdout:
```

```
model:
```python
print((8 + 12 + 19) / 3)
```
hint: The average is the total divided by how many numbers there are.
hint: Without parentheses, only the 19 would be divided by 3.
solution: Add the numbers inside parentheses first, then divide: `(8 + 12 + 19) / 3` is `39 / 3`, which is `13.0`. Writing `8 + 12 + 19 / 3` would divide only the 19.

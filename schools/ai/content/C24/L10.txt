@article
A model learns the world as it was in its training data. The world moves on: a new phone model changes the camera images, a recession changes spending, a competitor changes what customers buy. **Drift** is any change between the data a model was trained on and the data it now sees. Detecting it early is the point of monitoring.

### Kinds of drift

Write the joint distribution of inputs $\mathbf{x}$ and labels $y$ as $p(\mathbf{x}, y) = p(\mathbf{x})\, p(y \mid \mathbf{x})$. Three kinds of change matter.

| kind | what changes | example |
|---|---|---|
| covariate shift (data drift) | $p(\mathbf{x})$, while $p(y \mid \mathbf{x})$ stays | applicants' incomes rise, but the link between income and default is unchanged |
| label shift (prior shift) | $p(y)$ | a disease becomes more common, while its symptoms look the same |
| concept drift | $p(y \mid \mathbf{x})$ | after a rule change, the same transaction that was safe is now fraud |

Covariate shift and label shift are visible without labels, from inputs or from the distribution of predictions. Concept drift changes the right answer for the same input, so it can be confirmed only with labels (or a proxy for them). Drift can be **sudden**, **gradual** or **seasonal**; a baseline that ignores seasons will raise false alarms every winter.

### The population stability index

To compare a baseline sample with a current one for a numeric feature, cut the baseline into bins (often deciles, so each baseline bin holds the same share), then count how many current values fall in each bin. Let $e_i$ be the baseline proportion and $a_i$ the current proportion in bin $i$. The **population stability index** (PSI) is

$$\text{PSI} = \sum_{i} (a_i - e_i) \ln \frac{a_i}{e_i} .$$

Each term is nonnegative, because $a_i - e_i$ and $\ln(a_i/e_i)$ have the same sign, so $\text{PSI} \ge 0$, and it is $0$ exactly when the two distributions agree on every bin. It is also symmetric: swapping $a$ and $e$ gives the same value. For four equal baseline bins, $e = (0.25, 0.25, 0.25, 0.25)$, and current proportions $a = (0.10, 0.20, 0.30, 0.40)$:

$$\text{PSI} = (-0.15)\ln 0.4 + (-0.05)\ln 0.8 + (0.05)\ln 1.2 + (0.15)\ln 1.6 \approx 0.137 + 0.011 + 0.009 + 0.071 = 0.228 .$$

A widely used rule of thumb from credit-scoring practice treats PSI below 0.1 as stable, 0.1 to 0.25 as a moderate shift to investigate, and above 0.25 as a large shift. These cutoffs are conventions, not laws of statistics. A bin that is empty in one sample makes $\ln(a_i/e_i)$ infinite, so floor every proportion at a small value such as $10^{-4}$.

```python
from math import log

def psi_counts(expected_counts, actual_counts, eps=1e-4):
    """PSI from bin counts; proportions below eps are raised to eps."""
    e_total, a_total = sum(expected_counts), sum(actual_counts)
    total = 0.0
    for ec, ac in zip(expected_counts, actual_counts):
        e = max(ec / e_total, eps)
        a = max(ac / a_total, eps)
        total += (a - e) * log(a / e)
    return total

print(round(psi_counts([25, 25, 25, 25], [10, 20, 30, 40]), 4))   # 0.2282
```

### The Kolmogorov-Smirnov statistic

The **two-sample Kolmogorov-Smirnov** (KS) statistic needs no bins. With empirical cumulative distribution functions $F_a$ and $F_b$ (the fraction of each sample at or below $x$), it is $D = \max_x |F_a(x) - F_b(x)|$, the largest vertical gap between the two curves, between 0 (identical samples) and 1 (no overlap). For categorical features compare category proportions, for example with PSI over the categories.

### What a drift alert means

A drift score says the inputs changed, not that the model got worse; the change may be in a feature the model ignores. Conversely a model can degrade through concept drift with no input change. Treat a drift alert as a reason to look: check upstream pipelines for a changed feature, compare performance on recently labeled data, look at segments, and then decide whether to retrain on fresher data, fix the pipeline or roll back. With huge samples even tiny shifts are statistically detectable, so choose thresholds by their usefulness, not by significance alone.
@example
title: PSI from bin counts
problem: A feature's baseline sample of 1,000 values falls into four bins with counts $200, 300, 300, 200$. This week's 1,000 values fall into the same bins with counts $100, 250, 350, 300$. Compute the PSI and interpret it.
step: Baseline proportions: $e = (0.2, 0.3, 0.3, 0.2)$. Current proportions: $a = (0.1, 0.25, 0.35, 0.3)$.
step: Term by term: $(0.1 - 0.2)\ln(0.5) = 0.0693$; $(0.25 - 0.3)\ln(0.8333) = 0.0091$; $(0.35 - 0.3)\ln(1.1667) = 0.0077$; $(0.3 - 0.2)\ln(1.5) = 0.0405$.
step: The sum is $0.0693 + 0.0091 + 0.0077 + 0.0405 = 0.1267$.
step: By the rule of thumb, a PSI between 0.1 and 0.25 is a moderate shift: investigate, mostly because of the move of mass from the lowest bin to the highest, but it is not an emergency. Check the segments and the labeled performance before acting.
answer: PSI $\approx 0.127$, a moderate shift.
@mistakes
- Treating a high PSI as proof that the model is worse; it shows the inputs changed, and the model may not depend on that feature.
- Defining bins from the current sample instead of the baseline, which makes the baseline proportions change with every comparison.
- Leaving empty bins unhandled, which gives an infinite or undefined PSI; floor the proportions.
- Using a baseline with no seasonal cycle, so that the normal swing between summer and winter looks like drift.

```python
def bin_counts(values, edges):
    """Count values per bin; an edge value belongs to the bin on its right."""
    counts = [0] * (len(edges) + 1)
    for v in values:
        i = 0
        while i < len(edges) and v >= edges[i]:
            i += 1
        counts[i] += 1
    return counts
```
hint: For each value, move right past every edge that is less than or equal to it, and add one to the count at the position where you stop.
solution: The loop advances past each edge that the value reaches, so the stopping index is the number of edges at or below the value, which is exactly its bin; a value equal to an edge goes to the bin on the right (second and first tests). With no edges the loop does not run and everything lands in bin 0.

```python
def ks_statistic(a, b):
    """Two-sample Kolmogorov-Smirnov statistic."""
    best = 0.0
    for x in set(a) | set(b):
        fa = sum(1 for v in a if v <= x) / len(a)
        fb = sum(1 for v in b if v <= x) / len(b)
        best = max(best, abs(fa - fb))
    return best
```
hint: At each value that occurs in either sample, compute the fraction of each sample at or below it, and keep the largest gap.
solution: Both empirical CDFs are step functions that change only at sample values, so their largest gap occurs at one of those values. Dividing by each sample's own length handles unequal sizes, which the last test uses (the gap is 0.75 at the value 2).

model:
```python
import math

def psi_samples(baseline, current, edges, eps):
    """PSI between two samples using bins defined by the given edges."""
    def proportions(values):
        counts = [0] * (len(edges) + 1)
        for v in values:
            i = 0
            while i < len(edges) and v >= edges[i]:
                i += 1
            counts[i] += 1
        return [max(c / len(values), eps) for c in counts]

    e = proportions(baseline)
    a = proportions(current)
    total = 0.0
    for ei, ai in zip(e, a):
        total += (ai - ei) * math.log(ai / ei)
    return total
```
hint: Write a helper that turns a sample into floored proportions, apply it to both samples, and add up the terms.
solution: Using the baseline edges for both samples makes the bins identical, so proportions are comparable. Flooring at `eps` keeps the logarithm finite for empty bins (the third test), identical samples give zero, and swapping the samples leaves the value unchanged because each term is symmetric.

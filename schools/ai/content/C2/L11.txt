@article
A **simple graph** $G = (V, E)$ consists of a finite set $V$ of **vertices** and a set $E$ of **edges**, each edge an unordered pair $\{u, v\}$ of distinct vertices (no loops and no repeated edges). Graphs model networks, maps, dependencies and relationships. Two vertices joined by an edge are **adjacent** (neighbors). The **degree** $\deg(v)$ is the number of edges at $v$.

### Families of graphs

The **complete graph** $K_n$ has all $\binom{n}{2}$ possible edges. The **cycle** $C_n$ ($n \ge 3$) has $n$ vertices in a ring and $n$ edges, and the **path** $P_n$ has $n$ vertices in a line and $n - 1$ edges. A graph is **bipartite** if its vertices can be split into two sets with every edge between the sets.

### The handshake lemma

Each edge has two ends, so summing the degrees counts every edge twice:

$$\sum_{v \in V} \deg(v) = 2|E|.$$

Consequently the sum of the degrees is even, and the **number of vertices of odd degree is even**. (If an odd number of vertices had odd degree, the total would be odd.) So no graph has degree sequence $3, 3, 3, 2$ (the sum is $11$), and nine computers cannot each be wired to exactly three others.

### Walks, paths and connectivity

A **walk** is a sequence of vertices in which consecutive ones are adjacent; its **length** is the number of edges. A **path** is a walk with no repeated vertex. A **cycle** is a closed walk of length at least $3$ with no repeated vertex except that the first equals the last. If some walk joins $u$ and $v$, then some path does (a shortest walk from $u$ to $v$ repeats no vertex, since otherwise the closed part between the two visits could be cut out to give a shorter walk, so it is a path).

A graph is **connected** if every pair of vertices is joined by a path. Otherwise it splits into **connected components**: maximal connected subgraphs. The relation "is joined by a path to" is an equivalence relation (Week 6), and its classes are the vertex sets of the components. The **distance** $d(u, v)$ is the length of a shortest path.

**Breadth-first search (BFS)** finds distances from a start vertex by exploring neighbors layer by layer with a queue. On a graph stored as an adjacency list it runs in $O(|V| + |E|)$ time.

```python
from collections import deque

def distances(adj, start):
    dist = {start: 0}
    queue = deque([start])
    while queue:
        u = queue.popleft()
        for v in adj[u]:
            if v not in dist:
                dist[v] = dist[u] + 1
                queue.append(v)
    return dist
```

Here `adj` is a dictionary mapping each vertex to the list of its neighbors. The vertices reached form the component of `start`.

### Euler tours

An **Euler trail** is a walk that uses every edge exactly once. An **Euler circuit** is an Euler trail that starts and ends at the same vertex. The Königsberg bridge problem asks for such a walk in a graph (strictly a multigraph, since some pairs of land masses are joined by two bridges) with four vertices of odd degree.

**Theorem (Euler).** Let $G$ be a graph in which all vertices of nonzero degree lie in one connected component. Then:

- $G$ has an Euler circuit if and only if every vertex has even degree.
- $G$ has an Euler trail that is not a circuit if and only if exactly two vertices have odd degree; the trail starts at one of them and ends at the other.

*Why the conditions are necessary.* Each time a circuit passes through a vertex it uses one edge to enter and another to leave, so edges at a vertex are used in pairs, and the degree must be even (for the start vertex, the first departure pairs with the final return). In a trail the start and end vertices each have one unpaired edge. *Sufficiency* is proved by building a closed trail until it is stuck, which can only happen at its start vertex because of even degrees, and splicing in closed trails through unused edges; the connectivity of the graph guarantees nothing is missed. By contrast, deciding whether a graph has a **Hamiltonian** cycle (visiting every vertex once) has no known simple criterion.

@example
title: Using the handshake lemma
problem: A network has 9 computers and every computer must connect to exactly 3 others. Is this possible?
step: If it were possible, the degrees would be nine $3$'s, with sum $27$.
step: The handshake lemma says the degree sum is $2|E|$, which is even.
step: $27$ is odd, so no such simple graph exists.
step: Equivalently, there would be nine (an odd number of) vertices of odd degree, which the lemma forbids.
answer: It is impossible, because the degree sum would be odd.

@example
title: Finding an Euler trail
problem: A "house" graph has vertices $1, \dots, 5$ and edges $12, 23, 34, 41, 15, 25$. Does it have an Euler circuit or an Euler trail?
step: Degrees: $\deg 1 = 3$ (neighbors $2, 4, 5$), $\deg 2 = 3$ (neighbors $1, 3, 5$), $\deg 3 = 2$, $\deg 4 = 2$, $\deg 5 = 2$.
step: The graph is connected, and exactly two vertices (1 and 2) have odd degree. So there is no Euler circuit, but there is an Euler trail from $1$ to $2$ (or from $2$ to $1$).
step: Construct one: $1 \to 4 \to 3 \to 2 \to 5 \to 1 \to 2$.
step: Check it uses each of the six edges once: $14, 43, 32, 25, 51, 12$.
answer: No Euler circuit; an Euler trail is $1, 4, 3, 2, 5, 1, 2$.

@mistakes
- Forgetting that an Euler tour requires the edges to be in one connected piece, not just even degrees (two disjoint triangles have all degrees even but no circuit).
- Confusing an Euler trail (every edge once) with a Hamiltonian path (every vertex once).
- Counting the edges of a graph as the sum of the degrees; the sum is twice the number of edges.
- Calling a walk a path: a path may not repeat vertices.

```python
def count_components(adj):
    seen = set()
    count = 0
    for start in adj:
        if start in seen:
            continue
        count += 1
        stack = [start]
        seen.add(start)
        while stack:
            u = stack.pop()
            for v in adj[u]:
                if v not in seen:
                    seen.add(v)
                    stack.append(v)
    return count
```

def has_euler_circuit(adj):
    if any(len(nbrs) % 2 == 1 for nbrs in adj.values()):
        return False
    active = [v for v in adj if adj[v]]
    seen = {active[0]}
    stack = [active[0]]
    while stack:
        u = stack.pop()
        for v in adj[u]:
            if v not in seen:
                seen.add(v)
                stack.append(v)
    return all(v in seen for v in active)

```python
from collections import deque


def shortest_path_length(adj, s, t):
    dist = {s: 0}
    queue = deque([s])
    while queue:
        u = queue.popleft()
        if u == t:
            return dist[u]
        for v in adj[u]:
            if v not in dist:
                dist[v] = dist[u] + 1
                queue.append(v)
    return -1
```
hint: Breadth-first search visits vertices in order of increasing distance from `s`.
hint: Record each vertex's distance when you first discover it, and return the distance of `t` when you reach it.
solution: BFS explores layer by layer, so the first time `t` is dequeued its recorded distance is the shortest. If the queue empties without reaching `t`, there is no path and the answer is `-1`.

@quiz self
prompt: Prove that in any simple graph the number of vertices of odd degree is even.
solution: Let $O$ and $E'$ be the sets of vertices of odd and even degree. Summing degrees counts each edge twice, so $\sum_{v} \deg(v) = 2|E|$ is even. Split the sum: $\sum_{v \in O} \deg(v) + \sum_{v \in E'} \deg(v) = 2|E|$. The second sum is a sum of even numbers, hence even. So $\sum_{v \in O} \deg(v)$ is even. It is a sum of $|O|$ odd numbers, and such a sum has the same parity as $|O|$. Therefore $|O|$ is even.
rubric: States the handshake lemma (degree sum equals $2|E|$) with the reason: each edge contributes to two degrees.
rubric: Splits the sum into odd-degree and even-degree vertices and notes the even-degree part is even.
rubric: Concludes that a sum of $|O|$ odd numbers is even only if $|O|$ is even.
hint: Use the handshake lemma and look at the parity of the part of the sum coming from odd-degree vertices.

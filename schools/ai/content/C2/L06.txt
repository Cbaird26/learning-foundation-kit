@article
A **binary relation on a set** $A$ is a subset $R \subseteq A \times A$. We write $a \mathrel{R} b$ when $(a, b) \in R$. Four properties classify the relations that matter in computer science. For all elements of $A$:

- **Reflexive**: $a \mathrel{R} a$.
- **Symmetric**: $a \mathrel{R} b$ implies $b \mathrel{R} a$.
- **Antisymmetric**: $a \mathrel{R} b$ and $b \mathrel{R} a$ together imply $a = b$.
- **Transitive**: $a \mathrel{R} b$ and $b \mathrel{R} c$ together imply $a \mathrel{R} c$.

Antisymmetric is not the opposite of symmetric: equality is both, and a relation can be neither.

### Equivalence relations

An **equivalence relation** is reflexive, symmetric and transitive. It captures "sameness with respect to some property": having the same remainder, the same length, the same file hash. Congruence is the key example: for a positive integer $n$, $a \equiv b \pmod n$ means $n \mid (a - b)$. It is reflexive ($n \mid 0$), symmetric (if $n \mid a - b$ then $n \mid b - a$) and transitive (if $n \mid a - b$ and $n \mid b - c$ then $n$ divides the sum $a - c$).

The **equivalence class** of $a$ is $[a] = \{b \in A : a \mathrel{R} b\}$. The central theorem: for an equivalence relation, any two classes are either equal or disjoint, and every element lies in some class. So the classes form a **partition** of $A$: pairwise disjoint non-empty sets whose union is $A$. Conversely, every partition defines an equivalence relation ("lie in the same block"). Equivalence relations on $A$ and partitions of $A$ are two descriptions of the same thing. For congruence mod $n$ there are exactly $n$ classes, indexed by the remainders $0, 1, \dots, n - 1$.

The number of partitions of an $n$-element set is the **Bell number** $B_n$: $B_1 = 1$, $B_2 = 2$, $B_3 = 5$, $B_4 = 15$.

### Partial orders

A **partial order** is a relation that is reflexive, antisymmetric and transitive; a set with a partial order is a **poset** $(A, \preceq)$. Examples: $\le$ on the integers, $\subseteq$ on sets, and divisibility $\mid$ on the positive integers. Two elements $a, b$ are **comparable** if $a \preceq b$ or $b \preceq a$. In a **total order** every pair is comparable; $\le$ is total but $\subseteq$ and $\mid$ are not ($\{1\}$ and $\{2\}$ are incomparable, and neither of $2$, $3$ divides the other).

A **Hasse diagram** draws the poset economically: a point for each element, an upward line from $a$ to $b$ when $a \prec b$ and nothing lies strictly between them, with reflexivity and transitivity left implicit.

- $m$ is **maximal** if no element is strictly above it; **minimal** if none is strictly below. A poset can have several maximal elements. $m$ is the **maximum** (greatest element) if every element is $\preceq m$; then it is the only maximal element.
- A **chain** is a set of pairwise comparable elements; an **antichain** is a set of pairwise incomparable ones.
- A **topological sort** (linear extension) lists all elements in a total order that respects $\preceq$. Every finite poset has one: this is how a build system orders tasks that depend on each other.

### Checking properties by hand

To refute a property, give a concrete counterexample. To prove one, argue for arbitrary elements. For $a \mathrel{R} b \iff |a - b| \le 1$ on the integers: it is reflexive and symmetric but not transitive, since $1 \mathrel{R} 2$ and $2 \mathrel{R} 3$ but $|1 - 3| = 2$.

@example
title: An equivalence relation and its classes
problem: On $\mathbb{Z}$, define $a \sim b$ iff $a \equiv b \pmod 3$. Show $\sim$ is an equivalence relation and describe its classes.
step: Reflexive: $3 \mid a - a = 0$. Symmetric: if $a - b = 3k$ then $b - a = 3(-k)$.
step: Transitive: if $a - b = 3k$ and $b - c = 3m$, then $a - c = 3(k + m)$, so $a \sim c$.
step: The class of $a$ consists of all integers with the same remainder as $a$ on division by $3$.
step: So there are exactly $3$ classes: $[0] = \{\dots, -3, 0, 3, 6, \dots\}$, $[1] = \{\dots, -2, 1, 4, 7, \dots\}$ and $[2] = \{\dots, -1, 2, 5, 8, \dots\}$. They partition $\mathbb{Z}$.
answer: $\sim$ is an equivalence relation with 3 classes, one for each remainder.

@example
title: A poset under divisibility
problem: Consider the divisibility order on $\{1, 2, 3, 4, 6, 12\}$. Find the minimal and maximal elements, a longest chain and a largest antichain.
step: It is a partial order: $a \mid a$; if $a \mid b$ and $b \mid a$ with $a, b > 0$ then $a = b$; and divisibility is transitive.
step: The Hasse edges (covers) are $1$–$2$, $1$–$3$, $2$–$4$, $2$–$6$, $3$–$6$, $4$–$12$ and $6$–$12$.
step: $1$ divides everything, so it is the only minimal element (the minimum); $12$ is divisible by everything, so it is the maximum.
step: A longest chain is $1 \mid 2 \mid 4 \mid 12$ with $4$ elements (also $1 \mid 2 \mid 6 \mid 12$).
step: $\{4, 6\}$ is an antichain since neither divides the other. No three elements are pairwise incomparable: the set splits into the two chains $\{1, 2, 4, 12\}$ and $\{3, 6\}$, and an antichain contains at most one element of each chain. So $2$ is the largest antichain size.
answer: Minimum $1$, maximum $12$, longest chain of length $4$, largest antichain of size $2$.

@mistakes
- Thinking antisymmetric means "not symmetric". Equality is both symmetric and antisymmetric.
- Checking transitivity on a single example instead of looking for a counterexample or giving a general argument.
- Calling an element the maximum when it is only maximal; a poset may have several maximal elements and no maximum.
- Forgetting reflexivity when listing the pairs of an equivalence relation: $(a, a)$ must be present for every $a$.

model:
```python
def is_equivalence(elements, pairs):
    reflexive = all((x, x) in pairs for x in elements)
    symmetric = all((b, a) in pairs for (a, b) in pairs)
    transitive = all((a, d) in pairs
                     for (a, b) in pairs
                     for (c, d) in pairs
                     if b == c)
    return reflexive and symmetric and transitive
```

model:
```python
def equivalence_classes(elements, related):
    classes = []
    for x in sorted(elements):
        for cls in classes:
            if related(cls[0], x):
                cls.append(x)
                break
        else:
            classes.append([x])
    return classes
```
hint: Process the elements in sorted order; each element either joins an existing class or starts a new one.
hint: Compare `x` with one representative of each class, for example `cls[0]`, using `related`.
solution: Because the relation is an equivalence relation, comparing with one representative of a class decides membership. Processing in sorted order creates classes in order of their smallest element and keeps each class sorted.

@quiz self
prompt: Let $\sim$ be an equivalence relation on a set $A$. Prove that for any $a, b \in A$ the classes $[a]$ and $[b]$ are either equal or disjoint.
solution: Suppose $[a] \cap [b] \neq \varnothing$ and pick $c$ in both. Then $a \sim c$ and $b \sim c$. By symmetry $c \sim b$, and by transitivity $a \sim b$. Now let $x \in [b]$, so $b \sim x$. By transitivity from $a \sim b$ and $b \sim x$ we get $a \sim x$, so $x \in [a]$. Hence $[b] \subseteq [a]$. Symmetrically, $b \sim a$ gives $[a] \subseteq [b]$. Therefore $[a] = [b]$. So the classes are either disjoint or equal.
rubric: Assumes the classes share an element $c$ and derives $a \sim b$ using symmetry and transitivity.
rubric: Shows one inclusion with an arbitrary element, using transitivity.
rubric: Gets the reverse inclusion by symmetry of the argument and concludes the classes are equal.
hint: If the classes are not disjoint, pick a shared element and use it to link $a$ and $b$.

@article
**Combinatorics** counts the objects in a finite set without listing them. Counting underlies the analysis of algorithms (how many inputs of size $n$ are there?), probability, and cryptography (how large is a key space?).

### The basic rules

- **Sum rule.** If a task can be done in one of $m$ ways **or** one of $n$ ways, and no way is in both lists, there are $m + n$ ways. For overlapping lists, see the next lesson.
- **Product rule.** If a procedure has two stages, with $m$ outcomes in the first and, for each of them, $n$ in the second, there are $m \cdot n$ outcomes. It extends to any number of stages. The number of choices at later stages may depend on earlier choices, as long as it is the same count for each.
- **Complement rule.** The number of objects with a property is the total minus the number without it. "At least one" problems are often easiest this way.
- **Division rule.** If each object is counted exactly $d$ times in some count, divide that count by $d$.

A bit string of length $n$ has $2^n$ possibilities (product rule, $2$ choices for each position). A set with $n$ elements has $2^n$ subsets, as you saw in Week 5.

### Permutations

An ordered arrangement of $k$ distinct items chosen from $n$ distinct items (no repetition) is a **$k$-permutation**. The first position has $n$ choices, the second $n - 1$, and so on:

$$P(n, k) = n(n-1)\cdots(n-k+1) = \frac{n!}{(n-k)!}.$$

Arranging all $n$ items gives $P(n, n) = n!$, with $0! = 1$.

### Combinations

An unordered selection of $k$ items from $n$ is a **$k$-combination** (a $k$-element subset). Each such subset can be ordered in $k!$ ways, so by the division rule

$$\binom{n}{k} = \frac{P(n, k)}{k!} = \frac{n!}{k!\,(n-k)!}.$$

Useful facts: $\binom{n}{k} = \binom{n}{n-k}$ (choosing the $k$ to take is the same as choosing the $n - k$ to leave), $\binom{n}{0} = \binom{n}{n} = 1$, and **Pascal's identity** $\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$ (a subset either contains a particular element or does not). The **binomial theorem** states $(x + y)^n = \sum_{k=0}^{n} \binom{n}{k} x^{n-k} y^k$, which also gives $\sum_k \binom{n}{k} = 2^n$.

The question to ask first is: **does order matter?** Choosing a president and a treasurer from nine people is a permutation ($9 \cdot 8$); choosing a two-person committee is a combination ($\binom{9}{2}$).

### Arrangements with repeated objects

If $n$ objects include $n_1$ of one kind, $n_2$ of another and so on (with $n_1 + n_2 + \cdots + n_r = n$), the number of distinct arrangements is the **multinomial coefficient**

$$\frac{n!}{n_1!\,n_2!\cdots n_r!}.$$

Think of $n!$ orderings of labeled objects, and divide out the $n_i!$ ways of shuffling the identical ones.

### Stars and bars

The number of ways to distribute $n$ identical objects into $k$ distinguishable boxes (equivalently, the number of non-negative integer solutions of $x_1 + \cdots + x_k = n$) is

$$\binom{n + k - 1}{k - 1}.$$

Picture $n$ stars in a row separated by $k - 1$ bars; choosing which $k - 1$ of the $n + k - 1$ positions hold bars determines the solution.

### Summary table

| Choose $k$ from $n$ | order matters | order does not matter |
|---|---|---|
| no repetition | $\dfrac{n!}{(n-k)!}$ | $\dbinom{n}{k}$ |
| repetition allowed | $n^k$ | $\dbinom{n + k - 1}{k}$ |

@example
title: An "at least one" count by complement
problem: How many 8-character passwords made from the 26 lowercase letters and the 10 digits contain at least one digit?
step: Total passwords: each of the $8$ positions has $36$ choices, so there are $36^8$.
step: Passwords with no digit use only letters: $26^8$.
step: By the complement rule, the number with at least one digit is $36^8 - 26^8$.
step: Compute: $36^8 = 2\,821\,109\,907\,456$ and $26^8 = 208\,827\,064\,576$, so the answer is $2\,612\,282\,842\,880$.
answer: $36^8 - 26^8 = 2\,612\,282\,842\,880$.

@example
title: Arrangements with repeated letters
problem: How many distinct strings can be made by rearranging all the letters of MISSISSIPPI?
step: There are $11$ letters: M once, I four times, S four times, P twice.
step: If all letters were different there would be $11!$ arrangements. Swapping identical letters does not change the string, so divide by $4!$ for the I's, $4!$ for the S's and $2!$ for the P's.
step: The count is $\dfrac{11!}{1!\,4!\,4!\,2!} = \dfrac{39\,916\,800}{1152} = 34\,650$.
answer: $34\,650$

@mistakes
- Using a combination when order matters (a president and a treasurer), or a permutation when it does not (a committee).
- Adding when the stages are independent: choices in successive stages multiply, while alternatives add.
- Double counting in "at least" problems; use the complement, or count disjoint cases.
- Forgetting to divide by the factorials of repeated items when counting arrangements of a word.

model:
```python
def choose(n, k):
    if k > n:
        return 0
    result = 1
    for i in range(1, k + 1):
        result = result * (n - k + i) // i
    return result
```
hint: Handle `k > n` first. Then build the answer one factor at a time.
hint: After step `i`, `result` equals $\binom{n-k+i}{i}$, so `result * (n - k + i) // i` is always an exact integer division.
solution: Starting from `1`, multiply by `n - k + i` and divide by `i` for `i = 1, ..., k`. After each step the value is the binomial coefficient $\binom{n-k+i}{i}$, an integer, so floor division is exact. For `k > n` the answer is `0` by definition.

@practice mc
prompt: A student counts the ways to choose a president and a treasurer (different people) from a club of 9 people as $\binom{9}{2} = 36$. What is wrong, and what is the correct count?
choice: Nothing is wrong; $36$ is correct.
choice*: Order matters because the two roles differ, so the count is $9 \cdot 8 = 72$.
choice: Repetition should be allowed, so the count is $9^2 = 81$.
choice: The count should be $9 + 8 = 17$, because choosing a president and choosing a treasurer are two alternatives.
hint: Is "Ana president, Ben treasurer" the same outcome as "Ben president, Ana treasurer"?
solution: Assigning roles makes the selection ordered: $9$ choices for president and then $8$ for treasurer, so $72$. The combination $\binom{9}{2}$ counts unordered pairs, so it counts each pair once instead of twice. Adding $9 + 8 = 17$ treats the two roles as alternatives, but they are successive stages, so the counts multiply.

@quiz num
prompt: A committee of 4 is chosen from 6 men and 5 women. How many committees contain at least one woman?
answer: 315
check: comb(11, 4) - comb(6, 4)
hint: Count all committees and subtract those with no woman.
solution: There are $\binom{11}{4} = 330$ committees in all and $\binom{6}{4} = 15$ with only men, so $330 - 15 = 315$.

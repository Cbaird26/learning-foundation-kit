@article
A **set** is an unordered collection of distinct objects, its **elements**. We write $x \in A$ for membership, $\{1, 2, 3\}$ for a set listed explicitly and $\{x \in \mathbb{Z} : x > 0\}$ for set-builder notation. Order and repetition do not matter: $\{1, 2, 2, 3\} = \{3, 1, 2\}$. The **empty set** is $\varnothing$, and $|A|$ is the number of elements of a finite set $A$.

### Set operations

- $A \subseteq B$ ($A$ is a **subset** of $B$): every element of $A$ is in $B$. Two sets are equal exactly when each is a subset of the other.
- $A \cup B$ (union), $A \cap B$ (intersection), $A \setminus B$ (difference: elements of $A$ not in $B$), $\overline{A}$ (complement within a universe $U$), $A \triangle B$ (symmetric difference: in exactly one of the two).
- The **power set** $\mathcal{P}(A)$ is the set of all subsets of $A$. A subset is chosen by deciding, for each of the $|A|$ elements, in or out, so $|\mathcal{P}(A)| = 2^{|A|}$.
- The **Cartesian product** $A \times B$ is the set of ordered pairs $(a, b)$ with $a \in A$, $b \in B$, and $|A \times B| = |A| \cdot |B|$.

De Morgan's laws hold for sets: $\overline{A \cup B} = \overline{A} \cap \overline{B}$ and $\overline{A \cap B} = \overline{A} \cup \overline{B}$. They are the set versions of the logical laws of Week 1, because $x \in A \cap B$ means $(x \in A) \land (x \in B)$. Python's built-in `set` has the operators `|`, `&`, `-` and `^` for union, intersection, difference and symmetric difference.

### Functions

A **function** $f : A \to B$ assigns to **each** element $a$ of the **domain** $A$ exactly one element $f(a)$ of the **codomain** $B$. The **image** (or range) is $f(A) = \{f(a) : a \in A\} \subseteq B$. The codomain is part of the definition: $x \mapsto x^2$ from $\mathbb{R}$ to $\mathbb{R}$ and from $\mathbb{R}$ to $[0, \infty)$ are different functions.

- $f$ is **injective** (one-to-one) if $f(a_1) = f(a_2)$ implies $a_1 = a_2$. Distinct inputs give distinct outputs.
- $f$ is **surjective** (onto) if every $b \in B$ equals $f(a)$ for some $a \in A$. The image is the whole codomain.
- $f$ is **bijective** if it is both. A bijection pairs the elements of $A$ and $B$ one to one, so two finite sets with a bijection between them have the same size.

To show **injectivity**, assume $f(a_1) = f(a_2)$ and derive $a_1 = a_2$; to refute it, give two different inputs with the same output. To show **surjectivity**, take an arbitrary $b$ and find an $a$ with $f(a) = b$; to refute it, name a $b$ that is never hit.

### Composition and inverses

The composition $g \circ f$ is defined by $(g \circ f)(a) = g(f(a))$ when the codomain of $f$ is the domain of $g$. Compositions of injective functions are injective, and compositions of surjective functions are surjective. A function has an **inverse** $f^{-1} : B \to A$ with $f^{-1}(f(a)) = a$ and $f(f^{-1}(b)) = b$ exactly when it is bijective.

### Counting functions

For finite sets with $|A| = m$ and $|B| = n$: there are $n^m$ functions from $A$ to $B$ (each of the $m$ inputs has $n$ choices), and if $m \le n$ there are $n(n-1)\cdots(n-m+1)$ injective ones. An injective function from $A$ to $B$ forces $m \le n$, and a surjective one forces $m \ge n$.

### Relations

A **relation** from $A$ to $B$ is any subset $R \subseteq A \times B$, and we write $a \mathrel{R} b$ for $(a, b) \in R$. A function is the special relation in which each $a \in A$ appears in exactly one pair. The next lesson studies relations on a single set.

@example
title: Classifying a function
problem: Classify $f : \mathbb{Z} \to \mathbb{Z}$ defined by $f(n) = 2n + 1$ as injective, surjective, both or neither.
step: Injective test: assume $f(a_1) = f(a_2)$, so $2a_1 + 1 = 2a_2 + 1$. Subtract $1$ and divide by $2$ to get $a_1 = a_2$. So $f$ is injective.
step: Surjective test: is every integer $b$ equal to $2n + 1$ for some integer $n$? Every value $2n + 1$ is odd, so $b = 2$ is never reached.
step: The function is injective but not surjective, so it is not bijective. The image is the set of odd integers.
answer: Injective, not surjective.

@example
title: Counting subsets and checking an identity
problem: For $A = \{1, 2, 3\}$ and $B = \{2, 3, 4, 5\}$, find $|A \cup B|$ and $|\mathcal{P}(A \cap B)|$.
step: The union is $\{1, 2, 3, 4, 5\}$, so $|A \cup B| = 5$.
step: Check with counting: $|A| + |B| - |A \cap B| = 3 + 4 - 2 = 5$, since $A \cap B = \{2, 3\}$ has $2$ elements.
step: The power set of a $2$-element set has $2^2 = 4$ elements: $\varnothing, \{2\}, \{3\}, \{2, 3\}$.
answer: $|A \cup B| = 5$ and $|\mathcal{P}(A \cap B)| = 4$.

@mistakes
- Forgetting that the codomain is part of a function, so asking "is $x^2$ surjective?" without saying onto what.
- Confusing injective with surjective, or "one-to-one" with "bijective".
- Counting the empty set and the set itself out of the power set: $\mathcal{P}(A)$ always includes both $\varnothing$ and $A$.
- Treating a set as ordered or as having repeated elements.

tests:
```python
assert classify(lambda x: x + 1, [0, 1, 2], [1, 2, 3]) == "bijective"
assert classify(lambda x: x // 2, list(range(6)), [0, 1, 2]) == "surjective"
assert classify(lambda x: x, [0, 1], [0, 1, 2]) == "injective"
```

model:
```python
def classify(f, domain, codomain):
    values = [f(x) for x in domain]
    injective = len(set(values)) == len(values)
    surjective = set(values) == set(codomain)
    if injective and surjective:
        return "bijective"
    if injective:
        return "injective"
    if surjective:
        return "surjective"
    return "neither"
```
hint: Injective means no repeated outputs; surjective means the set of outputs equals the whole codomain.
hint: Compute both properties as booleans first, then choose the string.
solution: Compute the outputs once. The function is injective when the outputs are all distinct and surjective when the set of outputs equals `set(codomain)`. Then return the matching word. For the empty domain and codomain both properties hold vacuously, so it is bijective.

@quiz self
prompt: Prove that if $f : A \to B$ and $g : B \to C$ are both injective, then $g \circ f$ is injective.
solution: Assume $(g \circ f)(a_1) = (g \circ f)(a_2)$ for some $a_1, a_2 \in A$. This says $g(f(a_1)) = g(f(a_2))$. Since $g$ is injective, $f(a_1) = f(a_2)$. Since $f$ is injective, $a_1 = a_2$. Hence $g \circ f$ is injective.
rubric: Starts from the definition of injectivity: assumes $(g \circ f)(a_1) = (g \circ f)(a_2)$ and aims for $a_1 = a_2$.
rubric: Applies the injectivity of $g$ first, to the equation $g(f(a_1)) = g(f(a_2))$.
rubric: Applies the injectivity of $f$ second and states the conclusion.
hint: Start by assuming two inputs have equal images under the composition, then peel off $g$ and $f$ in turn.

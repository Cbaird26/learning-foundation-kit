material: Starting code for option A. The data are $x \sim \text{Uniform}[0,1]$ and labels $y = \mathbb{1}[x \ge 0.4]$ flipped with probability $0.1$. The class is $\mathcal{H} = \{\mathbb{1}[x \ge j/100] : j = 0, \dots, 100\}$, so $\lvert\mathcal{H}\rvert = 101$ and the target threshold is in the class. The true risk of the threshold $t$ is exactly $0.1 + 0.8\lvert t - 0.4\rvert$, so the excess risk of the ERM output is $0.8\lvert t - 0.4\rvert$.
```python
import math
import random

def erm_thresholds(m, rng, K=100, theta=0.4, noise=0.1):
    """ERM over thresholds t = j / K; returns the excess true risk."""
    xs = [rng.random() for _ in range(m)]
    ys = [(x >= theta) != (rng.random() < noise) for x in xs]
    best_t, best_err = 0.0, m + 1
    for j in range(K + 1):
        t = j / K
        err = sum((x >= t) != y for x, y in zip(xs, ys))
        if err < best_err:
            best_t, best_err = t, err
    return (1 - 2 * noise) * abs(best_t - theta)

rng = random.Random(0)
for m in (50, 200, 800):
    vals = sorted(erm_thresholds(m, rng) for _ in range(200))
    q95 = vals[int(0.95 * len(vals)) - 1]
    bound = math.sqrt(2 * math.log(2 * 101 / 0.05) / m)
    print(m, round(sum(vals) / len(vals), 4), round(q95, 4), round(bound, 4))
```
material: Starting code for option B. For a fixed sample, $R_S$ of the $\ell_2$ ball equals $\frac{B}{m}\mathbb{E}\lVert\sum_i\sigma_i\mathbf{x}_i\rVert_2$, which the code estimates by sampling sign vectors.
```python
import math
import random

def rademacher_ball(points, B, trials, rng):
    """Monte Carlo estimate of R_S for the l2 ball of radius B."""
    m, d = len(points), len(points[0])
    total = 0.0
    for _ in range(trials):
        s = [0.0] * d
        for x in points:
            sign = rng.choice((-1, 1))
            for k in range(d):
                s[k] += sign * x[k]
        total += B * math.sqrt(sum(v * v for v in s))
    return total / trials / m

rng = random.Random(1)
pts = [[rng.gauss(0, 1) for _ in range(5)] for _ in range(100)]
rho = max(math.sqrt(sum(v * v for v in x)) for x in pts)
print(rademacher_ball(pts, 1.0, 500, rng), rho / math.sqrt(len(pts)))
```
material: Starting code for option C. Expert 0 has a slightly lower loss probability than the others, so the regret is measured against it (in hindsight, against the best expert on the realized losses).
```python
import math
import random

def hedge_regret(T, N, rng):
    eta = math.sqrt(8 * math.log(N) / T)
    cum = [0.0] * N
    total = 0.0
    for _ in range(T):
        w = [math.exp(-eta * c) for c in cum]
        z = sum(w)
        loss = [1.0 if rng.random() < 0.5 - (0.1 if i == 0 else 0.0) else 0.0
                for i in range(N)]
        total += sum(wi / z * li for wi, li in zip(w, loss))
        cum = [c + l for c, l in zip(cum, loss)]
    return total - min(cum)

rng = random.Random(2)
for T in (100, 400, 1600):
    print(T, round(hedge_regret(T, 10, rng), 2),
          round(math.sqrt(T / 2 * math.log(10)), 2))
```

## Week by week

**1. The learning problem and ERM.** True risk $L_{\mathcal{D}}$, empirical risk $L_S$, ERM, approximation and estimation error. Hoeffding: $P[|L_S(h) - L_{\mathcal{D}}(h)| > \epsilon] \le 2e^{-2m\epsilon^2}$. Lemma 1: an ERM output over an $\epsilon/2$-representative sample is $\epsilon$-optimal.

**2. PAC learning, finite classes.** Realizable: $m \ge \ln(|\mathcal{H}|/\delta)/\epsilon$. Agnostic: $m \ge 2\ln(2|\mathcal{H}|/\delta)/\epsilon^2$. Quantifier order: $\epsilon, \delta$ first, then every distribution.

**3. VC dimension.** Shattering, $\operatorname{VCdim}$, growth function $\Pi_{\mathcal{H}}(m)$. Two-step proofs: one shattered set, and no shattered larger set. Thresholds $1$, intervals $2$, rectangles $4$, affine halfspaces $d + 1$ (Radon).

**4. Sauer and the fundamental theorem.** $\Pi_{\mathcal{H}}(m) \le \sum_{i \le d}\binom{m}{i} \le (em/d)^d$. Finite VC dimension is equivalent to PAC and agnostic learnability, uniform convergence and success of ERM. Rates $(d + \ln(1/\delta))/\epsilon^2$ and $(d + \ln(1/\delta))/\epsilon$ up to constants and logarithms.

**5. Rademacher complexity.** $\mathbb{E}f \le \hat{\mathbb{E}}_Sf + 2R_m + \sqrt{\ln(1/\delta)/(2m)}$ (McDiarmid and symmetrization). Massart: $R(A) \le r\sqrt{2\ln|A|}/m$. Linear classes: $B\rho/\sqrt{m}$.

**6. Bias-complexity and no free lunch.** For $m < |\mathcal{X}|/2$ every algorithm fails with probability $\ge 1/7$ to get error below $1/8$ on some realizable distribution. Infinite VC dimension implies not PAC learnable. Structural risk minimization.

**7. Stability.** $\beta$-uniform stability implies expected gap $\le \beta$; RLM with a convex $\rho$-Lipschitz loss has $\beta = 2\rho^2/(\lambda m)$.

**8. Margins.** Geometric margin, hard-margin SVM, perceptron bound $(R/\gamma)^2$, margin bound with ramp loss and contraction: complexity term $2B\rho/(\gamma\sqrt{m})$.

**9. Boosting.** AdaBoost: $\alpha_t = \frac{1}{2}\ln\frac{1 - \epsilon_t}{\epsilon_t}$, training error $\le \prod_t 2\sqrt{\epsilon_t(1 - \epsilon_t)} \le e^{-2\sum\gamma_t^2}$; margin explanation and its limits.

**10. Online learning.** Regret; Hedge: $\ln N/\eta + \eta T/8$, tuned $\sqrt{(T/2)\ln N}$; Hoeffding's lemma; online-to-batch.

**11 and 12. Deep learning and reading papers.** Random labels, double descent, minimum-norm interpolation, benign overfitting, implicit bias: what is proved and what is open. Checklist: setting, quantifiers, constants, tightness, proof technique.

## Common errors

Applying a bound for a fixed hypothesis to a learned one; swapping the quantifiers; quoting a bound without its constants; proving only one half of a VC dimension claim; mixing Rademacher conventions; treating a vacuous bound as evidence against a method; stating open problems of deep learning as settled.

@exam self
prompt: Let $\mathcal{H} = \{h_1, \dots, h_N\}$ be a finite class and $\ell(h, z) \in [0,1]$ a loss. Examples $z_1, \dots, z_T$ are i.i.d. from $\mathcal{D}$. Run Hedge over the hypotheses with $\eta = \sqrt{8\ln N/T}$ and losses $\ell_t(i) = \ell(h_i, z_t)$, so that $\mathbf{p}_t$ depends only on $z_1, \dots, z_{t-1}$. Let $\bar{\mathbf{p}} = \frac{1}{T}\sum_t\mathbf{p}_t$ and let $I \sim \bar{\mathbf{p}}$ be drawn independently of the data. Prove that $\mathbb{E}\,L_{\mathcal{D}}(h_I) \le \min_i L_{\mathcal{D}}(h_i) + \sqrt{\ln N/(2T)}$, using the Hedge regret bound $\sqrt{(T/2)\ln N}$. Then say in two sentences how this compares with ERM and Theorem 2 of week 2.
hint: The risk of the randomized predictor is linear in $\bar{\mathbf{p}}$. Use independence of $z_t$ from $\mathbf{p}_t$ to turn risks into the losses on the next example, then the regret bound for the realized sequence, then $\mathbb{E}\min \le \min\mathbb{E}$.
solution: Write $L_i = L_{\mathcal{D}}(h_i)$. Conditioned on the data, $\mathbb{E}_I L_{\mathcal{D}}(h_I) = \sum_i\bar{p}(i)L_i = \frac{1}{T}\sum_t\langle \mathbf{p}_t, \mathbf{L}\rangle$, which is linear in $\bar{\mathbf{p}}$. The vector $\mathbf{p}_t$ is a function of $z_1, \dots, z_{t-1}$ and $z_t$ is independent of them, so $\mathbb{E}[\ell_t(i) \mid z_1, \dots, z_{t-1}] = L_i$ and hence $\mathbb{E}\langle \mathbf{p}_t, \mathbf{L}\rangle = \mathbb{E}\langle \mathbf{p}_t, \boldsymbol{\ell}_t\rangle$. The Hedge theorem holds for every loss sequence, in particular for the realized one: $\sum_t\langle \mathbf{p}_t, \boldsymbol{\ell}_t\rangle \le \min_i\sum_t\ell_t(i) + \sqrt{(T/2)\ln N}$. Taking expectations and using $\mathbb{E}\min_i\sum_t\ell_t(i) \le \min_i\mathbb{E}\sum_t\ell_t(i) = T\min_i L_i$, we get $\sum_t\mathbb{E}\langle \mathbf{p}_t, \boldsymbol{\ell}_t\rangle \le T\min_i L_i + \sqrt{(T/2)\ln N}$. Dividing by $T$ gives $\mathbb{E}\,L_{\mathcal{D}}(h_I) \le \min_i L_i + \sqrt{\ln N/(2T)}$. Compared with ERM and Theorem 2, the excess risk rate $\sqrt{\ln N/T}$ has the same dependence on $N$ and $T$ (up to constants), but the guarantee is in expectation over the data and the learner's randomization and the output is a randomized predictor rather than a single hypothesis, whereas Theorem 2 holds with probability $1 - \delta$ for a deterministic ERM output.

@article
A class with VC dimension $d$ produces all $2^m$ labelings of some set of $m$ points when $m \le d$. What happens for $m > d$? One might guess that the number of labelings keeps growing exponentially, only a little slower. It does not: it drops to a polynomial. This dichotomy, found independently by Vapnik and Chervonenkis (1971), Sauer (1972) and Shelah (1972), is the combinatorial heart of learning theory.

### Sauer's lemma

**Lemma (Sauer, Shelah, and Vapnik and Chervonenkis).** If $\operatorname{VCdim}(\mathcal{H}) = d < \infty$, then for all $m$,
$$\Pi_{\mathcal{H}}(m) \le \sum_{i=0}^{d} \binom{m}{i}.$$
Moreover, for $m \ge d \ge 1$, $\sum_{i=0}^{d} \binom{m}{i} \le (em/d)^d$.

The first bound is tight for thresholds ($d = 1$, $1 + m$ labelings) and intervals ($d = 2$, $1 + m + \binom{m}{2}$). The table compares it with $2^m$ for $d = 3$.

| $m$ | 3 | 4 | 5 | 6 | 10 | 20 |
|---|---|---|---|---|---|---|
| $\sum_{i \le 3}\binom{m}{i}$ | 8 | 15 | 26 | 42 | 176 | 1351 |
| $2^m$ | 8 | 16 | 32 | 64 | 1024 | 1048576 |

The proof goes through a stronger statement: for any finite set $C$ and any class $\mathcal{H}$ of functions on $C$, **the number of labelings $|\mathcal{H}_C|$ is at most the number of subsets of $C$ that $\mathcal{H}$ shatters** (counting the empty set as shattered whenever $\mathcal{H}$ is nonempty). If $\operatorname{VCdim} = d$ then every shattered subset has at most $d$ elements, and there are $\sum_{i \le d}\binom{m}{i}$ such subsets of an $m$-point set. The first example proves the strong statement by induction, the second proves the bound $(em/d)^d$.

### The fundamental theorem

The VC dimension is not just a convenient sufficient condition. For binary classification with the 0-1 loss it is the exact criterion.

**Theorem (fundamental theorem of statistical learning, binary classification, 0-1 loss).** For a class $\mathcal{H}$ of functions $\mathcal{X} \to \{0,1\}$ the following are equivalent: (1) $\mathcal{H}$ has the uniform convergence property; (2) $\mathcal{H}$ is agnostic PAC learnable; (3) every ERM rule is a successful agnostic PAC learner for $\mathcal{H}$; (4) $\mathcal{H}$ is PAC learnable; (5) every ERM rule is a successful PAC learner for $\mathcal{H}$; (6) $\operatorname{VCdim}(\mathcal{H}) < \infty$.

**Quantitative form.** Write $d = \operatorname{VCdim}(\mathcal{H})$. There are absolute constants $C_1, C_2 > 0$ such that the sample complexities satisfy
$$C_1 \frac{d + \ln(1/\delta)}{\epsilon^2} \le m_{\mathcal{H}}^{\text{agnostic}}(\epsilon, \delta) \le C_2 \frac{d + \ln(1/\delta)}{\epsilon^2},$$
$$C_1 \frac{d + \ln(1/\delta)}{\epsilon} \le m_{\mathcal{H}}^{\text{realizable}}(\epsilon, \delta) \le C_2 \frac{d \ln(1/\epsilon) + \ln(1/\delta)}{\epsilon}.$$
These are the statements in the main reading; the constants are not explicit, so do not quote numbers from them. The logarithm in the realizable upper bound is the price of using an arbitrary ERM rule, and it can be removed by other algorithms (Hanneke, 2016).

The implications form a map of the next weeks. (1) implies (3) and (5) by Lemma 1 of week 1. (3) implies (2) and (5) implies (4) trivially, and (2) implies (4) because realizable problems are agnostic ones. (6) implies (1) is week 5: a bound of the form
$$\sup_{h \in \mathcal{H}} |L_{\mathcal{D}}(h) - L_S(h)| \le \sqrt{\frac{2 d \ln(em/d)}{m}} + \sqrt{\frac{\ln(2/\delta)}{2m}} \quad \text{with probability} \ge 1 - \delta, \ m \ge d,$$
proved with Rademacher complexity, Massart's lemma and the bound of this lesson (week 5 states the exact version). Finally, (4) implies (6) is the no-free-lunch argument of week 6: if the VC dimension is infinite, then for every $m$ some set of $2m$ points is shattered and no learner can succeed from $m$ examples.

Read what this says. Finite VC dimension is necessary and sufficient, the dependence on the class is *only* through $d$, and the learner that works is the simplest one, ERM. It also says what the theorem does not: it concerns binary labels, the 0-1 loss and worst-case distributions, and it says nothing about computational cost. Statements for other settings need other dimensions.

@example
title: Counting shattered sets
problem: Prove that for every finite set $C$ and every class $\mathcal{H}$ of functions $C \to \{0,1\}$, $|\mathcal{H}| \le |\{B \subseteq C : \mathcal{H} \text{ shatters } B\}|$.
step: Induct on $m = |C|$. For $m = 0$ the only function is the empty function, so $|\mathcal{H}| \le 1$, and $\mathcal{H}$ shatters $\emptyset$ exactly when $\mathcal{H}$ is nonempty; the claim holds.
step: For $m \ge 1$ write $C = \{c_1\} \cup C'$ with $C' = \{c_2, \dots, c_m\}$. Define $Y_0 = \mathcal{H}_{C'}$, the restriction to $C'$, and $Y_1 = \{ \mathbf{y} \in \{0,1\}^{C'} : (0, \mathbf{y}) \in \mathcal{H}_C \text{ and } (1, \mathbf{y}) \in \mathcal{H}_C\}$.
step: Each pattern in $Y_0$ extends in one or two ways to $c_1$, and it extends in two ways exactly when it is in $Y_1$. Hence $|\mathcal{H}| = |\mathcal{H}_C| = |Y_0| + |Y_1|$.
step: By induction on $C'$, $|Y_0| \le |\{B \subseteq C' : Y_0 \text{ shatters } B\}| = |\{B \subseteq C' : \mathcal{H} \text{ shatters } B\}|$, since $Y_0$ is the restriction of $\mathcal{H}$ to $C'$. Likewise $|Y_1| \le |\{B \subseteq C' : Y_1 \text{ shatters } B\}|$.
step: If $Y_1$ shatters $B \subseteq C'$, then $\mathcal{H}$ shatters $B \cup \{c_1\}$: every labeling of $B$ appears in $Y_1$, and each pattern in $Y_1$ appears with both labels of $c_1$. So $|Y_1| \le |\{B' \subseteq C : c_1 \in B', \mathcal{H} \text{ shatters } B'\}|$.
step: Add the two bounds. The first counts shattered sets not containing $c_1$, the second counts shattered sets containing $c_1$, so $|\mathcal{H}| \le |\{B \subseteq C : \mathcal{H} \text{ shatters } B\}|$. Sauer's lemma follows, because when $\operatorname{VCdim} = d$ every shattered set has at most $d$ elements.
answer: The number of labelings is at most the number of shattered subsets, hence at most $\sum_{i \le d}\binom{m}{i}$.

@example
title: The bound (em/d)^d
problem: Prove that for $m \ge d \ge 1$, $\sum_{i=0}^{d} \binom{m}{i} \le (em/d)^d$, and evaluate both sides for $d = 4$, $m = 40$.
step: Since $d/m \le 1$, we have $(d/m)^d \le (d/m)^i$ for every $i \le d$. Hence $\left(\frac{d}{m}\right)^d \sum_{i=0}^{d}\binom{m}{i} \le \sum_{i=0}^{d}\binom{m}{i}\left(\frac{d}{m}\right)^i$.
step: Extend the sum to all $i \le m$, which only adds nonnegative terms: $\sum_{i=0}^{d}\binom{m}{i}(d/m)^i \le \sum_{i=0}^{m}\binom{m}{i}(d/m)^i = (1 + d/m)^m$ by the binomial theorem.
step: Use $1 + x \le e^x$: $(1 + d/m)^m \le e^{d}$. So $(d/m)^d \sum_{i \le d} \binom{m}{i} \le e^d$, that is, $\sum_{i \le d}\binom{m}{i} \le (em/d)^d$.
step: Numbers for $d = 4$, $m = 40$: the exact sum is $1 + 40 + 780 + 9880 + 91390 = 102091$, and $(em/d)^d = (10e)^4 \approx 545{,}982$. The bound is loose by a factor of about 5 but has the right polynomial degree.
answer: The sum is $102091$, and the bound $(em/d)^d$ is about $5.46 \times 10^5$.

@mistakes
- Stating Sauer's bound as $m^d$ or $2^d$: the correct bound is $\sum_{i \le d}\binom{m}{i}$, equal to $m^d/d!$ up to lower-order terms, and it applies for every $m$ while $(em/d)^d$ needs $m \ge d$.
- Treating the fundamental theorem as covering all losses and label sets: it is a statement about binary classification with the 0-1 loss.
- Quoting the sample complexity as $d/\epsilon^2$ with a specific constant: the constants in the quantitative form are unspecified absolute constants, and bounds with explicit constants (such as those proved from Rademacher complexity) carry extra logarithmic factors.

@practice code
prompt: Hypotheses on $n$ points are represented as tuples of $n$ labels, so a class is a nonempty list of 0/1 tuples of length `n`, and a subset of the points is a set of indices from `range(n)`. model:
```python
from itertools import combinations

def count_shattered(H, n):
    """Number of index subsets (including the empty one) shattered by H."""
    count = 0
    for size in range(n + 1):
        for subset in combinations(range(n), size):
            patterns = {tuple(h[i] for i in subset) for h in H}
            if len(patterns) == 2 ** size:
                count += 1
    return count
```
hint: For each subset of indices, collect the set of restricted tuples and compare its size with $2^{|B|}$; the empty subset has one restriction, the empty tuple.
solution: Enumerate subsets of every size with `combinations`, restrict each hypothesis to the subset, and count the subset when it sees all patterns. The count is at least $|H|$ by the lemma in the first example; the first two tests attain equality, and the third shows a strict inequality ($2$ hypotheses, $4$ shattered sets). The last test checks that the empty set counts, since the class is nonempty.

@practice self
prompt: Let $\mathcal{H}_1$ and $\mathcal{H}_2$ be classes of functions $\mathcal{X} \to \{0,1\}$, each of VC dimension at most $d$, where $d \ge 1$. Prove that $\mathcal{H}_1 \cup \mathcal{H}_2$ has VC dimension at most $2d + 1$. You may use Sauer's lemma.
hint: If the union shatters $m$ points, then $2^m \le \Pi_{\mathcal{H}_1}(m) + \Pi_{\mathcal{H}_2}(m)$. Take $m = 2d + 2$ and use the symmetry of the binomial coefficients.
solution: Suppose the union shatters a set $C$ of $m = 2d + 2$ points. A labeling of $C$ is realized by a function from $\mathcal{H}_1$ or from $\mathcal{H}_2$, so $2^{m} \le |(\mathcal{H}_1)_C| + |(\mathcal{H}_2)_C| \le 2\sum_{i=0}^{d}\binom{m}{i}$ by Sauer's lemma. Since $\binom{m}{i} = \binom{m}{m-i}$, we have $\sum_{i \le d}\binom{m}{i} = \sum_{i \ge d+2}\binom{m}{i}$, so $2^m = 2\sum_{i \le d}\binom{m}{i} + \binom{m}{d+1}$. Therefore $2\sum_{i \le d}\binom{m}{i} = 2^m - \binom{m}{d+1} < 2^m$, because $\binom{m}{d+1} > 0$. This contradicts $2^m \le 2\sum_{i \le d}\binom{m}{i}$. So no set of $2d + 2$ points is shattered, and any larger shattered set would contain one; hence $\operatorname{VCdim}(\mathcal{H}_1 \cup \mathcal{H}_2) \le 2d + 1$.
rubric: Bounds the number of labelings of the union by the sum of the two growth functions, and applies Sauer's lemma to each.
rubric: Evaluates the bound at $m = 2d + 2$ and uses the symmetry $\binom{m}{i} = \binom{m}{m-i}$ with the middle term $\binom{m}{d+1}$.
rubric: Derives the strict inequality $2\sum_{i \le d}\binom{m}{i} < 2^m$, reaches the contradiction, and concludes that no larger set can be shattered.

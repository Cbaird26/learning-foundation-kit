@article
The sample bounds of week 2 depend on $\ln|\mathcal{H}|$, which is infinite for the classes we care about: thresholds on the real line, linear separators, neural networks. Yet a threshold on a line is a far simpler object than an arbitrary function. The **VC dimension**, introduced by Vapnik and Chervonenkis (1971), measures that simplicity not by counting hypotheses but by counting how many *labelings of points* they can produce.

### Restriction and shattering

Let $\mathcal{H}$ be a class of functions $\mathcal{X} \to \{0, 1\}$ and $C = \{c_1, \dots, c_m\} \subseteq \mathcal{X}$. The **restriction** of $\mathcal{H}$ to $C$ is the set of label vectors it can produce,
$$\mathcal{H}_C = \{(h(c_1), \dots, h(c_m)) : h \in \mathcal{H}\} \subseteq \{0,1\}^m .$$
The set $C$ is **shattered** by $\mathcal{H}$ if $|\mathcal{H}_C| = 2^m$, that is, if every one of the $2^m$ labelings is realized by some hypothesis. The **VC dimension** $\operatorname{VCdim}(\mathcal{H})$ is the size of the largest shattered set, and $\infty$ if arbitrarily large sets are shattered. The **growth function** is $\Pi_{\mathcal{H}}(m) = \max_{|C| = m} |\mathcal{H}_C|$, so $\Pi_{\mathcal{H}}(m) = 2^m$ exactly when some $m$-point set is shattered, and $\operatorname{VCdim}(\mathcal{H}) = \max\{m : \Pi_{\mathcal{H}}(m) = 2^m\}$.

The logic of a VC proof has two halves with different quantifiers. To show $\operatorname{VCdim}(\mathcal{H}) \ge d$ you need **one** shattered set of size $d$. To show $\operatorname{VCdim}(\mathcal{H}) < d + 1$ you must show that **every** set of size $d + 1$ fails to be shattered, by exhibiting for each such set a labeling that no hypothesis realizes. Confusing the halves is the most common error: three collinear points are not shattered by lines in the plane, yet the VC dimension of halfplanes in the plane is 3.

### A catalogue

| class $\mathcal{H}$ | $\operatorname{VCdim}$ | growth function |
|---|---|---|
| thresholds $\mathbb{1}[x \ge t]$ on $\mathbb{R}$ | 1 | $m + 1$ |
| intervals $\mathbb{1}[a \le x \le b]$ on $\mathbb{R}$ | 2 | $\binom{m+1}{2} + 1$ |
| axis-aligned rectangles in $\mathbb{R}^2$ | 4 | |
| affine halfspaces $\mathbb{1}[\langle \mathbf{w}, \mathbf{x} \rangle + b > 0]$ in $\mathbb{R}^d$ | $d + 1$ | |
| homogeneous halfspaces $\mathbb{1}[\langle \mathbf{w}, \mathbf{x} \rangle > 0]$ in $\mathbb{R}^d$ | $d$ | |
| any finite class | $\le \log_2 |\mathcal{H}|$ | $\le |\mathcal{H}|$ |

Thresholds show the pattern. A single point is shattered by $h_t$ with $t$ below or above it. For $a < b$ the labeling $(1, 0)$ would need $h_t(a) = 1$ and $h_t(b) = 0$, but $a \ge t$ forces $b \ge t$; so no pair is shattered. The growth function counts the monotone labelings, namely $m + 1$ choices of where the labels switch from 0 to 1. The finite-class bound holds because a shattered set of size $d$ needs $2^d$ distinct label vectors, hence $2^d \le |\mathcal{H}|$.

Two warnings. The VC dimension is not the number of parameters: the class $\{x \mapsto \mathbb{1}[\sin(\theta x) > 0] : \theta \in \mathbb{R}\}$ has one parameter and infinite VC dimension, a classical example. And the VC dimension depends on the class only through the labelings it produces, so it does not depend on the distribution or on the learning algorithm.

### Restriction in code

```python
def restriction(points, hyps):
    """The set of label vectors that the hypotheses produce on the points."""
    return {tuple(h(x) for x in points) for h in hyps}

def is_shattered(points, hyps):
    return len(restriction(points, hyps)) == 2 ** len(points)

ts = [0.5, 1.5, 2.5, 3.5]
thresholds = [lambda x, t=t: int(x >= t) for t in ts]
print(is_shattered([2], thresholds), is_shattered([2, 3], thresholds))
```

The program prints `True False`. Brute force of this kind checks one *candidate* set at a time, and only against the finite list of hypotheses supplied; the proofs in the examples are what establish a VC dimension for an infinite class.

@example
title: Intervals have VC dimension 2
problem: Prove that the class of intervals $h_{a,b}(x) = \mathbb{1}[a \le x \le b]$ on $\mathbb{R}$, with $a \le b$, has VC dimension exactly 2.
step: Lower bound. Take $C = \{0, 1\}$. The labeling $(1,1)$ comes from $[0,1]$, $(1,0)$ from $[-0.5, 0.5]$, $(0,1)$ from $[0.5, 1.5]$, and $(0,0)$ from $[5, 6]$. All four are realized, so $C$ is shattered and $\operatorname{VCdim} \ge 2$.
step: Upper bound. Take any three points $c_1 < c_2 < c_3$ and the labeling $(1, 0, 1)$.
step: A hypothesis with $h(c_1) = h(c_3) = 1$ has $a \le c_1$ and $b \ge c_3$, so it contains $c_2$ because $a \le c_1 < c_2 < c_3 \le b$. Hence $h(c_2) = 1$, and $(1, 0, 1)$ is not realized.
step: So no three-point set is shattered, and since shattering a larger set would shatter its three-point subsets, $\operatorname{VCdim} \le 2$. Together, $\operatorname{VCdim} = 2$.
answer: $\operatorname{VCdim} = 2$.

@example
title: Affine halfspaces in R^d have VC dimension d+1
problem: Let $h_{\mathbf{w}, b}(\mathbf{x}) = \mathbb{1}[\langle \mathbf{w}, \mathbf{x} \rangle + b > 0]$ for $\mathbf{w} \in \mathbb{R}^d$, $b \in \mathbb{R}$. Prove $\operatorname{VCdim} = d + 1$.
step: Lower bound. Take the $d + 1$ points $\mathbf{x}_0 = \mathbf{0}$ and $\mathbf{x}_i = \mathbf{e}_i$ for $i = 1, \dots, d$. Given labels $y_0, \dots, y_d \in \{0, 1\}$, let $s_i = 2y_i - 1 \in \{\pm 1\}$. Choose $b = s_0 / 2$ and $w_i = s_i - b$.
step: Check: at $\mathbf{x}_0$ the value is $b = s_0/2$, whose sign is $s_0$; at $\mathbf{x}_i$ it is $w_i + b = s_i$. So every labeling is realized, and $\operatorname{VCdim} \ge d + 1$.
step: Radon's lemma. Any $d + 2$ points $\mathbf{x}_1, \dots, \mathbf{x}_{d+2}$ in $\mathbb{R}^d$ split into two sets whose convex hulls intersect. Proof: the $d + 2$ vectors $(\mathbf{x}_i, 1) \in \mathbb{R}^{d+1}$ are linearly dependent, so there are $a_i$, not all zero, with $\sum_i a_i \mathbf{x}_i = \mathbf{0}$ and $\sum_i a_i = 0$.
step: Let $P = \{i : a_i > 0\}$ and $N = \{i : a_i < 0\}$. Both are nonempty because the $a_i$ sum to zero and are not all zero. Put $s = \sum_{i \in P} a_i = \sum_{i \in N} |a_i| > 0$. Then $\mathbf{z} = \sum_{i \in P} (a_i / s) \mathbf{x}_i = \sum_{i \in N} (|a_i|/s) \mathbf{x}_i$ lies in both convex hulls.
step: Upper bound. Label $P$ with 1 and $N$ with 0. If some $h_{\mathbf{w}, b}$ realized this, then $f(\mathbf{x}) = \langle \mathbf{w}, \mathbf{x} \rangle + b$ is affine, so $f(\mathbf{z}) = \sum_{P} (a_i/s) f(\mathbf{x}_i) > 0$ (a convex combination of positive numbers) and $f(\mathbf{z}) = \sum_{N} (|a_i|/s) f(\mathbf{x}_i) \le 0$, a contradiction. Thus no $d + 2$ points are shattered, and $\operatorname{VCdim} = d + 1$.
answer: $\operatorname{VCdim} = d + 1$.

@mistakes
- Proving only one half: a shattered set of size $d$ gives $\operatorname{VCdim} \ge d$, and you still need an argument for every set of size $d + 1$.
- Concluding that a class has small VC dimension because it has few parameters, or large VC dimension because it has many; neither implication holds.
- Reading "shatters" as "separates the given labeling": shattering requires all $2^m$ labelings of the same $m$ points, with a possibly different hypothesis for each.

answer: 22
check: len({tuple(int(i <= k <= j) for k in range(6)) for i in range(7) for j in range(-1, 6)})
hint: A labeling is determined by which block of consecutive points is labeled 1; count the nonempty blocks and add the all-zero labeling.
solution: The nonempty consecutive blocks among 6 points number $6 \cdot 7 / 2 = 21$ (choose the first and last point of the block), and the empty block adds one labeling, giving $21 + 1 = 22$. This is $\binom{7}{2} + 1$, well below $2^6 = 64$.

@practice num
prompt: A finite hypothesis class contains 300 functions $\mathcal{X} \to \{0, 1\}$. What is the largest possible value of its VC dimension?
answer: 8
check: floor(log2(300))
hint: A shattered set of size $d$ needs at least $2^d$ distinct hypotheses.
solution: If $d$ points are shattered, the class realizes $2^d$ distinct labelings, so $2^d \le 300$. Since $2^8 = 256 \le 300 < 512 = 2^9$, the VC dimension is at most 8, and 8 is achievable by taking a class that shatters 8 points and adding 44 more functions.

model:
```python
from itertools import combinations

def growth_function(pool, hyps, m):
    """Max number of labelings of an m-subset of the pool by the hypotheses."""
    best = 0
    for subset in combinations(pool, m):
        labelings = {tuple(h(x) for x in subset) for h in hyps}
        best = max(best, len(labelings))
    return best
```
hint: Loop over the $m$-element subsets with `itertools.combinations`, count the distinct label tuples on each, and keep the maximum.
solution: The growth function maximizes over subsets, so the code must try every subset rather than the first $m$ points: the third test is built so that the first two points of the pool give only 2 labelings while another pair gives 3. With the interval class the counts $1, 2, 4, 7, 11$ equal $\binom{m+1}{2} + 1$.

@practice self
prompt: Let $\mathcal{H}$ be the class of axis-aligned rectangles in $\mathbb{R}^2$, $h(\mathbf{x}) = \mathbb{1}[a_1 \le x_1 \le b_1 \text{ and } a_2 \le x_2 \le b_2]$ with closed sides. Prove that $\operatorname{VCdim}(\mathcal{H}) = 4$.
hint: For the lower bound try the four points $(\pm 1, 0)$ and $(0, \pm 1)$. For the upper bound, among any five points pick four that attain the extreme coordinates and look at the fifth.
solution: Lower bound. Let $C = \{(1,0), (-1,0), (0,1), (0,-1)\}$. For any subset $T \subseteq C$ take the smallest rectangle containing $T$ (a tiny rectangle far away if $T = \emptyset$). No point of $C \setminus T$ lies in it: the bounding box of one point is that point; of two points on opposite sides it is a segment through the origin that misses the other two points; of two adjacent points it is a unit square or segment missing the others; of three points it is a rectangle such as $[0,1] \times [-1,1]$ that excludes the fourth. Hence $C$ is shattered. Upper bound. Take any five points. Choose a point with smallest first coordinate, one with largest first coordinate, one with smallest second coordinate and one with largest second coordinate; these are at most four distinct points, so some point $q$ among the five is not chosen. Label all chosen points 1 and $q$ 0. Any rectangle containing the chosen points contains their bounding box, which has the extreme coordinates of all five points and therefore contains $q$, so $q$ is also labeled 1. This labeling is unrealizable, so no five-point set is shattered and $\operatorname{VCdim} = 4$.
rubric: Gives a four-point set and checks that all sixteen labelings (or all subsets) are realized by rectangles.
rubric: For five points, selects points attaining the four extreme coordinates and identifies a leftover point.
rubric: Argues that any rectangle containing the extreme points contains the leftover point, so the labeling is unrealizable.

answer: 10

hint: Count the labelings in which the labels switch once from 0 to 1, and those in which they switch from 1 to 0; the constant labelings appear in both families.
solution: The upward thresholds give $m + 1 = 6$ labelings (including all zeros and all ones), the downward thresholds give another 6, and the two constant labelings are counted twice, so the total is $6 + 6 - 2 = 10 = 2m$.

@quiz mc
prompt: Affine halfspaces in the plane have VC dimension 3. Which statement about this fact is correct?
choice*: Some three-point sets are shattered, while other three-point sets, such as three collinear points, are not.
choice: Every set of three points in the plane is shattered by affine halfspaces.
choice: Three collinear points are shattered, but three points in general position are not.
choice: Affine halfspaces in the plane shatter some set of four points but not every set of four points.
hint: VC dimension is a statement about the existence of one shattered set and the nonexistence of any shattered larger set.
solution: Three points in general position (the vertices of a triangle) are shattered, so the VC dimension is at least 3. Three collinear points $c_1, c_2, c_3$ in this order cannot receive the labeling $(1, 0, 1)$, because an affine function on a line is monotone along it. The VC dimension is 3 because no four-point set is shattered (by Radon's lemma, for instance the four corners of a square cannot receive the diagonal labeling).

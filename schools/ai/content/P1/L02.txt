@article
How many examples does it take to learn conjunctions of Boolean features? Last week we had one fixed hypothesis and Hoeffding's inequality. This week we ask for a guarantee that holds for *every distribution*, with a number of examples that depends only on the accuracy we want, the confidence we want and the size of the class. That is Valiant's framework of probably approximately correct (PAC) learning (Valiant, 1984).

### The definitions

The **realizability assumption** holds for $\mathcal{H}$, $\mathcal{D}$ and a labeling function $f : \mathcal{X} \to \{0, 1\}$ if there is $h^\star \in \mathcal{H}$ with $L_{\mathcal{D}, f}(h^\star) = 0$, where $L_{\mathcal{D}, f}(h) = P_{x \sim \mathcal{D}}[h(x) \neq f(x)]$. Then $L_S(h^\star) = 0$ with probability one.

**Definition (realizable PAC learnability).** $\mathcal{H}$ is PAC learnable if there are a function $m_{\mathcal{H}} : (0, 1)^2 \to \mathbb{N}$ and a learning algorithm $A$ such that for every $\epsilon, \delta \in (0, 1)$, for **every** distribution $\mathcal{D}$ over $\mathcal{X}$ and **every** $f$ for which realizability holds, running $A$ on $m \ge m_{\mathcal{H}}(\epsilon, \delta)$ i.i.d. examples labeled by $f$ returns, with probability at least $1 - \delta$ over the sample, a hypothesis $h$ with $L_{\mathcal{D}, f}(h) \le \epsilon$. The **sample complexity** is the smallest such function.

Read the quantifiers: $\epsilon$ (accuracy) and $\delta$ (confidence) come first and fix the number $m_{\mathcal{H}}$; the distribution comes after and may not change $m_{\mathcal{H}}$. That is what "distribution-free" means.

**Definition (agnostic PAC learnability).** Drop realizability: $\mathcal{D}$ is any distribution over $\mathcal{X} \times \{0, 1\}$, and $A$ must return $h$ with $L_{\mathcal{D}}(h) \le \min_{h' \in \mathcal{H}} L_{\mathcal{D}}(h') + \epsilon$ with probability at least $1 - \delta$.

### Finite classes, realizable case

**Theorem 1.** Let $\mathcal{H}$ be finite, $\epsilon, \delta \in (0, 1)$, and $m \ge \ln(|\mathcal{H}|/\delta)/\epsilon$. For every $\mathcal{D}$ and $f$ with realizability, with probability at least $1 - \delta$ over $S \sim \mathcal{D}^m$, every $h_S \in \operatorname{ERM}_{\mathcal{H}}(S)$ has $L_{\mathcal{D}, f}(h_S) \le \epsilon$.

*Proof.* Let $\mathcal{H}_B = \{h \in \mathcal{H} : L_{\mathcal{D}, f}(h) > \epsilon\}$ be the bad hypotheses. With probability one $L_S(h^\star) = 0$, so every ERM output has $L_S(h_S) = 0$. Hence $h_S \in \mathcal{H}_B$ implies that some bad $h$ has $L_S(h) = 0$. For a fixed $h \in \mathcal{H}_B$, the examples are independent and each is classified correctly with probability $1 - L_{\mathcal{D}, f}(h) < 1 - \epsilon$, so
$$P[L_S(h) = 0] \le (1 - \epsilon)^m \le e^{-\epsilon m},$$
using $1 - \epsilon \le e^{-\epsilon}$. By the union bound over $\mathcal{H}_B \subseteq \mathcal{H}$, the probability that some bad hypothesis is consistent with the sample is at most $|\mathcal{H}|\, e^{-\epsilon m}$, which is at most $\delta$ exactly when $m \ge \ln(|\mathcal{H}|/\delta)/\epsilon$. $\square$

### Finite classes, agnostic case

**Theorem 2.** Let $\mathcal{H}$ be finite and $m \ge 2\ln(2|\mathcal{H}|/\delta)/\epsilon^2$. For every distribution $\mathcal{D}$ over $\mathcal{X} \times \{0,1\}$, with probability at least $1 - \delta$ every ERM output satisfies $L_{\mathcal{D}}(h_S) \le \min_{h \in \mathcal{H}} L_{\mathcal{D}}(h) + \epsilon$.

*Proof.* By Hoeffding's inequality applied to each fixed $h$ with deviation $\epsilon/2$, and a union bound,
$$P[\exists h \in \mathcal{H} : |L_S(h) - L_{\mathcal{D}}(h)| > \epsilon/2] \le 2|\mathcal{H}|\, e^{-2m(\epsilon/2)^2} = 2|\mathcal{H}|\, e^{-m\epsilon^2/2}.$$
This is at most $\delta$ exactly when $m \ge 2\ln(2|\mathcal{H}|/\delta)/\epsilon^2$. On the complementary event $S$ is $\epsilon/2$-representative, and Lemma 1 from week 1 gives the claim. $\square$

These are the constants of the main reading; other sources state slightly different ones (for instance by using one-sided deviations), so always check which version a paper uses. Two features matter more than the constants. First, the dependence on $\epsilon$ is $1/\epsilon$ in the realizable case and $1/\epsilon^2$ in the agnostic case. Second, the class enters only through $\ln|\mathcal{H}|$, the number of nats (bits times $\ln 2$) needed to name a hypothesis.

### An example class

Boolean **conjunctions** over $d$ variables: $h(\mathbf{x}) = \bigwedge_{i \in P} x_i \wedge \bigwedge_{j \in N} \lnot x_j$. As functions there are $3^d + 1$: each variable appears positively, negatively or not at all, plus the constant-false function that every contradictory formula computes. With $d = 10$, $\epsilon = 0.1$ and $\delta = 0.05$, Theorem 1 asks for $m \ge \ln(59050/0.05)/0.1 \approx 139.8$, so 140 examples, although the domain has 1024 points.

```python
from math import ceil, log

def realizable_bound(size, eps, delta):
    """Sample size from Theorem 1: ln(|H| / delta) / eps, rounded up."""
    return ceil(log(size / delta) / eps)

print(realizable_bound(3 ** 10 + 1, 0.1, 0.05))
```

The program prints `140`.

@example
title: Inverting the bound
problem: A finite class has $|\mathcal{H}| = 1024$ hypotheses and the realizability assumption holds. With $m = 200$ examples and confidence $0.95$, what accuracy $\epsilon$ does Theorem 1 guarantee?
step: Solve $m \ge \ln(|\mathcal{H}|/\delta)/\epsilon$ for $\epsilon$: any $\epsilon \ge \ln(|\mathcal{H}|/\delta)/m$ works.
step: Substitute: $\ln(1024 / 0.05) / 200 = \ln(20480) / 200 = 9.927 / 200$.
step: The guaranteed accuracy is $\epsilon \approx 0.0496$: with probability at least $0.95$ every consistent hypothesis has error at most about $5\%$.
answer: $\epsilon \approx 0.0496$.

@mistakes
- Swapping the quantifiers: PAC learnability needs one sample size $m_{\mathcal{H}}(\epsilon, \delta)$ that works for all distributions, not a size that may depend on $\mathcal{D}$.
- Using the realizable bound without realizability: if no hypothesis has zero true risk, a consistent hypothesis may not exist, and the proof's key fact $L_S(h^\star) = 0$ fails.
- Quoting a bound without its constants: $\ln(|\mathcal{H}|/\delta)/\epsilon$ and $2\ln(2|\mathcal{H}|/\delta)/\epsilon^2$ are specific versions, and papers differ in the constants.

```python
def exact_samples(size, eps, delta):
    """Smallest m with size * (1 - eps) ** m <= delta."""
    m = 0
    failure = float(size)
    while failure > delta:
        failure *= 1 - eps
        m += 1
    return m
```
hint: Start with the failure bound `size` (that is, $m = 0$) and multiply it by $1 - \epsilon$ once per additional example, counting steps until it is at most `delta`.
solution: The loop is the definition: each extra example multiplies the union bound by $1 - \epsilon$. The last test needs exactly one example, because the bound starts at 1, just above `delta`, and one factor of $0.9$ brings it below; a loop that stops one step early or late fails it. Comparing with $\lceil \ln(|\mathcal{H}|/\delta)/\epsilon \rceil$ (for example 63.5 against 57 for a class of 6562 hypotheses with $\epsilon = 0.2$ and $\delta = 0.02$) shows that the relaxation $1 - \epsilon \le e^{-\epsilon}$ costs a few examples, which is invisible in the order of magnitude.

@practice self
prompt: Let $\mathcal{H}$ be finite, assume realizability, and let $h_S$ be any hypothesis in $\mathcal{H}$ with $L_S(h_S) = 0$ (a consistent hypothesis). Use Theorem 1's tail bound $P[L_{\mathcal{D}, f}(h_S) > \epsilon] \le |\mathcal{H}|\, e^{-\epsilon m}$ for every $\epsilon \in (0, 1)$ to prove that $\mathbb{E}_S\big[L_{\mathcal{D}, f}(h_S)\big] \le \dfrac{1 + \ln |\mathcal{H}|}{m}$.
hint: For a random variable $Z \in [0, 1]$, $\mathbb{E}Z = \int_0^1 P[Z > \epsilon]\, d\epsilon$. Bound the integrand by $1$ below a threshold and by the tail bound above it.
solution: Let $Z = L_{\mathcal{D}, f}(h_S) \in [0, 1]$, so $\mathbb{E} Z = \int_0^1 P[Z > \epsilon]\, d\epsilon$. Let $a = \ln|\mathcal{H}|/m$. If $a \ge 1$ the claim is trivial because $Z \le 1 \le a$. Otherwise bound the integrand by $1$ on $[0, a]$ and by $|\mathcal{H}| e^{-\epsilon m}$ on $[a, 1]$, and extend the second integral to $\infty$. Then $\mathbb{E} Z \le a + \int_a^\infty |\mathcal{H}| e^{-\epsilon m}\, d\epsilon = a + |\mathcal{H}| e^{-a m} / m = a + 1/m$, since $|\mathcal{H}| e^{-am} = 1$. Hence $\mathbb{E} Z \le (\ln|\mathcal{H}| + 1)/m$. The expected risk of a consistent learner therefore falls like $\ln|\mathcal{H}|/m$.
rubric: Writes the expectation of a $[0,1]$-valued variable as the integral of its tail probability.
rubric: Splits the integral at $\ln|\mathcal{H}|/m$, using the trivial bound $1$ below and the exponential tail above.
rubric: Evaluates the exponential integral correctly, obtaining $1/m$, and states the final bound.

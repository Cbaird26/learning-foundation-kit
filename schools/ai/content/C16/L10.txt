@article
The pump monitor reported ok, alarm, alarm. Was the pump normal, faulty, faulty? Or normal, normal, faulty? **Decoding** asks for the hidden state sequence $\mathbf{z}^\star = \arg\max_{\mathbf{z}} P(\mathbf{z} \mid \mathbf{o})$. Since $P(\mathbf{z} \mid \mathbf{o}) = P(\mathbf{z}, \mathbf{o}) / P(\mathbf{o})$ and the denominator does not depend on $\mathbf{z}$, this is the same as maximizing the joint probability $P(\mathbf{z}, \mathbf{o})$ from last lesson. There are $K^T$ candidate paths, but dynamic programming finds the best one in $O(TK^2)$ steps.

### The Viterbi algorithm

The **Viterbi algorithm** (Viterbi, 1967) is the forward algorithm with a maximum in place of the sum. Define
$$\delta_t(j) = \max_{z_1, \dots, z_{t-1}} P(z_1, \dots, z_{t-1},\, z_t = j,\, o_1, \dots, o_t),$$
the probability of the best path that ends in state $j$ at time $t$. It satisfies
$$\delta_1(j) = \pi_j B_j(o_1), \qquad \delta_t(j) = \Big[\max_{i} \delta_{t-1}(i)\, A_{ij}\Big] B_j(o_t).$$
The reason is the same optimal-substructure argument as before: the best path into $j$ at time $t$ must pass through some state $i$ at time $t - 1$, and given that state, the earlier part of the path must itself be the best path into $i$. Alongside the values we store a **backpointer**
$$\psi_t(j) = \arg\max_{i}\ \delta_{t-1}(i)\, A_{ij}.$$
At the end, the best final state is $z_T^\star = \arg\max_j \delta_T(j)$ with the path probability $\max_j \delta_T(j)$; the rest of the path is recovered by **backtracking**, $z_{t}^\star = \psi_{t+1}(z_{t+1}^\star)$ for $t = T-1, \dots, 1$. Ties are broken by a fixed rule, here by the lowest state index.

### The pump, decoded

With $\pi = (0.9, 0.1)$, $A = \begin{pmatrix} 0.8 & 0.2 \\ 0.3 & 0.7 \end{pmatrix}$, $B = \begin{pmatrix} 0.9 & 0.1 \\ 0.2 & 0.8 \end{pmatrix}$ (state 0 normal, state 1 faulty; observation 0 ok, observation 1 alarm) and the reports (ok, alarm, alarm):

| $t$ | $\delta_t(\text{normal})$ | back | $\delta_t(\text{faulty})$ | back |
|---|---|---|---|---|
| 1 | 0.81 | none | 0.02 | none |
| 2 | 0.0648 | normal | 0.1296 | normal |
| 3 | 0.005184 | normal | 0.072576 | faulty |

For example $\delta_2(\text{faulty}) = \max(0.81 \times 0.2,\ 0.02 \times 0.7) \times 0.8 = 0.162 \times 0.8 = 0.1296$, coming from normal. At $t = 3$ the best final state is faulty with probability $0.072576$; backtracking gives faulty at time 3, then $\psi_3(\text{faulty}) = $ faulty at time 2, then $\psi_2(\text{faulty}) = $ normal at time 1. The decoded path is **normal, faulty, faulty**, with joint probability $0.072576$. This is one path out of eight, and it carries $0.0726/0.0988 \approx 73\%$ of the total likelihood $P(\mathbf{o}) = 0.0988$.

### Two kinds of "most likely"

Viterbi returns the single most probable **sequence**. A different decoder, **posterior decoding**, picks at each time the state with the largest posterior $P(z_t = j \mid \mathbf{o})$ (computed with the forward and backward recursions). The two can disagree, and the posterior-decoded sequence can even be impossible (it can contain a transition with probability 0), because it ignores how the choices at different times fit together. Viterbi respects the transition structure and is the usual choice when you need a coherent sequence, such as a tagged sentence; posterior decoding minimizes the expected number of wrong individual states.

### Log space

As with the forward algorithm, products of many probabilities underflow. Because the logarithm is increasing, maximizing a product is the same as maximizing a sum of logs, so the recursion becomes
$$\log\delta_t(j) = \max_i \big[\log\delta_{t-1}(i) + \log A_{ij}\big] + \log B_j(o_t),$$
with $\log 0 = -\infty$ for impossible events. There is no sum of probabilities, so no log-sum-exp is needed. Unlike the forward algorithm, Viterbi in log space is exact and simple.

### In code

```python
def viterbi(pi, A, B, obs):
    K = len(pi)
    delta = [pi[j] * B[j][obs[0]] for j in range(K)]
    back = []
    for o in obs[1:]:
        new, ptr = [], []
        for j in range(K):
            cands = [delta[i] * A[i][j] for i in range(K)]
            best = cands.index(max(cands))          # lowest index on ties
            new.append(cands[best] * B[j][o])
            ptr.append(best)
        delta = new
        back.append(ptr)
    state = delta.index(max(delta))
    path = [state]
    for ptr in reversed(back):
        state = ptr[state]
        path.append(state)
    return path[::-1], max(delta)

pi = [0.9, 0.1]
A = [[0.8, 0.2], [0.3, 0.7]]
B = [[0.9, 0.1], [0.2, 0.8]]
print(viterbi(pi, A, B, [0, 1, 1]))
```

Viterbi decoding is used wherever a hidden sequence must be reconstructed from noisy observations, such as speech recognition, part-of-speech tagging and error-correcting codes.

title: Decoding a two-step sequence
problem: A model has $\pi = (0.7, 0.3)$, $A = \begin{pmatrix} 0.6 & 0.4 \\ 0.5 & 0.5 \end{pmatrix}$ and $B = \begin{pmatrix} 0.2 & 0.8 \\ 0.7 & 0.3 \end{pmatrix}$. Find the most likely state sequence for the observations $(1, 0)$ and its probability.
step: Initialize with observation 1: $\delta_1(0) = 0.7 \times 0.8 = 0.56$ and $\delta_1(1) = 0.3 \times 0.3 = 0.09$.
step: For state 0 at time 2: candidates $0.56 \times 0.6 = 0.336$ (from state 0) and $0.09 \times 0.5 = 0.045$ (from state 1); the maximum is $0.336$ from state 0, and times $B_0(0) = 0.2$ gives $\delta_2(0) = 0.0672$.
step: For state 1 at time 2: candidates $0.56 \times 0.4 = 0.224$ (from state 0) and $0.09 \times 0.5 = 0.045$; the maximum is $0.224$ from state 0, and times $B_1(0) = 0.7$ gives $\delta_2(1) = 0.1568$.
step: The best final state is 1 with $\delta_2(1) = 0.1568$. Backtrack: $\psi_2(1) = 0$, so the path is $(0, 1)$.
step: Check by enumeration: the four paths have probabilities $(0,0)$: $0.56 \times 0.6 \times 0.2 = 0.0672$, $(0,1)$: $0.1568$, $(1,0)$: $0.09 \times 0.5 \times 0.2 = 0.009$ and $(1,1)$: $0.09 \times 0.5 \times 0.7 = 0.0315$. The best is $(0, 1)$.
answer: The most likely sequence is $(0, 1)$ with probability $0.1568$.

@example
title: Backtracking through backpointers
problem: A Viterbi run over three observations stored the backpointers $\psi_2 = (0, 0)$ and $\psi_3 = (1, 1)$ (the entry $j$ is the best previous state for state $j$) and ended with the best final state $z_3 = 1$. Recover the path.
step: The final state is $z_3^\star = 1$.
step: $z_2^\star = \psi_3(z_3^\star) = \psi_3(1) = 1$.
step: $z_1^\star = \psi_2(z_2^\star) = \psi_2(1) = 0$.
answer: The path is $(0, 1, 1)$.

@mistakes
- Keeping only the values $\delta$ and forgetting the backpointers: without them you know the best probability but not the path.
- Backtracking from the wrong end: start from the best final state at time $T$ and walk backward through $\psi$.
- Confusing Viterbi with posterior decoding: the best sequence need not be made of the individually most probable states.
- Taking the logarithm of 0 without handling it: use $-\infty$ for impossible transitions and emissions.

```python
def viterbi_step(prev, A, emit):
    """One Viterbi step: new best-path probabilities and backpointers."""
    K = len(prev)
    delta, back = [], []
    for j in range(K):
        cands = [prev[i] * A[i][j] for i in range(K)]
        best = cands.index(max(cands))
        delta.append(cands[best] * emit[j])
        back.append(best)
    return delta, back
```
hint: For each new state `j`, compute the list of `prev[i] * A[i][j]` over `i`, take its maximum and its index, and multiply the maximum by `emit[j]`.
solution: `cands.index(max(cands))` gives the lowest index among ties. The first test is an all-ties case that checks the tie rule; the last test has a permutation-like transition matrix whose backpointers are not all 0.

```python
def viterbi(pi, A, B, obs):
    """Most likely state path and its joint probability."""
    K = len(pi)
    delta = [pi[j] * B[j][obs[0]] for j in range(K)]
    back = []
    for o in obs[1:]:
        new, ptr = [], []
        for j in range(K):
            cands = [delta[i] * A[i][j] for i in range(K)]
            best = cands.index(max(cands))
            new.append(cands[best] * B[j][o])
            ptr.append(best)
        delta = new
        back.append(ptr)
    state = delta.index(max(delta))
    prob = delta[state]
    path = [state]
    for ptr in reversed(back):
        state = ptr[state]
        path.append(state)
    return path[::-1], prob
```

model:
```python
from math import log


def viterbi_log(pi, A, B, obs):
    """Viterbi decoding in log space; returns (path, log joint probability)."""
    neg_inf = float("-inf")

    def lg(x):
        return log(x) if x > 0 else neg_inf

    K = len(pi)
    delta = [lg(pi[j]) + lg(B[j][obs[0]]) for j in range(K)]
    back = []
    for o in obs[1:]:
        new, ptr = [], []
        for j in range(K):
            cands = [delta[i] + lg(A[i][j]) for i in range(K)]
            best = cands.index(max(cands))
            new.append(cands[best] + lg(B[j][o]))
            ptr.append(best)
        delta = new
        back.append(ptr)
    state = delta.index(max(delta))
    logprob = delta[state]
    path = [state]
    for ptr in reversed(back):
        state = ptr[state]
        path.append(state)
    return path[::-1], logprob
```
hint: Use the same recursion as Viterbi, with `+` in place of `*`, a helper that returns `-inf` for zero, and the same backpointers.
solution: Adding logarithms replaces multiplying probabilities, and the maximum of the sums picks the same path as the maximum of the products because the logarithm is increasing. The 900-step test has 300 observations in each regime, and the correct path switches state exactly where the observations switch; the all-ties test checks the lowest-index rule.

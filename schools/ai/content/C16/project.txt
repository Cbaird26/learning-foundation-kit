## Review guide: unsupervised learning and probabilistic models

**Week 1, k-means.** Objective $J = \sum_i \lVert \mathbf{x}_i - \boldsymbol{\mu}_{z_i} \rVert^2$. Lloyd's algorithm alternates assignment to the nearest center and the move of each center to its cluster mean; $J$ never increases and the result is a local minimum that depends on initialization. k-means++ seeds each new center with probability proportional to $D(\mathbf{x})^2$.

**Week 2, other clusterings.** Agglomerative clustering with single (min), complete (max) or average linkage and the dendrogram cut at a height. DBSCAN: core, border and noise points from $\varepsilon$ and `min_pts` (the neighborhood includes the point itself).

**Weeks 3 and 4, mixtures and EM.** $p(x) = \sum_k \pi_k \mathcal{N}(x \mid \mu_k, \sigma_k^2)$. E-step: responsibilities $r_{ik} \propto \pi_k \mathcal{N}(x_i \mid \mu_k, \sigma_k^2)$. M-step with $N_k = \sum_i r_{ik}$: $\pi_k = N_k/n$, $\mu_k = \sum_i r_{ik} x_i / N_k$, $\sigma_k^2 = \sum_i r_{ik}(x_i - \mu_k)^2 / N_k$. EM never decreases the likelihood and can end in a local maximum.

**Weeks 5 and 6, PCA and embeddings.** Center, form $\mathbf{S} = \mathbf{X}_c^\top\mathbf{X}_c/(n-1)$; components are its eigenvectors; $\lambda_j = \sigma_j^2/(n-1)$ for the singular values of $\mathbf{X}_c$. Classical MDS double-centers squared distances; t-SNE matches neighbor probabilities by minimizing $\mathrm{KL}(P \Vert Q)$; UMAP matches a fuzzy neighbor graph. Do not read cluster sizes or gaps in the map.

**Weeks 7 and 8, factorization and anomalies.** $\hat r_{ui} = \mathbf{p}_u^\top\mathbf{q}_i$ fitted on observed entries, by SGD or by ridge-regression ALS, whose objective never increases. Anomalies: modified z-score with the median and MAD, Mahalanobis distance, k-nearest-neighbor distance, isolation score $2^{-E[h]/c(n)}$.

**Weeks 9 and 10, hidden Markov models.** $P(\mathbf{z},\mathbf{o}) = \pi_{z_1}B_{z_1}(o_1)\prod_t A_{z_{t-1}z_t}B_{z_t}(o_t)$. Forward: $\alpha_t(j) = [\sum_i \alpha_{t-1}(i)A_{ij}]B_j(o_t)$, likelihood $\sum_j \alpha_T(j)$. Viterbi: replace the sum by a maximum, keep backpointers, backtrack; use logarithms or scaling for long sequences.

**Weeks 11 and 12, graphical models and evaluation.** Bayesian network: $P(\mathbf{x}) = \prod_i P(x_i \mid \mathrm{pa}(x_i))$; queries by enumeration; explaining away in a collider. MRF: $P(\mathbf{x}) = \frac1Z\prod_c\phi_c$. Evaluation: silhouette, BIC $= p\ln n - 2\ln L$, AIC $= 2p - 2\ln L$, adjusted Rand index, stability.

**Self-check.**
- Can you run two iterations of k-means and of EM by hand on a five-point example?
- Can you compute principal components of a small data set and the fraction of variance explained?
- Can you decode an HMM sequence and answer a query in a small network?
- Can you name two reasons that a clustering with a high silhouette may still be misleading?

**Common errors.** Forgetting to standardize; trusting one initialization; using the training likelihood to choose $K$; reading distances between clusters in a t-SNE map; forgetting $\lambda$ in ALS; summing over the wrong index in the forward recursion; omitting normalization in a query; calling an anomaly an error.

model:
```python
from math import sqrt


def best_k(points, inits):
    """Pick k by the mean silhouette of k-means started from fixed centers."""

    def d2(a, b):
        return sum((x - y) ** 2 for x, y in zip(a, b))

    def lloyd(centers):
        centers = [list(c) for c in centers]
        for _ in range(100):
            labels = []
            for p in points:
                dists = [d2(p, c) for c in centers]
                labels.append(dists.index(min(dists)))
            new = []
            for j, c in enumerate(centers):
                members = [p for p, l in zip(points, labels) if l == j]
                if members:
                    c = [sum(col) / len(members) for col in zip(*members)]
                new.append(c)
            if new == centers:
                break
            centers = new
        labels = []
        for p in points:
            dists = [d2(p, c) for c in centers]
            labels.append(dists.index(min(dists)))
        return labels

    def silhouette(labels):
        scores = []
        for i, p in enumerate(points):
            groups = {}
            for j, q in enumerate(points):
                if j != i:
                    groups.setdefault(labels[j], []).append(sqrt(d2(p, q)))
            if labels[i] not in groups:
                scores.append(0.0)
                continue
            a = sum(groups[labels[i]]) / len(groups[labels[i]])
            b = min(sum(d) / len(d) for k, d in groups.items() if k != labels[i])
            scores.append((b - a) / max(a, b))
        return sum(scores) / len(scores)

    best_k_value, best_score = None, None
    for k in sorted(inits):
        score = silhouette(lloyd(inits[k]))
        if best_score is None or score > best_score + 1e-12:
            best_k_value, best_score = k, score
    return best_k_value
```
hint: Break the problem into three small functions: one Lloyd run from given centers, one silhouette score for a labeling, and a loop over the candidate `k` in increasing order that keeps the best score.
solution: The pipeline combines Lloyd's algorithm (week 1) with the silhouette (week 12). Looping over `k` in increasing order and replacing the best only on a strictly higher score gives the smallest `k` on ties. On the six points $0, 1, 10, 11, 20, 21$ the three-cluster solution has mean silhouette about 0.90, while two clusters give about 0.38 and four give about 0.60, so $k = 3$ wins; a function that picks the smallest objective $J$ would choose the largest $k$.

@exam self
prompt: An analyst clusters 5,000 customers described by annual spend in euros (values in the thousands) and visits per month (values from 1 to 30). She runs k-means once with $k = 4$ on the raw numbers, finds a mean silhouette of 0.9, and reports "four customer types" to management. Write a critique of this analysis in one paragraph, and list the steps, with the evidence each would give, that you would take before the segmentation is used for decisions.
hint: Think about the scales of the two features, the number of runs, how $k$ was chosen, the meaning of a silhouette, and how to check the result.
solution: The analysis has several weaknesses. Annual spend is in the thousands and visits are below 30, so the squared Euclidean distance is almost entirely determined by spend and the visits feature has no influence: the "four types" are four spend bands, not behavior types, and the high silhouette reflects well-separated values on one dimension. The analyst ran k-means once, from one initialization, which can end in a poor local minimum; she gives no reason for $k = 4$; and a high silhouette measures separation under this distance and does not show that the groups are real categories. Before using the result I would standardize both features (or use a scale-aware distance) and rerun; run k-means++ with many restarts and keep the lowest objective; compare $k = 2$ to $8$ by the silhouette, the elbow of the objective and, with a Gaussian mixture, by BIC or held-out likelihood; measure stability by clustering bootstrap resamples and computing the adjusted Rand index between runs; check for outliers that distort the centers; describe each cluster by its feature averages and ask a domain expert whether the groups make sense; and test whether the segments predict something the business cares about, such as response to an offer, on held-out customers.

rubric: Points out that a single run, an unjustified $k$ and a high silhouette do not show that the segments are real or stable.

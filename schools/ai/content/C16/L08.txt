@article
A server logs how many seconds each request takes: $10, 11, 9, 10, 12, 30$. One request, the last, looks wrong, but nobody labeled it. **Anomaly detection** (outlier detection) scores how unusual each point is, using only data that is mostly normal. There are no labels, so every method rests on an assumption about what "normal" looks like.

### Distance from the bulk: z-scores and their failure

The **z-score** $z = (x - \bar{x})/s$ measures how many standard deviations a point is from the mean; the common "3-sigma" rule flags $\lvert z \rvert > 3$. For the request times, $\bar{x} = 13.67$ and the population standard deviation is $s = 7.36$, so the z-score of 30 is $2.22$: **not flagged**. The outlier inflated the mean and the standard deviation, which hid it, an effect called **masking**. A sample of $n$ points can never produce a population z-score above $\sqrt{n-1}$, which is $2.24$ for $n = 6$, so the 3-sigma rule cannot flag anything in so small a sample.

Robust statistics repair this. Replace the mean by the **median** and the standard deviation by the **median absolute deviation** $\mathrm{MAD} = \operatorname{median}_i \lvert x_i - \tilde{x} \rvert$. The **modified z-score** is
$$M_i = \frac{0.6745\,(x_i - \tilde{x})}{\mathrm{MAD}},$$
where $0.6745$ makes the MAD comparable to a standard deviation for Gaussian data; a cutoff of $3.5$ is conventional. For the request times the median is $10.5$, the absolute deviations are $0.5, 0.5, 1.5, 0.5, 1.5, 19.5$, so $\mathrm{MAD} = 1.0$ and $M = 0.6745 \times 19.5 / 1 = 13.2$: clearly flagged.

### Mahalanobis distance

In several dimensions, a point can be unremarkable on each feature and still unusual in combination. The **Mahalanobis distance** to a distribution with mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$ is
$$d_M(\mathbf{x})^2 = (\mathbf{x} - \boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu}).$$
It rescales each direction by its spread and accounts for correlation. For Gaussian data in $d$ dimensions $d_M^2$ follows a chi-squared distribution with $d$ degrees of freedom, so in two dimensions about 5% of normal points have $d_M^2 > 5.99$. Using the same Gaussian as a density model and flagging low density is equivalent. With a heavy outlier cluster the estimated $\boldsymbol{\mu}$ and $\boldsymbol{\Sigma}$ are themselves distorted, which is masking again; robust covariance estimates address it.

### Neighbors and density

The **$k$-nearest-neighbor score** of a point is its distance to its $k$-th nearest neighbor: isolated points have large scores. It makes no Gaussian assumption but treats a sparse region as anomalous even if that region is simply a different cluster. The **local outlier factor** (Breunig and colleagues, 2000) compares a point's local density with that of its neighbors, so a point is anomalous only relative to its surroundings, which handles clusters of different density.

### Isolation forests

The **isolation forest** (Liu, Ting and Zhou, 2008) turns the idea around: anomalies are few and different, so they are *easy to isolate*. Build many random trees; each split picks a random feature and a random threshold between that feature's minimum and maximum in the current node. The **path length** $h(\mathbf{x})$ is the number of splits needed to isolate $\mathbf{x}$ in a tree. Averaging over trees gives $E[h(\mathbf{x})]$, which is short for anomalies. To compare across sample sizes $n$, normalize by the average path length of an unsuccessful search in a binary search tree,
$$c(n) = 2\big(\ln(n-1) + \gamma\big) - \frac{2(n-1)}{n}, \qquad \gamma \approx 0.5772,$$
and define the **anomaly score**
$$s(\mathbf{x}, n) = 2^{-E[h(\mathbf{x})]/c(n)} .$$
A score near 1 means anomalous; a score well below 0.5 means normal; scores near 0.5 for all points mean the data have no distinct anomalies. For $n = 256$, $c(256) = 10.245$, so an average path length of $4$ gives $s = 2^{-0.390} = 0.763$ and an average path length of $9$ gives $s = 0.544$.

### Choosing a threshold, and its limits

Scores must be turned into flags by a threshold, usually the top fraction of scores (a **contamination** rate), or a chi-squared quantile for Mahalanobis. Without labels you cannot measure precision or recall directly; with a few labeled anomalies you can, and because anomalies are rare, accuracy is useless (flagging nothing is 99% accurate when 1% are anomalies). Prefer precision and recall at a chosen number of alerts. Finally, "anomalous" does not mean "bad": a flagged point can be a data error, a rare but legitimate event, or a new kind of normal behavior, and a person must decide which.

@example
title: Modified z-scores
problem: Which of the values $4, 5, 5, 6, 8, 40$ are flagged by the modified z-score with the cutoff $3.5$?
step: Sort: $4, 5, 5, 6, 8, 40$. The median is $(5 + 6)/2 = 5.5$.
step: Absolute deviations from 5.5: $1.5, 0.5, 0.5, 0.5, 2.5, 34.5$. Sorted: $0.5, 0.5, 0.5, 1.5, 2.5, 34.5$, so $\mathrm{MAD} = (0.5 + 1.5)/2 = 1.0$.
step: Modified z-scores $0.6745 (x - 5.5)/1$: $-1.01, -0.34, -0.34, 0.34, 1.69, 23.27$.
step: Only 40 exceeds 3.5 in absolute value. (The ordinary z-score of 40 is only $2.23$ here, using the population standard deviation $12.9$, so the 3-sigma rule would miss it.)
answer: Only the value 40 is flagged ($M \approx 23.3$).

@example
title: Same distance, different Mahalanobis distance
problem: Data have mean $(0, 0)$ and covariance $\boldsymbol{\Sigma} = \begin{pmatrix} 4 & 2 \\ 2 & 3 \end{pmatrix}$. Compare the points $(2, 2)$ and $(2, -2)$, which are the same Euclidean distance from the mean.
step: The determinant is $4 \cdot 3 - 2 \cdot 2 = 8$, so $\boldsymbol{\Sigma}^{-1} = \tfrac{1}{8}\begin{pmatrix} 3 & -2 \\ -2 & 4 \end{pmatrix}$.
step: The quadratic form is $d_M^2 = \tfrac18 (3x^2 - 4xy + 4y^2)$.
step: At $(2, 2)$: $\tfrac18(12 - 16 + 16) = 1.5$. At $(2, -2)$: $\tfrac18(12 + 16 + 16) = 5.5$.
step: The features are positively correlated, so a point along the diagonal $(2,2)$ is typical, while $(2, -2)$ goes against the correlation and is much more unusual, though it is no farther away in the ordinary sense.
answer: $d_M^2 = 1.5$ for $(2, 2)$ and $5.5$ for $(2, -2)$.

@mistakes
- Trusting the 3-sigma rule on small samples or with several outliers: the outliers inflate the mean and standard deviation and mask themselves.
- Using Euclidean distance on correlated or differently scaled features: a point against the correlation can be far more unusual than its raw distance suggests.
- Reporting accuracy for a detector of rare events: a detector that flags nothing is almost perfectly accurate.
- Treating every flagged point as an error: an anomaly is a point that is unusual under the model, which may be a rare real event.

```python
def robust_outliers(xs, threshold):
    """Indices flagged by the modified z-score (median and MAD)."""

    def median(values):
        s = sorted(values)
        n = len(s)
        return s[n // 2] if n % 2 else (s[n // 2 - 1] + s[n // 2]) / 2

    med = median(xs)
    mad = median([abs(x - med) for x in xs])
    if mad == 0:
        return []
    return [i for i, x in enumerate(xs)
            if abs(0.6745 * (x - med) / mad) > threshold]
```

solution: The median of an even-length list averages the two middle values. The tests include an even-length list, a list where the ordinary 3-sigma rule fails (the second), a MAD of zero, and a low threshold in the last test that flags both 6 and 30.

```python
def mahalanobis_sq(x, mean, cov):
    """Squared Mahalanobis distance of a 2-D point."""
    a, b = cov[0]
    c, d = cov[1]
    det = a * d - b * c
    inv = [[d / det, -b / det], [-c / det, a / det]]
    dx = [x[0] - mean[0], x[1] - mean[1]]
    return sum(dx[i] * inv[i][j] * dx[j] for i in range(2) for j in range(2))
```
hint: The inverse of $\begin{pmatrix} a & b \\ c & d \end{pmatrix}$ is $\frac{1}{ad - bc}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix}$. Then compute the quadratic form of the centered point.
solution: Invert the covariance with the 2 by 2 formula, subtract the mean from the point and evaluate $\mathbf{d}^\top \boldsymbol{\Sigma}^{-1}\mathbf{d}$. The starter returns the squared Euclidean distance, which passes only the identity-covariance case; the second and third tests share a Euclidean distance but need different answers.

model:
```python
from math import sqrt


def knn_scores(points, k):
    """Distance from each point to its k-th nearest other point."""
    scores = []
    for i, p in enumerate(points):
        dists = sorted(sqrt(sum((a - b) ** 2 for a, b in zip(p, q)))
                       for j, q in enumerate(points) if j != i)
        scores.append(dists[k - 1])
    return scores
```
hint: For each point, sort its distances to all the other points and take the entry at position `k - 1`.
solution: Excluding the point itself matters: its distance to itself is 0 and would take the place of the nearest neighbor. The fourth test has two identical points, whose nearest-neighbor distance is 0 even though both are far from the third.

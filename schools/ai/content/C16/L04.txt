@article
If we knew which component produced each point, fitting a mixture would be easy: average the points of each component. If we knew the parameters, finding the components would be easy: compute responsibilities. We know neither, so the **expectation-maximization (EM) algorithm** (Dempster, Laird and Rubin, 1977) alternates between the two guesses.

### The algorithm for a Gaussian mixture

Start from initial parameters $\{\pi_k, \mu_k, \sigma_k^2\}$ and repeat:

**E-step (expectation).** Compute the responsibility of each component for each point with the current parameters,
$$r_{ik} = \frac{\pi_k\, \mathcal{N}(x_i \mid \mu_k, \sigma_k^2)}{\sum_j \pi_j\, \mathcal{N}(x_i \mid \mu_j, \sigma_j^2)} .$$

**M-step (maximization).** Treat the responsibilities as fractional counts and re-estimate the parameters. With $N_k = \sum_{i=1}^{n} r_{ik}$, the **effective number of points** of component $k$,
$$\pi_k = \frac{N_k}{n}, \qquad \mu_k = \frac{1}{N_k} \sum_i r_{ik}\, x_i, \qquad \sigma_k^2 = \frac{1}{N_k} \sum_i r_{ik}\,(x_i - \mu_k)^2 ,$$
where the variance uses the **new** mean. These are the weighted versions of the ordinary formulas for the proportion, the mean and the variance of a single Gaussian. In $d$ dimensions the last formula becomes $\boldsymbol{\Sigma}_k = \frac{1}{N_k}\sum_i r_{ik} (\mathbf{x}_i - \boldsymbol{\mu}_k)(\mathbf{x}_i - \boldsymbol{\mu}_k)^\top$.

### One iteration on four numbers

Take the data $1, 2, 6, 7$ with initial parameters $\pi = (0.5, 0.5)$, means $(0, 5)$ and variances $(1, 1)$. The E-step gives responsibilities for the first component of $0.9994$, $0.9241$, $0.0000$ and $0.0000$ for the four points; the second component takes the rest. Then $N_1 = 1.9235$ and $N_2 = 2.0764$, so $\pi = (0.4809, 0.5191)$. The new means are $\mu_1 = 1.4804$ and $\mu_2 = 6.3341$, and the new variances are $\sigma_1^2 = 0.2496$ and $\sigma_2^2 = 0.9611$. The log-likelihood rises from $-11.369$ to $-6.316$ nats. After a few more iterations the parameters settle at $\pi = (0.5, 0.5)$, means $(1.5, 6.5)$ and variances $(0.25, 0.25)$, with log-likelihood $-5.676$.

### Why the likelihood never decreases

Let $q_i(k)$ be any distribution over the hidden label of point $i$. By Jensen's inequality, since $\log$ is concave,
$$\ell(\boldsymbol{\theta}) = \sum_i \log \sum_k q_i(k)\, \frac{\pi_k\, \mathcal{N}(x_i \mid \mu_k, \sigma_k^2)}{q_i(k)} \;\ge\; \sum_i \sum_k q_i(k) \log \frac{\pi_k\, \mathcal{N}(x_i \mid \mu_k, \sigma_k^2)}{q_i(k)} =: F(q, \boldsymbol{\theta}).$$
The right side $F$ is a lower bound on the log-likelihood (often called the evidence lower bound, ELBO). Equality holds exactly when $q_i(k)$ equals the posterior $P(z_i = k \mid x_i, \boldsymbol{\theta})$. The two steps are coordinate ascent on $F$:

- The **E-step** sets $q$ to the posterior (the responsibilities) for the current $\boldsymbol{\theta}$, which makes the bound touch the likelihood: $F = \ell(\boldsymbol{\theta}_{\text{old}})$.
- The **M-step** maximizes $F$ over $\boldsymbol{\theta}$ with $q$ fixed, so $F(q, \boldsymbol{\theta}_{\text{new}}) \ge F(q, \boldsymbol{\theta}_{\text{old}})$.

Chaining these, $\ell(\boldsymbol{\theta}_{\text{new}}) \ge F(q, \boldsymbol{\theta}_{\text{new}}) \ge F(q, \boldsymbol{\theta}_{\text{old}}) = \ell(\boldsymbol{\theta}_{\text{old}})$. **The EM algorithm never decreases the likelihood.** The likelihood is bounded above when variances are kept away from zero, so the sequence of likelihood values converges; under mild conditions the parameters approach a stationary point of the likelihood, usually a local maximum and not necessarily the global one.

### Practical matters

- **Initialization matters.** Different starting parameters can reach different local maxima. A common recipe is to initialize the means with k-means (or k-means++) and run EM from several starts, keeping the highest likelihood.
- **Singularities.** If a component collapses onto a single point, its variance goes to 0 and the likelihood to infinity. Add a small floor to each variance, such as $10^{-6}$, or use a prior.
- **Stopping.** Stop when the log-likelihood improves by less than a small tolerance, say $10^{-6}$, or after a maximum number of iterations.
- **Hard EM.** Replacing the responsibilities by 0/1 indicators of the most probable component gives the k-means algorithm, for equal spherical components.
- EM is general: it fits any model with latent variables whose complete-data problem is easy, such as mixtures of other distributions and hidden Markov models (Lesson 9).

### In code

```python
from math import exp, log, pi, sqrt

def normal(x, m, v):
    return exp(-(x - m) ** 2 / (2 * v)) / sqrt(2 * pi * v)

def em_step(data, w, m, v):
    K, n = len(w), len(data)
    resp = []
    for x in data:                                  # E-step
        p = [w[k] * normal(x, m[k], v[k]) for k in range(K)]
        resp.append([pk / sum(p) for pk in p])
    nk = [sum(r[k] for r in resp) for k in range(K)]            # M-step
    m = [sum(r[k] * x for r, x in zip(resp, data)) / nk[k] for k in range(K)]
    v = [sum(r[k] * (x - m[k]) ** 2 for r, x in zip(resp, data)) / nk[k]
         for k in range(K)]
    return [c / n for c in nk], m, v

params = ([0.5, 0.5], [0.0, 5.0], [1.0, 1.0])
for _ in range(3):
    params = em_step([1, 2, 6, 7], *params)
    print([round(a, 4) for a in params[1]])
```

@mistakes
- Using the old mean in the variance update: the M-step variance is the weighted spread around the new mean $\mu_k$.
- Dividing the M-step sums by $n$ instead of $N_k$: the weighted mean and variance divide by the component's effective count.
- Expecting EM to find the global optimum: it climbs the likelihood from its starting point and can stop at a local maximum.
- Ignoring a collapsing component: when a variance shrinks toward 0 the likelihood explodes and the fit is meaningless; floor the variances.

from math import exp, pi, sqrt


def e_step(data, weights, means, variances):
    """Responsibilities r[i][k] for a 1-D Gaussian mixture."""
    rows = []
    for x in data:
        parts = [w * exp(-(x - m) ** 2 / (2 * v)) / sqrt(2 * pi * v)
                 for w, m, v in zip(weights, means, variances)]
        total = sum(parts)
        rows.append([p / total for p in parts])
    return rows
```

def m_step(data, resp):
    """Weights, means and variances that maximize the expected log-likelihood."""
    n = len(data)
    K = len(resp[0])
    weights, means, variances = [], [], []
    for k in range(K):
        nk = sum(r[k] for r in resp)
        mu = sum(r[k] * x for r, x in zip(resp, data)) / nk
        var = sum(r[k] * (x - mu) ** 2 for r, x in zip(resp, data)) / nk
        weights.append(nk / n)
        means.append(mu)
        variances.append(var)
    return weights, means, variances
```

```python
from math import exp, pi, sqrt


def em_fit(data, weights, means, variances, iters):
    """Run `iters` EM iterations for a 1-D Gaussian mixture."""
    n, K = len(data), len(weights)
    for _ in range(iters):
        resp = []
        for x in data:
            parts = [weights[k] * exp(-(x - means[k]) ** 2 / (2 * variances[k]))
                     / sqrt(2 * pi * variances[k]) for k in range(K)]
            total = sum(parts)
            resp.append([p / total for p in parts])
        nk = [sum(r[k] for r in resp) for k in range(K)]
        means = [sum(r[k] * x for r, x in zip(resp, data)) / nk[k]
                 for k in range(K)]
        variances = [sum(r[k] * (x - means[k]) ** 2
                         for r, x in zip(resp, data)) / nk[k] for k in range(K)]
        weights = [c / n for c in nk]
    return weights, means, variances
```
hint: In each iteration compute the responsibilities from the current parameters, then replace all three parameter lists at once from the weighted sums.
solution: One iteration is an E-step followed by an M-step, and the parameters are replaced only after the responsibilities are known. The single-component test shows that one Gaussian is fitted in one step (the sample mean 2 and variance 2/3), and the third test checks one iteration from a mixed start with unequal weights.

```python
from math import exp, log, pi, sqrt


def mixture_loglik(data, weights, means, variances):
    """Log-likelihood of 1-D data under a Gaussian mixture."""
    total = 0.0
    for x in data:
        density = sum(w * exp(-(x - m) ** 2 / (2 * v)) / sqrt(2 * pi * v)
                      for w, m, v in zip(weights, means, variances))
        total += log(density)
    return total
```

solution: The logarithm is applied to the mixture density of each point, not to each component. The tests include the log-likelihoods before and after one EM iteration on a small data set, and check that it increased.

@article
Variables vanish when a program ends. A **file** keeps data on disk so a program can read it later or hand it to another program. Real data sets, from sensor readings to survey answers, usually arrive as text files.

### Opening files

`open(name, mode)` gives you a file object. The mode says what you intend to do:

| Mode | Meaning |
|---|---|
| `"r"` (default) | read; the file must exist |
| `"w"` | write; **creates the file, or erases it if it already exists** |
| `"a"` | append; add to the end of an existing file |

Always open files with a `with` block. It closes the file when the block ends, even if an error occurs, and closing is what makes sure the data is really written:

```python
with open("scores.txt", "w") as f:
    f.write("ana,90\n")
    f.write("ben,72\n")

with open("scores.txt") as f:
    text = f.read()
```

`write` does not add a newline; you write `"\n"` yourself. `f.read()` returns the whole file as one string, and `text.splitlines()` splits it into a list of lines without the `\n` characters. You can also loop with `for line in f:`, but the lines then keep their trailing newline, so call `line.strip()`.

(On this site the files live in the browser's memory, but the same code works on real files on your computer.)

### Turning lines into data

A common format is **CSV**, comma-separated values: one record per line, fields separated by commas. Everything read from a file is a string, so convert the numbers:

```python
line = "ana,90"
name, score = line.split(",")
score = int(score)           # use float(...) for decimals
```

### Real data is messy

Real files contain blank lines, header rows, missing values and typos. A program that crashes on the first bad line is not much use, so decide what to do and make it explicit:

```python
def parse_scores(text):
    scores = {}
    for line in text.splitlines():
        if not line.strip():
            continue                      # skip blank lines
        parts = line.split(",")
        if len(parts) != 2:
            continue                      # skip malformed lines
        try:
            scores[parts[0].strip()] = int(parts[1])
        except ValueError:
            pass                          # skip a non-numeric score
    return scores
```

`continue` jumps straight to the next pass of the loop. `int("x")` raises `ValueError`, which the `try`/`except` catches. Notice that this function takes the *text*, not a file name: separating *reading* from *parsing* makes the parsing easy to test with `assert`.

### Summarizing with dictionaries

Once the data is parsed, the counting and grouping patterns from the last lesson do the analysis: a dictionary of totals per group, a dictionary of lists, a count per category. Analyzing a data file is nearly always the same three steps: **read, parse, summarize**.

@example
title: Write, then read
problem: What does this program print?

```python
with open("log.txt", "w") as f:
    f.write("a\nb\n")
with open("log.txt", "a") as f:
    f.write("c\n")
with open("log.txt") as f:
    lines = f.read().splitlines()
print(len(lines), lines[-1])
```
step: Mode `"w"` creates `log.txt` and writes the two lines `a` and `b`.
step: Mode `"a"` adds `c` after them without erasing anything, so the file holds three lines.
step: `read()` returns `"a\nb\nc\n"`, and `splitlines()` turns it into `['a', 'b', 'c']`.
step: `len(lines)` is 3 and `lines[-1]` is the last line, `c`.
answer: `3 c`

@example
title: Totals per group
problem: A text holds lines `group,value`. Write `group_totals(text)` that returns a dictionary of the total value of each group.
step: Split the text into lines, and for each non-blank line split at the comma into a group name and a value.
step: The value is a string, so convert it with `int` before adding.
step: Use the counting pattern, but add the value instead of 1:

```python
def group_totals(text):
    totals = {}
    for line in text.splitlines():
        if not line.strip():
            continue
        group, value = line.split(",")
        totals[group] = totals.get(group, 0) + int(value)
    return totals
```
step: Check: for `"a,1\nb,4\na,3\n"` the totals are `{'a': 4, 'b': 4}`.

@mistakes
- Opening a file with mode `"w"` when you meant `"a"`, which erases what was already there.
- Forgetting that everything read from a file is a string, so `"90" + "5"` joins text instead of adding numbers.
- Leaving the newline on each line (`"ana,90\n"`) and being surprised when comparisons or conversions behave oddly.
- Writing code that crashes on a blank last line or a header row instead of skipping it.

```python
def count_lines(filename):
    with open(filename) as f:

    count = 0
    for line in text.splitlines():
        if line.strip():
            count += 1
    return count
```

```python
def load_scores(filename):
    scores = {}
    with open(filename) as f:

```

@quiz code
prompt: Write `group_averages(filename)` that reads a text file whose lines look like `group,value`, where `value` is a number such as `3` or `2.5`, and returns a dictionary mapping each group name to the average of its values as a float. Every line is valid; ignore blank lines. An empty file gives `{}`.

```python
def group_averages(filename):

```
tests:
```python
write_file("g.txt", "a,1\nb,4\na,3\n")
assert group_averages("g.txt") == {"a": 2.0, "b": 4.0}
write_file("h.txt", "x,2.5\n\nx,3.5\ny,10\n")

```
model:
```python
def group_averages(filename):
    with open(filename) as f:
        text = f.read()
    totals = {}
    counts = {}
    for line in text.splitlines():
        if not line.strip():
            continue
        group, value = line.split(",")
        totals[group] = totals.get(group, 0) + float(value)
        counts[group] = counts.get(group, 0) + 1
    return {g: totals[g] / counts[g] for g in totals}
```
hint: You need two dictionaries: the total of each group and the number of values in each group.
hint: After reading all lines, divide each group's total by its count.
solution: Keep a running total and a count per group using the counting pattern, converting each value with `float`. At the end, build a dictionary of `total / count` for every group, which gives floats such as `2.0`.

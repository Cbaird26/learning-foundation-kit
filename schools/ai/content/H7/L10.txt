@article
The **central dogma** says information flows from DNA to RNA to protein: **replication** copies DNA, **transcription** copies a gene into RNA and **translation** builds a protein from mRNA.

### DNA structure and replication

A DNA **nucleotide** has a deoxyribose sugar, a phosphate and a base (A, T, G, C). DNA is a **double helix** of two **antiparallel** strands (one runs 5' to 3', the other 3' to 5'). Bases pair by hydrogen bonds: **A with T** (2 bonds) and **G with C** (3 bonds). **Chargaff's rules**: in double-stranded DNA, %A = %T and %G = %C.

Replication is **semiconservative**: each new double helix has one old strand and one new strand. **Helicase** unwinds the helix, **primase** lays an RNA primer, **DNA polymerase** adds nucleotides only in the 5' to 3' direction (the lagging strand is made in **Okazaki fragments**), and **ligase** seals gaps.

### Transcription

**RNA polymerase** reads the **template strand** 3' to 5' and builds mRNA 5' to 3'. RNA uses **ribose**, and **uracil (U)** replaces T. So the mRNA has the same sequence as the coding (non-template) strand, with U for T. In eukaryotes the pre-mRNA is processed in the nucleus: a **5' cap**, a **poly-A tail** and **splicing** (removal of introns, keeping exons).

### Translation

Ribosomes read mRNA in **codons** (3 bases). The genetic code has 64 codons: **AUG** (start, methionine), three stops (**UAA, UAG, UGA**), and 61 others coding for 20 amino acids. The code is **redundant** (several codons per amino acid) but not ambiguous. **tRNA** carries an amino acid and has an **anticodon** that pairs with the codon. Steps: **initiation** (small subunit finds AUG), **elongation** (peptide bonds form; ribosome moves along), **termination** (stop codon; the release factor ends it).

A few codons: UUU Phe, GGU Gly, CCC Pro, AAA Lys, GAA Glu, UGG Trp, CCA Pro.

### Mutations

- **Silent:** codon changes but amino acid does not.
- **Missense:** a different amino acid (sickle cell: GAG to GUG, Glu to Val).
- **Nonsense:** a stop codon appears early, giving a short protein.
- **Frameshift:** insertion or deletion of a number of nucleotides not divisible by 3 changes every codon downstream.

@example
title: Transcribe and translate
problem: A template strand reads 3'-TAC TTT GGG CCA ATT-5'. Write the mRNA and the peptide.
step: Transcription pairs bases with the template: T to A, A to U, C to G, G to C. TAC TTT GGG CCA ATT becomes AUG AAA CCC GGU UAA.
step: The mRNA is written 5'-AUG AAA CCC GGU UAA-3'. Read it in codons from the start codon.
step: AUG is Met, AAA is Lys, CCC is Pro, GGU is Gly, and UAA is a stop codon.
step: The peptide is Met-Lys-Pro-Gly (4 amino acids), and the stop codon does not code for an amino acid.

@mistakes
- Putting T in mRNA; RNA uses uracil.
- Reading the template strand's own sequence as the mRNA; the mRNA is complementary to the template.
- Counting the stop codon as an amino acid.
- Thinking a mutation always changes the protein; silent mutations do not.

@practice num
prompt: In a sample of double-stranded DNA, 30% of the bases are adenine. What percentage are guanine?
answer: 20
check: (100 - 2 * 30) / 2
unit: %
hint: A pairs with T, so %T equals %A.
solution: A + T = 60%, leaving 40% for G + C, and G = C, so G = 20%.

@practice num
prompt: A protein consists of 100 amino acids. How many nucleotides are in the mRNA coding region including the stop codon?
answer: 303
check: 100 * 3 + 3
hint: Each amino acid needs one codon.
solution: $100 \times 3 = 300$ nucleotides for the amino acids, plus 3 for the stop codon, giving 303.

choice*: A frameshift that alters many downstream amino acids
choice: No effect because the code is redundant
hint: What happens to the reading frame when one nucleotide is removed?
solution: Deleting one nucleotide shifts the reading frame for every downstream codon, usually producing a nonfunctional protein.

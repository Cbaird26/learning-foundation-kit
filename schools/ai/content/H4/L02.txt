@article
Two ideas turn single functions into a toolbox: **composition** (feeding one function into another) and **inverses** (undoing a function).

### Composition

$$(f \circ g)(x) = f(g(x)).$$

Read it from the inside out: apply $g$ first, then apply $f$ to the result. If $f(x) = x^2$ and $g(x) = x + 1$, then

$$(f \circ g)(x) = (x+1)^2, \qquad (g \circ f)(x) = x^2 + 1.$$

These are different functions, so **order matters**.

The **domain** of $f \circ g$ has two conditions: $x$ must be in the domain of $g$, and $g(x)$ must be in the domain of $f$. For $f(x) = \sqrt{x}$ and $g(x) = x - 4$, we need $g(x) \ge 0$, so the domain of $f \circ g$ is $x \ge 4$.

### Decomposition: seeing the layers

Going backwards is just as useful. In $h(x) = (2x - 5)^4$ the first thing done to $x$ is $2x - 5$ (inner function $g$), and then the result is raised to the fourth power (outer function $f(u) = u^4$). Spotting the layers is exactly the skill the chain rule will need in calculus.

### Inverse functions

A function $f$ has an **inverse** $f^{-1}$ if it undoes $f$:

$$f^{-1}(f(x)) = x \quad\text{and}\quad f\big(f^{-1}(y)\big) = y.$$

An inverse exists only when $f$ is **one-to-one**: different inputs give different outputs. On a graph, this is the *horizontal line test*: no horizontal line may cross the graph twice.

To find $f^{-1}$:

1. Write $y = f(x)$.
2. Swap the letters $x$ and $y$.
3. Solve for $y$.
4. Check by composing: $f(f^{-1}(x)) = x$.

Three facts to remember:

- **Domain and range swap.** The domain of $f^{-1}$ is the range of $f$, and vice versa.
- **The graph of $f^{-1}$ is the reflection of the graph of $f$ in the line $y = x$**, because the point $(a, b)$ on $f$ becomes $(b, a)$ on $f^{-1}$.
- **$f^{-1}(x)$ is not $1/f(x)$.** The "$-1$" marks an inverse function, not a reciprocal.

### Restricting a domain

$f(x) = x^2$ fails the horizontal line test, since $f(-3) = f(3)$. But on the restricted domain $x \ge 0$ it is one-to-one, with inverse $f^{-1}(x) = \sqrt{x}$. Restricting the domain to make an inverse is a standard move you will see again with trigonometric functions.

When two functions are composed, the inverse undoes the steps in reverse order, like taking off shoes and socks: $(f \circ g)^{-1} = g^{-1} \circ f^{-1}$.

@example
title: Finding the inverse of a rational function
problem: Find the inverse of $f(x) = \dfrac{x+1}{x-2}$ and verify it.
step: Write $y = \dfrac{x+1}{x-2}$ and swap the letters: $x = \dfrac{y+1}{y-2}$.
step: Clear the fraction: $x(y - 2) = y + 1$, so $xy - 2x = y + 1$.
step: Collect the $y$-terms on one side: $xy - y = 2x + 1$, so $y(x - 1) = 2x + 1$.
step: Divide: $f^{-1}(x) = \dfrac{2x+1}{x-1}$.
step: Verify: $f(f^{-1}(x)) = \dfrac{\frac{2x+1}{x-1} + 1}{\frac{2x+1}{x-1} - 2} = \dfrac{3x/(x-1)}{3/(x-1)} = x$.

@example
title: Composite and its domain
problem: Let $f(x) = \dfrac{1}{x - 2}$ and $g(x) = \sqrt{x}$. Find $(f \circ g)(x)$ and its domain.
step: Substitute $g$ into $f$: $(f \circ g)(x) = f(\sqrt{x}) = \dfrac{1}{\sqrt{x} - 2}$.
step: The inner function $g$ needs $x \ge 0$.
step: The outer function $f$ needs its input to be nonzero after subtracting $2$: $\sqrt{x} - 2 \neq 0$, so $x \neq 4$.
step: Combine: the domain is $[0, 4) \cup (4, \infty)$.

@mistakes
- Applying the outer function first. In $f(g(x))$ the inner function $g$ acts on $x$ first.
- Writing $f^{-1}(x) = \dfrac{1}{f(x)}$. The inverse undoes $f$; the reciprocal is a different function.
- Swapping $x$ and $y$ but stopping before solving for $y$.
- Finding the domain of a composite from the final simplified formula only, and losing the restriction that comes from the inner function.

@article
A function is **recursive** if its body calls the function itself. This works when the problem can be split into a **smaller instance of the same problem**, plus a little extra work, and a smallest instance that can be answered directly.

### The two parts

```python
def fact(n):
    """Return n! for an integer n >= 0."""
    if n == 0:            # base case
        return 1
    return n * fact(n - 1)   # recursive case
```

- The **base case** answers the smallest instance without recursing. Without one the calls never stop.
- The **recursive case** calls the function on a strictly smaller instance and combines the result.

To convince yourself a recursive function is correct, check three things: the base case is right, each recursive call moves toward a base case, and *if* the call on the smaller instance is correct, the combination is correct (this is induction).

### The call stack

Each call gets its own frame with its own local variables, kept on the **call stack** until it returns. Evaluating `fact(3)` builds `3 * fact(2)`, then `2 * fact(1)`, then `1 * fact(0)`; when `fact(0)` returns `1` the frames finish in reverse order: `1`, `1 * 1`, `2 * 1`, `3 * 2`, giving `6`. Python limits the depth (the default limit is 1000 frames); exceeding it raises `RecursionError`, which is also what a missing base case eventually produces.

### Recursion on sequences

Strings and lists have natural smaller instances: everything except the first item.

```python
def reverse(s):
    if s == "":
        return ""
    return reverse(s[1:]) + s[0]
```

Slicing copies, so this is for understanding rather than for efficiency; and the depth equals the length of the string, so it only suits short inputs.

For nested data, recurse into the parts that are themselves nested. To flatten `[1, [2, [3]]]` into `[1, 2, 3]`, treat each item either as a list (flatten it recursively) or as a plain value:

```python
def flatten(x):
    result = []
    for item in x:
        if isinstance(item, list):
            result.extend(flatten(item))
        else:
            result.append(item)
    return result
```

### Several recursive calls

The Fibonacci numbers satisfy `fib(0) = 0`, `fib(1) = 1` and `fib(n) = fib(n-1) + fib(n-2)`. The direct translation makes **two** calls per level, so it recomputes the same values again and again: the number of calls grows exponentially (about $1.6^n$). A **memo** (a dictionary from argument to answer) remembers results:

```python
def fib(n, memo=None):
    if memo is None:
        memo = {}
    if n < 2:
        return n
    if n not in memo:
        memo[n] = fib(n - 1, memo) + fib(n - 2, memo)
    return memo[n]
```

Now each value is computed once, so the cost is linear in `n`. Python's `functools.cache` decorator does this for you. This technique, **memoization**, is the first step toward dynamic programming.

### Recursive thinking: Towers of Hanoi

To move `n` disks from peg `src` to peg `dst` using a spare peg: move `n - 1` disks to the spare, move the largest disk, then move the `n - 1` disks onto it. Each level does one move plus two smaller problems, so $2^n - 1$ moves are needed. Some problems are easier to write recursively than iteratively; others (like computing a factorial) are best written with a loop. Both styles solve the same problems.

@example
title: Tracing a recursive call
problem: What does this program print, and in what order do the calls finish?

```python
def total(n):
    if n == 0:
        return 0
    return n + total(n - 1)

print(total(3))
```
step: `total(3)` is not the base case, so it needs `3 + total(2)` and waits.
step: `total(2)` waits for `2 + total(1)`, and `total(1)` waits for `1 + total(0)`.
step: `total(0)` hits the base case and returns `0`.
step: Frames now return in reverse order: `total(1)` is `1 + 0 = 1`, `total(2)` is `2 + 1 = 3`, `total(3)` is `3 + 3 = 6`.
answer: `6`

@example
title: Designing a recursive function
problem: Write `count_char(s, c)` that returns how many times the single character `c` occurs in the string `s`, recursively.
step: Smallest instance: the empty string contains `c` zero times. That is the base case.
step: Otherwise split off the first character: the answer is `1` if `s[0] == c` (else `0`) plus the count in `s[1:]`.
step: Combine the two cases:

```python
def count_char(s, c):
    if s == "":
        return 0
    first = 1 if s[0] == c else 0
    return first + count_char(s[1:], c)
```
step: Trace `count_char("aba", "a")`: it is `1 + count_char("ba", "a")`, which is `1 + (0 + count_char("a", "a"))`, which is `1 + (0 + (1 + 0))`, so `2`.

@mistakes
- Forgetting the base case, or writing one that is never reached (for example recursing on `n + 1` instead of `n - 1`), which ends in `RecursionError`.
- Writing a recursive call and not using its result: `fact(n - 1)` on a line by itself computes a value and discards it.
- Expecting naive recursive Fibonacci to be fast: it makes an exponential number of calls.
- Mixing up the base case value: `fact(0)` must be `1`, not `0`, or every product becomes zero.

model:
```python
def hanoi_moves(n, src, dst, spare):
    if n == 0:
        return []
    first = hanoi_moves(n - 1, src, spare, dst)
    last = hanoi_moves(n - 1, spare, dst, src)
    return first + [(src, dst)] + last
```
hint: Swap the roles of the pegs in the two recursive calls.
hint: The first call moves `n - 1` disks from `src` to `spare` (so `dst` is the spare peg there); the second moves them from `spare` to `dst`.
solution: Return the moves for `n - 1` disks from `src` to `spare`, then the single move `(src, dst)`, then the moves for `n - 1` disks from `spare` to `dst`. The move count satisfies `T(n) = 2 T(n - 1) + 1`, which is `2**n - 1`.

def show(n):
    if n > 0:
        show(n // 2)
        print(n % 2, end="")

answer: 110

hint: The recursive call happens before the `print`, so the innermost call prints first.
solution: `show(6)` calls `show(3)`, which calls `show(1)`, then `show(0)`, which does nothing. Printing then happens on the way back: `1 % 2 = 1`, then `3 % 2 = 1`, then `6 % 2 = 0`. The output is `110`, the binary form of 6.

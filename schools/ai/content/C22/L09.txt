@article
A company randomly sends an encouragement email about a new feature to half of its users. Users choose whether to use the feature, and those who do are more engaged to begin with (a motive we cannot measure). Comparing feature users with non-users is confounded. But the email is random, and it changes feature use. Can we use that randomness to learn the effect of the feature itself?

### The setting and the assumptions

Let $Z$ be the **instrument** (the email), $T$ the treatment (feature use) and $Y$ the outcome (engagement), and $U$ the unmeasured confounders. The causal graph has nodes $Z, T, Y, U$ and edges $Z \to T$, $T \to Y$, $U \to T$, $U \to Y$. There is no edge $Z \to Y$ and no edge from $U$ to $Z$. The assumptions, each named, are:

1. **Relevance**: $Z$ affects $T$, so $\mathbb{E}[T \mid Z=1] \ne \mathbb{E}[T \mid Z=0]$.
2. **Independence** (as-if randomization): $Z$ is independent of the potential outcomes and potential treatments, so there is no confounding of $Z$ and $Y$.
3. **Exclusion restriction**: $Z$ affects $Y$ only through $T$ (no direct edge $Z \to Y$). Formally $Y(z, t) = Y(t)$.

Relevance can be checked from data; independence holds by design if $Z$ is randomized; the exclusion restriction can only be defended by argument (suppose the email also reminds users of a different product: it would violate exclusion).

### Linear model and the Wald estimator

Suppose $Y = \alpha + \beta T + U'$ with $\beta$ the same for everyone, where $U'$ includes the confounding and satisfies $\mathrm{Cov}(Z, U') = 0$ (independence and exclusion). Then $\mathrm{Cov}(Z, Y) = \beta\,\mathrm{Cov}(Z, T)$, so

$$\beta = \frac{\mathrm{Cov}(Z, Y)}{\mathrm{Cov}(Z, T)}.$$

For a binary instrument this is the **Wald estimator**:

$$\hat\beta_{\text{Wald}} = \frac{\mathbb{E}[Y \mid Z=1] - \mathbb{E}[Y \mid Z=0]}{\mathbb{E}[T \mid Z=1] - \mathbb{E}[T \mid Z=0]},$$

the effect of $Z$ on $Y$ (the intention-to-treat effect) divided by the effect of $Z$ on $T$ (the **first stage**). With two-stage least squares, the first stage regresses $T$ on $Z$ and the second regresses $Y$ on the fitted $\hat{T}$; with one binary instrument and one treatment this gives the Wald estimate.

Example: of users emailed, 60% use the feature and the mean engagement is 12.0; of users not emailed, 20% use it and the mean is 10.4. The ITT effect is $1.6$, the first stage is $0.4$, and $\hat\beta = 1.6/0.4 = 4.0$ units of engagement per feature user.

### Who is the effect for? LATE

If effects differ across people, the Wald estimator identifies an effect for a subgroup. Define each unit's **compliance type** by $(T(0), T(1))$:

| type | $T(0)$ | $T(1)$ | behavior |
|---|---|---|---|
| always-taker | 1 | 1 | uses the feature either way |
| never-taker | 0 | 0 | never uses it |
| complier | 0 | 1 | uses it only if emailed |
| defier | 1 | 0 | uses it only if not emailed |

Add **monotonicity** (no defiers: $T(1) \ge T(0)$ for every unit). **Theorem (Imbens and Angrist, 1994; Angrist, Imbens and Rubin, 1996).** Under relevance, independence, exclusion and monotonicity, the Wald estimator equals the **local average treatment effect**

$$\text{LATE} = \mathbb{E}[Y(1) - Y(0) \mid T(1) > T(0)],$$

the average effect among compliers. The reason: $\mathbb{E}[Y \mid Z=1] - \mathbb{E}[Y \mid Z=0] = \mathbb{E}[(T(1) - T(0))(Y(1) - Y(0))]$, and only compliers have $T(1) - T(0) \ne 0$ (it is 1), so the ITT effect equals $P(\text{complier}) \times \text{LATE}$; the first stage equals $P(\text{complier})$. In the example, $P(T=1 \mid Z=0) = 0.2$ is the share of always-takers, $1 - 0.6 = 0.4$ the share of never-takers, and the compliers are the remaining 40%. The 4.0 is the effect among those 40%, who may differ from always-takers and never-takers.

### Weak instruments

If the first stage is small, the Wald ratio divides by a number near zero: it is very noisy, and small violations of exclusion or independence are greatly amplified. A rule of thumb (Staiger and Stock, 1997) asks for a first-stage $F$ statistic above about 10. Always report the first stage.

```python
def wald(rows):
    """rows: list of (z, t, y) with z, t in {0, 1}. Returns the Wald estimate."""
    def mean(xs):
        return sum(xs) / len(xs)
    y1 = mean([y for z, t, y in rows if z == 1])
    y0 = mean([y for z, t, y in rows if z == 0])
    t1 = mean([t for z, t, y in rows if z == 1])
    t0 = mean([t for z, t, y in rows if z == 0])
    return (y1 - y0) / (t1 - t0)

rows = [(1, 1, 9), (1, 1, 11), (1, 0, 6), (1, 0, 8),
        (0, 1, 8), (0, 0, 5), (0, 0, 7), (0, 0, 6)]
print(wald(rows))
```

This prints `8.0`: the ITT effect is $8.5 - 6.5 = 2$ and the first stage is $0.5 - 0.25 = 0.25$, so the ratio is $2/0.25 = 8$. Note how a modest ITT effect is magnified when the first stage is small.

step: The Wald estimate is $1.5/0.25 = 6.0$.

answer: Wald estimate $6.0$; 25% always-takers, 50% never-takers, 25% compliers.

@example
title: From ITT to LATE
problem: Under the four IV assumptions, $P(T = 1 \mid Z = 1) = 0.7$ and $P(T = 1 \mid Z = 0) = 0.3$, and the ITT effect on the outcome is 2.0. Find the share of compliers and the LATE.
step: The first stage $0.7 - 0.3 = 0.4$ is the share of compliers.
step: The ITT effect equals $P(\text{complier}) \times \text{LATE}$, so $\text{LATE} = 2.0/0.4$.
step: $\text{LATE} = 5.0$. The always-takers (30%) and never-takers (30%) have no effect on the ITT.
answer: 40% compliers and a LATE of $5.0$.

@mistakes
- Using an instrument that affects the outcome directly (a violation of exclusion): the Wald ratio then absorbs the direct effect.
- Reading the Wald estimate as the ATE. Without constant effects it is the LATE, the effect among compliers.
- Using a weak instrument without reporting the first stage.
- Thinking that the instrument must be unrelated to the treatment: it must be related to the treatment (relevance), and unrelated to the outcome except through it.

model:
```python
def iv_slope(zs, ts, ys):
    """Cov(Z, Y) / Cov(Z, T), the instrumental variable slope."""
    n = len(zs)
    mz = sum(zs) / n
    mt = sum(ts) / n
    my = sum(ys) / n
    cov_zy = sum((z - mz) * (y - my) for z, y in zip(zs, ys))
    cov_zt = sum((z - mz) * (t - mt) for z, t in zip(zs, ts))
    return cov_zy / cov_zt
```
hint: Subtract each variable's mean, sum the products of centered $Z$ with centered $Y$ and with centered $T$, and divide the first sum by the second.
solution: The instrumental variable slope is the ratio of two covariances with the instrument. With a binary instrument it equals the Wald estimator (the first test), and a solution that regresses $Y$ on $T$ directly (ordinary least squares) fails the tests because it ignores the instrument.

@article
A team plans an A/B test of a new ranking model. If the true effect is a 2% lift and the experiment is too small, they will probably see "no significant difference" and discard a good model. If they run it too long they waste traffic. How many users are enough?

### Error rates and power

A test of the null hypothesis $H_0$: ATE $= 0$ rejects when the test statistic $z = \hat\tau / \mathrm{SE}$ satisfies $|z| > z_{1-\alpha/2}$. The **significance level** $\alpha$ is the probability of rejecting when $H_0$ is true (a **type I error**, a false positive); for $\alpha = 0.05$, $z_{1-\alpha/2} = 1.96$. The **power** $1 - \beta$ is the probability of rejecting when the true effect is $\delta \ne 0$ ($\beta$ is the probability of a **type II error**, a false negative).

If $\hat\tau$ is approximately normal with mean $\delta$ and standard error $\mathrm{SE}$, then $z$ has mean $\delta/\mathrm{SE}$ and power is approximately $\Phi(\delta/\mathrm{SE} - z_{1-\alpha/2})$, where $\Phi$ is the standard normal cumulative distribution function (the chance of rejecting in the wrong tail is negligible). Setting this equal to $1 - \beta$ gives $\delta/\mathrm{SE} = z_{1-\alpha/2} + z_{1-\beta}$.

### Sample size for means

With $n$ units in each of two arms and common standard deviation $\sigma$, $\mathrm{SE} = \sigma\sqrt{2/n}$. Solving $\delta / (\sigma\sqrt{2/n}) = z_{1-\alpha/2} + z_{1-\beta}$ for $n$:

$$n = \frac{2\sigma^2 (z_{1-\alpha/2} + z_{1-\beta})^2}{\delta^2} \quad \text{per arm}.$$

With $\alpha = 0.05$ and 80% power, $z_{1-\alpha/2} = 1.96$ and $z_{1-\beta} = 0.84$, so $(z + z)^2 = 7.84$. For $\sigma = 20$ and $\delta = 5$: $n = 2 \cdot 400 \cdot 7.84 / 25 = 250.88$, so 251 per arm. The smallest effect the experiment is designed to detect is its **minimum detectable effect** (MDE), $\delta = (z_{1-\alpha/2} + z_{1-\beta})\,\sigma\sqrt{2/n}$. Because $n \propto 1/\delta^2$, halving the MDE needs four times the data.

### Sample size for proportions

For conversion rates $p_0$ (control) and $p_1 = p_0 + \delta$, the variance of each observation is $p(1 - p)$ and a standard approximation is

$$n = \frac{(z_{1-\alpha/2} + z_{1-\beta})^2\,\big[p_0(1 - p_0) + p_1(1 - p_1)\big]}{(p_1 - p_0)^2} \quad \text{per arm}.$$

To detect a rise from 10% to 12% at $\alpha = 0.05$ with 80% power: $7.84 \times (0.09 + 0.1056)/0.0004 = 3833.8$, so 3,834 users per arm. Round up; rounding down loses power.

```python
import math

def n_per_arm_means(sigma, delta, z_alpha=1.96, z_beta=0.84):
    return math.ceil(2 * sigma ** 2 * (z_alpha + z_beta) ** 2 / delta ** 2)

print(n_per_arm_means(20, 5))
```

### Pitfalls

**Peeking.** A fixed-sample test controls the type I error only if you look once, at the planned sample size. If you check the $p$-value after each of five equally sized batches and stop at the first $p < 0.05$, the chance of a false positive under $H_0$ is about 14%, not 5%. Remedies are fixed horizons, or sequential designs with corrected boundaries.

**Multiple comparisons.** If you test $m$ metrics (or segments) at level $\alpha$ each, the chance of at least one false positive among independent true nulls is $1 - (1 - \alpha)^m$: for $m = 20$ and $\alpha = 0.05$ it is $0.64$. The **Bonferroni correction** tests each at $\alpha/m$, which keeps the familywise error at most $\alpha$.

**Sample ratio mismatch (SRM).** If the design assigns 50/50 but the observed counts are 5,200 and 4,800, compute the chi-squared statistic $\sum (O - E)^2/E$ with $E = 5{,}000$: $8 + 8 = 16$, far above the 1-degree-of-freedom critical value of $3.84$ at $\alpha = 0.05$. A mismatch like this suggests a bug in assignment or logging, and the result should not be trusted until it is explained.

**Other threats.** Users may react to novelty, so the first days can differ from the long run; effects can change across seasons; and interference between arms (SUTVA) can bias the comparison. A small $p$-value says the effect is unlikely to be exactly zero, not that it is large: report the estimate and its interval.

@example
title: Power of a planned test
problem: A test will use 100 users per arm, with outcome standard deviation $\sigma = 10$. What is the approximate power at $\alpha = 0.05$ (two-sided) to detect a true effect of $\delta = 3$?
step: The standard error is $\mathrm{SE} = \sigma\sqrt{2/n} = 10\sqrt{0.02} \approx 1.414$.
step: The mean of the $z$ statistic under the alternative is $\delta/\mathrm{SE} = 3/1.414 \approx 2.121$.
step: Power $\approx \Phi(2.121 - 1.96) = \Phi(0.161) \approx 0.564$.
step: Interpretation: the test would detect this real effect only about 56% of the time. To reach 80% power, $n = 2 \cdot 100 \cdot 7.84/9 \approx 174.2$, so 175 per arm.
answer: About $56\%$ power; about 175 users per arm would give 80%.

@example
title: Sample size for a conversion test
problem: A checkout page converts at 5%. How many users per arm are needed to detect an increase to 6% with $\alpha = 0.05$ (two-sided) and 80% power, using $z$ values 1.96 and 0.84?
step: The variances per observation are $0.05 \times 0.95 = 0.0475$ and $0.06 \times 0.94 = 0.0564$, which sum to $0.1039$.
step: The squared difference is $0.01^2 = 0.0001$ and $(1.96 + 0.84)^2 = 7.84$.
step: $n = 7.84 \times 0.1039 / 0.0001 = 8{,}145.76$, so round up to 8,146 users per arm.
answer: 8,146 users per arm (16,292 in total).

@mistakes
- Rounding the sample size down. The formula gives the smallest $n$ achieving the target power, so round up.
- Forgetting that the formula gives users per arm, not in total.
- Stopping the test as soon as the $p$-value dips below 0.05. With repeated looks the false-positive rate is far above 5%.
- Treating "not significant" as "no effect": with low power the interval is wide and may contain large effects.

model:
```python
import math

def n_per_arm_prop(p0, p1, z_alpha, z_beta):
    """Users per arm to detect p0 -> p1, rounded up."""
    variance = p0 * (1 - p0) + p1 * (1 - p1)
    return math.ceil((z_alpha + z_beta) ** 2 * variance / (p1 - p0) ** 2)
```
hint: Compute the numerator and denominator separately, and round up with `math.ceil`, which returns an integer.
solution: The formula needs the sum of the two Bernoulli variances, the squared sum of the $z$ values, and the squared difference of rates (so it is symmetric in $p_0$ and $p_1$ order). The second test (384.16) catches a solution that rounds to the nearest integer instead of up.

model:
```python
import math

def mde(sigma, n, z_alpha, z_beta):
    """Minimum detectable effect of a two-arm test with n users per arm."""
    return (z_alpha + z_beta) * sigma * math.sqrt(2 / n)
```
hint: The standard error of the difference is $\sigma\sqrt{2/n}$; multiply it by $z_\alpha + z_\beta$.
solution: The MDE is the effect for which the mean of the $z$ statistic equals $z_\alpha + z_\beta$, that is $(z_\alpha + z_\beta)$ times the standard error $\sigma\sqrt{2/n}$. The fourth test checks that quadrupling the sample size halves the MDE.

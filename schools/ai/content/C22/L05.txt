@article
Hospital data show that, among admitted patients, having diabetes and having a broken leg are negatively associated. Nobody believes diabetes protects against fractures. What has happened is that we only looked at patients selected by a condition (admission) that either problem can cause. To reason about when such artifacts arise, and when an association is causal, we encode our assumptions in a picture; here, in a list of nodes and edges.

### Causal graphs

A **directed acyclic graph** (DAG) has a set of **nodes** (variables) and **directed edges** $A \to B$, with no directed cycle. In a **causal graph**, an edge $A \to B$ means $A$ is a direct cause of $B$ (relative to the variables in the graph), and the absence of an edge means no direct effect. Every common cause of two variables in the graph must itself be in the graph. The **parents** of a node are the nodes with edges into it, its **descendants** are the nodes reachable by following edges forward.

A graph is written as a list: for example, nodes $\{Z, X, M, Y, C\}$ and edges $Z \to X$, $Z \to Y$, $X \to M$, $M \to Y$, $X \to C$, $Y \to C$.

A distribution $P$ is **Markov** to the DAG if it factorizes along the graph:

$$P(v_1, \dots, v_n) = \prod_{i=1}^{n} P\big(v_i \mid \mathrm{pa}(v_i)\big).$$

For binary variables, a node with $k$ parents needs $2^k$ numbers. The graph above needs $1 + 2 + 2 + 4 + 4 = 13$ numbers versus $2^5 - 1 = 31$ for an unrestricted joint distribution.

### Three building blocks

Every path (a sequence of adjacent nodes, ignoring edge direction) is built from three patterns, according to what happens at the middle node $B$:

| pattern | edges | $A$ and $C$ independent? |
|---|---|---|
| chain | $A \to B \to C$ | dependent; independent given $B$ |
| fork | $A \leftarrow B \to C$ | dependent (common cause); independent given $B$ |
| collider | $A \to B \leftarrow C$ | independent; dependent given $B$ or any descendant of $B$ |

The collider case is the surprising one. Let $A$ and $C$ be independent fair coins and $B = A \lor C$. Then $P(A = 1) = 1/2$, but among cases with $B = 1$ the possible $(A, C)$ are $(1, 0), (0, 1), (1, 1)$, so $P(A = 1 \mid B = 1) = 2/3$; and given $B = 1$ and $C = 0$, $A = 1$ with probability 1. Conditioning on a common effect makes its causes informative about each other ("explaining away"). This is the hospital example: admission is a common effect.

### d-separation

Let $Z$ be a set of nodes. A path is **blocked** by $Z$ if it contains

- a chain or fork whose middle node is in $Z$, or
- a collider such that neither the collider nor any of its descendants is in $Z$.

Nodes $X$ and $Y$ are **d-separated** by $Z$ if every path between them is blocked by $Z$. **Theorem (global Markov property; Verma and Pearl).** If $P$ is Markov to a DAG and $X$ and $Y$ are d-separated by $Z$, then $X \perp Y \mid Z$ in $P$. The converse, that every independence of $P$ shows up as d-separation, holds only under the additional assumption of **faithfulness** (no accidental cancelations of effects).

In the five-node graph above, the paths from $X$ to $Y$ are $X \leftarrow Z \to Y$ (fork at $Z$), $X \to M \to Y$ (chain at $M$) and $X \to C \leftarrow Y$ (collider at $C$). Given $\{Z, M\}$ all three are blocked, so $X \perp Y \mid \{Z, M\}$; given $\{Z, M, C\}$ the collider path opens, and they are not d-separated.

### In code

```python
def node_types(edges, path):
    """Label each interior node of a path as chain, fork or collider."""
    es = set(edges)
    out = []
    for a, b, c in zip(path, path[1:], path[2:]):
        arrows_in = ((a, b) in es) + ((c, b) in es)
        if arrows_in == 2:
            out.append((b, "collider"))
        elif (b, a) in es and (b, c) in es:
            out.append((b, "fork"))
        else:
            out.append((b, "chain"))
    return out

edges = [("Z", "X"), ("Z", "Y"), ("X", "M"), ("M", "Y"), ("X", "C"), ("Y", "C")]
print(node_types(edges, ["X", "C", "Y"]))
```

This prints `[('C', 'collider')]`.

@example
title: Reading d-separation off a graph
problem: A graph has edges $S \to T$, $T \to U$, $V \to T$, $V \to W$. Decide whether $S$ and $W$ are d-separated by $\varnothing$, by $\{T\}$, by $\{U\}$ and by $\{T, V\}$.
step: The only path between $S$ and $W$ is $S \to T \leftarrow V \to W$. Its interior nodes are $T$ (a collider, since both edges enter it) and $V$ (a fork).
step: Given $\varnothing$: the collider $T$ is not in $Z$ and neither is its descendant $U$, so the path is blocked. $S \perp W$.
step: Given $\{T\}$: the collider is opened and the fork $V$ is not conditioned, so the path is open. Not d-separated. Given $\{U\}$: $U$ is a descendant of the collider $T$, which also opens it; not d-separated.
step: Given $\{T, V\}$: the collider is open but the fork $V$ is in $Z$, so it blocks the path. $S \perp W \mid \{T, V\}$.
answer: d-separated by $\varnothing$ and by $\{T, V\}$; not by $\{T\}$ or $\{U\}$.

@example
title: The factorization and its parameter count
problem: A graph has edges $S \to T$, $T \to U$, $V \to T$ and $V \to W$, and all five variables are binary. Write the factorization of a distribution that is Markov to it and count its parameters.
step: Parents: $S$ and $V$ have none; $T$ has parents $S, V$; $U$ has parent $T$; $W$ has parent $V$.
step: $P(S, T, U, V, W) = P(S)\,P(V)\,P(T \mid S, V)\,P(U \mid T)\,P(W \mid V)$.
step: Parameters: $1 + 1 + 4 + 2 + 2 = 10$, versus $2^5 - 1 = 31$ for an unrestricted joint.
answer: $P(S)P(V)P(T \mid S,V)P(U \mid T)P(W \mid V)$, with 10 parameters.

@mistakes
- Conditioning on everything available. Conditioning on a collider or its descendant opens a path that was blocked.
- Forgetting the descendants of a collider: a path through $A \to B \leftarrow C$ is also opened by conditioning on a child of $B$.
- Reading an edge as correlation. An edge $A \to B$ is a causal claim, and a missing edge is a strong claim that there is no direct effect.
- Concluding dependence from "no d-separation": d-separation certifies independence, while non-separation only allows dependence (it implies it under faithfulness).

```python
def simple_paths(edges, x, y):
    nbrs = {}
    for a, b in edges:
        nbrs.setdefault(a, set()).add(b)
        nbrs.setdefault(b, set()).add(a)
    found = []
    def walk(path):
        if path[-1] == y:
            found.append(path)
            return
        for n in sorted(nbrs.get(path[-1], ())):
            if n not in path:
                walk(path + [n])
    walk([x])
    return found

def descendants(edges, node):
    out, stack = set(), [node]
    while stack:
        u = stack.pop()
        for a, b in edges:
            if a == u and b not in out:
                out.add(b)
                stack.append(b)
    return out

def d_separated(edges, x, y, z):
    """True when every path from x to y is blocked by z."""
    es = set(edges)
    for path in simple_paths(edges, x, y):
        blocked = False
        for a, b, c in zip(path, path[1:], path[2:]):
            if (a, b) in es and (c, b) in es:
                if b not in z and not (descendants(edges, b) & set(z)):
                    blocked = True
            elif b in z:
                blocked = True
        if not blocked:
            return False
    return True
```
hint: For each path, scan its interior triples $(a, b, c)$; a collider has both edges $(a, b)$ and $(c, b)$ in `edges`. The path is open only if no triple blocks it.
solution: Loop over the paths and mark each as blocked if any interior node blocks it: a collider blocks when neither it nor a descendant is in `z`, and a non-collider blocks when it is in `z`. The answer is `True` only if all paths are blocked. The third test checks the descendant rule: conditioning on `F`, a descendant of the collider `B`, opens the path.

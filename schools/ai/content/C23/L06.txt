@article
A bank declines your loan application. You ask why. "The model's output was below the threshold" is accurate and useless. You want to know which facts about you mattered and what you could change. Three related ideas separate here. **Transparency** is information about the system: that it exists, what it is for, what data it uses, how it was tested. **Explanation** is information about a particular decision or about the model's behavior. **Contestability** is the ability of affected people to challenge a decision and obtain review or correction. A system can have one without the others.

### Explaining a prediction with feature attributions

A **feature attribution** assigns each input feature a share of the difference between a prediction and a baseline. For a linear model $f(\mathbf{x}) = b + \sum_i w_i x_i$, and a baseline equal to the average input $\bar{x}_i$, the natural attribution of feature $i$ is $\phi_i = w_i (x_i - \bar{x}_i)$, and the attributions sum to $f(\mathbf{x}) - f(\bar{\mathbf{x}})$.

For general models the standard definition comes from cooperative game theory. Let $N$ be the set of $n$ features and let $v(S)$ be the model's expected output when only the features in $S$ are known. The **Shapley value** of feature $i$ is

$$\phi_i = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!\,(n - |S| - 1)!}{n!}\,\big[v(S \cup \{i\}) - v(S)\big],$$

the feature's average marginal contribution over all orders in which features could be added. The values satisfy **efficiency**: $\sum_i \phi_i = v(N) - v(\emptyset)$. SHAP (Lundberg and Lee, 2017) applies Shapley values to model explanation; LIME (Ribeiro, Singh and Guestrin, 2016) fits a simple local model around an input; integrated gradients (Sundararajan, Taly and Yan, 2017) attributes via a path integral. Results depend on the baseline and on how $v(S)$ handles missing features.

### Counterfactual explanations

A **counterfactual explanation** (Wachter, Mittelstadt and Russell, 2017) states a nearby input with a different outcome: "had your income been 10,000 higher, the loan would have been approved." It tells the person something they can act on, and it can be given without revealing the model. For a linear score $s = b + \mathbf{w}^\top\mathbf{x}$ and threshold $\tau$, changing only feature $j$ by $\Delta$ reaches the threshold when $w_j \Delta = \tau - s$, that is $\Delta = (\tau - s)/w_j$. Counterfactuals have limits: the changes may be infeasible, may not change real-world risk, and different valid counterfactuals can exist.

### What explanations can and cannot do

Explanations can be **unfaithful** (they describe a simple stand-in, not what the model computes), **unstable** (small input changes give different explanations), and **manipulable**. A feature attribution describes the model, not the world: that a ZIP code drives a score does not mean ZIP code causes the outcome. And an explanation is not a justification: a clear account of why the model did something does not show that it was right to use that model.

### Contestability

Contestability requires notice that an automated system was used, understandable reasons, a path to human review by someone with authority to change the decision, and the chance to correct wrong data. Law addresses parts of this: the EU's General Data Protection Regulation (applied since 2018) contains a provision on decisions based solely on automated processing with legal or similarly significant effects, and the EU AI Act contains transparency and human-oversight duties for some systems (see Lesson 11). Scope and wording of these rules are debated and change, so check the current text.

### Interpretable models or post-hoc explanations?

*For using inherently interpretable models in high-stakes settings* (a position associated with Rudin, 2019): post-hoc explanations of a complex model are approximations that can mislead, so where an interpretable model (a short rule list, a sparse scoring model) performs about as well, it should be used, because its reasoning can be inspected directly. Objection: for some tasks, such as perception and language, complex models are far more accurate, and the interpretable alternative may cost real accuracy and so real harms.

*For post-hoc explanation and auditing of complex models*: explanations, testing and monitoring provide useful information even without perfect fidelity, and requiring simplicity would forgo performance. Objection: explanations can create false confidence and are weak evidence of safety.

Which holds in a given setting is partly an empirical question about the accuracy gap and partly a judgment about acceptable risk.

@example
title: Shapley values for two features
problem: A model's expected output with no features known is $v(\emptyset) = 10$. With only feature 1 known it is $v(\{1\}) = 16$; with only feature 2, $v(\{2\}) = 12$; with both, $v(\{1,2\}) = 20$. Compute the Shapley value of each feature and check efficiency.
step: With $n = 2$ the weights are $\frac{0!\,1!}{2!} = \frac12$ for adding a feature to the empty set and $\frac{1!\,0!}{2!} = \frac12$ for adding it to a set containing the other feature.
step: Feature 1: $\phi_1 = \frac12\big[(16 - 10) + (20 - 12)\big] = \frac12(6 + 8) = 7$.
step: Feature 2: $\phi_2 = \frac12\big[(12 - 10) + (20 - 16)\big] = \frac12(2 + 4) = 3$.
step: Check: $\phi_1 + \phi_2 = 10 = v(\{1,2\}) - v(\emptyset) = 20 - 10$.
answer: $\phi_1 = 7$ and $\phi_2 = 3$; they sum to the total change of 10.

@example
title: A counterfactual for a linear rule
problem: A loan is approved when the score $s = 0.05\,x_1 - 2\,x_2 + 1$ is at least 3, where $x_1$ is income in thousands and $x_2$ is the debt ratio. An applicant has $x_1 = 50$ and $x_2 = 0.5$. How much would income need to rise, with debt unchanged, for approval?
step: Compute the current score: $0.05(50) - 2(0.5) + 1 = 2.5 - 1 + 1 = 2.5$, below the threshold 3.
step: The gap is $3 - 2.5 = 0.5$.
step: Solve for income: $0.05\,\Delta = 0.5$, so $\Delta = 10$ (thousand).
answer: Income would need to rise by 10 thousand; equivalently the debt ratio would need to fall by 0.25.

@mistakes
- Treating an attribution as a causal effect: it describes the model's use of a feature, not its effect in the world.
- Forgetting the baseline: Shapley and other attributions depend on what the missing features are replaced by.
- Treating an explanation as a justification: knowing why the model said no does not show it was right to use it.
- Treating transparency, explanation and contestability as the same: a published explanation does not give anyone a way to challenge the decision.

answer: 2.4
tol: 0.001
check: 0.6 * (9 - 5)
hint: Subtract the average from the individual's value and multiply by the weight.
solution: $\phi_1 = 0.6 \times (9 - 5) = 2.4$; this feature raised the score by 2.4 relative to the average person.

@practice num
prompt: For a model with two features, $v(\emptyset) = 4$, $v(\{1\}) = 9$, $v(\{2\}) = 6$ and $v(\{1,2\}) = 13$. What is the Shapley value $\phi_1$ of feature 1?
answer: 6
tol: 0.001
check: 0.5 * ((9 - 4) + (13 - 6))
hint: Average the marginal contribution of feature 1 over the two orders: first, and after feature 2.
solution: $\phi_1 = \frac12[(9 - 4) + (13 - 6)] = \frac12(5 + 7) = 6$. The other feature gets $\phi_2 = \frac12[(6-4) + (13-9)] = 3$, and the total is $9 = 13 - 4$.

@practice num
prompt: A count of 87 is released with the Laplace mechanism using $\varepsilon = 1$ (sensitivity 1). What is the probability that the released value lies within 2 of the true count, that is, that the absolute noise is at most 2? Give your answer to three decimal places.
answer: 0.865
tol: 0.001
check: 1 - exp(-2 / 1)
hint: The scale is $b = 1/\varepsilon$, and $P(|X| \le t) = 1 - e^{-t/b}$.
solution: With $b = 1$, $P(|X| \le 2) = 1 - e^{-2} \approx 0.865$. In words: the release is within 2 of the truth about 86.5% of the time, yet any single person's presence changes output probabilities by at most a factor $e^{1} \approx 2.72$.

@practice self
prompt: A hospital is choosing between a sparse scoring model that is slightly less accurate and a complex model with a post-hoc explanation tool, for a high-stakes decision. Argue for one choice and give the strongest objection with your reply.
hint: Say how much accuracy matters, how faithful the explanations are, and what clinicians and patients need.
solution: One defensible position favors the interpretable model: in a high-stakes decision the people responsible must be able to inspect the reasoning, and post-hoc explanations are approximations that can be unfaithful or unstable, so they may reassure without informing. If the accuracy gap is small, the interpretable model costs little and lets clinicians and auditors check the rules and spot errors, and patients can be given reasons. The strongest objection is that even a small accuracy gap means more patients are misclassified, and when lives are at stake accuracy can outweigh inspectability; also, complex models can be audited by testing outcomes and monitored in use. A reply is that the claim rests on the size of the gap, which should be measured on the hospital's own data, and that if the complex model is clearly better, using it with outcome audits and human review is defensible, so the position changes with the evidence on the gap. A fair answer states what evidence would switch the choice.

@quiz ms
prompt: Which of these statements about feature-attribution explanations are correct? Select all that apply.
choice*: Shapley values satisfy efficiency: they sum to the difference between the model's output and the baseline expectation.
choice*: An attribution can depend on the choice of baseline.
choice*: A large attribution for a feature shows that the model uses that feature, not that the feature causes the outcome in the world.
choice: A post-hoc explanation is always an exact description of the model's computation.

hint: Recall efficiency, baselines and the difference between model and world.

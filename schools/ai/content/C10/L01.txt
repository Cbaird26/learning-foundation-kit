@article
**Machine learning** is the study of algorithms that improve at a task by using data instead of being given explicit rules. Instead of writing the rules that separate spam from legitimate mail, you collect examples of both and let a learning algorithm find a rule that fits them. The goal is never to do well on the examples you already have: it is to do well on **new** examples drawn from the same source. This property is called **generalization**, and almost every idea in this course serves it.

### Data, features and targets

A data set is a table. Each row is one **example** (also called a sample or observation); each column is a **feature** (also called a predictor, attribute or input variable). With $n$ examples and $d$ features we store the inputs in a **data matrix** $X \in \mathbb{R}^{n \times d}$, whose row $x_i$ is the feature vector of example $i$. In **supervised learning** every example also has a **target** or **label** $y_i$, and the data are pairs $(x_i, y_i)$. The learner searches a family of functions (the **model class**) for a function $f$ with $f(x_i) \approx y_i$.

Categorical features such as a color must become numbers. **One-hot encoding** replaces a feature with $m$ categories by $m$ columns of 0s and 1s, exactly one of which is 1 in each row. Numeric features on very different scales are often **standardized**: subtract the column mean $\mu$ and divide by the standard deviation $\sigma$, giving $z = (x - \mu)/\sigma$.

### Tasks

| Task | Data | Output | Example |
|---|---|---|---|
| Regression | $(x, y)$, $y$ a real number | a number | predict a house price |
| Classification | $(x, y)$, $y$ one of $K$ classes | a class (or class probabilities) | spam or not spam |
| Clustering | $x$ only | a group index | segment customers |
| Dimensionality reduction | $x$ only | a short vector $z$ | compress to 2 numbers for plotting |

Regression and classification are supervised; clustering and dimensionality reduction are **unsupervised** because no labels guide them. A third setting, **reinforcement learning**, learns from rewards for actions in an environment; this course does not cover it.

### Loss and baselines

A **loss function** measures how wrong a prediction is. For regression the standard choice is the squared error $(y - \hat{y})^2$; its average over the data is the **mean squared error**
$$\mathrm{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2.$$
For classification, the simplest measure is **accuracy**, the fraction of correct predictions.

Before trusting any model, compute a **baseline**: the best trivial predictor. For regression it predicts the training mean $\bar{y}$ for everyone, and its MSE is the (population) variance of $y$. For classification it predicts the most common class, and its accuracy is that class's share of the data. A model that cannot beat the baseline has learned nothing useful, and a classifier with 95% accuracy is unimpressive when 95% of the examples belong to one class.

@example
title: Naming the task
problem: A hospital has records of past patients: age, blood pressure, and whether the patient was readmitted within 30 days. (a) Predict whether a new patient will be readmitted. (b) Predict the number of days a new patient will stay. (c) Group the patients into types without using any outcome. Name each task.
step: In (a) the label is one of two classes (readmitted or not), so this is **binary classification**.
step: In (b) the target is a number of days, so this is **regression**, even though days are whole numbers: the values are ordered and the size of an error matters.
step: In (c) there is no label at all, so this is **unsupervised**: the task is **clustering**.
step: Each of (a) and (b) needs the labelled history as training data; (c) needs only the feature columns.
answer: (a) classification, (b) regression, (c) clustering.

@example
title: A mean baseline
problem: The training targets are $y = (3, 5, 10)$. What is the mean predictor and its MSE on this data?
step: The mean is $\bar{y} = (3 + 5 + 10)/3 = 6$, so the baseline predicts 6 for every input.
step: The errors are $3 - 6 = -3$, $5 - 6 = -1$ and $10 - 6 = 4$.
step: The squared errors are $9$, $1$ and $16$, which sum to $26$.
step: Divide by $n = 3$: $\mathrm{MSE} = 26/3 \approx 8.67$.
answer: The baseline predicts $6$, with $\mathrm{MSE} = 26/3$.

@mistakes
- Treating a numeric label as regression automatically: a zip code or a class number such as 1, 2, 3 is a category, not a quantity.
- Reporting accuracy without the majority-class baseline, so an unimpressive model looks excellent on imbalanced data.
- Standardizing with the mean and standard deviation of the whole data set instead of the training set only (information from test data leaks into training).
- Encoding a categorical feature as 1, 2, 3, which tells the model that category 3 is "larger" than category 1.

```python
def mean_baseline_mse(ys):
    mean = sum(ys) / len(ys)
    return sum((y - mean) ** 2 for y in ys) / len(ys)
```
hint: Compute the mean first, then average the squared differences from it.
hint: Divide by `len(ys)`, not by `len(ys) - 1`: this is the mean of the squared errors, not a sample variance.
solution: The baseline prediction is the mean of `ys`; the MSE is the average of `(y - mean) ** 2`. This equals the population variance of `ys`.

model:
```python
def majority_class_accuracy(labels):
    if not labels:
        return 0.0
    counts = {}
    for label in labels:
        counts[label] = counts.get(label, 0) + 1
    return max(counts.values()) / len(labels)
```
hint: Count how often each label occurs, for example in a dictionary.
hint: The classifier is right exactly on the examples that carry the most common label.
solution: The accuracy of always predicting the most common class is (count of that class) / (number of examples). Guard the empty list first.

model:
```python
def standardize(column):
    n = len(column)
    mean = sum(column) / n
    var = sum((v - mean) ** 2 for v in column) / n
    std = var ** 0.5
    return [(v - mean) / std for v in column]
```
hint: You need the mean, then the variance (the average squared deviation), then its square root.
hint: After standardizing, the values always have mean 0 and variance 1; use that to check your work.
solution: Compute `mean`, then `std = sqrt(mean of squared deviations)`, and map each value to `(v - mean) / std`. The result has mean 0 and (population) variance 1.

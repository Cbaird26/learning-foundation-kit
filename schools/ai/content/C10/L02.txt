@article
**Linear regression** models a numeric target as a linear function of the features. With one feature the model is $\hat{y} = \beta_0 + \beta_1 x$, where $\beta_0$ is the **intercept** and $\beta_1$ the **slope**. The question is which line to choose. The **least-squares** answer: pick the line that minimizes the **residual sum of squares**
$$\mathrm{RSS}(\beta_0, \beta_1) = \sum_{i=1}^{n} \bigl(y_i - \beta_0 - \beta_1 x_i\bigr)^2,$$
where the **residual** $e_i = y_i - \hat{y}_i$ is the vertical distance from point $i$ to the line.

### The formulas

RSS is a smooth bowl-shaped function of $(\beta_0, \beta_1)$, so its minimum is where both partial derivatives are zero. Setting $\partial\mathrm{RSS}/\partial\beta_0 = 0$ gives $\bar{y} = \beta_0 + \beta_1\bar{x}$: the best line passes through the point of means $(\bar{x}, \bar{y})$. Setting $\partial\mathrm{RSS}/\partial\beta_1 = 0$ and substituting gives
$$\hat{\beta}_1 = \frac{S_{xy}}{S_{xx}} = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}, \qquad \hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}.$$
The slope is the covariance of $x$ and $y$ divided by the variance of $x$ (the factors $n-1$ cancel). Two consequences: the residuals sum to zero when the model has an intercept, and the residuals are uncorrelated with $x$.

### Several features: the normal equations

With $d$ features, put a column of ones in front of $X$ so that the intercept is just another coefficient, and write $\hat{y} = X\beta$. Then $\mathrm{RSS} = \lVert y - X\beta \rVert^2$, and setting the gradient $-2X^\top(y - X\beta)$ to zero gives the **normal equations**
$$X^\top X\,\beta = X^\top y.$$
If the columns of $X$ are linearly independent, $X^\top X$ is invertible and $\hat\beta = (X^\top X)^{-1}X^\top y$. In practice you solve the linear system (for example by Gaussian elimination) rather than forming the inverse. If features are perfectly correlated, $X^\top X$ is singular and the solution is not unique; regularization (week 5) fixes this.

### How good is the fit?

The **total sum of squares** is $\mathrm{TSS} = \sum (y_i - \bar{y})^2$, the error of the mean baseline. The coefficient of determination
$$R^2 = 1 - \frac{\mathrm{RSS}}{\mathrm{TSS}}$$
is the fraction of the variance of $y$ that the model explains. On the training data of a least-squares fit with an intercept, $0 \le R^2 \le 1$; $R^2 = 0$ means no better than the mean. On new data $R^2$ can be negative. Training $R^2$ never decreases when you add features, which is one reason it cannot choose between models (week 5).

```python
def fit_line(xs, ys):
    n = len(xs)
    xbar, ybar = sum(xs) / n, sum(ys) / n
    sxy = sum((x - xbar) * (y - ybar) for x, y in zip(xs, ys))
    sxx = sum((x - xbar) ** 2 for x in xs)
    slope = sxy / sxx
    return ybar - slope * xbar, slope
```

The cost of fitting is $O(nd^2 + d^3)$ operations for the normal equations: forming $X^\top X$ costs $O(nd^2)$ and solving the $d \times d$ system $O(d^3)$.

@example
title: Fitting a line by hand
problem: Fit $\hat{y} = \beta_0 + \beta_1 x$ by least squares to the points $(1, 2), (2, 3), (3, 5), (4, 4)$ and compute $R^2$.
step: The means are $\bar{x} = 2.5$ and $\bar{y} = 3.5$.
step: The deviations are $x - \bar{x} = (-1.5, -0.5, 0.5, 1.5)$ and $y - \bar{y} = (-1.5, -0.5, 1.5, 0.5)$.
step: $S_{xy} = 2.25 + 0.25 + 0.75 + 0.75 = 4$ and $S_{xx} = 2.25 + 0.25 + 0.25 + 2.25 = 5$, so $\hat\beta_1 = 4/5 = 0.8$.
step: $\hat\beta_0 = 3.5 - 0.8 \cdot 2.5 = 1.5$, so the line is $\hat{y} = 1.5 + 0.8x$.
step: The predictions are $2.3, 3.1, 3.9, 4.7$, so the residuals are $-0.3, -0.1, 1.1, -0.7$ (they sum to 0) and $\mathrm{RSS} = 0.09 + 0.01 + 1.21 + 0.49 = 1.8$.
step: $\mathrm{TSS} = 2.25 + 0.25 + 2.25 + 0.25 = 5$, so $R^2 = 1 - 1.8/5 = 0.64$.
answer: $\hat{y} = 1.5 + 0.8x$ and $R^2 = 0.64$.

@example
title: The normal equations for a line
problem: Write the normal equations for the data $(0, 1), (1, 2), (2, 2)$ with the model $\hat{y} = \beta_0 + \beta_1 x$ and solve them.
step: The design matrix has rows $(1, 0), (1, 1), (1, 2)$ and $y = (1, 2, 2)$.
step: $X^\top X = \begin{pmatrix} 3 & 3 \\ 3 & 5 \end{pmatrix}$ and $X^\top y = \begin{pmatrix} 5 \\ 6 \end{pmatrix}$.
step: The equations are $3\beta_0 + 3\beta_1 = 5$ and $3\beta_0 + 5\beta_1 = 6$.
step: Subtract the first from the second: $2\beta_1 = 1$, so $\beta_1 = 1/2$.
step: Then $3\beta_0 = 5 - 3/2 = 7/2$, so $\beta_0 = 7/6$.
answer: $\hat\beta_0 = 7/6$ and $\hat\beta_1 = 1/2$.

@mistakes
- Using the formula $S_{xy}/S_{xx}$ but forgetting the intercept $\bar{y} - \hat\beta_1\bar{x}$, which forces the line through the origin.
- Swapping $x$ and $y$: regressing $y$ on $x$ and $x$ on $y$ give different lines.
- Computing the residual as prediction minus target in one place and target minus prediction in another and so mixing signs (the squared sum is unaffected, but the sum of residuals is not).
- Concluding that a high $R^2$ means the relationship is causal or that the model will predict well on new data.

model:
```python
def r_squared(ys, preds):
    mean = sum(ys) / len(ys)
    rss = sum((y - p) ** 2 for y, p in zip(ys, preds))
    tss = sum((y - mean) ** 2 for y in ys)
    return 1 - rss / tss
```
hint: RSS compares the targets with the predictions; TSS compares the targets with their mean.
solution: Compute RSS and TSS as sums of squares and return `1 - rss / tss`. Predicting the mean gives RSS = TSS and $R^2 = 0$; a worse-than-mean predictor gives a negative value, as in the reversed-predictions test.

model:
```python
def solve_linear_system(A, b):
    n = len(A)
    M = [list(map(float, row)) + [float(rhs)] for row, rhs in zip(A, b)]
    for col in range(n):
        pivot = max(range(col, n), key=lambda r: abs(M[r][col]))
        M[col], M[pivot] = M[pivot], M[col]
        for r in range(col + 1, n):
            factor = M[r][col] / M[col][col]
            for c in range(col, n + 1):
                M[r][c] -= factor * M[col][c]
    x = [0.0] * n
    for i in range(n - 1, -1, -1):
        s = sum(M[i][j] * x[j] for j in range(i + 1, n))
        x[i] = (M[i][n] - s) / M[i][i]
    return x
```
hint: Build an augmented matrix with a copy of each row plus its right-hand side, so the arguments stay unchanged.
hint: For each column, swap the best pivot row into place, subtract multiples of it from the rows below, then solve from the last row upward (back substitution).
solution: Eliminate below each pivot after swapping the largest entry of the column into the pivot row, which avoids dividing by zero (as in `[[0, 1], [1, 0]]`) and limits rounding error. Back substitution then gives each unknown from the last equation to the first. Solving the normal equations this way is how a multiple regression is fitted.

@article
An **expression** is a combination of numbers, variables and operations, such as $3x + 5$. Two expressions are **equivalent** if they give the same value for every value of the variable. Rewriting an expression in an equivalent form makes it easier to read or to solve with.

### Like terms

**Terms** are the pieces separated by plus or minus signs. **Like terms** have the same variable part: $4x$ and $7x$ are like terms, while $4x$ and $7$ are not. Combine like terms by adding the coefficients:

$$4x + 7x = 11x, \qquad 5x - 2x + 3 = 3x + 3.$$

You can think of $4x + 7x$ as 4 apples plus 7 apples making 11 apples.

### The distributive property

Multiplying a sum by a number multiplies every term:

$$a(b + c) = ab + ac.$$

So $3(x + 4) = 3x + 12$. Check with $x = 2$: $3(6) = 18$ and $6 + 12 = 18$. The property works for subtraction too: $2(5x - 1) = 10x - 2$.

### Negative signs

A minus sign in front of brackets multiplies every term inside by $-1$:

$$-(x - 4) = -x + 4, \qquad -2(x - 5) = -2x + 10.$$

The most common slip is changing only the first sign.

### Factoring

**Factoring** is the distributive property run backwards: pull out the greatest common factor. In $6x + 9$ both terms are multiples of $3$, so $6x + 9 = 3(2x + 3)$. You can always check by expanding.

### Testing equivalence

To show two expressions are not equivalent, find one value of the variable where they give different results. To be confident that they are equivalent, simplify both and compare. For example $2(x + 3) - x$ simplifies to $x + 6$, so it is equivalent to $x + 6$ but not to $2x + 6$.

@example
title: Expand and combine
problem: Simplify $3(x + 4) + 2x - 5$.
step: Distribute the $3$: $3x + 12 + 2x - 5$.
step: Group the like terms: $(3x + 2x) + (12 - 5)$.
step: Combine them: $5x + 7$.
step: Check with $x = 1$: the original is $3(5) + 2 - 5 = 12$, and $5(1) + 7 = 12$.

@mistakes
- Distributing to only the first term: $3(x + 4) = 3x + 4$.
- Missing the sign change when removing brackets after a minus sign: $-(x - 4) = -x - 4$ is wrong.
- Combining unlike terms, such as writing $3x + 5 = 8x$.

@practice expr
prompt: Simplify $3x + 5x - 2x$.
vars: x
answer: 6x
check: lambda x: 3*x + 5*x - 2*x
hint: All three terms are like terms. Combine the coefficients.
solution: $3 + 5 - 2 = 6$, so the expression is $6x$.

@practice expr
prompt: Expand $4(x - 3)$.
vars: x
answer: 4x - 12
check: lambda x: 4*(x - 3)
hint: Multiply both terms inside the brackets by $4$.
solution: $4 \cdot x - 4 \cdot 3 = 4x - 12$.

@practice mc
prompt: Which expression is equivalent to $-2(x - 5)$?
choice: $-2x - 10$
choice*: $-2x + 10$
choice: $-2x - 5$
choice: $2x + 10$
hint: Multiply both terms by $-2$, and watch the sign of the second product.
solution: $-2 \cdot x = -2x$ and $-2 \cdot (-5) = +10$, so the result is $-2x + 10$. The choice with $-10$ forgets that a negative times a negative is positive.

@practice expr
prompt: Simplify $2(3x + 1) - (x - 4)$.
vars: x
answer: 5x + 6
check: lambda x: 2*(3*x + 1) - (x - 4)
hint: Expand each bracket first. The minus sign before the second bracket changes both of its signs.
hint: You get $6x + 2 - x + 4$.
solution: $6x + 2 - x + 4 = 5x + 6$.

@practice expr
prompt: Factor out the greatest common factor: $6x + 9$.
vars: x
form: factored
answer: 3(2x + 3)
check: lambda x: 6*x + 9
hint: Find the largest number that divides both $6$ and $9$.
solution: The greatest common factor is $3$, so $6x + 9 = 3(2x + 3)$. Expanding gives back $6x + 9$.

@quiz expr
prompt: Simplify $5(2x - 1) - 3(x + 2)$.
vars: x
answer: 7x - 11
check: lambda x: 5*(2*x - 1) - 3*(x + 2)
hint: Expand both products, taking care with the sign of the second one.
hint: You get $10x - 5 - 3x - 6$.
solution: $10x - 5 - 3x - 6 = 7x - 11$.

@quiz expr
prompt: Simplify $\frac{1}{2}(4x + 6) + x$.
vars: x
answer: 3x + 3
check: lambda x: 0.5*(4*x + 6) + x
hint: Multiply each term in the brackets by $\frac{1}{2}$.
solution: $\frac{1}{2}(4x + 6) = 2x + 3$, and adding $x$ gives $3x + 3$.

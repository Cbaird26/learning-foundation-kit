material: **Ecosystem skeleton (runs as given; extend it or write your own).** Save as `game.py`.

```python
from abc import ABC, abstractmethod


class Creature(ABC):
    """Anything that lives on the grid."""

    def __init__(self, name, energy):
        self.name = name
        self.energy = energy

    @property
    def alive(self):
        return self.energy > 0

    @abstractmethod
    def symbol(self):
        """Return the one character shown on the map."""

    @abstractmethod
    def act(self, world, row, col):
        """Take one turn at position (row, col)."""


class Plant(Creature):
    def symbol(self):
        return "p"

    def act(self, world, row, col):
        self.energy += 1


class World:
    def __init__(self, rows, cols):
        self.rows = rows
        self.cols = cols
        self._cells = [[None] * cols for _ in range(rows)]

    def in_bounds(self, row, col):
        return 0 <= row < self.rows and 0 <= col < self.cols

    def get(self, row, col):
        if not self.in_bounds(row, col):
            raise IndexError("outside the world")
        return self._cells[row][col]

    def place(self, creature, row, col):
        if self.get(row, col) is not None:
            raise ValueError("cell is occupied")
        self._cells[row][col] = creature

    def remove(self, row, col):
        self.get(row, col)
        self._cells[row][col] = None

    def step(self):
        for r in range(self.rows):
            for c in range(self.cols):
                creature = self._cells[r][c]
                if creature is not None:
                    creature.act(self, r, c)
        for r in range(self.rows):
            for c in range(self.cols):
                creature = self._cells[r][c]
                if creature is not None and not creature.alive:
                    self._cells[r][c] = None

    def __str__(self):
        lines = []
        for row in self._cells:
            lines.append("".join("." if x is None else x.symbol() for x in row))
        return "\n".join(lines)
```

@review
**Week 1: classes and objects.** A class is a blueprint; an object (instance) is one thing built from it. `__init__` sets up an object, `self` is the object a method works on, and attributes live inside objects. Assignment copies references, not objects: `b = a` makes two names for one object, and `is` tests identity.

**Week 2: methods, attributes and `__init__`.** Default parameters, validation in `__init__`, mutators versus accessors, checking before changing, class attributes (shared, changed through the class name) versus instance attributes. Never share a mutable list through a class attribute or a default argument.

**Week 3: special methods.** `__str__` for printing and `__repr__` for developers and list displays; `__eq__` for content equality (and then `__hash__` if you need sets or dictionary keys); `__lt__` for sorting; `__add__`, `__len__`, `__getitem__`, `__contains__`.

**Week 4: encapsulation and design.** Protect invariants; `_name` is a convention, `__name` is name mangling, and `@property` with a setter validates assignment. Do not return internal lists. Design by finding nouns (classes, attributes) and verbs (methods).

**Week 5: inheritance.** `super().__init__(...)`, overriding, extending with `super().method()`, `isinstance` and `issubclass`, and the "is a" versus "has a" test.

**Week 6: polymorphism and abstract classes.** One call, many behaviors; `ABC` and `@abstractmethod` make the contract explicit and fail early; duck typing needs only the method.

**Week 7: two-dimensional lists.** `grid[r][c]`, nested loops, bounds checks, neighbors, and the shared-row trap in `[[0] * n] * m`.

**Week 8: recursion.** Base case plus recursive case; the call stack; work before the call happens on the way down, work after it on the way up; `RecursionError` when there is no base case.

**Week 9: recursive algorithms.** Binary search ($O(\log n)$), memoization, subsets ($2^n$), Towers of Hanoi ($2^n - 1$ moves), flood fill.

**Week 10: merge sort and quicksort.** Merge sort is $O(n \log n)$ always and stable with $O(n)$ extra memory; quicksort is $O(n \log n)$ on average but $O(n^2)$ in the worst case with a bad pivot.

**Week 11: stacks and queues.** LIFO and FIFO, `list` as a stack, `deque` as a queue, bracket matching and postfix evaluation.

**Week 12: linked lists.** Nodes joined by `next` references, $O(1)$ at the head, $O(k)$ to reach position `k`, the special cases of empty lists and the head, keeping `head`, `tail` and size consistent.

**Self-check.** Can you, without notes: write a class with validation and a property; write `__eq__`, `__lt__` and `__str__`; explain what `super()` does; replace an `if kind == ...` chain with polymorphism; build a grid correctly and visit its neighbors safely; trace a recursive call and its returns; write `merge`; explain why a first-item pivot is bad on sorted input; write `balanced`; remove a node from a linked list including the head and tail cases?

**Common errors.** Forgetting `self`; `name = name` instead of `self.name = name`; shared mutable class attributes; `__eq__` without `__hash__`; forgetting `super().__init__`; instantiating an abstract class; negative indexes slipping through bounds checks; a missing base case; slicing inside a recursive search and returning the wrong index; dropping the leftovers after a merge; using `pop(0)` as a queue; forgetting to reset `tail` when a queue becomes empty.

model:
```python
class Item:
    daily_fee = 0.5

    def __init__(self, title):
        self.title = title

    def loan_days(self):
        return 14

    def fee(self, days_late):
        if days_late <= 0:
            return 0
        return days_late * self.daily_fee

    def __str__(self):
        return f"{type(self).__name__}: {self.title}"

    def __eq__(self, other):
        if not isinstance(other, Item):
            return NotImplemented
        return type(self) is type(other) and self.title == other.title

    def __hash__(self):
        return hash((type(self).__name__, self.title))

    def __lt__(self, other):
        if not isinstance(other, Item):
            return NotImplemented
        return self.title < other.title


class Book(Item):
    daily_fee = 0.25

    def loan_days(self):
        return 21


class Dvd(Item):
    daily_fee = 1.0

    def loan_days(self):
        return 7


def total_fees(pairs):
    return sum(item.fee(days) for item, days in pairs)
```
hint: Put the shared behavior in `Item` and let the subclasses override only `daily_fee` and `loan_days`. `fee` reads `self.daily_fee`, so each subclass's value is used automatically.
hint: Defining `__eq__` removes the inherited `__hash__`, so define `__hash__` as well, using the same data that `__eq__` compares. Compare `type(self) is type(other)` for the same-class rule.
solution: A class attribute `daily_fee` lets one `fee` method serve every subclass through `self.daily_fee`. `__eq__` compares the class and the title; `__hash__` hashes the same two values so equal items hash equally. `__lt__` compares titles, which is all `sorted` needs. `total_fees` sums `item.fee(days)` polymorphically.

model:
```python
def count_islands(grid):
    if not grid:
        return 0
    rows = len(grid)
    cols = len(grid[0])
    seen = set()

    def explore(r, c):
        if not (0 <= r < rows and 0 <= c < cols):
            return
        if grid[r][c] != 1 or (r, c) in seen:
            return
        seen.add((r, c))
        explore(r - 1, c)
        explore(r + 1, c)
        explore(r, c - 1)
        explore(r, c + 1)

    count = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 1 and (r, c) not in seen:
                count += 1
                explore(r, c)
    return count
```
hint: Scan every cell. When you meet land that has not been visited, you have found a new island: count it, then visit all of its connected land.
hint: Keep a set of visited positions instead of changing the grid. The recursive helper returns at once for positions outside the grid, water, or visited cells; otherwise it marks the cell and recurses in four directions.
solution: The outer double loop finds an unvisited land cell, which starts a new island. The recursive `explore` marks every land cell reachable from it, so those cells are never counted again. Bounds are checked before indexing, so negative positions are rejected explicitly.

model:
```python
class BrowserHistory:
    def __init__(self, start):
        self._back = []
        self._forward = []
        self._current = start

    @property
    def current(self):
        return self._current

    def visit(self, url):
        self._back.append(self._current)
        self._current = url
        self._forward.clear()

    def back(self):
        if not self._back:
            raise IndexError("no earlier page")
        self._forward.append(self._current)
        self._current = self._back.pop()
        return self._current

    def forward(self):
        if not self._forward:
            raise IndexError("no later page")
        self._back.append(self._current)
        self._current = self._forward.pop()
        return self._current
```
hint: Use two stacks: one for pages you can go back to and one for pages you can go forward to. The current page sits between them.
hint: `visit` pushes the current page on the back stack and empties the forward stack. `back` and `forward` move the current page onto the opposite stack, then pop the stack they are moving along. Check for an empty stack before changing anything.
solution: `back` pushes the current page on the forward stack and pops the back stack to become current; `forward` does the mirror image. `visit` records the page you leave and clears the forward stack, because a new visit starts a new branch of history. Raising before any change keeps the state unchanged on failure, and `current` is a getter-only property.

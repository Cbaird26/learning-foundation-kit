@article
Suppose a classifier is so confident about an image that nudging any pixel changes its output by almost nothing. Its gradient with respect to the input is nearly zero everywhere on the image, yet the output clearly depends on the input. A method that reports "no pixel matters" is wrong in an instructive way. This week's methods are three answers to the question "how should the output be divided among the inputs?"

### Gradients and saturation

The **gradient saliency map** (Simonyan, Vedaldi and Zisserman, 2013) scores feature $i$ by $\partial f / \partial x_i$ at the input. **Gradient times input** multiplies by $x_i$, which for a linear model recovers $w_i x_i$. Both are cheap, and both measure *local sensitivity*, not the contribution of a feature to the output. When a unit saturates (a sigmoid in its flat region, a ReLU that is off) the local gradient is small even for features that mattered earlier on the path from a neutral input.

### Integrated gradients

**Integrated gradients** (Sundararajan, Taly and Yan, 2017) integrate the gradient along the straight line from a baseline $\mathbf{x}'$ to the input $\mathbf{x}$:

$$\mathrm{IG}_i(\mathbf{x}) = (x_i - x'_i) \int_0^1 \frac{\partial f\big(\mathbf{x}' + \alpha(\mathbf{x} - \mathbf{x}')\big)}{\partial x_i}\, d\alpha .$$

By the fundamental theorem of calculus applied to $\alpha \mapsto f(\mathbf{x}' + \alpha(\mathbf{x} - \mathbf{x}'))$, the attributions satisfy the **completeness axiom**: $\sum_i \mathrm{IG}_i = f(\mathbf{x}) - f(\mathbf{x}')$, for differentiable $f$. In practice the integral is replaced by a Riemann sum with $m$ steps,

$$\mathrm{IG}_i \approx \frac{x_i - x'_i}{m} \sum_{k=1}^{m} \frac{\partial f}{\partial x_i}\Big(\mathbf{x}' + \tfrac{k}{m}(\mathbf{x} - \mathbf{x}')\Big),$$

and completeness holds only approximately; the gap $f(\mathbf{x}) - f(\mathbf{x}') - \sum_i \mathrm{IG}_i$ is a standard check on whether $m$ is large enough.

Take $f(\mathbf{x}) = \sigma(x_1 + 2x_2 - 1)$, $\mathbf{x} = (1, 1)$ and baseline $\mathbf{0}$. Then $f(\mathbf{x}) - f(\mathbf{0}) = 0.8808 - 0.2689 = 0.6119$. Gradient times input gives $(0.105, 0.210)$, summing to only $0.315$: the unit is nearly saturated at $\mathbf{x}$. With $m = 4$ the Riemann sum gives $\mathrm{IG} = (0.1898, 0.3796)$ with sum $0.5694$; with $m = 1000$ the sum is $0.6117$.

```python
from math import exp

def f(x):
    return 1 / (1 + exp(-(x[0] + 2 * x[1] - 1)))

def grad_f(x):
    p = f(x)
    return [p * (1 - p), 2 * p * (1 - p)]

def integrated_gradients(grad, x, base, m):
    total = [0.0] * len(x)
    for k in range(1, m + 1):
        point = [b + k / m * (xi - b) for xi, b in zip(x, base)]
        for i, g in enumerate(grad(point)):
            total[i] += g / m
    return [(xi - b) * t for xi, b, t in zip(x, base, total)]

ig = integrated_gradients(grad_f, [1, 1], [0, 0], 4)
print([round(v, 4) for v in ig])
```

Libraries compute the gradients by automatic differentiation; the algorithm is this loop.

### Shapley values

Shapley (1953) asked how to split the payoff of a cooperative game among players. Treat the features $N = \{1, \dots, n\}$ as players and let $v(S)$ be the model's value when only features in $S$ are "present" (how absent features are handled is a modeling choice, discussed below). The **Shapley value** of feature $i$ is its average marginal contribution over all orders in which features could be added:

$$\varphi_i = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!\,(n - |S| - 1)!}{n!}\,\big(v(S \cup \{i\}) - v(S)\big).$$

It is the unique attribution that satisfies **efficiency** ($\sum_i \varphi_i = v(N) - v(\emptyset)$), **symmetry** (features that contribute equally to every coalition get equal credit), the **dummy** property (a feature adding nothing to any coalition gets zero) and **additivity** across games. SHAP (Lundberg and Lee, 2017) applies Shapley values to model predictions and unifies several earlier methods, including LIME (Ribeiro, Singh and Guestrin, 2016), which fits a weighted local linear surrogate around the input. Exact computation needs $2^n$ evaluations, so practical implementations sample or exploit model structure.

The axioms do not settle the value function. Defining $v(S)$ by fixing the features in $S$ and averaging the others over a reference data set (interventional) or over their conditional distribution (observational) gives different attributions, and researchers disagree about which answers the intended question: the first asks what the model uses, the second what is informative about the output in the data.

### Do attributions explain anything?

Axioms say how credit is divided, not that the credit tracks the model's reasoning. Adebayo and colleagues (2018) proposed **sanity checks**: randomize the model's trained weights, layer by layer, or train on shuffled labels, and see whether the saliency maps change. A method whose maps barely change is not explaining the trained model, whatever it looks like. Several popular methods failed, which is why visual appeal is not accepted as evidence. The deeper open problem is that real models have no ground-truth attribution to compare with; evaluation relies on interventions (deletion, insertion), synthetic models whose answer is known, and human studies, each with its own limits.

@example
title: Exact Shapley values for three features
problem: Three features have the value function $v(\emptyset) = 0$, $v(\{1\}) = 10$, $v(\{2\}) = 20$, $v(\{3\}) = 6$, $v(\{1,2\}) = 50$, $v(\{1,3\}) = 18$, $v(\{2,3\}) = 28$, $v(\{1,2,3\}) = 66$. Compute the Shapley value of each feature and check efficiency.
step: For $n = 3$ the weights are $1/3$ for $S = \emptyset$, $1/6$ for each of the two singletons, and $1/3$ for the pair, since $|S|!(2 - |S|)!/3!$ equals $2/6$, $1/6$, $2/6$.
step: Feature 1: the marginals are $10 - 0 = 10$ (from $\emptyset$), $50 - 20 = 30$ (from $\{2\}$), $18 - 6 = 12$ (from $\{3\}$) and $66 - 28 = 38$ (from $\{2,3\}$). So $\varphi_1 = \tfrac13 \cdot 10 + \tfrac16 (30 + 12) + \tfrac13 \cdot 38 = 3.333 + 7 + 12.667 = 23$.
step: Feature 2: the marginals are $20$, $50 - 10 = 40$, $28 - 6 = 22$ and $66 - 18 = 48$. So $\varphi_2 = \tfrac13 \cdot 20 + \tfrac16 (40 + 22) + \tfrac13 \cdot 48 = 6.667 + 10.333 + 16 = 33$.
step: Feature 3: the marginals are $6$, $18 - 10 = 8$, $28 - 20 = 8$ and $66 - 50 = 16$. So $\varphi_3 = \tfrac13 \cdot 6 + \tfrac16 (8 + 8) + \tfrac13 \cdot 16 = 2 + 2.667 + 5.333 = 10$.
step: Check efficiency: $23 + 33 + 10 = 66 = v(\{1,2,3\}) - v(\emptyset)$.
answer: $\varphi = (23, 33, 10)$.

@mistakes
- Reading gradient times input as a contribution: at a saturated unit it can be near zero for a feature that clearly matters.
- Forgetting the baseline in integrated gradients: the attributions sum to $f(\mathbf{x}) - f(\mathbf{x}')$, not to $f(\mathbf{x})$, so a different baseline gives a different decomposition.
- Trusting completeness after a coarse Riemann sum: with few steps the attributions can miss the output change, and the gap should be reported.
- Treating Shapley values as causal effects: they depend on the value function chosen for absent features, and the axioms are silent on that choice.

@practice num
prompt: A one-feature model is $f(x) = x^3$. Compute the integrated-gradients attribution of the input $x = 2$ with baseline $x' = 0$ using a right Riemann sum with $m = 2$ steps (the points $\alpha = 1/2$ and $\alpha = 1$).

model:
```python
from itertools import combinations
from math import factorial


def shapley_values(v, n):
    """Exact Shapley values by averaging marginal contributions over coalitions."""
    values = []
    for i in range(n):
        others = [j for j in range(n) if j != i]
        total = 0.0
        for size in range(n):
            weight = factorial(size) * factorial(n - size - 1) / factorial(n)
            for coalition in combinations(others, size):
                with_i = tuple(sorted(coalition + (i,)))
                total += weight * (v[with_i] - v[coalition])
        values.append(total)
    return values
```
hint: For each feature, loop over all coalitions of the other features, weight each marginal contribution by $|S|!(n-|S|-1)!/n!$, and remember that coalitions are sorted tuples.
solution: Enumerate the subsets of the other features with `combinations`, which yields sorted tuples, and look up `v` for the coalition with and without feature `i`. The efficiency test (the values sum to the grand coalition's value) catches wrong weights, and the additive game catches a missing dummy or symmetry property.

@practice self
prompt: A colleague reports SHAP feature importances for a tabular model, using a background sample of 100 training rows to represent absent features, and concludes that "feature A is the most important feature in the real world". Critique the claim and design one check that tests a part of it.
hint: Ask what depends on the choice of background sample, and what happens when features are correlated.
solution: The attributions describe how the model's output is divided among features relative to the chosen background, not importance in the world. Three issues: the interventional value function breaks correlations (if A and B are strongly correlated, evaluating the model on combinations of A and B that never occur tests it off the data distribution, where its behavior was never constrained), so the numbers depend on the background and the dependence structure; Shapley values split credit among correlated features in a way that may hide that A is a proxy for B; and nothing here is causal, since the model may use A because it is a correlate of the true cause. A check: recompute the attributions with a different background (a subsample, or a conditional-sampling value function) and report how the ranking changes; if the ranking of A against B flips, the claim is not robust. A model-level check is a deletion test, replacing features in importance order and plotting the output, to see whether the ranking predicts the model's behavior. Claims about the world need causal assumptions or experiments, not attributions alone.
rubric: Separates what the model uses from importance in the world, and names the dependence of the result on the background or value function.
rubric: Identifies the effect of correlated features (off-distribution evaluation or credit splitting).
rubric: Designs a concrete check (alternative background or deletion test) and says how the result would bear on the claim.

solution: The marginals of feature 1 are $3$ from $\emptyset$, $12 - 3 = 9$ after feature 2, $3 - 0 = 3$ after feature 3, and $12 - 3 = 9$ after both. Then $\varphi_1 = 3/3 + (9 + 3)/6 + 9/3 = 1 + 2 + 3 = 6$. Feature 3 adds nothing to any coalition, so it is a dummy with value 0, and by symmetry feature 2 also gets 6.

@quiz self
prompt: Design a randomization sanity check (in the spirit of Adebayo and colleagues, 2018) for integrated gradients applied to an image classifier. State the procedure, one quantitative summary, and how you would interpret each possible outcome.

Summary: for each image, the rank correlation (or structural similarity) between the original map and the randomized-model map, reported as a distribution over images and layers, together with the same quantity between two independently trained real models as a reference. A low correlation does not show the method is faithful; it needs interventions such as deletion tests in addition.

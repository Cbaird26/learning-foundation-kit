@article
Last week's agent optimized a reward someone wrote by hand. For many tasks (a helpful answer, a safe one, a good summary) nobody can write the reward, but people can *compare* two outputs and say which is better. Learning from human feedback turns those comparisons into a training signal. What can go wrong when a model is trained to please a learned stand-in for human judgment?

### From comparisons to a reward model

Christiano and colleagues (2017) trained agents from human comparisons of short trajectory segments in simulated robotics and Atari games, by fitting a reward model to the comparisons and optimizing the agent against it. The standard model of comparisons is **Bradley-Terry**: if a reward model $r$ assigns scores to two outputs, the probability that the first is preferred is

$$P(y_w \succ y_l) = \sigma\big(r(y_w) - r(y_l)\big).$$

Given a data set of pairs (winner $y_w$, loser $y_l$) the reward model minimizes the negative log-likelihood

$$\ell = -\log \sigma\big(r(y_w) - r(y_l)\big).$$

Writing $\Delta = r(y_w) - r(y_l)$, the gradient is $\partial \ell / \partial r(y_w) = -\sigma(-\Delta)$ and $\partial \ell/\partial r(y_l) = +\sigma(-\Delta)$: mistakes ($\Delta < 0$) produce large gradients, and only the score difference matters, so rewards are determined up to an additive constant.

```python
from math import exp, log1p

def bt_loss(r_w, r_l):
    """Bradley-Terry loss -log sigmoid(r_w - r_l), computed stably."""
    return log1p(exp(-(r_w - r_l)))
```

### The RLHF objective

Ouyang and colleagues (2022), "InstructGPT", described the recipe for instruction following: fine-tune a pretrained model on human demonstrations, train a reward model on human comparisons of its outputs, then optimize the policy $\pi$ against the reward model with PPO, adding a penalty that keeps it near a reference policy $\pi_{\text{ref}}$ (the fine-tuned model). The objective for a prompt $x$ is

$$J(\pi) = \mathbb{E}_{y \sim \pi(\cdot \mid x)}\big[r(x, y)\big] - \beta\, D_{\mathrm{KL}}\big(\pi(\cdot \mid x)\,\Vert\,\pi_{\text{ref}}(\cdot \mid x)\big).$$

The KL term limits how far optimization can move the policy where the reward model is trustworthy. The maximizer has a closed form, $\pi^*(y \mid x) = \pi_{\text{ref}}(y \mid x)\, e^{r(x,y)/\beta} / Z(x)$ with $Z(x) = \sum_y \pi_{\text{ref}}(y \mid x)\, e^{r(x,y)/\beta}$, and the optimal value is $\beta \log Z(x)$. As $\beta \to \infty$ the optimum is $\pi_{\text{ref}}$; as $\beta \to 0$ it concentrates on the highest-reward output. Ouyang and colleagues reported that human raters preferred outputs of a much smaller model trained this way to those of a far larger base model on their prompt distribution.

**Constitutional AI** (Bai and colleagues, 2022) replaces some human comparisons by feedback generated by a model following written principles (week 10).

### Direct preference optimization

Rafailov and colleagues (2023) noticed that the closed form can be inverted: $r(x,y) = \beta \log \frac{\pi^*(y \mid x)}{\pi_{\text{ref}}(y \mid x)} + \beta \log Z(x)$. Substituting into the Bradley-Terry loss makes $Z(x)$ cancel in the difference, giving a loss on the policy itself, with no separate reward model and no RL loop:

$$\ell_{\text{DPO}} = -\log \sigma\Big(\beta\Big[\log\tfrac{\pi(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \log\tfrac{\pi(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)}\Big]\Big).$$

DPO optimizes the same KL-regularized objective implicitly, under the Bradley-Terry assumption. Whether it matches online RLHF in practice, and how it behaves under distribution shift and overoptimization, is an active empirical question.

### Overoptimization

A reward model is a proxy trained on finite data. Gao, Schulman and Hilton (2022) studied this with a fixed "gold" reward model standing in for humans, and smaller proxy models trained on its labels. As the policy is optimized further from its starting point (measured by KL divergence, or by the number of samples in best-of-$n$), the proxy reward keeps rising while the gold reward first rises and then falls. They fit smooth functional forms in the square root of the KL distance, and found that the gold peak moves out as the reward model gets more data and parameters. Best-of-$n$ sampling has a KL divergence from the base policy of $\log n - (n-1)/n$ for a continuous reward.

### Limits and the open question

Casper and colleagues (2023) surveyed open problems and limitations in three groups: **problems with feedback** (evaluators are fallible, biased, inconsistent, can be deceived, and cannot judge what they cannot evaluate); **problems with the reward model** (a single scalar cannot represent diverse values, misspecification, overoptimization); and **problems with the policy** (RL is hard to make stable, and learned behavior can generalize badly).

Can learning from human feedback be made reliable? The optimistic position: it has a strong empirical record for making models more useful and less likely to produce objectionable content; its failures are the kind that better data, ensembles of reward models, regularization, targeted feedback on failures and iteration reduce; and reliability is an engineering target. The pessimistic position: the method optimizes for what raters approve of, not what is true or good, so it rewards outputs that look right to the rater, including flattery and confident error; overoptimization is guaranteed by the logic of optimizing a proxy; and the approach has no answer when the task exceeds the rater's ability to judge, which is the case that matters most. Both agree that the technique is not by itself a complete solution; they differ on whether it is a foundation to build on or a stopgap that hides the problem. The evidence available now does not decide between them.

@example
title: Bradley-Terry loss and a gradient step
problem: A reward model scores a preferred output $r_w = 1.2$ and a rejected output $r_l = 0.4$. Compute the loss and the gradients, then take one gradient-descent step of size 0.5 on the two scores and recompute the loss.
step: The difference is $\Delta = 0.8$ and $\sigma(0.8) = 0.690$, so $\ell = -\log 0.690 = 0.371$.
step: The gradient is $\partial\ell/\partial r_w = -\sigma(-0.8) = -0.310$ and $\partial\ell/\partial r_l = +0.310$.
step: Update with step size $0.5$: $r_w \leftarrow 1.2 + 0.5(0.310) = 1.355$ and $r_l \leftarrow 0.4 - 0.5(0.310) = 0.245$.
step: The new difference is $1.110$ and the new loss is $-\log\sigma(1.110) = 0.285$, lower than $0.371$: the step widened the margin.
answer: Loss $0.371$, then $0.285$ after the step.

@example
title: The KL-regularized optimum for three responses
problem: Three responses have reference probabilities $\pi_{\text{ref}} = (0.5, 0.3, 0.2)$ and rewards $r = (1, 0.5, 2)$, with $\beta = 0.5$. Find the optimal policy and compare its objective value with that of $\pi_{\text{ref}}$.
step: The weights $\pi_{\text{ref}}\,e^{r/\beta}$ are $0.5\,e^{2} = 3.695$, $0.3\,e^{1} = 0.815$ and $0.2\,e^{4} = 10.920$. Their sum is $Z = 15.430$.
step: Normalize: $\pi^* = (0.239, 0.053, 0.708)$. The highest-reward response, which was least likely under the reference, now has most of the probability.
step: The optimal value is $\beta\log Z = 0.5 \times 2.736 = 1.368$.
step: For $\pi_{\text{ref}}$ the KL term is zero and the expected reward is $0.5 + 0.15 + 0.4 = 1.05$, so $J(\pi_{\text{ref}}) = 1.05 < 1.368$.
answer: $\pi^* = (0.239, 0.053, 0.708)$ with value $1.368$ versus $1.05$.

@mistakes
- Treating the reward model's score as a measurement of human values: it is a proxy fit to finite, noisy comparisons, and optimizing it hard moves the policy to where the proxy is unreliable.
- Using proxy reward as the evaluation metric: the proxy keeps rising during overoptimization while true quality falls, so evaluate with held-out human judgments or a separate gold signal.
- Forgetting that Bradley-Terry depends only on score differences: adding a constant to all rewards changes nothing, so absolute reward values are not meaningful.
- Reading the KL coefficient $\beta$ backwards: a larger $\beta$ keeps the policy closer to the reference, and a smaller one allows more optimization against the reward model.

model:
```python
from math import exp, log1p


def dpo_loss(logp_w, logp_l, ref_w, ref_l, beta):
    """DPO loss for one preference pair."""
    margin = beta * ((logp_w - ref_w) - (logp_l - ref_l))
    if margin >= 0:
        return log1p(exp(-margin))
    return -margin + log1p(exp(margin))
```
hint: Compute the margin $m = \beta[\dots]$ first; the loss is $\log(1 + e^{-m})$, which you can rewrite as $-m + \log(1 + e^{m})$ when $m$ is negative.
solution: The loss is the softplus of $-m$. For a very negative margin, `exp(-m)` would overflow, so the model uses the identity $\log(1 + e^{-m}) = -m + \log(1 + e^{m})$ in that case. The last test has margin $-1000$ and would fail with a naive formula.

@article
A box around a pedestrian is a rough answer: it also contains sidewalk, a bicycle wheel and some sky. For a robot arm that must grasp a cup, or a radiologist measuring a tumor, the outline matters. **Segmentation** answers "which pixels belong to what?"

### Conventions used in this course

A **mask** is a grid of 0s and 1s with the same shape as the image, row-major (`mask[r][c]`), with 1 for pixels of the object. A **label map** is a grid of integers, one class id (or instance id) per pixel. Connectivity is **4-connectivity** (a pixel touches its up, down, left and right neighbors) unless a problem says 8-connectivity (it also touches the four diagonal neighbors). Component labels are numbered $1, 2, 3, \dots$ in the order in which the first pixel of each component is met when scanning row by row from the top-left.

### Kinds of segmentation

**Semantic segmentation** assigns a class to every pixel ("road", "car", "sky") but does not distinguish two cars: all car pixels share one label. **Instance segmentation** outputs one mask per object, each with a class and a score, so two touching cars get two masks, but background "stuff" such as sky is usually not labeled. **Panoptic segmentation** combines both: every pixel gets a class, and pixels of countable things also get an instance id.

Fully convolutional networks (Long, Shelhamer and Darrell, 2015) made semantic segmentation a dense prediction problem by replacing the final fully connected layers with convolutions so the network outputs a class-score map. The encoder shrinks the spatial size, so the decoder must **upsample**, by nearest-neighbor or bilinear interpolation or by learned transposed convolutions. U-Net (Ronneberger, Fischer and Brox, 2015) adds skip connections that pass high-resolution encoder features to the decoder. Mask R-CNN (He and colleagues, 2017) extends a two-stage detector with a branch that predicts a mask inside each detected box, which gives instance segmentation.

### Scoring masks

For a predicted mask $P$ and a ground-truth mask $G$ (as sets of pixels), the mask IoU is $|P \cap G|/|P \cup G|$, and the **Dice coefficient** is $2|P \cap G|/(|P| + |G|)$. If $P$ has 3 pixels, $G$ has 4 and they share 3, then $\mathrm{IoU} = 3/4 = 0.75$ and $\mathrm{Dice} = 6/7 \approx 0.857$. The two are related by $\mathrm{Dice} = 2\,\mathrm{IoU}/(1 + \mathrm{IoU})$, so they rank results the same way.

For semantic segmentation, build a confusion matrix with true classes as rows and predicted classes as columns. The IoU of class $k$ is $\mathrm{TP}_k/(\mathrm{TP}_k + \mathrm{FP}_k + \mathrm{FN}_k)$ and the **mean IoU** (mIoU) is the average over classes. **Pixel accuracy**, the fraction of correct pixels, can mislead: a model that labels every pixel "background" in an image that is 95% background scores 95% pixel accuracy but an IoU of 0 on the object class, an mIoU of about 0.475.

### Instances from a semantic mask

A simple way to split a binary mask into objects is **connected-component labeling**: scan the grid, and whenever you meet a foreground pixel with no label yet, start a new label and flood-fill all foreground pixels reachable from it. This finds separate blobs but merges touching objects, which is why learned instance methods are needed when objects overlap. The same comparison machinery as in detection carries over: instance masks can be matched with mask IoU, and duplicate masks can be removed by non-maximum suppression with mask IoU in place of box IoU.

### In code

```python
def label_components(mask):
    """4-connected components; returns (label grid, count)."""
    h, w = len(mask), len(mask[0])
    labels = [[0] * w for _ in range(h)]
    count = 0
    for r in range(h):
        for c in range(w):
            if mask[r][c] == 1 and labels[r][c] == 0:
                count += 1
                labels[r][c] = count
                stack = [(r, c)]
                while stack:
                    y, x = stack.pop()
                    for dy, dx in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                        ny, nx = y + dy, x + dx
                        if (0 <= ny < h and 0 <= nx < w
                                and mask[ny][nx] == 1 and labels[ny][nx] == 0):
                            labels[ny][nx] = count
                            stack.append((ny, nx))
    return labels, count

mask = [[1, 1, 0, 0], [0, 1, 0, 1], [0, 0, 0, 1], [1, 0, 0, 1]]
print(label_components(mask))
```

SciPy's `scipy.ndimage.label` and OpenCV's `connectedComponents` do the same; the point here is the flood fill.

@example
title: Mean IoU from a confusion matrix
problem: A two-class segmentation has a confusion matrix (rows true class, columns predicted) of $\begin{bmatrix} 80 & 20 \\ 10 & 40 \end{bmatrix}$. Find each class IoU, mIoU and pixel accuracy.
step: Class 0: $\mathrm{TP} = 80$, $\mathrm{FN} = 20$ (true 0, predicted 1), $\mathrm{FP} = 10$ (true 1, predicted 0). $\mathrm{IoU}_0 = 80/110 \approx 0.727$.
step: Class 1: $\mathrm{TP} = 40$, $\mathrm{FN} = 10$, $\mathrm{FP} = 20$. $\mathrm{IoU}_1 = 40/70 \approx 0.571$.
step: $\mathrm{mIoU} = (0.727 + 0.571)/2 \approx 0.649$. Pixel accuracy is $(80 + 40)/150 = 0.8$.
answer: IoUs 0.727 and 0.571, mIoU about 0.649, pixel accuracy 0.8.
@mistakes
- Reporting pixel accuracy on imbalanced images: a model that predicts only the common class can look excellent while missing every object.
- Using 8-connectivity when the problem asks for 4-connectivity (or vice versa): diagonal pixels then merge into one component or stay separate.
- Treating semantic segmentation as instance segmentation: two adjacent cars of the same class share one label, and connected components cannot split them if they touch.

```python
def mask_scores(pred, gt):
    """IoU and Dice of two binary masks."""
    inter = union = size_p = size_g = 0
    for rp, rg in zip(pred, gt):
        for p, g in zip(rp, rg):
            inter += 1 if (p and g) else 0
            union += 1 if (p or g) else 0
            size_p += 1 if p else 0
            size_g += 1 if g else 0
    if union == 0:
        return 1.0, 1.0
    return inter / union, 2 * inter / (size_p + size_g)
```
hint: Count the pixels in the intersection, the union and each mask, and handle the case where the union is empty first.
solution: Dice divides by the sum of the two sizes, not by the union. For the last test the overlap is 1 pixel, the union 3 and the sizes 2 and 2, giving IoU $1/3$ and Dice $2/4 = 0.5$. Two empty masks agree perfectly by convention.

```python
def components8(mask):
    """8-connected component labeling by flood fill."""
    h, w = len(mask), len(mask[0])
    labels = [[0] * w for _ in range(h)]
    count = 0
    steps = [(dy, dx) for dy in (-1, 0, 1) for dx in (-1, 0, 1)
             if (dy, dx) != (0, 0)]
    for r in range(h):
        for c in range(w):
            if mask[r][c] == 1 and labels[r][c] == 0:
                count += 1
                labels[r][c] = count
                stack = [(r, c)]
                while stack:
                    y, x = stack.pop()
                    for dy, dx in steps:
                        ny, nx = y + dy, x + dx
                        if (0 <= ny < h and 0 <= nx < w
                                and mask[ny][nx] == 1 and labels[ny][nx] == 0):
                            labels[ny][nx] = count
                            stack.append((ny, nx))
    return labels, count
```
hint: Reuse the flood fill idea from the article, but loop over all eight offsets instead of four.
solution: With 8-connectivity the diagonal pixels of the first test join into one component, while 4-connectivity would give two. In the second test the pixel at the bottom left stays alone and the pixels at the bottom right join each other; the labels come from the scan order.

```python
def mask_nms(masks, scores, tau):
    """Greedy NMS using mask IoU."""
    def miou(a, b):
        inter = union = 0
        for ra, rb in zip(a, b):
            for p, q in zip(ra, rb):
                inter += 1 if (p and q) else 0
                union += 1 if (p or q) else 0
        return inter / union if union else 0.0

    order = sorted(range(len(masks)), key=lambda i: (-scores[i], i))
    keep = []
    for i in order:
        if all(miou(masks[k], masks[i]) <= tau for k in keep):
            keep.append(i)
    return keep
```
hint: Go through the masks in score order and keep one only if its mask IoU with every already kept mask is at most `tau`.
solution: This is the same greedy procedure as box NMS, with mask IoU replacing box IoU. The second mask has IoU exactly 0.75 with the first, which is not strictly greater than a threshold of 0.75, so it survives there; in the third test the lower-scoring larger mask is processed after the smaller one, and the smaller one wins.

model:
```python
def semantic_miou(pred, gt, num_classes):
    """Mean IoU over the classes present in the prediction or truth."""
    ious = []
    for k in range(num_classes):
        inter = union = 0
        for rp, rg in zip(pred, gt):
            for p, g in zip(rp, rg):
                inter += 1 if (p == k and g == k) else 0
                union += 1 if (p == k or g == k) else 0
        if union > 0:
            ious.append(inter / union)
    return sum(ious) / len(ious)
```
hint: For each class count pixels where both maps equal it and where at least one does, skip empty unions, and average.
solution: A class present only in the ground truth still counts, with IoU 0, as the last test shows: class 0 has IoU $1/2$ and class 1 has IoU 0, so the mean is $0.25$. A class that appears nowhere (the third class in the second test) is skipped, not counted as 1 or 0.

@article
A digit recognizer receives a $28 \times 28$ image, 784 numbers. A fully connected hidden layer of 100 units has $784 \cdot 100 + 100 = 78{,}500$ parameters, and it treats pixel (3, 4) and pixel (3, 5) as unrelated inputs. Two things are wrong: the count explodes for larger images, and a stroke shifted by one pixel looks to the layer like a completely different input. A **convolutional neural network** (CNN) fixes both by reusing the same small filter at every position.

### Conventions used in this course

A feature map with $C$ channels, height $H$ and width $W$ is a list of $C$ images, each a list of rows (row-major). A convolution layer has $C_{\text{out}}$ **filters**; each filter is a list of $C_{\text{in}}$ kernels of size $k_h \times k_w$, and has one bias. As in most libraries, "convolution" means **correlation** (no flip). We use **valid** mode and stride 1 unless said otherwise: the output has $C_{\text{out}}$ channels and shape $(H - k_h + 1) \times (W - k_w + 1)$. Filter $f$ computes

$$y_f(r, c) = b_f + \sum_{ch=0}^{C_{\text{in}}-1} \sum_{i,j} x_{ch}(r + i, c + j)\, K_{f,ch}(i, j).$$

### Why it works

A layer with $C_{\text{out}}$ filters has $C_{\text{out}}(C_{\text{in}} k_h k_w + 1)$ parameters whatever the image size. Eight $3 \times 3$ filters on a gray image have $8 \cdot (9 + 1) = 80$. This **weight sharing** also gives **translation equivariance**: shifting the input shifts the feature map by the same amount (apart from borders). Early layers learn small oriented edge and color detectors, and the hand-designed Sobel kernels of the last lesson are exactly the kind of filter such a layer can hold.

A **nonlinearity** is needed between layers; the standard is $\operatorname{ReLU}(z) = \max(0, z)$ applied to every entry. **Max pooling** with window $s$ and stride $s$ replaces each $s \times s$ block by its maximum, shrinking the map to $\lfloor H/s \rfloor \times \lfloor W/s \rfloor$ and making the output insensitive to small shifts. Finally the feature maps are flattened into a vector, passed through a linear layer to class scores $\mathbf{z}$, and turned into probabilities by the softmax,

$$p_k = \frac{e^{z_k - \max_j z_j}}{\sum_{m} e^{z_m - \max_j z_j}}.$$

Subtracting the maximum changes nothing mathematically and avoids overflow. Training minimizes the cross-entropy $-\log p_y$ of the true class $y$ by backpropagation.

### Receptive fields

The **receptive field** of a unit is the patch of the input that can affect it. For layer $l$ with kernel size $k_l$ and cumulative stride (jump) $j_{l-1}$ in front of it, $r_l = r_{l-1} + (k_l - 1)\,j_{l-1}$, and the jump becomes $j_l = j_{l-1} s_l$. Two stacked $3 \times 3$ convolutions see $3 + 2 = 5$ pixels across, three see 7. Stacking small kernels reaches the same field as one large kernel with fewer parameters: for $C$ channels in and out, two $3 \times 3$ layers use $18C^2$ weights against $25C^2$ for one $5 \times 5$.

### A short history

LeCun and colleagues trained convolutional networks with backpropagation to read handwritten digits (1989), and the LeNet family (1998) became the standard recipe of convolution, subsampling and a classifier. After the ImageNet classification challenge (Deng and colleagues, 2009), AlexNet (Krizhevsky, Sutskever and Hinton, 2012) won it by a wide margin with a deep CNN trained on GPUs. Residual networks (He and colleagues, 2015) added skip connections, $\mathbf{y} = \mathbf{x} + F(\mathbf{x})$, which let networks hundreds of layers deep train.

### In code

```python
def relu_map(x):
    """ReLU on a feature map: list of channels of list of rows."""
    return [[[max(0, v) for v in row] for row in ch] for ch in x]

def max_pool2(img):
    """2x2 max pooling, stride 2, on one channel; drops odd edges."""
    return [[max(img[r][c], img[r][c + 1], img[r + 1][c], img[r + 1][c + 1])
             for c in range(0, len(img[0]) - 1, 2)]
            for r in range(0, len(img) - 1, 2)]

print(max_pool2([[1, 3, 2, 0], [4, 2, 1, 1], [0, 0, 5, 6], [1, 2, 7, 8]]))
```

title: Shapes and parameters of a small network
problem: A network takes a $1 \times 8 \times 8$ image, applies 4 filters of size $3 \times 3$ (valid, stride 1), ReLU, $2 \times 2$ max pooling, flattening, and a linear layer to 10 classes. Find the shape after each step and the number of parameters.
step: Convolution: the output is $4 \times (8-3+1) \times (8-3+1) = 4 \times 6 \times 6$, with $4(1 \cdot 9 + 1) = 40$ parameters.
step: ReLU keeps the shape $4 \times 6 \times 6$ and has no parameters. Max pooling gives $4 \times 3 \times 3$.
step: Flattening gives a vector of $4 \cdot 3 \cdot 3 = 36$ numbers. The linear layer has $36 \cdot 10 + 10 = 370$ parameters.
step: The total is $40 + 370 = 410$ parameters, against $64 \cdot 10 + 10 = 650$ for a single linear layer on the raw pixels.
answer: Shapes $4\times6\times6$, $4\times6\times6$, $4\times3\times3$, 36, 10; 410 parameters.
@example
title: Convolution, ReLU and max pooling by hand
problem: Apply the kernel $\begin{bmatrix}1&0&-1\\1&0&-1\\1&0&-1\end{bmatrix}$ (valid, no flip) to $\begin{bmatrix}1&2&0&1\\3&0&1&2\\1&1&0&0\\2&3&1&1\end{bmatrix}$, then ReLU, then $2 \times 2$ max pooling.
step: The output of the valid convolution is $2 \times 2$. At the top left, the left column sums to $1+3+1 = 5$ and the right column to $0+1+0 = 1$, so the response is $5 - 1 = 4$.
step: The other three positions give $0$, $4$ and $1$: the map is $\begin{bmatrix}4&0\\4&1\end{bmatrix}$.
step: ReLU leaves it unchanged because no entry is negative. Max pooling over the single $2 \times 2$ block gives 4.
answer: The convolution map is $\begin{bmatrix}4&0\\4&1\end{bmatrix}$ and the pooled output is $4$.
@mistakes
- Counting parameters as if each position had its own weights: a filter's weights are shared across all positions, so the count depends on kernel size and channels, not image size.
- Forgetting the input channels: a filter over a 3-channel image has $3 \times k_h \times k_w$ weights plus one bias, not $k_h \times k_w$.
- Stacking linear layers without a nonlinearity: two convolutions in a row with no ReLU between them equal a single convolution with a larger kernel.

```python
def conv_layer(x, filters, biases):
    """Multi-channel valid correlation with one bias per filter."""
    out = []
    for kernels, bias in zip(filters, biases):
        kh, kw = len(kernels[0]), len(kernels[0][0])
        h, w = len(x[0]), len(x[0][0])
        fmap = []
        for r in range(h - kh + 1):
            row = []
            for c in range(w - kw + 1):
                total = bias
                for ch, ker in zip(x, kernels):
                    for i in range(kh):
                        for j in range(kw):
                            total += ch[r + i][c + j] * ker[i][j]
                row.append(total)
            fmap.append(row)
        out.append(fmap)
    return out
```
hint: For every filter and every output position, start from the bias and add the window-times-kernel products from each input channel.
solution: The sum runs over channels as well as over the kernel window, which is why a filter holds one kernel per input channel. The second test uses the Sobel kernel as a first-layer filter and finds the vertical edge; the last test fails if only the first channel is used or the bias is added once per channel.

```python
def pool(img, size, mode):
    """Non-overlapping max or average pooling; incomplete windows dropped."""
    out = []
    for r in range(0, len(img) - size + 1, size):
        row = []
        for c in range(0, len(img[0]) - size + 1, size):
            window = [img[r + i][c + j]
                      for i in range(size) for j in range(size)]
            if mode == 'max':
                row.append(max(window))
            else:
                row.append(sum(window) / len(window))
        out.append(row)
    return out
```
hint: Step the top-left corner of each window by `size` while the whole window still fits; collect its values and take `max` or the mean.
solution: Stopping at `len(img) - size + 1` drops incomplete windows, which gives $\lfloor H/s \rfloor$ rows. The last test has one row, which cannot hold a $2 \times 2$ window, so the output is empty.

```python
import math

def cnn_probs(img, kernel, w, b):
    """Valid conv, ReLU, flatten, linear layer, stable softmax."""
    kh, kw = len(kernel), len(kernel[0])
    feats = []
    for r in range(len(img) - kh + 1):
        for c in range(len(img[0]) - kw + 1):
            total = 0
            for i in range(kh):
                for j in range(kw):
                    total += img[r + i][c + j] * kernel[i][j]
            feats.append(max(0, total))
    z = [sum(wi * f for wi, f in zip(row, feats)) + bk
         for row, bk in zip(w, b)]
    m = max(z)
    exps = [math.exp(v - m) for v in z]
    s = sum(exps)
    return [v / s for v in exps]
```
hint: Compute the four features first (convolution then ReLU), then the scores, then subtract the largest score before exponentiating.
solution: With the right-brightening kernel each of the four features is 6, so the scores are $0.1 \cdot 24 = 2.4$ and $0.5$. The opposite kernel gives negative responses, which ReLU turns into zeros, leaving only the biases. The last test has a score near 2400 and overflows without subtracting the maximum.

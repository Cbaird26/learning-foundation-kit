@article
A detector with anchors at every position produces a flurry of boxes around each object: the box that fits best, and a dozen neighbors that nearly fit. If you report them all, one person in a photo becomes twelve detections and eleven are counted as false alarms. **Non-maximum suppression** (NMS) keeps the best box in each cluster and discards the rest.

### Conventions used in this course

A detection is a box $(x_1, y_1, x_2, y_2)$ with **exclusive** right and bottom edges (width $x_2 - x_1$), a confidence score and, when classes matter, a label. IoU is as in the last lesson. In **greedy NMS** with threshold $\tau$:

1. Sort detections by score, highest first. **Ties** are broken by the smaller original index.
2. Keep the first remaining detection and remove every other remaining detection whose IoU with it is **strictly greater** than $\tau$ (an IoU exactly equal to $\tau$ is kept).
3. Repeat with the next remaining detection until none are left.

NMS is normally run **per class**: a person box and a bicycle box covering the same pixels do not suppress each other. The threshold controls a trade-off. A low $\tau$ (say 0.3) suppresses aggressively, which removes duplicates but also removes real neighbors in a crowd; a high $\tau$ (say 0.7) keeps more overlapping boxes and so more duplicates. Variants such as soft-NMS lower the scores of overlapping boxes instead of deleting them.

### Matching detections to ground truth

To score a detector we must decide which detections are correct. Take the detections of one class, sorted by score from highest to lowest. For each detection find the unmatched ground-truth box with the highest IoU. If that IoU is at least a threshold (commonly 0.5), the detection is a **true positive** (TP) and that ground-truth box is marked matched, so it cannot be matched again; otherwise the detection is a **false positive** (FP). Ground-truth boxes left unmatched are **false negatives** (FN). A second detection of an already matched object is therefore an FP, which is why NMS matters for the metric.

From the counts, **precision** $= \mathrm{TP}/(\mathrm{TP} + \mathrm{FP})$ is the fraction of detections that are right, **recall** $= \mathrm{TP}/(\mathrm{TP} + \mathrm{FN})$ is the fraction of true objects found, and $F_1 = 2PR/(P + R)$ combines them. With 6 TP, 4 FP and 2 FN, $P = 0.6$, $R = 0.75$ and $F_1 = 2 \cdot 0.6 \cdot 0.75/1.35 \approx 0.667$.

### Average precision

Both numbers depend on the score cutoff. Walking down the ranked list and recomputing precision and recall after each detection traces a **precision–recall curve**. **Average precision** (AP) is the area under it, computed with the precision envelope: at each recall level, use the largest precision achieved at that recall or higher. In symbols, with recall values $r_1 \le r_2 \le \dots$ after each detection, $r_0 = 0$ and envelope $\hat p_i = \max_{j \ge i} p_j$,

$$\mathrm{AP} = \sum_i (r_i - r_{i-1})\,\hat p_i.$$

Suppose the ranked outcomes are TP, FP, TP, TP, FP with 4 ground-truth boxes. After each step (precision, recall): $(1, 0.25)$, $(0.5, 0.25)$, $(0.667, 0.5)$, $(0.75, 0.75)$, $(0.6, 0.75)$. The envelope is $1, 0.75, 0.75, 0.75, 0.6$, and the recall increases are $0.25, 0, 0.25, 0.25, 0$, so $\mathrm{AP} = 0.25 \cdot 1 + 0.25 \cdot 0.75 + 0.25 \cdot 0.75 = 0.625$. Recall never reaches 1 here, and the missed objects count as precision 0 beyond 0.75.

**Mean average precision** (mAP) averages AP over classes. The PASCAL VOC benchmark reports it at one IoU threshold, 0.5; the COCO benchmark averages AP over IoU thresholds from 0.5 to 0.95 in steps of 0.05, which also rewards precise localization. mAP numbers from different benchmarks, thresholds and implementations are not comparable, so always check which protocol is meant.

### In code

```python
def iou(a, b):
    w = min(a[2], b[2]) - max(a[0], b[0])
    h = min(a[3], b[3]) - max(a[1], b[1])
    if w <= 0 or h <= 0:
        return 0.0
    inter = w * h
    union = ((a[2] - a[0]) * (a[3] - a[1])
             + (b[2] - b[0]) * (b[3] - b[1]) - inter)
    return inter / union

def nms(dets, tau):
    """dets: list of (box, score). Returns kept indices, best first."""
    order = sorted(range(len(dets)), key=lambda i: (-dets[i][1], i))
    keep = []
    while order:
        best = order.pop(0)
        keep.append(best)
        order = [i for i in order
                 if iou(dets[best][0], dets[i][0]) <= tau]
    return keep

dets = [((0, 0, 10, 10), 0.9), ((1, 1, 11, 11), 0.8), ((30, 30, 40, 40), 0.7)]
print(nms(dets, 0.5))
```

torchvision provides `nms` and `batched_nms` (the per-class version) as fast compiled operators that follow the same logic.

title: Greedy NMS on four detections
problem: Four detections (exclusive edges) are $d_0 = ((0,0,10,10), 0.6)$, $d_1 = ((0,0,10,5), 0.9)$, $d_2 = ((20,0,30,10), 0.8)$ and $d_3 = ((0,5,10,10), 0.7)$. Run NMS with $\tau = 0.5$.
step: Sorted by score: $d_1$ (0.9), $d_2$ (0.8), $d_3$ (0.7), $d_0$ (0.6). Keep $d_1 = (0,0,10,5)$, area 50.
step: Against $d_1$: $d_2$ is disjoint, IoU 0, so it stays. $d_3 = (0,5,10,10)$ touches $d_1$ along an edge, IoU 0, so it stays. $d_0$ contains $d_1$ with intersection 50 and union 100, IoU exactly 0.5, which is not strictly greater than $\tau$, so it stays.
step: Keep $d_2$ next: it is disjoint from $d_3$ and $d_0$, so nothing else is removed.
step: Keep $d_3$ (0.7). Its IoU with $d_0$ is $50/100 = 0.5$, again not greater than 0.5, so $d_0$ survives and is kept last.
answer: All four detections are kept, in the order $d_1, d_2, d_3, d_0$.

problem: A detector has 5 ground-truth boxes. Its ranked detections are TP, TP, FP, TP, FP, FP. Find the final precision and recall and the average precision.
step: Final counts: TP $= 3$, FP $= 3$, FN $= 5 - 3 = 2$. Precision $= 3/6 = 0.5$, recall $= 3/5 = 0.6$.

@mistakes
- Running NMS across classes: a person and a bicycle can legitimately overlap, so boxes of different classes should not suppress each other.
- Counting a second detection of an already matched object as a true positive: each ground-truth box can be matched once, so the extra box is a false positive.
- Averaging precision values at the ranks of true positives without the envelope or the recall weights, or comparing mAP numbers computed with different IoU thresholds.

```python
def nms_per_class(dets, tau):
    """Greedy NMS applied separately to each label."""
    def iou(a, b):
        w = min(a[2], b[2]) - max(a[0], b[0])
        h = min(a[3], b[3]) - max(a[1], b[1])
        if w <= 0 or h <= 0:
            return 0.0
        inter = w * h
        area_a = (a[2] - a[0]) * (a[3] - a[1])
        area_b = (b[2] - b[0]) * (b[3] - b[1])
        return inter / (area_a + area_b - inter)

    order = sorted(range(len(dets)), key=lambda i: (-dets[i][1], i))
    keep = []
    for i in order:
        suppressed = any(dets[k][2] == dets[i][2]
                         and iou(dets[k][0], dets[i][0]) > tau
                         for k in keep)
        if not suppressed:
            keep.append(i)
    return keep
```
hint: Process detections in sorted order and keep one unless a previously kept detection with the same label overlaps it by strictly more than `tau`.
solution: Checking each candidate against the already kept detections of its label is equivalent to the repeat-and-remove loop. The third test has IoU exactly 0.5, which is not strictly greater than 0.5 and so both boxes are kept; the tie test checks that equal scores keep the smaller index.

```python
def average_precision(is_tp, num_gt):
    """All-point average precision with the precision envelope."""
    tp = 0
    precision, recall = [], []
    for n, hit in enumerate(is_tp, start=1):
        tp += 1 if hit else 0
        precision.append(tp / n)
        recall.append(tp / num_gt)
    for i in range(len(precision) - 2, -1, -1):
        precision[i] = max(precision[i], precision[i + 1])
    ap = 0.0
    prev = 0.0
    for p, r in zip(precision, recall):
        ap += (r - prev) * p
        prev = r
    return ap
```
hint: First build the precision and recall lists; then sweep the precision list from the end, replacing each value by the larger of itself and its right neighbor; finally sum the recall increments times the envelope.
solution: The backward sweep creates the envelope, so a high precision at a late rank lifts the earlier ones. Recall increases only at true positives, so only those ranks contribute. The `[True]` test shows that missed ground-truth boxes are penalized: recall stops at 0.5, so the AP is 0.5.

```python
def match_dets(dets, gts, thr):
    """Greedy matching of ranked detections to ground-truth boxes."""
    def iou(a, b):
        w = min(a[2], b[2]) - max(a[0], b[0])
        h = min(a[3], b[3]) - max(a[1], b[1])
        if w <= 0 or h <= 0:
            return 0.0
        inter = w * h
        area_a = (a[2] - a[0]) * (a[3] - a[1])
        area_b = (b[2] - b[0]) * (b[3] - b[1])
        return inter / (area_a + area_b - inter)

    order = sorted(range(len(dets)), key=lambda i: (-dets[i][1], i))
    matched = [False] * len(gts)
    result = []
    for i in order:
        best, best_iou = -1, 0.0
        for j, g in enumerate(gts):
            if matched[j]:
                continue
            v = iou(dets[i][0], g)
            if v > best_iou:
                best, best_iou = j, v
        if best >= 0 and best_iou >= thr:
            matched[best] = True
            result.append(True)
        else:
            result.append(False)
    return result
```
hint: For each detection scan the unmatched ground-truth boxes for the highest IoU, then compare it with `thr` and mark that box matched.
solution: Choosing the best-IoU unmatched box, not the first one above the threshold, matters in the second test: the first detection overlaps both ground-truth boxes at the low threshold 0.2 and must take the better one, or the second detection (which only fits the first ground-truth box) loses its match. In the first test the duplicate of an already matched object is a false positive.

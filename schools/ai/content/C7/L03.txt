@article
An $m \times n$ matrix has $m$ rows and $n$ columns. Matrices add entrywise (same shape required) and scale entrywise. The interesting operation is multiplication.

### The product $AB$

If $A$ is $m \times n$ and $B$ is $n \times p$, then $AB$ is $m \times p$ and

$$(AB)_{ij} = \sum_{k=1}^{n} A_{ik} B_{kj},$$

the dot product of row $i$ of $A$ with column $j$ of $B$. The inner dimensions must match. There are three more views of the same product, and each is useful:

- **Columns**: each column of $AB$ is $A$ times the corresponding column of $B$, so it is a linear combination of the columns of $A$.
- **Rows**: each row of $AB$ is the corresponding row of $A$ times $B$, a linear combination of the rows of $B$.
- **Columns times rows**: $AB$ is the sum over $k$ of (column $k$ of $A$)(row $k$ of $B$), a sum of $n$ rank-one matrices.

Computing $AB$ with the definition takes $mnp$ multiplications; for two $n\times n$ matrices that is $n^3$.

```python
def matmul(A, B):
    return [[sum(a * b for a, b in zip(row, col)) for col in zip(*B)]
            for row in A]

print(matmul([[1, 2], [3, 4]], [[0, 1], [1, 0]]))  # [[2, 1], [4, 3]]
```

Multiplying by $\begin{bmatrix}0&1\\1&0\end{bmatrix}$ on the right swapped the columns of $A$.

### Rules of matrix algebra

Matrix multiplication is **associative**, $(AB)C = A(BC)$, and **distributive**, $A(B + C) = AB + AC$. It is **not commutative**: $AB \ne BA$ in general (and one of them may not even be defined). The cancellation law also fails: $AB = 0$ does not force $A = 0$ or $B = 0$.

The **identity matrix** $I$ has ones on the diagonal and zeros elsewhere, with $AI = IA = A$. The **transpose** $A^T$ swaps rows and columns, $(A^T)_{ij} = A_{ji}$, and $(AB)^T = B^T A^T$ (the order reverses).

### Inverses

A square matrix $A$ is **invertible** if some matrix $A^{-1}$ satisfies $AA^{-1} = A^{-1}A = I$. For square matrices a one-sided inverse is automatically two-sided. If $A$ is invertible, $Ax = b$ has the unique solution $x = A^{-1}b$. If $Ax = 0$ for some nonzero $x$, then $A$ is **singular** (not invertible), since an inverse would give $x = A^{-1}0 = 0$.

When $A$ and $B$ are both invertible, so is $AB$, and

$$(AB)^{-1} = B^{-1}A^{-1}$$

(the order reverses, as with transposes: undo the last step first). For $2\times2$ matrices with $ad - bc \neq 0$,

$$\begin{bmatrix} a & b \\ c & d \end{bmatrix}^{-1} = \frac{1}{ad - bc}\begin{bmatrix} d & -b \\ -c & a \end{bmatrix}.$$

### Gauss-Jordan elimination

To find $A^{-1}$ in general, row reduce the $n \times 2n$ matrix $[A \mid I]$ until the left half is $I$. The right half is then $A^{-1}$. Each row operation is multiplication on the left by an elementary matrix $E$; the product of all of them is the matrix $A^{-1}$ that takes $A$ to $I$. If you cannot get $n$ pivots, $A$ is singular. In practice one rarely forms $A^{-1}$: solving $Ax = b$ directly by elimination is cheaper and numerically better.

@example
title: Multiplying a 2 by 3 matrix by a 3 by 2 matrix
problem: Compute $AB$ for $A = \begin{bmatrix}1 & 2 & 0\\ 3 & -1 & 4\end{bmatrix}$ and $B = \begin{bmatrix}2 & 1\\ 0 & 3\\ 1 & -2\end{bmatrix}$.
step: $A$ is $2\times3$ and $B$ is $3\times2$, so the inner sizes match and $AB$ is $2\times2$.
step: Entry $(1,1)$: row 1 of $A$ times column 1 of $B$ is $1\cdot2 + 2\cdot0 + 0\cdot1 = 2$. Entry $(1,2)$: $1\cdot1 + 2\cdot3 + 0\cdot(-2) = 7$.
step: Entry $(2,1)$: $3\cdot2 + (-1)\cdot0 + 4\cdot1 = 10$. Entry $(2,2)$: $3\cdot1 + (-1)\cdot3 + 4\cdot(-2) = -8$.
answer: $AB = \begin{bmatrix}2 & 7\\ 10 & -8\end{bmatrix}$

@example
title: Inverse by Gauss-Jordan elimination
problem: Find the inverse of $A = \begin{bmatrix}2 & 1\\ 4 & 3\end{bmatrix}$.
step: Form $[A \mid I]$: rows $[2, 1 \mid 1, 0]$ and $[4, 3 \mid 0, 1]$.
step: Subtract $2\times$ row 1 from row 2: $[0, 1 \mid -2, 1]$. Both pivots ($2$ and $1$) exist, so $A$ is invertible.
step: Eliminate upward: subtract row 2 from row 1: $[2, 0 \mid 3, -1]$.
step: Scale row 1 by $\tfrac12$: $[1, 0 \mid \tfrac32, -\tfrac12]$. The left half is now $I$.
step: Check with the $2\times2$ formula: $ad - bc = 6 - 4 = 2$, giving $\tfrac12\begin{bmatrix}3&-1\\-4&2\end{bmatrix}$, the same matrix.
answer: $A^{-1} = \begin{bmatrix}3/2 & -1/2\\ -2 & 1\end{bmatrix}$

@mistakes
- Assuming $AB = BA$. Even for square matrices this is usually false.
- Writing $(AB)^{-1} = A^{-1}B^{-1}$ or $(AB)^T = A^TB^T$; both orders must reverse.
- Multiplying matrices whose inner dimensions do not match, such as $(2\times3)(2\times3)$.
- Trying to invert a matrix with a zero row or with a column that is a combination of the others; such a matrix is singular.

model:
```python
def matmul(A, B):
    if len(A[0]) != len(B):
        raise ValueError("inner dimensions do not match")
    cols = list(zip(*B))
    return [[sum(a * b for a, b in zip(row, col)) for col in cols]
            for row in A]
```
hint: Entry `(i, j)` is the dot product of row `i` of `A` with column `j` of `B`.
hint: `zip(*B)` gives the columns of `B`. Check `len(A[0]) == len(B)` first.
solution: Transpose `B` with `zip(*B)` to get its columns, then for each row of `A` and each column of `B` take the sum of products. The two last asserts show that multiplying by a swap matrix on the right swaps columns but on the left swaps rows, so order matters.

@practice mc
prompt: $A$ and $B$ are invertible $n \times n$ matrices. Which statement is true?
choice*: $(AB)^T = B^T A^T$
choice: $AB = BA$ always.
choice: $(AB)^{-1} = A^{-1}B^{-1}$ always.
choice: If $AB = 0$ then $A = 0$ or $B = 0$, even if they are not invertible.

solution: The transpose of a product reverses the order. Matrix multiplication is not commutative, and the inverse of a product also reverses the order: $(AB)^{-1} = B^{-1}A^{-1}$. The claim that $AB = 0$ forces $A = 0$ or $B = 0$ is false for singular matrices; for example $\begin{bmatrix}1&0\\0&0\end{bmatrix}\begin{bmatrix}0&0\\0&1\end{bmatrix} = 0$.

model:
```python
def _mul(A, B):
    cols = list(zip(*B))
    return [[sum(a * b for a, b in zip(r, c)) for c in cols] for r in A]

def mat_pow(A, k):
    n = len(A)
    result = [[1 if i == j else 0 for j in range(n)] for i in range(n)]
    base = [row[:] for row in A]
    while k > 0:
        if k % 2 == 1:
            result = _mul(result, base)
        base = _mul(base, base)
        k //= 2
    return result
```
hint: Start from the identity matrix and multiply by `A` repeatedly.
hint: To be fast, use repeated squaring: if `k` is odd multiply the result by the current base, then square the base and halve `k`.
solution: Repeated squaring computes $A^k$ with $O(\log k)$ matrix products. Powers of $\begin{bmatrix}1&1\\1&0\end{bmatrix}$ contain consecutive Fibonacci numbers: the $(0,1)$ entry of the 60th power is $F_{60} = 1548008755920$.

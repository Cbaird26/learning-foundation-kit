@article
A **transformation** $T : \mathbb{R}^n \to \mathbb{R}^m$ is **linear** if for all vectors $u, v$ and scalars $c$,

$$T(u + v) = T(u) + T(v), \qquad T(cv) = c\,T(v).$$

Together these say $T$ preserves linear combinations. In particular $T(0) = 0$, which immediately shows that a translation $T(x) = x + t$ with $t \neq 0$ is not linear.

### Every linear map is a matrix

Every matrix $A$ gives a linear map $x \mapsto Ax$. The converse is also true: if $T$ is linear, write $x = x_1e_1 + \dots + x_ne_n$ in the standard basis, then $T(x) = x_1T(e_1) + \dots + x_nT(e_n) = Ax$, where **column $j$ of $A$ is $T(e_j)$**. So to find the matrix of a linear map, ask where it sends the standard basis vectors.

### Matrices of common 2D maps

- **Rotation** counterclockwise by $\theta$ about the origin sends $e_1 = (1,0)$ to $(\cos\theta, \sin\theta)$ and $e_2 = (0,1)$ to $(-\sin\theta, \cos\theta)$, so
$$R_\theta = \begin{bmatrix}\cos\theta & -\sin\theta\\ \sin\theta & \cos\theta\end{bmatrix}.$$
- **Scaling** by $s_x$ and $s_y$: $\begin{bmatrix}s_x&0\\0&s_y\end{bmatrix}$.
- **Reflection** across the $x$-axis: $\begin{bmatrix}1&0\\0&-1\end{bmatrix}$; across the line $y = x$: $\begin{bmatrix}0&1\\1&0\end{bmatrix}$.
- **Shear** along $x$ by $k$: $\begin{bmatrix}1&k\\0&1\end{bmatrix}$, sending $(x, y)$ to $(x + ky, y)$.

### Composition is multiplication

If $T$ has matrix $A$ and $S$ has matrix $B$, then "first $T$, then $S$" has matrix $BA$, because $S(T(x)) = B(Ax) = (BA)x$. The transformation applied **first** is the **rightmost** factor. Since matrix products depend on order, rotating then scaling generally differs from scaling then rotating.

### Kernel and range

The **kernel** of $T(x) = Ax$ is $N(A)$ and its **range** is $C(A)$. $T$ is one-to-one exactly when $N(A) = \{0\}$, and onto $\mathbb{R}^m$ exactly when $C(A) = \mathbb{R}^m$. A square matrix gives an invertible transformation exactly when $A$ is invertible, and the inverse transformation has matrix $A^{-1}$ (for a rotation, $R_\theta^{-1} = R_{-\theta} = R_\theta^T$).

### Homogeneous coordinates

Computer graphics wants translations as matrix products too. The trick is to represent the point $(x, y)$ as the three-component vector $(x, y, 1)$. Then

$$\begin{bmatrix}1&0&t_x\\0&1&t_y\\0&0&1\end{bmatrix}\begin{bmatrix}x\\y\\1\end{bmatrix} = \begin{bmatrix}x + t_x\\y + t_y\\1\end{bmatrix},$$

and a $2\times2$ matrix $A$ becomes $\begin{bmatrix}A&0\\0&1\end{bmatrix}$. Now translations, rotations, scalings and shears all compose by multiplying $3\times3$ matrices. (Projective maps use a last row other than $(0,0,1)$, and then the result is divided by the third component.) To rotate about a point $p$, translate $p$ to the origin, rotate, and translate back: $M = T_p\,R_\theta\,T_{-p}$, with $T_{-p}$ applied first.

```python
import math

def rotation(deg):
    t = math.radians(deg)
    return [[math.cos(t), -math.sin(t)], [math.sin(t), math.cos(t)]]
```

@example
title: Composing a rotation and a scaling
problem: Find the matrix of the map that first rotates by $90^\circ$ counterclockwise and then doubles the $x$-coordinate, and apply it to $(1, 1)$.
step: Rotation by $90^\circ$: $R = \begin{bmatrix}0&-1\\1&0\end{bmatrix}$. Doubling $x$: $S = \begin{bmatrix}2&0\\0&1\end{bmatrix}$.
step: The rotation is applied first, so it is the right factor: $M = SR = \begin{bmatrix}2&0\\0&1\end{bmatrix}\begin{bmatrix}0&-1\\1&0\end{bmatrix} = \begin{bmatrix}0&-2\\1&0\end{bmatrix}$.
step: Apply to $(1, 1)$: $M(1,1) = (0\cdot1 - 2\cdot1,\ 1\cdot1 + 0) = (-2, 1)$.
step: Check step by step: $R(1,1) = (-1, 1)$, then doubling $x$ gives $(-2, 1)$.
answer: $M = \begin{bmatrix}0&-2\\1&0\end{bmatrix}$ and $M(1,1) = (-2, 1)$.

@example
title: Rotating about a point with homogeneous coordinates
problem: Find the $3\times3$ matrix that rotates the plane by $90^\circ$ counterclockwise about the point $p = (1, 0)$, and check it on $(2, 0)$.
step: Translate $p$ to the origin: $T_{-p} = \begin{bmatrix}1&0&-1\\0&1&0\\0&0&1\end{bmatrix}$. Rotate: $R = \begin{bmatrix}0&-1&0\\1&0&0\\0&0&1\end{bmatrix}$. Translate back: $T_p = \begin{bmatrix}1&0&1\\0&1&0\\0&0&1\end{bmatrix}$.
step: Multiply, rightmost first: $RT_{-p} = \begin{bmatrix}0&-1&0\\1&0&-1\\0&0&1\end{bmatrix}$. Then $T_p(RT_{-p})$ adds $1$ times the third row to the first row, giving $M = \begin{bmatrix}0&-1&1\\1&0&-1\\0&0&1\end{bmatrix}$.
step: Apply to $(2, 0, 1)$: $M(2,0,1) = (0 - 0 + 1,\ 2 + 0 - 1,\ 1) = (1, 1, 1)$, the point $(1, 1)$.
step: Sanity check: $(2,0)$ is one unit to the right of $p$, and rotating $90^\circ$ counterclockwise about $p$ puts it one unit above $p$, at $(1, 1)$. Also $M(1,0,1) = (1,0,1)$: the center $p$ stays fixed.
answer: $M = \begin{bmatrix}0&-1&1\\1&0&-1\\0&0&1\end{bmatrix}$

@mistakes
- Multiplying the matrices in the order the transformations are applied. The first transformation is the rightmost factor.
- Treating translation as linear. A map that moves the origin cannot be $x \mapsto Ax$; use homogeneous coordinates.
- Writing the columns of a rotation matrix as rows (this rotates the other way) or forgetting the minus sign in the $-\sin\theta$ entry.
- Using degrees in `math.sin` and `math.cos`, which expect radians.

model:
```python
import math

def rotation_about(px, py, deg):
    t = math.radians(deg)
    c, s = math.cos(t), math.sin(t)
    return [[c, -s, px - c * px + s * py],
            [s, c, py - s * px - c * py],
            [0.0, 0.0, 1.0]]
```
hint: The fixed point of the rotation must be `(px, py)`. The rotation part is the usual $\begin{bmatrix}c&-s\\s&c\end{bmatrix}$.
hint: Multiplying out $T_pRT_{-p}$ gives translation column $p - Rp$.
solution: $M = T_pRT_{-p}$ has the rotation block $R$ and last column $p - Rp$, that is $(p_x - c\,p_x + s\,p_y,\ p_y - s\,p_x - c\,p_y)$. The test with $(2,3)$ checks that the center is a fixed point.

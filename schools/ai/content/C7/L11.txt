@article
Two subspaces $V$ and $W$ are **orthogonal** if every vector in $V$ is orthogonal to every vector in $W$. The **orthogonal complement** $V^\perp$ is the set of all vectors orthogonal to every vector in $V$. The four fundamental subspaces pair up this way: in $\mathbb{R}^n$, $N(A) = C(A^T)^\perp$, and in $\mathbb{R}^m$, $N(A^T) = C(A)^\perp$. The proof is one line: $Ax = 0$ says that every row of $A$ is orthogonal to $x$.

### Projection onto a line

Given a nonzero vector $a$ and any vector $b$, the **projection** of $b$ onto the line through $a$ is the point $p = \hat{x}\,a$ on that line closest to $b$. The error $e = b - p$ must be orthogonal to $a$: $a \cdot (b - \hat{x}a) = 0$, so

$$\hat{x} = \frac{a \cdot b}{a \cdot a}, \qquad p = \frac{a \cdot b}{a \cdot a}\,a, \qquad P = \frac{aa^T}{a^Ta}.$$

The matrix $P$ satisfies $P^2 = P$ (projecting twice changes nothing) and $P^T = P$.

### Least squares

If $Ax = b$ has no solution (typically $m > n$: more equations than unknowns), $b$ is not in $C(A)$. The **least squares solution** $\hat{x}$ minimizes the length of the error $\|b - Ax\|$. The closest point of $C(A)$ to $b$ is the projection $p = A\hat{x}$, and the error $e = b - A\hat{x}$ is orthogonal to $C(A)$, that is $A^T(b - A\hat{x}) = 0$. This gives the **normal equations**

$$A^TA\,\hat{x} = A^Tb.$$

If the columns of $A$ are independent, $A^TA$ is invertible, so $\hat{x} = (A^TA)^{-1}A^Tb$ and the projection onto $C(A)$ is $P = A(A^TA)^{-1}A^T$.

### Fitting a line

To fit $y = C + Dx$ to points $(x_i, y_i)$, take the matrix $A$ with rows $(1, x_i)$ and the vector $b = (y_i)$. The normal equations become

$$\begin{bmatrix}n & \sum x_i\\ \sum x_i & \sum x_i^2\end{bmatrix}\begin{bmatrix}C\\D\end{bmatrix} = \begin{bmatrix}\sum y_i\\ \sum x_iy_i\end{bmatrix},$$

which gives the closed forms $D = \dfrac{n\sum x_iy_i - \sum x_i\sum y_i}{n\sum x_i^2 - (\sum x_i)^2}$ and $C = \dfrac{\sum y_i - D\sum x_i}{n}$. The residuals of the best-fit line add up to zero when a constant column is included, because $e \perp (1, \dots, 1)$. The same recipe fits polynomials and other models that are linear in their unknown coefficients. In numerical practice $A^TA$ squares the condition number, so libraries use QR or SVD methods instead of forming the normal equations.

### Orthonormal vectors and Gram-Schmidt

Vectors $q_1, \dots, q_k$ are **orthonormal** if $q_i \cdot q_j$ is $1$ when $i = j$ and $0$ otherwise. A matrix $Q$ with orthonormal columns satisfies $Q^TQ = I$, and then projection onto $C(Q)$ is simply $P = QQ^T$. A square $Q$ with orthonormal columns is an **orthogonal matrix**: $Q^{-1} = Q^T$, and it preserves lengths and angles.

**Gram-Schmidt** turns independent vectors $a_1, \dots, a_k$ into orthogonal vectors $q_1, \dots, q_k$ spanning the same spaces: subtract from each new vector its projections onto the earlier ones,

$$q_j = a_j - \sum_{i<j}\frac{q_i \cdot a_j}{q_i \cdot q_i}\,q_i.$$

Dividing each $q_j$ by its length gives an orthonormal set. This is the factorization $A = QR$.

@example
title: Projecting onto a line
problem: Project $b = (1, 2, 3)$ onto the line through $a = (1, 1, 1)$, and verify that the error is orthogonal to $a$.
step: $a \cdot b = 1 + 2 + 3 = 6$ and $a \cdot a = 3$, so $\hat{x} = 6/3 = 2$.
step: The projection is $p = 2a = (2, 2, 2)$.
step: The error is $e = b - p = (-1, 0, 1)$.
step: Check: $a \cdot e = -1 + 0 + 1 = 0$, so $e \perp a$. The projection is the mean of $b$'s entries repeated, which is the best constant approximation.
answer: $p = (2, 2, 2)$ with error $e = (-1, 0, 1)$.

@example
title: Fitting a line through three points
problem: Find the least squares line $y = C + Dx$ through $(1, 1)$, $(2, 2)$, $(3, 2)$.
step: Set up $A = \begin{bmatrix}1&1\\1&2\\1&3\end{bmatrix}$ and $b = (1, 2, 2)$. The system $Ax = b$ has no solution because the points are not collinear.
step: Compute $A^TA = \begin{bmatrix}3&6\\6&14\end{bmatrix}$ and $A^Tb = (1 + 2 + 2,\ 1 + 4 + 6) = (5, 11)$.
step: Solve $3C + 6D = 5$ and $6C + 14D = 11$. Subtract $2\times$ the first equation from the second: $2D = 1$, so $D = \tfrac12$. Then $3C = 5 - 3 = 2$, so $C = \tfrac23$.
step: The line is $y = \tfrac23 + \tfrac12x$. The residuals are $1 - \tfrac76 = -\tfrac16$, $2 - \tfrac53 = \tfrac13$ and $2 - \tfrac{13}{6} = -\tfrac16$. They sum to $0$ and are orthogonal to the column $(1,2,3)$: $-\tfrac16 + \tfrac23 - \tfrac12 = 0$.
answer: $y = \tfrac23 + \tfrac12 x$

@mistakes
- Forgetting the denominator when projecting, for example computing $p = (a \cdot b)\,a$ instead of $p = \dfrac{a \cdot b}{a \cdot a}\,a$.
- Solving $Ax = b$ by "least squares" with $A^Tx = A^Tb$; the normal equations are $A^TA\hat{x} = A^Tb$.
- Fitting a line without a constant column (forcing it through the origin) when an intercept is wanted.
- Believing the least squares line minimizes perpendicular distances; it minimizes the sum of squared vertical errors.

model:
```python
from fractions import Fraction

def fit_line(xs, ys):
    n = len(xs)
    sx = sum(xs)
    sy = sum(ys)
    sxy = sum(x * y for x, y in zip(xs, ys))
    sxx = sum(x * x for x in xs)
    slope = Fraction(n * sxy - sx * sy, n * sxx - sx * sx)
    intercept = (sy - slope * sx) / n
    return (slope, Fraction(intercept))
```
hint: The normal equations only need $n$, $\sum x$, $\sum y$, $\sum xy$ and $\sum x^2$.
hint: $D = (n\sum xy - \sum x \sum y)/(n\sum x^2 - (\sum x)^2)$, and then $C = (\sum y - D\sum x)/n$.
solution: Compute the five sums, get the slope as an exact `Fraction`, then the intercept from the second normal equation. For `[1, 2, 3]` and `[1, 2, 2]` this gives slope $1/2$ and intercept $2/3$.

@practice self
prompt: Explain why the error vector $e = b - A\hat{x}$ of a least squares fit is orthogonal to every column of $A$, and how this leads to the normal equations.
hint: If the error had a component inside $C(A)$, could you move $A\hat{x}$ to get closer to $b$?
solution: $A\hat{x}$ is the point of the column space $C(A)$ closest to $b$. If $e$ had a component along some vector in $C(A)$, subtracting that component from $e$ (moving $A\hat{x}$ in that direction) would give a closer point, contradicting minimality. So $e$ is orthogonal to $C(A)$, that is to every column of $A$. In matrix form this is $A^Te = 0$, i.e. $A^T(b - A\hat{x}) = 0$, which rearranges to $A^TA\hat{x} = A^Tb$.

model:
```python
from fractions import Fraction

def gram_schmidt(vectors):
    result = []
    for v in vectors:
        w = [Fraction(x) for x in v]
        for q in result:
            c = sum(a * b for a, b in zip(q, v)) / sum(a * a for a in q)
            w = [wi - c * qi for wi, qi in zip(w, q)]
        result.append(w)
    return result
```
hint: For each new vector, subtract its projection onto every earlier orthogonal vector.
hint: The coefficient for an earlier vector `q` is `(q . v) / (q . q)`; use `Fraction` division.
solution: Keep a list of orthogonal vectors. For each input `v`, start from a `Fraction` copy `w`, subtract `c * q` for every earlier `q` with `c = (q . v)/(q . q)`, and append `w`. Using the original `v` or the current `w` in the coefficient gives the same result because the earlier `q`'s are mutually orthogonal.

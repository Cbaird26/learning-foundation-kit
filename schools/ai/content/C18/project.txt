### Week by week
- **Weeks 1 and 2, convolution.** Cross-correlation of a kernel with a grid; output size $\lfloor (n + 2p - k)/s \rfloor + 1$; parameters $c_{out}(c_{in}k^2 + 1)$; pooling; stacked layers and the receptive field $r \leftarrow r + (k-1)j$, $j \leftarrow js$; residual blocks $\mathbf{y} = \operatorname{ReLU}(\mathbf{x} + F(\mathbf{x}))$.
- **Weeks 3 and 4, recurrence.** $\mathbf{h}_t = \tanh(\mathbf{W}_{xh}\mathbf{x}_t + \mathbf{W}_{hh}\mathbf{h}_{t-1} + \mathbf{b})$; backpropagation through time sums contributions over steps; gradients scale like products of $u(1 - h^2)$; clipping by norm; LSTM $c_t = f_t c_{t-1} + i_t g_t$, $h_t = o_t \tanh c_t$; GRU $h_t = (1-z)h_{t-1} + z\tilde h$; parameters $4n_h(n_{in} + n_h + 1)$ for an LSTM.
- **Weeks 5 and 6, seq2seq and attention.** Encoder, context vector, teacher forcing, negative log-likelihood and perplexity, greedy and beam search; attention weights $\operatorname{softmax}(s_i)$, output $\sum\alpha_i\mathbf{v}_i$, scores $\mathbf{q}^\top\mathbf{k}/\sqrt{d}$ or additive; masking with $-\infty$.
- **Weeks 7 and 8, the transformer.** $\operatorname{softmax}(\mathbf{Q}\mathbf{K}^\top/\sqrt{d_k})\mathbf{V}$, heads of size $d/h$, feed-forward $d \to 4d \to d$, residual plus layer norm over the features of one token; embeddings, cosine similarity, sinusoidal positions $\sin(\text{pos}\,\omega_i)$, $\cos(\text{pos}\,\omega_i)$ with $\omega_i = 10000^{-2i/d}$.
- **Weeks 9 and 10, graphs and self-supervision.** Message passing with a permutation-invariant aggregator; GCN weights $1/\sqrt{\hat d_v \hat d_u}$; after $k$ rounds the receptive field is the $k$-hop neighborhood; next-token and masked-token objectives; InfoNCE $= -\log\frac{e^{s^+/\tau}}{e^{s^+/\tau} + \sum e^{s^-_k/\tau}}$.
- **Weeks 11 and 12, adaptation and choice.** Linear probe versus fine-tuning, discriminative learning rates, LoRA $\mathbf{W}_0 + \frac{\alpha}{r}\mathbf{B}\mathbf{A}$ with $r(d_{in}+d_{out})$ parameters; costs $nkd^2$, $2nd^2$, $4nd^2 + 2n^2d$; matching inductive bias to data structure, baselines first.

### Common errors
- Flipping the kernel, or forgetting the factor $2p$ for padding.
- Forgetting that shared weights have gradients summed over time steps.
- Softmax over the wrong axis; mixing up keys and values; omitting the $\sqrt{d}$ scale.
- Normalizing over the batch rather than the features of a token in layer normalization.
- Treating self-attention as order-aware, or an aggregator as order-dependent.
- Tuning on the test set, or comparing hypotheses of different lengths without normalization.

@exam code
prompt: Write `position_attention(tokens, table)` for single-head self-attention with positions. `tokens` is a list of token ids and `table` maps each id to a 2D embedding (a list of two numbers). The input at position `i` is `table[tokens[i]]` plus the 2D sinusoidal encoding `[sin(i), cos(i)]`. Using these inputs as queries and keys, return the attention weights as a list of rows: row `i` holds the scaled dot-product softmax weights (scores divided by `sqrt(2)`) of position `i` over all positions.
starter:
```python
def position_attention(tokens, table):
    n = len(tokens)
    return [[1.0 / n] * n for _ in range(n)]
```

model:
```python
from math import cos, exp, sin, sqrt


def position_attention(tokens, table):
    """Self-attention weights for embeddings plus [sin(i), cos(i)]."""
    x = [[table[t][0] + sin(i), table[t][1] + cos(i)]
         for i, t in enumerate(tokens)]
    rows = []
    for q in x:
        scores = [(q[0] * k[0] + q[1] * k[1]) / sqrt(2) for k in x]
        m = max(scores)
        e = [exp(s - m) for s in scores]
        rows.append([v / sum(e) for v in e])
    return rows
```
hint: Build the position-aware inputs first; then each row is a softmax over the dot products of that input with all inputs, divided by $\sqrt 2$.
solution: Without the positional terms, identical tokens would give identical rows. The last test feeds the same token three times: the weights differ between positions only because of the added sinusoidal encoding, which is why a model needs positions to handle order.

@exam self
prompt: In the string-reversal project, an encoder-only transformer must output at position $i$ the input letter from position $4 - i$ of a five-letter string. (a) Explain why a model with self-attention but no positional encodings cannot solve the task in general. (b) Describe the attention pattern you expect from a trained model that solves it, as a table of which position each row attends to. (c) Compare with an LSTM encoder-decoder of the same task in terms of how the information from the first input letter reaches the last output.
hint: For (a), recall that permuting the input rows permutes the output rows. For (b), think of a table with 5 rows and 5 columns. For (c), count the steps the information must travel.
solution: (a) Self-attention without positions is permutation equivariant: swapping two input tokens swaps the two output rows and changes nothing else, so the output at a position depends on the multiset of letters and on the letter at that position, not on where letters are. Two strings with the same letters in different order, for example `abcda` and `acbda`, would produce output rows that are the same up to the same permutation. The needed output at position 0 is the last letter of the input, which the model cannot locate without knowing positions; so it cannot solve the task in general (it may succeed only on special inputs, such as palindromes). (b) A successful model should show an anti-diagonal: row 0 attends mostly to column 4, row 1 to column 3, row 2 to column 2 (itself), row 3 to column 1 and row 4 to column 0, with the positional encodings providing the information to match position $i$ with position $4 - i$. Real models may spread the weights over several heads or layers, so the pattern may be clearest in one head. (c) In an LSTM encoder-decoder the first letter must be carried through the encoder's state updates and the context vector, then read out by the decoder at the last step; its path is several state updates long and the bottleneck must hold all five letters. In the transformer the path from any input position to any output position has length 1 through attention, with no bottleneck. For five letters the LSTM can still work, but the comparison grows more favorable to attention as the length grows.

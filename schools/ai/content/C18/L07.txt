@article
Recurrent networks read one token at a time, so step $t$ cannot start until step $t - 1$ finishes, and distant tokens interact only through a long chain of states. Vaswani and colleagues (2017) asked: what if every token could look at every other token directly, in one step, with attention alone? The result is the **transformer**.

### Self-attention
In **self-attention** the queries, keys and values all come from the same sequence. Stack $n$ token vectors of size $d$ (the model dimension) as the rows of $\mathbf{X}$. Learned projections give $\mathbf{Q} = \mathbf{X}\mathbf{W}_Q$, $\mathbf{K} = \mathbf{X}\mathbf{W}_K$ and $\mathbf{V} = \mathbf{X}\mathbf{W}_V$, and the output is $\operatorname{softmax}(\mathbf{Q}\mathbf{K}^\top/\sqrt{d_k})\mathbf{V}$, as in the last lesson. Row $i$ of the weight matrix says how much token $i$ reads from each token $j$. The score matrix is $n \times n$, so time and memory grow as $n^2$ with sequence length, in exchange for a path of length 1 between any two tokens.

### Multiple heads
One attention pattern is a limited way to relate tokens. **Multi-head attention** runs $h$ attentions in parallel on lower-dimensional projections, with head size $d_k = d/h$, concatenates their outputs and mixes them with a final matrix $\mathbf{W}_O$:

$$\operatorname{head}_m = \operatorname{Attention}(\mathbf{X}\mathbf{W}_Q^{(m)}, \mathbf{X}\mathbf{W}_K^{(m)}, \mathbf{X}\mathbf{W}_V^{(m)}), \quad \operatorname{MHA}(\mathbf{X}) = [\operatorname{head}_1; \dots; \operatorname{head}_h]\,\mathbf{W}_O.$$

Different heads can specialize in different relations. With $\mathbf{W}_Q, \mathbf{W}_K, \mathbf{W}_V, \mathbf{W}_O$ each of size $d \times d$ and no biases, the layer has $4d^2$ parameters, whatever $h$ is.

### The rest of the block
Attention mixes information *across* positions. The **position-wise feed-forward network** transforms each position independently, with the same weights at every position:

$$\operatorname{FFN}(\mathbf{x}) = \mathbf{W}_2 \operatorname{ReLU}(\mathbf{W}_1 \mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2,$$

where $\mathbf{W}_1$ expands from $d$ to $d_{ff}$ (often $4d$) and $\mathbf{W}_2$ contracts back. Each sublayer is wrapped in a **residual connection** (the shortcut of lesson 2) and **layer normalization** (Ba, Kiros and Hinton, 2016). Layer normalization standardizes the features of *one* token:

$$\operatorname{LN}(\mathbf{x}) = \boldsymbol{\gamma} \odot \frac{\mathbf{x} - \mu}{\sqrt{\sigma^2 + \epsilon}} + \boldsymbol{\beta}, \quad \mu = \tfrac{1}{d}\sum_i x_i, \quad \sigma^2 = \tfrac{1}{d}\sum_i (x_i - \mu)^2.$$

Unlike batch normalization it does not use other examples in the batch, so it behaves the same for any batch size and sequence length. The original transformer uses the "post-norm" order:

$$\mathbf{Y} = \operatorname{LN}(\mathbf{X} + \operatorname{MHA}(\mathbf{X})), \qquad \mathbf{Z} = \operatorname{LN}(\mathbf{Y} + \operatorname{FFN}(\mathbf{Y})).$$

Many later models apply the normalization *before* each sublayer ("pre-norm"), which tends to train more stably in deep stacks. The output $\mathbf{Z}$ has the same shape as $\mathbf{X}$, so blocks stack. For example, with $d = 8$ and $d_{ff} = 32$, the FFN has $8\cdot 32 + 32 + 32 \cdot 8 + 8 = 552$ parameters, more than the $4 \cdot 64 = 256$ in attention.

For the vector $(1, 2, 3, 6)$, $\mu = 3$ and $\sigma^2 = 3.5$, so layer normalization (with $\boldsymbol\gamma = 1$, $\boldsymbol\beta = 0$, $\epsilon \approx 0$) gives $(-1.069, -0.535, 0, 1.604)$.

### In code
```python
from math import sqrt

def layer_norm(x, eps=1e-5):
    """Standardize one vector (gamma = 1, beta = 0)."""
    mu = sum(x) / len(x)
    var = sum((a - mu) ** 2 for a in x) / len(x)
    return [(a - mu) / sqrt(var + eps) for a in x]

print([round(a, 3) for a in layer_norm([1, 2, 3, 6], eps=0.0)])
```

Note that self-attention alone ignores token order: shuffling the rows of $\mathbf{X}$ just shuffles the rows of the output. Lesson 8 adds positional information. In PyTorch, `nn.MultiheadAttention` and `nn.TransformerEncoderLayer` package these pieces.

@example
title: Two heads by hand
problem: Two tokens $\mathbf{x}_1 = (1, 0)$ and $\mathbf{x}_2 = (0, 2)$ pass through multi-head self-attention with $h = 2$ heads, identity projections and $\mathbf{W}_O = \mathbf{I}$. Head 1 uses the first coordinate and head 2 the second, so each head has size 1 and $\sqrt{d_k} = 1$. Compute the output.
step: Head 1 uses the first coordinates $(1, 0)$ for queries, keys and values. The scores are $q_i k_j$: row 1 is $(1, 0)$ and row 2 is $(0, 0)$. Row 1 weights are $(0.7311, 0.2689)$ and row 2 weights are $(0.5, 0.5)$.
step: Head 1 outputs: token 1 gets $0.7311 \cdot 1 + 0.2689 \cdot 0 = 0.7311$; token 2 gets $0.5 \cdot 1 + 0.5 \cdot 0 = 0.5$.
step: Head 2 uses the second coordinates $(0, 2)$. The scores are row 1: $(0, 0)$ and row 2: $(0, 4)$. Row 1 weights are $(0.5, 0.5)$ and row 2 weights are $(0.0180, 0.9820)$.
step: Head 2 outputs: token 1 gets $0.5 \cdot 0 + 0.5 \cdot 2 = 1$; token 2 gets $0.0180 \cdot 0 + 0.9820 \cdot 2 = 1.964$.
step: Concatenate the heads and multiply by $\mathbf{I}$: token 1 is $(0.7311, 1)$ and token 2 is $(0.5, 1.964)$.
answer: The output rows are $(0.7311, 1.0)$ and $(0.5, 1.964)$.

@example
title: Feed-forward block and residual
problem: One token is $\mathbf{x} = (2, 1)$. The FFN has $\mathbf{W}_1$ with rows $(1, 0)$, $(0, 1)$, $(1, 1)$, $\mathbf{b}_1 = (-1, 0, -4)$, $\mathbf{W}_2$ with rows $(1, 0, 1)$ and $(0, 2, 0)$, and $\mathbf{b}_2 = (0.5, 0)$. Compute $\mathbf{x} + \operatorname{FFN}(\mathbf{x})$.
step: Hidden pre-activation: $(2 - 1,\ 1 + 0,\ 3 - 4) = (1, 1, -1)$.
step: ReLU gives $(1, 1, 0)$.
step: Output layer: first component $1 + 0 + 0 + 0.5 = 1.5$, second component $2 \cdot 1 = 2$. So $\operatorname{FFN}(\mathbf{x}) = (1.5, 2)$.
step: Add the residual: $(2, 1) + (1.5, 2) = (3.5, 3)$. A layer normalization would follow (in post-norm).
answer: $\mathbf{x} + \operatorname{FFN}(\mathbf{x}) = (3.5, 3)$.

@mistakes
- Normalizing over the batch instead of over the features of each token; layer normalization uses the $d$ features of one token only.
- Thinking more heads means more parameters. With head size $d/h$ the parameter count stays $4d^2$ for the attention weights.
- Forgetting that the FFN is applied to each position separately, with shared weights; it never mixes positions, only attention does.
- Treating self-attention as order-aware. Without positional information, permuting the input tokens permutes the output in the same way.

model:
```python
from math import exp, sqrt


def multi_head_self_attention(X, h):
    """Multi-head self-attention with identity projections."""
    d = len(X[0])
    dh = d // h
    out = [[] for _ in X]
    for m in range(h):
        part = [x[m * dh:(m + 1) * dh] for x in X]
        for i, q in enumerate(part):
            scores = [sum(a * b for a, b in zip(q, k)) / sqrt(dh) for k in part]
            top = max(scores)
            e = [exp(s - top) for s in scores]
            w = [v / sum(e) for v in e]
            out[i] += [sum(w[j] * part[j][c] for j in range(len(X)))
                       for c in range(dh)]
    return out
```
hint: For each head, slice out its coordinates of every token, run ordinary scaled dot-product attention among those slices, and append the result to each token's output.
solution: Each head attends within its own slice of the coordinates, with scale $\sqrt{d/h}$ rather than $\sqrt d$. The test with a single head ($h = 1$) differs from the two-head output because the heads see different coordinates and use a different scale.

model:
```python
from math import exp, sqrt


def transformer_block(X, h, W1, b1, W2, b2):
    """Post-norm transformer block with identity attention projections."""
    d = len(X[0])
    dh = d // h

    def ln(v):
        mu = sum(v) / len(v)
        var = sum((a - mu) ** 2 for a in v) / len(v)
        return [(a - mu) / sqrt(var + 1e-5) for a in v]

    attn = [[] for _ in X]
    for m in range(h):
        part = [x[m * dh:(m + 1) * dh] for x in X]
        for i, q in enumerate(part):
            s = [sum(a * b for a, b in zip(q, k)) / sqrt(dh) for k in part]
            top = max(s)
            e = [exp(t - top) for t in s]
            w = [t / sum(e) for t in e]
            attn[i] += [sum(w[j] * part[j][c] for j in range(len(X)))
                        for c in range(dh)]
    Y = [ln([a + b for a, b in zip(x, y)]) for x, y in zip(X, attn)]
    out = []
    for y in Y:
        hid = [max(0.0, sum(w * a for w, a in zip(row, y)) + b)
               for row, b in zip(W1, b1)]
        f = [sum(w * a for w, a in zip(row, hid)) + b for row, b in zip(W2, b2)]
        out.append(ln([a + b for a, b in zip(y, f)]))
    return out
```
hint: Build the attention output first, then do residual plus layer norm, then the feed-forward network per token, and a second residual plus layer norm.
solution: The block is two sublayers, each as `LN(input + sublayer(input))`. The last two tests check a property of any correct output: each normalized row has mean 0 and (up to $\epsilon$) variance 1, which a missing final normalization violates.

model:
```python
def feed_forward(X, W1, b1, W2, b2):
    """Position-wise two-layer ReLU network applied to each vector in X."""
    out = []
    for x in X:
        hidden = [max(0.0, sum(w * a for w, a in zip(row, x)) + b)
                  for row, b in zip(W1, b1)]
        out.append([sum(w * a for w, a in zip(row, hidden)) + b
                    for row, b in zip(W2, b2)])
    return out
```
hint: Handle each vector on its own: first layer, ReLU, second layer; no information flows between positions.
solution: The same two weight matrices are applied to each position independently. The last test has a negative hidden pre-activation, which the ReLU zeroes, leaving only the output bias.

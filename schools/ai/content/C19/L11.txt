@article
A translation system outputs "the cat sat on a mat" and the reference says "the cat sat on the mat". Is the output right? A person would say it is nearly perfect. For a classifier we count correct labels, but for generated text there are many acceptable outputs. Evaluation therefore combines **automatic metrics**, which are cheap and repeatable, with **human judgment**, which is the standard they try to approximate.

### BLEU

**BLEU** (Papineni and colleagues, 2002) was designed for machine translation. It compares a candidate with one or more reference translations by n-gram overlap. The **modified n-gram precision** $p_n$ counts each candidate n-gram, but only up to the number of times it appears in the reference (this is **clipping**), and divides by the number of candidate n-grams:
$$p_n = \frac{\sum_{g} \min\big(\mathrm{count}_{\text{cand}}(g),\ \mathrm{count}_{\text{ref}}(g)\big)}{\sum_{g} \mathrm{count}_{\text{cand}}(g)}.$$
Without clipping, "the the the the" would get precision 1 against any reference containing "the". Precision alone rewards short outputs, so BLEU multiplies by a **brevity penalty** with candidate length $c$ and reference length $r$:
$$\mathrm{BP} = \begin{cases} 1 & c > r \\ e^{1 - r/c} & c \le r \end{cases},\qquad \mathrm{BLEU} = \mathrm{BP}\cdot\exp\Big(\sum_{n=1}^{N} w_n \log p_n\Big),$$
with uniform weights $w_n = 1/N$; the usual choice is $N = 4$, and the score is $0$ if any $p_n = 0$. For the candidate "the the the dog sat" and the reference "the dog sat on the mat" with $N = 2$: the unigram counts give $\min(3,2) + 1 + 1 = 4$ matches out of 5, so $p_1 = 0.8$; the candidate bigrams are the-the (twice), the-dog, dog-sat, and only the-dog and dog-sat occur in the reference, so $p_2 = 2/4 = 0.5$; $c = 5$, $r = 6$ gives $\mathrm{BP} = e^{-1/5} = 0.8187$. Then $\mathrm{BLEU} = 0.8187\sqrt{0.8 \times 0.5} = 0.518$.

```python
import math
from collections import Counter

def ngrams(tokens, n):
    return Counter(tuple(tokens[i:i + n]) for i in range(len(tokens) - n + 1))

def modified_precision(cand, ref, n):
    c, r = ngrams(cand, n), ngrams(ref, n)
    total = sum(c.values())
    if total == 0:
        return 0.0
    return sum(min(count, r[g]) for g, count in c.items()) / total

def bleu(cand, ref, max_n):
    ps = [modified_precision(cand, ref, n) for n in range(1, max_n + 1)]
    if min(ps) == 0:
        return 0.0
    bp = 1.0 if len(cand) > len(ref) else math.exp(1 - len(ref) / len(cand))
    return bp * math.exp(sum(math.log(p) for p in ps) / max_n)
```

BLEU is computed over a whole test set (counts are summed before dividing), not as an average of sentence scores, because sentence-level BLEU is often zero for short sentences. Scores depend on the tokenization and on the number of references, so they are comparable only under the same settings.

### ROUGE

**ROUGE** (Lin, 2004) was designed for summarization and emphasizes **recall**: how much of the reference appears in the candidate. **ROUGE-N** uses clipped n-gram overlap divided by the number of reference n-grams. **ROUGE-L** uses the **longest common subsequence** (LCS): the longest sequence of words that appears in both texts in the same order, not necessarily contiguously. With LCS length $\ell$, candidate length $c$ and reference length $r$, the precision is $\ell/c$, the recall is $\ell/r$, and the score is the F-measure $2PR/(P+R)$. For the candidate and reference above, the LCS is "the dog sat" with $\ell = 3$, so $P = 3/5$, $R = 3/6$ and $F = 0.545$.

### Human judgment and agreement

People can rate outputs on scales such as fluency and adequacy (does it keep the meaning?), or compare two outputs and say which is better; pairwise comparison is often easier and more consistent than absolute ratings. Raters disagree, so we measure **agreement**. Raw agreement is misleading because two raters who both say "good" most of the time agree by chance. **Cohen's kappa** corrects for this: with observed agreement $p_o$ and the agreement $p_e$ expected if the raters labeled independently with their own label frequencies,
$$\kappa = \frac{p_o - p_e}{1 - p_e}.$$
Two raters judge 10 outputs as good or bad: both say good for 5, both bad for 2, rater A good and B bad for 2, A bad and B good for 1. Then $p_o = 0.7$; rater A says good 7 times and B 6 times, so $p_e = 0.7\cdot 0.6 + 0.3\cdot 0.4 = 0.54$ and $\kappa = 0.16/0.46 = 0.348$. A value of 1 is perfect agreement and 0 is chance level.

### What the metrics cannot do

Studies of machine translation and summarization have repeatedly found that overlap metrics correlate with human judgments better when averaging over many sentences or comparing systems of similar design than when scoring a single sentence, and that they can penalize a correct paraphrase and reward a fluent but wrong output. They cannot check truth, and they depend on the quality and number of references. They are best used to track progress on a fixed test set alongside human evaluation, with differences reported with confidence intervals (for example by bootstrap resampling of the test set), not as proof that one output is better.

@mistakes
- Computing BLEU without clipping, so repeated words are rewarded.
- Averaging sentence-level BLEU scores instead of pooling n-gram counts over the test set.
- Comparing BLEU values obtained with different tokenizations or reference sets.
- Reading high raw agreement between raters as high reliability: always compare with chance agreement.

```python
from collections import Counter


def rouge_n(cand, ref, n):
    """Clipped n-gram precision, recall and F1."""
    def grams(tokens):
        return Counter(tuple(tokens[i:i + n]) for i in range(len(tokens) - n + 1))
    c, r = grams(cand), grams(ref)
    overlap = sum(min(count, r[g]) for g, count in c.items())
    n_c, n_r = sum(c.values()), sum(r.values())
    precision = overlap / n_c if n_c else 0.0
    recall = overlap / n_r if n_r else 0.0
    f1 = 2 * precision * recall / (precision + recall) if precision + recall else 0.0
    return precision, recall, f1
```
hint: Build a `Counter` of n-grams for each text, add up `min` of the two counts over the candidate's n-grams, then divide.
solution: The same clipped overlap gives precision (divide by the candidate's n-grams) and recall (divide by the reference's). The test with three copies of `x` against one shows clipping: the overlap is 1 of 3 candidate unigrams.

model:
```python
def rouge_l(cand, ref):
    """ROUGE-L F-measure from the longest common subsequence."""
    if not cand or not ref:
        return 0.0
    table = [[0] * (len(ref) + 1) for _ in range(len(cand) + 1)]
    for i, a in enumerate(cand, 1):
        for j, b in enumerate(ref, 1):
            if a == b:
                table[i][j] = table[i - 1][j - 1] + 1
            else:
                table[i][j] = max(table[i - 1][j], table[i][j - 1])
    lcs = table[-1][-1]
    if lcs == 0:
        return 0.0
    precision, recall = lcs / len(cand), lcs / len(ref)
    return 2 * precision * recall / (precision + recall)
```
hint: Fill a table where cell (i, j) is the LCS length of the first i candidate words and the first j reference words: add 1 on a match, otherwise take the larger neighbor.
solution: The table recurrence is the standard LCS dynamic program. For `abcde` against `ace` the LCS is `ace` (length 3), so $P = 3/5$, $R = 1$ and $F = 0.75$. Unlike ROUGE-N, the matched words need not be adjacent, only in order.

```python
from collections import Counter


def cohen_kappa(a, b):
    """Chance-corrected agreement between two raters."""
    n = len(a)
    p_o = sum(1 for x, y in zip(a, b) if x == y) / n
    ca, cb = Counter(a), Counter(b)
    p_e = sum(ca[label] / n * cb[label] / n for label in set(a) | set(b))
    if p_e == 1:
        return 1.0
    return (p_o - p_e) / (1 - p_e)
```
hint: Compute the observed agreement, then the chance agreement from each rater's label frequencies, then apply the formula.
solution: Kappa rescales agreement so that 0 means chance level and 1 perfect agreement; two raters who always disagree on two balanced labels get $-1$. Here, $p_o = 0.75$ and $p_e = 0.6 \cdot 0.55 + 0.4 \cdot 0.45 = 0.51$ in the first test, giving $0.24/0.49 \approx 0.49$.

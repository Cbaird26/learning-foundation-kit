@article
An $n$-gram model treats "the cat sat" and "the kitten sat" as unrelated, and it cannot look back more than a few words without running out of data. A **neural language model** fixes both problems: it maps words to vectors, so similar words share statistical strength, and it computes next-word probabilities with a function that has far fewer parameters than a count table.

### A feedforward language model

The first widely cited neural language model (Bengio and colleagues, 2003) predicts the next word $w_t$ from the previous $n$ words. Each word is looked up in an **embedding** table $\mathbf{E} \in \mathbb{R}^{|V| \times d}$, the $n$ embeddings are concatenated into one vector of length $nd$, a hidden layer applies a nonlinearity, and a final layer with a **softmax** gives a distribution over the vocabulary:
$$\mathbf{h} = \tanh(\mathbf{W}_1 \mathbf{x} + \mathbf{b}_1),\qquad P(w_t = j \mid \text{context}) = \operatorname{softmax}(\mathbf{W}_2 \mathbf{h} + \mathbf{b}_2)_j.$$
The parameter count is $|V|d$ for $\mathbf{E}$, $(nd)h + h$ for the hidden layer and $h|V| + |V|$ for the output layer. With $|V| = 1000$, $d = 50$, $n = 3$ and $h = 100$ this is $50{,}000 + 15{,}100 + 101{,}000 = 166{,}100$. The model is trained by minimizing cross-entropy with backpropagation, and its perplexity (week 4) is the measure of success. It still has a fixed window of $n$ words.

### Self-attention

A **transformer** (Vaswani and colleagues, 2017) drops the fixed window. Each position builds its new representation as a weighted average of the values of all positions it may look at, with weights computed from how well a **query** matches each **key**. For a sequence of $n$ vectors, let $\mathbf{Q}, \mathbf{K} \in \mathbb{R}^{n \times d_k}$ and $\mathbf{V} \in \mathbb{R}^{n \times d_v}$ be learned linear functions of the inputs, one row per position. Then
$$\operatorname{Attention}(\mathbf{Q},\mathbf{K},\mathbf{V}) = \operatorname{softmax}\!\Big(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}\Big)\mathbf{V},$$
with the softmax taken along each row. If the entries of a query and a key are independent with mean 0 and variance 1, their dot product has variance $d_k$; dividing by $\sqrt{d_k}$ keeps the scores in a range where the softmax is not saturated and its gradients do not vanish.

For $\mathbf{Q} = \begin{pmatrix}1&0\\0&1\end{pmatrix}$, $\mathbf{K} = \begin{pmatrix}1&0\\1&1\end{pmatrix}$, $\mathbf{V} = \begin{pmatrix}1&2\\3&4\end{pmatrix}$ and $d_k = 2$, the scaled scores are $\begin{pmatrix}0.7071&0.7071\\0&0.7071\end{pmatrix}$, the row-wise softmax gives weights $(0.5, 0.5)$ and $(0.3302, 0.6698)$, and the outputs are $(2, 3)$ and $(2.3395, 3.3395)$.

```python
import math

def softmax(scores):
    m = max(scores)
    exps = [math.exp(s - m) for s in scores]
    total = sum(exps)
    return [e / total for e in exps]

def attention(Q, K, V):
    """Q, K: lists of d_k-vectors; V: list of d_v-vectors. One output per query."""
    d_k = len(Q[0])
    out = []
    for q in Q:
        scores = [sum(a * b for a, b in zip(q, k)) / math.sqrt(d_k) for k in K]
        w = softmax(scores)
        out.append([sum(w[j] * V[j][c] for j in range(len(V))) for c in range(len(V[0]))])
    return out
```

### Language modeling needs a causal mask

A language model must predict word $t$ from words before $t$. If position $t$ could attend to position $t+1$, the task would be trivial. The **causal mask** sets the scores for all future positions to $-\infty$ before the softmax, so their weights are exactly 0. Position $t$ then attends to positions $1,\dots,t$ only. Training uses all positions of a sequence in parallel, each predicting its own next word, which is a major reason transformers train faster than recurrent networks on modern hardware. The cost is that attention compares every allowed pair of positions: $n^2$ scores, or $n(n+1)/2$ with the causal mask, so long inputs are expensive.

### The rest of the block

Attention alone ignores the order of positions: shuffling the inputs just shuffles the outputs. The original transformer adds **positional encodings**: for position $p$ and dimension pair $i$,
$$\mathrm{PE}(p, 2i) = \sin\!\big(p / 10000^{2i/d}\big),\qquad \mathrm{PE}(p, 2i+1) = \cos\!\big(p / 10000^{2i/d}\big),$$
added to the word embeddings (many later models learn the positions instead). **Multi-head attention** runs several attention heads with different learned projections in parallel and concatenates them. A **transformer block** applies attention, then a position-wise feedforward network, each wrapped in a **residual connection** (the layer's output is added to its input) and **layer normalization**, which rescales each vector to zero mean and unit variance: $\operatorname{LN}(\mathbf{x}) = (\mathbf{x} - \mu)/\sqrt{\sigma^2 + \epsilon}$ (then a learned scale and shift). Stacking such blocks and finishing with a softmax over the vocabulary gives a **decoder-only** language model; the same ingredients, without the mask, give an **encoder** that reads a whole sentence.

@example
title: Attention weights by hand
problem: A query is $\mathbf{q} = (1, 1)$ and there are two keys $\mathbf{k}_1 = (2, 0)$ and $\mathbf{k}_2 = (0, 1)$ with values $\mathbf{v}_1 = (4, 0)$ and $\mathbf{v}_2 = (0, 8)$. Compute the attention output with $d_k = 2$.
step: Dot products: $\mathbf{q}\cdot\mathbf{k}_1 = 2$ and $\mathbf{q}\cdot\mathbf{k}_2 = 1$. Scale by $1/\sqrt2$: scores $1.4142$ and $0.7071$.
step: Softmax: $e^{1.4142} = 4.113$ and $e^{0.7071} = 2.028$, total $6.141$, so the weights are $0.6698$ and $0.3302$.
step: Output: $0.6698\,(4, 0) + 0.3302\,(0, 8) = (2.679, 2.642)$.
answer: $(2.679,\ 2.642)$.

@mistakes
- Forgetting the $1/\sqrt{d_k}$ scaling, which makes the softmax saturate for large $d_k$.
- Applying the softmax along columns instead of along each row: each query needs weights over the keys that sum to 1.
- Masking by setting future scores to 0 instead of $-\infty$: a score of 0 still gets weight $e^0$ in the softmax.
- Assuming attention knows word order without positional information.

model:
```python
import math


def causal_attention(Q, K, V):
    """Scaled dot-product attention where position i sees positions 0..i."""
    d_k = len(Q[0])
    out = []
    for i, q in enumerate(Q):
        scores = [sum(a * b for a, b in zip(q, K[j])) / math.sqrt(d_k) for j in range(i + 1)]
        top = max(scores)
        exps = [math.exp(s - top) for s in scores]
        total = sum(exps)
        weights = [e / total for e in exps]
        out.append([sum(weights[j] * V[j][c] for j in range(i + 1)) for c in range(len(V[0]))])
    return out
```
hint: Compute scores only for `j` from 0 to `i`, which has the same effect as setting the future scores to minus infinity.
solution: Restricting the sum to `j <= i` is equivalent to masking with $-\infty$. The first position can attend only to itself, so its output equals its own value row. The last test has huge scores; without subtracting the maximum, the exponentials overflow.

model:
```python
import math


def sinusoidal_pe(pos, dim):
    """Sinusoidal positional encoding of one position."""
    out = []
    for i in range(dim // 2):
        angle = pos / 10000 ** (2 * i / dim)
        out.append(math.sin(angle))
        out.append(math.cos(angle))
    return out
```
hint: Loop over the pair index `i` from 0 to `dim // 2 - 1`; each pair shares one angle and contributes a sine and then a cosine.
solution: Each pair of dimensions is a sine and a cosine of the same angle, with a wavelength that grows geometrically with `i`: the first pair changes fastest with position, the last pair slowest. Position 0 gives zeros for the sines and ones for the cosines.

model:
```python
import math


def layer_norm(x, eps):
    """Normalize a vector to zero mean and unit variance."""
    mean = sum(x) / len(x)
    var = sum((v - mean) ** 2 for v in x) / len(x)
    return [(v - mean) / math.sqrt(var + eps) for v in x]
```
hint: Compute the mean, then the mean of squared deviations, then rescale each entry.
solution: Layer normalization normalizes across the features of one vector, not across a batch of examples. The `eps` term keeps the division safe for a constant vector, whose variance is 0: the result is then all zeros.

@quiz mc
prompt: Why does a decoder-only language model use a causal mask during training?
choice*: So that the prediction at each position cannot use the words that come after it, which would make next-word prediction trivial.
choice: To reduce the vocabulary size at later positions.

solution: Without the mask, the representation at position $t$ could copy the word at $t+1$, which is the target, and the model would learn nothing useful for generation.

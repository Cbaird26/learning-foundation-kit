@article
In "the saw is sharp" the word "saw" is a noun, and in "I saw it" it is a verb. No dictionary can settle this: the tag depends on the neighbors. **Sequence labeling** assigns one label to each token of a sentence while letting neighboring labels influence one another. Two classic tasks are **part-of-speech (POS) tagging**, with labels such as noun, verb and determiner (the Universal Dependencies scheme has 17 coarse tags), and **named-entity recognition** (NER), which finds spans naming people, places or organizations.

### The hidden Markov model

A **hidden Markov model** (HMM) generates a sentence by a chain of hidden tags. It has an initial distribution $\pi(t)$, a transition matrix $A(t', t) = P(t_i = t \mid t_{i-1} = t')$ and emissions $B(t, w) = P(w_i = w \mid t_i = t)$. The joint probability of tags $t_1\dots t_n$ and words $w_1\dots w_n$ is
$$P(\mathbf{t}, \mathbf{w}) = \pi(t_1)\,B(t_1, w_1)\prod_{i=2}^{n} A(t_{i-1}, t_i)\,B(t_i, w_i).$$
Two assumptions are built in: a tag depends only on the previous tag, and a word depends only on its own tag. Tagging means finding $\hat{\mathbf t} = \arg\max_{\mathbf t} P(\mathbf t, \mathbf w)$ (the same maximizer as for $P(\mathbf t \mid \mathbf w)$, since $P(\mathbf w)$ is fixed). The parameters are estimated by counting in a tagged corpus: $A(t',t) = c(t',t)/c(t')$ and $B(t,w) = c(t,w)/c(t)$.

Our toy model has tags D (determiner), N (noun) and V (verb), and $\pi = (D\!:\!0.6,\ N\!:\!0.3,\ V\!:\!0.1)$.

| from \ to | D | N | V |
|---|---|---|---|
| D | 0.0 | 0.9 | 0.1 |
| N | 0.2 | 0.2 | 0.6 |
| V | 0.5 | 0.4 | 0.1 |

| tag | emissions |
|---|---|
| D | the 0.6, a 0.4 |
| N | dog 0.3, cat 0.3, runs 0.1, saw 0.3 |
| V | runs 0.3, sees 0.4, saw 0.3 |

### Viterbi

There are $K^n$ tag sequences for $n$ words and $K$ tags. The **Viterbi algorithm** finds the best one in $O(nK^2)$ time by dynamic programming. Let $\delta_i(t)$ be the probability of the best tag sequence for the first $i$ words that ends in tag $t$:
$$\delta_1(t) = \pi(t)B(t, w_1),\qquad \delta_i(t) = \Big[\max_{t'} \delta_{i-1}(t')\,A(t', t)\Big] B(t, w_i).$$
Store the maximizing $t'$ as a back-pointer, and at the end follow the back-pointers from the best final tag. Ties are broken in favor of the tag listed first. For "the dog runs":

| $i$ | word | $\delta_i(\mathrm{D})$ | $\delta_i(\mathrm{N})$ | $\delta_i(\mathrm{V})$ |
|---|---|---|---|---|
| 1 | the | 0.36 | 0 | 0 |
| 2 | dog | 0 | 0.0972 | 0 |
| 3 | runs | 0 | 0.001944 | 0.017496 |

At $i = 3$, $\delta(\mathrm N) = 0.0972\cdot 0.2\cdot 0.1 = 0.001944$ and $\delta(\mathrm V) = 0.0972\cdot 0.6\cdot 0.3 = 0.017496$. The best sequence is D N V with probability $0.017496$.

```python
def viterbi(obs, states, pi, A, B):
    """Return (best tag list, its probability). Ties go to the earlier state."""
    delta = [{s: pi[s] * B[s].get(obs[0], 0.0) for s in states}]
    back = []
    for word in obs[1:]:
        row, ptr = {}, {}
        for s in states:
            best, best_p = states[0], -1.0
            for r in states:
                p = delta[-1][r] * A[r][s]
                if p > best_p:
                    best, best_p = r, p
            row[s] = best_p * B[s].get(word, 0.0)
            ptr[s] = best
        delta.append(row)
        back.append(ptr)
    last = states[0]
    for s in states:
        if delta[-1][s] > delta[-1][last]:
            last = s
    path = [last]
    for ptr in reversed(back):
        path.append(ptr[path[-1]])
    return path[::-1], delta[-1][last]
```

For long sentences, products of probabilities underflow, so implementations add log probabilities instead; the maximization is unchanged. HMM taggers are limited: they cannot use features of the word such as its suffix or capitalization. **Conditional random fields** (Lafferty, McCallum and Pereira, 2001) and later neural taggers condition on such features and on the whole sentence.

### Named entities and the BIO scheme

NER is turned into tagging with the **BIO** scheme: `B-X` begins an entity of type X, `I-X` continues it, and `O` is outside any entity. "Ada Lovelace visited Paris" is tagged B-PER, I-PER, O, B-LOC. Reading the tags back gives the spans: PER covering words 0 to 1 and LOC covering word 3. NER is scored at the **entity level**: a predicted entity counts as correct only if both its span and type match a gold entity exactly, and precision, recall and F1 are computed over entities, not words. A tagger that gets "Ada" right and "Lovelace" wrong gets word accuracy $3/4$ but finds no correct entity.

@example
title: Viterbi on two words
problem: With the toy model above, find the best tag sequence and its probability for "dog saw".
step: Initialize: $\delta_1(\mathrm N) = 0.3 \cdot 0.3 = 0.09$. D has no emission for "dog" and V neither, so $\delta_1(\mathrm D) = \delta_1(\mathrm V) = 0$.
step: For "saw" and tag N: the only nonzero predecessor is N, with $0.09 \cdot A(\mathrm N, \mathrm N) = 0.018$, then times $B(\mathrm N, \text{saw}) = 0.3$ gives $0.0054$.
step: For tag V: $0.09 \cdot A(\mathrm N, \mathrm V) = 0.054$, times $B(\mathrm V, \text{saw}) = 0.3$ gives $0.0162$. Tag D cannot emit "saw".
step: The best final tag is V, with back-pointer N, so the sequence is N V.
answer: N V, with probability $0.0162$.

@example
title: Spans from BIO tags

step: Word 0 is `B-ORG` and word 1 is `I-ORG`, so an ORG entity covers words 0 and 1.
step: Words 2 and 3 are `O`, outside any entity.

@mistakes
- Maximizing each tag separately: the best tag for every word can form a sequence that the transitions make very unlikely. Viterbi optimizes the whole sequence.
- Confusing the maximum (Viterbi) with the sum over all tag sequences (the forward algorithm, which gives the probability of the sentence).
- Starting the recursion with the transition from a tag instead of the initial distribution $\pi$.
- Scoring NER by word accuracy; most words are `O`, so accuracy is high even when entities are missed.

model:
```python
def forward_prob(obs, states, pi, A, B):
    """Forward algorithm: total probability of obs under the HMM."""
    if not obs:
        return 1.0
    alpha = {s: pi[s] * B[s].get(obs[0], 0.0) for s in states}
    for word in obs[1:]:
        alpha = {
            s: sum(alpha[r] * A[r][s] for r in states) * B[s].get(word, 0.0)
            for s in states
        }
    return sum(alpha.values())
```
hint: This is the Viterbi recursion with the maximum over previous tags replaced by a sum, and the final answer is the sum over the last tags.
solution: Let `alpha[s]` be the probability of the words so far, summed over all tag sequences ending in `s`. Each step sums over the previous tag and multiplies by the emission. The test with the unknown word "zebra" gives 0, because no tag can emit it.

model:
```python
def bio_to_spans(tags):
    """Entity spans (type, start, end_exclusive) from BIO tags."""
    spans = []
    start, kind = None, None
    for i, tag in enumerate(tags):
        if tag == "O":
            if kind is not None:
                spans.append((kind, start, i))
            start, kind = None, None
            continue
        prefix, label = tag.split("-", 1)
        if prefix == "B" or kind != label:
            if kind is not None:
                spans.append((kind, start, i))
            start, kind = i, label
    if kind is not None:
        spans.append((kind, start, len(tags)))
    return spans
```
hint: Keep the start index and type of the currently open span; close it when you see `O`, a `B` tag, or an `I` tag of a different type, and close it at the end of the list.
solution: A span closes in four situations: an `O`, a new `B`, an `I` with another type, and the end of the input. The lenient rule that an `I-X` can start a span makes the second test return a span even without a `B`.

model:
```python
from collections import Counter, defaultdict


def estimate_hmm(tagged):
    """Maximum-likelihood initial, transition and emission probabilities."""
    starts = Counter()
    trans = defaultdict(Counter)
    emit = defaultdict(Counter)
    for sent in tagged:
        starts[sent[0][1]] += 1
        for (_, t1), (_, t2) in zip(sent, sent[1:]):
            trans[t1][t2] += 1
        for word, tag in sent:
            emit[tag][word] += 1
    pi = {t: c / len(tagged) for t, c in starts.items()}
    A = {t1: {t2: c / sum(row.values()) for t2, c in row.items()}
         for t1, row in trans.items()}
    B = {t: {w: c / sum(row.values()) for w, c in row.items()}
         for t, row in emit.items()}
    return pi, A, B
```
hint: Use three counters: sentence-initial tags, tag bigrams, and (tag, word) pairs, then normalize each row.
solution: Transition rows are normalized by the number of transitions out of a tag, not by the number of tokens with that tag: tag V is never followed by another tag here, so it has no row in `A`. Emission rows are normalized by all tokens of the tag.

@article
A phone keyboard suggests the next word after "I'll see you". A speech recognizer must choose between "recognize speech" and "wreck a nice beach", which sound alike. Both tasks need a **language model**: a function that gives each word sequence a probability. The simplest ones count.

### From the chain rule to bigrams

By the chain rule of probability, a sentence $w_1 w_2 \dots w_m$ has probability
$$P(w_1,\dots,w_m) = \prod_{i=1}^{m} P(w_i \mid w_1,\dots,w_{i-1}).$$
Conditioning on the whole history is hopeless, since most histories occur once. An **$n$-gram model** keeps only the last $n-1$ words: the **bigram** model uses $P(w_i \mid w_{i-1})$ and the **trigram** model $P(w_i \mid w_{i-2}, w_{i-1})$. This is a Markov assumption: the next word depends on a short history only. We pad each sentence with a start symbol `<s>` and an end symbol `</s>`, so that the model also learns how sentences begin and end.

The **maximum-likelihood estimate** (MLE) is relative frequency:
$$P(w \mid v) = \frac{c(v, w)}{c(v)},$$
where $c(v,w)$ counts the bigram and $c(v)$ counts $v$ as the first word of a bigram.

Take three invented sentences: "the cat sat", "the cat ran", "a dog sat". With padding the bigram counts are $c(\texttt{<s>}, \text{the}) = 2$, $c(\texttt{<s>}, \text{a}) = 1$, $c(\text{the}, \text{cat}) = 2$, $c(\text{cat}, \text{sat}) = 1$, $c(\text{cat}, \text{ran}) = 1$, $c(\text{a}, \text{dog}) = 1$, $c(\text{dog}, \text{sat}) = 1$, $c(\text{sat}, \texttt{</s>}) = 2$, $c(\text{ran}, \texttt{</s>}) = 1$. Then
$$P(\text{the cat sat}) = P(\text{the}\mid\texttt{<s>})\,P(\text{cat}\mid\text{the})\,P(\text{sat}\mid\text{cat})\,P(\texttt{</s>}\mid\text{sat}) = \tfrac{2}{3}\cdot 1\cdot \tfrac{1}{2}\cdot 1 = \tfrac{1}{3}.$$
But "a cat sat" gets probability $0$ because $c(\text{a}, \text{cat}) = 0$. A single unseen bigram wipes out the sentence, and new text always contains unseen bigrams. Also, products of many probabilities underflow, so implementations add logarithms.

### Smoothing

**Smoothing** moves some probability from seen to unseen events. **Add-one (Laplace) smoothing** adds 1 to every count:
$$P_{\text{add-}k}(w \mid v) = \frac{c(v,w) + k}{c(v) + k\,|V|}, \quad k = 1.$$
Here $|V|$ is the number of possible next words, counting `</s>` but not `<s>`; in the example, $|V| = 7$ (the, cat, sat, ran, a, dog, `</s>`). The denominator grows by $k|V|$ so that the probabilities over all $w$ still sum to 1. Now $P(\text{cat} \mid \text{a}) = (0+1)/(1+7) = 1/8$. **Add-$k$** uses a smaller $k$, such as 0.5 or 0.01. Add-one gives too much mass to unseen events when $|V|$ is large (here an unseen bigram after "cat" gets $1/9$ while the seen "sat" gets only $2/9$); in practice $k$ is chosen on held-out data.

**Interpolation** mixes models of different orders:
$$\hat{P}(w \mid v) = \lambda\, P_{\text{MLE}}(w \mid v) + (1-\lambda)\, P_{\text{MLE}}(w), \quad 0 \le \lambda \le 1,$$
with $\lambda$ tuned on held-out data. A word never seen after $v$ still gets credit for being common. **Backoff** uses the lower-order estimate only when the higher-order count is zero. Kneser–Ney smoothing, which replaces the unigram with a count of the contexts in which a word appears, is the best-known strong method for $n$-gram models.

### In code

```python
from collections import Counter

def bigram_counts(sentences):
    bigrams, contexts = Counter(), Counter()
    for sent in sentences:
        padded = ["<s>"] + sent + ["</s>"]
        for v, w in zip(padded, padded[1:]):
            bigrams[(v, w)] += 1
            contexts[v] += 1
    return bigrams, contexts

def prob(bigrams, contexts, vocab_size, v, w, k=0.0):
    return (bigrams[(v, w)] + k) / (contexts[v] + k * vocab_size)

sents = [["the", "cat", "sat"], ["the", "cat", "ran"], ["a", "dog", "sat"]]
bi, ctx = bigram_counts(sents)
print(prob(bi, ctx, 7, "cat", "sat"))
print(prob(bi, ctx, 7, "a", "cat", k=1))
```

This prints `0.5` and `0.125`. Counters return 0 for unseen keys, which keeps the code short. With a trigram model the context is the previous two words and the padding has two `<s>` symbols. Because of the sparsity problem, $n$-gram models rarely go beyond 5-grams even with very large corpora, and they cannot generalize across similar words: seeing "the cat sat" says nothing about "the kitten sat". Neural models, later in the course, address exactly that.

@example
title: A smoothed bigram probability
problem: Training sentences: "i read books", "i read news", "you read books". Using add-one smoothing, find $P(\text{news} \mid \text{read})$, and the unsmoothed probability of "i read books".
step: Pad and count: $c(\text{read}) = 3$, $c(\text{read}, \text{books}) = 2$, $c(\text{read}, \text{news}) = 1$.
step: The vocabulary is `i read books news you </s>`, so $|V| = 6$.
step: Add-one: $P(\text{news}\mid\text{read}) = (1+1)/(3+6) = 2/9 \approx 0.222$. The same formula gives the unseen $P(\text{you}\mid\text{read}) = 1/9$.
step: For the sentence: $P(\text{i}\mid\texttt{<s>}) = 2/3$, $P(\text{read}\mid\text{i}) = 2/2 = 1$, $P(\text{books}\mid\text{read}) = 2/3$, $P(\texttt{</s>}\mid\text{books}) = 2/2 = 1$. The product is $4/9 \approx 0.444$.
answer: $2/9$ and $4/9$.

@example
title: Interpolating two estimates
problem: A bigram estimate is $P_{\text{MLE}}(w \mid v) = 0.5$ and the unigram estimate is $P_{\text{MLE}}(w) = 0.1$. What is the interpolated probability with $\lambda = 0.8$? What if the bigram context $v$ was never seen?
step: Apply the formula: $0.8 \times 0.5 + 0.2 \times 0.1 = 0.4 + 0.02 = 0.42$.
step: If $v$ was never seen, the bigram estimate is taken to be 0 (there is no evidence), so the result is $0.2 \times 0.1 = 0.02$.
answer: $0.42$, and $0.02$ for an unseen context.

@mistakes
- Dividing by the number of bigram types or by the total number of tokens instead of $c(v)$: the denominator is the count of the context word.
- Adding 1 to the numerator but not $|V|$ to the denominator, so the probabilities no longer sum to 1.
- Including `<s>` in $|V|$: it is never predicted, only used as context.
- Evaluating a smoothed model on the training text and tuning $\lambda$ or $k$ there. These are hyperparameters and belong on held-out data.

model:
```python
def interpolated(tokens, v, w, lam):
    """Linear interpolation of a bigram and a unigram estimate."""
    unigram = tokens.count(w) / len(tokens)
    context = tokens[:-1].count(v)
    pair = sum(1 for a, b in zip(tokens, tokens[1:]) if a == v and b == w)
    bigram = pair / context if context else 0.0
    return lam * bigram + (1 - lam) * unigram
```
hint: Compute the two estimates separately, guarding the bigram division against a zero context count, then mix them.
solution: The unigram estimate uses all tokens, the bigram estimate only the contexts that have a following word. When the context was never seen, the bigram part contributes 0 and only the unigram share remains, which the test with `"zzz"` checks.

```python
from collections import Counter


def trigram_prob(sentences, w1, w2, w3, k):
    """Add-k estimate of P(w3 | w1, w2) with two start symbols."""
    triples, pairs = Counter(), Counter()
    vocab = {"</s>"}
    for sent in sentences:
        vocab.update(sent)
        padded = ["<s>", "<s>"] + sent + ["</s>"]
        for a, b, c in zip(padded, padded[1:], padded[2:]):
            triples[(a, b, c)] += 1
            pairs[(a, b)] += 1
    return (triples[(w1, w2, w3)] + k) / (pairs[(w1, w2)] + k * len(vocab))
```
hint: Pad with two start symbols, then slide a window of three over each padded sentence, counting the triple and its first two words.
solution: The structure is the bigram model with a context of two words. The test with `("a", "cat", "sat")` has an unseen context: both counts are 0, so the estimate is the uniform $1/|V| = 1/7$ for add-one smoothing.

```python
from collections import Counter, defaultdict


def greedy_bigram(sentences, max_len):
    """Generate by always taking the most frequent next word."""
    follow = defaultdict(Counter)
    for sent in sentences:
        padded = ["<s>"] + sent + ["</s>"]
        for v, w in zip(padded, padded[1:]):
            follow[v][w] += 1
    out = []
    current = "<s>"
    while len(out) < max_len and follow[current]:
        counts = follow[current]
        top = max(counts.values())
        current = min(w for w, c in counts.items() if c == top)
        if current == "</s>":
            break
        out.append(current)
    return out
```
hint: Store, for each word, a counter of the words that follow it; then pick the maximum count, using `min` over the tied words.
solution: Greedy generation is deterministic once ties are fixed. The loop in the third test never reaches `</s>` (after `a` the words `b` and `c` tie and `b` wins), so only `max_len` ends it. An empty corpus has no successors of `<s>` and returns an empty list.

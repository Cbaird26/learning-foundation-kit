@article
Every method in this course learns from text written by people, and so can inherit patterns in that text that we would not choose to reproduce. A responsible practitioner learns to measure those patterns, to say what a measurement does and does not show, and to document the limits of a system. This lesson gives tools for that, and describes documented findings from published studies; the field moves quickly, so check the current literature.

### Where problems enter

Differences in outcomes across groups of people can arise at several stages: the **data** (which people and languages are represented and how they are described), the **annotation** (who labels, with what instructions), the **objective** (predicting likely text rewards reproducing common patterns, including stereotyped ones), and **deployment** (who uses the system, for what). A measurement should say which stage it probes.

### Measuring associations in embeddings

Studies of word embeddings trained on large text corpora (Bolukbasi and colleagues, 2016; Caliskan, Bryson and Narayanan) found that their geometry reflects associations present in the text, including stereotyped ones, and that tests modeled on the Implicit Association Test can reproduce documented human association patterns. The **Word Embedding Association Test** (WEAT) of Caliskan and colleagues works as follows. Take two sets of target words $X, Y$ and two sets of attribute words $A, B$. The association of a word $w$ is
$$s(w, A, B) = \frac{1}{|A|}\sum_{a\in A}\cos(\mathbf{w},\mathbf{a}) - \frac{1}{|B|}\sum_{b\in B}\cos(\mathbf{w},\mathbf{b}),$$
and the **effect size** is
$$d = \frac{\operatorname{mean}_{x\in X}\, s(x,A,B) - \operatorname{mean}_{y\in Y}\, s(y,A,B)}{\operatorname{std}_{w \in X\cup Y}\, s(w,A,B)}$$
(here with the sample standard deviation, dividing by $n - 1$). With invented two-dimensional vectors, take flowers $X = \{\text{rose}, \text{tulip}\}$, insects $Y = \{\text{ant}, \text{wasp}\}$, pleasant words $A = \{\text{joy}, \text{love}\}$ and unpleasant words $B = \{\text{pain}, \text{rot}\}$, with $\text{joy} = (1, 0.2)$, $\text{love} = (0.9, 0.4)$, $\text{pain} = (0.1, 1)$, $\text{rot} = (0.2, 0.9)$, $\text{rose} = (0.95, 0.3)$, $\text{tulip} = (0.8, 0.5)$, $\text{ant} = (0.3, 0.9)$, $\text{wasp} = (0.2, 1)$. The association scores are $0.546$ and $0.306$ for the flowers and $-0.400$ and $-0.516$ for the insects, and $d = 1.69$: in these vectors flowers sit much closer to the pleasant words than insects do.

```python
import math

def cosine(u, v):
    dot = sum(a * b for a, b in zip(u, v))
    return dot / (math.sqrt(sum(a * a for a in u)) * math.sqrt(sum(b * b for b in v)))

def association(w, A, B):
    """w is a vector; A and B are lists of vectors."""
    return (sum(cosine(w, a) for a in A) / len(A)
            - sum(cosine(w, b) for b in B) / len(B))
```

An association score is a fact about the vectors and the corpus they came from. It does not by itself show that a downstream system harms anyone, and a system can be harmful with no visible embedding association. Efforts to remove a bias direction from embeddings have been found to hide, rather than fully remove, the associations.

### Auditing outputs

A direct approach is to audit what a system does. Build inputs that differ only in a group term (for example, template sentences with different names or descriptors), record an outcome (a sentiment label, a toxicity flag, whether a pronoun resolves to a person), and compare the **rate of the outcome by group**. Published benchmarks for coreference resolution use sentences whose correct answer does not depend on gender, to test whether systems resolve pronouns by stereotype. A gap in rates is evidence that needs interpretation: check sample sizes, test whether the gap could be chance, check that templates are natural, and report the gap with uncertainty. The fairness criteria of the earlier courses define what to compare; there is no single right metric, and some criteria cannot all hold at once.

### Many languages

There are roughly 7,000 languages, and the large majority have little digital text. Models and benchmarks have been built mostly for languages with large online corpora, so performance and evaluation resources are very uneven. **Multilingual** models are trained on text in many languages with a shared subword vocabulary and can transfer what they learn across related languages, but each language gets a smaller share of the vocabulary and of the training data. A measurable consequence is **fertility**, the average number of subword pieces per word: a tokenizer trained mostly on one language splits words in other languages into more pieces, so the same content costs more tokens, more compute and more of the fixed context window; studies of subword tokenizers have documented such differences across languages. Dialects and varieties of a language, and languages with little standard written form, face similar gaps.

### Limits

Next-token prediction rewards probable text, not true text. Published studies of summarization and question answering have documented fluent outputs that contain statements unsupported by the input, so fluency is not evidence of accuracy. Models can reproduce training text, which raises privacy and licensing questions; how copyright law applies to training data is contested and under review in courts and legislatures. Benchmarks can leak into training data, which inflates scores, and a benchmark measures only the skill it was built to test. Whether such models understand language is a question on which researchers disagree; the evidence needed to settle it is itself debated, so treat both confident answers with care.

Good practice is to document systems and data: **model cards** (Mitchell and colleagues, 2018) report intended use, evaluation by group and limitations, and **datasheets for datasets** (Gebru and colleagues) report how data was collected and what it contains. Laws and standards on AI change over time; for example, the EU AI Act sets transparency obligations for some systems, such as chatbots, with dates that apply in stages, so check the current text.

@mistakes
- Treating an embedding association as proof that a deployed system is harmful, or its absence as proof that it is safe.
- Auditing with templates that differ in more than the group term, so that the difference cannot be attributed.
- Reporting a rate gap without sample sizes or uncertainty.
- Assuming that a tokenizer or benchmark built mostly on one language serves all languages equally.

model:
```python
import math


def effect_size(X, Y, A, B):
    """WEAT effect size with the sample standard deviation."""
    def cos(u, v):
        dot = sum(a * b for a, b in zip(u, v))
        return dot / (math.sqrt(sum(a * a for a in u)) * math.sqrt(sum(b * b for b in v)))

    def assoc(w):
        return (sum(cos(w, a) for a in A) / len(A)
                - sum(cos(w, b) for b in B) / len(B))

    sx = [assoc(w) for w in X]
    sy = [assoc(w) for w in Y]
    allv = sx + sy
    mean = sum(allv) / len(allv)
    std = math.sqrt(sum((v - mean) ** 2 for v in allv) / (len(allv) - 1))
    return (sum(sx) / len(sx) - sum(sy) / len(sy)) / std
```
hint: Compute the list of associations for X and for Y, take the difference of their means, and divide by the sample standard deviation of the combined list.
solution: Swapping X and Y, or swapping A and B, flips the sign of the numerator and leaves the standard deviation unchanged, so the effect size changes sign, as the second and third tests check. The sample standard deviation divides by $n - 1$.

model:
```python
def rate_gap(rows):
    """Per-group outcome rates and the largest gap between groups."""
    counts, flagged = {}, {}
    for group, flag in rows:
        counts[group] = counts.get(group, 0) + 1
        flagged[group] = flagged.get(group, 0) + flag
    rates = {g: flagged[g] / counts[g] for g in counts}
    if len(rates) < 2:
        return rates, 0.0
    return rates, max(rates.values()) - min(rates.values())
```
hint: Keep two dictionaries, the number of rows and the number of flagged rows for each group, then divide.
solution: The gap compares the extreme groups, so it is 0 with one group. A real audit would add the number of rows per group and a measure of uncertainty, since a small group can have a large gap by chance.

assert fertility(["the", "cats", "unhappy", "zzz"], v) == 2.0
assert fertility(["happy"], {"h", "a", "p", "y"}) == 5.0

model:
```python
def fertility(words, vocab):
    """Average number of greedy longest-match pieces per word."""
    if not words:
        return 0.0
    total = 0
    for word in words:
        i = 0
        while i < len(word):
            for j in range(len(word), i, -1):
                if word[i:j] in vocab:
                    i = j
                    break
            else:
                i += 1
            total += 1
    return total / len(words)
```
hint: Count one piece for each step of the segmentation loop, whether it matched a vocabulary string or fell back to one character.
solution: Fertility counts pieces, so the same word costs more pieces when the vocabulary lacks longer strings for it; the second and third tests use the same word with different vocabularies. Unknown characters count as one piece each, as in the word `zzz` of the first test.

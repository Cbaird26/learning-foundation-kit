@article
The words "cat" and "dog" are not similar as strings, yet a program that understands text should treat them as closer than "cat" and "mortgage". The **distributional hypothesis** says that words that occur in similar contexts have similar meanings. So we represent each word by the company it keeps: a vector built from counts of the words around it.

### Co-occurrence vectors

Take four invented sentences: "cat drinks milk", "dog drinks water", "cat chases mouse", "dog chases cat". Count, for each word, the words within a window of $\pm 1$ position in the same sentence. The nonzero entries are:

| word | chases | drinks |
|---|---|---|
| cat | 2 | 1 |
| dog | 1 | 1 |
| milk | 0 | 1 |
| water | 0 | 1 |
| mouse | 1 | 0 |

All other entries in these rows are 0 (the full matrix has one column for each of the seven words, and it is symmetric: "chases" has the counts cat 2, dog 1 and mouse 1). The vectors for "cat" and "dog" overlap on "chases" and "drinks". **Cosine similarity** measures the angle between two vectors:
$$\cos(\mathbf{u},\mathbf{v}) = \frac{\mathbf{u}^\top \mathbf{v}}{\lVert \mathbf{u} \rVert_2 \lVert \mathbf{v} \rVert_2}.$$
For cat and dog: $(2\cdot 1 + 1\cdot 1)/(\sqrt5\sqrt2) = 3/\sqrt{10} \approx 0.949$. For milk and water, the vectors are identical and the cosine is 1. For cat and milk it is $1/\sqrt5 \approx 0.447$. Cosine ignores vector length, so a frequent word and a rare word with the same contexts are still similar; the raw dot product would favor frequent words.

### Pointwise mutual information

Raw counts are dominated by frequent words ("the" co-occurs with everything). **Pointwise mutual information** asks whether two words co-occur more often than chance:
$$\mathrm{PMI}(w, c) = \log_2 \frac{P(w, c)}{P(w)\,P(c)}.$$
Estimate $P(w,c) = n(w,c)/T$ where $T$ is the sum of all counts, and $P(w)$, $P(c)$ by the row and column sums divided by $T$. In our corpus $T = 16$, $n(\text{cat}, \text{chases}) = 2$, and the row sums are 3 for cat and 4 for chases. Then
$$\mathrm{PMI}(\text{cat},\text{chases}) = \log_2 \frac{2 \cdot 16}{3 \cdot 4} = \log_2 2.667 \approx 1.415.$$
A value above 0 means more co-occurrence than independence predicts. Pairs never seen have $\mathrm{PMI} = -\infty$, and negative values are unreliable from small counts, so one uses **positive PMI**, $\mathrm{PPMI} = \max(0, \mathrm{PMI})$.

```python
import math
from collections import Counter

def cooccurrence(sentences, window=1):
    counts = Counter()
    for sent in sentences:
        for i, w in enumerate(sent):
            lo, hi = max(0, i - window), min(len(sent), i + window + 1)
            for j in range(lo, hi):
                if j != i:
                    counts[(w, sent[j])] += 1
    return counts

def cosine(u, v):
    dot = sum(a * b for a, b in zip(u, v))
    return dot / (math.sqrt(sum(a * a for a in u)) * math.sqrt(sum(b * b for b in v)))

sents = [["cat", "drinks", "milk"], ["dog", "drinks", "water"],
         ["cat", "chases", "mouse"], ["dog", "chases", "cat"]]
counts = cooccurrence(sents)
vocab = sorted({w for s in sents for w in s})
vec = lambda w: [counts[(w, c)] for c in vocab]
print(round(cosine(vec("cat"), vec("dog")), 3))
```

This prints `0.949`. Real systems use windows of 2 to 10 words and corpora of billions of words, and often reduce the dimension with a matrix factorization such as the singular value decomposition.

### Word2vec: skip-gram with negative sampling

Instead of counting, **word2vec** (Mikolov and colleagues, 2013) trains dense vectors, typically 100 to 300 dimensions, by prediction. The **skip-gram** model predicts a context word $o$ from a center word $c$. Each word has two vectors: $\mathbf{v}_c$ as a center word and $\mathbf{u}_o$ as a context word. Normalizing over the whole vocabulary is expensive, so **negative sampling** turns the task into classification: for each real pair $(c, o)$ draw $K$ random words $k_1, \dots, k_K$ as "fake" contexts, and minimize
$$\ell = -\log \sigma(\mathbf{u}_o^\top \mathbf{v}_c) - \sum_{j=1}^{K} \log \sigma(-\mathbf{u}_{k_j}^\top \mathbf{v}_c),$$
where $\sigma(s) = 1/(1+e^{-s})$. Because $\frac{d}{ds}\big(-\log\sigma(s)\big) = \sigma(s) - 1$ and $\frac{d}{ds}\big(-\log\sigma(-s)\big) = \sigma(s)$, the gradients are
$$\nabla_{\mathbf{u}_o}\ell = (\sigma(s_o) - 1)\mathbf{v}_c,\quad \nabla_{\mathbf{u}_{k}}\ell = \sigma(s_k)\mathbf{v}_c,\quad \nabla_{\mathbf{v}_c}\ell = (\sigma(s_o)-1)\mathbf{u}_o + \sum_j \sigma(s_{k_j})\mathbf{u}_{k_j},$$
with $s = \mathbf{u}^\top\mathbf{v}_c$ for each word. Stochastic gradient descent moves each vector against its gradient. Levy and Goldberg (2014) showed that skip-gram with negative sampling implicitly factorizes a matrix of PMI values shifted by $\log K$, which connects the two halves of this lesson.

```python
import math

def sigmoid(s):
    return 1 / (1 + math.exp(-s))

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def sgns_step(v, u_pos, u_negs, lr):
    g_pos = sigmoid(dot(v, u_pos)) - 1
    g_negs = [sigmoid(dot(v, u)) for u in u_negs]
    grad_v = [g_pos * u_pos[i] + sum(g * u[i] for g, u in zip(g_negs, u_negs))
              for i in range(len(v))]
    new_v = [v[i] - lr * grad_v[i] for i in range(len(v))]
    new_pos = [u_pos[i] - lr * g_pos * v[i] for i in range(len(v))]
    new_negs = [[u[i] - lr * g * v[i] for i in range(len(v))]
                for g, u in zip(g_negs, u_negs)]
    return new_v, new_pos, new_negs
```

@example
title: One skip-gram update
problem: A center word has $\mathbf{v} = (1, 0.5)$, its true context word has $\mathbf{u}_o = (0.5, 1)$, and one negative sample has $\mathbf{u}_k = (1, -1)$. Compute the loss, then one step with learning rate $\eta = 0.1$.
step: Scores: $s_o = 0.5 + 0.5 = 1$ and $s_k = 1 - 0.5 = 0.5$. Then $\sigma(1) = 0.7311$ and $\sigma(0.5) = 0.6225$.
step: Loss: $-\log 0.7311 - \log \sigma(-0.5) = 0.3133 + 0.9741 = 1.2873$.
step: Gradients: $\nabla_{\mathbf{u}_o} = (0.7311 - 1)\mathbf{v} = (-0.2689,\,-0.1345)$, $\nabla_{\mathbf{u}_k} = 0.6225\,\mathbf{v} = (0.6225,\,0.3112)$, $\nabla_{\mathbf{v}} = -0.2689(0.5, 1) + 0.6225(1, -1) = (0.4880,\,-0.8914)$.
step: Update: $\mathbf{u}_o \leftarrow (0.5269,\,1.0134)$, $\mathbf{u}_k \leftarrow (0.9377,\,-1.0311)$, $\mathbf{v} \leftarrow (0.9512,\,0.5891)$. The new loss is $1.1333$, lower than before.
answer: Loss $1.2873$ before the step and $1.1333$ after it; $\mathbf{v}$ becomes $(0.9512, 0.5891)$.

@example
title: PMI from counts
problem: In a corpus with $T = 40$ co-occurrence counts, the pair (coffee, cup) occurs 6 times, "coffee" has row sum 10 and "cup" has column sum 12. Compute PMI and PPMI.
step: Probabilities: $P(w,c) = 6/40 = 0.15$, $P(w) = 10/40 = 0.25$, $P(c) = 12/40 = 0.3$.
step: Ratio: $0.15 / (0.25 \times 0.3) = 2$, so $\mathrm{PMI} = \log_2 2 = 1$ bit. It is positive, so PPMI is also 1.
answer: $\mathrm{PMI} = \mathrm{PPMI} = 1$.

@mistakes
- Using raw counts as vectors and measuring the dot product: frequent words dominate. Use cosine, PMI or both.
- Treating a negative PMI as meaningful when it comes from a count of 0 or 1.
- Updating $\mathbf{v}_c$ with the already updated context vectors: compute all gradients from the old values, then update.
- Reading cosine similarity as "synonymy": co-occurrence also puts together antonyms and related words such as "doctor" and "nurse".

prompt: Why are cosine similarities usually preferred to dot products when comparing co-occurrence vectors of words?
choice*: The dot product grows with vector length, which grows with word frequency, so frequent words look similar to everything.

solution: Doubling a vector doubles its dot products but leaves its cosines unchanged. Cosine therefore compares directions, which reflect the pattern of contexts, rather than frequency. Cosine lies in $[-1, 1]$ in general, and the dot product works for sparse vectors.

```python
def weighted_cooc(sentences, window):
    """Co-occurrence counts that decay as 1 / distance inside a window."""
    counts = {}
    for sent in sentences:
        for i, w in enumerate(sent):
            for j, c in enumerate(sent):
                d = abs(i - j)
                if i != j and d <= window:
                    counts[(w, c)] = counts.get((w, c), 0.0) + 1 / d
    return counts
```
hint: For every ordered pair of different positions in a sentence, check the distance and add `1 / distance`.
solution: The distance-weighted window gives nearer words more weight. Because the loop visits ordered pairs of positions, a repeated word pair `("a", "a")` collects a contribution from both directions, which the third test checks.

model:
```python
import math


def softplus(x):
    """log(1 + exp(x)) without overflow."""
    return max(x, 0.0) + math.log1p(math.exp(-abs(x)))


def sgns_loss(v, u_pos, u_negs):
    """Negative-sampling loss for one (center, context) pair."""
    def score(u):
        return sum(a * b for a, b in zip(u, v))
    loss = softplus(-score(u_pos))
    for u in u_negs:
        loss += softplus(score(u))
    return loss
```
hint: Use $-\log\sigma(s) = \log(1 + e^{-s})$ and $-\log\sigma(-s) = \log(1 + e^{s})$, computed in a way that never exponentiates a large positive number.
solution: Both terms are softplus functions: the positive pair contributes $\mathrm{softplus}(-s_o)$ and each negative sample contributes $\mathrm{softplus}(s_k)$. Writing softplus as $\max(x, 0) + \log(1 + e^{-|x|})$ avoids overflow, which the tests with score 800 or -800 would trigger in a direct implementation.

model:
```python
import math


def analogy(a, b, c, vectors):
    """Word closest in cosine to vec(b) - vec(a) + vec(c), excluding a, b, c."""
    target = [y - x + z for x, y, z in zip(vectors[a], vectors[b], vectors[c])]

    def cos(u):
        dot = sum(p * q for p, q in zip(u, target))
        return dot / (math.sqrt(sum(p * p for p in u)) * math.sqrt(sum(q * q for q in target)))

    candidates = [w for w in vectors if w not in (a, b, c)]
    return min(candidates, key=lambda w: (-cos(vectors[w]), w))
```
hint: Build the target vector, then take the best of the candidate words with `min` and a key that negates the cosine and breaks ties by the word.
solution: Excluding the three query words matters: in the third test the target equals the vector of `king`, which would otherwise win. In the last test the target is $(0, 4)$, and among the allowed words `queen` has the direction closest to it, since `apple` is excluded.

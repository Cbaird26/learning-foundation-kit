## Key ideas by week

1. **Normalization and tokenization.** Tokens and types, regular-expression tokenizers, case folding, stemming, sentence splitting. The type-token ratio falls as text grows (Herdan–Heaps law).
2. **Byte-pair encoding.** Start from characters plus an end symbol, merge the most frequent adjacent pair (weighted by word frequency; ties by the smallest pair), replay merges in order to encode. Vocabulary size = alphabet + merges.
3. **N-grams and smoothing.** Chain rule and the Markov assumption, MLE $c(v,w)/c(v)$, add-$k$: $(c + k)/(c(v) + k|V|)$, interpolation, backoff.
4. **Perplexity.** $\exp(-\frac1N\sum\log p)$ with `</s>` counted and `<s>` not; $2^H$ for cross-entropy in bits; comparable only for the same text and vocabulary.
5. **Embeddings.** Co-occurrence, cosine, PMI $\log_2\frac{P(w,c)}{P(w)P(c)}$ and PPMI, skip-gram with negative sampling and its gradients $(\sigma(s_o)-1)\mathbf{v}$, $\sigma(s_k)\mathbf{v}$.
6. **Classification.** Naive Bayes in log space, logistic regression with gradient $(\hat p - y)\mathbf{x}$, precision, recall, F1.
7. **Sequence labeling.** HMM, Viterbi $\delta_i(t) = \max_{t'}\delta_{i-1}(t')A(t',t)B(t,w_i)$, the forward algorithm (sum instead of max), BIO tags and entity-level scoring.
8. **Neural LMs and transformers.** Embedding plus softmax, $\operatorname{softmax}(QK^\top/\sqrt{d_k})V$, causal mask, positional encoding, layer normalization.
9. **Pretraining.** Causal loss over all positions with teacher forcing; masked loss over selected positions (80/10/10); $C \approx 6ND$.
10. **Decoding.** Greedy, beam search (and length normalization), temperature, top-$k$, top-$p$.
11. **Evaluation.** BLEU (clipping, brevity penalty), ROUGE-N and ROUGE-L, Cohen's kappa, limits of automatic metrics.
12. **Bias, languages, limits.** Association tests, output audits, fertility, documentation with model cards and datasheets.

## Common errors

- Counting types as tokens, or forgetting the end-of-word symbol in BPE.
- Forgetting $|V|$ in the smoothed denominator, or putting `<s>` in $|V|$.
- Averaging per-sentence perplexities, or comparing perplexities across vocabularies.
- Multiplying many probabilities instead of adding logs.
- Using the sum instead of the max in Viterbi (or the reverse in the forward algorithm).
- Masking attention with zeros instead of $-\infty$.
- Evaluating on the data used to choose hyperparameters.
- Treating an association score or a metric as more than it measures.

model:
```python
import math
from collections import Counter


def subword_bigram_perplexity(train, test, merges, k):
    """Perplexity of an add-k bigram model over BPE pieces."""
    def encode(word):
        symbols = list(word) + ["_"]
        for left, right in merges:
            out, i = [], 0
            while i < len(symbols):
                if i + 1 < len(symbols) and symbols[i] == left and symbols[i + 1] == right:
                    out.append(left + right)
                    i += 2
                else:
                    out.append(symbols[i])
                    i += 1
            symbols = out
        return symbols

    def sequence(sentence):
        pieces = []
        for word in sentence:
            pieces.extend(encode(word))
        return ["<s>"] + pieces + ["</s>"]

    bigrams, contexts = Counter(), Counter()
    vocab = {"</s>"}
    for sentence in train:
        seq = sequence(sentence)
        vocab.update(seq[1:-1])
        for v, w in zip(seq, seq[1:]):
            bigrams[(v, w)] += 1
            contexts[v] += 1
    total, n = 0.0, 0
    for sentence in test:
        seq = sequence(sentence)
        for v, w in zip(seq, seq[1:]):
            p = (bigrams[(v, w)] + k) / (contexts[v] + k * len(vocab))
            total += math.log(p)
            n += 1
    return math.exp(-total / n)
```
hint: Write three small helpers: encode a word with the merges, turn a sentence into a padded piece sequence, and score a sequence; then reuse the add-k bigram and perplexity formulas.
solution: This combines weeks 2, 3 and 4: BPE encoding replays the merges in order, the bigram model is over pieces instead of words, and the perplexity is averaged over all predicted pieces, including each `</s>`. The vocabulary size counts pieces seen in training and `</s>`, not `<s>`.

prompt: A word-level language model gives a 1,000-word test text the perplexity 100 per word. The same text becomes 1,600 subword tokens under a BPE tokenizer. A subword model gives the text the same total probability as the word model. What is the perplexity per subword token of the subword model? Give your answer to two decimal places.
answer: 17.78
tol: 0.01
check: exp(1000 * log(100) / 1600)
hint: The total log-probability is $-N\ln\mathrm{PP}$ for each model. Set the two totals equal.
solution: The word model's total log-probability is $-1000\ln 100$. The subword model has the same total over 1,600 tokens, so $1600\ln \mathrm{PP}_s = 1000 \ln 100$ and $\mathrm{PP}_s = 100^{1000/1600} = 100^{0.625} \approx 17.78$. A lower per-token perplexity does not mean a better model, since the tokens are different.

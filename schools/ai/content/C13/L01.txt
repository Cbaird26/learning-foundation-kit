@article
A spam filter looks at two things about each email: whether it is spam ($S$) and whether it contains the word "free" ($W$). From a large mailbox we estimate the **joint distribution** $P(S, W)$, the probability of every combination:

| | $W$ = yes | $W$ = no |
|---|---|---|
| $S$ = spam | 0.12 | 0.18 |
| $S$ = ham | 0.08 | 0.62 |

The four entries are nonnegative and sum to 1. Everything else in this lesson is computed from such a table (or from its continuous cousin, a joint density).

### Marginals

The **marginal** distribution of one variable ignores the other. For discrete variables we add up over the variable we drop (the **sum rule**):

$$P(x) = \sum_{y} P(x, y), \qquad P(y) = \sum_{x} P(x, y).$$

Adding across the rows gives $P(S = \text{spam}) = 0.12 + 0.18 = 0.30$ and $P(S = \text{ham}) = 0.70$; adding down the columns gives $P(W = \text{yes}) = 0.12 + 0.08 = 0.20$. For continuous variables with joint density $p(x, y)$ the sum becomes an integral: $p(x) = \int p(x, y)\, dy$.

### Conditionals and the product rule

The **conditional probability** of $x$ given $y$ restricts attention to the cases where $Y = y$ and renormalizes:

$$P(x \mid y) = \frac{P(x, y)}{P(y)}, \qquad \text{defined when } P(y) > 0.$$

Among emails containing "free", the fraction that are spam is $P(\text{spam} \mid \text{yes}) = 0.12 / 0.20 = 0.6$. The other direction is different: $P(\text{yes} \mid \text{spam}) = 0.12/0.30 = 0.4$. Confusing $P(x \mid y)$ with $P(y \mid x)$ is among the most common errors in applied probability.

Rearranging the definition gives the **product rule** $P(x, y) = P(x \mid y)\,P(y) = P(y \mid x)\,P(x)$. Equating the two forms gives **Bayes' rule**,

$$P(x \mid y) = \frac{P(y \mid x)\, P(x)}{P(y)}, \qquad P(y) = \sum_{x'} P(y \mid x')\, P(x').$$

For $n$ variables the product rule repeats into the **chain rule**: $P(x_1, \dots, x_n) = P(x_1)\,P(x_2 \mid x_1) \cdots P(x_n \mid x_1, \dots, x_{n-1})$. Generative models, from naive Bayes to language models, are chain-rule factorizations.

### Independence

Variables $X$ and $Y$ are **independent** when $P(x, y) = P(x)\,P(y)$ for every pair $(x, y)$. Equivalently, $P(x \mid y) = P(x)$ whenever $P(y) > 0$: learning $y$ tells you nothing about $x$. In the spam table, $P(\text{spam})\,P(\text{yes}) = 0.30 \times 0.20 = 0.06$, but the joint entry is $0.12$, so the word carries information about spam. Note that one failing cell is enough to prove dependence, whereas independence requires every cell to match. Variables are **conditionally independent** given $Z$ if $P(x, y \mid z) = P(x \mid z)\,P(y \mid z)$; naive Bayes assumes the features are conditionally independent given the class.

### Continuous case

Let $(X, Y)$ have density $p(x, y) = x + y$ on the unit square (it integrates to $\int_0^1 (x + \tfrac12)\,dx = 1$). The marginal is $p(x) = \int_0^1 (x + y)\,dy = x + \tfrac12$, and the conditional density is

$$p(y \mid x) = \frac{x + y}{x + 1/2}.$$

For $x = 1/2$ this is $p(y \mid x) = 1/2 + y$, so $P(Y < \tfrac12 \mid X = \tfrac12) = \int_0^{1/2} (\tfrac12 + y)\,dy = \tfrac14 + \tfrac18 = 0.375$. A conditional density is a legitimate density in $y$ for each fixed $x$: it integrates to 1.

### In code

```python
joint = {("spam", "yes"): 0.12, ("spam", "no"): 0.18,
         ("ham", "yes"): 0.08, ("ham", "no"): 0.62}

def marginal_w(joint, w):
    return sum(p for (s, w2), p in joint.items() if w2 == w)

pw = marginal_w(joint, "yes")
print(round(joint[("spam", "yes")] / pw, 3))
```

A joint distribution over $k$ binary variables has $2^k - 1$ free numbers, which is why models impose structure (independence, conditional independence) instead of storing the table.

@example
title: Marginals and conditionals from a table
problem: Two variables $X \in \{0, 1, 2\}$ and $Y \in \{0, 1\}$ have joint probabilities $P(0,0) = 0.10$, $P(0,1) = 0.20$, $P(1,0) = 0.15$, $P(1,1) = 0.15$, $P(2,0) = 0.30$, $P(2,1) = 0.10$. Find $P(Y = 0)$, $P(X = 2 \mid Y = 0)$ and $P(Y = 1 \mid X = 0)$, and decide whether $X$ and $Y$ are independent.
step: Check the table: the six numbers sum to $0.10 + 0.20 + 0.15 + 0.15 + 0.30 + 0.10 = 1$.
step: Marginal of $Y$: $P(Y = 0) = 0.10 + 0.15 + 0.30 = 0.55$.
step: Conditional: $P(X = 2 \mid Y = 0) = P(2, 0) / P(Y = 0) = 0.30 / 0.55 \approx 0.545$.
step: Conditional: $P(X = 0) = 0.10 + 0.20 = 0.30$, so $P(Y = 1 \mid X = 0) = 0.20 / 0.30 \approx 0.667$.
step: Independence test: $P(X = 0)\,P(Y = 0) = 0.30 \times 0.55 = 0.165$ but $P(0, 0) = 0.10$. One cell fails, so $X$ and $Y$ are dependent.
answer: $P(Y=0) = 0.55$, $P(X=2 \mid Y=0) \approx 0.545$, $P(Y=1 \mid X=0) \approx 0.667$; the variables are dependent.

@example
title: A conditional density on a triangle
problem: $(X, Y)$ has density $p(x, y) = 2$ on the triangle $0 < y < x < 1$ and 0 elsewhere. Find $p(x)$, $p(y \mid x)$ and $P(Y < 0.2 \mid X = 0.5)$, and compare with $P(Y < 0.2)$.
step: Marginal of $X$: for a fixed $x$, $y$ ranges over $(0, x)$, so $p(x) = \int_0^x 2\,dy = 2x$ for $0 < x < 1$.
step: Conditional: $p(y \mid x) = 2 / (2x) = 1/x$ on $(0, x)$, the uniform density on $(0, x)$.
step: With $x = 0.5$ the conditional is uniform on $(0, 0.5)$, so $P(Y < 0.2 \mid X = 0.5) = 0.2 / 0.5 = 0.4$.
step: Marginal of $Y$: $p(y) = \int_y^1 2\,dx = 2(1 - y)$, so $P(Y < 0.2) = \int_0^{0.2} 2(1 - y)\,dy = 0.4 - 0.04 = 0.36$. The two probabilities differ, so $X$ and $Y$ are dependent: knowing $X$ changes what we believe about $Y$.
answer: $P(Y < 0.2 \mid X = 0.5) = 0.4$, while $P(Y < 0.2) = 0.36$.

@mistakes
- Confusing $P(x \mid y)$ with $P(y \mid x)$: in the spam table $P(\text{spam} \mid \text{yes}) = 0.6$ but $P(\text{yes} \mid \text{spam}) = 0.4$. The denominators differ.
- Computing a conditional by dividing by the wrong total: the denominator is the marginal of the variable you condition on, not 1 and not the sum of the whole table.
- Declaring independence because the marginals "look fine": independence needs $P(x, y) = P(x)P(y)$ in every cell, and one mismatch is enough to refute it.
- Treating a density value as a probability: $p(x, y)$ can exceed 1; only integrals of densities are probabilities.

@practice num
prompt: The pair $(X, Y)$ has density $p(x, y) = \tfrac{2}{3}(x + 2y)$ on the unit square $0 \le x, y \le 1$ (and 0 elsewhere). What is $P(X < 0.5)$? Give three decimal places.
answer: 0.417
tol: 0.001
check: 2 / 3 * (0.5 ** 2 / 2 + 0.5)
hint: First find the marginal density $p(x) = \int_0^1 p(x, y)\,dy$, then integrate it from 0 to 0.5.
solution: $p(x) = \tfrac23\int_0^1 (x + 2y)\,dy = \tfrac23 (x + 1)$. Then $P(X < 0.5) = \tfrac23 \int_0^{0.5} (x + 1)\,dx = \tfrac23(0.125 + 0.5) = 5/12 \approx 0.417$.

@practice mc
prompt: Two binary variables satisfy $P(X = 1) = 0.5$, $P(Y = 1) = 0.4$ and $P(X = 1, Y = 1) = 0.2$. What can you conclude about the pair $(X = 1, Y = 1)$ cell?
choice*: It matches $P(X = 1)\,P(Y = 1)$, so this cell is consistent with independence, and $P(X = 1 \mid Y = 1) = 0.5$.
choice: $X$ and $Y$ are dependent, because $P(X = 1, Y = 1) = 0.2$ is smaller than $P(X = 1) = 0.5$.
choice: $X$ and $Y$ are dependent, because $P(X = 1 \mid Y = 1) = 0.5$ differs from $P(Y = 1) = 0.4$.
choice: $X$ and $Y$ must be identical, because the conditional probability equals the marginal probability of $X$.
hint: Compare the joint entry with the product of the marginals, and compute the conditional by dividing by $P(Y = 1)$.
solution: $P(X = 1)\,P(Y = 1) = 0.5 \times 0.4 = 0.2$, equal to the joint entry, and $P(X = 1 \mid Y = 1) = 0.2/0.4 = 0.5 = P(X = 1)$. A single matching cell does not prove independence of the whole table, but it is consistent with it. The conditional of $X$ is compared with the marginal of $X$, not of $Y$, and equal probabilities do not make variables identical.

@practice ms
prompt: For any joint distribution of discrete variables $X$ and $Y$ with all probabilities positive, which of these identities hold? Select all that apply.
choice*: $P(x, y) = P(x)\,P(y \mid x)$
choice*: $\sum_{x} P(x \mid y) = 1$ for each $y$
choice*: $P(x) = \sum_{y} P(x \mid y)\,P(y)$
choice: $P(x \mid y) = P(y \mid x)$
choice: $P(x) = \sum_{y} P(x \mid y)$
hint: Each true identity follows from the product rule and the sum rule; check the false ones with a two-by-two table.
solution: The product rule gives the first identity, a conditional distribution is normalized over its own variable, and the third is the sum rule applied to $P(x, y) = P(x \mid y) P(y)$. Conditionals are not symmetric (Bayes' rule needs the ratio of marginals), and summing conditionals without weighting by $P(y)$ gives a number that can exceed 1.

@quiz num
prompt: $(X, Y)$ has density $p(x, y) = \tfrac32 (x^2 + y^2)$ on the unit square. Find $P(Y < 0.5 \mid X = 1)$. Give three decimal places.
answer: 0.406
tol: 0.001
check: (3 / 4) * (0.5 + 0.5 ** 3 / 3)
hint: The conditional density is $p(1, y) / p(1)$ with $p(1) = \int_0^1 p(1, y)\,dy$.
solution: $p(1, y) = \tfrac32 (1 + y^2)$ and $p(1) = \tfrac32 (1 + \tfrac13) = 2$, so $p(y \mid x = 1) = \tfrac34 (1 + y^2)$. Integrating from 0 to 0.5 gives $\tfrac34 (0.5 + 0.125/3) = 0.40625 \approx 0.406$.

@quiz self
prompt: Let $X$ and $Y$ be discrete with $P(y) > 0$ for every $y$. Prove that $X$ and $Y$ are independent (that is, $P(x, y) = P(x)P(y)$ for all $x, y$) if and only if $P(x \mid y) = P(x)$ for all $x$ and $y$.
hint: Use the definition $P(x \mid y) = P(x, y)/P(y)$ in each direction.
solution: Suppose $P(x, y) = P(x)P(y)$ for all $x, y$. Then $P(x \mid y) = P(x, y)/P(y) = P(x)P(y)/P(y) = P(x)$. Conversely, suppose $P(x \mid y) = P(x)$ for all $x, y$. By the definition of the conditional, $P(x, y) = P(x \mid y)P(y) = P(x)P(y)$. Both directions use only the definition of conditional probability and the assumption $P(y) > 0$, which is needed so that the conditional exists.
rubric: Uses the definition of the conditional probability in the forward direction to cancel $P(y)$.
rubric: Uses the product rule in the reverse direction.
rubric: Notes where $P(y) > 0$ is needed.

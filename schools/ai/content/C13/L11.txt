@article
A classifier gets 164 of 200 test examples right, an accuracy of $0.82$. A second test set of 200 fresh examples would not give exactly $0.82$ again. How much would it vary, and when we write "82%", how many of those digits mean anything?

### The sampling distribution of a metric

If each test example is an independent draw from the population the model will face, the number correct is $\text{Binomial}(n, a)$ with $a$ the true accuracy of the (fixed, already trained) model. The estimate $\hat a = k/n$ has standard error

$$\operatorname{SE}(\hat a) = \sqrt{\frac{a(1-a)}{n}} \approx \sqrt{\frac{\hat a(1 - \hat a)}{n}}.$$

Here $\sqrt{0.82 \times 0.18/200} \approx 0.0272$. A **normal-approximation 95% confidence interval** is $\hat a \pm 1.96\operatorname{SE}$, here $0.82 \pm 0.053 = [0.767, 0.873]$. It rests on the central limit theorem, so it is poor when $n$ is small or $\hat a$ is near 0 or 1. Most test sets leave more uncertainty than people expect: with $n = 200$ the plausible range spans more than 10 points of accuracy.

### What a confidence interval means

A 95% confidence interval is produced by a procedure that, over repeated samples, covers the true value in about 95% of repetitions. For one computed interval, the true value is either inside or not. Do not read it as "the probability that the true accuracy lies in $[0.767, 0.873]$ is 95%" (that is a credible interval and needs a prior, Lesson 5).

### The bootstrap

For many metrics (F1, AUC, a mean loss, a difference of two models) there is no simple formula for the standard error. The **bootstrap** (Efron, 1979) replaces the unknown population by the observed sample and simulates repeated sampling from it:

1. Given the $n$ test examples (each with its per-example outcome), draw $n$ examples **with replacement**: a bootstrap sample.
2. Recompute the metric on the bootstrap sample.
3. Repeat $B$ times (commonly $B = 1000$ to $10{,}000$), giving $\hat\theta^\ast_1, \dots, \hat\theta^\ast_B$.

The standard deviation of these replicates is the **bootstrap standard error**. The **percentile interval** takes the 2.5th and 97.5th percentiles of the replicates as a 95% interval: sort them and read the values at ranks $0.025B$ and $0.975B$.

Because sampling is with replacement, each bootstrap sample contains about $1 - (1 - 1/n)^n \to 1 - 1/e \approx 63.2\%$ of the distinct examples, and some appear twice or more. For accuracy, the per-example outcome is 0 or 1, so a bootstrap sample is just $n$ draws from the list of 0s and 1s, and the bootstrap interval for 164 correct out of 200 is close to the normal interval above.

### Conditions and limits

The bootstrap assumes the examples are **independent and identically distributed** draws from the target population. It fails or needs modification when:

- examples are clustered or correlated (many images from one patient, many sentences from one document): resample whole clusters instead of single examples;
- the statistic depends on extremes (the maximum, a very high quantile), for which the bootstrap is inconsistent;
- the sample is very small, where percentile intervals tend to be too narrow (refinements such as bias-corrected intervals exist).

Equally important is what it does not cover. The interval above captures **test-set sampling variability for one fixed trained model**. It does not capture variability from random initialization or training-data selection (you need several training runs or a resampled training set), or from a shift between the test and deployment populations. Say which source of variation your interval reflects.

### Comparing two models on the same test set

To compare models $A$ and $B$ evaluated on the same examples, bootstrap the **paired** difference: in each replicate, draw one set of example indices and compute the metric for both models on those same examples, then take the difference. Resampling the pairs together preserves the correlation between the models' errors, which is why paired intervals for a difference are typically much narrower than combining two separate intervals. If the interval excludes 0 the data are inconsistent with equal performance at that level; the next lesson adds formal tests.

### In code

```python
import random

def bootstrap_means(values, B, seed):
    rng = random.Random(seed)
    n = len(values)
    means = []
    for _ in range(B):
        sample = [values[rng.randrange(n)] for _ in range(n)]
        means.append(sum(sample) / n)
    return sorted(means)

correct = [1] * 164 + [0] * 36
means = bootstrap_means(correct, 1000, 0)
print(means[25], means[975])
```

The two printed values are the percentile interval endpoints, near $0.77$ and $0.87$; they change a little with the seed, which is itself Monte Carlo error that shrinks as $B$ grows.

@mistakes
- Resampling without replacement: that returns the original sample every time and gives zero variability; the bootstrap draws with replacement.
- Bootstrapping the two models' scores separately when they were evaluated on the same examples: use the same resampled indices for both (paired), which preserves the correlation of their errors.
- Treating the interval as covering all sources of uncertainty: it reflects the sampling of test examples, not retraining randomness or distribution shift.
- Ignoring dependence between examples: resample clusters (patients, documents, sessions), not individual rows.

model:
```python
import random

def bootstrap_ci(correct, B, seed):
    """95% percentile bootstrap interval for the mean of 0/1 outcomes."""
    rng = random.Random(seed)
    n = len(correct)
    means = []
    for _ in range(B):
        sample = [correct[rng.randrange(n)] for _ in range(n)]
        means.append(sum(sample) / n)
    means.sort()
    return means[int(0.025 * B)], means[int(0.975 * B)]
```
hint: Build a list of replicate means, sort it, and index it at `int(0.025 * B)` and `int(0.975 * B)`.
solution: Each replicate resamples the outcomes with replacement and averages them; the percentile interval reads off the sorted means. The all-correct and all-wrong tests check that a constant sample gives a zero-width interval, and the last tests check reproducibility and that different seeds give different resamples.

@quiz self
prompt: You have two classifiers, $A$ and $B$, evaluated on the same 1000 test examples, and you want an interval for the difference in accuracy. Describe a paired bootstrap procedure, say what you would report, and explain why it can be much narrower than combining two separate intervals.
hint: Think about the per-example correctness vectors and how many examples both models get right or wrong together.
solution: Record for each test example whether $A$ and $B$ are correct. In each of $B_0 = 10{,}000$ replicates, draw 1000 indices with replacement, compute the accuracy of $A$ and of $B$ on those same indices, and store the difference. Sort the differences and report the observed difference with the 2.5th and 97.5th percentiles, noting that the interval reflects test-set sampling for these two fixed models. Examples that both models get right (or both wrong) contribute identically to both accuracies in every replicate, so they cancel in the difference; only the examples where the models disagree create variability. Two separate intervals ignore this positive correlation between the models' errors and add their variances, so the combined interval is wider than the paired one when the errors are correlated.

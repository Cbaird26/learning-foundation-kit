@article
Two features of an email, $X$ (whether it contains "free") and $Y$ (whether it contains "winner"), take values 0 or 1 with joint probabilities $P(0,0) = 0.3$, $P(0,1) = 0.1$, $P(1,0) = 0.1$, $P(1,1) = 0.5$. Do they move together, and by how much? Covariance answers this.

### Expectation and variance

The **expectation** of a function of a random variable is $\mathbb{E}[g(X)] = \sum_x g(x) P(x)$ (or $\int g(x) p(x)\,dx$). It is **linear**: $\mathbb{E}[aX + bY + c] = a\,\mathbb{E}[X] + b\,\mathbb{E}[Y] + c$ for any random variables, independent or not. The **variance** is $\operatorname{Var}(X) = \mathbb{E}[(X - \mathbb{E}X)^2] = \mathbb{E}[X^2] - (\mathbb{E}X)^2$.

For the email features, $\mathbb{E}[X] = P(X = 1) = 0.6$ and $\mathbb{E}[Y] = 0.6$, so each has variance $0.6 \times 0.4 = 0.24$.

### Covariance and correlation

The **covariance** measures linear co-movement:

$$\operatorname{Cov}(X, Y) = \mathbb{E}[(X - \mathbb{E}X)(Y - \mathbb{E}Y)] = \mathbb{E}[XY] - \mathbb{E}[X]\,\mathbb{E}[Y].$$

Here $\mathbb{E}[XY] = P(1, 1) = 0.5$, so $\operatorname{Cov}(X, Y) = 0.5 - 0.36 = 0.14$. Covariance has the units of $X$ times those of $Y$, so we rescale it into the **correlation**

$$\rho = \frac{\operatorname{Cov}(X, Y)}{\sqrt{\operatorname{Var}(X)\operatorname{Var}(Y)}} \in [-1, 1], \qquad \text{here } \rho = \frac{0.14}{0.24} \approx 0.583.$$

The bound $|\rho| \le 1$ is the Cauchy–Schwarz inequality. The variance of a weighted sum includes the covariance:

$$\operatorname{Var}(aX + bY) = a^2 \operatorname{Var}(X) + b^2 \operatorname{Var}(Y) + 2ab \operatorname{Cov}(X, Y).$$

If $X$ and $Y$ are independent then $\mathbb{E}[XY] = \mathbb{E}X\,\mathbb{E}Y$, so the covariance is 0 and variances simply add. The converse fails: let $X$ be uniform on $\{-1, 0, 1\}$ and $Y = X^2$. Then $Y$ is a function of $X$, yet $\operatorname{Cov}(X, Y) = \mathbb{E}[X^3] - \mathbb{E}[X]\mathbb{E}[X^2] = 0$. **Uncorrelated does not imply independent**; covariance sees only linear relationships.

### Random vectors

For a random vector $\mathbf{x} \in \mathbb{R}^d$ the mean is $\boldsymbol{\mu} = \mathbb{E}[\mathbf{x}]$ and the **covariance matrix** is $\boldsymbol{\Sigma} = \mathbb{E}[(\mathbf{x} - \boldsymbol{\mu})(\mathbf{x} - \boldsymbol{\mu})^\top]$, with entries $\Sigma_{ij} = \operatorname{Cov}(x_i, x_j)$. It is symmetric and positive semidefinite, since $\mathbf{v}^\top \boldsymbol{\Sigma} \mathbf{v} = \operatorname{Var}(\mathbf{v}^\top \mathbf{x}) \ge 0$. For a linear map, $\mathbb{E}[\mathbf{A}\mathbf{x}] = \mathbf{A}\boldsymbol{\mu}$ and $\operatorname{Cov}(\mathbf{A}\mathbf{x}) = \mathbf{A}\boldsymbol{\Sigma}\mathbf{A}^\top$.

### The multivariate Gaussian

For symmetric positive definite $\boldsymbol{\Sigma}$, the density of $\mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ on $\mathbb{R}^d$ is

$$p(\mathbf{x}) = \frac{1}{(2\pi)^{d/2} |\boldsymbol{\Sigma}|^{1/2}} \exp\!\Big(-\tfrac12 (\mathbf{x} - \boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})\Big).$$

Its level sets are ellipsoids centered at $\boldsymbol{\mu}$ whose axes are the eigenvectors of $\boldsymbol{\Sigma}$. Three facts make it the workhorse of machine learning. Split $\mathbf{x} = (\mathbf{x}_a, \mathbf{x}_b)$ with the matching blocks of $\boldsymbol{\mu}$ and $\boldsymbol{\Sigma}$. Then:

1. **Marginals** are Gaussian: $\mathbf{x}_a \sim \mathcal{N}(\boldsymbol{\mu}_a, \boldsymbol{\Sigma}_{aa})$. Just read off the sub-blocks.
2. **Conditionals** are Gaussian: $\mathbf{x}_a \mid \mathbf{x}_b \sim \mathcal{N}\big(\boldsymbol{\mu}_a + \boldsymbol{\Sigma}_{ab}\boldsymbol{\Sigma}_{bb}^{-1}(\mathbf{x}_b - \boldsymbol{\mu}_b),\ \boldsymbol{\Sigma}_{aa} - \boldsymbol{\Sigma}_{ab}\boldsymbol{\Sigma}_{bb}^{-1}\boldsymbol{\Sigma}_{ba}\big)$.
3. **Linear maps** keep it Gaussian: $\mathbf{A}\mathbf{x} \sim \mathcal{N}(\mathbf{A}\boldsymbol{\mu}, \mathbf{A}\boldsymbol{\Sigma}\mathbf{A}^\top)$.

In two dimensions the conditional is easy to read. Let $\boldsymbol{\mu} = (1, 2)$ and $\boldsymbol{\Sigma} = \begin{pmatrix} 4 & 2 \\ 2 & 3 \end{pmatrix}$. The marginal of $x_1$ is $\mathcal{N}(1, 4)$. Conditioning on $x_2 = 3$ gives mean $1 + \tfrac{2}{3}(3 - 2) = 5/3$ and variance $4 - \tfrac{2^2}{3} = 8/3$. The conditional variance (8/3) is smaller than the marginal variance (4) and does not depend on the observed $x_2$: observing a correlated variable removes uncertainty. For **jointly Gaussian** variables (though not for general ones), zero covariance does imply independence, because with $\boldsymbol{\Sigma}_{ab} = \mathbf{0}$ the density factorizes.

### In code

```python
def sample_cov(xs, ys):
    n = len(xs)
    mx, my = sum(xs) / n, sum(ys) / n
    return sum((x - mx) * (y - my) for x, y in zip(xs, ys)) / (n - 1)

print(sample_cov([1, 2, 3, 4], [1, 3, 2, 5]))
```

Dividing by $n - 1$ makes this estimate unbiased for the true covariance; NumPy's `np.cov` does the same by default.

@example
title: Covariance from a joint table
problem: $X$ and $Y$ are binary with $P(0,0) = 0.4$, $P(0,1) = 0.1$, $P(1,0) = 0.2$, $P(1,1) = 0.3$. Find $\operatorname{Cov}(X, Y)$, the correlation, and $\operatorname{Var}(X - Y)$.
step: Marginal means: $\mathbb{E}[X] = P(X = 1) = 0.2 + 0.3 = 0.5$ and $\mathbb{E}[Y] = P(Y = 1) = 0.1 + 0.3 = 0.4$.
step: Mixed moment: $\mathbb{E}[XY] = P(1, 1) = 0.3$, so $\operatorname{Cov}(X, Y) = 0.3 - 0.5 \times 0.4 = 0.1$.
step: Variances of binary variables are $p(1 - p)$: $\operatorname{Var}(X) = 0.25$ and $\operatorname{Var}(Y) = 0.24$. The correlation is $0.1/\sqrt{0.25 \times 0.24} = 0.1/\sqrt{0.06} \approx 0.408$.
step: Variance of a difference ($a = 1$, $b = -1$): $\operatorname{Var}(X - Y) = 0.25 + 0.24 - 2(0.1) = 0.29$.
answer: $\operatorname{Cov} = 0.1$, $\rho \approx 0.408$, $\operatorname{Var}(X - Y) = 0.29$.

@example
title: Conditioning a two-dimensional Gaussian
problem: $(x_1, x_2) \sim \mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})$ with $\boldsymbol{\mu} = (0, 1)$ and $\boldsymbol{\Sigma} = \begin{pmatrix} 2 & -1 \\ -1 & 1 \end{pmatrix}$. Find the marginal of $x_2$ and the distribution of $x_1$ given $x_2 = 2$.
step: Marginal: read off the second entries: $x_2 \sim \mathcal{N}(1, 1)$.
step: Regression coefficient: $\Sigma_{12}/\Sigma_{22} = -1/1 = -1$.
step: Conditional mean: $\mu_1 + (\Sigma_{12}/\Sigma_{22})(x_2 - \mu_2) = 0 + (-1)(2 - 1) = -1$.
step: Conditional variance: $\Sigma_{11} - \Sigma_{12}^2/\Sigma_{22} = 2 - 1/1 = 1$.
answer: $x_2 \sim \mathcal{N}(1, 1)$ and $x_1 \mid x_2 = 2 \sim \mathcal{N}(-1, 1)$.

@mistakes
- Using the wrong sign of the covariance term: $\operatorname{Var}(X - Y) = \operatorname{Var}X + \operatorname{Var}Y - 2\operatorname{Cov}(X, Y)$, not plus.
- Concluding independence from zero correlation: this is guaranteed for jointly Gaussian variables but fails in general (the pair $X$ and $X^2$ with $X$ symmetric about 0 is uncorrelated but dependent).
- Using the standard deviation where the variance belongs: $\mathcal{N}(\mu, \sigma^2)$ and the entries of $\boldsymbol{\Sigma}$ are variances, so square the standard deviations.
- Forgetting that the conditional variance of a Gaussian does not depend on the observed value, while the conditional mean does.

```python
def corr(xs, ys):
    """Sample correlation coefficient of two equal-length lists."""
    n = len(xs)
    mx, my = sum(xs) / n, sum(ys) / n
    sxy = sum((x - mx) * (y - my) for x, y in zip(xs, ys))
    sxx = sum((x - mx) ** 2 for x in xs)
    syy = sum((y - my) ** 2 for y in ys)
    return sxy / (sxx * syy) ** 0.5
```
hint: Compute the two means, then the sums of centered products and squares; the divisors cancel in the ratio.
solution: Center both lists, accumulate $\sum (x - \bar x)(y - \bar y)$, $\sum (x - \bar x)^2$ and $\sum (y - \bar y)^2$, and divide the first by the square root of the product of the other two. The perfectly negative test catches a solution that returns the absolute value.

@quiz self
prompt: Derive the formula $\operatorname{Var}(aX + bY) = a^2\operatorname{Var}(X) + b^2\operatorname{Var}(Y) + 2ab\operatorname{Cov}(X, Y)$ from the definitions of variance and covariance, and say what it reduces to when $X$ and $Y$ are independent.
hint: Write $\operatorname{Var}(Z) = \mathbb{E}[(Z - \mathbb{E}Z)^2]$ with $Z = aX + bY$ and expand the square after using linearity of expectation.
solution: Let $Z = aX + bY$. By linearity, $\mathbb{E}Z = a\mathbb{E}X + b\mathbb{E}Y$, so $Z - \mathbb{E}Z = a(X - \mathbb{E}X) + b(Y - \mathbb{E}Y)$. Squaring gives $a^2(X - \mathbb{E}X)^2 + b^2(Y - \mathbb{E}Y)^2 + 2ab(X - \mathbb{E}X)(Y - \mathbb{E}Y)$. Taking expectations term by term gives $a^2\operatorname{Var}X + b^2\operatorname{Var}Y + 2ab\operatorname{Cov}(X, Y)$. If $X$ and $Y$ are independent the covariance is 0, so the variance is $a^2\operatorname{Var}X + b^2\operatorname{Var}Y$.
rubric: Centers the variables and uses linearity of expectation to get the centered form of $Z$.
rubric: Expands the square and takes expectations of each of the three terms.
rubric: States that independence makes the covariance 0 and the cross term vanish.

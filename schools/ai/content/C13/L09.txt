@article
Two weather forecasters report the chance of rain. One says 50% every day; the other says 95% on days when it will rain and 5% otherwise, and is usually right. We would say the second forecaster's messages carry more information about the weather, and the first carries less than it seems. **Information theory** makes "how surprising" precise and gives machine learning its most common loss.

### Information and entropy

The **information content** (surprisal) of an outcome with probability $p$ is $\log\frac1p = -\log p$: rare outcomes are more surprising. The **entropy** of a discrete distribution $p$ over $K$ outcomes is the expected surprisal:

$$H(p) = -\sum_{k=1}^{K} p_k\log p_k, \qquad \text{with the convention } 0\log 0 = 0.$$

With $\log_2$ the unit is the **bit**; with the natural log it is the **nat** (1 nat $= 1/\ln 2 \approx 1.443$ bits). A fair coin has entropy $1$ bit. A biased coin with $p = (0.9, 0.1)$ has $H = 0.9\log_2\frac{1}{0.9} + 0.1\log_2\frac1{0.1} \approx 0.469$ bits: its outcomes are more predictable.

Basic properties: $H(p) \ge 0$, with equality exactly when one outcome has probability 1; and $H(p) \le \log K$, with equality exactly for the uniform distribution (you prove this in the quiz). Uniform over 8 outcomes has 3 bits.

### Entropy as code length

**Shannon's source coding theorem** says that the shortest average length of a lossless binary code for a source, in bits per symbol, is between $H(p)$ and $H(p) + 1$ for a symbol-by-symbol prefix code (and approaches $H(p)$ when symbols are coded in long blocks). For $p = (0.5, 0.25, 0.25)$ the code $0, 10, 11$ has average length $0.5(1) + 0.25(2) + 0.25(2) = 1.5$ bits, equal to $H(p) = 0.5 + 0.5 + 0.5 = 1.5$. In general an outcome of probability $p_k$ deserves a codeword of about $\log_2(1/p_k)$ bits.

### Cross-entropy

Suppose data come from $p$ but we use a code (or a model) built for a different distribution $q$. The **cross-entropy** is the average code length we then pay:

$$H(p, q) = -\sum_k p_k\log q_k.$$

When $q = p$ it equals the entropy. It is not symmetric, and it is infinite if $q_k = 0$ for some $k$ with $p_k > 0$ (the model declares a possible outcome impossible). For $p = (0.9, 0.1)$ and a model $q = (0.6, 0.4)$,
$$H(p, q) = 0.9\log_2\tfrac1{0.6} + 0.1\log_2\tfrac1{0.4} \approx 0.663 + 0.132 = 0.795 \text{ bits},$$
above the entropy $0.469$; a uniform model $q = (0.5, 0.5)$ costs exactly 1 bit. The next lesson shows that $H(p, q) \ge H(p)$ always, with equality only if $q = p$.

### Cross-entropy as a loss

In classification with $K$ classes, the true label $y$ is encoded by the one-hot distribution $p_k = \mathbf{1}\{k = y\}$, and the model outputs probabilities $q_k = \hat y_k$ (for example from softmax). Then

$$H(p, q) = -\sum_k p_k\log q_k = -\log\hat y_y,$$

the negative log-probability the model gave to the correct class. Averaged over a data set this is $-\frac1n\sum_i\log\hat y_{i, y_i}$, the **negative log-likelihood** per example, so minimizing cross-entropy is maximum likelihood (Lesson 3). A model that gives the correct class probability $0.2$ pays $-\ln 0.2 \approx 1.609$ nats; at probability $0.9$ it pays $0.105$; at $0.01$ it pays $4.6$. The loss is unbounded for confident wrong answers, which is one reason practitioners use techniques such as label smoothing.

### Perplexity

For a language model that assigns probabilities to the true next tokens, the average cross-entropy per token is $\bar H = -\frac1T\sum_t\log q(\text{token}_t \mid \text{context})$, and the **perplexity** is $\exp(\bar H)$ for $\bar H$ in nats, or equivalently $2^{\bar H}$ for $\bar H$ in bits. It can be read as the size of a uniform distribution that would be as hard to predict: a perplexity of 4 means the model is as uncertain as if choosing among 4 equally likely tokens at each step. Perplexity depends on the tokenization and the data, so values are comparable only under the same setup.

### Continuous variables

For a density $p(x)$ the **differential entropy** is $h(p) = -\int p(x)\log p(x)\,dx$. For $\mathcal{N}(\mu, \sigma^2)$ it equals $\tfrac12\ln(2\pi e\sigma^2)$ nats. Unlike the discrete case it can be negative (a narrow density, $\sigma^2 < 1/(2\pi e)$) and it changes if $x$ is rescaled, so only differences such as the divergences of the next lesson are scale-free.

### In code

```python
import math

def entropy(p, base=2.0):
    return -sum(x * math.log(x, base) for x in p if x > 0)

print(round(entropy([0.9, 0.1]), 4))
print(round(entropy([0.25] * 4), 4))
```

The program prints `0.469` and `2.0`: the biased coin is cheaper to describe than a fair one, and four equally likely outcomes need exactly 2 bits.

@example
title: Entropy of a three-outcome distribution
problem: A model predicts the class $p = (0.7, 0.2, 0.1)$. Compute its entropy in bits and compare it with the maximum possible for three outcomes.
step: Surprisals in bits: $\log_2(1/0.7) \approx 0.515$, $\log_2(1/0.2) \approx 2.322$, $\log_2(1/0.1) \approx 3.322$.
step: Weighted by probabilities: $0.7(0.515) = 0.360$, $0.2(2.322) = 0.464$, $0.1(3.322) = 0.332$.
step: Add: $H \approx 0.360 + 0.464 + 0.332 = 1.157$ bits.
step: The maximum for three outcomes is $\log_2 3 \approx 1.585$ bits, for the uniform distribution; the skewed $p$ is about $73\%$ of it.
answer: $H \approx 1.157$ bits, below the maximum $\log_2 3 \approx 1.585$.

@example
title: Cross-entropy and perplexity of a language model
problem: A language model gives the true next tokens of a short text the probabilities $0.5$, $0.25$ and $0.125$. Compute the average cross-entropy in bits and nats, and the perplexity.
step: The per-token costs in bits are $-\log_2 0.5 = 1$, $-\log_2 0.25 = 2$ and $-\log_2 0.125 = 3$.
step: The average cross-entropy is $(1 + 2 + 3)/3 = 2$ bits per token.
step: In nats this is $2\ln 2 \approx 1.386$ nats per token, since 1 bit $= \ln 2$ nats.
step: Perplexity: $2^{2} = 4$, and also $\exp(1.386) = 4$.
answer: $2$ bits ($1.386$ nats) per token, perplexity $4$.

@mistakes
- Mixing units: entropy in bits uses $\log_2$ and in nats uses $\ln$; a classification loss in a library is almost always in nats.
- Treating $H(p, q)$ as symmetric: $H(p, q) \ne H(q, p)$ in general, and the data distribution $p$ always goes first (it supplies the weights).
- Forgetting $0\log 0 = 0$: terms with $p_k = 0$ contribute nothing, even when $q_k = 0$; but $p_k > 0$ with $q_k = 0$ gives infinity.
- Reading perplexity as a probability or comparing perplexities across different tokenizations: it is an effective number of choices per token.

model:
```python
import math

def cross_entropy(p, q):
    """Cross-entropy -sum p_k ln q_k in nats, with 0 ln 0 = 0."""
    total = 0.0
    for pk, qk in zip(p, q):
        if pk == 0:
            continue
        if qk == 0:
            return math.inf
        total -= pk * math.log(qk)
    return total
```
hint: Loop over pairs, skip those with $p_k = 0$, and return infinity if $q_k = 0$ where $p_k > 0$.
solution: Each pair with $p_k > 0$ contributes $-p_k\ln q_k$, and an impossible-but-observed outcome makes the cross-entropy infinite. The test with $p = (0, 1)$ and $q = (0, 1)$ checks the $0 \log 0$ convention, which a naive `math.log(0)` would crash on.

@quiz self
prompt: Prove that $H(p) \le \log K$ for every distribution $p$ on $K$ outcomes, with equality for the uniform distribution. State the property of the logarithm that you use.
hint: Write $H(p) = \sum_{k: p_k > 0} p_k\log\frac{1}{p_k}$ and apply Jensen's inequality for the concave function $\log$.
solution: Let $S = \{k : p_k > 0\}$, with $|S| \le K$. Then $H(p) = \sum_{k \in S}p_k\log\frac1{p_k}$ is an expectation of $\log(1/p_k)$ under the distribution $p$ on $S$. The logarithm is concave, so Jensen's inequality gives $\mathbb{E}[\log X] \le \log\mathbb{E}[X]$, and here $\mathbb{E}[1/p_k] = \sum_{k \in S}p_k\cdot\frac1{p_k} = |S|$. Hence $H(p) \le \log|S| \le \log K$. For the uniform distribution $p_k = 1/K$ every surprisal is $\log K$, so $H(p) = \log K$ and the bound is attained.

@article
Last lesson ended with a fact we have not proved: the cross-entropy $H(p, q)$ is never below the entropy $H(p)$. The gap between them has a name and is one of the most important quantities in machine learning.

### KL divergence

The **Kullback–Leibler divergence** from $q$ to $p$ is

$$D_{\mathrm{KL}}(p \,\Vert\, q) = \sum_k p_k\log\frac{p_k}{q_k} = H(p, q) - H(p),$$

with $0\log\frac0q = 0$ and the value $+\infty$ if $q_k = 0$ for some $p_k > 0$. (For densities the sum is an integral.) It is the extra code length, in bits or nats per symbol, paid for coding $p$-distributed data with a code built for $q$.

**Gibbs' inequality: $D_{\mathrm{KL}}(p \,\Vert\, q) \ge 0$, with equality if and only if $p = q$.** Proof: let $S = \{k : p_k > 0\}$. By Jensen's inequality for the concave logarithm,
$$-D_{\mathrm{KL}}(p \,\Vert\, q) = \sum_{k \in S}p_k\log\frac{q_k}{p_k} \le \log\sum_{k \in S}p_k\frac{q_k}{p_k} = \log\sum_{k \in S}q_k \le \log 1 = 0.$$
Equality in Jensen's inequality (the log is strictly concave) needs $q_k/p_k$ constant on $S$, and equality in the last step needs $\sum_{k \in S}q_k = 1$; together these force $q = p$.

The divergence is **not symmetric** and not a distance. For $p = (0.5, 0.5)$ and $q = (0.9, 0.1)$, in nats,
$$D_{\mathrm{KL}}(p \,\Vert\, q) = 0.5\ln\tfrac{0.5}{0.9} + 0.5\ln\tfrac{0.5}{0.1} \approx 0.511, \qquad D_{\mathrm{KL}}(q \,\Vert\, p) = 0.9\ln\tfrac{0.9}{0.5} + 0.1\ln\tfrac{0.1}{0.5} \approx 0.368.$$
The direction matters in practice. Minimizing the **forward** divergence $D_{\mathrm{KL}}(p \,\Vert\, q)$ over $q$ forces $q$ to put mass wherever $p$ does (otherwise the divergence is huge), so $q$ is mass-covering. Minimizing the **reverse** divergence $D_{\mathrm{KL}}(q \,\Vert\, p)$, as variational inference does, lets $q$ ignore regions of $p$ and tends to lock onto one mode.

For two univariate Gaussians,
$$D_{\mathrm{KL}}\big(\mathcal{N}(\mu_1, \sigma_1^2)\,\Vert\,\mathcal{N}(\mu_2, \sigma_2^2)\big) = \ln\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1 - \mu_2)^2}{2\sigma_2^2} - \frac12.$$

### Maximum likelihood is KL minimization

Let $\hat p$ be the **empirical distribution** of the data, putting mass $1/n$ on each observed example. For a model $q_\theta$,
$$D_{\mathrm{KL}}(\hat p \,\Vert\, q_\theta) = -H(\hat p) - \frac1n\sum_i\log q_\theta(x_i).$$
The entropy $H(\hat p)$ does not involve $\theta$, so minimizing the KL divergence from the data to the model is the same as maximizing the average log-likelihood. Training with cross-entropy loss is therefore maximum likelihood, and it drives $q_\theta$ toward the data distribution in the sense of forward KL. The same fact explains why $H(p, q) = H(p) + D_{\mathrm{KL}}(p \,\Vert\, q)$ is minimized, over $q$, exactly at $q = p$.

### Conditional entropy and mutual information

The **conditional entropy** is the average remaining uncertainty about $Y$ once $X$ is known: $H(Y \mid X) = \sum_x p(x)H(Y \mid X = x)$. The chain rule is $H(X, Y) = H(X) + H(Y \mid X)$. The **mutual information** is

$$I(X; Y) = D_{\mathrm{KL}}\big(p(x, y)\,\Vert\,p(x)p(y)\big) = H(X) - H(X \mid Y) = H(X) + H(Y) - H(X, Y).$$

By Gibbs' inequality $I(X; Y) \ge 0$, with equality if and only if $X$ and $Y$ are independent. It is symmetric and measures how many nats or bits of information one variable carries about the other. It is zero for independent variables, but unlike correlation it also detects nonlinear dependence ($X$ uniform on $\{-1, 0, 1\}$ and $Y = X^2$ have zero covariance and positive mutual information).

Take the table $P(0,0) = 0.3$, $P(0,1) = 0.1$, $P(1,0) = 0.1$, $P(1,1) = 0.5$. Both marginals are $(0.4, 0.6)$, and
$$I = 0.3\ln\tfrac{0.3}{0.16} + 2(0.1)\ln\tfrac{0.1}{0.24} + 0.5\ln\tfrac{0.5}{0.36} \approx 0.1777 \text{ nats} \approx 0.256 \text{ bits}.$$
For a bivariate Gaussian with correlation $\rho$, $I(X; Y) = -\tfrac12\ln(1 - \rho^2)$ nats: $\rho = 0.8$ gives $0.511$ nats.

The **data-processing inequality** says that if $X \to Y \to Z$ is a Markov chain (so $Z$ depends on $X$ only through $Y$), then $I(X; Z) \le I(X; Y)$: processing cannot create information about $X$. Mutual information is used for feature selection, in representation learning objectives, and to analyze what a layer of a network retains.

### In code

```python
import math

def kl(p, q):
    return sum(a * math.log(a / b) for a, b in zip(p, q) if a > 0)

print(round(kl([0.5, 0.5], [0.9, 0.1]), 3))
print(round(kl([0.9, 0.1], [0.5, 0.5]), 3))
```

The program prints `0.511` and `0.368`, the two directions computed above.

title: KL divergence between Gaussians, in both directions
problem: Let $p = \mathcal{N}(0, 1)$ and $q = \mathcal{N}(0, 4)$ (variance 4). Compute $D_{\mathrm{KL}}(p \,\Vert\, q)$ and $D_{\mathrm{KL}}(q \,\Vert\, p)$.
step: Forward: $\sigma_1 = 1$, $\sigma_2 = 2$, $\mu_1 = \mu_2$. $D = \ln 2 + \frac{1 + 0}{2 \cdot 4} - \frac12 = 0.6931 + 0.125 - 0.5 = 0.3181$ nats.
step: Reverse: $\sigma_1 = 2$, $\sigma_2 = 1$. $D = \ln\frac12 + \frac{4 + 0}{2 \cdot 1} - \frac12 = -0.6931 + 2 - 0.5 = 0.8069$ nats.
step: The reverse divergence is larger: $p$ puts little mass where the wide $q$ has most of its tails, which costs much more than the other way around.
answer: $D_{\mathrm{KL}}(p \,\Vert\, q) \approx 0.318$ nats and $D_{\mathrm{KL}}(q \,\Vert\, p) \approx 0.807$ nats.

@example
title: Mutual information from a joint table
problem: Two binary variables have $P(0,0) = P(1,1) = 0.4$ and $P(0,1) = P(1,0) = 0.1$. Compute $I(X; Y)$ in nats and in bits.
step: Both marginals are uniform, $(0.5, 0.5)$, so each product $p(x)p(y) = 0.25$.
step: Matching cells ($0.4$ each, two of them): $2 \times 0.4\ln\frac{0.4}{0.25} = 0.8\ln 1.6 = 0.8(0.4700) = 0.3760$.
step: Mismatched cells ($0.1$ each, two of them): $2 \times 0.1\ln\frac{0.1}{0.25} = 0.2\ln 0.4 = 0.2(-0.9163) = -0.1833$.
step: Total: $I = 0.3760 - 0.1833 = 0.1927$ nats; dividing by $\ln 2$ gives $0.278$ bits. Check with entropies: $H(X) = H(Y) = \ln 2$ and $H(X \mid Y) = H(0.8, 0.2) = 0.5004$ nats, so $I = 0.6931 - 0.5004 = 0.1927$.
answer: $I(X; Y) \approx 0.1927$ nats $\approx 0.278$ bits.

@mistakes
- Treating KL divergence as a distance: it is asymmetric, and it does not satisfy the triangle inequality.
- Putting the distributions in the wrong order: in $D_{\mathrm{KL}}(p \,\Vert\, q)$ the expectation is under the first argument $p$, so it is infinite when $q$ assigns zero to something $p$ can produce.
- Forgetting that the mutual information of independent variables is 0 but zero correlation does not imply zero mutual information.
- Mixing units: $I$ in nats divided by $\ln 2$ gives bits, and the closed-form Gaussian expressions are in nats.

@quiz self
prompt: Prove Gibbs' inequality: for distributions $p$ and $q$ on a finite set, $D_{\mathrm{KL}}(p \,\Vert\, q) \ge 0$, with equality if and only if $p = q$. Then deduce that the cross-entropy satisfies $H(p, q) \ge H(p)$.
hint: Apply Jensen's inequality to $\log$ with weights $p_k$ on the support of $p$.
solution: Let $S = \{k : p_k > 0\}$ and assume $q_k > 0$ on $S$ (otherwise $D_{\mathrm{KL}} = \infty$ and the claim holds). Then $-D_{\mathrm{KL}}(p \,\Vert\, q) = \sum_{k \in S}p_k\log(q_k/p_k)$. Jensen's inequality for the concave $\log$ gives $\sum_{k \in S}p_k\log(q_k/p_k) \le \log\sum_{k \in S}p_k(q_k/p_k) = \log\sum_{k \in S}q_k \le \log 1 = 0$, so $D_{\mathrm{KL}} \ge 0$. Because $\log$ is strictly concave, equality in Jensen's inequality requires $q_k/p_k$ to be constant on $S$, say $c$; equality in the second step requires $\sum_{k \in S}q_k = 1$, so $c\sum_S p_k = c = 1$ and $q = p$ on $S$, hence $q_k = 0$ off $S$ as the total is 1. Conversely $p = q$ gives $\log 1 = 0$ in every term. Finally $H(p, q) - H(p) = D_{\mathrm{KL}}(p \,\Vert\, q) \ge 0$.

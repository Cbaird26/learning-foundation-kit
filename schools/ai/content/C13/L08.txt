@article
Importance sampling needs a proposal that resembles the target, which is hard in many dimensions. **Markov chain Monte Carlo** (MCMC) takes a different route: do a random walk whose long-run visiting frequencies equal the target. Bayesian posteriors are usually known only up to the normalizing constant $p(\mathcal{D})$, and MCMC needs only that unnormalized form $\tilde p(x) \propto p(x)$.

### Markov chains and stationary distributions

A **Markov chain** produces $x_0, x_1, x_2, \dots$ where each state depends only on the previous one, through a transition probability $T(x \to x')$. A distribution $\pi$ is **stationary** if one step preserves it: $\sum_x \pi(x)T(x \to x') = \pi(x')$ for every $x'$. Under mild conditions (the chain is **irreducible**, able to reach every region of positive probability, and **aperiodic**) a chain with a stationary distribution $\pi$ converges to it from any start, and averages along the chain converge to expectations under $\pi$: $\frac1N\sum_t f(x_t) \to \mathbb{E}_\pi[f]$.

A sufficient condition for stationarity is **detailed balance**: $\pi(x)T(x \to x') = \pi(x')T(x' \to x)$ for all $x, x'$. It implies stationarity, because summing over $x$ gives $\sum_x \pi(x)T(x \to x') = \sum_x \pi(x')T(x' \to x) = \pi(x')\sum_x T(x' \to x) = \pi(x')$.

### The Metropolis algorithm

Given the current state $x$ and a **symmetric proposal** $q(x' \mid x) = q(x \mid x')$ (for example $x' = x + \text{Gaussian noise}$):

1. Propose $x' \sim q(\cdot \mid x)$.
2. Compute the acceptance probability $\alpha = \min\!\big(1, \tilde p(x')/\tilde p(x)\big)$.
3. With probability $\alpha$ move to $x'$; otherwise stay at $x$ (and record $x$ again).

The normalizing constant cancels in the ratio. Moves uphill are always accepted; downhill moves are accepted with probability equal to the density ratio. This is the algorithm of Metropolis and colleagues (1953); Hastings (1970) generalized it to asymmetric proposals with $\alpha = \min\big(1, \frac{\tilde p(x')q(x \mid x')}{\tilde p(x)q(x' \mid x)}\big)$.

**Why it works.** For $x' \ne x$ the transition probability is $T(x \to x') = q(x' \mid x)\min\big(1, \tilde p(x')/\tilde p(x)\big)$. Then
$$p(x)T(x \to x') = q(x' \mid x)\,\min\!\big(p(x), p(x')\big),$$
using $p(x)\min(1, p(x')/p(x)) = \min(p(x), p(x'))$. By symmetry of $q$ this expression is unchanged when $x$ and $x'$ swap, which is detailed balance, so $p$ is stationary. Convergence additionally needs the proposal to allow the chain to reach everywhere.

### A three-state example

Let the target on states $\{1, 2, 3\}$ be proportional to $(1, 2, 3)$, so $p = (1/6, 2/6, 3/6)$. The proposal picks a neighbor ($\pm 1$) with probability $1/2$ each; a proposal off the ends is rejected. From state 1 the move to 2 has $\alpha = \min(1, 2/1) = 1$, so $T(1 \to 2) = 0.5$ and $T(1 \to 1) = 0.5$. From state 2: $T(2 \to 1) = 0.5 \times \tfrac12 = 0.25$, $T(2 \to 3) = 0.5 \times 1 = 0.5$, $T(2 \to 2) = 0.25$. From state 3: $T(3 \to 2) = 0.5 \times \tfrac23 = 1/3$ and $T(3 \to 3) = 2/3$. Check detailed balance on the pair $(1, 2)$: $p(1)T(1 \to 2) = \tfrac16(0.5) = \tfrac1{12}$ and $p(2)T(2 \to 1) = \tfrac26(0.25) = \tfrac1{12}$. They match.

### Practical issues

Samples are **correlated**: consecutive states are close, so $N$ chain samples carry less information than $N$ independent ones. The effective sample size can be far below $N$.

- **Burn-in.** Early samples depend on the starting point and are often discarded.
- **Step size.** A tiny step is accepted almost always but moves slowly (high autocorrelation); a huge step proposes far into low-density regions and is mostly rejected. Both mix poorly. For random-walk Metropolis in high dimensions, an acceptance rate of roughly 0.2 to 0.4 is a common target.
- **Logs.** Compute $\log\tilde p(x') - \log\tilde p(x)$ and accept if $\log u < $ this difference, with $u \sim \text{Uniform}(0, 1)$. This avoids overflow and underflow.
- **Diagnostics.** Run several chains from different starts and compare them; trace plots (here, tables of values) and the effective sample size reveal poor mixing, but no diagnostic can prove convergence.

### In code

```python
import math
import random

def metropolis(log_p, x0, step, n, seed):
    rng = random.Random(seed)
    x = x0
    chain = []
    for _ in range(n):
        proposal = x + step * rng.gauss(0.0, 1.0)
        if math.log(1.0 - rng.random()) < log_p(proposal) - log_p(x):
            x = proposal
        chain.append(x)
    return chain

chain = metropolis(lambda x: -x * x / 2, 0.0, 1.0, 2000, seed=0)
print(round(sum(chain) / len(chain), 2))
```

The target here is the standard normal, given only through its unnormalized log-density, and the chain mean is close to 0.

@example
title: Detailed balance for a two-state chain
problem: The target on two states is $\pi = (0.2, 0.8)$. The proposal always proposes the other state. Build the Metropolis transition probabilities and verify detailed balance.
step: From state 1 the proposal is state 2, with $\alpha = \min(1, 0.8/0.2) = 1$. So $T(1 \to 2) = 1$ and $T(1 \to 1) = 0$.
step: From state 2 the proposal is state 1, with $\alpha = \min(1, 0.2/0.8) = 0.25$. So $T(2 \to 1) = 0.25$ and $T(2 \to 2) = 0.75$.
step: Detailed balance: $\pi(1)T(1 \to 2) = 0.2 \times 1 = 0.2$ and $\pi(2)T(2 \to 1) = 0.8 \times 0.25 = 0.2$. They are equal.
step: Stationarity follows: the new probability of state 1 is $\pi(1)T(1 \to 1) + \pi(2)T(2 \to 1) = 0 + 0.2 = 0.2$.
answer: $T = \begin{pmatrix} 0 & 1 \\ 0.25 & 0.75 \end{pmatrix}$, and $\pi = (0.2, 0.8)$ is stationary.

@mistakes
- Forgetting to repeat the current state on a rejection: dropping rejected steps from the chain biases the samples away from high-density regions.
- Using the Metropolis ratio with an asymmetric proposal: then the Hastings correction $q(x \mid x')/q(x' \mid x)$ is required.
- Treating chain samples as independent: autocorrelation makes the effective sample size much smaller than the chain length, so standard errors are underestimated.
- Judging a chain by a high acceptance rate alone: a very small step size is accepted almost always yet explores the target slowly.

model:
```python
import math
import random

def metropolis(log_p, x0, step, n, seed):
    """Random-walk Metropolis; returns the n states visited after x0."""
    rng = random.Random(seed)
    x = x0
    chain = []
    for _ in range(n):
        proposal = x + step * rng.gauss(0.0, 1.0)
        if math.log(1.0 - rng.random()) < log_p(proposal) - log_p(x):
            x = proposal
        chain.append(x)
    return chain
```
hint: Keep the current state `x`; on each iteration propose, compare the log uniform number with the log ratio, update `x` if accepted, and append `x` either way.
solution: The acceptance test in logs avoids overflow. Rejected moves leave `x` unchanged, and the chain records it again; the box target tests that proposals outside the support are always rejected (the log ratio is minus infinity), and the zero step size test checks that nothing moves when every proposal equals the current state and the ratio is 1 (a solution that skips repeating states fails the length test).

@quiz self
prompt: Prove that if a Markov chain with transition probabilities $T$ satisfies detailed balance with respect to $\pi$, then $\pi$ is stationary. Then show that the Metropolis acceptance rule with a symmetric proposal satisfies detailed balance for the target $\pi \propto \tilde p$.
hint: For the first part sum the detailed-balance equation over $x$. For the second part write $T(x \to x')$ for $x' \ne x$ and compare $\pi(x)T(x \to x')$ with $\pi(x')T(x' \to x)$.
solution: Suppose $\pi(x)T(x \to x') = \pi(x')T(x' \to x)$ for all $x, x'$. Summing over $x$ gives $\sum_x \pi(x)T(x \to x') = \pi(x')\sum_x T(x' \to x) = \pi(x')$, since the transition probabilities out of $x'$ sum to 1; so $\pi$ is stationary. For Metropolis and $x' \ne x$, $T(x \to x') = q(x' \mid x)\min(1, \pi(x')/\pi(x))$ (the constant in $\tilde p$ cancels in the ratio). Hence $\pi(x)T(x \to x') = q(x' \mid x)\min(\pi(x), \pi(x'))$. The same computation with the roles swapped gives $\pi(x')T(x' \to x) = q(x \mid x')\min(\pi(x'), \pi(x))$. Since $q(x' \mid x) = q(x \mid x')$ the two are equal, and the case $x' = x$ is trivial, so detailed balance holds.

@article
**Statistics** is the science of learning from data, and medicine runs on it: a screening threshold, a drug dose and a prognosis all come from data summarized and compared. Every analysis starts with the same two questions: who or what was measured (the **individuals**), and what was measured about them (the **variables**)?

### Types of variables

A **categorical** variable places an individual in a group. If the groups have no natural order (blood type, smoking status) it is **nominal**; if they have an order (pain rated mild, moderate or severe; cancer stage I to IV) it is **ordinal**. A **quantitative** variable is a number on which arithmetic makes sense. It is **discrete** if it counts things (number of hospital admissions, number of children) and **continuous** if it can take any value in an interval (systolic blood pressure, body mass index, serum sodium).

A useful test: if averaging the values would be meaningless, the variable is probably categorical, even when the values are coded as digits. A ZIP code or a patient ID number is a label, not a quantity.

### Tables for categorical data

A **frequency table** lists each category with its count. The **relative frequency** is the count divided by the total, usually written as a percent:

$$\text{relative frequency} = \frac{\text{count in category}}{\text{total count}}.$$

A **bar chart** shows one bar per category. Bars have gaps between them because categories are separate, and their order is arbitrary for nominal data. A pie chart shows the same shares but is hard to read when there are many slices; bars are usually clearer.

### Graphs for quantitative data

- A **dotplot** puts one dot per observation above a number line. It suits small data sets.
- A **stemplot** splits each value into a stem (leading digits) and a leaf (last digit), so it keeps every value while showing shape.
- A **histogram** groups values into equal-width **bins** and draws bars whose heights are the counts (or relative frequencies). Bars touch because the horizontal axis is a continuous number line. Convention: a value that falls exactly on a bin edge is placed in the bin that starts at that edge, so the bin $70$ to $80$ contains $70$ but not $80$. Software and textbooks sometimes use the opposite rule, so check.
- A **time plot** (line graph) puts time on the horizontal axis and joins the measurements in order. Use it whenever data were collected over time, such as daily new cases during an outbreak.

### What to look for

Look for the overall pattern (where the values cluster, how spread out they are, the shape) and for **deviations** such as gaps or unusually large or small values. Week 2 turns this into precise vocabulary. For now, practice choosing the display that fits the data: bar chart for categories, histogram or dotplot for one quantitative variable, time plot for a variable tracked over time.

@example
title: Relative frequencies of blood type
problem: Among 200 blood donors, 88 have type O, 80 have type A, 24 have type B and 8 have type AB. Find the relative frequency of each type as a percent and name the graph you would use.
step: The total is already given: $88 + 80 + 24 + 8 = 200$ donors.
step: Divide each count by $200$. Type O: $88/200 = 0.44$, or $44\%$. Type A: $80/200 = 40\%$. Type B: $24/200 = 12\%$. Type AB: $8/200 = 4\%$.
step: Check that the percents add to $100\%$: $44 + 40 + 12 + 4 = 100$.
step: Blood type is a nominal categorical variable, so use a bar chart with separated bars, one per type.

@example
title: Reading a histogram
problem: A histogram of resting heart rates for 40 adults has bins $50$ to $60$, $60$ to $70$, $70$ to $80$, $80$ to $90$ with counts $6$, $14$, $15$, $5$. A reading of exactly $70$ beats per minute is in which bin, and what fraction of the adults are below $70$?
step: Using the stated convention (a bin includes its left edge), $70$ belongs to the bin $70$ to $80$.
step: Adults below $70$ are in the first two bins: $6 + 14 = 20$.
step: The fraction is $20/40 = 1/2$.

@mistakes
- Treating a numeric code (ZIP code, patient ID, a 1 to 5 satisfaction rating coded as digits) as a quantitative variable and averaging it.
- Drawing a histogram with gaps between bars, or a bar chart with touching bars, as if the two graphs were interchangeable.
- Computing relative frequency by dividing by the largest count instead of the total.
- Forgetting to say which bin edge a boundary value belongs to.

@practice num
prompt: Of 120 patients in a clinic, 54 have blood type A. What percent of the patients have type A?
answer: 45
check: 54 / 120 * 100
tol: 0.01
unit: %
hint: Relative frequency is the count in the category divided by the total.
hint: Divide $54$ by $120$, then convert to a percent by multiplying by $100$.
solution: $54/120 = 0.45$, which is $45\%$.

@practice num
prompt: A histogram of resting heart rates for 40 adults has bins $50$ to $60$, $60$ to $70$, $70$ to $80$, $80$ to $90$, $90$ to $100$ with counts $4$, $9$, $15$, $8$, $4$. What fraction of the adults have a heart rate of $80$ or more? Give a decimal.
answer: 0.3
check: (8 + 4) / (4 + 9 + 15 + 8 + 4)
tol: 0.001
hint: Which bins contain values of $80$ or more? Add their counts.
hint: The total number of adults is the sum of all five counts.
solution: The last two bins hold $8 + 4 = 12$ adults out of $40$, so the fraction is $12/40 = 0.3$.

@quiz mc
prompt: Why do the bars of a histogram touch, while the bars of a bar chart are separated?
choice*: A histogram's horizontal axis is a continuous numeric scale divided into adjacent bins, whereas a bar chart's categories are separate groups.
choice: Histograms show relative frequencies and bar charts show counts.
choice: The bars touch only when there are more than ten bins.
choice: Touching bars mean that the data are categorical.
hint: Think about what the horizontal axis represents in each graph.
solution: In a histogram the axis is a number line broken into consecutive intervals, so there are no gaps between bins. A bar chart compares distinct categories, and gaps emphasize that they are separate.

@article
Grown-up helper, please read this out loud.

Python is very good at math. It can add, take away and multiply in a blink.

```python
print(3 + 4)
```

This shows:

```text
7
```

Look closely. There are **no quote marks** around `3 + 4`. So Python does the sum and shows the answer.

### With quote marks or without

```python
print("3 + 4")
print(3 + 4)
```

The first line has quote marks, so it shows the words: `3 + 4`. The second line has no quote marks, so it shows the answer: `7`.

### The math signs

| Sign | Meaning | Example | Answer |
|---|---|---|---|
| `+` | add | `5 + 2` | 7 |
| `-` | take away | `5 - 2` | 3 |
| `*` | times | `5 * 2` | 10 |

The sign for times is a star `*`, not an x.

### Brackets go first

Python does the part in brackets first. So `(2 + 3) * 4` is `5 * 4`, which is `20`.

Also, Python does times before add: `2 + 3 * 4` is `2 + 12`, which is `14`.

@example
title: Sum or words?
problem: What do these two lines show?

```python
print("2 * 5")
print(2 * 5)
```
step: The first line has quote marks, so it shows the words `2 * 5`.
step: The second line has no quote marks, so Python works out 2 times 5.
step: The screen shows `2 * 5` and then `10`.

@example
title: Brackets first
problem: What does `print((1 + 2) * 3)` show?
step: Brackets go first. `1 + 2` is `3`.
step: Now the sum is `3 * 3`, which is `9`.
step: The screen shows `9`.
answer: 9

@mistakes
- Putting quote marks around a sum, so the computer shows the words instead of the answer.
- Using the letter x for times. Use the star `*`.
- Forgetting that times happens before add, so `2 + 3 * 4` is `14`, not `20`.

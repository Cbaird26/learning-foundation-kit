@article
Many integrands, such as $e^{-x^2}$, have no antiderivative in terms of elementary functions. Even when one exists, a program often only has a function it can *evaluate*. **Numerical integration** (quadrature) approximates $\int_a^b f(x)\,dx$ from values of $f$ at sample points.

Split $[a,b]$ into $n$ equal subintervals of width $h = \frac{b-a}{n}$ with nodes $x_i = a + ih$ for $i=0,\dots,n$.

### The rules

The **trapezoid rule** replaces $f$ on each subinterval by the straight line through its endpoints:

$$T_n = \frac h2\Big[f(x_0) + 2f(x_1) + 2f(x_2)+\dots+2f(x_{n-1}) + f(x_n)\Big].$$

The **midpoint rule** uses the height at each subinterval's midpoint: $M_n = h\sum_{i=1}^n f\!\left(\frac{x_{i-1}+x_i}{2}\right)$.

**Simpson's rule** replaces $f$ on each *pair* of subintervals by the parabola through three consecutive nodes. It needs $n$ **even**:

$$S_n = \frac h3\Big[f(x_0)+4f(x_1)+2f(x_2)+4f(x_3)+\dots+2f(x_{n-2})+4f(x_{n-1})+f(x_n)\Big].$$

The weights follow the pattern $1,4,2,4,\dots,2,4,1$. A useful identity is $S_{2n} = \frac{4T_{2n}-T_n}{3}$: Simpson's rule is a weighted combination of two trapezoid estimates, in which the leading error terms cancel.

### Error bounds

Suppose $|f''(x)|\le K_2$ and $|f^{(4)}(x)|\le K_4$ on $[a,b]$. Then the errors $E = \int_a^b f - (\text{approximation})$ satisfy

$$|E_T|\le\frac{K_2(b-a)^3}{12n^2},\qquad |E_M|\le\frac{K_2(b-a)^3}{24n^2},\qquad |E_S|\le\frac{K_4(b-a)^5}{180n^4}.$$

The key lesson is the *power of $n$*. Doubling $n$ divides the trapezoid bound by $4$ but the Simpson bound by $16$. Because $f^{(4)}\equiv0$ for any cubic polynomial, Simpson's rule is **exact for polynomials of degree at most 3**, one degree better than its parabolas would suggest.

These are worst-case bounds. The actual error is often smaller, and these formulas assume $f$ is smooth on $[a,b]$; a singularity or jump breaks them.

### In code

A rule is a short loop. Evaluating $f$ is the expensive step, so each node is evaluated once. Floating-point rounding is negligible for moderate $n$; the truncation error above dominates.

```python
def trapezoid(f, a, b, n):
    h = (b - a) / n
    total = (f(a) + f(b)) / 2
    for i in range(1, n):
        total += f(a + i * h)
    return total * h
```

Here the endpoints get weight $\frac12$ and the interior nodes weight $1$, then everything is multiplied by $h$, which is the same as the formula above.

@example
title: Trapezoid and Simpson by hand
problem: Approximate $\displaystyle\int_0^1 x^2\,dx$ with $T_4$ and $S_4$, and compare with the exact value $\tfrac13$.
step: $n=4$, $h=\tfrac14$. The values $f(x_i)=x_i^2$ at $0,\tfrac14,\tfrac12,\tfrac34,1$ are $0,\tfrac1{16},\tfrac14,\tfrac9{16},1$.
step: Trapezoid: $T_4=\tfrac18\left[0+2\left(\tfrac1{16}+\tfrac14+\tfrac9{16}\right)+1\right]=\tfrac18\left[\tfrac{11}{4}\right]=\tfrac{11}{32}=0.34375$.
step: The error is $\tfrac{11}{32}-\tfrac13=\tfrac1{96}\approx0.0104$. The bound with $K_2=2$ is $\tfrac{2\cdot1}{12\cdot16}=\tfrac1{96}$, so it is attained exactly (because $f''$ is constant).
step: Simpson: $S_4=\tfrac1{12}\left[0+4\cdot\tfrac1{16}+2\cdot\tfrac14+4\cdot\tfrac9{16}+1\right]=\tfrac1{12}\cdot4=\tfrac13$.
step: Simpson's rule is exact here, as it must be for a polynomial of degree at most $3$.
answer: $T_4=\frac{11}{32}$ and $S_4=\frac13$

@example
title: Choosing $n$ from the error bound
problem: How many subintervals guarantee that the trapezoid rule approximates $\int_0^1 e^x\,dx$ with error at most $10^{-4}$?
step: $f''(x)=e^x$ is increasing, so $K_2=e$ on $[0,1]$.
step: Require $\dfrac{e\cdot1^3}{12n^2}\le10^{-4}$, that is $n^2\ge\dfrac{e}{12\cdot10^{-4}}\approx2265.2$.
step: Take square roots: $n\ge47.6$.
step: Since $n$ is an integer, $n=48$ suffices (while $47^2=2209<2265.2$ does not satisfy the bound).
answer: $n = 48$

@mistakes
- Using $n$ odd with Simpson's rule, which pairs subintervals and so requires an even $n$.
- Mis-weighting the nodes: all interior nodes get $2$ in the trapezoid rule, but they alternate $4,2,4,\dots$ in Simpson's rule.
- Forgetting the factor $h$ (or $\frac h2$, $\frac h3$) in front of the sum.
- Bounding $|f''|$ at one endpoint instead of the maximum on the whole interval $[a,b]$.

```python
def simpson(f, a, b, n):
    if n < 2 or n % 2 != 0:
        raise ValueError("n must be an even integer of at least 2")
    h = (b - a) / n
    total = f(a) + f(b)
    for i in range(1, n):
        weight = 4 if i % 2 == 1 else 2
        total += weight * f(a + i * h)
    return total * h / 3
```
hint: Check `n` first and raise `ValueError` before computing anything.
hint: Odd-numbered interior nodes have weight 4 and even-numbered ones weight 2.
solution: Validate `n`, then sum `f(a)`, `f(b)` and the interior nodes with alternating weights 4 and 2, and multiply by `h / 3`. Cubic and quadratic test functions are exact, while the sine test shows a genuine error of about 0.0046.

```python
def _trap(f, a, b, m):
    h = (b - a) / m
    total = (f(a) + f(b)) / 2
    for i in range(1, m):
        total += f(a + i * h)
    return total * h


def simpson_from_trapezoids(f, a, b, n):
    return (4 * _trap(f, a, b, 2 * n) - _trap(f, a, b, n)) / 3
```
hint: Write a helper that computes $T_m$ for any $m$.
hint: Call it with $2n$ and with $n$, then combine as $(4T_{2n}-T_n)/3$.
solution: The helper computes the trapezoid rule; the combination $(4T_{2n}-T_n)/3$ cancels the leading $h^2$ error term and equals Simpson's rule with $2n$ subintervals. It integrates $x^3$ exactly, as Simpson's rule must.

@review
This review follows the weeks of the course. Use it to find gaps, then redo the practice items for any week where you hesitate.

**Weeks 1 and 2: techniques of integration.** Substitution undoes the chain rule (change the limits in a definite integral). Parts undoes the product rule: $\int u\,dv=uv-\int v\,du$, with $u$ chosen so that $du$ is simpler. For trigonometric integrals strip off an odd power or use half-angle identities. For rational functions, divide first if the degree is too high, then decompose into partial fractions. Check any antiderivative by differentiating.

**Weeks 3 and 4: numerical and improper integrals.** Trapezoid error is bounded by $\frac{K_2(b-a)^3}{12n^2}$ and Simpson's by $\frac{K_4(b-a)^5}{180n^4}$, with Simpson needing even $n$ and being exact for cubics. Improper integrals are limits. Know the p-integrals ($\int_1^\infty x^{-p}$ converges iff $p>1$; $\int_0^1x^{-p}$ iff $p<1$) and the comparison test.

**Week 5: applications.** Area is top minus bottom; disks and washers use $\pi\int(R^2-r^2)$; shells use $2\pi\int x\,f(x)\,dx$; arc length is $\int\sqrt{1+f'^2}\,dx$.

**Weeks 6 and 7: sequences and series.** A series converges when its partial sums do. Check $a_n\to0$ first, then use geometric, telescoping, p-series, integral, comparison, limit comparison, ratio and alternating series tests. Know absolute versus conditional convergence.

**Weeks 8 and 9: power and Taylor series.** The ratio test gives the radius; test endpoints separately. Differentiate and integrate term by term. Taylor coefficients are $\frac{f^{(k)}(a)}{k!}$ and the error obeys $|R_n|\le\frac{M|x-a|^{n+1}}{(n+1)!}$. Memorize the series for $e^x$, $\sin x$, $\cos x$, $\frac1{1-x}$, $\ln(1+x)$ and $\arctan x$.

**Week 10: parametric and polar curves.** $\frac{dy}{dx}=\frac{dy/dt}{dx/dt}$; arc length uses $\sqrt{x'^2+y'^2}$; polar area is $\frac12\int r^2\,d\theta$ over a single traversal.

**Weeks 11 and 12: several variables.** Domains, level curves, and path arguments for limits. Partial derivatives treat the other variables as constants; the gradient points toward steepest ascent; $D_{\mathbf u}f=\nabla f\cdot\mathbf u$ needs a unit vector. Gradient descent is $\mathbf x\leftarrow\mathbf x-\alpha\nabla f$, and its step size must be small enough for the steepest direction.

**Common errors.** Forgetting to change limits; dropping a constant from $du$; treating $\frac1n\to0$ as proof that $\sum\frac1n$ converges; concluding from the ratio test when $L=1$; forgetting endpoints; omitting $\frac12$ in polar area; using a non-unit vector for a directional derivative; using a step size outside the stable range.

model:
```python
import math


def gauss_simpson(n):
    if n < 2 or n % 2 != 0:
        raise ValueError("n must be even and at least 2")
    h = 1 / n
    total = 1 + math.exp(-1)
    for i in range(1, n):
        weight = 4 if i % 2 == 1 else 2
        total += weight * math.exp(-((i * h) ** 2))
    return total * h / 3


def series_integral(n):
    total = 0.0
    for k in range(n + 1):
        total += (-1) ** k / (math.factorial(k) * (2 * k + 1))
    return total
```
hint: For Simpson, the nodes are `i / n`, the endpoint values are `exp(0) = 1` and `exp(-1)`, and the interior weights alternate 4, 2.
hint: Integrate $\sum\frac{(-1)^kx^{2k}}{k!}$ term by term over $[0,1]$: $\int_0^1x^{2k}dx=\frac1{2k+1}$.
solution: The Simpson function is the standard rule with $f(x)=e^{-x^2}$; the series function integrates the Maclaurin series of $e^{-x^2}$ term by term. The series is alternating with rapidly decreasing terms, so after $n=14$ the error is below $1/(15!\cdot31)\approx2\times10^{-14}$, while Simpson's error decreases like $1/n^4$.

@exam self
prompt: Gradient descent is applied to $f(x,y)=x^2+10y^2$ with step size $\alpha$ from the point $(1,1)$. (a) Write the update for each coordinate. (b) Find all $\alpha$ for which the iterates converge to the minimum $(0,0)$. (c) For $\alpha=0.05$, give the first two iterates. (d) Explain why this function is slow to minimize for step sizes near the upper limit.
hint: Write the gradient first; each coordinate then gets multiplied by a constant factor on every step, and convergence needs both factors to have absolute value below 1.
solution: (a) $\nabla f=(2x,20y)$, so $x_{k+1}=(1-2\alpha)x_k$ and $y_{k+1}=(1-20\alpha)y_k$. (b) Both factors must have absolute value below $1$: $|1-2\alpha|<1$ gives $0<\alpha<1$, and $|1-20\alpha|<1$ gives $0<\alpha<0.1$. So convergence holds exactly for $0<\alpha<0.1$. (c) With $\alpha=0.05$: factors $0.9$ and $0$, so $(x_1,y_1)=(0.9,0)$ and $(x_2,y_2)=(0.81,0)$. (d) Near $\alpha=0.1$ the $y$-factor is near $-1$, so the $y$-coordinate oscillates and decays slowly; at the same time the $x$-factor $1-2\alpha$ is near $0.8$. The steep direction limits the step size, and the flat direction then moves slowly. The best uniform choice balances $|1-2\alpha|=|1-20\alpha|$, giving $\alpha=\frac1{11}$ and rate $\frac9{11}$ per step, so the ratio of curvatures (10) limits speed.

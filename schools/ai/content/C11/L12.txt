@article
Every model in this course so far took neat lists of numbers. Real data arrives as text: a CSV file with a header line, numbers written as strings, blank cells, and categories such as city names. Most of the work of a machine learning project is turning that text into a clean numeric matrix, and mistakes at this stage quietly ruin everything after it.

### From text to numbers

A **CSV** (comma-separated values) file has one record per line and fields separated by commas, usually with a header line of column names. Read it with `open`, split the text into lines with `splitlines()`, and split each line with `split(",")`. Fields are strings, so convert numbers with `float(...)`. The `csv` module handles quoted fields that contain commas (`"Paris, France"`), which a plain `split` cannot. A **missing value** is an empty field: `float("")` raises `ValueError`, so decide how to represent it. We use `None`.

```python
def parse_csv_numeric(text):
    lines = text.splitlines()
    header = lines[0].split(",")
    rows = []
    for line in lines[1:]:
        cells = line.split(",")
        rows.append([float(c) if c.strip() != "" else None for c in cells])
    return header, rows

header, rows = parse_csv_numeric("x,y\n1,2.5\n3,\n")
print(header, rows)   # ['x', 'y'] [[1.0, 2.5], [3.0, None]]
```

With pandas this is `df = pd.read_csv("file.csv")`, and missing cells become `NaN`; the logic underneath is the same.

### Handling missing values

Options include dropping rows with missing cells (simple, but wasteful and possibly biased), or **imputing** a value such as the column mean. Imputation with the mean leaves the column average unchanged but shrinks its spread, and it hides the fact that a value was missing; a careful analysis may add an indicator column. Whatever you choose, compute it from observed values only, and say so.

### Standardizing columns

Columns often live on different scales: an age near 40 and an income near 50,000. Unscaled columns hurt in two ways. The matrix $\mathbf{X}^\top\mathbf{X}$ becomes badly conditioned (Lesson 6), and gradient descent needs a tiny step size for the big column and then crawls along the small one. **Standardization** replaces each value $x$ in a column by
$$z = \frac{x - \bar{x}}{\sigma},$$
where $\bar{x}$ is the column mean and $\sigma$ its standard deviation (we divide by $n$, the population version; dividing by $n - 1$ changes nothing important). The new column has mean 0 and standard deviation 1. A constant column has $\sigma = 0$; set it to zeros rather than dividing by zero. **Min–max scaling**, $(x - \min)/(\max - \min)$, maps a column to $[0, 1]$ instead and is sensitive to outliers.

### Avoiding leakage

Statistics such as $\bar{x}$ and $\sigma$ must be computed from the **training rows only** and then applied unchanged to the test rows. Computing them on all the data lets information from the test set influence the model, called **data leakage**, and makes test performance look better than it will be on genuinely new data. The same rule applies to imputation values. First split, then fit the preprocessing on the training part.

### Categories, bias and splitting

A categorical feature with $K$ levels becomes $K$ **one-hot** columns, where exactly one is 1. If the design matrix also has a column of ones for the intercept, the $K$ one-hot columns add up to that column, so the matrix is rank deficient and $\mathbf{X}^\top\mathbf{X}$ is singular. The usual fix is to drop one level, leaving $K - 1$ columns.

To split data, shuffle the row indices with a seeded generator (Lesson 10), take the first part for testing and the rest for training. Fixing the seed makes the split reproducible. Note that a split that depends on file order can hide trends, for instance when the file is sorted by date.

```python
import random

rng = random.Random(0)
idx = list(range(10))
rng.shuffle(idx)
test_idx, train_idx = idx[:2], idx[2:]
print(len(test_idx), len(train_idx))   # 2 8
```

answer: The standardized rows are $[-1.2247, -1]$, $[0, 0]$, $[1.2247, 1]$.

@example
title: Using training statistics on test data
problem: The training values of a column are $10, 20, 30$ and a test value is $100$. Standardize the test value correctly, and say what goes wrong if the statistics are computed on all four numbers.
step: Training mean: $20$. Training population standard deviation: $\sqrt{(100 + 0 + 100)/3} = \sqrt{200/3} \approx 8.165$.
step: The test value becomes $z = (100 - 20)/8.165 \approx 9.80$, correctly flagging it as extreme relative to the training data.
step: With all four numbers the mean is $40$ and the standard deviation is $\sqrt{(900 + 400 + 100 + 3600)/4} \approx 35.4$, so $100$ would look like $z = 1.7$, ordinary. The test point has leaked into the statistics and hides its outlying nature.
answer: The correct test $z$-score is about $9.80$; using all the data gives about $1.7$ and understates the difference.

@mistakes
- Computing means and standard deviations on the whole data set before splitting: the test set then influences preprocessing (leakage).
- Using `split(",")` on files with quoted fields that contain commas: use the `csv` module for those.
- Including a full set of one-hot columns together with a column of ones: the columns are linearly dependent and $\mathbf{X}^\top\mathbf{X}$ is singular.
- Dividing by a standard deviation of 0 for a constant column, which produces `ZeroDivisionError` or `nan`.

```python
def read_csv_numeric(filename):
    """Read a simple numeric CSV file; empty fields become None."""
    with open(filename) as f:
        lines = f.read().splitlines()
    header = [c.strip() for c in lines[0].split(",")]
    rows = []
    for line in lines[1:]:
        if line.strip() == "":
            continue
        cells = [c.strip() for c in line.split(",")]
        rows.append([float(c) if c != "" else None for c in cells])
    return header, rows
```
hint: Read the whole file, split it into lines, treat the first line as the header, then convert each remaining nonblank line cell by cell.
solution: Each line is split on commas and each cell is stripped; an empty string becomes `None` and anything else goes through `float`, which also accepts forms such as `-1e2`. The blank-line check keeps trailing newlines from producing empty rows.

model:
```python
import math

def standardize_columns(rows):
    """Standardize columns using observed values; missing entries become 0."""
    ncols = len(rows[0])
    means = []
    stds = []
    for j in range(ncols):
        vals = [r[j] for r in rows if r[j] is not None]
        mean = sum(vals) / len(vals)
        var = sum((v - mean) ** 2 for v in vals) / len(vals)
        means.append(mean)
        stds.append(math.sqrt(var))
    out = []
    for r in rows:
        new = []
        for j in range(ncols):
            if r[j] is None or stds[j] == 0:
                new.append(0.0)
            else:
                new.append((r[j] - means[j]) / stds[j])
        out.append(new)
    return out, means, stds
```
hint: First pass: collect the observed values of each column and compute its mean and standard deviation. Second pass: build the new rows, writing 0.0 for missing values and constant columns.
solution: The statistics come only from observed values, so a missing cell does not distort them; after standardizing, the column mean is 0, so 0.0 is the mean imputation. The constant column has standard deviation exactly 0 (all entries equal 7.0), which the code must not divide by.

model:
```python
import random

def train_test_split(rows, test_fraction, seed):
    """Seeded random split into (train, test)."""
    n = len(rows)
    idx = list(range(n))
    random.Random(seed).shuffle(idx)
    n_test = int(n * test_fraction)
    test = [rows[i] for i in idx[:n_test]]
    train = [rows[i] for i in idx[n_test:]]
    return train, test
```
hint: Shuffle a list of indices rather than the rows, then slice it at `n_test` and look up the rows.
solution: Shuffling indices leaves `rows` untouched, and slicing at `n_test` gives disjoint parts that together contain every row exactly once. The seed makes the split repeatable, while different seeds give different splits.

```python
import math

def probability_from_file(filename):
    """Estimate a probability and its standard error from a CSV of outcomes."""
    with open(filename) as f:
        lines = f.read().splitlines()
    hits = 0
    n = 0
    for line in lines[1:]:
        if line.strip() == "":
            continue
        trial, hit = line.split(",")
        n += 1
        if int(hit) == 1:
            hits += 1
    p = hits / n
    return p, math.sqrt(p * (1 - p) / n)
```
hint: Skip the header and blank lines, count the trials and the lines whose `hit` field is 1, then use the binomial standard error formula.
solution: The file is a log of Bernoulli outcomes, so the hit fraction estimates the probability and $\sqrt{\hat p(1-\hat p)/n}$ is its standard error. The second test shows the all-hits edge case where the standard error is exactly 0 (a reason to be careful with so few trials).

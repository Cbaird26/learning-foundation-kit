@article
Rank web pages, find the main direction of variation in a data set (the first principal component), or study how a recurrent system behaves over time: each of these asks for an **eigenvector** of a matrix, a vector $\mathbf{v} \ne \mathbf{0}$ with $\mathbf{A}\mathbf{v} = \lambda\mathbf{v}$ for a number $\lambda$, the **eigenvalue**. For a large matrix we rarely need all of them, just the biggest, and one very simple algorithm finds it.

### The idea

Take any vector $\mathbf{v}_0$ and multiply it by $\mathbf{A}$ again and again. Suppose $\mathbf{A}$ is symmetric (or at least diagonalizable) with eigenvalues $|\lambda_1| > |\lambda_2| \ge \cdots \ge |\lambda_n|$ and eigenvectors $\mathbf{u}_1, \ldots, \mathbf{u}_n$. Write $\mathbf{v}_0 = c_1\mathbf{u}_1 + \cdots + c_n\mathbf{u}_n$. Then
$$\mathbf{A}^k\mathbf{v}_0 = c_1\lambda_1^k\mathbf{u}_1 + c_2\lambda_2^k\mathbf{u}_2 + \cdots = \lambda_1^k\Big(c_1\mathbf{u}_1 + c_2\big(\tfrac{\lambda_2}{\lambda_1}\big)^k\mathbf{u}_2 + \cdots\Big).$$
Every term except the first is multiplied by a ratio of magnitude less than 1 raised to the power $k$, so it fades. The direction of $\mathbf{A}^k\mathbf{v}_0$ approaches $\mathbf{u}_1$.

### The algorithm

The vector $\mathbf{A}^k\mathbf{v}_0$ would overflow or underflow, so we **normalize** at each step (compare Lesson 2):
$$\mathbf{v}_{k+1} = \frac{\mathbf{A}\mathbf{v}_k}{\lVert \mathbf{A}\mathbf{v}_k \rVert_2}.$$
To read off the eigenvalue, use the **Rayleigh quotient**
$$\lambda_k = \frac{\mathbf{v}_k^\top \mathbf{A}\mathbf{v}_k}{\mathbf{v}_k^\top \mathbf{v}_k},$$
which equals $\lambda$ exactly when $\mathbf{v}_k$ is an eigenvector. The cost per iteration is one matrix-vector product, $n^2$ multiplications.

```python
import math

def matvec(A, v):
    return [sum(a * b for a, b in zip(row, v)) for row in A]

def power_iteration(A, v0, iters):
    v = v0[:]
    for _ in range(iters):
        w = matvec(A, v)
        norm = math.sqrt(sum(t * t for t in w))
        v = [t / norm for t in w]
    Av = matvec(A, v)
    lam = sum(a * b for a, b in zip(v, Av)) / sum(a * a for a in v)
    return lam, v

lam, v = power_iteration([[2, 1], [1, 3]], [1.0, 0.0], 8)
print(round(lam, 4), [round(t, 4) for t in v])   # 3.618 [0.5264, 0.8503]
```

### Convergence

For $\mathbf{A} = \begin{bmatrix} 2 & 1 \\ 1 & 3 \end{bmatrix}$ the eigenvalues are $(5 \pm \sqrt{5})/2 \approx 3.618$ and $1.382$, a ratio of $0.382$. Starting from $\mathbf{v}_0 = [1, 0]$:

| iteration | $\mathbf{v}_k$ | $\lambda_k$ |
|---|---|---|
| 1 | $[0.8944, 0.4472]$ | 3.0000 |
| 2 | $[0.7071, 0.7071]$ | 3.5000 |
| 3 | $[0.6000, 0.8000]$ | 3.6000 |
| 5 | $[0.5369, 0.8437]$ | 3.6176 |
| 8 | $[0.5264, 0.8503]$ | 3.6180 |

The exact eigenvector is $[0.5257, 0.8507]$. The general statement: if $|\lambda_1| > |\lambda_2|$ and $c_1 \ne 0$ (the start has a component along $\mathbf{u}_1$), the direction converges to $\mathbf{u}_1$ with the error shrinking by about a factor $|\lambda_2/\lambda_1|$ per iteration; for symmetric matrices the Rayleigh quotient error shrinks like $|\lambda_2/\lambda_1|^2$ per step, twice as fast. Power iteration is slow when the two largest magnitudes are close, fails if $|\lambda_1| = |\lambda_2|$ with different signs (the iterates keep flipping), and in exact arithmetic fails from a start orthogonal to $\mathbf{u}_1$ (rounding error usually creates a small component that grows, but do not count on it). If $\lambda_1 < 0$ the sign of $\mathbf{v}_k$ alternates, though the line it spans converges. A random start almost surely has $c_1 \ne 0$.

### Deflation

To find a second eigenpair of a **symmetric** matrix, subtract the part belonging to the first: for a unit eigenvector $\mathbf{u}_1$, the matrix $\mathbf{A} - \lambda_1\mathbf{u}_1\mathbf{u}_1^\top$ has the same eigenvectors as $\mathbf{A}$, with the eigenvalue $\lambda_1$ replaced by 0. Power iteration on it finds $\lambda_2$ (when $|\lambda_2|$ is the largest remaining). Errors in $\mathbf{u}_1$ accumulate, so deflation is accurate for a few eigenpairs only; library routines use other methods for full eigendecompositions. The PageRank idea is power iteration on a very large, sparse matrix, and the first principal component is power iteration on a covariance matrix.

@example
title: Power iteration by hand
problem: Run two steps of power iteration on $\mathbf{A} = \begin{bmatrix} 4 & 1 \\ 2 & 3 \end{bmatrix}$ from $\mathbf{v}_0 = [1, 0]$, normalizing by the largest entry instead of the 2-norm, and estimate $\lambda_1$.
step: First product: $\mathbf{A}\mathbf{v}_0 = [4, 2]$. Dividing by its largest entry gives $\mathbf{v}_1 = [1, 0.5]$.
step: Second product: $\mathbf{A}\mathbf{v}_1 = [4 + 0.5,\; 2 + 1.5] = [4.5, 3.5]$, so $\mathbf{v}_2 = [1, 0.7778]$ and the scaling factor 4.5 estimates $\lambda_1$.
step: The characteristic polynomial $\lambda^2 - 7\lambda + 10$ has roots 5 and 2, with eigenvector $[1, 1]$ for $\lambda = 5$. The iterates $[1, 0], [1, 0.5], [1, 0.78]$ move toward $[1, 1]$, and the scale factors $4, 4.5, \ldots$ approach 5, with error ratio $2/5$ per step.
answer: After two steps $\mathbf{v}_2 \approx [1, 0.778]$ and $\lambda_1 \approx 4.5$, heading toward $\lambda_1 = 5$ and eigenvector $[1, 1]$.

@example
title: Deflation
problem: The matrix $\mathbf{A} = \begin{bmatrix} 2 & 1 \\ 1 & 2 \end{bmatrix}$ has the dominant eigenpair $\lambda_1 = 3$, $\mathbf{u}_1 = [1, 1]/\sqrt{2}$. Form the deflated matrix and find the second eigenvalue.
step: Compute $\mathbf{u}_1\mathbf{u}_1^\top = \tfrac12\begin{bmatrix} 1 & 1 \\ 1 & 1 \end{bmatrix}$, so $\lambda_1\mathbf{u}_1\mathbf{u}_1^\top = \begin{bmatrix} 1.5 & 1.5 \\ 1.5 & 1.5 \end{bmatrix}$.
step: Subtract: $\mathbf{B} = \mathbf{A} - \lambda_1\mathbf{u}_1\mathbf{u}_1^\top = \begin{bmatrix} 0.5 & -0.5 \\ -0.5 & 0.5 \end{bmatrix}$.
step: Check: $\mathbf{B}\mathbf{u}_1 = \mathbf{0}$, and $\mathbf{B}[1, -1] = [1, -1]$, so $\mathbf{B}$ has eigenvalues 0 and 1; its dominant eigenvalue is 1.
answer: The second eigenvalue of $\mathbf{A}$ is 1, with eigenvector $[1, -1]/\sqrt{2}$.

@mistakes
- Forgetting to normalize: the vector grows like $\lambda_1^k$ and overflows, or shrinks to zero.
- Starting from a vector orthogonal to the dominant eigenvector, such as $[1, -1]$ for a matrix with eigenvector $[1, 1]$.
- Expecting fast convergence when $|\lambda_2| \approx |\lambda_1|$: the error factor per step is close to 1.
- Using the Rayleigh quotient on a vector that is far from an eigenvector and trusting it: it is a good estimate only after the direction has converged.

model:
```python
import math

def top_singular(A, v0, iters):
    """Largest singular value and right singular vector by power iteration."""
    m, n = len(A), len(A[0])
    v = list(v0)
    for _ in range(iters):
        w = [sum(a * b for a, b in zip(row, v)) for row in A]
        z = [sum(A[i][j] * w[i] for i in range(m)) for j in range(n)]
        norm = math.sqrt(sum(t * t for t in z))
        v = [t / norm for t in z]
    w = [sum(a * b for a, b in zip(row, v)) for row in A]
    return math.sqrt(sum(t * t for t in w)), v
```
hint: One pass is two matrix-vector products: `A v` has length `m`, and multiplying it by `A^T` means summing `A[i][j] * w[i]` down each column `j`. Normalize the result, and take the norm of `A v` only at the end.
solution: One pass of power iteration on $\mathbf{A}^\top\mathbf{A}$ is $\mathbf{v} \leftarrow \mathbf{A}^\top(\mathbf{A}\mathbf{v})$ followed by normalization, which costs two passes over $\mathbf{A}$ and never builds the $n \times n$ product. For a unit $\mathbf{v}$ near the dominant eigenvector, $\lVert\mathbf{A}\mathbf{v}\rVert = \sqrt{\mathbf{v}^\top\mathbf{A}^\top\mathbf{A}\mathbf{v}} = \sigma_1$, so the singular value is a square root, not the eigenvalue $\sigma_1^2$ and not the norm of $\mathbf{z}$ (which is about $\sigma_1^2$); the first test catches both. Running ordinary power iteration with `A` itself is meaningless for a non-square matrix, because $\mathbf{A}\mathbf{v}$ has length $m$, not $n$; it gives wrong values or an error on the 4 by 3 and 2 by 4 tests. The one-iteration test pins down the exact update, the 1e10 test catches code that never normalizes inside the loop (the iterates overflow), and the last test catches code that modifies its inputs.

```python
def deflate(A, lam, u):
    """Remove the eigenpair (lam, u) from symmetric A: A - lam * u u^T."""
    n = len(A)
    return [[A[i][j] - lam * u[i] * u[j] for j in range(n)] for i in range(n)]
```
hint: Entry $(i, j)$ of $\mathbf{u}\mathbf{u}^\top$ is `u[i] * u[j]`; subtract `lam` times it from `A[i][j]`.
solution: The outer product $\mathbf{u}\mathbf{u}^\top$ projects onto the direction of $\mathbf{u}$, so subtracting $\lambda\mathbf{u}\mathbf{u}^\top$ zeroes the eigenvalue belonging to $\mathbf{u}$ and leaves the rest. The last test confirms that the deflated matrix sends $\mathbf{u}$ to the zero vector.

```python
import math

def power_iteration_tol(A, v0, tol, max_iter):
    """Power iteration that stops when the Rayleigh quotient settles."""
    def matvec(M, x):
        return [sum(a * b for a, b in zip(row, x)) for row in M]

    v = list(v0)
    prev = None
    lam = 0.0
    for k in range(1, max_iter + 1):
        w = matvec(A, v)
        norm = math.sqrt(sum(t * t for t in w))
        v = [t / norm for t in w]
        Av = matvec(A, v)
        lam = sum(a * b for a, b in zip(v, Av)) / sum(a * a for a in v)
        if prev is not None and abs(lam - prev) < tol:
            return lam, v, k
        prev = lam
    return lam, v, max_iter
```
hint: Keep the previous `lam` in a variable that starts as `None`; compare after computing each new one, starting from the second iteration.
solution: The stopping rule compares successive eigenvalue estimates. A one-by-one matrix is already converged, so the second estimate equals the first and the loop stops at `k = 2`. With a tiny tolerance and `max_iter = 3` the loop runs out, returning `max_iter`.

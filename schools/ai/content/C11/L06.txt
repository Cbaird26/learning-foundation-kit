@article
Consider $\mathbf{A}\mathbf{x} = \mathbf{b}$ with $\mathbf{A} = \begin{bmatrix} 1 & 1 \\ 1 & 1.01 \end{bmatrix}$ and $\mathbf{b} = [2, 2.01]$; the solution is $\mathbf{x} = [1, 1]$. Now change the second entry of $\mathbf{b}$ by 0.001, a relative change of 0.05%. The solution jumps to $[0.9, 1.1]$, a 10% change. No algorithm can do better, because the damage is in the problem itself. Some problems amplify small input errors, and rounding errors are small input errors.

### Condition numbers

The **infinity norm** of a matrix is its largest absolute row sum, $\lVert \mathbf{A} \rVert_\infty = \max_i \sum_j |a_{ij}|$; it measures how much $\mathbf{A}$ can stretch a vector in the $\lVert\cdot\rVert_\infty$ norm. The **condition number** of an invertible matrix is
$$\kappa(\mathbf{A}) = \lVert \mathbf{A} \rVert \, \lVert \mathbf{A}^{-1} \rVert \;\ge\; 1 .$$
If $\mathbf{A}\mathbf{x} = \mathbf{b}$ and $\mathbf{A}(\mathbf{x} + \delta\mathbf{x}) = \mathbf{b} + \delta\mathbf{b}$, then
$$\frac{\lVert \delta\mathbf{x} \rVert}{\lVert \mathbf{x} \rVert} \le \kappa(\mathbf{A}) \, \frac{\lVert \delta\mathbf{b} \rVert}{\lVert \mathbf{b} \rVert}.$$
The relative error of the answer is at most $\kappa$ times the relative error of the data, and this can be nearly attained. A matrix with $\kappa$ near 1 is **well-conditioned**; a large $\kappa$ means **ill-conditioned**; a singular matrix has $\kappa = \infty$. For the matrix above, $\mathbf{A}^{-1} = \begin{bmatrix} 101 & -100 \\ -100 & 100 \end{bmatrix}$, so $\lVert \mathbf{A} \rVert_\infty = 2.01$, $\lVert \mathbf{A}^{-1} \rVert_\infty = 201$ and $\kappa_\infty = 404.01$. The perturbation above was amplified by a factor of 201, within the bound 404.

For the family $\mathbf{A}_\varepsilon = \begin{bmatrix} 1 & 1 \\ 1 & 1+\varepsilon \end{bmatrix}$ the same calculation gives $\kappa_\infty = (2 + \varepsilon)^2/\varepsilon$, which grows like $4/\varepsilon$ as the two rows become parallel. Closeness to singular is what makes a matrix ill-conditioned. Another standard family is the **Hilbert matrix** $H_{ij} = 1/(i + j - 1)$: $\kappa_\infty$ is 748 for the $3 \times 3$ case and 28,375 for the $4 \times 4$ case, and it keeps exploding.

### Residuals can mislead

For a computed solution $\hat{\mathbf{x}}$ the **residual** is $\mathbf{r} = \mathbf{b} - \mathbf{A}\hat{\mathbf{x}}$. Since $\mathbf{x} - \hat{\mathbf{x}} = \mathbf{A}^{-1}\mathbf{r}$, we get
$$\frac{\lVert \mathbf{x} - \hat{\mathbf{x}} \rVert}{\lVert \mathbf{x} \rVert} \le \kappa(\mathbf{A}) \frac{\lVert \mathbf{r} \rVert}{\lVert \mathbf{b} \rVert}.$$
A tiny residual guarantees an accurate solution only when $\kappa$ is small. With $\kappa = 10^{12}$ a solution can satisfy the equations to machine precision and still have no correct digits.

### Digits lost, stability, and what algorithms can do

An algorithm is **backward stable** if the answer it returns is the exact answer to a slightly perturbed problem, with the perturbation of relative size a modest multiple of $u \approx 1.1 \times 10^{-16}$. Gaussian elimination with partial pivoting is backward stable in practice (its worst-case growth is a known theoretical exception that almost never occurs). Combining this with the bound above gives the rule of thumb: the relative error of the solution is about $\kappa(\mathbf{A})\, u$, so you lose about $\log_{10}\kappa$ of your 16 decimal digits. With $\kappa = 10^{6}$ expect about 10 correct digits.

Two things should be kept apart. **Conditioning** belongs to the problem: if it is bad, no algorithm helps. **Stability** belongs to the algorithm: a well-conditioned problem can still be ruined by an unstable method. A classic example is the variance. The formula $\frac{1}{n}\sum x_i^2 - \bar{x}^2$ is exact in real arithmetic, but for the three values $10^8 + 1, 10^8 + 2, 10^8 + 3$ the two terms are near $10^{16}$, where doubles are spaced 2 apart, and the computed difference is 0.0 instead of $2/3$. The **two-pass** formula $\frac1n \sum (x_i - \bar{x})^2$ subtracts first, when the numbers are still exact, and returns 0.6667. Problem unchanged, algorithm better.

### Measuring the effect

To measure how the error grows with $\kappa$, build a family of systems with a known solution, solve each, and compare the computed answer with the truth. Plot (or tabulate) relative error against $\kappa$ on logarithmic axes: the points should rise roughly along a line of slope 1, until the error reaches 1 at $\kappa \approx 1/u \approx 10^{16}$, where nothing is left. Rounding makes single points scatter, so measure the perturbation amplification as well, which is far less noisy.

```python
def amplification(eps, delta):
    """Relative change in x per relative change in b for A_eps x = b."""
    a, b = [[1.0, 1.0], [1.0, 1.0 + eps]], [2.0, 2.0 + eps]
    def solve2(rhs):
        det = a[0][0] * a[1][1] - a[0][1] * a[1][0]
        x1 = (rhs[0] * a[1][1] - a[0][1] * rhs[1]) / det
        x2 = (a[0][0] * rhs[1] - a[1][0] * rhs[0]) / det
        return [x1, x2]
    x, x2 = solve2(b), solve2([b[0], b[1] + delta])
    dx = max(abs(p - q) for p, q in zip(x, x2)) / max(abs(v) for v in x)
    db = delta / max(abs(v) for v in b)
    return dx / db

for eps in (0.1, 0.01, 0.001):
    print(eps, round(amplification(eps, 1e-6), 1), round((2 + eps) ** 2 / eps, 1))
```

@example
title: A condition number and its bound
problem: Compute $\kappa_\infty$ for $\mathbf{A} = \begin{bmatrix} 2 & 1 \\ 1 & 1 \end{bmatrix}$ and bound the relative error in $\mathbf{x}$ when $\mathbf{b}$ has a relative error of $10^{-8}$.
step: The inverse of a $2 \times 2$ matrix is $\frac{1}{\det}\begin{bmatrix} d & -b \\ -c & a \end{bmatrix}$; here $\det = 2\cdot1 - 1\cdot1 = 1$, so $\mathbf{A}^{-1} = \begin{bmatrix} 1 & -1 \\ -1 & 2 \end{bmatrix}$.
step: Row sums of absolute values: $\lVert \mathbf{A} \rVert_\infty = \max(3, 2) = 3$ and $\lVert \mathbf{A}^{-1} \rVert_\infty = \max(2, 3) = 3$, so $\kappa_\infty = 9$.
step: The bound gives $\lVert \delta\mathbf{x} \rVert / \lVert \mathbf{x} \rVert \le 9 \times 10^{-8}$.
answer: $\kappa_\infty = 9$; the relative error of $\mathbf{x}$ is at most $9 \times 10^{-8}$.

@example
title: Variance in two ways
problem: Compute the population variance of $10^8 + 1, 10^8 + 2, 10^8 + 3$ by $\operatorname{mean}(x^2) - \operatorname{mean}(x)^2$ and by the two-pass formula, and say which is right.
step: Exactly, the mean is $10^8 + 2$ and the deviations are $-1, 0, 1$, so the variance is $2/3$.
step: Naive: $\operatorname{mean}(x^2) \approx 1.00000004 \times 10^{16}$ and $\operatorname{mean}(x)^2$ is nearly the same number. Doubles near $10^{16}$ are 2 apart, so the true difference $2/3$ is smaller than the spacing; Python's result is $0.0$.
step: Two-pass: subtract the mean first. The deviations $-1, 0, 1$ are computed exactly, their squares sum to 2, and $2/3 = 0.6667$.
answer: The two-pass formula is right (0.6667); the naive formula returns 0.0 because of cancellation.

@mistakes
- Judging accuracy by the residual alone: with a large condition number the residual can be tiny while the solution is far off.
- Blaming the algorithm for an ill-conditioned problem: no algorithm can recover digits that the data and the rounding of its entries already destroyed.
- Taking the determinant as a measure of conditioning: scaling a matrix by 0.1 changes its determinant a lot but leaves $\kappa$ unchanged.
- Treating $\kappa$ as an exact prediction: it is a worst-case bound, and the actual error is often smaller.

```python
def cond_inf_2x2(A):
    """Infinity-norm condition number of a 2x2 matrix."""
    (a, b), (c, d) = A
    det = a * d - b * c
    if det == 0:
        raise ValueError("singular matrix")
    inv = [[d / det, -b / det], [-c / det, a / det]]

    def norm(M):
        return max(abs(M[0][0]) + abs(M[0][1]), abs(M[1][0]) + abs(M[1][1]))

    return norm(A) * norm(inv)
```
hint: Compute the determinant and the inverse, then multiply the two largest absolute row sums.
solution: The norm is the maximum over rows of the sum of absolute entries, applied to $\mathbf{A}$ and to its inverse. The scaled diagonal matrix in the fifth test shows that $\kappa$ measures the ratio of the largest to smallest stretch, not the size of the entries.

model:
```python
def amplification_2x2(A, b, db):
    """Relative change of x per relative change of b for a 2x2 system."""
    (p, q), (r, s) = A
    det = p * s - q * r
    if det == 0:
        raise ValueError("singular matrix")

    def solve2(rhs):
        return [(rhs[0] * s - q * rhs[1]) / det, (p * rhs[1] - r * rhs[0]) / det]

    x = solve2(b)
    dx = solve2(db)
    rel_x = max(abs(v) for v in dx) / max(abs(v) for v in x)
    rel_b = max(abs(v) for v in db) / max(abs(v) for v in b)
    return rel_x / rel_b
```
hint: Write a small `solve2` helper using Cramer's rule, call it on `b` and on `db`, and form the two relative sizes with the maximum absolute value as the norm.
solution: Because the system is linear, the change in the solution is exactly the solution for the perturbation `db`, so no subtraction of nearly equal solutions is needed. The ratio of the two relative sizes never exceeds $\kappa_\infty$, and for the nearly singular matrix in the fifth test it is about 2001 (the article's $(2+\varepsilon)/\varepsilon$ with $\varepsilon = 0.001$).

```python
def variance(xs):
    """Population variance by the two-pass algorithm."""
    n = len(xs)
    mean = sum(xs) / n
    return sum((x - mean) ** 2 for x in xs) / n
```
hint: Compute `mean` first, then average `(x - mean) ** 2`; do not use the mean of the squares.
solution: Subtracting the mean first leaves small deviations that are computed exactly, so the squares are accurate. The formula $\operatorname{mean}(x^2) - \operatorname{mean}(x)^2$ returns 2.0 instead of 3.5 for the third test, which the tolerance of $10^{-6}$ rejects.

@article
A bank wants to explain a loan decision to a customer in a way a person can follow: "income below this value, then debt above that value, so decline." A **decision tree** produces exactly such rules: it asks a sequence of yes-or-no questions about single features and ends in a prediction. Trees handle numeric and categorical features, need no feature scaling, and capture interactions between features. This week we grow one by hand and in code; the next two weeks combine many trees into some of the most accurate tabular models.

### Impurity

At each node the tree holds a set of training examples. For classes with proportions $p_1, \dots, p_K$ in the node, two standard measures of how mixed it is are

$$G = 1 - \sum_k p_k^2 \quad\text{(Gini impurity)}, \qquad H = -\sum_k p_k \log_2 p_k \quad\text{(entropy, in bits)}.$$

Both are 0 for a pure node and largest when the classes are evenly mixed: a node of 4 zeros and 4 ones has $G = 0.5$ and $H = 1$ bit. A node with proportions $(6/8, 2/8)$ has $G = 0.375$. Why not simply count the misclassification rate $1 - \max_k p_k$? It is blunt: from a parent with 4 examples of each class, a split into $(3, 1)$ and $(1, 3)$ and a split into $(4, 2)$ and $(0, 2)$ both leave an error rate of $2/8$, although the second produced a pure child. Their weighted Gini impurities are $0.375$ and $0.333$, so Gini prefers the second. Gini and entropy are smooth and strictly concave in $p$, so they credit any split that makes the children purer, and they are the criteria used by CART (Breiman, Friedman, Olshen and Stone) and by the ID3 and C4.5 family.

### Choosing a split

A candidate split asks "is feature $j$ at most $t$?". It sends $n_L$ of the $n$ examples left and $n_R$ right. Its **weighted impurity** is $\frac{n_L}{n}I(\text{left}) + \frac{n_R}{n}I(\text{right})$, and the **gain** is the parent's impurity minus this (with entropy, the gain is called **information gain**). For a numeric feature only thresholds halfway between consecutive distinct values matter, so the search tries each feature and each midpoint, computing impurities from class counts. With $n$ examples and $p$ features this costs about $O(p\,n\log n)$ per node if the feature is sorted once, and $O(p\,n^2)$ in the simple implementation below.

The tree is **grown greedily**: take the best split at the root, then recurse on each side, stopping when a node is pure, has too few examples, or reaches a maximum depth. A leaf predicts its majority class (or its class proportions). Greedy growth does not find the best tree overall, only a good one.

Take eight points $(x_1, x_2)$: $(1,2), (2,3), (3,1), (4,4), (5,2), (6,5), (3,5), (5,4)$ with classes $0,0,0,1,1,1,1,0$. The root has $G = 0.5$. The best split is $x_1 \le 2.5$: the left side holds two class-0 points (pure), the right six points $(0,1,1,1,1,0)$ have $G = 0.444$, and the weighted impurity is $\frac{6}{8}(0.444) = 0.333$, a gain of $0.167$. With entropy the same split gives a weighted entropy of $\frac{6}{8}(0.918) = 0.689$ bits and an information gain of $0.311$ bits. Continuing without a depth limit separates every point from the points of the other class: six leaves and zero training error.

### Overfitting and pruning

A fully grown tree can memorize noise: it has zero training error whenever no two examples with different labels share all features. Two controls exist. **Pre-pruning** stops growth early (maximum depth, minimum examples per leaf, minimum gain). **Post-pruning** grows a large tree and cuts it back. The standard method is **cost-complexity pruning**: for a penalty $\alpha \ge 0$ minimize

$$R_\alpha(T) = R(T) + \alpha\,|T|,$$

where $R(T)$ is the training misclassification rate of tree $T$ and $|T|$ its number of leaves. For an internal node $t$ with subtree $T_t$, collapsing $T_t$ to a single leaf raises the error from $R(T_t)$ to $R(t)$ and removes $|T_t| - 1$ leaves, so it pays off once

$$\alpha \ge \alpha_{\text{eff}}(t) = \frac{R(t) - R(T_t)}{|T_t| - 1}.$$

**Weakest-link pruning** repeatedly collapses the node with the smallest $\alpha_{\text{eff}}$, producing a nested sequence of trees; $\alpha$ is then chosen by cross-validation (week 12). For the eight-point tree the sequence is:

| tree | leaves | training error | pruned at $\alpha_{\text{eff}}$ |
|---|---|---|---|
| full | 6 | 0 | $0.042$ |
| 1 | 3 | $1/8$ | $0.125$ |
| 2 | 2 | $2/8$ | $0.25$ |
| 3 | 1 | $4/8$ | |

### In code

```python
X = [[1, 2], [2, 3], [3, 1], [4, 4], [5, 2], [6, 5], [3, 5], [5, 4]]
y = [0, 0, 0, 1, 1, 1, 1, 0]

def gini(labels):
    n = len(labels)
    if n == 0:
        return 0.0
    return 1 - sum((labels.count(c) / n) ** 2 for c in set(labels))

def best_split(X, y):
    n = len(y)
    best = None
    for j in range(len(X[0])):
        values = sorted(set(row[j] for row in X))
        for lo, hi in zip(values, values[1:]):
            t = (lo + hi) / 2
            left = [c for row, c in zip(X, y) if row[j] <= t]
            right = [c for row, c in zip(X, y) if row[j] > t]
            score = (len(left) * gini(left) + len(right) * gini(right)) / n
            if best is None or score < best[2] - 1e-12:
                best = (j, t, score)
    return best

def majority(labels):
    return max(sorted(set(labels)), key=labels.count)

def build(X, y, depth=0, max_depth=3):
    split = best_split(X, y)
    if gini(y) == 0 or depth == max_depth or split is None:
        return majority(y)
    j, t, _ = split
    L = [i for i, row in enumerate(X) if row[j] <= t]
    R = [i for i, row in enumerate(X) if row[j] > t]
    return (j, t,
            build([X[i] for i in L], [y[i] for i in L], depth + 1, max_depth),
            build([X[i] for i in R], [y[i] for i in R], depth + 1, max_depth))

def predict(tree, x):
    while isinstance(tree, tuple):
        j, t, left, right = tree
        tree = left if x[j] <= t else right
    return tree

print(best_split(X, y))
tree = build(X, y, max_depth=2)
print(tree)
print([predict(tree, row) for row in X])
```

A leaf is a class label and an internal node is the tuple `(feature, threshold, left, right)`. With depth limited to 2 the tree is `(0, 2.5, 0, (1, 1.5, 0, 1))` and misclassifies only the point $(5, 4)$. Libraries add pruning, categorical splits and faster sorting, but the core is these forty lines.

@example
title: Finding the best split on one feature
problem: Six examples have a single feature $x = 1, 2, 3, 4, 5, 6$ and classes $0, 0, 1, 0, 1, 1$. Find the threshold that minimizes weighted Gini impurity.
step: The root has three of each class, so $G = 0.5$. The candidate thresholds are $1.5, 2.5, 3.5, 4.5, 5.5$.
step: For $x \le 2.5$ the left side $(0, 0)$ has $G = 0$ and the right side $(1, 0, 1, 1)$ has $G = 1 - (0.25^2 + 0.75^2) = 0.375$. Weighted: $\frac{4}{6}(0.375) = 0.25$.
step: For $x \le 4.5$ the left side $(0, 0, 1, 0)$ has $G = 0.375$ and the right side $(1, 1)$ is pure: weighted $\frac{4}{6}(0.375) = 0.25$ again.
step: The other thresholds are worse: $1.5$ and $5.5$ give $0.4$, and $3.5$ gives $\frac{3}{6}(0.444) + \frac{3}{6}(0.444) = 0.444$.
step: Two thresholds tie at $0.25$, a gain of $0.5 - 0.25 = 0.25$. Taking the first (lowest) threshold gives $x \le 2.5$.
answer: The best weighted impurity is $0.25$, at $x \le 2.5$ (tied with $x \le 4.5$).

@example
title: Which subtree is pruned first?
problem: On 100 training examples, subtree $A$ has 3 leaves and misclassifies 2 examples; collapsed to a leaf it would misclassify 8. Subtree $B$ has 2 leaves and misclassifies 5; collapsed it would misclassify 9. Compute $\alpha_{\text{eff}}$ for each and say which is pruned first.
step: Use $\alpha_{\text{eff}} = \dfrac{R(t) - R(T_t)}{|T_t| - 1}$, where the errors are fractions of the 100 examples.
step: For $A$: $R(t) = 0.08$, $R(T_t) = 0.02$, $|T_t| - 1 = 2$, so $\alpha_{\text{eff}} = 0.06/2 = 0.03$.
step: For $B$: $R(t) = 0.09$, $R(T_t) = 0.05$, $|T_t| - 1 = 1$, so $\alpha_{\text{eff}} = 0.04/1 = 0.04$.
step: Weakest-link pruning collapses the node with the smallest $\alpha_{\text{eff}}$. Subtree $A$ is cut first, at $\alpha = 0.03$, because it buys the least training accuracy per leaf.
answer: $\alpha_{\text{eff}}(A) = 0.03 < \alpha_{\text{eff}}(B) = 0.04$, so $A$ is pruned first.

@mistakes
- Choosing the split that minimizes the children's impurity without weighting by their sizes: a tiny pure child would then look better than a balanced split.
- Trying thresholds at the data values instead of between them, or considering many thresholds that give the same partition.
- Reporting training accuracy of an unpruned tree as its quality: a tree grown to purity has zero training error almost always.
- Treating tree growth as optimal: each split is chosen greedily, and a slightly worse first split can lead to a better tree.

```python
    if n == 0:
        return 0.0
```

```python
def split_gain(parent, left, right):
    """Parent impurity minus the weighted impurity of the two children."""
    n = len(left) + len(right)
    weighted = (len(left) * gini(left) + len(right) * gini(right)) / n
```

```python
from math import log2

def entropy(labels):
    n = len(labels)
    return -sum(labels.count(c) / n * log2(labels.count(c) / n)
                for c in set(labels)) if n else 0.0

def best_split_entropy(X, y, min_leaf):
    """Split with the largest information gain and big enough children."""
    n = len(y)
    parent = entropy(y)
    best = None
    for j in range(len(X[0])):
        values = sorted(set(row[j] for row in X))
        for lo, hi in zip(values, values[1:]):
            t = (lo + hi) / 2
            left = [c for row, c in zip(X, y) if row[j] <= t]
            right = [c for row, c in zip(X, y) if row[j] > t]
            if len(left) < min_leaf or len(right) < min_leaf:
                continue
            gain = parent - (len(left) * entropy(left)
                             + len(right) * entropy(right)) / n
            if best is None or gain > best[2] + 1e-12:
                best = (j, t, gain)
    return best
```
hint: Loop over features and midpoints as in the Gini search, but skip a candidate whose child is smaller than `min_leaf`, and keep the largest gain instead of the smallest impurity.
solution: Maximizing the gain is the same as minimizing the weighted child entropy, since the parent's entropy is fixed. The `min_leaf` constraint changes the answer: with one positive example at the left end, an unconstrained search isolates it at $1.5$, but requiring two examples per child moves the threshold to $2.5$, and requiring three leaves no allowed split on five examples. The first test is a tie between the two features, which the strict-improvement rule resolves toward feature 0.

```python
def gini(labels):
    n = len(labels)
    if n == 0:
        return 0.0
    return 1 - sum((labels.count(c) / n) ** 2 for c in set(labels))

def best_split(X, y):
    n = len(y)
    best = None
    for j in range(len(X[0])):
        values = sorted(set(row[j] for row in X))
        for lo, hi in zip(values, values[1:]):
            t = (lo + hi) / 2
            left = [c for row, c in zip(X, y) if row[j] <= t]
            right = [c for row, c in zip(X, y) if row[j] > t]
            score = (len(left) * gini(left) + len(right) * gini(right)) / n
            if best is None or score < best[2] - 1e-12:
                best = (j, t, score)
    return best

def majority(labels):
    return max(sorted(set(labels)), key=labels.count)

def build_tree(X, y, max_depth, min_samples):
    """Grow a tree of nested tuples; leaves are class labels."""
    split = best_split(X, y)
    if (gini(y) == 0 or max_depth == 0 or len(y) < min_samples
            or split is None):
        return majority(y)
    j, t, _ = split
    L = [i for i, row in enumerate(X) if row[j] <= t]
    R = [i for i, row in enumerate(X) if row[j] > t]
    return (j, t,
            build_tree([X[i] for i in L], [y[i] for i in L],
                       max_depth - 1, min_samples),
            build_tree([X[i] for i in R], [y[i] for i in R],
                       max_depth - 1, min_samples))

def count_leaves(tree):
    """Number of leaves of a tree of nested tuples."""
    if not isinstance(tree, tuple):
        return 1
    return count_leaves(tree[2]) + count_leaves(tree[3])
```
hint: Check the stopping conditions first, including `len(y) < min_samples`; otherwise split with `best_split` and recurse on each side with `max_depth - 1`. A tree that is not a tuple has one leaf.
solution: Counting depth down from `max_depth` is the simplest way to enforce the limit, and `min_samples` is a second pre-pruning rule: with seven alternating labels on a line the unrestricted tree has seven leaves, and raising `min_samples` stops the recursion in the small nodes, giving six and then five. The test with identical features checks that a node without any valid split becomes a leaf.

@article
Many lines separate two classes of points, and some are clearly better than others: a line that grazes one class will misclassify a new point that lands slightly off. The **support vector machine** (SVM; Cortes and Vapnik, 1995, building on Vapnik and Chervonenkis's earlier work on maximum-margin classifiers) picks the line farthest from both classes.

### Margins

Use labels $y_i \in \{-1, +1\}$ and a linear classifier $f(\mathbf{x}) = \mathbf{w}^\top\mathbf{x} + b$ that predicts $\operatorname{sign}(f(\mathbf{x}))$. The **functional margin** of example $i$ is $y_i f(\mathbf{x}_i)$: positive when it is classified correctly. The signed distance from $\mathbf{x}_i$ to the hyperplane $f = 0$ is the **geometric margin** $y_i f(\mathbf{x}_i)/\lVert\mathbf{w}\rVert_2$. For $\mathbf{w} = (3, 4)$ and $b = -5$, the point $(4, 3)$ has $f = 19$ and distance $19/5 = 3.8$.

Scaling $(\mathbf{w}, b)$ by any positive constant leaves the hyperplane unchanged, so we may fix the scale by requiring the closest points to have $y_i f(\mathbf{x}_i) = 1$. The distance from the hyperplane to the closest point of each class is then $1/\lVert\mathbf{w}\rVert$, and the gap between the two classes is $2/\lVert\mathbf{w}\rVert$.

### Hard and soft margins

For separable data the **hard-margin SVM** maximizes the gap, which is the same as minimizing $\tfrac{1}{2}\lVert\mathbf{w}\rVert^2$ subject to $y_i(\mathbf{w}^\top\mathbf{x}_i + b) \ge 1$ for all $i$. This is a convex quadratic program with a unique solution. With six points $(3,2), (4,4), (5,3)$ labeled $+1$ and $(1,1), (0,2), (1,0)$ labeled $-1$, the solution is $\mathbf{w} = (0.8, 0.4)$ and $b = -2.2$, a gap of $2/0.894 = 2.236$. Only $(3, 2)$ and $(1, 1)$ touch the margin ($y f = 1$); every other point has $y f \ge 1.4$ and could be moved or deleted without changing the answer.

Real data are rarely separable. The **soft-margin SVM** lets points violate the margin and pays for it with the **hinge loss** $\max(0, 1 - y_i f(\mathbf{x}_i))$:

$$J(\mathbf{w}, b) = \tfrac{1}{2}\lVert\mathbf{w}\rVert^2 + C\sum_{i=1}^{n}\max\big(0,\, 1 - y_i(\mathbf{w}^\top\mathbf{x}_i + b)\big).$$

The hyperparameter $C > 0$ trades margin width against violations. Large $C$ punishes violations heavily and gives a narrow margin that fits the training set closely; small $C$ tolerates violations in exchange for a wide margin, which acts as regularization. The term $\tfrac{1}{2}\lVert\mathbf{w}\rVert^2$ is exactly the ridge penalty, so an SVM is a linear model with hinge loss and L2 regularization; logistic regression has the same form with log loss.

### Training by subgradient descent

The hinge loss has a kink at margin 1, so $J$ is convex but not differentiable everywhere. A **subgradient** is any slope of a line that stays below the function; at a kink there are many, and any works. For example $i$ with $y_i f(\mathbf{x}_i) < 1$ the hinge term has gradient $-y_i\mathbf{x}_i$ in $\mathbf{w}$ and $-y_i$ in $b$; for $y_i f(\mathbf{x}_i) \ge 1$ it contributes 0 (we use 0 at exactly 1). The subgradient of $J$ is

$$\mathbf{g}_{\mathbf{w}} = \mathbf{w} - C\sum_{i \in V} y_i\mathbf{x}_i, \qquad g_b = -C\sum_{i\in V} y_i, \qquad V = \{i : y_i f(\mathbf{x}_i) < 1\}.$$

On the six points above, with $C = 1$ and step size $0.01$ from $\mathbf{w} = \mathbf{0}$, the objective falls from $6$ to $4.647$ after one step, $0.918$ after 100, and $0.402$ after 500, close to the optimum $0.4$. With a constant step the iterates keep jittering around the optimum, so practical solvers shrink the step over time (as the Pegasos algorithm does).

### The dual and support vectors

Introducing a multiplier $\alpha_i \ge 0$ for each constraint gives the dual problem, whose solution satisfies

$$\mathbf{w} = \sum_{i=1}^{n}\alpha_i y_i\mathbf{x}_i, \qquad \sum_i \alpha_i y_i = 0, \qquad 0 \le \alpha_i \le C.$$

Only examples on or inside the margin have $\alpha_i > 0$: these are the **support vectors**. In the example, $\alpha = 0.4$ for $(3,2)$ and for $(1,1)$ and 0 elsewhere: $0.4\cdot(3,2) - 0.4\cdot(1,1) = (0.8, 0.4)$, and the labels balance. The prediction $f(\mathbf{x}) = \sum_i\alpha_i y_i\,\mathbf{x}_i^\top\mathbf{x} + b$ uses the data only through dot products. Next week this observation lets us replace the dot product with a kernel.

### In code

```python
X = [[3, 2], [4, 4], [1, 1], [0, 2], [5, 3], [1, 0]]
y = [1, 1, -1, -1, 1, -1]

def score(w, b, row):
    return sum(wj * xj for wj, xj in zip(w, row)) + b

def objective(X, y, w, b, C):
    hinge = sum(max(0.0, 1 - t * score(w, b, r)) for r, t in zip(X, y))
    return 0.5 * sum(wj * wj for wj in w) + C * hinge

def subgradient(X, y, w, b, C):
    gw = list(w)
    gb = 0.0
    for r, t in zip(X, y):
        if t * score(w, b, r) < 1:
            for j in range(len(w)):
                gw[j] -= C * t * r[j]
            gb -= C * t
    return gw, gb

w, b = [0.0, 0.0], 0.0
for step in range(1, 501):
    gw, gb = subgradient(X, y, w, b, 1.0)
    w = [wj - 0.01 * g for wj, g in zip(w, gw)]
    b -= 0.01 * gb
    if step in (1, 10, 100, 500):
        print(step, [round(v, 4) for v in w], round(b, 3),
              round(objective(X, y, w, b, 1.0), 4))
```

Libraries solve the dual with specialized quadratic-programming methods (sequential minimal optimization), but the objective they minimize is the one above.

@example
title: Finding the maximum-margin line by hand
problem: Positive points $(3, 0)$ and $(4, 2)$; negative points $(1, 0)$ and $(0, -1)$. Find the hard-margin classifier $\mathbf{w}, b$ and the gap between the classes.
step: Look for the closest opposite pair: $(3, 0)$ and $(1, 0)$ are $2$ apart; every other pair is farther. Guess that these two are the support vectors.
step: The weight vector points along the line joining the support vectors, $(3, 0) - (1, 0) = (2, 0)$, so $\mathbf{w} = (a, 0)$. The constraints $y f = 1$ give $3a + b = 1$ and $-(a + b) = 1$, so $a = 1$ and $b = -2$.
step: Check the other points: $(4, 2)$ gives $f = 4 - 2 = 2 \ge 1$ and $(0, -1)$ gives $f = -2$, so $y f = 2 \ge 1$. Both satisfy the constraints, so the guess is right.
step: The gap is $2/\lVert\mathbf{w}\rVert = 2$, with boundary $x_1 = 2$ halfway between the support vectors.
answer: $\mathbf{w} = (1, 0)$, $b = -2$, gap $2$; the support vectors are $(3, 0)$ and $(1, 0)$.

@example
title: One subgradient step
problem: Points $(1, 1)$ with $y = +1$, $(-1, 0)$ with $y = -1$ and $(2, -1)$ with $y = +1$. With $C = 1$, start at $\mathbf{w} = (0, 0)$, $b = 0$, take one subgradient step of size $0.1$, and compare the objective before and after.
step: At the start every score is 0, so every $y f = 0 < 1$ and all three points are in $V$. The objective is $0 + 1 \cdot 3 = 3$.
step: Compute $\sum y_i\mathbf{x}_i = (1, 1) + (1, 0) + (2, -1) = (4, 0)$ and $\sum y_i = 1 - 1 + 1 = 1$.
step: The subgradient is $\mathbf{g}_{\mathbf{w}} = \mathbf{0} - (4, 0) = (-4, 0)$ and $g_b = -1$.
step: Update: $\mathbf{w} = (0.4, 0)$ and $b = 0.1$.
step: The margins are $y f = 0.5$, $0.3$ and $0.9$, all still below 1, so the hinge terms are $0.5 + 0.7 + 0.1 = 1.3$. Add $\tfrac{1}{2}\lVert\mathbf{w}\rVert^2 = 0.08$: the objective is $1.38$.
answer: After the step $\mathbf{w} = (0.4, 0)$, $b = 0.1$, and the objective fell from $3$ to $1.38$.

@mistakes
- Using labels $0/1$ with the hinge loss: the margin formula $y f$ needs $-1/+1$ labels.
- Treating $C$ like a regularization strength: it is the inverse. Small $C$ means strong regularization and a wide margin.
- Forgetting the bias in the gradient, or regularizing it: here $b$ is not in $\lVert\mathbf{w}\rVert^2$ and its gradient comes only from the hinge terms.
- Computing the violating set with $\le 1$ instead of $< 1$: a point exactly on the margin contributes zero loss and no gradient.

```python
def total_hinge(X, y, w, b):
    """Sum of hinge losses of the linear classifier (w, b)."""
    total = 0.0
    for row, t in zip(X, y):
        f = sum(wj * xj for wj, xj in zip(w, row)) + b
        total += max(0.0, 1 - t * f)
    return total
```
hint: For each example compute $f = \mathbf{w}^\top\mathbf{x} + b$, then add $\max(0, 1 - y f)$.
solution: Correctly classified points beyond the margin contribute zero, which the `max` handles. The third test has a margin of at least 1 at every point, so the total is zero; the last test uses a classifier that is wrong on the first three points and exactly on the boundary for the fourth, and pays $3 + 2 + 2 + 1$.

```python
def sq_hinge_gradient(X, y, w, b, C):
    """Gradient of the squared-hinge SVM objective at (w, b)."""
    gw = list(w)
    gb = 0.0
    for row, t in zip(X, y):
        f = sum(wj * xj for wj, xj in zip(w, row)) + b
        slack = 1 - t * f
        if slack > 0:
            for j in range(len(w)):
                gw[j] -= 2 * C * slack * t * row[j]
            gb -= 2 * C * slack * t
    return gw, gb
```
hint: The regularizer contributes `w`. For a violator with slack $s = 1 - y f > 0$, the derivative of $s^2$ with respect to $f$ is $-2 s y$, so subtract $2 C s\,y\,\mathbf{x}$ from `gw` and $2 C s\,y$ from `gb`.
solution: The squared hinge $\max(0, s)^2$ has derivative $2s$ times $\partial s/\partial \mathbf{w} = -y\mathbf{x}$ when $s > 0$ and 0 otherwise, so each violator's term is weighted by its slack, unlike the plain hinge where every violator counts the same. In the second test one example sits exactly on the margin and contributes nothing; a version that drops the factor of slack or the factor 2 gives a different answer.

model:
```python
def train_svm(X, y, C, lr, steps):
    """Soft-margin linear SVM by subgradient descent from zero."""
    w = [0.0] * len(X[0])
    b = 0.0
    for _ in range(steps):
        gw = list(w)
        gb = 0.0
        for row, t in zip(X, y):
            f = sum(wj * xj for wj, xj in zip(w, row)) + b
            if t * f < 1:
                for j in range(len(w)):
                    gw[j] -= C * t * row[j]
                gb -= C * t
        w = [wj - lr * g for wj, g in zip(w, gw)]
        b -= lr * gb
    return w, b
```
hint: In each step compute the subgradient at the current `(w, b)` first, and only then update both `w` and `b`.
solution: Each step computes the subgradient $\mathbf{g}_{\mathbf{w}} = \mathbf{w} - C\sum_{i\in V} y_i\mathbf{x}_i$, $g_b = -C\sum_{i\in V} y_i$ at the current weights, followed by $\mathbf{w} \leftarrow \mathbf{w} - \eta\mathbf{g}_{\mathbf{w}}$ and $b \leftarrow b - \eta g_b$. After two steps the weights are $0.38$ each, as a hand calculation shows; at step four the margins exceed 1, so only the shrinking term acts and the weights fall to $0.4878$.

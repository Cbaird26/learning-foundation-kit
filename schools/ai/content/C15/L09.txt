@article
Bagging averaged many deep trees to cut variance. **Boosting** goes the opposite way: it adds many very small trees, one after another, each correcting the mistakes of the ensemble so far. Early boosting, AdaBoost (Freund and Schapire, 1997), reweighted the examples the ensemble got wrong. Friedman, Hastie and Tibshirani (2000) showed that AdaBoost builds an additive model by stagewise minimization of an exponential loss, and Friedman (2001) turned this view into **gradient boosting**: a form of gradient descent in the space of functions that works for any differentiable loss.

### Gradient descent on functions

We build a model $F(\mathbf{x})$ stage by stage, starting from a constant $F_0$ and setting

$$F_m(\mathbf{x}) = F_{m-1}(\mathbf{x}) + \nu\, h_m(\mathbf{x}),$$

where $h_m$ is a small tree and $\nu \in (0, 1]$ is the **learning rate** (or shrinkage). How should $h_m$ be chosen? The training loss $\sum_i \ell(y_i, F(\mathbf{x}_i))$ depends on the model only through its values $F_i$ at the training points. Treat those $n$ values as parameters: gradient descent would move each by $-\eta\,\partial\ell/\partial F_i$. So compute the **pseudo-residual** at each example,

$$r_{im} = -\left.\frac{\partial \ell(y_i, F)}{\partial F}\right|_{F = F_{m-1}(\mathbf{x}_i)},$$

and fit $h_m$ by least squares to the pairs $(\mathbf{x}_i, r_{im})$. The tree is a smooth version of the ideal gradient step: it moves similar points the same way, and it can be evaluated at new points.

For squared error $\ell = \tfrac{1}{2}(y - F)^2$ the negative gradient is $y - F$, the ordinary residual. For logistic loss with $F$ the log-odds and $p = \sigma(F)$, the negative gradient is $y - p$ for $y \in \{0, 1\}$: at $F = 0.8$ and $y = 1$ it is $1 - 0.690 = 0.310$. For absolute error it is $\operatorname{sign}(y - F)$. Friedman's method also re-optimizes the value in each leaf, with a Newton step for logistic loss; fitting the mean of the residuals, as below, is the simplest version.

### The algorithm

1. Start from $F_0 = \bar{y}$ (for squared error, the best constant).
2. For $m = 1, \dots, M$: compute the residuals $r_{im} = y_i - F_{m-1}(\mathbf{x}_i)$, fit a small regression tree $h_m$ to them, and set $F_m = F_{m-1} + \nu h_m$.

A **regression stump** (a tree with one split) predicts the mean residual on each side of a threshold, chosen to minimize the sum of squared errors. Each tree is a **weak learner**: slightly better than nothing. The sum of many of them is flexible, because each round fits whatever structure the earlier rounds missed.

### An example

Six points $x = 1, \dots, 6$ have targets $1, 2, 1.5, 5, 6, 5.5$, whose mean is $3.5$. Boosting stumps with $\nu = 0.5$:

| round | split | left value | right value | training MSE |
|---|---|---|---|---|
| 0 | | | | $4.167$ |
| 1 | $x \le 3.5$ | $-2.0$ | $+2.0$ | $1.167$ |
| 2 | $x \le 3.5$ | $-1.0$ | $+1.0$ | $0.417$ |
| 3 | $x \le 4.5$ | $-0.375$ | $0.75$ | $0.206$ |
| 4 | $x \le 1.5$ | $-0.8125$ | $0.1625$ | $0.107$ |
| 5 | $x \le 3.5$ | $-0.231$ | $0.231$ | $0.067$ |
| 6 | $x \le 1.5$ | $-0.291$ | $0.058$ | $0.054$ |

Round 1 finds the big jump between $x = 3$ and $x = 4$. Round 2 finds it again, because $\nu = 0.5$ took only half the correction. Later rounds chase finer detail, and the training error keeps falling, which is why the number of rounds matters.

### Controlling overfitting

Boosting reduces **bias**, and enough rounds will fit the training set arbitrarily well, so it can overfit. The controls are: a small learning rate (many small steps generalize better than few large ones, at the price of more rounds), the number of rounds $M$ (chosen with validation data, stopping when validation error stops falling: **early stopping**), the depth of each tree (stumps give additive models; depth $d$ allows interactions of order $d$), and subsampling the rows for each tree. Compare bagging: it averages independent deep trees to reduce variance; boosting adds dependent shallow trees to reduce bias.

### In code

```python
x = [1, 2, 3, 4, 5, 6]
y = [1.0, 2.0, 1.5, 5.0, 6.0, 5.5]

def fit_stump(xs, ys):
    values = sorted(set(xs))
    best = None
    for lo, hi in zip(values, values[1:]):
        t = (lo + hi) / 2
        left = [r for v, r in zip(xs, ys) if v <= t]
        right = [r for v, r in zip(xs, ys) if v > t]
        ml, mr = sum(left) / len(left), sum(right) / len(right)
        sse = (sum((r - ml) ** 2 for r in left)
               + sum((r - mr) ** 2 for r in right))
        if best is None or sse < best[0] - 1e-12:
            best = (sse, t, ml, mr)
    return best[1:]

def stump_predict(stump, v):
    t, ml, mr = stump
    return ml if v <= t else mr

def boost(xs, ys, rounds, lr):
    F = [sum(ys) / len(ys)] * len(ys)
    stumps = []
    for m in range(rounds):
        resid = [t - f for t, f in zip(ys, F)]
        s = fit_stump(xs, resid)
        stumps.append(s)
        F = [f + lr * stump_predict(s, v) for f, v in zip(F, xs)]
        mse = sum((t - f) ** 2 for t, f in zip(ys, F)) / len(ys)
        print(m + 1, s, round(mse, 4))
    return stumps, F

stumps, F = boost(x, y, 6, 0.5)
print([round(f, 3) for f in F])
```

Production libraries add second-order information, regularized leaf values, histogram-based split finding and column sampling, but the loop above is the core. Choosing $\nu$, $M$ and the depth by cross-validation is the subject of week 12.

@mistakes
- Fitting each new tree to the original targets instead of the current residuals: the ensemble then just repeats the same tree.
- Using a learning rate of 1 and many rounds, then wondering why validation error rises after a while: use a small rate with early stopping on validation data.
- Using the training error to pick the number of rounds: it falls with every round.
- Forgetting that for classification the pseudo-residuals are $y - \sigma(F)$ with $F$ on the log-odds scale, and averaging probabilities of trees instead of adding scores.

from statistics import median

def fit_median_stump(xs, ys):
    """Best single-threshold stump by absolute error, with median leaves."""
    values = sorted(set(xs))
    best = None
    for lo, hi in zip(values, values[1:]):
        t = (lo + hi) / 2
        left = [r for v, r in zip(xs, ys) if v <= t]
        right = [r for v, r in zip(xs, ys) if v > t]
        ml = median(left)
        mr = median(right)
        cost = (sum(abs(r - ml) for r in left)
                + sum(abs(r - mr) for r in right))
        if best is None or cost < best[0] - 1e-12:
            best = (cost, t, ml, mr)
    if best is None:
        m = median(ys)
        return (xs[0], m, m)
    return best[1:]
```

def fit_reg_stump(xs, ys):
    values = sorted(set(xs))
    best = None
    for lo, hi in zip(values, values[1:]):
        t = (lo + hi) / 2
        left = [r for v, r in zip(xs, ys) if v <= t]
        right = [r for v, r in zip(xs, ys) if v > t]
        ml = sum(left) / len(left)
        mr = sum(right) / len(right)
        sse = (sum((r - ml) ** 2 for r in left)
               + sum((r - mr) ** 2 for r in right))
        if best is None or sse < best[0] - 1e-12:
            best = (sse, t, ml, mr)
    if best is None:
        m = sum(ys) / len(ys)
        return (xs[0], m, m)
    return best[1:]

def best_rounds(xs, ys, xv, yv, lr, max_rounds):
    """Number of rounds with the lowest validation MSE (ties: fewer)."""
    base = sum(ys) / len(ys)
    F = [base] * len(ys)
    Fv = [base] * len(xv)

    def val_mse():
        return sum((t - f) ** 2 for t, f in zip(yv, Fv)) / len(yv)

    best_m = 0
    best_err = val_mse()
    for m in range(1, max_rounds + 1):
        resid = [t - f for t, f in zip(ys, F)]
        thr, a, b = fit_reg_stump(xs, resid)
        F = [f + lr * (a if v <= thr else b) for f, v in zip(F, xs)]
        Fv = [f + lr * (a if v <= thr else b) for f, v in zip(Fv, xv)]
        err = val_mse()
        if err < best_err:
            best_m, best_err = m, err
    return best_m
```

```python
import math

def pseudo_residuals(y, F, loss):
    """Negative gradient of the loss at the current scores."""
    if loss == "squared":
        return [t - f for t, f in zip(y, F)]
    if loss == "logistic":
        out = []
        for t, f in zip(y, F):
            if f >= 0:
                p = 1 / (1 + math.exp(-f))
            else:
                e = math.exp(f)
                p = e / (1 + e)
            out.append(t - p)
        return out
    if loss == "absolute":
        return [(t > f) - (t < f) for t, f in zip(y, F)]
    raise ValueError("unknown loss: " + loss)
```
hint: Handle each loss name separately; for the logistic case use a sigmoid that exponentiates only non-positive numbers.
solution: The three losses give residual, probability error and sign of the error respectively. The sigmoid is computed from `exp(-f)` when `f >= 0` and from `exp(f)` otherwise, so it never overflows; the test at $\pm 800$ fails for the naive formula.

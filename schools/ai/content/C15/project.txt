## Review guide

**Week 1: linear regression.** Model $\hat{y} = \mathbf{w}^\top\mathbf{x}$; loss $\frac{1}{n}\lVert\mathbf{X}\mathbf{w} - \mathbf{y}\rVert^2$; gradient $\frac{2}{n}\mathbf{X}^\top(\mathbf{X}\mathbf{w} - \mathbf{y})$; normal equations $\mathbf{X}^\top\mathbf{X}\mathbf{w} = \mathbf{X}^\top\mathbf{y}$. Gradient descent converges for $\eta < 2/\lambda_{\max}$ and slowly when the condition number is large, so standardize. $R^2 = 1 - \mathrm{SS_{res}}/\mathrm{SS_{tot}}$.

**Week 2: regularization.** Ridge: $(\mathbf{X}^\top\mathbf{X} + \lambda\mathbf{I})^{-1}\mathbf{X}^\top\mathbf{y}$, shrinks by $d^2/(d^2 + \lambda)$ and never gives exact zeros. Lasso: soft thresholding $S(z, \lambda)/a$ in coordinate descent, exact zeros.

**Week 3 and 4: logistic and softmax regression.** Negative log-likelihood, gradient $\frac{1}{n}\mathbf{X}^\top(\mathbf{P} - \mathbf{Y})$ in both cases; loss $\log K$ at zero weights; stable softmax and log-sum-exp; separable data give no finite maximum likelihood estimate; weights are log-odds.

**Week 5 and 6: SVM and kernels.** Margin $2/\lVert\mathbf{w}\rVert$; soft margin $\frac{1}{2}\lVert\mathbf{w}\rVert^2 + C\sum\max(0, 1 - yf)$; support vectors have $\alpha_i > 0$. A kernel is an inner product in a feature space; Gram matrices are positive semidefinite; $\gamma$ and $C$ control flexibility.

**Week 7 and 8: trees, bagging, forests.** Gini $1 - \sum p_k^2$, entropy, weighted impurity of a split, cost-complexity pruning $\alpha_{\text{eff}} = (R(t) - R(T_t))/(|T_t| - 1)$. Averaging $B$ trees with correlation $\rho$ has variance $\rho\sigma^2 + (1 - \rho)\sigma^2/B$; random feature subsets lower $\rho$; OOB error needs no test set.

**Week 9: boosting.** Fit each stump to the negative gradient (residuals for squared loss, $y - \sigma(F)$ for logistic loss) and add it with a learning rate; it reduces bias and needs early stopping.

**Week 10 and 11: probabilities and imbalance.** Calibration, ECE, Brier score, log loss, Platt scaling on held-out data. Confusion matrix, precision, recall, $F_1$, ROC AUC as a ranking probability, average precision, prevalence baseline.

**Week 12: model selection.** K-fold CV, standard error, one-standard-error rule, grid and random search, nested CV, no leakage, one use of the test set.

### Common errors

Forgetting the intercept column; penalizing the intercept; computing softmax or the sigmoid without stabilization; labels $0/1$ in a hinge loss; fitting boosting trees to targets instead of residuals; voting with trees that trained on the example; choosing a threshold or hyperparameter on the test set; standardizing before the split.

model:
```python
def best_f1_threshold(scores, y):
    """Threshold on the scores that maximizes F1, preferring larger ones."""
    best_t = None
    best_f = -1.0
    for t in sorted(set(scores), reverse=True):
        pred = [1 if s >= t else 0 for s in scores]
        tp = sum(1 for a, b in zip(y, pred) if a == 1 and b == 1)
        fp = sum(1 for a, b in zip(y, pred) if a == 0 and b == 1)
        fn = sum(1 for a, b in zip(y, pred) if a == 1 and b == 0)
        f1 = 2 * tp / (2 * tp + fp + fn) if tp else 0.0
        if f1 > best_f + 1e-12:
            best_t, best_f = t, f1
    return best_t, best_f
```
hint: Loop over the distinct scores from high to low, build the predictions, count TP, FP and FN, and keep the best $F_1$ seen so far.
solution: Each threshold gives a confusion matrix and an $F_1$; the search keeps the first maximum met when scanning downward, which is the largest threshold. In the third test thresholds $0.4$ and $0.1$ tie at $2/3$ and the larger one wins. Choosing a threshold this way on the data used to evaluate the model would be optimistic, so in practice use validation data.

After one step with step size 1, what is the Brier score of the new predicted probabilities on the same three examples? Give three decimal places.
answer: 0.218
tol: 0.001
check: (lambda w: sum((1 / (1 + math.exp(-(w[0] + w[1] * x))) - t) ** 2 for x, t in [(0, 0), (2, 0), (4, 1)]) / 3)([0 - 1 * (0.5 + 0.5 - 0.5) / 3, 0 - 1 * (0 * 0.5 + 2 * 0.5 + 4 * (0.5 - 1)) / 3])
hint: At zero weights every probability is $0.5$. The gradient is $\frac{1}{3}\sum(p_i - y_i)\,(1, x_i)$; subtract it, then evaluate the three new probabilities.
solution: The errors $p - y$ are $0.5, 0.5, -0.5$. The intercept gradient is $0.5/3 = 0.1667$ and the slope gradient is $(0 + 1 - 2)/3 = -0.3333$, so $\mathbf{w} = (-0.1667, 0.3333)$. The scores at $x = 0, 2, 4$ are $-0.1667$, $0.5$ and $1.1667$, giving probabilities $0.458$, $0.622$ and $0.763$. The squared errors are $0.210$, $0.387$ and $0.056$, and their mean is $0.218$.

hint: Ask what the best of 200 noisy scores is an estimate of, and which data should be touched only once.
solution: The reported figure is the best of 200 noisy estimates, so it benefits from selection bias: the winner is partly the configuration that happened to suit these folds, and the fold scores that picked it are also the scores being reported. Any preprocessing or feature selection done before the folds were cut adds leakage. A better procedure holds out a test set at the start (stratified, kept untouched), then performs the hyperparameter search by cross-validation on the remaining data only, with stratified folds so that each holds the same 3 percent of positives and with scaling and any feature selection fitted inside each training fold. To measure the whole procedure, including the search, use nested cross-validation or the single held-out test set, scoring the refit winner once. Because positives are rare, report precision, recall and average precision (read against the 3 percent prevalence baseline) besides ROC AUC, and choose the threshold on validation data according to the costs of the two kinds of error.

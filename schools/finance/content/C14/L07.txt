@article
The simplest model of an uncertain stock price lets it move to only two values in the next period. Surprisingly, that is enough to price an option exactly, and by chaining many such periods you can approximate a realistic price process.

**Conventions in this lesson.** Each step lasts $\Delta t$ years. The stock moves from $S$ to $uS$ (up) or $dS$ (down), with $d < e^{r\Delta t} < u$ (otherwise there would be arbitrage). The risk-free rate $r$ is continuously compounded, there are no dividends and no transaction costs, and options are on one share.

### One step: replication

Let $f_u$ and $f_d$ be the option's payoffs in the up and down states. Build a portfolio of $\Delta$ shares and a loan (or deposit) $B$ that matches those payoffs:
$$\Delta\, uS + B\,e^{r\Delta t} = f_u,\qquad \Delta\, dS + B\,e^{r\Delta t} = f_d.$$
Subtracting gives the **delta** (hedge ratio)
$$\Delta = \frac{f_u - f_d}{S(u-d)}.$$
Because the portfolio and the option have the same payoffs, the option's price equals the portfolio's cost, $f = \Delta S + B$, with $B$ negative if you borrow.

### Risk-neutral valuation

Solving for $f$ gives a form that does not involve anyone's beliefs about the stock:
$$f = e^{-r\Delta t}\left[\,p\,f_u + (1-p)\,f_d\,\right],\qquad p = \frac{e^{r\Delta t} - d}{u-d}.$$
The number $p$ is the **risk-neutral probability** of an up move: the probability under which the stock's expected return equals the risk-free rate. It is *not* the real-world probability. The option price is its expected payoff under $p$, discounted at the risk-free rate. For options on a stock paying a continuous dividend yield $q$, replace $e^{r\Delta t}$ by $e^{(r-q)\Delta t}$ in $p$.

### Many steps and backward induction

For an $n$-step tree, work backward: set the terminal node values to the option's payoffs, then at each earlier node apply the one-step formula to the two nodes that follow. For a **European** option that is all. For an **American** option, at every node compare the continuation value $e^{-r\Delta t}[pf_u+(1-p)f_d]$ with the **exercise value** (intrinsic value, $\max(S-K,0)$ for a call, $\max(K-S,0)$ for a put) and keep the larger. Where exercise value wins, early exercise is optimal.

### Choosing $u$ and $d$

To match the stock's volatility $\sigma$ (the standard deviation of its continuously compounded return, per year), the CRR choice is
$$u = e^{\sigma\sqrt{\Delta t}},\qquad d = \frac{1}{u} = e^{-\sigma\sqrt{\Delta t}}.$$
This makes the tree **recombining**: an up move followed by a down move gives the same price as down followed by up, so an $n$-step tree has only $n+1$ terminal nodes. As $n$ grows with $\Delta t = T/n$, the European option price converges to the Black-Scholes-Merton price (Week 8). Real-world drift does not appear anywhere in the pricing.

@example
title: One-step call by replication
problem: A stock is at \$50. In one year it will be \$62.50 or \$40. The rate is 4% (continuously compounded). Price a European call with strike \$50 and replicate it.
step: Here $u = 1.25$, $d = 0.8$, $f_u = 12.50$, $f_d = 0$.
step: Delta: $\Delta = (12.50 - 0)/(50 \times 0.45) = 0.5556$ shares per option.
step: Risk-neutral probability: $p = (e^{0.04} - 0.8)/0.45 = (1.040811 - 0.8)/0.45 = 0.5351$.
step: Price: $f = e^{-0.04}\,[0.5351 \times 12.50] = 0.960789 \times 6.6892 = \$6.4269$.
step: Check by replication: buy 0.5556 shares for \$27.78 and borrow \$21.35 (so that the loan repays \$22.22 in the future): cost $27.78 - 21.35 = \$6.43$. In the up state the shares are worth \$34.72, less the \$22.22 owed, which is \$12.50; in the down state \$22.22 less \$22.22 is \$0.
answer: \$6.43 (6.4269); replicate with 0.5556 shares and a loan of about \$21.35.

title: A two-step European put
problem: A stock is at \$100. Each step lasts 0.5 years, and the stock goes up by a factor $u=1.1$ or down by a factor $d=0.9$. The rate is 5% (continuously compounded). Price a European put with strike \$100 and 1 year to expiration.
step: $p = (e^{0.05\times0.5} - 0.9)/(1.1-0.9) = (1.025315 - 0.9)/0.2 = 0.62658$ and the discount factor per step is $e^{-0.025} = 0.975310$.
step: Terminal prices: 121, 99 and 81. Put payoffs: 0, 1 and 19.
step: Up node ($S=110$): $f = 0.975310\,[0.62658\times 0 + 0.37342\times 1] = 0.3642$. Down node ($S=90$): $f = 0.975310\,[0.62658 \times 1 + 0.37342 \times 19] = 7.5310$.
step: Root: $f = 0.975310\,[0.62658\times 0.3642 + 0.37342\times 7.5310] = 0.975310 \times 3.0402 = \$2.9654$.

@mistakes
- Using the real-world probability of an up move instead of the risk-neutral probability $p$.
- Forgetting to discount at each step, or discounting the final answer once by the whole time period with a wrong rate; the factor $e^{-r\Delta t}$ is applied at every step.
- Failing to compare with the exercise value at every node of an American option (not only at the root).
- Dividing the tree's volatility by 252 or using a daily $\Delta t$ without matching $\sigma$ to the same time unit: $\sigma$ is annual, so $\Delta t$ is in years.

model:
```python
import math


def binomial_price(S, K, r, sigma, T, n, kind="call", american=False):
    """Price a European or American option on an n-step CRR binomial tree."""
    dt = T / n
    u = math.exp(sigma * math.sqrt(dt))
    d = 1 / u
    p = (math.exp(r * dt) - d) / (u - d)
    disc = math.exp(-r * dt)
    sign = 1 if kind == "call" else -1

    def exercise(step, ups):
        price = S * u ** ups * d ** (step - ups)
        return max(sign * (price - K), 0.0)

    values = [exercise(n, j) for j in range(n + 1)]
    for step in range(n - 1, -1, -1):
        new_values = []
        for j in range(step + 1):
            cont = disc * (p * values[j + 1] + (1 - p) * values[j])
            if american:
                cont = max(cont, exercise(step, j))
            new_values.append(cont)
        values = new_values
    return values[0]
```
hint: Start with the payoffs at the `n + 1` terminal nodes, where node `j` has `j` up moves.
hint: Step backward one level at a time: each new value uses `values[j]` (a down move) and `values[j + 1]` (an up move).
solution: Build the terminal payoffs, then replace the list by the discounted risk-neutral expectation of adjacent pairs, level by level; for an American option take the maximum with the exercise value at each node. An American call on a non-dividend stock equals the European call (the last equality test), while the American put is worth more (the third and fourth tests).

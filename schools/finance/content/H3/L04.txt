@article
Suppose you know that $\sin\theta = \frac{1}{2}$ and want the angle. Many angles work: $\frac{\pi}{6}$, $\frac{5\pi}{6}$, $\frac{\pi}{6} + 2\pi$, and so on. A function must give **one** output for each input, so to undo sine we must choose which angle to report.

### Restricting to make an inverse

A function has an inverse only if it is one-to-one (it passes the horizontal line test). Sine, cosine and tangent repeat, so none is one-to-one on the whole line. We restrict each to a piece where it is one-to-one and still covers its full range, and invert that piece:

| Function | Restricted to | Inverse | Domain of inverse | Range of inverse |
|---|---|---|---|---|
| $\sin$ | $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ | $\arcsin$ | $[-1, 1]$ | $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ |
| $\cos$ | $[0, \pi]$ | $\arccos$ | $[-1, 1]$ | $[0, \pi]$ |
| $\tan$ | $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ | $\arctan$ | all reals | $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ |

So $\arcsin y$ means **the angle in $[-\frac{\pi}{2}, \frac{\pi}{2}]$ whose sine is $y$**, and similarly for the others. Another notation is $\sin^{-1}y$; the $-1$ marks the inverse function and does **not** mean $\frac{1}{\sin y}$.

$$\arcsin\tfrac{1}{2} = \tfrac{\pi}{6}, \qquad \arccos\left(-\tfrac{1}{2}\right) = \tfrac{2\pi}{3}, \qquad \arctan(-1) = -\tfrac{\pi}{4}.$$

The middle answer is in Quadrant II. It is not $-\frac{2\pi}{3}$ or $\frac{4\pi}{3}$, because $\arccos$ only reports angles between $0$ and $\pi$.

### Compositions: one direction is safe

Applying a function and then its inverse returns your input only when the input is in the right set:

$$\sin(\arcsin x) = x \ \text{ for } -1 \le x \le 1, \qquad \arcsin(\sin x) = x \ \text{ only for } -\tfrac{\pi}{2} \le x \le \tfrac{\pi}{2}.$$

For other $x$, find the angle in the range that has the same sine. Since $\sin\frac{5\pi}{6} = \frac{1}{2}$, we get $\arcsin\left(\sin\frac{5\pi}{6}\right) = \frac{\pi}{6}$, not $\frac{5\pi}{6}$.

### The right-triangle trick

To evaluate $\cos\left(\arcsin\frac{3}{5}\right)$, let $\theta = \arcsin\frac{3}{5}$. Then $\sin\theta = \frac{3}{5}$: draw a right triangle with opposite side $3$ and hypotenuse $5$. The adjacent side is $4$, so $\cos\theta = \frac{4}{5}$.

Equivalently, $\cos\theta = \pm\sqrt{1 - \sin^2\theta}$, and the range of the inverse fixes the sign. The angle $\arcsin x$ lies in $[-\frac{\pi}{2}, \frac{\pi}{2}]$ where cosine is never negative, so we take $+$. In general

$$\cos(\arcsin x) = \sqrt{1 - x^2}, \qquad \sin(\arccos x) = \sqrt{1 - x^2}.$$

```python
import math
print(round(math.asin(0.5), 4))              # 0.5236, which is pi/6
print(round(math.asin(math.sin(5*math.pi/6)), 4))   # 0.5236 again, not 2.618
print(round(math.atan2(1, -1), 4))           # 2.3562, the angle of the point (-1, 1)
```

The last line uses `atan2(y, x)`, which returns the angle of the point $(x, y)$ in $(-\pi, \pi]$ and gets the quadrant right. We will use it again with polar coordinates.

@example
title: Evaluating inverse functions carefully
problem: Evaluate $\arccos\left(-\frac{\sqrt{2}}{2}\right)$ and $\arcsin\left(\sin\frac{7\pi}{6}\right)$.
step: For the first, we want the angle in $[0, \pi]$ whose cosine is $-\frac{\sqrt{2}}{2}$. The reference angle is $\frac{\pi}{4}$, and cosine is negative in Quadrant II, which lies inside $[0, \pi]$.
step: So $\arccos\left(-\frac{\sqrt{2}}{2}\right) = \pi - \frac{\pi}{4} = \frac{3\pi}{4}$.
step: For the second, evaluate the inside first: $\sin\frac{7\pi}{6} = -\frac{1}{2}$.
step: Now $\arcsin\left(-\frac{1}{2}\right)$ is the angle in $[-\frac{\pi}{2}, \frac{\pi}{2}]$ with sine $-\frac{1}{2}$, namely $-\frac{\pi}{6}$. The answer is not $\frac{7\pi}{6}$, which lies outside the range.

@example
title: A trigonometric function of an inverse
problem: Find the exact value of $\tan\left(\arcsin\left(-\frac{4}{5}\right)\right)$.
step: Let $\theta = \arcsin\left(-\frac{4}{5}\right)$. Then $\theta$ is in $[-\frac{\pi}{2}, \frac{\pi}{2}]$ and $\sin\theta = -\frac{4}{5}$, so $\theta$ is in Quadrant IV.
step: Cosine is never negative on $[-\frac{\pi}{2}, \frac{\pi}{2}]$, so $\cos\theta = +\sqrt{1 - \frac{16}{25}} = \frac{3}{5}$.
step: Therefore $\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{-4/5}{3/5} = -\frac{4}{3}$.

@mistakes
- Reading $\sin^{-1}x$ as $\frac{1}{\sin x}$. The exponent $-1$ names the inverse function.
- Believing $\arcsin(\sin x) = x$ for every $x$. It holds only when $x \in [-\frac{\pi}{2}, \frac{\pi}{2}]$.
- Giving an answer outside the range: $\arccos\left(-\frac{1}{2}\right)$ is $\frac{2\pi}{3}$, never $\frac{4\pi}{3}$ or $-\frac{2\pi}{3}$.
- Choosing the wrong sign for the missing coordinate. After $\arcsin$ the cosine is non-negative; after $\arccos$ the sine is non-negative.

prompt: Find the exact value of $\sec\left(\arcsin\frac{5}{13}\right)$.
answer: 13/12
check: 1/cos(arcsin(5/13))
hint: Let $\theta = \arcsin\frac{5}{13}$. Find $\cos\theta$ first, then take the reciprocal.
hint: Draw a right triangle with opposite side $5$ and hypotenuse $13$, and find the adjacent side.
solution: The adjacent side is $\sqrt{13^2 - 5^2} = 12$, and $\cos\theta = \frac{12}{13}$ (non-negative, as $\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$). So $\sec\theta = \frac{13}{12}$.

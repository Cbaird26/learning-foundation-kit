@article
A **rational number** is any number that can be written as a fraction $\frac{a}{b}$ of two integers with $b \neq 0$. Integers, fractions, terminating decimals such as $-1.75$ and repeating decimals are all rational. Today you add and subtract them, including negatives.

### Adding on the number line

Start at the first number. To add a positive number, move right. To add a negative number, move left. So $-3 + 5$ starts at $-3$ and moves $5$ to the right, landing on $2$.

### The sign rules for addition

- **Same signs:** add the absolute values and keep the sign. $-4 + (-6) = -10$.
- **Different signs:** subtract the smaller absolute value from the larger, and keep the sign of the number with the larger absolute value. $-9 + 4 = -5$, since $9$ is bigger than $4$ and $-9$ is negative.
- **Opposites** add to zero: $7 + (-7) = 0$. The opposite of $a$ is $-a$.

Think of money: owing \$9 and then earning \$4 leaves you still owing \$5.

### Subtraction is adding the opposite

$$a - b = a + (-b).$$

So $5 - 8 = 5 + (-8) = -3$ and $5 - (-8) = 5 + 8 = 13$. Subtracting a negative moves you right, because taking away a debt makes you better off.

### Distance between two numbers

The distance between $a$ and $b$ on the number line is $|a - b|$. The distance from $-2$ to $5$ is $|-2 - 5| = |-7| = 7$. Distance is never negative.

### Fractions and decimals

The same rules apply. For fractions, first write them over a common denominator:

$$-\frac{1}{2} + \frac{1}{3} = -\frac{3}{6} + \frac{2}{6} = -\frac{1}{6}.$$

For decimals, line up the decimal points. $-0.4 + 1.5 = 1.1$. Whenever the signs differ, think "which number is farther from zero?" to choose the sign.

@example
title: Subtracting a negative fraction
problem: Compute $-\frac{4}{5} - \left(-\frac{1}{2}\right)$.
step: Subtracting a number is adding its opposite, so rewrite it as $-\frac{4}{5} + \frac{1}{2}$.
step: Use the common denominator $10$: $-\frac{8}{10} + \frac{5}{10}$.
step: The signs differ and $\frac{8}{10}$ is farther from zero, so the answer is negative: $\frac{8 - 5}{10}$ with a minus sign.
step: The result is $-\frac{3}{10}$.

@mistakes
- Treating $5 - (-8)$ as $5 - 8$. Two minus signs in a row become a plus.
- Adding the absolute values when the signs differ, for example writing $-9 + 4 = -13$.
- Giving a negative distance. Use the absolute value of the difference.

@practice num
prompt: Compute $-7 + 3$.
answer: -4
check: -7 + 3
hint: The signs differ. Which number has the larger absolute value?
solution: $|-7| = 7$ is larger than $|3| = 3$, so the result is negative: $7 - 3 = 4$, giving $-4$.

prompt: Compute $2.5 - (-1.75)$.
answer: 4.25

solution: $2.5 - (-1.75) = 2.5 + 1.75 = 4.25$.

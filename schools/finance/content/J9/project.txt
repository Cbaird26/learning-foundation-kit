```python
questions = [
    ["What is 6 * 7?", "42"],
    ["What is the capital of France?", "paris"],
    ["How many days are in a week?", "7"],
]


def ask(question, correct):
    answer = input(question + " ")
    return answer.strip().lower() == correct


def play(questions):
    score = 0
    for q in questions:
        if ask(q[0], q[1]):
            print("Correct!")
            score += 1
        else:
            print("Not quite. The answer was", q[1])
    return score


score = play(questions)
print(f"You scored {score} out of {len(questions)}.")
```

@review
## Course review: Programming in Python I

**Weeks 1-2: arithmetic and variables.** `print` shows values. The operators are `+ - * / // % **`, and `/` always gives a float. Order: `**`, then `* / // %`, then `+ -`; parentheses first. `=` stores a value under a name. The basic types are `int`, `float`, `str` and `bool`; convert with `int()`, `float()` and `str()`.

**Weeks 3-4: strings and input.** Strings are indexed from `0`, slices stop before the end index, and strings are immutable, so methods such as `strip`, `upper`, `replace` and `count` return new strings. `input()` always returns a string, so convert it before doing arithmetic. Use f-strings for output, `:.2f` for decimals, and `sep` and `end` to control `print`.

**Weeks 5-6: decisions and logic.** `if`, `elif` and `else` run the first true branch, so test the most specific case first. `==` compares and `=` stores. `and`, `or` and `not` combine conditions, with `not` first, then `and`, then `or`. Write both sides in full: `day == "sat" or day == "sun"`.

**Weeks 7-8: loops.** A `while` loop needs a condition that can become false; update the loop variable inside it. A sentinel stops a loop, and `break` leaves it. `for` with `range(start, stop, step)` repeats a known number of times, and the stop is never included. Nested loops run the inner loop completely for each outer pass.

**Weeks 9-10: functions and debugging.** `def` defines a function, `return` hands a value back, and without `return` the result is `None`. Parameters are matched by position, defaults go last, and variables made inside a function are local. In a traceback, read the last line first: it names the error type. Logic errors give no message, so test with small inputs and trace by hand.

**Weeks 11-12: lists and planning.** Lists are mutable, with `append`, `pop`, `remove` and `sorted`. Loop over a list to count, total or filter. `b = a` makes both names refer to the same list. Plan first: inputs and outputs, a hand-worked example, small functions, pseudocode, tests with edge cases, and one piece at a time.

### Self-check

- Can you predict the output of a short program by tracing its variables line by line?
- Can you explain the difference between `=` and `==`, between `print` and `return`, and between `/` and `//`?
- Can you write a function that counts, totals or filters a list, and test it with an empty list?
- Can you read a traceback and say which line and kind of error it reports?
- Can you plan a program in plain words before writing it?

### Most common errors

- Adding strings from `input()` without converting them.
- An off-by-one error with `range` or a slice.
- A loop that never changes its condition variable.
- Printing a value in a function when it should be returned.
- Putting the more general `elif` before the specific one.
- Forgetting the empty list and the boundary values when testing.

prompt: Write a function `letters(scores)` that takes a list of whole-number scores and returns a **new list** of letter grades, in the same order: `"A"` for 90 or more, `"B"` for 80 to 89, `"C"` for 70 to 79, and `"F"` for anything lower. For `[95, 80, 69]` it returns `["A", "B", "F"]`. The list passed in must not change.
starter:
```python
def letters(scores):
    pass
```
tests:
```python
data = [95, 80, 69]
assert letters(data) == ["A", "B", "F"]
assert data == [95, 80, 69]
assert letters([]) == []
assert letters([90, 89, 79, 70]) == ["A", "B", "C", "C"]
assert letters([0, 100]) == ["F", "A"]
```
model:
```python
def letters(scores):
    result = []
    for s in scores:
        if s >= 90:
            result.append("A")
        elif s >= 80:
            result.append("B")
        elif s >= 70:
            result.append("C")
        else:
            result.append("F")
    return result
```
hint: Loop over the scores, decide a letter for each one with `if`, `elif` and `else`, and append it to a new list.
hint: Check the highest grade first and use `>=`, so that exactly 90 is an `A` and exactly 70 is a `C`.
solution: Build `result` as an empty list. For each score, test `>= 90`, then `>= 80`, then `>= 70`, and use `else` for the rest, appending the letter each time. Return `result` after the loop. The boundary tests (`90`, `89`, `70`) catch a `>` used where `>=` is needed.

@exam num
prompt: How many times does the line `n = step(n)` run in this program, so that the program prints that number?

```python
def step(n):
    if n % 2 == 0:
        return n // 2
    return 3 * n + 1

n = 6
count = 0
while n != 1:
    n = step(n)
    count += 1
print(count)
```
answer: 8
check: int(run("def step(n):\n    if n % 2 == 0:\n        return n // 2\n    return 3 * n + 1\n\nn = 6\ncount = 0\nwhile n != 1:\n    n = step(n)\n    count += 1\nprint(count)\n"))
hint: Write down the value of `n` after each call, starting from 6, until it reaches 1.
solution: The values of `n` are `6`, `3`, `10`, `5`, `16`, `8`, `4`, `2` and `1`. Each arrow between them is one call to `step`, so there are 8 calls before `n` reaches `1`.

@exam code
prompt: Write a function `times_table_lines(n, count)` that returns a list of strings, one for each multiplier from 1 up to and including `count`, in the form `n x i = product`. For example `times_table_lines(3, 2)` returns `["3 x 1 = 3", "3 x 2 = 6"]`. If `count` is `0` it returns the empty list. Return the list; do not print.
starter:
```python
def times_table_lines(n, count):
    pass
```
tests:
```python
assert times_table_lines(3, 2) == ["3 x 1 = 3", "3 x 2 = 6"]
assert times_table_lines(7, 0) == []
assert times_table_lines(5, 1) == ["5 x 1 = 5"]
assert times_table_lines(-2, 3) == ["-2 x 1 = -2", "-2 x 2 = -4", "-2 x 3 = -6"]
assert times_table_lines(10, 4)[-1] == "10 x 4 = 40"
```
model:
```python
def times_table_lines(n, count):
    lines = []
    for i in range(1, count + 1):
        lines.append(f"{n} x {i} = {n * i}")
    return lines
```
hint: The multipliers come from `range(1, count + 1)`, so that `count` itself is included.
hint: Build each line with an f-string and `append` it to a list that you return after the loop.
solution: Use `range(1, count + 1)` for the multipliers. An f-string builds each line from `n`, `i` and `n * i`, and `append` adds it to the result list, which is returned after the loop. For `count` of `0` the range is empty, so the list stays empty.

@lesson
title: Linear equations
summary: Solve linear equations with brackets, variables on both sides and fractions, and confirm every answer by substituting it back.
objective: Solve an equation by doing the same thing to both sides until the variable stands alone.
objective: Expand brackets and collect like terms before isolating the variable.
objective: Clear fractions by multiplying every term by the least common denominator.
objective: Check a solution by substitution, and recognise equations with no solution or with every number as a solution.

@article
An **equation** says that two expressions are equal, such as $2x + 3 = 11$. To **solve** it means to find the value of $x$ that makes the statement true. A **linear equation** in one variable is one where $x$ appears only to the first power (no $x^2$, no $\frac{1}{x}$), so it can usually be rearranged into $ax + b = c$ with $a \neq 0$.

### Start with a story

A taxi charges a flat fee of 4 dollars plus 2 dollars for each kilometre. Your fare was 18 dollars. How far did you ride? If the distance is $d$ kilometres, the fare in dollars is $2d + 4$, so

$$2d + 4 = 18.$$

You can find $d$ by running the story backwards: take off the 4-dollar flat fee (14 dollars is left), then share those 14 dollars among the 2-dollar kilometres to get $7$ km. Algebra does exactly this, one small step at a time.

### The one rule

**Whatever you do to one side of an equation, do to the other side.** Add, subtract, multiply or divide both sides by the same number (never divide or multiply by zero) and the equation stays true. Your goal is to get the variable alone, so undo what was done to it in reverse order:

$$2d + 4 = 18 \;\to\; 2d = 14 \;\to\; d = 7.$$

### Brackets and variables on both sides

Expand brackets first: the number outside multiplies **every** term inside. Combine like terms on each side. Then gather the $x$-terms on one side and the plain numbers on the other.

For $5(x - 1) = 3x + 7$, expand to get $5x - 5 = 3x + 7$. Subtract $3x$ from both sides: $2x - 5 = 7$. Add $5$: $2x = 12$. So $x = 6$.

### Fractions: clear them first

Fractions are the main source of slips, so remove them. Find the **least common denominator** (LCD), the smallest number that every denominator divides into, and multiply **every term** on both sides by it. In $\frac{x}{2} + \frac{x}{3} = 5$ the LCD is $6$:

$$6\cdot\frac{x}{2} + 6\cdot\frac{x}{3} = 6\cdot 5 \;\Rightarrow\; 3x + 2x = 30 \;\Rightarrow\; x = 6.$$

(From the fractions lesson: $6\cdot\frac{x}{2} = \frac{6}{2}\cdot x = 3x$, because $6$ is a multiple of the denominator $2$.)

### Check by substitution

Put your answer into the **original** equation, not a later line, and see whether both sides agree: $\frac{6}{2} + \frac{6}{3} = 3 + 2 = 5$. A check takes ten seconds and catches nearly every arithmetic slip.

### Two odd cases

Sometimes the $x$-terms cancel completely. If you reach a **false** statement such as $6 = 5$, no value of $x$ works: there is **no solution**. If you reach a **true** statement such as $4 = 4$, every number works: there are **infinitely many solutions**. For example, $2(x + 1) = 2x + 2$ is true for every $x$.

@example
title: Fractions with brackets on top
problem: Solve $\frac{x + 1}{2} - \frac{x - 2}{3} = 2$.
step: The denominators are $2$ and $3$, so the LCD is $6$. Multiply every term, including the $2$ on the right, by $6$: $3(x + 1) - 2(x - 2) = 12$.
step: Expand the brackets. The minus sign in front of the second bracket changes both of its terms: $3x + 3 - 2x + 4 = 12$.
step: Combine like terms: $x + 7 = 12$.
step: Subtract $7$ from both sides: $x = 5$.
step: Check in the original equation: $\frac{5 + 1}{2} = 3$ and $\frac{5 - 2}{3} = 1$, and $3 - 1 = 2$. Both sides agree.

@example
title: When do two phone plans cost the same?
problem: Plan A costs \$10 per month plus \$0.05 per text. Plan B costs \$4 per month plus \$0.08 per text. For how many texts in a month do the two plans cost the same?
step: Let $t$ be the number of texts. Plan A costs $10 + 0.05t$ and Plan B costs $4 + 0.08t$. "The same" means we set them equal: $10 + 0.05t = 4 + 0.08t$.
step: Gather the $t$-terms on the side where the coefficient stays positive. Subtract $0.05t$ from both sides: $10 = 4 + 0.03t$.
step: Subtract $4$ from both sides: $6 = 0.03t$.
step: Divide both sides by $0.03$: $t = 200$.
step: Check: Plan A is $10 + 0.05(200) = 20$ and Plan B is $4 + 0.08(200) = 20$. Both cost \$20.

@mistakes
- Multiplying only the fraction terms by the LCD and forgetting the whole-number terms. Every term gets multiplied.
- Losing a sign when expanding: in $3x - (x - 4)$ the minus changes both terms, giving $3x - x + 4$, not $3x - x - 4$.
- Checking in a rewritten line instead of the original equation, which can hide an earlier slip.

@practice num
prompt: Solve for $x$: $5x + 3 = 28$.
answer: 5
check: root(lambda x: 5*x + 3 - 28, -100, 100)
hint: Which operation was applied to $x$ last? Undo that one first.
hint: Subtract $3$ from both sides, then divide both sides by $5$.
solution: Subtract $3$: $5x = 25$. Divide by $5$: $x = 5$. Check: $5(5) + 3 = 28$.

@practice num
prompt: Solve for $x$: $4(x - 3) = 2x + 10$.
answer: 11
check: root(lambda x: 4*(x - 3) - (2*x + 10), -100, 100)
hint: Expand the bracket first: the $4$ multiplies both $x$ and $-3$.
hint: You get $4x - 12 = 2x + 10$. Subtract $2x$ from both sides, then add $12$.
solution: $4x - 12 = 2x + 10$ gives $2x = 22$, so $x = 11$. Check: $4(8) = 32$ and $2(11) + 10 = 32$.

@practice num
prompt: Solve for $x$: $\frac{2x}{3} + \frac{1}{2} = \frac{x}{6} + 4$. Give an exact answer.
answer: 7
check: root(lambda x: 2*x/3 + 1/2 - (x/6 + 4), -100, 100)
hint: The denominators are $3$, $2$ and $6$, so the LCD is $6$. Multiply every term by $6$, including the $4$.
hint: You should get $4x + 3 = x + 24$.
solution: Multiplying by $6$: $4x + 3 = x + 24$. Then $3x = 21$, so $x = 7$. Check: $\frac{14}{3} + \frac{1}{2} = \frac{31}{6}$ and $\frac{7}{6} + 4 = \frac{31}{6}$.

@practice num
prompt: Solve for $x$: $\frac{2x - 1}{3} - \frac{x + 2}{4} = 1$. Give an exact answer (a fraction).
answer: 22/5
check: root(lambda x: (2*x - 1)/3 - (x + 2)/4 - 1, -100, 100)
hint: The LCD of $3$ and $4$ is $12$. Multiply every term by $12$, keeping each top line in brackets.
hint: You should get $4(2x - 1) - 3(x + 2) = 12$. The minus sign applies to both terms of the second bracket.
solution: $8x - 4 - 3x - 6 = 12$ gives $5x - 10 = 12$, so $5x = 22$ and $x = \frac{22}{5}$. Check: $\frac{2(4.4) - 1}{3} = 2.6$ and $\frac{4.4 + 2}{4} = 1.6$, and $2.6 - 1.6 = 1$.

@quiz num
prompt: A plumber charges a \$45 call-out fee plus \$30 for each hour of work. The bill came to \$172.50. For how many hours did the plumber work?
answer: 4.25
check: root(lambda h: 45 + 30*h - 172.5, -100, 100)
hint: Write the bill as an expression in the number of hours $h$, then set it equal to \$172.50.
hint: $45 + 30h = 172.5$. Subtract $45$, then divide by $30$.
solution: $30h = 127.5$, so $h = 4.25$ hours. Check: $45 + 30(4.25) = 45 + 127.5 = 172.5$.

@quiz expr
prompt: Solve $p(x - q) = r$ for $x$, assuming $p \neq 0$.
vars: p, q, r
lead: $x =$
answer: r/p + q
check: lambda p, q, r: root(lambda x: p*(x - q) - r, -100, 100)
domain: p: 1..3; q: 0..2; r: 1..4
hint: Treat $p$, $q$ and $r$ as fixed numbers. What was done to $x$ first, and what was done last?
hint: Divide both sides by $p$ first, then deal with the $q$.
solution: Divide by $p$: $x - q = \frac{r}{p}$. Add $q$: $x = \frac{r}{p} + q$.

@article
A fund manager claims a strategy earns a positive average excess return. Your sample shows 0.9% a month. Is that evidence of skill, or could luck alone produce it? A **hypothesis test** answers by asking how surprising the data would be if there were no effect.

### Hypotheses

The **null hypothesis** $H_0$ is the default claim, usually "no effect" or "no difference," and always contains an equals sign: $H_0: \mu = \mu_0$. The **alternative hypothesis** $H_a$ is what we look for evidence of: $H_a: \mu \ne \mu_0$ (two-tailed), $H_a: \mu > \mu_0$ or $H_a: \mu < \mu_0$ (one-tailed). Choose the direction from the question before seeing the data.

### The test statistic and the p-value

A **test statistic** measures how far the sample estimate is from the null value in standard errors. For a mean, with $\sigma$ unknown:

$$t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}, \qquad df = n-1.$$

For a proportion, with $\hat{p} = x/n$ (the standard error uses the null value $p_0$):

$$z = \frac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}}.$$

The **p-value** is the probability, *assuming $H_0$ is true*, of a test statistic at least as extreme as the one observed. For a two-tailed test it counts both tails. A small p-value means the data would be unusual under $H_0$.

### Decision rule and errors

Choose a **significance level** $\alpha$ (commonly 0.05) before looking at the data. If $p \le \alpha$, **reject** $H_0$; otherwise **fail to reject** $H_0$. Failing to reject is not proof that $H_0$ is true; the sample may simply be too small to detect the effect.

| | $H_0$ true | $H_0$ false |
|---|---|---|
| Reject $H_0$ | **Type I error** (probability $\alpha$) | Correct decision (probability = **power** $= 1-\beta$) |
| Fail to reject | Correct decision | **Type II error** (probability $\beta$) |

Lowering $\alpha$ makes false alarms rarer but raises $\beta$; the cure for both is a larger sample. Power rises with sample size, with the size of the true effect, and with $\alpha$.

### Critical values and confidence intervals

Instead of a p-value you can compare the statistic with a **critical value**: for a two-tailed 5% test with $df = 35$, reject if $|t| > 2.030$; with the normal distribution, if $|z| > 1.96$. A two-tailed test at level $\alpha$ rejects $H_0: \mu = \mu_0$ exactly when $\mu_0$ lies outside the $(1-\alpha)$ confidence interval, so intervals and tests tell the same story.

### Statistical versus practical significance

A very large sample can make a tiny, economically trivial difference "statistically significant," and a small sample can miss a large one. Always report the estimate and a confidence interval beside the p-value.

### In Python

```python
from statistics import NormalDist
from math import sqrt

def z_test_proportion(x, n, p0):
    p_hat = x / n
    z = (p_hat - p0) / sqrt(p0 * (1 - p0) / n)
    p_value = 2 * (1 - NormalDist().cdf(abs(z)))   # two-tailed
    return z, p_value
```

For t-test p-values, the standard library has no t distribution; on your own computer use `scipy.stats.ttest_1samp`. In this course you will use critical values from a table.

@example
title: Does the strategy beat zero?
problem: A strategy's monthly excess returns over 36 months have mean 0.9% and standard deviation 3.0%. Test $H_0: \mu = 0$ against $H_a: \mu \ne 0$ at $\alpha = 0.05$. For 35 degrees of freedom the two-tailed 5% critical value is 2.030.
step: The standard error is $3.0/\sqrt{36} = 0.5$.
step: The test statistic is $t = (0.9 - 0)/0.5 = 1.8$ with 35 degrees of freedom.
step: Since $|1.8| < 2.030$, we do not reject $H_0$. (The two-tailed p-value is about 0.080, above 0.05.)
step: Conclusion: at the 5% level there is not enough evidence that the true mean differs from zero. This does not show the strategy has no skill, only that 36 noisy months cannot tell skill from luck. The 95% interval, $0.9 \pm 2.030(0.5) = (-0.115\%, 1.915\%)$, contains zero, as the test said.
answer: $t = 1.8$; fail to reject $H_0$ at the 5% level (p of about 0.080).

@example
title: Is the default rate higher than claimed?
problem: A lender claims a 5% default rate. In a sample of 400 loans, 28 defaulted. Test $H_0: p = 0.05$ against $H_a: p > 0.05$ at $\alpha = 0.05$.
step: $\hat{p} = 28/400 = 0.07$. The standard error under $H_0$ is $\sqrt{0.05(0.95)/400} = 0.010897$.
step: $z = (0.07 - 0.05)/0.010897 = 1.835$.
step: For this one-tailed test the p-value is $P(Z \ge 1.835) = 0.0332$.
step: Since $0.0332 < 0.05$, reject $H_0$: there is evidence the default rate exceeds 5%. (A two-tailed test would give $p = 0.0665$ and would not reject, which is why the direction must be chosen in advance.)
answer: $z = 1.835$, $p = 0.0332$; reject $H_0$ at the 5% level.

@mistakes
- Saying the p-value is the probability that the null hypothesis is true. It is the probability of data this extreme if $H_0$ is true.
- Concluding "the null is true" or "there is no effect" from a failure to reject. The test may have had low power.
- Choosing a one-tailed or two-tailed test, or the significance level, after seeing the data.
- Using the sample proportion $\hat{p}$ instead of the null value $p_0$ in the standard error of the test statistic for a proportion.

model:
```python
from math import sqrt
from statistics import NormalDist


def z_test_proportion(x, n, p0):
    """Two-tailed z test for a proportion; returns (z, p_value)."""
    if n <= 0 or not 0 < p0 < 1:
        raise ValueError("invalid n or p0")
    z = (x / n - p0) / sqrt(p0 * (1 - p0) / n)
    p_value = 2 * (1 - NormalDist().cdf(abs(z)))
    return z, p_value
```
hint: Use the null value `p0` in the standard error, not the sample proportion.
hint: The two-tailed p-value doubles the upper-tail area beyond `abs(z)`.
solution: Compute the standardized distance of the sample proportion from `p0`, then double the upper-tail area for the two-tailed p-value. Using `abs(z)` makes the formula work for negative `z` too.

model:
```python
import math
import statistics


def one_sample_t(data, mu0):
    """t statistic for H0: mean = mu0."""
    n = len(data)
    if n < 2:
        raise ValueError("need at least two values")
    se = statistics.stdev(data) / math.sqrt(n)
    return (statistics.mean(data) - mu0) / se
```
hint: The standard error is `statistics.stdev(data) / math.sqrt(n)`.
hint: Subtract `mu0` from the sample mean before dividing by the standard error.
solution: The statistic measures the distance from the sample mean to the null value in standard errors. It is 0 when the sample mean equals `mu0`, positive when it is above and negative when below.

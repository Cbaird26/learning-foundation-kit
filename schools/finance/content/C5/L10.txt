@article
A stock's return depends on more than the market. Size, value and industry exposures matter too. **Multiple regression** extends the line to several predictors:

$$y_i = \beta_0 + \beta_1 x_{i1} + \beta_2 x_{i2} + \dots + \beta_k x_{ik} + \varepsilon_i.$$

The least-squares estimates $b_0, \dots, b_k$ minimize $SSE = \sum e_i^2$. In matrix form, $\mathbf{b} = (X^{\top}X)^{-1}X^{\top}\mathbf{y}$; software does this for you.

### Interpreting coefficients

Each **partial slope** $b_j$ is the predicted change in $y$ for a one-unit increase in $x_j$ **holding the other predictors constant**. Its value depends on which other variables are in the model. A stock's slope on a size factor in a model that also includes the market can differ from its slope in a model with size alone, because the predictors are correlated.

### Inference

- **Individual t tests.** To test $H_0: \beta_j = 0$, use $t = b_j/SE(b_j)$ with $n - k - 1$ degrees of freedom. A confidence interval is $b_j \pm t^* SE(b_j)$.
- **Overall F test.** To test $H_0: \beta_1 = \dots = \beta_k = 0$ (no predictor helps),

$$F = \frac{R^2/k}{(1-R^2)/(n-k-1)},$$

with $k$ and $n-k-1$ degrees of freedom; reject if $F$ exceeds the critical value. The F test can be significant even when no single t test is, which happens when predictors are highly correlated.

### R-squared and adjusted R-squared

$R^2 = 1 - SSE/SST$ never decreases when you add a variable, even a useless one. **Adjusted R-squared** penalizes extra predictors:

$$\bar{R}^2 = 1 - (1-R^2)\frac{n-1}{n-k-1}.$$

It rises when a new variable improves the fit by more than chance would, and falls otherwise. Use it, not $R^2$, to compare models with different numbers of predictors. Neither is a test of whether the model is correct.

### Dummy variables

A **dummy variable** equals 1 when an observation is in a category and 0 otherwise. If $D = 1$ for months in which a fund's manager changed, its coefficient is the average shift in $y$ for those months, holding the other variables fixed. For a categorical variable with $m$ categories, include $m-1$ dummies; including all $m$ along with an intercept causes perfect multicollinearity (the "dummy variable trap").

### Multicollinearity

When two predictors are very highly correlated, the model cannot separate their effects: standard errors are large and estimates unstable, although predictions can still be good. Lesson 11 shows how to detect it.

### In Python

For two predictors the least-squares solution can be written with sums of squares around the means ($S_{11}$, $S_{22}$, $S_{12}$ among the predictors, and $S_{1y}$, $S_{2y}$ with $y$):

$$b_1 = \frac{S_{1y}S_{22} - S_{2y}S_{12}}{S_{11}S_{22} - S_{12}^2}, \quad b_2 = \frac{S_{2y}S_{11} - S_{1y}S_{12}}{S_{11}S_{22} - S_{12}^2}, \quad b_0 = \bar{y} - b_1\bar{x}_1 - b_2\bar{x}_2.$$

On your own computer, `numpy.linalg.lstsq` or the `statsmodels` package fits any number of predictors and prints the full table of standard errors and t statistics.

@example
title: Reading regression output
problem: A fund's 36 monthly excess returns (percent) were regressed on the market's excess return (MKT) and a size factor (SMB). Software reports the table below, with $R^2 = 0.62$. Interpret it.

| Term | Coefficient | Std. error | t |
|---|---|---|---|
| Intercept | 0.15 | 0.20 | 0.75 |
| MKT | 0.95 | 0.12 | 7.92 |
| SMB | 0.40 | 0.18 | 2.22 |
step: There are $n = 36$ and $k = 2$, so each t test has $36 - 2 - 1 = 33$ degrees of freedom; the two-tailed 5% critical value is 2.035.
step: MKT: $t = 0.95/0.12 = 7.92 > 2.035$, so the market slope is significant. Holding SMB fixed, a 1% higher market excess return goes with a 0.95% higher fund return on average. The 95% interval is $0.95 \pm 2.035(0.12) = (0.71, 1.19)$.
step: SMB: $t = 2.22 > 2.035$, significant at 5%: the fund tilts toward small stocks, with 0.40% extra return per 1% of the size factor, holding the market constant.
step: The intercept's $t = 0.75$ is far below 2.035, so there is no significant average excess return beyond what the two factors explain.
step: Overall, $F = (0.62/2)/(0.38/33) = 26.92$ against a 5% critical value of about 3.28, so the model is significant, and $\bar{R}^2 = 1 - 0.38(35/33) = 0.597$.
answer: Significant market and size exposures (0.95 and 0.40), no significant intercept, $F = 26.9$, adjusted $R^2 = 0.597$.

@example
title: Adding a useless variable
problem: A third predictor is added to the model above ($n = 36$), and $R^2$ rises from 0.620 to 0.621. Does adjusted $R^2$ improve?
step: With $k = 2$: $\bar{R}^2 = 1 - 0.380(35/33) = 0.5970$.
step: With $k = 3$: $\bar{R}^2 = 1 - 0.379(35/32) = 0.5855$.
step: The adjusted $R^2$ falls from 0.597 to 0.585: the extra variable did not improve the fit enough to justify the lost degree of freedom, though ordinary $R^2$ went up.
answer: No: adjusted $R^2$ falls from 0.597 to 0.585.

@mistakes
- Interpreting a coefficient without "holding the other variables constant," or as if the other variables were absent from the model.
- Choosing the model with the highest $R^2$ when models have different numbers of predictors; $R^2$ always rises as predictors are added.
- Using $n-k$ instead of $n-k-1$ degrees of freedom for the t tests.
- Including a dummy for every category together with the intercept (perfect multicollinearity).

model:
```python
def ols_two(x1, x2, y):
    """Least-squares intercept and two slopes."""
    n = len(y)
    m1, m2, my = sum(x1) / n, sum(x2) / n, sum(y) / n
    s11 = sum((a - m1) ** 2 for a in x1)
    s22 = sum((b - m2) ** 2 for b in x2)
    s12 = sum((a - m1) * (b - m2) for a, b in zip(x1, x2))
    s1y = sum((a - m1) * (c - my) for a, c in zip(x1, y))
    s2y = sum((b - m2) * (c - my) for b, c in zip(x2, y))
    den = s11 * s22 - s12**2
    if abs(den) < 1e-12:
        raise ValueError("predictors are collinear")
    b1 = (s1y * s22 - s2y * s12) / den
    b2 = (s2y * s11 - s1y * s12) / den
    return my - b1 * m1 - b2 * m2, b1, b2
```
hint: Compute the three means, then the five sums of squares and cross-products.
hint: Compute the shared denominator once, check it, then use it for both slopes.
solution: Centering all variables at their means turns the problem into two normal equations in $b_1$ and $b_2$, whose solution is the pair of formulas given. The intercept makes the fitted plane pass through the point of means. If $x_2$ is an exact multiple of $x_1$ the denominator is zero and the slopes cannot be separated.

model:
```python
def adjusted_r2(r2, n, k):
    """Adjusted R-squared for n observations and k predictors."""
    if n - k - 1 <= 0:
        raise ValueError("not enough degrees of freedom")
    return 1 - (1 - r2) * (n - 1) / (n - k - 1)
```
hint: The unexplained share $1 - R^2$ is scaled up by $(n-1)/(n-k-1)$.
hint: Guard the case where $n - k - 1$ is zero or negative before dividing.
solution: The penalty factor $(n-1)/(n-k-1)$ grows with the number of predictors. A weak fit with many predictors, such as $R^2 = 0.05$ with $k = 4$ and $n = 10$, gives a negative adjusted $R^2$, which signals that the model is worse than using the mean alone.

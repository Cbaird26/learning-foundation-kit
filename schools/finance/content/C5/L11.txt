@article
A fitted line always produces numbers, whether or not the model is sensible. **Diagnostics** check whether the assumptions behind the standard errors, t tests and confidence intervals are plausible. The main tool is the **residuals** $e_i = y_i - \hat{y}_i$, the part of the data the model did not explain. If the model is adequate, residuals should look like patternless noise.

### The assumptions

For a regression $y = \beta_0 + \beta_1x_1 + \dots + \varepsilon$, the usual inference assumes:

1. **Linearity**: the average of $y$ is a linear function of the predictors.
2. **Independence**: the errors are uncorrelated with each other.
3. **Constant variance** (**homoskedasticity**): the errors have the same variance for all observations.
4. **Normality**: the errors are roughly normally distributed (needed mainly for small samples; the central limit theorem helps otherwise).
5. **No perfect multicollinearity**: no predictor is an exact linear combination of the others.

### What each violation looks like and costs

| Problem | Symptom in residuals | Consequence | Common remedy |
|---|---|---|---|
| Nonlinearity | Residuals plotted against fitted values show a curve | Biased coefficients and predictions | Add a squared term, transform a variable |
| Heteroskedasticity | Spread of residuals fans out as fitted values (or $x$) grow | Coefficients still unbiased, but usual standard errors and t tests are unreliable | Robust (White) standard errors, transform $y$ |
| Autocorrelation | Residuals in time order drift in runs of the same sign | Coefficients unbiased, but standard errors typically too small when correlation is positive, so t statistics are too large | Robust standard errors for time series, add lagged variables |
| Non-normality | Heavy tails or skew in a histogram or normal probability plot | Small-sample tests and intervals unreliable | Larger sample, transform, robust methods |
| Multicollinearity | Not seen in residuals; seen in predictor correlations | Large standard errors, unstable coefficients; predictions may still be fine | Drop or combine predictors, more data |

Financial returns often show the second and third problems: volatility clusters (calm and turbulent periods), and fat tails are common.

### Autocorrelation: the Durbin-Watson statistic

For residuals $e_1, \dots, e_n$ in time order,

$$DW = \frac{\sum_{t=2}^{n}(e_t - e_{t-1})^2}{\sum_{t=1}^{n}e_t^2} \approx 2(1 - r_1),$$

where $r_1$ is the correlation between consecutive residuals. $DW$ lies between 0 and 4. A value near 2 suggests no first-order autocorrelation; near 0, strong positive autocorrelation; near 4, strong negative autocorrelation. Formal bounds depend on $n$ and $k$ and come from tables or software.

### Multicollinearity: the variance inflation factor

Regress predictor $x_j$ on the other predictors and call the resulting $R^2$ value $R_j^2$. The **variance inflation factor** is

$$VIF_j = \frac{1}{1 - R_j^2}.$$

It tells you how many times larger the variance of $b_j$ is than it would be if $x_j$ were uncorrelated with the other predictors. A common rule of thumb treats $VIF > 5$ (some use 10) as a warning. With just two predictors correlated at $r$, $R_j^2 = r^2$ for both.

### Outliers, leverage and influence

An **outlier** has an unusually large residual. A **high-leverage** point has an extreme predictor value. In simple regression the leverage of observation $i$ is

$$h_i = \frac{1}{n} + \frac{(x_i - \bar{x})^2}{S_{xx}},$$

whose average is $2/n$; values above about twice the average deserve a look. A point that is both outlying and high-leverage can be **influential**, pulling the fitted line toward itself. Refit without it to see how much the estimates move, and investigate it (a data error, or a genuine event such as a crash) before deciding what to do. Do not delete points merely because they spoil the fit.

### In Python

```python
def durbin_watson(e):
    num = sum((e[t] - e[t - 1]) ** 2 for t in range(1, len(e)))
    return num / sum(v * v for v in e)
```

On your own computer, `statsmodels` provides `durbin_watson`, `het_breuschpagan` and `variance_inflation_factor`, and `matplotlib` draws residual plots.

@example
title: Residuals in time order
problem: A regression's eight residuals, in time order, are 0.5, 0.3, -0.2, -0.6, -0.4, 0.1, 0.4, 0.2. Compute the Durbin-Watson statistic and interpret it.
step: The sum of squared residuals is $0.25 + 0.09 + 0.04 + 0.36 + 0.16 + 0.01 + 0.16 + 0.04 = 1.11$.
step: The successive differences are $-0.2, -0.5, -0.4, 0.2, 0.5, 0.3, -0.2$, with squares $0.04, 0.25, 0.16, 0.04, 0.25, 0.09, 0.04$, which sum to $0.87$.
step: $DW = 0.87/1.11 = 0.784$, well below 2. The implied first-order autocorrelation is about $1 - 0.784/2 = 0.61$.
step: The residuals run positive, then negative, then positive in long streaks: positive autocorrelation. The coefficient estimates are still unbiased, but the usual standard errors are likely too small, so t statistics and significance claims are overstated. Use standard errors robust to autocorrelation, or add missing time-related variables.
answer: $DW = 0.784$: strong positive autocorrelation.

@example
title: Multicollinearity and leverage
problem: (a) Two predictors, a stock's market return and an industry index return, have a sample correlation of 0.90. Find the VIF. (b) In a simple regression of a stock on the market with $n = 8$, $\bar{x} = 0.5625$ and $S_{xx} = 19.21875$, find the leverage of an observation at $x = 3.0$ and compare it with twice the average.
step: (a) $R_j^2 = 0.90^2 = 0.81$, so $VIF = 1/(1 - 0.81) = 5.26$. The variance of each slope is about 5.3 times what it would be with uncorrelated predictors, and the standard errors are about $\sqrt{5.26} = 2.3$ times larger, so each slope is hard to pin down.
step: (b) $h = 1/8 + (3.0 - 0.5625)^2/19.21875 = 0.125 + 0.3092 = 0.434$.
step: The average leverage is $2/8 = 0.25$, so twice the average is 0.50. This point's leverage (0.434) is high but below that threshold. Check its residual too: only a point that is both high-leverage and far from the line is strongly influential.
answer: (a) $VIF = 5.26$; (b) $h = 0.434$ against a threshold of 0.50.

@mistakes
- Reading a high $R^2$ as proof that the model's assumptions hold. A model with a strongly curved residual pattern can still have a high $R^2$.
- Computing the Durbin-Watson statistic on residuals that are not in time order, or for cross-sectional data where the order is arbitrary.
- Thinking heteroskedasticity or autocorrelation bias the coefficients. They leave the estimates unbiased but make the usual standard errors, and so the tests and intervals, unreliable.
- Dropping a variable or an outlier only because it makes the results look better, without understanding why.

model:
```python
def durbin_watson(e):
    """Durbin-Watson statistic for residuals in time order."""
    if len(e) < 2:
        raise ValueError("need at least two residuals")
    denominator = sum(v * v for v in e)
    if denominator == 0:
        raise ValueError("all residuals are zero")
    numerator = sum((e[t] - e[t - 1]) ** 2 for t in range(1, len(e)))
    return numerator / denominator
```
hint: The numerator has $n - 1$ terms (it starts at the second residual); the denominator has $n$ terms.
hint: Use `range(1, len(e))` for the differences and check the denominator for zero before dividing.
solution: Pair each residual with the one before it, square the differences and add them; divide by the total of the squared residuals. Residuals that alternate in sign give values near 4 (here exactly 3.0 for four alternating values), and a smooth drift gives values near 0.

model:
```python
def residuals(x, y):
    """Residuals of the least-squares line of y on x."""
    n = len(x)
    if n != len(y) or n < 2:
        raise ValueError("need two lists of equal length, at least two points")
    mean_x = sum(x) / n
    mean_y = sum(y) / n
    sxx = sum((xi - mean_x) ** 2 for xi in x)
    if sxx == 0:
        raise ValueError("x is constant")
    sxy = sum((xi - mean_x) * (yi - mean_y) for xi, yi in zip(x, y))
    b = sxy / sxx
    a = mean_y - b * mean_x
    return [yi - (a + b * xi) for xi, yi in zip(x, y)]
```
hint: First compute the slope and intercept, exactly as in simple regression.
hint: Each residual is the observed `y` minus the fitted value `a + b * x`.
solution: Fit the line, then subtract each fitted value from its observed value. Least-squares residuals always sum to zero (apart from rounding), which the third test uses as a check on your fit.

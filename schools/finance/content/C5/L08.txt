@article
Do two funds differ in average return? Does a new process lower the error rate? Business questions are often about **comparisons**. The first decision is the design of the data.

### Independent versus paired

- **Independent samples**: observations in one group have no link to observations in the other (customers randomly assigned to two offers).
- **Paired samples**: each observation in one group is matched to one in the other (the same stock before and after an event, or two funds over the *same* months). Compute the difference within each pair and analyze the differences as one sample.

Two funds' monthly returns over the same months are **paired**, not independent: market-wide moves hit both funds at once. Pairing removes that shared variation and usually gives a more sensitive test.

### Two independent means: Welch's t test

Let the samples have sizes $n_1, n_2$, means $\bar{x}_1, \bar{x}_2$ and standard deviations $s_1, s_2$. To test $H_0: \mu_1 - \mu_2 = 0$,

$$t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}}.$$

The denominator is the standard error of the difference. **Welch's** version does not assume equal variances, and the degrees of freedom come from the Welch–Satterthwaite formula, with $v_i = s_i^2/n_i$:

$$df = \frac{(v_1 + v_2)^2}{\dfrac{v_1^2}{n_1-1} + \dfrac{v_2^2}{n_2-1}}.$$

It is not usually a whole number; use the critical value for the nearest smaller degrees of freedom, or software. A confidence interval for $\mu_1-\mu_2$ is $(\bar{x}_1-\bar{x}_2) \pm t^* \cdot SE$. (An older "pooled" test assumes equal population variances; Welch's test is the safer default.)

### Paired means

With within-pair differences $d_i$, their mean $\bar{d}$ and standard deviation $s_d$, and $n$ pairs:

$$t = \frac{\bar{d}}{s_d/\sqrt{n}}, \qquad df = n - 1.$$

### Two proportions

For $\hat{p}_1 = x_1/n_1$ and $\hat{p}_2 = x_2/n_2$, testing $H_0: p_1 = p_2$, use the **pooled** proportion $\hat{p} = (x_1 + x_2)/(n_1 + n_2)$, which is the best estimate of the common $p$ if $H_0$ holds:

$$z = \frac{\hat{p}_1 - \hat{p}_2}{\sqrt{\hat{p}(1-\hat{p})\left(\frac{1}{n_1} + \frac{1}{n_2}\right)}}.$$

### In Python

```python
import statistics
from math import sqrt

def welch_t(a, b):
    v1 = statistics.variance(a) / len(a)
    v2 = statistics.variance(b) / len(b)
    t = (statistics.mean(a) - statistics.mean(b)) / sqrt(v1 + v2)
    df = (v1 + v2) ** 2 / (v1**2 / (len(a) - 1) + v2**2 / (len(b) - 1))
    return t, df
```

On your own computer, `scipy.stats.ttest_ind(a, b, equal_var=False)` and `scipy.stats.ttest_rel(a, b)` do the same and report p-values.

@example
title: Two funds with different samples
problem: Fund A (40 months) has mean monthly return 0.95% and standard deviation 3.2%. Fund B (45 months, a different period) has mean 0.40% and standard deviation 2.8%. Treat the samples as independent. Test $H_0: \mu_A = \mu_B$ at the 5% level.
step: $v_A = 3.2^2/40 = 0.2560$ and $v_B = 2.8^2/45 = 0.17422$, so $SE = \sqrt{0.4302} = 0.6559$.
step: $t = (0.95 - 0.40)/0.6559 = 0.8385$.
step: The Welch degrees of freedom are $0.4302^2/(0.2560^2/39 + 0.17422^2/44) = 78.1$. The two-tailed 5% critical value is about 1.99 (the p-value is about 0.40).
step: Since $0.84 < 1.99$, fail to reject. The 95% interval for the difference is $0.55 \pm 1.99(0.6559) = (-0.76\%, 1.86\%)$, which includes 0. The data do not show that the funds differ in average return.
answer: $t = 0.84$, $df \approx 78$; fail to reject $H_0$.

@example
title: A fund against its benchmark, month by month
problem: Over 8 months, a fund returned 2.1, -0.4, 1.5, 3.0, -1.2, 0.8, 1.9, -0.3 (percent), and its benchmark returned 1.6, -0.9, 1.1, 2.2, -1.0, 0.2, 1.2, -0.5. Test whether the fund's mean return differs from the benchmark's. The two-tailed 5% critical value for 7 degrees of freedom is 2.365.
step: The monthly differences (fund minus benchmark) are 0.5, 0.5, 0.4, 0.8, -0.2, 0.6, 0.7, 0.2.
step: Their mean is $\bar{d} = 0.4375$ and their standard deviation is $s_d = 0.3159$. The standard error is $0.3159/\sqrt{8} = 0.1117$.
step: $t = 0.4375/0.1117 = 3.917$ with 7 degrees of freedom.
step: Since $3.917 > 2.365$, reject $H_0$ (the p-value is about 0.006). The 95% interval for the mean difference is $0.4375 \pm 2.365(0.1117) = (0.17\%, 0.70\%)$ a month.
step: Treating the two return series as independent would give a much larger standard error, because it ignores that the fund and its benchmark move together. Pairing is what makes the difference detectable.
answer: $t = 3.92$, $df = 7$; reject $H_0$: the fund's mean return exceeds the benchmark's by about 0.44% a month in this sample.

@mistakes
- Using an independent-samples test on paired data (two funds over the same months), which throws away the pairing and loses power.
- Using a paired test when the two groups are unrelated, or when the groups have different sizes.
- Concluding "the means are equal" when a test fails to reject. The interval for the difference shows how large a difference is still plausible.
- Using the pooled proportion in a confidence interval for the difference of proportions; the pooled estimate belongs only to the test, where $H_0$ says $p_1 = p_2$.

model:
```python
import math
import statistics


def welch_t(a, b):
    """Welch's t statistic and degrees of freedom for two samples."""
    if len(a) < 2 or len(b) < 2:
        raise ValueError("each sample needs at least two values")
    va = statistics.variance(a) / len(a)
    vb = statistics.variance(b) / len(b)
    t = (statistics.mean(a) - statistics.mean(b)) / math.sqrt(va + vb)
    df = (va + vb) ** 2 / (va**2 / (len(a) - 1) + vb**2 / (len(b) - 1))
    return t, df
```
hint: Compute $v_a = s_a^2/n_a$ and $v_b = s_b^2/n_b$ first; `statistics.variance` gives $s^2$.
hint: Both $t$ and $df$ are built from $v_a + v_b$.
solution: The standard error of the difference is $\sqrt{v_a + v_b}$. The degrees-of-freedom formula weights each sample's variance term by its sample size, so unequal sizes or variances give a non-integer value between the smaller sample's $n-1$ and $n_a + n_b - 2$.

model:
```python
import math
import statistics


def paired_t(a, b):
    """Paired t statistic for H0: mean difference is zero."""
    if len(a) != len(b) or len(a) < 2:
        raise ValueError("need two equal-length lists of at least two values")
    diffs = [x - y for x, y in zip(a, b)]
    se = statistics.stdev(diffs) / math.sqrt(len(diffs))
    return statistics.mean(diffs) / se
```
hint: Build the list of differences first, then treat it like a one-sample problem.
hint: The statistic is the mean difference divided by `stdev(diffs) / sqrt(n)`.
solution: A paired test is a one-sample t test on the within-pair differences. Reversing the order of the lists flips the sign of every difference, so the statistic changes sign.

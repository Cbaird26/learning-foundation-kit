@article
A **random variable** assigns a number to each outcome of a random process. It is **discrete** if it takes countable values, such as the number of loans in a pool that default. Its **probability mass function** (PMF) gives $P(X = x)$ for each value, the probabilities sum to 1, and

$$E(X) = \mu = \sum_x x\,P(X=x), \qquad \operatorname{Var}(X) = \sigma^2 = \sum_x (x-\mu)^2 P(X=x).$$

### The binomial distribution

Suppose a process has $n$ **trials** such that: (1) each trial has two outcomes, "success" and "failure"; (2) the success probability $p$ is the same on every trial; (3) the trials are **independent**; and (4) the number of trials $n$ is fixed. The number of successes $X$ then has a **binomial distribution**, $X \sim \text{Binomial}(n, p)$:

$$P(X = k) = \binom{n}{k}p^k(1-p)^{n-k}, \qquad k = 0, 1, \dots, n,$$

where $\binom{n}{k} = \frac{n!}{k!\,(n-k)!}$ counts the ways to choose which $k$ trials are the successes. The mean and variance are

$$E(X) = np, \qquad \operatorname{Var}(X) = np(1-p).$$

"Success" is just the event you count: for a credit analyst, a default is a "success." For probabilities such as $P(X \ge 1)$ it is easiest to use the complement: $P(X \ge 1) = 1 - P(X = 0) = 1 - (1-p)^n$. A **cumulative probability** $P(X \le k)$ adds the PMF up to $k$.

Check the independence condition before trusting the model. Loans in one recession tend to default together, so a binomial model for a pool of loans usually *understates* the chance of many defaults at once. The model is a starting point, not the final word.

### The Poisson distribution

When events occur at random, independently, at a constant average rate, the **number of events in a fixed interval** (a day, a page, a square kilometer) has a **Poisson distribution** with mean $\lambda$:

$$P(X = k) = \frac{e^{-\lambda}\lambda^k}{k!}, \qquad k = 0, 1, 2, \dots$$

Its mean and variance are both $\lambda$, so $\sigma = \sqrt{\lambda}$. Unlike the binomial, there is no upper limit on the count. If the interval doubles, so does $\lambda$. A binomial with large $n$ and small $p$ is well approximated by a Poisson with $\lambda = np$.

### In Python

```python
from math import comb, exp, factorial

def binom_pmf(k, n, p):
    return comb(n, k) * p**k * (1 - p)**(n - k)

def poisson_pmf(k, lam):
    return exp(-lam) * lam**k / factorial(k)

print(round(binom_pmf(0, 20, 0.05), 4))   # 0.3585
print(round(poisson_pmf(0, 3), 4))        # 0.0498
```

@example
title: Defaults in a small loan pool
problem: A lender holds 20 independent loans, each with a 5% probability of default over the year. Find the probability of no defaults, of at most two defaults, and the mean and standard deviation of the number of defaults.
step: Let $X \sim \text{Binomial}(20, 0.05)$. No defaults: $P(X=0) = 0.95^{20} = 0.3585$.
step: Also $P(X=1) = 20(0.05)(0.95)^{19} = 0.3774$ and $P(X=2) = 190(0.05)^2(0.95)^{18} = 0.1887$.
step: At most two: $P(X \le 2) = 0.35849 + 0.37735 + 0.18868 = 0.92452$, or 0.9245 to four places.
step: The mean is $np = 20(0.05) = 1$ default, and the standard deviation is $\sqrt{np(1-p)} = \sqrt{0.95} = 0.9747$.
answer: $P(X=0) = 0.3585$; $P(X \le 2) = 0.9245$; mean 1; standard deviation 0.9747.

@example
title: Failed trades per day
problem: A back office averages 3 failed trades per day, and failures are independent and random. Find the probability of no failures on a day, and of at least 2.
step: Let $X \sim \text{Poisson}(3)$. Then $P(X=0) = e^{-3} = 0.0498$.
step: $P(X=1) = 3e^{-3} = 0.1494$.
step: Use the complement: $P(X \ge 2) = 1 - 0.049787 - 0.149361 = 0.800852$, or 0.8009 to four places.
answer: $P(X=0) = 0.0498$; $P(X \ge 2) = 0.8009$.

@mistakes
- Using a binomial model when trials are not independent or the probability changes from trial to trial (for example, defaults that cluster in a recession).
- Forgetting the binomial coefficient $\binom{n}{k}$ and computing only $p^k(1-p)^{n-k}$, which is the probability of one particular sequence.
- Computing $P(X \ge k)$ by adding too many or too few terms; the complement is usually quicker, and $P(X \ge 1) = 1 - P(X=0)$, not $P(X=1)$.
- Mixing up the units of $\lambda$: it must match the length of the interval being asked about.

model:
```python
from math import comb


def binom_cdf(n, k, p):
    """P(X <= k) for X ~ Binomial(n, p)."""
    total = 0.0
    for j in range(0, min(k, n) + 1):
        total += comb(n, j) * p**j * (1 - p) ** (n - j)
    return total
```
hint: Loop over $j$ from 0 up to $k$ and add the PMF at each $j$.
hint: Stop the loop at `min(k, n)`, and note that `range(0, k + 1)` is empty when `k` is negative.
solution: The cumulative probability is the sum of $\binom{n}{j}p^j(1-p)^{n-j}$ for $j = 0, \dots, k$. Capping the upper limit at `n` keeps `comb` valid when `k` exceeds `n`, and a negative `k` gives an empty loop and a total of 0.

model:
```python
import math


def poisson_cdf(k, lam):
    """P(X <= k) for X ~ Poisson(lam)."""
    total = 0.0
    for j in range(0, k + 1):
        total += math.exp(-lam) * lam**j / math.factorial(j)
    return total
```
hint: Add $e^{-\lambda}\lambda^j/j!$ for each $j$ from 0 to $k$.
hint: Use a `for j in range(0, k + 1)` loop and a running total.
solution: The cumulative probability is a running sum of the Poisson PMF from 0 through $k$. For negative $k$ the loop does not run and the total stays 0, and for large $k$ the sum is essentially 1.

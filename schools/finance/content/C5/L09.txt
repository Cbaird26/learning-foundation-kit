@article
Does a stock move with the market, and by how much? Two tools answer this: **correlation** measures how tightly two variables move together, and **regression** fits a line that predicts one from the other.

### Covariance and correlation

For paired data $(x_i, y_i)$, $i = 1, \dots, n$, define the sums of squares and cross-products

$$S_{xx} = \sum (x_i - \bar{x})^2,\quad S_{yy} = \sum (y_i - \bar{y})^2,\quad S_{xy} = \sum (x_i-\bar{x})(y_i-\bar{y}).$$

The **sample covariance** is $s_{xy} = S_{xy}/(n-1)$, and the **correlation coefficient** is

$$r = \frac{S_{xy}}{\sqrt{S_{xx}S_{yy}}} = \frac{s_{xy}}{s_x s_y}, \qquad -1 \le r \le 1.$$

The sign shows the direction of the linear relationship and the magnitude its strength; $r = \pm 1$ means the points lie exactly on a line and $r = 0$ means no *linear* relationship (a strong curved one is still possible). Correlation does not depend on units (percent versus decimal) and does not imply causation.

### The least-squares line

We predict $y$ from $x$ with $\hat{y} = a + bx$. The **least-squares** line chooses $a$ and $b$ to minimize the sum of squared **residuals** $e_i = y_i - \hat{y}_i$, which gives

$$b = \frac{S_{xy}}{S_{xx}} = r\,\frac{s_y}{s_x}, \qquad a = \bar{y} - b\bar{x}.$$

The slope $b$ is the predicted change in $y$ for a one-unit increase in $x$; the intercept $a$ is the predicted $y$ when $x = 0$. The line always passes through $(\bar{x}, \bar{y})$, and the residuals sum to zero.

### R-squared and the standard error of the regression

The **coefficient of determination** is the share of the variation in $y$ that the line accounts for:

$$R^2 = 1 - \frac{SSE}{SST} = r^2, \qquad SSE = \sum e_i^2,\quad SST = S_{yy}.$$

(The equality $R^2 = r^2$ holds in simple regression.) The **standard error of the regression** is $s_e = \sqrt{SSE/(n-2)}$, with $n-2$ degrees of freedom since two parameters are estimated. It measures a typical residual size.

### Inference on the slope

The standard error of $b$ is $SE_b = s_e/\sqrt{S_{xx}}$. To test $H_0: \beta = \beta_0$, use $t = (b - \beta_0)/SE_b$ with $n-2$ degrees of freedom; a confidence interval is $b \pm t^* SE_b$. The usual test of "no relationship" has $\beta_0 = 0$.

### Beta, the market model

In finance, regress a stock's returns $R_i$ on the market's returns $R_m$ (often both measured in excess of the risk-free rate):

$$R_{i,t} = \alpha + \beta R_{m,t} + \varepsilon_t.$$

The slope is the stock's **beta**, its sensitivity to the market: $\beta = \operatorname{Cov}(R_i, R_m)/\operatorname{Var}(R_m)$. A beta of 1.2 means that, on average, the stock moves 1.2% when the market moves 1%. The regression only *estimates* beta, with sampling error shown by $SE_b$.

### Cautions

Plot the data. An outlier can move $b$ and $r$ a lot; a curved pattern calls for a different model; predicting far outside the observed range of $x$ (**extrapolation**) is unreliable; and a regression estimated on one period need not hold in another.

### In Python

```python
import statistics

x = [1.0, 2.0, 3.0, 4.0]
y = [2.0, 4.0, 5.0, 9.0]
slope, intercept = statistics.linear_regression(x, y)
r = statistics.correlation(x, y)
print(slope, intercept, r ** 2)
```

`statistics.linear_regression` returns `(slope, intercept)`, in that order.

title: Estimating a beta by hand
problem: Over 8 months, the market's returns (%) were $x$ = -1.0, 2.0, 0.5, -2.0, 1.5, 3.0, -0.5, 1.0 and a stock's returns were $y$ = -0.8, 2.4, -0.6, -2.9, 2.6, 3.2, 0.4, 0.3. Estimate the regression line and $R^2$.
step: The means are $\bar{x} = 0.5625$ and $\bar{y} = 0.575$.
step: The sums of squares are $S_{xx} = 19.21875$, $S_{yy} = 29.775$ and $S_{xy} = 22.1125$.
step: Slope: $b = 22.1125/19.21875 = 1.1506$. Intercept: $a = 0.575 - 1.1506(0.5625) = -0.0722$. So $\hat{y} = -0.0722 + 1.1506x$, an estimated beta of 1.15.
step: Correlation: $r = 22.1125/\sqrt{19.21875 \times 29.775} = 0.9244$, so $R^2 = 0.8545$: the market explains about 85% of the variation in the stock's returns in this sample.
answer: $\hat{y} = -0.072 + 1.151x$; beta estimate 1.15; $R^2 = 0.854$.

@example
title: Is the beta different from 1?
problem: Suppose a stock's returns are regressed on the market's returns over 8 months, giving ($b = 1.1506$, $n = 8$, $S_{xx} = 19.21875$, $SSE = 4.3330$), test $H_0: \beta = 1$ against $H_a: \beta \ne 1$ at the 5% level and build a 95% confidence interval. The critical value for 6 degrees of freedom is $t^* = 2.447$.
step: The standard error of the regression is $s_e = \sqrt{4.3330/6} = 0.8498$.
step: The standard error of the slope is $SE_b = 0.8498/\sqrt{19.21875} = 0.1938$.
step: The test statistic is $t = (1.1506 - 1)/0.1938 = 0.777$, well inside $\pm 2.447$, so we fail to reject $H_0$: the data are consistent with a beta of 1.
step: The 95% confidence interval is $1.1506 \pm 2.447(0.1938) = (0.68,\ 1.62)$. With only 8 months, beta is estimated imprecisely: values from 0.68 to 1.62 are all plausible.
answer: $t = 0.78$, fail to reject; 95% interval $(0.68, 1.62)$.

@mistakes
- Interpreting a high correlation as proof that one variable causes the other.
- Swapping $x$ and $y$: the regression of $y$ on $x$ is not the regression of $x$ on $y$ (the slope changes, though $r$ does not).
- Reading $R^2$ as the correlation; it is the *square* of the correlation, so $r = 0.5$ explains only 25% of the variation.
- Extrapolating the line far beyond the range of the data, or ignoring an outlier that dominates the fit.

```python
def simple_ols(x, y):
    """Least-squares intercept, slope and R-squared of y on x."""
    n = len(x)
    if n != len(y) or n < 2:
        raise ValueError("need two lists of equal length, at least two points")
    mean_x = sum(x) / n
    mean_y = sum(y) / n
    sxx = sum((xi - mean_x) ** 2 for xi in x)
    syy = sum((yi - mean_y) ** 2 for yi in y)
    sxy = sum((xi - mean_x) * (yi - mean_y) for xi, yi in zip(x, y))
    if sxx == 0:
        raise ValueError("x is constant")
    slope = sxy / sxx
    return mean_y - slope * mean_x, slope, sxy**2 / (sxx * syy)
```
hint: Compute the means, then $S_{xx}$, $S_{yy}$ and $S_{xy}$ with sums over the data.
hint: The slope is `sxy / sxx`; the intercept is `mean_y - slope * mean_x`.
solution: Compute the three sums of squares around the means, then the slope as $S_{xy}/S_{xx}$ and the intercept so the line passes through $(\bar{x}, \bar{y})$. Squaring $S_{xy}$ in the $R^2$ formula keeps $R^2$ nonnegative even when the slope is negative.

model:
```python
import statistics


def beta(stock, market):
    """Beta = Cov(stock, market) / Var(market)."""
    if len(stock) != len(market):
        raise ValueError("lists must have the same length")
    variance = statistics.variance(market)
    if variance == 0:
        raise ValueError("market returns are constant")
    return statistics.covariance(stock, market) / variance
```
hint: Both the covariance and the variance use divisor $n-1$ in the `statistics` module.
hint: Check for a zero variance before dividing.
solution: Beta equals the least-squares slope of the stock's returns on the market's, which is the covariance divided by the market's variance. The beta of the market with itself is exactly 1, and a stock that always moves twice as much in the opposite direction has beta $-2$.

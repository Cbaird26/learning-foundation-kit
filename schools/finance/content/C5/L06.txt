@article
A sample mean of 1.10% a month is our best single guess for a fund's true mean return, but we know it would change with another sample. A **confidence interval** gives a range of plausible values for the parameter, with a stated level of confidence that the method is reliable.

### The general form

Almost every interval in this course has the form

$$\text{estimate} \;\pm\; \text{critical value} \times \text{standard error}.$$

The product of the last two terms is the **margin of error**. The critical value is set by the confidence level, such as 95%.

### Interval for a mean

If the population standard deviation $\sigma$ is known (rare in practice), a $(1-\alpha)$ interval uses the standard normal critical value $z_{\alpha/2}$:

$$\bar{x} \pm z_{\alpha/2}\frac{\sigma}{\sqrt{n}}.$$

Common values: $z = 1.645$ for 90%, $1.960$ for 95%, $2.576$ for 99%. In practice $\sigma$ is estimated by the sample standard deviation $s$, and the extra uncertainty is handled by the **t distribution** with $n-1$ degrees of freedom. It is bell-shaped like the normal but with heavier tails, and it approaches the normal as $n$ grows:

$$\bar{x} \pm t^*_{n-1}\frac{s}{\sqrt{n}}.$$

For 95% confidence, $t^*$ is 2.262 with 9 degrees of freedom, 2.131 with 15, 2.064 with 24, 2.045 with 29 and 1.960 in the limit. The t interval assumes the data come from a roughly normal population, or that $n$ is large enough for the central limit theorem to help.

### Interval for a proportion

With $\hat{p} = x/n$, the usual large-sample interval is

$$\hat{p} \pm z_{\alpha/2}\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}.$$

It needs $n\hat{p}$ and $n(1-\hat{p})$ both at least about 10, and it behaves badly when $\hat{p}$ is near 0 or 1.

### What a confidence level means

A 95% confidence interval is produced by a procedure that captures the true parameter in 95% of repeated samples. Once an interval has been computed, the parameter either lies inside it or does not; it is wrong to say "there is a 95% probability that $\mu$ is in this interval." Higher confidence means a wider interval. A larger $n$ or a smaller $s$ means a narrower one, and the width shrinks like $1/\sqrt{n}$.

### Choosing a sample size

To get a margin of error of at most $E$ for a mean, solve $E = z\,\sigma/\sqrt{n}$:

$$n \ge \left(\frac{z\,\sigma}{E}\right)^2,$$

and always round **up**. For a proportion, $n \ge \left(z/E\right)^2 \hat{p}(1-\hat{p})$, where $\hat{p} = 0.5$ is the cautious choice when nothing is known.

### In Python

```python
import statistics
from math import sqrt

def mean_ci(data, tstar):
    m = statistics.mean(data)
    se = statistics.stdev(data) / sqrt(len(data))
    return m - tstar * se, m + tstar * se
```

The standard library has no t distribution, so you supply $t^*$ from a table (or, on your own computer, `scipy.stats.t.ppf(0.975, df)`).

@example
title: A confidence interval for a mean return
problem: A fund's 25 monthly returns have sample mean 1.10% and sample standard deviation 3.5%. Build a 95% confidence interval for the true mean monthly return, using $t^* = 2.064$ for 24 degrees of freedom.
step: The standard error is $s/\sqrt{n} = 3.5/\sqrt{25} = 0.70\%$.
step: The margin of error is $2.064 \times 0.70 = 1.4448\%$.
step: The interval is $1.10 \pm 1.4448$, that is, $(-0.34\%,\ 2.54\%)$.
step: The interval contains 0, so the data cannot rule out a true mean of zero: 25 months with this volatility are too few to say the fund earns a positive average return.
answer: $(-0.34\%, 2.54\%)$.

@example
title: A confidence interval for a proportion
problem: In a survey of 500 retail investors, 310 say they review their portfolio at least monthly. Build a 95% confidence interval for the population proportion.
step: $\hat{p} = 310/500 = 0.62$. Check the conditions: $500(0.62) = 310$ and $500(0.38) = 190$ are both at least 10.
step: The standard error is $\sqrt{0.62(0.38)/500} = 0.021707$.
step: The margin of error is $1.96 \times 0.021707 = 0.04255$.
step: The interval is $0.62 \pm 0.0425$, or $(57.7\%,\ 66.3\%)$ to one decimal place.
answer: About $(57.7\%, 66.3\%)$.

@mistakes
- Saying "there is a 95% probability that the true mean is in this interval." The 95% describes the method's long-run success rate.
- Using the z critical value when $\sigma$ is estimated from a small sample; use $t^*$ with $n-1$ degrees of freedom.
- Reading a 95% confidence interval as containing 95% of the individual observations. It is an interval for the *mean*, and individual values vary much more.
- Rounding the required sample size down; round up to guarantee the margin of error.

model:
```python
import math
from statistics import NormalDist


def proportion_ci(successes, n, confidence):
    """Large-sample confidence interval for a proportion."""
    if n <= 0:
        raise ValueError("n must be positive")
    p_hat = successes / n
    z = NormalDist().inv_cdf((1 + confidence) / 2)
    margin = z * math.sqrt(p_hat * (1 - p_hat) / n)
    return p_hat - margin, p_hat + margin
```
hint: Compute `p_hat = successes / n` and the critical value `z` first.
hint: The margin of error is `z * sqrt(p_hat * (1 - p_hat) / n)`; return `p_hat - margin, p_hat + margin`.
solution: The interval is the estimate plus or minus the critical value times the standard error. `inv_cdf((1 + confidence) / 2)` gives 1.96 for 95% (and 1.645 for 90%), so changing the confidence level changes the width.

model:
```python
import math
import statistics


def mean_ci(data, tstar):
    """Confidence interval for a mean using a supplied t critical value."""
    n = len(data)
    if n < 2:
        raise ValueError("need at least two values")
    mean = statistics.mean(data)
    se = statistics.stdev(data) / math.sqrt(n)
    return mean - tstar * se, mean + tstar * se
```
hint: Compute the sample mean and the standard error `stdev / sqrt(n)`.
hint: The lower limit is `mean - tstar * se` and the upper limit is `mean + tstar * se`.
solution: Estimate plus or minus critical value times standard error. For `[4, 6, 8]`, $\bar{x} = 6$, $s = 2$ and $SE = 1.1547$, so the margin of error with $t^* = 4.303$ is $4.969$. With only 3 observations the interval is very wide.

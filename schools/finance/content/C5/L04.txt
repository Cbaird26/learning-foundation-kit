@article
Many quantities pile up symmetrically around a center and thin out in both directions: measurement errors, heights, and, roughly, daily stock returns. The **normal distribution** models this with a bell-shaped curve. It is described by two parameters, the mean $\mu$ and the standard deviation $\sigma$, and we write $X \sim N(\mu, \sigma^2)$. Its density is

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}}\,e^{-(x-\mu)^2/(2\sigma^2)}.$$

The curve is symmetric about $\mu$, and the mean, median and mode coincide. Because $X$ is continuous, probabilities are **areas under the curve**: $P(X = x) = 0$ for any single value, and $P(a < X < b)$ is the area between $a$ and $b$.

### Z-scores

A **z-score** measures how many standard deviations a value lies from the mean:

$$z = \frac{x-\mu}{\sigma}.$$

If $X \sim N(\mu, \sigma^2)$, then $Z \sim N(0, 1)$, the **standard normal distribution**, whose cumulative probability we write $\Phi(z) = P(Z \le z)$. Every normal probability reduces to $\Phi$: $P(X \le x) = \Phi\!\left(\frac{x-\mu}{\sigma}\right)$. By symmetry, $\Phi(-z) = 1 - \Phi(z)$.

Useful values: $\Phi(1) = 0.8413$, $\Phi(1.645) = 0.95$, $\Phi(1.96) = 0.975$, $\Phi(2.326) = 0.99$. The **empirical rule** says that about 68.27% of a normal distribution lies within $1\sigma$ of the mean, 95.45% within $2\sigma$ and 99.73% within $3\sigma$.

### Percentiles

To find the value with a given cumulative probability $p$, run the process backward: $x = \mu + z_p\,\sigma$, where $z_p = \Phi^{-1}(p)$. The 5th percentile of a return distribution, a **parametric value-at-risk** quantile, is $\mu + z_{0.05}\sigma = \mu - 1.645\sigma$.

### Normal approximation to the binomial

If $X \sim \text{Binomial}(n, p)$ with $np$ and $n(1-p)$ both at least about 10, then $X$ is approximately $N(np,\, np(1-p))$. Because $X$ is an integer, apply a **continuity correction**: $P(X \ge k) \approx P\!\left(Y \ge k - 0.5\right)$ for $Y \sim N(np, np(1-p))$. For a pool of 400 loans with default probability 3%, the approximation to $P(X \ge 20)$ is $1.40\%$, while the exact binomial value is $1.96\%$. The binomial is right-skewed when $p$ is small, so the approximation understates the right tail. Treat it as a rough guide.

### When the normal model fails

Real daily returns have **fat tails**: moves of four or more standard deviations occur far more often than the normal model's roughly 0.006% (two-sided) predicts. Returns are also not exactly symmetric, and volatility changes over time. The normal model is a useful first description, and the central limit theorem (next lesson) explains why it appears so often, but a risk manager must not trust it in the extreme tails.

### In Python

```python
import math
from statistics import NormalDist

def normal_cdf(x, mu=0.0, sigma=1.0):
    return 0.5 * (1 + math.erf((x - mu) / (sigma * math.sqrt(2))))

nd = NormalDist(mu=0.05, sigma=1.2)
print(round(nd.cdf(-2), 4))        # 0.0438
print(round(nd.inv_cdf(0.05), 3))  # -1.924
```

@example
title: A bad day
problem: Suppose daily returns of a stock index fund are modeled as normal with mean 0.05% and standard deviation 1.2%. What is the probability of a daily return below -2%, and about how often would that happen in 250 trading days?
step: Standardize: $z = (-2 - 0.05)/1.2 = -1.7083$.
step: Look up the area: $P(Z < -1.7083) = \Phi(-1.7083) = 0.0438$.
step: Over 250 trading days, we expect $250 \times 0.0438 = 10.9$ such days, about one day in 23.
step: This is what the normal model predicts. Real returns have fatter tails, so actual bad days are typically more common than this.
answer: $P(R < -2\%) = 0.0438$ (4.38%), about 11 days a year under the model.

@example
title: A percentile cutoff
problem: Under the same model (mean 0.05%, standard deviation 1.2%), find the daily return that is exceeded on 95% of days, that is, the 5th percentile.
step: We need $x$ with $P(R \le x) = 0.05$. The standard normal value is $z_{0.05} = -1.6449$.
step: Convert back: $x = \mu + z\sigma = 0.05 + (-1.6449)(1.2) = 0.05 - 1.9738 = -1.9238$.
step: So on 95% of days the return is above $-1.92\%$, and on 5% of days it is below. Risk managers call a loss of this size the one-day 95% parametric value-at-risk (here 1.92% of the position's value).
answer: The 5th percentile is $-1.92\%$.

@mistakes
- Forgetting to standardize (using $x$ instead of $z = (x-\mu)/\sigma$ in the standard normal table).
- Reading $\Phi(z)$ as an upper-tail area: $\Phi(z)$ is the area to the left of $z$, so a right-tail probability is $1 - \Phi(z)$.
- Using the variance where the standard deviation belongs, for example standardizing with $\sigma^2$.
- Applying the normal approximation to a binomial without a continuity correction, or when $np$ or $n(1-p)$ is small.

```python
import math


def normal_cdf(x, mu, sigma):
    """P(X <= x) for X ~ N(mu, sigma**2)."""
    if sigma <= 0:
        raise ValueError("sigma must be positive")
    z = (x - mu) / sigma
    return 0.5 * (1 + math.erf(z / math.sqrt(2)))
```

model:
```python
import statistics


def z_scores(values):
    """Z-scores using the sample mean and sample standard deviation."""
    if len(values) < 2:
        raise ValueError("need at least two values")
    mean = statistics.mean(values)
    sd = statistics.stdev(values)
    if sd == 0:
        raise ValueError("values are all equal")
    return [(x - mean) / sd for x in values]
```
hint: Compute the mean and `statistics.stdev` once, outside the list comprehension.
hint: Check for a zero standard deviation before dividing.
solution: Compute the mean and sample standard deviation once, then apply $z = (x - \bar{x})/s$ to each value. A set of equal values has $s = 0$, which would divide by zero, so the function raises an error. The z-scores of any data set sum to 0.

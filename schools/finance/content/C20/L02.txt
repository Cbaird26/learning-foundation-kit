@article
Offer a person a 50% chance to win \$150 and a 50% chance to lose \$100. The expected gain is \$25, but most people refuse. Offer the same person a 1-in-20 chance to win \$2,000 for a \$100 ticket, and many buy. **Prospect theory** (in its cumulative version of 1992) was built to describe exactly this: people evaluate outcomes as gains and losses from a reference point, dislike losses more than they like equal gains, and distort probabilities.

### The value function

Outcomes are measured as changes $x$ from a **reference point** (often the current wealth or a purchase price), not as final wealth. The **value function** is

$$v(x) = \begin{cases} x^{\alpha} & x \ge 0 \\ -\lambda\,(-x)^{\beta} & x < 0, \end{cases}$$

with three features. **Reference dependence**: value is defined on gains and losses. **Diminishing sensitivity**: with $0 < \alpha, \beta < 1$, going from 0 to 100 matters more than going from 1,000 to 1,100, so $v$ is concave for gains and convex for losses. **Loss aversion**: $\lambda > 1$, so the loss curve is steeper. The median estimates from the 1992 experiments were $\alpha = \beta = 0.88$ and $\lambda = 2.25$. Later studies estimate different values, commonly $\lambda$ between about 1.5 and 2.5; some researchers argue that loss aversion is smaller than once thought or depends on context, and the debate continues.

### The probability weighting function

Prospect theory replaces probabilities $p$ with **decision weights** $w(p)$:

$$w(p) = \frac{p^{\gamma}}{\left(p^{\gamma} + (1-p)^{\gamma}\right)^{1/\gamma}},$$

with $\gamma = 0.61$ for gains and $\gamma = 0.69$ for losses in the 1992 estimates. This is an inverse-S curve: **small probabilities are overweighted** ($w(0.05) = 0.132 > 0.05$) and **moderate to large probabilities are underweighted** ($w(0.95) = 0.793 < 0.95$). Also $w(0)=0$ and $w(1)=1$, and $w(p) + w(1-p) < 1$ (**subcertainty**). Weighting is strongest when probabilities are described; when people learn them from experience, small probabilities tend to be underweighted (the **description-experience gap**).

### Valuing a prospect

For a gamble that gives a gain $x$ with probability $p$ and a loss $y<0$ with probability $1-p$, the prospect value is

$$V = w^{+}(p)\,v(x) + w^{-}(1-p)\,v(y),$$

and the person chooses the prospect with the higher $V$. For prospects with several outcomes, the cumulative version applies the weighting function to cumulative probabilities, ranking outcomes from best to worst for gains and worst to best for losses.

### The fourfold pattern

Combining curvature with weighting predicts:

| | Gains | Losses |
|---|---|---|
| **High probability** | Risk averse (take a sure gain) | Risk seeking (gamble to avoid a sure loss) |
| **Low probability** | Risk seeking (lotteries) | Risk averse (insurance) |

Evidence supports the pattern across many experiments, but it varies with stakes, framing and whether payoffs are real. Prospect theory is **descriptive**: it organizes choices and does not say they are wise. It also has gaps: the reference point is often ambiguous in markets (initial price, last quarter's value, an expectation?), and that freedom can make predictions flexible.

@example
title: Risk attitudes in gains and losses
problem: Using $\alpha=\beta=0.88$, $\lambda=2.25$, $\gamma^{+}=0.61$ and $\gamma^{-}=0.69$, compare (a) a sure gain of \$800 with an 80% chance of \$1,000 (else \$0), and (b) a sure loss of \$800 with an 80% chance of losing \$1,000 (else \$0).
step: Weights at $p = 0.8$: $w^{+}(0.8) = 0.607$ and $w^{-}(0.8) = 0.669$.
step: Gain side. Sure: $v(800) = 800^{0.88} = 358.7$. Gamble: $0.607 \times 1000^{0.88} = 0.607 \times 436.5 = 265.0$. The sure gain wins: risk averse.
step: Loss side. Sure: $v(-800) = -2.25 \times 800^{0.88} = -807.1$. Gamble: $0.669 \times (-2.25 \times 1000^{0.88}) = 0.669 \times (-982.1) = -657.0$. The gamble has the higher (less negative) value: risk seeking.
step: Both prospects have the same expected dollar outcomes (\$800), so the reversal comes from curvature and weighting, not from expected value: this is the reflection effect.
answer: (a) sure gain preferred ($358.7$ against $265.0$); (b) gamble preferred ($-657.0$ against $-807.1$).

@example
title: Rejecting a favorable mixed gamble
problem: With the same parameters, evaluate a 50% chance of winning \$150 and 50% chance of losing \$100, and find the gain $G$ that would make a 50-50 gamble against a \$100 loss exactly acceptable.
step: Weights at $p = 0.5$: $w^{+}(0.5) = 0.4206$ and $w^{-}(0.5) = 0.4540$.
step: $v(150) = 150^{0.88} = 82.2$ and $v(-100) = -2.25 \times 100^{0.88} = -129.5$.
step: $V = 0.4206(82.2) + 0.4540(-129.5) = 34.6 - 58.8 = -24.2 < 0$, so the gamble is rejected even though its expected value is +\$25.
step: Solve $0.4206\,G^{0.88} = 58.8$, so $G^{0.88} = 139.8$ and $G = 139.8^{1/0.88} = \$274$. A person like this wants about \$2.74 of upside for each \$1 at risk.
answer: $V = -24.2$, so reject; the break-even gain is about \$274.

@mistakes
- Applying the value function to final wealth instead of to gains and losses from a reference point.
- Forgetting that the weights for a gain and a loss use different parameters ($\gamma = 0.61$ and $0.69$) and that the loss is multiplied by $\lambda$ inside $v$, not outside $V$ a second time.
- Reading $\lambda = 2.25$ as "losses hurt exactly 2.25 times as much" for every gamble: with $\alpha < 1$ and decision weights, the break-even ratio depends on the stakes and probabilities.
- Treating prospect theory as normative advice, or its median parameters as universal constants.

model:
```python
def weight(q, gamma):
    """Prospect theory decision weight for probability q."""
    return q ** gamma / (q ** gamma + (1 - q) ** gamma) ** (1 / gamma)


def mixed_value(p, gain, loss, alpha=0.88, beta=0.88, lam=2.25,
                gamma_gain=0.61, gamma_loss=0.69):
    """Prospect value of a gain with probability p and a loss otherwise."""
    gain_part = weight(p, gamma_gain) * gain ** alpha
    loss_part = weight(1 - p, gamma_loss) * (-lam) * (-loss) ** beta
    return gain_part + loss_part
```
hint: Write a helper `weight(q, gamma)` first.
hint: `loss` is negative, so use `(-loss) ** beta` and multiply by `-lam`; the loss probability is `1 - p`.
solution: Compute the gain term with the gain weight at `p` and the loss term with the loss weight at `1 - p`. The loss term is negative because the value function multiplies the loss magnitude raised to `beta` by `-lam`. The linear test (all exponents and weights neutral, `lam=2`) checks that the parameters are actually used.

prompt: Explain, using prospect theory, why an investor might (a) refuse a 50-50 chance to win \$180 or lose \$90, yet (b) buy a lottery ticket with a 1-in-1,000 chance of a large prize. Name the feature of the theory behind each choice.
hint: One feature involves the slope of the value function around zero; the other involves the weighting function.
solution: (a) Loss aversion: near the reference point the loss branch of the value function is about $\lambda = 2.25$ times as steep, so a \$90 loss counts for more than a \$180 gain, and the weighted value is negative even though the expected value is positive. (b) Probability weighting: a probability of 0.001 receives a decision weight larger than 0.001, so the small chance of a large prize is overweighted; the person is risk seeking in the low-probability gain region. The same investor can be risk averse for moderate gambles and a buyer of lottery-like assets.
rubric: Identifies loss aversion (steeper loss branch, with the \$90 loss outweighing the \$180 gain) for the refusal.
rubric: Identifies overweighting of small probabilities for the lottery ticket.
rubric: Notes that both choices come from the same value and weighting functions, not from inconsistent preferences.

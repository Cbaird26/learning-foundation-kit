@article
A risk manager is asked a plain question: "How much could we lose tomorrow?" The honest answer is "it depends how unlucky we are." **Value at risk (VaR)** turns that into a number by fixing how unlucky.

### Definition and conventions

The VaR at confidence level $c$ over horizon $h$ is the loss that is not expected to be exceeded, with probability $c$, over the next $h$ days:

$$P(\text{loss over } h \text{ days} \le \text{VaR}_{c,h}) = c.$$

Three conventions must always be stated: the **confidence level** (commonly 95% or 99%), the **horizon** (commonly 1 day, or 10 days in the older Basel market-risk rules), and the **sign**. In this course **losses are positive numbers**, so a VaR of \$1 million means a loss of \$1 million, and gains are negative losses. A 99% one-day VaR of \$1 million says that, on about 1 day in 100, the loss should exceed \$1 million. It says nothing about how much more.

### Method 1: parametric (delta-normal) VaR

Assume that the portfolio's P&L is a linear function of the risk factors and that factor returns are jointly normal, iid, with constant parameters. For a portfolio of value $V$ with daily return mean $\mu$ and daily volatility $\sigma$, the loss over $h$ days has a normal distribution, and

$$\text{VaR}_{c,h} = V\left(z_c\,\sigma\sqrt{h} - \mu h\right),$$

where $z_c$ is the standard normal quantile: $z_{0.90} = 1.2816$, $z_{0.95} = 1.6449$, $z_{0.975} = 1.9600$, $z_{0.99} = 2.3263$, $z_{0.999} = 3.0902$. Many desks set $\mu = 0$ for short horizons. The square-root-of-time scaling assumes iid returns, as in Week 2. For several positions, compute the portfolio volatility from the covariance matrix first: **diversification** lowers the VaR below the sum of the stand-alone VaRs when correlations are below 1.

The method is fast and transparent, but it understates risk when returns have fat tails and it is poor for portfolios with options, whose P&L is not linear in the factors.

### Method 2: historical simulation

Collect the portfolio's current positions' P&L under each of the last $n$ days' actual factor moves (for example $n = 500$ trading days). The result is $n$ hypothetical P&Ls with no distributional assumption. Convert them to losses and sort them ascending. **Convention used in this course:** the VaR is the $k$-th smallest loss, where $k = \lceil c\,n \rceil$. With $n = 20$ and $c = 0.95$, $k = 19$, the second-largest loss. Software also uses interpolation between neighbors, so always state the rule. Historical simulation captures fat tails and nonlinearity found in the sample, but it is only as good as the window: it knows nothing about events that did not occur in it, and it weights old and new days equally unless adjusted.

### Method 3: Monte Carlo simulation

Specify a model for the risk factors (for example correlated normal or fat-tailed returns), draw many random scenarios, **fully revalue** the portfolio in each, and take the same empirical quantile of the simulated losses. It handles options and path-dependence, but it is only as good as the model, it is slow, and it has **sampling error**: the error in the estimated quantile shrinks roughly like $1/\sqrt{N}$ in the number of scenarios $N$.

### What VaR does not tell you

VaR is a threshold, not a worst case. It can fail to be subadditive (the VaR of a combined portfolio can exceed the sum of the parts, for some non-normal loss distributions), and it gives no information about the size of losses beyond the threshold. Next week's expected shortfall addresses the second point.

@example
title: One-day and ten-day parametric VaR
problem: Bellwether Foods' treasury portfolio is worth \$10,000,000 and has a daily return volatility of 1.2%. Assume zero mean, normal iid returns. Compute the 99% one-day VaR and the 99% ten-day VaR (losses positive).
step: One day: $\text{VaR} = 10{,}000{,}000 \times 2.32635 \times 0.012 = \$279{,}162$.
step: Ten days: multiply by $\sqrt{10} = 3.1623$: $\$279{,}162 \times 3.1623 = \$882{,}787$.
step: Interpretation: with 99% confidence, losses should not exceed \$279,162 in a day, nor \$882,787 in two weeks, under the model's assumptions.
answer: \$279,162 (1 day) and \$882,787 (10 days).

@example
title: Historical-simulation VaR from 20 days
problem: A portfolio's 20 hypothetical daily P&Ls, in thousands of dollars, are: -75, -60, -45, -33, -20, -12, -8, -3, 5, 12, 19, 23, 31, 41, 54, 67, 88, 102, 145, 210. Find the 95% and 99% one-day historical VaR using $k = \lceil c\,n \rceil$ (losses positive).
step: Losses are the negatives of P&L: the largest loss is \$75 thousand, then \$60 thousand, then \$45 thousand.
step: For 95%, $k = \lceil 0.95 \times 20 \rceil = 19$, the 19th smallest loss. The 20th smallest (largest) is 75, so the 19th is 60.
step: For 99%, $k = \lceil 0.99 \times 20 \rceil = 20$, the largest loss, 75.
step: With only 20 observations, the 99% VaR is just the worst day; a real window needs hundreds of days.
answer: 95% VaR \$60,000; 99% VaR \$75,000.

@mistakes
- Forgetting to state the confidence level, horizon and sign convention. A VaR number without them is meaningless.
- Using the 99% quantile with a 95% label, or $z_{0.99}$ where $z_{0.95}$ is meant.
- Scaling VaR by $\sqrt{h}$ for portfolios whose risk changes over the horizon, such as options, or when returns are autocorrelated.
- Reading VaR as the maximum possible loss. The loss exceeds it on about $(1 - c)$ of days.

model:
```python
import math


def historical_var(losses, confidence):
    """k-th smallest loss, k = ceil(confidence * n); losses are positive."""
    ordered = sorted(losses)
    k = math.ceil(round(confidence * len(ordered), 9))
    return ordered[k - 1]
```
hint: Sort a copy of the list; `sorted` returns a new list.
hint: Compute $k$ with `math.ceil`, then remember that Python indexes from 0, so the $k$-th smallest is at index `k - 1`.
solution: Sort the losses ascending, compute $k = \lceil c\,n\rceil$ (rounding the product to nine decimals first, so that floating-point noise such as 19.000000000000004 cannot push the ceiling up by one), and return the element at position $k-1$. A common mistake is indexing with `int(confidence * n)`, which returns the loss above the right one when $c\,n$ is an integer.

prompt: A trading book has two positions: \$3,000,000 in asset A (daily volatility 1.5%) and \$2,000,000 in asset B (daily volatility 2.0%). The correlation between their returns is 0.4, and means are zero. Using the parametric normal method (losses positive), by how much does diversification reduce the 99% one-day VaR below the sum of the two stand-alone 99% VaRs? Round to the nearest dollar.
answer: 32176
lead: \$
tol: 2
check: ninv(0.99) * (3000000 * 0.015 + 2000000 * 0.02) - ninv(0.99) * ((3000000 * 0.015) ** 2 + (2000000 * 0.02) ** 2 + 2 * 0.4 * 3000000 * 0.015 * 2000000 * 0.02) ** 0.5
hint: Dollar volatilities are \$45,000 for A and \$40,000 for B.
hint: Portfolio dollar volatility is $\sqrt{45{,}000^2 + 40{,}000^2 + 2(0.4)(45{,}000)(40{,}000)}$; multiply by $z_{0.99}$.
solution: The stand-alone VaRs sum to $2.3263 \times (45{,}000 + 40{,}000) = \$197{,}740$. Portfolio dollar volatility is $\sqrt{2{,}025{,}000{,}000 + 1{,}600{,}000{,}000 + 1{,}440{,}000{,}000} = \$71{,}169$ and the diversified VaR is $2.3263 \times 71{,}169 = \$165{,}563$. The difference is about \$32,176.

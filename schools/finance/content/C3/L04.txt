@article
A consumer turns money into utility; a firm turns inputs into output. The **production function** $q = f(K, L)$ gives the maximum output $q$ that can be produced from $K$ units of capital and $L$ units of labor. The parallel with consumer theory is deliberate: isoquants play the part of indifference curves, but output is measurable, so the numbers matter and are *cardinal*.

### Short run and long run

In the **short run** at least one input is fixed (usually capital $\bar{K}$: a factory cannot be rebuilt overnight); in the **long run** every input is variable. These are not calendar periods; they differ by what the firm can change.

### Marginal and average product

- The **marginal product of labor** is $MP_L = \partial f/\partial L$: the extra output from one more unit of labor.
- The **average product of labor** is $AP_L = q/L$.
- The **law of diminishing marginal returns**: holding other inputs fixed, beyond some point the marginal product of an input decreases as more of it is used.

When $MP_L > AP_L$ the average is rising; when $MP_L < AP_L$ it is falling; $MP_L$ crosses $AP_L$ at the maximum of $AP_L$.

### Isoquants and the MRTS

An **isoquant** joins all input combinations that produce the same output. Moving down an isoquant, we substitute labor for capital: since $dq = MP_L\,dL + MP_K\,dK = 0$, the slope is $dK/dL = -MP_L/MP_K$. The **marginal rate of technical substitution** is

$$MRTS = \frac{MP_L}{MP_K},$$

the units of capital that one more unit of labor replaces. For the Cobb-Douglas form $q = A K^{a}L^{b}$, $MP_L = b\,q/L$ and $MP_K = a\,q/K$, so $MRTS = \dfrac{b}{a}\dfrac{K}{L}$.

| Technology | Production function | Isoquant | MRTS |
|---|---|---|---|
| Cobb-Douglas | $A K^{a}L^{b}$ | smooth, convex | $(b/a)(K/L)$ |
| Perfect substitutes | $aK + bL$ | straight line | constant $b/a$ |
| Fixed proportions | $\min\{K/a,\, L/b\}$ | L-shaped | zero or undefined |

### Returns to scale

Multiply all inputs by $t > 1$. If $f(tK, tL) > t f(K, L)$ the technology has **increasing returns to scale**; if equal, **constant**; if less, **decreasing**. For $q = AK^{a}L^{b}$, $f(tK, tL) = t^{a+b}f(K, L)$, so returns to scale are increasing if $a + b > 1$, constant if $a + b = 1$ and decreasing if $a + b < 1$. Diminishing marginal returns (one input varies) and returns to scale (all inputs vary) are different concepts: Cobb-Douglas with $a = b = 0.8$ has diminishing marginal returns to each input and increasing returns to scale.

@example
title: Marginal and average product in the short run
problem: A bakery's production function is $q = 4K^{0.5}L^{0.5}$ (loaves per hour). In the short run $K = 16$. Find $q$, $MP_L$ and $AP_L$ for $L = 4$ and $L = 16$, and the long-run MRTS at $(K, L) = (16, 4)$.
step: With $K = 16$: $q = 4(4)L^{0.5} = 16\sqrt{L}$. Then $MP_L = 8L^{-0.5}$ and $AP_L = 16/\sqrt{L}$.
step: At $L = 4$: $q = 32$, $MP_L = 8/2 = 4$, $AP_L = 32/4 = 8$. At $L = 16$: $q = 64$, $MP_L = 8/4 = 2$, $AP_L = 64/16 = 4$.
step: $MP_L$ falls from 4 to 2 as labor quadruples: diminishing marginal returns. $MP_L$ is below $AP_L$ at both points, so $AP_L$ is falling.
step: Long run: $MRTS = (b/a)(K/L) = (0.5/0.5)(16/4) = 4$. Direct check: $MP_L = 2K^{0.5}L^{-0.5} = 2(4)/2 = 4$ and $MP_K = 2K^{-0.5}L^{0.5} = 2(2)/4 = 1$, so $MRTS = 4/1 = 4$.
answer: $L = 4$: $q = 32$, $MP_L = 4$, $AP_L = 8$. $L = 16$: $q = 64$, $MP_L = 2$, $AP_L = 4$. MRTS $= 4$.

@example
title: Returns to scale
problem: Classify the returns to scale of (a) $q = 3K^{0.4}L^{0.7}$, (b) $q = 2K^{0.3}L^{0.5}$ and (c) $q = \min\{2K, L\}$.
step: (a) Exponents sum to $0.4 + 0.7 = 1.1 > 1$. Doubling inputs multiplies output by $2^{1.1} = 2.1435$, more than double: increasing returns.
step: (b) $0.3 + 0.5 = 0.8 < 1$. Doubling inputs multiplies output by $2^{0.8} = 1.7411$: decreasing returns.
step: (c) $\min\{2(tK), tL\} = t\min\{2K, L\}$ for any $t$. Doubling inputs doubles output exactly: constant returns.
answer: (a) increasing, (b) decreasing, (c) constant.

@mistakes
- Mixing up diminishing marginal returns with decreasing returns to scale. The first changes one input; the second scales all of them.
- Using $MP_K/MP_L$ for the MRTS: with labor on the horizontal axis, $MRTS = MP_L/MP_K$.
- Reading a falling $MP_L$ as a falling $q$. Output keeps rising as long as $MP_L > 0$.
- Using the sum of the Cobb-Douglas exponents to judge diminishing marginal returns. The sum tells you returns to scale; marginal products diminish when each individual exponent is below 1.

hint: Find $f(2K, 2L)/f(K, L)$.
solution: $f(2K, 2L) = 2^{0.3 + 0.5}f(K, L) = 2^{0.8}f(K, L) = 1.74\,f(K, L) < 2f(K, L)$. The exponent sum $0.8 < 1$ gives decreasing returns to scale. A diminishing marginal product is a separate fact and holds for any exponent below 1.

@practice num
prompt: A firm produces with $q = K^{0.3}L^{0.7}$. What is its MRTS $= MP_L/MP_K$ at $K = 20$ and $L = 10$? Round to two decimal places.
answer: 4.67

@practice ms
prompt: A technology has the production function $q = \min\{K, 2L\}$. Which statements are true?
choice*: The isoquants are L-shaped, with corners where $K = 2L$.
choice*: Doubling both inputs doubles output.
choice*: To produce 20 units with no wasted input, the firm needs $K = 20$ and $L = 10$.

choice: Capital and labor are perfect substitutes.
hint: Evaluate $\min\{K, 2L\}$ at $(10, 5)$ and at $(10, 6)$.
solution: The isoquants have right-angle corners where $K = 2L$; $\min\{2K, 4L\} = 2\min\{K, 2L\}$ gives constant returns; and $\min\{20, 20\} = 20$ at $(20, 10)$. At $(10, 5)$ output is $\min\{10, 10\} = 10$ and at $(10, 6)$ it is still $\min\{10, 12\} = 10$, so extra labor adds nothing. The inputs are perfect complements, not substitutes.

```python
assert returns_to_scale(lambda K, L: K ** 0.5 * L ** 0.5, 4, 9) == "constant"
assert returns_to_scale(lambda K, L: K ** 0.7 * L ** 0.6, 3, 5) == "increasing"

```
model:
```python
import math


def returns_to_scale(f, K, L):
    """Classify returns to scale by doubling both inputs."""
    doubled = f(2 * K, 2 * L)
    twice = 2 * f(K, L)
    if math.isclose(doubled, twice, rel_tol=1e-9):
        return "constant"
    if doubled > twice:
        return "increasing"
    return "decreasing"
```
hint: Compute the output with doubled inputs and compare it with twice the original output.
hint: Check for equality first (with the tolerance), then decide between larger and smaller.
solution: Evaluate `f(2K, 2L)` and `2 f(K, L)`. If they match within the tolerance, returns are constant; if the first is larger, increasing; otherwise decreasing. The `K + L + 5` test has a fixed amount in it, so doubling inputs less than doubles output.

@quiz num
prompt: A firm has the production function $q = 8K^{0.25}L^{0.75}$. At $K = 81$ and $L = 16$, what is the marginal product of labor?
answer: 9
tol: 0.01
check: 0.75 * 8 * 81 ** 0.25 * 16 ** 0.75 / 16
hint: For $q = AK^{a}L^{b}$, $MP_L = b\,q/L$.
solution: $q = 8(3)(8) = 192$ because $81^{0.25} = 3$ and $16^{0.75} = 8$. So $MP_L = 0.75 \times 192/16 = 9$ units of output per unit of labor.

@quiz num
prompt: A consumer has $U = x^{0.4}y^{0.6}$ and income \$200, with demand for $x$ given by $x = 0.4\,m/p_x$. The price of $x$ falls from \$5 to \$4 and the price of $y$ stays the same. What is the substitution effect on her demand for $x$, in units? Round to one decimal place.
answer: 2.4
tol: 0.1
check: 0.4 * (200 + (4 - 5) * (0.4 * 200 / 5)) / 4 - 0.4 * 200 / 5
hint: Original demand is $0.4(200)/5 = 16$. The Slutsky income is $m + (p' - p)\,x^{A}$: the income at which the old bundle is just affordable at the new price.
solution: $x^{A} = 16$. Slutsky income $m' = 200 + (4 - 5)(16) = 184$. Demand at $(4, 184)$ is $0.4(184)/4 = 18.4$, so the substitution effect is $18.4 - 16 = +2.4$ units. (The income effect is $20 - 18.4 = +1.6$ units.)

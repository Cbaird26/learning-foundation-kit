@article
The **strategic asset allocation** (SAA) is the long-run mix of asset classes, such as 60% equities and 40% bonds, that is expected to meet the client's return objective within the client's risk objective. Decades of evidence suggest that the asset-class mix explains most of the variation in a diversified portfolio's returns over time, which is why the SAA gets the most attention in the IPS.

### Capital market assumptions

Allocation starts from **capital market assumptions** (CMAs): expected returns, standard deviations and correlations for each asset class. The following hypothetical annual assumptions (arithmetic expected returns, no forecast of any real market) are used in this lesson and the next:

| Asset class | Expected return | Standard deviation |
|---|---|---|
| US equity | 8.0% | 16% |
| International equity | 8.5% | 19% |
| Bonds | 4.0% | 6% |
| Cash (risk-free rate) | 2.5% | 0% |

Correlations: US equity with international equity 0.80, US equity with bonds 0.15, international equity with bonds 0.10. The **covariance** of assets $i$ and $j$ is $\sigma_{ij} = \rho_{ij}\sigma_i\sigma_j$; for US equity and bonds it is $0.15 \times 0.16 \times 0.06 = 0.00144$.

### Portfolio return and risk

With weights $w_i$, expected return is $E(R_p) = \sum_i w_i E(R_i)$ and variance is
$$\sigma_p^2 = \sum_i\sum_j w_i w_j \sigma_{ij},$$
a double sum over the covariance matrix (the diagonal terms $\sigma_{ii} = \sigma_i^2$ are variances). All figures are annual, with returns as decimals.

### The efficient frontier and the minimum-variance portfolio

Plot every feasible portfolio with standard deviation on the horizontal axis and expected return on the vertical axis. The **efficient frontier** is the upper-left boundary: for each level of risk, the highest expected return. Its leftmost point is the **global minimum-variance portfolio** (GMV). For two risky assets with standard deviations $\sigma_1, \sigma_2$ and correlation $\rho$, the weight in asset 1 that minimizes variance is
$$w_1^{*} = \frac{\sigma_2^2 - \rho\sigma_1\sigma_2}{\sigma_1^2 + \sigma_2^2 - 2\rho\sigma_1\sigma_2}, \qquad w_2^{*} = 1 - w_1^{*}.$$
(With this formula, a negative weight means a short position, so check that the answer is between 0 and 1 for a long-only portfolio.)

### The Sharpe ratio and the capital allocation line

The **Sharpe ratio** of a portfolio is $S = \dfrac{E(R_p) - R_f}{\sigma_p}$, excess return per unit of risk. When investors can lend and borrow at the risk-free rate $R_f$, combining it with a risky portfolio $P$ traces the **capital allocation line** (CAL), a straight line with slope $S_P$:
$$E(R) = R_f + S_P \cdot \sigma.$$
The risky portfolio with the highest Sharpe ratio is the **tangency portfolio**: the CAL through it dominates every other line. The investor then picks how far along the line to go with the IPS: a risk objective sets the standard deviation, and the CAL gives the expected return.

### Practical limits

Optimizers are very sensitive to inputs. Small changes in expected returns can swing the weights, so unconstrained optimization tends to magnify estimation errors ("error maximization"). Practitioners add constraints (long-only, ranges), average inputs, resample, blend views with a market equilibrium (the Black-Litterman approach), or budget risk by asset class. Allocation also depends on liabilities: a pension fund optimizes the surplus, not the asset return alone.

@example
title: The minimum-variance mix of equities and bonds
problem: Using the CMAs above, find the global minimum-variance portfolio of US equity and bonds, and its expected return and standard deviation.
step: Use $\sigma_1 = 0.16$ (equity), $\sigma_2 = 0.06$ (bonds), $\rho = 0.15$. Numerator: $0.06^2 - 0.15 \times 0.16 \times 0.06 = 0.0036 - 0.00144 = 0.00216$.
step: Denominator: $0.16^2 + 0.06^2 - 2 \times 0.15 \times 0.16 \times 0.06 = 0.0256 + 0.0036 - 0.00288 = 0.02632$.
step: $w_{\text{equity}} = 0.00216/0.02632 = 8.21\%$, so $w_{\text{bonds}} = 91.79\%$.
step: Expected return $= 0.0821 \times 8\% + 0.9179 \times 4\% = 4.33\%$. Variance $= 0.0821^2(0.0256) + 0.9179^2(0.0036) + 2(0.0821)(0.9179)(0.00144) = 0.003422$, so $\sigma_p = 5.85\%$, a little below the 6% of bonds alone.
answer: 8.21% equity and 91.79% bonds; expected return 4.33% and standard deviation 5.85%.

@example
title: Setting risk on the capital allocation line
problem: A risky portfolio has an expected return of 7.5% and a standard deviation of 11%; the risk-free rate is 2.5%. A client's IPS allows a standard deviation of 15%. What expected return can the client target, and what weight in the risky portfolio does that need? Ignore borrowing costs above the risk-free rate.
step: Sharpe ratio: $(7.5 - 2.5)/11 = 0.4545$.
step: Along the CAL, $E(R) = 2.5\% + 0.4545 \times 15\% = 9.32\%$.
step: The weight in the risky portfolio is $15/11 = 136.4\%$, so the client borrows 36.4% of capital at the risk-free rate.
step: If borrowing is not permitted by the IPS, the best a long-only, unlevered investor can do on this line is $E(R) = 7.5\%$ at 11% risk, and a higher return would need a riskier portfolio instead.
answer: Expected return 9.32% with 136.4% invested in the risky portfolio (borrowing 36.4%).

@mistakes
- Averaging the standard deviations with the weights; portfolio risk needs the covariances.
- Using correlation where covariance belongs (or the reverse) in the variance formula.
- Treating a mean-variance optimizer's output as precise: its weights are only as good as the CMAs.
- Choosing the portfolio with the highest Sharpe ratio regardless of the client's risk objective, instead of using the CAL to scale risk.

model:
```python
import math


def portfolio_stats(weights, mu, cov):
    """Expected return and standard deviation of a portfolio."""
    n = len(weights)
    expected = sum(w * m for w, m in zip(weights, mu))
    variance = sum(weights[i] * weights[j] * cov[i][j]
                   for i in range(n) for j in range(n))
    return expected, math.sqrt(variance)
```
hint: The expected return is the dot product of the weights and the expected returns.
hint: The variance is a double loop over $i$ and $j$ of `weights[i] * weights[j] * cov[i][j]`; include the diagonal terms and both orderings of each pair.
solution: Compute the weighted average of `mu`, then add up every term of the double sum, so each covariance appears twice (as $\sigma_{ij}$ and $\sigma_{ji}$). Take the square root of the variance. Leveraged weights such as `1.5` and `-0.5` work without any change, and the tests compare floats with `math.isclose`.

@quiz mc
prompt: An analyst runs an unconstrained mean-variance optimizer on expected returns that have been estimated from five years of data. The recommended weights swing wildly when one asset's expected return is changed by half a percentage point. What is the best explanation and response?
choice: The optimizer is broken, because small input changes should never change the optimal weights
choice*: Optimizers magnify estimation errors in the inputs, so the analyst should constrain the weights, average or resample inputs, or blend them with equilibrium assumptions
choice: The correlations must be wrong, so the analyst should set every correlation to zero
choice: The analyst should always choose the portfolio with the most extreme weights, because they carry the most information
hint: Mean-variance optimization amplifies differences in expected returns between similar assets.
solution: This is the well-known sensitivity of mean-variance optimization to its inputs: similar assets with slightly different expected returns produce large offsetting positions. Remedies are weight constraints, averaging or resampling inputs, and blending views with market-implied returns, as in the Black-Litterman approach. Setting correlations to zero would only introduce a different error.

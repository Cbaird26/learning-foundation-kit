@article
Earning a profit is not enough: a profit that does not cover the cost of the capital used destroys value. **Residual income** (RI) charges earnings for the equity capital employed, so it measures profit *after* a fair return to shareholders.

### Residual income for equity

$$\text{RI}_t = NI_t - r_E\, B_{t-1} = (\text{ROE}_t - r_E)\,B_{t-1},$$

where $NI_t$ is net income, $B_{t-1}$ is the book value of equity at the start of the year, $r_E$ is the cost of equity and $\text{ROE}_t = NI_t/B_{t-1}$. Residual income is positive when the firm earns more than its cost of equity.

### The residual income model

Equity value is today's book value plus the present value of all future residual income:

$$V_0 = B_0 + \sum_{t=1}^{N} \frac{\text{RI}_t}{(1 + r_E)^t} + \frac{TV_N}{(1 + r_E)^N}.$$

Book value evolves by the **clean surplus relation**, $B_t = B_{t-1} + NI_t - D_t$, where $D_t$ is dividends and repurchases net of new share issues: all changes in equity flow through net income. (Items booked directly to equity, such as some unrealized gains in other comprehensive income, break it; adjust for them.) The model is equivalent to the dividend discount model when clean surplus holds.

**Terminal value with persistence.** Superior returns tend to fade as competitors respond. Model residual income after year $N$ as $\text{RI}_{N+k} = \omega^k\,\text{RI}_N$, with persistence factor $0 \le \omega \le 1$. Then

$$TV_N = \frac{\omega\,\text{RI}_N}{1 + r_E - \omega}.$$

With $\omega = 0$ the advantage vanishes at once ($TV_N = 0$, and the value is book plus the explicit residual income); with $\omega = 1$ it lasts forever and $TV_N = \text{RI}_N/r_E$.

### Link to price to book

Dividing by $B_0$: $\dfrac{V_0}{B_0} = 1 + \dfrac{PV(\text{RI})}{B_0}$. A firm trades above book value only if the market expects positive residual income, that is, ROE above the cost of equity. If a firm is expected always to earn exactly $r_E$, its value equals its book value.

### Economic profit for the whole firm

For all capital, **economic profit** (also EVA, a trademarked name for a similar measure) is

$$\text{EP}_t = \text{NOPAT}_t - \text{WACC}\times IC_{t-1} = (\text{ROIC}_t - \text{WACC})\,IC_{t-1},$$

where $IC$ is invested capital (operating assets less operating liabilities). Firm value is

$$V_0^{\text{ops}} = IC_0 + \sum_{t=1}^{\infty} \frac{\text{EP}_t}{(1+\text{WACC})^t}.$$

For a level economic profit forever, the sum is $\text{EP}/\text{WACC}$.

### Strengths and cautions

The residual income model puts much of the value in today's book value, so it is less sensitive to the terminal value than a DCF, and it works when free cash flow is negative. It relies on the quality of accounting: aggressive revenue recognition, write-offs and asset revaluations distort book value and net income. Because the model and a DCF are consistent only when the assumptions match, it is useful as a cross-check.

@example
title: Residual income valuation with fading advantage
problem: Bellwether Foods has book equity of \$1,000 million and a cost of equity of 10%. ROE on beginning book value is forecast at 14%, 13% and 12% in years 1 to 3. The firm pays out 50% of net income each year. After year 3 residual income fades with persistence factor $\omega = 0.5$. Value the equity.
step: Year 1: $NI = 0.14 \times 1{,}000 = 140$; $\text{RI} = 140 - 0.10 \times 1{,}000 = 40$. Dividends 70, so $B_1 = 1{,}070$.
step: Year 2: $NI = 0.13 \times 1{,}070 = 139.1$; $\text{RI} = 139.1 - 107 = 32.1$; dividends 69.55, so $B_2 = 1{,}139.55$. Year 3: $NI = 0.12 \times 1{,}139.55 = 136.746$; $\text{RI} = 136.746 - 113.955 = 22.791$.
step: $PV(\text{RI}) = 40/1.1 + 32.1/1.1^2 + 22.791/1.1^3 = 36.364 + 26.529 + 17.123 = 80.016$.
step: $TV_3 = 0.5 \times 22.791/(1.10 - 0.5) = 18.9925$; its present value is $18.9925/1.331 = 14.269$.
step: $V_0 = 1{,}000 + 80.016 + 14.269 = \$1{,}094.29$ million, a price to book ratio of 1.09.
answer: About \$1,094.3 million (1.09 times book).

@example
title: Economic profit and enterprise value
problem: Fernhill Packaging earns NOPAT of \$150 million on invested capital of \$1,200 million. Its WACC is 9%. Assume NOPAT and invested capital stay level forever. Compute economic profit and enterprise value, and check the answer against a perpetuity of NOPAT.
step: $\text{EP} = 150 - 0.09 \times 1{,}200 = 150 - 108 = \$42$ million a year.
step: Level EP forever has present value $42/0.09 = \$466.67$ million.
step: $V^{\text{ops}} = IC_0 + PV(\text{EP}) = 1{,}200 + 466.67 = \$1{,}666.67$ million.
step: A level NOPAT of 150 forever is worth $150/0.09 = \$1{,}666.67$ million, the same. (With level capital there is no reinvestment, so FCFF equals NOPAT.) The two approaches agree.
answer: EP = \$42 million; enterprise value = \$1,666.67 million.

@mistakes
- Charging no cost for equity (or deducting only interest) and calling net income "residual income".
- Using ending instead of beginning book value to compute the capital charge.
- Violating clean surplus (forgetting dividends or share issues when rolling book value forward).
- Assuming residual income stays at its year-$N$ level forever, which makes the value too high when competition erodes excess returns.

model:
```python
def ri_value(book, cost_equity, net_incomes, dividends, persistence=0.0):
    """Equity value: book value plus the present value of residual income."""
    value = book
    current_book = book
    residual = 0.0
    for year, (income, dividend) in enumerate(zip(net_incomes, dividends), 1):
        residual = income - cost_equity * current_book
        value += residual / (1 + cost_equity) ** year
        current_book += income - dividend
    years = len(net_incomes)
    terminal = persistence * residual / (1 + cost_equity - persistence)
    value += terminal / (1 + cost_equity) ** years
    return value
```
hint: Update the running book value after computing each year's residual income.
hint: The last year's residual income feeds the terminal value; with no forecast years it is zero.
solution: Loop through the years: charge cost of equity on the beginning book value, discount the residual income, then roll the book value forward with net income less dividends. After the loop, discount the terminal value built from the last residual income and the persistence factor.

prompt: A firm has book equity of \$800 million and a cost of equity of 9%. Net income is forecast at \$100 million in year 1 and \$104 million in year 2, with dividends of \$40 million in each year. After year 2, residual income fades with persistence factor $\omega = 0.6$ (terminal value at year 2 is $\omega\,\text{RI}_2/(1 + r_E - \omega)$). Compute the equity value in millions of dollars to the nearest whole number. Discount at year end.
answer: 875
lead: \$
tol: 1
check: 800 + (100 - 0.09 * 800) / 1.09 + (104 - 0.09 * (800 + 100 - 40)) / 1.09 ** 2 + 0.6 * (104 - 0.09 * (800 + 100 - 40)) / (1.09 - 0.6) / 1.09 ** 2
hint: $B_1 = 800 + 100 - 40 = 860$. Compute $\text{RI}_1$ and $\text{RI}_2$.
hint: $\text{RI}_1 = 28$ and $\text{RI}_2 = 104 - 0.09 \times 860 = 26.6$.
solution: $\text{RI}_1 = 100 - 72 = 28$ and $B_1 = 860$, so $\text{RI}_2 = 104 - 77.4 = 26.6$. The present value of the two is $28/1.09 + 26.6/1.09^2 = 25.69 + 22.39 = 48.08$. The terminal value is $0.6 \times 26.6/(1.09 - 0.6) = 32.57$, with present value $32.57/1.1881 = 27.41$. Value $= 800 + 48.08 + 27.41 = \$875.5$ million.

@article
The NPV rule treats a project as a fixed plan: invest now, collect the cash flows. In reality managers can respond to what they learn: expand if the market is strong, abandon if it is weak, wait for information before committing. This flexibility has value that static NPV ignores, and **real options** analysis measures it.

### Types of real options

- **Option to expand** (a call): invest more later if the project does well.
- **Option to delay** (a call): wait to decide before paying the investment cost.
- **Option to abandon** (a put): sell or shut the project for a salvage value if it does poorly.
- **Option to switch** (inputs, outputs or location) and **to stage** investment in steps.

Expanded NPV is

$$\text{NPV}_{\text{expanded}} = \text{NPV}_{\text{static}} + \text{value of the options}.$$

A project with a negative static NPV may be worth doing if it gives a valuable follow-on option. Options are most valuable when uncertainty is high, because the holder keeps the upside and avoids the downside.

### The mapping to financial options

| Financial option | Real option |
|---|---|
| Stock price $S$ | Present value of the project's expected cash flows $V$ |
| Strike price $K$ | Investment cost to exercise (expand or launch) |
| Time to expiry $T$ | Time until the decision must be made |
| Volatility $\sigma$ | Uncertainty in the project's value |
| Risk-free rate $r$ | Risk-free rate |
| Dividend yield $q$ | Cash flows lost by waiting (value leakage) |

### The binomial model

Over one period the project value $V$ moves to $uV$ or $dV$. The **risk-neutral probability** of the up move is

$$p = \frac{1 + r_f - d}{u - d},$$

and an option with payoffs $C_u$ and $C_d$ is worth

$$C_0 = \frac{p\,C_u + (1 - p)\,C_d}{1 + r_f}.$$

These are not real-world probabilities: $p$ is the probability that makes the expected return on $V$ equal the risk-free rate, so discounting at $r_f$ is right. For several periods, work backward from the end of the tree. At each node value is the discounted risk-neutral average of the two next nodes (for a European-style option, taking the exercise decision at expiry). For an expansion option that multiplies the project by a factor $f$ at cost $I$, the payoff is $\max(fV - I, 0)$.

### The Black-Scholes-Merton model

For a European option to delay investment at cost $K$ with $T$ years to decide, continuous rate $r$ and leakage $q$:

$$C = V e^{-qT}N(d_1) - K e^{-rT}N(d_2), \quad d_1 = \frac{\ln(V/K) + (r - q + \sigma^2/2)T}{\sigma\sqrt{T}}, \quad d_2 = d_1 - \sigma\sqrt{T}.$$

Waiting is costly if the project's cash flows are lost (competitors may enter, or cash flows are delayed), so a high $q$ makes the option worth less.

### Cautions

The underlying project value is not traded, so $V$ and $\sigma$ must be estimated: put a range on them. The option is worth something only if the firm has an exclusive right to exercise it (a patent, a license, a unique position); in a competitive market rivals will take the opportunity. Options also interact, and the model gives a value, not a decision.

@example
title: An option to expand
problem: Halden Retail's new store format has a present value of cash flows of \$500 million today and an investment cost of \$480 million. In one year the value will be \$650 million (up, factor 1.3) or \$400 million (down, factor 0.8). If the format succeeds, the company may expand by 50% at an additional cost of \$300 million. The risk-free rate is 5%. Find the static NPV, the risk-neutral probability, the value of the expansion option and the expanded NPV.
step: Static NPV: $500 - 480 = \$20$ million. Risk-neutral probability: $p = (1.05 - 0.8)/(1.3 - 0.8) = 0.5$.
step: Expansion payoff $= \max(0.5V - 300, 0)$. Up: $0.5 \times 650 - 300 = 25$. Down: $0.5 \times 400 - 300 = -100$, so the company does not expand and the payoff is 0.
step: Option value: $C_0 = (0.5 \times 25 + 0.5 \times 0)/1.05 = \$11.90$ million.
step: Expanded NPV $= 20 + 11.90 = \$31.90$ million. The option adds about 60% to the project's value even though expansion would be unprofitable in the down case.
answer: Static NPV \$20 million; $p = 0.5$; option value \$11.90 million; expanded NPV \$31.90 million.

@example
title: The option to wait
problem: A firm holds the exclusive license to launch a product. Launching requires an investment of \$105 million, and the present value of the cash flows is \$100 million, so launching today has an NPV of $-\$5$ million. The license lasts 2 years. Project value has volatility of 30%, the continuous risk-free rate is 4% and the cash flows lost each year by waiting are 4% of value ($q = 4\%$). Value the option to launch.
step: $d_1 = [\ln(100/105) + (0.04 - 0.04 + 0.045)(2)]/(0.30\sqrt{2}) = (-0.04879 + 0.09)/0.42426 = 0.0971$ and $d_2 = 0.0971 - 0.4243 = -0.3271$.
step: $N(d_1) = 0.5387$ and $N(d_2) = 0.3718$.
step: $C = 100e^{-0.08}(0.5387) - 105e^{-0.08}(0.3718) = 92.31(0.5387) - 96.92(0.3718)$. The value is about \$13.69 million.
step: Although launching today destroys \$5 million, the right to wait and launch only if the product proves attractive is worth about \$13.7 million. The firm should exercise only when the value of launching sufficiently exceeds the option's value.
answer: About \$13.69 million.

@mistakes
- Using real-world probabilities (such as 60% up, 40% down) in the binomial valuation while discounting at the risk-free rate; use the risk-neutral probability.
- Forgetting that the payoff of an option is never negative: in the bad state the firm simply does not expand.
- Valuing an option that the firm does not exclusively hold, so rivals can take the opportunity.
- Adding the option value without checking that static NPV was computed without the option's cash flows (double counting).

model:
```python
def binomial_call(s0, k, u, d, rf, steps):
    """European call value on a recombining binomial tree."""
    p = (1 + rf - d) / (u - d)
    values = [max(s0 * u ** j * d ** (steps - j) - k, 0.0)
              for j in range(steps + 1)]
    for n in range(steps, 0, -1):
        values = [(p * values[j + 1] + (1 - p) * values[j]) / (1 + rf)
                  for j in range(n)]
    return values[0]
```
hint: Start with the payoffs at expiry for every number of up moves, then roll back one period at a time.
hint: After each step the list of node values is one shorter; stop when one value is left.
solution: Compute the payoff at each of the `steps + 1` terminal nodes (j up moves and `steps - j` down moves). Then move back period by period, replacing each pair of adjacent nodes by the discounted risk-neutral average. The single remaining value is the option's value today. The tests use a two-step case, a zero-step case and a case with a positive risk-free rate.

Value the abandonment option today, in millions of dollars to two decimal places.

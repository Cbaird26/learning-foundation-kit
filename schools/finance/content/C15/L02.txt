@article
A discounted cash flow (DCF) valuation rests on one idea from your first finance course: an asset is worth the present value of the cash it will deliver, discounted at a rate that reflects the risk of that cash. For a company, the cash is free cash flow, so the value of the operations is

$$V_0^{\text{ops}} = \sum_{t=1}^{N} \frac{\text{FCFF}_t}{(1 + \text{WACC})^t} + \frac{TV_N}{(1 + \text{WACC})^N}.$$

$TV_N$ is the **terminal value**, the value at year $N$ of all cash flows after the explicit forecast. This week the terminal value is given; week 3 shows how to estimate it.

### Match the cash flow with the rate

FCFF belongs to lenders and shareholders together, so it is discounted at the **weighted average cost of capital**:

$$\text{WACC} = \frac{E}{V}\,r_E + \frac{D}{V}\,r_D(1 - t),$$

with $E$ and $D$ the market values of equity and debt, $V = D + E$, $r_E$ the cost of equity (for example from the CAPM), $r_D$ the pretax cost of debt and $t$ the marginal tax rate. The result is **enterprise value**, the value of the operating business. FCFE belongs to shareholders only, so it is discounted at $r_E$ and gives equity value directly. Never discount FCFF at $r_E$: the cash flow includes lenders' share, and the rate omits their cheaper financing.

### From enterprise value to equity value

Enterprise value is not what shareholders own. Subtract claims ahead of them and add assets whose cash flows are not in FCFF:

$$\text{Equity value} = EV - \text{debt} - \text{preferred stock} - \text{noncontrolling interests} + \text{cash and non-operating assets}.$$

Divide by diluted shares outstanding for **value per share**. Debt here means market (or fair) value of interest-bearing obligations; lease liabilities are included if lease costs were kept out of EBIT and excluded if the lease cost was deducted in EBIT. State which you did.

### Timing: end-of-year and mid-year

The formula above is the **end-of-year convention**: each year's FCFF is assumed to arrive on the last day of the year. Cash flows really arrive through the year, so many practitioners use the **mid-year convention**, discounting $\text{FCFF}_t$ for $t - 0.5$ years:

$$PV = \sum_{t=1}^{N} \frac{\text{FCFF}_t}{(1 + \text{WACC})^{t - 0.5}}.$$

This multiplies the present value of the forecast flows by $(1 + \text{WACC})^{0.5}$. A terminal value taken as an exit-multiple price at year $N$ is still discounted $N$ years; week 3 treats the Gordon-growth case. Whichever you use, say so, and use the same convention for every company you compare.

### Reading a DCF critically

A DCF is only as good as its inputs. A valuation date, the explicit forecast horizon (long enough for growth and margins to settle), the WACC and the terminal value each deserve scrutiny. Because the terminal value is often more than half of enterprise value, the final answer is better presented as a range with a sensitivity table than as one number.

@example
title: From cash flows to a price per share
problem: Larkspur Outfitters is forecast to generate FCFF of \$60 million, \$66 million and \$72 million in years 1 to 3. At the end of year 3 the operations are worth \$1,200 million (a given terminal value). The WACC is 10%. Net debt (debt minus cash) is \$250 million and there are 40 million shares. Use end-of-year discounting. Find the value per share.
step: Discount the forecast flows: $60/1.10 = 54.545$, $66/1.10^2 = 54.545$, $72/1.10^3 = 54.095$. The sum is \$163.186 million.
step: Discount the terminal value: $1{,}200/1.10^3 = \$901.577$ million.
step: Enterprise value: $163.186 + 901.577 = \$1{,}064.763$ million.
step: Equity value: $1{,}064.763 - 250 = \$814.763$ million. Per share: $814.763/40 = \$20.37$.
answer: Enterprise value \$1,064.8 million; equity value \$814.8 million; \$20.37 per share.

@example
title: End-of-year versus mid-year
problem: Using the same cash flows, terminal value, WACC and net debt as Larkspur above (FCFF of \$60, \$66 and \$72 million, terminal value \$1,200 million at year 3, WACC 10%, net debt \$250 million, 40 million shares), recompute the value per share with mid-year discounting of the forecast flows.
step: The forecast flows are discounted for 0.5, 1.5 and 2.5 years. The sum of present values is $163.186 \times 1.10^{0.5} = \$171.150$ million.
step: The terminal value is an exit price at the end of year 3, so it is still discounted three years: \$901.577 million.
step: Enterprise value: $171.150 + 901.577 = \$1{,}072.728$ million. Equity value: $1{,}072.728 - 250 = 822.728$, or \$20.57 per share.
step: The mid-year convention adds about \$0.20 per share here, because only 15% of enterprise value comes from the forecast flows. The effect grows when the forecast carries more of the value.
answer: \$20.57 per share, about \$0.20 above the end-of-year value.

@mistakes
- Discounting FCFF at the cost of equity (or FCFE at the WACC): the rate must match the investors who own the cash flow.
- Forgetting to subtract debt, preferred stock and noncontrolling interests, or subtracting gross debt while also adding cash twice.
- Using the book value of debt or equity in the WACC weights when market values are available.
- Applying the mid-year convention to the terminal value without thinking about how the terminal value was computed.

model:
```python
def dcf_value(flows, wacc, terminal_value=0.0, mid_year=False):
    """Enterprise value from forecast FCFF and a terminal value at year N."""
    shift = 0.5 if mid_year else 0.0
    value = 0.0
    for year, flow in enumerate(flows, start=1):
        value += flow / (1 + wacc) ** (year - shift)
    value += terminal_value / (1 + wacc) ** len(flows)
    return value
```
hint: Use `enumerate(flows, start=1)` so the first flow is year 1.
hint: The exponent for a flow is `year - 0.5` under the mid-year convention; the terminal value always uses `len(flows)`.
solution: Loop over the flows with the year number starting at 1, discounting each by `(1 + wacc) ** (year - shift)` where `shift` is 0.5 under the mid-year convention. Add the terminal value discounted by the full number of forecast years.

@article
**Capital budgeting** is the process of deciding which long-term investments a firm should undertake: a new plant, a product line, a fleet of vehicles. Every such decision exchanges cash now for a stream of cash later, so the tools are those of the time value of money. The goal from week 1 gives the guiding principle: take projects that increase the value of the owners' equity.

### Net present value

The **net present value** (NPV) of a project with cash flows $CF_0, CF_1, \ldots, CF_N$ at times $0, 1, \ldots, N$ and discount rate $r$ is

$$NPV = \sum_{t=0}^{N}\frac{CF_t}{(1+r)^t}.$$

$CF_0$ is usually negative (the investment), and the **discount rate** is the project's required return, its opportunity cost of capital (we estimate it in weeks 9 to 11). The **NPV rule**: accept a project if $NPV > 0$ and reject it if $NPV < 0$. The NPV is the value the project adds to the firm in today's dollars, so it measures exactly what the goal of the firm asks. NPVs of independent projects can be added. Conventions: the first cash flow is at time 0 and later ones at the end of each year. (A spreadsheet's NPV function assumes the first flow is at time 1, so add the time 0 flow outside the function.)

### Internal rate of return

The **internal rate of return** (IRR) is the discount rate that makes NPV zero:

$$0 = \sum_{t=0}^{N}\frac{CF_t}{(1+IRR)^t}.$$

The **IRR rule**: accept if the IRR exceeds the required return. For a conventional project (one outflow, then inflows) with a positive NPV at some rate, IRR and NPV give the same decision. A closed form exists only for very short projects, so we find the IRR by trial and error or a numerical method such as bisection.

### Payback and discounted payback

The **payback period** is the time until the cumulative (undiscounted) cash flows turn nonnegative. When payback falls within a year, we interpolate: if the cumulative flow is $-\$18{,}000$ at the end of year 2 and year 3 brings \$21,000, payback is $2 + 18{,}000/21{,}000$ years. The **discounted payback** uses the present values of cash flows. Payback is easy to explain and is a rough guide to liquidity and risk, but it ignores the time value of money (the simple version), ignores cash flows after the cutoff, and its cutoff is arbitrary. Discounted payback fixes the first problem only. Neither tells you the value added.

### Profitability index

The **profitability index** is $PI = PV(\text{future flows}) / \text{initial investment}$, or $1 + NPV/\text{investment}$ when $CF_0$ is the investment. PI above 1 means a positive NPV. It is useful when capital is limited, to rank projects by value per dollar.

### When IRR misleads

1. **Mutually exclusive projects** (only one can be chosen). IRR ignores scale and timing, so a small project with a high IRR can beat a larger project with a lower IRR, while the larger one adds more value. When NPV and IRR conflict, follow NPV.
2. **Multiple IRRs.** A project whose cash flows change sign more than once (a **nonconventional** project, for example a mine with a clean-up cost at the end) can have several IRRs or none, so the IRR rule is unreliable. NPV is always well defined.

The **NPV profile** plots NPV against the discount rate. It crosses the horizontal axis at the IRR. For a conventional project it slopes down.

### A programmer's view

To find an IRR numerically, search for the rate where NPV changes sign, halving the interval each time (bisection). For a conventional project that is well defined and takes only a few dozen steps for high precision.

@example
title: Evaluating a four-year project
problem: A project costs \$50,000 now and returns \$14,000, \$18,000, \$21,000 and \$16,000 at the ends of years 1 to 4. The required return is 10%. Find the NPV, IRR, payback, discounted payback and profitability index.
step: Present values at 10%: $14{,}000/1.1 = 12{,}727$; $18{,}000/1.21 = 14{,}876$; $21{,}000/1.331 = 15{,}778$; $16{,}000/1.4641 = 10{,}928$. They sum to \$54,309, so $NPV = 54{,}309 - 50{,}000 = \$4{,}309.13$. Accept.
step: The IRR solves $NPV = 0$: at 13% the NPV is +\$853 and at 14% it is $-\$221$, so the root is about 13.79%, above 10%, which agrees with accepting.
step: Payback: cumulative flows are $-36{,}000$, $-18{,}000$ and $+3{,}000$ after years 1, 2 and 3, so payback is $2 + 18{,}000/21{,}000 = 2.86$ years.
step: Discounted payback: cumulative present values are $-37{,}273$, $-22{,}397$, $-6{,}619$ and $+4{,}309$, so $3 + 6{,}619/10{,}928 = 3.61$ years. The profitability index is $54{,}309/50{,}000 = 1.086$.
answer: NPV \$4,309.13; IRR about 13.79%; payback 2.86 years; discounted payback 3.61 years; PI 1.086.

@example
title: A project with two IRRs
problem: A project has cash flows of $-\$1{,}000$ now, $+\$2{,}900$ in year 1 and $-\$1{,}980$ in year 2. Find its IRRs and decide when to accept at a 5% and a 20% required return.
step: Set $NPV = 0$ and let $x = 1/(1+r)$: $-1{,}000 + 2{,}900x - 1{,}980x^2 = 0$, or $99x^2 - 145x + 50 = 0$. By the quadratic formula $x = (145 \pm 35)/198$, giving $x = 0.9091$ or $x = 0.5556$.
step: The IRRs are $r = 1/x - 1 = 10\%$ and $80\%$. The IRR rule is ambiguous because one project has two answers.
step: NPV: at 5% it is $-1{,}000 + 2{,}761.90 - 1{,}795.92 = -\$34.01$; at 20% it is $-1{,}000 + 2{,}416.67 - 1{,}375.00 = +\$41.67$. So the NPV is positive only for required returns between 10% and 80%: reject at 5% and accept at 20%.
answer: IRRs of 10% and 80%; reject at 5% (NPV $-\$34.01$), accept at 20% (NPV \$41.67).

@mistakes
- Accepting a project because its payback is short while its NPV is negative.
- Including the time 0 investment inside a spreadsheet's NPV function (which treats the first value as time 1) and so discounting it.
- Ranking mutually exclusive projects by IRR instead of by NPV.
- Comparing the IRR with the wrong benchmark, such as the interest rate on the loan used to finance the project, rather than the project's required return.

model:
```python
def irr(flows):
    """IRR by bisection on [-0.99, 10.0]; NPV changes sign once."""
    def npv(rate):
        return sum(cf / (1 + rate) ** t for t, cf in enumerate(flows))

    low, high = -0.99, 10.0
    npv_low = npv(low)
    for _ in range(200):
        mid = (low + high) / 2
        npv_mid = npv(mid)
        if npv_low * npv_mid <= 0:
            high = mid
        else:
            low, npv_low = mid, npv_mid
    return (low + high) / 2
```
hint: Write an inner function for NPV at a given rate, and keep an interval whose end points have NPVs of opposite signs.
hint: Compare the sign of the NPV at the midpoint with the sign at the low end, and replace the end point that has the same sign.
solution: Bisection keeps an interval where the NPV changes sign. Each pass evaluates the NPV at the midpoint; if its sign matches the sign at the low end, the root lies in the upper half, so the low end moves up, otherwise the high end moves down. After 200 halvings the interval is far smaller than needed. Checking the sign of the product also handles flows whose NPV rises with the rate (a borrower's cash flows).

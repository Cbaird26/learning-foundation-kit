@article
A project's NPV is computed from forecasts, and forecasts are wrong. A manager who sees an NPV of \$187,000 should ask how confident to be, which forecasts matter most and how bad things could get. This week gives three tools: **sensitivity analysis**, **scenario analysis** and **break-even analysis**. They do not make forecasts better, but they show where the risk is, and so where to spend effort on information.

### The model used in this lesson

A simple project: an investment $I$ at time 0, depreciated straight-line to zero over $N$ years, with annual units sold $Q$, price $P$, variable cost per unit $v$, fixed cash costs $FC$, tax rate $T$ and discount rate $r$. There is no salvage and no working capital, and cash flows come at year ends. Then

$$\text{OCF} = \big[(P - v)Q - FC\big](1 - T) + T\,\frac{I}{N}, \qquad NPV = -I + \text{OCF}\times\frac{1 - (1+r)^{-N}}{r}.$$

### Sensitivity analysis

Pick a base case, then change **one input at a time** over a plausible range while holding the others fixed, and record the NPV. The inputs whose changes move the NPV most are the project's **key risks**. A table or a **tornado chart** (a bar chart of NPV ranges, widest bar on top) shows this. Sensitivity analysis is easy but has limits: the inputs are usually related (a price cut raises volume), and it gives no probabilities.

### Scenario analysis

A **scenario** changes several inputs together to describe a coherent state of the world, such as a best, base and worst case. Assign each a probability, and compute the **expected NPV** and its **standard deviation** exactly as for expected return (week 9):

$$E(NPV) = \sum_s p_s\,NPV_s, \qquad \sigma = \sqrt{\sum_s p_s\,[NPV_s - E(NPV)]^2}.$$

A related approach is **Monte Carlo simulation**, in which inputs are drawn from distributions many times; it needs a computer and good estimates of the distributions. Scenario probabilities are judgment, not data.

### Break-even analysis

Break-even finds the sales level at which something equals zero. Define the **contribution margin** $P - v$ per unit.

- **Accounting break-even**: net income is zero, $Q = (FC + D)/(P - v)$ with $D$ annual depreciation. At this level accounting profit and taxes are zero and the OCF equals the depreciation $D$, which only returns the investment and leaves nothing for the cost of capital.
- **Cash break-even**: OCF is zero, which (ignoring tax) is $Q = FC/(P - v)$.
- **Financial break-even**: NPV is zero. This is the level that matters, and it is higher than the accounting break-even whenever the discount rate is positive.

The **degree of operating leverage** is the percentage change in OCF per percentage change in quantity, and it is higher when fixed costs are a large share of costs.

### Using the results

Large sensitivity to a variable the firm can learn about cheaply (a market test) suggests spending to learn it before investing. A positive expected NPV with a large chance of a big loss may or may not be acceptable. Finally, sensitivity and scenario analysis do not replace the NPV rule and do not change the discount rate: the discount rate already compensates for the risk of average outcomes.

@example
title: Windmere Cycles' e-bike line
problem: Windmere Cycles plans an e-bike line: investment \$2,400,000, depreciated straight-line to zero over 5 years, price \$1,800, variable cost \$1,100 per bike, fixed cash costs \$300,000 a year, 1,500 bikes a year, a 25% tax rate and a 10% discount rate. Find the base NPV, see how it varies with units sold, and find the financial and accounting break-even quantities.
step: Depreciation is \$480,000. $\text{OCF} = [(700)(1{,}500) - 300{,}000](0.75) + 0.25(480{,}000) = 562{,}500 + 120{,}000 = \$682{,}500$. The annuity factor is 3.790787, so $NPV = -2{,}400{,}000 + 682{,}500 \times 3.790787 = \$187{,}212$.
step: Vary units sold, others fixed:

| Units per year | OCF | NPV |
|---|---|---|
| 1,200 | \$525,000 | $-\$409{,}837$ |
| 1,350 | \$603,750 | $-\$111{,}312$ |
| 1,500 | \$682,500 | \$187,212 |
| 1,650 | \$761,250 | \$485,736 |
| 1,800 | \$840,000 | \$784,261 |

Each 150 bikes moves the NPV by about \$298,500.
step: Financial break-even: the project needs $\text{OCF} = 2{,}400{,}000/3.790787 = \$633{,}114$. Solving $(700Q - 300{,}000)(0.75) + 120{,}000 = 633{,}114$ gives $Q = 1{,}405.9$, so about 1,406 bikes: only 6.3% below the base forecast.
step: Accounting break-even: $Q = (300{,}000 + 480{,}000)/700 = 1{,}114.3$ bikes. At that volume accounting profit is zero, yet the OCF is just the depreciation, \$480,000, and the NPV is about $-\$580{,}000$ ($-2{,}400{,}000 + 480{,}000 \times 3.790787$), because the project only gets its investment back and does not cover its cost of capital.
answer: Base NPV \$187,212; NPV zero at about 1,406 bikes a year; accounting break-even at about 1,114 bikes.

@example
title: Scenario analysis
problem: For the same project, a worst case (1,100 bikes, price \$1,700; probability 25%), a base case (1,500 bikes, \$1,800; 50%) and a best case (1,800 bikes, \$1,850; 25%) are considered, with all other inputs unchanged. Find the NPV in each scenario, the expected NPV and its standard deviation.
step: The scenario NPVs are $-\$921{,}593$ (worst), \$187,212 (base) and \$1,040,139 (best).
step: $E(NPV) = 0.25(-921{,}593) + 0.50(187{,}212) + 0.25(1{,}040{,}139) = \$123{,}242$.
step: $\sigma^2 = 0.25(-1{,}044{,}835)^2 + 0.50(63{,}970)^2 + 0.25(916{,}897)^2$, so $\sigma \approx \$696{,}521$.
step: The expected NPV is positive but small relative to its spread, and the worst case loses about \$0.9 million: the decision depends on how much risk the firm can tolerate and how well it can forecast demand and price.
answer: NPVs of $-\$921{,}593$, \$187,212 and \$1,040,139; expected NPV \$123,242; standard deviation about \$696,521.

@mistakes
- Changing several inputs at once and calling the result a sensitivity analysis: a sensitivity changes one input at a time; a scenario changes several together.
- Treating the accounting break-even as the point at which the project is worth undertaking: it ignores the time value of money.
- Reading scenario probabilities as statistical facts rather than judgments.
- Forgetting that depreciation is still added back in the cash flows at the accounting break-even, so the OCF there equals depreciation, not zero.

model:
```python
def project_npv(inputs):
    depreciation = inputs["investment"] / inputs["life"]
    margin = (inputs["price"] - inputs["var_cost"]) * inputs["units"]
    ocf = ((margin - inputs["fixed_cost"]) * (1 - inputs["tax_rate"])
           + inputs["tax_rate"] * depreciation)
    annuity = sum(1 / (1 + inputs["rate"]) ** t
                  for t in range(1, inputs["life"] + 1))
    return -inputs["investment"] + ocf * annuity


def sensitivity(inputs, name, values):
    """NPV for each value of one input, others held at their base values."""
    results = []
    for value in values:
        case = dict(inputs)
        case[name] = value
        results.append(project_npv(case))
    return results
```
hint: Copy the dictionary for each value so the original stays unchanged.
hint: Set `case[name] = value`, call `project_npv(case)` and append the result.
solution: For each value, make a copy of the inputs with `dict(inputs)`, replace the one input named `name`, and compute the NPV with the supplied function. Building a new list means the caller's dictionary is never changed, and an empty list of values gives an empty result.

@article
Discounting a callable bond's cash flows at one yield cannot work: its cash flows depend on future interest rates, because the issuer calls when rates are low. We need a model of how rates might evolve, and a way to value a bond along every path.

**Conventions.** Annual periods, annual coupons, par 100, and rates that are effective annual one-year rates. The tree is **recombining**: an up move followed by a down move equals a down move followed by an up move. Each move has probability 0.5 under the valuation (risk-neutral) measure. All numbers are hypothetical.

### The binomial interest-rate tree

A tree gives the one-year rate at each **node**. At time $t$ there are $t+1$ nodes, indexed by the number of up moves $j = 0, \dots, t$. Rates at a given date are linked by the volatility $\sigma$:

$$r_{t,j+1} = r_{t,j}\,e^{2\sigma}.$$

The rates at time $t$ are therefore geometrically spaced, and $\sigma$ is the annual volatility of the log of the one-year rate. The **calibration** step chooses the lowest rates at each date so that the tree prices every zero-coupon benchmark bond exactly: the tree's price of an $n$-year zero must equal $100/(1+z_n)^n$. That makes the model **arbitrage-free**: it reproduces the market's spot curve.

### Backward induction

To value a bond maturing at $T$ with annual coupon $C$ per 100 of par, define $V_{t,j}$ as the value at node $(t,j)$ **just after** the coupon paid at time $t$. At maturity $V_{T,j} = 100$ (the coupon due at $T$ is added when stepping back). At each earlier node:

$$V_{t,j} = \frac{\tfrac12\left(V_{t+1,j+1} + C\right) + \tfrac12\left(V_{t+1,j} + C\right)}{1 + r_{t,j}}.$$

For an option-free bond this reproduces the price from the spot curve. For a **callable bond** with call price $K$, at each call date $t$ the issuer redeems if the value exceeds the call price, so replace the node value by $\min(V_{t,j},\,K)$. For a **putable bond** replace it by $\max(V_{t,j},\,P_{\text{put}})$. The value at time 0 is the bond's model price. The difference between the straight and callable values is the **call option value** (in price terms), $V_{\text{call}} = V_{\text{straight}} - V_{\text{callable}}$.

### Option-adjusted spread

Suppose a callable bond trades at a market price $P_{\text{mkt}}$. The **option-adjusted spread (OAS)** is the constant $s$ added to **every one-year rate on the tree** so that the callable bond's model price equals $P_{\text{mkt}}$. It is the yield pick-up after removing the option's cost, so it measures compensation for credit and liquidity risk. Relationships:

$$\text{OAS} \approx \text{Z-spread} - \text{option cost}.$$

For a callable bond the OAS is below the Z-spread; for a putable bond it is above. OAS is a model-dependent measure: it changes with the assumed volatility, since higher volatility raises the call option's value and lowers OAS for a callable bond.

### Effective duration from a tree

To get effective duration, shift the whole curve by $\pm\Delta y$, recalibrate the tree, **hold the OAS constant**, and reprice to get $P_-$ and $P_+$; then $D_{\text{Eff}} = (P_- - P_+)/(2P_0\Delta y)$. Holding OAS constant isolates the effect of the option.

@mistakes
- Using a single yield to value a bond with an embedded option, ignoring that its cash flows change along each path.
- Applying the call price cap to the value that still includes the coupon paid at that date (cap the value after the coupon).
- Adding the OAS only to the first node instead of to every node on the tree.
- Thinking OAS is model-free: it depends on the assumed volatility and the tree.

model:
```python
def tree_value(rates, coupon, call_price=None):
    """Value of a bond on a recombining binomial interest-rate tree."""
    n = len(rates)
    values = [100.0] * (n + 1)
    for t in range(n - 1, -1, -1):
        new_values = []
        for j in range(t + 1):
            up = values[j + 1] + coupon
            down = values[j] + coupon
            value = 0.5 * (up + down) / (1 + rates[t][j])
            if call_price is not None and t >= 1:
                value = min(value, call_price)
            new_values.append(value)
        values = new_values
    return values[0]
```
hint: Start with value 100 at every node of time `n`, then step back one date at a time.
hint: At each node, add the coupon to the up and down values, average, discount at that node's rate, and apply the call cap when `t >= 1`.
solution: Backward induction replaces each node's value with the discounted average of the next period's values plus the coupon. The call cap `min(value, call_price)` models the issuer redeeming when the bond is worth more than the call price; it is not applied at time 0, where the bond is not yet callable.

### Radians

The **radian measure** of an angle is arc length divided by radius, $\theta = s/r$. A full turn is $2\pi$ radians, so

$$180^\circ = \pi \text{ rad}, \qquad \text{degrees} \times \frac{\pi}{180} = \text{radians}.$$

Calculus formulas for trig functions are only simple in radians, so work in radians unless told otherwise.

### The unit circle

Place an angle $\theta$ in standard position (counterclockwise from the positive $x$-axis). The point where its terminal side meets the circle $x^2 + y^2 = 1$ is $(\cos\theta, \sin\theta)$. This immediately gives the identity $\cos^2\theta + \sin^2\theta = 1$, and $\tan\theta = \dfrac{\sin\theta}{\cos\theta}$.

| $\theta$ | $0$ | $\pi/6$ | $\pi/4$ | $\pi/3$ | $\pi/2$ |
|---|---|---|---|---|---|
| $\sin\theta$ | $0$ | $\tfrac12$ | $\tfrac{\sqrt2}{2}$ | $\tfrac{\sqrt3}{2}$ | $1$ |
| $\cos\theta$ | $1$ | $\tfrac{\sqrt3}{2}$ | $\tfrac{\sqrt2}{2}$ | $\tfrac12$ | $0$ |

For any other angle, find the **reference angle** (the acute angle to the $x$-axis), take the value from the table, and fix the sign by quadrant: sine is positive in quadrants I and II, cosine in I and IV, tangent in I and III. For example $\sin\frac{5\pi}{6} = +\sin\frac{\pi}{6} = \frac12$.

### Graphs: $y = A\sin(B(x - C)) + D$

- **Amplitude** $|A|$: half the distance from minimum to maximum.
- **Period** $\dfrac{2\pi}{|B|}$.
- **Phase shift** $C$: to the right if $C > 0$.
- **Midline** $y = D$, so the maximum is $D + |A|$ and the minimum is $D - |A|$.

Always factor $B$ out of the argument before reading the shift: $\sin(2x - \pi) = \sin\big(2(x - \tfrac{\pi}{2})\big)$ is shifted $\frac{\pi}{2}$, not $\pi$. Cosine works the same way. Tangent has period $\pi$ and vertical asymptotes at $x = \frac{\pi}{2} + k\pi$.

### Inverse trig functions

Sine, cosine and tangent repeat, so to invert them we restrict the domain:

| Function | Range of the inverse |
|---|---|
| $\arcsin x$ | $[-\frac{\pi}{2}, \frac{\pi}{2}]$ |
| $\arccos x$ | $[0, \pi]$ |
| $\arctan x$ | $(-\frac{\pi}{2}, \frac{\pi}{2})$ |

So $\arcsin(\sin x) = x$ only when $x$ lies in $[-\frac{\pi}{2}, \frac{\pi}{2}]$. For example $\arcsin\big(\sin\frac{5\pi}{6}\big) = \frac{\pi}{6}$, not $\frac{5\pi}{6}$.

### Solving trig equations

To solve $\sin x = c$ on $[0, 2\pi)$: find the reference angle from $|c|$, then use the signs of the quadrants to list **every** angle in the interval. Over all real numbers, add $2\pi k$ for any integer $k$.

@example
title: Solve a sine equation on an interval
problem: Solve $2\sin x - 1 = 0$ for $0 \le x < 2\pi$.
step: Isolate the sine: $\sin x = \tfrac12$.
step: The reference angle is $\frac{\pi}{6}$, because $\sin\frac{\pi}{6} = \frac12$. That is a solution in quadrant I.
step: Sine is also positive in quadrant II, where the angle is $\pi - \frac{\pi}{6} = \frac{5\pi}{6}$.
step: Check: $\sin\frac{5\pi}{6} = \frac12$. The solutions are $x = \frac{\pi}{6}$ and $x = \frac{5\pi}{6}$.

@example
title: Read a transformed sine graph
problem: Describe $y = 3\sin(2x - \pi) + 1$: amplitude, period, phase shift, midline, maximum and minimum.
step: Factor out the coefficient of $x$: $2x - \pi = 2\left(x - \frac{\pi}{2}\right)$, so $y = 3\sin\!\big(2(x - \tfrac{\pi}{2})\big) + 1$.
step: Amplitude $= 3$. Period $= \dfrac{2\pi}{2} = \pi$. Phase shift $= \dfrac{\pi}{2}$ to the right. Midline: $y = 1$.
step: Maximum $= 1 + 3 = 4$ and minimum $= 1 - 3 = -2$.
step: A cycle starts on the midline at $x = \frac{\pi}{2}$, rises to its maximum a quarter period later at $x = \frac{3\pi}{4}$, and ends at $x = \frac{3\pi}{2}$.

@mistakes
- Reading the phase shift as $C$ from $\sin(Bx - C)$ instead of $C/B$.
- Using the reference-angle value without checking the sign for the quadrant.
- Assuming $\arcsin(\sin x) = x$ for every $x$. It holds only on $[-\frac{\pi}{2}, \frac{\pi}{2}]$.
- Giving only one solution of $\sin x = c$ in $[0, 2\pi)$ when there are two.

@practice expr
prompt: Find a function of the form $y = A\cos(Bx) + D$ with $A > 0$ and $B > 0$ whose maximum value is $5$, minimum value is $-1$ and period is $4\pi$.
vars: x
lead: $y =$
answer: 3cos(x/2) + 2
check: lambda x: ((5 - (-1))/2) * cos((2*pi/(4*pi)) * x) + (5 + (-1))/2
hint: The amplitude is half the distance from minimum to maximum, and the midline is halfway between them.
hint: The period is $\frac{2\pi}{B}$. Set it equal to $4\pi$ and solve for $B$.
solution: $A = \frac{5 - (-1)}{2} = 3$ and $D = \frac{5 + (-1)}{2} = 2$. Period $\frac{2\pi}{B} = 4\pi$ gives $B = \frac12$. So $y = 3\cos\!\big(\tfrac{x}{2}\big) + 2$.

@quiz list
prompt: Solve $\tan x = -1$ for $0 \le x < 2\pi$. Enter the solutions separated by commas.
answer: 3pi/4, 7pi/4
check: allroots(lambda x: sin(x) + cos(x), 0, 2*pi)
hint: Tangent has reference angle $\frac{\pi}{4}$ here, because $|\tan\frac{\pi}{4}| = 1$.

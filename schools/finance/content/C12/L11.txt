@article
When a company announces earnings, a merger or a dividend change, did its stock price move because of the news, or would it have moved anyway? An **event study** answers by comparing the actual return around the event with the return the stock would normally have earned given what the market did. It is the standard way to measure how fast and how much prices react to information, and it is a direct test of market efficiency.

### The design

1. **Define the event and the event date** ($t = 0$). If the news arrives after the market closes, the first trading day that reflects it is the event date.
2. **Choose the event window**, the days over which the effect is measured, such as $[-1, +1]$ (the day before to the day after) or $[0, +5]$. It includes days before the event if information may leak or be anticipated.
3. **Choose the estimation window**, a period *before* the event window, for example 120 or 250 trading days ending a few weeks before the event, used to estimate the normal relation between the stock and the market. It must not overlap the event window.
4. **Model normal returns.** The **market model** is $R_{it} = \alpha_i + \beta_i R_{mt} + \varepsilon_{it}$, estimated by OLS over the estimation window (week 1), giving $\hat\alpha_i$, $\hat\beta_i$ and the residual standard deviation $\hat\sigma_i = \sqrt{SSR/(M-2)}$, with $M$ the number of days in the window. Simpler alternatives are the **constant-mean model** (normal return = the average return in the estimation window) and the **market-adjusted model** ($\alpha = 0$, $\beta = 1$).
5. **Compute abnormal returns.** The **abnormal return** is the actual return minus the normal return:

$$AR_{it} = R_{it} - (\hat\alpha_i + \hat\beta_i R_{mt}).$$

The **cumulative abnormal return** over an event window of $L$ days is $CAR_i = \sum_{t=t_1}^{t_2} AR_{it}$.

### Testing one event

Under $H_0$ (the event has no effect), each $AR_{it}$ has mean zero and variance about $\hat\sigma_i^2$. If abnormal returns on different days are independent, $\text{Var}(CAR_i) \approx L\hat\sigma_i^2$, so

$$t = \frac{CAR_i}{\hat\sigma_i\sqrt L},$$

compared with a $t$ distribution with $M - 2$ degrees of freedom (nearly normal for $M$ large). This ignores the sampling error in $\hat\alpha_i, \hat\beta_i$, which is small when $M$ is large. It assumes normal, independent daily abnormal returns, a stable market model, and a window free of other news.

### Testing many events

A single stock's daily return is noisy ($\hat\sigma$ is typically large relative to the effect), so studies pool $N$ events. The **average abnormal return** on day $t$ is $AAR_t = \frac1N\sum_i AR_{it}$, and the **cumulative average abnormal return** is $CAAR = \frac1N\sum_i CAR_i$. A robust test uses the cross-section of the CARs themselves:

$$t = \frac{CAAR}{s_{CAR}/\sqrt N}, \qquad s_{CAR}^2 = \frac{1}{N-1}\sum_i (CAR_i - CAAR)^2,$$

with $N - 1$ degrees of freedom. Because it estimates the variance from the event-window CARs, it stays valid when the event itself raises the variance of returns, a common situation. It assumes the CARs are independent across firms, which fails if the events are *clustered* in calendar time (all firms announce on the same day, so market-wide shocks affect all of them and the CARs are correlated).

### Pitfalls

- **Confounding events**: other news (a dividend, a merger rumor, a competitor's announcement) in the window contaminates the abnormal return.
- **A contaminated estimation window**: if it includes the event, $\hat\alpha$ and $\hat\beta$ absorb part of the reaction and the measured abnormal return shrinks.
- **Event date error and anticipation**: a wrong date misses the reaction, and a window that starts too late misses leakage before the announcement.
- **Long windows** accumulate errors in the model of normal returns and weaken the test; short windows are more reliable for tests of efficiency.
- **Thin trading** and changes in risk after the event distort $\hat\beta$.

### Earnings announcements

Earnings studies compare actual earnings with an expectation (analyst forecasts, or a seasonal random walk); the difference, often standardized, is the **earnings surprise**. The event study then relates the CAR around the announcement to the sign or size of the surprise. Whether good surprises earn positive abnormal returns on the announcement is the empirical question; the study answers with data, not with this page.

@example
title: One firm's announcement
problem: For Larkspur Outfitters, a market model estimated over 100 days gives $\hat\alpha = 0.02\%$ a day, $\hat\beta = 1.2$ and $\hat\sigma = 1.5\%$. Around its earnings announcement, daily returns for days $-1, 0, +1$ were $0.8\%, 4.6\%, 1.1\%$ and the market's returns were $0.3\%, 0.5\%, -0.2\%$. Compute the abnormal returns, the CAR and test it at 5%.
step: Normal returns $\hat\alpha + \hat\beta R_m$: day $-1$: $0.02 + 1.2(0.3) = 0.38$; day 0: $0.02 + 1.2(0.5) = 0.62$; day $+1$: $0.02 + 1.2(-0.2) = -0.22$.
step: Abnormal returns: $0.8 - 0.38 = 0.42$; $4.6 - 0.62 = 3.98$; $1.1 - (-0.22) = 1.32$ (percent).
step: $CAR(-1, +1) = 0.42 + 3.98 + 1.32 = 5.72\%$.
step: The standard error is $\hat\sigma\sqrt L = 1.5\sqrt 3 = 2.598$, so $t = 5.72/2.598 = 2.20$.
step: The 5% two-sided critical value of $t_{98}$ is 1.984. Since $2.20 > 1.984$ we reject zero abnormal return: the announcement window earned a statistically significant positive abnormal return, assuming no confounding news.
answer: $AR = (0.42, 3.98, 1.32)$, $CAR = 5.72\%$, $t = 2.20$: reject $H_0$ at 5%.

@example
title: Pooling 25 events
problem: A study of $N = 25$ announcements finds a cumulative average abnormal return of $CAAR = 2.4\%$ over the window $[-1, +1]$, and the cross-sectional standard deviation of the 25 CARs is $s_{CAR} = 6.0\%$. Test $H_0: CAAR = 0$ at the 5% level.
step: The standard error of the mean CAR is $6.0/\sqrt{25} = 1.2\%$.
step: $t = 2.4/1.2 = 2.00$, with $N - 1 = 24$ degrees of freedom.
step: The 5% two-sided critical value of $t_{24}$ is 2.064, and the 10% value is 1.711. Since $2.00 < 2.064$ we cannot reject at 5%, although we would at 10%: the evidence is suggestive but not conclusive.
step: A larger sample would shrink the standard error if the average effect is real; a different window or model should be tried only as a pre-planned robustness check, not until the result is significant.
answer: $t = 2.00 < 2.064$: do not reject at 5% (reject at 10%).

@mistakes
- Estimating the market model over a window that includes the event, which absorbs part of the effect into $\hat\alpha$ and $\hat\beta$.
- Using $\hat\sigma$ instead of $\hat\sigma\sqrt L$ as the standard error of a CAR over $L$ days.
- Treating firms' CARs as independent when the events fall on the same calendar dates, so that they share market shocks.
- Choosing the event window after seeing which window gives the largest $t$ statistic.

model:
```python
import math


def car_test(stock, market, alpha, beta, sigma):
    """CAR and its t statistic over the event window."""
    abnormal = [s - (alpha + beta * m) for s, m in zip(stock, market)]
    car = sum(abnormal)
    return car, car / (sigma * math.sqrt(len(abnormal)))
```
hint: First build the list of daily abnormal returns using the market model.
hint: Sum them for the CAR, and divide by $\sigma\sqrt{L}$, where $L$ is the length of the window, not by $\sigma$ alone.
solution: Compute each day's abnormal return as stock minus normal return, add them to get the CAR, and scale by $\hat\sigma\sqrt L$, since the variance of the sum of $L$ independent abnormal returns is $L\hat\sigma^2$. In the first test the abnormal returns are $0.5, 3.1, 2.7$ for a CAR of $6.3$.

model:
```python
import math


def market_model(stock, market):
    """OLS market-model estimates (alpha, beta, residual std. deviation)."""
    m = len(stock)
    x_bar = sum(market) / m
    y_bar = sum(stock) / m
    s_xx = sum((x - x_bar) ** 2 for x in market)
    beta = sum((x - x_bar) * (y - y_bar) for x, y in zip(market, stock)) / s_xx
    alpha = y_bar - beta * x_bar
    ssr = sum((y - alpha - beta * x) ** 2 for x, y in zip(market, stock))
    return alpha, beta, math.sqrt(ssr / (m - 2))
```
hint: This is a simple regression of the stock on the market, as in week 1.
hint: After the slope and intercept, compute the residuals and divide their sum of squares by $M - 2$ (two estimated parameters) before taking the square root.
solution: Fit the line with the usual formulas, compute the residuals, and return $\hat\sigma = \sqrt{SSR/(M-2)}$. The three numbers are exactly the inputs that `car_test` needs; the estimation window and the event window must not overlap.

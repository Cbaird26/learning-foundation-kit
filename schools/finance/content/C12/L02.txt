@article
A fund's estimated beta is 0.92. Is that different from 1, or is the gap just noise from a short sample? **Inference** answers this by asking how much an estimate would vary from sample to sample. A coefficient is estimated with a **standard error**, and a test compares the estimate with a hypothesized value in units of standard errors.

### Variance of the estimator

Let $n$ be the sample size and $k$ the number of regressors (excluding the intercept). The error variance is estimated by

$$s^2 = \frac{SSR}{n-k-1}, \qquad \widehat{\text{Var}}(\hat\beta) = s^2 (X'X)^{-1}.$$

The **standard error** $\text{se}(\hat\beta_j)$ is the square root of the $j$-th diagonal element of that matrix. It shrinks when the sample is larger, when the regressor varies more, and when the fit is better.

### The t test

To test $H_0: \beta_j = \beta_{j,0}$ (usually 0), form

$$t = \frac{\hat\beta_j - \beta_{j,0}}{\text{se}(\hat\beta_j)}.$$

Under $H_0$ and the classical assumptions it has a $t$ distribution with $n-k-1$ degrees of freedom. For a two-sided test at the 5% level, reject when $|t|$ exceeds the critical value $t_{0.025,\,n-k-1}$. The **p-value** is the probability, if $H_0$ were true, of a $t$ statistic at least as extreme as the one observed; it is *not* the probability that $H_0$ is true. A $(1-\alpha)$ **confidence interval** is $\hat\beta_j \pm t_{\alpha/2,\,n-k-1}\,\text{se}(\hat\beta_j)$; it contains exactly the hypothesized values the two-sided test does not reject.

A few two-sided 5% critical values: $t_{7} = 2.365$, $t_{9} = 2.262$, $t_{20} = 2.086$, $t_{57} = 2.002$, and $1.960$ in the limit of large samples.

### The F test of joint restrictions

To test $q$ restrictions at once (for example, that two factor loadings are both zero), estimate the **unrestricted** model and the **restricted** model (restrictions imposed) on the same data and compare their residual sums of squares:

$$F = \frac{(SSR_r - SSR_u)/q}{SSR_u/(n-k-1)} \sim F_{q,\,n-k-1}.$$

Here $k$ counts the regressors of the *unrestricted* model. If the restrictions are true, imposing them barely raises the SSR and $F$ is small. Reject when $F$ exceeds the critical value; $F$ tests are always one-sided. When both models have the same dependent variable, $F = \frac{(R^2_u - R^2_r)/q}{(1 - R^2_u)/(n-k-1)}$. The **overall F test** of $H_0: \beta_1 = \dots = \beta_k = 0$ has $q = k$ and $F = \frac{R^2/k}{(1-R^2)/(n-k-1)}$. With a single restriction, $F = t^2$. Some 5% critical values: $F_{2,7} = 4.737$, $F_{3,40} = 2.839$, $F_{2,56} = 3.162$.

### Assumptions

The $t$ and $F$ distributions are exact only under the **classical linear model** assumptions: a correctly specified linear model, exogenous regressors ($E[\varepsilon \mid X] = 0$), errors with constant variance and no correlation across observations, and normally distributed errors. With large samples, the central limit theorem makes the tests approximately valid without normality. If the variance is not constant, use the robust standard errors of week 3; if errors are correlated over time, see weeks 6 and 7.

### Significance is not importance

A coefficient can be statistically significant but economically tiny (huge samples make everything significant) or economically large but imprecisely estimated. Report the estimate, its standard error and a confidence interval, not only stars. Running many tests also inflates false positives, a theme of week 12.

@example
title: Is the fund's beta different from 1?
problem: Over $n = 60$ months, Larkspur Growth Fund's excess return is regressed on the market's excess return, the size factor (SMB) and the value factor (HML). The market coefficient is $\hat\beta = 0.92$ with standard error $0.08$. Test $H_0: \beta = 1$ against $H_1: \beta \ne 1$ at the 5% level and give a 95% confidence interval.
step: There are $k = 3$ regressors, so the degrees of freedom are $60 - 3 - 1 = 56$ and the two-sided 5% critical value is $t_{56} = 2.003$.
step: The statistic is $t = (0.92 - 1)/0.08 = -1.00$.
step: Since $|t| = 1.00 < 2.003$, we fail to reject $H_0$: the data do not show that the beta differs from 1.
step: The interval is $0.92 \pm 2.003(0.08) = 0.92 \pm 0.160$, that is $(0.760, 1.080)$, which contains 1, consistent with the test.
answer: $t = -1.00$, so we fail to reject $\beta = 1$; the 95% confidence interval is $(0.760, 1.080)$.

@example
title: Do the size and value factors matter jointly?
problem: In the same fund regression ($n = 60$), the unrestricted model with market, SMB and HML has $SSR_u = 180$. Dropping SMB and HML (the restricted model with only the market) gives $SSR_r = 198$. Test $H_0: \beta_{SMB} = \beta_{HML} = 0$ at the 5% level.
step: There are $q = 2$ restrictions, and the unrestricted degrees of freedom are $60 - 3 - 1 = 56$.
step: The numerator is $(198 - 180)/2 = 9$ and the denominator is $180/56 = 3.2143$, so $F = 9/3.2143 = 2.80$.
step: The 5% critical value is $F_{2,56} = 3.162$. Since $2.80 < 3.162$, we fail to reject: SMB and HML do not jointly add significant explanatory power at the 5% level.
step: Two individually insignificant factors can still be jointly significant (and the reverse), which is why a joint $F$ test is needed rather than two $t$ tests.
answer: $F = 2.80 < 3.162$, so we fail to reject; the two factors are not jointly significant at 5%.

@mistakes
- Reading the p-value as the probability that the null hypothesis is true, or "fail to reject" as proof that the null is true.
- Using the sample size $n$, rather than $n - k - 1$, as the degrees of freedom of the $t$ and $F$ tests.
- Testing several restrictions with separate $t$ tests instead of one $F$ test, or using a two-sided critical value for an $F$ statistic.
- Treating a statistically significant coefficient as economically important without looking at its size.

model:
```python
import math


def slope_t_stat(x, y, beta0=0.0):
    """t statistic for H0: slope == beta0 in a simple OLS regression."""
    n = len(x)
    x_bar = sum(x) / n
    y_bar = sum(y) / n
    s_xx = sum((xi - x_bar) ** 2 for xi in x)
    slope = sum((xi - x_bar) * (yi - y_bar) for xi, yi in zip(x, y)) / s_xx
    intercept = y_bar - slope * x_bar
    ssr = sum((yi - intercept - slope * xi) ** 2 for xi, yi in zip(x, y))
    s2 = ssr / (n - 2)
    return (slope - beta0) / math.sqrt(s2 / s_xx)
```
hint: First fit the line, then compute the residuals and their sum of squares.
hint: Divide the SSR by $n - 2$ (two estimated parameters) to get $s^2$, and the standard error of the slope is $\sqrt{s^2/S_{xx}}$. Remember to subtract `beta0` in the numerator.
solution: Fit the slope and intercept, compute the SSR, estimate $s^2 = SSR/(n-2)$, then divide $\hat\beta_1 - \beta_0$ by $\sqrt{s^2/S_{xx}}$. The second test tests $H_0: \beta_1 = 1$, which gives a different statistic from the test of zero; forgetting `beta0` is the usual error.

model:
```python
def joint_f_test(ssr_r, ssr_u, q, n, k, crit):
    """F statistic and rejection decision for q linear restrictions."""
    f_stat = ((ssr_r - ssr_u) / q) / (ssr_u / (n - k - 1))
    return f_stat, f_stat > crit
```
hint: The numerator is the increase in SSR per restriction.
hint: The denominator is the unrestricted SSR divided by $n - k - 1$, not by $n$.
solution: $F = \frac{(SSR_r - SSR_u)/q}{SSR_u/(n-k-1)}$. In the first test, $(10/1)/(40/27) = 6.75$, which exceeds 4.21, so the restriction is rejected. Return the comparison `f_stat > crit` as the decision.

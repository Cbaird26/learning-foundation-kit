@article
Not every explanatory variable is a number. A month is January or it is not; a stock is in the technology sector or it is not; a quarter is before or after a regulation changed. A **dummy variable** (indicator variable) takes the value 1 when a condition holds and 0 otherwise, and lets a regression compare groups.

### An intercept shift

Let $D_t = 1$ if month $t$ is January and $0$ otherwise, and regress a return on it:

$$r_t = \alpha + \delta D_t + \varepsilon_t.$$

For non-January months $E[r_t] = \alpha$; for Januaries $E[r_t] = \alpha + \delta$. So $\hat\alpha$ is the average return in the **base (reference) category**, here the non-January months, and $\hat\delta$ is the *difference in average returns* between January and the other months. The $t$ test of $H_0: \delta = 0$ is a test of the **January effect**: whether January's mean return differs from the rest of the year. With only these two groups it equals the pooled two-sample $t$ test, which assumes equal variances in the two groups; with unequal variances use robust standard errors (week 3). The January effect has been documented historically in the returns of small US stocks, but its strength has varied across periods, so treat it as a hypothesis to test on your own data, not as a fact.

Dummies can sit alongside other regressors. In $r_t = \alpha + \delta D_t + \beta m_t + \varepsilon_t$, the January dummy shifts the intercept while the market slope $\beta$ is common to all months.

### The dummy-variable trap

A variable with $g$ categories needs $g - 1$ dummies when the model has an intercept. If you include all $g$ dummies and an intercept, the dummies sum to the column of ones, so the regressors are perfectly collinear and OLS cannot be computed. This is the **dummy-variable trap**. Either drop one category (it becomes the base) or drop the intercept. To describe quarterly seasonality, use three quarterly dummies and the intercept; each coefficient is the difference between that quarter and the omitted one.

When the dependent variable is a log, a dummy coefficient $\delta$ means that the group's mean is $100(e^{\delta} - 1)\%$ different, about $100\delta\%$ for small $\delta$.

### Interactions

A dummy can also change a *slope*. The **interaction** term is the product of the dummy and another regressor:

$$r_t = \alpha + \beta m_t + \delta D_t + \gamma (D_t \cdot m_t) + \varepsilon_t.$$

Now outside January, the line is $\alpha + \beta m_t$. In January it is $(\alpha + \delta) + (\beta + \gamma) m_t$: the intercept shifts by $\delta$ and the slope (the market beta) by $\gamma$. Test $H_0: \gamma = 0$ with a $t$ test for a difference in beta, and $H_0: \delta = \gamma = 0$ with an $F$ test ($q = 2$) for any difference between January and other months, a Chow-type test. Always keep the lower-order terms ($\delta$ and $\beta$) when you include the interaction, or $\gamma$ is hard to interpret.

### In practice

Test a pre-specified calendar effect, not the best of twelve month dummies: picking the largest of many dummies after looking at the data inflates false positives (week 12). Remember how few observations a monthly test has: three years provide only three Januaries, so power is low.

@example
title: A dummy variable as a difference in means
problem: Nine months of returns (in percent) of the Larkspur Small-Cap Index are: the three Januaries returned $4, 6, 5$ and the six other months returned $1, 0, 2, -1, 3, 1$. Regress the return on a January dummy and test whether January differs.
step: The base group (non-January) has mean $\hat\alpha = (1 + 0 + 2 - 1 + 3 + 1)/6 = 1$. The January mean is $5$, so $\hat\delta = 5 - 1 = 4$.
step: The residual sum of squares is the sum of the squared deviations within each group: January $1 + 1 + 0 = 2$, other months $0 + 1 + 1 + 4 + 4 + 0 = 10$, so $SSR = 12$.
step: With $n - 2 = 7$ degrees of freedom, $s^2 = 12/7 = 1.7143$. The standard error of $\hat\delta$ is $s\sqrt{1/3 + 1/6} = \sqrt{1.7143 \times 0.5} = 0.9258$.
step: $t = 4/0.9258 = 4.32$. The 5% two-sided critical value of $t_7$ is 2.365, so we reject equal means. This assumes equal variances in the two groups, independent returns and, because $n$ is tiny, roughly normal returns.
answer: $\hat\alpha = 1$, $\hat\delta = 4$, $t = 4.32 > 2.365$: January's mean return differs from the other months' in this sample.

@example
title: Interpreting an interaction
problem: A regression of a small-cap fund's monthly return on the market return $m$ (in percent), a January dummy $D$ and their product gives $\hat r = 0.4 + 1.1\,m + 2.6\,D + 0.3\,(D \cdot m)$. What return does the model predict for a month with $m = 2$ in January and outside January, and what is the beta in each case?
step: Outside January ($D = 0$) the model is $\hat r = 0.4 + 1.1m$: beta $1.1$, and for $m = 2$ the prediction is $0.4 + 2.2 = 2.6\%$.
step: In January ($D = 1$) the model is $\hat r = (0.4 + 2.6) + (1.1 + 0.3)m = 3.0 + 1.4m$: beta $1.4$, and for $m = 2$ the prediction is $3.0 + 2.8 = 5.8\%$.
step: The January premium at $m = 2$ is $5.8 - 2.6 = 3.2 = \delta + \gamma m = 2.6 + 0.3 \times 2$: it grows with the market return, because $\gamma$ is not zero.
answer: January: $5.8\%$ with beta $1.4$; other months: $2.6\%$ with beta $1.1$.

@mistakes
- Including a dummy for every category together with an intercept (the dummy-variable trap), which makes OLS impossible.
- Reading a dummy coefficient as a coefficient on "the category" rather than as a difference from the omitted base category.
- Including an interaction without the main effects of its two components.
- Testing a calendar effect after scanning all twelve months and choosing the largest, then reporting a single $t$ statistic as if the month had been chosen in advance.

model:
```python
import math


def january_effect(returns, months):
    """Alpha, delta and t statistic of a regression on a January dummy."""
    dummy = [1 if m == 1 else 0 for m in months]
    n = len(returns)
    d_bar = sum(dummy) / n
    r_bar = sum(returns) / n
    s_dd = sum((d - d_bar) ** 2 for d in dummy)
    delta = sum((d - d_bar) * (r - r_bar) for d, r in zip(dummy, returns)) / s_dd
    alpha = r_bar - delta * d_bar
    ssr = sum((r - alpha - delta * d) ** 2 for d, r in zip(dummy, returns))
    s2 = ssr / (n - 2)
    return alpha, delta, delta / math.sqrt(s2 / s_dd)
```
hint: Build the dummy list first: 1 where the month equals 1, otherwise 0. The order of the months does not matter.
hint: Then run the simple regression of the returns on the dummy and compute the $t$ statistic exactly as for any slope: $\hat\delta/\sqrt{s^2/S_{dd}}$.
solution: Create the 0/1 list from `months`, fit the simple regression of the returns on it (the intercept is the non-January mean and the slope is the January mean minus the non-January mean), and divide the slope by its standard error. The third test has a January that is not the first observation and a negative effect, which catches solutions that assume the first return is the January one.

model:
```python
def design_rows(months, market):
    """Rows [1, jan, m, jan*m] for each observation."""
    rows = []
    for month, m in zip(months, market):
        jan = 1 if month == 1 else 0
        rows.append([1, jan, m, jan * m])
    return rows
```
hint: Loop over the months and market returns together with `zip`.
hint: The interaction column is the dummy times the market return, which is $0$ outside January.
solution: For each observation compute the dummy, then append the row `[1, jan, m, jan * m]`. The fourth column equals the market return in January and zero otherwise, which is what lets the slope differ in January.

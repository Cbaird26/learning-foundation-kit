@review
### Week by week

1. **Linear regression.** $y = X\beta + \varepsilon$; OLS minimizes the sum of squared residuals; assumptions: linearity, exogeneity, no perfect collinearity, spherical errors; $R^2 = 1 - SSR/TSS$; the market model's slope is beta.
2. **t and F tests.** $s^2 = SSR/(n-k-1)$; $t = (\hat\beta - \beta_0)/\text{se}$; confidence intervals; $F = \frac{(SSR_r - SSR_u)/q}{SSR_u/(n-k-1)}$; p-values are not probabilities of the null.
3. **Heteroskedasticity.** OLS stays unbiased, standard errors fail; Breusch–Pagan $LM = nR^2_{aux}$; White (HC0, HC1) robust standard errors; WLS when the form is known.
4. **Multicollinearity and specification.** $\text{VIF} = 1/(1-R_j^2)$; omitted-variable bias $\tilde\beta_1 = \hat\beta_1 + \hat\beta_2\tilde\delta_1$; adjusted $R^2$, AIC, BIC, RESET.
5. **Dummies and interactions.** The dummy coefficient is a difference from the base group; $g - 1$ dummies with an intercept; interactions let slopes differ; January-effect test.
6. **Trends and seasonality.** Linear and log-linear trends ($e^{g} - 1$); seasonal dummies; Durbin–Watson $\approx 2(1-\hat\rho)$; Newey–West standard errors.
7. **AR and MA.** AR(1): $\mu = c/(1-\phi)$, $\rho_k = \phi^k$, forecast $\mu + \phi^h(y_T - \mu)$; MA(1): $\rho_1 = \theta/(1+\theta^2)$; ACF/PACF identification; Ljung–Box.
8. **Unit roots.** Random walks; Dickey–Fuller on $\Delta y_t = \alpha + \gamma y_{t-1} + \varepsilon_t$ with DF critical values (constant: $-2.86$ at 5%); spurious regression; cointegration.
9. **ARCH and GARCH.** $\sigma_t^2 = \omega + \alpha\varepsilon_{t-1}^2 + \beta\sigma_{t-1}^2$; $V = \omega/(1-\alpha-\beta)$; variance forecasts mean-revert at rate $\alpha + \beta$; ARCH LM $= TR^2$.
10. **Panel data.** Fixed effects by demeaning, degrees of freedom $NT - N - k$; random effects; Hausman test; cluster-robust standard errors.
11. **Event studies.** $AR_t = R_t - (\hat\alpha + \hat\beta R_{mt})$; $CAR = \sum AR_t$; $t = CAR/(\hat\sigma\sqrt L)$ for one event; cross-sectional $t$ for many; clean estimation window.
12. **Machine learning pitfalls.** Overfitting; chronological splits; $R^2_{OOS}$; ridge; $1 - (1-\alpha)^m$ and Bonferroni.

### Common errors

Using $n$ instead of $n - k - 1$ degrees of freedom; reading $p$ as the probability that the null is true; using normal critical values for Dickey–Fuller; confusing $\sqrt{252}$ with 252; forgetting the dummy-variable trap; including the event in the estimation window; splitting time series at random; reporting the best of many specifications without counting them.

model:
```python
def ar1_forecast_path(y, h):
    """Fit an AR(1) by OLS and return h iterated forecasts."""
    x = y[:-1]
    z = y[1:]
    n = len(x)
    x_bar = sum(x) / n
    z_bar = sum(z) / n
    s_xx = sum((a - x_bar) ** 2 for a in x)
    phi = sum((a - x_bar) * (b - z_bar) for a, b in zip(x, z)) / s_xx
    c = z_bar - phi * x_bar
    path = []
    current = y[-1]
    for _ in range(h):
        current = c + phi * current
        path.append(current)
    return path
```
hint: Estimation and forecasting are separate steps: first get `c` and `phi` from the regression of the current value on the lagged one.
hint: Then start from `y[-1]` and apply `c + phi * current` once per forecast step, appending each result.
solution: Regress `y[1:]` on `y[:-1]` to get $\hat\phi = S_{xz}/S_{xx}$ and $\hat c = \bar z - \hat\phi\bar x$, then iterate the one-step rule $h$ times starting from the last observation. In the first test $\hat\phi$ is small (about 0.16), so the forecasts converge almost at once to the estimated mean, about 3.39.

Write a memo of 6 to 8 sentences saying whether the fund has a significant alpha, which of the reported standard errors you would trust, what the diagnostics show, and what you would do next.

solution: The alpha is $0.12/0.15 = 0.80$ standard errors from zero, far below any critical value, so there is no evidence of a nonzero alpha, but that conclusion rests on standard errors that are not reliable. The Durbin–Watson statistic of 0.95 is well below 2 (and below the 5% lower bound for a sample of this size), indicating positive autocorrelation, and the Breusch–Pagan statistic of 21.4 exceeds 9.488, indicating heteroskedasticity, so the usual standard errors and $t$ statistics are invalid; I would report Newey–West (HAC) standard errors, which are robust to both. The value and quality factors have a variance inflation factor of $1/(1 - 0.96^2) = 12.8$: their individual coefficients (se 0.20 and 0.21) are imprecise, though a joint $F$ test of the two remains valid, and I would consider combining them or dropping one only on economic grounds. The RESET statistic of 1.1 is below 3.08, so there is no evidence of functional-form misspecification. The market and size loadings are large relative to their standard errors, but their $t$ statistics should be recomputed with the robust errors before concluding. Next steps: re-estimate with HAC standard errors, test the value and quality coefficients jointly, and check stability on subperiods.

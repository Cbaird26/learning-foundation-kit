@article
Last week's models assumed a stationary series: one that keeps returning to a stable mean. Many financial series do not. Stock prices, exchange rates and interest-rate levels wander, and a regression on a wandering series can produce impressive nonsense. This week gives you the tests and the cures.

### Random walks and unit roots

In the AR(1) model $y_t = c + \phi\, y_{t-1} + \varepsilon_t$ the key parameter is $\phi$. When $\phi = 1$,

$$y_t = c + y_{t-1} + \varepsilon_t,$$

a **random walk** (with drift $c$). It has a **unit root**. Then $y_t = y_0 + ct + \sum_{s=1}^{t}\varepsilon_s$: every shock is permanent, the variance $t\sigma^2$ grows without bound, and the best forecast of any future value is today's value plus drift. For $|\phi| < 1$ shocks die out at rate $\phi^h$ (the **half-life** of a shock is $\ln 0.5/\ln\phi$ periods). A series that must be differenced $d$ times to become stationary is **integrated of order $d$**, written $I(d)$; a random walk is $I(1)$ and its first difference $\Delta y_t = y_t - y_{t-1}$ is stationary. Log prices are usually treated as $I(1)$, which is why analysts model *returns* (differences of logs), not prices.

A **trend-stationary** series, $y_t = a + bt + \text{stationary noise}$, also trends but returns to its trend line; detrending (week 6) is the right treatment there, differencing the right one for a unit root. Using the wrong one distorts the series.

### The Dickey–Fuller test

Subtract $y_{t-1}$ from both sides of the AR(1): $\Delta y_t = \alpha + \gamma\, y_{t-1} + \varepsilon_t$ with $\gamma = \phi - 1$. Estimate it by OLS and test

$$H_0: \gamma = 0 \text{ (unit root)} \qquad \text{against} \qquad H_1: \gamma < 0 \text{ (stationary)}.$$

The statistic is the usual $t$ ratio $\hat\gamma/\text{se}(\hat\gamma)$, which equals $(\hat\phi - 1)/\text{se}(\hat\phi)$. But **under $H_0$ it does not follow the $t$ or normal distribution**: it has the **Dickey–Fuller distribution**, which is shifted to the left. The test is one-sided: reject for statistics *below* (more negative than) the critical value. Large-sample 5% critical values:

| Regression includes | 1% | 5% | 10% |
|---|---|---|---|
| no constant | -2.57 | -1.94 | -1.62 |
| constant | -3.43 | -2.86 | -2.57 |
| constant and linear trend | -3.96 | -3.41 | -3.13 |

(Compare the usual one-sided normal 5% value of $-1.645$.) Use the "constant" row for a series that wanders around a nonzero level, as with spreads, and the "constant and trend" row for a series with a visible trend. The **augmented Dickey–Fuller (ADF)** test adds lagged differences $\Delta y_{t-1}, \dots, \Delta y_{t-p}$ to the regression so the errors are white noise, with $p$ chosen by AIC or BIC; the critical values are the same.

Assumptions and limits: the errors must be serially uncorrelated (hence the augmentation), the deterministic terms must be specified correctly, and the test has **low power** against a stationary series with $\phi$ close to 1 in a short sample: failing to reject does not prove a unit root. A structural break in the series also biases the test toward not rejecting. The **KPSS** test reverses the null (stationarity), and using both is common.

### Spurious regression and cointegration

Regress one random walk on another, independent one, and in a typical sample you find a high $R^2$, a large $t$ statistic and a very low Durbin–Watson statistic. Nothing is related; the trending behavior fooled the inference. A warning sign is $R^2 > DW$. The standard cures: difference the series (and regress returns on returns), or check for cointegration.

Two $I(1)$ series are **cointegrated** if some linear combination $y_t - \beta x_t$ is stationary: they wander, but together, like a stock and a closely related security that cannot drift apart without limit. The **Engle–Granger** test regresses $y$ on $x$ and applies an ADF test to the residuals, with more negative critical values than the ordinary Dickey–Fuller table (about $-3.34$ at 5% for two variables and a constant, the large-sample value from MacKinnon's tables). If cointegrated, the levels regression is meaningful and an error-correction model can be used; if not, difference.

### Fitting and forecasting an AR(1)

For a stationary series, estimate the AR(1) by regressing $y_t$ on $y_{t-1}$ for $t = 2, \dots, T$ (so $T - 1$ observations), obtaining $\hat c$ and $\hat\phi$. The estimated mean is $\hat\mu = \hat c/(1 - \hat\phi)$ and the one-step forecast is $\hat y_{T+1} = \hat c + \hat\phi\,y_T$. In small samples $\hat\phi$ is biased downward, and the forecast's uncertainty also includes parameter error.

@example
title: A Dickey–Fuller test by hand
problem: A log-price-like series over ten days is $100.0, 100.8, 100.3, 101.5, 102.2, 101.6, 102.9, 103.4, 103.0, 104.1$. Run the Dickey–Fuller regression with a constant and test for a unit root at 5%.
step: Form $\Delta y_t$ for $t = 2, \dots, 10$: $0.8, -0.5, 1.2, 0.7, -0.6, 1.3, 0.5, -0.4, 1.1$ (nine observations), and regress them on $y_{t-1}$, the first nine levels. The regressor has mean $101.744$ and $S_{xx} = 11.962$.
step: OLS gives $\hat\gamma = -0.1665$ (the cross-product sum is $S_{xy} = -1.992$) and an intercept of $17.40$. The residual sum of squares is $4.290$ with $9 - 2 = 7$ degrees of freedom, so $s^2 = 0.6129$.
step: $\text{se}(\hat\gamma) = \sqrt{s^2/S_{xx}} = \sqrt{0.6129/11.962} = 0.2264$, so the Dickey–Fuller statistic is $-0.1665/0.2264 = -0.74$.
step: The 5% critical value (constant) is $-2.86$. Since $-0.74 > -2.86$, we cannot reject the unit root: the data are consistent with a random walk. With nine observations the test has very little power, so a longer sample would be needed for a firm conclusion.
answer: $DF = -0.74 > -2.86$: do not reject a unit root.

@example
title: Reading an AR(1) estimate as a unit-root test
problem: An AR(1) regression of a bond-yield series with an intercept gives $\hat\phi = 0.97$ with standard error $0.02$. Is the series stationary according to a Dickey–Fuller test at the 5% level? What is the half-life implied by the point estimate?
step: The test statistic is $(\hat\phi - 1)/\text{se} = (0.97 - 1)/0.02 = -1.50$.
step: Against the Dickey–Fuller critical value $-2.86$ (constant), $-1.50$ is not far enough to the left, so we do not reject the unit root. Note that the ordinary $t$ test of $\phi = 1$ would *also* not reject here, but its critical values are wrong, and in other samples the two would disagree.
step: The half-life implied by $\hat\phi = 0.97$ is $\ln 0.5/\ln 0.97 = 22.8$ periods: even if the series is stationary, it reverts very slowly, which is why unit-root tests have trouble telling the two apart.
answer: $DF = -1.50 > -2.86$: do not reject; half-life about 22.8 periods.

@mistakes
- Using ordinary $t$ or normal critical values for the Dickey–Fuller statistic; they reject the unit root far too often.
- Treating "fail to reject a unit root" as proof that the series is a random walk, ignoring the test's low power.
- Regressing one trending series on another in levels and trusting the $R^2$ and $t$ statistics (spurious regression).
- Differencing a series that is stationary or trend-stationary, which introduces unnecessary moving-average errors.

model:
```python
def fit_ar1(y):
    """OLS estimates (c, phi) of y_t = c + phi * y_{t-1} + e_t."""
    x = y[:-1]
    z = y[1:]
    n = len(x)
    x_bar = sum(x) / n
    z_bar = sum(z) / n
    s_xx = sum((a - x_bar) ** 2 for a in x)
    phi = sum((a - x_bar) * (b - z_bar) for a, b in zip(x, z)) / s_xx
    return z_bar - phi * x_bar, phi
```
hint: Set `x = y[:-1]` (the lagged values) and `z = y[1:]` (the current values) and run a simple regression of `z` on `x`.
hint: The slope is the AR coefficient $\phi$; the intercept is $\bar z - \phi\bar x$, using the two different means.
solution: The regression has $n - 1$ pairs. Its slope is $S_{xz}/S_{xx}$ and its intercept is $\bar z - \hat\phi\bar x$; the means of the lagged and the current values differ slightly, which is why you must not use a single mean for both. The alternating series gives exactly $\phi = -1$ and $c = 3$.

model:
```python
import math


def df_statistic(y):
    """Dickey-Fuller t statistic with a constant."""
    x = y[:-1]
    dy = [y[i] - y[i - 1] for i in range(1, len(y))]
    n = len(x)
    x_bar = sum(x) / n
    d_bar = sum(dy) / n
    s_xx = sum((a - x_bar) ** 2 for a in x)
    gamma = sum((a - x_bar) * (d - d_bar) for a, d in zip(x, dy)) / s_xx
    alpha = d_bar - gamma * x_bar
    ssr = sum((d - alpha - gamma * a) ** 2 for a, d in zip(x, dy))
    s2 = ssr / (n - 2)
    return gamma / math.sqrt(s2 / s_xx)
```
hint: Build the differences and the lagged levels first; they have the same length.
hint: Then it is an ordinary simple regression: slope $\hat\gamma$, residuals, $s^2 = SSR/(N-2)$, and the $t$ ratio. Compare the result with the Dickey–Fuller critical values, not with $t$ values.
solution: Regress the change on the lagged level, compute the slope and its standard error exactly as in any simple regression, and return the ratio. The rule for using it is the one-sided comparison with $-2.86$ (5%, constant): the second series, at $-5.07$, rejects the unit root while the first and third do not.

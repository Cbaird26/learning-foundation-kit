@article
Financial data arrives as tables: prices by date, holdings by ticker, a loan schedule by month. A table is a list of **rows**, and each row is a **record** with named fields. In plain Python the natural shape is a *list of dictionaries*:

```python
holdings = [
    {"ticker": "AAA", "sector": "Tech", "value": 100.0},
    {"ticker": "BBB", "sector": "Energy", "value": 50.5},
    {"ticker": "CCC", "sector": "Tech", "value": 25.0},
]
```

### Reading a CSV file
A CSV (comma-separated values) file is text. The `csv` module splits it into fields, and `csv.DictReader` uses the header line as the dictionary keys. **Every field arrives as a string**, so you must convert it: `float(row["close"])`. Dates stay text until you convert them with `datetime.date.fromisoformat("2026-01-02")`.

```python
import csv, io

text = "date,close\n2026-01-02,101.5\n2026-01-05,102.0\n"
rows = list(csv.DictReader(io.StringIO(text)))
closes = [float(r["close"]) for r in rows]
```

`io.StringIO` makes a string behave like a file; with a real file you would write `open("prices.csv", newline="")`. Because the site's Python runs in your browser, items give the file contents as text.

### Sorting and filtering
`sorted(rows, key=lambda r: r["value"], reverse=True)` returns a new list ordered by a field; the `key` function says what to sort on. A list comprehension filters: `[r for r in rows if r["sector"] == "Tech"]`.

### Grouping and summarizing
A dictionary accumulates totals by category: the accumulator loop of earlier courses, with a key.

```python
totals = {}
for r in holdings:
    totals[r["sector"]] = totals.get(r["sector"], 0.0) + r["value"]
# {'Tech': 125.0, 'Energy': 50.5}
```

`dict.get(key, default)` returns the default when the key is new. A **weighted average** divides $\sum w_i x_i$ by $\sum w_i$, for example a portfolio's average coupon weighted by face value.

### The same work in pandas
Pandas is a third-party library, so it does not run in the browser, but on your own computer it does these steps in one line each.

```python
# on your own computer: pandas
import pandas as pd

df = pd.read_csv("prices.csv", parse_dates=["date"])
df = df.sort_values("date")
df["ret"] = df["close"].pct_change()
by_year = df.groupby(df["date"].dt.year)["ret"].mean()
```

A pandas `DataFrame` is a table whose columns are typed, so conversion happens when the file is read. Learn the plain-Python version first: it shows what pandas is doing, and it is what a short script on any machine can run.

### A dated schedule
A loan schedule from last week is a list of tuples; attaching a payment date to each row turns it into a table a client can read. Compute payment $k$'s date from the first payment date, as in week 3, so month-ends stay correct.

| period | date | payment | interest | principal | balance |
|---|---|---|---|---|---|
| 1 | 2026-01-31 | 100.00 | 10.00 | 90.00 | 910.00 |
| 2 | 2026-02-28 | 100.00 | 9.10 | 90.90 | 819.10 |
| 3 | 2026-03-31 | 100.00 | 8.19 | 91.81 | 727.29 |

```python
holdings = [("AAA", "Tech", 100.0), ("BBB", "Energy", 50.5),
            ("CCC", "Tech", 25.0), ("DDD", "Energy", 10.0)]
totals = {}
for ticker, sector, value in holdings:
```

step: `CCC` adds to Tech: `100.0 + 25.0 = 125.0`.
step: `DDD` adds to Energy: `50.5 + 10.0 = 60.5`.
step: The `print` runs once after the loop.
answer: `125.0 60.5`

@example
title: Parsing a price file
problem: Write `closing_prices(text)` that returns the list of closing prices (floats) from CSV text with columns `date,close`.
step: Wrap the text so that `csv` can read it: `io.StringIO(text)`.
step: `csv.DictReader` yields one dictionary per data row, with string values.
step: Convert each `close` with `float`:

```python
import csv, io

def closing_prices(text):
    reader = csv.DictReader(io.StringIO(text))
    return [float(row["close"]) for row in reader]
```
step: Check: for `"date,close\n2026-01-02,101.5\n"` the result is `[101.5]`, and for a header only it is `[]`.
answer: The function above returns the closes as floats.

@mistakes
- Forgetting that `csv` gives strings, then adding `row["close"]` to a number (a `TypeError`) or comparing `"9"` with `"10"` as text (so `"9"` sorts after `"10"`).
- Sorting dates stored as `"01/02/2026"` text: only ISO dates (`2026-01-02`) sort correctly as text.
- Dividing a weighted sum by the number of rows instead of by the sum of the weights.
- Modifying a list while looping over it; build a new list with a comprehension instead.

model:
```python
import calendar
from datetime import date

def add_months(d, n):
    year, month0 = divmod(d.year * 12 + d.month - 1 + n, 12)
    last = calendar.monthrange(year, month0 + 1)[1]
    return date(year, month0 + 1, min(d.day, last))

def dated_schedule(first_payment, rows):
    """Attach payment dates to schedule rows."""
    table = []
    for period, payment, interest, repaid, balance in rows:
        table.append({
            "date": add_months(first_payment, period - 1),
            "period": period,
            "payment": payment,
            "interest": interest,
            "principal": repaid,
            "balance": balance,
        })
    return table
```
hint: Unpack each row tuple into five names in the `for` statement.
hint: The date for period `k` is `add_months(first_payment, k - 1)`; always count from `first_payment`.
solution: For each tuple, build a dictionary that adds the date computed from the first payment date and the period number. Counting from the first date keeps October 31 correct after the clamped September 30, which stepping from the previous date would turn into October 30.

tests:

```python
import math
bonds = [{"coupon": 5.0, "face": 400}, {"coupon": 4.0, "face": 250},
         {"coupon": 6.0, "face": 350}]
assert math.isclose(weighted_average(bonds, "coupon", "face"), 5.1, rel_tol=1e-9)
```

model:
```python
def weighted_average(rows, value_key, weight_key):
    """Average of value_key weighted by weight_key."""
    total_weight = sum(row[weight_key] for row in rows)
    if total_weight == 0:
        raise ValueError("weights sum to zero")
    weighted_sum = sum(row[value_key] * row[weight_key] for row in rows)
    return weighted_sum / total_weight
```
hint: You need two sums: the weighted sum and the sum of the weights.
hint: Check that the sum of the weights is not zero before dividing.
solution: Divide the sum of `value * weight` by the sum of the weights, not by the number of rows. Raise `ValueError` when the total weight is zero, which covers an empty list.

@quiz num
prompt: A bond portfolio holds three bonds: face value \$300 thousand with a 3.5% coupon, face value \$500 thousand with a 4.5% coupon, and face value \$200 thousand with a 5.5% coupon. Find the portfolio's average coupon rate weighted by face value, as a percent to two decimal places.
answer: 4.40
tol: 0.01
unit: %
check: (300 * 3.5 + 500 * 4.5 + 200 * 5.5) / (300 + 500 + 200)
hint: Weight each coupon by its face value and divide by total face value, \$1,000 thousand.
solution: $(300 \times 3.5 + 500 \times 4.5 + 200 \times 5.5)/1000 = (1050 + 2250 + 1100)/1000 = 4.40\%$.

### Key formulas
- $PV = \sum CF_t/(1+r)^t$; annuity $PMT\,[1-(1+r)^{-n}]/r$; payment $PV\,r/[1-(1+r)^{-n}]$.
- Balance after $k$ payments: $P(1+r)^k - PMT\,[(1+r)^k-1]/r$.
- $R_t = P_t/P_{t-1} - 1$; $r_t = \ln(P_t/P_{t-1})$; $\sigma_{\text{annual}} = \sigma_{\text{period}}\sqrt{m}$.
- $FCFF = EBIT(1-t) + D\&A - \text{Capex} - \Delta NWC$; $TV = FCFF_N(1+g)/(WACC - g)$.
- $\Delta\text{Cash} = NI + D - \Delta AR - \text{Capex} - \text{Repayment} - \text{Dividends}$.

### Common errors
- Percent instead of decimal rate; annual rate as monthly rate.
- `==` on floats; `Decimal` built from a float.
- Spreadsheet NPV convention mixed with the time-0 convention.
- Terminal growth at or above WACC; adding debt to get equity value.
- Mixed units (thousands and millions); hard-coded assumptions inside formulas.
- Averaging simple returns as if they were growth rates.

model:
```python
def npv(rate, flows):
    return sum(cf / (1 + rate) ** t for t, cf in enumerate(flows))

def irr(flows):
    lo, hi = -0.99, 10.0
    f_lo = npv(lo, flows)
    if f_lo * npv(hi, flows) > 0:
        raise ValueError("no sign change")
    for _ in range(200):
        mid = (lo + hi) / 2
        f_mid = npv(mid, flows)
        if f_lo * f_mid <= 0:
            hi = mid
        else:
            lo, f_lo = mid, f_mid
    return (lo + hi) / 2

def evaluate_project(flows, rate):
    """NPV, IRR, payback year and profitability index of a project."""
    if flows[0] >= 0:
        raise ValueError("first cash flow must be a negative outlay")
    payback = None
    cumulative = 0.0
    for year, flow in enumerate(flows):
        cumulative += flow
        if cumulative >= 0:
            payback = year
            break
    value = npv(rate, flows)
    return {"npv": value, "irr": irr(flows), "payback": payback,
            "pi": 1 + value / -flows[0]}
```
hint: Validate `flows[0]` first, then compute each of the four results.
hint: Payback is a running-total loop that stops at the first year with a cumulative flow of zero or more; the profitability index is `1 + npv / -flows[0]`.
solution: Raise `ValueError` for a non-negative first flow, find the payback year with an accumulator loop, then call the supplied `npv` and `irr`. The first project never returns its outlay in discounted terms (NPV below zero, IRR 8.9% below the 10% rate), but it pays back in cumulative cash terms in year 3; the second never pays back and has a negative IRR.

@article
Prices are levels; **returns** are what investors earn, so almost every analysis starts by turning a price list into a return list. Return to the formulas of earlier courses, now as functions.

### Simple and log returns
With prices $P_0, P_1, \dots$ (adjusted for splits and dividends, or with dividends added explicitly), the **simple return** over period $t$ is

$$R_t = \frac{P_t}{P_{t-1}} - 1,$$

and the **log (continuously compounded) return** is

$$r_t = \ln\frac{P_t}{P_{t-1}} = \ln(1 + R_t).$$

A list of $N+1$ prices gives $N$ returns. In code, `zip(prices, prices[1:])` pairs each price with the next one:

```python
def simple_returns(prices):
    return [b / a - 1 for a, b in zip(prices, prices[1:])]
```

### Which return to use
Simple returns **aggregate across assets**: a portfolio's return is the weighted average of its assets' simple returns. Log returns **add across time**: $\ln(P_T/P_0) = r_1 + r_2 + \dots + r_T$, while simple returns must be compounded, $(1+R_1)(1+R_2)\cdots(1+R_T) - 1$. The two are close when returns are small and differ for large moves: a rise from 100 to 110 is $R = 10\%$ but $r = 9.53\%$.

### Averages and annualizing
The arithmetic mean of periodic returns is not the growth rate you earned: use the **geometric** return, $\left[\prod (1+R_t)\right]^{1/N} - 1$ per period. Four quarterly returns of 3%, -2%, 5% and 1% compound to $1.03 \times 0.98 \times 1.05 \times 1.01 - 1 = 7.05\%$ for the year.

**Volatility** is the sample standard deviation of returns, `statistics.stdev` (divisor $N-1$). To annualize a periodic volatility, multiply by $\sqrt{m}$, where $m$ is the number of periods per year (12 for months, 52 for weeks, about 252 trading days):

$$\sigma_{\text{annual}} = \sigma_{\text{period}}\sqrt{m}.$$

This **square-root-of-time rule** assumes returns are independent from one period to the next with the same variance; with autocorrelation it is only an approximation. Means scale by $m$ (or by compounding), not by $\sqrt{m}$. The **Sharpe ratio** divides the average excess return over the risk-free rate by the volatility, both over the same period length.

### Drawdown
Volatility treats gains and losses alike; a **drawdown** measures the loss from the highest price so far:

$$DD_t = 1 - \frac{P_t}{\max_{s \le t} P_s}.$$

The **maximum drawdown** is the largest $DD_t$. Compute it with a running peak: for each price, update the peak if the price is a new high, then measure the fall from the peak.

```python
peak = prices[0]
worst = 0.0
for p in prices:
    peak = max(peak, p)
    worst = max(worst, 1 - p / peak)
```

For prices 100, 120, 90, 110, 80 the peak is 120 from the second price on, and the deepest fall is to 80: $1 - 80/120 = 33.3\%$.

@example
title: Simple versus log returns
problem: A stock closes at \$50.00, \$52.00 and \$49.40 on three days. Find the two simple returns, the two-day return, and the two log returns.
step: Day 1: $52/50 - 1 = 4.00\%$. Day 2: $49.40/52 - 1 = -5.00\%$.
step: Compounding, the two-day simple return is $1.04 \times 0.95 - 1 = -1.20\%$, which matches $49.40/50 - 1$. Adding $4\%$ and $-5\%$ would give $-1\%$, which is wrong.
step: Log returns: $\ln 1.04 = 0.03922$ and $\ln 0.95 = -0.05129$.
step: These add: $0.03922 - 0.05129 = -0.01207 = \ln(49.40/50)$, the two-day log return.
answer: Simple returns 4.00% and -5.00% (two-day -1.20%); log returns 0.03922 and -0.05129 (two-day -0.01207).

@example
title: Annualizing daily volatility
problem: Six daily returns are 1.0%, -2.0%, 1.5%, 0.0%, 0.5% and -1.0%. Find the daily sample standard deviation and the annualized volatility using 252 trading days.
step: The mean is $(0.010 - 0.020 + 0.015 + 0 + 0.005 - 0.010)/6 \approx 0$.
step: The squared deviations sum to $0.000850$, and dividing by $N - 1 = 5$ gives a variance of $0.000170$.
step: The daily standard deviation is $\sqrt{0.000170} = 1.304\%$.
step: Annualize: $1.304\% \times \sqrt{252} = 1.304\% \times 15.875 = 20.70\%$.
answer: About 1.30% per day, or 20.70% per year.

@mistakes
- Averaging simple returns over time and calling it the growth rate; use the geometric return, since a $+50\%$ year followed by a $-50\%$ year loses 25%.
- Using the population standard deviation (`pstdev`) on a sample of returns, or annualizing by multiplying by $m$ instead of $\sqrt{m}$.
- Annualizing monthly volatility by $\sqrt{252}$ or daily volatility by $\sqrt{12}$: the multiplier must match the period length.
- Computing a drawdown from the first price instead of from the running peak.

prompt: Why do analysts often model returns with log returns when they work through time?
choice: Log returns are always larger than simple returns, so they are more conservative.
choice*: The log returns of consecutive periods add up to the log return over the whole interval.
choice: Log returns of different stocks add up to the return of a portfolio.
choice: Log returns remove the need to adjust prices for dividends and splits.
hint: Think of what $\ln(ab) = \ln a + \ln b$ does to a product of growth factors.
solution: Growth factors multiply across periods, and the logarithm turns a product into a sum, so $\ln(P_T/P_0)$ is the sum of the period log returns. def annualized_volatility(returns, periods_per_year):
    """Sample standard deviation scaled by the square root of time."""
    if len(returns) < 2:

    return statistics.stdev(returns) * math.sqrt(periods_per_year)

model:
```python
def max_drawdown(prices):
    """Largest fall from a running peak, as a positive decimal."""
    if not prices:
        return 0.0
    peak = prices[0]
    worst = 0.0
    for price in prices:
        peak = max(peak, price)
        worst = max(worst, 1 - price / peak)
    return worst
```
hint: Keep two accumulators: the highest price so far, and the worst drawdown so far.
hint: For each price, update the peak first, then compare `1 - price / peak` with the worst so far. In `[100, 80, 120, 90]` the fall from 100 to 80 is 20% but the fall from 120 to 90 is larger.
solution: Track the running peak; at each price the drawdown is `1 - price / peak`, and the answer is the largest of these. Updating the peak before measuring makes a new high a drawdown of zero. Measuring from the first price instead of the peak would miss the 120 to 90 fall.

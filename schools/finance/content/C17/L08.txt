@article
A **three-statement model** links the income statement (IS), the balance sheet (BS) and the cash flow statement (CFS). Net income flows from the IS to the CFS and to equity on the BS; the CFS explains the change in the BS cash line. If the links are right, the BS balances **by construction**, and the balance check is a test of your work, not something to force.

### A small model
Use five balance sheet accounts: cash, receivables, property, plant and equipment (PP&E), debt and equity. All amounts are in millions of dollars.

| Assets | Opening | Liabilities and equity | Opening |
|---|---|---|---|
| Cash | 100 | Debt | 200 |
| Receivables | 80 | Equity | 280 |
| PP&E | 300 | | |
| **Total** | **480** | **Total** | **480** |

### Roll-forwards
Each account's ending balance is its opening balance plus the year's changes:

- Receivables: ending receivables, set by an assumption (for example, a percent of revenue).
- PP&E $=$ opening $+$ capital expenditures (capex) $-$ depreciation.
- Debt $=$ opening $-$ repayments.
- Equity $=$ opening $+$ net income $-$ dividends.
- Cash $=$ opening $+$ the net change in cash from the cash flow statement.

### The cash flow statement
$$\Delta\text{Cash} = \underbrace{NI + D - \Delta AR}_{\text{operations}} \; \underbrace{- \text{Capex}}_{\text{investing}} \; \underbrace{- \text{Repayment} - \text{Dividends}}_{\text{financing}}$$

Depreciation $D$ is added back because it reduced net income without using cash. An *increase* in receivables $\Delta AR$ uses cash (sales not yet collected), so it is subtracted; a decrease adds cash.

### Why it balances
The change in assets is $\Delta\text{Cash} + \Delta AR + (\text{Capex} - D)$. The change in liabilities and equity is $-\text{Repayment} + NI - \text{Dividends}$. Substitute the cash flow formula into the first expression and the two are identical. So if the opening balance sheet balances and every account is rolled forward with the flows above, the ending sheet balances. If it does not, there is an error in a link: a flow counted on one side only, a sign flipped, or a line forgotten.

### Never plug
A **plug** forces the sheet to balance by adjusting a line (usually cash) by the difference. It hides the error and breaks the tie between cash and the cash flow statement. The honest tool is the **balance check**: a function that compares total assets with total liabilities plus equity within a tolerance, because floats leave tiny differences. It should be run on every forecast year and fail loudly.

### A revolver is not a plug
Companies hold a minimum cash balance and borrow on a revolving credit facility (a **revolver**) when cash would fall below it. Modeled correctly, the draw is a *financing flow*: cash rises and debt rises together, so the sheet still balances. The draw is $\max(0, \text{minimum cash} - (\text{opening cash} + \text{net change before the draw}))$. Interest on the revolver depends on the draw, which depends on net income, which depends on interest: a **circularity**. Computing interest on opening balances avoids it.

### In code
```python
def net_change_in_cash(net_income, depreciation, change_in_receivables,
                       capex, debt_repayment, dividends):
    return (net_income + depreciation - change_in_receivables
            - capex - debt_repayment - dividends)
```

Test the roll-forward on one year, then write a function that checks the balance and run it on every year.

@example
title: Rolling one year forward
problem: Starting from the opening balance sheet above, net income is 60, depreciation 30, ending receivables 90, capex 40, debt repayment 20 and dividends 15. Find the ending balance sheet.
step: Change in receivables $= 90 - 80 = 10$. Net change in cash $= 60 + 30 - 10 - 40 - 20 - 15 = 5$, so cash is $105$.
step: PP&E $= 300 + 40 - 30 = 310$. Debt $= 200 - 20 = 180$. Equity $= 280 + 60 - 15 = 325$.
step: Total assets $= 105 + 90 + 310 = 505$. Debt plus equity $= 180 + 325 = 505$.
step: The sheet balances because every flow in the cash flow statement has a matching change on the balance sheet.
answer: Cash 105, receivables 90, PP&E 310, debt 180, equity 325; total 505 on each side.

@example
title: What an error looks like
problem: Suppose the model forgets to subtract the dividend from equity (equity becomes 340). Does the check catch it?
step: Assets are still $505$, but debt plus equity is $180 + 340 = 520$.
step: The difference is $-15$, exactly the forgotten dividend.
step: A check with a tolerance of 0.01 fails, pointing to a flow that appears in the cash flow statement but not in equity.
step: A plug would have added 15 to cash and hidden the mistake.
answer: Yes: assets minus liabilities and equity is -15, the size of the missing dividend.

@mistakes
- Forcing the balance sheet to balance by adjusting cash, which hides the error.
- Subtracting a *decrease* in receivables (or adding an increase), flipping the sign of the working-capital effect.
- Testing balance with `==` on floats instead of a tolerance.
- Forgetting to add depreciation back in the cash flow statement while also reducing PP&E by it.

```python
def net_change_in_cash(net_income, depreciation, change_in_receivables,
                       capex, debt_repayment, dividends):
    """Net change in cash from operating, investing and financing flows."""
    operating = net_income + depreciation - change_in_receivables
    investing = -capex
    financing = -debt_repayment - dividends
    return operating + investing + financing
```
hint: Add up operating cash flow first: net income plus depreciation minus the change in receivables.
hint: Then subtract capex (investing) and the debt repayment and dividends (financing).
solution: Operating cash flow is `net_income + depreciation - change_in_receivables`; investing is `-capex`; financing is `-debt_repayment - dividends`. A fall in receivables is a negative change, so subtracting it adds cash.

```python
def next_balance_sheet(bs, net_income, depreciation, receivables_end,
                       capex, debt_repayment, dividends):
    """Roll the balance sheet forward one year."""
    change_in_receivables = receivables_end - bs["receivables"]
    cash_change = (net_income + depreciation - change_in_receivables
                   - capex - debt_repayment - dividends)
    return {
        "cash": bs["cash"] + cash_change,
        "receivables": receivables_end,
        "ppe": bs["ppe"] + capex - depreciation,
        "debt": bs["debt"] - debt_repayment,
        "equity": bs["equity"] + net_income - dividends,
    }
```
hint: First compute the change in receivables and the net change in cash.
hint: Build the new dictionary account by account; do not assign into `bs`.
solution: Compute the change in receivables and the cash flow statement's net change in cash, then roll each account forward. Because every flow touches both a cash-flow line and a balance sheet account, the new sheet balances if the opening one did. A year with no flows returns the same balances.

def is_balanced(bs, tol=0.01):
    """True if assets equal liabilities plus equity within tol."""
    assets = bs["cash"] + bs["receivables"] + bs["ppe"]
    claims = bs["debt"] + bs["equity"]
    return abs(assets - claims) <= tol

model:
```python
def revolver_draw(cash_begin, net_change, minimum_cash):
    """Borrowing needed to keep ending cash at or above the minimum."""
    shortfall = minimum_cash - (cash_begin + net_change)
    return max(0, shortfall)
```
hint: Ending cash before any draw is `cash_begin + net_change`.
hint: The shortfall is the minimum minus that ending cash; borrow it only if it is positive.
solution: Compute the shortfall against the minimum cash and borrow `max(0, shortfall)`. In the third test ending cash equals the minimum exactly, so no draw is needed.

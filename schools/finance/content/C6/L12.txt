@article
This lesson brings the course together. Calculus (derivatives and optimization) and linear algebra (vectors, matrices, inverses) combine into the central computation of portfolio theory: choose weights to minimize risk.

### The global minimum-variance portfolio

With $n$ assets, covariance matrix $\Sigma$ (assumed invertible and positive definite) and weights $w$ summing to 1, the problem is
$$\min_w\; w^T\Sigma w \quad\text{subject to}\quad \mathbf 1^Tw = 1.$$
Last lesson's Lagrangian gave $w^* = \dfrac{\Sigma^{-1}\mathbf 1}{\mathbf 1^T\Sigma^{-1}\mathbf 1}$ and $\sigma^2_{\min} = \dfrac{1}{\mathbf 1^T\Sigma^{-1}\mathbf 1}$. In practice you do not invert $\Sigma$: solve the linear system $\Sigma x = \mathbf 1$ by elimination and then **rescale** $x$ so it sums to 1.

Two properties are worth remembering. First, $w^*$ uses only $\Sigma$, never the expected returns, which are the noisiest inputs in practice. Second, weights can be negative: a high-variance asset that is highly correlated with another may be sold short to reduce risk. If the assets are uncorrelated, the solution is simple: the weights are proportional to the inverse variances, $w_i \propto 1/\sigma_i^2$.

### A target return

To reach a required expected return $m$ with minimum risk, add a second constraint $\mu^Tw = m$ and a second multiplier $\gamma$:
$$\mathcal L = w^T\Sigma w - \lambda(\mathbf 1^Tw - 1) - \gamma(\mu^Tw - m).$$
The conditions are $2\Sigma w = \lambda\mathbf 1 + \gamma\mu$, together with both constraints. Stacked together they are one linear system in $(w, \lambda, \gamma)$ with $n + 2$ equations:
$$\begin{pmatrix} 2\Sigma & -\mathbf 1 & -\mu \\ \mathbf 1^T & 0 & 0 \\ \mu^T & 0 & 0 \end{pmatrix}\begin{pmatrix} w \\ \lambda \\ \gamma \end{pmatrix} = \begin{pmatrix} 0 \\ 1 \\ m \end{pmatrix}.$$
Solving it for different $m$ traces the **minimum-variance frontier**. For two assets the two constraints already fix the weights completely, and there is nothing to optimize.

### Verify numerically

An analytical answer should always be checked. Evaluate $w^T\Sigma w$ at your solution and at nearby weights that still satisfy the constraints (shift $0.01$ from one asset to another): the variance must rise. Check that the weights sum to 1 and that $\mu^Tw = m$. In code, a function that returns $\Sigma^{-1}\mathbf 1$ scaled to sum to 1 is only a few lines once you have a linear solver.

Treat all inputs as estimates: covariance matrices estimated from limited data are noisy, and the weights are sensitive to them. This is general education about the mathematics, not a recommendation about any portfolio.

@example
title: Minimum-variance weights for uncorrelated assets
problem: Three uncorrelated assets have variances $0.04$, $0.08$ and $0.16$. Find the global minimum-variance weights, the minimum variance and the standard deviation.
step: For a diagonal $\Sigma$, $\Sigma^{-1}\mathbf 1 = \left(\frac{1}{0.04}, \frac{1}{0.08}, \frac{1}{0.16}\right) = (25, 12.5, 6.25)$.
step: The sum is $\mathbf 1^T\Sigma^{-1}\mathbf 1 = 43.75$, so $w^* = \left(\frac{25}{43.75}, \frac{12.5}{43.75}, \frac{6.25}{43.75}\right) = \left(\frac47, \frac27, \frac17\right) = (57.14\%, 28.57\%, 14.29\%)$.
step: The minimum variance is $\frac{1}{43.75} = 0.022857$, so $\sigma_{\min} = 15.12\%$, below the lowest individual standard deviation of $20\%$.
step: Verify directly: $\left(\frac47\right)^2(0.04) + \left(\frac27\right)^2(0.08) + \left(\frac17\right)^2(0.16) = 0.013061 + 0.006531 + 0.003265 = 0.022857$.
answer: $w^* = (4/7, 2/7, 1/7)$, $\sigma^2_{\min} = 0.022857$, $\sigma_{\min} = 15.12\%$.

@example
title: A target-return portfolio
problem: The same three uncorrelated assets (variances $0.04$, $0.08$, $0.16$) have expected returns $\mu = (6\%, 9\%, 14\%)$. Find the minimum-variance portfolio with expected return $m = 10\%$ and compare its risk with the global minimum.
step: With $\Sigma$ diagonal, $2\Sigma w = \lambda\mathbf 1 + \gamma\mu$ gives $w_i = \frac{\lambda + \gamma\mu_i}{2\sigma_i^2}$. Define $p_i = \frac{1}{2\sigma_i^2} = (12.5, 6.25, 3.125)$.
step: The budget constraint becomes $21.875\lambda + 1.75\gamma = 1$ (using $\sum p_i = 21.875$ and $\sum p_i\mu_i = 1.75$). The return constraint becomes $1.75\lambda + 0.156875\gamma = 0.10$ (using $\sum p_i\mu_i^2 = 0.156875$).
step: Solving this $2 \times 2$ system gives $\lambda = -0.0491$ and $\gamma = 1.1852$. Then $w_1 = 12.5(-0.0491 + 0.071111) = 0.2751$, $w_2 = 6.25(-0.0491 + 0.106667) = 0.3598$, $w_3 = 3.125(-0.0491 + 0.165926) = 0.3651$.
step: Check: weights sum to $1.0000$; return is $0.06(0.2751) + 0.09(0.3598) + 0.14(0.3651) = 10.00\%$. The variance is $0.2751^2(0.04) + 0.3598^2(0.08) + 0.3651^2(0.16) = 0.034709$, so $\sigma = 18.63\%$, higher than the global minimum of $15.12\%$: extra return costs extra risk.
answer: $w \approx (27.5\%, 36.0\%, 36.5\%)$ with $\sigma \approx 18.63\%$ versus $15.12\%$ at the global minimum.

@mistakes
- Using the covariance matrix inverse but forgetting to rescale so the weights sum to 1.
- Believing the minimum-variance weights depend on expected returns; only the target-return portfolio does.
- Assuming all weights must be positive; the unconstrained solution can include short sales, and a no-short-selling rule changes the problem.
- Mixing units: variances and expected returns must use the same period (annual or monthly) and decimals throughout.

def solve_linear(A, b):
    n = len(A)
    M = [list(map(float, row)) + [float(rhs)] for row, rhs in zip(A, b)]
    for col in range(n):
        pivot = max(range(col, n), key=lambda r: abs(M[r][col]))

model:
```python
def solve_linear(A, b):
    n = len(A)
    M = [list(map(float, row)) + [float(rhs)] for row, rhs in zip(A, b)]
    for col in range(n):
        pivot = max(range(col, n), key=lambda r: abs(M[r][col]))
        M[col], M[pivot] = M[pivot], M[col]
        for r in range(col + 1, n):
            factor = M[r][col] / M[col][col]
            for c in range(col, n + 1):
                M[r][c] -= factor * M[col][c]
    x = [0.0] * n
    for r in range(n - 1, -1, -1):
        total = sum(M[r][c] * x[c] for c in range(r + 1, n))
        x[r] = (M[r][n] - total) / M[r][r]
    return x


def min_variance_weights(cov):
    """Global minimum-variance weights: solve cov x = 1, then rescale."""
    x = solve_linear(cov, [1.0] * len(cov))
    total = sum(x)
    return [value / total for value in x]
```
hint: The right-hand side of the system is a list of ones, one for each asset.
hint: Call `solve_linear(cov, [1.0] * len(cov))`, then divide each entry by the sum of the entries.
solution: Solving $\Sigma x = \mathbf 1$ gives $\Sigma^{-1}\mathbf 1$ without forming the inverse, and dividing by its sum enforces the budget constraint. The fourth test shows a short position when two assets are strongly correlated.

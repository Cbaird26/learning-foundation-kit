@article
Most financial quantities depend on several inputs at once: an annuity's value depends on the payment, the rate and the number of periods; a portfolio's variance depends on every weight; an option's value depends on the asset price, volatility and time. A **function of several variables** such as $f(x, y)$ assigns one output to each pair of inputs.

### Partial derivatives

The **partial derivative** of $f$ with respect to $x$ is the rate of change as $x$ varies with every other variable held constant:
$$\frac{\partial f}{\partial x} = f_x = \lim_{h\to 0}\frac{f(x+h, y) - f(x, y)}{h}.$$
In practice, differentiate as usual and treat the other variables as constants. For $f(x, y) = x^2y + 3y^2$:
$$f_x = 2xy, \qquad f_y = x^2 + 6y.$$
At $(2, 3)$, $f_x = 12$ and $f_y = 4 + 18 = 22$. The **gradient** collects them into a vector, $\nabla f = (f_x, f_y)$, which points in the direction of steepest increase.

**Second partials** differentiate again: $f_{xx}$, $f_{yy}$ and the mixed partials $f_{xy}$ and $f_{yx}$. For the functions in this course the mixed partials are equal, $f_{xy} = f_{yx}$. Here $f_{xx} = 2y$, $f_{yy} = 6$ and $f_{xy} = 2x$. Second partials are what the optimization lessons use to classify critical points.

### The total differential

If both inputs change a little, the output changes by approximately the sum of the partial effects:
$$\Delta f \approx f_x\,\Delta x + f_y\,\Delta y.$$
This is the linear approximation, accurate for small changes. It underlies duration (bond price sensitivity to yield) and the "Greeks" of options: delta, for example, is the partial derivative of an option's value with respect to the underlying price.

### Production functions

A **Cobb–Douglas** production function $Q = AL^{\alpha}K^{\beta}$ gives output from labor $L$ and capital $K$. The partial derivatives are the **marginal products**:
$$MP_L = \frac{\partial Q}{\partial L} = \alpha\,\frac{Q}{L}, \qquad MP_K = \frac{\partial Q}{\partial K} = \beta\,\frac{Q}{K}.$$
Each is the extra output from one more unit of that input with the other held fixed. The exponents $\alpha$ and $\beta$ are the output elasticities of labor and capital.

### Sensitivity of an annuity

The present value of an ordinary annuity is $PV(C, i, n) = C\,\frac{1 - (1+i)^{-n}}{i}$. Its partial derivatives answer two practical questions. Holding $i$ and $n$ fixed, $\frac{\partial PV}{\partial C}$ is just the annuity factor $\frac{1 - (1+i)^{-n}}{i}$. Holding $C$ and $n$ fixed, the quotient rule gives
$$\frac{\partial PV}{\partial i} = C\,\frac{n(1+i)^{-n-1}\,i - \left(1 - (1+i)^{-n}\right)}{i^2},$$
which is negative: a higher rate lowers the value of the annuity. Multiplying it by a small change $\Delta i$ estimates the price change, exactly as bond duration does. The result is a derivative with respect to the rate per period, so a rate quoted in percent must be converted to a decimal first.

@example
title: Marginal products of a Cobb–Douglas function
problem: Cedar Ridge Mills produces $Q = 10L^{0.6}K^{0.4}$ units per day with $L$ labor hours and $K$ machine hours. Find $Q$, $MP_L$ and $MP_K$ at $L = 100$ and $K = 50$.
step: Output is $Q = 10(100)^{0.6}(50)^{0.4} = 10 \times 15.849 \times 4.7818 = 757.86$ units.
step: $\frac{\partial Q}{\partial L} = 6L^{-0.4}K^{0.4} = 0.6\,\frac{Q}{L}$, so $MP_L = 0.6 \times \frac{757.86}{100} = 4.547$ units per labor hour.
step: $\frac{\partial Q}{\partial K} = 4L^{0.6}K^{-0.6} = 0.4\,\frac{Q}{K}$, so $MP_K = 0.4 \times \frac{757.86}{50} = 6.063$ units per machine hour.
step: Total differential: adding 2 labor hours and removing 1 machine hour changes output by about $4.547(2) + 6.063(-1) = 3.03$ units.
answer: $Q = 757.86$; $MP_L = 4.547$; $MP_K = 6.063$.

@example
title: How sensitive is an annuity to the interest rate?
problem: An annuity pays \$1,000 per year for 10 years. Find its present value at 5% and the partial derivatives $\partial PV/\partial C$ and $\partial PV/\partial i$ there. Estimate the change in value if the rate rises to 6%, and compare with the exact change.
step: $(1.05)^{-10} = 0.613913$, so the annuity factor is $\frac{1 - 0.613913}{0.05} = 7.7217$ and $PV = \$7{,}721.73$. Also $\frac{\partial PV}{\partial C} = 7.7217$: each extra \$1 of payment adds \$7.72.
step: In the numerator of $\frac{\partial PV}{\partial i}$, $n(1+i)^{-n-1}\,i = 10(0.584679)(0.05) = 0.292340$ and $1 - (1.05)^{-10} = 0.386087$. So $\frac{\partial PV}{\partial i} = 1000 \times \frac{0.292340 - 0.386087}{0.0025} = -37{,}499$ dollars per unit of rate.
step: A rise of $\Delta i = 0.01$ changes value by about $-37{,}499 \times 0.01 = -\$375$.
step: Exactly, $PV$ at 6% is $\$7{,}360.09$, a change of $-\$361.65$. The linear estimate slightly overstates the fall, because the value is a convex function of the rate.
answer: $PV = \$7{,}721.73$; $\partial PV/\partial i \approx -37{,}499$; estimated change $-\$375$ versus exact $-\$361.65$.

@mistakes
- Differentiating with respect to $x$ but also treating $y$ as a variable (applying the chain rule to $y$) instead of holding it constant.
- Plugging a percent such as 5 instead of $0.05$ into $\partial PV/\partial i$.
- Assuming the total-differential estimate is exact; it is only a first-order approximation.
- Mixing up $f_{xy}$ and $f_{xx}$: the second subscript pattern tells you which variables you differentiate by, in order.

@practice num
prompt: Bellwether Foods has output $Q = 5L^{0.5}K^{0.5}$. Find the marginal product of capital, $\partial Q/\partial K$, at $L = 64$ and $K = 100$, in units per machine hour.
answer: 2
tol: 0.001
check: (5 * 64**0.5 * (100 + 1e-5)**0.5 - 5 * 64**0.5 * (100 - 1e-5)**0.5) / 2e-5
hint: Differentiate $K^{0.5}$ with the power rule and treat $L$ as a constant.
hint: $MP_K = 2.5\,L^{0.5}K^{-0.5}$.
solution: $MP_K = 2.5\sqrt{64}/\sqrt{100} = 2.5 \times 8 / 10 = 2$ units per machine hour.

@practice num
prompt: An annuity pays \$2,000 per year for 15 years, and the annual rate is 6%. Using the partial derivative $\partial PV/\partial i$ at $i = 0.06$, estimate the change in present value if the rate rises by 0.5 percentage points (to 6.5%). Round to the nearest dollar.
answer: -635
tol: 1
lead: \$
check: (2000 * (1 - (1.06 + 1e-6)**-15) / (0.06 + 1e-6) - 2000 * (1 - (1.06 - 1e-6)**-15) / (0.06 - 1e-6)) / 2e-6 * 0.005
hint: The estimate is $\frac{\partial PV}{\partial i}\,\Delta i$ with $\Delta i = 0.005$.
hint: $\frac{\partial PV}{\partial i} = C\,\frac{n(1+i)^{-n-1}i - (1 - (1+i)^{-n})}{i^2}$ with $C = 2000$, $n = 15$, $i = 0.06$.
solution: At $i = 0.06$: $n(1+i)^{-n-1}i = 15(0.393646)(0.06) = 0.354281$ and $1 - 1.06^{-15} = 0.582735$, so $\frac{\partial PV}{\partial i} = 2000\,\frac{0.354281 - 0.582735}{0.0036} = -126{,}918$. Then $\Delta PV \approx -126{,}918 \times 0.005 = -\$634.59$, about $-\$635$.

@quiz num
prompt: A production function is $Q = 12L^{1/3}K^{2/3}$. Find the marginal product of labor, $\partial Q/\partial L$, at $L = 27$ and $K = 8$. Round to two decimal places.
answer: 1.78
tol: 0.01
check: 12 * (1/3) * 27**(-2/3) * 8**(2/3)
hint: $\frac{\partial Q}{\partial L} = 12 \cdot \frac13 L^{-2/3}K^{2/3}$.
hint: $27^{-2/3} = \frac19$ and $8^{2/3} = 4$.
solution: $MP_L = 4 \times \frac19 \times 4 = \frac{16}{9} = 1.78$.

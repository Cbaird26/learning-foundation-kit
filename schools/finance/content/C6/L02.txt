@article
The **derivative** of $f$ at $x$ measures the instantaneous rate of change: the slope of the tangent line to the graph. It is defined as the limit of the slope of secant lines,
$$f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}.$$
If the limit exists, $f$ is **differentiable** at $x$. The notation $\frac{dy}{dx}$ means the same thing and reminds you that the derivative is a ratio of small changes.

### Rules you will use constantly

| Rule | Statement |
|---|---|
| Constant | $\frac{d}{dx}(c) = 0$ |
| Power | $\frac{d}{dx}x^n = nx^{n-1}$ |
| Sum and constant multiple | $(af + bg)' = af' + bg'$ |
| Product | $(fg)' = f'g + fg'$ |
| Quotient | $\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$ |
| Chain | $\frac{d}{dx} f(g(x)) = f'(g(x))\,g'(x)$ |

For example, $\frac{d}{dx}(3x^4 - 5x^2 + 7) = 12x^3 - 10x$, so the slope at $x = 2$ is $96 - 20 = 76$. For the composite $(2x + 1)^3$, the chain rule gives $3(2x+1)^2 \cdot 2 = 6(2x+1)^2$: differentiate the outside, keep the inside, multiply by the derivative of the inside.

### Marginal analysis

Economists call the extra cost of one more unit the **marginal cost**. If $C(q)$ is total cost for output $q$, then marginal cost is approximately $C(q+1) - C(q)$, and calculus replaces that difference with the derivative:
$$MC(q) = C'(q), \qquad MR(q) = R'(q), \qquad M\pi(q) = \pi'(q) = MR(q) - MC(q),$$
where $R(q) = p(q)\,q$ is total revenue and profit is $\pi(q) = R(q) - C(q)$. The derivative is an approximation to the cost of the next unit; it is exact for a very small change in $q$.

### The profit-maximizing rule

If producing one more unit adds more revenue than cost ($MR > MC$), profit rises; if it adds less ($MR < MC$), profit falls. Profit is therefore at a peak where $\pi'(q) = 0$, that is,
$$MR(q) = MC(q),$$
provided profit is turning from rising to falling there: the second derivative $\pi''(q) < 0$. You will study this second-order check in the optimization weeks.

When a firm faces a downward-sloping demand curve $p = a - bq$, revenue is $R(q) = aq - bq^2$ and $MR(q) = a - 2bq$, which falls twice as fast as price. A firm that is a price taker has $p$ constant and $MR = p$.

Remember the units: $MC$ and $MR$ are in dollars per unit, and a derivative is only a good guide to the cost of the next unit when $q$ is large relative to one unit.

@example
title: Profit maximization for a firm with downward-sloping demand
problem: Larkspur Outfitters has total cost $C(q) = 5000 + 10q + 0.01q^2$ dollars and faces the demand curve $p = 90 - 0.04q$ dollars per unit. Find the profit-maximizing output, the maximum profit, and compare $MC(800)$ with the actual cost of the 801st unit.
step: Revenue is $R(q) = pq = 90q - 0.04q^2$, so $MR(q) = 90 - 0.08q$. Marginal cost is $MC(q) = 10 + 0.02q$.
step: Set $MR = MC$: $90 - 0.08q = 10 + 0.02q$, so $80 = 0.10q$ and $q^* = 800$ units. Profit is concave ($\pi'' = -0.08 - 0.02 < 0$), so this is a maximum.
step: At $q = 800$: $R = 90(800) - 0.04(800)^2 = 72{,}000 - 25{,}600 = \$46{,}400$ and $C = 5000 + 8000 + 6400 = \$19{,}400$. Maximum profit is $\pi = \$27{,}000$.
step: $MC(800) = 10 + 0.02(800) = \$26.00$. The actual cost of the 801st unit is $C(801) - C(800) = 10 + 0.01(801^2 - 800^2) = 10 + 0.01(1601) = \$26.01$. The derivative is an excellent approximation.
answer: $q^* = 800$ units; maximum profit \$27,000; $MC(800) = \$26.00$ versus \$26.01 actual.

@mistakes
- Setting price equal to marginal cost instead of marginal revenue when the firm faces a downward-sloping demand curve.
- Differentiating $R(q) = pq$ as if $p$ were constant when price depends on $q$: write $p$ as a function of $q$ first.
- Applying the power rule to $e^x$ or forgetting the chain rule's inner derivative.
- Treating $MR = MC$ as sufficient: check that profit is concave (second derivative negative), otherwise you may have found a minimum.

answer: 76
tol: 0.001
check: (( 3*(2+1e-5)**4 - 5*(2+1e-5)**2 + 7) - (3*(2-1e-5)**4 - 5*(2-1e-5)**2 + 7)) / 2e-5
hint: Apply the power rule to each term and drop the constant.
hint: $f'(x) = 12x^3 - 10x$.
solution: $f'(x) = 12x^3 - 10x$, so $f'(2) = 12(8) - 10(2) = 96 - 20 = 76$.

| Firm | Total cost $C(q)$ | Demand $p(q)$ |
|---|---|---|
| Larkspur Outfitters | $3000 + 10q + 0.01q^2$ | $100 - 0.05q$ |
| Bellwether Foods | $1500 + 25q + 0.02q^2$ | $80 - 0.3q$ |
| Cedar Ridge Mills | $800 + 12q + 0.03q^2$ | $60 - 0.2q$ |

Which firm would raise its profit by producing slightly fewer than 100 units?
choice: Larkspur Outfitters
choice*: Bellwether Foods
choice: Cedar Ridge Mills
choice: None of the firms: all three gain by producing more
hint: Compute $MR$ and $MC$ for each firm at $q = 100$.
hint: A firm should cut output when marginal revenue is below marginal cost.
solution: Larkspur: $MC = 10 + 0.02(100) = 12$, $MR = 100 - 0.1(100) = 90$. Bellwether: $MC = 25 + 0.04(100) = 29$, $MR = 80 - 0.6(100) = 20$. Cedar Ridge: $MC = 12 + 0.06(100) = 18$, $MR = 60 - 0.4(100) = 20$. Only Bellwether has $MR < MC$, so only Bellwether gains by cutting output.

prompt: Bellwether Foods has total cost $C(q) = 4000 + 20q + 0.02q^2$ dollars and faces the demand curve $p = 140 - 0.06q$ dollars per unit. Find the maximum profit, in dollars.
answer: 41000
tol: 1
lead: \$
check: max(q * (140 - 0.06*q) - (4000 + 20*q + 0.02*q*q) for q in [x / 100 for x in range(0, 200001)])
hint: Revenue is $R(q) = pq$. Find $MR$ and $MC$ and set them equal.

solution: $q^* = 120/0.16 = 750$. Then $R = 140(750) - 0.06(750)^2 = 105{,}000 - 33{,}750 = 71{,}250$ and $C = 4000 + 15{,}000 + 11{,}250 = 30{,}250$, so profit is \$41,000.

@quiz num

answer: 300
tol: 0.01
unit: units
check: max(range(0, 2001), key=lambda q: q * (60 - 0.04*q) - (2500 + 18*q + 0.03*q*q))
hint: Compute $R(q) = pq$, then $MR$ and $MC$.

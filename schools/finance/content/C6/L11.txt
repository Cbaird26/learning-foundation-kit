@article
Most real choices come with a restriction: a budget, a fully invested portfolio, a production quota. We want to optimize $f(x, y)$ **subject to** a constraint $g(x, y) = c$. Sometimes you can solve the constraint for one variable and substitute, as in the last lesson's two-asset problem, but that gets awkward with many variables or complicated constraints. The method of **Lagrange multipliers** handles them all.

### The idea

At a constrained optimum the level curve of $f$ just touches the constraint curve $g = c$, so the two curves have the same tangent direction, which means their gradients are parallel: $\nabla f = \lambda\nabla g$ for some number $\lambda$. Write this as the stationarity conditions of the **Lagrangian**
$$\mathcal L(x, y, \lambda) = f(x, y) - \lambda\bigl(g(x, y) - c\bigr).$$
Set every partial derivative to zero:
$$\frac{\partial\mathcal L}{\partial x} = f_x - \lambda g_x = 0, \qquad \frac{\partial\mathcal L}{\partial y} = f_y - \lambda g_y = 0, \qquad \frac{\partial\mathcal L}{\partial\lambda} = -(g - c) = 0.$$
The last equation returns the constraint itself. You then have as many equations as unknowns. Check the candidates by evaluating $f$ (or with the second-order test for the bordered Hessian, beyond this course). For the problems here, the structure of $f$ (convex for minimizing variance) tells you the solution is the optimum.

### The multiplier is a shadow price

Let $f^*(c)$ be the optimal value as a function of the constraint level $c$. Then
$$\lambda = \frac{df^*}{dc}.$$
So $\lambda$ measures how much the best achievable value improves per unit of relaxation of the constraint: with a budget constraint it is the value of an extra dollar of budget, called the **shadow price**. It is the sensitivity of the optimum, a practical output of the method.

### Minimum variance with a budget constraint

For $n$ assets with covariance matrix $\Sigma$, minimize the variance $w^T\Sigma w$ subject to full investment $\mathbf 1^Tw = 1$. With $\mathcal L = w^T\Sigma w - \lambda(\mathbf 1^Tw - 1)$, the gradient condition is
$$2\Sigma w = \lambda\mathbf 1 \quad\Longrightarrow\quad w = \frac{\lambda}{2}\Sigma^{-1}\mathbf 1.$$
Impose $\mathbf 1^Tw = 1$ to find $\frac{\lambda}{2} = \frac{1}{\mathbf 1^T\Sigma^{-1}\mathbf 1}$, so
$$w^* = \frac{\Sigma^{-1}\mathbf 1}{\mathbf 1^T\Sigma^{-1}\mathbf 1}, \qquad \sigma_p^2 = \frac{1}{\mathbf 1^T\Sigma^{-1}\mathbf 1}, \qquad \lambda = 2\sigma_p^2.$$
Matrix inverses from Week 8 are now doing real work. For two assets this reduces to the weight formula of the last lesson, and a short sign check is worthwhile: the multiplier is twice the minimum variance, a positive number.

Do not forget that this solution allows negative weights (short sales); with a no-short-selling restriction the problem becomes an inequality-constrained one and the answer can differ.

@example
title: A budget-constrained choice with a shadow price
problem: A consumer maximizes $U(x, y) = xy$ subject to a budget of \$100 when $x$ costs \$2 and $y$ costs \$5, so $2x + 5y = 100$. Find the optimal bundle, the utility, and the multiplier, and interpret it.
step: Write $\mathcal L = xy - \lambda(2x + 5y - 100)$. The conditions are $\mathcal L_x = y - 2\lambda = 0$, $\mathcal L_y = x - 5\lambda = 0$ and $2x + 5y = 100$.
step: So $y = 2\lambda$ and $x = 5\lambda$. Substituting into the budget gives $2(5\lambda) + 5(2\lambda) = 20\lambda = 100$, so $\lambda = 5$, $x = 25$ and $y = 10$.
step: Utility is $U = 25 \times 10 = 250$.
step: Check the shadow price: with budget $B$ the same steps give $U^*(B) = \frac{B^2}{40}$, and $\frac{dU^*}{dB} = \frac{B}{20} = 5$ at $B = 100$, equal to $\lambda$. One more dollar of budget raises the best utility by about 5 units.
answer: $(x, y) = (25, 10)$, $U = 250$, $\lambda = 5$ utility units per extra dollar.

@example
title: Minimum-variance weights by Lagrange multipliers
problem: Asset 1 has variance $0.16$, asset 2 has variance $0.04$ and their covariance is $0.02$. Find the fully invested minimum-variance weights, the minimum variance, and $\lambda$.
step: Let $w_2 = 1 - w_1$ be implied by the constraint $w_1 + w_2 = 1$. The Lagrangian is $\mathcal L = 0.16w_1^2 + 0.04w_2^2 + 2(0.02)w_1w_2 - \lambda(w_1 + w_2 - 1)$.
step: Setting $\mathcal L_{w_1} = 0$ and $\mathcal L_{w_2} = 0$: $2(0.16w_1 + 0.02w_2) = \lambda$ and $2(0.02w_1 + 0.04w_2) = \lambda$. Equate them: $0.16w_1 + 0.02w_2 = 0.02w_1 + 0.04w_2$, so $0.14w_1 = 0.02w_2$, or $w_2 = 7w_1$.
step: With $w_1 + w_2 = 1$: $8w_1 = 1$, so $w_1 = 0.125$ and $w_2 = 0.875$.
step: The variance is $0.16(0.015625) + 0.04(0.765625) + 2(0.02)(0.125)(0.875) = 0.0025 + 0.030625 + 0.004375 = 0.0375$, so $\sigma_p = 19.36\%$. The multiplier is $\lambda = 2(0.0375) = 0.075$, matching $2(0.16 \times 0.125 + 0.02 \times 0.875) = 0.075$.
answer: $w = (12.5\%, 87.5\%)$, $\sigma_p^2 = 0.0375$, $\lambda = 0.075$.

@mistakes
- Forgetting the constraint equation $g(x, y) = c$ when counting equations: you need $n + 1$ equations for $n$ variables and one multiplier.
- Dropping a sign by writing $f + \lambda(g - c)$ in some equations and $f - \lambda(g - c)$ in others; pick one convention and keep it.
- Treating the multiplier as an afterthought rather than as the shadow price $df^*/dc$.
- Assuming the weights are nonnegative; the equality-constrained solution may include short positions.

@practice num
prompt: Minimize $f(x, y) = x^2 + y^2$ subject to $x + y = 10$. Find the minimum value of $f$.
answer: 50
tol: 0.001
check: min(x * x + (10 - x) ** 2 for x in [k / 100 for k in range(-2000, 3001)])
hint: Form $\mathcal L = x^2 + y^2 - \lambda(x + y - 10)$ and set both partial derivatives to zero.
hint: $2x = \lambda$ and $2y = \lambda$, so $x = y$.
solution: $x = y$ and $x + y = 10$ give $x = y = 5$, so the minimum value is $25 + 25 = 50$.

@practice num
prompt: Maximize $U(x, y) = xy$ subject to $3x + 4y = 96$. Find the optimal value of $x$.
answer: 16
tol: 0.001
check: max(range(0, 3201), key=lambda k: (k / 100) * (96 - 3 * (k / 100)) / 4) / 100
hint: The first-order conditions are $y = 3\lambda$ and $x = 4\lambda$.
hint: Substitute into $3x + 4y = 96$: $12\lambda + 12\lambda = 96$.
solution: $24\lambda = 96$ gives $\lambda = 4$, so $x = 16$ and $y = 12$, with $U = 192$.

@practice num
prompt: Asset A has variance $0.16$, asset B has variance $0.04$ and their covariance is $-0.02$. A portfolio is fully invested with weights $w_A + w_B = 1$. Using a Lagrange multiplier or the two-asset formula, find the minimum-variance weight in asset B as a percent.
answer: 75
tol: 0.01
unit: %
check: (1 - min(range(-100000, 200001), key=lambda k: (k / 100000)**2 * 0.16 + (1 - k / 100000)**2 * 0.04 + 2 * (k / 100000) * (1 - k / 100000) * (-0.02)) / 100000) * 100
hint: The conditions $2(\sigma_A^2w_A + \sigma_{AB}w_B) = \lambda$ and $2(\sigma_{AB}w_A + \sigma_B^2w_B) = \lambda$ must hold at once.
hint: Equating them: $0.16w_A - 0.02w_B = -0.02w_A + 0.04w_B$, so $0.18w_A = 0.06w_B$, or $w_B = 3w_A$.
solution: With $w_B = 3w_A$ and $w_A + w_B = 1$ we get $w_A = 0.25$ and $w_B = 0.75$. The variance is $0.16(0.0625) + 0.04(0.5625) + 2(-0.02)(0.25)(0.75) = 0.01 + 0.0225 - 0.0075 = 0.025$.

@practice num
prompt: A consumer maximizes $U = xy$ subject to $6x + 2y = B$. At $B = 72$ the multiplier is $\lambda = 3$, and the optimal utility is $U^* = 108$. Use the multiplier to estimate the increase in the maximum utility if the budget rises from \$72 to \$74.
answer: 6
tol: 0.5
check: 3 * (74 - 72)
hint: The multiplier is the change in the optimal value per extra unit of budget.
hint: $\Delta U^* \approx \lambda\,\Delta B$.
solution: $\Delta U^* \approx 3 \times 2 = 6$. The exact value is $U^*(B) = B^2/48$, so $U^*(74) - U^*(72) = 114.08 - 108 = 6.08$, close to the estimate.

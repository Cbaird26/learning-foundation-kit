@article
The exponential function $e^x$ and its inverse, the **natural logarithm** $\ln x$, are the language of growth. They are linked by $e^{\ln x} = x$ for $x > 0$ and $\ln(e^x) = x$.

### Properties and derivatives

For positive $a$, $b$ and any $k$:
$$\ln(ab) = \ln a + \ln b, \qquad \ln\frac{a}{b} = \ln a - \ln b, \qquad \ln(a^k) = k\ln a.$$
The derivatives are
$$\frac{d}{dx}e^{kx} = ke^{kx}, \qquad \frac{d}{dx}\ln x = \frac1x, \qquad \frac{d}{dx}\ln g(x) = \frac{g'(x)}{g(x)}.$$
The exponential $e^x$ is its own derivative (and the functions $Ce^x$ are the only ones that are), which is exactly what a continuously compounding balance does: the faster it grows, the more it earns. Note the last formula: the derivative of $\ln$ of something is that something's **proportional rate of change**.

### Continuous growth rates

If a quantity follows $V(t) = V_0e^{rt}$, then $\frac{d}{dt}\ln V = r$: the **continuous growth rate** $r$ is constant. Given a start value $V_0$ and an end value $V_T$ after $T$ years,
$$r = \frac{1}{T}\ln\frac{V_T}{V_0}.$$
The **doubling time** solves $e^{rT} = 2$, so $T = \frac{\ln 2}{r} \approx \frac{0.693}{r}$.

The familiar **compound annual growth rate** (CAGR) instead assumes annual compounding: $\text{CAGR} = (V_T/V_0)^{1/T} - 1$. The two are linked by $r = \ln(1 + \text{CAGR})$, so $r$ is always slightly smaller than the CAGR for the same growth.

### Simple and log returns

If a price moves from $P_0$ to $P_1$, the **simple return** is $R = \frac{P_1}{P_0} - 1$ and the **log return** (continuously compounded return) is $r = \ln\frac{P_1}{P_0}$. They are related by $r = \ln(1 + R)$ and $R = e^{r} - 1$. For small returns they are almost equal, because $\ln(1+R) \approx R$.

Log returns have a property that makes them the standard in quantitative finance: they **add across time**. If the price goes $P_0 \to P_1 \to P_2$,
$$\ln\frac{P_2}{P_0} = \ln\frac{P_1}{P_0} + \ln\frac{P_2}{P_1}.$$
Simple returns instead *compound*: $1 + R_{0\to2} = (1 + R_1)(1 + R_2)$. On the other hand, simple returns add across *assets* within a portfolio in one period (a portfolio's simple return is the weighted average of the asset returns), and log returns do not. Use the right one for the job.

In the code below, `math.log` is the natural logarithm. A function to compute log returns from a list of prices is a single list comprehension:

```python
import math

def log_returns(prices):
    return [math.log(b / a) for a, b in zip(prices, prices[1:])]
```

The `zip(prices, prices[1:])` pairs each price with the one after it, so a list of $n$ prices gives $n - 1$ returns.

@example
title: Continuous growth rate versus CAGR
problem: The value of an investment grows from \$80 to \$100 in 3 years. Find the continuous growth rate and the CAGR, as percents to two decimal places.
step: The growth ratio is $100/80 = 1.25$.
step: The continuous rate is $r = \frac{1}{3}\ln 1.25 = \frac{0.22314}{3} = 7.44\%$ per year.
step: The CAGR is $1.25^{1/3} - 1 = 1.07722 - 1 = 7.72\%$ per year.
step: Check the link: $\ln(1.0772) = 0.07438$, which matches $r$. The continuous rate is smaller than the CAGR.
answer: Continuous rate 7.44% per year; CAGR 7.72% per year.

@example
title: Why log returns add
problem: A stock rises 5% on day 1 and falls 5% on day 2. Find the two-day simple return, then the log returns for each day and their sum.
step: Simple returns compound: $1.05 \times 0.95 = 0.9975$, so the two-day simple return is $-0.25\%$. Adding $+5\%$ and $-5\%$ would wrongly give $0$.
step: Day 1 log return: $\ln 1.05 = 0.048790$. Day 2 log return: $\ln 0.95 = -0.051293$.
step: Their sum is $-0.002503$, which equals $\ln 0.9975$, the log return over the two days.
step: Converting back, $e^{-0.002503} - 1 = -0.25\%$, the simple return. Log returns add exactly across time.
answer: Simple return $-0.25\%$; log returns $+4.879\%$ and $-5.129\%$ sum to $-0.2503\%$.

@mistakes
- Adding simple returns across periods instead of compounding them.
- Confusing $\ln(a + b)$ with $\ln a + \ln b$: the logarithm turns products into sums, not sums into sums.
- Using base-10 `log10` where the natural logarithm is intended; in Python `math.log` is natural.
- Quoting a continuous rate as if it were the effective annual rate: $r = \ln(1 + \text{CAGR})$, so the two are different numbers.

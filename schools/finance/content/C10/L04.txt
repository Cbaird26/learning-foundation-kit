@article
Lesson 3 showed that risk depends on how assets are combined. Mean-variance analysis asks the next question: out of all the portfolios you could build from a set of assets, which are worth holding? The answer assumes that an investor cares only about the expected return $\mu_p$ and the standard deviation $\sigma_p$ of the portfolio, preferring more return and less risk.

### The opportunity set and the efficient frontier

Plot every feasible portfolio as a point with $\sigma_p$ on the horizontal axis and $\mu_p$ on the vertical axis. The **minimum-variance frontier** is the left edge of the set: for each target return, the portfolio with the smallest risk. It has a bullet shape, with its leftmost point at the **global minimum-variance portfolio** (GMV). Portfolios on the lower arm are dominated, because a point on the upper arm has the same risk and a higher return. The upper arm, from the GMV upward, is the **efficient frontier**.

For $n$ risky assets with expected-return vector $\boldsymbol{\mu}$ and covariance matrix $\Sigma$, with $\mathbf{1}$ a vector of ones, the GMV weights are

$$\mathbf{w}_{\text{GMV}} = \frac{\Sigma^{-1}\mathbf{1}}{\mathbf{1}^{\top}\Sigma^{-1}\mathbf{1}}.$$

Weights may be negative (short sales) unless you add constraints; with a no-short-sales constraint the frontier is computed numerically and lies inside the unconstrained one.

### Adding a risk-free asset

Let the risk-free rate be $r_f$. For a risky portfolio $P$, the **Sharpe ratio** is

$$S_P = \frac{\mu_P - r_f}{\sigma_P}.$$

Mixing $P$ with the risk-free asset traces a straight line, the **capital allocation line** (CAL), with intercept $r_f$ and slope $S_P$: investing a fraction $y$ in $P$ gives $\mu = r_f + y(\mu_P - r_f)$ and $\sigma = y\sigma_P$. The best CAL is the steepest one, which touches the efficient frontier at the **tangency portfolio** $T$, the risky portfolio with the highest Sharpe ratio:

$$\mathbf{w}_T = \frac{\Sigma^{-1}(\boldsymbol{\mu} - r_f\mathbf{1})}{\mathbf{1}^{\top}\Sigma^{-1}(\boldsymbol{\mu} - r_f\mathbf{1})}.$$

The line through $r_f$ and $T$ is the **capital market line** when $T$ is the market portfolio. The **separation property** says that every mean-variance investor, whatever the risk tolerance, holds the same risky portfolio $T$; only the split between $T$ and the risk-free asset (the choice of $y$) differs. Borrowing at $r_f$ ($y>1$) extends the line beyond $T$.

For two risky assets with excess means $e_i = \mu_i - r_f$ and covariance $\sigma_{12}$, the tangency weight in asset 1 is

$$w_1 = \frac{e_1\sigma_2^2 - e_2\sigma_{12}}{e_1\sigma_2^2 + e_2\sigma_1^2 - (e_1 + e_2)\sigma_{12}}.$$

### Tracing the frontier in Python

With two assets, put $w_1 = 0, 0.01, \dots, 1$ and compute $(\sigma_p, \mu_p)$ for each weight, then plot the points. On your own computer you would write:

```python
# on your own computer: requires matplotlib
import matplotlib.pyplot as plt
points = frontier(0.10, 0.06, 0.20, 0.12, 0.3, 100)
plt.plot([s for s, m in points], [m for s, m in points])
plt.xlabel("standard deviation"); plt.ylabel("expected return")
plt.show()
```

For many assets, a quadratic optimizer finds the minimum-variance weights for each target return; the frontier of ten assets in the project uses that approach.

### The limits of optimization

The optimizer treats $\boldsymbol{\mu}$ and $\Sigma$ as known, but both are estimated with error. Expected returns are estimated especially badly, and mean-variance optimization amplifies the error: tiny changes in $\boldsymbol{\mu}$ can swing the weights from large longs to large shorts. This is why practitioners shrink estimates, impose constraints, or compare against simple rules such as equal weighting.

@example
title: The tangency portfolio of two assets
problem: Asset 1 has $\mu_1 = 10\%$, $\sigma_1 = 20\%$; asset 2 has $\mu_2 = 6\%$, $\sigma_2 = 12\%$; the correlation is 0.3 and the risk-free rate is 2%. Find the tangency portfolio and its Sharpe ratio.
step: Excess means: $e_1 = 8\%$, $e_2 = 4\%$. Covariance: $\sigma_{12} = 0.3(0.20)(0.12) = 0.0072$.
step: Numerator: $0.08(0.0144) - 0.04(0.0072) = 0.001152 - 0.000288 = 0.000864$.
step: Denominator: $0.001152 + 0.04(0.04) - 0.12(0.0072) = 0.001152 + 0.0016 - 0.000864 = 0.001888$. So $w_1 = 0.000864/0.001888 = 45.76\%$ and $w_2 = 54.24\%$.
step: $\mu_T = 0.4576(10) + 0.5424(6) = 7.83\%$ and $\sigma_T = 12.72\%$, so $S_T = (7.83 - 2)/12.72 = 0.458$.
step: Check: a 30/70 mix has Sharpe 0.444 and a 70/30 mix 0.440, both lower.
answer: 45.76% in asset 1, 54.24% in asset 2; expected return 7.83%, standard deviation 12.72%, Sharpe ratio 0.458.

@example
title: Choosing a point on the capital allocation line
problem: Continue with the tangency portfolio above ($\mu_T = 7.83\%$, $\sigma_T = 12.72\%$, $r_f = 2\%$). What mix gives a standard deviation of 10%, and what is its expected return?
step: A fraction $y$ in $T$ gives $\sigma = y\sigma_T$, so $y = 10/12.72 = 0.786$ and the risk-free weight is $0.214$.
step: The expected return is $2\% + 0.786(7.83\% - 2\%) = 6.58\%$, or equivalently $2\% + 0.4583 \times 10\% = 6.58\%$.
step: Any other portfolio of the two risky assets with 10% risk has a lower expected return than 6.58%.
answer: 78.6% in the tangency portfolio and 21.4% risk-free, with expected return about 6.58%.

@mistakes
- Treating the whole minimum-variance frontier as efficient; only the part above the global minimum-variance portfolio is.
- Computing the tangency portfolio's Sharpe ratio after mixing in the risk-free asset; every point on the capital allocation line has the same Sharpe ratio as the risky portfolio it mixes.
- Forgetting that the tangency weights use excess returns $\mu - r_f$, not raw expected returns.
- Trusting optimized weights as if the inputs were known with certainty.

model:
```python
import math


def frontier(mu1, mu2, sigma1, sigma2, rho, n):
    """(sigma, mu) of two-asset portfolios with w1 = 0, 1/n, ..., 1."""
    points = []
    for k in range(n + 1):
        w1 = k / n
        w2 = 1 - w1
        variance = (w1 ** 2 * sigma1 ** 2 + w2 ** 2 * sigma2 ** 2
                    + 2 * w1 * w2 * rho * sigma1 * sigma2)
        points.append((math.sqrt(max(variance, 0.0)), w1 * mu1 + w2 * mu2))
    return points
```
hint: Loop over `k` and compute the weight `w1 = k / n` each time.
hint: Use the two-asset variance formula and take the square root; guard against a tiny negative variance from rounding when `rho` is -1.
solution: For each weight, compute the portfolio variance with the two-asset formula and the expected return as the weighted average, then append the pair. Plotting the points shows the bullet shape: the standard deviation first falls below the safer asset's before rising again. The `max(variance, 0.0)` protects the square root from floating-point error when $\rho = -1$.

@quiz self
prompt: A student estimates expected returns for ten stocks from five years of monthly data and finds that the mean-variance optimizer puts 60% of the portfolio in one stock and shorts three others. Explain in a short paragraph why this result should be treated with caution, and name two practical remedies.
hint: Think about which inputs are estimated most precisely.
solution: Expected returns estimated from a few years of data have very large standard errors (a stock with 20% annual volatility has a standard error of about 9 percentage points of annual mean return after five years), and the optimizer treats them as exact, so it loads up on assets whose estimated means happen to be high or whose estimated covariances are low. Small changes in inputs change the weights a lot, so the extreme result is mostly estimation error. Remedies include constraining weights (no short sales or position limits), shrinking estimated means toward a common value, using a shrinkage estimate of the covariance matrix, or comparing with the equal-weighted portfolio.

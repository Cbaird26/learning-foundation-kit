# Finance Learning Foundation

**Open the school:** https://cbaird26.github.io/finance-learning-foundation/

A Khan Academy-style self-study school: 63 courses in five stages, from kindergarten through a complete college finance
degree to CFA Program exam review and an investment career — elementary, middle and high school (including money
math, financial literacy, Python, personal finance and AP-level economics), the finance degree (financial and
managerial accounting, intermediate microeconomics, macroeconomics and banking, business statistics, quantitative
methods, corporate finance, financial markets and institutions, financial reporting and analysis, investments,
econometrics, fixed income, derivatives, valuation, portfolio management, Python for finance, international finance,
risk management, behavioral finance, and business law, ethics and regulation), and career preparation (CFA Program
Levels I, II and III review, equity research and financial modeling, a capstone research report, and the ethics and
practice of the investment profession).

Each course has 12 weekly lessons (an article, worked examples, common mistakes, and auto-graded practice and quiz
questions), a week 13–14 project with a review guide, and a cumulative final exam. Skills move through mastery levels
with unit quizzes, a midterm and course challenges, and missed questions go into an error log that brings back a
parallel problem 48 hours later.

## Python in the page

Python exercises run real Python in the browser, with nothing to install: the page includes Brython, which follows
Python 3.14, with CPython's own json package. Press Run to try code and Check to grade it against the exercise's tests;
a program that runs too long is stopped after a few seconds. Lesson code that runs here has a "Try it" button, and the
Python tab is a scratchpad. The browser's Python has the whole language and most of the standard library (including
math, statistics, decimal, datetime and csv), but not threads, networking or packages such as NumPy and pandas; the
courses that use those explain how to set them up on your own computer. Your code is never uploaded.

## Using it

Open the site in any modern browser. The whole school is one self-contained page (`index.html`), so you can also save the page and use it offline.

Progress and the error log are kept only in your own browser and are never uploaded. Keep using the same browser and do not clear its site data; another browser or device starts fresh. The Tutor button prepares a prompt you can copy into a chat with Claude.

## Accuracy and disclaimers

Every course was written and then independently reviewed. Every numeric answer was checked against an independent
calculation, every Python exercise's model solution was run against its tests both in standard Python and in the
browser's Python, and every "what does this print?" answer was produced by running the program. Tax figures,
contribution limits, regulations and exam details change every year; the lessons label them by year, so check the
current official sources. The lessons are general education, not investment, tax or legal advice. Self-study scores
do not award credit, degrees or any credential.

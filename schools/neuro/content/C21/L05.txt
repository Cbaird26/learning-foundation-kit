@article
You are typing messages to two correspondents in other rooms. One is a person, the other a machine. After five minutes of conversation on any topic you like, you must say which is which. If you cannot do so reliably, has the machine shown that it can think? Alan Turing posed this puzzle in 1950, and philosophers have been arguing about it since.

### The imitation game

In "Computing Machinery and Intelligence" (1950), Turing began by proposing to replace the question "Can machines think?", which he thought too vague, with a more concrete question about a game. In the **imitation game** an interrogator communicates by text with a human and a machine and tries to identify which is which, while the machine tries to pass as the human. The machine is said to do well if the interrogator misidentifies it often. Turing predicted that by about the end of the twentieth century an average interrogator would have no more than a 70% chance of making the right identification after five minutes of questioning. He also considered a list of objections, including the theological objection, the mathematical objection from limits of formal systems, the argument from consciousness and the argument from various disabilities, and replied to each.

The **Turing test** is the name given to this setup. It is behavioral: it judges by what the machine says, not by how it is built. In this respect it resembles logical behaviorism, and it faces some of the same objections.

### What does the test show?

There are two readings of the claim. On the strong reading, passing the test is **sufficient** for thinking: anything that passes thinks. On a weaker reading, passing is good **evidence** of thinking, defeasible by what else we learn about the system. Interpreters disagree about which Turing intended, and both are worth evaluating. A related question is whether the test is **necessary**: a creature that could think but does not converse in a human way (an animal, say) would fail, so the test is generally not taken to be a necessary condition for thinking.

The argument on the strong reading:

| P1 | If a machine passes the imitation game, it behaves in conversation in a way indistinguishable from a thinking human. |
| P2 | Whatever behaves in conversation in a way indistinguishable from a thinking human is thinking. |
| C | So a machine that passes the imitation game is thinking. |

It is valid, and the debate is about P2. Turing's own defense was in effect an appeal to the **other-minds** problem: we attribute thought to other people only on the basis of behavior, so if we withhold it from a machine that behaves the same way, we are applying a double standard.

### Objections

**Blockhead.** Ned Block imagined a machine that has stored in advance a huge table of conversation: for every possible sequence of sentences an interrogator might type within a time limit, an appropriate reply is stored. Such a machine, a "look-up table," could in principle pass the test. But it does no reasoning, only retrieval. If Block is right, P2 is false: a system can match thinking behavior without thinking. Defenders reply that the machine is physically impossible, that the intuition is unreliable because we cannot imagine so large a table, or that the test should be understood as evidence, where Blockhead matters less since we know how it works.

**Behavior is not enough.** A more general objection, associated with the Chinese room (week 6), says that producing the right outputs does not show understanding.

**Human-centered.** The test measures similarity to human conversation, not intelligence as such. A machine might be intelligent in a very different way and fail, or be good at imitating without intelligence.

### Artificial intelligence now

Computer systems today can produce fluent humanlike conversation. As of 2026 there is no scientific or philosophical consensus on whether any AI system understands, is conscious or has moral status, nor on what evidence would settle it. Leading theories of consciousness give different verdicts, and the question is actively researched. Some argue that fluent behavior is exactly the evidence the Turing test treats as decisive; others point out that such systems are trained on human text, so human-like output is what we would expect even without understanding. Evaluate each argument on its premises.

title: Strong and weak readings
problem: A student says: "Passing the Turing test proves that the machine thinks." Distinguish what the strong and weak readings of the test would say, and which premise the student needs.
step: Strong reading: passing is sufficient for thinking. The argument needs P2: whatever converses like a thinking human thinks.
step: Weak reading: passing is evidence, so it makes it likely that the machine thinks unless there is a defeater, such as a look-up-table design.
step: The word "proves" suggests the strong reading. A critic can reply by producing a case, such as Blockhead, in which the behavior is present without thinking.
step: The weak reading survives Blockhead by allowing the evidence to be defeated.
answer: The student needs P2. The strong reading is vulnerable to Blockhead; the weak reading is not.

@example
title: Reading the Blockhead argument
problem: Put the Blockhead objection in standard form and identify what it attacks.
step: P1: A machine with a stored table of replies for every possible conversation within a time limit could pass the test.
step: P2: Such a machine does not think: it only retrieves stored replies.
step: C: So passing the test is not sufficient for thinking.
step: The argument attacks the sufficiency claim, premise P2 of the argument for the test. A defender can deny P1's possibility or deny P2 of Blockhead.
answer: Blockhead is a counterexample to the claim that behavior suffices for thought.

@mistakes
- Thinking Turing claimed the test is necessary for thinking.
- Confusing the Turing test with the Chinese room: the test is a proposal; the room is an objection to a view of computers.
- Saying that Turing defined thinking as passing the test. His text is read as replacing the question or giving a sufficient condition; interpreters disagree.
- Claiming that the Blockhead objection is a proof. It depends on an intuition about the table.

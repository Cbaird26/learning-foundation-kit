@article
Last week gave us the equations. This week we run them. A short current pulse of the right size triggers a spike; a pulse a little smaller triggers only a small bump; a second pulse right after the first fails to trigger anything. These three facts, all-or-none firing, a threshold and refractoriness, fall out of the same four differential equations.

### Simulating with Euler steps

With the conventions of week 5 ($V$ in mV, time in ms, current in µA/cm²), the **Euler method** advances every variable from its old values: $V \leftarrow V + \Delta t\,(I_\text{ext} - I_\text{ion})/C$ with $C = 1$, and $x \leftarrow x + \Delta t\,[\alpha_x(1 - x) - \beta_x x]$ for $x = m, h, n$. All new values must be computed from the old state, and the simulation starts at the resting state, where each gate is at its steady state at $-65$ mV.

```python
import math


def rates(V):
    x, y = V + 55.0, V + 40.0
    a_n = 0.1 if abs(x) < 1e-7 else 0.01 * x / (1.0 - math.exp(-x / 10.0))
    a_m = 1.0 if abs(y) < 1e-7 else 0.1 * y / (1.0 - math.exp(-y / 10.0))
    return (a_n, 0.125 * math.exp(-(V + 65.0) / 80.0),
            a_m, 4.0 * math.exp(-(V + 65.0) / 18.0),
            0.07 * math.exp(-(V + 65.0) / 20.0),
            1.0 / (1.0 + math.exp(-(V + 35.0) / 10.0)))


def hh_simulate(amp, t_on, t_off, t_end, dt=0.01):
    """Voltage trace (mV): the start value plus one value per Euler step."""
    V = -65.0
    a_n, b_n, a_m, b_m, a_h, b_h = rates(V)
    n, m, h = a_n / (a_n + b_n), a_m / (a_m + b_m), a_h / (a_h + b_h)
    trace = [V]
    for k in range(int(round(t_end / dt))):
        I = amp if t_on <= k * dt < t_off else 0.0
        a_n, b_n, a_m, b_m, a_h, b_h = rates(V)
        i_ion = (120.0 * m ** 3 * h * (V - 50.0) + 36.0 * n ** 4 * (V + 77.0)
                 + 0.3 * (V + 54.387))
        dV = I - i_ion
        dn = a_n * (1 - n) - b_n * n
        dm = a_m * (1 - m) - b_m * m
        dh = a_h * (1 - h) - b_h * h
        V, n, m, h = V + dt * dV, n + dt * dn, m + dt * dm, h + dt * dh
        trace.append(V)
    return trace

trace = hh_simulate(10.0, 0.0, 1.0, 6.0)
peak = max(trace)
print(round(peak, 2), round(trace.index(peak) * 0.01, 2))
```

This prints `39.34 2.53`: a 1 ms pulse of 10 µA/cm² produces a spike peaking at $+39$ mV, 2.5 ms after the pulse starts. The voltage trace, sampled at a few times (step 0.01 ms):

| time (ms) | 0 | 0.5 | 1 | 1.5 | 2 | 2.5 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|---|---|---|
| $V$ (mV) | −65.0 | −60.5 | −56.0 | −53.4 | −41.6 | 39.0 | 22.1 | −27.0 | −75.4 | −76.0 |

After the pulse ends the voltage keeps rising on its own: the Na+ current has taken over. The spike then falls below rest to about $-76$ mV (the **undershoot**, near $E_\text{K} = -77$ mV) because $g_\text{K}$ is still elevated. The Euler step must be small relative to the fastest time constant (about 0.2 ms); halving $\Delta t$ from 0.01 to 0.005 ms changes the peak by well under 1 mV.

### Threshold

A pulse of 7 µA/cm² for 1 ms is only just enough: with much less the voltage rises a few millivolts and decays back, with a bit more the spike is full size. The response is **all-or-none**: above threshold the spike is nearly the same whatever the stimulus, because its energy comes from the Na+ gradient, not from the stimulus. Threshold is the point where the inward Na+ current, which grows regeneratively with depolarization, first exceeds the outward K+ and leak currents. It is not a fixed voltage: it depends on the stimulus duration (a **strength–duration relation**). Minimum amplitudes found by bisection in this model, for a pulse starting at 0 ms:

| pulse duration (ms) | 0.5 | 1 | 2 |
|---|---|---|---|
| minimum amplitude (µA/cm²) | 13.3 | 7.0 | 3.9 |

Longer pulses need less current, but the product amplitude × duration (the charge) is lowest for brief pulses: charge is lost through the leak while the capacitor charges slowly.

### Refractoriness

Right after a spike, Na+ channels are inactivated ($h$ is small) and K+ channels are still open ($n$ is large). During the **absolute refractory period** no stimulus can trigger a second spike; afterwards, in the **relative refractory period**, a stronger-than-normal stimulus is needed. With the 1 ms pulse of the example as the first stimulus, the minimum amplitude of a second 1 ms pulse that evokes a second spike was about 63 µA/cm² when it started 8 ms after the first, about 31 at 10 ms and about 9 at 15 ms, while nothing up to 200 µA/cm² worked at 4 to 6 ms. The refractory period limits the maximum firing rate to roughly $1000/(\text{refractory period in ms})$ Hz.

### Propagation

A spike at one point of an axon depolarizes the neighboring membrane by local-circuit current (the passive spread of week 4); when that membrane reaches threshold, it fires, and so on. The spike is regenerated at every point, so it does not decay. It travels in one direction because the membrane just behind it is refractory. Two spikes colliding head-on annihilate each other for the same reason. The **conduction velocity** is the slope of position against spike arrival time; the length of the spike along the axon is velocity × spike duration (for 20 m/s and a 1 ms spike, 20 mm).

problem: Three electrodes on an axon at positions 0, 12 and 30 mm record spike peaks at 2.0, 3.1 and 4.5 ms. Estimate the conduction velocity by the slope of a least-squares line of position against arrival time.

step: The slope is $37.8/3.14 = 12.04$ mm/ms, and 1 mm/ms is 1 m/s.

@example
title: Spike time from a sampled trace
problem: A voltage trace is sampled every 1 ms: $-65, -20, 30, 10, -40$ mV at $t = 0, 1, 2, 3, 4$ ms. When does the spike cross $0$ mV?
step: Find the sample pair where $V$ goes from below 0 to at or above 0: between $t = 1$ ms ($-20$) and $t = 2$ ms ($30$).
step: Interpolate linearly: the fraction of the interval is $(0 - (-20))/(30 - (-20)) = 0.4$.
step: The crossing time is $1 + 0.4 \times 1 = 1.4$ ms. The later fall from 10 to $-40$ is a downward crossing and is not counted.
answer: The upward crossing is at $1.4$ ms.

@mistakes
- Updating the variables one after another within a step: $V$ must be advanced with the old $m$, $h$, $n$, and the gates with the old $V$; otherwise the scheme is not Euler's.
- Calling a subthreshold bump a spike: spikes are counted as upward crossings of a fixed level (here 0 mV), and a trace that stays below it contains none.
- Reading refractoriness as a property of the stimulus: it is a property of the membrane state, set by Na+ inactivation and elevated K+ conductance.
- Using $1$ mm/ms $= 1$ mm/s: the units give $1$ m/s, since mm/ms equals m/s.

```python
def detect_spikes(times, V, thresh=0.0):
    """Interpolated upward crossings of thresh in a sampled trace."""
    spikes = []
    for k in range(len(V) - 1):
        if V[k] < thresh <= V[k + 1]:
            frac = (thresh - V[k]) / (V[k + 1] - V[k])
            spikes.append(times[k] + frac * (times[k + 1] - times[k]))
    return spikes
```
hint: Loop over consecutive pairs; when the first is below the threshold and the second is at or above it, interpolate the time.
solution: A trace that starts above the threshold (the fourth test) has no upward crossing, so nothing is counted; a spike that only rises toward threshold is not a spike either. Interpolating gives times between samples, which matters when the sampling interval is coarse.

```python
                 + 0.3 * (V + 54.387))
        dn = a_n * (1 - n) - b_n * n
        dm = a_m * (1 - m) - b_m * m
        dh = a_h * (1 - h) - b_h * h
        V, n, m, h = V + dt * (I - i_ion), n + dt * dn, m + dt * dm, h + dt * dh
        peak = max(peak, V)
```

```python
def spike_threshold(t_off):
    """Smallest pulse amplitude (uA/cm^2) that evokes a spike, by bisection."""
    lo, hi = 0.0, 30.0
    for _ in range(8):
        mid = (lo + hi) / 2.0
        if peak_voltage(mid, t_off) > 0.0:
            hi = mid
        else:
            lo = mid
    return (lo + hi) / 2.0
```

The last two tests check the bracket: a pulse a bit above the returned value fires and one well below does not. Longer pulses need less current, the strength–duration relation.

```python
def conduction_velocity(positions_mm, arrival_ms):
    """Least-squares slope of position against arrival time, in m/s."""
    n = len(positions_mm)
    mean_t = sum(arrival_ms) / n
    mean_x = sum(positions_mm) / n
    sxy = sum((t - mean_t) * (x - mean_x) for t, x in zip(arrival_ms, positions_mm))
    sxx = sum((t - mean_t) ** 2 for t in arrival_ms)
    return sxy / sxx
```
hint: Regress position on time, not time on position: the slope has units mm/ms, which is m/s.
solution: The slope is $\sum (t - \bar t)(x - \bar x)/\sum (t - \bar t)^2$. Regressing time on position and inverting would give a different value for noisy data; the third test uses jittered arrival times, where the two differ. The fifth test lists positions in decreasing order with decreasing times, which gives the same slope.

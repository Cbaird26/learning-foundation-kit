@article
A synapse on a dendrite produces a voltage change at the synapse. By the time it reaches the cell body, a millimeter away, how much is left? Last week's single-compartment membrane has no answer, because it has no space. A dendrite is a thin tube, and voltage must flow along it, through the resistance of the cytoplasm, while leaking out across the membrane.

### From circuits to the cable equation

Divide a cylindrical process of diameter $d$ into short segments. Per unit length the membrane has resistance $r_m = R_m/(\pi d)$ (in Ω·cm) and capacitance $c_m = C_m \pi d$ (per cm), and the cytoplasm has axial resistance $r_i = 4R_i/(\pi d^2)$ (in Ω/cm), where $R_i$ is the **intracellular resistivity** (typically 70 to 150 Ω·cm). Current conservation in a segment, together with Ohm's law along the axis, gives the **cable equation** for the deviation $V$ from rest:

$$\lambda^2 \frac{\partial^2 V}{\partial x^2} = \tau \frac{\partial V}{\partial t} + V,$$

with the **length constant** and **time constant**

$$\lambda = \sqrt{\frac{r_m}{r_i}} = \sqrt{\frac{R_m\, d}{4 R_i}}, \qquad \tau = r_m c_m = R_m C_m .$$

The time constant is the same $\tau$ as in the single-compartment membrane. The length constant sets the spatial scale; it grows with the square root of the diameter, so thick processes carry signals farther than thin ones.

### Steady state

For a constant voltage $V_0$ held at one end of a very long ("semi-infinite") cable, $\partial V/\partial t = 0$ and the equation becomes $V'' = V/\lambda^2$, whose decaying solution is

$$V(x) = V_0\, e^{-x/\lambda} .$$

With $R_m = 20\ \text{k}\Omega\,\text{cm}^2$, $R_i = 100\ \Omega\,\text{cm}$ and $d = 2\ \mu\text{m}$, $\lambda = 1000\ \mu\text{m}$ and $\tau = 20$ ms. Voltage decays to 37% of its value at $x = \lambda$:

| $x/\lambda$ | 0.5 | 1 | 2 | 3 |
|---|---|---|---|---|
| $V/V_0$ | 0.607 | 0.368 | 0.135 | 0.050 |

If the cable ends at $x = L$ with a **sealed end** (no current through it), the solution that satisfies $V'(L) = 0$ is

$$V(x) = V_0\,\frac{\cosh\big((L - x)/\lambda\big)}{\cosh(L/\lambda)} ,$$

which decays less than the infinite cable because current cannot escape through the end. For $L = \lambda$ the voltage at the end is $V_0/\cosh 1 = 0.648\,V_0$, compared with $0.368\,V_0$ for the infinite cable.

### Input resistance and timing

The input resistance of a semi-infinite cable is $R_\infty = \sqrt{r_m r_i} = \frac{2}{\pi}\sqrt{R_m R_i}\,d^{-3/2}$ (with $d$ in cm, giving ohms); for the cable above it is 318 MΩ. Thin processes have high input resistance, so a small synaptic current produces a large local voltage, but little of it spreads far.

The time dimension adds a delay: voltage at a distance $x$ rises more slowly and to a smaller value than at the injection site, because the membrane between must charge first. Fast inputs are therefore attenuated more than slow ones along a dendrite, and fast and distant inputs arrive at the soma smoothed, a theme of week 9.

### A cable as a chain of compartments

A computer cannot handle a continuous $x$, so we cut the cable into $n$ compartments of length $\Delta x$, with $h = \Delta x/\lambda$ and time in units of $\tau$ ($T = t/\tau$). Each compartment obeys the discretized equation

$$\frac{dV_j}{dT} = \frac{V_{j-1} - 2V_j + V_{j+1}}{h^2} - V_j,$$

which says that a compartment is charged by its two neighbors and leaks. In code, with the first compartment clamped to $V_0$ and the last one sealed (its missing right neighbor is replaced by itself), an Euler step is stable when $\Delta T (2/h^2 + 1) \le 1$:

```python
def cable_step(V, h, dt):
    """One Euler step; V[0] stays clamped, the last compartment is sealed."""
    new = V[:]
    for j in range(1, len(V)):
        right = V[j + 1] if j < len(V) - 1 else V[j]
        new[j] = V[j] + dt * ((V[j - 1] - 2 * V[j] + right) / h ** 2 - V[j])
    return new

V = [10.0, 0.0, 0.0]
for _ in range(2):
    V = cable_step(V, 1.0, 0.1)
print([round(v, 3) for v in V])
```

This prints `[10.0, 1.7, 0.1]`: the clamp drives compartment 1, and only then does compartment 2 start to charge, a discrete picture of the delay.

title: How far does a dendritic potential spread?
problem: A dendrite has $R_m = 25\ \text{k}\Omega\,\text{cm}^2$, $R_i = 125\ \Omega\,\text{cm}$ and diameter $3\ \mu\text{m}$. What fraction of a steady voltage survives 800 µm along a long, uniform stretch?
step: Convert the diameter: $d = 3 \times 10^{-4}$ cm.
step: Compute $\lambda = \sqrt{R_m d/(4R_i)} = \sqrt{25000 \times 3\times10^{-4}/500} = \sqrt{0.015} = 0.1225$ cm, which is 1225 µm.
step: The fraction is $e^{-x/\lambda} = e^{-800/1225} = e^{-0.653}$.
step: Evaluate: $e^{-0.653} = 0.520$.
answer: About 52% of the voltage survives, with $\lambda \approx 1225\ \mu\text{m}$.

@example
title: A sealed-end cable
problem: A cable with $\lambda = 500\ \mu\text{m}$ is $L = 500\ \mu\text{m}$ long and sealed at the far end. A steady 10 mV is applied at $x = 0$. What is the voltage at the sealed end, compared with an infinitely long cable?
step: For the sealed cable, $V(L) = V_0 \cosh(0)/\cosh(L/\lambda) = 10/\cosh 1$.
step: $\cosh 1 = 1.543$, so $V(L) = 6.48$ mV.
step: For the infinite cable, $V(L) = 10 e^{-1} = 3.68$ mV.
answer: $6.48$ mV, almost twice the $3.68$ mV of the infinite cable, because the sealed end stops current from leaving.

@mistakes
- Using micrometers in the formula for $\lambda$ without converting: with $R_m$ in Ω·cm² and $R_i$ in Ω·cm, $d$ must be in centimeters (1 µm is $10^{-4}$ cm), and the result is in cm.
- Thinking thicker dendrites change the time constant: $\tau = R_m C_m$ does not depend on diameter; $\lambda$ does, as $\sqrt{d}$.
- Applying $V_0 e^{-x/\lambda}$ to a short cable: if the end is sealed or the cable branches, the profile differs; the exponential holds only for a very long uniform cable at steady state.
- Using a time step that violates the Euler stability limit in a compartmental model: halving $\Delta x$ forces a time step about four times smaller.

```python
import math


def steady_profile(V0, positions, lam, length=None):
    """Steady-state voltage along a cable clamped at x = 0."""
    if length is None:
        return [V0 * math.exp(-x / lam) for x in positions]
    denom = math.cosh(length / lam)
    return [V0 * math.cosh((length - x) / lam) / denom for x in positions]
```
hint: Handle the infinite cable with the exponential, and the sealed-end cable with the ratio of hyperbolic cosines.
solution: The two formulas differ only in how current can leave at the far end. At $x = 0$ both give $V_0$. In the sealed cable at every $x > 0$ the voltage is larger than in the infinite cable, which the last test checks for the points beyond the clamp.

```python
def simulate_cable(n, h, V0, t_end, dt):
    """Euler simulation of a clamped, sealed-end chain of passive compartments."""
    V = [0.0] * n
    V[0] = V0
    for _ in range(int(round(t_end / dt))):
        new = V[:]
        for j in range(1, n):
            right = V[j + 1] if j < n - 1 else V[j]
            new[j] = V[j] + dt * ((V[j - 1] - 2 * V[j] + right) / h ** 2 - V[j])
        V = new
    return V
```
hint: Copy the list at the start of each step so that every compartment is updated from the old voltages, and treat the last compartment's right neighbor as itself.
solution: Updating in place would let a compartment see its left neighbor's new value, changing the numbers; building `new` from `V` keeps the update synchronous. The long run converges to the steady-state profile of a sealed cable, and the early profile is ordered by distance from the clamp, showing that distant compartments charge later and to a smaller voltage.

```python
def cable_steady_state(n, h, V0):
    """Steady state of a clamped, sealed-end compartment chain (Thomas algorithm)."""
    if n == 1:
        return [V0]
    lower = [0.0] * n
    diag = [0.0] * n
    upper = [0.0] * n
    rhs = [0.0] * n
    diag[0], rhs[0] = 1.0, V0
    for j in range(1, n):
        lower[j] = -1.0
        diag[j] = 2.0 + h * h if j < n - 1 else 1.0 + h * h
        upper[j] = -1.0 if j < n - 1 else 0.0
    for j in range(1, n):
        w = lower[j] / diag[j - 1]
        diag[j] -= w * upper[j - 1]
        rhs[j] -= w * rhs[j - 1]
    x = [0.0] * n
    x[-1] = rhs[-1] / diag[-1]
    for j in range(n - 2, -1, -1):
        x[j] = (rhs[j] - upper[j] * x[j + 1]) / diag[j]
    return x
```
hint: Build the three diagonals and the right-hand side (the first row just says $V_0$ = `V0`), eliminate the lower diagonal going down, then back-substitute going up.
solution: The steady state is the solution of a tridiagonal linear system, solved in about $n$ operations by the Thomas algorithm. For $n = 3$ and $h = 1$ the equations $3V_1 - V_0 - V_2 = 0$ and $2V_2 - V_1 = 0$ give $V_2 = V_0/5 = 2$ and $V_1 = 2V_2 = 4$ when $V_0 = 10$. With many small compartments the result approaches the continuous cable formula for a sealed end; the last test is within about 10% of it.

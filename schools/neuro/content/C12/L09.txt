@article
A cortical pyramidal neuron receives thousands of synapses, each producing a deflection of a fraction of a millivolt, yet the cell fires when a handful of them coincide. How does a neuron add up many small, brief, scattered inputs? The answer has three parts: time (inputs overlap if they arrive close together), space (inputs attenuate along dendrites, next week) and conductance (synapses change the membrane they act on).

### A synaptic current into an RC membrane

Take a passive membrane (week 3) with resting potential $E_L$ and time constant $\tau_m$, and a synaptic current that decays exponentially, $I(t) = I_0 e^{-t/\tau_s}$, with $\tau_s$ the synaptic time constant (a few milliseconds for AMPA receptors). Writing $V$ for the deviation from rest, $\tau_m\,dV/dt = -V + R I(t)$ has the solution (for $\tau_s \ne \tau_m$)

$$V(t) = \frac{R I_0\,\tau_s}{\tau_m - \tau_s}\left(e^{-t/\tau_m} - e^{-t/\tau_s}\right).$$

This **excitatory postsynaptic potential** (EPSP) rises with the faster time constant and decays with the slower one. It peaks at

$$t_\text{peak} = \frac{\tau_m\tau_s}{\tau_m - \tau_s}\ln\frac{\tau_m}{\tau_s} .$$

For $\tau_m = 20$ ms and $\tau_s = 2$ ms, $t_\text{peak} = 5.12$ ms, and with $R I_0 = 10$ mV the peak is $0.77$ mV. The membrane smooths the input: the EPSP is far slower than the current that creates it.

### Summation

Because the membrane equation is linear, EPSPs from separate current inputs add: the response to two inputs is the sum of the two shifted EPSPs. This is **temporal summation**: two inputs 5 ms apart add to $1.88$ times the peak of one (in units where one peak is 1), against $2.0$ for simultaneous inputs and $1.0$ when the inputs are far apart. The longer $\tau_m$ is, the wider the window over which inputs add, which is why the time constant sets how well a neuron acts as a coincidence detector. An **inhibitory postsynaptic potential** (IPSP) is the same with the opposite sign, or, with a conductance, a pull toward $E_\text{Cl}$.

### Conductance-based synapses and shunting

A real synapse is a conductance, not a current source: $I_\text{syn} = g_\text{syn}(t)\,(V - E_\text{syn})$, with $E_\text{exc} \approx 0$ mV for glutamate receptors and $E_\text{inh}$ near $-70$ to $-80$ mV for GABA$_\text{A}$ receptors. The membrane equation becomes

$$C\frac{dV}{dt} = -g_L(V - E_L) - g_e(t)(V - E_e) - g_i(t)(V - E_i).$$

With constant conductances the steady state is a weighted average, as in week 2:

$$V_\infty = \frac{g_L E_L + g_e E_e + g_i E_i}{g_L + g_e + g_i}.$$

Two consequences follow. First, the driving force $V - E_e$ shrinks as the cell depolarizes, so **summation of conductance inputs is sublinear**: with $g_L = 10$ nS, $C = 200$ pF, $E_L = -70$ mV, $E_e = 0$ mV and an alpha-function conductance with a peak of 0.5 nS per synapse (time constant 2 ms), one synapse gives a 0.69 mV peak, 10 give 6.5 mV (not 6.9) and 20 give 12.3 mV (not 13.7). Second, **shunting inhibition**: a GABA$_\text{A}$ synapse with $E_i$ equal to the resting potential causes no hyperpolarization, but it adds conductance and so lowers the depolarization that excitation can produce. With $g_L = 10$ nS and $g_e = 2$ nS, a resting-level inhibitory conductance $g_i = 10$ nS reduces the steady depolarization from $11.7$ mV to $6.4$ mV. Whether inhibition at a given reversal potential hyperpolarizes, shunts or even depolarizes depends on $E_\text{inh}$ relative to the resting potential (week 11 returns to chloride regulation).

### In code

```python
import math


def epsp_shape(t, tau_m, tau_s):
    """EPSP waveform normalized to a peak of 1 (t in ms); zero for t <= 0."""
    if t <= 0:
        return 0.0
    t_peak = tau_m * tau_s / (tau_m - tau_s) * math.log(tau_m / tau_s)
    peak = math.exp(-t_peak / tau_m) - math.exp(-t_peak / tau_s)
    return (math.exp(-t / tau_m) - math.exp(-t / tau_s)) / peak

print(round(epsp_shape(5.1169, 20.0, 2.0), 3), round(epsp_shape(10.0, 20.0, 2.0), 3))
```

This prints `1.0 0.861`: the EPSP is at its peak at 5.12 ms and has fallen to 86% of it at 10 ms.

title: Peak of an EPSP
problem: A synapse injects a current $I_0 = 40$ pA with $\tau_s = 3$ ms into a membrane with $R = 150$ MΩ and $\tau_m = 15$ ms. Find the time and amplitude of the EPSP peak.
step: The time of the peak is $t_\text{peak} = \frac{15 \times 3}{12}\ln 5 = 3.75 \times 1.609 = 6.04$ ms.
step: The prefactor is $R I_0 = 150 \times 40/1000 = 6$ mV, times $\tau_s/(\tau_m - \tau_s) = 3/12 = 0.25$, which is 1.5 mV.
step: The bracket at the peak is $e^{-6.04/15} - e^{-6.04/3} = 0.6687 - 0.1339 = 0.5348$.
step: The peak amplitude is $1.5 \times 0.5348 = 0.80$ mV.
answer: Peak at $6.04$ ms with an amplitude of $0.80$ mV.

@example
title: Shunting
problem: A cell has $g_L = 10$ nS and $E_L = -70$ mV. Excitation adds $g_e = 2$ nS ($E_e = 0$). Compare the steady voltage with and without an inhibitory conductance $g_i = 10$ nS at $E_i = -70$ mV.
step: Without inhibition: $V_\infty = (10 \times (-70) + 2 \times 0)/12 = -58.33$ mV, a depolarization of $11.67$ mV.
step: With inhibition the total conductance is $22$ nS: $V_\infty = (-700 + 0 - 700)/22 = -63.64$ mV.
step: The depolarization is now $6.36$ mV, little more than half.
step: Inhibition at $E_i = E_L$ did not hyperpolarize the cell; it divided the effect of excitation by increasing the conductance.
answer: $-58.33$ mV without and $-63.64$ mV with inhibition.

@mistakes
- Treating the EPSP as the synaptic current: the current lasts a few milliseconds but the EPSP lasts tens of milliseconds, set by $\tau_m$.
- Adding conductance-based EPSPs linearly: as the voltage approaches $E_e$ the driving force shrinks, so the sum is below the linear prediction.
- Saying inhibition must hyperpolarize: inhibition at $E_i$ equal to rest has no voltage effect on its own and works by shunting.
- Using $E_\text{exc} = -70$ mV: the reversal potential of cation-permeable glutamate receptors is about 0 mV.

```python
import math


def summed_response(times, spike_times, amp, tau_m, tau_s):
    """Linear sum of normalized double-exponential EPSPs."""
    t_peak = tau_m * tau_s / (tau_m - tau_s) * math.log(tau_m / tau_s)
    peak = math.exp(-t_peak / tau_m) - math.exp(-t_peak / tau_s)
    out = []
    for t in times:
        total = 0.0
        for s in spike_times:
            dt = t - s
            if dt > 0:
                total += amp * (math.exp(-dt / tau_m) - math.exp(-dt / tau_s)) / peak
        out.append(total)
    return out
```
hint: For each time, add the EPSP of every input that has already arrived (strictly earlier than the time), scaled so that its peak is `amp`.
solution: The membrane is linear, so the response is a sum of shifted copies of one waveform. Inputs that have not yet arrived contribute exactly zero, including an input arriving at the same instant ($dt = 0$ gives a shape of zero anyway).

model:
```python
import math


def peak_depolarization(g_max, n_syn):
    """Peak EPSP (mV) of n identical synchronous conductance synapses."""
    g_leak, cap, e_leak, e_exc = 10.0, 200.0, -70.0, 0.0
    dt, tau_s = 0.1, 2.0
    V = e_leak
    peak = 0.0
    for k in range(400):
        t = dt * k
        g = n_syn * g_max * (t / tau_s) * math.exp(1.0 - t / tau_s)
        V += dt * (-g_leak * (V - e_leak) - g * (V - e_exc)) / cap
        peak = max(peak, V - e_leak)
    return peak
```
hint: Compute the total synaptic conductance at time $t$, then take one Euler step with both the leak and synaptic terms; keep the largest $V - E_L$ after each step.
solution: The synaptic term $-g(V - E_e)$ shrinks as $V$ rises toward $E_e$, so ten synapses give less than ten times the response of one (the fourth test). For tiny conductances the driving force hardly changes and the response is linear (the fifth test). With $g_\text{max} = 0$ the voltage never leaves rest.

```python
import math


def temporal_summation_peak(delta, tau_m, tau_s):
    """Peak of two summed normalized EPSPs separated by delta ms."""
    t_peak = tau_m * tau_s / (tau_m - tau_s) * math.log(tau_m / tau_s)
    peak = math.exp(-t_peak / tau_m) - math.exp(-t_peak / tau_s)

    def shape(t):
        if t <= 0:
            return 0.0
        return (math.exp(-t / tau_m) - math.exp(-t / tau_s)) / peak

    return max(shape(0.1 * k) + shape(0.1 * k - delta) for k in range(601))
```
hint: Write a helper for the single-EPSP shape that returns 0 for non-positive times, then scan the grid and keep the maximum of the sum.
solution: The peak of the sum falls from 2 at zero interval to 1 for widely separated inputs; the decrease with delta shows the width of the integration window, which is about $\tau_m$. The monotone decline is the last test.

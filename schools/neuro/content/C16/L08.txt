@article
You can recognize a friend's face in a crowd, in shadow, from the side, at one-tenth the distance, and in a photograph with half the pixels gone. Yet every one of those views produces a very different pattern on the retina. Recognition is the problem of ignoring huge changes in the image (position, size, viewpoint, lighting) while staying sensitive to small differences that matter (this face and not that one). This is the **selectivity–invariance problem**.

### Two streams

Beyond V1, visual cortex divides into two broad pathways. The **ventral stream** runs from V1 through V2 and V4 to **inferotemporal cortex** (IT) in the temporal lobe and is central to recognizing objects, faces and scenes. The **dorsal stream** runs to parietal cortex and supports spatial vision and the guidance of action. Ungerleider and Mishkin (1982) contrasted "what" and "where" pathways from lesions in monkeys; Goodale and Milner (1992) argued, from patient studies, that the dorsal stream is better described as vision for action than as vision for location. Both pathways interact, and the division is a simplification. Along the ventral stream, receptive fields get larger, and neurons respond to more complex features and are more tolerant of position and size.

### Faces, places and bodies

Neurons in macaque IT that respond more to faces than to other objects have been known since the 1970s, and fMRI-guided recordings (Tsao and colleagues, 2006) located patches of the temporal lobe where most cells prefer faces. In humans, fMRI found a region in the fusiform gyrus that responds more to faces than to objects, the **fusiform face area** (Kanwisher, McDermott and Chun, 1997), and a region in parahippocampal cortex that responds to scenes, the **parahippocampal place area** (Epstein and Kanwisher, 1998). Damage to the occipitotemporal cortex can cause **prosopagnosia**, a severe difficulty recognizing faces, sometimes with spared object recognition, while other patients show the reverse; developmental forms also exist. Whether these regions are specialized for faces or places, or reflect expertise with finely discriminated categories, is debated, and distributed patterns of activity (Haxby and colleagues, 2001) carry category information outside these regions too.

### Template matching and max pooling

A simple way to get both selectivity and invariance is a two-stage hierarchy, as in the HMAX model of Riesenhuber and Poggio (1999) and in deep convolutional networks. Stage one is **template matching**: a unit compares a stored template with the input at every position, giving a score per position. Stage two is **max pooling**: a unit takes the maximum of those scores. The maximum is large wherever the template matches best, so it does not depend on where the object is, within the pooled range. The cost is that exact position information is thrown away at that stage. Stacking such stages builds features of increasing complexity and tolerance. Deep networks trained on object categories (Yamins and colleagues, 2014) predict IT responses better than earlier models, though what this shows about the brain's own learning is debated.

### Face space and decoding

One account describes faces as points in a **face space**, with the average face at the origin and each face a vector of deviations; identity is then a direction and distinctiveness a distance from the average. Another way to ask what a brain area represents is to **decode** it: train a classifier on responses to some stimuli and test it on held-out stimuli. A **nearest-class-mean** classifier assigns a new response to the class whose average response is closest in Euclidean distance $\sqrt{\sum_i (x_i - m_i)^2}$. Accuracy above chance (one over the number of classes) shows that the area carries information, though not that the brain uses it. To avoid testing on the training data, use **leave-one-out cross-validation**: hold out each sample in turn, build the class means from the rest, and classify the held-out sample.

### In code

Signals are lists of numbers at consecutive positions.

```python
def template_scores(signal, template):
    """Match score (sum of products) at every position."""
    k = len(template)
    return [sum(s * t for s, t in zip(signal[i:i + k], template))
            for i in range(len(signal) - k + 1)]


def invariant_response(signal, template):
    """Max pooling over positions."""
    return max(template_scores(signal, template))


tmpl = [1, 2, 1]
obj_a = [0, 0, 1, 2, 1, 0, 0, 0]
obj_a_shifted = [0, 1, 2, 1, 0, 0, 0, 0]
obj_b = [0, 1, 1, 1, 1, 0, 0, 0]
print([invariant_response(s, tmpl) for s in (obj_a, obj_a_shifted, obj_b)])
```

This prints `[6, 6, 4]`: the shifted copy of object A gives the same pooled response (6), but a different object (B) gives less (4). The unpooled scores, `[1, 4, 6, 4, 1, 0]` and `[4, 6, 4, 1, 0, 0]`, show where the match occurred, which pooling discards. In practice researchers use libraries (for example PyTorch) for deep networks, but the operations are these.
@example
title: Nearest-class-mean classification
problem: Two object classes have mean response vectors $\mathbf{m}_A = (1, 2)$ and $\mathbf{m}_B = (4, 6)$ in two features. Which class does a new response $\mathbf{x} = (3, 3)$ belong to?
step: Distance to $A$: $\sqrt{(3-1)^2 + (3-2)^2} = \sqrt{4 + 1} = 2.236$.
step: Distance to $B$: $\sqrt{(3-4)^2 + (3-6)^2} = \sqrt{1 + 9} = 3.162$.
step: The smaller distance wins, so the response is assigned to class $A$.
answer: Class $A$ (distances $2.24$ and $3.16$).
@example
title: Position tolerance from max pooling
problem: The template $[1, -1]$ detects a falling edge (a drop from one position to the next). Compute the template scores for the signal $[0, 3, 1, 4, 0, 2, 5]$ and the max-pooled response.
step: The scores are sums of products over each pair of neighbors, $x_i - x_{i+1}$: $0-3$, $3-1$, $1-4$, $4-0$, $0-2$, $2-5$.
step: That gives the list $[-3, 2, -3, 4, -2, -3]$.
step: Max pooling takes the largest score, $4$, at the position of the drop from 4 to 0.
step: Shifting the whole signal would move the 4 to another position but leave the pooled response unchanged.
answer: Scores $[-3, 2, -3, 4, -2, -3]$ and a pooled response of $4$.
@mistakes
- Calling max pooling "averaging over positions": it keeps only the best match, which gives invariance to position but also discards where the match occurred.
- Concluding from a decoder's above-chance accuracy that the brain uses that information, or that the area is "the" area for a category: decoding shows information is present, not that it is read out.
- Computing cross-validated accuracy with class means that include the held-out sample, which leaks the answer into the classifier and inflates accuracy.

```python
import math


def classify_nearest_mean(x, means):
    """Label of the class mean nearest to x; ties go to the earlier label."""
    best_label, best_dist = None, None
    for label in sorted(means):
        d = math.sqrt(sum((a - b) ** 2 for a, b in zip(x, means[label])))
        if best_dist is None or d < best_dist - 1e-12:
            best_label, best_dist = label, d
    return best_label
```
hint: Loop over the labels in sorted order and keep the closest one, replacing it only when the new distance is smaller by more than the tolerance.
solution: Looping through `sorted(means)` and replacing the best only on a strictly smaller distance (beyond the tolerance) makes alphabetical order the tie-breaker. The third and fourth tests are exact ties, which dictionary order alone would resolve arbitrarily.

```python
def winner_take_all(image, rfs):
    """Label of the receptive field with the largest rectified response."""
    best_label, best = None, 0.0
    for label in sorted(rfs):
        rf = rfs[label]
        u = sum(w * x for rw, rx in zip(rf, image) for w, x in zip(rw, rx))
        r = max(0.0, float(u))
        if r > best:
            best_label, best = label, r
    return best_label
```
hint: Start with a best response of 0 and replace it only when a strictly larger response appears; looping over sorted labels handles ties.
solution: Each cell computes a rectified linear response, as in the previous week's simple-cell model. Starting the best value at zero and requiring a strictly larger response means that a stimulus that drives no cell returns `None`, and sorted order resolves ties alphabetically. The uniform patch and the bar at the left edge produce non-positive sums, so no cell wins.

```python
import math


def leave_one_out_accuracy(X, y):
    """Fraction correct for a nearest-mean classifier, leaving one out."""
    correct = 0
    for i in range(len(X)):
        means = {}
        for label in sorted(set(y)):
            pts = [X[j] for j in range(len(X)) if j != i and y[j] == label]
            means[label] = [sum(col) / len(pts) for col in zip(*pts)]
        best_label, best_dist = None, None
        for label in sorted(means):
            d = math.sqrt(sum((a - b) ** 2 for a, b in zip(X[i], means[label])))
            if best_dist is None or d < best_dist - 1e-12:
                best_label, best_dist = label, d
        if best_label == y[i]:
            correct += 1
    return correct / len(X)
```
hint: For each held-out index, build the class means from the samples whose index differs, then classify that sample.
solution: Excluding the held-out sample when computing the means avoids testing on training data. In the second test the point at (4.5, 4.5) belongs to class `a` but lies closer to the mean of class `b` once it is left out, so one of the six is misclassified.

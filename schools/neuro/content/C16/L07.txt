@article
In 1959 David Hubel and Torsten Wiesel were recording from a neuron in a cat's visual cortex while projecting dots of light onto a screen. The cell stayed silent for every dot, until the edge of a glass slide moved across the screen and the neuron fired. It did not care about spots; it wanted an edge at a particular orientation. This finding (Hubel and Wiesel, 1959 and 1962) changed our view of vision: after the retina's contrast detectors comes a stage that detects oriented structure.

### The pathway to cortex

Retinal ganglion cell axons end in the **lateral geniculate nucleus** (LGN) of the thalamus, whose cells have center-surround receptive fields much like ganglion cells. The LGN projects to **primary visual cortex** (V1, striate cortex) in the occipital lobe. V1 is **retinotopic**: neighboring points on the retina map to neighboring points in cortex. The map is distorted by **cortical magnification**: the fovea claims a disproportionately large share of cortex, so the cortical distance per degree of visual angle is large at the center and shrinks with eccentricity, roughly as $M \propto 1/(E + E_2)$ for eccentricity $E$ and a constant $E_2$ of a degree or two.

### Simple and complex cells

Hubel and Wiesel described two main types. A **simple cell** has an elongated receptive field with parallel **ON** and **OFF** subregions; it responds best to a bar or edge of a preferred orientation at a particular position, and its response to a stimulus can largely be predicted by adding up the light in the ON regions and subtracting the light in the OFF regions. A **complex cell** also prefers an orientation, but it responds to the stimulus anywhere within its receptive field and with either polarity, with no separate ON and OFF subregions. Some cells are **end-stopped**: they respond less when the bar extends beyond a certain length.

Cortex is organized in columns. Cells stacked perpendicular to the surface share a preferred orientation, and the preferred orientation shifts steadily across the surface, forming orientation columns (Mountcastle's cortical-column idea, 1957, applied here by Hubel and Wiesel). **Ocular dominance columns** alternate between cells driven more by one eye and by the other.

### The linear–nonlinear model

A simple cell is modeled by two steps. First, a **linear filter** multiplies each image pixel $x_{ij}$ by a weight $w_{ij}$ (positive in ON regions, negative in OFF regions) and adds: $u = \sum_{ij} w_{ij} x_{ij}$. Second, a **rectifying nonlinearity** turns the result into a firing rate that cannot be negative: $r = \max(0, u)$. Filters are well described by a **Gabor function**, a sinusoid under a Gaussian envelope: $g(x) = e^{-x^2/(2\sigma^2)}\cos(2\pi f x + \phi)$, with spatial frequency $f$, phase $\phi$ and width $\sigma$.

A complex cell is modeled by the **energy model**: take two filters in **quadrature**, a pair with the same shape but a quarter-cycle phase difference (an even-symmetric bar detector and an odd-symmetric edge detector), square each output and add: $r = u_{\text{even}}^2 + u_{\text{odd}}^2$. If a grating shifts in phase, the two outputs trade off as $\cos\phi$ and $\sin\phi$ and the sum stays constant, so the response is phase invariant, a position tolerance built from simple-cell-like parts.

### Where selectivity comes from, and limits

Hubel and Wiesel proposed that orientation selectivity arises because a cortical cell collects input from LGN cells whose center-surround fields line up along a line. Evidence supports this feedforward alignment, but cortical circuits, including recurrent excitation and inhibition and normalization across cells, also shape tuning, and how much each contributes is debated. The linear–nonlinear model predicts responses to simple stimuli well but less well to natural images, where contrast normalization and other nonlinearities matter.

### In code

An image is a list of rows of numbers (brightness, 0 to 1) and so is a receptive field.

```python
def linear_response(image, rf):
    """Weighted sum of the pixels (row by row)."""
    return sum(w * x for rw, rx in zip(rf, image) for w, x in zip(rw, rx))


def simple_cell(image, rf):
    """Rectified linear response: never below zero."""
    return max(0.0, float(linear_response(image, rf)))


rf = [[-1, 2, -1]] * 3
vertical = [[0, 1, 0]] * 3
horizontal = [[0, 0, 0], [1, 1, 1], [0, 0, 0]]
print(simple_cell(vertical, rf), simple_cell(horizontal, rf))
```

This prints `6.0 0.0`. The filter has an ON column flanked by OFF columns, so a vertical bar in the center drives it at 6 units, while a horizontal bar puts one ON pixel and two OFF pixels in each row it covers: the sum is zero. This is orientation selectivity from nothing but the layout of the weights. A bar shifted to the left edge gives a negative sum of $-3$, which is rectified to zero: the cell responds to position as well as orientation, as a simple cell should.
@example
title: A simple cell on an image patch
problem: A simple cell has the 3 by 3 filter with rows [1, 0, -1], [2, 0, -2], [1, 0, -1] (an edge detector). Compute its linear and rectified response to the patch with rows [5, 5, 1], [5, 5, 1], [5, 5, 1], and to the same patch flipped left to right.
step: Multiply row by row: row 1 gives $1\times5 + 0\times5 - 1\times1 = 4$; row 2 gives $2\times5 - 2\times1 = 8$; row 3 gives $4$.
step: Add: $u = 4 + 8 + 4 = 16$, and the rectified response is $\max(0, 16) = 16$.
step: The flipped patch has rows [1, 5, 5], so each row gives the opposite sign: $u = -16$ and the rectified response is $0$.
answer: $16$ for the patch and $0$ for its mirror image: the cell prefers a bright-to-dark edge in one direction.
@example
title: The energy model is phase invariant
problem: A quadrature pair responds to a grating with outputs $u_{\text{even}} = 4\cos\phi$ and $u_{\text{odd}} = 4\sin\phi$, where $\phi$ is the grating phase. Compare a simple cell using only the even filter with the energy model at $\phi = 0°$, $45°$ and $90°$.
step: The simple cell's rectified output is $\max(0, 4\cos\phi)$: $4$, then $2.83$, then $0$.
step: The energy is $u_{\text{even}}^2 + u_{\text{odd}}^2 = 16\cos^2\phi + 16\sin^2\phi$.
step: Because $\cos^2\phi + \sin^2\phi = 1$, the energy is $16$ at every phase.
answer: The simple cell's response falls from 4 to 0 as the phase moves, while the energy model gives a constant $16$.
@mistakes
- Treating a simple cell as a detector of bright bars only: its ON and OFF subregions mean it also needs the surrounding region dark, and a bar at the wrong position cancels.
- Forgetting the rectification: a linear sum can be negative, but a firing rate cannot, so the model output is $\max(0, u)$.
- Confusing receptive-field structure with where the information comes from: orientation columns are about how preferred orientation varies across the cortical surface, not about the cell's position in the visual field.

model:
```python
import math


def bar_image(n, angle_deg, width):
    """n by n image with a bar through the center at the given angle."""
    c = (n - 1) / 2
    t = math.radians(angle_deg)
    image = []
    for r in range(n):
        row = []
        for col in range(n):
            x, y = col - c, c - r
            d = abs(-x * math.sin(t) + y * math.cos(t))
            row.append(1.0 if d <= width / 2 + 1e-9 else 0.0)
        image.append(row)
    return image
```
hint: Loop over rows and columns, convert to centered coordinates with y pointing up, then compare the distance from the line with half the width.
solution: The distance of a point $(x, y)$ from a line through the origin with direction $(\cos t, \sin t)$ is $|-x\sin t + y\cos t|$. Taking $y = c - r$ makes the picture's top row the positive $y$ direction, so 45° gives the diagonal that rises to the right. The slack guards against floating-point error in $\cos 90°$.

model:
```python
def energy_response(image, rf_even, rf_odd):
    """Sum of squared outputs of a quadrature pair of linear filters."""
    def dot(rf):
        return sum(w * x for rw, rx in zip(rf, image) for w, x in zip(rw, rx))

    return dot(rf_even) ** 2 + dot(rf_odd) ** 2
```
hint: Write a small helper that computes the weighted sum for one filter, call it twice, square, and add.
solution: Each filter gives a signed output, which is squared so that polarity does not matter, and the two squares are added. The negated image gives the same energy as the original, the polarity invariance of complex cells, and a blank image gives zero. In the last test the even output is $0$ and the odd output is $1$, so the energy is $1$.

model:
```python
def orientation_selectivity(responses):
    """(preferred - orthogonal) / (preferred + orthogonal)."""
    n = len(responses)
    p = max(range(n), key=lambda i: responses[i])
    pref = responses[p]
    orth = responses[(p + n // 2) % n]
    if pref + orth == 0:
        return 0.0
    return (pref - orth) / (pref + orth)
```
hint: Find the index of the largest response, then look half the list around for the orthogonal one.
solution: Orientations are evenly spaced over 180°, so the orthogonal orientation is half the list away (wrapping around). The index runs from 0 for a cell with equal responses to preferred and orthogonal bars to 1 for a cell silent at the orthogonal orientation. `max` with a key returns the first index in a tie, as the third test needs.

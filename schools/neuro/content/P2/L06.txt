@article
A perturbation experiment looks simple: change the circuit and watch the behavior. But the claim "this circuit is responsible" survives only if the alternatives are excluded, and each alternative corresponds to a control. This lesson turns that list into a design.

### The estimand

Call the behavioral measure $Y$ (accuracy, a lick rate, a reaction time). The effect of a perturbation on one trial is the difference between what would happen with and without it, and we can never observe both on the same trial. We estimate the average effect by comparing trials that differ in perturbation and are otherwise exchangeable. This is why **randomization** matters: interleave perturbation and control trials at random within a session, so slow drifts in motivation and arousal affect both equally.

For stimulated trials with mean $\bar y_s$ and variance $s_s^2$ over $n_s$ trials, and control trials with $\bar y_c$, $s_c^2$ and $n_c$, the estimated effect and its standard error are

$$\hat\delta = \bar y_s - \bar y_c, \qquad \text{SE} = \sqrt{\frac{s_s^2}{n_s} + \frac{s_c^2}{n_c}},$$

with sample variances using $n-1$ in the denominator. In a **within-animal design**, each animal contributes both conditions; the paired differences $d_i = \bar y_{s,i} - \bar y_{c,i}$ have mean $\bar d$ and standard error $s_d/\sqrt{N}$, with $N$ animals. Pairing removes between-animal variability, often a large part of the noise.

### The unit of replication

Hundreds of trials from three animals do not give $N = 300$. Trials within an animal share its anatomy, expression and state, so the effective sample size for a claim about the species is closer to the number of animals. Honest analyses summarize each animal first (as above) or use a hierarchical model with animals as a random effect.

### Compensation and off-target effects

**Compensation** means other parts of the system change to restore function, hiding the contribution of the perturbed circuit. It is more likely after chronic perturbations, such as lesions and constitutive manipulations, and less likely after brief acute ones, but acute manipulations bring **off-target** effects: silencing a population can disturb downstream circuits it does not normally drive, as in the songbird study of Otchy and colleagues (2015) in lesson 5. A conclusion should therefore say "this manipulation has this effect," and a claim about normal function needs convergent evidence from several manipulations with different weaknesses.

### Controls, matched to alternatives

| alternative explanation | control |
|---|---|
| light heats tissue or is seen by the animal | light delivered to animals without the opsin, or to a control site; masking light |
| ligand acts on its own | the same ligand in non-expressing animals |
| drift in motivation, state | randomized, interleaved perturbation and control trials; blinding |
| the manipulation did not work | record during the manipulation; histology of expression and placement |
| effect is nonspecific, such as a motor deficit | tests of other behaviors, and epoch-specific perturbation |
| effect depends on a single parameter setting | dose or power series; a second site or manipulation |
| effect is due to one animal | analysis with animals as the unit; report each animal |

A **rescue** experiment, in which a second manipulation restores the behavior, and a **dose-response** relation both strengthen a causal claim.

### Power and sample size

Underpowered experiments miss real effects and exaggerate those they detect (Button and colleagues, 2013). For a two-group comparison with two-sided significance level $\alpha$, power $1-\beta$, true effect $\delta$ and standard deviation $\sigma$, the number needed per group is approximately

$$n = \frac{2\,(z_{1-\alpha/2} + z_{1-\beta})^2\,\sigma^2}{\delta^2},$$

with $z_{0.975} \approx 1.96$ for $\alpha = 0.05$ and $z_{0.80} \approx 0.84$ for power $0.80$. The calculation needs a plausible $\sigma$ and the smallest effect that would matter; both come from pilot data or earlier work, never from the data you are about to collect. The number is rounded up.

### Open questions

How to combine the results of different perturbations that disagree, and how far results from acute manipulations in one preparation extend to the same circuit in a natural condition, are unresolved. The best practice is to preregister the analysis, verify the manipulation, report all animals and state what each outcome would mean before collecting data.

@example
title: Effect and standard error
problem: In four animals' sessions, a behavioral measure (in licks per second) on stimulated trials is $[3, 5, 4, 6]$ and on control trials is $[7, 8, 6, 7]$, treating each value as a trial summary. Estimate the effect of the perturbation and its standard error (unpaired).
step: Means: $\bar y_s = 18/4 = 4.5$ and $\bar y_c = 28/4 = 7.0$, so $\hat\delta = 4.5 - 7.0 = -2.5$.
step: Variances with $n - 1$: the stimulated deviations are $-1.5, 0.5, -0.5, 1.5$ with sum of squares $5$, so $s_s^2 = 5/3 \approx 1.667$. The control deviations are $0, 1, -1, 0$ with sum of squares $2$, so $s_c^2 = 2/3 \approx 0.667$.
step: Standard error: $\sqrt{1.667/4 + 0.667/4} = \sqrt{0.583} \approx 0.764$.
step: The effect is about $-2.5$ licks per second, about $3.3$ standard errors from zero, so the perturbation lowered the behavior. Whether the circuit is responsible still depends on the controls in the table.
answer: $\hat\delta = -2.5$ licks per second, with standard error about $0.76$.

@mistakes
- Using trials as the unit of replication when the claim concerns animals.
- Using the standard deviation of the data collected to compute the sample size for the same experiment, which makes the estimate circular.
- Rounding a sample size down rather than up, which reduces the power below the target.
- Reading a null result with a small sample as evidence of no effect.

model:
```python
import math


def _mean(x):
    return sum(x) / len(x)


def _var(x):
    m = _mean(x)
    return sum((v - m) ** 2 for v in x) / (len(x) - 1)


def effect_and_se(stim, ctrl):
    """Difference of means and the unpaired standard error."""
    effect = _mean(stim) - _mean(ctrl)
    se = math.sqrt(_var(stim) / len(stim) + _var(ctrl) / len(ctrl))
    return effect, se
```
hint: Write a small helper for the sample variance with `n - 1`, then combine the two variances divided by their own sample sizes.
solution: The standard error adds the variances of the two means, each variance divided by its group's size. In the first test the variances are 2 and 8, so the standard error is $\sqrt{2/2 + 8/2} = \sqrt{5}$. A version dividing by `n` gives smaller variances and fails.

model:
```python
import math


def paired_effect(stim, ctrl):
    """Mean of paired differences and its standard error."""
    d = [a - b for a, b in zip(stim, ctrl)]
    n = len(d)
    mean_d = sum(d) / n
    var = sum((x - mean_d) ** 2 for x in d) / (n - 1)
    return mean_d, math.sqrt(var / n)
```
hint: Form the per-animal differences first, then compute their mean and sample standard deviation.
solution: Pairing works on the differences, so between-animal variability in baseline drops out. The third test has identical differences, which gives zero standard error, and a version that computes the unpaired standard error from the two lists would not.

@article
A circuit experiment is only as interpretable as the behavior it is paired with. A drop in accuracy after silencing a region could mean the animal no longer sees the stimulus, no longer remembers it, no longer wants the reward, or cannot move its tongue. The behavioral paradigm decides which of these the experiment can distinguish.

### Paradigms

Most systems experiments use **trial-based tasks** with a stimulus, a delay or a decision period, a report and an outcome. Common forms: **detection** (was a stimulus present?), **discrimination** (which of two stimuli?), **go/no-go** (respond to one stimulus, withhold to another), **two-alternative forced choice** (report by one of two actions) and **delayed match or non-match** tasks that require memory. Animals are usually trained by reward, which makes motivation part of the measurement. **Naturalistic and ethological** behavior (foraging, navigation, social interaction) has the advantage of engaging circuits as evolution shaped them, and the disadvantage of weaker experimental control.

### Sensitivity and bias

In signal detection theory (Green and Swets, 1966), responses depend on two quantities: **sensitivity** $d'$, how well signal is separated from noise, and the **criterion** $c$, how much evidence the observer requires to respond "yes." With hit rate $H$ and false-alarm rate $F$, and $z(\cdot)$ the inverse of the standard normal cumulative distribution,

$$d' = z(H) - z(F), \qquad c = -\tfrac12\big[z(H) + z(F)\big].$$

For $H = 0.90$ ($z = 1.28$) and $F = 0.20$ ($z = -0.84$), $d' = 2.12$ and $c = -0.22$, a slightly liberal criterion. A perturbation that lowers both hits and false alarms can leave $d'$ almost unchanged and shift $c$: the animal is more conservative, not less able. Accuracy alone cannot tell these apart, so detection experiments should report hits and false alarms separately.

### The psychometric function

A **psychometric function** plots the proportion of one report against stimulus strength. Two features matter: the **threshold** (the stimulus strength at which the animal is at a criterion level, such as 50% for a bias-free choice) and the **slope**, which measures sensitivity. A perturbation that shifts the curve sideways changes **bias**; one that flattens it changes sensitivity; one that moves the asymptotes changes the **lapse** rate, responses unrelated to the stimulus (inattention, motor errors). These are three distinct claims about a circuit, and a single accuracy number mixes them.

### Why behavioral claims are ambiguous

| confound | alternative explanation | control |
|---|---|---|
| motivation or arousal | the animal works less because it wants the reward less | measure lapse rate and licking or engagement; satiety control |
| motor deficit | the animal cannot execute the report | test an unrelated response and movement kinematics |
| sensory change | the stimulus is not perceived | change the sensory modality of the report, or test detection thresholds |
| strategy | the animal solves the task by an alternative cue or by history (repeating the last choice) | model the choice with previous choices and outcomes; vary the stimulus statistics |
| training history | the animals differ in how they learned | counterbalance, and report training time |

### Generality and reproducibility

A task is a model of a cognitive process, and the match is an argument, not a fact: success on a two-choice task does not show that the animal "perceives" or "decides" in the way the experimenter's label implies. Performance depends on strain, sex, age, housing, handling and the apparatus, and low-powered behavioral studies add noise (Button and colleagues, 2013). Reporting all animals, the exclusion rules and the training procedure allows replication.

### Open questions

Whether richly measured natural behavior, analyzed with pose tracking and models, should replace constrained trial-based tasks, or complement them, is debated. Constrained tasks allow clean inference about a variable; natural behavior may reveal strategies that tasks suppress.

title: Sensitivity or bias?
problem: In a detection task, $H = 0.90$ and $F = 0.20$ before a manipulation, and $H = 0.70$ and $F = 0.05$ after it. Use $z(0.90) = 1.28$, $z(0.20) = -0.84$, $z(0.70) = 0.52$, $z(0.05) = -1.64$. Which changed, sensitivity or criterion?
step: Before: $d' = 1.28 - (-0.84) = 2.12$ and $c = -\tfrac12(1.28 - 0.84) = -0.22$.
step: After: $d' = 0.52 - (-1.64) = 2.16$ and $c = -\tfrac12(0.52 - 1.64) = 0.56$.
step: Compare: $d'$ is essentially unchanged ($2.12$ versus $2.16$) while $c$ moved from $-0.22$ to $0.56$.
step: Interpret: both the hit rate and the false-alarm rate fell, and the pattern is a shift to a more conservative criterion. The accuracy alone would have shown a drop in hits and misled a reader into concluding a loss of sensitivity.
answer: The criterion changed ($c$ from $-0.22$ to $0.56$); sensitivity was unchanged ($d' \approx 2.1$).

@mistakes
- Reporting only percent correct in a detection task, which mixes sensitivity and bias.
- Reading a drop in performance as a loss of perception without checking lapse rate, motor ability and motivation.
- Assuming the animal solves the task the way the experimenter designed it.
- Computing $d'$ from hit or false-alarm rates of exactly 0 or 1, which gives infinite $z$; a correction is required.

If a point has `p[i] == 0.5`, return `xs[i]`. If `p` never reaches 0.5 or the first value is already above 0.5, return `None`. For example, `threshold_50([-2, -1, 0, 1, 2], [0.05, 0.2, 0.4, 0.7, 0.95])` returns about `0.3333`.

tests:
```python
assert abs(threshold_50([-2, -1, 0, 1, 2], [0.05, 0.2, 0.4, 0.7, 0.95]) - 1 / 3) < 1e-9
assert threshold_50([0, 1, 2], [0.2, 0.5, 0.8]) == 1

```
model:
```python
def threshold_50(xs, p):
    """Stimulus strength where the proportion first reaches 0.5."""
    for i in range(len(p)):
        if p[i] == 0.5:
            return xs[i]
        if i + 1 < len(p) and p[i] < 0.5 < p[i + 1]:
            frac = (0.5 - p[i]) / (p[i + 1] - p[i])
            return xs[i] + frac * (xs[i + 1] - xs[i])
    return None
```
hint: Scan the points in order; if a point equals 0.5 return it, and if 0.5 lies strictly between two neighbors interpolate between them.
solution: Linear interpolation puts the crossing at the fraction $(0.5 - p_i)/(p_{i+1} - p_i)$ of the way from $x_i$ to $x_{i+1}$. A curve that starts above 0.5 never crosses it from below in the data and gives `None`, as does a curve that stays below, which tests the edge cases.

prompt: A detection experiment silences a cortical region on a subset of trials. The control hit and false-alarm rates are $H = 0.82$ and $F = 0.18$ and during silencing they are $H = 0.60$ and $F = 0.08$. Use $z(0.82) = 0.915$, $z(0.18) = -0.915$, $z(0.60) = 0.253$ and $z(0.08) = -1.405$. solution: Control: $d' = 0.915 + 0.915 = 1.83$ and $c = 0$. Silencing: $d' = 0.253 + 1.405 = 1.66$ and $c = -\tfrac12(0.253 - 1.405) = 0.58$. Hits fell from 0.82 to 0.60, which on its own looks like impaired detection, but false alarms fell too, and $d'$ is nearly unchanged (1.83 to 1.66), while the criterion moved from neutral to conservative. The data therefore support a shift in the animal's willingness to report a stimulus, not a large loss of sensitivity. This could still reflect a role for the region in reporting or motivation, or a small loss of sensitivity that this data set cannot resolve (the difference of 0.17 in $d'$ needs a standard error). To distinguish, test lapse rate and a different report modality, and replicate across animals with an interleaved light-only control.

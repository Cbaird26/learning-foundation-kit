@article
Suppose the $n\times n$ matrix $A$ has $n$ linearly independent eigenvectors $v_1, \dots, v_n$ with eigenvalues $\lambda_1, \dots, \lambda_n$. Put the eigenvectors in the columns of $S$ and the eigenvalues on the diagonal of $\Lambda$ (capital lambda). Then $AS = S\Lambda$, and since $S$ is invertible,

$$A = S\Lambda S^{-1}.$$

We say $A$ is **diagonalizable**. The eigenvector basis makes $A$ act as simple scaling along each eigenvector.

### Which matrices are diagonalizable?

$A$ is diagonalizable exactly when it has $n$ independent eigenvectors. If $A$ has $n$ **distinct** eigenvalues, this is guaranteed (eigenvectors for different eigenvalues are independent). With repeated eigenvalues it can fail, as for $\begin{bmatrix}2&1\\0&2\end{bmatrix}$, but it can also hold: the identity has a repeated eigenvalue $1$ and is already diagonal. Invertibility and diagonalizability are different properties. Real symmetric matrices are always diagonalizable, by an orthogonal $S$.

### Powers

$A^2 = S\Lambda S^{-1}S\Lambda S^{-1} = S\Lambda^2S^{-1}$, and in general

$$A^k = S\Lambda^kS^{-1}, \qquad \Lambda^k = \operatorname{diag}(\lambda_1^k, \dots, \lambda_n^k).$$

To compute $A^ku_0$, expand $u_0 = c_1v_1 + \dots + c_nv_n$ (the coefficients are $c = S^{-1}u_0$). Then

$$A^ku_0 = c_1\lambda_1^kv_1 + \dots + c_n\lambda_n^kv_n.$$

Terms with $|\lambda_i| < 1$ die out, and terms with $|\lambda_i| > 1$ grow, so the largest $|\lambda_i|$ governs the long-run behavior.

### Markov chains

A **Markov matrix** (column-stochastic matrix) $P$ has nonnegative entries and each **column** sums to $1$. Entry $P_{ij}$ is the probability of moving from state $j$ to state $i$. If $u_k$ is the probability vector over states at step $k$ (nonnegative entries summing to $1$), then

$$u_{k+1} = Pu_k, \qquad u_k = P^ku_0.$$

(Many texts use rows that sum to $1$ and write row vectors; it is the same idea transposed. Here we use columns.) Key facts:

- Every Markov matrix has the eigenvalue $\lambda = 1$, because $\mathbf{1}^T P = \mathbf{1}^T$ shows $P^T$ has eigenvector $\mathbf{1}$ with eigenvalue $1$, and $P$ and $P^T$ have the same eigenvalues.
- Every eigenvalue satisfies $|\lambda| \le 1$.
- If all entries of $P$ are positive (more generally, if some power of $P$ is positive), then $\lambda = 1$ is the only eigenvalue of magnitude $1$ and its eigenspace is a line. Then $P^ku_0$ converges to the unique **steady state** $u_\infty$, with $Pu_\infty = u_\infty$, whatever the starting probability vector $u_0$ is. This is a case of the Perron–Frobenius theorem.

To find the steady state, solve $(P - I)u = 0$, then scale so the entries sum to $1$. The speed of convergence is set by the second-largest $|\lambda|$.

```python
def step(P, u):
    return [sum(p * x for p, x in zip(row, u)) for row in P]

P = [[0.9, 0.5], [0.1, 0.5]]
u = [1.0, 0.0]
for _ in range(20):
    u = step(P, u)
print([round(t, 4) for t in u])  # [0.8333, 0.1667]
```

@example
title: Powers of a matrix by diagonalization
problem: Use the eigenpairs of $A = \begin{bmatrix}4&1\\2&3\end{bmatrix}$ to find $A^k$.
step: From the previous lesson, $\lambda = 5$ with $v = (1, 1)$ and $\lambda = 2$ with $v = (1, -2)$. So $S = \begin{bmatrix}1&1\\1&-2\end{bmatrix}$ and $\Lambda = \begin{bmatrix}5&0\\0&2\end{bmatrix}$.
step: $\det S = -3$, so $S^{-1} = \tfrac13\begin{bmatrix}2&1\\1&-1\end{bmatrix}$.
step: $A^k = S\Lambda^kS^{-1} = \tfrac13\begin{bmatrix}1&1\\1&-2\end{bmatrix}\begin{bmatrix}5^k&0\\0&2^k\end{bmatrix}\begin{bmatrix}2&1\\1&-1\end{bmatrix}$. Multiplying out gives rows $\tfrac13[2\cdot5^k + 2^k,\ 5^k - 2^k]$ and $\tfrac13[2\cdot5^k - 2\cdot2^k,\ 5^k + 2\cdot2^k]$.
step: Check $k = 1$: the first row is $\tfrac13[12, 3] = [4, 1]$ and the second is $\tfrac13[6, 9] = [2, 3]$. This is $A$. Check $k = 0$: we get $I$.
answer: $A^k = \dfrac13\begin{bmatrix}2\cdot5^k + 2^k & 5^k - 2^k\\ 2\cdot5^k - 2\cdot2^k & 5^k + 2\cdot2^k\end{bmatrix}$

@example
title: The steady state of a two-state Markov chain
problem: A day is sunny or rainy. After a sunny day, the next day is sunny with probability $0.9$; after a rainy day, the next day is sunny with probability $0.5$. Find the long-run fraction of sunny days.
step: With states (sunny, rainy) and columns for the current state, $P = \begin{bmatrix}0.9&0.5\\0.1&0.5\end{bmatrix}$. Each column sums to $1$.
step: Solve $(P - I)u = 0$: $\begin{bmatrix}-0.1&0.5\\0.1&-0.5\end{bmatrix}u = 0$ gives $u_1 = 5u_2$.
step: Scale to sum $1$: $u_2 = 1/6$ and $u_1 = 5/6$. The steady state is $(5/6, 1/6)$.
step: The other eigenvalue is $\operatorname{tr}P - 1 = 1.4 - 1 = 0.4$, so the distance to the steady state shrinks by a factor $0.4$ each day. All entries of $P$ are positive, so the chain converges to $(5/6, 1/6)$ from any starting distribution.
answer: About $5/6 \approx 83.3\%$ of days are sunny in the long run.

@mistakes
- Putting the eigenvector columns of $S$ and the eigenvalues in $\Lambda$ in a different order. The $j$th column of $S$ must pair with the $j$th diagonal entry of $\Lambda$.
- Claiming a matrix is diagonalizable just because it is invertible, or non-diagonalizable just because it has a repeated eigenvalue. The test is whether there are $n$ independent eigenvectors.
- Using a matrix whose rows (instead of columns) sum to $1$ with the column convention $u_{k+1} = Pu_k$.
- Forgetting to rescale the eigenvector for $\lambda = 1$ so that its entries sum to $1$.

```python
def distribution_after(P, u, k):
    x = list(u)
    for _ in range(k):
        x = [sum(p * t for p, t in zip(row, x)) for row in P]
    return x
```
hint: One step is `x = [dot(row, x) for row in P]`.
hint: Repeat the step `k` times starting from a copy of `u`.
solution: Each step multiplies the current vector by `P`. Since the columns of `P` sum to $1$ and the entries of `u` sum to $1$, the entries of every later vector also sum to $1$; the test with `Fraction`s confirms this exactly.

model:
```python
def steady_state(P, iters=200):
    n = len(P)
    u = [1.0 / n] * n
    for _ in range(iters):
        u = [sum(p * t for p, t in zip(row, u)) for row in P]
    return u
```
hint: Start from the uniform distribution and apply `P` repeatedly.
hint: A positive Markov matrix converges to the steady state from any starting distribution, so 200 steps are plenty for these examples.
solution: Repeated multiplication is the power method for the eigenvalue $1$: the other eigenvalues have magnitude below $1$, so their components vanish. The fixed point satisfies $Pu = u$, which the last test verifies.

model:
```python
from fractions import Fraction

def steady_state_2x2(P):
    a = Fraction(P[1][0])
    b = Fraction(P[0][1])
    return [b / (a + b), a / (a + b)]
```
hint: The steady state satisfies $(1 - a)u_1 + bu_2 = u_1$, which reduces to $au_1 = bu_2$.
hint: Together with $u_1 + u_2 = 1$ this gives $u_1 = b/(a+b)$.
solution: From $Pu = u$ the flow out of state 0 equals the flow in: $a\,u_1 = b\,u_2$. Normalizing gives $u = (b, a)/(a + b)$. For the first test $a = 1/10$, $b = 1/2$, so $u = (5/6, 1/6)$.

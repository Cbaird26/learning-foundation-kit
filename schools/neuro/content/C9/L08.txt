@article
The **determinant** $\det A$ is a number computed from a square matrix that tells you, among other things, whether $A$ is invertible. It is uniquely determined by three properties:

1. $\det I = 1$.
2. Exchanging two rows **changes the sign** of the determinant.
3. The determinant is **linear in each row** separately: scaling one row by $c$ scales $\det$ by $c$, and $\det$ is additive when one row is a sum of two rows and the other rows stay fixed.

### Consequences

From these properties:

- A matrix with two equal rows, or a zero row, has $\det = 0$.
- Subtracting a multiple of one row from another **does not change** $\det$.
- For a triangular matrix, $\det$ is the **product of the diagonal entries**.
- $\det(AB) = \det A \det B$ and $\det A^T = \det A$, so column properties mirror row properties.
- $\det(cA) = c^n \det A$ for an $n\times n$ matrix, since every one of the $n$ rows is scaled.
- $A$ is invertible if and only if $\det A \neq 0$, and then $\det A^{-1} = 1/\det A$.

For a $2\times2$ matrix, $\det\begin{bmatrix}a&b\\c&d\end{bmatrix} = ad - bc$. Note that $\det(A + B)$ is **not** $\det A + \det B$.

### Computing by elimination

Eliminate to an upper triangular $U$ using only row replacement and swaps. Replacements do not change $\det$ and each swap flips its sign, so

$$\det A = (-1)^{s} \cdot (\text{product of the pivots}),$$

where $s$ is the number of row swaps. If a pivot position cannot be filled, $\det A = 0$. This takes about $n^3/3$ operations, so it is the practical method.

### Cofactor expansion

The **minor** $M_{ij}$ is the determinant of the matrix obtained by deleting row $i$ and column $j$, and the **cofactor** is $C_{ij} = (-1)^{i+j}M_{ij}$. Expanding along any row $i$,

$$\det A = \sum_{j=1}^{n} a_{ij}C_{ij},$$

and the same works along any column. The signs follow a checkerboard pattern starting with $+$ in the top left. Expansion is convenient by hand along a row or column with many zeros, but computing it fully takes about $n!$ terms, which is useless for large $n$.

### Geometry

For $A$ with columns $a_1, \dots, a_n$, $|\det A|$ is the volume of the parallelepiped spanned by the columns (area of the parallelogram when $n = 2$). The sign records orientation. A linear map $x \mapsto Ax$ multiplies areas (or volumes) by $|\det A|$. When $\det A = 0$, the columns lie in a lower-dimensional subspace and the volume collapses to zero.

### Cramer's rule

If $\det A \neq 0$, the solution of $Ax = b$ is $x_j = \det B_j / \det A$, where $B_j$ is $A$ with column $j$ replaced by $b$. It is a neat formula for tiny systems and for proofs, but elimination is far faster in practice.

@example
title: Cofactor expansion of a 3 by 3 determinant
problem: Compute $\det\begin{bmatrix}2&1&3\\0&4&1\\1&0&2\end{bmatrix}$.
step: Expand along the first column, which has a zero. The cofactor signs are $+, -, +$ going down.
step: Entry $2$: $+2\cdot\det\begin{bmatrix}4&1\\0&2\end{bmatrix} = 2(8 - 0) = 16$. Entry $0$ contributes nothing.
step: Entry $1$ in row 3: $+1\cdot\det\begin{bmatrix}1&3\\4&1\end{bmatrix} = 1\cdot(1 - 12) = -11$.
step: Add: $16 + 0 - 11 = 5$.
answer: $5$

@example
title: A determinant by elimination with a row swap
problem: Compute $\det\begin{bmatrix}0&2&1\\1&1&0\\2&1&3\end{bmatrix}$ by elimination.
step: The first pivot position holds $0$, so swap rows 1 and 2. That is one swap, so the sign factor is $-1$: the matrix becomes $\begin{bmatrix}1&1&0\\0&2&1\\2&1&3\end{bmatrix}$.
step: Subtract $2\times$ row 1 from row 3: $[0, -1, 3]$. The determinant is unchanged by this step.
step: Add $\tfrac12\times$ row 2 to row 3: $[0, 0, 3 + \tfrac12] = [0, 0, \tfrac72]$. The pivots are $1, 2, \tfrac72$.
step: The product of pivots is $7$, and with one swap $\det = -7$. Cofactor check along row 1: $0 - 2\cdot\det\begin{bmatrix}1&0\\2&3\end{bmatrix} + 1\cdot\det\begin{bmatrix}1&1\\2&1\end{bmatrix} = -2(3) + (1 - 2) = -7$.
answer: $-7$

@mistakes
- Forgetting the sign change from a row swap when computing the determinant by elimination.
- Using $\det(A + B) = \det A + \det B$; the determinant is linear in each row separately, not in the whole matrix.
- Writing $\det(cA) = c\det A$; for an $n \times n$ matrix it is $c^n\det A$.
- Getting the cofactor sign pattern wrong: the sign is $(-1)^{i+j}$, positive in the top left corner.

model:
```python
from fractions import Fraction

def det(A):
    M = [[Fraction(x) for x in row] for row in A]
    n = len(M)
    result = Fraction(1)
    for c in range(n):
        p = next((i for i in range(c, n) if M[i][c] != 0), None)
        if p is None:
            return Fraction(0)
        if p != c:
            M[c], M[p] = M[p], M[c]
            result = -result
        result *= M[c][c]
        for i in range(c + 1, n):
            f = M[i][c] / M[c][c]
            M[i] = [a - f * b for a, b in zip(M[i], M[c])]
    return result
```
hint: Eliminate below each pivot; the answer is the product of the pivots, with a sign flip for every row swap.
hint: If there is no nonzero entry at or below the diagonal in some column, the determinant is `0`.
solution: Keep a running `result` that starts at $1$, multiply it by each pivot, and negate it for every swap. Row replacements do not change the determinant, so after the loop `result` equals the determinant.

choice*: $\det(AB) = \det A \cdot \det B$
choice: $\det(A + B) = \det A + \det B$

@practice self
prompt: Explain, using determinant properties, why a square matrix with two equal rows is singular.
hint: What happens to the determinant when you swap the two equal rows?
solution: Swapping the two equal rows leaves the matrix unchanged, but by the swap property it changes the sign of the determinant. So $\det A = -\det A$, which gives $2\det A = 0$ and $\det A = 0$. A square matrix with determinant zero is not invertible, so $A$ is singular. (Equivalently, elimination produces a zero row, so there are fewer than $n$ pivots.)
rubric: Applies the row-swap sign rule to the two equal rows.
rubric: Concludes $\det A = -\det A$, so $\det A = 0$.
rubric: Links $\det A = 0$ to non-invertibility.

model:
```python
from fractions import Fraction

def _det(M):
    if len(M) == 1:
        return Fraction(M[0][0])
    total = Fraction(0)
    for j in range(len(M)):
        minor = [row[:j] + row[j + 1:] for row in M[1:]]
        total += (-1) ** j * M[0][j] * _det(minor)
    return total

def cramer(A, b):
    d = _det(A)
    n = len(A)
    result = []
    for j in range(n):
        B = [row[:j] + [b[i]] + row[j + 1:] for i, row in enumerate(A)]
        result.append(_det(B) / d)
    return result
```
hint: For each unknown $x_j$, replace column $j$ of `A` by `b` and take the determinant.
hint: Divide each of those determinants by $\det A$.
solution: Compute $\det A$ once. For each $j$, build $B_j$ by replacing column $j$ with `b`, and $x_j = \det B_j / \det A$. A recursive cofactor expansion along row 0 is fine for the small matrices here, but it takes $O(n!)$ time.

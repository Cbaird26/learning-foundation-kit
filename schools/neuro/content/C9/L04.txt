@article
Elimination does more than solve one system: it can be recorded as a **factorization**. Suppose elimination on $A$ needs no row exchanges. Each step subtracts a multiple $\ell_{ij}$ of row $j$ from row $i$ ($i > j$) to create a zero. The result is an upper triangular matrix $U$ (with the pivots on its diagonal).

### Why $A = LU$

Each step is multiplication on the left by an elementary matrix $E_{ij}$, so $E_{k}\cdots E_{2}E_{1}A = U$. Each $E$ is easy to undo (add the multiple back), and the inverses multiply, in order, into one lower triangular matrix:

$$A = LU, \qquad L = E_1^{-1}E_2^{-1}\cdots E_k^{-1}.$$

The remarkable fact is that the multipliers go into $L$ without interfering: $L$ is **unit lower triangular** (ones on the diagonal, zeros above) and its entry $L_{ij}$ ($i > j$) is exactly the multiplier $\ell_{ij}$ used to eliminate entry $(i, j)$. So you can fill in $L$ as you eliminate.

For example, eliminating the matrix $\begin{bmatrix}2&1\\6&8\end{bmatrix}$ uses the multiplier $6/2 = 3$ and leaves pivots $2$ and $5$:

$$\begin{bmatrix}2&1\\6&8\end{bmatrix} = \begin{bmatrix}1&0\\3&1\end{bmatrix}\begin{bmatrix}2&1\\0&5\end{bmatrix}.$$

### Solving with $L$ and $U$

To solve $Ax = b$, write $LUx = b$ and set $c = Ux$:

1. **Forward substitution**: solve $Lc = b$ from the top row down. Because $L$ has ones on its diagonal, $c_i = b_i - \sum_{j<i} L_{ij}c_j$.
2. **Back substitution**: solve $Ux = c$ from the bottom row up.

The two substitutions together cost about $n^2$ multiply-adds (about $n^2/2$ each). The factorization itself costs about $n^3/3$ multiplications. If you have many right-hand sides $b$ for the same $A$, you factor once and then each new $b$ costs only $O(n^2)$, which is much cheaper than repeating the elimination. The factorization is also how determinants and many numerical libraries work internally.

### Row exchanges: $PA = LU$

If a pivot position holds $0$, a row exchange is needed. Collect all the exchanges in a **permutation matrix** $P$ (the identity with its rows reordered). Then there is always a factorization $PA = LU$ for any invertible $A$. In floating-point practice, the row with the largest entry in the pivot column is swapped in even when no zero occurs (**partial pivoting**), because dividing by a tiny pivot amplifies rounding errors. In this lesson's code we assume the pivots are nonzero.

### Uniqueness

If $A$ is invertible and no exchanges are needed, the factorization $A = LU$ with $L$ unit lower triangular is **unique**. If you prefer the pivots as a separate diagonal matrix $D$, you can write $A = LDU'$ where both triangular factors have ones on the diagonal.

```python
from fractions import Fraction

def lu(A):
    n = len(A)
    U = [[Fraction(x) for x in row] for row in A]
    L = [[Fraction(int(i == j)) for j in range(n)] for i in range(n)]
    for j in range(n):
        for i in range(j + 1, n):
            L[i][j] = U[i][j] / U[j][j]
            U[i] = [a - L[i][j] * p for a, p in zip(U[i], U[j])]
    return L, U
```

@example
title: LU factorization of a 3 by 3 matrix
problem: Factor $A = \begin{bmatrix}1&2&1\\3&8&7\\2&7&9\end{bmatrix}$ as $LU$.
step: Eliminate column 1. The multipliers are $\ell_{21} = 3/1 = 3$ and $\ell_{31} = 2/1 = 2$. Row 2 becomes $[0, 2, 4]$ and row 3 becomes $[0, 3, 7]$.
step: The second pivot is $2$. The multiplier for row 3 is $\ell_{32} = 3/2$. Row 3 becomes $[0, 3, 7] - \tfrac32[0, 2, 4] = [0, 0, 1]$.
step: So $U = \begin{bmatrix}1&2&1\\0&2&4\\0&0&1\end{bmatrix}$ and the multipliers fill $L = \begin{bmatrix}1&0&0\\3&1&0\\2&3/2&1\end{bmatrix}$.
step: Check the $(3,3)$ entry of $LU$: $2\cdot1 + \tfrac32\cdot4 + 1\cdot1 = 2 + 6 + 1 = 9$. It matches $A_{33}$.
answer: $A = LU$ with the $L$ and $U$ above.

@example
title: Solving a system with the factors
problem: Use $A = LU$ with $L = \begin{bmatrix}1&0\\3&1\end{bmatrix}$ and $U = \begin{bmatrix}2&1\\0&5\end{bmatrix}$ to solve $Ax = b$ for $b = (4, 17)$.
step: Forward substitution on $Lc = b$: the first row gives $c_1 = 4$. The second gives $3c_1 + c_2 = 17$, so $c_2 = 17 - 12 = 5$.
step: Back substitution on $Ux = c$: the second row gives $5x_2 = 5$, so $x_2 = 1$.
step: The first row gives $2x_1 + x_2 = 4$, so $x_1 = \tfrac32$.
step: Check with $A = LU = \begin{bmatrix}2&1\\6&8\end{bmatrix}$: $2\cdot\tfrac32 + 1 = 4$ and $6\cdot\tfrac32 + 8 = 17$.
answer: $x = (3/2, 1)$

@mistakes
- Putting the multipliers into $L$ with the wrong sign. With "subtract $\ell$ times the pivot row", $L$ holds $+\ell$.
- Mixing up the roles: $L$ is lower triangular with ones on the diagonal, and $U$ is upper triangular with the pivots on its diagonal.
- Using the factorization without row exchanges when a zero pivot appears; then you need $PA = LU$.
- Solving $Ux = b$ directly instead of first solving $Lc = b$ for the intermediate vector.

model:
```python
from fractions import Fraction

def forward_sub(L, b):
    n = len(b)
    c = []
    for i in range(n):
        s = sum(L[i][j] * c[j] for j in range(i))
        c.append(Fraction(b[i] - s) / L[i][i])
    return c
```
hint: The first unknown comes from the first equation alone.
hint: Row `i` says `L[i][0]*c[0] + ... + L[i][i]*c[i] = b[i]`, and `c[0..i-1]` are already known.
solution: Go through the rows in order and compute `c[i] = (b[i] - sum of L[i][j]*c[j] for j < i) / L[i][i]`. Wrapping in `Fraction` keeps every value exact.

```python
from fractions import Fraction

def lu(A):
```

```python
    U = [[Fraction(x) for x in row] for row in A]
    L = [[Fraction(int(i == j)) for j in range(n)] for i in range(n)]

```
hint: Start with `U` as a copy of `A` and `L` as the identity.
hint: When you subtract `m` times row `j` from row `i`, store `m` in `L[i][j]`.
solution: For each pivot column `j` and each row `i` below it, the multiplier is `U[i][j] / U[j][j]`. Record it in `L[i][j]` and subtract that multiple of row `j` from row `i`. When the loops finish, `U` is the echelon form and `L` the multipliers.

model:
```python
from fractions import Fraction

def lu_solve(L, U, b):
    n = len(b)
    c = []
    for i in range(n):
        s = sum(L[i][j] * c[j] for j in range(i))
        c.append(Fraction(b[i] - s) / L[i][i])
    x = [Fraction(0)] * n
    for i in range(n - 1, -1, -1):
        s = sum(U[i][j] * x[j] for j in range(i + 1, n))
        x[i] = (c[i] - s) / U[i][i]
    return x
```
hint: First solve `L c = b` from the top, then `U x = c` from the bottom.
hint: In the back substitution, `x[i] = (c[i] - sum of U[i][j]*x[j] for j > i) / U[i][i]`.
solution: Forward substitution produces the intermediate vector `c`, and back substitution turns `c` into `x`. With `b = (1, 0, 0)` the result is the first column of $A^{-1}$, namely $(23/2, -13/2, 5/2)$.

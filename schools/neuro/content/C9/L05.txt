@article
A **vector space** is a set of objects (vectors) that can be added and multiplied by real numbers, with the usual rules (addition is commutative and associative, there is a zero vector, every vector has a negative, and scalar multiplication distributes over addition and satisfies $1v = v$ and $(ab)v = a(bv)$). The spaces $\mathbb{R}^n$ are the main examples; so are the polynomials of degree at most $d$ and the $m\times n$ matrices. In this course we work mostly inside $\mathbb{R}^n$.

### Subspaces

A **subspace** of a vector space $V$ is a subset $S$ that is itself a vector space under the same operations. To check, you need only the **subspace test**: $S$ is a subspace if

1. $S$ contains the zero vector,
2. $u, v \in S$ implies $u + v \in S$ (closed under addition),
3. $v \in S$ and $c \in \mathbb{R}$ implies $cv \in S$ (closed under scalar multiplication).

Every subspace therefore contains $0$, which is the quickest way to rule sets out: the line $y = 2x + 1$ misses the origin, so it is not a subspace. In $\mathbb{R}^2$ the subspaces are exactly $\{0\}$, the lines through the origin, and $\mathbb{R}^2$ itself. In $\mathbb{R}^3$ they are $\{0\}$, lines through $0$, planes through $0$, and $\mathbb{R}^3$.

Closure can fail even when $0$ is present: the two coordinate axes $\{(x, y) : xy = 0\}$ contain $0$ and are closed under scaling, but $(1, 0) + (0, 1) = (1, 1)$ is not in the set. The union of two subspaces is generally not a subspace, but the **intersection** of subspaces always is.

### Span

The **span** of vectors $v_1, \dots, v_k$ is the set of all their linear combinations. It is always a subspace, the smallest subspace that contains those vectors.

### Two subspaces attached to a matrix

Let $A$ be $m \times n$.

- The **column space** $C(A)$ is the span of the columns of $A$. It is a subspace of $\mathbb{R}^m$. It equals $\{Ax : x \in \mathbb{R}^n\}$, so **$Ax = b$ has a solution exactly when $b \in C(A)$**.
- The **null space** $N(A)$ is the set of all solutions of $Ax = 0$. It is a subspace of $\mathbb{R}^n$: if $Au = 0$ and $Av = 0$ then $A(u + v) = 0$ and $A(cu) = 0$. It always contains $x = 0$.

Note the different homes: for a $4 \times 7$ matrix the column space lives in $\mathbb{R}^4$ and the null space in $\mathbb{R}^7$.

### The complete solution of $Ax = b$

If $x_p$ is one particular solution of $Ax = b$, then every solution has the form

$$x = x_p + x_n, \qquad x_n \in N(A),$$

because $A(x - x_p) = b - b = 0$. The solutions form a translated copy of the null space, which is a subspace only when $b = 0$ (the set of solutions of $Ax = b$ for $b \ne 0$ does not contain $0$). So a consistent system has a unique solution exactly when $N(A) = \{0\}$, and otherwise infinitely many.

To decide whether $b \in C(A)$ by computer, row reduce the augmented matrix $[A \mid b]$: $b$ is in $C(A)$ exactly when no row of the form $[0\ \cdots\ 0 \mid c]$ with $c \neq 0$ appears, which is the same as saying the rank of $[A\mid b]$ equals the rank of $A$.

@example
title: Showing a set is a subspace
problem: Show that $S = \{(x, y, z) \in \mathbb{R}^3 : x + 2y - z = 0\}$ is a subspace.
step: Zero: $(0,0,0)$ gives $0 + 0 - 0 = 0$, so $0 \in S$.
step: Addition: if $u = (x, y, z)$ and $u' = (x', y', z')$ are in $S$, then $(x + x') + 2(y + y') - (z + z') = (x + 2y - z) + (x' + 2y' - z') = 0 + 0 = 0$, so $u + u' \in S$.
step: Scaling: if $u \in S$ and $c \in \mathbb{R}$, then $cx + 2cy - cz = c(x + 2y - z) = 0$, so $cu \in S$.
step: All three conditions hold. Equivalently, $S = N(A)$ for the $1\times3$ matrix $A = [1\ 2\ -1]$, and null spaces are always subspaces.
answer: $S$ is a subspace (a plane through the origin).

@example
title: Is a vector in the column space?
problem: For $A = \begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix}$, decide whether $b = (1, 2, 3)$ and $b' = (1, 2, 4)$ lie in $C(A)$.
step: $C(A)$ is the set of combinations $x_1(1,0,1) + x_2(0,1,1) = (x_1, x_2, x_1 + x_2)$.
step: For $b = (1, 2, 3)$ the first two components force $x_1 = 1$ and $x_2 = 2$, and then $x_1 + x_2 = 3$ matches the third component. So $b \in C(A)$.
step: For $b' = (1, 2, 4)$ the same $x_1 = 1$, $x_2 = 2$ would give third component $3 \ne 4$. In elimination terms the augmented row is $[0, 0 \mid 1]$, so $Ax = b'$ has no solution.
step: So $b' \notin C(A)$. Geometrically $C(A)$ is a plane in $\mathbb{R}^3$ and $b'$ is off that plane.
answer: $b \in C(A)$; $b' \notin C(A)$.

@mistakes
- Forgetting to check that the zero vector belongs to the set; a line or plane that misses the origin is never a subspace.
- Checking closure for a few examples instead of for all vectors. A subspace test is a proof that must work for arbitrary $u, v, c$.
- Mixing up the ambient spaces: $C(A)$ is in $\mathbb{R}^m$ (the number of rows) and $N(A)$ is in $\mathbb{R}^n$ (the number of columns).
- Calling the solution set of $Ax = b$ with $b \ne 0$ a subspace; it is a translate of $N(A)$ and misses $0$.

```python
assert in_column_space([[1, 0], [0, 1], [1, 1]], [1, 2, 3]) is True

```
model:
```python
from fractions import Fraction

def in_column_space(A, b):
    M = [[Fraction(x) for x in row] + [Fraction(c)]
         for row, c in zip(A, b)]
    m = len(M)
    n = len(M[0]) - 1
    r = 0
    for col in range(n):
        piv = next((i for i in range(r, m) if M[i][col] != 0), None)
        if piv is None:
            continue
        M[r], M[piv] = M[piv], M[r]
        for i in range(r + 1, m):
            f = M[i][col] / M[r][col]
            M[i] = [a - f * p for a, p in zip(M[i], M[r])]
        r += 1
    return all(row[n] == 0 for row in M[r:])
```
hint: Eliminate on the augmented matrix, treating only the first `n` columns as pivot columns.
hint: After elimination, look at the rows below the last pivot row: their coefficients are all zero, so their last entry must be zero too.
solution: Reduce `[A | b]`, counting pivots only among the coefficient columns. Rows below the last pivot row have zero coefficients, so any nonzero entry in the last column means the system is inconsistent and `b` is not in $C(A)$.

@practice self
prompt: Prove that the intersection $S \cap T$ of two subspaces $S$ and $T$ of $\mathbb{R}^n$ is a subspace.
hint: Check the three subspace conditions for $S \cap T$, using that each holds for $S$ and for $T$.
solution: Both $S$ and $T$ contain $0$, so $0 \in S \cap T$. Let $u, v \in S \cap T$ and $c \in \mathbb{R}$. Since $u, v \in S$ and $S$ is closed under addition and scaling, $u + v \in S$ and $cu \in S$. The same argument with $T$ gives $u + v \in T$ and $cu \in T$. So $u + v$ and $cu$ lie in both sets, that is in $S \cap T$. The three conditions hold, so $S \cap T$ is a subspace.
rubric: Shows $0$ is in the intersection.
rubric: Takes arbitrary $u, v$ in the intersection and shows $u + v$ is in both $S$ and $T$.
rubric: Shows $cu$ is in both $S$ and $T$ for an arbitrary scalar $c$.

```python
def in_null_space(A, x):
    if any(len(row) != len(x) for row in A):
        raise ValueError("wrong length")
    return all(sum(a * b for a, b in zip(row, x)) == 0 for row in A)
```

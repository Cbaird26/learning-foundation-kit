## Week-by-week key ideas

1. **Vectors and dot products.** Linear combinations; $u\cdot v = \|u\|\|v\|\cos\theta$; orthogonal means dot product $0$; Cauchy-Schwarz and the triangle inequality.
2. **Gaussian elimination.** Three row operations; pivots and free variables; a system has no solution, one solution, or infinitely many; a row $[0\ \cdots\ 0 \mid c]$ with $c \neq 0$ means inconsistent.
3. **Matrix operations and inverses.** Row-times-column product, $AB \neq BA$, $(AB)^{-1} = B^{-1}A^{-1}$, $(AB)^T = B^TA^T$; Gauss-Jordan on $[A \mid I]$.
4. **LU factorization.** $A = LU$ with the elimination multipliers in $L$; solve with forward then back substitution; factor once for many right-hand sides; $PA = LU$ when rows are exchanged.
5. **Subspaces.** Contains $0$, closed under addition and scaling; $C(A)$ in $\mathbb{R}^m$, $N(A)$ in $\mathbb{R}^n$; complete solution is particular plus null space.
6. **Independence, basis, dimension, rank.** Rank is the number of pivots; $\dim N(A) = n - r$; the four subspaces have dimensions $r$, $r$, $n - r$, $m - r$; use pivot columns of the original $A$.
7. **Linear transformations.** The columns of the matrix are the images of $e_1, \dots, e_n$; composition multiplies matrices with the first map on the right; homogeneous coordinates for translation.
8. **Determinants.** Sign change under swaps, product of pivots, $\det AB = \det A\det B$, $\det A = 0$ exactly when singular, $|\det|$ is area or volume.
9. **Eigenvalues.** $\det(A - \lambda I) = 0$; sum of eigenvalues is the trace, product is the determinant; eigenvectors span $N(A - \lambda I)$; power iteration.
10. **Diagonalization and Markov chains.** $A = S\Lambda S^{-1}$ and $A^k = S\Lambda^kS^{-1}$; Markov matrices have $\lambda = 1$ and the steady state is its eigenvector scaled to sum $1$.
11. **Orthogonality and least squares.** Projection $p = \frac{a\cdot b}{a\cdot a}a$; normal equations $A^TA\hat{x} = A^Tb$; the error is orthogonal to $C(A)$; Gram-Schmidt.
12. **SVD.** $A = U\Sigma V^T$; $\sigma_i = \sqrt{\lambda_i(A^TA)}$; best rank-$k$ approximation and its error; storage $k(m + n + 1)$.

## Common errors

- Wrong order of multiplication when composing transformations or inverting a product.
- Forgetting a sign change when swapping rows in a determinant, or using $\det(A+B) = \det A + \det B$.
- Taking the column-space basis from the reduced matrix instead of the original pivot columns.
- Dimension slips: mixing up $m$ and $n$ in $\dim N(A)$ and $\dim N(A^T)$.
- Accepting $v = 0$ as an eigenvector, or assuming a repeated eigenvalue means a diagonalizable matrix.
- Using rows summing to $1$ with the column convention for Markov matrices.
- Taking singular values to be eigenvalues of $A$ instead of square roots of eigenvalues of $A^TA$.

```python
from fractions import Fraction

def least_squares(A, b):
    m, n = len(A), len(A[0])
    N = [[Fraction(sum(A[k][i] * A[k][j] for k in range(m)))
          for j in range(n)] for i in range(n)]
    r = [Fraction(sum(A[k][i] * b[k] for k in range(m))) for i in range(n)]
    M = [N[i] + [r[i]] for i in range(n)]
    for col in range(n):
        p = next(i for i in range(col, n) if M[i][col] != 0)
        M[col], M[p] = M[p], M[col]
        for i in range(col + 1, n):
            f = M[i][col] / M[col][col]
            M[i] = [a - f * c for a, c in zip(M[i], M[col])]
    x = [Fraction(0)] * n
    for i in range(n - 1, -1, -1):
        s = sum(M[i][j] * x[j] for j in range(i + 1, n))
        x[i] = (M[i][n] - s) / M[i][i]
    return x
```
hint: Build the $n\times n$ matrix $A^TA$ and the vector $A^Tb$ from sums over the rows of `A`.
hint: Then solve the square system exactly: eliminate below each pivot (swapping if needed), and back substitute.
solution: The normal equations $A^TA\hat{x} = A^Tb$ form a square system with a unique solution because the columns of `A` are independent. Entry $(i, j)$ of $A^TA$ is the dot product of columns $i$ and $j$, and entry $i$ of $A^Tb$ is column $i$ dotted with `b`. Gaussian elimination with `Fraction`s then gives the exact solution.

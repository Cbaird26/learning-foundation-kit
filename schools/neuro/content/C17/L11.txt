@article
You see half of a friend's face behind a door and know at once who it is. A memory that can be recovered from a part of its content is **content-addressable**, unlike a computer's memory, which needs an address. Hopfield (1982) showed that a simple network of binary neurons, with weights set by a Hebbian rule, behaves this way: its stored patterns are stable states that the network falls into from nearby starting points.

### The model

A network of $N$ neurons has states $s_i \in \{-1, +1\}$ (active or silent). The weights $W_{ij}$ are **symmetric** ($W_{ij} = W_{ji}$) with a **zero diagonal** ($W_{ii} = 0$). To store $P$ patterns $\boldsymbol{\xi}^1, \ldots, \boldsymbol{\xi}^P$, each a vector of $\pm 1$, use the Hebbian outer-product rule

$$W_{ij} = \frac{1}{N}\sum_{\mu=1}^{P} \xi^\mu_i\,\xi^\mu_j \quad (i \ne j), \qquad W_{ii} = 0.$$

Two neurons that are active together (or silent together) in many patterns are connected excitatorily; neurons that disagree are connected by inhibition. Each neuron has a **local field** $h_i = \sum_j W_{ij}\,s_j$, and the **update rule** is

$$s_i \leftarrow \begin{cases} +1 & h_i > 0 \\ -1 & h_i < 0 \\ s_i & h_i = 0. \end{cases}$$

Updates are **asynchronous**: one neuron at a time, in a stated order (here a sweep $i = 0, 1, \ldots, N-1$, each neuron using the current states of the others). Recall means starting from a corrupted cue and updating until a full sweep changes nothing.

### The energy function

Define $E(\mathbf{s}) = -\tfrac12 \sum_{i,j} W_{ij}\,s_i s_j$. When neuron $k$ changes sign, only the terms with $k$ change, and because $W$ is symmetric with a zero diagonal the change is $\Delta E = -\Delta s_k\,h_k$, where $\Delta s_k = \pm 2$ has the same sign as $h_k$. So $\Delta E = -2\lvert h_k\rvert \le 0$: each asynchronous update lowers the energy or leaves it unchanged. Since $E$ takes finitely many values, the network must reach a state where no neuron changes, a **fixed point** (an attractor).

Take $N = 8$ and two patterns $\boldsymbol{\xi}^1 = (+,+,+,+,-,-,-,-)$ and $\boldsymbol{\xi}^2 = (+,-,+,-,+,-,+,-)$, which are orthogonal ($\boldsymbol{\xi}^1\!\cdot\boldsymbol{\xi}^2 = 0$). Every weight is $0$ or $\pm 0.25$. Corrupt the first bit of $\boldsymbol{\xi}^1$ to get the cue $(-,+,+,+,-,-,-,-)$. The local fields are $(0.75, 0.75, 0.25, 0.75, -0.75, -0.25, -0.75, -0.25)$, so neuron 0 flips to $+1$ and the other signs already agree. One sweep restores $\boldsymbol{\xi}^1$, and the energy falls from $-1.5$ to $-3.0$, the energy of both stored patterns (and of the mirror image $-\boldsymbol{\xi}^1$, which is also a stable state because $E(\mathbf{s}) = E(-\mathbf{s})$).

```python
def hopfield_weights(patterns):
    """Outer-product weights, symmetric, zero diagonal."""
    n = len(patterns[0])
    W = [[0.0] * n for _ in range(n)]
    for p in patterns:
        for i in range(n):
            for j in range(n):
                if i != j:
                    W[i][j] += p[i] * p[j] / n
    return W

def recall(W, s, max_sweeps=20):
    """Asynchronous sweeps in order 0..N-1 until nothing changes."""
    s = list(s)
    for _ in range(max_sweeps):
        changed = False
        for i in range(len(s)):
            h = sum(W[i][j] * s[j] for j in range(len(s)))
            new = s[i] if h == 0 else (1 if h > 0 else -1)
            if new != s[i]:
                s[i], changed = new, True
        if not changed:
            break
    return s

xi1 = [1, 1, 1, 1, -1, -1, -1, -1]
xi2 = [1, -1, 1, -1, 1, -1, 1, -1]
W = hopfield_weights([xi1, xi2])
cue = [-1] + xi1[1:]
print(recall(W, cue) == xi1)
```

This prints `True`.

### Capacity, spurious states and realism

Patterns that are not orthogonal interfere: the field on a neuron contains the signal from the pattern being recalled plus **crosstalk** from the others. For random patterns, the statistical physics of the model (Amit, Gutfreund and Sompolinsky, 1985) shows that recall works well only up to about $0.14\,N$ stored patterns for large $N$; beyond that, memories blur into **spurious states**, such as mirror images, mixtures of several patterns and states that match none. A network of $N = 8$ is too small for these asymptotic numbers (0.14 N is about one pattern), so small examples work only with carefully chosen, nearly orthogonal patterns.

As a model of the brain, the Hopfield network is an idealization: real neurons obey Dale's law (a neuron is excitatory or inhibitory, not both), have asymmetric connections, emit spikes at graded rates, and patterns in the brain are sparse. Extensions address these points. The recurrent collateral connections of hippocampal area CA3 are often proposed as an autoassociative network of this kind, supporting pattern completion (week 7), but direct evidence is limited. The model also connects to week 10: the weight rule is the Hebbian rule, with the stored patterns as the inputs.

title: Local field and update of one neuron
problem: A neuron has weights to four other neurons $\mathbf{W}_{i\cdot} = (0, 0.5, -0.25, 0.25)$ (the first is its own, zero) and the current state is $\mathbf{s} = (+1, +1, -1, +1)$. Find the local field and the neuron's new state.

step: Adding: $0 + 0.5 + 0.25 + 0.25 = 1.0$.
step: $h > 0$, so the neuron's new state is $+1$ (it was already $+1$, so nothing changes).
answer: $h = 1.0$ and the state stays $+1$.

@example
title: Two neurons updated synchronously and asynchronously
problem: Two neurons have $W_{01} = W_{10} = 1$ (zero diagonal) and the state $(+1, -1)$. Compare one synchronous update of both neurons with an asynchronous sweep in the order 0, 1.
step: Synchronous: both fields are computed from the old state. $h_0 = 1 \times (-1) = -1$ and $h_1 = 1 \times (+1) = +1$, so the new state is $(-1, +1)$. Updating again gives $(+1, -1)$: the network cycles forever with a period of 2.
step: Asynchronous: neuron 0 first has $h_0 = -1$, so it becomes $-1$ and the state is $(-1, -1)$. Neuron 1 now has $h_1 = -1$, so it stays at $-1$.
step: A later sweep changes nothing: the state $(-1,-1)$ is a fixed point with energy $E = -1$, lower than $E = +1$ of the starting state.
answer: Synchronous updates cycle between $(+1,-1)$ and $(-1,+1)$; asynchronous updates reach the fixed point $(-1,-1)$.

@mistakes
- Updating all neurons at once and expecting convergence: the energy argument needs one neuron at a time, and synchronous updates can oscillate.
- Leaving the diagonal $W_{ii}$ nonzero: the field $h_k$ then includes the self-term $W_{kk}s_k$, so the formula $\Delta E = -\Delta s_k h_k$ needs a correction, and positive self-connections make more spurious states stable; the diagonal is set to zero.
- Expecting a stored pattern to always be a fixed point: crosstalk from other, non-orthogonal patterns can flip bits of a stored pattern.
- Thinking recall retrieves the original exactly from any cue; cues that start in another memory's basin of attraction are completed to the wrong pattern, or to a spurious state.

def hopfield_energy(W, s):
    """Hopfield energy -1/2 * s^T W s."""
    n = len(s)
    total = 0.0
    for i in range(n):
        for j in range(n):
            total += W[i][j] * s[i] * s[j]
    return -0.5 * total
```
hint: Sum $W_{ij}s_is_j$ over all ordered pairs (both $i,j$ and $j,i$), then multiply by $-1/2$.
solution: Summing over all ordered pairs counts every connection twice, which the factor $\tfrac12$ compensates. The energy is the same for a state and its mirror image (the third and fourth tests), and with the weights above the state $(1,1,-1)$ has lower energy than $(1,1,1)$.

def sync_update(W, s):
    """One synchronous update; ties keep the old state."""
    new = []
    for i in range(len(s)):
        h = sum(W[i][j] * s[j] for j in range(len(s)))
        if h > 0:
            new.append(1)
        elif h < 0:
            new.append(-1)
        else:
            new.append(s[i])
    return new
```

model:
```python
def count_stable(patterns):
    """Number of stored patterns that are fixed points of the network."""
    if not patterns:
        return 0
    n = len(patterns[0])
    W = [[0.0] * n for _ in range(n)]
    for p in patterns:
        for i in range(n):
            for j in range(n):
                if i != j:
                    W[i][j] += p[i] * p[j] / n
    count = 0
    for p in patterns:
        stable = True
        for i in range(n):
            h = sum(W[i][j] * p[j] for j in range(n))
            if h * p[i] < 0:
                stable = False
        if stable:
            count += 1
    return count
```
hint: Build the weights first. A pattern is stable if for every neuron the product of its field and its state is not negative.
solution: Orthogonal patterns do not interfere, so the first and last cases keep every pattern. In the third case the random-looking patterns have overlaps, and the crosstalk flips at least one bit in two of them, so only one is stable. The test on a field of exactly 0 matters because a tie leaves the neuron unchanged.

@quiz self
prompt: A student stores 10 random patterns in a Hopfield network of 20 neurons and finds that recall from clean cues often fails. Explain why, with reference to capacity and crosstalk, and say what the student could change. Then list two respects in which the Hopfield network is not a realistic model of hippocampal area CA3.
hint: Compare 10 patterns with about 0.14 times the number of neurons, and think about the local field on one neuron.
solution: The local field on a neuron in a stored pattern equals the signal from that pattern plus a noise term from the other patterns, and the noise has a standard deviation that grows as the square root of $P/N$. With $P = 10$ and $N = 20$ we have $P/N = 0.5$, well above the capacity of about $0.14$ for random patterns, so the crosstalk often reverses a neuron's field and recall fails, producing spurious states. The student can increase the number of neurons, store fewer patterns, make the patterns more nearly orthogonal or sparse, or use a rule that reduces interference, such as the pseudo-inverse (projection) rule. The Hopfield network differs from CA3 in that its neurons are binary and each has both excitatory and inhibitory outgoing weights (violating Dale's law), its weights are symmetric and fully connected while CA3 connectivity is sparse and asymmetric, and its stored patterns are dense while hippocampal activity is sparse; real neurons also fire spikes with graded rates and learn with timing-dependent rules.
rubric: Explains crosstalk as noise in the local field that grows with the load $P/N$, and compares $P/N$ with about 0.14.
rubric: Proposes a sensible remedy such as more neurons, fewer patterns, sparser or more orthogonal patterns, or a different learning rule.
rubric: Names two valid unrealistic features (Dale's law, symmetry, dense full connectivity, binary units, dense patterns).

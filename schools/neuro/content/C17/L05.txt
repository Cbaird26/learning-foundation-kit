@article
A rat has pressed a lever for food pellets for weeks. Now give it pellets in its home cage until it is full, or pair the pellets with illness so that it avoids them. Put it back in the chamber. Does it still press? A rat in an early stage of training presses less, as if it knew what the lever produces and no longer wants it. A rat after extensive training often keeps pressing, as if the lever had become a habit. This **outcome devaluation** test separates two ways of choosing.

### Two controllers

A **goal-directed** (model-based) controller keeps a model of what each action leads to and computes its value on the spot:

$$Q_{\text{MB}}(a) = \sum_o P(o \mid a)\,U(o),$$

the sum over outcomes $o$ of their probability given the action times their current utility $U$. If $U(\text{food})$ drops, $Q_{\text{MB}}$ for the lever drops immediately, with no new experience of the lever. A **habitual** (model-free) controller instead stores a cached value $Q_{\text{MF}}(a)$ learned from past rewards by the prediction-error rules of weeks 3 and 4. After devaluation its cached value stays high until the animal presses and experiences the new, worse outcome; then the error $0 - Q_{\text{MF}}$ shrinks it gradually.

Behavior is often described as a mixture, with weight $w$ on the model-based system:

$$Q(a) = w\,Q_{\text{MB}}(a) + (1 - w)\,Q_{\text{MF}}(a).$$

Take a lever that gives food ($U = 1.0$) and a chain that gives water ($U = 0.6$), both with probability 1, so that $Q_{\text{MF}} = (1.0, 0.6)$ after training. Devalue the food so that $U(\text{food}) = 0$:

| | $Q_{\text{MB}}$ | $Q_{\text{MF}}$ | $Q$ with $w = 0.3$ | $Q$ with $w = 0.8$ |
|---|---|---|---|---|
| lever | 0.0 | 1.0 | 0.70 | 0.20 |
| chain | 0.6 | 0.6 | 0.60 | 0.60 |

With a small $w$ the animal keeps pressing the lever (habit); with a large $w$ it switches to the chain (goal-directed). The two are equally good when $(1-w)\cdot 1.0 = 0.6$, so at $w = 0.4$.

```python
def mb_value(outcome_probs, utilities):
    """Model-based value: expected utility of the outcomes of one action."""
    value = 0.0
    for outcome, p in outcome_probs.items():
        value += p * utilities[outcome]
    return value

def choose(q_mb, q_mf, w):
    """Action with the highest mixed value; ties go to the first action."""
    best, best_q = None, None
    for a in q_mb:
        q = w * q_mb[a] + (1 - w) * q_mf[a]
        if best_q is None or q > best_q:
            best, best_q = a, q
    return best

U = {"food": 0.0, "water": 0.6}
q_mb = {"lever": mb_value({"food": 1.0}, U), "chain": mb_value({"water": 1.0}, U)}
q_mf = {"lever": 1.0, "chain": 0.6}
print(choose(q_mb, q_mf, 0.3), choose(q_mb, q_mf, 0.8))
```

This prints `lever chain`.

### What favors habits

In rodents, devaluation sensitivity is lost with extended training and with training on interval schedules (where reward depends little on response rate), while it persists longer on ratio schedules, where actions clearly produce outcomes. Humans in sequential decision tasks show a mixture of both kinds of control, and stress or cognitive load tends to shift it toward habit-like choice. Not every habit is a failure of rationality: a cached value is cheap, and a good one is as good as a plan.

### The basal ganglia

The **basal ganglia** are a set of nuclei beneath the cortex. The input stage is the **striatum** (caudate nucleus and putamen, with the nucleus accumbens ventrally), which receives excitatory input from nearly all of the cortex and thalamus and dopamine from the substantia nigra pars compacta (SNc) and the ventral tegmental area (VTA). Output leaves through the internal globus pallidus and the substantia nigra pars reticulata, which inhibit the thalamus tonically. Two classic routes through the striatum are:

- the **direct pathway**: striatal neurons with D1 dopamine receptors inhibit the output nuclei, which releases the thalamus from inhibition and tends to promote an action;
- the **indirect pathway**: striatal neurons with D2 receptors act through the external globus pallidus and the subthalamic nucleus to strengthen the output nuclei's inhibition, which tends to suppress actions.

Dopamine from the prediction-error signal of week 4 is thought to strengthen cortico-striatal synapses of the pathway that led to a good outcome, which is the cached value in the model. Loss of dopamine neurons in the SNc causes Parkinson's disease, with slowed movement, rigidity and tremor; degeneration of striatal neurons causes Huntington's disease. Diagnosis and treatment belong to clinicians.

In rodents, lesion and inactivation studies link the dorsomedial striatum (caudate in primates) to goal-directed behavior and the dorsolateral striatum (putamen) to habits. The map is informative, but how cleanly the habit/goal split corresponds to model-free/model-based computation is debated, as is whether the two systems are separate or interact at every stage.

@example
title: A devaluation test by hand
problem: A rat's lever press leads to a pellet with probability 0.9 and to nothing with probability 0.1. After training the cached value is $Q_{\text{MF}} = 0.9$. The pellet's utility is cut from $1.0$ to $0.5$ and the utility of "nothing" is 0. Find $Q_{\text{MB}}$ and the mixed value for $w = 0.5$.
step: Model-based value: $Q_{\text{MB}} = 0.9 \times 0.5 + 0.1 \times 0 = 0.45$.
step: The cached value is unchanged: $Q_{\text{MF}} = 0.9$.
step: The mixture is $0.5 \times 0.45 + 0.5 \times 0.9 = 0.675$.
step: A planner would value the lever at $0.45$ and a pure habit at $0.9$; the mixture falls between them.
answer: $Q_{\text{MB}} = 0.45$ and the mixed value is $0.675$.

@example
title: How many devalued trials until the habit is revised?
problem: A cached value $Q_{\text{MF}} = 0.9$ for the lever competes with a value of $0.5$ for another action. After devaluation each lever press gives reward 0 and the delta rule with $\alpha = 0.3$ is applied. After how many presses is the lever's cached value below $0.5$?
step: Each press gives $Q \leftarrow Q + 0.3(0 - Q) = 0.7\,Q$.
step: After one press: $0.9 \times 0.7 = 0.63$, which is still at least $0.5$.
step: After two presses: $0.63 \times 0.7 = 0.441$, below $0.5$.
answer: Two presses. Until then, a purely model-free controller keeps choosing the lever.

@mistakes
- Calling any repeated behavior a habit; the operational test is insensitivity to devaluation of the outcome, not frequency.
- Reading the direct pathway as "go" and the indirect as "stop" with no exceptions: the roles of the two pathways in real behavior are more complicated.
- Thinking that devaluation changes the cached value directly; it changes the utility $U$, which the model-based system sees at once and the model-free system learns only through new outcomes.
- Treating Parkinson's disease as a disorder of motivation alone; the cause is loss of dopamine neurons in the SNc, with effects on movement and learning.

```python
def devaluation_choice(P, U, q_mf, w, devalued):
    """Action with the highest mixed value after devaluing some outcomes."""
    utilities = {o: (0.0 if o in devalued else u) for o, u in U.items()}
    best, best_q = None, None
    for a, outcomes in P.items():
        q_mb = 0.0
        for o, p in outcomes.items():
            q_mb += p * utilities[o]
        q = w * q_mb + (1 - w) * q_mf[a]
        if best_q is None or q > best_q:
            best, best_q = a, q
    return best
```
hint: Build a copy of the utilities with the devalued outcomes set to 0, compute each action's model-based value, mix, and keep the first action with the highest value (use a strict comparison).
solution: Setting the utility of the devalued outcome to zero lowers only the model-based part. With $w = 0.3$ the left action keeps $0.7 \times 0.8 = 0.56$ against $0.4$ for the right one, a habit; with $w = 0.8$ it drops to $0.16$. With no devaluation both systems agree on the left action. The last test has a tie ($0.0$ against $0.0$), which a strict comparison resolves in favor of the first action.

model:
```python
def presses_until_switch(q_habit, q_alt, alpha):
    """Presses of a devalued lever until its cached value falls below q_alt."""
    q, n = q_habit, 0
    while q >= q_alt:
        q += alpha * (0.0 - q)
        n += 1
    return n
```
hint: Loop while the value is at least `q_alt`: apply the update and count one press. The count when the loop ends is the answer.
solution: Each press multiplies the value by $1 - \alpha$. The fourth and fifth tests land exactly on the alternative's value (for example $0.8 \times 0.5^3 = 0.1$), and the switch requires the value to be strictly below it, so one more press is needed; a loop that stops at `>` would return one too few presses. A habit therefore disappears only after several devalued experiences.

model:
```python
def indifference_weight(q_mb, q_mf):
    """Weight on the model-based system that makes two actions equal."""
    a, b = list(q_mb)
    d_mb = q_mb[a] - q_mb[b]
    d_mf = q_mf[a] - q_mf[b]
    if d_mb == d_mf:
        return None
    w = d_mf / (d_mf - d_mb)
    if 0.0 <= w <= 1.0:
        return w
    return None
```
hint: Write the difference of the mixed values as $w\,d_{\text{MB}} + (1-w)\,d_{\text{MF}}$, set it to zero and solve for $w$; then check the range.
solution: Setting $w\,d_{\text{MB}} + (1-w)\,d_{\text{MF}} = 0$ gives $w = d_{\text{MF}}/(d_{\text{MF}} - d_{\text{MB}})$. If both systems agree on the difference no weight changes it, so there is no solution (even when the difference is zero, where all weights tie rather than one); if both prefer the same action, $w$ falls outside $[0, 1]$. The last test has $d_{\text{MF}} = 0$, so the actions are equal at $w = 0$.

@article
Confidence intervals say what values of a parameter are plausible. A **hypothesis test** asks a yes-or-no question: is the data consistent with "nothing is going on"? Its main use in computing is the **A/B test**: randomly show visitors version A or version B and decide whether B really converts better, or whether the observed difference is just luck.

### The logic of a test

1. State the **null hypothesis** $H_0$ (no effect, for example "both versions have the same conversion rate") and the **alternative** $H_1$ (a difference exists).
2. Choose a **test statistic** that measures how far the data are from $H_0$.
3. Compute the **p-value**: the probability, assuming $H_0$ is true, of a test statistic at least as extreme as the one observed.
4. Choose a **significance level** $\alpha$ in advance (commonly $0.05$). **Reject** $H_0$ if the p-value is below $\alpha$.

The p-value is **not** the probability that $H_0$ is true, and it is not the probability that the result is "due to chance". It is a probability of data given $H_0$, not of $H_0$ given data. A large p-value means the data are compatible with $H_0$, not that $H_0$ is proven.

### Errors and power

- A **type I error** is rejecting a true $H_0$ (a false positive). A test at level $\alpha$ makes it with probability at most $\alpha$.
- A **type II error** is failing to reject a false $H_0$ (a missed real effect), with probability $\beta$.
- The **power** is $1 - \beta$, the probability of detecting an effect of a given size. Power grows with the sample size and the true effect size, and shrinks as $\alpha$ is made smaller.

An approximate sample size per group to detect a difference between conversion rates $p_1$ and $p_2$ with a two-sided level-$\alpha$ test and power $1 - \beta$ is $n \approx (z_{1-\alpha/2} + z_{1-\beta})^2\,\big[p_1(1-p_1) + p_2(1-p_2)\big]/(p_1 - p_2)^2$. Plan this **before** the experiment.

### The two-proportion z-test

Variant A has $x_1$ conversions out of $n_1$ visitors and variant B has $x_2$ out of $n_2$. Let $\hat p_1 = x_1/n_1$ and $\hat p_2 = x_2/n_2$. Under $H_0: p_1 = p_2$ both groups share one rate, estimated by the **pooled** proportion $\hat p = (x_1 + x_2)/(n_1 + n_2)$. The test statistic is

$$z = \frac{\hat p_2 - \hat p_1}{\sqrt{\hat p(1 - \hat p)\left(\frac{1}{n_1} + \frac{1}{n_2}\right)}},$$

which is approximately standard normal under $H_0$ when the counts are large enough. The two-sided p-value is $2\big(1 - \Phi(|z|)\big)$.

### Exact and permutation tests

Under $H_0$ the labels A and B are arbitrary. A **permutation test** exploits this: shuffle the pooled observations into two groups of the original sizes many times, compute the difference of means each time, and take as the p-value the fraction of shuffles whose difference is at least as extreme as the observed one (adding 1 to numerator and denominator avoids a p-value of exactly 0). It needs no normal approximation. An **exact test** uses the exact distribution: for 9 heads in 10 tosses of a supposedly fair coin, the one-sided p-value is $P(X \ge 9) = (10 + 1)/1024$.

### Pitfalls

- **Multiple comparisons.** If you test $m$ independent true null hypotheses at level $\alpha$, the chance of at least one false positive is $1 - (1 - \alpha)^m$: about $64\%$ for $m = 20$ and $\alpha = 0.05$. The **Bonferroni correction** tests each at $\alpha/m$ to keep the overall false-positive probability at most $\alpha$.
- **Peeking.** Checking the p-value repeatedly and stopping as soon as it dips below $\alpha$ inflates the false-positive rate. Fix the sample size or use a sequential method designed for it.
- **Statistical versus practical significance.** With enough data a trivial difference becomes "significant". Report the **effect size** with a confidence interval, not only the p-value.
- **Randomization.** A/B tests support causal claims only because visitors are assigned to variants at random.

@example
title: An A/B test for a conversion rate
problem: Variant A converts 200 of 2000 visitors and variant B converts 250 of 2000. Test $H_0: p_A = p_B$ at $\alpha = 0.05$ with a two-sided two-proportion z-test.
step: $\hat p_A = 0.10$ and $\hat p_B = 0.125$. The pooled proportion is $\hat p = 450/4000 = 0.1125$.
step: The standard error is $\sqrt{0.1125 \cdot 0.8875 \cdot (1/2000 + 1/2000)} = \sqrt{9.984 \times 10^{-5}} \approx 0.00999$.
step: $z = (0.125 - 0.10)/0.00999 \approx 2.50$.
step: The two-sided p-value is $2(1 - \Phi(2.50)) \approx 0.012$, which is below $0.05$, so we reject $H_0$: the data are hard to explain by luck alone.
step: A 95% interval for the difference is about $0.025 \pm 1.96\sqrt{\frac{0.1 \cdot 0.9}{2000} + \frac{0.125 \cdot 0.875}{2000}} \approx 0.025 \pm 0.0196$, that is roughly $(0.005,\ 0.045)$, so the lift could be anywhere from half a percentage point to four and a half.
answer: $z \approx 2.50$, $p \approx 0.012$: reject $H_0$ at the 5% level

@example
title: An exact test
problem: A coin lands heads 9 times in 10 tosses. Test whether it is fair, using a two-sided exact test.
step: Under $H_0$ (fair coin), $X \sim \mathrm{Binomial}(10, 1/2)$. The one-sided tail is $P(X \ge 9) = \binom{10}{9}/1024 + \binom{10}{10}/1024 = 11/1024$.
step: Results as extreme in the other direction are at most 1 head, with the same probability $11/1024$ by symmetry.
step: The two-sided p-value is $2 \cdot 11/1024 = 11/512 \approx 0.0215$.
step: At $\alpha = 0.05$ we reject fairness; at $\alpha = 0.01$ we would not.
answer: $p = 11/512 \approx 0.0215$

@mistakes
- Interpreting the p-value as the probability that the null hypothesis is true.
- Concluding "no effect" from a non-significant result, when the test may simply have too little power.
- Running many tests (or many metrics and segments) and reporting only the significant ones without correcting.
- Stopping an experiment the first time the p-value is below $0.05$.

```python
import math


def two_proportion_z(x1, n1, x2, n2):
    p1 = x1 / n1
    p2 = x2 / n2
    pooled = (x1 + x2) / (n1 + n2)
    se = math.sqrt(pooled * (1 - pooled) * (1 / n1 + 1 / n2))
    if se == 0:
        return 0.0
    return (p2 - p1) / se
```

model:
```python
import math


def ab_test(x1, n1, x2, n2):
    pooled = (x1 + x2) / (n1 + n2)
    se = math.sqrt(pooled * (1 - pooled) * (1 / n1 + 1 / n2))
    if se == 0:
        return (0.0, 1.0)
    z = (x2 / n2 - x1 / n1) / se
    phi = 0.5 * (1 + math.erf(abs(z) / math.sqrt(2)))
    return (z, 2 * (1 - phi))
```
hint: First get the z statistic exactly as in the two-proportion test.
hint: The two-sided p-value is `2 * (1 - phi)` where `phi = 0.5 * (1 + math.erf(abs(z) / math.sqrt(2)))`.
solution: Compute `z` from the pooled standard error, evaluate the normal CDF at `abs(z)` with `math.erf`, and return `2 * (1 - phi)`. For 120/1000 versus 150/1000 this gives $z \approx 1.963$ and $p \approx 0.0496$, just below $0.05$.

model:
```python
import random


def permutation_p_value(a, b, trials, seed):
    rng = random.Random(seed)
    n = len(a)
    observed = abs(sum(a) / len(a) - sum(b) / len(b))
    pooled = list(a) + list(b)
    count = 0
    for _ in range(trials):
        rng.shuffle(pooled)
        diff = abs(sum(pooled[:n]) / n - sum(pooled[n:]) / len(b))
        if diff >= observed - 1e-12:
            count += 1
    return (count + 1) / (trials + 1)
```
hint: Copy the data into a new pooled list before shuffling so the inputs are not changed.
hint: After each shuffle, the first `len(a)` values play the role of group A and the rest the role of group B.
solution: Under the null hypothesis the group labels are exchangeable, so shuffling the pooled data generates the null distribution of the difference of means. The tolerance `1e-12` protects against floating-point noise when a shuffle reproduces the observed difference exactly, and the plus-one terms keep the estimated p-value above 0. Identical groups give a p-value of exactly 1.

@article
Backpropagation trains networks of the kind used as models of the visual system (Week 2) and of recurrent circuits (Weeks 5–6). If brains learn complex tasks, does anything like it happen there? The question divides into two: can neural circuits compute the gradients that backpropagation needs, or something close enough? And how would we know? The first is a question about mechanisms; the second is the methodological problem of this week.

### What backpropagation requires

Consider a network with input $\mathbf{x}$, hidden activity $\mathbf{h} = \varphi(\mathbf{a})$, $\mathbf{a} = \mathbf{W}_1\mathbf{x}$, output $\mathbf{y} = \mathbf{W}_2\mathbf{h}$ and loss $L = \frac{1}{2}\|\mathbf{y} - \mathbf{t}\|^2$ with target $\mathbf{t}$. Let $\mathbf{e} = \mathbf{y} - \mathbf{t}$ be the output error. The gradients are
$$\frac{\partial L}{\partial \mathbf{W}_2} = \mathbf{e}\,\mathbf{h}^\top, \qquad \boldsymbol{\delta}_h = (\mathbf{W}_2^\top \mathbf{e}) \odot \varphi'(\mathbf{a}), \qquad \frac{\partial L}{\partial \mathbf{W}_1} = \boldsymbol{\delta}_h\,\mathbf{x}^\top,$$
where $\odot$ is element-wise multiplication. Four requirements are conventionally listed as problems for a literal biological implementation:

1. **Weight transport.** The error is sent back through $\mathbf{W}_2^\top$, the transpose of the forward weights. That needs a feedback pathway whose synaptic weights are a copy of the forward ones; no known mechanism sets backward synapses to equal forward ones.
2. **Derivative of the nonlinearity.** Each hidden unit's error is gated by $\varphi'(\mathbf{a})$, which must be available at the unit.
3. **Separate phases.** Forward activity and backward error are treated as separate passes with the same units, while neurons carry both in a continuous process.
4. **A global, precise error.** Output error is propagated through many layers with the exactness of the chain rule.

These are objections to a literal reading. They do not show that approximate gradient-following is impossible, and several proposals relax them.

### Alternatives and what each gives up

**Feedback alignment** (Lillicrap and colleagues, 2016) replaces $\mathbf{W}_2^\top$ by a fixed random matrix $\mathbf{B}$: $\boldsymbol{\delta}_h = (\mathbf{B}\mathbf{e}) \odot \varphi'(\mathbf{a})$. Surprisingly, small networks still learn: the forward weights adapt so that $\mathbf{W}_2^\top$ comes to resemble $\mathbf{B}$ in direction, and the updates become positively aligned with the true gradient. It removes weight transport but works less well in deep networks and on harder tasks, and it still needs a derivative and a separate error signal.

**Three-factor rules** combine local pre- and postsynaptic activity with a third, global signal such as a neuromodulator: $\Delta w = \eta\,\text{pre} \times \text{post} \times M$. With $M$ a reward prediction error (Week 7), the rule is a candidate for reinforcement learning in the striatum and cortex. It is local and plausible but has no way to assign credit to a particular hidden unit by itself, so it learns slowly as networks grow.

**Perturbation methods** (node perturbation, REINFORCE-style learning) add noise to unit activity and correlate the noise with the change in reward or loss. They estimate the gradient without a backward pass, but the estimates are noisy, and the number of trials needed grows with the number of units.

**Pure Hebbian learning** ($\Delta w \propto \text{pre} \times \text{post}$) is local but has no error signal at all; by itself it learns correlations, not task solutions. Further proposals use local prediction errors (predictive coding, Week 9), or dendrites that carry error-like signals; these are active research with differing assumptions and partial evidence.

### How to compare a rule with gradient descent

A fair comparison asks two things: how well does the rule solve the task, and how close are its updates to the gradient? For a weight update $\Delta\mathbf{w}$ and the true gradient step $-\mathbf{g}$, the **alignment angle** is given by the cosine $\cos\theta = \Delta\mathbf{w}\cdot(-\mathbf{g})/(\|\Delta\mathbf{w}\|\,\|\mathbf{g}\|)$; angles below $90^\circ$ mean the rule decreases the loss to first order. Report learning curves with the same architecture, initialization, learning-rate search budget and number of updates for each rule; use several seeds; and separate the learning rule from architecture and nonlinearity. Compare also with a control (a random update direction of the same norm has cosine near 0), and evaluate on held-out data. Two cautions: a rule that matches backpropagation's performance on a small task may fail at scale, and a rule that reaches the same loss may do so with different internal representations, so it can be a different model of the brain even when behavior matches.

The most honest summary is that no one has shown that cortex implements backpropagation, and no one has shown that it cannot approximate gradient information with local circuits. Experiments that could discriminate (for example, measuring whether feedback synapses align with forward ones, or whether neurons carry error signals in dendrites) are difficult.

@example
title: Backpropagation and feedback alignment in one hidden layer
problem: A network has two hidden tanh units with pre-activations $\mathbf{a} = (0.5, -0.5)$ and a single output with weights $\mathbf{W}_2 = (1.0, -2.0)$. The output error is $e = 0.4$. A fixed random feedback vector is $\mathbf{B} = (0.5, 0.5)$. Compute the hidden deltas under backpropagation and under feedback alignment.
step: Compute the derivatives: $\varphi'(a) = 1 - \tanh^2(a)$. For $a = \pm 0.5$, $\tanh(0.5) = 0.4621$, so $\varphi' = 1 - 0.2135 = 0.7864$ for both units.
step: Backpropagation: $\delta_{h,j} = W_{2,j}\,e\,\varphi'_j$ gives $\delta_{h,1} = 1.0 \times 0.4 \times 0.7864 = 0.3146$ and $\delta_{h,2} = -2.0 \times 0.4 \times 0.7864 = -0.6291$.
step: Feedback alignment: $\delta_{h,j} = B_j\,e\,\varphi'_j$ gives $0.5 \times 0.4 \times 0.7864 = 0.1573$ for both units.
step: Compare: the cosine between $(0.3146, -0.6291)$ and $(0.1573, 0.1573)$ is $(0.0495 - 0.0990)/(0.7034 \times 0.2224) = -0.316$, so on this step the random feedback pushes unit 2 in the wrong direction; feedback alignment works because over training $\mathbf{W}_2$ changes until the signs agree.
answer: Backpropagation gives $(0.315, -0.629)$; feedback alignment gives $(0.157, 0.157)$, with cosine $\approx -0.32$ at this step.

@mistakes
- Saying the brain "cannot" do backpropagation because of weight transport: this is an objection to the literal algorithm, and approximations that avoid it exist.
- Saying that feedback alignment is a model of cortex because it learns a small task: matching a toy task does not test the mechanism.
- Comparing rules with different tuning budgets, initializations or architectures, and attributing the difference to the rule.
- Reporting final accuracy only: the alignment with the gradient and the learning curve show how a rule learns.

answer: 0.126

answer: 0.96
tol: 0.001

@practice self
prompt: You are asked to compare a three-factor rule (Hebbian eligibility trace times a global error signal) with gradient descent on a toy task: a two-layer network with 10 hidden units learning to classify 2D points as inside or outside a circle. Specify the protocol: the matched elements, the metrics, the controls and the analysis of results, and state which conclusions the experiment can and cannot support.
hint: Ask what could differ between the two runs besides the learning rule, and remove each difference; then choose metrics that show how the rule learns, not only where it ends.
solution: Matched elements: the same architecture (two inputs, 10 tanh hidden units, one sigmoid output), the same initial weights for each seed (20 seeds), the same training and held-out sets (for example 400 and 400 points drawn once), the same number of updates and minibatch order, and a learning rate chosen for each rule by the same budget of a grid search on a validation set, so neither rule gets better tuning. Metrics: the learning curve of the loss and accuracy on held-out points; the alignment angle between each rule's weight update and the true gradient at regular points in training (cosine, averaged over minibatches); the number of updates to reach 95% accuracy; and the final accuracy with a confidence interval over seeds. Controls: a random update of the same norm (cosine near 0, accuracy not improving, showing the metrics are not trivially satisfied), gradient descent with noise added to the gradient of matched variance (since the three-factor rule is noisy), and a version of the rule that updates only the output layer. Analysis: paired comparisons across seeds, with effect sizes and intervals; the alignment curve over training to see whether the rule follows the gradient early or late. Supported conclusions: on this task and at this size, whether the three-factor rule reaches comparable accuracy, how many more updates it needs, and how well it follows the gradient. Not supported: that cortex uses the rule (a toy task says nothing about the mechanism), that the rule scales to deep networks or hard tasks, or that equal accuracy implies equal internal representations; those need larger tasks, comparisons of representations, and biological evidence.
rubric: Matches architecture, initialization, data, update budget and hyperparameter-tuning budget across rules and uses several seeds.
rubric: Uses the alignment angle and learning curves, plus controls such as a random update or noisy gradient.
rubric: States both what the toy comparison supports and what it cannot (scaling, representations, biology).

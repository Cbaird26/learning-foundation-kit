@article
An encoding model asks whether a network's features can be mapped onto a voxel. But a layer with 4,096 units and a cortical area with thousands of voxels have no natural correspondence of units, and a model with a flexible mapping can fit almost anything. **Representational similarity analysis** (RSA; Kriegeskorte, Mur and Bandettini, 2008) sidesteps the mapping: it compares *how the stimuli relate to one another* in each system.

### The representational dissimilarity matrix

For $n$ stimuli, record a response pattern $\mathbf{r}_i$ for each stimulus $i$ (the activity of a layer, of voxels in a region, or of recorded neurons). The **representational dissimilarity matrix** (RDM) is the $n \times n$ symmetric matrix with entries $D_{ij} = d(\mathbf{r}_i, \mathbf{r}_j)$ and zeros on the diagonal. Common choices of $d$ are the **correlation distance** $1 - r(\mathbf{r}_i, \mathbf{r}_j)$, which ignores the overall level and scale of each pattern, and the **Euclidean distance** $\|\mathbf{r}_i - \mathbf{r}_j\|$, which does not. Because the matrix is symmetric, only the $n(n-1)/2$ entries above the diagonal carry information, and comparison uses that vector of entries.

Take three stimuli A, B, C with two-unit patterns $(1, 0)$, $(0, 1)$ and $(3, 4)$. The Euclidean distances are $d_{AB} = \sqrt 2 \approx 1.41$, $d_{AC} = \sqrt{20} \approx 4.47$ and $d_{BC} = \sqrt{18} \approx 4.24$. The vector $(1.41, 4.47, 4.24)$ is a *geometry*: A and B are close, C is far from both. A model layer with 4,096 units, a human fMRI region and a monkey IT population each give a $3 \times 3$ matrix that can be compared directly, even across species, imaging methods and models. This is the main attraction of RSA: one common currency for brains, models and behavior (for example, judged dissimilarity).

### Comparing RDMs

Compare two RDMs by correlating their upper-triangle vectors. The standard choice is the **Spearman rank correlation**: replace each vector by the ranks of its entries (the smallest entry gets rank 1, ties get the average of the ranks they span) and take the Pearson correlation of the ranks. Without ties it equals $1 - 6\sum_i d_i^2/(n(n^2 - 1))$, with $d_i$ the rank differences and $n$ here the number of entries. Ranks are used because the distance measure's scale is arbitrary: a model and a brain may be related by an unknown monotonic nonlinearity, and a rank comparison respects only the ordering that all reasonable measures share. For the example, the ranks of $(1.41, 4.47, 4.24)$ are $(1, 3, 2)$; against a model RDM $(2, 3, 6)$ with ranks $(1, 2, 3)$ the rank differences are $(0, 1, -1)$, so $\rho = 1 - 6 \times 2/(3 \times 8) = 0.5$.

### Inference, noise and the ceiling

A correlation between RDMs needs a null and an uncertainty. Entries of an RDM are not independent: all distances involving stimulus $i$ change when pattern $i$ changes, so bootstrapping over RDM cells would give overconfident intervals. The usual approach is to resample or permute the *stimuli* (and subjects), recompute the RDMs, and repeat. Noise has a second, subtler effect: with noisy patterns, estimated distances are positively biased, because noise adds to every distance. Estimators built from independent splits of the data (cross-validated distances) remove this bias, and reliability must also bound what any model can achieve, which is the noise ceiling of Week 11.

### What RSA tests, and what it does not

A model and a brain share a representational geometry if they agree on which stimuli are similar. That is a strong constraint, since the unit-to-voxel mapping is not fitted, and the comparison is easy to run for many models. Its limits are equally clear.

- **Equal weighting.** With a fixed distance measure, all response dimensions count equally. A layer in which a few high-variance, irrelevant units dominate the distances can fit poorly even if a weighted subset of its units would fit well. *Fitted* RSA, in which feature weights are learned with cross-validation, trades some of the parameter-free appeal for sensitivity, and it moves the method toward the encoding models of Week 3.
- **Geometry, not mechanism.** Different networks can share a geometry for the stimuli tested, and a matching geometry on 50 stimuli says nothing about untested ones.
- **Confounds.** If two RDMs correlate because both reflect low-level image similarity (luminance, color, outlines), the match does not support a claim about object representation. Control models, partial correlation, and stimulus sets that decorrelate the candidate models are the remedy.
- **Stimulus-set dependence.** The conclusion depends on which stimuli were chosen, and a stimulus set designed to decorrelate model geometries is much more informative than a random set.

RSA and encoding models are complementary: encoding models test which features are linearly decodable and evaluate on held-out stimuli; RSA tests the geometry directly. A claim supported by both is stronger than either alone.

title: From patterns to a model–brain comparison
problem: Three stimuli have two-unit response patterns P1 $= (2, 0)$, P2 $= (0, 0)$ and P3 $= (2, 3)$ in a recorded population. A model gives pairwise dissimilarities $(P1,P2) = 4$, $(P1,P3) = 9$ and $(P2,P3) = 1$. Compute the Euclidean RDM vector of the population and its Spearman correlation with the model.
step: Compute the three distances: $d_{12} = \sqrt{(2-0)^2 + 0^2} = 2$; $d_{13} = \sqrt{0 + 3^2} = 3$; $d_{23} = \sqrt{2^2 + 3^2} = \sqrt{13} \approx 3.61$.
step: Rank the population vector $(2, 3, 3.61)$: ranks $(1, 2, 3)$.
step: Rank the model vector $(4, 9, 1)$: ranks $(2, 3, 1)$.
step: Rank differences $(-1, -1, 2)$ give $\sum d^2 = 6$, so $\rho = 1 - 6 \times 6/(3 \times 8) = 1 - 1.5 = -0.5$. The model's geometry disagrees with the population's, since it puts the pair with the largest population distance closest.
answer: $\rho = -0.5$.

@mistakes
- Using the full matrix, including the diagonal and both triangles, when correlating RDMs: the diagonal is trivially zero and the symmetry duplicates every entry.
- Bootstrapping over RDM cells: the entries share stimuli, so resample stimuli (and subjects) instead.
- Treating ties naively when ranking: tied entries get the average of their ranks.
- Interpreting a significant RDM correlation as support for a specific representation when low-level image similarity or another confound explains both.

model:
```python
import math


def _corr(a, b):
    n = len(a)
    ma, mb = sum(a) / n, sum(b) / n
    num = sum((x - ma) * (y - mb) for x, y in zip(a, b))
    den = math.sqrt(sum((x - ma) ** 2 for x in a)
                    * sum((y - mb) ** 2 for y in b))
    return num / den


def rdm_corr(patterns):
    """Upper triangle of the correlation-distance RDM, in row order."""
    n = len(patterns)
    return [1.0 - _corr(patterns[i], patterns[j])
            for i in range(n) for j in range(i + 1, n)]
```
hint: Write a helper that returns the Pearson correlation of two lists, then loop over pairs with $j > i$.
hint: Correlation distance ignores the scale of a pattern: `[1, 2]` and `[10, 20]` are at distance 0.
solution: Correlate each pair of patterns after centering, subtract from 1, and walk the pairs row by row. The third and fourth tests check that scale does not matter and that perfectly anticorrelated patterns sit at the maximum distance 2; a Euclidean version would fail both.

model:
```python
import math


def _ranks(v):
    order = sorted(range(len(v)), key=lambda i: v[i])
    ranks = [0.0] * len(v)
    i = 0
    while i < len(v):
        j = i
        while j + 1 < len(v) and v[order[j + 1]] == v[order[i]]:
            j += 1
        for k in range(i, j + 1):
            ranks[order[k]] = (i + j) / 2 + 1
        i = j + 1
    return ranks


def spearman(a, b):
    """Spearman rank correlation with average ranks for ties."""
    ra, rb = _ranks(a), _ranks(b)
    n = len(ra)
    ma, mb = sum(ra) / n, sum(rb) / n
    num = sum((x - ma) * (y - mb) for x, y in zip(ra, rb))
    den = math.sqrt(sum((x - ma) ** 2 for x in ra)
                    * sum((y - mb) ** 2 for y in rb))
    return num / den
```
hint: Sort the indices by value, then give every run of equal values the average of its first and last rank.
hint: After ranking, the rest is an ordinary Pearson correlation.
solution: Ranking with averaged ties and then computing a Pearson correlation of the ranks is the definition. The tests with ties fail for a version that gives tied values consecutive ranks, and the monotonic test shows that only order matters, not scale.

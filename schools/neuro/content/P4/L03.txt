@article
A model unit that looks like a neuron proves little. A model that predicts what a neuron will do to images it has never seen is a claim you can test. An **encoding model** is a function from stimulus features to neural responses, and its evaluation on held-out data is the standard way to turn a resemblance into evidence. The reverse direction, a **decoding model** that predicts the stimulus from the responses, is the logic of multivariate pattern analysis (Haxby and colleagues, 2001). The two use the same regression tools but answer different questions: an encoding model says which features the responses carry and how; a decoder says what information could be read out.

### The linear encoding model

Let $\mathbf{X}$ be an $n \times p$ matrix of features (one row per stimulus, for example the activations of a network layer), and $\mathbf{y}$ the $n$ responses of one neuron or voxel. The **linear encoding model** is $\mathbf{y} = \mathbf{X}\mathbf{w} + \boldsymbol{\varepsilon}$, with noise $\boldsymbol{\varepsilon}$. Least squares minimizes $\|\mathbf{y} - \mathbf{X}\mathbf{w}\|^2$ and gives $\hat{\mathbf{w}} = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{y}$. With $p$ close to or larger than $n$, which is typical (thousands of units, hundreds of images), $\mathbf{X}^\top\mathbf{X}$ is singular or nearly so, and the fit memorizes the noise. **Ridge regression** shrinks the weights:

$$\hat{\mathbf{w}}_\lambda = (\mathbf{X}^\top\mathbf{X} + \lambda \mathbf{I})^{-1}\mathbf{X}^\top\mathbf{y}, \qquad \lambda \ge 0.$$

For one centered feature $x$ and centered $y$ this reduces to $\hat{w} = \sum_i x_i y_i / (\sum_i x_i^2 + \lambda)$, so $\lambda$ shrinks the slope toward zero. The penalty $\lambda$ is not learned from the training error, which would always prefer $\lambda = 0$; it is chosen by cross-validation. With one feature, the least-squares slope and intercept are $\hat{w} = \sum_i (x_i - \bar{x})(y_i - \bar{y})/\sum_i (x_i - \bar{x})^2$ and $\hat{b} = \bar{y} - \hat{w}\bar{x}$.

### Held-out evaluation

The quantity that matters is performance on stimuli the model did not see. Two summaries are common. The **held-out correlation** is the Pearson correlation between predictions and actual responses on the test stimuli, insensitive to the scale of the predictions. The **held-out explained variance** is

$$R^2_{\text{test}} = 1 - \frac{\sum_i (y_i - \hat{y}_i)^2}{\sum_i (y_i - \bar{y}_{\text{test}})^2},$$

with the sums over test stimuli and the mean taken over the test set. It can be negative: a model that predicts worse than the test-set mean has $R^2_{\text{test}} < 0$, which signals overfitting or a wrong model, and a negative value is informative, not a bug. In **$k$-fold cross-validation** the stimuli are split into $k$ folds; each fold is held out in turn, the model is fitted on the rest, predictions for the held-out fold are collected, and the metric is computed on all pooled predictions.

Raw $R^2_{\text{test}}$ also depends on how noisy the neuron is, so in practice it is reported relative to the **noise ceiling** (Week 11), the largest value any model could reach given the reliability of the data. A neuron with $R^2_{\text{test}} = 0.2$ may be nearly perfectly explained if its repeat reliability is itself near 0.2.

### Leakage and circularity

An evaluation is only as good as its separation of training and test. Typical failures:

- **Selecting hyperparameters on the test set**, such as $\lambda$, the layer or the number of units. Use nested cross-validation or a separate validation split.
- **Preprocessing on all the data**, for example standardizing features or removing components using the test stimuli too. Learn every transformation from the training set only.
- **Random folds on autocorrelated data.** In fMRI and in calcium imaging, neighboring time points share slow signals, so a test point has near-copies in the training set. Hold out contiguous blocks, runs or whole stimulus groups.
- **Selecting units or voxels with the same data used to test them.** Choosing the voxels with the largest response and then reporting how strongly they respond to the same data is circular analysis (Kriegeskorte and colleagues, 2009). Selection must be independent of the evaluation.
- **Near-duplicate stimuli** across train and test, such as frames from one video or views of the same object.

### Choosing features

The feature matrix defines the hypothesis. Features from a network layer, from a hand-built model (orientation filters, word frequency), or from a control (image luminance) can all be compared on the same held-out data. A feature set that adds explained variance beyond a control is evidence that the neurons carry something the control does not. Comparing nested feature sets on the same folds, with uncertainty over stimuli, is the standard design. In code researchers use libraries (for example, ridge solvers that fit every voxel at once), but you should be able to write one feature, one fold, and one metric by hand, which the exercises below do.

@example
title: A one-feature ridge slope
problem: A model unit has centered responses $x = (-1, 0, 1)$ to three images, and a neuron's centered responses are $y = (-2, 0, 3)$. Find the least-squares slope and the ridge slope for $\lambda = 2$.
step: Compute the sums: $\sum x_i y_i = 2 + 0 + 3 = 5$ and $\sum x_i^2 = 1 + 0 + 1 = 2$.
step: Least squares ($\lambda = 0$): $\hat{w} = 5/2 = 2.5$.
step: Ridge with $\lambda = 2$: $\hat{w}_\lambda = 5/(2 + 2) = 1.25$, half the least-squares slope.
step: Interpret: with $\lambda$ equal to $\sum x_i^2$, the penalty halves the slope; as $\lambda$ grows the slope tends to 0 and the prediction to the training mean.
answer: Least squares gives $2.5$ and ridge ($\lambda = 2$) gives $1.25$.

@mistakes
- Reporting training-set fit as evidence: with enough features any model fits the training responses.
- Choosing $\lambda$, the layer or the voxel set by looking at test performance, then reporting that same test performance.
- Using random folds on time series with slow signals, which places near-duplicates in training and test.
- Computing $R^2$ around the training mean for test data: the denominator should use the test mean (or state the convention), and negative values should be reported, not clipped.

model:
```python
def heldout_r2(x_train, y_train, x_test, y_test):
    """Held-out R^2 of a least-squares line fitted on the training data."""
    n = len(x_train)
    mx = sum(x_train) / n
    my = sum(y_train) / n
    sxx = sum((a - mx) ** 2 for a in x_train)
    sxy = sum((a - mx) * (b - my) for a, b in zip(x_train, y_train))
    w = sxy / sxx
    b = my - w * mx
    mt = sum(y_test) / len(y_test)
    sse = sum((y - (w * x + b)) ** 2 for x, y in zip(x_test, y_test))
    sst = sum((y - mt) ** 2 for y in y_test)
    return 1.0 - sse / sst
```
hint: Compute the slope and intercept from the training data only, then apply them to the test inputs.
hint: The denominator uses the mean of `y_test`, not the training mean.
solution: Fit the line on the training pairs, predict the test inputs, and compare the squared errors with the squared deviations of the test responses from their own mean. The third and fourth tests return negative values: a line fitted to noisy training data (or a constant) can predict the test data worse than the test mean does, and a version that clips at 0 fails them.

model:
```python
import math


def _fit(x, y):
    n = len(x)
    mx, my = sum(x) / n, sum(y) / n
    w = sum((a - mx) * (b - my) for a, b in zip(x, y))
    w /= sum((a - mx) ** 2 for a in x)
    return w, my - w * mx


def kfold_corr(x, y, k):
    """Cross-validated correlation between pooled predictions and responses."""
    n = len(x)
    m = n // k
    preds = [0.0] * n
    for f in range(k):
        test = set(range(f * m, (f + 1) * m))
        tr = [i for i in range(n) if i not in test]
        w, b = _fit([x[i] for i in tr], [y[i] for i in tr])
        for i in test:
            preds[i] = w * x[i] + b
    mp, my = sum(preds) / n, sum(y) / n
    num = sum((p - mp) * (t - my) for p, t in zip(preds, y))
    den = math.sqrt(sum((p - mp) ** 2 for p in preds)
                    * sum((t - my) ** 2 for t in y))
    return num / den
```
hint: Build a list of training indices that excludes the held-out block, fit on those, and write the predictions into a list at the held-out positions.
hint: Compute the correlation only once, on the pooled predictions, not per fold.
solution: Each fold is predicted by a model that never saw it, and the predictions are pooled before one correlation is computed. Because the last test uses an erratic response series, the cross-validated correlation is near zero or negative, unlike the in-sample correlation, which a fit-on-everything version would report as positive.

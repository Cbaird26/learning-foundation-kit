@article
A trained recurrent network is a black box with a few hundred or thousand moving parts. Reading its weight matrix is hopeless, and reading single units gives a confusing mixture. **Dynamical systems analysis** replaces both with a short question: where does the population state go, and what organizes its trajectories? This is the approach of Sussillo and Barak (2013), who showed how to find a trained network's fixed points numerically and to linearize the dynamics around them, and it is the bridge used by Mante, Sussillo, Shenoy and Newsome (2013) between a network and recorded populations.

### Fixed points and their stability

Write the network in discrete time as $\mathbf{x}_{t+1} = F(\mathbf{x}_t)$ (the Euler step of Week 5 with $\Delta t = \tau$ gives $F(\mathbf{x}) = \mathbf{W}\varphi(\mathbf{x}) + \mathbf{b}$, and the next section uses $F(\mathbf{x}) = \tanh(\mathbf{W}\mathbf{x} + \mathbf{b})$). A **fixed point** satisfies $\mathbf{x}^* = F(\mathbf{x}^*)$. Whether it attracts nearby states depends on the **Jacobian** $\mathbf{J} = \partial F/\partial \mathbf{x}$ at $\mathbf{x}^*$. A small deviation $\boldsymbol{\delta}$ evolves as $\boldsymbol{\delta}_{t+1} \approx \mathbf{J}\boldsymbol{\delta}_t$, so the fixed point is stable if every eigenvalue of $\mathbf{J}$ has magnitude less than 1 (the spectral radius is below 1), and unstable if some eigenvalue has magnitude above 1. In continuous time, $\tau\,d\mathbf{x}/dt = F(\mathbf{x}) - \mathbf{x}$, the condition is that every eigenvalue of $\mathbf{J} - \mathbf{I}$ has negative real part. For one unit $x \leftarrow \tanh(wx + b)$ the Jacobian is $w(1 - \tanh^2(wx^*+b)) = w(1 - x^{*2})$.

A scalar example: $x \leftarrow \tanh(1.5x)$. The origin is a fixed point with derivative $1.5 > 1$, so it is unstable; two further fixed points sit near $\pm 0.8586$, where the derivative is $1.5(1 - 0.8586^2) \approx 0.394 < 1$, so they are stable. This is a **bistable** memory: a unit starting slightly positive goes to $+0.86$ and stays, a unit starting slightly negative goes to $-0.86$. One bit is stored in the sign.

### Slow modes and line attractors

Near-unit eigenvalues mean slow dynamics. For a linear mode $\tau\,dx/dt = -x + wx$, the deviation decays as $e^{-t/\tau_{\text{eff}}}$ with $\tau_{\text{eff}} = \tau/(1 - w)$. With $\tau = 10$ ms and $w = 0.8$, $\tau_{\text{eff}} = 50$ ms; with $w = 0.99$ it is 1 s. A mode with $w = 1$ exactly is an integrator: it keeps whatever value it is given, and a line of such modes is a **line attractor**. Real circuits cannot be tuned to exactly 1 by chance, which is why the tuning problem is a central question about integrator models: with $w$ off by a percent, memory leaks or runs away on the scale of seconds. Slow effective time constants built from fast neurons are the second major use of recurrence, after pattern completion.

### A tiny timing task

Interval timing tasks require an output at a fixed delay after a cue. In a minimal version, a cue pulse arrives at $t = 0$ and the network must output a signal that rises from 0 and reaches 1 at $T = 100$ ms, then stays. A few recurrent units trained by gradient descent through time on a squared-error loss (compare the output with the target ramp at every time step) typically find one of two solutions: a state that **ramps** along a slow direction, so the readout is a fixed threshold on a one-dimensional trajectory, or a state that moves along a **trajectory through many dimensions** with the readout picking out a fixed point in time. Both solve the task. Analyses that distinguish them examine the population trajectory, fixed points, and what happens when the input timing or interval is changed (does the network generalize to $T = 150$ ms, and how, by speed or by new trajectories?). Whether biological timing relies on ramping, trajectories, or both is not settled.

### From network to data

Analyses of this kind run on recordings too. **Principal component analysis** of population activity (rows are time points and conditions, columns are neurons) gives a few directions that capture most variance, and the trajectories projected on them can be compared with those in a trained network; Mante and colleagues used a targeted version that finds axes for choice, stimulus and context. The comparisons must be validated: dimensionality reduction can produce smooth, rotating-looking trajectories from many kinds of random signals, so trajectories need a null model, such as shuffled data with the same single-neuron statistics.

@example
title: Finding and testing a fixed point
problem: Consider the scalar map $x \leftarrow \tanh(0.5x + 0.8)$. Iterate it from $x_0 = 0$ for a few steps, estimate the fixed point, and test its stability.
step: Iterate: $x_1 = \tanh(0.8) \approx 0.664$; $x_2 = \tanh(0.5 \times 0.664 + 0.8) = \tanh(1.132) \approx 0.812$; $x_3 = \tanh(1.206) \approx 0.836$.
step: The iterates converge, and continuing gives $x^* \approx 0.8396$, which satisfies $x^* = \tanh(0.5 x^* + 0.8)$.
step: Compute the Jacobian at the fixed point: $J = 0.5(1 - x^{*2}) = 0.5(1 - 0.7049) \approx 0.148$. Since $|J| < 1$, the fixed point is stable.
step: Interpret: each step shrinks a small deviation by a factor $0.148$, so the iteration converges quickly, which is why only about five iterations were needed.
answer: $x^* \approx 0.840$, stable with $J \approx 0.148$.

@mistakes
- Testing stability by the size of the weights alone: it is the Jacobian, which includes the slope of the nonlinearity at the fixed point, that matters.
- Mixing discrete and continuous conventions: in discrete time stability needs $|\lambda| < 1$, while in continuous time it needs the real parts of the eigenvalues of $\mathbf{J} - \mathbf{I}$ to be negative.
- Assuming that undamped iteration finds every fixed point: unstable fixed points repel iteration, and a map with $|J| > 1$ may oscillate or cycle (damping or a root finder is needed).
- Reading smooth low-dimensional trajectories in a PCA plot as evidence of a specific dynamical mechanism without a null model.

model:
```python
import math


def find_fixed_point(W, b, x0, tol, max_iter, alpha):
    """Damped fixed-point iteration for x = tanh(W x + b)."""
    x = list(x0)
    n = len(x)
    for count in range(max_iter):
        fx = [math.tanh(sum(W[i][j] * x[j] for j in range(n)) + b[i])
              for i in range(n)]
        if max(abs(fx[i] - x[i]) for i in range(n)) < tol:
            return x, count
        x = [x[i] + alpha * (fx[i] - x[i]) for i in range(n)]
    return x, max_iter
```
hint: Compute $F(\mathbf{x})$ at the top of each loop, test the residual, and only then update.
hint: With $\alpha < 1$ the update is a weighted average of the old state and $F(\mathbf{x})$, which tames maps whose slope is below $-1$.
solution: Each pass computes the residual, stops if it is small and otherwise moves a fraction `alpha` of the way to $F(\mathbf{x})$. The single unit with $w = -2$ has slope $-2$ at its fixed point $0$, so undamped iteration cycles forever (the cap is reached), while $\alpha = 0.5$ gives an effective slope of $0.5 + 0.5(-2) = -0.5$ and converges.

model:
```python
import math


def jacobian_radius(W, b, x):
    """Spectral radius of the Jacobian of tanh(W x + b) at x (1 or 2 units)."""
    n = len(x)
    y = [math.tanh(sum(W[i][j] * x[j] for j in range(n)) + b[i])
         for i in range(n)]
    J = [[(1 - y[i] ** 2) * W[i][j] for j in range(n)] for i in range(n)]
    if n == 1:
        return abs(J[0][0])
    tr = J[0][0] + J[1][1]
    det = J[0][0] * J[1][1] - J[0][1] * J[1][0]
    disc = tr * tr - 4 * det
    if disc < 0:
        return math.sqrt(det)
    d = math.sqrt(disc)
    return max(abs((tr + d) / 2), abs((tr - d) / 2))
```
hint: Compute $\mathbf{y}$ first, then scale row $i$ of $\mathbf{W}$ by $1 - y_i^2$.
hint: The eigenvalues of a 2 by 2 matrix are $(\mathrm{tr} \pm \sqrt{\mathrm{tr}^2 - 4\det})/2$. When the discriminant is negative they are a complex pair with product $\det$, so each has magnitude $\sqrt{\det}$.
solution: The Jacobian is the weight matrix with each row scaled by the slope of the nonlinearity at that unit. The rotation-like matrix in the third test has eigenvalues $\pm i$, so a version that takes only real parts of the eigenvalues returns 0 instead of 1.

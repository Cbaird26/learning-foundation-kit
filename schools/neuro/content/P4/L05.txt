@article
A feedforward network maps an input to an output once. Brains do not work that way: cortex is dense with recurrent connections, a delay in the middle of a trial has consequences later, and a memory held for ten seconds has no input to hold it. Recurrent networks are the main models of this temporal, self-sustaining side of cognition, and they come in three generations.

### Attractor memories

The **Hopfield network** (1982) has $N$ binary units $s_i = \pm 1$ with symmetric weights and no self-connection. To store patterns $\boldsymbol{\xi}^\mu$ it uses the Hebbian outer-product rule

$$W_{ij} = \frac{1}{N}\sum_{\mu} \xi^\mu_i \xi^\mu_j \quad (i \ne j), \qquad W_{ii} = 0.$$

Each unit updates to the sign of its net input $h_i = \sum_j W_{ij} s_j$. With symmetric weights, asynchronous updates never increase the **energy** $E = -\tfrac{1}{2}\sum_{i \ne j} W_{ij}s_i s_j$, so the state descends into a local minimum, and stored patterns are (approximately) such minima. A degraded cue is thereby completed into the nearest stored memory: content-addressable memory. For random patterns, recall degrades once the number of patterns exceeds roughly $0.14\,N$. The picture of memory as an **attractor**, a stable state of the dynamics, was a model of persistent activity during working-memory delays.

### Simple recurrent networks

Elman (1990) added context units that copy the previous hidden state, giving a network whose output depends on the past. Trained to predict the next element of a sequence of words, such a **simple recurrent network** developed hidden states whose similarity structure reflected word categories, without a built-in grammar. This showed that structure useful for language could emerge from prediction in a recurrent system; it did not show that people learn language this way, a claim on which researchers disagree.

### Continuous-time rate networks

The workhorse of modern modeling is the **rate network**

$$\tau \frac{d\mathbf{x}}{dt} = -\mathbf{x} + \mathbf{W}\,\varphi(\mathbf{x}) + \mathbf{B}\,\mathbf{u}(t), \qquad \mathbf{z}(t) = \mathbf{C}\,\varphi(\mathbf{x}(t)),$$

with units' state $\mathbf{x}$, nonlinearity $\varphi$ (for example $\tanh$), input $\mathbf{u}$ and readout $\mathbf{z}$. Early forms of this idea include the Wilson–Cowan equations (1972) for coupled excitatory and inhibitory populations. One Euler step of size $\Delta t$ is $\mathbf{x} \leftarrow \mathbf{x} + (\Delta t/\tau)(-\mathbf{x} + \mathbf{W}\varphi(\mathbf{x}) + \mathbf{B}\mathbf{u})$. In **trained recurrent networks** the weights are not designed but learned, by gradient descent through time, so that the readout produces the correct output on a task. The network is then studied like a preparation: what activity does it use, what are its fixed points, what does perturbation do (Week 6).

### Ways to hold information

- **Point attractors** (as in Hopfield memories) store a discrete item; a held category is a stable state.
- **Line attractors** (an integrator) have a continuous line of marginally stable states along which activity can be set and then stays: this can hold an analog value, such as a remembered eye position, and, driven by input, accumulate evidence.
- **Ring attractors** hold a circular variable, such as a heading direction.
- **Dynamic or activity-silent coding.** Memory need not be a static persistent state. Information may be carried by changing activity patterns, or by short-term synaptic changes with little spiking in the delay; experiments in this area are debated, and several mechanisms may coexist.

### Networks as models of cognitive tasks

A landmark example is Mante, Sussillo, Shenoy and Newsome (2013). Monkeys judged either the motion or the color of a random-dot display depending on a context cue, and recordings in prefrontal cortex showed that single neurons mix the relevant and irrelevant signals in complicated ways. A recurrent network trained on the same task reproduced much of this mixing, and analyzing the network's dynamics suggested that the irrelevant input is represented but does not drive the choice axis, with selection arising inside the circuit's dynamics rather than at the input. The result is a good model of method: use a trained network to generate a hypothesis about population dynamics, then test the hypothesis on the data. Its interpretation, and how general it is, remain discussed.

The central caution: **trained networks are underdetermined.** Different initializations, regularizers, training curricula and architectures reach the same behavior with different internal solutions, and a network matching single-neuron statistics can do so for the wrong reasons. A trained network is a hypothesis generator and a proof of sufficiency (a network of this kind can solve the task), not evidence that the brain uses that solution.

@example
title: Recalling a Hopfield memory from a corrupted cue
problem: A Hopfield network with $N = 4$ units stores the single pattern $\boldsymbol{\xi} = (1, -1, 1, 1)$. It starts in the corrupted state $\mathbf{s} = (1, 1, 1, 1)$. Show that updating unit 2 repairs it.
step: Build the weights: $W_{ij} = \xi_i \xi_j/4$ for $i \ne j$ and $W_{ii} = 0$. In particular $W_{21} = (-1)(1)/4 = -0.25$, $W_{23} = -0.25$ and $W_{24} = -0.25$.
step: Compute the net input to unit 2: $h_2 = W_{21}s_1 + W_{23}s_3 + W_{24}s_4 = -0.25 \times 3 = -0.75$.
step: Update: $s_2 \leftarrow \mathrm{sign}(-0.75) = -1$. The state becomes $(1, -1, 1, 1)$, equal to the stored pattern.
step: Check stability: for unit 1, $h_1 = W_{12}s_2 + W_{13}s_3 + W_{14}s_4 = 0.25(-1)(-1) + 0.25 + 0.25 = 0.75 > 0$, so it stays $+1$; the stored pattern is a fixed point.
answer: Unit 2 flips to $-1$, completing the pattern $(1, -1, 1, 1)$, which is then stable.

@mistakes
- Thinking of an attractor as a state the network is forced into: it is a state the dynamics settle into and stay in unless perturbed.
- Forgetting the zero diagonal in the Hopfield weights, which makes each unit's own state contribute to its input.
- Treating a trained network that reproduces the data as proof that the brain implements its solution: several solutions can fit equally well.
- Equating persistent activity with working memory: the delay could be bridged by dynamics or by synaptic changes.

@practice ms
prompt: Which of the following are stable-state structures used in models of persistent neural activity?
choice*: A point attractor, which holds one of a discrete set of items.
choice*: A line attractor, along which activity can be set to hold a continuous value.
choice*: A ring attractor, which holds a circular variable such as heading.
choice: A repelling fixed point, which holds nearby states in place.
hint: A stored state must keep nearby states near it, or move them only along the set of stored states.
solution: Point, line and ring attractors are the standard memory structures. A repelling (unstable) fixed point pushes nearby states away and cannot hold information against noise.

@practice self
prompt: Two recurrent networks, trained on the same delayed-match task with different initial weights, both reach 98% accuracy and both reproduce the mixed selectivity of recorded prefrontal neurons. Their fixed-point structures differ. Explain what this implies for the claim that "the network reveals how cortex solves the task", and propose two analyses or experiments that could discriminate among candidate solutions.
hint: Ask what a match to behavior and to single-neuron statistics rules out, and what it leaves open; then look for a measurement on which the two networks must differ.
solution: It implies that the task and the neural statistics underdetermine the solution: matching behavior and single-neuron statistics is a necessary condition, not a sufficient one, so the networks establish that a recurrent circuit of this kind can solve the task and generate hypotheses, but they do not identify the solution cortex uses. The claim should be reworded as a hypothesis with predictions. Two discriminating tests. First, dynamics on the population level: compare how the population state evolves across conditions in the data and in each network, for example by aligning the data and the network states with a cross-validated linear mapping and asking which network explains held-out trial trajectories and the geometry of the delay-period states (static versus changing codes) better; the two networks are likely to disagree on cross-time generalization of a decoder, which is a measurable difference. Second, perturbation: inactivate or stimulate a defined subspace or time window in the network and in the animal (for example, optogenetic silencing during the delay) and compare the predicted behavioral and neural effects; a line attractor and a transient dynamic code predict different recoveries from a brief perturbation, since the first drifts permanently along the line and the second recovers along its trajectory. Both need pre-specified predictions and held-out data, and the networks must be compared with each other and with control models, not only with the null.
rubric: States that matching behavior and single-neuron statistics is necessary but not sufficient, so solutions are underdetermined.
rubric: Proposes a population-level comparison on held-out data (for example, cross-time decoding or trajectory comparison) that separates the networks.
rubric: Proposes a perturbation experiment or simulation whose predicted outcomes differ between the candidate solutions.

@quiz num
prompt: A Hopfield network with $N = 4$ units stores the two patterns $(1, 1, -1, -1)$ and $(1, -1, 1, -1)$ with $W_{ij} = \frac{1}{N}\sum_\mu \xi^\mu_i\xi^\mu_j$ for $i \ne j$ and $W_{ii} = 0$. What is the energy $E = -\frac{1}{2}\sum_{i \ne j}W_{ij}s_is_j$ of the state $\mathbf{s} = (1, -1, 1, -1)$?
answer: -1
check: -sum(sum(p[i] * p[j] for p in [(1, 1, -1, -1), (1, -1, 1, -1)]) / 4 * s[i] * s[j] for i in range(4) for j in range(i + 1, 4) for s in [(1, -1, 1, -1)])
hint: Only $W_{14}$ and $W_{23}$ are nonzero; compute them first. Summing over $i \ne j$ counts each pair twice, so $E = -\sum_{i<j}W_{ij}s_is_j$.
solution: $W_{14} = \frac{1}{4}[(1)(-1) + (1)(-1)] = -0.5$ and $W_{23} = \frac{1}{4}[(1)(-1) + (-1)(1)] = -0.5$; every other off-diagonal weight is $0$. For $\mathbf{s} = (1, -1, 1, -1)$ we have $s_1s_4 = -1$ and $s_2s_3 = -1$, so $E = -[(-0.5)(-1) + (-0.5)(-1)] = -1$.

@quiz self
prompt: Design an experiment, in a species and with a method of your choice, to distinguish persistent-activity (attractor) working memory from an activity-silent mechanism in a delay task. State the prediction of each account for your key measurement and say what result would embarrass each.
hint: Think about what each account predicts for spiking during the delay and for the response to a nonspecific probe or perturbation late in the delay.
solution: Task: a delayed match-to-sample with a 4 s delay and a variable stimulus, with neural population recordings (Neuropixels-type probes or two-photon imaging) in a prefrontal or parietal region of a monkey or mouse. Key measurements: (a) a decoder of the remembered item trained on early delay and tested at several late delay times, and (b) the effect of a brief, nonspecific perturbation or probe (a weak optogenetic pulse, or a task-irrelevant stimulus) late in the delay on the decodability of the item afterward. Persistent-activity account: the item is decodable from spiking throughout the delay with cross-time generalization (a static code); the nonspecific pulse should be absorbed with the item remaining (the attractor is stable) unless the perturbation moves the state across a basin boundary, in which case the memory is lost abruptly. Activity-silent account: spiking carrying the item decays during the delay, so decoding from spikes falls toward chance for a period, while the item is stored in synaptic state; the nonspecific pulse should reactivate the item in the spiking pattern ("ping"), and decoding after the pulse should recover. Results that would count against each: for the persistent-activity account, a late-delay decoder at chance from spiking while the animal still performs well, and an item that reappears after a nonspecific pulse; for the activity-silent account, stable, high-accuracy spiking decoding throughout the delay, with the pulse adding nothing. A decoder at chance during the delay with no recovery after the probe would embarrass both, since the animal needs the item to perform. I would pre-register the decoder windows and the null, since several mechanisms may coexist across regions.
rubric: Defines a measurement (cross-time decoding and a perturbation or probe) with distinct predictions for the two accounts.
rubric: States concrete predictions for each account and a result that would count against each.
rubric: Acknowledges the possibility that both mechanisms coexist and that the analysis plan must be fixed in advance.

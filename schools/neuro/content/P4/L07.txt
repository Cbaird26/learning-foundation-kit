@article
Reinforcement learning is the second great exchange between machine learning and neuroscience. Animal learning theory gave it the idea of learning from reward; computer science gave it a precise algorithm; and recordings of dopamine neurons suggested that the brain computes the quantity the algorithm needs.

### Value and the temporal-difference error

An agent moves through states and receives rewards $r_t$. The **value** of a state is the expected discounted sum of future reward, $V(s) = \mathbb{E}\big[\sum_{k \ge 0} \gamma^k r_{t+k} \mid s_t = s\big]$, with discount factor $0 \le \gamma \le 1$. Value satisfies a recursion, $V(s_t) = \mathbb{E}[r_t + \gamma V(s_{t+1})]$, so an estimate $V$ is wrong exactly when it violates the recursion. The **temporal-difference (TD) error** is the violation observed on one step:

$$\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t),$$

with $V = 0$ for the state after the end of a trial. The **TD(0)** update (Sutton, 1988) moves the value toward its target: $V(s_t) \leftarrow V(s_t) + \alpha\,\delta_t$, with learning rate $\alpha$. It *bootstraps*: the target uses the current estimate of the next state's value, so learning can propagate backward from reward to the cues that predict it, without waiting for the trial to end. The **Rescorla–Wagner model** (1972) is the special case of a single step: $V \leftarrow V + \alpha(\lambda - V)$, with $\lambda$ the reward received; TD learning extends it over time within a trial.

### Dopamine neurons and the prediction error

Schultz, Dayan and Montague (1997) proposed that the phasic firing of midbrain dopamine neurons, recorded in monkeys during conditioning, reports a TD error. Three signatures follow, and each matches a reported pattern.

| situation | TD error | dopamine neuron firing |
|---|---|---|
| unpredicted reward | $\delta > 0$ (value of the reward state was 0) | burst at the reward |
| reward fully predicted by a cue | $\delta = 0$ at the reward; $\delta > 0$ at the cue, whose onset is unpredicted | burst moves from reward to cue |
| predicted reward omitted | $\delta < 0$ | dip below baseline at the time the reward was due |

Later work showed that this account explains a great deal, in particular the dependence of dopamine signals on prediction and the causal role of dopamine in learning (shown with optogenetic stimulation in later studies, whose details you should read in the primary literature). It is not complete. Dopamine neurons are diverse; dopamine release is also related to movement, novelty, salience and the vigor of action; slowly ramping dopamine signals appear in some tasks; and the interpretation of these signals is actively debated. Treat "dopamine encodes reward prediction error" as a successful quantitative account of one major signal, not a complete theory of dopamine.

### Distributional reinforcement learning

A scalar value hides the shape of the reward distribution. In distributional reinforcement learning, a population of predictors learns different summaries of the same distribution. A simple version uses asymmetric learning rates: each predictor updates $V \leftarrow V + \alpha^+\delta$ when $\delta > 0$ and $V \leftarrow V + \alpha^-\delta$ when $\delta < 0$. It converges to a value where positive and negative errors balance, the **expectile** of the reward distribution with $\tau = \alpha^+/(\alpha^+ + \alpha^-)$; $\tau > 0.5$ is an optimistic predictor, $\tau < 0.5$ a pessimistic one. For two equally likely rewards $0$ and $R$ the fixed point solves $\alpha^+(R - V)\cdot\frac12 = \alpha^- V\cdot\frac12$, giving $V = \tau R$. Dabney and colleagues (2020) reported that dopamine neurons in mice differ in the reward size at which they switch from dip to burst, and that the pattern of differences matches predictors with different asymmetries; the finding supports a distributional code for value, though how the rest of the brain reads such a code is open.

### What remains open

Which circuits learn what: the striatum's roles in learning values of states versus actions; how to combine fast habitual (model-free) and deliberative (model-based) control; how dopamine's different timescales and targets divide the work; and how credit is assigned over long delays. These are research questions, and models that explain one signal are tested against the others.

@example
title: TD errors across a conditioning trial
problem: A trial has an inter-trial state ITI (value 0, since the cue's timing is unpredictable), then a cue state C, then a delay state D, after which a reward of $1$ is delivered and the trial ends. Use $\gamma = 1$. After learning, $V(C) = V(D) = 1$. Compute the TD error at the cue onset (ITI to C), at C to D, at the reward, and when the reward is omitted.
step: Cue onset: $\delta = 0 + V(C) - V(\text{ITI}) = 1 - 0 = 1$. The cue is unpredicted, so there is a positive error.
step: From C to D: $\delta = 0 + V(D) - V(C) = 1 - 1 = 0$. Nothing new is learned between predictable states.
step: At the reward: $\delta = 1 + 0 - V(D) = 1 + 0 - 1 = 0$. The reward was fully predicted.
step: Omission: $\delta = 0 + 0 - V(D) = -1$, a negative error at the time the reward was due. These three results are the three signatures in the table.
answer: $\delta = 1$ at the cue, $0$ in the delay and at a delivered reward, and $-1$ when the reward is omitted.

@mistakes
- Forgetting that the value of the terminal state is zero: the last step of a trial has $\delta = r - V(s)$.
- Updating the value of the next state, not the current one: TD(0) changes $V(s_t)$, using $V(s_{t+1})$ only in the target.
- Saying that dopamine neurons signal reward: they signal reward relative to prediction, so a fully expected reward produces no burst.
- Claiming that dopamine only encodes prediction error: it is a well-supported account of an important signal, not an account of everything dopamine does.

@practice num
prompt: A population of asymmetric predictors updates $V \leftarrow V + \alpha^+\delta$ for $\delta > 0$ and $V \leftarrow V + \alpha^-\delta$ for $\delta < 0$. A predictor with $\alpha^+ = 0.6$ and $\alpha^- = 0.2$ experiences rewards of $0$ or $10$ with equal probability, over many trials. To what value does $V$ converge on average?
answer: 7.5
tol: 0.01
check: 10 * 0.6 / (0.6 + 0.2)
hint: At the fixed point, the average positive update balances the average negative one.
solution: At the fixed point $\alpha^+ \cdot \tfrac{1}{2}(10 - V) = \alpha^- \cdot \tfrac{1}{2}V$, so $V = 10\,\alpha^+/(\alpha^+ + \alpha^-) = 10 \times 0.75 = 7.5$, an optimistic estimate above the mean of 5.

model:
```python
def td_errors(V, states, rewards, gamma):
    """TD error for each step of a trial; the final next state is terminal."""
    errors = []
    for t, s in enumerate(states):
        next_v = V[states[t + 1]] if t + 1 < len(states) else 0.0
        errors.append(rewards[t] + gamma * next_v - V[s])
    return errors
```
hint: For each step, look up the next state's value only if there is a next state; otherwise use 0.
solution: Each error compares the reward plus the discounted value of the next state with the value of the current state. The final step has no successor, so its target is just the reward, which the omitted-reward test checks (a version that wraps around to the first state fails it).

model:
```python
def td0_chain(n, trials, alpha, gamma):
    """Online TD(0) on a chain with reward 1 at the end of each trial."""
    V = [0.0] * n
    for _ in range(trials):
        for s in range(n):
            next_v = V[s + 1] if s + 1 < n else 0.0
            reward = 1.0 if s == n - 1 else 0.0
            V[s] += alpha * (reward + gamma * next_v - V[s])
    return V
```
hint: Update `V[s]` immediately inside the loop over steps, so that the next step sees the new value.
hint: The last state's successor is terminal, with value 0.
solution: Online updates mean that within the second trial the value gained by the last state in the first trial is available one step earlier, so reward information moves back one state per trial. A version that computes all errors from the values at the start of a trial (a batch update) gives different numbers and fails the first two tests.

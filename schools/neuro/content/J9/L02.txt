@article
A **variable** is a name attached to a value, like a label on a box. You create one with **assignment**, using a single `=`:

```python
cm = 254
inches = cm / 2.54
print(inches)
```

Read `=` as "gets" or "is set to", not as "equals". Python works out the right side first, then attaches the name on the left to the result. This program prints `100.0`.

### Changing variables

A variable can be reassigned, and the new value can use the old one:

```python
score = 10
score = score + 5
print(score)   # 15
```

When Python reaches `score = score + 5`, it computes `10 + 5` using the old value and then stores `15` under the name `score`. If you copy one variable into another (`b = a`), later changes to `a` do not change `b`.

### Naming rules

A name may contain letters, digits and underscores, but it cannot start with a digit, cannot contain spaces or hyphens, and cannot be a Python keyword such as `class` or `if`. Capital letters matter: `Score` and `score` are different names. By convention, Python programmers write names in lowercase with underscores, such as `total_price`, and choose names that say what the value is.

### Types

Every value has a **type**:

| Type | Meaning | Examples |
|---|---|---|
| `int` | whole number | `7`, `-3`, `0` |
| `float` | number with a decimal point | `2.5`, `4.0`, `-0.1` |
| `str` | text (a string) | `"hi"`, `'7'`, `""` |
| `bool` | true or false | `True`, `False` |

The function `type(x)` tells you which one a value has, so `type(3.0)` is `<class 'float'>`. Types matter because they decide what an operation does: `3 + 4` is `7`, but `"3" + "4"` is the string `"34"`.

### Converting types

Use `int()`, `float()` and `str()` to convert:

```python
text = "12"
number = int(text)    # 12, an int
print(number * 2)     # 24
print(str(5) + "!")   # 5!
```

`int("3.7")` is an error, because `"3.7"` is not a whole number; use `int(float("3.7"))` or just `float("3.7")`. Converting a float with `int()` throws away the decimal part: `int(3.9)` is `3`.

@example
title: Following a variable
problem: What does this program print?

```python
a = 4
b = a
a = a * 3
print(a, b)
```
step: `a = 4` makes `a` hold `4`.
step: `b = a` copies the value `4` into `b`. The two variables do not stay linked.
step: `a = a * 3` computes `4 * 3 = 12` and stores it in `a`. The variable `b` is still `4`.
step: `print(a, b)` shows `12 4`.
answer: `12 4`

@example
title: A kilometers-to-meters converter
problem: Write a program that stores a distance of 3.5 kilometers in a variable and prints it in meters.
step: Store the distance with a clear name: `km = 3.5`.
step: One kilometer is 1000 meters, so multiply: `meters = km * 1000`.
step: Print the result:

```python
km = 3.5
meters = km * 1000
print(meters)
```
step: The program prints `3500.0`, a float, because `km` is a float. To show a whole number, use `print(int(meters))`.

@mistakes
- Reading `=` as "equals". It means "store the value on the right under the name on the left".
- Adding a number and a string: `"Age: " + 12` is an error, but `"Age: " + str(12)` works.
- Starting a name with a digit (`2nd_place`) or using a hyphen (`my-score`).
- Expecting `int(3.9)` to round: it cuts off the decimal part and gives `3`.

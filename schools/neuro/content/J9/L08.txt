@article
A `while` loop repeats until a condition fails. When you already know how many times to repeat, or what you want to loop over, a **`for` loop** is shorter and safer, because Python does the counting for you.

```python
for i in range(3):
    print("Hello", i)
```

This prints `Hello 0`, `Hello 1` and `Hello 2`. The variable `i` is the **loop variable**: on each pass it takes the next value.

### range

`range` produces a sequence of whole numbers:

| Call | Numbers produced |
|---|---|
| `range(4)` | `0, 1, 2, 3` |
| `range(2, 6)` | `2, 3, 4, 5` |
| `range(0, 10, 3)` | `0, 3, 6, 9` |
| `range(5, 0, -1)` | `5, 4, 3, 2, 1` |

The **stop** value is never included, just like the end of a slice. `range(4)` has four numbers, starting at 0. The third value is the **step**, and a negative step counts down. To include the number `n`, use `range(1, n + 1)`.

### Looping over a string

A `for` loop can also go through the characters of a string, one at a time:

```python
for letter in "cat":
    print(letter)
```

This prints `c`, `a` and `t` on separate lines.

### Accumulating in a for loop

The totals and counters from the `while` lesson work in a `for` loop too:

```python
total = 0
for n in range(1, 6):
    total += n
print(total)   # 15
```

### for or while?

Use `for` when the number of repetitions is known or you are going through a collection. Use `while` when you repeat until something happens, such as the user typing a stop word.

### Nested loops

A loop inside a loop is a **nested loop**. The inner loop runs completely for every pass of the outer loop. Nested loops print tables and patterns:

```python
for row in range(1, 4):
    for col in range(1, 4):
        print(row * col, end=" ")
    print()
```

This prints a small multiplication table:

```text
1 2 3
2 4 6
3 6 9
```

The inner `print(row * col, end=" ")` keeps everything on one line, and the lone `print()` after the inner loop starts a new line after each row.

@example
title: Tracing a star triangle
problem: What does this program print?

```python
for i in range(1, 4):
    print("*" * i)
```
step: `range(1, 4)` gives `1`, `2` and `3`, so the loop runs three times.
step: When `i` is `1`, `"*" * 1` is `*`. When `i` is `2`, it is `**`.
step: When `i` is `3`, it is `***`, and then the loop is finished.
step: The output is a small triangle of three lines.
answer: `*`, `**`, `***`

@example
title: A table of squares
problem: Print the squares of 1 to 5 in the form `3 squared is 9`.
step: The numbers 1 to 5 come from `range(1, 6)`, because the stop value is not included.
step: For each number, print it with its square, using an f-string:

```python
for n in range(1, 6):
    print(f"{n} squared is {n * n}")
```
step: The first line is `1 squared is 1` and the last one is `5 squared is 25`.

@mistakes
- Expecting `range(1, 5)` to include 5. It stops at 4.
- Forgetting that `range(5)` starts at 0, so a loop that should print 1 to 5 prints 0 to 4.
- Changing the loop variable inside the loop and expecting that to change the next value, which `range` decides by itself.
- Leaving out the lone `print()` after an inner loop, so all the rows run together on one line.

answer: 12

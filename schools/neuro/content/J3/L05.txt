@article
A **linear function** has a constant rate of change. Its graph is a straight line and its rule can be written in **slope-intercept form**
$$y = mx + b,$$
where $m$ is the **slope** and $b$ is the **$y$-intercept**, the value of $y$ when $x = 0$ (the point $(0, b)$ where the line crosses the $y$-axis).

### Reading the rule

In $y = 2x + 3$, the slope is $2$: each time $x$ goes up by $1$, $y$ goes up by $2$. The $y$-intercept is $3$: when $x = 0$, $y = 3$. To find $y$ for a given $x$, substitute. At $x = 4$: $y = 2(4) + 3 = 11$.

### Writing an equation

**From the slope and the $y$-intercept:** just fill in $m$ and $b$. Slope $-2$ and $y$-intercept $5$ give $y = -2x + 5$.

**From the slope and one point:** use the point to find $b$. If $m = 3$ and the line passes through $(2, 7)$, then $7 = 3(2) + b$, so $b = 1$ and $y = 3x + 1$.

**From two points:** first compute the slope, then use one point to find $b$. For $(1, 5)$ and $(3, 11)$: $m = \frac{11 - 5}{3 - 1} = 3$. Then $5 = 3(1) + b$ gives $b = 2$, so $y = 3x + 2$.

### Modeling

Many real situations are linear. A taxi charges a fixed fee of \$3 and \$2 per mile. The cost after $m$ miles is $C = 2m + 3$. The **rate** \$2 per mile is the slope; the **starting value** \$3 is the intercept.

A relationship with $b = 0$, such as $y = 3x$, is called **proportional**: its graph passes through the origin. A relationship like $y = 3x + 1$ is linear but not proportional.

### Is a table linear?

Check the rate of change between consecutive rows. If $\frac{\Delta y}{\Delta x}$ is the same everywhere, the table is linear. For $x = 0, 1, 2, 3$ and $y = 4, 7, 10, 13$, each step adds $3$, so $y = 3x + 4$.

### Using the model

Once you have the equation you can predict. Substituting an $x$ gives $y$. To find the $x$ that gives a particular $y$, set the rule equal to that value and solve, using the equation skills from earlier weeks.

@example
title: From two points to an equation
problem: A line passes through $(0, 4)$ and $(2, 10)$. Write its equation and find $x$ when $y = 22$.
step: The point $(0, 4)$ is on the $y$-axis, so the $y$-intercept is $b = 4$.
step: Slope: $m = \frac{10 - 4}{2 - 0} = 3$. The equation is $y = 3x + 4$.
step: Set $y = 22$: $22 = 3x + 4$, so $3x = 18$.
step: Divide by $3$: $x = 6$. Check: $3(6) + 4 = 22$.

@mistakes
- Swapping the roles of $m$ and $b$, for example reading $y = 5x + 2$ as slope $2$.
- Calling $y = 3x + 1$ proportional; proportional lines pass through the origin.
- Forgetting to find $b$ after computing the slope from two points.
- Ignoring the sign of the slope in the model, so that a decrease is written as an increase.

@practice num
prompt: A line passes through $(1, 5)$ and $(3, 11)$. Find $y$ on this line when $x = 10$.
answer: 32
check: 5 + (11 - 5) / (3 - 1) * (10 - 1)
hint: First find the slope, then the equation.
hint: The slope is $3$, so $y = 3x + b$; use $(1, 5)$ to find $b$.
solution: $m = \frac{11 - 5}{3 - 1} = 3$ and $5 = 3(1) + b$ gives $b = 2$. Then $y = 3(10) + 2 = 32$.

@quiz num
prompt: A line passes through $(2, 3)$ and $(5, 12)$. Find $y$ on the line when $x = 8$.
answer: 21
check: 3 + (12 - 3) / (5 - 2) * (8 - 2)
hint: Find the slope from the two points.
hint: The slope is $3$; each $1$ step in $x$ adds $3$ to $y$.
solution: $m = \frac{12 - 3}{5 - 2} = 3$. From $x = 5$ to $x = 8$ is $3$ steps of size $3$, so $y = 12 + 9 = 21$.

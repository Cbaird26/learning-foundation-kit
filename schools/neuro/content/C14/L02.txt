@article
At a loud party you follow one conversation and lose the others, yet you may suddenly notice your own name across the room. Attention is selective, limited, and yet leaky. Cherry (1953) studied this with **shadowing**: each ear receives a different spoken message and you repeat one aloud. Listeners noticed physical changes in the ignored message (a switch of speaker's voice, a tone) but typically missed a change of language or the content. Later work found that a minority of listeners detect their own name in the ignored channel (Moray, 1959).

### Where does selection happen?

Three families of theory explain these results.

- **Filter theory** (Broadbent, 1958): a filter early in processing passes one channel on physical properties such as location or pitch; the rest is blocked before meaning is analyzed.
- **Attenuation theory** (Treisman): unattended messages are turned down, not blocked, so highly primed or important items (your name) can still cross threshold.
- **Late selection** (Deutsch and Deutsch, 1963): all inputs are analyzed for meaning, and selection acts later, at response or memory.

**Perceptual load theory** (Lavie, 1995) tries to reconcile them: when the task is perceptually demanding, capacity is used up and irrelevant stimuli go unprocessed (early-like selection); when it is easy, spare capacity spills onto distractors (late-like). The theory is influential and still debated. A striking demonstration of what selection costs is **inattentional blindness**: in Simons and Chabris (1999), about half of observers counting basketball passes failed to notice a person in a gorilla suit crossing the scene.

### Visual search and capacity

Treisman and Gelade (1980) had participants search for a target among distractors and varied the number of items $n$. RT is modeled as $\text{RT} = a + b\,n$, where the **search slope** $b$ (ms per item) is the cost of each added distractor. When the target differs from all distractors by one basic feature (a red item among green), the slope is near zero: the target "pops out." When the target is defined by a conjunction (a red vertical bar among red horizontals and green verticals), slopes are steeper, and the target-absent slope is about twice the target-present slope, as expected if items are inspected one at a time and search stops on finding the target (on average half the items are checked when present, all of them when absent).

| set size | feature search (ms) | conjunction, present (ms) | conjunction, absent (ms) |
|---|---|---|---|
| 5 | 452 | 560 | 685 |
| 10 | 455 | 685 | 935 |
| 15 | 451 | 810 | 1185 |
| 20 | 454 | 935 | 1435 |

These illustrative values give slopes of about 0, 25 and 50 ms per item. **Feature integration theory** explains this: basic features are registered in parallel in separate maps, but binding features into an object requires focal attention, applied serially. The limits: later work found slopes form a continuum and not two categories, and that many conjunction searches are efficient. **Guided search** (Wolfe and colleagues) proposes that feature maps guide attention toward likely targets, so search is neither purely parallel nor purely serial. Slopes alone cannot settle serial versus parallel processing.

```python
def slope_intercept(xs, ys):
    """Least-squares slope and intercept of ys against xs."""
    n = len(xs)
    mx, my = sum(xs) / n, sum(ys) / n
    sxy = sum((x - mx) * (y - my) for x, y in zip(xs, ys))
    sxx = sum((x - mx) ** 2 for x in xs)
    slope = sxy / sxx
    return slope, my - slope * mx
```

### Spatial attention: cueing

In Posner's (1980) cueing task a cue indicates where a target will probably appear. On **valid** trials the target appears there, on **invalid** trials elsewhere, and on **neutral** trials the cue is uninformative. Valid trials are faster than neutral (a **benefit**) and invalid slower (a **cost**):

$$\text{benefit} = \overline{\text{RT}}_{\text{neutral}} - \overline{\text{RT}}_{\text{valid}}, \qquad \text{cost} = \overline{\text{RT}}_{\text{invalid}} - \overline{\text{RT}}_{\text{neutral}} .$$

A central arrow produces voluntary (**endogenous**) orienting that builds over several hundred ms; a flash at the location produces fast, automatic (**exogenous**) orienting. At long delays after an exogenous cue, responses to the cued location become slower, **inhibition of return** (Posner and Cohen, 1984), which may favor exploring new locations.

### Control and conflict

In the **Stroop task** (Stroop, 1935) you name the ink color of a word; naming is slower when the word names a different color (incongruent) than when it matches (congruent). In the flanker task (Eriksen and Eriksen, 1974) the identity of surrounding letters affects responses to a central target. Both tasks show that irrelevant information is processed enough to compete, so control must resolve the conflict. They are robust, widely replicated effects, though individual differences in the size of these effects are measured with surprisingly low reliability (see week 11).
@example
title: A search slope from four points
problem: In a conjunction-style search, mean RTs are 521, 547, 573 and 601 ms for set sizes 4, 8, 12 and 16. Find the slope and intercept and say what the slope implies.
step: Set sizes average $\bar n = 10$ and RTs average $\bar y = (521 + 547 + 573 + 601)/4 = 560.5$ ms.
step: Deviations of $n$ are $-6, -2, 2, 6$ (sum of squares 80). Deviations of RT are $-39.5, -13.5, 12.5, 40.5$, so the cross-product sum is $237 + 27 + 25 + 243 = 532$.
step: Slope $= 532/80 = 6.65$ ms per item; intercept $= 560.5 - 6.65 \times 10 = 494$ ms.
step: A slope this small means each extra item adds only about 7 ms: search is efficient, much closer to pop-out than to the 25 ms per item of the article's serial-like conjunction data.
answer: Slope 6.65 ms per item, intercept 494 ms: efficient search.

@example
title: Benefit and cost in a cueing task
problem: Mean RTs are 312 ms (valid), 328 ms (neutral) and 351 ms (invalid). Compute the benefit, the cost and the total validity effect.
step: Benefit $= 328 - 312 = 16$ ms.
step: Cost $= 351 - 328 = 23$ ms.
step: Total validity effect $= 351 - 312 = 39$ ms, which equals $16 + 23$.
step: Interpretation: attending the cued location speeds responding a little, and attention that is misdirected costs more, since it must be disengaged and moved. Only the neutral baseline lets us split the effect this way.
answer: Benefit 16 ms, cost 23 ms, validity effect 39 ms.

@mistakes
- Treating a flat search slope as meaning that "no attention is needed": it means that the target is found without a cost per distractor, not that attention plays no role.
- Computing a cueing effect without a neutral condition and then calling it a "benefit": valid versus invalid alone cannot say whether attention helped, hurt, or both.
- Reading Cherry's results as showing that unattended speech is not processed at all: some participants detect their own name.
- Using all trials, including errors, when computing mean RTs per condition.

model:
```python
def cueing_effects(trials):
    """Benefit (neutral - valid) and cost (invalid - neutral) in ms."""
    means = {}
    for cue in ("valid", "invalid", "neutral"):
        rts = [t["rt"] for t in trials if t["cue"] == cue and t["correct"] == 1]
        if not rts:
            return (None, None)
        means[cue] = sum(rts) / len(rts)
    return (means["neutral"] - means["valid"],
            means["invalid"] - means["neutral"])
```
hint: Build a mean for each cue type from correct trials only, then check that none is empty before subtracting.
solution: The valid mean is 308 ms, invalid 350 and neutral 326, giving benefit 18 and cost 24. The third test removes every correct valid trial (only the error remains), so the valid condition is empty and the function must return the missing-condition result; the last test adds a fast valid trial, which changes only the benefit.

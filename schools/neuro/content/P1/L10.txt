@article
Hebb's postulate (1949) says that connections strengthen when presynaptic activity helps drive postsynaptic activity. Turned into an equation it is too simple to be stable, and understanding why, and what the fixes imply, is a good example of theory shaping neuroscience. Take a linear neuron $v = \mathbf w^\top\mathbf u$ with input vector $\mathbf u$ and the Hebbian rule $\tau_w\dot{\mathbf w} = v\,\mathbf u$.

### The plain Hebbian rule

If learning is slow compared with input fluctuations, average over the inputs: $\tau_w\dot{\mathbf w} = \langle\mathbf u\mathbf u^\top\rangle\mathbf w = \mathbf C\mathbf w$, with the input correlation matrix $\mathbf C$ (symmetric, positive semidefinite). Expand in its eigenvectors, $\mathbf C\mathbf e_k = \lambda_k\mathbf e_k$:
$$\mathbf w(t) = \sum_kc_k\,e^{\lambda_kt/\tau_w}\,\mathbf e_k .$$
The component with the largest eigenvalue $\lambda_1$ grows fastest and eventually dominates: the weights grow without bound along the direction of greatest input variance. For $\mathbf C = \begin{pmatrix}2 & 2/3\\2/3 & 1\end{pmatrix}$, the eigenvalues are $7/3$ and $2/3$ and the principal eigenvector is $(2,1)/\sqrt5$; with $\tau_w = 100$ ms the dominant component grows by $e$ every $\tau_w/\lambda_1 = 42.9$ ms. A rule that only strengthens synapses must be limited somehow: by bounds on the weights, or by normalization.

### Oja's rule

Oja (1982) added a decay proportional to the squared output:
$$\tau_w\dot{\mathbf w} = v\,\mathbf u - \alpha v^2\mathbf w .$$
Averaged: $\tau_w\dot{\mathbf w} = \mathbf C\mathbf w - \alpha(\mathbf w^\top\mathbf C\mathbf w)\mathbf w$. **Fixed points** satisfy $\mathbf C\mathbf w = \alpha(\mathbf w^\top\mathbf C\mathbf w)\mathbf w$, so $\mathbf w$ is an eigenvector of $\mathbf C$; writing $\mathbf w = a\mathbf e_k$ gives $\lambda_k = \alpha\lambda_ka^2$, hence $\|\mathbf w\|^2 = 1/\alpha$: the weight vector is normalized automatically. **Stability.** Let $\mathbf w = \mathbf e_k/\sqrt\alpha + \boldsymbol\delta$. To first order, $\mathbf w^\top\mathbf C\mathbf w = \lambda_k/\alpha + 2\lambda_k\,\mathbf e_k\!\cdot\!\boldsymbol\delta/\sqrt\alpha$, and
$$\tau_w\dot{\boldsymbol\delta} = \mathbf C\boldsymbol\delta - \lambda_k\boldsymbol\delta - 2\lambda_k(\mathbf e_k\!\cdot\!\boldsymbol\delta)\,\mathbf e_k .$$
Along $\mathbf e_k$ the eigenvalue is $-2\lambda_k < 0$ (the norm is restored); along $\mathbf e_j$, $j\ne k$, it is $\lambda_j - \lambda_k$. All are negative only if $\lambda_k$ is the **largest** eigenvalue (assuming it is non-degenerate). So Oja's neuron converges to $\pm\mathbf e_1/\sqrt\alpha$ and computes the first principal component of its inputs. For the matrix above with $\alpha = 1$: $\mathbf w^* = \pm(0.894, 0.447)$, with linearization eigenvalues $-2\lambda_1 = -4.667$ and $\lambda_2 - \lambda_1 = -1.667$ (in units of $1/\tau_w$). A simulation with the six inputs $\pm(2,1)$, $\pm(1,1)$, $\pm(1,-1)$ (so that $\mathbf C$ is this matrix), $\eta = 0.01$, 300 passes from $\mathbf w = (0.1, 0.1)$, reached $(0.894, 0.449)$ with norm $1.0003$.

### Subtractive normalization

Multiplicative schemes like Oja's keep $\|\mathbf w\|$ fixed. **Subtractive** normalization instead removes the same amount from every weight so as to conserve $\sum_iw_i$: $\Delta w_i = \eta\,v\,(u_i - \bar u)$ with $\bar u$ the mean input. It projects the growth onto the subspace orthogonal to the uniform vector $(1,\dots,1)$. For two equally correlated inputs, $\mathbf C = \begin{pmatrix}a&b\\b&a\end{pmatrix}$ with $b>0$, Oja's rule converges to $(1,1)/\sqrt{2\alpha}$: no selectivity. Subtractive normalization removes the $(1,1)$ mode, which has eigenvalue $a + b$, and leaves the difference $d = w_1 - w_2$ growing at rate $(a-b)/\tau_w$ (positive when $a>b$); unless weights are bounded, $d$ grows without limit, and with bounds one input wins (Miller and MacKay, 1994). The choice of normalization is a modeling assumption with qualitatively different outcomes.

### The BCM rule

Bienenstock, Cooper and Munro (1982) proposed a rule with a **modification threshold** $\theta_M$: $\tau_w\dot{\mathbf w} = v\,\mathbf u\,(v - \theta_M)$. Activity above $\theta_M$ potentiates; activity below depresses. Stability comes from letting $\theta_M$ slide with the output, $\theta_M = \langle v^2\rangle$ (a nonlinear function of the recent activity), so a more active neuron raises its threshold and a less active one lowers it.

**Two patterns.** Let the inputs be $\mathbf u_1 = (1,0)$ and $\mathbf u_2 = (0,1)$ with probability $1/2$ each. Then $\theta = \tfrac12(w_1^2 + w_2^2)$ and the averaged rule is $\tau_w\dot w_i = \tfrac12w_i(w_i - \theta)$. Fixed points: $(0,0)$; the **selective** states $(2,0)$ and $(0,2)$ (where $w_1 = \theta = w_1^2/2$); and the **non-selective** state $(1,1)$. The Jacobian entries are $\partial f_i/\partial w_i = \tfrac12[(w_i - \theta) + w_i(1 - w_i)]$ and $\partial f_i/\partial w_j = -\tfrac12w_iw_j$. At $(2,0)$ the eigenvalues are $-1, -1$: stable. At $(1,1)$ they are $\pm\tfrac12$: a saddle. So BCM learning makes the neuron selective for one pattern, even though the patterns are statistically identical. An online version with $\eta = 0.05$ converges to about $(2.11, 0)$ from $(1.2, 0.8)$ and to about $(0, 2.11)$ from $(0.8, 1.2)$; the difference from 2 is the finite learning rate and the lag of the running average of $v^2$.

### Evidence and limits

These are averaged, rate-based models. Spike-timing-dependent plasticity (Markram and colleagues, 1997; Bi and Poo, 1998) shows that the sign of change depends on spike timing, and a homeostatic synaptic scaling in cultured neurons (Turrigiano and colleagues, 1998) provides a normalizing mechanism. The sliding threshold has experimental support in some preparations, but whether any particular theoretical rule is *the* rule of cortex is open.

### In code

```python
def oja_step(w, u, eta, alpha=1.0):
    """One online step of Oja's rule: dw = eta * v * (u - alpha * v * w)."""
    v = sum(wi * ui for wi, ui in zip(w, u))
    return [wi + eta * v * (ui - alpha * v * wi) for wi, ui in zip(w, u)]
```

Learning rates must be small enough that the averaged analysis applies.

title: Oja's rule fixed point and stability
problem: Inputs have correlation matrix $\mathbf C = \begin{pmatrix}4&1.5\\1.5&1\end{pmatrix}$ (eigenvalues $0.3787$ and $4.6213$). For Oja's rule with $\alpha = 0.25$, find the fixed-point weight length and the two linearization eigenvalues at the stable fixed point.
step: The stable fixed points are $\pm\mathbf e_1/\sqrt\alpha$ along the principal eigenvector, so $\|\mathbf w\| = 1/\sqrt{0.25} = 2$.
step: The eigenvalue along $\mathbf e_1$ is $-2\lambda_1 = -9.243$ (in units of $1/\tau_w$).
step: The eigenvalue along $\mathbf e_2$ is $\lambda_2 - \lambda_1 = 0.3787 - 4.6213 = -4.243$.
step: Both are negative. At the other fixed point $\pm\mathbf e_2/\sqrt\alpha$ the eigenvalue along $\mathbf e_1$ is $\lambda_1 - \lambda_2 = +4.243$: a saddle.
answer: $\|\mathbf w\| = 2$; eigenvalues $-9.243$ and $-4.243$ (stable); the minor-axis fixed point is a saddle.

@mistakes
- Believing that normalization removes the principal-component behavior: Oja's rule has the same direction as the Hebbian rule's dominant mode, with the length held fixed.
- Reading stability from the sign of $\lambda_k$: for Oja's rule the radial eigenvalue is always $-2\lambda_k$; stability requires every other $\lambda_j - \lambda_k$ to be negative, so only the largest eigenvalue works.
- Calling BCM selectivity a result of different patterns having different statistics: in the two-pattern example the patterns are identical in frequency and strength, and selectivity arises from symmetry breaking.
- Assuming the sliding threshold is fixed: a fixed $\theta_M$ makes the BCM rule unstable.

```python
def bcm_run(w, patterns, eta, k, n_steps, theta):
    """Online BCM learning with a sliding threshold; returns (w, theta)."""
    w = list(w)
    for t in range(n_steps):
        u = patterns[t % len(patterns)]
        v = sum(wi * ui for wi, ui in zip(w, u))
        w = [wi + eta * ui * v * (v - theta) for wi, ui in zip(w, u)]
        theta += k * (v * v - theta)
    return w, theta
```
hint: Compute $v$ once, update the weights with the old threshold, then update the threshold from the same $v^2$.
solution: The order matters: the weight update uses the threshold from before this step and the threshold update uses the output before the weights change. With the start $(1.2, 0.8)$ the first pattern drives $w_1$ above the threshold and the second pattern's input pushes $w_2$ below it, so the weights separate and the neuron becomes selective for the first pattern; starting from $(0.8, 1.2)$ the opposite pattern wins.

@practice self
prompt: Two inputs have correlation matrix $\mathbf C = \begin{pmatrix}a&b\\b&a\end{pmatrix}$ with $a > b > 0$. Compare what happens to the weights under (i) Oja's rule and (ii) a Hebbian rule with subtractive normalization that conserves $w_1 + w_2$ (weights bounded between $0$ and $w_{\max}$). State the dynamics of $w_1 - w_2$ in each case and what a modeler should conclude about the role of the normalization scheme.
hint: The eigenvectors of $\mathbf C$ are $(1,1)/\sqrt2$ with eigenvalue $a + b$ and $(1,-1)/\sqrt2$ with eigenvalue $a - b$.
solution: (i) Oja's averaged rule converges to the eigenvector of the largest eigenvalue, which is $(1,1)/\sqrt{2\alpha}$ since $a + b > a - b$ for $b>0$. Linearizing at that point, the eigenvalue along $(1,-1)$ is $(a - b) - (a + b) = -2b < 0$, so any difference $w_1 - w_2$ decays at rate $2b/\tau_w$: the neuron stays non-selective, with equal weights. (ii) Subtractive normalization subtracts the same amount from each weight, so $w_1 + w_2$ is conserved and the dynamics act only on $d = w_1 - w_2$: $\tau_w\dot d = (a - b)d$, an unstable growth because $a > b$. Without bounds $d$ grows exponentially; with bounds, the weights end at $(w_{\max}, 0)$ or $(0, w_{\max})$ depending on the sign of the initial difference, so one input wins. The modeler should conclude that the outcome (graded symmetric weights versus winner-take-all selectivity) depends on the normalization rule, not only on the Hebbian term and the input statistics, so the normalization is a substantive hypothesis that must be tested (for example with experiments on how total synaptic strength is conserved), and the model's predictions should be checked under both.

model:
```python
def train_subtractive(w, inputs, eta, wmax):
    """Hebbian learning with subtractive normalization and bounded weights."""
    w = list(w)
    for u in inputs:
        v = sum(wi * ui for wi, ui in zip(w, u))
        mean_u = sum(u) / len(u)
        w = [min(wmax, max(0.0, wi + eta * v * (ui - mean_u)))
             for wi, ui in zip(w, u)]
    return w
```
hint: In each step compute the output with the old weights, add the mean-subtracted Hebbian change, then clip with `min` and `max`.
solution: The subtractive step conserves the sum of the weights until clipping acts, and it amplifies the difference between inputs: the input that starts slightly ahead keeps gaining at the expense of the others until the bounds stop the change, so one weight reaches `wmax` and the rest go to zero. This is the winner-take-all outcome discussed above. A uniform input (the fourth test) changes nothing, because the mean-subtracted input is zero.

@article
A rat's head-direction cells each fire when the head points in one preferred direction (Taube, Muller and Ranck, 1990), and together they hold the current heading even in the dark. A population of $N$ neurons arranged by preferred direction around a circle can store one angle in the **location of a bump** of activity. Models of this kind (Ben-Yishai, Bar-Or and Sompolinsky, 1995, for orientation tuning; Skaggs and colleagues, 1995, and Zhang, 1996, for head direction) are the cleanest example of a continuous attractor, and they can be analyzed exactly.

### The ring model

Neurons are labeled by preferred angle $\theta \in (-\pi, \pi]$. With the threshold-linear gain,

$$\tau\,\dot r(\theta,t) = -r + \Big[\frac1{2\pi}\int_{-\pi}^{\pi}W(\theta-\theta')\,r(\theta')\,d\theta' + h\Big]_+,\qquad W(\theta) = J_0 + J_1\cos\theta .$$

This kernel depends only on the angular difference, so the network is invariant under rotations. Write $a_0 = \frac1{2\pi}\int r\,d\theta$ and $a_1 = \frac1{2\pi}\int r\cos\theta\,d\theta$ for the mean rate and the first cosine component. Because $\frac1{2\pi}\int\cos(\theta-\theta')\cos\theta'd\theta' = \frac12\cos\theta$, the input to a neuron is

$$I(\theta) = h + J_0a_0 + J_1a_1\cos\theta = A + B\cos\theta .$$

### Instability of the uniform state

The uniform state $r = h/(1 - J_0)$ (for $J_0 < 1$) has perturbations that decouple by Fourier mode: the mean mode has growth rate $(J_0 - 1)/\tau$ and the $\cos\theta$ (and $\sin\theta$) modes have $(J_1/2 - 1)/\tau$. The uniform state becomes unstable to a spatially modulated pattern when $J_1 > 2$, with e-folding time $\tau/(J_1/2 - 1)$. All other modes decay, so the pattern that grows is one bump. Rectification then limits its growth.

### The bump

Look for a symmetric bump $r = [A + B\cos\theta]_+$ with half-width $\theta_c$, where $A = -B\cos\theta_c$. Integrating gives $a_0 = (B/\pi)(\sin\theta_c - \theta_c\cos\theta_c)$ and $a_1 = (B/2\pi)(\theta_c - \sin\theta_c\cos\theta_c)$. The condition $B = J_1a_1$ yields

$$\theta_c - \sin\theta_c\cos\theta_c = \frac{2\pi}{J_1},$$

which fixes the half-width **independently of $h$**: the width of tuning does not change with the strength of the input (contrast invariance). The amplitude follows from $A = h + J_0a_0$:

$$B = \frac{h}{-\cos\theta_c - \frac{J_0}{\pi}(\sin\theta_c - \theta_c\cos\theta_c)} .$$

For $J_0 = -1$, $J_1 = 3$, $h = 1$ (dimensionless units, $\tau = 10$ ms) the solutions are $\theta_c = 1.8389$ rad ($105.4^\circ$), $B = 1.3756$, $A = 0.3644$ and peak rate $A + B = 1.7401$. A simulation with $N = 64$ units and Euler steps of $0.5$ ms gives a peak of $1.7399$, and the bump width is as predicted. For $J_1 = 4$ the equation gives exactly $\theta_c = \pi/2$.

### The neutral mode

Because the bump can be placed anywhere, $r_0(\theta - \phi)$ is a steady state for every $\phi$. Differentiating with respect to $\phi$ shows that $u(\theta) = r_0'(\theta) = -B\sin\theta$ (on the active region, zero outside) is an eigenvector of the linearization with eigenvalue **zero**. This is the **Goldstone mode** of the broken rotation symmetry: the dynamics have no restoring force along the ring, so the stored angle is held without decay. The linear operator on the active set, $K = -1 + \mathrm{G}W\mathrm{G}$ (G projects on the active neurons), is self-adjoint because $W$ is symmetric, so $u$ is also its left null vector. Perturb the input by $\delta I(\theta)$ and write $r = r_0(\theta - \phi(t)) + \delta$. Projecting the dynamics onto $u$ removes $K\delta$ and leaves
$$\dot\phi = -\frac{1}{\tau}\frac{\langle u, \delta I\rangle}{\langle u,u\rangle}.$$

Two results follow, both checked by simulation.

1. **Asymmetric kernel.** Adding $J_s\sin(\theta - \theta')$ to the kernel gives $\delta I = J_sa_1\sin\theta$ (since $B = J_1a_1$), hence $\dot\phi = J_s/(J_1\tau)$: the bump rotates at constant speed proportional to $J_s$. With $J_s = 0.1$, $J_1 = 3$, $\tau = 10$ ms the formula gives $0.003333$ rad/ms and the simulation $0.003334$. If $J_s$ is made proportional to the head angular velocity, the network integrates velocity into heading, as in head-direction models.
2. **Weak input.** A weak input $\delta h = \varepsilon\cos(\theta - \psi)$ gives $\dot\phi = \varepsilon\sin(\psi - \phi)/(\tau B)$: the bump is pulled toward the peak of the input and settles there. With $\varepsilon = 0.1$, $\psi - \phi = \pi/2$, $B = 1.3756$ this is $0.00727$ rad/ms (simulated: $0.00722$). Landmark cues can reset the heading this way.

### Fine tuning and the evidence

The same calculation shows the weakness. A small heterogeneity in connectivity or input has components along $u$ and so produces drift, and a generic one creates a potential landscape with a few stable points instead of a ring. Real systems must therefore be tuned or averaged over many neurons. The evidence is mixed in a useful way. In the fly, a bump of activity moves around a ring-shaped neural structure as the animal turns (Seelig and Jayaraman, 2015), and perturbation experiments show attractor-like dynamics (Kim, Rouault, Druckmann and Jayaraman, 2017). In rodent head-direction cells, population activity lies on a ring-shaped manifold that persists across waking and sleep (Chaudhuri and colleagues, 2019), consistent with an attractor but not proof of this specific wiring. Models differ in the wiring that produces the ring, so the question is not settled by one model fitting the data.

### In code

```python
import math


def ring_run(N, J0, J1, h, tau, T, dt, init):
    """Euler integration of the threshold-linear ring; returns final rates."""
    th = [2 * math.pi * i / N - math.pi for i in range(N)]
    W = [[(J0 + J1 * math.cos(th[i] - th[j])) / N for j in range(N)]
         for i in range(N)]
    r = list(init)
    for _ in range(int(round(T / dt))):
        x = [sum(W[i][j] * r[j] for j in range(N)) + h for i in range(N)]
        r = [r[i] + dt / tau * (-r[i] + max(x[i], 0.0)) for i in range(N)]
    return r
```

The $1/N$ turns the sum into the integral $\frac1{2\pi}\int d\theta'$ (the spacing is $2\pi/N$).

title: Instability and bump width
problem: A ring network with $W(\theta) = J_0 + J_1\cos\theta$, $J_0 = -0.5$, $\tau = 20$ ms has $J_1 = 2.6$. How fast does a cosine perturbation of the uniform state grow, and what is the bump half-width in the saturated state?
step: The cosine-mode eigenvalue is $J_1/2 = 1.3$, so the growth rate is $(1.3 - 1)/\tau = 0.3/20 = 0.015$ ms$^{-1}$ (e-folding time $66.7$ ms): the uniform state is unstable since $J_1 > 2$.
step: The half-width solves $\theta_c - \sin\theta_c\cos\theta_c = 2\pi/J_1 = 2.4166$.
step: Try $\theta_c = 2.0$: $2.0 - (0.9093)(-0.4161) = 2.3784$. Try $2.1$: $2.1 - (0.8632)(-0.5048) = 2.5358$. Interpolating gives $\theta_c \approx 2.024$ rad (about $116^\circ$); direct root finding gives $2.0234$.
step: The width does not depend on the input $h$ or on $J_0$, so changing the input strength rescales the bump height only.
answer: Growth rate $0.015$ ms$^{-1}$; half-width $\theta_c \approx 2.02$ rad ($116^\circ$).

@mistakes
- Treating the bump position as set by a parameter: with an exactly rotation-invariant kernel it is set by the initial condition and the history of input, and it is neutrally stable.
- Concluding that a zero eigenvalue means the network is unstable: a zero eigenvalue along the attractor is what lets it hold a value; stability requires all other eigenvalues to be negative.
- Using $J_1$ with the wrong normalization: here $W$ acts through $\frac{1}{2\pi}\int d\theta'$, so the cosine-mode eigenvalue is $J_1/2$ and the threshold is $J_1 = 2$. With another normalization the threshold changes.
- Believing exact continuous attractors exist in biology because the model has them: the model's neutral mode requires exact symmetry; real wiring has noise and heterogeneity.

model:
```python
import math


def ring_weights(N, J0, J1, Js):
    """Circulant weights J0 + J1 cos + Js sin of the angular difference, over N."""
    th = [2 * math.pi * i / N - math.pi for i in range(N)]
    return [[(J0 + J1 * math.cos(th[i] - th[j])
              + Js * math.sin(th[i] - th[j])) / N for j in range(N)]
            for i in range(N)]
```
hint: Compute the preferred angles first. The sine term uses $\theta_i - \theta_j$ (row minus column), so the matrix is not symmetric when $J_s \ne 0$.
solution: The entry depends only on $\theta_i - \theta_j$, so the matrix is circulant (the second-to-last test) and every row sums to $J_0$ because the cosine and sine terms sum to zero over a full circle (the last test). The sign convention of the sine term decides the direction in which the bump rotates.

@practice self
prompt: Derive the speed at which a bump rotates in the threshold-linear ring network when an antisymmetric component $J_s\sin(\theta - \theta')$ is added to the kernel $J_0 + J_1\cos(\theta - \theta')$, to first order in $J_s$. State clearly the zero-mode argument, and explain why a small heterogeneity in $h(\theta)$ produces drift while the unperturbed network does not.
hint: Use the left null vector $u = r_0'(\theta) = -B\sin\theta$ and the fact that $B = J_1a_1$.
solution: For the unperturbed bump $r_0 = [A + B\cos\theta]_+$ the first cosine component is $a_1$, with $B = J_1a_1$ and $b_1 = 0$. The extra kernel gives a perturbing input $\delta I(\theta) = J_s(a_1\sin\theta - b_1\cos\theta) = J_sa_1\sin\theta$. Write $r = r_0(\theta - \phi(t)) + \delta$ and linearize on the active region. The time derivative of the first term is $-\dot\phi\,u$ with $u = r_0'$. The operator $K = -1 + \mathrm GW\mathrm G$ is self-adjoint on the active set because $W$ is symmetric, and $Ku = 0$, so projecting on $u$ removes the $\delta$ terms: $-\tau\dot\phi\langle u,u\rangle = \langle u,\delta I\rangle$. With $u = -B\sin\theta$ and $\delta I = J_sa_1\sin\theta$ on $|\theta|<\theta_c$, $\langle u,\delta I\rangle = -BJ_sa_1\int\sin^2\theta\,d\theta$ and $\langle u,u\rangle = B^2\int\sin^2\theta\,d\theta$, so $\dot\phi = J_sa_1/(\tau B) = J_s/(J_1\tau)$, independent of $h$ and $\theta_c$. For a heterogeneity $\delta h(\theta)$ the same projection gives $\dot\phi = -\langle u, \delta h\rangle/(\tau\langle u,u\rangle)$, which is generally nonzero for any $\delta h$ with a component along $\sin(\theta - \phi)$, and it depends on $\phi$: the bump drifts to the stable points of $\phi$ where it vanishes. In the symmetric network no such term exists, so every $\phi$ is a steady state.

model:
```python
import math


def population_vector(r):
    """Angle of the population vector for preferred angles 2*pi*i/N."""
    N = len(r)
    total = 0.0
    for x in r:
        total += x
    if total == 0:
        return None
    c = sum(x * math.cos(2 * math.pi * i / N) for i, x in enumerate(r))
    s = sum(x * math.sin(2 * math.pi * i / N) for i, x in enumerate(r))
    return math.atan2(s, c)
```
hint: Add up the vector contributions $r_i(\cos\theta_i, \sin\theta_i)$, then take `atan2(sin_sum, cos_sum)`.
solution: Using `atan2` instead of `atan(s / c)` gets the right quadrant and avoids dividing by zero when the cosine sum vanishes. Zero activity has no direction, hence `None`. Note that the population vector of a bump equals the bump center only when the bump is symmetric about it.

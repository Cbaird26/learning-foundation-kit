@article
A network with enough parameters can memorize a small training set, driving the training loss to nearly zero while the loss on new data climbs. This is **overfitting** (the bias-variance trade-off from the machine learning course, C22). **Regularization** is any change to training that trades a bit of training loss for better generalization. Three methods are in nearly every deep learning recipe.

### Weight decay

Add to the loss an L2 penalty on the weights, $L_{\text{reg}}(\boldsymbol{\theta}) = L(\boldsymbol{\theta}) + \frac{\lambda}{2}\lVert \boldsymbol{\theta} \rVert_2^2$. The gradient of the penalty is $\lambda\boldsymbol{\theta}$, so a gradient step becomes

$$\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} - \eta\big(\mathbf{g} + \lambda \boldsymbol{\theta}\big) = (1 - \eta\lambda)\,\boldsymbol{\theta} - \eta\,\mathbf{g}.$$

Every step first *decays* the weights by the factor $1 - \eta\lambda$ and then takes the usual gradient step, hence the name **weight decay**. It keeps weights small, which makes the function smoother. For $\boldsymbol{\theta} = (2, -1)$, $\mathbf{g} = (0.5, 0.3)$, $\eta = 0.1$ and $\lambda = 0.1$ the decay factor is $0.99$ and the result is $(1.98 - 0.05,\ -0.99 - 0.03) = (1.93, -1.02)$. Weight decay is usually applied to weights, not biases. For plain SGD, an L2 penalty and weight decay are the same thing; for adaptive optimizers such as Adam they are not, because the penalty's gradient is rescaled by Adam's denominator. Decoupling the decay from the gradient step (the AdamW variant) restores the intended behavior.

For a one-weight model $\hat{y} = wx$ with loss $\frac{1}{n}\sum (wx_i - y_i)^2 + \frac{\lambda}{2}w^2$, setting the derivative to zero gives $w^\star = \frac{(2/n)\sum x_i y_i}{(2/n)\sum x_i^2 + \lambda}$: the penalty shrinks the unregularized solution toward zero (this is ridge regression, C10).

### Dropout

**Dropout** (Srivastava and colleagues, 2014) randomly sets each hidden activation to zero with probability $p$ during training. The network cannot rely on any single unit, which discourages units from co-adapting. The **inverted** version rescales the survivors so that the expected activation is unchanged:

$$\tilde{h}_j = \frac{m_j}{1 - p}\,h_j, \qquad m_j \sim \text{Bernoulli}(1 - p).$$

Since $\mathbb{E}[m_j] = 1 - p$, we get $\mathbb{E}[\tilde{h}_j] = h_j$. At test time dropout is switched off and the network is used as it is, with no rescaling needed. Example with $p = 0.5$: activations $(0.5, 1.0, 2.0, 1.5)$ and mask $(1, 0, 1, 0)$ give $(1.0, 0, 4.0, 0)$. Dropout's gradient flows only through the surviving units, with the same scaling. Forgetting to turn it off at evaluation time is a classic bug: predictions become noisy and the validation loss looks worse than it is (frameworks provide `model.train()` and `model.eval()`).

### Early stopping

Track the loss on a held-out **validation set** after every epoch. Training loss keeps falling; validation loss typically falls, bottoms out, then rises as the model starts to memorize. **Early stopping** keeps the parameters from the epoch with the lowest validation loss. In practice you stop after the validation loss has failed to improve for `patience` epochs and restore the best saved parameters. An illustrative run:

| epoch | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| training loss | 0.90 | 0.60 | 0.42 | 0.30 | 0.21 | 0.15 | 0.10 | 0.07 |
| validation loss | 0.95 | 0.72 | 0.60 | 0.55 | 0.57 | 0.62 | 0.70 | 0.80 |

The best epoch is 4. With patience 2, the run is stopped after epoch 6, and the model returned is the one from epoch 4. The validation set is used for this choice, so the final unbiased estimate of performance must come from a separate test set (C10).

### Comparing with and without regularization

The honest comparison trains twice, identically except for the regularizer, and reports training and validation loss for both. An unregularized run typically shows a lower training loss and a higher validation loss; a well-tuned regularized run shows a smaller gap and often a better validation loss. The strength ($\lambda$, $p$, the patience) is a hyperparameter chosen by validation performance, not by training loss.

### In code

```python
import random

def dropout(h, p, rng):
    keep = 1.0 - p
    mask = [1.0 if rng.random() < keep else 0.0 for _ in h]
    return [m * x / keep for m, x in zip(mask, h)], mask

def decay_step(w, g, lr, lam):
    return [(1 - lr * lam) * wi - lr * gi for wi, gi in zip(w, g)]

print([round(v, 2) for v in decay_step([2.0, -1.0], [0.5, 0.3], 0.1, 0.1)])
```

This prints `[1.93, -1.02]`. In PyTorch, dropout is `torch.nn.Dropout(p)` and weight decay is the `weight_decay` argument of the optimizer (or `torch.optim.AdamW`).

@example
title: Weight decay on a one-weight model
problem: Fit $\hat{y} = wx$ to the points $(1, 1)$ and $(2, 3)$ with the loss $\frac{1}{n}\sum (wx_i - y_i)^2 + \frac{\lambda}{2}w^2$ and $\lambda = 2$. Find the minimizing $w$ with and without the penalty.
step: Here $n = 2$, $\sum x_i y_i = 1 + 6 = 7$ and $\sum x_i^2 = 1 + 4 = 5$.
step: Without the penalty: $w^\star = \sum x_i y_i/\sum x_i^2 = 7/5 = 1.4$.
step: With the penalty, $w^\star = \frac{(2/n)\sum x_i y_i}{(2/n)\sum x_i^2 + \lambda} = \frac{7}{5 + 2} = 1.0$.
step: The penalty shrinks the weight from 1.4 toward 0.
answer: $w^\star = 1.4$ without and $w^\star = 1.0$ with $\lambda = 2$.

@example
title: Inverted dropout and its expectation
problem: A hidden layer outputs $\mathbf{h} = (1.2, 0.6, 0.0, 2.4)$ and dropout with $p = 0.25$ draws the mask $(1, 0, 1, 1)$. Compute the dropout output, and the expected value of the first output over the random mask.
step: The keep probability is $1 - p = 0.75$, so surviving entries are multiplied by $1/0.75 = 4/3$.
step: Output: $(1.2 \cdot 4/3,\ 0,\ 0 \cdot 4/3,\ 2.4 \cdot 4/3) = (1.6, 0, 0, 3.2)$.
step: The first output equals $1.6$ with probability $0.75$ and 0 with probability $0.25$, so its expectation is $0.75 \cdot 1.6 = 1.2$, the original activation.
answer: Output $(1.6, 0, 0, 3.2)$, and the expected output equals the input, $1.2$ for the first unit.

@mistakes
- Evaluating the validation or test loss with dropout still active: the predictions are noisy and the measured loss is too high.
- Choosing $\lambda$ or the stopping epoch by training loss: training loss always prefers less regularization, so these choices must use validation loss.
- Dropping the $1/(1-p)$ rescaling in training and also not compensating at test time: the activations then have a different scale at test time than the network was trained on.
- Using early stopping and then reporting the validation loss at the best epoch as the final performance: that number was selected to be the lowest, so it is optimistic; report test-set performance.

@practice mc
prompt: Why does inverted dropout divide the surviving activations by $1 - p$ during training?
choice*: So that the expected value of each activation during training equals its value without dropout, and no rescaling is needed at test time.
choice: So that the gradient is guaranteed to be zero for dropped units.
choice: So that the number of parameters is reduced by a factor $1 - p$.
choice: So that the training loss is always lower than the validation loss.
hint: Compute the expected value of $m_j h_j/(1-p)$ when $m_j$ is 1 with probability $1 - p$.
solution: $\mathbb{E}[m_j h_j/(1 - p)] = (1-p) h_j/(1-p) = h_j$. The rescaling keeps the scale of activations consistent, so at test time the network is used unchanged. It does not change the parameter count or guarantee any loss ordering.

model:
```python
def decay_step_masked(w, g, lr, lam, decay):
    """One SGD step with L2 weight decay applied only where decay is true."""
    return [wi - lr * (gi + (lam * wi if d else 0.0))
            for wi, gi, d in zip(w, g, decay)]
```
hint: The decay term `lam * w_i` is added to the gradient only for entries whose flag is true.
solution: The penalty contributes `lam * w_i` to the partial derivative of a decayed entry and nothing to the others, so the masked entries follow plain SGD. The second test has zero gradients, so decayed weights just shrink by the factor $1 - \eta\lambda = 0.9$ while the unmasked one stays put; the last test checks that nothing is decayed when every flag is false.

model:
```python
def dropout_backward(upstream, mask, p):
    """Gradient through inverted dropout: only kept units, scaled by 1/(1-p)."""
    return [u * m / (1.0 - p) for u, m in zip(upstream, mask)]
```
hint: The forward map is linear in `h[j]` with slope `mask[j] / (1 - p)`, so the local derivative is that slope.
solution: Each output depends on its own input through the factor `mask[j] / (1 - p)`, so the chain rule multiplies the upstream gradient by that same factor: dropped units receive zero gradient and kept units receive the scaled gradient. A solution that forgets the rescaling fails the first two tests, and one that passes gradients to dropped units fails because of the zeros.

```python
def early_stopping_epoch(val_losses, patience):
    """Index of the best epoch when training stops after `patience` bad epochs."""
    best = float('inf')
    best_epoch = 0
    bad = 0
    for epoch, loss in enumerate(val_losses):
        if loss < best:
            best = loss
            best_epoch = epoch
            bad = 0
        else:
            bad += 1
            if bad >= patience:
                break
    return best_epoch
```
hint: Keep the best loss, its epoch and a counter of epochs since the last improvement; reset the counter on an improvement and stop when it reaches `patience`.
solution: The counter of non-improving epochs decides when to stop, so a late improvement that comes after the stopping point (the final 0.6 in the first tests) is never seen unless the patience is long enough. The strict comparison matters for the all-equal test, where the first epoch stays the best.

```python
def fit_with_decay(data, lr, lam, steps):
    """Gradient descent on MSE plus an L2 penalty for y_hat = w * x."""
    n = len(data)
    w = 0.0
    for _ in range(steps):
        grad = 2 / n * sum((w * x - y) * x for x, y in data) + lam * w
        w -= lr * grad
    return w
```
hint: The gradient is the usual MSE gradient $\frac{2}{n}\sum(wx_i - y_i)x_i$ plus $\lambda w$.
solution: The penalty adds $\lambda w$ to the gradient, moving the minimizer from $31/14 \approx 2.214$ to $(2/3 \cdot 31)/(2/3 \cdot 14 + 1) = 2.0$ for $\lambda = 1$. The last test shows the shrinkage is monotone in $\lambda$: more decay, smaller weight.

@quiz self
prompt: Two runs of the same network on a small data set end with these losses. Run X (no regularization): training 0.02, validation 0.85. Run Y (weight decay 0.01 and dropout 0.3): training 0.31, validation 0.52. A colleague says Run X is better because its training loss is 15 times lower. Respond, and explain what each of weight decay and dropout does to make the numbers look this way. Then say what you would still check before choosing Y.
hint: Which loss measures generalization? Then think about how each regularizer limits the model's ability to fit the training set.
solution: The training loss measures how well the model fits data it has seen; generalization is measured by the validation loss, and Run Y's is clearly lower (0.52 against 0.85). Run X's large train-validation gap (0.02 against 0.85) is the signature of overfitting: it has memorized the training set. Weight decay penalizes large weights, which restricts the function to be smoother, and dropout prevents units from co-adapting by randomly removing them during training, so neither can fit the training data as tightly; that is why Run Y's training loss is higher, and why its training and validation losses are closer. Before choosing Y I would confirm the training loss in Run Y was computed in evaluation mode (dropout off) for a fair comparison, check that the hyperparameters were selected on validation data only, and measure the final performance of the chosen configuration on a separate test set, since validation data was used for selection.

```python
import random

def train(model, opt, train_data, val_data, epochs, batch_size, rng):
    history = []
    for epoch in range(1, epochs + 1):
        order = list(range(len(train_data)))
        rng.shuffle(order)
        for i in range(0, len(order), batch_size):
            batch = [train_data[j] for j in order[i:i + batch_size]]
            opt.zero_grad()
            loss = mean_loss(model, batch)      # average loss over the batch
            loss.backward()
            opt.step()
        history.append((epoch, evaluate(model, train_data), evaluate(model, val_data)))
    return history
```

## Week-by-week key ideas

1. **Neurons and MLPs.** $z = \mathbf{w}^\top\mathbf{x} + b$, $a = f(z)$; sigmoid, tanh, ReLU; a layer is $f(\mathbf{W}\mathbf{x} + \mathbf{b})$; parameters $= \sum (d_{l-1}d_l + d_l)$; without nonlinearity, depth collapses to one affine map.
2. **Losses.** Mean squared error for regression; softmax cross-entropy $-\log p_c$ for classification with gradient $\mathbf{p} - \mathbf{y}$; subtract the maximum logit for stability.
3. **Computational graphs.** Forward pass, then backward with local derivatives; add the contributions at a node used several times; check with central differences.
4. **Autograd.** `Value` objects record the graph; reverse topological order; gradients accumulate with `+=`; reverse mode is cheap for one scalar loss and many parameters.
5. **Training.** Mini-batch gradient is an unbiased average; $\lceil n/B \rceil$ updates per epoch; shuffle every epoch; the learning rate decides stability.
6. **Initialization.** Break symmetry; keep $n\sigma^2 \approx 1$; LeCun $1/n_{\text{in}}$, Xavier $2/(n_{\text{in}}+n_{\text{out}})$, He $2/n_{\text{in}}$ for ReLU.
7. **Optimizers.** Momentum $v \leftarrow \beta v + g$; Adam with bias-corrected first and second moments, first step about $\eta\,\text{sign}(g)$.
8. **Regularization.** Weight decay $(1 - \eta\lambda)\theta - \eta g$; inverted dropout scales by $1/(1-p)$ and is off at test time; early stopping on validation loss.
9. **Normalization.** Batch norm: per feature over the batch, running averages at inference; layer norm: per example over features; learned $\gamma$, $\beta$.
10. **Diagnostics.** Read learning curves (underfit, overfit, diverge, stuck at $\log K$); sigmoid chains shrink gradients by at most $1/4$ per layer; clip by norm.
11. **Residual networks.** $\mathbf{y} = \mathbf{x} + F(\mathbf{x})$ has Jacobian $\mathbf{I} + \partial F/\partial\mathbf{x}$, a direct path for gradients.
12. **Frameworks.** Tensors with shapes, autograd, modules, optimizers, `zero_grad`; `train()` and `eval()`.

## Key algorithms to be able to write from memory

- Forward pass of an MLP; stable softmax and cross-entropy with its gradient.
- The `Value` class with `backward` in reverse topological order.
- One mini-batch SGD epoch; the momentum and Adam updates; weight decay step; inverted dropout.
- Batch and layer normalization; gradient clipping by norm.

## Common errors

Assigning rather than accumulating gradients; forgetting the bias in parameter counts; applying softmax before a loss that expects logits; summing instead of averaging over a batch; using training loss to choose hyperparameters; leaving dropout or batch statistics on at evaluation; and forgetting to clear gradients between steps.

model:
```python
import math

def tiny_step(params, x, y, lr):
    """One gradient descent step on (w2 * tanh(w1 * x + b1) + b2 - y) ** 2."""
    w1, b1, w2, b2 = params
    h = math.tanh(w1 * x + b1)
    o = w2 * h + b2
    do = 2 * (o - y)
    dw2 = do * h
    db2 = do
    dz = do * w2 * (1 - h * h)
    dw1 = dz * x
    db1 = dz
    return (w1 - lr * dw1, b1 - lr * db1, w2 - lr * dw2, b2 - lr * db2)
```
hint: Do the forward pass and keep `h` and `o`; then go backward: the loss gives `2 * (o - y)`, the output layer gives `w2` and `h` factors, and `tanh` has the derivative `1 - h ** 2`.
solution: The backward pass multiplies local derivatives from the loss to each parameter: $\partial L/\partial o = 2(o - y)$, $\partial L/\partial w_2 = \partial L/\partial o \cdot h$, $\partial L/\partial b_2 = \partial L/\partial o$, and through the hidden unit $\partial L/\partial z = \partial L/\partial o \cdot w_2 (1 - h^2)$, giving $\partial L/\partial w_1 = \partial L/\partial z\cdot x$ and $\partial L/\partial b_1 = \partial L/\partial z$. The last test sets the target equal to the prediction, so every gradient is zero and nothing may change.

The true class is class 0 (the first). Using the softmax cross-entropy loss, one SGD step with learning rate $\eta = 0.1$ and weight decay $\lambda = 0.1$ updates each weight by $W \leftarrow W - \eta(g + \lambda W)$, where $g$ is the loss gradient. What is the new value of the weight in the first row and first column, $W_{00}$? Give your answer to four decimal places.
answer: 0.5874
tol: 0.0001
check: 0.5 - 0.1 * ((exp(0.5 * 1 - 0.5 * 2) / (exp(0.5 * 1 - 0.5 * 2) + exp(0 * 1 + 1 * 2)) - 1) * 1 + 0.1 * 0.5)

@exam self
prompt: You are asked to train a 30-layer fully connected network with sigmoid activations on a 10-class problem. After one epoch the training loss is 2.30 and the gradient norms of the first ten layers are below $10^{-8}$. (a) Explain the cause using the chain rule and a number. (b) Propose a redesign using at least three ideas from this course (for example the activation, initialization, normalization and residual connections), and say what each contributes. (c) Describe the first three diagnostic experiments you would run after the redesign and what result would tell you each is healthy.
hint: Sigmoid's derivative is at most 1/4, so a product of many such factors shrinks geometrically; then match each remedy to what it changes in the product or in the signal's scale.
solution: (a) By the chain rule the gradient reaching layer $l$ is a product of one local factor per layer above it. For a sigmoid unit the local factor is $w\,a(1 - a)$ with $a(1 - a) \le 1/4$, so with weights of order 1 each layer shrinks the gradient by at least a factor of 4; over 20 layers that is about $4^{-20} \approx 10^{-12}$, which explains gradient norms below $10^{-8}$ in the early layers and a loss stuck at $\log 10 = 2.30$, the loss of a uniform prediction. (b) Replace sigmoid by ReLU, whose derivative is 1 for positive inputs, so the factors no longer shrink systematically; use He initialization ($\sigma^2 = 2/n_{\text{in}}$) so that the signal and gradient scales are preserved across layers; add normalization (batch or layer normalization) so activations stay in a well-scaled range during training; and wrap blocks in residual connections so that the Jacobian is $\mathbf{I} + \partial F/\partial\mathbf{x}$ and the gradient has a direct path to early layers. (c) First, check the loss at step 0 against $\log 10 \approx 2.30$; a value far above means the initial outputs are badly scaled. Second, try to overfit a single batch of 10 examples; the training loss should go close to 0, and if it does not there is a bug. Third, log the gradient norm of each layer for a few steps; healthy training shows norms of the same order of magnitude across layers rather than a decay of orders of magnitude, and the training loss should fall steadily over the first epochs while the validation loss is tracked alongside.

@article
A single neuron with a bell-shaped tuning curve is a poor measuring instrument: it fires at the same rate for two stimuli on either side of its peak, and its count varies from trial to trial. Yet animals judge stimuli precisely. The idea behind **population decoding** is that many broadly tuned neurons together pin the stimulus down. Decoding asks the inverse of the encoding question: given the counts $n_1, \dots, n_M$ of $M$ neurons on one trial, what was the stimulus?

### The tuning model

Take a stimulus $s$ on a line, in degrees, and neuron $i$ with preferred value $c_i$ and **Gaussian tuning curve**

$$f_i(s) = r_{\max}\, e^{-(s - c_i)^2/(2\sigma^2)} \quad \text{(Hz)},$$

with the same peak rate $r_{\max}$ and width $\sigma$ for all neurons. Counts are measured in a window of $T$ seconds, and given $s$ the counts of different neurons are independent Poisson variables with means $f_i(s)\,T$.

### Population vector

The **population vector** decoder takes the average preferred value of the neurons, weighted by their counts:

$$\hat s_{\mathrm{PV}} = \frac{\sum_i n_i\, c_i}{\sum_i n_i}.$$

It needs no knowledge of $r_{\max}$ and $\sigma$ and is simple, but it is biased near the edges of the covered range, where neurons on only one side contribute. For a stimulus on a circle, such as direction, the preferred values are angles and the estimate is the angle of the vector sum, $\operatorname{atan2}\!\big(\sum_i n_i\sin c_i,\ \sum_i n_i\cos c_i\big)$.

### Maximum likelihood

The **maximum-likelihood** (ML) decoder picks the stimulus under which the observed counts are most probable. For independent Poisson neurons the log-likelihood of a candidate $s$ is

$$\ell(s) = \sum_i \big[\,n_i \ln\big(f_i(s)\,T\big) - f_i(s)\,T - \ln n_i!\,\big].$$

The last term does not depend on $s$ and is dropped. The estimate $\hat s_{\mathrm{ML}}$ is the candidate with the largest $\ell(s)$, found here by evaluating $\ell$ on a fixed grid and taking the first best value in the case of ties. ML needs the tuning curves, which are estimated beforehand from training trials (the previous lessons), and uses the full Poisson variability. For Gaussian tuning with evenly spaced preferred values densely covering the range, $\sum_i f_i(s)$ is nearly constant and the ML estimate is close to the population vector away from the edges.

```python
import math


def population_vector(counts, centers):
    """Count-weighted mean of preferred values; None if there are no spikes."""
    total = sum(counts)
    if total == 0:
        return None
    return sum(n * c for n, c in zip(counts, centers)) / total


def ml_decode(counts, centers, sigma, rmax, T, grid):
    """Grid stimulus with the largest Poisson log-likelihood (first on ties)."""
    best, best_ll = None, None
    for s in grid:
        ll = 0.0
        for n, c in zip(counts, centers):
            mu = rmax * math.exp(-(s - c) ** 2 / (2 * sigma ** 2)) * T
            ll += n * math.log(mu) - mu
        if best_ll is None or ll > best_ll:
            best, best_ll = s, ll
    return best
```

With centers $-60, -30, 0, 30, 60$ degrees, $\sigma = 30$, $r_{\max} = 20$ Hz, $T = 0.5$ s and counts $(1, 4, 8, 5, 1)$, the ML estimate on a grid of 5-degree steps is $0^\circ$, while the population vector is $30/19 = 1.58^\circ$.

### How accurate can a decoder be?

The **Fisher information** measures how much a response tells about the stimulus. For independent Poisson neurons,

$$J(s) = T\sum_i \frac{f_i'(s)^2}{f_i(s)}, \qquad f_i'(s) = -\frac{s - c_i}{\sigma^2}\, f_i(s),$$

so for Gaussian tuning $J(s) = T\sum_i \frac{(s - c_i)^2}{\sigma^4}\, f_i(s)$. The **Cramér–Rao bound** says that any unbiased estimator has variance at least $1/J(s)$. Information adds across independent neurons and grows in proportion to $T$, so doubling the window lowers the smallest possible standard deviation by $\sqrt 2$. Notice that a neuron carries the most information about stimuli on the flanks of its tuning curve (for Gaussian tuning, at a distance $\sqrt 2\,\sigma$ from the peak) and none at its peak, where $f' = 0$. Real neurons have correlated noise, which can change this scaling; the independent Poisson formula is a baseline.

### Cross-validation and limits

Estimate tuning curves from some trials and decode others; decoding the same trials used to fit the curves overstates the accuracy. A decoder's success shows that the information is present in the recorded neurons, not that the brain reads it out that way.

@example
title: A population vector and its bound
problem: Neurons with preferred values $c = (0, 20, 40)$ degrees respond with counts $(1, 5, 4)$. Find the population-vector estimate. Then, for two independent Poisson neurons with Gaussian tuning ($c = 0$ and $c = 20$, $\sigma = 10$, $r_{\max} = 30$ Hz) and window $T = 0.5$ s, compute $J(10)$ and the Cramér–Rao bound on the standard deviation of an unbiased estimate at $s = 10$.
step: The population vector is $\sum n_i c_i / \sum n_i = (1\cdot 0 + 5\cdot 20 + 4\cdot 40)/10 = 260/10 = 26^\circ$.
step: At $s = 10$ both neurons are 10 degrees from their centers, so each has $f = 30e^{-0.5} = 18.196$ Hz.
step: Each neuron's term is $T (s - c)^2 f/\sigma^4 = 0.5 \times 100 \times 18.196/10^4 = 0.0910$, so $J(10) = 2 \times 0.0910 = 0.182$ per square degree.
step: The bound is $1/\sqrt{J} = 1/\sqrt{0.182} = 2.34^\circ$: no unbiased decoder can do better than a standard deviation of about 2.3 degrees from these two neurons in this window.
answer: $\hat s_{PV} = 26^\circ$; $J(10) = 0.182$ deg$^{-2}$ and a bound of $2.34^\circ$.

@mistakes
- Using the population vector for a circular variable by averaging angles directly: $350^\circ$ and $10^\circ$ average to $180^\circ$ instead of $0^\circ$; use the vector sum.
- Forgetting the $-\mu$ term in the Poisson log-likelihood when neurons have different rates at different stimuli: the term depends on $s$ and cannot be dropped.
- Decoding on the same trials used to estimate the tuning curves, which makes the decoder look better than it is.
- Treating a successful decoder as proof that the brain uses that code.

```python
import math


def ml_decode_table(counts, table, T):
    """Index of the candidate stimulus with the largest Poisson log-likelihood."""
    best, best_ll = 0, None
    for j, row in enumerate(table):
        ll = sum(n * math.log(r * T) - r * T for n, r in zip(counts, row))
        if best_ll is None or ll > best_ll:
            best, best_ll = j, ll
    return best
```
hint: Compute the log-likelihood for each row of the table and keep the index of the best; replace the best only when a candidate is strictly better.
solution: Drop the $\ln n!$ term, which is the same for every candidate, but keep $-r T$, which differs between candidates. model:
```python
import math


def fisher_information(s, centers, sigma, rmax, T):
    """Fisher information of independent Poisson neurons, Gaussian tuning."""
    total = 0.0
    for c in centers:
        f = rmax * math.exp(-(s - c) ** 2 / (2 * sigma ** 2))
        fp = -(s - c) / sigma ** 2 * f
        total += fp * fp / f
    return T * total
```
hint: For each neuron compute its rate and its slope at `s`, add slope squared over rate, and multiply by the window at the end.
solution: A neuron whose peak is exactly at `s` has zero slope and contributes nothing (third test): information comes from the flanks of the tuning curves. Information adds across independent neurons, so the three-neuron test is the sum of the contributions of the neurons at $-10$ and $10$ degrees, each $0.1213$, and the one at 0, which is zero.

model:
```python
import math


def circular_population_vector(counts, centers_deg):
    """Angle (deg, 0-360) of the count-weighted vector sum of preferred angles."""
    if sum(counts) == 0:
        return None
    x = sum(n * math.cos(math.radians(c)) for n, c in zip(counts, centers_deg))
    y = sum(n * math.sin(math.radians(c)) for n, c in zip(counts, centers_deg))
    return math.degrees(math.atan2(y, x)) % 360
```
hint: Add the cosine and sine components separately, weighted by the counts; convert the angle back with `atan2`, and bring negative angles into range with the modulo operator.
solution: Averaging angles directly would put the estimate for counts at 0 and 315 degrees near 157.5 degrees; the vector sum correctly gives 337.5 degrees. The negative angle returned by `atan2` for a point below the horizontal axis is shifted into $[0, 360)$ by the modulo.

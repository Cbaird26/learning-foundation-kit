@article
Record 100 neurons at once and each time bin gives a point in a 100-dimensional space, one axis per neuron. You cannot look at that cloud. But neurons are not independent: they share inputs, tuning and fluctuations, so the cloud is often elongated along a few directions. **Principal component analysis** (PCA) finds those directions. It is the standard first look at a population recording.

### The data matrix and its covariance

Arrange the recording as a list of rows: each row is one time bin or trial (a **sample**), each column one neuron, and the entry is a spike count or a rate. Say there are $n$ rows and $d$ neurons. First **center** each column by subtracting its mean over the rows, giving $\mathbf{X}_c$. The $d \times d$ **covariance matrix** is

$$\mathbf{C} = \frac{1}{n - 1}\,\mathbf{X}_c^\top \mathbf{X}_c, \qquad C_{ij} = \frac{1}{n-1}\sum_{t=1}^{n} (x_{ti} - \bar x_i)(x_{tj} - \bar x_j),$$

with the sample divisor $n - 1$. The diagonal holds each neuron's variance and the off-diagonal entries the covariances between neurons.

### Principal components

A direction in neuron space is a unit vector $\mathbf{v}$. The variance of the activity projected on it (the scores $\mathbf{X}_c\mathbf{v}$) is $\mathbf{v}^\top \mathbf{C}\,\mathbf{v}$. The **first principal component** (PC1) is the unit vector $\mathbf{v}_1$ that maximizes this variance; it is the eigenvector of $\mathbf{C}$ with the largest eigenvalue $\lambda_1$, and $\lambda_1$ is the variance it captures. The second component $\mathbf{v}_2$ maximizes the variance among directions perpendicular to $\mathbf{v}_1$, and so on. The eigenvalues sum to the total variance, $\sum_k \lambda_k = \operatorname{trace}(\mathbf{C})$, so the **fraction of variance explained** by component $k$ is $\lambda_k/\operatorname{trace}(\mathbf{C})$.

### Power iteration

For tiny matrices we find $\mathbf{v}_1$ by **power iteration**. Start from the fixed vector $\mathbf{v} = (1, 2, \dots, d)$. Repeat a fixed number of times: replace $\mathbf{v}$ by $\mathbf{C}\mathbf{v}$ and rescale it to length 1. Each multiplication stretches the component along $\mathbf{v}_1$ by $\lambda_1$ and the component along $\mathbf{v}_2$ by $\lambda_2 < \lambda_1$, so after $m$ steps the ratio of the second to the first is multiplied by $(\lambda_2/\lambda_1)^m$ and the vector converges to $\mathbf{v}_1$, provided the start has some component along it. The eigenvalue is the **Rayleigh quotient** $\lambda = \mathbf{v}^\top\mathbf{C}\mathbf{v}$. An eigenvector is defined only up to sign, so we fix the sign by making the entry of largest absolute value (the first, in a tie) positive. **Deflation** finds the next component: subtract the found component, $\mathbf{C} \leftarrow \mathbf{C} - \lambda_1 \mathbf{v}_1\mathbf{v}_1^\top$, and run power iteration again.

```python
import math


def covariance(X):
    """Sample covariance (divisor n - 1) of the columns of a list of rows."""
    n, d = len(X), len(X[0])
    mean = [sum(row[j] for row in X) / n for j in range(d)]
    return [[sum((row[i] - mean[i]) * (row[j] - mean[j]) for row in X) / (n - 1)
             for j in range(d)] for i in range(d)]


def top_pc(C, iters):
    """Eigenvalue and unit eigenvector for the largest eigenvalue of C."""
    d = len(C)
    v = [float(j + 1) for j in range(d)]
    for _ in range(iters):
        w = [sum(C[i][j] * v[j] for j in range(d)) for i in range(d)]
        norm = math.sqrt(sum(x * x for x in w))
        if norm == 0:
            return 0.0, [0.0] * d
        v = [x / norm for x in w]
    lam = sum(v[i] * C[i][j] * v[j] for i in range(d) for j in range(d))
    k = max(range(d), key=lambda i: abs(v[i]))
    if v[k] < 0:
        v = [-x for x in v]
    return lam, v
```

For the six-bin, three-neuron recording with rows $(2,4,3), (3,6,1), (6,12,2), (1,2,3), (5,10,1), (3,6,2)$ the covariance has diagonal $3.47, 13.87, 0.80$, and PC1 is $(0.443, 0.887, -0.132)$ with $\lambda_1 = 17.63$, which explains $17.63/18.13 = 97\%$ of the variance: the first two neurons rise and fall together (the second fires about twice as much as the first), and the activity is nearly one-dimensional.

### How many dimensions?

The number of components needed to reach, say, 90% of the variance is a common but arbitrary measure. A smoother one is the **participation ratio**,

$$\mathrm{PR} = \frac{\big(\sum_k \lambda_k\big)^2}{\sum_k \lambda_k^2} = \frac{\operatorname{trace}(\mathbf{C})^2}{\sum_{ij} C_{ij}^2},$$

which equals 1 when all the variance is on one component and $d$ when it is spread equally. Dimensionality estimates depend on the number of samples and on noise: independent noise in each neuron adds a flat floor to the eigenvalues, and with few samples the eigenvalues are inflated. PCA is **linear** and **unsupervised**: it finds directions of large variance, not directions that are important for behavior, and its components need not be interpretable. It also depends on scale: neurons with large counts have large variances and dominate unless you rescale each column (for example to unit variance) first.

@example
title: PCA of two neurons by hand and by one power-iteration step
problem: Two neurons have counts $(3, 1), (1, 3), (5, 5), (3, 3)$ in four bins. Find the covariance matrix, its eigenvalues, the fraction of variance in PC1, and the first power-iteration step from $\mathbf{v} = (1, 2)$.
step: The means are $3$ and $3$. The centered rows are $(0, -2), (-2, 0), (2, 2), (0, 0)$. Variances: $(0 + 4 + 4 + 0)/3 = 8/3$ for each neuron. Covariance: $(0 + 0 + 4 + 0)/3 = 4/3$.
step: So $\mathbf{C} = \begin{pmatrix} 8/3 & 4/3 \\ 4/3 & 8/3 \end{pmatrix}$. A matrix $\begin{pmatrix} a & b \\ b & a\end{pmatrix}$ has eigenvalues $a + b = 4$ (eigenvector $(1, 1)/\sqrt2$) and $a - b = 4/3$ (eigenvector $(1, -1)/\sqrt2$).
step: The fraction in PC1 is $4/(4 + 4/3) = 4/(16/3) = 0.75$.
step: One power-iteration step from $\mathbf{v} = (1, 2)$: $\mathbf{C}\mathbf{v} = (8/3 + 8/3,\ 4/3 + 16/3) = (16/3, 20/3)$, of length $\sqrt{256 + 400}/3 = 8.54$, so the new $\mathbf{v} = (0.625, 0.781)$, already closer to $(0.707, 0.707)$ than the start $(0.447, 0.894)$.
answer: $\lambda = 4$ and $4/3$; PC1 explains $75\%$; after one step $\mathbf{v} = (0.625, 0.781)$.

@mistakes
- Forgetting to center the columns: the first "component" then mostly points toward the mean activity, not the direction of variation.
- Mixing divisors ($n$ in one place and $n - 1$ in another); the explained-variance fractions do not change, but the eigenvalues do.
- Starting power iteration from a vector perpendicular to the top component, or running too few iterations when $\lambda_2$ is close to $\lambda_1$.
- Reading the sign or the order of the neurons in a component as meaningful by itself: the sign of an eigenvector is arbitrary.

```python
def reconstruction_error(X, v):
    """Variance left over after keeping only the projection onto unit vector v."""
    n, d = len(X), len(X[0])
    mean = [sum(row[j] for row in X) / n for j in range(d)]
    total = 0.0
    for row in X:
        c = [row[j] - mean[j] for j in range(d)]
        score = sum(c[j] * v[j] for j in range(d))
        total += sum((c[j] - score * v[j]) ** 2 for j in range(d))
    return total / (n - 1)
```
hint: For each centered row, subtract `score * v` from it and add up the squares of what remains; divide by $n - 1$ at the end.
solution: For a unit vector the leftover variance equals the trace of the covariance matrix minus $\mathbf{v}^\top\mathbf{C}\mathbf{v}$: here $12 - 10.93 = 1.07$. When all the variation lies along `v` (the third test, where only the second neuron varies) nothing is left over, and PC1 is the unit vector that makes this error smallest.

```python
import math


def _top(C, iters):
    d = len(C)
    v = [float(j + 1) for j in range(d)]
    for _ in range(iters):
        w = [sum(C[i][j] * v[j] for j in range(d)) for i in range(d)]
        norm = math.sqrt(sum(x * x for x in w))
        if norm == 0:
            return 0.0, [0.0] * d
        v = [x / norm for x in w]
    lam = sum(v[i] * C[i][j] * v[j] for i in range(d) for j in range(d))
    k = max(range(d), key=lambda i: abs(v[i]))
    if v[k] < 0:
        v = [-x for x in v]
    return lam, v


def second_pc(C, iters):
    """Second eigenpair of a symmetric matrix by power iteration and deflation."""
    d = len(C)
    lam1, v1 = _top(C, iters)
    D = [[C[i][j] - lam1 * v1[i] * v1[j] for j in range(d)] for i in range(d)]
    return _top(D, iters)
```
hint: Run power iteration once to get the top pair, build the deflated matrix by subtracting $\lambda_1\mathbf{v}_1\mathbf{v}_1^\top$ entry by entry, and run the same routine again on it.
solution: Deflation removes the variance along $\mathbf{v}_1$, so the largest eigenvalue of the deflated matrix is $\lambda_2$ and its eigenvector is $\mathbf{v}_2$. The second test's recording has a third eigenvalue near 0 because the second neuron is twice the first, so the second component captures the remaining 0.50 of variance, mostly along the third neuron.

model:
```python
def participation_ratio(C):
    """(sum of eigenvalues)^2 / (sum of squared eigenvalues), from C directly."""
    trace = sum(C[i][i] for i in range(len(C)))
    frob = sum(x * x for row in C for x in row)
    if frob == 0:
        return 0.0
    return trace * trace / frob
```
hint: The sum of squared eigenvalues equals the sum of all squared entries of a symmetric matrix, so no eigenvalues are needed.
solution: For a symmetric matrix, $\sum_k\lambda_k^2 = \operatorname{trace}(\mathbf{C}^2) = \sum_{ij}C_{ij}^2$. The identity matrix has equal eigenvalues and gives the full dimension 3, and the rank-one matrix with all entries 2 gives 1. The last test has eigenvalues 3 and 1, so $16/10$.

solution: Poisson-like counts have variance that grows with the mean, so the high-count neuron contributes most of the total variance and PC1 tends to point along it. A covariance matrix is positive semidefinite, so its eigenvalues are not negative.

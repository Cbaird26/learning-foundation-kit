@article
Two neurons next to each other on an electrode both respond to the same stimulus. Are they independent, each following the stimulus on its own, or do they share inputs or connections that make them fire together? The raw rasters cannot answer this by eye. We need a measure of whether the two neurons' spikes are related beyond what the stimulus explains.

### Spike-count correlation

Present the **same** stimulus on $N$ trials and count spikes of neuron A and neuron B in a fixed window, giving $x_1, \dots, x_N$ and $y_1, \dots, y_N$. The **spike-count correlation** (also called noise correlation) is the Pearson correlation coefficient,

$$r_{xy} = \frac{\sum_i (x_i - \bar x)(y_i - \bar y)}{\sqrt{\sum_i (x_i - \bar x)^2}\ \sqrt{\sum_i (y_i - \bar y)^2}} \in [-1, 1].$$

Both numerator and denominator have the same factor $N - 1$ if you write them as covariance over standard deviations, so it cancels. It must be computed for a single stimulus, or after subtracting each stimulus's mean count: pooling stimuli would add the **signal correlation** (two neurons with similar tuning rise and fall with the stimulus together) to the trial-to-trial co-variation that remains when the stimulus is fixed. In sensory cortex, noise correlations for nearby pairs are typically small and positive, but their size depends on the area, the neurons, the window and the state of the animal, so measure them. If either neuron has zero variance across trials, $r$ is undefined.

### The cross-correlogram

Count correlation uses one number per trial. A **cross-correlogram** keeps fine timing. Spike times here are in **milliseconds**. For every pair of one spike $t_A$ from neuron A and one spike $t_B$ from neuron B, compute the **lag**

$$d = t_B - t_A \quad \text{(ms)},$$

so a **positive lag means B fires after A**. Choose a maximum lag $L$ and a bin width $w$ that divides $2L$. The lag axis is divided into $2L/w$ half-open bins $[-L + kw,\ -L + (k+1)w)$ for $k = 0, \dots, 2L/w - 1$; a pair with $d$ exactly equal to $-L$ goes into the first bin and a pair with $d = L$ is dropped. The correlogram entry is the number of pairs whose lag falls in the bin.

```python
def ccg(a, b, max_lag, bin_ms):
    """Counts of lags d = t_b - t_a in half-open bins over [-max_lag, max_lag)."""
    n_bins = 2 * max_lag // bin_ms
    counts = [0] * n_bins
    for ta in a:
        for tb in b:
            d = tb - ta
            if -max_lag <= d < max_lag:
                counts[(d + max_lag) // bin_ms] += 1
    return counts
```

For $A = (10, 40, 80, 120)$ and $B = (13, 42, 79, 125, 200)$ with $L = 10$ and $w = 5$, the nearby pairs have lags $3, 2, -1, 5$ ms, and the correlogram over bins $[-10,-5), [-5,0), [0,5), [5,10)$ is $(0, 1, 2, 1)$. The cost is the number of spike pairs, which is fine for short recordings and is done in practice by sorting and sweeping.

### What to expect by chance

If the two trains were independent with constant rates, each bin would hold about $n_A\, n_B\, w / T$ pairs, where $n_A$ and $n_B$ are the spike counts and $T$ is the recording length in the same unit as $w$. With $n_A = 200$, $n_B = 150$, $T = 100\,000$ ms and $w = 2$ ms, this is $0.6$ pairs per bin. Counts well above this near zero lag indicate **synchrony**; counts well below it indicate inhibition or a refractory effect. Because firing rates change with the stimulus, a stimulus-locked pair of rates also makes a peak. A **shift predictor** recomputes the correlogram after shifting one train by a fixed lag larger than the correlation time (or by a whole number of trials, using the other trial's spikes): any peak that survives is due to the common stimulus drive, not to interaction between the neurons.

### Reading a correlogram

A narrow peak within about 1 to 5 ms at a positive lag is the classic signature consistent with a direct excitatory connection from A to B; a narrow peak centered near zero lag is consistent with a shared input. Neither proves it: correlation is not causation, and a trough can come from inhibition or from both neurons' refractory periods. The **autocorrelogram** is the same computation of a train with itself, leaving out each spike's pairing with itself; its lags come in $\pm$ pairs (so it is symmetric apart from bin edges) and it shows bursts (a peak at short lags) and refractoriness (an empty bin near zero).

@example
title: A noise correlation by hand
problem: Over five repetitions of one stimulus, neuron A fires $4, 7, 3, 6, 5$ spikes and neuron B fires $3, 2, 5, 4, 6$ spikes in a 500 ms window. Compute the spike-count correlation.
step: The means are $\bar x = 25/5 = 5$ and $\bar y = 20/5 = 4$. The deviations are $x - \bar x = -1, 2, -2, 1, 0$ and $y - \bar y = -1, -2, 1, 0, 2$.
step: The products of deviations are $1, -4, -2, 0, 0$, with sum $-5$. The squared deviations sum to $1 + 4 + 4 + 1 + 0 = 10$ for A and $1 + 4 + 1 + 0 + 4 = 10$ for B.
step: Then $r = -5/\sqrt{10 \times 10} = -0.5$.
step: With only five trials this is a very uncertain estimate; a correlation of $-0.5$ from $N = 5$ is compatible with no correlation at all, so it should not be reported as a finding without more trials.
answer: $r = -0.5$.

@mistakes
- Pooling trials from different stimuli before correlating counts, which adds the signal correlation to the noise correlation.
- Flipping the lag sign: with $d = t_B - t_A$ a peak at a positive lag means B follows A; say which train is the reference.
- Counting a pair at the maximum lag in the last bin of the correlogram when the bins are half-open, or leaving out the pair at exactly $-L$.
- Concluding that a peak shows a synaptic connection without checking the stimulus-locked rates and a shift predictor.

```python
import math


def count_correlation(x, y):
    """Pearson correlation of two count lists; None if a list is constant."""
    n = len(x)
    mx = sum(x) / n
    my = sum(y) / n
    sxy = sum((a - mx) * (b - my) for a, b in zip(x, y))
    sxx = sum((a - mx) ** 2 for a in x)
    syy = sum((b - my) ** 2 for b in y)
    if sxx == 0 or syy == 0:
        return None
    return sxy / math.sqrt(sxx * syy)
```
hint: Center both lists, form the three sums, and guard against a zero denominator before dividing.
solution: The correlation is the sum of products of deviations over the square root of the product of the sums of squares. A constant list has no variance, so the correlation is undefined; returning `None` avoids a division by zero. Because integer counts are exact, comparing a sum of squares with 0 is safe here.

model:
```python
def autocorrelogram(spikes, max_lag, bin_ms):
    """Counts of lags between different spikes of one train."""
    n_bins = 2 * max_lag // bin_ms
    counts = [0] * n_bins
    for i, ti in enumerate(spikes):
        for j, tj in enumerate(spikes):
            if i != j:
                d = tj - ti
                if -max_lag <= d < max_lag:
                    counts[(d + max_lag) // bin_ms] += 1
    return counts
```
hint: Use the cross-correlogram loop with the same train twice, but skip the pair where both indices are equal.
solution: Skipping $i = j$ removes the trivial zero lag of each spike with itself, so the bin holding 0 is not inflated. Each unordered pair is counted in both directions, so the lags come in $\pm$ pairs, but half-open bins are not mirror images: a lag of $-6$ falls in $[-6, -3)$ while $+6$ falls in $[6, 9)$, so the counts are not symmetric. In the fourth test four pairs of spikes lie within 12 ms, giving 8 ordered pairs.

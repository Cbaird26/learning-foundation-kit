@article
Hubel and Wiesel (1959, 1962) found that a neuron in primary visual cortex responds best to a bar of light at one orientation and responds less and less as the bar rotates away. Plot mean firing rate against orientation and you get the neuron's **tuning curve**. It is the basic summary of what a neuron cares about, and the first thing most analyses estimate.

### From trials to a tuning curve

Present each stimulus value many times and count spikes in a fixed window of $T$ seconds on each trial. The tuning curve is the mean rate for each stimulus, $r(s) = \bar n(s)/T$, in hertz, where $\bar n(s)$ is the mean count over the trials with stimulus $s$. Always report the number of trials per stimulus: a mean over three trials is far less certain than a mean over thirty.

### Cosine tuning

For a variable on a circle, such as direction of motion in degrees, a simple model is

$$r(\theta) = b + a\cos(\theta - \theta_0),$$

with baseline $b$ (Hz), amplitude $a$ (Hz) and **preferred direction** $\theta_0$. Using $\cos(\theta - \theta_0) = \cos\theta_0 \cos\theta + \sin\theta_0 \sin\theta$, write the model as linear in three numbers,

$$r(\theta) = b + c_1\cos\theta + c_2\sin\theta, \qquad c_1 = a\cos\theta_0,\ c_2 = a\sin\theta_0 .$$

Fit them by **least squares**, minimizing $\sum_i \big(r_i - b - c_1\cos\theta_i - c_2\sin\theta_i\big)^2$. When the $N \ge 3$ angles are equally spaced around the full circle, $\sum_i \cos\theta_i = \sum_i \sin\theta_i = 0$, $\sum_i \cos^2\theta_i = \sum_i \sin^2\theta_i = N/2$ and $\sum_i \cos\theta_i \sin\theta_i = 0$, so the normal equations separate and the solution is

$$b = \frac{1}{N}\sum_i r_i, \quad c_1 = \frac{2}{N}\sum_i r_i \cos\theta_i, \quad c_2 = \frac{2}{N}\sum_i r_i \sin\theta_i,$$

then $a = \sqrt{c_1^2 + c_2^2}$ and $\theta_0 = \operatorname{atan2}(c_2, c_1)$, taken in $[0^\circ, 360^\circ)$. For eight directions $0^\circ, 45^\circ, \dots, 315^\circ$ and mean rates $12, 19, 22, 15, 8, 4, 3, 6$ Hz, the fit is $b = 11.125$ Hz, $a = 9.23$ Hz, $\theta_0 = 77.1^\circ$. The raw maximum is at $90^\circ$ (22 Hz), but the fit uses all eight points, so it places the peak between the sampled directions.

```python
import math


def cosine_fit(angles_deg, rates):
    """Closed-form fit of b + a*cos(theta - theta0) for equally spaced angles.

    Returns (b, a, theta0_deg) with theta0 in [0, 360).
    """
    n = len(rates)
    b = sum(rates) / n
    c1 = 2 / n * sum(r * math.cos(math.radians(t)) for t, r in zip(angles_deg, rates))
    c2 = 2 / n * sum(r * math.sin(math.radians(t)) for t, r in zip(angles_deg, rates))
    return b, math.hypot(c1, c2), math.degrees(math.atan2(c2, c1)) % 360
```

If the angles are not equally spaced, the sums no longer separate and you solve a $3 \times 3$ linear system instead; NumPy's `numpy.linalg.lstsq` does that in one call.

### Grid search for a nonlinear parameter

A bump-shaped tuning curve for a variable on a line, such as stimulus position, is often modeled by a Gaussian,

$$r(s) = b + A\, e^{-(s - c)^2/(2\sigma^2)},$$

which is **nonlinear** in the center $c$ and width $\sigma$, so there is no closed form. A **grid search** evaluates the sum of squared errors $\mathrm{SSE}(c) = \sum_i (r_i - r(s_i; c))^2$ on a list of candidate values and keeps the best. It is slow in many dimensions but transparent in one or two, and with a fixed grid the answer is only as fine as the grid. Ties go to the first candidate in the list.

### Summaries of selectivity

The preferred stimulus is the argmax of the fitted curve. Two summaries of selectivity are common. The **modulation depth** is $(r_{\max} - r_{\min})/(r_{\max} + r_{\min})$. For direction tuning, the **direction selectivity index** compares the preferred direction with the opposite one: $\mathrm{DSI} = (R_{\text{pref}} - R_{\text{null}})/(R_{\text{pref}} + R_{\text{null}})$, which is 0 for a neuron that responds equally to both and 1 for a neuron silent in the null direction.

### Limits

A tuning curve measured with one stimulus dimension is a slice of a higher-dimensional response: change contrast, size or speed, and the curve changes. Cosine tuning cannot represent a neuron with two peaks (an axis-tuned neuron), and the fit gives no information about trial-to-trial variability, the subject of the next lesson.

@example
title: Fitting four directions
problem: A neuron's mean rates at $0^\circ, 90^\circ, 180^\circ, 270^\circ$ are $6, 16, 6, 2$ Hz. Fit $b + a\cos(\theta - \theta_0)$ and predict the rate at $45^\circ$.
step: The baseline is the mean: $b = (6 + 16 + 6 + 2)/4 = 7.5$ Hz.
step: Compute $c_1 = \tfrac{2}{4}(6\cos 0^\circ + 16\cos 90^\circ + 6\cos 180^\circ + 2\cos 270^\circ) = \tfrac12(6 + 0 - 6 + 0) = 0$.
step: Compute $c_2 = \tfrac{2}{4}(6\sin 0^\circ + 16\sin 90^\circ + 6\sin 180^\circ + 2\sin 270^\circ) = \tfrac12(0 + 16 + 0 - 2) = 7$.
step: So $a = \sqrt{0 + 49} = 7$ Hz and $\theta_0 = \operatorname{atan2}(7, 0) = 90^\circ$. The predicted rate at $45^\circ$ is $7.5 + 7\cos(45^\circ - 90^\circ) = 7.5 + 7(0.7071) = 12.45$ Hz.
answer: $b = 7.5$ Hz, $a = 7$ Hz, $\theta_0 = 90^\circ$; the prediction at $45^\circ$ is $12.45$ Hz.

@mistakes
- Mixing degrees and radians: `math.cos` takes radians, so convert angles with `math.radians` first.
- Using the closed-form fit when the angles are unequally spaced or cover only part of the circle: the sums no longer vanish and the answer is wrong.
- Reading the preferred direction as the stimulus with the highest observed rate when the data are noisy; a fit that uses all points is usually more stable.
- Treating a tuning curve as a complete description of the neuron: it depends on the other stimulus parameters, which were held fixed.

```python
def mean_rates_by_stimulus(stims, counts, T):
    """Tuning curve: mean spike count per stimulus divided by T, sorted."""
    groups = {}
    for s, n in zip(stims, counts):
        groups.setdefault(s, []).append(n)
    return [(s, sum(v) / len(v) / T) for s, v in sorted(groups.items())]
```

model:
```python
import math


def fit_center(stims, rates, b, amp, sigma, grid):
    """Grid search for the Gaussian center with the smallest SSE."""
    best, best_sse = None, None
    for c in grid:
        sse = 0.0
        for s, r in zip(stims, rates):
            pred = b + amp * math.exp(-(s - c) ** 2 / (2 * sigma ** 2))
            sse += (r - pred) ** 2
        if best_sse is None or sse < best_sse:
            best, best_sse = c, sse
    return best
```
hint: Loop over the candidate centers, compute the SSE for each, and keep the candidate with the smallest value, replacing the best only on a strictly smaller SSE.
solution: Replacing the best only when the SSE is strictly smaller keeps the first of any exact ties (the last test, where the amplitude is 0, makes every candidate tie). The third test shows the grid's limit: the true center 8 is not on the coarse grid, so the nearest grid value, 10, is returned.

```python
def direction_selectivity(rates):
    """(R_pref - R_null) / (R_pref + R_null) for evenly spaced directions."""
    n = len(rates)
    pref = rates.index(max(rates))
    null = (pref + n // 2) % n
    total = rates[pref] + rates[null]
    if total == 0:
        return 0.0
    return (rates[pref] - rates[null]) / total
```
hint: Find the index of the maximum, add half the list length with wraparound, and form the ratio after checking for a zero denominator.
solution: The wraparound `(pref + n // 2) % n` finds the opposite direction even when the preferred index is in the second half of the list: in the last test the maximum is at index 5, whose null is index 1 (rate 8), giving $12/28$. In the fifth test the null rate is 0, so the index is 1.

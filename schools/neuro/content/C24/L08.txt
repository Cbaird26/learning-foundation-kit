@article
Electrodes record a handful of neurons. **Two-photon calcium imaging** lets a microscope watch hundreds of neurons at once: a fluorescent indicator brightens when calcium enters a cell, and each action potential lets in a puff of calcium. But what the microscope records is a brightness, not a spike. The indicator binds and releases calcium slowly compared with a spike's 1 ms, so the trace shows a sharp rise at each spike followed by a decay lasting hundreds of milliseconds to seconds. Turning brightness back into spikes is an inverse problem.

### Fluorescence to $\Delta F/F_0$

For each cell the **region of interest** (ROI) gives a fluorescence value $F_t$ per frame, sampled every $\Delta t$ seconds (for example $\Delta t = 0.1$ s, a frame rate of 10 Hz). Because cells differ in indicator expression and optics, we normalize to the relative change from a baseline $F_0$:

$$\frac{\Delta F}{F_0}(t) = \frac{F_t - F_0}{F_0}.$$

In this lesson $F_0$ is the mean of the first $n_b$ frames, chosen to be before any stimulus. (Other analyses use a low percentile of a sliding window, which tracks slow drift.) Neuropil, the glow of out-of-focus processes, adds a contaminating signal that is usually subtracted before this step.

### A model of calcium dynamics

A common simple model treats the calcium-dependent signal $c_t$ (in units of $\Delta F/F_0$) as an **autoregressive process of order 1**, AR(1):

$$c_t = \gamma\, c_{t-1} + a\, s_t, \qquad \gamma = e^{-\Delta t/\tau},$$

where $s_t \ge 0$ is the number of spikes in frame $t$, $a$ is the signal gained per spike, and $\tau$ is the decay time constant of the indicator (from a few hundred milliseconds to more than a second, depending on the indicator). Each frame, the signal decays by the factor $\gamma$ and jumps by $a$ for each spike. For $\Delta t = 0.1$ s and $\tau = 0.5$ s, $\gamma = e^{-0.2} = 0.8187$; one spike in frame 2 and two in frame 6 give, with $a = 1$,
$$c = (0,\ 0,\ 1,\ 0.819,\ 0.670,\ 0.549,\ 2.449,\ 2.005,\ 1.642,\ 1.344).$$
The observed trace adds measurement noise, $y_t = c_t + \epsilon_t$.

### Inverting the model

If $c$ were noiseless we could solve for the spikes: $a\,s_t = c_t - \gamma\, c_{t-1}$, taking $c_{-1} = 0$. This **deconvolution** step undoes the decay. With noise, applying the same formula to $y_t$ amplifies the noise: if each $\epsilon_t$ has standard deviation $\sigma$, then $y_t - \gamma y_{t-1}$ has standard deviation $\sigma\sqrt{1 + \gamma^2}$. We then clip negative values to 0, since spike counts cannot be negative, and either keep the amplitude as a measure of activity or **threshold**: declare an event in frame $t$ when the estimate reaches a criterion; a count estimate is the estimate divided by $a$ and rounded.

```python
def deconvolve_ar1(y, gamma):
    """Estimate a * s_t = y_t - gamma * y_{t-1}, clipped at 0, with y_{-1} = 0."""
    out, prev = [], 0.0
    for v in y:
        out.append(max(0.0, v - gamma * prev))
        prev = v
    return out
```

Real methods (nonnegative deconvolution with a sparsity penalty, or trained neural networks) do better than this subtraction, but they answer the same question.

### What the trace cannot tell you

- **Timing** is limited by the frame interval: the estimate says a spike occurred in a frame, not when within it.
- **Counts** are ambiguous: one large event could be several spikes in one frame, and an indicator's response is not strictly proportional to the number of spikes (it saturates and has a nonlinear dependence on calcium).
- **Rates**: $\Delta F/F_0$ is not a firing rate, and neurons with different indicator levels or decay times cannot be compared by amplitude alone.
- Validation comes from **ground truth**: recording the same neuron with an electrode while imaging it and checking how well the inferred events match the real spikes.

### Spectra of calcium traces

Slow fluctuations in a calcium trace can be analyzed like an LFP. With frames every $\Delta t$ the Nyquist frequency is $1/(2\Delta t)$, only 5 Hz at 10 Hz imaging, so fast neural rhythms cannot be resolved by calcium imaging at all.

@example
title: Deconvolving a short trace
problem: A noiseless calcium trace with $\gamma = 0.8$ is $c = (0, 2, 1.6, 1.28, 3.024, 2.4192)$ in units of $\Delta F/F_0$, and each spike adds $a = 1$. Find the spike count in each frame.
step: Apply $a s_t = c_t - \gamma c_{t-1}$ with $c_{-1} = 0$. Frame 0 gives $0 - 0 = 0$.
step: Frame 1: $2 - 0.8 \times 0 = 2$. Frame 2: $1.6 - 0.8 \times 2 = 0$. Frame 3: $1.28 - 0.8 \times 1.6 = 0$.
step: Frame 4: $3.024 - 0.8 \times 1.28 = 3.024 - 1.024 = 2$. Frame 5: $2.4192 - 0.8 \times 3.024 = 0$.
step: With $a = 1$ the counts are $(0, 2, 0, 0, 2, 0)$: two spikes in each of frames 1 and 4. With real noise the zeros would be small non-zero numbers, and a threshold such as $0.5$ would separate events from noise.
answer: $(0, 2, 0, 0, 2, 0)$ spikes per frame.

@mistakes
- Using a baseline that contains activity: if the first frames include responses, $F_0$ is too high and $\Delta F/F_0$ is underestimated.
- Applying the deconvolution formula to noisy data without clipping or thresholding: the output is dominated by noise of size about $\sigma\sqrt{1 + \gamma^2}$.
- Using the decay time constant in frames or seconds inconsistently: $\gamma = e^{-\Delta t/\tau}$ needs both in the same unit.
- Reporting a $\Delta F/F_0$ amplitude as a firing rate in hertz.

def dff(F, n_base):
    """Relative fluorescence change with F0 = mean of the first n_base frames."""
    if not F:
        return []
    f0 = sum(F[:n_base]) / n_base
    return [(f - f0) / f0 for f in F]
```

def simulate_calcium(s, gamma, amp, noise):
    """AR(1) calcium signal from spike counts, plus supplied noise."""
    c, out = 0.0, []
    for count, eps in zip(s, noise):
        c = gamma * c + amp * count
        out.append(c + eps)
    return out
```
hint: Keep the noiseless signal $c$ separate from the noisy output; the noise is added to the output but must not feed back into the next update.

model:
```python
def event_frames(y, gamma, thr, min_gap):
    """Frames where the deconvolved signal reaches thr, at least min_gap apart."""
    events, prev, last = [], 0.0, None
    for t, v in enumerate(y):
        d = max(0.0, v - gamma * prev)
        prev = v
        if d >= thr and (last is None or t - last >= min_gap):
            events.append(t)
            last = t
    return events
```
hint: Compute the clipped difference for every frame (keeping the previous raw sample), and compare each candidate frame with the last event you recorded, not the last candidate.
solution: The differences are $0, 1, 0, 0.5, 0, 0, 1.5$ (times 1 in these units), so with threshold 0.4 the candidates are frames 1, 3 and 6. A minimum gap of 3 frames removes frame 3 because it is only 2 frames after frame 1, while frame 6 is 5 frames after it and stays; a gap of 6 leaves only frame 1. Comparing with the previous candidate rather than the last recorded event would give a different answer when several candidates are close together.

@quiz num
prompt: Each frame of a calcium trace has independent noise with standard deviation $\sigma = 0.1$ ($\Delta F/F_0$). With $\gamma = 0.8$, what is the standard deviation of the deconvolved quantity $y_t - \gamma y_{t-1}$ before clipping, to three decimal places?

hint: The variance of a difference of independent terms is the sum of the variances, with the second term scaled by $\gamma^2$.
solution: $\operatorname{Var}(\epsilon_t - \gamma\epsilon_{t-1}) = \sigma^2(1 + \gamma^2) = 0.01 \times 1.64$, so the standard deviation is $0.1 \times 1.281 = 0.128$, larger than the per-frame noise.

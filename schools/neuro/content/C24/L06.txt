@article
Place an electrode in cortex and filter the signal below a few hundred hertz instead of above: the sharp spikes disappear and a slowly wandering voltage remains, the **local field potential** (LFP). It reflects the summed transmembrane currents, mainly synaptic, of many neurons within a region around the electrode, and it often shows rhythms, such as the 8 to 12 Hz alpha rhythm in human EEG or gamma rhythms of roughly 30 to 80 Hz in cortex. How do we measure how much of a rhythm a trace contains? The tool is the Fourier transform: it writes the signal as a sum of sine waves and tells you the amplitude of each.

### A sampled signal

A recording is a list $x_0, x_1, \dots, x_{N-1}$ of $N$ voltages taken at times $t_n = n\,\Delta t$, with **sampling interval** $\Delta t$ in seconds. The **sampling frequency** is $f_s = 1/\Delta t$ in hertz. At $\Delta t = 0.004$ s, $f_s = 250$ Hz. The recording lasts $N\Delta t$ seconds.

### The discrete Fourier transform

The **discrete Fourier transform** (DFT) of the list is, for $k = 0, 1, \dots, N-1$,

$$X_k = \sum_{n=0}^{N-1} x_n\, e^{-2\pi i\, kn/N} = \sum_{n=0}^{N-1} x_n\Big[\cos\frac{2\pi kn}{N} - i \sin\frac{2\pi kn}{N}\Big].$$

This is the convention used in this course: **no factor of $1/N$ in the forward transform**. Each $X_k$ is a complex number whose size $|X_k|$ measures how much of a wave with $k$ cycles per recording the signal contains. Direct computation takes $N^2$ operations, which is fine for $N \le 64$; the fast Fourier transform does the same job in about $N \log N$ steps.

**Frequency axis.** Component $k$ corresponds to the frequency
$$f_k = \frac{k}{N\,\Delta t}\ \text{Hz}.$$
The spacing between neighboring frequencies, the **frequency resolution**, is $\Delta f = 1/(N\Delta t) = 1/(\text{duration})$: a longer recording gives finer resolution. For real signals $X_{N-k} = \overline{X_k}$ (the complex conjugate), so only $k = 0, \dots, N/2$ carry information. The largest frequency, at $k = N/2$, is the **Nyquist frequency** $f_s/2 = 1/(2\Delta t)$.

**Amplitudes.** For a sine wave $A\cos(2\pi f_k t_n + \varphi)$ whose frequency falls exactly on the grid, $|X_k| = A N/2$. So the amplitude of a rhythm is $2|X_k|/N$ for $0 < k < N/2$. The $k=0$ term is the sum of the signal, $X_0 = N \bar x$, so $|X_0|/N$ is the mean (the DC component); at $k = N/2$, $|X_{N/2}|/N$ is the amplitude.

For $N = 8$ and $\Delta t = 0.004$ s, the signal $x = (0, 1, 0, -1, 0, 1, 0, -1)$ is a sine wave repeating every 4 samples, $f = 1/(4 \times 0.004) = 62.5$ Hz, which is $k = 2$ because $f_k = k \times 31.25$ Hz. Its transform has $|X_2| = |X_6| = 4$ and all other $|X_k| = 0$; the amplitude $2 \cdot 4/8 = 1$ is right.

```python
import math


def dft(x):
    """DFT of a real list; returns a list of (real, imag) pairs, no 1/N."""
    n = len(x)
    out = []
    for k in range(n):
        re = sum(x[j] * math.cos(2 * math.pi * k * j / n) for j in range(n))
        im = -sum(x[j] * math.sin(2 * math.pi * k * j / n) for j in range(n))
        out.append((re, im))
    return out
```

### Aliasing

Sampling a wave of frequency $f$ above the Nyquist frequency does not lose it; it moves it. A sinusoid of frequency $f$ sampled at $f_s$ is indistinguishable from one at $f - m f_s$ for any integer $m$, so it appears at the **aliased frequency** in $[0, f_s/2]$. A 150 Hz wave sampled at 200 Hz looks like a 50 Hz wave. The cure is to filter out frequencies above $f_s/2$ with an analog filter before sampling, since afterward the alias cannot be told from a real 50 Hz component.

### Leakage

If a wave does not complete a whole number of cycles in the recording, its energy spreads across neighboring bins (**spectral leakage**), because the DFT treats the recording as one period of a repeating signal and the jump at the join looks like extra frequencies. Windowing (next lesson) reduces but does not remove leakage.

### Limits

The DFT assumes the signal is stationary over the recording: it reports how much of each frequency is present on average, not when. Rhythms that come and go need windowed or time-frequency methods. Also, the LFP is not a pure measure of spiking: it mixes synaptic currents with volume conduction, and the same voltage can come from different sources.

@example
title: Reading a short spectrum
problem: An LFP is sampled at $\Delta t = 0.005$ s, $N = 16$ samples. Give the frequency resolution, the Nyquist frequency, and where a $25$ Hz oscillation of amplitude $3$ µV appears, with its $|X_k|$.
step: The sampling frequency is $f_s = 1/0.005 = 200$ Hz and the recording lasts $16 \times 0.005 = 0.08$ s, so $\Delta f = 1/0.08 = 12.5$ Hz. The Nyquist frequency is $200/2 = 100$ Hz, at $k = 8$.
step: The bin for 25 Hz is $k = f/\Delta f = 25/12.5 = 2$. The wave has exactly 2 cycles in the recording, so there is no leakage.
step: The amplitude relation $A = 2|X_k|/N$ gives $|X_2| = A N/2 = 3 \times 16/2 = 24$ µV (the transform has the units of the signal, times samples).
step: By symmetry, $|X_{14}| = 24$ as well; the mirror image is the negative frequency.
answer: $\Delta f = 12.5$ Hz, Nyquist 100 Hz; the oscillation is in bin $k = 2$ with $|X_2| = 24$ µV.

@mistakes
- Forgetting that the frequency of bin $k$ is $k/(N\Delta t)$, not $k$: the index is cycles per recording, not hertz.
- Reading bins above $N/2$ as high frequencies; they are the mirror image (negative frequencies) of a real signal.
- Mixing normalizations: this course puts no $1/N$ in the forward DFT, so amplitudes need the factor $2/N$; NumPy's `numpy.fft.fft` uses the same convention, but other packages scale differently.
- Ignoring aliasing: a rhythm above half the sampling frequency shows up at the wrong frequency.

```python
import math


def amplitude_spectrum(x):
    """One-sided amplitude spectrum 2|X_k|/N (k = 0 and N/2 not doubled)."""
    n = len(x)
    out = []
    for k in range(n // 2 + 1):
        re = sum(x[j] * math.cos(2 * math.pi * k * j / n) for j in range(n))
        im = -sum(x[j] * math.sin(2 * math.pi * k * j / n) for j in range(n))
        mag = math.hypot(re, im)
        out.append(mag / n if k in (0, n // 2) else 2 * mag / n)
    return out
```
hint: Compute the real and imaginary parts of $X_k$ for $k$ up to $N/2$, take the magnitude, and double it (after dividing by $N$) except at the two ends.
solution: The two end bins have no mirror image, so they are not doubled. A constant signal has all its amplitude in $k = 0$ (the mean), and the alternating signal puts its amplitude at the Nyquist bin; the last test, $[1, 2, 3, 4]$, has mean $2.5$.

```python
def alias_frequency(f, fs):
    """Apparent frequency (0 to fs/2) of a sinusoid f sampled at fs."""
    r = f % fs
    return fs - r if r > fs / 2 else r
```
hint: A sinusoid at $f$ is indistinguishable from one at $f - m f_s$; reduce with the modulo operator and fold the upper half back.
solution: After `f % fs` the frequency is in $[0, f_s)$. Values above the Nyquist frequency fold back to $f_s - r$. A frequency exactly at the Nyquist frequency, the fourth test, is not folded.

```python
def ccg_peak(a, b, max_lag, bin_ms):
    """Lower lag edge (ms) of the largest cross-correlogram bin, or None."""
    n_bins = 2 * max_lag // bin_ms
    counts = [0] * n_bins
    for ta in a:
        for tb in b:
            d = tb - ta
            if -max_lag <= d < max_lag:
                counts[(d + max_lag) // bin_ms] += 1
    best = max(counts) if counts else 0
    if best == 0:
        return None
    return -max_lag + counts.index(best) * bin_ms
```
hint: Build the lag histogram, find the largest count, and convert the first index with that count back to a lag with `-max_lag + index * bin_ms`.
solution: `list.index` returns the first position holding the maximum, so ties go to the lowest lag. In the fourth test the lag $-3$ is in the bin $[-4, -2)$ and the lag $-2$ is in $[-2, 0)$, each with count 1, so the tie goes to the lower edge $-4$.

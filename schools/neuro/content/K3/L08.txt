@article
Decimals add and subtract just like whole numbers. The one big rule: **line up the decimal points**. Then each place lines up with the same kind of place.

### Adding

Add $2.5 + 1.75$. Write them in a column. Fill empty places with zeros.

$$\begin{array}{r} 2.50 \\ +\,1.75 \\ \hline 4.25 \end{array}$$

Add hundredths, then tenths, then ones. Put the decimal point straight down in the answer.

### Subtracting

Subtract $3.40 - 1.25$ the same way. Line up the points: $3.40 - 1.25 = 2.15$. Check by adding back: $2.15 + 1.25 = 3.40$.

### Multiplying

To multiply a decimal by a whole number, multiply as if there were no point. Then count the places after the point.

For $0.4 \times 3$: think $4 \times 3 = 12$. Because $0.4$ is tenths, the answer is $12$ tenths, which is $1.2$.

For $0.3 \times 0.2$: think $3 \times 2 = 6$. Tenths times tenths gives hundredths. So the answer is $6$ hundredths, $0.06$.

### Money

Money uses decimals all the time. Three pencils at \$0.25 each cost $3 \times 0.25 = 0.75$, so \$0.75. If you pay with \$10 for a \$6.35 toy, your change is $10 - 6.35 = 3.65$, so \$3.65.

### Metric units

The metric system is built on tens. A meter is $100$ centimeters. So $1$ centimeter is $0.01$ meter, which is one hundredth. A decimeter is one tenth of a meter. To change meters to centimeters, multiply by $100$. So $2.5$ m is $250$ cm.

@example
title: Add decimals in a column
problem: What is $3.6 + 2.45$?
step: Write both numbers with two decimal places: $3.60$ and $2.45$. Line up the decimal points.
step: Add hundredths: $0 + 5 = 5$. Add tenths: $6 + 4 = 10$. Write $0$ and carry $1$ to the ones.
step: Add ones: $3 + 2 + 1 = 6$. Put the point in the answer: $6.05$.
step: Estimate to check: $3.6 + 2.45$ is about $4 + 2 = 6$. The answer $6.05$ is close.

@mistakes
- Not lining up the decimal points, for example adding $2.5$ and $1.75$ as if the $5$ and the $5$ were in the same place.
- Putting the decimal point in the wrong spot in a product.
- Forgetting that $10$ tenths make a whole and so must be carried.

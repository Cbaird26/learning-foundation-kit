@article
The definite integral $\int_a^b f$ assumes a bounded interval and a bounded function. An **improper integral** relaxes one of these. There are two types, and in both the integral is *defined as a limit*.

### Type 1: infinite interval

$$\int_a^\infty f(x)\,dx = \lim_{t\to\infty}\int_a^t f(x)\,dx,$$

and similarly for $\int_{-\infty}^b$. For $\int_{-\infty}^\infty f$, split at any point $c$ and require **both** $\int_{-\infty}^c f$ and $\int_c^\infty f$ to converge. (You may not use the symmetric limit $\lim_{t\to\infty}\int_{-t}^t$ as a definition: it can exist when the integral diverges, such as for $f(x)=x$.)

If the limit exists and is finite, the integral **converges**; otherwise it **diverges**. For example,

$$\int_1^\infty\frac{dx}{x^2}=\lim_{t\to\infty}\left[-\frac1x\right]_1^t=\lim_{t\to\infty}\left(1-\frac1t\right)=1.$$

### Type 2: unbounded integrand

If $f$ is continuous on $(a,b]$ but unbounded near $a$,

$$\int_a^b f(x)\,dx=\lim_{t\to a^+}\int_t^b f(x)\,dx,$$

and similarly when the trouble is at $b$. If the trouble is at an interior point $c$, split there. For example $\int_0^1\frac{dx}{\sqrt x}=\lim_{t\to0^+}\left[2\sqrt x\right]_t^1=2$.

Beware of overlooking a Type 2 integral: $\int_{-1}^1\frac{dx}{x^2}$ looks proper, but the integrand is unbounded at $0$; the integral diverges, and "evaluating" $\left[-\frac1x\right]_{-1}^1=-2$ is nonsense (the answer is not even positive).

### The p-integrals

These are the benchmark cases for comparison:

$$\int_1^\infty\frac{dx}{x^p}\ \text{converges iff }p>1,\qquad \int_0^1\frac{dx}{x^p}\ \text{converges iff }p<1.$$

The first has value $\frac{1}{p-1}$ and the second $\frac{1}{1-p}$ when they converge. At $p=1$ both diverge, since $\int\frac{dx}{x}=\ln x$ is unbounded at both $0$ and $\infty$.

### The comparison test

Suppose $0\le f(x)\le g(x)$ for $x\ge a$.

- If $\int_a^\infty g$ converges, then $\int_a^\infty f$ converges.
- If $\int_a^\infty f$ diverges, then $\int_a^\infty g$ diverges.

The same holds for Type 2 integrals. Use it when you cannot find an antiderivative: for instance $0\le\frac{\sin^2x}{x^2}\le\frac1{x^2}$ shows that $\int_1^\infty\frac{\sin^2x}{x^2}dx$ converges, though its value is not elementary. The comparison test requires $f \geq 0$; the *limit comparison test* (if $\lim f/g$ is a positive finite number, both integrals behave the same) handles functions that are only approximately like a $p$-integral.

### Back to numerical integration

Quadrature rules need a bounded interval and a smooth integrand. For an improper integral you must first truncate (for Type 1, choose $t$ large enough that the tail is negligible) or substitute. Applying Simpson's rule directly to a function that blows up at an endpoint fails. On smooth integrands, however, the rules of Week 3 behave exactly as their error bounds predict, and you can measure that in code.

@example
title: An integral that needs integration by parts
problem: Evaluate $\displaystyle\int_0^\infty x e^{-x}\,dx$.
step: By definition it is $\lim_{t\to\infty}\int_0^t xe^{-x}\,dx$. Find the antiderivative with parts: $u=x$, $dv=e^{-x}dx$, so $\int xe^{-x}dx=-xe^{-x}-e^{-x}$.
step: Evaluate from $0$ to $t$: $\left[-xe^{-x}-e^{-x}\right]_0^t=-te^{-t}-e^{-t}+1$.
step: As $t\to\infty$, $e^{-t}\to0$ and $te^{-t}\to0$ (exponentials beat polynomials; or use L'Hôpital on $t/e^t$).
step: The limit is $1$, so the integral converges to $1$.
answer: $1$

@example
title: Deciding convergence by comparison
problem: Does $\displaystyle\int_1^\infty\frac{dx}{\sqrt{x^3+1}}$ converge?
step: For $x\ge1$, $x^3+1>x^3$, so $\sqrt{x^3+1}>x^{3/2}$ and $0<\dfrac1{\sqrt{x^3+1}}<\dfrac1{x^{3/2}}$.
step: The p-integral $\int_1^\infty x^{-3/2}dx$ has $p=\frac32>1$, so it converges.
step: By the comparison test, $\int_1^\infty\frac{dx}{\sqrt{x^3+1}}$ converges (its value is at most $2$).
answer: It converges.

@mistakes
- Treating $\int_{-1}^1\frac{dx}{x^2}$ as a proper integral and applying the Fundamental Theorem across the singularity at $0$.
- Believing $\int_1^\infty f$ must converge because $f(x)\to0$; for $f=1/x$ it diverges.
- Applying the comparison test in the wrong direction: an integrand that is *larger* than a convergent comparison function says nothing (and one that is *smaller* than a divergent one says nothing either).
- Mixing up the two p-integral ranges: $\int_1^\infty x^{-p}$ needs $p>1$ but $\int_0^1 x^{-p}$ needs $p<1$.

model:
```python
def compare_errors(f, exact, a, b, n):
    h = (b - a) / n
    trap = (f(a) + f(b)) / 2
    simp = f(a) + f(b)
    for i in range(1, n):
        value = f(a + i * h)
        trap += value
        simp += (4 if i % 2 == 1 else 2) * value
    trap *= h
    simp *= h / 3
    return abs(trap - exact), abs(simp - exact)
```
hint: Compute both sums in the same loop so each node is evaluated once.
hint: The trapezoid total is multiplied by `h`, the Simpson total by `h / 3`.
solution: Accumulate the trapezoid sum (weights 1/2, 1, ..., 1, 1/2) and the Simpson sum (weights 1, 4, 2, ..., 4, 1) together, scale each, and return absolute differences from `exact`. With sine and `n = 4`, Simpson's error is about 23 times smaller than the trapezoid error. The error bounds explain why Simpson's rule wins: its error shrinks like h⁴, while the trapezoid rule's shrinks like h².

@quiz num
prompt: Evaluate $\displaystyle\int_e^\infty\frac{dx}{x(\ln x)^2}$.
answer: 1
check: 1 / (2 - 1)
hint: Substitute $u=\ln x$, so $du=dx/x$, and change the limits.
hint: The new integral is $\int_1^\infty u^{-2}\,du$.
solution: With $u=\ln x$ the limits are $u=1$ and $u\to\infty$, and $\int_1^\infty u^{-2}du=1$.

@quiz num
prompt: Evaluate $\displaystyle\int_0^1\ln x\,dx$.
answer: -1
check: (1 * math.log(1) - 1) - 0.0
hint: The integrand is unbounded at $0$. Use $\lim_{t\to0^+}\int_t^1$ and parts with $u=\ln x$, $dv=dx$.
hint: An antiderivative is $x\ln x-x$, and $t\ln t\to0$ as $t\to0^+$.
solution: $\big[x\ln x-x\big]_t^1=-1-(t\ln t-t)\to-1$ as $t\to0^+$, since $t\ln t\to0$.

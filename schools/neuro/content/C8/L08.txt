@article
A **power series** centered at $a$ is a series of the form

$$\sum_{n=0}^\infty c_n(x-a)^n=c_0+c_1(x-a)+c_2(x-a)^2+\cdots,$$

a polynomial of infinite degree. For each fixed $x$ it is an ordinary series of numbers; the question is for which $x$ it converges.

### Radius and interval of convergence

For every power series exactly one of the following holds: it converges only at $x=a$ (radius $R=0$); it converges for all $x$ ($R=\infty$); or there is $R>0$ such that it converges absolutely for $|x-a|<R$ and diverges for $|x-a|>R$. The set of convergence, the **interval of convergence**, is therefore an interval centered at $a$ whose endpoints $a\pm R$ may or may not be included. **The endpoints must be tested separately**, with the tests of Week 7.

To find $R$ use the ratio test on the terms: with $L=\lim\left|\frac{c_{n+1}}{c_n}\right|$ the series converges when $|x-a|\,L<1$, so

$$R=\frac1L\quad(R=\infty\text{ if }L=0,\ R=0\text{ if }L=\infty).$$

The root test gives the same radius: $R=1/\lim|c_n|^{1/n}$ when that limit exists. A series that contains only even powers, such as $\sum x^{2n}/4^n$, has gaps in its exponents; apply the ratio test to the *terms* (including $x$), not to $c_n$ alone.

### Functions as power series

The geometric series gives the basic example:

$$\frac1{1-x}=\sum_{n=0}^\infty x^n\qquad(|x|<1).$$

Substituting $x\to2x$, $x\to-x^2$ and so on gives new series: $\frac1{1-2x}=\sum(2x)^n$ for $|x|<\frac12$, and $\frac1{1+x^2}=\sum(-1)^nx^{2n}$ for $|x|<1$.

### Termwise calculus

Inside the interval of convergence a power series can be differentiated and integrated **term by term**, and the new series has the **same radius** $R$ (the behavior at the endpoints may change):

$$\frac{d}{dx}\sum c_n(x-a)^n=\sum nc_n(x-a)^{n-1},\qquad\int\sum c_n(x-a)^n\,dx=C+\sum\frac{c_n(x-a)^{n+1}}{n+1}.$$

These give new series from old ones. Differentiating the geometric series gives $\frac{1}{(1-x)^2}=\sum_{n\ge1}nx^{n-1}$. Integrating $\frac1{1+x}=\sum(-1)^nx^n$ gives

$$\ln(1+x)=\sum_{n=0}^\infty\frac{(-1)^nx^{n+1}}{n+1}=x-\frac{x^2}2+\frac{x^3}3-\cdots\qquad(-1<x\le1),$$

where the constant of integration is $0$ because both sides vanish at $x=0$. Similarly, integrating $\frac1{1+x^2}$ gives $\arctan x=\sum\frac{(-1)^nx^{2n+1}}{2n+1}$ for $|x|\le 1$.

### Evaluating a polynomial: Horner's rule

To compute a truncated series $c_0+c_1x+\dots+c_mx^m$ efficiently, nest it: $c_0+x(c_1+x(c_2+\dots))$. This uses $m$ multiplications and $m$ additions, and it avoids computing large powers separately.

@example
title: Interval of convergence
problem: Find the radius and interval of convergence of $\displaystyle\sum_{n=1}^\infty\frac{(x-2)^n}{n\,3^n}$.
step: The ratio of consecutive terms is $\left|\frac{(x-2)^{n+1}}{(n+1)3^{n+1}}\cdot\frac{n3^n}{(x-2)^n}\right|=\frac{|x-2|}{3}\cdot\frac{n}{n+1}$.
step: The limit is $\frac{|x-2|}{3}$. The series converges when this is less than $1$: $|x-2|<3$, so $R=3$ and the open interval is $-1<x<5$.
step: At $x=5$ the series is $\sum\frac{3^n}{n3^n}=\sum\frac1n$, the harmonic series, which diverges.
step: At $x=-1$ the series is $\sum\frac{(-3)^n}{n3^n}=\sum\frac{(-1)^n}{n}$, which converges by the alternating series test.
step: The interval of convergence is $[-1,5)$.
answer: $R=3$, interval $[-1,5)$

@example
title: A function from the geometric series
problem: Find a power series for $\dfrac{x}{1+x^2}$ and its radius of convergence.
step: Start from $\frac1{1-u}=\sum u^n$ for $|u|<1$ and put $u=-x^2$: $\frac1{1+x^2}=\sum_{n=0}^\infty(-1)^nx^{2n}$, valid when $|-x^2|<1$, that is $|x|<1$.
step: Multiply the series by $x$, which does not change convergence: $\frac{x}{1+x^2}=\sum_{n=0}^\infty(-1)^nx^{2n+1}=x-x^3+x^5-\cdots$.
step: The radius of convergence is $R=1$.
answer: $\sum_{n=0}^\infty(-1)^nx^{2n+1}$ with $R=1$

@mistakes
- Forgetting to test the endpoints, so the interval is written open when it should be closed (or the reverse).
- Using $\left|\frac{c_{n+1}}{c_n}\right|$ when the series has only even or odd powers, so the exponents of $x$ skip; apply the ratio test to the whole terms.
- Reporting $R=L$ instead of $R=1/L$ after taking the ratio limit.
- Differentiating a series term by term and forgetting that the index shifts, or forgetting that the constant term disappears.

@practice code

starter:
```python
def eval_series(coeffs, x):
    pass
```
tests:
```python
assert eval_series([], 3) == 0
assert eval_series([5], 3) == 5
assert eval_series([1, 2, 3], 2) == 17
assert eval_series([1, -1, 1, -1], -1) == 4
assert abs(eval_series([1] * 50, 0.5) - (2 - 0.5 ** 49)) < 1e-12
```
model:
```python
def eval_series(coeffs, x):
    result = 0
    for c in reversed(coeffs):
        result = result * x + c
    return result
```
hint: Start from the highest-degree coefficient and work down.
hint: At each step, `result = result * x + c`, visiting the coefficients in reverse order.
solution: Horner's rule evaluates $c_0+x(c_1+x(c_2+\cdots))$ from the inside out: loop over the coefficients from last to first, multiplying the running result by `x` and adding the coefficient. For `[1, 2, 3]` at `x = 2` it computes `3`, then `3*2+2 = 8`, then `8*2+1 = 17`.

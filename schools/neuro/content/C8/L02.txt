@article
Week 1's tools are not enough for $\int \sin^3 x\cos^2 x\,dx$ or $\int \frac{3x+5}{(x+1)(x+3)}\,dx$. This lesson adds identities that reshape trigonometric integrands and an algebraic method that splits rational functions.

### Powers of sine and cosine

For $\int \sin^m x\cos^n x\,dx$:

- If **$m$ is odd**, peel off one $\sin x$, rewrite the remaining even power with $\sin^2 x = 1-\cos^2 x$, and substitute $u = \cos x$ (so $du = -\sin x\,dx$).
- If **$n$ is odd**, peel off one $\cos x$, use $\cos^2 x = 1-\sin^2 x$, and substitute $u = \sin x$.
- If **both are even**, use the half-angle identities $\sin^2 x = \frac{1-\cos 2x}{2}$ and $\cos^2 x = \frac{1+\cos 2x}{2}$, possibly more than once.

### Tangent and secant

Use $\tan^2 x = \sec^2 x - 1$, together with $\frac{d}{dx}\tan x = \sec^2 x$ and $\frac{d}{dx}\sec x = \sec x\tan x$. For example $\int\tan^2 x\,dx = \int(\sec^2 x - 1)\,dx = \tan x - x + C$.

### Trigonometric substitution

When an integrand contains $\sqrt{a^2 - x^2}$, substitute $x = a\sin\theta$ (so $\sqrt{a^2-x^2} = a\cos\theta$ for $-\frac\pi2\le\theta\le\frac\pi2$). For $\sqrt{a^2+x^2}$ use $x = a\tan\theta$; for $\sqrt{x^2-a^2}$ use $x = a\sec\theta$. The substitution converts the root into a trigonometric function whose integral you can finish with the identities above. For a definite integral, change the limits to $\theta$-values.

### Partial fractions

A rational function $\frac{P(x)}{Q(x)}$ with $\deg P < \deg Q$ can be written as a sum of simpler fractions determined by the factorization of $Q$ over the reals:

- Each distinct linear factor $(x-r)$ contributes $\frac{A}{x-r}$.
- A repeated factor $(x-r)^k$ contributes $\frac{A_1}{x-r} + \frac{A_2}{(x-r)^2} + \dots + \frac{A_k}{(x-r)^k}$.
- An irreducible quadratic $(x^2+bx+c)$ contributes $\frac{Bx+C}{x^2+bx+c}$.

Multiply both sides by $Q(x)$ and find the constants by comparing coefficients, or, for simple linear factors, substitute the root of each factor (the "cover-up" shortcut). If $\deg P \ge \deg Q$, first do polynomial long division; the quotient integrates directly.

The integrals that result are standard: $\int\frac{A}{x-r}dx = A\ln|x-r|$, $\int\frac{dx}{(x-r)^2} = -\frac{1}{x-r}$, and $\int \frac{dx}{x^2+1} = \arctan x$.

@example
title: An odd power of sine
problem: Find $\displaystyle\int \sin^3 x\cos^2 x\,dx$.
step: The power of sine is odd. Peel off one $\sin x$: $\sin^3x\cos^2x = (1-\cos^2x)\cos^2x\,\sin x$.
step: Let $u = \cos x$, so $du = -\sin x\,dx$. The integral becomes $-\int(1-u^2)u^2\,du = -\int(u^2-u^4)\,du$.
step: Integrate: $-\left(\frac{u^3}{3}-\frac{u^5}{5}\right) + C$.
step: Substitute back: $-\frac{\cos^3x}{3}+\frac{\cos^5x}{5}+C$.
step: Check: the derivative is $\sin x\cos^2x - \sin x\cos^4x = \sin x\cos^2x(1-\cos^2x) = \sin^3x\cos^2x$.
answer: $-\frac{\cos^3x}{3}+\frac{\cos^5x}{5}+C$

@example
title: Distinct linear factors
problem: Find $\displaystyle\int\frac{3x+5}{(x+1)(x+3)}\,dx$.
step: Write $\frac{3x+5}{(x+1)(x+3)} = \frac{A}{x+1}+\frac{B}{x+3}$. Multiply by the denominator: $3x+5 = A(x+3)+B(x+1)$.
step: Substitute $x=-1$: $2 = 2A$, so $A=1$. Substitute $x=-3$: $-4 = -2B$, so $B=2$.
step: Integrate term by term: $\int\frac{dx}{x+1}+2\int\frac{dx}{x+3}$.
step: The result is $\ln|x+1| + 2\ln|x+3| + C$.
answer: $\ln|x+1|+2\ln|x+3|+C$

@mistakes
- Using $\sin^2x = 1-\cos 2x$ (forgetting the factor $\frac12$) in the half-angle identity.
- Peeling off the wrong factor: with $\sin^3x\cos^2x$ you strip a $\sin x$ and substitute $u=\cos x$, not the other way round.
- Skipping long division when $\deg P \ge \deg Q$, which makes the partial fraction setup impossible.
- Using $\frac{A}{x^2+1}$ for an irreducible quadratic instead of $\frac{Bx+C}{x^2+1}$.

@practice num
prompt: Evaluate $\displaystyle\int_0^{\pi/2}\sin^2x\,dx$. Give an exact value.
answer: pi/4
check: quad(lambda x: sin(x)**2, 0, pi/2)
hint: Both powers are even, so use the half-angle identity $\sin^2x=\frac{1-\cos2x}{2}$.
hint: Integrate $\frac12(1-\cos 2x)$ from $0$ to $\pi/2$.
solution: $\frac12\left[x-\frac{\sin2x}{2}\right]_0^{\pi/2} = \frac12\cdot\frac\pi2 = \frac\pi4$.

@practice expr
prompt: Find an antiderivative of $\cos^3x$.
vars: x
answer: sin(x) - sin(x)^3/3
check: lambda x: sin(x) - sin(x)**3/3
const: yes
hint: The power of cosine is odd: write $\cos^3x = (1-\sin^2x)\cos x$.
hint: Let $u=\sin x$, so $du=\cos x\,dx$, and integrate $1-u^2$.
solution: $\int(1-u^2)\,du = u-\frac{u^3}{3}$, so the antiderivative is $\sin x-\frac{\sin^3x}{3}+C$.

@practice num
prompt: Evaluate $\displaystyle\int_0^1\frac{dx}{(x+1)(x+2)}$. Give an exact value.
answer: ln(4/3)
check: quad(lambda x: 1/((x+1)*(x+2)), 0, 1)
hint: Write $\frac{1}{(x+1)(x+2)}=\frac{A}{x+1}+\frac{B}{x+2}$ and find $A$ and $B$ by substituting $x=-1$ and $x=-2$.
hint: You should find $A=1$ and $B=-1$.
solution: $\int_0^1\left(\frac1{x+1}-\frac1{x+2}\right)dx = \big[\ln(x+1)-\ln(x+2)\big]_0^1 = (\ln2-\ln3)-(0-\ln2) = 2\ln2-\ln3=\ln\frac43$.

@practice mc
prompt: Which is the correct form of the partial fraction decomposition of $\dfrac{x+5}{(x-1)(x^2+1)}$ over the real numbers?
choice*: $\dfrac{A}{x-1}+\dfrac{Bx+C}{x^2+1}$
choice: $\dfrac{A}{x-1}+\dfrac{B}{x^2+1}$
choice: $\dfrac{A}{x-1}+\dfrac{B}{x+1}+\dfrac{C}{x-1}$
choice: $\dfrac{Ax+B}{x-1}+\dfrac{C}{x^2+1}$
hint: The numerator over each factor has degree one less than that factor.
solution: The linear factor gets a constant numerator, and the irreducible quadratic $x^2+1$ gets a linear numerator $Bx+C$. The quadratic does not factor over the reals, so it cannot be split further.

@practice self
prompt: Evaluate each integral by hand and check each antiderivative by differentiating. (a) $\int\sin^3x\,dx$ (b) $\int\cos^2x\,dx$ (c) $\int\frac{dx}{x^2-1}$ (d) $\int_0^1\sqrt{1-x^2}\,dx$ (e) $\int\frac{x}{x^2+3x+2}\,dx$ (f) $\int\sec^2x\tan x\,dx$
hint: For (a) use the odd-power method; for (c) and (e) factor the denominator and use partial fractions; for (d) try $x=\sin\theta$.
solution: (a) $-\cos x+\frac{\cos^3x}{3}+C$. (b) $\frac x2+\frac{\sin2x}{4}+C$. (c) $\frac{1}{x^2-1}=\frac12\left(\frac1{x-1}-\frac1{x+1}\right)$, giving $\frac12\ln\left|\frac{x-1}{x+1}\right|+C$. (d) With $x=\sin\theta$ it is $\int_0^{\pi/2}\cos^2\theta\,d\theta=\frac\pi4$. (e) $\frac{x}{(x+1)(x+2)}=\frac{-1}{x+1}+\frac{2}{x+2}$, giving $-\ln|x+1|+2\ln|x+2|+C$. (f) Let $u=\tan x$: $\frac{\tan^2x}{2}+C$.

@quiz num
prompt: Evaluate $\displaystyle\int_0^{\pi/4}\tan^2x\,dx$. Give an exact value.
answer: 1 - pi/4
check: quad(lambda x: math.tan(x)**2, 0, pi/4)
hint: Use $\tan^2x=\sec^2x-1$.
hint: An antiderivative of $\sec^2x-1$ is $\tan x-x$.

@quiz num
prompt: Evaluate $\displaystyle\int_0^1\frac{x^2}{x+1}\,dx$. Give an exact value.
answer: ln(2) - 1/2
check: quad(lambda x: x*x/(x+1), 0, 1)
hint: The degree of the numerator is not less than the degree of the denominator, so divide first.
hint: $\frac{x^2}{x+1} = x-1+\frac{1}{x+1}$.
solution: $\int_0^1\left(x-1+\frac1{x+1}\right)dx=\left[\frac{x^2}{2}-x+\ln(x+1)\right]_0^1=\frac12-1+\ln2=\ln2-\frac12$.

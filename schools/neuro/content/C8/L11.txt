@article
So far each function had one input. Real quantities usually depend on several: the temperature in a room depends on position $(x,y,z)$; the loss of a model depends on all its parameters. A **function of two variables** assigns a real number $f(x,y)$ to each point $(x,y)$ in its **domain**, a subset of the plane. Its **range** is the set of values it takes. Functions of three or more variables work the same way, with $\mathbb R^n$ as the input space.

### Domain and range

The natural domain is the set of inputs where the formula makes sense. For $f(x,y)=\sqrt{9-x^2-y^2}$ the radicand must be non-negative, so the domain is the closed disk $x^2+y^2\le9$ and the range is $[0,3]$. For $g(x,y)=\ln(x-y)$ we need $x-y>0$: the half-plane below the line $y=x$ (the line itself excluded).

### Graphs, level curves and traces

The **graph** of $f$ is the surface $z=f(x,y)$ in three-dimensional space. Surfaces are hard to draw, so we study slices:

- A **trace** is the intersection of the graph with a plane $x=c$, $y=c$ or $z=c$.
- A **level curve** of value $k$ is the set $\{(x,y):f(x,y)=k\}$ in the plane: the horizontal trace, viewed from above. A **contour map** is a set of level curves for equally spaced values of $k$: curves packed closely mean $f$ changes rapidly. For three variables, the corresponding objects are **level surfaces** $f(x,y,z)=k$.

For $f(x,y)=x^2+y^2$ the level curves are circles, and the graph is a **paraboloid**. Common quadric surfaces:

| Equation | Surface |
|---|---|
| $z=x^2+y^2$ | elliptic paraboloid |
| $z=x^2-y^2$ | hyperbolic paraboloid (saddle) |
| $z^2=x^2+y^2$ | double cone |
| $\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1$ | ellipsoid |

### Limits

We write $\lim_{(x,y)\to(a,b)}f(x,y)=L$ if $f(x,y)$ gets arbitrarily close to $L$ whenever $(x,y)$ is close enough to $(a,b)$, with $(x,y)\ne(a,b)$. In one variable there are only two directions of approach; in the plane there are infinitely many paths, and the value must be the same along **all** of them.

- **To show a limit does not exist:** find two paths along which $f$ approaches different values (or one path along which there is no limit).
- **To show a limit exists:** the path test cannot prove it, however many paths you try. Use algebra, a substitution to polar coordinates ($x=r\cos\theta$, $y=r\sin\theta$ with $r\to0$), or the squeeze theorem with $|f(x,y)-L|\le g(x,y)\to0$.

The limit laws (sums, products, quotients with a non-zero denominator limit) and composition rules carry over from one variable.

### Continuity

$f$ is **continuous** at $(a,b)$ if $(a,b)$ is in the domain, the limit exists, and the limit equals $f(a,b)$. Polynomials, rational functions (where the denominator is non-zero), exponentials, logarithms (where defined) and sums, products and compositions of continuous functions are continuous on their domains. A function such as $\frac{x^2-y^2}{x^2+y^2}$ cannot be made continuous at the origin by any choice of value there, because the limit does not exist.

### In code

A function of two variables is a Python function `f(x, y)`. Evaluating it along a line `y = m*x` reduces the question to a one-variable table that you can inspect; sampling it on a grid is how contour plots are built. Numerical evidence can suggest that a limit fails (values differ between paths), but a finite table can never prove that a limit exists.

@example
title: Domain, range and level curves
problem: For $f(x,y)=\sqrt{9-x^2-y^2}$ find the domain, the range and the level curves.
step: The square root requires $9-x^2-y^2\ge0$, so the domain is the closed disk $x^2+y^2\le9$.
step: On the domain, $0\le 9-x^2-y^2\le9$, so $0\le f\le3$. The value $3$ occurs at the origin and the value $0$ on the boundary circle, so the range is $[0,3]$.
step: Setting $f=k$ with $0\le k\le3$ gives $x^2+y^2=9-k^2$.
step: The level curves are circles of radius $\sqrt{9-k^2}$ centered at the origin (a single point for $k=3$). They are closer together near the boundary, where the graph, an upper hemisphere, is steepest.
answer: Domain: the disk $x^2+y^2\le9$; range $[0,3]$; level curves are circles.

@example
title: A limit that does not exist
problem: Does $\displaystyle\lim_{(x,y)\to(0,0)}\frac{x^2-y^2}{x^2+y^2}$ exist?
step: Approach along the $x$-axis ($y=0$, $x\ne0$): $f(x,0)=\frac{x^2}{x^2}=1$, so the values tend to $1$.
step: Approach along the $y$-axis ($x=0$, $y\ne0$): $f(0,y)=\frac{-y^2}{y^2}=-1$, so the values tend to $-1$.
step: Two paths give different limits, so the limit does not exist.
step: In polar coordinates the function is $\cos2\theta$, which depends only on the direction of approach, confirming that no single limit is possible.
answer: The limit does not exist.

@mistakes
- Concluding that a limit exists because it is the same along the $x$-axis, the $y$-axis and every line through the origin; curved paths such as $x=y^2$ can behave differently.
- Substituting $(0,0)$ into a quotient and writing "$\frac00$ so the limit is $0$" (or "$\frac00=1$").
- Confusing level curves (in the domain plane) with traces (cross-sections of the graph in 3D).
- Forgetting that the domain of a composite such as $\ln(x-y)$ or $\sqrt{9-x^2-y^2}$ is restricted by the inner and outer functions.

def along_line(f, m, ts):

assert grid_min(lambda x, y: (x - 1) ** 2 + (y + 2) ** 2,
                list(range(-3, 4)), list(range(-4, 3))) == (1, -2)
assert grid_min(lambda x, y: 0, [5, 6], [7, 8]) == (5, 7)

model:
```python
def grid_min(f, xs, ys):
    best = None
    best_value = None
    for x in xs:
        for y in ys:
            value = f(x, y)
            if best is None or value < best_value:
                best = (x, y)
                best_value = value
    return best
```
hint: Keep the best pair and its value so far, starting from the first pair.
hint: Replace the best pair only when the new value is strictly smaller, so that ties keep the first pair.
solution: Scan the grid in row-major order, remembering the best pair and its value; use a strict `<` so that the earliest pair wins ties. For $(x-1)^2+(y+2)^2$ the grid contains the true minimum point $(1,-2)$.

@quiz mc
prompt: Consider $\displaystyle\lim_{(x,y)\to(0,0)}\frac{xy^2}{x^2+y^4}$. Which statement is correct?
choice: The limit is $0$, because the value is $0$ along every line $y=mx$.
choice*: The limit does not exist: along every line the values tend to $0$, but along the parabola $x=y^2$ they equal $\frac12$.
choice: The limit is $\frac12$, because along $x=y^2$ the value is $\frac12$.
choice: The limit does not exist: along the $x$-axis the values are $0$ and along the $y$-axis they are $1$.
hint: Test the curve $x=y^2$ and compare with a line.
solution: Along $y=mx$ the quotient is $\frac{m^2x}{1+m^4x^2}\to0$. Along $x=y^2$ it is $\frac{y^4}{y^4+y^4}=\frac12$ for every $y\ne0$. Two paths with different limits mean that the limit does not exist. The $y$-axis ($x=0$) gives $0$, not $1$.

@article
A **sequence** is a function from the positive integers: $a_1,a_2,a_3,\dots$, written $\{a_n\}$. It can be given by a formula ($a_n=\frac{n}{n+1}$) or recursively ($a_1=1$, $a_{n+1}=\sqrt{2+a_n}$).

### Limits

We write $\lim_{n\to\infty}a_n=L$ if for every $\varepsilon>0$ there is an $N$ such that $|a_n-L|<\varepsilon$ for all $n>N$. If such a finite $L$ exists the sequence **converges**; otherwise it **diverges** (to $\pm\infty$, or by oscillating, as $(-1)^n$ does).

If $a_n=f(n)$ and $\lim_{x\to\infty}f(x)=L$, then $\lim a_n=L$. This lets you use L'Hôpital's rule on the real variable $x$. The converse fails: $\sin(\pi n)\to0$ although $\sin(\pi x)$ has no limit.

### Tools

- **Limit laws.** If $a_n\to A$ and $b_n\to B$, then $a_n\pm b_n\to A\pm B$, $a_nb_n\to AB$, and $a_n/b_n\to A/B$ when $B\ne0$.
- **Rational expressions in $n$.** Divide numerator and denominator by the highest power of $n$ in the denominator. Thus $\frac{3n^2+n}{2n^2+5}\to\frac32$.
- **Squeeze theorem.** If $a_n\le b_n\le c_n$ for large $n$ and $a_n,c_n\to L$, then $b_n\to L$. Corollary: $|a_n|\to0$ implies $a_n\to0$.
- **Continuous functions.** If $a_n\to L$ and $g$ is continuous at $L$, then $g(a_n)\to g(L)$.

### Standard limits

- $r^n\to0$ if $|r|<1$; $r^n\to1$ if $r=1$; $r^n$ diverges if $r>1$ or $r\le-1$.
- $\left(1+\frac xn\right)^n\to e^x$ for every real $x$.
- $n^{1/n}\to1$ and $c^{1/n}\to1$ for $c>0$.
- $\frac{n^k}{r^n}\to0$ for $r>1$, and $\frac{r^n}{n!}\to0$ for every $r$. Growth ranks (slowest to fastest): $\ln n$, powers $n^k$, exponentials $r^n$ with $r > 1$, $n!$, $n^n$.

### Monotone sequences

A sequence is **increasing** if $a_{n+1}\ge a_n$ for all $n$, **decreasing** if $a_{n+1}\le a_n$, and **bounded** if $|a_n|\le M$ for some $M$. The **monotone convergence theorem** says that a bounded monotone sequence converges. It guarantees a limit exists without telling you its value.

### Recursive sequences

For $a_{n+1}=g(a_n)$ with $g$ continuous, a limit $L$, if it exists, satisfies $L=g(L)$, because both $a_{n+1}$ and $a_n$ tend to $L$. The correct order is: first prove the limit **exists** (usually monotone and bounded), then solve $L=g(L)$ and reject any solution inconsistent with the bounds. Solving $L=g(L)$ without proving existence can give nonsense: $a_{n+1}=2a_n$ with $a_1=1$ would "give" $L=2L$, so $L=0$, but the sequence diverges.

A computer can only suggest a limit by iterating; it does not prove one. The fixed-point iteration below repeats $x\leftarrow g(x)$ until successive values agree to a tolerance.

@example
title: A limit of a rational expression
problem: Find $\displaystyle\lim_{n\to\infty}\frac{4n^2-n}{n^2+3n+1}$.
step: The highest power of $n$ in the denominator is $n^2$. Divide every term by $n^2$.
step: $\displaystyle\frac{4n^2-n}{n^2+3n+1}=\frac{4-\frac1n}{1+\frac3n+\frac1{n^2}}$.
step: As $n\to\infty$, $\frac1n\to0$ and $\frac1{n^2}\to0$.
step: By the limit laws the quotient tends to $\frac{4-0}{1+0+0}=4$.
answer: $4$

@example
title: A recursive sequence
problem: Let $a_1=1$ and $a_{n+1}=\sqrt{2+a_n}$. Show that $\{a_n\}$ converges and find its limit.
step: Claim: $a_n<2$ for all $n$. True for $a_1=1$; if $a_n<2$ then $a_{n+1}=\sqrt{2+a_n}<\sqrt4=2$.
step: Claim: $a_{n+1}>a_n$. Since $0<a_n<2$, $a_{n+1}^2-a_n^2=2+a_n-a_n^2=(2-a_n)(1+a_n)>0$, so $a_{n+1}>a_n$ (both terms are positive).
step: The sequence is increasing and bounded above, so it converges by the monotone convergence theorem. Call the limit $L$.
step: Taking limits in $a_{n+1}=\sqrt{2+a_n}$ gives $L=\sqrt{2+L}$, so $L^2-L-2=0$ and $(L-2)(L+1)=0$.
step: Since $a_n\ge1$, $L\ge1$, which rules out $L=-1$. So $L=2$.
answer: $L = 2$

@mistakes
- Solving $L=g(L)$ without first showing that the limit exists.
- Concluding that $a_n\to0$ from "the terms get smaller": $a_n=1+\frac1n$ decreases, but its limit is $1$.
- Applying L'Hôpital's rule to the sequence directly; it applies to the corresponding function of a real variable $x$.
- Saying $(-1)^n$ has limit $0$ because $1/n\to 0$: $(-1)^n$ oscillates between $-1$ and $1$ and diverges, while $(-1)^n/n\to0$.

prompt: Write `iterate_limit(g, x0, tol=1e-12, max_iter=1000)` for the recursive sequence $x_0$, $x_{k+1}=g(x_k)$. It returns the first value $x_k$ (with $k\ge1$) for which $|x_k-x_{k-1}|<$ `tol`. If no such value appears within `max_iter` steps, raise `RuntimeError`.
starter:
```python
def iterate_limit(g, x0, tol=1e-12, max_iter=1000):
    pass
```
tests:
```python
import math
assert abs(iterate_limit(lambda x: math.sqrt(2 + x), 1.0) - 2) < 1e-9
assert abs(iterate_limit(math.cos, 1.0) - 0.7390851332151607) < 1e-9
assert abs(iterate_limit(lambda x: (x + 2 / x) / 2, 1.0) - math.sqrt(2)) < 1e-9
assert iterate_limit(lambda x: 3.0, 0.0) == 3.0
assert raises(RuntimeError, iterate_limit, lambda x: x + 1, 0.0)
assert raises(RuntimeError, iterate_limit, lambda x: x / 2, 1.0, 1e-12, 5)
```
model:
```python
def iterate_limit(g, x0, tol=1e-12, max_iter=1000):
    prev = x0
    for _ in range(max_iter):
        cur = g(prev)
        if abs(cur - prev) < tol:
            return cur
        prev = cur
    raise RuntimeError("sequence did not converge")
```
hint: Keep the previous value; compute the next with `g(prev)` and compare.
hint: Use a `for` loop over `range(max_iter)` and raise the error after the loop.
solution: Each pass computes `cur = g(prev)`. If the two differ by less than `tol`, return `cur`; otherwise move on. For the constant function $g=3$ the first step lands at $3$ and the second repeats it, so the function returns `3.0`. The divergent $x+1$ never settles, so the loop ends and the error is raised.

@quiz num

@article
High-dimensional data are hard to visualize, expensive to process, and often redundant: many features move together. **Principal component analysis (PCA)** finds a small number of new, uncorrelated directions that retain as much of the variance of the data as possible. It is unsupervised, and it is used for visualization, compression, denoising, and as preprocessing before other models.

### Setting up

Let $X$ be the $n \times d$ data matrix. First **center** each column by subtracting its mean, giving $X_c$. The **sample covariance matrix** is
$$S = \frac{1}{n-1}X_c^\top X_c,$$
a symmetric $d \times d$ matrix whose diagonal holds the variances of the features and whose off-diagonal entries hold their covariances. If the features are on different scales, standardize them first, so that $S$ becomes the correlation matrix; otherwise the feature with the largest units dominates.

### Principal components

The first **principal component** is the unit vector $v_1$ that maximizes the variance of the projections $X_c v$. The answer is the eigenvector of $S$ with the largest eigenvalue $\lambda_1$, and the variance along it is exactly $\lambda_1$. The second component maximizes the variance among directions orthogonal to the first, and so on. Because $S$ is symmetric, it has real eigenvalues $\lambda_1 \ge \dots \ge \lambda_d \ge 0$ and orthonormal eigenvectors $v_1, \dots, v_d$. For a symmetric $2 \times 2$ matrix $\begin{pmatrix} a & b \\ b & d \end{pmatrix}$ the eigenvalues are
$$\lambda = \frac{a + d}{2} \pm \sqrt{\left(\frac{a - d}{2}\right)^2 + b^2}.$$

### Explained variance

The total variance is $\operatorname{tr}(S) = \sum_j \lambda_j$, which the rotation to principal axes leaves unchanged. The **explained variance ratio** of component $j$ is $\lambda_j / \sum_i \lambda_i$. To choose the number $m$ of components, keep enough for a target such as 90% of the variance, or look for the bend in a **scree plot** of the eigenvalues. Keeping the first $m$ components projects each point to the scores $z = V_m^\top (x - \mu)$, and the point can be approximately reconstructed as $\hat{x} = \mu + V_m z$. The discarded eigenvalues measure what is lost: the average squared reconstruction error (with the $n-1$ convention) is $\sum_{j > m}\lambda_j$.

### Computing PCA in practice

Rather than forming $S$, libraries compute the **singular value decomposition** $X_c = U\Sigma V^\top$. The columns of $V$ are the principal components and $\lambda_j = \sigma_j^2/(n-1)$. This is more accurate and works when $d > n$. The cost is $O(nd\min(n, d))$ for the full decomposition.

### Limits

PCA is **linear**: it cannot unroll a curved manifold such as a spiral. Variance is not the same as relevance: a direction of small variance can carry the signal for a label. Principal components are combinations of all features and so are harder to interpret than the original features, and their signs are arbitrary (if $v$ is a component, so is $-v$). PCA is sensitive to outliers and to scaling.

@example
title: PCA of collinear points
problem: Find the principal components of the points $(1,2), (3,4), (5,6)$.
step: The means are $\bar x = 3$ and $\bar y = 4$, so the centered points are $(-2,-2), (0,0), (2,2)$.
step: $S = \frac{1}{2}\begin{pmatrix} 8 & 8 \\ 8 & 8\end{pmatrix} = \begin{pmatrix} 4 & 4 \\ 4 & 4\end{pmatrix}$.
step: The eigenvalues are $\frac{4+4}{2} \pm \sqrt{0 + 16} = 4 \pm 4$, that is $\lambda_1 = 8$ and $\lambda_2 = 0$.
step: The eigenvector for $8$ solves $(S - 8I)v = 0$, which gives $v_1 = (1, 1)/\sqrt{2}$, the direction of the line through the points.
step: The first component explains $8/(8 + 0) = 100\%$ of the variance, and the scores are $-2\sqrt{2}, 0, 2\sqrt{2}$: one number per point loses nothing.
answer: $v_1 = (1,1)/\sqrt{2}$ with $\lambda_1 = 8$, $\lambda_2 = 0$; 100% explained.

@example
title: Explained variance from a covariance matrix
problem: A data set has the covariance matrix $S = \begin{pmatrix} 3 & 1 \\ 1 & 3\end{pmatrix}$. Find the eigenvalues, components and the explained variance of the first.
step: $\frac{a+d}{2} = 3$ and $\sqrt{0 + 1^2} = 1$, so the eigenvalues are $\lambda_1 = 4$ and $\lambda_2 = 2$.
step: For $\lambda_1 = 4$: $(S - 4I) = \begin{pmatrix} -1 & 1 \\ 1 & -1 \end{pmatrix}$, so $v_1 = (1, 1)/\sqrt{2}$. For $\lambda_2 = 2$: $v_2 = (1, -1)/\sqrt{2}$, orthogonal to $v_1$.
step: The total variance is $\operatorname{tr}(S) = 6 = 4 + 2$.
step: The first component explains $4/6 = 2/3 \approx 66.7\%$ of the variance, and the second $1/3$.
answer: $\lambda = 4, 2$; $v_1 = (1,1)/\sqrt{2}$; the first component explains $2/3$.

@mistakes
- Forgetting to center the data, which makes the first "component" point toward the mean instead of along the direction of greatest spread.
- Running PCA on features of different units without standardizing, so the feature with the largest numbers captures nearly all the variance.
- Assuming the directions of large variance are the ones useful for predicting a label.
- Comparing the signs of components between runs: $v$ and $-v$ are the same component.

```python
def covariance_2d(rows):
    n = len(rows)
    mx = sum(r[0] for r in rows) / n
    my = sum(r[1] for r in rows) / n
    sxx = sum((r[0] - mx) ** 2 for r in rows) / (n - 1)
    syy = sum((r[1] - my) ** 2 for r in rows) / (n - 1)
    sxy = sum((r[0] - mx) * (r[1] - my) for r in rows) / (n - 1)
    return [[sxx, sxy], [sxy, syy]]
```
hint: Center both coordinates, then sum the products of the centered values and divide by $n - 1$.
solution: The variances are the sums of squared centered values over $n - 1$, and the covariance is the sum of products of centered values over $n - 1$; the matrix is symmetric.

model:
```python
import math

def principal_axis(cov):
    a, b = cov[0]
    d = cov[1][1]
    mid = (a + d) / 2
    rad = math.sqrt(((a - d) / 2) ** 2 + b * b)
    lam1 = mid + rad
    lam2 = mid - rad
    if b == 0:
        v = (1.0, 0.0) if a >= d else (0.0, 1.0)
    else:
        x, y = lam1 - d, b
        norm = math.hypot(x, y)
        v = (x / norm, y / norm)
    return (lam1, lam2, v)
```
hint: Compute the midpoint and the radius of the eigenvalue formula; the two eigenvalues are midpoint plus and minus radius.
hint: The second row of $(S - \lambda_1 I)v = 0$ reads $b v_x + (d - \lambda_1)v_y = 0$, which is satisfied by $(v_x, v_y) = (\lambda_1 - d, b)$. Normalize that vector with `math.hypot`.
solution: Use the closed form for the eigenvalues. For $b \ne 0$ the vector $(\lambda_1 - d, b)$ satisfies the second row of $(S - \lambda_1 I)v = 0$; its first component is positive, and dividing by its length gives a unit eigenvector. When $b = 0$ the matrix is diagonal and the axes are the eigenvectors.

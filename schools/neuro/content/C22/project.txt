```python
import csv
import math


def make_data(n=600, seed=2024):
    state = seed

    def rand():
        nonlocal state
        state = (1103515245 * state + 12345) % 2**31
        return state / 2**31

    rows = []
    for i in range(n):
        group = "A" if rand() < 0.7 else "B"
        age = 18 + int(rand() * 62)
        distance = round(1 + rand() * (9 if group == "A" else 24), 1)
        prior = min(4, int(-math.log(1 - rand()) * 0.8))
        reminder = 1 if rand() < 0.6 else 0
        score = (-2.0 + 0.09 * distance + 0.45 * prior
                 - 0.8 * reminder - 0.01 * (age - 40))
        p = 1 / (1 + math.exp(-score))
        no_show = 1 if rand() < p else 0
        rows.append([i + 1, age, distance, prior, reminder, group, no_show])
    return rows


if __name__ == "__main__":
    rows = make_data()
    with open("appointments.csv", "w", newline="") as f:
        writer = csv.writer(f)
        writer.writerow(["id", "age", "distance_km", "prior_noshows",
                         "reminder", "group", "no_show"])
        writer.writerows(rows)
    print(len(rows), "rows;",
          "no-show rate", round(sum(r[6] for r in rows) / len(rows), 3))
```

@review
### Key ideas, week by week

1. **Data, features and tasks.** A data matrix $X$ ($n \times d$) and targets $y$. Regression predicts numbers, classification predicts classes, clustering and dimensionality reduction use no labels. Always compute a baseline (the mean, or the majority class).
2. **Linear regression.** Minimize RSS: slope $S_{xy}/S_{xx}$, line through $(\bar x, \bar y)$; normal equations $X^\top X\beta = X^\top y$; $R^2 = 1 - \mathrm{RSS}/\mathrm{TSS}$.
3. **Gradient descent.** $w \leftarrow w - \eta\nabla L$; the learning rate decides convergence; the MSE gradient is $\frac{2}{n}X^\top(Xw - y)$; batch, stochastic and mini-batch versions; standardize features.
4. **Logistic regression.** $p = \sigma(w^\top x + b)$; linear log-odds; log loss; gradient $\frac{1}{n}\sum(p_i - y_i)x_i$; linear decision boundary.
5. **Overfitting and regularization.** Error = bias$^2$ + variance + noise. Ridge shrinks coefficients (slope $S_{xy}/(S_{xx} + \lambda)$); the lasso gives exact zeros; early stopping.
6. **Evaluation.** Train, validation and test sets; $k$-fold cross-validation; leakage; confusion matrix, precision, recall, $F_1$; confidence intervals for metrics.
7. **Nearest neighbors and trees.** $k$-NN needs scaled features; Gini $1 - \sum p_k^2$ and greedy splits; deep trees overfit.
8. **Ensembles.** Bagging and random forests reduce variance (OOB error, decorrelated trees); gradient boosting fits residuals and reduces bias.
9. **K-means.** Assign, update, repeat; inertia decreases to a local minimum; initialization (k-means++), choosing $k$.
10. **PCA.** Center; eigenvectors of the covariance matrix; explained variance ratio $\lambda_j/\sum\lambda_i$.
11. **Neural networks.** Layers, nonlinearities, forward pass, backpropagation by the chain rule, parameter counts.
12. **Deep learning and responsible ML.** Convolutions, attention, momentum, dropout; group-wise metrics, fairness criteria that cannot all hold at once, model cards.

### Common errors

- Reporting training error, or tuning on the test set.
- Fitting scalers, feature selection or PCA before splitting the data.
- Forgetting to standardize before gradient descent, $k$-NN, k-means, PCA, ridge or the lasso.
- Mixing up precision and recall, or quoting accuracy on imbalanced data.
- Updating parameters before all gradients are computed.
- Reporting a metric without its uncertainty.

model:
```python
def best_threshold_f1(y_true, scores):
    best = None
    for t in sorted(set(scores)):
        tp = fp = fn = 0
        for y, s in zip(y_true, scores):
            pred = 1 if s >= t else 0
            if pred == 1 and y == 1:
                tp += 1
            elif pred == 1:
                fp += 1
            elif y == 1:
                fn += 1
        f1 = 2 * tp / (2 * tp + fp + fn) if tp else 0.0
        if best is None or f1 > best[1]:
            best = (t, f1)
    return best
```
hint: Loop over the sorted distinct scores and compute the confusion counts for each threshold.
hint: Replace the best only when the new $F_1$ is strictly larger, so the smallest threshold wins ties.
solution: For every candidate threshold count TP, FP and FN, compute $F_1$ as `2*tp / (2*tp + fp + fn)` (0 when there are no true positives), and keep the first threshold achieving the highest value. Choosing the threshold on validation data, never on test data, is the point of weeks 4 and 6.

hint: With $w = b = 0$ every predicted probability is $1/2$.
hint: $\partial L/\partial b = \frac{1}{n}\sum(p_i - y_i)$ and the update is $b \leftarrow b - \eta\,\partial L/\partial b$.
solution: The differences $p_i - y_i$ are $0.5$, $-0.5$ and $-0.5$, with mean $-1/6$. The update is $b = 0 - 1\cdot(-1/6) = 1/6$. (For reference, $\partial L/\partial w = \frac{1}{3}(0 - 0.5 - 1) = -0.5$, so $w = 0.5$.)

solution: (1) No baseline: predicting "no fault" for every case is already 99% accurate, so 99.2% is barely better and says almost nothing about whether faults are detected. (2) Accuracy hides the rare class: report the confusion matrix, precision and recall for faults (recall is likely critical) and compare them with the baseline, with confidence intervals; with 1% positives a test set of a few thousand cases has only a few dozen faults, so the intervals will be wide. (4) Selection on the test set: picking the best of 40 settings by test accuracy makes the reported number optimistically biased; tune with cross-validation on the training data (stratified, so each fold contains faults), and touch the test set once, for the final model.

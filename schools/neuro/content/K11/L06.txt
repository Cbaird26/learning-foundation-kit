@article
Grown-up helper, please read this out loud.

Loops are great for patterns. Let us make some out of stars.

### A row of stars

Remember that times works on text. A star times 5 is five stars in a row.

```python
print("*" * 5)
```

This shows:

```text
*****
```

### A box of rows

Put that line inside a loop and you get many rows.

```python
for i in range(3):
    print("*" * 4)
```

This shows:

```text
****
****
****
```

That is 3 rows with 4 stars in each.

### A pattern that grows

The loop counter can set how long each row is. Start the counter at 1 with `range(1, 4)`.

```python
for i in range(1, 4):
    print("*" * i)
```

When `i` is 1, the row has 1 star. When `i` is 2, it has 2 stars. When `i` is 3, it has 3 stars.

```text
*
**
***
```

It looks like a little staircase.

### Make your own

Try a different symbol, like `"#"` or `"-"`. Change the numbers to make a bigger or smaller pattern. Run it and see.

@example
title: A staircase
problem: What does this program show?

```python
for i in range(1, 4):
    print("*" * i)
```
step: The first time, `i` is 1, so we print 1 star.
step: Then `i` is 2 and we print 2 stars. Then `i` is 3 and we print 3 stars.
step: The screen shows `*`, then `**`, then `***`.

@example
title: A box of stars
problem: Print 2 rows with 3 stars in each row.
step: We want 2 rows, so the loop uses `range(2)`.
step: Each row is `"*" * 3`.
step: Write `for i in range(2):` and then, indented, `print("*" * 3)`.

@mistakes
- Putting the star inside the loop but forgetting the quote marks, so Python says `SyntaxError`.
- Writing `range(3)` when you wanted rows of 1, 2 and 3 stars. That starts at 0, so the first row is empty. Use `range(1, 4)`.
- Mixing up the number of rows (the loop) with the number of stars in a row (the times).

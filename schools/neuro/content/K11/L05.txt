@article
Grown-up helper, please read this out loud.

Computers never get bored. We can ask one to do the same thing again and again. That is called a **loop**.

```python
for i in range(3):
    print("Hip hip hooray!")
```

This shows the cheer three times:

```text
Hip hip hooray!
Hip hip hooray!
Hip hip hooray!
```

### The parts

- `for` starts the loop.
- `range(3)` means, "do it 3 times."
- The colon `:` at the end says, "the lines to repeat come next."
- The lines to repeat are pushed in by **4 spaces**. This push is called **indenting**.

Only the indented lines repeat. A line that is not indented runs just once, after the loop is finished.

```python
for i in range(2):
    print("Jump")
print("Stop")
```

This shows `Jump`, `Jump`, `Stop`.

### Counting with the loop

The little name `i` is a variable. It counts for you, and it starts at **0**.

```python
for i in range(3):
    print(i)
```

This shows `0`, `1` and `2`. That is three numbers, so the loop ran 3 times. It stops *before* 3.

To start at 1, give two numbers: `range(1, 4)` gives `1`, `2`, `3`.

@example
title: Cheer four times
problem: Write a program that prints `Go team!` four times.
step: We want four repeats, so use `range(4)`.
step: Write `for i in range(4):` and end the line with a colon.
step: On the next line, indent 4 spaces and write `print("Go team!")`.
answer: for i in range(4): then print("Go team!") indented.

@example
title: Inside or outside the loop
problem: What does this program show?

```python
for i in range(2):
    print("Jump")
print("Stop")
```
step: The indented `print("Jump")` repeats 2 times.
step: The `print("Stop")` is not indented, so it runs once at the end.
step: The screen shows `Jump`, `Jump` and then `Stop`.

@mistakes
- Forgetting the colon at the end of the `for` line, which gives a `SyntaxError`.
- Forgetting to indent the line to repeat. Python says `IndentationError`, which means, "Please push this line in."
- Thinking `range(3)` counts 1, 2, 3. It counts 0, 1, 2.

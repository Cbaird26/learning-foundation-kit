@article
You have seen a few dogs and a few cats. A new animal appears, a little like both. How do you decide? One theory says you compare it with a summary, the "average dog" and the "average cat" (a **prototype**; Rosch, 1975). Another says you compare it with every individual you remember (**exemplars**). The theories sound different, but do they predict different behavior?

### A shared ingredient: similarity

Stimuli are points in a feature space, here two dimensions (say size and orientation, each on a 1 to 5 scale). The distance between stimuli $x$ and $y$ is a weighted city-block distance

$$d(x, y) = \sum_m w_m\,|x_m - y_m|, \qquad w_m \ge 0,\ \sum_m w_m = 1,$$

where the **attention weights** $w_m$ say which dimensions matter. Similarity falls off exponentially, $s(x, y) = e^{-c\,d(x, y)}$, with **sensitivity** $c > 0$: a large $c$ makes only very close stimuli count as similar. The exponential form is a common choice, consistent with the finding that generalization falls off exponentially with distance in many tasks (Shepard's universal law), but it is an assumption of the model.

### Two models

The **generalized context model** (GCM; Nosofsky, 1986) says the probability of responding "A" to a stimulus $x$ is the summed similarity to all stored exemplars of category A relative to the total:

$$P_{\text{GCM}}(A \mid x) = \frac{\sum_{j \in A} s(x, j)}{\sum_{j \in A} s(x, j) + \sum_{j \in B} s(x, j)}.$$

(This version has no response bias; a bias would multiply each sum by a weight.) The **prototype model** replaces each category by its mean $\bar{x}_A$ and $\bar{x}_B$:

$$P_{\text{proto}}(A \mid x) = \frac{s(x, \bar{x}_A)}{s(x, \bar{x}_A) + s(x, \bar{x}_B)}.$$

```python
import math

def similarity(x, y, w, c):
    return math.exp(-c * sum(wi * abs(a - b) for wi, a, b in zip(w, x, y)))

def gcm_prob_a(x, a_items, b_items, w, c):
    sa = sum(similarity(x, j, w, c) for j in a_items)
    sb = sum(similarity(x, j, w, c) for j in b_items)
    return sa / (sa + sb)

def prototype(items):
    return tuple(sum(v) / len(items) for v in zip(*items))

def proto_prob_a(x, a_items, b_items, w, c):
    sa = similarity(x, prototype(a_items), w, c)
    sb = similarity(x, prototype(b_items), w, c)
    return sa / (sa + sb)

A = [(1, 2), (2, 1), (2, 3), (1, 1)]
B = [(4, 4), (5, 3), (4, 5), (5, 5)]
for t in [(2, 2), (3, 3), (4, 3)]:
    print(t, round(gcm_prob_a(t, A, B, (0.5, 0.5), 1.0), 3),
          round(proto_prob_a(t, A, B, (0.5, 0.5), 1.0), 3))
```

With $c = 1$ and equal weights it prints `(2, 2) 0.845 0.881`, `(3, 3) 0.521 0.5` and `(4, 3) 0.285 0.269`. The prototypes here are $(1.5, 1.75)$ and $(4.5, 4.25)$, and $(3, 3)$ is the same distance from both. The two models give nearly the same probabilities on these compact categories. That is **model mimicry** again: with compact, well-separated categories data cannot easily tell the models apart.

### Where they differ

Categories with a different structure separate them. Let category A be $\{(0,0), (4,4)\}$ and category B be $\{(0,4), (4,0)\}$. Both have the mean $(2,2)$, so the prototype model gives $0.5$ for every stimulus and cannot learn the classification. The GCM gives $P(A \mid (0,0)) = 0.790$ for $c = 1$ because $(0,0)$ is identical to a stored A exemplar. People can learn such categories, although with difficulty. The evidence from many experiments is mixed: exemplar models have often fit categorization better, prototype effects appear in other conditions (large categories, early learning, high-dimensional natural stimuli), and hybrid or clustering models, which store several prototypes between the two extremes, have been proposed. The debate concerns the **representation**, an algorithmic-level question, and model comparison on one data set rarely closes it.

### Fitting and memory

Given test stimuli with $k_i$ of $n_i$ responses "A," the log-likelihood is $\sum_i [k_i \log p_i + (n_i - k_i)\log(1 - p_i)]$, which can be maximized over $c$ by a grid search exactly as in week 3. The same summed similarity serves as a model of **recognition memory**: the **familiarity** of a test item is $F(x) = \sum_{j \in \text{studied}} s(x, j)$ and the item is called "old" if $F(x)$ exceeds a criterion. This is a **global matching** account, in which the test item is matched against all of memory at once, and it links the categorization and memory literatures (a model of this kind was applied to recognition by Nosofsky and others).

@mistakes
- Computing the prototype from the test stimulus or from only one category: each category's prototype is the mean of its own training items.
- Using the largest similarity instead of the summed similarity in the GCM.
- Forgetting that the attention weights must sum to 1, or applying them to similarities instead of to distances.
- Concluding that a model whose fit is a little better "wins": exemplar and prototype predictions are often nearly identical.

model:
```python
import math


def gcm_probs(x, categories, w, c):
    """GCM response probabilities for any number of categories."""
    sums = []
    for items in categories:
        total = 0.0
        for item in items:
            d = sum(wi * abs(a - b) for wi, a, b in zip(w, x, item))
            total += math.exp(-c * d)
        sums.append(total)
    grand = 0.0
    for s in sums:
        grand += s
    return [s / grand for s in sums]
```
hint: Compute the summed similarity of `x` to the exemplars of each category, then divide each sum by the grand total.
solution: With three one-item categories on a diagonal the test stimulus at the middle one gets most of the probability, and the outer two share the rest equally. With `c = 0` every similarity is 1, so each category's probability is proportional to its number of exemplars; here both categories have one item, so the result is 0.5 each.

```python
import math


def fit_sensitivity(model, a_items, b_items, tests, w, c_grid):
    """Grid-search maximum likelihood of c for a GCM or prototype model."""
    def sim(x, y, c):
        return math.exp(-c * sum(wi * abs(a - b) for wi, a, b in zip(w, x, y)))

    def mean(items):
        return tuple(sum(v) / len(items) for v in zip(*items))

    def prob_a(x, c):
        if model == "gcm":
            sa = sum(sim(x, j, c) for j in a_items)
            sb = sum(sim(x, j, c) for j in b_items)
        else:
            sa = sim(x, mean(a_items), c)
            sb = sim(x, mean(b_items), c)
        return sa / (sa + sb)

    best = None
    for c in c_grid:
        ll = 0.0
        for x, k, n in tests:
            p = prob_a(x, c)
            ll += k * math.log(p) + (n - k) * math.log(1 - p)
        if best is None or ll > best[1]:
            best = (c, ll)
    return best
```
hint: For each `c`, compute the probability of "A" for every test stimulus under the chosen model, accumulate the binomial log-likelihood, and keep the best `c` with a strict comparison.
solution: On the compact categories the two models fit almost equally well (log-likelihoods $-27.96$ and $-28.19$ with one parameter each), so the data cannot separate them. On the XOR categories the prototype model is stuck at 0.5, with log-likelihood $40\log 0.5 = -27.73$ for every $c$, and the exemplar model reaches $-16.92$: here model comparison is decisive.

```python
import math


def recognize(tests, studied, w, c, crit):
    """Old/new decisions from summed similarity to the studied items."""
    decisions = []
    for x in tests:
        fam = 0.0
        for j in studied:
            d = sum(wi * abs(a - b) for wi, a, b in zip(w, x, j))
            fam += math.exp(-c * d)
        decisions.append(fam > crit)
    return decisions
```
hint: Compute the familiarity of each test item as a sum of similarities and compare it with `crit` using a strict inequality.
solution: A studied item matched exactly has similarity 1 to itself, so with a single studied item its familiarity equals the criterion 1.0 and the strict inequality gives `False`. With `c = 0` every similarity is 1, so familiarity equals the number of studied items (3), which exceeds 2.5 for every test item: sensitivity zero erases the distinction between old and new.

@quiz self
prompt: A study finds that the prototype model and the exemplar model fit the categorization of two groups of compact, well-separated categories equally well (log-likelihoods within 0.3 with one parameter each). Explain why this does not show that people use prototypes, and design a category structure and a test that would separate the models, saying what each model predicts.
hint: Think about categories with the same means but different exemplars, and about which test items the models treat differently.
solution: With compact, well-separated categories the summed similarity to exemplars and the similarity to the mean produce nearly identical response probabilities for most test items, so equal fits are expected from both: this is model mimicry, and equal fit cannot identify the representation. To separate them choose categories with the same means but different structure, such as A = {(0,0),(4,4)} and B = {(0,4),(4,0)}, and test the trained exemplars and new items. The prototype model predicts 0.5 for every item because both prototypes are at (2,2); the exemplar model predicts a strong preference for the trained category on each trained item. Another contrast is a category with high within-category variability, where the exemplar model keeps the influence of outliers that a prototype hides. If participants learn the structure above chance, the prototype model is in trouble; if they do not, the evidence favors prototypes, and a hybrid model must then be considered.

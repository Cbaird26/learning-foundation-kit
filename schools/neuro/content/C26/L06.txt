@article
Tell a participant "respond as fast as you can" and she makes more mistakes. Tell her "be as accurate as you can" and she slows down. This **speed–accuracy trade-off** means that reaction time and accuracy cannot be interpreted separately: a group that is faster and less accurate may not be better at the task at all, only more hasty. A model has to say how the two trade.

### The trade-off in the drift-diffusion model

In the unbiased model of last week (drift $v$, noise $s$, boundaries $\pm a$, $x_0 = 0$), widening the boundary makes the decision variable travel farther, which takes longer but averages out more noise. Using $\tanh y = 2/(1 + e^{-2y}) - 1$, the closed forms combine into a neat identity. Writing $P = 1/(1 + e^{-2va/s^2})$ for accuracy,

$$\tanh\!\Big(\frac{av}{s^2}\Big) = 2P - 1 \quad\Longrightarrow\quad \mathbb{E}[\text{DT}] = \frac{a}{v}\,(2P - 1), \qquad a = \frac{s^2}{2v}\,\ln\frac{P}{1-P}.$$

Here is the trade-off for $v = 1$ and $s = 1$:

| boundary $a$ | accuracy $P$ | mean decision time (s) |
|---|---|---|
| 0.5 | 0.731 | 0.231 |
| 1.0 | 0.881 | 0.762 |
| 1.5 | 0.953 | 1.358 |

Moving along such a table by changing only $a$ traces a **speed–accuracy trade-off function**. A different thing happens when the evidence gets better: a larger $v$ makes the person both faster and more accurate. The model therefore separates a change of strategy (boundary) from a change of ability or stimulus (drift).

### Predicting RT in two conditions

Take $v = 1.2$ per second, $s = 1$ and $t_0 = 0.30$ s. Suppose accuracy is $0.75$ under speed instructions and $0.90$ under accuracy instructions. The identity gives the boundary in each condition and a predicted mean RT $t_0 + \mathbb{E}[\text{DT}]$:

```python
import math

def boundary_from_accuracy(acc, v, s):
    return s * s / (2 * v) * math.log(acc / (1 - acc))

def predicted_mean_rt(acc, a, v, t0):
    return t0 + a / v * (2 * acc - 1)

v, s, t0 = 1.2, 1.0, 0.30
for acc in (0.75, 0.90):
    a = boundary_from_accuracy(acc, v, s)
    print(acc, round(a, 3), round(predicted_mean_rt(acc, a, v, t0), 3))
```

It prints `0.75 0.458 0.491` and `0.9 0.916 0.91`: the model needs a boundary twice as wide in the accuracy condition and predicts mean RTs of 491 ms and 910 ms. If the observed RTs were close to these, a single drift rate and a single non-decision time would explain both conditions through the boundary alone, which is a testable restriction: the same $v$ and $t_0$ must fit both.

### Errors, variability, and measures

In the simple model with an unbiased start, correct and error responses have the same mean decision time. Real data often show slow errors when evidence is hard and fast errors when speed is stressed. Extended versions of the model explain slow errors with trial-to-trial variability in the drift rate and fast errors with variability in the starting point, which are model-based explanations of an observed pattern, though not the only ones.

Researchers sometimes combine speed and accuracy into one number, such as the **inverse efficiency score**, the mean RT of correct trials divided by the proportion correct. It assumes that speed and accuracy trade linearly and in a fixed way, and the DDM shows that they do not (the table is curved). Estimating model parameters, as above, is more principled but depends on the model being right.

Two points remain debated. One is whether speed instructions change only the boundary: some studies also report changes in drift rate or non-decision time, and the answer may depend on the task. Another is whether a fixed boundary is realistic: models with a boundary that **collapses** over time (an urgency signal) make different predictions for slow decisions, and data do not decide clearly between them in all designs.

problem: With $v = 1.2$, $s = 1$ and $t_0 = 0.30$ s, an observer is 85% accurate in a condition. Find the boundary and the predicted mean RT.
step: Boundary: $a = \frac{1}{2.4}\ln\frac{0.85}{0.15} = 0.4167 \times 1.7346 = 0.7228$.
step: Mean decision time: $\frac{a}{v}(2P - 1) = \frac{0.7228}{1.2}(0.70) = 0.4216$ s.
step: Add the non-decision time: $0.30 + 0.4216 = 0.7216$ s.

@mistakes
- Comparing RTs across conditions without looking at accuracy: a faster condition with lower accuracy may only reflect a narrower boundary.
- Using the identity when the start is biased or the parameters vary from trial to trial: it holds for the unbiased, constant-parameter model.
- Interpreting inverse efficiency as a pure measure of ability: it assumes a particular, linear trade-off.
- Forgetting the non-decision time when predicting RT: the model's decision time is only part of the response time.

model:
```python
import math


def fit_boundary_grid(obs_acc, obs_rt, v, s, t0, a_grid):
    """Grid value of the boundary that best matches accuracy and mean RT."""
    def loss(a):
        acc = 1.0 / (1.0 + math.exp(-2 * v * a / s ** 2))
        rt = t0 + (a / v) * math.tanh(a * v / s ** 2)
        return (acc - obs_acc) ** 2 + (rt - obs_rt) ** 2

    return min(a_grid, key=loss)
```
hint: Compute the predicted accuracy and RT for each `a`, add the squared errors, and take the grid value with the smallest total.
solution: The loss uses both observations, so the fit is a compromise when one boundary cannot match both exactly. Because accuracy is on a scale of 0 to 1 and RT in seconds, the two terms are comparable here; with RT in milliseconds the RT term would dominate, which is why units must be kept consistent.

model:
```python
import math


def compare_with_theory(trials, v, a, s, dt):
    """Simulated minus closed-form accuracy and mean decision time."""
    upper, times = 0, []
    for noise in trials:
        x = 0.0
        for k, xi in enumerate(noise, start=1):
            x += v * dt + s * math.sqrt(dt) * xi
            if x >= a or x <= -a:
                upper += 1 if x >= a else 0
                times.append(k * dt)
                break
    if not times:
        return None
    p_sim = upper / len(times)
    dt_sim = sum(times) / len(times)
    p_th = 1.0 / (1.0 + math.exp(-2 * v * a / s ** 2))
    dt_th = (a / v) * math.tanh(a * v / s ** 2)
    return p_sim - p_th, dt_sim - dt_th
```
hint: First simulate and tally the upper-boundary count and the decision times; then compute the two closed-form values and subtract them from the simulated ones.
solution: With five short trials the simulated accuracy and mean time are noisy estimates, so differences of this size are expected; the comparison becomes informative with thousands of trials and a small time step, because Euler steps also miss boundary crossings within a step and so give slightly longer decision times than the continuous-time formula.

model:
```python
import math


def ddm_collapsing(noise, v, a0, s, dt, rate):
    """Euler DDM whose boundaries shrink linearly with time (floored at 0)."""
    x = 0.0
    for k, xi in enumerate(noise, start=1):
        x += v * dt + s * math.sqrt(dt) * xi
        a = max(a0 - rate * k * dt, 0.0)
        if x >= a:
            return 1, k * dt
        if x <= -a:
            return 0, k * dt
    return None
```
hint: Compute the current boundary inside the loop, after the update, from the step number.
solution: A collapsing boundary forces a decision sooner: the same noise sequence gives a decision at 0.6 s with rate 0.5 and at 0.4 s with rate 2, instead of 0.7 s with a fixed boundary. Once the boundary reaches 0, any value of $x$ at or above 0 gives choice 1, which the zero-noise test exercises.

@quiz self
prompt: A lab compares two groups and reports that group A has a mean RT of 520 ms with 92% accuracy and group B 480 ms with 86% accuracy, and concludes that B is "faster, so better." Using the drift-diffusion model, explain why this conclusion is not justified, how you could separate a difference in caution from a difference in ability, and one limitation of that model-based answer.
hint: Think about which parameter each difference corresponds to, and about what the DDM assumes.
solution: Group B is faster and less accurate, which is the pattern produced by a narrower boundary: a shift along a speed–accuracy trade-off function, not necessarily a difference in ability. With the DDM, estimate the drift rate, boundary separation and non-decision time for each group from both accuracy and the RT distributions. If the drift rates are equal and only the boundary differs, the groups differ in strategy; if the drift rates differ, the groups differ in the quality of evidence they extract, which is closer to ability. An experiment that manipulates instructions within each group, giving each person a speed and an accuracy condition, helps to separate the two. A limitation is that the conclusion depends on the model being right: other models can explain the same pattern with different parameters, parameters can trade off against each other with few trials, and instructions may change drift or non-decision time as well as the boundary.

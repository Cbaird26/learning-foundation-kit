@article
Two stimuli signal food: a light, and later a light plus a tone. If the light alone already predicts food perfectly, an animal that then experiences light-plus-tone followed by food learns almost nothing about the tone. This effect is called **blocking** (Kamin, 1969). It means that association does not grow just because a cue and an outcome occur together: what matters is whether the outcome was already expected, that is, the prediction error. A learning rule built on prediction error accounts for it, and the same rule is the heart of **connectionist** models.

### Units, weights and the delta rule

A connectionist model is a network of simple units. A **logistic unit** computes $y = \sigma(\mathbf{w}^\top \mathbf{x} + b)$ with $\sigma(z) = 1/(1 + e^{-z})$ from its inputs $\mathbf{x}$. To learn a target $t$, the weights are changed in proportion to the error and the input (the **delta rule**, with learning rate $\eta$):

$$w_i \leftarrow w_i + \eta\,(t - y)\,x_i, \qquad b \leftarrow b + \eta\,(t - y).$$

For a logistic unit this is gradient descent on the cross-entropy error. Take the patterns $(0,0), (0,1), (1,0), (1,1)$ and targets $0, 1, 1, 1$ (logical OR).

```python
import math

def sigmoid(z):
    return 1.0 / (1.0 + math.exp(-z))

def train_unit(patterns, targets, eta, epochs):
    w = [0.0] * (len(patterns[0]) + 1)
    for _ in range(epochs):
        for x, t in zip(patterns, targets):
            xb = list(x) + [1.0]
            y = sigmoid(sum(wi * xi for wi, xi in zip(w, xb)))
            for i in range(len(w)):
                w[i] += eta * (t - y) * xb[i]
    return w

patterns = [(0, 0), (0, 1), (1, 0), (1, 1)]
for targets in ([0, 1, 1, 1], [0, 1, 1, 0]):
    w = train_unit(patterns, targets, 0.5, 500)
    print([round(sigmoid(w[0] * a + w[1] * b + w[2]), 3) for a, b in patterns])
```

The last weight is the bias. For OR, the program prints `[0.02, 0.992, 0.992, 1.0]`: the unit has learned. For XOR (targets $0,1,1,0$) it prints `[0.571, 0.5, 0.429, 0.361]`, near $0.5$ for everything: it has failed, and more epochs do not help.

### Why XOR fails and what history followed

A single unit separates its inputs with a straight line (a hyperplane), so it can learn only **linearly separable** categories. No line puts $(0,1)$ and $(1,0)$ on one side and $(0,0)$ and $(1,1)$ on the other. The same limit hit Rosenblatt's perceptron (1958), and Minsky and Papert (1969) analyzed such limits; interest in neural networks dropped for years. A network with a **hidden layer** removes the limit. Take two hidden threshold units, one that fires when $x_1 + x_2 \ge 0.5$ (OR) and one when $x_1 + x_2 \ge 1.5$ (AND); an output unit that fires when the first is on and the second off computes XOR. What was missing was a way to learn the hidden weights; the **backpropagation** of errors through layers, popularized by Rumelhart, Hinton and Williams (1986) within the parallel distributed processing (PDP) program of Rumelhart and McClelland (1986), supplied one. Related milestones are the Hopfield network (1982), simple recurrent networks (Elman, 1990) and, much later, deep networks as models of the ventral visual stream (Yamins and colleagues, 2014).

### The Rescorla–Wagner rule as a delta rule

In the Rescorla–Wagner model (1972) each cue $i$ has an associative strength $V_i$, and on a trial with a set of cues present and outcome magnitude $\lambda$ (1 if the outcome occurs, 0 if not),

$$\Delta V_i = \eta\Big(\lambda - \sum_{j \text{ present}} V_j\Big) \quad\text{for each cue } i \text{ present}.$$

This is the delta rule with linear units, where the prediction $\sum_j V_j$ is summed over cues. Blocking follows. After 20 trials of the light (cue 0) alone with $\lambda = 1$ and $\eta = 0.2$, $V_0 = 0.988$ and the error is almost zero, so during 20 trials of light plus tone, the tone's strength grows only to $V_1 = 0.006$ (and $V_0$ ends at $0.994$). Without the pretraining, the same 20 compound trials give $V_0 = V_1 = 0.5000$, because they share the prediction equally.

### What connectionist models show

Connectionist models were a major source of ideas about learning, distributed representation and graceful degradation. Their role in explaining cognition has been argued. A model of learning past tenses (Rumelhart and McClelland, 1986) was criticized (Pinker and Prince, 1988) by researchers who argued that it did not capture rule-like behavior and that its input representation did the work; others replied that networks can capture regularities and exceptions in one system, and later models addressed some criticisms. A related dispute asks whether networks can account for the systematic, compositional structure of thought. These debates have not been settled, and they concern what the models explain, not only how well they fit. A network that fits data is a model at the algorithmic level; its relation to the brain's implementation needs separate evidence.

@example
title: One delta-rule update, and a first Rescorla–Wagner trial
problem: (a) A logistic unit has weight $w = 0.2$ on an input $x = 1$, learning rate $\eta = 0.5$, target $t = 1$, and its output is $y = 0.4$. Find the new weight. (b) In the Rescorla–Wagner rule with $\eta = 0.5$, cues 0 and 1 both start at $V = 0$ and appear together with $\lambda = 1$. Find both values after one trial.
step: (a) The error is $t - y = 0.6$, so $\Delta w = 0.5 \times 0.6 \times 1 = 0.3$ and the new weight is $0.5$.
step: (b) The summed prediction is $0 + 0 = 0$, so the error is $1 - 0 = 1$.
step: Each present cue changes by $\eta \times 1 = 0.5$, so $V_0 = V_1 = 0.5$.
step: On a second compound trial the summed prediction is $1.0$, so the error is $0$ and nothing more is learned: the cues share the single outcome.
answer: (a) $w = 0.5$; (b) $V_0 = V_1 = 0.5$.

@mistakes
- Updating weights with the output instead of the error $t - y$: a perfectly predicted pattern should produce no change.
- Updating each cue by its own prediction error in Rescorla–Wagner: the error uses the summed prediction of all cues present.
- Expecting a single unit to learn any labeling: it learns only linearly separable ones.
- Equating a good fit with an explanation: networks can fit many data sets, and what they explain is debated.

model:
```python
def rw_compound(trials, eta, n_cues):
    """Rescorla-Wagner associative strengths after a sequence of trials."""
    v = [0.0] * n_cues
    for cues, lam in trials:
        error = lam - sum(v[i] for i in cues)
        for i in cues:
            v[i] += eta * error
    return v
```
hint: Compute the summed prediction of the cues present first, then apply the same error to each of them.
solution: Computing the error once per trial from the summed prediction is what produces blocking: after the first cue has absorbed the outcome, the error on the compound trials is nearly zero and the second cue gains almost nothing. The extinction test shows the same rule lowering a value when the outcome is omitted.

model:
```python
import math


def train_until(patterns, targets, eta, tol, max_epochs):
    """Train a logistic unit until every error is below tol (or give up)."""
    def out(w, x):
        z = sum(wi * xi for wi, xi in zip(w, list(x) + [1.0]))
        return 1.0 / (1.0 + math.exp(-z))

    w = [0.0] * (len(patterns[0]) + 1)
    for epoch in range(1, max_epochs + 1):
        for x, t in zip(patterns, targets):
            y = out(w, x)
            for i, xi in enumerate(list(x) + [1.0]):
                w[i] += eta * (t - y) * xi
        worst = max(abs(t - out(w, x)) for x, t in zip(patterns, targets))
        if worst < tol:
            return w, epoch
    return w, max_epochs
```
hint: After each epoch's updates, recompute the outputs for all patterns and take the largest error before deciding whether to stop.
solution: The stopping rule turns learning into a measurable quantity: OR is learned in 47 epochs and AND in 46 at their rates. XOR runs to the epoch limit because no weights of a single unit can bring every error below $0.2$. With `max_epochs = 0` no training happens and the loop never returns early.

model:
```python
import math


def net_forward(x, W1, b1, w2, b2):
    """Forward pass of a one-hidden-layer logistic network."""
    def sigmoid(z):
        return 1.0 / (1.0 + math.exp(-z))

    hidden = [sigmoid(sum(w * xi for w, xi in zip(row, x)) + b)
              for row, b in zip(W1, b1)]
    out = sigmoid(sum(w * h for w, h in zip(w2, hidden)) + b2)
    return out, hidden
```
hint: Compute each hidden unit from its own row of `W1`, then compute the output from the list of hidden activations.
solution: With large weights the logistic units behave like threshold units: the first hidden unit computes roughly OR of the inputs and the second roughly NAND, and the output unit computes their AND, which is XOR. The first test checks one generic pass with small weights by hand-computable values.

@quiz self

solution: The strongest argument: a single learning mechanism with no explicit rules produced both regular and irregular forms and a pattern of errors resembling children's, so the claim that rules are needed to explain the data is weakened; the model also makes predictions about frequency effects that can be tested. Further evidence would include testing the model on novel words and across languages, comparing it with rule-plus-memory models using a criterion that penalizes parameters, checking that the data distinguish the models, and neuropsychological or neuroimaging evidence on whether regular and irregular forms use separable processes.

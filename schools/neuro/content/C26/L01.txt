@article
People forget. A list learned today is partly gone tomorrow, and more is gone next week. Ebbinghaus (1885) measured this and gave us the **forgetting curve**. A verbal theory says "memory decays with time" and stops there. A model says how much, for each delay, and so it can be wrong in a way you can measure. That is why we build models: to turn a theory into numbers that data can contradict.

### What a model is

A **cognitive model** is a function from **parameters** $\theta$ (and the task's conditions) to predicted behavior: choices, reaction times (RT, in ms), accuracies or recall proportions. The parameters are the model's free quantities, such as a decay rate or a learning rate. **Fitting** a model means choosing $\theta$ so the predictions come as close as possible to the data; **testing** it means asking whether it still fits when you change the conditions.

Models differ in what they claim:

- A **descriptive** model summarizes a pattern (a psychometric function relating stimulus strength to accuracy) without a claim about the mind's machinery.
- A **process** model proposes a mechanism, a sequence of operations unfolding in time (evidence accumulating to a bound in the drift-diffusion model of Ratcliff, 1978; a value update after each outcome in the Rescorla–Wagner rule).
- A **normative** model says what an ideal agent would do given the task and its goals (a Bayesian observer, signal detection theory with the optimal criterion).

### Marr's levels

Marr (1982) separated three **levels of analysis**. The **computational** level asks what problem is being solved and why a solution is appropriate. The **algorithmic** (or representational) level asks which representations and processes carry it out. The **implementational** level asks how neurons and circuits realize them. A claim that people weight cues by their reliability because that minimizes error is computational. A claim that evidence is summed until it reaches a bound is algorithmic. A claim about which population of neurons carries the sum is implementational. Researchers disagree about how tightly the levels constrain each other. Some argue that a computational-level analysis can proceed independently and explains why behavior has its form; others argue that without algorithmic and neural constraints such analyses are too flexible to be tested. Both positions are held by serious researchers, and this course will use models at all three levels.

### A first fit: two models of forgetting

Proportion recalled after lags of 1, 2, 4, 8 and 16 days (invented data): $0.62, 0.47, 0.30, 0.17, 0.08$. An **exponential** model predicts $p(t) = e^{-\lambda t}$, and a **power** model predicts $p(t) = (1+t)^{-b}$. Each has one parameter. We score a parameter value by the **sum of squared errors** $\text{SSE} = \sum_i (\hat p_i - p_i)^2$ and search a grid of values.

```python
import math

def exp_model(t, lam):
    return math.exp(-lam * t)

def power_model(t, b):
    return (1 + t) ** (-b)

def sse(model, param, lags, data):
    return sum((model(t, param) - y) ** 2 for t, y in zip(lags, data))

lags = [1, 2, 4, 8, 16]
data = [0.62, 0.47, 0.30, 0.17, 0.08]
for lam in (0.30, 0.35, 0.40):
    print(lam, round(sse(exp_model, lam, lags, data), 4))
```

This prints SSE values $0.0322$, $0.0285$ and $0.0354$, so on this grid the best exponential rate is $\lambda = 0.35$ per day. The best power exponent on a grid of steps of $0.1$ is $b = 0.7$, with SSE $0.0060$. The power model fits better here.

### Mimicry and the limits of fit

A smaller SSE does not prove that the better-fitting mechanism is the true one. **Model mimicry** means that models with different mechanisms can make nearly the same predictions over the conditions you tested, so the data cannot separate them. Added parameters let a model fit more patterns, including noise. Good practice is to compare models with a penalty for flexibility (week 8), to test them on new conditions, and to ask which level of Marr's hierarchy the claim lives at. A fit is evidence, not a verdict.

@example
title: Scoring one parameter value
problem: An exponential forgetting model has $\lambda = 0.3$ per day. Recall at lags of 1, 2 and 3 days was $0.70, 0.52, 0.38$. Compute the predictions and the SSE.
step: Predictions: $e^{-0.3} = 0.7408$, $e^{-0.6} = 0.5488$, $e^{-0.9} = 0.4066$.
step: Errors (prediction minus data): $0.0408$, $0.0288$, $0.0266$.
step: Square and add: $0.001665 + 0.000829 + 0.000708 \approx 0.0032$.
step: Compare with another $\lambda$ the same way; the value with the smallest SSE on the grid is the best-fitting one.
answer: SSE $\approx 0.0032$.

@mistakes
- Treating a good fit as proof of mechanism: different models can mimic each other on the conditions tested.
- Confusing the levels: a normative argument that behavior is optimal says nothing yet about the algorithm or the neurons.
- Comparing models by SSE alone when they have different numbers of parameters, or fitting more parameters than the data can constrain.
- Searching a grid that does not contain the best value: if the best value sits at the edge of the grid, widen the grid.

model:
```python
def top_params(model, grid, lags, data, k):
    """The k grid values with the smallest SSE, best first (stable)."""
    def sse(p):
        return sum((model(t, p) - y) ** 2 for t, y in zip(lags, data))

    return sorted(grid, key=sse)[:k]
```
hint: Sorting with a key function that computes the SSE of each grid value does most of the work, and Python's sort is stable.
solution: Score each grid value by its SSE, sort by that score (stability keeps tied values in grid order), and slice off the first `k`. Slicing handles a `k` larger than the grid automatically.

model:
```python
import math


def fit_scaled_exp(lags, data, a_grid, lam_grid):
    """Best (a, lam, sse) for p(t) = a * exp(-lam * t) over the two grids."""
    best = None
    for a in a_grid:
        for lam in lam_grid:
            err = sum((a * math.exp(-lam * t) - y) ** 2
                      for t, y in zip(lags, data))
            if best is None or err < best[2]:
                best = (a, lam, err)
    return best
```
hint: Use two nested loops, keep the best triple so far, and replace it only when the new SSE is strictly smaller.
solution: Every pair is scored with the same SSE formula as the one-parameter model, with the extra factor `a`. The strict comparison keeps the first of any tied pairs. Adding the intercept gives the model more freedom, so its best SSE can never be larger than the one-parameter model's at `a = 1`.

model:
```python
def minimax_param(model, grid, lags, data):
    """Grid value minimizing the maximum absolute prediction error."""
    def worst(p):
        return max(abs(model(t, p) - y) for t, y in zip(lags, data))

    return min(grid, key=worst)
```
hint: Replace the sum of squares by the maximum of the absolute errors and pick the grid value that minimizes it.
solution: The choice of error measure is part of the model-fitting method: squared error punishes large misses more than the maximum rule balances them, so the two rules can pick different parameters. `min` with a key returns the first minimizer, which handles ties.

@quiz self
prompt: Two models of forgetting, one exponential and one power, both fit a five-point data set well. A classmate says the winner has revealed how memory really decays. Explain model mimicry, say at which of Marr's levels each model makes its claim, and describe one new experiment that could separate the two models.
hint: Think about what conditions would make the two predicted curves diverge.
solution: Mimicry means different mechanisms can produce nearly the same curve over the lags tested, so a small difference in SSE between them cannot identify the mechanism, especially with five points and noise. Both models are descriptive at the computational-to-algorithmic boundary: each says how retention changes, and neither says by what neural or cognitive process. An experiment can separate them by testing lags where the curves differ most, for example very short and very long delays, such as 1 hour and 60 days, where an exponential falls toward zero much faster than a power function. Comparing the models there, preferably with a penalty for parameters and with parameters fixed from earlier lags, makes the models risk a prediction.

@article
Last week's delta-rule learner fit a participant's choices better than chance. Of course it did: a model with two free parameters almost always beats a model with none. The question is whether it fits **enough** better to justify the extra parameters. Fit improves with complexity even when the extra parameters only absorb noise, so we need a way to compare models that penalizes flexibility.

### Nested models and the likelihood-ratio test

Model 0 is **nested** in model 1 if it is the special case of model 1 obtained by fixing some parameters. If model 0 is true and standard regularity conditions hold, with a large number of observations, then

$$D = 2\,(\log L_1 - \log L_0)$$

follows approximately a $\chi^2$ distribution with degrees of freedom equal to the number of extra parameters. For one degree of freedom, $p = 2\big(1 - \Phi(\sqrt{D})\big)$; for two, $p = e^{-D/2}$. With log-likelihoods $-48.1$ (a softmax with one parameter) and $-45.2$ (the same model plus a bias, two parameters), $D = 5.8$ and $p = 0.016$ on one degree of freedom. The conditions matter. Comparing a learner with chance puts the parameter $\beta = 0$ on a boundary and makes $\alpha$ unidentified, so the $\chi^2$ reference is not valid there. The test also cannot compare non-nested models such as a delta-rule learner and a win-stay lose-shift rule.

### Information criteria

Two widely used scores penalize the number of parameters $k$. With maximized log-likelihood $\ell$ and $n$ data points (here, choices):

$$\text{AIC} = 2k - 2\ell, \qquad \text{BIC} = k\ln n - 2\ell.$$

Lower is better, and only differences between models fitted to the same data mean anything. The AIC (Akaike) aims at the model expected to predict new data best; the BIC (Schwarz) approximates the log of the Bayesian marginal likelihood and, under assumptions, picks the true model among those considered as $n$ grows. The BIC's penalty per parameter, $\ln n$, exceeds the AIC's penalty of $2$ once $n \ge 8$, so the BIC favors simpler models and the two can disagree. When $n$ is small relative to $k$, a corrected criterion $\text{AICc} = \text{AIC} + 2k(k+1)/(n-k-1)$ is often used. Differences convert to **Akaike weights**: $\Delta_i = \text{AIC}_i - \min_j \text{AIC}_j$ and $w_i = e^{-\Delta_i/2}/\sum_j e^{-\Delta_j/2}$, which sum to one and can be read as the relative support among the models compared.

### Three models of 16 choices

Choices $1,0,1,1,1,1,1,0,0,0,1,1,1,1,1,1$ with rewards $1,0,1,1,0,1,0,1,0,0,1,1,1,1,0,1$ were fitted by (a) **chance**: $p = 0.5$, $k = 0$; (b) **win-stay lose-shift** (WSLS): the first choice has probability $0.5$, then the previous choice is repeated with probability $1-\epsilon$ after a reward and switched to with probability $1-\epsilon$ after none, $k = 1$; and (c) the delta-rule softmax learner of last week with $Q_0 = 0.5$, $k = 2$. Grid searches gave $\epsilon = 0.25$ and $(\alpha, \beta) = (0.5, 6)$.

```python
import math

def aic(ll, k):
    return 2 * k - 2 * ll

def bic(ll, k, n):
    return k * math.log(n) - 2 * ll

def akaike_weights(aics):
    best = min(aics)
    raw = [math.exp(-(a - best) / 2) for a in aics]
    return [r / sum(raw) for r in raw]

fits = {"chance": (-11.0904, 0), "WSLS": (-9.4028, 1), "RL": (-5.4009, 2)}
n = 16
for name, (ll, k) in fits.items():
    print(name, round(aic(ll, k), 2), round(bic(ll, k, n), 2))
print([round(w, 3) for w in akaike_weights([aic(ll, k) for ll, k in fits.values()])])
```

It prints `chance 22.18 22.18`, `WSLS 20.81 21.58`, `RL 14.8 16.35` and the weights `[0.023, 0.046, 0.931]`. Both criteria prefer the learner: $\Delta\text{AIC} = 6.0$ over WSLS, enough that it gets 93% of the weight. Notice what this means and what it does not. The learner is the best of the three; nothing here shows that it is a good model, or that the participant learned values rather than followed some fourth rule.

### What comparison cannot do

Information criteria rank the models you thought of. If all are wrong, the best is only the least wrong; model mimicry means distinct mechanisms can have almost identical scores; and AIC and BIC rest on asymptotic arguments that are rough with a few dozen trials. Safeguards are checks of absolute fit (does the winner reproduce the main features of the data?), cross-validation on held-out trials, and recovery studies (week 12). Reasonable analysts weigh AIC against BIC differently, and the disagreement is a reminder that "best model" depends on the goal: prediction or identification.

title: AIC, BIC and weights for two models
problem: A learner model has $\ell = -42.0$ with $k = 3$ parameters, and a simpler model has $\ell = -44.5$ with $k = 1$, both fitted to $n = 60$ choices. Compute AIC and BIC for each and the Akaike weight of the simpler model.
step: AIC for the learner: $2(3) - 2(-42.0) = 90.0$. For the simpler model: $2(1) - 2(-44.5) = 91.0$.
step: BIC: $\ln 60 = 4.094$. Learner: $3(4.094) + 84 = 96.28$. Simpler: $1(4.094) + 89 = 93.09$.
step: The two criteria disagree: AIC favors the learner by 1.0, BIC favors the simpler model by 3.2.
step: Weights from AIC: $\Delta = 0, 1.0$, so the raw values are $1$ and $e^{-0.5} = 0.6065$, and the simpler model's weight is $0.6065/1.6065 = 0.378$.
answer: AIC $90.0$ vs $91.0$, BIC $96.28$ vs $93.09$; the simpler model's Akaike weight is $0.378$.

@mistakes
- Comparing criteria computed on different data, or with different numbers of trials, or comparing a criterion across data sets.
- Using the likelihood-ratio test for non-nested models, or for nested models when the null sits on a boundary of the parameter space.
- Reading a small AIC as proof that the model is good: it only says the model is better than the others tried.
- Counting parameters wrongly: every fitted parameter counts, including a lapse rate or a bias, but not a quantity fixed in advance.

```python
import math
from statistics import NormalDist


def lr_test_p(ll0, ll1, df):
    """p-value of the likelihood-ratio statistic for df = 1 or 2."""
    if df not in (1, 2):
        raise ValueError("df must be 1 or 2")
    d = 2 * (ll1 - ll0)
    if d <= 0:
        return 1.0
    if df == 1:
        return 2 * (1 - NormalDist().cdf(math.sqrt(d)))
    return math.exp(-d / 2)
```
hint: Compute $D$ first; the two closed forms are the chi-square upper tail for one and for two degrees of freedom.
solution: A one-degree-of-freedom $\chi^2$ variable is the square of a standard normal, so $P(\chi^2_1 > D) = 2(1 - \Phi(\sqrt{D}))$, and for two degrees of freedom the upper tail is exactly $e^{-D/2}$. A richer model cannot have a lower maximized log-likelihood than a nested one, so $D \le 0$ only arises from imperfect fitting and gives $p = 1$. The raised error for other degrees of freedom says that no closed form is implemented here.

```python
import math


def compare_learners(choices, rewards, alpha_grid, beta_grid, eps_grid):
    """AIC of the best delta-rule softmax fit and the best WSLS fit."""
    def rl_ll(alpha, beta):
        q = [0.5, 0.5]
        total = 0.0
        for c, r in zip(choices, rewards):
            p1 = 1.0 / (1.0 + math.exp(-beta * (q[1] - q[0])))
            total += math.log(p1 if c == 1 else 1.0 - p1)
            q[c] += alpha * (r - q[c])
        return total

    def wsls_ll(eps):
        total = math.log(0.5)
        for i in range(1, len(choices)):
            p_same = 1 - eps if rewards[i - 1] == 1 else eps
            same = choices[i] == choices[i - 1]
            total += math.log(p_same if same else 1 - p_same)
        return total

    best_rl = max(rl_ll(a, b) for a in alpha_grid for b in beta_grid)
    best_wsls = max(wsls_ll(e) for e in eps_grid)
    aic_rl = 2 * 2 - 2 * best_rl
    aic_wsls = 2 * 1 - 2 * best_wsls
    return aic_rl, aic_wsls, ("rl" if aic_rl < aic_wsls else "wsls")
```
hint: Write one inner function for each model's log-likelihood, take the best grid value of each, and convert with the right number of parameters.
solution: The same grid search as in earlier weeks is run for each model, and the AIC puts them on a common scale: 4 minus twice the best log-likelihood for the two-parameter learner and 2 minus twice the best for the one-parameter rule. The second test has choices that follow win-stay lose-shift exactly, so the simpler rule wins despite the learner's greater flexibility.

model:
```python
import math


def rank_by_criterion(fits, n, criterion):
    """Models sorted by AIC or BIC, lowest (best) first."""
    scored = []
    for name, (ll, k) in fits.items():
        if criterion == "aic":
            value = 2 * k - 2 * ll
        else:
            value = k * math.log(n) - 2 * ll
        scored.append((name, value))
    return sorted(scored, key=lambda item: (item[1], item[0]))
```
hint: Compute the chosen criterion for every model, then sort by the value, using the name as the second sort key.
solution: With 50 choices the BIC's penalty per parameter is $\ln 50 = 3.9$, nearly twice the AIC's 2, so the big model's extra two parameters are worth their cost under the AIC but not under the BIC. Sorting by the pair `(value, name)` gives the required tie-break.

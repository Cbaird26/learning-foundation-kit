@article
In a two-armed bandit task you repeatedly choose between two options, each paying off with some hidden probability. You drift toward the option that has paid off recently, but not perfectly, and when the payoffs change you adapt. A model must say how past rewards shape the next choice. The simplest answer is the **delta rule**, the core of the Rescorla–Wagner model (1972) and of temporal-difference learning (Sutton, 1988).

### The delta rule

Each option $i$ has a value $Q_i$, starting at an initial value $Q_0$ (here $0.5$, the midpoint of rewards of 0 or 1). After choosing option $c_t$ on trial $t$ and receiving reward $r_t$, only the chosen option is updated:

$$\delta_t = r_t - Q_{c_t}, \qquad Q_{c_t} \leftarrow Q_{c_t} + \alpha\,\delta_t, \qquad 0 \le \alpha \le 1.$$

The **prediction error** $\delta_t$ is the difference between what happened and what was expected, and the **learning rate** $\alpha$ sets how far each error moves the value. With $\alpha = 1$ the value is just the last reward; with $\alpha$ near 0 it barely moves. The unchosen option keeps its value. Unrolling the rule shows that $Q$ is an exponentially weighted average of past rewards, with weights $\alpha(1-\alpha)^{j}$ for the reward $j$ choices ago. Schultz, Dayan and Montague (1997) proposed that the phasic firing of midbrain dopamine neurons resembles a temporal-difference prediction error; that proposal has strong support, and what these signals encode exactly is still studied and debated.

### The choice rule and the likelihood

Choices come from the softmax of last week's lesson: $p_t(1) = 1/\big(1 + e^{-\beta(Q_1 - Q_0)}\big)$, computed from the values **before** the trial's update. The model has two parameters, $\alpha$ and $\beta$. The likelihood of the data is the product of the probabilities of the actual choices, with values updated by the actual rewards:

$$\log L(\alpha, \beta) = \sum_t \log p_t(c_t).$$

Take twelve trials with choices $0,1,1,1,1,1,1,1,0,1,1,0$ and rewards $0,1,1,1,1,1,0,1,0,0,1,0$. On trial 1 both values are $0.5$, so $p(1) = 0.5$; the choice of 0 is rewarded with 0, so with $\alpha = 0.4$ the update gives $Q_0 = 0.5 + 0.4(0 - 0.5) = 0.3$.

```python
import math

def q_learning_ll(choices, rewards, alpha, beta, q0=0.5):
    q = [q0, q0]
    total = 0.0
    for c, r in zip(choices, rewards):
        p1 = 1.0 / (1.0 + math.exp(-beta * (q[1] - q[0])))
        total += math.log(p1 if c == 1 else 1.0 - p1)
        q[c] += alpha * (r - q[c])
    return total

choices = [0, 1, 1, 1, 1, 1, 1, 1, 0, 1, 1, 0]
rewards = [0, 1, 1, 1, 1, 1, 0, 1, 0, 0, 1, 0]
best = max(((q_learning_ll(choices, rewards, a / 10, b), a / 10, b)
            for a in range(1, 10) for b in range(1, 11)))
print(round(best[0], 4), best[1], best[2])
```

This prints `-6.1533 0.4 3`: on the grid $\alpha \in \{0.1, \dots, 0.9\}$, $\beta \in \{1, \dots, 10\}$, the best fit is $\hat\alpha = 0.4$, $\hat\beta = 3$. A well-chosen $\beta$ matters: at $\alpha = 0.4$, $\beta = 6$ the log-likelihood falls to $-7.2713$, because the learner would then be overconfident on the trials where she switched.

### Extensions and cautions

Common extensions: separate learning rates for positive and negative prediction errors ($\alpha_+$, $\alpha_-$); a perseveration (choice-history) term; a decay of unchosen values. Each adds parameters, and whether they earn their place is a model-comparison question (week 8). A caution: $\alpha$ and $\beta$ can trade off, because a slowly learning but decisive agent can resemble a fast-learning but noisy one over a short run; this is why researchers check parameter recovery (week 12). Parameters estimated from a model are descriptions of behavior under that model, and calling $\alpha$ "the dopamine learning rate" is an interpretation that needs independent evidence.

title: Two delta-rule updates and a choice probability
problem: Both values start at $Q_0 = 0.5$, with $\alpha = 0.4$ and $\beta = 3$. The agent chooses option 1 and gets reward 1, and then chooses option 1 again and gets reward 0. Find the values after each trial and the probability of choosing option 1 on the third trial.
step: Trial 1: $\delta = 1 - 0.5 = 0.5$, so $Q_1 = 0.5 + 0.4 \times 0.5 = 0.70$. $Q_0$ is unchanged at $0.5$.
step: Trial 2: $\delta = 0 - 0.70 = -0.70$, so $Q_1 = 0.70 + 0.4 \times (-0.70) = 0.42$.
step: Trial 3: $Q_1 - Q_0 = 0.42 - 0.50 = -0.08$, so $p(1) = 1/(1 + e^{0.24}) = 0.440$.
answer: $Q_1 = 0.70$ then $0.42$; the probability of choosing option 1 on trial 3 is about $0.440$.

@mistakes
- Updating both options after every choice: in this model only the chosen option's value changes.
- Computing the choice probability after the update instead of before it: the choice on trial $t$ depends on the values left by trial $t-1$.
- Forgetting the initial value $Q_0$: it affects the early trials and should be stated.
- Interpreting a fitted $\alpha$ without checking that the fit is stable: $\alpha$ and $\beta$ can trade off.

model:
```python
def asym_delta_trace(rewards, alpha_pos, alpha_neg, q0):
    """Values after each update with separate rates for gains and losses."""
    q = q0
    out = []
    for r in rewards:
        delta = r - q
        rate = alpha_pos if delta > 0 else alpha_neg
        q += rate * delta
        out.append(q)
    return out
```
hint: Compute the prediction error first, pick the rate from its sign, then update and record the new value.
solution: An optimistic learner has `alpha_pos > alpha_neg` and ends with values biased upward; here the 0.3 and 0.1 rates give a slow, steadily rising trace. With a single rate for both signs the model reduces to the ordinary delta rule.

model:
```python
import math


def fit_dual_alpha(choices, rewards, alpha_grid, beta, q0=0.5):
    """Grid-search fit of separate learning rates for positive and negative errors."""
    def log_lik(a_pos, a_neg):
        q = [q0, q0]
        total = 0.0
        for c, r in zip(choices, rewards):
            p1 = 1.0 / (1.0 + math.exp(-beta * (q[1] - q[0])))
            total += math.log(p1 if c == 1 else 1.0 - p1)
            delta = r - q[c]
            if delta > 0:
                q[c] += a_pos * delta
            elif delta < 0:
                q[c] += a_neg * delta
        return total

    best = None
    for a_pos in alpha_grid:
        for a_neg in alpha_grid:
            ll = log_lik(a_pos, a_neg)
            if best is None or ll > best[2]:
                best = (a_pos, a_neg, ll)
    return best
```
hint: Write an inner function that returns the log-likelihood for one `(alpha_pos, alpha_neg)` pair, choosing the rate by the sign of the prediction error, then keep the best triple over the two nested loops.
solution: The values are recomputed from `q0` for every pair, and the sign of $\delta$ picks the rate. In the second test every reward is 1 and every value is below 1, so only $\alpha_+$ ever acts: the larger $\alpha_+ = 0.9$ raises option 1's value fastest and makes its repeated choice most probable, while every $\alpha_-$ gives the same likelihood and the first, 0.1, wins the tie (a solution that swaps the two rates returns `(0.1, 0.9)` here). In the third test both values start at 1, so the first choice has $p = 0.5$, its error is 0 and nothing changes, and the second choice again has $p = 0.5$: every pair ties at $2\ln 0.5 \approx -1.3863$, and the first pair wins.

model:
```python
import math


def simulate_q_learner(reward_table, us, alpha, beta, q0):
    """Generate choices from a delta-rule softmax learner and supplied uniforms."""
    q = [q0, q0]
    choices = []
    for row, u in zip(reward_table, us):
        p1 = 1.0 / (1.0 + math.exp(-beta * (q[1] - q[0])))
        c = 1 if u < p1 else 0
        choices.append(c)
        q[c] += alpha * (row[c] - q[c])
    return choices, q
```
hint: Draw each choice by comparing the supplied uniform number with `p1`, then update only the chosen option with its reward from the table.
solution: Supplying the uniform numbers makes the stochastic simulation deterministic. With `alpha = 0` the values never move and each choice only depends on `u < 0.5`; with `alpha = 1` and a large `beta` the learner locks onto whichever option last paid its reward.

@quiz self
prompt: A student fits the delta-rule softmax model to a participant and reports $\hat\alpha = 0.4$ and $\hat\beta = 3$, concluding that the participant "has a learning rate of 0.4 in her dopamine system." Evaluate the claim: say what the fitted values do and do not tell us, give one reason the estimates might be unreliable, and say what additional evidence would be needed for the claim about dopamine.
hint: Separate a parameter of a behavioral model from a claim about neurons, and think about how $\alpha$ and $\beta$ can trade off.
solution: The fitted values describe the participant's behavior under one model: how strongly recent rewards shifted her choices ($\alpha$) and how deterministically she followed the learned values ($\beta$). They do not show that the model is right, nor which neural process produced the behavior. Estimates may be unreliable because with few trials $\alpha$ and $\beta$ trade off (a slow, decisive learner and a fast, noisy one can look alike), because the likelihood may be flat, and because a different model (with asymmetric rates, perseveration or Bayesian updating) may fit as well or better. Parameter recovery on simulated data and a comparison with rival models address this. A claim about dopamine needs independent evidence, for instance recordings or imaging of dopamine-related activity whose trial-by-trial size tracks the model's prediction errors, or a manipulation that changes $\alpha$ in the predicted way; even then it would support a link rather than identity.

@article
Pick which of two dot clouds has more dots, as fast as you can. You are faster when the difference is large, slower and less accurate when it is small, and your reaction times (RTs, in ms) are right-skewed: a few responses are much slower than most. Signal detection theory predicts accuracy only. The **drift-diffusion model** (DDM; Ratcliff, 1978) predicts the choice and the entire RT distribution from one mechanism.

### The model

An internal **decision variable** $x$ starts at $x_0$ and accumulates noisy evidence until it reaches one of two boundaries, $+a$ (the upper, here the correct alternative) or $-a$ (the lower). In continuous time,

$$dx = v\,dt + s\,dW,$$

where $v$ is the **drift rate** (evidence quality, higher for easier stimuli), $s$ is the **noise** standard deviation per square-root second, and $dW$ is a Wiener increment. The parameters are the boundary separation $2a$ (caution), the starting point $x_0$ (a prior bias if $x_0 \neq 0$), and a **non-decision time** $t_0$ for encoding and motor execution. The predicted RT is $t_0$ plus the **decision time** (the time to reach a boundary). A response at $+a$ is a correct response if $v > 0$.

### Simulation with Euler steps

In a step of length $\Delta t$ (seconds) the variable changes by

$$x_{k} = x_{k-1} + v\,\Delta t + s\sqrt{\Delta t}\;\xi_k, \qquad \xi_k \sim \mathcal{N}(0, 1),$$

and the decision is made at the first step $k$ with $x_k \ge a$ or $x_k \le -a$, at decision time $k\,\Delta t$. In the code the noise values $\xi_k$ are supplied as a list, so the run is deterministic and testable.

```python
import math

def simulate_ddm(noise, v, a, s, dt):
    """(choice, decision time in s); choice 1 at +a, 0 at -a; None if no decision."""
    x = 0.0
    for k, xi in enumerate(noise, start=1):
        x += v * dt + s * math.sqrt(dt) * xi
        if x >= a:
            return 1, round(k * dt, 10)
        if x <= -a:
            return 0, round(k * dt, 10)
    return None

noise = [0.5, -0.3, -1.2, 0.2, -0.8, 0.9, 0.4, 0.6, -0.1, 0.6, 0.7, 0.3]
print(simulate_ddm(noise, 2.0, 1.0, 1.0, 0.1))
```

With $v = 2$, $a = 1$, $s = 1$ and $\Delta t = 0.1$ s, the variable takes the values $0.358, 0.463, 0.284, 0.547, 0.494, 0.979, 1.305$ over the first seven steps, so the program prints `(1, 0.7)`: the upper boundary is crossed at step 7, a decision time of 0.7 s. Euler steps only look at the variable at the end of each step, so a path that crosses a boundary and comes back inside within a step is missed; a small $\Delta t$ (such as 0.001 s) reduces this error.

### Closed-form predictions

For a Wiener process with constant drift $v \ne 0$, noise $s$, boundaries $\pm a$ and an **unbiased start** $x_0 = 0$ (and no across-trial variability in any parameter), the probability of the upper boundary and the mean decision time are

$$P(\text{upper}) = \frac{1}{1 + e^{-2va/s^2}}, \qquad \mathbb{E}[\text{DT}] = \frac{a}{v}\tanh\!\Big(\frac{av}{s^2}\Big).$$

For $v = 0$ the limits are $P = 0.5$ and $\mathbb{E}[\text{DT}] = a^2/s^2$. With $v = a = s = 1$, $P = 0.881$ and $\mathbb{E}[\text{DT}] = \tanh 1 = 0.762$ s. A simulation of 4,000 trials with $\Delta t = 0.001$ s gave about $0.885$ and $0.78$ s, in line with these values. Predicted RT is $t_0 + \mathbb{E}[\text{DT}]$.

### Why RTs are skewed

The time to reach a bound is the first passage time of a random walk with drift. Most paths drift steadily to a boundary, but some wander near zero for a long time, which gives a long right tail. This skew is a striking successful prediction of the model: it arises without any parameter chosen to produce it. How far the model is a literal account of neural processing is debated; neurons in parietal and frontal areas of monkeys show activity that ramps up during decisions in a way consistent with accumulation, but the interpretation, and whether the accumulators are simple integrators, remain under discussion, and competing models (race models, leaky competing accumulators) can mimic the DDM in many designs.

title: Accuracy and mean decision time
problem: A decision has $v = 0.8$ per second, $a = 1.2$, $s = 1$ and an unbiased start. Predict the accuracy and the mean decision time.
step: Compute $2va/s^2 = 2 \times 0.8 \times 1.2 = 1.92$.
step: Accuracy: $1/(1 + e^{-1.92}) = 1/(1 + 0.1466) = 0.8721$.
step: Compute $av/s^2 = 0.96$ and $\tanh 0.96 = 0.7443$.
step: Mean decision time: $(a/v)\tanh(av/s^2) = 1.5 \times 0.7443 = 1.116$ s.
answer: Accuracy $0.872$ and mean decision time $1.116$ s (before adding $t_0$).

@mistakes
- Applying the closed-form formulas to a biased starting point or with across-trial variability: they hold only for $x_0 = 0$ and constant parameters.
- Forgetting the $\sqrt{\Delta t}$ in the noise term: the noise variance grows in proportion to time, so its standard deviation per step is $s\sqrt{\Delta t}$.
- Using milliseconds for $\Delta t$ while $v$ and $s$ are per second: keep one time unit throughout, and convert to ms only at the end.
- Reading the decision time as the RT: the RT includes the non-decision time $t_0$.

model:
```python
import math


def ddm_deadline(noise, v, a, s, dt, x0, t0, deadline):
    """Euler DDM from start x0 with non-decision time and a response deadline."""
    x = x0
    for k, xi in enumerate(noise, start=1):
        x += v * dt + s * math.sqrt(dt) * xi
        if x >= a or x <= -a:
            rt = t0 + k * dt
            if rt > deadline:
                return None, None
            return (1 if x >= a else 0), rt
    return None, None
```
hint: Start the loop at `x0`, add the Euler increment, test both boundaries, and compare `t0 + k * dt` with the deadline only when a boundary has been reached.
solution: The starting point shifts how far each boundary is: a start of $0.5$ is closer to the upper boundary, so the decision comes sooner (RT 0.7 s instead of 1.0 s), and a start of $-0.95$ is nearly at the lower boundary yet this noise sequence still carries the variable to the upper one, later. The deadline turns slow responses into misses.

```python
import math


def ddm_summary(trials, v, a, s, dt):
    """Upper-boundary proportion, mean decision time and undecided count."""
    upper, times, undecided = 0, [], 0
    for noise in trials:
        x, done = 0.0, False
        for k, xi in enumerate(noise, start=1):
            x += v * dt + s * math.sqrt(dt) * xi
            if x >= a or x <= -a:
                upper += 1 if x >= a else 0
                times.append(k * dt)
                done = True
                break
        if not done:
            undecided += 1
    if not times:
        return None, None, undecided
    total = 0.0
    for t in times:
        total += t
    return upper / len(times), total / len(times), undecided
```
hint: Loop over trials, run the Euler update until a boundary is crossed, and keep three tallies: upper-boundary count, decision times and undecided trials.
solution: Undecided trials are counted separately and excluded from both averages, because their decision time is unknown. Raising the boundary from $0.7$ to $1.0$ makes decisions slower (mean 0.725 s) and leaves one trial undecided within the 14 supplied noise values.

model:
```python
import math


def rt_quantile(rts, q):
    """q-quantile of rts by linear interpolation between order statistics."""
    data = sorted(rts)
    h = (len(data) - 1) * q
    lo = int(math.floor(h))
    hi = min(lo + 1, len(data) - 1)
    return data[lo] + (h - lo) * (data[hi] - data[lo])
```
hint: With five values and `q = 0.9`, `h = 3.6`, so interpolate 60% of the way from the fourth to the fifth sorted value; guard the last index when `q = 1`.
solution: Sorting, locating `h`, and interpolating gives $500 + 0.6 \times (700 - 500) = 620$. The top index must be clipped so that `q = 1` or a single value does not read beyond the list. Comparing the 0.1, 0.5 and 0.9 quantiles shows the right skew that the DDM predicts: the upper quantile is stretched far more than the lower.

@quiz self
prompt: A student says "the drift-diffusion model explains skewed RTs, so the brain must integrate noisy evidence." Evaluate this inference. Explain how the model produces right skew, why that success does not by itself show the mechanism, and what kind of evidence beyond RT distributions would strengthen the claim.
hint: Think about model mimicry and what other measurements would distinguish accumulation from alternatives.
solution: In the DDM the decision time is the first passage time of a random walk with drift: most paths drift quickly to a bound, while some linger near the start, producing a long right tail without any extra parameter. This is a real, quantitative success. It does not by itself show the mechanism, because other models, such as race models, leaky competing accumulators or models with variable thresholds, can also generate right-skewed RTs and accurate choice proportions, so the data may be mimicked. Stronger evidence would include manipulations that the model predicts in detail (for example, how the whole RT distributions for correct and error responses change with speed or accuracy instructions), neural data such as ramping activity whose slope tracks drift and whose level at the decision tracks the bound, and causal tests that perturb the putative accumulator. Even then, the claim concerns the algorithmic level and says little about how neurons implement it.

@review
This course followed an fMRI or EEG data set from the physics of the signal to the claims that can be made from it.

**Week by week**
- **1. BOLD.** Larmor frequency $f = \bar\gamma B_0$; signal $S = S_0 e^{-\mathrm{TE}/T_2^*}$; BOLD rises because flow overshoots oxygen use, lowering deoxyhemoglobin and lengthening $T_2^*$; percent signal change $100(S - S_0)/S_0$.
- **2. HRF.** The double-gamma response peaks near 5 s, with an undershoot; the predicted series is the convolution $y[n] = \sum_k x[n-k]h[k]$, assuming linearity and time invariance.
- **3. Designs.** Block designs have high detection efficiency; jittered event-related designs estimate response shape and allow sorting trials; efficiency is $1/\mathbf{c}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{c}^\top$.
- **4. Preprocessing.** Framewise displacement, slice-timing interpolation, registration by a cost function, Gaussian smoothing with $\sigma = \text{FWHM}/2.3548$.
- **5. GLM.** $\hat{\boldsymbol\beta} = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{y}$, $\hat\sigma^2 = \text{RSS}/(n - p)$, $R^2 = 1 - \text{RSS}/\text{TSS}$.
- **6. Contrasts.** $t = \mathbf{c}\hat{\boldsymbol\beta}/\sqrt{\hat\sigma^2\,\mathbf{c}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{c}^\top}$ with $n - p$ degrees of freedom; group t on subject effects with $N - 1$.
- **7. Multiple comparisons.** Bonferroni $\alpha/m$; Benjamini–Hochberg step-up; clusters need a strict forming threshold or permutation; the maximum-statistic permutation threshold.
- **8. ROIs.** Select and test on independent data (split, leave-one-run-out, localizer).
- **9. MVPA.** Nearest centroid, leave-one-run-out accuracy, binomial p value, dissimilarity $1 - r$; decodable is not used.
- **10. Connectivity.** Correlation, Fisher $z = \operatorname{arctanh} r$, partial correlation, confounds; not causal.
- **11. ERPs.** Epoch, baseline-correct, reject, average; noise falls as $1/\sqrt{N}$; latency = start + index $\times 1000/f_s$.
- **12. Time–frequency and sources.** Amplitude $2|X|/N$, resolution $f_s/N$, Nyquist $f_s/2$; evoked versus induced; the inverse problem and the minimum-norm estimate.

**Common errors**
- Dividing by $n$ instead of $n - p$ for the noise variance, or by $n$ instead of $n - 1$ for a standard deviation.
- Reporting a $t$ or p value without an effect size and its units.
- Concluding that A exceeds B from "A significant, B not".
- Selecting voxels, windows or electrodes in the data used to test them.
- Treating correlation or decoding accuracy as proof of mechanism.

model:
```python
import math


def task_t(onsets, n_scans, h, y):
    """t statistic of the convolved task regressor in y = b0 + b1 * r."""
    x = [0.0] * n_scans
    for o in onsets:
        x[o] = 1.0
    r = []
    for i in range(n_scans):
        r.append(sum(x[i - k] * h[k] for k in range(len(h)) if i - k >= 0))
    rm = sum(r) / n_scans
    ym = sum(y) / n_scans
    sxx = sum((v - rm) ** 2 for v in r)
    sxy = sum((a - rm) * (b - ym) for a, b in zip(r, y))
    syy = sum((b - ym) ** 2 for b in y)
    b1 = sxy / sxx
    rss = syy - b1 * sxy
    sigma2 = rss / (n_scans - 2)
    return b1 / math.sqrt(sigma2 / sxx)
```
hint: Build the regressor first, then use the sums of squares; the t statistic is the slope divided by its standard error $\sqrt{\hat\sigma^2/S_{xx}}$.
solution: This chains lesson 2 (convolution), lesson 5 (least squares with a constant) and lesson 6 (the t statistic). With a constant in the model, the slope and the residual sum of squares can be computed from the centered sums. Negating the data flips the sign of $b_1$ and so of $t$, which the last test checks.

@exam self
prompt: A lab reports: "We scanned 20 participants. In each, we selected the 50 voxels in the fusiform region most responsive to faces versus houses, then found that these voxels responded significantly more to faces than to houses ($p < 0.001$, uncorrected; peak effect 2.1% signal change). Because the region responds to faces, activity there shows that participants were thinking about identity." Write a critique of the analysis and the conclusion, using ideas from at least four different weeks of the course, and say what analysis you would run instead.
hint: Look for a selection step, an uncorrected threshold, an effect size, and a reverse inference.
solution: Four problems. First (week 8), the voxels were selected by the faces-versus-houses contrast and then tested on the same contrast, which is circular: the selected voxels have the largest noise in the favorable direction, so the test is guaranteed to look significant and the 2.1% effect is inflated. The fix is to define the region with independent data (a separate localizer run, an anatomical mask, or leave-one-run-out selection) and test on held-out data, reporting the effect size from the independent data. Second (week 7), the threshold is uncorrected: if the 50 voxels were found in a whole-brain search, thousands of tests were made, and an uncorrected $p < 0.001$ would give tens of false positives in a whole-brain null map; a familywise or false-discovery correction, or a permutation threshold, is needed for any claim of a location. Third (weeks 5 and 6), the claim concerns a difference, so it must be tested with the contrast faces minus houses at the group level (a random-effects test across the 20 participants with 19 degrees of freedom) rather than the effects against baseline, and the voxel-wise or ROI test must come with an effect and a confidence interval, with the design and the HRF model stated. Fourth (week 1 and the logic of inference), the conclusion is a reverse inference: the BOLD increase is an indirect vascular signal, and a region that responds more to faces may also be engaged by attention, familiarity or visual features, so its activity does not show that participants were thinking about identity; a stronger design would manipulate the cognitive process, include controls for low-level stimulus differences, and, if the claim is about information, use an independently validated decoding or encoding analysis. A better analysis: define a face-selective region in each person from a separate localizer, extract percent signal change in the main runs, test faces minus houses across participants with a one-sample t test and report the mean effect with its interval, and correct across all regions examined.

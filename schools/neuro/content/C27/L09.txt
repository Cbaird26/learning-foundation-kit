@article
Two regions can respond equally strongly, on average, to faces and to houses and still tell the stimuli apart: some voxels prefer faces and others houses, and the average hides it. A GLM at each voxel, or an ROI mean, would find no difference. **Multivariate pattern analysis** (MVPA) looks at the pattern of responses across many voxels at once. Haxby and colleagues (2001) showed that categories of objects could be told apart from distributed patterns of responses in ventral temporal cortex, even excluding the voxels that preferred a category most.

### Decoding

A **pattern** is a vector with one entry per voxel, for example the fitted effect of one condition in one run, or the response on one trial. **Decoding** trains a classifier to predict the condition from the pattern and measures how often it is right on patterns it has not seen. The simplest classifier is the **nearest centroid** (or nearest mean): average the training patterns of each class to get a centroid, and assign a new pattern to the class whose centroid is closest in squared Euclidean distance. Correlation-based variants compare patterns by their correlation instead, which ignores the overall level.

### Cross-validation

A classifier will fit its training data too well, so accuracy must be measured on held-out data. In fMRI the held-out unit should be a whole **run**, because trials within a run are correlated through drift and slow noise. In **leave-one-run-out cross-validation**, each run takes a turn as the test set while the others train the classifier; the accuracy is the fraction of all test patterns classified correctly. Anything chosen from the data, such as which voxels to use, must be chosen inside the training set only (the same logic as in the last lesson).

Consider four voxels and three runs, with one pattern per condition per run, in percent-signal-change-like units:

| run | condition A pattern | condition B pattern |
|---|---|---|
| 1 | (2.0, 1.0, 0.0, 1.0) | (0.0, 1.0, 2.0, 1.0) |
| 2 | (1.5, 1.5, 0.5, 0.5) | (1.5, 1.0, 0.5, 1.0) |
| 3 | (2.5, 0.5, 0.0, 1.5) | (0.5, 1.5, 2.5, 0.0) |

Hold out run 2. The training centroids come from runs 1 and 3: $A = (2.25, 0.75, 0, 1.25)$ and $B = (0.25, 1.25, 2.25, 0.5)$. The test pattern B$_2 = (1.5, 1.0, 0.5, 1.0)$ has squared distance $0.9375$ to $A$ and $4.9375$ to $B$, so it is wrongly labeled A. Over all three folds, five of the six test patterns are correct, an accuracy of $5/6 = 83.3\%$. Chance for two balanced classes is 50%.

### Is the accuracy above chance?

If the classifier has no information, each test pattern is correct with probability $1/2$ (two classes), so the number correct out of $N$ follows a binomial distribution. The one-sided p value for $k$ correct is $P(X \ge k) = \sum_{j \ge k}\binom{N}{j}/2^N$. For example, 14 correct out of 16 has $p = (120 + 16 + 1)/65536 = 0.0021$. Cross-validated patterns are not completely independent, so the binomial p value is only approximate; a more robust approach is to compute accuracy within each participant and test the accuracies against chance across participants, or to use permutation of the labels.

### Representational similarity

Decoding says only whether classes can be separated. **Representational similarity analysis** (Kriegeskorte, Mur and Bandettini, 2008) describes the whole geometry. For each pair of conditions it computes a **dissimilarity**, commonly $1 - r$ where $r$ is the correlation between their patterns, and arranges them in a square, symmetric **representational dissimilarity matrix** (RDM) with zeros on the diagonal. The RDM from a brain region can be compared with the RDM predicted by a model, such as the similarity of the stimuli's visual features or of a deep network's responses.

### What a decoding result means

Above-chance decoding shows that the region's activity pattern *contains information* that distinguishes the conditions. It does not show that the brain uses that information, that the information is the one you intended, or that the region is the only one that carries it. A decoder can also exploit confounds: if the two conditions differ in difficulty, eye movements or arousal, the pattern may reflect those. Also, a mean difference between conditions is itself decodable, so decoding is not automatically evidence of a fine-grained code. And at chance, the information may be present at a scale or in a form the method does not capture.

@mistakes
- Training and testing on the same data, or splitting trials of the same run between training and test sets. The accuracy then measures how well the classifier memorized, not what it can generalize.
- Selecting voxels using all the data before cross-validation. The selection has already seen the test labels.
- Reading above-chance decoding as proof that the region represents the information in the way the experimenter intended, or that the brain reads it out.
- Using the wrong chance level: it is 1 over the number of classes only when classes are balanced; with unequal numbers the majority-class rate is higher.

model:
```python
def nearest_centroid(train_X, train_y, x):
    """Label of the class centroid closest to the pattern x."""
    best_label, best_dist = None, None
    for label in sorted(set(train_y)):
        rows = [p for p, y in zip(train_X, train_y) if y == label]
        centroid = [sum(p[i] for p in rows) / len(rows) for i in range(len(x))]
        dist = sum((a - b) ** 2 for a, b in zip(x, centroid))
        if best_dist is None or dist < best_dist:
            best_label, best_dist = label, dist
    return best_label
```
hint: Loop over the sorted set of labels, build each centroid from the matching rows, and keep the label with the strictly smallest distance.
solution: Looping over sorted labels and updating only on a strictly smaller distance gives the required tie-breaking. The last test has two training patterns for one label and one for the other: the centroid of `n` is $(0.5, 0.5)$, at squared distance $60.5$ from $(6, 6)$, while the single pattern of `m` is at squared distance $32$, so `m` wins.

```python
def cv_accuracy(patterns, labels, runs):
    """Leave-one-run-out accuracy of a nearest-centroid classifier."""
    correct = 0
    for held in sorted(set(runs)):
        train = [(p, y) for p, y, r in zip(patterns, labels, runs) if r != held]
        names = sorted(set(y for _, y in train))
        cents = {}
        for name in names:
            rows = [p for p, y in train if y == name]
            cents[name] = [sum(p[i] for p in rows) / len(rows)
                           for i in range(len(rows[0]))]
        for p, y, r in zip(patterns, labels, runs):
            if r != held:
                continue
            best, best_d = None, None
            for name in names:
                d = sum((a - b) ** 2 for a, b in zip(p, cents[name]))
                if best_d is None or d < best_d:
                    best, best_d = name, d
            correct += best == y
    return correct / len(patterns)
```
hint: Inside a loop over runs, build the training centroids from the other runs, then classify each pattern of the held-out run and count the hits.
solution: Each run is held out once, the centroids never include the test patterns, and the accuracy is the total number of hits over the total number of patterns. In the third test the labels in run 2 are swapped relative to run 1, so every held-out pattern is classified as the opposite label and the accuracy is 0, below chance, which is possible when the training and test data disagree.

model:
```python
import math


def rdm(patterns):
    """Matrix of 1 - correlation between all pairs of patterns."""
    n = len(patterns)
    k = len(patterns[0])
    cent = []
    for p in patterns:
        mean = sum(p) / k
        cent.append([v - mean for v in p])
    out = [[0.0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            if i == j:
                continue
            si = sum(v * v for v in cent[i])
            sj = sum(v * v for v in cent[j])
            if si == 0 or sj == 0:
                out[i][j] = 1.0
                continue
            r = sum(a * b for a, b in zip(cent[i], cent[j])) / math.sqrt(si * sj)
            out[i][j] = 1.0 - r
    return out
```
hint: Center each pattern, then compute the correlation of each pair from the centered vectors, guarding against zero variance.
solution: The dissimilarity is computed for every ordered pair, so the matrix is symmetric by construction, with zeros on the diagonal. Three mutually orthogonal one-hot patterns each have correlation $-1/2$ with the others, so their dissimilarities are $1.5$, not $1$, because correlation removes each pattern's mean.

@quiz self
prompt: A lab trains a classifier to distinguish two visual categories from voxel patterns in a region and reports 62% accuracy (chance 50%, p = 0.01 by a binomial test). A reviewer asks whether this shows that the region represents the categories. Write the reasons for caution and two additional analyses that would address them.
hint: Think of what else differs between the categories, and of how the p value was computed.
solution: The result shows that the pattern contains some information that separates the categories in these data; it does not show that the region represents the categories in a way the brain uses. The categories may differ in low-level features (contrast, spatial frequency), in difficulty, in the eye movements they provoke or in attention, and a decoder will use whichever difference is present, so the information may concern a confound rather than the category. A binomial test also assumes independent test patterns, which cross-validated trials from the same runs are not, so p may be too small; and 62% is modest, with the effect size dependent on the number of voxels and trials.

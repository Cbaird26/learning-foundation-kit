@article
A whole-brain map asks "where?" for 50,000 voxels, and pays for it with a severe correction. If you already know which region matters, you can ask a sharper question in one place: how large is the effect in the amygdala, or in the region that responds to faces? That is a **region-of-interest** (ROI) analysis. It has high power because it makes few tests. It also hides a trap that has produced many inflated results: choosing the region with the same data you then use to measure it.

### Defining and using an ROI

An ROI is a set of voxels, written as a **mask** with 1 inside the region and 0 outside. There are three common ways to define one.

- **Anatomical**: from an atlas or from the person's own anatomical image (for example the hippocampus). It is independent of the functional data, but individual anatomy varies, and the function may occupy only part of the structure.
- **Functional localizer**: voxels that respond to a contrast in a separate scan, such as faces versus objects in a localizer run, defined in each person.
- **From other studies**: coordinates or maps from previous work.

The ROI summary is usually the average over its voxels, either of the time series (giving one series to analyze with the GLM, so only one test) or of the fitted effect, expressed in percent signal change. Across participants, the ROI effects are then tested with a one-sample or paired t test.

### Circular analysis

Suppose that no voxel carries any true effect, and the measured value at each voxel is noise. Select the voxels with the largest values and average them: the average is large, because you picked the largest noise. Test that average on the same data and you will find an "effect". This is **circular analysis**, also called **double dipping**: the selection criterion and the test statistic share the same noise (Kriegeskorte and colleagues, 2009).

A small invented example. Eight voxels each have an effect estimate (contrast A minus B, in percent signal change) from run 1 and from run 2, and there is no real effect: the numbers are noise.

| voxel | run 1 | run 2 |
|---|---|---|
| 1 | 0.9 | −0.4 |
| 2 | −0.3 | 0.5 |
| 3 | 1.1 | 0.2 |
| 4 | 0.4 | −0.7 |
| 5 | −0.8 | 0.6 |
| 6 | 0.2 | −0.1 |
| 7 | 1.3 | −0.9 |
| 8 | −0.5 | 0.3 |

The mean over all eight voxels is $0.29$ in run 1 and $-0.06$ in run 2. Now select the three voxels with the largest run-1 effects (voxels 7, 3 and 1). Their run-1 mean is $(1.3 + 1.1 + 0.9)/3 = 1.10$, an apparently strong effect. But in run 2, which did not take part in the selection, the same three voxels average $(-0.9 + 0.2 - 0.4)/3 = -0.37$. The strong effect in run 1 was produced by the selection. When there is a true effect, the same selection inflates it: the selected voxels are those where the noise happened to add to the effect, so the effect is overestimated in the data used for selection and regresses toward the truth in independent data.

### Avoiding circularity

The rule is that the data used to select must be independent of the data used to test, under the null hypothesis.

- **Independent data**: select in one set of runs (or one localizer) and test in another.
- **Cross-validation**: leave one run out, select voxels on the remaining runs, test on the held-out run, and average over the folds.
- **Orthogonal contrasts**: select on a contrast that is independent of the one tested (for example, select on A plus B, test A minus B, when the design is balanced and the noise is independent and equal).
- **Report the selection**: any analysis that chooses voxels from the data should say so, and describe the selection step in the methods.

Circularity also arises in less obvious ways: selecting voxels by their correlation with behavior and then reporting the correlation of those voxels with behavior; choosing the best time window or the best electrode and then testing it in the same data; or reporting peak coordinates of a thresholded map as if they were an unbiased estimate of effect size. Whole-brain maps themselves are not circular; a plot of the values in the significant voxels is, as a measure of effect size.

def top_k(values, k):

problem: Five voxels have effect estimates $[1.2,\ 0.3,\ -0.5,\ 0.8,\ -0.1]$ in the localizer run and $[0.4,\ 0.0,\ 0.6,\ -0.2,\ 0.1]$ in the test run. Select the top two voxels by the localizer run and compare the mean effect of the selection in the two runs.

step: Their mean in the localizer run is $(1.2 + 0.8)/2 = 1.0$.
step: Their values in the test run are $0.4$ and $-0.2$, with mean $0.1$.
step: The drop from 1.0 to 0.1 shows the bias in the selecting run. The test-run value is the fair estimate.
answer: The selected voxels average $1.0$ in the localizer run but only $0.1$ in the independent test run.

@mistakes
- Selecting voxels by a contrast and reporting the size of that same contrast in the selected voxels as if it were an independent effect size.
- Believing that a different statistical threshold removes the problem. Circularity is about the shared noise, not the threshold.
- Defining an ROI from the group's data and then testing the same group, when the ROI came from the effect being tested.
- Using a region defined by the peak of one contrast as an unbiased estimate of that contrast in a new sample. The new sample's effect will usually be smaller.

```python
def roi_mean_series(data, mask):
    """Mean time series over the voxels selected by the mask."""
    chosen = [series for series, m in zip(data, mask) if m == 1]
    if not chosen:
        return []
    n_scans = len(chosen[0])
    return [sum(s[t] for s in chosen) / len(chosen) for t in range(n_scans)]
```
hint: First keep only the voxels whose mask value is 1; if none remain, return an empty list; otherwise average across voxels at each scan.
solution: Filter the voxels with the mask, then for each scan average over the chosen voxels. Averaging first and fitting the model once gives one test for the ROI, instead of one test per voxel. The empty mask needs its own return, since the mean of nothing is undefined.

```python
def select_and_test(sel_vals, test_vals, k):
    """Mean effect of the top-k voxels in the selecting and testing data."""
    order = sorted(range(len(sel_vals)), key=lambda i: (-sel_vals[i], i))
    chosen = order[:k]
    sel_mean = sum(sel_vals[i] for i in chosen) / k
    test_mean = sum(test_vals[i] for i in chosen) / k
    return sel_mean, test_mean
```
hint: Sort the voxel indices by `sel_vals` descending (index ascending on ties), take the first `k`, and average both lists over those indices.
solution: The selection uses only `sel_vals`, so `test_vals` is an unbiased view of the chosen voxels. If both lists were noise, the first mean would be large and positive while the second would stay near zero, which is the bias that circular analysis hides.

model:
```python
def leave_one_run_out(runs, k):
    """Cross-validated mean effect of the top-k voxels."""
    n_runs = len(runs)
    n_vox = len(runs[0])
    total = 0.0
    for held in range(n_runs):
        others = [r for i, r in enumerate(runs) if i != held]
        avg = [sum(r[v] for r in others) / len(others) for v in range(n_vox)]
        chosen = sorted(range(n_vox), key=lambda v: (-avg[v], v))[:k]
        total += sum(runs[held][v] for v in chosen) / k
    return total / n_runs
```
hint: Inside a loop over the held-out run, build the average of the other runs, pick the top `k` voxel indices, and average the held-out run at those indices.
solution: Selection never sees the held-out run, so the estimate is not biased by shared noise. In the noise data, the cross-validated effect is negative, while selecting and testing on the same run would give positive values. The last test selects every voxel, so the result is just the mean of all values, $2.5$.

@quiz self
prompt: A paper reports that voxels in a region were selected because their activation correlated with participants' anxiety scores ($p < 0.001$), and then reports that the activation in these voxels correlated with anxiety at $r = 0.88$ across 16 participants. Explain what is wrong with the second result, estimate its likely direction of error, and describe an analysis that would give a fair estimate.
hint: The selection used the same correlation that is later reported.
solution: The selection step chose the voxels with the strongest correlation with anxiety in these 16 people, so the reported correlation in them is high by construction, even if the true correlation is modest, and with a whole-brain search it can be high even when there is no true effect. The error is an overestimate, and it grows with the number of voxels searched and shrinks with sample size. A fair estimate needs data not used for selection: define the region in a separate set of participants (or from an independent localizer or an atlas), or use leave-one-participant-out cross-validation, where the voxels are selected from 15 participants and the correlation computed in the held-out person, repeated across participants, or report the whole-brain map without a separate effect-size plot. The whole-brain map itself is a fair test of where a relation exists after correction for multiple comparisons; the plotted $r$ is not an unbiased effect size.
rubric: Identifies the shared selection and test as circular and states that the reported correlation is inflated.
rubric: Gives the direction of the error and what increases it, such as the number of voxels searched.
rubric: Proposes an independent-data or cross-validated analysis.

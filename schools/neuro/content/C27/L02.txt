@article
Show a person a flash of light for a fraction of a second and neurons in visual cortex respond within tens of milliseconds. The BOLD signal in the same patch does almost nothing for about two seconds, climbs to a maximum around five seconds after the flash, and then sinks slightly *below* baseline for ten seconds or more before recovering. The vascular system is a slow filter between neural activity and the signal. To predict what a voxel should do when a task has many events, we need a description of that filter. This is the **hemodynamic response function** (HRF).

### The HRF as an impulse response

Suppose the BOLD response to one brief event at time 0 is a function $h(t)$, in units of signal change per event. If the system is **linear and time-invariant**, two assumptions that we shall examine below, then the response to any sequence of events is the sum of shifted, scaled copies of $h$. Writing $x(t)$ for the neural input (for example 1 at each event and 0 otherwise), the predicted signal is the **convolution**

$$y(t) = (x * h)(t) = \int_0^{t} x(s)\, h(t - s)\, ds, \qquad y[n] = \sum_{k=0}^{n} x[n-k]\, h[k]$$

where the second form is for samples taken once per TR, with $h[k]$ the HRF sampled at $t = k \cdot \mathrm{TR}$.

### The double-gamma HRF used in this course

A common model of the HRF is the difference of two gamma densities, one for the positive peak and one for the undershoot. With $t$ in seconds,

$$h(t) = \frac{t^{5} e^{-t}}{5!} - \frac{1}{6}\,\frac{t^{15} e^{-t}}{15!}, \qquad t \ge 0.$$

The first term is a gamma density with shape 6 and scale 1 s; its maximum is at $t = 5$ s. The second is a gamma density with shape 16, scaled by $1/6$, and produces the undershoot. This is a standard canonical form; researchers also use other parameter values, and the true shape varies across people and brain regions. Sampled every 2 s, the formula gives:

| $t$ (s) | 0 | 2 | 4 | 6 | 8 | 10 | 12 | 14 | 16 |
|---|---|---|---|---|---|---|---|---|---|
| $h(t)$ | 0 | 0.036 | 0.156 | 0.160 | 0.090 | 0.032 | 0.001 | −0.013 | −0.016 |

Check the table entries by evaluating the formula yourself. A finer grid shows the peak at $t = 5.00$ s (height 0.175) and the minimum of the undershoot near $t = 15.75$ s (height $-0.016$).

### Convolution by hand

Sample the HRF at TR $= 2$ s and round to three decimals: $h = [0,\ 0.036,\ 0.156,\ 0.160,\ 0.090,\ 0.032,\ 0.001,\ -0.013,\ -0.016,\ -0.013]$ (the first ten samples, $t = 0$ to $18$ s). Take two events, at scans 0 and 3. Then $x = [1, 0, 0, 1, 0, 0, \dots]$ and

$$y[n] = h[n] + h[n-3].$$

The result for $n = 0, \dots, 9$ is $[0,\ 0.036,\ 0.156,\ 0.160,\ 0.126,\ 0.188,\ 0.161,\ 0.077,\ 0.016,\ -0.012]$. The second response, shifted by three scans (6 s), lands on the falling flank of the first, so the two overlap and add; the maximum of $y$ (0.188) exceeds that of a single response (0.160 at this sampling).

For a task that lasts several seconds, $x$ is a **boxcar**: 1 while the task is on, 0 otherwise. Convolving a boxcar with $h$ gives a smooth, delayed, rounded copy of it, which is exactly the regressor we will use in the general linear model.

### When the model is wrong

Linearity and time-invariance hold approximately for events spaced more than a few seconds apart, but not exactly. For events very close together (under about 2 seconds) the measured response is smaller than the sum of the single-event responses, so the linear model over-predicts. The HRF also differs between voxels, between people, and with caffeine, age and disease. A common remedy is to add the HRF's time derivative as a second regressor so the fit can absorb a small shift in the latency of the response.

### In code

```python
import math

def hrf(t):
    """Double-gamma HRF, t in seconds, returned in arbitrary BOLD units."""
    if t <= 0:
        return 0.0
    first = t ** 5 * math.exp(-t) / math.factorial(5)
    second = t ** 15 * math.exp(-t) / math.factorial(15) / 6
    return first - second

h = [hrf(2 * k) for k in range(5)]
print([round(v, 3) for v in h])
```

This prints `[0.0, 0.036, 0.156, 0.16, 0.09]`. In NumPy, researchers write the convolution as `np.convolve(x, h)[:len(x)]`; here you will write it yourself.

title: The response at one scan from two events
problem: Using the sampled HRF $h = [0,\ 0.036,\ 0.156,\ 0.160,\ 0.090,\ 0.032]$ at TR $=2$ s, events occur at scans 1 and 2 (so $x[1] = x[2] = 1$ and all other $x$ are 0). What is the predicted signal $y[5]$?
step: Write the sum: $y[5] = \sum_k x[5-k]\,h[k]$. Only $x[1]$ and $x[2]$ are nonzero.
step: The term from $x[1]$ has $5 - k = 1$, so $k = 4$ and contributes $h[4] = 0.090$.
step: The term from $x[2]$ has $5 - k = 2$, so $k = 3$ and contributes $h[3] = 0.160$.
step: Add: $y[5] = 0.090 + 0.160 = 0.250$.
answer: $y[5] = 0.250$ in the same signal-change units as $h$.

@mistakes
- Treating the HRF as the neural response. It is the vascular filter: the BOLD signal peaks about five seconds after a brief event, long after the neural activity is over.
- Forgetting to truncate or to align the convolution: the predicted series should have the same length as the scans, with the response to an event starting at that event's scan and not before it.
- Assuming that the sum of responses always applies. For events closer than a couple of seconds, the real response saturates and the linear model over-predicts.

model:
```python
def convolve(x, h):
    """First len(x) samples of the convolution of x with h."""
    y = []
    for n in range(len(x)):
        total = 0.0
        for k in range(len(h)):
            if 0 <= n - k < len(x):
                total += x[n - k] * h[k]
        y.append(total)
    return y
```
hint: For each output index `n`, add up `x[n - k] * h[k]` over every `k` for which `n - k` is a valid index of `x`.
solution: Loop over output samples, and for each one sum over the response lags, skipping lags that would reach before the start of the series. The output is truncated to the length of `x`, so a long response is cut off. In the last test a boxcar of length three convolved with a difference kernel leaves only the edge at the start.

```python
def convolve(x, h):
    y = []
    for n in range(len(x)):
        total = 0.0
        for k in range(len(h)):
            if 0 <= n - k < len(x):
                total += x[n - k] * h[k]
        y.append(total)
    return y


def predicted_bold(onsets, durations, tr, n_scans, h):
    """Boxcar from events at the scan times, convolved with the HRF."""
    box = []
    for n in range(n_scans):
        t = n * tr
        on = any(o <= t < o + d for o, d in zip(onsets, durations))
        box.append(1.0 if on else 0.0)
    return convolve(box, h)
```
hint: First decide for each scan time `n * tr` whether any event covers it; use `any(...)` so overlaps stay at 1. Then convolve.
solution: Build the boxcar with a membership test at each scan time, then convolve. The third test has two overlapping events, where adding the events would give a value of 2 at the middle scan; the fifth has an event that starts exactly on a scan time (3.0 = 2 * 1.5), which counts because the test uses `<=` at the start and `<` at the end.

model:
```python
def peak_ratio(h, k):
    """Peak of the two-event response relative to the single-event peak."""
    n_out = len(h) + k
    y = []
    for n in range(n_out):
        a = h[n] if n < len(h) else 0.0
        b = h[n - k] if 0 <= n - k < len(h) else 0.0
        y.append(a + b)
    return max(y) / max(h)
```
hint: Build the output list sample by sample, adding `h[n]` when `n` is in range and `h[n - k]` when `n - k` is in range.
solution: The two-event response is the single response plus a copy shifted by `k`. Where the two overlap near their peaks, the maximum grows (ratio 1.5 and 2.0 in the first and fourth tests); when the second copy arrives after the first has gone, the ratio is 1 (second test). A real HRF saturates for close events, so measured ratios are smaller than this linear model predicts.

@quiz self
prompt: A lab uses one fixed canonical HRF for every voxel in a study that compares young and older adults. Explain how this could bias a comparison of activation between the groups, and describe two analysis choices that would reduce the problem.
hint: Think about what happens to the fitted amplitude when the true response is delayed or has a different width.
solution: The fitted amplitude measures how well the data match the canonical shape. If one group has a response that is systematically delayed, wider or smaller in its undershoot, the same neural activity gives a poorer match and so a smaller fitted amplitude for that group, which can look like less activation when it is really a different hemodynamic response (a vascular difference, not a neural one). Two remedies: add the temporal and dispersion derivatives of the HRF as extra regressors, or use a flexible model (a finite impulse response basis) that estimates the shape for each person or region, so the amplitude and timing are separated. A third check is a control task or region whose neural response is expected to be equal between groups, to see whether the HRF itself differs.

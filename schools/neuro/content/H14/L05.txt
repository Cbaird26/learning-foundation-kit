@article
A list finds things by position. A **dictionary** finds them by *key*: you ask for `"ana"` and get her score, without caring where she is stored. Dictionaries (type `dict`) are one of the most useful tools in Python.

### Dictionaries

```python
scores = {"ana": 90, "ben": 72}
scores["cy"] = 85          # add a new key
scores["ben"] = 75         # replace an existing value
print(scores["ana"])       # 90
print("dee" in scores)     # False: `in` tests the keys
del scores["cy"]           # remove a key
```

Asking for a key that is missing with `scores["dee"]` raises `KeyError`. The method `scores.get("dee", 0)` returns the default `0` instead. Keys must be **immutable** values such as numbers, strings and tuples (a list cannot be a key); values can be anything. Since Python 3.7 a dictionary remembers the order in which keys were first added.

Loops give you the keys by default; use `.values()` for values and `.items()` for pairs:

```python
for name, score in scores.items():
    print(name, score)
```

`len(scores)` is the number of keys.

### The counting pattern

To count how often each item occurs, use the dictionary as a table of counters, adding 1 to the item's counter and starting at 0 for new items:

```python
counts = {}
for ch in "banana":
    counts[ch] = counts.get(ch, 0) + 1
print(counts)   # {'b': 1, 'a': 3, 'n': 2}
```

This visits each item once, so a word-frequency counter for a long text needs far fewer steps than calling `words.count(w)` for every word.

### The grouping pattern

To collect items into lists by some property, make each value a list. Create the list the first time a key appears:

```python
groups = {}
for w in ["pea", "fig", "apple"]:
    if len(w) not in groups:
        groups[len(w)] = []
    groups[len(w)].append(w)
# {3: ['pea', 'fig'], 5: ['apple']}
```

### Sets

A **set** is an unordered collection with no duplicates. `set([3, 1, 3, 2])` is `{1, 2, 3}` (printed in no promised order). Create an empty set with `set()`, because `{}` is an empty *dictionary*. Membership tests `x in s` are fast, and sets support the operations of school mathematics:

| Expression | Meaning |
|---|---|
| `a & b` | in both (intersection) |
| `a \| b` | in either (union) |
| `a - b` | in `a` but not in `b` (difference) |
| `s.add(x)` | add an element |

Sets have no order and no positions, so `s[0]` is an error. When you need sorted output, write `sorted(s)`, which returns a list.

### Which one to use?

Use a **list** when order or repeated items matter, a **dictionary** when you look things up by a key or keep a value for each key, and a **set** when only "is it in there?" and uniqueness matter.

@example
title: Counting letters
problem: What dictionary does the counting pattern build for the string `"banana"`?
step: Start with `counts = {}`.
step: `"b"` is new, so `counts.get("b", 0)` is `0` and the counter becomes `1`: `{"b": 1}`.
step: `"a"` is new: `{"b": 1, "a": 1}`. Then `"n"`: `{"b": 1, "a": 1, "n": 1}`.
step: The next `"a"` finds the value `1` and makes it `2`, then `"n"` becomes `2`, and the last `"a"` becomes `3`.
answer: `{'b': 1, 'a': 3, 'n': 2}`

@example
title: Comparing two guest lists with sets
problem: `a = {"ann", "bo", "cy"}` and `b = {"bo", "cy", "di"}`. Who is on both lists, on either, and only on `a`?
step: Both lists means intersection: `a & b` is `{"bo", "cy"}`.
step: Either list means union: `a | b` has all four names, `{"ann", "bo", "cy", "di"}`, with the shared names counted once.
step: Only on `a` means difference: `a - b` removes the names that are also in `b`, leaving `{"ann"}`.
step: A set prints in no promised order, so to show the names in a stable order use `sorted(a & b)`, which gives `['bo', 'cy']`.

@mistakes
- Using `{}` for an empty set; it creates an empty dictionary. Write `set()`.
- Reading `d[key]` for a key that may be missing, instead of `d.get(key, default)` or an `in` check.
- Expecting a set to keep order or to have indexes.
- Using a list as a dictionary key; keys must be immutable, so use a tuple.

def count_items(items):

expected = {1: ["a", "c"], 2: ["bb", "dd"], 3: ["eee"]}

assert group_by_length([]) == {}

model:
```python
def group_by_length(words):
    groups = {}
    for w in words:
        n = len(w)
        if n not in groups:
            groups[n] = []
        groups[n].append(w)
    return groups
```
hint: Each value is a list, so create the list the first time a length is seen.
hint: Inside the loop: `if n not in groups: groups[n] = []`, then append the word to `groups[n]`.
solution: The grouping pattern: for each word compute its length, create an empty list for that length if there is none yet, and append the word. Words are visited in order, so each list keeps the original order.

@quiz code
prompt: Write `first_repeat(items)` that scans the list from left to right and returns the first item that has already appeared earlier in the list, or `None` if no item repeats. For example `first_repeat([3, 1, 4, 1, 5, 9, 2, 6, 5])` is `1`, because the second `1` is reached before the second `5`.
starter:
```python
def first_repeat(items):
    pass
```
tests:
```python
assert first_repeat([3, 1, 4, 1, 5, 9, 2, 6, 5]) == 1
assert first_repeat(["a", "b"]) is None
assert first_repeat([]) is None
assert first_repeat([7, 7]) == 7
assert first_repeat([1, 2, 2, 1]) == 2
```
model:
```python
def first_repeat(items):
    seen = set()
    for item in items:
        if item in seen:
            return item
        seen.add(item)
    return None
```
hint: Keep a set of the items you have already seen as you scan.
hint: If the current item is already in the set, return it immediately; otherwise add it to the set.
solution: Scan once with a set `seen`. The first time an item is found in `seen`, it is the first repeat in scanning order, so return it. In `[1, 2, 2, 1]` the answer is `2`, because the second `2` is reached before the second `1`.

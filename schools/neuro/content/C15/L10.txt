@article
A lab records 10 electrodes and tests each for a difference between conditions at $\alpha = 0.05$. Even if nothing at all is going on, each test has a 5% chance of a false alarm. How likely is at least one "significant" electrode? For $m$ independent tests of true null hypotheses,

$$P(\text{at least one false positive}) = 1 - (1 - \alpha)^m = 1 - 0.95^{10} = 0.401.$$

A 40% chance of a spurious finding is the **familywise error rate** (FWER) of uncorrected testing. With thousands of voxels in a brain scan or thousands of genes in an expression study, the problem is far worse, and a few "active" voxels are guaranteed by chance. The cure is to decide in advance which tests form the **family**, and to correct for the whole family.

### Controlling the familywise error rate

The **Bonferroni correction** tests each of $m$ hypotheses at level $\alpha/m$ (equivalently, multiplies each p-value by $m$, capping at 1). By the union bound, $P(\text{any false positive}) \le m\cdot\alpha/m = \alpha$, whatever the dependence between the tests. For 10 tests the per-test threshold is $0.005$. A close relative, the **Šidák correction**, uses $1 - (1-\alpha)^{1/m} = 0.00512$, exact for independent tests.

The **Holm** procedure (1979) is never less powerful and keeps the same guarantee. Sort the p-values $p_{(1)} \le \dots \le p_{(m)}$. Compare $p_{(1)}$ with $\alpha/m$, $p_{(2)}$ with $\alpha/(m-1)$, and so on, comparing $p_{(i)}$ with $\alpha/(m - i + 1)$. Reject each hypothesis in turn until the first comparison that fails, then stop: that hypothesis and all with larger p-values are retained.

### Controlling the false discovery rate

When thousands of tests are run to find candidates for follow-up, requiring zero false positives is too strict. The **false discovery rate** (FDR) is the expected proportion of false positives among the hypotheses you declare significant ("discoveries"). Benjamini and Hochberg (1995) showed how to control it at a level $q$. Sort the p-values, find the largest rank $i$ with

$$p_{(i)} \le \frac{i}{m}\,q,$$

and reject the hypotheses with the $i$ smallest p-values, even if some of those p-values individually exceed their own threshold. The guarantee holds for independent tests and for many kinds of positive dependence. FWER control answers "How likely is any false claim in my list?" FDR control answers "What fraction of my list do I expect to be false?" A confirmatory test of a few planned hypotheses calls for FWER; an exploratory screen of thousands of features can reasonably use FDR, if the results are then described as candidates.

```python
def bonferroni(ps, alpha=0.05):
    """True for each hypothesis rejected by the Bonferroni correction."""
    return [p <= alpha / len(ps) for p in ps]


def benjamini_hochberg(ps, q=0.05):
    """True for each hypothesis rejected at false discovery rate q."""
    m = len(ps)
    order = sorted(range(m), key=lambda i: ps[i])
    cutoff = 0
    for rank, i in enumerate(order, start=1):
        if ps[i] <= rank / m * q:
            cutoff = rank
    rejected = set(order[:cutoff])
    return [i in rejected for i in range(m)]


ps = [0.0004, 0.004, 0.0056, 0.012, 0.021, 0.038, 0.12, 0.35, 0.64, 0.9]
print(sum(bonferroni(ps)), sum(benjamini_hochberg(ps)))
```

It prints `2 5`. Bonferroni (threshold $0.005$) keeps the first two p-values; Holm compares the third against $0.05/8 = 0.00625$ and keeps $0.0056$ too, rejecting 3; Benjamini-Hochberg finds $p_{(5)} = 0.021 \le 0.025$ and rejects the five smallest. The more liberal procedures buy power at the price of a weaker guarantee. Note that BH looks for the *largest* passing rank, not the first failure: a later p-value can rescue earlier ones.

### What counts as a family

No formula decides this. Declare the family before looking at the data: all electrodes, all pairwise group comparisons, all regions in an atlas. Trying many analyses and reporting the one that worked is a multiplicity problem even if each analysis looks like a single test (Week 11). In neuroimaging, correction is typically over voxels or clusters; Eklund, Nichols and Knutsson (2016) showed that some common cluster-based methods had false-positive rates well above the nominal 5%, which is why the exact corrected procedure and its assumptions must be named in a report. Corrections cost power, so plan the number of tests: fewer, theory-driven hypotheses give a smaller family.

@example
title: Bonferroni versus Benjamini-Hochberg
problem: Six comparisons give p-values $0.002, 0.011, 0.017, 0.040, 0.10, 0.45$ (already sorted). Which are rejected by the Bonferroni correction at $\alpha = 0.05$ and by Benjamini-Hochberg at $q = 0.05$?
step: Bonferroni's per-test threshold is $0.05/6 = 0.00833$. Only $0.002$ is below it, so one hypothesis is rejected.
step: For Benjamini-Hochberg, the thresholds $\frac{i}{6}(0.05)$ for ranks 1 to 6 are $0.00833, 0.01667, 0.025, 0.03333, 0.04167, 0.05$.
step: Compare each sorted p-value with its threshold: $0.002 \le 0.00833$ yes; $0.011 \le 0.01667$ yes; $0.017 \le 0.025$ yes; $0.040 \le 0.03333$ no; $0.10 \le 0.04167$ no; $0.45 \le 0.05$ no.
step: The largest passing rank is 3, so the three smallest p-values are rejected, including $0.011$ and $0.017$, which fail the Bonferroni threshold.
step: Interpret: Bonferroni keeps the chance of any false claim among the six at or below 5%. BH accepts that, on average, about 5% of the claims it makes may be false, and in return it finds three effects rather than one.
answer: Bonferroni rejects 1 hypothesis (p = 0.002); Benjamini-Hochberg rejects 3 (p = 0.002, 0.011, 0.017).

@mistakes
- Correcting only the tests that look interesting after the fact: the family is every test that could have been reported.
- Applying Benjamini-Hochberg but stopping at the first p-value that fails its threshold: the rule uses the largest rank that passes.
- Describing FDR control as "5% chance that any result is false": it is the expected proportion of false results among those declared significant.
- Using Bonferroni's $\alpha/m$ for the number of tests actually reported rather than the number run.

```python
def holm_reject(ps, alpha=0.05):
    """Holm step-down procedure; rejections in the original order."""
    m = len(ps)
    order = sorted(range(m), key=lambda i: ps[i])
    rejected = [False] * m
    for step, i in enumerate(order):
        if ps[i] <= alpha / (m - step):
            rejected[i] = True
        else:
            break
    return rejected
```
hint: Remember the original index of each p-value while sorting, and use `break` at the first comparison that fails.
solution: Holm compares the smallest p-value with $\alpha/m$ (Bonferroni's threshold), then relaxes the threshold to $\alpha/(m-1)$, and so on, so it rejects everything Bonferroni does and sometimes more. In the first test the third p-value 0.012 is rejected because its threshold is $0.05/3 = 0.0167$, though Bonferroni's 0.01 would have kept it. In the test `[0.011, 0.06, 0.0004]`, the two smaller p-values pass at $0.05/3$ and $0.05/2$, but 0.06 exceeds the final threshold $0.05/1$, so it is retained.

model:
```python
def bh_adjusted(ps):
    """Benjamini-Hochberg adjusted p-values in the original order."""
    m = len(ps)
    order = sorted(range(m), key=lambda i: ps[i])
    adjusted = [0.0] * m
    running = 1.0
    for rank in range(m, 0, -1):
        i = order[rank - 1]
        running = min(running, ps[i] * m / rank)
        adjusted[i] = running
    return adjusted
```
hint: Walk through the sorted p-values from the largest rank down to 1, keeping a running minimum of `p * m / rank`.
solution: The running minimum, computed from the largest p-value downward, makes the adjusted values monotone in the p-values, which is why a later p-value can rescue earlier ones (the first test shows 0.012 and 0.008 both adjusted to 0.02). The cap at 1 is the starting value of the running minimum.

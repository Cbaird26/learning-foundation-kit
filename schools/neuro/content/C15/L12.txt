@article
After eleven weeks of computing, the last skill is saying clearly what you found. A good results section lets a skeptical reader check each claim: it says what was planned, gives the numbers that matter, shows the data, and claims no more than the design supports.

### A model results paragraph

Two groups of participants did a visual search task. Seven completed a week of training; eight were controls. Mean RTs were 517.3 ms ($SD = 14.4$) for the trained group and 540.1 ms ($SD = 13.5$) for the controls. The trained group was faster by 22.8 ms (Welch $t(12.44) = -3.16$, $p = .008$; 95% CI of the difference $[-38.5, -7.1]$ ms; Cohen's $d = -1.64$, approximate 95% CI $[-2.81, -0.47]$). The sentences name the groups and sample sizes, give each group's center and spread, put the **difference in raw units** first, add a **confidence interval** (the range of plausible differences), then a **standardized effect size**, then the exact p-value. The interval is wide: the data are compatible with a modest 7 ms effect and with a very large one. That is honest, and it is information that "$p < .05$" alone hides.

Conventions (from common psychology and neuroscience reporting guidelines) that this course follows: report exact p-values to three decimals, with "$p < .001$" below that; do not write $p = .000$; name the test, its version (Welch or pooled), the degrees of freedom and whether tests are one- or two-sided; give the number of participants and trials analyzed and how many were excluded and why (using the pre-declared rules); say whether results survived the correction for multiple tests; label unplanned analyses as exploratory.

### Standardized effects with an interval

A $d$ without an interval is a point estimate from a noisy sample. A common large-sample approximation to the standard error of $d$ for two groups of sizes $n_1$ and $n_2$ is

$$\text{SE}_d \approx \sqrt{\frac{n_1 + n_2}{n_1 n_2} + \frac{d^2}{2(n_1 + n_2)}},$$

with interval $d \pm 1.96\,\text{SE}_d$. It is rough in small samples, but it shows how little $n = 7$ and $n = 8$ pin down an effect size.

```python
import math


def d_ci(d, n1, n2, z=1.96):
    """Approximate confidence interval for Cohen's d (large-sample SE)."""
    se = math.sqrt((n1 + n2) / (n1 * n2) + d ** 2 / (2 * (n1 + n2)))
    return d - z * se, d + z * se


lo, hi = d_ci(-1.64, 7, 8)
print(round(lo, 2), round(hi, 2))
```

The program prints `-2.81 -0.47`, the interval quoted above.

### Figures and tables in words

A figure should show the data, not only summaries: with few participants, show each participant's mean, or both conditions with lines joining each person's two points for a within-subject design. Say what error bars are (standard deviation, standard error or confidence interval) and what $n$ counts. Since this site shows no images, practice describing a plot as a table that a reader could redraw:

| group | n | mean RT (ms) | SD (ms) | 95% CI of mean (ms) |
|---|---|---|---|---|
| trained | 7 | 517.3 | 14.4 | 504.0 to 530.6 |
| control | 8 | 540.1 | 13.5 | 528.9 to 551.4 |

In the caption, state the design, the number of participants per condition, the statistic shown and the test performed.

### Honest claims

Match the verb to the evidence:

| situation | licensed wording |
|---|---|
| randomized assignment, preregistered test, $p = .008$ | "Training reduced RT by about 23 ms (95% CI 7 to 39 ms) in this sample" |
| no random assignment, same data | "Trained participants had faster RTs; the groups may differ in other ways" |
| $p = .08$, interval $[-2, 30]$ ms, small $n$ | "Inconclusive: the data fit no effect and effects of 30 ms" |
| post hoc subgroup with $p = .03$ among 12 looks | "An exploratory pattern to test in a new sample" |

Avoid "trend toward significance" (a $p$ above the threshold is not a weaker positive result), "proves" (a study never does), and "no effect" for a non-significant result when the interval includes effects that matter. To claim that an effect is negligible, specify the smallest difference you care about and show that the whole interval lies inside it (an **equivalence test**). Finally, state limitations (who the participants were, what was not controlled) and share the data and analysis code so that others can check the work: an analysis that runs from raw data to the reported numbers is the best defense against both error and doubt.

@example
title: From summary numbers to a reported sentence
problem: Twenty-four participants judge a faint stimulus; their mean accuracy is $0.62$ with $SD = 0.15$. Test it against the chance level $0.5$ (two-sided, $t^* = 2.0687$ for df $= 23$) and write the result.
step: The standard error is $0.15/\sqrt{24} = 0.0306$, so $t = (0.62 - 0.5)/0.0306 = 3.92$ with df $= 23$.
step: The two-sided p-value for $t(23) = 3.92$ is about $0.0007$, below $0.001$, so it is reported as $p < .001$.
step: The one-sample effect size is $d_z = (0.62 - 0.5)/0.15 = 0.80$.
step: The 95% interval for mean accuracy is $0.62 \pm 2.0687 \times 0.0306 = 0.62 \pm 0.063$, that is $[0.557, 0.683]$.
step: Write it: "Accuracy (M = .62, SD = .15, n = 24) exceeded chance, $t(23) = 3.92$, $p < .001$, $d_z = 0.80$, 95% CI of the mean [.557, .683]." The interval shows that the true accuracy is plausibly anywhere from barely above chance to about 68%.
answer: $t(23) = 3.92$, $p < .001$, $d_z = 0.80$, 95% CI $[0.557, 0.683]$.

@mistakes
- Reporting only "$p < .05$": give the effect in raw units, its interval, and the exact p-value.
- Writing $p = .000$: the p-value is never exactly zero; write $p < .001$.
- Calling a non-significant result "no effect" or a near-threshold one a "trend": say what the interval allows.
- Drawing bars of means with error bars of an unstated kind, or hiding the individual data when $n$ is small.

```python
def format_p(p):
    """Format a p-value with three decimals and no leading zero."""
    if p < 0.001:
        return 'p < .001'
    return 'p = ' + f'{p:.3f}'.replace('0.', '.', 1)
```
hint: Handle the small values first; for the rest, format with three decimals and replace the first `'0.'` with `'.'`.
solution: The cut-off at 0.001 avoids the impossible `p = .000`. For the rest, `f'{p:.3f}'` gives text such as `0.034`, and replacing the first `'0.'` strips the leading zero; `1.000` has none to strip, so it is left alone.

model:
```python
def report_t(t, df, p, d):
    """One-line report of a t test with p-value and effect size."""
    if df == int(df):
        df_text = str(int(df))
    else:
        df_text = f'{df:.2f}'
    if p < 0.001:
        p_text = 'p < .001'
    else:
        p_text = 'p = ' + f'{p:.3f}'.replace('0.', '.', 1)
    return f't({df_text}) = {t:.2f}, {p_text}, d = {d:.2f}'
```
hint: Build the three pieces (degrees of freedom, p-value, and the whole line) separately; test `df == int(df)` for a whole-number df.
solution: Welch tests give fractional degrees of freedom and pooled or paired tests give integers, so the formatter must handle both: `30.0` is shown as `30` but `12.4445` as `12.44`. Using one rule for p-values everywhere keeps a report consistent.

model:
```python
import math


def mean_ci_text(x, tcrit):
    """Mean and 95% confidence interval as one formatted string."""
    n = len(x)
    m = sum(x) / n
    s = math.sqrt(sum((v - m) ** 2 for v in x) / (n - 1))
    half = tcrit * s / math.sqrt(n)
    return f'M = {m:.1f}, 95% CI [{m - half:.1f}, {m + half:.1f}]'
```
hint: Compute the mean and half-width first, then format the three numbers with `:.1f` inside one f-string.
solution: The mean, the lower limit and the upper limit each get one decimal. With only two observations and the huge critical value for one degree of freedom, the interval spans many standard errors on either side of the mean, so the lower limit is negative, the last test's point: such an interval honestly says that two observations tell you very little.

@article
Two studies compare a drug with a placebo. One tests 20 participants and finds a 5 ms speed-up that is not significant; another tests 20,000 participants and finds a 1 ms speed-up that is highly significant. A p-value depends on both the size of the effect and the amount of data, so it cannot say how big an effect is. Two further quantities can: an **effect size**, which says how large, and **power**, which says how likely a planned experiment is to detect an effect of a given size.

### Effect size: Cohen's d

The raw difference in means is in the units of the task (ms), and it is the first thing to report. To compare across tasks and measures, divide by a standard deviation. **Cohen's $d$** for two independent groups divides by the **pooled standard deviation**:

$$d = \frac{\bar{x}_1 - \bar{x}_2}{s_p}, \qquad s_p = \sqrt{\frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}}.$$

It says how many standard deviations apart the group means are. Cohen's rough conventions of 0.2 (small), 0.5 (medium) and 0.8 (large) are only reference points: what counts as large depends on the field and on cost. In small samples $d$ overestimates the population effect slightly; **Hedges' $g$** multiplies it by the correction $J = 1 - \frac{3}{4\,\text{df} - 1}$ with $\text{df} = n_1 + n_2 - 2$.

Take two groups of six with means 458.3 and 440.5 ms and variances 176.3 and 108.3. Then $s_p = \sqrt{(5 \times 176.27 + 5 \times 108.3)/10} = 11.93$ ms, so $d = 17.83/11.93 = 1.50$ and $g = 1.50 \times (1 - 3/39) = 1.38$. For a paired design the standardized effect is $d_z = \bar{d}/s_d$, the mean difference over the standard deviation of the differences; it is not directly comparable with a two-group $d$.

### Errors and power

A test can err in two ways. A **Type I error** rejects a true $H_0$; its rate is $\alpha$. A **Type II error** fails to reject when an effect exists; its rate is $\beta$. **Power** is $1 - \beta$, the probability of rejecting $H_0$ when the true effect has a stated size. Power rises with a larger true effect, a larger sample, a larger $\alpha$ and less noise (or a paired design).

For a two-sided two-sample test with $n$ per group and true standardized effect $d$, the **normal approximation** to the power is

$$\text{power} \approx \Phi\!\left(d\sqrt{n/2} - z_{1-\alpha/2}\right),$$

where $\Phi$ is the standard normal cumulative distribution function and $z_{0.975} = 1.96$. The quantity $d\sqrt{n/2}$ is the expected test statistic; the test succeeds when it clears the critical value. Setting power to $1 - \beta$ and solving gives the sample size per group:

$$n = 2\left(\frac{z_{1-\alpha/2} + z_{1-\beta}}{d}\right)^2,$$

with $z_{0.80} = 0.8416$ for 80% power and $z_{0.90} = 1.2816$ for 90%. For a paired or one-sample design with standardized effect $d_z$, the number of participants is $n = \big((z_{1-\alpha/2} + z_{1-\beta})/d_z\big)^2$. Round up. The approximation ignores the heavier tails of $t$, so it is a little optimistic for small $n$.

```python
import math


def normal_cdf(z):
    return 0.5 * (1 + math.erf(z / math.sqrt(2)))


def cohens_d(a, b):
    """Cohen's d with the pooled standard deviation (n - 1 variances)."""
    na, nb = len(a), len(b)
    ma, mb = sum(a) / na, sum(b) / nb
    ss = sum((v - ma) ** 2 for v in a) + sum((v - mb) ** 2 for v in b)
    return (ma - mb) / math.sqrt(ss / (na + nb - 2))


def power_two_sample(d, n, zcrit=1.96):
    """Approximate power of a two-sided two-sample test, n per group."""
    return normal_cdf(d * math.sqrt(n / 2) - zcrit)


print(round(power_two_sample(0.5, 64), 3))
print(math.ceil(2 * ((1.96 + 0.8416) / 0.5) ** 2))
```

These print `0.807` and `63`: a medium effect ($d = 0.5$) needs about 63 participants per group for 80% power. (The exact $t$-based calculation asks for 64; the exact power with 63 per group is 0.795.)

### Why power matters

An underpowered study misses true effects, and it distorts the literature in a second way: among studies that do reach significance, the estimated effects are inflated, because with low power only unusually large sample differences get past the threshold. Button and colleagues (2013) argued that the typical power in neuroscience studies was low, which means that many significant findings are exaggerated and some are false. Power must be set **before** the data are collected, from the smallest effect worth detecting, not from the effect observed in the study itself ("post hoc power" is just a re-expression of the p-value). A planning effect size from a published study should be treated with suspicion for the inflation reason above.

@example
title: Choosing a sample size for a planned experiment
problem: You plan a two-group experiment on RTs and want 90% power at two-sided $\alpha = 0.05$ to detect $d = 0.4$. Use $z_{0.975} = 1.96$ and $z_{0.90} = 1.2816$. How many participants per group, and in total?
step: State the design: two independent groups, equal sizes, standardized effect $d = 0.4$, so the per-group formula applies.
step: Add the two critical values: $1.96 + 1.2816 = 3.2416$.
step: Divide by the effect and square: $(3.2416/0.4)^2 = 8.104^2 = 65.67$.
step: Multiply by 2: $n = 131.35$ per group. Round up to 132 per group, 264 participants in total. Rounding down would leave the power just under 90%.
step: Check the sensitivity: if the true effect were only $d = 0.3$, the same 132 per group would give power about $\Phi(0.3\sqrt{66} - 1.96) = \Phi(0.477) \approx 0.68$. Planning for the smallest effect that matters, not the hoped-for one, protects against this.
answer: 132 per group (264 in total).

@mistakes
- Equating a small p-value with a large effect: with enough data a negligible difference is "significant", and with little data a large one is not.
- Computing power from the effect observed in the same experiment: that adds no information beyond the p-value; plan from the smallest effect of interest.
- Rounding a sample size down: always round up to the next whole participant.
- Comparing a paired $d_z$ with a two-group $d$ as if they were the same quantity: their denominators differ.

```python
import math


def hedges_g(a, b):
    """Cohen's d with the pooled SD, times the small-sample correction."""
    na, nb = len(a), len(b)
    ma, mb = sum(a) / na, sum(b) / nb
    ss = sum((v - ma) ** 2 for v in a) + sum((v - mb) ** 2 for v in b)
    df = na + nb - 2
    d = (ma - mb) / math.sqrt(ss / df)
    return d * (1 - 3 / (4 * df - 1))
```
hint: Get the two sums of squared deviations, divide their total by `df` for the pooled variance, and apply the correction factor last.
solution: The correction shrinks $d$ slightly: with $df = 9$ it is $1 - 3/35 = 0.914$, so $d = 1.671$ becomes $g = 1.528$. The correction matters for small samples and approaches 1 as the groups grow. The sign follows the order of the groups.

```python
import math


def n_needed(d, z_alpha, z_beta, paired=False):
    """Sample size (per group, or participants if paired), rounded up."""
    n = ((z_alpha + z_beta) / d) ** 2
    if not paired:
        n *= 2
    return math.ceil(n)
```
hint: Compute $((z_\alpha + z_\beta)/d)^2$ once and double it only for the independent-groups design.
solution: The paired design needs half as many participants for the same standardized effect, because one participant contributes a difference rather than half of a comparison; the squaring also makes the sign of `d` irrelevant, so a negative effect gives the same size. Always round up with `ceil`.

```python
import math


def power_paired(dz, n, zcrit=1.96):
    """Approximate power of a paired two-sided test (normal approximation)."""
    z = dz * math.sqrt(n) - zcrit
    return 0.5 * (1 + math.erf(z / math.sqrt(2)))
```
hint: The expected test statistic is $d_z\sqrt{n}$; subtract the critical value and pass the result through $\Phi$.
solution: The expected test statistic is $d_z\sqrt{n}$, and the test rejects when the observed statistic exceeds the critical value, so power is $\Phi(d_z\sqrt{n} - z_{\text{crit}})$. With no effect it equals $\Phi(-1.96) = 0.025$, the one tail of the two-sided test that lies on the effect's side; the approximation ignores the other tail.

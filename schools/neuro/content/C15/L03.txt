@article
Twelve participants take a reaction-time task, six after a placebo and seven after a drug that is claimed to speed responses. The drug group is faster on average, by 33 ms. Is that a real effect or the kind of gap that chance produces when you split any group of people in two? The $t$-test answers by asking how large the difference is compared with the noise in the difference.

### The logic of a test

A **null hypothesis** $H_0$ states that there is no effect (for example, equal population means). The **test statistic** measures how far the data are from $H_0$ in standard-error units. The **p-value** is the probability, if $H_0$ and the model's assumptions were true, of a test statistic at least as extreme as the one observed. It is not the probability that $H_0$ is true, and it says nothing about how large or important the effect is (Week 4). A pre-declared threshold $\alpha$ (conventionally 0.05) fixes the rate of false alarms when $H_0$ is true: reject if $p < \alpha$, equivalently if $|t|$ exceeds the critical value.

### One sample and paired

The **one-sample $t$ statistic** compares a sample mean with a fixed value $\mu_0$ (a chance level, a published norm):

$$t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}, \qquad \text{df} = n - 1.$$

A **paired $t$-test** applies the same formula to the within-pair differences $d_i$ (for each participant, condition B minus condition A) with $\mu_0 = 0$: $t = \bar{d}/(s_d/\sqrt{n})$, df $= n - 1$. Pairing removes stable differences between people, which is why within-subject designs are powerful.

### Two independent samples

For separate groups, the standard error of the difference $\bar{x}_1 - \bar{x}_2$ combines the two sampling variances. **Welch's $t$** does not assume equal variances:

$$t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}}, \qquad \text{df} = \frac{\left(\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}\right)^2}{\dfrac{(s_1^2/n_1)^2}{n_1 - 1} + \dfrac{(s_2^2/n_2)^2}{n_2 - 1}}$$

(the Welch–Satterthwaite degrees of freedom, usually not an integer). The **pooled $t$** assumes both populations share a variance and estimates it from both samples: $s_p^2 = \dfrac{(n_1 - 1)s_1^2 + (n_2 - 1)s_2^2}{n_1 + n_2 - 2}$, $t = \dfrac{\bar{x}_1 - \bar{x}_2}{s_p\sqrt{1/n_1 + 1/n_2}}$, df $= n_1 + n_2 - 2$. With equal group sizes the two statistics coincide; with unequal sizes and unequal variances, Welch keeps the error rate near $\alpha$ and is the safer default, and this course uses it unless told otherwise.

```python
import math


def mean(x):
    return sum(x) / len(x)


def var(x):
    """Sample variance (n - 1)."""
    m = mean(x)
    return sum((v - m) ** 2 for v in x) / (len(x) - 1)


def one_sample_t(x, mu0):
    return (mean(x) - mu0) / math.sqrt(var(x) / len(x))


def welch_t(a, b):
    """Welch t statistic and Welch-Satterthwaite degrees of freedom."""
    va, vb = var(a) / len(a), var(b) / len(b)
    t = (mean(a) - mean(b)) / math.sqrt(va + vb)
    df = (va + vb) ** 2 / (va ** 2 / (len(a) - 1) + vb ** 2 / (len(b) - 1))
    return t, df


placebo = [498, 512, 530, 505, 521, 540]
drug = [468, 490, 475, 502, 481, 495, 479]
t, df = welch_t(placebo, drug)
print(round(t, 2), round(df, 2))
```

It prints `4.25 9.25`. The means are 517.7 and 484.3 ms; the critical value for a two-sided 5% test at df $= 9.25$ is about $2.25$, and the two-sided p-value is about $0.002$. The difference is far larger than chance would typically produce. A 95% confidence interval for the difference is $(\bar{x}_1 - \bar{x}_2) \pm t^*\,\text{SE}$, and it carries more information than the verdict: it shows the plausible sizes of the effect.

### Assumptions and their limits

The tests assume that observations are **independent** (the most important condition: repeated trials from one person are not independent observations of a group), that the sampling distribution of the mean is roughly normal (fine for moderate $n$ unless the data are very skewed or contain outliers), and, for the pooled version only, equal variances. A "non-significant" result does not show the groups are equal: it may only mean the experiment was too small to detect the difference (Week 4). Run one test planned in advance, not several chosen afterward (Weeks 10 and 11).

@example
title: A paired t-test on before-and-after RTs
problem: Six participants perform a task before and after 30 minutes of sustained work. Their mean RTs (ms) are before: 452, 470, 431, 488, 465, 440 and after: 440, 463, 428, 471, 462, 431. Test whether RT changed, using a two-sided test at $\alpha = 0.05$ with critical value $t^* = 2.571$ for df $= 5$.
step: Form the differences, after minus before: $-12, -7, -3, -17, -3, -9$. Their mean is $\bar{d} = -51/6 = -8.5$ ms.
step: Compute the sample standard deviation of the differences. The deviations from $-8.5$ are $-3.5, 1.5, 5.5, -8.5, 5.5, -0.5$ with squares $12.25, 2.25, 30.25, 72.25, 30.25, 0.25$, which sum to $147.5$. So $s_d = \sqrt{147.5/5} = \sqrt{29.5} = 5.431$ ms.
step: The standard error is $5.431/\sqrt{6} = 2.217$ ms, so $t = -8.5/2.217 = -3.83$ with df $= 5$.
step: Compare: $|t| = 3.83 > 2.571$, so reject $H_0$ (the p-value is about 0.012). RTs were faster after the work by about 8.5 ms, with a 95% interval $-8.5 \pm 2.571 \times 2.217$, that is $[-14.2, -2.8]$ ms. The design has no control for practice, so the experiment cannot say that work caused the speed-up.
answer: $t(5) = -3.83$, $p \approx 0.012$; mean change $-8.5$ ms, 95% interval about $[-14.2, -2.8]$ ms.

@mistakes
- Running an independent-samples test on paired data (or the reverse): ignoring the pairing throws away power, and pretending independent groups are paired is simply wrong.
- Reading $p = 0.03$ as "a 97% chance the effect is real": a p-value is computed assuming $H_0$ is true, and does not give the probability of $H_0$.
- Treating a non-significant result as proof of no difference: the interval may still include large effects.
- Using the Welch statistic with the pooled degrees of freedom, or the reverse; the statistic and its df go together.

model:
```python
import math


def pooled_t(a, b):
    """Pooled-variance two-sample t statistic and its degrees of freedom."""
    na, nb = len(a), len(b)
    ma, mb = sum(a) / na, sum(b) / nb
    ssa = sum((v - ma) ** 2 for v in a)
    ssb = sum((v - mb) ** 2 for v in b)
    df = na + nb - 2
    sp2 = (ssa + ssb) / df
    return (ma - mb) / math.sqrt(sp2 * (1 / na + 1 / nb)), df
```
hint: The sums of squared deviations of each group divided by $n_1 + n_2 - 2$ give the pooled variance directly.
solution: $(n_i - 1)s_i^2$ is just the sum of squared deviations of group $i$, so the pooled variance is the total of both sums of squares over $n_1 + n_2 - 2$. The last test checks the sign: swapping the groups reverses the sign of $t$ but not its size.

model:
```python
import math


def paired_diff_ci(before, after, tcrit):
    """Confidence interval for the mean of after minus before."""
    d = [y - x for x, y in zip(before, after)]
    n = len(d)
    m = sum(d) / n
    s = math.sqrt(sum((v - m) ** 2 for v in d) / (n - 1))
    half = tcrit * s / math.sqrt(n)
    return m - half, m + half
```
hint: Build the list of differences first, then treat it as a one-sample problem.
solution: A paired analysis is a one-sample analysis of the differences, so the interval is the mean difference plus or minus $t^*$ standard errors of the differences. If every participant changes by the same amount, the standard deviation is zero and the interval collapses to a point, as the second test shows; reversing the order of subtraction flips and swaps the limits.

```python
import math


def welch_ci(a, b, tcrit):
    """Confidence interval for mean(a) - mean(b) with the Welch standard error."""
    def mean_var(x):
        m = sum(x) / len(x)
        return m, sum((v - m) ** 2 for v in x) / (len(x) - 1)

    ma, va = mean_var(a)
    mb, vb = mean_var(b)
    diff = ma - mb
    se = math.sqrt(va / len(a) + vb / len(b))
    return diff - tcrit * se, diff + tcrit * se
```
hint: The standard error adds each group's $s^2/n$ before the square root; the interval is centered on the difference of means.
solution: The interval is the observed difference plus or minus $t^*$ Welch standard errors. It is centered on $\bar{a} - \bar{b}$ and is wider when either group is small or variable. The caller supplies the critical value because it depends on the Welch degrees of freedom.

@article
A picture on a screen is made of tiny squares called **pixels**. Pixels are so small that you cannot see each one. Together they make a picture.

Computers can only store numbers. So how do they store a picture? They give each pixel a number.

### Black and white pictures

In a black and white picture, we need only two numbers:

- **1** means a black pixel.
- **0** means a white pixel.

Here is a tiny picture of 3 rows with 3 pixels in each row:

```text
1 0 1
0 1 0
1 0 1
```

If you color the 1s black and leave the 0s white, you see a big X. We can count the black pixels: there are 5 ones, so there are 5 black pixels.

### Writing a picture as numbers

You can go the other way, too. Say a row has these pixels: black, white, black. Write 1 for black and 0 for white. The row is **1 0 1**.

Do that for every row. You have turned a picture into numbers. A computer can store those numbers, and send them to a friend. The friend's computer turns the numbers back into a picture.

### Color

For colors, a computer uses more numbers for each pixel. But the idea is the same: a picture is a grid of numbers.

Grown-up helper: draw a 5 by 5 grid on paper. Let your child color squares to make a letter. Then write the 1s and 0s together, row by row.

@example
title: Reading numbers as a picture
problem: What shape do these numbers make, where 1 is black and 0 is white?

```text
0 1 0
1 1 1
0 1 0
```
step: Look at the top row. Only the middle pixel is black.
step: The middle row is all black. The bottom row has only the middle pixel black.
step: Together, the black pixels make a plus sign.
answer: A plus sign.

@mistakes
- Mixing up which number means black and which means white. Write it at the top of your picture.
- Skipping a pixel when you read a row. Move along each row from left to right.
- Counting the white pixels when you were asked for the black ones.

@practice text
prompt: A row of pixels is black, white, white, black, black. Write it with 1 for black and 0 for white. Type five digits with no spaces.
answer: 10011
accept: 1 0 0 1 1
check: "".join("1" if c == "black" else "0" for c in ["black", "white", "white", "black", "black"])
hint: Go from left to right. Write 1 for each black pixel and 0 for each white one.
solution: Black is 1, white is 0, white is 0, black is 1 and black is 1. The row is 10011.

@practice num
prompt: Look at this picture, where 1 is black and 0 is white. How many black pixels are there? Type a number.

```text
1 1 0
0 1 0
1 1 1
```
answer: 6
check: sum(row.count("1") for row in ["110", "010", "111"])
hint: Count the 1s in each row, then add the rows together.
solution: The top row has 2 ones, the middle row has 1 one and the bottom row has 3 ones. That is 2 plus 1 plus 3, which is 6 black pixels.

@quiz num
prompt: A picture is 4 pixels wide and 4 pixels tall. How many pixels does it have in all? Type a number.
answer: 16
check: 4 * 4
hint: There are 4 rows, and each row has 4 pixels.
solution: 4 rows with 4 pixels each is 4 times 4, which is 16 pixels.

material: **Model.** Rate $r$ in Hz, time in ms, one population with self-excitation $w$ (dimensionless), tonic input $h$ (Hz) and a cue $u(t)$ (Hz) equal to `amp` for the first `pulse_ms` and 0 afterward:

$$\tau\,\frac{dr}{dt} = -r + F\big(w\,r + h + u(t)\big), \qquad F(x) = \frac{100}{1 + e^{-(x - 50)/10}} .$$

Use $\tau = 20$ ms, $h = -10$ Hz, $\Delta t = 1$ ms, start at $r = 0$, and $F'(x) = F(x)\,(1 - F(x)/100)/10$.

For $w = 1.0$ the fixed points are 0.254, 67.15 and 97.76 Hz, with $wF'$ equal to 0.025, 2.206 and 0.219. The smallest remembered cue amplitude for $w = 1.0$ and a 50 ms pulse is about 39.2 Hz. A starting point for the code:

```python
import math


def F(x):
    return 100.0 / (1.0 + math.exp(-(x - 50.0) / 10.0))


def simulate(w, h, amp, pulse_ms, t_max, dt, tau):
    """Rate trace (Hz) of the bistable unit; returns a list of rates."""
    r, trace = 0.0, []
    for k in range(int(round(t_max / dt))):
        u = amp if k * dt < pulse_ms else 0.0
        r += dt / tau * (-r + F(w * r + h + u))
        trace.append(r)
    return trace
```

@review
This guide runs through the course week by week. Use it to find what you can still explain, derive and code without notes.

**Week 1, modeling.** A model commits to numbers and makes predictions. Marr's levels: computational, algorithmic, implementational. Euler: $c \leftarrow c + \Delta t\,\dot c$ with error shrinking in proportion to $\Delta t$; fit a time constant from $\ln c$ against $t$. A perfect fit with as many parameters as points proves little.

**Week 2, integrate-and-fire.** $C\,\dot V = -g_L(V - E_L) - w + I$, reset, refractory period, adaptation $w \to w + b$. Interval $t_{\text{ref}} + \tau_m\ln\frac{V_\infty - V_{\text{reset}}}{V_\infty - V_{\text{th}}}$; rate $1000/\text{interval}$; coefficient of variation.

**Week 3, Hodgkin–Huxley.** $c_m\dot V = -\sum g\,(V - E) + I_e/A$ with $n^4$ and $m^3h$; $x_\infty = \alpha/(\alpha + \beta)$, $\tau_x = 1/(\alpha + \beta)$; update all variables from the old state; handle the removable singularities.

**Week 4, phase plane.** FitzHugh–Nagumo nullclines, fixed points, Jacobian trace and determinant, eigenvalues $\tfrac12(\tau \pm \sqrt{\tau^2 - 4\Delta})$, spiral versus node, saddle, Hopf bifurcation, excitability.

**Week 5, synapses.** $g_s = \bar g\sum e^{-(t - t_s)/\tau_s}$, $I = g_s(E_{\text{syn}} - V)$; Tsodyks–Markram: recover over the gap, $u \leftarrow u + U(1 - u)$, efficacy $u\,x$, $x \leftarrow x - u\,x$.

**Week 6, spiking networks.** Weight matrix rows are inputs; synaptic traces; update order; delays; population rate and coincidence counts; $\Delta V \approx R\,W\tau_s/\tau_m$.

**Week 7, rate models.** $\tau\,\dot{\mathbf r} = -\mathbf r + [\mathbf W\mathbf r + \mathbf h]_+$; fixed point $(\mathbf I - \mathbf W)^{-1}\mathbf h$ when all are active; stability from $\text{Re}(\lambda_W) < 1$; winner-take-all.

**Week 8, E–I networks.** $D = (1 - w_{EE})(1 + w_{II}) + w_{EI}w_{IE}$; stability needs trace $< 0$ and determinant $> 0$; the paradoxical effect $\partial r_I/\partial h_I = (1 - w_{EE})/D$; balanced input has mean $\propto\sqrt{K}$ and fluctuations independent of $K$.

**Week 9, attractors.** Bistable unit: stable if $wF' < 1$; Hopfield: $W_{ij} = \frac1N\sum\xi_i\xi_j$, asynchronous sign updates, overlap, energy, capacity about $0.138N$.

**Week 10, coding.** Fano factor, Poisson likelihood $\sum n\ln f - Tf$, population vector, Fisher information $T\sum f'^2/f$, Cramér–Rao bound $1/\sqrt{I_F}$.

**Week 11, information.** $H = -\sum p\log_2 p$; $I = H(R) - H(R\mid S)$; Gaussian channel $\tfrac12\log_2(1 + \text{SNR})$; efficient coding by quantile thresholds.

**Week 12, oscillations.** $\dot\varphi = \Delta\omega - 2K\sin\varphi$, locking if $|\Delta\omega| \le 2K$; Kuramoto $R$; phase-locking value; E–I loop frequency from the imaginary part of the eigenvalues.

**Self-check.** Can you (1) derive the interval of the integrate-and-fire neuron, (2) classify a fixed point from a Jacobian, (3) compute a Tsodyks–Markram train by hand, (4) state when a rate network is stable, (5) compute a Fisher information, (6) compute a mutual information from a table, and (7) state what a PLV of 1 does and does not show?

**Common errors.** Mixing ms with s or Hz with rad/ms; updating variables one at a time instead of from the old state; judging stability from the entries rather than the eigenvalues; forgetting rectification when solving for fixed points; using natural logarithms for bits; averaging phases instead of unit vectors; confusing correlation between a rhythm and a behavior with causation.

@exam code
prompt: A depressing synapse (utilization fixed at `U`, recovery time constant `tau_D` in ms) drives a leaky membrane. Write `psp_after_spikes(spike_times, U, tau_D, w, tau_m)` that returns, for each spike in the sorted list `spike_times` (ms), the voltage deviation from rest (mV) just after that spike. Before each spike except the first, the voltage decays by `exp(-gap / tau_m)` and the resources recover, $x \leftarrow 1 - (1 - x)e^{-\text{gap}/\tau_D}$. At each spike the synaptic efficacy is `U * x`; add `w * U * x` (mV) to the voltage, then set $x \leftarrow x - U x$. Start with $x = 1$ and $V = 0$. For example, `psp_after_spikes([0.0], 0.4, 100.0, 5.0, 10.0)` returns `[2.0]`.

model:
```python
import math


def psp_after_spikes(spike_times, U, tau_D, w, tau_m):
    """Voltage deviation (mV) just after each spike of a depressing synapse."""
    x, V, last, out = 1.0, 0.0, None, []
    for t in spike_times:
        if last is not None:
            gap = t - last
            V *= math.exp(-gap / tau_m)
            x = 1.0 - (1.0 - x) * math.exp(-gap / tau_D)
        V += w * U * x
        x -= U * x
        out.append(V)
        last = t
    return out
```
hint: Decay the voltage and recover the resources over the gap first; then add the efficacy-weighted jump and deplete the resources.
solution: The voltage is the sum of decayed earlier jumps, and each jump shrinks because the resources $x$ are depleted. In the first test the second jump is smaller than the first, so the voltage grows by less than a naive sum of equal jumps: depression and the leak together make the response saturate with the spike number.

@exam self
prompt: A neuron in an association cortex fires at a higher rate during a one-second delay after a strong cue than after a weak cue, and the elevated rate stays nearly constant for the whole delay. One lab proposes a bistable recurrent attractor, and another proposes that the cue leaves a trace in short-term synaptic facilitation, with no persistent firing needed. For each model, write the key equations and parameters, say what it predicts about (a) the effect of a brief inhibitory pulse during the delay, (b) the effect of delay length, and (c) how much information about the cue the neuron's spike count carries, which you would estimate with a table of cue and spike-count bins. Then describe the experiment that best separates the two models.
hint: Use the bistable unit of week 9, the facilitation of week 5, the mutual information of week 11, and think about what a perturbation does to a fixed point compared with a slowly decaying variable.
solution: The attractor model is $\tau\,\dot r = -r + F(w r + h + u(t))$ with $w$ large enough for two stable fixed points; the cue is a pulse $u(t)$ that moves the state across the unstable threshold, after which the rate is held at the upper fixed point. The facilitation model has a rate that follows the input and a synaptic variable $u$ with $\dot u = -u/\tau_F$ and jumps $U(1 - u)$ at spikes: the cue raises $u$, and the elevated efficacy decays with $\tau_F$ (hundreds of milliseconds to seconds), so a probe input during the delay produces a larger response without any change of the baseline rate. (a) A brief inhibitory pulse that pushes the attractor below its threshold erases the memory permanently (the rate falls to the lower state and stays there), while in the facilitation model the pulse changes the rate transiently and leaves the synaptic trace nearly intact, so the later probe response recovers. (b) The attractor predicts a constant rate for as long as the delay lasts (until noise or drift moves the state), and the facilitation model predicts a decay with $\tau_F$, so longer delays reduce the trace. (c) The information is $I = H(R) - H(R \mid S)$ from the table of cue levels against spike-count bins; the attractor gives all-or-none counts and so at most about one bit for a binary cue, and the facilitation model gives graded information carried by synaptic efficacy that shows in the probe response and not in the delay-period spike count, so the information must be measured with a probe. The best separating experiment delivers a brief hyperpolarizing or optogenetic inhibitory pulse mid-delay and then tests both the spike rate and the response to a probe, since the models predict opposite combinations: permanent loss of both under the attractor, transient loss of rate with intact probe response under facilitation.

rubric: Describes the information measure from a table of cue against spike-count bins and uses it to compare the models.

@article
The leaky integrate-and-fire neuron fires when you tell it to. A real neuron makes the spike itself, from the voltage dependence of its channels. The **Hodgkin–Huxley model** (1952) explains the squid giant axon's action potential with four coupled equations, and it remains the template for conductance-based models. This lesson uses the convention of Dayan and Abbott (2001), in which the resting potential is near $-65$ mV.

### The equations

Let $V$ be the membrane potential (mV), time $t$ in ms, and let currents per unit area be in nA/mm². The membrane obeys

$$c_m \frac{dV}{dt} = -\bar g_L (V - E_L) - \bar g_K\, n^4 (V - E_K) - \bar g_{Na}\, m^3 h\,(V - E_{Na}) + \frac{I_e}{A},$$

with $c_m = 10$ nF/mm², conductances per area $\bar g_L = 3$, $\bar g_K = 360$ and $\bar g_{Na} = 1200$ µS/mm² (that is 0.003, 0.36 and 1.2 mS/mm²), and reversal potentials $E_L = -54.387$, $E_K = -77$ and $E_{Na} = 50$ mV. Units close: µS times mV is nA, and nA/mm² divided by nF/mm² is mV/ms. Each **gating variable** $x \in \{m, h, n\}$ lies between 0 and 1 and relaxes as

$$\frac{dx}{dt} = \alpha_x(V)(1 - x) - \beta_x(V)\,x, \qquad x_\infty = \frac{\alpha_x}{\alpha_x + \beta_x}, \qquad \tau_x = \frac{1}{\alpha_x + \beta_x}.$$

Here $m$ is the sodium **activation** gate (fast), $h$ the sodium **inactivation** gate (slower) and $n$ the potassium activation gate (slower). The rate functions, with $V$ in mV and rates in 1/ms, are

| gate | $\alpha$ | $\beta$ |
|---|---|---|
| $m$ | $0.1(V+40)/[1 - e^{-0.1(V+40)}]$ | $4\,e^{-0.0556(V+65)}$ |
| $h$ | $0.07\,e^{-0.05(V+65)}$ | $1/[1 + e^{-0.1(V+35)}]$ |
| $n$ | $0.01(V+55)/[1 - e^{-0.1(V+55)}]$ | $0.125\,e^{-0.0125(V+65)}$ |

The $\alpha_m$ and $\alpha_n$ expressions are $0/0$ at $V = -40$ and $V = -55$ mV; their limits are $1$ and $0.1$ per ms, which code must handle explicitly.

### Values at rest

At $V = -65$ mV the steady states are $m_\infty = 0.0529$, $h_\infty = 0.5961$ and $n_\infty = 0.3177$, with time constants $\tau_m = 0.237$ ms, $\tau_h = 8.52$ ms and $\tau_n = 5.46$ ms. Few sodium channels are open ($m^3 h \approx 9 \times 10^{-5}$) and a few percent of the potassium channels are ($n^4 \approx 0.010$). The resting potential is the voltage at which the net current of the three channel types is zero when the gates are at their steady states; a bisection on $i_m(V)$ finds $V_{\text{rest}} = -64.996$ mV.

### The action potential

A current $I_e/A$ above a threshold depolarizes the cell. Because $\tau_m$ is so short, $m$ follows $V$ almost instantly: sodium channels open, $E_{Na} = 50$ mV pulls $V$ upward, and the upswing feeds itself (positive feedback). Over the next millisecond $h$ falls (inactivation) and $n$ rises, so sodium current shuts down and potassium current repolarizes the membrane, overshooting to an **afterhyperpolarization** below rest. While $h$ is low and $n$ is high the cell is **refractory**, and this explains why the real refractory period is a property of channels rather than an extra rule. With $I_e/A = 100$ nA/mm² switched on at rest, a simulation reaches a peak of about $+40.8$ mV after $2.1$ ms.

### In code

Always update all four variables from the same old values, and use a time step well below $\tau_m = 0.24$ ms at rest (here $\Delta t = 0.02$ ms):

```python
import math


def alpha_m(V):
    x = V + 40.0
    return 1.0 if abs(x) < 1e-7 else 0.1 * x / (1.0 - math.exp(-0.1 * x))


def beta_m(V):
    return 4.0 * math.exp(-0.0556 * (V + 65.0))


def alpha_h(V):
    return 0.07 * math.exp(-0.05 * (V + 65.0))


def beta_h(V):
    return 1.0 / (1.0 + math.exp(-0.1 * (V + 35.0)))


def m_inf(V):
    return alpha_m(V) / (alpha_m(V) + beta_m(V))
```

Researchers use packages that integrate the same equations with adaptive solvers, but this fixed-step version is enough to reproduce the spike.

The model also has well-known limits: it describes one patch of membrane with space-clamped, voltage-independent reversal potentials, and the numerical rates above were fitted to one preparation at one temperature. Rates scale with temperature, and mammalian neurons have many more channel types.

@mistakes
- Updating $V$ first and then using the new $V$ to update the gates: use the old $V$ for every variable in one step, or the scheme is not a consistent Euler step.
- Forgetting the removable singularities at $V = -40$ and $V = -55$ mV, where the formulas give $0/0$ and the code raises a division error or returns nan.
- Mixing conductances in mS/mm² and µS/mm²: the same cell has $\bar g_{Na} = 1.2$ mS/mm² $= 1200$ µS/mm², and the factor 1000 changes the currents completely.
- Reading $m_\infty$ as the fraction of open channels: it is the steady state of one gate, and the open fraction is $m^3 h$ for sodium and $n^4$ for potassium.

model:
```python
import math


def alpha_m(V):
    x = V + 40.0
    return 1.0 if abs(x) < 1e-7 else 0.1 * x / (1.0 - math.exp(-0.1 * x))


def beta_m(V):
    return 4.0 * math.exp(-0.0556 * (V + 65.0))


def alpha_h(V):
    return 0.07 * math.exp(-0.05 * (V + 65.0))


def beta_h(V):
    return 1.0 / (1.0 + math.exp(-0.1 * (V + 35.0)))


def alpha_n(V):
    x = V + 55.0
    return 0.1 if abs(x) < 1e-7 else 0.01 * x / (1.0 - math.exp(-0.1 * x))


def beta_n(V):
    return 0.125 * math.exp(-0.0125 * (V + 65.0))


def hh_step(V, m, h, n, I_e, dt):
    """One Euler step of the Hodgkin-Huxley equations (all from old values)."""
    i_m = (3.0 * (V + 54.387) + 360.0 * n ** 4 * (V + 77.0)
           + 1200.0 * m ** 3 * h * (V - 50.0))
    dV = (-i_m + I_e) / 10.0
    dm = alpha_m(V) * (1.0 - m) - beta_m(V) * m
    dh = alpha_h(V) * (1.0 - h) - beta_h(V) * h
    dn = alpha_n(V) * (1.0 - n) - beta_n(V) * n
    return V + dt * dV, m + dt * dm, h + dt * dh, n + dt * dn
```
hint: Compute the membrane current and the four derivatives first, all from the old state, and only then add `dt` times each derivative.
solution: Computing every derivative before changing anything makes the update consistent. The first test shows that after 0.02 ms the voltage has moved $0.2$ mV while the gates barely change, because they are already at rest; the final test runs 20 ms and recovers the spike peak near $+40.8$ mV.

model:
```python
import math


def rates(V):
    x, y = V + 40.0, V + 55.0
    am = 1.0 if abs(x) < 1e-7 else 0.1 * x / (1.0 - math.exp(-0.1 * x))
    bm = 4.0 * math.exp(-0.0556 * (V + 65.0))
    ah = 0.07 * math.exp(-0.05 * (V + 65.0))
    bh = 1.0 / (1.0 + math.exp(-0.1 * (V + 35.0)))
    an = 0.1 if abs(y) < 1e-7 else 0.01 * y / (1.0 - math.exp(-0.1 * y))
    bn = 0.125 * math.exp(-0.0125 * (V + 65.0))
    return am, bm, ah, bh, an, bn


def i_m(V):
    am, bm, ah, bh, an, bn = rates(V)
    m, h, n = am / (am + bm), ah / (ah + bh), an / (an + bn)
    return (3.0 * (V + 54.387) + 360.0 * n ** 4 * (V + 77.0)
            + 1200.0 * m ** 3 * h * (V - 50.0))


def rest_potential(lo, hi, iters):
    """Zero of the steady-state membrane current, by bisection."""
    for _ in range(iters):
        mid = (lo + hi) / 2.0
        if i_m(lo) * i_m(mid) <= 0:
            hi = mid
        else:
            lo = mid
    return (lo + hi) / 2.0
```
hint: Keep the half of the bracket where the current changes sign. With no iterations the answer is simply the middle of the bracket.
solution: The steady-state current is negative just below rest (net inward) and positive above, so the zero lies where the sign changes. Each iteration halves the bracket, so forty iterations of a 30 mV bracket give a precision of about $3 \times 10^{-11}$ mV; the answer is near $-65$ mV as the convention intends.

@quiz self
prompt: In the Hodgkin–Huxley model a brief depolarization to $-50$ mV produces no spike while one to $-40$ mV does. Explain in terms of the gating variables and currents why the response is all-or-none, and why a second stimulus delivered 1 ms after a spike fails to produce a second spike of full size.
hint: Compare the inward sodium current with the outward potassium and leak currents just after the stimulus, and recall what $h$ and $n$ are doing after a spike.
solution: Just above rest, depolarization raises $m$ quickly, so the inward sodium current grows, but it also raises the outward potassium and leak currents. If the net current stays outward, $V$ returns to rest. Above a threshold the sodium current wins, the net current becomes inward, and the further depolarization opens more sodium channels, a regenerative loop, so the spike amplitude is set by the channels and $E_{Na}$ and not by the stimulus. One millisecond after a spike $h$ is still low (it recovers with $\tau_h$ of several milliseconds) and $n$ is still high, so fewer sodium channels are available and the potassium current is larger. Then the same stimulus no longer makes the net current inward, or produces only a smaller response; this is the refractory period of the neuron arising from the channel dynamics.

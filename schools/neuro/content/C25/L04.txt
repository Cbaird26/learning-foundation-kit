@article
The Hodgkin–Huxley model has four variables, which is hard to picture. But $m$ is fast and $h$ and $n$ move in a related way, so the dynamics can be squeezed into **two** variables: a fast voltage-like variable and a slow recovery variable. In two dimensions every trajectory can be drawn on a plane, and the reason a neuron fires, or does not, becomes visible. The **FitzHugh–Nagumo** (FHN) model is the standard example.

### The model

All quantities are dimensionless; time is in arbitrary units. With a fast variable $v$ (like voltage), a slow recovery variable $w$ and a constant input $I$,

$$\frac{dv}{dt} = v - \frac{v^3}{3} - w + I, \qquad \frac{dw}{dt} = \varepsilon\,(v + a - b\,w).$$

In this lesson $a = 0.7$, $b = 0.8$ and $\varepsilon = 0.08$ unless stated; $\varepsilon \ll 1$ makes $w$ slow compared with $v$. The cubic term gives positive feedback at small $v$ (the regenerative upstroke) and saturation at large $v$.

### Nullclines and fixed points

The **nullclines** are the curves where one derivative vanishes. The $v$-nullcline ($dv/dt = 0$) is the cubic $w = v - v^3/3 + I$, and the $w$-nullcline ($dw/dt = 0$) is the line $w = (v + a)/b$. A **fixed point** lies at an intersection. Substituting the line into the cubic gives

$$g(v) = v - \frac{v^3}{3} - \frac{v + a}{b} + I = 0 .$$

For $b < 1$, $g'(v) = 1 - v^2 - 1/b < 0$ for every $v$, so $g$ is strictly decreasing and there is exactly one fixed point, which can be found by bisection. For $I = 0$ it is $v^* = -1.1994$, $w^* = -0.6243$.

### Stability from the Jacobian

Near a fixed point, small deviations obey the linear system $\dot{\mathbf{x}} = \mathbf{J}\mathbf{x}$ with

$$\mathbf{J} = \begin{pmatrix} 1 - v^{*2} & -1 \\ \varepsilon & -\varepsilon b \end{pmatrix},$$

whose trace is $\tau = 1 - v^{*2} - \varepsilon b$ and determinant is $\Delta = -(1 - v^{*2})\varepsilon b + \varepsilon$. The eigenvalues are $\lambda = \tfrac{1}{2}\big(\tau \pm \sqrt{\tau^2 - 4\Delta}\big)$. The rules are: $\Delta < 0$ is a **saddle**; $\Delta > 0$ with $\tau < 0$ is stable and with $\tau > 0$ unstable; and within each, $\tau^2 - 4\Delta < 0$ gives a **spiral** (complex eigenvalues) and $\tau^2 - 4\Delta \ge 0$ gives a **node**.

| $I$ | $v^*$ | trace | determinant | type |
|---|---|---|---|---|
| 0 | −1.1994 | −0.503 | 0.108 | stable spiral |
| 0.3 | −0.9933 | −0.051 | 0.079 | stable spiral |
| 0.5 | −0.8048 | +0.288 | 0.057 | unstable spiral |

At $I = 0$ the eigenvalues are $-0.251 \pm 0.212\,i$: perturbations spiral back to rest, decaying at rate $0.25$ per unit time. At $I = 0.5$ the real part is positive, so the fixed point repels, and the trajectory settles onto a **limit cycle**: repetitive firing, with a peak $v \approx 2.0$.

### Excitability and the Hopf bifurcation

At $I = 0$ the fixed point is stable but the system is **excitable**: a small displacement decays, but a displacement beyond a threshold sends the trajectory on a large excursion (a spike) before it returns. The $v$-nullcline's middle branch acts as the threshold. Starting at $w = w^*$, a kick to $v = -0.8$ decays without a spike, while $v = -0.5$ reaches $v = 1.76$.

As $I$ increases, the trace $\tau$ crosses zero where $1 - v^{*2} = \varepsilon b$, that is $v^* = -\sqrt{1 - \varepsilon b} = -0.9675$, which gives $I_c = 0.331$. This is a **Hopf bifurcation**: a stable spiral loses stability and a limit cycle appears. For these parameters the fixed point regains stability at $I \approx 1.419$ (at $v^* = +0.9675$), so repetitive firing occurs for $0.331 < I < 1.419$; at higher $I$ the neuron is depolarized and silent, like a neuron in depolarization block.

### In code

Euler's method needs a step well below the fastest time scale of the model, here about 1 unit, so $\Delta t = 0.05$ is fine. Update both variables from the old $v$:

```python
def simulate_fhn(a, b, eps, I, v0, w0, dt, n_steps):
    """Euler trajectory of the FitzHugh-Nagumo model; returns the v values."""
    v, w, vs = v0, w0, [v0]
    for _ in range(n_steps):
        v, w = v + dt * (v - v ** 3 / 3 - w + I), w + dt * eps * (v + a - b * w)
        vs.append(v)
    return vs
```

The simultaneous assignment makes the second update use the old $v$. Reduced models of this kind are easier to analyze than Hodgkin–Huxley, but they are not quantitatively fitted to a particular channel set; they capture the geometry of excitability, not the conductances.

@example
title: Classifying a fixed point
problem: For $a = 0.7$, $b = 0.8$, $\varepsilon = 0.08$ and $I = 0.2$, the fixed point is at $v^* = -1.0694$. Classify it.
step: Compute $v^{*2} = 1.1436$, so $1 - v^{*2} = -0.1436$.
step: Trace: $\tau = -0.1436 - 0.08 \times 0.8 = -0.1436 - 0.064 = -0.2076$.
step: Determinant: $\Delta = -(-0.1436)(0.064) + 0.08 = 0.00919 + 0.08 = 0.0892$.
step: Discriminant: $\tau^2 - 4\Delta = 0.0431 - 0.3568 = -0.3137 < 0$, and $\tau < 0$ with $\Delta > 0$, so the fixed point is a stable spiral.
answer: A stable spiral, with eigenvalues $-0.104 \pm 0.280\,i$.

@mistakes
- Using the trace alone: a negative trace with a negative determinant is a saddle, which is unstable; check the determinant first.
- Reading nullclines as trajectories: a trajectory crosses the $v$-nullcline vertically and the $w$-nullcline horizontally, and fixed points are only the intersections.
- Updating $v$ and then using the new $v$ in the $w$ update: that is a different, less accurate scheme; use the old values for both.
- Expecting oscillation whenever the fixed point is unstable: instability of a spiral is what produces the limit cycle here, but for a node or a saddle the outcome needs more analysis.

```python
def fhn_fixed_point(a, b, I):
    """Fixed point (v*, w*) of the FitzHugh-Nagumo model for 0 < b < 1."""
    def g(v):
        return v - v ** 3 / 3 - (v + a) / b + I

    lo, hi = -3.0, 3.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        if g(lo) * g(mid) <= 0:
            hi = mid
        else:
            lo = mid
    v_star = (lo + hi) / 2.0
    return v_star, (v_star + a) / b
```
hint: For $b < 1$ the function $g$ is strictly decreasing, so it changes sign exactly once on the bracket; keep the half of the bracket where the sign changes.
solution: Bisection halves the bracket 60 times, giving a precision far below the test tolerance. The last test confirms that the point lies on the $v$-nullcline, $w = v - v^3/3$ for $I = 0$, and the $w$ value comes from the linear nullcline.

```python
def classify_fhn(a, b, eps, I):
    """Type of the fixed point of the FitzHugh-Nagumo model (0 < b < 1)."""
    lo, hi = -3.0, 3.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        g_lo = lo - lo ** 3 / 3 - (lo + a) / b + I
        g_mid = mid - mid ** 3 / 3 - (mid + a) / b + I
        if g_lo * g_mid <= 0:
            hi = mid
        else:
            lo = mid
    v = (lo + hi) / 2.0
    tr = 1.0 - v * v - eps * b
    det = -(1.0 - v * v) * eps * b + eps
    if det < 0:
        return 'saddle'
    kind = 'stable' if tr < 0 else 'unstable'
    return kind + (' node' if tr * tr - 4.0 * det >= 0 else ' spiral')
```
hint: First find $v^*$; then compute the trace and determinant from the Jacobian entries and test the determinant, the sign of the trace and the discriminant in that order.
solution: A negative determinant means eigenvalues of opposite sign (a saddle) whatever the trace. With a positive determinant, both eigenvalues have the sign of the trace, and complex eigenvalues (negative discriminant) give spirals. The FitzHugh–Nagumo Jacobian has determinant $\varepsilon(1 - b(1 - v^{*2}))$, which is positive for $b < 1$ and these ranges, so saddles do not occur here, but the function should still handle the case.

model:
```python
def period_from_trace(vs, dt):
    """Mean time between upward zero crossings of a sampled trace."""
    times = []
    for k in range(len(vs) - 1):
        if vs[k] < 0 <= vs[k + 1]:
            frac = -vs[k] / (vs[k + 1] - vs[k])
            times.append((k + frac) * dt)
    if len(times) < 2:
        return None
    gaps = [b - a for a, b in zip(times, times[1:])]
    return sum(gaps) / len(gaps)
```
hint: Collect the interpolated crossing times first; then average the differences between consecutive ones.
solution: A crossing needs the sample to be negative before and non-negative after, so a trace that starts above zero or only touches zero from above does not count. Linear interpolation places each crossing between samples; the fourth test has the trace reach exactly zero, which counts as a crossing at the later sample.

@quiz self
prompt: Using nullclines, explain why a FitzHugh–Nagumo neuron with $a = 0.7$, $b = 0.8$, $\varepsilon = 0.08$ is silent but excitable at $I = 0$ and fires repetitively at $I = 0.5$. Say where the fixed point sits on the cubic $v$-nullcline in each case and what the Jacobian says.
hint: The fixed point is where the line meets the cubic. Which branch is it on, and what is the sign of the real part of the eigenvalues?
solution: At $I = 0$ the line $w = (v + 0.7)/0.8$ meets the cubic $w = v - v^3/3$ on its left branch ($v < -1$), where the cubic slopes downward and $1 - v^{*2} < 0$. There the Jacobian has $\tau = -0.503$ and $\Delta = 0.108$, a stable spiral with eigenvalues $-0.25 \pm 0.21i$, so small perturbations decay. A large kick to the right of the middle branch makes $v$ grow quickly (the regenerative upstroke), the slow variable $w$ then increases, and the trajectory is pushed back over the right branch and down: a single spike, which is excitability. At $I = 0.5$ the cubic is shifted up and the intersection moves to $v^* = -0.805$, onto the rising middle branch just past the cubic's minimum at $v = -1$, where $1 - v^{*2} = 0.35$ exceeds $\varepsilon b = 0.064$. The trace becomes $+0.288$, the spiral is unstable and the trajectory settles on a limit cycle that goes around the cubic repeatedly, giving repetitive firing.

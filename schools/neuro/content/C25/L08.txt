@article
Cortical neurons receive thousands of excitatory inputs and thousands of inhibitory ones, yet they fire irregularly, and a modest change in sensory input does not set off runaway activity. Nearly every cortical circuit pairs recurrent excitation, which amplifies, with inhibition, which stabilizes. This lesson turns that pairing into two equations and reads off what they predict, including one prediction that sounds wrong: *adding drive to the inhibitory cells can lower their firing*.

### The excitatory–inhibitory model

Let $r_E$ and $r_I$ be the rates (Hz) of an excitatory and an inhibitory population, with time constants $\tau_E$ and $\tau_I$ (ms) and positive weights named by what they do:

$$\tau_E \dot r_E = -r_E + \big[w_{EE} r_E - w_{EI} r_I + h_E\big]_+, \qquad \tau_I \dot r_I = -r_I + \big[w_{IE} r_E - w_{II} r_I + h_I\big]_+ .$$

If both populations are active at the fixed point, it solves a linear system with $\mathbf{W} = \begin{pmatrix} w_{EE} & -w_{EI} \\ w_{IE} & -w_{II} \end{pmatrix}$. Let $D = (1 - w_{EE})(1 + w_{II}) + w_{EI} w_{IE}$. Then

$$r_E^* = \frac{(1 + w_{II})\,h_E - w_{EI}\,h_I}{D}, \qquad r_I^* = \frac{w_{IE}\,h_E + (1 - w_{EE})\,h_I}{D},$$

valid when both rates are positive. The Jacobian is

$$\mathbf{J} = \begin{pmatrix} (w_{EE} - 1)/\tau_E & -w_{EI}/\tau_E \\ w_{IE}/\tau_I & -(1 + w_{II})/\tau_I \end{pmatrix}.$$

For a $2\times 2$ system the fixed point is stable if and only if the trace is negative and the determinant is positive; when the discriminant is negative the approach is an oscillation. For $\tau_E = \tau_I$ the determinant is $D/\tau^2$.

### An example network

Take $w_{EE} = 1.5$, $w_{EI} = 1.2$, $w_{IE} = 2.0$, $w_{II} = 0.5$, $\tau_E = \tau_I = 10$ ms and inputs $h_E = 10$ Hz, $h_I = 5$ Hz. Then $D = (-0.5)(1.5) + 1.2 \times 2.0 = 1.65$, giving $r_E^* = 5.45$ Hz and $r_I^* = 10.61$ Hz. The trace is $-0.1$ per ms and the determinant $0.0165$ per ms$^2$, so the eigenvalues are $-0.05 \pm 0.118\,i$ per ms: stable, with damped oscillations of period about 53 ms. Excitation alone would be unstable, since $w_{EE} > 1$, but inhibition stabilizes it. This regime is called an **inhibition-stabilized network** (ISN): the excitatory subnetwork would be unstable by itself and is held in check by the inhibitory feedback.

### The paradoxical effect

How do the rates change when only the inhibitory population gets more input? Differentiating the fixed point with respect to $h_I$ gives

$$\frac{\partial r_I^*}{\partial h_I} = \frac{1 - w_{EE}}{D}, \qquad \frac{\partial r_E^*}{\partial h_I} = -\frac{w_{EI}}{D}.$$

In the stable regime $D > 0$, so excitation always falls, and the inhibitory rate falls too when $w_{EE} > 1$. With the numbers above, raising $h_I$ from 5 to 6 Hz changes $(r_E, r_I)$ from $(5.45, 10.61)$ to $(4.73, 10.30)$ Hz, and the slope $(1 - 1.5)/1.65 = -0.30$. The reason is that the excitatory cells' own recurrent excitation is so strong that silencing them reduces the drive to the inhibitory cells more than the extra input raises it. This **paradoxical effect** was predicted by Tsodyks and colleagues (1997), and observing it in a circuit, by stimulating inhibitory cells and seeing their rate fall, is a test that the circuit is inhibition-stabilized.

### Balanced input

Consider a neuron that receives $K$ excitatory and $K$ inhibitory Poisson inputs, with weights $+J/\sqrt{K}$ and $-gJ/\sqrt{K}$, at rates $r_E$ and $r_I$. Over a window of $T$ seconds the net input has mean $\sqrt{K}\,J\,T\,(r_E - g\,r_I)$ and variance $J^2 T\,(r_E + g^2 r_I)$, because Poisson counts have variance equal to their mean. The mean grows as $\sqrt{K}$ unless excitation and inhibition cancel ($r_E \approx g r_I$), while the fluctuations do not depend on $K$. In the **balanced network** of van Vreeswijk and Sompolinsky (1996) the network sets its own rates so that the mean cancels at leading order, leaving fluctuation-driven, irregular firing. Balance explains irregular spiking and the rapid, linear response of large networks; it is supported by recordings of excitatory and inhibitory currents that rise and fall together, though how close real cortex is to the balanced limit is debated.

### In code

```python
def ei_step(rE, rI, w, h, tau, dt):
    """One Euler step of the E-I rate model; w = (wEE, wEI, wIE, wII)."""
    wEE, wEI, wIE, wII = w
    xE = wEE * rE - wEI * rI + h[0]
    xI = wIE * rE - wII * rI + h[1]
    return (rE + dt / tau[0] * (-rE + max(0.0, xE)),
            rI + dt / tau[1] * (-rI + max(0.0, xI)))
```

Both new rates use the old pair, so the step is a simultaneous update.

@mistakes
- Assuming that more drive to the inhibitory cells always raises their rate: in an inhibition-stabilized network ($w_{EE} > 1$) it lowers it, while the excitatory rate always falls.
- Checking only the trace: a negative trace with a negative determinant is a saddle, which is unstable; stability needs a negative trace and a positive determinant.
- Using the fixed-point formulas without checking that both rates are positive: a negative value means that population is silent and the formulas no longer apply.
- Concluding that a balanced network has zero input: the large mean excitatory and inhibitory inputs cancel to leave a net input of order one, and the remaining fluctuations make the neuron fire.

model:
```python
def ei_stability(wEE, wEI, wIE, wII, tau_E, tau_I):
    """Trace, determinant and stability of the E-I rate model's Jacobian."""
    a = (wEE - 1.0) / tau_E
    b = -wEI / tau_E
    c = wIE / tau_I
    d = -(1.0 + wII) / tau_I
    trace = a + d
    det = a * d - b * c
    return trace, det, (trace < 0 and det > 0)
```
hint: Build the four Jacobian entries, then the trace $a + d$ and the determinant $ad - bc$.
solution: Stability of a $2\times 2$ linear system needs both eigenvalues to have negative real parts, which is equivalent to a negative trace and a positive determinant. The third test has zero trace and a negative determinant (a saddle); the fourth has a positive trace with a positive determinant (an unstable spiral or node).

```python
def simulate_ei(w, h, tau, dt, n_steps):
    """Final (rE, rI) of the E-I rate model after n_steps Euler steps."""
    wEE, wEI, wIE, wII = w
    rE, rI = 0.0, 0.0
    for _ in range(n_steps):
        xE = wEE * rE - wEI * rI + h[0]
        xI = wIE * rE - wII * rI + h[1]
        rE, rI = (rE + dt / tau[0] * (-rE + max(0.0, xE)),
                  rI + dt / tau[1] * (-rI + max(0.0, xI)))
    return rE, rI
```
hint: Compute both inputs from the old rates, then update both rates in one assignment.
solution: The final rates agree with the analytic fixed point, and the first two tests reproduce the paradoxical effect: raising $h_I$ from 5 to 6 lowers both rates. The third test checks the transient after five steps, where the inhibitory rate has risen more slowly than the excitatory rate.

model:
```python
import math


def balanced_stats(K, J, g, rE, rI, T):
    """Mean and standard deviation of balanced Poisson input over T seconds."""
    mean = math.sqrt(K) * J * T * (rE - g * rI)
    std = J * math.sqrt(T * (rE + g * g * rI))
    return mean, std
```
hint: Use the two formulas in the prompt; note that $K$ appears only in the mean.
solution: Quadrupling $K$ doubles the mean (from 2.0 to 4.0) but leaves the standard deviation unchanged, which is why a large network must cancel the mean to keep the neuron in a fluctuation-driven regime. In the last test $r_E = g\,r_I$, so the mean vanishes.

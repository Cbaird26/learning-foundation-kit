@article
Inject a steady current into a neuron and it starts to fire, regularly, like a metronome. A stronger current makes it fire faster, and below a certain current it does not fire at all. Can a single equation predict all of this? The **leaky integrate-and-fire** (LIF) model, whose idea goes back to Lapicque (1907), does it with a few lines of algebra.

### The membrane as a leaky capacitor

The cell membrane separates charge, like a **capacitor** with capacitance $C_m$, and lets some current leak through ion channels, like a **resistor** with resistance $R$. Without input, the voltage settles at the **resting potential** $E_L$. With an input current $I$, the membrane potential $V(t)$ obeys

$$\tau_m \frac{dV}{dt} = -(V - E_L) + R I, \qquad \tau_m = R\,C_m .$$

The **membrane time constant** $\tau_m$ sets how fast the voltage changes. Units fit together neatly: a resistance in megaohms (MΩ) times a current in nanoamperes (nA) gives millivolts (mV).

### Below threshold: exponential approach

Setting $dV/dt = 0$ gives the **steady-state voltage** $V_\infty = E_L + R I$. Starting from $V_0$, the solution approaches it exponentially:

$$V(t) = V_\infty + (V_0 - V_\infty)\, e^{-t/\tau_m} .$$

After one time constant the voltage has covered $1 - e^{-1} \approx 63\%$ of the distance to $V_\infty$.

### Threshold and reset

The model adds one rule: when $V$ reaches the **threshold** $V_{\text{th}}$, the neuron fires a spike, and $V$ is reset to $V_{\text{reset}}$. The spike's shape is not modeled, only its time. Take $E_L = -70$ mV, $R = 10$ MΩ, $\tau_m = 10$ ms, $V_{\text{th}} = -55$ mV and $V_{\text{reset}} = -70$ mV. The neuron can fire only if $V_\infty > V_{\text{th}}$, that is, if $I$ exceeds the **rheobase** $I_{\text{rh}} = (V_{\text{th}} - E_L)/R = 15/10 = 1.5$ nA. Below it the leak wins and the voltage stalls below threshold.

Solving $V(T) = V_{\text{th}}$ for the time $T$ to reach threshold from $V_{\text{reset}}$ gives

$$T = \tau_m \ln \frac{V_\infty - V_{\text{reset}}}{V_\infty - V_{\text{th}}}, \qquad f = \frac{1}{T},$$

the firing rate $f$ for a constant current (in hertz when $T$ is in seconds; with $T$ in ms, $f = 1000/T$).

| current $I$ (nA) | $V_\infty$ (mV) | interval $T$ (ms) | rate $f$ (Hz) |
|---|---|---|---|
| 1.5 | −55 | never fires | 0 |
| 2.0 | −50 | 13.86 | 72.1 |
| 3.0 | −40 | 6.93 | 144.3 |
| 5.0 | −20 | 3.57 | 280.4 |

This firing rate against current is the model's **f–I curve**: zero up to the rheobase, then rising steeply. Real neurons cannot fire arbitrarily fast; adding an **absolute refractory period** $t_{\text{ref}}$ after each spike, during which $V$ is held at reset, gives $f = 1/(t_{\text{ref}} + T)$.

### In code

The **Euler method** steps the equation forward by a small time step $\Delta t$: $V \leftarrow V + \frac{\Delta t}{\tau_m}\big(-(V - E_L) + R I\big)$.

```python
def simulate_lif(I, t_max, dt=0.1):
    """Spike times (ms) of an LIF neuron with constant current I (nA)."""
    tau, R, E_L, V_th, V_reset = 10.0, 10.0, -70.0, -55.0, -70.0
    V, spikes = E_L, []
    for k in range(int(round(t_max / dt))):
        V += dt / tau * (-(V - E_L) + R * I)
        if V >= V_th:
            spikes.append(round((k + 1) * dt, 10))
            V = V_reset
    return spikes

print(simulate_lif(2.0, 100.0))
```

This prints `[13.8, 27.6, 41.4, 55.2, 69.0, 82.8, 96.6]`: seven spikes about 13.8 ms apart, close to the exact 13.86 ms. The small difference comes from the time step; Euler steps are accurate only when $\Delta t$ is much smaller than $\tau_m$. Simulators such as Brian or NEST run the same model for thousands of neurons at once.

@example
title: Time to the first spike
problem: The neuron in the article ($E_L = -70$ mV, $R = 10$ MΩ, $\tau_m = 10$ ms, $V_{\text{th}} = -55$ mV) starts at rest, and a current of $2.5$ nA is switched on. When does it fire its first spike?
step: Find the steady state: $V_\infty = -70 + 10 \times 2.5 = -45$ mV, which is above threshold, so the neuron will fire.
step: Measure the distances from the steady state: the start is $-45 - (-70) = 25$ mV away, and the threshold is $-45 - (-55) = 10$ mV away.
step: Apply $T = \tau_m \ln(25/10) = 10 \ln 2.5 \approx 9.16$ ms.
step: Check with the solution: $V(9.16) = -45 + (-70 + 45)\,e^{-0.916} \approx -45 - 25 \times 0.400 = -55$ mV, the threshold.
answer: About $9.16$ ms after the current is switched on.

@mistakes
- Forgetting the leak: a perfect integrator ($\tau_m\,dV/dt = R I$) fires for any positive current, while the leaky model needs a current above the rheobase.
- Mixing units: megaohms times nanoamperes gives millivolts, and an interval in milliseconds gives a rate of $1000/T$ hertz, not $1/T$.
- Using a time step that is too large: Euler steps need $\Delta t \ll \tau_m$; with $\Delta t$ near $\tau_m$ the simulated voltage overshoots, and above $2\tau_m$ it oscillates and blows up.

model:
```python
import math


def time_to_spike(I, tau, R, E_L, V_th, V0):
    """Time (ms) for an LIF neuron to reach threshold from V0, or None."""
    if V0 >= V_th:
        return 0.0
    V_inf = E_L + R * I
    if V_inf <= V_th:
        return None
    return tau * math.log((V_inf - V0) / (V_inf - V_th))
```
hint: Compute $V_\infty$ first. If it does not exceed the threshold, the voltage only approaches it from below and never reaches it.
solution: Solving $V_\infty + (V_0 - V_\infty)e^{-T/\tau} = V_{\text{th}}$ gives $T = \tau \ln\big((V_\infty - V_0)/(V_\infty - V_{\text{th}})\big)$. The third test has $V_\infty$ exactly at threshold, which a strict `<` comparison gets wrong, and the fourth starts above reset, so the start voltage must be `V0`, not $E_L$.

model:
```python
def count_spikes(I, t_max, t_ref, dt=0.1):
    """Number of spikes of an LIF neuron with an absolute refractory period."""
    tau, R, E_L, V_th, V_reset = 10.0, 10.0, -70.0, -55.0, -70.0
    V, n, hold = E_L, 0, 0
    for _ in range(int(round(t_max / dt))):
        if hold > 0:
            hold -= 1
            continue
        V += dt / tau * (-(V - E_L) + R * I)
        if V >= V_th:
            n += 1
            V = V_reset
            hold = int(round(t_ref / dt))
    return n
```
hint: Keep a counter of steps still to skip. While it is positive, decrease it and leave $V$ alone; otherwise take an Euler step and check the threshold.
solution: The refractory counter freezes the voltage at reset for `t_ref` milliseconds after each spike, which lengthens every interval to about $t_{\text{ref}} + T$. Comparing the first two tests shows the effect: the same current gives 14 spikes without a refractory period and 11 with 2 ms.

@quiz self
prompt: A classmate says that a neuron that fires for any positive input current, however small, must lack a leak. Explain why the leaky integrate-and-fire model has a smallest current that makes it fire, what a perfect integrator would do instead, and describe a current-injection experiment that tells the two apart.
hint: Compare the steady-state voltage with the threshold in each model.
solution: In the leaky model the voltage approaches $V_\infty = E_L + R I$ and never passes it, so a current with $V_\infty \le V_{\text{th}}$ never produces a spike: the rheobase is $(V_{\text{th}} - E_L)/R$. A perfect integrator has no restoring term, so any positive current raises the voltage without limit and eventually reaches threshold, and its rate grows in proportion to the current, $f = I/(C_m (V_{\text{th}} - V_{\text{reset}}))$. To tell them apart, inject a series of constant currents of increasing size and record the rate: a leaky membrane shows no spikes below a clear rheobase and then a steep, curved rise, while a perfect integrator fires at low rates for small currents with a straight-line f–I curve. Measuring how the subthreshold voltage settles after a small current step, with a time constant $\tau_m = R C_m$, confirms the leak directly.

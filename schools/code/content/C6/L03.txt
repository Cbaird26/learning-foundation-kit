@article
Every digital circuit computes a **Boolean function**: it maps some input bits to output bits. Boolean algebra is the notation we use to specify, simplify and compare such functions before we draw a single gate.

### Operators and gates

There are three basic operations. **AND** ($A\cdot B$, or just $AB$) is 1 only when both inputs are 1. **OR** ($A+B$) is 1 when at least one input is 1. **NOT** ($\bar A$) flips a bit. Derived gates include **NAND** ($\overline{AB}$), **NOR** ($\overline{A+B}$), **XOR** ($A\oplus B$, 1 when the inputs differ) and **XNOR** (1 when they are equal). In Python, `&`, `|`, `^` and `1 - a` act on single bits.

A **truth table** lists the output for every input combination; a function of $n$ inputs has $2^n$ rows and there are $2^{2^n}$ distinct such functions.

### Identities

| name | AND form | OR form |
|---|---|---|
| identity | $A\cdot1=A$ | $A+0=A$ |
| null | $A\cdot0=0$ | $A+1=1$ |
| idempotent | $AA=A$ | $A+A=A$ |
| complement | $A\bar A=0$ | $A+\bar A=1$ |
| commutative, associative | as for ordinary algebra | as for ordinary algebra |
| distributive | $A(B+C)=AB+AC$ | $A+BC=(A+B)(A+C)$ |
| absorption | $A(A+B)=A$ | $A+AB=A$ |
| De Morgan | $\overline{AB}=\bar A+\bar B$ | $\overline{A+B}=\bar A\,\bar B$ |

Two further consequences are used constantly: $AB+A\bar B=A$ (combining) and $A+\bar AB=A+B$.

Unlike ordinary algebra, the OR form of the distributive law also holds, and the complement of a product is the *sum* of complements, not the product of complements. Any identity can be proved by checking all rows of a truth table, which is exactly what a program can do.

### Sum of products

A **minterm** is an AND of every variable, each plain or complemented, that is 1 on exactly one row. Any function equals the OR of the minterms of its 1-rows: the canonical **sum of products** (SOP). The 3-input majority function (1 when at least two inputs are 1) has minterms on rows 011, 101, 110 and 111, so

$$M = \bar A BC + A\bar B C + AB\bar C + ABC .$$

SOP is correct but wasteful. Applying $X+X=X$ and the combining rule gives the minimal form $M = AB + AC + BC$. A **Karnaugh map** automates this: it arranges the truth table so that cells differing in one variable are adjacent (rows and columns ordered 00, 01, 11, 10), and each group of $2^k$ adjacent 1-cells (a power of two, possibly wrapping around the edges) becomes one product term with $k$ fewer variables.

### Universality

A set of gates is **functionally complete** if it can build every function. NAND alone suffices:

- $\bar A = \overline{AA}$, so NOT is `nand(a, a)`;
- $AB = \overline{\overline{AB}}$, so AND is a NAND followed by NOT;
- $A+B=\overline{\bar A\,\bar B}$ (De Morgan), so OR is `nand(nand(a, a), nand(b, b))`.

NOR is also complete. Real chips are built mostly from NAND and NOR gates for this reason, plus the fact that in CMOS they need fewer transistors than AND and OR.

@example
title: Simplifying with identities
problem: Simplify $F=\bar A B + AB + A\bar B$.
step: Group the first two terms and factor out $B$: $\bar AB+AB = (\bar A + A)B$.
step: By the complement law $\bar A + A = 1$, so the group equals $B$ and $F = B + A\bar B$.
step: Apply $X + \bar X Y = X + Y$ with $X=B$ and $Y=A$ (note $A\bar B=\bar B A$): $F = B + A$.
step: Check on the rows: $F$ is 0 only when $A=B=0$, which matches $A+B$.
answer: $F=A+B$

@example
title: From a truth table to gates
problem: A circuit has inputs $A,B$ and output $Z=1$ exactly when $A$ and $B$ differ. Write $Z$ as a sum of products and rewrite it using only NAND.
step: The 1-rows are $(A,B)=(0,1)$ and $(1,0)$, with minterms $\bar AB$ and $A\bar B$, so $Z=\bar AB+A\bar B$ (this is XOR).
step: Let $N=\overline{AB}$. Then $Z = \overline{\,\overline{A N}\cdot\overline{B N}\,}$.
step: Check $A=B=1$: $N=0$, so $AN=BN=0$, both NANDs are 1, and the last NAND gives 0. Check $A=1,B=0$: $N=1$, $AN=1$, $BN=0$, the NANDs are 0 and 1, so $Z=1$.
step: This uses four NAND gates in total: one for $N$, two for $\overline{AN}$ and $\overline{BN}$, and one to combine them.
answer: $Z = \overline{\,\overline{A\,\overline{AB}}\cdot\overline{B\,\overline{AB}}\,}$ (four NAND gates)

@mistakes
- Writing De Morgan's law as $\overline{AB}=\bar A\,\bar B$; the complement of AND is the OR of the complements, $\bar A+\bar B$.
- Reading $A+BC$ as $(A+B)C$: AND binds tighter than OR, so parentheses matter.
- Grouping Karnaugh-map cells in sizes that are not powers of two, or forgetting that the map wraps around its edges.
- Concluding two expressions are equal after checking only some rows of the truth table.

Row `i` supplies the bits of `i` to `f` with the most significant bit as the first argument, so for `n = 2`, row 1 means `f(0, 1)` and row 2 means `f(1, 0)`. Example: for XOR on two inputs the answer is `[1, 2]`.
starter:
```python
def minterms(f, n):
    pass
```
tests:
```python
assert minterms(lambda a, b: a & b, 2) == [3]
assert minterms(lambda a, b: a ^ b, 2) == [1, 2]
assert minterms(lambda a: 1 - a, 1) == [0]
assert minterms(lambda a, b, c: int(a + b + c >= 2), 3) == [3, 5, 6, 7]
assert minterms(lambda a, b, c: 0, 3) == []
assert minterms(lambda a, b, c: a, 3) == [4, 5, 6, 7]
```
model:
```python
def minterms(f, n):
    rows = []
    for i in range(2 ** n):
        bits = [(i >> (n - 1 - k)) & 1 for k in range(n)]
        if f(*bits):
            rows.append(i)
    return rows
```
hint: Loop over every row number `i` and turn it into a list of `n` bits.
hint: Bit `k` of the argument list (counting from the first argument) is `(i >> (n - 1 - k)) & 1`. Call `f(*bits)`.
solution: For each `i` in `range(2**n)`, extract the bits most significant first, call `f` with them, and keep `i` when the result is truthy. Because `i` increases, the list is already sorted.

tests:
```python
assert equivalent(lambda a, b: 1 - (a & b), lambda a, b: (1 - a) | (1 - b), 2) is True
assert equivalent(lambda a, b: 1 - (a & b), lambda a, b: (1 - a) & (1 - b), 2) is False
```

model:
```python
def equivalent(f, g, n):
    for i in range(2 ** n):
        bits = [(i >> k) & 1 for k in range(n)]
        if f(*bits) != g(*bits):
            return False
    return True
```
hint: Try every one of the $2^n$ input combinations.
hint: Return `False` as soon as the outputs differ; return `True` after the loop.
solution: Enumerate all $2^n$ rows, building the argument list from the bits of the row number, and compare the two outputs. An identity is proved exactly when no row disagrees.

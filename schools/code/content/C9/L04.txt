@article
People use names such as `www.example.org`; routers use IP addresses. The **Domain Name System (DNS)** maps one to the other. It is a distributed database of **resource records** (RRs), queried by an application-layer protocol that normally runs over UDP port 53 (and over TCP port 53 when a response is too large or for zone transfers). DNS also provides host aliasing, mail-server lookup and a way to spread load across several servers.

### The hierarchy

Names are read right to left: `www.example.org.` has the **root** (the final dot, usually omitted), the **top-level domain** (TLD) `org`, the **domain** `example.org`, and the host label `www`. Responsibility is delegated down the tree. There are three kinds of servers:

- **Root servers** know the servers for each TLD.
- **TLD servers** (`com`, `org`, `uk`, ...) know the **authoritative** servers for each domain below them.
- **Authoritative servers** hold the actual records for a domain.

A host's operating system asks a **recursive resolver** (supplied by the network or a public service) to do the work. The resolver then performs **iterative** queries: it asks a root server, which does not answer but returns a **referral** (the NS records of the `org` servers); it asks a TLD server, which returns a referral to the authoritative servers for `example.org`; it asks one of those, which returns the answer. Finally the resolver returns the answer to the client, which sent a single **recursive** query.

### Resource records

A record is `(name, type, class, TTL, data)`. Important types:

| Type | Data |
|---|---|
| A | an IPv4 address |
| AAAA | an IPv6 address |
| CNAME | the canonical name of an alias |
| NS | the name of an authoritative server for a zone |
| MX | a mail server (with a preference number; lower is preferred) |
| TXT | text, used for verification and email policy |

### Caching

Every record carries a **TTL** in seconds. A resolver keeps a record until the TTL expires, so repeated lookups are answered without contacting the hierarchy. Caching is what makes DNS scale, and also why a changed record takes up to a TTL to be seen everywhere. Servers also cache referrals, so root servers are rarely contacted for popular TLDs.

### The message format

A DNS message starts with a 12-byte header (a 16-bit ID, flags, and four 16-bit counts for questions, answers, authority and additional records), followed by those four sections. A name is written as a sequence of **labels**, each a length byte followed by that many characters, ending with a zero byte: `www.example.org` is `\x03www\x07example\x03org\x00`. Each label is at most 63 bytes and a whole name at most 255 bytes. DNS can be signed with **DNSSEC**, which lets a resolver verify that a record is authentic, and queries can be encrypted with DNS over TLS (port 853) or DNS over HTTPS.

### SMTP, IMAP and DHCP

**SMTP** (Simple Mail Transfer Protocol) pushes mail over TCP: between mail servers on port 25, and from a user's mail client to its server on the submission port 587. It is a text protocol with numeric reply codes:

```text
S: 220 mail.example.org ESMTP ready
C: EHLO client.example.com
S: 250 mail.example.org greets client.example.com
C: MAIL FROM:<alice@example.com>
S: 250 OK
C: RCPT TO:<bob@example.org>
S: 250 OK
C: DATA
S: 354 End data with <CR><LF>.<CR><LF>
C: Subject: Hello
C:
C: Hi Bob.
C: .
S: 250 OK queued
C: QUIT
S: 221 Bye
```

SMTP only delivers mail to the recipient's server. The user reads it with a **pull** protocol such as **IMAP** (port 143, or 993 with TLS), which keeps messages and folders on the server. **DHCP** is an application-layer protocol on UDP (server port 67, client port 68) that gives a new host an IP address, subnet mask, default gateway and DNS resolver address.

@example
title: Tracing a DNS lookup with a cold cache
problem: A client asks its recursive resolver for the A record of `www.example.org`; the resolver's cache is empty. List the messages.
step: The client sends one recursive query `www.example.org A` to the resolver (message 1).
step: The resolver queries a root server; the root replies with a referral listing the NS records of the `org` TLD servers, with their addresses.
step: The resolver queries a `org` TLD server; it replies with a referral to the authoritative servers of `example.org`.
step: The resolver queries an authoritative server for `example.org`; it replies with the A record and a TTL (for example 300 s). The resolver caches it.
step: The resolver sends the answer to the client. In total there are 3 query-response pairs between the resolver and servers plus 1 pair with the client: 8 messages.
answer: 8 messages: 1 pair client-resolver, then root, TLD and authoritative pairs.

@example
title: Encoding a name
problem: Write the wire format of `mail.example.org`.
step: Split into labels: `mail`, `example`, `org`.
step: Prefix each label with its length: `\x04mail`, `\x07example`, `\x03org`.
step: End with the zero-length root label `\x00`.
step: Together: `\x04mail\x07example\x03org\x00`, which is $1 + 4 + 1 + 7 + 1 + 3 + 1 = 18$ bytes.
answer: `\x04mail\x07example\x03org\x00` (18 bytes)

@mistakes
- Thinking that the client queries the root servers itself. A host sends one recursive query to its resolver, which does the iterative work.
- Believing that a root server returns the final IP address. It returns a referral to the next level.
- Treating CNAME as an address. A CNAME points to another name that must be resolved further.
- Forgetting the TTL: when a record is changed, caches continue to give the old value until the TTL has expired.

@practice code
prompt: Write a class `DnsCache` that models a TTL cache. `put(name, address, ttl, now)` stores a record that expires at time `now + ttl`; `get(name, now)` returns the address if `now` is strictly before the expiry time and `None` otherwise (also for names never stored). Names are case-insensitive. A later `put` for the same name replaces the earlier record. Time is passed in as an argument, in seconds.
starter:
```python
class DnsCache:
    pass
```
tests:
```python
c = DnsCache()
c.put("Example.com", "93.184.216.34", 300, 1000)
assert c.get("example.com", 1000) == "93.184.216.34"
assert c.get("EXAMPLE.COM", 1299) == "93.184.216.34"
assert c.get("example.com", 1300) is None
assert c.get("other.org", 1000) is None
c.put("example.com", "198.51.100.7", 60, 2000)
assert c.get("example.com", 2059) == "198.51.100.7"
assert c.get("example.com", 2060) is None
```
model:
```python
class DnsCache:
    def __init__(self):
        self._records = {}

    def put(self, name, address, ttl, now):
        self._records[name.lower()] = (address, now + ttl)

    def get(self, name, now):
        entry = self._records.get(name.lower())
        if entry is None:
            return None
        address, expires = entry
        if now < expires:
            return address
        del self._records[name.lower()]
        return None
```
hint: Store each record under the lower-cased name together with its expiry time.
hint: In `get`, compare `now` with the stored expiry time using `<`, so a record is valid for exactly `ttl` seconds.
solution: Keep a dictionary from lower-case name to `(address, now + ttl)`. `get` returns the address only while `now < expires`; an expired entry is removed and `None` is returned.

prompt: Write `decode_name(data, offset=0)` that reads a DNS name in wire format from the bytes `data`, starting at index `offset`, and returns a tuple `(name, next_offset)`. `name` is the labels joined with dots and no trailing dot (the root gives an empty string); `next_offset` is the index just after the terminating zero byte. You may assume there is no name compression.
starter:
```python
def decode_name(data, offset=0):
    pass
```
tests:
```python
wire = b"\x03www\x07example\x03com\x00"
assert decode_name(wire) == ("www.example.com", 17)
assert decode_name(b"XX" + wire, 2) == ("www.example.com", 19)
assert decode_name(b"\x00") == ("", 1)
assert decode_name(b"\x01a\x00rest") == ("a", 3)
```
model:
```python
def decode_name(data, offset=0):
    labels = []
    pos = offset
    while data[pos] != 0:
        length = data[pos]
        labels.append(data[pos + 1:pos + 1 + length].decode("ascii"))
        pos += 1 + length
    return ".".join(labels), pos + 1
```
hint: Read a length byte, then that many characters, and repeat until the length is 0.
hint: When you see the zero byte, the next offset is one past it.
solution: Loop reading a length byte and then that many bytes as a label until a zero length appears; join the labels with dots and return the position after the zero byte.

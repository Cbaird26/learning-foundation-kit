@article
The **link layer** moves a datagram across **one link** between adjacent nodes, in a **frame**. Its services include **framing** (marking where a frame begins and ends and adding addresses), **medium access control** when a medium is shared, **error detection** and sometimes **reliable delivery** (common on wireless links, rare on wired ones).

### Error detection

The sender appends redundant bits and the receiver checks them. **Parity** adds one bit so that the number of 1s is even (or odd); it detects any odd number of flipped bits and misses even numbers. The **Internet checksum** (week 5) is simple and weak. The link layer uses a **cyclic redundancy check (CRC)**, which is strong and cheap in hardware. Pick a **generator** $G$ of $r + 1$ bits (with leading bit 1). The sender appends $r$ zero bits to the data $D$, divides the result by $G$ using **modulo-2 arithmetic** (subtraction is XOR) and appends the $r$-bit remainder; the frame sent is divisible by $G$. The receiver divides the frame by $G$ and any nonzero remainder means an error. An $r$-bit CRC detects all burst errors of up to $r$ bits and all errors with an odd number of bits if $G$ has a factor $x + 1$. Ethernet uses the 32-bit CRC-32 as its **frame check sequence**.

A division example: data `1101011011`, generator `10011` ($r = 4$): append `0000` giving `11010110110000`, divide modulo 2, and the remainder is `1110`.

### MAC addresses and ARP

Each network interface has a 48-bit **MAC address**, written as six hex bytes (`00:1a:2b:3c:4d:5e`). The broadcast address is `ff:ff:ff:ff:ff:ff`. In the first byte, bit 0 (least significant) is 1 for **group** (multicast and broadcast) addresses and bit 1 is 1 for **locally administered** addresses. The **Address Resolution Protocol (ARP)** maps an IP address to a MAC address on the same link: the host broadcasts "who has 10.0.0.7?", and the owner replies by unicast. Replies are cached for a short time. ARP has no authentication, which allows ARP spoofing on a local network.

### Ethernet

An Ethernet frame is a preamble (7 bytes) and start delimiter (1 byte), then destination MAC (6), source MAC (6), EtherType (2, such as `0x0800` for IPv4 or `0x86DD` for IPv6), payload (46 to 1500 bytes) and the 4-byte FCS. The minimum frame is $14 + 46 + 4 = 64$ bytes; short payloads are padded. Early Ethernet shared one cable and used **CSMA/CD**: a station senses the medium, transmits when idle, detects a collision while sending, aborts and waits a random time chosen by **binary exponential backoff**. The 64-byte minimum guarantees that a sender is still transmitting when news of a collision returns. Today's Ethernet is **switched** and full duplex: each link connects one host to a switch port, so there are no collisions and CSMA/CD is unused.

### Switches

A **switch** forwards frames by destination MAC address and is **self-learning**: it keeps a table mapping MAC addresses to ports.

1. When a frame arrives on port $p$ from source $S$, record "S is on $p$".
2. If the destination is the broadcast address or is not in the table, **flood**: send the frame out all ports except $p$.
3. If the destination is in the table on port $q$: if $q = p$ **filter** (drop it, the destination is on the same segment), otherwise **forward** it out of $q$ only.

Table entries expire after a timeout so that moved hosts are re-learned. Switches are plug and play, isolate collision domains and forward without looking at IP. A **router** differs: it connects different IP networks, forwards by IP address and does not forward broadcasts. **VLANs** (IEEE 802.1Q) split one physical switch into several broadcast domains.

### Wi-Fi

Wi-Fi is IEEE 802.11. Hosts associate with an **access point**. A radio cannot listen while it transmits, so Wi-Fi uses **CSMA/CA** (collision avoidance): a station waits until the channel is idle, then waits a random **backoff** before transmitting, and the receiver replies with a link-layer **ACK**, with retransmission if none arrives. **Hidden terminals** (two stations that cannot hear each other but both reach the access point) cause collisions; an optional **RTS/CTS** exchange reserves the channel. Generations are named Wi-Fi 5 (802.11ac), Wi-Fi 6 (802.11ax; Wi-Fi 6E adds the 6 GHz band) and Wi-Fi 7 (802.11be); security should use WPA3 or at least WPA2.

@example
title: Computing a CRC
problem: Compute the CRC remainder for data `101101` with generator `1011`.
step: The generator has 4 bits, so $r = 3$. Append three zeros to the data: `101101000`.
step: The leading bit is 1, so XOR the generator `1011` into the first four bits: `1011` XOR `1011` = `0000`, which leaves `000001000`.
step: Skip the zero bits. The next 1 is at the sixth position, so XOR `1011` into the last four bits `1000`: `1000` XOR `1011` = `0011`, leaving `000000011`.
step: No leading 1 remains in the first six positions, so the remainder is the last three bits: `011`. The frame sent is `101101011`.
answer: `011`

@example
title: A learning switch at work
problem: A switch with ports 1, 2 and 3 starts with an empty table. Host P (port 1) sends a frame to Q, Q (port 2) replies to P, then P sends to Q again. What does the switch do each time?
step: First frame, P to Q on port 1: learn "P is on port 1". Q is unknown, so flood to ports 2 and 3.
step: Reply, Q to P on port 2: learn "Q is on port 2". P is known on port 1, so forward only to port 1.
step: Second frame, P to Q: Q is known on port 2, so forward only to port 2; port 3 sees nothing.
answer: flood to ports 2 and 3; forward to port 1; forward to port 2

@mistakes
- Treating the switch table as an IP routing table. A switch table maps MAC addresses to ports.
- Forgetting to learn the source address before forwarding. A switch learns from every arriving frame.
- Flooding a frame back out of the port it arrived on.
- Saying that switched Ethernet needs CSMA/CD. Full-duplex links to switches have no collisions.

tests:
```python

assert crc_remainder("1101011011", "10011") == "1110"
assert crc_remainder("11010011101100", "1011") == "100"
```

model:
```python
def crc_remainder(data, generator):
    r = len(generator) - 1
    bits = [int(c) for c in data + "0" * r]
    gen = [int(c) for c in generator]
    for i in range(len(data)):
        if bits[i]:
            for j, g in enumerate(gen):
                bits[i + j] ^= g
    return "".join(str(b) for b in bits[len(data):])
```
hint: Work on a list of bits: wherever the current bit is 1, XOR the generator into the bits starting there.
hint: Only the first `len(data)` positions can start a division step; the remainder is the last `r` bits.
solution: Convert the padded data to a list of bits; for each of the first `len(data)` positions that holds a 1, XOR the generator bits into the list starting at that position. What remains in the last `r` positions is the remainder.

@practice code
prompt: Write a class `Switch(ports)` that models a self-learning Ethernet switch; `ports` is a list of port numbers. The method `receive(in_port, src, dst)` first learns that `src` is reachable via `in_port` (replacing any older entry) and then returns the sorted list of ports the frame is sent out of: if `dst` is the broadcast address `"ff:ff:ff:ff:ff:ff"` or has not been learned, all ports except `in_port`; if `dst` is known on a port other than `in_port`, just that port; if `dst` is known on `in_port`, the empty list (the frame is filtered).
starter:
```python
class Switch:
    pass
```
tests:
```python
s = Switch([1, 2, 3, 4])
assert s.receive(1, "A", "B") == [2, 3, 4]
assert s.receive(2, "B", "A") == [1]
assert s.receive(1, "A", "B") == [2]
assert s.receive(3, "C", "ff:ff:ff:ff:ff:ff") == [1, 2, 4]
assert s.receive(2, "D", "B") == []
assert s.receive(4, "B", "D") == [2]
```
model:
```python
class Switch:
    def __init__(self, ports):
        self.ports = sorted(ports)
        self.table = {}

    def receive(self, in_port, src, dst):
        self.table[src] = in_port
        if dst == "ff:ff:ff:ff:ff:ff" or dst not in self.table:
            return [p for p in self.ports if p != in_port]
        out = self.table[dst]
        return [] if out == in_port else [out]
```
hint: Learn first, then decide: the table is a dictionary from address to port.
hint: Flood when the destination is the broadcast address or unknown; otherwise compare the learned port with `in_port`.
solution: Update `table[src] = in_port`, then flood (all ports but `in_port`) for broadcast or unknown destinations, forward to the single learned port if it differs from `in_port`, and filter otherwise. In the last test B has moved to port 4, so the switch relearns it, and D is still on port 2.

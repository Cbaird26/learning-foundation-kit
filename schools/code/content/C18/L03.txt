@article
Uninformed search wastes effort in every direction. A **heuristic function** $h(n)$ estimates the cost of the cheapest path from the state of node $n$ to a goal, and lets search prefer promising nodes. The true cost is written $h^*(n)$.

### Greedy best-first and A*

**Greedy best-first search** expands the node with the smallest $h(n)$. It is fast when the heuristic is good, but it is neither optimal nor, in graph search with cycles and no explored set, complete: it ignores the cost already paid.

**A\*** orders the frontier by
$$f(n) = g(n) + h(n),$$
the cost so far plus the estimated cost to go, so $f(n)$ estimates the cost of the cheapest solution through $n$. It is **uniform-cost search with $h$ added to the priority**; with $h = 0$ the two coincide.

```python
import heapq

def a_star(graph, h, start, goal):
    frontier = [(h[start], 0, [start])]
    best_g = {}
    while frontier:
        f, g, path = heapq.heappop(frontier)
        node = path[-1]
        if node == goal:
            return g, path
        if node in best_g and best_g[node] <= g:
            continue
        best_g[node] = g
        for nxt, cost in graph[node]:
            new_g = g + cost
            heapq.heappush(frontier, (new_g + h[nxt], new_g, path + [nxt]))
    return None
```

### Admissible and consistent heuristics

A heuristic is **admissible** if it never overestimates: $0 \le h(n) \le h^*(n)$ for every node $n$, which forces $h = 0$ at goals. It is **consistent** (monotone) if for every node $n$ and successor $n'$ reached by action $a$,
$$h(n) \le c(n, a, n') + h(n').$$
This is a triangle inequality.

**Theorem.** A consistent heuristic with $h(\text{goal}) = 0$ is admissible. *Proof.* Take an optimal path $n = n_0, n_1, \dots, n_k$ with $n_k$ a goal. Consistency gives $h(n_i) \le c_i + h(n_{i+1})$. Adding these inequalities, the intermediate $h$ terms cancel, leaving $h(n) \le \sum c_i + h(n_k) = h^*(n)$. $\square$

The converse fails: an admissible heuristic can be inconsistent. The results to remember:

- A\* **tree search** is optimal if $h$ is admissible.
- A\* **graph search** (with an explored set that never reopens nodes) is optimal if $h$ is consistent. The code above avoids the requirement by reopening a state whenever a cheaper path to it is found.
- With a consistent $h$, the values of $f$ never decrease along a path, so A\* expands nodes in nondecreasing order of $f$ and the first time it removes a goal, the path is optimal.
- A\* is **optimally efficient**: with a given consistent heuristic, no other optimal algorithm that uses the same information is guaranteed to expand fewer nodes. It can still take exponential time and space in the worst case, and memory is usually the limit.

### Designing heuristics

A **relaxed problem** has fewer restrictions on actions; the exact cost in the relaxed problem is an admissible, and in fact consistent, heuristic for the original. For the 8-puzzle, "a tile may move to any adjacent square, even if occupied" gives the **Manhattan distance** (the sum, over tiles, of the horizontal plus vertical distance to the goal square), and "a tile may jump anywhere" gives the **number of misplaced tiles**. Heuristic $h_2$ **dominates** $h_1$ if $h_2(n) \ge h_1(n)$ for all $n$, both being admissible. A dominating heuristic never expands more nodes in A\*, so take the larger one (or the maximum of several admissible heuristics, which is itself admissible). Manhattan distance dominates misplaced tiles.

title: Running A* by hand
problem: Edges: S to A (2), S to B (3), A to C (2), B to C (2), C to G (4), B to G (7). Heuristic: h(S) = 7, h(A) = 5, h(B) = 4, h(C) = 3, h(G) = 0. Run A* from S to G. Discard a generated node whose g is not better than the best g already known for that state.
step: Expand S (g = 0, f = 7). Generate A with g = 2, f = 2 + 5 = 7, and B with g = 3, f = 3 + 4 = 7.
step: Expand A (f = 7). Generate C with g = 4, f = 4 + 3 = 7.
step: Expand B (f = 7). C through B has g = 5, worse than 4, so discard it. Generate G with g = 3 + 7 = 10, f = 10.
step: Expand C (g = 4, f = 7). Generate G with g = 8, f = 8, better than 10.
step: The frontier has G with f = 8 and G with f = 10. Remove G (f = 8): it is the goal.
answer: Path S, A, C, G with cost 8.

@example
title: Is this heuristic admissible and consistent?
problem: A graph has edges S to A (1), A to G (3) and S to G (5). With h(S) = 4, h(A) = 3 and h(G) = 0, decide whether h is admissible and whether it is consistent.
step: True costs to the goal: h*(G) = 0, h*(A) = 3, and h*(S) = min(5, 1 + 3) = 4.
step: Admissible: 4 is at most 4, 3 is at most 3 and 0 is at most 0, so no value overestimates.
step: Consistency on each edge. S to A: h(S) = 4 is at most 1 + h(A) = 4. A to G: h(A) = 3 is at most 3 + 0. S to G: h(S) = 4 is at most 5 + 0.
step: Every edge satisfies the inequality.
answer: Admissible and consistent.

@mistakes
- Believing an admissible heuristic is automatically consistent; graph search with an explored set that never reopens nodes can return a non-optimal path with an inconsistent one.
- Using $h = $ Manhattan distance when moves can be diagonal at cost 1: it can overestimate, so it is not admissible.
- Stopping A* when a goal is generated instead of when it is removed from the frontier.
- Treating greedy best-first search as optimal, or using $f = g + h$ with an $h$ that is "usually" an underestimate.

@practice ms
prompt: Moves on an unobstructed grid go to any of the 8 neighbouring squares (including diagonals), each with cost 1. Which heuristics for the cost to reach a goal square are admissible? Let $\Delta x$ and $\Delta y$ be the absolute coordinate differences to the goal.
choice: Manhattan distance, $\Delta x + \Delta y$
choice*: Chebyshev distance, $\max(\Delta x, \Delta y)$
choice: Euclidean distance, $\sqrt{\Delta x^2 + \Delta y^2}$
choice*: The constant $0$
choice*: Half the Manhattan distance, $(\Delta x + \Delta y)/2$

solution: The true cost is the Chebyshev distance. Manhattan distance overestimates on a diagonal: a displacement of (1, 1) costs one move but has Manhattan distance 2. Euclidean distance also overestimates there, since $\sqrt{2} > 1$. Half the Manhattan distance is at most $\max(\Delta x, \Delta y)$, because the average of two numbers never exceeds their maximum, and the constant 0 is trivially admissible.

model:
```python
import heapq


def greedy_order(graph, h, start, goal):
    frontier = [(h[start], start)]
    generated = {start}
    order = []
    while frontier:
        _, node = heapq.heappop(frontier)
        order.append(node)
        if node == goal:
            break
        for nxt in graph[node]:
            if nxt not in generated:
                generated.add(nxt)
                heapq.heappush(frontier, (h[nxt], nxt))
    return order
```
hint: Pop from a heap of `(h[node], node)` tuples and append each popped node to the result.
hint: Add a neighbour to `generated` and to the heap only the first time it is seen.
solution: Greedy search looks only at `h`. In the first test it follows the low-`h` nodes `B` and `C` and reaches `G` after four expansions, although `S, A, G` is a shorter path. That is why greedy best-first search is not optimal.

@quiz mc
prompt: Graph search with an explored set that never reopens a node is run with A*. Which condition on $h$ guarantees that the first goal removed from the frontier is optimal?
choice: $h$ is positive at every node
choice: $h$ is admissible but possibly inconsistent
choice*: $h$ is consistent and $h = 0$ at goals
choice: $h(n) \ge h^*(n)$ for all $n$
hint: Which property makes $f$ nondecreasing along every path?
solution: With a consistent heuristic, the first path to reach any state is the cheapest one, so never reopening nodes is safe. Admissible but inconsistent heuristics can make the first path found to a state non-optimal. A heuristic that overestimates ($h \ge h^*$) breaks admissibility.

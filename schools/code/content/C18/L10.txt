@article
Planning with certainty assumes that each action has one outcome. When outcomes are random, the right answer is not a sequence of actions but a **policy**: a rule that says what to do in every state. A **Markov decision process (MDP)** is the standard model.

### Definition

An MDP consists of

- a set of **states** $S$,
- for each state a set of **actions** $A(s)$,
- a **transition model** $T(s, a, s') = P(s' \mid s, a)$,
- a **reward** $R(s, a, s')$ received on each transition,
- a **discount factor** $\gamma \in [0, 1)$ (and a start state or distribution).

The **Markov property** says that the next state and reward depend only on the current state and action, not on the earlier history. A **terminal** state has no actions; its value is 0. A **policy** $\pi$ maps each state to an action. The **return** of a reward sequence $r_0, r_1, r_2, \dots$ is $\sum_{t} \gamma^t r_t$. Discounting makes immediate rewards worth more than distant ones and keeps infinite sums finite: a constant reward $c$ forever is worth $c / (1 - \gamma)$.

### Values and the Bellman equations

The **value** of a state under a policy is the expected return when starting there and following $\pi$:
$$V^\pi(s) = \sum_{s'} T(s, \pi(s), s')\,\bigl[R(s, \pi(s), s') + \gamma V^\pi(s')\bigr].$$
The **optimal value** $V^*(s)$ is the best expected return over all policies. It satisfies the **Bellman optimality equation**
$$V^*(s) = \max_{a \in A(s)} Q^*(s, a), \qquad Q^*(s, a) = \sum_{s'} T(s, a, s')\,\bigl[R(s, a, s') + \gamma V^*(s')\bigr].$$
$Q^*(s, a)$ is the value of taking $a$ in $s$ and acting optimally afterwards. Given $V^*$, an optimal policy is **greedy**: $\pi^*(s) = \arg\max_a Q^*(s, a)$.

### Value iteration

Start with $V_0(s) = 0$ and repeatedly apply the **Bellman backup** to every state:
$$V_{k+1}(s) = \max_{a} \sum_{s'} T(s, a, s')\,\bigl[R(s, a, s') + \gamma V_k(s')\bigr].$$
For $\gamma < 1$ the backup is a **contraction** in the maximum norm: $\|V_{k+1} - V^*\|_\infty \le \gamma \|V_k - V^*\|_\infty$, so $V_k \to V^*$ geometrically from any start. In practice, stop when $\max_s |V_{k+1}(s) - V_k(s)| < \varepsilon (1 - \gamma)/\gamma$, which guarantees $\|V_{k+1} - V^*\|_\infty < \varepsilon$. One sweep costs $O(|S|^2 |A|)$ in the worst case (less for sparse transitions). The values at step $k$ are the optimal values for a horizon of $k$ steps.

```python
def backup(mdp, V, s, gamma):
    actions = mdp[s]
    if not actions:
        return 0.0                      # terminal state
    return max(sum(p * (r + gamma * V[s2]) for p, s2, r in outcomes)
               for outcomes in actions.values())
```

In this format `mdp[s][a]` is a list of `(probability, next_state, reward)` triples.

### Policy iteration

**Policy iteration** alternates **policy evaluation** (compute $V^\pi$, which is a system of $|S|$ linear equations, solvable in $O(|S|^3)$) with **policy improvement** (make the policy greedy with respect to $V^\pi$). For a finite MDP it terminates in finitely many iterations at an optimal policy, and often needs few iterations.

### Limits

Real problems have huge state spaces, unknown $T$ and $R$ (next week), and states that are only partly observable, which leads to **POMDPs**, where the agent maintains a belief state. The MDP model also assumes the reward function captures what we want, which is a design problem in itself.

@example
title: Value iteration by hand
problem: State S has two actions. `safe` goes to the terminal state T with reward 2. `risky` goes to T with probability 0.5 and reward 6, and returns to S with probability 0.5 and reward 0. Take $\gamma = 0.5$ and $V_0 = 0$. Compute $V_1$, $V_2$ and the exact optimal value.
step: $V_1(S)$: `safe` gives $2$; `risky` gives $0.5 \cdot 6 + 0.5 \cdot (0 + 0.5 \cdot 0) = 3$. So $V_1(S) = 3$.
step: $V_2(S)$: `safe` is still $2$. `risky` gives $0.5 \cdot 6 + 0.5 \cdot (0 + 0.5 \cdot 3) = 3 + 0.75 = 3.75$. So $V_2(S) = 3.75$.
step: At the fixed point `risky` is best, so $V = 3 + 0.25\,V$.
step: Solve: $0.75\,V = 3$, so $V = 4$. (`safe` would give only 2, so the optimal policy takes the risk.)
answer: $V_1 = 3$, $V_2 = 3.75$ and $V^*(S) = 4$, with the optimal action `risky`.

@example
title: How the discount factor changes the best plan
problem: Plan A gets reward 10 at time $t = 2$ (and 0 otherwise). Plan B gets reward 4 at time $t = 0$. Which has the higher return for $\gamma = 0.9$ and for $\gamma = 0.4$?
step: The return is $\sum_t \gamma^t r_t$. Plan A: $10\,\gamma^2$. Plan B: $4$.
step: With $\gamma = 0.9$: A is $10 \times 0.81 = 8.1$, which is more than 4, so A wins.
step: With $\gamma = 0.4$: A is $10 \times 0.16 = 1.6$, which is less than 4, so B wins.
answer: A is better at $\gamma = 0.9$ (8.1 against 4); B is better at $\gamma = 0.4$ (4 against 1.6).

@mistakes
- Using $\gamma = 1$ with infinite horizons and positive rewards: the return can be infinite and the contraction argument no longer applies.
- Updating values in place with a stale mixture of $V_k$ and $V_{k+1}$ and then reporting them as "the values after $k$ sweeps"; the synchronous version uses only $V_k$ on the right-hand side.
- Forgetting the expectation over next states: the backup sums over outcomes weighted by their probabilities, and the reward belongs inside the sum.
- Taking the maximum of rewards instead of the maximum of $Q$-values (reward plus discounted future value).

model:
```python
def value_iteration(mdp, gamma, k):
    V = {s: 0.0 for s in mdp}
    for _ in range(k):
        new = {}
        for s, actions in mdp.items():
            if not actions:
                new[s] = 0.0
                continue
            new[s] = max(
                sum(p * (r + gamma * V[s2]) for p, s2, r in outcomes)
                for outcomes in actions.values()
            )
        V = new
    return V
```
hint: Build a completely new dict in each sweep so that every state uses only the previous sweep's values.
hint: For a non-terminal state take `max` over `actions.values()` of the sum of `p * (r + gamma * V[s2])`.
solution: After one sweep `s1` has value 10 (take `right` for reward 10) and `s0` is still 0; after two sweeps `s0` can reach `s1` and has value $0.9 \times 10 = 9$. Writing into a new dict keeps each sweep synchronous, which is why the values at step $k$ are exactly the optimal $k$-step values. In `mdp2` the value follows $2, 2.5, 2.625, \dots$ toward $8/3$.

```python
def extract_policy(mdp, V, gamma):
    policy = {}
    for s, actions in mdp.items():
        best_action, best_q = None, None
        for a in sorted(actions):
            q = sum(p * (r + gamma * V[s2]) for p, s2, r in actions[a])
            if best_q is None or q > best_q:
                best_action, best_q = a, q
        if best_action is not None:
            policy[s] = best_action
    return policy
```
hint: For each state, compute the Q-value of every action using `V`.
hint: Scan the actions in sorted order and replace the best only when a Q-value is strictly larger, which makes ties go to the first action.
solution: The greedy policy is the argmax of the one-step lookahead. Using a strict `>` while scanning in sorted order implements the tie rule: with equal Q-values the action `"x"` stays. A terminal state has no actions, so it never gets a policy entry.

@article
Search and logic assume that the agent knows the state. Real agents see noisy sensors, hidden causes and incomplete information, so they represent **degrees of belief** with probability. A **random variable** takes values in a domain; a **joint distribution** gives the probability of every complete assignment. The full joint over $n$ Boolean variables has $2^n$ entries, so we need structure.

### Basic rules

- **Conditional probability**: $P(A \mid B) = P(A, B) / P(B)$ when $P(B) > 0$.
- **Product rule**: $P(A, B) = P(A \mid B)\,P(B)$.
- **Marginalization**: $P(A) = \sum_b P(A, B = b)$.
- **Chain rule**: $P(X_1, \dots, X_n) = \prod_i P(X_i \mid X_1, \dots, X_{i-1})$.
- **Bayes' rule**: $P(H \mid E) = \dfrac{P(E \mid H)\,P(H)}{P(E)}$, with $P(E) = \sum_h P(E \mid h)P(h)$.

$A$ and $B$ are **independent** if $P(A, B) = P(A)P(B)$. They are **conditionally independent given** $C$ if $P(A, B \mid C) = P(A \mid C)P(B \mid C)$. Bayes' rule is how an agent turns a causal model $P(\text{evidence} \mid \text{cause})$ into a diagnosis $P(\text{cause} \mid \text{evidence})$. Rare causes stay unlikely even after a fairly reliable positive test, because the prior $P(H)$ is small; ignoring it is the **base-rate fallacy**.

### Bayesian networks

A **Bayesian network** is a directed acyclic graph with one node per random variable and, for each node $X_i$, a **conditional probability table (CPT)** $P(X_i \mid \text{Parents}(X_i))$. Its semantics is the joint distribution
$$P(x_1, \dots, x_n) = \prod_{i=1}^n P\bigl(x_i \mid \text{parents}(X_i)\bigr).$$
Each variable is conditionally independent of its non-descendants given its parents. A Boolean node with $k$ Boolean parents needs $2^k$ numbers, so a sparse network needs far fewer than the $2^n - 1$ numbers of the full joint.

```python
net = {
    "Rain": ((), {(): 0.2}),
    "Wet": (("Rain",), {(True,): 0.9, (False,): 0.1}),
}
# P(Rain=True, Wet=False) = 0.2 * (1 - 0.9)
```

### Independence in a network: d-separation

Three local structures decide when evidence blocks or opens a path between $X$ and $Y$ through $Z$:

| Structure | Without evidence | Given $Z$ |
|---|---|---|
| Chain $X \to Z \to Y$ | dependent | independent |
| Fork $X \leftarrow Z \to Y$ (common cause) | dependent | independent |
| Collider $X \to Z \leftarrow Y$ (common effect) | independent | **dependent** (also if a descendant of $Z$ is observed) |

The collider case is **explaining away**: if the alarm sounded, learning that a burglary happened makes an earthquake less likely. Two sets of variables are **d-separated** by evidence if every path between them is blocked; then they are conditionally independent.

### Inference

**Inference by enumeration** answers $P(Q \mid e)$ by summing the joint over the hidden variables $H$ and normalizing:
$$P(Q \mid e) = \alpha \sum_{h} P(Q, e, h).$$
It takes $O(2^n)$ time for Boolean variables. **Variable elimination** sums out one hidden variable at a time over **factors** and reuses intermediate results; it is exponential only in the size of the largest factor, which depends on the elimination order. Exact inference is NP-hard in general, but linear in the size of the network for **polytrees** (at most one undirected path between any two nodes). When exact inference is too costly, **sampling** methods (rejection sampling, likelihood weighting, Gibbs sampling) give approximate answers. A **naive Bayes** model, one cause with conditionally independent effects, is a Bayesian network that supports fast classification.

@example
title: A diagnostic test with Bayes' rule
problem: A condition has prevalence 2%. A test is positive for 95% of people with the condition and for 10% of people without it. What is $P(\text{condition} \mid \text{positive})$?
step: Write the numbers: $P(C) = 0.02$, $P(+ \mid C) = 0.95$, $P(+ \mid \neg C) = 0.10$.
step: Joint with the condition: $P(+, C) = 0.95 \times 0.02 = 0.019$.
step: Joint without the condition: $P(+, \neg C) = 0.10 \times 0.98 = 0.098$. So $P(+) = 0.019 + 0.098 = 0.117$.
step: Divide: $P(C \mid +) = 0.019 / 0.117 \approx 0.162$.
answer: About 0.162, much lower than the 0.95 sensitivity because the condition is rare.

@example
title: Joint probabilities from a network
problem: The network is $A \to B$ and $A \to C$ with $P(A) = 0.5$, $P(B \mid A) = 0.9$, $P(B \mid \neg A) = 0.2$, $P(C \mid A) = 0.7$ and $P(C \mid \neg A) = 0.1$. Compute $P(A, B, \neg C)$, then decide whether $B$ and $C$ are independent.
step: The joint factors as $P(A)\,P(B \mid A)\,P(C \mid A)$. For $A = T$, $B = T$, $C = F$: $0.5 \times 0.9 \times (1 - 0.7) = 0.135$.
step: Marginal $P(B, C) = 0.5 \cdot 0.9 \cdot 0.7 + 0.5 \cdot 0.2 \cdot 0.1 = 0.315 + 0.01 = 0.325$.
step: Marginals: $P(B) = 0.5 \cdot 0.9 + 0.5 \cdot 0.2 = 0.55$ and $P(C) = 0.5 \cdot 0.7 + 0.5 \cdot 0.1 = 0.40$, so $P(B)P(C) = 0.22 \ne 0.325$.
step: $B$ and $C$ are dependent, but they are conditionally independent given $A$ (a fork).
answer: $P(A, B, \neg C) = 0.135$; $B$ and $C$ are not independent.

@mistakes
- Reporting $P(E \mid H)$ as if it were $P(H \mid E)$ (the base-rate fallacy): a 95%-accurate test of a rare condition gives a posterior far below 95%.
- Believing that independent causes stay independent after observing their common effect; in a collider, evidence on the effect makes them dependent.
- Forgetting to normalize after enumerating: the sums for $Q = \text{true}$ and $Q = \text{false}$ must be divided by their total.
- Using a CPT entry $P(X = \text{true} \mid \text{parents})$ for a false value without taking $1 - p$.

model:
```python
from itertools import product


def enumerate_query(net, query, evidence):
    def joint(assignment):
        prob = 1.0
        for var, (parents, cpt) in net.items():
            p_true = cpt[tuple(assignment[p] for p in parents)]
            prob *= p_true if assignment[var] else 1 - p_true
        return prob

    hidden = [v for v in net if v != query and v not in evidence]
    totals = {}
    for value in (True, False):
        total = 0.0
        for values in product([True, False], repeat=len(hidden)):
            assignment = dict(evidence)
            assignment[query] = value
            assignment.update(zip(hidden, values))
            total += joint(assignment)
        totals[value] = total
    return totals[True] / (totals[True] + totals[False])
```
hint: Write a helper that computes the joint probability of a complete assignment: one CPT factor per variable, `p` if the variable is `True` and `1 - p` if it is `False`.
hint: For each value of `query`, loop over all assignments of the hidden variables, add up the joint probabilities, then divide the total for `True` by the sum of both totals.
solution: Enumeration implements $P(Q \mid e) = \alpha \sum_h P(Q, e, h)$ literally. The two unnormalized sums are $P(Q = \text{true}, e)$ and $P(Q = \text{false}, e)$, and dividing by their total normalizes. With evidence `W=True`, the posterior of `R` is about 0.358, above its prior 0.2, because wet grass is more likely when it rained.

model:
```python
def naive_bayes(prior, likelihoods, observed):
    score_c = prior
    score_not_c = 1 - prior
    for feature, value in observed.items():
        p_c, p_not_c = likelihoods[feature]
        score_c *= p_c if value else 1 - p_c
        score_not_c *= p_not_c if value else 1 - p_not_c
    return score_c / (score_c + score_not_c)
```
hint: Keep one running product for `C` true and one for `C` false, each starting from its prior.
hint: For an observed feature value `False`, multiply by `1 - p`; at the end divide the first product by the sum of the two.
solution: Bayes' rule with conditional independence gives $P(C \mid f_1, \dots, f_k) \propto P(C) \prod_i P(f_i \mid C)$. Compute the unnormalized scores for $C$ and $\neg C$ and normalize them. A feature whose likelihoods are equal under both classes (the last test) does not change the prior.

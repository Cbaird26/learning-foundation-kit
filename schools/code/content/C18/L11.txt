@article
Value iteration needs the transition model $T$ and reward $R$. In **reinforcement learning (RL)** the agent does not know them. It interacts with the environment, observes **experiences** $(s, a, r, s')$, and must learn a good policy from the rewards alone. Unlike supervised learning, no one gives the correct action; the feedback is a scalar reward, often delayed (the **credit assignment** problem), and the data the agent sees depends on its own actions.

### Model-based and model-free learning

A **model-based** agent estimates $T$ and $R$ from counts and then plans with value iteration. A **model-free** agent learns values or a policy directly from experience, without ever building a model. **Passive** RL evaluates a fixed policy; **active** RL also chooses actions.

### Temporal-difference learning

After one step $(s, a, r, s')$ the quantity $r + \gamma V(s')$ is a sample of the value of $s$. **TD(0)** moves the estimate a fraction $\alpha$ (the **learning rate**) toward it:
$$V(s) \leftarrow V(s) + \alpha\,\underbrace{\bigl[r + \gamma V(s') - V(s)\bigr]}_{\text{TD error}}.$$
It updates after every step and learns by **bootstrapping**: it uses its own estimate $V(s')$ in the target.

### Q-learning

To act, the agent needs action values. **Q-learning** updates
$$Q(s, a) \leftarrow Q(s, a) + \alpha\bigl[r + \gamma \max_{a'} Q(s', a') - Q(s, a)\bigr].$$
For a terminal $s'$ the term $\max_{a'} Q(s', a')$ is $0$. The target uses the best next action, whatever action the agent actually takes next, so Q-learning is **off-policy**: it can learn the optimal $Q^*$ while following an exploratory behavior policy. **SARSA** uses the action $a'$ actually chosen, so it is **on-policy** and learns the value of the policy it follows:
$$Q(s, a) \leftarrow Q(s, a) + \alpha\bigl[r + \gamma Q(s', a') - Q(s, a)\bigr].$$

```python
def q_update(Q, s, a, r, s2, actions, alpha, gamma):
    best = 0.0 if s2 is None else max(Q.get((s2, b), 0.0) for b in actions)
    old = Q.get((s, a), 0.0)
    Q[(s, a)] = old + alpha * (r + gamma * best - old)
    return Q[(s, a)]
```

### Exploration and exploitation

An agent that always takes the action with the highest current $Q$ may never discover a better one. **$\varepsilon$-greedy** exploration takes a random action with probability $\varepsilon$ and the greedy action otherwise; $\varepsilon$ is often reduced over time. Other schemes use optimism about unseen actions or a bonus for rarely tried ones.

For **tabular** Q-learning in a finite MDP, $Q$ converges to $Q^*$ with probability 1 if every state-action pair is updated infinitely often and the learning rates satisfy $\sum_t \alpha_t = \infty$ and $\sum_t \alpha_t^2 < \infty$ (in a deterministic environment a constant $\alpha$ also converges, as in the corridor below). Learning can need very many samples (poor **sample efficiency**).

### Scaling up and risks

Tables do not scale to large state spaces, so **function approximation** represents $Q$ (or a policy) with a parameterized function such as a neural network, trained with gradient steps; this is **deep reinforcement learning**. Convergence guarantees weaken: combining bootstrapping, off-policy data and function approximation can be unstable. **Policy-gradient** methods optimize a parameterized policy directly. Because the agent maximizes the reward it is given, a badly specified reward can be exploited in unintended ways (**reward hacking** or specification gaming), and exploration in the real world can be unsafe. Both are central issues in applying RL.

### A tiny grid world

A corridor has states $0, 1, \dots, n - 1$ with state $n - 1$ terminal. Actions `L` and `R` move one step (`L` at state 0 stays). Entering the terminal state gives reward 10 and every other step gives 0. With $\gamma = 0.9$ the optimal values in a corridor of 4 states are $Q^*(2, R) = 10$, $Q^*(1, R) = 9$ and $Q^*(0, R) = 8.1$.

@example
title: One Q-learning update
problem: $Q(s, a) = 1$, $\alpha = 0.1$, $\gamma = 0.9$. The agent takes $a$ in $s$, receives $r = 2$ and lands in $s'$, where the action values are $Q(s', a_1) = 5$ and $Q(s', a_2) = 3$. Compute the new $Q(s, a)$.
step: The target uses the best next action: $\max(5, 3) = 5$.
step: Target $= r + \gamma \cdot 5 = 2 + 0.9 \cdot 5 = 6.5$.
step: TD error $= 6.5 - Q(s, a) = 6.5 - 1 = 5.5$.
step: New value $= 1 + 0.1 \cdot 5.5 = 1.55$.
answer: $Q(s, a) = 1.55$.

@example
title: Q-learning versus SARSA on the same experience
problem: The same experience as before but with $\alpha = 0.5$: $Q(s, a) = 1$, $r = 2$, $\gamma = 0.9$, and in $s'$ the agent explores and takes $a'$ with $Q(s', a') = 1$ while the best action there has value 5. Compare the updates.
step: Q-learning uses the best next value: target $2 + 0.9 \cdot 5 = 6.5$, so the new value is $1 + 0.5\,(6.5 - 1) = 3.75$.
step: SARSA uses the action actually taken: target $2 + 0.9 \cdot 1 = 2.9$, so the new value is $1 + 0.5\,(2.9 - 1) = 1.95$.
step: SARSA's value reflects the exploratory behavior, which is why it is more cautious near risky states; Q-learning learns the greedy policy's value.
answer: Q-learning gives 3.75 and SARSA gives 1.95.

@mistakes
- Using the next action actually taken in the target and calling it Q-learning; that is SARSA. Q-learning takes the maximum over next actions.
- Forgetting that a terminal next state has future value 0, which makes the final step's target just the reward.
- Setting $\varepsilon = 0$ from the start, so the agent never tries actions that look worse under its initial estimates.
- Confusing the learning rate $\alpha$ with the discount factor $\gamma$: $\alpha$ controls how fast estimates change, $\gamma$ controls how much the future counts.

model:
```python
def train_q(n, sweeps, alpha, gamma):
    Q = {(s, a): 0.0 for s in range(n - 1) for a in "LR"}
    for _ in range(sweeps):
        for s in range(n - 1):
            for a in "LR":
                s2 = max(s - 1, 0) if a == "L" else s + 1
                r = 10.0 if s2 == n - 1 else 0.0
                if s2 == n - 1:
                    best = 0.0
                else:
                    best = max(Q[(s2, "L")], Q[(s2, "R")])
                Q[(s, a)] += alpha * (r + gamma * best - Q[(s, a)])
    return Q
```
hint: The environment is deterministic, so the next state and reward follow directly from `s` and `a`.
hint: Update the table in place, in the stated order, using `max(Q[(s2, "L")], Q[(s2, "R")])` for a non-terminal next state.
solution: Each sweep applies one Q-learning update to every state-action pair. After one sweep only the pair `(1, "R")` has learned anything, because it is the only one that reaches the terminal state (value $0.5 \times 10 = 5$). Information then flows backward along the corridor one state per sweep, and with enough sweeps the table converges to $Q^*$, where moving right is best in every state.

model:
```python
def choose_action(Q, s, actions, epsilon, u, pick):
    if u < epsilon:
        return actions[pick]
    best = actions[0]
    for a in actions[1:]:
        if Q.get((s, a), 0.0) > Q.get((s, best), 0.0):
            best = a
    return best
```
hint: The condition `u < epsilon` selects exploration; nothing is random inside the function.
hint: For the greedy case start with the first action and replace it only when another action has a strictly higher value.
solution: Exploration returns `actions[pick]`. Greedy selection scans the actions in order, replacing the best only on a strictly larger `Q`, which gives the first-in-list tie-break. In the last test, `u = 0.2` is not below `epsilon = 0.2`, so the agent acts greedily: `D` has value $-1$ and the unseen `U` has the default $0$, so `U` wins.

@article
A **code** is a rule for changing a message into something else. A code can hide what the message says. Only people who know the rule can read it.

### Letters as numbers

Let us give each letter a number: A is 1, B is 2, C is 3, and so on.

```text
A=1  B=2  C=3  D=4  E=5  F=6  G=7  H=8  I=9  J=10
```

The word **CAB** becomes 3, 1, 2. Anyone who knows the rule can turn it back into letters. Computers do something like this. They store letters as numbers.

### A shift code

Here is another rule. Change each letter into the next letter of the alphabet. A becomes B, B becomes C, and so on.

The word **CAT** becomes **DBU**. C goes to D, A goes to B, and T goes to U.

To read a shift message, you undo the rule. Change each letter into the letter before it.

### Making and breaking codes

To **encode** is to turn a message into code. To **decode** is to turn the code back into the message. The rule that does it is the same, but you run it backwards to decode.

Secret codes only work when the rule is shared with the person you want to read the message. But be careful: a rule like "shift by one" is easy to guess. Real computer codes use much harder rules.

Grown-up helper: write a short word in the number code and let your child decode it. Then swap roles.

@example
title: Decoding numbers
problem: Use A=1, B=2, C=3, D=4, E=5. What word is 4, 1, 4?
step: The first number is 4. The letter for 4 is D.
step: The next number is 1. The letter for 1 is A.
step: The last number is 4 again, so the last letter is D.
answer: DAD

@mistakes
- Counting wrong in the alphabet. Write the letters out in a row with their numbers.
- Shifting the wrong way. To encode, go to the next letter. To decode, go to the letter before.
- Forgetting the rule. Write it at the top of your message.

@practice num
prompt: Use A=1, B=2, C=3 and so on. What number is the letter D? Type a number.
answer: 4
check: ord("D") - ord("A") + 1
hint: Count along the alphabet: A is 1, B is 2, C is 3.
solution: D is the fourth letter of the alphabet, so D is 4.

@practice text
prompt: Use A=1, B=2, C=3 and so on. Write the word CAB as numbers, with spaces between them. Type the numbers.
answer: 3 1 2
accept: 3, 1, 2
accept: 3,1,2
check: " ".join(str(ord(c) - ord("A") + 1) for c in "CAB")
hint: Find the number for C, then A, then B.
solution: C is 3, A is 1 and B is 2. So CAB is 3 1 2.

@practice text
prompt: The shift code changes each letter into the next letter of the alphabet. Write the word CAT in this code. Type capital letters.
answer: DBU
accept: dbu
check: "".join(chr(ord(c) + 1) for c in "CAT")
hint: C goes to D. What do A and T go to?
solution: C goes to D, A goes to B, and T goes to U. So CAT becomes DBU.

@quiz text
prompt: A secret message was written in the shift code, where each letter was changed into the next letter of the alphabet. The code is IFMMP. What was the message? Type capital letters.
answer: HELLO
accept: hello
check: "".join(chr(ord(c) - 1) for c in "IFMMP")
hint: To decode, change each letter into the letter before it in the alphabet. I comes after H.
solution: I goes back to H, F goes back to E, M goes back to L, M goes back to L, and P goes back to O. The message is HELLO.

@article
In **unsupervised learning** there are no labels, only feature vectors $x_1, \dots, x_n$, and the goal is to find structure. **Clustering** divides the points into groups so that points in the same group are similar. Uses include customer segmentation, grouping documents, and compressing images by replacing each pixel with its cluster's color.

### The k-means objective

Fix the number of clusters $k$. K-means looks for $k$ **centroids** $\mu_1, \dots, \mu_k$ and an assignment of each point to one cluster that minimize the **inertia** (within-cluster sum of squares)
$$J = \sum_{i=1}^{n}\lVert x_i - \mu_{c(i)}\rVert^2,$$
where $c(i)$ is the cluster of point $i$. Finding the global minimum is NP-hard, so we use a local-search heuristic.

### Lloyd's algorithm

1. **Initialize** $k$ centroids, for example $k$ distinct data points.
2. **Assign**: put each point in the cluster of its nearest centroid (ties go to the lowest index).
3. **Update**: move each centroid to the mean of the points assigned to it.
4. Repeat steps 2 and 3 until the assignments no longer change.

Why does it work? For fixed centroids, assigning each point to its nearest centroid minimizes $J$. For a fixed assignment, the mean minimizes the sum of squared distances to a set of points. So neither step can increase $J$. There are finitely many assignments and $J$ cannot decrease forever without stopping, so the algorithm terminates, at a **local minimum**. Each iteration costs $O(nkd)$ operations, dominated by the $nk$ distance computations of the assignment step. A cluster that loses all its points needs a rule (keep the old centroid, or re-seed it).

### Initialization matters

Different starting centroids can end in different local minima with very different inertia. Two standard remedies: run the algorithm several times from random starts and keep the lowest $J$, and use **k-means++** seeding. K-means++ picks the first centroid uniformly at random from the data; each further centroid is a data point chosen with probability proportional to $D(x)^2$, the squared distance from $x$ to its nearest already-chosen centroid. This spreads the starting centroids out, and gives a result whose expected inertia is within a factor $O(\log k)$ of the optimum.

### Choosing $k$

Inertia always decreases as $k$ grows (it is 0 when $k = n$), so it cannot choose $k$ alone. The **elbow method** plots $J$ against $k$ and looks for the bend after which improvements are small. The **silhouette** of a point is $s = (b - a)/\max(a, b)$, where $a$ is its mean distance to its own cluster and $b$ its mean distance to the nearest other cluster; the average silhouette near 1 indicates well-separated clusters. Often $k$ is dictated by how the clusters will be used.

### Limits

K-means uses Euclidean distance to a mean, so it prefers clusters that are round, of similar size and spread; it splits an elongated cluster and cannot separate concentric rings. It is sensitive to outliers (they drag means) and to feature scales, so **standardize** features first. Alternatives include hierarchical clustering, DBSCAN (density-based, finds arbitrary shapes and marks noise) and Gaussian mixture models fitted by the EM algorithm, which is a soft-assignment relative of k-means.

@example
title: K-means by hand in one dimension
problem: Cluster the points $1, 2, 6, 7, 12$ with $k = 2$ and initial centroids $1$ and $12$. Run until it stops and compute the inertia.
step: Assign: $1 \to A$ (distance 0); $2 \to A$ (1 against 10); $6 \to A$ (5 against 6); $7 \to B$ (6 against 5); $12 \to B$.
step: Update: $A = \{1, 2, 6\}$ has mean $3$ and $B = \{7, 12\}$ has mean $9.5$.
step: Assign again: $2 \to A$; $6$ is at distance $3$ from $A$ and $3.5$ from $B$, so $A$; $7$ is at distance $4$ from $A$ and $2.5$ from $B$, so $B$. The assignment is unchanged, so stop.
step: Inertia: $(1-3)^2 + (2-3)^2 + (6-3)^2 = 4 + 1 + 9 = 14$ for $A$, and $(7 - 9.5)^2 + (12 - 9.5)^2 = 6.25 + 6.25 = 12.5$ for $B$.
answer: Clusters $\{1,2,6\}$ and $\{7,12\}$ with centroids $3$ and $9.5$, $J = 26.5$.

@example
title: A poor local minimum
problem: Points $(0,0), (0,2), (4,0), (4,2)$ and $k = 2$. Run k-means from the initial centroids $(0,0)$ and $(0,2)$.
step: Assign: $(0,0)$ goes to the first centroid and $(0,2)$ to the second. For $(4,0)$ the squared distances are $16$ and $20$, so first; for $(4,2)$ they are $20$ and $16$, so second.
step: Update: the first cluster $\{(0,0),(4,0)\}$ has mean $(2,0)$ and the second $\{(0,2),(4,2)\}$ has mean $(2,2)$.
step: Assign again: $(0,0)$ is at squared distance $4$ from $(2,0)$ and $8$ from $(2,2)$, and likewise for the other points. Nothing changes, so the algorithm stops with $J = 4 \cdot 4 = 16$.
step: The left/right split $\{(0,0),(0,2)\}$ and $\{(4,0),(4,2)\}$ has centroids $(0,1)$ and $(4,1)$ and $J = 4 \cdot 1 = 4$. So the algorithm stopped at a local minimum that is four times worse than the best solution.
answer: The result is the top/bottom split with $J = 16$; the best split has $J = 4$. Restarting from other initial centroids finds it.

@mistakes
- Believing that k-means finds the global minimum of the inertia: it finds a local minimum that depends on the initialization.
- Clustering raw features of very different scales, so one feature decides the clusters.
- Choosing $k$ by the lowest inertia, which always favors the largest $k$.
- Using k-means on non-convex or very unequal clusters and then interpreting the groups as natural categories.

```python
def assign_clusters(points, centers):
    labels = []
    for p in points:
        best = 0
        best_d = None
```

```python
def update_centers(points, labels, k):
    centers = []
    for j in range(k):
        members = [p for p, lab in zip(points, labels) if lab == j]
        if not members:
            centers.append(None)
        else:
            dim = len(members[0])
            centers.append(
                tuple(sum(m[i] for m in members) / len(members) for i in range(dim))
            )
    return centers
```

model:
```python
def kmeans(points, centers, max_iter):
    centers = list(centers)
    prev = None
    labels = []
    for _ in range(max_iter):
        labels = []
        for p in points:
            best, best_d = 0, None
            for j, c in enumerate(centers):
                d = sum((a - b) ** 2 for a, b in zip(p, c))
                if best_d is None or d < best_d:
                    best, best_d = j, d
            labels.append(best)
        for j in range(len(centers)):
            members = [p for p, lab in zip(points, labels) if lab == j]
            if members:
                dim = len(members[0])
                centers[j] = tuple(
                    sum(m[i] for m in members) / len(members) for i in range(dim)
                )
        if labels == prev:
            break
        prev = labels
    return (labels, centers)
```
hint: Write the assignment step (nearest center for each point) and the update step (mean of each cluster's points) first, then wrap them in a loop.
hint: Remember the previous labels and break when the new labels equal them. An empty cluster keeps its old center.
solution: Loop at most `max_iter` times: assign, update (skipping empty clusters), then stop when the labels equal those of the previous iteration. With `max_iter = 1` the loop performs one assignment and update, so the second test shows a state before convergence.

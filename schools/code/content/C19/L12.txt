@article
**Deep learning** means neural networks with many layers, trained on large data sets. Each layer builds on the previous one's output, so the network learns its own **representation** of the input instead of relying on hand-designed features. The main ideas are architectural (what structure the network has) and practical (how it is trained). Neither removes the need for the discipline of weeks 5 and 6: held-out data and honest evaluation.

### Architectures

A **convolutional neural network (CNN)** is designed for grid-like data such as images. A convolutional layer slides a small **kernel** (filter) over the input and computes a dot product at each position, reusing the same weights everywhere (**weight sharing**) and looking only at a local patch. For input size $n$, kernel size $k$, padding $p$ and stride $s$ the output size per dimension is
$$\left\lfloor \frac{n + 2p - k}{s} \right\rfloor + 1.$$
A layer with $C_{\text{in}}$ input channels and $C_{\text{out}}$ filters of size $k \times k$ has $k^2 C_{\text{in}} C_{\text{out}} + C_{\text{out}}$ parameters, far fewer than a fully connected layer on the same image. Pooling layers shrink the maps.

For sequences (text, audio, time series), **attention** lets each position compute a weighted average of the values at all positions, with weights from a softmax of query–key similarity:
$$\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.$$
The **transformer** architecture stacks attention and feed-forward layers; unlike recurrent networks it processes all positions in parallel, at a cost that grows quadratically with the sequence length. Large language models are transformers trained to predict the next token of text and then adapted to follow instructions. **Transfer learning** reuses a network pretrained on a large data set and **fine-tunes** it on a small task-specific set.

### Training deep networks

**SGD with momentum** keeps a running velocity $v \leftarrow \beta v + g$ and updates $w \leftarrow w - \eta v$, which smooths noisy gradients and speeds travel along consistent directions. **Adam** adapts a step size for each parameter using running averages of the gradient and of its square. Common regularizers are **weight decay** (an L2 penalty), **early stopping**, **data augmentation** and **dropout**: during training each hidden unit is zeroed at random with some probability, which prevents units from relying on each other, and at inference all units are used. **Normalization layers** stabilize the scale of activations and make deep networks easier to train.

### What language models can and cannot do

A language model produces text that is statistically plausible given its training data. It does not look facts up by construction, so it can state falsehoods fluently and confidently ("hallucination"); its confidence is not evidence of correctness. It reflects the biases of its training text, can reproduce memorized passages (a privacy and copyright concern), and can be manipulated by text in its input that tries to override its instructions (**prompt injection**). Evaluating open-ended outputs is hard, so outputs that matter must be checked by people or by independent sources.

### Responsible machine learning

A model that is accurate on average can fail particular groups, and its mistakes are not equally costly. Always report metrics **by group** with their uncertainty. For a binary decision with sensitive attribute $A$:

- **Demographic parity**: the selection rate $P(\hat y = 1 \mid A = a)$ is equal across groups.
- **Equal opportunity**: the true positive rate is equal across groups. **Equalized odds**: both true and false positive rates are equal.
- **Calibration within groups**: among people given score $s$, a fraction $s$ are actual positives in every group.

These criteria are different. When the groups have different base rates (the fraction of actual positives), a classifier cannot have calibration within groups and equal false positive and false negative rates at the same time, except in degenerate cases such as perfect prediction; demographic parity likewise conflicts with these criteria in general. So choosing among them is a decision about values and context, not a purely technical one. Bias enters through unrepresentative **sampling**, biased **labels** (past human decisions), **proxy features** correlated with a sensitive attribute, **feedback loops** (the model's decisions shape future data) and **distribution shift** between training and deployment.

Further practices: protect privacy (minimize data, control access, consider **differential privacy**); keep a human able to review and override consequential decisions; monitor deployed models; and document them. A **model card** states the intended use and out-of-scope uses, the training data, evaluation results (overall and by group, with uncertainty), known limitations and risks, and the contact for questions. Datasets get similar documentation. Laws and regulations on AI differ between jurisdictions (the European Union has adopted a comprehensive AI Act, while some other places rely mainly on sector-specific rules); this is not legal advice, and engineers should learn the rules that apply to them.

@example
title: Output size and parameters of a convolution
problem: A $28 \times 28$ grayscale image (1 channel) passes through a convolutional layer with 8 filters of size $3 \times 3$, stride 1 and no padding. Find the output shape and the number of parameters, and compare with a fully connected layer from the 784 pixels to the same number of outputs.
step: The size per dimension is $\lfloor(28 + 0 - 3)/1\rfloor + 1 = 26$, so the output is $26 \times 26 \times 8$.
step: Each filter has $3 \cdot 3 \cdot 1 = 9$ weights and a bias, so 8 filters have $8 \cdot 9 + 8 = 80$ parameters.
step: The output has $26 \cdot 26 \cdot 8 = 5408$ values, so a fully connected layer producing the same number of values has $784 \cdot 5408 + 5408 = 4{,}245{,}280$ parameters.
step: Weight sharing and local connectivity cut the parameter count by a factor of more than $50{,}000$.
answer: Output $26 \times 26 \times 8$ with 80 parameters, against $4{,}245{,}280$ for the fully connected layer.

@example
title: Fairness metrics by group
problem: A model flags people for review. Group A has 100 people, 50 truly positive; the model flags 40, of which 30 are truly positive. Group B has 100 people, 20 truly positive; the model flags 20, of which 10 are truly positive. Compute the selection rate, the true positive rate and the false positive rate for each group.
step: Group A: selection rate $40/100 = 0.40$. True positive rate $30/50 = 0.60$. False positives $= 40 - 30 = 10$ among $50$ negatives, so FPR $= 0.20$.
step: Group B: selection rate $20/100 = 0.20$. True positive rate $10/20 = 0.50$. False positives $= 20 - 10 = 10$ among $80$ negatives, so FPR $= 0.125$.
step: The demographic parity gap is $0.40 - 0.20 = 0.20$; the equal opportunity gap is $0.60 - 0.50 = 0.10$; the FPR gap is $0.075$.
step: The gaps are measured on small groups, so they should be reported with confidence intervals before concluding that the model treats the groups differently. The groups also have different base rates (50% and 20%), so even an accurate model would select the groups at different rates; a demographic parity gap alone does not show that the model is faulty.
answer: A: $(0.40, 0.60, 0.20)$; B: $(0.20, 0.50, 0.125)$.

@mistakes
- Believing that a fluent, confident answer from a language model is evidence that it is correct.
- Reporting only overall accuracy and not metrics by group, so a failure on a smaller group is invisible.
- Treating "remove the sensitive attribute" as a guarantee of fairness, when proxy features can carry the same information.
- Using dropout at inference time as at training time instead of using all units.

model:
```python
def train_tiny(data, w1, b1, w2, b2, lr, epochs):
    for _ in range(epochs):
        for x, y in data:
            z = w1 * x + b1
            h = max(0.0, z)
            err = w2 * h + b2 - y
            dz = err * w2 * (1.0 if z > 0 else 0.0)
            gw1, gb1, gw2, gb2 = dz * x, dz, err * h, err
            w1 -= lr * gw1
            b1 -= lr * gb1
            w2 -= lr * gw2
            b2 -= lr * gb2
    return (w1, b1, w2, b2)
```
hint: Reuse the forward and backward formulas of the tiny network: compute `z`, `h`, the error, then the four gradients.
hint: Compute all four gradients before changing any parameter, then update all four. The loop order is epochs outside, examples inside.
solution: For each example compute the gradients at the current parameters, then subtract `lr` times each. Updating after every example is stochastic gradient descent; with one example the first test reproduces the hand computation of the forward and backward pass for this network. When `z <= 0` the ReLU gradient is 0, so `w1`, `b1` and `w2` do not move (the third test).

model:
```python
def fairness_report(groups, y_true, y_pred):
    stats = {}
    for g, t, p in zip(groups, y_true, y_pred):
        s = stats.setdefault(g, [0, 0, 0, 0])
        s[0] += 1
        s[1] += p
        if t == 1:
            s[2] += 1
            s[3] += p
    report = {}
    for g, (n, flagged, positives, hits) in stats.items():
        tpr = hits / positives if positives else None
        report[g] = (flagged / n, tpr)
    return report
```
hint: For each group keep four counters: people, flagged people, true positives, and true positives that were flagged.
solution: Accumulate the four counters per group in one pass, then divide. A group without true positives has no defined true positive rate, so it gets `None`. Comparing these numbers across groups, with confidence intervals, is the first step of a fairness audit.

model:
```python
def sgd_momentum(w0, grads, lr, beta):
    w = w0
    v = 0.0
    for g in grads:
        v = beta * v + g
        w = w - lr * v
    return w
```
hint: Update the velocity first, then use the new velocity to update the parameter.
solution: The velocity accumulates past gradients, decaying by `beta` each step. In the example, `v` is 1 and then 1.9, so `w` moves by $-0.1$ and then $-0.19$. In the last test the velocities are $1, 0.5, 0.25$, so $w = -1.75$.

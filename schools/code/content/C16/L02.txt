@article
Probabilities change when we learn something. The chance that a randomly chosen email is spam differs from the chance given that it contains the word "free". **Conditional probability** is the tool that updates probabilities in light of information.

### Definition

For events $A$ and $B$ with $P(B) > 0$, the probability of $A$ **given** $B$ is

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}.$$

Intuitively, conditioning on $B$ throws away every outcome outside $B$ and renormalizes so that $B$ has probability 1. In a uniform space this reads $P(A \mid B) = |A \cap B| / |B|$. Note that $P(A \mid B)$ and $P(B \mid A)$ are generally different numbers.

### The multiplication rule

Rearranging the definition gives $P(A \cap B) = P(B)\,P(A \mid B)$. For a chain of events,

$$P(A_1 \cap A_2 \cap \cdots \cap A_n) = P(A_1)\,P(A_2 \mid A_1)\,P(A_3 \mid A_1 \cap A_2) \cdots$$

This is how you compute probabilities of multistage experiments such as drawing cards without replacement.

### The law of total probability

If $B_1, \dots, B_k$ **partition** the sample space (they are disjoint and their union is $\Omega$) and each $P(B_i) > 0$, then for any event $A$

$$P(A) = \sum_{i=1}^{k} P(A \mid B_i)\,P(B_i).$$

This splits a hard probability into cases. If server 1 handles 70% of requests and fails 1% of them, and server 2 handles 30% and fails 4%, then the overall failure probability is $0.7(0.01) + 0.3(0.04) = 0.019$.

### Independence

Events $A$ and $B$ are **independent** if

$$P(A \cap B) = P(A)\,P(B).$$

When $P(B) > 0$ this is equivalent to $P(A \mid B) = P(A)$: learning that $B$ occurred does not change the probability of $A$. Independence is a statement about probabilities, not about causation, and it is easy to check numerically.

Three events $A, B, C$ are **mutually independent** if every sub-collection satisfies the product rule, including $P(A \cap B \cap C) = P(A)P(B)P(C)$. **Pairwise** independence (each pair independent) is weaker. For example, toss two fair coins and let $A$ = first is heads, $B$ = second is heads, $C$ = the two tosses agree: every pair is independent, yet $P(A \cap B \cap C) = 1/4$, while $P(A)P(B)P(C) = 1/8$.

Independence is also not the same as being **mutually exclusive**. If $A$ and $B$ are disjoint and both have positive probability, then $P(A \cap B) = 0 \ne P(A)P(B)$, so they are dependent: knowing $A$ happened tells you $B$ did not.

@example
title: Drawing two aces
problem: Two cards are dealt from a well-shuffled 52-card deck without replacement. What is the probability that both are aces?
step: Let $A_1$ be "the first card is an ace" and $A_2$ "the second card is an ace". We want $P(A_1 \cap A_2)$.
step: $P(A_1) = 4/52$. Given $A_1$, 3 aces remain among 51 cards, so $P(A_2 \mid A_1) = 3/51$.
step: By the multiplication rule, $P(A_1 \cap A_2) = \frac{4}{52} \cdot \frac{3}{51} = \frac{12}{2652}$.
step: Simplify: $\frac{12}{2652} = \frac{1}{221}$.
answer: $1/221$

@example
title: Conditioning on different information
problem: A family has two children, and each is equally likely to be a girl or a boy, independently. Find the probability that both are girls (a) given that at least one is a girl, and (b) given that the older child is a girl.
step: The sample space is the four equally likely ordered pairs (older, younger): GG, GB, BG, BB.
step: (a) The event "at least one girl" is $\{GG, GB, BG\}$, with 3 outcomes. Only GG has two girls, so the conditional probability is $1/3$.
step: (b) The event "older is a girl" is $\{GG, GB\}$, with 2 outcomes. Only GG has two girls, so the conditional probability is $1/2$.
step: The two conditions give different answers because they remove different outcomes from the sample space.
answer: (a) $1/3$, (b) $1/2$

@mistakes
- Confusing $P(A \mid B)$ with $P(B \mid A)$; they are equal only in special cases.
- Multiplying probabilities for dependent events as if they were independent (for example, using $4/52 \cdot 4/52$ for two aces drawn without replacement).
- Believing that disjoint events are independent; disjoint events with positive probability are always dependent.
- Checking only pairs of events and concluding that three events are mutually independent.

@practice num
prompt: An urn holds 5 red and 3 blue balls. Two balls are drawn without replacement. What is the probability that both are red? Give an exact fraction.
answer: 5/14
check: Fraction(comb(5, 2), comb(8, 2))
hint: Use the multiplication rule: the first ball is red with probability $5/8$.
hint: After removing one red ball, 4 red remain among 7 balls.
solution: $P = \frac{5}{8} \cdot \frac{4}{7} = \frac{20}{56} = \frac{5}{14}$. Equivalently $\binom{5}{2} / \binom{8}{2} = 10/28 = 5/14$.

@practice mc
prompt: Events $A$ and $B$ are mutually exclusive (disjoint), and $P(A) > 0$ and $P(B) > 0$. Which statement is true?
choice: $A$ and $B$ are independent because they cannot influence each other.
choice*: $A$ and $B$ are not independent, because $P(A \cap B) = 0$ but $P(A)P(B) > 0$.
choice: $A$ and $B$ are independent only if $P(A) = P(B)$.
choice: $P(A \mid B) = P(A)$.
hint: Compute $P(A \cap B)$ for disjoint events and compare it with $P(A)P(B)$.
solution: For disjoint events $P(A \cap B) = 0$, while the product $P(A)P(B)$ is positive. The product rule fails, so they are dependent: learning that $B$ occurred tells you that $A$ did not.

model:
```python
from fractions import Fraction


def cond_prob(outcomes, event, given):
    in_given = [o for o in outcomes if given(o)]
    if not in_given:
        raise ValueError("conditioning event has probability 0")
    both = sum(1 for o in in_given if event(o))
    return Fraction(both, len(in_given))
```
hint: Conditioning on `given` keeps only the outcomes satisfying `given`.
hint: Among those, count the ones where `event` is also true; the answer is that count divided by the number of kept outcomes.
solution: Filter `outcomes` to those with `given(o)`; raise `ValueError` if none remain. Then the answer is `Fraction(both, len(in_given))`, where `both` counts the kept outcomes that also satisfy `event`. This is $|A \cap B| / |B|$.

model:
```python
from fractions import Fraction


def independent(outcomes, a, b):
    n = len(outcomes)
    p_a = Fraction(sum(1 for o in outcomes if a(o)), n)
    p_b = Fraction(sum(1 for o in outcomes if b(o)), n)
    p_both = Fraction(sum(1 for o in outcomes if a(o) and b(o)), n)
    return p_both == p_a * p_b
```
hint: Compute the three probabilities $P(A)$, $P(B)$ and $P(A \cap B)$ by counting outcomes.
hint: Compare `p_both` with `p_a * p_b`; with `Fraction` the comparison is exact.
solution: Count outcomes for `a`, for `b` and for both, divide each count by the total using `Fraction`, and return whether `p_both == p_a * p_b`. The impossible event is independent of everything, because both sides are $0$.

@quiz num
prompt: A fair coin is tossed three times. What is the probability of three heads given that at least one toss is heads? Give an exact fraction.
answer: 1/7
check: Fraction(1, 8) / (1 - Fraction(1, 8))
hint: The event "at least one head" is the complement of "no heads".
solution: $P(\text{at least one head}) = 1 - 1/8 = 7/8$. Three heads is contained in that event and has probability $1/8$, so $P = (1/8)/(7/8) = 1/7$.

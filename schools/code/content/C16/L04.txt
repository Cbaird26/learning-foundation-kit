@article
A **random variable** turns the outcome of an experiment into a number. Formally, it is a function $X : \Omega \to \mathbb{R}$. The experiment "toss a coin three times" has eight outcomes, but we often only care about the number of heads $X$, which takes values in $\{0, 1, 2, 3\}$. Writing $X$ as a function makes clear that the randomness lives in the outcome, and the variable is just a numerical summary of it.

### Probability mass function

A random variable is **discrete** if it takes finitely many or countably many values. Its **probability mass function** (PMF) is

$$p_X(x) = P(X = x).$$

Here $\{X = x\}$ is the event consisting of all outcomes that $X$ sends to $x$. A valid PMF satisfies $p_X(x) \ge 0$ for all $x$ and $\sum_x p_X(x) = 1$, where the sum runs over the possible values. Probabilities of events about $X$ come from adding PMF values: $P(X \in S) = \sum_{x \in S} p_X(x)$.

For the number of heads in 3 fair tosses, $p_X(0) = 1/8$, $p_X(1) = 3/8$, $p_X(2) = 3/8$ and $p_X(3) = 1/8$.

### Cumulative distribution function

The **cumulative distribution function** (CDF) is $F_X(x) = P(X \le x)$, defined for every real $x$. It is non-decreasing, right-continuous, tends to $0$ as $x \to -\infty$ and to $1$ as $x \to \infty$. For discrete $X$ it is a step function, and $P(a < X \le b) = F_X(b) - F_X(a)$. The CDF also works for continuous random variables, which we meet in week 7.

### Functions of a random variable

If $X$ is a random variable and $g$ is a function, then $g(X)$ is a random variable. To find its PMF, add up the probabilities of all $x$ that map to each value: $P(g(X) = y) = \sum_{x : g(x) = y} p_X(x)$. If $X$ is uniform on $\{-1, 0, 1\}$ then $X^2$ takes the value $0$ with probability $1/3$ and the value $1$ with probability $2/3$, because $x = -1$ and $x = 1$ both map to $1$.

### Joint distributions and independence

For two random variables on the same sample space, the **joint PMF** is $p_{X,Y}(x, y) = P(X = x, Y = y)$. The **marginal PMF** of $X$ is obtained by summing out $Y$: $p_X(x) = \sum_y p_{X,Y}(x, y)$.

Random variables $X$ and $Y$ are **independent** if $P(X = x, Y = y) = P(X = x)P(Y = y)$ for **all** pairs $(x, y)$, including those whose joint probability is zero. A single pair where the product rule fails is enough to show dependence. Two dice rolled separately are independent; the larger and the smaller of the two faces are not.

### Named distributions so far

A **Bernoulli**$(p)$ variable is $1$ with probability $p$ and $0$ with probability $1 - p$; it indicates whether an event happened. A **discrete uniform** variable on $\{1, \dots, n\}$ gives each value probability $1/n$. Week 6 develops the binomial, geometric and Poisson distributions.

@example
title: The sum of two dice
problem: Let $X$ be the sum of two fair dice. Find $P(X \ge 10)$, then find $F_X(4)$.
step: The 36 ordered pairs are equally likely. We count how many give each sum, which is the PMF numerator: sum 10 has 3 pairs, sum 11 has 2, sum 12 has 1.
step: $P(X \ge 10) = (3 + 2 + 1)/36 = 6/36 = 1/6$.
step: For the CDF at 4, add the counts for sums 2, 3 and 4: $1 + 2 + 3 = 6$ pairs.
step: $F_X(4) = P(X \le 4) = 6/36 = 1/6$.
answer: $P(X \ge 10) = 1/6$ and $F_X(4) = 1/6$

@example
title: A function of a random variable
problem: Let $X$ be the number of heads in 3 fair tosses and $Y = (X - 1)^2$. Find the PMF of $Y$.
step: The PMF of $X$ is $p_X(0) = 1/8$, $p_X(1) = 3/8$, $p_X(2) = 3/8$, $p_X(3) = 1/8$.
step: The map $x \mapsto (x - 1)^2$ sends $0 \mapsto 1$, $1 \mapsto 0$, $2 \mapsto 1$ and $3 \mapsto 4$.
step: $Y = 0$ only when $X = 1$, so $P(Y = 0) = 3/8$. $Y = 1$ when $X \in \{0, 2\}$, so $P(Y = 1) = 1/8 + 3/8 = 1/2$. $Y = 4$ only when $X = 3$, so $P(Y = 4) = 1/8$.
step: Check: $3/8 + 4/8 + 1/8 = 1$.
answer: $P(Y=0) = 3/8$, $P(Y=1) = 1/2$, $P(Y=4) = 1/8$

@mistakes
- Treating the random variable as a number rather than a function; $P(X = 3)$ is the probability of an event, not a probability "of the number 3".
- Writing a PMF whose values do not sum to 1, or that includes a negative value.
- Declaring $X$ and $Y$ independent after checking only some pairs of values, or only the marginals.
- Confusing the PMF $P(X = x)$ with the CDF $P(X \le x)$ when reading a table.

answer: 1/4
check: Fraction(sum(1 for a in range(1, 7) for b in range(1, 7) if max(a, b) == 5), 36)
hint: The maximum equals 5 if both faces are at most 5 and at least one face is 5.
solution: Pairs with maximum at most 5 number $25$, and pairs with maximum at most 4 number $16$, so exactly $25 - 16 = 9$ pairs have maximum 5. The probability is $9/36 = 1/4$.

assert pmf_of_sum(6)[7] == Fraction(1, 6)

model:
```python
from collections import Counter
from fractions import Fraction


def pmf_of_sum(sides):
    counts = Counter()
    for a in range(1, sides + 1):
        for b in range(1, sides + 1):
            counts[a + b] += 1
    total = sides * sides
    return {s: Fraction(c, total) for s, c in counts.items()}
```
hint: Count the ordered pairs `(a, b)` producing each sum.
hint: A `Counter` or dictionary of counts works; then divide every count by `sides * sides`.
solution: Loop over all ordered pairs, count how many give each sum, and divide each count by `sides * sides`. Only sums that occur appear as keys, so the dictionary has `2 * sides - 1` entries.

@quiz code
prompt: Write `are_independent(joint)` where `joint` is a dictionary mapping pairs `(x, y)` to $P(X = x, Y = y)$ as `Fraction` values (pairs that are missing have probability 0, and the values sum to 1). Return `True` exactly when the random variables $X$ and $Y$ are independent. Remember that the product rule must hold for every combination of an $x$ value and a $y$ value that appears in the dictionary, including combinations that are missing from it.
starter:
```python
from fractions import Fraction


def are_independent(joint):
    pass
```
tests:
```python
from fractions import Fraction

q = Fraction(1, 4)
assert are_independent({(0, 0): q, (0, 1): q, (1, 0): q, (1, 1): q}) is True
assert are_independent({(0, 0): Fraction(1, 2), (1, 1): Fraction(1, 2)}) is False
assert are_independent({(0, 0): Fraction(1, 2), (0, 1): Fraction(1, 2)}) is True
assert are_independent({(0, 0): Fraction(1, 2), (0, 1): q, (1, 0): q}) is False
```
model:
```python
from fractions import Fraction


def are_independent(joint):
    px = {}
    py = {}
    for (x, y), p in joint.items():
        px[x] = px.get(x, 0) + p
        py[y] = py.get(y, 0) + p
    for x in px:
        for y in py:
            if joint.get((x, y), 0) != px[x] * py[y]:
                return False
    return True
```
hint: First compute both marginals by summing the joint probabilities over the other variable.
hint: Then loop over every pair (x, y) of marginal values, using `joint.get((x, y), 0)` for pairs that are missing, and compare with the product of the marginals.
solution: Build the marginals `px` and `py`, then check `joint.get((x, y), 0) == px[x] * py[y]` for all `x` in `px` and `y` in `py`. Missing pairs matter: in the second test, $P(0, 1) = 0$ but $P(X = 0)P(Y = 1) = 1/4$, so the variables are dependent.

@quiz num
prompt: A filter classifies mail: 20% of messages are spam, the word "prize" appears in 50% of spam messages and in 5% of non-spam messages. What is the probability that a message containing "prize" is spam? Give an exact fraction.
answer: 5/7
check: Fraction(2, 10) * Fraction(5, 10) / (Fraction(2, 10) * Fraction(5, 10) + Fraction(8, 10) * Fraction(5, 100))
hint: Apply Bayes' rule with the law of total probability in the denominator.
solution: The numerator is $0.5 \cdot 0.2 = 0.1$ and the non-spam term is $0.05 \cdot 0.8 = 0.04$. So $P(\text{spam} \mid \text{prize}) = \frac{0.1}{0.14} = \frac{5}{7}$.

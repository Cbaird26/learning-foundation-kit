@article
A random variable has a whole distribution, but we often want a single number that summarizes it. The **expectation** (expected value, mean) is the probability-weighted average of its values.

### Definition

For a discrete random variable $X$ with PMF $p_X$,

$$E[X] = \sum_x x \, p_X(x).$$

It is the long-run average of $X$ over many independent repetitions of the experiment (the law of large numbers, week 8, makes this precise). For a fair die, $E[X] = \frac{1 + 2 + \cdots + 6}{6} = 3.5$, a value the die never shows: the expectation need not be a possible value. For a Bernoulli$(p)$ variable, $E[X] = 0(1-p) + 1(p) = p$.

### Expectation of a function

To find $E[g(X)]$ you do **not** need the distribution of $g(X)$ first. This is sometimes called the law of the unconscious statistician (LOTUS):

$$E[g(X)] = \sum_x g(x)\,p_X(x).$$

In general $E[g(X)] \ne g(E[X])$. For a fair die $E[X^2] = \frac{1 + 4 + 9 + 16 + 25 + 36}{6} = \frac{91}{6} \approx 15.17$, while $(E[X])^2 = 12.25$.

### Linearity of expectation

For any random variables $X$ and $Y$ on the same probability space and any constants $a$, $b$,

$$E[aX + bY] = a\,E[X] + b\,E[Y].$$

This holds **whether or not $X$ and $Y$ are independent**. That is what makes it the most useful tool in this course: you never need the joint distribution. By induction, $E[X_1 + \cdots + X_n] = E[X_1] + \cdots + E[X_n]$. (By contrast, $E[XY] = E[X]E[Y]$ is only guaranteed when $X$ and $Y$ are independent.)

### Indicator random variables

The **indicator** of an event $A$ is $I_A = 1$ if $A$ occurs and $0$ otherwise. It is Bernoulli with $E[I_A] = P(A)$. This is the **fundamental bridge** between expectation and probability.

To find the expected number of events that occur, write the count as a sum of indicators and apply linearity. Suppose $n$ people throw their hats in a pile and each receives a uniformly random hat back (a random permutation). Let $X$ be the number who get their own hat, and let $I_j$ indicate that person $j$ does. Then $P(I_j = 1) = 1/n$, so

$$E[X] = \sum_{j=1}^{n} E[I_j] = n \cdot \frac{1}{n} = 1,$$

for every $n$. The indicators are dependent, but linearity does not care.

### Waiting times and the coupon collector

Each purchase of a cereal box yields one of $n$ equally likely coupons, independently. Let $T$ be the number of boxes needed to collect all $n$ types. When you already hold $k$ distinct types, the next new type arrives with probability $(n-k)/n$ per box, so the waiting time is a geometric variable with mean $n/(n-k)$. Summing over $k = 0, \dots, n-1$ by linearity gives

$$E[T] = n\left(\frac{1}{n} + \frac{1}{n-1} + \cdots + \frac{1}{1}\right) = n H_n \approx n \ln n,$$

where $H_n$ is the $n$th harmonic number. The same analysis tells you how many random probes a randomized algorithm needs to see every bucket.

@example
title: Fixed points of a random permutation
problem: A random permutation of $\{1, \dots, n\}$ is chosen uniformly. What is the expected number of fixed points (positions $j$ with $\pi(j) = j$)?
step: Define $I_j = 1$ if $\pi(j) = j$ and $0$ otherwise. The number of fixed points is $X = I_1 + \cdots + I_n$.
step: Position $j$ is equally likely to receive any of the $n$ values, so $P(I_j = 1) = 1/n$ and $E[I_j] = 1/n$.
step: By linearity (no independence needed), $E[X] = n \cdot \frac{1}{n}$.
step: This is $1$, regardless of $n$.
answer: $1$

@example
title: Empty bins
problem: Four balls are thrown independently and uniformly into 4 bins. What is the expected number of empty bins?
step: Let $I_j = 1$ if bin $j$ is empty. The number of empty bins is $X = I_1 + I_2 + I_3 + I_4$.
step: A single ball misses bin $j$ with probability $3/4$. The four balls are independent, so $P(I_j = 1) = (3/4)^4 = 81/256$.
step: By linearity, $E[X] = 4 \cdot \frac{81}{256}$.
step: This simplifies to $81/64 \approx 1.27$.
answer: $81/64$

@mistakes
- Using $E[XY] = E[X]E[Y]$ (or $E[X^2] = (E[X])^2$) for variables that are not independent.
- Computing $E[g(X)]$ as $g(E[X])$ for nonlinear $g$.
- Thinking linearity requires independence; for sums it never does.
- Forgetting that an indicator's expectation is the probability of the event, then trying to enumerate the whole distribution of the count.

model:
```python
from fractions import Fraction


def coupon_expected(n):
    total = Fraction(0)
    for k in range(n):
        total += Fraction(n, n - k)
    return total
```

from fractions import Fraction

assert expected_collisions(3, 8) == Fraction(3, 8)

assert expected_collisions(10, 100) == Fraction(9, 20)

model:
```python
from fractions import Fraction
from math import comb


def expected_collisions(n_keys, m_slots):
    return Fraction(comb(n_keys, 2), m_slots)
```
hint: There are `comb(n_keys, 2)` pairs of keys, and each pair needs its own indicator.
hint: Two given keys land in the same slot with probability `1 / m_slots`.
solution: Each of the `comb(n_keys, 2)` pairs collides with probability $1/m$, so by linearity the expected number of colliding pairs is $\binom{n}{2}/m$. For 10 keys and 100 slots this is $45/100 = 9/20$.

@quiz num
prompt: A fair coin is tossed 10 times. Let $X$ be the number of positions $i$ from 1 to 9 at which toss $i$ and toss $i + 1$ show the same face. Find $E[X]$ as an exact value.
answer: 9/2
check: 9 * Fraction(1, 2)
hint: Use one indicator for each of the 9 adjacent pairs.
solution: Two adjacent tosses agree with probability $1/2$ (whatever the first shows, the second matches it with probability $1/2$). Neighboring indicators share a toss, and linearity does not need independence in any case: $E[X] = 9 \cdot \frac12 = \frac92$.

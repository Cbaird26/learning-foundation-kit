@article
Many random processes have **no memory beyond the present state**: the next page a web surfer visits depends on the current page, not on how they arrived. A **Markov chain** formalizes this.

### Definition

A (discrete-time, finite) **Markov chain** is a sequence of random variables $X_0, X_1, X_2, \dots$ taking values in a finite set of **states** such that

$$P(X_{t+1} = j \mid X_t = i, X_{t-1}, \dots, X_0) = P(X_{t+1} = j \mid X_t = i) = P_{ij}.$$

This is the **Markov property**. The numbers $P_{ij}$ form the **transition matrix** $P$: every entry is non-negative and every **row** sums to 1, because row $i$ is a probability distribution over the next state.

### Distributions after $t$ steps

Write the distribution of $X_t$ as a row vector $\pi_t$ with $(\pi_t)_i = P(X_t = i)$. By the law of total probability,

$$\pi_{t+1} = \pi_t P, \qquad \text{so} \qquad \pi_t = \pi_0 P^t.$$

The entry $(P^t)_{ij}$ is the probability of going from $i$ to $j$ in exactly $t$ steps. For example, $(P^2)_{ij} = \sum_k P_{ik}P_{kj}$: sum over the intermediate state $k$.

### Stationary distributions

A distribution $\pi$ is **stationary** if $\pi = \pi P$: once the chain has distribution $\pi$ it keeps it. Together with $\sum_i \pi_i = 1$, this is a linear system. For a two-state chain with $P(1 \to 2) = a$ and $P(2 \to 1) = b$, balance of flow gives $\pi_1 a = \pi_2 b$, hence $\pi = \big(\tfrac{b}{a+b}, \tfrac{a}{a+b}\big)$.

**Convergence theorem.** A finite chain is **irreducible** if every state can reach every other state, and **aperiodic** if it does not cycle with a fixed period. An irreducible, aperiodic finite chain has a *unique* stationary distribution $\pi$, and $\pi_0 P^t \to \pi$ for **every** starting distribution. A chain that deterministically alternates between two states is irreducible but periodic: it has a stationary distribution $(1/2, 1/2)$ but never converges to it from a fixed start.

### Random walks

**Gambler's ruin.** A walker starts at $i \in \{0, 1, \dots, N\}$ and each step moves $+1$ or $-1$ with probability $1/2$, stopping on reaching $0$ or $N$ (the **absorbing** states). Then

- $P(\text{reach } N \text{ before } 0) = i/N$, and
- the expected number of steps until absorption is $i(N - i)$.

The second fact explains why a random walk takes about $n^2$ steps to travel distance $n$.

**Random walk on a graph.** At each step move to a uniformly random neighbor. On a connected undirected graph with $m$ edges, the stationary distribution is $\pi(v) = \deg(v)/(2m)$: visits are proportional to degree. If the graph is not bipartite the walk is also aperiodic, so it converges to $\pi$. A path $a - b - c$ has $m = 2$ and $\pi = (1/4, 1/2, 1/4)$. Web ranking by the "random surfer" is a random walk on the link graph with occasional random jumps.

### Computing with transition matrices

```python
P = [[0.9, 0.1],
     [0.5, 0.5]]
pi = [1.0, 0.0]
for _ in range(2):
    pi = [sum(pi[i] * P[i][j] for i in range(2)) for j in range(2)]
print(pi)  # about [0.86, 0.14]
```

@example
title: A weather chain
problem: A chain has states Sunny and Rainy with $P(\text{S} \to \text{R}) = 0.1$ and $P(\text{R} \to \text{S}) = 0.5$. Find its stationary distribution.
step: Let $\pi = (\pi_S, \pi_R)$. Balance of flow between the two states requires $\pi_S \cdot 0.1 = \pi_R \cdot 0.5$.
step: So $\pi_S = 5\pi_R$.
step: Normalize with $\pi_S + \pi_R = 1$: $6\pi_R = 1$, so $\pi_R = 1/6$ and $\pi_S = 5/6$.
step: Check $\pi = \pi P$: the Sunny entry is $\frac56(0.9) + \frac16(0.5) = \frac{4.5 + 0.5}{6} = \frac56$.
answer: $\pi = (5/6,\ 1/6)$

@example
title: Gambler's ruin
problem: A fair gambler starts with 3 units and bets 1 unit per round until reaching 10 or 0. Find the probability of reaching 10 and the expected number of rounds.
step: This is the walk on $\{0, \dots, 10\}$ with $N = 10$ and start $i = 3$.
step: $P(\text{reach } 10) = i/N = 3/10$.
step: The expected number of rounds is $i(N - i) = 3 \cdot 7 = 21$.
answer: probability $3/10$, expected $21$ rounds

@mistakes
- Making columns (instead of rows) sum to 1, or using a transition "matrix" with a row that does not sum to 1.
- Multiplying a row vector by $P$ in the wrong order, or using $\pi P^t$ when you needed a single step.
- Assuming every chain converges to its stationary distribution; periodic and reducible chains need care.
- Forgetting that the stationary probability of a vertex in a graph walk is proportional to its degree, not equal for all vertices.

@practice num
prompt: A chain on states $0, 1, 2$ has transition matrix with rows $(0, 1, 0)$, $(0, 0, 1)$ and $(1/2, 0, 1/2)$. Find the probability of being in state 0 two steps after starting in state 2, as an exact fraction.
answer: 1/4
check: (lambda P: sum(P[2][k] * P[k][0] for k in range(3)))([[0, 1, 0], [0, 0, 1], [Fraction(1, 2), 0, Fraction(1, 2)]])
hint: Sum over the intermediate state $k$ of $P_{2k} P_{k0}$.
solution: From state 2 the chain goes to 0 or 2 with probability $1/2$ each. From 0 it moves to 1 (not 0), and from 2 it moves to 0 with probability $1/2$. So $(P^2)_{20} = \frac12 \cdot 0 + \frac12 \cdot \frac12 = \frac14$.

model:
```python
def step_distribution(pi, P, t):
    n = len(pi)
    current = list(pi)
    for _ in range(t):
        current = [sum(current[i] * P[i][j] for i in range(n))
                   for j in range(n)]
    return current
```
hint: One step computes, for each state `j`, the sum over `i` of `current[i] * P[i][j]`.
hint: Copy `pi` into a new list first and rebuild the whole list on each step.
solution: Each step maps the row vector to `[sum(current[i] * P[i][j] for i in range(n)) for j in range(n)]`. After many steps the result is close to the stationary distribution $(5/6, 1/6)$ whatever the start, as the convergence theorem predicts.

model:
```python
from fractions import Fraction


def random_walk_stationary(adj):
    total = sum(len(neighbors) for neighbors in adj.values())
    return {v: Fraction(len(nbrs), total) for v, nbrs in adj.items()}
```
hint: The sum of all degrees equals twice the number of edges.
hint: The stationary probability of a vertex is its degree divided by that total.
solution: Compute `total = sum of degrees` and return `Fraction(degree, total)` for each vertex. For the star with centre degree 3 and total degree 6, the centre has probability $1/2$ and each leaf $1/6$.

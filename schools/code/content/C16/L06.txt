### Variance

The **variance** of $X$ with mean $\mu = E[X]$ is the expected squared deviation,

$$\mathrm{Var}(X) = E\big[(X - \mu)^2\big] = E[X^2] - (E[X])^2,$$

and the **standard deviation** is $\mathrm{SD}(X) = \sqrt{\mathrm{Var}(X)}$, which has the same units as $X$. The second form follows by expanding the square and using linearity. Two rules matter:

- $\mathrm{Var}(aX + b) = a^2\,\mathrm{Var}(X)$: shifting changes nothing and scaling by $a$ scales the variance by $a^2$.
- If $X$ and $Y$ are **independent**, $\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$. Unlike linearity of expectation, this needs independence (or at least zero covariance).

For a fair die, $E[X^2] = 91/6$ and $(E[X])^2 = 49/4$, so $\mathrm{Var}(X) = \frac{91}{6} - \frac{49}{4} = \frac{35}{12}$.

### Four workhorse distributions

- **Bernoulli$(p)$**: one trial, success with probability $p$. Mean $p$, variance $p(1-p)$.
- **Binomial$(n, p)$**: the number of successes in $n$ independent Bernoulli$(p)$ trials. $P(X = k) = \binom{n}{k}p^k(1-p)^{n-k}$ for $k = 0, \dots, n$. Mean $np$ and variance $np(1-p)$ follow from writing $X$ as a sum of $n$ independent indicators.
- **Geometric$(p)$**: the number of independent trials up to and including the first success. $P(X = k) = (1-p)^{k-1}p$ for $k = 1, 2, \dots$. Mean $1/p$, variance $(1-p)/p^2$. (Some books count only the failures; always check the convention.)
- **Poisson$(\lambda)$**: counts of rare, independent events in a fixed interval, such as requests arriving in a minute. $P(X = k) = e^{-\lambda}\lambda^k/k!$ for $k = 0, 1, 2, \dots$, with mean and variance both equal to $\lambda$. It approximates Binomial$(n, p)$ when $n$ is large, $p$ is small and $\lambda = np$.

### Expected costs of randomized algorithms

Randomized algorithms are analyzed by **expected** cost over their internal coin flips, for a worst-case input.

**Las Vegas restarts.** If an attempt costs $c$ and succeeds with probability $p$ independently, the number of attempts is Geometric$(p)$ and the expected total cost is $c/p$.

**Hashing with chaining.** With $n$ keys hashed uniformly into $m$ slots, a given key shares its slot with each of the other $n-1$ keys with probability $1/m$, so by linearity its expected number of chain neighbors is $(n-1)/m$.

**Randomized quicksort.** Pick the pivot uniformly at random among the $n$ elements. Partitioning compares the pivot with the other $n-1$ elements, and the pivot's rank is uniform, so the expected number of comparisons $C_n$ satisfies

$$C_n = (n - 1) + \frac{2}{n}\sum_{k=0}^{n-1} C_k, \qquad C_0 = C_1 = 0.$$

The solution is $C_n = 2(n+1)H_n - 4n \approx 1.39\,n\log_2 n$, where $H_n$ is the harmonic number. For $n = 3$ the recurrence gives $C_3 = 2 + \frac23(0 + 0 + 1) = \frac83$, matching a direct count.

@example
title: Variance of a fair die
problem: Find the variance and standard deviation of one roll of a fair six-sided die.
step: The mean is $E[X] = 7/2$ and $E[X^2] = (1 + 4 + 9 + 16 + 25 + 36)/6 = 91/6$.
step: Use $\mathrm{Var}(X) = E[X^2] - (E[X])^2 = \frac{91}{6} - \frac{49}{4}$.
step: With denominator 12 this is $\frac{182}{12} - \frac{147}{12} = \frac{35}{12}$.
step: The standard deviation is $\sqrt{35/12} \approx 1.71$.
answer: $\mathrm{Var}(X) = 35/12 \approx 2.92$, $\mathrm{SD}(X) \approx 1.71$

@example
title: Expected cost of a restart algorithm
problem: A randomized algorithm picks a random candidate and verifies it. One attempt costs 10 operations and succeeds with probability $1/4$, independently each time. Find the expected total cost until the first success.
step: The number of attempts $N$ is Geometric$(1/4)$, so $E[N] = 1/p = 4$.
step: Each attempt costs 10, so the total cost is $10N$.
step: By linearity (scaling), $E[10N] = 10\,E[N] = 40$.
answer: $40$ operations

@mistakes
- Adding variances of variables that are not independent, or forgetting that $\mathrm{Var}(aX) = a^2\mathrm{Var}(X)$, not $a\,\mathrm{Var}(X)$.
- Mixing up geometric conventions: counting trials including the success (mean $1/p$) versus counting failures only (mean $(1-p)/p$).
- Using the binomial when trials are not independent or the success probability changes (sampling without replacement is hypergeometric).
- Computing the expected cost of a randomized algorithm as the cost of the "average case input" instead of averaging over the algorithm's own random choices.

```python
from fractions import Fraction


def expected_quicksort_comparisons(n):
    c = [Fraction(0)] * (n + 1)
    for m in range(2, n + 1):
        c[m] = (m - 1) + Fraction(2, m) * sum(c[:m])
    return c[n]
```
hint: Build a table `c[0], c[1], ..., c[n]` from smallest to largest.
hint: For `m >= 2`, `c[m] = (m - 1) + Fraction(2, m) * sum(c[:m])`.
solution: Dynamic programming over `m` evaluates the recurrence with exact fractions: partitioning costs `m - 1` comparisons and the two subproblems have sizes `k` and `m - 1 - k` with `k` uniform, which by symmetry gives the factor $\frac{2}{m}\sum_{k<m} C_k$. For $n = 10$ the value is about $24.44$.

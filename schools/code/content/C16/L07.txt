@article
Some quantities, such as a waiting time or a measurement error, can take any value in an interval. A **continuous** random variable has no probability mass at individual points; probability is spread out over intervals.

### Density and CDF

A continuous random variable $X$ has a **probability density function** (PDF) $f$ with $f(x) \ge 0$ and $\int_{-\infty}^{\infty} f(x)\,dx = 1$, such that

$$P(a \le X \le b) = \int_a^b f(x)\,dx.$$

The density is *not* a probability: $f(x)$ can exceed 1, and $P(X = x) = 0$ for every single value $x$, so it does not matter whether endpoints are included. The CDF is $F(x) = P(X \le x) = \int_{-\infty}^x f(t)\,dt$, and where $F$ is differentiable, $f(x) = F'(x)$. The mean and variance replace sums by integrals: $E[X] = \int x f(x)\,dx$ and $\mathrm{Var}(X) = E[X^2] - (E[X])^2$. Linearity of expectation and the variance rules from weeks 5 and 6 still hold.

### The uniform distribution

$X \sim \mathrm{Unif}(a, b)$ has density $1/(b-a)$ on $[a, b]$ and $0$ elsewhere. Probabilities are proportional to length: $P(c \le X \le d) = (d - c)/(b - a)$ for $a \le c \le d \le b$. The mean is $(a + b)/2$ and the variance is $(b-a)^2/12$. A call to `random.random()` in Python produces (an approximation of) a $\mathrm{Unif}(0, 1)$ variable.

### The exponential distribution

$X \sim \mathrm{Exp}(\lambda)$ with rate $\lambda > 0$ has density $\lambda e^{-\lambda x}$ for $x \ge 0$. Then $P(X > x) = e^{-\lambda x}$, the CDF is $F(x) = 1 - e^{-\lambda x}$, the mean is $1/\lambda$ and the variance is $1/\lambda^2$. It models the waiting time until the next event in a process of independent events at a constant rate, such as the gap between requests arriving at a server (the counts in a fixed interval are then Poisson).

It is **memoryless**: $P(X > s + t \mid X > s) = P(X > t)$. If you have already waited $s$ minutes, the distribution of the remaining wait is exactly as if you had just started. Among continuous distributions on $[0, \infty)$, only the exponential has this property.

**Sampling by inversion.** If $U \sim \mathrm{Unif}(0,1)$, then $-\ln(1 - U)/\lambda \sim \mathrm{Exp}(\lambda)$, because solving $F(x) = u$ gives $x = -\ln(1-u)/\lambda$. The same trick turns uniform random numbers into samples of any distribution with an invertible CDF.

### The normal distribution

$X \sim N(\mu, \sigma^2)$ has density

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}}\,e^{-(x-\mu)^2/(2\sigma^2)},$$

with mean $\mu$ and standard deviation $\sigma$. The bell curve is symmetric about $\mu$. Two properties make it central:

- **Standardization.** If $X \sim N(\mu, \sigma^2)$ then $Z = (X - \mu)/\sigma \sim N(0, 1)$, the **standard normal**. So $P(X \le x) = \Phi\big((x - \mu)/\sigma\big)$, where $\Phi$ is the standard normal CDF.
- **Closure.** Sums and linear functions of independent normal variables are normal; means add and variances add.

The CDF $\Phi$ has no elementary formula, but it can be computed from the error function: $\Phi(z) = \tfrac12\big(1 + \mathrm{erf}(z/\sqrt2)\big)$, available in Python as `math.erf`. The **68-95-99.7 rule** says a normal variable lies within $1$, $2$ and $3$ standard deviations of its mean with probability about $0.683$, $0.954$ and $0.997$. A useful value to remember is $\Phi(1.96) \approx 0.975$.

```python
import math


def phi(z):
    return 0.5 * (1 + math.erf(z / math.sqrt(2)))


print(round(phi(1.96), 4))  # 0.975
```

@example
title: A waiting time
problem: The time between requests is exponential with mean 2 seconds. What is the probability that the next request takes more than 3 seconds?
step: The mean is $1/\lambda = 2$, so the rate is $\lambda = 1/2$ per second.
step: For an exponential variable, $P(X > x) = e^{-\lambda x}$.
step: So $P(X > 3) = e^{-3/2}$.
step: Numerically $e^{-1.5} \approx 0.2231$.
answer: $e^{-3/2} \approx 0.2231$

@example
title: Standardizing a normal variable
problem: Exam scores are modeled as $N(70, 10^2)$. What fraction of students score above 85?
step: The score 85 is $(85 - 70)/10 = 1.5$ standard deviations above the mean, so $P(X > 85) = P(Z > 1.5)$.
step: By symmetry and complements, $P(Z > 1.5) = 1 - \Phi(1.5)$.
step: Using $\Phi(1.5) \approx 0.9332$, we get $1 - 0.9332 = 0.0668$.
answer: about $0.0668$ (6.7%)

@mistakes
- Treating a density value as a probability; $f(x)$ can be larger than 1 and $P(X = x) = 0$.
- Forgetting to standardize by dividing by the standard deviation $\sigma$ (not the variance $\sigma^2$).
- Mixing up the rate $\lambda$ and the mean $1/\lambda$ of an exponential variable.
- Reading a left-tail table or CDF value as a right-tail probability; $P(Z > z) = 1 - \Phi(z)$.

@practice num
prompt: The function $f(x) = cx$ for $0 \le x \le 2$ (and $0$ elsewhere) is a probability density function. Find $c$ as an exact fraction.
answer: 1/2
check: 1 / (Fraction(2) ** 2 / 2)
hint: A density must integrate to 1 over its support.
solution: $\int_0^2 cx\,dx = c \cdot \frac{2^2}{2} = 2c = 1$, so $c = 1/2$.

@practice num
prompt: Scores are modeled as $N(100, 15^2)$. Find $P(X > 130)$, rounded to 4 decimal places.
answer: 0.0228
tol: 0.0005
check: 0.5 * (1 - math.erf(2 / math.sqrt(2)))
hint: How many standard deviations above the mean is 130?
hint: It is $z = 2$. Use $P(Z > 2) = 1 - \Phi(2)$ and $\Phi(2) \approx 0.9772$.
solution: $z = (130 - 100)/15 = 2$, so $P(X > 130) = 1 - \Phi(2) \approx 1 - 0.97725 = 0.0228$.

model:
```python
import math


def exponential_quantile(p, rate):
    return -math.log(1 - p) / rate
```
hint: Solve $p = 1 - e^{-\lambda x}$ for $x$.
hint: $e^{-\lambda x} = 1 - p$, so take the natural logarithm of both sides.
solution: From $1 - e^{-\lambda x} = p$ we get $x = -\ln(1 - p)/\lambda$, which is `-math.log(1 - p) / rate`. For $p = 0$ this is $0$ (note `-math.log(1.0)` is `-0.0`, which equals `0.0`).

@quiz num
prompt: A request takes an exponentially distributed time with mean 4 seconds. Find the probability that it takes less than 2 seconds, rounded to 4 decimal places.
answer: 0.3935
tol: 0.0005
check: 1 - math.exp(-2 / 4)
hint: The rate is the reciprocal of the mean. Use $F(x) = 1 - e^{-\lambda x}$.
solution: The rate is $\lambda = 1/4$, so $P(X < 2) = 1 - e^{-2/4} = 1 - e^{-0.5} \approx 0.3935$.

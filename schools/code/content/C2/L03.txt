@article
A **proof** is a finite sequence of statements, each an assumption, a definition, or a consequence of earlier ones by valid reasoning, ending in the claim. Checking examples is not a proof of a universal statement; one counterexample, however, is enough to disprove it. The famous polynomial $n^2 - n + 41$ is prime for $n = 0, 1, \dots, 40$, yet $n = 41$ gives $41^2$, which is not prime.

### Definitions do the work

Most first proofs are won by unfolding definitions. An integer $n$ is **even** if $n = 2k$ for some integer $k$, and **odd** if $n = 2k + 1$ for some integer $k$. For integers $a$ and $b$, $a \mid b$ ("$a$ divides $b$") means $b = ak$ for some integer $k$. A real number is **rational** if it equals $a/b$ for integers $a, b$ with $b \neq 0$.

### Direct proof

To prove $p \to q$ directly, assume $p$ and derive $q$.

*Claim.* The sum of two odd integers is even. *Proof.* Let $m = 2a + 1$ and $n = 2b + 1$. Then $m + n = 2a + 2b + 2 = 2(a + b + 1)$, which is twice an integer, so it is even. $\blacksquare$

Write a proof like a short argument to a skeptical reader: introduce names for the objects, say what you assume, and justify each step by a definition or a known fact.

### Proof by contrapositive

Since $p \to q \equiv \neg q \to \neg p$, you may prove $\neg q \to \neg p$ instead. This helps when the hypothesis $p$ gives little to work with but $\neg q$ gives a lot. Announce the technique ("We prove the contrapositive") and state precisely what is assumed.

### Proof by contradiction

To prove a statement $S$, assume $\neg S$ and derive a **contradiction**: a statement of the form $r \land \neg r$, or any fact known to be false. Since correct reasoning from a true assumption cannot produce a falsehood, the assumption $\neg S$ must be false, so $S$ is true. Always state the assumption at the start ("Suppose, for contradiction, that ...") and name the contradiction at the end.

Contradiction proves implications too: to prove $p \to q$, assume $p \land \neg q$ and derive a contradiction. The contrapositive is a special case of this where the contradiction is "$p$ and $\neg p$".

### Choosing a technique

1. Try a direct proof: unfold the definitions in the hypothesis.
2. If the conclusion is a negative statement ("is not", "is irrational", "no such $x$ exists"), contradiction is natural.
3. If the hypothesis is awkward but the negated conclusion is concrete (an integer is *not* even), try the contrapositive.

### Common traps

- Proving the **converse** instead of the statement.
- Using a single example as a proof of "for all".
- **Circular reasoning**: using the claim, or something equivalent to it, as a step.
- Saying "since $n$ is even, $n = 2k$" and later reusing the same $k$ for a different quantity.

@example
title: A contrapositive proof
problem: Prove that if $n^2$ is even then $n$ is even, for every integer $n$.
step: The hypothesis "$n^2$ is even" is hard to unfold, so prove the contrapositive: if $n$ is odd then $n^2$ is odd.
step: Assume $n$ is odd, so $n = 2k + 1$ for some integer $k$.
step: Then $n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1$, and $2k^2 + 2k$ is an integer, so $n^2$ is odd.
step: We proved the contrapositive, which is equivalent to the original statement. $\blacksquare$
answer: The contrapositive (odd $n$ gives odd $n^2$) is true, so the original implication holds.

@example
title: A proof by contradiction
problem: Prove that $\sqrt{2}$ is irrational.
step: Suppose, for contradiction, that $\sqrt{2} = a/b$ with integers $a, b$, $b \neq 0$, written in lowest terms so that $\gcd(a, b) = 1$.
step: Squaring gives $a^2 = 2b^2$. So $a^2$ is even, and by the previous example $a$ is even. Write $a = 2k$.
step: Substituting, $4k^2 = 2b^2$, so $b^2 = 2k^2$. Thus $b^2$ is even, and again $b$ is even.
step: Now $a$ and $b$ are both even, so $2$ divides both, contradicting $\gcd(a, b) = 1$.
step: The assumption led to a contradiction, so $\sqrt{2}$ is not rational. $\blacksquare$
answer: Assuming $\sqrt{2} = a/b$ in lowest terms forces both $a$ and $b$ to be even, a contradiction.

@mistakes
- Proving the converse: showing "if $n$ is even then $n^2$ is even" does not prove "if $n^2$ is even then $n$ is even".
- Treating several examples as a proof of a statement for all integers.
- Starting a proof by contradiction without stating the assumption, or ending without identifying the contradiction.
- Assuming what is to be proved (circular reasoning), for example using "$\sqrt{2}$ is not a fraction" while proving it.

@practice self
prompt: Prove that the sum of a rational number and an irrational number is irrational.
hint: Assume the sum is rational and look for a way to express $x$ in terms of rational numbers.
solution: Let $r$ be rational and $x$ irrational. Suppose, for contradiction, that $r + x$ is rational. Write $r = a/b$ and $r + x = c/d$ with integers $a, b, c, d$ and $b, d \neq 0$. Then $x = c/d - a/b = (cb - ad)/(bd)$. The numerator is an integer and the denominator $bd$ is a non-zero integer, so $x$ is rational. This contradicts the assumption that $x$ is irrational. Therefore $r + x$ is irrational.
rubric: States the proof method and the assumption: $r + x$ is rational, with $r$ rational and $x$ irrational.
rubric: Expresses $x$ as a difference of two rationals, written with integer numerators and non-zero integer denominators.
rubric: Shows that the difference is rational (denominator $bd \neq 0$) and names the contradiction with $x$ being irrational.

@quiz mc
prompt: A proof by contradiction that $\sqrt{3}$ is irrational begins with $\sqrt{3} = a/b$ in lowest terms and derives $a^2 = 3b^2$. Which continuation produces the contradiction?
choice: $a$ is even and $b$ is odd, which is impossible since $3$ is odd.
choice*: $3 \mid a^2$ forces $3 \mid a$; writing $a = 3k$ gives $b^2 = 3k^2$, so $3 \mid b$ too, contradicting lowest terms.
choice: The equation $a^2 = 3b^2$ has no integer solutions at all because $3$ is not a perfect square.
choice: Taking $b = 0$ makes the equation true, so $a = 0$, which is allowed.
hint: Repeat the argument for $\sqrt{2}$, replacing "even" by "divisible by 3".
solution: From $a^2 = 3b^2$, $3$ divides $a^2$, and since $3$ is prime it divides $a$. Then $a = 3k$, so $9k^2 = 3b^2$ and $b^2 = 3k^2$, so $3 \mid b$. Now $3$ divides both $a$ and $b$, contradicting $\gcd(a, b) = 1$. The equation $a^2 = 3b^2$ does have the solution $a = b = 0$, so the "no solutions" choice is false (and $b = 0$ is excluded from fractions).

@quiz self
prompt: Prove by contrapositive: for every integer $n$, if $3n + 2$ is odd then $n$ is odd.
hint: Negate the conclusion and the hypothesis, swap them, and use $n = 2k$.
solution: We prove the contrapositive: if $n$ is even then $3n + 2$ is even. Suppose $n$ is even, so $n = 2k$ for some integer $k$. Then $3n + 2 = 6k + 2 = 2(3k + 1)$, and $3k + 1$ is an integer, so $3n + 2$ is even. This proves the contrapositive, and therefore the original statement.

@article
### Measuring with a ruler

A ruler has a line for each inch or centimeter. To measure, line up one end of the object with the **0** mark. Then read the number at the other end. A pencil that stops at 6 is 6 units long.

Sometimes an object does not start at 0. If a string starts at 2 and ends at 5, count the steps between: 3, so it is 3 units long. You can also subtract: $5 - 2 = 3$.

Pick a unit that fits. Use **centimeters** or **inches** for a pencil. Use **meters** or **feet** for a room. Use **kilometers** or **miles** for a long trip.

### Surveys and tally marks

A **survey** asks a group the same question. We write one tally mark for each answer. We group tallies in fives, with the fifth mark going across the other four.

### Bar graphs

A **bar graph** uses bars to show how many. Each bar is for one choice, such as a kind of fruit. The taller the bar, the more answers.

To make one:

- Write a title, such as "Favorite Fruit."
- Label the bottom with the choices.
- Number the side by 1s or 2s.
- Draw each bar as high as its number.

To find **how many more**, subtract. If 6 children like grapes and 3 like bananas, then $6 - 3 = 3$ more like grapes. To find **how many in all**, add the bars.

@example
title: Read a bar graph
problem: A bar graph shows favorite fruits: apples 5, bananas 3, grapes 6. How many more children chose grapes than bananas? How many children answered in all?
step: Find the bars for grapes (6) and bananas (3).
step: How many more? Subtract: $6 - 3 = 3$. Three more children chose grapes.
step: How many in all? Add all three bars: $5 + 3 + 6 = 14$ children.

@mistakes
- Measuring from the end of the ruler instead of lining the object up with 0.
- Adding when the question asks how many more. Subtract to compare.
- Forgetting to label the bars or give the graph a title.

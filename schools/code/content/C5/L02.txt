@article
A recursive algorithm's running time is itself defined recursively. Merge sort splits the input in half, sorts each half, and merges in linear time, so

$$T(n) = 2\,T(n/2) + \Theta(n), \qquad T(1) = \Theta(1).$$

A **recurrence** like this is not yet a bound. We need a closed form such as $T(n) = \Theta(n \log n)$.

### Recursion trees

Draw one node per recursive call, labelled with the non-recursive work it does. Sum the labels level by level, then sum over levels. For $T(n) = 2T(n/2) + n$:

- Level 0 has one call of size $n$: work $n$.
- Level 1 has 2 calls of size $n/2$: work $2 \cdot n/2 = n$.
- Level $i$ has $2^i$ calls of size $n/2^i$: work $n$.
- The tree has about $\log_2 n$ levels, plus a bottom level of $n$ leaves.

Each of the $\log_2 n$ levels costs $n$, so $T(n) = \Theta(n \log n)$.

### Substitution

To **verify** a guess, prove it by induction. Claim: $T(n) \le c\,n \log_2 n$ for $T(n) = 2T(n/2) + n$ and suitable $c$, $n \ge 2$. Assume it holds for $n/2$. Then
$$T(n) \le 2c\,\tfrac n2 \log_2 \tfrac n2 + n = c\,n(\log_2 n - 1) + n = c\,n\log_2 n - (c-1)n \le c\,n\log_2 n$$
whenever $c \ge 1$. The base case fixes the remaining constants. The classic trap is an induction that "proves" something false by hiding a constant: always prove the **exact** inequality you assumed.

### The master theorem

For $T(n) = a\,T(n/b) + f(n)$ with $a \ge 1$, $b > 1$, let $p = \log_b a$ (the exponent of the number of leaves, $n^p$). In the common case $f(n) = \Theta(n^d)$:

| Compare $d$ with $p$ | Who dominates | Solution |
|---|---|---|
| $d < p$ | the leaves | $T(n) = \Theta(n^{p})$ |
| $d = p$ | every level equally | $T(n) = \Theta(n^{d} \log n)$ |
| $d > p$ | the root | $T(n) = \Theta(n^{d})$ |

Examples: $T(n) = 8T(n/2) + n^2$ has $p = 3 > 2$, so $\Theta(n^3)$. $T(n) = T(n/2) + 1$ has $p = 0 = d$, so $\Theta(\log n)$ (binary search). $T(n) = 3T(n/2) + n$ has $p = \log_2 3 \approx 1.585$, so $\Theta(n^{\log_2 3})$ (Karatsuba multiplication, next week).

The general theorem allows any $f$: if $f(n) = O(n^{p-\varepsilon})$ the leaves win; if $f(n) = \Theta(n^p)$ you get $\Theta(n^p \log n)$; and if $f(n) = \Omega(n^{p+\varepsilon})$ **and** $a f(n/b) \le k f(n)$ for some $k < 1$ (the regularity condition), the root wins with $T(n) = \Theta(f(n))$.

### When it does not apply

The theorem needs a polynomial gap. $T(n) = 2T(n/2) + n\log n$ falls between cases: $f$ is bigger than $n^p = n$ but not by a polynomial factor. A recursion tree gives $\log n$ levels each costing $n \log(n/2^i)$, which sums to $\Theta(n \log^2 n)$. Recurrences that shrink by subtraction, such as $T(n) = T(n-1) + n$, are not of the form $T(n/b)$ either. Unrolling gives $n + (n-1) + \dots = \Theta(n^2)$, and $T(n) = 2T(n-1) + 1$ gives $\Theta(2^n)$.

### Check your solution by computing

For powers of two you can compute $T(n)$ exactly from the recurrence and compare it with your formula. For $T(1) = 1$, $T(n) = 2T(n/2) + n$ the exact value is $n\log_2 n + n$.

@example
title: Applying the master theorem
problem: Solve $T(n) = 4\,T(n/2) + n^2$ and $T(n) = 4\,T(n/2) + n$, both with $T(1) = 1$.
step: Read off $a = 4$ and $b = 2$, so $p = \log_2 4 = 2$ for both recurrences.
step: First recurrence: $f(n) = n^2$, so $d = 2 = p$. Every level costs the same, so $T(n) = \Theta(n^2 \log n)$.
step: Second recurrence: $f(n) = n$, so $d = 1 < p = 2$. The leaves dominate, so $T(n) = \Theta(n^2)$.
step: Sanity check on the second: level $i$ has $4^i$ calls of size $n/2^i$, costing $4^i \cdot n/2^i = 2^i n$. The costs double each level, so the last level, with $n^2$ leaves, dominates the geometric sum.
answer: $\Theta(n^2 \log n)$ and $\Theta(n^2)$.

@example
title: A recurrence outside the master theorem
problem: Solve $T(n) = T(n-1) + n$ with $T(0) = 0$.
step: The input shrinks by subtraction, not by a constant factor, so the master theorem does not apply. Unroll instead.
step: $T(n) = n + T(n-1) = n + (n-1) + T(n-2) = \dots$
step: After $n$ expansions, $T(n) = n + (n-1) + \dots + 1 + T(0) = n(n+1)/2$.
step: Prove it by induction: $T(0) = 0$, and $T(n) = n + \frac{(n-1)n}{2} = \frac{n(n+1)}{2}$.
answer: $T(n) = n(n+1)/2 = \Theta(n^2)$.

@mistakes
- Using the master theorem when $f(n)$ is not polynomially larger or smaller than $n^{\log_b a}$, as in $2T(n/2) + n\log n$.
- Computing $\log_b a$ with $a$ and $b$ swapped. For $8T(n/2)$ it is $\log_2 8 = 3$, not $\log_8 2$.
- Comparing $f(n)$ with $n^a$ instead of $n^{\log_b a}$.
- Forgetting that the master theorem applies to $T(n/b)$, not to $T(n-1)$; subtraction recurrences need unrolling.

def T(n):

@practice code
prompt: For $T(n) = a\,T(n/b) + \Theta(n^d)$ with $a \ge 1$, $b > 1$ and $d \ge 0$, write `master_case(a, b, d)` that returns `"leaves"` if $d < \log_b a$, `"balanced"` if $d = \log_b a$, and `"root"` if $d > \log_b a$. Avoid floating-point logarithms: $d < \log_b a$ is the same as $b^d < a$.
starter:
```python
def master_case(a, b, d):
    pass
```
tests:
```python
assert master_case(8, 2, 2) == "leaves"
assert master_case(2, 2, 1) == "balanced"
assert master_case(1, 2, 1) == "root"
assert master_case(9, 3, 2) == "balanced"
assert master_case(3, 2, 1) == "leaves"
assert master_case(2, 4, 0.5) == "balanced"
assert master_case(1, 2, 0) == "balanced"
```
model:
```python
def master_case(a, b, d):
    growth = b ** d
    if growth < a:
        return "leaves"
    if growth == a:
        return "balanced"
    return "root"
```
hint: $d$ versus $\log_b a$ is the same comparison as $b^d$ versus $a$, because $b^x$ is increasing.
solution: Compute `b ** d` and compare it with `a`. If it is smaller, then $d < \log_b a$ and the leaves dominate; if equal, all levels cost the same; if larger, the root dominates. In the last test, `4 ** 0.5` is exactly `2.0`.

@practice self
prompt: Solve each of these six recurrences (all with $T(1) = 1$) and name the method you used: (a) $T(n) = 3T(n/2) + n$; (b) $T(n) = 2T(n/2) + n^2$; (c) $T(n) = T(n/2) + 1$; (d) $T(n) = 2T(n/2) + n\log n$; (e) $T(n) = T(n-1) + n$; (f) $T(n) = 2T(n-1) + 1$.
solution: (a) Master theorem, $p = \log_2 3 \approx 1.585 > 1$: leaves dominate, $\Theta(n^{\log_2 3})$. (b) Master theorem, $p = 1 < 2$ with regularity $2(n/2)^2 = n^2/2$: $\Theta(n^2)$. (c) Master theorem, $p = 0 = d$: $\Theta(\log n)$. (d) The master theorem does not apply (the gap between $n \log n$ and $n$ is not polynomial). A recursion tree has $\log n$ levels, and level $i$ costs $2^i \cdot (n/2^i)\log(n/2^i) = n(\log n - i)$; summing gives about $\frac12 n \log^2 n$, so $\Theta(n\log^2 n)$. (e) Unrolling: $n + (n-1) + \dots + 1 = n(n+1)/2$, so $\Theta(n^2)$. (f) Unrolling: $T(n) = 2T(n-1) + 1$ gives $T(n) = 2^n - 1$ (check: $T(1) = 1$ and $2(2^{n-1} - 1) + 1 = 2^n - 1$), so $\Theta(2^n)$.
hint: Compute $\log_b a$ for each master-theorem case first; (d), (e) and (f) need a tree or unrolling.
rubric: Gets the three master-theorem cases right: (a), (b) and (c).
rubric: Recognizes that (d) is not covered by the master theorem and obtains $\Theta(n \log^2 n)$ by a tree or substitution.
rubric: Solves (e) and (f) by unrolling and states the closed forms, $\Theta(n^2)$ and $\Theta(2^n)$.

@quiz num
prompt: Let $T(1) = 1$ and $T(n) = 3T(n/3) + n$ for $n$ a power of 3. What is the exact value of $T(729)$?
answer: 5103
check: int(run("def T(n):\n    return 1 if n == 1 else 3 * T(n // 3) + n\nprint(T(729))\n"))
hint: There are $\log_3 729 = 6$ levels above the leaves, and each costs $n$ in total.
solution: The six internal levels cost $729$ each, giving $4374$, and the $3^6 = 729$ leaves cost $1$ each, giving $729$. The total is $n\log_3 n + n = 4374 + 729 = 5103$.

@quiz mc
prompt: Which guess is the correct one to verify by substitution for $T(n) = 2T(n/2) + n$, and why?
choice: $T(n) \le c\,n$, because the work at the root is $n$
choice*: $T(n) \le c\,n\log_2 n$, because each of $\log_2 n$ levels costs $n$

choice: $T(n) \le c\log_2 n$, because the input halves each time

solution: The tree has about $\log_2 n$ levels and each level costs $n$ in total, so the right guess is $c\,n\log_2 n$. The guess $c\,n$ fails the inductive step: $2c(n/2) + n = (c+1)n > cn$. The other two guesses are valid upper bounds but not tight, or are simply too small.

@article
A **network** is a group of computers that can send data to each other, by cables or by radio (Wi-Fi). The **internet** is a **network of networks**: millions of home, school, company and phone networks joined together, using shared rules to cooperate.

### Packets

A big message, such as a photo, is not sent as one long stream. It is cut into small pieces called **packets**. Each packet carries

- a **header**: the sender's address, the destination address and a sequence number;
- a **payload**: one piece of the actual data.

Why packets? Many users can share the same cables, a lost piece can be sent again without resending everything, and different packets may take different routes if one path is busy or broken.

### IP addresses and routers

Every device on the internet has an **IP address**, a number that works like a postal address. An **IPv4** address is 32 bits, written as four numbers from 0 to 255 separated by dots, such as `192.168.1.20`; there are only about 4.3 billion of them, so the newer **IPv6** uses 128 bits, written in hexadecimal groups, to provide far more.

A **router** is a device with several connections. When a packet arrives, the router reads the destination in its header and forwards the packet towards it, one hop at a time, like a postal sorting centre. No single computer knows the whole route.

### Protocols

A **protocol** is an agreed set of rules for communication. **IP** (Internet Protocol) says how packets are addressed and forwarded. **TCP** (Transmission Control Protocol) runs on top of IP: it numbers the packets, makes the receiver confirm what arrived, resends lost packets and puts the pieces back into the right order. Because the packets can arrive in a different order, the sequence number is essential.

```python
def make_packets(message, size):
    packets = []
    for start in range(0, len(message), size):
        piece = message[start:start + size]
        packets.append((start // size, piece))
    return packets

packets = make_packets("HELLO WORLD", 4)
print(packets)   # [(0, 'HELL'), (1, 'O WO'), (2, 'RLD')]
print("".join(piece for number, piece in sorted(packets)))
```

The second print sorts the packets by number and joins the pieces, rebuilding `HELLO WORLD`.

@example
title: Cutting a message into packets
problem: A message of 1,000 bytes is sent in packets that each carry at most 400 bytes of payload. How many packets are needed and how big is the last one?
step: Two packets carry only 800 bytes, which is not enough.
step: Divide and round up: $1000 \div 400 = 2.5$, so 3 packets.
step: The first two carry 400 bytes each, leaving $1000 - 800 = 200$ bytes for the last.
answer: 3 packets, the last with 200 bytes

@example
title: Putting packets back in order
problem: Packets arrive in the order (2, "ld!"), (0, "hel"), (1, "lo wor"). What was the message?
step: Sort by sequence number: 0, 1, 2.
step: Join the payloads in that order: `hel`, `lo wor`, `ld!`.
step: The message is `hello world!`.
answer: `hello world!`

@mistakes
- Thinking one packet carries the whole message. Large data is split into many packets.
- Believing packets always arrive in order. Different routes mean different arrival times, so the sequence numbers matter.
- Writing an IPv4 address with a part above 255, such as `300.1.1.1`. Each part is one byte, so 0 to 255.
- Thinking a router knows the whole path. Each router only chooses the next hop.

def reassemble(packets):
    ordered = sorted(packets)
    message = ""
    for number, piece in ordered:
        message += piece
    return message

```python
def is_valid_ipv4(text):
    parts = text.split(".")
    if len(parts) != 4:
        return False
    for part in parts:
        if not part.isdigit() or int(part) > 255:
            return False
    return True
```

solution: `text.split(".")` gives the parts. Reject unless there are exactly four, and reject any part that is not all digits or is above 255. Only when every part passes do we return `True`.

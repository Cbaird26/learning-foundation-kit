@article
**Hardware** is the physical machine. **Software** is the instructions that tell it what to do. Software comes in two broad kinds: **application software** (a browser, a game, a photo editor) that does jobs for you, and **system software** that runs the computer itself. The most important system software is the **operating system** (OS), such as Windows, macOS, Linux, Android or iOS.

### What the operating system does

The OS sits between programs and hardware. Its main jobs are:

- **Running programs**: starting them, stopping them and sharing the processor between them.
- **Managing memory**: giving each running program its own part of RAM so that they do not overwrite each other.
- **Managing files**: keeping track of what is stored where on the drive.
- **Talking to devices**: keyboards, screens, printers and network cards, using small programs called **drivers**.
- **Providing the interface** you use, such as windows, icons and a mouse pointer, and keeping programs from interfering with one another.

### Programs and processes

A **program** is a set of instructions saved as a file on storage. A **process** is a program that is **running**: it has its own memory and its own progress through the instructions. Open two windows of the same browser and you have one program but two processes.

### Sharing the processor

A CPU core runs one instruction stream at a time, yet you can play music, browse and download together. The OS uses **scheduling**: it gives each process a very short turn on the CPU, then switches to the next. The switches are so fast that everything seems to run at once. A simple fair method is **round-robin**: each process in turn gets one turn, until it has no work left.

```python
jobs = {"music": 2, "browser": 1}     # turns each process still needs
turn = 0
while jobs:
    for name in list(jobs):
        turn += 1
        jobs[name] -= 1
        print(turn, name)
        if jobs[name] == 0:
            del jobs[name]
```

This prints `1 music`, `2 browser`, `3 music`: browser finishes after its single turn and music needs a second one.

### Compiled and interpreted

People write programs in a **programming language**. A **compiler** translates the whole program into machine code before it runs. An **interpreter** reads and runs it step by step. Python is usually run by an interpreter.

@example
title: Time sharing by hand
problem: Three processes A, B and C need 3, 1 and 2 turns. The scheduler gives one turn at a time in the order A, B, C and repeats, skipping finished processes. In what order do they finish?
step: Round 1: A has 2 left, B has 0 left (finished first), C has 1 left.
step: Round 2: A has 1 left, and C has 0 left (finished second). B is skipped.
step: Round 3: only A is left, and it has 0 left (finished third).
step: The finishing order is B, C, A.
answer: B, C, A

step: Each double-click starts a running copy with its own memory.

@mistakes
- Saying the program and the process are the same thing. A program is a file; a process is that program while it runs.
- Thinking a single-core computer really runs several programs at the same instant. It switches between them very quickly.
- Treating "the operating system" and "the user interface" as the same thing. The interface is only one of the OS's jobs.
- Confusing application software with system software: a browser is an application, a driver is system software.

tests:
```python
assert finish_order({"A": 3, "B": 1, "C": 2}) == ["B", "C", "A"]
assert finish_order({"A": 2, "B": 1, "C": 3}) == ["B", "A", "C"]
assert finish_order({"X": 1, "Y": 1}) == ["X", "Y"]
```

model:
```python
def finish_order(jobs):
    remaining = dict(jobs)
    done = []
    while remaining:
        for name in list(remaining):
            remaining[name] -= 1
            if remaining[name] == 0:
                del remaining[name]
                done.append(name)
    return done
```
hint: Copy the dictionary so that the caller's data is not changed, and keep looping while some process still has work.
hint: Inside the loop, give each process one turn by subtracting 1. When it reaches 0, remove it and add its name to the finished list. Loop over `list(remaining)` so deleting is safe.
solution: Keep a copy of the remaining turns. In each pass over the processes, subtract 1; a process that reaches 0 is removed and its name is appended to the result. Looping over `list(remaining)` makes a copy of the names, so deleting items during the loop does not break it.

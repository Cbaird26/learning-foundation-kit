@article
Inside a computer there are billions of tiny switches. Each switch is either **off** or **on**. We write off as `0` and on as `1`. One `0` or `1` is called a **bit** (short for *binary digit*). A single bit is not much, but a long row of bits can stand for a number, a letter, a colour or a sound.

### Place values

You already know decimal (base 10). In `347` the digits are worth 100s, 10s and 1s: $3\times100 + 4\times10 + 7\times1$. Each place is worth **10 times** the place to its right.

**Binary** (base 2) works the same way, but each place is worth **2 times** the place to its right: 1, 2, 4, 8, 16, 32, 64, 128, and so on. The only digits are `0` and `1`.

| place value | 8 | 4 | 2 | 1 |
|---|---|---|---|---|
| bits | 1 | 0 | 1 | 1 |

The binary number `1011` is $8 + 0 + 2 + 1 = 11$ in decimal. Add up the place values wherever there is a `1`.

### Decimal to binary

To go the other way, divide by 2 again and again, and write down each remainder. The remainders, read from the **last to the first**, are the bits. For 13: $13 \div 2 = 6$ remainder 1, $6 \div 2 = 3$ remainder 0, $3 \div 2 = 1$ remainder 1, $1 \div 2 = 0$ remainder 1. Reading upward gives `1101`.

### How many values?

With 1 bit you can make 2 values (0, 1). Each extra bit doubles the count, so $n$ bits give $2^n$ different patterns. 8 bits give $2^8 = 256$ patterns, which stand for the numbers 0 to 255. In general the largest number is $2^n - 1$.

### Checking with Python

```python
print(bin(13))           # 0b1101  (the 0b means "binary")
print(int("1101", 2))    # 13
print(2 ** 8)            # 256
```

`bin()` gives a string that starts with `0b`. `int(text, 2)` reads a string of bits as a binary number.

@example
title: Binary to decimal
problem: What is the binary number `101101` in decimal?
step: Write the place values under the bits, starting with 1 on the right: 32, 16, 8, 4, 2, 1.
step: The bits are `1 0 1 1 0 1`, so the places with a `1` are 32, 8, 4 and 1.
step: Add them: $32 + 8 + 4 + 1 = 45$.
step: Check with Python: `int("101101", 2)` is `45`.
answer: `45`

@example
title: Decimal to binary
problem: Write 37 in binary.
step: Divide by 2 and keep the remainders: 37 gives remainder 1 (quotient 18), 18 gives 0 (quotient 9), 9 gives 1 (quotient 4).
step: Keep going: 4 gives 0 (quotient 2), 2 gives 0 (quotient 1), 1 gives 1 (quotient 0).
step: The remainders in order were 1, 0, 1, 0, 0, 1. Read them from last to first: `100101`.
step: Check the place values: $32 + 4 + 1 = 37$. It works.
answer: `100101`

@mistakes
- Reading the remainders from first to last instead of last to first, which writes the number backwards.
- Giving the place values from the left as 1, 2, 4, 8. The 1 is always the **rightmost** place.
- Thinking 8 bits can hold 256 as the biggest number. There are 256 patterns, but they start at 0, so the biggest number is 255.
- Using digits other than 0 and 1 in a binary number.

model:
```python
def to_binary(n):
    if n == 0:
        return "0"
    bits = ""
    while n > 0:
        bits = str(n % 2) + bits
        n = n // 2
    return bits
```
hint: The remainder of `n % 2` is the next bit, starting with the rightmost one.
hint: Put each new bit on the **left** of the string you have so far, then replace `n` with `n // 2`. Handle `0` separately.
solution: Repeatedly take `n % 2` as the next bit and put it in front of the result, then halve `n` with `n // 2` until it reaches 0. Zero never enters the loop, so it needs its own case.

def from_binary(bits):

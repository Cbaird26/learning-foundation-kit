@article
Grown-up helper, please read this out loud.

Lists and loops are best friends. A loop can visit every item in a list, one at a time.

```python
food = ["milk", "eggs", "bread"]
for item in food:
    print(item)
```

This shows:

```text
milk
eggs
bread
```

### How it works

- `for item in food:` means, "For each thing in the list `food`, call it `item`."
- The first time, `item` is `milk`. Then it is `eggs`. Then it is `bread`.
- The indented line runs once for each item.

The name `item` is just a name we chose. You can pick another, like `thing` or `x`.

### Do more with each item

```python
for item in food:
    print("Buy", item)
```

This shows `Buy milk`, `Buy eggs` and `Buy bread`.

### Adding up

Keep a total in a variable. Start it at 0, and add each number.

```python
total = 0
for n in [2, 3, 4]:
    total = total + n
print(total)
```

The total goes 0, then 2, then 5, then 9. The last `print` is not indented, so it runs once. It shows `9`.

problem: What does this program show?

```python
total = 0
for n in [1, 5]:
    total = total + n
print(total)
```
step: The total starts at `0`.
step: First `n` is 1, so the total is `1`. Then `n` is 5, so the total is `6`.
step: The print runs once at the end and shows `6`.
answer: 6

@mistakes
- Forgetting the colon at the end of the `for` line, or forgetting to indent the line under it.
- Putting quote marks around the list name, so `"food"` is just a word.
- Printing the total inside the loop, so you see every step and not just the answer.

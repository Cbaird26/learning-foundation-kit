@project
title: Story machine
overview: Write a short Python program that tells a story. It uses variables for the characters, a loop for a part that repeats, and if and else for two different endings. Run it, fix any errors, and read the output aloud with your helper.
goal: Use variables to hold the names in your story.
goal: Use a for loop for a part of the story that repeats.
goal: Use if and else to choose between two endings.
step: Open Python on your computer with your grown-up helper.
step: Start with the variables. Write `hero = "Mia"` and `pet = "dog"`. Use your own names if you like.
step: Print the start of the story, joining in the variables. For example `print(hero, "had a", pet)`.
step: Add a loop for the part that repeats. For example, `for i in range(3):` and then an indented `print("They walked and walked")`.
step: Add a variable called `luck` that holds a number from 1 to 10.
step: Add if and else so there are two endings. If `luck` is 5 or more, print a happy ending. Otherwise, print a different ending.
step: Run the program. If Python shows an error, read the message with your helper, find the line, fix it and run again.
step: Change the value of `luck`, run again, and see the other ending. Then read the whole story aloud.
deliverable: A program file with the story machine.
deliverable: The output of your program for both endings, read aloud to your helper.
rubric: The program uses at least two variables for the characters.
rubric: The program has a for loop whose indented line repeats.
rubric: The program has if and else that give two different endings, and changing `luck` shows both.
rubric: The program runs without errors, and the helper has heard the story read aloud.
safety: Ask your helper before you start. Only type your own story, and do not put private things like your address in a program that you share.
tutor: Why does my loop print the line only once?
tutor: What does this error message mean, and which line should I look at?
tutor: How can I change my story so the ending depends on a number?
material: Here is a small story to get you started. Change the names, the words and the numbers to make it yours.

```python
hero = "Mia"
pet = "dog"
luck = 7
print(hero, "had a", pet)
for i in range(3):
    print("They walked and walked")
if luck >= 5:
    print("They found a treasure!")
else:
    print("They went home to rest.")
```

@review
## Review: key ideas

**Week 1 and 2.** `print("words")` shows words. No quote marks means Python works out a sum. The signs are `+`, `-` and `*`.

**Week 3 and 4.** A variable is a name for a value: `age = 7`. Words in quote marks are strings, and `+` or a comma can join them.

**Week 5 and 6.** `for i in range(3):` repeats the indented lines 3 times. `"*" * 4` makes a row of stars.

**Week 7 and 8.** `if` and `else` choose. Use `==` to ask "the same?", and `<`, `>`, `>=` and `!=` to compare.

**Week 9 and 10.** A list holds many items. Place numbers start at 0. `len` counts and `append` adds. `for item in list:` visits every item.

**Week 11 and 12.** `def` makes a function, and calling it runs it. `return` hands back an answer.

### Self-check

- I can print words and the answer to a sum.
- I can tell `=` from `==`.
- I can say what `range(3)` counts.
- I can pick the first item out of a list.
- I can write and call a small function.

### Common errors

- A missing quote mark or bracket.
- A missing colon or indent after `for`, `if`, `else` and `def`.
- Using `=` when you mean `==`.
- Counting list places from 1 and not 0.

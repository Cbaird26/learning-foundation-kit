@lesson
title: Choices with if and else
summary: Make a program choose between two things with if and else.
objective: Write an if line with a colon and an indented line.
objective: Add an else for when the answer is no.
objective: Use == to check if two things are the same.
reading: Raspberry Pi Foundation free coding projects for young learners: look for a beginner Python project that makes a choice.

@article
Grown-up helper, please read this out loud.

We make choices all day. *If it is raining, take an umbrella. Else, wear sunglasses.* A program can choose too.

```python
weather = "rain"
if weather == "rain":
    print("Take an umbrella")
else:
    print("Wear sunglasses")
```

This shows `Take an umbrella`.

### The parts

- `if` asks a yes or no question.
- `==` (two equal signs) asks, "Are these the same?"
- The colon `:` ends the `if` line.
- The line to run when the answer is yes is indented by 4 spaces.
- `else:` says what to do when the answer is no. It has its own colon, and its line is indented too.

Only one of the two choices runs, never both.

### One equal sign or two

- `=` puts a value in a box: `weather = "rain"`.
- `==` asks a question: `weather == "rain"`.

### Try the other way

Change the first line to `weather = "sun"`. Now the question `"sun" == "rain"` is no, so the `else` runs. It shows `Wear sunglasses`.

You can also use `if` without `else`. Then nothing happens when the answer is no.

@example
title: Which line runs?
problem: What does this program show?

```python
color = "red"
if color == "blue":
    print("Sky")
else:
    print("Apple")
```
step: `color` holds `red`.
step: Is `"red" == "blue"`? No.
step: So the `else` runs, and the screen shows `Apple`.
answer: Apple

@example
title: Write your own choice
problem: If `pet` is `"dog"`, print `Woof`. Otherwise print `Meow`.
step: Start with `if pet == "dog":` and the colon.
step: Indent and print `Woof`.
step: Add `else:` and, indented under it, `print("Meow")`.

@mistakes
- Using one equal sign `=` in the question. Use two: `==`.
- Forgetting the colon at the end of the `if` or the `else` line.
- Forgetting to indent the lines under `if` and `else`.
- Forgetting that `"Dog"` and `"dog"` are not the same, because of the big D.

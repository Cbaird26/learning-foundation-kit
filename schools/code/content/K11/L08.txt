@article
Grown-up helper, please read this out loud.

Is 5 bigger than 3? Yes! Python can answer questions like this.

```python
print(5 > 3)
```

This shows `True`. When the answer is no, Python shows `False`.

### The comparing signs

| Sign | Question | Example | Answer |
|---|---|---|---|
| `>` | bigger than? | `5 > 3` | True |
| `<` | smaller than? | `5 < 3` | False |
| `==` | the same? | `4 == 4` | True |
| `!=` | not the same? | `4 != 4` | False |
| `>=` | bigger or the same? | `4 >= 4` | True |
| `<=` | smaller or the same? | `5 <= 4` | False |

`True` and `False` start with a big letter.

### Use it with if

```python
age = 9
if age >= 8:
    print("Yes")
else:
    print("No")
```

`age` is 9 and 9 is bigger than or the same as 8, so this shows `Yes`.

### Yes or no program

Put the number in a variable, compare it, and print `Yes` or `No`. Change the number and run it again to see the answer change.

Careful: `==` is a question and `=` puts a value in a box. Do not mix them up.

@example
title: True or False
problem: What do these lines show?

```python
print(2 < 7)
print(6 == 5)
```
step: Is 2 smaller than 7? Yes, so the first line shows `True`.
step: Is 6 the same as 5? No, so the second line shows `False`.

@example
title: A yes or no program
problem: Print `Yes` if `n` is more than 10, and `No` if not. Here `n = 12`.
step: Write `if n > 10:` and print `Yes` under it, indented.
step: Add `else:` and print `No` under it, indented.
step: `12 > 10` is true, so the screen shows `Yes`.
answer: Yes

@mistakes
- Using `=` instead of `==` in an `if` line. Python says `SyntaxError`.
- Writing `True` with a small t, like `true`. Python does not know that word.
- Mixing up `>` (bigger) and `<` (smaller). The open end of the sign faces the bigger number.
- Forgetting that `>` does not count equal numbers, but `>=` does.

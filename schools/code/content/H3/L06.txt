@article
An identity is true for every angle. An **equation** such as $2\sin x = 1$ is true only for some angles, and **solving** it means finding all of them. The inverse functions hand you one solution; the symmetry of the unit circle supplies the rest.

### The basic equations

Fix a number $c$ with $|c| < 1$. On the unit circle, the height $\sin\theta = c$ is a horizontal line, which cuts the circle in two points. The same is true of the vertical line $\cos\theta = c$. So there are two solutions per turn:

- $\sin\theta = c$: $\theta = \arcsin c$ or $\theta = \pi - \arcsin c$, plus any multiple of $2\pi$.
- $\cos\theta = c$: $\theta = \pm\arccos c$, plus any multiple of $2\pi$.
- $\tan\theta = c$: $\theta = \arctan c$, plus any multiple of $\pi$, because a line through the origin meets the circle at two opposite points.

For example, $\sin\theta = \frac{1}{2}$ has the **general solution** $\theta = \frac{\pi}{6} + 2\pi k$ or $\theta = \frac{5\pi}{6} + 2\pi k$ for every integer $k$. If an interval is stated, such as $[0, 2\pi)$, keep only the values of $k$ that land inside it.

### A four-step routine

1. **Reduce** to one trigonometric function, using identities if needed.
2. **Isolate** it. A quadratic in $\sin x$ or $\cos x$ is solved by factoring or by the quadratic formula.
3. **Solve** each basic equation using inverse functions and symmetry.
4. **Filter** the solutions to the stated interval, and discard values where the original equation is undefined.

### Multiple angles

For $\sin 2x = c$ on $[0, 2\pi)$, let $u = 2x$. Then $x \in [0, 2\pi)$ means $u \in [0, 4\pi)$, which is **two turns**. Find all solutions $u$ in the doubled interval first, then divide by $2$. Forgetting to double the interval loses half the solutions.

### Two traps

**Never divide by a trigonometric expression that might be zero.** From $\sin x\cos x = \sin x$, do not divide by $\sin x$: that throws away every solution with $\sin x = 0$. Move everything to one side and factor instead: $\sin x(\cos x - 1) = 0$.

**Squaring can create false solutions.** If you square both sides, substitute each candidate back into the original equation.

A quick numerical check of a claimed solution list never hurts:

```python
import numpy as np
x = np.array([np.pi/2, 7*np.pi/6, 11*np.pi/6])
print(np.allclose(2*np.cos(x)**2 + np.sin(x) - 1, 0))   # True
```

@example
title: A quadratic in sine, using an identity first
problem: Solve $2\cos^2 x + \sin x - 1 = 0$ for $x$ in $[0, 2\pi)$.
step: Reduce to one function with $\cos^2 x = 1 - \sin^2 x$: $2 - 2\sin^2 x + \sin x - 1 = 0$, which simplifies to $2\sin^2 x - \sin x - 1 = 0$.
step: Factor: $(2\sin x + 1)(\sin x - 1) = 0$. So $\sin x = -\frac{1}{2}$ or $\sin x = 1$.
step: From $\sin x = 1$ we get $x = \frac{\pi}{2}$. From $\sin x = -\frac{1}{2}$, the reference angle is $\frac{\pi}{6}$ and sine is negative in Quadrants III and IV, so $x = \frac{7\pi}{6}$ and $x = \frac{11\pi}{6}$.
step: All three lie in $[0, 2\pi)$. Check $x = \frac{7\pi}{6}$: $2\cdot\frac{3}{4} - \frac{1}{2} - 1 = 0$. The solutions are $\frac{\pi}{2}, \frac{7\pi}{6}, \frac{11\pi}{6}$.

@example
title: A multiple-angle equation
problem: Solve $\sin 2x = \frac{\sqrt{3}}{2}$ for $x$ in $[0, 2\pi)$.
step: Let $u = 2x$. Since $0 \le x < 2\pi$, we need $u$ in $[0, 4\pi)$, two full turns.
step: In the first turn, $\sin u = \frac{\sqrt{3}}{2}$ gives $u = \frac{\pi}{3}$ and $u = \frac{2\pi}{3}$. Adding $2\pi$ for the second turn gives $u = \frac{7\pi}{3}$ and $u = \frac{8\pi}{3}$.
step: Divide by $2$: $x = \frac{\pi}{6}, \frac{\pi}{3}, \frac{7\pi}{6}, \frac{4\pi}{3}$.
step: Check $x = \frac{7\pi}{6}$: $\sin\frac{7\pi}{3} = \sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}$. There are four solutions, twice the number for $\sin u = c$ in a single turn.

@mistakes
- Reporting only the calculator's principal value and missing the second solution in each period.
- For $\sin 2x = c$ on $[0, 2\pi)$, solving for $2x$ only in $[0, 2\pi)$ and so missing half of the solutions.
- Dividing both sides by a trigonometric factor and losing the solutions where that factor is zero. Factor instead.
- Keeping values outside the stated interval, or values where the original equation is undefined, such as $\tan x$ at $\frac{\pi}{2}$.

@practice self
prompt: (a) Prove the identity $\dfrac{\sin 2x}{1 - \cos 2x} = \cot x$ by working on the left side only. (b) Use it to solve $\dfrac{\sin 2x}{1 - \cos 2x} = \sqrt{3}$ for $x$ in $(0, \pi)$, and explain why the interval is open at both ends.
hint: Rewrite the numerator with a double-angle formula and the denominator with $\cos 2x = 1 - 2\sin^2 x$.
hint: After simplifying you get a cotangent. For part (b), rewrite $\cot x = \sqrt{3}$ as a tangent equation.
solution: (a) $\sin 2x = 2\sin x\cos x$ and $1 - \cos 2x = 1 - (1 - 2\sin^2 x) = 2\sin^2 x$. So $\dfrac{\sin 2x}{1 - \cos 2x} = \dfrac{2\sin x\cos x}{2\sin^2 x} = \dfrac{\cos x}{\sin x} = \cot x$, valid when $\sin x \ne 0$. (b) The equation becomes $\cot x = \sqrt{3}$, so $\tan x = \frac{1}{\sqrt{3}}$ and $x = \frac{\pi}{6} + k\pi$. Only $x = \frac{\pi}{6}$ lies in $(0, \pi)$. The endpoints $0$ and $\pi$ are excluded because there $\sin x = 0$, so $1 - \cos 2x = 0$ and the original fraction is undefined.
rubric: Part (a) starts from the left side only and never operates on both sides.
rubric: Uses $\sin 2x = 2\sin x\cos x$ and $1 - \cos 2x = 2\sin^2 x$ correctly, and cancels the common factor $2\sin x$.
rubric: Part (b) reduces to $\tan x = \frac{1}{\sqrt{3}}$ and finds only $x = \frac{\pi}{6}$ in $(0, \pi)$.
rubric: Explains that the endpoints are excluded because the original denominator is zero there.

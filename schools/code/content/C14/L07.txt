@article
An **infinite series** $\sum_{n=1}^\infty a_n$ is defined through its **partial sums** $S_N=a_1+a_2+\dots+a_N$. The series **converges** to $S$ if the sequence $\{S_N\}$ converges to $S$; otherwise it **diverges**. Every convergence question about a series is a question about the sequence $\{S_N\}$, which is why Week 6 came first.

### Two series you can sum exactly

A **geometric series** $\sum_{n=0}^\infty ar^n$ has $S_N=a\frac{1-r^{N+1}}{1-r}$, so it converges, to $\frac{a}{1-r}$, exactly when $|r|<1$, and diverges when $|r|\ge1$ (for $a\ne0$).

A **telescoping series** has partial fractions that cancel in pairs. Since $\frac1{n(n+1)}=\frac1n-\frac1{n+1}$, we get $S_N=1-\frac1{N+1}\to1$.

### The divergence test

If $\sum a_n$ converges then $a_n\to0$. So if $a_n\not\to0$ the series **diverges**. The converse is false and is the most common error: $\sum\frac1n$, the **harmonic series**, has $a_n\to0$ yet diverges.

### Tests for positive terms

- **Integral test.** If $f$ is positive, continuous and decreasing on $[1,\infty)$ with $f(n)=a_n$, then $\sum a_n$ and $\int_1^\infty f$ converge or diverge together. This gives the **$p$-series**: $\sum\frac1{n^p}$ converges iff $p>1$.
- **Comparison test.** If $0\le a_n\le b_n$: $\sum b_n$ converges implies $\sum a_n$ converges; $\sum a_n$ diverges implies $\sum b_n$ diverges.
- **Limit comparison test.** If $a_n,b_n>0$ and $\lim\frac{a_n}{b_n}=c$ with $0<c<\infty$, then the two series behave alike. Use it with $b_n$ the dominant term, for instance $\frac{n+1}{n^3+2}$ versus $\frac1{n^2}$.
- **Ratio test.** Let $L=\lim\left|\frac{a_{n+1}}{a_n}\right|$. If $L<1$ the series converges absolutely; if $L>1$ (or $L=\infty$) it diverges; if $L=1$ the test says **nothing**. It is the right tool when terms contain factorials or exponentials.

### Alternating series

The **alternating series test**: if $b_n>0$, $b_n$ is decreasing, and $b_n\to0$, then $\sum(-1)^nb_n$ converges. Moreover the error in stopping after $N$ terms is at most the first omitted term: $|S-S_N|\le b_{N+1}$.

### Absolute and conditional convergence

$\sum a_n$ **converges absolutely** if $\sum|a_n|$ converges; this implies that $\sum a_n$ converges. A series that converges but not absolutely converges **conditionally**. For example $\sum\frac{(-1)^{n+1}}{n}$ converges (alternating series test) but $\sum\frac1n$ diverges, so the convergence is conditional. Rearranging the terms of a conditionally convergent series can change its sum, so only absolute convergence permits reordering.

### A strategy

Look at $a_n\to0$ first. Then match the form: geometric or $p$-series, factorial or exponential (ratio test), a rational or algebraic expression (comparison or limit comparison), a decreasing function with an easy integral (integral test), alternating signs (alternating series test).

@example
title: Telescoping series
problem: Find $\displaystyle\sum_{n=1}^\infty\frac{1}{n(n+1)}$.
step: Decompose: $\frac1{n(n+1)}=\frac1n-\frac1{n+1}$.
step: The partial sum is $S_N=\left(1-\frac12\right)+\left(\frac12-\frac13\right)+\dots+\left(\frac1N-\frac1{N+1}\right)$.
step: All middle terms cancel, leaving $S_N=1-\frac1{N+1}$.
step: As $N\to\infty$, $S_N\to1$.
answer: $1$

@example
title: The ratio test
problem: Does $\displaystyle\sum_{n=1}^\infty\frac{n^2}{3^n}$ converge?
step: Let $a_n=\frac{n^2}{3^n}$. Then $\frac{a_{n+1}}{a_n}=\frac{(n+1)^2}{3^{n+1}}\cdot\frac{3^n}{n^2}=\frac13\left(\frac{n+1}{n}\right)^2$.
step: As $n\to\infty$, $\left(\frac{n+1}n\right)^2\to1$, so $L=\frac13$.
step: $L<1$, so the series converges absolutely (and therefore converges).
answer: It converges.

@mistakes
- Concluding that a series converges because $a_n\to0$. The harmonic series is the standard counterexample.
- Concluding anything from the ratio test when $L=1$; the series $\sum\frac1n$ and $\sum\frac1{n^2}$ both have $L=1$.
- Applying the integral or alternating series tests without checking the hypotheses (positive and decreasing).
- Using the geometric sum formula $\frac{a}{1-r}$ when $|r|\ge1$, or from the wrong starting index.

@practice num
prompt: Find the sum $\displaystyle\sum_{n=1}^\infty\frac{1}{n(n+2)}$. Give an exact value.
answer: 3/4
tol: 1e-4
check: sum(1 / (n * (n + 2)) for n in range(1, 10**5))
hint: Use partial fractions: $\frac1{n(n+2)}=\frac12\left(\frac1n-\frac1{n+2}\right)$.
hint: In the telescoping sum, only the first two terms $1$ and $\frac12$ of the positive part survive.
solution: $S_N=\frac12\left(1+\frac12-\frac1{N+1}-\frac1{N+2}\right)\to\frac12\cdot\frac32=\frac34$.

@practice mc
prompt: The terms of the harmonic series $\sum_{n=1}^\infty\frac1n$ tend to $0$. Which statement is correct?
choice: The series converges, because its terms tend to $0$.
choice*: The series diverges; terms tending to $0$ is necessary for convergence but not sufficient.
choice: The series converges, because its terms are decreasing.
choice: The series diverges, because its terms are positive.
hint: Compare $\sum\frac1n$ with the integral $\int_1^\infty\frac{dx}x$.
solution: The integral $\int_1^\infty\frac{dx}{x}=\lim\ln t$ diverges, so by the integral test the harmonic series diverges. Terms tending to $0$ only rules out divergence by the divergence test; it never proves convergence.

model:
```python
def harmonic_exceeds(target):
    n = 1
    total = 1.0
    while total <= target:
        n += 1
        total += 1 / n
    return n
```
hint: Keep a running total and a counter, and stop as soon as the total is greater than `target`.
hint: The first partial sum is $H_1=1$; start the loop from there, using `<=` in the loop condition.
solution: Start with `n = 1` and `total = 1.0` and keep adding `1 / n` while `total <= target`. For `target = 1`, $H_1=1$ is not strictly greater, but $H_2=1.5$ is, so the answer is $2$. The harmonic series diverges, so the loop always ends, though slowly: $H_N$ grows like $\ln N$.

@quiz num
prompt: Find the sum $\displaystyle\sum_{n=1}^\infty\frac1{4n^2-1}$. Give an exact value.
answer: 1/2
tol: 1e-4
check: sum(1 / (4 * n * n - 1) for n in range(1, 10**5))
hint: Factor $4n^2-1=(2n-1)(2n+1)$ and use partial fractions.
hint: $\frac1{4n^2-1}=\frac12\left(\frac1{2n-1}-\frac1{2n+1}\right)$.
solution: The sum telescopes: $S_N=\frac12\left(1-\frac1{2N+1}\right)\to\frac12$.

@quiz num
prompt: For $a_n=\dfrac{n!}{n^n}$, find $\displaystyle\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|$, the quantity used in the ratio test. Give an exact value.
answer: e^(-1)
tol: 1e-5
check: (1 + 1 / 10**6) ** (-(10**6))
hint: Simplify $\frac{(n+1)!}{(n+1)^{n+1}}\cdot\frac{n^n}{n!}$, cancelling $(n+1)$ and $n!$.
hint: You should get $\left(\frac{n}{n+1}\right)^n=\left(1+\frac1n\right)^{-n}$.
solution: The ratio equals $\left(1+\frac1n\right)^{-n}\to e^{-1}$. Since $\frac1e<1$, the ratio test shows that $\sum\frac{n!}{n^n}$ converges.

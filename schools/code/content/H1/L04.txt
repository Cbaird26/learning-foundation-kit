@article
An **inequality** compares two quantities with $<$, $\le$, $>$ or $\ge$. An equation usually has one solution; an inequality usually has a whole **solution set** containing infinitely many numbers.

### Start with a story

You have 50 dollars for a pizza night. Each pizza costs 8 dollars and delivery is a flat 6 dollars. With $n$ pizzas the cost in dollars is $8n + 6$, and it must be **at most** 50:

$$8n + 6 \le 50.$$

Subtract $6$: $8n \le 44$. Divide by $8$: $n \le 5.5$. Every number up to $5.5$ works as a number, but you cannot buy half a pizza, so the context says: at most $5$ pizzas.

### Solve it like an equation, with one twist

Add or subtract the same number on both sides, and multiply or divide both sides by the same **positive** number, exactly as you do for equations. The twist:

**If you multiply or divide both sides by a negative number, reverse the inequality symbol.**

Why? We know $2 < 5$. Multiply both sides by $-1$ and you get $-2$ and $-5$. On the number line $-5$ lies to the left of $-2$, so now $-2 > -5$. Multiplying by a negative mirrors the number line, which swaps the order.

$$-3x > 12 \;\Longrightarrow\; x < -4.$$

### Writing solution sets

On a number line, use an open circle when the endpoint is excluded ($<$, $>$) and a filled circle when it is included ($\le$, $\ge$). **Interval notation** writes the same thing in brackets: a round bracket excludes the endpoint, a square bracket includes it, and $\infty$ always gets a round bracket.

| Inequality | Interval notation |
|---|---|
| $x > 3$ | $(3, \infty)$ |
| $x \le -1$ | $(-\infty, -1]$ |
| $-2 \le x < 5$ | $[-2, 5)$ |

### Compound inequalities

$-3 < 2x + 1 \le 9$ packs two conditions into one. Do the same step to **all three parts**: subtract $1$ to get $-4 < 2x \le 8$, then divide by $2$ to get $-2 < x \le 4$, which is $(-2, 4]$.

### Distance and absolute value

$|x - 3|$ is the distance from $x$ to $3$ on the number line. So $|x - 3| < 4$ means "within $4$ of $3$", which is $-1 < x < 7$. And $|x - 3| > 4$ means "more than $4$ away from $3$", which is $x < -1$ **or** $x > 7$: two separate pieces.

### Check

Substitute one value from inside your solution set (it should make the original statement true) and one from outside (it should make it false). Also test the endpoint itself.

@example
title: A negative coefficient flips the symbol
problem: Solve $5 - 3x \ge 20$ and write the answer in interval notation.
step: Subtract $5$ from both sides: $-3x \ge 15$.
step: Divide both sides by $-3$. Dividing by a negative reverses the symbol: $x \le -5$.
step: Because the symbol is $\le$, the endpoint $-5$ is included, so the interval is $(-\infty, -5]$.
step: Check the endpoint: $5 - 3(-5) = 20 \ge 20$ is true. Check a value inside, $x = -6$: $5 + 18 = 23 \ge 20$ is true. Check a value outside, $x = 0$: $5 \ge 20$ is false, as it should be.

@example
title: A compound inequality with a fraction
problem: Solve $-1 \le \frac{2x - 1}{3} < 3$.
step: There are three parts, so every move is applied to all three. Multiply each part by $3$ (positive, so no reversing): $-3 \le 2x - 1 < 9$.
step: Add $1$ to each part: $-2 \le 2x < 10$.
step: Divide each part by $2$: $-1 \le x < 5$.
step: In interval notation this is $[-1, 5)$: square bracket at $-1$ (included), round bracket at $5$ (excluded).
step: Check the ends: at $x = -1$ the middle part is $\frac{-3}{3} = -1$, allowed. At $x = 5$ it is $\frac{9}{3} = 3$, which is not less than $3$, so $5$ is rightly excluded.

@mistakes
- Forgetting to reverse the symbol after dividing or multiplying by a negative number.
- Reversing the symbol when merely adding or subtracting a negative number. Only multiplication and division flip it.
- Using a square bracket next to $\infty$, or a round bracket at an included endpoint.
- Writing $|x - 3| > 4$ as one interval. It is two pieces joined by "or".

answer: 5
check: max(n for n in range(-200, 201) if 3*n - 7 < 11)
hint: Solve it as you would an equation: add $7$ to both sides, then divide by $3$.
hint: You get $x < 6$. Is $6$ itself allowed when the symbol is strict?
solution: $3x < 18$, so $x < 6$. Since $6$ is not allowed, the largest whole number is $5$. Check: $3(5) - 7 = 8 < 11$, but $3(6) - 7 = 11$ is not less than $11$.

@practice num
prompt: Solve the equation $\frac{x}{2} - \frac{1}{3} = \frac{x}{6} + 1$. Then substitute your solution into the left-hand side of the original equation. What common value do both sides take? Give an exact fraction.
answer: 5/3
check: (lambda x: x/2 - 1/3)(root(lambda x: x/2 - 1/3 - (x/6 + 1), -100, 100))
hint: Multiply every term by the LCD, $6$, to clear the fractions.
hint: You should get $3x - 2 = x + 6$. Solve for $x$, then substitute that value back into $\frac{x}{2} - \frac{1}{3}$.
solution: $3x - 2 = x + 6$ gives $2x = 8$, so $x = 4$. Check: the left side is $\frac{4}{2} - \frac{1}{3} = \frac{5}{3}$ and the right side is $\frac{4}{6} + 1 = \frac{2}{3} + 1 = \frac{5}{3}$. Both sides equal $\frac{5}{3}$.

@practice list
prompt: Find the two endpoints of the solution set of $|2x - 1| \le 5$. Enter them separated by a comma.
answer: -2, 3
check: allroots(lambda x: abs(2*x - 1) - 5, -100, 100)
hint: $|A| \le 5$ means $-5 \le A \le 5$. Here $A = 2x - 1$.
hint: Solve $-5 \le 2x - 1 \le 5$ by working on all three parts at once: add $1$, then divide by $2$.
solution: $-5 \le 2x - 1 \le 5$ gives $-4 \le 2x \le 6$, so $-2 \le x \le 3$. The endpoints are $-2$ and $3$, and the solution set is $[-2, 3]$. Check: $|2(-2) - 1| = 5$ and $|2(3) - 1| = 5$.

@quiz num

answer: 5
check: min(n for n in range(-300, 301) if (5 - 2*n)/3 < -1)
hint: Multiply both sides by $3$. This is positive, so the symbol stays.
hint: You get $5 - 2x < -3$. Subtract $5$, then divide by $-2$ and remember what that does to the symbol.
solution: $5 - 2x < -3$, so $-2x < -8$. Dividing by $-2$ reverses the symbol: $x > 4$. The smallest whole number greater than $4$ is $5$. Check $x = 4$: $\frac{-3}{3} = -1$, which is not less than $-1$.

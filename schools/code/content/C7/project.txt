```text
LOAD path        replace the table with the   reply: OK, or ERR cannot read

```

material: **Hash function.** Use djb2 on the bytes of the key, with an unsigned 32-bit accumulator:

```c
#include <stdint.h>

static uint32_t hash_key(const char *s) {
    uint32_t h = 5381;
    while (*s != '\0') {
        h = h * 33 + (unsigned char)*s;
        s++;
    }
    return h;
}
```

The bucket index is `hash_key(key) % nbuckets`. Start with 16 buckets; resizing is optional.

### Week by week

- **Week 1, basics.** Integer division truncates toward zero; `%` takes the sign of the dividend; unsigned types wrap modulo $2^N$ but signed overflow is undefined; `=` is not `==`; a `switch` falls through without `break`.
- **Week 2, build.** Declaration versus definition; pass by value; headers hold declarations and use include guards; the four stages are preprocess, compile, assemble and link; `make` rebuilds a target when a dependency is newer.
- **Week 3, pointers.** `&` takes an address and `*` follows one; pass an address to modify the caller's variable; never use a dangling, null or uninitialized pointer; draw boxes and arrows.
- **Week 4, arrays.** `a[i]` is `*(a + i)`; pointer arithmetic is scaled by the element size; arrays decay to pointers, so pass a length; row-major layout for multidimensional arrays.
- **Week 5, strings.** NUL-terminated `char` arrays; capacity must include the terminator; `strncpy` does not always terminate; use `snprintf` and check lengths; never `gets`.
- **Week 6, structs.** `.` and `->`; struct copies are shallow; padding and alignment determine `sizeof`; unions and enums.
- **Week 7, heap.** `malloc` must be checked and paired with exactly one `free`; `calloc` zeroes; `realloc` uses a temporary pointer; doubling gives amortized $O(1)$ appends.
- **Week 8, tools.** Compile with `-g`; Valgrind reports the kind of error, the faulting line and the block's allocation site; sanitizers and gdb (`bt`, `print`, `next`, `watch`) find the rest; fix the first error first.
- **Week 9, linked lists.** Save `next` before freeing; `node **` removes the head special case; reversal is $O(n)$ time and $O(1)$ space; appending without a tail pointer is $O(n)$.
- **Week 10, files.** Check `fopen`; loop on the return value of the read, not on `feof`; `sscanf` returns the number of conversions; `fread` returns complete items.
- **Week 11, processes.** `fork` returns twice; `exec` replaces the program; `waitpid` collects the status; shells implement redirection with `dup2` and pipes with `pipe`; `cd` is a built-in.
- **Week 12, undefined behavior.** UB means no requirements; compilers exploit it; check overflow before it happens; bound every copy; never pass untrusted text as a format.

### Common errors

Off-by-one in buffer sizes (forgetting the terminator), using memory after `free` or after `realloc` moved it, `sizeof` on an array parameter, comparing strings with `==`, forgetting `break` or a `NULL` check, and testing for overflow after it has happened. Fix each by writing down an invariant, and use the tools to confirm it.

@exam code
prompt: A chained hash table is a list of buckets, each bucket a list of `[key, value]` pairs. Write three functions. `djb2(s)` returns the djb2 hash of the string `s` (all characters have codes below 128): start with `h = 5381`, and for each character with code `c` set `h = (h * 33 + c) % 2**32`. `put(buckets, key, value)` finds the bucket at index `djb2(key) % len(buckets)`; if `key` is already present it replaces the value in place and returns `False`; otherwise it inserts `[key, value]` at the **front** of the bucket and returns `True`. `get(buckets, key)` returns the value for `key`, or `None` if it is absent.

tests:
```python

assert djb2("a") == 177670
assert djb2("ab") == 5863208
assert djb2("hello") == 261238937
one = [[]]
assert put(one, "a", 1) is True
assert put(one, "b", 2) is True
assert one[0] == [["b", 2], ["a", 1]]
assert put(one, "a", 9) is False

assert get(one, "zzz") is None
four = [[], [], [], []]

```
model:
```python
def djb2(s):
    h = 5381
    for ch in s:
        h = (h * 33 + ord(ch)) % 2 ** 32
    return h


def put(buckets, key, value):
    bucket = buckets[djb2(key) % len(buckets)]
    for pair in bucket:
        if pair[0] == key:
            pair[1] = value
            return False
    bucket.insert(0, [key, value])
    return True


def get(buckets, key):
    for k, v in buckets[djb2(key) % len(buckets)]:
        if k == key:
            return v
    return None
```
hint: Compute the hash with a loop, reducing modulo `2**32` after each step, as an unsigned 32-bit variable would wrap.
hint: Both `put` and `get` start by selecting the bucket with `djb2(key) % len(buckets)` and scanning its pairs for the key.
solution: The hash is the same loop as the C function with `uint32_t` arithmetic. A lookup scans one bucket, so the expected time is $O(1 + n/m)$ for $n$ keys in $m$ buckets with a good hash. Inserting at the front of the chain mirrors `push_front` on a linked list.

@exam text
prompt: What does this program print? Type the output exactly (one line).

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char *name;
    int score;
} entry;

static char *dupstr(const char *s) {
    size_t n = strlen(s) + 1;
    char *p = malloc(n);
    if (p == NULL) {
        exit(1);
    }
    memcpy(p, s, n);
    return p;
}

int main(void) {
    entry *es = calloc(2, sizeof *es);
    if (es == NULL) {
        return 1;
    }
    es[0].name = dupstr("ann");
    es[1].name = dupstr("bob");
    es[1].score = 3;
    entry *p = es;
    p->score += 4;
    p++;
    p->score *= 2;
    p->name[0] = 'B';
    for (int i = 0; i < 2; i++) {
        printf("%s:%d ", es[i].name, es[i].score);
    }
    printf("\n");
    for (int i = 0; i < 2; i++) {
        free(es[i].name);
    }
    free(es);
    return 0;
}
```
answer: ann:4 Bob:6
check: run_c('#include <stdio.h>\n#include <stdlib.h>\n#include <string.h>\n\ntypedef struct {\n    char *name;\n    int score;\n} entry;\n\nstatic char *dupstr(const char *s) {\n    size_t n = strlen(s) + 1;\n    char *p = malloc(n);\n    if (p == NULL) {\n        exit(1);\n    }\n    memcpy(p, s, n);\n    return p;\n}\n\nint main(void) {\n    entry *es = calloc(2, sizeof *es);\n    if (es == NULL) {\n        return 1;\n    }\n    es[0].name = dupstr("ann");\n    es[1].name = dupstr("bob");\n    es[1].score = 3;\n    entry *p = es;\n    p->score += 4;\n    p++;\n    p->score *= 2;\n    p->name[0] = \'B\';\n    for (int i = 0; i < 2; i++) {\n        printf("%s:%d ", es[i].name, es[i].score);\n    }\n    printf("\\n");\n    for (int i = 0; i < 2; i++) {\n        free(es[i].name);\n    }\n    free(es);\n    return 0;\n}\n')

```python
def parse_kv_command(line):
    line = line.rstrip("\n")
    parts = line.split(" ", 2)
    cmd = parts[0]
    if cmd == "SET" and len(parts) == 3 and parts[1] and parts[2]:
        return ("SET", parts[1], parts[2])
    if cmd in ("GET", "DEL") and len(parts) == 2 and parts[1]:
        return (cmd, parts[1])
    if cmd == "COUNT" and len(parts) == 1:
        return ("COUNT",)
    return None
```
hint: Split at most twice on a single space with `line.split(" ", 2)`, so that a value with spaces stays in one piece.
hint: Check the command word and the number of parts for each form, and require the key (and for `SET`, the value) to be non-empty.
solution: `split(" ", 2)` yields the command, the key and the rest of the line. `SET` needs three non-empty-key-and-value parts, `GET` and `DEL` exactly two (a key containing a space would produce a third part), and `COUNT` exactly one. The C version would use `strchr` to find the spaces and copy each field with a length check.

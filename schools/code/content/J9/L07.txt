@article
Computers are good at repeating things. A **loop** repeats a block of instructions. The `while` loop keeps repeating **as long as** its condition is true:

```python
n = 3
while n > 0:
    print(n)
    n = n - 1
print("Liftoff!")
```

This prints `3`, `2`, `1` and `Liftoff!`. Each time around, called an **iteration**, Python checks the condition first. If it is true, the indented block runs and Python checks again. When the condition becomes false, Python skips to the first line after the loop.

### Three parts of a good loop

1. **Set up** a variable before the loop (`n = 3`).
2. **Test** it in the condition (`n > 0`).
3. **Change** it inside the loop (`n = n - 1`).

If you forget the third part, the condition never becomes false and the loop never ends. This is an **infinite loop**. For example, `while n > 0:` with no `n = n - 1` prints `3` forever. If a program seems frozen, a loop that cannot end is the first thing to check.

If the condition is false the very first time, the block runs **zero** times. A while loop with `n = 0` in the example above prints only `Liftoff!`.

### Counters and totals

A loop often updates two variables, a counter and a total:

```python
total = 0
count = 0
while count < 4:
    count += 1
    total += count
print(total)   # 10
```

The counter goes `1, 2, 3, 4` and the total becomes `1`, `3`, `6` and `10`. The short form `count += 1` means `count = count + 1`.

### Sentinels and break

Sometimes you do not know how many times to repeat. A **sentinel** is a special input value that means "stop". The program reads a value, checks it, and reads again at the bottom of the loop:

```python
count = 0
word = input()
while word != "stop":
    count += 1
    word = input()
print(count)
```

The keyword `break` leaves a loop immediately. It is often used with `while True:`, a loop that runs until `break` happens:

```python
while True:
    word = input()
    if word == "stop":
        break
    print("You typed", word)
```

Use `while True` carefully: make sure that some path reaches `break`.

@example
title: Tracing a doubling loop
problem: You start with 5 dollars and double the amount each day until it reaches at least 50. What does this program print?

```python
amount = 5
days = 0
while amount < 50:
    amount = amount * 2
    days += 1
print(amount, days)
```
step: Before the loop, `amount` is `5` and `days` is `0`.
step: Pass 1: `5 < 50` is true, so `amount` becomes `10` and `days` becomes `1`. Pass 2: `amount` is `20` and `days` is `2`.
step: Pass 3: `amount` is `40` and `days` is `3`. Since `40 < 50` is still true, the loop runs again.
step: Pass 4: `amount` is `80` and `days` is `4`. Now `80 < 50` is false, so the loop stops.
step: The `print` runs once, after the loop, and shows `80 4`.
answer: `80 4`

@example
title: Counting words until stop
problem: The user types the words `red`, `blue`, `green` and then `stop` into this program. What does it print, and why?

```python
count = 0
word = input()
while word != "stop":
    count += 1
    word = input()
print(count)
```
step: The first `input()` reads `red`. It is not `stop`, so the loop starts.
step: Inside the loop `count` becomes `1`, and the next word `blue` is read. The same happens for `blue` (`count` is `2`) and `green` (`count` is `3`).
step: After `green`, the program reads `stop`. The condition `word != "stop"` is now false, so the loop ends without counting it.
step: The program prints `3`.

@mistakes
- Forgetting to change the loop variable, which makes an infinite loop.
- Being off by one: `while n > 0` stops before 0, but `while n >= 0` includes 0.
- Reading the next value before the loop but not again inside it, so the loop keeps testing the same value.
- Indenting the `print` of the final result inside the loop, so it prints on every pass.

@practice mc
prompt: Why does this loop never stop?

```python
n = 5
while n > 0:
    print(n)
```
choice*: Nothing inside the loop changes `n`, so `n > 0` stays true forever
choice: `print` cannot be used inside a loop
choice: The loop would stop only if `n` were a float
choice: A `while` loop needs an `else` to stop
hint: Which variable appears in the condition, and does the loop body ever change it?
solution: The condition depends on `n`, but the body never changes `n`. Adding `n = n - 1` as the last line of the loop fixes it.

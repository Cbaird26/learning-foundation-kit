@article
Sometimes one comparison is not enough. A ticket might be free *if you are under 5 or over 65*, and a player might win *if the score is high and the time is short*. A value that is `True` or `False` is a **Boolean**, and three operators combine Booleans.

### and, or, not

- `a and b` is `True` only when **both** `a` and `b` are true.
- `a or b` is `True` when **at least one** of them is true.
- `not a` flips the value: `not True` is `False`.

A **truth table** lists every case:

| `a` | `b` | `a and b` | `a or b` |
|---|---|---|---|
| `True` | `True` | `True` | `True` |
| `True` | `False` | `False` | `True` |
| `False` | `True` | `False` | `True` |
| `False` | `False` | `False` | `False` |

```python
age = 70
if age < 5 or age >= 65:
    print("free ticket")
```

Here `70 < 5` is false but `70 >= 65` is true, so `or` gives `True` and the program prints `free ticket`.

### Order of evaluation

Like arithmetic, logic has an order: `not` first, then `and`, then `or`. Parentheses override it. So `True or False and False` is `True`, because `and` happens first, but `(True or False) and False` is `False`. When in doubt, add parentheses: they cost nothing and make your meaning clear.

### Ranges

To test that a value lies in a range, you can chain comparisons:

```python
x = 7
print(1 <= x <= 10)         # True
print(x >= 1 and x <= 10)   # True, the same thing
```

Pay attention to `and` versus `or`. The test `x >= 1 or x <= 10` is true for every number, because every number is at least 1 or at most 10.

### A very common mistake

You might want to write "if `day` is Saturday or Sunday" as `day == "sat" or "sun"`. Python reads this as `(day == "sat") or "sun"`, and a non-empty string counts as true, so the condition is always true. Write the full comparison on both sides of `or`:

```python
day = "mon"
if day == "sat" or day == "sun":
    print("weekend")
else:
    print("weekday")
```

This prints `weekday`. You can also write `day in ["sat", "sun"]`, which you will meet again with lists.

@example
title: Evaluating a compound condition
problem: With `a = 4` and `b = 9`, what does `print(a > 5 or b > 5 and not a == 4)` print?
step: Evaluate each comparison: `a > 5` is `False`, `b > 5` is `True`, and `a == 4` is `True`.
step: `not a == 4` becomes `not True`, which is `False`.
step: `and` comes before `or`, so first `True and False` is `False`.
step: Now `False or False` is `False`, so the program prints `False`.
answer: `False`

@example
title: Pass with a retake
problem: A student passes if the test score is at least 60, or if the score is at least 50 and the homework was handed in (`"yes"`). Print `pass` or `fail`.
step: Read the two inputs: the score as a number and the homework answer as text.
step: Write each rule as a condition: `score >= 60`, and `score >= 50 and homework == "yes"`.
step: Join the rules with `or`:

```python
score = int(input())
homework = input()
if score >= 60 or (score >= 50 and homework == "yes"):
    print("pass")
else:
    print("fail")
```
step: For a score of `55` with homework `no`, the first rule is false and the second is false, so the program prints `fail`. With homework `yes` it prints `pass`.

@mistakes
- Writing `x == 1 or 2` instead of `x == 1 or x == 2`. The number `2` alone always counts as true.
- Choosing `or` when you need `and` for a range, so that the condition is true for every number.
- Forgetting that `and` binds tighter than `or`, and not using parentheses to say what you mean.
- Writing `not x == 3` and reading it as `(not x) == 3`. It means `not (x == 3)`.

@quiz ms
prompt: With `x = 5`, which of these expressions are `True`? Select all that apply.
choice*: `x > 5 or x == 5`
choice: `x > 3 and x < 5`
choice*: `not (x < 5)`
choice: `x < 5 and x > 5`
choice*: `x != 4 and x != 6`
hint: Work out each comparison with `x = 5`, then combine them.
solution: `x > 5 or x == 5` is true because `x == 5` is true. `not (x < 5)` is true because `x < 5` is false. `x != 4 and x != 6` is true because both parts are true. The expression `x > 3 and x < 5` is false because 5 is not less than 5, and `x < 5 and x > 5` is false because no number is both.

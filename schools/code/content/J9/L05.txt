@article
Real programs make decisions: show a warning if the battery is low, give a discount if the order is large. Python decides with the `if` statement, which runs some lines only when a condition is true.

### Comparisons

A **comparison** asks a yes-or-no question and gives a `bool`, either `True` or `False`:

| Operator | Question | Example | Result |
|---|---|---|---|
| `==` | equal? | `5 == 5` | `True` |
| `!=` | not equal? | `5 != 5` | `False` |
| `<` | less than? | `3 < 4` | `True` |
| `>` | greater than? | `3 > 4` | `False` |
| `<=` | less than or equal? | `4 <= 4` | `True` |
| `>=` | greater than or equal? | `3 >= 4` | `False` |

Be careful: a single `=` stores a value, while a double `==` compares two values.

### if, elif and else

```python
temperature = 8
if temperature < 0:
    print("freezing")
elif temperature < 15:
    print("cool")
else:
    print("warm")
```

This prints `cool`. Python checks the conditions from the top. The first one that is true runs its block, and all the remaining branches are skipped. If none is true, the `else` block runs. The `else` is optional, and you can have as many `elif` branches as you like.

Each condition ends with a colon, and the lines that belong to it are **indented** by 4 spaces. The indentation is how Python knows which lines are inside the block. A line that is not indented is outside it and always runs:

```python
if temperature < 15:
    print("take a coat")   # only when it is cool
print("have a nice day")   # always
```

### Order matters

Because the first true branch wins, put the most specific condition first. Suppose a score of 85 is tested like this:

```python
score = 85
if score >= 60:
    print("pass")
elif score >= 80:
    print("great")
```

It prints `pass`, and the `great` branch can never run, because every score of 80 or more is also 60 or more. Test `score >= 80` first, and the program does what you meant.

### Decisions with input

Remember that `input()` gives a string, so convert it before comparing numbers: `age = int(input())`. Comparing the string `"9"` with the number `10` is an error.

@example
title: Which branch runs?
problem: What does this program print?

```python
n = 12
if n > 20:
    print("big")
elif n > 10:
    print("medium")
elif n > 5:
    print("small")
else:
    print("tiny")
print("done")
```
step: `n > 20` is `12 > 20`, which is false, so the `big` block is skipped.
step: `n > 10` is `12 > 10`, which is true, so `medium` is printed.
step: Python skips the remaining branches, even though `n > 5` is also true.
step: The last `print` is not indented, so it always runs. The output is `medium` and then `done`.
answer: `medium`, `done`

step: Test one case at a time: `n > 0` is positive and `n < 0` is negative.
step: Whatever is left must be zero, so that case can be the `else`:

```python
n = int(input())
if n > 0:
    print("positive")
elif n < 0:
    print("negative")
else:
    print("zero")
```
step: For the input `-3` the first condition is false, the second is true, and the program prints `negative`.

@mistakes
- Writing `=` instead of `==` in a condition. `if x = 5:` is an error.
- Forgetting the colon at the end of the `if`, `elif` or `else` line, or forgetting to indent the block.
- Putting a general condition before a specific one, so the specific branch can never run.
- Using a series of separate `if` statements when you meant `elif`, so several blocks run instead of just one.

@article
Among the problems in NP, some are as hard as any other. These are the **NP-complete** problems. If one of them has a polynomial-time algorithm then every problem in NP does.

### Polynomial-time reductions

Language $A$ is **polynomial-time mapping reducible** to $B$, written $A \le_p B$, if there is a function $f$, computable in polynomial time, such that for every string $w$,
$$w \in A \iff f(w) \in B.$$
**Theorem.** If $A \le_p B$ and $B \in \mathrm{P}$, then $A \in \mathrm{P}$. (Compute $f(w)$, then run the decider for $B$; a polynomial of a polynomial is a polynomial.) Reductions are also transitive.

### NP-complete

A language $B$ is **NP-hard** if every language in NP is polynomial-time reducible to $B$. It is **NP-complete** if it is NP-hard **and** $B \in \mathrm{NP}$.

**Corollary.** If any NP-complete problem is in P, then $\mathrm{P} = \mathrm{NP}$. Conversely, if $\mathrm{P} \ne \mathrm{NP}$, no NP-complete problem has a polynomial-time algorithm.

### The Cook–Levin theorem

A Boolean formula is **satisfiable** if some assignment of true/false to its variables makes it true. $\mathrm{SAT}$ is the set of satisfiable formulas. A formula is in **conjunctive normal form (CNF)** if it is an AND of clauses, each an OR of literals (variables or their negations). **3SAT** is the satisfiability problem for CNF formulas with exactly three literals per clause.

**Theorem (Cook–Levin).** SAT is NP-complete. A refinement of the same proof, which produces formulas with exactly three literals per clause, shows that 3SAT is NP-complete as well.

*Idea of the proof:* SAT is in NP (the certificate is a satisfying assignment). For any $A \in \mathrm{NP}$ with a polynomial-time verifier or NTM, describe the computation as a table (a **tableau**) of polynomially many cells, and write a formula that is satisfiable exactly when the table can be filled in as an accepting computation. The formula has polynomial size and is built in polynomial time.

### Proving a new problem NP-complete

Once one problem is known to be NP-complete, others follow by reduction:

1. Show that $B \in \mathrm{NP}$ (give a certificate and a polynomial-time verifier).
2. Choose a known NP-complete problem $A$ and show that $A \le_p B$.

Chains of reductions starting from 3SAT show that CLIQUE, INDEPENDENT-SET, VERTEX-COVER, HAMPATH, SUBSET-SUM and the decision version of the traveling salesman problem are NP-complete. Be careful about the direction again: you reduce *from* the known-hard problem *to* the new one. Small changes can matter: 2SAT, with two literals per clause, is in P.

### The reduction from 3SAT to CLIQUE

Given a formula with $m$ clauses, build a graph $G$ whose vertices are the literal occurrences: one vertex per literal in each clause, grouped in $m$ **triples**. Join two vertices by an edge unless they are in the same clause or they are contradictory (such as $x$ and $\neg x$). Set $k = m$.

*Claim:* the formula is satisfiable iff $G$ has a $k$-clique. A $k$-clique takes one literal from each clause, and no two are contradictory, so setting all of them true is consistent and satisfies every clause. Conversely, a satisfying assignment makes at least one literal true in each clause; the chosen true literals form a clique. The graph has $3m$ vertices, so the construction is polynomial.

### Practical meaning

NP-completeness is strong evidence that no efficient exact algorithm exists, but it does not make a problem hopeless. Engineers use heuristics, approximation algorithms, special-case algorithms, and modern SAT solvers that handle huge structured instances.

@example
title: From 3SAT to CLIQUE on a small formula
problem: Build the graph for $\varphi = (x_1 \lor x_2 \lor x_3) \land (\neg x_1 \lor \neg x_2 \lor x_3)$ and find a clique of the required size.
step: There are $m = 2$ clauses, so $k = 2$ and the graph has $6$ vertices: $x_1, x_2, x_3$ in clause 1 and $\neg x_1, \neg x_2, x_3$ in clause 2.
step: Possible edges join a vertex of clause 1 to a vertex of clause 2: there are $3 \times 3 = 9$ of them. Remove the contradictory pairs $(x_1, \neg x_1)$ and $(x_2, \neg x_2)$. That leaves $7$ edges.
step: A $2$-clique is a single edge between the clauses. The edge between the $x_3$ in clause 1 and the $x_3$ in clause 2 is present, since they are not contradictory.
step: Set $x_3 = \text{true}$. Both clauses contain $x_3$, so $\varphi$ is satisfied, and the clique corresponds to a satisfying assignment.
answer: The graph has $6$ vertices and $7$ edges, and the edge between the two $x_3$ vertices is a $2$-clique, matching the satisfying assignment $x_3 = \text{true}$.

@example
title: Independent set and vertex cover
problem: A **vertex cover** of a graph is a set of vertices that touches every edge, and an **independent set** is a set of vertices with no edge between them. Show that INDEPENDENT-SET $\le_p$ VERTEX-COVER.
step: Claim: for any graph $G = (V, E)$, a set $S$ is independent if and only if $V \setminus S$ is a vertex cover.
step: If $S$ is independent, every edge has at most one endpoint in $S$, so at least one endpoint lies in $V \setminus S$; hence $V \setminus S$ covers every edge.
step: If $V \setminus S$ covers every edge, no edge has both endpoints in $S$, so $S$ is independent.
step: The reduction maps $\langle G, k \rangle$ to $\langle G, n - k \rangle$ where $n = |V|$. It is computable in polynomial time, and $G$ has an independent set of size $k$ iff it has a vertex cover of size $n - k$.
step: Example: the path $a - b - c$ has the independent set $\{a, c\}$ of size $2$ and the vertex cover $\{b\}$ of size $3 - 2 = 1$.
answer: $\langle G, k \rangle \mapsto \langle G, |V| - k \rangle$.

@mistakes
- Reducing in the wrong direction: to prove $B$ NP-complete, reduce a known NP-complete problem *to* $B$.
- Forgetting to show membership in NP. A problem that is NP-hard but not in NP (for instance, the halting problem) is not NP-complete.
- Giving a reduction that is not polynomial-time, or one that is correct in only one direction. The equivalence $w \in A \iff f(w) \in B$ needs both.
- Treating NP-complete as "impossible": it means no known polynomial algorithm for all instances, not that every instance is hard.

model:
```python
def build_clique_graph(clauses):
    vertices = []
    for ci, clause in enumerate(clauses):
        for lit in clause:
            vertices.append((ci, lit))
    edges = []
    for u in range(len(vertices)):
        for v in range(u + 1, len(vertices)):
            cu, lu = vertices[u]
            cv, lv = vertices[v]
            if cu != cv and lu != -lv:
                edges.append((u, v))
    return len(vertices), edges
```
hint: First list the vertices as pairs `(clause_index, literal)`.
hint: Then consider every pair of vertices `u < v`, keep it if the clause indices differ and the literals are not opposites.
solution: List the literal occurrences as vertices, then test all pairs: an edge needs different clauses and non-contradictory literals. Looping `u` before `v` with `u < v` produces the edges already sorted. The graph has at most $\binom{N}{2}$ edges where $N$ is the number of literal occurrences, so the construction is polynomial.

model:
```python
from itertools import product


def brute_force_sat(n_vars, clauses):
    for values in product([False, True], repeat=n_vars):
        ok = True
        for clause in clauses:
            if not any(values[abs(lit) - 1] == (lit > 0) for lit in clause):
                ok = False
                break
        if ok:
            return True
    return False
```
hint: There are $2^{n}$ assignments; `itertools.product([False, True], repeat=n_vars)` generates them.
hint: A literal `lit` is true when `values[abs(lit) - 1]` equals `lit > 0`. A clause is satisfied if any literal is true.
solution: Try every assignment, and accept as soon as all clauses are satisfied. The loop is exponential, $O(2^n \cdot |\varphi|)$, while checking *one* assignment (the verifier) is polynomial, which places SAT in NP.

@practice self
prompt: (a) Show that VERTEX-COVER $= \{\langle G, k \rangle : G \text{ has a vertex cover with at most } k \text{ vertices}\}$ is in NP. (b) Sketch a proof that INDEPENDENT-SET is polynomial-time reducible to VERTEX-COVER, including why the reduction is correct.
solution: (a) The certificate is a set $C$ of at most $k$ vertices. The verifier checks $|C| \le k$ and that every edge of $G$ has at least one endpoint in $C$, which takes time $O(|E| \cdot |C|)$ or better, polynomial in the input. If a cover of size at most $k$ exists, it is accepted; otherwise no certificate is. (b) Map $\langle G, k \rangle$ with $G = (V, E)$ and $n = |V|$ to $\langle G, n - k \rangle$. A set $S \subseteq V$ is independent iff no edge has both endpoints in $S$, iff every edge has an endpoint in $V \setminus S$, iff $V \setminus S$ is a vertex cover. So $G$ has an independent set of size $k$ iff it has a vertex cover of size $n - k$, and the map takes polynomial time (it copies the graph and subtracts).

rubric: The reduction maps $\langle G, k \rangle$ to $\langle G, n - k \rangle$ and runs in polynomial time.
rubric: Proves both directions of the equivalence: $S$ is independent iff $V \setminus S$ is a vertex cover.

@quiz mc
prompt: Suppose someone discovers an algorithm that decides 3SAT in polynomial time on a deterministic machine. What would follow?
choice*: $\mathrm{P} = \mathrm{NP}$.
choice: Only 3SAT would be in P; other NP problems would stay hard.
choice: $\mathrm{P} \ne \mathrm{NP}$.
choice: Every NP-complete problem would become undecidable.
hint: Every NP problem reduces to 3SAT in polynomial time.
solution: 3SAT is NP-complete, so every problem in NP reduces to it in polynomial time. Composing a reduction with a polynomial-time 3SAT algorithm decides any NP problem in polynomial time, so $\mathrm{NP} \subseteq \mathrm{P}$, and with $\mathrm{P} \subseteq \mathrm{NP}$ we get $\mathrm{P} = \mathrm{NP}$.

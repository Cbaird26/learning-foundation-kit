@article
A DFA has finitely many states, so it cannot count without bound. Languages such as $\{0^n 1^n : n \ge 0\}$ need unbounded counting, and the **pumping lemma** turns that intuition into a proof technique.

### The statement

**Pumping Lemma.** If $A$ is a regular language, then there is a number $p \ge 1$ (the **pumping length**) such that every string $s \in A$ with $|s| \ge p$ can be written $s = xyz$ with

1. $|y| > 0$,
2. $|xy| \le p$,
3. $xy^iz \in A$ for every $i \ge 0$.

**Why it is true.** Let $D$ be a DFA for $A$ with $p$ states. A string $s$ with $|s| \ge p$ makes $D$ visit at least $p + 1$ states $q_0, q_1, \dots, q_p$ within its first $p$ symbols. By the pigeonhole principle two of them are equal, say $q_j = q_k$ with $j < k \le p$. Let $y$ be the part of $s$ read between these visits, $x$ the part before, $z$ the part after. The part $y$ is a loop from a state to itself, so it can be repeated any number of times, or removed ($i = 0$), and $D$ still ends in the same final state.

### Using it: a game against an adversary

The lemma says "$A$ regular $\Rightarrow$ the property holds." So to show $A$ is **not regular**, show that the property fails. Write the proof as a game:

1. Suppose $A$ is regular with pumping length $p$ (the adversary picks $p$; you do not know it).
2. **You** choose a string $s \in A$ with $|s| \ge p$, in terms of $p$.
3. The adversary may split $s = xyz$ in any way meeting conditions 1 and 2. Because $|xy| \le p$, $y$ lies entirely inside the first $p$ symbols, which usually pins down what $y$ contains.
4. **You** choose $i$ such that $xy^iz \notin A$. This contradicts the lemma, so $A$ is not regular.

The order of the quantifiers matters: $p$ first, then your $s$, then the adversary's $xyz$, then your $i$. You must beat *every* legal split.

### Closure properties help too

Regular languages are closed under union, intersection, complement and reversal. If $A$ were regular, then $A \cap R$ would be regular for any regular $R$. For example, the set of binary strings with equally many $0$s and $1$s, intersected with $0^*1^*$, is $\{0^n1^n\}$, so that set is also not regular.

### What the lemma cannot do

The pumping lemma is a *necessary* condition for regularity, not a sufficient one. If a language does satisfy the pumping property, you learn nothing. There are non-regular languages that can be pumped. To prove regularity, build a DFA, NFA or regular expression.

@example
title: Proving that {0^n 1^n} is not regular
problem: Prove $B = \{0^n 1^n : n \ge 0\}$ is not regular.
step: Suppose $B$ is regular, with pumping length $p$. Choose $s = 0^p 1^p$. Then $s \in B$ and $|s| = 2p \ge p$.
step: Let $s = xyz$ be any split with $|y| > 0$ and $|xy| \le p$. Since $xy$ lies within the first $p$ symbols, which are all $0$s, we have $y = 0^k$ for some $k \ge 1$.
step: Pump up with $i = 2$: $xy^2z = 0^{p+k}1^p$.
step: This string has $p + k > p$ zeros but only $p$ ones, so it is not in $B$.
step: This contradicts the pumping lemma, so $B$ is not regular.
answer: $B$ is not regular.

@example
title: Pumping down
problem: Prove $C = \{0^i 1^j : i > j \ge 0\}$ is not regular.
step: Suppose $C$ is regular with pumping length $p$, and take $s = 0^{p+1}1^p$. It is in $C$ because $p + 1 > p$, and $|s| \ge p$.
step: Any legal split has $xy$ inside the first $p$ symbols, so $y = 0^k$ with $k \ge 1$.
step: Try $i = 0$ (pump down): $xz = 0^{p+1-k}1^p$.
step: Since $k \ge 1$, the number of zeros is at most $p$, which is not greater than the number of ones. So $xz \notin C$, a contradiction.
step: Pumping up would not work here, since extra $0$s keep $i > j$ true. Choosing the right direction is part of the proof.
answer: $C$ is not regular.

@mistakes
- Choosing $s$ after seeing the split. The string $s$ depends only on $p$; the adversary chooses $xyz$ afterwards.
- Checking only one convenient split such as $y = 0$. You must show a contradiction for every $xyz$ with $|y| > 0$ and $|xy| \le p$.
- Using the lemma backwards: "the language can be pumped, so it is regular" is false.
- Forgetting condition 2, $|xy| \le p$, which is what tells you where $y$ lies.

model:
```python
def find_loop(delta, start, w):
    state = start
    first = {start: 0}
    for j, ch in enumerate(w, start=1):
        state = delta[(state, ch)]
        if state in first:
            return (first[state], j)
        first[state] = j
    return None
```
hint: Record the position at which each state was first visited, using a dictionary.
hint: After each transition, check whether the new state is already in the dictionary. If so, return the stored position and the current position.
solution: Remember the first position of each visited state. The first time the run revisits a state at position `j`, return that state's earlier position and `j`. The substring `w[i:j]` then is a loop that can be pumped. For `"0101"` the states are `s, z, t, z`, so the first repeat is `z` at positions `1` and `3`.

prompt: Prove that $L = \{a^n b^{2n} : n \ge 0\}$ is not regular, using the pumping lemma. Write the proof as a careful argument covering every legal split.
solution: Suppose $L$ is regular, with pumping length $p$. Take $s = a^p b^{2p}$, which is in $L$ and has length $3p \ge p$. Let $s = xyz$ with $|y| > 0$ and $|xy| \le p$. Since the first $p$ symbols of $s$ are all $a$, we have $y = a^k$ with $k \ge 1$. Consider $xy^2z = a^{p+k} b^{2p}$. For this to be in $L$ we would need $2(p + k) = 2p$, that is $k = 0$, which contradicts $k \ge 1$. So $xy^2z \notin L$, contradicting the pumping lemma. Therefore $L$ is not regular.

model:
```python
def no_split_pumps(s, p, in_lang):
    for a in range(len(s) + 1):
        for b in range(a + 1, len(s) + 1):
            if b > p:
                break
            x, y, z = s[:a], s[a:b], s[b:]
            if all(in_lang(x + y * i + z) for i in range(4)):
                return False
    return True
```
hint: Loop over the start `a` and end `b` of `y`, with `a < b` and `b <= p`.
hint: A split pumps if `in_lang(x + y*i + z)` is true for all `i` in `range(4)`. Return `False` as soon as you find one such split.
solution: Try every legal split. If one split keeps the string in the language for all four values of `i`, the string can be pumped there, so return `False`. If no split survives, return `True`. For $0^3 1^3$ with $p = 3$ every legal $y$ consists of zeros only, and pumping changes the count of zeros, so the answer is `True`.

@quiz mc
prompt: Which of these languages is **not** regular?
choice*: $\{1^{n^2} : n \ge 0\}$
choice: $\{w : \text{the number of } 0\text{s in } w \text{ is divisible by } 5\}$
choice: $\{0^n 1^m : n, m \ge 0\}$
choice: $\{w : w \text{ has length divisible by } 7\}$
hint: Three of these need only finitely much memory: a counter modulo a fixed number, or two simple phases.
solution: The language $\{1^{n^2}\}$ is not regular: with pumping length $p$, take $s = 1^{p^2}$. Any legal split has $y = 1^k$ with $1 \le k \le p$, so $xy^2z$ has length $p^2 + k$. Since $p^2 < p^2 + k \le p^2 + p < p^2 + 2p + 1 = (p+1)^2$, that length lies strictly between two consecutive squares, so $xy^2z \notin L$. The other three languages are regular: a counter modulo $5$, the expression $0^*1^*$, and a counter modulo $7$.

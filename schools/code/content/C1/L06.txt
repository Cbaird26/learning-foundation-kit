@article
A **dictionary** (`dict`) maps **keys** to **values**: `ages = {"ann": 31, "bo": 27}`. Looking up a key is fast: on average the time does not grow with the size of the dictionary, $O(1)$ on average. Lists are indexed by position; dictionaries by meaning.

### Basic operations

```python
ages = {"ann": 31, "bo": 27}
ages["cy"] = 45          # insert or update
ages["ann"]              # 31; a missing key raises KeyError
ages.get("dee", 0)       # 0 (a default instead of an error)
"bo" in ages             # True (tests keys)
del ages["bo"]           # remove a key
len(ages)                # number of keys
```

Iteration: `for k in d` visits keys; `d.keys()`, `d.values()` and `d.items()` give views of keys, values and `(key, value)` pairs. Since Python 3.7 a dictionary remembers **insertion order**, and iteration follows it. Updating the value of an existing key keeps its position. `d | other` (Python 3.9 and later) builds a merged dictionary in which `other` wins ties, and `d.update(other)` merges in place.

### Keys must be hashable

A key must be **hashable**: an object whose hash never changes while it is in use. Numbers, strings, `None`, booleans and tuples of hashable items qualify. Lists and dictionaries are mutable, so `{[1, 2]: "x"}` raises `TypeError`. Two keys count as the same if they are equal: `1` and `1.0` are one key.

### Pattern 1: counting

```python
counts = {}
for ch in "abca":
    counts[ch] = counts.get(ch, 0) + 1
# {'a': 2, 'b': 1, 'c': 1}
```

`counts.get(ch, 0)` gives the current count, or 0 the first time. (The standard library's `collections.Counter` does this job; write the loop yourself first.)

### Pattern 2: grouping

```python
by_length = {}
for w in ["pi", "tau", "e", "phi"]:
    n = len(w)
    if n not in by_length:
        by_length[n] = []
    by_length[n].append(w)
# {2: ['pi'], 3: ['tau', 'phi'], 1: ['e']}
```

Each key maps to a list that collects the items that share a property.

### Nested data

Real data nests dictionaries and lists, for example `{"ann": {"math": 90, "art": 80}}`. Read it with chained lookups (`book["ann"]["math"]`) and process it with nested loops. When a function builds new nested data it must build new inner containers; reusing an inner list or dictionary creates aliases, as in week 5.

```python
def averages(book):
    result = {}
    for name, marks in book.items():
        result[name] = sum(marks.values()) / len(marks)
    return result
```

A **dictionary comprehension** is a compact form: `{w: len(w) for w in words}`.

### Mutation while iterating

Adding or deleting keys while looping over the same dictionary raises `RuntimeError`. Loop over `list(d)` or build a new dictionary.

@example
title: Counting with get
problem: What does this program print?

```python
d = {}
for ch in "abca":
    d[ch] = d.get(ch, 0) + 1
print(d)
```
step: `d` starts empty. `ch = "a"`: `d.get("a", 0)` is `0`, so `d["a"]` becomes `1`.
step: `ch = "b"`: the key is missing, so `d["b"]` becomes `1`. Likewise `d["c"]` becomes `1`.
step: `ch = "a"` again: `d.get("a", 0)` is `1`, so `d["a"]` is updated to `2`. The key keeps its original position.
step: Printing shows the keys in insertion order: `a`, `b`, `c`.
answer: `{'a': 2, 'b': 1, 'c': 1}`

@example
title: Transforming nested data
problem: `book = {"ann": {"math": 90, "art": 80}, "bo": {"math": 70}}`. Write `best_subject(book)` returning a dictionary that maps each student to the subject with the highest mark. What is the result for `book`?
step: The input is a dictionary of dictionaries, so the outer loop visits students and the inner step finds a maximum over their marks.
step: Keep the best subject so far in an accumulator and compare marks, using `marks[subject]`:

```python
def best_subject(book):
    result = {}
    for name, marks in book.items():
        best = None
        for subject in marks:
            if best is None or marks[subject] > marks[best]:
                best = subject
        result[name] = best
    return result
```
step: For `ann`: `math` (90) beats `art` (80), so `math`. For `bo`: only `math`.
step: The function builds a new dictionary and never changes `book`.
answer: `{'ann': 'math', 'bo': 'math'}`

@mistakes
- Using `d[key]` for a key that may be absent, which raises `KeyError`; use `d.get(key, default)` or test `key in d`.
- Using a list as a key (`TypeError: unhashable type`); use a tuple instead.
- Creating one inner list and reusing it for several keys (`d[a] = d[b] = []`), so all keys share the same list.
- Deleting or inserting keys while iterating over the same dictionary, which raises `RuntimeError`.

def word_counts(text):

@practice code
prompt: A gradebook is a dictionary that maps each student name to a dictionary of subject marks, for example `{"ann": {"math": 90, "art": 80}, "bo": {"math": 70}}`. Write `averages(book)` that returns a new dictionary mapping each student to the average of their marks as a float. Every student has at least one mark. The gradebook must not be modified.
starter:
```python
def averages(book):
    pass
```
tests:
```python
book = {"ann": {"math": 90, "art": 80}, "bo": {"math": 70}}
assert averages(book) == {"ann": 85.0, "bo": 70.0}
assert book == {"ann": {"math": 90, "art": 80}, "bo": {"math": 70}}
assert averages({}) == {}
assert averages({"cy": {"a": 60, "b": 70, "c": 80}}) == {"cy": 70.0}
```
model:
```python
def averages(book):
    result = {}
    for name, marks in book.items():
        total = 0
        for subject in marks:
            total += marks[subject]
        result[name] = total / len(marks)
    return result
```
hint: Loop over `book.items()` to get each student's name and inner dictionary.
hint: Add the values of the inner dictionary, then divide by `len(marks)`.
solution: For each student, total the marks in the inner dictionary and divide by their count. Using `/` gives a float, and a new result dictionary leaves `book` unchanged.

@quiz code
prompt: Write `merge_counts(a, b)` that takes two dictionaries mapping items to integer counts and returns a **new** dictionary in which each item's count is the sum of its counts in `a` and `b` (an item missing from one dictionary counts as 0). Neither input may be modified.
starter:
```python
def merge_counts(a, b):
    pass
```
tests:
```python
a = {"x": 1, "y": 2}
b = {"y": 5, "z": 7}
assert merge_counts(a, b) == {"x": 1, "y": 7, "z": 7}
assert a == {"x": 1, "y": 2}
assert b == {"y": 5, "z": 7}
assert merge_counts({}, {}) == {}
assert merge_counts({"k": 3}, {}) == {"k": 3}
```
model:
```python
def merge_counts(a, b):
    result = {}
    for key in a:
        result[key] = result.get(key, 0) + a[key]
    for key in b:
        result[key] = result.get(key, 0) + b[key]
    return result
```
hint: Start from an empty result and add the counts of each input in turn.
solution: Add every count of `a` and then every count of `b` into a new dictionary, using `get(key, 0)` for items not seen yet. Starting from `{}` rather than `a` avoids modifying an input.

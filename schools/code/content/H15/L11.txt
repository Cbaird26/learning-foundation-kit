@article
A **data structure** organizes data so that certain operations are easy. An **abstract data type** (ADT) is the *interface*: the operations you may perform and what they mean, without saying how the data is stored. Two of the most useful ADTs have very small interfaces.

### The stack: last in, first out

Think of a pile of plates. You add a plate on top and take a plate from the top, so the plate added **last** comes off **first**: **LIFO**. The operations are:

- `push(x)`: put `x` on top.
- `pop()`: remove and return the top item (an error if the stack is empty).
- `peek()`: look at the top item without removing it.
- `is_empty()` and `len(...)`.

A Python list makes a good stack: `append` pushes and `pop()` removes from the end. Both take amortized $O(1)$ time. Stacks appear whenever the most recent thing must be handled first: the **undo** history of an editor, the browser's back button, and the call stack that makes recursion work.

```python
stack = []
stack.append("a")
stack.append("b")
print(stack.pop())    # b
print(stack[-1])      # a  (peek)
```

### The queue: first in, first out

Think of a line at a shop: the person who arrived **first** is served **first**: **FIFO**. The operations are `enqueue(x)` (add at the back), `dequeue()` (remove from the front), `peek()`, `is_empty()` and `len`. Queues model print jobs, customer requests and tasks waiting for a processor, and they drive *breadth-first search*, which you will meet in algorithms courses.

A list is a poor queue: `list.pop(0)` must shift every other item left, so it takes $O(n)$. The standard library's `collections.deque` (double-ended queue) supports `append` and `popleft` in $O(1)$ time:

```python
from collections import deque

q = deque()
q.append("first")
q.append("second")
print(q.popleft())    # first
```

### Wrapping the structure in a class

A good class exposes only the ADT operations and hides the storage:

```python
class Stack:
    def __init__(self):
        self._items = []

    def push(self, item):
        self._items.append(item)

    def pop(self):
        if not self._items:
            raise IndexError("pop from empty stack")
        return self._items.pop()

    def is_empty(self):
        return not self._items

    def __len__(self):
        return len(self._items)
```

Anyone using `Stack` cannot tell (and need not care) that a list is inside, so you could switch the storage later without changing any caller. That is the value of an ADT, and it is exactly the encapsulation you studied in week 4. Notice that popping from an empty stack is a *programmer error* that should raise an exception, not return a silent value.

### Example application: matching brackets

To check that `([]{})` is balanced, scan left to right. Push each opening bracket. On a closing bracket, the most recent unmatched opening bracket must be its partner, so pop it and compare. The string is balanced if no mismatch occurs and the stack is empty at the end. The *most recent* unmatched thing is exactly what a stack gives you.

### Example application: postfix expressions

In postfix notation the operator comes after its operands, so `3 4 +` means $3 + 4$ and `5 1 2 + 4 * + 3 -` means $5 + (1 + 2) \times 4 - 3$. Evaluate by scanning left to right: push numbers; on an operator, pop two values, apply the operator and push the result. The first value popped is the **right** operand, which matters for `-`.

@example
title: Tracing a stack and a queue
problem: What does this program print?

```python
from collections import deque

s = []
q = deque()
for x in [1, 2, 3]:
    s.append(x)
    q.append(x)
print(s.pop(), q.popleft())
print(s.pop(), q.popleft())
print(list(s), list(q))
```
step: Both containers receive `1`, `2`, `3` in that order: the stack is `[1, 2, 3]` with `3` on top, and the queue holds `1, 2, 3` with `1` at the front.
step: First line: the stack removes the newest item, `3`; the queue removes the oldest, `1`. It prints `3 1`.
step: Second line: the stack removes `2` and the queue removes `2`, so it prints `2 2`.
step: Remaining: the stack has `[1]` and the queue has `[3]`, so the last line is `[1] [3]`.
answer: `3 1`, then `2 2`, then `[1] [3]`

@example
title: Checking brackets with a stack
problem: Is `"(]"` balanced? What about `"(()"`?
step: Scan `"(]"`: push `(`. The next character `]` is a closer, so pop the top, which is `(`. A `(` does not match `]`, so the string is not balanced.
step: Scan `"(()"`: push `(`, push `(`, then the closer `)` pops one `(`. No mismatch occurred.
step: At the end one `(` is still on the stack, so the string is not balanced.
step: A balanced string passes both tests: every closer finds a matching opener, and the stack is empty at the end.

@mistakes
- Using `list.pop(0)` for a queue; it works but is $O(n)$ per removal. Use `collections.deque` and `popleft`.
- Popping from an empty stack without checking, which raises `IndexError` in the middle of an algorithm; test `is_empty()` first when it can happen.
- In the bracket algorithm, forgetting the final check that the stack is empty, so `"(("` wrongly passes.
- Evaluating a postfix `-` or `/` with the operands in the wrong order: the first value popped is the right operand.

class Stack:

        self._items = []

    def push(self, item):
        self._items.append(item)

    def pop(self):

            raise IndexError("pop from empty stack")

        if not self._items:

model:
```python
from collections import deque


class Queue:
    def __init__(self):
        self._items = deque()

    def enqueue(self, item):
        self._items.append(item)

    def dequeue(self):
        if not self._items:
            raise IndexError("dequeue from empty queue")
        return self._items.popleft()

    def peek(self):
        if not self._items:
            raise IndexError("peek at empty queue")
        return self._items[0]

    def is_empty(self):
        return len(self._items) == 0

    def __len__(self):
        return len(self._items)
```
hint: Items enter at the right end with `append` and leave from the left end with `popleft`.
hint: A deque raises its own `IndexError` on an empty `popleft`, but check first so that your message and behavior are explicit; the front item is `self._items[0]`.
solution: Keep a `deque` created in `__init__`. `enqueue` appends on the right, `dequeue` uses `popleft` for $O(1)$ removal from the front, and `peek` reads index `0`. The order of the output in the test shows first-in, first-out.

model:
```python
def balanced(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
    return not stack
```
hint: Push every opening bracket. A closing bracket must match the item on top of the stack.
hint: Watch two special cases: a closer when the stack is empty (return `False`), and leftover openers at the end.
solution: A dictionary maps each closer to its opener. For a closer, the stack must be non-empty and its top must equal the partner, else return `False`. After the loop, the string is balanced only if no openers remain, which is `not stack`.

assert evaluate_postfix(["2", "3", "-"]) == -1
assert evaluate_postfix(["10", "4", "-"]) == 6
assert evaluate_postfix(["7"]) == 7

model:
```python
def evaluate_postfix(tokens):
    stack = []
    for tok in tokens:
        if tok in ("+", "-", "*"):
            right = stack.pop()
            left = stack.pop()
            if tok == "+":
                stack.append(left + right)
            elif tok == "-":
                stack.append(left - right)
            else:
                stack.append(left * right)
        else:
            stack.append(int(tok))
    return stack.pop()
```
hint: Push numbers; for an operator, pop two values and push the result.
hint: The first value popped is the right operand. Compare each whole token with the operator strings, because `"-3"` starts with a minus sign but is a number.
solution: Test `tok in ("+", "-", "*")` on the whole token so negative numbers are not mistaken for operators. Pop `right` first, then `left`, and apply the operator as `left op right`. At the end the single remaining value is the answer.

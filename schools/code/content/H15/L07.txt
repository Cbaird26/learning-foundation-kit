@article
Many things come in rows and columns: a tic-tac-toe board, a spreadsheet, a game map, the pixels of an image. Python has no special grid type; the standard way is a **list of lists**: a list in which each item is itself a list representing one row.

```python
grid = [
    [1, 2, 3],
    [4, 5, 6],
]
print(grid[1][2])     # 6: row 1, column 2
grid[0][1] = 20       # change one cell
print(len(grid))      # 2 rows
print(len(grid[0]))   # 3 columns
```

`grid[r]` is row `r` (a list) and `grid[r][c]` is the cell in row `r` and column `c`. Rows and columns both count from 0. A grid with `rows` rows and `cols` columns has valid positions `0 <= r < rows` and `0 <= c < cols`. Negative indexes are legal in Python (`grid[-1]` is the last row) but usually mean a bug when you are doing arithmetic on positions.

### Visiting every cell

Use one loop inside another: the outer loop picks the row, the inner loop picks the column.

```python
total = 0
for r in range(len(grid)):
    for c in range(len(grid[r])):
        total += grid[r][c]
```

When you do not need the positions, loop directly: `for row in grid:` then `for value in row:`. Work done per cell is constant, so visiting a grid of `R` rows and `C` columns takes $O(R \cdot C)$ time.

### Building a grid correctly

To make an `R` by `C` grid of zeros, create one list per row:

```python
grid = [[0] * 4 for _ in range(3)]   # 3 rows, 4 columns
```

The tempting short form is wrong:

```python
bad = [[0] * 4] * 3
```

`[0] * 4` is evaluated **once**, and the outer `* 3` makes three references to that *same* row. Setting `bad[0][1] = 5` shows up in every row, exactly the aliasing from week 1. (Multiplying a list of numbers or strings is safe because those are immutable; multiplying a list that contains lists is not.) The comprehension evaluates `[0] * 4` anew for each row.

### Neighbors and bounds

Games and simulations constantly ask about the cells around a position. The offsets of the four orthogonal neighbors are `(-1, 0)`, `(1, 0)`, `(0, -1)` and `(0, 1)`. Always check the bounds first, because a position such as `(-1, 0)` does not fail in Python: it silently wraps to the last row.

```python
def in_bounds(grid, r, c):
    return 0 <= r < len(grid) and 0 <= c < len(grid[0])
```

For the eight surrounding cells, loop over `dr` and `dc` in `(-1, 0, 1)` and skip the pair `(0, 0)`, which is the cell itself.

### Transforming grids

Row-wise work is easy because a row is a list: `sum(row)`, `max(row)`, `row.count(x)`. Column-wise work needs the second index: a column sum is `sum(grid[r][c] for r in range(len(grid)))`. The **transpose** swaps rows and columns, so that the new cell `[c][r]` holds the old cell `[r][c]`.

### Printing

For a text grid, join each row into a string:

```python
for row in grid:
    print(" ".join(str(v) for v in row))
```

### Copying

`grid.copy()` or `grid[:]` copies only the outer list: both lists still share the same row objects. To copy a grid, copy each row: `[row[:] for row in grid]` (or `copy.deepcopy`).

title: Reading and updating a grid
problem: What does this program print?

```python
g = [[1, 2], [3, 4], [5, 6]]
g[1][0] = 9
total = 0
for row in g:
    total += row[1]
print(g[1], total)
```
step: `g` has 3 rows and 2 columns. `g[1][0] = 9` replaces the first cell of row 1, so row 1 becomes `[9, 4]`.
step: The loop adds the column-1 value of every row: `2 + 4 + 6 = 12`.
step: `print(g[1], total)` prints the list `[9, 4]` and then `12`.
answer: `[9, 4] 12`

@example
title: Counting neighbors safely
problem: Write `count_around(grid, r, c)` that counts how many of the eight surrounding cells contain `1`.
step: Plan: try each offset `(dr, dc)` from `-1` to `1`, skip `(0, 0)`, skip positions outside the grid, and count cells equal to `1`.
step: Write it:

```python
def count_around(grid, r, c):
    count = 0
    for dr in (-1, 0, 1):
        for dc in (-1, 0, 1):
            if dr == 0 and dc == 0:
                continue
            nr, nc = r + dr, c + dc
            if 0 <= nr < len(grid) and 0 <= nc < len(grid[0]):
                if grid[nr][nc] == 1:
                    count += 1
    return count
```
step: In `[[1, 1], [0, 0]]` with `(r, c) = (0, 0)`, the neighbors inside the grid are `(0, 1)`, `(1, 0)` and `(1, 1)`, so the count is `1`. The other five offsets fall outside and are skipped by the bounds test.

@mistakes
- Building a grid with `[[0] * 4] * 3`, so all rows are one shared list and changing a cell changes a whole column.
- Swapping the indexes: `grid[c][r]` instead of `grid[r][c]`. Row first, then column.
- Forgetting that negative indexes do not raise an error, so a neighbor check without `0 <=` silently reads from the opposite edge.
- Copying a grid with `grid[:]` and then changing the copy's cells, which changes the original because the rows are shared.

def transpose(grid):
    if not grid:
        return []
    return [[grid[r][c] for r in range(len(grid))]
            for c in range(len(grid[0]))]

hint: The result has as many rows as the input has columns.

def count_around(grid, r, c, value):

model:
```python
def rotate_clockwise(grid):
    if not grid:
        return []
    rows = len(grid)
    cols = len(grid[0])
    return [[grid[r][c] for r in range(rows - 1, -1, -1)]
            for c in range(cols)]
```
hint: The new grid has as many rows as the old one had columns.
hint: New row `c` reads old column `c` from the bottom row up: `r` runs from `rows - 1` down to `0`.
solution: A clockwise turn is a transpose with each new row reversed. Equivalently, build new row `c` by reading column `c` of the old grid from the bottom up, which the comprehension with `range(rows - 1, -1, -1)` does.

assert winner_row([["X", "X", "X"], [".", "O", "."], ["O", ".", "."]]) == 0
assert winner_row([["X", "O", "."], ["O", "O", "O"], [".", ".", "X"]]) == 1

model:
```python
def winner_row(board):
    for r in range(len(board)):
        row = board[r]
        if row[0] != "." and row.count(row[0]) == len(row):
            return r
    return None
```
hint: A row is a winner when every cell equals its first cell and that first cell is not `"."`.
hint: `row.count(row[0]) == len(row)` checks that all cells match the first one. Return the index as soon as you find a winner.
solution: Loop over row indexes in order and return the first index whose row is uniform and not empty. Returning inside the loop gives the first winner; falling out of the loop returns `None`. A row of `"."` is uniform but excluded by the first test.

@article
Vectors $v_1, \dots, v_k$ are **linearly independent** if the only way to get $c_1v_1 + \dots + c_kv_k = 0$ is $c_1 = \dots = c_k = 0$. Otherwise they are **dependent**: at least one is a combination of the others. Put the vectors in the columns of a matrix $A$: the columns are independent exactly when $N(A) = \{0\}$, that is, when elimination finds a pivot in every column. More than $m$ vectors in $\mathbb{R}^m$ are always dependent, because $A$ then has more columns than rows, so some column is free.

### Basis and dimension

A **basis** of a subspace $S$ is a list of vectors that is linearly independent and spans $S$. Every vector in $S$ is then a combination of the basis vectors in exactly one way. A subspace has many bases, but all of them have the same number of vectors; this number is the **dimension** $\dim S$. The standard basis $e_1, \dots, e_n$ shows $\dim\mathbb{R}^n = n$.

### Rank and the reduced row echelon form

The **rank** $r$ of a matrix is the number of pivots after elimination. The **reduced row echelon form** $R$ has each pivot equal to $1$ with zeros above and below it. Column $j$ of $A$ is a **pivot column** if $R$ has a pivot there, and a **free column** otherwise.

### The four fundamental subspaces

For an $m \times n$ matrix $A$ of rank $r$:

| subspace | lives in | dimension | basis |
|---|---|---|---|
| column space $C(A)$ | $\mathbb{R}^m$ | $r$ | the pivot columns of $A$ (the original columns) |
| row space $C(A^T)$ | $\mathbb{R}^n$ | $r$ | the nonzero rows of $R$ |
| null space $N(A)$ | $\mathbb{R}^n$ | $n - r$ | one **special solution** per free column |
| left null space $N(A^T)$ | $\mathbb{R}^m$ | $m - r$ | solutions $y$ of $y^TA = 0$ |

The statement $\operatorname{rank}(A) + \dim N(A) = n$ is the **rank-nullity theorem**: pivot variables plus free variables account for all $n$ variables. Row operations do not change the row space or the null space, but they do change the column space, which is why you take the pivot columns of the **original** $A$.

A **special solution** for the free column $f$ sets that free variable to $1$, the other free variables to $0$, and solves for the pivot variables. If row $i$ of $R$ has its pivot in column $p_i$, the pivot variable $x_{p_i}$ becomes $-R_{if}$. The special solutions form a basis of $N(A)$.

The row rank equals the column rank, so $\operatorname{rank}(A) = \operatorname{rank}(A^T)$. A square $n \times n$ matrix is invertible exactly when its rank is $n$.

```python
from fractions import Fraction

def rref(A):
    R = [[Fraction(x) for x in row] for row in A]
    m, n, r = len(R), len(R[0]), 0
    pivots = []
    for c in range(n):
        p = next((i for i in range(r, m) if R[i][c] != 0), None)
        if p is None:
            continue
        R[r], R[p] = R[p], R[r]
        R[r] = [x / R[r][c] for x in R[r]]
        for i in range(m):
            if i != r:
                R[i] = [a - R[i][c] * b for a, b in zip(R[i], R[r])]
        pivots.append(c)
        r += 1
    return R, pivots
```

@example
title: The four subspaces of a 3 by 4 matrix
problem: Find the rank and bases of the four fundamental subspaces of $A = \begin{bmatrix}1&2&0&1\\2&4&1&4\\3&6&1&5\end{bmatrix}$.
step: Eliminate: row 2 minus $2\times$ row 1 is $[0,0,1,2]$, and row 3 minus $3\times$ row 1 is $[0,0,1,2]$. Then row 3 minus row 2 is zero. So $R = \begin{bmatrix}1&2&0&1\\0&0&1&2\\0&0&0&0\end{bmatrix}$, with pivots in columns 1 and 3, so $r = 2$.
step: Column space: the pivot columns of the original $A$, $(1, 2, 3)$ and $(0, 1, 1)$. Row space: the nonzero rows of $R$, $(1, 2, 0, 1)$ and $(0, 0, 1, 2)$. Both have dimension $2$.
step: Null space ($\dim = 4 - 2 = 2$): free columns are 2 and 4. Setting $x_2 = 1, x_4 = 0$ gives $x_1 = -2$, $x_3 = 0$, so $(-2, 1, 0, 0)$. Setting $x_2 = 0, x_4 = 1$ gives $x_1 = -1$, $x_3 = -2$, so $(-1, 0, -2, 1)$.
step: Left null space ($\dim = 3 - 2 = 1$): the elimination steps show $\text{row}_3 - \text{row}_2 - \text{row}_1 = 0$ in $A$, so $y = (-1, -1, 1)$ satisfies $y^TA = 0$.
step: Check one special solution: $A(-1, 0, -2, 1)^T = (-1 + 0 + 0 + 1,\ -2 + 0 - 2 + 4,\ -3 + 0 - 2 + 5) = (0, 0, 0)$.
answer: rank $2$; $\dim C(A) = \dim C(A^T) = 2$, $\dim N(A) = 2$, $\dim N(A^T) = 1$.

@example
title: Testing independence
problem: Are $(1, 2, 3)$, $(2, 1, 0)$ and $(4, 5, 6)$ linearly independent?
step: Put them in the columns of $A = \begin{bmatrix}1&2&4\\2&1&5\\3&0&6\end{bmatrix}$ and eliminate.
step: Row 2 minus $2\times$ row 1: $[0, -3, -3]$. Row 3 minus $3\times$ row 1: $[0, -6, -6]$.
step: Row 3 minus $2\times$ row 2: $[0, 0, 0]$. There are only two pivots, so column 3 is free and the rank is $2 < 3$.
step: So the vectors are dependent. Indeed $2(1,2,3) + (2,1,0) = (4, 5, 6)$.
answer: dependent

@mistakes
- Taking the basis of the column space from the columns of $R$ instead of the pivot columns of the original $A$.
- Saying "the dimension is the number of vectors in the list" without checking independence; a dependent list has fewer independent directions than entries.
- Mixing up the dimensions: $\dim N(A) = n - r$ uses the number of columns, and $\dim N(A^T) = m - r$ uses the number of rows.
- Forgetting the sign in special solutions: the pivot entry is $-R_{if}$, not $+R_{if}$.

```python
from fractions import Fraction

def rank(A):
    M = [[Fraction(x) for x in row] for row in A]
    m, n = len(M), len(M[0])
    r = 0
    for c in range(n):
        p = next((i for i in range(r, m) if M[i][c] != 0), None)
        if p is None:
            continue
        M[r], M[p] = M[p], M[r]
        for i in range(r + 1, m):
            f = M[i][c] / M[r][c]
            M[i] = [a - f * b for a, b in zip(M[i], M[r])]
        r += 1
    return r
```
hint: The rank is the number of pivots found.
hint: For each column, look for a nonzero entry at or below row `r`. If there is one, swap it up, clear below it and increase `r`; if not, skip the column.
solution: Eliminate column by column and count the columns that supply a pivot. Skipping a column without a pivot (instead of stopping) matters for matrices such as `[[0, 1], [1, 0], [1, 1]]`.

```python
from fractions import Fraction

def nullspace_basis(A):
    R = [[Fraction(x) for x in row] for row in A]
    m, n = len(R), len(R[0])
    r = 0
    pivots = []
    for c in range(n):
        p = next((i for i in range(r, m) if R[i][c] != 0), None)
        if p is None:
            continue
        R[r], R[p] = R[p], R[r]
        R[r] = [x / R[r][c] for x in R[r]]
        for i in range(m):
            if i != r:
                R[i] = [a - R[i][c] * b for a, b in zip(R[i], R[r])]
        pivots.append(c)
        r += 1
    basis = []
    for f in range(n):
        if f in pivots:
            continue
        v = [Fraction(0)] * n
        v[f] = Fraction(1)
        for i, p in enumerate(pivots):
            v[p] = -R[i][f]
        basis.append(v)
    return basis
```
hint: First reduce the matrix to reduced row echelon form and record which columns hold pivots.
hint: For each free column `f`, build a vector with `1` at `f`; the entry at the pivot column of row `i` is `-R[i][f]`.
solution: Compute the reduced row echelon form `R` with the list of pivot columns. Every other column is free; its special solution has a `1` in the free position and `-R[i][f]` in the position of the pivot of row `i`. These vectors are independent (each has its own `1`) and span the null space.

```python
from fractions import Fraction

def column_space_basis(A):
    M = [[Fraction(x) for x in row] for row in A]
    m, n = len(M), len(M[0])
    r = 0
    pivots = []
    for c in range(n):
        p = next((i for i in range(r, m) if M[i][c] != 0), None)
        if p is None:
            continue
        M[r], M[p] = M[p], M[r]
        for i in range(r + 1, m):
            f = M[i][c] / M[r][c]
            M[i] = [a - f * b for a, b in zip(M[i], M[r])]
        pivots.append(c)
        r += 1
    return [[row[c] for row in A] for c in pivots]
```
hint: Find which columns contain pivots during elimination.
hint: Return those columns taken from the original `A`, not from the eliminated copy.
solution: Row operations change the column space, but they preserve which columns are independent. So record the pivot column indices during elimination and extract those columns from the original matrix.

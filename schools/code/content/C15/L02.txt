@article
A **linear system** of $m$ equations in $n$ unknowns looks like

$$a_{11}x_1 + \dots + a_{1n}x_n = b_1, \quad \dots, \quad a_{m1}x_1 + \dots + a_{mn}x_n = b_m.$$

Collect the coefficients in a matrix $A$ (with $m$ rows and $n$ columns), the unknowns in $x$ and the right-hand sides in $b$, and the system is $Ax = b$. The **augmented matrix** $[A \mid b]$ stores everything we need.

### Two pictures

The **row picture**: each equation is a line (in $\mathbb{R}^2$) or a plane (in $\mathbb{R}^3$), and a solution lies on all of them. The **column picture**: $Ax = b$ asks for $x_1, \dots, x_n$ such that $x_1 a_1 + \dots + x_n a_n = b$, where $a_j$ are the columns of $A$. That is, is $b$ a linear combination of the columns? Both views describe the same solutions.

### Elementary row operations

Three operations change a system without changing its solution set:

1. **Replace** a row by itself minus a multiple of another row.
2. **Swap** two rows.
3. **Scale** a row by a nonzero number.

**Gaussian elimination** uses them to reach **row echelon form**: all zero rows at the bottom, and each nonzero row starts further right than the row above. The first nonzero entry in each nonzero row is a **pivot**. To clear below a pivot $p$, subtract (entry$/p$) times the pivot row from each lower row; that entry$/p$ is the **multiplier**. If a pivot position holds $0$, swap in a lower row that has a nonzero entry in that column. If there is none, that column has no pivot.

### Back substitution

Once the system is triangular, solve from the bottom up: the last equation gives the last unknown, which you substitute into the equation above, and so on. Cost: about $\tfrac{n^3}{3}$ multiplications for elimination on an $n \times n$ system and about $\tfrac{n^2}{2}$ for back substitution.

### Three possible outcomes

A column with a pivot gives a **pivot variable**; a column without one gives a **free variable**, which can take any value.

- **No solution** if elimination produces a row $[0\ 0\ \cdots\ 0 \mid c]$ with $c \neq 0$ (the equation $0 = c$).
- **Unique solution** if there is no such row and every variable is a pivot variable.
- **Infinitely many solutions** if there is no such row and at least one free variable.

There are never exactly two or three solutions: a consistent system has one solution or infinitely many. In code, use `fractions.Fraction` so that elimination is exact; floating point introduces rounding errors that make "is this entry zero?" unreliable.

```python
from fractions import Fraction

M = [[Fraction(2), Fraction(4)], [Fraction(6), Fraction(3)]]
m = M[1][0] / M[0][0]                       # multiplier 3
M[1] = [a - m * b for a, b in zip(M[1], M[0])]
print(M[1])                                 # [Fraction(0, 1), Fraction(-9, 1)]
```

@example
title: Elimination and back substitution on a 3 by 3 system
problem: Solve $x + 2y + z = 4$, $\ 2x + 5y + 3z = 9$, $\ x + 3y + 4z = 3$.
step: Augmented matrix: rows $[1, 2, 1 \mid 4]$, $[2, 5, 3 \mid 9]$, $[1, 3, 4 \mid 3]$. The first pivot is $1$.
step: Subtract $2\times$ row 1 from row 2: $[0, 1, 1 \mid 1]$. Subtract $1\times$ row 1 from row 3: $[0, 1, 3 \mid -1]$.
step: The second pivot is $1$. Subtract $1\times$ row 2 from row 3: $[0, 0, 2 \mid -2]$. The system is now triangular with pivots $1, 1, 2$.
step: Back substitution: $2z = -2$ gives $z = -1$. Then $y + z = 1$ gives $y = 2$. Then $x + 2y + z = 4$ gives $x = 4 - 4 + 1 = 1$.
step: Check in the original equations: $1 + 4 - 1 = 4$, $2 + 10 - 3 = 9$, $1 + 6 - 4 = 3$.
answer: $(x, y, z) = (1, 2, -1)$

@example
title: No solution versus infinitely many
problem: Classify $x + y = 2,\ 2x + 2y = c$ for $c = 5$ and for $c = 4$.
step: Augmented matrix: $[1, 1 \mid 2]$ and $[2, 2 \mid c]$. Subtract $2\times$ row 1 from row 2: $[0, 0 \mid c - 4]$.
step: For $c = 5$ the last row is $[0, 0 \mid 1]$, meaning $0 = 1$. The system has no solution (two parallel lines).
step: For $c = 4$ the last row is all zeros, so the second equation adds no information. Column 2 has no pivot, so $y$ is free.
step: Set $y = t$. Then $x = 2 - t$. The solutions are $(2 - t, t)$ for every real $t$: infinitely many, forming a line.
answer: $c = 5$: no solution; $c = 4$: infinitely many.

@mistakes
- Applying a row operation to the coefficients but forgetting the right-hand side, which corrupts the system.
- Subtracting a multiple of the wrong row (for instance using the multiplier from the original row 1 after row 1 has changed).
- Declaring "no solution" because a zero row appeared. A row $[0\ 0\ 0 \mid 0]$ is harmless; only $[0\ \cdots\ 0 \mid c]$ with $c \ne 0$ signals inconsistency.
- Dividing by a zero pivot instead of swapping rows.

model:
```python
from fractions import Fraction

def solve(A, b):
    n = len(A)
    M = [[Fraction(x) for x in row] + [Fraction(c)]
         for row, c in zip(A, b)]
    for col in range(n):
        pivot = next(r for r in range(col, n) if M[r][col] != 0)
        M[col], M[pivot] = M[pivot], M[col]
        for r in range(col + 1, n):
            m = M[r][col] / M[col][col]
            M[r] = [a - m * p for a, p in zip(M[r], M[col])]
    x = [Fraction(0)] * n
    for i in range(n - 1, -1, -1):
        s = sum(M[i][j] * x[j] for j in range(i + 1, n))
        x[i] = (M[i][n] - s) / M[i][i]
    return x
```
hint: Build the augmented matrix as a new list of `Fraction` rows so the inputs are not changed.
hint: For each column, find a row at or below the diagonal with a nonzero entry, swap it up, then clear the entries below it. Finish with back substitution from the last row to the first.
solution: Eliminate column by column, swapping a nonzero pivot into place when needed, then solve upward: `x[i] = (rhs - sum of known terms) / pivot`. Using `Fraction` keeps every step exact, so the result compares equal to integers or fractions.

model:
```python
from fractions import Fraction

def classify_system(M):
    A = [[Fraction(x) for x in row] for row in M]
    m = len(A)
    n = len(A[0]) - 1
    r = 0
    for col in range(n):
        piv = next((i for i in range(r, m) if A[i][col] != 0), None)
        if piv is None:
            continue
        A[r], A[piv] = A[piv], A[r]
        for i in range(r + 1, m):
            f = A[i][col] / A[r][col]
            A[i] = [a - f * p for a, p in zip(A[i], A[r])]
        r += 1
    for row in A[r:]:
        if row[n] != 0:
            return "none"
    return "unique" if r == n else "infinite"
```
hint: Track how many pivots you find among the coefficient columns (not the last column).
hint: After elimination, rows below the last pivot row have zero coefficients; if any has a nonzero right-hand side, there is no solution. Otherwise compare the number of pivots with the number of unknowns.
solution: Eliminate column by column, counting pivots `r` and skipping columns with no usable pivot. Any leftover row with zero coefficients but nonzero constant means `"none"`; otherwise `r == n` means every variable is a pivot variable (`"unique"`), and `r < n` leaves free variables (`"infinite"`).

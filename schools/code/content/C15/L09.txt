@article
Most vectors change direction when a matrix acts on them. An **eigenvector** of a square matrix $A$ is a **nonzero** vector $v$ that keeps its direction (or reverses it): $Av = \lambda v$ for some number $\lambda$, the **eigenvalue**. The zero vector is excluded, but $\lambda = 0$ is allowed (it happens exactly for singular matrices).

### Finding eigenvalues

$Av = \lambda v$ means $(A - \lambda I)v = 0$ with $v \neq 0$, so $A - \lambda I$ must be singular:

$$\det(A - \lambda I) = 0.$$

The left side is a degree-$n$ polynomial in $\lambda$, the **characteristic polynomial**. For $2\times2$ matrices,

$$\det(A - \lambda I) = \lambda^2 - (\operatorname{tr}A)\,\lambda + \det A,$$

where the **trace** $\operatorname{tr}A$ is the sum of the diagonal entries. For any $n \times n$ matrix, counted with multiplicity over the complex numbers,

$$\lambda_1 + \dots + \lambda_n = \operatorname{tr}A, \qquad \lambda_1 \cdots \lambda_n = \det A.$$

For a **triangular** matrix, the eigenvalues are the diagonal entries.

### Finding eigenvectors

For each eigenvalue $\lambda$, the eigenvectors are the nonzero vectors of the null space $N(A - \lambda I)$, called the **eigenspace**. Its dimension is the number of independent eigenvectors for $\lambda$. Eigenvectors that belong to **different** eigenvalues are linearly independent.

### Useful facts

- If $Av = \lambda v$, then $A^kv = \lambda^kv$, $A^{-1}v = \lambda^{-1}v$ (when $\lambda \neq 0$), and $(A + cI)v = (\lambda + c)v$.
- A real matrix can have complex eigenvalues. A rotation of the plane by $90^\circ$ has $\lambda^2 + 1 = 0$, so $\lambda = \pm i$ and no real eigenvector: no real direction is preserved.
- A **real symmetric** matrix ($A = A^T$) has real eigenvalues and eigenvectors for different eigenvalues are orthogonal (a result we use in the last two weeks).
- A repeated eigenvalue may have fewer independent eigenvectors than its multiplicity. Such a matrix is called **defective**.

### Power iteration

To approximate the eigenvector for the largest-magnitude eigenvalue (the **dominant** eigenvalue), start with a vector $x_0$ and repeat $x_{k+1} = Ax_k / \|Ax_k\|$. If $|\lambda_1| > |\lambda_2|$ and $x_0$ has a nonzero component along the dominant eigenvector, the iterates converge to that eigenvector, with the error shrinking roughly like $|\lambda_2/\lambda_1|^k$. The **Rayleigh quotient** $x^TAx / x^Tx$ then estimates $\lambda_1$. This simple method is the heart of PageRank-style computations.

```python
import math

def power_step(A, x):
    y = [sum(a * b for a, b in zip(row, x)) for row in A]
    norm = math.sqrt(sum(t * t for t in y))
    return [t / norm for t in y]

x = [1.0, 0.0]
for _ in range(30):
    x = power_step([[4, 1], [2, 3]], x)
print([round(t, 4) for t in x])  # [0.7071, 0.7071]
```

@example
title: Eigenvalues and eigenvectors of a 2 by 2 matrix
problem: Find the eigenvalues and eigenvectors of $A = \begin{bmatrix}4&1\\2&3\end{bmatrix}$.
step: $\operatorname{tr}A = 7$ and $\det A = 12 - 2 = 10$, so the characteristic polynomial is $\lambda^2 - 7\lambda + 10 = (\lambda - 2)(\lambda - 5)$. The eigenvalues are $2$ and $5$.
step: For $\lambda = 5$: $A - 5I = \begin{bmatrix}-1&1\\2&-2\end{bmatrix}$. The null space is spanned by $v = (1, 1)$.
step: For $\lambda = 2$: $A - 2I = \begin{bmatrix}2&1\\2&1\end{bmatrix}$. The null space is spanned by $v = (1, -2)$.
step: Check: $A(1,1) = (5, 5) = 5(1,1)$ and $A(1,-2) = (2, -4) = 2(1,-2)$. Also $2 + 5 = 7 = \operatorname{tr}A$ and $2\cdot5 = 10 = \det A$.
answer: $\lambda = 5$ with $v = (1,1)$; $\lambda = 2$ with $v = (1,-2)$ (and any nonzero multiples).

@example
title: A repeated eigenvalue with only one eigenvector
problem: Find the eigenvalues and eigenvectors of $B = \begin{bmatrix}2&1\\0&2\end{bmatrix}$.
step: $B$ is triangular, so the eigenvalues are the diagonal entries: $\lambda = 2$ twice (the characteristic polynomial is $(\lambda - 2)^2$).
step: Eigenvectors: $B - 2I = \begin{bmatrix}0&1\\0&0\end{bmatrix}$. The equation $(B - 2I)v = 0$ says $v_2 = 0$, with $v_1$ free.
step: The null space is spanned by $(1, 0)$ alone, so the eigenspace has dimension $1$, even though $\lambda = 2$ has multiplicity $2$.
step: So $B$ is defective: there are not enough independent eigenvectors to span $\mathbb{R}^2$.
answer: $\lambda = 2$ (repeated) with a single independent eigenvector $(1, 0)$.

@mistakes
- Accepting $v = 0$ as an eigenvector. Eigenvectors must be nonzero.
- Forgetting that $\det(A - \lambda I) = 0$ subtracts $\lambda$ only along the diagonal; $A - \lambda$ is not meaningful.
- Assuming eigenvalues of $A + B$ are sums of eigenvalues of $A$ and $B$, or eigenvalues of $AB$ are products. This holds for shifts $A + cI$, not for general sums or products.
- Assuming a repeated eigenvalue always gives two independent eigenvectors; the matrix $\begin{bmatrix}2&1\\0&2\end{bmatrix}$ has only one.

model:
```python
import math

def eigenvalues_2x2(A):
    tr = A[0][0] + A[1][1]
    det = A[0][0] * A[1][1] - A[0][1] * A[1][0]
    d = math.sqrt(tr * tr - 4 * det)
    return ((tr - d) / 2, (tr + d) / 2)
```
hint: Compute the trace and the determinant, then solve the quadratic.
hint: The roots are $(\operatorname{tr} \pm \sqrt{\operatorname{tr}^2 - 4\det})/2$; put the minus sign first so the tuple is increasing.
solution: The quadratic formula applied to $\lambda^2 - \operatorname{tr}\,\lambda + \det = 0$ gives the roots. Since the square root is nonnegative, `(tr - d) / 2` is the smaller one.

model:
```python
import math

def power_iteration(A, iters):
    n = len(A)
    x = [1.0] + [0.0] * (n - 1)
    for _ in range(iters):
        y = [sum(a * b for a, b in zip(row, x)) for row in A]
        norm = math.sqrt(sum(t * t for t in y))
        x = [t / norm for t in y]
    y = [sum(a * b for a, b in zip(row, x)) for row in A]
    lam = sum(a * b for a, b in zip(x, y))
    return lam, x
```
hint: Each iteration multiplies by `A` and divides by the length of the result.
hint: After the loop, the Rayleigh quotient is the dot product of `x` with `A x`.
solution: Normalizing every step keeps the numbers from growing. Because the dominant eigenvalue is strictly larger in magnitude than the others, the direction of `x` converges to its eigenvector, and $x^TAx$ with $\|x\| = 1$ converges to the eigenvalue.

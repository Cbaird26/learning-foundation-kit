@article
Diagonalization needs a square matrix with enough eigenvectors. The **singular value decomposition** (SVD) works for **every** real matrix. For an $m \times n$ matrix $A$ of rank $r$,

$$A = U\Sigma V^T,$$

where $U$ is an $m \times m$ orthogonal matrix, $V$ is an $n \times n$ orthogonal matrix, and $\Sigma$ is an $m \times n$ matrix that is zero except on its diagonal, where the **singular values** $\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_r > 0$ appear (followed by zeros). Geometrically: rotate or reflect with $V^T$, stretch along the coordinate axes by the $\sigma_i$, then rotate or reflect with $U$. The unit circle becomes an ellipse whose semi-axes have lengths $\sigma_1, \sigma_2$.

### Where the pieces come from

The matrix $A^TA$ is symmetric and positive semidefinite, so it has real eigenvalues $\lambda_i \ge 0$ and orthonormal eigenvectors. Then:

- the columns of $V$ (the **right singular vectors**) are orthonormal eigenvectors of $A^TA$,
- the singular values are $\sigma_i = \sqrt{\lambda_i}$,
- the columns of $U$ (the **left singular vectors**) are orthonormal eigenvectors of $AA^T$; for $\sigma_i > 0$ they satisfy $u_i = Av_i/\sigma_i$.

The key relation is $Av_i = \sigma_iu_i$. A quick check on any square matrix: the product of the singular values is $|\det A|$.

### Rank and the four subspaces

The rank of $A$ is the number of nonzero singular values. The first $r$ columns of $U$ are an orthonormal basis of $C(A)$, the last $m - r$ columns of $U$ a basis of $N(A^T)$; the first $r$ columns of $V$ are a basis of the row space and the last $n - r$ columns of $V$ a basis of $N(A)$. So the SVD gives orthonormal bases for all four fundamental subspaces at once.

### Rank-one sums and compression

Multiplying out gives

$$A = \sigma_1u_1v_1^T + \sigma_2u_2v_2^T + \dots + \sigma_ru_rv_r^T,$$

a sum of rank-one matrices ordered by importance. Keeping only the first $k$ terms gives $A_k$, of rank $k$. The **Eckart-Young theorem** says $A_k$ is the **best** rank-$k$ approximation of $A$, in the sense of both the spectral norm and the Frobenius norm. The errors are

$$\|A - A_k\|_2 = \sigma_{k+1}, \qquad \|A - A_k\|_F = \sqrt{\sigma_{k+1}^2 + \dots + \sigma_r^2},$$

where $\|A\|_F^2$ is the sum of the squares of all the entries, which also equals $\sigma_1^2 + \dots + \sigma_r^2$.

Storing $A_k$ takes $k(m + n + 1)$ numbers (the $k$ vectors $u_i$, the $k$ vectors $v_i$ and the $k$ singular values) instead of $mn$, a large saving when $k$ is small. This is how SVD compresses an image stored as a matrix of gray levels, and the same idea underlies principal component analysis (PCA), latent semantic analysis and recommender systems. The ratio $\sigma_1/\sigma_r$ is the **condition number** of $A$, which measures how much solving $Ax = b$ can amplify errors in the data.

```python
import math

def singular_values_2x2(A):
    (a, b), (c, d) = A
    p = a * a + c * c          # entries of A^T A
    q = a * b + c * d
    s = b * b + d * d
    tr, det = p + s, p * s - q * q
    disc = math.sqrt(max(tr * tr - 4 * det, 0.0))
    return (math.sqrt(max((tr + disc) / 2, 0.0)),
            math.sqrt(max((tr - disc) / 2, 0.0)))
```

@example
title: Singular values of a 2 by 2 matrix
problem: Find the singular values of $A = \begin{bmatrix}3&0\\4&5\end{bmatrix}$.
step: Compute $A^TA$: the columns of $A$ are $(3, 4)$ and $(0, 5)$, so $A^TA = \begin{bmatrix}25&20\\20&25\end{bmatrix}$.
step: Its trace is $50$ and its determinant is $625 - 400 = 225$, so the eigenvalues solve $\lambda^2 - 50\lambda + 225 = 0$, giving $\lambda = 45$ and $\lambda = 5$.
step: The singular values are $\sigma_1 = \sqrt{45} = 3\sqrt5$ and $\sigma_2 = \sqrt5$.
step: Check: $\sigma_1\sigma_2 = 15$ and $|\det A| = |15 - 0| = 15$. Also $\sigma_1^2 + \sigma_2^2 = 50 = 9 + 0 + 16 + 25$, the sum of squares of the entries.
answer: $\sigma_1 = 3\sqrt5 \approx 6.708$, $\sigma_2 = \sqrt5 \approx 2.236$.

@example
title: Best low-rank approximations and storage
problem: $A = \begin{bmatrix}5&0&0\\0&3&0\\0&0&1\end{bmatrix}$. Find the best rank-1 and rank-2 approximations and their errors, and the storage of a rank-5 approximation of a $100 \times 80$ matrix.
step: $A$ is diagonal with positive entries, so its SVD is $A = I\,\Sigma\,I$ with singular values $5, 3, 1$ and $u_i = v_i = e_i$.
step: Rank 2: keep $\sigma_1 = 5$ and $\sigma_2 = 3$, so $A_2 = \operatorname{diag}(5, 3, 0)$. The error is $\|A - A_2\|_2 = \sigma_3 = 1$ and $\|A - A_2\|_F = 1$.
step: Rank 1: $A_1 = \operatorname{diag}(5, 0, 0)$. The spectral error is $\sigma_2 = 3$ and the Frobenius error is $\sqrt{3^2 + 1^2} = \sqrt{10}$.
step: Storage: a rank-5 approximation of a $100\times80$ matrix needs $5(100 + 80 + 1) = 905$ numbers instead of $100\cdot80 = 8000$, about $11\%$.
answer: Errors $(1, 1)$ for rank 2 and $(3, \sqrt{10})$ for rank 1 (spectral, Frobenius); $905$ numbers instead of $8000$.

@mistakes
- Taking singular values to be eigenvalues of $A$. They are square roots of the eigenvalues of $A^TA$ (and can be computed for non-square or non-diagonalizable matrices).
- Forgetting the square root, so reporting the eigenvalues of $A^TA$ as singular values.
- Computing the rank-$k$ storage as $k \cdot m \cdot n$; it is $k(m + n + 1)$.
- Choosing the singular vectors $u_i$ and $v_i$ independently. Each pair must satisfy $Av_i = \sigma_iu_i$ (signs must match).

model:
```python
import math

def singular_values_2x2(A):
    (a, b), (c, d) = A
    p = a * a + c * c
    q = a * b + c * d
    s = b * b + d * d
    tr = p + s
    det = p * s - q * q
    disc = math.sqrt(max(tr * tr - 4 * det, 0.0))
    big = max((tr + disc) / 2, 0.0)
    small = max((tr - disc) / 2, 0.0)
    return (math.sqrt(big), math.sqrt(small))
```
hint: $A^TA$ has entries $p = a^2 + c^2$, $q = ab + cd$, $s = b^2 + d^2$.
hint: The eigenvalues of $A^TA$ are $(\operatorname{tr} \pm \sqrt{\operatorname{tr}^2 - 4\det})/2$.
solution: Compute the three distinct entries of $A^TA$, solve the quadratic for its eigenvalues (larger one first), clamp tiny negatives to zero for rank-deficient matrices, and take square roots. For `[[1, 1], [1, 1]]`, $A^TA$ has eigenvalues $4$ and $0$, so the singular values are $2$ and $0$.

choice: The columns of $V$ are the eigenvectors of $A$, and $\sigma_i$ are the eigenvalues of $A$.

hint: Compute $A^TA = V\Sigma^TU^TU\Sigma V^T$ and simplify using $U^TU = I$.
solution: $A^TA = V\Sigma^T\Sigma V^T$, which is a diagonalization with eigenvector matrix $V$ and eigenvalues $\sigma_i^2$. The columns of $U$ (not $V$) are the eigenvectors of $AA^T$. Singular values are square roots, hence never negative, and are not the eigenvalues of $A$ in general.

model:
```python
def smallest_rank(sigmas, fraction):
    total = sum(s * s for s in sigmas)
    partial = 0
    for k, s in enumerate(sigmas, start=1):
        partial += s * s
        if partial >= fraction * total:
            return k
    return len(sigmas)
```
hint: Compute the total energy first, then accumulate squares one at a time.
hint: Stop at the first `k` where the running sum reaches `fraction * total`.
solution: Add up $\sigma_i^2$ in order and return the first index at which the partial sum is at least `fraction * total`. For `[5, 3, 1]` the squares are $25, 9, 1$ with total $35$, so $25/35 \approx 0.714$ already covers $0.7$ but not $0.72$.
